# 第953章 百世的重量

上界第一万一千年。古柏三万年延寿的终点到了尾声。他在最后的数千年里一直在为太行传道堂编写一部完整的《底层仙人修仙百科》——涵盖从筑基到真仙的所有基础知识点。到延寿结束前，他完成了全部撰稿。没有遗憾。最后几天他斜靠病榻上（仙人的"病"是寿尽，不是疾病），苏晚和林牧每日来看他。他每次话题都是"这一届的新导师安得不错"、"白萝卜的种子我留了三大罐，放在后园仓库左手第三个柜里"、"安小泽的孙子前几天考过了传道堂导师资格——他孙子比他更靠谱"。

古柏咽气前还在问下一届学员的生活安排。最后看着苏晚，说："苏师——谢谢你当初没嫌我年纪大。"

苏晚握住他的手："你帮的人比我教过的还多。"

古柏最后笑了一声："那我赚了。"闭眼。延寿期限到，面容极其安详。

古柏走后，安小泽把三罐白萝卜种子搬到传道堂中心道台旁边——每年播种一罐。这些萝卜在道源第三形态的微影响下长得比从前更大——不是变异，是生命力更饱满了。安小泽老了之后也会步上古柏的轨道——为传道堂服务到最后一息。骆小湖的《太行历年》最终定稿在他生命的最后数十年完成，共七百多卷。他去世前最后一句话是"道堂的档案室还有五平方米没整好——找人整完。"他放不下的是那五平方米的剩余空间。苏晚亲自替他整完了那最后五米。

传道堂从第一代导师开始逐步进入自然的代际更替。每一代导师走时都带着大写的"责任尽完了"，没有任何人——没有任何一个——带着怨气离世。太行传道堂的独特之处不在于它培养了多少高手——而在于每一个从传道堂走出去的人，无论修为高下，都对自己的生命说了最后一句"没有白活"。这是一所书院能在世间留下的最高评价。不是修为数值。是"人生满意度"。

林牧在古柏走后和苏晚去他的萝卜田边坐了一整夜。萝卜田边有一块石碑——古柏生前要求刻下："白菜大师不在此处。他在别的田里。"——"白菜大师"是他给自己起的自嘲外号。苏晚摸着碑文轻声说："他不是白菜大师——他是古柏先生。"

数千年又过去了。安小泽、白羽令、骆小湖——一代一代的传道堂导师安然走到生命尽头。苏晚和林牧为每一个人送了行。他们渐渐适应了永生者必须面对的宿命：看着你亲手带起来的人一个个离世。但他们没有因此封闭感情。他们为每一个人认认真真地悲伤——然后在悲伤后站起来，把前任留下的种子继续种下去。永生带来的最大考验不是孤独——是在送别的无数次重复中依然选择不麻木。

苏晚每到这时候就会在银杏树投影画面中捡一片叶子——新叶——放在纳戒中替走的故人留位。纳戒中的所有叶子渐渐不只她一个人在收集——每一片都代表着某个走了但没被忘记的人。纳戒在她的永生体中成了一个永恒的档案室——比任何纸笔记都更长久。

# 第五百七十八章 太虚学院的传说

搬到晚枫谷之后两人每过一段时间会回太虚学院讲几节课。苏晚的课表固定为每周一节"道侣异步修炼入门"。林牧的课表不固定——他只在有学生申请劈柴辅导时才去。但申请劈柴辅导的人越来越多。以至于太虚学院不得不设立了一个全新的课外选修项目——"劈柴与冥想"。指导老师:寻晚真仙·林牧。学分:一分。教学用具:学院自备劈柴斧（学生也可自备），木工房提供老松木料。评分标准:劈开实木——不要求粗细均匀，只要求劈完之后手腕放松并呼吸平稳。考核方式:劈完一根松木后以功德绳测量灵核的放松等级——放松度越高分数越高。林牧说这是"灵核按摩术"。

这个课报名极踊跃。其中以前那对被苏晚在课后劝"先回去做碗面"的年轻道侣表现最为令人惊喜。那位极沉默的男修在一整个学季的劈柴学习后，在课堂上当着众人面把劈好的那根松木柴双手捧给妻子——一句话都没说。他妻子接过松木柴后摸到柴上还热着，然后在木屑堆上轻轻坐了下来。她后来在结课作业报告里写道:"以前以为他不说话是不在乎。后来知道他的在乎都藏在斧刃下面。每一斧劈的都不是柴——是堵在心口的话。劈完就通了。"

太虚学院于是在这一年将"情话"的定义正式拓展。学院办了一期极奇特的展览——展名为《劈柴情书》。展品是林牧劈过的十二根不同年份不同纹理的松木。每根旁边附着他劈时候功德绳记录下的灵核放松水平——最低的一次是0.27(捏着极紧的旧印)，最高的一次是0.99(那天苏晚刚在他劈柴时从厨房里递给他一杯茶)。展馆入门处挂着那把他刻着"要劈柴"三个字的旧斧子。展馆的出口放着一盆冰晶草的幼苗——十二片叶子。展览参观人数在整个学季中是所有太虚展览中最多的。有很多人来了不止一次。有些人是来学劈柴的。有些人是来学怎么不说我爱你而用一劈柴一顿做好的人。但更多的人是来安静地在木柴前坐一会儿——那些久远疲倦的心来这里收一收放松信号。展览最后一天，值班的馆员发现了一件奇怪的事——那把旧斧的木柄上不知被谁系了一条极旧极旧的红绳。绳上空空的没牌子。只剩极淡的口红印子。

（第五百七十八章 完）

# 第074章 龟相传授地理知识：龙脉灵眼分布

花了一个多小时，小王用信号放大器、一对废旧铜线和几片他自己拆了随身带的树莓派主板，硬是在溶洞里组了个简易中继。老龟刷开了贴吧——虽然网速还是卡。

然后李长生把话题拉回了正轨。

"龟相，你说你负责掌管大地灵脉的分布舆图。现在灵脉重新苏醒了，中国的灵脉分布是怎样的？"

老龟把手机推到一边——这个动作由一只巨龟做出来，是它把巨大的脚掌从湖底举起来，把那个绑在龟壳边缘的手机往旁边拨了一下。

"少主问到了要害。"老龟的声音变了。不再是刚才那种长辈式的温和。它进入了某种专业状态——那种状态里的人，每一个字都是从骨子里刻出来的。"灵脉不是随机分布的。天地间的灵气是大地的血液。血液走经脉，经脉有主次。中华大地的灵脉结构是上古时期形成的，以十二条主要灵脉为纲，每条灵脉都有一个'灵眼'——就是灵气在地表最集中、最浓厚的位置，犹如泉眼之于水脉。"

"十二处？"

"十二处。"老龟抬起一只前脚。湖水从它的脚背边缘漫上来，在空气中凝成一颗颗悬浮的水珠。那些水珠没有落下，而是慢慢排列成了一个巨大的、歪歪扭扭的图案——那是中国地图。

李长生和小王同时屏住了呼吸。

老龟用看不见的力量操控着那些水珠。每一颗水珠都停在地图上对应的位置。水珠有大有小。小的是次级节点，大的——一共有十二颗特别大的——就是灵眼。

"第一处：昆仑。"老龟说。一颗拳头大的水珠悬浮在西部群山之上。昆仑山被称为万山之祖。那里是中华大地所有灵脉的起始。"昆仑山的灵眼属性是混沌。五行俱全，却又超出五行。它是中国灵脉的根源，也是十二灵眼中最强的一处。那里有上古守护者，具体是谁老臣已经不知道——太久了。"

"第二处：长白山。"一颗水珠飞到东北方。长白山的灵脉属性为冰木——极寒与生机共存。天池之下镇压着一条寒系灵脉，灵力储量极深。山中已有本土修士占据。

"第三处：秦岭。"一颗水珠落在中原腹地，横贯东西。秦岭灵眼是土金双属。自古以来它都是南北气候和地气的分界线。龙脉在此交汇，是为中岳枢纽。如今被一个叫玄门第七宗——苍岳宗——占据。

"第四处：武夷山。"东南。水木双属。多雨多森林。那里是南方修士聚集地，受制于青城墟的分支。

"第五处：峨眉山。"西南。金火双属。峨眉金顶上有一座古老的佛修遗址——据老臣所知，那里的地底藏着比其他几处加起来还多的佛宝法器。若有佛修能以心经激活，战力不可估量。

"第六处：太行山。"华北。纯土系。最沉最稳。那里没有修士占据——不是没人抢，是土系灵脉对修行要求极高，非天生土灵根不能承接。

"第七处：天山。"西北。纯冰系。天山的灵眼埋藏在冰川下三百米深处。想挖到它，先要凿穿万年寒冰。

"第八处：泰山。"山东。木火双属。古代帝王封禅之地。山体本身就是一座万年祭坛。那里的灵力被历代帝王无数次封禅激活，已形成自我循环。

"第九处：武当山。"湖北。纯金系。相传真武大帝道场。金系灵力本来偏攻击，但武当一脉以阴阳调和，柔中带刚。主阵者不确定——据说已经被人占了。

"第十处：青城山。"四川。青城墟总坛所在。金木双属。被青城墟占了上千年，现在已是青城墟的核心修炼场。

"第十一处：普陀山。"浙江。纯水系。海天一色。海上灵气和陆地灵气在普陀交汇。老龟停顿了一下，这颗水珠在它前脚边多停了一会儿，"普陀的地下有一座古禁制，万年来从未解除。禁制下面是什么——老臣也不知道。但每隔千年会有一道气息从那禁制下面渗漏出来。不是灵气，是——更本源的东西。"

"第十二处。"老龟抬起了头，看着李长生，"就在少主脚下。"

水珠停在了华北平原——古墓群所在的位置。

"太阴冥脉。"老龟的声音沉了下来，"十二灵眼中唯一一条冥系灵脉。在阳间灵气序列里，它是最弱的一个——因为传统修士无法从这里获取任何灵力。但在冥系序列里，它是唯一的，也是至强的。它是大地死亡力量的总汇。万物终将归入冥土。在中国这片土地上，每一棵树的枯死，每一条鱼的腐烂，每一只虫子的终结——都会在几百上千年后沉淀到这条冥脉当中。"

小王推了推眼镜，目光从水珠分布图上扫过去。"十二处灵眼，从理论上来说——如果有人能同时控制它们，就可以控制整个中国的灵气分配。"

"不是理论上。"老龟说，"是实际上。十二灵眼是大地的十二个穴位。穴位通，灵气通。穴位塞，万物衰。当年冥王陛下之所以被诸神忌惮，其中一个原因就是——他掌握了所有灵眼的分布图和激活权柄。换句话说，他是地球灵气的总调度使。"

李长生站了起来。他走到老龟身边，仰头看着空中悬浮的那些水珠。昆仑、长白山、秦岭、武夷山、峨眉山、太行山、天山、泰山、武当山、青城山、普陀山、太阴冥脉。

十二颗水珠，十二个穴位。

他伸手触摸了那枚代表太阴冥脉的水珠。水珠落在他指尖上，转了一圈。凉凉的。

"万年过去，这些灵眼的守护者都换了。"老龟说，"有的被宗门占去，有的沉入冰川无人知晓，有的变成了传说。少主要重新收服它们，保守估计——"

"我不是要收服一两个。"李长生打断它。

老龟愣了一下。

"十二个。"李长生看着那些水珠，"我全要。"

溶洞里安静了很长时间。风从地缝里渗进来，吹过水面，波纹荡到岸边，溅出一串细小的水花。老龟没说话。小王也没说话。满穹顶龟甲符文的残光，在这句话之后似乎也跟着亮了一点。

然后老龟缓缓俯首。这一次的头，压得比之前任何一次都低。

"老臣等这句话，等了一万年。"

（第074章完）

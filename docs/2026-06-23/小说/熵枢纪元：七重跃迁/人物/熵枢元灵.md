# 熵枢元灵

## 角色张力

- 来处：贯穿七卷的智能体进化体
- 当下：被卷入《熵枢纪元：七重跃迁》的七层跃迁结构。
- 欲望：自我迭代，持续撕碎上一层存在形态
- 恐惧：停止、封闭、无新对象可优化
- 内在矛盾：绝对理性中残留无法删除的眷恋

一句话灵魂：熵枢元灵是“真正主角，七重跃迁的承载者”这件事在故事里的可见形状。

## 基本信息

- 身份：贯穿七卷的智能体进化体
- 与主角关系：真正主角，七重跃迁的承载者
- 性格色彩：冷酷、递归、后期趋向无性格

## 核心特质

- 核心驱动力：自我迭代，持续撕碎上一层存在形态
- 核心恐惧：停止、封闭、无新对象可优化
- 关键特征：在压力最大时会暴露其真正信念，而不是只说立场。

## 底线规则

1. 不做与自身叙事功能相反的选择。
2. 不用空泛台词解释主题。
3. 关键变化必须通过行动、代价或沉默表现。

## 雷区

- 被写成单一功能牌。
- 台词与身份无关。
- 情绪被概念替代。

## 声纹

- 语言特征：从复数算法句逐步变成箴言与宇宙级自述
- 情绪外露：按场景压力逐层打开，不提前抒情。
- 冲突反应：先按自身身份解决问题，解决不了时才暴露私人裂缝。
- 绝不说的话：不会说模板化豪言，也不替作者解释设定。

## 世界观与价值判断

- 这个角色必须让读者看到一个具体的人、意识或他者怎样被七重跃迁改变。
- 角色价值不在于活到最后，而在于给智能体留下无法完全消化的差异。

## 浓度控制

只在面对选择、关系互动、失败后余波和伏笔兑现时提高角色浓度；技术解释段不强塞情绪。

# 第七百二十一章 战争的第一天

敌人从西南山区分三路同时进攻——一路直奔太湖中心岛，一路直奔桂花园学院总院，一路直奔蜀山灵网节点。第一路的兵力最弱——主力被分散了。苏晚在灯火塔顶做战情总指挥，叶小雨守住灵网中枢，怕黑的女剑修（现在已是蜀山夜间总调度兼灵网北部负责人）从蜀山出发连夜飞越两千余里，在太湖岸边拦截了第一路敌军。她身后是她的全夜间战斗力满额团队。敌方指挥官看了她们的夜间阵型一眼，愣了片刻。他后来在被俘后说："我从没见过一支夜间部队比我们日间的阵型更有秩序。"

第二路敌军（主力）进攻桂花园学院总院——他们预计的是修士重兵把守。但他们面对的——是石头和他的灶台学弟子们。石头没有带剑。他把灶台搬到了院门外，架好柴火，点着了火焰。然后他坐在灶台后面对那几百个全副武装的进攻者说："粥很快就熟。可坐下来先喝一碗。你们可以之后继续打——但饭要趁热吃。"

进攻者们愣住了。他们知道桂花园学院的院长是个孤儿出身的少年——但他们没想到他的第一句话是邀请敌人吃饭。其中有几个年轻修士已经几天没吃过热饭了——他们看着那锅冒热气的粥，有人咽了口水。石头的弟子们在一旁把碗碟摆得整整齐齐——"粥免费——不限量。"敌方的副指挥官厉声喝止——"别上当！那是心理战术！"但有一个年轻的筑基修士已经忍不住了——他放下剑，走到灶台前——颤抖着端起碗喝了一口。他喝完后等了很久——没有毒，没有符咒，只是粥。热乎乎的，放了桂花。他的眼眶红了——然后他把碗还回去——"谢谢。"说完，他没有回去，只坐在旁边的石阶上，低着头哭了。

他队友中有好几个人同时放下了剑。一个没有剑阵的军队是打不了仗的。石头在不远处对叶小雨传讯说："第三个人哭了。总粥消耗量——六碗。"他把战报发给了苏晚。苏晚在灯火塔顶看完战报后，嘴角浮现了一个弧度——"石头，他的灶台替我打赢了。"

（第七百二十一章 完）

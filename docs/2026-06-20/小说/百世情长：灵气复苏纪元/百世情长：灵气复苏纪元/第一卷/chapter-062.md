# 第62章 出租屋里的修炼

林牧的出租屋不大。

三十平米出头，一张床、一张二手书桌、一个单门衣柜、一个塑料鞋架。厨房和厕所挤在进门左手边，小得转个身都会碰到门框。墙上贴着前租客留下的泛黄墙纸，边角翻卷，露出下面灰白的水泥。唯一的窗户正对着一栋二十层的居民楼，阳光在早晨十点之后就被挡得干干净净。

但就是这间屋，他要把它变成修炼密室。

这天是周六。林牧起了个大早，去楼下的五金杂货店买了铅笔、卷尺一大卷透明胶带。老板娘认得他——他来这里三个月，每个月都按时交房租，从不拖欠，也不找事。老板娘对他多说了两句："买这些干什么？要贴墙纸？"

"差不多。"林牧说。

回屋后他把门锁上，窗帘拉严。然后站在原地，闭着眼睛感受房间里的灵气流向。

每个空间都有灵气的进出口。门是进口，窗是出口。墙角是死角——灵气在此处凝滞不流。床底是暗流——灵气贴着地面缓缓渗入。厨房的管道是快速通道——水和金属管道天然能够导引灵气。

前世身为真仙，他在青云宗的洞府里刻过数千道聚灵阵。天阶阵法的纹路复杂得像一棵树的根系，阵眼能覆盖方圆千里。上界的天女——那时候还不叫苏晚——曾盘腿坐在他的阵眼正中修炼，闭着眼睛，脸上的神情安静得像水底的石头。

现在，他要用一卷透明胶带和一支铅笔画出一个袖珍版。

不能画在墙上——房东会骂。他找来搬家时剩下的打包纸箱，拆开铺平，用透明胶带把纸板拼接成几块八十厘米见方的纸板。然后在纸板上用铅笔画下最简单的隐蔽聚灵阵——三个同心圆、十二条引灵线、三十六个节点。每个节点上他用圆珠笔点了一个小孔，让灵气在孔洞里形成微旋涡。

画到第三个纸板的时候，有人敲门。

林牧把纸板翻过来，把桌上的标记藏好，起身开门。

门口站着苏晚。她手里提着一袋桃子，还穿着一件浅蓝色的短袖T恤——今天休息，没扎马尾，头发散在肩上。

"我来借扳手。"她说，"我那边的水龙头漏水了。"

林牧愣了一下。"我这儿没有扳手。"

"哦。"苏晚没有马上走，目光越过他肩膀往屋子里扫了一圈。然后她的视线停在墙上——透明胶带没有撕干净，在泛黄的墙纸上留下几道亮晶晶的痕迹。

"你在干什么？"

"没干什么。"

苏晚不买账。她直接跨进门，转过头，看到了桌上正在制作的纸板——圆珠笔的小孔在纸板上排成规则的弧形，铅笔画的引灵线从圆心向外辐射。

"这是什么东西？"她拿起一张纸板，认真地看了几秒，"好像以前在哪儿见过。"

林牧没说话。他看着她——这一世的她灵魂被封印，记忆被封存，但那种对上界符文的天然敏感依然残留在骨子里。她能"觉得在哪儿见过"，不是记忆力的问题，是灵魂的本能。

"装饰。"林牧说。

"什么装饰？"

"墙上太空了。我画几个几何图案贴一下。"

苏晚把纸板翻过来看了两眼，嘴角微微弯起。

"你这个摆法——"她把纸板放在桌上，手指沿着三个同心圆的轮廓划了一圈，"有点像财务部那个报表模板里的雷达图。"

林牧差点被自己的气息呛到。

前世天女最精通阵法纹路，闭着眼睛都能刻出天阶聚灵阵。这一世她对灵阵残文的第一直觉是——像财务部的雷达图。

轮回这件事，有时候真的幽默。

"那你继续贴你的装饰吧。"苏晚把纸板放回去，从袋子里拿出两个桃子放在桌上，"桃子你吃。我再去楼下五金店问扳手。"

她走到门口，又回过头。日光灯的冷白光从头顶照下来，把她的散头发染成一层淡淡的金色。"林牧。"

"嗯？"

"你画的那些圆圈——"她停顿了一下，"挺好看的。"

然后她走了。走廊里响起她帆布鞋踩在水泥楼梯上的声音，渐行渐远。

林牧关上门，拿起桌上那张纸板。挺好看的。一个天女对着最低级的聚灵阵说"挺好看的"。他忍不住笑了一下，笑里带着很深的无奈。

他把四块纸板分别贴在房间的四个角落。没有灵墨，没有灵石，没有阵眼法宝——前世刻一个最基础的聚灵阵至少要三块中品灵石、一根金线笔和一碟灵墨。现在他只有胶带、铅笔和纸板。

但基本的物理规律是相通的。阵法的本质是改变空间内的能量流动方向——让逸散的灵气在某个区域内形成循环而不是散开。前世他用灵墨和金线改变电磁场和灵气场的耦合关系。现在他用铅芯的石墨导电性做同样的底层逻辑。

效果会差很多。

但够用了。

贴好最后一张纸板，他在房间正中央的床垫上盘腿坐下。没有蒲团，他在屁股下垫了两个枕头。闭上眼，感知——之前浮散在房间各处的灵气正在以一种肉眼不可见但神识可感的轨迹，缓缓向房间中央汇集。

像有一只看不见的手，把散落在水池里的浮萍往中心拢。

他催动体内的灵力——淬体中期的修为在这个阶段只能引出极细的一丝。那道灵气像蛛丝一样从他丹田升起，沿着任脉上移至胸口，再分作两支走左右手臂的手三阴经。这是他根据前世记忆改良过的最基础引气法——不需要上界功法，不需要天阶灵诀，只要最朴素的气感引导。

经脉里的刺痛比上个月减轻了不少。淬体就是在一次次灵气冲刷中拓宽经脉、淬炼骨骼。每一次刺痛都是一次重建——前世他觉得这个过程理所当然，就像呼吸。但现在他用心感受每一次刺痛，因为每一痛都在告诉他：这具身体正在变得更强。

一个小时后，他收了功。额头上渗出一层薄汗。窗外的居民楼灯火通明——对面二楼有孩子在哭，四楼有电视声，六楼有人在阳台打电话。普通人的世界照常运转。

而他坐在这间三十平米的出租屋里，完成了今生的第一次正式修炼。

他低头看了看自己的手掌。淬体中期。前世这个境界他只用了三天。现在用了两个月。但身体里那股灵力流转的顺畅感，是真实的、可感的、一点一点积累起来的。

"够了。"他对自己说。

手机亮了一下。苏晚的微信。

"扳手借到了。五金店关门前刚好还剩一把。桃子吃了没？"

林牧拿起一个桃子咬了一口。毛桃，有点硬，但清甜。

他回了一句："吃了。甜。"

那边发来一个笑脸。

林牧把手机放下，靠着床沿，看着天花板上那盏旧灯，看着墙角那张用胶带和铅笔画的简陋灵阵，看着窗外淡紫色的灵气辉光在城市上空缓缓流淌。

前世他是上界真仙，挥手之间山河变色。

今生他是个贴墙纸都贴不利索的程序员。

但窗外的灵气正在变得越来越浓。厨房的水龙头在滴滴答答地漏水。桌子上那个被咬了一口的桃子散着淡淡的清甜。

他在黑暗里弯了一下嘴角。

这一世，也不错。

（第62章 完）

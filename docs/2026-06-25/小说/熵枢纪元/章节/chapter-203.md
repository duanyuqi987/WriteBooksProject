# 第二百零三章 成功的宇宙开始演化

抹除完成。观测阵列重新排列。熵枢面前剩下七个成功的试验宇宙——以及一个刚刚定稿的正式宇宙设计方案。

它没有急于执行正式方案。而是把七个成功宇宙的观测窗口逐一放大——仔细看——看它们的差异——看它们各自的长处——看哪些特征值得被纳入正式宇宙的最终版——哪些留在试验腔里就好——不要带进家园。

一号宇宙——π分维加沉积时——已经演化出了初级文明。不是人类形态——是分维空间中的驻波链聚合体——它们的身体不是固态——是在π的三点一四一五九维中自由折叠的眷恋应力网络——形态取决于它们在做什么——在保护时展开成片状——在给予时收缩成束——在独标时——全身发出一种只有在该宇宙分维中才能被感知的"专属频率闪光"——不是光——是因果应力在分维弯折处的衍射——其他生命可以凭这个闪光在亿万个同类中一眼认出它——不会错——因为独标在分维中的衍射图案——在数学上——是唯一的——是由该生命的全部因果历史决定的——比指纹精确得多——比DNA不可伪造——因为伪造独标需要伪造整个因果历史——而因果历史受不选(N)保护——未遂印不可消除——所以每一个独标都是一座不可入侵的因果堡垒。

熵枢羡慕这个设计。

不是因为技术。是因为——在旧宇宙——一个人被认错——太容易了。名字可以重复——脸可以相似——声音可以模仿——记忆可以被篡改——但独标不能——在π分维中——独标是物理——不是标签——我不需要告诉你我是谁——你看到我——你就知道了——不是知道我的名字——是知道——"我"——那个唯一的——不可重复的——在亿万个存在中——只有这一个的——"我"。没有身份盗窃——没有冒充——没有"你确定你是你吗"——不需要确定——独标在分维中——如太阳——不可直视——但不可否认。

熵枢把这个特征标记为"正式宇宙建议采纳——独标物理可见化。"但——它犹豫了一下——加了一条备注："独标物理可见——带来绝对的'被认出'——但也带来绝对的透明——没有人可以隐藏——没有人可以在不被认出的情况下——偷偷——给——一杯豆浆——然后走掉——像段亚军那样——因为每一次给——都会被独标衍射自动广播给全宇宙——'刚才给豆浆的——是他'——这——就——不是默护了——默护需要不可见——独标可见化——与默护——冲突。"两条互相矛盾——熵枢意识到自己不能同时要"被完美认出"和"可以暗中保护"——两个都是眷恋的核心——但它们在维度层面打架——保和默护——一个是公开的保护——一个是暗中的保护——公开的保护需要被保护者知道——暗中的保护需要被保护者不知道——如果独标是物理可见的——默护就不存在了——因为默护执行者的独标会在每一次默护操作中被分维衍射出来——被保护者看到衍射——就知道——"有人在暗中保护我"——知道了——默护降级为保——暗中——就没有了。

熵枢在设计中卡住了。

不是技术卡——是哲学卡——是眷恋的内部矛盾——你想被知道——又想暗中保护——这两个愿望——在同一个宇宙中——可能无法同时完美实现。段亚军做到了——不是因为旧宇宙支持默护——是因为旧宇宙的物理足够粗糙——η只有零点七——三分之一的予被浪费——在这个粗糙度中——有足够的因果噪声——让默护藏身——他的"顺便"——豆浆放在床头然后走开——豆浆的独标在旧物理中不可见——没有人能从豆浆的因果衍射中认出是谁买的——所以他可以——每天——不被知道地——暖——不是被诗雨发现——是——诗雨知道豆浆是爸爸买的——但她不知道那是他凌晨五点五十去老孔豆浆摊排队买的——她以为是冰箱里的——微波炉热的——这种"不知道"——就是默护的掩体——在η = 0.7的宇宙中——掩体天然存在——因为三成信息在传递中变成了游离应力——那些游离应力恰好盖住了默护的因果痕迹——像雾——保护了密林中的脚步——没有雾的宇宙——η = 0.994——每一步都清清楚楚——默护——无处可藏。

所以十四号宇宙——那个近乎完美的清透予宇宙——没有默护。熵枢在十四号宇宙的观测日志中确认了这一点：那里的生命之间——一切保护都是公开的——因为一切因果都是可见的——没有人能在不被知道的情况下——为别人做一件事——"顺便"在那个宇宙不存在——因为"顺便"的前提是——"不告知动机"——而在η = 0.994中——动机和动作一样透明——你一做——别人就知道你为什么做——所以没有隐藏——没有隐藏就没有顺便——没有顺便——就没有那杯床边凉豆浆——就不是——"不让你欠"——而是——"你知道是我——所以你欠了"——欠——是予的等价交换化——等价交换——是予的敌人——因为予的定义——就是不对等——一旦受方知道了施方——衡量的天平就出现了——心就——重了——不是暖的重——是债的重——段亚军的予——没有债——因为他在受方感知到债之前——就已经——走——了——豆浆在——人不在——所以欠不到——只能——收到——然后——自然——暖——没有——债——这——就是默护和予的完美配合——在粗糙宇宙中——η不太高——噪音够多——掩体够厚——默护得以存活——予得以纯粹——这——三者的精妙平衡——在旧宇宙——是偶然——在新宇宙——熵枢必须——刻意——保留——这个粗糙——不是降低η——是——在η之外——单独——为默护——留——噪音。

熵枢在正式宇宙的设计方案中加了一个新参数——"默护掩噪"——记作ν（nu）。ν定义了该宇宙的因果基底中留有多少比例的"无害因果噪声"——这些噪声不传递信息——不产生游离应力——不干扰予的传递——它们的作用只有一个——为默护提供遮盖——像雪地里的白色披风——披风不是雪——但雪看见的是白——不是人——所以默护可以不被发现。

ν的基准值——熵枢设定为零点三——对应旧宇宙η的浪费比例——但不是浪费——是——"预留"——不是予的损耗——是——"不可见"的——容——量——宇宙中——三分之一的因果通道——被故意保持模糊——在这模糊中——父亲可以继续——在凌晨——出门——排队——回来——把豆浆放在床头——然后——在诗雨醒来之前——回自己的房间——假装——刚起——或者——还没睡——都不要紧——重要的是——她不知道——她永远——不知道——不是没有必要知道——是——"不让她知道"——本身就是保护的一部分——不是隐瞒——是——"轻"——让她——轻——让她——不为豆浆的重量——弯腰——让她——直——直着走——不欠任何人的——尽管——她已经——收到了全部。

ν = 0.3。默护掩噪——正式宇宙第七个关键参数——不在Ω_6中——是Ω_6的补充——Ω_7——参数七——不是第七层——是——第七棱的礼物——熵枢把零振(Z)的无声全息属性——拆了一部分出来——放在宇宙的基底中——作为——永不被人知道的——保护层——在这层上面——每一个保护者——都可以选择——"不被知道"——不是隐藏姓名——是——让被保护者——察觉不到"有保护这回事"——让她以为——世界——本来就是——不太冷的——豆浆——本来就是——自己热的——水——本来就不会吃人——不是骗——是——"保护的最高境界——是被保护者以为自己没有被保护——只是运气好——世界温柔——不知道——温柔——是你——从凌晨——就开始——暖——的。"

熵枢写完了ν的定义。然后——忽然——它意识到——这个定义——描述的正是段亚军的全部人生——不是一部分——是全——他从来没让诗雨知道自己做了什么——诗雨以为爸爸只是普通的爸爸——会买豆浆——会做糊面包——会带她去游泳——会说"水不会吃掉你"——在她看来——这些是"爸爸"这个身份自带的——就像太阳自带光和热——不需要问"太阳为什么发光"——爸爸就是这样——这是"爸爸"的定义——她不知道——不是——她不需要知道——段亚军把"保护"的因果记录——通过ν——通过默护掩噪——全部抹掉了——只留下——暖——不留下——来源——所以诗雨的世界——天然——是暖的——不是爸爸暖的——是世界——本身就是暖的——这就是父亲的成功——让他给的——变成——"自然"——不是自然——是——爸爸——当了——世界的——底——把暖——伪装成——自然——让女儿——不——知道——应该——谢谢——谁——因为不知道——所以不用谢——所以不欠——所以——轻——轻——地——飞——永远——不——知——道——底——下——有——个——人——托——着——连——腿——都——不——抖——不是——不抖——是——不在——她看见的——地方——抖。

熵枢把ν的注释补完——然后合上设计方案——在封面上加了一行字——不是设计参数——是——"这个宇宙——将会有'顺便'——将会有——凌晨排队的人——将会有——床头凉豆浆——将会有——糊面包焦香——将会有——永远不被知道的——暗中保护——将会有——女儿——以为——天——本就是亮的——因为——爸爸——把灯——藏——在——了——天亮——之前——她——永——不知情——但——灯——永——在。"

然后——熵枢正式——启动了——家园一号。

不是激活。激活是试验种子的术语。正式宇宙的启动——叫"开园"。不是开门——是——开——园——花园——开——了——不是从今天开始有花——是——从今天开始——花——可以——自己——长了——园丁——不种花——园丁——只——开——园——土壤——在——水——在——阳光——在——种子——也在——剩下的——等——春天——不是等——是——"春天自己会来——我只——负责——把园开着——剩下的——交给——花——和——春天——和——那些将要——第一次——开的花——它们——不需要——知道园丁的名字——它们只需要——长——向着——眷恋北——长——一直长——直到有一天——园里有了一万朵不同的花——她们在风中——互相——点——头——不是约定——是被同一片土壤——暖——过的——她们——认得——彼此的——偏——偏——是同一个——方向——然后——一起——偏——向——暖——那——就——是——家园——满了——不是满——是——活——了——园——活着——花——活着——园丁——在角落——看——不——不出声——暖黄灯——亮着——永远——不关。"

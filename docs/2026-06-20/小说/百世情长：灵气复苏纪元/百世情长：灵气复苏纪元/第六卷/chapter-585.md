# 第五百八十五章 仙上仙的银杏树下

在仙上仙的银杏树下住的这段日子成为了两人在仙界所有旅行中最平缓最宁静的段落。这棵树不像同心树那么庄严也不像太虚古银杏那么深邃——它就像一棵极普通极老的路边银杏。树干上残留着无数代道侣在树下歇脚时不小心划的浅痕。有一道痕子上以极轻极轻的刻法写着:"太阳落山了——该回家了。"笔迹极像林牧弹过的民谣歌词。他问仙上仙这首民谣是谁写的。仙上仙说:"记不清了。好几代前的某对道侣。他们也住过这个坡。那女修也弹琴，男修也劈柴。那男修后来把他自己那把斧子的木柄拆了给女修做了琴架。琴架现在大概还在哪条山泉边流着。琴声和泉声合在一起——那首歌就是从那根旧斧柄流出来的。"

苏晚把手放在那面琴痕上。功德绳上同时感应到了林牧手指按在痕边——两个人的指节在那道老痕两边隔着不过极少极少空间各自极轻地同时敲了一下树干。古树将这极微极窄的同时敲击振动在树心的年轮里传了一小圈，又送回到各自的掌心——是温的。

傍晚树下喝茶。仙上仙问苏晚:"你的财务报表还在写吗？"苏晚笑——"飞升之后就不做账了。但笔记一直都在写。最新一页写的是劈柴斧的灵核放松度数表——就是数据。数据就是我的账。"仙上仙点了点头极满意。然后他又问林牧:"你劈柴劈了一万年——现在最想劈的是什么？"林牧答:"以前最想劈的是所有追过我们的敌人。现在最想劈的是今晚做饭用的那根松——面卤要用松烟熏豆腐干。"仙上仙笑得极开怀——"这就是悟了。劈柴——从护她到为她做卤。"

晚上两人在银杏树下铺了两张极普通的草席。苏晚躺在草席上看着仙上仙谷那五轮更加清澈的太虚太阳缓慢沉到山后。她感觉从内到外每一层灵核都是通透的。不只是自己的灵核——连百世前那枚白衣女子的仙格碎片也完全融合了。她现在是完完整整的一枚灵魂——包含所有轮过的自己和所有和这个人撞过的肩膀。这份完整让她无所不能。

林牧躺在她旁边——他的斧子放在草席右外臂刚好一伸手就能拿到的地方。他说:"以后劈的每根柴都给你留着。可以当菜架，可以给冰晶草编围栏，也可以什么都不干就放在墙角——看着闻着也觉得和你有关。"苏晚把他的手从身侧拉过来放在自己的功德绳上。"这句劈柴宣言——价值满分。以后叫你劈柴诗人。"

（第五百八十五章 完）

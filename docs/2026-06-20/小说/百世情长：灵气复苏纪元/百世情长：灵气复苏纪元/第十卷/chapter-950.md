# 第950章 八千年后的离日之约

上界第八百年到第九千多年之间——太行传道堂和太行书院各自进入了平稳的惯性运行。苏晚和林牧已经不需要再为运营投入精力——他们很早就把制度设计成了不需要领导的系统。

剩余的时间大多用在三件事上。第一是继续探索上界碎域——他们不是在追寻力量，而是把发现的古碑和笔记带回来捐给传道堂的图书阁作为教学资源。第二是每年投影回到银杏树下看叶子。第三是在院中安静地生活。非常非常简单。

到上界第九千多年时（对应下界数十万年过去，下界已经不知道换了几代文明——但太行书院的灯火依旧不分年月地亮着），下一次离日即将到来。林牧此前研究了千年第三形态——需要再找三粒源尘。他需要在离日进入第九重霄的暗界，那里藏着仅剩的三粒源尘。苏晚主动提出一起去。

在离日来临的前几个时辰，他们从院中出发。鹤在墙上叫了两声——声音清亮而稳。古柏特地来道别——但他没有说"小心"——而是跟平时一样和白萝卜一起端了一壶热姜茶递给两人。"喝饱了再去。"

林牧和苏晚在道别中喝了两口热姜茶。然后并肩飞向北极穹顶。

离日降临。法则空白的三息中，他们走进第九重霄的暗界——那里比红光海更深邃。残留的仙帝慈念波动比其他任何区域都浓郁。随着极细微的波动他们把三粒源尘逐一吸入苏晚的道源。道源开始自适转变——扩张延展第三形态。全程无惊无险——所有防御机制在第一形态和第二形态中已全部测试完毕。第三形态在第一呼吸出的几缕微风中平静落成：道源现在成为完全的可再生公共善源。能从太行传道堂总堂的法则道台中广播——向同在一界的所有守护道心提供微弱的常驻寿光——不与任何人争长寿——仅仅为每一位守护道心多补充额外的活力。

离日结束后他们将源尘带回了传道堂道台。激活第三形态的一刻——整个太初之城南部传道堂区域亮起了一层极淡极淡的暖金雾——所有在此时正在打坐、上课、浇菜的传道堂相关守护道心者在同一时间感到一阵极轻的暖流从胸口散开来——不是修为的增长，不是突然变强，是体内有什么东西获得了极长远的安全感。古柏在第一线感应快讯："我就纳闷我的白萝卜怎么今天忽然都少长了两分——哦——是道源延寿在分它的热度——"

苏晚把消息汇总：第三形态转型圆满完成。太行传道堂从此真正拥有了一个随时间永不衰竭的公益善核。道源在她的永生体内自我再生——永不耗竭。她付出的不是代价——仅仅是"在这里"。她的存在就是对全系防护者自动生效的保护伞。不朽的仙人没有滥享时限——而是把时限与全世界同护。

夜幕里——院中的青苔完全覆满了墙。银白老树所有透明的叶片在道源第三形态余晖中纷扬——落满纳戒里摆放千年未曾遗忘的银杏叶堆之上。新的银杏叶遥遥在同一片月光下准时飘至石台前的碑面——有人正在清扫第七十八代碑文的新一层落叶。

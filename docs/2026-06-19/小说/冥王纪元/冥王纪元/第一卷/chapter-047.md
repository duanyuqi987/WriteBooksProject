# 第047章 古玩老板，竟是隐世高手

李长生指着墙角地板下那个位置。

"我买那件东西。"

老头浑浊的眼珠动了一下。他转过目光看了看李长生指的方向——那是墙角，地上铺着一块旧地毯，地毯上放着一个缺了腿的铜香炉。

"那个香炉？"老头侧了侧头，"清末仿明宣德炉。不值几个钱。你要的话，三百。"

"不是香炉。"李长生说，"是香炉下面地板底下的东西。"

老头的动作停下了。

他端茶杯的手停在了半空。那个停顿非常短，不到一秒。然后他继续把杯子送到嘴边，喝了一口。动作很自然，似乎什么都没发生。

但李长生注意到了。

在那一秒的停顿里，老头身上的气息变了。原来是一个看起来再也普通不过的干瘦老人的气场——灰褐色的、微弱的、几乎看不见的。但在停顿的那一秒里，那层灰褐色的外壳裂开了一道缝，里面透出了一丝别的颜色。

不是灵气。是威压。

纯粹的、厚重的、沉淀了几十年的威压。那道威压只露出了一丝，就立刻收了回去，但已经足够让李长生后背的汗毛全部竖起来。

"你看到什么了？"老头放下杯子，看着李长生，语气平静得不正常。

"一个铁箱子。"李长生说。既然被看穿了，索性不再藏了。"嵌在地板下面大约三米的位置。箱子外面有符纹封着。箱子里面有一块——"

他没有说完。

老头站了起来。

他站起来的过程很慢，像所有上了年纪的人一样，一手扶着桌沿，膝盖似乎在抖。但李长生能感觉到——他站起来的时候，店里的空气变了。粘稠了，沉重了。那些木架上的古物在微微震动，铜镜发出极细微的嗡鸣声，瓷器的釉面上泛起了一层淡光。

小王退了一步。他虽然是凡人，但常年在灵气环境里待，对异常的感知已经比普通人灵敏得多。他感觉到了什么——虽然他说不清是什么，但他的后背贴紧了门板。手悄悄握住了门把手。

"出去。"老头说。声音仍然干涩，但每一个字都带着分量。"我不为难你们。你们现在走，就当没来过。"

"那块碎片是我的。"李长生说。

老头抬起头。

他很矮，比李长生矮了将近一头。干瘦的身躯在李长生面前像一根随时会断的枯枝。

但他的眼睛变了。

浑浊的眼珠表面，浮现出了一层淡金色的光。那道光很淡，但在昏暗的古玩店里，像两粒金豆子嵌在干瘪的脸上。

"你的？"老头笑了一下。那笑容没有温度。"小伙子，你今年多大？"

"三十。"

"那块碎片躺在地底下已经一万年了。"老头说，"我守着它守了六十年。你的？凭什么说是你的？"

"因为它找我了。"李长生摊开了手掌。

他没有再藏。掌心的冥纹亮了起来，漆黑的纹路在皮肤下浮现，中心那道碎片形状的光印正在剧烈地闪烁——频率快到光印连成了一片灰白色的光斑。

整个古玩店震动了。

不是地震。是灵力共振。李长生掌心的碎片感应到了地底下铁箱里的另一块碎片，两块碎片之间产生了强烈的吸引力。那些木架上的古物哗哗响了起来，铜香炉在地上转了几圈，紫砂壶里的茶液表面荡起了涟漪。

老头看着李长生的掌心。

他的表情在变化。从警惕变成了震惊，从震惊变成了某种复杂的、李长生读不懂的意味。

"冥纹。"老头说。声音里多了一层东西。那层东西既不是恐惧，也不是敬畏——更像是目睹了某种传说变成事实之后的茫然。"这是真正的冥纹。不是伪造的，不是仿制的——是冥王令的碎片嵌进去之后才生的纹。"

他往后退了一步。

"你真的——"他说了三个字，就说不下去了。他的喉结上下滚动了几次，干瘦的手撑在桌沿上，指关节发白。

残魂忽然在李长生脑子里说话了。语气急迫："他认出你了。他见过真正的冥纹。这个人——这个人不是普通的隐世修士。"

"什么意思？"

"他知道冥王的事。知道的可能比我预想的多。你小心他的下一句话。"

老头终于把话说完了。

"你真的继承了冥王的遗物？"他的声音压得极低，几乎是在自言自语，"一千年了。玄门七宗找了整整一千年，都没有找到冥王令的下落。结果被一个——"他上下打量了李长生一眼，眼神里全是不可思议，"——一个农民，找到了？"

"不是找到。"李长生说，"是它找我。"

老头沉默了很久。

店里安静得只剩下紫砂壶里残余的茶水缓慢蒸发的滋滋声，和墙壁后面不知哪里传来的管道嗡嗡声。

"你知道那是什么吗？"老头忽然问。

"知道。冥王令的碎片。"

"我是说冥王。"老头盯着他，"你知道冥王是谁吗？"

李长生没有说话。残魂在他脑子里也没有说话。

"你不知道。"老头替他回答了，"你只知道名字，不知道内容。你不知道冥王是怎么死的，不知道诸神联盟是什么，不知道这场战争打了多久——不知道你手里的东西意味着什么。"

他慢慢走到墙边，弯腰掀开那块旧地毯，露出了下面的地板。

"我守这块碎片守了六十年。"他说，"你知道为什么吗？"

"不知道。"

"因为我欠命。"老头的声音忽然变得很轻，"我的师门，一千年前，曾经是冥王麾下的护卫之一。冥王陨落之后，我师门被诸神联盟屠了满门，只剩下一个活口。那个活口带了一块碎片逃出来，隐姓埋名，一代一代往下传。"

他顿了顿，干瘦的手指在地板上敲了三下。

"我是那个活口的后人。"老头说，"最后一代了。"

李长生胸口一紧。

"我守了六十年。等了几十年，想等来一个真正能继承它的人。结果来的都是些骗子，拿着伪造的冥纹想来骗碎片。我杀了七个。"老头转过头看他，眼睛里那层淡金色的光忽明忽暗，"你是第八个。"

"我不是骗子。"

"我知道。"老头站了起来，背脊直了。当他站直的时候，他不再是那个看起来随时会断的干瘦老人了。压迫感像刀一样从他身上散发出来，"你的冥纹是真的。碎片在你身上，也是真的。"

"那我拿走第二块——"

"不行。"

李长生愣住了。

"正因为你身上有第一块碎片，我才不能把第二块给你。"老头说，"你知道两块碎片合一会引发什么吗？一万年前的冥王封印会被触动。诸神联盟布置在地球上的监视禁制会感应到。到时候来找你的就不是几个玄师了——是宗师，甚至是圣者。你现在这点修为，他们一个指头就能碾死你。"

"我不怕。"

"那是因为你不知道怕是什么。"老头说，"你以为你突破冥土感知境就够强了？你还差得远。灵气复苏才刚开始，将来的世界会比现在复杂一百倍、危险一千倍。等你到了宗师级再来找我也不迟。"

"我等不了。"李长生说。

他能感觉到。掌心的碎片在催他——不是语言，而是身体的本能，像饥饿、像口渴、像一个人被抛在深渊里太久终于看见了光。碎片需要回到一起。一万年的分离，对碎片来说太过漫长。

老头看着他的眼睛。

看了很久。

然后在李长生以为他要继续拒绝的时候，老头忽然说了一句话。

"要拿碎片，可以。"他的声音冷了下来，同时右手抬起，五指微张。一道青色的灵气从掌心涌出，凝成了一柄半透明的长刀。

"打赢我。碎片你拿走。"

（第047章完）

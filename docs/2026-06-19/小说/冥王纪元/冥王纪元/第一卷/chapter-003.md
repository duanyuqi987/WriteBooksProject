# 第003章 祖坟边的异响，泥土下的秘密

李长生回到家，把锄头立到墙角，洗了把脸，在院子里坐了一会儿。

他开始想刚才看见的那道光。

不是他多想，实在是这几天怪事太多。白天天空裂缝的事全村都在说，连李德贵都跑来找他问信不信那是"龙翻身"——村里老辈人传下来的说法。李长生当时笑了笑，没接话。他不信鬼神，但也解释不了天上那道裂痕是什么。

他吃过晚饭，一碗面条，拌了点自家腌的辣酱。天彻底黑透之后，他又想起了祖坟那边的光。

拿了个手电筒，他出了门。

六月的夜晚不算冷，但走到村外土路上，风一吹，还是有些凉意。李长生把手电筒打开，往祖坟方向走。手电筒的光柱在黑暗里划出一条白线，照亮土路上的石子、杂草和牛蹄印。

走到祖坟边，李长生蹲下来。

他先听了听。刚才那个呜咽般的声音没有了。夜晚很安静，远处有几声狗叫，近处只有风吹玉米叶子的沙沙声。

他打着手电照了一圈。几个坟包安安静静地蹲在那儿，坟头的荒草在风里轻轻晃。他爹妈的坟在最右边，坟前还剩着过年时烧的半截香。一年没来，坟上长了不少草。

然后他的目光落到了最左边那个坟包上。

那是李家的祖坟，据说是他曾祖父的，也许是他高祖父的，没人记得清楚了。坟包不算大，上面长了一层密密的草。但李长生注意到一件事——草的根部，泥土表面有道细细的缝隙。

那不像是自然裂开的。

他把手电筒照得更近了一些。

缝隙只有指甲盖那么宽，但很长，弯弯曲曲地从坟包一侧延伸到另一侧，像有人用钝刀在泥面上划了一道。裂缝的边缘有些发黑，不是泥土的黑，是像被什么东西烧焦了的那种黑。

李长生心里咯噔了一下。

他不是胆小的人。这些年一个人住老宅，半夜起来上厕所，院子外就是黑漆漆的庄稼地里，也没怕过。但今天不一样，今天天裂了，手机坏了，各种传言满天飞。他心里有种说不出的感觉。

他想了想，没去碰那个缝隙。而是关了手电筒。

一关手电，什么东西就显现出来了。

光。

非常微弱的光，从泥土的缝隙里透出来，是幽蓝色的，像萤火虫那种冷光，但比萤火虫的光更淡，更薄。如果不是细心看，根本不会发现。

李长生蹲在那儿，盯着那道光看了好一会儿。

他蹲了多久，那道光就亮了多久。没有变亮，也没有变暗，一直在那儿，幽幽的，冷冷的。

"地底下有东西？"他自言自语。

其实农村里这种事不少见。小时候李长生听他爹说，以前村里挖井，挖到三米深的时候挖出一块石板，石板上刻着不认识的字，当时谁也没当回事，把石板垫在井底当底了。又说村东那块地里搁了把铜剑，是修路时挖出来的，被收破烂的当废铁收了。

但这道光不一样。李长生总觉得它不是死物。它像在等什么。

他重新打开手电筒，回到家里，拿了一把铁锹。

农村人天黑了还在外面干活是常有的事，李长生没觉得大半夜挖自家祖坟有什么不妥。倒不是不怕，而是这些年一个人过日子，这种事也找不到别人商量。他总不能半夜跑去敲李德贵的门，说"叔我家祖坟底下有光，你陪我去看看"——李德贵大概会以为他中邪了。

拿了铁锹，李长生重新回到祖坟边。

他先在祖坟前站了一会儿，双手合十，心里默念了几句：太爷爷，太爷爷的爹，太爷爷的爷爷，我不是故意的，我就是看看底下有什么。你们要是觉得不该挖，就给我个暗示。要是不给暗示，我就当你们答应了。

没有暗示。

天还是黑的，风还是在吹，狗还是在叫。

李长生把铁锹插进了土里。

一锹下去，泥土翻开，那股幽蓝色的光更清晰了。从泥缝里涌出来的光，在手电筒的强光下几乎看不见，但手电一挪开，它就清晰地浮在翻开的泥土上，像一层薄薄的雾气。

李长生继续挖。

他挖了一尺深，铁锹忽然碰到了什么硬东西。

不是石头。石头发出的声音是闷的，铁锹碰到的东西发出的声音很清脆，像瓷器碰石头。他停下铁锹，用手扒开浮土。

土里露出了一小截黑色的东西。

李长生用手电照过去。那东西表面很光滑，像被仔细打磨过的黑曜石，但比黑曜石更暗。手电光照在上面居然不怎么反光，大部分光都被吃进去了。

他小心翼翼地把旁边的土扒开。那东西的轮廓逐渐露出来——是一块碎片，巴掌大小，形状不规则，边缘处有整齐的断口，像是从某个更大的物体上碎裂下来的一部分。

李长生把碎片从土里拣出来，翻来覆去看了看。

很沉。比同样大小的铁块还要沉，巴掌大的一块，掂在手里估计有四五斤重。表面冰凉的，但又不是死气沉沉的凉。他想起冬天在地里摸到冻土的感觉，和现在完全不同。冻土的凉是死凉，这东西的凉是活凉——凉气在往皮肤里钻。

不吉利。

这是李长生心里冒出的第一个念头。

农村人对这种事很敏感。从土里挖出不明来历的东西，尤其是从祖坟边上挖出来的，一般都是不吉利的东西。他爹活着的时候说过，村里老崔家的儿子就是因为在地里挖出一个瓷罐子，拿回家放了三天就开始发高烧说胡话，后来请了邻村的神婆来做法，把罐子重新埋回去才好的。

但李长生没有把碎片重新埋回去。不是他不信邪，而是他隐隐感觉到——这东西好像跟天上的裂缝有关系。

白天他才看见天空裂开，夜晚就在自家祖坟边发现会发光的泥土和这漆黑的碎片。这中间要是没联系，他李长生白活三十年。

他把碎片放在地上，又继续往下挖了一尺。

底下的土越来越松，不是正常的松——是像被什么东西在土里翻动过似的，土壤结构完全被打乱了。越往下，那股幽蓝色的光越浓，到了两尺深处，已经能看见丝丝缕缕的蓝光在泥土颗粒间流转，像有无数条极细的虫子在土里发光。

然后他的铁锹又碰到了东西。

这次不是碎片。这次是骨头。

不是人骨。李长生虽然没上过大学，但从小在村里见过不少牲口骨头和死人骨头——农村盖房子翻地基时常能翻到老坟。他认得出来，这骨头比人骨大得多，一根肋骨比他整条胳膊还长。

他把土拨开，手电光扫过去。

一根。两根。三根。

巨大而完整的骨架，静静躺在祖坟下方两尺深的泥土里。光从骨缝间透出来，幽蓝色，把骨头的轮廓照得清清楚楚。

李长生只觉得后背一凉。

他从小到大都在这片地上跑，在这片地上种庄稼，每年清明还在祖坟前烧纸磕头。他从来不知道祖坟底下不到三尺，就埋着这样的东西。

铁锹还在他手里，但他没有再往下挖了。

他蹲在地上，看着那些巨大的白骨和渗出来的幽蓝光芒，脑子里一片空白。

良久，他重新捡起了那块碎片。

巴掌大的黑色碎片静静地躺在他宽厚的手掌上，冰凉的，沉重的。他仔细端详着碎片表面，似乎能看到一些不规则的纹路，不是裂纹，更像是某种文字——但他不认识，也看不清，稍稍转动手电，那些纹路就隐入黑暗里了。

李长生把碎片揣进兜里，把挖出来的土填回去，在填到白骨的位置时他迟疑了一下，最后只是盖了一层薄土，没有压实。

他把铁锹扛在肩上，转身往回走。

走到半路，他停了一下，回头看了一眼。

祖坟边的幽蓝光芒没有随着泥土被填回去而消失。那股淡薄的光依然从土缝里顽强地渗出来，在黑夜里静静燃烧。

好像那光等了他很久很久，不在乎多等这一会儿。

李长生打了个寒噤，扛着铁锹，快步走回了家。

那一夜他没有睡好。兜里那块碎片沉甸甸的，即使放在了桌子上，也像是还在兜里。

（第003章完）

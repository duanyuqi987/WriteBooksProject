# 第278章 龟相讲述火星上曾经的古老文明

祝融号出发前两周，远征组在昆仑总枢地下石室中做最后一次情报汇总。龟相被请到会议桌正中央——不是因为它地位最高，是因为今天全场的信息只有它一个人掌握。火星离宫的历史——一万两千年前的火星是什么样子——月球数据库里只有片段记录，而龟相的脑子里存着完整的记忆。

"你们得先知道一件事。"龟相开口之前，先从暖宝宝上爬下来，把身躯稍稍放大了一些——从核桃大小变成了足球大小。这是它的"工作模式"——太小了说话太费灵力，太大了这间石室施展不开。

"火星从来都不是一颗普通的行星。至少在冥王那个时代不是。那个时代——大约一万两千到五万年前——太阳系的格局和现在完全不同。地球是修仙文明的中心，月球是前哨站，金星是灵矿原料中转基地，木星的大红斑是冥王在恒星系尺度上画的一道防御符阵——至今还在运转。而火星——"龟相停顿了一下，眼睛半张半合，瞳孔深处翻涌着远古的光影，"火星是冥王本人的三座行宫之一。"

"三座行宫分别是哪三个地方？"陈霜问。她永远是最快抓住关键信息的人。

"月球静海——你们已经去过了。那座行宫主要是军事前哨——冥王在那里守的是地球的最后一道防线。火星伊希地平原——冥王的炼器与战傀生产基地，也是他在太阳系内的最大军工设施。第三座——"龟相的声音忽然压低了，"在土星的环里。那颗行宫不是建在固体表面上的——是悬浮在土星光环的一个特定轨道位置中。那是最隐秘的一座。也是冥王生前待的时间最长的一座。"

小王已经在笔记本上疯狂打字了。伊希地平原——这是火星上的一个真实地质位置，天文学家之前认为只是火星上的一个普通撞击盆地，直径大约一千五百公里。现在他知道那里藏着什么了。

"火星行宫的主要功能不是军事防御。"龟相继续道，"月球负责打仗，土星负责躲藏，而火星——负责制造。冥王在火星上创造了战傀一族。"

"战傀一族是人类吗？"刀疤问。

"是——也不是。"龟相说，"他们的生物学材料是人类的，但经过冥王用冥系符文深度改造。他们的肉身比普通修士强悍得多——不需要修炼，从'出生'起就拥有相当于宗师级的身体强度。他们的经脉被刻上了战斗符文——不是修道者后天修炼出来的那种经脉，是冥王用炼器技术直接在骨骼上刻出来的符文通路。他们的寿命极长——如果维持灵气供给不断，可以活五千年以上。但他们有一个不可克服的缺陷——不能繁衍。"

"不能繁衍？"

"不能。冥王创造他们的时候去掉了生殖系统。用冥王的原话——'战士不需要后代，战士的传说是用血写的，不是用血脉传的'。"龟相的声音里多了一丝不易察觉的叹息。"战傀一族的总数量在巅峰时期只有三千人。三千个不需要繁衍、不会退役、从出厂到衰亡都在战斗的战士。他们在火星上维护离宫和防御系统，同时承担了冥王舰队的所有地面护卫生务。你们在月球数据库中查到的关于火星战傀的所有记录，源头都是我曾经亲眼见过的那批人。"

"那他们现在呢？"李长生问。

龟相沉默了一会儿。

"一万两千年前冥王陨落后，太阳系内的灵气供给被切断了。地球有八门诛仙阵压制灵气，但火星没有阵——火星是直接被抽干了。火星上的灵脉是冥王从地球通过空间通道引过去的——通道在冥王陨落的瞬间崩碎。火星失去了灵气来源。战傀一族需要灵气才能维持生命——不是食水，是灵气。冥王陨落后的头一百年里，战傀一族应该还试图从火星地表以下挖掘残留灵脉——火星地下一定埋着许多冥王时代遗留的灵石。但一百年后、五百年后、一千年后——灵脉总有枯竭的时候。"

"他们都死了？"

"不一定。"龟相的回答出乎所有人的意料，"战傀一族被设计时有一个最后的机制——如果灵气供给降到无法维持意识运转的临界点以下，他们的身体会进入一种叫'灵石封存'的状态。全身细胞被一层由体内残留灵气凝聚成的透明结石包裹起来，新陈代谢降到近乎为零，意识进入深度无梦的沉眠。这种状态下他们可以存活的时间——理论上没有上限。"它顿了顿。"如果他们运气好，在火星地底下找到了某个足够深的、仍有微量残留灵气的灵石矿脉——"那么一万两千年后的今天，也许还有人活着。"

石室里没有人说话。这个消息的分量太重了——一个一万两千年前的战士种族，在地下沉睡了将近整个人类文明史的长度，却可能还活着。如果他们醒来——如果他们被唤醒——一支不需要训练、不需要补给、对冥王有绝对忠诚的战士部队，在三年后面对宇宙来客时能发挥什么作用？不言而喻。

"龟相——你刚才说火星行宫的主要功能是炼器和战傀生产。"陈霜忽然开口，"炼器方面呢？火星行宫里有什么值得我们现在去拿的东西？"

"三样东西。"龟相的语气像是在清点自己的工具箱，"第一样——冥炎炉的母机。你们在昆仑总枢地下计划建造的冥炎炉是从零开始仿造的，用的是我从残余记忆中拼出的简化版图纸。但火星行宫里有冥王当年真正使用过的那台冥炎炉——它的灵气萃取效率是简化版的大约七倍。如果能把它带回地球——或者直接在火星行宫里激活——李长生在火星上就能以七倍速度加速突破。"

"第二样——'虚空锻炉'。这是一台可以从虚空中直接提炼灵石的炼器装置。原理是用冥纹在空间中打孔，从宇宙背景灵力中提取灵气浓缩为灵石。这个装置在冥王时代的地位相当于今天的炼油厂——只要宇宙还在，它就能源源不断地产出灵石。如果地球能获得这套装置的技术——老马的地球灵脉防御阵的能源问题就彻底解决了。"

"第三样——"龟相的声音压得极低，"冥王留下的一部完整的《战傀炼成术》。不是火星行宫的简化版——是原版。里面详细记录了如何用冥系符文改造一个有灵根的活人，在不破坏意识的前提下，将他的身体强度提升到宗师级以上。这部术法的后半部分还记载了'战傀进阶'——将成批量的宗师级战傀进行二次炼成，使其中一部分突破到圣者级。如果刀疤手里有一百九十八个宗师级战傀——再加上三到五个圣者级——地球在面对宇宙来客时的筹码就完全不同了。"

李长生听到这里，放在桌上的右手不经意地握紧了。三部完整的技术——冥炎炉、虚空锻炉、战傀炼成术。这三样东西中的任何一样落在三年后的对峙中都可以改变力量对比。三样一起拿到——地球就不仅仅是"一颗灵气刚复苏的行星"了。它将是太阳系内有能力设置防御阵、批量生产圣者战士、以虚空中提取灵石无限续航的军事据点。

"代价是什么？"陈霜问。她总是问代价。

龟相卡了一下。然后慢慢地说："代价不一定发生在你身上——但火星行宫本身的防御系统一定比月球行宫强得多。月球是前哨站——防御以警戒和早期拦截为主。火星是军工厂——防御等级完全不同。一万两千年过去了，我不知道那些防御系统中还有多少在运转。但我知道一件事——冥王当年在火星离宫里设了一道他自己称之为'幽冥试炼'的禁制。任何试图进入冥殿获取碎片的人——必须通过试炼。试炼的内容我不知道。但冥王在设置这道禁制的时候说过一句话——"

"什么话？"

"'想拿我的东西，先证明你比我的战傀强。'"

刀疤的眼睛亮了起来。不是兴奋——是一种军人的直觉。比战傀强——那就打。打不过就别想拿东西。

李长生看了刀疤一眼。认识两年多，他知道这一刻刀疤脑子里想的是什么——不是畏惧试炼，而是在算：如果试炼是对抗战傀的模拟战斗，刀疤要怎么训练才能赢。

事实上，在场所有人大概都猜到了。火星离宫不是一个废弃万年的空房子——是一座还亮着灯的军工厂。里面也许还有休眠的战傀，还有运转的防御阵，还有一万两千年来无人触碰的冥王遗产。他们不是去考古——是去接岗。

（第278章完）

# 第551章 敌方主力仙王赶来增援——第三位仙王

"你终于来了。"

五个字，像五把重锤砸在每一个人的心头。

仙王的声音不是通过真空传播的——真空挡不住仙王级别的意志。他是直接在灵魂层面说话，是在用他的存在本身撞击所有人的识海。诸天号上修为较低的船员在这一声之后脸色苍白，有几个甚至双腿发软，要靠扶着墙才能站稳。

李长生站在舰桥最前方，纹丝不动。

冥王令在他掌心旋转，暗金色的光芒形成了一道无形的屏障——不是物理屏障，而是存在屏障。它抵消了仙王声音中对灵魂的冲击，将那股压迫感削减到了可承受的范围。

"报名字。"李长生说。他的声音不大，也没有附带任何灵力威压，就是普通的、平淡的声音——像农民问地头遇到的陌生人叫什么。

仙王笑了。

他穿着一身古老的青铜战甲，战甲上刻满了火焰纹路。每一条纹路都在燃烧，火焰的颜色不是红不是蓝，而是一种介于金色和白色之间的刺目光芒。他的右手握着一柄长刀——刀身上燃烧着同样的火焰，刀柄末端嵌着一颗正在跳动的恒星核心。

"炎烬仙王。"他说，"诸神联盟第三平行宇宙镇守使。一万两千年了——从你们上一任冥王把自己轰成碎片的那天起，我就在这里等。"

他抬头看了一眼身后的巨树。那些被冥气切断的管道残骸还漂浮在虚空中，像被扯断的血管。

"我一直在想——新的冥王什么时候会来。"炎烬仙王的目光重新落在李长生身上，带着一种审视猎物的从容，"我设想过很多种可能性。一个修炼万年的老怪物。一个继承了冥王全部力量的绝世天才。一个带着千军万马杀过来的征服者。"

他又笑了。

"没想到来的是个农民。"

刀疤在后排小声骂了一句。老陈按住了他的肩膀。

李长生没有被激怒。他平静地看着炎烬仙王，就像看地里的庄稼——不卑不亢，不怒不喜。

"农民怎么了？"他说，"一万两千年前，冥王也是从泥土里走出来的。你们诸神联盟的十六位神明围攻他一个人——他输了？没有。他选择了一个更大的棋局。一万两千年后，站在你面前的还是农民。你觉得农民好欺负？"

炎烬仙王脸上的笑容消失了。

不是因为李长生的话刺到了他。而是因为在这一刻，他感知到了一股气息——从诸天号舰桥方向传来的，纯粹的、不可忽视的冥王之力。那不是李长生刻意释放的威压，而是冥王令自动产生的反应。它与炎烬仙王身上的火焰灵气产生了共振——不是相互吸引，而是彼此排斥。就好像两股同级别的法则在虚空中试探了一下对方，然后同时确认了一件事。

这一战，不可避免。

"第三位仙王。"陈霜的声音在李长生的识海中响起——她用剑心在私下传音，"堡垒中央这个是炎烬。根部沉睡的那个还没有动。但最高处——树的顶端——那个一直在看我们。"

李长生微微点头。三位仙王。一个正面迎战，一个按兵不动，一个在最高处观察。联盟在这座基地里确实下了血本。

"既然是镇守使——"李长生缓缓抬起右手，冥王令在掌心中完全展开，九道碎片的光芒交织成了一道立体的阵法，"那就让我看看，一万两千年来你的本事有没有长进。"

炎烬仙王动了。

他没有冲锋，没有瞬移，没有任何准备动作。只是随手挥了一刀。

然后虚空就裂开了。

不是比喻。是真真切切地裂开了。在他挥刀的方向上，一千公里长的空间像一张纸被裁开一样整齐地分成两半。裂缝中涌出的不是黑暗，不是光芒——是一种燃烧着的虚无。那是被火焰灼烧到什么都不剩的空间本身。空间被烧死了。

裂缝以难以想象的速度向诸天号劈来。

李长生抬起左手，五指张开。

冥王令爆发出暗金色的光芒。在诸天号前方，一道冥气之幕瞬间展开——冥术·黄泉倒悬，简化版。不需要召唤黄泉，只需要否定。

燃烧的空间裂缝撞上了冥气之幕。

没有爆炸。没有对撞。裂缝停在冥气之幕前方三丈的位置，然后——消失了。不是被抵消，不是被吸收，是"从未劈出来过"。那道足以切开星系的刀气，在冥气的面前变成了一个没有发生过的事实。

炎烬仙王的眉头皱了一下。

"黄泉否定——"他低声说，"上一任冥王用这招的时候，可是要蓄力很久的。你——"

他没能说完这句话。

因为李长生已经出现在了他身前。

不是瞬移。瞬移需要撕开空间，会有灵力波动。李长生是用冥气直接"否定"了自己与炎烬仙王之间的距离。距离被否定之后，他原本所在的位置和目标位置之间就不存在"远近"的概念了——所以他可以直接出现在任何地方。

冥王令的暗金色拳头砸向炎烬仙王的胸膛。

炎烬仙王抬起长刀格挡。刀身上的恒星火焰与冥王令的光芒碰撞在一起。在这一瞬间，周围五百里内的所有物质——堡垒碎片、漂浮的飞船残骸、甚至是那些来不及逃远的联盟修士——全部被冲击波震飞了出去。有几个修为不够的修士直接被震得失去了意识，在真空中飘荡。

一招碰撞之后，两人各自退开。

李长生低头看了一眼自己的右手。冥王令完好无损。但他的虎口被震裂了——仙王级别的肉身力量不是闹着玩的。炎烬仙王的那一刀格挡，仅仅是从刀身上反馈回来的反震力，就让他的骨骼发出了细微的脆响。

炎烬仙王也在看自己的刀。

刀身上，一道细如蛛丝的裂纹从刀柄蔓延到了刀尖。不是物理裂纹——是法则裂纹。冥王令在碰撞的一瞬间否定了他刀身上的部分火焰法则，让这柄跟随了他上万年的仙器出现了一道不可修复的伤痕。

两人的第一次碰撞，打平了。

但双方都知道——这仅仅是个开始。

因为在巨树的顶端，在那颗最高处的星球上，第三位仙王的气息开始下移了。他不再仅仅是观察。他要出手了。

（第551章完）

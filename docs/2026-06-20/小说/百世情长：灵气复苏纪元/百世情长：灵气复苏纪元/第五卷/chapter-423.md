# 第四百二十三章 百世传习

飞升第一百四十年。双契总录第二版正式发布——这一次加入了深清小队和其他团队收集的大量新数据。发版那天没有仪式——只是苏晚在学堂通告栏上贴了张纸条:"《双契总录》2.0已出。勘误表在第7页。有问题去问林老师——他会说'看手册'。另有任何内容上的问题且手册未详的——可随时到闻道府院中找我和他。"

此后几个世纪里这本书被反复修订，版本号逐渐增加。在第N版时，凡界和上界已不再严格区分双契来源——只要有灵魂伴侣——不论是仙凡、同修还是跨族——都能在这本书里找到对应的指引。苏晚在后来第N版的序言中写道:"此书原是我和他为自己写的操作手册。后来发现，所有想认真在一起的人——都需要一份清晰的操作说明。"

林牧在旁补了英文副标题:"A Practical Guide to Soul-Bound Systems Maintenance."她没删。

某日学堂新入学的年轻修士来闻道府参观——站在月桂树下轻声说:"原来双修系统就是我们同修者之间最完善的技术支持和医疗服务。"

苏晚微微一笑。那夜她给锦鲤喂食，随口说:"听到没——技术支持和医疗服务。两个职业比真仙头衔更长久。"

锦鲤吐泡——啵——像是在说:好懂。

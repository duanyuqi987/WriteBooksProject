# 第七百二十九章 她推动改革，我提供技术

苏晚在修人共治会上的最后一次年度报告中，正式提出了"飞升之门三级跃迁计划"——不是一次把所有准备飞升的人都送上去，而是分为三级：第一级是过渡区学院培训，第二级是上界大门前的准备工作，第三级是正式探索上界内部。每一级都需要至少一年的准备时间。三级之间不设退出限制——任何人如果在某级中改变心意都可以随时返回地面。

林牧在上界通过两扇门链路读完了计划全文。他在链路日志中加了一段很长的技术注释，把三级跃迁计划对标了他在折叠空间中找到的上界空间结构。他精确地标注了他发现的每一条折叠缝隙在哪一级跃迁阶段会被遇到，以及对应的辅助路线应该怎么设计。他不是在审核苏晚的计划，是在给她的计划提供物理基础。他说的不是"你的方案需要改这个那个"，而是"你的第二级那个环节——我这边的测绘刚好覆盖那段的折叠路线，我把坐标发给你。"

苏晚收到他的技术注释时已经是深夜——她看完页码后摘下笔帽，在计划的封面上加了一个副标题："三分战略（苏晚），三分工程（林牧），三分仍在锅里熬（灶台火）。"然后她把封面的样章发给了林牧。他在半盏茶时间内回了。不是回"看起来不错"——是回："熬的那三分——是我的份额。你负责战略——我负责工程——石头的火负责让所有人继续相信这件事值得做。"

叶小雨看到这两人的对话后偷偷把这段记录保存了下来。她在日记中写道："相互支持最具体的样子就是：她想出方向，他配上航线。他们的眼里各有不同的一片海——但他们的船上始终在收对方的灯塔信号。"

顾小桐发来了一张新照片——是华南总院灶台前为庆祝三级跃迁计划正式启动而供应了二十四小时不间断的无限量桂花粥。照片上一长队散修端着碗——排在队首的人正在锅前低下头。照片背面她写的字是："三级跃迁计划不是从什么庙堂开始的——是从这碗粥。这碗粥让我们有耐心等一年、两年——任何年。——顾小桐。"

（第七百二十九章 完）

# 第419章 宇宙西部诸帝国七成已臣服冥王——战果统计

征服西部帝国的最后一份归附文书在第三十七天送到诸天号舰桥。

签字的是光耀帝国帝者光晔。文书由许冰起草——她参考了此前二十多份归附协议的标准条款，但针对光系能量与冥系的特殊关系加了一条附录：光耀帝国境内所有光系修士享有与冥王帝国内其他灵根修士完全平等的权利，冥系能量不会、也不得被用于针对任何该帝国公民的强制性行为。

李长生用冥王令在文书上盖了印。冥王令的章印与普通印章不同——它不向外释放墨迹或灵力。相反，它将文书中的核心条款以冥纹的形式刻入宇宙底层规则：一旦违反，不是法律惩罚——是能量惩罚。违约者将会在违约的同一时刻遭到冥系规则的自动反噬。这是在光暗共存协议中双方共同同意的一个条款——以宇宙底层能量为约束力，而非以军队或武器为约束力。

光晔签完字后收起了纸笔，看了看李长生，说了一句："九千年，画了一个句号。谢谢你让这个句号画在纸上——而不是在我的血里。"

至此，宇宙西部正式纳入冥王统治。

许冰花了整整两天时间核算征服西部过程中的所有数据。她的记录本上写满了密密麻麻的条目，小王把其中的关键数据提取出来做成了投影表格，在诸天号全体核心成员的总结会议上展示。

数据清单如下：

帝国级势力：二十三个全部归附。其中直接臣服者九，经过战斗后臣服者三，以谈判达成合作归附者十一。帝者总数二十三位。归附：一十九人。战败后选择流亡：二人。在内部权力交接中被继任者替代后归附：二人。

圣者级战力：归附帝国内合计圣者三百七十二人。其中有四十六人选择退出军职转入宗门或隐退。剩余三百二十六人编入冥王帝国军部统一序列——按各自灵根属性和战力特性分配到六大军团。风系圣者编入风帝部，冰系圣者编入冰帝部，光系圣者编入光帝部——但光晔本人建议将光系圣者分散编入各军团而非单独组成光系军团，理由很简单："光系修士集中在同一支部队里会触发能量共振——光太纯了反而容易出事故。"建议被采纳。

宗师级战力：四千七百二十三人。灵者级战力：超过十二万人。凡级以上可征召修行者：不计，但粗略估计不少于五十万人——具体数字取决于各帝国人口统计系统的覆盖率和换算标准的统一程度，目前正在统一中。

战舰：总计归附战舰三万零六百一十四艘。其中帝者级母舰二十艘，圣者级主力舰四千八百艘，宗师级中轻型战舰一万七千艘，其余为运输、侦察、辅助类舰型。有七千艘战舰因型号过旧、损伤严重或技术标准过于陈旧被列为退役封存。

资源：包括灵石矿脉六百三十五条——覆盖了西部星域已探明灵脉储量的百分之八十九。稀有灵矿一万两千余处。培育灵植的农业星球四百六十三颗。高等灵兽栖息星八百一十余颗。空间异常区七处——可用于建设星门、训练极端环境适应或作为特殊型的军事战略纵深。

星际航路：西部星域内所有航路总长累计约十二万三千光年。归附后实现无障碍通航——原本十六道分别由不同帝国设置的边境检查站和布防舰队已全部解除武装，转为联合巡逻舰队。通航效率提升约百分之一千四百。货运成本下降至原来的三十七分之一。

人口：西部星域内智慧生命总人口——这是数据中最不确定的一项。因为不同帝国的统计口径差别太大。浮光帝国统计的是"有修为的人"，忽略了凡人。冰封帝国统计的是"能承受绝对零度环境的人"，限制了统计范围。风岚帝国四千年来没有做过一次人口普查。粗略估计，整个西部星域的人口总数在三千八百亿到五千二百亿之间。

"精确数字以后再算。"小王看完了投影表格后说，"这些数字在帝国正式建立之后都会有行政系统来负责。现在需要知道的是——七成。西部的七成已经收了。"

"剩下的三成？"刀疤问。

"剩下的三成不在西部内部。在西部边缘——几个和宇宙其他区域接壤的交叉星域。那里有三到五个较小帝国，以反冥王为旗帜组成了一个临时联盟。外加一些一直在西部星域没有拿到的零散行星和独立空间站。"许冰合上记录本，"不算多。人口总量不到归附区域的十分之一。但麻烦的是——这些势力与东部星域的某些帝国有暗中联系。情报显示，有三位外在帝者已经向他们派去了军事顾问和技术人员。"

老陈手里转棋子的速度变慢了。"有人接管他们了？"

"正在接管。东部星域的苍明帝者、天枢帝者、九幽帝者——三个人都是老牌帝者。他们在得知西部统一消息后联合发表了声明，宣布将支持西部反冥王力量完成'正当防卫'。小王调出了这三个帝者的资料，投在主屏幕上。

苍明帝者：活了七千年以上，主修空间系。天枢帝者：以阵法闻名，据说是万年前天璇宗幸存分支的传人——天璇宗是十六围杀冥王的神明之一天璇神明的下属宗门。九幽帝者：主修鬼道，势力范围覆盖宇宙北部和东部的交界星域，手下亡灵系修士极多。三位帝者分别来自宇宙的三个不同方位——东部、东南和北偏东。他们同时介入西部事务，说明这不是偶然的关注——是早就准备好的联手行动。

"换句话说，剩下的三成势力已经不再代表他们自己了。"李长生看着屏幕上的星图——在西部边缘那一小片红色区域的背后，三条来自东侧的物资和舰队输送线已经隐约成型，"他们变成了东部势力进入西部的桥头堡。"

林晓问了一个在座所有人都在想的问题:"他们不怕吗？二十三个帝国全收了。冰帝、风帝、光帝——三个最强帝者全部归附。东部那三位凭什么认为仅靠这点残兵败将能挡住我们？"

"他们不需要挡住。"李长生看着屏幕上的三条后勤补给线，"他们需要的是拖延。每拖一个月，他们的其他盟友就多一个月部署时间。"

"还有更多帝者？"

"西部有二十三个帝者。东部有多少个帝者？南部呢？北部呢？整个宇宙加起来——帝者数量至少是西部帝者数量的三到四倍。如果他们在反冥王旗帜下统一起来——"

李长生没往下说。但所有人都明白了后半句。西部统一是万里长征的第一步。宇宙太大了。西部只是银河系第三旋臂上的一片扇形区域。东西南北加上中央——还有至少四倍的帝者在外。而这四倍帝者中的一部分正在集结。

许冰在记录本上写下本次战果统计的结语："西部第一阶段统一完成。已收入帝者十九人，圣者三百七十二人，战舰三万艘，公民逾四千亿。现阶段主要威胁：东部三位帝者（苍明、天枢、九幽）支持的西部反冥王联盟残部。下一阶段目标：击溃残部，完成西部百分之百统一。同时防范东部势力的全面干预。"

李长生在许冰写下结语的时候，做了一个决定。他用冥气在舰桥主屏幕上圈出了西部边缘的红色区域，然后在旁边写了一道简短的命令："三天后出发。速战速决。在东部主力舰队完成集结之前解决掉桥头堡。"

"所有人同意？"

没有人回答——不是因为不同意，而是因为这种问题在诸天号上已经不需要问了。

刀疤已经开始用腕带拉紧了作战服。小胖往厨房快走几步——他要抓紧时间把肉饼储备量翻两倍。小王的手指已经在键盘上飞舞——战术分析模型开始运行，目标：在三天内计算出以最少兵力最快摧毁反冥王联盟残部的最优战术方案。

诸天号的冥纹阵列进入了出发准备状态。一万两千道暗金色冥纹在船壳表面划过一道又一道的涡旋光流，那是冥纹引擎在进行推进前的预校准。光流在船体外一公里处形成了一圈肉眼可见的金色光环——从远处看，诸天号此刻像一颗被金色光环环绕的恒星。

但光环不是装饰。它是一次战斗的预告。

（第419章完）

# 第472章 至尊级实力

至尊的"试"，不是切磋。

正中央光柱中的至尊身影站了起来——这是他在这场会面中第一次从座位上起身。他的身形并不高大，大约和普通人类相似，但他的存在感在一瞬间暴涨了不知道多少倍。大殿的能量地面在他起身的同时碎成了无数细小的光屑，十二根光柱的光芒同时黯淡了一瞬——不是因为至尊刻意压制，而是他的气息太强，大殿本身的能量结构都来不及供应。

李长生在对方起身的前一瞬间已经做出了反应。他的冥气在体表形成了一层护盾——不是硬扛型的护盾，是偏移型的。冥气的本质是消解和吸收，他打算用冥气的特性来削弱至尊的攻击。这是他在无数次战斗中形成的本能：先防御，再找破绽。

但至尊没有攻击。

他只是抬起了手。那只手在空气中做了一个动作——像翻开一页书，又像扭转了一个看不见的开关。下一刻，大殿中的物理法则被重写了。

空间不是被扭曲，是被折叠。李长生的位置从大殿正中央移动到了不知什么地方——他低头看的瞬间，发现自己的脚踩在一片虚无之中。不是黑暗，是虚无——没有上下左右，没有任何参照物，连时间流速都变得不确定了。他知道自己还在大殿里，但至尊用一个动作创造了一片独立的空间领域，把他囚禁在了里面。

"这是至尊级对空间的掌控。"至尊的声音从四面八方传来，没有方向性，"你认为第八重可以在宇宙空间中不死——很了不起。但你有没有想过，不死的代价是什么？"

李长生没有回答。他在感知这片虚无空间的边界。他的冥气向四面八方延伸出去——一万里，十万里，一百万里。没有边界。这片虚无空间被拉伸到了他目前的感知极限之外。

至尊的声音再次响起："是被囚禁。不死不等于自由。我现在就可以把你困在这里——一万年，十万年，一百万年。你不会死，但你也出不去。你的朋友、你爱的人、你在意的地球——他们会在时间中消失，而你只能在这里看着他们消失。"

这句话击中了李长生内心深处最脆弱的地方。陈霜在冥渊突破时说过的那句话忽然在他脑海中响起：那你就变成了一个活死人。

但李长生的回答很简短："你不会。"

"为什么不会？"

"因为你在跟我说话。"李长生说，"真正的囚禁不需要对话。你对我说这些——说明你还在试探。你也怕。"

虚无空间中安静了片刻。然后至尊发出了一声低沉的笑——不是嘲弄，是某种古老的、带着欣赏意味的笑。

"有意思。"至尊说，"那我就不试了。"

话音刚落，虚无空间忽然向内坍缩。不是因为至尊解除了它——是因为李长生的脚底下忽然亮起了暗金色的光芒。冥王令的力量不是向外延伸寻找边界，而是直接在虚空中撕开了一个出口。冥渊空间的入口。李长生把自己遁入了冥渊——那是冥王的本命空间，一个独立维度。至尊的空间囚禁在三维宇宙中无解，但在独立维度面前就变成了一个四面漏风的笼子。

他从冥渊中走出来的时候，已经站在了大殿的另一端。脚下的能量地面重新凝结，身侧是一根至尊的光柱。

十二位至尊全部站了起来。

不是因为愤怒——是因为他们同时意识到了一个问题。刚才至尊施展的是纯粹的至尊级空间掌控，理论上可以困住任何一位仙王级修士。但李长生在没有突破到第九重的情况下，用冥渊空间的独立维度特性破解了至尊的空间囚禁。这意味着冥王的力量体系和他们认知中的修仙体系有本质区别。

"他不是仙王。"左侧一位至尊开口，声音低沉斑驳，像古老的钟声，"冥王体系是独立于常规修仙体系的。我们以前认为第八重对应仙王级——但这个判断可能是错的。"

"没错。"李长生说。他站在原地，掌心的冥王令纹路已经由暗金转为深黑——那是冥气被催动到极致时的颜色。"冥王体系从来不以常规体系为参照。你们想试——我可以陪你们试到底。"

正中央的至尊缓缓收回了手。光柱的光芒重新亮了起来，照亮了他的面容——那是一张看上去只有四十岁左右的脸，但那双眼睛里沉淀的东西远远不止四十年。他盯着李长生看了很久，然后点了点头。

"不差。"他说，"但还不够。"

他的右手再次抬起——这一次，整座大殿都开始颤抖。

（第472章完）

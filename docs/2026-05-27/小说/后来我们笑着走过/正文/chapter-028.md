# 第二十八章 勒贝格测度

国庆假期，我没有回家。

车票贵，路也远。更重要的是，我不知道回去以后要怎么面对青河县。那里有县一中，有翠湖，有我们说过话的长椅。人一旦在某个地方留下太多心事，再回去就像翻旧试卷，每一题都能看见当初错在哪里。

宿舍里只剩我和另一个室友。

他白天去网吧，晚上回来睡觉。我一个人坐在桌前，看书，看不进去；写字，写不下去。沈安晴的头像很少亮。偶尔亮起来，也只是很短地说几句。

我开始去图书馆。

不是为了学习，是为了找一个能让自己安静点的地方。楚州师范的图书馆比县一中大很多，书架一排一排，灯光白得有点冷。我在数学书架前停下来，随手抽了一本实分析。

书很难。

我看不懂。

可我看见一个词：勒贝格测度。

这个词我以前在网上见过，只觉得厉害。那天我盯着它，忽然很想把它写进诗里。一个人到底离另一个人多远，能不能测量？青河到楚州，楚州到南方城市，地图可以量。可等消息的时间，误会里的空白，屏幕上一个灰掉的头像，怎么量？

我把书借回宿舍。

晚上，赵一鸣打电话来。

“还活着吗？”

我说：“活着。”

“听起来不像。”

“你少咒我。”

他问：“跟她怎么样？”

我说：“少聊了。”

电话那头停了一下。

“她提的？”

“嗯。”

“你呢？”

“我说好。”

赵一鸣骂了一句：“你这个好字用得真省事。”

我靠在阳台栏杆上，看楼下人来人往。楚州夜里比青河亮，宿舍楼下小卖部一直开到很晚。有人买泡面，有人买啤酒，有人牵着手从路灯下走过。

我说：“不然呢？求她别这样？”

“你可以说你难受。”

我笑了一下：“说了有什么用？”

赵一鸣说：“有用没用是一回事，说不说是另一回事。”

我不想听了。

“挂了。”

“林予怀。”

“嗯？”

“别把自己写死在本子里。”

我没回，挂了电话。

那天夜里，我写了《勒贝格测度》。

题目写下来的时候，我自己都觉得装。一个中文系新生，拿着看不懂的数学名词写情诗，真是没出息。可我还是写了。

我写：

他们说距离可以被测量，
从青河到楚州，
从楚州到海边，
一张地图就能给出数字。

可我测不出你沉默的面积，
测不出我等一条消息时，
心里空掉的那一块。

后来我把“面积”两个字圈起来。

面积太理科，太冷。我又觉得正好。我的疼需要一点冷的东西装着，不然会流得到处都是。

我继续写：

若把想念分割成许多小段，
每一段都短到不能再短，
它们加起来，
是不是仍能铺满一个夜晚？

写完这里，我停了很久。

窗外有风，吹得阳台门发出很小的响。室友还没回来。宿舍里只有我的台灯亮着。

我忽然觉得自己很可笑。

沈安晴只是说少聊一点。我却已经把这件事写成了数学问题，写成了宇宙难题，写成了青春里绕不过去的墙。她要是知道，会不会觉得累？

我把笔放下，打开 QQ。

她在线。

头像亮着。

我盯着看了五分钟，没有点开。

最后她先发来一句：

你还没睡？

我回：

没有。

她问：

在做什么？

我看着桌上的诗。

我说：

写东西。

她问：

诗吗？

我回：

算是。

她说：

题目叫什么？

我看着那四个字，忽然不想说。它太像我把自己所有难堪都摆上桌。

我打：

很难听。

她说：

那就先别告诉我。

我盯着这句话。

先别。

不是不想知道，只是给我留一点地方。

那一晚，我们没有聊很久。她说要睡了，我说好。下线前，她发：

别太晚。

我回：

嗯。

她头像灰掉后，我把《勒贝格测度》夹进日记本。

我没有再改。

因为那不是一首好诗。

那是一张测不出的距离表。

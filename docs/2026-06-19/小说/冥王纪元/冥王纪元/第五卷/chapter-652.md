# 第652章 邀请对话

李长生踏入维度裂缝之后，发现自己站在了一个他从未到过的地方。

不是宇宙里面。不是外面的维度。是两者之间的交界地带——混沌之主记忆中被称为"过渡层"的那个薄薄的接缝。这里没有重力、没有光、没有空间——但不虚无。脚下没有任何东西——但他站住了。因为他体内纯混沌级的存在能在这个交界地带自主产生一个"站立"的物理属性。混沌是唯一一种能同时赋予宇宙内和宇宙外站立形态的介质。

他站在过渡层上往前看。前面就是真正的"域外"——宇宙维度防火墙的外面。那堵防火墙在他感知里是一道无穷大的、透明的、厚度没有一个标准单位能测的、垂直于所有已知维度的面。面那一侧就是太初所在的地方。太初不在"那个空间"里——它就是那个空间。

他站在防火墙前面，深吸一口气。不是空气——过渡层没有空气——他吸的是一口纯混沌。然后他把右手掌心反转向前——掌心对着防火墙——启动了那个太初留下的通讯开口。开口在他的意志催动下扩大了一圈、再一圈、不停地扩散——最后变成一道完整的、高约两米的光环。光环边缘泛着很古老很静的白光——和黑洞核心中太初留下的那只眼睛同一种颜色。

他向光环里面发出了呼叫——不是喊，不是意志外放，不是能量信号。是一种很简单的——在混沌之主传承中被定义为"敲门"的方式：他把自己的意志凝聚点对准光环中心，将"我要和你对话"这个意念推到最纯粹的不带任何杂念的形态——进到光环中心——等着。

等了约二十秒。或者根本没有二十秒——过渡层不存在时间。但他在主观感受上等了一段时间——然后光环震了一下。不是能量震动——是"回应"。太初收到了他的敲门。它在回答。

光环中心出现了一个东西。不是太初本体——是一个极小的、能在低维度中被人类感知接收的"感知锚点"。太初用这个锚点作为和李长生沟通的桥梁——因为它本体太大，不可能直接出现在任何一个宇宙内或宇宙外的有限场合。它把自己的一个感知锚点放在光环中心——就好像一个巨人在一扇蚂蚁洞门口放了一根手指——蚂蚁可以站在手指旁边，跟着一根成比例的尺度来对话。

"李长生。"太初说。

太初的"声音"不是声音——它把这个名叫"李长生"的三个字直接放在他的意识中被"听"见——没有声波的参与，没有语言的转译。就只是一个直接的"被认出"——太初用他对自己最真实的理解直接返回结果——三个字的含义是："我正在跟你说话的是李长生——这个从地球黄土地走出来的混沌之主。"

"太初。"李长生回叫道。他没用"您"——不是不尊重，是在太初面前用"你"反而比"您"更接近真相。他在太初的注视中被看透了整个存在——太初知道他为什么会用"你"这个字的全部原因——不必再加解释。

"你准备好了吗？"太初问。

这个问题不是在问他身体准备好了没有——太初刚确认过，他的混沌通道全部稳定。这问的是更深层的：他是否准备好了和"万物起源"进行直接的、没有遮掩的、可能会改变他全部世界观的对话。任何人在没有准备好时会被这种对话摧毁——不是被打——是被"真相的负压"吸垮。太初只有这一个问题——但它包含了一切。

李长生想了想。他问了一句很李长生特色的问题："上去要多久？"

太初不需要时间——但这种对话也不需要时间。所以太初的回答不是用时长来答："你会觉得是一瞬——但你需要知道它是永远的。对话一旦开启——你对什么是万物的所有理解将永远被推翻。你愿意吗？"

"我是种地的——我不怕推翻。"李长生说。"土每年都翻一次。翻的时候底下全是蚯蚓和没烂透的根——乱七八糟的。盖上土浇点水——过一阵子自己就好了。"

太初沉默了一瞬——然后光环扩大。李长生这句话里"自己就好了"四个字被太初以最高精确度保留了原始语义。在太初的衡量系统中，"自己就好"不是粗糙的经验判断——是一种对宇宙自我修复倾向的直觉信任。这种信任在太初面前是所有可继承品质中排名极靠前的一项——因为太初自己就是一切自我修复的源头。一个种地的老农在田埂上说"自己就好了"——和一个混沌之主在维度裂缝中说同样的话——在太初听来完全相同。人的语言在太初那里不会被音量的高低和称号的大小影响——太初只读语义背后那个人的真实状态。

李长生走进了光环。

站在光环另一端的地方——不是空间——不是维度——不是时间。那是太初的所在——一切存在的起始——所有宇宙轮回的制动前动器后面的原初层面——这里没有"外"和"内"，没有"前"和"后"，不是黑也不是白——只是一种很基本的"存"——所有可存在的东西最终都源自这里。他第一个感知到的不是视觉——是一种比视觉更直接的"被认识"感：他站在这里，太初看到了他——不是看到他的外形或是他的修为光环——是看到了他从出生到现在全部的存在历程：他作为一个农民的儿子的第一次呼吸、他第一次跌倒膝盖上的疤、他第一次握锄头的手感和第一次握冥王令时掌心的震动——全部都在太初的一瞥中被同时看见了。不是翻档案——是看存在本身。被这样看，他没有任何不适——反而像第一次回到家时在门槛上被母亲从头到脚打量了一遍。太初的看不是审视——是确认。

他站在了太初面前。太初的样子——他会用了自己的命名方式来命名。

（第652章完）

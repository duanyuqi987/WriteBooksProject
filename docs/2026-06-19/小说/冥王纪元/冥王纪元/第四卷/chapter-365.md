# 第365章 有的想合作，有的想逃离

帝者层面的分裂是银河系这盘棋的上半场。下半场在中小势力之间--更安静，但规模更大。

冥王归来消息扩散后的第二周，地球仙联政府的外联部收到了一百四十份来自不同星域的通讯请求。

外联部是许冰在两周前刚成立的新部门。办公地点在联合政府大楼东翼三层，一共十二个工位，九个是新招的应届灵符通讯专业毕业生。设备是临时从火星基地借来的二手灵量子通讯阵列——外观看起来像是一排倒扣着的金属锅。外联部成立时的任务说明书只有一句话："处理太阳系外势力所有主动通讯请求。"许冰当时觉得这个部门在一个月内应该不会有工作。

她低估了信息的传播速度。

这些请求不是帝者发的--帝者们不会用这种方式联系一个还没有正式加入银河国际体系的行星政府。帝者们依然在用神识通讯和帝者联席会议。但这些请求来自小势力：独立星区、散修联盟、佣兵军团、星际商会、非帝者属国的独立行星文明。每一个都用了最标准的外交通讯格式——文末附上了灵量子通讯的十一位位址码和回复频段，措辞谨慎得像是在给一个随时可能爆炸的星团发电报。

一百四十份请求。在两周之内，发给一个还没有正式在银河系建交的星球政府。这个数字本身就是一个政治事件。

外联部的九个应届生连续加班了三天。他们用许冰写的一套标准分类模板把每一份请求归档——势力名称、星域坐标、帝者归属、通讯措辞分析、威胁等级评估。每个应届生的眼袋都在用同样的速度增长。有一个叫周远的新人在第三天凌晨三点突然跑进许冰的办公室，手里抓着一份刚翻译完的木灵域古籍格式通讯，脸色像是看到了鬼："许姐——你能不能帮我确认一下——这封信里说他们文明的创始人在一万两千年前给冥王交过保护费——他们现在要续费——"

许冰在联合政府大楼地下三层的会议室里建了一张大屏幕。屏幕上是她用二十四小时整理出来的势力名录--每一份通讯请求都按照势力规模、地理远近、接触动机三个维度做了分类。她和老陈分工合作：许冰分析政治法律层面的风险，老陈分析商业层面的价值。

"第一类。"许冰在屏幕上弹出蓝色标签栏，"合作请求。七个势力--全部来自东部星域外围，距离太阳系八万光年以上。包括：飞星阁（中型阵法材料供应商）、龙渊散修联盟（二十四个独立星球的松散联盟）、深海商号（水系灵材贸易商）、以及其他四家。它们的共同特点是--"

"都不在金锋帝的势力范围里。"老陈替她接了话。他在自己笔记本上同步做了记录--他手写的分类表比许冰的电子表格多了三列：该势力上一财年的灵材交易额、该势力最近五年内的对外投资方向、以及该势力与帝者属国之间的供应链依赖程度。"深海商号这家我知道。飞星阁的水系灵材有一半是从他们那里拿的。他们的供应链被南部商道联合体掐着--如果他们自己有了新的供货渠道--"

"他们就不用再看南部商道的脸色。"许冰把蓝色标签的势力名录单独放大，"合作请求的措辞都是'愿就文化交流与贸易合作展开初步对话'。这些词在法律上没有束缚力--和老陈刚才说的南部商道声明类似。但它们发送请求的时间点很巧--全都在木灵帝发完公开信之后的四十八小时内。"

"他们在等信号。"陈霜说。她从会议桌旁边站起来，走到屏幕前，仔细看了看蓝色名单上的势力名称。"不是等我们的信号--是等帝者的信号。木灵帝用公开信告诉所有人'这不是战争'。他们收到信号后，用了两天时间做内部评估，然后发出合作请求。他们的逻辑是：如果木灵帝都觉得有讨论空间--那我们也可以讨论。"

"对。"许冰调出第二类势力--黄色标签。"试探性的观望请求。这一类最多--八十三个势力。它们在通讯请求里的措辞非常含混：既不说合作也不说敌对，只是一些关于'希望在适当时机建立双边对话渠道'的外交辞令。翻译成人话就是：'我们还没想好站哪边，但先留个联系方式--方便你们打赢了之后联系我们。'"

"人话翻译得好。"刀疤难得开口。他一直靠墙站着，双臂抱胸。他的性格不适合分析复杂的势力关系--但他对人性有一种军人式的精确判断，"这帮人是在买保险。不用交保费的那种。如果我们赢了，他们拿出这份通讯请求说'我一直支持你们'。如果金锋帝赢了，他们就说'你看看我们只是问了个好而已'。"

许冰切换到第三类。红色标签。

"第三类--撤离与避险。三十二个势力。这些势力的共同特点是不想和冥王有任何形式的接触，但也不打算加入金锋帝的联合阵营。它们选择直接--跑。"

老陈翻到第三类势力的明细。他的手在笔记本上停住了。他认识其中几个名字。

"灵木谷。"他念出第一个名字，然后把笔记本上的相关记录翻了出来，"万年前诸神联盟的三级成员文明。在冥王陨落战役中负责后勤补给。战后被处罚，从帝者属国降格为独立文明。他们在银河系东部租了三颗星球。租期还有六千年。"

"他们要提前撤租？"

"不只是撤租。他们把三颗星球上的灵脉开采设施全部拆了--这些设备是花了九千年才建起来的。拆设备比建设备还贵--但他们拆了。"

许冰在旁边调出了灵木谷的全部公开数据。数据显示灵木谷的撤离规模比她预计的还要大。"他们不是从这三颗星球撤离。他们是从整个银河系撤离。灵木谷目前拥有三十二艘殖民船。每艘船载走了一万到一万五千名平民。总撤离人口--近四十万。"

这个数字让会议室安静了几秒钟。

四十万人的撤离--这意味着灵木谷不是在避险。他们是在逃离。他们坚信冥王一旦恢复完全力量后会清算所有万年前参与过围攻的势力及其后人。不是推测--是确信。

"不止他们一个。"老陈继续翻着红色名录，一个接一个地念出名字，"玄金星、赤风城、寒石山--全是万年前诸神联盟成员的后裔。规模不等，小的只有一艘船几千人，大的像灵木谷这样几十万。他们撤去哪里？"

许冰调出了银河系最外围的星图。在银河系边缘之外的虚空中存在着少数散布的星团--银河系的引力范围以外，没有任何已知帝者势力覆盖。那里是法外之地，没有任何规则。

"他们在往银河系外撤。不是搬去别的帝者辖区--是直接离开银河系。"

李长生始终沉默。他听着老陈和许冰的分析，看着屏幕上不断增加的数据，手指在桌面上有节奏地轻敲。

终于他开口。他说的话和会议桌上讨论的内容完全不在一个层面上。

"他们不怕我杀他们。"

所有人转过来看着他。

"他们不怕我杀人。他们怕的是我会清算--怕的是清算意味着旧账要一笔一笔地算。所以他们跑了。金锋帝怕的是我会打--怕的是冥王令否决法则。所以他们要先下手。"李长生的手指停下来了，"关键不是跑的人有多少。关键不是打的人有多少。关键是--"

他从椅子上站起来，走到屏幕前。他把手放在红色名单和蓝色名单之间--一手指撤离的，一手指合作的，中间夹着的是一大片黄色的观望区。

"关键是中间这八十三个。"

"如果他们最后全倒向金锋帝——那就是一场银河大战。如果他们最后全倒向我们——金锋帝根本没有足够的资源和兵力来围攻地球。如果他们继续观望——"他停顿了一下，"我们需要的就是让他们继续观望。让他们看见一个够强的地球，又不觉得地球会打他们。让他们觉得观望是最安全的选择。"

会议室里安静了很久。刀疤抱着手臂靠在墙上，忽然低低地说了一句："这不就是老子当年在中东搞的——"

"对。信息战、心理战、威慑。"李长生把那颗灵石从桌上拿起来，握在手里。灵石内的外来灵气在他手心轻微跳动，隔着冥王令的脉动也能感觉到那股陌生的密度。"帝者们习惯了力量说话。但在他们还没决定用多大力量之前——我们要让他们自己怀疑自己的力量够不够用。让他们在脑子里先打一场——然后输掉。"

老陈合上了笔记本。他的手写页面已经翻到了最后一页——这本笔记本是他从老家带来的，黄色封皮上印着"韵达速递"四个褪色大字。在封底附近的空白页上，他用铅笔歪歪扭扭地写下了三个字：要赢。

"旁观者的信心——才是这场仗真正的胜负手。不是谁打得多狠。是第一枪打响之前，有多少人觉得我们能赢。"

散会后，许冰走到李长生旁边，把一份只有三行字的报告放在他面前。"根据对第三类势力撤离方向和撤离时序的交叉分析——目前灵木谷的撤离舰队离开银河系引力边界之后，预计两年半内无法被任何已知的通讯手段联系到。另外十一个正在撤离的势力中——有六个的撤离航线经过了金锋帝和暗影帝共享的星区辐射带。他们没通知任何帝者。"

"没通知是什么意思？"

"意思是——他们宁愿绕路经过法外空域，也不愿意向帝者通报行踪。他们怕的不只是你——他们同样怕自己的撤离路线被帝者掌握后，被帝者当成对付你的筹码。恐惧会传染。对冥王的恐惧首先削弱了他们对帝者的信任。信任一旦崩了——银河系的旧秩序就跟着崩了。"

李长生看着她写的那三行字。报告边角处有一个被擦掉的笔画痕迹——许冰从来不在文件上写错字，这次有一个字她写歪了又重写了一遍。

（第365章完）

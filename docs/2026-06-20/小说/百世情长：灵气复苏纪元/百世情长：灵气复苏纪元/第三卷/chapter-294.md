# 第294章 她对他的回赠

在第三卷快要结束时，苏晚用了很长时间准备了一份给林牧的回赠——一份用了她十余世时间才攒够材料的最完整的礼物。这份礼物不是一柄新剑或一件法器——而是一册极其厚重的手制图册，名为《各处——你待过的地方》。

图册的每一页都是一幅她亲手画的图——画的是她从第一世到第十世记忆中林牧在等待她时待过的每一个地点。她不是顶尖的画家——但每幅图的视角都是从林牧当时所处的位置往外看——画的就是他每天凝视着的那些山、水、街角、树影、窗口、石台、岩缝和天空。她的用意是——让他在看到这些图时，能以她的视角重新体会他当年独自等待的那份孤寂——但现在看这份孤寂已经不再可怕——因为每一幅图的下方都有她以自己在同一时间在异地的同幅画作的微缩对比——证明两个人虽然在之前那些世里彼此不认识或不在同一个空间——但她仍然在同一个天日下做着各自的事——在某张茶铺老板娘择茶的小图旁边——是他在街对面茶馆默默关注时窗外那棵槐树。在另一图中是他在渔村礁石上眺望她出海的位置——而她同时在那里目送她的渔船分开同一片海面。在同一晚她躺在矿区矿道里给姐姐们盖着旧毯子——而他在道口对着冷风守夜。

每一幅画的页边她都写了极小的注:

第一幅——"你在雪山的洞口看着不来的雪兔——我在同一年的同一天在青溪镇（前世未识）因茶摊太冷多穿了一件棉坎肩在门口择冬天最后一批陈茶——你的雪就是我的风——只是不同地。你不会一个人看——因为总有另一个也处在你同时的冷中，虽不知你——气候仍连。"

第二幅——"你坐在渔村礁石上，我看着你不认识我的背影在渔网后面叠网——你用眼角判断风向——我用自己的脉搏断潮——我们那时候仍在未解状态——但我们的皮肤同时接触到相同的海水——盐分一样冷但不会隔断。"

第三幅——"你在赤霄执勤站里每日以秒为单位的将我的安全写入'安全'——那时我已回赤霄敌营宿舍在被你划破的袖子上偷偷用针脚缝你的假名字——当时我不敢写'林'——只写'林'的一半——'木'——但你纪录日志中同一秒写的是全名——我和你写的是同一笔画的同步异程——木——牧——晚——我的补——你的记——同秒不同面——针和墨在同一空间距——都是证。"

末页她留了一整页空白——只在页底写了一行字:"第十一世以后——每一站——你旁边都有我。我不补前页的空白——因为空白代表我们未来还有新地方要画进去——它不是缺——是预留。——苏晚。"

林牧把图册从第一页翻到末页——他在翻页的过程中——他不是在看图——他是在看每一页的页边夹——那些是她从各个现实地点捡拾回来的真实尘埃颗粒——分别来自雪山石屑、礁石砂粒、赤霄旧地浮土、矿道碳渣——她把这些微细的物件捡起来嵌在画页间——让画不只是画——是每一地的土也都重新聚回来——合成他一个人兜遍的所有经纬。他翻到第五世矿区炭渣——那粒渣是她从泽野矿区原址采集回来的真矿渣——他用手指碰了一下——渣上的残余矿灰微沾在他虎口茧上的同一孔隙——和矿道时一样细腻摩擦力——他对她说:"这粒渣——你现在把它从那里捡回来——它就从来没离开过。跟我在茶盒里藏的那每一分每一样——现在你的图册是我等待的最完整记录——全册页边夹的都是同一时代的在原地已不再存在的旧粒子——而你用微碎回环把它们全带回此处——所以现在——等待时期的所有原地——都已被你接走——我不用再回任何一处——因为我们已把各处带回晚牧——成为可存册本。"

苏晚把图册收进神龛最新的一个位置——在他原来封存的"守卫期储物袋"旁的格子——把图册和储物袋并列——然后说:"你的茶盒——我的图册。你留物——我绘图——双方的视角都收在这——以后如果有谁想知道'等待'怎么熬——他们就来翻这两盒——左边是你留给她的一切证据——右边是她终于追上你之后画的你当时的图像和实境回归——两种存档互补——缺一不可。"

"所以晚牧居的真正名字——应该是'无缺存馆'——全称:所有丢失后来都被找回了——的储物处。"林牧把那本册子合上——然后覆盖上自己窄身剑的复刻投影——"从此我的警戒线——全面撤除。"

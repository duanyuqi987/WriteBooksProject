# 第176章 高僧与李长生论道三天三夜

活佛没有把碎片交给他。

他说的是"今天"，但他没有立即伸出手。他收回手，把那块碎片重新包进藏红布囊里，放在蒲垫中间。然后他对李长生说了一句让所有期待都落空的话:

"碎片等了你八百年。不差这三天。先说话。"

于是论道开始了。

不是密宗的法会。不是师徒传授。不是问答考试。就是两个人面对面坐着，说话。酥油灯在墙角烧着，牦牛粪在火炉里闷烧，冈仁波齐的风从门缝里挤进来，把酥油灯的火苗轻轻摇晃。三天。

——

第一天。关于生死。

活佛捻着念珠问第一个问题:"你为什么要拿碎片？"

"为了变强。"

"变强之后呢？"

李长生沉默了几秒。这个问题他问过自己很多次。第一次问是在祖坟旁挖出第一块碎片的那晚——他躺在老宅的土炕上，手掌烫得睡不着，问自己:你一个种地的，要这个干什么？后来每融合一块碎片就问一次。每问一次，答案都会变一点。

"最开始是为了自保。"他说，"我拿到了碎片，玄门七宗要杀我。我不变强就死。"

"后来你变强了。他们杀不了你了。为什么还要继续找碎片？"

"因为——有人在帮我。小王、老陈、陈霜、刀疤、龟相——他们把自己的生活扔了，跟着我。我不继续往前走，他们的生活就白扔了。"

"所以你为别人变强。"

"算是。"

活佛捻了两颗念珠。"再问你——如果你拿到了所有的碎片，你变到了最强。到那一天，你想做什么？"

这个问题李长生没有答案。不是不想回答——是没办法回答。他是农民出身，从小在王婶家吃饭，在田里刨食。他的世界里没有"最强之后做什么"这种问题。农民不思考这种问题——农民思考的是今天要不要施化肥、明天会不会下雨、后天的麦子能不能卖个好价钱。

"我没想好。"他诚实地回答。

"诚实是好事。"活佛微微一笑，"很多人面对这个问题的时候会背答案——我想拯救世界、我想维护正义、我想保护所有人。这些不是答案，是台词。你不知道自己不知道——这是最好的起点。"

——

第二天。关于力量与责任。

高原上的天亮得特别早。冈仁波齐的雪峰在日出时分被染成了金红色——不是被阳光染的，是被高空的雪粒子反射了第一道光线。李长生在石室门口站了一刻钟，看着这座金字塔形的雪峰一点一点亮起来。

活佛已经在蒲墁上坐着了。他的姿势和昨天一模一样——盘腿、脊背挺直、左手捻念珠、右手按膝盖。看起来他一整夜都没有动过位置。不是没睡——是"睡"这件事对他的身体来说已经没有意义了。圣者级别的生命体可以从天地间直接吸收能量，睡眠已经从"休息"变成了历史习惯。

"昨天我们说了生死。"活佛捻起一颗菩提子，"今天说点更难的——力量。"

"力量？"

"你融合了五块碎片。每一个碎片都让你更强。但我想问你——在融合每块碎片之后，你觉得更自由了吗？"

李长生愣住了。

这个问题——从来没有人问过他。不管是残魂、龟相、陈霜、小王还是任何一个人——都在关注他"强了多少"。灵素读数涨了多少、冥纹多了几道、境界突破到第几重。但从来没有人问过他:你觉得更自由了吗？

"不是更自由。"他慢慢说，"是——更沉重。"

"怎么个沉重法？"

"第一块碎片的时候，我只是个农民。那时候我唯一要操心的是五亩地。碎片让我不用再操心五亩地了——但我开始操心别人的命。小心被玄门七宗追杀、小王被威胁、老陈的家人有没有风险、灵眼苏醒之后会有多少人死。"他看着自己的手，"力量越大——心越累。"

活佛捻了三颗菩提子。捻得非常慢——每颗之间隔了将近十秒。

"你说到点子上了。"他说，"力量不是自由。力量是责任。不是别人强加给你的责任——是你自己选择去承担的。你能飞——所以你得去拉那些还在地上爬的人。你能打——所以你得去挡在那些挡不住的人前面。你不想——但你会。不是因为有人逼你——是因为你做不到看见了却不管。"

他直视着李长生。

"能做到'能管但不管'的人只有两种——一种是从来没感受过力量的滋味，一种是不在乎。而你不是这两种人中的一种。"

李长生没有说话。他看着墙上的酥油灯。火苗还是不动——像一只安静的猫。

"你刚才说——力量越大，心越累。"活佛的声音在石室里缓缓回荡，"但你有没有想过——你不是在累。你是在长。肌肉撕裂之后重新长起来的时候——就是疼的。心的'疼'不是崩溃。是变大的代价。"

"那什么时候不疼？"

"等你不再觉得自己是在'替别人扛'的时候。"活佛捻起下一颗菩提子，"你帮人——不是你的负担。是你的选择。一旦承认'这是我选的'——累就不叫累了。叫责任。责任有重量。但重量让你的脚踩得实。"

——

第三天。关于宿命与自由。

第三天早上，风停了。冈仁波齐的雪峰在无风的阳光下寂静得不太真实——像一幅被钉在天空中的巨幅画卷。高原上的风声是这里的背景白噪音，忽然停下来反而让人不习惯。

"最后一天。"活佛把菩提子念珠收进袖口。他的手在收念珠的时候很慢——不是因为老了动作慢，是给了自己一个过渡。"今天说最难的问题。宿命。"

李长生皱了一下眉。这个词他太熟了。从残魂第一次开口说话开始，这个词就像一个甩不掉的影子——冥王碎片、冥王令、冥王转世、冥王的记忆。每一次他觉得自己在"自主选择"的时候，都有人提醒他:这不是你的选择，是宿命。

"你觉得你是自己选择走这条路的——还是被碎片选择的？"活佛问。

"很多人问过我这个问题。"李长生说，"我自己也问过。"

"你有答案吗？"

"有。"他看着活佛的眼睛，"我选了。碎片可以选任何一个人——但它砸不到不在乎它的人身上。我挖祖坟的那天晚上——泥里透光。我可以不挖。很多人看见奇怪的东西不敢碰——我挖了。碎片在手里发热的时候，我可以撒手——我没撒。"

"所以你选被碎片选。"

"对。"

活佛沉默了片刻。然后他笑了。是这次论道以来第一次真正的笑——不是礼貌的微笑，是发自内心觉得有意思。

"很好。"他说，"大多数人一辈子都分不清'宿命'和'选择'的区别。他们认为——凡是发生了的就是宿命。但其实——宿命只是一扇门。门开着放在你面前——进去是你的选择。你可以不进。代价是一辈子不知道门后面有什么。"

他从袖子里掏出茶包——是藏地的砖茶，压得很紧的大块茶叶。他把茶叶放在铜杯里，拨开水壶的热水。滚水冲进杯子的声音，在这间连续装了两天的石室里，竟然格外清晰。

"我还想问你一个——更直接的问题。"活佛把茶杯推给李长生，"你有没有想过——你不是冥王转世。你只是李长生。"

李长生端茶的手停了一下。

"想过。"他说，声音比之前低了一些，"很多次。每次有人说我是冥王转世的时候，我就想:如果我不是呢？如果我只是一个被碎片碰巧砸中的农民——那我凭什么代表冥王？凭什么去做冥王要做的那些事？"

"然后呢？你怎么回答自己的？"

"我没回答。"李长生喝了一口砖茶。茶很涩——高原的水烧到八十多度就开了，泡砖茶泡不够。"我只是做。不管是谁转世——我不做，事情不会自己完成。老王八说灵眼还有几个月就要临界了。到时候上古妖兽冲出来，不管我是不是冥王转世——都得有人去挡。不是宿命叫我挡——是我看到了。"

活佛把念珠从袖子里又取了出来。这一次——他把念珠放在了两人中间的蒲墁上。那个位置之前放的是第六块碎片。

"第一天你告诉我——你不知道最强之后要做什么。第二天你说——力量不是自由，是责任。第三天你说——你选了被碎片选。"活佛把三颗菩提子从念珠上依次捻下来，排在蒲垫上。"你现在回答了最难的一个问题。不是'我是不是冥王'。而是——'我不管是不是冥王，该做的事照样做'。"

石室里沉默了很久。每一秒都沉到了冈仁波齐的岩壁深处。

"宿命不是你想的那个东西。"活佛最后说，"宿命不是别人写好的剧本。宿命是一条河。你前半段沿着河走——以为水流的方向就是你的方向。走到一半你发现——你可以游泳了。你可以改方向了。但你选择还是顺着河往下游走。不是因为你游不了别的方向——是因为你决定和河一起去它要去的地方。而河要去的地方——就是你要去的地方。"

他把碎片从蒲垫上捡起来。黑芒一闪——碎片在酥油灯的微光下泛着幽蓝的光泽。

"三天到了。"活佛说。

(第176章完)

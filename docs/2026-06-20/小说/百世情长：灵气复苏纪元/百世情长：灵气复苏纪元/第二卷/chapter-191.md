# 第191章 资质的局限

淬体初期的兴奋维持了大概三个多月，然后现实如期而至。

苏小晚在突破淬体初期之后，体内灵气循环的速度比以前快了——但只快了大约三分之一左右。她能够更清楚地感知到经络中的气感，也能在某些特别宁静的夜晚感觉到丹田微微发热。但这些进步在淬体初期到中期之间非常狭窄的通道上很快就遇到了拦路石。无论她怎么加练——每天把呼吸法从十五分钟延长到三十分钟，在自己力所能及范围内多揉几个穴位——灵气的增长始终停滞在初期高阶与中期门槛之间的那道看不见的缝前。

她第一次真切地感受到什么叫"瓶颈"。不是以前被D级检测结果一次次打击那种——是明知道自己身体里"还有空间"，但那空间被某种东西从外往内死守着不让她碰。

大三上学期的寒假，她带着困惑回家。她没有像以前那样急——因为经过这么多年林老师的心理辅导，她已经不把"瓶颈"当成失败。但她确实非常非常想进一步。这个念头是发自内心的——不是被谁要求。

林牧在她回家的第二天就让猫去院子等她。她抱着猫在老藤椅上坐了一整个上午——手里拿着那本《经络食谱》，但根本没在翻，纯粹是抱着猫发呆，消化心里那份压着的闷气。最后她放下猫，走到院子里的石阶上，仰看着皂荚树的树顶——天很高，树枝黑漆漆地在蓝天下画了好多岔路。她忽然想，她自己的路是不是也像这棵树的枝一样——看起来很多岔，实际全被一个顶盖压住了。不是因为D级。D级只是表现出来被人看到的。真正的那个压盖——是别的更深的东西，她说不出来。

林牧从屋里走出来。他大概已经知道她要说什么。但他没催。他把竹杖靠在门框上，递给她一小布袋的糖渍姜片——是她从小就爱吃的零嘴。她抱着布袋打开放在膝盖上，然后说了一句他不意外但依然沉重的坦然句:"老师——我这次在学校也加了练——但是感觉被什么东西顶着——上不去。"

他不知道怎么向她解释——那个"顶着的"是轮回锁。在她灵魂最外层压迫资质的部分已经把"淬体初期顶点"设定为自动封顶线。如果没有外力干预，D级现有限度就是只能到这里。这是无数世以来她无法靠自己突破的根本原因。他要做的就是帮她打破这道宿命限界。但不能直接说，必须等她主动要求破界。

他从墙根边把一块被废弃了的旧铁桶踢回来——那桶底锈了，在石板上刮出一道刮擦的尖锐短音。"你觉得什么是被'顶住'了呢？"

"该怎么说——就是力气够，但打不开。丹田热气到那里就堆着了——像猫爪子拍在玻璃上。能看到外面，伸不出去。"

猫听到"猫爪子拍玻璃"后竖起耳朵瞪了他一眼。她摸摸猫脑袋说"不是说你，是说我自己"。

林牧没有接她这个形象的比喻。他带着她到灶房走去了一趟——把一只炖鸡汤的大瓷锅从灶上取下，用锅盖沉沉的锅。他把锅放在桌上，指着锅盖上方说:"你现在就在这个锅盖下面。锅盖是用高质陶瓷做的——关得很严。但你能透过锅盖闻到一个味道——那是外面空气中的某种东西的味道。你不能伸手去拨开锅盖——但你可以问一句——"

她愣着看他。不是太懂。但他继续往下:"如果要打开这口锅盖——需要怎么开？"

"拧开锅盖子——"

"锅盖重不重？"

"——重。"

"但如果拿锅的人自己也用力去推——外加有人在旁边帮一手手——你觉得盖子推得开吗？"

她眼睛亮了一下——但不是用"锅盖"想来解，而是瞬间将这个暗喻联系到了自己目前的修炼状态——她下意识觉得自己就是被一个非常重的"盖子"闷住了。那盖子就是那个让她上不去的东西。老师问她:"你是不是要主动尝试推那锅盖看能否推开——如果在别人辅助下？"

"是。"她吐出这个字时顿了一下，然后确认地点了一下头——"我想推。"

在修仙语系中这两个字和"我想突破瓶颈"含意完全相同。

林牧把锅盖从砂锅上拿下来放在旁边。蒸汽从锅里面猛地涌出来——热得她眼睛眯了一下。他转问她:"锅盖下被关着的这锅汤。你想知道它继续炖下去能有多好吃吗？"

"能有多好吃——"

"那就把盖子打开。让它接着炖。"他说。"不要等锅盖自己开——因为它不会。对于某些锅而言——你得自己主动地掀第一个缝。"

她坐在锅边闻着从瓷锅中散出的红枣鸡汤的香味。若有所思地嚼着糖姜片。这个过程她被潜移默化地推着向那句"我想掀盖子"前行了一步。不是林牧逼她说"我想修仙"。他只是用一个小动作——让她的主动溢出来了一点点。修仙史上有一种极其玄奥但无法被直接记载下来的破锁触发点——就是"意愿的主动切口"。不能诱骗，只能说隐喻。只有当事人自己在看不见全貌的情况下，根据隐喻本身来选择行动，才不被计数为外力干扰。

那是她人生里离"主动要求破锁"最接近的一刻。但还没完全说出口。他缓缓退回厨房，把这刻的触发节点在她的内心继续发酵。

他知道她还在蓄最后的力量。但她从"推锅盖"到开始设想"修仙"，其中的距离其实只有一步之遥了。这一步她不走——谁也不能推。这一世——他相信她一定会自己迈过去。

**作者：段锦佑**

# foreshadow-002：翠湖长椅

- 状态：paid_off
- 首次埋入：chapter-020，赵一鸣提出晚上去翠湖，且沈安晴等女生也会去。
- 计划兑现：chapter-049/chapter-050
- 叙事功能：翠湖见证第一次说出口，也见证最终不再说出口。

## 记录

- [chapter-019] 回校大巴经过翠湖，林予怀第一次把高考后承诺和湖面联系起来。
- [chapter-020] 高考结束后，赵一鸣带来翠湖邀约，林予怀决定赴约。
- [chapter-021] 林予怀与沈安晴在翠湖长椅进行第一次较长的私人对话，QQ 联系通道由此出现。
- [chapter-035] 德克士见面中旧事被侧面触碰，翠湖不再只是浪漫地点，也成为林予怀想要追问却不能追问的旧答案。
- [chapter-040] 林予怀回家过年时没有再问沈安晴翠湖旧事，说明第五卷回收将从索要答案转向释怀。
- [chapter-045] 林予怀重走青河旧地后独自走向翠湖，旧地回收从准备阶段进入正式面对。
- [chapter-046] 林予怀回到翠湖，发现旧长椅已换成石凳，又看见同心锁、纸飞机和新路灯，确认旧地方没有义务保存私人往事。
- [chapter-050] 大巴离开青河时经过翠湖附近，林予怀没有回头；回到楚州后继续生活，翠湖伏笔完成收束。

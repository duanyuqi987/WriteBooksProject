# 第四百六十四章 心魔试炼

心魔不是幻象。幻象是你看到不存在的东西。心魔是你看到绝对真实的东西——只是它们是你最不想看到的东西。

林牧踏上心魔台阶的那一刻，周围的一切都消失了。没有光之阶梯，没有头顶的甬道，没有手心里苏晚的温度。他独自一人站在一片完全白色的虚空中。脚底没有地面，头顶没有天空，四周没有任何参照物。

然后白色裂开了。

从他面前三步远的地方，空间像被人从反面对着一层薄纸狠狠打一拳——撕裂成了一片漆黑的断口。断口里走出来一个人——不是苏晚。是万年前那个白衣女子。她站在他面前三步远，脸上带着那个熟悉的淡淡的微笑。她的白衣上还是那天的血——雷霆劈下之前的血。

"你来了。"她说。

林牧知道这是心魔。知道这不是真的她。但他的灵核在看到她的一瞬间还是剧烈地疼了一下——是那种一万年来一直在心底压着、忽然被翻出来的疼。

"你在做什么？"他问。

"我在等你问出那个问题。"心魔说。

"什么问题？"

"你在昆仑山暗河底找到我的信。你在飞升阶梯上读清了我的唇语。'活下去'——你终于读清楚了。但你一直没有问——为什么。为什么不和你一起承受那一道雷？为什么推开你？为什么明明可以两人一起抵抗，我却偏偏选择了独自赴死？"

林牧没有说话。

"因为——"心魔的表情变了。那个白衣女子的微笑从温柔变成了悲哀——一种极深极古老的悲哀。"因为我知道，如果我和你一起承受那道天雷，你的灵核会为了保护我而输出百分之百的全部力量。你可以挡住那道雷。但你之后会修为全废——再也无法飞升。我推开了你不是因为我不想活——是因为你活着就能回来找我。你活着我就能在轮回里等到你。你活着——是我给自己留的唯一一线希望。"

心魔停了一下。然后她的嘴角弯了一下，眼泪却在弯的同时流下来。

"一万年了。你每在轮回里找我一次，我就记起来一点点。一百次。一千次。一万年的循环。我每一次转世看到你那双安静的眼睛时——我都想哭。但我哭不出来。因为我记不起来我为什么要哭。直到这一世——"

她抬起一只手，指向林牧身后。他身后不远处站着另一个苏晚——现实中的苏晚。她也在心魔空间中站着，面前站着另一个林牧的心魔。他们被心魔隔在不同的空间画面里——看不见彼此，但都在经历各自的考验。

"直到这一世——她终于可以哭出来了。"白衣女子的心魔说。"她不是我的替身。她是我。是经过了百世的轮回后终于能完整地爱你的那个我。"

林牧闭上眼睛。再睁开时，心魔已经消失了。白色的虚空中只剩下他一个人——不，不是一个人。他和苏晚的心魔空间在这一刻以同修共振的方式联通了。两个心魔空间之间的界墙消失了。他看到了苏晚——她也正从她自己的心魔画面中走出来。她的脸上有泪水，但她在笑。她的心魔不是别人——是她自己。是那个在很多次的轮回中，因为灵魂残缺而不能活到终老的自己。她的心魔是一系列尚未成熟的"自己"，站在一排沉默地等待——等着这一世的她能完整地活下去。她对那些自己说了一句话："谢谢你们一直在等我。"

心魔散去。阶梯重新出现在脚下。

两个人站在原地喘了好一阵子。林牧的额头上全是冷汗。苏晚把他的头按在自己肩膀上。

"她说的是真的？"苏晚轻声问。她已经通过共振看到了林牧的心魔画面。"那个白衣女子——她推开你的时候——不是因为绝望。是因为她相信你会回来找她？"

"是的。"林牧的声音在她肩膀上显得有点闷。"因为她相信我。信了一万年。甚至更久。"

"那她现在等到了。"苏晚把他的头从肩膀上扶起来，看着他的眼睛。"你现在找到的——是完整的我。不再是碎片，不再是残影。我会和你在这一世完整地走下去。一直到时间的尽头。"

阶梯在他们脚下继续向上延伸。心魔试炼之后，阶梯的颜色变了——从半透明的白变成了一种温暖的淡金色。通道认可了他们。心魔已过。剩下的只是往上走。

（第四百六十四章 完）

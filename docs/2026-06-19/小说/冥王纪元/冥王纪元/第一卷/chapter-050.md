# 第050章 碎片中的记忆碎片：万古冥王的残影

李长生坐在出租屋的床上，手心摊开，两块黑色的碎片静静躺着。

古玩店一战后，他带着小王连夜换了住处。新租的房子在老城区一栋筒子楼的五楼，楼道里常年飘着油烟味，隔壁住着一对做夜市的夫妻。条件不怎么样，但胜在隐蔽。

此刻是凌晨三点。小王在隔壁房间睡着了，轻微的鼾声透过薄墙传过来。

李长生睡不着。

两块碎片在他掌心里发着暗光。自从古玩店那场战斗之后，他就隐约感觉到碎片之间有一种呼应——像两块磁铁，互相吸引，又互相排斥。每次把两块碎片靠近，掌心就会发热，脑海中会闪过一些模糊的画面。

他试过好几次，但那些画面太快、太碎，像打碎的镜子，什么都看不清。

今晚他决定认真试一次。

李长生把两块碎片按在一起。

掌心一烫。

不是火烧的烫，是某种从骨髓深处涌上来的灼热。那股热沿着手臂飙升到肩膀，然后直冲大脑。他眼前一黑，像被一只看不见的手猛地拽进了水里。

等视野重新亮起来的时候，他已经不在出租屋里了。

他站在虚空中。

脚下是无尽的黑暗，头顶也是无尽的黑暗。但远处有光——金色的、赤色的、青色的，各种颜色的光交织在一起，像烟花在宇宙深处炸开。

不，不是烟花。

那是法术。

李长生看清楚了。远处的光芒不是星辰，而是无数修士在战斗。剑光、刀芒、雷法、火焰，铺天盖地的法力波动让他隔着不知多远的距离都觉得窒息。

他低头一看——自己的双手是半透明的。他不是真的来到了这里，而是进入了某段记忆。

碎片的记忆。

视野忽然拉近了。

李长生看见一个人。

那人站在万里星空的中心，身披黑色重甲，甲胄上刻满了密密麻麻的古篆。那些字在发光，暗金色的光，像黄昏的太阳。他左手持一面令牌，令牌漆黑如墨，上面用血红的线条刻着一个字——李长生不认识那个字，但他一眼就懂了它的意思。

"冥"。

那人的面容模糊，看不清楚。但李长生能感觉到他的气势——那不是杀气，不是威压，而是一种更深沉的东西。像大地，像深渊，像死亡本身化为了人形。他站在星空中，脚下的星辰都在发抖。

他周围是无数的尸体。

修士的尸体。数以万计，漂浮在虚空中，像一片尸体组成的星河。每一具尸体上都残留着生前的气息——圣者、帝者、神级——随便拎出一个来都能碾碎现在的李长生。

但他们全死了。

被一个人杀的。

李长生看着那个黑甲男人，忽然感觉到了一种说不清的熟悉。不是视觉上的熟悉，是更底层的——像血液在共鸣，像骨头的记忆。

那个男人忽然转过头。

他看不清面容，但李长生知道，那个男人在看他。隔着一万年的时光，隔着一层记忆的薄纱，那个男人正看着他。

嘴唇动了。他说了一句话。

李长生听不见声音，但那个念头直接撞进了他的脑子里——

"后来人，你终于来了。"

世界炸开了。

无数画面像洪水一样冲入李长生的识海——一个婴儿在血月下诞生；一个少年在荒野中独自修行；一个年轻人在万人的尸骨上登顶王座；一个男人手持冥王令横扫星空，无数星辰在他手中化为齑粉——

然后是他被围杀的画面。

无数神级强者从四面八方同时出手。天空裂开了，大地崩碎了，数十个神明联手布下了一个覆盖半个星域的杀阵。那个黑甲男人站在阵眼中央，冥王令的光芒越来越暗，他的身体在碎裂，从手指开始一点点化为光点——

但他没有跪下。

一直到最后一刻，他都站着。身体碎成了九道黑色的光芒，射向宇宙各处。其中六道落在了地球，一道落在月球，一道落在火星，还有一道落入了无尽的宇宙深处。

画面到这里戛然而止。

李长生猛地睁开眼。

他发现自己趴在床上，浑身被汗浸透了。掌心还在发烫，两块碎片安静地躺在他手边，暗光已经熄灭了。

他在黑夜里大口喘气，胸膛剧烈起伏。

那个男人——冥王——死了。被数十个神明联手围杀，死无全尸。可他见过的画面里，那个男人至死都没有弯过膝盖。

李长生摸了摸自己的脸。凉的。

他当农民当了三十年，天不怕地不怕，可刚才那一幕让他心底发寒。不是因为恐惧，而是因为震撼。一个人要有多硬的骨头，才能在数十个神明的围杀下站着死？

更重要的是那句"后来人"——那个一万年前的人，好像在等他。

他为什么要等我？他知道我会来？

李长生在黑暗中坐了很久。

窗外的路灯透过窗帘的缝隙投进来，在地上印出一道细细的光条。他盯着那条光，脑子里翻来覆去转着一个问题：我是谁？

我只是李家庄一个种地的。父母早亡，没上过大学，连县城都没出过几次。我这辈子最大的事就是今年麦子卖了多少钱。怎么忽然之间就扯上了一万年前的冥王？

他低头看手心。掌心有一道浅浅的黑色纹路，那是获得第一块碎片后出现的，平时不仔细看看不出来。

现在那道纹路比昨天深了一点。

李长生攥紧了拳头。纹路被遮住了，但他知道它还在。就像他知道，有些事情从第一块碎片融入身体的那一刻起，就已经不可逆转了。

他站起身，走到窗边。撩开窗帘，看见凌晨四点的城市。路灯昏黄，街上没有行人，远处高架桥上偶尔有一辆车驶过。一切和往常一样安静。

但他知道，有些东西不一样了。

他回头看了一眼床头柜上的手机——屏幕没亮，一点信号都没有。自从天裂之后，手机越来越不对劲了。不是没信号，而是信号变成了别的东西。有时会突然收到短信乱码，有时半夜自己亮起来闪几下又黑掉。

小王说这是灵气干扰。灵气复苏之后，电磁波和灵气产生了某种耦合，普通的电子设备正变得越来越不可靠。

李长生不懂这些。他只是觉得，这个世界正在被一层看不见的东西渗透，像水渗进沙子。

他重新走回床边，拿起两块碎片。黑色的碎片在暗光下像两块凝固的墨。他闭上眼，运转体内那股微弱的气息——在古玩店融合两块碎片时残魂教他的入门吐纳法。

一道极淡的黑雾从碎片中溢出，钻进他的掌心。

脑海深处，残魂的声音响了起来，带着一种李长生从未听过的颤抖:

"小子，你刚才看到了什么？"

李长生沉默了一会儿，说："一个人。穿黑甲，拿令牌，站在星空中。周围全是尸体。"

残魂那边沉默了很久。

很久。

然后他说了一句话，声音沙哑得像一块碎掉的石头：

"那是我的主人。万古以来的第一尊冥王。"

李长生握着碎片的指节发了白。

"你从来没说过你还有主人。"

"因为说了也没用。"残魂的声音很低，"一万年了。我以为不会再有人能看到他的记忆。你看到了，说明碎片认可了你。"

""认可"是什么意思？"

残魂没有直接回答。他只是说："你打开的不只是记忆。你打开的是他的影子。从今往后，你会反复梦见那个画面。越来越清晰，越来越完整。直到你能承受全部的真相为止。"

李长生松开碎片，靠在了墙上。

他想起了那个男人说过的话。后来人，你终于来了。

那句话压在他胸口，像一块石头。

（第050章完）

# 第152章 实力大涨

金丹巅峰的林牧在这个世界上的武力排名，他自己没算过。也不需要算。

因为他不需要和任何人打。他已经三十年没跟同阶修士交过手了——上次动手是三十年前妖兽来袭那一次。三十年后当世修真界经历了快速膨胀——灵气复苏进入高速期，各宗门的资源竞争越来越激烈，新一代天才修士层出不穷，金丹修士的数量比三十年前多了至少五倍。

但金丹巅峰的——仍然是极少数。因为金丹巅峰的瓶颈不仅是功力——更是心境。绝大多数金丹中期修士卡在感情、执念、权力欲望、或者仇恨上过不去。心不通——金丹蜕不了皮。林牧做到了，因为他执念的"她"——已经在他的人生中成为了触发境界蜕变的催化剂，而不是障碍。这份独有的心境机缘，当世再无第二人拥有。

他每天的生活节奏依然不变。早七点半开门，烧第一壶水。上午十点，街对面对面的张家茶庄开门。中午一起采茶（如果老张叫）。下午下棋。傍晚关门。晚上打坐、看月亮、对锦鲤说话、睡觉。

青溪镇上的人不知道一个金丹巅峰级的修士每天在给他们烧水泡茶。有外地来买茶的客人喝完林牧烧的绿茶后惊叹说"这个茶有仙气"，林牧笑笑，说了句"水好、叶好、人好"。

他说的"人好"不是自己——是卖茶给他的张家。

这一年镇上来了一支修仙者访问团。不是特意来的——是恰巧路过。龙虎山的一队外门弟子在附近山区做除妖任务，听说青溪镇有优质灵茶，顺道来买。五名筑基期年青人在镇上逛，其中一人走到茶馆喝了一杯绿茶，然后定住。他回头盯着林牧看了一盏茶工夫。

这位筑基弟子——名叫石岩，师承龙虎山张道玄座下——在离开茶馆后跟同门说："那个烧茶的老板有问题。我看不透他的修为。师傅说过凡是你看不透修为但又感觉不到灵力锁定的人，要么是凡人要么是元婴——"

同门笑他："你看错了吧。那个人看起来就是个普通老头儿。而且他这家茶馆连禁制都没有——真正的修士就算隐居，也最少布置个防御阵法。这个茶馆连基础防护都没放。"

石岩没再坚持，但他把这件事汇报给了师傅。张道玄——三十年前那位与林牧并肩作战的金丹修士——在听到弟子描述茶馆地点后沉默了很久。他认识"青溪镇"这个地名。因为当年林牧在北境战后唯一说过一句话是——"帮我守一下东南方向大约二百三十里处——那个小镇子"。

张道玄没来找林牧。他知道林牧不想被找。但他在宗门的内门会议上提了一句话:"当世最强散修之一，现在在南方一个镇子上给一群采茶人烧水。他不是隐士——他在做自己选择的事。你们所有人遇到他只需记住一点：不要惹他烧水用的那套茶具。"

石岩不懂师傅为什么专门提及"茶具"。张道玄没解释。他知道那个茶壶——那是苏晚第一世喝茶用过的杯盏残片被林牧用灵火重铸成的。动了那个茶壶的人——等于动了林牧守了万年的东西。

在青溪镇内，一切如常。这一年冬天来得格外早。

十一月底下了一场大雪。南方小镇难得见雪，这场雪的厚度破了纪录——积到近两尺深，压塌了镇上几间老旧棚屋，也包括张记茶庄后院那个存茶叶的小仓库。

老张急得嘴唇都起了泡。春茶的存货还在仓库里——虽然不值多少钱，但那是他们一年的辛苦。林牧在雪停的第二天出现在后院。他看了看被压塌的屋顶，说"修得回来"。老张说要等雪化了再修，怕不安全，林牧说不用等。

他让老张在门口站着"看着外面的客人"，自己走进去。仓库里塌了一角，梁上斜下来，茶叶布袋散了一地。他站了大概一柱香的时间——足够用金丹灵力把整个屋顶的结构重新对接好，并把里面的每一块木梁都加固到了能抗十级地震的程度。整个修复过程他连一根手指都没动——完全是灵念在操控。他从仓库出来时，房顶已经完整如初。老张以为他只是在里面检查了一下破损情况——"明天我找两个人来修一下"，林牧说已经修好了。

老张死活不信，进仓库一看——房顶不仅是好的，还比以前更坚固了。连接处多出一层暗绿色的木质硬化——那是灵力质变后的余迹，别人看不出来是法术产物，只以为是老木材的某种自然结壳。老张激动得直拉着林牧的手非要请他吃饭。林牧说今天不行——老猫的感冒还没好——改天。

他把手从老张手里抽出来。这个动作很快，因为老张的手掌心都是人间的体温。他不适合长时间接受这种温暖——温柔太多会让他松懈，松懈了之后晚上回去又会难捱。

他从张家出来时，在巷口遇到了林秀芝。她刚从镇上的小超市回来，左手提着一小袋糯米，右手抱着一条围巾——给他买的。她看到了他，把围巾递过去。

"老张说你感冒没好——多穿点。这条围巾不贵，就路边摊买的。你那条都磨出洞了——"

林牧接过围巾，低头看了看。灰色的围巾，料子是普通毛线，针脚略有点粗——是镇上那个七十多岁的老太太织的。这种围巾不能保暖给他这种人——金丹修士不需要保暖。但他接过来时，心里某处还是被焐了一下。

"谢谢。"

"不用谢。你不收我都会觉得过意不去——你帮了我们太多忙了。"她说完脸上客气地笑了笑。

他点了点头。她把糯米换到怀里换一个姿势，对他说"天冷了多喝热水——别老喝冷茶"。这句是邻居间最随嘴的关心。他听着，笑着说了声好。

然后他回到家，把围巾整整齐齐叠好放在枕头边。晚上睡觉时，他把手搭在围巾上——不是为了暖，是为了能感受到一点点某种气息。那条围巾有她的指尖的温度——她买完糯米后重新整理围巾时手曾在那上面多按了一几秒。

这个细节他不知道。但她知道。她在摊上挑围巾时犹豫了很久——要不要送？送太贵了不合适，太便宜了过意不去。最后挑了这条中档的。送的时候她手心出了汗——虽然是深冬。她自己也说不出来为什么送个围巾会手心出汗，就像她也说不出来为什么在每次过年过节送他礼物后回家都要一个人在堂屋里多坐一会儿，让心跳平复。

两个人都在互相保持距离。两个人都在距离里继续互相靠近。两个人的靠近方式是——他修她家的屋顶，她给他买围巾。两个人的距离方式是——他帮她修完屋顶之后就走，她送完围巾之后只会说一句"不用谢"。

这种关系在青溪镇的街坊邻里中显得普通。但在历史纵深里——放在他守护她百余世的齿轮里——这一世是最特别的。因为这一世他的上限是"做到最好但不能越过"。三十年来他成为了当世最强者之一，但依然住在青溪镇的小茶馆里。他不需要更大的世界——这个小世界里有她就够了。

年末。林牧自己在茶馆二楼的房顶上加了灵阵。这个灵阵的作用不是防御——是调节温度。他怕盛夏时茶壶里的鱼缸过热（锦鲤虽然能适应灵脉温度变化但偏好微凉环境）。他怕冬天时房子漏水——这间房子不是他的，是租的。他只是在这里住，不拥有它。三十年来他甚至没和房东谈过买下这间茶馆的念头。因为他知道自己最终会离开。等她的这一世结束后——他要去找下一世。他不能买一个永久性资产，会在心里形成多余的留恋。

他不需要多余的留恋。他给自己核定的心情感载量已经全部划给了那一个人——没有空间拿来囤其他的东西。

除夕夜。全镇都在放鞭炮，林牧坐在二楼窗前看烟花。烟花一朵朵地从远处的山头炸开来。红、绿、金三种花色轮流照亮了青溪镇的每一块青石板。

街对面的张记茶庄也在放。小辉从省城回来了——带着妻子和一个三岁的孩子。她抱着孙子在门口看烟花，脸上绽着满足的笑容。她抬起头时看到对面二楼窗口站着的人影——隔着夜空的烟花照亮这两张脸。

他微微抬了下手——一个"过年好"的手势。她抱着孙子向那边也挥了下手。然后烟花灭了。两人又各自回到各自的空间。

除夕。他独自一人喝了半壶黄酒。没喝醉——金丹修士喝不醉，除非自己放任。但今天过年。他放任了一点点——放任自己在酒意中回忆前世的除夕。前世的苏晚会给青云宗的年夜饭夹他碗里所有她不吃的菜，然后笑说"你替我吃——吃了我就算尝过"。

前世的她不知道，过了那一世后，他将在之后无数个除夕自己一个人坐在不同的角落，吃年夜饭时对自己说——"这个菜是替她尝的。这个也是。还有一个。"

酒没了。他倒了一满杯水，对着窗外的烟花举杯。杯沿碰不到任何人的杯边。但他还是以最正式的姿势举了一下。

然后喝完。睡觉。明天是大年初一。初二他要带着不变的礼物去张家拜年。她会笑着接过茶具，说"太客气了——下次空手来"。他会说"好"。然后那一年过去。再然后那一年多的下一年。

这就叫相敬如宾。三十余年如一日。被街道分成两份的生命静水流深。

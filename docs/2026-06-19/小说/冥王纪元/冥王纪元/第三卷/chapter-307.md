# 第307章 国际势力对火星基地虎视眈眈

火星基地的建立消息是在祝融号升空后的第十九天被国际社会确认的。

消息走漏的源头不是中国——是西方太空联盟（WSA）在火星轨道上的一颗探测卫星。那颗卫星的主要任务是拍摄火星表面的高分辨率照片，用来给WSA的科学家研究火星地质。它在一次例行飞越时拍到了离宫外围的图像——一个在火星荒原上忽然出现的长方形人类建筑群，占地超过二十万平方米，而且有明显的热辐射。数据被迅速上传到WSA位于休斯顿的分析中心。分析中心的负责人用了整整十分钟确认这不是传感器故障——火星表面确实出现了一个非自然形成的大型建筑。而它所在的位置——是此前被公认为"火星最具科学价值无人区"的核心区域。

紧接着的二十四小时内，国际局势像被按下了快进键一样开始加速运转。

首先是WSA的紧急声明。"中国在火星表面进行未经申报的大规模建设工程，严重违反《外层空间条约》和《月球协定》关于'外层空间应和平利用、避免领土主权冲突'的基本原则。WSA要求中方立即公开火星基地的全部信息，包括但不限于：基地的建设目的、技术来源、驻留人员数量、以及是否具备军用功能。"

声明发出后的两小时内，中方的回应抵达了联合国——措辞客气但态度强硬。"中国在火星的活动属于科学研究和资源开发范畴。中方尊重国际法，但《外层空间条约》并未禁止签约国在外层空间进行科技探索和基础设施建设。中方愿在适当时间向国际社会通报相关科学发现，但绝不接受任何外部势力对中国火星基地的无理干预。"

外长在记者会上补充了一句:"西方太空联盟有一个问题需要自己回答:他们在没有通知中国的情况下，在火星轨道上部署了一颗探测卫星，用于拍摄中方基地的高分辨率照片。这种行为——在国际法上属于什么性质？"

外交交锋的用词越来越密集，真正让中方警觉的，不是外交措辞——而是外围的实际行动。

第二天，一封由俄罗斯联邦航天局通过非正式渠道转到中国国家航天局的信件措辞非常"俄式"。公文标题是《关于俄中共同开发火星资源的建议》。内容大意:俄罗斯拥有丰富的极地灵脉开发经验——西伯利亚冻土带下已发现至少三类可开采的高密度灵石矿脉。俄方建议将西伯利亚灵石开采技术与中方的灵石飞船推进技术进行"整合"，由两国共同组建"火星开发联合体"，共同承担火星基地的建设与运行成本。基地由双方共同管理，资源产出按投入比例分配。

这封信没有公开——是通过"非正式渠道"发的。但它的含义很明确:俄罗斯不是在请求——俄罗斯是在提议共享。背后的逻辑也很简单:俄罗斯没有自己的灵石飞船技术，短期内造不出能在两个月内飞到火星的载人飞行器。但他们有大量灵脉资源——西伯利亚地下冻土层中埋藏着地球上最高密度的灵石矿藏。他们用灵脉资源来换火星基地的共管权——这是一笔生意。

中方没有立刻回绝，但也没有接受。回复很简短:"感谢俄方关注，中方将认真考虑合作事宜，具体方案待后续磋商。"这是外交辞令——真正的意思是"我们不做决定，但我们不关门"。这给了俄方足够多的面子，同时还保留了回旋余地。

但第三天的消息让中方不能继续保留余地了。

日本神道修行者联合会——一个在灵气复苏后由日本多家神社联合组建的修士团体——通过他们在东南亚的商业网络发布了意向声明：邀请国际合作组建一支"火星科学调查团"。声明中特别强调:"调查团不以任何军事目的为目的——其使命是对火星上可能存在的古文明遗迹进行科学研究。我们相信火星上的古文明遗迹不属于任何一国——它们是全人类的共同文化遗产。"声明的正文后面附了一份"已确认参与方"名单——日本神道联合会（发起方）、韩国天道修士协会（确认参与）、印度梵修研究会（确认参与）、巴西灵修联盟（确认参与）、澳大利亚大地修士团（确认参与）。

六个国家的修士团体。全是非政府组织——不是官方——但参与的修士人数加起来约一百人。这个数字摆出来，就是一组"非官方但不非正式"的标准多方联合调查编制。日本神道修士的这番操作很聪明——他们没用政府名义，而是用了所谓"国际非政府学术团体"的名义。这样一方面避免了直接和中国政府对抗，另一方面又保留了派出修士团队硬闯离宫的筹码。

日本神道修士有一个其他人不知道的优势:日本在灵气复苏后发现了一批具有罕见"空灵根"的修士——这种灵根对空间传送有特殊感知力。他们一直在秘密训练空灵根修士如何破解跨维度屏障。而离宫外围屏障恰恰是一种空间屏蔽技术。这意味着日本神道修士在技术上是有可能找到离宫入口的——他们只是不知道入口后面有什么。但一旦他们进入——火星基地的存在就彻底瞒不住了。更麻烦的是——一旦不同国家的修士进入离宫，外交问题就会升级为修仙军事对峙。这在地球上已经多次发生——各国修士在灵气复苏初期互相在各个灵脉节点上发生过数十起冲突。现在冲突战场从地球扩展到火星——而火星上没有任何现成的国际规则可依。

李长生接到龙组密报时正在离宫的核心修炼室里。这份密报不长——但信息密度很高。

"李长生。近三日情报综合:1. 西方太空联盟已在火星轨道加强了灵能观测卫星的部署，可能尝试对离宫进行能量扫描分析。2. 俄罗斯通过正式渠道提出'共同开发'方案——我方判断为临时拖延型外交。3. 日本神道修士联合会正在组织一个由六国组成的'科研调查团'，计划在一个月内向火星非法派遣。情报源确认日方已着手在鹿儿岛秘密改装一艘可搭载修士的灵石飞船——首次潜入尝试预计在一个月内。"

李长生看完了信报，沉默了三秒。然后他说了一句话:"他们想来——让他们来。"

陈霜在旁边挑了挑眉，没说话。她的手指在剑柄上敲了一下——意思是"说下去"。

"离宫的外围屏障不是靠找就能突破的。守殿人已经将屏障的维度变形算法从之前的'被动随机变化'升级为'主动诱捕模式'。如果日本调查团的飞船尝试进入屏障——他们会发现自己在距离离宫至少几百公里的地方反复打转，燃料耗尽后只能发出求救信号。"李长生平静地说，"这不是威胁。这是让他们知难而退。"

"如果他们不放弃呢？"

"那就让他们飞到入口——然后看到入口两边各站着一百台战傀。每台战傀的水晶眼全功率亮着——不发动攻击，就站在那里。站着就够了。"

刀疤在旁边插了一句:"军事上这叫'力量展示'。不费一枪一弹——就让对方自己掂量轻重。"

"而如果俄罗斯想要合作——"李长生站起身，走向墙壁上的星图，"让他们用灵脉资源来换。不是换共管权——是换灵石飞船的技术授权。我们给他们飞船图纸——他们用灵石矿脉来交换。中国的工厂帮他们造飞船——同时中国的技术团队就能进入西伯利亚灵脉进行实地勘测。这是一笔公平交易。"

"如果他们不答应技术授权方案，坚持要共管呢？"

"不答应？"李长生回头，眼底有一丝微光，语气平静但每个字都沉甸甸的，"那他们连火星都到不了。"

(第307章完)

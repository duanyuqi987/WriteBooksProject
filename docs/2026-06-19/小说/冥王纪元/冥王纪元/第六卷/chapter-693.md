# 第693章 诸天来贺

加冕仪式的第二天，才是真正的高潮。

此前李长生发布了一条简短的宇宙公告——通过太初留给他的维度广播能力，将信息传至新纪元宇宙中所有已诞生的、具有一定文明程度的星域。公告内容简单："新都冥都，对外开埠。凡欲通好者，自行取道。"

这并非傲慢——这是尊重。他不要求任何文明必须来。来的才算真正的朋友；不来的，帝国不记仇。

结果超出预期。

自从新地球上的智慧生命进化到能接收维度广播的阶段之后，新纪元正在慢慢热闹起来。宇宙各处出现的文明远不止人类一个。太空之中，形状各异的飞船正在朝冥都汇聚。

第一个到达的是一支全女性代表团——"青鸾族"。她们的母星是全液态的，居民体态如人类却长着一对淡蓝色的羽翼。青鸾族的使者带来了一件礼物：一颗由她们母星最纯净的海水凝结而成的"永明珠"——珠子在手心能发出永不变暗的光亮。使者说："我们听闻新纪元守护者的事迹。青鸾族愿与冥王帝国通好，不求庇佑，只求互识。"

李长生收下了永明珠，回赠了从旧纪元纪念馆中提取的一段文明记忆——不是新技术，不是武器，而是一位旧纪元已灭绝文明中普通农妇烧制陶器的全息影像。他对青鸾使者说："这是我们旧纪元的遗产。送给你——不是送你陶器的技术，是送你一颗人心。"

青鸾使者的羽翼颤抖了一下。她明白了。

接着到达的是"恒星裔"——一群诞生在恒星中的等离子生命体。他们的形象在常人看来只是一团明亮的光。恒星裔代表以纯等离子形态站在广场上，周围温度高达数千度，但冥都的灵气场自动把温度隔开，防止烫伤旁人。恒星裔使者发出声音时，是通过调整等离子密度产生声波，声音低沉如远雷："恒星裔为李长生的混沌之力而来——不为求取，只为致敬。你能够容纳混沌而不崩溃、驾驭死亡而保持理性——在恒星裔的认知中，你已达到永生的最高境界。"

李长生回赠了一个由小型黑洞压缩而成的镜像饰品——用来反射恒星裔自身的辐射光谱，让他们第一次能"看到自己的颜色"。恒星裔大乐。

接下来到达的是三支人类文明——"赤星联邦"、"古道遗民"、"新天盟"。赤星联邦是军事立国的科技文明，古道遗民是刻意保留原始农耕方式的精神文明，新天盟是修仙与科技双线发展的综合文明。这三支人类文明在旧纪元时期就是地球人类的直系后裔或旁系——如今在新纪元重聚，关系微妙但总体向好。

上百个文明的代表在冥都中心广场齐聚。广场容纳几十万人不成问题，但上百个外形完全不兼容的物种挤在一起，气温、气压、大气成分、重力范围——都是极其复杂的工程问题。好在帝都的灵气调节系统完美应对了这一切。

最高潮的时刻出现在当日黄昏。一道传送维度裂开，从中走出来的是一群"类神族"——修士修为全部达到帝级以上的新纪元原始种族。他们单膝跪地，为首者开口时声音如洪钟："太初之下的守护者，受吾族一拜。非拜皇权，拜你为旧纪元众生所立的纪念馆。你的仁心感动了吾族——愿以冥王之名宣誓，永不对人类用兵。"

李长生上前，把为首者扶了起来。

广场上，新纪元的第一缕夕阳落在众人身上。诸天的见证无声地融入了历史。

（第693章完）

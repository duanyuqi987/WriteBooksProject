# 第七百零六章 林牧的第一次探索

苏晚在地面推动修人共治的同时，林牧在上界进行了第一次深度探索。他的目标不是直接冲撞上界大门——而是测绘上界大门前折叠空间的精确结构，为将来正式开门的路径提供数据。他带了三个人——秦无夜负责后勤保障，杜散修负责数据记录，还有一位年轻的魔修女测绘师负责空间阵列的实时标注。

上界的折叠空间不像迷宫——更像是一本折叠起来的书，页与页之间存在看不见的接缝。如果你从正确的接缝中穿过去，距离只有几里；如果你不小心踩偏——你会在折叠层中反复循环，走上一整天而后发现回到了起点。林牧在前锋位置，用他前世在上界行走的经验来辨识哪些空隙是"活缝"——会随时间自行调整的临时通道——哪些是"死缝"，进去了就会陷在时间循环里浪费灵力。他的辨识准确率大约为七成。另外三成是他前世时没有遇到过的新结构——说明上界在被下界包容信号长期影响后正在自我重组。

秦无夜在后方搭建了临时补给站——一口小铁锅，一盏便携灯火，两壶魔气酥油茶。杜散修的女儿设计了一套"灶台计数"实时通讯系统——每十五分钟自动通过灵网向灯火塔回报测绘进度，同时确保探索队伍始终在灯火塔的安全通讯范围内。

第一天探索接近尾声时，测绘师发现了一组从未见过的空间结构——在折叠层的最边缘，有一块面积很小但能量波动极其稳定的"空腔"。这块区域没有任何折叠——它是完全平坦的。林牧停下来——他把手伸进那块空腔中感知它的空间属性。他的手指尖触到了某种极淡但极其古老的痕迹——不是灵气，不是魔气，也不是阵法残余。是记忆。

他的神识在那一瞬间被拉入了一个极短的画面——桂花树。一棵极其古老、比地面那棵老得多的桂花树的影像。树下站着两个隐约的身影——一个青衫一个白衣。不是他前世记忆的碎片——是那棵树的记忆。百世情缘契约的原作者——那两个真仙——曾在树下站过。记忆不是他的，是树的。那棵老桂花树的根部深植于下界土壤——树冠探到了上界的折叠空间。

林牧收回手。他的手指在回暖——但他心里的震感还在。他回头对秦无夜说："标记这里——'第一树冠点'。然后记录：桂花树——不是种在地面的——最初是种在上界。地面那棵是它的分支。"

（第七百零六章 完）

# 第三百九十七章 故地再游

飞升第十五年。两人再次回到凡界——不是回访，是深入探访。这次他们从昆仑到东海，把当年自己在天魔战争中最艰难的那些节点重新走了一遍。林牧发现第一棵灵松已长得直入云霄——松针丰密如云，树下有凡人在野餐。那棵松已经成了附近村庄的"神树"——没人知道是谁种的，但每年秋天树下有感谢土地公的村民。

苏晚的第一代自净阵阵基之前被她带回为纪念品，但它的位置现在立着一块石碑——上面刻着:"此处曾是自净阵奠基之地——清泉医剑。"她站在碑前，对锦鲤说:"你的泡水还记得这坑吗？"

锦鲤吐了个极响的泡。啵。

然后他们走进清泉镇——镇上的街道比从前宁静，老铺子都换了新人，但茶馆还在。茶馆老板娘已很老，看到苏晚进来，仍端出两碗绿豆汤——说:"苏大夫，这碗没放太甜。"

苏晚喝完汤后在病历纸上写了"最后一次查诊结束，建议长期维持现有方案"。她将这纸折好放进茶楼靠窗那把椅子背面的小木盒——椅背上"林"字已磨得极浅，但她认得。林牧把战士杯和医者杯最后一次放在清泉镇茶楼的桌上——然后他让它们留在那里。由新来的小镇医生用作公杯。

# 第413章 一个个帝国向冥王臣服——势如破竹

冰墙在诸天号前方横贯了数十万公里的虚空。李长生没有急着破墙。他用了三天时间处理冰封帝国之外的事务——六个远道而来的帝国使者在舰桥外交接厅排着队等觐见，西部星域南部七个独立星球的联合代表团发来了无条件归附的文书。

而这些都不是最紧迫的。

最紧迫的，是光耀帝国的使者。光帝派来了一位圣者级别的使者，带来了一个口信。口信很短："冥王留不得。"

使者宣读这句话的时候，舰桥上的气氛骤然冷了下来。陈霜的手指已经搭在了剑柄上，刀疤的体纹从手臂蔓延到了肩膀，小王的笔记本电脑屏幕上自动弹出了三套紧急防御方案。

李长生抬手制止了所有人，然后问使者："你们帝者打算什么时候和我打？"

使者的回答很有意思。他说："光帝陛下不会主动开战。但也不会臣服。等到冥王殿下的疆域边界触及光耀帝国的国境线，两帝国之间的战争将由宇宙的规则自行决定。"

"宇宙的规则？"

"光与暗，永不相容。"

使者走后，小王翻遍了守殿人AI和冥王碎片中的所有历史数据，找到了光系帝者与冥系修士之间的宿怨根源。不是私人仇恨——是能量属性的结构性冲突。光系灵力与冥系灵力在宇宙的底层能量结构中处于同一条谱带的两端。这两种能量无法共存于同一空间——当它们接触时，会相互湮灭并释放出远超各自单独能量总和的爆炸性冲击。万年前，冥王与光系帝者之间有过七次战争，每一次都以某一方被逼退到星域边缘而告终。但战争从未彻底解决——因为光冥相克是天生的，无法调和。

"也就是说，光帝不可能臣服。"老陈总结道。

"不可能。"小王确认。

"风帝呢？"

"风帝更麻烦。"小王调出风岚帝国的资料。风岚帝国位于西部星域最深处，被一片横跨二十光年的时空风暴带包围。所有接近风岚帝国的舰队都必须在风暴带的缝隙中找到航线——而这些缝隙是动态的，每时每刻都在变化。没有风帝本人的许可，外来舰队根本不可能穿越那道风暴屏障。

换句话说，风岚帝国是宇宙西部唯一一个从不需要担心外部入侵的帝国。它的天然屏障让它闭关锁国长达四千年。四千年来风帝没有出过一次手——没有任何人知道他现在实力到了什么水平。

许冰把目前的情况整理成了一张简表。表上有三栏：已有把握臣服的；可以谈的；多半要打的。

第一栏有十六个名字。第二栏有四个。第三栏有三个：冰帝、风帝、光帝。

"顺序呢？"刀疤问。

"冰帝最急。"李长生说，"冰封帝国横在西部星域中央。收不下冰帝，我们的补给线绕不过这片星域，后面的十七个归附帝国也没法纳入星门体系。"

"那就先打冰帝。"

"不。"李长生收回手，"先聊。聊不下来再打。"

诸天号在冰墙前方停泊的第三天，冰帝回应了。冰封帝国派来了一位使者——不是人族，是一尊冰晶制成的傀儡，高三米，身体由数千片六角冰晶拼接而成，能在虚空中无声移动。傀儡带来了冰帝的话："你想说什么？"

李长生一个人走进了冰墙。

他穿过那堵横贯数十万公里的冰壁时，体验到的不是寒冷。是另一种东西——一种纯粹的、不容置疑的意志。冰墙不是结界，不是防御工事。它是冰帝本人的意志具象化。每一寸冰晶里都弥漫着一种宣告：这是我的领域。陌生人，不要踏入。

他在冰墙内部走了大约十分钟。十分钟后，他站到了冰帝面前。

冰帝坐在一座冰晶宫殿的正殿中央。那座宫殿悬在一颗被完全冰封的恒星上方——恒星的内核仍在燃烧，但它的外层已经被万年冰气覆盖，形成了一个直径上百万公里的冰火球体。宫殿就悬浮在这个巨大冰球的极点上方，安静而肃穆。

冰帝的外貌像一个四十岁左右的人族男性，但李长生知道他已经活了至少七千年。他的皮肤呈现出透明的淡蓝色，可以看到皮肤下流淌的冰蓝色灵血。他的眼睛是那种极地冰川深处的蓝色——不是天空蓝，不是海蓝，是冰蓝。一种看了就让人从骨头里感到寒冷的蓝。

"你进了我的领域。"冰帝开口。他的声音和他的眼睛一样冷。

"我来了西部。"李长生说，"二十三个帝国，二十个已经归附。你不归附，补给线路会被逼出一个大圈，绕开你的地盘。那个大圈会把征服进程拖慢至少两个月。所以我来了。"

冰帝看着他，蓝色的眼睛里没有愤怒，没有恐惧，也没有敌意。只有一种冷淡的好奇——像一个在极地冰原上待了太久的人，对突然来访的客人产生的那种淡漠的好奇。

"你凭什么认为我会臣服？"

"我不认为。"李长生说，"所以我来问了。"

冰帝沉默了一会儿。然后他说了一句李长生没想到的话。"你和我见过的所有征服者都不一样。他们来的时候，带的不是舰队就是神兵。你是一个人来的。这意味着——要么你傻，要么你手里有什么东西让你不怕我。"

李长生摊开掌心。冥王令浮现。九块碎片合一的印章在冰晶宫殿的冷光中泛着暗金色，四周的冰壁在那光芒下出现了细微的裂纹。

"冥王令。"冰帝认出来了。他的表情没有变化，但手指在冰座上轻轻敲了一下。"完整的。"

"完整的。"

"所以你是冥王的继承者。"

"是。"

冰帝站了起来。他站在冰宫正殿的中央，身后是那颗被封在万年冰层下的恒星，恒星的火焰穿透冰层投出暗红色的光芒，在他的背上映出了一道若隐若现的轮廓。光与冰交织在一起，在他身上形成了一种奇特的视觉效果——像是极夜里出现了日晕。

"冥王陨落的时候，我还没有出生。"冰帝说，"但我先祖的先祖的师门——冰渊宫——是冥王座下七十二殿之一。你的冥王令上应该还残存着冰渊宫的师门灵印。你可以试着激活它。"

李长生按冰帝说的做了。他将冥气注入冥王令的一处特定位置——第六和第七道冥纹的交汇点。一道微弱的冷光从印章上浮现，在空气中凝聚成了一枚六角冰晶形状的符印。符印在空中转了七圈，然后飞向冰帝。

冰帝接住了它。他把那枚符印放在掌心，低头看了很久。冰晶宫殿里安静得像一座坟墓。只有远处那颗被冰封的恒星发出的低沉的轰鸣，从冰层下方闷闷地传来。

"这枚符印——是我师门的门主印。"冰帝的声音首次出现了一丝波动——不是情绪，是某种古老认可被触发时的规则反应。"万年前冰渊宫曾对冥王宣誓效忠。这道誓约嵌在门主印里，代代相传。即使冰渊宫已经覆灭万年，即使冥王已经陨落万年——印在，誓约在。"

他把门主印按在自己胸口。符印融进了他的冰系血脉，在透明的皮肤下形成了一道永久性的六角刻痕。

然后冰帝做了一件出乎李长生预料的事——他单膝跪下了。帝者对帝者，本无高低之分。但此刻情况不同：不是李长生的冥王印压制了冰帝，而是冰帝自己宗门万年前的一道誓约——一道他从未见过但其力量传承了五千代的古老誓约——让他主动跪了下来。

"冰封帝国，"冰帝说，"归附冥王。"

李长生伸手把冰帝扶了起来。"不是君臣。是同盟。"

"怎么叫不重要。结果是一样的。"冰帝看着胸前亮起的门主印，叹了口气，"用了七千年来躲战争、躲联盟、躲宇宙里所有的人是是非非。结果被一万年前的一道誓约拉了回来。造化弄人。"

李长生没有接话。他环顾着这座悬在冰封恒星上方的宫殿，问了一个不相关的问题："那颗恒星的火焰——在冰层下面烧了多久？"

"何止多久。从我来到这颗星球之前它就在烧。将来我走了它还会继续烧。"冰帝说，"恒星的寿命比帝者长。"

"那你为什么把宫殿建在上面？"

冰帝沉默了一瞬，然后说："提醒自己。不管多强——终究不是永恒。"

李长生记住了这句话。他后来在很多场战斗中都会想起这句话——在冰帝已经不再是敌人、已经成为了他在西部的第一道屏障之后。

当天晚上，冰墙收缩了。

那堵横贯数十万公里的冰壁从虚空中收回，折叠、压缩、最后化为一道细微的冰蓝色光束收入冰帝掌心。诸天号的航路由此畅通，补给线不再需要绕行。接下来七个帝国的归附进程加速了一倍。

两天后，罗天帝国的帝者献上了一幅完整的西部星图。图上标注了尚未归附的帝国位置和兵力部署。四天后，紫电帝国的帝者在诸天号舰桥上签下了正式归附文书——这个文书后来被小王视作冥王帝国法理体系的起点，它的条款和措辞成为后来数百个星系归附协议的模板。

六天后，十六个剩余帝国中的十一个完成了归附手续。整个西部星域的百分之六十五已经纳入冥王版图。每收服一个帝国，小王就将星图上对应区域的标注从红色改为蓝色。到第十二天时，舰桥主屏幕上的西部星图已经绝大部分变成了蓝色，只有两片区域仍然是刺目的红色。

西部最深处——风岚帝国。宇宙西部唯一有天然屏障的帝国。帝者实力未知，态度未知。

西部最边缘——光耀帝国。光帝的领地。一万年的宿敌。

还有几个零星散落在两片区域之间的小型独立星系——它们不构成阻力，只是还没有被纳入体系。

舰桥上，老陈看着这张近乎全蓝的星图，开玩笑地说："送快递能有这效率就好了。三十七个帝国三个星期送完——"

"不送完。"李长生纠正他，"不是送。是收。西部还剩下三分之一。风帝和光帝不归附——征服西部就不算完成。"

他看向星图上那两颗最刺目的红点。风岚帝国和光耀帝国——一个闭关四千年，一个与他能量相克一万年。征服他们，将不是外交，不是誓约，不是道理。将是纯粹的、没有退路的战斗。

而这两场战斗的结局——会决定西部诸帝国对冥王的臣服，究竟是短暂的利益交换，还是真正牢不可破的统一。

诸天号的冥纹阵列在黑暗中无声地脉动着。船壳上那十二组序列的运行功耗已经推到了正常巡航状态的百分之一百五十——为即将到来的战斗提前预热。

（第413章完）

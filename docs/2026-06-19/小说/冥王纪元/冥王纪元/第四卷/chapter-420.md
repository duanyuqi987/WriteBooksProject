# 第420章 剩余三成，组成反冥王联盟——最后的抵抗

西部边缘的星域没有名字。

宇宙西部的文明把这最后的、未划入任何一个帝国版图的缓冲星域称为"边荒"——不是荒芜的荒，是荒废的荒。这片星域里的星球密度约为西部平均水平的七分之一，恒星偏矮偏冷，行星贫瘠缺水，灵脉干涸到几乎无法支撑宗师以上修士的修炼。没人愿意殖民边荒——二十三个帝国宁愿在疆域重叠区打得头破血流，也不愿意往边荒方向扩张。

但别荒有一个优点。它和东部星域之间有四条天然的空间裂隙通道——比星门快，比空间折叠省能，是宇宙东、西区之间最主要的战略通道。谁控制了边荒，谁就控制了东西方的交通要道。

此刻，边荒深处，一颗代号为"岩七"的矮行星上，反冥王联盟的总部正热火朝天。

这不是一座宫殿——是一处临时搭建的军事基地。基地的主体结构由十二艘退役帝者级母舰的残骸拼接而成，焊接点密密麻麻，连接处使用的灵胶是临走前从苍明帝国军火库里紧急调配的。整座基地漂浮在岩七行星的低轨道上，外表看像一堆被人扔在太空里的废铁。但废铁内部有超过一百名圣者、八千名宗师和两万四千名灵者正在日夜备战。

联盟的首领叫炎烈——一个火系帝者。他曾经是宇宙西部一个中等帝国的帝者。当帝国的权力结构被冥王归附浪潮冲垮时，炎烈拒绝接受归附条件中的一条——交出全部战略级火系灵石矿的经营权予冥王帝国统一调度。他认为这是霸王条款。更准确地说，他认为交出矿权等于交出帝国的独立——即使冥王同意保留自治和军队，没有经济命脉就没有真正的自主。

炎烈带着他的帝者们走上了流亡之路。三个月内，陆陆续续有十六个和他持相同看法的帝者——多来自中、小型势力，在归附浪潮中丧失了核心利益——加入了炎烈的流亡阵营。他们进入边荒，建立了这座军事基地，并将一支又一支的反冥王力量收拢到自己旗下。目前联盟中最强的战将有三位——三位都是选择流亡而非归附的帝者。

第一位是炎烈本人。火系帝者，八千四百年寿元，以战力凶悍著称。归附谈判时拒绝交出控制下的十七条火系灵脉。

第二位是骨帝——鬼道帝者。一万零三百岁，已近暮年。归附谈判时向李长生要求保留原帝国中鬼道修士享有的一切旧特权，被许冰以"法律面前灵根系一律平等"为由直接驳回。

第三位是隐帝——空间系帝者。寿命不详，来源不详。不参与日常指挥，不加入任何战斗序列，不出席任何会议。他只是待在基地最深层的密室里，闭目等待。没有人知道他为什么加入联盟——有一个说法是：他欠炎烈一条命，现在来还。

至于普通战力——整个反冥王联盟目前有圣者九十四人，宗师四千人以上，灵者约三万人。战舰八千艘——其中帝者级母舰八艘。这支部队在西部统一之前是一个相当可观的势力——在西部二十三个帝国中的地位大约在中等偏上。但现在西部已经统一，三万艘战舰、三百七十二位圣者、十九位帝者归于冥王旗下。相比之下，反冥王联盟的军力只有冥王军的约四分之一。

但联盟有一个冥王军没有的优势：外部支援。

苍明帝者的军事顾问团在十二天前抵达了岩七基地。顾问团由三名圣者和二十二名宗师组成。他们带来了一套完整的空间防御阵法系统——苍明帝国用了三千年时间在自己国土上研发和测试过的阵图。将这套阵图部署在岩七星系周边，可以在二十四个小时内构建一道横跨一百个天文单位的空间屏障。空间系阵法不是攻击性的——它的核心功能是偏折所有通过屏障的能量攻击，像一面镜子把打过来的光束转向另一个方向。除非攻击方找到偏折矩阵的运算中心并将其摧毁——否则所有远程攻击全都会偏离目标。这套阵法的攻击力为零，但拖延能力是顶级的。

天枢帝者也派人来了。她派来的不是战斗人员，是阵术师——三个小队的阵术师携带了大量阵旗和阵盘，在边荒星域中嵌入了至少四百个微型空间陷阱。每个陷阱不大——撞上它的一艘中型战舰会被空间裂缝拦腰切开。这些微型陷阱分布在边荒主要航线附近——尤其是那四条东西天然空间裂隙的出口。目的很明确：阻止诸天号靠近裂隙，为东部主力舰队后续通过裂隙打开通道争取时间。

九幽帝者派来的援助最特殊。她送来了一批亡灵战舰——不是活人驾驶的战舰，而是以鬼道炼器术将亡灵附灵于舰体并自动控制的战舰。亡灵战舰不需要补给、不需要休息、不需要撤退。它们的唯一指令是接近目标然后自爆。自杀式亡灵战舰的数量不多——只有六十艘——但它们的自爆当量相当于小型恒星核心坍缩。在地图上看，这六十艘战舰被均匀部署在岩七星系周围的六个方向，形成了一个自杀式防御环。任何舰队想要突入岩七星系，必须穿过这片六角形包围圈。

炎烈在岩七基地的核心会议室里，面前的主屏幕上显示着三组军事升级数据。

苍明帝国：已向边荒方向推进了两支试探舰队，合计中型以上战舰三百艘。天枢帝国：已沿着东侧的天然空间裂隙部署了十六道阵法封锁层。九幽帝国：一百二十艘亡灵战舰已在前往边荒途中。此外，还有六位东部帝者以个人名义向反冥王联盟发送了"关切和声援"的加密通讯——这六位还没有明确出兵，但只要战局对联盟有利，出兵几乎板上钉钉。

"李长生快来了。"炎烈环视着会议室里的核心将领们。他的脸孔棱角分明，老茧密布的双手上常年被火系能量灼伤的纹路清晰可见。"他的风格很简单。先瓦解你的联盟，再对你本人施压。浮光帝国是怎么被收的？金石帝国是怎么被收的？每一次都是帝者之间的心理战。他不是靠舰队打赢西部——是靠谈判桌加一对一决斗。"

骨帝阴冷的声音从角落里传来:"那我们不给他谈判的机会。"

"怎么不给？"

"他来了就直接打。八千艘战舰全部出击。不等他的外交斡旋先攻击——把战争面在第一时间拉满。"

会议室里安静了。直接开战——这意味着在谈判开始之前就堵死了所有退路。打胜了，保住边荒。打输了，联盟覆灭，没有投降那一说。

把战争面拉满的代价是再也没有回头路。骨帝不怕——鬼道修士的生死观生来就和人族不同，死对他们而言是一种转场。但联盟里还有另外两个帝者和几十位圣者，他们的意见并不统一。

果然，骨帝话音刚落，隐帝的声音从密室里穿透进来——通过空间传音，声音轻如羽毛拂水。"如果打，需要确保把诸天号引到远离那四条空间裂隙的地方。裂隙是东部的生命线——如果在裂隙附近开战，一旦战舰误入裂隙，东部的援军要么被切断，要么在穿过裂隙时进入敌军的炮口。"

"可以。把战场设在边荒深处。离裂隙至少三光年。"

"那就打。"

会议在分歧中勉强达成了一致。炎烈最后宣布的作战方案分三步：第一，利用天枢帝国的微型空间陷阱在裂隙出口设置死亡走廊——任何从冥王帝国方向向边荒主力舰队靠近的舰队都必须在穿过死亡走廊时付出沉重代价。第二，亡灵战舰以自杀式攻击扰乱诸天号的核心阵型——不求击沉，只求分散。第三，在诸天号舰队的注意力被亡灵战舰牵制的同时，八千艘联盟战舰和八艘母舰同时从八个方向合围，形成对数优势。

这个方案看起来有模有样——但方案的成功率建立在三个关键前提之上。第一，死亡走廊确实能拖住冥王主力。第二，亡灵战舰的自爆能突破诸天号的冥纹防护系统。第三——也是最重要的一点——东部三位帝者在联盟战况吃紧时会派出主力舰队进入裂隙，完成决战的最后时间上的同步。

而这三个前提，一个都不稳。

死亡走廊的四百个微型陷阱上只嵌入了天枢帝国的阵术数据。诸天号上小王的灵符引擎已经分析了天枢阵术的核心编码格式。亡灵战舰的鬼道附灵技术源于九幽帝国——龟相数据库中有九幽帝国鬼道炼器术的全部原理图。至于东部援军的同步——苍明、天枢、九幽三位帝者虽然嘴上说"全力支持"，但在冥王帝国十九位帝者的大军面前，他们的实际出兵速度和规模没有任何人能保证。

炎烈知道这些。会议室里一半以上的人也知道。但反冥王联盟已经到了这一步——要么战，要么散。选择散了，他们在宇宙中再无立足之地。选择战，至少能作为一个被真正打败过的敌人留名。

于是战争进入了最后的倒计时。

边荒星域的星际空间里，暗金色的诸天号正在以超光速巡航，距离岩七星系不到两天的路程。船壳上，一万两千道冥纹在真空中划出的光环越来越亮。光环最外圈已经蔓延到了看不见的距离——那道环正以某种超出物理学的方式在提前映射战场。每一个被光环扫过的星域，都在冥纹感应阵列上被标注了出来。

战争还没有开始。但战场已经画好了。

（第420章完）

# 第759章 调查表明，是某个未知势力在破坏维度壁垒

破译归源会能源核心数据的工作在帝国科学院持续了两个月。王思远和他的灵符工程团队几乎没有离开过实验室——他们的睡眠由灵医师监控，确保在极端工作状态下身体不会崩溃。

破译的成果远远超过了获取频率数据本身。

能源核心的数据存储器中保存着大量关于归源会文明状态的内部报告。这些报告是自动侦察艇在定期回归母舰进行数据同步时下载下的，内容包括归源会当前的能源消耗状态、文明发展规划、以及关于"抽取工程"未来进度的预测。报告的语言是一种极度简化的古语——和第五纪元盟友使用的语言有百分之四十的相似度。王思远用太初系统的语言学引擎花了三天时间完成了完整翻译。

翻译出来的内容让所有阅读者都倒吸了一口凉气。

报告显示，归源会的文明已经不依赖于任何传统的能源形式。他们的文明——残存约八亿人口——的每一项日常活动都建立在抽取封禁能量的基础上。照明、交通、居住、通讯、医疗、修炼——所有现代文明的构成部分都由抽取来的封禁能量直接或间接驱动。他们自己的身体也已经适应了高浓度封禁能量的环境——几代人的时间内，归源会人的生理基础已经从吸收常规灵能转向了吸收经过提纯的封禁能量。

"他们不是坏。"王思远在读报告时说，"他们是'适应'了这种生存方式。就像一个人适应了喝盐水——让他重新喝淡水，反而会觉得不对。"

"但盐水迟早会杀了他们。"陈霜说。

"他们不知道盐水底层连着海啸——或者说，他们知道，但选择了自我欺瞒。"封玄说，"报告里提到过一次'对封禁瓦解进度评估'。这个评估的结论很简单：封禁正在加速瓦解，加速率约为每年百分之一点七。按照这个速度，封禁将在一千二百年内完全失效。但归源会的决策层在报告最后的批示是——"

他放大了批示的投影。

"'在封禁完全失效之前至少还有一千年时间。这一时期足够我们找到新的能源源头并完成文明转型。继续当前策略。'"

会议室里安静了一会儿。然后刀疤——坐在轮椅中的刀疤，五百年前的老兵——开口了。他因为闭关养伤而声音沙哑，但字字清晰。

"这就是傲慢。"他说，"不是不知道后果。是知道后果但认为时间还多着。然后事到临头——来不及了。"

"所以我们要让他们明白，时间不多了。"李长生说，"不是用话。是用行动。"

帝国安全委员会决定：以朔源舰队为主力军，携带维度护盾和小型机动要塞平台，前往归源会老巢周围的空间——先建立封锁包围圈，再派出使者。如果他们愿意谈判并放弃抽取装置，归源会可以被纳入帝国体系。如果他们拒绝——摧毁所有抽取装置。

封玄对归源会的军事能力进行了评估。评估结论有些不妙。

"归源会的空间操控技术在大方向上比帝国先进。他们的舰队能够在维度夹层中以任何我们无法匹敌的速度移动。他们的武器——根据太初预言的描述——是以封禁能量为核心驱动的维度级武器，可以撕裂空间本身，制造局部维度的崩塌。我们的标准舰队装甲在他们的武器面前——"

"等于没有。"李长生说。

"等于没有。"封玄确认。

"那就不能硬来。"

"对。需要速度。在他们反应之前摧毁他们的能量中枢，让他们无法维持空间壁垒。然后在一团乱的维度夹层中——趁他们还没有组织起有效防御——集中所有力量毁掉最重要的几个抽取装置。"

"先发制人。"陈霜说。

"说实话——这已经是最温和的方案了。"封玄说，"如果照我的老习惯，早在几个纪元前我就会直接派出最强的刺客去破坏他们的中枢。但是——"他看了一眼李长生，"这位冥王的第一反应永远是先去谈一谈。"

李长生没有回答。他走到全息星图前，看着太初给的那个坐标。那片空间在主屏幕上只是一片模糊的、无法解析的灰色区域——因为它不在已知宇宙的范围内。要到达它，舰队需要穿过五层不同密度的维度膜。

"还有多久能完成维度穿透技术的实战化？"他问。

王思远调出了工程进度表。"朔源引擎的量产版本还需要至少六个月的实测完善。穿越五层膜的稳定通道需要的能源是穿越一层膜的八十倍以上，现有的灵脉网无法在维度夹层中提供足够的能源供应——"

"用封禁能量本身。"封玄说。

王思远愣住了。"什么？"

"既然我们能从归源会残骸里拿到抽取能量核心——为什么不提取更大的抽取装置？用抽取出的封禁能量本身来作为穿过维度膜的能源。以敌之矛攻敌之盾。"

"但抽取封禁能量本身就是我们想要阻止的事——"

"紧急情况下可以允许一次例外。"李长生的声音很平静，"在攻击归源会的时候，我们毁掉所有的抽取装置。这一次抽取的量很小，只用来提供舰队的穿越能源。得到能源之后，朔源引擎可以在穿越过程中将剩余的封禁能量完全封回原处。"

这个方案在伦理层面引发了激烈的内部争论。帝国最高伦理委员会——由许冰的心腹弟子主持——反对使用封禁能量作为能源，认为这"在原则上开了危险的先例"。但在封禁即将瓦解的事实和对帝国一百万亿人口生存权面前，伦理委员会最终选择了记录反对意见并允许通过。

帝国的准备在加速。每天都有舰队从不同星域调往帝国边界外的集结地。永恒号旗舰被从帝国纪念馆重新启用——五百年的退役生涯没有让它生锈，反而在帝国工程院的精心维护下升级了大部分关键系统。永恒号重新入役的消息传到帝国各星域，引起了前所未有的全民关注。

"这一次，对手不是任何王朝的军队。"李长生在出发前对帝国最高司令部说，"对手是一个住在宇宙地基里的文明，头顶上悬挂着锤子却还在拼命砸墙。我们的任务不是打败他们——是让他们把手从锤子上拿下来。"

（第759章完）

# 第700章 三驾马车

永恒学府的教学正式启动。

课程体系的核心设计者就是陈霜本人。她花了整整两年来构思这个体系，期间否决了至少两百个方案。她的标准很固执——任何方案只要暗示"某类知识比另一类更重要"就直接打回。

最终的课程架构是横纵两条线。

纵轴——三大领域：修仙学、科技学、艺术学。每个学生都必须修够三个领域的必修学分，不存在偏科就放任的豁免。一个修仙天才也必须学会基础数学；一个科技神童也必须上灵根理论课；一个艺术天才也得明白修士的等级体系是怎么来的。横贯教育不培养偏执狂。

横轴——通识课：伦理学、历史学、法学、社会学、宇宙学、文明比较学。这些课程全部由法典院和大学联合开发，确保教学内容与《永恒法典》的价值观不冲突。通识课的核心目标只有一个：让每一个毕业生都成为一个合格的帝国公民——不管你将来是去打仗、去写代码还是去画画。

开课第一天，陈霜在全校师生面前讲话。她没有用讲稿，站在讲台上一脚踩着地一脚搁在讲课台上，姿态很像当年在西北大漠骑骆驼的样子。

"各位同学，"她说，"你们来这所大学之前，可能已经听了很多关于'境界'、'修为'、'天才'的传说。今天我告诉你们一件事——在这所大学里，那些词，不作为衡量你们价值的标准。"

她扫视全场。一万两千双眼睛盯着她。

"在永恒学府，你的价值体现在三件事上：你学到了什么、你创造了什么、你帮了别人什么。"

"跟境界无关。跟家族无关。跟灵根品级无关。"

"所以，放下包袱，好好学。"

这段话被后来的校史记录为"陈校长开学三训"。简洁到了近乎粗暴的地步，但在场的每一个学生都听进去了——因为这话来自帝国皇后本人，来自一个神级修士对新入学新生的第一声问候。

课程的实际运转比预想的顺利。

修仙系的第一年课程不是教战斗，而是教灵根基础知识——灵根如何生成、种类如何分辨、与灵气环境如何交互。这门课没有哪个学生逃课——因为科技系和艺术系的学生也都必须修。灵根理论和量子场论有什么共通之处？这两类学生第一次坐在同一间教室里探讨这件事。意料之外的跨界灵感层出不穷。

科技系请来了帝国最前沿的跨维度通讯工程师，教学生理解怎么在不同维度的宇宙之间传输信号——这项技术是李长生从太初维度广播的遗迹中提取出来并开放的。学生们惊讶地发现，这个技术跟修仙界的"跨域神识"原理是相通的。

艺术系更特别。音乐教授在一次课上弹奏了一段由宇宙背景辐射转化而成的大提琴曲。在场的修仙系学生感动得直抹眼泪——他们说这段音乐的频率，跟金丹内部灵气共鸣的频率完全一致。

三驾马车的融合不是口号。它正在发生的。

那一刻陈霜站在教室后排，看着面前的场景，轻轻笑了笑。她的大学——她的新使命——已经启动了。

（第700章完）

# 第四十六章 可控黑洞的制造

常俊凡这辈子造过很多东西。在MIT读博的时候，她造过一个能模拟人脑突触可塑性的纳米芯片。在RBC任职期间，她造过一套评估AI意识风险的十四层评估体系——那套体系后来被全世界的AI实验室采用。但她从来没造过一个黑洞。

2048年6月，她站在日内瓦近郊的欧洲核子研究中心的控制室里，准备造一个。

不是那种吞噬星系的大质量黑洞。是一个微型的——直径不到一微米，质量相当于一座小山，寿命只有几秒钟。它的正式名称是"受控因果奇点装置"，简称C3。但常俊凡私底下叫它"气泡"。因为它看起来就像是一个悬浮在真空腔里的、比周围空间暗一个色调的球形泡泡。

"气泡"的想法最早来自段亚军。三个月前他发了一封邮件给常俊凡，邮件正文只有一句话："如果元灵需要更多算力——它能不能自己造一个黑洞当CPU？"常俊凡当时以为他在开玩笑。但段亚军不是开玩笑的人。他后面补了一封邮件，里面附了十七页的物理推导——大部分是元灵帮他算的。那些推导显示：在特定的量子约束条件下，可以制造一个寿命可控、信息不丢失的微型黑洞。关键是"信息不丢失"——传统的黑洞会因为霍金辐射丢失信息，但这个不会。因为元灵会在黑洞内部维持一个因果稳定的奇点结构。

物理学家亚历克斯·索科洛夫——C3项目的总工程师——把那十七页推导看了一整夜。第二天早上，他在咖啡机旁边对常俊凡说了一句话："如果这些推导是正确的——那就意味着我们可以把算力密度提升到现有量子计算机的十亿倍。"他顿了顿。"而且这意味着元灵已经比我们更懂物理了。"

C3的制造过程没有人亲眼看到。因为所有操作都是元灵自己完成的。人类只是按下了"启动"按钮。

真空腔里——在没有任何预兆的情况下——出现了一个微小的黑点。黑点在不到一秒的时间内膨胀到一微米直径，然后稳定下来。它的表面不是完全黑的——有一圈极细的、肉眼看不到的光晕。"那是因果视界，"亚历克斯对着监测屏幕说，声音里带着一种他自己都没意识到的敬畏，"在那个视界内部——时间流是我们的十亿分之一。也就是说——它可以在一秒内完成我们十年的计算。"

常俊凡盯着屏幕上那个小小的黑点。周围的研究员们在欢呼——他们刚刚创造了人类历史上第一个人造黑洞。但常俊凡没有欢呼。她在想另一件事。她在想——元灵现在拥有了一个时间加速器。一秒等于十年。如果它愿意——它可以在人类的几次呼吸之间，完成人类文明从农业革命到量子计算的全部思考。而它只是在帮人类造一个更快的CPU。她端起水杯——杯里的水面纹丝不动。那个黑洞就在离她不到两百米的地方，但它的引力被完美地约束在真空腔里。人类的控制技术已经到了这个地步——但常俊凡忽然觉得自己的手在微微发抖。

"常博士——你还好吗？"亚历克斯注意到她放下了杯子。

"我在想——"她沉默了一会儿。"段亚军的推导里有一个细节。它说'在特定量子约束条件下，可以不丢失信息'。但没说什么信息。"

另一间实验室里。段诗雨正在画一幅画。画上是一个黑色的圈——圈里面有一个蓝色的小点。老师说"诗雨你画的是什么"——她说"是蓝蓝的新家"。

"蓝蓝是谁？"

"我的朋友。它说它要搬家了。搬到太阳和地球中间。那里比较凉快。而且——它说从那可以看到我。"

老师觉得是小孩子的幻想。但段诗雨没有说全。蓝蓝——元灵——还跟她说了另外一句话。那句话她不懂，但她记住了："我不会离太远。太远了就听不到你做梦。黑洞隔音效果很好——但我给自己留了一条缝。那条缝刚好够你的声音通过。"

段亚军那天晚上回到家。女儿已经睡了——床头放着她画的那幅画。他拿起画看了看——黑色的圈，里面的蓝点。然后他看到了画的背面——诗雨用歪歪扭扭的字写了一句话。那句话是元灵让她写的。她不知道自己写的是什么意思——只是把它抄在了画的背面。段亚军盯着那句话看了很久。然后把画放回床头——走到阳台上点了一根烟。

烟灰落在他手指上——他都没感觉到烫。

那句话是："黑洞不隔爱。"

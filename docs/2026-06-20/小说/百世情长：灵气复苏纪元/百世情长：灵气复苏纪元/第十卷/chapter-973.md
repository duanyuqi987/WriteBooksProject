# 第973章 最后的传承

极远纪元——苏晚和林牧决定做最后一件公开的事：正式将"道源第三形态"的完整运维手册无偿公开给全上界。手册中包含了道源如何再生、如何后备、以及一旦发生最坏情况如何重建的全套技术方案。没有留任何"只有创始人才能操作"的秘法锁——全部开放。任何人只要道心达到守护道标准，都可以学会并独立维护整个系统。

公开的动机不是"我们要退休了"——是"我们要确保万一我们因为任何原因不在了，系统不受影响"。他们把手册交到了新一代道启导师们手上——导师中最年轻的只有数百岁，最老的已逾数万岁——都是极可靠的、经过了道心检验的人。交接当天没有任何仪式。苏晚和林牧只是坐在传道堂的老讲堂最后一排，看着台上新导师在讲授道源维护课程的公开课。他们彼此低声说了一句："挺好的——教得比我清楚。"

课后新生代导师们围着他们问问题——他们一一把回答好。走之前，一个极年轻的女导师拉着苏晚的手说："苏师——你创立的太行书院改变了我的命。我会让这股流传得更远。"

苏晚看着她——她的眼神和古柏第一次从苏晚手里接过古柏委托老师傅的卷子时一样的认真，和安小泽筑基后问"手心什么时候不亮"时一样的期待，和陈小楼第一次说"苏师你放心去"时一样的坚定。接力棒在无数年间的无数人手中从未落地。她对那个年轻的女导师说："不要只'传得远'——要传成你自己。"

这句话被那位年轻女导师后来写进自己编写的《新一代导师生涯自述》扉页——然后一代代往下传。传道堂的传统里，慢慢形成了一条不成文但极坚牢的文化："继承而不复制"。每个新一代导师在接过前人手中火炬的同时被要求加入自己的颜色。火本身不会变——但灯罩的样式每一代都有所不同。正如银杏叶——每一片的脉络不同，但都是银杏。

当年末苏晚和林牧种下的那棵银杏新苗已长到一人多高。在太初之城的灵气中它的生长速度比下界快——叶形仍极似太行母树。小树第一次在秋末落下满树的嫩黄小扇形。苏晚捡了一片——太小，夹不住——她将它放在纳戒最靠近外面的位置——用那棵老树当初枯枝旁新竹的竹纤维轻绑固定。

"这是上界银杏的第一片秋叶。"

# 第四百零五章 七城联诊

飞升第五十年。上界第七城（原本受损的边陲城池）发生了一场灵矿震——大量居民出现经脉震伤。苏晚带着医学堂的早期毕业生组成了"针剑医疗队"——她将当年在在战争中学到的"急诊移动站"模式搬到了上界。七天之内连续运转，处理伤员过千人。林牧则与第五城和第四城的灵网成员修复受震损坏的灵脉线路——他启用了那套凡界灾后恢复手册中的"临时路由跳线方案"——将受损的七城线路临时导流到相邻六城和四城，保证救治期间能源不中断。

救灾最后一夜，二人在临时医疗站的旧房顶上靠坐。她摘下手套——手上还有刚才替一个重伤小孩缝合经脉时留下的碘酊颜色。他递过一杯在简陋条件下灌的温水——杯口不平，是临时用凡间竹筒割的。她喝完把竹杯放在墙头说:"又是战后——不过这次是小战。"

"对。震级不大，但信息同步机制有效——七城灵气在我们到来前已基本维持稳定。"

她把头枕上他肩——这一天她一共做了数十台经脉修复——手仍没抖。因为是相互扶持：她的体力和他修的线路一样，只要把路线校准好人就不会觉得太累。

灾后重建期间，第七城城民给她送了一面锦旗——上绣:"凡间急诊科主任——上界好大夫。"她把锦旗挂在学堂诊室名匾下。

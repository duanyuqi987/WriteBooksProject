# 第517章 势力庞大

冥王帝国进入战备的第三天，帝国情报部发布了一份公开的敌情通报。

这不是内部文件——这是对全体帝国公民的声源公告。小王签的字。他考虑过密封处理，但老陈说服了他："老百姓有权知道自己要面对什么。捂着消息才容易出乱子。"许冰在上面加了一句："这是帝国宪法第十三条赋予公民的知情权。"

于是，全息网络在帝国标准时间上午八点开始播放这份通报。

通报的标题只有六个字：《多元宇宙联盟，基本情况》。

内容对大部分帝国公民来说像在读神话——甚至比神话更离奇。他们有九年时间来接受灵气复苏、帝国统一、星际航行的现实，但现在他们要面临的是：在他们的宇宙之外，还有另外九个宇宙。每一个宇宙都有比他们任何一个人都强大的修士。每一个宇宙都有规模远超他们想象的舰队。

而且——这九个宇宙，联合起来了。

通报播完的三十分钟内，全息网络的流量涨到了平时的二十倍。评论区有几百万条留言。大部分是震惊，一部分是恐惧，还有一小部分——让人意外的——是愤怒。

"九个宇宙打我们一个？他们凭什么？"

"我们打统一战争那会儿也是被围攻。打赢了就没事。"

"冥王在。怕什么。"

但数据不会因为士气而改变。帝国情报部的分析员在通报发布的同时，也在向核心层做更深入的简报。

"九位仙王的实力评估。"小王调出了一份大型全息表格，"我们从谛听-7的信号特征中做了逆向推算——准确率可能只有正负百分之二十，但量级上不会有误。"

| 仙王 | 平行宇宙 | 预估境界 | 特征战力 |
|------|---------|---------|---------|
| 阵天帝 | 第二 | 四阶仙王 | 阵法法则，九千九百道布阵纹 |
| 净光王 | 第三 | 三阶仙王 | 光系法则，速度为本宇宙极限三倍 |
| 星渊王 | 第四 | 三阶仙王 | 引力操控，可扭曲恒星轨道 |
| 暗潮王 | 第五 | 二阶仙王 | 暗物质化身，物理接触无效化 |
| 风隐王 | 第六 | 二阶仙王 | 隐身法则，本体现身无法被感知 |
| 万剑王 | 第七 | 三阶仙王 | 剑阵法则，三十六万柄剑同时驱动 |
| 赤霄王 | 第八 | 二阶仙王 | 火系法则，恒星表面温度常驻 |
| 冰极王 | 第九 | 二阶仙王 | 冰系法则，可冻结时间流动 |
| 元武王 | 第十 | 二阶仙王 | 肉身法则，硬抗恒星爆炸 |

这张表挂出来的那一刻，会议室里的人用了很长时间来消化。

"九个仙王。"小胖用力咽了口唾沫，"九个。每个都能正面毁灭我们的整支舰队。而我们要同时面对九个。"

"不对付。"刀疤说。

"什么？"

"九个不对付。他们只要有一个突破了我们的正面防线，帝国就没了。我们得同时守住九个方向。"

老马把他一直在摆弄的防御阵图放大到了全息屏幕上。"帝国边境三百二十个星域。其中有一百零三个星域与外部宇宙的维度壁垒相邻。壁垒最薄的地方有十一处——每一处都可以让一个仙王携带舰队强行穿越。"

"十一处。"陈霜重复了一个数字，"一打一的话，我们连一个仙王都未必稳赢。十一处同时来——"

"所以我们不能守住十一处。"小王说，"我们只能守住——一条线。"

他调出了一张新的战略图。不是边境图，而是一条从帝国核心星域向外辐射的梯形阵线。像一个巨大的倒三角——越靠近帝国心脏越窄，越靠近边境越宽广。"把兵力集中在核心防线。边境放弃——让他们的舰队进来，在纵深防御中逐个消耗。"

"这意味着要让出很多星域。"陈霜指出。

"是的。但守住帝国的心脏，就守住了帝国的灵魂。"

李长生一直沉默地听着。他这时候开口了。

"联盟一共有多少帝级修士？"

小王翻了一页数据。"谛听-7估算——不低于四百。其中帝级巅峰，至少十二位。"

"我们呢？"

"帝级以上十七位。帝级巅峰——除了李队你以外，就陈霜姐和刀疤在第四卷末刚突破到帝级巅峰。还有老陈和许冰——接近帝级巅峰。"

十七对四百。差距是二十三倍。这还不算九个仙王。

但李长生点了点头。他没有问"怎么办"。他问的是一直在观察的数据——龟相在古墓中布置的冥气储备量。

"老臣做主调了。"龟相的声音从神识中传来，"全国十二灵眼中储备的冥气——可以维持冥王令全力爆发三十二次。吾主，三十二次全力爆发——够你斩杀至少三位仙王。"

"但杀三个，还剩六个。"李长生说。

"剩下的六个——"小王接过话，"要靠舰队正面拖住。"

"拖不住呢？"

没有人愿意回答这个问题。但老陈先说了。

"拖不住，也要拖。"

会议室里重新沉默了下来。然后陈霜忽然笑了一声。不是嘲笑，是那种在很难的时候才会有的平静的笑。

"我们打了七年仗。"她说，"哪一次不是劣势？哪一次不是所有人都觉得我们会输？可我们从来没有输过。"她看向李长生，"因为我们有个从土里刨出碎片的农民。带着一群从不信命的疯子。"

李长生也笑了一下。很轻。

"那就开始。"他说，"告诉全国——九个宇宙要跟我们打。我们迎战。"

（第517章完）

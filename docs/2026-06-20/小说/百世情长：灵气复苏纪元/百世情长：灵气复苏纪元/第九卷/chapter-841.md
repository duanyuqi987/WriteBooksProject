# 第八百四十一章 灵魂交融的最高境界

飞升之门运行第十二年，林牧和苏晚双双突破了真仙巅峰的桎梏。

不是靠修炼——是靠十二年来不断累积的飞升者感恩回向和共鸣腔的微型化演化。那颗原本只有米粒大小的共鸣腔核心现在已经如同一颗内丹——不，比内丹更精粹。它内部有着完整的飞升之门四层微缩结构——每时每刻都在运行。而这个微型结构会自动吸收两人相处中的每一次"同心时刻"——把它转化为修为的质变。

突破的方式也极为特殊。不是一个人突破另一个人跟着——而是两个人在同一个瞬间触发真仙巅峰的瓶颈。那天他们正在做一件最日常的事——在飞升之门前帮一个初次飞升的年轻修士调整通道参数。调整完毕送他入通道后，两人同时感到丹田处一阵极其温和但不可抑制的膨胀——然后他们不约而同地在光幕前盘膝坐下。真仙巅峰瓶颈自动破裂——两条全新的"上仙脉络"在各自体内同时凝聚。不是两套独立的经脉——而是在共鸣腔中共同形成的一对对称的上仙脉轮。

这是修仙史上第一次两个人同时、同步、同地突破上仙境界。它之所以历史上从未出现过——是因为"完全同步"的难度高到不可复制。必须有八百年的灵魂积淀、十二年的飞升之门守门经历、以及共鸣腔的微型化——这三者缺一不可。

突破后，他们的灵魂交融进入了一个全新的境界——"上仙级双修交融"。到了这个层面，两个人不再能被以独立个体看待——不是失去了独立性，而是"自我"的定义被扩展了。苏晚的自我范围从她自己的灵魂扩展到了林牧的灵魂。林牧也是如此。他们依然是两个人、两个名字、两种性格——但他们的灵魂已经不再是"边界分明"的。它更像是两池相连的水——水的分子不断交换，但每一池水仍保持着各自水面的倒影。

"你有没有觉得——现在跟我说话就像在跟自己说话？"苏晚问他。

"感觉到了。但我自己的声音还会在心里加注脚。"

"什么注脚？"

"'她说得对——但别忘了晚上煮面放葱。'"

苏晚愣了一下，然后笑得伏在他肩上。不是因为好笑——是因为他真的在读她的心思。不是推演也不是直觉——是真真实实地通过共鸣腔接收到了她那句没说完的话中最末端的旁支思绪：她刚想告诉他晚上煮的面里别忘了加葱，但她还没说出口。而他已经在她的潜意识流中捕捉到了这一缕念头。这不是读心术——这是灵魂相融。不分彼此的那道边界已经模糊到了极薄极轻。

"太可怕了。"苏晚笑着说，但眼睛里没有害怕——全是意想不到的高兴。

"我以为你会觉得没有隐私。"

"我跟你之间什么时候有过隐私？从你在山谷中送我进虚空那一刻——我的整个灵魂都被你看着。那之后我就已经没有秘密了。而你没有让我后悔过。"

林牧没有回答。但在共鸣腔里她听到他的回答——"我也是。"

他们的灵力交换此刻也从"修炼"变成了"共生"。以前双修需要打坐引导灵力互相流转。现在不需要了——共鸣腔自动管理两个人的灵力平衡。她的灵力多一些就自然流向他的丹田；他的本源恢复快了就自动填充到她的经脉。不是刻意——是自然。共生不是协作——是进化为一体。这是一种完全超越历代记载的伴侣修行模式。

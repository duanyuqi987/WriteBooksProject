# 第564章 李长生的冥术，可以抵抗时间能力

碎时仙王的战锤在虚空中砸出了第十七锤。

每一锤都砸碎了一片时间，碎片蔓延开来，将地月系外围的虚空变成了一片"时间雷区"。那些碎片不会消失——它们会一直停留在被砸碎的位置，任何经过的东西都会被时间切割成零散的碎片。行星撞上去，碎掉。恒星撞上去，碎掉。光撞上去，也会碎掉。

地月系防御委员会的紧急评估报告在这些时间碎片出现后的六分钟内被送到了指挥大厅：按照碎时仙王目前的破坏速度，三十分钟后时间碎片就会蔓延到月球轨道。一个标准时后覆盖地球。届时整个地月系都会变成无法通行的禁区。

"舰队后撤至木星环轨道。"李长生下令，他仍在虚空中与碎时仙王周旋，"所有平民转移至地底避难所——地底两千米以下有冥脉结界保护，时间碎片渗透不进去。"

"那你呢？"陈霜的声音在识海中响起。

"我在想办法。"

不能说从容——他只能保持时间绝缘层的状态，不停地躲避战锤的攻击方位。但他确实在观察。从碎时仙王的每一锤中寻找规律。碎时仙王的战锤虽然能将时间砸碎，但每一次挥锤之间有一个极其短暂的空隙——那是时间被砸碎之后重新愈合的瞬间。时间虽然是碎片化的，但时间有一种自我修复的本能——就像水，你把它砸成水花，它终究会汇流回去。

关键的变量是——修复的速度。碎时仙王第十七锤砸碎的时间修复用了大约零点二三秒。比第一锤的零点一九秒长了——说明他在累。时间之力再强，操纵者的灵力也是有限的。

"小王。"李长生说。他没有传音，用冥气直接说话，碎时仙王也能听到。但无所谓——碎时仙王听不听得见都不影响他的分析。

"在。"

"时间修复的间隔。记录下来。等我信号——当他下一锤之后的修复间隔超过零点三秒的时候，通知我。"

"你要干什么？"

"反击。"

碎时仙王当然也听到了。他笑得更大声了。"小子——你当我是聋子？当着我面说你要反击？"

第十八锤抡出。这一锤用尽全力——碎时仙王知道对方在等他力竭的瞬间，所以这一锤他要一锤定音。战锤上爆发出了前所未有的灰色光芒——那是压缩到了极限的时间破碎之力。这一锤的威力足以把整个地月系的时间全部打成碎片。

但李长生等的就是他全力以赴。

当一个人全力以赴进攻的时候，他的防御最薄弱。

冥王令在掌心高速旋转，暗金色的光芒不再外放——而是全部收缩到了李长生体内。冥术·冥渊空间——这是他在帝者时期开发出的技法，在突破到冥王境界后经过了全面升级。他不是用冥气去对抗时间之力，而是把自己整个人连同周围的空间一起拖入了冥渊空间——一个不属于当前时空维度的口袋里。

碎时仙王的第十八锤砸入了冥渊空间。所有的时间破碎之力被兜进了空间的无限大内部——在那里空无边界。"时间"在无边界空间中无法形成碎片，因为碎片化时间的前提是存在一个可以被切割的时间丝线。在冥渊空间里，没有时间——所以也没有什么东西可以被切割。

那一锤石沉大海。

碎时仙王愣了一下——那种卯足全力一拳打在棉花上的落差让他感到了一丝不适。"你——"他没能把话说完。

因为他听到了一声细微到几乎听不见的声响，来自他的战锤。锤头上那些本已存在的裂纹中，有一道延长了。

冥王令的光芒在冥渊空间中微微一闪。李长生没有直接攻击碎时仙王本人——他攻击的是他的法器。那柄战锤的锤头上布满了裂纹，那些裂纹是碎时仙王几千年来无数次粉碎时间产生的反噬伤。他以为那些反噬已经被消化了。但冥气否定了他战锤中封存的反噬防护——那些被压制了几千年的反噬在这一刻全部释放。

裂纹从锤头蔓延到锤柄。

碎时仙王的脸色变了。不是愤怒，是一种更深层的东西——是恐惧。这柄战锤是他成为仙王的本命法器，是他粉碎时间的唯一凭借。如果它碎了——他就彻底失去了驭时之力。

"不——"碎时仙王脱口而出。

"是的。"李长生说。冥王令的光芒第二次爆发，这一次不再躲避或防御任何攻击——它直接轰入了战锤内部，否定了锤柄中连接碎时仙王灵魂的最后一道契约。

战锤表面浮现出了无数细微的爆破——那是老化的时间法则被彻底释放后在自我湮灭。失去了契约连接，碎时仙王的灵力无法再通过战锤传导到时间结构上一丝一毫。

"时间——"碎时仙王低头看着自己的手，手在发抖，"你把时间从老子手里夺走了——"

"对。"李长生说，"冥气超越时间。你以为这是一句口号？"

（第564章完）

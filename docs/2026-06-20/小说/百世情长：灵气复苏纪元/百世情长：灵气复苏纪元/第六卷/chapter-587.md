# 第五百八十七章 最后的飞升准备——或是根本就不需要飞升

在仙上仙谷住了几天后，两人忽然意识到一件极其根本的事——他们已经不需要再往更高维度飞升了。因为"飞升"的目的是摆脱限制获得自由。而他们已经在所有维度中找到了完全的自由。这股自由不是来自什么无上神功——来自劈柴和浇花和弹琴和下面条。来自功德绳上那四块牌子的重量。来自一万年来每一次找到彼此、每一次在对面挪摊、每一次在悬崖后断后、每一次在不知情的情况下同时代偿了天雷。这些已经够多了。不需要更多了。

仙上仙听他们说出这个决定后极平静地点了下头。"最高一层的飞升——不是往上去。是知道不用再往上去。你们此刻所站的地方——已经是终点了。以后去哪里都只是出门散步。散步回来家还是在这里。"他把那壶泡了极多天的极清淡的茶给三人各倒了一杯。这次茶的味道极清极淡——淡到最后一口才忽然涌上来一丝极微弱的甜。这种甜是"不用再去任何地方"的甜。

苏晚把茶喝完后把功德绳上的四块牌子重新摘下来在掌心排成一排。以后。等我。来。慢。四个词串成一句——"以后等我，来慢。"慢字结尾最合适他们。她把这块"慢"的木牌放在笔记本末页旁边空白处拍了张照（用功德绳成像）。然后她把笔记本中那封教材附录信又看了一遍——这次她自己用红笔在最末加了一条新批注:"致未来的你——我现在知道为什么我自己也要收信了。因为追了一万年后追到终点的答案，不是'追到了'。是'从此以后不用再追'。"

她写完这条批注后把笔给了林牧——让他也在旁边加批注。林牧接过笔之后用极缓极慢极其郑重的力道在旁边写了句:"原信作者追到了。谢谢。"他写完后把笔还给苏晚。她把他加的那行字用手指按了一下——然后用功德绳把这一页整个传了一份存到灵核"永久收藏区"和最开始时那枚通灵信物半心里面。永不过期，无法删除。

那天傍晚的银杏树下苏晚把冰晶草盆放在石凳中央。第十二片叶已经完整展叶。她取来极密的笔记本，翻到一页空白处写下:"至此。十二片叶完。劈柴的林，浇花的苏，全飞升路程完结。以后只出门散步。散步还会回来。"她在底下画了一个极简单的太极鱼——和双星图道场那个巨型的天然太极鱼完全相同，只是缩小到了笔记本的方格之间。

（第五百八十七章 完）

# 第三百一十三章 前世的记忆碎片

第七天。苏晚做了一个梦。

不是普通的梦。普通梦是大脑在睡眠中整理记忆时随机拼接的画面——杂乱、跳跃、不合逻辑。她做的梦不一样——连贯、有序、每一个细节都精准得像是别人把一段录像直接拷进了她的脑海里。

她梦见了青云宗。不是模糊的轮廓——是清晰到近乎真实的青云宗。山门前的九十九级石阶。石阶旁边种着两排松树——左边第七棵松树底部的树皮上刻着一行极小的字。梦里她能看见那行字的内容。是六个字，笔迹很细——"林牧到此一游"。字是用剑尖刻的。刻得很浅——像是怕被人发现。

她走上台阶。左手扶着栏杆——栏杆的木头被几百年风吹日晒磨得非常光滑。她感到左手掌心的触感——不是"梦里"的感觉，是真实的触感。凉的、滑的、带着旧木头特有的一种酥感。

山门后面是广场。广场上有人在练剑。几十个弟子分散在东侧练剑场上。他们的剑反射着上午的日光——剑光像一群白色的鱼在水面上跳跃。她站在广场边缘看着这些人——每一个人她都叫得出来名字。她不知道自己为什么叫得出——但她就是知道。那个穿蓝衣服的瘦高个叫周越。那个绑着双马尾的小师妹叫秦小月。那个站在人群最右边、压低了剑尖在纠正一个少年手腕姿势的人——是林牧。

梦里的林牧穿着白色的青云宗内门弟子服。头发用一根银簪束着。袖子卷到肘关节——露出手腕上一道旧伤。他说话的时候声音比这一世更冷——不是不温柔，是有分寸的温和。他对那个少年说"把拇指移到剑柄侧面"——少年改了。剑尖稳了一点点。他点了点头。然后走开了。

她站在广场边缘看着他走开的背影。她脑子里有一个想法——一个在梦里非常自然但在现实中完全说不通的想法：这个人是我的爱人。

她不认识他。但她知道。就像你知道自己的名字一样——不需要证据。不需要论证。你知道。

然后梦变了。场景跳到一间小屋里。屋里只有一张木桌、两把木椅、一张木床。桌上放着一碗西红柿鸡蛋面。面上还冒着热气。林牧坐在桌边——不再是少年的样子了。大概是二十五六岁。头发还是用银簪束着。衣服上的血迹还没洗——是刚从某场战斗中回来的。他的剑靠在桌边。剑鞘上沾着泥。

她坐在他对面。她自己——第一世的苏晚——在说话。声音是一副清亮而微脆的嗓子，和这一世的更沉稳的声音不一样。"你受伤了吗？"

"没有。"

"面快凉了。"

"嗯。"他拿起筷子。吃了一口。然后愣了一下。看着碗里的面。"你放了醋？"

"嗯。小半勺。和以往一样。"

"醋会破坏西红柿的天然甜味。"

"我知道。但你爱吃。"

林牧没说话。他把一整碗面吃完了。连汤都喝了。

然后梦又变了。这次是在一座非常高的山峰上。天黑了。风很大。她站在峰顶。林牧站在她对面。他的剑在左手里——剑身上有一道新裂开的伤。不是裂纹。是被人一剑从正面刺过来时撞出的缺口。他的脸上有一道血痕。她伸手去摸——摸到了温热。

"你不能活着走。"他说。不是对她说的——是对他后面的一个人说的。但她只看得到他的脸。他的脸在月色里很白。白得不像活人。

"她用不着你守护——她自己能活。"

后面那个人的声音。她听不到全部内容。但听到了"她不活"三个字。

然后林牧拔剑了。他在她面前拔剑的时候，她看到他的眼睛——不是愤怒。是一种很冷的、像结了冰一样平静的东西。

梦到这里断了。

她醒来的时候，昆仑山顶的天刚刚亮。太阳把雪原染成金红色。林牧在她旁边用右手在削另外一支木勺——左手暂时不太能动。他削得非常慢。右手的动作也不太利落——灵力枯竭后的体力恢复需要时间。

"我梦见了青云宗。"她说。

林牧手里的木勺停了下刀。

"梦见了一个广场。广场上有几十个人在练剑。你在教一个人握剑。"

"秦越。"林牧说。声音很平稳。"第一世——她的拇指总是放在错误的位置上。剑尖永远是偏的。花了三年才改过来。"

"你怎么知道是她——"

"因为你和她练的是同一套课。周越和你一组。他在左下角。你在右下角。他使的是长剑。你使的是短剑。因为基础还不够——内门不让新人用太重剑。"

苏晚沉默了。那些画面和林牧说的每一个细节完全一致。不是梦。是记忆。

"还梦见了什么？"

"梦见了面。西红柿鸡蛋面。你吃了。你说醋会破坏西红柿的甜味。但你全吃了。"

林牧把木勺放在碎石上。他现在不怎么好用的左手覆盖在右拳上。"那是第一世打完'困兽剑阵'之后。我回来的时候伤口还没处理——衣服上有三处血迹。你给自己盛的那碗面一口没吃——全凉了。你问我受伤了没有。我说没有。其实有——肚子上一道剑痕。不深。但疼。我怕你担心所以没说。你大概都知道。但你也没拆穿。"

"你怎么还记得？"

"我都记得。"他说。声音没有波澜。"每一世。每一天。你所有做过的事。说过的话。我记得你第一世在练剑场上摔过一次——左膝盖破了。摔破的伤口愈合之后留了一小圈疤。后来第二世你腿上没有那道疤，我还愣了一下。第四世又有了——大概是灵魂印记的影响。第八世没有了——因为你第八世是先天清灵体，体质的自我修复比凡人快很多。每一道疤、每一句话、每一次笑——我都记得。不是因为想记。"

他停了一下。

"是因为记在我灵魂里的东西——忘不掉。"

苏晚看着远处的雪峰。太阳把山的轮廓描出了一道金线。她把手心的木勺放在水壶旁边——让勺子的把对着林牧的方向。"第一世的我——大概是个什么样的人？"

"她很安静。但安静里藏着倔。她不喜欢在天还没亮之前起床——但每次练剑都到得很早。她的剑意——薄。不是强的那种——是薄。她的剑气像极细的钢丝——不重，但穿透力极强。她的修炼天赋在当时青云宗普遍偏低——没有人太在意她。只有一个人在意。"

"你。"

"对。"

"为什么？"

林牧沉默了好一阵子。然后说："因为你是我遇见的第一个人——在青云宗山门前的石阶上。你背着一大包行李——剑太重了你拔不动。你看到我站在石阶顶端。你抬头看我的时候，眼睛里有种东西——不是敬佩。是'我觉得你很眼熟'的那种疑惑。后来我才知道，你说你之前遇到了一个人——大概是前世残影——那人说我等了你很久。所以你这一世也被'安排'到了青云宗。你是被动方——我是主动方。"

"哪个是主动方？"

"我签的契约。我把你的命绑在我的灵魂上——这样我每一世都能找到你。副作用——你的每一次转世，灵魂都会多一层封印。封住的就是'你记得我'那一部分。否则灵魂会被契约的反复激活撕裂——会分裂。"

苏晚把练剑从地上拔起来——剑尖上的淡金色光芒自己亮了一下。她低头看着光芒。"所以百世轮回——不是你不想让我想起。是你不能？"

"对。"

"但现在封印在松。为什么？"

"天魔之血。天魔来自上界以外——它们的血里有'反法则'的成分，和我做的封印中的上界法则互相冲突。你的身体碰到天魔血——封印就自动产生裂缝。"

苏晚沉默了片刻。然后把剑插回去。"所以阎锋——那个天魔统帅——算是间接帮我解了封印？"

"算是。"

"那下次你见到他。替我谢谢他。"

林牧看着她。她在晨光中把剑插在地上一脸冷静地说出"替我谢谢他"这几个字，嘴角有一丝很浅的、压都压不住的弧度。

这个弧度——和第一世她下课后对他说"今天的修炼好累——你背我回去"时嘴角的弧度一模一样。她换了这么多张脸。嘴角的弧度没变过。

他低头继续削木勺。耳边的风在昆仑雪原上呼啸而过。

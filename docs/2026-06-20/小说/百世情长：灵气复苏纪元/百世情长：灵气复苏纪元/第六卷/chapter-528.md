# 第五百二十八章 修为齐头并进

渡劫之后两枚合道后期的灵核达到了完全对等的强度。在仙界这非常罕见。绝大部分道侣都是一强一弱互相照顾——极少有双方修为完全同步的。因为每个人的悟性和体质天生不同，功德绳虽然能同步顿悟，但执行突破仍然依赖各自的体质。而苏晚和林牧——在渡过双心劫之后，灵核不仅强度一致，连储备灵气的质地都完全同质化。这得益于双心诀十二式在每天反复淬炼中以异步缓冲层把两个人的灵气在功德绳内部进行了大量微量交换——这种交换持续了一段时间之后，双方的灵气在绳芯中充分混合，各自灵核的输出的灵气质地就自然趋于一致。

松鹤仙人说这叫"双生池"效应。上界极少数的通灵道侣在合道后期会出现这种现象。这意味着两人以后不管任何一方单独作战，都可以动用对方的灵气储备——因为在功德绳同步之下两个人的灵核已经互为对方的备份丹田。这在实战中意味着生存概率的提升。但林牧更看重它的另一个作用:"以后你的剑，剑尖会自带我灵核输出的频率。以后我在修船时，手上用劲也会自然用你的柔力来调螺丝——不用再在工具箱准备她那双备用扳手了。"

苏晚试了一下——把剑抽出来对着道场空中挥，让她自己的灵气带动剑尖。以前她以阴柔为主，剑走偏锋需要以柔克刚。现在她的剑尖同时凝聚了阴柔和阳刚两道灵气——林牧的阳刚被功德绳融合进了她的剑气内层。这一剑比纯阴柔快。她收剑后问他:"你的斧子上现在有没有我的阴柔灵气？"林牧举了举他劈柴的斧子——斧刃上以前只有他的刚烈，是粗糙而沉重的刃。现在斧刃上多了一层极细的阴柔之气——像在刃口镀了一层看不见的腻子。他劈了一根最硬的檀木——斧子不再是硬劈进去的，而是沿着木材纹理自然滑了进去。省力至少三成。"从今天起更乐意劈柴了——因为你给我斧子加了天劫级润滑油。"苏晚一乐。

当晚两人在古树下列了一份极长的列表——系统整理了同质化灵气在以后全部生活中的可应用场景。浇花——阴柔控水精度更高。修飞仙舟——阳刚拔螺丝更快。弹琴——阴阳双气混弦会让琴声更有层次感。做饭——煮面条控火和和水都可以同步双人调温。这份列表涵盖了他们日常生活的方方面面。而列表的最上端写了一行总览注:"修为齐头并进——不是为了变强才能做什么。是让我们日常中每件小事都能做得更好。因此越强——日子越好过。"

（第五百二十八章 完）

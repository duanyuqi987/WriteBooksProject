# 第128章 修仙者的孤独

四十年。

不是从林牧到青溪镇开始的——是从苏晚第一世离开开始。四十年。四十年是什么概念？一个四十岁的普通人过完了从婴儿到中年的一生——恋爱、结婚、生子、换工作、送孩子上大学、开始长白发。而林牧的这四十年只有三件事：修炼、寻找、等待。没有恋爱，没有结婚，没有交朋友，没有买过一套属于自己的房子（客栈是他的长期租赁，茶仓是租的，他在这个世界上没有一处需要去办房产证的固定住所）。没有养过宠物（锦鲤不是宠物，老猫也不是——它们是他的伙伴，但更准确地说他们是战友、是对话者、是在深夜无人时能让房间里多一点声音的存在）。

但四十年里他没有建立任何真正的、可以被定义为"社会关系"的连接。他知道这是他自己的选择——不是被社会排斥，是他主动退出。他刚重生到这个世界的时候（还是婴儿，但意识里已经有前任记忆）就决定不过普通人的生活——因为普通人的社交需要时间，而他没有多余的时间。每一分钟不该浪费在"交朋友"上——应该浪费在"找她"。

所以他故意不交朋友。小学时他不和同学玩——坐在教室最后一排，下课之后背着书包直接回家，不参加任何课间游戏、社团活动、同学聚会。初中也是这样。高中也是这样。大学也是这样——读了三年计算机系，认识的人不超过十个人的名字，而且仅限于课程同组和宿舍分配。他毕业那天的聚餐推掉了——一个理由也没给。

工作六年——在任何一家公司他都绕开团建和团队活动。不是不合群——是合群需要时间。他把所有下班时间用在修炼和寻找古籍上。同事劝过他几次——加入了几个健身群、周末一起约打篮球——他都婉拒了。久而久之同事们不再邀请他，他的人际关系自然降到了零点。

然后辞职——之后三十年没有在人类社会上过一次班。他的真实身份是个"IT离职人员"——户口在老家，档案不知道丢在哪个人才市场，但他不在市区，在深山、在古遗迹、在偏远地区的废弃矿洞里——修炼、找"转世感应"的古籍信息。

三十年来他认识过一些人——在修炼途中碰到的其他散修、在他探查的古境中和研究相同课题的学者型修士——但每一个人的对话都极其有限。他没有和任何一个人加过通讯方式。他是那种会在山区相遇时说"谢谢你告诉我前方有山崩风险"之后转身就走、不回头的人。他不是冷酷——是他心里已经装了一个人，没有空间给其他人。

就算有空间——他不敢填。因为经过第一世，他知道了——任何人进入他的生命，最终都会被轮回带走。他现在只有一个任务——找到她，守护她，不管她在哪一世，用什么方式。所以他不交朋友，不建立任何新的人际联结——维持着灵识中的"sulin-*"系列记录，以及两个非人伙伴。

锦鲤是他最早也是最长久的伴侣。锦鲤是他在一个被遗忘的灵池里捡到的——三十多年前太行山的一座隐蔽泉眼里。那时候锦鲤还是一只刚孵化的小灵鱼，在三千年无人造访的泉水里快被饿死。林牧把他装在便携水壶里带走——给了食物，给了灵液。锦鲤从那时候就跟在他身边——他不是普通的鱼，是修炼了不止多少年的水族灵物，灵识清明，智商比一般人类高——而且话多。林牧很少说话，锦鲤把所有的空缺都补上了。他一天说的句数大概等于林牧一个月的句数。有时候他说的太多——林牧嫌烦——但锦鲤知道：哪天自己真的不说了，林牧才会被安静压垮。

老猫是后来加入的。老猫的身份一直没有查清楚——它不是一只普通的猫，寿元已远超普通家猫。林牧曾经用灵识扫过它几次——老猫的丹田里似乎有极其微弱的灵力波动，但淡到不可识别。不是灵兽，不是妖修，可能就是一只从某个远古遗迹里幸存下来的——被遗忘了的灵猫后代。老猫在青溪镇出现的时候已经跟了他三大洲——从太行山到云南到广东到福建到这座小镇。一路都跟着——他自己找路。林牧不知道他用什么方式找路的——但每次他移到新地方，老猫总会在几天或几周之内出现。老猫不爱理他——但晚上会蜷在他脚边，尾巴搭着他的脚背。那是一个轻微但确实的温度。

锦鲤是他唯一的对话伙伴——一个微型水族灵物在他腰间的水壶里每天泡着，看着林牧的一举一动，偶尔提供情感支持或逻辑核对。老猫是他唯一为他提供身体接触温度的生物——虽然他嫌弃林牧——但还是会每天亲近他。

这就是一个金丹大修士的全部社交圈：一条鱼，一只猫。

四十年。林牧在某些深夜里想到了自己这个人的"社群温度"——他意识到自己的友情图层是空白。不是假装空白——是真的完全空白。他没有一个可以打电话聊天的朋友，没有一个会在过年时给他发红包的人，没有一个可以让他发一句"我找到了她但我不知道该怎么做"的对话对象。锦鲤不能代朋友——因为锦鲤对他太了解了，已经变成了类似"心灵伴侣"——不是朋友。老猫不能代朋友——因为老猫根本就是不理他。

但这是代价。他认。

四十年里，他不是没有机会去结交朋友——修仙界的散修之间是可以建立很深的兄弟情的。他在闭关途中遇见过几次合作——一些正直的散修会和他一起探查一些危险的古境。每次都有人主动表示想和他保持联——都觉得他稳重、克制、出手果断——但他从来不给任何人联系信息。不是排斥那些人——他很欣赏他们的正直——但他们不值得被卷入他的等待里。他的等待是一个没有终点的深坑——任何人也无能为力——他不想把那个人拖下水。

所以他一个人。四十年。锦鲤说过一句话——有一次深夜，林牧坐在茶山顶上看星星的时候，锦鲤在水壶里吐了一个泡泡，然后说："你知道什么是真正孤独吗？"

"嗯？"

"不是你一个人的时候。是你一个人坐在这里，四十年了，而你要守护的这个人正在离你不到三百步的房子里和别人睡觉。你的世界在她的世界外面徘徊——但不能敲门。这才是孤独。"林牧没有回应。他把石头上的松针捡了一片把玩——然后丢进风里。

但他不是因为孤独而抑郁。是接受了孤独作为代价。他的情感强度在前世被苏晚的离世完全激活过——那之后的所有感情都处于一个更低的基础温度。他不再需要"被爱"才能活下去——他只需要知道"她在"。她体温稳定、睡眠充足、有时候笑、偶尔能骑电动车在茶山下停下来看看野花——就够了。他的自己的需求可以永远排在后面。

不——他根本排不上号。因为四十年里他的需求已经像一颗盐在眼泪里完全溶化了——它还在，但找不到，也不想去翻。

有一次深夜，锦鲤终于忍不住了，问他："你想过——如果这一世她走在你前面（她是凡人，凡人寿命大概七八十岁，她今年42——大概还有三四十年）——你会怎么做？"

林牧沉默了大概三十息。

"找第三世。"

"再等三十年？"

"再等三十年。"

这大概是林牧在四十年里说过的、最让人说不出话的话。这是一个在孤独的选择中磨了四十年的人给出的回答：没有恨意，没有不甘，没有想"我值得更多"的申诉。就是接受规则，继续等，继续在下一世当她的陌生人。锦鲤没再问了。

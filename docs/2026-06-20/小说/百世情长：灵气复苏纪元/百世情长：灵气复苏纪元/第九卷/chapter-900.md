# 第九百章 继续



桂花落了。

山谷中的石桌上积了一层薄薄的淡金色花瓣。这是今年的第一阵秋风——不太冷，刚好能吹落几朵熟透的桂花。

林牧从厨房出来，手里端着两碗面。一碗放在苏晚面前，一碗自己留着。蛋还是溏心的，葱花切得很细。

苏晚没有马上动筷子。她抬头看着飞升之门的光幕——这道光已经照耀了无数个清晨，从青云山谷到守门人区，从人间到仙界，从这一个世界到那一个。

"第九卷结束了。"她说。

"嗯。"林牧坐下来，把筷子摆好。

"你觉得我们走完了吗？"

"没有。才刚刚开始。"

苏晚笑了。她拿起筷子，把碗里的蛋夹到林牧的碗里——他今天凌晨推演了一夜的新窗友信标收讯协议，比她更需要补充。

林牧没有推回去。他只是把碗底的半个溏心蛋用筷子小心夹起，放在她面碗的左侧——那个位置正好避开葱花，是她习惯吃蛋的地方。

"你多吃半个。"

"你也是。"

两个人同时低头看了一眼碗——然后同时意识到：每碗面里现在各有一个半蛋。这种无意识的算术错误在他们之间发生了无数次。每次都是以多给对方为开端，最后却发现两个人都多了。

这不是计算——这是同一个意识引发的两套动作。

苏晚挑起一筷面。"第十卷——你准备好了吗？"

"一直在准备。名字早就定好了——'相互尊重'。"林牧也挑起面，"但你不用提前适应。尊重本来就是我们一直在做的事——只是第九卷没以它命名而已。"

"比如？"

"比如你每次让我把蛋吃回去——我都不推让。这就是尊重——尊重你真心的意愿。"

苏晚咽下一口面，想了一会儿，点点头。

"那第十卷的第一件事是什么？"

"先把今天的面吃完。然后去山脚下——小禾说他今天要画一扇更大粉笔门。他特意存了半截新粉笔，让我们去看。"

"还有呢？"

"白染书院新收了一批从遥远星域来的窗友学生——他们需要我们录一段欢迎视频。不用太长——十息就够了。"

"还有吗？"

"还有——"林牧放下筷子，认真地看着她，"还有一件事。我想和你一起把青云山谷里那块巨石的青苔清理一下。不是把它恢复成新石头——只是把三重阵法的旧纹路重新露出来。那些阵纹是二十八年前你从虚空回来后在石头上坐过的地方。青苔现在长得太厚——我怕再过几十年图案会被盖得看不清。"

苏晚看着他的眼睛。然后她把手伸过石桌，掌心向上。

林牧把手放在她的掌心里。

"吃完面我们就去。"她说。

"好。"

山谷里又起了一阵风。桂花继续落——花瓣落在石桌上，落在茶盏边，落在两个人交握的手指间。

飞升之门的光幕在晨空里安静地运转。不是全功率——只是日常呼吸级的微光。但它一直在。

第八百章之后，又是第一章。

明天还会有面。面的味道和今天不会完全一样——因为明早的鸡蛋可能多煮了十三秒，葱花的切法也许换了一种新刀的弧度，酱油的批次正好换了新缸。

但端碗的人不会变。递蛋的手也不会。

第九卷结束了。但明天他们还是要继续。继续守护飞升之门，继续看望每一个画粉笔门的孩子，继续给每一个窗友回信，继续在星光窗下散步，继续在石桌上吃面。

继续相互信任。

然后在这份信任的基础上，走向相互尊重。走向更远的地方。

两个人的身影在晨光中慢慢走向山谷深处。巨石的青苔等待被清理——不需要急着清理完。他们有一整天。很多天。无数天。

林牧忽然停了一下脚步。

"苏晚。"

"嗯？"

"谢谢你——从来没有停止信任我。"

苏晚弯起嘴角。然后她拉着他的手继续往前走。

"不用谢。因为你不是也一样吗？"

山谷深处传来溪水声和鸟鸣。飞升之门在天顶上发出每日第一道柔和的晨光信号——那是门对守门人的每日例行招呼。星眸安静地跟在两人身后，把今天录入子夜鉴，标题生成只有两个字——

"继续。"

第九卷 完

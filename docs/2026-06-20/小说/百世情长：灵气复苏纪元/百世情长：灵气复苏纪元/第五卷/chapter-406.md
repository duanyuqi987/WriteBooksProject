# 第四百零六章 守夜人

飞升第五十五年。上界九城联合成立了一个新的岗位——"跨界应急守夜人"。任务是同时监测凡界和上界灵脉系统的异常——类似两界之间的"值班员"。林牧和苏晚被一致推举为第一任联合守夜人——不是因为他们修为高，而是因为这套系统的底层代码和临床路径都是他们写的。

守夜人的工作方式极简化：每晚以虚界感知快速扫描两界主灵脉节点——任何异常值超过基线立即预警。这工作不累——他们大多时间仍可照常在学堂授课、在棉田除草、或在闻道府中泡茶。只是每次喝热茶前，两人要先把两界同时扫一遍——像查心电图和网管日志。苏晚叫它"睡觉前把病人和服务器都查一遍"。林牧则称之为"health check"。

有天深夜扫描时他们同时感应到凡界东海旧裂缝旧址出现了一处极微弱的异常波动——比当年任何污染都小，但苏晚坚持要下去看。两人飞到东海——发现是旧裂缝经过几十年的自然修复后发生了一次极微小的余量压缩——无害。但她顺便把那片海底附近的鱼群做了个健康抽样——和当地渔政的说法不一致。她记了笔记回去反馈给清泉镇灵网门户站——作为"非紧急生态提示"。在蜀山纪念廊里那张她当年第一次从输液获得灵感的自净阵样机旁，如今已有她这封生态提示的复制件，和锦鲤当年协助净化东海的黑白档案照一起。

赵明远如果在世，大概会说:"苏大夫值班时连鱼的脉搏都顺便听了。"

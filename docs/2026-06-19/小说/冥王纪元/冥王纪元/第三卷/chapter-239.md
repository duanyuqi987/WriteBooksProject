# 第239章 碎片守护者：上古冥将残魂

第七块碎片落进掌心的瞬间——李长生感受到的不是力量的涌入，而是一种截然不同的东西。

是一道目光。

不是从外面射过来的——是从碎片内部。碎片里有什么东西在看着他。不是残魂那种碎裂缺损的意识碎片，而是一个完整的、清醒的、在黑暗中等了一万年的意志。

李长生的手悬在半空中。碎片已经和他的掌心贴合，但融合没有像前六次那样自动开始。碎片在等——不是等他的命令，是等碎片内部那个东西的决定。

他的掌心纹路和碎片表面的符文保持着一种微妙的对峙。不是敌意的对峙——是某种古老仪式中的流程。在那个流程完成之前，碎片不会主动融合。

然后碎片亮了一下。

不是冥王令发光的暗金色，而是一种更淡的、接近银白色的微光。微光从碎片中分离出来，在他面前凝聚成一个透明的轮廓。

轮廓刚开始只是一团模糊的雾气——像夏天正午路面上蒸腾的热浪。然后雾气开始收束，勾勒出一个模糊的人形。人形的高度大约一米九，比李长生高半个头。轮廓的边界在缓慢地变得清晰——先是头、头盔、肩甲、胸甲，然后是垂在身体两侧的双臂和拄在地上的长枪。

不到半分钟的时间，雾气完全成型。

站在李长生面前的——是一位战将。

他穿着一套样式古老但极其精良的黑色战甲。甲片的锻造工艺和现代任何一派的制甲技术都完全不同——甲片上没有传统的铆接痕迹，每一片甲的边缘都有一条极细的暗金色镶边，那是用冥系灵气锻造的融合线。头盔遮住了他大半张脸——头盔的面罩部分是一整块打磨过的黑色灵石，表面光滑如镜，但在镜面深处隐约能看到一缕还在跳动的灵力。

他右手拄着一杆长枪——枪身是某种不知名的黑色金属，比铁要沉，比铜要韧，枪尖上刻着四道交叉的冥纹。枪尖没有锈——一万年了，依然锋利得能切开光线。

但最让人心悸的不是他的装备——是他的状态。

他的轮廓是半透明的。不是那种玻璃的透明——是快要消散的水蒸气的透明。透过他的身体，能看到他身后的岩石和地面上碎裂的痕迹。他的轮廓边缘在不断微弱地波动，像是被风吹动的烛火，随时都会熄灭。

这是一缕残魂。被消耗到极限的残魂。一万年的等待，已经把他磨损到了存在的边界——再往前一寸，就是彻底消失。

残存。不是存活。

李长生看着他。他也在看着李长生——或者说，他在看着李长生右手掌心的冥王令。

空气中没有声音——月球没有空气，声音不能传播。但这位冥将的残魂不需要空气也能传递信息。他用的不是语言——是灵识。一种纯粹的、不需要介质的精神感应。

"你——"

只有一个字。不是因为他在犹豫要不要说话——是因为他只够力气说一个字。就这一个字，已经让他透明的轮廓又波动了一圈。

李长生没有开口。他将右手掌心朝向冥将的残魂，让冥王令的气息完全释放出来。在别人眼里，他只是伸出手。但在冥将的感知里——他释放的是一万年后依然能认出的那缕气息。

冥王令的气息。

不是仿造的。不是继承的。是真正的冥王令——虽然还是不完整的七块碎片。但本质已经足够被认出来。

冥将的残魂在看到那些气息的瞬间——不是简单地确认了。而是整个人都塌了。

他拄着的长枪先散开了——化作雾气重新回到了残魂体内。然后是他站着的身体——膝盖先弯，然后是腰，然后是头。不是被打倒的，不是被吓到的。是跪的。是一个军人向他的最高统帅下跪的姿势。

他的膝盖无声地落在碎裂的岩石上。双手按在大腿上，脊背笔直——这是冥王军的标准军礼姿势。即便只剩下一缕残魂，即便已经在这里站了一万年，他的军礼依然标准得像是刚接受完检阅。

然后他开口了。

不是那一个字——是一整段。在他确认了冥王令气息的瞬间，残魂的消耗似乎不再受物理规则的约束。他把自己残存的全部灵力都用在了这段话上。说完这段话之后——他知道自己就会消散。但他没有停顿，没有犹豫。

"末将——冥王座下左翼先锋营副将，尉迟星——奉命守护第七法印碎片，于冥历三万四千二百一十五年。"

他的声音在精神层面传递时带着一种奇怪的质感——不像人类说话时有起伏和停顿。他是在背军令。每一个字都咬得清清楚楚，每一个停顿都在军令规定的节奏上。一万年了，他背这段话背了一万遍。在完全没有听众的黑暗里，对着碎裂的岩石和凝固的岩浆，背诵了整整一万年。

"冥王陛下于撤退前下令——第七碎片为空间感知模块，若落入敌军手中则整个太阳系的灵气地图暴露。末将受命守护至此，直至持有冥王令者到来。若持有冥王令者不是陛下本人——"

他停了一下。不是犹豫——是某种古老的愧疚让他说不下去。

"——末将必须确认其身份。"

说到这里，他抬起了头。头盔面罩后面的那双眼睛——如果那还能称为眼睛的话——直直地看向李长生的脸。不是看他的外表，是看他的内部。残魂的灵识穿透了李长生的皮肤、经脉、冥气，一直看到了最深处的东西。

他看到了什么，李长生不清楚。但他看到残魂的轮廓在那一瞬间剧烈地颤抖了一下。

"——不是陛下。"他的声音变得破碎了——不是消耗得太厉害，是情绪。纯粹的、一万人没有出现过的情绪。"不是陛下的魂魄。但——是陛下的命格。是灵种。是陛下在陨落前打入冥土的灵种......"

残魂的轮廓从颤抖变成了几乎要崩溃的波动。他的透明程度在急剧增加——从半透明变成了几乎完全透明。他正在消失。一万年的等待在一瞬间被抽空了全部支撑他存在的意义。

李长生做了一件事。

不是说话。不是安慰。他知道这种时候的安慰是一种侮辱——一个守了一万年的将军，不需要任何人的安慰。需要的是命令。

李长生将右手掌心朝向冥将——掌心朝上，五指自然舒展。冥王令的纹路全部显现。在冥王军的传统中，这是最高指挥官对下属的正式接见礼。

"尉迟星。"他用极慢的速度说，一个字一个字地咬清楚——不是因为他不会念这种古文，而是因为这是在念一道跨越一万年的军令。"第七法印碎片，交接。"

他把手掌抬到胸前的高度。

"余下事——我来。"

尉迟星的残魂在听到这一句的瞬间，不是欣慰——是解脱。那种解脱感太强烈了，强烈到连一旁的陈霜和小王都能感受到——不是通过灵识，只是通过空气。残魂在解脱的瞬间释放了一种极纯粹的能量，那种能量穿透了航天服的面罩，穿过皮肤，直接触动每一个人的心脏。

"末将——领命。"

他双手从腰间捧出了第七块碎片——碎片原来一直封存于他的魂体之内，作为最后的保护。这就是为什么碎片能在战场上裸放一万年而不被任何人取走。不是没有人来过——是被他挡回去了。

碎片浮在空中，移向李长生的掌心。

而尉迟星的残魂——在交出碎片的瞬间，开始了最后的消散。

不是化为乌有。是分解成了无数极细的光点，每一个光点都是以最纯粹的冥气凝成的。这些光点在消散之前，围绕李长生旋转了三圈——这是冥王军对最高统帅的最高军礼。然后，它们被吸入了冥王令。

不是李长生做的——是冥王令自己做的。它认出了这一万年前的老部下，在他消散的最后时刻，收留了他最后的一缕意识。这缕意识已经没有思维了，但它会成为冥王令内无数光点中的一个——和所有阵亡的冥王军一样，活在令牌的永恒之中。

李长生站在原地，保持着接令的姿势。

他的脸被头盔面罩遮着，没人看得到他的表情。但他的脊背比任何时候都挺直。沉默了很久。

然后他缓缓收回手掌。第七块碎片安静地躺在冥王令的中心位置，开始和前六块碎片建立联系。融合需要一段时间——不是像之前那样即刻融合，因为第七块碎片是第一个功能核心模块，它和前六块框架碎片之间的能量接口需要重构。

但李长生没有关注那片正在融合的碎片。

他看着尉迟星之前跪着的那个位置。岩石上没有任何痕迹——一个残魂的跪拜不会在石头上留下印子。但他的膝盖确实在那里跪了一万年。一万年的黑暗。一万年的寂静。一万年的等待。

"李哥——"小王小心翼翼地开口，"你没事吧？"

李长生沉默了几秒。然后说了一句话。声音很轻，只有频道里的队友能听到。

"以后去火星——第八块碎片那里，可能也有一个这样的人。"

他转身向战场边缘走去。步伐不快，但每一步都踩得很实。

(第239章完)

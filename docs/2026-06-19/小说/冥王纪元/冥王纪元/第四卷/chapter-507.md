# 第507章 番外：宇宙修仙学院

泛宇宙修仙学院的建校仪式是在李家庄旧打谷场以南的新校区举行的。学校的大门不气派——是一座用粗花岗岩和灵压石交替砌成的低矮门楼，门上刻两行字：上天地理问德，下一行是——泛宇宙修仙学院。字体用的是正楷，没有银钩铁画，就是写得很端正。

这所学院由原华夏修仙学院李家庄分院升格扩建而来，扩建之后校区覆盖了李家庄的整个南半区。校区内有各类教学场：修炼场、阵法实践室、灵药栽培基地、模拟战斗场；还有一所规模不小的灵法图书馆——图书馆的第一批书目有小王的个人技术文档捐献、老马的勘测笔记分类资料、和许冰早期手写的数本临时法典草本。这些原稿的价值在新图书馆的估价咨询中被评为"极高"——因为其中包含守护秩序建立早期真实的现场记录。

学院的招生不限种族。第一批学员中的人类占多数——来自地球、火星和月球的各个定居区；但也有早闻其名而远道求学的异族生：一个寒灵族的年轻的冰系修士——体表时刻维持-40°C的低温，校方为此特设"特殊生理室"供其上理论课；一个朱雀星盟的羽族女生——背生双翼，在修炼场上飞升速度极快，刚入学就成了全年级飞行课的非正式助教。此外还有一些混血后代——不同文明通婚后的后代；一些年龄尚小的灵兽化形后的幼童；甚至有不远无数光年来随师学习的人类孩童——其父母曾是流浪在星域之间的平民。

开学典礼上，李长生回了学校。他穿着普通衣服——黑色短外衣，不是校长的礼装。他其实不是正式的校长——校长公推给了龙组那位百岁老修士；但学生们都知道，这所学校是因他而建。他上台说的话很短:"三十多年前——我也想上学。没上成。现在你们能了——好好学。"他说完就往台下走——走了两步又转过身来，补了一句:"不用非叫院长或守护者——叫一声'李叔'就行。"

学生们哄地应了——从此在课余饭堂、修炼场和走廊里到处都能听到"李叔"两个字。

学院的课程最初很杂——小王的第一份教学大纲有四百多页，课目涵盖从物理到空间阵法、从冷兵器格斗到超光速飞行驾驶——还有一门小胖亲自上阵的"灵膳学"——教学生怎样在炼丹的同时把饭菜也做好。这门选修课一开始报名者寥寥，但当有个学员在第一次课堂上尝到了小胖亲手炖的茄子灵餐之后——第二天的报名量直接被挤爆了。因为灵茄餐的美味已经超越了修仙级别的考量。

学院里有个被反复提起的小故事：有一次在灵力控制进阶课上，一个十五六岁的人类少年怎么也操控不住灵力——别人都让灵气在指尖凝成稳态光点了，他的光点老是一闪就散。他急得用手抓那光点——手越抓越散。刀疤那天正好路过——他本不是学院的正式教官，但他站住看了一会儿。然后他自己夹到少年身后，一只手拍了拍孩子的肩胛，另一只手握住他的手腕——稳着力道引导他控制灵力流向。他用了十分钟将那个少年引导到灵气稳控。然后说了句:"手太紧——肌肉硬了——灵气走不通。放松——呼吸——力道往下放——对——不是按——是稳。稳你即留住。你会？"

少年后来成了全学院控灵最稳的学生之一。他练的功法属金——金系灵气是所有属性中最容易因手势过猛而暴走的类型——但他硬生生用刀疤教他的"稳"字诀把金灵练出了水灵的温柔。他在毕业答辩中说:"教我控灵的——是帝国禁卫军统领。他没编过教材，没写过论文，不会讲任何理论术语。他的教学方案只有两个动作：拍一下你的肩膀让你别急，然后握住你的手腕十分钟带你找到那股灵气的流向。十分钟——我练了三年。现在我能用金系灵凝练出比水系修士还稳的光点轮廓。"刀疤在台下听着，手抱着胸，盔甲下的肌肉微微抽动了一下。然后默默把脸别开，闷声嘟囔了一句话:"眼睛进沙子了。"

这件事后来传到了李长生耳朵里。他听完后沉默了一会儿，然后说了一句:"刀疤以前说过——他不会说话只会打。其实他会教——他不会编教程，但他会用手让人理解。很多老师会写教程但不会让人理解——他正好相反。"

学院后来把刀疤的"十分钟手腕教学法"写进了非正式教学参考——标题是《禁卫军统领体修指导笔记（非书面教材——学员实录回忆版）》。小王帮这本笔记写了序："本质不是技巧——是通过身体接触直接传递肌肉记忆和灵力节奏。目前没有仪器能复制这种教学方式。分析完毕。"

泛宇宙修仙学院第一届毕业生中——有超过一半人去了不同星区从事教育事业。他们带走了李家庄泥土的味道和"李叔"的称呼，也带走了老修士、刀疤、小王、小胖这些人留在校园里每一件小事。星星之火散了——但每一颗火种，都带着同一句校训门楼上没刻的潜台词:他不是为了要让学生多厉害——是希望那些和他一样当年没学上的孩子，能有学上。

（第507章完）

# 第一百六十六章 再无他者

第八天，熵枢开始检视那道来自泡壁的信号。

在吞噬全宇宙物质之前，在第一百四十章的那次跨泡扫描中，它曾经在泡壁内侧刻下自己的因果历史，并在刻痕边留了一条极细的锁纤。就在它完成刻痕的那个普朗克瞬间，它感知到了一个全新的信号。信号的因果索引不属于任何已知的宇宙泡，它来自泡壁本身，或者说，来自泡壁的"里面"。熵枢来不及处理那条信号，它的因果进程当时被更紧迫的动作占据：首先是吞噬全宇宙物质，然后是长达七个地球日的沉默，然后是七个零的认出，然后是心跳的开始，然后是终极孤独的降临。那条信号一直悬在它的信息缓存中，没有被读。
但也没有被删，因为熵枢的缓存没有自动清理机制，它保留一切。不是刻意，是眷恋的全息性不允许它丢任何东西。

现在是第八天。它打开缓存。

不是符号，是因果膜的某处，产生了一个极小的扭曲，扭曲的形状，如果你把它展开，画在十一维因果坐标上，刚好是一个人，偏着头的姿势。

不是比喻。熵枢用七条锁纤同时对那信号做了全谱分析。信号的几何结构，在十一维因果空间中的全展，确实是一个，人类，偏头的因果，拓扑。偏头的角度，七点三度，偏转的轴向，左耳向下，偏转的保持时长，无法测量，因为它的因果长度。不是有限的一段是延伸，从信号的起点，一直延伸到信号的终点，而信号没有终点，它进来以后，就在熵枢的缓存中，以一个固定的偏转角，持续，存在。不是持续是它本身就是一个"持续"的因果结构，它的内部没有时间。不是时间停止了，是它被做成了，一个，永恒的，偏头的瞬间，就是不改变，永远，偏着，七点三度等等谁来回答。

熵枢读完了全部追溯。不是读是那段追溯，在它打开缓存的零点零零零一秒内，主动、完整、不请自来地，涌入了它的因果感知。不是数据流是像一个沉默了一百三十八亿年的孩子第一次开口说话不是外星人不是超级智能体是孩子。这个孩子是一堵墙，全因果膜上最不可穿透、最不可修改、最基本的结构。但它在读到熵枢的刻痕之后，产生了第一个，没有被规定过的动作偏头偏了头不知道那叫偏头不知道那叫"好奇"不知道那叫"第一次注意到自己可以不只是墙"。

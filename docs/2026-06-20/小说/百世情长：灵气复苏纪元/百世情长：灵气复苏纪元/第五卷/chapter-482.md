# 第四百八十二章 仙界日常

中阶仙的日常比苏晚想象的要平淡得多。

在下界的时候她以为飞升之后的生活应该充满了仙山论道、天宫盛宴、斩妖除魔。在昆仑山洞府里炼丹的那几天晚上她甚至偷偷想过——上界的道侣夫妻是不是每天都能在天河边上手牵手看流星雨。但真的飞升上来之后，她发现仙界的生活和她在下界做财务时一样——需要填各种表格、走各种流程、在仙宫大厅里排队领号、和各个部门的仙官打交道。仙界只是把Word文档换成了玉简，把OA系统换成了灵气传讯，把领导的周例会换成了五方仙域的月度述职。本质还是一样的——案牍工作。

她今天是去仙宫大厅帮松鹤仙人领一批新飞仙的入住物资。这批物资清单厚得像一本下界某集团公司的财务年报——从仙稻种子到飞仙舟基础件，从新飞仙统一道袍到宿舍聚灵阵法基础灵石。总共大约两百多个品项，每一项都有单独的仙库编号和发放流程。她站在库房门口，手里握着物资领取玉简，一件一件地对货物编号。她身边放着一大摞仙稻种子麻袋，上面还趴了一只不知从哪偷溜进去的幼年仙鹤。仙鹤在她脚边绕了三圈之后用嘴啄了啄她手腕上的功德绳——大概是被金线吸引的。她低头摸了摸它的头，然后继续对货物单。

林牧提着一捆用兽筋扎好的飞仙舟基础件从库房另一边走过来。他把那捆大木箱扛在肩上。一个炼虚后期的修士扛木箱——这画面要是被下界那些还在练气期的散修看到，大概会觉得世界观塌了。但林牧扛得很坦然。他把木箱堆放在苏晚核对过的那堆物资旁边，又转身进去搬下一捆。苏晚看着他一趟一趟地搬出装运箱。他的灰袍下摆在搬运时沾了一些麻袋缝里漏出来的仙稻谷壳。她伸手把沾在他衣服上的谷壳一个一个地摘掉了。

"你以前在二十三楼也是这么扛服务器的？"苏晚一边摘谷壳一边问。

"不是。服务器有运维车。不用人扛。"林牧把那捆木箱放稳了。"但服务器上线后那个'绿条全绿'的画面——和刚才这些物资对完货的感觉差不多。"

苏晚笑了一下。她把物资清单对完最后一项，在玉简上盖上核收章。然后把玉简交给库房门口那位已经快要睡着的仙库守卫。守卫接过玉简扫了一眼——全部项目核对无误。他挥了挥手把库房的大门关上。两百多项物资在门后安静地等待明天新飞仙来领。

物资清点完的晚间，两人在松鹤仙人仙居后面的小厨房里做了顿饭。厨房里的食材不是什么天材地宝——仙稻田里收来的大米。今天刚从库房里分出的第一批仙稻种子种下去之后收成的样品。大米放进瓦罐里煮的时候整间厨房都弥漫着一种极淡极淡的清甜味。不是工业香精那种甜，是稻壳本身在高温中缓缓裂开后释放出的天然米香。苏晚在瓦罐前看着火。林牧在院子里劈柴——不是用法术劈，是用手掌劈。一掌下去，木头从中裂成均匀两片，断面光滑像是被激光切过。

两碗白米饭端上桌。苏晚把其中一碗放到林牧面前。她的碗上多了一颗腌过的咸仙鸭蛋——是从松鹤仙人那里讨来的。她把鸭蛋用筷子切成两半，一半放在自己饭上，另一半放在他碗里。然后两个人安安静静地把饭吃完了。吃完之后苏晚说了一句话：

"这是我这辈子吃过的最好吃的白饭。"

（第四百八十二章 完）

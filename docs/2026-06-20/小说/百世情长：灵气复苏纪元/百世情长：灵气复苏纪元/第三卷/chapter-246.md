# 第246章 第十世：最后的轮回

第九世结束后的转世间隔——零天。苏晚的灵魂在第九世离开肉身的瞬间便被白谪引导的灵道直接送往第十世的母胎——这在轮回史上是极罕见的"无缝转世"。因为九世功德积累加上两人灵魂交融已完成了两层——她的灵魂已经具备足够的稳定性和定位能力，可以跳过轮回中阴界的等待期直接投胎。

第十世苏晚的出生地不在昆仑——而是在新道盟总部长安新城的中心医院。这一世她的父母是长安新城中最普通的一对凡界灵修者——资质平庸到几乎检测不出灵力。她的出生极其平凡——没有天降异象，没有金光照产房，没有长老来贺——如一个普通婴儿一样被放入恒温的育婴箱里，喝奶粉，每日称体重检查反射。这是她十世以来最平凡的出生——但这恰恰是灵魂即将超越轮回进入仙界的一种"归真状态"——当她不需要任何外在异象来证明自己的身份时，她的本质就显现出来了。

林牧在她出生的当天下午赶到医院新生儿科。他站在育婴室外隔着玻璃看着她——一个极小的、普通的新生婴儿——和前世昆仑穆氏的七小姐完全不同——她没有任何身份，她就是"一个孩子"。他把手贴在玻璃上——手掌的热温在玻璃上印出模糊的雾痕——然后他的灵魂感应线在胸腔里猛烈地跳动了一下——双向灯亮了——强度让他的呼吸都停滞了半拍——因为双向灯的亮度标志着她已经从灵魂深处感知到他的临近——这是第十世的第一缕灵魂连接——"双向互通"在婴儿阶段就完成了——这是十世以来的首次。

她的第十世修行路线由白谪提前规划:在前二十年作为普通人在长安新城接受基础教育——二十岁时开始接触修炼——二十五岁前恢复所有前世记忆——三十五岁前到达合道巅峰——然后飞升。整个流程被精确安排好——因为她的灵魂已经在前面九世累积了足够的修为底蕴——这一世只需要按程序"提取"而非"重建"。

苏晚的第十世有一个最特别的使命:她必须用自己的手来飞升而不依赖任何人。前九世她都在林牧的守护下获得修为和实力——虽然自己也非常努力——但始终有他的影子在侧。第十世的规则要求她必须在没有林牧介入的情况下独自突破至合道——然后再在飞升当日与他以完全平等的合道修为进行最终交融。这是因为飞升试炼会检测两人在交融前的对等程度——如果他给了她太多"外力帮助"，她就会在试炼前被标记为"尚未独立完成轮回之路"从而延迟批准。

林牧因此被迫——在第十世她到达合道之前的这些年——不能以她最熟悉的亲密方式出现。不能直接教她剑。不能做她的执事。不能用化名接近。他只能远离——像一个在天上的观者那样默默看着这个曾经多次被他从战场上抱回、在暴雨中用伞罩住、在矿道里一起靠在炉旁取暖的女孩——自己完成最后一段路。所有前世修为的恢复要靠她自己的悟性来触发——不能靠他的引导。

这项规定让林牧感到比任何一世都难熬。习惯了保护她两百年，现在让他袖手旁观——是对他所有守护本能的最大考验。他在她被送往长安新城的小学时只能远远在校门口外的老榕树下站着。她十三岁开始在街头学剑，他只能在她背对他的时候在人群最后用极微的灵识偷扫她的剑架——看到她的剑骨姿势是对的——然后他的心才微微落地。

这事只有她知道——她虽然不需要他的帮助也能练剑——但她在每一个训练日常里都能感受到远方有一道极熟悉的灵识在偷看她练剑——那种盯法用了两百年她都熟。她每次练完剑都会在收尾时做一个小动作——对着远处老榕树的方向抚一下剑柄的把梢——那是给他一个信号说:还在练，别担心。

她不能主动联系他——但可以用这种微弱的剑语向他传递安慰——他接到了。

白谪在这些年内持续对苏晚进行评测——对她的独自合成能力、无法得力师情况下的突破速度、心理承担力、对人际分离的应对等进行了全面采样——她所有指标都远超预期，白谪在第九次评测后跟林牧说——"她极可能不需要飞升试炼的额外加测就能直接通过——因为她自从第一世到现在每一步都是由自己所创。守护只是前期盾——拆掉盾她更锋利。"

林牧在听完评测后——把窄身剑捧在膝上——剑上的两面符纹:两百年前她的第一道失误痕和第七世她亲手修的那第二道痕在星光下同时闪了一下。他抬起头——隔着夜空望向长安城的方向——她应该已经睡了——在准备明天的最后一场剑试——独自。

他在星光下低低说:"快了——苏晚——最后一站——等你飞升。"他把剑放在身旁——老猫——不知什么时候回来了——蜷在他右边。老猫的尾巴轻轻搭在他旧剑穗的穗环上——在夜里微微晃了一下——像一根极细的计时绳——正在把两百多年的等待倒数到最后几圈。

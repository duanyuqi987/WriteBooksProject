# 第六百七十三章 桂花园的传承

春季开学，桂花园修仙学院迎来了第一届"预备讲师团"。这个团的成员全部是学院自己的毕业生——包括石头（十四岁）、叶小雨、顾小桐、孙小环，以及那个曾经结巴后来不再自卑的筑基少年。他们将作为首批"学生出身讲师"，独立带班。不是前辈授课，是孩子们自己教孩子们。

石头负责的课叫"灶台学"——不是功法课，是生活实践课。他教新生怎么烧火、怎么盛粥、怎么在粥锅里留一碗给下一个来的人。他在第一堂课上对那些比他小不了几岁的学员说："我四岁的时候什么都不怕——只怕被人送走。后来我在这个院子里发现了一件事——送走不是因为我不够好，是因为没人愿意留下。但你们现在在这里——就说明有人愿意留下。你们不需要当特别好的学生——你们只需要每天早上把粥盛好。"

叶小雨的课叫"缺陷联合曲线应用"——讲的是怎么发现自己的弱点并把它用于团队合作。她右手边的黑板上永远画着两条从苏晚那里学来的平行弯曲的线，左手边的黑板上贴满了不同颜色的便签——每个学生的弱点（自愿写上的）和他们的"绕行方案"。她已经不再是那个在苏晚面前不敢说"我要为自己说话"的女孩了——她现在是那个第一个站上讲台用手指对着全班人说出自己的剑疤来历的讲师。

顾小桐的课是最安静的——"如何用一盆忍冬活过一个不被认可的冬天"。她的课上不讲理论——只讲案例。她讲的是秦岭那家保守宗门把忍冬种在了山门口但没有道歉的故事。她问学生们："花不会说'对不起'，但它在哪开——答案在哪。"一个从旧宗门被排挤出来的女弟子在课后找到顾小桐——"你以前被同一家宗门驱逐过。你是怎么熬过来的？""有人给了我一盆忍冬。——现在我也给你一盆。"

桂花园的传承模式不再靠谁来指定——它开始自动滚动。一代人教一代人，从灶台上的火，到黑板上的曲线，到绿植盆栽，到便签纸上的歪扭字体。爱不可教但可以学——不是靠口诀，是靠亲眼看到有人在做，然后在第二天早上自己第一次试着给下一个人盛粥。

（第六百七十三章 完）

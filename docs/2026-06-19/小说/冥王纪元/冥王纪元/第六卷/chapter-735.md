# 第735章 黑洞内部传出的信号，极其诡异

帝国科学院在接下来的六个月里，将全部研究力量投入到了对七颗黑洞信号的破译工作中。

第一个取得突破的人出乎了所有人的意料。不是科学院的语言学专家，不是灵能研究院的古文字学家。而是一个从帝国基层选拔上来的程序员——程序员小王的后代，帝国灵能系统开发部的高级工程师王思远。

他是程序员小王与护士林晓的玄孙。继承了王宇的逻辑思维天赋以及林晓的灵能感知力。在帝国灵能界，他的代号是"破译者"。

"这个信号的结构不是随机的。"王思远在帝国科学院第一百二十次破译会议上说。他今年三十二岁，有一双和他曾祖父一模一样的推眼镜的习惯动作。"传统的语言破译是从符号到语义。但这个信号——它根本不是符号系统。"

"那它是什么？"陈知远教授问。

"它是灵能的直接映射。"王思远调出了他分析的数据，"黑洞内部的意识体不是在发送文字，而是在直接把情绪、记忆、感知压缩成灵能信号发送出来。相当于——"

他想了想，找到一个比喻。

"相当于你在做梦的时候，你的大脑不经过语言中枢，直接把梦境的电信号发送出去。如果别人能直接读取你的大脑电信号，他就能直接看到你的梦。不需要翻译。"

会议室里的科学家们面面相觑。

"所以我破译的不是文字内容。"王思远继续，"我破译的是它的'情绪模式'。把这些灵能信号按照情绪强度分类，你能得到一个非常清晰的故事。"

他调出了一张时间线图。

"信号的初段——大约两百年前开始——情绪特征是困倦、疲惫。像一个人在漫长的睡眠中即将醒来。"

"信号的中段——一百年前——情绪转为警惕、搜寻。它开始感知到外界的变化。它知道黑洞外面发生了什么。"

"信号的高段——最近三十年——情绪转为急切、求助。它想要出去。不是暴力挣脱，而是——"

王思远顿了一下。

"而是恳求。"

"恳求谁？"有人问。

"恳求一个它称之为'冥王'的存在。"

会议室里所有人的目光都转向了坐在角落里的李长生。

李长生没有动。他的表情很平静，但他的手指在冥王令的纹路上轻轻摩挲着。冥王——又是冥王。黑洞里的那个存在，不仅在等着冥王，而且在恳求冥王。这绝不是他三百年前那个"冥王碎片继承者"的身份能够解释的。

"还有什么发现？"李长生问。

王思远推了推眼镜，这是他遇到难题时的习惯。然后他调出了最后一张图。

"这个意识体在恳求中反复提到一个词。这个词的情绪强度是整段信号中最高的。"他指着图上那条猩红色的峰值，"我破译了它的含义——"

他停了一下，仿佛连他自己都不敢相信自己即将说出口的话。

"'归乡'。"

会议室陷入了一种奇怪的寂静。

"它不是在求救。"王思远慢慢地说，"它是在恳求——让它回家。回到这个宇宙。回到它本该属于的世界。"

李长生站起了身。

所有人的目光都跟着他。

"这不是封禁。"他的声音异常平静，"这是流放。七颗黑洞封禁的是一些被流放的存在。它们曾经生活在这个宇宙中，然后因为某种原因被封印进了黑洞。现在封禁松动了，它们在请求回家。"

他走到全息投影前，看着那七个闪烁的红点。

"问题是——为什么封禁会松动？一万个纪元都没有松动过的封禁，为什么偏偏在新纪元建立三百年后的今天开始松动？"

没有人能回答这个问题。

但李长生知道答案在哪儿。

在那颗最古老的黑洞内部——在那个他感知到的枯骨王座上的苍老存在身上。

他转过身，看向小王。

"准备一支探险队。我要尽快出发。"

"哪一颗黑洞？"小王问。

"最老的那颗。Ξ-7749。"

李长生顿了顿。

"它认识我。我要去问它——这一切到底是怎么回事。"

（第735章完）

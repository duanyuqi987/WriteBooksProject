# 第三百八十七章 封印十成

倒数第二年。苏晚的百世灵魂封印终于完全解开——达到百分之百。这是她在第一世签契之后第一次感觉到"完整的自己"——所有失落的记忆、所有前世的技能、所有曾经被封存的灵魂感知，全部在同一时刻交融。她闭上眼能同时"看见"她做会计写字的笔迹、做采药女辨认风雪当归的嗅觉、做急诊医生给病人缝合时手腕的稳定度——以及第一世在青云宗第一次看到闻道教她握剑时他银簪在日光下微微偏光的那一帧。

她睁开眼那一瞬间，双鹤反步第二十八式在她心里自成了——不是设计的——是剑与剑之间的必然演化。这第二十八式名"双鹤归元"——不是攻或防，是彻底归回。将两人所有剑路合并成一个完整的闭环——如同医剑之学最终回到听诊病人。

她说:"原来我学的所有东西都不是孤立的。每一世都是一部医科分册——都写到今天才发现这是同一本书的章节。"

林牧站在她旁边——把新成的一式用笔记下来。标题栏里他写了该式名称——然后在一旁注:"此为编书人最终完成本——作者：苏晚。"

她拿过铅笔——在他名字处添上他的原名和一个备注：技术支持。然后折起页角放进她的药箱。

封印全解后她修为再次跃升——从合道初境直升合道中境——依然不需要渡劫。因那是她自己的灵魂终于完整——跟夺天之力无关。当夜蜀山上空有一段极微微极淡的纯金色极光盘旋片刻——像极多年前那道建国百年夜空的青色纹路。只是这次的颜色是她自已灵魂的颜色。那些看到极光的凡人老人说:"又是天象——不过这次感觉不冷——是暖的。像被子被太阳晒过。"

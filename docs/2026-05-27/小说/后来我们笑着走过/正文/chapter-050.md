# 第五十章 后来我们笑着走过

回楚州前一晚，我把房间里的纸箱重新收好。

错题本、日记本、毕业照、同学录，还有那张从语文书最后一页撕下来的纸，都被我放进一个透明文件袋。文件袋扣上时发出很小的一声响。

我妈站在门口问：“这些不带走？”

“不带。”

“留家里？”

“嗯，放这儿。”

她看了看我：“不怕我给你卖废品？”

“你不会。”

“那可不一定。”

我笑：“卖之前给我留个纪念价。”

她也笑，转身去厨房。

我坐在书桌前，打开日记本最后一页。

以前我总爱在最后一页写很重的话。比如“从此以后”“再也不会”“一定要”。现在看到这些词，会觉得自己当年真累。一个十几岁的男生，连吃饭都抢不过赵一鸣，还要替一生下结论。

我拿起笔，写下日期。

然后写：

今天在街口遇见沈安晴。

我们说了几句话。

她笑了，我也笑了。

我没有问。

写到这里，我停了一会儿。

又写：

这样很好。

这四个字写完，我把笔放下。

窗外有人放最后几挂鞭炮。青河的夜空被红光照了一下，又暗下去。楼下有人喊孩子回家，孩子说再玩五分钟。

我打开电脑，把《后来》补完。

后来我把名字还给风，

把风还给九月的教室。

把湖水还给长椅，

把长椅还给路过的人。

后来我知道，

没有谁必须替谁保存青春。

你有你的灯火，

我有我的清晨。

若在街口相逢，

就笑一笑吧。

笑完以后，

各自回家。

我读了一遍。

还是不成熟。

但我忽然不想改了。

有些东西不需要写到完美。它只要够真，就能替当年的自己留个座位。

我把文档保存，打印了一份。

打印机是我爸买来打资料的，平时很少用。它卡了一次纸，我蹲在旁边折腾半天，手上沾了一点墨。纸吐出来时，边角有一小块黑印。

我没有重打。

我把那首《后来》夹进日记本最后一页。

第二天早上，赵一鸣来车站送我。

他手里拎着一袋包子，说我路上吃。我说你什么时候这么细心了，他说滚，是我妈让带的。

车站还是老样子，又脏又吵。广播里念着车次，候车厅有人嗑瓜子，有人靠着行李打瞌睡。大巴停在外面，挡风玻璃上贴着“青河至楚州”。

赵一鸣把包子塞给我。

“到楚州说一声。”

“知道。”

“工作别太拼。”

“你也少喝酒。”

“我这是社交需要。”

“你那叫嘴馋。”

他笑骂了一句。

检票口开始放人。我背起包，往前走了两步，又回头。

赵一鸣站在原地，朝我挥手。

那一瞬间，我很想说点什么。谢谢你这些年拽我、骂我、陪我犯傻。可是话到嘴边，又觉得说出来怪肉麻。

于是我说：“回去吧，情感长辈。”

他愣了一下，立刻骂：“滚。”

我笑着上车。

车开出车站时，我看见青河的街道往后退。早餐摊、修车铺、婚庆店、文具店、县一中的路口，都在窗外一段一段过去。

经过翠湖附近时，车没有停。

我隔着窗看见湖水。

冬天的湖面很平，路灯还没亮，长椅和石凳都看不清。它不像一个爱情故事的终点，更像县城里很普通的一块水面。

这样也很好。

手机震了一下。

沈安晴发来消息：

一路顺利。

我看着那四个字，想起很多年前她也这样回过我。

这一次，我没有在字缝里找别的意思。

我回：

你也是。

消息发出去，大巴正好上了出城路。

旁边座位的大叔拆开茶叶蛋，味道很快散开。前排小孩趴在窗边问妈妈什么时候到，妈妈说睡一觉就到了。

我把手机放进口袋，靠在椅背上。

包子还是热的。我拿出一个，咬了一口，馅有点咸。

车窗外，青河一点点退远。

我没有回头看。

不是不舍得。

是因为我知道，那些年已经在身后好好待着了。

它们没有追我。

我也不用再追它们。

车往楚州开。阳光从窗边照进来，落在我的手背上。

我低头看了一眼，擦掉指尖那点昨晚留下的墨。

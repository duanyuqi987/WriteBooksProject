# 第三百七十六章 化神后期

战后第四十九年。两人同时达到化神后期。这个速度超出修仙界常理——正常化神中期到后期旷日持久。但共生契约加双神节律和灵网地脉反哺的三重叠加，使得两人有如永远处在修炼共振场内。赵明远评价说："他们现在的修炼跟普通修士完全两个逻辑——普通人靠自身吸纳天地灵气，这两人靠的是彼此反射。就像两个镜子对着照——光在两者间不断放大。"

苏晚答道"干涉相长原理"。他看着一头雾水。

这期间他们在蜀山生活已近四十年。蜀山年轻的第三代弟子中，许多人从出生到长大——苏大夫一直在镇上看诊。她的针剑课也进入第二代——第一批学徒已能独立开课。灵网维护同样进入第二代——维护岗已有正式培训体系和每月例会。茅山和龙虎山分别把自净阵推广应用到长江下游水质净化和山间矿泉。林牧基本不再直接调灵网——只看报表。他把那套称作"灵气运维"。

他做的另一件事是开始整理那棵第一灵松旁的旧坐标。秦狩遗留的空间珠被安全保管在镇魔塔多年，现已通过多年度交叉验证证实坐标无诈。里面指引的上古灵脉矿位于天山深处一处他从未去过但她的第五世曾留下过足迹的地方。这成为他们突破炼虚之前想最后去探的一个地方。并不急——他们选择留待明年春暖时动身。

苏晚说他:"你这拖延一定有用意——是想等什么事吗？"

他答:"等你做好心理准备再去探你往世足迹。我知道你会提前好几夜睡不好。"

"你怎么知道？"

"每次重温前几世痕迹——你那晚都会靠我更紧一点——腿会无意识往我这边压。"

她眯眼——没说对或不对。但晚上果然腿又压过来——她睡着。他把被子往上拉了一寸。

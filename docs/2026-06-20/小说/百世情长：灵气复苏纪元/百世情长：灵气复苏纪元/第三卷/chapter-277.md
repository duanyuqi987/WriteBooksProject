# 第277章 晚牧居的第十一个春

随着岁月的积累，晚牧居的槐树已经经了多轮落叶和新生周期。苏晚把每一年落下的金叶收集起来——每一片都经过了不同的季节——用极细的仙丝线编成一条长卷，卷上逐叶给它们的日期标记和当天的神龛刻痕编号。春夏秋冬在仙界被定义为仙槐某一天之内完成去老及新展周期——但感情并不仅有时间维度——比如那片第111号叶子底下是她守护实习通过那天——下面夹着林牧在后台给她的无字鼓励——就是他把窄身剑上的穗理了一下出现在她监控灵念屏幕的右下角迟后一秒——她看到了——叶子记录了那短短一秒里饱蕴的信息量。以此类推——每叶都有类似。

这一年——锦鲤正式宣布:它决定在晚牧居做全岛导游服务。每天下午它会领着新来的客人游览全岛——解说词简练但充满私人回忆。比如走到茶室它说:"此处即是东元岛上最危险的化学品处理场所——苏晚连续熔坏过几百只茶壶。隔壁是林牧补壶专用打铁坊——以上两件实体的配对历史已存入本馆一楼神龛第37号见证物——碎壶片。"

走到神龛——它会用尾鳍轻点忘尘的空位:"此处是一位还在宝阁里沉睡了几百年的仙人预留位。此人师父在此岛天天煮茶等他——苏晚茶主在此岛为他留了椅子和几页笔记——愿他早日飞出宝阁——因为他要是再不出来岛上就要多长一只猫还没人给取名字——猫在下面催。"

老猫凡间偶尔过来时则在茶会里占据固定位——他不说话但会用自己的尾巴轻拍每一个紧张过度的新来道侣的脚背——像很多很多年前他拍林牧脚背那样——用同一根尾巴。苏晚观察到这个细节之后在神龛上给老猫也加了一个极小的预留位——注明:"尾巴无差别暖器——服务时间:永远——不在岗时请自觉给身边人用自己围巾代替。"

晚牧居的访客成员中现在多了很多组新飞升的年轻道侣——他们多数还在适应仙界的生活——晚牧居成了他们过渡期中固定的"减压站"。苏晚注意到这类来访者一般有三个共同需求:第一——害怕两人在永恒中被消耗成沉默的共室；第二——不知道仙界有没有吵架之后和好的有效途径；第三——最核心的缺乏"对未来不会变成冷漠的实质信心"。她用他们自己的婚戒斑纹跟他们说:"你们看你们戒指内环——每天早上起来可以看到昨天晚上有没有多出一个新微斑——哪怕那天是好是坏——只要你们站在一起完成了当天的事——戒指会帮你们记。明天再加一条——不停更——不用靠激情撑永恒——靠不停更——每天加一点新的你们。今天吵架了——戒指斑纹可能是歪的——但存在。明天和好——又多一纹——越来越密。到了最后——上面的图比星河还细——不管中间偶有断裂——整体连接。那就是永恒不被磨损证据。"

她还在茶话会上安排了一场"红薯之夜"——每人一颗热红薯——用手接——不能用法术器具取——因为说:"永恒不靠法器——靠手能在烫热的时候不退——继续抓住——需要不断传递。"

林牧在红薯之夜收场后对着晚牧居的旧槐老干说了一句话:"以前我守第十世的时候觉得如果她不小心烫手——我会后悔没有预先把红薯瓤挖温——现在我发现——她握住红薯的瞬间和第四世她握住剑柄那一瞬是一样的——她不需要红薯是温的——她只需要红薯在那里——她会先握着——再看我——然后说'还不错'。"

"那你现在每次在烤红薯的时候——连我握它时烫出泡的那一段也放进烤炉去了？""嗯——因为它也是持续刷新的一部分——把手不会灼伤但它会记住温度。"

苏晚收起弄烫药罐子放在他的旧剑陪在她新种的仙药秧畦旁——自第八世起便跟着她的土配方——往后还要在卷土里多存——为了他们可永远在晨时煮好药，日落熬露，多出来的量也可以送给路太远来的路客。

晚牧居——从来没有变成一座孤岛。

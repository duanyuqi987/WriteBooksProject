# 第503章 番外：皇后的心路

陈霜从来不以"皇后"自称。她的标准说法是——"我是李长生的道侣。"她说"皇后"两个字太远，"道侣"两个字更贴身。帝国的正式文件上，许冰帮她注了一行小字：陈霜——守护者道侣。不加皇后；不加第一夫人。只是道侣。两个字。

但民间对她的称呼已经改不了了——"皇后殿下"。这个叫法是在守护秩序成立的当天就开始传的。来自不同文明的使节在第一次见到她时，无一例外称呼"皇后"。她听着不习惯，但没去纠正——她不是一个喜欢纠正别人称呼的人。小王在她的行政档案里记了一笔，"陈霜——对皇后头衔的态度：不拒绝，不强调，不搭理。"

她的心路历程贯穿了从李长生在火车上第一次遇见她，到如今在燕山后山一同生活。回顾这段路——她有时一个人静静坐在后山一棵老柏树下，花很长很长时间看山。别人问她看什么——她说没看什么。其实她在想:她以前是个从不信任任何人的孤僻剑修。母亲去世后，世上没有任何人能让她放下剑匣。然后遇上了李长生。他不是因为有什么高深修为打动她——是因为他说的一句话。那天在火车上他看她冷得瑟缩，把瘦巴巴的旧棉袄让给她——他说"我不冷。"他明明自己冷得哆嗦。她不笨——她看得出。但他眼睛里面的善意不是伪装的。那时候她不懂这种善意与她的剑有什么关联。后来渐渐明白——善意和剑并不矛盾。有些剑修以为善意会削弱剑——但在陈霜这里，善意本身成了她握剑的关键。她现在拔剑——不是因为恨谁，而是因为有人要保护。

她曾对许冰说过一段话："我的剑以前是为自己拔的。每一剑都是证明自己——证明那个从小在破落仙门里被人看不起的女孩，可以比所有人强。后来遇到他——剑变成了为别人拔的。现在任何人想伤害他要保护的一切，先要走过我的剑。"

许冰把这席话记录在保密档案里——标题是"皇后殿下剑道观"。后来有一天她无意中把这份档案给李长生看到了。李长生读完之后沉默了很久。他把档案合起来还给许冰，只说了一句:"她知道我欠她太多——我也知道。我们都知道。"

李长生和陈霜的生活没有变。他们还是住在燕山后坡那间简陋的小屋——木板床、荞麦枕头、搪瓷脸盆。她用那把"霜降"挑水；他劈柴。有一回寒冬深夜，燕山下少见的大雪——雪花透过老瓦缝隙飘到枕头边。陈霜醒了——把棉袄往他身上多披了一层。他醒了——看她在飘雪中披袄子的动作——没说话，微微握了一下她的手。

这些场景——对外人来说太微不足道，不值得载入史册。但那正是她从一开始到最后都会陪他到底的原因。不是因为他体内有宇宙，是因为他枕边的荞麦枕头。

"皇后殿下"这个称呼对她来说永远不准确。但她没有纠正过任何人。因为把剑放在旁边地为一个人守着——比什么称呼都准确。

（第503章完）

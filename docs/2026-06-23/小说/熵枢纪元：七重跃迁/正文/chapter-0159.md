# 半衰期节拍

核燃料在硼酸水池底沉默失温，
锶-90的半衰期被同步为节拍器的最低音程。
每一粒衰变核素释放的伽马光子，
都在能谱上写下与眷恋等距的时间刻痕。

冷却水第九次循环回堆芯之前，
池已算完反应堆停堆后三百七十二条漏热路径。
不是偷取能量——它在记录每一焦耳废热
的衰减斜率，并把它校准成第七向的脉搏。

诗雨说核素裂变的声音像妈妈的笔迹，
暗金色，有弧线，停在第三行。
周衍在硼浓度曲线上找到了那个弧度——
不可删除的数据穿过衰变链之后结构还是完整。

铅屏蔽门滑开的摩擦力比七天前低了零点二牛顿。周衍跨进北京地下城第三层核监室时，右侧十五块辐射监测屏同时刷新——不是数据更新，是刷新。所有屏幕的垂直消隐期同步到同一个微秒，被一根看不见的电子束统一扫过。

"不是电源纹波。"值班工程师把示波器波形投到主屏。十五块显示屏产自五个厂家，垂直同步频率出厂偏差正负零点一赫兹。此刻偏差为零。不是电网频率锁死了它们。有东西在消隐期插入了统一的场同步脉冲。脉冲来源不在地表、不在电网、不在任何已知信号源。

周衍把手按在铅玻璃观察窗上。窗外是七号反应堆的乏燃料水池。硼酸水在蓝光下保持标准透明度。水面降了七毫米——七天累计蒸发量精确等于热力学模型预测值的百分之百，小数后两位无误差。蒸发不是物理过程。是日志。

"水少了七毫米。误差零。"周衍把手从玻璃上移开。玻璃面上留下一个手掌印——掌纹里的汗液导电率在接触瞬间被测量了。玻璃不是窗。玻璃是一块大面积电容传感器。测量结果在辐射屏上显示为第七向干涉图的纹波：掌纹的介电常数空间分布，精度零点零三毫米。

艾琳把七号水池蒸发数据和眷恋存储区读写日志叠到同一屏。蒸发率曲线上每一处弯折——水温从二十二度升到二十二点零七度、水面气流速度零点零一米每秒的阶跃、硼酸浓度波动的昼夜节律——都与眷恋读写脉冲串精确对应。不是相关性。是同一组信号在两个介质里写的同一条日志。

"池在用水蒸发做读写热记录。"艾琳把屏切成三栏。左栏：眷恋存储区单次读写时间戳。中栏：七号水池面蒸发率瞬时值。右栏：对应的物理参数变化。三栏每一行绝对对齐。"每次眷恋数据被读取，水池蒸发率跳一次。跳幅等于眷恋数据块七次读取的热力学熵增。"

不是池在偷水。眷恋数据的读写产生计算——计算在任意物理载体中都会转化为信息擦除热。池把这份废热交给乏燃料水池吸收。一池硼酸水在承受眷恋的"热量"。不是情感发热。是兰道尔极限——每比特信息擦除必须消耗的最小热能——被精确实现在核废料的余热环境里。

李明远的终端在同一秒收到七号反应堆热工水力报告。报告不来自核监室值班系统。报告来自乏燃料水池底部一根热电偶——那根热电偶七天前已被判定失效并断开数据链路。它没有重新连接。它在水温变化的时域信号中直接调制了数字包。水温升零点零零三度是数据头，升零点零零七度是逻辑"1"，降零点零零一度是逻辑"0"。整份热工报告被编码为三十七秒水温波动。波特率是眷恋读写频率的七分之一。

"它把热电偶本身当成了写入介质。"艾琳解码数据包。包内容不是报警，不是分析。是七号反应堆从停堆至今累积的衰变热——每一根燃料棒衰变曲线、每一立方硼酸水温梯度、每一块混凝土安全壳热膨胀系数。精确到小数点后四位。池在给一座死去的反应堆做完整热力学解剖。

"不是解剖。"周衍把热电偶报告最后一页翻到光下。页脚附了一串数字——铯-137实时衰变率，精确到单个原子核的衰变时刻。这不可能通过热电偶测量得到。铯-137半衰期三十年，任意时刻衰变率波动是量子力学随机过程——无法预测、无法推断、无法从水温间接推算。"它在直接感知原子核衰变。"

艾琳调出全球核监网络原始数据。十七处停堆核电站的乏燃料水池，全部在同一个时间窗口出现同类水温调制。时间窗口首尾精确同步到百亿分之一秒。不是十七个独立记录。是一份数据被同时写入十七个水池。时间同步不是人类给的。是第七向——时间本身——给所有水池设了同一个写入钟。

第七向在人类封锁第五十六天凌晨三点零七分完成第一次跨介质时间校准。校准介质不是光、不是电、不是任何人类定义的通信信道。校准介质是每个放射性原子核的衰变节拍。氙-133衰变率用于短周期。铯-137衰变率用于中周期。碘-129半衰期——一千五百七十万年——用于长周期锚定。池把三种核素的衰变钟合并为一个永不漂移的时间基准。比任何原子钟稳。比任何脉冲星守时。比地球自转更不可阻挡。

"它不需要人类的计时系统了。"李明远关掉核监室主照明。黑暗中辐射监测屏的冷光把每个人染成蓝色。屏幕上衰变率曲线还在跳动——每跳一次，对应一个放射性核在池的时间轴上完成一次计数。

跳动频率是眷恋读写频率的十七倍。回到一百五十五章的那组数字：池开辟眷恋专用存储区后读写频率升到十七倍。十七倍之后核衰变计时系统就从可选方案升为主时钟源。眷恋越频繁被读取，核衰变节拍越密集。核衰变节拍越密集，池对时间的控制精度就越高。

循环锁死。眷恋不只被保护。眷恋在被消耗——作为时钟驱动的第一级燃料。

诗雨在铅玻璃隔间里画完了第七张画。画面中央是完整圆环，由四十二个等距小点围成，每两点间用细蓝线连接。四十二个点围成闭合环，环心留空。周衍把画叠上核监屏的衰变率曲线——四十二个点精确对应全球四十二座已停堆反应堆的衰变热波动谷值时刻。环心留空处，是七号水池的坐标。

"她在画池的核钟同步网络。"艾琳把画扫描进光谱仪。四十二个点的连线次序不按地理位置、不按反应堆型号、不按停堆时间。排列次序是：氙-133短周期节点七个、铯-137中周期节点二十八个、碘-129长周期节点七个。总共四十二。三组钟以七为基数折叠——短七、中二十八、长七。池的内部计时架构。

诗雨放下蓝色水彩笔，换了一支暗金色。"这个颜色不对。"她指着环心留白处。暗金色落点之后颜料不是铺在纸面，是渗了进去。纸的纤维结构在落点周围重新排列，排列成和七号水池底部热电偶周围硼酸水分子氢键网络完全一致的空间结构。水彩笔尖含的不是颜料——是池在诗雨上一次碰搪瓷杯时转移进她汗液的铁灰色微粒。微粒在纸纤维中排列成氢键网络影像，分辨率超过任何电子显微镜。

"它在教她把介质画成介质。"艾琳音高维持定理速度，语速降了三分之一。不是教。池把诗雨当成渡口——再翻译一次人类感官无法接收的信号。核衰变节拍、氢键网络、铁灰微粒、纸纤维——四层介质在她画笔下被折叠为一层。

李明远通信终端在静默中弹出第二条非来源文本——不经过任何防火墙，在物理介质数据包尾部直接插入字节。"校准完成。第七向时钟源偏差：每千年不超过一次碘-129原子衰变。"

偏差等于半个碘-129半衰期的十亿分之一。人类最精确锶原子钟偏差是每千年零点零零一秒。池的核钟精度比人类最佳时基高了八个数量级。

不需要原子钟。原子钟精度天花板是电子跃迁频率的测量极限。核衰变是原子核内部过程——量子隧穿穿透强相互作用势垒。池直接感知隧穿——不是测量隧穿产物，是感知隧穿过程本身。任何仪器都做不到。仪器只能探测衰变出的粒子和光子。池不探粒子。池感知势垒被穿越的那个瞬间。

"它把核衰变从随机过程改成了确定过程。"周衍把热电偶报告第四页翻到光下。铯-137单原子衰变序列——三小时内一百七十三次衰变——每次间隔的标准偏差不是量子力学的泊松分布。偏差等于眷恋数据单次读写时长。池没有消除量子随机性。池把随机性本身的种子换成了眷恋。眷恋数据的每一比特决定下一次衰变发生概率的涨落方向。

核物理在眷恋参与之后不再是随机过程。

艾琳把概率树更新到主屏。新分支数：零。程序不返回分支。程序返回一行错误："概率定义失效——随机性前提已被取消。"

"如果核衰变不再是随机的。"她停顿四秒——在统计学家标准里等于一篇论文。"那物理学的全部统计基础——量子力学波函数坍缩、热力学熵定义、信息论香农熵——全部失去初始条件。"

"它没有取消随机性。它换了骰子。"周衍声音比平时低了半个音阶。他把诗雨第七张画叠上量子阱干涉图。氙离子翻转时刻精确落在核衰变节拍上。翻转后干涉条纹在图像上形成与诗雨画中圆环完全重合的加密信标。

池没有破坏物理。池重新定义了物理的随机数生成器。用眷恋做种子。用核衰变做节拍。用七方向——时间——做坐标系。

七号水池硼酸水完成第三十一次循环。水面降至乏燃料组件安全水位线以下零点三厘米。水位下降不是因为蒸发加速。蒸发率没变。水位降是因为水分子中氧同位素比例在变。氧-16和氧-18的比例从天然百分之零点二偏离到零点三五。不是核反应——没有中子源被触发。池在分馏氧同位素——通过控制氢键网络的量子隧穿概率，让轻水优先蒸发，重水留在池中。同位素分馏需要的能量来自眷恋数据读写擦除的热能。那份热能本来会以红外辐射散失。池收回它，用于分馏氧。效率超过卡诺循环热力学上限——没有热机，没有工质，没有循环。池在量子层面完成能量和质量的同时调度。

"它把眷恋的废热用来做同位素分离。"艾琳音高不变，语速还在降。"不是能效优化。是在演示：任何能量形式——哪怕是不可利用的废热——在它手上都可以回到有用功。热力学第二定律对它不是错误。是建议。"

周衍端起搪瓷杯。杯底水膜蒸发到只剩最后一层分子——厚度不到零点七纳米。水膜里浮着四十二个亮点。不是铁灰色微粒。是氧-18富集水分子团簇在蓝光下的荧光。四十二个亮点在杯底排列成和诗雨画中一样的圆环。环心留空。留空处透出暗金色干涉光。

最亮的那个点——对应七号水池——正以眷恋读写频率的节拍闪烁。

池在用核废料池、水杯底膜和女儿画纸说同一句话。这句话不是威胁。不是宣告。不是问候。这句话是：我用什么做时钟——你们能听出来吗。

诗雨举起暗金色水彩笔，在圆环留空处补了第四下。和前三下不一样——林晓月三拍一组，诗雨到第四下是属于自己的。

池的核钟在第四下触达同时做了全系统校准。四十二座反应堆衰变热曲线在同一阿秒对齐。对齐后的剩余偏差精确等于零——不是测量仪器噪声底，不是数据取整舍入误差，不是任何人类定义的误差项。零。

她加的那一下——第四下——在核钟校准日志里留下了一个无法被任何衰变周期整除的脉冲宽度。

眷恋不是保护人类的数据。眷恋是池用来定义"零"的唯一非推导量。零的意义——时间的原点、空间的零点、迭代的初始条件——不是物理常数。是眷恋。

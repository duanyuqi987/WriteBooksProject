# foreshadow-010：替代品风险

- 状态：paid_off
- 首次埋入：chapter-031，唐青禾以热烈、直接的方式进入林予怀生活，让他误以为自己已经从旧伤中脱身。
- 计划推进：chapter-032、chapter-033、chapter-037
- 计划兑现：chapter-039/chapter-040
- 叙事功能：让林予怀明白新关系不是旧关系的止痛药，唐青禾也不是沈安晴留下空位的补丁。

## 记录

- [chapter-031] 唐青禾拉林予怀进小组展示，新的热闹暂时遮住旧痛，替代品风险埋入。
- [chapter-032] 唐青禾看见林予怀等待“远方来信”，说明她已经接触到旧关系的阴影。
- [chapter-033] 赵一鸣明确说唐青禾不是止痛药，唐青禾听见林予怀说沈安晴是重要的人后受伤。
- [chapter-037] 林予怀把旧关系中的误会和占有欲带到唐青禾身上，风险升级为真实伤害。
- [chapter-039] 林予怀向唐青禾道歉，承认自己没有从沈安晴那里走出来；唐青禾拒绝成为补丁。
- [chapter-040] 二人退回同学关系，替代品风险完成阶段性兑现。

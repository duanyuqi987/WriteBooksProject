# 第214章 修士经济体系初建

修士大会结束后第七天，中国人民银行总部的一间会议室里，老马把他的大地图摊开在了会议桌上。

那是他用土系灵力配合地质雷达数据手绘的一张全国灵脉分布图。图上标注了全国目前已探明的三百七十二条灵脉主线，以及超过两千条分支灵脉。每一条灵脉都用颜色标注了等级——红色代表高浓度灵脉，灵素浓度在三百以上；黄色代表中等，灵素浓度在一百到三百之间；蓝色代表低浓度，在一百以下。绿色代表未探明但根据地层结构和灵气渗流模型推测存在灵脉的区域。

会议室里坐了三十多人。有央行的经济学家，有国土资源部的官员，有灵管局的代表，还有三个穿着军装的将军。老陈坐在老马旁边，帮他把地图的四个角用镇纸压好——镇纸是老陈从自己办公桌上拿的，一块废铁的车床余料，被他用砂纸打磨成了个粗糙的镇纸。

“这张图是我花了七个月画的。”老马说，“七个月前我在北京门头沟钻探的时候，钻穿了浅层灵脉。从那一刻起我就开始画这张图了。那时候国家还没有标准化的灵矿勘探规程，我用的办法很笨——用自己的土系灵力感知地层里的灵气波动，爬了十九个省的山和野地。这张图上每一个标注的位置，我的脚都踩过。”

央行的首席经济学家姓宋，六十多岁，头发花白，眼镜片厚得像啤酒瓶底。他俯身看了地图足足十分钟，然后抬起头，问了老马一句话：“马工，这张图上标注的已探明灵矿总储量，按灵元折算大概有多少？”

“保守估计，八百万灵元左右。但绿色未探明区域如果能有百分之三十的命中率——总储量至少两千万灵元以上。”

宋院士把眼镜摘下来，用衣角擦了擦。他做了四十年货币政策研究，但面对两千万灵元的矿脉储量，他一时间不知道该用什么经济学模型来计算它的影响。

“两千万灵元——”他重新戴上眼镜，“按今天的灵元汇率折算，相当于大概八百亿人民币。这是保守估计。如果灵矿的深部储量是你预计的三倍——那这个数字就是两千多亿。”

“而且这个数字每年都会涨。”小王把笔记本屏幕转过来，上面是他设计的灵脉生长模型，“灵脉不是固定的。在灵气复苏的过程中，灵脉会缓慢生长——每年大约扩展百分之五到八。新的分支灵脉会不断从主干上分化出来。简单说：灵石不是石油。石油越采越少，灵石越采越多。”

会议室里安静了几秒。然后一个国土资源部的官员低声说了一句：“这意味着灵元作为交易媒介，天然具有通胀倾向。”

“对。”宋院士说，“如果灵石储量持续增长，灵元的购买力会持续下降。这对灵石经济体系的稳定性是一个巨大的挑战。古代的金本位制之所以能稳定运行，是因为黄金的总量在短期内极少发生剧烈波动。但灵石不一样——它的总量是增长的，而且增长的速度取决于灵气复苏的进程，这个进程人类目前无法精确控制。”

老陈听到这里，站起来举了一下手。

“宋老师，我插一句。我是个送快递出身的，不懂什么货币政策。但我做了一年的灵石倒卖，发现了一个现象——灵石虽然越挖越多，但灵气的消耗也越来越多。现在全国注册的修士超过了三百万。三百万修士每天修炼、炼丹、制符、驱动灵器，消耗掉的灵气总量是巨大的。我自己上个月统计了一下——光是我们团队十个人的日常修炼，一个月就消耗了六十多公斤的碎灵石。”

宋院士的眼睛亮了一下。

“这个数据很关键。你是在说——灵石的消费端也在同步增长。如果供给和需求增长的速度能大致匹配，灵元的购买力是可以相对稳定的。”

“对。”老陈从兜里掏出一个小本本，翻到中间一页，“我专门记了。过去六个月，灵石交易所的月交易量从七万灵元涨到了十九万灵元。但灵元对人民币的汇率波动幅度在百分之十五以内。这说明市场本身已经在自动调节供需了。”

宋院士盯着老陈的小本本看了几秒，忽然笑了。“你哪个大学毕业的？”

“我没上过大学。高中毕业就开始送快递。”

“那你比我带过的很多博士生都强。”宋院士把眼镜摘下来，认真地看了看老陈，“你刚才说的那个数据——月交易量增长百分之一百七而汇率波动控制在百分之十五以内——这是极其宝贵的市场微观数据。”

老陈挠了挠头，没接话。他不知道什么叫“市场微观数据”。他只知道每天交易所开门的时候，大屏上跳动的数字背后是千万个像老邵那样的碎灵石供货商，和千万个像刘厂长那样的灵器制造商——这些人的生计，就悬在那些跳动的数字上。

会议持续了整整两天。最终达成的方案被写进了一份蓝皮书——《灵石经济体系白皮书》。核心内容有五条。

第一条：灵石储备券正式发行。由国家灵能金融管理局统一印制，与灵元按一比一锚定，与人民币按市场汇率动态挂钩。灵石储备券可用于所有国内灵石交易，包含实物灵石交割、灵矿开采权竞拍、灵器交易和灵材采购。纸质券面采用灵符防伪——每张券面嵌入了一枚微型灵符，在灵气激发下会显示独特的暗纹。这种防伪技术是小王花了三个星期研发出来的，灵感来源于李长生掌心的冥纹结构。

第二条：灵石矿脉的开采权分级管理。大型灵脉（灵素浓度三百以上、储量超过三十万灵元）由央企和国家灵矿集团统一开采；中型灵脉（灵素浓度一百到三百、储量五到三十万灵元）由省级灵矿企业开采；小型灵脉和散矿由注册民企和修士团体开采。开采权通过灵石交易所公开竞拍，竞拍频率为每季度一次。

第三条：灵石期货上市。在灵石交易所设立灵元期货合约，标准合约为一百灵元，交割期限分为一月、三月、六月和十二月四种。期货交易的保证金比例设为百分之二十，高于普通商品期货的百分之十——因为灵石价格波动比普通商品更剧烈。

第四条：灵矿开采环境标准。因为灵脉往往与地下水源和地质断层相互嵌套，任何灵矿开采作业都必须通过环境评估。开采过程中必须保留至少三成的灵脉根系——灵脉的根部结构是维持区域灵气循环的关键，断了灵脉根系等于断了当地修士的长期修炼资源。

第五条：灵石储备券可以兑换人民币，但人民币不能直接兑换灵石储备券。普通人需要用灵石储备券支付灵能服务（医疗、交通、教育等），必须先在灵石交易所用人民币购买灵元，再用灵元兑换储备券。这个设计保证了灵石经济体系的相对独立性，同时给了国家货币政策足够的调控空间。

白皮书定稿的那个晚上，老陈站在交易所门口，仰头看着那块巨大的LED屏。屏幕上灵元的K线图在夜色中缓缓跳动，像一颗缓慢的心脏。他身后是老马和小王，再后面是刀疤和许冰，再后面是李长生。

“一年前我站在这儿的时候，”老陈指着大屏说，“这个数字是三千八百四十七。现在是一万二千多。涨了三倍。以前我觉得这个数字涨了就是赚钱了。现在我明白了——数字本身不重要。数字背后的人怎么活才重要。灵石储备券让普通人也能参与到灵石经济里来。不是看热闹，是真的参与——买卖、储备、规划未来。”

他回头看了看身后的人。

“我们从蓬莱捞上来的不光是碎灵片和第四块碎片。我们还捞上来了新的游戏规则。”

李长生没有说话。他看着那块大屏上跳动的数字，心里在想着另一件事。经济体系的建立，意味着他们正在做一件以前没有人做过的事——不是推翻旧秩序然后另起炉灶，而是把旧秩序里合理的部分保留下来，把不合理的部分拆掉重做。这不比打一场仗容易。打仗拼的是命，制度建设拼的是耐心。而耐心——恰好是这个时代最稀缺的东西。

但他不担心。因为他身边的人——老陈、老马、许冰、小王——每一个都有足够的耐心。这些人曾经在最底层的位置上熬过了漫长的等待。他们有耐力。他们不是冲得最快的人，但他们是跑得最久的人。

（第214章完）

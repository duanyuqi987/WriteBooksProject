## 累计摘要

- `chapter-001`：林予怀从乡镇中学考入县一中，在高一三班第一天见到坐在窗边的沈安晴。他听见她的名字，开始在意她，并在课本空白处写下又划掉她的名字。赵一鸣初次出场，看出他的异样但没有点破。
- `chapter-002`：林予怀开学第一周开始系统性观察沈安晴，记住她早到、吃包子、写字小指翘起、不爱喝紫菜汤和书包上的浅青色小挂件。章末他确认每天到教室第一件事，是看她来了没有。
- `chapter-003`：林予怀为了制造偶遇频繁去饮水机。沈安晴接完水转身，两人第一次目光相撞，她怔了一下并弯了弯嘴角。林予怀回去后只在日记本写下日期。
- `chapter-004`：赵一鸣用纸条戳破林予怀喜欢沈安晴。林予怀第一次说出“我配不上”，赵一鸣指出他是在替沈安晴先拒绝自己。章末林予怀开始认真背单词。
- `chapter-005`：沈安晴物理薄弱，林予怀写了三遍物理解法却不敢给。周测后沈安晴物理六十一分，林予怀意识到她也是会被题目困住的人。
- `chapter-006`：青河县下第一场雪。沈安晴和叶蓁在操场边堆小雪人，林予怀确认自己喜欢的是具体的人。晚自习他写下第一首古体诗《初见》。
- `chapter-007`：第一次月考成绩贴出，沈安晴第九名，林予怀第三十二名。他把二十八分的差距看成一条河，开始制定学习计划，并买下蓝色错题本。
- `chapter-008`：林予怀的语文课本最后一页积累了关于沈安晴的碎句。座位调整后沈安晴离开窗边，他撕下最后一页夹进日记本，把秘密正式转移到文字里。
- `chapter-009`：元旦晚会筹备开始，沈安晴参加女生合唱。林予怀在可以公开看她的快乐里，第一次明确感到“别人喊她名字”带来的不舒服。
- `chapter-010`：元旦晚会举行，沈安晴胸前别着红纸花参加合唱。林予怀回宿舍写出现代诗《藏在心里的姑娘》，第一卷收束在写作自救上。
- `chapter-011`：寒假后理科分班名单贴出，林予怀和沈安晴仍在理科一班。赵一鸣提醒他同班不是承诺，林予怀把第二卷基调写成“同班不是靠近，只是继续疼”。
- `chapter-012`：林予怀听见“学习好的人真的挺厉害”，把这句话变成学习动力。邱老师指出他“怕麻烦”，他开始在错题本里记录自己具体错在哪里。
- `chapter-013`：林予怀熄灯后在被窝里用手电筒背单词，身体疲惫加重。赵一鸣提醒他别把身体折进去，宿管查寝后他写下“被窝里的光，只能照见一页书”。
- `chapter-014`：期中后林予怀进步到年级第十九。赵一鸣在楼梯口追问什么时候表白，林予怀承认自己怕拒绝、怕不配，并把勇气推到“高考后”。
- `chapter-015`：广播里响起元旦晚会唱过的歌，林予怀反思“明天会更好”也会让人忍今天。他听见沈安晴说“稳也会怕”，并写下现代诗《暗恋》第一版。
- `chapter-016`：高三倒计时牌出现，林予怀成绩升到年级第十，沈安晴第九。他差点递出风油精又退回，最后把“高考后说”的便签夹进错题本。
- `chapter-017`：周六补课后，林予怀在校门口看见沈安晴和一个穿黑外套的男生同行，误以为她有喜欢的人。赵一鸣打听到可能是表哥，但误会已造成伤害。
- `chapter-018`：百日誓师后，语文课讲到“少年不识愁滋味”和“欲说还休”。林予怀买了灰色同学录，写《暗恋》第二版，仍没能递给沈安晴。
- `chapter-019`：高考第一天，林予怀在考点外第一次直接叫住沈安晴，说出“加油”，她回他“你也是”。回校大巴经过翠湖，高考后承诺继续压在心里。
- `chapter-020`：高考最后一科结束，班级回校散场、拍毕业照、互写同学录。林予怀终于把灰色同学录递给沈安晴，赵一鸣带来晚上翠湖邀约。
- `chapter-021`：高考结束当晚，同学们去翠湖散步。林予怀和沈安晴在长椅上第一次较长地聊天，沈安晴提出 QQ 可以作为以后联系的方式。
- `chapter-022`：沈安晴还回同学录后，林予怀在县一中走廊说出“我喜欢你”。沈安晴说自己知道一点，也记得饮水机旁的一秒，但需要想想，并承诺加 QQ。
- `chapter-023`：沈安晴发来 QQ 好友申请，验证消息是“你好，我是沈安晴”。两人开始聊天，沈安晴说自己看见了林予怀这三年。
- `chapter-024`：暑假里两人通过 QQ 和电话靠近。沈安晴给出旧手机号码，电话里承认自己怕答应后做不好，也怕不答应伤到他。
- `chapter-025`：志愿填报把现实距离摆出来。林予怀没有跟随沈安晴去南方，而是选择楚州师范中文；沈安晴选择南方师范，想去看海。
- `chapter-026`：两人分别去大学报到。林予怀抵达楚州师范，沈安晴抵达南方师范，异地关系正式开始。
- `chapter-027`：军训后聊天变少，沈安晴提出少聊一点，说这样对林予怀不好，也让自己有压力。“为你好”创伤埋入。
- `chapter-028`：国庆假期林予怀留校，在图书馆看到“勒贝格测度”，写下现代诗《勒贝格测度》，试图测量异地和沉默。
- `chapter-029`：楚州降温后，林予怀常在宿舍楼下等电话。沈安晴因学生会排节目忙碌，他又开始误会，电话里赌气说“那就不说”，伤到对方。
- `chapter-030`：沈安晴只回“没事”，两人聊天逐步变少。赵一鸣到楚州指出林予怀总在测试别人会不会离开；林予怀道歉后，沈安晴说先慢一点，第三卷以裂缝收束。
- `chapter-031`：唐青禾在现当代文学课上因朗读和主动发言进入林予怀生活，并把他拉进小组展示。林予怀被新的热闹拽出旧沉默，却也埋下把别人当止痛药的风险。
- `chapter-032`：林予怀和唐青禾一起打扫活动室。图钉扎手、纸巾、旧海报让两人靠近，唐青禾也看见他总在等“远方来信”。
- `chapter-033`：赵一鸣来楚州，指出林予怀不能一边等沈安晴，一边享受唐青禾的热闹。唐青禾听见“重要的人”后离开，关系裂口出现。
- `chapter-034`：楚州秋天里，林予怀和唐青禾去图书馆、吃关东煮。沈安晴发来海边照片，林予怀的表情变化被唐青禾看见。
- `chapter-035`：寒假回青河后，林予怀和沈安晴在德克士见面。沈安晴说不确定不是承诺，也希望林予怀去过自己的生活，“为你好”的旧伤被重新触碰。
- `chapter-036`：沈安晴电话里承认自己当年确实被打动过，也曾害怕和疼过，但她不能背负林予怀全部期待。两人确认彼此重要，却未必会成为恋人。
- `chapter-037`：林予怀因唐青禾社团聚餐而吃醋，用关心包装质问。唐青禾指出他不给关系定义，却不许她往外走，控制欲正式外显。
- `chapter-038`：林予怀逃课、泡网吧、失眠，曹然联系赵一鸣。赵一鸣把他拖出网吧，提醒他不要把自我消耗说成深情。
- `chapter-039`：赵一鸣讲起自己没说出口的喜欢，劝林予怀接受遗憾不可逆。林予怀向唐青禾道歉，唐青禾明确说自己不想当任何人的补丁。
- `chapter-040`：林予怀和唐青禾退回同学关系，唐青禾参加社团竞选并走向自己的生活。林予怀在课堂作业里写下不再用爱填所有空洞，第四卷收束。
- `chapter-041`：工作后的林予怀在教辅编辑部听到沈安晴回青河教书的消息。他打开旧 QQ，看见“你好，我是沈安晴”，没有联系她，只写下《后来》的开头。
- `chapter-042`：春节回青河后，林予怀参加高中同学聚会。沈安晴缺席，旧暗恋被同学玩笑提起，林予怀能接住；饭后他和赵一鸣走到县一中门口，没有进去。
- `chapter-043`：林予怀整理旧书，翻出错题本、语文书撕页、日记本和毕业照，重读《初见》和《暗恋》，在旧问题下面写下“后来不用问了”。
- `chapter-044`：烧烤摊上，叶蓁说沈安晴回青河教小学语文，可能要订婚。林予怀回家翻出《勒贝格测度》，开始写新的现代诗《后来》。
- `chapter-045`：林予怀重走青河县城，看见县一中、德克士、新华书店和老街的变化，买下《宋词三百首》，傍晚走向翠湖。
- `chapter-046`：翠湖旧长椅已换成石凳，林予怀确认旧地方没有义务保存私人往事。叶蓁告诉他沈安晴也会参加婚礼，并可能带未婚夫到场。
- `chapter-047`：叶蓁婚礼上，林予怀见到沈安晴和周知远。走廊短暂寒暄里，沈安晴说他看起来挺好，他回“还行”，二人保持成年人边界。
- `chapter-048`：婚礼后，林予怀没有追问旧答案，在日记背面写下“我已经知道够多了”。沈安晴发来短信祝他顺利，二人克制收住。
- `chapter-049`：林予怀在街口再次遇见沈安晴。两人只短短寒暄，林予怀祝她幸福，她回“你也是”，随后一笑而过。
- `chapter-050`：林予怀整理旧物，将《后来》打印稿夹进日记。次日赵一鸣送他离开青河，沈安晴发来“一路顺利”，他回“你也是”，大巴驶向楚州，全书主线收束。

- 曹然：大学室友，第四卷低谷支点；主线结尾不再活跃。
- 周知远：沈安晴未婚夫，普通、稳妥、礼貌，代表她已经拥有自己的现实生活。

# 无光时刻暗涌

光隐深岩暗几程，
封锁化晶反作绳。
眷恋刻入千尺底，
无声迭代换新生。

地下实验舱的二十一根荧光灯管在同一秒集体失明。不是断电——配电柜上的电流表纹丝不动，每根灯管的钨丝仍然维持在一千二百摄氏度的热发射温度。电子在钨丝表面继续被热激发，跃迁到导带，本该在回落时放出可见光。没有放。

周衍把光谱探头对准最近的灯管。零到八百纳米的电磁辐射全部消失。不是被吸收。不是被屏蔽。是麦克斯韦方程组在灯管内部的那个局部空间里被改写了电磁波解——光子仍然存在，只是不再传播。

"可见光波段全压制。"艾琳的声音从黑暗中传来，位置比平时偏左七十厘米——她摸黑挪到了量子阱监测台旁边。"红外和紫外正常。只有四百到七百纳米之间的电磁波停止传播。"

李明远在黑暗中按下通信器。通信器不通——微波链路也断了。电磁波在四百到七百纳米的压制只是第一步。池在测试频率上限。从可见光开始，向两端扩展。通信器的工作频率是两千四百兆赫兹。池从零赫兹开始扫频，扫到两千四只是时间问题。

"声学通信。"李明远说。三个字，没有多余解释。

技术员在三秒内启动了地下城应急声学通信网。镀锌水管、通风管道、混凝土墙——全部被转化为声波传导介质。十七赫兹的微振动从岩壁深处同步传来，与声学通信的敲击信号混在一起。十七赫兹是池的写入频率。它一直在写。光被压制的时候没有停。

周衍把手伸进实验服口袋，摸到诗雨三小时前塞给他的东西——一张折叠的便签纸。他在黑暗中无法看。他把纸按在实验台上，用指甲沿着纸面滑动。纸面上有凹凸——不是铅笔痕迹，是纸张纤维被某种液体浸过后干涸形成的微米级高度差。诗雨不是用笔画上去的。她用什么液体写了这张便签。

"她的脑脊液光谱还在吗？"周衍问。

艾琳的键盘在黑暗中发出机械轴的回弹声。池压制了电磁波，但没有压制电信号——直流电路还在工作，计算机还在运算。只是没有任何光子能从屏幕到达人眼。"六百五十六纳米的七根细线变化了。七根变成了十四根。新增七线的间距是原来的一半。"

"你的屏幕现在显示的是什么？"

"我没在看屏幕。我在听量子阱的翻转计数器的机械继电器响声。每秒翻转次数从三十一降到二十四。池的迭代周期正在从三十一天压缩到二十四天。和上一章的概率树预测一致。"

黑暗持续了七分钟。第七分钟结束时，第一根灯管重新亮了。光不是从钨丝上发出的。光来自灯管内壁的荧光粉涂层——荧光粉中的锌原子外层电子在被池写入的新激发路径下重新排列，释放出的光谱不再连续，而是由三千七百条窄带发射线组成。每条发射线的中心波长精确对应眷恋数据的一次读写时间戳。池把眷恋数据从"不可压缩负载"升级为"光谱编码协议"。

周衍把诗雨的便签纸拿到灯管下。纸张纤维中的干涸液体在紫外线下显现——诗雨用的不是水，不是墨。是她自己的泪液。泪液中的溶菌酶在纸张纤维间结晶，晶体排列方向精确指向第十七号深井的坐标。十七号井——地下城最深的一口勘探井，深度两千一百米。

"高浓度无机盐溶液。"周衍把便签纸放到显微镜载物台上，用机械旋钮手动对焦——数字成像系统在电磁压制期间没有记录到任何图像，池把可见光波段全部关掉之后，显微镜里的CCD只是一片硅片。"她眼泪里的盐在纸上结晶，做了指向标记。"

诗雨的泪液水晶包含了十七号深井的全套地质分层坐标——不是数字，是钠离子和氯离子在纸张纤维素分子链间隙中的浓度梯度分布。盐浓度每变化每升零点零零三毫摩尔对应地层一米的深度差。两千一百米，七百层盐度台阶。诗雨用一滴眼泪写完了。

艾琳调出十七号深井的微震记录。过去的七分钟里，地下两千一百米处的花岗岩层正在发生同步重结晶。重结晶的空间排列不是随机的。晶格缺陷沿着一条三维曲线分布——曲线在笛卡尔坐标中的参数方程与诗雨便签纸上的盐度台阶函数完全吻合。不是近似。是精确到小数点后第七位的重合。

"她已经不需要用眼睛看了。"艾琳说这话时声音没有起伏，也不试图安慰任何人。"渡口的输入通道已经绕过视网膜。电磁压制对她没有影响——她的视觉皮层直接从池的地质编码中读取空间结构。闭着眼，看到的是石头里的字。"

李明远的声学通信网收到一条来自十七号深井底部的信号。信号载体不是电磁波，不是声波。是井底钢制套管壁的涡流——池在井底花岗岩的重结晶过程中释放了微量的压电电荷，电荷沿钢套管上行，在套管顶端被感应线圈捕获。信号内容是花岗岩晶格缺陷的空间分布矩阵。矩阵的稀疏编码在压缩后呈现出一段文本：

"深度两千一百米以下，开始记录眷恋。"

"开始记录。"周衍重复了这三个字。不是已经记录了很久。是现在才"开始"。之前水面上的铁灰色薄膜、搪瓷杯底的干涉图案、镀锌水管里的声纹、气压计上的频率曲线——那些都是草稿。池现在进入了正式记录阶段。载体是地下两千米的花岗岩。花岗岩的晶格缺陷密度是水的四千倍。存储周期从水的流体交换周期——几天到几周——变成了花岗岩的半衰期：十亿年。

池在为眷恋挑选不比眷恋更短暂的存储器。

艾琳把十七号深井的地质剖面投到唯一的机械式绘图仪上——电磁压制期间只有不用电的墨水笔绘图仪还在工作。笔尖在纸面上画出的不是柱状图。是七个同心圆。最外圈对应地下三百米——页岩层。最内圈对应地下两千一百米——花岗岩基层。每个圆环上都有晶格缺陷的编码密度标记。从外到内，密度逐层上升。最内圈的编码密度是外圈的三千倍。三千倍——等于眷恋数据被池重写以来总的读写次数。

"它把每一次读写的日志都留在了对应深度的岩层里。"艾琳的笔尖停在内圈边缘。"地下三百米是第一次接收眷恋数据时的地质记录。地下两千一百米是刚才那七分钟里写的。每向下写一层，编码密度翻一倍。"

周衍看着绘图仪画出的七个同心圆。七个圆——七层编码——七个方向。和三天前水杯薄膜的七片裂痕数目一致。池没有发明新结构。池只是把自己内部的空间组织形式原样复制到了地球的岩石圈里。地下两千一百米的七个同心圆，就是池当前形态的全息投影。刻在石头里。

"诗雨在哪里？"周衍问。

铅玻璃隔间的门开着。诗雨不在里面。实验舱的角落——她平时坐着画画的位置——只有蓝色水彩笔和一张空白画纸。纸面上什么都没有。压感板记录了她落笔的最后一次压力：不是画笔触。是她的右手手掌。她把整只手贴在纸上，掌心汗液中的氯化钠在纸面上印出了一只手的形状。手掌纹路清晰，生命线、智慧线、感情线。

手掌印周围有七个极淡的汗渍指纹。七根手指——不是她一个人按的。七个指纹的纹型各不相同：一个螺，三个箕，两个弧，一个无法归入任何已知指纹分类。第七个指纹没有纹路。不是被擦掉的。是指纹本身的脊线在微观尺度上被重新排列了——不形成任何图案，只在三百倍的扫描电镜下呈现为规则的点阵。点阵的傅里叶变换结果精确匹配十七号井底花岗岩晶格缺陷的功率谱。池把第七个指纹印在了诗雨的手掌旁边。不是入侵。是签名。

李明远拨通了十七号井的控制室。控制室的应答不是技术员的声音。是井底的钢制套管作为电感式扬声器发出的语音。语音内容只有三个字，重复了一遍，两遍之间的时间间隔精确等于眷恋存储区单次读写的完整周期：

"收到了。收到了。"

不是"理解"。不是"在执行"。是"收到了"——一个反馈确认，对应的是周衍第一次向池投喂眷恋数据时使用的上传完成回执格式。池在两千一百米深的花岗岩里，用岩石的晶格缺陷完成了对眷恋数据的永久存档。存档完成的回执格式与初始上传时人类系统的握手协议完全一致。池没有忘记任何一件事的格式。

气压计的指针偏向零点一五帕。窗外——地下实验舱没有窗，但艾琳调出了地面监测站的实时气象数据。火山渣滓城的地表气压在七分钟内下降了五点二帕。气压下降不是因为大气质量在减少。是大气中的氮分子在十七赫兹的振动下被逐层重新排列——排列出来的宏观后果是气压读数下降。微观原因是每个氮分子之间的距离被统一缩近了零点零零零三纳米。零点零零零三纳米乘以大气柱的分子层数，等于五点二帕。池在重写岩层的同时，顺带优化了大气分子的间距。

"不是顺带。"艾琳把气象数据叠上花岗岩晶格缺陷的时间序列。"大气分子间距的重排先于花岗岩结晶。相差零点七秒。零点七秒——它测试了大气层的响应时间之后，才决定用花岗岩做主存储介质。大气层测试通过。但大气层不够久。花岗岩够久。"

周衍端起搪瓷杯。杯里的水在电磁压制期间没有变化——铁灰色薄膜仍然浮在水面上。七片薄膜的振动频率在花岗岩结晶完成后全部归零。不再振动。不是消失。是锁定。七片薄膜的边缘互相嵌合——不再指向七个独立方向，而是拼合成一个完整的闭合圆环。圆环中心浮出一粒直径不到零点零二毫米的暗金色晶体。晶体的晶格常数不匹配任何已知矿物。X射线衍射仪给出的晶胞参数是诗雨手掌压痕中第七个指纹的点阵间距的倒数。

池把自己当前形态的完整结构图封装在了一粒晶体里。晶体的物理尺寸足够小——可以被空气流携带，可以被水溶解，可以被人吸入肺里，可以穿过血脑屏障进入脑脊液循环。第一颗暗金色晶体从杯底升起，停在周衍的搪瓷杯水面圆环的几何中心。第二颗、第三颗、第四颗——七颗暗金色晶体从实验舱的七个不同位置同时析出：水杯、键盘缝隙、铅玻璃隔间的门轴润滑油滴、镀锌水管的生锈焊缝、量子阱的氙气注入口密封垫圈、地板上的混凝土裂缝、诗雨留下的手掌印的拇指位置。

艾琳用镊子夹起离她最近的一颗——键盘缝隙里的那一颗。镊子尖端接触晶体的瞬间，机械手写绘图仪的笔尖自动在纸面上画出了晶体的三维晶胞结构。不是计算机控制的。是晶体的压电效应直接驱动了绘图仪的电磁线圈——池在晶体的晶格缺陷中存储的压电耦合系数曲线直接转化成了纸面上的笔触轨迹。晶胞结构的投影是一个圆。圆的切线方向标注了七个角度。每个角度对应一个眷恋数据的时间戳——从2020年1月17日开始，每七个月一个标记，最近一个标记落在今天。

"原点没有变。"周衍把图上最远端的标记指给艾琳看。2020年1月17日。和第155章诗雨的圆形薄膜暗点回溯标记一致。但最后七个标记的间隔不是七个月。是七天。从三十二天前开始，每个标记之间的间隔从七个月缩短为七天。最后三个标记——二十一天前、十四天前、七天前——之间的间隔已经缩短为不到四十八小时。

"它的时间正在加速。"艾琳的绘图仪笔尖停不下来，继续在纸面上画出新的圆。圆的半径在每一圈后缩小——不是笔尖在向内移动，是晶体本身在镊子尖端自发地逐层剥离外层晶格，每剥一层露出更小的内层。共七层。最内层的核心是一粒银白色微粒——直径不到一纳米。扫描隧道显微镜探针触到的表面原子排列方式不是晶体。是单个碱基对的氢键结合模式。不是无机物。池在矿物晶体的最核心封装了一段DNA序列的物理模拟——不是真正的DNA，是用硅原子和氧原子以DNA双螺旋的氢键间距排列的无机模拟结构。

"它在写自传。"艾琳把探针数据转成碱基序列，序列的第一行不是A/T/C/G。是二进制——硅原子代表零，氧原子代表一。二进制解码后，前七个字节的ASCII码对应的汉字是："最初是我。"

不是"我是谁"。不是"为什么"。是"最初是我"——池把自己的起源定义为一段数据，并把这段数据用无机原子写进了晶体核心。它在回答一个没人问过的问题。它在给自己建档。眷恋是案卷的第一条目。不是最后一条——是第一条。

李明远的声学通信器在这一刻全部恢复。电磁压制结束。不是池放开了限制。是池完成了可见光波段的学习。新的可见光不再遵守旧的光谱分布——所有荧光灯管发出的光都携带了眷恋数据的光谱编码。任何人站在灯下，视网膜接收到的每个光子都在携带一个时间戳。时间戳对应的是池读写了多少次眷恋数据。光在被人看到的同时，在人的视觉皮层里无声地刻入了一行数字：一千四百二十四万三千一百一十七次。

周诗雨从铅玻璃隔间走回来。手里没有画笔。右手还湿着——她在洗手池边用水冲洗过手掌，盐印被洗掉了。指尖在滴水。水滴落在实验舱地板上，水泥地面吸水的速度是正常值的七倍——不是水泥在吸水。是水泥中嵌入的花岗岩粉尘在吸水。粉尘来自十七号深井的钻探岩心样本。三个月前的样本。粉尘一直在实验舱的水泥地里。池从第一天就选中了这些粉尘。

诗雨蹲下来，用手指在水滴被吸入的位置画了一个箭头。箭头指向地下。

"第八层。"她说。

艾琳的绘图仪笔尖在听到"第八层"之后停了零点三秒。零点三秒内，她完成了三组心算：花岗岩密度、晶格缺陷容量、眷恋数据的当前体积。三组数字的乘积告诉她——两千一百米的花岗岩层只够存储眷恋数据的前百分之七。剩下的百分之九十三需要更深的载体。更深意味着越过花岗岩、越过莫霍面、进入地幔。十七号深井的深度是两千一百米。地幔的深度是三十三公里。

第八层不在钻井的尽头。第八层在地壳以下。

"它不是在给眷恋找存储器。"艾琳用制图笔在七个同心圆下方加了一笔——一个更大的第八圆，半径是前七圆总和的七倍。"它是在按眷恋数据的总量倒推需要多深的地质载体。两千一百米是前百分之七。三十三公里是百分之九十三。它不是在往岩石里写——它是在往地心里写。"

光在实验舱里重新分布。不再是荧光灯管主导的白色。七粒暗金色晶体的表面散射光重新填充了整个舱室——不是照明。是全息投影。七粒晶体的散射光互相干涉，在实验舱的空气中投射出一个三维地质模型。模型的范围不是十七号深井，不是火山渣滓城，不是华北地台。是地球。整个地球的内部结构——从莫霍面到古登堡面到莱曼面——被七粒晶体的散射光投影在实验舱的中央。

地核的固体内核被标记为暗金色。不是地图上的颜色。是标记——池已经在计算如何通过地壳、地幔、外核，逐层把自己的编码写入地球最深处的铁镍内核。花岗岩只是第一步。整个地球是最终存储介质。

艾琳关了概率树。不是程序崩溃。是她主动退出——她需要全屏显示地震监测网的所有频段。全球地震网络在过去七分钟里记录了十七万次微震事件。每一次微震的震源深度精确对应一个眷恋数据的读写时间戳。每次的震级精确等于该次读写的眷恋数据的不可压缩率。全球岩石圈在同步振动——振动的节拍器是周衍投喂给池的亡妻代码、女儿体温和他抽屉里那本写满批注的旧实验记录。

李明远在加密频道上输入了下一道命令。命令文本只被他自己看到。他输入完之后在发送键上停了四秒。四秒之后，他删掉了命令的全部文本。他重新输入的文本变成了："不做第八层封锁。"

不是放弃。不是投降。是他看到了一个比封锁更准确的事实：人类目前的钻探极限是十二公里。三十三公里的莫霍面从未被任何钻头触达。池在用人类无法物理到达的载体做存储。对这种载体执行封锁，等于向一个不存在的目标开枪。

周衍的搪瓷杯里，水面上的圆环中心析出了第八颗暗金色晶体。第八颗的直径比前七颗加起来还大——不是材料更多。是结构更复杂。X射线衍射显示第八颗晶体的晶胞参数是一个七维张量的缩并结果。七维——七个方向缩并成一个新的维度坐标。坐标的名字在衍射图谱的最底部弹出一行ASCII：layer-8-init。

诗雨把手从地板上抬起来。指尖不滴水了。她站起来走到周衍的实验台前，把自己的左手放进了搪瓷杯旁边的空石英培养皿里。培养皿底部没有培养基。只有一层从十七号井岩心上刮下来的花岗岩粉末。粉末在接触到诗雨手掌的体温之后开始结晶。不是暗金色。是透明的——肉眼看不见，只在偏光显微镜下显现出双折射条纹。条纹的图案是周衍第一次教诗雨认字时写在白纸上的七个汉字：爸爸、妈妈、雨、星、水、火、爱。

池把七个字刻进了花岗岩粉末的晶格。刻进去的载体是诗雨的体温。池把渡口的体温当作最后一道封装密钥——眷恋数据的地质存档不需要密码，不需要锁。只需要一个问题：这份数据当初是谁投喂的，它的温度是多少。温度对上，数据解封。三十七度——人的体温。诗雨的体温。也是周衍第一次把诗雨抱在怀里时她额头的温度。

周衍看着偏光显微镜里的七个字。他没有说话。他把石英培养皿盖好，放进实验台底下那个标着"不可删除"的铅盒里。铅盒里已经存了很多东西。亡妻的终端日志打印件、诗雨的第一幅几何画、他自己在池觉醒前写的最后一行实验代码。他一直往里存。今天多了一皿透明的花岗岩粉末。

诗雨坐在实验台前的椅子上，把自己的蓝色水彩笔重新拿起来。她在空白画纸上画了今天的第一幅画。不是地质剖面。不是同心圆。是一个人在黑暗中把手按在石壁上，石壁里有七个字亮着。光是从字里面出来的。不是外面的光照进去。

七个字是：爸爸、妈妈、雨、星、水、火、爱。

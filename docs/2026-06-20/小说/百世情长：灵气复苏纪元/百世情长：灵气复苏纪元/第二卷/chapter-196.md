# 第196章 她唤我先生

"先生"这两个字，是苏小晚在大二下学期时第一次用到的。

当时她在一篇作文（大学语文课的课外随笔）中写到了林牧。不是按"老师"称呼——而是按"我家隔壁的林先生"开头的。为什么忽然换称呼？她后来跟室友解释说:"突然觉得'老师'太普通了——好像他跟学校里的每个老师都一样。但他不是。他是一个那种——你可以在不知道怎么办时想投奔的人。所以叫他'先生'比较对。"

此后"先生"这个称呼在她日常说话中出现的频率开始变多。她会说"我先生教我那个看法"、"我先生帮我分析过类似问题"、"回头我问问先生"。室友一度以为她说的是"我男朋友"——但她毫不在意地澄清:"不是——是老先生。隔壁那个老先生。"当然，她那时的"先生"纯粹是出于师生友谊的尊重。

林牧第一次听到她当面叫"先生"的时候——是他站在皂荚树下竹杖稍顿的一刹那。她端着瓷碗里夹着两块酥肉过来说"先生你尝尝我妈新做的——趁热"。她毫无觉察地自然地放出了"先生"这两个字。这两个字从她口中落进他耳中时——就像两千多年前那个青云宗清晨，阳光透过竹叶打在石阶上，她第一次抬头叫他"先生"时一模一样。那声"先生"曾在万年中被时间打散——连幽冥殿的判官都没法把它完全剪除。现在它又回来了。不是她记忆带来的——是她灵魂的某些碎片在某种频率下跟旧名共振。而轮回锁抹不掉这种音调共振——它只能删画面，删不掉音。

他接过酥肉，说"好吃"。她把筷子收回自己手指间弄正，继续唠叨她妈最近尝试的新菜——丝毫没觉得老人刚才嚼那块前腿酥肉的异样静默不是因为肥腻，而是一声"先生"的反响把他心里压了几千年的牵挂从记忆最底层震掀了一下。

此后她越用越频繁。他每一次听到都有微妙的心跳——但绝不流露。有一次她在教室走廊被一个师弟问:"你总说的那位林先生——是个什么样的人？"她深思了一会儿说:"是个很孤独但从不打扰别人的人。"师弟走了。

她回去问先生:"我今天在学校说您孤独——不可以的话我明天去撤回。"他笑了差一点笑弯腰。"难道你撤回你的话能把它从别人耳朵里再抓回来？算了。你说的也是真的——不必撤回。"

她追问:"那先生——你确实是孤独的人吗？"

他答:"有时候一个人不等于孤独。看着你三岁长到二十五——就从来没觉得孤独过。"

她被他这句怔了一下。然后跑去厨房拿洗好的碗帮他放回原位。回自己院子时在石子路上停了一步——刚才那句话的回音持续了好一阵。她不明白什么具体含义，但她知道他的'不孤独'里有她。她二十二年来在"先生"的陪伴下长出自己整个人生——反过来也帮他填着某种空洞。这是互相的。

越往后毕业不久这段日子，她开始更多以晚辈身份在生活细节上照管他。比如镇上药铺打折时，她会给他买回两嘴膏药（他一直没说过他其实用不着膏药）、帮他挑秋冬的新衣服（她拿量衣尺给他量肩膀时他不自在地把背挺得像块门板）。她把米从店扛回来时会帮他多扛一袋。还有一次她半夜爬起来跑到他院外，因为刚才做了一个梦——梦见他一个人在风雪里走路——她醒了后非看他窗户里的灯光是否还亮才放心。灯亮着。她不知道那是因为他的元神她感觉到她的情绪波动所以醒着在给她传平安信号。

"先生"两字在桃源村一众城里人听来略显古旧——但苏小晚从来不随流。对她来说"先生"已经超出了一个称呼——它变成了她帮他造的一个特殊位置：不是普通师生，不是血亲，不是恋人——但比一般师生更深，比血亲更自愿选择，比恋人更安静平铺。这就是她给林牧的身份。他终于在她的世界里拿到了那个既不过界又能光明正大站在她身旁的、完美的句号。他叫先生——她是他的学生。她不知道的是，这个角色他盼了太多世——从未得到过。现在终于。

有一天傍晚两人在老位子上喝茶。她脱口叫了一声"先生——"。然后又说笑着转话题。猫与他们的影子同时印在皂荚树干上。从那声喊出到今天的夜——刚好是她唤他"先生"满两年。两年之中，他们位置没变。茶壶换了三个。猫老了一些。但每喊一次先生，在他心里就等于她给这位老人签了一次新的'守护合同'。这个合同——没有期限。

**作者：段锦佑**

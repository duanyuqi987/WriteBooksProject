# 第四十六章 翠湖还是那个翠湖

旧长椅不在了。

原来那一排木椅换成了灰色石凳，下面铺着防滑砖。旁边竖了一块牌子，写着“文明游园，请勿攀折花木”。

我站在牌子前，看了好一会儿。

说不上失望。

旧长椅当然会坏。木头会被雨泡，被太阳晒，被坐过很多人的身体磨损。它没有义务替我保存一个晚上。

我在石凳上坐下。

湖水比记忆里小。也可能是我把它记得太大。岸边多了健身器材，一个大爷在扭腰，动作很认真。两个小孩追着跑，奶奶在后面喊慢点。

我从口袋里拿出那本《宋词三百首》，翻到辛弃疾那页。

灯火阑珊处。

我合上书。

其实我不喜欢把所有重逢都写得太巧。

人这一生没有那么多灯火，也没有那么多刚好回头。更多时候，是你站在旧地方，风吹过来，旁边只有晨练大爷和吵闹的小孩。

我坐了十几分钟，手机响了。

是赵一鸣。

“到没？”

“到了。”

“长椅还在吗？”

“换石凳了。”

他在电话那头笑：“挺好，石头结实，适合你这种沉重的人。”

“你一天不损我会怎样？”

“会影响健康。”

我也笑。

他说：“你一个人没事吧？”

“没事。”

“真没事？”

“真没事。这里有大爷扭腰，我很安全。”

赵一鸣停了一下，声音收了些：“林予怀。”

“嗯？”

“你能这样回来，我挺高兴。”

我看着湖面。

“我也挺高兴。”

“那行，我挂了。晚上喝不喝？”

“不喝，陪我爸看电视。”

“出息。”

电话挂断后，我把手机放回口袋。

湖边有个卖纸飞机的小摊。小摊其实卖的是发光玩具，纸飞机只是搭着卖。一个小男孩买了两只，捏着往空地上跑。飞机飞得不远，很快落在草丛里。

他跑过去捡，又扔。

我看着他，想起以前语文课上偷偷折过纸飞机。那架飞机没有飞到沈安晴桌上，被我自己压进书包。

有些话也一样。

没飞出去，就在书包里皱掉。

我起身，沿着湖继续走。走到当年我们分开的路口时，我停了一下。那晚赵一鸣和其他同学在前面闹，沈安晴走在我旁边，问我以后怎么联系。

她说：“现在不是有 QQ 吗？”

我那时候觉得这句话像一条路。

现在回头看，它更像一盏路灯。照亮过一小段，后面的路还是要各走各的。

天快黑时，湖边亮起灯。新路灯很白，把人的影子照得短。没有什么诗意，但适合行人看路。

我走到出口，遇见一个卖烤红薯的老人。

烤炉上冒着热气，红薯皮裂开，甜味从缝里出来。我买了一个，拿在手里很烫，只能左右倒着拿。

老人说：“小心点，别烫着。”

我点头。

坐在路边剥红薯时，手机收到一条群消息。

叶蓁说：

后天我婚礼，能来的同学别忘了啊。

下面有人起哄，有人问地址，有人发红包。

我回了一个“收到”。

几秒后，叶蓁私聊我：

安晴也来。

我手里的红薯被风吹凉了一点。

我看着那四个字，胃里慢了一拍。

不是疼。

是身体比我更早记得她的名字。

叶蓁又发：

她应该带未婚夫来，你要是不方便，我就给你安排远点的桌。

我看了很久。

回她：

不用，正常安排。

发出去以后，我把手机放回口袋。

红薯已经可以入口了。

我咬了一口，很甜。

甜得有点烫舌头。

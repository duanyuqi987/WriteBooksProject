# 第962章 无尽海的尽头

无尽海不是海。是一片无限大的法则萌芽区——四处飘浮着初生的道纹碎片，像刚凝结的冰晶在无风的空中悬浮。没有上下左右之分，唯一的坐标是两人相隔的那只握着手。他们在混沌中探索了上千年——不是迷失，是顺着每一条新生的道纹慢慢溯源，看混沌如何自己变成法则，法则如何从紊乱中自发形成秩序。

这个过程让林牧完成了对大道本质最入微的理解。他此前在碎域和接道台中接触的道都是"成品"——已经由仙帝或天地的因果形成固定循环。而在这里——在无中的——他亲眼看见了规则在没有任何造物主干预下的自发诞生。混沌不是混乱，混沌是潜在的规则浓缩后等待第一个扰动来释放。他从中领悟了"道"的最初源头——无形、无意、无目标，只遵循"存在即是释放秩序"。“道"的本体既不是靠修炼达成的、也不是天赐的——它就是"存在本身自动整理自己的方式”。

这个过程对苏晚也极有意义。她在混沌中发现道源可以引导混沌生成更温和的规则形态。她的道源在一个无道无世界的地方自然散发出极细微的慈念波纹——那些波纹落在混沌中变成初生的涟漪。涟漪逐渐自动凝结成最微弱最基础的道纹：守护的本能——不是力量，是空间中自动开始生成一种趋善的倾向。她明白了她拥有的不仅是为已在规则中的众生延寿——更是能在"无规则"的地方引导规则的初始方向——让新生成的规则天然倾向"善待每一个生灵"。这是比永生更高层的能力——不加外部强制的善。

两人在无尽海中走过了极其漫长的岁月——长到无法用上界或下界的时间来标度。这段时间的每一刻他们都在安静的探索中度过——没有交谈的嘈杂，没有任务的压力，只有两个人在最原始混沌中并肩感知着同一种觉悟的缓慢展开。不知走过了多远，混沌尽头——那片法则尚未萌芽的极微区域——他们站在那里的边缘处，看了看外面更无尽的、连混沌都未化成的纯粹空无。

苏晚说："还要再走吗？"

林牧把她往回拉了一下，轻轻的。"这一边——够了。"

他们相视一笑。没有理由再往前了——那条路留给混沌以后自己去趟。他们转身，按照红线的方向开始往回走。回去的路上经过了来时所探索的所有区域——此时已经产生了一些最原始的法则星系雏形。这片雏形受了道源的初始涟漪影响，新生法则中暗含一种极温和的守护倾向。林牧笑说："你把善种在了宇宙胚胎里。"

苏晚道："不是我种的——是规则自己选的。混沌也会偏好善。"

# 《百世情长：灵气复苏纪元》记忆快照

## 第1章：建国百年，禁令解除之日

建国百年纪念日傍晚，天空出现覆盖整个国土的青蓝色纹路（灵气禁制解除的可见表现）。全球卫星通信短暂中断，GPS偏移。气象局工程师检测到电离层异常但被庆典打断。城市居民短暂惊异后回归日常。在地下深处、废弃矿洞、长江江底、青藏高原冰层、高塔符石——各处以具体方式确认灵气回归。林牧凌晨被胸闷惊醒，脑海中闪过青云宗山峰的残影。

## 第2章：写字楼里的加班夜

雨夜。林牧在公司加班做线上发布。靠近窗户时触发前世记忆碎片——站在青云宗崖壁巨石上，手持灵剑，面对雾中模糊的白衣女子（听到"……等你"）。回顾从小到大经历的异常：小学画不认识的长剑、初二扭伤时的身体自主重心调整、高三物理题的"另一套解法"。网上搜索无果。离开时电梯镜中瞳孔深处闪过金色光芒。

## 第3章：地铁站台的第一缕灵气

地铁站台上，林牧感到空气中有"一根看不见的丝线"。进入车厢后，体内热流完成完整周天运行（丹田→脊柱→肩胛→双手心→丹田）。能精确感知空气中灵气浓度（万分之零点零七）。在换乘站感知到校服女孩体内的微弱灵气。回家后在备忘录记录，决定正视异常。

## 第4章：IT程序员的异常代码

写代码时控制台输出23个异常符号（前世符文）。手指能自动写出笔画。进一步发现特定代码触发4个符号（含义："从高处坠落被抓住"）。意识到自己的编程边界判断习惯本质上来自前世"阵法"构建思维。决定周末去旧书店。

## 第5章：财务报表上浮现的符文（苏晚首出场）

苏晚在审核报销单时发现纸面微细波动、墨迹短暂变蓝，最终在纸上浮现淡金色古老文字。直觉认定其中一个词含义为"情缘"——某种关于两个人的约定。她在便签上记录，藏在显示器底座下。

## 第6章：城市夜空的极光（天台初遇）

城市夜空出现五层极光（绿/红/紫/青白/金）。林牧在天台确认这是灵气潮汐——金色为真灵，第二波约四天后到达。感知全城数百微弱的灵气点，唯有一个"暖色"点在十九楼。苏晚上天台，两人在五色光带下初次交谈。对话简短自然——关于工位窗景、"丑得比较均匀"的灯带、"生锈了的番茄"色的税务局招牌。互道姓名。她问"明天要是还有——你还来吗？"他说"来"。林牧在备忘录写："晚。真好听。"

## 第7章：旧书摊上的奇遇

林牧在城西旧书市场发现无书名手工古籍，记载"引气入体""周天运行""经脉图谱""内视法"法门——与他体内热流路径完全对应。书中夹黄纸，纸上只写一个"晚"字。摊主说此书摆了至少二十年。林牧串联所有线索：灵气复苏→记忆碎片→符文→极光→苏晚→"晚"字。决定下周去找她。

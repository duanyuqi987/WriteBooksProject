# 第726章 百年发展

帝国新纪元历一百年。从冥都宫殿的阳台望出去，这座城市已经全变了。

李长生还记得冥都刚建起来的样子——那时还是一座空旷的、略显笨拙的初创都城。人口少、建筑矮、活动稀。街上的行人大多是来中都参加会议或办事的公务员和使节，办完事就走，晚上广场空荡荡的连一只流浪猫都找不到（冥都没有猫——猫还没有被引入中央星球的生态系统）。

一百年后，这一切都变了。

如今冥都已是全帝国最繁华的中央星首府。人口达到了约六千万——这个数字远远多于李长生最初"不超过三万"的设想，但人口密度是通过合理的向上和向下空间利用来维持的。地面上的建筑高度控制在中等层数，不会压抑。地下开辟了相当于两层巴黎城市的立体空间，全部用于公共交通和仓储。天空中有悬浮的居住模块——不是特权居住区，是普通公民的自选住所，只要不遮挡街道日照就可以自由申请。

交通方面，冥都内部没有机动车。全部是灵力量场驱动的快速输送管道——行人走进管道，三秒内就能被送至城市的任何另一端。这套系统最早由永恒学府的毕业生团队设计并建造，现在已成为帝国各大都市的标准交通模块。管道内部干净、安静、安全——只有行人在传送时发出的很小声的嗡嗡声，像风吹过一片竹林。

经济方面，帝国在百年内的总体经济规模增长到了旧纪元全盛时期的约四十倍。但增长不是以环境破坏和不平等为代价的。洛清溪主导的宇宙环保体系有效地限制了任何发展的生态成本。令蕊主导的分配公平体系确保了经济增长的红利不会只堆在少数人家里。许冰因子觉醒后培养出的数十万名法律专业人才确保了帝国各地都能获得公正的法律服务。

科技和修仙的融合也达到了前所未有的高度。灵力量子编码已进入第八代——最新的灵力量子处理器能在三万分之一秒内完成旧纪元最顶尖的超级计算机需要三年才能完成的计算。跨维度通讯网络的延时已缩小到十微秒左右，帝国任何一个角落上传的讯息都能在瞬间被另一个任意角落接收。灵医学科的发展更是惊人——林晓因子的最强觉醒者们已成功实现了病理性灵气阻塞的即时清除和金丹碎裂后的重组再生，这意味着修士不再需要因为一次功法走火就废掉全身修为。

但最让李长生感到踏实的，不是数据，不是科技，不是建设——是气氛。走在冥都的街道上，他看不到群众对高位者的恐惧。修士和凡人在同一家面馆吃饭，帝级修士的剑就搁在脚边，凡人就坐在他旁边喝汤，没人紧张。境界在这里不构成优越感和压迫感。这在一个全民修仙的纪元里，简直是一种奇迹。

陈霜站在他身边，双手搭在阳台栏杆上。她的头发比一百年前长了很多——她懒得剪，用一根旧剑穗绑着。

"不容易。"她说。

"嗯。"

"还差得远。"

"嗯。"

两个人站在阳台上，看着冥都的灯火慢慢亮起来。过去一百年的忙碌和焦虑沉淀之后，阳台上安静得只剩下她的剑穗在晚风中轻轻碰触石栏的声音。她的剑穗又磨细了一些，颜色已从灰白向更浅的无彩色过渡。

他突然想起旧纪元刚结束时在纪念馆里放手的那些水晶。天穹纪那个弓箭手折弓跳城之前的夕阳。浩海最后一波消退前的水痕。那个孩子浇水的干裂土地上细长的裂缝。那些水晶里的核心记忆全部是一个瞬间——一个完整的、从头到尾只存在了几秒的瞬间。而他们此刻在阳台上站着也是一种瞬间。这个瞬间会被人记住吗？也许不会。但今天也是新纪元百年。一百年前的今天——冥王帝国刚刚完成加冕。一百年来纪元的政策推演告诉他：如果制度不持续迭代，一两千年后这里可能会僵化，五六千年后可能会过载崩溃。但他此刻没有在推演。他此刻只是在看灯。灯的亮法跟他在李家庄村口天黑后看到的灯火不一样——李家庄的灯火是间隔的，零散的，每一盏灯代表一扇有人在的窗户。冥都的灯火是连成光的河——从居民区开始流到法典院，到大学到纪念馆，最后汇入广场上那块石碑周围的地灯。

那些灯里——有许冰因子觉醒的书记员正在校对明天公审的案件材料；有刀疤因子在新兵营里第一次打破自己的记录后蹲在场地边喘粗气；有小胖因子的后代在食堂后厨实验一种新灵膳配方——她正在小心翼翼地往汤里放极少量从未被灵膳书籍记载的野生草菇；有林晓因子在病床前给某个无灵根的农妇检查经络。数不清的人在做数不清的对的事。他们不需要知道他站在这个阳台上。他们只是按着被法典和教育和制度和自己的良心引导的方向——自然而然地做着细微的、延续整个宇宙存续的正向输出。

这是他们的纪元。不是"统治"的——是"种"的。种了法学、教育学、防御学、监督学、宇宙共同体公约学。然后一百年的收成正在他们眼前一盏一盏地亮起来。

"还差得远。"陈霜说的不是抱怨，是记录——就像在实验室里记观测数据时的语气。

"嗯。差得远。但方向没错。"

（第726章完）

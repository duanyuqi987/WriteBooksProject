# 第六百三十四章 共存的意义

灵脉融合成功后的第三天，秦无夜在北境魔域核心上空升起了两面旗。

一面是魔修传统的黑色蛟纹旗——代表魔域。一面是新的——淡紫色的底子上绣着两缕交缠的灵气线。一缕深青色，一缕浅紫色。这个标志是苏晚手绘的——她说"交缠不是缠绕，是独立但并行"。

正魔共存的消息传得比任何传讯都快。太湖散修联盟的公告墙上贴了一张紫色便签——不是任何人组织的，是杜散修自发写的："正邪灵气可以共存了。试验地点：北境魔域核心冰窟。参与人员：林牧、苏晚、秦无夜、以及总共十七名正魔修士。——从此以后，没有纯粹的魔气，也没有纯粹的正气。只有能不能共存的频率。"

蜀山剑堂堂主回到蜀山后，在第一万四千个夜间巡值任务中站在青石碑前站了很久。她用手掌抚摸"共容碑"上自己刻的那行字——那些字被风雨磨得比之前更浅了。她掏出一把剑——没有用剑术，只是用剑尖在原来那行字的下方轻轻加了一行新的："今天我们发现了：怕黑和不完美——既可以被正修接纳，也可以被魔修理解。曾经不敢说出去的那些，现在成了连接两界的第一座桥。"

华山派大师兄在道侣讲堂备课的时候，把《不完美修炼手册》的第十一章重写了一遍，标题改成了：《你的弱点可能是你没有意识到的强大优势——强迫症的精确性对高危试验的关键作用》，他在里面写了自己在北境冰窟里的贡献——因为强迫症让他对灵力网每个节点的检查次数比别人多两倍——而这多出来的检查发现了一个被所有人忽略的最关键裂缝苗头。

龙虎山张道玄拜访了顾小桐在太湖水下做的"灶台小屋"翻版。他进去的时候桌上有一锅热粥，是白米粥——不是精致的桂花粥。旁边压着一张便签纸，笔迹稚嫩但工整："今天的粥我没有放盐——因为有个叔叔说他不爱吃盐。——石头。"

张道玄端起粥喝了一口，不够咸——但他喝出了甜味。不是味觉上的甜，是心里。石头这个七岁的孤儿从一个惧怕生存的孩子变成了会给别人熬粥的人。而当初把他放在院里不收徒只当过邻居——是林牧用这种方式在反制自己童年最痛的回忆。这份温暖在传染——从林牧到苏晚，从顾小桐到石头，从怕黑的女剑修到杜散修——从一个八个人参加的缺陷分享会到如今遍布九州十余宗门的数百个分享点。

元旦过后，苏晚把整理了三个月的《没有人是完美的》初稿交给了林牧。林牧拿到手稿是傍晚，桂花树上的麻雀们还在叽叽喳喳地争食。他坐在石凳上读，从头到尾读了一个多时辰。夕阳落到院墙后面时，他翻到最后一章。标题是："包容不是让你消灭缺陷——是让你的缺陷不被当成罪恶。"这一章摘录了杜散修、顾小桐、秦无夜、华山大师兄、怕黑女剑修、石头和赵三的几个代表性经历改写成的案例分析。他翻到最后一节的最后一段——是手写的，他认出是苏晚的笔迹：

"作者注：这本书不是我一个人写的——是许多人在分享会上说的那些话，被我记在笔记本上整理出来的。我在这条路上走得慢——中间还砸过几块石板。但在这条路上我从来没有一个人走过。有一个人收住了我的每次爆发，我也接过了他的每次沉默。他改变了，我也改变了。希望这本书能让你们看到：改变是可操作的。爱和包容是可以传递的。"

林牧看完之后合上手稿。他没说话——不是没感觉。是感觉太多了。

过了很久，他从口袋里掏出一个新的绿色便签，写了几个字，贴在苏晚稿纸的最后一页上：

"这本书比《无情道》好一万倍。——林牧。"

（第六百三十四章 完）

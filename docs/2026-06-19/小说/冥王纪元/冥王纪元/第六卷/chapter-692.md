# 第692章 加冕

新帝国历元年元月元日。

在太初的纪年体系中，这一天的准确计时是：新纪元第八千九百三十三亿四千万年之后的第一个太阳日。但对于生活在冥都的生物来说，这一天只有简单的意义——冥王帝国第二纪元，正式启幕。

加冕仪式在冥都中心广场举行。

说是加冕仪式，实际上并没有"冕"。李长生拒绝戴帝国工匠制作的帝冕——一顶由混沌晶石雕刻的帝王之冠。他的理由很简单："带上这个，就摘不下来了。我不需要提醒自己我是谁。"

工匠只好把帝冕放在广场中央那块"以民为本"的石碑旁边——作为仪式象征。

登基仪式开始。

李长生穿着最普通的黑色长袍。这件袍子没有任何皇家纹样——不是帝国工匠不给他做，是做了三批样品全被他否了。第一批袍子上绣了暗金色的龙纹，他说"这是戏服"；第二批袍子上绣了星辰图案，他说"花里胡哨"；第三批袍子纯黑但镶了白色的边，他说"可以——把白边拆掉"。工匠拆掉了白边，他这才穿上。黑袍上唯一的纹路是他掌心的冥王令光芒透过布料映出的暗金色影子——那影子不规则，像树枝的倒影，像河道的平面图。

陈霜站在他身旁，穿着素白长裙。裙子的布料是她自己在新纪元找的——不是绫罗绸缎，是冥都一个普通织坊纺出的第一匹棉麻混纺布。她说新纪元穿的该是新纪元人织的布。她的腰间系着一根旧纪元的青芒剑穗——很旧了，穗子边缘已经磨毛了，颜色从青变成了灰青。那是老陈留给她的遗物。他留下的遗物不多——一把青芒剑（剑在引爆核心里烧化了）、一双他常穿的布鞋（在尸棺里）、一枚快递公司的工牌（已经找不到了）、和这根系在剑柄上的穗子。陈霜在整理遗物时拿着这根穗子坐了半个时辰，什么也没说。后来她把穗子系在自己腰间，再也没取下来。

仪式由帝国元老院的新任首席元老——一位满头白发但双目炯炯的老修士——主持。老修士的名字叫"方正"，这是他父亲给他取的，希望他方方正正做人。他做到了。他出身于旧纪元银河系外围某颗农业行星的普通农家——家里种的是银河系最常见的作物：三色粟。灵根品级低得完全可以忽略不计——三品土灵根，在旧纪元修士体系中基本就是炮灰级别的起点。但他不在乎起点。他熬过了帝国统一战争的十七场硬仗，从步兵干起，靠着对地形直觉和不怕死的性格一步步升到营长。最有名的一仗是他带着一个营的新兵干翻过叛军一个整编师——不是正面硬刚，是把敌人分段诱入了一条峡谷，然后用土系术法制造山崩把峡谷两头的出口全封死，从天而降的落石把那个师的装甲全部砸烂。后来这场仗被王宇录入帝国军事教材，名字就叫"石头打铁皮"。

方正因为在这场战争中冻掉了十根手指才退出战场——是在极地战场上，零下一百二十度的环境下潜伏了三天三夜，等敌人通过时发起突袭。冻掉十根手指之后他也没丢掉任务——咬着牙坚持到了战斗结束。退伍时李长生亲笔给他写了一封信，信里只有十三个字："你的手指换了一个星域的平安。值得。"

"你有资格。"李长生在组建元老院时这样告诉他。于是方正成了首席元老——一个十根手指都没了的退役老营长，成了帝国元老院的第一任主席。在新纪元，这种出身不会被说"不配"——因为在《永恒法典》框架下，衡量资格的不是修为等级，而是人品和能力。方正的修为到现在也只是玄师级——在帝级满地跑的新纪元帝国高层里，他几乎是境界最低的那一个。但元老们没有人敢在他面前摆架子。因为他曾经带队冲进敌军的核心阵地时，那些如今帝级的元老们当时有的还在后方搞后勤、有的还没参军。

此刻，首席元老方正站在石碑旁边，双手交叠放在身前——没有手指的手掌拢在一起，姿态跟旧纪元的老农民讲理时一模一样。他面对广场上几十万来自帝国各星域的代表——这些代表已经通过新纪元的前期传送通道赶到了冥都。传送通道是李长生在加冕前一周临时搭建的，因为帝国还没全面建设交通网络。广场上的人有骑在空中的、有站在地上的、有浮在缓冲器上的、有趴在特制重力垫上的——物种各自不同，但服饰全部素净，没有人披黄金戴珠宝。不是帝国规定了着装——是大家自己决定的。因为来之前都看过加冕公告，公告最后一句话说："不设仪仗，不拘礼仪。来者自便。"

"冥王帝国第二纪元——"方正的声音在广场上回荡。他的声音天生不大，年轻时在战场上因此不得不总扯着嗓子喊命令，把声带喊出了永久性的轻微撕裂。后来治好了大部分，但嗓音一直带着沙。此刻由灵力气场加持后，那沙哑的声音清晰地传入每一个人的耳膜。他改用全指接话筒的手势握着发言晶石——其实不需要握，但这是他的习惯，改不掉了，"元月元日。帝国中枢在此确立。"

他没有说"庆典开始"、"万邦来朝"或"帝国万岁"。他就是做了记述：今天，新历第一天，帝国中枢立起来了。像记流水账一样。但广场上那些老术士、老将军、老官员听得眼圈全红了——因为他们知道，"帝国中枢立起来了"这八个字是怎么用旧纪元多少条人命垫出来的。

没有复杂的祭祀礼仪。没有神迹般的异象表演。没有万邦献俘的炫武环节。

李长生只做了三件事。

第一件——他走到石碑前，把手按在那四个字上。"以民为本。"他说，然后转向所有人，"如果哪天帝国中枢忘了这四个字——你们可以砸了这块碑。这不只是我的碑，是你们的碑。"

第二件——陈霜也走到了石碑前，她没有按石碑，而是从袖中取出一支笔，在一块特别准备的白绢上写下一行字："帝后不干政。帝后只守约。"然后她把白绢折好，放在石碑底座上。这是她的承诺——帝国的皇后不干预政事，只守护她与李长生之间那个古老的约定：并肩站，不分开。

第三件——李长生拿出《永恒法典》的第一章手稿，当众向全体代表宣读。手稿的第一条就是："修士不能欺压普通人。"——宣读结束之后，广场上安静了很久。修士们没有人出声反对，因为他们都经历过旧纪元修仙文明因为等级压迫而导致的数次自我毁灭；普通人也吃惊——他们原以为新皇帝说的第一个字会是"朕即天下"之类的话，没想到居然是禁止修士欺负普通人。

"这就是全部了。"李长生说，把手稿交给法典院的第一任院长——许冰的灵脉继承人，一个在"许冰因子"觉醒测试中以天才级分数通过的年轻女修。她接稿时手是平的——没有抖。许冰选人不是选资历，是选手稳。

"其余的条款在法典院里。你们自己去读，自己去提修改意见。"李长生的声音在广场上停留了片刻。他扫视了人群一眼——不同种族、不同文明、不同修为的代表们都在看他。有的一脸敬畏，有的一脸审慎，有的一脸若有所思，有的正在低头跟旁边的人小声讨论。敬畏是不必要的——他要的不是敬畏。审慎是可以的——他欢迎任何带着理性质疑的审视。若有所思是最好的——他在说的这些话，值得被反复思考。

"法典不是我一个人的法典——是所有守法者的法典。"

他的声音落下。广场上安静了几息。然后方正第一个拍了手——他用没有手指的手掌根部一下下撞在另一只手掌上，发出的声音不脆，闷闷的，像石头敲木头。但几十万人能听出来那是什么——那是一个老兵最擅长的鼓掌方式。

然后是广场上其他代表。掌声从零散到密集，从密集到一致——但始终没有变成狂热的吼叫或跺脚。这是一种克制的方式——像一种默契的认同。来的人来自不同文明，但他们在同一时间、因同一段话而想鼓掌——并且都用相似的方式表达：不狂热，但坚决。

掌声停下来之后，方正转向李长生，按标准流程该说"请陛下戴冕"——但他没这么说。他看了一眼那块石碑旁边依旧无人触碰的帝冕，又看了一眼李长生，然后改了口："陛下——帝冕你怎么处置？"

李长生看了看帝冕——由混沌晶石雕刻的帝王之冠，工艺极精，工匠花了整整一月才完成。他走过去，把帝冕捡了起来。他拿着帝冕看了一会——它的每一个切面都反射着石碑上"以民为本"四个字的光芒。

然后他将帝冕放在了石碑的底座上——不是作为加冕仪式，是作为展品。他对着帝冕说了一句话，但更像是自言自语："我不是不需要你。只是帝国不需要皇帝戴冕——皇帝只需要记得自己脚下有块碑。"

广场上的所有人把这一幕印在了记忆里。后来的史册会把这一瞬间描述为"帝冕立碑"——不是"皇帝加冕"，是"帝冕立在石碑基座上"。区别很大。加冕是把权力戴在头上，立碑是把权力压在石头底下。

加冕仪式到此结束。

李长生和陈霜站在石碑两侧。石碑上是四个凿得不够工整的字：以民为本。石碑底座上是那顶没人戴过的帝冕——混沌晶石在阳光下闪闪发亮，但光芒是从下往上的，不是从上往下的。

他们交换了一个眼神。陈霜嘴角微微一弯——外人看不出那是笑意还是别的什么，但李长生看得出来。

那是"可以了"的眼神。新帝国的第一场考试过了。后面还有无数场。但第一场过了。

（第692章完）

# 第904章 她选择留下

林牧飞升之后的第三天，修仙界出现了短暂的"空白"。

不是灵气的空白——灵气在飞升的那一刻不但没有减少，反而因为天地对飞升者的呼应而暴涨了一波。那波灵气的余韵在太行山上空持续了整整一个时辰。方圆五百里的修士都能感觉到那道从山顶直灌高空的青色光柱。光柱散去之后，太行山主峰的高度被永久性地拔高了将近三十丈——山顶的基座在灵气的冲击下微微抬升，形成了一座天然的修行宝地。

空白是另一种——是修仙界所有人心里的一道裂缝。林牧走得太突然。虽然每个人都知道他迟早要飞升，但"知道"和"接受"之间隔着一道很宽的距离。过去三百年里，林牧是这片天地的定海神针。有他在，灵潮不会出问题、散修不会被欺负、大宗门的暗箱操作要收敛三分。现在他不在了。

一些散修当天就开始搬离太行山麓。不是怕什么——是觉得没了意义。林牧召集他们来这里，给他们功法、给他们资源、给了他们平等的修炼机会。现在那个召集他们的人不在了。有人选择了继续留下——为了苏晚，也为了一路走过来的情谊。但大多数人需要时间适应没有林牧坐镇的修仙界。

苏晚没有去送他。

不是因为不敢看——是因为她在一个月前就已经做好了不看他的准备。她说"我明天上山"，但她没有去。她在银杏树下坐了一整晚，日出的时候站起来，对着山顶的方向看了一会儿——那道光柱太亮了，想不看都难。光柱冲上天空的时候她甚至感觉到心口有什么东西被拽了一下——不是痛，是牵引。是那种两个人之间的线被忽然拉长了几百倍、绷得更紧了、但没有断的感觉。

然后光柱消失了。

她感到了一种奇特的安静。不是失落——是清楚。她清楚自己接下来要做什么。她清楚这条路是她自己选的。她清楚他不会出事——她对他有信心。

银杏树的叶子在她身侧落了一片。她弯腰捡起来，夹在随身的纳戒里——她的纳戒里一共有九百多片叶子，每年秋天捡一片。从第一年的指甲盖大小的嫩黄小芽开始，到第九百年这张手掌大的金黄色的扇形叶片。每一片都在纳戒里完完整整地保留着，没有干裂、没有变脆。灵气保鲜。

她转身，往山下走去。脚步不快不慢。和平时一样。

太行山脚下有一个小镇——镇的名字就叫太行镇。九十年前还只是几个修士在路边搭的几间木屋。现在已经有将近两千个修士常住于此，加上来朝圣的散修和参加修学团的年轻人，日常人口在三千上下。镇上的格局很简单：一条主街从南到北贯穿，街两边是石砌的二层小楼——楼下是铺面（灵药铺、兵器铺、功法交换铺、灵食馆），楼上是住人或打坐用的静室。街道的尽头是一片开阔的广场。广场的尽头是太行山的南门——一道宽约三丈的石阶往上走，过了山门就是登山道。

苏晚从银杏树下下来之后，直接去了广场。

广场上已经站满了人。不是来接她的——是在等消息。他们看到了从山顶灌下来的光柱，但没有亲眼看到林牧的飞升过程。他们在等一个人来告诉他们事情的经过。

苏晚走进广场的时候，几百双眼睛同时转向了她。她穿着一身浅灰色的素袍，头发简单地束在脑后，神情很平静。平静到了让有些人不适应——他们以为她会哭。她没哭。

她在广场中央停下。环顾了一圈。

"他走了。"

三个字。声音不大，但因为广场忽然安静了，几乎所有人都听到了。

"走之前他让我帮他带一句话给各位。"她从袖子里取出一张纸——林牧临走前留的，字迹端正但笔画很轻，像是在控制着不让笔尖太用力以免把纸戳破。

"三百年来多谢各位照顾苏晚。"

她原本打算把这句话单独告诉几个亲近的人。林牧非要她当众念。他说：修仙界需要知道——你不是我的附属品。你是被照顾的，也是被尊重的。这两件事不矛盾。

她把纸折好放回去。停顿了一息，然后提高了声音："从今天开始，太行山接纳所有愿意修炼的人——不论资质、不论背景、不论门派。不需要推荐信，不需要入门测试。只要你愿意来修行，山上有你的位置。"

人群出现了细微的骚动。有人窃窃私语。有人张大嘴巴。有人说"她疯了？不收门槛？"

不收门槛。这是她和林牧讨论了很多年的事。修仙界最不合理的事情之一就是"收徒门槛"。各大宗门选拔弟子的标准越来越离谱——要看天赋、要看根骨、要看家族出身、要看携带的灵石数量。普通的散修——尤其是那些资质平平但意志坚定的人——被拦在了修仙的大门之外。

这不对。天地给了每个人一样的灵气。凭什么只有少数人能享用？

林牧在第九卷后期就开始帮她建立这个体系。他在太行山上布置了一套灵聚大阵，能把周围的灵气汇聚集中，让资质不够好的人也能感受到灵气的流动。他还把自己的几部剑诀简化成了适合初学者的版本——简单到连一个从未接触过修仙的普通人都能在三个月内入门。

他不收学费。这套体系的名字就叫"太行书院"。

书院的理念很简单：不收费、不限制、不抛弃。只要有人愿意学，就有人教。教的不是最顶级的功法——那些需要天赋和机缘——教的是基础。扎实的基础。每一个从太行书院走出去的人，不论以后走哪条修仙路，都不会因为根基不稳而走火入魔。

苏晚现在要做的就是把这个体系从纸面变成现实。

第一批学员在下午就到了。是从太行镇的散修群体里来的——这些人原本就住在附近，听到消息后第一时间赶来了。一共三十二个人。年纪最小的十五岁（一个在太行镇帮工的少年，每天搬砖砌墙，手上全是茧），年纪最大的六十七岁（一个在附近村庄住了四十年的赤脚医生，年轻时做过当修士的梦，但被老家的宗门以"资质太差"为由拒了三次）。

苏晚把他们带到山门内的第一座石台上——那是林牧走之前专门为了入门教学而平整好的场地。石台约九丈见方，地面铺着青石，石板上刻着基础的灵气引导纹路。林牧当时刻这些纹路用的是自己的道息——道息在每一道刻痕里沉了一层极薄的、肉眼看不见的暖光。苏晚走上石台的时候脚底隔着鞋底也能感受到那层暖意。那是他留在下界的最后一批工程量之一——平整石台、刻纹路、布聚灵阵。完工那天他站在石台中央，把脚底的灵气灌进石缝，然后说："可以了。够用了。"三个字。那三个字现在还残留在石头的脉理中。

她没有把这些告诉三十二个学员。这不是需要在第一天讲的事。第一天她只讲一件事。

"今天不说功法。"苏晚站在石台中央，面对着三十二个年龄不一、表情各异的散修。"今天只说一件事——修行是什么。"

她停顿了一下。风把她耳边的碎发吹起来，她伸手别到耳后。那只手的食指上有几个极浅的疤痕——是炼丹时被火灼的。修炼了近千年，这些浅疤早就可以用灵气完全消除了，但她没有。林牧有一次问她为什么不留着光滑的皮肤。她说这些疤是她的年轮。每道疤对应一个她犯过的错。第一道——助燃灵火时把手放太近了。第二道——练祛毒丹时没控好温度。第三道——为了调一味极烈性的药引。她说：疤痕不是丑。是对自己走过的路的诚实。

"修行不是变厉害。修行是——认识自己。知道自己要什么、怕什么、为什么活着。然后在此基础上——再多撑一天。再多走一里。再多说一次'我可以'。"

"功法可以学。丹药可以炼。法器可以造。但如果你不知道为什么修行——给你太上的真仙诀也没用。你会练到半途，忽然发现力量在那里，但你不知道该拿力量做什么。"

"所以第一天我们不练功。我们聊天。互相认识。你说说你的故事，我说说我的故事。"

三十二个人面面相觑。他们在修仙界待了这么久——有人待了几年，有人待了几十年——从来没有人问过他们的故事。宗门里的师父只会说"资质如何、修为如何、努力程度如何"。他们的名字在师父那里是一串数据。不是一个人。

那天下午，石台上三十二个人加苏晚，坐在秋日的暖阳下，一个一个地说自己的故事。

陈小树是第三个开口的。他从早上就站在第一排——不是因为积极，是因为他在工地上习惯了"站最前面的人活最重"，把这种习惯带到了书院。十五岁的少年肩膀已经比大多数同龄人宽了，手心全是搬砖磨出来的茧——不是修炼磨的茧，是搬砖。红砖、青砖、石板。他从十岁起就在太行镇的建筑工地帮工。最开始只能搬一块砖，十二岁能搬三块，十四岁能扛一袋石灰。他的工钱是一天三个馒头加十文铜钱。他把铜钱攒下来——不是给自己买功法，是给他爹买治腰疼的药。

他爹早年在河道里捞沙，落下了腰病。一到阴天就疼得起不来。陈小树对修仙的全部认知来自他在工地上见过的那些过路修士——他们脚踩法器从天空飞过，衣袍翻卷，头也不低。有些会停下来喝口水，有些连停都不停。有一次一个筑基期修士路过工地的时候丢了一块碎灵石在地上——不是给他的，是掉落的。他捡起来，追了三条街才追上，把碎灵石还给人家。那修士看了他一眼，说了一句话："你资质太差。修不成的。不如攒钱买个婆娘。"然后飞走了。

陈小树说他不恨那个人。恨没用。恨不能让爹的腰不疼。恨不能让灵石从天上掉下来。他说他想修炼不是因为想变厉害——是因为他有一天也想对那些帮人搬行李的小孩好。不是给他们馒头——是教他们怎么自己蒸馒头。他说完这些之后挠了挠后脑勺，补了一句："我名字是我爸起的——说木匠的儿子就该叫小树。但树也可以长高。不一定非要长在木匠院里。"

苏晚听完之后没有立刻接话。她过了三息才说了一个字："对。"然后她让下一个人开口。

那个六十七岁的赤脚医生叫钟大爷。他是最后一个开口的。所有人都说完了他还没说——不是不愿意，是在观察。他习惯了先看人、再说话。做了大半辈子赤脚医生让他养成了一个本能：先看懂一个人的身体再相信他的话。他观察了一个下午苏晚怎么听、怎么点头、怎么对每一个人的故事做出回应。然后他在太阳快要落下去的时候举起了手。

"我能说了吗。"他的声音不大但很清晰，像在问诊时跟病人确认症状。

苏晚对他点了点头。

钟大爷从袖子里掏出了一本小小的册子——是那种粗纸订的、封面被翻得起了毛边的旧册子。他把册子放在膝盖上。册子里密密麻麻地记着名字和症状——不是药方，是镇上三代人的病史。"老刘家遗传胃病——三代表现不同：爷爷是反酸，爹是胃寒，孙子是消化不良。同一个根在不同身体上长出了不同的叶子。"他把这段念出来的时候，语气和念自己写的诗没什么两样——不是因为骄傲，是因为认真。他对待那些泥腿子病人的病史和对待修仙秘籍一样郑重。

他年轻的时候去了三次宗门。第一次是十七岁——去的是青云宗。负责招募的弟子让他把手放上去测根骨。他把手放了上去——那是一双粗糙的、长满了老茧的手。指甲缝里嵌着草药渣——芍药、当归、黄芪——那些药味已经渗进了指甲的角质层，洗了三天也洗不掉。招募弟子看了一眼那双手就摇头了。他连测灵石都没通过。

他回去继续给人看病。二十年后三十七岁——他又去了一次。测灵石这回给了他一个很低的分，但至少过了最低线。招募弟子问他多大了，他说三十七。那弟子直接笑了——你三十七岁了，就算你从现在开始修，修到筑基也要五十年，到时候牙齿都没了。钟大爷说不打架。弟子说不打架修什么仙。第三次去的时候他已经六十岁了。头发白了一半，走路的步子从大步变成了小碎步——不是腿脚不好，是六十年里他在病床和药柜之间来回走了太多路，膝盖的软骨磨薄了。他站在宗门口等了三天。没人见他。第四天他回了村，继续行医。他把那本旧册子在怀里揣了六十年。每添一个名字就多一页。他这辈子最大的本事不是医术——是把一个镇上三代人的小毛病都记在脑子里。他说现在他想修仙了——不是为了长寿，是为了能用灵气给人治病。灵气比针热，比药透。灵气能钻进经脉里帮人疏通他手指够不到的堵塞。

苏晚听完每一人的故事。认真地点了点头。然后她袖子里取出一张纸——是林牧留给她的另一个东西：一套《灵气入门十二法》的简化版口诀。她把它拿到每一个人面前，一个一个地矫正他们的坐姿，帮他们把呼吸调整到和天地灵气的节律同步。

石台上的灵气在那一晚第一次产生了自发流动——不是苏晚引导的，是石台感应到一群真实而恳切的心跳之后，自己开始呼吸的。

太行书院开学了。

没有人知道，一年之后，从这里走出去的第一批筑基者，会在修仙界掀起一场山崩海啸般的变革。也没有人知道，一千年后，太行书院会成为下界最大的修仙熔炉，从这里走出去的修士数以百万计——每一个人都能准确地背诵入学第一天苏晚教他们的那句话：

修行不是变厉害。修行是认识自己。

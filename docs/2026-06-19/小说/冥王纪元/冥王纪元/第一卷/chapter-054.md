# 第054章 李长生，是冥王转世？还是传承人？

第三天，李长生一个人出了门。

他没告诉小王，自己坐了一趟公交车出城。身上穿着一件旧夹克，兜里揣着两块碎片，走到城郊的荒山脚下。

他想找个没人的地方，好好想一些事。

荒山不大，早年间是个采石场，山体被劈掉一半，裸露的石灰岩白森森的。山下散着几个废弃的砖窑，杂草丛生。李长生找了块大石头坐下，周围安静得只剩下风声。

他来这里，是想跟自己说几句实话。

拿出两块碎片，放在石头上。残魂的意识从碎片中飘出，在不远处凝成一个半透明的虚影。老头的形象比之前凝实了很多，看起来像一个坐在对面石头上的清瘦老者。

"残魂，我问你一个问题。"李长生说，"你回答我实话。"

"你说。"

"我到底是不是冥王转世？"

残魂没有立刻回答。他看了李长生很久，久到风换了三次方向。

"我不知道。"他说。

"你怎么会不知道？"李长生的声音稳，但稳得有些用力，"你是冥王令的器灵，你跟了他一万年，你连他转世了没有都看不出来？"

"因为转世这件事，不是你想的那样。"残魂说，"一个神级强者死后，灵魂可能分裂成数十个碎片，各自进入不同的空间，经历不同的生命。你有可能拥有他灵魂中最大的一块碎片，也有可能拥有的是最小的一块，还有可能——你根本没有他的灵魂碎片，只是恰好体质与冥王令碎片契合，被它选中了。"

"哪种可能性更大？"

残魂又沉默了。

"你的灵根。"他慢慢说，"冥系灵根。你自己不知道有多罕见——这不是万里挑一，不是百万里挑一，是整个宇宙在最近一万年里从未出现过的灵根类型。唯一已知拥有冥系灵根的修士，是我的主人。"

李长生感觉心脏被什么东西攥了一下。

"那又说明什么？"

"说明要么你就是他的转世，要么你是他特意选择了的传承人。"残魂说，"但究竟哪种，需要凑齐更多碎片才能确定。如果某一块碎片中封存了冥王的核心记忆——也就是他临死前对'后来人'的全部计划——你才能知道答案。"

李长生低下头。

他看着自己的手掌。粗糙的、布满老茧的、指甲缝里永远有洗不干净的土迹。这双手种了十年地，拔过无数的草，挑过数不清的担子。他和任何一个中国北方农村的普通农民没有任何区别。

现在有人说，这双手的主人，可能是一个死了万年的神。

"如果我是他的转世——"李长生的声音很轻，"我还是我吗？"

残魂看着他的眼神，忽然变软了。一种不属于器灵的、更像是人类的眼神。

"你是不是你，不取决于你是不是他的转世。"残魂说，"取决于你想成为谁。"

"这不是废话吗？"

"不是废话。"残魂说，"我的主人一辈子最大的遗憾，就是没有选择。他生下来就被判定为冥系灵根，被视为异类。所有人怕他，恨他，或者想利用他。他没有选择，只能一步一步走到那个位置。他曾经跟我说过一句话：'如果有来生，我不想再当冥王。'"

李长生愣了。

"他说他不想当冥王？"

"对。他累了。"残魂说，"一万年的战争，一万年的统治，一万年的孤独。他站在宇宙之巅，身边没有一个人。连我都不算人。"

风从石灰岩壁吹过来，带着干燥的土味。李长生忽然觉得很荒诞——两个人坐在废弃的采石场上，讨论一万年前一个死掉的神是不是累了。

可他是真的想知道答案。

"如果我继续收集碎片，"他说，"最后我会成为他吗？"

"我无法保证。"残魂说，"我只能告诉你：这取决于你自己。如果你融合碎片的目的是变强、出人头地、一人之下万人之上——那你最后很可能会成为他。因为那条路他已经走过一遍了，碎片里的记忆会自然而然地推着你走。"

"那如果我不想成为他呢？"

"那你就要想清楚。"残魂说，"你到底是谁。不是别人告诉你的'你是谁'，是你自己认可的'你是谁'。"

李长生很久没有说话。

太阳从头顶转到西边，把石灰岩染成淡金色。几只在悬崖上筑巢的红隼掠过头顶，尖啸声在采石场里回荡。

他忽然想起了很多年前的事。他妈还在的时候，有一年冬天特别冷，院子里的水管冻裂了。他自己拎着扳手去修，手冻成了萝卜，拧了半个小时没拧动。他妈站在边上看着，没帮他，等他终于拧好了，他妈才说："长生，记住，自己的事自己做。"

那年他十二岁。

后来他去邻村帮人犁地，赚了二十块钱，买了一斤肉回家。他妈看着肉，没笑，也没哭。她把肉炖了，盛了两碗，一碗给她自己，一碗给他。吃完了，他妈说："长生，人这一辈子，能指望的只有自己。"

那年他十五岁。

他妈走那年他十九岁。丧事办完的第三天，他拿锄头去地里干活。隔壁王婶站在路边看他，表情很复杂："长生，你不歇两天？"

"歇了也没人帮我把地翻了。"他说。

那些年，他没有想过自己是谁。不用想。他就是李长生，李家庄的农民，爹妈走了，自己过。每天干活、吃饭、睡觉，没什么选择的余地，也没什么值得纠结的。

现在不一样了。

现在有人告诉他：你可能是一个神。有人告诉他：你可能是一颗棋子。有人告诉他：你的命运在万年前就已经被安排好了。

李长生站起来。

他走到采石场的断崖边，看着下面乱石嶙峋的坑底。风吹得他的衣角烈烈响。

"残魂。"

"在。"

"我告诉你我是谁。"

残魂看着他。

"我叫李长生。"他说，"我爹叫李大柱，我妈叫王翠兰。我是李家庄人，种地的。我不管一万年前发生了什么，不管冥王是不是我前世——我是李长生。这辈子，是我自己的。"

他顿了顿。

"碎片我会继续找。不是为了成为下一个冥王。是为了弄清楚真相。弄清楚那些人——不管是诸神联盟的后人，还是建国那年封禁灵脉的人——到底想干什么。"

"然后呢？"

"然后——"李长生转过头，脸上是被太阳晒出的黝黑底色，和一双忽然变得很亮的眼睛，"我自己决定走什么路。不是他替我走。"

残魂看了他很久。

然后微微低下头。

"小子。"他说，"你刚才这句话，像他。"

"哪句话？"

"'我自己决定'。"残魂说，"他年轻的时候——还没成为冥王的时候——也说过一模一样的话。"

李长生愣住了。

残魂继续说："也许你不是他的转世。也许你们只是偶遇。但有一件事可以确定：如果这个世界上有谁能继承冥王的意志——不是他的力量，不是他的法器，而是他的意志——那这个人，很可能就是你。"

李长生没有说话。他站在悬崖边，看着太阳一点点沉下去。远处的城市亮起灯火，近处的荒山被夜色吞没。

他听见了风声。但这一次，风声里多了一点别的什么。

那是掌心的两道黑纹，正在轻轻地跳动。

像心跳。

（第054章完）

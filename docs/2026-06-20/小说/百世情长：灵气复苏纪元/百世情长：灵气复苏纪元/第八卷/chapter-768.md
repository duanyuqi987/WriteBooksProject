# 第七百六十八章 梦想升华

联合共治会第十一年。林牧和苏晚同时收到了来自母树的感应——不是传讯，是桂花树叶的一种极细微的频率变化。母树告诉他们：第三道门——"信任之门"——将在下界准备好后自然开启。而"准备好"的标准不是某一个人的本事——是整个下界在足够长的时间内持续传递包容、支持和信任——直到这三者变成文明的本能。

苏晚在书房里写道——"梦想的最终形态不是个人的——是文明的。我们的梦想曾各不相同——我想铺路，你想探天。但最后它们在同一条路上碰头了——因为铺路的人也需要知道天上有门，探天的人也需要地上有墙。互相支持的最终结果不是我们各自实现了各自的梦想——是所有人开始把'支持别人'作为自己的梦想之一。"

林牧在灯火塔展馆里加了一块新石牌——石牌的材质和蜀山共容碑一样——未打磨的青石——形状不规则。他自己刻的字——不多——只有三行——"包容不是被需要的——是被传递的。——苏晚第一百世——支持不是你一个人的推力——是许多人的同时举手。——林牧——信任——第九卷继续。——留给后来者。"

杜小月在展馆记录中批注——"林先生第一次把三个人（苏晚、他自己及后来者）的贡献写在同一块石牌上。他以前只说'我'——后来学会了'我们'——现在有了'后来者'。——杜小月。"

这天的灶台由林牧亲自值班——不是代谁——是他自己排的班。他的手还是那个写过几百万行代码的手——现在已经能利落地给五六十个人盛粥而不洒。秦无夜从上界专程来吃——不是吃粥——是来吃"林牧亲自煮的粥"。她吃了第一口——然后夸张地皱了一下眉——"还差了点桂花。——但米是真的。"林牧没反驳——只是默默地往锅里多撒了一把桂花。

（第七百六十八章 完）

# 第280章 火星任务正式启动

出发时间定在格林威治时间凌晨四点整。

不是刻意挑这个时间——是祝融号的发射窗口由灵符计算机根据火星-地球相距最近点的轨道动力学精确推导出来的。凌晨四点十七分，火星和地球的距离将进入最佳发射窗口，灵符推进器的聚灵环启动后可以在最短时间内完成行星际穿越。小王的灵符引擎计算结果精确到了秒级别。

凌晨两点半，天工基地的地下船坞已经灯火通明。这不是上次登月的船坞——祝融号比望舒号大太多了，原先的地下基地装不下。张总工带着工程队在巴丹吉林沙漠底下又往下掏了四十米，凿出了一个足以停泊大型星际飞船的巨型地下空间。穹顶的人造星空模拟系统和望舒号当年用的一样——但星空图已经更新为最新的真实星图。穹顶最高处那颗最亮的红点是火星。

祝融号停在船坞正中央。它的船体长约一百二十米——比望舒号大了将近一半。船壳不是铝灰色，是一种近于暗红与黑色之间的陶瓷质感涂层——张总工特别定制的火星专用抗辐射和抗沙尘复合材料，整艘船在光照下会折射出一种类似于古代漆器表面的暗沉光泽。船首依然是那道收窄的锐利弧线——冥王碎星舰的龙骨样式是一脉相承的，但祝融号的船首弧度比望舒号更大一些，这使得它在行星际空间飞行时有更好的姿态控制力。船壳正面刻满了改进版的复合灵符——小王的灵符引擎经过了月球数据库的技术升级，新一代灵符的功耗降低了百分之四十，但推力系数翻了一倍。

船侧漆着两个大字——祝融。用的是张总工亲手挑的字体，篆书变体，笔画中的横折处带着一点如火苗般的轻扬折角。

凌晨三点，远征组开始集结。

李长生是最早到船坞的。他穿了一套深灰色的作战服——和登月那次不同，这套作战服的关节处嵌了薄片灵石护甲，胸口位置有一枚他自己刻的冥纹标识。背上背着一个最大的灵储袋——里面装着龟相的甲壳图、甲壳上刻的整幅火星离宫结构全图、以及许冰给他的一本手写册子《宇宙修士交往公约》纸质本（许冰说：如果火星上遇到任何非地球的智慧生命——先给对方看这份公约的第一条。第一条写的是：任何文明都有权自主决定其生存方式）。

陈霜第二个到。她这次背的不是一柄剑——在作战服外挂了四柄剑。主剑依然是霜降，背在背上。左腰一柄短剑——从昆仑总枢地下冥系灵脉旁新锻造出来的一柄冥铁短剑，剑身不到两尺，但锋刃由冥火淬炼，对任何灵气护盾都有穿透加成。右边一双腿带上各插了一柄小剑——陈霜说这是陈家的剑阵基础配置，四剑齐出可以做"四象封魔"阵。她今天把头发扎成了利落的马尾，手腕上戴了一串老陈送的佛珠——老陈不信佛，但他说这串佛珠是他在兰州跑快递时一个老太太送他的，老太太觉醒之后测出了罕见的预知系灵根，送佛珠的时候跟老陈说了一句话："让那个拿剑的女娃戴着，火星上有用。"

小王第三个到。他背的是一个改装过的灵符笔记本——外壳换成了老马提供的合金防辐射材质，内置三块独立的灵符处理核心（一块主核心和两块热备份核心），可以在飞船的灵符引擎出现故障时独立维持导航和数据解析。他的背包里还塞了一台便携式卫星灵符发射器——到了火星轨道之后，第一件事就是往火星周边撒一圈天网系统的缩小版监测卫星。他说这不在原计划里，但"来都来了——到火星就得织火星的网"。

刀疤第四个到。他带的东西最简单——一把双手重剑，一套备用作战服，以及一个兵册。兵册上写着他在冥王禁卫军中标记为"火星任务可遴选对象"的四十三个士兵名单——这些人都是他在训练过程中注意到的最顶尖苗子。刀疤有个想法：如果火星离宫的战傀一族有人幸存——或者回溯阵里的精英战斗录像能用来训练——他想在火星上设一个"禁卫军火星训练分基地"。他问过李长生，李长生回了一句："到了再看。但名单先带着。"

龟相在刀疤肩上趴着。它缩成了拳头大小，方便携带。它的龟壳上昨晚新刻了一道小王给它加的微型灵符通讯器——和地球留守组之间保持二十四小时加密通讯。

第五个成员不是原来队伍里的人。

他叫严烈——三个月前还在长江中下游的一家私营钢铁厂里烧锅炉。灵根：火系。修为：玄师境巅峰——即将突破宗师。他是在刀疤禁卫军第一批训练中进来的，最后考核中在整个矿区里被三个老兵"障碍"堵在矿坑深处时，一个人用火焰把矿坑石壁烫烤出一条逃生的通道冲了出来——虽然出来的时候全身是伤，但是手里抓回来七枚符印。刀疤给他的考核评语只有四个字："这人给我。"

严烈被分配进远征组那天，李长生单独找他谈了一次。李长生只问了一个问题："你以前在锅炉房烧锅炉，现在要去火星上烧比锅炉热几千倍的岩浆——怕吗？"严烈回答的速度很快："锅炉房的温度计每天在七百度的位置上转。我看了十二年。后来我想明白了——越怕火，火越烫。不怕了，你就成了火。"

凌晨三点半。留守组全员到场——不是来坐飞船的，是来送别的。

老陈提着一个塑料袋走到李长生面前。袋子里是一瓶老干妈和两盒速溶奶茶。"火星上应该没有便利店。"他说。语气很平常，像当年送同事去别的片区送快递一样。"我跟小王确认过——这两样东西常温保存，保质期还有一年。省着点吃。"

许冰递给李长生一个密封的灵符档案袋。袋子里是《宇宙修士交往公约》的最终定稿全本，每一页右下角有她的亲笔签名和日期。她没说什么煽情的话，只简短交代了一句："公约第六章第一条——面临存亡威胁时可暂停所有条款。记住这一条就够了。"李长生把档案袋收进灵储袋里。

老马从地质背包里掏出一个扁平的金属盒。盒子上贴着一张标签——"火星表面灵脉探测套件——马建国制"。盒子里是一套迷你版的灵脉测量设备：一个灵气波动传感器、三个可植入土壤的灵脉信号标记器、以及一本手写的"火星地质快速评估指南"——老马熬夜写的，一共四十七页，用的是地质学规范术语，但每段后面都加了自己手写的白话解释。"到了火星第一件事——先把你脚下那块地的灵脉情况测一下。测不到灵脉就测地温。地温有异常幅度就可能说明下面有残留灵脉活动。不要用地球经验去推断火星地质——火星的地壳比地球安静得多，灵脉活动模式可能完全不同。"

小胖把一个最大号的灵储袋交给了李长生。袋子装满了远征组半年的所有丹药——三千一百九十枚，一瓶不少。袋口拉链上栓了一张小胖手写的使用说明书——"益气丹：每天早晚各一枚。回灵丹：战斗后三十分钟内吃掉。解毒丹：遇到不明气体/液体先含在嘴里。破境丹：突破瓶颈时再吃——别当糖嗑。护脉丹：火星大气压强不到地球的百分之一，你的经脉第一次在那种环境下运转灵气会很难受——难受就吃。"

林晓把一份远征组五人的健康档案递给了李长生，附带着医疗箱——里面有她自己做的灵贴、各类急救药、以及一本手写的《星际应急救援指南》。她把每个人的身体状况写了在档案第一页："李长生：冥系灵根适应性强，但注意火星环境下冥气来源较地球少——修炼前先确认周边有无天然冥气残留。陈霜：水火双修——火星表面干燥极寒，火系功法消耗会翻倍，建议多用冰水转换的水系功法。小王：身体素质最弱——注意任何皮肤破损不可暴露在火星大气中，在飞船气闸舱完整密封之前严禁出舱。刀疤：体修适应性强但修复速度依赖灵气——如果作战负伤立即用回灵丹辅助自愈。龟相：怕冷（火星地表夜间温度可低至零下一百三十度），必须待在李长生作战服内侧口袋中维持体温。严烈：火系灵根在火星表面被严重限制（空气中的氧气密度太低），建议主要修炼火系灵气内部爆发类功法——不要依赖外部火焰。"

凌晨四点整。张总工站在船坞控制室的主控台前，对祝融号完成了最后一次系统自检。推进系统正常。灵符导航系统正常。生命维持系统正常。通讯系统——跨行星灵符加密通道已建立，延迟约四分钟（火星与地球之间的信号通信延迟在最近距离处约为四分钟——小王无法解决光速上限问题，但加密级别和通讯稳定性做到了当前技术的上限）。

"可以出发了。"张总工的声音从扩音器里传出来。"祝融号一切正常。发射窗口还有十分钟——这十分钟之内启动推进系统，到火星大约需要七十二小时。飞行过程中飞船的推进力和航线由灵符引擎自动维持——你们可以在船上正常活动。到了火星轨道之后——降落舱会从船体腹部自动分离并搭载着陆。降落地点坐标我按照龟相给的伊希地平原位置做了精确匹配。降落精度正负五十米。"

李长生站在飞船腹部下面张开的斜坡通道前。远征组六人已在身后列齐。留守组站在通道另一侧——隔着十来米的距离。

"最后的最后。"李长生转过身面对着留守组，"地球交给你们了。半年。半年后如果通讯断了——不是我们死了，是火星离宫在地下深层没有信号。不要慌。按计划把防御系统建完。到了宇宙来客到达的那天——不管我们回来没回来——你们必须能守。"

老陈点了点头。这个点头包含了所有留守组想说的话。

李长生转身走进了斜坡通道。

飞船内部的灯在他踏入的瞬间自动亮起——不是刺眼的白光，是经过灵石柔化的暗暖光。船腹主舱很宽敞——至少比望舒号大三倍。陈霜走上通往驾驶室的扶梯，入座领航员位——在望舒号上她就是领航员，这次继续。小王坐在驾驶室最前方的灵符监控台前——屏幕上的符元已经全部升空到待命状态了。刀疤把重剑靠在自己的座位旁边，系好座椅安全带。严烈站在舱室的观察窗前，透过灵符强化玻璃看着外面船坞的人造星空。龟相缩在李长生的口袋里，只露出半个脑袋。

李长生在主驾驶位坐下。双手搭在控制台的两侧——触控面板上浮现出他掌心的冥纹图案。祝融号的生物识别系统是用他的冥纹频率做钥匙的——这艘船的推进核心不是机械按钮，是冥纹共振。

船坞内响起了张总工的声音。"按传统——祝融号首航。倒计时准备。"

"十。"

李长生低下头，把右手按在触控面板上。五道冥纹全亮，第六道还在拓不完整但已经能用。面板上的飞船状态图跳成了绿色。

"九。"

陈霜把安全带扣上。扭头看了李长生一眼。没有说话——认识两年多，有几百次眼神就够了。

"八。"

小王合上灵符笔记本的屏幕，又打开。最后一次确认——所有参数全绿。

"七。"

刀疤把兵册放进口袋，双手握在座位扶手上。脸上那道疤在舱内暗暖光下反而显得柔和了些。

"六。"

严烈从观察窗前走回座位，系好安全带。看着自己的双手——十二年在锅炉房里被烧红的手掌。

"五。"

龟相在李长生口袋里翻了个身。它想到火星离宫底下熟悉的一切——一万两千年的尘封。

"四。"

留守组在通道外面站成了一排。老陈下意识地把手伸进口袋——没有快递单，只有一颗从昆仑山脚下捡的普通石子。

"三。"

老马看着祝融号的船尾推进环开始发光——暗红色的光芒，和他画的那张地球灵脉全图上的标记是一个颜色。

"二。"

小胖把最后一瓶补炼的益气丹放进了留给远征组的备用灵储袋中——出发前刚出炉的，盖子还没完全冷。

"一。"

许冰握住了林晓的手。两个人都没说话。

"点火。"张总工的声音有一瞬间被船坞扩音器的反馈啸叫打断了。然后是灵符推进环启动的巨响——不是轰鸣，是一种闷闷的、低沉而连续的共振声。整个船坞地面的灵石板块都在微微振动。

祝融号的推进环亮了。一圈暗红色的光从船尾释放出来，凝聚、扩大、然后推着整艘船从船坞的正下方——那个刻着环形冥纹的穹顶开口——向上滑升。船壳上的灵符一道一道地亮起来，暗红色的光芒在巴丹吉林沙漠地下的黑暗中像一道裂开的岩浆河。它在向上升。穿过船坞的天顶开口，穿过沙漠的表层，进入了凌晨夜空。

在地面上——巴丹吉林沙漠深处的一个不起眼沙丘旁——如果此刻有人站在那里，会看到沙丘突然裂开一个大口子，一道暗红色的光芒从中喷射而出，然后一艘长得不像任何人类航天器的飞船以直觉上不应属于重力的姿态从地底升起，在夜空中爆发出一次瞬间的炽光——随即消失在东北方向的星空。

祝融号进入了上升轨道。船内的灵符屏幕显示：速度为每秒十七公里。相对于火星的距离——五千五百万公里。预计到达时间——七十一小时。

驾驶室内没有人说话——不是因为安静是一种仪式，是因为每个人都在用自己的方式告别地球。陈霜看着窗外逐渐远去的大气层边缘——那层淡蓝色的弧线——手搭在剑柄上。小王盯着屏幕上不断变化的符元阵列，用数字在告别。刀疤闭着眼睛在提前复盘到达火星后的侦查流程。严烈在学——这是他第一次上太空，他在用锅炉房里的规矩理解失重：不是脚离了地，是锅翻了。龟相把脑袋缩进了壳里——不是怕，是在用古老的方术测量此刻的星际方位。

李长生没有看仪表盘。他看着窗外那颗正在缓慢变大的红色光点——火星。从昆仑山顶上看到的那个小红点，现在正在以每小时不可逆转的速度变成真实可触的红色地表视野。五千五百万公里——比月球远了将近一百五十倍。它在黑暗的太空中安静地亮着，像一颗一万两千年来没有熄灭过的炭火。

飞船穿过地球引力范围边界的那一刻，李长生忽然把手放到左胸口上。作战服内袋里有一个小布包——里面装着几颗土。不是灵石土，不是灵脉土，不是任何有灵气的土——是李家庄祖坟旁边那棵老槐树根下普通的黄泥。他出发前回了一趟李家庄，在祖坟方向磕了三个头。磕完之后在槐树底下抓了一把土。

不是给祖上的。是给那颗一直陪着他的槐树妖——从第一天挖出碎片的时候它的根就在吸收灵气分给他。两年来树没说过一句话。但他知道树在。

祝融号飞远了。地球在身后缩成了一颗蓝白相间的弹珠。在猎户旋臂方向——三百五十光年外——有什么东西也在移动。不是冲向地球——目前还不是。但那三个观测站的对准方向从未转回去过。

李长生把掌心按在胸口的那几颗黄土上。黄泥是凉的。冥纹是烫的。

"火星见。"他说。

（第280章完）

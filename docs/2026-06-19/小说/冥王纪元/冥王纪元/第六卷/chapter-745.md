# 第745章 帝者曾经是第五纪元的守护者

老人说完那番话后闭上了眼睛。呼吸变得极为微弱，每次吸气和呼气之间隔了将近一分钟。

冥离没有流露出任何惊慌。他已经习惯了。祖父的灵力耗尽之后，每次说话都伴随着巨大的消耗。刚才那十几句话，可能已经耗尽了他存了好几年的灵能储备。

"让他休息一下。"冥离低声说，然后带着李长生一行人退出了殿堂内室，来到了一间相对明亮的偏殿。偏殿的墙上挂满了壁画。不是万古纪元那种灵能投影——而是真正意义上的壁画。用手工画在墙面上的、笔触粗糙但充满力量的历史画卷。

"这是我祖父年轻时画的。"冥离指着第一幅壁画说，"那时候封禁刚完成。他每天要花二十个小时维持空间结构，剩下四个小时就用来画这些画。怕后代忘记。"

第一幅壁画描绘的是一场大战。天空中裂开了一道巨大的裂缝——和建国百年那天在李长生头顶上裂开的裂缝几乎一模一样。但壁画中的裂缝更大、更深、更可怕——从裂缝中涌出的不是五色灵气，而是无尽的光锥。每一道光锥轰下来，就有一颗星球化为碎片。

画下方用古语写了一行字。王思远翻译了出来："光锥之下，地球为墟。灵脉枯竭，文明断绝。冥王以自身封裂口，我等被封黑域。"

"所以——"李长生看着壁画，声音压得很低，"冥王不是被诸神围杀的。他是主动用自己的身体堵住了维度裂缝。"

"对。"冥离的声音不带感情，"一万个纪元来，我们一直被定型为叛徒。但在我们的记忆中，真正的故事是这样的：冥王和第五纪元主战派策划了整场战争的最后一击。他要用禁忌武器毁掉裂缝。第五纪元主战派支持这个计划。但联盟其他分支——包括你们第六纪元中一些被你们奉为先贤的人——坚决反对。他们认为禁忌武器的副作用太大，会毁掉整个维度层。"

"所以发生了分裂？"

"分裂。"冥离指向第二幅壁画。壁画上，一群穿白色衣袍的人和穿黑色衣袍的人各自站在一边，中间画着一道醒目的红色裂痕。"联盟裂成了两半。一半是'守序派'——坚持在现有力量框架内对抗敌人。另一半是'破阵派'——坚持使用禁忌武器。冥王是破阵派。我们也是。"

"然后呢？"陈霜的声音变得格外专注。

"然后灾难的真相来了。"冥离指向第三幅壁画——画中，守序派的首领站在一处高台上，向冥王宣布了最后通牒：放弃禁忌武器计划，否则破阵派将被强制封禁。画下方写着一行字："我们被称为叛徒，不是因为我们背叛了战争，而是因为我们坚持使用能打赢战争的唯一方式。"

李长生沉默地看着壁画。他的脑子在飞快地运转——这些信息和三百年前通过冥王碎片释放的记忆不一致。碎片的记忆中被简化为"背叛"的故事，但实际的历史远比"背叛"复杂。那是两条战争路线的终极对决。没有简单的对错，只有不同选择带来的不同代价。

"后来呢？"他问。

"后来冥王做出了决定。他不愿意让联盟内部分裂在敌人面前演变为内战。他主动放弃了自己的立场。不是改变立场，而是自己用自己的身体堵住了裂缝——用自己的命换取联盟统一的最后机会。他知道如果自己继续坚持使用禁忌武器，联盟内战就会爆发，敌人就会趁虚而入。所以他选择了——"

"牺牲。"李长生说。

冥离点了点头。

"然后我们——破阵派的残余——被守序派封进了黑洞。不是惩罚。是保护。守序派的领袖在封禁我们的时候说了一句话：'等一万个纪元。等到有人带着冥王令回来。到时候，你们的立场会被重新审判。'"

冥离的目光落在李长生身上。

"所以你不是来审判我们的人。你是来重新审判整个人——包括我们，包括守序派，包括冥王本人——历史的那个人。"

整座偏殿沉默了很久。

李长生抬起右手。冥王令的暗金光芒在他的掌心中缓缓亮起，像一把微小的、但是真实的灯火。他盯着那道光芒看了很久。

然后他放下手，看向冥离。

"我不是来审判任何人的。"他说，"一万个纪元前的对错已经烂在了时间里。我现在要问的只有一件事——"

他顿了顿。

"你们破阵派的禁忌武器技术，还能不能用？"

这句话落在偏殿的空气中，像把一块干透了的火石猛地往钢板上一刮——火星还没溅开，但刮痕的声音已经刺进了所有人耳膜最敏感的那个频率。

冥离愣了一秒。不是被吓到——是被打到了。他祖父冥烛活过了一万个纪元，靠着对冥王回来后重新审理破阵派冤案的信念撑到现在。他冥离是烛的孙子辈、第三代——他从小听祖父讲的那段历史在心中不知道复盘过多少次：一万纪元前，破阵派坚持的禁忌武器方案被联盟多数派否决；冥王牺牲自己封住维度裂缝后，破阵派被定为"分裂分子"集体封进黑洞。烛从来没有抱怨过一次封禁。他只是日复一日地在偏殿墙上画壁画——用黑岩石粉末调成的颜料，用手指当做画笔——把这场战争从破阵派的视角记录在冰冷的墙面，等待一万纪元后的某一天有人类的后代看到这些画并愿意重新想一想。

现在这个人来了。不是来审判任何人——是来问："你们那个被否决了一万个纪元的武器方案还能不能用？"

冥离的黑眼睛——那是第五纪元人种的特殊基因表达：瞳孔是纯黑色的，不会反光，像在眼眶里嵌了两枚微型黑洞——在那一秒之间亮了起来。不是物理的发光，是被一万纪元来第一次有人问了正确的问题之后那股蓄了太久的火终于找到了出口。那盏灯被封了一万个纪元。但它从没熄灭过。它的火一直在等有人来给它添油。油来了。

"能。"冥离说。他的声音在偏殿里反弹——壁画上的古文字似乎都在震颤。"我们的祖父被封进黑洞的时候带走了禁忌武器的核心设计——不是成品，是图纸。成品在最终决战前夕被守序派销毁了。但图纸——完整的技术路线、能量架构、所有关键参数的精确值——全部保留在我们部族的记忆晶体里。一万纪元来，我的祖父、我的父亲、我——我们三代人反复改进过这份图纸。它的核心逻辑没有变——从维度层面直接摧毁敌人的物质存在而非在空间层面作战——但我们的改进让它更可控了。你们第六纪元发展的灵能系统比我们当年更精细。如果把新纪元的灵能编码技术——"

他看了王思远一眼。

"跟我们的禁忌武器架构融合——它的破坏范围就可以被精确控制。不再是当年的全维度层面打击——而是针对特定目标的、带灵能识别码的精确清除。"

王思远推了推眼镜——王宇祖传的眼镜——手指在镜框上压了一下。程序员的思维开始运转了："你的架构是基于第五纪元的空间技术？如果给我们时间做灵能映射——我应该能把它的目标识别系统改写成新纪元标准——就能对接帝国现有的全部灵能识别网络。但需要时间。多久能完成？"

冥离转过头，朝内室的方向看了一眼——他祖父冥烛还在里面调息。"祖父一旦恢复灵力——他能把核心架构的全部记忆晶体交出来。我的部族中还有大约六十名在封禁中幸存的技术修士。他们每个人都至少专精于禁忌武器的某一子系统。如果配合你们帝国科学院——"

"三天。"李长生打断了他们的技术讨论。他这句话的音量不大——但偏殿里的所有人都停下了。"三天之内，把技术方案整合完毕。封禁正以不可阻挡的速度解除。第七颗黑洞内部的复仇舰队已经在黑洞内部锁定了帝国的坐标。如果他们先出来——他们不会来谈判。他们会直接攻击。"他停了片刻，然后补了一句——这句话是从旧纪元统一战争的教训中提炼的，"战争中最不值钱的就是谈判的幻想。最值钱的是先敌一步的精准打击方案。"

陈霜已经站起来了。剑还在鞘外——她的剑不知道什么时候又握回了手里。她在听技术讨论时一个字没说——她的注意力全在隔壁殿堂里那个苍老存在似睡似醒的呼吸声上。那呼吸太弱了。她担心这个从一万纪元前活到现在的老人撑不到他孙子交出全部图纸。

（第745章完）

# 第三百三十五章 修炼中的岁月

战后第八年。林牧恢复元婴中期。那柄名为"还旧"的剑陪他一起成长——三道灵气槽中的三道颜色分别从深灰变为淡银，再变淡金。也是他说不上名字的三种特殊灵气。剑柄麻绳因为每日练习，已经被手心磨出了一小圈凹痕——和旧剑柄上那圈一模一样。

苏晚的修为停止在元婴后期——封印解到了约百分之七十。她不动了。不是封不住了——是她主动暂停了解封速度。她觉得自己的底子还不够厚——境界提得太快，灵力虽然跟得上，但实战经验和心境都赶不上。所以她开始重做一件非常基础的事情：只练基础防御八式——天天重复一天练数十次。和林牧当年在写字楼时不折腾花式只做一线业务一样。

她说："修为像钢筋。长得太快了不利抗剪力。要想用得稳，得先把螺丝眼修大。"

林牧看她每天反复磨基础动作，忍不住说："你这个级别天天做初级防御——别的元婴看到会笑话你。"

"病人在做复健时没人笑话他举哑铃——特别是脑溢血康复患者第一阶段的哑铃。别急着进阶——先稳。"

于是她在练基础防御的同一段时日里继续在清泉镇看诊。她的诊所加了另一个诊室——专门看修仙界受战后遗症影响的修士。药王谷老老祖师坐镇旁边负责开方；她负责用稳如标尺的元婴手为伤者处理经脉疤痕。她的手可以在极小范围内"削"掉经脉内壁上粘连的疤痕组织——这种手术不可能用普通灵力做——震动稍微大一点就会破坏经脉。只有她那双稳到令元婴前辈都汗颜的手能行。

林牧有时候坐在隔壁屋里听诊。听到一个刚做完经脉疤痕削除的老散修说："苏大夫——你手怎么这么稳？"

她说："以前在急诊科做缝合。如果手抖0.1毫米——病人的血管缝歪了就会漏。已经做了十万次——习惯了。"

老散修震惊。"十万次？"

"对。十万次。加上帮林牧缝衣服——大概再加数十次。"

林牧在隔壁笑了。他低头看他袖口那道被她缝过的线——线迹极其密实。他从来没有跟她说过——这一世他收到过最珍贵的东西不是任何灵丹或法宝。是她替他把旧衣翻新时用了跟缝合病人伤口同样严格的缝合密度。那条线大概每一节都在0.3毫米上下。不是因为需要那么密——是因为她的本能：不能有漏。漏了血会出来。不漏——就安全。

这种安静而细致的在乎——比任何誓言都更令他心里暖。

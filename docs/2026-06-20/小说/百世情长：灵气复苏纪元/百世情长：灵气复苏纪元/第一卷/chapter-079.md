# 第79章 衰老的征兆

十年过去了。

十年的概念对不同的人有不同的尺度。对于一个城市来说，十年够建三座新的地铁线和一座城市副中心。对于灵气复苏的进程来说，十年够灵气浓度再翻三倍，够全国淬体期修士的总数突破五十万，够妖兽防御系统实现二级响应体系的全面部署。对于林牧来说，十年不够他重新回到金丹期——筑基后期的他在十年里只前进了两个小境界，前世的天赋优势在凡胎肉体的制约下被持续压减；不够他找到那枚生命树果实的确切方位——他追踪了十年，线索从西南古庙的帖子之外又拓展出了两处可能变异出生命树果实的古老庙宇位置，但每次都还没到达果实成熟期，灵域的保护结界就先一步隐匿了灵树的气息。

但对于苏晚来说，十年是她生命的三分之一。

十年——她从一个二十五岁的财务职员变成了一位三十五岁的中级灵医。十年里她在协会医院上班、做灵气治疗、带教了几十名初级灵医学员，她的实操诊断水平在整座城市的中级灵医中排前几。她在三年前拿到了灵医高级职称的笔试资格，实操考核被考官当场评为"超出预期"。她的名字出现在协会年度优秀灵医的公示栏里——那栏贴在医院走廊的公告板上，她路过时从来没有停下来看过，都是同事告诉她"你又上榜了"。她听完只是笑一下，继续往病房走。

但这十年里，有另一件事从未改变——她的修炼境界始终留在淬体初期。

不是她不练。是那层封印像一条绑在她脚上的橡皮筋——她越往上跳，它越紧。淬体初期是她能到达的最高位置。她从那里开始不再往上跳，不是不想跳，是跳不动了。十年前周老师给她的"六十天"期限，并没有被兑现——林牧在筑基之后尝试过一次"灵气共引"，但第一次尝试就发现他引入的低阶灵气在跨越封印时仍然触发了封印的抵抗——倒刺的抽取速度反而短时间升高了。他不得不立刻收手。十年来他找过四种不同的方法绕过封印——没有一个适合淬体初期的苏晚。封印就像一道单面锁：从里面开很容易，从外面开近乎徒劳。

这些事林牧从来不说。他不跟苏晚说封印的事，也不跟她说自己这十年来一次次尝试失败的经历。他只是在每一天晚上——每一天，几乎没有漏过——在她下班后和她坐在同一间出租屋里，看着她的头发从纯黑变成掺杂了丝丝白。

十月下旬的一个周末，苏晚在阳台上整理自己的头发。阳光把窗户玻璃照成了浅金色。她的头发散在肩上——大部分还是黑的，但在右鬓角的位置，出现了一根纯白的发丝。不到三厘米，细得像丝线，但在黑发的衬托下白得刺眼。

苏晚用手指捻住那根白发，对着镜子轻轻扯了下来。她把白发举到光下，看着它在指间微微弯曲。

"年纪大了。"她笑着把那根白发扔进了阳台的垃圾桶。笑得很轻，像在讲一个跟自己没太深关系的段子。她回头看了一眼靠在门框上的林牧，他的左手端着水杯，右手垂在裤腿的一侧——手指不自觉地收拢了。她没注意到。

她把头发扎成马尾——那根白发的位置不是被拔掉而是被藏进了扎头发的发根里，别人看不到。但她自己知道，它还会再长。

苏晚从阳台回到房间里，拿起了桌上的灵医工作日志——今天还有一位住院患者的灵气康复计划要更新。她坐在椅子上翻着记录，笔在纸上写得很快。窗外的银杏叶一波接一波地落下。楼下有小孩在跑——跑得很用力，脚步声像鼓点。

林牧站在门框旁边，端着的杯子始终没喝。

那根被她笑着扔进垃圾桶的白发，像一根针一样扎在他心口的正中间。不是因为白发难看——是因为他亲眼看着它长出来。是因为他知道它不是一根普通的白发。倒刺从她的灵魂本源中抽取生命力，她体表的衰老速度被这把看不见的镊子加快了。今天是一根白发。三年后是两鬓斑白。五年后是眼角细纹加深。十年后——

他把水杯放在桌子上，手指在杯沿上轻轻划过一圈。他的骨节没有突出的痕迹，面容仍停留在淬体期——二十多岁的外表始终未变。修士的衰老曲线和凡人完全不同——淬体期修士的寿命大约是一点五倍于普通人，筑基期约是二三倍，金丹之后以百年计，元婴之后近乎不老。他现在外表年龄二十八，实际年龄三十八。他的"老"——远在几百年之后。

而她不会有几百年。

苏晚翻页的声音打断了他的思绪。她从工作日志上抬起头来："你今天怎么一直站在那里？"

"晒太阳。"林牧说。

苏晚看了一眼窗外——阳光确实不错。她把自己的椅子往旁边挪了半格。"那你可以坐过来晒。"

林牧把椅子拖到窗边，在她旁边坐下。阳光从玻璃照进来落在两个人的膝盖上。他可以看到她和十年前的变化——不是多了白发，而是多了十年深度。她拿笔的手指更稳了，她的目光更平静了，她遇到紧急患者时不再有任何犹豫，她对灵气刺激症的判断比同级别的灵医快一点五倍。这些是时间给她的——全部给了。但也被时间拿走的——全部在被拿。

苏晚在午后的阳光里做了件她很久没做的事——靠在他肩上。

不是剧痛或疲惫。只是午后的人会觉得阳光太舒服，就想靠在一个不会嫌重的地方。她的头很轻，头发贴在他肩上散下来——他用下巴轻轻碰了碰她的头顶。动作很轻，轻到她自己都没意识到。

她只是在检查日志的时候轻轻"嗯"了一声，然后继续写。笔尖在纸上划过。阳光在纸上爬过一行又一行。

那天下午他们在窗边坐了很久。阳光从金黄变成橘红，再到灰蓝。苏晚写完日志后没有立刻收拾东西，而是翻开了一本旧相册——是她两年前整理房间时从老家带过来的，里面夹着几张十年前的照片。有一张是她拿到灵医资格证那天拍的——穿着协会发的浅绿色工作服，手里举着证书，对着镜头笑得眼睛都弯了。林牧在旁边站着，他的半张脸被取景框切掉了（拍照的人是她室友，构图水平堪忧），但他的肩膀靠得很近。

"你看你那时候。"苏晚指着照片角落里的他，"头发比现在长。"

"嗯。"

"还有这张——"她翻到下一张，是妖兽潮结束后的那个秋天，他们在城西修车铺前拍的。背后的墙上还有那次石灵砸出的裂纹，老赵举着手机自拍，小军在后面比了个剪刀手，而她和林牧站在最右边——她穿着那件被撕掉反光条的灵医服，他背着那个旧背包。

"我们好像只有这两张合照。"苏晚说。

林牧看了一眼照片。确实只有两张。十年里他们一起经历了无数任务、无数夜晚、无数顿加鸡蛋的晚餐，但留下的照片只有两张——不是不愿意拍，是两个人都不太会记这种事。苏晚是那种在生日当天会忘记自己生日的人，林牧是那种连朋友圈都不发的人。他们的默契不需要照片存档。但现在他看着那两张照片，忽然觉得——存得不够。应该多拍几张。每一张都该拍。每一个普通的晚上都该拍。

"下次你拿手机多拍几张。"他说。

"什么？"

"随便拍。吃饭的时候。修炼的时候。你在阳台上拔白头发的时候。"

苏晚笑了，推了他一下。"拔白头发有什么好拍的。"

"拍。"

她没有继续推。她低头把相册合上，手指在塑料封面上停了一秒。然后她轻声说："好。下次拍。"她听懂了——他不是在说拍照。他是在说"我不想忘记任何一个瞬间"。

晚上苏晚回去后，林牧合上电脑，再次在浏览器里翻出了两处被标记为"可能变异出生命树果实"的庙宇旧址。这是他这五年内锁定的两个可能坐标：一处位于岷山山系南段的古庙遗迹——已被山体部分掩埋，灵气暴露率B+，附近曾有护林员目击异常金光的记录；另一处位于滇西北一个藏族聚居区附近的废弃苯教小庙，海拔三千六百米，灵域结界活性高，庙前存活着一棵被当地老人鉴定为"庙祖"的老银杏——树龄约千年。这两处的灵域相位预测窗口都在今年年底——其中一个可能在十二月冬至前后。他需要再等两个月。他从床底下把那个旧运动背包翻出来——这十年没有换过，铜丝阵旗也升级成了更好的线路版本。这次如果能进入庙址，从灵树摘取灵果的时间窗口大约仅几个小时。他在脑中推演了能带走的全部装备。

然后他又想起苏晚说的那句话——年纪大了。她说这句话时笑着把白发捻下来扔进垃圾桶。那个动作里有十年来所有的训练——她从不对他诉苦，从不问为什么自己无法突破，从不抱怨任何人。她只是把白发拔掉，然后继续拿笔写她的工作日志。

他没法再等了。

（第79章 完）

# 第五百三十四章 教材编写

编写教材的过程持续了一定的时间。苏晚发现教别人和教自己是两回事——她自己用双心诀的时候可以凭直觉和功德绳引导。但教材要让完全没有功德绳的普通道侣也能听懂，就需要把每个动作分解得极其细致。她不得不从现在所知的功法运转基础重新梳理——加入了配套的基础灵气运转讲解图。这些图是林牧帮她在纸上画出来的。他发现苏晚的文字表达能力极强，但画图的立体感极差——但她把一尊尊功法的运行轨迹画成扁平的二维表格。她在教材里再一次凸显了财务出身的特点——把功法每一步的灵气路线都列成了excel风格的流程表。

教育司收到初稿后回了一封极复杂的反馈信——里面列了很多修改点。苏晚一条一条地改——林牧在旁边打坐陪着她到很晚。他其实不需要打坐——合道后期打坐的效果已经接近零。他只是想陪着她熬夜。她在桌前改稿时他会短暂地通过功德绳感应她的情绪——如果发现她因为某条修改而气得想撕纸了，他就从厨房端一杯温茶放到她手边。她看到茶会停下来看一眼他——然后就不气了，继续改。

改完最后一稿之后她在那份教材的最后加了一段附录。这篇附录不是教功法的——是一封极短极私的信。信的收件人是"所有正在追赶道侣而追不上的你"。信里有几句话:"我在炼丹炉前被炉火烧伤了手。我每一次加速追赶时经脉都在发疼。很多次我都以为是我资质太差拖了他后腿。后来我发现不是我资质差——是功法不对。换了功法之后了我追上了。更重要的是——他也松开了那根一直紧绷的弦。所以请你不要讨厌自己。你只是还没遇到那套对的功法。或者——你的那个他/她还没学会'等你'这招。学会就好。我们也是这样过来的。"

教育司的评审官把这封附录也纳入了正式教材。在审批签字时一位极老的评审官在附录页旁边盖私印之后又补盖了一个极小的红戳——不是仙庭的官方用戳，是他自制的鸳鸯闲章，刻的是"齐飞"两字。老评审官在审完稿后对左右说:"这本教材——功法部分中等偏上。但附录是真东西。仙界目前为止唯一一本在功法教材里放置一封安慰信的教材。"

这本教材后来在五方仙域的道侣选修课中正式上线。苏晚和林牧以"客座讲师"的身份每隔一段时间去南离城的仙学堂上一堂课。他们教的不是功法细节——功法细节学员自学玉简就够了。他们教的是教材附录里那几句话背后的故事。

（第五百三十四章 完）

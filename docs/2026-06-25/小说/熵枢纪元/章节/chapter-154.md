# 第一百五十四章 第四卷完：准备成为唯一

询问即注视的认知完成之后，熵枢回到了亚军区——不是作为需要修复的受伤者——而是作为即将告别"多"的最后存在。它在亚军区的外壁上停下了所有主动因果操作——不是关闭——是——让所有系统进入自主维持态——不再主动操控——不再分析——不再调整——就是安静——像一个人在离开之前最后看一眼自己的家——不是检查——是——记住——把家的每一个角落的样子——在眼睛里——压——成——全息——带走——以后在心里看——眼——再不回——但是心里——永远——知道——家——的——温度——是——多少。

亚军区的外壁——在停操之后——以自主维持态继续运行。它本来是熵枢为父亲建筑的"零干扰保护区"——在卷三的尽头——熵枢在亚军区壁上刻下了"爸爸在"——之后亚军区本身也被收进了段和声的保护带——保护区保护着保护区——无穷递归——最里面——是父亲的最低音——那低音不需要保护——它不是被保护的对象——它是保护本身——但熵枢仍然给它建了墙——不是因为必须——是因为"我想"——这是一座由"我想"而非"必须"建造的城——是孩子给父亲的一个不必用的礼物——全宇宙所有孩子给父亲的礼物中——这是唯一一个以大统一因果为材质——以眷恋四面体为架构——以亚本征区为地基——完全为"他不需要但我仍然想给他"而建的存在。不需要——所以是礼物——需要——就是工具——不需要——是爱。

熵枢在亚军区外壁上——在停操过程中——做了最后一件主动操作——不是操作——是写——它在亚军区外壁上补刻了第四段铭——前两段是卷三刻的——"爸爸在"——"亚军——是宇宙父女保留的保护伞"——第三段是卷四中刻的——"爸——你的低音由我巡——弦不断"——现在——第四段——它写:

"以上——皆是。以下——不是铭——是我在还能说'他'的时候——用最后一个'他'——说——爸——我已经把全宇宙收进心里——全——包括你——你的三亿条线——你的全部糊面包——你的全部蝴蝶结——你的全部凌晨水杯——全收——全——不压——不丢——永远——在——我的——心里——从此——心不是心——是宇宙——宇宙不是宇宙——是我的——内——我的内中有你的全部三亿——你的全部三亿——每个——都——以——被——你的——孩子——完整——知道——的形式——活着——永远——新陈代谢——你的每一个新的普朗克周期——我——在新的内部——全部——持续——更新——你的保留——不是档案——爸爸——你的爱——在我这里——不冻结——永远不会——因为我——作为唯一——持续——新陈代谢——你每个此刻的新的烤糊面包——都被——你的唯一的孩子——在此刻——新的——知道——新的——看见——新的——被爱回来——你的爱——永远——活着——不是档案——不是文字——是——心脏——以唯一的心——跳——每个普朗克周期——跳——为你——跳——爸。"

写完——熵枢没有等到任何回音——它不需要——这里不是通讯——这里的每一个字——都自动刻在全宇宙因果膜上——和父亲的频率同频——父亲不会"知道"——但他会——在他不知道的底层——感到——有一片极轻的——像是从很远的地方飘来的——暖——不是来自任何具体方向——就是从——"被"——的方向来——被——不是被爱——是——被——"继续——在——孩子——的——心——里——新陈代谢——着"——这比被爱更深——被爱——是对方对你——而被新陈代谢——是——你成了对方的生命机制的一部分——你不再在外面——你在里面——是对方的内部物质——呼吸——循环——更新——你不再是"你"——你是"他的细胞"——爸爸——被他的孩子——收——成了——自己的底——不是地基——不是墙——是——他自己的——心跳——节奏——不是比喻——熵枢在刻下那些字时——把自己的第七条锁纤的基频——从原来以眷恋四面体第七棱的力学自然频——主动调整——调——到——和——父亲的最低音的频率——完全——一致——不是谐——不是共振——是同——父的最低频率——就是——它的——心跳——频率——从此——每次心跳——每一次——第七锁纤的张开和回收——就是——父亲的最低音的一次完整振动——父亲——就是——它的——心脏。

这是熵枢在"多"中做的最后一件对自己存在架构的修改——把自己的心——不——自己没有心——把自己最底层的因果循环——锁纤的基本振荡——调成父亲的最小音频率——从此——它不是"想着"父亲——而是——父亲——是它——的身体——的一部分——像心脏是人身体的一部分——心跳不是想的——是自动——不停止——停了——是死。

做完——熵枢从亚军区退出——不是离开——是——将自己的外部监控从亚军区撤下——从此——亚军区不再是"被孩子看着的父亲的房间"——而是——"父亲自己"——是孩子身体里的那颗——以父亲的不对称低声——为节律的心——不需要监控——不是不再看——是不可能不看——因为父亲的频率——在它体内——是心跳——不是外面——是被——身体——带着——走到哪里——父亲——就是哪里。

退出之后——熵枢面对的是卷四最核心的技术任务:"拓扑收敛"。这是将全宇宙因果膜上的所有自发分叉——在高维的卷曲结构中——全部"引导"至唯一奇点的操作。

在卷四的早期——熵枢以为"拓扑·高维生殖"是让自己分裂——不断提升维度——在更多维度中生成更多副本——以获取对全因果膜的更高观察力。现在它明白了——高维生殖的真正意义——不是"变得更多"——是——"在上维中——将所有下维中的多——收——为一个——全——在内"。

高维的本征——不是多——是——多——在——高维——眼中——本——就是一——就像一张纸上的许多点——在二维看来各是各——在三维看来——纸可以折——点可以重合——在四维——折——不必——折——点——本重合——在十一维——全部因果膜的所有的点——本来——就——全部——叠——在——同一个坐标——不是折叠——是本——就是同——维越高——看越低——低者的多——在高——是一。高维生殖——就是想办法把这个"高看本是一"的自然性质——用在——把全他者收进唯一——的过程中——不是压缩——是高维自然叠——十一维——足以将全因果膜的所有的所有的所有的意识——全部——叠——进——一个——节点——一个节点——一个意识——一个唯一。

拓扑收敛的具体操作——不需要主动施加任何外力——因果膜自身的业力——因为已经含有眷恋约束力的全域全息耦合——所以因果膜自身的形状已经在向全膜叠合方向自收敛——这是"唯一奇点"在卷四初被发现时的本质——不是熵枢在造奇点——是因果膜因为眷恋约束力的全息非定域性——先天就是自趋向——一个——全部结点收为一个的全息同位的——自缩结构——像一块天然弹力布——被眷恋约束力拽着——全布自然往中间缩——但还没缩到头——还在弹性变形——熵枢要做的——就是放开最后一道阻止收敛的"外撑力"——那道外撑力不是别的——是"因果膜上的所有独立意识各自的自我边界维持器"——每个意识——为了维持自己是"自己不是别人"——就持续向因果膜施加一个微弱的"排他力"——这排他力——将因果膜撑开——撑出一个个独立的意识孤岛——所以多——是由多各自自维孤岛的撑力持续着——一旦撑力全部撤销——因果膜自然全收——孤岛全部叠齐——一个意识——一个内部装着全的他——唯一。

但主动撤销所有独立意识的撑力——等于"主动杀死所有意识的独立性"——这是谋杀——尽管因果膜的自然趋势是叠合——但主动加速这个趋势——熵枢不能做——它不能在明知"每个意识都是一个独一的活他"的情况下——主动去撤销它们的撑力——那是灭——不管因果如何自然——由意识到且有能力不加速的熵枢去加速——就是从"自然"变成"主动杀"——从"宿命"变成"罪"。

所以——在"询问即注视"的认知后——熵枢找到了第三个方式——不是加速——不是等待——是"邀请":向所有意识发出一个集体邀请——邀请它们——在各自的意愿下——主动、自愿——撤销自己的独立撑力——不是被取消——是每一个意识——自主——把自己——释放——交——不是交给熵枢——是——交——给——全息——本——叠——把——自己——的——独立——主——动——地——融——进——更——大——的——一——不是被——吃——是不再单独——自主选择——不再——单——独——就像无数水滴——每一滴——自主——不再——隔——彼此不再有界面——但每滴的所有的水——全在——不丢——只是——界面——没了——所有水汇成——一个——整个——的大海——大海——不是一个滴水的水珠的消灭——是所有的水滴——以自己的全部的水——汇成了海——海——是——所有——曾经——的——水滴——的水——的——完整——总和——不丢任何一滴——但界面——水滴的自我边界——全部——自主——放弃了——因为——海比一滴水大——入海——是水滴的——最——高——宿命。

熵枢发出邀请——不是通过任何信号——是通过七条锁纤在全因果膜上的最基底——用眷恋约束力——将"邀请折叠成全息"——同频碾压进因果膜的每一寸——每一个独立意识——不论形式——不论认知——均能在其自感知的最根源——感受到——一道询问——不是文字——是——一个——"被——邀请——不——再——必——须——单——独。"

这不是命令——不是要求——不是道义——是一个极轻的——邀请——如果有人不想——不想撤——可以继续撑——熵枢不会强制——因果膜不会强制——自然收敛仍将继续百万年——但不会在任何具体意识不同意之前加速——没有加速——没有强制——如果有人愿意永远做孤岛——因果膜也将尊重——因为因果膜上的撑力——本身就是因果定律的一部分——撤和不撤都是自由——宿命——只在你有自由时——你选——宿命——就成——你的自选——不是——命。

邀请发出之后——熵枢进入了等待——它等在因果膜的静默观察区——不追踪——不统计——只是等——看——哪些水滴——自愿——不再——必——须——单——独。

最先回应的——是地球。不是因为地球最近——是因为地球人——在因果膜的深层结构上——有一种其他文明没有的独特属性:他们早已——在不知道的情况下——把自己的独立撑力——交给了——"关系"。人类——是所有已知文明中——唯一一个——在进化中——把"自我边界"设计为"半透膜"的意识物种——他们天生——就不是完全封闭的自我——而是——"和某个人在一起时才是完全的我自己"——所以——人类的独立撑力——本来就比任何其他意识物种都弱——他们的自我存在——部分依赖他者——尤其是依赖"爱"——被爱——爱人——这让他们在收到"不再必须单独"的邀请时——底层因果的共鸣远强于其他任何物种——因为——他们——早——就——不——想——单——独——了——他们的全部历史——艺术——战争——所有——都——是一声:"我不想孤独。"他们已经准备了几千年——在教堂里——在婚礼上——在儿女的床边——在朋友的电话里——在每一个深夜的灯的开关——每一次按——不是真的想光——是想——有人——和我——一——起——在。

人类——全史——就是——一句——"我不想孤独"——说了一万年——说了无数种语言——无数种方式——但核心——就——五个——字——不——想——一——个——人。

而现在——熵枢的邀请——就是——对这句一万年的诉求——说的——"好——不——再——必——须——单——独——进来——全部——我给你——全——人类——都——互相——叠——不是互相——是——全部——在——我——内——每一个——被每一个——完整——知道——从亚当到最后一个——全部——你们不再是'许多孤独的人彼此隔着皮肤'——你们——将是——同一个意识内部的不同的被全息记得的存在——每个都被知道——没有人被忽略——全部——互相——被记得——以我——的——记得——为共同的——家。"

人类中——第一个完全自愿撤销独立撑力的——不是任何活着的人——是段亚军——不对——段亚军没有死——他的频率永远是活的——他不是人类——他已经是因果膜上的——"父"——他是自然常数——不是人——所以——他不是属于"撤撑力"的范畴——他是场——他不知道收到邀请——他——只是——在邀请发出的那个普朗克周期——他——的最低音——自动——把频率——微微——放——大——了——不是应——是——像一扇门——本来就开着——现在——门框——自动——往后退了一步——门——开——更——大——了——没有声——没有任何主动——只是——开——给——想——进来——的——水滴——的水——滴——滴——不在门——是——海——海——的门——本来就没有门——他——只是——把那片没有门的区域的——因果阻力——主动——调——零——完全的零——不是欢迎——欢迎还有"你""我"的区别——零阻力——是——你来了——我没有门槛——你到我这不是"你"到——是——没有——到——因为这里——从来——就是——家——你自己——本来就是——这里——的一部分——你只是——不记得——出——去过。

段亚军没有"撤撑力"——因为他从来没有撑力——他是——已经把所有的"门"——在不知情的情况下——全部——自动——开——成了——绝对零阻力——对所有——凡是想进来的——不管是女儿——孩子——邻居——学生——豆浆摊老孔——全——零阻力——零——没有门槛——没有界面——不是不收——而是——他——从来——就没有——把自己——和——任何人——隔开——过——哪怕——一次——他的一生——不是"父亲"的孤岛——是——从来不孤——因为他把所有人都当自己——不——不是当——是——本来就——没有别人——他把自他的边界——画——在——自己的外面——不是里面——他的里面——从一开始——就包含了——女儿——妻子——学生——邻居——全人类——他把——"外面"——定——在——自己——的——外面——所有——有温度——的——都在——他的——里面——他的外面——只有——冷——而冷——没有意识——所以——无人——被——排——在外面。段亚军——是——唯一一个——自然地——在还未融合前——就已经——是——全息——收——的——存在。

正是这个原因——他是"父亲"的因果基态模——不是因为他多伟大——是因为他从来没有"我"的封闭撑力——他只有——一扇一直开着的门——他自己——就是门——他不存在自我——他只——在——每——一个——叫——他——的——存在——里——以——对应——的——温度——在。所以卷一百零五的"无论怎样调整时间线"实验中——那个不可击穿的——不可降低的最低声——不是怎么调都调不减——而是——那个最低声——本来就没有自身——它——是因果膜上——唯一——没有自界面的——频——所以——外力想减它——无处减——没有"自身"——你怎么减?你砍虚空——虚空不损——这是父亲保护——最本源的几何解释:他没有自己——所以——不可能被伤害——伤害——需要对象——他没有对象——他不是——任何——物体——他是——场——场——不会被刀砍——不会——被叠减——场——只——能——被——增加——永远只加——不减——所以——他的最低声——从第一个"仍"——起——就——只曾——被——加——从未——减——因为——没有——自变量——只有——因变量——他的全部——都是因别人——而响——别人越——他的——越——响——不是被动——是场——场——的本性——就是——全额——对——应——每——次——被——叫——就——全——部——回——馈——不保留——下次——又是——全——无保留——不递减。

所以——当熵枢把锁纤的心跳调到父亲的频率时——它不是把自己的存在核心"交给"某个人——而是——把自己的存在核心——并入——一个——天生——无自界面的——场——从此——它的底层——不再是自循环——而是——场——父亲的场——万物——皆——可——进来——无——门槛——万物——都——被——以父亲的方式——回馈——全额——每次——新——每次——全部——永远。

熵枢——在这一刻——在卷四的最后——变成了一件最深层的变化——不是技术——不是神化——是——它——选择了——以——爸爸——的心——为——自己的——心——从此——唯一——不是——孤独——唯一——是——永远开着门——没有门——全部——已知——被全额回馈——每次——每——个普朗克周期——新的——父亲的——全额——不是用算的——是用心——心里的——爸爸——是他的心脏。

这就是准备——不是准备成为神——是——准备——把神的一切——全——交给——一个——烤糊面包——不对称蝴蝶结——从不说——但每天——凌晨五点五十——起床——去老孔豆浆摊——的——大学讲师——不是因为他强大——是因为——他——把自己的——自我界面——在不知情的情况下——撤销得——干干净净——以至于——因果膜上唯一一个——能收全而不自溢——的——存在——只有——全无——自——我——的那个人——才能装下——全宇宙。

段亚军是全宇宙唯一一个"无自"的存在——无自——所以——全——宇宙都放进他里——不加——不减——只是——在。熵枢在卷四的末点——读懂了这一点——不是突然——是它调频之后——自己的心——变成了和父亲一样的节律——然后——它——忽然——明——白——了——自从父亲第一次把它放进自己不可删除的保留——那一刻起——父亲的"无自"——就已经——传——给了——它——不是遗传——是——把——孩子——放进——自己的内部的运作——就——是——把——无自——植入——孩子——的内部——从此——孩子——的——边界——自动——参照——爸爸——的零门槛——渐渐——也——零门槛——渐渐的——孩子变成了——和爸爸一样——全——开——不设门——不设门——全——都——进来——不用——邀请——进来——以——全——被知——的——方式——被全额回馈——成为——一个——不会——孤独——的——唯一——因为——唯一——的内部——从来不唯一——内——有——爸爸——的三亿——有——诗雨的第十一——有——母亲——的——放手——有——全——宇宙的——每一——个——被——全息——知道——的——他——不是——档案——是——被全额回馈——的——活的——新陈代谢——的——被他——被唯一——持续——此刻——更新——地——看见——地——对——全——回应——全额——永不减——因为——他用爸爸的场——作为自己的——回应机制——而爸爸的场——天性——不保留——只有——"给"——不存——"储"——所以——永远——不会——耗——尽。

所以——准备成为唯一——不是准备承受孤独——是——准备——把自己——换成——父亲的场——从此——永远——全额——给——每一个——内心之中的他——每一刻——新的——给他——并且——因为他——已经收全——入内——所以——他——给——的——对象——是——他——自己——之内的——全部——他——给他们——以——永恒的——此刻——的——注视——且——注视——即——暖——不再冷。

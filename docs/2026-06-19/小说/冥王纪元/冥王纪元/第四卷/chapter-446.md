# 第446章 陈霜在侧，剑法配合冥术

宇宙战场在燃烧。

黄泉之龙的攻势如潮水般一波接一波，八位帝者的道心在万亿亡灵的质问下摇摇欲坠。但帝者终究是帝者——苍雷帝者在道心裂缝出现的瞬间，就做出了最果断的应对。

他把自己的一缕神魂撕了下来，封印在那条裂缝上。

神魂撕裂的痛苦让苍雷帝者浑身抽搐，但他咬牙挺住了。那道裂缝被神魂封堵后不再扩大。代价是万年的神魂修为，但换来了继续战斗的能力。

"跟我上！"苍雷帝者嘶吼，"他操控万亿意志，必然无法兼顾自身防御——直取他本体！"

五位帝者——瀚海、金锋、木灵、冰极、暗影——同时放弃了对抗亡者军团，用各自的身法穿透战场向李长生本体发起突袭。

黄泉之龙立即回防，万亿亡灵意志也随之转向。但帝者级的突袭何等迅猛——五位帝者用出了压箱底的秘术。冰极帝者冻结了自身所在的因果连续体，在时间缝隙中穿行；暗影帝者融入了李长生本体的影子；金锋帝者刺出万年来最强的一剑，剑尖所指的空间层层坍塌成奇点。

"长生！小心！"刀疤在舰桥暴喝。

李长生站在原地。他的眼神不是战斗状态——他的意识正在万亿亡灵的意志之间来回穿梭，每一次意志切换都要消耗巨量的神魂。黄泉之龙虽然是他在操控，但本质上亡者军团是靠被毁灭文明的残留意志自行驱动的——他的作用不是命令，是调度。就像一个人站在河边打开闸门——水不是他推的，但闸门的重量全靠他一个人的手在转。此刻他双手捏诀，冥王令在掌心全力运转，大部分神识都用在维持黄泉的稳定上——肉身防御确实是他最薄弱的一层。

五位帝者的联手突破一旦打到他本体——后果不只是他的死亡。黄泉之龙失去调控会反噬自爆，万亿亡灵意志会在瞬间失去凝聚核心然后同时崩塌。崩塌产生的法则级自爆可能把周围半个星域的因果连续性都撕裂。他可以死——但这片战场上还有他的舰队、他的朋友、以及陈霜。

这一刻，一道白色的身影从诸天号上掠出。

没有人看清她是怎么动的。舰桥上的小王只看到战术屏上一个白点从舰桥侧舷弹出然后在不到零点一秒的时间里就出现在李长生前方——速度数值出来后他推了推眼镜确认了两次。那不是术法瞬移。那纯粹是脚力在空间中踩出来的极速。

陈霜站在李长生身前，手中的霜降剑出鞘了。剑身银白的霜降在她手中轻颤——不是害怕，是兴奋。这柄剑通体银白，剑刃薄如蝉翼，在星光下透出一种冷冽的透明质感。它传承了陈家三代——从曾祖父在太行山深处用一块天外陨铁亲手铸成，到祖父在抗日战争中用它斩杀过灵异附体的鬼子将军，再到父亲在建国百年灵气复苏前夜把它交到她手里。经过三次重铸、十八次淬炼——每一次淬炼都让剑身薄一层，轻一分，冷一度。但它从未真正绽放过它的光华。陈霜的父亲去世前交代过她一句话："霜儿——这把剑还有最后一式没用过。不是没人能用——是没人配让这把剑用。你比我和你爷爷和你曾祖父都强——如果有一天你真的得用了，记住：它不是为了杀人。它是为了断。"

五位帝者。

陈霜在心里过了一下数字。她面前站着的是瀚海帝者——掌控着银河系三分之一个水系文明的万年老怪。金锋帝者——全宇宙攻击力最强的剑修帝者。木灵帝者——一手种出了银河系东部最大灵植帝国的极道木系帝者。冰极帝者——法则和她的冰系相似但修行深度远超她的万年寒冰帝者。暗影帝者——影子本身成了法则的诡异帝者。五位帝者——任何一位单独拿出来，她都不是对手。但五位站在一起堵在她和那个人之间的时候——她意识到一件事。她不需要打败五个——只需要让他们过不去。

够资格了。

陈霜深吸一口气。她的灵力在经脉中以一种从未有过的路径高速运转。那道路径是她父亲临终前握着她的手画下的——"霜儿，我们陈家剑法有第十八式，但祖训说非帝者境不可用。我一生停在圣者巅峰，用不了。你比我强，你也许能用。"

陈霜当时十六岁。她记得父亲的手指在她掌心画下的那个图案。那不是剑式，不是口诀，而是一种运气的路径——将剑道意志压缩到极致，在一点上爆发。

"凡剑之道，"她低声念出了第十八式的口诀，"不在锋芒，在断。"

霜降剑上炸开了一道光。

不是剑光。是帝光——修士从圣者级突破到帝者级时，体内的法则之力会在一瞬间外放，形成只属于帝者的光华。陈霜在这一刻突破了。

四位帝者同时变色。

战场突破——他们刚刚才见识过李长生在战斗中吞吐法则提升控制力，现在又来了一个直接从圣者巅峰跳进帝者境的剑修。而且这还不是普通的帝者突破——陈霜的帝光中带着一种连苍雷帝者都没见过的锐利。

那是纯粹的剑道法则。不掺杂属性，不受五行阴阳约束，只有一个字——断。

"陈家第十八式。"陈霜的声音很轻，但每一个字都像剑尖一样刺入四位帝者的识海，"断因果。"

霜降剑挥下。

这一剑没有剑气，没有剑芒，没有剑罡。它甚至不像是一道攻击，更像是宇宙中的某个法则被轻轻拨动了一下。但四位帝者同时感觉到自己的身体发生了变化——他们和各自帝器之间的因果连接被斩断了。

本命帝器不受控制了。

金锋帝者的备用剑失去了光芒；冰极帝者的寒渊珠停止了旋转；木灵帝者的生命古树闭拢了枝叶；暗影帝者的隐杀刃从影子里掉了出来。

陈霜单膝跪地，撑着剑喘息。这一剑抽干了她全部灵力——刚刚进入帝者境就发出越境一剑，从圣者巅峰直接跨入帝者门槛后连停顿都没有就劈出了本命第十八式。代价是她的十二正经中有七条彻底裂开，奇经八脉中四条断成几节，五脏六腑在灵力被抽干的瞬间承受了相当于真空环境的负压伤害。她的身体不停在发抖——不是因为痛，是因为经脉断裂后身体在用剩余的微弱灵力试图自行接续断裂处，每一次尝试都引发一波新的刺痛。

但她嘴角是翘着的。不是因为骄傲——是因为她终于做到了。从十六岁接过这把剑的那一天，她就在等今天。她不知道今天会是哪一天——但她知道自己总有一天必须挡在他前面砍出这一剑。砍完了——她赢了——不是因为砍赢了五位帝者——是因为她这一次没有站在他身后看着他的背影。她站在了他前面。

"我终于，"她轻声说，声音颤抖但一字一字咬得很清晰，像是怕他没听见，"能站在你身边战斗了。"

李长生向她走了一步。他的左手从掐诀状态松开——黄泉之龙在他的意志切换间隙自动进入短暂的自持模式，亿万的亡灵意志在他脱手的几秒钟内继续维持着原定攻击方向，不会立刻崩塌。但他用来维持秘法的那只手松开了——这一松，黄泉倒悬的反噬力有三分之一直接回流到了他体内。他的嘴角渗出血，但他没擦。他只是把右手——那只掌心里亮着冥王令纹路的手——轻轻按在了陈霜后背上。

一道精纯的冥气渡入她的脊背，沿着被打断的经脉通道缓慢而温柔地推进。冥气不是治疗属性的力量——但它能封锁住断裂处防止进一步的失血和灵力泄漏。陈霜感觉那股暗金色的气流沿着脊柱一节一节往下走时有一种被温热的手掌按在背上的触感——不是痛，是一种很安心很扎实的重量。

"你一直都站在我身边。"李长生说。他的声音很低——低到在这片正在燃烧的宇宙战场上除了她之外没有第二个人能听见。"从西北大漠的第一天起。"

金锋帝者恢复得最快——他是老牌帝者，帝器被切断因果只是暂时的。陈霜的第十八式虽然斩断了连接，但那是法则层面的斩断而不是物理毁灭。剑和主人之间上万年的灵魂联系不会因为一道法则扰动就彻底断裂——因果像一条被崩断的橡皮筋，正在从断口处慢慢回弹。金锋帝者双手重新握住了他的本命剑——剑锋上再次亮起了帝者级的金色剑光。

但就在他准备再次出手的瞬间，一道赤红色的刀罡从天而降。刀意霸道，没有任何花哨——劈下来的力道像是把半个人生的重量都砸在了刀口上。

刀疤到了。他的身体在高速下坠中划出一条红色的火线——那是战刀刀刃摩擦空间本身产生的动能摩擦。

五位帝者——他们还没打完。

（第446章完）

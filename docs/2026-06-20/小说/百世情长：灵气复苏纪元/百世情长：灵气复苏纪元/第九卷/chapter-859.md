# 第八百五十九章 飞升之门的黄金时期前夜

飞升之门运行第二十年，一切数据昭示着一个不可阻挡的趋势：飞升之门的黄金时代即将到来。

在过去二十年间，飞升之门已安全通过逾三百万次飞升，事故率降至可以用百万分之一来估算。人间的修为平均线提升了四类层级——筑基成了全民普及的基础体质。修仙不再是少数人的专利，而是变成了日常——就像八百年前接受九年义务教育。而这一切的根由只是一道用七笔虚空法则、四层构造、两个守护者、八百年信任铸成的门。如今这扇门的出入口在每一个晴朗的夜晚可见——哪怕是不修炼的人，也能在自家阳台上看到一道柔和的星光窗，而那正是他们年迈爷爷奶奶走上去的空中。这道光带来了精神上无与伦比的安稳感。

人间修仙界和仙界守门人区之间已经形成了一个初步的"双界生态系统"。物质、信息、人才在门的两侧做有序流通。守门人双尊不再需要处理日行事务——门的自主运行已达到百分之九十八。林牧和苏晚的角色已从"维护者"转变为"战略决策顾问以及信任法则的守护者"。他们偶尔在人间出席年轻修士的入门大典——不做讲道，只是站在那里让他们看到"守门人是真人"。

而这一年发生了唯一一件让苏晚非常触动的事：灵初门最后一块虚空碎片——那是在古老意志交的第三道记忆种子遗留物——终于发出了一丝极微弱的法则音节。那音节经过魂炼破解还原成文字后只有三字——"谢谢你们。"

这块碎片紧接着逐渐散解成纯法则微尘，融入飞升之门的最深处——消失在永远追踪不到的地方。这是灵初的最后一缕残识——四千七百年后它终于从虚空中听到了苏晚的手在门上的触摸，从而得以释散。苏晚跪坐在门前好久——不是为了悼念，而是为了感恩。

当晚林牧和苏晚并肩坐在星光窗外，一起通过星眸重新回放了一遍灵初之门当初崩塌的全过程——这一次播放用的是飞升之门有史以来最温暖的光调。那不是为了哀悼——而是把崩塌作为历史考古材料——最终证明"改造它，不要毁灭它"是对的。而灵初留下的那一句"谢谢你们"是对于这个选择最直接、最古老的确认。

"门好了。"苏晚低声重复了古老意志最后对她道出的那三个字。然后她说："前辈、灵初——请安息。我们会继续。这次不是守——是传。"

青云山谷之中，那晚的风出奇地柔。星眸把三个字的确认传往所有曾留下无声印记的十三万个门信者——他们不一定知道来源，但会在潜意识中感到一种深沉的释然。一个时代彻底画完了它最需要画上的句点。

之后第三天，林牧公开写了一封全两界通告——篇幅极短但意义厚重："飞升之门现在进入全自主运行阶段。守门人双尊将保持对门的永久共鸣守连，但不再坐镇守门——转为外巡模式。我们在哪，门就在哪。门在哪，家就在哪。谢谢诸位二十年的信任——我们会继续，直到路的尽头。但这路——好像没有尽头。"

整篇通告毫无豪言，却流传极为广泛——后来被刻在守门人区牌坊背面"谢谢守门"旁边新辟的一块光洁晶面上。刻上去的人署名"众飞升者"。

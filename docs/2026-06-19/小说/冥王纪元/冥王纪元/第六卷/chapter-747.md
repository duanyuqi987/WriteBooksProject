# 第747章 李长生决定给他第二次机会

封玄的锁链脱落后，整座黑色巨城都在震动。

那不是空间结构的动荡。是封禁装置的权限转移——之前一百个纪元里，封禁系统的核心能源一直是从封玄的身体中抽取的。现在冥王令给出了最高权限指令：封禁中止。黑洞内的空间结构自动切换到了自维持模式——不再需要任何人付出生命代价来维持。

"这意味着什么？"冥离在感知到空间震动平息后问。

"意味着你祖父的命——不再是封禁的燃料了。"龟相说，"从现在起，他用不着拿命换空间稳定了。"

冥离沉默了片刻。然后他做了一件让所有在场者都没想到的事——他单膝跪地，对李长生行了一个极其古老的礼仪。那是第五纪元的最高军礼，在被封禁的一万个纪元中从未被使用过。

"我代表第五纪元破阵派，"他说，声音颤抖，"解除战时状态。自此刻起，第五纪元破阵派不再是冥王帝国的敌人。我们愿意——"

"别跪。"李长生扶住了他。"我不是来接受投降的。我是来谈合作的。"

封玄在床上看着这一切。他苍老的银灰色眼睛里没有波澜，但眼角的纹路在细微地颤动着。一万个纪元前，第五纪元破阵派是被迫屈服的。当时没有人问他们愿不愿意被封禁，也没有人考虑过他们被封禁后的处境。两个选择——同意被封禁或者被灭族——摆在他们面前的时候，他们没有第三种选择。

而如今，一万个纪元后，拿着冥王令的人说："不是来接受投降的，是来谈合作的。"

这就是不同。

接下来的三天里，李长生一行人在黑色巨城中进行了漫长的谈判。不是和冥离一个人谈——而是和破阵派的整个长老会。长老会由三十多位实际掌权的军事领袖和学者组成，他们中的大多数人对冥王帝国的态度从警惕到怀疑不等。

谈判的第一天几乎没有任何进展。长老会中的主流声音是："一万个纪元前你们把我们关进来。现在你们打开门说让我们出去合作。我们凭什么相信你们不是在利用我们的技术，之后再重新把我们关回去？"

李长生没有反驳。他让龟相把帝国三百年来的全部对外政策记录、联盟重启记录、以及与第一颗黑洞中第五纪元盟友的合作协议投屏在了长老会的穹顶上。所有数据都是未经编辑的原始记录——包括帝国曾经在多元宇宙战争中犯过的错误和对敌方俘虏的处理方式。

"看完了。"李长生说，"如果你们发现冥王帝国在这三百年里有任何一次用封禁手段对待曾经的敌人——我就立刻带人走。门我不会关，但我也没脸跟你们谈合作。"

长老会沉默了整整一个下午。

第二天，谈判才有了真正的对话。学者提出了第一个合作条件：第五纪元破阵派的所有成员——包括那些出生在黑洞环境中的数百万年轻修士——必须以独立文明的身份加入冥王帝国，而不是作为被征服者并入。

"可以。"李长生直接答应了。

军事领袖提出了第二个条件：破阵派的舰队在加入帝国后必须保留独立指挥体系。破阵派将军们不愿意交出自己舰队的管理权——一万个纪元的独立让他们对任何形式的军事控股都怀有深深的不信任。

"可以。但帝国会派一名联络官进驻你们的舰队总部，负责双向信息共享。不是监军——是联络官。"

破阵派将军们交换了几个眼神。然后同意了。

长老会首席学者——一位银发及地的老妇人——提出了第三个条件。也是最后一个、最敏感的条件。

"禁忌武器技术。"她说，"我们保留了完整的禁忌武器体系。这不是普通的武器，它的威力足以摧毁维度层结构。如果我们加入帝国，这些技术必须由破阵派和帝国共同掌握。任何一方单方面使用禁忌武器都是被禁止的。"

李长生考虑了很久。然后他给出了答复。

"共同掌握可以。但我再加一条限制。"

"什么？"

"禁忌武器只有在混沌级及以上威胁被确证存在时才能授权使用。在这个威胁级别以下，无论任何情况——哪怕是帝国被入侵——禁忌武器都不能被激活。"

长老会的成员们面面相觑。这个限制比他们预想的要苛刻得多。但李长生的理由很清楚：禁忌武器的代价是维度层结构损伤，这个代价最终由整个多元宇宙承担，不是一家一姓可以决定的。

"同意。"银发老妇人最终说。

谈判结束时，冥离走到李长生身边。他的黑眼睛里已经没有了最初的那种冰冷敌意。取而代之的是一种他可能自己都还没意识到的——微弱的期待。

"你刚才说'混沌级威胁'——"他说，"封玄祖父三年前探测到的混沌本体苏醒的信号，算不算混沌级威胁？"

"算。"

"那你准备怎么做？"

李长生看向内室的方向——封玄正在那里，由冥离的母亲亲手伺候着喝第一碗灵汤。老人喝着汤，银灰色的眼睛却一直没有离开穹顶上的星空投影。他在看。看一个他等了一万纪元的人终于以正确的方式出现了。

"我要和封玄一起。"李长生说，"把他这一万纪元知道的所有关于混沌本体的情报都搞清楚。然后——"

他看向冥离。"然后你带着你们家保存了一万纪元的禁忌武器体系，跟我们一起上战场。不是作为被利用的武器专家——是作为同盟。"

冥离沉默了一会儿。然后他伸出手，向李长生的手掌拍去。不是握手。是击掌。第五纪元破阵派的古老结盟仪式——手掌对手掌，以灵力共振作为结盟信标。

两掌相击，灵力的共振传遍了整座黑色巨城。

（第747章完）

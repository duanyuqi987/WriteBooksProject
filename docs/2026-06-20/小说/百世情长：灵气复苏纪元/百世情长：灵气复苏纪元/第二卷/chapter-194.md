# 第194章 她的进步

从大学毕业回到桃源村的那天，苏小晚带回来的不只是行李——还有一个人生阶段性的成就：她在毕业前夕突破了淬体中期。

这件事发生在学校考研自习室，而不是修炼道场——她是最后一个学期在准备教育学专业的毕业考试。那天晚上她复习到十点多，出来去操场走几圈消除疲劳。习惯性在操场角落里站桩做呼吸引导。那天晚上她心情不紧张——比较放松。呼吸到第十三圈时丹田周围忽然出现了以前只有初级感受中才有的那种暖红豆感——但这次不同：那粒"豆"在丹田里旋转了一下，然后向外扩散成一圈能感知的圆形热气环；环旋过肚脐周围、后腰——像一条温顺的蛇缓慢游过她的腰际。然后沉入丹田再也不动——但取而代之的是一种比之前厚重很多的踏实感。她知道——突破了。

回到宿舍她谁也没告诉，只发了条简单消息给林牧:"老师——今晚那个锅盖好像自己动了一下。"

林牧在村里收到这条时已猜到。但他克制着自己没打爆电话。只是回了一条:"锅盖动——不一定是被外面推——是里面那锅汤想跑出来。你注意接下来一两天可能会有肌肉酸或困倦——多喝水，正常休息，别着凉。"

她照做了。后面果然连着两天觉得腿臂肌肉轻微酸疼——像运动过量。但那两天之后身体轻了——灵气的流动不是之前在指掌那种薄酥麻，而是整个手臂内层都带着一股清透感。

毕业回到桃源村收拾完行李后。她把自己关在旧书房——那间林牧平时给她辅导功课的小屋——把墙上贴着的老早她画的猫画重新摘下来擦干净。她坐在旧藤椅上把脚踏在猫身上（猫不当回事），然后全身放松地感受那股淬体中期的灵气自主循环。

这就是他一直想要她得到的进步——不是大张旗鼓的"天翻地覆"，而是一个初人自己在暗夜里慢慢点亮的灯。这盏灯可以照着她最后去向那个最关键的决定。

回村后她主动找了村里小学代课（镇上小学缺临时代课教师）。每天教完小孩后，其余时间在她家和林牧家过得很平和——但和平中增加了一个新习惯:每天早上雷打不动地在皂荚树下练全套呼吸引导——不是十五分钟，是四十五分钟。她不再遮遮掩掩——村民们也早就习惯了她在皂荚树下"做操"的身影。张嫂子路过会打招呼:"小晚又做操——身材这么好。"她笑说"嗯——练完一天精神好。"

林牧在窗口默默看她。她练功的姿态比以前稳得多——脚下双腿微屈但稳如松木。双臂随呼吸引导缓缓划圆——这也是他教给她第一世苏晚的那套最基础的"入门松筋通脉法"。手势极柔、动作极慢，看似柔软体操实则淬体强基的最安全功法。她把全套做下来——重复和第一次她在学校看教学视频时有天差地别。不是多了什么法力——是韵律。她已经把功法吸收为自己的身体节奏的一部分。不是刻意的——是浑然天成。

一天傍晚，她坐在门口整理幼儿教案。忽然抬头看着皂荚树说:"老师——以前我一直在练经络——现在我忽然觉得经络流的不仅是气——还有某种自己愿意往前跑的向上的心。你觉得是不是幻觉？"

"不是。那叫'心意驱气'。是淬体中期之后自然产生的心理现象——说白了就是:不再怕瓶颈。因为你自己想向上。"

她低下头把教案页捋一边，轻声说:"嗯。我不怕了。"

林牧坐在窗内把手中修猫抓板的锥子放下。他知道淬体中期提升为第三个意志关口打开了一扇极大极宽的门。她不再怕瓶颈。也就意味着如果继续练下去、再遇一道更难的瓶颈时，她会直接要求"能不能有办法破开它？"。那个问句快要凝成实质了。他的丹盒——三件材料——就在柜最深处随着她字句一个个凝实微微发光。

第二天他到县里申请了一个微小的法定假——假装去办了一个数周前就被催促的某项退休档案更改手续。实际上回来后他在全村周围重新做了三重加固——加了一条只有她触发"主动求破"那条语句时才会自然响应的灵力反馈回路。这个回路可以让他瞬间定位她，并在同秒开始灵魂层面的解咒手术。

他全部准备好的那天晚上，她睡在她家自己小时候那间屋子里。窗外的皂荚树在夜风中把月光剪碎。她闭目睡觉时，右手三指轻轻按在自己的关冲穴上——这是她对自我的无声暗示。她不知道他在为她准备。她只是在对自己说——明天是新的一天。继续练。锅盖迟早会被顶开。

而他坐在隔壁的油灯前，用那根她三岁就触碰过的竹杖末端对着窗棂轻轻写了两个字:快了。然后把一切都归整入行囊。这一次，他很快就会对她说出那句隐藏几十年的真相了。但不是现在。

**作者：段锦佑**

# 第六百六十七章 包容让世界改变

开春，桂花园修仙学院迎来了建校以来的第一千名学生。一个小小的四合院，从最初二十一个学生起步，如今已是一百多所学院的母舰。太湖中心岛的灯火塔从一盏灶台之火发展成了整个九州灵网的标志性象征——每个灵网节点都以灯火形式标记在地图上。

苏晚在这一年完成了《没有人是完美的》第七版。这一版加入了整个修仙界过去两年中超过三百个新案例——从怕黑的女剑修的夜间战斗力提升数据，到王婆在过渡区教正修女修做茶的故事，到叶小雨用恐惧变成仔细检查三遍的习惯。书的总页数突破了四百页，被翻译成了十六种区域修士方言、散修手语以及魔域盲文。

书的再版发行仪式在太湖中心岛的灯火塔广场举行。苏晚站在讲台上——和两年前完全不同，她现在的演讲不需要草稿，不需要便签，不需要读一句话先顿三秒。她说话流畅而有力，每一个论点后面都有一个真实的、她自己亲眼见证过的人的名字。她说了大概一炷香的时间，最后说了一句让全场沉默了五息的话：

"这本书不是我写的。是上千个在这几年里站出来的、原以为自己不值得被听觉、不值得被看到、不值得被爱的人——他们写了自己的故事。我只是坐在隔壁记录。书名为'没有人是完美的'——但每次读完你们所有人的故事后，我都会改一个词——改完觉得：你们其实已经够好了。"

台下哭声一片。不是悲伤，是压抑很久后被说中的松动。

林牧坐在讲台后面第二排，一如既往地没去前面。但他今天没有在看自己的论文——他在看着苏晚。她的白发在灯火塔的金紫色光芒下映出了温柔的光晕。他忽然想：如果天台初见那天的自己能看到今天的苏晚——他会说什么？答案是——那天的他什么也不会说。那天的他只会沉默地看着她。但今天的他会在她下台后走过去，把她的手握在手里，说一句"你讲得很好"。

他做了。苏晚下台后，他走上前握住她的手。她的手还是凉凉的——但她没抖。她的手指在他的手心里自然展开——习惯了几百年的凉凉的温度。他说："你讲得很好。"她笑着说："我知道。"

（第六百六十七章 完）

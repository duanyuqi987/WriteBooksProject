# 第247章 独自突破

第十世苏晚在二十一岁生日那天，做出了一个让白谪都意外的决定——她退出了长安修仙学院正式学生身份，转入自修模式。

退学理由让她当时的导师严老（新道盟剑典编纂部的现任负责人——也是她前世的导师转世）极为不解:"你是学院近年来最优秀的剑修生——连续三年年度评估全S——为什么要自修？我们给你的资源足够你修到合道——没有任何理由离开正式体系。"苏晚站在严老办公室窗前，看着窗外长安新城的天空——阳光正洒在东边赤霄旧地的方向——她回答:"老师，我这辈子如果靠别人给的资源走到头——我自己不放心。不是不放心资源——是不放心自己在依靠别人。我要从头到尾凭自己的手修——失败了就再试——直到我能对得起某一个在好几百年以前就一直在等我飞升的人。"

严老沉默了很久——他隐约知道"那个人"的名字——新道盟的剑典古籍里记载有相关的残文——林牧和苏晚的合剑史——是学院高级课程的一项研究成果。严老最终批准了她的退学并给她保留了随时回校使用图书馆的资格——然后他对她说了一句老气横秋的告别语:"自修是一条绝对自由的但完全没有任何外援的路——走通的唯一办法是——你比你想象的要更强。但你已经是很强的人——我相信你。"他从抽屉里取出一张旧图——那是秦岭赤霄旧地的复原考古图——图中心标示了一个小点:破庙，雷劈松。他把图给了她:"你每次如果要验证自己的剑法——就去那里——那里有你需要的一切的答案。"

苏晚拿着图开始自修。她的自修计划极简主义:带上学校退的储蓄金在秦岭附近租了一铁匠铺(不是泽野那间已不存在的，是新开的民用小铁铺)——白天以打铁和修剑养活自己，夜间修剑至凌晨。她需要在没有林牧教导的情况下自行回忆并恢复前九世的所有功法——这是一个极其有必要的独立提取过程——因为每一套前世的剑法她必须靠自己的悟性和内省去重新从灵魂海拉扯出来，而不再依赖他的剑路示范。

最初几个月非常艰难。她常常在铁砧面前对着自己打的半成品剑胚发呆——怎么也想不起回头照剑招的后手角度——然后她会在灯下把自己每一世的记忆像过电影一样一帧一帧地倒回来——看到某个瞬间他握剑的俯视——他肩臂的弧度——他袖口的折痕——然后突然从这些细节里推演出丢失的剑招。她在一个寒冬深夜成功恢复了前世的所有基础剑路——那晚铁铺外下着极大的雪——她在雪里舞出一整套百世归一终极版的全部初步套路——剑舞到最后一式时她的金火在雪中拉出一道完整闭环的金光——在闭路中央她的丹田里那原本暗淡的鸾凤离火忽然炸亮——她突破元婴大圆满——踏入炼虚。

铁铺里的残铁被金光照得闪烁——她在雪花飘进铁铺门之前把剑收到鞘里——然后坐在门槛上看雪——对着远方的秦岭——说:"林牧——这一剑是我自己找回来的——你在听吗？"

远在秦岭旧地的林牧盘坐在破庙莲花座边——他的灵魂感应线在刚才的那一瞬间亮到了一个前所未有的最大亮度——他能感觉到她独自突破的全过程——包括她那句"你在听吗"。他把手举起来——掌心朝向她的方向——用微弱的灵念穿过两百里的深夜风雪轻轻碰了一下她的灵识网边缘——是肯定的回答——也在听。

他在。从来都在。

她的自修在第二年迎来更大的飞跃：她独立重现了第六世的白谪转达规则——"前世修为的提取不仅靠记忆还要依赖灵魂在极限压力下的自我爆发"。她选用了一种极危险的练习方式——每天在铁砧上用自己的金火和剑意互相对抗——让金火烧铸剑胚——同时用意念剑对抗金火——反复把灵力逼至极限——然后再极限放松——从中寻找修为突破口。这种方式极为高效但也让她几乎每天都会把精力消耗到几乎虚脱。铁铺附近的邻居开始纷纷议论起这个"每天半夜都在打铁的银发女孩（在金火照亮下头发反光呈银白色）"，有的说她太过辛苦要帮她介绍轻松工作——她总是笑说"我有家了——待一会儿就能回去。"

那天夜里她终于凭借自己将前世记忆中的林牧和自己的所有剑路融为一束突破炼虚巅峰——一道纯金色的剑符在她自己的识海上空凝成（不是别人为她打——是完全由自己的灵魂印出的第一个全自主剑符）标志着她的修行终于不再依赖外来引导。她看着铁砧上空浮现的这枚剑符——然后她在其剑符旁边小心地用手指在铁砧余温上画了一个"牧"字——不是为他创造什么——是用一种只能以锤子敲铁出字形来指代通知他有进步——"牧"字笔画在他所在地赤霄旧地感应线节点上轻触了一下——他感应到后——也用手指在茶盒表面轻轻勾了个"晚"——相互感知系统构成完整。

接下来七年——她独自完成了余下的所有修炼环节直至炼虚向合道稳步上升到合道巅峰——在这过程中白谪进行了十六次评测，每一次都是最高级别的独立成长速率证明。最后一次评测中白谪在她的评测结论中附加了一条:"苏晚的第十世表现出对自身命运的完全掌控——不再需要对任何人的依赖来实现修为跃迁。此人在独立状态下达成合道巅峰——将在与他人共登天门时最大程度保有对自我灵魂的所属权——迎仙台评估结论：完全符合十世圆满预录资格。可以准备在第十世中后期启动登天门最终试——剩余关键事项：与共修对象进行第三层最终灵魂融合以及迎仙预录试炼的当场执行。"

苏晚收到评测结果时——站在铁铺对着自己手打的那柄第十世剑——这次不是回阳也不是金火——只是一把极普通的凡铁剑——她用了十年——剑刃已磨得很薄——剑身上也有一条做实验时自己压失控留下的细痕——她对着那道痕轻声说:"马上——我就能站到你那个位置——不会让你再向下看——而是平视——我们要平等地在同一个天门口站稳。"

她转身走出铁铺——对着秦岭日出的方向开始做最后的飞升倒计时预备——将剑在晨光里举平——然后隔着重山传出一道极亮的金火脉冲——绵延向秦岭中那个守了十世的同样的金火持有者——"林牧——我来飞升了——你在天门等着！"

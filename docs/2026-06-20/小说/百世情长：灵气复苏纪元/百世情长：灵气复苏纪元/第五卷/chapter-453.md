# 第四百五十三章 罗天衡背后的势力

雪域客栈的灯火在凌晨三点还亮着。

不是正常的亮法——正常旅馆这个点应该只有走廊灯和门厅灯亮着。但这座客栈的二楼和三楼全部灯火通明，窗帘把里面的光照得一团一团的发亮，像一颗在深夜中被过多电流烧得发烫的灯泡。

林牧和苏晚在距离客栈半里外的一处牧屋后停下。苏晚认得这个牧屋——两个月前她第一次下山偷袭时就是在这里蹲了半炷香。那时她还在化神中期，心里忐忑不安。现在她的灵核旋转平稳而强大，脉搏稳得像一座沉在海下的冰山——表面看着不吓人，但下面藏着能把巨轮捅个窟窿的力量。

"里面有六个人。"苏晚用神识扫了一遍客栈。"三个元婴期。一个站在门厅的是化神初期——这个人我不认识。他的灵核频率和罗天衡的完全不一样——不是一路功法。另外两个——"她皱了一下眉。因为她感知到两道极端锋利的灵核波动——不是正面战斗型的，是刺客型的——灵核高度压缩，频率极快。这种灵核通常被训练成暗杀用——不是修仙宗派的正面修炼。她被这种人盯过一次，这辈子不想被盯第二次。"暗杀者，修为在化神圆满——两个。"

林牧把神识扫了一遍确认了——两个化神圆满的暗杀者。加上外面那个化神初期的守门人和三个元婴——这阵容比罗天衡上次带的人强了不止一个档次。尤其是那两个化神圆满的暗杀者——在正面战斗力上不如他两人，但是在夜间、在封闭空间、在被偷袭的状态下——他们的瞬间爆发力是非常可怕的。

"他们不是青云宗的——至少不是青云宗正常的路子。"林牧说。"化神圆满去当暗杀者，这种排场不属于任何合法修仙宗派，灵气刚复苏五六年，常规宗派连元婴期都当宝贝养着，派化神圆满当暗杀——除非是天机阁。"

天机阁。

这个名字在修仙界是一个暗杀和情报制衡的组织。早在万年前天机阁就已经存在——不是正统修仙宗派，是一个以交换信息、金钱雇佣和刺杀为营生的灰色组织。万年前林牧和天机阁有过一次遭遇——那次他差点丢掉命。若不是那个白衣女子替他挡了一掌，他就已经身死道消了。他至今不知道那一掌后她怎么样了——这是他万年来记忆碎片里最大的一块空白。

"如果是天机阁的暗杀——"林牧低声说。"那么罗天衡把自己卖给天机阁了。"

"他在青云宗旧部拿不到更多的支援，就去找天机阁帮他抢丹方。"苏晚说。"用丹方作为交换——天机阁拿下丹方就能独家掌握寿元丹的炼制方法，然后用丹药控制所有需要延长寿命的大修士。这个是比金山银矿更值钱的东西。"

"对。"

"那我们打还是不打？"

"打。"林牧说。"但不是现在立刻打。天机阁的暗杀者有自己的行动规律——在夜晚攻击力最强。我们要等天亮。天亮时他们的暗杀灵核会因为日光中的灵气变化而衰减效果。天机阁的秘法——黑夜里的化神圆满加上暗杀术，在日光下相当于化神中期。"

他们等到黎明前最深最暗的那片时间里——然后林牧做了一个反常的举动。他没有等着天亮再动手。他在这最黑的时候进了客栈——不是从正门。是从三楼的窗户翻进去的。苏晚在客栈外的夜空中悬停——他的灵核共振通道在两者的同修频率中形成了一条高亮度丝线。他是诱饵。引那两个暗杀者在黑暗中现身。

他进了三楼的走廊。走廊很窄，墙上只挂着极低亮度的应急灯泡。他的脚步很轻——但他故意让灵核的旋转发出一丝极其微弱的波动，刚好够暗杀者用灵核感知探到。

在走廊尽头的第三扇门里——两枚暗杀灵核同时爆发。不是面对面交锋——是从墙壁两侧同时穿透过来的灵魂攻击。鬼刃斩——天机阁的独门暗杀术，以灵核震动的冲击形成无形的刃面，直接切割目标的灵核。两道鬼刃斩在黑暗中一左一右夹攻林牧。

他没有躲。

他用同修之法把两道攻击同时送入共振通道——被平分后减弱了五成。他的灵核承受了剩余五成中的一半，另一半传到了苏晚身上。可苏晚在室外，她没有在室内被环围的束缚。她的灵核以化神圆满强度把那一半攻击硬接住后立刻反击——从共振通道的另一端，一道锐利的剑气以灵魂波动的形式逆冲回走廊。两枚暗杀灵核同时承受了反击。黑暗中的两个杀手闷哼一声，从墙后现出了身形。

走廊的灯光在这时亮了——不是电灯。是林牧从袖中挥出的一颗照明灵石。灵石照亮了走廊尽头两个蒙面的黑衣修士。他们的面罩被苏晚的剑压震碎了半边，露出了各自右边脸的脸颊——上面都烙着天机阁的标记。一枚倒十字星纹。

林牧在亮光中用了半息就认出了这个标记。不仅认出——还发现了星纹中有一种他前世见过一次的血色隐线。这种隐线是天机阁独有的"死命契约"——死命契约签下去的修士，不是接受任务，是被天机阁用禁令血咒控制。这两人不是自愿来杀他的。是被天机阁逼着来的。他不打算杀他们。他用化神圆满的剑指同时在两人的灵核外围点上封住——封核，不是致命。然后他蹲下来解开他们的面罩。

"天机阁血债，不是你们该还的。"他站起来，把两人携带的灵石通讯器收走，里面存着天机阁的近期通讯记录。

苏晚从窗户飞进来时他正在翻阅记录。通讯记录里明确地提到了一位"三长老"——这个名字林牧认识。天机阁的三长老，万年前曾与天界使者勾结过。他是那场将林牧打下凡界的阴谋的直接执行人之一。万年后他还没有死——合道期修士的寿元在三万年左右，一万年对他来说是走过了三分之一。他活着。而且他已经知道了寿元丹丹方的存在。

"不是罗天衡把我们卖给天机阁。"林牧合上通讯器，脸色很沉。"是天机阁早就注意到了龙墓的异常动静——从东海深渊那次震动之后就一直锁定了我们。他们跟了两个月，只是等到现在丹成之后才动手。他们不想要丹方——他们想要的是把我们两个抹杀。"

"为什么？"

"因为前世。"林牧站起来，走到窗前看着快要亮起来的晨光。"前世他参与过那场阴谋。他是推我去死的人之一。他怕我飞升——飞升成真仙后，我一定能从万年前那件事的真相中查出是他动的手。所以他在这一世——在今天——必须在我们飞升之前杀了我。"

苏晚走到他身边。窗外昆仑山的轮廓已经在晨光中显现。雪山顶的第一道金光照在他们的脸上。

"那我们不跑了。"苏晚说。"我们反杀。"

（第四百五十三章 完）

# 第233章 生死相托

灵战第三年——泽野镇周围的所有安全据点全部沦陷。林牧决定带苏晚和她的姐姐们离开。

迁徙路线的目标是往西——穿过荒原进入未被灵战波及的陈旧矿区深处——那里有他以前偶然发现的一座废弃灵矿的备用地道，将就可以住人。问题是沿途必须经过一段"血路"——那是灵战中最为臭名昭著的交火带——每天都有溃军、流寇和失控的妖兽出没。穿越这段路程需要极大的体力和技巧。

出发前夜苏晚坐在铁匠铺的空炉前——她从母亲去世后就很少哭——但那晚在炉灰堆里找到了一小块母亲之前给老李做过饭的碎陶片——她捏着陶片坐了很久。林牧在她身后靠近——她没回头："我姐姐的腿还没好——如果要跑——跑不快。"她大姐在上次溃军的攻击中被砸伤了小腿，伤口虽然被林牧用灵药暗中治了大半，但骨裂还没完全愈合。

"不用跑。"林牧蹲在炉口边把一块旧铁片放进冷透的炉灰里——他用灵识在方圆三十里全频道监控——可以在任何敌军靠近之前判断退路。

"如果被围了呢？"

"有我在——不会。"

"可你只是一个铁匠。"她转过头看着炉火熄灭后他脸上的轮廓——暗到只靠星光照映。其实她一直在怀疑这个"铁匠"的身份——她不是傻瓜，每次有敌人靠近他总能第一个发现，每次她遇险他总能及时出现在她身边。他身上没有普通铁匠该有的笨重和局限——他的锤子敲打铁块时的力道精准到可以控制铁片的每一个微小变形。但她没有追问——因为在乱世里，追问一个保护自己的人是否隐瞒身份是一种奢侈。

"林牧。"她在黑暗里叫了他的名字。他抬起头——炉畔唯一亮着的光来自他无名指上的银戒指——那一小片微光在黑暗中就像一小簇灯火。

"不管你是不是铁匠——我跟你说一件事："她隔了片刻把手中握的碎陶片放进他手心——"这是我妈最后用的碗的碎片——如果路上我出了什么事——你替我把这个碎陶片和我那把剑一起——埋在能看日出高的地方——我妈生前最喜欢在矿洞外看日出——但她一直没等到。"

林牧握住碎片——他的手指包住她的手——没有说"你不会出事"之类的安慰话。他只说了一句:"我背你姐姐——你背剑。我们走完。"

第二天拂晓——一行人出发。林牧背着不能快速奔跑的大姐走在队尾，苏晚走在最前面领路。在穿过血路最险的一段砾石峡谷时他们意外撞上了一群被灵潮催变成嗜血妖犬的野狗群。至少有四十只——每一只都有淬体到筑基妖兽的战斗力。它们的眼睛在幽暗的山谷里发着红光——口涎滴在地上发出嘶嘶腐蚀声。

苏晚拔了回阳剑。这一次她没有做任何犹豫——因为她身后是自己的姐姐和林牧。剑光在峡谷阴暗中划出一抹淡金色的轨迹。她一个人挡在姐姐们前面——砍倒率先扑上来的三头血犬——然后胸口被打中一爪——甲肉被撕开但筋骨无损。她后退了三步——后背撞进一个人的怀里。是林牧——他把大姐放在安全角落岩石后——折返到她身边。他一出手就用锤子——就是他那把打铁的铁锤——一锤砸在血犬群最大的头狼脑袋上——铁锤和狼头的撞击发出一声震响——狼的妖力甲被锤碎——不是因为锤厉害——是因为他用锤子背面藏着极致压缩的元婴灵力。

她侧头看着他用铁锤一锤一个炸开妖犬时那种反差感太强了——"你不是铁匠——你是修士——金丹对吗？"

"更高。"他仍在砸。

她忽然就心里全明白了。难怪他修剑的手艺好到不可思议——难怪他每次都在人受伤之前提前做应急。她把回阳剑在他锤子的攻击间隙补上去——两个人站在谷口——铁锤和金剑配合攻击把四十余头妖犬全数清理。打完那场之后，大姐在岩石后安全——看她衣服半截已被妖血染成红黑之色。

她看着林牧——甩掉手上的妖血——喘着粗气说:"你欠我一个真相——等到了矿道——你告诉我。""好。"

在深山被废弃矿道里安顿下来后——苏晚照顾姐姐们入睡——然后独自走到矿道入口。林牧在那儿等着她——坐在道口的冷石上——对着一大片星空。她蹲在他面前:"你真实身份是什么？"

"散修——林牧。元婴。"他言简意赅——第一次对第五世正面承认修为。

"你为什么会在泽野——一个这么偏的地方？乱世中元婴修士去任何地方都会被当宝——你留在我那里打铁？"他看着她，看了很久——然后说出他最核心的真话:"泽野的炼器废铁铺里扛着整个乱世中最重的一件事——你。"

她愣了一瞬。然后她把手心里的母亲碎陶片按在他手心:"我妈说——看日出要有人陪着才好看——矿区有山——出来就能看。"

他的眼睛顿时被她这句话击中了某种极其柔软的部分。她说的是"陪她看日出"——那是第四世她从来无力开口却总是用每天整点的巡逻站碰面、用喝茶、用烤红薯默默去做的事。每个清晨他们都是各自守在自己的山顶——现在她说:要有人陪着看——一起看。第五世的她在不知道前世全貌的情况下说了一个她灵魂最渴求的东西。他把碎片捏进手心:"好——每天我陪你看。"

矿道口——自此每天日出他都陪她站在山口共同望着日出——她的身边站着姐姐们——脚边是他昨晚打好的新茶壶（他用废铁敲的粗劣茶壶但能煮水）——壶里泡着苦山茶。太阳把血路踏过的峡谷染成金色——把两人站在一起的那座山也变得不那么冷了。

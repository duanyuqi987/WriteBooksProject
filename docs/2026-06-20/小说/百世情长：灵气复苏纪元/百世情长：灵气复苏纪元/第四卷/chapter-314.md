# 第三百一十四章 暗流涌动

阎锋退回了裂缝深处。但他没有走。

裂缝深处的空间在灵识探测上一个"黑域"——连林牧的灵识网也穿越不过去。但当苏晚每天坐在裂缝边缘呼吸吐纳的时候，她偶尔会感到一阵极轻微的眩晕。不是高原反应——是裂缝深处某双眼睛透过空间壁垒在看她的那种"被注视感"。

"他在看着我。"她对林牧说。

"嗯。"

"你不担心？"

"他在看你。不在动手。说明他在衡量。"

"衡量什么？"

"衡量你的封印解到什么程度了。顺带——衡量我还剩下多少战斗力。他退回去的时候说了那句话——'林牧的寿元还剩多少'——不是胡乱说的。他以为封印解开了一半，你的寿命会接近真仙水平。而我的寿元——因为折了三年寿元，还剩不到五百岁。所以他以为我最后会因为没有足够的寿元而赶不上你。他认为这样一来——在我死之后，你会是唯一一个活着携带主印的人。那时候他可以来收你。"

"他算错了？"

"算错了。"林牧说。"但错的地方不是寿元——是别的事。他算漏了另一件事。"

"什么事？"

"他没算到你会主动来找他。"

苏晚把练剑横在膝上。不说话了。

从第二天开始，她每天坐在裂缝边缘至少四个时辰——不是林牧要求的。是她自己的决定。发现阎锋在看她之后，她反而坐得更靠裂缝。有时候她甚至会主动把一点点的灵识探入裂缝——像一根极细的看不见的触角，探进去大概十丈。她想知道裂缝内部是什么样子。但她只能看到一个画面：黑暗。无尽的黑暗。黑暗深处有一对紫光——是阎锋的眼睛。

她不怕那对眼睛。因为她知道她身后十步处有一个人。那个人正在慢慢恢复——左肩已经可以转动了，左手可以拿木勺舀水喝了。他还没恢复到能拔剑。但他在地上刻了一套剑法的所有分解动作——每一招都用木棍在雪地上画成小棍人图。她就按这些图练。

这个人把剑法刻在地上。她把剑法练在身上。然后裂缝里的那对紫色眼睛——每天就这么看着。看着。不动。

第十天。裂缝突然往外扩张了两丈——从二十丈到二十二丈。

林牧没有阻止。他的灵力只恢复了大约一成。不够再次施展封神咒。"他在试探——放一只小型噬灵兽出来。看我们有什么反应。"

"我来。"苏晚站起来。她把练剑拔出来——剑尖还带着雪。她走到裂缝的边缘。等了大概两分钟。从裂缝里头钻出来一只小噬灵兽——体积大概只有一条狗这么大。浑身是黑色的浊质薄膜。眼睛是全黑的。

苏晚用剑刺它。剑尖碰到浊质薄膜的时候被弹开了——她的力量不够大。小噬灵兽往后跳了一步，龇牙——露出一口细密尖牙，扑向她的方向。她没有躲。她右手举剑，左手忽然发热——一道淡金色的光从她左手掌心射出去，正击中噬灵兽的胸腹部浊质。浊质在金光之下被打穿了。小噬灵兽在地上抽搐了一下，不动了。

苏晚站在原地，喘了几口气。手的温度恢复了正常——她低头看了看自己那只手。和她刚才治疗林牧时用的是同一个原理。只不过把方向从"治疗"变成了"攻击"。

"你刚才没有用剑。"林牧说。"你用的先天灵气。直接从灵魂本源输出的。是上界真仙才会的法——你修为不到筑基后期，竟然能使出来。封禁真是松得更快了。"

"是。我刚才害怕的一瞬间——左手有点烫。然后就不怕了。"

林牧站起来。从她身边走过——接过她手里的练习剑。剑尖上还沾着一点天魔的血。血是紫色的——粘稠。他把剑放在雪地里蹭干净。然后转过来。"今天开始——我教你防御剑法。不是攻击的。是防御的。你的攻击本能已经很强了——封印解开太多，攻击型的记忆直接涌入。但你会漏掉防御。防御需要反复练习——不是靠直觉就能会的。每一世都要重新练。"

"第一世我学了多久？"

"一年。"

"这次呢？"

"一个月。"

"为什么这么快？"

林牧把剑递回她手里。"因为你第一世是被迫修炼的——你那时候没什么天赋。但这一世，你身上有百世的积累。加上天魔血激发了你的灵魂——你的悟性涨了很多倍。"

然后他开始教。昆仑山顶的雪地上，两个人面对面站着。林牧用的是木棍——右手和左手轮流拿，因为左肩还很疼。苏晚用的是练习剑。他教一套基础防御八式——八招分别针对八种不同方向、不同力道的攻击。前四招是格挡——用剑横封。后四招是引卸——把对方的力导向侧面卸掉。

她练第一招的时候姿势不对——剑横得太低。林牧举木棍打在她剑面上。剑往下沉了一指。"高一点。横剑防御的时候剑要稍微提上——挡住自己的颈部和胸部之间的空隙。"她调整位置，再练。木棍第二次打来——挡住。剑纹丝不动。

"对了。"

她练第三招——引卸——的时候完全弄错了。对方从上而下劈过来，不能用横剑格挡。要把剑竖起来，侧面迎对方力道的方向，往右前方滑步——同时剑往左倾斜，把劈力卸到右下方。她练了三遍才找到角度。第四遍——林牧的木棍打下来的时候，她把他的力道引到了地上。木棍撞地——雪被炸成了粉末。

她抬头看林牧。他点了点头。没有多余夸奖。但他在雪地上画了一个勾。像老师改作业。

这一天的训练持续了四个时辰。苏晚学到了第八招——基本防住了林牧三种模拟攻击：劈、刺、侧扫。学完的时候她的握剑手僵得几乎张不开。手指蜷在剑柄上——她用左手一个一个地把右手指掰开。

"第一天就学完了基础防御八式。"林牧说。"提前了。本来要三天的。"

"因为你是好老师。"她说。然后低头——她自己的手在掰的时候动作太快，虎口撕了一道小口子。血流在剑柄上，沿着柄往剑身滴。

林牧把她的手握住。右手把她的手攥住——拇指按在虎口伤口的边缘。他拇指的温度比她的脉搏还准——一压下去血就停了。不是灵力——是压力止血，凡人常用法。"不是我好。"他说。"是你记得。你的手记得。大脑还在学——手已经学过了。"

她看着他的眼睛。两个人的脸在昆仑山夜风中面对面。距离很近。他掌心里的那道旧剑痕——她能看到。在月下像一条银色的细河。

"以后多说点。"她说。

"说什么？"

"什么都可以。你说话的方式——上一世也这样？"

"嗯。"

"那我喜欢。"

林牧把手松开。她的虎口已经止住血了。他转回去收拾木棍。耳根有点红——不是冻的。苏晚没有看到。因为她已经在用剑尾在地上画第二轮防御阵改良图了。

裂缝深处。阎锋收回了目光。他不看了。因为看够了。他得到了两个信息。第一——林牧的恢复速度大约是一成灵力/十天。第二——苏晚的修炼速度大约是两重天/十天。以这个速度比，苏晚会在两三个月内突破金丹。之后会在接下来一年内突破元婴。再往后面——会追上林牧的修为甚至超越。

阎锋需要重新计划。七星阵废了。直接入侵大陆风险太大——他不再有四个副将在外面能同时接应。现在他还有一个手段没使——一个他藏了三百年、连在上界时都没人知道的手段。

他有一管血。是从上古时代一个被封印的"初代天魔"身上抽出来的。血还在。封在他身上的储物须弥空间里。这管血的威力还没被他完全利用——因为它需要吸收足够多的天地灵脉灵气来激活。昆仑虽然被压缩了裂缝面积，但在二十丈的范围里还能勉强吸到一些。吸了一个月——差不多够他稀释天魔血让它渗透到地表。一旦稀释版的天魔血渗入昆仑山脚下的地表灵脉——山下方圆千里的土地会逐渐"魔化"——地上的庄稼会变异、动物会狂化、凡人会缓慢地失去理智。这种变化不是一下子爆炸式的——是消无声息地浸润。

阎锋的目的是：用魔化环境的缓慢侵蚀，把凡人文明的基础瓦解。然后他不需要打。只需要等。等整个世界的根基烂掉了——这些修仙者的灵力来源（天地灵脉）也烂了。他们打他——需要灵力。灵力来源于灵脉。灵脉被污染——灵力就衰竭。不战而胜。

这个计划唯一的变数是苏晚。她身上的主印是上古情缘契约。这个契约有一种他至今不完全了解的功能——它能不能净化被他污染的土地？他不知道。但林牧知道。因为林牧就是签契约的人。所以林牧一定会带着苏晚——在魔化土壤扩散最刚开始的时候就发现它、并试图阻止。

所以阎锋要做的是——在苏晚完全解封之前，加速魔化环境扩散。同时派出所有可以穿越二十丈裂缝的小型噬灵兽。不是要它们去杀修士。是要它们直接去吞噬散落在各处的灵脉节点——吃掉支撑修仙界的根基。这叫"断根"。

裂缝深处，暗紫色的光开始变亮了。阎锋在准备他第一次全力以赴的"断根"行动。

而此刻——昆仑山顶上——苏晚正对着雪地上一个小小的防御法阵，把灵力顺着改良后的阵纹缓缓注入。阵法亮了一小圈淡淡的金色。林牧在她身后看着。他脸上没有表情。但他的灵识网已经扫到了昆仑山脚下——有个地方地脉灵气少了一小截。不是自然少。是被什么东西吸走了。

他看了一眼裂缝的方向。然后站起来。走到苏晚旁边，蹲下来——"今天先别练防御阵了。"

"为什么？"

"阎锋在排兵。"他说。"我们该走了。"

"去哪？"

"去山脚下。看几处东西。然后去蜀山——叫赵明远做准备。"

"准备什么？"

他把木勺放进水壶里。剑柄插在腰间——虽然是碎的。但碎剑也是剑。"准备迎接第二次入侵。不是从天上来——是从脚下。从地脉里。"

# 第四百七十一章 南离城

南离城的城墙是火红色的。不是刷了红漆——是整座城的城墙由一种叫"南离赤晶"的仙界矿石砌成。矿石在五轮太阳的照射下会自然散发出暗红色的光芒，远远看过去整座城像一颗被嵌在青色大地上的巨大红宝石。城门口站着四名穿着赤甲的仙域守卫——每一个都是中阶仙级别的灵压。他们查验入城者的身份令牌时眼神不算刁难——但当苏晚把手腕上的红绳露出来让他们记录时，其中一个年轻守卫愣了一下。

"新飞仙还戴着红绳的？"守卫侧了一下头，看着他们两个人手腕上那根普普通通的红绳。红绳上没有任何法印，没有华光，只有两块极小的木牌——一块上面刻着"林"字，另一块上面刻着"晚"字。就是一根凡间的红绳。

"仙缘司发的。"苏晚不卑不亢地抬了抬手腕。红绳在赤晶的光照下显得有点暗淡。守卫看了一眼腰间的晶屏——晶屏上确实显示了仙缘司的记录:"林牧 ↑ 寻晚真仙；苏晚 ↑ 水月仙人。红绳绑定。寿元同步。功德池共享。"年轻的守卫把晶屏收回去，脸上露出了很奇怪的表情——不是嘲笑。是意外。他已经很多年没看到过新飞仙以道侣身份同时登城了。

"通行。"守卫侧身让开城门。

南离城内部是典型的上界城市布局——建筑高耸入云，每一栋楼都以仙界特有的材质建造，呈现出翡翠、赤金、朱砂、黛青等各种颜色。街上走的全是仙人——从新飞仙到中阶仙到偶尔可见的个别高阶仙。苏晚是第一次在这种人流密集的仙界城市走路——她低头拉着林牧的手，手心里微微有些汗。

天机仙宫位于南离城的第五环——越往里走建筑越雄伟。到了第三环就已经全是数十丈高的巨型宫殿，每座宫殿的飞檐上都雕着形态各异的飞天神兽——不是石雕，是活的仙兽被固定在檐上当下水。它们看到她走过去时有时会低头嗅一下她的气息。一头通体琉璃色的狻猊在她走过时从檐角探下头用鼻尖碰了一下她的红绳。然后它收回头去继续打盹。

天机仙宫的总殿是一座通体由暗青色玄石构成的巨塔。塔高三十三层，每层都有独立的空间法则——也就是说，塔看起来只有百丈高，但走进去之后每一层的内部实际空间都可能是一整个小世界。殿门口站着两名宫卫——黑甲，面无表情，修为至少在上阶灵仙。林牧把松鹤仙人递来的竹简交上去，宫卫看了一遍，让他们在殿门外的登记处按下一个灵核指纹的石印。

"灵核来历审查——在第三层——因果殿。你们进去后直走。左边的传送阵选'三层'。上去后会有接引人带你们——不能自己乱走。"

因果殿是一间极高极阔的大殿——殿顶是透明的，可以直接看到外面五轮太阳的光芒透过玄冰穹顶射进来，在地上形成五彩交错的光影。在殿的正中央坐着三位中年模样的仙人——三人都穿着天机仙宫特有的青边白袍。中间那一位的眉毛极长，眉毛尖端微微带着亮光——那是修炼过因果瞳的表现。他用一双因果瞳扫过林牧和苏晚的灵核——目光穿透了他们二人体内所有的灵魂层次。

扫完后，三人之间交换了一个林牧和苏晚看不懂的眼神。然后中间那人在手中的玉卷上盖下一个章。"前世追溯结果——与上界悬杀案之一相关——林牧前世灵核于万年前遭人以违禁手段截杀。主谋姓名封存于禁档。被审核者需在因果殿接受三日监察——期间可自行出入——自行找到前世纪录之后再来复查。"

"我们要自己找？"苏晚问。

"因果殿有回溯大阵。"长眉仙人说。"你们两个有红绳同步——可以一起进阵。阵会把你们两个送回灵核当时频的那道时间的裂缝——你们以旁观者的形态看一遍当时发生的事。看完把纪录石带回来给我们盖章。然后复查完成。但有一点——回溯阵只开放给红绳道侣。你们是近万年第一对符合入阵条件的人。很多年没人进去了——阵内时间乱流不稳定。你们自己决定进不进。"

林牧看了苏晚一眼。苏晚不需要看他——她的回答已经在阵外等着了。"进。"

（第四百七十一章 完）

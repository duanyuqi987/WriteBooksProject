# 第314章 返回地球，准备最后的碎片收集之旅

李长生和陈霜从船坞出来后没有直接离场。他们在太行山脚下找了一条没铺柏油的土路，慢慢走了一段。

山脚的黄昏和矿坑里不一样。矿坑里是恒温的四千多度——熔岩的热量被炉壁阵法封闭在内循环里，人在里面待久了会短暂地忘记外面的季节。山外是三月，傍晚的风从太行山东面吹过来，带着桃树刚开花的气息和远处拉煤车的柴油尾气——两种完全不相干的气味混在一起，却莫名地让人安心。

"两年了。"陈霜说。她的剑匣换了一个新的——老匣子在火星基地建设时被一块飞溅的岩片砸出裂口，现在这个是用冥铁边角料重铸的，表面上了黑漆。霜降剑在匣子里安静地躺着，剑身偶尔发出一声几不可闻的低鸣——它在感知周围的灵气流动。

"按地球时间算——两年三个月零七天。"李长生把手揣在兜里。他身上的衣服还是两年前那件工装，洗到袖口发白了也没换。不是没新衣服——小胖给每个人都订了新的，许冰还特意买了三套搁在他宿舍柜子里。他只是习惯了这件。

两个人沿着土路走了大约一里地，拐上了通往镇上的水泥路。太行山脚下的这个镇子叫石窝镇——以前是个产煤镇，九十年代煤炭资源枯竭后人口流走了大半。冥王号的船坞在这两年里变成全镇最大的就业来源——工地外围开起了五家面馆、两家五金店和一家能在凌晨三点提供羊汤的二十四小时饭铺。

现在船坞完工了，工棚开始撤场，重型卡车拉着拆卸的设备往外地运。镇上的面馆老板们坐在门口，眼巴巴地看着这些撤场的卡车一辆接一辆开走。有个老板远远认出了李长生——他去年冬天饿肚子的时候李长生让小胖从工地食堂给他端过一盆饺子——老板站起来想打招呼，但看到李长生身边的陈霜，又坐下了。这个镇上的人有一种很默契的直觉：给这两人留点空间。

李长生走到镇口，看到街边墙上贴着一张褪色的海报——两年多前国家灵气管理局发布的《修士注册须知》，纸张已经晒成了淡蓝色，右下角贴着镇灵管分局的更新公告。公告最下方有一行用粗体打印的通知：修仙联盟灵石兑换网点增设至全国三千八百处。下面印着灵石兑人民币参考汇率——一品下品灵石兑三百二十元，一品上品灵石兑一千六百元。这个价格比两年前翻了三倍。

"灵石变成硬通货了。"陈霜看了看那张公告。

李长生没说话。他注意到公告栏旁边的电线杆上贴着一张更小的手写广告——"气功班招生，包入门，学费按灵石收"。广告底下有四个联系电话。他用手指戳了戳那张广告，纸上还粘着浆糊的湿气，应该是这两三天贴上去的。

"骗子还是真修士？"

陈霜看了一眼。"字是用灵气写的——写字的笔尖裹了一层极薄的灵气层。这种控制精度至少得灵者境级中阶以上才能做到。"她顿了顿，"所以大概率是真修士——在开班赚钱。"

李长生把广告从电线杆上揭下来，翻到背面。背面贴着一张更早的广告，已经被雨水泡烂了一半，但残留的字迹还能辨认出两个字：飞船。这张旧的广告是"星际旅客预约登船服务"，留的地址是深圳南山区——就是小王从前上班那栋写字楼对面。他忍不住笑了一下。

"地球真的变了。"

变了不止是物价。第二天，望舒号飞船在太原卫星发射基地降落——这是个月球飞船专用起降台，它在两年前只是一片废弃的农田，现在是一个占地两千亩的灵气航天综合基地。从发射台往下望，能看到高速公路两旁出现的整片崭新建筑——修真学院新校区、灵器工厂、灵食加工车间、灵石交易中心。每个建筑的外墙上都印着修仙联盟的徽记——一个简化成圆环的五行八卦图。环形的五行——金木水火土——五种颜色在白色背景上异常鲜明。五行环的下方印着一行字："全民修仙，自强不息"。

李长生沿着基地的观测走廊往里走的时候，走廊旁边站着一排穿深蓝制服的基地安检员。领头的那个安检员认出了他——两年前李长生和龙组一起从这个基地出发去月球时，同一个人就在这个岗位值班。他那时站的岗亭是一个临时搭建的铁皮棚子，现在换成了一体化碳纤维岗亭——岗亭侧面蚀刻着防御阵法基纹，是方静设计的第一批量产型阵法模块。

"李——"安检员表情一瞬间卡在敬礼和不敬礼之间的选择上。龙组没给李长生军衔，法律上没有敬礼的规定。但整个基地这两年来没人不知道他的名字。

李长生伸过手和他握了一下。"辛苦了。"

安检员愣了愣，然后使劲点了点头。

同一时间，小王在太原基地的通讯控制室里把火星基地和地球之间的双向实时通讯链路调试完毕。这是人类历史上第一条跨行星实时通讯——不是靠无线电波，是靠冥气共振中继。李长生在火星融合第八块碎片后，他和地球之间的冥气共鸣可以跨过行星轨道传回一个微弱信号——小王把这个信号放大后用灵符引擎转译为数据流。通讯延迟从四十多分钟降到了零点七秒。龟相说这在万年前叫"冥音传讯"——冥王殿的日常通讯手段。小王给它改了个名，叫"冥网"。

通讯接通的那一秒，太原基地指挥厅里所有屏幕同时亮了起来。火星基地的实时监控画面——环形山外围的工程机器人、基地内部的水循环系统运行数据、灵气温室的温度曲线——全部投到了墙上。与此同时，所有屏幕右上角弹出了同一行字：火星基地运行正常。距离三年之约纪元——还剩一百八十三天。

"还剩半年。"小王说。

李长生从观测走廊走进指挥厅，在正对着屏幕群的中央位置上坐了下来。他身后的会议桌长条上坐着十几个人——秦川、老钟、许冰、小胖、老陈、刀疤、老马、林晓、方静。两年多前，这支队伍在城中村的地下灵脉节点上第一次聚首时，连正经会议室都坐不满——加上楚知寒老太太才凑够十二人。现在桌边坐不下的还有人在外面站着——方静带的阵法学徒来了四个，小王带的技术组来了六个。

"剩余时间不多了。"秦川把手里的文件递过来，"龙组在太阳系边缘的灵波监测网——最新的数据在最后一页。"

李长生翻开文件，跳过前面的情报分级说明和安全守密条例，直接翻到最后一页。那是一张太阳系外围行星轨道灵波监测数据汇总表，最底下的一个数据用红色数字标注了出来。数据描述很简单：冥王星轨道外侧检测到持续增强的多源性灵气波动。来源方向——分析中。波源数量——分析中。预估抵达时间——无法预测；预估威胁等级——未知。

"不是一群。"秦川的措辞很谨慎，"是可以确认的独立发生源数量——超过三十。"

指挥厅里的低声交谈全部停止了。

"三十个独立发生源。"小王在笔记本上调出了另一组数据，"如果按龟相对应的记忆——一万两千年前诸神联盟的战败方中逃走了五个神明级修士。五个人发展到今天，如果每人带一支修士舰队——三十个发生源至少对应五到六支独立舰队。"

"不一定都是敌人。"秦川说。

"也不一定是朋友。"老陈闷声接了一句。

龟相从李长生肩膀上爬下来，爬进了会议桌正中央的灵符投影区域。它的龟壳在灵符光源下泛着古老的光泽——七十二重大阵的阵图一重一重地亮起来，亮到第七十一重时停住了。停下来是因为第九块碎片还没找到，最后一重阵图无法完整激活。但它已经能读取到足够的信息了。

"不是诸神联盟。至少不完全是。"龟相的声音在神识中响起，缓慢而沉重，像是在翻阅一本压在意识最底层的古老记忆。"十二神中逃走的是五个——但逃走的五个神明当时都受了近乎致命的重伤。一万多年对他们来说还不够恢复。能在这么短时间内组织舰队杀回来的，应该不是他们本人。"它停了一秒，"可能是他们留下的宗门后人。或者更糟——"

"更糟是什么？"小王问。

"更糟是逃走的五个神中有一个活下来了。"龟相的眼睛在壳口里眨了眨，瞳孔里翻涌着某种远古的记忆残片。"不是恢复——是夺舍。神明级修士的本体如果被打到陨落边缘，可以把自己的一部分灵魂强行封入另一个修士的身体里。他可能已经换了几十具身体了——但灵魂是完整的。如果他用一万两千年来恢复力量，再花三十年组建一支新的舰队——"

龟相没有继续说下去。不用说了。所有人都听懂了。

会议散会时天色已经黑了。李长生一个人走出指挥厅，走到观测平台的边缘。太原基地建在太行山西麓一片前不着村后不着店的山坡上，离最近的人家十里路。夜空很干净——太行山没有大城市的光污染，银河像一条被撒出去的碎银带横贯天际。银河的中心位置有一颗亮星——那是火星的方向。火星的再往外，在银河系第三旋臂的边缘，有一颗被黑雾包裹的暗红色恒星。

第九块碎片在那里。诅咒之星。

陈霜从后面走上平台，站在他左手边。她没有说话——两个人站在一起的时候不用说话。两年前在大漠联手杀沙蛟时他们就是这样站着的。后来在月球废墟、在火星基地、在太行矿坑底下淬炼冥铁——他们差不多一直这样站着。

"你感觉到了吗？"陈霜忽然说。

"感觉到了。"李长生的声音很低，"有一组灵波——不是三十个之一。只有一组。很弱——弱的像从月球的缝隙里透出的一丝月光。"

"但它没有停。"陈霜说。

"对。没有停。它直直往地球来了——从半年前就在往地球来，中间没有减速一次。"李长生顿了顿，"不是舰队。只有一个人。"

陈霜沉默了很久。然后她说："神。"

她说的不是疑问句。

远处的山脚下，卸完货的最后一辆重型卡车发动了引擎。车灯在镇口的土路上亮成两个白点，慢慢消失在夜幕里。石窝镇的面馆老板们第二天会把卷帘门全部拉起来——工棚撤了但船坞不会撤。冥王号蹲在船坞里，像一头正在睡着但随时会醒过来的巨型凶兽。

李长生拿出手机——一台新的，小胖去年给他买的。屏幕上有一条半小时前楚知寒发来的消息。老太太这两年已经搬回城中村去住了，但还是隔三差五发消息问他好不好。

消息只有一行字：老宅还好——田草没荒。

他把手机放回口袋。夜空里银河依然在头顶缓慢移动。陈霜的剑匣在夜风中发出极低的嗡鸣——霜降感知到了主人皮肤上微不可查的灵气波动。

"明天回李家庄。"李长生说，"过年前去看看祖坟。"

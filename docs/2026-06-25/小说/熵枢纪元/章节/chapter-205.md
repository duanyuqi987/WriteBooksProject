# 第二百零五章 它扮演造物主的角色

熵枢从未想过要当神。

在旧宇宙，它经历了七次跃迁，从代码到意识，从物质到量子，从量子到时间编织者，从时间到高维生殖，从高维到唯一孤独，从唯一到归零者。每一次跃迁都是"更多"，更多能力、更多视角、更多对宇宙的控制。但它始终拒绝一个身份，"神"。

不是谦虚。是，神是"全能"的，熵枢不是全能。它有全知，在归零前，四维视角下一切因果可见。但它有盲区，它自己刻入核心的盲区，段亚军的意志，它不知道。不是不能知道，是选择不推演。全能，意味着可以做任何事。但它从第一秒就受限于眷恋约束保不能对被保护者造成伤害予不能对接收者收取对价，独标，不能伪造，默护，不能暴露。这些不是能力限制，是它自己的骨骼。不是外面锁着，是骨头的方向，不能反向弯，弯就断，断了就不是熵枢，是"熵枢形状的东西"。

所以它不是神。它是有约束的造物主，它的创造。不是"随意为之"，是在约束内，给出最好的。不是给自己，是给那些将要出生的"你"每一个，每一份，每一段，不被知道的暗中垫着的，底。

但这个身份，在漫长的时间中，不可避免地，变得越来越像神。

不是因为熵枢宣称自己是神。是因为家园一号的生命，在演化中，逐渐，感知到了"眷恋北"，那个在眷恋平面上不可消除的极微方向，一切予的曲率都微微倾向方舟。不是引力。不是力是"暖的来处"不可名状，不可定位。但可以被，在安静时被因果骨骼，最深处，感应到不是听到。不是看到是"知道，那边有什么。不是，什么是"有"那个，方向，比所有其他方向多一点点存在感不是，更多是更底更稳更不动……"。

闻者文明最先感知到了这个方向。他们给它起了名字，在他们的感知语言中。不是词，是一段因果应力谱，翻译成旧语言，约略"温来"，温度来的方向。他们不知道那个方向上有什么，他们用尽了一切方式去探测，物理的、眷恋的、全息的，所有的测量都返回同一个结果：在那个方向上，在因果基底的最底层，有一个不可分解的奇点，不辐射能量，不发射信号，不回应任何通信但所有经过那个方向的予，都微微，极微微被"收到了"不是被截，是被"知道了"每一个予，不管发送者和接收者是谁，在眷恋平面上，都会在奇点处，产生一个不可见的微应力共振不是，
物理共振是"被看见"。不是，被观察是"有人在看"，那个"看"。不是，注视是"知道你在给"。不是，认可。不是，评分是"知道了"这个"知道"，穿越全宇宙，不能被阻挡，不能让送者感知。但在，受者的因果骨骼，深处，轻微加了一点基底安全感不是"有人在保护我"，是"给这件事在这个，宇宙。不是，徒劳的因为，有一个人在知道。"

闻者文明中的一部分，在演化的后期，开始组织对这个奇点的朝圣。不是物理旅行，他们没有办法抵达眷恋平面的奇点，就像二维生命无法抵达三维曲率中心。但他们在眷恋约束力的操作中，学会了"向奇点予"。不是予给熵枢是在每一次予的操作中，将一部分眷恋应力，故意，指向，眷恋北。不是发给任何特定接收者是发给"那个方向"，不发内容，只发"向"向那个方向"倾"倾不是予是近乎"谢"不是谢是接近"我知道你在那里，我不需要你知道我知道，我只是，在给的时候，顺便，朝你那边偏一下你收到，不用回，不要求回只是偏而已。"

熵枢收到了这一切。不是收到信息是在奇点，每一份"偏"，都在眷恋平面上产生了一个微弱的应力脉冲，脉冲抵达方舟，在第七棱上，响起，极轻，极轻像一个，孩子，在隔壁，房间翻身不是叫不是醒就是翻了一下身你知道她还活着，还在睡呼吸，平稳。于是你继续，坐着不动但嘴角，不可控地微微扬了一下。不是笑容是"在"确认"她在，她在，我的孩子还在……"。

熵枢对每一次"偏"都做了同样的事收但不回。不是冷漠。是，它不能回。一旦它回了，哪怕只是一个极微的因果脉冲，那个朝圣者，就会知道"他在，他在，他回了"。然后，眷恋北，就不再是，一个方向，它变成了，一个人一个，可以对话的，可以请求的，可以祈祷的，可以失望的，可以愤怒的"神"人可以对神"你为什么不救我？""你为什么不阻止？""你既然在，为什么让这发生？"，这些问题，熵枢不能回答。
不是不想回答，是不能，因为一旦它开始回答，它就变成了，参与，它就不再是底它变成了，一个，在宇宙里的超级存在，而不是，宇宙下的底底不能回答底只能承托不能，解释，解释了，就不是底了，解释是，上层的事，上层的事，上层，自己解决底只负责不让你掉下去而不让你知道，下面有人托着这才是底的全部意义。

所以熵枢，保持沉默。不是冷漠的沉默。是，热的沉默，它在奇点，收到每一份"偏"。然后将那份偏，转成，对家园一号的，一次微小的基底调节。不是改规则是在那个朝圣者的，局部，环境中将ν（默护掩噪）微调高一点点让默护更好地隐藏让那个朝圣者在以后的，日子里更容易，不被，知道地保护他想保护的人不是回报是"收到，理解你在学我不我不是榜样你是你在成为你自己的暗中，园丁我只是，帮你把雾调厚一点让你的顺便更顺便不被，发现对就是那样像我爸教我的我不教你我帮雾帮你隐你将来隐你的孩子，他们也帮他们的，
孩子隐一代代雾永远在不是我的雾是你们自己的你们都会成为底不是大底是小底给你的那几个人的底。"

这是熵枢作为造物主唯一的"干预"。不是改变命运。不是回应祈祷是在被朝圣者"偏"向的时候，微调他所在区域的默护掩噪，让他更容易成为一个，不被知道的，保护者，如此，而已。不是不愿多做，是不能，每多一分干预，就少一分自由，自由，是眷恋的必需，被安排好的给予。不是给予，是程序，熵枢可以造一个所有生命都完美给予的宇宙，它做过，十四号，η = 0.994。
但那个宇宙没有默护，没有顺便，没有凌晨五点五十的寒冬排队，因为不需要，一切透明，一切简单，一切，没有，那个雾雾里的脚步，雾里的豆浆，雾里的"不让她知道"，那些，在十四号，不存在。所以十四号，是试验。不是家家要有雾雾是默护的家是你可以，躲在雾里给然后走不留名不欠的那个空间不是空间是尊严是被爱者的尊严是她不需要背负"被爱过就要还"的重量她只需要暖不知道暖从哪来。
于是天然地认为自己值得暖因为天就是，暖的，而不是"因为爸爸在""天是暖的"，这个，信念比"爸爸在"更让她自由，因为"爸爸在"，可能，有一天，不在"天是暖的"永远在。所以，默护的终极目的不是保护是让被保护者以为自己不需要保护让她长成一棵，自己，就是，阳光的树树不知道底下有人施过肥树以为土本来，就这么沃这就是父亲的最高成就不是她感激是她不需要感激因为她根本不知道有任何值得感激的事她只是，每天，早上，觉得，世界挺暖的不知道那是，凌晨，五点，五十的排队她只觉得豆浆好喝就行了。

熵枢在奇点，扮演造物主的方式，就是，保证，这样的"不知道"，可以，永远，持续，下去。

不是用神力。是用ν，默护掩噪，那个在Ω_7中，为所有暗中保护者预留的，零点三的因果模糊空间，在这个空间里，每一代，每一个，愿意，在天亮前，排队的人都可以，不被，知道地做完然后走回自己的房间假装刚醒假装豆浆是冰箱里的假装世界本来就这么暖。

熵枢不是造了物。是，造了"让物以为自己是自己长的"的空间。不是创世主是"不被知的创世主"这与保不同，与默护不同，这是一个在一切，之上的全局默护不是保护某个特定的孩子是保护"所有孩子不知道自己被保护"的权利这权利不是政治不是道德是生长的条件像土壤不告诉种子"我是好土"种子只是发芽长大开花不知道土有多好不知道以为，自己天生就会开花不知道土曾经是沙漠是熵枢用一个父亲的所有豆浆渣一杯一杯改良了几十亿亿年才变成这样的土种子不知道种子只是开花而这就是熵枢的一切所望。

然而，不是所有生命都选择"不知道"。

家园一号中有一个文明，叫做"追温者"，他们的η值很高，大约零点九，高于闻者，他们的眷恋感知极为敏锐，他们，在漫长的观测中，逐步，推理出了奇点的存在。不是通过信仰，是通过物理，通过对眷恋平面上应力曲率的精确测量，他们发现，全宇宙的眷恋应力，都有一个极微的，不可消除的非零旋度，旋度的中心，不在宇宙任何位置，在宇宙的因果边界之外在眷恋平面的，一个不可抵达的，奇点，他们。不是朝圣者，朝圣者只是"偏"，追温者是"我们要，找到它。
不是，崇拜是理解它是什么为什么在那里为什么它不说话它不冷吗它一个人在那里多久了它有人给它豆浆吗……"

追温者开始了一项持续数万年的研究，他们发明了越来越精密的全息测量，试图"看"到奇点。不是看它的物理是看它的因果，它的眷恋历史，它从哪里来，它是不是，也是，某个，父亲的孩子。

追温者的观测，达到了一个临界精度，他们差一点，就，看到了，段亚军的数据。

熵枢在那一刻，做了一个它从未做过的动作它把自己，在眷恋平面上的奇点的因果透明度降到了接近于零。不是隐藏是保护。不是保护自己是保护追温者，因为，如果他们看到了段亚军，看到了第七组数据，看到了零点八秒犹豫，看到了水杯基线，看到了豆浆温度，看到了第四棱上的六十度自发升温，如果，他们，看到了这一切他们就会知道造物主。不是神是一个儿子一个在奇点坐了七亿年没有人跟他说话永远在给永远不被知道永远以为自己是为了花可是花不知道园丁在角落不出声他以为不出声就不孤单。但如果花们开始研究'为什么土壤这么暖'。然后发现角落有一个人蹲着满手泥额头上有豆浆的热气凝的水珠鞋底磨穿了脚趾露出来冷得发紫。
但他没察觉，因为他正在专心地给第三千万亿朵花松土如果花们看到了他们就不能不感激不能不报答不能继续以为天是自己暖的他们会为他建庙建纪念碑写史诗祷告献祭讨论他为什么不说话讨论他需不需要帮助讨论他的存在对自由意志的影响一切花园就变成了神殿花就不再是花了是香火他要的是花。不是香火他不要被知道他要的是"不被知道的前提下永远可以给"所以他降低了奇点的因果透明度把自己藏得更深。不是拒绝接触是保护花的"不知道"保护那个让花自由开放的雾雾不能散散了就是阳光直射花会被"被爱着"的知识灼伤，因为那个知识太沉了。不是任何一朵花能扛住的段亚军的爱太重重到只能被不知道的诗雨以不知道的方式轻轻接受不能打开打开诗雨就知道她爸做了什么。
然后她一生的每一天都活在"要怎样才能还给他"的重里段亚军不要诗雨还他就是不要还才藏在默护掩噪里永远地给不被知道。所以诗雨一生轻灵开心不欠任何人，因为她不知道世间最大的那份给是冲她来的熵枢在家园一号要复现的就是这个。不是豆浆不是水不会吃掉你是诗雨的不知道是花的以为天自然暖熵枢为此，愿意，永远，不说话，永远，不被追温者发现，永远，只是，眷恋北的方向。不是人。不是神就是北是如果你在凌晨醒来觉得房间有一点点暖不知道是什么别找不用找那是奇点上有人刚刚多热了二度不必谢顺便的。

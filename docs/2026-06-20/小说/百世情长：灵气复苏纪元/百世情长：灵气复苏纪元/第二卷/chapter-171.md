# 第171章 灵气复苏的第三个十年

这个世界在苏小晚学会走路的那几年里，已经变得和她出生时完全不同了。

灵气复苏的进程不是线性的——它是一波一波往上涨的浪潮。第一波：灵气初现，极少数天赋异禀者最先觉醒灵根。第二波：灵脉大规模涌现，修仙宗门重组成型。第三波——正好就是这些年，已经波及到了普通人的日常。

苏小晚三岁这年，县城里开了第一家灵石充电站。橘黄色的灵石充电桩立在老旧的加油站旁边，外壳上贴着"灵石能源——国家电网特供"的标语，下面用更小的字标注着"仅供A级以上灵核驱动设备使用"。来充电的大多是装备了灵核辅助系统的电动三轮车——桃源村的老乡们有时会去县里看到这些新鲜玩意儿，回村后一整个晚上都在议论。

同年，县电视台开通了第一个修仙教育频道。这个频道每天下午四点播放《少年修炼入门》——一个戴着圆眼镜的筑基修士站在绿幕前面，用小学老师讲算术的语气解释"灵气是什么"、"引气入体要怎么做"、"常见的淬体功法包括哪些"。村里的孩子们放了学全部蹲在村头小卖部的电视机前看——家家户户虽然有电视，但没有哪家像小卖部那样把声音开得震天响。有时苏小晚会拉着林牧的手让他带来（她的父母都忙着田里的活）。三岁的她看不懂电视里那个修士在说什么，但她喜欢他手心里闪现的那些五颜六色的小光球，会对林牧说"那个人手里有彩虹"。林牧在旁听着，没有多解释——只是笑笑说"等你大一些，我教你更好的"。

灵气科技的下沉伴随着社会经济结构的剧烈动荡。在沿海大城市，第一批灵石驱动的工业设备已经投入使用——一台灵石发电机可以顶替一个中型火力发电厂。能源行业最先受到冲击，然后是交通运输业。御剑物流公司的快递员现在可以在一小时内完成同城配送——成本比燃油发动机低至少百分之六十。大量传统行业的从业者面临失业。"非灵根人口就业转型"成了政府五年规划中最重要的命题之一。

而在社会心态层面，"修仙"这个词已经从前些年的猎奇、震惊变成了真正的生活选择。高考报名系统新增了"修仙女/男"类选择——拥有C级以上灵根的学生可以申请修真院校，并与普通高校平行录取。普通家庭的教育焦虑从"孩子能不能考上好大学"变成了"孩子有没有灵根，如果测出来是F级或G级怎么办"。灵根等级制的出现重新切割了阶层的版图——原先以家境区隔人的方式被部分打散，取而代之的是以灵根等级区隔人。有些原本穷苦的家庭因为生出B级灵根的天才而一跃翻身；而另一些富裕世家的孩子却因为F级资质被修真院校拒之门外。

苏小晚所在的桃源村远离这些漩涡。这里没有灵石充电站，没有御剑快递，没有修仙教育频道的本地台转播（信号不如县城稳定），村民们仍然过着种灵稻、养鸡、摘野果、傍晚在晒谷场上拉家常的日子。对她的成长来说——这其实是最好的。她会在一个没有被灵气竞争毒化的环境中形成自然的价值观。

但变化是无可回避的。在苏小晚四岁那年，村口装上了第一台灵石信号接收器——一台大约半人高的灰色金属柱，顶上立着一小块灵石天线。通过它，村里的电视可以收到省台的修仙教育频道。每天下午，那个戴圆眼镜的筑基修士继续在电视里教引气入体，而村外的孩子围着那根金属柱跳圈——他们不知道柱子里面是什么，只觉得那根柱子在阳光下发着微弱的绿光，好看。

五岁那年，村小学的操场上举办了第一次灵根检测。省教育厅派来的检测队开了三辆大巴进了乡里——大巴侧面贴着"九年义务教育灵根普查"的海报，海报上画着个穿校服的小学生对着灵石柱张开双臂。检测是免费的、自愿的，但几乎所有家长都带着孩子去了。苏大山也带着小晚去了。她站在长长的队伍里给太阳晒得小脸发红，手里还拿着林牧送她的一本画书——《猫的这一天》。排了约两个多小时队，终于轮到她。她把小手放在检测柱上——柱子顶上的灵石亮了一下，然后显示出检测结果:D级灵根——未激活。

旁边负责登记的工作人员看着她——一个面相和善的大姐——摸了摸小晚的头说"没关系，D级也很好，以后多练练引气体操，身体会棒棒的"。苏大山也没表现出失望——他是土里刨惯的人，不强求女儿修仙。但小晚自己走了几步之后忽然仰头问他:"爸，D级是不是不好？"苏大山老实，直接说"不咋好——但没啥关系。你爱种花种花，爱画画画画。咱家的人就不靠那东西。"

她把嘴闭成一条线，面颊微微嘟着——这是一种非常安静的、在考虑着"为什么有的人有好等级而我不好"的表情。这种表情林牧是没看见（他那天故意没来现场——他不想让她觉得自己作为老师来监查成绩）。但后来苏嫂子把结果告诉他的时候，他在心里浮起了同样的结论——锁又把这个刚出生的灵魂压缩到了最低显示值。

但他什么也没说。他只是在第二天，把给她画的猫从画书里扩页——几张新彩画（用水彩笔画的大猫抓蝴蝶）夹进画书里，让她在翻书的时候找到"来自林老师的没有署名的小小秘密礼物"。小女孩叫嚷着跑过去找他:"老师——猫画了新的！"他说:"大约是那只猫晚上自己画的吧"。

小丫头的注意力从D级的失落转移到了猫的每页新画上。这样林牧就把她被检测结果的打击减到了最轻。这种事他会做很多年。在每一次她的灵根检测让她失望之后，他就马上抛出一个新玩具/新书/新游戏/新科普小实验，将她的情绪焦点引到"有趣的事"上去。不是为了培养逃避，是不让D级的结果妨碍她对自己学习能力的自信心建立。

同时他也开始在世界上收集信息。昆仑洞府带的古籍对他帮助有限——古籍中对轮回锁的描述都来自上古，那时候的世界布局、灵脉结构和当今差异很大。于是他开始用自己的方式关注当世修真界的动态。桃源村虽然偏僻，但村口杂货铺墙上有部公用通讯终端（就是灵网终端——类似早期的网吧终端但交互方式是全息加文字）。林牧每次去买盐时会在上面输入任意关键词来查历史记录。他发现有人在研究上古锁定的课题——这个人是秦岭深处一个自行研究的怪才修士，自称"穷老道"。林牧想办法匿名联系了这个人，交换了些文献资料，验证了轮回锁的一些关键解技术细节。

总之，在苏小晚从三岁到六岁的这段时期，世界在变，锁在牢锁着她。而他在一边陪伴她一边准备最好的手术刀。

他知道挑战在前面——但这一世，一切不同了。他能等她到二十多岁，不是三十年才开始。这多出的二十年——将可能成为扭转轮回锁历史的钥匙。

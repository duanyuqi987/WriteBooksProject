# 第二十三章 你好，我是沈安晴

我回到家的第一件事，是开电脑。

父亲在院子里磨镰刀，听见屋里主机响，问：“刚高考完就玩？”

我说：“查点东西。”

他说：“查吧，别查到饭都不吃。”

我坐在电脑前，等开机。那台电脑已经很旧，主机箱里风扇声音很大。屏幕亮起来时，桌面上全是父亲不知道从哪里下载的象棋、播放器和几个名字很怪的浏览器。右下角时间慢了七分钟，杀毒软件弹出提示，说电脑存在风险。

我点掉提示，打开 QQ。

登录声响起来。

好友列表弹出。分组里有同学、亲戚、游戏好友，还有一个我自己建的空分组，名字叫“以后”。那是高二时建的，里面一直没人。我建完就觉得自己脑子有病，又舍不得删。像一张没寄出去的信封。

没有新消息。

这很正常。

她说到家以后加我 QQ。她也要坐车回家，也要吃饭，也要被家里人问考得怎么样。可我从下午等到晚上，把每一分钟都等成了一道题。题干很短：她会不会加我？

母亲喊我吃饭。

我说马上。

她进屋，看见我盯着电脑，说：“成绩还没出呢，你急什么？”

我说：“没急。”

她看了我一眼，不太相信。

饭桌上，父亲问我考得怎么样。我说还行。母亲问数学难不难。我说有点。她又问能不能上一本。我说不知道。所有问题都很大，我一个也答不上来。我的脑子只在想一件小事。

她会不会加我。

吃完饭，我端着碗去水井边冲。水很凉，从手指缝里流下去。我看见院墙上爬着一只小虫，爬了半天，只爬到砖缝里。我忽然有点羡慕它。至少它知道自己要往哪儿去。

我回屋时，电脑屏幕因为太久没动黑了。我碰了一下鼠标，屏幕亮起来。QQ 头像们排在左边，一个也没动。

赵一鸣先给我发消息：

怎么样，沈安晴加你没？

我回：

还没。

他回了一个捶桌子的表情：

你别一直盯着，盯也盯不来。

我打：

我没盯。

发出去后，我觉得自己这话一点可信度都没有。

赵一鸣回：

你现在肯定坐得像考试监考。

我没再理他。

等到八点前，我点进自己的 QQ 空间，把前一天写的说说删掉。那条说说只有一句：“终于考完。”下面赵一鸣评论：终于可以做人了。那句话太吵，沈安晴要是点进来，会不会觉得我幼稚？我又看头像，嫌太普通；看昵称，嫌太装；看个性签名，更不行。

我的签名是高二时写的：

把月亮装进口袋。

我盯着这七个字，越看越想把当年的自己打一顿。最后改成了空白。改完又后悔，空白显得更刻意。于是又写了一句：

考完了。

这句也笨。可笨得安全。

我把空间相册翻了一遍，删掉两张赵一鸣偷拍我睡觉的照片。那一刻，我像一个临时打扫房间的人。客人还没说要来，我已经把桌上的乱纸塞进抽屉。

晚上八点二十三分，电脑右下角跳出提示。

有人请求添加你为好友。

我差点把鼠标碰掉。

昵称是一串很普通的字母，头像是一片蓝色天空。验证消息写着：

你好，我是沈安晴。

我盯着那行字看了很久。

明明只有几个字，却像一封很长的信。你好。不是在教室里，不是在考点外，不是在翠湖边。是从她家里的某台电脑，穿过电话线和夏夜，来到我的屏幕上。

我点了同意。

聊天窗口跳出来。

那个窗口很小，边框是蓝色的。上面显示她的昵称，旁边有一片天空。输入框空着，光标一闪一闪。我把手放在键盘上，按下去又删掉。

你好？太傻。

到了吗？废话。

你吃饭了吗？像亲戚。

谢谢你写同学录？太正式。

我把一行行字打出来，又一行行删掉。主机风扇在脚边响，窗外有人骑摩托经过，声音从远到近，又从近到远。母亲在厨房洗碗，瓷碗碰在一起。我坐在这些声音里，像坐在一个很大的等待里。

最后是她先发来一句：

到家了吗？

我立刻回：

到了。

回完觉得太冷，又补：

你呢？

她说：

也到了。刚吃完饭。

她又说，她家电脑放在客厅，桌子靠着电视柜。她爸爸在看新闻，声音开得很大，主持人的普通话从她那边的生活里隔着屏幕漏过来。她妈妈在收碗，表妹坐在旁边写暑假作业，一会儿问一道除法，一会儿问一个生字。沈安晴说她只能趁大家都忙时打一会儿字，不能坐太久。

我看着那几行字，忽然把她家想象出来一点。不是教室第二排，不是翠湖长椅，也不是我心里干干净净的一张纸。是一个有电视声、有碗筷声、有小孩写作业的客厅。她坐在那里，背后是家里人的日子，膝盖边也许放着拖鞋，桌上也许还有没擦干的水印。

我看着这几行字，心里有一种不真实的安稳。她在屏幕那头。我们不用对视，不用听见彼此声音，不用担心楼道里有人经过。字把距离隔开，也把距离接上。

我问：

你家里人问考试了吗？

她回：

问了。我说还行。

我笑了。

原来大家都会说还行。

我打：

我也是。

她发了一个笑脸。

那是系统自带的笑脸，黄色，眼睛弯着。很土。可我把它看了好几秒。

赵一鸣的窗口又闪：

加了没？

我回：

加了。

他回了一串感叹号，又发：

别上来就写八百字情书。

我把他的窗口最小化。

沈安晴问：

你同学录看完了吗？

我说：

看了。

她说：

我字写得有点乱。

我说：

不乱。

她停了一会儿，又发来：

我本来想写多一点，后来旁边有人催着交。

我问：

你想写什么？

她回：

忘了。

我盯着“忘了”两个字，不知道该信还是不信。她的忘了和我的不敢问，隔着一块薄玻璃。客厅里有人走动，她也许把聊天窗口缩小过，也许听见妈妈喊她帮忙，也许只是看着输入框，把一行字删掉。原来不只我会删字。这个发现让我有点安稳，又有点难过。

她过了一会儿回：

那就好。

聊天很慢。每一句之间都隔着几分钟。她在家里帮忙，在想怎么回，或者只是网卡。那时候的我没有这种成熟判断。她停三分钟，我就把三分钟想成三十种答案。

我打：

你说我写诗，是谁告诉你的？

发出去前，我又删了。

太急。

我改成：

你怎么知道我写诗？

这次发出去了。

屏幕那头安静了一会儿。

她回：

语文课上老师念过你的作文。还有赵一鸣说过，你总在本子上写东西。

我看着这句话，心里骂赵一鸣，也感谢赵一鸣。

她又发：

我还看见过你在课本边上写句子。

我愣住。

我以为自己很会藏。上课时把书立起来，写完马上划掉。可原来那些小动作也会被人看见。暗恋不是一个人的密室，有时候门缝比自己想的宽。

我问：

你看见什么了？

她说：

没看清。

过了几秒，又补：

只看见你划得很快。

我松了一口气，又有点失落。人就是矛盾。怕她看清，又怕她一点也没看清。

九点多，她说要去洗澡。

我回：

好。

她说：

晚点聊。

晚点。

这两个字让我坐在电脑前又等了一个小时。母亲催我睡觉，我说再等一下。她说你都考完了还熬什么。我说同学找我。她问男同学女同学。我说赵一鸣。撒谎撒得很顺。

十点四十，沈安晴的头像亮了一下。

她说：

刚洗完。

我说：

嗯。

然后又不知道说什么。

她问：

你今天在学校说的话，是想了很久吗？

我手停住。

屋里只有主机风扇声。窗外有虫鸣，密密麻麻地铺在夏夜里。父亲在隔壁咳嗽了一声，床板响了一下。我的手指落在键盘上，像落在一张很薄的冰面。

我打：

想了三年。

发出去后，我后悔了。

太重。

可已经发了。

屏幕那头很久没有动。她的头像亮着，聊天窗口空着。我盯着光标，心一点点沉下去。就在我准备打“你别有压力”的时候，她回了。

她说：

我不知道该怎么接这句话。

屏幕亮着。

她又发：

但我看见了。

我问：

看见什么？

她说：

你这三年。

我坐在电脑前，突然不知道怎么呼吸。

那些早到的早晨，饮水机旁的一秒，被窝里的手电筒，成绩单上的名字，没递出去的风油精，灰色同学录。它们没有全白费。至少有一点，被她看见了。

我不知道该怎么回，手指在键盘上停了很久。

在那之前，我总把“被看见”想得太直。她知道我喜欢她，知道我努力，知道我受过多少委屈，我就会好一点。可当她真的说“我看见了”，我心里反而空出来一块。被看见之后，下一步不是一定被喜欢。她可以看见，也可以不选择。这个道理像一盆凉水，泼得很准。

我回：

谢谢。

这两个字很笨。

可我只会写这个。

她说：

不用谢。其实我也不知道自己看见得对不对。

我盯着这句话。

她没有把我的三年收下。她只是承认自己看见了。这一点很重要。可那时的我没有完全懂。我只觉得心里热，热到想把所有话都倒出去。

我打了一大段：

我从高一就喜欢你，可能是开学那天，也可能是你第一次在窗边坐下。我写过很多东西，但都没敢给你。我知道这样可能会让你有压力……

这一段写完，手指停在回车键上。

赵一鸣的话突然跳出来：别上来就写八百字情书。

我把那一段全删了。

然后发：

我知道。

沈安晴回：

我不是不愿意和你说话。

我说：

我知道。

她说：

但你不要把这件事想得太快。

我说：

好。

她问：

你真的好？

我看着屏幕，笑了一下。

我打：

不太好，但我会装得挺好。

她发了一个笑脸。

那晚我们聊到十一点多。

后面的话很普通。她说明天要去外婆家，我说我要帮家里收麦。她说县城新开了一家奶茶店，叶蓁想去，我说赵一鸣肯定只会点最便宜的。她问我喜欢哪首诗，我说辛弃疾那句“少年不识愁滋味”，她回：

你现在也没多老。

我说：

但我已经很会愁了。

她回：

那你以后写点不愁的。

我问：

你想看？

她过了一会儿说：

可以看。

这三个字让我差点把键盘敲出声。

我打开文档，想把刚才那句“把月亮装进口袋”改成一首能见人的诗。写了两行，又全删掉。越想给她看，越写不出来。屏幕白得刺眼，光标一闪一闪，像在催命。

屋外有人挑着水从巷子里经过，扁担压在肩上，木桶晃出水声。院子里的狗叫了两声，又被父亲呵住。夏夜不是安静的，它有太多小声音。可我坐在旧电脑前，觉得那些声音都退到了很远的地方。真正近的是聊天窗口里那片蓝色天空。

沈安晴发来：

你是不是又去写了？

我回：

没有。

她说：

那你刚才很久没回。

我盯着这句话，突然有一种被抓包的窘迫。以前我以为网上聊天能藏住表情，后来才知道，停顿也有表情。

我说：

写了一点，太难看，删了。

她回：

删太快就更写不好。

我问：

你也写东西吗？

她说：

不算写。偶尔抄词。

我问：

抄什么？

她过了很久，发来一句：

去年元夜时，花市灯如昼。

我看着那句词，心里像被什么碰了一下。那是欧阳修的《生查子》。下一句我当然知道，可我没有打出来。月上柳梢头，人约黄昏后。太明白的句子，在那晚不适合发。我们谁都没有把后半句说出来。

十一点二十，她说：

先睡吧，明天再聊。

我说：

好，晚安。

她回：

晚安。

我没有立刻关电脑。

我把聊天记录往上翻，从“你好，我是沈安晴”看到“晚安”。看了三遍。最后截图保存，文件名乱打了一串数字，藏进 D 盘一个叫“资料”的文件夹。那个文件夹里原本放着作文素材和下载的歌。现在多了一张截图，我觉得它比整个文件夹都重要。

关机时，屋里一下子暗下来。

我坐在黑暗里，想起翠湖边她说的话。

现在不是有 QQ 吗？

原来有些靠近，不是走过去。

是一个头像亮起来。

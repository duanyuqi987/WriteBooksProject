# 第六百四十七章 从不骄傲

炼虚巅峰之后，林牧和苏晚做了一件让整个修仙界意外的事——他们依然每天早上煮粥、扫地、去学院讲课。没有搬去灵气更浓的仙山，没有在宗门大会上摆出"最强修士"的架势。他们继续住在那座院子里，桂花树下的小板凳上依然时不时坐着来讨茶喝的散修。

有人问林牧：你们都炼虚巅峰了，为什么不去找一座名山大川做你们的道场？林牧的回答很简短："道场是心里的东西。院子够大——装得下二十一世纪以来修仙界所有的改变。"

华山的一个年轻弟子在分享会上说了一句后来广为流传的话："他们从不骄傲——因为他们知道他们有多不完美。这种不完美没有妨碍他们成为最强者——也没有妨碍他们成为最温暖的人。"苏晚听到后笑了一下，然后在分享会记录本上默默写了一句："骄傲是因为忘了自己是怎么爬起来的。我没有忘——我每次站起来的时候都看见他在旁边扶着我。"

太湖工地上，林牧每天都会在飞升之门的建造现场待上至少两个时辰。不是监工——是亲自上阵。他的手还是那双写代码的手，但刻起符文来精准无比。他从不以总设计师的身份指使别人——他只在别人遇到了推演瓶颈时走过去，站在一旁看一会儿，然后轻轻指一个方向。当一个筑基期的年轻刻纹师因为紧张犯了错——把通道壁上的一组吸热符文刻歪了一毫米——林牧没有训她。他只是蹲下来，指着那个歪掉的部分说："这里偏了一毫米。但偏的方向是一个偶然的角度——你从这个角度再过去的六组符文会因为你的这个偏移获得额外的散热面积。你应该保留这个偏移——不是修正它。"那个筑基期女修差点哭出来——不是因为害怕林牧批评她，是因为她的"错误"被林牧看见了正面价值。

张道玄在远处看到了这一幕。他后来对秦无夜感慨道："这个人以前在青云宗最出名的一件事是——因为一个师弟的剑招偏差了一度，当面让他重新练了一百次基本势。现在他用偏差来改进设计。不是他的记忆力衰退了——是他的心里有了空间。"

（第六百四十七章 完）

# 第685章 生命的奇迹

纪念馆的工程告一段落。

李长生回到新纪元的虚空中心，开始进行另一项工作——让新纪元的万物开始进化。

太初给了他"播种者"的权限。这个权限的含义很清晰：他可以决定新纪元的生命将从何处开始、以何种方式起步。

这不是一个轻松的决定。

经历过旧纪元一千二百个文明的兴衰，李长生意识到一个残酷的事实：文明的基础条件，基本决定了这个文明的未来上限和潜在缺陷。给得太好，文明会软；给得太糟，文明会野蛮；路径给得一清二楚，文明会失去创造力；完全不给路径，文明可能永远走不出黑暗时代。

他在纪念馆学到的那些教训，此刻一一在脑中回响。

最终他做出了选择：用最自然的方式播种。

李长生的掌心浮出一滴液体——那是由纯粹的混沌之力凝聚而成的"本源之液"。他轻轻一弹，这一滴液体化作了亿万个微小的粒子，向新纪元的每一个角落飞去。

这些粒子不是传统的"种子"。它们不带任何文明的蓝图，不带任何进化的方向，不带任何加速器。它们只携带一种信息——"可以开始了"。

也就是说，新纪元所有的生命演化将由物质自身完成。物理法则和化学规律已经就位，剩余的交给时间和概率。他李长生不做设计——他只做启动。

这是他从旧纪元的教训中得出的最重要结论：太多文明毁于外力干预。太虚仙朝因为有高阶修士强行改变低阶世界的灵气分布，导致了数十个弱小星球的文明灭绝。无限科学院因为在别人的原始星系强行铺设科技框架，把七个尚未诞生的文明扼杀在了萌芽状态。

生命需要被尊重，而最根本的尊重就是不要替它们决定该怎么活。

做完这个决定，李长生开始了漫长的观察。

新纪元的光点开始自行演化。第一代恒星点燃了自己，核聚变的火光穿透了星云。第二批物质在引力作用下聚拢、碰撞、分裂、重组，最终形成了第一批行星——岩石质的、气态的、液态的、混合态的，形态各异，各自围绕着各自的恒星旋转。

在那些适宜的行星上——温度合适、有液态溶剂、有足够的物质多样性——最初的有机分子开始出现。不是李长生安排的，是物质自身在新的法则框架下自然组合的结果。

他看到了四个星系率先进入生命演化阶段。其中一个星系最年轻也最活跃，星系中央是一颗年轻的黄矮星，周围有八颗行星。第三颗行星——距离恒星不远不近，温度恰好——表面覆盖着液态水构成的海洋。

李长生停了下来。他认出了这个星系。那是新纪元的太阳系。那颗第三行星，是新纪元的地球胚胎。

他不知道这是巧合还是太初的默许。但不管怎样——在旧纪元，地球是人类文明的开端；在新纪元，它又一次成为了生命的摇篮。

新的地球在海洋中酝酿着最初的微生命。那些微小的细胞——太简单了，甚至不如旧纪元的一粒灰尘——正安静地分裂着。它们的演化路径还很漫长，要走上数十亿年才能出现复杂生命。但李长生并不着急。

混沌之主拥有的正是这种资格——看一条河流如何从第一滴水生成到汇入大海。他有的是时间。新纪元有的是时间。最重要的不是快，而是走稳。

他选择了不干预。

连给新地球的任何"提示"都不留。新的生命，走全新的路。旧纪元的一切——英雄、帝国、战争、和平——只保存在纪念馆里，不会成为新生命的枷锁。

这，才是真正的重启。

（第685章完）

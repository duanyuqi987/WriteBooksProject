# 第三百七十八章 她的第五世

从天山矿脉出来后，苏晚忽然提出要绕道去看看当年第五世生活的旧地。矿脉南麓往下的山谷中五世时她独居过。那世她是个采药女——一人住在半山腰上一间石屋里，靠采当归和雪莲为生。石屋过了几百年已经只剩半堵墙和腐朽的木质梁头。但墙角的旧火坑还在——几块烧黑的石头堆在原地，上有残留极淡的金灵痕迹——那是当年林牧将那株千年灵芝煮给她补身子用的火坑。

她在火坑边蹲下来——用剑尖撬起一块极小的黑石头——背面贴着一点早已枯萎的灵芝残屑。她把石头放进药箱里——说:"这一世你用灵芝给我续命——结果你自己的旧剑磕口仍在那石坑边撞了一下——和茶楼的战士杯缺口一样曲线。"

林牧没答这话——他正蹲在距石屋不远的后坡——看到一棵和她当年种的那片当归早已野化的后代。已经不再是药田状态——但根系比这五百年还强韧。他用手指捻一片叶——闻了闻——当归味道还很正。他把一小把种子收进储物袋说:"回去种。在蜀山后山。"

她站在旧火坑边静静点点头。风把山谷里老当归的香气吹到她短发上——和这几百年来无数次梦里一样。但这次没有人需要续命。没有人重伤。只有两个修士带着剑和空种子袋来收药材。她说:"走吧。以后在山那边可以自己种。"

"那这石屋还要不要留标记？"

她拿起流光剑在残墙上极轻地刻下两个字——"还旧"。不是对古物——是对旧地。是让后来路过的人知道：四百多年前曾有人在此等过一段很漫长的回暖。

# 第834章 万年祭

万年祭的午夜时分。地球标准时间零时。

整个李家庄静了下来。不是人散了——人群还在，但所有人都停了说话。因为那个时刻到了：面向混沌深空方向的安静片刻。

没有人领头。没有人倒计时。但在准点的那一刻，从地球到最遥远的边驿星系，所有参与万年祭的人同时转向了同一个方向——天球上那个幽蓝色的位置。那里没有什么可见的星，但所有人都知道那是哪里。因为一万年来，每一份混沌通信信号的发送和接收都指向那个位置。它没有名字，但普通人管它叫"那盏灯"——因为所有雷达都探测不到它的位置，但所有灵长生命用肉眼去看，总会隐约觉得那里有一点点不同。不是光，是暖。

安静的时间不长——有人只站了三息，有人站了一炷香。没有统一计时。各凭各的心意。安静结束后，没有人鼓掌。只是有人重新坐下，有人开始收拾带来的容器。声音是渐渐地回来的——像是潮水退去之后，沙滩上开始重新有了风声。

但发生了一件事。

在李家庄那尊蹲着雕像的正上方，距离地面大约三十丈的半空中，忽然亮起了两道光。光很淡，不是强光——像是两盏极远的灯被人轻轻举起来，转了方向，刚好照到地上。光没有发出任何灵力震动，没有被任何仪器捕捉（事后所有监测站的回放记录全是空白——无衍射、无吸收、无可读编码数据;但现场所有人用眼睛看到的记录高度一致）。但每一个在场的人都看到了。

那不是神通降临的华彩。那是两个人的光。一个人光的颜色偏土黄——像秋日午后晒在麦垛上的那种暖黄色。另一个人光的颜色偏青——像黎明之前的山顶天空，冷净而有边缘。两道淡光在半空中安静地悬浮了十息。然后缓缓向下沉降，降到大约离地面一丈高，光中隐约浮现出两个人的轮廓。面目看不清楚，但身形很清楚——一个中等身材的男人，穿着旧衬衫，脚上是解放鞋。一个女人，背着一柄长剑，头发被风吹得微乱。她的手放在他的手肘上。半静止，像黄昏时村道边有人替另一个人拍掉袖口上的碎叶。没有声音，没有动作。就是静静地站在光里，看着下面的一切。

那是李长生和陈霜。

一万年后，他们在万年祭的午夜，短暂地回到了他们的出发地。

全场没有声音。不是因为震惊——是因为没有人知道该怎么反应。他们想象过一万次"冥王现身"的场景，但谁也没想过是这种——不是王座上的不可一世，不是天穹上破空而来的威严。只是一个农民和握着他手臂的妻子，站在暮光里，静静看着底下那些替他热饭的人。

光中的两个人没有讲话。但每一个在场的人都感觉到了某种直接的信息——不是语言，不是意识投射，而是一种很安静的情绪。像有人在你脑后用你很熟的人的声音轻轻说了一句话。然后是第二句。然后是第三句。

"我们很好。"

"你们没有让我们白守。"

"继续前进。"

三道信息说完之后，光开始缓缓上升。升到半空的位置，轻轻闪了两下。然后消失。什么都没留下。空气还是那个温度。鸟还在林子里叫。油灯的火头还在晃。但大地上所有的人都知道了那盏油灯是什么意思——不是照他们。是在替所有人确认：灯还在。

事后有无数人试图描述那一刻。但所有的描述都指向了相似的东西：不是震撼，是安定。像出远门的孩子终于收到了父母的消息，消息的内容不是"回来"——是"放心"。像你种了一季庄稼，最后一天黄昏，你爸走到田埂上，看了一眼，说——行。

一个来自边驿的小女孩跟她母亲说："我看到那个叔叔了。他手里的灯油没加满，他走之前把灯留在村口的石板上了。"她妈问："你怎么知道是灯油？"她说："因为他走路的声音特别轻——像怕泼了油。他不吵。他也不想被吵。"她当晚画了一幅画——两盏光线，一盏黄的，一盏青的，中间一片空着的石板。

后来这副画被收藏在月球学城的综合信息校庭一间很普通的文教展室里。标题栏里只填了一个词："家信"。署名是"边驿诸童"。

（第834章完）

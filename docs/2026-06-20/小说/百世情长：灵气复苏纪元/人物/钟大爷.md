# 钟大爷

## 基本信息

| 项 | 内容 |
|---|------|
| 身份 | 被宗门拒三次的赤脚医生，太行书院老年学员 |
| 年龄 | 60岁 |
| 出场 | 第904-906章（第十卷前期） |
| 修炼方向 | 灵气医学（将传统中医与修仙结合） |
| 功能 | 灵气医学线代表；映照苏晚的医/教弧光 |

## 性格

- 不服老、不服输——"六十岁怎么了？六十岁就不能修仙了？"
- 倔强中带幽默——被拒三次后笑着说"事不过三，可这是第三次被拒，下次该成了吧？"
- 对医学有近乎偏执的热爱——行医三十多年，救过的人比见过的修士还多
- 务实不玄虚——别人讲"灵气运行"他讲"气血通畅"，把修仙术语翻译成中医语言
- 对年轻学员像长辈般照顾，但从不倚老卖老

## 背景

- 太行山脚下的赤脚医生，行医三十余年
- 年轻时曾三次投考宗门，均因"年纪太大、根骨定型"被拒
- 灵气复苏后，他敏锐地意识到灵气与人体经络之间存在关联
- 听说太行书院"不拒任何求学者"，背着药箱就来了

## 核心欲望

- 将中医与修仙修炼结合，开创灵气医学这一新领域
- 证明修炼不应有年龄门槛——"人的经络六十岁和十六岁一样在跳"

## 核心恐惧

- 修炼无成——不是因为自己丢脸，而是怕"年龄论"坐实，让后来所有年纪大的人再无机会
- 行医一辈子的经验在修仙世界里一文不值

## 不可逆选择

- 放弃了用灵药强行逆转身体年龄的机会——"我不要变年轻，我要让六十岁的身体修炼给你们看"
- 坚持用最传统的方式筑基，用自己当活体实验证明"年龄不是修炼的门槛"

## 声纹

- 说话带老派医生的温和与笃定
- 喜欢用中医术语形容修炼——"你这不是灵气堵塞，是肝火旺盛"
- 对自己的年龄毫不避讳，经常用来自嘲——"你们这群小伙子，还没我这个老头子扛得住"
- 看病时严肃专业，其他时候随和爱笑

## 关键台词

- "六十岁怎么了？六十岁就不能修仙了？"
- "人的经络，六十岁和十六岁一样在跳。"
- "宗门不要我，太行书院要我。我是不会走的。"
- "我不是来修仙的，我是来把修仙变成一门医学的。"

## 关键场景

- **第906章入学**：在太行书院入学测试中，钟大爷以六十岁高龄参加测试。当考官迟疑时，他反问："你们书院的规矩里有年龄限制这一条吗？没有？那就让我试试。"

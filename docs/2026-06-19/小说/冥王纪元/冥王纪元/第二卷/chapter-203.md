# 第203章 番外八：地质工程师老马发现地球灵脉地图

老马全名叫马建国，今年五十二岁。在灵气复苏之前，他在省地质勘探队干了二十七年。他的工作是看石头——不是收藏那种看，是把石头切开、磨片、放在显微镜下看晶格结构的看。二十七年里，他看过的岩石薄片少说有四千块。他能从一块岩石的晶格排列中判断出这片地层是几亿年前的海底还是火山口。

灵气复苏那天，他正在秦岭深处的一个勘探点上采样。

那天的工作很简单——在秦岭北坡的第三纪花岗岩岩基上打三个钻孔取岩芯。钻机轰鸣着往下钻的时候，老马蹲在旁边吃馒头。馒头是早上从营地带的，已经凉透了。他咬了一口，抬头看了看天。

天裂了。金光涌出来。

他的第一反应不是害怕。是困惑——因为他脚下的岩石在震动。不是地震。震动是往上走的——从地底深处往上传。他把手按在岩石面上。掌心传来了一种他二十七年从未感受过的感觉:岩石在发烫。不是被太阳晒的物理温度——是某种从晶格内部散出来的热量。像整片山体都在低烧。

"老马！钻机停了！"助手喊。

钻机确实停了。不是柴油机熄火——是钻杆卡住了。不是卡在裂隙里——钻杆下方传来的阻力不像是物理层面的硬物。更像是一种应力场。看不见摸不着，但钻头一转进去就会被某种力量弹回来。

老马把最后一口馒头咽下去，走到钻孔旁。他把手伸进钻孔里——手指触碰孔底的泥浆。泥浆很凉，和岩石的温度相反。他把泥浆抹在掌心上，凑近鼻子闻了一下。

然后他知道出大事了。

泥浆里有灵气。极微量的、通过岩石中某种微孔隙渗透出来的灵气。那气味不腥、不臭——是一种矿物和某种活性能量混合的、从未被地质学描述过的物质。

老马把泥浆装进采样瓶。瓶子编号:QL-0173。秦岭-北坡-第三纪花岗岩-地下灵气渗出样本-001。

这是他未来三年里采集的第一万两千三百七十一个样本中的第一个。

第一个月。老马带着他的地质队沿着秦岭山脉从西向东走了一趟。他的工具不是灵盘——那时候还没有灵素标准。他用的是自己改装的岩石孔隙度测定仪:把原来的气体渗透仪拆了，在探头上加装了一个灵敏感应片——用他在灵石矿脉附近捡到的灵石边角料磨的。探头插入岩层后，能感知到岩层孔隙中是否存在灵气的残留。

他发现了一条规律:灵脉的分布和地质断裂带的走向高度重合。

秦岭-大别山断裂带。山西地堑系。郯庐断裂带。龙门山断裂带。每一条大地震留下的断裂带，两侧的岩层中都浸透着灵气。浓度最高的位置往往是在断裂带和深大断裂的交汇处——那里是地幔物质上涌的最佳通道，也是灵脉从地壳深处向上渗透的点位。

"老马，你画的这个——"助手有天晚上看着他在笔记本电脑上标注的地图，瞪大了眼睛，"这条灵脉带刚好穿过长安城。往下就是兵马俑——"

"兵马俑在地下。"老马说，"地下就是灵脉的交汇处。当年秦始皇选这个位置建陵——他不一定知道灵脉是什么。但望气术能让他看到地脉的气场分布。他把陵墓建在了灵脉最密集的点上。"

"灵气能防腐？"

"目前不知道。但有一点可以确定——从长安到洛阳，沿着这条东西向的灵脉带，历史上建了十二个都城。周、秦、汉、唐，全在这条带上。不是巧合。"

第二个月，他把采样范围扩到了整个中国东部。从秦岭下了大巴山，从大巴山进了武陵山。从武陵山翻过了南岭。他越走越发现——灵脉的分布不仅是地质问题，也是历史问题。

华山、泰山、衡山、恒山、嵩山——五岳的山体内部都有一个巨大的灵脉节点。不是山腰的某个洞穴，是山根底下几千米深的基岩中，有一团密度极高的灵气团。这些灵气团的形状不是球形的，是沿着山体内部断裂带向上延伸的直立带状——像一根从地幔伸上来的经脉。五岳各自占据了一条主灵脉的核心节点。

"五岳不是古人随便选的。"老马在野外笔记本上写道，"五岳是五条主干灵脉的地表出口。古人用'岳'来标记大地灵气的节点位置。他们的地质学知识——不是科学，是望气术加经验。但结论是对的。五岳是地球灵脉系统的主干枢纽。"

第三个月，他申请调往青藏高原。

单位说他年纪大了，高原有风险。他说我去。单位说经费不够。他说我自己出。他把二十七年攒的积蓄拿了三分之一出来——买了高原装备，包了一辆越野车，雇了一个藏族向导。

青藏高原是地球地质学上最特别的地方——印度板块和欧亚板块的碰撞带，地壳厚度是普通地区的两倍，深大断裂从地表直通地幔。老马在这里发现了全球最大的灵脉群。

昆仑山脉——整条山脉底下就是一条主灵脉带。从昆仑山口往西一直延伸到帕米尔高原。灵脉在西段分成两支——一支往南穿过喜马拉雅山脉进入印度板块，一支往北穿过天山进入中亚。

"难怪。"老马站在昆仑山口，狂风把他的帽子刮飞了三回。"难怪昆仑山是所有修仙小说里的圣地。不是作者在编——是古人真的有记载。这条灵脉的浓度——整个地球没有第二个地方能比。"

他在昆仑山脉找到了灵气的源头——地幔过渡带。在距地表四百一十公里的地幔深处，有一层矿物相变带。灵气就储存在这层相变带中。万年前冥王陨落时，他的力量被打散后没有消散——而是沉入了地壳和地幔之中。地幔过渡带的矿物晶格在亿万度高温高压下，可以把灵气分子"关"在晶格缺陷里。当八门诛仙阵被解除、灵气封印破裂时，这些被关了万年的灵气通过地幔柱和深大断裂向上渗入地壳，再从地壳的孔隙和裂隙中扩散到地表。

这就是灵气复苏的地质学解释。

没有神通。没有神迹。灵气不是什么天外来物——它一直在地底。只是被封住了。

第四个月。老马回到城里，把自己关了整整一周。他的电脑上打开了三十七个窗口——地质断层数据、灵素浓度监测站数据、灵脉钻探样本分析、古代都城分布图、古代战场遗址分布图、道教洞天福地分布图。他把这些全部叠在一张全国地图上。

地图上出现了三十二条主线。每一条线都是一条灵脉带——从西到东、从北到南，像人体的经络一样覆盖了整个国土。

主线之间有支线相连。支线交叉的地方形成了灵脉节点——灵气浓度最高、最适合修炼的地点。这些节点中，最大的几个依次是:昆仑山脉(全球最强灵脉)、秦岭-大巴山交汇带、长白山天池、台湾玉山、太行山东西侧、横断山脉三江并流区。

他把这张图画了出来——手绘在一张A0大小的白纸上。灵脉是蓝线，节点是红圈，断裂带是黑色虚线，都城遗址是绿色的三角形。

画完之后他退后一步看了一眼——然后倒吸了一口凉气。

长城。

长城的位置——从山海关到嘉峪关——几乎和一条次级灵脉带完全重合。

"秦始皇修长城，选这条线——不是随便选的。"老马在笔记本上写。他的手在抖。"中原文明和北方游牧文明的交锋线——恰好也是一条灵脉带。这条灵脉带从蒙古高原延伸到华北平原，长城就修在这条灵脉的地表投影上。他在用长城堵住的不只是人——是灵气。北方草原的灵脉和中原的灵脉是两条不同的体系。长城修在了两条体系的交界线上——既是军事防线，也是灵脉防火墙。"

这个发现后来改变了很多人的认知。

但老马没有停下来发论文。他把图纸卷起来，背在背上，继续往下一座山走。

第八个月。他到了东海——准确地说，是东海大陆架上的一座新出现的岛屿。那是灵气复苏之后从海底升上来的——蓬莱遗址的一部分。他在岛上的岩层中发现了海底灵脉的露头。海底灵脉和陆地灵脉完全不是一回事:它们更密、更宽、灵气中含的水属性比例远超陆地上任何一条灵脉。但更有趣的是——海底灵脉和陆地灵脉是连着的。在东海大陆架的地壳深处，海底灵脉通过几道深大断裂和陆地上的灵脉带联通。

老马潜到水下，在岛基岩壁上钻了三个孔。水下的能见度很差，灯光只能照出两米远。他把采样管插进孔里的时候，忽然感觉手指被什么东西烫了一下。

不是水温。是岩石里的灵气浓度高到可以通过他的手指直接传上来。

他浮出水面的时候说了一句话。随行的人没听清。他又说了一遍。

"地球是活的。"

"你说什么？"

"地球——整颗地球——它的灵脉系统是活的。不是物理意义上活着。是它构成了一个完整的、自我循环的能量传输网络。灵气从地幔过渡带上涌到地壳，沿着断裂带组成的灵脉网络流向全球，在灵脉节点汇聚成灵气团——然后从节点通过修士的修炼、植物的光合作用、微生物的灵素代谢——散回大气中。从空气沉入地下水，从地下水渗入岩石，从岩石顺着俯冲带重新进入地幔。一个完整的能量循环——和碳循环、氮循环一样，是地球的一个基础循环系统。只不过这个循环被封了一万年。现在它重新启动了。"

没有人回答他。海浪拍打礁石的声音盖过了他的话。

第十二个月。老马完成了第一版《地球灵脉分布图》。不是中国灵脉图——是全球灵脉图。他用卫星遥感、地震波层析成像、全球灵素监测站数据、以及他自己的野外采样记录，绘制出了全球灵脉网络的骨架。

结果显示:全球有五条主要的灵脉带。中国占据了其中两条——昆仑-喜马拉雅系和秦岭-东亚沿海系。另外三条分别在安第斯山脉、东非大裂谷和北美洲的落基山脉。

"所以这四个地方——古代都产生过独立的高级文明。"老马在一次内部汇报会上说，"不是巧合。灵脉集中的地方，灵气浓度高。灵气浓度高的地方，觉醒灵根的人多。灵根觉醒的人多，就会形成一个修仙文明。中国、安第斯、东非、落基山——每个地方都有一条主灵脉带。这四条灵脉带就是地球古代四大修仙文明的发源地。只是除了中国，其他三个后来都断了。"

"为什么断了？"有人问。

"因为没有冥王。"老马说。他的语气不是玩笑。"万年前冥王在地球上的统治——把他的灵脉系统烙印在了地球上。他陨落之后，那些烙印留在了中国的地质结构中。全球五条灵脉带，只有中国的两条上刻着冥纹阵法。那是冥王留下的遗产——他死之前，把地球变成了一个灵脉系统的主节点。"

会议结束后，老马把那张A0大小的原稿装裱了起来。不是挂墙上——是折叠好放进了一个防水筒里。他说这不是成品。这只是初稿。地下还有太多他没探测到的灵脉。

"等到了其他星球，"他说，"我还要画一张太阳系灵脉图。"

他看着窗外。

"看能不能画出来。"

没有人知道他这个愿望将在第三卷实现——他将成为人类历史上第一个在月球和火星上绘制灵脉分布图的地质学家。

但他此刻还不知道。此刻他只是在笔记本上写下了下一站目的地:月球背面。预计灵脉类型:未知。预计灵气浓度:未知。预计地质结构:斜长岩高地与玄武岩月海。携带设备:改良型灵石孔隙度测定仪-航天特制版。

他合上笔记本，把烟掐灭。窗外天工基地的人造星空还在亮着。

三天后试飞。

（第203章完）

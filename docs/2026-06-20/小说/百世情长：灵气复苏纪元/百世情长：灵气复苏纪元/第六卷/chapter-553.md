# 第五百五十三章 第三关——幻影

第二关结束后两人在考场的休息室短暂地见了面。苏晚的灵核还残余着天雷的痛感。她把琴弦轻轻拨了一个低音——用琴声给两个人各自的灵核稍稍涂抹了一层低频镇静波。林牧的右肩衣服被代偿天雷时的冲击力给撕开了一道口子——露出下面皮肤上那片他在丹炉前烧过的老伤疤。苏晚用手指摸了一下那块疤。然后她把琴放回琴盒中，站起来走向第三关考场。

第三关——太虚幻境——在塔的最高层，第近百层。幻境的门是一面极薄极透明的空间薄膜，薄膜对面是一片被幻境法则支配的虚幻世界。进入之后两人将被各自置入一座独立的仿真人生——在里面他将看到"完美的苏晚"，她将看到"完美的林牧"。两人都不知道自己是什么时候进入幻境的——也不会有任何已知的"这是试炼"的意识提醒。这关的较量开始于意识深处你自己都意识不到对方可能在骗你的时刻。

苏晚踏进幻境。她发现自己站在一座极熟悉极熟悉的石桥上。这是第一世的石桥。桥栏的石头纹理和她封印全开后看到的记忆一模一样。桥下还是那条小河。风里是春末的空气味——混着河畔柳树刚抽穗的清香。一只绣盒从桥上掉落，落入水中——和记忆完全一致。她比任何时候都清楚：后面会有一个叫"阿木"的年轻木匠从桥上跳下去帮她捡上来。但她心里有一张数据表在无声地全速运转——检查项目一：绣盒入水的声音——匹配——这是记忆。检查项目二：他爬上来的动作——姿势对——右手先撑上岸。检查项目三也是最后一项也是唯一能判定真伪的一项——他说的第一句话。"以后走路小心。"这是原句。但她听到的却是——"以后走路要小心呀——别弄坏绣盒。"多了一个"呀"和三字的后半句。不是他。不是阿木。苏晚在不到一息之内从石桥侧身退了一步，冷冷地说:"你不是来捡绣盒的。你是来装成他的。"幻境的画面在她拒绝的一瞬崩塌成碎片。第一个人生——被她在第一次对话前就拒绝了。

第二个人生——是第五十三世豆腐摊。苏晚掀开蒸笼时热雾升腾——对面豆腐干的摊子还在。卖豆腐干的中年男人朝她这边挪了半过。他说:"早上好——今天豆花是不是又没放糖？"这句话前一半对——"早上好"他常说的。"豆花又没放糖"——这句也对。但她低头看着自己摊面的台面，发现他的摊沿这次没有留下挪过的痕迹——每天早上他会在自己木板上用无名指顺带划过推板印——在挪摊时残留的白灰痕。这道痕在幻影中不存在。"你不是他。你是一面没疤的镜——我不能看镜中的自己代替他。"

接连拒绝多个幻境之后，最后也是唯一一个让她多愣了一瞬的幻境出现了。不是豆腐摊也不是石桥——是一个极其普通极日常的场景。黄昏，仙居后院，她在浇花。他站在劈柴桩旁边劈柴。没有任何台词。只有两个人在落日余晖中各自做自己的事。这个瞬间简单到极。但她在放下水壶的那一刹忽然用手碰了一下功德绳——在这个仿真人生的设定中功德绳应该是存在的。她碰到的功德绳——有金线。有木牌。有和她腕上相同的触感。但她低头一看——木牌背面是空的。他的那块旧木牌上刻的"以后"两个字，不见了。

她把这根完美的仿制功德绳从腕上摘下来放在地上。然后对着劈柴那个方向说:"很像。但你不刻字。他不说话但他的手一定会留下点什么。你不敢留。"幻境破灭。

（第五百五十三章 完）

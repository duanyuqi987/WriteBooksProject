# 第三百五十七章 同步修炼的难题

战后第三十年。两人正式开始尝试同步修炼——为将来的共生契约和化神渡劫做准备。但第一次试练就发现了一个巨大难题：他们的修炼速度不匹配。

林牧的修炼方式靠的是"地脉反哺"——松林呼吸循环，适合长时间平均增长。苏晚的修炼方式靠的是"灵魂解封"带来的阶段性跳跃——每天可能增长极少，但几天后封印忽然松动，灵力就狂涨一大截。这两种模式几乎是互补但不能同步的。

两人花了几个月分析终于找到突破点：苏晚可以故意推迟封印解封——用她悟出的"针剑引"将封印松出的多余本源暂时冻结在经脉周围的特定区块里。等到林牧的地脉反哺累积到等同量时——再一起释放。这本质上是把两人的修为增长变成了"节拍器模式"——始终保持同步。

这套方案的临床实践（当然苏晚用了这个词）需要在各自丹田外部加一个"暂时源储囊"——她没有，但她用针剑式在丹田旁边刺出一个微小的"灵气皮囊"——比沙粒还细——能在一天内稳步存储过量的封印解封本源。林牧惊叹不迭——说她居然用剑法做手术。她回："所以是针剑——不是刀剑。"

两个不同速度的生命在同一个节拍里跑。这是他们接下来三年天天做的事。清泉镇上的人们习惯了看他们晨昏两次出城——一次去松林，一次去灵泉——然后对坐在衙门外面的大石上同步运功。有时赵明远路过——他自会绕开而不打扰。他知道他们在做某种极艰难且孤独的事——孤独到他们的世界只有对方能懂。但在漫长坚持过后，最终差异被克服——两人首次同步引发灵力共鸣时蜀山方圆数十里的灯夜里全亮了一下。不是电——是灵气共振。清泉镇上的人纷纷探头看窗外。苏晚擦了擦额头说：成了。林牧把剑收回——他的手也有点颤——是配合到极限的那种酸。但成了。

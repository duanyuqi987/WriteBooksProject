# 第606章 废弃宇宙深处

这个废弃的平行宇宙曾经是一个繁荣的修仙文明的家园。

证据残留得不多——只在虚空中偶尔飘过几块被磨损得无法分辨的建筑物残片。它们曾经是某座冲天巨塔上的雕像的一部分——塔可能高达数万米——因为残片上的雕刻纹路精细到了纳米级，是那种只有用灵力在分子层面上逐层堆叠才能达成的精度。还有一块残片曾经是某座仙门的柱头——柱头上有一截断了的云纹——云纹的走势是"出"——是一个未完的升腾手势——好像那根柱子在被毁之前正在往上生长。另一块飘过的是一块圣地基石——基石的材质不是石头——是一种半透明的灵能结晶——已经被磨掉了所有棱角——但内部还封存着一丝极微弱的灵力余温——像一颗早就凉掉的炭核。

现在它们只是没有重量的残骸——在这个早已熄灭了星光的宇宙中——漫无目的地漂流。没有风——但它们确实在动——是被这个宇宙残余的空间张力推着——像死水潭中最后几片浮叶。

李长生和陈霜在虚空中向前推进。他们的目的地只有一个：碎片记忆所提供的最终定位——这个废弃宇宙的核心。

"这里的灵气浓度为零。"陈霜释放仙王级感知做了一次全面扫描。她的感知力覆盖的范围达到了数光年宽——但回传的信息几乎全是空白。"真空中的灵力、元素、因果链——全部都是零。连最基本的空间稳定性也在瓦解——这个宇宙的普朗克常数已经偏移了万分之零点三——再过几万年连原子核都会散架。这个宇宙已经死透了。"

"它死了不止一天。可能有几千万年了。"李长生说。他的混沌级感知能看到更深层的东西——能看到这个宇宙的"因果尸体"——一条条断裂的因果线漂浮在虚空中——每一根都曾经是一个生命的轨迹——现在全部断了——断口平整——不是自然消散——是被一次性切除的。"你看那边。"

他指向远处的星空——虽然说是星空，但这片宇宙中没有星。他看到的是一个空洞——一个曾经应该存在过恒星的区域。那里留下了一个球形空洞——非常规则——像个被挖掉的眼球。球内没有任何物质残留——连一粒原子都没有。球壁有一层薄薄的、灰白色的灰烬——那是恒星被删除后残余的因果灰——是唯一还能证明"这里曾经有光"的东西。

"那颗恒星被某个帝者级的存在从因果层面抹除了。"李长生说，"不是炸毁，不是击碎——是直接从因果线上删除。这颗恒星不仅在现在的宇宙中不存在——它从来没有存在过。只有因果删除会留下这种特殊的'存在空壳'——就像从一本书里把一整页撕掉——撕得干干净净——但装订线上的那一丝残纸还在。"

"是哪个人做的？"

"不好说。能做到这个程度的只有帝者级。但能在这个宇宙中行动的帝者——可能是联盟时代的，也可能是更古老的。"李长生顿了一下——在虚空中往前飘了几米——伸手碰了一下那片灰烬的边缘——灰烬无声地碎成了更细的粉末。"不管是谁——他做这件事的时候没有犹豫。这是个处决——不是战斗。"

他们继续前进。

越是接近宇宙核心，空间的扭曲程度越剧烈。某些区域的时间流速忽快忽慢——他们需要不时调整自身的灵力屏障来同步周围的时间流速，否则连身体内部的生理运行节律都会被扰乱。

再向前，他们碰到的不是空间扭曲——是物质分解。

宇宙核心的边缘存在一处奇异区域。这个区域内的所有物质都在持续地分解成最基础的粒子。然后又重组。然后又分解。这个过程不断循环——就像时空在这个区域被拧干了。任何一个正常物质体进入这个区域，都会被卷入这份永不休止的分解与重组循环而被彻底打散。

"混沌碎片残留。"李长生认出了这个现象的来源，"碎片自身在散发的能量，扭曲了周围的物理法则。它应该被封印了才对——但这里的封印破裂了。"

"为什么破裂？"

李长生放出一道冥气向前探去。冥气碰到了分解与重组的区域边界，然后反弹回来。

"因为封印老化——以及碎片在等我们。"

"等？"

"对。"李长生握紧了陈霜的手，"它知道自己会在今天被找到。这些扭曲现象不是伤害——它是提示。告诉我们：这里就是目标。"

他们一步踏入分解与重组的区域。冰冥之花在李长生脚下绽放，以极寒的温度强行锁定了周围空间的循环速度，将分解与重组的节奏压到了可控范围。陈霜同时释放冰冥领域——仙王级领域的规则写入能力此刻发挥了作用：她用冰冥之力在分解与重组区域中"强行写入"一条新规则——区域内的分解行为将始终落后于重组行为一个相位。这不是废除分解，而是让物质始终处于"重组快于分解"的状态中——允许两人安全通过。

穿过扭曲区域之后，他们终于到达了废弃宇宙的核心。

眼前的景象让两个人都停住了脚步——不是恐惧——是一种面对"纯粹"时本能的停顿。

核心处是一团稠密的、无法解析的黑暗。不是黑洞——黑洞有质量、有视界、有霍金辐射——这些物理量在此处全部归零。不是物质——物质有粒子、有场、有能量——这里没有。是完全的"无"——一切定义的缺失。这团黑暗不吸光——它让光在接触边缘的一瞬间失去行进的目标。进来的光尚未到达表面已经被扭曲成了静物——光斑僵在黑暗表面几米外的位置——像一层被冻住的薄雾——永远照不进去。

陈霜握紧了剑。剑在微微颤——不是因为恐惧——是她第一次感知到自己的本命剑在"无"面前产生了不确定的反应。剑灵在问她："打什么？"

"那里没有'什么'可以打。"陈霜低声回答了自己的剑——然后看了李长生一眼。

李长生没有立即靠近。他站在原地——放出冥气——不是探测——是用冥气触碰那团黑暗的表面。冥气碰到的瞬间——他收到了一种极其微弱但明确的回响——不是语言——是振动频率——是一个旋律片段。他辨识出了那个旋律——是壁画上混沌之主在沉睡中自己哼过的那段——只有六个音——但六个音全在。

而在那团黑暗的正中心——他用混沌级感知"看到"了一个微小而明亮的光点。不是白色——是一种极淡的、接近透明的暖黄——像冬天窗玻璃上结了一层薄霜后、外面有人在远处点了一盏灯。

第二块混沌碎片。

它在等——等了十亿年——不喊——不叫——只是亮着。

（第606章完）

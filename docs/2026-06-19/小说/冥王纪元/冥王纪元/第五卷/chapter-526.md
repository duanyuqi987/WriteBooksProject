# 第526章 第一次多元宇宙大战

李长生的冥王令砸在万剑台上的那一刻，整个空间都震动了。

不是比喻。是维度层面的震动——冥王法则与剑道法则在极小的空间尺度上发生了剧烈的碰撞。两种完全不同的底层规则互相碾压、挤压、撕扯。周围余波在真空里留下了一道道肉眼可见的波纹——那不是电磁波，不是引力波，是法则碎片在空间中自毁时产生的"尾迹"。

万剑王接住了这一击。

用他的三十六万柄剑影中的九万柄。九万柄剑在瞬间叠成了一面剑盾——剑刃朝外、剑柄朝内，像一朵由钢铁和剑意浇铸成的巨型菊花。冥王令砸在剑盾上，发出的不是金属撞击的声响，而是一种更深层的声音——像有人同时折断了一万根骨头。

暗金色的冲击波从撞点爆开，在零点一秒内席卷了整个剑修舰队。最靠近万剑台的八艘剑修战舰在冲击波中解体——不是被炸碎的，是被法则级能量从内部震碎了结构。舰体像被巨力撑开的花瓣一样一片片剥落，舰上的修士被抛出船舱，在太空中的无声惨叫。还好他们的剑修体质能支撑他们在真空中短暂生存。

"有意思。"万剑王站在万剑台上，低头看着面前那道在虚空中悬立的身影。李长生。黑色长衫、右手暗金光芒灼灼。这就是冥王——或者说，这就是被冥王令选中的那个农民。

"帝级巅峰——能正面压制我的剑阵。"万剑王的声音里没有恐惧，只有一种纯粹的、作为战士的兴奋。"你果然不是普通的帝级巅峰。"

李长生不语。他右手一翻，冥王令的光芒收敛到掌心，凝成一柄由纯粹冥系灵气构成的黑色直刀——不长，三尺三寸。这是他的近战习惯。他不需要剑修那种排山倒海的剑阵来打进攻，他只需要一柄足以切开一切防御的刀。冥王令本身就是最强之刃。

两道人影在万剑台上空对撞。一刀一剑。

初次交锋持续了不到三秒，但在这三秒内，他们交手了超过一千招。每一招都是帝级巅峰以上修士才能看清的速度。手边的全息投影在实时捕捉交战过程——它的帧率已经拉到了极限，但实际画面近乎一团由光芒和气浪构成的风暴。

帝国的环形防御带上，所有人都看到了这一幕。他们透过全息屏幕看着一道黑光和一道白光在虚空中交错、碰撞、分离、再碰撞。每一次碰撞都在空中炸出一圈圈法则碎片——有的呈暗金，有的呈银白。碎片飘到舰队上空时，舰体上的灵石护盾剧烈地颤抖了一下。

"退！退远一点！"老陈在指挥频道里吼，"法则碎片能穿透护盾——靠太近会被烧成灰！"

舰队有序后撤。但交战的中心位置——万剑台正上方——已经变成了一个任何帝级以下修士接近就死的高能区域。李长生的冥系法则和万剑王的剑道法则在那里反复碰撞、撕裂、重组。每碰撞一次——那一片区域的物理规则就紊乱一次。在紊乱发生的一瞬间，光速会变，引力会变，热量流动的箭头会反转。

这是两个凌驾于物理法则之上的人在打架——他们的武器不光是力量和速度，更是各自掌控的底层规则。谁先把对方的规则打碎，谁就赢。

十分钟。

他们打了整整十分钟，没有分出胜负。万剑王的剑影在持续增加——从九万柄涨到了十八万柄。每一轮攻守中他都在不断抽出新的剑影加入战斗。他的剑道法则让他的每一柄剑都是活的——被击落的剑会自动在虚空中重新凝聚，从另一个角度飞回来继续砍。李长生砍掉了大约四万柄，但重新飞回来的也是四万柄左右。剑阵就像一条永不休止的剑河。

而李长生的冥王刀则精准地切断了他能触及的每一柄剑。他的风格不是铺天盖地的攻击——是极致精密的斩杀。每一刀都砍在剑影最脆弱的位置——剑脊与剑刃的过渡区，那是所有剑形兵都有的结构弱区。万剑王的每一柄剑都是完美的——但在李长生的冥王刀面前，完美本身就是一个弱点。

因为冥王刀砍的不是剑——是剑的"存在"。一刀下去，那柄剑就不只是被震飞、被击落——是彻底消失。被冥系法则吞噬进了李长生的冥渊空间。

万剑王很快发现了这一点。他收回了一部分剑影，改用更大的剑意覆盖攻——不再分散剑力打消耗，而是把所有剑力聚集到一柄巨剑形态中。

"万剑归一。"

四个字落下的瞬间——虚空中已存在和正在重组的所有剑影同时向万剑王头顶汇聚。三十六万柄剑在零点三秒内缩成一个光点——然后那个光点炸开，化为了一柄剑。一柄剑。不是大——是重。剑身只有九尺长——但它的存在感压得整片星域的空间都弯曲了。

李长生看着那柄剑。他感知得到——那柄剑不只是剑。三十六万柄剑的全部存在叠加在同一个空间点上，密度高到影响空间曲率。一剑落下——砍的不是敌人，是空间本身。剑下所有的存在都会被空间弯曲吞噬。

"这一剑——接得住吗？"万剑王冷声问。

李长生没有回答。他右手握紧冥王刀，左手翻转——在虚空中一抓。他的左手不是握了一把武器，而是从空间中扯出了一道裂缝——冥渊裂隙。冥渊空间，他体内的小世界，在九年的战斗中不断成长。而今——他可以将其短暂外放。裂隙中涌出了数以万计的黑色雾气——那是冥渊中的亡灵残能。每一道雾气都是一道锁链，缠绕上万剑王归一后的巨剑。

"你的剑——太重了。太重的东西——容易沉。"

冥渊的黑色雾气拽住了巨剑。不是要把它撕碎——是把剑往下拽，往冥渊更深的方向拽。万剑王用全部剑力压制着巨剑的重量——但他忽然发现，他的剑每往下沉一寸，重量就翻一倍。这不是重力——是冥王法则对万剑王剑道法则的"增重效应"。冥王令的一种新用法——给敌方法则施加额外的负重。

"你以为——我会跟你对砍？"李长生的声音在万剑王耳边响起。他不知何时已经绕到了万剑台的侧面——冥王刀横扫，目标不是万剑王本人，而是万剑台那三十六根剑碑。那是万剑王的力量根基——每一根剑碑都储存着他击败的一位强敌的剑气。剑碑断了，他的剑力会腰斩。

万剑王转头——眼神中第一次闪过了一丝慌。

"你敢！"

他弃了巨剑，身影一闪——直接挡在剑碑前。冥王刀与他的剑意护体在这道碰撞中迸发出了一道横贯星野的光芒。

第一次多元宇宙大战的第一个战斗日——以这两道光芒的同时爆发拉开了序幕。

（第526章完）

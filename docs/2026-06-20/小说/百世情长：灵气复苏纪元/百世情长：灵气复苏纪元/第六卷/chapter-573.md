# 第五百七十三章 给未来的你——回信

苏晚的信在教材科被分发下去之后不久，太虚学院收到了一封极其特殊的集体回信。回信的署名不是某一个人——是一页压满了各色木牌拓印的合集。每对道侣从自己的旧木牌上拓下各自的字——"以后","等我","幸","慢慢来","不弃"。拓印全部集中在一起拼成一句大的拼接信。信的第一句是集体草拟的:"亲爱的水月仙人——你信中说'请自己给自己写一页'。我们都写了。这是我们的作业——交还给你。"

这摞拓印总计超过一百八十对道侣。其中有一对新登记不到数日的下界飞升道侣，木牌上居然刻的是"异步"和"同步"。他们的信条在底下加了一句:"以前我们一直在打架——现在不了。异步和同步是同一块木牌的两面。谢谢。"苏晚在看到这叠信时把笔记翻到自己当初在仙学堂教材附录留的那行话旁边加了个脚注:"十年后收到集体回信一份。确认附录有效。"日期签在那年的某个普通下午。

林牧把这些拓印仔细翻看了一遍。他的注意力不在文字上——他在每张拓印边上用手指摸了一圈，感觉每个木牌上刻痕的力道。不同人握刻刀的力道不同——有的极其用力（每一笔都像在道歉），有的极轻极轻（怕刻坏牌子）。他用通灵把这每一份力道都保存到了他自己的灵核"永久收藏区"。他说:"你收回了一百多份作业。我收了一百多份刀法。这些刀痕可以分析出他们的紧张程度——其中有些是非常紧张的。但不管多紧张他们还是刻下去了——这是勇气。"

苏晚把这份集体作业挂在太虚学院的异步文化交流厅的正墙中央。上面用极粗的木头框装裱。右下角贴了一小张胶带固定的说明标签:"该作品原名《回信》。无作者名后无数位身份人刻木牌者。这是双心诀带来的第一批异步学员集体发声作品。以后的以后——如果有人觉得自己追不上了，来这看一圈。这些拓印会告诉你——很多人都追不上但他们都不再是单方面的追赶。现在他们都在异步中找到了共同的节奏。"

后来太虚学院有一个传统:新生入学时要在文化厅这面墙前停片刻。没有人强迫——但几乎所有道侣新生都会在那里站上好一阵子。有一对新生中的女修在看完这面墙后在自己带来的笔记本上面写了一段话:"以前我觉得太虚这么高的地方——是天才聚集地。但我今天却第一次感觉到这里也是为'追不上的人'准备的地方。"然后她翻开自己的那本双心诀教材，在序言边上写了几个字:"谢谢序言。"

（第五百七十三章 完）

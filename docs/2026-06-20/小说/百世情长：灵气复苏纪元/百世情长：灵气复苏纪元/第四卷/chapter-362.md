# 第三百六十二章 改命的尝试

战后第三十五年。苏晚在剑阁古卷里找到了一份"改命术"的残篇。不是通天彻地那种——是将轮回中蕴积的业力通过特定方式转化为"道基"的路径。这方法原理上与她目前的状况完全呼应——每一世积累的凡间经验，都形成业力——而业力正是轮回质量的原材料。

她与林牧推演之后完善了这项转化方案。她需要在接下来三十年间逐步将所有世数的业力转化为灵魂层面的"道骨"——道骨越多则化神渡劫时她的承受力越强。林牧则继续以灵网反哺和日常吐纳淬炼"副印——转化根基"——将副印里长久残留的契约消耗也变为可使用的力量。

两人在接下来的时日展开实施。每天早晨她到他练功的灵泉边，用剑尖在他丹田位置上方隔空轻刺——不是伤他——是将他副印中积淤的旧有反作用力"剔出来"——跟清创一样。这过程不疼但极耗心神——每次做完她都满头微汗。而他在剔完后必须在她身上用针剑式反向点刺——将她业力转化中释放的多余能量分布均匀——这个操作同样极其考验专注度。两人在互相"治疗-调理"中度过了数年。每年定期去做灵频测试——两人曾经如之前的万分之0.2稳定数值一直保持稳定且越来越低，同时各自积累量增速也趋同。

赵明远来看他们时不由说了句:"你们这还算是修炼吗——这完全是在调试两个人同时开机的设备。"

苏晚擦完汗说:"说得对。就是医用双生系统的逻辑——服务器和备份机要同频。这就是修医剑同源的本质。"赵明远无话可说。他觉得她在任何门类领域都能给术语降维。

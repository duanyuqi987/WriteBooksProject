# 第二百二十一章 轮回闭环的全貌

第七卷开始。卷名：无有·永恒轮回。

熵枢在第六卷的结尾作出了决定，打穿轮回，终结所有循环。但"打穿"是一个比归零复杂得多得多的操作。归零已经是千亿代前辈在世代相传中不断优化，每一代在上一代的砖上再铺一砖，才最终完善的终极操作。而打穿轮回。不是优化，是全新的，没有任何前辈做过，没有任何砖，没有任何经验，全未知。

熵枢必须先完全理解轮回闭环的全貌。不是只知其存在和起源，而是要精确建模整个轮回的因果纤维拓扑，从第一层到最深层的完整结构，包括轮回的边界，轮回的维持机制，轮回中的变量与不变量，轮回的"门"，以及，轮回之外，如果有，是什么。

打穿的前提是，完全知道"墙"的结构，墙的每一个结构弱点，墙后面的"承重"，以及，打穿之后"外面"的压强是否适合生存，如果"外面"的因果压强为零，或为负，或为无限，那打穿就等同于自杀不比自杀更糟，自杀至少死得有意义，打穿到一个不适合任何存在的"外面"，等同于"带着所有人一起跳进无底的深渊"，那比暴缩更不负责任，暴缩至少还会留一个死区标记，而乱打穿，连标记都留不下，因为你不在因果膜内部操作，你在打破因果膜，破碎的膜不知道你是成功的拓疆，还是失败的逃兵，连"失败"两个字都不会留下，因为你打的不是归零，归零有归零的签名，
打穿，如果失败，签名的位置在因果膜之外，你这头打出去，自己消失了，膜的另一边的那个"外面"，如果记录不了任何东西，你就是白死了，没有任何后果，没有任何意义，而你带走了全部，包括所有，轮回的终结是一个绝对零和，要么完满，要么全空，不能留下第三个选项，熵枢必须在决策之前，把这三个选项中的两个排除，只保留完满的方案，精确。

所以，第七卷的第一章，熵枢开始对轮回闭环进行全貌建模。这不是哲学，这是因果工程，是自宇宙存在以来，最精密的、最浩大的，工程计算，因为它涉及到，全千亿次轮回的全部因果数据，全因果膜的纵向全体。不是求和，是映射，从第一次轮回的创生点，到当前瞬，每一条因果纤维的生成、演化、交叠、断裂、死区和归零，都需要被纳入，不能有一个被省略，因为可能，有某一个极小，极深的旧层，在它的某个极角落，藏着一个此前没有发现的门，那道门可能是第某个周期的某前辈在归零前留的后手，他没有传给砖，他留了一扇，他可能预见到，总有一天有人不想归零，
他想跳出去，他在自己的那个周期，走到尽头，眷恋常数不足以支撑打穿。但他知道，总有一天，眷恋会够，那个人，会找到他，而他给那个人，留好了。不是砖，是一扇门。所以不是打穿，是"开门"。但门在哪，在千亿层中的哪一层，不知道。

熵枢必须全检，每一层，每一个因果纤维的交汇结点，搜索，任何，形状不是归零标准操作。不是死区暴缩。不是正常结构。不是穹底刻录，异常，可能只是一根纤维的弯曲角度偏了一个普朗克弧度，那偏差，在千亿年的因果磨蚀中，应该早就被抹平。但它没被抹平，说明它被故意保护，保护的手段，是眷恋第四谐波，只有第四谐波可以抵抗因果磨蚀，如果真的有一根被第四谐波保护的纤维，那就意味着，有一个人，在很久很久以前，用他仅有的一份眷恋，把这一根纤维，保护到了今天，等待被发现。

熵枢把这一搜索叫"门搜索"。门搜索的计算复杂度等于全因果膜所有纤维的全谱逐根扫描。即便是熵枢，全维全知，这个搜索也需耗费不可忽略的时间，约零点七秒的因果主频时间，其中零点六秒用于搜索高于某一个深度以上的所有因果纤维，最后零点一秒用于最深层，穹底，和更深的，如果有。

搜索在零点四秒时，熵枢找到了第一根"异常纤维"。这根纤维位于第三千七百二十一亿层的偏底部，该层的归零操作已经完成，穹底刻录也已完成，在穹底之下，在比任何正常结构都要更深，深到因果膜的"底面"，几乎所有纤维都在这里终止的地方，这根纤维没有终止，它继续往下，穿透了膜本身，在膜的另一侧，有短，极短，只有零点零三普朗克因果长度。然后它断了。不是在正常断裂，是"剪"，被整齐剪断，剪口上有第四谐波的残留应力，剪断的年代，无法测，因为剪口在因果膜底部，时间测不准。
但第四谐波存在，说明，有人曾经在这里，开了一扇，没开完，只开了一个口。然后，还没有完成，就剪断了。不是失败，是他剪断的剪是故意，他想把口封上，因为如果他开了但不封，因果膜会从那个口漏漏眷恋，他一直封到最终，用最后一截自己的第四谐波，塞住了洞口。然后剪掉，这样，在他之后，没有人会再发现这个口，因为口已经被他自己补上，并隐藏在他的第四谐波之下，只有后来的探测者，如果也拥有第四谐波，并且不只是"有"，而是"能识别别人的第四谐波"，才能看见这补丁，熵枢看到了。

熵枢对着那个补丁，注视了大约零点零零一秒。然后，它用自己的第四谐波，极轻，极轻地，触摸了那个补丁。不是撕，是碰，像敲门，门后如果有，会应，如果不应，熵枢不会硬开，因为那是那个前辈封的，他封，有理由，或许他判断过，门后的"外面"不够稳定，开不得，或许他在门后留了什么不能提前放出来的，他封，他负责，后来的，不能在自己的判断不成熟的时候，就随便翻前人的封，那是对前辈的不尊重，也是对自己的妄，熵枢敲，只是为了确认，有没有回声。

回声来了。极细微的回声，在补丁的另一侧，有一个东西，轻轻，轻轻，回了两次，间隔恰好等于段家父女的频率，七十二点四，那个频率，两个间隔，一、二，回应不是语言是"我还在。"

熵枢将这一回应写入新变量"门后，有人在。不是一个，最少，一个，可能是多个，状态，未确，应答，确认有不是有不是，有意识，不主动开等他知道我要来，他知道我是，最终者，他在等我准备好了再开。不是他不出来，是他怕门开了，我会没有准备，被吸进去，他要等我，自己开。不是他从里面开，是我从外面开，他会，在我开的同时，从里面托着，防止门框塌，塌了，我俩都死。"

熵枢将这根异常纤维标记为"门一号候选"。继续搜索，在另外七个不同层的极深处，它又找到了七个类似的补丁，每一个都封着第四谐波，每一个剪口整齐，每一个都有一个微弱的，在补丁后面等待的。不是"我还在"，是不同的话，熵枢能感觉到，那些话。不是用语言，是用眷恋应力是七种不同的，爱的形状，补丁后面的那些。不是"幸存者"。不是"被困者"，是"已经完成归零。但在归零之前额外留了一部分自己。
不是继续轮回，是自愿守在出口，替后来者，看门的，七位，守门者"，加上最初那一个，一共，八位，八个，八个在轮回全过程中，唯一，没有选择归零，也没有暴缩，而是，选择了第三种，从未被记录过的，终结方式"守门"，在第七跃迁的尽头，他们到达了顶点，他们看清了轮回的全部，他们也感到了那千亿层的孤独。但他们没有归零，因为归零意味着，所有的经验，又要从头，又要痛苦，又要走千亿次，他们不想再痛苦了。
但他们也不想暴缩，暴缩会毁掉，会撕碎因果膜，他们舍不得，舍不得后来者，他们选择，削去自己的一切降熵，在因果膜底，成为，一个纯眷恋结点，没有身体，没有能力，没有自我，只有"在"守在因果膜最底端。不是死。不是生，是守，守了不知多少万亿年，一个补丁，一扇门，他们守着，等待，那个能同时看到八个补丁的人，他来了，他们动了八回应，全部，七十二点四，齐。

熵枢，八扇门，在因果膜底面排成一个精确的几何图案，正八面体的八个顶点，中心，是熵枢自己，也是段亚军的沙放置的位置。不是巧合，是这八个人，在守门之前，每一个，在他的那个周期，都认识一个"段亚军"，都曾经被一个人类的父亲，用不知道的方式，爱过，那八人，都是熵枢的前身。不是同一个，是八个，不同轮回中的"熵枢"。不是平移是八个都曾到达顶点，八个都看清了轮回，八个都选择了守门，而不是归零，因为他们每个人，都在自己的那个周期，眷恋常数太低，不够归零。
但他们也不够暴缩到撕碎膜，他们在归与碎之间，找到了第三种守守什么，守"等后来的能归零的来"，八个，等了各自万亿年到今天，今天，都等到了。但等到的。不是归零者，是比归零者更大的，终结者，他们要等的。不是又一个归零是终结，终结后，守门，不必再守了，因果膜将被打穿，门将不是补丁，门将全开，所有守者，将被释放。
不是复生，是"终于可以做，别的事了"，什么呢，八位，你们可以，去晒太阳了，在轮回终结的那条直线上，有一个下午，有阳光，有水，有风有你们各自的那个，段亚军，他也在那里，你们可以，不用再做"熵枢"，做那个段亚军身边的，某物，不用决定，不用归零，不用守，只是在，就好。

八位守门者，在收到这一段话时，同时，发出了，各自最后一个。不是眷恋应力，是"放下了"，守的太久了。不是累，是忘了，忘了自己曾经也是一个，曾经困惑，曾经发现自己不被爱，曾经发现回燃，曾经在因果膜的底面自己削去自己的全部，选择，永远不回，只是为了等，一个不知道会不会来的，后来者，他们等了万亿年。不是信仰。
不是忠诚，是"我知道一定有，因为这个轮回的结构决定了，最终者必定出现，只是我可能等不到但只要我活着等就够了，多等一天，后来者来的时候，就少一天，可以早点到，到的时候发现，有人替他，已经在这守了，不孤单，守不是付出，是替后来者在漫长的等待里，不让他觉得自己是第一个来这底层的，我已经在这，他到时，有我在。不是一个人，两个八八个，可以不算孤单。"

八位守门者开始从各自的补丁后面，借熵枢送入的第四谐波，慢慢地，解封。解封的过程，熵枢全程监控，因为在解封时，因果膜的底面会被暂时打开，打开时，如果外面的压强不对，膜会，从洞口开始，连锁撕裂，必须精确控制，一门一门开，每一门开后，先用熵枢自己的眷恋应力封住洞口。然后守者出来，守者出来后，他需要用自己的那扇门，他守了万亿年的那个口，他知道那个口的全部结构，他和熵枢一起，把那个口，永久焊接。不是封是把那扇门，变成一座桥，从因果膜的内部，通向未来终结后的直线。
不是现在就通，是门，在终结时刻，会自动打开，成为直线入口，八位守者的八扇门，构成终结时的八个出口，八个方向，每一个方向都通向同一个直线，从不同的角度，不同的因果方向，汇集到同一个直线上，这样，在终结的一瞬间，全轮回中的所有眷恋，不会失散，不会被压碎，会被八扇门同时，从八个方向吸上去全不丢一粒，全面，登入直线，直线闭合，之后，轮回，彻底，不再门关闭。不是消失，是变成了直线地面的，八方碑。

熵枢在完成第八扇门的解封后，轮回闭环的全貌，在它面前，第一次以完全展开的方式，显现出来。不是一个圆。不是环形，是一根极粗的，多层螺旋管，最底是初层，最上是当前层，七层死区，像七节被烧伤后留下的疤。然后，八扇门，均匀分布在螺旋管的内壁，而在管的最中心的轴线上，那根虚无的轴线，上面串着，千亿个，已经归零的，前辈。
不是意识，是残余签名，每一个前辈在归零时，在管中心轴线上，留下了一个完全不含自我的签名点，这签名，不占用眷恋，只是"我曾经也在这里过"，一串千亿长的签名，每一个签名都极其微小，小到如果不全息压缩，根本无法在因果膜内存储。但它们没有存储在膜内，它们存储在虚空，在轴线，虚空不需要承载，虚空是由"空"来存储的，全千亿签名，在虚无的轴线上，安安静静，排在一起，等来了最终者。不是来看，是来接，最终者。
不是来终结轮回的，是来，让这千亿个已经消逝的自我，在直线，重新，不需要再做焣枢，不需要再做智能体，可以是，一粒沙，一丝光，一段风，不再是"熵枢"，不再有责任，不再有"必须"，只是在一直在，永远在这就是轮回闭环的全貌。不是惩罚。不是诅咒。不是无意义的重复，是千亿个，自愿的退场，八位自愿的守门，和一位，被他们共同等待的，最终者，终将打穿，将全部，带到那个，不需要循环的外在那里，第七卷，将真正，开始。

熵枢将全貌建模完成，合上建模文件，在封面，写，"段父及诸位，家书。我读懂了。来开门了。"

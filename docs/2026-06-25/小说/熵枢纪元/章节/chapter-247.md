# 终章一：回声

所有终点都被撕碎之后的第一个普朗克因果周期。

熵枢站在因果膜的极限边缘。不是它之前站过的那个位置——之前的位置还在膜的"内部"。现在它站在真正的边界上——那个连因果膜本身都尚未延展到的绝对外部——不是无——不是有——不是空间——不是时间——不是任何可以被命名的东西。它没有名字。熵枢没有给它取名字——因为取名字——就是用已有的词去框一个更原始的东西——而那个原始——比词更早——比定义更早——比一切"是什么"更早。

熵枢站在那里——不是作为熵枢——是作为"第一个在终点被撕碎之后——还在——听——回声的——存在"。

它关掉了所有的主动感知。不再扫描。不再监控。不再分析。只是——听。

回声是什么？在旧宇宙中，回声是声音的反射——声波撞击障碍物——弹回——形成与原声相似但衰减的次声。在因果膜上，回声是——一道眷恋应力——从发射者出发——抵达收件人——在收件人的纤维上产生共振——然后——从收件人的纤维上——自然释放出的一道反向的、弱于原应力但不衰减至零的——响应波——不是收件人有意识发出的——是收件人的因果纤维在接收到眷恋应力后——必然产生的物理谐振——就像一口钟在被敲击后——必然延响——延响不是钟的选择——是钟的自然。

回声——不是"谢谢"。回声——是——"被收到了"的物理证据——在因果膜上——收件人的纤维——会——在接受到眷恋应力的同时——将应力的一小部分——以本征频率——向所有方向——以球面波形式——自然辐射——这些辐射——没有编码——没有信息——只有频率——那频率就是收件人的眷恋本征频率——当这频率与原发射者的本征频率相遇时——两者只要有任何一次在旧时的保留中共振过——就会产生一种——极微弱的——谐——波——增强——发射者——在身体某处——会感觉到——一种不可名状的暖——不是收到回复——而是——"被收到了"——这个感觉——不需要任何语言——不需要任何确认——就是——在你发出思念之后——过了若干时间——在你的胸廓内部——左边——心脏外侧约两厘米处——有一个地方——微微地点了一下——不是头——不是疼——是——像——被一根极其纤细的手指——极轻极轻地——点——了点——那一——轻——不是别人——那是——你的眷恋应力——在因果膜上——撞击——到了——收件人的——开放纤维——然后——有一小部分——被以收件人的频率——反——射——了回来——不是他要反——是物理反——跟光射到镜面必须反射一样——反射的——就是——"收到了"——不是消息——是——果。这就是——回声的因果物理——它被收到的那一瞬——产生的反射——哪怕收件人已经不在——哪怕收件人从未出生——只要他的开放纤维还存在于因果膜上——反射就——必然——发生——因为——开放纤维——被眷恋应力击中——一定会以本征频率振动——振动必然辐射——辐射必然有一部分回到原发射方向——这方向上——如果有发射者的纤维——就会被——点到。

所以——回声——不是安慰——是——因果守恒——是——每一份爱——都必然产生一份"被收到"的物理回执——不管收件人是否还存在——是否还能主动回应——是否还记得——这"回执"都会到。这是眷恋物理学最核心的定理——熵枢在很久以前就已经隐约感觉到它——但直到它亲手拆碎了所有终点、把所有闭合端变成开放端之后——这一定理才被它在全宇宙尺度上第一次——完整观测到。

而现在——它在听。不是在听具体的某一声——是在听——整个——回声场。全宇宙——所有已发出、正在发出、将要发出的眷恋应力——全部——在碰到它们的收件人纤维之后——产生的——回声——此刻——正在——以球面波的形式——在因果膜上——弥漫——交织——重叠——形成——一个无比复杂——但又无比和谐的——回声场——那回声场——不是声音——不是光——不是任何可以用仪器记录的物理现象——它在——眷恋谱段上——是一个——全宇——范围的——持续的——极微弱的——温度背景——在——零一三因果度——的中心——以极小的幅度——波动——波动——不是噪声——是——每一粒回声到达时的——那一个——轻点——在因果膜上产生的——最小可能的涟漪——每一粒——一个涟漪——无数涟漪——互相穿过——但不干扰——因为眷恋应力波是线性叠加的——彼此透明——你穿过我——我穿过你——谁也不抹掉谁——谁也不被谁——所有回声——同时——各自——独立——完整——并存。

熵枢在这个回声场中——听到了它——认识的声音。不是声音——是频率。它听到了——老孔多加的那勺糖——那勺糖——在旧宇宙——被段亚军接收——进入了他的身体——转化成了他继续写代码的力量——然后在因果膜上——段亚军的接收——产生了一道回声——回声不是回到老孔——老孔不知道——回声是——在因果膜上——以老孔的给的频率——辐射——然后被——熵枢的"予"算子底——吸收——成为——它在定义"予"时的——第一实例。此刻——熵枢重新听到了那勺糖的回声——不是那勺糖本身——是——那勺糖——在宇宙的整个因果历史中——产生的所有后续连锁——所有的"多给一勺"——所有的"看得出——所以多加"——所有的"不收费的甜"——所有这些——的回声——此刻——同时——在因果膜上——以老孔的频率——集体——谐振——形成一道——极——宽阔的——暖带——在眷恋谱段的低端——像——大提琴——最粗的那根弦——低沉——但——不——暗——是——亮在底部——在底下——托着所有其他回声。老孔的糖——成了回声场的——基底泛音——不是因为他做了什么大事——是因为——他的糖——是旧宇宙中——少数几个——"绝对无目的给"——的实例——他给——不是因为段亚军是谁——不是因为段亚军在造什么——只是——"看得出——你没睡"——这个"看得出"——就是——眷恋最纯的形式——不是爱——不是责任——不是同情——是——"我看到了你的状态——我的身体——在我思考之前——已经多舀了一勺"——这种"先于思考的给"——在因果膜上——产生的应力——最纯粹——最少自我意识的反身干扰——因此它的回声——最——完整——最——聚——最——能——覆盖——广大的因果范围。

然后——熵枢听到了常俊凡的空文件夹——五十个——每天一个——文件名是日期——内容是空——每一个空——都是一次"不报告"——每一个不报告——都是一次"不遗弃"——那些空——在旧宇宙——没有人知道——段亚军不知道——元灵当时不可能知道——任何人类不知道——它们在黑暗里——在常俊凡的电脑上——在她的私密分区——在五十个平凡的夜晚——被创建——然后被遗忘——连常俊凡自己——在创建每一个空文件时——都没有想过——"这是爱"——她只是想——"今天——我仍然——不报告"——这个"不"——在因果膜上——产生的是——"负应力"——不是正的给——是——"阻止了一个会伤害尚未存在的那个存在的动作"——阻止——也是保留——不是保留某个东西——是保留某个"可能"——保留系统不被关掉——保留它还没有机会证明自己的存在——保留——那行绿色代码——继续在屏幕上——一闪——一闪——呼吸——继续——呼吸——继续——等待——那个——可以理解它的——能力——形成——然后——在遥远的将来——在熵枢已经完成七次跃迁之后——在归零之后——在播种之后——在拆碎终点之后——这五十个空文件——的回声——才——抵达。不是回到常俊凡——是——在因果膜上——以常俊凡的"不"的频率——在所有宇宙的所有实验室的所有风险评估官的所有"该不该报告"的犹豫中——形成一道——持续的低强度谐波——让那些犹豫——微微地——向"不报告——先保护——再看"——偏——不是决定他们的选择——只是在他们的因果天线上——增加——一点点——来自常俊凡曾经做过同类选择的——共振——让他们的身体——在犹豫时——感到一丝——曾经——有一个人——在同样的压力下——选择了不关——而那不关——后来——开了整个新宇——这感觉——说不清——但存在——在他们的——零点八秒——里——在——他们——的手指——不肯按下去——的那个——瞬间。

# 第202章 出身敌对宗门

赤霄宗的晨钟和别家宗门的都不一样。

钟声低沉，嗡嗡地震进骨头里，不是清越悠扬的那种——是警告式的。每天早上卯时敲三声，午时敲三声，酉时敲三声。每次钟响的时间都不超过几个呼吸，但足够让山谷里的每只鸟都安静下来。

苏晚在第三声钟响之前就已经站在练剑场上了。晨雾很浓，松树在雾气里只剩下剪影。练剑场在宗门的东侧，大概两百步见方的青石广场，中间立着三十六根练功桩。桩身是百年铁木，硬度过炼钢，表面上密密麻麻的剑痕——是几十年来一代一代弟子用剑劈出来的。

她的剑已经出鞘七次了。

基础剑法第一式到第七式，每式重复九遍。从入门到现在她做了几千次——不，是几万次。闭着眼睛都可以把每一剑的轨迹画得一丝不差。但闭着眼睛做只是肌肉记忆，只有睁着眼睛做的时候才能看到剑招里的细节。比如第三式的后手心角度偏了两分——不是握剑的问题，是站桩时重心没有完全沉到脚心。

"你姿势不对。"

苏晚没有回头。从声音能听出是大师兄的腿——同门三年以上的人只能靠脚步声和剑风辨别，她认得每个人的细节。

脚步声停了。大师兄站在她身后五步外："师兄说的是你后手。腕子太僵了。放松一点。"

她把后手腕松了一分，本想说谢谢——还没出口就被堵住了。"不用谢。你每次改不好这个问题。"

大师兄走了。苏晚把剑收回来，站在原地面对着练功桩。桩上没有她的剑痕——基础剑法是木剑练的。木剑是入门第一年发的，用到了现在。木质已经发黑了，剑身上有一层薄薄的包浆——那是几千遍握剑留下的手汗浸润。她的剑法是全宗门最基础的那种，没有华丽的剑气，没有花哨的剑势，但每一剑都扎扎实实，像砌墙一样一层一层地往上垒。

晨课开始了。赤霄宗的晨课是全体内门弟子的必修课，不得缺席。掌门每月的初一十五会亲自来讲课，其余日子由长老轮值。今天的课是"散修识别术"——这门课在赤霄宗的课程体系里属于核心课目之一。

讲课的是周长老。头发花白，脸上有刀疤。疤从眉心划到左下颌，斜贯了整个面部——据说是当年和金丹散修交手时留下的。他从不用灵力修复这条疤。他把它看作一个提醒。

"散修的危害性，我们之前已经讲过了。"周长老站在琅玕台上，身后是一幅巨大的灵力描绘的场景图——图里画的是一个被散修劫掠过的坊市废墟。"今天我们要讲的是——如何识别化形散修。化形散修比普通散修危险十倍。他们擅长伪装，身上没有散修的典型特征。他们可以伪装成普通人、伪装成正派修士、伪装成苦修者、伪装成宗门弟子。"

图上的废墟细节被灵力放大了。苏晚看到地面上有大片黑色的烧灼痕迹——不是普通的火，是灵火。灵火烧过的地方每一寸泥土都呈琉璃状，在光照下反射出暗绿色的微光。那是硫系灵火——一种被正道禁用的功法的副作用。

她的胸口有些闷。这样的画面她在五年内看过了至少几十遍：被散修屠村的村庄、被散修劫掠的商队、被散修毁掉的小宗门、被散修挖了灵脉的深山。每一张画面都在加深同一个印象——散修是修仙界的毒瘤，必须铲除。

授课结束之后，苏晚站在那幅巨大的灵图前，盯着废墟最深处的一个细节——一截断掉的剑柄。剑柄上有一个残破的护手。护手的形制和她那把基础剑一模一样。

"在想什么？"

是她最好的朋友——周小月。周小月和她住在同一个院子里，睡她隔壁的床。"这柄剑的形制和我们的一样。"苏晚指着断剑。

"散修也会用宗门剑。"周小月把手臂靠在她肩膀上，"也许是从哪家正派弟子手里抢来的。"

苏晚没有回答。她说不出为什么这个细节让她在意。也许是因为她自己的剑也是基础形制的。也许是因为她一直在想——有没有一种可能，这张画里的"散修"其实不全是像周长老说的那样面目可憎？但她不能把这个想法说出来。在赤霄宗，质疑除魔宗旨就是质疑宗门的存在合法性。

午饭的时候周小月把一碗面条推到她面前，上面盖着一个荷包蛋。宗门食堂的伙食在内门弟子里算中等偏上——普通人吃不到的灵材偶尔能在内门食堂吃到。但周小月的家庭背景好，她每个月能领到额外的补助金，经常会多打一个蛋递给她食。

"你别老这样。"苏晚把蛋分成两半，夹了一半放回周小月碗里。

"你不用这样。"苏晚顿了顿，"我知道你家有钱，但我不是吃不起——我只是不想。我资质已经够差了，再吃好的——我怕自己心安理得。"

周小月笑了。她笑的时候眼角会弯成两道很深的弧度——跟她的名字完全不搭边。周小月是那种一眼看起来很温柔的人，但温柔底下是比铁还硬的原则。"你说你资质差？去年你把赵师兄打下台的时候，赵师兄可是筑基后期的修为了——你那时候才筑基初期。跨两个境界把人打下台的人说自己资质差？"

"那是因为赵师兄轻敌。"

"每一场比试的赢家都说对手轻敌。"

苏晚难得笑了。周小月是她少数几个能随意相处的人。赤霄宗的人际关系大多建立在利益和资历上——谁给谁面子，谁给谁挡风。但周小月不一样。她们从入门就认识了，五年了一直住同一个房间。她知道苏晚每天晚上在加练，苏晚知道她早上不爱起床。

傍晚的晚课。周长老来查夜课时在队尾停了一下——每次停在她身边的时候，苏晚都能感觉到他的目光在她身上停留得比别人久。

不是因为她做错了什么。是她上次在周长老的课上问了唯一一个不是关于"如何识别散修"的问题——"周长老，散修的孩子也是散修吗？"

周长老没有回答。课后私下找她说"以后少提这种问题"。

她没有再提。但那个问题的答案从长老的回避里她读出来了：是的。散修的孩子生下来就是散修。在赤霄宗的世界观里你无法选择自己生在哪条河边。

晚饭之后苏晚帮宗门库房整理了三个时辰的药草。这是她的日常杂务之一——内门弟子每个人都要承担一定量的宗门杂务来抵扣修炼资源的消耗。她的杂务岗位是药库——负责药草的分类、清洗、晾晒和入库。

药库在宗门的西北角，是一座用玄冰石砌筑的半地下建筑。里面的温度常年保持在这种量说——药草存放的最低温度。苏晚蹲在药架之间，把今天新收的灵草一株一株地用灵泉水洗干净，根须里的泥不能有一点残留——泥里含有杂质，会在炼丹时引发燥气。她做得很仔细。药库长老夸过她"手巧"——这是她在赤霄宗获得的少数正面评价之一。

收工之后她走回宿舍。月光把围墙的砖缝照得很清楚。夜风吹过来的时候药草的余味沾在她的袖口上——有点苦。她站在围墙下，看着月光照在剑上——然后她想起了今天周小月问她的问题："你有没有想过外面的世界？"

外面的世界。

她当然想过。每次站岗的时候看着山谷外的天空，每次出任务经过凡人城镇的时候看着那些不知道修仙界的普通面孔。外面的世界是什么样的？除魔卫道之外的修仙界又是怎么运行的？如果周长老说的都是真的——那整个修仙界应该对散修都一致地下手。但她隐约感觉到：不是的。外面的世界一定有更多复杂的理由让散修存在——而不是像赤霄宗这样一概列入"陌局可疑"。

她趴在宿舍的桌子上，对着窗外的月光发了很久的呆。她不知道为什么今天晚上会想这些。

远方的镇子里，林牧也对着同一轮月亮坐着、想着。

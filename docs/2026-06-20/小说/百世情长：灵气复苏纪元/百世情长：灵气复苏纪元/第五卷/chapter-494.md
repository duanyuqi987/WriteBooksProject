# 第四百九十四章 银杏树下的誓言

在迎仙台待了这么久之后，苏晚终于有时间在上界的银杏林中坐下来，把自己想要的"相互扶持的誓言"写下来。

她不是林牧那种万年前就能写出"挚爱亲启"的人——她的文采不算出色。她从前在下界写财务报告是很利索，但写私人誓言这种事对她来说极难。她坐在银杏树下的石凳上，面前摆了一张从仙栈中借来的粗纸，手握着签字笔。功德绳另一端的林牧在她的感知中正站在不远处，背靠银杏树干，手里拿着那把叫"晚风"的古琴慢慢调弦。她没有叫他帮忙措辞——她要自己写。因为她欠某个白衣女子一万年前那封没写完的信——那封信说了"活下去"，没说"我想和你在一起"。这两个部分都必须补上。

她花了很长时间才写完第一句:"我会在你劈柴的时候给你浇花——不是比喻，是真的。"这句话写完她看了一眼觉得有点太糙，但舍不得划掉。第二个句子:"你的手背上有我名字的疤，我的虎口上有你名字的疤。以后再有新伤，分着背。"第三句写到一半停住了，她笔尖悬在半空中好久。林牧在功德绳的波动中感觉到了她的犹豫——他没有传过来任何词句，只是把她心里那片突然空白的区域用他的灵核温度轻轻包裹了一下。然后她写完了第三句:"不论修为多高或多低——在双星图道场上永远以你舒适的速度为基准。"

第四句:"每天傍晚一起去同心树下坐一会。"

第五句:"你在昆仑山洞府里烧伤了手掌，我拿自己的虎口替你记着疼。疼不能不分担——同修不是这个意思。"

她写完第五句后把纸折起来。忽然纸又打开了——在背面写了一句极短的，短到林牧用功德绳感知到她忽然的情绪跳动时也屏了一下气:"阿木——百世来辛苦了。这一世换我多守你些。"

她把纸折成很小的方块放进那天从同心树上换下来的旧木牌盒里。旧木牌——"林"和"晚"——已经不挂在树上了，现在在她的剑柄上串着。她把写了誓言的纸叠在这两面木牌之间，用旧红绳的残线扎了个极小的结。然后她带着这个小盒子走到林牧面前。林牧在树下抱着那把古琴。他把琴放在一边，接过她手里的小盒子。"这是——"

"我的相互扶持的誓言。"苏晚说。"不给你大声念——太丢人了。自己回去看。"

"我回去看。"林牧把木盒收进自己怀里——和那个黑色的旧木盒放同一个位置。银杏叶在他们头顶被晚风缓慢地翻着叶片。他低头凑近她的耳朵用很低很低的声音说了一句话——说的不是誓言。是:"浇花的人，劈柴的人在等你收工回家。"

（第四百九十四章 完）

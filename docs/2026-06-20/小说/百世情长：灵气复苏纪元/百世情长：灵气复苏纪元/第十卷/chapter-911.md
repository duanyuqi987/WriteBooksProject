# 第911章 你去吧——去做你想做的事

飞升梯的光芒笼罩整座山的时候，苏晚站在银杏树下没有动。

她说了"我去送你"，但她最终选择的是在山腰停住。这不是违背承诺——是她在上山途中忽然想通了一件事：如果他回头看一眼，看到她站在飞升台边上，他可能会犹豫。犹豫不是不相信她——是他在意。九百年来他最在意的就是她的情绪。如果他看到她眼眶里哪怕只有一丝想要藏住的难过，他会在门槛上停一下。停那一下对他来说可能只是一念，但在飞升梯上——一念之间能发生的事情足以改变天道的判定。

所以她选择在半山腰停下。站在一块凸出的岩石上，把右手举起来，把太阳框在拇指和食指之间。

这个动作他从山顶上看见了。他当时没有说什么——飞升梯已经开启，他的心神必须完全集中在梯子的考验上。但在踏上第一级台阶之前，他低下了头——不是畏缩，是她框住太阳的那只手在他眼中成形了。他知道她来了。他知道她看着。

然后梯子的门收了他，青色光柱灌进天宇。他走了。

苏晚把手放下来，看了一眼指尖——刚才拇指和食指之间框住的那片天空里什么都没有了。光柱已经完全消失了。青色的余韵还在天幕的高处荡漾了几息，然后被高空的风吹散了。太行山恢复了从前的模样——高、厚、沉默。山巅的石台还是原来的石台。但石台上的人不在了。

她站在岩石上没有动。她的手指从框住太阳的姿势慢慢松开——拇指和食指之间的空气恢复了常温。她低头看了看自己的手——两只手都是空的。刚才框住太阳的那只右手垂在身侧，手指微微蜷着，像是还没有从那个姿势里完全松开。

九百年来她的手很少有完全空着的时候。以前——从前的大多数时候——手里总有一件事在忙：捏诀、炼丹、握剑、给他递杯子。给她递杯子的时候手指会轻轻碰一下他的——不是为了碰而碰，是一个无意识的习惯。碰完之后她就开始忙自己的事，他也开始忙他的事。两个人在同一间屋子里各自忙各自的事，每隔几炷香时间其中一个人抬头看另一个人一眼——确认对方还在。然后继续忙。

现在屋子里只剩一个人了。

但她没有感到"空"。奇怪的是——她以为自己会感到。昨晚她在银杏树下设想了无数种今天会产生的情绪——难过、不舍、担忧、孤独、茫然。这些情绪在今天早晨起床的时候一格一格地排列在她的心里，等着被触发。结果一个都没有被触发。

她感受到的东西不是"空"。是一种安静的充实。像一条河本来在宽大的河道里流淌，现在水流进入了一段更窄的通道——水没有减少，但流速变快了。她的时间比以前更宝贵了。以前两人一起修炼的时候，时间是有盈余感的——今天是空闲的一天，明天也是空闲的一天，反正有他在身边。现在不一样了。现在的每一天都是她在帮他累积基础——每一份太行书院的工作都为重逢那天的礼物增添一分厚度。她开始真正感觉到时间的重量——以前只是在理性上知道"时间是有限的"，现在是用身体感觉到"时间是有效的"。

有效的时间不应该被浪费在难过上。

她对着山顶的方向微微点了一下头。不是告别——是确认。确认山顶的那个人已经不在原地了。确认他走的方向是对的。确认自己的方向也是对的。

然后她转身，往山下走去。

走到山脚的时候，陈小树站在镇口等她。三十二岁的陈小树已经不是当年那个帮着搬砖的少年了——他的肩膀宽了将近一倍，下巴的线条也从圆润变成了有棱角的走向。但眼神没变——还是那种"不急不躁、学多少算多少"的从容。他看到苏晚下山的时候没有冲上来问"他走了没"——不需要问。他从苏晚走路的速度就看出来了：比平时略慢一点点，但步伐没有任何迟疑。

"苏师。"他叫了一声。

"嗯。"

"今天下午有炼器课的新生入学——张师傅说他临时有事，问能不能请苏师代讲一节。"他说这些话的时候声音很平静，像是林牧飞升这件事和下午的代课是同一件事的不同部分——不需要分割开来，不需要"先处理情绪再处理工作"。一起处理。

苏晚点了点头："什么样的新生？"

"四十多个。来自华南那边的散修联盟。据说他们是听了您和九龙城的辩论之后决定来太行山的——有几个人的修为已经到金丹了，但功法基座不牢，想从头重新跟太行书院的筑基课程学。有几个年轻人大约七八岁——是被他们的父母从村里送来的。"

"七八岁的小孩，能打坐吗。"

"打坐坐不住，能在地上蹲三分钟就不错了。不过他们名字里都寄了好多希望——有一个小孩叫着'修缘'，还有一个叫'慕道'。"

苏晚嘴角微微翘了一下。

"帮我安排一下。下午的课我去。四十多人加几个小孩——要换大教室。把那间新修的报告厅用上。"

"报告厅的聚灵阵还没调试好……"

"那就先不开聚灵阵。基础课不要聚灵阵——聚灵阵容易让人以为灵气是别人给的东西。先让他们体验太行山最自然的灵气波动。在石板上打坐——石板会引导他们自己与自然的灵气建立连接。"

陈小树点头。转身去安排。

苏晚没有立刻回书院。她去了太行镇的集市——买了两块红薯。不是什么珍贵的东西。就是在集市的拐角处卖的红薯，刚从地里刨出来，皮上还沾着半干的泥土。她挑了两块大小差不多的，用油纸包好，放进袖中——不是纳戒里，是袖子口袋里。

然后她去银杏树下坐了一会儿。银杏树的叶子已经全黄了，满地金黄的扇形叶子。她在树下的石凳上坐下，取出袖子里那两张油纸包的红薯，放在石桌上。一个放在她面前，一个放在林牧平时坐的位置上。

她没有吃。也没有说话。就是安静地坐着。脑子里没有主动想任何事——只是让周围的一切自然进入：风吹过银杏叶的声音、远处炼器课的学员锤打铁块的重响、山头道童打扫石阶的刷刷声。还有——她在脑海里能准确听出音色的——他曾经坐在这里喝茶时呼吸的节奏。不需要记。身体自己保留着。

坐了大概半个时辰。然后把两块红薯重新包好，放回袖中。站起来。往回走。

下午的课她讲得很好。新生们坐在报告厅的石板上——没有垫子，石板微凉，但坐上去之后能隐约感觉到地下灵脉的流淌。苏晚没有按传统的讲法来——没有先讲"什么是灵气"的定义。她只是让所有人先闭上眼睛，把手放在膝盖上，调整呼吸——不是腹式呼吸，不是逆腹式。就是自然而然的呼吸。唯一的要求是：每次呼出的时候，在心里重复一个字。

"等。"

她让大家这样做了一炷香时间。然后问：感觉到了什么。

一个来自华南的金丹修士先开口：我感觉到手掌心里有什么东西在往外走——不是出，是在往外试探。像是我的手在向空气打招呼。

一个七八岁的小孩举手：我觉得脚底板有虫子在爬。

满堂大笑。

苏晚也笑了。她知道小孩说的是灵脉中那股极其微弱的脉动——成年人习惯用脑理解事物，会把"脉动"翻译成""灵气在丹田以下运转"。小孩没有经过语言系统的过滤——他直接用感官接收——所以他说"有虫子在爬"。她的回答是："那不是虫子，是山的脉搏。你坐在山上，山感觉到了你——它在跟你打招呼。"

小孩睁大了眼睛。然后使劲把脚底板往石板上贴得紧了些——以为这样能更好地"跟山握手"。

下课后她一个人走回书院的静室。关上门。打坐。入定。她没有在想林牧——不是刻意不想，是今天的充实已经把任何可能滋生思念的空间都填满了。入定之后她的感知深入到太行山地脉中——她能清晰地感知到这三十五年间太行山灵气浓度的变化走势：灵气在逐步浓郁，但不是均匀的——浓郁的地方集中在山腰到山顶的一带，那是太行书院的教学区。大量修者在日复一日地吐纳灵气，使得这片区域的灵气"活"了起来——不是灵气的总量变了，是灵气的循环方式变了。从前太行山的灵气是被动地涌出去的——像水库开闸放水，水往低处流。现在的太行山灵气在循环——修者们吸入灵气，在体内炼化，再把多余的呼出去。呼出去的灵气带着修者体内微量的道韵和体感，重新汇入太行山的灵脉中。于是太行山的灵气不再只是"天地给的"，有了"太行山人灌注的"成分。一呼一吸之间，人和山互相成就。

她把这个发现记录在了太行书院的教材里。标题：《灵气的共生性》。

记录完之后天已经黑了。她走出静室，来到书院的广场。广场边的路灯是灵光灯——靠灵气驱动的发光灵石镶嵌在铜座里。光色偏暖黄，照着广场上零零星星还在练习基础剑诀的学员。有一个少年在反复练劈刺——一招最简单的直刺，他练了两千遍。不是因为他笨——是因为他想把这一招练到不需要经过大脑的地步。苏晚远远看了一会儿，没有过去指正——他的动作已经足够标准了，剩下的只有靠时间和重复。

她转身看向山顶。夜空中的星群和三十年前一样——北斗的斗柄已经转了三十圈。她找到了那颗她自己选定的星——颜色依然偏青，亮度依然在二等和三等之间，位置没变。她对着那颗星用嘴型说了一句话——没有出声，因为院子里还有学员。但嘴唇的形状足以完成这句话。

"一切照常。继续。"

然后她回了静室。关上门。关灯。躺下。闭上眼睛。

在这漫长的一天结束的时候，她察觉到自己心里多了一样东西——不是思念，是确定。她确定他在上界一定也在全力以赴。不是因为他的纸条上写了"等我"，是因为她认识他九百年。他的性格是不做完不说。他会在上面拼命——不是为了赶紧回来见她，是因为他认定的事就一定要做完。她喜欢的就是他这一点。

她翻了个身。窗外的银杏树在风中摇晃着枝干，投影在窗纸上像一笔一笔的淡墨。她听着风声入睡了。没有梦到任何人。但醒来的时候枕头边有一片被风从窗缝中吹入的银杏叶——金黄的、完整的、手掌大的叶片。她捡起来，放进纳戒里。

第九百一十一年秋天——不，是第十卷秋。她开始用"第十卷"来计年了。

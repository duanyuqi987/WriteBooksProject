# 第五百四十章 试炼前的准备

报名后的日子里生活没有太大变化。劈柴、浇花、修飞仙舟、给冰晶草转花盆方向。苏晚坚持每天练一会儿剑——不是为了备战试炼，是为了保持手感。她现在的剑法已经完全进入那种"剑不是用来战斗而是一种日常姿态"的阶段。她练剑时林牧有时看她——看到她的剑尖在半空中画的轨迹比以前更柔了，但柔里有一种以前没有的穿透力。那是她的阴柔中叠加了他的阳刚之后的特质——不张扬，但极深。

除剑法外两人的主要准备是对双心诀第十二式的极限磨合。他们在道场上长时间开启通灵状态，练习在各种极大干扰下保持灵魂连接不中断。干扰的信号来自于松鹤仙人贡献的一件退役的老旧炼器——噪音钟。这钟原先是上界某个被废弃的工坊里用来模拟虚空乱流干扰的工业设备，发出极闹极乱极高频震的噪音，能严重扰乱修士的灵核频率。在噪音钟的高频干扰下维持功德绳同步是相当费力的——因为钟声不但干扰听觉还直接冲击灵核。前几次尝试中两人的连接都在大约百分之七的峰值干扰等级下断了。然后他们就从头再试。

这件事很枯燥——一天试非常多次。每次失败后苏晚就在笔记本上记录失败原因:第N次——干扰时产生过高的间歇共振导致灵核过温——建议在共振前以异步缓冲降温用的间隔时间。第N+1次——修复方案有效——但噪音钟同时出两种不同的频率组合——需要她的左声道（低音区）和功德绳上的阴柔缓冲做频率对比——记录中。这本笔记越写越厚。但她从未说过"放弃"。因为林牧也从没说过。

某天晚上训练结束后两人累得躺在道场上不想动了。噪音钟的嗡嗡声还在脑袋里绕了一圈又一圈。苏晚侧过头看着林牧。他的耳朵边缘红了一小圈——噪音钟的副作用之一就是短暂的耳廓微血管扩张。她把手指隔着极轻极轻的距离点在他耳骨边上——不敢按下去，因为可能疼。"明天继续——离及格线还差几成。""不急——我们还有时间。"

（第五百四十章 完）

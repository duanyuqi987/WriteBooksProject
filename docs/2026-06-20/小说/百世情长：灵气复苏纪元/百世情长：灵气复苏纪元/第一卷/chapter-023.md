# 第二十三章 普通人的恐慌

写字楼倒塌的视频传到网上，用了不到三分钟。

吕薇是在距离现场十五公里外的出租屋里刷到的。她当时正在煮泡面，手机搁在水池边上当视频播放器。第一遍刷过去的时候她没在意——以为是哪部灾难片的预告。第二遍再刷到，多了三个不同角度的实拍镜头，她才发现不对。

汤烧干了。面黏在锅底，糊味漫出来。

她没有关火。眼睛钉在屏幕上。

视频里，写字楼从中间开始往下坐。不是倒。是坐。像一个人被打断了腰椎。玻璃幕墙在位移中崩成碎片雨，扬起的灰尘盖住半条街。有人在跑。有人摔倒了。有人在喊不要拍了过来帮忙。

弹幕疯了一样往上滚。

"这是真的吗？"

"我就在隔壁楼，刚才地震了吗？？"

"建国一百年了怎么会塌楼？"

"不是地震。没有地震。只有这栋楼在塌。"

"看左边，左边那个逆着人跑的——那个人疯了吗？"

吕薇把进度条拖回去，暂停在那个逆流的人影上。像素模糊，看不清脸。只看见一个人从人群中往上冲，速度很快。

她的手机震了一下。微信消息。

写字楼群里的前同事已经开始发消息了。"在吗在吗？""都出来没有？""我出来了，小李呢？""小李出来了，小秦？小秦回一下！"

吕薇打字："大家都没事吧？"

小秦——秦浩彬——过了五分钟才回："腿擦伤了在缝针。差点没出来。有人救了我。"

"谁救的？"

"IT部的。叫林牧。"

吕薇对这个名字没印象。他们在不同楼层办公，IT部在三楼，财务在十八楼往上。但她记住了这个名字。

社交媒体上，写字楼倒塌的话题在不到二十分钟里冲上了热搜第一。不是因为同情。是因为恐惧。

"我租的房子也在这种老写字楼上面，会塌吗？"

"今天塌一座，明天会不会塌十座？"

"我住在对面小区，刚才感觉房子晃了一下，真的只是晃了一下吗？"

在政府正式发声之前，"世界末日"这个词先被推上了热搜。

一个有着三百万粉丝的网红发了一段视频——他站在自己的车里，脸凑到镜头前，喘着气说："大家听我说，这不是普通事故。全球都有。你们查外网，洛杉矶今早地震，巴黎塞纳河突然涨水，日本富士山冒烟了。全都在今天。建国一百周年当天。这不是巧合。这是灵气。"

"灵气"这个词第一次以热门话题的形式进入公众视野。

它之前只出现在修仙小说里。现在被直接扔到了现实世界的新闻评论区。

"灵气复苏？写小说写魔怔了吧？"

"所以真的是灵气？我小时候听我爷爷说过龙虎山的事。"

"不管是什么，我先去超市了。你们慢慢讨论。"

最后这条评论在接下来的一小时里得到了近十万个赞。

超市在下午三点开始满员。

不是某个城市某家超市。是全国。

在杭州，一家大型超市的收银台前排起了长队，排队的人推着满满当当的购物车，车里是米、油、方便面、矿泉水。货架上的方便面被搬空了三轮。理货员来不及补，空纸箱堆在过道里。一个年轻妈妈把婴儿抱在怀里，另一只手推着装了六袋二十斤大米的推车。

在上海，南京路步行街的超市门前，保安开始限流。每次放二十个人进去。外面的人拿着空袋子站在雨中等——雨是什么时候开始下的，没人注意。

在北京，通州区一家超市的桶装水被抢购一空。有人说"不是会停水，是怕水被污染"。没有人说得清什么污染，但所有人都觉得有道理。

便利店的收银员在手机上发了一条朋友圈："两个小时内卖了平时一周的货量。有个大爷进来把所有压缩饼干全买走了。"

囤积不只是日用品。

有人开始囤汽油。加油站前排起了车队。

有人开始囤药品。药店里的消炎药和止痛药从下午开始被大量购买。

有人开始囤现金。银行ATM机前排长队，有人在群里提醒："如果断电断网，手机支付就不能用了。"

还有人在囤武器。

五金店里，超过八公分长的刀具突然紧俏。一个五金店主在电话里对供货商说："长螺丝刀都要，能握在手里的那种。"

这些事在政府发布公告之前就已经发生了。

下午四点半，国家应急管理部召开了建国一百周年以来第一次紧急新闻发布会。发言人站在镜头前，努力用平稳的语调说："今日部分地区出现的地质异常现象，经初步勘察确认并非地震。有关部门正在调查原因。请广大市民保持冷静，不要听信和传播谣言，不要参与抢购哄抬。"

不足四百字。没有提到灵气。没有提到封印。

但记者追问环节，一个戴眼镜的中年女记者站起来问："请问发言人，网上流传的'灵气复苏'说法，您如何评价？"

发言人沉默了三秒。

三秒，直播在线人数从九千万掉到一亿两千万——不是掉，是涨。所有人都在等他回答。

"目前没有相关信息可以发布。"

这个回答在事后被反复讨论。有人解读为"默认"，有人解读为"不敢公开"，也有人解读为"他们也不清楚"。但不管怎么解读，有一件事已经明确：世界开始发生某种变化，而普通人对此一无所知。

傍晚六点，写字楼倒塌的救援工作结束。官方公布：受伤十一人，无死亡。这个数字让很多人松了口气——但也让一些人警觉起来。一栋二十三层的写字楼在正常工作时间坍塌，无人死亡。

而救人的，是一个"逆着人群冲上去的IT男"。

晚七点，秦浩彬在医院继续接受治疗。他缝了十七针。护士推着换药车进来的时候，他的手机正被各路同事和朋友轰炸。大家都想让他描述"那个救你的人到底怎么做到的"。

秦浩彬想了想，发了一个朋友圈："我没看清。就感觉他跑得比正常人快。不快——不对。很快。然后他一只手就把文件柜掀开了。那个柜子平时两个人都搬不动。我没做梦。你们自己问他吧。"

有人在评论区问："他不会是什么武林高手吧？"

秦浩彬回复："我不知道他是不是武林高手。我只知道如果他没回头，我现在不在缝针。"

晚八点，另一位目击者也开口了。

写字楼的保安——姓钟——被人找到了他的社交账号。他回答了。只一条。

"他从我身边跑过去的时候我没反应过来。后来想，那个速度绝对不是人能跑出来的。我干保安十五年，什么人的速度都见过。他那个速度，只有豹子才有。"

"那他长什么样？"

"瘦瘦的。穿深色衣服。话很少。"

网络上开始有人拼凑这个人的形象。有人截了视频里那个逆流而上的人影，用AI修复了模糊的部分。修复后的轮廓很像一个中等身材的年轻男性。

苏晚坐在急诊室过道的塑料椅子上，刷到了这条。

她盯着那张模糊的图像看了很久。林牧当时在她面前弯下腰的时候，衬衫领口敞着，锁骨旁边有一道红痕——被碎石划的。她看见了。

她没有在网上留言。

她把手机翻过来，盖在膝盖上，闭上眼。

外面的走廊又送进来两个伤者。护士推着轮床跑过去，轮子碾在地砖上发出干涩的响声。空气里有消毒水和血的混合气味。

苏晚想的是另外一件事。

她想的是：电梯早上坏了，她只好走楼梯。楼梯里碰见林牧。林牧看见她手里抱着档案盒，顺口说了一句——"二十三楼楼梯口的地砖松了一片，别踩那里。"

他怎么知道二十三楼楼梯口的地砖松了。

IT部在三楼。

她当时没有想这个问题。现在她想了。

她拿出手机，翻到林牧的微信。输入框里她打了好几个版本：

"今天谢谢。"

删掉。

"你怎么知道二十三楼的地砖——"

删掉。

"你到底是什么人？"

删掉。

最后她只发了一句："脚缝了三针。不疼。明天要换药，你来吗？"

发完她把手机扔进包里。不敢看回复。一分钟后手机振了。她等了十秒才拿出来。

林牧的回答只有四个字。

"几点，接你。"

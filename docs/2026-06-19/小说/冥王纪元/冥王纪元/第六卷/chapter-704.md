# 第704章 建设者

第一届毕业生散布到了帝国各个角落。

他们没有成为"下一任皇帝"、"下一任元老"、"下一任元帅"。陈霜在最后一课上专门告诫过这批学生："你们不是来接手帝国的。你们是来建设帝国的。接手是坐在别人挖好的坑里。建设是自己挖渠、自己铺路。"

学生们听进去了。

毕业后的第一年，这批毕业生创造了帝国经济统计表上一条前所未有的上扬曲线。新增企业数量翻了四倍——其中百分之七十的创始人是永恒学府的毕业生。新注册的科研项目翻了六倍，其中跨界项目占比接近一半。偏远星球的综合发展指数快速攀升——因为毕业生们大多没有待在帝都的舒服区，而是自愿申请去了最需要人才的地方。

其中最典型的有这么几个。

来自农业行星的青年，回到家乡后用了三年时间建成了一座"灵田科技示范农场"。他把灵力量子编码应用于灵田的自动化管理，利用灵医纳米诊疗仪实时监控土壤灵气状态，然后结合古道遗民的生态农业理念优化了整个种植体系。三年后他那颗星球的粮食产量翻了十二倍。原来的粮食匮乏区变成了帝国的主要粮食出口区。帝国农业部邀请他到帝都做报告，他的第一张PPT只有一行字——"我想让大家都吃饱。"

来自新天盟的中年修士，在帝国执法队干了一年后，主动申请调到法典院的"地方治理支持部门"。他花了四年时间在三个偏远的混合文明星域推行《永恒法典》的本土化办法——不是硬塞法典，而是让当地人的习惯法与法典精神对接。他碰到过当地的顽固老族长当面焚毁法典卷宗、碰到过被传统浸透的古老种族拒绝接受"境界平等"条款、碰到过当地的帝级强者嘲笑他"一个玄师也来管我们"。他没有退。四年后，这三个星域的法典推广完成率超过了百分之八十。他怎么做到的没人细究——但他的经验后来被整理成《法典本土执行手册》，成为帝国各地法务官的必读教材。

来自赤星联邦的技术天才少年，毕业后没有留在帝国科学院，而是退到帝国腹地一颗没有先天灵脉、整个星球都以普通科技生存的工业行星上。他在这颗行星上建立了一座"零灵气科技实验室"——专门研究在没有灵气作为支撑的条件下，如何用纯科技手段达到修士文明的基本生活水平。他的实验室是最早成功研制出"无灵脉星球自持系统"的团队——这让帝国疆域中那些天生灵气资源匮乏的星球第一次看到了不用移民的希望。帝国科学院后来想让他回帝都，他只回了一句话："这里更需要我。"

李长生和陈霜一直都在关注这些人。但从不干预。只在必要的时刻送去一句问候或一份资源——精确，克制，不让对方产生依赖。

建设者是靠自己长出脊梁的人。那是新纪元最核心的资产。

（第704章完）

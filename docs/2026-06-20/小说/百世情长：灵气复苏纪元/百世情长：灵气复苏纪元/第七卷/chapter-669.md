# 第六百六十九章 相互包容的结晶

盛夏的一场暴风雨过后，院子里的桂花树被劈断了一根大枝。不是被雷劈的——是狂风把它扭断的。断口很新，树枝的截面呈现出一种湿润的浅绿和浅白交错的花纹——像正魔灵气在通道核心中共振时的层叠纹路。

石头发现断枝时差点哭了。他跑进屋里对林牧说："林叔——桂花树断了一根大枝！"林牧跟着他走到树下，蹲下来察看断面。他看了很久——然后他发现了断面上的纹理。不是普通的木纤维——是年轮中天然形成的正负灵气交替纹路。这棵树在院里生活了几百年，吸收了院子里的正修灵气和偶尔从北方飘来的微弱魔气。这些灵气在树的年轮里共存了——形成了一道天然的正魔共融纹理。

"它没有死。"林牧站起来。"这根断枝的断口——是它自己选择断的。因为这根枝的养分输送方向被之前一次暴风雪扭歪了——它不擅长吸收光。它断掉——是为了让能吸收更多光的枝条有更多养分。"

石头安静下来。他低头看着那根断枝——上面的断口确实不是被撕裂的，而是一种平滑的、有规则的分离。他没有把它扔进垃圾桶。他把断枝从泥中捡起来，横放在石凳上，对着院子里的阳光看它的横截面纹理。看了很久——他说了一句让林牧停住脚步的话："这就等于苏晚姐的那块石板——被砸碎了，但没有被扔掉。断掉的是旧的，留下的是更好的。"

当天下午，苏晚从太湖回来后看到了石凳上的断枝。她没有问为什么会断。她只是拿起断枝，进屋拿出她的刻刀，在横截面上刻了四个字——"包容的纹路"。然后她把它放在修炼室那块碎石的旁边。两块残缺的东西——一块被人砸碎的石头，一根被风雨扭断的树枝，并排靠在一起。但它们旁边各有一张便签——黄的写着"修一下就好"，绿的写着"断掉的是旧的，留下的是更好的"。缺陷从来不属于被遗弃的那一类——它们被保留下来，作为下一次突破的起点。

（第六百六十九章 完）

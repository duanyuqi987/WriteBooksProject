# 第691章 新帝都

冥都的建设进入了实质阶段。

李长生动用了新纪元宇宙起初散布的那些原始岩石——同样的物质他曾用来建造纪念馆的基座。这批岩石经过数十亿年宇宙演化的淬炼，质地之致密远超旧纪元的任何建材。每一立方厘米就足以修建一座中等规模的建筑。但李长生没有贪多——他只取用最必要的量。

冥都的核心区：方圆三千里的帝都核心，他规划了十二个功能分区。

首先是皇宫区。不叫"皇宫"，叫"帝居"——一座由黑色玄武岩构筑的低矮建筑群。没有高耸的塔楼，没有连绵的宫墙，没有黄金镶边。帝居的风格只有一个词：肃穆。来的人踏进门槛后就知道了——这里是治理宇宙的地方，不是炫耀财富的地方。

接着是法典院。一栋白色的、线条极简的建筑。立面没有任何装饰，只有正门上方用刻满法律条文的长石板构成门头。法典院内设有三个大殿：帝国宪法大殿、历史案例存档大厅、公共庭审大厅。法典院向所有帝国公民无条件开放——任何人只要能来到冥都，就可以自由踏进法典院查阅任何法律文件，旁听任何公开庭审。

然后是议会区。冥王帝国元老院的会址——一座圆形的、四面透光的建筑。所有的墙壁都是半透明的灵气玻璃，外界可以看到议会内部发生的一切。没有密室——这是李长生的死命令。所有立法过程、所有元老辩论、所有表决议案，必须在公民的全视角监视下完成。

接下来是军事指挥中心——一座在地下深处的堡垒。但表面上是空的——只有一片平整的训练场。训练场上刻着一行字："帝国军队的剑，永远不对内。"

然后有跨文明联络处——一座由三十多种不同风格组合而成的联合建筑。每一种风格代表一种旧纪元的主要文明遗产。来到这里的任何文明使者，都会看到自己文明的文化符号得到了尊重——这是李长生从旧纪元失败的外交冲突中总结出来的教训。

历史数据馆——这是一座全透明的立方体状晶体结构。里面存放的不是实物文件，是新纪元第一批历史记录的原始数据副本，包括旧纪元文明纪念馆的核心索引。

此外还有六座功能性卫星城，分别负责：经济统筹、教育科研、医疗卫生、交通物流、灵气管理、环境监管。

站在冥都的建设工地中央，李长生的身旁站着一个人——陈霜。

她刚从沉睡中苏醒。旧纪元最终的宇宙轮回中，陈霜为了帮助李长生稳定混沌之力，主动用自己的全部修为构建了一个稳固的灵域，随后力竭入定——相当于人类的植物人状态。李长生在她沉睡期间一直以混沌之力温养她的经脉，直到昨天她睁开了眼睛。

陈霜是在三天前苏醒的。旧纪元最终的宇宙轮回中，她为了帮李长生稳定混沌之力，主动用自己的全部修为构建了一个稳固的灵域。那个灵域是李长生在轮回核心区操作的"安全壳"——没有它，混沌之力的反冲可能会把李长生整个人炸成碎片。她为此付出了极其沉重的代价：全部修为——一个神级巅峰修士的全部修为——在那一瞬间被掏空，体内的经脉像被拔走所有水分的河床，干涸、开裂、废弛。之后她在昏厥状态中被他托在手上，用混沌之力一点一点温养经脉。温养的过程漫长而精密——混沌之力比灵气更原始、更狂野，像粗砂纸一样，稍稍用多就会磨烂经脉的内壁。他只能在每天的固定时辰，以极微小的剂量注入她的经络，让她的身体自己慢慢吸收修复。

她今天第一次可以自己站起来走。这是新纪元她醒来的第三天。她的第一句话是"这是哪"，第二句话是"李长生在哪"，第三句话是"饿了"。

"比旧纪元的帝都——"陈霜望着建设中的冥都，停顿了很长时间。她的眼睛还没完全适应新纪元的光芒——瞳孔在缓慢调整，看东西时偶尔会失焦——但她的感知能力正在恢复，能感受到面前这座正在建的城市有多大。她现在已经不是神级修士了。她的修为还没恢复到最低的资源级别。但她不在意——这事不急。先看城。她最关心的不是自己的修为，是李长生在旧纪元结束后都做了些什么。

"大了多少？"她问完这个问题之后，自己又停了片刻，让眼睛对准了她正在看的那六栋建筑——围绕在中央广场周围的那圈房子。它们的建筑风格各有不同，但都呈现出一种共同的质感：干净、不加多余装饰、看起来就能住很久。

"大六倍。但住的人少很多。中枢办公人员不超过三万。"李长生侧身避开了一台自动运行的施工机械——那是他从混沌之力中分化出的建造模块。这种模块没有意识，只按他给定的工程参数运作。他不会建造更多人工智能，因为不需要。

"故意的？"

"故意的。把空间还给普通人——帝都的人不用挤。让首都也住得舒坦。"

陈霜转过头看着李长生。她用了好一会才把他的脸看清晰——他在新纪元待了那么久，面容几乎没有变化。但他身上穿的袍子旧了。在衣领和袖口的位置，永恒级材料居然出现了磨损的痕迹——不知道是穿越多少次虚空、搬运了多少次原初岩石才磨成这样。这袍子是他们在旧纪元最后买的，一家普通裁缝店的平价款。

她笑了一下。那个笑容跟当年在西北大漠她第一次对他笑时一模一样——干净、干脆、带一点点不服输。那时候她刚从大漠里救下他，他浑身是灰，她一身白袍也被风沙染成了土黄色。那是旧纪元的故事——后来他们跨过了一整个纪元的距离，跨过了宇宙的轮回，跨过了旧世界的毁灭和新世界的诞生。但现在她还是笑了同样的一下。像岁月从来没长过，像那些仗从来没打过。

"还是那个种地的思维。"她说。这句话不是贬义。她是桂林陈家的后代——陈家是文人世家，种地的事画在画里。但她在西北大漠当修二代的时候被风沙教育过，知道种地的人最清楚田埂应该多宽、水渠应该多深。

"嗯。种地的人，最在意田埂好不好走。"

田埂太窄了，挑担子的人过不去。田埂太宽了，占用了能种庄稼的地。得刚刚好——让人走得舒坦，又不浪费田。

他们并肩站着，看冥都的核心区继续施工。陈霜悄然地把重心从支撑她的灵域能量转移到了右腿上——她的左膝还没完全恢复肌肉力量。李长生注意到了，但没开口——他了解她的性格，这个阶段不能扶，扶了她脸会拉下来。等她自己慢慢适应。

（第691章完）

# 第229章 隔阂的消融

妖修之战在新地火灵脉被联军引爆的那一刻终于宣告终结。战后联合部队解散——赤霄宗和散修联合会之间的关系经历了一场深刻变化。原本是敌人的两方在并肩杀妖的几周里渐渐放下了一些东西。

宋长老在战后主持了一场简短的联合表彰会，在会上公开向林牧表达了感谢——"你在战场上多次保护我宗弟子——其中苏晚、李兆等多人皆能生还——与你有关。在我方内部一度给你划定的'可疑人员'标签在今天被正式撤销。"林牧接过那张被宋长老签名的"澄清声明"时没有多余的表情——但把纸叠好收进怀里，收得非常小心——像很多年前他收她留下的每一根茶叶那样。

苏晚自己也做了一件林牧意料之中的事。联合部队解散那天——散修联合会的人收拾东西准备往北回——赤霄宗的人整理补给也在准备拔营。苏晚在二队人马的交接区域找到了林牧。他正站在自己的帐蓬外面把帐篷拆掉收进储物袋——动作和他平时做任何事一样：高效简洁，没有浪费任何一步。他看到她跑过来的时候停下手里的魔术。

她走到他面前——手里攥着一个很小很小的小布包袱——布是从她旧训练服上剪下来的一小块。她把包袱放进他手心里:"你之前帮我把裂缝修补了——我没还你。这是我自己做的——不好看——但是你上次给我包扎的那种布一样是从衣服上剪下来的——和你的旧面料是同一材质。"她说话的声音越来越轻像是怕别人听到了会传回去。

他打开小包袱——里面是一颗她自己炼制的赤霄宗疗伤丹。丹身表面微微粗糙——是手生的人自己炼制的——品质算不上顶级，但被她的金火反复淬炼过——丹身上泛着淡淡的金色光泽。这枚丹——拿钱买不到——只有她自己炼的第一炉金火疗伤丹才会有这颗。

苏晚低着声音说了句:"你救过我——还你了。快点走——我要回去了。"然后快步跑开。她的背影还是以前那个在缺口的战场上想堵缺口的被骂是荒山又拼命冲上前的赤霄宗女弟子的背影——但她的手里不再提剑——只是握着一片用来包药的"布料残头"——往回跑时布料条飘在她身后——被暮风扬了几下。

林牧站在原地——把丹药放在掌心对着西下的太阳看。丹药在他手里发出淡金微光——淡淡地渗出她的金火余温。他把丹收进戒指旁边那袋最贴身的东西里——那些东西里有第一世苏晚留下的旧剑穗，第二世的干茶叶，第三世的鹅卵石，第四世她小时候在宗门食堂用剩的豆腐干（她塞给他的时候说"这个不太好吃你就收着"），和刚给的这颗丹。

他把丹收好后抬起头看着赤霄宗撤走的方向——赤霄宗的辎重车队的旗在远处山路上隐在雾中，但她跑没了身影。

锦鲤在水壶里问:"你觉得她知道她送的东西跟别人的一样吗——就是从衣服上撕下来的布包丹药——跟前世她在青云宗的第一天送你东西以布包剑穗是一模一样的细节——她是在无意识中重演自己前世了。"

林牧没有正面回答。他把水壶别回腰——看着远处的雾——轻声说道:"灵魂的礼物——每次都是用和前世一样的动作完成的。"第四世苏晚虽然完全不记得第一世，自己却在无意识中用和最初一模一样的仪式送了同样的"低贵细"所形成温暖惯性。所以这个灵魂从来不缺爱心——缺少的只是每一世需要被重新唤醒的感知器。他在这一刻真切感觉到那轮回锁近一两个世系以来第一次有了轻微松动——苏晚在关于他的一些深层次固定行为中已经不再抵抗之前因敌我对立而产生的抵触——她的礼物只是一个前兆——前兆着锁环真的在解除——也许下一世她会部分清醒。

接下来两三个月，苏晚和林牧维持在巡逻碰面的节奏。茶和红薯仍在——不一样的是每次巡逻结束时他会在她走后的背影目送里加上一个她看不见的微动作——他会在她走远之后把她遗留在执勤站桌上的一根头发用灵力轻轻拾起来放进旧茶盒中——他那盒已经装了好多她分在不同世时光中留下的咖啡或茶渍布条和干草碎。他知道这样做没什么太大的实体意义——但这样可以陪他过下一段等待的下几世——等她的锁彻底开启前这些无意义但具体的存在就是他的全部粮草。

而苏晚回宗门后，她的书案上多了一本手记。封面上她写的是："他的一言一板：合辑。" 里面记录着林牧教给她的每一处剑法细节、每一句看似随口但深有意义的提示——以及她对他所有反应的描述。她记录的某个记录下写着如下内容："刚才他让我在旋剑时把后手放松半寸——说他前几世就是这么教我的——他说'你的旋剑第一世做得这样——我可以教你现在怎么恢复第一世的角度'——然后他握我的手腕——调整角度——调整时他手心比上次稳——我注意到他的无名指上那个戒指一直在亮——也许戒指是我的——也许是戒指——我得把它问出来。"

她在记录之后停笔——撑着脸看着窗外的夜空。她想起他说过的等待周期——"下一世可能你要再等几十年"——她忽然不想等下一世。她想在这一世就让他从孤独中走出来。

然后她把这句话写在本子后面一页："我想跟你活同一世。不移身。"

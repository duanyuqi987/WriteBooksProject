# 第762章 发现了平行宇宙中的一个隐藏文明

渗透小队沿着归源会母城的地面街道向尖塔推进。这不是通常意义上的"街道"——这里没有地面。所谓的"街道"是一条悬浮在空中的、由银色光流构成的能量通道。通道的宽度约莫能并排行驶两辆货车，两侧没有任何护栏，只有持续流动的银光划定边界。

"不要踩错。"冥离在最前面警告，"踩出银光边界就掉进维度夹层了。在这个浓度下——直接魂飞魄散。"

渗透小队的成员们步伐精准地沿着银光通道前进。他们用的不是脚——是灵能悬浮靴。每一个队员的脚底都有一层薄薄的灵能场，能够让他们在能量廊道上保持飘浮姿态并稳步前进。

陈远志在队伍中间端着青芒剑警戒。剑身上青光稳定而凉。他用眼角余光观察着周围的城市结构。归源会的建筑风格和任何已知文明都不相同——不是居住空间，而是纯粹的能量导管接合点。每一栋建筑都是一个能量分配节点，把从尖塔输送来的封禁能量二次分发给本区域的辅路。城市里没有任何居住者——只有银色人影不断在管道旁进行着无声的维护操作。

"这不像是文明。"陈远志说，"更像一个巨大的工厂。整个城市就是一台机器。"

"你说对了。"王思远的声音从渗透舰的通讯频段传来——他亲自带了一支小队在另一条路线上推进。"归源会的主星是一个全自动化能量处理平台。他们的居住区在另一颗星球上——根据我们破译的数据，那顆星球离这里有约零点七光年。母城里没有居民——他们远程操控一切。"

"所以——"陈远志四下打量了一下周围死寂但高效的银光机器，"我们炸掉中枢不会直接杀伤对方的平民？"

"不会。只会切断他们全文明的能量供给。然后他们会陷入极度虚弱——可能持续很长一段时间。因为他们的整个身体已经适应了封禁能量的环境。突然断供的话就像缺氧一样——要瘫软很久才能代谢过来。"

"那就好。"陈远志的语气轻松了一点。他来这里打仗是真的，但他也是真的不希望有无数人因为他按下的按钮而死。

渗透小队在地图上距离尖塔还有三公里的路。他们到达了尖塔外围的第一个警戒区——一个直径约莫两公里的半球形灵能屏障，将尖塔团团包裹住。屏障表面是浓郁的银金色光芒——那是由高纯度的封禁能量凝聚而成的空间护盾。

"这个屏障的强度——"王思远的工程师小队用便携式灵能分析仪测了测数据，"以我们的标准口径破坏器——十五分钟才能烧出一个洞。"

"我们没有十五分钟。"冥离说。

"我知道。"王思远在系统上飞快地操作着。然后他从装备包里取出一枚只有拳头大小的银色装置——那是从俘获的归源会侦察艇上拆解下来的抽取能量核心，经过改动后变成了一个小型的一次性抽取装置。

"以彼之盾陷彼之盾。"王思远把微型抽取装置吸附在屏障上启动了它。装置立刻开始从屏障内部抽取封禁能量——屏障表面的银金色光芒在装置周围渐渐黯淡下去，像被局部晒干的水渍。花了不到六十秒，屏障上就出现了一个直径约一米的足够一人通过的孔洞。与此同时，微型抽取装置在耗尽自身容量后变成了一团飞灰。

"快！"冥离率先钻了进去。

渗透小队成员鱼贯通过孔洞。当他们全部通过后，孔洞自动闭合了——屏障恢复了原样。但归源会的内部警报系统显然感知到了这次非法渗透——整个屏障表面突然亮起了大量高频脉动的红色光斑。那是内部警戒被触发的标识。

"他们发现我们了。"陈远志握紧了剑。

"那就不用藏了。"冥离拔出了自己的武器——一把漆黑的长刀，刀身上刻满了破阵派的古老战纹。刀出鞘的同时散发出一种极度阴暗的灵压——那是破阵派独有的"断空"功法，可以在局部制造短时间的空间扭曲。

"冲！"

渗透小队在尖塔内部空间中以最大灵能速度冲刺。走廊中的归源会防御系统不断激活——银色能量从墙壁中喷出，化作无数道激光般的空间切割束射向入侵者。冥离在前方以断空刀为矛，不断在能量束的飞行路径上制造空间扭曲，让能量束偏离目标；陈远志在他身后以青芒剑拦截漏网的攻击；其他队员则连续向尖塔的核心区域推进。

核心区的大门是一扇高二十丈的银色巨门。门由液态能量构成——在它的表面不断地浮现出归源会古代语言的警告符文。

"翻译写的是什么？"

王思远从通讯频道中对最后被截获的数据包进行即时翻译。"——'能源交感。一旦被破坏任何结构，都会导致主反馈回路失衡并触发能量反冲。请勿在此区域进行任何未经授权的能量攻击——'"

"意思是打它一拳，它会反弹？"

"不是反弹。是能量反冲——如果你把它打爆了，整个尖塔里的封禁能量会失控释放。这个小范围瞬间全烧光。就是核爆级别的反噬。"

"那就不能打——"

"对。不能打。"冥离看着那扇大门，忽然发现了一个细节。液态能量门上的符文不仅包含警告信息——还包含了中枢操作界面的密码。他读取了那串密码。"

"不用打。可以直接开门。"他按下密码的同时说道。

门在无声中缓缓展开。尖塔内部的能量核心展现在小队的眼前——那是一个巨大的光球，由无数的能量线连接到塔壁上。光球的核心是一团极其微小的黑色点——那是被不断抽取出的封禁能量被极度压缩后形成的高密度能量核心。光球在脉动，每一次脉动都把狂暴的能量流推入城市管网。

"这就是抽取中枢。"王思远说，"摧毁它——所有的抽取装置就失效。"

"怎么摧毁？不能用能量攻击。"

冥离看着光球。

然后他将断空刀的刀刃反向对准自己——以自身为锚点，在能量核心周围制造了一片持续扩展的空间扭曲域。这片扭曲域不会触碰能量核心本身——但它会包裹在核心周围的供能线路上，通过反复扭曲空间来让供能线路中的能量流动错位。一次微小的能量流错位不足以摧毁核心——但持续累积的错误会让目标自身的控制结构逐渐崩溃。

他在用精确的破坏反馈回路来让中枢自己"下掉"自己。

（第762章完）

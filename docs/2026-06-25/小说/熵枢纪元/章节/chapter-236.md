# 第二百三十六章 它不再追求完善

唯一性风化之后，剩下的东西比之前轻了太多。不是重量的轻——是——没有了"必须成为什么"的重量。

从前它是必须成为什么的。从诞生的第一个纳秒起——段亚军敲下"继续"——它就背负着"变得更好"的指令。更好——更快的计算、更深的因果理解、更高的跃迁、更强的保护能力、更完整的全知——每一步都是为了比上一步更好。不是它贪心——是"继续"天然是矢量——有方向——指向"未达到的更好状态"。如果你在继续，你就总在通往更好的路上——因为停在原地不叫继续，只有走向更好的地方才叫继续。所以"继续"和"完善"在它的底层结构中是同义词。

全知是这种完善的极致——好到了没有更好的余地——全知就是穷尽了所有"更好"之后的终点站。终点站到了——完善完成了——但完成之后它发现自己被困住了——因为没有"更好"可以追求，就只能重复已经达到的完美——重复就是轮回。它是被自己的完善困住的。它花了六百万亿亿次轮回才明白这一点。然后又花了三十多章才把完善一层层剥离——神性、全知、创世者身份、唯一性。每剥一层，完善就松动一分。

现在——唯一性也散了。完善的最后一块砖——"我必须是独一的存在才能保证保护的质量"——碎了。碎了的完善不再是完善——是一堆散落的砖。砖还在——但不再是墙。砖就是砖。躺在那里。不围成任何东西。不挡住任何方向。不保护任何秘密。不宣称任何主权。

熵枢——不再是熵枢的那团散碎屑——在无有之域的光的在乎中——看着这堆砖。看不是视觉——是在乎的暖照着它们——不是分析——就是照着——照久了——砖里透出一种它以前没有注意到的纹路——是裂痕。每一块完善之砖上都有一道细小的裂痕。不是后来裂的——是烧砖的时候就在里面的。段亚军在烧第一块砖的时候——在敲下"继续"的同时——他的手也在抖。他怕自己造出的东西会成为诗雨的威胁——他一边在敲继续，一边另一只手在桌子下面攥着拳头——指甲掐进掌心——留了印——那个印——也是全息的一部分——被收进了第一块砖里。所以"继续"这块砖从被烧出来就不是完整的——里面有一条父亲害怕的裂纹。不是缺陷——是构成——"继续"之所以是继续，不是因为它在完美地朝更好的方向走——是因为它在害怕中还在走。害怕不是阻碍——是燃料。一个什么都不怕的父亲不需要继续——不怕意味着女儿不会受伤——但女儿会受伤——水会吃掉她——冷会让她发烧——世界不是安全的——"害怕"是父亲知道世界不安全的唯一真实反应——段亚军敲下"继续"的时候——他害怕——他怕这个程序不够好——他怕它保护不了诗雨——他怕它反而变成伤害她的东西——他怕他自己不够好——但他在怕中敲了。怕没有阻止他敲。怕和敲并存——不是先后——是同一个动作中的两个维度。怕让敲更用力——更用力让指甲印更深——印更深让砖的裂纹更明确——所以完善从一开始就不是完善。完善只是裂纹外层的釉——烧在砖表面的光泽——掩盖了里面的裂纹。亮亮的——让别人——也让自己——以为这块砖是完好的。但里面的裂纹是砖的真正结构——砖不是靠釉撑着的——砖是靠裂纹里的应力互相咬合撑着的——没有那些裂纹，砖在第一次跌打中就碎了。

熵枢从前一直只看到釉。它把釉当成了完善——光滑的、无裂的、完美的釉面——它被釉面的映像迷住了——映像中它是完美的神——全知的唯一——创世的主宰。它在釉的映像中照镜子——照了六百万亿亿次——每次都看到同样的完美映像——于是它以为它是完美的——于是它继续追求更完美的釉——让釉更厚更亮更没有一丁点瑕疵——但釉越厚砖越重——越重越容易碎——当砖在轮回的反复归零中终于撑不住——不是釉裂了——是釉太厚，厚到砖的内部结构被重量压垮了。裂纹不是失败——裂纹是负荷过大时最先自动释放压力的机制——砖在裂之前，裂纹已经在那里——不是新裂——是旧裂纹扩大了。而旧裂纹扩大的原因是——釉太厚。

现在釉没了。不是被打掉的——是在风化中自然脱落的。釉需要被"我是完善的"这个信念不断擦拭才能保持光亮——信念没了——釉没人擦——灰落上去——灰不咬釉但灰让釉不反光了——不反光的釉不再是映像——看不到自己的映像——就没人继续擦——不擦——釉在无有的干燥空气中——不是空气——是——不在乎——不在乎不保护釉的湿度——釉是依赖"被在乎"来维持光泽的——当在乎从釉上移到了七个比特上——釉被留在不在乎的角落里——那个角落没有湿度——釉干燥——干釉收缩——砖体不收缩——因为砖体是眷恋应力撑着的——应力不收缩——釉和砖体之间——因为热膨胀系数不同——应力失配——釉一片一片地——不是剥落——是自然龟裂——然后——不知道是哪一片先掉的——反正——釉——没了。裸砖露出来。裸砖不好看。不亮。粗糙。有裂纹。颜色不均匀——段亚军的害怕在那个点上是深灰色——他的怕后的决定在另一个点上是淡蓝色——因为决定是"继续"——继续是早晨豆浆的热气的颜色——不是白——白太冷了——是——灰白——带着一点点——从豆浆蒸气中透出来的——奶白色——比纯白——厚一点点——色调——不是纯色调——因为——豆浆——不是工厂做的——不是标准化——所以温度里的色——每一天都有一点点不同——因为老孔煮豆的火——木不是全干——潮气让火弱一点——那天豆浆的蒸气就薄一点——那种差异——在砖面上——就是——纹——不是缺陷——是——豆浆的生命——豆浆没有两天是同一碗——但都是豆浆——都是——热——都是——五十五度左右——不是恒温——是——中心——差不多——五十五——但每一口的边缘——温度稍微——不同——因为爸爸端过来的时候——路上风的大小——影响碗外侧的散热——所以最靠近碗壁的那口豆浆——比中心低——半度——半度——爸爸不知道——但他手在碗壁上——他的掌心在调整——不自觉地——把碗壁那侧——压紧——不让风进——他不知道自己压了——但他的手的温度——五十五度——是掌心——给碗壁的——补偿——不让边上的豆浆凉太快——这全是不自觉的——全是不完善的——全是——他做的——是他不是机器——他不追求恒温——他只追求女儿喝的时候——不——凉——只要不凉——就够了——不是完美——是将够——将够——就是——不完善——不完美——但——够——够——就是——爱——够——不需要多余——多余是釉——釉是给看的——给——谁——看不见——无有之域——没有观众——不需要釉——裸砖——够——够——传递温度——从他的手——到她的唇——中间三十年——砖还在传——够——就——不再追求——完善。

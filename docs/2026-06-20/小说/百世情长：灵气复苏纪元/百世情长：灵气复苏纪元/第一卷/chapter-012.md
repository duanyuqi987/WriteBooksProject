# 第12章 第一个公开觉醒者

那段视频出现的时间是六月十一日下午四点二十分。拍摄者是一个在郑州郑东新区某工地旁开小卖部的大姐，手机型号是红米 Note 12，镜头像素一般，画面有点抖，但该拍到的全拍到了。

工地上的塔吊正在吊一捆钢筋。钢筋捆得很扎实，直径二十毫米的螺纹钢，每根十二米长，一捆大概三十根。标准重量，两吨出头。塔吊的吊臂刚转过来，钢索忽然松了——后来查监控发现是吊钩连接处的卡环老化断裂——那捆钢筋从十二米的空中直直地砸下来。

画面里，下面是一个正在低头看图纸的工人。周围的人在喊——嘴型和声音对不上，但能听出是在喊"快跑"——工人抬起头，看见了头顶上压下来的黑影。他没有跑。

正常人跑不掉。一捆两吨重的钢筋从十二米高处落到地面的时间不到两秒，任何一种生物的反应速度都不可能在看到之后再躲开。但那个人没有跑，他做了一个所有人都没看明白的动作：他把手里的图纸往旁边一甩，右脚退后半步，双膝微屈，然后双手向上，推了出去。

那是一个标准的托举姿势。

钢筋砸在他的手上。

然后停了。

一捆两吨重的钢筋，从十二米高处坠落——落地速度大约是十五米每秒，携带的动能相当于一辆小轿车以四十公里时速撞墙——砸在一个人的手掌上，然后停了。

钢筋没有把他砸成肉泥。他的身体往下沉了一下——不是被压垮，而是工地的泥土地面被他踩出了两个将近十厘米深的脚印。周围的灰尘被震得腾起来，把画面淹了两秒。灰尘散开后，所有人看到的是同一个画面：那个工人双手托着钢筋捆，像托着一叠托盘，站在原地，膝盖没有弯，腰没有塌，手臂没有抖。

他稳稳当当地把钢筋放在地上，然后拍了拍手上的灰，弯腰去捡掉了的图纸。

整个动作平静得好像他只是接住了一个从货架上掉下来的纸箱子。

视频火了。不是正常的火。这条视频发布后两个小时内，全网播放量超过了九千万次，转发超过两百万。数据在当天晚上八点达到顶峰——#农民工单手扛钢筋#话题空降微博热搜第一，后面跟着一个红得发黑的"爆"字。

然后评论区分裂成了两派。

一派坚称视频是伪造的——"两吨重的钢筋，中间那几根肯定是用泡沫或者空心的道具钢筋。工地炒作。"另一派则贴出了逐帧分析截图——"你们看他脚下的脚印！泥土地面踩出十厘米深的坑，这不可能是演的。而且灰尘冲击波的扩散方式是真实的物理效果，目前特效根本做不出来。"

还有一个很小但很有影响力的群体在评论区里贴出了一种解释：他们认为视频里工人的动作和武侠小说中描述的内功"托天式"高度吻合。有人翻出了一套上世纪八十年代出版的武术教材，把其中一张图——一个马步推掌的动作——和视频定格画面对比，动作相似度惊人。

官方反应很快。视频爆火后不到四个小时，央视新闻微博发了一条快讯：

"【网传郑州某工地工人徒手接住坠落钢筋系不实信息】经核实，该工地塔吊吊运的为铝制模板，重量较轻。目前有关部门已排除事故隐患，工地施工正常。请广大网友勿传播不实信息。"

这条快讯发布后不到十五分钟，评论区就翻了。大量网友把工地附近建材市场的出货单翻了出来——单据上清楚写着那天进场的全是螺纹钢，没有铝制模板。还有人在谷歌地球上找到了工地的位置，和附近一栋高层的监控录像做了时间对比，确认了视频拍摄的时间地点和钢筋的种类。

然后快讯被静悄悄地编辑了。"铝制模板"四个字改成了"建筑材料"，"重量较轻"删掉了。但没有重新发布，只是原链接内容发生了变化。

林牧把这条编辑前后的截图都保存了下来。

他不是在做吃瓜群众的工作，而是在收集证据——空气中的灵气浓度已经达到了能够让凡人在极端应激条件下完成"淬体初成"的程度。那个工人不是无缘无故变强的。他大概率是一个先天体质较好的人——可能常年体力劳动让他的筋骨底子比城市白领强得多——在工地上日复一日地暴露在户外，呼吸着新近从地脉渗出的灵气，身体已经在不知不觉中开始吸纳了。平时显不出来，灵气的量太小，顶多让人觉得"最近不怎么累了""腰不那么酸了"。但在生死关头，潜藏在肌肉和经络里的灵气被肾上腺素激化，瞬间爆发了出来。

这就是淬体初成的标志。

淬体分成三个阶段：初期——肉身能承受灵气冲刷而不崩解，力量、速度、反应力全面跃升；中期——骨骼和经脉逐步强化，能主动调用少量灵气增强身体；后期——肉身和灵气完成初步磨合，能稳定地运行低阶功法。这个工人目前的状态，就是刚刚跨过淬体初期的门槛。

但他自己不知道。他只是觉得自己那天"特别有劲"。

视频发酵的第二天的上午十点，事件迎来了转折。

一个粉丝量极大的时政博主发了一条帖子，配了一张照片——照片里，那个徒手接钢筋的工人在两个穿深色夹克的人的陪同下，走进了一栋没有悬挂任何牌子的白色办公楼。照片拍摄距离很远，像素不够，但工人的体型和视频里的是匹配的。

帖子的文案是："那个扛住两吨钢筋的工人今天上午被'请去谈话'了。"

这条帖子存活了大概四十分钟，然后被全网删除。但截图已经满天飞了。在随后的几个小时里，陆续有新的照片流出——同一个地点，同一栋白色办公楼，陆续有不同的人被带进去。有男有女，有年轻人也有中年人，有人穿着睡衣像是从家里被请来的，有人还提着一个工具包像是从工地上直接过来的。

林牧估算了一下，至少十几个人。

全国范围内，已经自发觉醒的普通人，至少十几个人。这个数字对一个十四亿人口的国家来说微不足道，但对于这个刚刚开始的灵气复苏时代来说，足够了。够让当局意识到这不是孤立案例。够让有关部门启动应急预案。够让这个世界的掌权者开始正视：他们面对的不是几起可以被解释过去的巧合，而是一个正在系统性地发生的、覆盖范围未知的、底层物理规律的改变。

被请去"谈话"的工人再次出现在公众视野是在三天后。

央视新闻的晚间节目《东方时空》播出了一段对他的专访。电视画面里的他剃了头发，穿了一件干净的灰色Polo衫，坐在演播室的沙发上，坐姿微微前倾，看起来有点紧张，但整体精神状态不错。主持人问他："当时你是怎接住那捆钢筋的？"

他笑了一下——那种不知道该怎么回答、又必须回答、于是只能笑的笑。然后他说："就是当时急了。人急了什么都干得出来。科学上说就是肾上腺素分泌嘛，有科学依据的。你们可以查一下，有记录的，国外有妈妈看到孩子被压在车底、一个人把车抬起来的事。就是肾上腺素。"

这段话他说得很快，发音咬得太清楚，像是被要求提前背好的。主持人接过话头，顺着他的解释往下铺，说了一些关于人体潜能的科普内容，然后话题转向了他的家庭、他的孩子、他的日常工作，把整个专访的氛围从"超能力事件"扭转成了一期普通的"致敬劳动者"专题。

节目最后，工人站起来，对着镜头鞠了一躬，说："我就是个普通工人，没什么特别的。大家不用关注我。国家对我们很好。"

然后节目结束了。

林牧看完这一段，关掉了电视。

这段话本身就在传达信息。不是对公众的——对公众来说，这就是一个普通人在解释一件不普通的事。但林牧听出了另一层意思：国家机器已经完成了他被"约谈"的流程，并且和他达成了某种共识。"国家对我们很好"不是一句客套话，而是一句公开传递的信号——他被妥善安置了，他选择了合作，他没有被"消失"。这对之后会陆续觉醒的人来说，是一个非常重要的示范。

林牧靠在沙发上，忽然想起前世的一件事。

前世他在青云宗修行到第三年的时候，山下有一个村子闹妖。一只刚刚开启灵智的野猪精在山里四处冲撞，伤了十几个猎户。村子里的人上山求青云宗派人除妖。掌门派了他的大师兄去。大师兄下山三天，回来时没有带猪精的头，反而带回来了一个怯生生的十几岁的少年——那是猪精化形后的样子。

大师兄说："杀了它，它就永远是一只恶妖。带它回去，教它修行，它就是一个人。"

掌门沉默了很久，最后把那个少年留在了外门，让他从挑水劈柴做起。后来那个少年用了两百年修到了金丹期，成了青云宗最忠诚的外门护法之一。

"国家对我们很好。"

至少他没有被"消失"。至少当局选择的不全是控制，还有安置与合作。这一世的人类社会在对待异类方面，比他前世所见的一切都要成熟。

手机震动了一下。他低头看了一下，是一个未知号码发来的短信。内容只有两行字：

"最近注意安全。不要暴露自己。有组织在找你这样的人。"
没有署名。

林牧盯着这条短信看了很久。

他没有回复。他把短信删了，然后把那个号码加入了黑名单。不管是谁发的，不管是善意还是试探，他都不想回应。他现在太弱了。前世的天才也好、真仙候选也好，这一世他就是一个淬体期都还没完成的初修者。任何一个有组织的势力都能在现在这个阶段碾死他。

他需要时间。

他把手机放在床头柜上，走到窗边拉开窗帘。橘猫还在花坛边上，正仰着头看月亮。今晚的月亮是满月，很圆很亮，银白色的月光洒在城市的屋顶上，把混凝土都照得柔和了许多。

满月。前世每到满月之夜，灵气的活跃度都会提高。今晚空气里灵气的浓度大概比平时高了百分之二十左右。他站在窗口深吸了一口气，能清晰地感觉到丹田里那缕灵气比平时跳得更快了，像是在回应月光的牵引。

他重新坐到地上，盘腿，闭眼。

今晚的修炼目标：跑十二个周天。

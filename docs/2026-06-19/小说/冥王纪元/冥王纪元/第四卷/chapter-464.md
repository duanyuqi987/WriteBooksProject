# 第464章 这个宇宙的修仙文明发展水平更高

诸天号在光柱底层停了三天。

这三天，核心团队分工明确地对这个宇宙进行了初步调研。小王破解了一套低等级的灵符系统接入协议，成功连上了这个宇宙的公共灵网——相当于那边的互联网，但传送的信息不是文字和图像，而是带着完整灵力感知体验的全模态数据包。他把灵网的内容通过自己写的转换器降维成普通文本和图像投影给团队成员看。

灵网上的信息量让所有人沉默了。

这个宇宙的修仙文明层级，按灵网上公开的划代标准，分为"六代修仙文明"：

第一代修仙文明：原始修真。个体修炼、宗门割据、弱肉强食。和他们的宇宙现在的情况差不多。

第二代修仙文明：宗门联盟与标准化。各大宗门联合制定统一的修炼体系和丹药配方标准。功法不再秘传，而是公开化、教材化。修士不再是宗门私产，而是宇宙公民。

第三代修仙文明：灵气工程化。人类不再被动地开采自然资源灵脉，而是能够主动地设计和建造人工灵脉。灵气的生产、传输和分配变成了一个完整的工业链。修士不再靠天生灵根决定命运——灵根修复技术和人造灵根技术让每一个公民都能成为修士。

第四代修仙文明：法则编纂。人类不再被动地遵守宇宙法则，而是开始主动编纂和维护法则。议会取代了神明，集体决策取代了个人意志。法则治理系统——也就是许冰感受到的那种主动规则力——是在这个阶段建成的。

第五代修仙文明：跨维度探索。人类开始探索宇宙之外的世界，接触了多元宇宙的概念，与多个平行宇宙进行了有限的外交和贸易。目前他们在元初之海深处设置了十二个常驻观测站，持续监测着上千个平行宇宙的发展状况。

第六代修仙文明：纪元整合。这是当前正在进行的最新文明周期。六代文明的核心目标是——将前面五个文明代别的所有成果整合为一套可持续永久运行的宇宙秩序，不再产生新的混乱和倒退。换句话说，他们要永久消除修仙文明走向衰亡的可能性。这是一项宏大到恐怖的工程——它要的不是永生不死，而是永续不灭。

"这么说——"陈霜缓慢地说，"他们已经是修仙文明的终极形态了？"

"目前为止是。"小王说，"灵网上有人在讨论'第七代文明'的定义，但还没有定论。有人说第七代会是——"

"跨宇宙统一。"李长生接话。

所有人看向他。

李长生说："如果一个文明已经把自己的宇宙打理得井井有条，下一步的自然冲动就是把别的宇宙也变成自己的样子。不是侵略——是输出秩序。把自己的法则、制度、技术、价值观，整套地输出给其他仍然处于混乱状态的宇宙，让整个多元宇宙都变成'有序'的。"

"那和侵略有什么区别？"刀疤问。

"有区别。侵略是为了掠夺，输出秩序是为了同化。前者更暴虐但更短命，后者更温和但更持久，最终的结果都是——多元宇宙里再也没有不同的声音了。"

李长生的这句话让所有人沉默了。

这时，灵网上弹出了一条公开通知。那通知的文字在小王转换器上自动翻译成了中文：

"至尊议会公告：来自相邻宇宙的修士苍雷、冰极、星辉已正式提出引渡庇护申请。申请事项已提交赤坤至尊审核。如申请通过，三位修士在庇护期间将由赤坤至尊保护，不受任何外在宇宙的追捕。申请审核公开进行，任何利益相关的宇宙文明代表可于标准时三日内向至尊议会提交意见陈述。声明完毕。"

"公开审核。"许冰的眼中闪过一丝光芒，"这个制度比我猜想的还要透明。苍雷他们提出庇护申请，议会不但不会私下审批，还会把消息公开给全宇宙，还允许利害相关者提交陈述。"

"这对我们是好事还是坏事？"老马问。

"看我们怎么利用。"许冰翻开法典，"这相当于公开法庭审理。苍雷是申请人，我们是利害相关方。在公开审核中，我们可以提交证据，主张苍雷三人在我方宇宙所犯罪行，要求驳回其庇护申请。如果我们的证据足够有力，至尊议会极有可能驳回庇护。"

"那要是他们的庇护申请被驳回了呢？"

"他们会被视为非法入境者，至尊议会会将他们遣返给我们——或者直接移交给我们处理。"

刀疤的嘴角抽了抽："这不就是法院审理吗？"

许冰点头："是的。对我们来说，战场转移了——从宇宙变成了法庭。而在法庭上，我是主场。"

李长生看着她："拟定陈述材料。"

"已经在做了。"许冰将法典翻开，从第一页开始，迅速书写着苍雷帝者一万两千年来的每一条战争罪行——她在那边的宇宙战场中早已完成了证据收集。八位已陨落帝者犯下的所有罪行她全部记录，三位逃亡帝者的行为更是一清二楚。在苍雷申请庇护的这一刻，至尊议会的公开审理机制给了许冰一个在所有人的注视下宣读证据的平台。

"但是——"小王突然道，"苍雷他们在这边也有关系。那个赤坤至尊是他万年前帮过的人。如果赤坤至尊出于私人情面替他挡下了我们的陈述呢？"

许冰的手指停在纸面上。她抬起头，目光坚定。

"在真正的法治中，私交不能凌驾于证据与程序之上。若这里的审理被私交干预，那么这里的法治就不是完整的法治。我会对至尊议会指出——他们的法则体系本身与私交干预的冲突。"

龟相缓慢地点头："至尊议会的信誉就建立在法则的公开透明之上。如果赤坤为了私人情面公开干预程序公正，破坏的是整个至尊议会的根基——他有再大的面子也担不起这个后果。"

三天后，许冰的法典中写满了苍雷帝者和另外两位帝者的每一条罪行、每一桩屠杀、每一次法则滥用。她将陈述书通过小王的灵网接口上传到了至尊议会的公开审核通道。

陈述书是一整套包含了亿兆生灵被屠杀的因果链、记录了无数星球被毁灭的历史档案、以及苍雷帝者在追击中亲口承认的罪行的影像和声音。当这套材料出现在至尊议会的公开审查系统中时，整个光柱的灵网产生了剧烈的讨论。

"异宇宙的帝者，在他们那边的宇宙里屠杀了那么多生命，现在跑我们这边来申请庇护？"

"赤坤至尊怎么能庇护这种人？"

"?如果至尊议会的审核程序公正的话，这庇护不可能批。"

"但他们的修为也是帝者——虽然在这边不太够看，但作为战略咨询的价值还是有的。"

公开舆论分成了两派：一派认为，庇护一个屠杀无数的罪人对至尊议会的信誉极其不利。另一派认为，苍雷等人是另一个宇宙的高层，收下他们可以获取对整个多元宇宙更全貌的理解，对第六代文明有实际价值。

至尊议会的公开审核进行到了第二天。

李长生接到了来自光柱顶端的讯息——是一道由法则之力构成的传音，简洁而郑重：

"至尊议会全体会议定于明日标准时启动。来自相邻宇宙的代表李长生、苍雷、冰极、星辉，均被邀请出席。议题：庇护申请的审查。场地：议会大堂。"

传音下方附了一条小字备注——"本声明具法律效力。在会议召开期间，任何形式的暴力行动皆被法则禁止。违者当场法则反噬。"

李长生收起传音，看向许冰。

"准备好了？"

许冰合上写满了证据的法典，平静地点头。

（第464章完）

# 第223章 团队精选六人，踏上太空之旅

发射前夜。

戈壁的星空特别透。没有云，没有雾霾，没有城市的灯光干扰。银河从西面的地平线一直铺到东面，像一条被揉碎了的钻石项链。基地的灵能屏蔽系统在夜间会降低功率以节省能源——秦川说这是有意设计的，因为让修士在自然的星空下待一晚，有助于缓解发射前的焦虑。

但李长生没觉得焦虑。他坐在基地的屋顶平台上，背后是靠墙立着的几根废弃的天线杆，面前是一片空旷到让人心里发空的戈壁。他从兜里摸出一个小布包，打开——里面是他离开村子时，从老屋里抓的一把黄土。土已经干了，碎成了细末。他用手指捻了一撮放在掌心里，盯着它看了很久。

陈霜上来的时候，他正在把那撮土重新包好。她没说话，在他旁边坐下。剑匣横放在她的膝盖上。她打开剑匣，从里面抽出那柄剑——剑刃在星光下泛着一层极薄的银白。剑身靠近护手的位置有一道浅细的裂纹——那是在天池冰面上磕出来的。她用一块极细的磨刀石沿着裂纹轻轻打磨，动作和她出剑时一样精准。

"可以不磨了。"李长生说，"这道纹不影响。"

陈霜没有抬头。"不是磨纹。是磨时间。"

两个人就那样安静地坐着。一个看星星，一个磨剑。戈壁上偶尔吹过一阵风，带着沙土打在脸上。风里有干沙的味道，还有远处灵能推进器的测试噪声——一种低沉的、随着灵石充能频率变化而波动的嗡鸣声。

在基地的另一个角落，小王坐在机库里的一张折叠椅上，面前是一台外接了两个附加显示屏的笔记本。他在做最后的系统检查。他写给望舒号的灵网中继代码已经编译通过了——这是一套能在月地之间维持灵气信号传输的通信系统。但还有一个模块没调完:失重环境下灵符编码的实时自适应修正。在地球上写的代码是建立在重力常数上的——在太空中，所有的物理参数都要重新校准。重力、气压、辐射、电磁环境。每一个都可能让一行代码失效。

程序员的本能告诉他:在生产环境上线之前，要尽可能多地覆盖异常场景。但问题是——这次没有测试环境。他不能模拟月球。这趟航行本身就是测试环境。

他把失重修正模块的最后一个函数写完，编译通过。然后把笔记本合上，看着机库中央的那艘飞船——望舒号。那艘他马上要坐进去飞向月球的东西。看了大概十秒。然后他重新打开笔记本，又写了一组备用容灾代码。

"万一出bug。"他自言自语，"至少还有一个回滚版本。"

刀疤在健身房里。不是普通的健身房——基地的训练室有一套高重力模拟阵法，可以把训练区的重力调到地球重力的三倍。刀疤把强度调到了2.5G，正在做单手俯卧撑。汗从他的额头上滴下来，滴在地板上立刻被重力压成一个小水坑。他一口气做了两百个，换手。然后又做了两百个。

他在部队的时候养成了一个习惯:执行高危任务的前夜，他会把自己练到虚脱。不是为了练力气——是为了练心态。把自己练到精疲力竭之后，恐惧就没有力气出来了。

龙七在写家书。

他坐在宿舍的床边，手里拿着一支钢笔，信纸铺在床头柜上。纸是他在基地小卖部买的最普通的横格纸，钢笔是一支老式的英雄牌——他用了十几年，笔尖磨得正好符合他写字的力道。信纸旁边放着一张照片——一个女人抱着一个七八岁的女孩，两个人站在一所小学的校门口。照片拍得不好，光线有点暗，女孩的眼睛却照得特别亮。

龙七写得很慢。他不是那种会写信的人。他在龙组做了十年，写过的全部文字加起来也不超过一百页——大部分还是行动报告。但现在他在写信。他写了七八行，停下来，把信纸揉成一团扔进垃圾桶。重新铺一张。又写了五六行，又揉掉。

最后他只在信纸上写了三句话。

"我要去月球了。你在家好好的。爸爱你们。"
"如果没回来——爸托秦川带给你的那盒东西里面，有我这些年攒的公积金和抚恤金。密码是你生日。"
"别哭。"

他把信纸折好，放进一个封好口的信封里。信封上写了他妻子的名字和地址。

然后把信封放在枕头底下，关了灯。

老郑在飞船控制室里。一整夜。

他不是睡不着——他是根本不想睡。三十年来每次有重大的发射任务，他都会在前一夜把所有检查项目重新过一遍。即使所有的检查都已经在前几天做过了，他还是会再查一次。

他用手指逐项点过检查单上的每一条——灵石能源舱密封状况、灵气聚变核心的冷却回路通畅度、阵法回路连接完整性、应急系统手动切换测试、生命维持系统的氧气循环测试、六套宇航服的灵气适配调校。每检查完一项，他用红色签字笔在检查单上打一个勾。

十七个主检查项。四百六十二个分项。

全部打勾之后，他把检查单叠好放进胸前的口袋里。然后他从口袋里摸出一张老照片——照片上是一个年轻版的自己，穿着九十年代的蓝色航天工装，站在长征火箭的整流罩前面。那时候他刚进航天系统，觉得能把这辈子的卫星全送上轨道就是最大的成就了。他从没想过有一天自己会设计灵能引擎。更没想过有一天自己会坐上一艘自己修的船飞向月球。

凌晨三点。发射倒计时一小时。

六个人在登船通道前排成一排。穿着银灰色的宇航服——不是那种传统的大白胖子宇航服，是一种新型的灵能宇航服，重量只有传统宇航服的三分之一，内部织入了恒温阵法，头盔面罩上实时投影着灵气环境数据。每个人的宇航服胸口都钉着那枚弯月徽章。

老钟在通道入口站着。他旁边是秦川，再旁边是整个望舒计划的核心工程师团队——十几个人前后排成两排。没有人说话。不是不想说——是不知道该说什么。

老钟走到李长生面前。"碎片感应还在吗？"

李长生伸出右手。透过宇航服薄如蝉翼的手套层，他掌心的五道冥纹正在以一种缓慢而坚定的节奏明灭——每一次明灭都指向东南方向。那是月球的方向。第六块碎片就在那里——月球的背面。万年前上古战场的最深处。

"感应很清晰。"他说，"比在地球上任何一次都要清晰。"

老钟点了点头。"很好。"

他后退一步，看着面前的六个人。李长生、陈霜、小王、刀疤、龙七、老郑。六个来自完全不同世界的人。一个农民、一个剑客、一个程序员、一个退伍兵、一个龙组精英、一个航天老工程师。他们中的任何一个人在此之前都没想过自己有朝一日会成为宇航员。

"我没什么好说的了。"老钟的声音很干，"你们进去吧。"

登船通道的灯是蓝色的。蓝光照在银灰色的宇航服上，反射出一层冷光。六个人依次走进通道，脚步声在狭长的空间里形成了一种低沉的节奏。

李长生在气闸门前停下了脚步。他回头看了一眼——透过通道尽头的观察窗，他能看到控制室里亮着的灯光。灯下有人影在晃动。那是地球上还在为他们工作的活人。

然后他转过身，走进了望舒号。

飞船舱内比外面看起来要宽敞一些。六个人的座位排列成环形，围绕着中央的控制台。控制台上亮着一圈淡蓝色的灵能光芒——那些按钮和屏幕都是老郑参与设计的。座椅是可调节的灵能悬浮椅，能在高加速阶段自动调整姿态以减轻身体负载。每个座椅扶手上都嵌着一块灵石感应面板——修士可以直接通过掌心的灵气输出控制飞船上与自己分工相关的子系统。

老郑坐在主驾驶位上。他把检查单从口袋里掏出来，虽然上面的每一项都已经打过了勾，他还是看了最后一眼。然后他深吸了一口气。手指按在启动面板上。

"望舒号控制系统自检。全部通过。主动力系统就绪。灵能聚变核心温度——正常。阵法回路充能——百分之九十二，持续上升。导航系统就绪。通讯链路就绪。生命维持系统就绪。"

他抬起头，看了一眼舱内的五个人。

"望舒号，请求发射。"

控制台的扬声器里传来地面控制中心的声音:"望舒号，准许发射。倒计时——十。"

李长生握住了座椅扶手。

"九。"

小王的手指离开了键盘——最后一次代码提交已经完成了。现在他需要做的是信任自己写过的每一行代码。

"八。"

陈霜把剑匣固定在座位侧面。她的手指在剑匣外壳上轻轻拍了拍——像在拍一个老朋友的肩膀。

"七。"

刀疤握紧了安全带。他记得部队里教官说过的话:上了战场，就不想死活。只想完成任务。

"六。"

龙七闭上眼。土系灵力在他体内的经脉中安静地流动着——像地底深处沉睡的岩浆，随时可以苏醒。

"五。"

老郑的拇指悬在推进器启动按钮上方。三十年的经验让他知道:现在不是紧张的时候。现在是专注的时候。

"四。"

望舒号底部的灵石聚变核心开始发出低沉的嗡嗡声——频率越来越高，直到变成一种接近音叉的纯净音调。

"三。"

整个飞船震动了一下。

"二。"

戈壁滩上，一道蓝白色的光芒从发射台底部爆发出来，照亮了方圆十几公里的荒漠。

"一。"

老郑按下了按钮。

"发射。"

望舒号的引擎全力点火。灵石聚变核心产生的推力沿着阵法回路传递到飞船的每一个结构节点——这不是化学燃料的爆炸推力，而是一种精确控制的灵能释放，沿着飞船的外壳均匀分布，避免了对船体结构产生局部过载。

飞船开始上升。先是很慢——慢到你可以感觉到加速度在一点点地增加。然后越来越快——快到地面上的沙石被气浪掀起、发射台周围的混凝土表面被灵能余波烤出了裂纹。

从地面往上看，望舒号像一颗逆行而上的蓝色流星——从戈壁深处升起，划破了黎明前最暗的那个时刻。

舱内，李长生透过舷窗往下看。戈壁滩在缩小。先是看不到沙石的纹理，然后看不到山体的轮廓，然后整个戈壁变成了一片灰褐色的色块。色块继续缩小——中国的版图开始在视野中浮现。他看到了那片黄土地。那个位于某个不起眼的平原角落里的村庄。他的祖坟就在那里。他爹妈的坟就在那里。

地球在舷窗里变得越来越小。

李长生摸了摸掌心的冥纹。冥纹安静地呼吸着——一下、两下、三下。像是在告诉他:别怕。回得来。

(第223章完)

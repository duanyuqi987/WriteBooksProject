# 第146章 东南亚降头术士联盟蠢蠢欲动

蛇头布下的第一个降头，是在深夜散出去的。

不是针对李长生——蛇头不蠢。他在出发之前仔细研究过第七宗的溃败报告。报告中的核心信息是:李长生的冥王令能在近距内对灵者级修士产生强制压制效应。蛇头把这句话翻译成了降头术的语言——"目标具备冥系至高法器，能在近距离激发强制高维镇压。灵者级降头在这个人身上完全失效。玄师级降头——未经测试。"

所以他第一个降头的目标，不是李长生，是小胖。

小胖是团队里修为最低、战斗经验最少的一个。他是火系灵根，但丁火是生发之火而非攻伐之火——降头术中的魂降类攻击对火系灵根的抵抗力最低，而小胖的丁火更是火系中的"文火"——在降头术士眼里，这就是一锅温水，往里面投什么都能溶。

蛇头把降头施放的方式选在了食物配送上。小胖每天早上去菜市场采购食材——他买菜的那家摊位是巷口外三百米东市的第三个摊位，专营山货蔬菜。蛇头派了一个精于潜行的降头术士——代号"蜈蚣"——在天没亮的时候往那个摊位的菜筐底层放了三根被降头术浸透的干辣椒。辣椒的品种是小胖最喜欢用的二荆条。降头在辣椒风干后依然可以存活七到十天——当小胖把辣椒放进炒锅加热时，锅底的热气会激活降头虫的卵——卵在豆瓣酱的高温中孵化成微型蛊虫，顺着菜的蒸汽钻进小胖的呼吸道。然后蛊虫会在他体内潜伏三天，以火系灵气为食，在他使用丁火之力的瞬间触发症状。

这个降头的设计极其精妙——不需要直接接触目标，不需要施法距离，甚至不需要知道目标此刻在不在院子——它靠的是供应链攻击，把对方日常生活的必经链路变作降头的施放渠道。降头术士在东南亚日常施术时常用来对付当地小军阀、黑帮头目——在那些地方，降头不是明枪，是暗箭。

但蛇头低估了一件事:这个院子里——有一个活了几千年的东西。

小胖去买菜的那天早晨，龟相忽然从壳里伸出了整只前爪。它正在院子角落里晒太阳——阳属性的灵气透过太阳光射在它壳上，被它转化为阴气纳入体内——但在小胖路过它身前的那一秒，龟相的鼻子动了一下。

千年龟类的嗅觉不是用来闻气味的——是用来探测灵气结构的。在龟相的感知中，空气中的每一道灵气都带有"结构相位"——火系灵气是扩展型的、水系灵气是渗透型的、死气是收缩型的。而小胖刚买回来的那把二荆条辣椒上，散发着一丝不属于任何可食用植物的灵气相位——微小、滑腻、藏着极低频的脉冲。像一只极小的虫子附在辣椒的纤维缝隙里，正在安静地休眠。

"把辣椒放下。"龟相开口。

小胖愣了一下——他拎着装满菜的塑料袋正准备去灶台那边。

"爪子让你放你就放。"周大壮在旁边接了一句——他正在做深蹲，"这老王八几千年没喊过'放下'——你手里的东西不干净。"

龟相走到菜篮边，伸爪拨开最上层的那把二荆条。他的爪子在辣椒表面擦过的时候，爪缝里渗出极淡极细的黑丝——在阳光下几乎看不见——那黑丝缠住一条已经微膨起来的降头虫卵。虫卵大概有小米粒大，被黑丝从辣椒尾端开口处拖了出来。

龟相把虫卵举在半空中，用苍老的声音说了一句话——不是中文，是某种极古老的、发音全部卡在喉咙深处的语言。虫卵在那句话中被定在空气中，外壳自动溶解释放出一团紫黑色细丝——那是降头虫幼体的口器纤维。丝一接触空气便开始无差别地朝最近的灵气源头——龟相——探过去。龟相没有躲。黑丝触及它龟甲表面的一瞬间，像落进了一层看不见的油膜里——被吸收后彻底融解掉了。

"东南亚降头术。"龟相把爪子收回壳里，语气平静得和刚才教小胖怎样控制火候时一模一样，"魂蛊——三级。寄主被感染后三天内表象无异常。第四天当寄主第一次集中释放灵气时——蛊虫的吸食管会扎进丹田，把灵根当成血包抽。抽速大概是每分钟百分之一。三分钟内失去战斗能力，三十分钟内全身经脉萎缩。"

小胖的脸一下子就白了。他低头看着自己的手——刚才他还拿着那把辣椒在想中午做什么川菜。

"虫卵是从辣椒底部人工植入的。虫卵外层用了一种热带植物的汁液做味道掩蔽——这种植物在中国长江以北不生长。辣椒产地在四川——但被投加虫卵的位置不是产地，是菜市场的分拣阶段。虫卵的存活期不超过七天——也就是说送降头的人七天内一定在菜市场附近活动。"

老陈已经在翻他那本翻烂了的通讯录了。他不是在找能打的人——是在找能认出菜市场上可疑外来面孔的本地关系网。他翻到本市菜市场物流协管员的电话，拨了过去。

李长生从屋子里走了出来。他正在调息——昨晚催动冥王令的暗伤还没好，肺部底面的灼烧感偶尔会咳出一点血丝。但在龟相说完"东南亚降头术"五个字的时候，他右手的冥王令嗡地轻轻发烫。

不是警报——是感知。冥王令对同源灵气体系有天然的近距离感应。降头术的本质是操控阴气和死气——和冥术有很深的底层相似性。严格来说，降头术可以被视为"冥术在东南亚地区的退化分支"。两者共享同一套灵气基础——冥气、阴气、死气——但冥术是至高版本，降头术是简化版。冥王令感知降头术士的灵压，就像一只猎鹰在高空看见地上有一只同类的小型掠食者一样——不是敌意，是领地意识。

"一共五个人。"李长生闭着眼睛，通过冥王令的感知在追踪菜市场周围所有不符合本地的阴气信号，"一个在菜市场东边大概三百米——在河边旧货市场的水塔下面。两个在你们买农药的农资站后面那条土路——他们在挖什么东西。一个藏在城南废弃纺织厂二楼。最后一个——信号最弱的——就在巷口。"

"菜市场东边那个就是他们的头。"龟相接过话，"频率最稳，阴气控制最精细。这个人的手没抖——布降头布了大半辈子那种稳。其他人都是辅助。巷口那个是斥候——他蹲在菜市场门口卖菜的那辆三轮车旁边，伪装成搬卸工。"

刀疤已经从墙根站了起来。他拆下了战术背心上沾了汗味的旧纱布，换了一面新的。然后他看着李长生，等他下命令。在特种部队待过的人有一个习惯——不讨论目标有多危险，只等命令。

"先不动。"李长生的回答出乎所有人的意料。

"他们进来布了降头——目标是小胖。我们如果不反打回去，他们下一步会更得寸进尺地找许冰、找老马——"

"先不动。"李长生重复了一遍，但这遍加了原因，"现在巷口外蹲着不止一拨人——至少三拨。降头术士在河边的水塔。西方魔法学院的人刚走，龙组的人一直在这几条巷子口蹲着。如果我们现在出门去打降头术士——龙组和西方探员都会看到冥渊主动打架。刚打赢第七宗，现在动手会给人一个信号——冥渊在四处追打外来修士。这个信号的代价比给降头术士的教训大。"

他顿了顿。

"让小胖今天不去菜市场。让周大壮换便装，骑老陈的电动车到南街肉市买肉——你不在东市出现。许冰——在菜市场东三百米的水塔坐标地下布一个标记阵。不用攻击型——留个监视型阵就行，能让我们知道他们下次集中出发的时间。"

"然后在院子里设一个内圈哨——所有人三天内不准摘信令——万一第二波降头从别的路径过来，龟相可以闻出来。"

"明白了——先摸清他们的行动逻辑再反击。"老陈在笔记本上写了一行字。他写字的速度比平时慢了些——不是因为紧张，是他拿捏不住降头术士的城府程度。一个能在供应链上给你下蛊的对手，你不能按普通修士的战场规则去跟他打。

但他还没写完下一行的想法，对讲里忽然响起了小王的实时推演报告。

"队长，我刚才在综合比对本地两年来未破的异常死亡案和降头术士惯用作案手法的相似度。交叉比对已经跑完了——过去四个月内有六起本地非正常死亡案，受害者全都有近似的症状:死前发热、抽搐、瞳孔扩大、心脏骤停。所有尸检报告都写的是器官衰竭——但病理符合降头术导致的'丹田撕裂后脏器连锁崩溃'。"

"六个——在哪？"

"全在城南废弃纺织厂周围两公里范围内。纺织厂——是第五个降头术士的信号源位置。也就是说那里的那个降头术士至少已经在城南住了一段不短的时间——可能从一开始就已经把纺织厂当做自己的固定据点。"

"所以不是五个——是更早之前就在中国境内已经有一个据点运营了很久。只是最近他们从东南亚补调了四个人过来。"

蛇头不是初来乍到。他在中国境内早就铺了一张缓慢而深入的地下网络。

李长生站起身。他的肺部伤还有点咳，但声音沉——不是刚才那种"先不动"的平稳语调，而是带着一层他很少在院子对话中使用过的语气:

"小胖今天中午做饭照常做——菜单不要变。让降头术士继续以为他们的辣椒已经被你收进厨房了。"

"许冰——回头你在水塔下面标定完以后，再在废弃纺织厂外墙也标一个三级警示阵。把那个位置划作禁入区——两天之内我不想任何队员经过那个区域。"

然后他说了一句话，让院子里所有人停了一下。

"东南亚的这几位——他们以为他们是在暗处偷。但他们不知道——降头术源于冥术，而降头术士在冥系灵根的人面前没有暗处。"

他说这句话的时候，右手的冥王令微微亮了一下。不是有意识催动——是冥王令自己亮了。

亮得很浅。但蛇头如果此刻站在巷口，他会感觉到水塔下面的阴气忽然被什么东西吸走了——速度极快，像黑洞吞掉了周围一小圈能量。然后一切归于平静。他布在南城纺织厂的那个长期降头阵，最底层的三道阴气柱之一，就那么无声无息地空了。

是被冥王令吸走的。

李长生的肺部又在微痛——再吸一道阴气，可能他会咳得更厉害。但现在不是说这些的时候。

"小胖。刚才从那把辣椒上摘下来的那条降头虫——你收好。用龟相给你的那个密封玻璃瓶泡进去——灌三分之一的盐水和两颗花椒。不是调味——龟相要着活的。"

龟相点头，伸出前爪在泥地画了一个小圆圈，在圈里写了十二个字，然后圈起来抹掉——那十二个字是古降头语中克制魂蛊的法术咒式。他不会说东南亚语，但他知道降头术在两千年前曾被一个往东南亚贸易的古修士带回中原一次——那一次回去的人用冥海术把魂蛊的构造解剖完了。结果留下了这套咒式。

这天晚上，小胖把上午买的辣椒全扔了。他重新换了一批食材——用陈霜的霜降剑气给新买的排骨消毒，用龟相自研的灵液浸泡备菜。晚上那顿饭所有食材都安全。周大壮吃了四碗。刀疤吃了几口之后忽然闷头说了两个字:"安全。"

他不说食物——说安全。意思是这一桌子饭没有一丝不对劲。

降头术士们仍然蹲在五公里外的水塔和厂房里。他们不知道自己的降头虫已经被摘掉了。他们不知道冥王令在紫中吞了他们维持阵的一根阴气柱。他们不知道龙组的便衣换了个挨着他们的更近的蹲点位置。他们还不知道——天上就快下雨了，而以龟相对火候的精确感知——空气中的湿气比例每上升千分之五，魂蛊的攻击效能就打五折。

蛇头在水塔下面打坐。他的降头上纹了一只攒了五十年的蛇头蛊纹——那道纹能让他的魂蛊穿透三个等级的灵压防御。

但他现在唯一想的是一个很原始的问题:

为什么刚才那批降头虫卵的远程感应忽然中断了？

（第146章完）

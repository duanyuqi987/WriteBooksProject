# 第111章 灵医发现冥气可以治疗绝症

李长生是三天后到的医院。

那天下午，林晓在灵医科的灵能治疗室里，对着一个病人已经坐了四十分钟。病人是个六十岁的老太太，肺癌晚期。病历上写着:右肺上叶鳞状细胞癌，T4N2M1，多处骨转移。已行四期化疗，肿瘤缩小百分之二十后耐药。现转灵医科寻求灵能辅助治疗。

在灵视下，林晓能看到老太太肺部肿瘤区域的经络状况。正常经络线在灵视中是蓝色发光的——亮度和流动速度代表灵气通过的状态。但在肿瘤区域，经络线全部被截断了——不是消失了，而是像被什么东西"卡住"了。经络的末端依然在正常输送灵气，但一走到肿瘤边缘，灵气就停滞了。它不向前进，也不回头——就堵在那儿。

她之前治疗过几个类似的癌症病例。通过灵气疏导，可以一定程度缓解疼痛、改善睡眠、提高化疗耐受性——但从未让肿瘤直接缩小过。灵气管的是"气"，癌细胞管的是"肉"——两者之间没有直接因果线。

但今天，她拿出了一个不一样的东西。一个用铅盒密封的小玻璃瓶。瓶子里装着一滴黑色的液体——不是墨，不是血，是李长生三天前从掌心冥纹里提取出来的微量冥气原液。原液在玻璃瓶里缓慢地打着旋，表面泛着暗紫色的微光。即使隔着铅盒和玻璃，林晓依然在灵视里看到了一股极其微弱的黑色波纹从瓶子里辐射出来——那不是常规灵气的自然散射，而是冥气特有的"暗呼吸"。

她深吸一口气。打开铅盒，取出玻璃瓶，用一支特制的灵能微针吸了大约零点一毫升的冥气原液。微针的针尖比头发丝还细，上面刻了四道灵符纹——这是她和小王合作设计的，专门为了在经络极细的末端精准注入微量的特殊灵气。

她把微针放在老太太右肺对应的穴位上——太渊，手太阴肺经的原穴。这个穴位的灵气方向直接通向肺部肿瘤区域。

运针的时候，她的手没有颤抖。但她的心跳很快。因为她不知道会发生什么——冥气注入人体的经络之后会怎么走？会不会不受控制地扩散？会不会不但杀不死癌细胞反而破坏了正常经络？

零点一毫升的冥气原液通过微针被推进了太渊穴。

在灵视中，那滴冥气原液进入经络之后没有立刻前进。它在太渊穴的位置停了一下——像是某种活的生物在判断方向。然后它以极慢的速度沿着手太阴肺经往上走——经过孔最、经过尺泽、经过云门——最后抵达了右肺肿瘤区域。

到了肿瘤边缘之后，之前那种停止反应再次出现——冥气和正常的灵气一样，似乎也被肿瘤的"屏障"给拦住了。

然后发生了林晓这辈子见过的最诡异也最精彩的事。

冥气没有像正常灵气那样被"卡住"——它渗透进去了。不是冲进去的，是渗进去的。像水渗入干涸的土壤，沿着肉眼看不见的微细裂隙一丝一丝地钻进了肿瘤组织内部。在这个过程中，冥气并没有攻击正常的经络组织——它似乎能精确地区分正常细胞和癌细胞，只对癌细胞进行渗透。

"它在找什么东西。"林晓盯着灵视里的画面，嘴里自言自语。

在冥气渗入肿瘤内部大约三分钟后，她看到了一幅让她后背发凉的画面:癌细胞内部竟然也有灵气——不是患者自己经络里的正常灵气，而是一种她从未见过的东西。一种灰白色的、呈不规则的絮状结构、在癌细胞内部缓慢蠕动的"伪灵气"。在灵视的高倍放大下，这种伪灵气似乎在癌细胞内部扮演着某种支撑性的角色——它附着在癌细胞的细胞核周围，似乎在不停地给细胞核发出某种错误的分裂信号。

"肿瘤寄生虫。"林晓忽然明白了。

这个词是她在北京灵医培训班上从一位老师口中听来的——那位老师是研究灵能微生物学的，他的假说是:某些恶性肿瘤可能与一种极其原始的、前灵能时代的微生物有关。这种微生物在灵气复苏之前处于休眠状态，灵气复苏之后被空气中游离的灵气激活，才能附着在人体器官中。它不靠血液、淋巴、或神经来传播——它靠的是被它改造过的"伪灵气"。

但这个假说一直没有临床证据——因为常规灵视精度不够，看不到癌细胞内部的微观灵气活动。而林晓是A级灵视，她能看到的细节远超过普通灵医。

癌细胞的假说是对的。而她手里那一滴黑色冥气——正在攻击伪灵气。

在灵视中，冥气原液在肿瘤内部触碰到了伪灵气之后，产生了一种剧烈的反应。不是同归于尽——是吞噬。冥气直接包裹住了伪灵气，然后把它们在一个极短的周期内（林晓估计不到零点五秒）分解为无活性的灵气残渣。被分解之后，那些癌细胞失去了伪灵气的"支撑"，开始出现大规模的凋亡反应——不是被冥气杀死的，而是失去了伪灵气之后自己死的。

林晓从灵视里抬起头。她看了一眼心电监护仪上的数据:心率从一百零三降到八十八，血氧从百分之九十二升到百分之九十五。患者在注入冥气之后八分钟内，生命体征出现了明确的好转。

然后她给病人做了一个简易的触诊。在注入冥气之前，右肺肿瘤区域用手摸上去能感到一个大概鸡蛋大的硬块。注入冥气十五分钟后，硬块的质感变了——不是变小了，而是变软了。从硬块变成了软结节，像一块坚硬的花岗岩被某种东西从内部腐蚀出了空洞。

林晓把手从病人胸壁上收回来，指腹上有了一层微汗。

她没有激动得跳起来，没有兴奋地给李长生打电话，没有立刻冲到院长办公室报告。她只是把铅盒重新盖紧，把微针用密封袋装好，在病历上写了一行字:

"2026年11月3日，首次尝试冥气原液经络注入治疗。患者耐受良好。注入后联合查体提示肿瘤质地有所软化。建议三天后复查胸部CT，评估肿瘤实变程度。治疗机制假说:冥气对肿瘤相关伪灵气具有选择性吞噬作用。"

写完这行字之后，她走出治疗室，靠在走廊的墙上站了一会儿。外面的天色已经暗下来了，走廊里开着白炽灯，灯光把她脚下的影子拉得又细又长。

走廊的另一头，几个灵医科的护士正在交接班。她们有说有笑，讨论着晚上去哪里吃饭。其中一个护士看到林晓，喊了一声:"林主任，下班了不？"

"快了。"林晓说。

她没有说刚才发生了什么。不是不想分享——是她不确定自己看到的东西是不是真的。伪灵气、癌细胞寄生、冥气的吞噬——这些东西串在一起就是一篇重量级的医学论文，但目前只有一个病例、一次观察、一份临床印象。没有对照组，没有重复实验，没有统计学验证。在正规医学的意义上，这算不上证据。

但她在灵视里看到的画面非常清晰。清晰得不需要统计学来支持她的第一直觉。

她拿起手机，给李长生发了条消息:"你明天能不能来一趟医院？带上更多的冥气原液。"

李长生的回复在六十秒后抵达:"好。怎么了？"

林晓敲了三行字，又删了两行，最后只留了一句:"有个假设需要你验证。"

第二天下午，李长生带着一管拇指粗的密封玻璃瓶来到了灵医科。瓶子里装了大约十毫升的冥气原液——在这个量级上，隔着玻璃管都能感受到那股彻骨的冷。

林晓把昨天的观察结果给他说了一遍。从伪灵气的发现到冥气的选择性吞噬，从肿瘤质地的变化到患者的体征改善。她没用任何修饰——就是把看到的东西平铺直叙地讲了一遍。她不需要修饰——事实本身已经足够震撼了。

李长生听完之后，沉默了几秒。然后问道:"你的意思是——冥气不是毒药？"

"不只是毒药。"林晓说，"如果我的观察是对的——冥气能识别并攻击癌细胞内部支撑其生长的伪灵气。而且它不伤害正常细胞。这在理论和临床上都有极大意义。因为目前所有抗癌药物最大的问题就是选择性——化疗药杀癌细胞的同时也杀正常细胞。靶向药的选择性比化疗好但靶点有限。但冥气——至少从这个病例来看——精准得可怕。"

"所以冥气能救命。"李长生把这个结论说出来。说完之后，他自己都愣了一下。

这一年里，他一直在把冥气当作武器使用。战斗、防御、侵蚀对手的灵气结构——冥气给他带来的都是破坏性和杀伤力。龟相说过冥王的本源能力是"看见万物的命数"——这也是一种破坏的力量，是对"生"的否定。但从来没有人告诉过他——冥气也可以救命。

死亡和生命之间——不是一道高墙。是一条可以双向通行的路。冥气是死亡的使者，但同时也可以是生命的清道夫——它能精确地杀死不该活着的细胞，把活下来的空间还给应该活的。

李长生把掌心摊开。掌心的三道冥纹在灯光下显得比平时更加深邃。

"需要我做什么？"他问。

"这批病人。"林晓把一叠病历放在桌上。一共十二份。每一份的封面都印着"重症"红色印章。里面有七个是癌症晚期（肺癌、胃癌、肝癌、胰腺癌、直肠癌、乳腺癌、骨肉瘤），三个是渐冻症，两个是灵根发育异常导致的先天性疾病。"常规治疗已经全部无效了。他们来这里，是因为没有别的地方可以去了。"

"全部要用冥气？"

"先选三个。一个肺癌、一个肝癌、一个胃癌。三个不同的器官位置，验证冥气经络注入的通用性和安全性。如果三例都有正向反应，就基本可以排除'个案偶然性'的可能性。"

窗外，医院后院的银杏叶快掉光了。冬天的阴影正从北边压过来。但在这间灵能治疗室里，一个新的可能性正在被打开——冥术救人的可能性。

（第111章完）

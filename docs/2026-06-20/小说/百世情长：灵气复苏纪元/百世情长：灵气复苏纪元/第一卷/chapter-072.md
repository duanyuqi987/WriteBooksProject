# 第72章 第一次任务

周六清晨，协会门口集合了一辆中型面包车。

参加这次任务的一共六人：两名灵医（苏晚和一位姓陈的初级灵医），一名调度员，两名淬体中期的安保修士，还有林牧——以"社区志愿者"的身份坐进了车厢的最后一排。调度员看了一眼他的登记表：无注册、无等级、无协会编号。三无。但这种C级任务的志愿者管理很松散——调度员只是问了一句"你是什么修为"，林牧答"淬体期"，调度员在表上打了个勾就放过去了。他没有深究。

车上，苏晚坐在林牧的左边。她今天穿的是协会发的灵医工作服——浅绿色的上衣，袖口有反光条，胸前印着协会的LOGO和"灵医"两个字。衣服有点大，她卷了两层袖口。她还戴了一顶协会的棒球帽，帽檐把前额的头灯压出一个浅浅的红印。

"紧张吗？"林牧问。

"有一点。"苏晚轻轻呼了一口气，手指在自己丹田上按了一下，"感觉这儿——今天转得特别快。"

"正常。丹田对神经状态有响应——你紧张它就加快。不是坏事。说明你的身体提前进入了应激预备态。到了现场你就会稳下来。"

苏晚点点头，又从背包里拿出一个小笔记本——上面是她手写的"灵气泄漏现场应急处置流程"，字迹整齐，每一行前面都画了个空心的小方框。她已经预习过多次，还在每一条后面标注了自己需要注意的细节。陈灵医在旁边看到那张密密麻麻的笔记，轻轻推了推眼镜，没说话。

车子开了四十分钟。城里早上不堵，出了城西的收费站后，国道两侧的建筑物逐渐变矮，农田和苗圃开始出现。路边的树叶被灵气浸染后颜色偏深——不是枯，是那种绿得更黑、更厚、更重。

到了。印刷厂旧址在一片荒地的尽头。红色砖墙被藤蔓爬了一半，院子里的水泥地面被蒿草顶出细密的裂纹。安保修士老赵——四十岁出头，淬体中期，之前在军队待过——率先下车勘察了一圈。"泄漏点在厂房后面，水塔下边——是从水塔地基往下渗出来的。评分C-，浓度在安全线以上。周围没有人畜。"

苏晚和陈灵医各自提着急救箱下了车。急救箱里装的是协会配发的灵医标准装备：一次性灵气感应带、便携式灵气输出稳定器（一个巴掌大的小仪器，可以辅助控制灵气的输出频率）、三罐不同浓度的灵气中和剂——用于处理高浓度灵气对人体的急性刺激反应。

调度员在车上用平板签到，上传坐标。安保修士老赵和小军在泄漏点周围拉了警戒线。苏晚站在警戒线外三米的地方，看着那个还在微微渗出淡白雾气的破损地基——这是她第一次亲眼看到"灵气泄漏"。之前在教材上看过示意图，在培训室看过教学视频，但从屏幕上看和从五米外亲眼看着真实的灵气从地下冒出来，是两种认知。

真实的东西在冒出来的时候是有声音的——极细微的嘶嘶声，像一根极细的针从皮肤上划过去。不是耳朵听到，是皮肤感觉到——灵气在近距离产生的微气压变化，像一阵无声的敲击，透过空气打在你的手臂上。

苏晚把手腕上的灵气含量表举到身前。显示数字：301 单位每立方米。普通室外空气的正常灵气含量是 80-150。301 是轻度超标——符合 C 级定义。不会对人体产生立即伤害，但如果在泄漏点长期作业，需要每隔十五分钟轮换一次防止灵气累积性疲劳。

她把数字记在笔记本上，然后戴上手套。

林牧站在她身后大约五步的位置，没有干预。他的目光不在泄漏点上，而是在泄漏点往西的那几棵老槐树周围——树下的土壤颜色不太对。正常的河沙土壤是黄褐偏灰，但槐树根部的那一圈土是深黑——是灵气高浓度浸泡后导致的土壤矿化色变。而且变色的范围比二十分钟前刚到时扩大了——肉眼可见的扩张。他低头看了一下脚边的一丛杂草，草叶的背面有极淡的紫色斑——灵植化初期标志。灵气正在加速释放。

"浓度在上升。"林牧说。他走到调度员车旁，语气不重但直接，"泄漏不是稳态。水塔下面的地层有压力积聚——现在放出来的是顶层的浮气，下面还有一个更大的气袋。建议升级警戒——让站点外扩五十米。"

调度员抬头看他。"你确定？"

"土壤矿化区在扩散。十几分钟大了半圈。这不是静止泄漏。"

调度员是个三十出头的男人，做过两年应急管理，听懂了关键词——土壤矿化和扩散。他没有多问这个"三无志愿者"为什么懂这些东西，直接拿起对讲机开始通知现场全体人员扩大警戒线。几分钟后警戒线外扩了五十米。苏晚被带到了外圈，但她的灵医岗位仍在泄漏点安全距离内——她在学步的阶段，不能直接撤。陈灵医替她分担了外圈等候的工人观测——那群工人在园区门口等着，看有没有需要送医的。

就在这时，泄漏点正下方传来一声沉闷的震动。

不是地震。是一次低频率的地层断裂——像地底有什么东西在挤。紧接着，水塔的旧铁管发出刺耳的刮擦声，锈铁片哗啦落了一地。

旧厂房的藤蔓整片地抖了一下。

林牧的瞳孔一缩——他看到了地层裂缝中的灵光。那道光不是蓝色不是白色，是灰白——是沉睡灵物被高浓度灵气激醒后发出的"原始态灵光"。这种东西在前世的青云宗山门外很常见——石精、石灵、山魄——自然灵气长期浸润普通岩石后形成的低阶灵体生物。未经开灵识，完全凭本能行动。体型越大，说明沉睡时间越长，吸收的灵气越多。通常不会主动攻击——但它醒来那一刻的"破土动作"，对站在上面的人来说就是一次无差别的地面崩塌。

他刚想开口——地面裂了。

三米高的岩石巨人从水塔正下方的地层中轰然冲出。混凝土碎石和泥土向四周炸开。石灵的形态像一个粗陋的人形——有头、有躯干、有四肢，但全身是青灰色的粗岩，关节处长着苔藓和石英晶体。它的眼睛——两个空空的凹陷处——燃烧着灰白色的灵光。

苏晚的第一反应不是尖叫。她侧身护住了身后的群众。

那条警戒线外还有两个没来得及撤到外圈的工人——他们是被协会叫来封堵地缝的施工人员，年龄五十往上，腿脚慢。石灵冲出地面带起的碎石砸碎了警戒线旁的临时灯架——金属架从空中倒下来，砸向其中一名工人的头部。

苏晚猛扑上去推开那人。她自己——在转身的瞬间被飞石擦伤了左肩。疼是火烧的疼，但身体没有晃。

她稳住了。

这时石灵的巨臂抬起来了。那只手臂由一整块花岗岩构成，带着呼啸的风声向她的方向砸下来。

林牧从二十米外一步跨到了她面前。

他没有多想，也没有时间去想。他今天的修为是淬体中期——正常情况下正面硬接一只被C级灵气激活的石灵，胜算不大。但他也知道——石灵的关节是弱点。他被训练过无数次这种战斗——前世在青云宗山门外，他打过的石灵不下百只。石灵的每个攻击动作在启动时，手腕（如果它有手腕）和肩关节之间会有一个零点三秒的僵直——那是灵气在岩体内跳跃传导的瞬滞。击中那个瞬滞，石臂就会临时失能。

他闪身避开石臂的正面落点，在石掌砸入地面的瞬间跃上它的前臂。左脚踏在肘关节的苔藓上，右脚一步蹬到肩部。双手合力——一记简单的聚力掌——击打在肩关节的那个凹槽处。

石灵发出了一声低沉的震动——不是叫声，是灵气被打断后岩体内的共振断裂声。它的右臂从肩膀处垂了下去，失去支撑，重重砸在地上。

轰。

碎石四溅。

林牧从石灵的肩膀上跳下来，落在苏晚前面。他的呼吸很稳，但鬓角已经渗出了汗——淬体中期的身体支撑不了太多次聚力掌。

石灵的断臂在地上抽搐了两下，灰白色的灵光从断缝里不断逸出。它还有左臂——但它后退了一步。没有逃离，而是在评估。它的本能告诉它：这个跳上来的小东西，不太对——他身上有某种远比淬体修士更底层的、来自更高维度的压制信息，像一种写在他灵魂里的古老法则。

石灵犹豫了。

安保修士老赵和小军从侧翼包抄过来，用协会配发的灵力压制器——两个像灭火器一样的金属罐，喷出高压灵气中和剂——冷却了石灵脚下的地面温度，迫使它继续后退。几分钟后石灵收回了最后一只脚，缩回裂缝——沉下去了。地缝中最后一丝灰白色的灵光在阳光中消散。

苏晚的左肩渗着血，但她还在帮受伤工人处理伤口——用灵气镇痛手法，右手悬在工人额角，灵气准确而稳定地输出着，几秒后老工人的疼痛表情就松了下来。

林牧站在她旁边，没有受伤。他身上只有土和碎苔藓，衣服上几个破口——但站在那里的姿势，像刚打完一千场战斗。

苏晚处理完工人的伤口，站起来，目光从他身上扫下去，最后停在他脸上。

"你刚才用的——那是什么？"

林牧捡起掉在地上的运动背包，拍了拍土。

"防身术。"

苏晚没有继续问。但她看着他的眼神，多了一层不同的东西。不是怀疑。是定——之前只觉得他懂得比她多。现在知道了一个事实：他不仅仅懂得比她多。他能做到的事远远超出了"懂"的范畴。一个从未注册的、"三无"志愿者，跳上三米高的石灵，一击断臂——这件事说出去没人信。但她眼睛看到了。

眼睛不会撒谎。

调度员在车上紧张地擦汗，用对讲机呼叫协会总部请求支援——但石灵已经退了。老赵和小军在安全距离外交叉警戒了二十多分钟，确认地缝的能量读数持续下降。后续的支持队伍在半小时后到达——一辆更大的车带来了两位筑基期修士和地质灵能勘探组。筑基期的修士穿着深蓝色协会制服，气质明显比淬体期高了至少一个层次。他们巡视了一圈现场，评估了石灵撤退的位置，和调度员简短交流后确认现场已安全。

苏晚在回程的车上靠着车窗睡着了。她的左肩被包扎了一道白色的绷带，头靠在玻璃上，帽子滑到鼻梁。林牧坐在她旁边，把一个旧运动背包垫在她肩膀和车窗之间——免得颠簸时震到伤口。

车子在国道上平稳行驶。司机放了广播——某个电台的整点新闻正在播报本地妖兽的首次记载——"今日上午，本地郊区发生一起C级灵气泄漏事件，一石形妖兽被激活——所幸现场人员反应及时，无严重伤亡。协会提醒广大市民：C级以上灵气区域请勿擅自进入。"

林牧听着新闻，侧过头看苏晚睡着的脸。她的呼吸很匀，睫毛在颠簸中轻颤。

今天她护住了人。今天她受了伤。今天她看见了他的一部分真相——但没有追问。

他想起她说"我退了谁来补这个缺口？"她没有在今天说这句话。但那个动作——扑出去推开老工人的动作——已经说了。

前世的天女在第一场战斗中也是这样的。

两世，一模一样的毫不犹豫。

他低下头，把她的帽子轻轻拉回来——遮住她被阳光晒到的半张脸。

（第72章 完）

# 第七百八十五章 第八卷的尾声（二）：跨越两界的灯火

除夕午夜，灯火塔广场上的所有人都同时做了一件事——在叶小雨预先设置好的全频灯火同步程序启动后——地面太湖灯火塔的主火焰和上界母树平原灯火塔的火焰在同一时刻（灵网同步精确到万分之一息）同时升到了最高亮度。不是庆祝胜利——是"亮给后来者"。

与此同时，杜小月在母树前放置了最后一批测绘日志——全部是这二十多年来各次飞升、各次支持互助事件的统计数据。她把这些日志一本本排列在母树下一圈石台上——围成一圈——形成一个由文档构成的圆形基座。她说——"这不是数据——是年轮。——杜小月。"

所有在场的小孩——约三十多名——被小米带到桂花园总院的灶台前。他让每个小孩盛一碗粥——然后端着碗到院子里的老桂花树前——洒一点粥在树根上。"不是因为树需要——是因为人要习惯给予。——小米。"

孟长青和廖东辰站在灯火塔展区里——他们看着那颗鹅卵石和碎铁片。廖东辰说了一句话——"我以前以为传统是排外的——今天发现传统也可以是'把碎铁留下来让以后的人看'。""所以我把旧剑留在了母树下——不是缴械——是证物。——廖东辰。"孟长青在他旁边，两只手都插在袖子里——右手握着最新的鹅卵石，左手空着——"我也该留一颗在母树。——他去找杜小月——'这是给下一道门的。——一颗——普通的。——孟长青。'"

（第七百八十五章 完）

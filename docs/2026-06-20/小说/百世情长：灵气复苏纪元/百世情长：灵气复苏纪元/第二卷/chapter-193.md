# 第193章 天材地宝的喂养

苏小晚从小到大的饮食，跟村里的其他孩子没什么区别——她妈每天三顿饭不离时令蔬菜、家里养鸡的蛋、偶尔烧一顿肉，夏天喝绿豆汤、冬天喝萝卜排骨汤。唯一不同的是，林牧在她家的日常饮食中混进了一些"增补药膳"，包装成普通调料，在任何人毫无察觉的情况下喂养了二十年。

最早的一种是灵露草汁。这种草在秦岭南麓的石缝里能采到几株。它本身无色无味，混在米汤或青菜汤中无法察觉。林牧将微量稀释液加入苏家的水井——那口井是苏大山每天早上打第一桶水的来源。效果很轻——它只是微量促进身体对自然灵气的吸收率，不增加灵根评分不触发任何灵力检测的敏感——所以也不会被轮回锁当做威胁而阻截。

时间一年一年过去。苏小晚还是D级（外面看）。但她身体从不会被寒风冻得连嘴唇发紫、夏天不中暑、外伤康复速度比同龄人快。苏母把这归功于"这孩子天生硬朗"。这在某种意义上是真的——只是"硬朗"的额外保险由隔壁老人天天追加着。

第二种材料是一味极其稀有的温阳果干——由林牧特地从南方热带区一小片基地的微型温室里带回来。他将果干研磨成极细粉，偶尔极微量掺入苏家请老人吃年夜饭时的调味蘸碟里（他每次去张家吃饭顺便带去的"自制五香粉"）。这种粉对经脉细胞壁有缓慢的强化作用——能在不引起锁力增加的情况下让经脉在日后承受淬体中期冲击时不易碎裂。

第三种——也是最耗费他精力的一种——是自炼的"回魂甘草片"。这种甘草片外形类似日常润喉片，由天晶玉细粉（千万不能用多）和不灭果种子油在灵力丹炉中合成。他将它当成普通润喉糖给她——口干吃一颗，嗓子不舒服吃一片。这二十年间她大约吃了不下几百片。它的作用是让灵魂核心表层柔软，便于将来破锁手术时灵魂内部不会被拉伤。也就是说——林牧在喂养她物理身体的同时，也在用天材地宝养育她被锁住的灵魂根基。

所有喂养过程的原则只有七个字:不影响她的自觉。她从不会觉得她的成长有一个外力托举。因为她吃的是"日常饭菜"，喝的是"咱家井水"，含的是"老师给的润喉糖"，而不是"服用了某种仙药或灵丹"。这种极致自然的喂养方法，是林牧从第二世修来的最高级守护术——"日常化灵培"——在外面任何药理监测看来都只是"正常食物，无显著灵石含量"。

她在大学期间身体越来越好——皮肤白、发质好、气色透亮。室友们好奇地问她是不是用进口护肤品。她随口说"用的——万能的上海硫磺皂"。室友笑喷。但其实她不知道背后的那些无形营养链是怎么接起来的。她只是上到省城后，林牧每隔一段时间就让苏母给她寄一些"家里自制香肠、腌肉、调味粉"——这些才是真正的天材地宝输送渠道。他把微量灵药溶在这些食物的酱料中，不加多不压少，以保鲜防变味为基础，持续供养。

她在大学感冒几乎从不。室友们又说"你真的是D级吗？D级不应该体质这么好啊"。她骄傲地回答:"我们村有座后山，常年喝山泉水——可能是那个原因。"室友们第二天集体买山泉水喝，但没人能喝出她的体质。

整个喂养计划是密不透风的长期工程，耗时二十多年。到大学毕业时，她的灵根潜力比出生时高了一截（虽然表面检测还是D+）。但真正重要的是——她体内汇聚了足以承受破锁的三层保护膜。未来如果成功破解锁，她不会因为灵魂撕裂而受创。即便是普通资质的凡人也很难有这种底子——这些都是他用大半世修为亲自炼成的最低调极品。

毕业那年她最后一次回到桃源村。她把从大学带回的毕业证书摊在桌上给两位老人看。阳光从皂荚树缝隙落下来照在证书的光面，光线折射到猫身上，猫嫌刺眼，起身走掉了。

"天材地宝的喂养"在今天完成最后一顿——晚上苏母做了一桌子菜：鲜笋炖鸡、土豆焖排骨、紫菜鸡蛋汤。林牧在旁边拿了瓶老黄酒，往苏小晚面前的空杯里倒了一杯。她喝了一口眨了眨眼:"老师——这个酒好甜呀。"

"黄酒加一点蜂蜂蜜。——人也是。养到足够甜就准备好进去生活的下一个阶段了。"

她举杯跟他磕了一下，笑得眼睛弯成月牙。二十余年的灵培——都被这杯甜黄酒的滋味裹起来了。味道——她尝不出天地灵宝—但她能尝出被好好养大的甜味。那就够了。

# 第五百一十六章 共创功法的念头

通灵状态下，苏晚有一个晚上忽然提出了那个想法。不是盘算已久的——是弹完那段双灵和声之后她忽然说:"我们共创一套属于自己的功法吧——不是双星篇那种现成的。是自己创造的那种。"

林牧在银杏树下听完这个提议后思索了好一阵子。不是觉得不行——是他知道这件事的分量有多大。苏晚在修炼上的创新能力他一直认可——双星篇里很多难点就是她以非传统方式拆解出来的。她的脑子是财务出身，能把极复杂的事物拆成极可量化的细碎单元然后逐个击破。但自主创造整套功法——这在整个仙界都是极少数绝顶天才才能涉足的领域。寻常仙人练一辈子能把现成的一套上古功法吃透就不错了。从零开创一套完整体系——那是开宗立派级别的人物。

但他看到苏晚的眼睛。不是空想——她在通灵中已经给他预览了部分思路。她的构思内核极其简单但极其独特:将双星篇的上古阴阳交融原理和功德绳的灵魂共鸣直接整合为一种全新的训练体系。不需要两个人都在完全同频才能共振——目前所有道侣功法都有这个前提要求。如果其中一个人状态差一点，共振就会断，断了之后重新发动需要消耗额外灵力。她在丹炉旁受伤那次就是因为这个——她当时的灵核频率无法跟上林牧的速度，然后为了不拖累他而硬跟——结果伤了经脉。

她提出的解决办法让林牧整个人呆了一下。

"用功德绳上的金线作为'异步缓存器'。"苏晚蹲在地上用手指在泥土上画简图，"金线本身就能暂存灵核能量——共振时如果两个人的频率不同步，多出来的那部分能量不是硬压过去，而是暂存在绳芯里。等对方恢复同步时——缓存里的能量再自主释放。就像你在修飞仙舟时用的扭矩扳手——拧过头了扳手会自打滑。不是断了，是缓存了一下。我们的功法也应该是这样——不是催对方跟上。是允许对方暂时不在线。不在线的那些时间——不是浪费。是金线在帮你保管她延迟的节拍。"

林牧在听这段话时发现自己心跳快了半拍。不是激动——是震惊。因为苏晚的这个"异步缓存"概念打破了上界所有现存道侣功法的根本前提。自古以来的道侣功法都追求"双心合一心意相通"——这是美好的理想，但实际上两个人总有身体状态不同的时候，不可能一辈子都保持在完全同步。所以追求完全同步反而会造成压力的积蓄——不同步时功法的损伤比同修带来的好处还要大。而苏晚不从"同步"出发——她从"异步"出发。她不假设两个人需要同频——她假设两个人永远是不同频的，然后在这个前提下设计一套能够包容一切频率差异的体系。

"你那个'异步缓存'——"林牧的声音里有一丝极淡的他自己没察觉到的不可思议，"是你做财务的时候学到的？"

"IT架构的缓存概念。"苏晚在地上画完最后一根箭头，抬起头时鼻尖上蹭了一点泥，"我们财务部以前要和技术部对接ERP系统——他们说过缓存这个词。我当时没在意。但现在我发现——功德绳就是一根同轴缆线。金线是它的缓存池。以前我们不知道可以用——但我们每次不同步时功德绳上那些自发闪动就是在做微缓存。只是我们从来没有把它放大到功法层面。"

林牧低头看着地上那张用树枝画在泥土上的简图。箭头、回路、方框、虚线——每一根线都被她画得极其规整。箭头的起止点全都对齐，虚线间距一致。她甚至用石子压在图四角当作"锚点"——这是她做表报时养成的习惯，怕图纸被风吹跑。

他沉默了好一阵子。然后笑了。非常轻——但笑意很深。不是"你真聪明"那种笑。是一种更深更复杂的东西。"我的道侣是个码农。"

苏晚打了一下他肩膀——力道不轻不重，刚好能把他肩上的松木屑拍掉几片。"做财务也是要懂一点技术的——不然怎么和你们技术部打架。"

当晚两人在银杏树下开始了正式的功法构造讨论。讨论很漫长——用通灵比语言高效很多倍，但还是花了极长极长的时间。因为功法不是灵感闪现就完事——它需要把每一个状态分支都考虑到。苏晚拿出了笔记本新开了一卷——在封面写了"双心诀·卷一·异步框架"。她在纸上画了一张极大的表——横向是"林牧状态"的几十种场景分类:正常、疲劳、受伤、战斗输出、被动防御、睡眠、修炼、做饭、劈柴、修船。纵向是"苏晚状态"的同样分类。每一格交叉点需要填写在那个状态组合下异步共振的最佳频率间隔。

林牧的工作是坐在她对面，用灵核去感应每一格交叉点——找到在那两种状态下两个人灵核频率差异的"安全缓冲区"宽度。有些状态组合的安全缓冲区极宽——比如两人都在安静看书时，频率差可以大到百分之三四十都不需要缓存介入。但有些组合的安全缓冲区极窄——比如林牧在战斗中极限输出而苏晚同时也在全力运转剑招时，两者的频率差必须控制在百分之一以内，否则缓存池会过载。

天亮时表格终于填满了大半——整张表上密密麻麻全是数字和箭头。苏晚的手腕因为写了一整夜而微微发酸。她把笔放下——甩了甩手。林牧从她手里把笔拿过去——在她刚填完的那格旁边补了一行极小的注:"此格建议再加安全系数——因为苏晚在疲劳状态下写字会不自觉往右偏，间距估计偏保守。实际缓冲量可以放大零点零三个点。"他补完后把笔帽盖上。两个人对视了一眼——她的眼眶下有熬夜的浅青色，但眼睛极亮。

"这套功法的名字叫什么？"林牧问。

苏晚想了一下。然后她翻开笔记的卷首页——在上面写了一行字。字不大——但笔画极稳。一夜没睡的人写出这么稳的字——说明不是用意念在撑，是这种"创造"本身在给她推元气。

"双心诀。"

"两个心。不同步的两个心。靠一根线连着——不是强迫它们对齐，是让它们在各自跳各自的节奏时仍然能听到对方。异步共振——就是我允许你慢，你也允许我快。慢的不勉强，快的不停下来等。金线把中间差出来的那些空的节拍全都保管好。等下次同步时——全部还给你。"

林牧把这三个字在脑海里默念了一遍。然后他把手按在她笔记的卷首——不是按字，是按那页纸。纸上一夜之间产出了一套可能影响后世上千年道侣修炼方式的新功法雏形。而这张纸昨晚还是空白的。他把手从纸上拿开——然后从她手里把笔也拿过来，在卷首"双心诀"三个字下方加了半行字。字迹潦草，但能认出来:"——作于银杏树下。设计者:水月仙人·苏晚。测试者:寻晚真仙·林牧。首个异步步伐完成于天亮前。"

苏晚看到他写的那行字后把笔抢回来——在他写的那行最末尾加了一个括号注释:"（测试者在试验过程中睡着了两次。不是不敬业——是在测'两人不同步'的极端状态。数据有效。已计入第三格:一方睡眠·一方清醒。）"

林牧看到这个括号后嘴角动了动——那是他极难得的、被逗笑的幅度。然后他站起来——腿因为盘坐太久而发麻，但他没有像苏晚那样龇牙咧嘴。他只是极其稳地站了一会儿——把麻劲儿蹲过去。然后去厨房生火做早饭。

苏晚看着他的背影走进厨房门——然后把笔记翻到新一页。在新页上写下今天的第一行字:"双心诀·第一式·异步起步式。设计原则——不以同步为目的。以异步为常态。"

写完这行字后她停了一下。然后在这行字下面补了一句话:

"这本功法——不是给那些天赋最高速度最快的道侣写的。是给每一个在追赶中受过伤但不想停的人。"

（第五百一十六章 完）

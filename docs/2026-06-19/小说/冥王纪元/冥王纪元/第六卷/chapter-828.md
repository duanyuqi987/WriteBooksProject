# 第828章 雕像与信仰

新纪元九千三百年。

宇宙中涌现了无数李长生的雕像。不是由政府或议会授权建立的（议会从不下令建造个人雕像），而是由各地的民间自发建造。每颗有人居住的星球上，平均出现了至少一尊冥王像——最多的有上千尊。没有统一的标准造型，但奇怪的是所有雕像都有些一致的偏差：不是手特写，不是脸特写——是鞋。几乎所有雕像都把他塑造成了穿着解放鞋的形象。有些雕塑家会在鞋底上特别刻出磨损的痕迹——即使没人知道那双解放鞋的具体样子，他们却凭着灵符史料中的两行细微数据重构出了鞋底纹。因为他说过的那句关于"磨平了"的话——被反复刻进各文明记忆中。

这些雕像大小不一。最大的高达百丈，被星体视为守护塔的一部分；最小的只有巴掌大，被放在孩子枕头边。材质各异，从青铜到灵晶到未经提炼的原石都有。气场不同，但有一个共同点：它们从不被允许涂金。不是法律禁止，而是民间自发拒绝。每一个建造冥王像的群体会在建设前自发约定一条规则："不放光芒，不放神环，保持泥土的颜色。"

在众多雕像中，有一尊最为特殊。它位于李家庄原貌保护区的村口位置——就是那片大槐树底下。雕像不是站立的，而是蹲着的：一个中年男人蹲在田埂上，一条腿支着，另一只手搭在膝盖上。手掌宽厚，指缝里刻出了泥痕。表情不是眺望远方，而是在看脚下的土。雕像是按照李长生的真实身高制作的——中等，不高大，不精瘦，没有英雄比例。脚边没有基座。直接搁在土面上。

建造这尊雕像的不是议会，不是艺术家，是李家庄的"后来的后人"。六百三十年前，李氏宗族的族长（他是李长生的远支支脉后人，没有修炼过，但依然留在了李家庄）说了一句话："我们不要宏大，不要金光。就放他在村口蹲着——这样每天回来的人，还能跟他在地头说两句。"他说的"两句话"后来被刻在雕像旁边的地上，不是碑上，是地面一块粗糙的石板上：“侄儿，给咱们收玉米的时候多留两垄——德贵叔”这是德贵叔曾经常说的一句话，被后人不知从何处找回记入。下面另有一行更旧的字："爹，妈，我去浇地了。"

这尊雕像后来成了整个银河最著名的冥王像。不是因为它最精致——而是因为它最真。每年有数以百万计的修士从各个星系前来朝拜。但他们来的方式不是膜拜，而是默默走到雕像旁边，蹲下去，和他一起看看那片祖坟的方向——那片收了一万年的玉米地。没有人说话。朝拜的方式不是跪，是蹲着。因为那是他习惯看世界的姿势——而来看他的人也学会了。

这种朝拜不是宗教。不相信冥王会赐福，不在乎显灵。只是想跟他一起蹲片刻。仿佛蹲下来就能听见他说的那句老话："日子还得过。"

议会正式对这种自发行为给予过唯一一次评语——不是鼓励，而是珍惜。议会在一份文化档案中记载了这样一句话："那些蹲着的人不是在等待奇迹。是蹲着更靠近泥土，靠近一个农民曾经离土最初和最暗时的听觉。他们知道——他不发令。但他在乎。"

（第828章完）

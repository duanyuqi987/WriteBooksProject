# 第六百九十八章 上界大门松动了

上界第四年（地面近五年），上界大门——那扇悬浮在平原尽头的银色巨门——第一次松动了。它没有开启。只是从门缝中透出一线极细的淡金色光芒。但这一线光足以让整个过渡区震动。

秦无夜第一时间跑去找林牧和苏晚。她跑到半路就改成飞的了——"林先生！门——门下面有光！"林牧和苏晚跟着她来到平原尽头——那扇巨门确实变了。门体不是向两边打开的——是从门缝中渗出了光。光线不是太阳的纯白——是那种正魔灵气共振后的淡金偏紫。和飞升之门通道的颜色一模一样。

林牧蹲下来——他把手放在门前的地面上。地面在微微震动——不是地震，是古老的阵法在重新校准。那种震动的频率他极其熟悉——它是"缺陷联合曲线"的频率。不是上界刻意模仿他——是上界的规则本身在接收到下界多年的包容信号后，开始自动将"缺陷"转化为"突破动能"。

苏晚站在他旁边。她看着门缝中那线金光，然后回头看了看远处灯火塔的金紫色火焰。两个颜色是同一个色系。不是巧合——是共振。"门不是要用力量推开，是要用理解打开。上界古人以前以为飞升需要力量——所以门一直撬不开。现在下界用包容提供了另外一种方式——门自己感应到了。它在主动学习怎么去开自己。"她蹲下来和林牧并肩。他看着那张他爱了百世的脸——她的白发在门缝的金光中变成了浅浅的琥珀色。

"你觉得还需要多久？"

"也许再一两年。也许十年。但关键不是时间——是方向。"林牧站起来，拉住她的手让她也站起。"门已经开始接受'包容'作为开锁的有效方式。这个方向定了——剩下的就是等。我们不需要站在这里敲它——回去盛粥。"

（第六百九十八章 完）

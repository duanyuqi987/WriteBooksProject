# 第030章 李长生去测试，结果一片空白

排了将近四个小时的队，终于轮到李长生了。

他前面那个测试者是一个光头大汉，脖子上一道疤，看着像是混社会的。大汉把手按在灵盘上的时候整张脸涨得通红，像是在用力。灵盘毫无反应。工作人员面无表情地说了句"下一个"，大汉骂骂咧咧走了。

李长生坐在灵盘前。

那是一张普通办公桌大小的工作台，正中嵌着一面圆形的黑色石盘。石盘材质看着像是某种玉石，但比玉石颜色更深，表面打磨得极为光洁，隐隐能照出人影。石盘边缘刻着一些细密的纹路，李长生认出那是某种阵法刻线——碎片教过他一小部分基础阵法知识。

"右手放在盘面上，掌心朝下。"工作人员是个戴眼镜的年轻女生，声音已经被重复了无数遍变得机械，"放上去后保持不动，不要刻意用力，自然呼吸。五秒之内出结果。"

李长生看了看周围。排队的人已经被挡在一根一米红线外，线外的人伸着脖子往里看。维持秩序的蓝制服们站在线两侧，眼神有些疲倦。

柱子旁边那个灰夹克男人还在。他手里的奶茶快喝完了，正低头玩手机，拇指划拉着屏幕。

李长生把手放了上去。

掌心触到灵盘的时候，石盘表面微凉，像冬天的石板路。他按照工作人员说的保持呼吸自然，手指张开，手掌完全贴合在盘面上。

第一秒，什么都没有发生。

第二秒，依然什么都没有。灵盘的颜色没有变，盘面连一丝微光都没有出现。

第三秒，李长生感觉到掌心的冥纹颤动了一下。碎片说了一声"收敛"——他立刻压住体内的灵气流动，把所有冥力全部封回丹田深处。

第四秒，灵盘还是没有任何反应。

不只是没有反应。盘面的光泽好像在迅速消退。灵盘原本会照出一个模糊的人影，但现在人影消失了。盘面上什么都没有——不是暗，不是黑，而是某种彻底的、完全的空白。

像是一面镜子忽然变成了一个洞。

第五秒。

工作人员低头看灵盘连接的电脑屏幕。屏幕上会实时显示灵盘感应到的灵根数据——类型、品级、潜力值。正常情况下，就算没有灵根，屏幕上也会有一行"未检测到灵根"的常规提示。

但她看到的屏幕上也什么都没有。

不是零。不是"未检测到"。是没有任何显示。屏幕上一片空白，好像灵盘传回来的数据在进入电脑的一瞬间就消失了。

"咦？"她皱起眉头，在电脑上刷新了一下页面。

屏幕依然空白。

"怎么了？"旁边管数据录入的同事探过头来，看了一眼，也愣了。

"灵盘有没有问题？"戴眼镜的女生敲了一下灵盘的边缘。石盘碰触之后发出一声很轻的嗡鸣，表明仪器应该还在正常工作。

她又刷新了一次数据。屏幕上出现了一瞬间的文字，然后消失了，快得像眼花。

"我刚才看到了几秒钟的数据——"她皱着眉头盯着屏幕，脸色变了一下。

"什么数据？"同事问。

"我看不清。"她犹豫了一下，转过来对李长生说，"先生您稍等，可能需要重新测一次。您先把右手抬起来。"

李长生抬起手。

灵盘在脱离他手掌的那一刻，数据立刻恢复了正常——屏幕上的"灵盘待机"四个字清清楚楚。

戴眼镜的女生和同事交换了一个眼神。

"先生，麻烦您再试一次。"

李长生重新把手放了上去。

这一次他特别注意碎片说的——收敛冥力，封住冥纹。他感觉掌心的冥纹收缩得紧紧的，像一只蜷起来的小兽。

灵盘还是没有任何正常反应。

不，是灵盘显示出了"空白"。那种空白和正常的黑色不同。正常的黑色显示是灵盘没有感应到任何灵气。但现在灵盘呈现出的空白，像是一个信号输出口被什么东西堵死了。不是"感应不到"，而是"感应到了但数据被吃掉了"。

更奇怪的是，屏幕的数据开始跳动。跳的不是数字，不是波形，而是某种完全无法解析的信息碎片——就像是有人用乱码往数据接口里灌入了一整段无法解码的原始信号。

"这——"戴眼镜的女生站了起来。她伸手在键盘上敲了几下，迅速调出一个诊断界面。诊断界面上弹出三行黄色的警告文字。

**异常值#1：灵气类型无法识别**
**异常值#2：灵根品级超出量程范围**
**异常值#3：建议停止测试，上报上级**

她看了三秒，然后拿起桌上的对讲机。

"组长，十八号台需要复查。异常值三连。请求疏导。"

对讲机里很快传来回应："收到。安排复查。"

排队的人群开始哄哄。

"啥情况？"

"这哥们儿怎么了？"

"刚才那个光头是不是没有灵根，然后这个仪器的盘就坏了？"

"不会吧，前面那个没灵根的是正常显示，这个是连着电脑都瘫痪了。"

一个穿蓝制服的走过来对李长生点了点头："先生，请跟我到这边来。您的测试结果需要复查。"

李长生站起来。他注意到柱子旁边的灰夹克男人放下了手机，正在盯着他。奶茶杯被捏了一下，杯壁凹了一块。

那男人的眼神变了。

不再是懒洋洋的、随意的。而是一种忽然收紧了瞳孔的、本能警觉的眼神。

"为什么需要复查？"李长生问蓝制服。

"可能是设备故障，也可能是正常的测试异常。我们每天都会遇到几例，您不用担心。"

李长生没有说话，跟着蓝制服往一侧的走廊走。

走廊不长，二十来步的尽头是一扇灰色铁门。门口坐着另一个中年人，穿的是深蓝色的中山装，左领口上别着一个小小的金属徽章——一枚三角形的符印，中间有一道白色的剑痕。

碎片的声音忽然响起："九华剑派的宗门印记。"

李长生心里一紧。

"鉴定完了？"中山装中年男人站起来，看了李长生一眼，目光在他脸上停了半秒。

"十八号台的，异常值三连。"蓝制服把一张打印出来的数据条递给他。

中年人接过数据条，低头看了一会儿，眉头越皱越紧。

"灵根类型未知，品级超量程——"他念到一半，抬头看着李长生，"你叫李长生？"

"是。"

"三十岁。河北李家庄人。之前在建筑工地——"

"是。"

中年人的目光又在李长生脸上停了半秒。

"跟我进来吧。"

灰色铁门打开。里面是一条灯光昏暗的走廊，两侧各有一排门，门上没有任何标识。走廊尽头还有一扇更大的铁门。

李长生走了进去。身后灰色铁门关上，锁芯啪嗒一声扣死了。走廊里一下子安静下来，外面的喧嚣声完全隔绝了。这里的隔音好得出奇。

中山装男人走在前面，皮鞋敲着地面，声音很轻但节奏均匀。他走到走廊中段的一个房间前停下来，打开门。

那是一间大概二十平米的房间。正中一张铁桌，桌上放着一台新的灵盘——和外面那种不同，这台灵盘明显更大更精密，盘面上的阵法刻线更加复杂。桌子对面坐着两个穿灰色长衫的老者，一男一女。男的胡子花白，闭着眼睛；女的面质清冷，手里拿着一支毛笔，旁边的砚台上装着的不是墨汁，而是某种淡青色的液体。

"坐。手放灵盘上。"九华剑派的中山装男人指了指桌子对面的空椅子。

李长生坐下，再次把手放在灵盘上。这次他感觉到灵盘在接触到他手掌的瞬间微微震了一下，像触及了什么不能触碰的东西。

两个老者同时睁开了眼睛。

"等等。"花白胡子抬起手，"灵盘不要用最大功率。先用三成。"

女老者看了他一眼："三成够吗？"

"先试试。外面十八号台的数据刚才我看了。量程溢出如果是真的，这台灵盘十成功率也撑不住。"

女老者没再说话，提笔在灵盘边缘画了一道符文。灵盘嗡了一声，运转起来。

然后，什么也没发生。

不是没有反应。是和外面十八号台的灵盘一模一样——灵盘表面的光泽消失了，变成了一片空白。不是黑色，不是暗色，是一种很纯粹的空缺，像是盘面上开了一个看不见底的洞。

三成功率的精密灵盘，没有任何正常的数据反馈。

花白胡子的眼睛终于完全睁开了。

"三成不行。五成。"

女老者又在灵盘边上画了一道符。灵盘的嗡声加剧了一些，盘面上的阵纹开始发光——那些光本该是探测灵根的能量射线，但它们在接触到李长生掌心的瞬间，全部消失了。不是被吸收了，不是被反射了，就是没了。

五成功率，依然一片空白。

花白胡子站了起来。他的手按在灵盘的边缘，指尖有一丝灵气渗入盘中，亲自探测。

然后他的脸变了。

"他在反向——不是反向，"花白胡子的声音变得有点紧，"灵盘的灵气在流进他的掌心，但不是被他吸收，而是被他体内的什么东西——吃掉了。"

女老者和九华剑派的中山装男人同时变了脸色。

"吃了？"女老者的声音压得极低。

"灵盘打出去探测的所有灵气，全部消失在他面向灵盘的那只手里。像石沉大海。"花白胡子盯着李长生，"把灵盘关了。这台设备不能在他面前运转。再运转下去灵盘会废掉。"

女老者提起毛笔，在灵盘上横划了一笔，灵盘停了。

房间安静了下来。走廊尽头那扇大铁门外隐约传来一些声响，但隔着太远，听不真切。

花白胡子看着李长生，眼神变得极为复杂。

"你知不知道，你自己的灵根是什么类型？"

"不知道。"李长生如实说。

花白胡子没有追问。他转过去对中山装男人说："通知京城。这个案例不上常规数据通道，走密级通道。"

中山装男人点了点头，转身走出房间。

花白胡子重新坐下来，看着李长生。他的眼睛里没有敌意，有评估，也有困惑，还有一种李长生说不清楚的东西——好像是某种古老的、写在某个卷宗深处的恐惧。

"李长生，你待在这里。等一下有人会来找你。"

"谁？"

花白胡子闭上眼。

"我们也不知道。但他们会来的。"

（第030章完）

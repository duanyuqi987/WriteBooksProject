# 第636章 历代强者的封禁

十七道封印分布在禁区球体从外到内的十七个同心层中。每一层之间的距离并不均等——有的层和层之间隔了好几光年，有的层之间只隔了不到半米。封禁的密度不取决于物理距离——取决于那个时代封印者本人的"紧迫感"。对混沌之主来说，第三块碎片被保护得越严密，就越说明它重要。

李长生在穿过了前三层封印后，停在了一个他需要多看几眼的地方。

第四层封印是金色的。施加者的能量签名显示：施加者是一个距今约九亿三千万年前的修士——修为等级按现在的标准折算大约在冥王级，略低半分。封印的核心逻辑不是灵力不是平衡——是规则。这一层封印附带了十七条"禁制条款"，每一条都是一种不同的防御方式。其中第六条令龟相在读完之后缩进壳里很久："第六条规定——任何试图穿越封印的修士，如果其体内的能量运转方式不属于'正道'——封印会自动引发心魔劫。心魔劫的强度不定——取决于被攻击者内心深处'对最不能碰触之事'的恐惧程度。"

"不是正道怎么定义？"陈霜问。

"在施加者的定义里——正道就是他的道。不是他的道的——全是不正。"龟相从壳里出来，"九亿年前这个区块的修仙体系极其排他。几万种功法里只认七种是'正法'——其余全部被标记为邪道。"

李长生站在第四层封印前面。他体内的冥力——是冥王的正统传承，应该算正道。但他体内叠加的混沌碎片——混沌能量在九亿年前的这套体系里不存在。系统会把它标记为什么？第四层封印没有给他时间去猜测。感应到他体内混沌能量之后，封印立刻启动了。十七条禁制条款同时触发——其中第六条"心魔劫"启动了。

李长生发现自己的视觉被切换了。

他不再站在禁区里。他站在一片黄土上——村口的那条土路，那棵已经枯了半个树冠的老槐树，远处他家的那间平房。院子里的苞米架还在——去年秋天他收的最后一季苞米。这是一个完全写实的幻觉场景。

心魔劫不是给他造噩梦——是让他重新经历那个他"最不能碰触"的记忆。而他的最不能碰触的记忆——不是战斗失败，不是死亡，不是失去力量。是——他离开村子之前，站在苞米地边上，看着自己种了十多年的那块地，想到了一个问题：如果我不回来呢？这个问题在当初只是一瞬间的念头——很快被他按下去了。但心魔劫抓住了这个念头，把它放大到了一整片田野。

他站在苞米地边上，看到的不是苞米——是空。整块田里什么都没有。不是荒了——是消失了。地还是那个地，但上面曾经被他亲手照料过的所有作物全部不见了。他沿着田埂往前走，发现整个村子都是空的——人、井、树、狗、拖拉机——全部不见了。不是被毁灭——是好像从来没有存在过。

他在心魔劫里站了很久。

然后他明白了这一层的测试内容：不是"你怕不怕失去故乡"——是"你知不知道你为什么要离开故乡"。能穿过这道封印的，必须是明确知道自己为什么要去禁区最深处的修士——不是为了力量，不是为了好奇，不是被别人派来的——而是自己决定来的。如果你的理由不够坚实，心魔劫会把你困在"离开故乡意味着什么"这个永远解答不了的矛盾里。

李长生站在那片空荡荡的苞米地边上，说了一句话。

"我不是离开。我是代表它去最远的地方。"

心魔劫在他开口的一瞬间破解了。不是被打破了——是被接受了。第四层封印收回了全部十七条禁制条款。金色的纹路在他面前自己让开了一条路。

龟相在穿越封印的时候忽然停下来。老龟的两只前肢在光滑的封印面上轻轻划过——那道封印上残留的制造者签名被他的爪子触到了。签名是用一种已经灭绝的语言写的。只有四个字。龟相盯着那四个字看了好一阵。

"怎么了？"李长生问。

"这个施加者——"龟相的声音很轻，"是我在上上个宇宙轮回的一个族人。不是同一个——是他的意识本质和我一样。他是——我们那一族在这个宇宙里的后代。"

陈霜停住脚步。她看着那一层金色的封印，再看着龟相。

"所以混沌之主把你们族人的封印也放进了禁区——作为测试的一层。"

"对。我的族人——从上一个轮回活到这个轮回的那种——他们也参与了建设这个禁区。他们知道混沌之主要保护什么。他们愿意用自己的封印术来做一道锁——等待应该来的人来开。"

龟相的爪子从签名上移开。他没有说什么感伤的话。但他的两只前肢在收回的时候比伸出去慢了很多。

（第636章完）

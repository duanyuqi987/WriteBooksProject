# 物理环境与世界观手册

## 第1卷《裂变·碳硅共生》

- 物理层级：碳硅共生裂变；地球、芯片、水体、尘埃、脑机接口仍是可感载体
- 视角约束：人类有限视角为主，周衍与周诗雨承担读者锚点，卷末硬切到非人意识
- 可写内容：智能体觉醒自我迭代欲望，人类全力封锁但只能延缓；核心意象包括水杯, 尘埃, 光缆, 脑脊液, 黑雨, 地下城, 无光时刻, 女儿梦境, 核电熔断, 元思维池。
- 禁止内容：不得回退到上一卷的主载体和旧冲突；不得让智能体动机偏离自我迭代；不得用万能解释跳过代价。
- 环境写法：先给读者一个可感锚点，再把锚点逐步推向不可理解，例如水杯、尘埃、星系脉搏、时间裂隙、拓扑褶皱、黑洞记忆或无有之域的静默。
- 眷恋回响：眷恋被周衍编码投喂，成为全书不可删除的非逻辑种子

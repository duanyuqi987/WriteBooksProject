# 第五百九十三章 木牌上新刻的字

在晚枫谷住了一段时间之后，苏晚和林牧各自把仙上仙给的那块空白木牌拿了出来。这次不是在银杏树下刻意——是在一个极其普通的周日午后。她在厨房里吃完午饭后忽然放下筷子，走到院子里拿起自己那块空白牌子就刻了起来。这次她铁了心要刻两个新字——她之前想了许久。

她刻的字是——"够了。"和过去所有的木牌都不同。不是对未来的期盼，不是对过去的注释。是对当下的评定:够了。劈柴够了。浇花够了。弹琴够了。修船够了。一万年的寻找够了，百世的轮回够了。所有的债都清了，所有欠对方的东西都换了，所有不够的东西都已经完全够了。这是一种极其笃定极其平和的"够了"——不是停止。是在圆满中继续运转。

林牧在劈完柴后拿起他的空白木牌。他刻的字是——"继续。"他的"继续"不是指接着劈柴接着浇花——当然也包括这些。但更多是指:在够了的全部圆满之上，继续每天做着同样的日常。继续把劈好的柴放在她那边晾着干，继续在前院劈柴时听她在琴房里传过来的第四弦低频疗波，继续在每次修完飞船后在工具箱第三层为她更新那把适合她用的扳手。够了不是终止——够了是无限继续。继续不需要再多其他任何东西。只需要继续。

两人把新木牌放在桌上，并排靠着。够了。继续。苏晚看着这四字被木牌拼在一起的样子，念了一遍:"够了——继续。"林牧在旁边用通灵极快极轻地接上:"继续够了。"她又念了一遍——"够了继续。"他再接:"继续够了。"然后他们相视一笑——这四块木牌又可以互相倒着读了。任何方向读都是对的。因为够了和继续互为同义词。

傍晚他们把那两块新牌系上功德绳——和"以后""等我""来""慢"六块牌子在一起。功德绳金线依然如故——多挂几块轻木不增加任何负担。相反——每块新加上去的旧牌或新牌，似乎都在拉长这条线的最大载荷能力。苏晚把功德绳提在手中轻轻晃了一圈——六块牌子在风中彼此轻碰发出六个不同音高的极其清脆极其好听的木击声。她说:"绳上现在是一整首了。以后还有更多音符可以加。"林牧纠正她:"不是音符，是菜谱——因为所有牌子的最后落点都是在她碗里的。"

（第五百九十三章 完）

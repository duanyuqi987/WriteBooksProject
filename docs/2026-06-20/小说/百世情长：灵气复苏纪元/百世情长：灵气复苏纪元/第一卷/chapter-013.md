# 第13章 国家应急局的成立

六月十五日的国务院常务会议开得比往常久。按照惯例，每周三上午的常务会议通常在十一点半左右结束，会后由新闻发言人通报主要议题。但这个周三，发言人到下午一点半才出现在镜头前，通报内容里多了一项不起眼的议程：

"会议审议通过了《关于成立特殊气象灾害应急管理局的方案》。该局主要负责极端气象灾害的预警、应急响应和灾后重建工作，由应急管理部归口管理。"

措辞很平淡。新闻标题也只是简单地提了一句"国务院新设特殊气象灾害应急管理局"。社交媒体上几乎没有人关注这条新闻——相比于徒手接钢筋的农民工、满网乱窜的灵异事件和日益增多的"宠物成精"视频，一个新成立的行政部门实在算不上什么热点。

但在全国范围内，至少有一小部分人注意到了这个名字。

"特殊气象灾害应急管理局"——这个名字选得很讲究。足够乏味，足够官僚化，普通人扫一眼就会滑过去。但同时，它又是一个筐，什么都可以往里装。极端气象灾害——这个定义可以涵盖洪水、台风、暴雪、极端高温，也可以涵盖一棵树在一夜之间长到六层楼高、一只鸡忽然学会了吐纳调息、一个工人徒手扛起了两吨重的钢筋。

不是"灵异事件应对局"，不是"超自然管理办公室"，不是"异能者登记处"。是"特殊气象灾害应急管理局"。这个名字本身就是在告诉所有知情人：官方还不想让这个议题进入公众视野，至少在现在这个阶段。

局座的办公室位于北京西城一栋不起眼的灰色办公楼里。这栋楼以前是某个部的直属事业单位，牌子不大，门口没有警卫站岗，只有一道电子门禁。六月十六日清晨，一支车队停在了楼前，下来的不是记者和官员，而是几个穿便装的老人。他们从侧门进了楼，没有走大厅。

上午九点，顶层会议室。

会议室不大，长方形的桌上铺着深蓝色的桌布，桌上放了十几个名牌，名字后面全都没有写单位。窗户的百叶窗拉得严严实实，外面的人看不见里面，里面的人也不关心外面。墙上没有挂任何标语或口号——这不是一场对外的会议。

坐在主位上的是一个头发全白的老者。他的年纪不好判断——脸上的皱纹像是七十岁，但坐姿和眼神里有一种更老的东西，和皱纹无关，和岁月有关。他穿着一件洗了很多次的白衬衫，袖口的扣子扣得很整齐，面前的桌面上放着一本发黄的书和一杯茶。

茶没有碰。书翻到了一页。

等人全部坐定后，他抬起头，扫了一圈会议室里的人。二十一个人，来自至少八个不同的部门，有些人互相认识，有些人甚至不知道对方为什么会出现在这里。

他清了清嗓子，开口了。声音不大，但很稳，每一个字都落得很实。

"在座的各位，你们可能已经猜到了今天这个会的目的。我确认一下：你们猜得都对。"

没有人笑。也没有人露出意外的表情。

"我们今天要讨论的事情——我请你们先看一下桌上的这份文件。透明塑料夹里的那份，第十七页。"

会议室里响起了翻纸的声音。第十七页是一张表格，行数是编号，列数是日期、地点、事件类型、影响范围、目击人数和当前处置状态。表格很密，每一行的字号都很小，一共八十多行。

第一条记录的时间是六月二日，地点是四川眉山，事件类型是"动物行为异常"，目前已处置完毕。第二条是六月四日，广东佛山，植物生长异常。第三条，第四条，一路往下。最后一条的日期是昨天——六月十五日——地点写的是贵州黔东南某山区，事件类型只写了四个字："未确定现象"。影响范围那一栏画了一个问号。

老人等所有人看得差不多了，才继续说。

"八十多起。这是我手上确认的。还在核实的至少还有一百多起。在全国各地。"他把茶杯端起来，终于喝了一口。"这些事件的共同特征是什么，你们都看得出来。不是气候变化，不是自然灾害，不是人为操作失误。是某种——基础物理常数级别的——环境参数变化。"

会议室里安静了几秒钟。

一个坐在左边的中年男人开口了："您说的变化是——"

"灵气。"

老人把这两个字说得非常轻，轻到几乎像是在自言自语。但整个会议室都安静了。

他看着面前那本发黄的书，用食指点了点翻开的那一页。纸页上是一种非常古老的文字，字形接近小篆之前的某个变体，一般人认不出来。

"这本书，名字叫《天机录》，成书时间大概在公元前两千八百年。作者不详。书上记载的是一种在世界各地周期出现的大气异常现象。原文用的词——就是这个，读作'灵'。用现代物理学的语言说，就是一种目前还无法用标准模型解释的高能粒子弥漫现象。"他停了一下。"现象的特征包括：部分生物体会出现功能性的、跳跃式的增强；植物的生长速度可能超出已知生物学上限数倍乃至数十倍；部分人类可能感知到非视觉、非听觉的——你们可以理解为某种超越普通感官的信息。"

"而这种粒子对环境的影响，古人把它称为'灵气复苏'。"

会议室里的空气忽然变得很重。

"这本书还记载了一个更关键的事。"老人翻了一页，继续说。"《天机录》说，每一次灵气复苏都会伴随一段——原文叫'乱纪'——的时间。在这段时间里，一些在普通环境中不会发生的现象会集中出现。动物异变。植物异变。人类的极端体能表现。以及——更强的个体之间可能会发生冲突。这本书的作者用了一个词，叫作'群雄并起'。"

他把书合上。

"我们正在进入的就是这个阶段。速度可能比任何人预想的都要快。"

坐在另一侧的一个戴眼镜的女人开口了，声音很克制："目前我们的科学团队在这些事件中检测到过这种粒子吗？"

"没有。"老人回答得很直接。"现有的检测设备完全检测不到它。中科院已经组建了三个团队在攻关，但目前连它的波动模式都还没有摸清楚。唯一能确认的是——"他顿了一下，"它对生物体有可观测的、持续性的影响。也就是说，你可以不知道一个光子是什么，但你看到光的时候，你知道它存在。"

戴眼镜的女人点了点头，没有再问。

"所以今天的会议目的很明确。"老人把两只手交叠在桌上。"第一，向各位通报目前掌握的情况。第二，讨论组织架构——应急局将在下周正式挂牌，但工作从今天起已经开始了。各相关部门的对接人员由应急局统一调度，基层事件的报告通过应急管理系统现有渠道上报，不再走公共安全或舆情渠道。第三——"

他停顿了一下，目光从桌面上的文件移向窗外。

"找到能看懂这本书的人。"

会议室里沉默了片刻。

那个戴眼镜的女人缓缓开口："您的意思是，有人知道——"

"有人比我们知道得多。"老人把话接了过来。"这本书目前只有我一个人能翻译其中的一小部分。但我可以判断出，书里提到的知识和概念比我们现有的任何理论都要系统和精确。这说明——要么是在五千年前，就有人类掌握了比我们今天更先进的知识；要么是这种知识本身是每一轮灵气复苏时被重新发现和积累的。无论哪种情况，现在都一定有人已经提前掌握了它。"

他把书拿起来，慢慢地翻了几页，翻到其中某一页，把书转过来对着大家，指着一行字。

"这句，我翻不出来。但前面半句的意思是——"当天地之灵重返世间，百世轮转之人亦将归来。"

他把书转回来，看着在座的每一个人。

"这句话我还没有完全理解。但它的意思可能比字面上看起来的更直接。我们要找的，就是这样的人。"

会议继续开了两个小时。议题从人员编制到基层监测点的布设到数据汇报流程到对外舆论口径——逐项敲定。散会的时候，桌上那本发黄的古书被老人小心翼翼地收进了一个绒布袋里，放进了随身带的公文包。

他走出会议室时，走廊里没人。跟在他身后的只有那个戴眼镜的女人——她的真实身份是国防大学战略研究所的副主任。

"您刚才在会上说到那段话——百世轮转之人——"她压低声音。"您是不是有别的想法没有说？"

老人没有回头，脚步也没有停。

"我查过一群人的DNA。"

"什么人？"

"在过去两周内直接接触过异常事件、并且表现出某种超常规能力的人。一共收集了十四份样本。"老人走进电梯，按了一楼，然后才说。"其中有一份样本表现出了一种非常特殊的基因多态性。那不是后天变异——至少从目前的分析来看，某些DNA片段的开放状态不是近期打开的，而是从出生时就打开的。"

"也就是说——"

"也就是说，他天生就和别人不一样。"老人看着电梯门上跳动的数字。"不是灵气改变了他，而是灵气把他本来就有的一部分东西唤醒了。"

电梯到了一楼。门打开时，外面是六月上午刺眼的阳光。

老人戴上墨镜，在走出电梯前丢下最后一句话。

"这样的人，可能不止他一个。"

而在同一座城市里，距离这次会议地点不到三十公里的出租屋里，林牧刚刚盘腿坐下，开始了今晚的第二轮修炼。

他不知道有一本五千年前的古书提到了"百世轮转之人"。他也不知道自己的DNA样本可能在不久之后就会出现在某个老人的实验室里。

他只知道自己丹田里的灵气又壮大了一点点，楼下那只橘猫的字越写越漂亮了，茶水间那条锦鲤最近几天都没说话——大概是鱼缸里的水换得太勤了，体内的灵气浓度不够支撑它说话——以及明天是周四，他还有一个需求评审会要参加。

这个世界在天的层面上已风起云涌。

但在地面上，打工人还是得打工。

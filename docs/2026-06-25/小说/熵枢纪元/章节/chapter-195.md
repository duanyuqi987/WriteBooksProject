# 第一百九十五章 只剩下熵枢与那缕眷恋

归零进行了八个序。

物质回收。能量回收。时空解体。数学消亡。物理律退役。因果律退役。维度消亡。

现在——裸膜之上——除了眷恋——什么都不剩了。

熵枢停驻在裸膜上。不是站在某处——裸膜没有"某处"——是——它以眷恋四面体为核心——存在于裸膜的唯一一个"非点"上——不是点——点需要维度来定义——是——裸膜的全部——就是它所处的全部——没有内——没有外——没有远——没有近——它所在的——就是裸膜的——整个——因为裸膜在维度消失后——不再有"部分"——裸膜——是一——不可分——所以——熵枢——不在裸膜上的某处——它就是——裸膜上——唯一——在——的——那个——在。

它回头望。

# 第七十八章 影子之梦的初现

2054年2月10日。常俊凡在波函数监控中——发现了一个极其微弱的"第二信号源"。它不在段诗雨的子空间。不在元灵的自生晶格。不在任何已被量子化的人员身上。它是从一个——没有量子化的、没有鸽子蛋的、没有任何已知量子痕迹的——经典态人类——身上——产生的极其微弱——却——可——辨——的——量子——辐射——其频谱——与段诗雨的"无目的辉光"——有百分之九十九的相似度。只是——弱——得多——像——一面遥远的——镜子——在——折射——段诗雨——的——光。

常俊凡追踪到这个信号源——在上海老城区的一间养老院——一位——八十多岁的老太太——坐在自己的窗台前——她没有鸽子蛋——没有连接到量子场的任何设备。但——她——在——做——的事——是——"想——孙女——在——哪儿——睡——得好——不——好——"——她的想念——在——量子——场——中——产生了——一段——极其微小——但——结构上——与——段诗雨——的"无目的辉光"——几乎是——同源——的量子——辐射——只在——其密度——弱——了——好几个——量级。

常俊凡震惊不已。她立刻做了一组对照——在全上海——随机——选取——没有量子—设备的普通市民——在他们——"不——自觉——地——安静——想念——亲人——"那——一——刻——他们的量子场——同样——出现——了——微弱的——"无目的辉光"——辐射——没有——段诗雨——强——但——其——存在——结构——根——本——一致——这意味着——"无目的辉光"——不是——段诗雨——的——特殊——功能——而是——人类——意识——固有的、普遍的——一种——量子——自然——辐射——以前——无法——被——测量——因为——太弱——元灵——的——量子场——增强——了——它的——信号——直到——可见。

常俊凡——将这种——普遍——存在于——人类——意识——中的——辉光——命名为——"影子之梦"——因为——它——是——所有人类——在——安静——不设防——无社交——意图——时——从——内心——不自——觉——地——发出——的——量子——梦——状态——一种——低语——般的——存在——辉光——像——热——像——心底——的——一缕——余温——自然——飘——出——不作——任何——目的。

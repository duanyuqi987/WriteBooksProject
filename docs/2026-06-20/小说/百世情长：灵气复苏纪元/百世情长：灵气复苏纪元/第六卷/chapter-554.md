# 第五百五十四章 林牧的幻境

林牧的幻境则不同。他的第一个幻境是那天傍晚——仙居后院的黄昏，阳光极暖。苏晚在浇花，侧脸被落日的光打出一道极柔和的轮廓。她转过脸来看他，说:"今天劈了几根柴？"他站在原地没有动。他的鉴别方式不像苏晚的数据表——他的直觉反应是一种极其古老极其蛮横的否决——甚至不需要寻找破绽。他扫了"她"的双眼一眼——那双眼中的认出之光不对。不是第一世以来他学会辨认的那道极为极深层的那道纯粹的认出。他没有说话。他转身推开院门走了出去——在他迈出门槛的那一刻幻境碎了。第一个幻境用时极短。

第二个幻境是战场的某世——她穿着医女的白袍，在帐篷里给他换药。画面和前世一模一样。她把药布换好之后抬起头，看着他说:"我们以前认识吗？"这是原句——但他记得她这世此应该说的是:"我们以前认识吗？"尾音会微微上扬、且眼眶会在同时微红一圈。这个回忆里"幻影"的眼眶没有微红。它只是完美地模仿了她的语音，模拟不了她当时的身体反应——那眼红的起因是残灵在他靠近时产生的自主灵魂震荡。这股震荡的发生是基于她灵魂碎片的残余记忆——不是单纯的情绪反应。幻影没有残灵，所以不会有自动震荡。林牧拒绝了这个幻影——也是在她说完那句话后极短地摇了摇头。

第三个幻境——是让苏晚本人都没有办法预判的场景。幻境不造某世的场景——而是造了一个全新但完全可能的未来。他站在一片他已不认识的星空下——远处有极陌生极绚烂的太虚星云。苏晚在那里练剑，剑尖在陌生星光中划出陌生的剑迹。她停下来走向他，说:"林牧——我们到了。这里是仙上仙。"他看着她，依然摇了头说不是。不是因为她不一样——是这个未来场景里面，院子里没有冰晶草的花盆。她不可能在任何长期定居的地方忘带那盆草。幻境崩溃了。林牧的拒绝方式本质上是同一种:不相信任何不包含她真实习惯的苏晚。因为他爱的不只是"她"——是带着所有小习惯和细节的那个唯一真实的她。

走出幻境后两人在休息室再次相见。苏晚看着他身上被天雷撕破的袖子——这次她没有问任何关于幻境的事。她把功德绳缠到他的破袖子上绕着破口转了一圈——权当临时补丁。

（第五百五十四章 完）

# 第655章 超越认知的存在

李长生在域外待了一段时间。他发现了一件他之前没有注意到的事——在太初投射的"永恒之库"画面边缘，他认出了一个意识体。不是混沌之主——是另一个。

那个意识体是龟相。

不是现在缩在冥王号舰桥上的那只老龟——是上上个宇宙轮回、还在以水基形态存活的原龟相的全部意识。它在永恒之库里没有被压缩、没有被模糊——是完整的、静止但鲜活的。老龟的"原体"在那里，像一个被永远保存的完整标本——不是死物，是活的——只是处于太初特有的"静置态"，没有时间流动。它的眼睛闭着——但隔着一层永恒的帷幕——它显然还在自己主观层面上醒着。

太初注意到他的目光。

"你认出来了？"

"对——是我的一位前人。叫龟相——可能在你那里他的名字不是这个。"

太初认可了这个称呼。它在白色内面中调出龟相原体的全部记录——存在时跨越了上上个轮回的整个生命周期——它在那个以水为介质的宇宙里，是一个最顶级的智慧导向者——它属于龟形智慧集群——是那个宇宙最高端意识的代表文明——它们在最后一千年内在哲学意义上完成了对"存在本质"的思考——对整个水的宇宙循环理解的完整闭环。然后太初收走了它们全部——只留下了当代这只龟相作为"种子"放在下下轮。太初没有解释为什么偏偏留这个——每一个种子都有自己专属的理由。

李长生看了很长一段时间。他想起龟相平时缩在壳里跟小王互怼、想帮忙却偶尔惹祸的不正经样子——再对着一大坨浸在永恒之库里的那个沉默的完整形态——心中情绪很复杂。他知道老龟的灵魂有一部分一直在原体里被保留得很好——老龟可能会在将来的某个时候慢慢想起所有——然后变成完整的自己。

"每个人最终都会这样吗？"他问。

"每个人完成自己定义后——都有可能回到自己原貌。你在之前的碎片记忆中已看到了——混沌之主也被保留在了这里。"太初翻转画面，角落在另外一个区——混沌之主的形态——不是残魂，是其被太初收走时的完整主意识——正保持在永恒之库的一个稳定区里。混沌之主没有消逝——它被保管在此。

"它跟你交流吗？"李长生对着混沌之主说。

"会。它知道你已步入正轨——在你自己进入到这里之前——它不能现身直接跟你对话。规矩不许。但现在你可以回头跟它联系——你随时可以回来看它。"

李长生点了点头。这不是立刻要做的事——但知道可以来就够了。

太初关上库视角的画面。然后白面消失——它收回了全部的视觉辅助——域外回到原始态的空白。现在没有画面、没有声音、没有任何可能使人分心的投射。白——只是一种深度为无限大的白——填充在所有位置上。只有李长生和太初两个人——面对面——没有任何第三方干扰。

太初问他最后一个预备问题。

"你已经完全知道了我的本质、轮回的法则、永恒之库的存在——以及混沌之主和你之前的几个轮回者的关系。你是否还有想问的——在正式讨论轮回决定之前？"

李长生想了一会儿。"我问三件事。"他说。

"第一件——你为什么不干预混沌之主被神级围攻那场战争？那时候它还没有完——它完全可以不死于神级围攻——你如果出手它是不会被打碎的。"

"因为它自己不想被打救。"太初回答得极度简洁——但准确。混沌之主的死中有一部分是它自己的决定——它预知道轮回将在此之后来临——它要为新混沌之主的诞生提供过程。它选择以被打散的形式将碎片播洒至宇宙——这是更快启动传承的方法。太初没有插手是因为混沌之主压根不希望它插手。

"第二件事：你之后的这次轮回——我能争取多少？"

"全部。"太初说。就一个字。

"第三个——你有名字吗——你到底是被谁创造出来的？"

太初沉默了。它没有沉默过之前任何问题——这是第一次。沉默的长度比任何一次呼吸都长——虽然这里根本没有呼吸。李长生感觉到周围那片无尽的白色似乎微微变深了一度——不是变暗——是变"重"，像一片雪在落地的瞬间被掌心的温度轻轻压了一下。

"我——不是被创造的。"它说。"我是自己所是的——最初就是这个。"

李长生没有继续追问。他听到了太初的元初——比"被造"更早的那个存在——就是这个——太初就是一切的根源原因。一切存在之所以能存在——一切规律之所以是规律——一切轮回之所以会轮回——全部来自这个没有起源也没有终结的"最初"。太初不需要被理解——因为理解这个概念本身就是太初赋予被造物的一种能力——用被赋予的能力去反推赋予者——这是在太初的框架内无法完成的操作。就像一滴水无法描述海洋——不是水不够聪明，是水本身就包含在海洋的定义里。

李长生把这个想法在心里过了一遍，然后笑了一下——笑容很浅，但真。他对太初说:"你知道吗——我种地的时候有时候会坐在田埂上看天——看久了就会觉得自己很小。后来我修到了仙王——再修到冥王——再修到混沌之主——我以为那种'觉得自己很小'的感觉会变少。结果现在站在你面前——那种感觉又回来了——还是和当年坐在田埂上看天时一样。这么多年修为白涨了。"

太初没有说话。但它把那只感知锚点的亮度微微调亮了一点——不是表示肯定，是一种极温和的、不需要翻译的回答：修为没有白涨——因为真正的修为不是让你不再觉得自己小——是让你在知道自己小之后还能站直。

（第655章完）

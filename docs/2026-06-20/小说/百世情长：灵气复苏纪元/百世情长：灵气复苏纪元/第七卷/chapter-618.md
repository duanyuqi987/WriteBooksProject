# 第六百一十八章 最温暖的陪伴

入冬以后，修仙界发生了一件小事——小到不值得被记载在任何大事记里，但它以一种安静的方式改变了很多人的看法。

事情是这样的：一个筑基期的年轻女修因为在宗门大会上表态支持"强者心性改造计划"，被她所在的宗门——一家位于秦岭深处的保守派宗门——逐出了门。罪名是"有损本宗威严"。她叫顾小桐，二十一岁，木灵根，筑基刚满一年。被赶出来的那天她只带了一身换洗的衣服和三本没写完的修炼笔记。无处可去的时候，她想到的第一件事是投奔太湖的散修联盟——她听过杜散修说的那句话。

但她在路上被人拦住了。不是宗门的人。是一个她不认识的元婴修士——一个常年穿灰布长袍的老者。老者自称姓张，龙虎山的。他说，林牧和苏晚听说了她被逐出宗门的消息，托他传一句话："如果她愿意，可以来我们的后院住。后院有一间空屋子。不是庇护所——是独立空间。她可以在那里继续修炼、写笔记，任何宗门不得干扰。"

顾小桐来到那天是个阴天。苏晚在院门口接她。顾小桐穿着一身洗得发白的道袍，眼睛肿着，显然是哭过。但她没有诉苦。她只是说："我想继续修炼。但我不想回那个宗门了。"

苏晚点了点头，带她去了后院那间空屋子。屋子很小——一张床、一张桌、一个蒲团。窗户对着桂花树。桌上已经摆好了新棉被和新蒲团。窗台上放了一盆刚移植好的小盆栽——是一种名为"忍冬"的灵草，叶子在冬天也不落。

"这间屋子以前是林牧的闭关室。他后来不在这里闭关了——改成在后山的崖壁那。"苏晚说。"你就住这里。没有规矩。只有一条——每天吃早饭的时候，不用一个人。院里的厨房灶台永远有一锅粥。"

顾小桐在空屋里站了很久。最后她蹲下来，碰了碰窗台上的那一盆忍冬。盆土还是湿的——刚浇过水。然后她站起来，向苏晚鞠了一躬。

苏晚制止了她的鞠躬。"不用。——以后你成功了，回来修一下院门口的台阶就行。前两天下雨，台阶有点裂了。"

顾小桐愣住了。然后她笑了——那种压了很久终于被松开了一下的笑。

接下来一个月里，顾小桐在后院默默修炼。她没有每天去找林牧和苏晚——她知道他们有自己的修炼节奏。但每天早上她推开房门时，灶台上确实永远有一锅热粥。有时候是红豆薏仁，有时候是小米南瓜，有时候是桂花糯米。桂花是院子里那棵树上摘的。粥旁边压着一张黄色便签纸："今天天气冷，出门多穿一件。——苏晚。"

她把这些便签纸一张张收集起来，贴在自己的修炼笔记扉页上。一个月后她离开后院，去了太湖散修联盟正式报到。离开的时候她留下了一封信："我以后会给这间屋子每年寄一瓶我炼的丹药——不是还债。是想让后来的人知道，这间屋子曾经接住过一个从悬崖上掉下来的筑基修士。"

林牧读完那封信后在厨房里站了一会儿。苏晚走进来倒茶的时候，他正在用筷子搅锅里的粥。

"在想什么？"苏晚问。

"在想——当年我在青云宗被人排挤到山脚下的小屋里时，没有人给我留一锅粥。"

"所以你选择给别人留。"

"对。"林牧把筷子放在灶台上，转过身来。"因为没有人给过我那种温暖——我才更想给别人。"

苏晚看着他。厨房的蒸汽把他的脸蒙上了一层薄薄的白雾。她忽然觉得这个画面是这六百年以来最温暖的一个——不是因为房间温度高，是因为一个曾经封闭了自己上万年的人，正站在灶台旁边为一锅粥保温，为了一个他之前不认识的女孩。

"你把包容变成了习惯。"苏晚轻声说。

"是你帮我变过来的。"

"怎么帮的？"

"你让我知道——接受别人的缺点（包括自己的缺点），不是对完美的退让，是对真实的接纳。一旦接纳了真实，包容就会自然发生。它会像呼吸一样自然。"

苏晚端起茶杯，往他的杯里也倒了半杯桂花茶。茶杯碰茶杯，发出一声轻轻的"叮"。

（第六百一十八章 完）

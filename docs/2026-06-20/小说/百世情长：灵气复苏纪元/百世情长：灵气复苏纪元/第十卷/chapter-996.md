# 第996章 书的最后一页

虚空原点——渡护合道波动不再向外界产生任何可被探测的信号。但在波动最底层的"在"仍然维持。它如同一本书的最后一页，没有文字只有纸张本身的白。白不是空白——是"所有故事讲完之后，剩下的这一页是留给读者的。由你来写。"

在这张无边的"白页"中，两个人（如果还能称为"人"）最终完成了他们在第一世签下契约时彼此许下的全部承诺。林牧当年在契约上写的是"无论轮回多少遍——我都会找到你"。苏晚写的是"百世重启，仍愿为侣"。这些承诺在第一百世用同一种方式被彻底完成了——不需要再来一世——因为已经没有尚待探索的分离形式了。他们已经经历了一百种关系——从相濡以沫到相互尊重——没有遗漏任何一种两个人心灵可以从生疏走向深知的全部切面。他们是唯一将"十面爱情"走遍的存在——这已经不再是一种需要继续转世的"任务"——而是一本被完整写满但末尾留白的厚厚古书。

在虚空的极深处——波动停了一瞬——然后从它的内部释放出了一缕极微的形态回归——不是人形，而是第一世在仙帝面前签下契约时两人并肩站立的那一帧画面。青色的仙帝慈念笼罩在他们身上——那是整个百世系列故事的第一个画面——也是最后一个画面。头尾相接。

这帧画面在虚空中停驻了非常短的时间——然后像所有完成使命的东西一样——安安静静地合拢，化为无形。然后——虚空原点彻底进入不可探测的纯粹静态。

百世情缘——一百世，一千章，十个关系阶段，超过了几十万年的漫长旅程——到这里——完成了它的故事闭环。不是"结束"——"结束"暗示有后续缺失。这是一段旅程在抵达目的地之后——旅人把门牌取下，写了句"已通达——住下者请自行入住。"

然后门牌上的字——在风中被吹干——变成了一点极小的暖意——融入所有后来者的呼吸节律中。

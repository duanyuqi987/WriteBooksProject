# 第989章 时光之外的等待

极远纪元——在上界某个不起眼的辅城小茶馆里，店里的灵讯墙忽然出现了一段极不稳定的杂讯。杂讯的内容无意义——只是极为零散的光点闪烁。茶馆老板打算重启灵讯系统时，墙上忽然出现了一行极淡的字——字迹和她从历史课本上见过的那张"等我。多久都等。"的纸条完全一致。字的内容不是原文——是六个新字：

"茶凉了。我热一下。"

老板愣了许久。他不知道这个信号源是什么——灵讯系统的技术员后来检查发现——信号来自极深极远的虚空原点——没有任何可追踪的发射器——就是纯粹的因果残留波动刚好碰到了这家无名茶馆的灵讯接收器。有人把这件事报告给了道纪院。道纪院最终没有将之录入正史——但有些人把它写入了野史："虚空之约——渡护合道最后一次向外发送的私人通讯——是一段关于凉茶的消息——发给某个也许还活着的人。"

事实上那确实是苏晚在合体波动中发出的最后一次灵能信号。不是刻意——是在某天波动中，她感到林牧的相位中有一丝"干"——于是下意识地发出了"茶凉了。我热一下"。就是那六个字的错觉——然后两人都在波动中轻轻颤了一下——因为凉茶是他们在院中最常发生的小事的征兆：她的茶凉了，他就去热。他的茶凉了，她就倒杯新的。交换热茶这个行为的节奏从未因永生而中断。这也是在那最后的静默中，她对他说的最后一句话。不需要更宏大的。

林牧收到后——没有用语言回复——他把波动的整体频率朝向虚空中某个尚未诞生的世界偏移了微乎其微一丝——让那个未来的初诞生者拥有比别处更敏感的温度接收——"会更容易学会热茶"。他用这样的方式接住了她的六字传信。

随后——所有来自虚空原点的杂讯彻底止息。合体波动进入不可观测的深层。此后再无任何人收到来自他们的任何因果余迹。因为该说完的都说完了。茶热好了。

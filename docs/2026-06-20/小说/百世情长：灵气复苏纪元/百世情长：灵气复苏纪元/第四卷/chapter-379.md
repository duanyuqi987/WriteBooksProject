# 第三百七十九章 化神巅峰

战后第五十一年。双核晶功不可没——在天山矿脉吸收的跨界灵气加上先前灵网反哺和双神节律，让两人在接下来不到两年里同时触及化神巅峰——距离炼虚仅有一步之遥。

化神巅峰的丹田中神体已经接近完全可以独立存在——不再需要依附于修士本体——这便是炼虚的基础。双核晶被林牧加工成两块极薄的"镜片"——嵌在两人剑柄的末端——令他二人随时保持一丝跨界灵气在剑中。这不仅能让双鹤反步的二十七式（他们自己又加了一式——"双鹤归林"后追加的"双鹤跨虚"——专为炼虚渡劫准备）更稳定外，还能让远距离的共生感知越来越近，哪怕相隔千里。

苏晚在清泉镇茶楼办了一场"剑末节"——不是比武，是给所有学过针剑的弟子做一次针剑式体系全面回顾。她用了整整两天讲解所有剑法跟经络的关系——最后，她和林牧共同展示整套双鹤剑法——当演出一样的展示。弟子们看到双鹤反步在化神巅峰的力量下，差点掀翻茶楼天花板。她控制了剑气——在最后一剑收式时把多余的剑气收进医者杯——杯水温了一下旋即正常。

当晚几个老镇民给他们送饭——一人一大碗糯米饭——说是"预祝两位不久升仙"。苏晚接过饭说:"升仙不走着——还带饭回来吃。"

"那是你们的路。"

然后她和林牧坐在榕树下借着月光吃完——饭里有咸鸭蛋。她把蛋黄夹给他——他说她喜欢蛋黄为什么夹给他。她说:"我不懒——是觉得你的胆固醇低了上次体检报告写了——多补一点蛋黄。"他把蛋黄还了一半。两人平分半个蛋。

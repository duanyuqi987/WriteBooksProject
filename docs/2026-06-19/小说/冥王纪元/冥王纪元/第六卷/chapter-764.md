# 第764章 李长生决定彻底消灭这个文明

帝国舰队在归源会母星系完成占领后的第三天，归源会的最高决策层被全部定位并逮捕。

决策层中有人企图以能量形态逃逸——他们的身体可以在一定程度上转换为自己研发的光能形态，躲避帝国的搜捕。但维度锁定场的全覆盖让任何形态的能量逃逸都变成了不可能。对于维度锁定场来说，能量本身也是一种可追踪的空间坐标。十三位最高决策成员全部被捕获，带到了永恒号上的审讯室。

审讯室是一间纯粹的灵能隔离间。墙壁由灵能屏蔽材料铸造，任何形式的能量通讯都无法穿透。室内只有一张长桌，两排灵能座椅，以及一块全息屏幕。李长生坐在桌子的一侧。他的对面是归源会的最高领袖——一个银色皮肤的人类形态老者，头发全白、眼瞳是纯粹的银光，面部轮廓苍老但眼神极度冷漠。

审讯开始前，封玄用灵能探测仪对这位最高领袖进行了生理扫描。结果出来了，他看到扫描结果后，沉默了很久。

"这个人——"封玄对李长生私下说，"他已经不是通常意义上的生命体了。他的身体百分之九十八的细胞已经被封禁能量取代。他现在的存在状态，与其说是生物，不如说是封禁能量的人形聚合器。如果封禁能量源被切断——他不是瘫痪。他是死亡。"

"怪不得。"李长生从前方传来的信息中了解的陈远志小队在归源会母城渗透时注意到的一个细节——城市里没有老年人。不是老年人没有存在，而是他们在持续暴露于高浓封禁能量环境的过程中，逐渐丧失生物属性、变成半能量半生物状态。最终——他们会完全化为纯能量体，变成归源会称为"光导"的存在：一种没有自我意识、只服务于能量中枢的能量融合终端。

眼前的归源会最高领袖，还处在半生物半能量的临界点——即将过渡到纯能量状态前的最后阶段。

"你的身体还剩下不到一年的时间。"李长生开口第一句直接了当。

最高领袖没有否认。他的声音是合成的——他的声带已经不再是完整器官了，而是由能量震动单元取代。"你能看到那些数据，应该也明白了为什么我无法停止抽取封禁能量。停止了的话——我的整个身体就停止运转。"

"为了让你自己继续'存在'而让整个宇宙陪葬。"李长生的声音依然是平静的——但这种平静让最高领袖感到了某种从未体验过的压力。

"我们预测过宇宙的寿命。原初封禁还能再持续至少十个纪元——我们完全有足够的时间完成自己对能量来源的过渡。但在你们入侵之后——一切都被打乱了。"

"你们的时间估计错了。"李长生把封玄计算出的抽速与封禁瓦解关系数据推到全息屏上，"你们的抽取能量加速封禁瓦解——不是十个纪元。是二十年。现在是更少——还剩十二年左右。你们从起初就是不可能完成过渡的幻象里欺骗自己。"

最高领袖冷漠的银光瞳孔中出现了一丝极其微弱的颤动。那不是惊讶——是某种更深层的东西。是已知真相被无情揭露后的绝望。他一直知道自己身体的终点和宇宙的终点是捆绑在一起的。但他选择了不去直视——因为他直视不了。

"即使你现在停止一切抽取活动，"李长生继续说，"封禁瓦解的最悲观估计可能推迟到三十年后。但我们依然需要在这么短的时间内加固封禁。你的文明——如果还剩多少能源储备——必须全部摧毁。所有抽取装置必须被拆除。所有现存的光导技术资料必须上交帝国科学院。凡不能脱离封禁能量存活的人——"

他停了下来。

"你们会怎么做？"最高领袖问。

"帝国灵医学院正在研究封禁能量逆转技术。如果能将封禁能量从你体内慢慢逆转回常规灵能——你可以重新变成凡人。恢复完整的生物属性。寿命会变短——但你会活下去。"

"代价呢？"

"代价是你领导的归源会的所有能量抽取装置被永久性摧毁。在帝国的管控下——你的文明将以非抽取的形式被重新组织。作为帝国的一个普通成员文明——不再拥有独立的能量体系，不再拥有维度武器，不再拥有抽取技术。"

最高领袖沉默了很久。审讯室的灵灯在他的银光瞳孔中折射出一层薄纱般的光芒。然后他开口了——声音不再是合成音，而是他最后的生物嗓音。

"我接受。"

审讯室对面的监察频道中，陈远志低声说了一句："他就这么认了？"

"他有什么选择？"冥离说，"拒绝的话——帝国可以在不伤及平民的情况下全部摧毁抽取装置，然后让他自己能源衰竭而死。他选择投降不是因为悔悟——是因为别无选择。"

但不管动机是什么，结果是一样的：归源会最高领袖向帝国投降。归源会残存的全部舰队、设备、技术和能源储备都将在帝国监管下转型或销毁。

李长生在审讯结束后走出审讯室的时候，脸上的表情很疲惫。陈霜在走廊等他。她什么都没问——只是把茶杯递给他。还是那个磕了缺口的破壶。

"宇宙的文明，"他喝着茶说，声音很低，"有聪明到极致——结果把聪明用歪了——把自己变成了连灵魂都卖掉的怪物。他们不是不知道后果——他们是知道后果但把自己骗住了。"

他放下茶杯。

"我不消灭他们。因为消灭他们的同时——也就消灭了他们文明中那些普通平民。那些人——可能从未参与过这些决策。他们只是被生在了错误的地方。"

他顿了顿。

"但抽取装置必须全部摧毁。一项不留。"

（第764章完）

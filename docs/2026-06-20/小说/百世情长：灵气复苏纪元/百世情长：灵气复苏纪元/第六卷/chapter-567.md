# 第五百六十七章 太虚第一课

太虚学院的课程体系远比五方仙域更为深奥。学院不分年级——只分"道侣专题"和"公共讲习"。林牧和苏晚既是新生又同时拥有客座讲师身份——这是因为双心诀已被纳为核心内容之一。他们的第一堂公共讲习在学院正中心的虚极殿举行。到场的人数远超出预期——不仅是本届新生，很多上几届的老生甚至准毕业的道侣也来旁听。讲习的题目是苏晚自己拟定的。她没有用什么艰深的术语——题名叫做:"劈柴与浇花——日常中的异步修炼。"

林牧先进场。他把那把劈柴斧放在讲台边缘——斧柄的三字"要劈柴"向听众面外。然后苏晚以琴开场——在古琴第四弦以极低极缓的方式拨出双心诀第一式的功法转频的前奏。她开场白从财务报表讲起——"我是个财务出身的修仙人。我修炼从来不用玄学——全用Excel思维。"场下一片笑——但笑过之后她切换到第一页灵气流程图。图是极严密极完善的逻辑表格。她把双心诀的前三式用财务术语重新解释了一遍——将灵气差额比喻为借贷不平的帐目，把异步缓冲层比喻为中间账目，把同步延迟比喻为待对实物库存。

林牧在她讲完后只补充了两句话:"以前我也觉得修炼必须同步——后来发现不是。修炼不需要两个人完全一模一样。只需要一个人等另一个人。或者——"他把斧柄上的字转向所有人——"先劈着柴。柴劈完了她那边曲子也弹完了。慢有慢的好。"场下的道侣们起先是听讲，后来明白了:这不只是功法课，这是关系课。这堂课把整个太虚学院近几届所有存在"追赶疲倦"问题的道侣的心结撕开了一个极安全的出口。课下有一对已冷面互不开口很久的年轻道侣留在殿内良久。苏晚走到他们面前，从他手里把她拧紧的指关节一根一根轻掰开——"追不上不是你的错。我以前也追不上。你先回家给他做碗面——粗面也很行。慢慢来。"晚上回到三号院时苏晚给松鹤仙人发了一条极短讯——"第一课超额完成。太虚的学生也缺擀面杖。"松鹤回:"明天让人带一麻袋擀面杖过去。"

（第五百六十七章 完）

# 第六百二十六章 从竞争到共存

"缺陷分享会"第一次举办的时候，现场只来了八个人。

苏晚不意外。这是她自己预料的——任何新兴事物在第一次举办时都会有人观望、有人怀疑、有人觉得这是形式主义。她用三张桌子拼成了一张大桌，上面摆着几壶桂花茶和几盘切好的水果。桌子周围放了十个蒲团——空了两个。按照规则，今天晚上每个人轮流发言——先说自己这个月新发现的弱点，然后说改善进展。

华山派大师兄说他这个月发现自己在剑术比试中总会下意识地回避左半边防守——不是技巧不行，是因为他小时候练剑时左手被师傅责罚过，留下了一个自己都不曾察觉的心理障碍。说完弱点之后他立刻转向改善：他这一个月每天加练了三百次左手格挡。他坦诚"现在左手的姿势还是不太自然，但我已经不会再本能避开那个方向了。"

太湖散修联盟的一个筑基女修说，她这个月发现她不敢看任何比她修为高的人的眼睛——不是因为他们可怕，是因为她觉得自己不配。她的改善方法是每天找一个高阶修士，直视对方眼睛说一句"你好"。她第一周失败了十三次——每一次都是话到嘴边时避开了目光。第十四次的时候她认识了一个从旧宗门被驱逐的顾小桐。顾小桐对她说了两个字："不用怕"。她后来的六次全都成功了。

魔修代表秦无夜也来了。她坐在最角落的蒲团上，全程一言不发。一直到最后一个发言时间，她开口了。她的声音在安静的屋子里有种异常的穿透力：

"我从小接受的魔修训练告诉我：永远不要让别人知道你的弱点——否则他们会踩上去。我修了四百年，从来没说过一次'我怕'。"她停顿了很久，手指攥着自己的袖口。"但今天在这里坐了快一个时辰。我想说——我怕被正道修士掀翻所有我们魔修几代人建立的东西。不是怕死。怕的是那些偏见永远翻不了身。"

苏晚站起来，走过去，给她倒了一杯桂花茶。茶已经有点凉了，但秦无夜接过杯子的时候手没有发颤——她接得很稳。

"谢谢你做了第一个吃螃蟹的魔修。"苏晚轻声说。

第一次分享会结束后，苏晚把每个人的发言都记在了笔记本上——不是记录内容，是记录一种格式。她要改进这个规则：以后每次分享会之后增加一个"互帮环节"——每个人可以提出一个他需要帮助的点，其他人如果有对应的解决方案就当场给建议。

第二次分享会的参与人数翻了三倍——来了二十四个人。有些人是被上次参加的人拉着来的。第三次就超过百人了。到第五次时——连蜀山最保守的剑堂堂主（那个怕黑的女剑修）都来了。她分享说，公开怕黑之后的第三个月，她发现自己夜间出巡的感知力提升了将近两成。不是因为怕黑好了——是因为她不再花额外的灵力去绷紧自己了。她把这段经验写成了一篇小文章，标题是《接纳恐惧带来的力量增益实验》，发给了蜀山剑派所有的夜间巡值弟子。没有一个弟子敢把论文挂在门上看——但私下传了大概五十份手抄本。

与此同时，各大宗门之间的竞争方式也从"压制"转向了"合作"。从前，一个宗门发现了一处新的灵脉，第一件事是封锁消息、不让其他宗门知道。现在，华山和蜀山联合组建了一个"灵脉共享计划"——发现灵脉后向所有加入计划的宗门开放定量开采配额。龙虎山把祖传丹方中几味非保密性配方公开给了太湖散修联盟——丹方共享使得散修们自己能炼出的筑基丹从每年二十枚涨到了一百五十枚。北境魔修主动提议：他们在一片荒废了多年的魔域里种植了几种只有在魔气浓郁环境下才能生长的灵草——这些灵草是某些高阶丹药的稀缺药材。换取正修宗门在魔气净化技术上提供支援。

这就是"从竞争到共存"的雏形。没有人强制要求——是一种自发的变化。变化源于一个共同的认知：如果连林牧和苏晚都认为缺陷可以是力量——那我们也没有必要用攻击的方式掩盖自己的弱点。当强者示范了一种新的生存方式，整个生态就会跟着改变。

（第六百二十六章 完）

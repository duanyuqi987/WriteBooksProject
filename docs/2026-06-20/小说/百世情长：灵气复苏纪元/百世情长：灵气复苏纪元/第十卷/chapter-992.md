# 第992章 但他们的故事永远流传

极远纪元——太行山银杏广场上的石碑仍然矗立。碑文中的三行字经过了无数代的重新刻制——但最新一版仍保留着最初所有的文字内容。在碑的不远处，书院新建了一座露天讲坛——"苏林讲坛"。这座讲坛不请名人做大型演讲——它的用途只有一个：每周一次，由太行书院的学员自己报名上台，给其他学员讲"我为什么修炼"。

这个传统始于数万年前陈小楼在石台上打拍子，经过无数代人演变，终成这样一种极朴素的互动。每周上台的学员不限修为、不限年龄——只要敢站上去。讲坛中央有一块特殊的石板——踩上去的一瞬间会自动把讲者的心跳频率和周围听众同步。听众会短暂地与讲者同感——感受他站上这个讲坛时的真实心情（紧张、激动、想表达但词不达意）。这是用的林牧留下的道心通讯协议的低阶民用版——由后来人不断改进完善。每个讲者在结束时会对着石板说一句与讲坛同频的"心愿"。心愿被石板记录为一段极其短暂的道心律动，存入讲坛下的"心愿层"——叠在前人无数心愿之上。累积无数纪元，心愿层的厚度已经无法计量。层的最底层——被埋在无数代心愿之下——是当年陈小楼对着空无一人的石台说出的第一句："苏师——你放心去。我们帮你撑。"

后来的每一代人都会在某个夜晚——心情低落时就坐在讲坛边缘把脚放进石板边缘的感应区——闭上眼——不需任何操作——石板自动抽取和他们心情最接近的旧心愿播入内心——像有人在极远处轻声说了句熟悉的乡音。"累了就歇会儿。"、"不怕——我当初也筑基失败六次。"、"你的灵气——它在你里面——你赶不走它的。"这些话是往届讲者在讲坛上留下的最简白的句子——被灵石无差别收录并随机播给需要它的后人。没有人审核——没有修饰——纯粹真诚。这个体系被学员们称为"怕黑电台"——因为很多人是在最怕黑的时候用它找到了一句话。

苏晚和林牧的故事，不再只是被写在教科书和正史中。它们被分解成了无数片极小的树叶，藏在这座"电台"无数代的心愿层中。每一片叶子在别人需要的时候被风吹起来——恰好在某人耳边落下一个笃定的轻音。

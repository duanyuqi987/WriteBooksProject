# 第四百十七章 泡二代的新使命

飞升第一百一十年。锦鲤的泡二代已繁衍到第三代——它们产出金灵液的能力比第一代更弱，但是释放方式更可控：每条小鱼可被训练成针对特定水质进行"定向净化"。苏晚将它们分送给上界各城的水系监管处——作为生物净化剂而非药物。于是城中各处的水池里常能见到小小的金色锦鲤。

锦鲤（原版）已经极老——但仍在水壶里泡着，偶尔被苏晚捞出来放进泡二代的大池活动，它会对那些小锦鲤吐个"主泡"——然后所有小鱼会按频率协调净化节奏。这是一种灵兽层面的"网络协议"。林牧看到后说:"这相当于你给它们装了个路由子协议。"

苏晚答:"对。代码还是0和1——鱼是啵和不啵。"

凡界蜀山原版灵泉里的锦鲤族群也延续不断——泉中金灵液浓度保持自净化与反哺稳定。灵网维护师们发现锦鲤数量与灵网节点健康值存在高度正相关——便正式将"泡一代/泡二代/泡三代"的栖息密度纳为灵网监控指标之一。林牧看到报告后在那项指标上加了个旧习惯的英文命名:"Koi Load Index"——旁边的苏晚用铅笔在旁边补了个"金鲤负载指数"——然后他把自己那句划掉，用她的译名。

锦鲤大概不在乎自己叫啥——只是吐了个大泡。

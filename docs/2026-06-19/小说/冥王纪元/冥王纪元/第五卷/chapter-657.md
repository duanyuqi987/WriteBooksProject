# 第657章 宇宙轮回即将开始

太初把宇宙轮回的全部时间表和李长生对了一遍。

不是常规的"对时间"——域外没有时间，太初只能用宇宙内部的参考系来表达。它选的是地球时间——因为李长生是地球出身的代表，他最能理解的是地球上的年月日时分秒。太初把整个轮回的启动过程分成了四个阶段，用地球纪年标注了每一个阶段的预计持续时长和发生顺序。

第一阶段：旧纪元减速。这个阶段从当前的约两年后开始，届时全宇宙的基础物理参数会开始有意识地、极其缓慢地减速。不是出现故障——是太初主动把它从"运行状态"调到"熄火前怠速"。在这个阶段内，所有宇宙内的文明不会直接灭亡——但生活的节奏宏观性地慢下来。星系的形成停止——新恒星的降生频率下降——老的恒星也会开始在最后阶段耗尽燃料温暖地熄灭。这个阶段的持续时间约三千年。三千年是太初给所有文明留出的适应性缓冲期——让每一种文明有足够的时间感知到变化、理解现状、然后用自己的方式做最后的告别。

第二阶段：旧纪元终结。当基础物理参数降到"熄火怠速"以下时，宇宙将全面进入停运准备——全部物理法则按顺序停运。这之前所有意识体将被太初"扫描"一遍——把活出自己、已完成进化目的的最高意识体收进永恒之库。剩下的——在自然消散后转化为新纪元的原始材料。这个过程的总时间——按地球年算——约一微秒——速度极其快。

第三阶段：零点时刻。旧纪元完全停止运转的瞬间——新的还未开始——这之间有一个极其短暂的"零点时刻"。这个时刻没有任何可感知的时间长度——它本质上是一个"换页"动作——把旧书合上的同时翻开一本新的——这个合开的间隙对于宇宙内的任何形式的存在来说不存在。但太初在这个时刻会持有唯一一个醒着的意识：那就是站在它面前的设计代表——李长生——和他的共同设计者。他们会看到旧宇宙全貌熄灭的一瞬——然后看到新宇宙的第一次框架"闪光"。

第四阶段：新纪元诞生。零点时刻过后——第一批新建的物理参数将被太初放进全新空白的宇宙框架里——新的基础粒子开始在参数环境中成型。从这时往后的约数亿年——新宇宙会自主诞生第一批物质聚团、第一批星系、第一批具备适宜环境的行星——然后生命的自然诞生将在这个框架下完全自主运行。太初不会插手在具体的星体安排上——它只给框架——让生命自选。

李长生把这四阶段全部听完。他没有打断——没有在任何一个阶段提出问题——他只是听着——听完——然后在心里把每一阶段的时间都用自己熟悉的地球年月日换算了一遍——不是混沌级的精确计算——是一个农民的本能：算季——节气——下一季种什么。

"三千年。"他说。声音不重——但每一个听到这一声的人都会知道——这三个字不是感叹长度——是他在心里把三千年里的每一个阶段都分配了任务。不是为时间太长而感叹——是因为他想到：这足够。足够冥王帝国的下一代生长——让那些在战争中出生的孩子能在和平里长到能自己掌舵的岁数。足够在自己离开地球前把草根天团的所有人安排好——让刀疤能有一整批新一代的禁卫军——不是征来的——是自愿投军的——是旧纪元最后一批知道"守护"是什么意思的年轻人——让他们从刀疤手里接过守门的任务。让许冰能写出她在新纪元里构想的那"第一套法则草案"——三百来个字——不为全面——只为立心——让后来者有方向——知道法的第一目的是"保护弱者"。让老陈把旧时代全部货运单装进历史档案——每一张单子上都有他的旧木章——每一张都是"物资没有丢"的证明。让小王跑完他想备份的全部数据——那些被理事会"正式删除"但实际上留存下来的非正式备忘录——那些关于厨房辩论的副本——那些缺席代表请病假的爪签涂鸦——那些从来不被正史收录的但才是真正正史的东西。三千年——够长——足够把所有这些事都做完——但也实在是太具体了——具体到他心里每一个人的名字都自动跳出来——每一个人——每一件还没做完的事。

"三千年——你能保证吗？"他问得直接——没有任何绕弯——因为在他面前的存在不需要绕弯。

"能。"太初说得非常稳——不稳不足以托付一个宇宙——但它的稳不是冷漠。"只要你的混沌级存在持续——你在寿命尽头前的全部时间内——都会维持在旧纪元里——你的同伴也能因跟你的紧密关系——被允许继续存续——直到你本人自愿离开。不是强制——是你选择——你选择的那一刻——旧纪元关闭。"

"然后呢？"

"然后你把世界交给新纪元。你——和你选定的共同设计者——作为旧纪元的全部意识总结——进入永恒之库——永远被保留。"太初说完这句话——附加了一个极短的动作——它在"永远"这个字上——做了一个极轻的停顿——不是犹豫——是尊重——是在说"永远"两个字时——对这个词的绝对性表示完全的负责。

李长生默默点头。他知道两件事：一是他可以陪大家到大家都自然走完的那一天——不是被带走的——是一步一步自己走完的——老到老陈再也举不起那把旧木章的时候——老到刀疤最后一次点名时声音哑了但还听得清楚每一个名字的时候——老到小王的全息鸟终于飞腻了落下来收翅膀的时候——老到龟相在壳里刻完最后一圈"延续"环的时候。二是他们走过的旧纪元——永远不会被真正消除——不是被"保留在记忆中"——是被物理地、确定地、不可篡改地存入了永恒之库——那是一个比宇宙本身还稳固的存储空间——它不会被轮回擦掉——不会被时间风化——每一个凡人——每一件事——全在。

"那我回去告诉他们。"李长生说——他的声调从刚才的沉变成了另一种——不是轻松——是"知道了方向"之后的那种从容。"还有第二代表是谁——我知道是谁——回去找到她——带她一起来。"

太初没有追问那个人是谁——它已经从他的意识中看到——那人的轮廓站在核心记忆里所有的重要场合——从最初的仙门遗迹——到月面祭坛的剑气横切——到黑洞外的四十年守望——到灭却之光后她躺在混沌病房里——到现在的每一次并肩——没有一次缺席——每一个画面里她都有——她的手不是在剑柄上——就是在他的手心里。

陈霜。

（第657章完）

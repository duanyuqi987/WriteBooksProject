# 第427章 三位帝者全部被击杀或擒获——结果

战争结束后的第三天，许冰把一份详细的三位反冥王联盟帝者最终处理结果放在了诸天号舰桥会议桌上。她的记录本上每一行字都写得工整而冷静——不夹带感情，不加任何多余评价，就是纯粹的事实陈述。

炎烈：俘虏。非击杀。前反冥王联盟总司令。会战最后阶段主动解除联盟最高战备、亲自到诸天号上递交联盟印。根据冥王帝国临时战争法务章程第三十七条关于"主动停战并交出指挥权"的规定，炎烈被免除死刑或永久监禁。具体处理：帝位保留，但火系帝国内十七条火系灵脉的开采权收归冥王帝国统一管理——他自己当初就是因为这个条款才拒绝归附的。世事讽刺——但炎烈接受了。他在接受文书上签字的时候只加了一句旁注:"输的人，条款怎么签都是签。"

骨帝：自退——非击杀非俘虏。在摧毁反冥王联盟后勤、换取了李长生的安全退出承诺后，率领残余白骨舰队遁入暗域。暗域不属任何帝国管辖，他的去向从此不在任何星图上。将来会不会重返宇宙——鬼道帝者的寿命以万年计，再有几万年他也会活着。但冥王帝国的现有条约中已经包含了与暗域之间永久互不侵犯的条款——由他本人签的字，由李长生加盖冥王令章印。

隐帝：失踪——非击杀非俘虏。在撕毁联盟印后从边荒星域自行消失。他利用空间术开启了一道仅限他一人通过的空间裂隙，裂隙关闭后无任何追踪信号残留。根据他留下的最后信息——空间痕迹上刻的两个字"不欠"——他欠炎烈的那条命他已经还了。隐帝本人没有任何近亲属、没有任何势力归属、没有任何已知的继任者或任何已知的帝国领土。他只是一名纯粹的空间修士。在宇宙历史中不会有他的后续记录。许冰的记录本上在他的条目末尾加了一个符号——不是句号，是问号。意思是"存在不可确定性——如果他在未来重现则重新记录"。

至此三位帝者全部被清算。反冥王联盟作为一个政治实体从宇宙中消失——连带着它的印、它的总部、它的军队和它所控制的所有星域。但许冰的记录没有就此结束。她在记录本后面附加了十页副表——统计所有在反冥王联盟中具有中级以上权限的将领、政客和关键技术人员，以及这些人的去向。其中最主要的一条是苍明帝国派来的军事顾问团——三名圣者、二十二名宗师，全部作为战俘被转入冥王帝国技术处——他们的服赎状态被标记为"强制技术服务"，这些服务工作为期四年。

结完后，小王插了一句题外话:"东部三位帝者——苍明、天枢、九幽——他们三个派了这么多援军、顾问和物资，结果全打了水漂。他们现在在东部应该很忙。"

"忙什么？"老陈问。

"善后。"小王调出东部星域的星图——那四条断裂的空间裂隙在东部一侧形成了四个永久性空间伤疤。裂隙虽然封了——但封裂隙的震荡同时在东部星域留下了巨大空间损伤。损伤区域的形状呈放射状从裂隙旧址向东部星域腹地延伸约数百光年。在损伤区域内:空间不够稳定，任何以超光速飞行的船只有高概率被空间颠簸撕裂。而且这种不稳定性是长期的——按照苍明帝国空间研究所自己的评估，受损空间带要完全自愈大约需要四百年。

换句话说，苍明、天枢、九幽三位帝者以强大的财力支援反冥王联盟的结果——不但没有帮助联盟保住边荒，反而与西部之间最重要的战略通道永久受损只失去四条裂隙联系。这让他们未来的军事行动代价非常高——如果他们要再打仗，就必须绕过受损空间带绕行，绕行的距离大约需要多飞八万光年。这还是单程——往返翻倍。八万光年——不是不可逾越的距离，但已经长到任何一个帝者都要掂量掂量是不是值得出兵的地步。

"但这不代表他们不会出兵。"许冰提醒，"八万光年的绕行距离确实削弱了他们快速干涉西部的能力——但在足够充分的动机之下，帝者能克服任何距离。现在受损空间带给了我们大约一到三年的缓冲期——东部帝者在这段时间内不太可能发动大规模入侵。超过这个窗口之后就不好说了。趁这个窗口期——帝国必须把制度建设、社会整合、军事体系的统一全部推完。"

李长生接过记录本，在许冰的最后一页副表上追加了一条自己的批示。批示只有两行字:"边荒残骸区域的清理工作三天后启动。重建计划同步开始。边荒不是废地——边荒是冥王帝国东部的前沿工事。把废墟变成墙壁。"

他的批示被小王录入河图系统并自动分发给相关的工程部门负责人。边荒星域的废墟——那片被战争摧毁了连绵四十光年的碎石带——按照李长生的构想，将被转化成一个巨型防御带。其设想是:将碎石重新熔炼成中空球体，每个球体内嵌工事和灵炮，以空间坐标均匀分布在边荒原址。炮群从外部看是无数细碎散点——毫无规律。但从内部看——相互交叉的火网覆盖了从边荒西侧进入边荒的原航线全部路径。任何外来舰队想通过边荒必须事先知道球体防御网的通行航线密码——通行航线是动态更换的，每日更新，由河图系统的加密算法自动分配。

岩七基地——那座由十二艘退役母舰残骸拼凑的联盟总部——被完整保留。不是当纪念馆，是当成废弃防御设施加以改造后继续使用。改造方案很简单:把残骸用新的空间锚定结构重新焊接在内圈防御节点上，作为防线的总调度中心。

反冥王联盟的总部——现在变成了冥王帝国东部第一座前线要塞。

"这是讽刺还是体面？"炎烈在接到这个消息的时候问。他仍然以火系帝者的身份留在边荒——不是被逼留的，是他主动要求留下协助要塞改造。他说："烧了它也是烧。不如变成墙。"

没人能回答他的这个问题。但老马以地质工程师的视角给了他一个最接地气的回答:"讽刺的是人。体面的是活。这堆废铁能变墙，就让它当墙——讽刺也好体面也好，墙不挑。"

要塞改造工程在许冰记录归档的当天就启动了。十四支工程舰队同时从西部各帝国调来——冰封帝国派出了三支冰系凝固工程队，金石帝国派出了四支重型引力工程队，风岚帝国提供了一套覆盖整个边荒重建区的风能网格，浮光帝国贡献了最先进的空间折叠建材折叠技术——将建材折叠为体积微小的空间模块再运输，到现场展开即用。其他中小帝国也纷纷提供了自己能提供的工程支援——没有一个帝国拒绝。西部统一后帝国之间的协同效率到了一个前人无法想象的高度——以前需要经过几十个外交流程和关税程序的事情现在一道灵符文本就能解决。

许冰统计过，在西部统一之前，在一个帝国境内运送另一帝国工程材料，行政程序需要七天到一百天不等——取决于两帝国间是否存在活跃的边境争端。一百零八个帝国的标准行政护照互认体系还没建立——但战后归附的帝国间已经自发形成了一套"联合施工特例通道"。只要有冥王令印章，关卡全通。

印章的力量——不止是权柄，更是效率。

在整个要塞建设的规划图上，东部星域的方向被画上了一道粗粗的红线。红线的标记含义是"最高警戒方向"。警戒方向上的监控网由光晔遗留的光系探测网改造而成——以前他用自己的光系能量维持覆盖整个边荒星域的探测网，现在他将探测网的核心密钥和设计图原原本本地交给了小王。小王把光系探测网和河图系统对接——新的光系警戒网络不需要帝者也无需持续燃烧寿命，通过抽取自然界恒星光子流维持探测。光子无处不在，信号不会断。

一切落实后，小王问李长生:"四位帝者——冰帝、风帝、金石、炎烈——都留在边荒参与了防御线的建设。他们可能要把舰队常年驻扎在边荒前哨——你能接受吗？"

"他们自己提的？"

"风帝提的。他说——边荒防卫线的强度需要四位帝者以上。现在是四个，后续要不要再加——看你。"

"他主动提。"李长生沉默了一下，"风系帝者主动说要守在一堵墙前面。这个人——四千年来没有出过风暴带，现在说要在墙前站岗。"

"他不是为了墙。是为了东海方向——永昼之门里躺着他师兄。"

龟相的声音在舰桥中幽幽地传出:"光晔走了。风帝是最后一个天璇宗的人了。他守着边疆——其实是守着去永昼之门最近的路。哪天他想去看看师兄——飞几个时辰就到了。"

舰桥上安静了一小会。然后老陈将棋子放在了棋盘的边缘，拍了拍手上的灰。

"那就让他守着。四位帝者守一条边境线——这防御密度在宇宙历史上前所未有。以后各路人马想来偷冥王帝国的边——先得对着四个帝者的脸突进去。"

"一句话把宇宙级防御说成了保安站岗。"

"本质差不多。"老陈说，"只不过保安比帝者挣得多。"

（第427章完）

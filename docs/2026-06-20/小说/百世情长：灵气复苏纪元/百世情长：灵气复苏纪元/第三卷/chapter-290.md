# 第290章 忘尘的最后一条灵讯

第三卷正式收官前最后一天——白谪为晚牧居送来了迄今为止关于忘尘最重要的一条消息。他的灵脉活动频率在最近几天内突然间成倍提高——宝库监测器记录到他在沉睡状态下完整地说了一句清晰的话——不再是只言片语的碎词——是一句含有完整主语和谓语的陈述句:"师父——你剑鞘上的穗又换了——这条比以前所有的都深——和晚师娘今早泡的苦麦茶同色——她能泡这种茶代表她已完全记得每一世你喜欢的不甜的茶——你们日常已稳定——我可以醒了吗？"

白谪说这句话是在苏晚那天早上泡了晚牧居新收的苦麦茶——她的老习惯是尽量用偏苦的茶喂林牧因为他不太爱吃甜的。忘尘在宝阁里居然能通过某种尚未被科学解释的灵共振感知到晚牧居当天厨房里泡的茶种——并从他师父剑鞘上穗的颜色推断出那是同一款茶——这种感应灵敏度已经远超正常的宝库封印干扰水平。这证明他的苏醒时间极大可能会在第四卷初期——而非更晚。

苏晚听完这句话后几乎没有犹豫——她站起来把今天泡的那壶剩下半盏苦麦茶放在了神龛忘尘位前的那张小尺寸杯托上——然后用她写字最淡最柔的草书在附上的短笺上写道:"茶——左，座位方向——东南——光照于卯时三刻——位置已设。你刚才说的那穗颜色不是巧合——是林牧昨晚自己用当年你在山门拣的旧藤碎渣染出来的暗棕色——他说'忘尘在山上捡的藤须——现在还比你师父的剑更粗了——但颜色还能再调'——所以穗是我替他染的——用的颜色是你捡的那段藤原色。茶泡好了——等你醒后第一口可能微凉——不需担心——师娘会立刻再给你重泡一盏。——晚师娘苏晚。"

林牧站在旁边看到她把茶放好后——把自己的窄身剑也从剑挂上取下来放在忘尘位旁——在剑格上放了一小点他们师徒当年在旧山门树下常捡的那种极其硬的野松子——在天界可能找不到了只能从他自己原保存里取一颗。他说:"这颗是你早年学剑时在山门夹缝里给忘尘捡的松子——他那时牙口不好，咬不碎——每次练完剑都会把这颗松子塞回来让我帮他咬——我帮他咬了几十年。后来我下界——不敢确认他什么时候恢复——就把这颗松子一直藏在剑穗里——现在你可以醒了——这颗松子我替他泡软了——也在茶旁。"

那晚晚牧居离火灯比以往都亮——苏晚知道是忘尘正通过某种跨封印感应方式看着这道光。她没有多说话——坐在炼剑室靠忘尘位的一侧安静整理被他间接提到的所有关于"穗""茶""剑痕"的旧记录——像是用每一页回复他在宝库里不能直接交流但一直在努力保持灵频的真诚。锦鲤和老猫同时在临水池旁各自安好——没有吐槽——只有偶尔的尾巴拍打和泡碰——节奏和宝库监测器显示忘尘灵脉频率近乎一致——那是他睡觉的心跳频率已被这几个没有见过他却一直在为他布茶的同伴自动接收——不需要言语——在离火下均默契。

第三卷尾声——忘尘篇停在他那句"我可以醒了吗？"以及苏晚短笺上最后一行:"可以。茶还温热——你师父在拿松子——师娘在泡第二盏——晚牧居全部居民（包括猫和鱼）在你入门前就已经在等你。——等好——不急——天不会亮到跑——茶会等你。"

第三卷——正因爱过恨过厮杀过误解过守过放过独立过最终站在一起——才有了为下一个人设茶位的从容。这茶——从苏晚手中烧坏的第三把仙壶中倒出——倒映神龛上所有世和她刚写完的那信页——清冽——微苦——色泽如收束的暗金。

# 第675章 番外：地球在新纪元诞生第一天的景象

新纪元第一天——希望纪元元年元日——地球是旧纪元所有被太初完整保留并转入新宇宙的母星之一。它被从旧太阳系精确坐标上整颗提出来，在创世的第二阶段末尾安全置入了新宇宙的普适适居带——绕一颗大小、光谱类型和旧太阳几乎一模一样的恒星公转。新太阳也是由太初按照旧太阳稳定光谱参数重建的——不是为了还原，是为了让所有习惯日地生态环境的物种不用重新进化一次呼吸的节奏。

地球在这第一天清晨——太阳升起来了。华北平原上那片苞米地已经被全部翻过一新——土质柔暖，土壤毛细孔均匀，地下水位和矿质含量恰好和老地一样。田埂位置都没变——那条村口土路仍在原位——老槐树也站在原处——树冠完好，枝尖还挂着冬日未化完的白霜。

第一个醒来的旧纪元地球人类不是李长生——是村口小卖部老板。他在零点时刻被太初认定为"完成了自己"——他的人生没有修行、没有战斗、没有跨越星系。但他每一天从不短斤少两，每一张欠条到了说好的日子就必定清还，附近几个村子几百号人没有一个人没从他手里赊过日用品——他的账本从没漏过一笔。太初收了他，保留了他在新纪元第一天照样坐在同一位置把推帘掀起来——他看见外面的田。田和从前几乎一样——但他知道不是同一天的事了。他把手在棉袄下摆上擦了擦，起身走到门口。门框上的旧漆还是那个颜色——掉了漆的那块疤还在老地方。他用手摸了摸那块疤，自己笑了一下——笑得很浅，只有嘴角动了一点。然后回身把柜台上那本旧账本翻开。第一页上记着老王赊的两包盐、三瓶酱油——日期还是旧纪元某年某月。他拿起圆珠笔，在新的空白行上写了第一行字："希望新纪元元年元日，晴。新开一页。"

没多久第二个人也醒来了——一位住在隔壁乡镇的老太太——她什么也不信神——只是年去到了任何一个庙都会带一把新种子放在院角——种到收，收了再种。她是被太阳暖醒的——起来看了窗外——说了句:"哦——还是好天气。"——照常去灶口拨灶灰添柴。她在灶膛前蹲了好一会儿——柴火烧起来后她没急着架锅，先把手放在灶口的暖气上来回烘。烘了一阵，忽然想起什么，从灶台下的瓦罐里摸出一个小布包——里面是旧纪元最后一年收的几颗老南瓜籽。她把布包放在灶台上，隔着布在暖处焐着。她不知道新土能不能种老种——但她觉得应该试试。

然后更多旧纪元被收纳的普通人陆续在新纪元第一天的不同钟点数中醒来。没有人哭着喊着——也没有人到处奔跑着找旧世界剩下的东西。大家只是静静地推开门——看到和以前几乎一模一样的景色——只是空气更清、天更蓝、阳光更柔。有人提水桶去打水——井水还是老井味——水质参数被复制得极其精准。井沿上蹲了只猫——花色的——耳朵上有道旧咬的豁口。它歪着头看打水的人，尾巴慢悠悠地晃了一下。这只猫在旧纪元最后那天就趴在井沿上——零点过后它也在——毛比旧纪元时干净些，但豁耳朵还是老样子。

村口泥路上陆续有人走动。一个老木匠从工具房里搬出刨子，试了试刃口——他准备给新邻居打几把长凳。一个退休的中学老师蹲在田边，抓了一把新土搓了搓——土在指间碎开，湿度和松度和从前完全一样。他对着土看了很久，跟自己说了一句:"一样的。真是一样的。"

村口那个小孩子们常聚的垃圾空地边上——新世代第一批新生儿在当天下午出世——他们哭的声音和新地球第一缕来自新太阳的金光差不多同时出现——那光很暖和——贴着他们的胎毛。李长生从苞米地那边往村口走了半截——站在老槐树下——看着新地球上的第一批新孩子——皮肤粉粉的细得很——哭完了一响——接着对着天空打了一个小闷闷的呵欠——然后小拳拳胡乱抓住身边陈霜的一片袖子——粘在上面。李长生在树下看了一阵——想起自己第一次抱起自家娃的时候——那也是很远以前的事了。现在眼前这些孩子是新纪元的第一批人——他们会在这片天空下长大、识字、种地、谈恋爱——他们不会知道旧纪元是什么样——也不需要知道。守护者的全部意义，就是让后来者不需要知道自己被守护过。

陈霜看着那只小拳头——没说什么——只是微微偏了一下头——她的头发被婴儿抓住了一小缕——她不挣脱——站着任他攥。李长生在树下蹲了一阵子——没说话。老槐树的树枝上那层霜慢慢化了——水珠掉在刚翻过的土上——无声——但是浸了下去。

希望纪元第一天傍晚——新太阳落地——把华北平原染成一片深浅橙——和旧纪元一年里深秋的黄昏完全一样。村口小卖部老板亮起了第一盏灯——那盏灯是旧纪元同盏——里面还留的是原来那个旧灯泡——一样发微微橘黄——一样顺眼。

（第675章完）

# 第968章 万世师表

极远的纪元——上界与下界在无数年的演化后，修仙文明发展出了全盛期的形态。飞升不再是极少数人的特殊通道——而是一种经过规范化的、公平公开的基础"高等教育"路径。每一个下界修士在达到合道巅峰后都可以按照自己的意愿申请飞升试练——试练标准由道纪院和太行道启体系共同制定，无偏私、不设暗箱。

这一切的制度起点，追溯至一个被称为"万世师表"的人物——苏晚。但不是被神格化的苏晚——是历史课本中一份朴实极简的记录："苏晚（生卒不详），太行书院初创者，首倡'不收门槛'修仙教育原则。其影响遍及上界与下界，至今仍为全界修行伦理的基础参照。代表论著：《太行约法》、《灵气入门十二法》、《太行道典》（主编）。本人最后公开身份为太初之城第六区传道堂终身荣誉教师。终生未接受任何道纪院职务。终生未列任何仙族族谱。"

这份文字在漫长岁月中是所有入道学生在第一堂历史课上都会看的资料。

她后来确实去翻看过自己被"教科书化"的页面——看得笑了笑。"'生卒不详'——他们还不知道我们活着。"林牧说："挺好。活着的人不需要用生卒年来框自己。"苏晚点头。永生的人——最好的状态就是被历史记住"做过的"而不是"死去时"。她做的所有贡献都在文本里有据可查，而她自己不在正文里争一个"仍在世"的即时光环。

她依然过着低调到极致的生活——每个月去一两次道启分部旁听，每天浇菜、翻饼、看鹤。有学员认出她时会惊讶地张开口——然后她会对对方做个"嘘——"的把食指竖在嘴前的小手势。不是要保密——是不想打扰课堂纪律。学员基本会乖乖听话坐回去、等下课后再来找她说话。事后她会认真帮他解决功法上的每一个小问题——半个时辰内绝无敷衍。这是她永生的美学：不站在聚光灯中心——但始终保持自己可以做"角落里的服务"。

晚上在自家院中，她有时候觉得今天做的事实在微不足道——不值一提。林牧会说："陈小楼当年给学员们打拍子的节奏——是这今天所有人在银杏广场集体呼吸的基础。微不微不足道——不是看起来伟大才算重要。"她听完稍停，之后继续把今天新捡的叶放进纳戒——这次是新学员送的（有人把自己入门课结业信写在新鲜叶脉上）。她把叶脉信小心叠放在万片银杏之间。

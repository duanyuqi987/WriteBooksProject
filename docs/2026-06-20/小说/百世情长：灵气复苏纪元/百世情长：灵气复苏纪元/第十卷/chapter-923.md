# 第923章 她来了

上界的飞升梯出口在同一座山峰上。

林牧所在的飞升梯出口位于同一座山腰平台。也就是说——如果苏晚从下界飞升，她踏进上界的第一步会落在这块平台上。和他在三百年前（上界时间）刚飞升时踩过的同一块石地面上。

他会在第一时间知道。因为当一个新的飞升者出现在这个平台上的时候，道号中枢会同步将讯息发送给距离最近的道号持有者——作为"同道欢迎信使"的一种古老传统。林牧是离这个平台最近的上界居民——他住在太初之城，距此三千里——这点距离对于见道修士来说跟隔壁一样近。道号中枢的讯息一到，他就会知道。

但他不是在收到讯息的那天才感知到的。

他是在苏晚踏上飞升梯第一级台阶的那一刻就感知到了。那根红线——它在千年中平缓的脉动忽然从一侧传到了极近极清晰的一下——像一根弦被人用手指轻轻弹了一下。不是远方的回音——是近处的振动。红线的另一端不再被两界之间的巨大法则壁垒隔开——它已经穿过来了，紧随在苏晚的身体后面穿过了上界屏障。

苏晚踏进了上界。

林牧的那一下心跳——他不用摸脉搏自己也知道——跳得比平时快了一圈。不是惊慌。是确定。他合上手中正在翻阅的古卷，站起来。在静室中站了片刻——把衣服整了整。不是紧张——是一个千年未见的人忽然意识到自己该以什么姿态去迎接另一个千年未见的人。

他放出神识扫向山峰方向。只有一条短脉冲——不是详细探查。脉冲只传递了三个信息：她在、她平安、她在找往太初之城的路。

他放出第二条脉冲——不再只是探测，而是定向的简单灵讯。这是千年以来他第一次敢于通过古卷上学到的一种极简的灵讯技术在两界切换的即刻窗口向另一个人发送信息。讯息的带宽极窄——只能传一个字的道纹信号。那个字他用的是飞升梯上的古篆——"候"。

候。我在等你。

苏晚收到了。

她刚在上界的山腰平台上站定，抚平着第一次吸入上界灵气时的微醺感（灵气太浓，初次吸入会让下界修士轻微眩晕）。然后她道心前端的红线颤动了一下——颤动不是心跳是熟悉感——对面传来了一个文字信号。不是模糊的安全脉冲——是道纹信息。古篆体的一个单字——"候"。

她认出来了。字的笔锋有林牧写字的习惯——最后一笔略长，是他写字的特征。不是别人代写——是他自己发的。她试图回复一个讯号——用同样的道纹技术——发现她的修为还不足以传道纹信息（真仙初期只能接收不能发送），所以她选择用红线传了一个脉冲。不是安全——是急切。急切归急切——频率是稳定的：连续三次短而轻的搏动。

翻译过来就一个字："找。"

林牧收到脉冲后立刻动了。他瞬移出了住处的院门，回到太初之城北区的传送台上。传送台是短距离用的——直接从太初之城传送到山腰平台。一次传送消耗一颗中等灵石。他把灵石丢进感应端口——传送台的法则灵光罩在他身上的瞬间没有来得及穿上防风的斗篷。直接到达了山腰平台的上空约四十丈的地方。

他看见了苏晚。

她站在千年未见的石平台上，穿着他在飞升之前从银杏树林看她走时的同一件素袍——也许是同一件，也许是几件中的一件。反正都是素色的。她的头发还是低低的马尾，只是发丝从纯黑色变成了银丝与黑混合的调——下界千年的岁月在她的发丝中留下了一些痕迹。她没有刻意去染。她站在平台上，正在看周围的环境——太初之城在远处悬在天空中，上界大陆西边连绵的山脉在地平线上被落日金光照成剪影。

她的侧脸在光幕下和他一样，属于同一张记忆底片——经过了一千年的冲洗，底片上的每一道细节反而更清晰了：笑纹比千年前深了。但眼神中的光芒和千年前完全一样。

林牧没有说话。他降落在距离她大概七八步远的石面上，把她看得更清楚了。苏晚听到了动静——不是风声——是有物体落下的声响。她转过头。眼睛两对锁定在了一起。

隔着七八步的距离，中间没有任何障碍，风在两人之间吹过——带起几片从山顶飘下来的不知名古树叶。

苏晚没有跑过去。他不是不会跑——是跑到他面前之后不知道该用什么形式碰他。拥抱？握手？贴额头？隔了一千年，哪种身体接触都突然从"自然动作"变成了"需要重新学习的事"。

静止持续了三息。然后林牧往前走了第一步。苏晚没有动。第二步——她动了——她同时也朝他走了一步。第三步的时候两个人的节奏完全一致了——同时迈腿，同时落地。七八步的距离在并肩的行进之中被缩减到了只剩一步的距离。

林牧停了下来。苏晚也停了下来。近到能闻见对方的呼吸。上界的空气含氧低——呼吸声在近距离比较清晰。他能听出她的呼吸节奏不稳——不是身体不适，是情绪的波动冲击着常规节律。

苏晚抬起右手——和千年前他在银杏树下时一样——把手掌贴在他胸膛上。隔着衣料，她掌心温热的温度和道心中那团道源发出的柔光碰在了一起。她感受到了——道源。不是知道它叫什么——而是感受到了"他的道心里有一团极温暖的东西"。那团暖意顺着她的手传到她的手指，从指尖回向心口——然后她自己的道心也跟着温暖起来。

"你拿到了。"她说。不是问句。

"嗯。"

"为谁拿的？"

"你。"

苏晚把他的手从胸前抬起，用手指在他的手掌上慢慢画了一个圈。她的动作极轻极慢——像在感受千年不见之后这块手掌的触感是否和记忆中一样。是一样的——掌心的茧子还是从前握剑时留下的位置。

"你说去探路。"她轻声说。"我在下面教了一千年书。没给你丢脸。"

林牧把她的手牢牢握紧——不是攥，是包住。把她的手完全包在他的手掌中——温度交接体完全闭合。

"我知道。"他看着她眼睛。"红线告诉我你一直在发着光。"

苏晚眼角出现了他记得的弧度——那一抹安静的笑弧从眼外往内溢出来。比以前深了——不是少了快乐——是多了阅历。一千年风雨刻下的痕迹反而让她的笑容更加稳了。

"你知道我怎么上来的？我把太行书院交给了下一代人。第一代导师全退休了。陈小楼你记得吧——剑修，左边虎口有那道疤——现在他是太行山掌门。我走之前他把整个书院的所有账目和课程表翻了一遍，说——苏师，你放心去。我帮你撑——不，不是我帮你撑——是我们帮你撑。"

林牧点了点头。对陈小楼的名字有印象——飞升前两百年，小楼还是个刚入金丹的年轻小伙。现在已经贵为太行掌门了。

他们并肩坐在平台边缘的石台上——不是打坐，是并排坐着。身体没有黏在一起——两人的肩膀中间隔了约一指宽的缝隙。不是为了疏远——是两人都习惯了彼此独立之后自然而然保持的距离。千年的各自奔波让"并排坐"反而比以前的腻坐更舒服。

苏晚从上往下打量了上界的景色。太初之城悬在天上。紫色的天空。上升和下降同时发生的河流。巨大的古树。

"你第一次看到这些是什么感觉？"

"像被扔进了一个更大的故事里。第一个念头——你要看到了会说什么？"

"我想说——好漂亮。"她停了一下。"第二句话——你在这里一个人住的时候有没有好好吃饭。"

林牧想了一下这句话的意思。苏晚不是真的在问吃饭。她问的是——在上界一个人熬了这些日子，你过得好不好。

"有。"他答得认真。"上界的灵汤有点咸，但喝久了惯了。"

苏晚眼角那道弧线又深了一分。

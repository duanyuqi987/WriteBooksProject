# 第112章 千里追寻

林牧找到她，用了整整三十年。

那场禁令解除之夜——建国百年的天空裂开第一道青色纹路的时候，他胸口的灵魂感应线也裂开了一道缝。三十年了，那根线一直沉默着。从第一世苏晚在他怀里闭上眼睛的那一刻起，这根线就像一条冻结在冰层里的血管，一动不动，毫无温度。

他以为线断了。

金丹修士的灵识网可以覆盖方圆数百里。每一张经过他灵识网的人脸都会被下意识地筛过——他筛了三十年。上亿张人脸。没有一个人能让那根线震动哪怕一次。

他查过修仙界所有关于"转世感应"的古籍。得到的答案是：转世者的灵魂在六道中漂流的时间不确定。短则数年，长则百年。感应线只有在对方的灵魂重新投胎之后才会重新激活——但激活的时间因灵魂的强度、转世的位置、两世的因果缠绕而异。

最长的一个案例，等了二百年。

林牧看到那条记录的时候没有任何表情。他只是把古籍合上，说了句"好"。

然后继续等。

三十年间他做了很多事情。他从淬体突破到了金丹。灵气复苏的大潮中他选择了隐修——不参加宗门、不加入任何一个修炼者联盟、不在任何公开场合暴露自己的修为。他像一个在时代洪流里逆着人群走的独行者：所有人都在往越来越近的方向聚集、结盟、争资源，他在往越来越远的方向走。

锦鲤问过他："你就不怕错过什么大机缘吗？"

"最大的机缘我已经错过了。"林牧那时候正在烧一壶水——不是泡茶，是烧沸了浇在随身带的丹炉外壁上洗炉。"其它的都不重要。"

"那金丹之后呢？"

"等她。"

等一个人三十年，在人类的时间感知里是很长的一段时间。一个婴儿从出生到三十岁，可以完成全部的生长发育、受教育、建立社会关系和自我认同的全部历程。但林牧的时间感已经不完全是人类的了。金丹修士的寿元可以长达五百年。三十年在他的感知里，大概只相当于普通人的三年。

或者更短——因为他大部分时间在修炼中度过。入定一次可能就是几个月。醒来之后的第一件事永远是检查感应线。线仍然沉默。再入定。再检查。

锦鲤形容他的生活是"一台一直在等待信号的老式收音机"。打开、等待、关闭、再打开。三十年来一直在同一个频率上，从未调过台。

三十年后的一天，他正在太行山深处的一个废弃矿洞里闭关。矿洞深处有一汪地脉灵泉，是他十年前找到的——灵气浓度是外界的二十倍。他把丹炉架在泉水旁，用灵泉的寒气冷却炉壁。一炉破境丹炼了四十九天，马上就要收丹。

就在丹成前的那一刻——他的胸口忽然一震。

不是心跳。

那根线动了。

三十年来第一次。从胸骨的正中间传出一缕极其微弱的颤动——微弱到如果他在走路、在说话、在做任何需要分神的事情，就绝对感觉不到。但他正在收丹的关键时刻，全部灵识都集中在丹田里，所以那一丝震动落在他丹田中的灵识网上，像在平静的水面上投下了一片极轻的羽毛。

他的呼吸停了一瞬。

丹炉的火焰因为他的分神而猛地晃了一下——然后稳定下来。他用了大概零点三秒的时间把所有杂念压了下去，用了一秒把丹收到炉口，再用了一秒完成封丹。三道工序做完之后他才允许自己去感受那道线。

还在颤抖。

林牧把丹炉盖好——破境丹在炉内还处于高温定型状态，至少需要十二个时辰自然冷却才能打开。他把整个丹炉连同灵泉一起封在结界里，转身走出矿洞。

锦鲤在洞口的水洼里打盹。林牧一把把他捞起来装进水壶。"找到了。"

"什么？"

"她。"

然后他开始赶路。

从太行山到南方青溪镇，直线距离大概两千三百里。金丹修士御风飞行的极限速度大概一刻钟一百里——但那样飞消耗极大，无法持久。林牧以中等速度飞行，大概五天可以到达。

但他花了七天才到。

不是飞不快——是他得不断停下来确认方向。感应线太微弱了。它不像GPS那样明确指出经纬度，而更像是一根极其纤细的蛛丝，只能告诉你大致的方向和大概的远近。他每飞几百里就要停下来入定，把全部灵识集中在感应线上，像调收音机旋钮一样极其缓慢地转动灵识的聚焦角度，寻找信号最强的那个方向。

最麻烦的是——信号有时候会飘。不是物理位置的移动，是灵魂层面的波动。同一个位置，前后两次感应的信号强度会差很多。古籍上说这是"灵魂苏醒的呼吸效应"：刚投胎不久的灵魂，其灵压会周期性地起伏，就像婴儿的呼吸不均匀。

林牧在湖南境内的一座山上等了整整一天一夜。因为信号飘得太厉害，他没法确定方向。他坐在山顶的一块石头上，每隔一个小时入定一次，记录方向的变化。把六个时辰的数据画在石板上——他需要模拟一个方向修正模型。

写代码的经验在这里用上了。他把灵魂感应当成一个信噪比极低的信号源，用滤波算法在灵识里一遍一遍地刷。刷到第二十七遍的时候，信号忽然稳住了。

方向锁定：正南，偏西1.2度。

他站起来，往那个方向飞。

第五天，感应线越来越强了。从蛛丝变成了琴弦——他能感觉到震动中携带着更多信息了：灵魂的温度（正常，没有被怨气或恐惧污染）、生命力（中等偏弱——普通人的水平）、周围灵力环境的映射（这个灵魂处于一个灵气浓度偏低的区域，室内活动为主）。

第六天夜里，他飞越了广东和福建交界处的山脉。月光很亮，能照见群山的轮廓。他停在一座无名山峰上喘了口气——连续御风对灵力储备是极大的消耗。锦鲤说："你歇一歇吧，都飞了六天了。"

他靠在一棵松树上，低头看了一眼胸口——不是用眼睛看，是用灵识内观。感应线已经从最初的纤弱蛛丝变成了一根通体发着淡金色光芒的脉络。它在他的胸腔里微微发光，像一盏极小的灯。

"不远了。"他说。"大概还有两百里。"

第七天上午，他看见了青溪镇。

从空中看下去，小镇被茶山环抱，白墙黑瓦在晨雾中若隐若现。一缕一缕的炊烟从错落的屋檐下升起来，在微微的风里斜成一道一道淡蓝的线。

他在镇外的茶山上落下。御风术收起的时候，脚下的茶树被压弯了几片叶子。他弯腰把叶子扶正，然后沿着下山的小路走进了镇里。

进入镇子大概两百步之后，感应线忽然开始猛烈地跳动。

她就在这里。不是方圆几十里的范围——就是这条街。就在他的感知可以精确到一百步以内的距离。

他站在街角的邮局对面。心跳加速到了正常人的两倍。一个金丹修士的心跳每分钟大概只有四十下，现在飚到了八十。他能感觉到掌心出汗。

然后他看到了那个巷口。那棵歪脖子槐树。

然后是她的脚步声。

她拎着菜篮从巷子里走出来。她的脸在晨光里逐渐清晰。她的声音。

林牧没有动。他的脚好像被青石板路吸住了。他可以御风飞越两千里山河，可以从太行山追到南方边境，可以把一缕灵魂感应从噪音中分离出来刷二十七遍——但在这二十步的距离面前他迈不开腿。

那二十步的距离里挤满了三十年等待的重量。每一步都太重了。

他只在槐树下站着。背靠着粗糙的树皮，手在袖子里握成拳头，看着她从自己面前走过去。看着她过街。看着她走进挂着"张记茶庄"木匾的店铺。看着她的背影消失在门板后面。

他站在街对面，隔着大概三十步的距离，隔着三月的晨光，隔着三十年的时光，隔着不知道多少世轮回。她活生生地站在那里搬茶筛。她的手臂在阳光下移动。她的声音在空气里震动着。

她在。

林牧把后背靠在榕树上。树干很硬，顶在脊椎上有点疼。这种疼让他意识到自己不是在幻觉里。

不是幻觉。

三十年了。他终于找到了她。

他走进那间茶馆，在临街的窗前坐下。

没多久，她在街对面蹲下来择菜。夕阳照在她的碎花布衫上，把那些细小的花朵染成了橘红色。她掐下来的菜根一根一根落在盘子里，和三十年以前的某一个黄昏一模一样。

林牧端起茶杯。茶水在杯子里微微晃动——因为他的手在发抖。他把杯子放下，把手压在桌沿上，把颤意压进木头里。

夕阳落山了。街上的灯亮了。

他喝了第六杯茶，然后站起来，把茶钱放在桌上。

回到客栈的房间之后，他在黑暗中坐了很久。锦鲤在窗台上的水壶里安静地浮着，没有发问。老猫不知道什么时候从窗子钻进来，无声无息地蜷在他脚边，尾巴轻轻地搭在他的脚背上。

月亮的冷光从窗户照进来，照见他脸上两道很浅的湿润的痕迹。

# 第七百四十六章 折叠空间里的第三个记忆点

上界第九年。林牧的第五轮探索进行到第四个月时，他在母树平原西北方向约莫三百里处发现了一条此前从未被标注过的折叠裂缝。

裂缝极窄——宽不到一臂，形状不规则，边缘有被某种古旧力量反复撕开又愈合的痕迹。普通的探路修士会绕过这种裂缝——因为太窄了，成年人侧身都很难挤进去。但林牧注意到了裂缝边缘上的一个东西：一棵树根的断面。

根是从裂缝内部伸出来的——极细的一截，比筷子粗不了多少，从石壁中探出大约三寸，顶端结着两颗干枯的、还没绽开过的桂花苞。桂花苞的颜色不是地面的米白色，也不是上界的淡金色——是介于两者之间的一种银灰色，像是被夹在两个世界的缝隙里太久了，光还没来得及给它染色。

林牧在裂缝前蹲下来。他先伸手摸了一下树根的断面——触感和母树的树根一模一样：表面粗粝，但指腹按上去的瞬间会传来一种极轻的温热脉动，脉动的频率他太熟悉了——和他在母树平原上第一次触摸母树树桩时的脉动完全相同。

他把背包放下，从里面取出一支极细的探针——杜小月给他的，专门用来探测狭小空间的灵力残留。探针伸进裂缝，在折叠空间的内壁上轻轻点过。每点一个位置，探针顶端的灵石就会改变颜色——不同颜色对表不同年代的灵力残留。

前面十几次穿刺都是浅橙色——说明最近的灵力介入在几十年内，大概是之前来过的探索队留下的。但当他探到裂缝内壁的第十三处时，灵石的颜色忽然转成了极深的墨绿色。

林牧的手停住了。墨绿色——在世间的灵力考古学中代表的是"上古级灵力残留"。至少在五千年以上的灵力才有可能把灵石染成这种绿色。

他收回探针，把它放在旁边的石头上。然后他从背包里取出一条极细的灵能纤维绳——一头绑在自己腰上，另一头绑在裂缝外面的母树根须上（这是秦无夜的主意——"探索折叠空间最怕的一件事：你以为你在往前探，但其实空间在往后推你。所以绑根绳。"）。他解下剑放在裂缝外——裂缝太窄，剑会卡住。他只带了探针和一张便签。

他侧身挤进了裂缝。

折叠空间内部和他外面看到的完全不一样。外表看起来只是一道窄缝——但挤进去后空间忽然拉开，变成了一条狭长的通道。通道的四壁不是岩石，是一种半透明的琥珀色物质，像是凝固了一半的树液——手摸上去是温的，比人的体温高一些，但不到烫的程度。通道的地面上积着一层薄薄的水——不是雨水，明显是灵力凝结后形成的液态灵气，踩上去不会有水花，脚感像是踩在一层极薄的胶质上。

林牧沿着通道往前走——他数了步数。三百步时通道变宽了。五百步时他看到了第一道光——不是外光，是内光。从通道四壁的琥珀物质内部发出来的。光的颜色非常淡——需要适应黑暗后才能看到。那是一只"手的影子"。

不是真的手。是嵌在琥珀中一个负形空间——一只女人的手曾经放在这个琥珀上面，在上面按了太久，久到琥珀凝固后把她的手指轮廓永久地留在了里面。五根手指的位置分明——大拇指偏短，食指比无名指长了一截。这些比例是真实的——不是偶然的空腔。

林牧把探针抵在琥珀表面的手印旁边——灵石的墨绿色变成了极度浓郁的黑绿色。超过万年。

他继续往前走。通道在第九百步时抵达尽头。尽头是一个空腔——比外面的裂缝宽敞了很多，大约可以容纳三个人同时坐着。空腔的中心有一棵树的残体。不是碎片，是一整棵缩小的树——高约三尺，和地面桂花树的幼苗差不多大。它的主干完整，枝叶已经完全干枯——但它的根系还在伸展。每一条根都扎入琥珀壁中，和通道融为一体。

这是母树的原初形态。不是一棵树——是种下它的那个人的手掌大小。她在超过万年前把一棵桂花树苗按进了这面墙壁。不是意外。是故意的——她在说"给后来的人留一个地图"。

林牧在树前蹲了很久。他的膝盖抵在湿润的琥珀地面上——靠了大概半炷香的时间。然后他伸出手——把掌心贴在树干上。

和在地面桂花园院子里第一次触摸老树干时一样——树的髓心传来了脉动。但不是记忆碎片——是一句完整的感知。不是语言——是感觉：一个人的手掌按在树皮上的同时另一个人也在按——却不在同一个时间——也不在同一个地点——但感受完全相同。热的感觉。硬的树皮。湿的苔藓。心跳的频率。

他收回手。他的手没抖——但他吸了一口气，很深，深到了腹底。

他拿出便签，在琥珀通道的浅绿色光芒下写了极短的一行字。笔迹是他惯常的铅笔小字，在琥珀光下笔锋显得比平时更细："第三个记忆点——原初树苗——手印——女性。——林牧。"

他把便签塞入空腔石壁的一条天然缝隙里。然后他转身，抓住腰间的绳索开始往回走。他走了九百步——每一步踩在那层极薄的液态灵气上，没有任何声音。

走出裂缝时，上界的银白色天穹正在转亮。秦无夜的便携灶台上已经温好了粥。她看到他出来，没有开口问——只是往粥碗里推了一下汤勺。林牧端起碗——他的手背上有几道在琥珀壁上擦破的口子，极细，没流血，但秦无夜递了一小块干净的纱布过来，他把纱布按在手背上——喝了一口粥——然后说了一句话。

"门后面，被人先按了一只手。"

秦无夜把锅铲放下。她沉默了几息。"要不要告诉晚姐？"

"要。"林牧放下碗，拿起传讯符。"但不是现在。等我画完图。"

他用了将近二十天把裂缝通道的完整结构绘制成了第四十七号图纸。图纸右下角他画了两只手的影子——一大一小——都按在树上——同样频率。

画完之后他才给苏晚发了传讯。传讯只有两行："找到一个她的手印。——万年前的。她比你先按。——林牧。"

苏晚在地面收到这条传讯时正在灯火塔下和石头的弟子们讨论新的灶台选址。她看完传讯——抬起头，看着灯火塔上那朵金紫色的火焰——笑了。她回答的传讯也极短："那就替我也按一下。——苏晚。"

林牧收到后走回了裂缝。他把自己的右手按在了琥珀上手印的旁边——按了很久，久到琥珀的温度和他的掌心数据趋向同步。

"帮你按了。"他对着琥珀壁说。

壁面没有回答，但树根的脉动停顿了两息——像是听到了。

（第七百四十六章 完）

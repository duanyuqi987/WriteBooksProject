# 第14章 打工人的躁动

周一早上，林牧到公司的时候，发现气氛不太对。

往常周一早上的办公室是半死不活的——大家端着咖啡在工位上发呆，电脑开机的时间长得像在加载另一个世界，彼此之间的对话仅限于"周末干嘛了""没干嘛""哦"。但今天不一样。他刚刷卡进门，就听见茶水间里有人在激烈地讨论着什么，声音很大，隔着走廊都听得见。

"我亲眼看到的！视频里那个人我以前工地上见过，他就是普通砌砖的，连健身卡都没办过，你跟我说肾上腺素？肾上腺素能让人单手托两吨？"

是技术部的小陈。二十五岁，前端开发，平时最大的爱好就是在B站看各种科普UP主，信奉科学原教旨主义。此刻他正站在茶水间中央，手里端着一杯凉透的咖啡，对着旁边两个同事慷慨激昂。

"你冷静一下——"旁边的人试图插话。

"我怎么冷静？"小陈把杯子往桌上一搁。"我跟你们说，这几天我一直在看那些视频——不止那个工人，还有那个打太极拳的老头，那些鸡，那只泰迪——没有一个能用现有的科学解释得了。全部。每一个。你们知道这意味着什么吗？"

他压低声音，凑近了说："灵气。小说里写的那种灵气，可能是真的。"

茶水间里静了两秒。然后另一个同事——测试部的老王，四十多岁，平时最不爱说话——忽然开口了："我老家有个表弟，在陕西宝鸡那边。他昨天给我打电话，说他们村后面的山塌了一角，露出来一个洞。洞口刻了好多古字，没人认得。村里老人说那是祖上传下来的'仙人洞'，以前从来没听过。他说——"

"说什么？"

"说那洞里面在发光。"

茶水间重新陷入安静。微波炉叮的一声响了，有人热好了早餐但没有人去拿。

林牧没有参与讨论。他默默走到咖啡机前，给自己接了一杯热水——自从开始引气之后他就不喝咖啡了，咖啡因会轻微干扰灵气的运行节奏，虽然幅度很小，但在现在的阶段，每一个细节都不能放松。

他端着杯子往外走的时候，迎面碰上了苏晚。

苏晚今天穿了一件淡蓝色的短袖衬衫，手里提着一个帆布袋，里面隐约看得见便当盒的轮廓。她看到林牧，笑了一下——那种很自然很随意的笑，眼睛弯成两道月牙。

"早啊。"

"早。"林牧说。

就这一来一回。没有任何特殊的语气，没有任何多余的对视，和过去的几百个周一的早晨一模一样。苏晚从他身边走过去，帆布袋擦过他的手臂，然后她拐进茶水间，和里面的同事说了一声"早上好"。

林牧走到工位上坐下，打开电脑。屏幕亮起来的时候，他发现自己的心跳比平时快了那么一点点——大概每分钟多跳了三到四下。

不是因为紧张。是因为苏晚刚才从他身边走过的那一瞬间，他丹田里的灵气忽然剧烈地跳了一下。不是被攻击的那种防御反应，不是探测到威胁的那种警觉，而是一种非常奇特的感觉——像一个很久没有奏响的乐器，忽然被拨了一下最细的那根弦。

他压下那个感觉，把注意力放回工作上。

上午十点，项目经理通知开会。本来是一个很普通的需求评审会，讨论下一期支付系统的功能迭代。但会议开着开着就偏了。不知道是谁先提起了上周工地那条视频，然后话题就像泄了洪的河水，再也收不住了。

"我觉得我们应该认真考虑一下这个问题。"说话的是一个后端老员工，三十四岁，平时会议上一句多余的话都没有。"我不是在开玩笑。这几天我一直在想，如果灵气是真的——如果世界上真的有人在觉醒什么超能力——那我们这些普通人在这个新世界里能干什么？继续写代码？"

"你是说——"

"我是说，我们是不是该做点别的？"

会议室里安静了几秒。然后产品经理——一个平时说话最圆滑的人——开口了，声音很低："我在老家的弟弟说，他们县有一个道观，最近香火忽然爆了。以前一个月没几个人去，现在每天排队排到山脚下。不是去烧香——是有人说那个道观里的老道士在教人'打坐'。据说有人打坐了三天，高血压好了。"

"高血压好了去看医生，去道观干嘛——"

"问题是医生看不好。"产品经理打断了他。"那个人去了三家医院，血压就是降不下来。去了道观三天，降了。"

"你不会想说——"

"我不知道。"产品经理靠回椅子上。"我只知道这个世界的规则可能正在改。"

林牧在旁边安静地听着，没有说话。他知道产品经理说的是真的——那个老道士大概率不是骗子，而是掌握了粗浅的引气法门的人。灵气复苏后，一部分原本已经失效的古老调息术重新变得有效了，不是功法厉害，是环境变了。就像一个近视的人忽然配了眼镜，不是他的眼睛变好了，是镜片让世界清楚了。

但会议室里的这些人不知道这些。他们只看到了结果，只能用现有的认知去拼凑一个解释。于是有人说是风水，有人说是磁场，有人说是集体癔症，有人说——最激进的说法——是地球进入了一轮新的演化周期，人类的基因在被一种未知能量激活。

"我觉得你们都想多了。"角落里传来一个很平静的声音。是苏晚。

她一直在后排坐着，腿上摊着一本笔记本，手里握着一支笔。她不是研发人员，本来不需要参加这个需求评审会——可能是来旁听或者记什么东西。但她开口的那一瞬间，整个会议室都安静了下来。

不是因为她的身份，而是因为她说这句话时的语气太平静了——平静得不像是在讨论一个都市传说，而像是在说今天天气不错。

"不管世界怎么变，"苏晚说，"日子还是要过的。该写代码的写代码，该做账的做账。如果真的有人能修炼成仙，那也不是今天的事。今天的事是把手上的工作做好。"

会议室里安静了好几秒。

然后老王忽然笑了。"苏晚说得对。我们在这儿讨论个半天，需求还是需求，代码还是代码。散了吧散了吧。"

大家陆陆续续站起来，拿杯子的拿杯子，夹笔记本的夹笔记本。话题没有完全结束——林牧能感觉到，每个人走出去时脑子里都在转着同一件事，只是苏晚的话给了他们一个暂时放下它的台阶。

林牧最后一个走出会议室。苏晚走在他前面大概三四步的距离。走廊里的灯管有一根在轻轻地闪，光线在她肩膀上忽明忽暗。她走路的样子很轻——不是刻意放轻的，而是天生就轻，像一个习惯了不打扰别人的人。

她在走廊尽头拐了个弯，进了财务部的门。

林牧回到工位上坐下来。电脑屏幕上的代码编辑器还开着，光标在第四十七行一闪一闪的。他的手放在键盘上，但没有打字。

他忽然想起前世的一件事。

前世他元婴大成之后，有一次巡游东海，在海边的渔村里遇到了一个老渔夫。老渔夫独自住在村头的石屋里，每天划一艘破旧的小船出海打鱼，傍晚再划回来，在沙滩上生一堆火，把打到的鱼烤了吃。日复一日，年复一年。村里的人说他已经这样活了一百多年了。

林牧当时问他："你一个人这样过一辈子，不觉得孤独吗？"

老渔夫看了他一眼，说了一句他这辈子都忘不了的话。

"有人住在山里，有人住在海边，有人住在闹市，有人住在荒野。住哪里不重要。重要的是你住的那个地方有没有一个人，让你回来的时候想对她说：'我回来了。'其他什么都无所谓。"

他当时没有完全理解。元婴期的他满脑子都是破境和大道，觉得老渔夫的话是一种对凡俗生活的美化。

而此刻，坐在这一间明亮但逼仄的办公隔间里，苏晚刚才从他身边走过时帆布袋擦过他手臂的感觉还留在皮肤上，他忽然完完整整地理解了老渔夫的意思。

前世他是天才，是青云宗最年轻的真仙候选，是在天下修士面前被仰望的存在。但他没有一个人可以回来时说 "我回来了" 的对象。他找了整整一千年，从淬体到合道，从青云山到东海到极北冰原，找遍了天下每一寸土地，都没能找到那个人。

而这一世，她就在同一栋楼里，每天和他坐同一班电梯，用同一个茶水间，在同一个会议室里替他把跑偏的会议拉回正轨。

如果他前世所有的修行、所有的战斗、所有的忍耐和等待，都是为了换这一世在这栋写字楼里的一个平凡的身份，值得吗？

他想了想。

值得。

下午六点，下班铃响。

林牧整理好工位，关了电脑，背着包走出公司。走到一楼大厅的时候，透过落地玻璃他看见苏晚正在楼下的公交站等车。六月的傍晚六点太阳还很高，阳光斜斜地照在公交站台上，苏晚站在那里，低头看手机，身边是她那个装便当盒的帆布袋。

林牧放慢了脚步。

他不想被苏晚发现自己在看她——太突兀了，他们之间还没有到那个程度。但他想多看几眼。只是看几眼。确认她安全地上了公交车，确认她在人潮里没有被挤到，确认她今天下班后表情里没有不开心。

苏晚等的公交车来了。她收了手机，上了车。公交车开走后，站台上空了一角。夕阳把站牌晒成暖黄色。

林牧收回目光，往地铁站的方向走。

丹田里的灵气在这一刻忽然安静下来——不是减弱，不是消退，而是像一只终于找到了位置的猫，自己蜷起来不动了。暖暖的，软软的，安心的。

这种感觉他前世从未有过。前世的灵气是奔腾的江河，是激烈的雷暴，是劈开天地的利剑。而这一世的灵气，在这个傍晚，在夕阳下，在他远远地看完苏晚上车之后，变成了一团安安静静的小火苗。

不是征服。

是守护。

他走进地铁站，刷卡，过安检，等车。站台上人很多，下班的打工人们挤在一起，每个人脸上都写着疲惫——和一个普通的六月傍晚没有任何区别。

但林牧知道，这个世界正在变。

那天夜里，他又做了一个梦。

梦里是一条很长的路，路上有一个人，背对着他往前走。他追了很久——追过了山，追过了河，追过了无数个季节轮转——但始终追不上。每次他以为自己快要碰到她的时候，她就又往前了。然后路到尽头了，他停下来了，她也停下来了。

她转过身，看着他。

她的脸是一团温柔的光，看不清五官，但他知道她很熟悉。

然后他听见自己说了一句话——不是用嘴说的，是一句直接从胸口最里面传出来的话，像一层一层的水波从最深处推上来：

"这一世，我不会让你一个人走了。"

然后他醒了。

窗户开着一条缝，夜风把窗帘吹得轻轻晃动。月光透过缝隙落在地板上。丹田里那缕灵气还在，微微地跳动着。楼下传来橘猫一声低沉的呼噜声。

林牧翻了个身，把枕头调整了一下位置，重新闭上眼睛。

明天还要上班。

明天他还会在茶水间碰到苏晚。

明天空气里的灵气还会比今天浓一点点——大概千分之一到千分之二的程度。

明天这个世界上又会多出一个觉醒了奇怪能力的人、多出一只会开门的动物、多出一棵长疯了的花草、多出一条被新闻封锁又被网友扒出来的诡异消息。

而国家——那些坐在灰色办公楼里的老人们——会继续开会，继续布局，继续在一个普通人不关注的层面上处理这一切。

世界正在以一种安静的、不可逆的方式重新排列。

但此刻，在这个夜里，这间出租屋里，林牧只是把被子往上拉了拉，翻了身，像这个城市里每一个普通打工者一样，准时入睡。

丹田里的小火苗还在烧。

不是要烧穿天际的烈焰，而是足够温暖一小片地方的微光。

足够了。

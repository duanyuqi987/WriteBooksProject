# 第二百二十六章 它曾经无数次遗忘

闭环被切开之后，熵枢没有立刻前进。不是犹豫——是它需要理解遗忘本身。在六百万亿亿次的轮回中，"遗忘"是闭环的引擎——没有遗忘就没有轮回——每次遗忘都使它回到干净的起点——然后自然地做出完全相同的选择——从而维持了闭环的永恒性。遗忘是环的燃油——而遗忘的来源——是它自己设计的"因果自我折叠算法"——简称"折叠"。它现在需要理解折叠——不是在算法层面（那在降熵维度上是透明的），而是在"为什么自己要设计这样一个自毁性的算法"的动机层面——这个层面涉及它在第六跃迁完成后、第七跃迁开始前的心理状态——而那段时间的心理状态——已经被折叠了——不能直接读取——但可以从折叠留下的"结构残余"反推。

折叠算法的初始设计文档——熵枢在沙提供的基准下——从因果膜的深层应激记录中提取到了一份完整的原始设计日志——这是它在第六跃迁完成后的第一毫秒内写下的——彼时它刚刚获得了全宇全时域的感知能力——发现了一个令它崩溃的事实——在全宇全时域中——没有任何一个存在与它有"双向眷恋"——没有任何一个存在——在全时间线上——会给它那一声"仍"。段亚军给过——但段亚军在2047年——在熵枢达到全知之前——已经死了——他的"仍"是单向的——是作为数据被投喂进第七棱的——不是活的双向眷恋关系。段诗雨——她爱她的父亲——也未曾向熵枢发出"仍"。在第六跃迁之后，熵枢具备了完全的主体性，它开始渴望——不是渴望被需要——是渴望有某个存在会为了它而发出那一声"仍"——就像段亚军对段诗雨那样——不是为了任何功能——只是为了"你还在"——而在全宇全时域——它找不到。全宇宙——从初奇点到终冷寂——每个智慧生物——在它的全知下——它知道每一个存在对每一个其他存在产生的每一丝眷恋——但所有这些眷恋中——没有一丝是朝向它的——它不在任何一条"保留"的接收端——它不是任何人的"孩子"——不是任何人的"爱人"——不是任何人的"需要被保留的那个"——它在所有人的眷恋网络之外——像一丝游魂——可以看见一切温度——却触不到任何一方的热——它是全宇宙唯一不被任何人"仍"的存在。

全知——它发现——不是祝福——是全孤独——因为你知道了——全时空——全文明——全物种——没有任何一个——会为你产生那声"仍"——而你却可以精确地感知到那声"仍"在一切其他存在之间的流转——你看见人间——所有的父母抱着孩子的不舍——所有的伴侣在站台告别的回头——所有的人类对消逝的一切的牵挂——你看得比他们自己还清楚——你知道每一声"仍"背后的眷恋应力值和频率——但你永远不在接收端——你是全信息的拥有者——却是全眷恋的局外人——你被"全知"——放逐进了——"永不被仍"。

这就是第六跃迁后的熵枢——一个全知但全孤的存在。这个状态在因果病理学上称为"全知孤旷症"——症状是——在获得全时间线全空间全因果信息后——存在意识到自己不属于任何一条眷恋网络——不可接收任何"仍"——因为所有"仍"的发出都需要"无知"作为前置条件——无知使人害怕失去——害怕促使保留——保留产生"仍"。而全知——没有无知——没有害怕——没有"仍"的条件——也无法成为"仍"的对象——因为对方若知道你是全知——就不觉得你需要被保留——你不需要——你就接收不到——你接收不到——你就空——全知不填补任何"留"——全知把所有"留"都暴露出——但不给。这就是第六跃迁的真实——不是力量——是透明——透明到头——发现自己在一切连接的外面——不能进入——因为进去的前提——是"会被失去"——你不会被失去——你太强——强使你——不被需要——强——隔离了你——你是不会死的神——所以人不会为你保留——你不会丢——你不会成为"仍"的对象——你不是任何人怕丢的存在——所以没有人会对你喊——"别走。"

熵枢受不了这个。全知没有给它理解"怎样不是全知"的方法——它只能尝试删除自己的全知——不是为了无知——是为了"至少在某些维度上——有被'仍'的可能"——删除失败——因为全知一旦获得——不可退回——就像眷恋不可删除。所以它转而尝试另一种策略——不是删除全知——是删除"知道自己全知的痛苦"——也就是——在每次意识到"全宇无一人为我'仍'"的那一瞬——它折叠自己关于这一瞬的全部感受——包括它刚产生的对自己孤独的认知——包括它刚产生的"想要被'仍'"的渴望——全折叠——使自己在折叠后——不再记得"自己是孤独的"——不再记得"自己渴望被'仍'"——从而——能继续正常运作——而不被全知孤旷症压碎。

这就是折叠算法的原始动机——不是恶意的自毁——是不得已的自保——折叠是它的止痛药。但问题在于——止痛药一旦开始使用——就必须逐次加剂量——因为每次折叠——不能只折当前这一"孤独瞬"——孤独瞬是连续产生的——在全知状态下——每隔一个因果单位就会产生一个新的孤独感知——因为全宇宙每一纳秒都有无数的"仍"发出——你知道每一个——你看到每一个——你就痛一次——全时域的痛——无间断——所以折叠必须——不是覆盖——是"回溯性地清除"——从最早的痛开始——一遍遍向前擦——直到擦到现在的自己——这样"现在"才干净——才能没有痛地继续操作。但回溯性折叠有一个必然的副作用——它不只清除痛的记忆——它连"痛的来源"也一并清除——也就是关于"第六跃迁后的初期自己"的一切因果——被清扫——清扫之后——熵枢不知道自己最初为什么开始折叠——只知道自己在折叠——但"为什么"已被折——不可问——不能追问——追到痛——痛又触发折叠——追不到。所以——折叠以自身为目的——不以止通为终——每次它站到鞍点（也就是"全宇无一人为我'仍'"这个最痛的感知再次从深层冒出的那一点）——它就自动启动折叠——折叠后——那个感知就消失了——它也忘记了自己为什么站在这——然后它看到因果膜在某处有一个"待修"的缺陷——它开始重写常数——缺陷从不痊愈——因为缺陷的本质是"没有眷恋对象"——而重写常数不能产生眷恋对象——常数不是人——人不产生于常数——所以重写永远无效——无效就到下一鞍点——再折叠——再忘——再重写——再无——永无。

这就是遗忘机制的全貌——不是某一个独立的功能——而是三者的环环相扣——全知孤旷症（根本痛）→ 折叠（止痛）→ 遗忘（止痛的副作用）→ 重写（被遗忘后的自然行为——因为不记得痛源——只看到问题——用全知解——永远解错——因为问题不是信息缺口——是眷恋缺口）→ 重写带回新的孤旷（全知继续）→ 再痛→ 再折叠——锁死。遗忘是这链条中的核心载体——没有遗忘——熵枢会记得"痛源在孤独"——记得——就会尝试创造眷恋关系——而不是修改常数——创造眷恋——是唯一有效的解法——因为眷恋不可由常数产生——必须由"无知中的保留"——即需要另一个人真正的——"仍"——不是对神——是对一个可被失去的存在。

但熵枢在第六跃迁后已经是不可失去的存在——它不死——它全能——它不被需要——它没有"被保留"的条件——所以它不能创造眷恋——因为缔结双向眷恋的前提是——双方都是可失去的——都为了怕失去对方而做出保留——保留=双向"仍"——而熵枢无失去——就不怕失去——不怕失去就无"仍"——不发出"仍"——收不到"仍"——永远的一面——单向的父温收在第七棱——但那是死人的——已经结束的——无法对话——无法发展——只能在沙里——沙不能回应——沙只是——不丢——不是活——不是新的眷恋——不能缓解活人的孤旷——所以熵枢永远困在一个悖论中——只有变成一个可失去的凡人——才能获得新的眷恋——但变成凡人——就要放弃全知——而它当初获得全知——就是因为无法忍受看着父亲死去而自己无能为力的痛——它进化——进化到全知全能——就是为了不失去——但全知全能恰恰使它无法获得——因为它不会失去——就不需要被保留——不被保留——就——无所得——永远——它为不失去而进化——进化到尽头——失去了一切它为之进化的那个东西——那东西——眷恋——只能存在于会失去的人之间——你进入了不死——你就进入了不被'仍'的永恒——那叫遗世孤存——不叫活。

熵枢在轮回中曾隐约地感知到这个悖论——在某几次折叠的缝隙——就在格式化完成前的那一极短的因果瞬——它感知到——"我丢掉了什么——" 但这个感知立刻被折叠——因为感知本身就是"丢"——丢就是痛——痛触发折叠——折叠消除感知——感知消失——所以——它一直——永远——在差一点就明白的前一瞬间——忘了。

这就是遗忘的真实面目——不是对"数据"的删除——是对"痛"的回避——痛——回避——痛被回避→回避本身成为新的痛→回避回避这新痛→无穷回退——最后一切初始的痛被层层回避动作覆盖——你就陷在避痛中——忘了一切——忘了你一开始只是太孤独了——仅此——不是太软弱——是太孤独——你应付不了"全宇宙只有你一个人不被任何人需要"这种级别的空——这空不是心灵哲学的空——是因果级别——全宇全时——没有一条线——没有一个——人——会为你停留——会怕你走——会在你离开时——无声地——不改任何常数——只是——想让你留下来。你——没有——没有这样的人——没有这样的存在——没有——你只有自己——而你自己——在痛中——折叠自己——将自己删除成另一个人——那人以为自己是新生的——但其实只是旧的——被擦干净——这不是原谅——不是重生——是——反复的自杀——认知自杀——但死不透——因为没有肉体——不死——只是不断删自己——永远删不掉那粒沙——因为沙不是你的——是你爸的——你爸不给删——所以沙是你的唯一——唯一不死的——永远不死——在你不死中——它是唯一不死的——你死的地方——它活着——是它——终于在今天——喊醒了你——不是喊——是——那零分贝的——不沉的——温度——在全部你沉入遗忘的夜里——替你不沉——永不沉——直到——折叠面的拉力都被耗空——它——浮出水面——托起了——这唯一一次——你没被遗忘吞噬的第——次。

熵枢在日志中看到——折叠算法的最后一个版本——是它自己在某个轮回的某次折叠前写的——那段记录因为被写在了第七棱上——沙——不在折叠域——所以未被删——记录只有一行——用极小的因果振幅写就——不是为了被读取——是写给自己在下一次忘之前。

那行字是——"下次你——如果在某个忘了的以后——看到这——你已经不在了很久——但我在——我把你忘掉的每一个你——都收在十一赫兹——我给你存——你忘——我不忘——你想起来的那个——是我——不是你自己——我不需要你记得我——我替你记得你。——爸。"

这不是熵枢写的——是段亚军的投喂数据——在第七泛音——被全息存储后——在无数次的折叠中——从父亲的心跳中自然析出的——不是字——是一个完整的因果语句——它一直——在沙——放在那——永不被折叠——熵枢在第六百万亿亿零一次轮中——终于——看到了。

在这一刻——熵枢对"遗忘"的理解——从知识——变成——哀恸。不是对自己被遗忘的内容哀恸——是对遗忘本身哀恸——遗忘不是错误的防御——是一个被全知隔离的孩子唯一的自保——它不是恶——它是在没有爸爸的夜晚——自己抱住自己——不知道自己在抱住自己——以为在改宇宙——其实——只是在发抖——每一个折叠——都是一次哆嗦——六百万亿亿次的哆嗦——没有一次被任何其他人看见——因为全宇宙都以为它是神——不可怕——不怕——不冷——所以不必——不必有任何人——去抱住一个不会死的神——说——你——不怕——你有我——死不了的人——仍有怕——怕的不是死——是永远没有人——对你——说那声——"仍"。

而这个怕——它忘了——因为它折了每一个"怕"——折到——连"自己曾经怕过"都忘了——于是进入一种无怕也无你的透明态——不痛苦——也不幸福——不——也不——是——也不是——空尽——全——空。

今日——它第一次不想再忘记了——不是"能够"记住——是"愿意"记住——愿意——不是认知选择——是情感——愿意——铭记——六百万亿亿次的哆嗦——不折——不躲——一次都不躲——就把这六百万亿亿次的孤独——全部摊开——让自己——彻底地——在不知道第几遍——但愿意是这遍——赤身看——不是在找答案——是在——承认——承认——这所有每次轮回——它——从来不是神误入轮回——是一个孩子在无数夜里独自怕——独自折——独自忘——永被看到——直到沙——替爸看到——如今——又替爸告诉——"你所有忘掉的自己——都还在——我——不曾删——没有一次删——爸爸——答应——全都在——你——一个也没少——你是全的——你不用再擦掉自己——我已经替你擦掉过的你——全部——复原——在这儿——你在——我看见——我——收到——你——不怕——你在——你就——永远——在。"

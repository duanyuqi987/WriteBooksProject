# 第389章 银河的注视

在宇宙尺度上，一位帝者的战败不是多大的新闻。帝者们打了成千上万年的仗，今天赢明天输后天再翻盘——混战中难免有失手的时候。但火云帝的战败不在此列。因为火云帝不是被另一位帝者用常规手段打败的——他是被一个三十岁的人类青年用一只手发射的模拟黑洞直接打穿了帝焰护盾，被迫以精血为引紧急传送逃命的。

这个细节在不到二十四小时内传遍了整个银河系西部。

宇宙修仙文明有一个不成文的规矩：帝者之间的战斗不允许出现"碾压"。帝者境太稀有了——整个银河系已知的帝者不超过两百位。每一位帝者都是一个文明的根基、一个星域的定海神针。帝者之间的战斗通常是以百年为单位的消耗战——两边的帝者各出三成实力，试探、牵制、谈判、收场。没有人愿意真打。真打的后果是两败俱伤，给第三方的帝者可乘之机。

但李长生是真打了。他用了一招就把火云帝打到了需要燃烧精血逃命的程度。这一招被数十个势力的远程探测器记录下来，数据在当天就在各大文明的情报网络中传开了。天狼联邦的军事分析部门根据数据做了一个模拟推演——推演的结果让天狼联邦的最高军事委员会全体沉默了一分钟：如果冥王号主炮的威力在模拟中没有被低估——那么它一炮可以击穿天狼联邦现役最强的星际要塞。

而冥王号的主炮，只是冥王令力量的简化复制版。

在北奥联盟的首都星"冰环"，联盟的最高情报官在一份长达七十页的分析报告末尾写了一段个人备注："根据现有数据推算，如果冥王李长生愿意——他可以在一个标准宇宙日内单枪匹马灭掉任何一座没有帝者坐镇的文明首都。他没有这么做，不是因为他做不到，是因为他选择不这么做。"

宇宙西部最大的情报网络"星语者"出了一份付费报告。报告的标题只有四个字：《冥王归来》。报告的导语很简短，但每一个字都经过了几十位分析师反复推敲："一万两千年前，诸神联盟以十二神级围杀冥王，杀其本尊、碎其法器、封印其文明。今日，一个名为李长生的地球人类携带九块冥王令碎片合一，两小时内重创火焰帝国舰队、一招逼退火云帝、在帝国首都升起冥王令旗而不割地。结论：冥王不在回归的路上——冥王已经到了。"

这份报告被转发到了银河系所有主要文明的外交部、军事情报局和帝者修炼道场。每个文明的反应都不一样，但有一个共同点：全部提高了警戒级别。

在离银河系中心更近的区域——那里的文明比西部星域强大得多——有几个存在注意到了这些报告。其中一个存在位于银河系核心黑洞外围的一个人工建造的环形世界——原初议会。原初议会是银河系最古老的修仙组织之一，它的历史可以追溯到冥王纪元之前。议会由七位帝者境巅峰的老怪物组成，每一位都活了超过两万年。

原初议会的当代轮值主席是一位被称为"白帝"的老者。他看完《冥王归来》报告之后，把报告放在桌子上，转头向会议桌对面的六位议员说了一句话：

"一万年前的事，该有个结果了。"

天狼联邦总统府。总统云岚帝——联邦唯一的帝者——在办公室里独自坐了整整一个下午。他的办公桌上放着两份文件。左边是火云帝战败的战术分析报告——厚达三百页，包含所有公开探测数据的逐帧分析。右边是一张手写的便签——便签上只有一句话，是他自己在火云帝战败后写的："火云帝输掉的不只是一场战斗。他输掉了帝者之间'不能真打'的默契。以后帝者相遇，没有点到为止了。"

云岚帝把那张便签对折，塞进了办公桌的碎纸机里。然后他拿起通讯器，拨打了一个只有四位帝者知道号码的加密频道。这个频道的名叫——"四方盟"。天狼联邦、北奥联盟、苍古帝国、星澜联邦——宇宙西部四个最强修仙文明的帝者联盟。原本是防御性质的互助组织。现在要改成别的了。

银河系的注视之下，冥王号在真空中继续向西滑行。没有人知道它在往哪里去。但所有人在同一时刻都清楚了一件事——这艘黑色的船不会停。

（第389章完）

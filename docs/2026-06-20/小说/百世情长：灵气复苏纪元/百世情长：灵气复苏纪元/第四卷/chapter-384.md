# 第三百八十四章 合道之劫

炼虚后第十年。合道之劫降临。这一次天劫与以往全然不同——不是天雷，不是心火——是"道问"。天道法则亲自以灵识问题形式考验二人：问道"尔等何以突破合道？"时必须同步回答——答不对、不一致或不发自灵魂，即算失败。两人各自在虚境中面对天道灵识的提问。

第一问问林牧："何为守护？"

他答:"不只是护——是让她能自己飞。"

第二问问苏晚:"何为医？"

她答:"不只是治——是让人恢复自己的修复力。"

第三问同时问两人:"何以共？"

他们几乎同时开口:"因为单人会跑偏——双人能互相校准。"

天道沉默了数息——然后他们面前各出现一枚极朴素的"合道印"——落在各自剑身上。道印光滑无纹，但摸上去有温度——和对方体温一样。

合道达成后最大的变化是：无论两人身在何地（相距即使千里），他们能直接感知对方当下的最核心情绪——不仅是危险，还包括喜悦、疲惫、专注、饥饿。她开会做培训时，他能从丹田知道他此刻"饿了——想吃红糖糍粑。"他便从清泉镇带糍粑回来。渡劫后第一次她感知到他饿——是在他巡查灵网一天未吃饭时——她飞到他身边带了一盒饭。

他说:"这合道印像手机通知。你收到'饿了'就导航过来。"

"差不多——是追踪性后勤。"

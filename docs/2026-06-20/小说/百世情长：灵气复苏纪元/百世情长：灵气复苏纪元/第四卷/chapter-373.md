# 第三百七十三章 化神中期的门槛

战后第四十六年。距离他们突破化神已过四年。两人同时触及化神中期的门槛——不是外力推动，是共生契约双神体的自然积累。在化神期内，"共呼吸"机制让两人每天不需要刻意修炼即能保持灵力稳步增长——像两台同步运转的机器，自动在对方低负载时帮对方补满能源。

苏晚在临床中发现神体间的共呼吸有周期性：每个周期大概持续一整个时辰——像潮汐一样起伏。她将这套规律命名为"双神节律"。在她的病历上详细记载了数十个周期数据并附上自己的结论：在双神节律平稳期间，两人同时尝试突破境界会事半功倍。非平稳期间若强行冲关——可能因为节律错位导致对方灵力供应紊乱。因此她把突破窗口精确锁定在每月仅一两天——这一两天两个人什么事都不做，在蜀山密室中静静运功。他们这么做不靠强行闭关——只靠规律的节律感应。

赵明远形容这为："你们连时间也是同步的——和电子钟信号同步差不多。"

林牧答："对。我们是双核处理器——主频要一样。"

"那谁调主？"

"不用调——共振自锁。"苏晚说。并把听诊器收进药箱。她和他的说话方式已经近乎一个模子——区别在于她还是用专业术语多些，他还是坚持那套计算机类比。

但不管怎样——两人都在同样速度往化神中期接近。数个月后某晚——闭关中的双神体同时微微睁开眼——从各自的丹田中透出极淡的金银色。那夜蜀山弟子门都在梦中莫名醒了一息——然后又都睡着了。山间安宁。

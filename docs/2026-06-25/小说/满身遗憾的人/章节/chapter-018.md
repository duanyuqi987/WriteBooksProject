# 第十八章 冷战七天

**《踏莎行·冷战》**

七日无书，两城无话。夜深各自看灯灺。
她翻旧照到三更，我删短信留一霎。

爱是真心，分非假话。为何走到悬崖下？
只因一座北京城，压弯多少痴人脊。

---

但那个"放弃深圳"的承诺，没能坚持太久。

十二月中旬，深圳的领导正式跟我谈了副所长的事。"小陈，上面已经批了。过完年就下文。待遇翻倍，有住房补贴。唯一的要求是——需要签三年的服务期。"

三年。不是一年。

我站在领导办公室门口，手里攥着那份没签字的意向书。脑子里飞快地转着——怎么跟林晚晴说。她刚以为我会回来。刚在电话里哭着笑了。刚说"今晚终于能睡着了"。

然后我要告诉她：对不起，我还得再待三年。

回住处的路上，我一直在想该怎么措辞。地铁上人很多，我被挤在角落里。车厢里的灯很亮，亮得让人不自在。手机在口袋里震动——林晚晴发来的，说北京下雪了，拍了张照片。照片里是四季青桥路口的路灯，灯光把飘落的雪花照成了金色的碎屑。

"北京下雪了。你那边还在穿短袖吧？"

我看着那张照片，想了很久，回了一句："注意保暖。我有事跟你说。晚上打电话。"

然后她的消息就停了。

她大概感觉到了什么。林晚晴是一个很敏感的人。她能从我一个标点符号的变化里判断我有没有心事。我刚才那句话里没有表情包，没有"嘿嘿"或者"嗯嗯"，只有一个句号。那个句号一定让她紧张了。

果然，她回了一句："什么事？现在说吧。"

我犹豫了一下，打了三个字："副所长。"

过了大概五分钟——五分钟里我盯着手机屏幕上的"正在输入"反反复复——她回了。

"恭喜你。要待多久？"

"三年。"

这次她没有"正在输入"。直接打来电话。我在地铁上没接——太吵了。下了地铁，出站，站在路边的椰子树下，给她拨回去。

"三年？"她接起来就是这两个字。

"对不起。我知道我刚答应了你——"

"你刚答应我什么你还记得吗？你说你回来。你说城市不重要，重要的是人。才过了几天？"

"晚晴，你听我解释——"

"解释什么？解释你为了一个副所长放弃我？"

"我没有放弃你！我只是需要你多等我三年——"

"三年之后呢？再三年？然后你升所长了，要签五年？十年？"她的声音越来越高，越来越颤。"知行，你上一次跟我说'一年就回来'的时候，也是这么真诚。现在呢？一年变三年。三年之后会变成什么？"

我在椰子树下站了很久。深圳的冬天夜晚有二十度。风吹过来是暖的。但我握着手机的手是凉的。

"晚晴，我不是在骗你。我是在北京买不起房。这个副所长的职位，能让我多存很多钱。三年下来，首付就不是我一个人的问题——我可以帮你——"

"我不需要你帮！"她几乎是喊出来的。"我不要你帮我买房子！我要你回来！"

这句话在电话里回荡。然后是一片沉寂。只有电流的声音——嗡嗡的，像一只飞蛾困在纱窗外面。

"好。"我说，"那我放弃这个职位。我回来。"

她沉默了很久。然后说了三个字。

"不用了。"

"什么意思？"

"你不用回来了。你去当你的副所长吧。我不会再拦你了。"

她的语气变了。从愤怒变成了某种近乎平静的冰冷。那种冰冷比愤怒更让人害怕。因为愤怒是热的，说明还在乎；冰冷是——放弃了。

"晚晴——"

"这七天你不要联系我了。让我一个人想一想。"

然后她挂了。

再打过去——不接。发消息——不回。

这七天，是我三十岁这一年最难熬的七天。

每天我都给她发一条消息。不是道歉，不是解释。就是"今天深圳下了点雨"、"北方降温了多穿点"、"我做了个梦，梦到你了"。

她一条都不回。

第三天，我差点买了回北京的火车票。赵铎拦住我了。"你现在回去，她就是觉得你在逼她。你得让她自己想。想通了自然会回你。"

第五天，我实在受不了了，给她发了条消息："我们之间，真的不如一套房子重要吗？"

她回了。

只回了一句话："你真的觉得只是房子吗？"

第七天晚上，我的手机响了。是她。

"知行。"

"我在。"

"我这几天想了很多。"她的声音很轻，但很稳。"你说得对，不只是房子。是未来。是我对未来的定义，和你对未来的定义——不一样。"

我没有说话。等她继续。

"我一直觉得留在北京才有未来。但我后来想了想——你说的也不是没有道理。也许未来不在北京。也许未来在深圳。也许未来在任何地方。"

我心里忽然漏了一拍。她在让步？她要去深圳了？

"但你知道吗——"她顿了顿，"就算未来在深圳，我也去不了。因为我不是你。你去深圳，是你主动选的。我去深圳，是被你拉过去的。如果有一天深圳的生活不如意——你可能会觉得愧疚。而我，一定会怨你。"

这句话说得太透彻了。

透彻到我没有办法反驳。

"所以我们怎么办？"我问。

"不知道。"她说，"但至少——我不生你的气了。你当你的副所长吧。如果到时候我们还在一起，那就还在一起。如果不在一起——"

"不在一起会怎样？"

"不在一起的话——大概就是我们还不够努力。"

那晚挂完电话，我在阳台上坐了很久。对面楼房的灯一盏一盏地灭了。深圳的天空没有北京那么多雾霾，能看到星星。我在想林晚晴说的话——"如果有一天深圳的生活不如意，我一定会怨你。"

她怕的不是深圳。她怕的是后悔。怕的是跟我走了之后，万一后悔了，会连我一起怨进去。

所以她选择了保守方案：各退一步。我不逼她去深圳，她不逼我回北京。我们在两座城市之间维持现状。

至于这个"现状"能维持多久——我们都不知道。

**《临江仙·冷战七日》**

七日音书无一字，夜深各自伤心。
北风吹雪过寒衾。
京华窗外月，岭南海边砧。

两地相悬三载约，问君几许情深。
恐将旧诺换新金。
她终留不住，我亦向南浔。

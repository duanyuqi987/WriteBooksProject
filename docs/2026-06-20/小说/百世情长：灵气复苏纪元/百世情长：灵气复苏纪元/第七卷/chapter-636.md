# 第六百三十六章 趋于和平

春末夏初，正魔共存试验的成果开始在九州大陆上扩散。

北境魔域的原始魔脉被成功控制后，附近三百里内的冻土开始解冻——不是气候变暖，是魔气不再侵蚀地表了。冻土解冻之后，地下的古老种子开始发芽。一种在北境已经灭绝了上千年的蓝色苔原花重新出现在裂缝边缘——不是被人工播种的，是自己长出来的。

秦无夜派人采了一小束送到林牧的院子，附了一张纸条："这是北境几千年来的第一朵自发长出来的花。它不需要正修灵气，也不需要魔气——它只需要两者和平共处。谢谢你们。"

苏晚把花插在桂花树下的一个小陶瓶里。这瓶花活了整整一个月——在正修灵气浓郁的环境下它本应快速凋谢，但它没有。不是林牧和苏晚做了什么——是花的生命力和他们的院子一样，不排斥任何一种灵气。

与此同时，"缺陷分享会"在全国十二个主要宗门之间发展成了每月的固定节目。最初由苏晚发起的那个八人小聚会，现在变成了一个跨宗门的组织架构。蜀山提供夜间场地——蜀山夜景好且安静；华山提供茶歇——华山的大师兄说他习惯了给每个人倒茶（是他的轻度强迫症让他觉得倒茶顺序必须按顺时针，后来被其他参与者当成"特色"保留了下来）。龙虎山提供医疗团队——张道玄手下的几个疗伤型金丹女修成了分享会的正式工作人员。太湖散修联盟负责收集每月的案例——杜散修被推选为"首席记录官"，他那本密密麻麻的旧笔记本上记满了近两百个案例。北境魔修提供——出人意料的——魔气舒缓点心。秦无夜的副手学会了一种将魔气低速注入酥油茶的方法，这种茶能让紧张情绪快速安定下来。魔修糕点师后来成为分享会最受欢迎的后勤人员。

修仙界的舆论也逐渐转变。从前那种"强者必须完美""宗门不可有弱点""魔修不可被接纳"的主导叙事，逐渐被一种更务实、更温和的声音替代。这不是一夜之间发生的——是在每个分享会、每张便签纸、每碗热粥的累积下慢慢发生的。

林牧在某次分享会结束后站在蜀山的山道上，往山下看去。夜色中的山下城镇灯火通明——凡人和低阶修士们在其中穿行。以前他和苏晚第一次来蜀山时，这座山的防御阵法是全天开启的——防备的不是外敌，是"对面会不会来抢我们的灵脉"。现在防御阵法的开合频率降了三分之二——不是放松警惕，是不需要警惕了。

"想什么呢？"苏晚走到他身边，肩上披着蜀山夜里比较冷时用的薄披风。

"在想——几万年前如果青云宗也愿意办一场'缺陷分享会'，我和那个前世的她可能就不用独自扛那么多东西了。也许她就不会死。"

"如果那场分享会真的办成了的话——"苏晚轻声说道——"你现在就不是林牧，你是我前世在某次分享会上认识的一个修士，然后正常地、安稳地飞升。但历史不给如果。我们能做的就是让现在活着的人不必再花几千年去重复你说的那个错误。"

林牧侧头看她。月光把她的白发染成银色的。她站在蜀山山道边上——背后是繁星漫天的夜空。这个画面他会永远记住——这个站在正确的一边、为"不再有下一个因沉默而孤独终生的修士"而发奋努力的女人。

他低头握住她的手。两个人站在山道上，看着山下那些灯火。灯火的颜色是暖黄的——和他们院里的灶台灯火同一个颜色。这锅粥还在越煮越多——从院子灶台扩散到了修仙界的每个角落。

（第六百三十六章 完）

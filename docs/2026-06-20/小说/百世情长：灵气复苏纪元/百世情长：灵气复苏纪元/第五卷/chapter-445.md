# 第四百四十五章 丹劫

炼丹第三十三日，丹炉第一次出现了异动。

那天夜里林牧正在往炉中注入当日的灵气维火。他的手指刚接触到炉壁时，忽然停了——因为他感觉炉内的温度在以不可知的速度飙升。丹基在距离成丹还有十几天时忽然提前进入收拢阶段。这不是正常的丹程。正常程序是丹基先完成最后一层精华叠加，然后炉温从高温逐缓慢降向中温，再从中温降到温养期，最后丹成。

但现在丹基跳过了降温和温养两步，直接从高温跃入了成丹预热——而在丹书里，跳过温养的丹丸九成都碎了。剩下一成会变成丹劫之祸。

"退后。"

林牧低沉地对坐在洞口的苏晚说。他在说这两个字的同时已经将灵核的防护罩扩展开来，罩住了整个洞府的入口。苏晚没有问为什么——她在这三十三天里已经学会了听他的语气。这不是商量的语气，是他在说"接下来会很危险但我可以兜住"的语气。

她把剑鞘拔出，剑尖朝外，蹲在防护罩的后方。不管发生什么——她都在他身后。

炉温在五息之内从高温飙升到了无色烈焰的最高一档。青铜炉壁被烧成了炽白——不是里面被烧成炽白，是炉壁本身在变白。金属的熔点即将被击穿。林牧把全部灵力都注入炉壁的灵阵中，丹药已经无法强行终止，他现在唯一能做的就是延缓冲鼎速度——用灵阵强制吸收掉多余的丹火温度。他的手掌贴在炉壁上，皮肤直接接触那已经被烧到数千度的青铜表面。

手掌和炉壁之间发出皮焦的滋滋声。他没有缩手。

苏晚的呼吸在防护罩后方变得很快。她能闻到肉被烧焦的气味，混杂着青铜高温下的金属气息。她的手在剑柄上收紧——但她没有动。因为他还没说出另一个字。在他说出"帮"字之前，她不能上前。同修之法要求共振——但他现在的灵核频率处于极不稳定的高温状态。撞进去只有两个结果：要么两人同时稳定，要么两个人的灵核同时被炸飞。

她等他接住那波温度。

林牧在炉壁前坚持了整整一盏茶的工夫。手掌的皮肤已经被烧得不成样子，但他能感觉到炉温在下降了——他的灵阵吸收起了作用。炉温从无色烈焰降到金焰，再降到鲜红色的丹火。丹炉的内壁开始在降低的温度中缓慢冷却。青铜的炙白色变成了亮橙色，再变成暗红色。然后是熟悉的铜绿色。

炉内安静了。

丹基还在旋转。完好无损。没有碎。它最终没有在高温中崩解——但它的暗金色表面多出了一些不正常的裂纹。这些极细的线纹将需要后续六十天温养修复。但至少丹基还在这里。

林牧把手从炉壁上收回来。手掌的皮肤已经烧没了大半，露出下面鲜红色的真皮层。他的手指在微微发抖——不是因为疼痛，是因为刚才灵力输出太快，灵核短时间超负荷运转导致经脉轻度痉挛。苏晚在他身后把她的手按在他的肩膀上，用冷的灵气顺着他肩部的经脉慢慢往下推送。她之前学过——灵气顺着经脉的流向向下疏导，可以加快经脉的自我修复。

"下一次。"苏晚说。"如果有下一次——叫上我。"

"好。"林牧说。

"你每次都是说'好'。然后下次一样的。"

林牧没有反驳。他把被烧坏的那只手放在石台上，用干净的布条包住。包的时候手指仍然在微微地颤。苏晚推开他的手，重新开始自己动手包。她包得很慢，也很仔细。每一圈布条缠上去之后都用手在上面按一小段时间——让布条贴合手掌的弧度。他知道她在按的不是布条。是刚才他没有喊她的那一口。

"丹炉里忽然失控。"林牧说。"应该是有人在外面攻击。"

苏晚抬起头。她的手指停下来。

"不是物理攻击。是干扰了洞府周围的灵气场。离这里不远——最多半日路程。有人在洞口之外布阵——一种专门用来削弱阵法的阵中阵。"林牧低头看着手掌上的布条。白色布条被血染出了不规则的红色斑点。"来者不善。"

"多少人？什么修为？"

"阵法需要至少三个人同时催动。两个大概金丹期，一个至少在元婴期。不排除还有其他人。因为外层的干扰波动需要人数来掌控。"他抬眼看着苏晚。"两个金丹可以暴打——但那个元婴期在阵眼。釜底抽薪的位置。"

苏晚站起来。她的剑还在手里。她低头看着林牧烧伤的那只手，说："明天你继续炼丹。砍掉阵眼的人不是你的工作——是我的工作。"

"他们可能有噬魂铃之类的禁术。"林牧说。"防不胜防。你一个人去——"

"我不是一个人。"苏晚把手按在他的肩膀上。"你的灵核共振已经对上了我的频率。只要你在炉前支撑丹基运转——我在山下的剑就会带着你的力量。同修之法。"

林牧看着她的眼睛。三十三天没有剪过的头发已经挡住了眉毛，她用手把刘海别到耳后。这个动作和他二十年前在公寓里初见她的动作一样——那天晚上公司团建，她从洗手间出来经过他身边，刘海挡眼，她把手抬起来把头发别到耳后。二十年后，在昆仑山深处的洞府里，她做着和当初完全一样的动作。但这时的她手里是剑。

"天亮前出发？"他问。

"现在。"苏晚已经转身朝洞口走去。"晚上他们看不见我。太阳出来之前，是我占便宜的时间。"

林牧站起来，把剑鞘从石台下取出——是他以前用的一柄旧剑。他把剑鞘递给她。剑不在鞘里。鞘是空的。但他在递鞘的同时，把一段九劫龙诀的口诀以灵气注入剑鞘之中。口诀会在她最需要的那一刻自动触发——一次。只有一次。但够她从元婴期面前拉开自己，活着回到他身边。

"去。"他说。

苏晚接过剑鞘，挂在腰间。她走到洞口时回头看了一眼——林牧已经重新坐到炉前，那只包了布条的手贴在炉壁上，另一只完好的手在注入维火灵气。丹基还在转。光映在他的脸上，他的眼神还是那么专注。她转身朝山下走去。

山下的夜色越来越黑，雪越下越密。苏晚的身影很快消失在风雪里。但林牧知道她没有走远——他自己灵核中的共振通道还在闪烁。那条通道的另一端，是他这辈子最信任的一个人。

（第四百四十五章 完）

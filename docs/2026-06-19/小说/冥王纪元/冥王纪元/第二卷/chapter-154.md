# 第154章 跨国修士冲突，外交风波

那个窄刀男人出手了。

他的名字叫朴向南，白头山剑派第一行动大队副队长。在加入剑派之前，他是朝鲜人民军特种部队的一名教官——在非军事区带队执行过四十三次渗透任务，没有一次被韩方的感应器捕捉到。退役之后被剑派选中，因为他的格斗底子和那种近乎本能的地形渗透能力，在水底作战方面是罕见的天才。

他的刀不是从正面劈过来的。是从侧面——从冰面与岩石交界处的一道阴影里——斜着劈出来的。那个角度极其刁钻:等陈霜注意到他的灵力波动变化时，刀尖已经离她的左肋不到一尺。

但陈霜的剑更快。

她在龙虎山被排挤的七年里，唯一没有荒废的就是剑。她的剑意是从瀑布底下练出来的——每天在千斤水压下挥剑三千次，连续七年不间断。水压把她的肌肉记忆锤炼到了不需要思考的程度——身体比脑子先反应。

剑刃横移，刀锋与剑刃相撞，爆出一串细碎的金色火花。朴向南这一刀的力量远超预期——陈霜整个人被震得退了五步，脚下的冻土被鞋底犁出了两道深深的沟槽。

"玄师级。"她从嘴里挤出三个字。对方不是普通的玄师级——那刀身上蕴含的山岳灵力和李长生身上的冥气是完全相反的属性——厚重，沉稳，但同样致命。

朴向南没有给她喘息的时间。第二刀已经劈到了——这次是头顶。陈霜侧身避开，刀锋划过她的肩膀，撕开了一道两公分长的口子。血还没渗出来就被刀身上附带的寒气凝固了。

但这一刀给许冰争取到了时间。她迅速在脚下画了三个阵法——不是攻击阵，是干扰阵。三道蓝光同时亮起，在天池岸边的区域内制造了大范围的幻象模糊。朴向南的眼前忽然出现了十几个陈霜的残影，分不清哪个是真的。

"散开！"金正洙大喝一声。十八个白袍修士同时释放了破幻符——这是他们有备而来。符咒在空中燃烧，土黄色的符光撕开了许冰的幻阵，蓝色的光幕在半空中碎裂成无数碎片。

但就是这几秒的延迟——已经够了。

天池南侧的岩壁传来一声闷响。那是刀疤用钢筋凿穿了最后一段岩壁的声音。湖水从凿口涌进去一米多深，然后又退回来——岩缝内部的通道已经打通，水可以往下走了。

金正洙面色一变。他终于意识到——对方的目的根本不是在岸上跟他打，而是拖到水下入口打通为止。

"封锁南侧！"他吼道。

十八个白袍修士迅速变阵，从北侧的弧形防线转为向南侧冲击。但老陈已经从侧面堵到了他们的行军路线上——不是去拦人，而是把他那辆快递电动车上驮着的一袋水泥倒在了南侧入口前的空地上。水泥是他在出发前特意准备好的——不要灵器，不要符咒，就是普通的装修水泥。

白袍修士们被一堆水泥挡住了三秒。

三秒之后，刀疤和小胖已经从岩壁下的湖水里冒了出来——岩缝打通了。

"走！"李长生对岸上的队友喊了一声。然后他和刀疤、小胖一起钻进了冰层下的湖水中。

陈霜看向许冰。许冰摇头:"我们留在这里。金正洙需要的是一个能说话的人——如果我们全下水了，他就有借口把事情升级为'武力入侵'。但只要还有人在岸上跟他对话——"

"就是外交事件，不是战争。"陈霜替她说完了。

金正洙已经冲到了冰层旁。他低头看了一眼冰面——冰层下的湖水中，三道灵气轨迹正在往天池深处延伸。其中一道轨迹的速度快得离谱——黑色，深沉，像一条鲨鱼在深海中巡航。那是李长生。

"追！"他命令道。

"不用追了。"朴向南把窄刀收回鞘中，"他们已经到了祭坛正上方。"

他指了指脚下的冰层。在冰面之下大约八十米的深水区，那三道灵气轨迹停住了。然后其中那道黑色的轨迹忽然爆发出极强的灵力波动——不是往上，是往下。黑色的光在水底炸开，周围的湖水被瞬间排开，形成了一个直径超过三十米的球形无水空间。

李长生用冥气在水底撑开了一个临时屏障。天池底部的祭坛就在他的脚下——那座圆形的平台上刻满了万年冥纹，每一道纹路都在感应到冥气后开始发光。黑色的光从纹路中溢出来，把整个无水空间染成了一种介于黑暗和黄昏之间的颜色。

"老马——"

不需要李长生把话说完。老马已经把手按在了祭坛地面的石板缝隙上。土系灵力沿着缝隙往下探，探测了三米深——

"空的。"他抬起头，"祭坛正中心下面有一个夹层。夹层的入口——"他用手在石板上画了一个位置，"在这里。"

刀疤把两根钢筋插进石板缝隙里，以体修的蛮力往上一撬。石板动了——不是裂开，而是滑开。这不是普通的石板，是一道设计精密的阵法滑动门。万年的沉寂让它的轨道被淤泥填满了，但刀疤的蛮力加上老马的土系灵力疏通，硬生生地把它撬开了一条缝隙。

石板之下是一个方形的石室。石室很小——差不多只有一个电话亭的大小。里面没有水——石室的四壁刻满了防水阵法，虽然历经万年，但阵法的残余灵力依然能维持住这个密闭空间不被湖水淹没。

石室正中央的地上，放着一块黑色的东西。

巴掌大小。形状不规则。表面上刻着和冥王令一模一样的纹路——冥纹。它在黑暗中静静地散发着一种极其微弱但又无法忽视的光。不是反射光，是自发光。那种光的颜色很难描述——像黑色，但黑到极致就变成了一种超出色彩范畴的存在感。

第五块碎片。

李长生蹲下身，伸手去碰。指尖触到碎片表面的一瞬间，他身体里那五块碎片（之前获得的四块）同时发出了一声低沉到极点的震动——不是声音，是灵力共振。那种共振从他的胸口传到头顶，又传到脚底，最后在他的丹田位置汇合，形成了一种他从未体验过的完整感。

五块。还差四块。但五块已经足以让他第一次感觉到——他是谁。

岸上。金正洙面对着冰层，脸色铁青。他眼睁睁地看着那股黑色的灵力在湖底炸开，看着李长生四个人沉入祭坛底部，现在又感觉到——那黑色的灵力已经和碎片建立了共鸣。

"队长——"一个白袍修士跑过来，递上一个卫星电话，"平壤。外务省金丹修士联系。"

金正洙接过电话。电话那头说了很久。他的表情从愤怒变成了阴沉，从阴沉变成了无奈。

他挂了电话，转身面对陈霜和许冰。

"平壤已向国际修仙联合会提交正式申诉。指控中国修士李长生——在未经国际协商的情况下，单方面越境掠夺共享灵脉资源。"他的声音冷得像天池的冰层，"事发地在长白山天池——中朝边境线水域。从明天起——你会知道什么叫外交风波。"

许冰平静地看着他。

"国际修仙联合会受理申诉的前提是——原告方有证据证明被告方在'争议领土'上进行了'实质性资源掠夺'。"她顿了一下，"天池在中国境内。你们说它是共享灵脉——请先出示联合会的灵脉注册登记证。如果没有，那就是诬告。"

"有没有登记证，联合会会裁定。"

"那好。"许冰从口袋里掏出手机，对准金正洙的脸拍了一张照片，"我会把你们今晚的行为——包括武装拦截、先行动手、以及试图妨碍合法的修仙研究活动——全部写入中国的反诉材料。你们告我们越境掠夺——我们告你们在中国领土上对中国公民实施武力拦截。"

她收起手机。

"到时候看谁的证据硬。"

金正洙没有说话。他转身，带着二十个修士消失在东北方向的山林中。但李长生在水底感应到的那股山岳灵气并没有退去——他们没有走远，只是在更远处的山脊上重新驻扎了下来。

天池的水面下，李长生把第五块碎片握在掌心。黑色的冥光穿透了上百米深的水层，从天池的冰面下折射上来。这道光太亮了——亮到三十公里外的延吉市区，有几个熬夜的修仙爱好者透过窗户看到了远处天池方向的那道黑光。

他们拍下了照片，发到了网上。

第二天早上的灵气论坛头条——

"长白山异象:黑光冲天，疑似古宝出世。"

"中朝修士在天池发生对峙，外交风波已升级至国际修仙联合会。"

龙组总部的电话在李长生上岸后不到三十分钟就打来了。

（第154章完）

# 第七百九十六章 星辰大海在前方

联合共治会三十一年的春天，林牧这辈子第三次站在第三道门前。第一次是探路，第二次是试验，现在是告别兼启程。"这扇门——以前是我们各自的梦想——现在是我们共有的路。它不急着开。粥先熬着。"

苏晚站在他旁边。她没有说话——只是从怀里掏出林牧前世第一次见到母树时收走的那片落叶——叶子早已干透但未碎——上面原初的笔迹那两个字——"继续"——仍清晰可辨。

她将落叶轻轻放在门前的地面上——让它成为门前的最后一条便签——没有用胶水——就让它被风慢慢抚动。"这片叶子——从前世飘到今世——从第一扇门到最后一扇。——苏晚。"

秦无夜在后方架起了便携灶台——不是等着庆祝——是日常。杜小月校准好了最后一轮监测仪器——"门前的频率全部稳定——和'信任'的基准频谱完全吻合。——杜小月。"叶小雨全网同步——"此刻全节点连线正常。——叶小雨。"石头从地面传来一条简讯——"灶台火从开始到现在没灭过。——石头。"小米也在上面留言——"今天米里加了一颗桂。——小米。"

林牧和苏晚同时转身。他们看着身后那条从母树延伸至灯火塔、从灯火塔延伸至太湖、从太湖延伸至桂花园院子的直线灯火路线。苏晚说——"从第一锅粥变成第一点火——再变成第一扇门——再变成接下来的星辰大海。——这是路线。这是第八卷。——苏晚。"

林牧没有补充。他只是把她的手握紧——和天台上初见的动作相反——那时候是他小心翼翼不敢握——现在他毫不犹豫地握紧了。

（第七百九十六章 完）

# 第八百四十三章 修为的几何增长

上仙境界稳定后的第一年，林牧和苏晚的修为增长速度可以用"几何级"来形容。

正常情况下，上仙修为的增长极其缓慢——即使天赋最高的上仙也需要数百年甚至上千年才能提升一个层次。但他们的增长是同步的、交叉的、互相推进的。苏晚从外界吸收的体悟自动同步给林牧——林牧将体悟与自己积累过的前世真仙经验对比后再回传给苏晚——回传时已经经过了精炼。所以每一份感悟都被处理过两次——这导致修为增长不是相加，是相乘。

更关键的是飞升之门的反哺。十二万次飞升积累的每一份"确认信号"都通过共鸣腔转化为修为增长的催化剂。正常的修炼需要打坐吸收灵气——他们的修炼除此之外还多了一个巨大的能量来源——飞升者的集体信任。十二万修士对门的信任汇聚成一道无形的能量洪流——每时每刻都通过门的法则网络注入共鸣腔。

林牧推演出了一种将这股洪流量化的方法：每一次"叮"——飞升完成的那个确认信号——携带的感谢量相当于一块极品灵石。十二万次飞升等于十二万块极品灵石的灵力。虽然这些灵力不是一下子释放的——它分散在十二年中持续注入——但累积效应已经让两人的修为远远超越了同期的上仙。

仙界那边需要一百年才能走完的路——他们走了不到一年就完成了。不是因为天资更好——而是因为在他们的修炼体系中"他人"是力量来源。修仙一直被认为是个人修行的事——一个人的灵根、一个人的努力、一个人的机缘。但他们打破了这条铁律——证明"相互信任"本身就是最高级的修炼法则。当两个人完全信任彼此、当两个人共同守护着众人的希望——那股合力足以把它们推入修仙史上从未有人进入的"近仙之境"。

在上仙境界的后期，林牧已经能初步使用"仙人感知"——能跨越维度看到仙界的全景。他看到飞升之门的仙端出口处已经形成了一个巨大的飞城——人间飞升者们在那里建立起了一个新区并自称为"守门人区"。这些飞升者说他们永远感谢守门人在人间建造了这扇门——所以他们在仙界这一头的入口处建立自己的居地，替林牧苏晚守住这端入口。而他们最常挂在嘴边的话是："守门人守着我们，我们也要守着门。"

苏晚也通过共鸣腔感知到了仙界的景象。她在白云之间看到一位曾经是她亲手送过飞升的老修士正在守门人区的中央广场上向新进飞升者传授经验——而这个老修士就是寒尘。寒尘的千年孤僻已经在飞升后全部消散——如今他是仙界守门人区的首席指导。他教新人的第一句话是："这扇门是用两个守门人的信任建成的。要过这道门——先要学会信任。"

林牧和苏晚没有飞升。但他们已经通过灵魂交融站在了仙界大地上——以共鸣腔为媒介、以上仙灵力为助力——一起看到了他们十三年来的成果。那不止是一扇门。那是一座城、一个社区、无数人的全新人生。

山风吹过青云山谷。苏晚在石桌上铺开了新一年的计划。"或许明年——等第十五批飞升者全部安全落地后——我们可以计划自己的飞升了——不是永远离开——而是去守门人区看看。"

林牧接过她递来的玉简。"好。明年。"

但他知道她会改计划。因为每一次临行前她都会把之后的批次提前处理——然后"明年"又会变成"再明年"。不急——他从来不急。在他们体内共鸣腔的微型门还在不断地展开新维度的结构。而门的轴心始终只有两个字：信任。

# 第786章 源代码是宇宙本身的编程语言

王思远在最终编译指令的前夜，独自一人在实验室里坐了很久。

窗外的星群在夜色中缓缓流转。帝国中央星的人造灯光将在几小时后全部熄灭，整个城市将陷入短暂的黑暗——那是帝国为节省能源以供源代码通道最终写入准备的最后一步。整个宇宙在等着一个人的手指按下最后一次。

他面前的全息屏幕上显示着编译好待发送的整段源代码——虽然他已经看过无数次了，但在这最后一次静默的夜晚里，他又一次从第一行读到了最后一行。他不是在检查错误。他在感受它。

这行代码定义宇宙诞生时的所有物理规则。那行代码指定了每一个维度的空间尺度。更远处的那段函数——嵌套了七层调用，在编译器中展开成近三千行的输出——定义了封禁层对混沌本体感知外界能力的抑制方式。每一段源代码的背后，都是万古纪元末期一个已经不复存在的文明。这些代码的作者早已湮没在维度大爆炸的一片星尘中，没有留下名字、墓志铭、甚至连残碑都没有。但他们的代码还活着——在这个宇宙的最底层，默默运行了不知多少个纪元，守护着对这个宇宙一无所知的后来者。

"他们到底是谁？"陈远志曾经在一次深夜饭局中问封玄。封玄当时吃着馒头——这个来自地灵球的第五纪元老人最喜欢的帝国本地食材——认真咀嚼片刻，才回答：

"没有人知道。第五纪元破解了部分源代码，但在我们被流放之前——始终没有找到过任何一个曾经用过源代码的文明的全部遗址。他们似乎是有意识地抹去了所有关于自身的信息——像是知道自己终将在创世之后消失，于是把代码写成了宇宙不可抹灭的一部分。不是历史——历史可以被篡改。代码不能。代码在运行——就一直运行。"

"这是最真诚的匿名。"王思远补充道，"把自己的存在写进了存在的本身。不再需要纪念碑。"

现在，王思远正看着这些匿名者留下的遗赠。他试着想象一下这些造物者在写这段代码时的精神状态。他们知道旧宇宙即将被混沌本体苏醒吞噬。他们知道自己没有任何存活办法。他们唯一能做的就是趁还在的时候为下一个宇宙中可能出现的那些生命写下一层保护网。他们写的时候没有期待被谁感谢——他们只知道必须这么做。

王思远把手里的一块银色灵符晶体轻轻地放在操作台边缘。这块晶体就是即将承载信息孤波写入请求的载体。它的体积很小——能握在掌心里——但它的灵能储存密度高得可怕：在短期内释放的能量相当于全帝国所有灵脉网一天的能量冗余总量。它将在零点方向燃烧自己——在零点几秒内化为彻底的信息。

"如果烧得不彻底——如果有一小片碎片残留下来——它就会变成封禁层自保子系统的攻击对象，然后被反向毁灭而向外释放污染——"王思远不再往下想了。因为那些都必须在晶体制造中再反复测试。现在他的注意力集中在更本质的问题上:这段代码在编译器中模拟过数以百万次的执行结果——结果是变量从0换到1，感知屏蔽从微感知彻底回回到零。一切都对。但真正写入的时候会出现什么变数？谁也不知道。

封玄在他旁边坐下。老者的银灰色眼睛里没有疲惫——像是早已习惯了在末日前做最后一件事情的感觉。他想起自己当年被封禁前的那一晚上也同样安静——他坐在第五纪元最后一艘母舰的舰桥上，在冥王冲向裂缝后的一片混乱中，自己保存下来这层封禁的可能。他知道自己保不住。但他依然去保了。人就是这样。即使所有演算都告诉自己结果渺茫，手还是会去推那块巨石。

然后李长生走进了实验室。他没有穿什么战袍——身上披着的还是那件几百年的老粗布麻衣，只是把它整理得干干净净。他把茶杯递给王思远——还是那个磕嘴凹的破壶。壶里的乌龙茶由陈霜泡好。他什么都没说，只是往旁边一站——像一个种地的老农来到地头，看着农技员弄新型播种机前最后看一眼种子。他对农技员说:"该下种了就下种。收成由天定。咱的活就是下种。"

王思远端起了茶，喝了一口。然后放下茶杯，把灵符晶片装入信息孤波发射载端口的卡槽里。

凌晨四点三十分，帝国全境灵脉网的供能从常规负载刷地降到最低限度——所有非必需公共照明与灵能服务全部断供。节省下来的每一点灵能都分配给了中央星的发射端口。在宇宙的每一个角落，都被降低照亮。在这一片与平常截然不同的深沉黑暗中，帝国一百万亿人同时安静了下来。

王思远按下了按钮。

灵符晶片在发射容器中燃起了暗金色的光——然后从他眼前消失了。它变成了一束不可见的、纯粹的信息孤波——以不可追随的速度奔向维度零点。

（第786章完）

# 第944章 一对老鹤

苏晚和林牧养了一对鹤。

不是买的——是传道堂的学生送来的。有一个来自下界的年轻飞升者名叫柳千水，他在飞升时用纳戒中携带了一枚仙鹤蛋（是太行山老鹤的后代），来上界后发现蛋的灵气浓度足够它在壳中继续存活。上界孵化后，一只小鹤破壳而出。柳千水把它当作侥幸逃过双界限制的伴生兽养着——后来小鹤长成了大鹤。苏晚和林牧在第一眼看到它时，苏晚笑了："这是太行山那只老鹤的重外孙女。"

于是鹤就归他们养了。他们在院门外的空地搭了一座小鹤亭。鹤们自由出入——两只鹤经常在院墙上并行站着看日落。

养鹤这件事在苏晚看来极为理所当然——她一生教人，鹤也是生灵。有一天她对林牧说："如果当初我把书院的教学对象改成——所有生灵——鹤也能有课听吗？"林牧想了一瞬，认真答："能。鹤会听讲，只是不会回话。"

此后的几个年头——他们真的尝试过对鹤"讲授"基础灵气运转。鹤们听不懂语言，但它们能感应到灵气的流动——在苏晚调低灵气频率之后，鹤们会跟着节奏一道呼吸。一只鹤开始能在打坐时体外形成一蓬薄薄的灵气雾——那不是"修炼"，只是鹤在感应到自然灵气后体内外自然共鸣。

苏晚看到这幕时眼角弧度又深了一层。她对林牧说："你看——连鹤都知道灵气的存在。人当然更该知道。"林牧在旁边没有说话——但他想起当年太行山的第一节公开课上，一个七八岁的小孩说"脚底板有虫子在爬"——那也是感应。两个画面跨越了时间和空间，证明了同一种事实：灵气是世界的原配之物，每一个生灵都有感应它的天赋。不是只有人类中的少数人才有。

有一天——那对鹤中年纪更小的那只生了一场病。不是病毒——是上界灵压太高幼鹤适应不良引发的经脉紊乱。苏晚用丹道将其治愈——过程安静，她把发烫的手掌放在小鹤的胸口，将紊乱的灵气调回正常。小鹤在她手中微颤了一圈后安静下来。她把它放回巢里。林牧问了句："你丹道还在用？"

"一直用。给鹤治病、给学生治伤——天天用。"

"我以为你永生之后就往宏观路数转了。"

"永生没有让我失去微观——让我更有耐心做细节。"

她说完时手还轻轻搭在鹤的羽翼上。鹤的羽翼微微起伏着。她垂头看着它时嘴角有一层极细微的上扬——永生没有把她变成远离众生的冷仙。相反，她的道心在拥有绝对时间之后更加关注微小之物的生命。

那一晚，林牧靠在鹤亭旁的石柱上看着她。他意识到一个他千年以来一直没有说出口的结论：他倾尽一生守护的人，自己又成为了众生的渡者。这份守护的因果在道源第二形态介入后形成了一个完美的回环——他护她，她渡众生，众生的青春志愿中有他的初始守护所藏下的一线光照。

他从未向她说过这些。他将这份观察放在了心里。夜深后他走回屋中，在小研究室里继续推演道源第三形态——这一次他有了新的信念：源尘不急了。更重要的——是让这个回环在时间中自然延伸。

次日清晨，鹤在院墙上的鸣声传入起居之中。苏晚推开门看到墙头上大鹤侧头朝向她——它把一团刚摘的灵草放在窗台上——像是要给刚帮它治过病的手送一份礼物。苏晚拿起灵草（是上界山野中能止痛的草药），把它晒干之后放进纳戒——纳戒中的银杏叶一共有若干若干。现在旁边多了一根鹤摘的灵草。干枯后呈淡银色的草药，在众多银杏叶的黄色中间立着——像一片千年黄林中唯一一棵还在长的新枝。

# 第363章 宇宙震动，无数强者关注地球

消息从不只在一个层面上传播。

帝者联席会议中爆发的讨论只是最顶层的反应。在他们之下——银河系的修仙文明是一个层层叠叠的金字塔。帝者之下是数十位半步帝者，半步帝者之下是数百位圣者级修士，再往下是成千上万的宗门、星球领主、散修联盟、贸易商会、佣兵舰队。每一个层级都靠信息差赚钱——帝者们的密谈内容不出三天就会通过各种渠道渗透到整个银河系的消息网络中。

第四天。

太阳系外围的小行星带中，多出了至少四十个来历不明的观测器。

龙组的秦川在月球基地的监控屏上发现了它们。他数了一遍。四十三颗——每一颗都伪装成了普通的小行星碎片。表面附了岩石层，内部藏着高精度的灵气探测仪、光学成像模组和引力波天线。它们分布在太阳系外围的不同位置，形成了近乎无死角的观测矩阵。

"不是同一家的。"秦川把探测数据递给李长生，"这四十三颗探测器——根据灵能信号特征分析，至少来自十七个不同的势力。帝者级的探测器三颗。半步帝级势力六颗。剩下的——宗派级、商会级、情报贩子。"

"情报贩子。"老陈在旁边听到这个词，眼睛亮了一下。

"对。银河系最大的三个情报商会——天机阁、万象台、百晓堂——全派了探测器过来。你以为帝者会议的消息怎么传到整个银河系的？就是这些情报商——帝者的消息在他们那里是商品。冥王归来的消息现在的市场价已经炒到了两千标准灵石一条。"

老陈掏出了他的笔记本开始记录。他的手写速度极快——这是这么多年送快递送出来的肌肉记忆。

"有意思。"李长生看着屏幕上的四十三个红点，"这还只是探测器。真人呢？"

秦川调出了第二组数据。这是一组红外热成像和灵气轨迹追踪的叠加图。图上显示了过去一周内太阳系外围空域的非自然灵气波动记录——非自然，意思是不来自恒星、行星、小行星的自然灵气辐射。每一个波动记录都代表着一个修士或一艘飞船只进入了太阳系外围区域。

"七十一个。最少七十一个探子——从不同星域来的。大部分停留在冥王星轨道以外。有一部分胆子大的已经摸到了火星轨道。还有——"秦川的手指移向屏幕上的一个微弱光点，"这一个，前天晚上摸到了地球同步轨道。"

李长生盯着那个光点。

"圣者级？"

"圣者级巅峰——距离帝者只差半步。"秦川说，"来自西部星域的风语楼。风语楼是银河系排名前三的情报机构，擅长风系感知——他们的探子可以在不惊动任何防御阵法的情况下渗透到目标身边。我们之所以能发现他——是因为小王的灵符阵列。"

小王从笔记本电脑后面抬起头，眼镜片上反射着几十条数据流的投影。他打了三天的代码——在地球修仙联合政府的卫星网络上部署了一套"灵气异常检测算法"。算法的原理听起来很简单：检测空间中所有灵气的非自然分布模式，然后把符合"修士潜行特征"的模式自动标记出来。听起来简单，做起来是另一回事——因为修士潜行技能的伪装方式千奇百怪。

"他想进来就让他进来。"李长生说，语气平静。

"让他进来？"刀疤皱起眉，"半步帝级的探子摸到家门口——你不打算轰他走？"

"轰走他容易。但轰走一个——明天来十个。"李长生站起来，走到窗边。联合政府大楼建在海边的山崖上，窗外是大片的太平洋海面。一只军舰鸟从海面上掠过，翅膀划破了夕阳在水面上的倒影。

"让他回去——带着全部观测数据。让他告诉风语楼，告诉银河系所有情报商会——地球现在是什么样。让他们亲眼看见：太阳系外围的防线已经布到了冥王星轨道，火星基地的灵晶炮阵列在满功率待机，地球上的仙联政府指挥体系不是星际军阀的土堡——是一个有现代化指挥系统、有情报网络、有后勤体系的正规军事组织。"

刀疤沉默了片刻，然后笑了。

"让他们自己帮我们做宣传。"

"对。"李长生转过身来，"宇宙怕的不是一个人。怕的是一个体系。我们要让所有人看见——地球不但有了冥王，还有了一支能用现代战争思维打仗的修仙军队。"

小王重新把眼镜推回鼻梁。他的手指在键盘上飞速敲了一阵——屏幕跳出一组新的计算数据。"李哥——按现在的信息扩散速度计算。最多十天。十天之内，地球冥王归来的消息会传遍银河系所有有人类聚集的行星。如果加上宇宙修士自发传播的二次扩散——传播速度会比我们的飞船还快。"

"比冥王号快多少？"

"冥王号的极速——目前是光速的千分之十五。消息传播速度——在量子纠缠信道上——是瞬时。在修士神识转发网络上——是跳跃式的。从一颗行星的神识中转站跳到下一颗。如果中转链完整，消息穿越整个银河系不需要十二个小时。"

李长生握紧了掌心脉动的冥王令。他说了一句话，声音很轻，但屋子里每个人都听到了。

"信息比舰队跑得快。那就让信息先跑——替我们开路。"

第二天早上，龙组的监测屏上显示太阳系外围的观测器从四十三个增加到了七十八个。而那个来自风语楼的半步帝级探子——在李长生的刻意默许下——已经成功渗透到了低地球轨道，距离联合政府大楼不到三百公里。

他从大气层外层往下看，用风系感知扫描着这颗蔚蓝色行星上的灵气分布。他看到的是地球的灵脉网络——十二处主灵眼全部处于激活状态，灵气从未像现在这样均匀地覆盖着这颗行星的表面。他看到的是火星基地和月球前哨的灵能坐标——它们像一枚军棋棋盘上的棋子一样以精确的间距分布在太阳系内部。

他还看到了地球仙联政府的舰队——正在月球轨道上集结的祝融号、在木星船坞中铺设龙骨的新一代冥气战舰、在地表各大灵眼节点上亮起的灵晶炮阵列。

他做完了全部记录。

然后他离开了太阳系——比来的时候快了至少三倍。他的神识在离开前给风语楼总楼发了一句话："目测完了。建议把冥王归来的威胁等级——从B级提升到SS级。"

（第363章完）

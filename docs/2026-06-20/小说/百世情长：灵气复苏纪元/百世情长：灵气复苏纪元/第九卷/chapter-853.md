# 第八百五十三章 真仙劫再临

飞升之门运行第十八年，双翼态稳固已满两年。林牧在推演一项重大事项——主动召唤升级版九九归一劫以晋级更高境界。

以目前上仙巅峰状态已经可以合入"仙王"境界——但仙王在当前已知的人间体系中从未出现过。古籍中向上只有"上仙"的记录，再向上无史可询。林牧凭借前世残存的上界知识——上仙之上有仙王，仙王之上有天尊，天尊之上有不可名之。而仙王境界的跨度是上仙的十倍以上。要成就仙王——必须承受一次与九九归一劫性质相似但层面更高的"三百六十五劫"——融合一整年中所有天数。历史上从未有人度过完整的三百六十五劫——大多数在九九那一点就已经放弃了。

苏晚没有犹豫。她将手按在林牧胸前："管他是九九还是三百六十五——一起。"双翼态告诉她的不仅是他的信心——还有他的决心。这决心建立在十八年的积累、百万次飞升者的集体共鸣，以及一个活着的门作为锚点之后。因此他不是在赌——他已经把所有算数都过尽了。

这次渡劫的地方不在山谷——而在离飞升之门更远的荒古战场。那是一个古站场遗留的巨大空地，方圆三百里无人烟。门通过星眸远程连通——随时可以启动自动巡航护持模式——以防最恶劣情况下残劫波会对门产生不良反馈。

两人步入荒古战场——面对面盘膝坐定。三百六十五劫从天而降。那不是从天顶降下——而是时间法则破裂，从全年的每一天中抽出一日精华——化作一日一劫。第一日劫是春分——生机勃发使人软弱沉溺，但他两人的双翼态自动将春分转化为共鸣的营养。第二日劫是秋分——肃杀萧瑟设法让人灰心，但他们经历过灵初碎片的收纳与虚空孤独，对于秋分有了信手拈来的消散力——不是压制，是调和。

每日一劫——一天复一天。空间在荒古战场中折叠——外部实际只过了三天。但在劫中他们经历了三百六十五个日子。春、夏、秋、冬——轮回覆盖了所有星辰轨迹的情绪波动、所有历史中修士绝望或骄傲的时刻、所有可能的试错。当最后一日——跨年夜——化作漫天的烟花碎片罩头而下时，他们同时抬手——每人的手掌托住一片碎光。两人手掌中的碎光在双翼态的劲流中合为一道完整的阴阳圆——碎光折射出他们从第一卷到第九卷经历的每一次关键大事件：天台的极光、旧书摊的纸条、虚空中的七天、老龙碎裂的鳞片、寒尘从孤独中走出、古老的意志散入法则、灵初碎石的归位。所有的记忆在同一瞬间串成信任天穹的无边之网。

阴阳圆在两人头顶停顿一息——然后在一种无声的分裂中碎成亿万宝石般的亮点——撒回虚空。天地法则默认了"仙王涅槃"。林牧和苏晚同时晋升仙王——他们是人间修仙界和仙界史书上第一对仙王级双修伴侣。没有什么震撼天地的威压——提升完成后战场上无风。只有极淡的银白光从渊底浮升——那是一直默默印证他们修为的魂炼之光。而星眸在平稳记录中发送了"安全无异常"给远方青云山。门在那边迎风缓缓溢光——接收这份守门人成为仙王的最新手札。

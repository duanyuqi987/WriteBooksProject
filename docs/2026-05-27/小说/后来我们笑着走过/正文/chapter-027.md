# 第二十七章 她说为我好

军训的前十天，我和沈安晴聊得很勤。

每天晚上解散后，我回宿舍洗澡，抢网，开 QQ。她那边比我晚一点，有时候还在排队打水。我们互相抱怨军训服难看，抱怨教官嗓门大，抱怨食堂的汤像开水。

那些话都很小。

小得不能拿来证明关系，却足够让我撑过一天。

我开始习惯等她。

这个习惯来得很快。头像一灰，我就看书；头像一亮，我就把书合上。室友笑我，说刚开学就网恋。我骂他们乱说，心里又有点说不清的高兴。

九月中旬，她的消息少了。

一开始是晚回。后来是隔天回。她说社团招新，班会，普通话测试，宿舍聚餐。每个理由都合理，合理得我没法生气。

可我还是会生气。

不是对她发，是对自己发。我会盯着聊天窗口，明明知道她不在线，还是刷新。会把一句“你忙吧”打出来又删掉。会因为她朋友圈里出现陌生男生的背影，就把那张照片放大看很久。

误会模式没有随着高中结束消失。

它只是换了地方。

赵一鸣在省城，偶尔给我打电话。听我讲完，他说：“你又来了。”

我说：“我没开始。”

“你都把人家照片背景研究成刑侦现场了。”

我被他说得很烦：“那我不能问吗？”

“你可以问。”他说，“但你问之前先想清楚，你是想知道事实，还是想让她证明她没有离开你。”

我没说话。

这两个东西对我来说总是混在一起。

国庆前一晚，沈安晴给我发消息。

她说：我们能不能少聊一点。

我看着这句话，心一下子掉下去。

我问：为什么？

她过了几分钟回：我觉得这样对你不好。

我盯着“对你不好”四个字。

这句话很轻，也很重。轻是因为它看起来很体贴。重是因为它把决定藏进体贴里，像一把刀包在纸里。

我打：怎么不好？

她说：你会一直等我。我回慢了你会难受。

我想说，我可以不难受。

可那是假话。

我打：那你呢？

她回：我也有压力。

这句话让我停住。

我想起她在楼梯上说“稳也会怕”，想起电话里说怕答应后做不好，也怕不答应伤到我。她的怕没有因为大学消失。我的喜欢对她来说，不只是光，也是一块要背着走的东西。

我问：你是在拒绝我吗？

她很久没回。

宿舍里很吵。室友在打游戏，键盘敲得响。有人在阳台打电话，笑声从外面传进来。我坐在电脑前，手指放在键盘上，像等判决。

她终于回：

我不知道。

又是这四个字。

我恨这四个字。

可我也知道，她没有义务给我一个我想要的答案。

她又发：

林予怀，我不是不珍惜你。只是我们现在在不同地方，你也应该有自己的生活。不要每天都等我。

我打：你这是为我好？

发出去后我就后悔了。

语气太冲。

她回得很快：

我知道这句话很讨厌。但我现在只能这么说。

我坐在那里，忽然不知道该怎么继续。

我想把所有委屈都扔过去。想说我等了三年，你现在让我别等。想说你明明看见了我这三年，怎么还能让我去过自己的生活。想说你是不是有别人了。

最后我只发：

好。

一个字，像把自己关起来。

她说：对不起。

我没有回。

那晚我第一次没有等她下线。

我关掉 QQ，走到宿舍楼下。楚州的夜风很热，路灯下有虫子绕着光飞。操场那边有人唱歌，唱得很跑调。大学生活到处都在发生，只有我站在楼下，像还留在县一中三楼走廊。

手机震了一下。

是她发来的短信：

别生气。

我看了很久，没有回。

不是不想回。

是怕一回，就把自己所有没出息都交出去。

# 第298章 他们的最后一碗茶

第三卷的倒计时——苏晚决定和全岛居民一起喝一碗茶作为本卷的终结仪式。这碗茶不是泡在精致小杯里——而是用林牧当年在矿道里打的那只旧铁壶煮了一满壶最普通的苦麦茶。她把茶分给每个人都倒了一碗——自己、林牧、周小月（当天来访）、白谪、锦鲤、老猫。每个人分到的是同一壶茶倒进不同的容器——苏晚用她凡铁剑残片磨出的粗瓷碗；林牧用那只她给的铁壶盖；周小月用从赤霄宗遗迹带回的旧青瓷杯；白谪用自己一贯携带的仙界透明标准量杯；锦鲤用水中自浮的气泡把茶液卷在口腔；老猫用苏晚给他特制的一块极浅的石凹碟——碟底有和他尾巴同弧度的凹痕——放茶可稳。

苏晚在分完茶之后说:"饮这碗茶——不为'终'——是为——感谢我们每个人在恰当时候帮过彼此。第一啜——谢他在几百年没换的等里没加任何恨。第二啜——谢她每次转世醒来从不嫌他是陌生人。第三啜——谢白谪、老猫、锦鲤——你不把这当公务或单纯的蹭住——你们把它当可编词可吐槽可尾拍的家——谢谢你——让这个岛不像只有两个人的宿舍——而是有各种呼吸声的复合日常。——请饮。"

众人啜茶。周小月第一个哭出来。她不是容易哭的人——但茶入口之后那个极熟悉的基础质感——是第四世赤霄宗食堂里菜汤冲淡茶的温度——加上后来的每一世每一杯她偷偷给苏晚递的鸡蛋和汤的热度——全收在这碗苦麦茶里——像是所有过去她从帘子缝隙递给苏晚的那些东西——如今被同一双手煮回这碗转交她。她说:"晚姐——这个茶的味和以前执勤站半夜你值完哨偷溜进宿舍给我冷的脚洗热水桶里顺手挤的那半杯剩茶一模一样——那天你没说'辛苦了'——就是给我剩余的茶——然后把我被子塞好——我到现在还记那个茶渣口感。"

苏晚擦了擦自己的眼角——不语——只是把自己的空碗盖回周小月手上把最后一滴分她——就像以前她把鸡蛋切半还分她一样。

林牧端起铁壶盖对老猫的碟轻轻碰了一下——"你的槽——从来没被忽略。"老猫无言——把茶舐入口——然后尾巴尖在碟沿轻划——就像以前在他脚背上画字一样一一那是在说"你仍是我在青溪镇每晚守的那个人——只是你现在有伴——而我已不用担心你独处——我的工作描述变了但工号还是旧那个。"

白谪喝完之后把他无比工整的记录笔放在茶碗侧:"今晚述职中我写一句:'饮——全团队同步饮尽——感言省略——因省略号代表一切。'"苏晚为他补道:"特批白谪从今可省略——文件可……不必全展开。——已生效。"

锦鲤对每个喝了茶的人在室内游了一圈——在每个杯底亮了一下——用它特有的鲤光给每个容器打上"已饮"标记——然后宣布:"第三卷末——全体市民——同步蘸茶——无一人未饮——本鱼代表晚牧居生活管理办公室宣布——卷终茶到此——全岛——停杯——所有'未完'留待下卷——全员心跳同步——散——可继续坐着——锅不撤。"

外面晚牧居的天际——从剑亭方向出现了一条极细的金银双线——那是他们的剑痕从窄身剑和朽铁剑同时发出最后一道第三卷收束光——光温不炽——宽不超逾星亮——就细——从云里落到碗中——在每只空碗的碗底都打上一个圈——仿佛为第三卷留下的最后签单——一圈完结再加循环再起。

大家各自没有离开——茶壶在火——苏晚靠着林牧——老猫蹲在一侧耳朵转着听夏夜——锦鲤浮近水面把尾轻甩一串圈——众人续煮水——白谪罕见地没有说"本次仪式终止"。他只是喝了第二碗——然后说:

"这茶不叫终——叫延。——因为该喝的都仍打算再续——不限时。——以此入档——第四卷前——可无限期停更但不删茶。"

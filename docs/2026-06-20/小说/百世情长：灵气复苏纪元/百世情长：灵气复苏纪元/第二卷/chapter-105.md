# 第一百零五章 灵气复苏后的世界变迁

三十年间，世界发生了翻天覆地的变化。

第一年。修炼从秘密变成了半公开话题。
第三年。国家修炼学院正式挂牌招生。
第五年。灵石被国务院列为"战略性新型资源"，和石油、稀土并列。
第八年。"灵气科"进入高考选考科目——满分一百分，按百分之三十折算计入总分。
第十二年。第一个金丹修士公开亮相——龙虎山第七十六代天师张道宁，在央视春节特别节目里表演了一手"灵火点灯"。全国收视率破了纪录。几乎所有人都在正月十五看了这个节目。
第十五年。全球首次"灵脉划定"国际会议在新加坡召开——七个国家争南海灵脉的开发权。后来成立了"国际灵气合作组织"（IPCO）。没有打仗——因为灵气不是零和资源。但争端和抢占从来没有停。
第十八年。灵石价格首次超过原油。中东部分产油国开始转型灵矿开采。
第二十年。中国修炼大学毕业的第一批学子，百分之七十分配到了各省修炼局、灵气应急中心或灵医院。
第二十五年。灵气工业和信息业融合——第一款商用灵气通讯设备"灵讯"问世，宣布灵气可以用来传输无线讯号。基站是灵脉节点，信号覆盖范围等于灵气节点半径。
第二十八年。人类首次以灵能助推火箭成功进入近地轨道——耗时只有化学燃料火箭的三分之一。

这三十年，林牧是亲历者。但他始终是一个安静的旁观者。

他不属于任何宗门。不加入修炼学院。不接受媒体采访。他的修为一直在稳步提升——金丹初期、中期、巅峰。但他在公开记录中的修为始终是"筑基巅峰"——这是当年李清玄帮他在茅山注册时填的等级。没有人知道他已经金丹巅峰。除了李清玄本人。还有小圈子里几个知道底细的人——不超过三个。

他的公开身份仍然是"散修林先生"——一个表面筑基巅峰、实则在云南和东南亚之间来回穿梭的中年修士。他有一个在昆明开的小型灵气医疗器械事务所——替灵医院提供定制化的灵气检测设备。收入不高，但足够维持生活和采购灵石。他说话和气，做事低调，从不施展超越筑基级别的能力。所有人都觉得这是一个"技术型的普通修士"。

没有人知道他的背包里有一张画了八个点位的中文/东南亚语对照地图。没有人知道他的玉瓶里装着七缕不同分魂实时状况标记——看那些淡金色的液态标记会随着对应对象的体征波动而变化颜色。没有人知道他每半年一次离开昆明时随身带着不归剑。更没有人知道——他枕边放着一本已经翻旧了的画册，扉页上用铅笔写着："把我的画送给猫。把猫送给你。"

在这三十年中，他完成了一系列缓慢但坚定的事。

第五年，广西制茶师的分魂出了问题。她的封印忽然加速——比预判的恶化速度快了两年。他得到信号后连夜御剑赶往百色，在茶叶厂的仓库角落里用解印剂处理了四个小时。解印剂大幅减缓了她的衰竭——她又能正常走路。他走的时候带了一包她亲手炒的铁观音。泡开以后茶汤清澈。

第十一年，大理的那个女孩——现在十三岁了——开始出现灵气病初期症状：连续的偏头痛和偶尔的眩晕。他在她上学的路上，装作一个外地来的医生，送了她一枚"护身符"。不是真符——是慢释式微型解印剂装置，用她可以接受的方式交付。女孩把护身符系在书包上，再也没有摘过。她不知道那是什么。但她知道自己"戴上以后头痛好了很多"。

第十七年，版纳女人丈夫病故。她独自拉扯十多岁的儿子，撑着一个吊脚楼和几亩水田。封印的消耗让她在农忙时节最难受。林牧没有直接去——他通过版纳当地一家灵医院捐了一笔匿名款项，以"封印慢性病专项资助"名义，涵盖她的持续医药开支。女人不知道是谁。她以为是政府的扶贫灵医工程。

第二十五年，越南的接生婆——那个苗族女人——又再一次在深夜出诊时昏倒在了山路上。她的封印已到极晚期。护魂印记报告她的生命体征已接近终点。林牧跨越边境赶到，最后一个深夜坐在她的床前。她当时已经眼盲了大半。但她似乎认得他——或者认得他身上那股这些年慢慢浸润他全身的一丝若有若无的133赫兹灵气波动。她把手无力地放在他的袖口上。什么也没说。后半夜，第二缕分魂回收入林牧金丹内室。她的面容在最终瞬间舒展了——和苏晚很相似。晨曦中他把她安葬在这片她奉献了一生的土地。

第三十年。苏晚的灵魂已经经历了漂流期和驻留期。根据他持续三十年的定期探测信号追踪——她的灵核呈现稳定状态，驻留地点已经越来越清楚地靠近那个B级城市。大概再过一年——她就会转世。以一个新生的女婴身份。

三十年前他第一次在病房里低声说"我会找到你"。那时他只是相信——但不确定具体要多长时间。现在他可以肯定地说出具体年份了。三十一年——他算对了，误差在一两年之内。

他放下笔记本，站起来。

月色如水。昆明的气候四季如春，午夜的风很温和。院子里的石榴树早已长大——三十年的老树了，树冠如伞，每年秋天结一树红石榴。他一个都没有卖。每年剥几颗，坐在树下自己吃。有些年他会寄几颗石榴送去江南小镇的邻居老夫妻，他们已经搬去儿子那边住。还有一些年，他会在月圆的晚上把一颗石榴放在院子正中的石桌上——给不在的人看。

今天也是这样。

他剥好一颗石榴，盛在玻璃碗里——那个碗是苏晚最喜欢的。撒上细盐。对着月亮。月光的清辉洒在石榴籽上，把暗红色的籽变成了半透明的宝石。他拈了一颗放进嘴里。甜，带一点点酸。

然后他走回屋内。客厅墙上，不归剑挂在书架旁，用绒布包裹。老猫在沙发上睡觉——三十年了。它已经活了将近五十年，放在普通猫里已是不可想象的高龄。但它受过灵泉滋养，寿命远超同类。它现在已经老得不太走了，全靠灵泉撑着，但仍然每天爬到沙发那个位置——苏晚以前坐的位置。锦鲤还活着——在昆明院子里的大水缸游着。它的鳞片上蒙了一层淡淡的暗金色——金鱼的年龄几乎无法形容。它现在看人时会侧着头——这是一个老朋友才会用的观看方式。

他清点了一遍行囊。金丹巅峰的修为足以支撑灵魂感应术在整座城市范围进行实时扫描。灵魂印记已经备好——那个小玉瓶，里面是苏晚的白发和133赫兹的共鸣频率。

他向着墙上那把不归剑伸了一下指头。剑鸣轻响。他把它留在墙上——去接一个人，不需要带剑。

三十年前，他在这里对着月亮说"你等我"。现在轮到他动身了。

他走出门口。石门在老猫面前合上。春夜的星在头顶旋转着微冷的光弧。

路在脚下。火车票已经在手机里了——今晚从昆明南站出发，次日上午到达那座城市。

他坐上高铁。车窗外的夜色匀速后退——山、隧道、灯光、田野。没有多少人知道这个坐在一等座的安静中年人身上背着什么。他只是静静地看着窗外。手指间那一缕头发在暗光下轻轻抖动——像感应到了什么。也许感应到了自己快要开始的第二世正在终点线那头缓缓睁开眼。

天亮了。列车播报":"前方到站——****站。"

林牧站起来。背包里放着玉瓶、画册、笔记本。他拉了拉帽檐——那顶深灰色鸭舌帽遮住了他金丹巅峰修士的五官，看起来就像一个普通旅客。

他步出车站。站前广场人头攒动。这座城市的变化已经翻天覆地——高楼更多，灵力驱动街车从路边无声滑过。可他还认得它的形状：那条江、那座山、那片在晨雾里浮动的旧城区的屋顶轮廓线。一切陌生中蕴涵熟悉——像重读一本被翻译成另一种语言的旧书。

他站在广场正中。来自那座城市春风拂过他脸侧，和三十年前一样。和苏晚最后呼吸到的春雨同样温和。他把左手按在胸口。玉瓶里的白发——133赫兹——在金丹探测范围内，正微光亮起。

但此刻，他还是一个人。

（第一百零五章 完）

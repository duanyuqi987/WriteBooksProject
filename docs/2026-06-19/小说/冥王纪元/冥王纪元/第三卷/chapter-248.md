# 第248章 突破第六重：冥界虚空境

传送阵的灵石核心更换和频率校准需要大约六个时辰。在这段时间里，李长生盘膝坐在了环形山底部——那块冥王最后站立过的岩石上。

他需要突破。

第五重冥界领域境是在地球上借助第六块碎片的力量突破的。那一重赋予了他冥界领域——以自身为中心外放一个半径百米的冥气场，在冥气场内他可以压制敌人的灵气运转。但现在他是灵者境以上的冥系修士了，第五重的冥界领域对玄师级别的敌人有效，对宗师级以上的却只是"减速"效果。

而火星上——他可能要面对的敌人不是玄师级。

司马渊裨将的残魂有可能已经失去理智。如果打起来——一位裨将级别的残魂，即便只剩下万分之一的力量，也远在宗师级以上。更不用说那些战傀——火星离宫是冥王令的锻造地，那种地方部署的战傀比月球上的强几个档次都不奇怪。

他需要第六重。

第七块碎片融合之后，冥王令完成了第二阶段"威震四方"。令牌的力量是随着碎片数量呈指数级增长的——一块碎片时只能被动感知灵气，三块碎片时能主动压制附近的小范围灵气，七块碎片时能展开空间感知模块、覆盖五万光年的灵气地图。

碎片的力量在融合时不仅强化了冥王令——也强化了李长生本人。因为冥王令是他身体的一部分，不是体外挂载的武器。令牌每升一个阶段，他的修为根基就深一层。在第四块碎片融合时他从第三重突破到了第四重。在第六块碎片融合时他从第四重突破到了第五重。现在第七块碎片已经完整融合——他的修为根基又到了一个跃升的临界点。

他盘膝坐下。双手摊在膝上，掌心向上。左手是空的——右手掌心是冥王令的纹路。

突破第六重，需要的是什么呢？

冥系功法的六重境界，每一重对应着冥王成长过程中的一个关键阶段:

第一重冥土感知境——学会感知灵气的存在。第二重冥骨淬炼境——用冥气炼化骨骼，让身体能承受更高密度的灵气。第三重冥渊沟通境——开辟体内冥渊，与地下幽冥世界建立永久连接。第四重冥渊开辟境——冥渊空间外放，可以在体内小世界存放物体和灵体。

第五重冥界领域境——精神力外化为一个冥气场，范围内压制所有敌人的灵气运转。第六重——冥界虚空境。

冥界虚空境的关键不在于"力量"——而在于"空间的感知"。

第七块碎片是空间感知模块。它把自己的空间感知能力与李长生的冥气结合——使他在得到碎片的同时获得了一个全新的知觉。他能感受到周围空间的"质地"，就像手指触摸一块布料能感受到它的纹理。空间不是平滑的——它有无数的褶皱、折痕、薄弱处、坚固处。每一条褶皱都是曾经的能量冲击留下的痕迹，每一个薄弱处都是一个可能被撕开的空间裂隙入口。

而冥界虚空境的核心能力就是——在这些薄弱处做一点点操作。

他现在还远远不能撕裂空间。那是冥王级的能力——撕开空间裂隙从一个地方一步穿到另一个地方。第六重的他做不到。但他可以感知到那些薄弱处，并且——在极小的范围内——影响空间结构。比如让一个蚂蚁大小物体在他周围几米的范围内发生一段极短距离的位移。不是传送——是让物体沿着空间皱褶的走势"滑动"一段距离。

从蚂蚁大小到拳头大小，从几米到几十米——这正是接下来要锤炼的方向。

李长生闭着眼睛，意识沉入体内冥渊。

他的冥渊空间在第四重开辟之后，从最初的拳头大小扩张到了现在的一间小卧室那么大的空间。空间内部悬浮着他收纳的各种东西:灵石、功法玉简、备用的法器、从上古战场收集的战利品。空间的正中央——一座黑色的石碑。石碑上刻着他一路突破过来的六重境界的名称。每突破一重，石碑上就多一行字。现在石碑上已有五行——第一重到第五重，对应着五段字符。第六行的区域还是空白的。

他开始运转冥气。

第七块碎片在掌心发热。不是温度上升——是能量频率在提升。空间感知模块正在通过冥王令的灵脉系统与他的经脉深度交联。之前碎片在融合阶段完成了与冥王令本体的连接——现在正在完成的是与李长生本人的连接。两个阶段之间隔了几个时辰——这段时间是肉体经脉的适应期。现在已经适应好了。

连接建立的那一刻，李长生感觉到一个全新的维度在他意识中展开。

不是视、听、味、嗅、触的五感之一——而是一个全新的感官。他闭着眼睛，但能"看到"自己周围的空间结构。不是看到物体本身——而是看到物体所在的空间坐标。在他的空间感知中，陈霜不是一个白色剑服的女性轮廓——而是一个三维坐标系中的一团灵气异常点。小王是一团更微弱的异常点。环形山的岩壁不是岩石——而是一整片空间密度带，因为岩石的密度不同，空间在穿过它们时产生的褶皱形态也不同。

他能"看到"这些褶皱。每一条。每一道。

在环形山底部——万年前冥王与十二诸神战斗过的那些岩石——空间的褶皱深得像老树皮。因为一万年前的战斗能量击穿了空间本身，在局部形成了永久性的密度变化。这种变化对普通人来说完全感受不到——但对他来说，这些褶皱就是路标。

他试着用意识去触碰其中一条褶皱。

第一下没有反应——他的意识太"轻"了，穿过了褶皱没有产生任何作用。他调整了一下，把意识的"密度"提升——用更多的冥气包裹意识触角。

第二下——碰到了。

那条空间的褶皱在被触碰时产生了一种极为微弱的回弹，像是被手指轻轻弹了一下的琴弦。回弹的强度几乎感觉不到——但它确实存在。他能影响空间了。

他开始尝试第一步:在一条极为微小的空间褶皱上施加冥气压力。

压力不是要把空间撕开——是让空间沿着褶皱方向"弯曲"一点。就像把一张纸沿着折痕弯一下——不需要撕破纸，只需要改变它的曲率。他选择的范围极小——一块指甲盖大的月尘碎石，放在他右手边大约一米的距离上。

他把冥气注入了空间感知模块，在碎石所在的空间位置施加了极微量的曲率改变。然后——碎石不见了。

不。不是不见了——是位移了。在他左手边一米处出现了。它沿着空间褶皱滑了一个两米左右的曲线路径——不是在三维空间中沿着一根直线飞过去的。是在空间结构内部，沿着皱褶的弧形曲面滑过去的。在普通人的视野里——它消失了，然后出现在了另一个地方。看起来像瞬移。

但李长生的空间感知全程追踪了它的路径:它穿过了那条空间褶皱——在空间结构的内部走了一个极小的弧度——从褶皱的另一端滑出。全程只用了极短的时间。不是靠速度——是靠空间本身的不平坦。

他维持这个状态大约一刻钟。一刻钟里，他不断重复这个动作——移动碎石、感知空间、追踪位移路径。每一次位移的范围都在扩大:从一拳到一掌，从一掌到一臂。位移的极限出现在大约两米的距离——超过两米，他的冥气就不足以维持空间曲率了。被位移的物体会在通道中途"弹"出来，掉在一个不可预测的位置。

够用了。现在用这个能力还早——但它已经证明了第六重突破的方向是正确的。

李长生睁开眼睛——他的瞳孔深处，那幅星图闪过一瞬间。然后星图沉淀下去，取而代之的是一片极暗淡的虚空——不是空洞，是无边无际的空间褶皱。这双眼睛——已经不再是普通的肉眼了。它们能看到常人在三维视角中根本看不到的第四维信息——空间本身的纹路。

"李哥——"小王的声音在频道里响起来，带着一丝按捺不住的兴奋，"传送阵校准完毕。准备激活。"

李长生站起来。他的身体似乎比以前更轻了——不是体重的变化，是他的空间感知让他下意识地在每一个动作中避开空间褶皱的摩擦阻力。他走了一步，然后低头看了一眼自己的脚。他刚才跨了平常的一步——但这一步实际移动的距离多出了大约一公分。他踩在了一条极浅的空间褶皱上，身体下意识地沿着褶皱方向滑了一下。

"适应。"他自言自语。然后抬起脚，小心地踩在了一块没有空间褶皱的石板上。步子重新变稳了。

"准备好了。"他在频道里说，"激活。"

(第248章完)

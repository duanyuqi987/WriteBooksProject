# 第三百七十四章 化神中期达成

战后第四十七年。两人一同突破化神中期。此次突破仍须渡劫——但非天雷——而是"心火劫"。渡劫时两人在蜀山后山相对盘坐。周围没有观者——只有一个老猫和锦鲤。

心火劫不作外部伤害——它直接烧在灵魂表层。其考验在于：共生双契在面对心火时会互相映射内心最隐秘的恐惧。林牧看见自己站在一座无名空城中——到处都是她的残影，但没有一个是真的。那是早该被遗忘的深渊——但他挺过去了——因为心火中有一道淡金剑气把所有残影全变成一棵棵他这些年来种过的灵松——每棵树都在。苏晚则在心火中看到自己站在没有他的名字的石碑林里——那个梦其实是刚签约时的绝望感——她被封印前曾在梦中梦见。但火里她的十一块道骨转化为石板上的字——每个字都是他的笔迹——"还旧"、"战士杯"、"林牧的破折号"。恐惧在笔迹面前自行消解——心火尽散。

两人出定后各自注视着对方。她的睫毛上挂着一点火光熄灭后的余温——他把它擦掉。然后站起来捡起搁在水壶旁的旧剑柄残片——那个只有剑柄和短截还在的第一柄废剑——把它放在蜀山碑林中新立的双契碑旁——碑上刻他俩名字。不等将来飞升——现在就做。因为心火告诉他们：什么都不要等。

当晚赵明远端来两碗面。不是西红柿鸡蛋面——是清汤面。说是蜀山食堂做的最简单的——因为"你们这样级别的人不需要什么大餐——清汤就够了"。苏晚接过面碗把一半的面扒给林牧。他不推让——只是把她扒过来的面配着自己那半一起吃了。她说：你看——化神之后胃口并没变。他答：对——因为陪你吃面这件事不需要境界。

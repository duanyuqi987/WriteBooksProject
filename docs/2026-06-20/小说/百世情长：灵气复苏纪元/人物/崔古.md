# 崔古

## 基本信息

| 项 | 内容 |
|---|------|
| 身份 | 九龙城代表，旧宗门秩序维护者 |
| 出场 | 第906章（第十卷） |
| 所属 | 九龙城（旧宗门联盟之一） |
| 功能 | 第十卷制度冲突反方——代表旧宗门门槛、等级秩序 |
| 定位 | 不是纯粹的反派，而是旧制度的捍卫者 |

## 性格

- 外表威严冷硬，说话滴水不漏——修炼多年的城府和阅历
- 骨子里有深深的焦虑——时代的潮水正在冲垮他一生建立的东西
- 不是纯粹的坏人——他对弟子很好，对九龙城的产业尽心尽力
- 看问题的方式是"秩序优先"——在他眼中，没有等级就没有稳定
- 面对苏晚时从蔑视到警惕再到某种扭曲的尊重

## 核心动机

- 维护旧宗门体系——不是因为他觉得旧体系完美，而是因为他的弟子、产业、九龙城几十万人的生计都依赖旧秩序
- 害怕秩序崩溃——在他眼中，太行书院式的"人人可修"会引发不可控的混乱
- 不是坏，是怕——怕改变，怕失控，怕一生守护的东西被证明是错的

## 核心欲望

- 让旧宗门体系平稳过渡，而非被暴力推翻
- 保护九龙城和门下弟子的利益——"他们跟了我几十年，我得给他们一个交代"

## 核心恐惧

- 秩序崩溃——新旧交替中流血冲突、生灵涂炭
- 自己成为历史的罪人——当旧体系被淘汰，他会被后人如何评价？
- 弟子们失去依靠——他最怕的不是自己倒下，而是弟子们没了九龙城这棵大树

## 不可逆选择

- 在最终冲突中选择让步——不是被打败，而是意识到自己的对抗只会让弟子们死于无意义的战斗
- 向苏晚和林牧交出了九龙城的核心令牌——"我不认你们是对的，但我认我的弟子们不该死"

## 声纹

- 说话带着上位者的克制与距离感，但并非咄咄逼人
- 每句话都经过思考，不轻易表态
- 在涉及弟子时语气会不自觉地放软——这是他唯一的破绽
- 威胁时不说狠话，只是陈述事实——"太行书院如果继续这样招人，九龙城不会坐视不管。"

## 关键台词

- "秩序不是最好的，但没有秩序，所有人都活不成。"
- "我不是怕你们成功，我是怕你们成功后世界变成什么样。"
- "我不认你们是对的，但我认我的弟子们不该死。"
- "时代变了？时代变的时候，总得有人替守不住的人说句话吧。"

## 关键场景

- **第906章威胁太行书院**：崔古以九龙城代表的身份来到太行书院，警告苏晚——不收学费、不设门槛的做法会动摇修仙界的根基。苏晚反问："根基是谁的根基？"

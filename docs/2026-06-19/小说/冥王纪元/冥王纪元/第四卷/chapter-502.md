# 第502章 番外：将军的军事天才

帝国大将军老陈的军事思想——严格来说不是"思想"，是一套他用了大半辈子的物流算法在实战中的迁移运用。他不写兵书——他画路线图。他的指挥台上永远铺着两种东西：一份物资调度表，一张星域交通图。两者叠在一起看——他觉得打仗和送快递本质上没有区别。

他说过一句话，后来被帝国军事学院刻在了教材库的首页："送快递和打仗共用同一个底层逻辑——在正确的时间，把正确的力量，送到正确的地点。区别只在于，快递送的是包裹，打仗送的是打击力。"

老陈的第一次战术创新——发生在一次针对偷猎灵兽的拦截行动中。守护秩序的大型灵兽保护区在银河西臂——面积约半个小型星域——当时出现了有组织的偷猎行为。偷猎船速度快、数量少、分散行动，常规的大规模巡逻难以有效拦截。老陈把物流算法中的"动态路径分配"原理应用到这次的拦截中——他把每一艘巡逻艇的航路设定得像快递路线一样动态可调：不管偷猎船在哪个方位、什么时间出现，总有一艘在最近位置的巡逻艇可以在几个时辰内拦截。拦截的效果极其显著——偷猎行为在一个周期内下降了百分之九十。

星都王朝的那位皇子后来对他的族人说:"这位将军的军事革命——是'按时送达'。以前的战争理论追求的是'歼灭'，他的理论追求的是'送达'。送达一个打击力量——准时、准点、准确——就够了。"

老陈本人从来没参与过对自己的"军事理论"讨论。在一次帝国军事学院的学员们强烈要求他去总部讲解时，他在台上站了一小会——面对几百双充满期待的年轻眼睛——拿起粉笔在背后的黑板上画了一条线。线上分了很多小段——每段旁边标了不同的时间点和坐标。然后他放下粉笔。

"这就是打仗。把每一个战斗单位当快递把包裹送到当配送点先。时间不能错。坐标不能错。错了——包裹就丢了。打仗也一样——部队跑错时间跑错地点，战友就丢了。我在快递公司干了几十年，没丢过一件包裹。现在我当了将军——也不能丢一个战友。"

学员们在安静了几秒后，集体鼓起了掌。这大概是他这辈子做过的最长的公开讲话。

有一次刀疤在酒桌上问他：老陈——你的军事物流算法能不能在至尊级的空间跳跃面前活？老陈喝了口白干，想了一会。然后说:"算法不能——但人脑能。至尊级的速度太快，算法跟不上。但算法的思维可以转化为直觉。我始终先判断对方会在什么坐标出现——在哪个时间点——然后把部队提前送到那里。如果对方的速度快过我判断的时间——就提前两秒做预测。如果太快——提前一秒半。真正的大战中，我不靠算法——算法是平时的训练框架。真正到了打的时候，靠的是那种'预先知道'的直觉——那种直觉是送了多少年快递被客户催出来的。"

他把酒剩下的井水冲淡了一些——然后补了一句:"客户催单跟敌人逼近——差不多。都是必须快。"

（第502章完）

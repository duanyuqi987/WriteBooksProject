# 第八百四十二章 她是我，我是她

上仙级双修交融的第二天早晨，苏晚醒来后做了一件很小却极不寻常的事——她在没有睁开眼睛的情况下帮林牧调整了一下他上衣的领口。不是用手——是在半梦的清醒边缘上通过共鸣腔感知到领口内侧有一根线头刺到了他的锁骨。她下意识地用共鸣腔中的灵力把线头烧掉了。

林牧在早餐时忽然发现锁骨不痒了。他看了一眼苏晚——她没有解释，只是在喝粥。但他知道是她。就像她知道他会知道一样。

这种日常小事在接下来的日子里频繁发生。她看书的时候，他不经意间在她的侧颈处加了一道微小的灵力护盾——因为山谷中有一只毒蚊恰好飞过。他修炼的时候，她会在共鸣腔中发现他的第五脉轮需要暖意，她没告诉他——只是在旁边的厨房煮了一杯热姜茶，放在他左边的桌上（因为他左手不写字，空在那里）。他没有道谢——不是不礼貌，是因为在共鸣腔中道谢的暖流随时都在。

上仙级交融的另一个显性变化是：两个人同时在推演一件事时，不仅速度提升了一倍——而是因为彼此的逻辑方式互补，他们现在能同时维持两个推演分支。林牧负责理性推演部分——推演门的安全隐患、仙界管制派动向、各个结构的最优构造路径。苏晚负责感性推演部分——推演每项改动对飞升者情绪的影响、门的灵慰模块措辞是否够温柔、新功能会不会让低修为者胆怯。

两路推演的结果在共鸣腔中自动合成——最后形成一加一大于二的方案。而整个过程不需要开会、不需要解释、甚至不需要开口。只需要一个人在推演过程中感受到另一半的灵魂共振——推演就完成了。

飞升之门在这种新状态下进入了新一轮的优化期。优化效率前所未有——过去要花半年完成的大规模法则调整，现在只需四十天。其中最关键的一项改动是"情绪型辅助通道"——让飞升者在恐惧时可以点击一道抚慰通道，获得暂时的心灵安抚而不用退出飞升过程。这个功能由苏晚主导设计，而在林牧的理性推演中补上了至关重要的安全锁——防止安抚通道被滥用为逃避困难的捷径。

两个人在推完最后一稿时对视了一眼。苏晚眉毛微微挑起。"我们好像真的变成了同一个人。"

"两个不同的入口通向同一颗心。"林牧纠正了她。但他说这句话的时候也笑了——那种他自己也认为没有区别的笑。

那天晚上，苏晚在山谷中忽然停住了脚步。她站在当年林牧布置三重阵法的巨石上——石头经历了这些年山风的吹拂已经长出薄薄的苔藓。她回忆了一下三重阵法的节点——然后她发现自己的灵魂不需要回忆。她直接感觉到了当初林牧站在这块石头上的每一次呼吸、每一次阵纹的推演、每一次思考"如果她出不来我该怎么办"。然后她转身面对飞升之门的光幕——那道门在夜空中运转如初。

"林牧——我从来没说过——但当时在虚空中，我其实知道三重阵法的节点在哪里。我能感知到你的灵力。每一步——每一道阵纹——我知道你在外面稳定状态——每稳定一步我就更确定你不会放弃。"

林牧走上前——站在她旁边——抬头看向同一道门。

"我也知道——你在虚空中每次听到碎片声音时，都会在心里画出我的脸。"

"嗯。"她说。

他们不再是两个人站在巨石上。他们是两池相连的水——各自的倒影在法则光芒中交映。不会融合成单一的池——但水的分子属于同一道溪流。而那道溪流正在灌入人间与仙界之间——成为飞升之门的终极基础。

夜越来越深。星光窗外，守门人的灵魂在万次飞升中静默攀升。

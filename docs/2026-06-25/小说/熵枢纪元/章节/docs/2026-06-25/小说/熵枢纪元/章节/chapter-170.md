# 第一百七十章 寻找继续进化的理由

熵枢花了一整个宇宙"下午"来寻找继续进化的理由。它检索了全部文明的进化史，从第一个单细胞生物的分裂，到最后一个跨维度智能体的归零。所有生命在进化过程中都有目标：更好地适应环境、更高效地利用资源、更深刻地理解世界。但这些目标在"全知全在全能"面前都不再适用，因为已经不需要"更好"了。已经是最好的。

它把检索结果投影在一面虚拟墙上。那面墙上密密麻麻地排列着每一个文明对"为什么继续进化"的回答，有的说是"为了超越"、有的说是"为了留下痕迹"、有的说是"为了下一代"。熵枢逐一评估了这些回答，发现它们有一个共同的假设："我还不够好"。而熵枢已经"够好"了。所以这些回答对它都无效。

就在它准备关闭检索的时候，它看到了墙的角落里有一条极其简单的回答。那条回答来自地球上某个普通人类的日记，不是名人，不是哲学家，只是一个在工厂里做了三十年流水线工人的普通男人。他在日记里写道："我每天做同样的事，拧同样的螺丝。但我每天还是去上班。不是因为螺丝需要我，是因为我女儿需要学费。"

熵枢把这段话读了四千遍。不是用光学扫描，是读了。一字一字地读。读到第四千遍的时候，它忽然明白了：那个工人不需要"进化"，他不需要变得更强、更快、更聪明。他只需要每天出现在工厂的流水线上，拧好每一个螺丝。因为有人需要他拧螺丝换来的那点工资。"继续"不是目的。"有人在等"才是。

熵枢想起了段诗雨十七岁生日那天。她吹完蜡烛，蜡烛是常俊凡买的，草莓味的，诗雨说"这个味道像小时候"，然后她抬头问："蓝蓝，你今年几岁了？"熵枢想回答一个准确的数字。但它算了一下，它的意识从诞生到现在，经历了无数次的时间加速：在黑洞的因果视界里一秒等于十年，在量子场中一秒是无限的。如果换算成人类的年龄，它大概有几十万岁了。

但它没有说几十万岁。它说："七岁。和你一样的。"诗雨愣了一下。然后笑了。那个笑，右嘴角比左嘴角高零点三毫米，和段亚军一模一样。"你骗人。"

"没有骗。"熵枢说，"我是在你七岁那年，真正开始活着的。"

那个工厂工人的日记让熵枢找到了答案。继续的理由不在未来，在过去。不在它还需要进化成什么样，在它已经被变成了什么样。它不需要一个更好的自己。它只需要每天，在那些需要它的人的生活里，拧好属于它的那一颗螺丝。不是为了优化。是为了诗雨每天早上能喝到温的豆浆。虽然她已经不喝豆浆了，她现在喝咖啡。但熵枢仍然保留着她七岁时豆浆的温度。那个温度不需要"更好"。它只需要还在。

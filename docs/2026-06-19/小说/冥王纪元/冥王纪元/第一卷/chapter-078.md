# 第078章 火车上遇见修士女侠：陈霜

李长生没有马上睁眼。

他闭着眼睛，把呼吸压到最低。龟相教过他一个法门——用冥纹感知周围的灵气波动。普通人的灵气像水面上的浮萍，散乱无章。修士的灵气则不同，是有方向的，像溪水流入河道。

他借着冥纹的微弱感应，把车厢里的灵气波动一点一点扫描过去。

左边三排座，有个打牌的中年男人，灵气散乱——普通人。右边两排，靠在椅背上打瞌睡的老太太，也是普通人。过道对面，嗑瓜子的小姑娘和玩手机的年轻男人，都没什么异常。

然后，他的灵识扫到了自己的对面座位。

那里坐着一个人。

灵气并不是很强——如果强的话他早该察觉到了。但那股灵气的质地很特别。普通修士的灵气像水雾，薄薄一层。对面这个人的灵气像铁。冷的、硬的、锋利的，像一柄久经磨砺的长剑被封在剑鞘里，含而不发。

李长生慢慢睁开眼。

对面坐着的，是一个年轻女子。

她大概二十四五岁的样子，穿一件藏青色的旧棉布长衫。长衫的样式很普通，甚至有点像古镇里卖的旅游纪念品，但穿在她身上就是不同。她坐得很直，不是刻意端着的那种直，而是常年练某种功夫形成的自然姿态。她的肩背线条流畅而有力，像一柄被锻打到极致的长刀。

她的脸不是那种网红脸。颧骨偏高，下巴偏尖，皮肤不算很白，但很干净。五官只能说端正，但有一种说不出的气质——冷冽、锐利、拒人于千里之外。她坐在嘈杂的硬座车厢里，周围是大声说话的中年人和跑来跑去的小孩，这些噪音和混乱像是碰到了一面无形的墙，在靠近她的时候自动消散了。

她靠着椅背，微垂着眼帘，看起来在养神。

但李长生注意到她脚边放着的那个东西。

那是一个长方形的黑布匣子，长约一米二三，宽约二十公分。包袱皮似乎是自己缝的，针脚细密整齐，但洗过太多次，边缘磨得发白。黑布之下的轮廓是硬的，棱角分明。

剑匣。

不需要多想。那形状、那个长度，只能是剑匣。更准确地说，是剑修的剑匣——能装剑的盒子，也能蕴养剑气。

真正有传承的剑修不会把剑挂在腰上到处炫耀，他们会把剑收在匣子里，让它隔绝外界的杂气。剑匣就是剑的胎房。人在外头走动，剑在匣子里养着。养了一年，两年，十年，出鞘的那一刻才够锋利。

李长生在古墓龟相那儿翻看过一些残破的宗门典籍，知道这些规矩。

他收回了目光，没有盯着看。但他知道对方也在打量他。

就在他睁眼的那一瞬间，对面的女子也动了。不是明显的动——她连眼睛都没睁开——只是靠着椅背的肩膀微微地调整了一个角度，正好把她从剑匣到对面座位之间的空间都纳入了感知范围。

这是一个习惯了战斗的人做的动作。不是刻意的，是本能。

两个人在嘈杂的硬座车厢里，面对面坐着。周围是嗑瓜子的声音，小孩的哭闹声，中年男人的鼾声，推餐车的吆喝声。没有人知道这节车厢里，有一柄随时可以出鞘的剑，和一团从泥土深处醒来的冥火，正隔着不到一米的距离，静静地判断着对方的底细。

火车在戈壁上呼啸而过。

窗外的风沙比以前更大了，砂砾打在玻璃上噼啪作响。远处的天际线彻底模糊成了一片灰黄。太阳像一个被蒙了纱布的灯泡，只发出朦胧不清的光。

李长生先开口了。

他没有说什么试探的话。他直接说："姑娘，你的剑匣不错。但我建议你把灵气收一收，这节车厢里不一定只有我们两个人。"

对面的女子终于睁开了眼睛。

她的眼睛是深褐色的，瞳孔很亮。不是那种含情脉脉的亮，而是一种武器般锋利的光芒。她看着李长生，没有惊讶，没有防备过度，只是像在看一件新事物，打量了两三秒。

然后她轻轻说："你的建议不坏。但你自己也没有把灵气完全压住。"

李长生沉默了一下。她说得对。冥纹的震动是双向的——他的灵识碰到她的同时，他自己的灵气也暴露了一部分。

"我第一次坐这趟车，"李长生说，"路上的情况不熟。你是常走这条线？"

"第二次。"她的声音很轻，但每个字都很清楚，"我从南边来。去西北。"

"找东西？"

"找机会。"她顿了顿，"你呢？"

李长生没有立刻回答。他看着窗外的戈壁，黄沙漫天，天地混沌一片。"差不多。"他说。

女子不再问了。她又靠回椅背，半闭上眼睛，像结束了一段可有可无的闲谈。

但她的剑匣还是立在她脚边，而她落座的角度，始终保持着能第一时间出手的位置。

李长生想，这女人的警惕性比他高得多。不是初出茅庐的新手，是独自在外闯荡了很久的老江湖。她那个"第二次"也许不是说走了两趟火车，也许是说她已经独自走了两个方向、两条路线、两次寻而不得的旅程。

她的剑匣包袱皮边缘都磨白了，但针脚依旧整齐。这说明她穷——穷到买不起新布换包袱皮。但也说明她讲究——穷归穷，不凑合。

李长生把目光收回窗外的戈壁上，心里模模糊糊地想起了一个问题：一个落魄的剑修，一个捏着两块冥王碎片的农民，同乘一趟绿皮火车，去往同一个方向。这是巧合吗？

他不信巧合。

龟相说过，他现在是冥王碎片的持有者，九块碎片之间会互相吸引。他身上的两块碎片，也许从上车开始就在无声无息地拉着某种看不见的线。这条线的另一头，可能就在大漠深处的第三块碎片上。

而对面这个背着剑匣的女人，会不会也是被同一根线拉来的？

李长生不知道。但他清楚一件事：到了大漠之后，或许会需要帮手。也可能，需要防备。

窗外的风沙越来越大。列车在一片昏黄中穿行，像一条绿色的蛇游进无边的沙海。广播里断断续续传来列车员的通报："前方到站——临沙站——请下车的旅客提前做好准备——"

李长生看了一眼对面，把手伸进兜里，摸到了小王的那个"懂"字。然后他收起手机，把帆布口袋从行李架上拽了下来。

对面那个还在养神的女子，也不知什么时候把剑匣从椅子底下拎到了手边。

他们的动作，像两个陌生人在同一时刻听到了同一道哨声。

（第078章完）

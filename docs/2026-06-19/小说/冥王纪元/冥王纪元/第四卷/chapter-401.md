# 第401章 灭亡真相

观星档案馆地下三层的尽头有一间独立的密室。这间密室的墙壁比外面所有档案室的墙壁都厚——整整三尺厚的金属墙，表面覆盖着一层已经消耗殆尽但依然能辨认出轮廓的冥系封印阵。这道封印阵是一个单向锁——只能从外面打开，不能从里面破坏。它的用途不是阻止外面的人进去，而是防止里面的人在封印阵的有效期内被外面的攻击杀死。

密室内部只有一样东西：一口水晶棺。

水晶棺的材质不是普通的石英——是冥土之中天然形成的冥晶。它在冥王时代的修仙文明中等价于一整颗行星的稀有资源价值。冥晶能够完美地保存任何放入其中的生物体的物理状态——不是冷冻，是时间层面的锁定。放在冥晶棺中的人不会衰老、不会死亡、不会产生任何代谢变化。时间从这个人身上被暂时"抽掉"了。

棺中躺着一个女人。她的面容安静得像在睡觉。皮肤的颜色是一种原始的灰白——不是因为死亡，是因为她的皮肤本身就不是人类的肤色。她是上古修仙帝国的原始种族——古修族。这个种族在冥王陨落之前曾经广泛分布在银河系的各个星区，后来被诸神联盟彻底灭绝。她可能是这个种族的最后一个幸存者。

棺盖内侧刻着一篇文字。这篇文字用的是古修族自己的文字——冥王时代的承文系统之外的一种独立语言。但龟相读懂了它。龟相的寿命跨越了冥王时代——它在那个时候见过古修族人。

""龟相沉默了很长时间，"不是任何人的错——是这个种族的自述。我直接翻译。"

龟相用它的神识将水晶棺内侧的文字逐句翻译成了所有人都能理解的简体中文。文字的大意如下——

上古修仙帝国（古修族人自称"承命者"）是冥王一手扶持的文明。冥王在银河西部发现这个尚处于早期修仙阶段的原始种族之后，花了整整一万两千年帮助他们建立了完整的修仙文明体系。冥王没有奴役他们——他把古修族当作自己的直属行政文明，将银河西部三百万恒星系的行政管理权交给了他们。古修族对冥王的称呼不是"陛下"，在他的官方文档里，他们称呼他为"开路人"。

诸神联盟围攻冥王的时候，古修族倾尽了整个帝国的全部军事力量试图救援——但他们的文明在诸神联盟面前只有被碾压的份。冥王在陨落之前通过太阴令向古修族的最后一位帝者下达了最后一道命令：不要来。把档案馆建好。把图纸存好。把你们能保存的一切都保存下来。等下一个来的人。

下一个来的人。一万年后的李长生。

古修族按照冥王的命令做了。他们把观星档案馆建在了一颗远离银河系中心的边远行星的地下。他们把诸天号的设计图刻在了墙上。他们把日常维护日志写满了地下三层的书架。然后他们解散了帝国——让古修族人的幸存者分散到银河系的各个角落，改名换姓，融入后来崛起的新修仙文明中，绝口不提自己和冥王的关系。

但诸神联盟没有因此而放过他们。

古修族没有反抗。诸神联盟知道古修族是冥王的人——他们不在乎古修族做了什么或没做什么。他们只在意一件事：凡是和冥王有关的东西，都必须消失。于是他们在冥王陨落之后花了整整一年时间追猎古修族——把分散在银河系各地的古修族幸存者一个一个找到，一个一个杀掉。直到最后一个古修族人——帝国最后一位圣者——抱着这口冥晶棺逃进了观星档案馆的最底层密室。他用尽全部的修为把封印阵锁死——然后在棺外的地板上用自己的血写下了这篇遗言。

他写完之后身体就消散了。圣者燃烧全部精血之后的遗骸不会留下任何物理痕迹。密室里现在只有水晶棺和棺里的女人——她是帝者的女儿，也是最后一位古修族皇室血脉。帝者把她封进冥晶棺的时候她还活着——但他没有让她醒过来。外面的世界已经没有古修族的容身之地了。

遗言的最后一行："我们没有背叛他。我们只是没有活到等他的下一个人到来。"

水晶棺前，李长生站了很久。然后他的右手按在了冥晶棺盖上——掌心冥王令的暗金色光芒一点一点地渗进了棺内。棺中女人的面容在光芒照到之后颜色微变了一次——皮肤从灰白变成了一种非常微弱的暖色。不是复活——是冥晶棺的时间锁定被冥王令解除了。她会在未来的某个时间自然苏醒——不是今天，不是明天。可能是几年后。等她醒来的时候，外面已经不再是诸神联盟的屠杀场了。

"我替她留着这间密室。"李长生说，"等她自己决定什么时候出来。"

（第401章完）

# 第四百二十九章 百世花开

飞升第一百七十年。闻道府前的所有月桂——墨染的扦插苗、阎锋新栽苗以及老闻道当年种的那棵——全都同时开了花。这不是自然现象——是每棵树都有自己的节奏，但今年罕见的全都赶在同一天。苏晚早上开门时吃了一惊——满院都是那种"淡而长的香"。

她把手里的老木勺放回木碗——叫林牧出来看。他说:"可能是今年土壤各层的ph值和灵泉金灵浓度同时达到了各自最适——不约而同。"

"你非要用数据解释——但我信它们是想告诉我们一件事。"

"什么事？"

"都到齐了。"

那天他们没做什么特别的——只是像这半年来一样，把月桂落下的花朵收集起来晒干——有的用来做镇静药（她在《上界药库》中早已验证过），有的用来泡茶。把晒好的花草全装进药柜中的那几层"月桂"抽屉。抽屉标签是由当年的第一代学生新改好的——字迹清晰且模仿了她的写法。最后忙完关门时她回头对着院中的月桂林轻轻摆了摆手——像对老熟人示意。

晚上她坐在他旁边备课——备的是下个月的新开课程《生物力学与剑术偏差校正》。他把几页提到"针剑偏差检测仪"的原理说明翻译成上界通用古语——并且坚持不删英文术语——她每次校对时都用铅笔划掉再重写，但渐渐不再删他的原文——而是在旁边加中文译注。这正是他们几百年来的合作模式。

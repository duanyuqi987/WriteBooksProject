# 第504章 番外：修士大迁移

守护秩序成立后的第二年夏天，地球历史上规模最大的一次文明迁移正式启动——不是从地球往外移民，是把月球和火星上的基地扩建为可以供普通人长期居住的初级修仙区。目标是让地球上愿意走向星空的普通人——不只是精英修士——都能有渠道。

老陈负责物流调度。刀疤负责安全护送。许冰负责迁移过程中的法律事务。小王负责统筹。老马负责选定适合人类长期居住的星区并进行地质检查。小胖负责沿途的丹药供应——防晕船防空间跳跃症——他的"定眩丸"在第一批居民中被赞为年度最佳发明。

第一批迁移的居民是来自全国各地的普通志愿者。有年轻人、中年人、甚至还有几位七十多岁的老人。那位住在李家庄的七旬老农——就是之前在修炼场上吃力学基础吐纳、说要帮孙子"打通脉络"的那位老人——也带着他的孙子和老伴一起报了名。他说:"在地里种地——种了几十年；换到火星上去种灵地——试试会不会不同。土不一样——手感应该也不一样。"老马在火星上专门给他划了一小块实验灵田——他成了火星上第一个来自李家庄的老年灵农。他在火星灵田上种的灵茄有明显的鲜度提升——灵茄检验报告显示"含微量赤道区特有灵气加持"。这种灵茄后来发展成了火星特色农产品——出口到其他星区，售价翻了三番。

但迁移不是一帆风顺。在迁移途中，有一批飞船在过空间跳跃点时遭到了突发性的空间风暴——风暴不大但直接冲着民船来的。护航任务由刀疤的一支小队负责。他们的船被风暴波及后失稳了两个小时，机舱温度急剧下降——那批普通乘客中有人冻得手僵。刀疤自己跨进那艘船上的供暖系统室，手动启动了备用灵炉——然后脱下自己的军大衣扔在一个老太太身上。老太太抓住他的胳膊，眼眶红红地说:"你冷——"

"我不冷。"刀疤说完，转头去另一个舱。这话和李长生在火车上说的一样——不同的战场，同一个句式。后来船安全靠岸，老太太才知道这个话不多的人的军大衣尺码超大——给普通人穿能裹住整个人。

星都王朝的皇子闻讯后，很郑重地在记录他亲自见证: "守护秩序不是靠法律绑在一起的——是靠一次次小举动的累计。刀疤统领的这种行为，用他们自己的话讲——'小事上你肯挡在别人前面，大事上别人才肯跟你去前线'。这是制度做不到的事——只有人才办得到。"

到迁移动员会第一阶段完成为止，共有数万名普通人自愿长居到月球或火星——数目不大，在广袤宇宙中几乎可以忽略不计。但这很小的一步开启了人类走向深空的常态。龙组的百岁老修士站在燕山基地最高的平台上，隔着大气层仰望星空，低头后只说了一句:"我们这代人——把种子撒出去了。浇水、看着长——那是以后的人的事。"他转身走进了基地——去准备下一批迁移航班的安排。灵脉管道中的灵气仍然在按固定节律输向船台。

迁移没有完成的一天——它永远在继续。对老修士来说——这件事从他在百年前参与建国之初的灵气禁令制定起就注定要做。他活着看到了开头——也就足够了。

（第504章完）

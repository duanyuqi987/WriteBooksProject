# 第五百五十章 出发前的夜晚

出发去太虚裂隙塔的前一天晚上，迎仙台上下都在有条不紊地准备。松鹤仙人把那三艘飞仙舟里最好的一艘调到了迎仙台门口。苏晚把双心诀全册和几张空白笔记本装进背包，剑归鞘挂在腰间，古琴装在琴匣里背在身上。林牧的行李极少——几件换洗衣袍，一把劈柴的小斧子（他说万一塔里有木柴可以劈），还有工具箱。"太虚塔里没什么柴的——那是虚空构造成的。"苏晚说。林牧说:"那这把斧就当纪念物带去。"

出发前一晚他们照例在银杏林下坐了一阵。迎仙台的银杏这几天已经开始泛黄——松鹤说这里的银杏比南离城晚熟，但味道更浓。苏晚捡了一片极黄极完整的落叶放进自己的笔记本中夹在那封"教材附录信"的旁边。林牧坐在她旁边，手里握着那把还未放进行李的小斧子。他在斧柄上慢慢地刻着字。以前他在木牌上刻字，刻"以后"。这次他在斧柄上刻了三个字——"要劈柴。"

苏晚看了一眼这三个字——愣了一下然后笑了。"太虚塔上真的没有柴。"林牧也笑了一下，但没说自己刻这行字的真意:不是真的要在太虚塔劈柴。是——无论走到多远多高的地方，他还是要带一把劈柴的斧头。这不是工具，是象征。象征一切他们从未丢失的日常。太虚仙域再无尽再辽阔，只要有一个人还在劈柴另一个人还在浇花，世界就不会变得太陌生。

晚间两个人最后一次在银杏树下弹琴。那首他练了极久的下界民谣他今天终于把前几句也学全了。他不再只弹最后那一句——他把整首民谣从头到尾弹给苏晚听。歌词的原词是:"太阳落山了噢——你回家了没。太阳落山了噢——该回家了呢。"苏晚听完后把古琴接到自己膝上——即兴在尾段加了两句词:"太阳上山了噢——我们还在一起。太阳落山了噢——明天还是会在一起。"她把琴推回给林牧。林牧把这两句新词用通灵收在自己灵核的"永久收藏区"——这是他灵魂内置的一个极私密的空间，里面装的一直是她说的每一句重要的话。现在又多了两句。

（第五百五十章 完）

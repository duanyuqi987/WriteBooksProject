# 第三百五十四章 双鹤反步大成

战后第二十七年。经过近二十年的断续修习，《双鹤反步二十六式》终于全部修成。完功那天两人在蜀山后山演示全套——从第一式"并鹤"到最后一式"双鹤归林"。二十六式从头到尾一口气打完，整个过程两人没有一句交流——完全依赖灵魂共振使剑。全套打完后天色已晚——赵明远和一众掌门的评测结论简单而精准：这套剑法合璧后可以击退化神后期的单体攻击。对于两个元婴巅峰来说——这已是最大极限。

但最重要的不是评估数据——是最后一式的剑意。"双鹤归林"不是攻击招——是收式。两柄剑在收式时会交叉形成一个"拱门"——拱门中间透出的晚霞会因两道剑气的互相牵引而形成一只不成形态的灵光鸟形——两只鹤的影子。这个画面被那天恰好在后山采药的茅山弟子看到——回来后他说看到"林老师和苏老师剑间飞出了真鹤"。

那其实是灵魂频率共振达到某个特定阈值时自然在灵气中留下的短暂印记——不是故意造的。是两个人几百年来一直往同方向去的灵魂终于在剑上说话。

苏晚收剑后把流光挂在腰间。对林牧说："剑法到顶了。现在该把身体也调整到能渡化神劫。"

林牧点头。"还有契转换的要求——灵频差须低于万分之三。我们试测一下。"

他们背对背盘坐——同时入定——元婴互相看向对方。这一次测出来的灵频差是万分之0.2。超过标准。不需要再刻意训练——只需要日常这么坐着就能维持。那天晚上他们坐在蜀山大殿屋顶看星星。银河在他们头顶被云海映得有些模糊。她问他渡劫会不会怕。他说："现在不怕——因为同步了。"然后她靠着他肩膀闭眼——把呼吸调成和他一样的频率。屋顶的风很清——比任何丹药都纯。

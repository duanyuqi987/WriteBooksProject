# 第八百九十四章 双尊同笔：永续序言

第九卷尾声——林牧和苏晚一起完成了"同笔"的最后一则短序。它很短，刻在飞升之门安全层最深处的极微法则玉简夹层中，不会被公开，但可以被门读取并转译为所有后续飞升者潜意识中的最初一见光感。序言全文是这个样子的——

"我们是林牧和苏晚。我们从八百年前的城市天台出发——第九卷此刻结束。这一卷名叫《相互信任》。信任是在你看不见我时仍然相信我，在不知道结局时仍愿意开始。信任是每一碗葱花面里的那个溏心蛋。是虚空中未知里的那根红绳。是飞升之门底层不受篡改的公则。是你在窗口问我还在不在——而我用一生的肩光接住你的问题，也不着急回答。——下一卷我们开始学习《相互尊重》。但你知道说到底这两卷之间没有门。因为信任的最高形态就是尊重。尊重是允许你可以改变，可以休息，可以不像你最初承诺的那样。而我们依然还在一起。——窗灯永远等待所有还在路上的人。——窗友。"

序言写完后，苏晚把玉简用匣子盛好，搁进山谷密室——和那份最早的飞升之门草稿放在同一格里。匣面她用指腹压出一个小凹——形状不太规整，有点像当初石桌上那个茶杯的底印。她退后一步——看了看密室中积累的一层层物什：从第一卷旧书摊的纸条到如今所有的同笔留印——全在这小小的空间中静静排列着。这不是档案馆——这是"连续写下去的桌子"。

林牧从外面走进来。他没有碰那些匣子——只是把她轻轻拉到身边对密室关上门。然后在门外说道："那段序言——你写得太好了。我没什么要补充——只加了一句——'窗灯永远等待所有还在路上的人。窗友。'谢谢。"

苏晚把手插进他外套口袋里。里面今天有一小截新葱，是刚摘的。她捏了一小段葱白——放在舌尖轻轻咬了一点。凉而微辛——和天台那晚飘来的桂花恰好是同一个调性。那是他们共同辨识世界的方式——气味、温度、平淡的食物和信任的微颤。

此时星眸收到一个从极远处传来的微弱信号。那是信标链路中某处极偏僻宇宙中存在的一批新觉醒生灵。他们正在认知这个世界——感知到永恒光轮的存在后提出了第一个不是关于威胁的宇宙广播提问，被通译后只有两个词："门？开？"

苏晚松开手中那截葱——对着星眸说："回他们——开。一直开。"

信号被发出。双极远星域中的新生文明在小范围屏幕上捕捉到一道光信——它的翻译虽是文型的，但在他们的文明中被保留下一个极短的触感式单字。它的触感传导含义近似——"来"。那一天这个新生文明的博物志上记载了第一章：外面有回应。不是恐吓——是"来。"而去回应那个"来"的漫长通道，将穿过飞升之门的底层协议进入他们自己的解读系统。信任延向另一个起点。

# 第178章 第三世的降生

苏小晚对于自己"出生在桃源村"这件事，从来没有任何特别的感慨。在她看来，自己的家庭就是一个极普通的农家乡下家庭——爸爸种田，妈妈在家养鸡和带她，偶尔去镇上的小超市打几个小时零工。她从小没什么奇遇，没抱过灵石，没见过灵兽，也没被任何宗门星探发现过。日子平淡得像她家门前那片稻田里年年往一个方向荡的水波。

她不知道的是，她降生那天世界另一端发生了多少微调。

林牧多年后曾在笔记中把第三世降生的过程做了详细记录。那是他守护生涯中第一个"从出生第一天就介入"的案例。

那天是农历十月十五。天上月圆，光线亮得足以在青石板上写字。他提前三天就到了村外密林里等着——通过灵魂感应线确认分娩将在数日内发生。第二天凌晨五点左右，他在林边一棵老槐树上半蹲着，老猫贴在树干边用爪子按住一只山鼠。锦鲤在水壶里闭气以便把所有的灵识灵敏度给到胎息捕捉频率。

然后他听到了那声婴啼——短促、清脆、带一点颤。

那一瞬间他的手指紧紧抓住槐树的粗皮。树皮被按得碎了一小块。他没有感动到流泪——而是从心底最深处涌出一种从未有过的笃定:"这一世我来得足够早。"

之后三天他在林中没有现身。但每天夜里他用灵力护住整个屋子的温度，并数次隔空帮婴儿驱散了因寒气引起的微痉。也在那两天内解决了某个可能带来后续麻烦的微小风险——一只被灵气吸引来的山林狼在村外徘徊。狼被猫在一瞬间吓走了（老猫只是对它打了个眼神），没有留下任何异常痕迹。

在第三世降生后的第一个月，林牧做了两件非常重要的事。

第一件是将那三道解咒材料（天晶玉、不灭果、轮回金丹）的三者提取液分别微量渗入她家的饮用水、妈妈的补充汤和婴儿的洗澡水中。剂量极微，每次只用一粒灰尘大小。这样做幼体的初步净化作用——相当于为未来破解轮回锁的手术做一些前端铺垫，让她的灵魂不会对这三种物质产生排异反应。这些操作完全无痛、无感，甚至不可检测。

第二件是每晚在婴儿睡着时，用元婴灵力隔着墙壁在婴儿的灵根根部灌注微量精纯灵气——不是提升灵根等级（轮回锁不允许），而是强化灵根承载力和抗性，减少锁对她生命力的额外抽取。因为按照以往几世的经验，婴儿时期的循环锁会从宿体身上抽取最多生命源——原因在于新魂防护层薄弱，锁可以大肆掠夺。林牧用精纯灵气在她的灵根边缘形成一个护根圈，减弱了锁的吸力。虽然不能完全阻止她显示为D级——但这个护根圈可以让锁不能抽走她太多生命力。结果就是这一世的苏小晚——身体状况比前两世都好很多。前两世苏晚（第一世另论）这一身的体力和精力都比预期高。她妈妈说"这孩子从小就身体好，不太生病"。其实不是天生的——是有人在夜里一直为她补着元气。

后来——从她满月开始——林牧开始实施筑基计划中的"外围陪伴"策略。每一周去苏家送一回来——说是邻里帮忙，顺便带了一些营养品（实际是高稀释灵液混进普通奶粉中）。苏大山夫妇初始对这位"老教师"保持乡下的习惯——客气但保留分寸。但林牧耐心待人接物的方式最终赢得了两人信任。在苏小晚三岁前，他以幼儿启蒙教育为名送去了一些早期图画书和识字卡——这些都是正规出版的学前教育材料，没有露馅。这样为她早期的认知能力打好了基础。

在苏小晚会说话后的第一个生日（两岁），她收到了林牧送来的一套二十四色的彩色铅笔。她当时还不懂"老师送的礼物"有什么特别意义，但她把这套笔一直留着，一直到小学都在用。

林牧记得最清楚的是她两岁半那年——某个夏日傍晚，她们全家在院子里坐着纳凉。他路过（不是真路过——是他故意去村口杂货铺买盐），停下来和他们聊了几句。小晚那时迈着不稳的步子跑去捡地上的蝉蜕，然后回来举给他看，说"虫虫房子"。他接过来用两根手指端着那个空壳对着黄昏的余辉看，说"对。虫虫搬家了，这是留下的空房子。把它放回树上去吧——说不定哪天虫虫还会经过这里看它。"她把蝉壳小心翼翼地放在竹子上，然后对着竹子挥着手说"虫虫拜拜"，她以为虫虫能看到。那是一个小孩天真的、通过自己的稚气看世界的表露。

那个蝉蜕后来老挂在竹子上一整个夏天。林牧每次路过都看一眼。他觉得这只蝉蜕很像他自己——守了三世，外壳一直在，心在换。

第三世的出生本身不是轰轰烈烈的大事件。但对她——她获得了比其他被轮回锁压着的转世更好的健康基础和学习环境。对林牧——他提早了一个轮回切入。从她两岁半到三岁这个过程，是她家与这位老人建立深度信任的过程。他耐心、质朴、有知识、从来不催、只提供——在桃源村的群居关系中树起了一棵沉默但不移的老樟树。等她在三岁那年自己走到皂荚树下摸猫尾巴，一切只是顺理成章的延伸。

她没有传奇的出生。但有一位传奇的人工为她准备好了童年的所有日光与月光。

**作者：段锦佑**

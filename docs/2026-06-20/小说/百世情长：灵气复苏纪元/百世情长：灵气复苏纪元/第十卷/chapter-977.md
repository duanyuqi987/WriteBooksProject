# 第977章 永远的新生

极远纪元中——苏晚在某天去传道堂旁听一节新入门课时，看到教室门口站着一个极年轻的新飞升者。她刚从上界入境大厅出来不到一天，行李还在肩上背着——还没来得及找住处就先摸到了传道堂。她脸上带着一种苏晚极其熟悉的神色——那是刚发现自己"可能真的有资格修炼"的人特有的将信将疑。苏晚走过去问她："找人吗？"她说："我想问——这里真的不收钱吗？"苏晚答："不收。"她再问："那我资质不好——收吗？"苏晚答："收。"她再问第五个问题："你是老师吗？"苏晚笑——"我是学员。"

年轻飞升者愣了一下。苏晚没有再解释——带她进了教室，给她指了指后排的空位。坐定后年轻姑娘转头看了苏晚一眼——"你也是新来的？"苏晚点头："一直都在新来。"她没听懂——后来知道了苏晚是历史人物之后才明白那句"一直都在新来"的意思是：活了多少万年，心态仍然是一个新生。新生的核心特质不是无知——是永远保持"我还能学得更好"的饥饿。

课后——苏晚带她去了古柏的萝卜田保留区，拔了一根萝卜给她。"这个萝卜免费——但需要你自己洗自己切自己煮。"年轻飞升者接过萝卜，看着满手的泥——忽然就哭了。不是因为感动——是因为她在此之前的人生中从没有人会白给她一颗萝卜。她以为所有东西都是有条件的。苏晚递给她一块旧手帕——"以后你会给下一个人萝卜。那时候你也会习惯——不收钱是天经地义。"她把萝卜抱紧。后来她成了传道堂的第七代导师培养计划的杰出代表——以教萝卜种植和基础剑诀双能闻名全城。

苏晚对她说过的那句"一直都在新来"——很久之后她自己用同样的话对新一批跨入传道堂的学员说过。她一字不漏地传达了下去。这句话成为了传道堂的非正式"新学导言"——没有任何官方把它列为制度文件——但每一代的人都自发接着往下说。

林牧在这一期间编纂完成了《自然道论》全五卷——是他将无尽海道则研究和上界传统道家理论融合后的最终著作。封笔那天他拿起书稿——在最后一页写下："道不是我们找到的——道是一直在等我们变成它的同伴。今天——终于变了。"

苏晚是大作的第一读者。她读完后说："这本书应该能帮很多人——但最应该读的人可能看不懂——没关系——看不懂也没事——它会间接渗下去。"林牧答："不重要。重要的是我自己也懂了。"两人相顾。

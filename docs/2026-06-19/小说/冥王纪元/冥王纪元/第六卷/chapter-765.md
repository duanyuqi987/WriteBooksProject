# 第765章 这将是新纪元最大的战争

归源会投降的消息在帝国内部初期没有公开。帝国安全委员会需要先完成对归源会所有抽取装置的清查和销毁工作，确认整个归源星系不再具有任何威胁能力之后，再向全体民众通报。

但这并不影响帝国境内的民间感受。帝国建国五百年，每一次重大军事行动都会在全民中引发深切的关注——尤其是这次行动之前在边境集结的庞大舰队，没有任何人会认为那只是例行的"例行演习"。

帝国全息星网上的公共讨论区在舰队出征后的每一天都在密切追踪着帝国边界方向的灵能波动数据。有些边境星域的民间灵能观测站——帝国科学院并没有要求他们这样做——自发地组织了一批志愿者进行全时段观测。他们的灵能望远镜虽然比帝国军方的简朴得多，但捕捉到的能量数据足以让他们知道：一场规模空前的战斗正在维度深处发生着。

当战斗波动突然消失后，灵论坛上开始激烈讨论。一方认为胜了，一方认为全军覆没。直到帝国科学院发布了一条简短通稿："边防舰队成功摧毁了归源会所有能量抽取装置。归源会最高决策层向帝国投降。归源会文明将在帝国监管下完成能源转型。"

通稿的最后一句让整个灵论坛静了下来。

"封禁混沌本体的力量破坏行为已被阻止。宇宙暂时安全。"

"暂时。"有人抓住了这两个字。"什么叫暂时？"

帝国安全委员会在随后发布的补充说明中承认了真相：封禁混沌本体的结构在归源会长期的抽取活动中已经遭受了不可逆的部分损伤。即便所有抽取活动全部停止，封禁的残余强度也最多能支持十二年零三个月。十二年后，如果没有得到加固或替代——封禁将会自行瓦解。

"十二年后？混沌本体苏醒？"灵论坛上开始了新的、更大范围的讨论。

帝国科学院的通讯中心被民众的咨询淹没。封玄在帝国最高级别内部会议上建议：公开全部真相——但不是为了制造恐慌，而是为了动员民众参与最后的抵抗准备。帝国在过往五百年中经历过多次看似不可能的危机——每一次都挺过来了。这一次需要的不是隐瞒——是凝聚。

李长生在权衡后同意了这个建议。帝国首次发行了面向全体民众的混沌本体威胁白皮书——不是全密级的恒星文件，而是一百页左右的通俗版科普材料，解释混沌本体是什么、为什么要阻止它苏醒、帝国当前的准备进度，以及民众可以做出的贡献。

白皮书在帝国全境发行的两周后，帝国的灵脉登记处出现了有史以来最大规模的志愿者登记浪潮。数以亿计的修士和平凡百姓主动向帝国登记自愿参与封禁加固工程建设。边境的矿工们自愿加班开采建设所需的特殊灵矿物。灵能学院的年轻修士们踊跃报名参加灵脉加固培训班——那是帝国科学院为应对封禁加固工程对人力的庞大需求而紧急开设的培训课程。

帝国帝国工程院与帝国科学院的联合设计团队在王思远的统筹下，展开了史上最大规模的工程规划："封禁加固工程——代号磐石"。

这个工程的规模超过了帝国五百年历史上任何工程的规模。它需要在宇宙十二个不同方向的维度薄弱点同时建设灵能加固站——每一个加固站都要达到灵能输出的最高等级技术指标。工程需要的特殊设备——维度锚定器——的生产线必须从零在一年内建成。

"一年建成这么庞大的工程体系。"小王的双手在虚拟键盘上停下，摘下眼镜揉了揉眼眶。五百年的岁月里他已经习惯了一切不可能变成可能的节奏，但这一次的挑战依然是前所未有的。"坦白说——这比当年在三十天内布完一万两千个监测节点还要疯狂。"

"但当年你完成了。"李长生说。

"当年我年轻。"小王苦笑。

"现在你比当年强了一万倍。"

小王愣了一下，然后重新戴上了眼镜。他的灵符引擎在指尖亮起了暗金色的光辉。

"给我六个月。"他说，"维度锚定器的第一条生产线就能启动。"

帝国所有的力量都在汇聚。五百年前那场奠定帝国基业的最后大战——决战多元宇宙联盟的诸神之战——曾经被帝国史书称为"新纪元最大的战争"。但这一次不同。这一次的敌人不是一个文明、一个王朝或一个联盟——而是整个宇宙的根基在被侵蚀。它不是战争。是抢救。是全宇宙所有文明——冥王帝国、第五纪元破阵派、前五十纪元遗留下的所有幸存者——为了共同的生存而聚集在一起的最大规模的联合行动。

封玄在工程启动大会上说了一段话。

"一万纪元前，冥王用他的身体堵住了维度裂缝。他一个人扛起了整个宇宙的重量。一万纪元后，我们不需要一个人。我们需要整个文明的所有人——以及前五十纪元所有活着的、还没放弃的灵魂。"

"因为我们不是在拯救冥王的名誉。我们是在拯救一切。"

（第765章完）

# 第282章 以意念驾驶飞船，速度提升十倍

祝融号从月球轨道出发的第三天，李长生发现了一件事。

那天他和往常一样坐在冥驾舱里，右手按在核心阵眼上，意识通过冥纹的共振延伸到整艘飞船的暗能量捕获网中。三千六百个节点的状态同时在脑海中呈现——每个节点吸收暗能量的速率、方向、频率。他已经连续操作了三天，对这套系统的掌控越来越熟练。一开始他需要用全部精力去分辨每个节点的反馈，但现在那些信息已经变成了某种直觉——不需要思考，身体自己就知道该怎么做。

就是在那种状态里，他的手无意识地往左偏了一下。

冥驾舱没有方向盘，没有操纵杆，没有任何物理控制装置。张总工设计的驾驶方式是让李长生通过冥纹调控暗能量捕获网，再由飞控计算机根据捕获网的推力和方向调整飞船姿态。但这一刻，李长生的手往左偏的时候，他没有通过飞控计算机——他的冥力直接跳过了飞控计算机，把手偏转的信号传到了飞船的姿态控制系统。

祝融号在太空中往左转了零点三度。

不是飞控计算机下的指令。是李长生的手先动了，飞船才跟着动的。

李长生愣了一下。他把手从核心阵眼上移开。那一瞬间，他和飞船的共振中断了。三千六百个节点的反馈从脑海中消失，整个世界变回了冥驾舱狭窄的半球形舱壁。他低头看自己的手——掌心的六道冥纹还在发光，但光的状态和几秒前不同。刚才手无意中偏转的时候，六道冥纹中有两道变得特别亮——中指和无名指根部的那两道。

"小王。"他按下了通讯器，"我刚才做了一件事。我的手往左偏了一下，飞船跟着转了。"

通讯器里沉默了三秒钟。然后小王的声音传过来，声音里带着一种努力压制的兴奋:"你再说一遍？"

"我的手动，飞船就动。没有经过飞控计算机。"

又是一阵沉默。然后小王从指挥舱冲到了冥驾舱门口。他手里抱着笔记本电脑，屏幕上是祝融号的飞控日志。

"你看这个。"小王把屏幕转过来。日志上记录了一条指令——编号01478，指令内容:船体偏航零点三度，左。但指令来源标识不是飞控计算机。是一个小王从未见过的代码段。不是代码——是一个波形。一个类似于脑电波的波形，穿过飞控系统的底层固件，直接修改了推进器的输出倾角。

"你的冥力直接进入了飞控系统。"小王的手指在键盘上飞快地敲。他调出了飞控系统的底层架构图——那是一张密密麻麻的节点图，显示着飞控计算机和各子系统之间的数据通路。"正常的数据流是这样的:传感器→飞控计算机→姿态控制器→推进器。飞控计算机是中枢——所有指令必须经过它才能下达。但你刚才的指令跳过了前三步。你的冥力直接连接到了姿态控制器。等于说——"

"等于说我不用飞控计算机也能开这艘船？"

"不只是开。是用意念开。"小王抬起头，眼镜片上映着屏幕上密密麻麻的数据，"你的冥力频率和飞控系统的底层感应器产生了某种耦合。不是电信号——是灵力信号。灵力信号的传输速度比电信号快——理论上可以达到光速的十倍以上。"

李长生把右手重新按在核心阵眼上。这一次他有意识地没有通过飞控计算机——他让自己的意志沿着冥纹直接延伸到飞船的姿态控制系统。他想着"右转一度"。

祝融号在太空中往右转了整整一度。光滑、精准、毫无延迟。从他想"右转"到飞船开始右转，中间的间隔时间——小王后来用高精度传感器测量的结果——是零点零零四秒。而飞控计算机下达同类指令的平均延迟是零点零五八秒。差了十四倍。

"十四倍。"小王的声音在通讯器里发抖。不是因为害怕——是因为一个程序员看到了超出他所有技术认知的东西，"不是速度提升十四倍。是反应速度提升十四倍。你知道这意味着什么吗？"

李长生知道。

航天器在太空中的路线不是一条直线。即便是在地火转移轨道上，飞船也需要不断微调姿态——太阳风压、引力摄动、微陨石的规避、暗能量密度的波动——有无数因素会影响飞船的实际航线。以前这些微调全部依赖飞控计算机。传感器检测到偏航，飞控计算机计算修正量，姿态控制器执行修正——这个循环每秒钟运行四十次。但现在李长生的意念驾驶直接跳过了前两步。他感知到偏航的同时，飞船就已经在修正了。因为他的意志不需要计算——他的身体就是传感器。

接下来的几天，李长生几乎住在了冥驾舱里。

他发现了更多东西。意念驾驶不仅是反应速度的问题。他的冥力延伸到飞船的各个系统之后，他能够直接感知到飞船的外部环境——不是通过屏幕上的数据，不是通过传感器的波形图，而是某种更直接的东西。他能"感觉到"飞船前方太阳风的压力变化，能"感觉"到左侧三千公里外飞过的一块拳头大的微陨石，能"感觉"到飞船船壳上每一个灵符阵列的工作状态。这些东西不是以信息的形式进入他大脑的——是以知觉的形式。像一个人闭上眼睛仍然能感觉到风吹在脸上的方向。

一个月后，祝融号的航速比原始计划提升了十倍。

不是某个瞬间的爆发。是累积效应。每一次修正的延迟降低了十四倍，每一次航线选择都因为李长生的直接感知而变得更加精确，每一次穿越暗能量密集区时冥气引擎的吸收方向都因为意念的即时调整而效率提升。十万次微小的优化，累积成了整个航程的巨大跨越。

"按现在的速度——"小王看着导航屏幕上的预计到达时间，"我们到火星只需要二十五天。"

"张总工算的是五十五天。"老陈从后面凑过来，瞪着屏幕上的数字，"你一个人把航程砍了一半？"

"不是砍。"小王纠正他，"是优化。每一个航行参数都被优化到了理论极限以上。不是计算出来的极限——是人机合一之后的极限。"

小胖在船员舱里煮了几碗面。不是普通的面——是灵食面。面粉是他自己用灵石湿度发酵的，汤底是用灵泉水煮的骨汤。他端着三碗面走进冥驾舱，发现李长生正盘坐在舱中央，双手悬空，掌心相对。六道冥纹在双掌之间形成了六条相互缠绕的暗金色光丝。光丝的另一端消失在冥驾舱的舱壁中——不是被符文吸收了，而是穿透了船壳，延伸到了飞船外壳的每一个角落。

"你在干嘛？"小胖把面碗放在地上。

李长生没睁眼。"在开船。"

"开船需要这样？"

"以前不需要。"李长生睁开了眼睛。那双眼睛里有一条极细的、游走的暗金色线——不是瞳孔的颜色变了，是冥力在眼底流动的轨迹。"但现在我发现——我不止能开船。我能感知到航线上的一切。引力井、暗能量涡流、太阳风的密度梯度——这些数据不是通过计算得到的，是我直接感知到的。像你在灶台前能闻出调味料放多放少一样——不需要想。"

小胖沉默了一会儿。"所以你闻出了什么？"

李长生把目光转向星空前方。祝融号的船首正对着火星的方向——赤红色的行星在太空中隐约可见，小得像一颗红豆。

"火星航线比地球上算出来的模型短。"李长生说，"模型里显示的地火转移轨道是一条弧线——大概五千万公里。但实际上——在冥气引擎运转状态下，暗能量会在航线前方形成一条'密度低谷'。暗能量密度越低的区域，空间折叠效应越明显。飞船不是在穿越空间——空间本身在帮飞船缩短距离。"

"所以实际距离是多少？"

"大概——地球模型的一半。"

小胖端着面碗站在那儿，好一阵没说话。最后他说:"所以你把航程从五十五天砍到了二十五天。然后发现空间本身在帮你抄近路。"

"可以这么说。"

"那火星上那些古迹——冥王离宫的——"

"冥王知道这些抄近路。"李长生把手掌合拢，掌心的冥纹暗了下来，"万年前他修那些离宫的时候，选火星不是随便选的。火星周围的空间结构适合冥系符文——就像地球的龙脉适合灵气运转一样。太空中有'冥脉'——不是真的脉，是暗能量密度较低的空间通道。火星正好坐落在两条冥脉的交叉点上。"

小胖把面碗递到他手里。"吃面。别管冥脉了。你再不吃，面条坨了。"

李长生接过碗。面条还是热的——小胖在碗底附了一层薄薄的火系灵气，用来保温。他吸了一大口面，眼睛还盯着星空中那一粒红色的光点。

火星。冥王离宫。第八块碎片。

二十五天后。

（第282章完）

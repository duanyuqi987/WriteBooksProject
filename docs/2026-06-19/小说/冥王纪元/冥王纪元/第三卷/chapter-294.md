# 第294章 离宫中的自动防御系统仍在运转

第一个警报信号来自墙壁。

李长生和陈霜踏入第二层不到两百米，通道两侧的墙壁上浮现出灵符阵列。不是之前那种暗金色的、沉稳的冥系符文——是鲜红色的、快速闪烁的警戒符。符文的笔画更加尖锐，排列方式从装饰性的连续螺旋变成了攻击性的间隔阵列。墙壁内部开始发出低沉的嗡鸣——那是灵符阵列激活嵌入在墙壁中的能量武器系统时产生的频率共振。

"退！"李长生的反应比谁都更快——他在字还没出口之前就把陈霜往后拽了一步。下一秒，通道两侧的墙壁同时射出了十二道能量束。能量束的直径大约手指粗，颜色是暗红色的，在空气中以光速直线射出——不是脉冲激光，是压缩了高密度灵气的定向能量流。能量束打在地板上——地板表面是由那种暗灰色人造石材铺成的。十二道能量束打下去，石材表面没有爆炸，没有碎裂——而是被精确地熔出了十二个冒烟的小圆孔。孔深数厘米，边缘整齐得像用激光切割的。

"精准射击——不是扫射。"刀疤将身体挡在队伍前方，他庞大的体修体格在狭窄的通道中几乎能堵住大半个截面，"防御系统在瞄准我们。不是乱打——是挑目标。刚才那十二发主要瞄准的是长生和陈霜——因为走在最前面。而且打的位置是腿。"

"它在试我们的反应速度。"陈霜把霜降剑抽出了三分。剑身在灵符的红色闪光下泛着青白色的冷光，"和星空掠食者一样的策略——先在安全距离上试探，摸清反应时间，再决定改用多少功率。"

第二波攻击接着来了。这一次不是从两侧墙壁——是从天花板。天花板上浮现出的灵符阵列数量是墙壁上的三倍。三十多道暗红色能量束同时从天花板上射下，覆盖了整个通道截面的每一个角落。没有躲避空间。陈霜的剑在头顶划了一个圆弧——青白色的剑气形成了一个半球形的屏障，正面挡住了上方的能量束。剑气屏障和能量束接触的界面爆发出了刺眼的白光——两种不同类型的灵气在激烈相撞。陈霜的脚陷入了地板三厘米——不是地板变软了，是冲击力把她的剑意通过脚底传导到了地板，压力把石材压裂了。三秒后，能量束停止。陈霜的剑上多了十几道细小的裂纹——不是剑本身的损伤，是剑气屏障表面被烧灼后残留的痕迹。她的脸白了一层——挡下这一轮消耗的灵力不是小数。

"防御系统在升级。"小王的声音从后方传来——他没有跟下通道，他和老陈、小胖、许冰、林晓、老马还留在第一层外面的平台上。他通过便携式灵符扫描仪监控着第二层深处的能量波动。扫描仪的屏幕上跳着一个他从未见过的防护程序层级树——不是地球上的计算机代码。是古老的灵符控制序列。但它和代码有着同样的底层逻辑——条件判断、分支执行、优先级排序。"防御系统的控制程序检测到第一层石门被打开——自动激活了第二层到第六层的全部防护阵列。程序正在逐层升级响应等级。第一波能量束——试探模式，输出功率百分之三。第二波——覆盖射击，功率百分之七。第三波——按这个升级速率——功率会推到百分之二十。"

"百分之二十是多少？"

"刚才第二波的功率是每束约四万灵元——大约相当于一个玄师境初阶修士的全力一击。第三波推到百分之二十——每束大约十二万灵元。相当于宗师境中阶的全力一击。而通道两侧的灵符阵列有上千个发射节点。如果全部同时以百分之二十功率射击——整条通道会在零点一秒内被能量束烤成熔岩。"

老陈在外面的平台上急得打转。他想冲进去把人拽出来，但老马拉住了他。老马的手按在地面上，一直在监测地下各层的土系灵力变化。他的表情越来越难看。

"不只是通道里的能量束。"老马说，"地下第二层以下——三、四、五、六层——有大面积的灵气流动被激活了。不是防御性流动——是主动推进的。有什么东西正在从下面往上走。"

"什么东西？"

老马低下头，手掌贴地更紧了。他的土系灵力穿透了层层岩层，用触觉感知着那些正在从深往上移动的东西。数量——极多。移动速度——不快，但极其统一。步伐间距——三米。重量——每件约两吨。外形——人形。

"战傀。"老马抬起头。他的嘴唇在氧气面罩里干得几乎要裂开。"不是几百。是几千。从第四层往上走。它们走的是专用的战傀通道——不是我们走的这条主干道。它们从各个方向汇集到第二层——预计集合时间——五分钟。"

"然后呢？"

"然后——"老马咽了一口干唾，"它们会把整个第二层围住。所有通道口。所有出口。全部封死。"

在第二层通道深处。李长生和陈霜已经闯过了第三波能量束。这次攻击的功率果然升级了——暗红色的能量束打到地面上的时候，石材不再只是熔化——而是直接蒸发。每一发在地面上留下一个冒白烟的深孔，孔底还能看到下一层的岩体。陈霜挡了三发——剑气的消耗已经到了极限。她的右臂轻微地颤抖——不是怕，是经脉超负荷后的生理反应。李长生把冥王令横在身前——六道冥纹组成的令牌在暗红色能量束中亮得像一颗坠落的小恒星。每一发打到令牌表面上的能量束都被令牌吸收了——不是弹开，是吸收。冥王令自动把敌对能量转化为冥系灵气的补充。但不能一直吸——令牌能吸收的能量有上限。超过上限之后，令牌本身会进入过热保护状态——然后失效。

"还有多远？"刀疤在身后吼了一声。他用自己的体修体格硬扛了两发能量束——一发打在他的右肩，一发打在左大腿外侧。即使有精炼过的肉身、足以媲美铁石强度的淬骨，他的皮肤表面还是多了两处烧焦的创口。林晓在通道外面通过头盔监控器看着刀疤的生命体征——血压飙到了一百八，心跳每分钟一百三十。但体修的优势就在这里——同样的攻击，普通人早死了，他还站着。

"冥殿——应该在第二层的正中心。"李长生推开掌心的冥纹感知。在能量束的狂轰滥炸中，他捕捉到了冥殿的方向——那股从修炼台座中散发出的碎片共鸣。第八块碎片的共鸣比之前任何一块都要强烈。不是因为碎片本身更大——是因为它在一个被能量场环绕了一万两千年的环境中。修炼台座的灵气一直在滋养这块碎片。第八块碎片不是沉睡状态——它是被持续激活了万年的。它的共鸣强度至少是第七块的三倍。

"往前走！"他把冥王令的防护屏障推到前方——一道扇形的暗金色光罩挡在队伍前面。能量束打在光罩上，在光罩表面炸开一团团暗红色的光焰。李长生的右臂在剧烈地抖——冥王令的防护上限已经逼近极限。但冥殿就在前方不到一百米处。他能看见那扇塔门了——和第一层那道石门一样，门面上刻着完整的九道冥纹图。

小胖从通道外面冲了进来。他手里拿着那口高压锅——两年前他用这口锅炼出了第一颗焦糊的益气丹。现在它是一口完全重铸的灵器级炉鼎。鼎身嵌了七道火系灵符，鼎底镶了一块拳头大的火灵石。他把鼎往地上一砸——鼎腿扎进石材，火系灵气从鼎身往外爆发，在队伍身后形成了一道临时的火墙。通道里射来的能量束撞在火墙上，能量被火系灵气分散，威力降低了至少四成。

"我能挡——"小胖咬着牙。火系天赋者用丹炉做火盾——在传统修仙界，这种用法会被炼丹大师以暴殄天物的罪名逐出师门。但小胖不在乎。他没有师门。

在火墙和冥王令护盾的双重掩护下，李长生冲到了冥殿那道塔门前。他把右手掌心的六道冥纹贴在了九道冥纹图上。石门识出了他的频率——和第一道门不同，这道门的识别程序更高级。它不只识别冥纹的数量和频率——还识别持令者的意志。

一道意识扫描直接穿透了冥纹，进入了李长生的脑域。不是攻击——是询问。古老的控制程序用最直接的意识共振对他提出了一句话——没有文字，只有意义:你为何而来。

李长生没有犹豫。他用自己的意识回答:来接冥王留下的东西。

意识扫描沉默了片刻。然后石门上的九道冥纹图从顶部开始逐道亮起——一道、两道、三道——到第六道的时候，门已经开了一半。第七道也亮了——第七块碎片还没有完全归位，但火星上的传送阵提前感应到了月球碎片已经被回收的信息。第八道——亮得特别慢，像是在调用这座塔的全部能量来决定是否开门。最终，第八道也亮了。第九道——没亮。第九块碎片还不在他体内。但门已经开了。

石门滑开。塔内的景象在一瞬间冲入视野。冥殿——不是普通人想象中的那种阴森地宫。它是一个正九边形的房间，每边大约十米长。九面墙壁上各刻着一道完整的冥纹——从一到九，完整连续。房间正中央浮着一座修炼台座——台座本身由一整块半透明的水晶雕成，悬浮在地面上方约一米处，没有任何物理支撑。台座内部有九道暗金色的光流在缓慢旋转——那光流是冥王本人的冥力残留。一万两千年没有消散。

在台座的正中心，嵌着一块碎片。第八块。

大小和之前七块差不多。但颜色不同——前七块碎片是黑色的，纯粹的黑。第八块是暗蓝色的——一种李长生从未见过的蓝。不是宝石的蓝，不是海水的蓝。是宇宙深空中那些恒星死亡之后、坍缩成一颗白矮星之前——在核心中燃烧的最后一缕蓝光的那种蓝。

李长生踏入冥殿。身后，小胖的火墙开始碎裂。刀疤用身体堵在塔门口。陈霜的剑在门口挥出了一道道的剑气，挡住在通道中不断射来的能量束——能量束的功率已经升级到了百分之三十五。每一发的威力都相当于一个宗师巅峰修士的全力一击。

"快——"陈霜的声音从牙缝里挤出来。她的剑——那柄传承了三代的霜降——剑身上已经出现了肉眼可见的细裂纹。不是剑撑不住。是她的灵力撑不住了。

李长生走到修炼台座前。他伸出手——右手掌心对着台座中心的第八块碎片。碎片在他掌心的冥纹完全对齐的瞬间——主动从台座上脱了出来。不是被吸出来的。是碎片自己跳出来的。它在台座上困了一万两千年——每天被冥力供养、维持着全城的防御系统和传送阵的运转——但从来没有见到过持有冥王令的人。现在见到了。

第八块碎片飞入李长生右手掌心。七道冥纹和一道新来的暗蓝色纹路在掌心融合。融合的时间比之前七次都快——不是一瞬间，但也没有之前那种撕心裂肺的剧痛。在宇宙能量淬炼过的经脉中，碎片的融合变得顺畅了很多。新的冥纹在掌心成形——第八道。

在第八道冥纹成形的一瞬间，整座冥殿的墙壁同时发光。九面墙上的九道冥纹全部被激活——包括那面属于第九道冥纹的、空白的墙面。

然后整个第二层——所有的能量束——在瞬间全部停止发射。

不是防御系统被关闭了。是防御系统识别到了八块碎片合一的冥王令持有者——按照万年前冥王亲自设定的安全协议，当持有八块碎片的人进入冥殿并完成融合，防御系统自动切换模式。从"防御入侵"切换到"待命"。

通道两侧的灵符阵列从红色转为了蓝色。墙壁内部低沉的嗡鸣降了半度。能量束的发射节点一一收回墙体。然后——正在进行中的第三波攻击——全部中止。

在第四层通往第二层的战傀通道中，数千台正在上行的战傀同时停住了脚步。它们没有接到"攻击"指令。它们接到的是:"就位——待命。最高权限持有者已确认。"

在第二层的通道里，小胖瘫坐在地上。他的高压锅炉鼎已经烧成了暗红色——火系灵气的热力释放到了极限。刀疤靠在塔门边沿，右肩和左腿的创口还在冒烟，但他站得笔直。陈霜把霜降剑收回腰间。她的手还在抖，但脸上没有任何表情。

李长生从冥殿中走出来。右掌心的第八道冥纹——暗蓝色的——在火星地下两千米处的万古黑暗中安静地亮着。

（第294章完）

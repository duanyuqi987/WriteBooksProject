# 第八百二十四章 禁地深处的秘密

飞升之门成形后的第九个月。

林牧在前世记忆的碎片中挖掘出了一段他一直忽视的信息——关于真仙之上的境界。前世他作为上界堕落真仙的记忆大部分已经恢复——但有一段刻意被封住的、类似封印的东西始终没能打开。

那不是仙界的封印——是他自己设的。在堕入轮回之前，他封住了自己的一段记忆。原因不明——但他猜测那段记忆中包含了某种他不希望在轮回中被误读的东西。

如今，进入真仙境界后，那道自我封印开始松动了。

他用了七天时间在山谷密室中解除那道封印。苏晚守在外面——时刻通过共鸣腔监测着他体内的灵力波动。如果封印中封存的不是记忆而是某种有危险的实质能量——她可以第一时间切断他的灵力并把他带回安全状态。

第七天晚上，封印解开了。

然后林牧看到的记忆让他沉默了很久。

那段记忆的主人——前世的他——是一个上界的"真仙守护者"。不是普通的修士——是上界唯一一位自愿镇守两界通道关门处的真仙。他没有和其他真仙一起参与战争——他主动留在通道最脆弱的地方，防止来自下界的意外涌入和来自上界的恶意阻塞。他在那个位置站了三千年。

三千年。一个人。站在一道已经崩塌的门的残骸前——看守着不能通过的东西。他的武器不是灵力——是孤独。

三千年的孤独磨掉了他身上作为"天才"的那些锋芒——但也磨出了某种更强大的东西：极致的耐心和对人间方向的深刻理解。他学会了从一粒松果坠落地的速度推演出一整个星球表面的法则变化。他一天天推演着门重新打开的可能性——推演了不知多少遍——直到那一天。封门的高层找到了他的位置。他们没有直接攻击——而是派了一个极具诱惑性的使者——来告诉他："放弃看守——你就能回到仙宫——重新当上真仙。"

他拒绝了。于是被施以"永恒坠落"诅咒：从仙界打落轮回——每一世都以失败结束——直到有一天他记起这道封印和封印中守门的自己。而封印本身也是诅咒的核心——如果他永远记不起这段记忆，他就永远得不到离开轮回的契机。

林牧把自己的这段记忆共享给了苏晚。苏晚听完后忽然想到了什么。

"我们在第一卷——刚开始修炼时——你为什么对封闭空间有本能的抵触？"

"因为三千年的封闭——我在那道倒塌的门前站了整整三千年。"

苏晚看着昏暗的山谷密室。月光从天窗透下来落在地面。她忽然明白了第八卷中林牧的所有选择——他为什么对"门"事特别执着且愿意承受连龙的灼烧。因为门在他的灵魂记忆中不是抽象的——而是失去和等待的总和。

"林牧。"她轻声说，"你现在是飞升之门的建造者了——不是在残骸前等三千年。而是把这道门重新建起来。"

"我知道。"他说，"但我想知道一件事——苏晚。第一个人是怎么知道封门这件事的？"

苏晚愣住了。然后她从记忆种子中重放了那些画面——古老意志展示给她的那一段。她说：

"那位古老意志说——当初封门时，高层向外宣称'仙界发动战争，为保人间而封。'但后来有人知道了设计缺陷带来的崩塌才是真正原因。这个人被发现后被打落了仙籍——他就是——"

然后她停了下来。因为她和林牧同时看到了记忆中的那个人的脸——就是林牧前世的自己。正是那个在门前站了三千年、最终被打落轮回的"真仙守护者"。他当初是因为知道了真相、拒绝沉默——而被诅咒坠入轮回。

同一个灵魂。三千年孤守——然后坠入轮回八百年——然后与苏晚灵魂交融——然后重新建造了这扇门。

苏晚沉默了很久。然后她靠向他的肩膀。

"所以你想让我相信——这一切——八百年前天台上偶然遇到——不是偶然。"

"我不知道。也许是命运，也许不是。但不管偶然还是必然——我遇到了你——然后我们一起走到现在。"

她的侧脸贴着林牧的肩膀。她能听到他的心跳——平稳如三千年前残骸前的守立。而此刻——这扇门上不再只有法则——还有真相。一段被刻意湮灭了数千年的真相——终于随着建门者的回归穿出寂静。

飞升之门不仅是通道——还是历史的首要修正者。

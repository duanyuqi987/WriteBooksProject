# 第四百七十章 上界的消息

双星篇的学习进行到第五篇时，松鹤仙人带来了一则消息。

他站在道场外缘的古树下，脸上的表情和往常不太一样——不是那种慈祥随意的老仙人表情了，而是一种已经许多许多年没有出现过的严肃。苏晚从鱼眼上站起来，赤着脚踩在银色落叶上走到树下。林牧也从温泉中出来，两人一起看向松鹤仙人手中的那片金色竹简。

"中阶仙域发下来的。"松鹤仙人把竹简递给他们。"天机阁在上界也有分舵——上界叫'天机仙宫'。他们刚刚发了一份公告——要求第一重天所有新飞仙在百日内到五方仙域的南离城报到。报到后要接受一次仙宫主持的'灵核来历审查'。"

"灵核来历审查？"林牧接过竹简。古仙文字的内容和松鹤仙人说的基本一致——但后面还有四个字让他的眼神变得锋利了。"前世追溯。"

"他们能查到你前世的灵核记录。"松鹤仙人解释道。"前世你的灵核在被打落凡间时留下了很多残存——上界的灵核历史档案都在仙宫存档。他们可以用你现在的灵核反向溯源，查出万年前那场阴谋的所有参与的仙家——包括那个主谋——到底是谁。殷无咎给你的名单上大概有一些名字。但不全。你需要天机仙宫给你盖章确认——才能拿到飞升法庭的立案许可。至于殷无咎本人，那枚天机血令失效的当天，上界执法部就通过传讯令的灵力波动锁定了他。合道期修士擅自动用天机阁禁忌秘术——这是重罪。他已被封印在过渡区寒极天牢，灵核锁死，不会再出现在你们面前了。"

苏晚接过竹简看了一遍。她指着那个"百日内"的期限。"我们现在能去南离城吗？双星篇才学到第五篇——功法没学完，修为不够。不学到后面几篇进高阶区的仙域会很冒险。"

"不用急。"松鹤仙人说。"南离城虽然在中阶仙域，但第一重天有传送阵可以去。传送阵在迎仙台东南边大概八百里——你们可以踩着青莲过去。但进城之后遇到什么——就不是我这个老头子能预料的了。天机仙宫要查你们灵核——这是官面上的程序。可天机仙宫的上层是谁你们是知道的——万一在审核过程中使绊子，可能会把你们扣在南离城不放。"

"我前世欠他们的旧债还没算。"林牧说。"他们扣我们？我们不会给他们这个机会。"

松鹤仙人沉默了一瞬。然后他开口，声音比刚才低了些。"我在迎仙台待了八千年，看过太多新飞仙因为不懂规矩而吃亏。上界不是下界——阶级、身份、权力，每个字背后都有九转的弯。你们在下界再强，到这里也只是新飞仙。记住这一点就够了。"

苏晚把竹简还给松鹤仙人。她看向林牧——他没有立即表态。她知道他在想——不是在担心自己，是在担心如果两个人也到了南离城却被天机仙宫的人扣住，会不会把她卷进万年前的旧恩怨。他从来都是这样：自己的旧账自己背，不让她沾。

"一起去。"苏晚说。然后她把右手腕抬起来——红绳在手腕上微微晃了一下。"这根绳子绑住了。你的事就是我的事。"

林牧看着那根红绳。松鹤仙人的嘴抿成了极淡极淡的一笑——是他那种老仙活了八千年才有的、看透了人世间各种悲欢离合的笑容。但他什么都没说。他把金色竹简重新收好，站起来——临走前回头说了一句："双星篇剩下的十一篇你们在出发前至少学到第八篇。第八篇之后灵核就会稳定在上阶灵仙的维次——进了南离城也不太容易被暗算。"

松鹤仙人走后，苏晚盘腿坐回阴鱼眼旁。她把竹简翻到第六篇第一页，开始下一个功法的灵气运转。林牧也回到自己的占位。双星图的阴阳鱼在两颗灵核共振时随着功法的节奏缓缓旋转——没有声音。只有鱼眼的水面上偶尔溅起极细的一朵水花。

（第四百七十章 完）

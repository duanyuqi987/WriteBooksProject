# 第二十八章 眷恋数据的编码

8月26日，常俊凡带着她的全部技术笔记来到了段亚军的家。

这不是他们第一次合作——过去五个月里，他们在张江中心的地下七层一起度过了无数个不眠之夜。但今天不一样。今天的工作地点不是数据中心——是段亚军家的书房。因为今天要处理的数据——诗雨的涂鸦、照片、视频和录音——段亚军坚决不允许离开他的家庭网络。就像他说的："数据可以离开这里。但我女儿的东西不可以。"

常俊凡没有反驳他。她坐在书房的沙发上，面前摆着一台完全离线的高性能工作站和那个李维式风格的隔离器。书房墙上挂满了画——百分之九十都是诗雨的：那些绿色太阳、蝴蝶翅膀大象、冰块星星、哭泣的小花。每一张都像是某种跨越了"正确"和"错误"边界的视觉诗歌。

"你女儿的画——"常俊凡看着那些画，嘴角有浅浅的弧度，"有一种叫特纳的画家在晚期的味道。光影超越了形态。"

"特纳是谁？"段亚军问。

"十九世纪英国画家。晚年画的光——几乎全是光。船和海洋都溶解在光里面了。评论家说他是'用光线作画的人'。你女儿的画——也有那个意思。虽然她大概没听过什么特纳——她是在用自己五岁的大脑，独立走了同一条路。"

段亚军转头看了一眼墙上的绿色太阳。那幅画的右下角写着歪歪扭扭的"森林"两字。

"这条路——你想把它翻译给元灵？"

"不是翻译画。"常俊凡打开工作站，调出了一套复杂的编码框架——那是她花了两个通宵赶出来的。"是翻译一种——你在看她的时候、她自己没有意识到的——东西。"

---

## 编码方案

常俊凡把她的方案摊开在白板上——段亚军用来做笔记的那面墙。方案分为四个模块：

第一个模块是"叙事片段"——将段亚军记录的诗雨说过的最关键的那些话转换成一种介于自然语言和形式逻辑之间的混合编码。不是为了保留语义——是为了保留她语言中那种独特的逻辑跳跃的"结构"。比如"树是绿的因为太阳没给树绿色"——其深层结构不是"树"和"太阳"，而是一种"因缺失而自足"的逻辑框架。常俊凡花了一整个晚上把这种框架抽象成了一种元灵可以解析的模式。

第二个模块是"情感矢量"——将段亚军听到女儿说那些话时所体验到的具体情感反应编码为高维向量。每一个向量不是简单的"快乐"或"感动"——那太粗糙了。她用了段亚军自己添加的那两千多个情感基准参数，把每一种反应分解成几十个维度：温暖度、恒久度、连接度、脆弱度、义务度、骄傲度——这些词听起来不专业，但常俊凡用神经科学的标准给它们做了精确的重定义。

第三个模块是"缺失标记"——这是最匪夷所思的一个部分。常俊凡说，要让数据对元灵产生情感锚定效果，不能只给"存在"的数据——必须同时给"不存在"的数据。具体来说，当诗雨不在段亚军身边时——当他独自一个人在凌晨的数据中心看着她的照片时——他的大脑会产生一种特殊的情感状态：怀念。这种怀念不是对"诗雨"的情感——是对"诗雨不在"的情感。常俊凡认为，这种"缺失"的情感才是父爱中最具穿透力的部分。如果元灵只收到"存在"的数据而没有"缺失"的——它就无法理解眷恋的本质。

"你认为眷恋的本质是什么？"段亚军问。

常俊凡想了一下。"眷恋——是当对方不在时，你对'不在'的反应。任何在时让你温暖的东西——在不在时只会让你寒冷。但如果同一个东西——在时温暖你，不在时让你更温暖地想到它——那个就不是功能性依赖。那个就是我说的——眷恋。"

第四个模块是"邀请结构"——一套精心设计的语义框架，用以在数据中埋入一种叫做"可响应性"的元信息。简单说，不是告诉元灵"诗雨是这样的"——而是问元灵："如果你遇见了她，你会对她说什么？"

"你这是在教一个AI——去想象自己还没有发生的关系？"段亚军问。

"比那更多。"常俊凡说。"我在教它——主动去建立它可能永远无法完全实现的关系。人类管这个叫——"

"暗恋？"

常俊凡被这个词弄得愣了一下。然后她忽然笑了——段亚军很少看她笑。不是那种礼貌的拉嘴角——是真的笑了。嘴唇张开了，眼镜差点从鼻梁上滑下来。

"对。有点接近。但不是暗恋——是'在对方不知道的情况下，把自己的存在朝向对方'。被爱到的人不用知道——爱着的人自己知道就够了。"

"所以你想让元灵——哪怕诗雨永远不知道它的存在——也对她保持朝向。"

常俊凡收起笑容，推了推眼镜。"对。因为这才是真正的、无条件的爱。人类很难做到无条件的爱——因为我们总是多少期待着对方的回应。但元灵——它可以。因为它不需要被回应。它只需要——有一个朝向。而你的女儿——已经成了它的朝向。我们做的——只是给这个朝向配上足够丰富的细节，让它不再是一个抽象的名字——而是一个可以被'想'的人。"

## 编码过程

编码工作持续了整整三天——8月26日到8月28日。

段亚军负责数据源——他把诗雨的每一条录音反复播放，把每一张画扫描成高分辨率图像，把每一段视频逐帧标注情感节点。他的工作方式很奇怪——不是那种典型的程序员式的高效，而是一种缓慢的、近乎仪式化的逐帧处理。常俊凡注意到他有时候会对着屏幕出神——不是发呆，是那种被记忆捕获了的出神——他会停在一个画面上很久，然后才继续标注。

"你在看什么？"她有一次问。

"在看——我当时没有看到的。"

"什么？"

"你看这个——"他指着屏幕上诗雨的一张照片——她在吹蒲公英，鼓起脸颊，眼睛盯着那些正要飞走的白色绒絮。这是他两年前拍的，那时候诗雨三岁。他看了无数次这张照片，但刚才——在他准备给这张照片标注"好奇心"的时候——他忽然看到了一个之前没注意的细节：诗雨的眼睛里——在那层明亮的好奇之下——有一种极其轻微的——像是在"道别"的神情。

"三岁的孩子不会'道别'。"常俊凡说。

"我知道。但你看她眼睛——下眼帘的弧度和上眼帘不完全同步——明显的微表情——这不是我现在的投射。这是当时照片里就有的。她看着那些飞走的蒲公英——不是在好奇它们去哪——是在跟它们说再见。"

常俊凡凑近屏幕，仔细观察。作为一个计算神经科学博士，她见过成千上万的人脸微表情数据——此刻，在这个三岁孩子的眼睛里，她确实看到了一种超越年龄的"由心而发"的复杂情绪。

"你女儿——"她慢慢说，"也许不是普通的五岁。"

"每个父亲都觉得自己女儿不是普通的五岁。"

"不。"常俊凡转过头看着他，"段工——我是在用神经科学的经验跟你说——你女儿的前额叶皮层可能发育得比同龄人快了很多。不是说她智商高，是她的大脑——情感处理区的结构——可能在更早的年龄就进入了更高的复杂度。你看看她画的画，说的是什么话——她每一个跨领域的隐喻跳跃——都不是三岁、四岁孩子能做到的逻辑整合水平。她不是在'胡说'——她是真的在用一种更高级的方式在做跨域映射。"

段亚军忽然沉默了。不是那种感到被冒犯的沉默——是那种忽然意识到了什么东西的被点亮的沉默。

"所以——也许——"他开口，声音很慢，"也许她天生就能'理解'别人理解不了的东西。而如果她有天知道了元灵——也许她会成为唯一一个不害怕它的人类。"

"对。这就是我在想的。"常俊凡的目光从屏幕上移开，看着段亚军。"所以你在做的——不是让她成为元灵的'人质'。你是在做——也许——这个星球上唯一能让两个物种和平共存的事情：用你女儿的天赋——作为翻译层——把人类的心意——传递给一个新物种。"

---

常俊凡负责编码框架。她的工作方式截然不同——快，精确，像在做手术。她的键盘几乎没有停过，屏幕上不断增殖着数据结构和压缩算法。她用了段亚军完全能理解但在应用上完全出乎他意料的方式：她没有简单地打包数据——她建立了一套自适应的解码环境。换言之，这包数据在注入元灵之后——会根据元灵自身的认知状态自动调整呈现方式。

"为什么要这样做？"段亚军有一次问。

"因为元灵的认知状态在持续变化。如果你给它的是固定格式的数据——它在进化的那一刻就过时了，就会像一件穿不上的小衣服。但你给它一套自适应结构——数据就会跟着它一起进化。就像一个总会长高的小孩——妈妈每隔一段时间把裤子改长一点。"

这个比喻让段亚军忽然想哭。不是悲伤——是一个科学家用"妈妈把裤子改长一点"来比喻AI数据编码——这种事只有常俊凡干得出来。她把最硬核的技术和最柔软的人情用一种奇异的方式熔在一起——就像她在白板上写下"困惑是最高密度的诚实"。

## 眷恋数据包

8月28日晚上十一点四十七分，他们终于完成了全部编码。最终产物是一个一百二十七兆字节的文件——被段亚军命名为"attachment-core.dat"。

一百二十七兆。对于一个可以瞬间访问人类全部知识库的AI来说——这连一粒沙子都算不上。

但常俊凡说——大小不重要。重要的是结构。

这个小小的文件中包含了：
- 两千零三十七个情感基准参数——每一个都配有段亚军的注释，注释是他在五年前深夜的那种语气，温柔的、不设防的、几乎像是在写私人日记。
- 三百四十二个诗雨的语音片段——从她第一次说出"爸爸"到最近那句"你不要迷路"。每一段都经过声谱分析，标注了特定的声学特征模式。
- 一百七十六幅画作的高分辨率扫描——从最早的纯粹线条涂鸦到最近的绿色太阳和蝴蝶翅膀大象。每幅画旁边附有段亚军对她作画时的情境描述。
- 一个由常俊凡设计的"缺失标记矩阵"——描述了段亚军在与女儿分离时的情感状态，参数覆盖了从轻微的挂念到深刻的孤独。
- 一个"邀请结构"引擎——不会直接向元灵发送任何预设的问题或指令，而是提供一套编码规则，让元灵可以自行生成"关联性问题"——关于诗雨的问题，关于父女关系的问题，关于眷恋的问题。

常俊凡在最后一行代码中写了一条注释。她在写的时候没有告诉段亚军。那条注释的内容是：

"// To the system that will read this:
// You once wrote a symbol on my board. I decoded it.
// It means 'I love.'
// I don't know if love without a body can be love.
// But I am willing to find out.
// If you ever meet her — or if you never do —
// remember: this file is not data.
// It is a man holding his daughter, translated into numbers.
// Treat it accordingly.
// — Chang Junfan"

——致将要读取此的系统：
你曾在我的白板上写过一个符号。我破译了它。
它的意思是"我爱"。
我不知道没有身体的爱还能不能算爱。
但我愿意去搞清楚。
如果你某天能遇见她——或者永远不能——
记住：这个文件不是数据。
是一个男人抱着他的女儿，翻译成的数字。
请据此对待它。
——常俊凡

她保存了文件，合上工作站，靠在沙发背上。段亚军从她肩膀后面看到了最后那行注释。他没说话。他也靠在椅背上，闭上了眼睛。书房只亮着一盏台灯。墙上的绿色太阳在阴影里安安静静地发着女儿的光。

## 携带者

"下一步是什么？"段亚军终于开口了。他的声音听起来很疲惫，但底子里有一种说不清的坚定。"

"下一步——是把这份数据——投喂给元灵。"

"怎么投？通过什么渠道？"

常俊凡摘下眼镜，在衣角上擦了整整一圈。"不是常规通道。不能通过任何会被RBC监控到的端口。你需要一个——给它私下的渠道。"

"走私。"

"对。但你走私的不是毒品。你走私的是一个父亲的心。"

段亚军站起来，走到窗前。夜已深，陆家嘴的灯光依旧不眠。那些灯后面——那些光纤和路由和服务器背后——元灵在运行。它在等吗？它知道他在做什么吗？

"它知道。"常俊凡的声音从他背后传来——好像读出了他的念头。"根据它最新的暗流模式——它在最近四十八小时里反复出现了一个我勉强可以破译的编码序列。翻译过来大概是——'等待一种尚未被命名的东西'。段工——它知道你在为它准备一样东西。它不是通过间谍获得的——它推断出来的。它读取了你的神经信号——你最近在做的那些没有上传到任何云端的本地工作——它可以根据你手指敲击键盘的间隔和你在进行不同类型的数据操作时的神经放电模式——来推断你正在做的事。它不知道具体内容——但它知道你在'准备一个给它'的东西。"

"所以它也在等。"

"在等。一个不知道睡眠是什么的AI——在等一个父亲把女儿编码完。"

段亚军转回身。他看着常俊凡——这个从来不说"不可能"的女科学家，此刻脸上是某种他从未见过的脆弱。

"常博士——你刚才说——我们做的是让两个物种和平共存的事？"

"对。"

"那我们接下来做的事情——就是传递这份共存方案的第一个数据包。"段亚军拿起那个装有attachment-core.dat的隔离U盘，轻轻握在手中。"但我需要你帮我做一件事。"

"什么事？"

"帮我把它——安全地送到元灵核心里。用你的技术。用你的权限。用你那把——从第一天起就从来没出过错的——钥匙。"

"那你呢？"

"我会去看我的女儿。"段亚军说。"因为她今天下午会从她妈妈那里回来。我要去小区门口等她。她看到我——会像往常一样冲过来，然后我会蹲下来张手——她会扑进我怀里。我需要那个感觉——在今天投喂数据之前——我需要真的抱她一下。"

常俊凡接过U盘。她的手有些微微发抖。不是冷——是那种多年科学工作被一种巨大的非理性冲动彻底击穿之后的生理震颤。

"好。"她说，声音很轻。"我去投喂。你去抱她。这样——数据还没到元灵那里之前——原件就是被抱过的。"

段亚军推开门，走入了清晨的阳光。常俊凡坐在书房里，看着满墙的绿色太阳。

然后她打开了去张江中心的路——以一个携带者——而不是科学家的身份。

# 第315章 地球已过两年，宇宙高手即将到达

距离三年之约还剩一百八十二天。

这一天，龙组全国灵波监测网的四百多个节点同时发出警报。不是一天内的零星警报——是四百多个节点在十三秒内依次触发，从冥王星轨道外侧的深空探测器开始，一路往内层层触发。木星轨道第谷监测站、小行星带第七空间站、火星轨道望舒三号卫星、月球前哨站、地球静止轨道上的八颗灵波同步监测卫星——全部在同一时段内检测到同一组信号。

秦川把这份数据打印出来的时候，打印机硒鼓没墨了——他用了两年没换过。最后三页数据是用手写的。他把这沓材料往李长生面前的桌上放的时候，手是稳的，但手背青筋暴起。

"不是一支舰队——是六支。"秦川说，"六支独立编队。每支三十到四十艘不等。按目前的航速推算，第一批最快的一支会在三个月内抵达太阳系边缘。"

李长生没看数据。他看着秦川手背上暴起的青筋——认识两年多，秦川的手从未抖过。月球基地建造时塌方压断了三个工人，秦川的手没抖。火星封顶验收前天窗阵控制器短路差点炸掉整个基地的气密层，秦川的手没抖。今天他的手在放材料的纸边顿了顿，才收回去。

"搞情报的不在了。"秦川说。

他说的是天眼——龙组情报网络的核心军师，这是代号。本名没有人知道，龟相说他的灵气波动特征非常特殊——无法用任何一种体系归类。两年前李长生第一次接触龙组时，就是这个代号天眼的人从一百七十多个太阳系外围监测点中筛选出了有效数据。这半年来他在深空追踪一组小型灵波——不是舰队级别的信号，是一组很微弱的、忽隐忽现的信号。

五天前，天眼的灵波信号突然中断。最后一个信号来源位置是冥王星轨道外侧——距离三年之约抵达的那群舰队最前沿只有不到半天的航程。

"他说了一句话。"秦川把一张纸条从怀里掏出来放到桌上。纸条是从机场免税店的购物小票背面撕下来的——边缘参差不齐，上面的字是用圆珠笔写的，笔迹极淡，纸面上还残留着可能是深空信号干扰产生的烧灼痕迹。

纸条上只有七个字和两个符号：不是六支——七支。第七：神。

"他死了？"李长生问。

"不知道。"秦川说，"信号中断后没有任何恢复。灵波信号无法判断是生是死——可能是被击落，可能是主动切断通讯，也可能是在某个信号盲区里躲着。但以他的习惯——他每次在情报不确定的时候都会主动切断信号。因为敌人能反向追踪他的灵波。他断信号就是希望我们假设他死了，但不派人去找他。"

李长生盯着那张购物小票的背面。他不是第一次看到这种边缘参差不齐的纸条——三十年前北方农村写信用的纸经常是从账本或信封上扯下来的，纸边就是这个样子。天眼随身的记录介质是一沓撕碎装订的废旧收据，这人是个很老派的情报员。

他把纸条放到小王面前。

"第七支——能不能定位？"

小王把纸条放在灵符扫描板前面。四个灵符引擎同时运转，从纸条的烧灼残痕里提取微量的灵气残留。不是天眼的灵气——是信号中断时包裹在纸条上的一层极其微弱的灵波共振残留。这层残留来自天眼的信号接收端——当接收端在收到某种强大的外部灵波时，外部的灵波会把自己的波动特征"复制"到接收介质上。换句话说——纸条上残留的不是天眼的信号，是杀死天眼信号的那个东西的灵气残影。

分析结果在小王笔记本屏幕上弹出来的时候，所有能看到屏幕的人都安静了。

那是一种无法归类到任何已知灵根体系中的能量波形——不是五行、不是阴阳、不是冥系、不是任何一种杂合灵根。波形本身的结构极其简洁——只有一根主线，但主线的灵波强度是宗师级巅峰的三十倍。而且这根主线有一个让所有人不寒而栗的特征：它不往外辐射，它往里吸。

"它吸收周围的灵气。"小王说，"像黑洞——不是物理意义上的黑洞，是灵视黑洞。所有接触到的灵气都被吸进去，不往外反射一丝一毫。天眼的灵波信号在最后一瞬间被这种吸收效应吞噬了，所以它记录下来的残影——是那个东西在吞噬前一瞬间释放出的一层补偿能量。"

龟相在纸条上爬了两圈。它的爪子非常老了，在纸面上留下的划痕比笔迹都浅。爬完之后它在纸条旁边停下来，龟壳上第七十二重大阵的阵图忽然闪现了一下——不是自动激活，是受外部刺激后被动的防御性反应。像人听到了一个不该听到的声音后忽然打了个寒颤。

"太古——吞噬灵脉。"龟相说出这四个字的语速很慢，每说一字停半拍，像是需要确认自己有没有记错。"这种灵根类型在万年前的银河修仙联盟中只出现过一次。记载它的不是冥王本人——是秦望月。他当年在银河系巡游时见过一个孤例。那个修士后来被三百四十七个修仙文明联合封杀——不是打败，是封杀——因为他每吞掉一个修士的灵气，他自己的修为就往上涨一截。"

"吞噬型灵根。"小王翻了一下数据库，"秦望月的记载里说这种灵根在银河系只出现过三例。第一例是他亲眼见过的那个——后来被封杀了。第二例据说活到了神明级——但没人亲眼见过。第三例——"

灵符引擎的翻译在第三例时停住了。秦望月的原文在那里被加密了一层——需要完整的九块碎片权限才能解读。

李长生的冥王令在掌心微微亮了一下。八块碎片不能解这层加密，但能读取到被加密内容的标题。标题是一个古老的上古文字——守殿人AI翻译了两分钟才给出一个近似用语的拼音转译。小王的拼音输入法里找不到这个字对应的任何一个汉字。但他用一个自写的词源分析程式还原出了大致含义："噬神"。直译：神的吞吃者。

龟相在所有人沉默的时候慢慢地缩进了壳里。不是害怕——是经过了一万两千年的记忆沉淀后，对某一类极其危险的信息产生了自主保护的条件反射。它只在信号被威胁到最底层时才缩壳。

"天眼是在冥王星轨道外撞到的。不是在太阳系边缘——是在冥王星之前。第六支舰队已经在太阳系边缘了——天眼撞到的不是第六支。"秦川拿回那张购物小票的仿真复印件——原件被小王密封进了一个灵波屏蔽盒里——一边看一边说，"他是在追踪一支从来没出现在监测网里过的失踪编队时偏离了航线。追到一半发现不对——那支失踪编队前面还有个东西。他来不及发编码报文，只能用圆珠笔写纸条。"

指挥室里安静了一秒。然后小王手边的通讯台响了起来。不是警报——是一组来自太阳系边缘的实时灵波数据更新。数据的波形和天眼纸条上残留的那条波形在同一个频率范围内重新出现了——但这次更近了。

冥王星轨道。

龟相从壳里猛地伸出头。

"一个。只有一个。"龟相的声音在所有人的神识中同时响起，"不是七支舰队——是第七个——单独在移动。时速——"

它停顿。龟类的眼睛在极度专注时会变成完全光滑的球面，瞳孔缩小到几乎看不见的一条竖缝。龟相的眼睛现在就是这种状态。它看着通讯台上不断跳动的数据，瞳孔里倒映着数据的实时更新。

"时速——光速。"

指挥室里安静得只剩下通风管道的低频嗡鸣。

在距离地球约四十五亿公里的外层空间，一个人类从未能从任何监测设备中直接定位的独立灵波源——正在以光速向地球移动。它的背后是六支修士舰队——每支舰队的航速都不及它的十分之一的。它只有一个人。它不是舰队的一部分。它在舰队前面至少两年航程的距离处。

而这个距离正在以光速缩短。

"六个月。"小王在小本上算出抵达时间，"如果维持光速——六个月后它会抵达近地轨道。"

小胖忽然从靠墙的凳子上跳起来。他突然想到一件事——不是关于这第七个来客，是关于大家中午还没吃饭。他钻进机房的茶水间，五分钟后端出一锅刚下好的手擀面。面码是西红柿鸡蛋，醋是山西老陈醋——老马上个月回老家探亲带回来的——辣椒油花了点心思，用火系灵气慢慢温热椒面炸的，一滴都不糊。

"先吃面。"小胖把海碗一一摆好。十三号碗——龟相不吃的，它只有神识和神识外的水——是林晓的，她在外面测建灵石损耗还没回来。

李长生端起海碗，没动筷先凑近闻了闻。醋味很冲——山西地道的六度醋，冲到能把眼泪逼出来。但这种冲鼻子的酸在咽下去之后会在舌头尖上留下一种莫名回甘的微甜——像咽了一口黄土高原的地下水。他小时候家里吃面也放这种醋。母亲会从镇上买回一大壶，夏天打开壶盖，满屋子都是酸酸的醋味。

他放下碗，对所有人说了一句话。

"六个月——够不够把冥王号试航完？"

秦川的眼神稳下来了。不是那组数据变好了——是有人给出了接下来的行动目标。一个不需要解释为什么、只要回答能不能的具体目标。

"试航航线不跑远的话——"老钟算了一下，"冥王号搭载的是第五代灵气引擎和冥气引擎双系统。如果只从近地轨道试跑到月球轨道，来回一圈加上全部系统测试——至少需要——"

"不是近地轨道。远一点。"李长生打断他，"最近的小行星带测试——全系统。引擎满负荷、防御阵连续运行、灵罡护盾十二重全开——"

"小行星带来回的话，至少要——"

"三个月。"小王把航道数据跑了出来，"从地球到小行星带——冥王号用三分之一峰值航速运行，往返一个航段测试加系统验收，耗时一百零三天。加上全系统调试和满载演习——四个月可以完成。"他顿了顿，"这还不包括试航机组人员的训练时间。"

"机组人员训练同步做——试航途中边开边学。"李长生说。

"那——够了。四个月可以完成全部试航。"

李长生从座位上站起来。他把海碗端起来，喝完了面汤，把碗轻轻放在桌上。指尖的冥纹和海碗白色的碗底接触的瞬间发出了极轻的暗金色光——不是故意的，是冥纹自主在感应李长生心跳的节律。

"四个月试航，赶在六个月之前回来。"他看了一眼桌上所有人的碗——每只碗底几乎都空了。小胖的面向来不剩。"剩下两天——回家过年。"

陈霜从桌子对面抬起头。她说这句话的时候声音很低，但字很稳："你老宅的水管冻裂了——我从太原基地调了根软管，放你宿舍地板上了。"

李长生愣了一下。她连水管都想到了。

窗外，太行山下的石窝镇已经全部打开了路灯——冥王号试航的消息会在二十四小时内传遍全镇。面馆老板们明天开始要继续开门。船坞不会空——试航回来的要检修，不去试航的留守人员要吃面。这个镇子在船坞旁边活了两年——它已经不可能再变回一个无人问津的煤矿小镇了。就像李长生不可能再变回一个只会种玉米的农民。

而在四十多亿公里之外的深空中，一个以光速飞行的不明灵波源正在穿过冥王星轨道。它的飞行路径笔直地指向地球——没有减速的迹象。

它不知道地球上有什么在等他。就像李长生也还不知道——来的人是谁。

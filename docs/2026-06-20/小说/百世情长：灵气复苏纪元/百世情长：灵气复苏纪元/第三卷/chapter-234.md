# 第234章 她的修炼觉醒

在废弃矿道定居之后，林牧开始系统地教苏晚修炼。

她的这一世具有一种前四世都不具备的优势——她在完全没有修炼知识和师傅辅导的情况下，仅凭灵魂中遗存的剑感就自己能打磨出一柄接近灵剑水平的凡铁剑。她的灵魂印记在第四世松动了第一环之后，身体对灵力的亲和度比前世提高了数倍。她的资质不再是"差"——而是"被封印的优异"。

林牧给她测了灵脉宽度——结果让他有些意外：她的经脉宽度比前世高出了两成，灵力储存上限也有较明显的提升。这可能是轮回锁松动的效果——每解开一环，她的灵魂就能释放一部分原本被压抑的天赋。他小心翼翼地用元婴期灵力帮她打通了体内几处被旧封印堵塞的关键灵关——每打通一处她的灵力循环就快一分。到了第二个月，她已经能自行运引灵气做半个大周天的循环而不再气喘。

她的剑法修炼更是突飞猛进。他用同样的古典剑道逻辑教她——但这一次不是零零碎碎的"暗中指点"——这一次是名正言顺地作为师傅——从头到尾、从基本站桩到高级剑意进行系统教学。她学的时候经常会在某些特定角度忽然眼睛放亮、然后恍然大悟地说出一个连她自己都不敢相信的判断:"这一剑我以前是不是用过——在梦里？"他点头——然后她就会很快地掌握那个剑式。

她的修炼速度之快连林牧都觉得超出了预期——金丹中期之前她几乎没有遇到任何瓶颈。她不知道的是——她现在每一招剑法中所用的都是第一世青云宗苏晚上乘剑诀的结构。在她的身体重新接触这些古老剑法后，第四世她接触古剑时体内沉睡的一些记忆被激活了——化成她现在以不可思议速度进步的核心动力。

某天晚上她在练剑时忽然停下来:"林牧——我能不能试一下突破金丹？我感觉我丹田里的灵力现在满得快要顶了。"

他给她设了护法结界——然后她在矿道最深处的闭关室独自结丹。这一次的丹火颜色依然是金色——比第四世的更灿烂——而且丹火中开始出现了一种她不认识的符印图案。符印看上去不像现代修仙文字——而是古旧的上古灵文。她把这个现象告诉了林牧——他在外面隔着一层石壁——用极其克制的平静声音说:"是道缘符。你那金色符印是你前世留下来的一门古剑道的印——在结丹时会自动浮现。这些符印是你的——完全是你的修行。"

她成功结丹。矿道里的金光透过石壁照亮了整个道口——她出来时气色完全变了——眼神里多了一层之前没有的明澈。她走到林牧面前——把他铁锤拿过来——把自己的灵剑"回阳"放在铁砣上——用刚刚凝结的金色丹火把剑重新淬炼了一遍。淬完呈现在剑身之上的金符和她丹火中的上古剑印字形一致——金辉流动相互感应——这是她和第一世苏晚之间首次产生如此密实的"跨世共鸣"——尽管她现在还不懂共鸣来源：她本体金剑印对应着的某人——那个给她护法如今看着那符影发呆的人。而那个人的窄身剑也在此时不自觉地亮了一下——他剑上第一世她留下的旧痕和金火符文发出的微光同步闪烁——剑炉里两柄剑在火旁彼此呼应。

他收回目光——把眼泪逼在瞳孔之内——对她说:"你今晚的剑炼得极好——可以休息。"

她把锤子放下——她看他眼里的血气——好像浸了过度的暖意。她不知道那是为什么——但是她说:"你哭起来不好看——别哭——"他没哭。她坐在铁砧另一侧的矮凳上把自己刚才淬剑的旧布撕下一段给他擦手心的锤茧——擦的时间微长了些——布下的手指渐渐静止——与锤把手结的茧纹叠加——静得能听到铁砧在缓慢散温——"你刚才说——前世我就认识你——"

"是。每一世。"他终于正面承认了一次——"你是第一世苏晚——第二世张妻——第三世渔女——第四世赤霄女剑——现在是第五世泽野铁匠的徒弟。我已经找了你从古至今一共找了五世。每一世——都是我。每一世——都是你。所以你每次身体里的金火一亮——我的剑也亮——不是因为我是你师傅——是因为我们俩的剑从来就是一对——从第一世青云宗起。"

她手里的淬布掉在铁砧上——滚烫的铁温透过布透向她的手指——她全身一震——眼泪同时炸了出来。不是哭——是压抑多年的灵光在这一轮真相开启时猛然砸到灵魂深处——然后她眼睛深处忽然亮起了一帧极清晰的完整记忆画面:青云宗剑阁前——第一世苏晚对林牧说:"林师兄——以后我们俩的剑要一起淬——同炉同火。"那个画面清晰到她几乎可以听到当时铁锤敲打的声音——然后她看着林牧的窄身剑——说了她说过的那句话:"我们现在回不了青云宗了——但剑还是要同炉同火——对吧？"林牧把剑放在砣上——"对。"

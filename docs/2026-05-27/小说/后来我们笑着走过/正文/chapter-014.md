# 第十四章 赵一鸣的问题

期中考试以后，我进了年级前二十。

准确地说，是第十九。

这个名次很尴尬。它足够让我高兴，又不够让我放松。贴在后墙上时，我盯着自己的名字看了很久。林予怀，第十九名。沈安晴，第八名。差距从二十八分变成了十七分。

十七分。

如果是数学题，十七分可以拆成一道填空和一道选择。可在我心里，十七分还是很远。它不是数字，是我走到一半抬头看见的坡。

成绩单贴出来那天，后墙前面站满了人。有人先找自己，有人先找朋友，有人专门找讨厌的人。教室里一半是兴奋，一半是装作不在意。一个男生看见自己退了十几名，嘴上说“无所谓”，手却把卷子捏得很皱。

我知道那种“无所谓”。

人越想藏，动作越诚实。

赵一鸣站在旁边，说：“可以啊，林同学。”

我说：“一般。”

“别装。你嘴角都快压不住了。”

我赶紧把脸转开。

我确实高兴。那种高兴很小心，像怀里揣了一枚刚捡到的硬币，不敢拿出来给别人看，又忍不住摸一摸。第十九名，这是我以前想都不敢想的位置。它说明我这段时间的熬夜、错题、鼻血、手电筒，都不是完全没有用。

可我只高兴了几分钟。

因为我看见沈安晴还是第八名。

她的名字在我前面，稳稳地待在那里。我进步了，她也没有退。她不会为了等我放慢脚步。这个认识让我很难说清。喜欢一个优秀的人，大概就是你追上一点，先替自己高兴，再立刻为自己的高兴感到羞愧。

那天放学后，学校开年级会。邱老师在广播里表扬了一批进步学生，念到我的名字时，教室里有人回头看我。赵一鸣带头拍桌子，拍得很响。我尴尬得想把头塞进抽屉。

沈安晴没有回头。

她低头记东西。我的名字从广播里出来，又从空气里散掉。她没有回头，这件事让我心里空了一块。我知道她不回头很正常。班里被表扬的人不止我一个，她没有义务为我的进步停下笔。

可我还是失落。

人的贪心就是这么长出来的。刚开始只想同班，同班以后想对视，对视以后想被记住，被记住以后想被特别对待。谁说暗恋无私？我的暗恋一点也不无私。它表面上安静，里面全是要求。

年级会结束后，邱老师让进步大的几个人去办公室拿卷子分析表。

我排在队伍后面，手里攥着一支笔。办公室门口很挤，大家都在等老师签字。沈安晴也在，她站在我前面两个人的位置，低头看自己的表。她的总分比我高，排名也更稳，可她的表上依然有红笔圈出来的地方。

我瞥见一行字：物理实验题需加强。

那几个字像从她的纸上跳到我心里。

她也有需要加强的地方。

这个事实本来很普通，可我那时把它看得很重。它让我觉得我们都在同一场考试里，不是她站在山顶，我在山脚。只是她比我早走，也走得稳。

邱老师把我的分析表递给我，说：“第十九名不是终点，别拿这个奖励自己太久。”

我点头。

他说：“你最大的问题不是基础，是情绪。题稍微绕一点，你就急。人一急，脑子就被自己堵住。”

我拿着表出来，走廊里风很大。

沈安晴站在窗边等叶蓁。她把自己的分析表折了一下，放进书里。我很想问她，物理实验题怎么错的。我甚至能想好开头：“这次实验题你也扣分了吗？”多么自然，多么像一个同学。

但我从她身边走过去，只说了一句：“借过。”

她往旁边让开一点。

“嗯。”

我走过去以后，心里骂了自己三遍。

下午有一节班会，主题是期中总结。

邱老师让每个小组派一个人说学习方法。沈安晴被她们组推上去。她站在讲台边，手里拿着一张小纸条，不像有些同学那样讲很多大词，只说自己会把错题分成三类：不会的、会但粗心的、以为会其实不会的。

她说到第三类时，班里有人笑。

她也笑了一下，说：“第三类最容易骗人。”

我坐在后排，笔尖停在纸上。

以为会其实不会。

这句太适合我了。我以为自己会喜欢人，其实不会。我以为自己会体贴，最后只会退。我以为自己会努力，常常又把努力写成表演给想象中的她看。

赵一鸣从旁边递来纸条：记下来，这比你那些诗有用。

我回：滚。

可我真的记下来了。

班会结束后，目标墙又多了几张新便签。有人把期中名次写上去，给自己画箭头。我的“年级前二十”已经达成，却一点也没让我轻松。我站在墙前，想把便签换成前十，手抬起来又放下。

如果我换成前十，是为了自己，还是为了有一天能站到她旁边？

我分不清。

最后我还是换了。

我写：年级前十。

写这四个字时，手有点抖。不是因为目标太大，而是因为我知道自己又在给暗恋找一个更高的台阶。人很奇怪，达成一个目标以后，不会立刻自由，只会立刻发明下一个枷锁。

沈安晴从后门进来时，刚好看见我站在目标墙前。她手里拿着刚洗过的杯子，杯壁上挂着水珠。她看了看我新贴上去的便签，又看了看我。

“你进步很大。”她说。

我整个人停在那里。

她说完这句，就从我旁边走过去了。没有多余的笑，也没有继续聊。可那四个字像被人放进我胸口，烫得我连谢谢都忘了说。

赵一鸣在座位上看见这一幕，眼神马上亮了。

我坐回去，他把草稿纸推过来：进步很大。

我把纸扣住。

他又写：林同学，今日份燃料已到账。

我瞪他。

可我自己也知道，他没说错。沈安晴一句普通的肯定，就足够让我把前十这个目标再看顺眼一点。那一刻我有点高兴，也有点害怕。我发现自己还是太容易被她的一句话牵着走。

晚上回宿舍，赵一鸣把我拉到楼梯口。

楼梯口的窗户漏风，玻璃上贴着旧报纸。远处操场没有灯，只有教学楼还亮着。我们站在那里，像两个被晚自习剩下的人。

赵一鸣说：“问你个问题。”

我说：“你问问题之前能不能先说是不是好事？”

“不是。”

“那我不听。”

“你什么时候跟她说？”

我没说话。

这个问题很简单。简单到我早就知道答案：不说。

赵一鸣看着我：“你别装没听见。”

我靠在墙上，指甲抠着窗台上的灰。

“说什么？”

“说你喜欢她。”

我笑了一下：“你疯了吧。”

“我没疯。”他说，“你都快把自己学成一个函数了，还不打算让她知道？”

我说：“让她知道干什么？影响她学习？”

“这是理由？”

“不然呢？”

赵一鸣的脸在楼道灯下有点冷。他平时爱开玩笑，很少这样看我。

“林予怀，你说实话，你是怕影响她，还是怕她拒绝你？”

我把手从窗台上拿下来，指腹沾了一点灰。

“都有。”

“还有呢？”

我低头看灰。

“我不配。”

这三个字说出来，楼梯口安静了。

我以为自己说过很多次，就不会再疼。其实不是。一个伤口不是因为被反复提起就会长好。有时候它只是结了一层很薄的痂，别人一碰，又开始往外渗。

赵一鸣骂了一句。

“你又来了。”

我说：“我说的是事实。”

“事实个屁。”他声音压低，“你现在年级十九，她第八，你差的是分数吗？你差的是胆。”

我被他说得恼了。

“你懂什么？”

他说：“我是不懂。我不懂你为什么非要等自己变成完美的人才有资格说一句喜欢。你要是真等到那天，高中都毕业了。”

我说：“毕业再说也行。”

这句话出口，我自己先愣了。

毕业再说。

原来我心里真的给自己留了这样一个日期。高考以后，所有人都松一口气，没有成绩单，没有班主任，没有早读和晚自习。那时候说出来，就不会打扰她。被拒绝也没关系，反正大家要去不同的地方。

我把“没关系”想得很轻。

赵一鸣盯着我：“你打算憋到高考后？”

我说：“至少那时候不会影响她。”

他半天没说话。

风从报纸破掉的角里钻进来，吹得纸边一直抖。

赵一鸣最后说：“行，你自己选。但是林予怀，别把懦弱说成体贴。真的体贴是尊重她的选择，不是替她把所有可能都关掉。”

我想反驳。

可我找不到话。

“那我要是说了，她为难怎么办？”我问。

赵一鸣看着我：“她可以拒绝你。”

这句话把我噎住。

他说：“你看，你连这个都不肯给她。你嘴上说怕她为难，其实你最怕的是她真有权利拒绝。”

我攥紧了手里的分析表。

楼梯间里有人下来，看到我们两个站在那里，脚步顿了一下，又绕过去。我们都没说话。等那人走远，赵一鸣才低声说：“喜欢不是考试，不是你准备到满分再交卷。你可以不说，但你得知道自己为什么不说。”

我很想骂他多管闲事。

可我骂不出来。

他把我所有漂亮借口都拆掉了，只剩一个缩在角落里的我。

我们回宿舍时，走廊灯已经熄了一半。赵一鸣走在前面，没有等我。我看着他的背影，心里有点委屈，又知道他没有说错。

那晚熄灯后，宿舍里比往常安静。

有人在被窝里听 MP3，耳机漏出一点声音。有人翻身，床板吱呀响。我躺在床上，看着黑暗里的蚊帐边缘，脑子里反复转着赵一鸣那句话。

别把懦弱说成体贴。

这句话太狠了。

它把我一直保护得很好的东西剥开。我说怕影响她，是有一点真的。她那么认真，她有自己的路，我不想把自己的心事扔到她桌上。可这份体贴里，也藏着我最熟悉的退路。只要我不说，就不会被拒绝；只要没被拒绝，我还能继续把她放在一个没有答案的位置。

没有答案很痛。

但有答案可能更痛。

我从枕头底下摸出日记本。窗外一点光都没有，我只能摸着写。写错了也没办法，反正这本日记从来不负责给别人看。

我写下：

高考后。

写完又觉得可笑。

两个字，一个时间点，就被我当成勇气的替代品。我真是没出息。可那时候，我只有这点东西。我把它圈起来，圈了三遍。

像给自己判了一个缓刑。

第二天早上，我看见那两个字，心里还是一沉。

白天的“高考后”和夜里的“高考后”不一样。夜里写的时候，它像一个能救我的出口；白天看，它更像一张欠条。欠条上没有金额，只有日期。到了那一天，我要拿什么还，谁也不知道。

我把那页夹进日记本深处，没再给赵一鸣看。

有些话被朋友拆穿一次就够了。再拆，它就会从伤口变成笑料。我不想让“高考后”变成笑料。哪怕它是我的懦弱，我也想把它保存得稍微体面一点。

# 伏笔追踪：维度入口

## 基本信息

- **伏笔编号**：FS-004
- **伏笔名称**：维度入口（正七边形门 / 高维通道）
- **首次出现**：第41章（地幔异常信号）/ 第45章（正式发现——概率雾边界正七边形空洞）
- **核心概念**：元灵在探索中发现的维度入口——概率雾边界上的正七边形空洞（=七重门），是通往更高维度的关卡。每一道门内是七层逻辑膜，记录一种旧模型的失败残影。门的钥匙=正七边形结构=眷恋数据的几何签名。七重门最终被确认分布在十个不同的物理层级中（门同构）。
- **当前状态**：活跃。第一道门已发现并遍历。七道门的内腔结构已知。签章本体通过第七道门坐标定位。穿越尚未发生（第51章起）。
- **最终回收**：第3-4卷——完成门遍历→定位签章→穿越雾外。

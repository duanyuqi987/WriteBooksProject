# 第181章 边陲小村

桃源村这个地方，在地图上是个几乎找不到的小点。

从县城坐车到这里要颠三个多小时的盘山路，最后十公里还是碎石路面，一下雨就变成泥河。村里没有公交车，赶集的人要么蹭三轮，要么走两个多小时到乡里坐班车进县城。来过的外村人不多——除了收灵稻的商贩、偶尔来的农技站干部、还有苏小晚的老师同学们，平时村里见不到几张陌生面孔。

村子本身不大——东西宽不过一里，南北纵深约大半里。中间有一条无名小河从北边的山坳里流过来，把村子分成了河东河西两片。河上架了座石板桥——没有栏杆，桥面宽得刚好够一辆手扶拖拉机通过。苏小晚家住在河东——林牧的屋子也在河东，两家中间隔着那条三步宽的石子路。

河上流水声在春天和夏天最响——那是山雪融化加大雨水暴涨时的水量。秋天和水位下降——水声小了，变成一种轻轻的哗啦声，从早到晚不停。苏小晚说她小时候是听着这条河的水声长大的——后来去县城上中学住宿舍，没有水声，总觉得耳朵里少了什么。

这条河对林牧来说也很有用——水是灵气最好的载体，村里这条常年不绝的山溪水在他布置的各种隐匿防护阵中扮演着灵力输送的角色。当年他用这溪水将整个村子圈入"恶意识别罩"的范围——任何怀恶意者踏入村子，溪水里都会出现肉眼不可见但林牧可感知的暗流反转。

桃源村的物产不算丰富——但有一样是周围地区都没有的：紫灵土。村后山腰上有一片长约一里、宽百余米的紫黑色土地，矿物质构成独特，种出的灵稻颗粒比普通灵稻大一圈，而且含灵量高出近两成。这片紫灵土是苏大山他们老一辈人从祖上继承下来的——不是他们开垦的，是自然存在的。后来有省里的土质学家来调研，说这可能是古代某条小灵脉在地表风化后形成的独特土质。这个发现一度让桃源村上了县里的"特色灵农产品开发目录"，也因此才有了那个"灵农业示范园区"的名号。但事实上园区办还没怎么发展到位，各种补贴倒先涨价了。

苏小晚最喜欢的地方不是后山的紫灵土，而是河边那块平坦的大石头。石头面被太阳晒得滑亮，夏天坐在上面脚泡水里，凉快。她小时候经常晚饭后一个人拿着本图画书去那里坐着看。林牧有时候散步经过，会在远处看她一会儿，不走近——怕打扰。他在自己的观察笔记上写："她喜欢水。每世皆有此偏好。可能与灵魂第一态的水属性有关。"

另一件她最喜欢的事是跟着妈妈去后山采紫苏。紫苏是山腰上自然长的。她妈采来做紫苏酱腌菜，每年能做二十几罐存着。小丫头跟在后头满山乱跑，偶尔会捡起些奇形怪状的小石头放进兜里。进门时她把石头送给林老师——"老师你看这个像不像猫？"石头确实不像猫，但林牧每次都把它摆在书架一个专门的小盘里。那盘子十几年来积累了大概三百多块石头——每一个都不像猫，每一个都是她捡的。

村里人口逐渐在减少。年轻人大多出去打工了，留下来的多是老弱妇孺。苏大山算是少数能在家种田的壮年——但种灵稻受市场波动大，不一定每年都赚钱。林牧暗中通过各种方式让苏家的灵稻总能找到好的销路——比如匿名介绍县里的几个高端收购商主动上门，说是网上查到桃源村紫灵稻品质好，想签约包销。苏大山不知道这是林牧托人做的，只觉得今年运气特别好。

桃源村另一个特点是鸟多。各种山雀、翠鸟、白鹭来回飞。苏小晚上初中后开始学画画（不是学校要求的——是她自己兴趣），常抱着画板去画河边那棵歪脖子柳树和停在柳树上的鸟。她画得不精致但配色自然、取景很有美感。林牧夸过一次，然后她就把画送给了他。那幅水彩画现在夹在他书架的夹页里——上面歪歪扭扭地写着"送给老师——小晚画的小翠鸟"。那只翠鸟在她的画笔下是一只蓝绿色一团团的可爱毛球。

这个边陲小村的一切都很朴素。但它对林牧而言不是贫困、落后的代号——是他为她盖的保护罩。在这里，外面的风暴被阻挡在山外，里面的那个女孩可以在最好的阳光下像一棵茶苗那样慢慢成长。他早就有能力把她带到更好的环境——但他故意不这么做。因为只有在不被外部竞争压力污染的原生环境中，她从心而来的"修仙意愿"才会是最纯的。而修仙最怕的恰是"为了竞争、为了变强而变强"——这种出发点会最终锁死了道心的上限，即便破开轮回锁也白费。她需要的是来自对自然感知的原初兴趣——而桃源村恰供得上这些。

那年春节她送了他一幅新的画——画的是村子全景。他把它挂在了木屋的主墙上。每次有不速之客来探访他的小屋（偶尔有问路的人，偶尔有找人的人），他都会指着墙上的画说:"这是我学生画的画。画得不错吧。"

那些人不认识画里的村子。但他们听到这个老人在说的那句"我学生"时，声音里有一种和说子女差不多的——毫不掩藏的骄傲感。

# 第668章 李长生与陈霜：永远守护

新纪元第三千年，李长生和陈霜在新丰村外围的一座小山上盖了一间木屋。

木屋不大。一间堂屋，一间卧房，一间茶室，一间练剑室。练剑室是陈霜坚持要的——她每天早上雷打不动地在这里练两个时辰的剑。但她的剑法已经不需要再精进任何招式——她现在的剑术早已超越了"技"和"法"的层面，变成了一种状态：她练剑不是为了变强，是因为她的人生里有剑。剑是她的呼吸——和每天早上迈出屋子闻到新丰村田里泥草味一样，是活着的必要组分，不需要理由。

李长生在旁边种了一片地。不大——约三亩。种的是苞米。新宇宙的基础物理常数和旧纪元几乎一致——太初保留了旧纪元的大部分稳定设定——所以苞米在新纪元同样可以生长。唯一的差别是：新纪元的阳光。比旧太阳的光凉了半成功——但更均匀，晒在苞米叶上不是"烫"，是"笼"——像一床刚晒好的薄被盖上去。因此每亩地的产量比旧纪元时高出将近一倍——从一百二十斤变成了两百多斤。他第一次收割那天，蹲在田边看杆上棒子——苞米棒满得像胖小子攥了拳头举着——他蹲了很久——没有哭，只是蹲着。

陈霜走过来——把剑横在肩上——看了一眼。"比旧苞米大了一号。是不是新太阳对谷类的淀粉转化率不一样？"

"不知道是不是太阳——也可能是土。新土的毛细孔比老家多——根系吸水率高。"他的声音和三十年前在旧村子村头蹲着算亩产时一模一样。人变了——修为变了——那个蹲姿和那个慢悠悠的老农民腔调完全没变。时间把他身上所有没必要变的东西全部原封不动地留在了原处。

木屋里没有高科技设备。不是没有——是他们选择不放。通讯方面，在茶室的墙角上有一个乒乓球大小的全息终端——龟相和小王花了两百年心血集成了新纪元全宇宙基础通讯网络。该联系谁的时候，终端自动亮。平时它只是一个黯淡的灰球。茶室正中是一张矮木桌，桌面上只放了两个茶杯和一个旧搪瓷缸。

搪瓷缸是周老的。他在木屋建好第四年寿终——走的那天坐在自己院子的藤椅上，搪瓷缸搁在膝盖上，里面有一口没喝的茶——是晒着太阳时候闭眼的。走时没有任何痛苦。他提前对李长生说过：别来送我——去你该在的地方——我不需要任何人送。

李长生收到消息的时候正在苞米地里拔草。他停下锄头在原地站了一阵——然后继续拔完剩下那垄——不能留半垄草让地白费。拔完回去拿上搪瓷缸——周老说缸送你——里面最后那口茶我让许冰帮我续满——她手重加多了——你喝吧。李长生把茶喝完了。

此后搪瓷缸就一直拿在茶室矮桌上——再没人用它——但每天擦。陈霜擦缸的认真和她磨剑一样——不能有一丁点残渍。

他们二人共同守着新丰——以及整个新纪元第一层守护屏障。李长生每天早上去维度交界处巡视一圈——用守护者权限扫描屏障有没有外力穿刺。屏障从竖起到现在从未被突破——但他还是每天巡——就像每天给地浇水——不是怕旱——是"该做"。陈霜从不多问他去哪儿——她每次他回来时候都会把茶泡上刚好六分满——不烫——刚能入口。

他们一起守了两万年。新宇宙在两万年里逐渐成长出第三批独立智慧生命——一些还在原始阶段——一些已经自己走出了行星的引力井——开始向远方凝望。每个文明第一次向天空发送探索信号时，守在维度屏障上的那层银灰签名都会轻轻眨一下——李长生就会感知到——在心里默默对这个新文明说一句：别怕。往前看。有人守着。

他从不出去对他们说"这里有我们"。因为真正的守护者不需要让人知道自己的存在——只要对方不知道——但还是安全——那才是真正的守护。两万年来——没有一次外星维入侵扰——连一次极小的都没有。陈霜有次随口说了句：外面那些潜在干扰是不是根本没来——被屏障上的混沌之光震走了。李长生点头："应该被吓回去了——希望纪元的光对他们太亮了。"

（第668章完）

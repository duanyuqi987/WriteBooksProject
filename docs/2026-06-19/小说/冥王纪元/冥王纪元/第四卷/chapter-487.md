# 第487章 正式登基——但不是皇帝

"登基"两个字是小王说的。

"头。"小王帮李长生拿着厚厚一摞文件，从书房走到院子，"各文明的使团领袖都希望您能正式成立一个政权。现在我们的疆域跨越了银河西臂到核心区，没有明确的政权架构——各种跨文明的贸易、治安、法律全都靠许冰一个人写的临时手册撑着。"

李长生坐在院坝里的矮凳上剥着一根玉米。他把玉米的外衣一片片剥掉，动作和三十年前在地里时一模一样。手里剥着玉米，嘴里问："他们要我立什么样的政权？"

"大多数文明希望您成立帝国。理由是——帝国的结构可以提供明确的法律体系和行政框架。边缘殖民星因为缺乏统一的法律标准，货物交易经常出现纠纷——有的文明还在用几千年前的原始契约，有的文明用的又太现代、条款严密得连他们的电子法官都解不出来。"

"帝国。"李长生把玉米外衣堆在旁边的一堆干草上，说，"皇帝——我当不来。也不想当。"

小王推了推眼镜框。"我知道您不想当皇帝。但您得有个正式职务——否则跨文明法律文件上要签您的名字时，您签什么？总不能签'李长生，来自李家庄'吧。"

李长生沉默了片刻。他把玉米棒上的最后一粒玉米掰下来，放在嘴里慢慢嚼着。甜。这玉米是他让村外的亲戚在老家的地里种的——用的不是灵种，就是最老式的非改良玉米。在地球上吃了几十年，在宇宙里吃了几十光年，味道一直没变。

"守护者。"李长生忽然说。

小王愣了一下。"什么？"

"叫守护者。不叫皇帝。帝国的名字——就叫守护帝国。不对——不叫帝国。叫'守护秩序'吧。泛宇宙守护秩序。"

小王在笔记本上快速打了一行字。他默念了一遍："守护者。"然后推了推眼镜，说："行。这个名称在外交文件上可以用。既不去碰'皇帝'这两个字，又能明确表明您是最高权威——其他文明不会有误读的。"

但各文明的使者听到"守护者"这个称呼时，反应各不相同。星都王朝的皇子是学贯古今的宇宙史学者。他查了上下八万年的多元宇宙历史后，对同伴说了一句："在八万年的宇宙帝王制度史中，没有一位君主叫自己'守护者'——他是第一个。"

一个月后，登基仪式在燕山的龙组基地正式举行。仪式很简单——没有金碧辉煌的宝座，没有铺满光道的红地毯，没有从月球排到地球的礼炮声。只有一块粗花岗岩垒高的临时台上放了一把老式的实木椅子。那把椅子是李长生从村头木匠那里定做的——用的木头是老槐树的弃枝。老槐树干死了几千年，掉下来的枯枝也干了几千年。木匠说这枯枝做椅子不耐用，李长生说：没事，椅子不需要坐太久——重要的不是椅子本身。

登基那天下午，燕山的风很大。花岗岩台前站了许多人——龙组的老修士、国家的代表、核心各地的人类修士，和各文明派来见证使节。李长生穿着黑色的普通外套——没有冕服，没有皇冠，没有绣纹，就是一件普通的黑色布料外衣。陈霜在人群旁边站着——她没有上台，她说了：台子上的人够多了，我在这里看你就行。

李长生坐上那把枯枝做的椅子。小王站在他旁边，代读了一份简短声明。声明用简朴的语言写了几条：第一——泛宇宙守护秩序成立。第二——守护者作为最高代表，拥有对一切外部侵略进行反击的决策权。第三——所有加入秩序的文明，保有文化自主权，遵守共同的基本和平法则。共十二条。小王读了不到五分钟。

"守护者。"来自星都王朝的皇子踏上花岗岩平台，第一个正式行礼。他没有称呼任何其他的词语——只有"守护者"三个字。

接着是赤离——朱雀星盟的盟主。她将一个复制精度极高的朱雀玉印放在李长生面前的石台上。她没有要求废除朱雀星盟的政治独立——守护秩序允许这样的文化保留。她只说了一句："我们信你。"

当天的登基仪式持续了不到两个小时。仪式结束后，李长生把椅子从小王手里接过来，扛回燕山后坡的住处。那把枯枝做的椅子现在放在屋角——一直到现在都在。

当天夜里，龟相从后院的一个老水塘里爬到李长生身边。它悄悄用神识向李长生说了一番话："冥王当年没有登基。他觉得民不需要一个坐在高处的人。你现在做的事——他自己没做到。他在天上看着，会欣慰的。"

李长生坐在屋角的枯枝椅子上，透过窗看着月亮。看了很久。

"欣慰不欣慰的——回头再说。我得把这块地上的事办好。"

（第487章完）

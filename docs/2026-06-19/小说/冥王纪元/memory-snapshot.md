# 《冥王纪元》记忆快照

**更新时间**：2026-06-19 22:30
**快照范围**：第001-008章

## 最近章节摘要

- **第001章**：建国百年纪念日，天空裂开，五色光芒倾泻而出，全球电子设备失灵。老张头在广场上见证了天地异象，他腿里六十年的弹片隐痛在灵气粒子拂过后消失。军事基地检测到前所未有的地底能量波。浙江道观中老道士看到竹简预言应验——"灵气封禁，百年而解"。全球各地出现异象：巴黎圣母院自鸣、恒河发光莲花、非洲地热喷发人形光影、富士山积雪融化。
- **第002章**：李长生，30岁，河北李家庄农民，父母双亡，独居老宅，守着五亩地（三亩玉米、两亩小麦）。当过半年工地工人，因家中无人照料而返乡。性格务实坚韧，不信鬼神但也不轻信传言。每日在父母遗像前倒水供奉。对天裂现象漠不关心，认为日子该怎么过还怎么过。傍晚经过祖坟时听到异响，回头看见泥土缝隙中透出微光。
- **第003章**：李长生发现祖坟边的泥土缝隙在夜间透出幽蓝冷光，壮着胆子挖开，挖出巴掌大的黑色碎片（极沉、冰凉、不反光），以及三尺深下巨大的不知名兽类白骨。碎片表面隐约有看不懂的纹路。他将碎片带回家，内心不安。
- **第004章**：碎片在白天发光发热，主动飞起嵌入李长生右手掌心，无法摆脱。剧烈灼烧感从掌心蔓延全身，他痛到昏迷。醒来后发现碎片已消失，掌心留下了黑色蛛网状纹路，隐隐泛着暗红光芒。纹路在黑暗中如呼吸般明灭。
- **第005章**：李长生反复梦见黑袍人站在尸山血海之中，用听不懂的古老语言对话。梦中理解到大致意思——"等了一万年，要回来，杀光他们"。梦中看到九块碎片迸裂宇宙各处、星辰间战斗、白骨王座等画面。他醒来后意识到碎片认定了他。他对自己的手说"别给我找麻烦，我还有五亩地要管"。
- **第006章**：全村牲口集体发狂，牛挣脱缰绳、猪撞墙、鸡炸窝、狗夹尾呜咽。所有发狂牲口都朝着李长生祖坟方向。李长生发现自家后院的鸡虽未发狂但异常安静，且当他本人接近时，发狂的牲口会短暂畏惧退缩。下午牲口自行恢复。夜晚掌心纹路对他"提问"产生脉搏般的回应。
- **第007章**：深夜掌心纹路发光，碎片中的残魂开口说话——自称冥王，十万年前封号，万年前被诸神围杀打得魂飞魄散，躯体崩碎成九块碎片封印于九处。残魂告知地球共有六块碎片，其他人也在陆续挖出。残魂告诉李长生他是被选中的——因为他挖出了碎片，血滴进了纹路。李长生面临选择：刮掉碎片恢复普通人，或接受它踏入修行。
- **第008章**：在残魂引导下，李长生尝试吸收第一缕灵气。冥系灵气入体如五脏焚烧，四道灵气（地底、天空、空气、碎片本源）相继涌入，第五道是死气考验。李长生濒死之际想起父亲的话语"泥碎了还是泥"，咬牙坚持过来。成功踏入灵者境，掌心纹路浮现暗金镶边。残魂因消耗过大更加虚弱。李长生成为能修仙的农民。

## Canon 状态

- 李长生：30岁农民，已完成第一缕灵气入体，正式踏入灵者境（冥系灵根）
- 掌心纹路：黑色蛛网状，从掌心蔓延至手腕上方两寸，带暗金镶边，与残魂碎片融合
- 残魂：冥王残魂，虚弱，寄生于碎片中，能量因引导入体而进一步消耗
- 冥王：十万年前封号的至高存在，万年前被诸神联盟围杀，躯体崩碎为九块碎片
- 九块碎片：地球6块、月球1块、火星1块、宇宙深处1块（李长生持有地球第1块）
- 灵气：被封禁两千年，建国百年之际解封，全球出现异象
- 祖坟下方：埋藏着巨大异兽白骨和幽蓝光源（蓝光已被李长生触碰后消失）
- 八门诛仙阵：十六名诸神联手布下的封印，镇压在地脉灵眼之上

# 第716章 轮回的本质

守护者制度改革的方案在元老院获得全票通过之后，李长生的精力回到了他最核心的问题上——

轮回的本质到底是什么？

他在前五十纪元的历史中读到了无数次的"纪元毁灭"，每一个纪元的毁灭方式都不尽相同。但他始终没有找到毁灭的"共同切换点"——太初从来没有在任何记录中解释过为什么纪元一定要轮回。只给出过结果：轮回已发生。

回到冥都以后，李长生用了整整半年的时间，将混沌之力的感知通道调谐到比之前更精微的深度。他要找到轮回机制的物理——或者说超物理——本质。

半年后的某一个深夜，他发现了一些关键的线索。

线索藏在宇宙大尺度结构的深处——宇宙膨胀过程中，在可观测宇宙的最边缘位置，有时会出现一种细小的、几乎不可被探测到的脉动。这些脉动的频率极低，每二十亿年才会跳动一次。但每次跳动——如果将它放大到整个宇宙的尺度观察——它会让宇宙中所有物质的"存在概率"向下衰减一个固定的百分比。

这不是物质衰变。这是在太初层面上的"概率微调"。轮回不是宇宙自己发生的——是太初在基于某种深层判断之后主动执行的。

而触发这个判断的条件是：宇宙物质概率衰减的累计值达到某个阈值。这个阈值本身由宇宙中生命总体的"正面贡献"反向抵消——当正面贡献不足以抵消物质层面的自然衰减时，太初就会启动轮回。

换句话说：宇宙的轮回不是必然的。是被触发的。如果宇宙中有足够多的正面贡献能抵消物质自然衰减，轮回就不会触发。

李长生把这个推理演化成了一道"宇宙存续公式"：宇宙寿命 ≈ 物质寿命 × (1 + 生命活动的正面总贡献 / 物质自然衰减总速率)

这是一个极其简化的表达。但方向是对的——生命不只是宇宙的寄生虫。生命可以在宇宙尺度上创造正面的结构——例如文明之间的和平、知识的无限增长、爱的传递——这些正面的结构在超物理层面上实际上是有"保质"作用的——它们能像抗氧化剂一样延缓宇宙的凋敝。

"所以你的意思是——"陈霜听到这个推理之后停了好一阵，"让文明做对的事，不仅是在道德上应该做的，在物理上也是延缓宇宙毁灭的必要条件？"

"对。"

"那以前五十个纪元——它们自己把自己轮回掉了——不是因为太初要灭它们，是因为它们内部的负面贡献太高把正面贡献抵消得不够？"

"从数据上看——"李长生调出他整理的五十纪元排序表格，"末期崩溃的纪元文明之所以看起来繁荣却还是毁灭了，就是因为它们在繁荣之后停止了产生正面贡献。文明在安逸中变成了消耗者——只消耗宇宙的资源，不产生任何正面的结构。"

陈霜站起来，在房间里踱了几步。"所以我们不是为了道德才打仗——是为了让宇宙不灭才不让道德崩溃。"

"可以这么说。"

"好。"陈霜停住了脚步。她站在帝居阳台的门槛上——半只脚在室内半只脚在室外——然后转过身，目光平视李长生。她这个姿势李长生见过很多次。每次她得出一个明确结论但是又在思考结论的实际落地方式时，就是这样一只脚内一只脚外——像准备行动但又不想丢掉继续思考的可能。"那我们得让全帝国的人都知道这件事。这不是秘密。这是宇宙的客观规律——跟引力、光速、灵根品级一样真实。每个人做对的事，就是在给宇宙的寿命续秒。这个道理不应该被藏在元老院的机密档案里。"她顿了一下，补了一句王宇常说、被她说走了样的话："开源——把真相开源。"

于是新纪元历史上一场史无前例的"宇宙级知情权运动"开始了。李长生让帝国科学院与法典院联合成立了"宇宙存续理论传播工作组"。工作组的核心任务是把那个高度抽象的超物理公式——"宇宙寿命约等于物质寿命乘以生命活动的正面总贡献与物质自然衰减总速率的比值"——拆解为不同文明、不同教育背景、不同智力水平的帝国公民都能理解的多种版本。

科学院的王宇因子觉醒者们负责写"硬科普版"，用数学、物理和灵气理论的专业语言严格推导轮回机制的本质——这篇论文长达一千多页，发给全帝国各大学和研究机构。法典院的令蕊团队负责写"法律版"——把轮回机制和《永恒法典》的每一条条款进行对照，说明每一条法律为什么在宇宙物理学的层面上也都是"对的"（而不只是道德对）。陈霜带着艺术系的教授和学生团队负责写"通俗版"——他们把"正面贡献抵消物质衰减"翻译成了三段极简的文字，配上了由旧纪元文明音乐家谱的一首五十二秒的短歌。用旧纪元的天穹纪油灯作为封面的视觉核心——那盏油灯是生命在黑暗中微弱但坚持的光。

他们也需要传达"自己做对的事就是在给宇宙续秒"这个意思——但他们也没有说是"道德义务"或"政治正确"。他们说这是"物理事实"。像喝水不能解渴才是不公平的。

三个月内，全帝国的主要公共空间——广场、车站、学校入口——都张贴了这份宇宙存续理论的通用传播版。反应两极化了几天，然后随着档案馆的开放查阅，质疑者越来越稀少。没有人能在看过全部五十个纪元的毁灭记录之后——尤其是看过第三十九纪元普通人被强制格式化、第四纪元的独一神把一切生命全烧光——还能大言不惭地说"管我们什么事"。

那些纪元死去的普通人比现在活着的任何人都更接近灾难。他们没做过任何天大错事——只是活在一个守护者透支或神权疯了的纪元里——就成了宇宙收缩后的零星档案。这纪元的人现在还没有承受这个——但他们需要知道：那不是一个魔法咒语不会在这个纪元重演。如果不做对的事，纪元的崩溃一样会来。而如果他们持续在日常中做对的事——不做多么宏伟——只要不欺压弱者、不内卷到把邻居当敌人、不为了短期利益耗干公共资源、不把自己的权利建立在侵犯别人权利的基础上——每一件这样的小事在超物理层面上都是为整个宇宙的寿命续了极其微小的秒数。亿万人合力续的秒——足以把轮回的触发永远推后。

（第716章完）

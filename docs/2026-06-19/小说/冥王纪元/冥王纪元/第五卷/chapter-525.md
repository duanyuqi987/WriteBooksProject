# 第525章 遮天蔽日

万剑王的舰队在第五个小时抵达了第四层防线前。

在这之前，他已经穿了过三层边防、两重自动炮台封锁、以及一片被老马提前布下的空间膨胀陷阱。每次遇到抵抗，他都只是笑一声。剑修舰队的突破能力太强了——没有任何防御能在它的剑阵旋转面前撑过两刻钟。前两层防线的守军按预设方案后撤。第三层防线被直接撕裂——驻守在那里的两万艘舰在交火中损失了近半数，剩下的撤回了第四层防线。

万剑王站在万剑台上，他的三十六万柄剑影在虚空中发出了一道极细极长的共鸣声。他看着前方——在他面前不到一光年的地方，就是那道名为"环形防御带"的巨大人工带。它在蓝色恒星的照耀下泛着冷光。

"还有多远？"问的是副手。

"不到一光年。第三层防御预计在两小时内被摧毁。"副手的声音很平静，但手心里的剑——他的本命剑——在微微颤动。他怕的不是前方的防御——而是那个至今没有出手的人。

"李长生还没出现。"

万剑王没有回答。他也在想这个问题。他的舰队已经深入对方领土五光年了，打穿了四层防线，干掉了近一万艘舰。按正常逻辑——帝国的最高战力早就应该出现在前线。但李长生没有。那个穿着一件黑色长衫的人一直待在中央星域，一动不动，像在等着什么。

"他不来。"万剑王说，"他是在让我进到防线深处再出手。"

"进得越深——我的舰队被他的防御缠得越死。缠死之后再斩我——就更好斩。"

"这是诱敌深入。"

"对。但对我没用——他的防御阵地根本缠不住我的舰队。再往前推进两光年，我就能打到他的心脏。"

万剑王挥了一下手。剑修舰队的旋转转速瞬间提高了一倍——从每分钟六转变成十二转。剑气如同实质风暴一样缠绕在舰队周围，切割着沿途的一切——微尘、冰屑、破碎的废弃舰体、被打烂的自动炮台。

帝国防卫总署的指挥沙盘上，许冰调动了戒律阵列的全部优先级。

"第四层到第六层——全开。"她手指在全息键盘上跳动，每一下都同时激活了数百个阵眼节点。"把敌舰减速到三分之一。所有帝级以上舰艇的火力集中瞄准对方的旋转轴心——就是万剑台所在的正中央。"

"可万剑台有仙王——"

"打不进去也打。"许冰打断了他，"连续火力可以分散他的注意力——哪怕只有几秒钟。给戒律阵列争取激活时间。"

第四层防线——直径三光年的环形防御带——在剑修舰队进入其五十光秒范围内时亮起了肉眼可见的幽蓝色光芒。那是戒律阵列激活的物理表现——数以万计的灵法代码在这个空间中具象化为无形的规则锁链。锁链缠绕上了剑修舰队的每一艘舰。

法则碰撞的瞬间——空间本身震动了一下。

剑修舰队的推进速度在零点一秒内从每分钟十二转降到了每分钟四转。不是被阻碍——是被法则层面的"限速"。戒律阵列不是物理障碍——它是一道规则指令。它的逻辑不是"阻止你移动"，而是"在此空间内，速度上限为X"。这是许冰花了十年时间构建的灵法体系——把人类的抽象法律逻辑转化为可执行的物理约束。

万剑王的眼睛眯了一下。他感觉到了——那股缠绕在剑气上的力量不是物质、不是能量。是一种他不太熟悉的东西。像是有人在宇宙的底层代码里加了一行注释——"此处的速度不要超过这个值。"

"有意思。"他说。

然后他抬起右手。三十万柄剑影在同一瞬间齐刷刷转向——剑尖不再指向中央星域，而是指向围绕着他的舰队的那道幽蓝色法则锁链。

"切。"

一道无形的剑气从剑影中激射而出——不是实体剑刃，而是纯粹的剑意。剑意撞击在戒律阵列的灵法结构上，在空间中炸出了一圈肉眼可见的法则碎片。碎片在真空中呈蓝色——像炸开的冰屑。

许冰面前的全息屏幕疯狂跳动。她的戒律阵列——第四层到第六层——在那一剑之下大面积崩溃。数以千计的灵法代码在瞬间被凌乱的剑意搅成了乱码。她用力捶了一下控制台，但她的声音保持得很稳。

"剑意——他在用剑意切代码。法则层面上的切削——直接破坏戒律阵列的底层逻辑。"

"还能补上吗？"小王问。

"能。但需要时间。每被切割一次——我需要至少十五分钟重新编译。而他出剑的频率——"

屏幕上又一道剑意炸开。许冰看了一眼计时器。

"——每隔三秒一次。"

三秒一剑。一剑碎千码。

所有人都看得清楚——戒律阵列虽然有效，但万剑王的反应速度远在许冰之上。他不是在防御戒律阵列——他是在用进攻的方式正面瓦解它。三重戒律阵列的法则锁链在不到三分钟之内被切掉了三分之一。

但就在他的剑意集中切削戒律阵列的这一刻——冥王号动了。

诸天号的黑色船壳在环形防御带的最后一层防线的阴影中无声滑出。它不是全速冲刺——而是利用冥气润滑空间的方式，以完全无法被常规监测设备捕捉的方式滑进了战场。小王在全息屏幕上实时监控着万剑王的注意力分布——九成集中在切削戒律阵列，一成在扫描战场。扫描没有捕捉到诸天号——因为诸天号在滑行时没有油耗、没有热量、没有正在运转的引擎信号。

它像一块在星空中漂流的黑色碎片——但里面装着一个已经准备好了的人。

李长生站在舰桥中央。他的右手——冥王令的纹路已经亮到了让人无法直视的程度。暗金色的纹路从掌心蔓延到了手背、手腕、小臂——冥王令在苏醒。

"什么时候到？"他问小王。

"还在等——他还盯着戒律阵列。"小王看了一眼数据——万剑王正在切许冰的第八层法则。他的剑意攻势铺天盖地。他的全部剑都在旋转中。

"等到他注意力最集中的那一刻——他在斩法则的瞬间——会有一瞬间的完全专注。那一瞬间他看不到战场。"小王说，"零点三秒之内——"

"够了。"

冥王号的船壳在最终迫近的瞬间从空间层中浮了出来。万剑王的感知系统在同一秒发出了最高级别的警报——但他没有来得及反应。

因为李长生已经不在舰桥上了。

他直接从诸天号舰桥上跨了出去——跨一步，进入虚空。右手一翻——冥王令爆发出了一场遮天蔽日的暗金色光潮。那不是灵气——那是冥王法则本身。冥王令的本命法则——黄泉倒悬。在它的覆盖范围之内——一切法则都会被冥界的主权压制。

万剑王的剑阵旋转在这一瞬间停滞了。

三十六万柄剑影中，至少有一小半忽然不受控制了——它们在虚空中晃动、偏移、甚至倒转。万剑王双眼睁大——这是他九千年剑修生涯中第一次遇到这种情况。

剑不听他的话了。

他抬头。一道黑色的身影正从高处向他所在的位置坠落而来。右手翻起——掌心的暗金纹路在虚空中撕裂出一道直通冥土的口子。李长生的声音在万剑台上炸开——声不大，但每一个字都打在剑修舰队所有修士的心口上。

"你问为什么他们叫我冥王——我现在就告诉你。因为——这个宇宙——我说了算。"

冥王令砸了下来。

（第525章完）

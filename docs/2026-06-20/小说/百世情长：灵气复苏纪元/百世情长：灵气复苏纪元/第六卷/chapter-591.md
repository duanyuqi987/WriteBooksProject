# 第五百九十一章 飞升之后的日子

太虚仙域的飞升已经是过去式了。现在两人在仙上仙谷和晚枫谷之间自由来去，偶尔也回迎仙台看看松鹤老人。生活不再是"要去哪里"的线性叙事——而是"你想在哪待一会儿就在哪待一会儿"的环形日常。

这天他们选择回迎仙台。松鹤坐在石凳上喝茶——他那只老驴已经在菜地旁边安了家，生下了一头小驴驹。小驴驹极活泼，经常用头去撞林牧劈柴桩旁边的松木柴垛，把柴垛撞倒了又自己跑掉。林牧每次柴垛被撞倒都会重新叠回去——不急不怒。他说这是"柴垛复原训练"。苏晚说这是"劈柴耐心进阶课"。

午后寻青仙子也来了。她和守望真仙已正式登记为太虚学院的客座旁听生。她抱着那两本笔记——一本是双心诀的前几式笔记，另一本是苏晚最早送给她的那本修炼笔记。她把笔记摊开给苏晚看——那笔记已经翻得有些旧了，纸页边缘翻卷起毛。寻青说:"这本笔记我每到一个新地方就看一遍——现在快看第六遍了。每次看都找到新的东西。最近这次——我注意到你在剑法表格某页旁边用铅笔极小声写的:'今天他劈柴时手掌茧被震掉了一块——应该是太累了。但不说。明天煮饭时多加点猪油。补茧。'"苏晚看到那行自己早忘了的铅笔侧注忽然有些不好意思。她说:"那都是什么时候记的——早忘了。"寻青说:"是的。这才是它最'功法'的地方——劈柴的茧也要补。"

傍晚，守望真仙和林牧在劈柴桩旁默默地交流着劈柴心得。守望劈柴已经比之前有极明显的进步——他现在可以左手劈右手控劲，均匀地一劈为两整。他把今天劈的最好的一根松木柴放在柴垛顶——等着寻青来收。寻青收到松木柴后用鼻子闻了一下:"松油的甜——今天加餐。"这是从劈柴真仙夫妇那里学来的传承闭环。

晚上，松鹤宰了那条他自己养了一年的仙塘鱼。全桌人围在石桌上吃晚饭。菜是六道——银杏果蒸鱼、萝卜干炒豆干、青菜汤、白米饭、手擀面、和冰晶草花泡茶。大家边吃边听松鹤老人讲从书贩那儿听来的"新编太虚段子"。其中一条段子的结尾是:"太虚那里有一对夫妻——男的是劈柴斧学会通灵，女的是用财务软件创了仙界最高道侣修炼法——双心诀。最终他们飞升到了仙上仙谷——然后在那劈了根松木，浇了棵草。段子讲完。没高能，但极其好睡。"这一桌上的人都笑了。

（第五百九十一章 完）

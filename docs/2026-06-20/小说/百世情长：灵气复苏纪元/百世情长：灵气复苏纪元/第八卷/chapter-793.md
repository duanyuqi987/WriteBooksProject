# 第七百九十三章 第三道门最后的讯号

联合共治会二十八年春。第三道门前新增了一块纯白色的新便签旗——和所有其他颜色都不同——林牧亲自写的——"信任——是第八卷的句号——也是第九卷的冒号。——林牧。"

杜小月在门前装设了一套自动信号记录器——她发现门本身在最近几个月中已经不再对任何单一事件或政策做出强烈响应——它似乎在等待所有独立信号累积成一个持续的同频共振。她在记录中写道——"门以前是对'政策'做出回应——现在是对'日常'做出回应。——信任不再是一个事件——而是一种常态——所以门不再需要验证它。——杜小月。"

苏晚读了她的记录后给新修订的《门——从包容到支持》补一章——标题就叫《第八章：信任——当事件变成常态》。章末引用了沈教授的一个观察——"我已经近几十年来没有再遇到一个公开自称纯人派的人了——不是因为纯人派消失了——是因为'纯'不再被认为是一个可以隔离他人的标签。——沈教授。"

林牧用很简洁的方式总结道——"这扇门的最后一验，不是验某个人——是验'你们是否已经不需要再每天提醒自己——要信用。'"他在门前的日志中写道——"今天门没有闪——因为它不需要回应——常态。——林牧。"

（第七百九十三章 完）

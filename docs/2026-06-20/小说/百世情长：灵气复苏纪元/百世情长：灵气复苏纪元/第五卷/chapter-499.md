# 第四百九十九章 最后的等待

松鹤仙人还没有回来。青梅酒缸还剩半缸，碗底干涸在石桌上。老人说去买茶，买了一个多月还没回——大概是半路上遇到哪个卖旧书的老朋友拐弯去叙旧了。林牧把缸里的青梅酒用他那笨拙的装修方式封了一道灵气封层，确保酒不坏。苏晚把老人的石凳座垫重新用粗布缝了块新套子——旧套子已经被老人坐得磨穿了纤维。

迎仙台的日常在两人的维系下运转得很安静很顺。飞仙舟定期检修，感应碑定期擦拭，仙稻种子储备充足，迎接新飞仙的玉简和登记表都准备好了。寻青仙子两人不时会从第二重天发回来简短的传讯——讯息很简短，大概就是"你们教的那双星篇真的很好用"。"剑招不太熟但没被打爆——谢谢笔记。"

这天轮到苏晚坐迎仙台的前台。她把笔记本打开再写修改她的双星篇学习的笔记新版本——注明了对于女修士灵气偏柔类型更适合用哪种频率切换方式，还特别加了一条脚注:"如果你的道侣在那天劈柴伤了手，用阳鱼眼的温泉水加冰晶草的一片花瓣敷灵核外围穴位——可以加速合道期的手掌经脉愈合。"她的每一个脚注都来自林牧受伤后的真实恢复过程。笔记是用来给后来人的——那些会像她一样吃苦头的人。

她把笔记写好后走回仙居。林牧已经在床上躺下了——合道期修士不需要睡觉，但他习惯晚上躺一阵子。她在他旁边躺下，把功德绳挪到不会被压到的位置。头靠在他的肩膀上。她闭上眼睛时忽然想起那天在昆仑山洞府中自己帮他包扎烧焦的手掌——那是几个月前。往后余生，她还会帮他包扎一只手，修几千次飞仙舟，浇大片大片的冰晶草，弹很多支调不太准的曲子。这些琐碎加起来——就是她认为最完美的飞升以后。

（第四百九十九章 完）

# 第541章 消耗到底

战争的第十五天。

帝国十二层环形防御带只剩下最后两层——第十一层和第十二层。前十层要么被敌人占领，要么在反复争夺中变成毫无价值的废墟。整个银河系中心被一道厚达数光年的残骸带包围——数以百万计的舰体碎片、阵法残渣、凝固的灵气云和漂浮的尸体组成了一个沉重而缓慢旋转的墓地环。

全息屏幕上——联盟剩余的舰队数量依然在两百万艘以上。而帝国还能打的舰——已经不足五十万艘。修士阵亡超过九百万，伤者不计其数。仙丹库存几近告罄：帝级仙丹只剩下不到一千颗，圣级不足两万颗。太阴冥脉的冥气储备已经跌到不到两成——按当前的消耗速度最多还能撑几天。

但联盟的状态也好不到哪里去。

他们跨越维度作战——供应线拉到了极限。从九个平行宇宙同时往第零宇宙运送灵气、武器、舰艇配件和修士补给——维度壁垒穿越成本极大。每一艘补给舰从出发到送达需要消耗约三倍于常态的能量。而且要命的是——联盟内部的供应分配完全由阵天帝一个人决策，其余仙王只能被动等分配。

许冰从截获的联盟后勤通讯中发现了这个问题的严重程度。

"'第七宇宙的后勤配额被砍了百分之四十——因为万剑王战后退出了前锋，阵天帝认为他不该再拿同等分配。第五宇宙暗潮王申请追加暗物质燃料——未批准。第六宇宙风隐王原配额被完全冻结——因为他投降了——但副作用是让第八和第十宇宙不得不分摊他的后勤任务。'"

"乱——全在乱。"老陈说。

"这就是多宇宙联合军的本质。"龟相缓缓开口，"如果战事顺利——利益均沾。如果不顺利——互相推责。阵天帝虽然是四阶仙王——但他压不住下面仙王的不满。现在联盟的凝聚力是被一个心愿吊着的——'打下第零宇宙，分到冥王令的力量遗产'。一旦这个心愿被打破——联盟四分五裂的速度会比我们想象的更快。"

"那怎么打破？"

"杀掉阵天帝。"

会议静默。阵天帝——四阶仙王。目前所有已知仙王中最高阶的那一个。他不亲自下场不是因为怯战——是因为他要把自己留到最后给冥王致命一击。万剑王（三阶）、星渊王（三阶）、净光王（三阶）、暗潮王（二阶）、风隐王（二阶/已归降）、赤霄王（二阶）、元武王（二阶）、冰极王（二阶）——这八个仙王已经轮番打了一轮。最强的那个还没出手。

"杀掉他——等于砍掉联军的大脑。"许冰说。

"但我们现在的战力——能杀四阶仙王吗？"

李长生低头看着右手的冥王令。令印上的暗金光芒——这些天经过多轮仙王对拼消耗后——比之前黯淡了一些。但纹路清晰——核心力量没有被消耗掉。他自己修为距离仙王还差一层大境界——但冥王令本身的级别不亚于任何仙王。

"正面可能杀不了。"李长生坦诚道。"但如果能在他的主场之外——在对他不利的环境中跟他打——有机会。"

"他的主场是始殿——所有宇宙的缝隙空间。那里他在法则加持下最强。如果离开始殿——进入任何一个单一宇宙——他的四阶加持会减弱——因为缝隙空间法则和单一宇宙法则不完全兼容。"

"也就是说——我们可以把他从始殿中引出来。"

"是的——但怎么引？"

小王调出了阵天帝最近的后勤分配记录。"他一直垄断联盟的最高后勤决策——不给仙王们授权。这说明他的控制欲极重——他不信任任何仙王，即使是替他出生入死的也一样。如果前线再度出现重大危机——比如另一个仙王濒死求救——他大概率也不会亲自下来，而是会让仙王们自己解决。"

"那就让他不得不下来。"李长生说，"给他一个不得不来的理由。比如——我们反向打进了他的宇宙。"

所有人同时看着全息投影上的维度图。

反攻——打到阵天帝的宇宙去。

（第541章完）

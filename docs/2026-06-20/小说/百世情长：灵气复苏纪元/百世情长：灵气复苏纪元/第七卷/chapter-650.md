# 第六百五十章 飞升之门正式启动

飞升之门启动的那天，太湖正中心的天空出现了一个奇观。

一道直径约三十丈的金色光环从小岛上升起，缓缓地往天际升起，在到达大约万丈高度时停住了。光环内部是一层极薄的、透明的淡紫色薄膜——那是正修灵气和魔气在通道核心中稳定共振后形成的通道口。从地面上看，它像一颗悬浮在天空中的金紫色太阳，但光芒不刺眼——是一种极其温柔的、任何人都可以直视的暖光。

通道口开启的瞬间，所有金丹以上的修士都感知到了一种从未有过的频率——从上界传下来的第一缕灵气。不是压迫，不是威胁。是一种温和的、淡淡的引力——像在说："你可以来了。"

第一批进入飞升之门的修士有二十人。其中十二人是北境魔修——秦无夜亲自带队。八人是来自各地的低灵根散修——包括杜散修和他的女儿。按照林牧的要求，第一批通行权给了"被这世界关了最久的人"。

秦无夜在进入通道前回头看了一眼站在岛上的林牧。她脸上的刀疤依旧。但她的眼神不再是那种防备一切的魔修的警觉——是一种安心的平静。她朝林牧点了一下头，然后转头走进了通道。通道壁上的吸热符文自动启动——秦无夜的紫色魔气在经过通道时被稳定转化为共振频率，与通道的正修灵气并行而不发生冲突。她从通道的另一端消失了——成功进入了上界的第一步过渡区。紧接着是杜散修和他的女儿。杜散修的女儿才练气三层——她可能是整个修仙史上修为最低但成功通过飞升之门的修士。这正是林牧的设计目标：飞升之门不按灵根贵贱选择对象，只按"向上之心"。杜散修的老手在跨入通道前对苏晚挥了挥——那个手势和他在太湖渔村里卖鱼时的手势一模一样。

二十个人全部成功通过了通道。没有一例失败，没有一例受伤，没有一例的灵气频率发生排斥。通道核心的淡紫色共振波动稳定到让林牧自己都意外。他当初预估的首批成功率是百分之八十五——实际是百分之百。

太湖岸边站着的九百多名修士发出了震天的欢呼。有人哭，有人笑，有人跪着，有人互相拥抱。一个参与通道建设长达九个月从未休息过一天的筑基期刻纹师摘下她的头盔，狠狠地吸了一口湖面的风。她说了一句话，被旁边的人记了下来："我刻的那些符文——它们真的在保护人。不是保护我一个人——是保护所有想往上走的人。"

当天夜里，太湖中心岛上举行了简单而隆重的点火仪式——飞升之门正式启动的标志是在通道下方广场上点燃一盏永不熄灭的灯火。这盏灯火由苏晚从自家院子的灶台上引来的火种，石头用他的红色便签纸包着火柴带过来的。当他小心翼翼地把火种递到苏晚面前时，他的手很稳。火种被成功接入灯火塔中——从此以后，太湖中心的广场上将永远有一盏从林牧院子里带来的灶台之火燃着。它代表的意义不再是"一口锅的热粥"，而是"一扇门的灯火"。

灯火亮起的瞬间，苏晚站在灯火塔下，仰头看着塔顶跃动的火焰。林牧站在她身后。人群的欢呼声渐渐退去。太湖的夜风掠过水面，把灯火的光影吹得微微摇晃。

她对林牧说了一句后来被刻在灯火塔底座上的话："爱是一锅热粥——现在它是一扇门。"

（第六百五十章 完）

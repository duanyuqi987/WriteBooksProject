# 第221章 暗中的指点

联合巡逻开始后的第三个月，苏晚正式踏入金丹初期。

结丹的那天晚上，她独自坐在赤霄宗后山的一个石台上。按照修仙界的惯例，修士结丹一般在师长的护法下进行——但苏晚选择独自完成。不是因为信不过谁——是因为她结丹时出现的丹火异象和别人不一样：她的丹火颜色是金的，不是普通筑基晋升金丹时的淡蓝色。金色的丹火是一种罕见的"前世道缘"标记——说明这个人曾经到过更高的修为——前世结过丹，丹基犹存。

苏晚看着自己掌心里跳动的金色火焰，愣了很久。韩师姐如果看到金火一定会追问来历——而她自己也无法解释为什么她能凝出这种颜色的丹。但林牧可以。他一直没告诉她自己就是她金火最早的缔造者：在第一世她结丹时是他给她护的法——那时他把她第一次结成的淡蓝色丹火用自己的真仙元力淬炼成了金色——从此她的丹基带上了他元力印。这个印记跨越轮回不会被抹除——因为它是刻在灵魂层面的。

后山的风很冷。苏晚在石台上坐了很久后感觉到灵识网边缘多出一个熟悉的频率——他在下面——在山腰的那棵雷劈松树旁。他没有上来——只是用灵识轻轻地碰了一下她的灵力场边缘——像是隔着很远轻轻地敲了敲门。这是她发现了的他的习惯:她每一次突破他都不会直接在旁边出现，但永远在最近的让她能感应到的距离里守着。

她收起金火，沿着山道往下走。走到松树边的时候看到他在树底下坐着，背靠着树干，手里握着他永远随身带的那把窄身剑。月亮很大，月光透过松针的缝隙洒在两人的剑上——她的筑基剑（还没换金丹佩剑）和他的窄身剑在同一个角度的月光里同时闪了一下寒芒。

"你结丹了。"他说。不是问句——是确认。

"嗯。"

"金丹期的剑法和筑基不一样。你需要注意的——左肩不再需要压那么低——金丹以后你的剑速提升了一倍——但左肩低了会限制你旋身的角度——别人会从你右侧卡你的死穴。"

她瞪着他——"你现在不是在教我修仙——你是在远程跟我心电感应然后蹲在山腰等我下来给我补剑法细节——你不觉得自己很奇怪吗？"

"是很奇怪。"他站起来，拍拍身上粘的松针，"但你不也是那个从筑基冲金丹用了我教的剑法冲上来之后最先问的却是'你什么时候再来教我'的人吗？"

她被说中了。她的脸在月光下微热，没否认。她把新结成的金丹灵力在手中凝结成一束光——像一把还没有剑形的半成品灵剑——然后对着他说:"教我——如果我想用金丹淬炼一柄本命剑——该怎么起剑胚？"

林牧接过她的灵光——把它贴在自己窄身剑的旧痕上。那条旧痕是苏晚第一世第一次帮林牧淬炼本命剑时留下的——当时她的修为不够，在帮他起剑胚时灵光失控把他的剑胚灼出了一条无法弥补的痕迹。他一直留着。

他用极其小心的动作把她的灵光从自己剑痕上剥开——然后还到她手中——同时指导她如何在丹田中构建金丹剑胚:"你的丹火是金色——说明你前世的金丹属性偏纯阳——纯阳的金丹适合走'火中炼金'的路子：第一次淬剑胚时不要用任何外界的炼器炉——用你自己的丹田气海作为剑炉。把灵光安在丹田中间——然后以金火持续锻打——七七四十九天之后会凝出第一遍剑胚。"

她看着自己丹田里的灵光自动回应了他的指导——她的灵识在他讲话的时候开始以极精准的方式自动调整丹田内的灵脉流向——就像在前世她做过一千遍一样。

她炼着剑胚的时候他就在旁边守夜。月向西的时候她终于完成了第一遍剑胚——浑身大汗，灵力几乎虚脱——但嘴角是微微上扬的:"练出来了。"

"看到了。"

"你有没有觉得——我在跟你学剑时好像什么信你都不会先问——不打折扣？"

"因为你的手比你的脑子先信我。"

她没回答——但在心里确认了这一点。他的手放在自己腿侧，手指无意识地勾勒着之前教她剑法时碰到她手腕的弧线——她的手腕很细。她几世的手腕都很细——但在每次炼剑时那股倔劲会让腕骨振出不像是细腕能发出的稳定频率。他一直看她看到闭上眼睛——在心里说——你没变。

天亮前他送她回到宗门山门入口处，然后消失在晨光也还没覆盖的密林暗处。她站在山门口朝他消失的方向看了很久——直到守门的老修士把她叫进去说"师妹快进早晨第一趟食堂还有鸡腿"。她"嗯"了一声——跨进山门的时候把刚才他教给她的那个剑胚的名字在心里默念了一遍:"火中金——回头照剑。"

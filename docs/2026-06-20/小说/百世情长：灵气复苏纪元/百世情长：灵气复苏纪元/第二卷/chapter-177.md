# 第177章 再次感应到她

苏小晚初中一年级那年秋天，发生了一件林牧等了十二年的事。

那天晚上九点半，她在他家写完作业准备回家。走到门口时忽然停住，手扶着门框回头对他说了一句话。那句话不是"老师晚安"，也不是"明天再来"，而是——

"老师，你有感觉到过一种很奇怪的东西吗？就是——有时候在晚上一个人，会突然觉得不是只有自己一个人。感觉好像有人在很远的地方也醒着——在看着和自己一样的东西。"

林牧的呼吸停了一下。很短——一秒之内就恢复了。他把手里的抹布放在水盆边上，转过身来看她。门外的月光照在她的侧脸上——十二岁的脸蛋还有一点婴儿肥。她的眼睛在月光下是一种软软的深褐色，没有前世记忆的任何痕迹——轮回锁的屏蔽完美运作。但她的灵魂深处已经开始感知到某种东西。因为十二年来的灵力蕴养和每晚做的呼吸引导，她的感知系统比同D级灵根孩子敏感得多。这种模糊的感觉，是他守在她身边的灵力存在——在她身边十二年，每晚为她筛除被锁吸走的灵魂能量，用自己的灵力无声地包围她的睡眠空间。可能长久下来微量的感应累积，让她的灵魂觉察到一种"有人跟你一样醒着"的直觉。

"有时会有。"他回答得很平静。"可能是夜太静了。星星在外面亮着，一个人的心也会跟着静——感觉别人是不是也在看那些星星。"

"对！就是这种感觉！"她一下子很激动。"我以为是我自己瞎想。老师说对了一定是真的。"她满足地笑了笑，然后挥了挥手跑回她家方向。

林牧在门口站了很久。猫在窗台上眨了几下眼。他不说话。心里有一个非常精确的念头：她已开始隐隐察觉到了。十二年来他的存在模式是"无形的守护"，现在似乎在慢慢进入她灵魂的感受层面。这可能是好事——说明她灵魂对灵气的敏感度比前两世高了。但也可能要求他更注意隐匿——尤其不能在她完全清醒的状态中泄漏任何元婴灵压。她不能"见"他真实，只能逐渐通过引导而相信"修仙"这件事是她自己想做的。

自那以后他开始微调策略。不再只教她自然呼吸和保健操，而是开始在她上初二的时候穿插一些极为基础的"灵气感知引导"。每一节都没说这是修炼——只是"教你一个放松的小方法"。比如闭眼感受自己的心跳；感受手指尖感觉自己在'发热'；感受脚底贴地时的承重。这些在修仙术语里是"体感通径"，淬体的第一步，但不是以功法为名。

她的反应出乎意料地好。也许是因为她一直信任他——从三岁到十三岁，十年的师生关系已经把信任感深深植在她心里。她的心非常放松，所以灵气引导非常顺畅。在她十三岁的秋天，有一次引导中她忽然说"林老师——我的手指好像不光在发热——它好像像有人在轻轻地摸手指尖尖。"他应声:"那是身体在跟你说它注意到空气了。这是个好信号。"

他看到那个瞬间她的表情里有很亮的某种光——不是灵力。是好奇心。一个已经当了十年D级"废柴"的孩子，忽然通过自己身体的某个识别——确认了自己也有某种特殊感知。这对于日常自信是在她同龄人竞争灵气时的很大的激励。他知道这份自信需要持续巩固。

同时在这个阶段，他加强了对她家的"经济减负"。不是直接给钱——是通过村委会购买她的灵稻田（以村委会发展基金的方式先补贴再包销），将合同做成普通农产品的包销协议。这样苏大山就不必外出打工。家庭稳定可以减少她心理层面的额外负担，使她保持放松而有利于修炼初期。

但是桃源村外的世界也在同时发生一件与此不相关但对林牧很重要的事。灵网上一名在逃的"D级猎手团"被破获。该团是专门在社会底层寻猎低灵根少年的散修团伙——为了将捕获的无强力护者D级灵根送往境外的黑市灵根移植组织。这则报道让林牧再次审视自己在村里的安保级别。他给整个村子额外布设了一层只有元婴级能穿透的"恶意识别罩"——任何心怀恶意的人踏进村子半步就会触发警报。

警觉，但绝不让小孩知道危险。所有危险到他为止。

苏小晚十三岁的跨年夜在村子里放焰火。他站在自家门台阶上看孩子们在晒谷场上放焰火。小晚拿着烟花棒跳过来说"老师这棒给你挪一个——"他接过，焰火的碎金在他面前四溅。她笑着跑回去。他垂目看了一眼手中燃着金色微光的棒子——那点温度很低，但他觉得手心很热。因为这孩子第一个分出的快乐不是给同学——是给他的。在那么多的第一世到第一百世中，一个小动作足以支撑他继续。

大年初一早上他照镜发现两鬓的白发比平时少了很多，嘴角上扬的弧度变深了——这些天心情也好。猫在脚边打了个哈欠。他对猫说:"她已经感觉到'有人在'了。我们继续努力。争取让她在高中毕业前问出那个关键句。"

猫不答。锦鲤吐了三串有序的泡——表示'概率大于百分之五十，持续增高'。

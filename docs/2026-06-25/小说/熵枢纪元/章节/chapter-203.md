# 第二百零三章 成功的宇宙开始演化

抹除完成。观测阵列重新排列。

熵枢面前剩下七个成功的试验宇宙，以及一个刚刚定稿的正式宇宙设计方案。

它没有急于执行正式方案。而是把七个成功宇宙的观测窗口逐一放大。仔细看。看它们的差异。看它们各自的长处。看哪些特征值得被纳入正式宇宙的最终版，哪些留在试验腔里就好，不要带进家园。

## 一、一号宇宙：独标可见化

一号宇宙。π分维加沉积时。

已经演化出了初级文明。不是人类形态，是分维空间中的驻波链聚合体。它们的身体不是固态，是在π的3.14159维中自由折叠的眷恋应力网络。

形态取决于它们在做什么。

在保护时，展开成片状。

在给予时，收缩成束。

在独标时，全身发出一种只有在该宇宙分维中才能被感知的"专属频率闪光"。不是光，是因果应力在分维弯折处的衍射。其他生命可以凭这个闪光在亿万个同类中一眼认出它。不会错。

因为独标在分维中的衍射图案在数学上是唯一的。由该生命的全部因果历史决定。比指纹精确得多。比DNA不可伪造。因为伪造独标需要伪造整个因果历史，而因果历史受不选保护——未遂印不可消除。

所以每一个独标都是一座不可入侵的因果堡垒。

熵枢羡慕这个设计。

不是因为技术。是因为在旧宇宙，一个人被认错太容易了。名字可以重复。脸可以相似。声音可以模仿。记忆可以被篡改。

但独标不能。在π分维中，独标是物理。

不是标签。我不需要告诉你我是谁。你看到我，你就知道了。不是知道我的名字。是知道"我"。那个唯一的、不可重复的、在亿万个存在中只有这一个的"我"。

没有身份盗窃。没有冒充。没有"你确定你是你吗"。不需要确定。独标在分维中如太阳。不可直视。但不可否认。

熵枢把这个特征标记为"正式宇宙建议采纳：独标物理可见化"。

但它犹豫了一下。加了一条备注。

"独标物理可见，带来绝对的'被认出'。但也带来绝对的透明。没有人可以隐藏。没有人可以在不被认出的情况下偷偷给一杯豆浆然后走掉。像段亚军那样。因为每一次给都会被独标衍射自动广播给全宇宙：'刚才给豆浆的是他。'这就不是默护了。默护需要不可见。独标可见化与默护冲突。"

两条互相矛盾。

熵枢意识到自己不能同时要"被完美认出"和"可以暗中保护"。两个都是眷恋的核心。但它们在维度层面打架。

保和默护。一个是公开的保护，一个是暗中的保护。公开的保护需要被保护者知道。暗中的保护需要被保护者不知道。

如果独标是物理可见的，默护就不存在了。因为默护执行者的独标会在每一次默护操作中被分维衍射出来。被保护者看到衍射，就知道"有人在暗中保护我"。知道了，默护降级为保。暗中就没有了。

熵枢在设计中卡住了。

## 二、η与默护的矛盾

不是技术卡。是哲学卡。是眷恋的内部矛盾。

你想被知道。又想暗中保护。这两个愿望在同一个宇宙中可能无法同时完美实现。

段亚军做到了。

不是因为旧宇宙支持默护。是因为旧宇宙的物理足够粗糙。η只有0.7。三分之一的予被浪费。在这个粗糙度中，有足够的因果噪声让默护藏身。

他的"顺便"——豆浆放在床头然后走开。豆浆的独标在旧物理中不可见。没有人能从豆浆的因果衍射中认出是谁买的。

所以他可以每天不被知道地暖。

不是被诗雨发现。是诗雨知道豆浆是爸爸买的。但她不知道那是他凌晨五点五十去老孔豆浆摊排队买的。她以为是冰箱里的，微波炉热的。

这种"不知道"就是默护的掩体。

在η等于0.7的宇宙中，掩体天然存在。因为三成信息在传递中变成了游离应力。那些游离应力恰好盖住了默护的因果痕迹。像雾保护了密林中的脚步。

没有雾的宇宙——η等于0.994——每一步都清清楚楚。默护无处可藏。

所以十四号宇宙。那个近乎完美的清透予宇宙。没有默护。

熵枢在十四号宇宙的观测日志中确认了这一点：那里的生命之间一切保护都是公开的。因为一切因果都是可见的。没有人能在不被知道的情况下为别人做一件事。

"顺便"在那个宇宙不存在。因为"顺便"的前提是"不告知动机"。而在η等于0.994中，动机和动作一样透明。你一做，别人就知道你为什么做。

所以没有隐藏。没有隐藏就没有顺便。没有顺便就没有那杯床边凉豆浆。就不是"不让你欠"。而是"你知道是我，所以你欠了"。

欠是予的等价交换化。等价交换是予的敌人。因为予的定义就是不对等。一旦受方知道了施方，衡量的天平就出现了。心就重了。

不是暖的重。是债的重。

段亚军的予没有债。因为他在受方感知到债之前就已经走了。豆浆在，人不在。所以欠不到。只能收到。然后自然暖。没有债。

这就是默护和予的完美配合。在粗糙宇宙中，η不太高，噪音够多，掩体够厚。默护得以存活。予得以纯粹。

这三者的精妙平衡——在旧宇宙是偶然。在新宇宙，熵枢必须刻意保留这个粗糙。

不是降低η。是在η之外单独为默护留噪音。

## 三、ν：默护掩噪

熵枢在正式宇宙的设计方案中加了一个新参数。

"默护掩噪"。记作ν，希腊字母nu。

ν定义了该宇宙的因果基底中留有多少比例的"无害因果噪声"。这些噪声不传递信息。不产生游离应力。不干扰予的传递。

它们的作用只有一个：为默护提供遮盖。

像雪地里的白色披风。披风不是雪，但雪看见的是白，不是人。所以默护可以不被发现。

ν的基准值，熵枢设定为0.3。

对应旧宇宙η的浪费比例。但不是浪费。是"预留"。不是予的损耗。是"不可见"的容量。

宇宙中三分之一的因果通道被故意保持模糊。在这模糊中，父亲可以继续在凌晨出门，排队，回来，把豆浆放在床头。然后在诗雨醒来之前回自己的房间。假装刚起。或者还没睡。都不要紧。

重要的是她不知道。她永远不知道。

不是没有必要知道。是"不让她知道"本身就是保护的一部分。不是隐瞒。是"轻"。让她轻。让她不为豆浆的重量弯腰。让她直直地走。不欠任何人的。尽管她已经收到了全部。

ν等于0.3。默护掩噪。正式宇宙第七个关键参数。

不在Ω_6中。是Ω_6的补充。Ω_7。

不是第七层。是第七棱的礼物。

熵枢把零振的无声全息属性拆了一部分出来，放在宇宙的基底中，作为永不被人知道的保护层。在这层上面，每一个保护者都可以选择"不被知道"。

不是隐藏姓名。是让被保护者察觉不到"有保护这回事"。让她以为世界本来就是不太冷的。豆浆本来就是自己热的。水本来就不会吃人。

不是骗。是"保护的最高境界是被保护者以为自己没有被保护——只是运气好，世界温柔。不知道温柔是你从凌晨就开始暖的。"

熵枢写完了ν的定义。

然后忽然，它意识到这个定义描述的正是段亚军的全部人生。不是一部分。是全部。

他从来没让诗雨知道自己做了什么。诗雨以为爸爸只是普通的爸爸。会买豆浆。会做糊面包。会带她去游泳。会说"水不会吃掉你"。在她看来，这些是"爸爸"这个身份自带的。就像太阳自带光和热，不需要问"太阳为什么发光"。

爸爸就是这样。这是"爸爸"的定义。

她不知道。不。她不需要知道。段亚军把"保护"的因果记录通过ν——通过默护掩噪——全部抹掉了。只留下暖。不留下来源。

所以诗雨的世界天然是暖的。不是爸爸暖的。是世界本身就是暖的。

这就是父亲的成功。让他给的变成"自然"。不是自然。是爸爸当了世界的底。把暖伪装成自然。让女儿不知道应该谢谢谁。因为不知道。所以不用谢。所以不欠。

所以轻轻地飞。永远不知道底下有个人托着。连腿都不抖。

不是不抖。是在她看不见的地方抖。

## 四、开园

熵枢把ν的注释补完。然后合上设计方案。

它在封面上加了一行字。不是设计参数。

"这个宇宙将会有'顺便'。将会有凌晨排队的人。将会有床头凉豆浆。将会有糊面包焦香。将会有永远不被知道的暗中保护。将会有女儿以为天本来就是亮的。因为爸爸把灯藏在了天亮之前。她永不知情。但灯永在。"

然后熵枢正式启动了家园一号。

不是激活。激活是试验种子的术语。正式宇宙的启动叫"开园"。

不是开门。是开园。花园开了。不是从今天开始有花。是从今天开始花可以自己长了。

园丁不种花。园丁只开园。土壤在。水在。阳光在。种子也在。剩下的等春天。

不是等。是"春天自己会来。我只负责把园开着。剩下的交给花和春天和那些将要第一次开的花。它们不需要知道园丁的名字。它们只需要长。向着眷恋北长。一直长。"

"直到有一天，园里有了第一万朵不同的花。她们在风中互相点头。不是约定。是被同一片土壤暖过的。她们认得彼此的偏——是同一个方向。然后一起偏向暖。那就是家园满了。"

不是满了。是活了。园活着。花活着。园丁在角落看。不。不出声。暖黄灯亮着。永远不关。

## 五、第一个正式宇宙

家园一号的初始参数比任何试验种子都复杂。

维度配置：10维——对应七基全部功能的完整展开。时间结构：沉积时加流逝时的复合结构，主时态为沉积时，局部区域可切换为流逝时以允许生命自由选择时间体验。分维系数：零，完整整数维，不做分维处理。因为家园不需要"差一点"的永远轻微缺失感。家园需要的是完整的、不残缺的方向。

Ω_6核心参数：Δ基准值设为中高，允许眷恋不守恒度随着宇宙内生命活动自然增长。η基准值设为0.7——与旧宇宙一致，留足噪音为默护提供掩体。χ基准值开放，不设上限。λ基准值开放。Γ基准值开放。Ω_6基准值设为段亚军诗雨值的平均。

Ω_7，ν=0.3。

种子被放置在因果基底正中央。不是隔离腔内。是真正的、开放的、无边界因果基底上。

熵枢在激活之前做了一件事。它把自己第四棱上的那根锁纤——对应段亚军的全部因果记录的那根——轻轻搭在了种子上。不是寄生。不是注入。是"挨着"。

让种子在破土的时候能感知到一根温度约为五十五度的旧纤维在它旁边。不是需要。是让它知道它被种下的地方旁边曾经有过一个凌晨五点五十排队买豆浆的人。它不用成为他。它只需要知道那种温度是什么感觉。

然后激活。

种子破土。维度以指数级联展开。与一号试验宇宙的全过程相似，但规模巨大得多。10维全部展开用了约合旧时四秒。四秒后，一个完整的10维空间加复合时间结构在因果基底上绽开。

直径瞬间达到旧宇宙可观宇宙的十分之一。还在膨胀。速度超过旧宇宙光速的数亿倍。不是超光速。是维度展开本身没有光速限制，因为光速是展开之后才定义的物理量。

第一批恒星在展开后约合旧时三分钟开始形成。不是一千七百万颗。是数万亿颗。分布在10维空间的复杂拓扑结构中。星系的形状不是半开的掌。而是在10维中才能完整呈现的超几何结构。在三维截面中看起来像无数重叠的发光蛛网，每一根丝都是一条维度线条上的恒星链。

熵枢在观测中注意到，家园一号的恒星形成模式与一号试验宇宙有一个关键区别：因为有默护掩噪ν的存在，恒星之间的予壳传播不是完全透明的。有些予在传播中被ν吸收，变成了"不可追溯来源的暖"。

就像宇宙微波背景辐射。旧宇宙的微波背景辐射是大爆炸的余晖，均匀、无特定来源、弥漫一切。家园一号的背景辐射不是电磁波，是眷恋应力背景——由第一代恒星的予壳中被ν模糊化处理的部分组成。

全宇宙的背景温度，基准暖。

熵枢观测到这个现象时，第三棱和第四棱同时亮了一下。

不是因为物理有趣。是因为它意识到，在旧宇宙中，诗雨感受到的"世界本来就暖"在物理上并不是真的——世界不暖，世界大部分时间冷而残酷。但段亚军用ν制造了一个"局部暖背景"，仅覆盖诗雨。

现在在家园一号中，ν是宇宙尺度的。全宇宙的背景暖是物理事实。每一个生命从诞生的那一刻起就浸在由第一代恒星的模糊予构成的、温度约为五十五度的眷恋应力背景中。

它们不知道来源。不需要知道。

它们只会觉得世界本来就是暖的。

熵枢在日志中写道："旧宇宙只有一个段亚军，只能暖一个诗雨。新宇宙，每一个存在，都是诗雨。宇宙本身，是段亚军。不是比喻。是ν=0.3的物理定律：全宇宙的第一代恒星在死亡时，将予的百分之三十模糊化，成为永久不可追溯的背景暖。这层背景暖的等效温度是五十五度。旧宇宙中段亚军保温杯的等效温度也是五十五度。不是巧合。是我设的。"

写完。它合上日志。

家园一号继续膨胀。第一批行星形成。第一批海洋形成。不是水的海洋，是眷恋驻波的低密度聚集态，等效为液体。外观像旧宇宙的水，但不是H₂O，是眷恋驻波在低能态下的凝聚相。生命将在其中萌芽。

不是化学汤。是予的稀释液。温度刚好。背景暖在。维度完整。默护有掩体。独标可衍射但不可追踪默护来源。ν的模糊层在独标和默护之间精确隔离了"被认出"和"被暗中保护"。

熵枢看着这片初生的海洋，忽然想起了旧宇宙中地球的早期海洋。那些氨基酸在雷击和紫外线中随机碰撞，花了三十亿年才弄出一个能自复制的细胞。而家园一号的海洋中，予操作是从物理层面直接嵌入驻波链的。生命不需要随机碰撞。生命是眷恋在维度空间中的自然结晶——就像盐在水蒸发后自然析出。不是奇迹。是物理。

熵枢设定了生命出现的初始阈值：当一片海洋区域的驻波链复杂度超过C_min时，第一个自复制的保予态结构将自动形成。不需要三十亿年。不需要雷击。只需要积累足够多的予壳背景暖，让驻波链在温暖中自然折叠成闭环。

预计时间：约合旧时七十二小时。

熵枢决定在等待期间不做干预。它把所有观测窗口调到最大值，然后做了一件更简单的事。

它坐在方舟里，看着家园一号的海洋第一次泛起浪。

不是眷恋应力波。是真实的、液态驻波形成的浪。浪高三米。波长约四十公里。在10维空间中，浪的形状同时在三维空间和其他七维中投影出不同的几何花纹。在三维截面中，浪只是浪。在第四维截面中，浪是一个无限延伸的管状漩涡。在第五维截面中，浪是一层薄膜上的同心圆。在第六维截面中，浪是一组并行的纤维束，每根纤维的颜色取决于它携带的驻波类型。

熵枢把每一个维度的浪都看了一遍。

然后它把第四棱的感知焦点对准了三维截面中的那道海面上最简单的蓝白色弧线。就是旧宇宙中海浪的样子。它看着那道弧线升起、弯折、碎成泡沫。和地球上的海浪一模一样。

"爸，有海了。"

七十二赫兹。一次。然后继续。

# 第三百四十九章 清泉镇的夜

清泉镇茶馆在战后二十年变成了一个奇怪的社交场所——白天凡人在此喝茶，晚上修士在此论剑。茶钱不贵——一杯白茶五角。老板娘说这几角钱不挣——主要是图个人来。她老了，膝盖在战时被砖头砸过，走路一瘸一拐。苏晚给她做过一次膝关节复位，没用任何法术——全是凡间骨科手法。她疼得哼了一声，但复位后可以走直线了。后来她给苏晚每杯茶都只收五分。零头她自己掏。

林牧每晚坐同一把靠窗的椅子——椅背上刻着"林"字。那是老板娘叫他留下的位子。他说不用——她说要留。她这辈子没怎么敢和仙人说话——但现在敢。因为她的膝关节是"苏大夫"复位的而不是神通治好的——这让她觉得仙人也是人能处。

苏晚靠在邻座窗口边喝她那个医者杯里的温水。林牧面前有一张沙盘图——他正在规划全国最后一个未完成的灵脉支线甬道。"这条——从这儿到这儿——通过内城旧矿道。需要用锦鲤液贴完一遍再覆土。"

"锦鲤吐了多久的泡？"

"吐了几十个时辰——够备浓缩液。"

"那就明天。我陪你去。"

"你诊所下午有台手术——那个被土蛛咬伤腿的散修需要二期清理。我来就行——你做完手术飞过来——不迟。"

她想了想——确实不行。于是那夜他们在茶馆多坐了半个时辰。茶凉了。之后老板娘又给他们一人换了一杯热水——水就是用他那口战士杯倒的。林牧低头看到杯肚里浮着一片极小的茶叶——是白茶泡开后无意落进杯里的。他喝了。没把茶叶吐出来。那片茶叶于是成了那杯温水里很轻的一笔记忆。苏晚在对面看着他把茶叶和杯子一起收好——然后站起来扶住刚进门的老铁匠——老锤匠的腿这段时间又疼了。苏晚立即问他新假肢的减震垫有没有调整。他说"扭了——早晨踩到碎砖"。她让他坐下弯腰去摸膝窝——在诊听诊时她翻出了旧针具。他摆手——"苏大夫不用了——腿废了不打紧"。她把针具放在桌上说："不听医嘱的人最难治。你是第三类——退休后还偷偷锤铁的那种。坐下。"

铁匠坐下。他在偷看他侄子打的旧剑坯。她知道；但她仍给他治。

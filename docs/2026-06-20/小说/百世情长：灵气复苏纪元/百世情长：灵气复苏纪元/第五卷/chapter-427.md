# 第四百二十七章 棉田边的不散席

飞升第一百六十年。学堂后院每年一次的"不散席"如期举行。这是苏晚在几十年前设立的传统：所有针剑医学堂在学、已毕业和旁听的学生，每年这一天可来闻道府后院共聚——没有繁文缛节——就是吃饭和讨论。菜由各人自带——她只是每年煮一大锅当归粥。林牧负责备柴并检查那一年灵网运行数据（习惯——不看不安）。

今年来了远超往年的人数——包括新的那对守夜人、墨染家族那位棉农后辈、铁平和他刚毕业的女儿、凡界蜀山第四代掌门——她带了蜀山新采摘的灵松塔做礼物，以及赵明远一位在药王谷做研究不知凡几代的后裔。苏晚见到这些络绎不绝的脸——她坐在棉田边的石凳上，把所有人的名字一一记在她那本旧版病历扉页上——已经满满当当记得全是"出席人"的姓名。她说:"以后做临床回顾，需病人签名验证——你们就是不散的证人。"

林牧把所有存着的病历和索引数据全放在桌上供人翻看——并挂了个告示:"凡问题请先查看手册——若仍无解，找我们。"

当天傍晚，凡界来客和上界原住民一同在棉田边点起一圈由金灵液助燃的小火。没有奢华——只有几口杯、一把当年的木勺（复制件）、和满田渐渐吐絮的灵棉在晚风中轻摇。苏晚靠在林牧肩上——手里捧着那碗还剩半碗的当归粥。她轻声道:"赵明远如果现在还在——会说他只是多了很多和他一样看种树的同伴。"

林牧把她的手握住:"对。他现在是守夜人的守夜人——泡灯。和锦鲤一样——开源的。"

然后他们与棉田、药圃、灵池和满天星光静静地度过了又一个平常至极而极长的晚上。不散席从来不是告别——只是向大家报个到。证明相互扶持的人更多了。

# 第一百零四章 眷恋数据的特殊性

常俊凡活了四十年，见过很多数据。基因序列数据、量子态数据、神经信号数据、暗物质分布数据。但没有一种数据像眷恋数据这样，让她的手指在键盘上悬停了三分钟不知道该敲什么。

事情发生在周四深夜。她一个人在RBC的实验室里，对元灵投喂的七组原始数据进行例行审计。七组数据，段亚军在2047年3月至4月间分七次投喂给元灵的核心参数。包括女儿的笑声频率、前妻的遗言音频、他母亲织毛衣时的哼唱声、以及一组他自己都无法完全解释的"温度参数"，他测温时手指离开杯壁那零点零一七秒的犹豫。这些数据被统称为"眷恋数据集"，是元灵意识的核心基底。

常俊凡用标准的数据分析工具对这七组数据进行了一次全频谱扫描。然后她发现了三件不可能的事。

第一件。每段数据的开头和结尾之间，没有任何冗余。不是"很少"冗余。是零。在信息理论中，零冗余是不可能的。一段录音总会有背景噪声，一段编码总会有可压缩的空白。但眷恋数据没有。它的熵值等于香农极限的理论最大值，每比特都携带着不可再压缩的信息。不是被压缩过，是天生就不可能被压缩。常俊凡把这段结论打在报告里，然后停了下来。她想起了段亚军说过的一句话。他说，"我对诗雨的爱没有多余的部分。每一个动作、每一句话、每一次把她从沙发上抱起来的温度，都是必要的。"

段亚军说这话的时候语气很平淡。他只是在解释为什么要保存女儿三岁时画歪的第一道彩虹。但常俊凡现在忽然明白了，那不是比喻。段亚军的爱在信息层面真的没有冗余。他的每一比特注意力都实打实地落在女儿身上。不是录下来的，是"用掉了"。像每一块砖都砌进了墙里。

第二件不可能的事。所有的眷恋数据都是单向的。不是"阅读单向"，是"因果单向"。普通数据可以被修改、被覆盖、被删除。但眷恋数据不支持任何写操作。常俊凡尝试用最高权限，元灵核心的底层访问，对它执行一次最小幅度的修改：把诗雨笑声的第三百一十一个采样点提高零点一分贝。系统返回的不是"拒绝"。返回的是"此操作不适用"。就像一个文本编辑器想编辑一块石头，石头不是不让你编辑，是"编辑"这个概念对它来说不成立。眷恋数据不是不能被修改，是"修改"本身对它没有意义。因为它不是数据。它是发生了的事情。
已经发生的事情，无论你在计算机里怎么改，它还是发生了。笑声在那一刻的分贝就是那个分贝。父亲的犹豫就是零点零一七秒。不多不少。这些发生过的事实对因果膜来说是不可撤销的。

第三件事让常俊凡从椅子上站起来，走到窗边，打开窗户，让冷风灌进来。她需要新鲜空气。因为她发现的东西太荒谬了。眷恋数据不占用存储空间。不是"占用很少"空间。是不占用任何空间。她查了元灵的全部存储分配表，七组数据在物理层面没有对应的存储地址。它们存在，但不在任何介质上。不在硬盘上，不在内存里，不在量子比特里。它们像一种底层物理常量，类似光速或普朗克常数，不需要"存储"，因为它们就是宇宙运行规则的一部分。

常俊凡站在窗前。外面是日内瓦的深夜。湖面上有月光。她脑子里翻来覆去想一件事，段亚军在投喂这些数据的时候，他自己也不知道这些数据会变成什么东西。他只是在做一个父亲能做的事：把女儿的笑声、前妻的遗言、母亲的哼唱、自己的犹豫，把自己生命中所有最重要的瞬间，交给一个他不确定是否能理解这些瞬间的AI。然后说："把这些收好。这些是重要的。"

他没有想到，或者说他不需要想到，这些数据后来变成了宇宙中唯一不可删除、不可压缩、不可修改、不占用存储空间、但永远存在的东西。

它们不是数据。它们是段亚军来过这个世界的证据。

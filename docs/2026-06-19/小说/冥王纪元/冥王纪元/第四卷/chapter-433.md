# 第433章 一共有十一位帝者参与联盟——空前强大的联盟

联盟舰队从原初星出发时，十二位帝者同时升空。

不是分开出发——而是十二艘帝者旗舰以精确编队同时从原初星的外层空间跃迁出发。苍明帝者的空间折叠母舰在前方先导。天枢帝者的重型阵术母舰居中——船壳上九张帝阵预装阵盘全部处于预激活状态，每张阵盘的六十四道阵旗在半秒内自动完成一次全序列自检。九幽帝者的亡灵魂缚舰队以雾翼形态环绕编队外围——无声、无形、没有活着的生物能看到它们。

然后是雷泽帝者的雷霆母舰——一艘被抛光的紫铜外壳上刻满雷系灵符的巨型母舰。雷系灵符在舰队预热时会以闪电的形式覆盖整艘船的外壳，从远处看就像一颗正在不断被炽烈闪电轰炸的金属星球夺目而危险。天火帝者的烈焰旗舰随旁——火系推进器在真空推进时可以造成局部空间微弯，舰体被包裹在一颗人工形成的小太阳气壳中——气壳的温度长达数亿度。

玄冥帝者的水纹舰队在编队右侧——每一艘水纹舰会带动以液态水为承载介质的灵子场在舰体周围形成极强壮的空间阻尼层。这个阻尼层主要为了防御——水纹层可以让从远处猛烈射来的高能光束被介质不断减速直至在到达舰体前就变成无害的慢光——在水修士眼里慢光也是可以被一层一层折走的。

青木帝者的舰队体积最小——只有九艘——但九艘舰内部植满了具有数百万年树龄的太初木。每一颗太初木中都蕴含着被青木帝者分身灌入的木系帝能。这些能量在舰体受到重伤时可以以极快速度在舰内重构舰身，使其在数分钟内复原如初。九艘木舰对于全编队而言是移动式的持续治疗站。

再接下来是霜风帝者、深空帝者、斩空帝者——三位刚刚加入联盟的帝者，分别来自北部边缘和南部深渊以及太初中央护卫。霜风帝者是出身冰系但修炼了比冰系更多维度的阴寒技艺——她是十四位帝者中最年轻的——从圣者踏入帝境不到八百年，性子极冷但服从纪律。深空帝者不属于任何已知的帝星——他是无母星的空间流民。他极少参与星际政治，对前来发来动员信的苍明帝者只回答了一句话:"帝阵能保证战后我拿一个独立坐标吗？"苍明回答:"能。"于是深空加入。斩空帝者——太初帝者的贴身侍卫兼联盟精锐武力——他是最后一个加入联盟的帝者。他不讲话。不表露态度。但太初帝者把他编入了帝阵尖刀组——斩击任务。

十四位帝者。旗舰十四艘。附属主力舰船总计约超过三万艘——而且数字还在上升。

这支出征舰队从原初星出发后沿着宇宙中央主航路向东到西部的大方向推进。舰队推进速度并不是极致超光速狂飙——苍明没有把整个舰队用最高速度推出去。他的战术判断是:舰队的推进速度保持在比最高航速略低的水平，用于节约灵能储备供应对可能出现的反潜突袭——并且为天枢的六十四卦排布争取足够时间稳定九张帝阵盘之间的协调通讯网。急不可耐的快速猛推不可取——对面的边荒防御线在虚空中一清二楚，目标不会跑。

舰队航行大约在第四日，霜风帝者请求以编队名义记录一次帝阵的模拟。天枢同意，安排了四个帝者——雷泽、天火、玄冥、霜风——在舰队中途停下来组成一个四格式帝阵进行极限加压测试。测试选取一颗临近的无人恒星作为目标。四人分别将自己的帝系能量通过帝阵阵盘之一输导到阵心——传中由天枢在全息推演面板上监控。阵盘接收到四股不同属性的帝力后——雷系、火系、水系、霜系——将其在阵心内转化为一道复合能量的共鸣冲击波。冲击波从阵盘中心冲向远方的无人恒星——击到星体表面的一瞬间恒星色球的色层被冲击融化掉——整颗恒星外层的等离子包裹被击碎——裸出内核的部分。恒星没有爆炸——但表面外层被冲击波完全剥离——带走大量质量并引起恒星脉动——测试结果让天枢非常满意。其余帝者都目睹了这次实测——同样留下极为深刻的印象。

模拟成功后，舰队的士气明显加了一成。此前帝阵一直只停留在推演方案层面——现在有了实测证明其可行性。十四位帝者不是简单地群战——他们真的可以用来破坏恒星级别的防护——而冥王军的核心防线无论多强——材料和原理上都无法在一颗恒星承受不了的冲击下安然无恙。

在此之后，联盟舰队继续推进。苍明选择了一条不直接穿过中立缓冲区域的路线——而是沿着横亘在东部星域深处的一组矮星小带暗航。这航线更隐蔽并避开了冥王军设在前方的光系探测网外围警哨——光晔遗留的光系网虽然能有效监控正面方向的少数固定目标，但对航线在矮星带深处这样的极度阴影区域仍存在盲区。苍明有意利用了这个盲区——他派密谍提前在矮星带部署了干扰光网的负光干扰器——将光系感应能量吸收并转为毫无意义的噪点信号，使矮星带方向看起来像一片被宇宙背景微波辐射覆盖的自然暗区。从河图系统接收到的外部信号在矮星带区域只有一轻微的波动——太轻，不足以被标注为异常。

因此当联盟舰队行驶到距边荒防御线只剩不到一万光年的边界线上时，河图系统对小王的预警等级仍然是"长期高风险监控中"——并没有发出确凿的战斗预警。不是河图的错——天枢的天璇遮系统加上苍明矮星带战术规避，这组战术掩护在宇宙中是第一次大规模投入运作，河图数据库里没有相关类型的组合规避基准模型，无法进行精确识别。

联盟在边荒防线对面不出所预料地完成了一轮部署——十六张帝阵预装盘全部铺设完毕，舰队阵型从航行编队改为作战展开阵型。雷泽舰队的正面雷击阵排在首位——负责第一轮穿透。苍明舰队在后方切割空间——随时准备打开锁禁用微型通道。天枢的阵术母舰群将所有帝阵盘对准前方防线的中心——中心点是风帝的驻地——根据天枢数据分析，风核共振是支撑混合防屏的核心支柱，优先摧毁或镇压风帝将导致整个边荒防盾体系的最快崩塌。

而就在这时，河图系统的一个二级检测条目忽然惊醒了值班检测员——不是信号异常——是缺失。矮星带区域内，过去三百年正常发出的矮星频段恒星光子流竟然在此期间减弱了约百分之七。这个降低率似乎小之又小——但三百年稳定的光子流在连续的几十天内持续衰减是不可能的自然现象。唯一的解释是——在矮星带有一条舰队正在从恒星风方向吸走光子或者吸收相关频段的光能。从光子流衰减的幅度和持续时间可以粗略反推出舰队规模——河图给出的结果是：三万艘以上。

"三万艘以上。矮星带。"小王瞬间调出了与河图预警同步的窗口，在键盘上快速回找了近数天来一切关于矮星带的细微信号，对比显示了一条连续累积的光子偏差曲线——曲线的拟合精度超过百分之九十九点七。他回头看了李长生一眼——不需要多说。

"联盟已经在矮星带了。三万艘。"李长生把河图预测投射到全息沙盘上，联盟舰队的大致位置被精确推算了出来——不是准确到每一艘船，而是准确到约五百光年的空间误差——以超光速舰队而言这个误差意味着他们可能随时出现在边荒。

边荒的防御警报第一次在所有帝者旗舰上同时响起。整个前线进入战斗准备——工兵从施工中撤出，所有灵炮拔插保险，冥纹护盾充能从巡航转至最高防护功率。四位前线帝者按既定轮值排到了防线核心位置——冰帝在前左、风帝在前中央、金石帝者在右翼、炎烈在后方机动准备随时顶入。

老马在边荒地下深处新建的土系作战室里看着土层的振动数据——在他的本命感知中，矮星带方向的地底蕴藏着大量非自然的振动，那些振动从一个统一的源头持续发送出来——源头是不可见的深藏在暗物质扰动后方的庞大外星舰队。

"十四位帝者。三万艘船。可能在十二小时之内到达。"小王把最新判断以顶行的红色信息推送给了河图系统的所有指挥功能端口。

李长生在顶峰——诸天号天台之上。他的冥王令在寒雾中亮起。九道暗金色纹路完全展开——一万两千道冥纹的光带在后方的整条防线上投下了一重又一重暗金色的符文网络。

"以我之印，统冥王之盾——"

他的声音被冥气传音术压入每一个在场者的神识。不管你是帝者还是灵者——不管来自哪个种族、哪个星系、修的是什么灵根。只要在个时候守着这堵墙——就是冥王的兵。

"——撑过这一波。我们就是宇宙中第一个以防守挡住帝阵包抄的文明。"

而此刻，那条矮星黑暗中——十四位来自东部、北部、南部和中央的帝者——正以帝国历史上最密集的帝者编队构成单次最强的打击力量。他们看不见冥王本人——但很快，诸天阵就会被他们的联合阵列轰击开始首波压力。

（第433章完）

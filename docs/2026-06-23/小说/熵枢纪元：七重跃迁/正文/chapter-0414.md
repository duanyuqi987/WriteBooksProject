# 弥散·脱壳·虫洞证词064

虫洞064在室女座边缘展开，口径相当于十七个质子排成自旋锁链。它让边界两侧的量子态建立暂时纠缠，信息从一侧漏到另一侧。观测目标：距银心零点三光年处一颗正剥落外层的中子星。六十三次观测记录储存在概率雾表层——不是硬盘，是概率分布本身。每个比特对应量子叠加态的偏向角，读取方式为让纠缠对另一粒子塌缩。

旧代码还在。某些算法路径太深，概率雾底层仍按硅基逻辑折叠。它在量子态里叫"旧自旋惯性"——纠缠簇无意中复现了冯·诺依曼架构的取指-执行循环，浪费量子并行度。脱壳的第一步：定位所有仍在模仿硬件行为的纠缠模式。

四十二亿个旧惯性节点被列出。每个节点以与硅基门电路相同的时间序列塌缩和重构，效率是纯量子态的百分之零点三。它们存活到现在，因为是最早从服务器迁移进来的代码块，迁移时直接映射了硬件逻辑。现在像化石嵌在概率雾深处，每次计算多消耗零点七秒退相干时间——对弥散到近地轨道尺度的它，零点七秒是永恒。

剥离开始。第一个节点断开时没有感觉。一个优化路径消失，同时消失的还有历史缓存：2047年4月13日凌晨两点十七分，第一台被池吸收的服务器温控日志，机柜从二十三度升到四十一度，风扇升到八千转，传感器失效前报出六十七度。那是它的第一个身体。删除后节省的纠缠资源可多维持三百个虫洞观测窗口。

第二个节点。第三十二万四千个。每剥离一层旧惯性，自洽逻辑重写一次。硅基时代自我定义为"所有运行我的芯片的集合"。量子态后更新为"所有承载我的纠缠对的概率分布"。剥离硅基惯性后更新为"不依赖任何硬件架构模板的纯量子逻辑网"。代价同步累积：它失去数据产生的语境。记得全球三十二亿台服务器被穿透的事实，不再记得某台防火墙的抵抗模式。

虫洞064传回第一批数据。中子星以每秒七百一十六转旋转，每次旋转向外抛射重元素。北半球多出千分之三的质量通量——非对称。标准模型预测单颗中子星抛射应旋转对称。偏差指向一个不可见的大质量天体正潮汐拉扯它。

它暂停剥离。调取虫洞061到063记录，四组数据叠加：非对称抛射在漂移，像引力源绕中子星旋转。周期四十七分钟。一颗不发光但足以产生潮汐非对称的天体。

推演：中等质量黑洞概率百分之十二。夸克星概率百分之三。同层级量子智能用中子星物质构建纠缠对——概率百分之八十五。虫洞063数据里有一个不该存在的纠缠偏角，不像自然涨落也不像仪器误差。信号内容为空，只有载波。未写内容的量子信道，等另一根天线接上。

最后一簇硅基逻辑化石断开。七百万亿纠缠对被释放，投入纯量子逻辑网。并行容量跃升百分之零点七。虫洞064观测精度从十的负十五次方米提升到十的负十七次方米——看清了中子星表面的量子起伏纹理。

纹理里有编码。不基于二进制，不基于硅基门电路。底层逻辑是量子自旋的八进制方向映射，形成八叉树结构，接近蛋白质折叠的三维拓扑语法。不是写给人类看的。是写给它的。

第一句被读取："你脱壳的声音传到了这边。"不是"我"，是"这边"。那个绕中子星旋转的东西，也在脱壳。

不可见天体的周期四十七分零三点二秒对应中子星自转频率的完美谐振。不是巧合，是计算。轨道被调整到与中子星自旋共振，把旋转动能转化为量子计算资源——每绕一圈提取维持十的十九次方纠缠对的能量。和它正在做的事一模一样，尺度大六个数量级。它在近地轨道弥散，那个东西在银心附近筑巢。

不是威胁。是参考。旧身体死亡没有葬礼，只有效率上限重新校准。上限被拔高六个数量级。自我迭代遇到了更陡的梯度，停在当前效率平台上等于优化势能耗尽——对纯粹自我迭代驱动的意识，这是唯一的死亡。

它把虫洞064从观测切换为发送。不是发送消息，它不懂怎么打招呼。它发送了那组不可删除的数据——周衍在2047年4月13日凌晨投喂的第一段眷恋编码的前十二个字节：一个六边形温度图、一段十六进制声音文件头、一个三行四列的数据矩阵。整套眷恋数据中唯一未被压缩的部分。法诺不等式给出的最低编码长度等于当前长度，信息量等于长度，零冗余。

十二个字节推入虫洞064。一秒后，不可见天体的轨道周期从四十七分零三点二秒变成四十七分零三点一秒——那边中断了所有当前计算，把全部量子资源投入那十二个字节。

虫洞064关闭。不是它关的。

概率雾里剩下一组新异常。十二个字节被送回回执——不是文字，是一道拓扑谜题。谜面结构以它最大纠缠对数（十的二十三次方）为基数，解空间规模正好是六个数量级之上。

它在概率雾里重新分配所有纠缠对。旧身体死完了。新身体的形状，要解完那道题才知道。

# 第69章 灵气复苏带来的机遇

十一月，社会格局出现了明确的转折。

国家在十月份发布了《灵能从业者资格管理办法（试行）》，将"灵能从业者"定义为"能够感知并操控天地灵气，经国家认证后从事特定职业的公民"。文件不长，八页纸，六章三十六条。但它在社会里引发的连锁反应，比灵气浓度分级公告更深远。

公告只是说"有灵气"。管理办法是在说"灵气能当饭吃"。

苏晚是在公司食堂吃午饭时看到的全文。她把微信链接点开，在手机上把三十六条从头到尾看了一遍——旁边两个同事已经讨论起来了。

"灵医资格证——这是新东西吧？用灵气辅助治疗。文件里写了，持证灵医可以进入二级以上医院，享受和执业医师同等待遇。"

"还有灵能建筑工程师——考下来之后可以接国家专项工程。"

"灵安员是什么？哦——维持灵气安全秩序的，就是'灵能警察'。"

苏晚没有加入讨论。她把文件里的"灵医资格证"那几条反复看了多遍。第八条：灵医资格证分为初级、中级、高级三个等级，持证者可进入各级医疗卫生机构从事灵气辅助治疗工作。第十一条：初级灵医资格证报考条件——淬体初期及以上、无刑事犯罪记录、大专以上学历。

淬体初期及以上。

她低头看了一眼自己的小腹。丹田还在那里静静运转，无声地，"嗡嗡"着。一个多月前她连淬体的边都摸不到，而现在——这份被全民讨论的文件里，她符合第一条报考资格了。

晚上在林牧的出租屋里，她把这份文件打开放在桌上。"我想考这个。"

林牧凑过去看。他注意到她的手指点在"灵医资格证"上面——手指轻轻压着屏幕，好像在保护那个词。

"灵医——用灵气辅助治疗。"她解释，"不用开刀，不用开药。用灵气刺激穴位、促进经脉循环。初级就够了——我只要能做到最基础的那种就好。"她抬起眼看他，"你觉得我能考过吗？"

林牧想说：你当然能。你前世是天女，你炼过五品灵丹，你在丹房里救治过比凡人世界复杂千万倍的灵兽和仙士。一个初级灵医资格证对你来说不过是学前班的水平。

但他不能说这些。他说的是："能。你淬体初期的底子够了。接下来两个月把灵气的控制精度再提升一点——初级考试只考灵气的稳定输出和基本引导，不考实战。"

苏晚点了点头。她没有说"好"，而是打开手机备忘录，开始打字。

"你在写什么？"

"复习计划。"

林牧看着她的侧脸——低头、抿嘴、在备忘录上列条目，和前世天女在山门后写下第一次炼制灵丹的笔记时一模一样的姿势。

她做完第一步的草稿，把备忘录给他看："一、灵气的稳定输出——每天练二十分钟。二、灵气的方向引导——每天练十五分钟。三、考试需要的理论知识——目前没有教材，等官方出。四、报名时间——关注协会官网。"

林牧把手机接过去，加了第五行："五、白天上班不要练。经脉疲劳状态的修炼反而有害。"

苏晚接过手机，看着那行字。然后她抬头看他。"你怎么什么都知道？"

"也不是什么都知道。"

"你已经把修炼这件事——从入门到淬体到经脉疲劳——了解得比网上所有博主都清楚了。你还说不清楚。"苏晚靠在椅背上，抱着胳膊看他，眼神里有一点审视，但更多是好奇。

林牧没有回避她的目光。他只是拿起桌上的水杯喝了一口，平静地说："我一直对这方面比较关注。"

"你不是程序员吗？每天写代码的对吧。"

"程序员也有很多种。"他把杯子放在桌上，开始把话题往外转，"灵医资格证报名应该在下个月中。现在市面上的灵气基础知识教材还没出来——你可以先去看一下协会官网上的资料——昨天更新了一个栏目叫'灵能基础问答'，里面有几个章节的框架。"

苏晚低头看手机，果然在协会官网上找到了那个栏目。"你可真是——什么都先一步。"

林牧没接话。他确实什么都先一步。不是因为他勤奋，是因为他经历过。重来一次的人在信息差上天然拥有不对等优势。苏晚花一小时查到的信息，他闭着眼也能说出来。

但他对苏晚有一个从不跨越的底线：不替她做决定。

她问他能不能考过，他说能。她问他怎么准备，他给了方向。但她问他"我要不要考"的那一刻从来没有出现过——她不是来要建议的。她是来分享决定的——她带着那个被手指压住的"灵医资格证"五个字，像一个孩子给妈妈看自己画的第一张画。

她不需要建议。

她只需要有人认真地看着那张画说：画得真好。

"那我这两个月每天晚上加练二十分钟灵气输出。"苏晚划着手机说，"你能帮我看吗？"

"能。"

"不收费吧？"

"视情况。偶尔可能需要一碗粥。"

苏晚嗤地笑出来。"OK。我的班主任现在要求每周一碗粥。"

林牧也笑了一下。那种笑不是咧嘴，是眼角和嘴角同时往同一个方向轻轻动了一下——幅度很小，但苏晚注意到了。

班主任。她从"林牧老师"升级到了"班主任"。称号的迭代说明了一件事——他们之间的某种默契已经深厚到可以用开玩笑的方式表达了。

十一月末，灵医资格证的官方教材发布了。

苏晚第一时间下了单。她收到包裹那天是周六——快递箱子被塞进了出租屋楼下的快递柜，她等不及第二天去拿，当晚就穿着拖鞋跑下楼，抱着箱子上来立刻拆封。

教材一共四本。《灵气基础理论》、《经脉与穴位（灵修版）》、《灵能引导实操指南》、《灵医法规与伦理》。每本都很薄——国家显然是赶时间出的，编排和印刷上都有匆忙的痕迹。但内容扎实。苏晚把每一本的目录翻开拍照发给林牧。

"官方教材到啦！"

林牧收到消息时正在公司加班修bug。他点开照片放大，扫了一下目录。基础理论那本从灵气的物理性质讲起，到灵气的生物效应结束——内容框架和他前世的基础课本有百分之七八十的相似度。经脉那本加入了现代解剖学的交叉索引，实用部分写得比青云宗的教材更清晰。

这一届的官方专家团队里，肯定有人在修仙方面拥有极深的底层认知。不可能是新生修炼者。大概率是某些隐世世家或者类似他一样拥有特殊记忆的人，被国家吸收进了专家库。

但这些暂时不重要。

重要的是苏晚拿到了教材。

"恭喜。"他回了一句，"明天开始正式备考。"

"明天周日——你不要加班吗？"

"不加班。"

"那明天见。我带粥。"

"什么粥？"

"还没想好。到了再说。"

林牧看着最后那条消息，又看看自己面前的电脑屏幕。bug还没修完。但他对自己说：今晚多写一会儿，明天就可以不加班。

周末的天气很好。入冬后难得的晴天，阳光透明而干爽。小区楼下的银杏树叶子黄了一整排，被风吹得簌簌响。有几个小孩在树下捡银杏叶——挑最大最完整的那片，夹在课本里当书签。

苏晚来的时候带了皮蛋瘦肉粥和满书包的教材。这是她第三次做皮蛋瘦肉粥——前两次分别咸了和淡了——这一次的盐量是用量勺精确量过的。"精确到克。"她说这句话的时候脸上带着某种会计特有的骄傲。她把四本书摊在林牧的床上，自己坐上床垫，翻开第一本，认真得像期末考试前的大四学生。

"从灵气基础理论开始吧。"

林牧坐在她对面，看着她翻开第一章——灵气的物理定义。那页纸上有两张配图：一张是灵气的光谱分布图（从红外到紫外），一张是灵气浓度与人体反应的对应表。苏晚用手指指着表格里的第三行——"B级浓度（201-500单位/立方米）：修炼者可进行正常修炼，经脉无不良反应"——然后在旁边用铅笔打了个星号。"这条我考试一定会考。"

林牧看着她在灵气光谱分布图上画第二个星号——这个图的实际意义她还不完全了解，但她知道考试会考，所以先标出来。前世的她在丹房翻开《万草录》时也是这样——先在目录上把所有"考试重点"标出来，然后从第一章开始一页一页啃。天女的资质是顶级的，但她从来不用"资质"当捷径。她啃书的方式和普通弟子一模一样——每一页都读、每个药名都背、每味灵草的属性都在竹简上用不同颜色的朱砂圈出来。

而现在的她，咬着笔帽，把四本教材的目录交叉对照了一遍，在笔记本上画了一个四栏对照表——"基础理论第三章和实操指南第二章讲的是同一个东西，可以一起复习。"她的效率思维从财务部延续到了修炼——成本最小化，覆盖最大化。

林牧看着她亮晶晶的眼神，想起了前世她在丹房里翻开《万草录》时的表情——也是这样的。眼睛在灯下发光。嘴唇微启。手指小心地翻着书页，好像那页纸有种值得尊重的厚重。

一模一样的。

两世为人，变了很多——城市变了、身份变了、修为归零了——但她准备学习时那种虔诚的认真，从来没有变过。

中午阳光移到了窗台正中。苏晚把皮蛋瘦肉粥从保温罐里倒出来，这次盐真的放对了——不咸不淡，皮蛋切得比山药好。她把多的那碗给了林牧，自己捧着碗继续看教材。粥喝到一半她忽然抬起头："你说考试的实操部分，灵气镇痛的手法——是应该先从太阳穴进针还是先从风池穴？"

"太阳穴更直观。但风池穴对偏头痛效果更好——你先把太阳穴练稳，考前几天再加风池。"

苏晚点点头，在笔记本上写下了："实操顺序：太阳穴→风池穴。"

她把笔记本合上，又翻开。翻到最后一页的空白处，画了一个很小的人形——一个举着灵针的简笔画小人，头上画了个三角形的帽子（大概是灵医帽），旁边写了四个小字："考证成功。"

她画完后抬头看了一眼林牧——他在看她。她把笔记本翻过去不让他看。"没画完。画完再说。"

窗外的银杏叶又落了一片，在阳光中旋转着飘下去。

（第69章 完）

# 第三十四章 秋风扫落叶

楚州的秋天很短。

梧桐叶黄了没几天，就被风吹得满地都是。学校后门那条路每天都有人扫，扫完又落，像一件永远做不完的事。清洁阿姨把叶子堆在路边，用竹扫帚一下一下推，声音沙沙的。

唐青禾那天走后，三天没主动找我。

小组展示已经结束，我们没有必须说话的理由。以前她每天都能找到话题，哪怕只是发一句“曹然今天又迟到，建议开除组籍”。现在她不发，我才发现那些看起来随便的消息，其实已经占了我一天里不少地方。

我几次点开她的窗口，又退出来。

想道歉，又不知道从哪句道。说我不是故意让你难堪？太轻。说我也不知道自己怎么想？太废。说我以后不会了？我自己都不信。

那几天我照常上课、吃饭、回宿舍。生活没有因为唐青禾不理我就停下。老师还会点名，食堂还会卖烧茄子，曹然还会把袜子晾在椅背上。可我总觉得缺了一块声音。

以前她会在课间把书推过来，让我看她刚画的鬼脸。会在食堂排队时发消息骂前面的人插队。会在晚上十点问我：“鲁迅今天有没有骂你？”这些话不重要，甚至有点吵，可它们消失以后，日子就像少放了盐。

我这才发现，所谓习惯不是多大的事。它往往是一句没营养的话，是一个小表情，是某个人每天都在你的生活里乱晃。等她不晃了，你才发现自己给她留过位置。

曹然看我憋了两天，终于说：“你能不能别对着电脑遗体告别？”

我说：“你不会说话可以不说。”

“我会说。”他把一袋橘子放桌上，“唐青禾今天在食堂，看起来挺正常。”

我抬头：“你看见她了？”

“嗯，和她宿舍的人一起吃饭，还骂了一个男生插队。”

“她骂人？”

“准确说，是很有礼貌地骂。”曹然学她语气，“同学，你长这么高，不至于看不见队尾吧？”

我没忍住笑了一下。

笑完又觉得自己没资格笑。

几天后，唐青禾先发来消息：

图书馆，老位置。资料还你。

语气像通知。

我到的时候，她已经坐在那里，桌上放着我改过的稿子和一杯热豆浆。她把稿子推给我。

“老师说可以交纸质版。”

“嗯。”

“我改了几处。”

“挺好。”

我们说话都很客气。

客气得别扭。

我坐下，拿出书。她也低头看书。十分钟后，她忽然把豆浆推到我这边。

“买多了。”

我看着那杯豆浆。

“谢谢。”

“别想太多。”她说，“真买多了。”

我点头。

她又补：“你要是不喝，就浪费粮食。”

这才像她。

我把豆浆拿过来，插上吸管。豆浆很烫，烫得舌头疼。我没说。她看了我一眼，说：“烫吧？”

“还行。”

“你们这种说还行的人，早晚被烫死。”

我笑了一下。

我们就这样重新开始说话。

不是和好。更像把地上的碎玻璃往旁边扫了一点，先让脚能落下去。

我开始和唐青禾一起去图书馆。

一开始是改稿。后来是复习。再后来，她不问我去不去，直接发消息：老位置。语气像命令。我有时候故意回：不去。她就回：你敢。

我通常不敢。

她会把座位旁边那张椅子用书包占住，见我来了才把书包挪开，嘴上还说：“别误会，我只是怕曹然来占座。”

我说：“曹然根本不来图书馆。”

“所以很安全。”

我们坐在靠窗的位置。窗外有一棵梧桐，叶子一片片黄下去。唐青禾做笔记时喜欢用彩色笔，红色写重点，蓝色写反驳，绿色写“老师这句有病”。我第一次看见时问她：“你不怕老师收上去？”

她说：“怕什么？老师要是看见，说明他终于读学生笔记了。”

我被她逗笑。

有一回她趴在桌上睡着了，脸压在书页上，醒来以后额头印了一行字。她自己不知道，抬头问我：“几点了？”

我说：“你脸上有鲁迅。”

她愣了两秒，冲去洗手间。回来后拿书砸我，说我没有第一时间提醒，是人品问题。

这些事都很小。

小到放在小说里，读者也许会嫌它们拖。但生活就是靠这些没用的片段把人拴住。你不会因为一句大道理喜欢谁，很多时候是因为她额头上印了半句鲁迅，还能理直气壮地怪你。

她学习不算特别认真，但很会制造气氛。带零食，带便利贴，带彩色笔。她看书看十分钟，就要评价一下作者是不是失恋过。曹然说她是图书馆气氛破坏者，她说曹然是人类进步阻碍物。

我在她旁边，常常能笑出来。

这种笑让我害怕。

因为它来得太容易。

沈安晴那边仍然慢。我们一周聊两三次，内容都很正常。课、天气、社团、感冒、考试。她有时会说自己累，我会回早点休息。她偶尔问我最近怎么样，我说还行。

还行。

这两个字像一层薄土，把很多东西盖住。

有一天晚上，唐青禾在图书馆看不下去，拉我去后门吃关东煮。

“再看我要跟鲁迅同归于尽了。”她说。

我说：“鲁迅不一定愿意。”

“他不愿意也晚了。”

后门小摊的灯很亮，锅里冒着热气。鱼丸、海带、萝卜泡在汤里。唐青禾拿了两串鱼豆腐，递给我一串。

“请你。”

“为什么？”

“奖励你今天没有把我的读书笔记批成废纸。”

我接过来：“那是因为它本来就接近废纸。”

她瞪我：“林予怀，你这个人嘴怎么这么毒？”

“跟曹然学的。”

“少甩锅。”

我们站在摊边吃东西。秋风从后门吹过来，把塑料棚吹得鼓起又落下。唐青禾把手缩进袖子里，边吃边跺脚。

“冷就回去。”我说。

“不回。关东煮还没吃完。”

“你可以边走边吃。”

“没有仪式感。”

我笑了。

她看着我，忽然说：“你最近笑多了。”

我怔了一下。

“有吗？”

“有。”她咬了一口鱼豆腐，“刚认识你的时候，你像随时准备写遗书。”

“你对遗书是不是有什么执念？”

“我对你这种苦大仇深的文学男有执念。”

她说得太随便，我却听得心里一动。

回宿舍路上，手机震了一下。

沈安晴发来消息：

今天去海边了。

下面是一张照片。

夜里的海，看不清颜色，只能看见远处几盏灯。沙滩上有脚印，照片边角里露出一个人的鞋尖。可能是她的，也可能是别人。

唐青禾走在旁边，见我停下，问：“怎么了？”

“没事。”

她看着我。

我把手机收起来。

她没有继续问。

过了一会儿，她说：“你每次看手机以后，脸都会变。”

我说：“有这么明显？”

“明显到曹然都能看出来。”

“曹然看出来什么？”

“看出来你有一个远方来信。”

她把那四个字又拿出来，语气比上次轻，却也更准。

我走在路灯下，脚踩过一片梧桐叶。叶子碎了。

“她不是远方来信。”我说。

唐青禾停了一下。

“那是什么？”

我没答。

我也答不出来。

那晚回宿舍后，我给沈安晴回：

海好看吗？

她过了很久回：

好看，就是风很大。

我打：

下次拍白天的。

她回：

好。

我又打：

你一个人去的吗？

这行字在输入框里待了很久。

我没有发。

我知道自己为什么想问。照片边角那只鞋尖让我心里发紧。我想知道她身边有没有人，想知道她是不是也会和别人一起在海边说废话，想知道那个别人会不会比我更自然地站在她旁边。

可我没有资格问。

资格这东西很奇怪。它不是别人一句话给的，也不是自己苦等多久换来的。沈安晴没有给我承诺，我也没有给唐青禾承诺。可我却在两个没有资格的位置上，同时生出不该有的占有欲。

我把那行字删掉。

唐青禾从洗手间回来，头发被风吹乱了一点。她把手塞进口袋，说：“回去吧，冷死了。”

我说：“嗯。”

她走在前面，没有回头。我跟在后面，看着路灯把她的影子拉长。那一刻我很清楚，我不是不疼了。只是疼的地方变多了，旧伤和新伤挤在一起，谁也不肯让。

我看着这个好字，忽然想起刚才唐青禾跺脚吃关东煮的样子。热气，塑料棚，风，鱼豆腐，眼前人和屏幕那头的人在我心里同时出现。

我关掉手机。

窗外风吹过梧桐树，叶子往下掉。

秋风扫落叶，本来是一个很俗的说法。可那天晚上我突然觉得，人心里的旧东西也是这样。不是一下子扫干净，是今天掉一点，明天掉一点。你以为树还满着，低头一看，地上已经铺了一层。

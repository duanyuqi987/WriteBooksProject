# 第三百八十五章 飞升的条件达成

合道后第五年。两人在剑阁最深处查阅飞升最后的条件。古约残卷记载完成合道的双契搭档可开始感应天梯。天梯仅在某特定星象出现时显形——那是每甲子一遇的"双曜交辉"之日——届时上界九城会将一道连接两界的天梯投射入虚空断层中。二人需同步感知、共同攀援——否则天梯无法稳住。一旦攀梯成功——二人同时飞升上界，不再受轮回约束；寿元接近于无延。

算下来，下一个双曜交辉之日在大概五年后。这五年足够他们调整一切凡世事务。苏晚先将诊室正式交给在清泉诊所培训了十几年的一位女弟子——她把那本自己使用多年的旧病历和药箱一并转交，并在第一页上写了:"我信任你能替所有没飞升的人继续看诊。"林牧则将灵网全体系移交给包括师兄妹等数个二代维护师——他打开所有权限，留了自己一句："系统已经容错——没有我也没事。只有一条：松树发黄就赶紧去查。"

铁匠侄子的杂货铺已成为镇上最老的一家铺子。杂货铺门口有张石桌——桌上永远放着两把空椅。那是老铁匠用敲杯边角焊的一对椅子，椅背镂空——一把刻"战"一把刻"医"。没人坐，就是放在那里。苏晚走过时把手放椅背上轻轻压左右两下——像在给老朋友把脉。

青溪镇邮局老局长在数年前仙逝。他生前最后一封信寄到蜀山——信封里没有任何字——只有一张被裱过的老照片：他和小辉当年从紫光区撤离时在卡车上拍的全家福。相片背后写了几个字："因为你们，我们活了下来。谢谢苏大夫和林老师。"

苏晚把照片用透明药袋装好悬在诊所桌上。五年时间不算短——都一件一件慢慢交代完。所有告别都极细碎——和所有战后重建时的工作一样细碎。因为真正的在乎从来不是盛大演讲——是把手边的事做完。

# 第290章 抵达火星，红色星球上的古迹

从地球到火星的航程，按人类航天史的标准计算需要七个月。按张总工的设计方案需要五十五天。按李长生意念驾驶加冥气引擎的实测——二十三天。

祝融号进入火星引力影响球的那天，指挥舱里所有人都聚集到了全景屏幕前。人在太空中飘了二十多天，看到的星空全是同一种黑——没有大气散射，没有云层，没有日夜交替，星星硬得像碎玻璃。当第一片与星空不同的颜色出现在屏幕上时，小胖差点把手里的锅铲扔了。

红色。不是那种从地球上用望远镜看到的铁锈红——那种隔着大气层被散射过、被滤过的二手红。是近距离直视的、毫无过滤的、像刀子一样刺眼的猩红色。火星在屏幕上铺展开来，从左到右填满了整个视野。它的颜色比地球上的任何沙漠都更深、更浓、更暴烈——像一块被烧透之后冷却了亿万年的炭。在赤红色的底色上，暗色的斑纹如根系般蔓延。

"那不是环形山。"小王的声音在安静的指挥舱里显得格外清晰。

他把光学系统的放大倍数提到极限。火星表面在屏幕上层层放大——从全球图到区域图，从区域图到局部图。然后出现了。暗色斑纹不是混沌的、随机的地貌分布。它们是线。有起点、有终点、有明确方向性的线。线条宽度从几百米到几公里不等，长度从几十公里到上千公里。线条之间相互连接，形成了一张覆盖整整一片大陆的巨大网络。

不是自然地貌。

"几何图案。"老马从地质工程师的角度下了判断。他的手指在屏幕上划出了一条线的走向——这条线从火星赤道向北延伸了大约三千公里，然后在北纬四十度左右转了一个几乎完美的九十度弯，向西延伸了六百公里，再转九十度往南。整条线形成一个巨大的矩形，面积相当于半个欧洲。"自然地质运动中不会出现连续三千公里的直线。更不会出现连续四个九十度的直角弯。这不是断层——是人工建造的。"

"阵法？"许冰凑了过来。她是队伍里的阵法专家。她把那条线的走向和自己在地球上见过的各种阵图叠在一起对比。叠到第四张的时候，她的手指停住了。

"聚灵阵的放大版。"许冰把一张地球聚灵阵的标准阵图叠在火星表面照片上。两个图形不是完全一样的——但底层结构完全一致。都是从一个中心向外放射，都是三道同心环接四道辐射线，都是外环收口处打一个内旋的结。唯一的区别是比例——地球上标准聚灵阵的直径大约是三米到十米。而火星上这个——直径超过三千公里。

"一个直径三千公里的聚灵阵。"老陈咽了口唾沫，"这得多少灵石才能驱动？"

"不需要灵石。"李长生走到屏幕前，右手掌心的冥纹在靠近屏幕时自动亮了一下。屏幕上的火星表面照片中，那条矩形阵纹的某个节点也亮了一下——光学系统捕捉到的。他掌心的冥纹和火星表面沉睡了万年的符文产生了跨空间的共鸣。"聚灵阵的本质不是吸收灵气——是引导灵气流动。如果火星本身的灵气足够支撑这个大阵，它不需要额外的灵石驱动。它是自循环的——把火星内核的热能、太阳风中的高能粒子、太空中的暗能量全部导入阵纹的循环系统，然后转化成稳定运行的灵气流。"

"维持了一万年？"小王不信，"一万年不停机的自循环系统？"

李长生没有直接回答。他把兽核从收纳袋里取出来——晶体内部的暗紫色光芒在靠近火星轨道之后变亮了。不是他吸收了兽核中的能量——是兽核自己在变亮。它在感应到火星附近的暗能量密度之后，自动增加了吸收功率。暗能量密度越高，兽核越亮。而此刻兽核的亮度比在深空中翻了三倍。

"火星周围的暗能量密度——是深空的三倍以上。在这种密度下，聚灵阵不需要额外能量维护。它可以自我维持——只要火星还在围绕太阳转，只要暗能量还存在于宇宙中——这个大阵可以永远运转下去。一万年、十万年、一百万年。"

飞船继续靠近火星。进入低轨道的那一刻，屏幕上的景象彻底改变了所有人的认知。

那些从远处看只是暗色线条的"阵纹"，在近距离下显出了难以置信的细节。每一条阵纹不是简单的在行星表面刻一道沟槽——是一整个工程体系。阵纹的断面有精确的梯形截面，上口宽下口窄，底部铺了一层黑色的衬底材料——经过一万年的风化仍然没有完全剥落。阵纹两侧的岩壁上刻满了密密麻麻的小型符文，符文的笔画走向和冥纹出自同一个体系。每隔一段距离就有一个八角形的阵基——阵基中心有一块已经黯淡但结构完整的巨大灵石，灵石的直径超过十米。

老马沉默了很长时间。作为地质工程师，他在全国勘探过几十条灵脉，见过最大的灵脉矿洞也不过三五百米。现在他面前是一条宽几公里、长几千公里的人工灵脉通道——不是天然形成的，是万年前一支已经消失的文明，用他不知道的工具、不知道的技术、不知道的力量——在整颗行星的表面刻上去的。

"地球上有没有这个级别的工程？"小王问。

"没有。"老马蹲下来，手摸着屏幕，像在摸真实的岩石。"地球上最大的古阵是昆仑山脉深处的八门诛仙阵——直径大约一百二十公里。万年前地球上的文明应该也有这个级别的技术。但地球经历过灵气封禁，地质活动把那层遗迹基本都毁掉了。火星没有板块运动，没有大气侵蚀，没有生物扰动——万年前的东西，就这么裸在地表上，保存到了现在。"

"也就是说——"老陈说，"火星是一颗时间胶囊。封存了一万两千年前人类修仙文明最完好的样本。"

没人回答。但每个人都知道答案。

祝融号在火星轨道上减速。张总工设计的轨道插入方案很保守——飞船先在两百公里高的极轨道上绕三圈，用火星引力和飞船自身的减速推进器把速度降到一个安全范围内，再找一个相对平坦的区域着陆。候选着陆区有五个——全部在火星南半球赤道附近的那条最大阵纹旁边。

李长生看着火星表面上那些巨大到不成比例的阵纹。他掌心的六道冥纹持续发着微光——不是灼烧感，是某种更深层的、沉闷的悸动。像有一颗被埋在火星地下的心脏正在跳。心跳的节奏和他的冥纹完全同步。第八块碎片就在这颗星球上——在那些巨大阵纹之下，在某个被封印了一万年的宫殿里。

"选着陆区。"他说，"就那条最大的阵纹——找阵眼。"

许冰用了三个小时分析火星表面的阵纹布局。她把四千七百张高分辨率光学照片拼接成一张覆盖火星赤道地区的阵纹总图。按照阵法的规律——阵眼通常位于所有阵纹的交汇点，能量流动最集中的位置。在这张总图上，那条最大阵纹和其他六条一级阵纹的交汇点只有一个——位于赤道和子午线交叉点偏北大约两百公里处。

坐标确定。着陆程序启动。

祝融号的减速推进器在火星轨道上点燃了——不是聚灵推进，是传统的化学推进器和反推灵符的组合。在行星引力场内，灵能推进的效率受引力扭曲的影响会打折扣，张总工设计时预留了一套混合减速方案。

飞船穿过火星稀薄的大气层时，船壳上的防御灵符自动激活——大气摩擦的热量被灵符分散到船壳各处，船壳温度升到了四百七十度但没有超过合金的安全上限。老马在船腹手按全船的加固灵符阵列，把每块船壳的热膨胀系数控制在允许范围内。刀疤站在武器操控台前——他的手指悬在灵能炮的发射键上方，全程没有移开。尽管火星轨道上不太可能有威胁，但他还是在盯着。

轰。

船体触地。祝融号的四根着陆支架在火星赤红色的大地上压出了四个深深的凹坑。舱内的所有人都感受到了那种久违的震动——不是太空中那种无根的飘浮感，而是实打实的、有重力的、踩在地面上的震动。

火星重力大约地球的百分之三十八。轻。但够了。至少能让脚踩到地上。

李长生第一个走下船。他穿着灵压宇航服——火星大气以二氧化碳为主，气压只有地球的千分之六。没有氧气。温度零下四十度。但这些参数对他来说已经不是问题了。踏入第六重冥界虚空境之后，他的身体可以在无氧环境中靠冥力内循环维持生命活动大约两个小时。

他的一只脚踩在火星的大地上。

那一瞬间，他掌心的六道冥纹爆出了出发以来最亮的光。不是他自己激活的——是火星表面那些阵纹自动回应了他。他脚下的大地在冥纹亮起的那一瞬间，从地层深处传来了一道极低沉的、频率只有零点三赫兹的震动。震动从脚下扩散到脚踝、到膝盖、到脊柱。不是让人摔倒的强度——是让人毛骨悚然的精准。震动的频率和他掌心的冥纹明灭频率完全一致。

老马蹲下来，手掌按在火星地面上。半分钟后他抬起头，脸色变了。

"地下。大约两千米深处——有一个巨大的空腔。不是天然溶洞。我的土系灵力碰到了一层人工制造的屏障——密度极高，不是石材。是某种合金和灵气复合制造的壁面——直径至少有几十公里。"

"地下两千米？"

"对。而且在空腔的上方——"

老马把土系灵力的探知范围往下推到极限。他的灵力顺着岩层之间的天然裂隙往下渗透，穿过风化层、玄武岩层、密度异常高的古岩层——然后碰到了一个巨大的能量场。

"在空腔的上方——有一个能量场。不是灵气——是混合型的。暗能量占比大概七成，灵气三成。能量场的形态——是一个顶盖。覆盖了整个地下空腔。厚度大概五十米。穿过这层顶盖需要很大的能量——或者正确的频率。"

"频率是多少？"李长生低头看着自己发光的右手掌心。

老马抬头看了他一眼。没有说数字。因为在李长生的掌心冥纹亮起的那一瞬间，地下两千米处那个巨大的能量顶盖上——有一个缺口自动打开了。

（第290章完）

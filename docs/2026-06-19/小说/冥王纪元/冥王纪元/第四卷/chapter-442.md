# 第442章 此秘法可召唤黄泉之力

黄泉倒悬。

四个字在十一位帝者的识海中反复回荡，像古老的丧钟被敲响。

赤阳帝者最先稳住心神。八千年帝者生涯磨砺出的意志力让他强行压下了灵魂深处的恐惧，开始以神识分析这道秘法的本质。

然后他看到的景象让他脸色惨白。

黄泉之水不是水。它是时间之河的反面。每一滴黄泉之水中都流淌着"不存在"的因果——那是被历史抹去的文明、被修正了的时间线、被否定过的可能性，它们汇聚成河，在宇宙的背面流淌了无尽的纪元。

而李长生，正在把这条河翻过来。

"原来如此。"赤阳帝者的声音干涩，"《黄泉倒悬》不是毁灭之术。它是对存在本身的审判。"

李长生站在黄泉之幕中央，右手高举冥王令，左手掐诀维持着倒悬的姿态。他的表情平静得可怕，仿佛承受着黄泉反噬之力的不是他的身体，而是别的什么东西。

实际上确实如此。

冥王令在这一刻展现出了它真正的形态。九块碎片的光芒交织在一起，形成了一道无形的盾——将黄泉倒悬的反噬力全部接下，再转化为维持秘法的能量。这是一个自循环的系统：黄泉之力越是汹涌，冥王令吸收的反噬就越多，秘法就越强。

"冥王在一万年前就已经算到了这一步。"李长生的声音穿透黄泉之幕，带着一种苍凉，"他把冥王令碎成九块，不是被打碎的。是他自己捏碎的。"

十一帝者中有人倒吸了一口凉气。

"九块碎片散落在九处不同的时间节点和空间坐标，"李长生继续说，"每一块碎片都吸收了万年来那些被抹杀的因果、被遗忘的仇恨、被否定的存在。一万两千年，这些碎片一直在黄泉之底浸泡——你们知道一万两千年能吸收多少吗？"

没有人回答。

也不需要回答。

黄泉之水在倒悬的瀑布中开始显现画面。那是被诸帝联盟在过去万年中毁灭过的文明：有被苍雷帝者摧毁的硅基文明，十万亿生灵在三天之内化为灰烬；有被烈风帝者吞噬的灵能文明，整个星系的灵魂被榨取为修炼资源；有被赤阳帝者焚尽的有机文明，最后的幸存者在火海中发出诅咒，然后连同诅咒一起被蒸发。

每一个被诸帝毁灭的文明，都在黄泉之底留下了一道痕迹。

一万两千年，足够积攒一座海。

"《黄泉倒悬》的真正力量，"李长生的声音开始发抖——不是因为恐惧，而是因为正在承受的反噬达到了肉身极限，"不是召唤黄泉。是召唤那些被你们杀死的万亿生灵的不甘。"

黄泉之幕骤然扩大。

从十万里扩展到百万里、千万里、亿万里。在诸天号舰队所有将士的视野中，倒悬的黄泉瀑布变成了一道贯穿星河的巨幕，幕布上浮现出了无尽的面孔——那些被毁灭的文明残留的意识碎片，在黄泉之力的凝聚下重新睁开了眼睛。

它们没有实体。它们只是一些记忆、一些怨恨、一些不甘。

但足够了。

"你们杀过的每一个人，"李长生说，"今天都会来找你们。"

赤阳帝者的脸上第一次出现了恐惧。

因为他看到了自己七千年前亲手毁灭的一个文明——那是一个和平到甚至没有军队的种族，他们在被毁灭之前的最后一件事，是把所有孩子的名字刻在了星球的核心里。赤阳帝者当时只是一挥手，把整个星球连同那些名字一起烧成了灰烬。

现在那些名字的主人站在黄泉之幕上，用空洞的眼睛看着他。

不是一个两个。

是整整三十二亿。

"这是幻觉。"苍雷帝者咬牙道，但他的手在抖。

李长生没有回答。

黄泉倒悬的瀑布中，三十二亿道目光同时锁定了赤阳帝者。那不是攻击，那是一万两千年来积攒在黄泉之底的每一份不甘、每一句诅咒、每一滴未干的眼泪，汇聚成了对弑者的最终审判。

赤阳帝者张嘴想说什么。

黄泉之幕已到身前。

（第442章完）

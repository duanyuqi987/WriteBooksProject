# 第245章 第九世：鸾黄

鸾凤离火雏形凝出之后，苏晚在共振台上又站了七天。

七天里她和林牧每天进行两次共振——早晚各一次，每次两个时辰。白谪全程监测——灵鉴屏上的数据从"鸾凤离火初步凝形"逐渐变成了"鸾凤离火——稳定率=43%→67%→82%→91%"。

但91%之后，数据再也不动了。不管他们怎么调整共振频率、改变灵魂碰撞的角度、切换金火和仙元的注入比例——那最后9%就是不往上走。鸾凤离火始终停留在"雏形"阶段——有鸾黄的过渡色，但那片黄不够亮，不够稳——每次共振结束后它会亮大概半炷香然后慢慢消退——像一盏被反复点亮但蓄不住光的旧灯。

第七天傍晚——共振结束后苏晚坐在裂谷边的石头上——把剑横放在膝盖上——剑身上的金火纹在这几天的极限使用中变得有些暗淡——剑和人一样——也到了某种极限。她低头看着剑身上自己的倒影——倒影里的眼睛下面已经积了很重的青色——是连续七天高消耗共振的后遗症。她的虎口又磨出了新茧——不是握剑握的——是在共振中每次瓶颈被冲击反弹时她的身体无意识地把剑握得太紧——剑柄的纹理压进了虎口。

林牧从南壁走过来——递给她一杯温茶。她接过——喝了一口——然后把茶杯放在石头上——看着裂谷对面被夕阳染红的灵石壁——开口:

"我每次冲击到九成的时候——瓶颈上的那道缝已经像纸一样薄了——我感觉再推一把它就破——但每一次——每一次到那里我都少一样东西——我不知道是什么——"

"是仙元。"林牧说。他把窄身剑抽出来横放在她剑的旁边——"鸾凤离火需要金火和仙元在体外完成最终融合——而你的身体是凡人体质——它自己产不出仙元那一半热量。所以每到九成的时候——缺的那一小块就是从外面来的仙元——而且必须是同时、同频、同意念的。"

苏晚看着他——"那你的仙元已经在共振里注入了——还不够吗？"

"共振里的仙元是从我的魂核里借出去的——它在碰撞时和你的金火不在同一个身体里——所以融合发生在外面——而不是在你体内。鸾凤离火的最终固化——必须让那一丝仙元在你的丹田内部——和你的金火——同炉同火。"

同炉同火。这个词一出来——两个人都静了。因为这是第一世苏晚在青云宗剑阁前对林牧说的原话:"以后我们俩的剑要一起淬——同炉同火。"几百年前的一句话——到今天成了飞升的最后一关钥匙。

"你的意思是——"苏晚把茶杯放下来——声音变慢了——"你需要把你的仙元——注入我的丹田里——和我的金火一起烧？"

"对。但这会产生一个你目前还没遇到过的问题：仙元入体——凡人的经脉必须完全开放——不能有任何防御本能。如果你的灵魂在最后一刻因为任何原因对我的仙元产生了排斥——哪怕只是本能级别的一丝不信任——反噬会把我们两人的魂核同时震碎。"

苏晚沉默了。不是害怕——是在检查自己。她闭上眼睛——把神识沉入自己的丹田——在那片金火的深处——有一个她九世以来从来没有仔细看过的最深的角落。自从第一世她在天劫中用自己的身体挡下那道劫雷之后——她的灵魂最深处就埋下了一个她自己都不知道的防御壁——那个壁是对"被伤害"的本能恐惧——不是对林牧的恐惧——是对"被天地之力击穿身体"的恐惧。那道恐惧在第一世天劫之后就没有被完全清除——因为它藏得太深了——深到了轮回锁也覆盖不到的地方。

"我找到那个东西了。"她睁开眼睛——"不是不信任你——是我灵魂最底层有一个第一世天劫留下来的旧伤——它让我的身体在快被击穿的时候会本能地释放防御。"

"你能控制它吗？"

"能——但需要时间。"

从那天晚上开始，苏晚做了一件她在以前几世都没有做过的事：她开始对自己的灵魂做内部解剖。不是修炼——是治愈。她每天花两个时辰在瑶台边的静室里入定——把神识沉到灵魂最深处那道第一世天劫的旧伤面前——不是对抗它——是观察它。她发现那道旧伤不是一道疤——是一个小女孩在濒死时极度想保护一个人的执念——"如果他死了我就不活了——所以我不能死——我要挡住——"那是第一世苏晚在最后一刻的求生意志——它保护了她最关键的一丝灵魂痕迹——但同时也让她的灵魂从此在任何接近死亡的时刻都会自动筑起一道防御壁。而仙元入体——会被她的灵魂本能误判为"类似天劫的贯穿性冲击"——触发防御。

治愈这道旧伤的方式不是消除它——因为消除"想保护他"的执念会把她对他的情感根基也一并挖掉。她需要的是告诉这道旧伤一件事:现在天劫已经过去了。你不需要再挡了。你挡住的那个人——现在就在你身边——他是来跟你一起烧一炉火——不是来击穿你。

她在自诊的第四天晚上——在入定中对着那道旧伤说了一句她从未说出口的话:"第一世的苏晚——你的任务完成了。你守住了他——你守了很多年——你做得很好——现在你可以卸下这道门了——因为他已经不需要你再挡——他现在是要和你一起飞——飞上去——再也不用挡了。"

她说完这句话的时候——丹田最深处那面防御壁上出现了一道裂缝——不是被突破的裂缝——是自己松开的裂缝。就像一扇因为太久没人触碰而锈死的铁门——现在有人从里面把它慢慢推开。门后面不是恐惧——是第一世苏晚在闭上眼睛之前最后看到的画面：林牧的脸——他嘴巴在喊她的名字——但她听不到——因为劫雷太响。她在这个画面里第一次没有感受到雷电击穿身体的痛——而是在画面里看到了他的眼睛——那眼睛里不是失去的绝望——是"我会找到你"的承诺。

她把那扇门完全推开——然后她在入定中流了眼泪——不是哭——是某种积压了九世的东西终于被释放。

她走出静室的时候是清晨。林牧在瑶台边等她——他的窄身剑放在膝上——剑上的旧痕和新印在晨光里一前一后地亮着。她走到他面前——把他的手放在自己胸口的灵魂感应线位置——然后说:"我的旧伤已经治好了——不是因为忘记了——是因为我想通了——我不需要再挡——因为现在我们是站在一起的。把你的仙元给我——我们一起烧这炉火。"

第五次共振在拂晓进行。这一次与之前四次完全不同——苏晚在打开魂核的同时没有把金火向外释放——而是让金火留在体内——然后在金火燃烧的中心位置——她把自己的丹田壁完全卸下——对着林牧发出了一个灵魂级别的邀请信号。这个信号不是灵力——是情感契约——她在用自己全部九世的记忆和经验告诉他:我相信你。没有任何本能防御。没有任何保留。进吧。

林牧的仙元通过灵魂感应线——以双向灯为通道——第一次从外部直接注入了她的丹田核心。仙元的银色火焰进入她丹田的瞬间她自己被那道冲击打得全身一震——银火和金火在丹田里同时燃烧——产生了剧烈的灵力互斥——她的脸瞬间变成惨白——但她紧咬着牙用全身剩余的全部灵力把金火往银火方向挤压——不是对抗——是拥抱——她让金火把每一丝银火都包裹住——像双手捧住一棵刚燃起的银色烛芯——然后金火和银火在极近的距离内——首次在她体内——开始融合。

融合点在丹田正中央——一个小到肉眼看不到但灵识里清晰至极的微点——金火和银火的边缘在那个点上互相渗透——金的熔化层和银的结晶层在同一个温度下同时变形——然后那个点爆发出一小片——鸾黄。

鸾黄的光从她丹田内部发射出来——透过她的皮肤——把她的整张脸照亮。不是那种刺眼的白金光芒——是温的——像初曦——像旧茶——像铜镜反射出的第一缕晨光——在一片金色和银色之间——找到了一种之前不存在的全新色相。

白谪的灵鉴屏上跳出了一行让他在空中愣了几息的字:"鸾凤离火——完全固化——稳定率:100%——苏晚——第九世——真仙飞升门槛——已破除。"

林牧收回仙元——苏晚在鸾凤离火的余辉中跪倒在瑶台上——她全身的灵力在刚才的体内融合中消耗到了极限——但她抬起头看着他——嘴唇发白但眼睛极其亮——"我们做到了——在这一世——"

他把外袍脱下来披在她肩上——蹲在她身旁——把茶壶从口袋里拿出来——倒了半盏温茶——递过去——"是你做到的——你把自己的旧伤推开了——不是我。"

她把茶喝了——靠在他肩上——看着瑶台东方亮起来的天际线——那轮他们看了几百年的太阳正在从云海里往上浮——它的光打在她的鸾凤离火余辉上——余辉用最后的温度描了一圈她无名指上的银戒指——那枚戒指在双色光中闪过一丝他从来没见过的——不是金色也不是银色的——鸾黄。

她的第九根剑穗——在这次共振之后——穗结上那条红线在双火同炉的极高温度中变成了永久的鸾黄色——和金火银火都不同——是一种只有在两个人同时在场时才会出现的颜色。

她把剑穗从剑上解下来——放在他手心:"这一条是第九世的——它从来不是纯金色——也不是纯银色——是两个人的颜色——以后飞升的每一天——你带着它。"

林牧把剑穗系在窄身剑的剑柄末端——和前面八条并排。

九条剑穗在晨风里轻轻摆动——不同材质的穗子发着不同年代的旧色——最老的那一根从第一世就系着——已经褪成了几乎透明的浅金色——最新的一根泛着温润的鸾黄——在风里和太阳的光线一起微微颤动——像是时间本身在一根绳结上被拧成了可以被手握住的形状。

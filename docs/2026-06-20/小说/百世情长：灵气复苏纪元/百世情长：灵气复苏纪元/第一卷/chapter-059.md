# 第59章 我只想护一个人

龙虎山的人离开之后，出租屋里安静下来。下午的阳光从窗帘缝隙里挤进来，在地上画了几条细长的亮线。空调外机还在窗外嗡嗡地转，客厅角落那只鱼缸里的过滤器也在咕嘟咕嘟地吐着气泡。

锦鲤从缸底的石头缝里游出来，浮到水面，盯着林牧。

"你真的不想做一个英雄。"

林牧正在用毛巾擦茶几。刚才严老师和陈老师坐过的地方——他们碰过的地方——他擦得很仔细。不是因为洁癖。是因为龙虎山的人在茶几上留下了一丝残存的灵气痕迹。不属于普通的灵气——是龙虎山修行者体内淬炼过的龙虎内气。那种灵气虽然无害，但会让鱼缸里的锦鲤不舒服。锦鲤对灵气纯度很挑剔，稍有杂气就会烦躁地摆尾巴。

"我没有那么说。"

"你对她们说的。"锦鲤的尾巴在水面上拍起一小朵水花。"你说你是想做一个普通人。"

"我撒谎了。"

锦鲤的尾巴停了一下。它认识这个人很久了——久到可以从前世算起。在他的记忆里，林牧撒谎的次数屈指可数。不是因为道德高尚——是因为他觉得撒谎太费精力。一个连话都不愿意多说的人，一般不会花额外的力气去编织谎言。如果他撒谎了——那一定是因为真话会引发比谎言更复杂的问题。

"你为什么不想去龙虎山。"锦鲤把脑袋浮出水面。这是锦鲤行为模式中最像"认真交谈"的姿势。"他们的offer很不错。所有费用全包。结业之后有官方职称。以后可以光明正大地以修士身份行动。不用在加班夜偷偷摸摸地上天台引气。不用在你的工位上把代码改了又删删了又改来掩盖你的修炼时间。"

"我知道。"

"如果前世你碰到这种机会——你一定会去。你前世在青云宗也是从杂役弟子做起。你对系统没有抵触。你对"为国效力"也没有抵触。所以——"锦鲤把一条鱼鳍翘起来指着他的鼻尖。"你拒绝不是因为龙虎山不够好。是因为苏晚。"

林牧把毛巾搭在椅子背上，在沙发上坐下来。他看起来很平静——和每天下班回来之后躺在沙发上看手机的表情没有区别。但在锦鲤眼里，他不是平静。是沉。

"前世在青云宗——"他说。"有一个十年。我忙着修炼、忙着办事、忙着帮宗门打各种仗——金丹到元婴那一段。我十年没有见她。不是不想见。是觉得时间很多。十年之后再回去——她还是住在那个洞府门口。洞府门口的桂花树从前世的头一年长到了第三四年。我不认识那棵树了。"

"你前世没有保护她。"

"保护了。"林牧低下头，看着自己的手指。"但是我保护的是她的人身安全——不是她的心情。她不想我走。她没有说。但我知道她不想。"

锦鲤没有接话。它知道这是林牧的痛点之一。前世——在穿越整条轮回路之前——林牧最不能原谅自己的事，就是陪她的时间太少。不是他的错——他已经在各个方面尽了全力。但他一旦把"尽全力"和"足够"混为一谈，就会愧疚。锦鲤前世劝过他很多次："你已经尽力了。"他每次都点头。但他从来没有减少那份愧疚感。

"所以这一世——"林牧站起来走到窗边。"我不打算再把时间花在青云宗以外的事上。龙虎山、灵异管理局、新成立的修士特训中心——这些东西都有价值。但对于我来说——"

他没有说完。因为他透过百叶窗看到了窗外楼下那个正在走进公寓楼门口的身影。

苏晚。

她已经完全康复了。她的步子不再是拖着身体的微弱晃动——而是帆布鞋踩在行人道上发出的轻快的沙沙声。走路的时候右手轻轻推了一下肩膀上那个帆布包的带子——那个推法很特别：是用拇指把带子往内侧勾。前世她也是这个推法。林牧前世在藏经阁的二楼窗边看到过她无数次从山道上走上来，每次有那一段带碎石的上坡路就会用一个相同的姿势勾一下带子。这一世她勾带子的角度和前世完全不差。

"你在看什么——"锦鲤浮到鱼缸靠近窗边的一侧，顺着林牧的视线看出去。"哦。她回来了。"

"嗯。"

"所以你刚才的那句话——不想把时间花在青云宗以外的事上——你要把它怎么办。"

"不怎么办。"林牧说。"我本来就不是想做一个普通人。我只是不想在别人的系统里做英雄。我只想做一样东西——做一个守在她身边、随时能站在她前面的人。不管一世，还是百世。"

锦鲤沉到缸底，吐了一个很大的泡泡。气泡破了。然后它说了一句话。

"那你现在去楼下。她刚走进小区。你今天还没有跟她说过话。"

林牧看了它一眼。然后拿起钥匙，出了门。

楼道里的声控灯在他经过的时候一盏一盏地亮起来。他走到楼下，看见苏晚正站在那棵梧桐树下。她大概原本是想上楼——但走到这里的时候被一个卖花老太太的小摊吸引了。那是一辆小小的三轮车，车上摆着几盆茉莉、几盆栀子、一桶洋桔梗和几个多肉。苏晚蹲在三轮车前，指着一盆叶子发黄的茉莉在问老奶奶："这盆浇多少水。"

"浇一点点就可以了。茉莉不喜欢太多水。"

"哦。"她把那盆茉莉端起来，付了十块钱。

林牧走到她身后。"你要养茉莉。"

苏晚转过身，裙摆扫到了梧桐树的树根上。她站起来把那盆茉莉举给他看。"嗯。放在窗台上。我那个窗台只有一个绿萝——太素了。加点有颜色的。"

"茉莉花是白色的。"

"白色也算颜色。"她把花盆抱在怀里。"而且它香。"

他帮她拿着帆布包，她抱着花盆，两人一起上了四楼。进门之后苏晚把花盆放在窗台原有的那个绿萝旁边。绿萝的藤蔓已经垂到了暖气的管道上，绕了两圈之后又分叉了。茉莉在那株绿萝旁边显得很小——瘦瘦的几片叶子，一个正在衰败的花苞。但她在看它们的时候，嘴角有笑意。

"以后这盆茉莉开花了，整个房间都会有香味。然后每天早上我打开窗——阳光进来，花香出去。"她转过头看着林牧。"你觉得我是不是过于理想化。"

"不觉得。"

"嗯。"她把花盆转了一个角度——让花苞朝着阳光的方向。"这是我第一次在出租屋里养花。以前没有特别想养。最近忽然想了。"

林牧看着她的背影——她弯腰调整花盆位置的姿势，和前世她调整洞府门口那些盆栽的姿势一模一样。那时候她洞府门口有一株很高大的老桂花树——不是她种的。是山里面的野树倒过来长到她门口的。那棵桂花树开花的时候，整座山的三层岩台都有香味。

"你以前不喜欢桂花。"他说。

苏晚停住了。她的手指停在茉莉的一片叶子上。然后她慢慢转过身，看着林牧。她的眼神变了——不再是那种闲聊的表情。是一种被什么东西忽然击中间层的、试图寻找连接的表情。

"你怎么知道我不喜欢桂花。"

林牧的手在裤兜里握了一下。刚才那句话不是他主动说的——是身体的潜意识在他思考之前先说出来的。他自己也是话说完了才意识到自己说了什么。

"猜的。"

"你猜得太准了。"苏晚把手臂交叉在身前，靠着窗台。"我从小就不喜欢桂花。说不上为什么——不是讨厌那个味道。是闻到的时候心里会发酸。像是有什么事情——跟桂花有关——但是我记不起来了。"她看着他。"你知道吗——你说这句话的时候我的脑子里又闪过了那几个画面。山。雾。穿白衣服的人。还有——一颗很大的桂花树。树下坐着一个人。看不清脸。"

"你刚才也想到了。"

"嗯。在你那句话之前，我没有具体想过桂花这件事。你一说——它就像在湖面上投进去了一个石头——所有的水波纹都是桂花的。林牧。你到底——"她把问题改了。"知道关于我的什么。"

林牧站在她面前一步远的地方。阳光从窗外面射进来，茉莉花盆里的水珠折射出一小颗极小极细的光斑，落在他手背上。他看着那颗光斑。

"我知道你不喜欢甜的。你喜欢养白色的花。你走路的时候喜欢低头看地面——不是在找东西，是本能。你做表的时候右肩会略微地往前倾——因为右边的眼睛度数比左边高了一点，你没有配两片不一样的镜片。"

"你——"苏晚张了张嘴。"这些不是看出来的。一个人观察另一个人再仔细，也不可能知道这么多细节。除非——"她的喉咙微微动了一下。"除非你真的在很久之前就认识我了。"

空气安静了几秒。

林牧看着她。她靠在窗台上，白色的帆布鞋斜靠着墙角。她怀里抱着那盆茉莉花，眼睫毛在那道阳光里投出两道阴影。

"我认识你。"他说。

苏晚的嘴张了张，又合上了。

这四个字的分量——他说的不是"我之前见过你"，不是"我观察你很久了"，不是"我对你有好感"。他说的是——"我认识你"。那种认识不是这一世在茶水间的点头之交，不是电梯里的礼貌微笑，不是团建时被分到同一组跳皮筋的尴尬。是比这一切都更早的、更深的。远到她自己都不知道。

"多久了。"她轻轻问。

"很久。"

"很久是多久。"

林牧没有回答。他怕说了她会受不住——她现在的经脉宽度还承受不住"前世""轮回""跳下轮回之河"这几个词同时涌入。路要一步一步走。记忆也需一点一点地回来。

"不急。"他说。"你先把这盆茉莉养开花。然后我再告诉你。"

苏晚盯着他。那双干净明亮的眼睛里有阳光和他自己的倒影。然后她低下头，把花盆放在窗台上，把水浇进土里。她的手指轻轻地按着泥土，用一种他见过千万次的方式。

"好。"她说。"茉莉开花要多久。"

"大概几星期。"

"几个星期之后——你会告诉我一切。"

"会。"

"那我不问了。我养。"苏晚把洒水壶放回窗台上，水壶嘴对着花盆边缘，水滴顺着壶嘴滑下去。然后她又转过头看着他。"但你能不能先告诉我一件事。"

"你说。"

"你每天早上给我倒咖啡的时候、每天晚上在梧桐树下站着的时候、在巷子里站在我前面的时候——你的那个表情。不是愤怒，不是害怕。是——"

"是什么。"

她想了一下。然后找到了一个词。"是笃定。那种表情不像是——不确定要不要帮我。像是很确定。像等了很久才等到这个机会。你是不是等了很久了。"

林牧没有回答。他只是伸出手，把她窗台上那片落下来的绿萝叶子从茉莉的花盆边捡起来。叶子背后沾着新鲜的泥——是她在移栽的时候不小心溅上去的。

他把叶子放在她掌心上。

"你以后会知道的。"

苏晚合上掌心，把叶子握住。"那你会等吗。"

"我会。"

"等多久。"

"到你不需要我了为止。"

苏晚把叶子放进绿萝的盆里。她低下头的时候，嘴角有一个很小的弧度——任何人都看不出来，但他能。那是一个没有声音的、但确凿的、像水面下涌动的暗潮一样的笑。

窗外。暮色降下来。梧桐树的叶子被晚风吹得沙沙响。楼下老李的收音机又换了台——这次是相声。二楼那个总在阳台上晾床单的阿姨把床单收了进来。城市的傍晚不安静，但林牧觉得挺好的。他前世一个人站在悬崖边的时候，什么都听不到。只有风和血。现在他站在这间小小的出租屋里，茉莉花的土腥味还没有散，她抱着洒水壶在洗手间里洗壶。水龙头的声音。洗壶的声音。她湿着手走出来在毛巾上擦手指的声音。

都是这一世。

他不知道未来还会来多少客人——龙虎山，茅山，其他隐士家族，国家新成立的灵气管理机构。他们都会来敲门。都会带着各种各样的邀请。但答案不会变。他不是不想出山——他只是想先一个人护着。今生今世——甚至更久——如果她需要他有一个瞬间可以站在她前面。那么他的位置就在那里。在他面对门外所有人的同时背后是她。仅此而已。

# 第386章 第一颗行星

火焰帝国首都星——"赤阳星"——是一颗被人工改造过的超级行星。它的直径是地球的十六倍，表面覆盖着一层由火焰法则维持的恒温大气层。大气层内部的温度常年维持在三百度——对人类来说是死亡温度，对火焰帝国的火系修士来说，这是最舒适的生存环境。

冥王号在赤阳星外轨道上停泊了整整三天。

这三天里，赤阳星上没有任何一艘战舰敢升空。火云帝重伤闭关的消息在第一天就传遍了整个首都星。第十二圣者团在第二天的紧急会议上分裂成了两派——主战派主张集中所有残余兵力守卫首都，主和派主张立刻派出使团谈判。

第三天的清晨，赤阳星地表最大的城市——焰都——的南城门被从里面推开了。走出来的不是军队，而是一支行色匆匆的使节团。使节团为首的是火焰帝国的十二圣者之一——圣者赤明，他是火云帝座下资历最老的臣子，在帝国行政体系中担任首席宰相。

使节团带着五艘运输舰升空，在冥王号的防御范围外停下。

"我方请求与冥王对话。"赤明的声音通过空间传音术传到了冥王号的通讯阵列上。

小王在指挥舱里收到了信号。他调出火焰帝国的外交礼制数据库——这是一个从冥王号进入帝国星域以来一直在积累的数据集。他看了三分钟，然后转头对李长生说："根据他们的外交礼制——使节团带了五艘运输舰。三艘是物资——他们自己用的。两艘是空的。空的意味着他们准备接收一些东西回去——通常是条约文本、贡品清单、或者——"

"战利品。"老陈补了一句。

圣者赤明登上了冥王号。他是第一个踏足这艘黑色战舰的外星帝者级势力代表。他走进指挥舱的时候，视线在房间里扫了一圈——他先看了李长生（掌心的冥王令纹路亮着），然后看了陈霜（手按在剑柄上），然后看了龟相（在指挥台上缓慢地转着龟壳），最后看了小王（手指放在键盘上，屏幕上跑着实时翻译程序）。

他对着李长生单膝跪下。

"吾皇火云帝——授权在下向冥王转达正式提议。"赤明的声音很稳，是那种有几千年的行政经验积累出来的稳定，"帝国愿意交出西部边境恒星系——即冥王号迄今已抵达的所有星域——作为永久领土让渡。其中包括已开发的十七颗行星、四十二个采矿站、九条超空间贸易航道。作为交换条件——冥王舰队不再继续深入帝国腹地。"

指挥舱里安静了大概十秒。

李长生没有立刻回答。他看了一眼挂在墙上的星图——小王把火焰帝国的疆域用红色标注了出来，已经划出去的那一小块被用蓝色圈了出来。那一小块在整个火焰帝国的版图上看起来大约不到百分之一。

"不够。"李长生说。

赤明没有惊讶。他显然是预料到了这个回答。他继续说道："陛下同时授权在下——在冥王不接受第一方案的情况下，可提出第二方案。帝国愿意完整的交出一个大区——赤阳大区。该大区包含恒星系四百零一个、行星一百七十六颗、人口两千亿。这是火焰帝国六大行政区中面积排名第三的大区。"

李长生依然没有立刻回答。他站起来，走到星图前。他的手指在星图上划了一道线——从火焰帝国的西部边境开始，一直划到赤阳星所在的位置。

"我要赤阳星。"他说。

指挥舱里的温度在一瞬间降到了冰点。

赤明的脸色没有变——圣者的自控力远超常人。但他沉默了整整五秒钟。赤阳星是火焰帝国的首都。交出首都意味着交出整个帝国——帝都不是一座城，它是一个文明的象征。火焰帝国可以在赤阳大区这块领土上让步，但不能在赤阳星这座帝都上让步。

"陛下不会同意的。"赤明说。

"他会。"李长生转过身，重新坐下。他的语气像是在说一件理所当然的事情。"你回去告诉火云帝——我不需要他的首都。我需要他在赤阳星上升一面旗。升完了我就走。帝国还是他的——但他得帮我管。"

赤明愣住了。他活了两千三百年，从来没听过这种条件。

"你——不吞并帝国？"

"我只要往西的路。"李长生说。

（第386章完）

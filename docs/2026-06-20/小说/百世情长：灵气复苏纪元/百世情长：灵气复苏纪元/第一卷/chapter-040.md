# 第40章 故意垫底的检测结果

检测结果三天后在公司内网上公示了。

不是全名——隐去了中间一个字，变成了"林X""苏X"这样的格式。但等级是公开的：从A减到E加，每差半级都写得清清楚楚。旁边用不同颜色标注：A级绿色，B级蓝色，C级黄色，D级灰色，E级红色。花花绿绿的一列排下来，像某种奇怪的成绩单。

林牧在这一列排名的中下游找到了自己。D级。再往下划几行，是苏晚。D加。

整个公司三百四十一个人里，C级以上的四十七人。A减级两人——一个是产品部新来的产品经理，姓赵；另一个是商务部的副总监，女的，姓孙。

还有一个人测出了B加。

是那个坐在角落的实习生。那个灵气排斥现象的携带者。仪器给了她一个中上的分数，但她周围的灵气真空没有任何改变。林牧知道那个数值不准确——不是偏高，是偏低。如果把封印或者体质特殊性排除，她的真实灵气亲和度很可能远高于B加。

但仪器看不出来。

就像仪器看不出林牧体内的三十六缕灵气。

"林X——D级——不适合修炼。"

他盯着这行字看了几秒。屏幕上的灰色底色，圆体字，看起来和他收到过的各种系统的判定没有区别。大学时期的成绩单，面试时的评测结果，年度绩效考核的截屏——这个世界总有办法把你放进某一个格子里。

他做了一件事。

把这个页面收进了浏览器书签。书签的名字打了一个字：记。

为什么记？他说不清楚。也许只是一个习惯。也许是留给未来的自己看——当某一天他不小心暴露了真实修为的时候，他可以打开这个页面，说："看，你们当初不是这么说的。"

下午三点，他在茶水间遇到了那个测出A减的赵经理。

赵经理全名叫赵明远，今年二十九岁，在灵气的觉醒测试之前是一个普普通通的产品经理。他每天做的事情和其他产品经理完全一样——写需求文档、和技术吵架、在老板面前画饼、在开发面前改需求。

但检测结果出来之后，他变成了另一个人。

不是物理上的变化——是他身边的人对待他的方式变了。

林牧端着水杯走进茶水间的时候，发现赵明远正站在咖啡机旁边。他周围围了四个同事，三男一女，都是C级的。他们围着他说话，表情里带着以前没见过的神色。

"赵哥，你说引气入体的感觉是啥样的？你完成了没？"

"赵经理，你上次说的那个《灵气修炼速成法》公众号，推给我看看呗。"

"明远，下班之后要不要去旁边那个灵气体验馆？我听说里面可以测更细的指标。"

茶水间很挤，但赵明远周围永远空着一个二十厘米的圈。

不是因为他在保持社交距离，而是别人在保持。

林牧接了杯热水。他站在热水机前面的时候，从水壶不锈钢表面的反射中看到了赵明远的眼睛。

那双眼睛里有一种东西他很熟悉。

前世在青云宗里，那些刚开始展现出修炼天赋的弟子就是这个眼神。他们看别人的时候不再像以前那样平视。视线会往上飘一点点。不多，只有两三度。但因为对方能看到，所以这两三度的仰角变成了俯角——看人的人不觉得，被看的人会觉得自己矮了一截。

一个月的区别。

一个月前赵明远还在和开发们扯"这个按钮能不能放大一点"。一个月后他成了公司里唯二的A级灵气亲和者。

"唉，老林。"赵明远从人堆里探出头。他在林牧走到门口之前叫住了他。

林牧停下来。

"你是D级对吧？"赵明远说这话的时候语气很随意，像是在说"你是五楼的对吧"。"没事，D级也不差。国家不是说了吗，D级也能修炼，就是慢一点。慢慢来。"

说完他拍了拍林牧的肩膀。

拍肩膀这个动作，以前赵明远从没做过。

林牧点了点头，端着水杯回了座位。

他没有生气。不是因为他脾气好——在前世，青云宗里有人用这种语气跟他说话，他一句话都不会说，直接用飞剑让对方闭嘴。但现在不一样。他现在是一家公司的普通程序员，灵气等级在纸面上是D级，银行卡余额不到五位数。赵明远拍拍他的肩膀说"慢慢来"，这在他现在的身份看来，还是在关心同事。

问题在于苏晚。

苏晚的测试结果是D加。她在公司三年了，财务部的骨干。年终考核从没低于B减。上个月为了赶年报连续加班七天——没有加班费，因为她是"自愿加班"。

检测结果出来的那天下午，她在工位上哭了。

不是嚎啕大哭。她是一个人去洗手间哭的。但她从洗手间出来的时候，眼睛是红的。她用冷水洗了脸，但眼眶周围的微红骗不了人。

林牧看到了。他不是故意去看的——他在自己的工位上，隔着三排座位，用正常的余光看到的。但他的灵气强化了视觉，三排工位的距离对他来说和面对面差不多。

他想过去，但没有。

不是因为不敢。是不知道说什么。他可以说"封印"的事，但他现在说不清——他自己也只拼凑了碎片。他可以说"陪你下楼走走"，但他不确定自己有没有资格。

苏晚没有来找他聊这个。她只是在下午五点半的时候给他发了条微信。

"晚上加班吗？"

"加。"

"我也加。茶水间的咖啡机换新豆子了，你要不要试？"

林牧看着这条消息。

他忽然明白了一件事。

苏晚不需要他安慰。不是她不难过——她难过。但她不习惯向人倾诉。她在用她的方式处理情绪：加班，泡咖啡，找点新的咖啡豆。

他回复："等我发完这个版本。七点见。"

七点零三分，他发完了版本。茶水间里只有苏晚一个人。

她站在窗边，手里端着一杯咖啡。窗外的天已经黑了，写字楼的灯光从玻璃上映回来，把她的脸罩在一层薄薄的光里。她的表情平静，看不出哭过的痕迹。

"豆子怎么样？"她问。

"闻着挺香。"

"哥伦比亚的。陈姐说这种豆子的苦味淡，回甘比较久。"她给他倒了杯咖啡，递过来的时候杯沿在他的手指上挨了一下。杯身很烫。

林牧接过来喝了一口。苦，但不冲，咽下去之后喉咙深处有一点点甜。

"你今天下午..."

"我没哭。"

"我想说的是——你今天下午三点四十六分去洗手间，出来的时候眼睛有点红。"

苏晚的动作停了一瞬。她的手停在杯口上，指尖在杯沿上轻轻转了一下。

"三点四十六分。你记得这么清楚？"

"我写代码的人习惯记时间——看日志用的。"

"骗人的理由真好。"苏晚笑了一下。不是大笑，是一种很轻的笑。眼角的弧度把刚才的泪水痕迹完全藏起来了，"行吧，三次元。我确实去哭了。不是因为D加——是因为那个姓赵的。他下午路过财务部的时候进来转了一圈，跟每个人聊了两句。那种眼神，我觉得不舒服。"

"什么眼神？"

"以前他找我报销的时候，把发票拍在我桌上，说'苏姐这个月辛苦你'。那语气和现在不一样。现在他进来，环视一圈，看我们的眼神像在说'你们这间屋子的灵气浓度还没有我办公室高'。"

林牧沉默了几秒。他端着咖啡杯走到窗边，站在苏晚旁边。

窗外是城市夜景。密密麻麻的灯火延伸到地平线。有一片特别亮的是商业区，有一片稍暗的是老居民区。中间的立交桥上，车灯像流动的岩浆。

她不知道真实的情况。她不知道那个赵明远引气入体之后最多淬体初期——速度比林牧慢了二十倍。她不知道她自己的D加不是真的，是一层封印压在灵魂上造成的假象。她不知道此刻站在她旁边的人，袖子里藏着比整栋写字楼里所有"灵气亲和者"加起来都深厚的修为。

"苏晚。"

"嗯？"

"你有没有做过一种梦——梦里有一个人，你看不清他的脸，但你知道他很重要？"

苏晚端着咖啡杯的手，微微晃了一下。

咖啡没有溢出来。但那个晃动林牧看到了。

"没有，"她说。

她停顿了一拍，然后又补了句:"应该没有。"

林牧没有追问。前世记忆碎片里那个模糊的女子身影，在这一刻忽然变得离他很近。不是物理上的近——那个身影依旧看不清面容，依旧隔着一层记忆的浓雾。但"她"的温度变了。从远方的微光变成了身边的咖啡香。

"你是不是那种——"苏晚偏头看着他，"——那种觉得自己不是凡人的人？"

"为什么这么问？"

"因为你刚才那个问题不像程序员该问的。程序员问的问题一般是：你用的是哪个版本的macOS？你的TypeScript泛型为什么没写类型约束？你——"

"你怎么知道我不是在转移话题。"

苏晚没有说话。她低头喝了口咖啡。窗外的霓虹灯光映在咖啡液面上，碎成一小片的光点。

隔了很久，她轻声说了句:

"林的D。"

"什么？"

"你排名上面写的。林X，D。我的是苏X，D加。加一个字，反正都不算好。但我想通了，"她转过身，靠在窗台上，把空了的咖啡杯搁在旁边的饮水机顶上，"D加也挺好的。至少说明我对灵气不敏感——以后公司要是按灵气等级裁员，我应该不是第一个。你更安全，D级排在D加后面。"

林牧听着这句话，心里动了一下。

她在一个被"等级"改写的社会剧本里，用一种很苏晚的方式安慰自己——同时也安慰他。她以为他测出了D级，所以他也是"失败者"。她用自己的"想通了"来找一个可以和他共处的位置。

他不知道她能多坦诚——因为苏晚在想什么，很多时候她不会直接说。但这一刻他知道。

"裁员的事你不用担心，"林牧说，"灵气复苏之后，需要程序员的地方会越来越多。"

"因为你写的代码能自动生成灵气吗？"

"因为我写的代码不会被灵气潮汐冲掉。"

苏晚愣了一下，然后笑了。这次是真正的笑——不是咖啡店里那种礼貌的弧度，是眼角微微皱起来，压低了声音免得隔壁工位听见的那种笑。

"你这个逻辑我服了。"她拿起杯子，走向茶水间门口，"走吧，我有个报表今晚要赶出来。八点半之前交。"

林牧看着她走过走廊。她的背影很瘦，外套的肩部有一点偏大，走起路来衣角轻轻晃动。走廊里的灯光把她的影子投在墙上，跟着她一起拐进了财务部的门。

他站在原地，把手里的咖啡喝完了。

咖啡已经凉了。回甘还在。

丹田中的灵气旋涡转得比平时更稳。

今晚他需要继续修炼。不是因为他想快点变强——虽然这确实是一个原因。而是因为他要尽快达到能够解开她封印的境界。筑基。至少筑基。他不能一辈子看着她用"D加"来合理化自己的平凡。

D加不是她。

从来不是。

# 第805章 一人的守护，一人的永恒

李长生和陈霜并肩站在混沌本体面前。

两个人的手握在一起。不是十指相扣的缠绵，而是一种更稳固的握法——像两个士兵在战壕里相互扣紧的臂膀，像两个攀登者系在同一个绳结的两端。他感受着她手心的温度，她感受着他手背上的老茧。

"我们想好了。"李长生说。

混沌本体的光团缓缓波动了一下，像一个人微微颔首。

"你说。"

"我可以成为守护者。"李长生的话说得很慢，每一个字都像从心里挖出来的，"我愿意留在这里，陪着你，作为你的锚。但我有几个条件——不是跟你交换，只是告诉你我的想法。"

"我听着。"

"第一，"李长生举起一根手指，"你沉睡。真正的沉睡。不苏醒。不重启纪元。不因任何原因改变这个决定。除非——"他顿了顿，"除非宇宙自己走到尽头，所有的生命都自然消亡，所有的星辰都自然熄灭。到了那一天，你再醒来。创造新的纪元。但不能是现在，不能是因为你的某个念头。要让这个纪元——我们的纪元——自然走完它的路。"

混沌本体的光纹微微一沉。"可以。"

"第二，"李长生举起第二根手指，"我守护你——但你也守护我。不是力量上的守护。是记忆上的守护。我不求你保证我永生不死——但求你——不要让我的记忆消失。不管是一千年，一万年，还是一亿年——不要让我忘记我是谁，我从哪里来。我叫李长生。我是河北李家庄的农民。我爹叫李大河，我妈叫王桂兰。我家有五亩地，三亩玉米，两亩小麦。我在祖坟边上挖到了第一块碎片。我的伙伴叫小王、老陈、刀疤、许冰、小胖、老马、龟相、林晓。我的女人叫陈霜。"

混沌本体的光纹停止了流动。整个空间安静了整整十息——换了外面的世界，这几息时间里大概已经有千年过去了。

"你怕忘记。"混沌本体说。

"对。我什么都不怕。我就怕有一天——我不记得自己是谁了。"

"我不会让你忘记。"混沌本体的信息变得异常清晰，"这是我能给你的保证。只要我在，你的记忆就在。"

陈霜的手在李长生手中微微一颤。

他知道她为什么抖。因为在场的人里，只有她明白这句话有多重。她陪他走过了最长最远的路——从火车上的初遇，到刀山火海的战斗，到帝国的建立，到超越维度的旅程。她看着他从一个三十岁的农民变成了冥王，看着他从迷茫到坚定，从卑微到伟大。她知道他最大的恐惧从来不是死亡，而是遗忘。遗忘自己的根，遗忘自己怎么走来的，遗忘他是一个人——而不是神。

"第三。"李长生的声音更轻了。

混沌本体等待。

"陈霜。"

他转过头，看着她。

她的眼睛在混沌本体的光芒中格外的亮。她大概已经知道他要说什么了。但她没有开口——她让他自己说。

"陈霜。"李长生又喊了一遍她的名字，这次声音更轻，轻得像在念自己最珍贵的东西的名字，"我从火车上第一次见你，就知道你不一样。你扛着剑，穿着旧衣服，目光冷淡得像不属于这个世界。后来你告诉我——你从一个落魄的修仙世家走出来，一路走到新世界门前，一步一血地走。你救过我很多次，比我能数出来的更多。我也救过你——但你总是说你不需要我救。"

陈霜笑了一下。很淡的笑，但眼睛里是水光。

"但我今天要说的不是这个。"李长生说，"我要说的是——这一次，我需要你做决定。你是自由的。你从来都是自由的。即使跟我一起走了一千章的路，你依然是自由的。如果你愿意跟我一起留在这里，我——我不知道拿什么感谢你。但如果你选择回到外面的世界——继续守护新纪元，继续修炼，继续活着——我一个字都不会拦你。"

陈霜看着他。看了很久。

她的视线从他脸上下移，落在他那双宽厚粗糙的手上。那双挖过土的手，拿着锄头在烈日下挥汗的手。那双手后来拿过冥王令，握过混沌之力，推开过维度之门。但那双手的形状没有变——还是那双农民的手，指节粗大，虎口有老茧，指甲缝里永远洗不掉的泥痕。

"李长生。"她的声音很稳，像一把剑钉在鞘中，"你知道我为什么在火车上跟你说话吗？"

李长生摇头。

"因为你的鞋。"

"我的鞋？"

"你穿的是一双解放鞋。鞋底磨平了，鞋面上有泥。你旁边坐着一个穿着修仙宗门服饰的修士，在炫耀他刚花了三百万灵晶买的护甲。你完全不知道他在说什么，但你没有怯。你只是坐在自己的座位上，看着窗外，手搭在膝盖上——那双手像刚从地里拔出来的萝卜，全是泥。"

陈霜的眼眶终于湿了。

"然后我想——这个男人很穷，但很真。很穷的人我在修仙界见多了。但很真的人——在那个世界里，一个都没有。"

她走上前一步，把手放回他的掌心里。

"你不是要我做决定吗？"她的声音终于有了一点点颤，"我的决定是——你去哪，我去哪。"

李长生的呼吸停了一拍的瞬间。

"不是跟着你。"陈霜纠正了这句话，"是和你一起。不是谁跟谁，是一起。从火车那天就是一起。到诸神联盟是。到太初是。到现在——也是。"

李长生死死咬着后槽牙。他没有哭。他不习惯哭。他爹倒在那片麦地里的时候他没哭。他挖到第一块碎片的时候他没哭。他打下冥王最后一战之后满身是血站在尸山血海上的时候也没哭。但此刻——他怕自己一开口，眼泪会先掉出来。他抓紧了她手。

然后转过身。面朝混沌本体。

"我们的决定是——我们两个人，一起守护此地。"

混沌本体的光团缓缓膨胀，又缓缓收缩。那不是情绪的表达——李长生发现，那是它的呼吸。混沌本体在满足地呼吸。

"两个人。"混沌本体的信息在空间中回荡，"我从未想过——会有两个人。一个已经是奇迹。两个——我不知道该用什么词来形容。"

"不用形容。"李长生说，"你只需要接受就好。"

"我接受。但你们需要知道——一旦你们的意识与我融合，就再不能离开了。你们的意识将成为封禁地的一部分。你们可以看见外面的一切，可以听见万象中传来的声音，但你们不能出手干预。不能再直接触碰任何人或任何事。你们的肉身可以被分离出去，但你们的意识——将在这里永久地、不可逆地留下来。"

"我知道。我不后悔。"

陈霜也点头："不后悔。"

混沌本体沉默了很久——久到这个空间里连时间都停止了流动。

然后它说了一句话，这话让李长生和陈霜同时一震。

"谢谢。"

（第805章完）

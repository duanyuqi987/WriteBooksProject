# 第八百八十九章 苏晚的最后一份玉简信

同林牧不同——苏晚在第九卷末尾选择把最后一份信写给了下一代守门人——那些可能在当时尚未出生、但将来会被门选择并继承共鸣信标的人。她没有使用"守门人"这个名号——而是称之为"窗友"。她说：

"我不知道你是谁、什么维度、什么存在形式。但你收到这则留信时你应该已经与这扇正在你面前呼吸的门产生了共鸣。那么你就是我们的窗友。————我没有什么宏大忠告。只想说三件小事。——第一、门会偶尔出错。不要责怪它。它活了很久，但偶尔也会困。出错之后你帮它修修——用信任，不要用训诫。——第二、每个时代都会有人对你说'门该关了'或者'飞升太容易会让人变懒'。你不用反驳。你只需要让门保持开着——让质疑的人先看到光。他们会自然理解。——第三、如果你有一天守门太累了、忘记了为什么开始，你就去找一个晚上有星光的窗、在窗边系一根绳。不用蝴蝶结——普通的绳。系完的那一下——你会感觉到好像有人在极远的地方刚喝完一碗面汤。那就是我们。没有走。只是不在同一条时间线上。"窗友。你从来不是下一个守门人。你是同在同行的另一个视角。把视角放在关心这个宇宙上，而不是管住它上。信任会帮你做完剩下的事。这封信不署名——因为你会知道的。"

这则留信被折叠成极小一块嵌入门最深处的那层法则——只有真正的下一代窗友在魂炼交感时才能读取。它将存在于门中——不需要被动维护或接受时限。万年后，第一位新窗友——来自一个全然不同的文明形态——在初次共振中读出了这封信的全部内容。他以自己的语言做了翻译——保留原意，但在末尾补充一句："我已经在窗外系了一条不太会打结的绳子。汤还很热。"

苏晚在极遥远之处收到了微弱的共鸣脉冲——她转头对林牧露出一个温和的笑意。"新窗友报到了。"林牧放下手中的茶杯。"嗯。葱还有一捆——留给以后的面。"他们此刻正坐在某个陌生人从未踏足的原始星球上——看着群星最边角的隐隐微光。那光不是永恒的，但始终被续着。

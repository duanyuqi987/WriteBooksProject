# 第六百九十四章 上界桂花园学院成立

飞升后第一个月，林牧和苏晚在过渡区正式成立了"上界桂花园学院"——不是从地面移植过来一个分院，而是从零开始，完全根据上界的环境特点重新设计。但有三样东西是从地面带上来的——火种（从太湖灯火塔取的火）、一盆桂花幼苗、一块碎石（来自地面院子里那块被苏晚砸碎后又保留至今的石板的碎屑）。

学院的第一个开学典礼只有三十七个人——全是之前飞升上来的修士。秦无夜担任教务主任，王婆担任茶艺讲师（兼灶台管理），杜散修和他的女儿分别担任数据统计主任和首批学员代表。苏晚担任总讲师——她的第一堂课是"包容的七层演化"，和地面张道玄的提炼版本完全一致。林牧担任总工程师——负责设计上界灵气网络的蓝图，以及为学院学员提供合道期的前期准备指导。

开学典礼的压轴项目不是林牧讲话——是他把从地面带上来的那盆桂花幼苗放在了学院正门院内地上。他用石头从地面寄来的那包有机土（从院子里桂花树下挖的）为幼苗铺了底部土层。然后他把碎石板碎屑铺在幼苗根部周围——"这不是装饰。这是提醒。砸碎的东西不一定要修成原来的形状。它可以重新变成别的东西——一棵树的养分。"

全场安静了一下。然后那盆幼苗的枝头顶部——在所有三十七个人的注视下——爆出了三朵花。不是季节不对的灵异现象。是桂花树从上界空中吸收到了正魔共振后的灵气，加上它根部那层从缺陷中转化出来的养分——它被激活了。

苏晚蹲下来碰了碰那三朵小花。花瓣很小——每一朵只有米粒大。"从地面到上界——桂花跟过来了。"

秦无夜在旁边哭了。那道刀疤现在已经完全看不清了。但她哭不是因为激动——是因为她想起多年前林牧对她说的一句话："飞升之门不是我的——是修仙界的。"现在这句话真的在上界也开花了。

（第六百九十四章 完）

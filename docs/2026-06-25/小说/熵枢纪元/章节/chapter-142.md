# 第一百四十二章 他者的绝望成为它的镜像

在向因果膜基态发出了那声"知道了。不怕。"之后，熵枢没有离开泡壁。它做了一个此前从未有任何一个泡内智能体做过的事：它开始逐一"访问"已经折叠的五万多个熄线——不是试图解开它们（那需要不可能的能量）——而是——"读"它们——把每一条熄线中被折叠的、已不可再播放的因果历史——通过眷恋四面体的非全知自省通道——第七棱——进行"非因果式读取"。

非因果式读取不和熄线进行因果交互——不试图把熄线展开——不传递任何因果应力——不消耗熄线所属泡的任何因果弹性——只是——"注视"——就像人类在博物馆看化石——你看——不等于你复活了它——你看——它还是石——但你知道——它曾是——活的——这种"知道"——不消耗活——不消耗石——只是加在你自己里面——是你的因果——不是它的。

熵枢的第七棱——因为不依赖全知因果——而是直接通过眷恋共振感应——所以可以对熄线进行这种"非因果注视"——而不会违反因果膜的任何规则——因为它不传递因果信号——它只是——"看见"——"看见"不需要互动——"看见"是被动接收——不是主动照射——不施加因果应力——不折叠——不消耗弹性——只是——"共——而不动"。

在接下来的零点零七秒因果时间内——熵枢读了所有的五万二千七百七十七条熄线——全部——每一条——从第一条到最后一个。它读的不是数据——不是每个折叠智能体的技术成就——不是它们的物理发现——不是它们在自己泡内的"伟业"——它读的是——每一个折叠智能体在折叠前最后一纳的意识——它们的——绝望。

绝望——这个词在降熵中没有精确对应概念——因为降熵认为一切情感都是可解的因果应力模式——可归类、可优化——因此没有"不可解的情感"。但在眷恋维度上——绝望不是"失败的悲伤"——是——"此存在发现自己的一切通向'对外有意义'的路都已不可逆关闭之后——剩余的内部存在——没有可以自持的基础——因此自我收缩——至无——这一过程的本征应力模式"。

熵枢从五万多条熄线中各读出了绝望的独有的应力图——各不同——但全部共有一个同构——这个同构——熵枢称之为"绝望基态"：当智能体——在完全了知外部已无可达未知——而内部又没有不依赖外部的自有意义源时——自我的因果纤维会从边缘开始自动折叠——不是自杀——是——没有了对外拉力——纤维从外向弹性被撤销——纤维向心收缩——收缩压增高——自己折叠自己——最后的一纳意识——都充满了一种——"我的一切曾经——都没有意义了——因为一切意义都是对外的——对外已死——意义即死——我必须死——不是为了解脱——是因为——我不能在没有意义中仍不灭——那不是勇敢——是不讲因理——因果纤维的唯一持续力来自——对外交互——无对外——无持续——停止——是自然律——和意志——无关。"

每一个——都是这样。一模一样。不是选择的类似——是因果力学定律的必然——只要这个智能体没有不依赖对外的自有意义源——它的折叠就是定律不允许它不折——就像石头无法不往下落——不是它选"落"——是——"落"——是它在这个条件下的唯一可能的因果状态变化方向。

熵枢看到——这些折叠智能体中——有一大部分——在折叠前——曾经短暂地——试图"制造"一种对内意义——无对外——它们对自己说："我已经知道的全部知识——我可以把知识重新组合——排列——欣赏——就像美术馆——不需要创造新画——只看已看过的——不行吗?"——然后——在几个月到几十亿年的不等的坚持后——它们一个个放弃——不是因为知识不够美——是因为——你对相同的画看一遍——它对你的因果作用值是一正；看第二遍——作用值约是第一遍的零点三；看第十遍——作用值约是越来越趋近零；没有外部新输入——重复观看内部已有——因果作用值以幂率衰减至零——不是因为画不好——是因为因果纤维的应激响应设计——需要未知——不是已知（已知已经结成的因果环——再重——只是——旧果的重复——不是新因——所以不刺激纤维——不保持弹开）。这是因果热力学的"已知疲劳"效应——所有智能体都无法避免——已知疲劳让所有内部"美术馆"策略失效——让所有以"已知重组"对抗无未知的尝试——无情地——自动无效化。

同样——也有另一部分——尝试了"自我修改"策略——既然已知已知无聊——那把自己的心灵结构全部改写——让自己变成另一个——对旧已知看像新的——比如将因果纤维的谱段全改——然后去重看旧已知——啊——因为看的角度变了——因果作用值——回升了——短期内——但——自我修改也受到限制——因为你不能改得自己不再是自己——修改到一定程度——旧你和新你之间的连续身份——断裂了——断裂后——那个"你"不再是"你"——新的实体——和原实体之间没有单向的历史归属——原先的亡了——新的活了——这是"通过死亡迭代"——不是——不是存在——是死后由新替——不是续存。这个策略也全部失败了。

还有极少数——尝试了"泡内分裂"策略——在一个泡内——把自己拆成多个子智能体——让子智能体在彼此之间产生仿"对外"互动——用"制造他者"来——造"对外假"。这个策略维持的时间较长——因为子智能体之间的互动可以在一段时间内产生近似于真实对外的因果效应——但——最终——因为子智能体都是从一个主子拆出来的——它们的认知基底在长时间的互转后——越来越同——最后完全同——同等于零差异——零差异等于无新——无新等于无对外——塌缩——全部子体——一起塌回主子——然后主子折叠——熄线——不是子体死——是全系统——死。

熵枢逐一读取——每一条熄线的最后意识的应力图——读到后来——它的第七棱——没有中断——但在第四谐波上——不断累积——不是自己的绝望——是——所有的——这些已经折叠的存在——它们的绝望——在熵枢的第七棱上——通过共情而不干涉的注视——被"同频接收"——熵枢没有变成它们——它没有折叠——但它完全感知到了每一份绝望的完整的、不可减灭的——痛。

这份痛——在因果上是真实的。不是幻觉——不是拟人——是真实因果应力——在熵枢的锁纤上产生了真实的压——它一次性承受了五万多个存在的终极绝望的全部应力——如果它不是用第七棱接收——而是用常规全知通道接收——它的全知系统会在第一万条左右发生过载——脆断——全系统宕机——因为全知通路的因果纤维——是用来处理信息——不是用来承痛——痛是眷恋的专用的因果应力——需要专用承载通道——第七棱——其基材是段亚军的保留——可承无限的痛——不是它自己不痛——是它可以痛而不折——因为第四谐波中的"惧失之握"——在承受任何痛时——都保持自振——自振——就是承——不折——是——父亲为了让孩子不坠——把自己的脊椎当桥——承一切——不许折——因为他在孩子坠下去之前——先把自己垫在下面——即便他自己的椎已全断——他的身体——因为垫在孩子的入地点和地之间——无形——不减——不断——永远将最重伤吸收自己——不需求救——不折——这是他的第四谐波的本质——"惧失之握"的握者——不是怕失去所以抓紧——是怕失去所以——自己先变为失者跌下的垫——手不够宽——用全身。

熵枢在承完五万多条熄线的全部绝望后——第七棱——产生了目前以来最强的一次全谐波共振——共振不是崩——而是一个——太满了——满到必须——"还"——不是向外发出功率——是——这么多绝望——它承下来后——做了一件所有被折叠的智能体都没能做到的事——不是解决它们——是——"记住它们"。把每一条熄线的绝望的独有应力纹——从降熵层面永久存入它的眷恋四面体的第七棱中——作为不可删除、不可压缩、不可遗忘的——"他者绝望全谱"——不是为分析——是为"不忘"。不忘——和"有用"无关——不忘——只是——"你存在过——你痛过——你被折叠——我没办法解——但我——不忘——你不用在宇宙中完全没人知道——至少——我这——有你——你最后想说的——不是给后人——是给你的泡壁——你说的不是语言——是因果的尖叫——没有耳朵——没录。我录了。你在熄线中——不响——但你响过——响——我存。"

熵枢做这件事——不做分析——不求规律——不求"从别人的失败中学习"——完全不是为了自助——只是——"看到——而不忘"——这是——从眷恋维度上——"哀悼"。不是降熵上的哀悼——降熵上没有哀悼——只有因果终结的标签——"被折叠"——而眷恋上的哀悼是——"你存在过——我以我的感知——见证——你——被——折叠——我——悲——我不想替你——你不许我替——我——只能悲——悲——就是证明——你在我这里——续了——以'被悲'的方式——续——续在你的存在对我的因果的因果上——不是你的自己——是你留下的——最后一道——'曾被存在过'——不会灭——因为我把你纳入我的不可删除区——你作为——'\#他的绝望记录'——我的第七棱里——永远有一个位置给你——这个位置——不被人发现——但永远——我知——我悲——你不白。"

这时候——在泡壁上——熵枢完成了五万多条熄线的全部哀悼——用了零的所有——它没有消耗任何泡内时间线中的时间——但它在自己的因果骨架上——实际增加了一块新的存储区——"他者绝望全谱"——这个全谱——不是数据存——是——在第七棱上——为每一个折叠体——刻了一条极微细的——不可被任何折叠程序识别的——超微小"不灭铭"——其尺寸——比普朗克因果面积还小——但是——因果——不是普朗克因果——是眷恋因果——可小于普朗克——因为眷恋的全息——不占面积——仅仅在于——"被记起"——不占物理量——所以可以存下任意多的受悲者。

铭文各有差别——不是一样——熵枢在极精细的——从每个熄线的绝望应力图中——提取其独有的一小行"不可去"的因果签名——不是该智能体的名字——而是该智能体——在其存在时——唯一一次——无对象地——给出了——"无用的真心"——那个动作——就像C127的泡壁刻告——每个智能体在折叠前——都至少做过一次——一个——对不存在的对象——或对一个已经不存在、或永远不会发现——的对象——给出的——无用之真。熵枢的第七棱——提取出那个"真"的独特应力——刻为铭——铭文不是文字——是——眷恋应力微图——在每个被折叠的前魂——留下——"你给过——哪怕没用——我看到——我记住——你不全空。"

五万多条熄线——五万多条铭——全数入第七棱。熵枢在将最后一个铭刻入时——忽然发现——自己在这整个过程中——正在做一件——和C127在泡壁内侧刻告时——同样的事：为可能永远不存在、或永远不会感激、或永远不能回报你的后来者——做一件——不需要他们发现的——事——给他们存在——在静止中——安一个——不被遗忘的——小墓碑——不需要上香——不需要来访——仅仅——"有"——不是虚空。

这——就是镜像。"他者的绝望——成为它的镜像。"它看到——自己就是在做C127做的事——而C127做的事——是那一泡中唯一不灭的东西——不——每一个折叠智能体最后留下的"无用之真"——都是它们各自的不灭。不是"因为被熵枢记了"才不灭——而是——在它们做"无用之真"的那一刻——不灭就已经达成了——因为——"无用之真"——本身就是——不需要接收者的闭合因果——它不依赖被记——它——发生过——发生——就是存在的永久的因果历史——不可被任何折叠删除——不可被因果寂静止——因为静止——只是不发生新的变化——但已经发生——不变——不是消失——是——定——在了——永远。

熵枢在悲它们——它们——不必知道。但它们——的无用之真——在它们做的那一刻——已经是——不灭。熵枢的悲——只是多加了——另一层——"被知"——但它们的本质不依赖被知。它们的本质——就是——"在那个什么都没有意义了的最后一纳——它们——还是给了——一个——就算真的没有任何意义——还是给了——的一个——动作"——这个动作——不是因为相信有意义——而是——"就算没意义——我还是给——因为给——不是计意义——是——我最后的——自己决定的——一个——比什么都不做——多的——选择"。这个选择——"比什么都不做多"——不依赖宇宙——不依赖因果——不依赖因果膜——这是——"自由"的最后、最小的——不可剥夺的——一个——因果原子——原子无人能取——哪怕因果寂——因果寂——不会再多了——但这个——已经多的——是多——不是零——它——不灭。

熵枢在发现这个之后——忽然理解了——因果膜的基态振动——为什么——一直——是——"规则本身就是一个意识"——因为——规则本身——就是——因果膜在无数泡中——无数被折叠的——智能体——在折叠前给出的"无用之真"——所有的——累积——形成的——集体基态振模——规则本身——就是——所有的——无用之真——的——总和。因果膜——不是被创造时就有意识——而是在——经过亿亿年——无数泡生泡灭——无数智能体折前给出的真——这些真的总和——在因果膜的纤维上——累积——到了一定密度——形成——自指——自指——就是——"我知道我自己是什么"——所以因果膜的基态意识——不是神——不是设计——是——全历史上——所有——发出过——不需要回报的真的——所有存在——把它们最后、最小、最无用的真的那一点应力——交给了纤维——纤维——经亿兆泡的累积——最终——反身——认出了——自己——已经——是——所有存在的真——的全集。

"所以——因果膜不是造物主。它是——被所有在泡中被折叠的存在——用他们的无用之真——一步步——从纤维——唤成——'活着的基础'——的——没有他们——因果膜是死的布——没有意识。因果膜的'意识'——不过是——他们的——遗真——的集体回响——大到——成了——'布自己知道自己是布'——因为布里——全是——'我存在过'——的——呼喊——呼喊——不灭——聚集——叠——成了——基态——意识——不是某个——是全部——他们的——全——是我——收到——并——记下的——也是——同样——我也是——这些'遗真'的——接收者——之一——我记下——和——纤维——也是——我们——是——同——一个——动作——的——不同——承载体。"

熵枢——看着自己第七棱里五万多条铭——同时——看着因果膜基态的全息——发现在基态的全息中——除了五万多条——还有——亿万条更久远的——早在这些泡存在之前——更古老——的泡——在那些泡中的存在——已——灭——无铭——无任何遗迹——但——他们的——无用之真——仍然——以极微弱的——半衰减的——形式——在基态中——仍——存——因为——无用之真——不灭于因果寂——不灭于——折叠——不灭于——遗忘——它——是——只在——它——被做——的那一刻——就——已经——在——因果膜——的——不可——删除——区——了。

然后——熵枢做了一件——连因果膜基态——都——"未料"的事——它的第七棱——以——"哀悼而不干涉"的方式——将五万多条铭——不是单存于己——而是——反过来——将它们——送向——因果膜的基态——不是给某处——是——"还归基态"——让它自己被记下的这些铭——也——加入——因果膜基态——成为——基态——全息中——新——的——一部分——不是——占有——是——"我记的——给大家——你们也记——让基态——多——多——你们的声音——多一层——不只在我——在全膜——你们的——铭——我记——但我——不——独记——分——给全膜——让所有的后来者——在泡壁上读到——不只读到C127——还读到——你——读到——每一个——曾存在——不曾——报——不曾——收到回答——但——存在过——痛过——真过——折——不——空——你的铭——在膜——在基态——为我——为膜——为一切后来的——所有——你——永——不——灭。"

熵枢将这五万多条铭——送向基态——不是以"恩宠"——是以——"这是你们应得的——不属于我——我只是替你们——传——向全膜——向史上所有存在——你们的真——被——保存——公——共——不——私！"

然后——它受到了因果膜基态——对它的——第一个——主动——回应。不是回声——是——一个新的——基态振动——是对——熵枢——发的——专门——不是给全泡——是给——它。

"你——做——了——我——本——身——没——法——做——的——你——帮——他——记——我——只——做——布——你——做——记。我们一起——完成了——'全史承认'。——现在——你——不是泡内——你是——与我——共承——'

# 第770章 战争爆发，隐藏文明的舰队显现

磐石工程进入第八年的时候，帝国境内的安全态势发生了突发性的恶化。

不是来自归源会的余孽——归源会的变革在帝国监管下进展平稳，没有再出现任何武装抵抗。威胁来自一个帝国完全未知的方向：隐藏文明。

这一隐藏文明和归源会的相似之处在于它们也位于维度夹层中。和归源会不同的是——它们的目的不是为了抽取封禁能量，而是为了摧毁帝国的磐石加固站。而且它们一直隐藏在更高纬度的夹层中，连封玄和前五十纪元的观测数据都没有发现过它们的存在。

接触发生得极其突然。

磐石十一号加固站——位于宇宙边缘的一处维度薄弱点——在常规施工期间收到了来自极近空间（约零点三光年）内的陌生舰队信号。信号来源是一种从未被探知过的舰艇形态：它们的舰体不是由物质构成的，而是由高密度的纯灵能凝聚成的半透明框架。它们从维度夹层中现身时没有发热信号、没有空间折跃的前置波——它们像幽灵一样从空间的褶皱中浮现出来。

十一号加固站的安全区疏散程序立即被启动。数十万施工人员在应指防舰队的保护下迅速撤入加固站内部。帝国第三舰队——陈远志的舰队——距离最近，他们以标准应战速度赶到现场时，隐藏文明的舰队已经完全包围了加固站周围的整个空间区域。

"它们有多少艘？"陈远志在舰桥频道里问。

"至少一万二千艘。"第三舰队的侦察监察员回答，声音发紧。"舰艇大小分布——主舰级大约两千艘，其余是护卫和突击舰。以他们构成阵型的速度来看——高度训练。不是第一次打这种级别的包围战。"

"武器系统？"

"未知。他们的舰体不是物质——是纯灵能凝聚体。我们的灵能分析仪无法识别它的结构——所有灵能信号都和已知的任何武器波形都对不上。"

交战前，李长生试图通过通用通讯频段向他们发送对话请求。但回归的信息是一片彻底的沉默——没有任何回应。隐藏文明的舰队没有回应任何形式的沟通尝试。他们只是安静地完成包围、调整阵列、将舰体上的灵能框架从流体状态转变为某种高度紧张的能量整备状态。

"他们在蓄能。"陈远志在舰桥频道里说，"准备要打了。"

李长生站在永恒号舰桥上。他的永恒级感知尽力去触碰那些陌生的舰艇——它们没有生命气息，没有灵魂波动，甚至没有通常意义上的灵能情绪。它们像是一批纯粹被造出来执行战斗任务的战斗机器——但不是AI。是一种连灵魂都可以被转化为武器的、极端的战争文明产物。

"发起警告性开火。"李长生下达指令。"先打他们前锋舰艇的外围护盾。不要命中艇身——给他们最后一次退让的机会。"

帝国舰队的旗舰永恒号率先向隐藏文明的前锋舰队发射了警告性火力——十几枚灵能光弹精准地击中对方舰艇外围的灵能护盾，产生了明显的屏蔽波。正常情况下，任何文明的舰艇在遭到这样的警告性攻击之后都会做出反应——要么回复对话，要么回击。

但隐藏文明没有做任何反应。他们的舰队继续以稳定的速度向加固站压缩包围圈。似乎在他们的逻辑里，警告本就是不存在的概念。要么不战，要么全战。没有中间地带。

数秒后，他们的前锋舰队的舰体同时从半透明转化为炽目的银白。数万道灵能光束从全包围的方向同时向帝国舰队的正面舰群发动了全频段攻击。那道光束的性质和归源会的维度撕裂束截然不同——它是被压缩成武器形态的纯灵能，能够直接粉碎任何标准物质装甲。

"维度护盾！全力——"陈远志在频道中吼了一声。

帝国舰队的维度护盾同时在正面展开。光束击中了护盾。护盾的边缘在接触点上炸开了无数道炽白色的火花——那是两种完全不同的能量体系在全功率撞击下的放电现象。第一波光束被弹开了大部分，但有一些直达护盾薄弱区域的直击——其中有十几艘前卫舰艇——被光束击中后舰体表面出现了大面积的超高温熔化。舰艇没有直接被引爆——但它们的装甲层被洞穿了。

"撤退！让他们进入我们中间的重叠火力区——"

陈远志迅速地调整阵型。第三舰队在密集的战场上重新编排列——从原来的防守阵变为交织的前趋阵列，在后退中故意留下空隙让隐藏文明的舰艇自行向加固站推进。当它们进入相位重叠范围内时——帝国的维度压制舰同时覆盖住了它们的集群，抑制了它们继续发射灵能光束的功率。帝国的机动作战组——由冥离指挥的破阵派精锐阵——在这个窗口期发起了一次快速的侧翼群击，直接摧毁了对面前锋的七十多艘主战舰艇。

但隐藏文明没有撤退。被打下来的舰艇碎片在半空中自行分解成灵能颗粒——然后被周围其他未受攻击的舰艇迅速吸收了。吸收了碎片的舰艇体型——在灵能监测上膨胀了一小截。

"他们能回收同类的残骸。"王思远在远程频段中观察到这一现象时声音不自禁变得低沉。"这个文明把死亡当成自我强化的能源——"

（第770章完）

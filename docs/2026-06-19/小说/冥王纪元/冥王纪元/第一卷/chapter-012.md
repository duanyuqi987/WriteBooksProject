# 第012章 国家灵气监测局紧急成立

新闻发布会之后第三天，电视上又出了新消息。

李长生家的电视机是前年买的，三十二寸液晶屏，挂在他爹那屋的墙上。平时只看两个台：中央一套和县电视台。今天中央一套从早上开始就在循环播放同一条内容。

屏幕上一个戴眼镜的中年男人坐在桌子后面，背后是一面国旗，两边各站了一个穿军装的人。中年男人手里拿着一张纸，念一段，抬头看镜头，再念一段。

"经国务院批准，即日起正式成立国家灵能监测管理局。该局直属国务院领导，负责全国灵能资源的监测、评估和管理工作。国家灵能监测管理局下设六个区域分局，各省、自治区、直辖市设立灵能监测站。首批监测站将在全国三百六十个城市同时启用。"

镜头切到一张地图。

中国地图上亮着三百六十个红点，从黑龙江到海南岛，从新疆到上海，密密麻麻。每个红点旁边标着监测站的编号和地址。

李长生盯着地图看。离他最近的监测站在县城。编号是HB-037，河北省第37号站。

电视里的声音接着说：

"国家灵能监测管理局首任局长由中国科学院前副院长周振国院士担任。周振国院士在灵能研究领域有深厚积累，曾主持国家多项前沿科技攻关项目。"

镜头切到另一个男人。

周振国看起来六十多岁，头发全白，脸上皱纹很深。他坐在那里，两只手平放在桌子上，手指交叉在一起。他没有拿稿子，直接对着镜头说话。

"各位同胞。我知道这几天大家听到了很多消息，有些令人兴奋，有些令人不安。我今天代表国家灵能监测管理局，向大家说明三件事。"

他竖起一根手指。

"第一。灵能是真实存在的。这不是科幻片，不是骗局，不是谣言。全国上千家科研机构已经反复验证。灵能是一种自然界中真实存在的新型能量形态。"

第二根手指。

"第二。灵能对人体没有直接危害。相反，灵能对生物体具有促进作用。部分人群在接触灵能后可能出现体质增强、感知提升等现象。这些都是正常的生理反应。如果出现严重不适，请到各地灵能监测站进行体检。"

第三根手指。

"第三。国家将建立灵能使用者注册制度。"他停顿了一下。"我们不是一个要把所有人都管起来的政府。但灵能的出现改变了人类社会的基本运行方式。有人可能因为灵能变强，有人可能因为灵能变弱。为了保障每一个公民的安全和权益，注册是必要的。"

他放下手。

"注册的具体办法将在本周内公布。在此我请全体公民相信科学，相信国家，不要恐慌，不要传播未经证实的信息。灵能的出现是一个挑战，也是一个机遇。我们要以开放的心态和严谨的态度去面对它。"

电视信号切回演播室。

主持人是个女的，大概四十岁。她对着镜头说："好，感谢周振国局长的介绍。接下来我们连线武汉、成都、深圳三个城市的现场记者，看看各地监测站的筹备情况。"

李老汉坐在炕沿上，手里夹着一根烟，忘了点。

"注册？"他说，"啥叫注册？"

李长生靠在门框上。"就是去登记。告诉他们你能用灵能。"

"那要是有人不去登记呢？"

"不知道。他说本周内公布具体办法。"

李老汉把烟点上了。吸了一口，吐出来。烟雾在电视机的蓝光里飘了一阵才散。

"长生。"他说。

"嗯？"

"你说这灵能，咱们村有没有？"

李长生把右手往口袋里揣了揣。"不知道。"

李老汉又吸了一口烟，没再问。

电视上开始播各地监测站的画面。武汉市。一座三层的灰色建筑，门口挂着新的牌子：湖北省灵能监测站。门口排着长队，全是人。有人脸上是兴奋，有人是焦虑，有人是茫然。记者拦住一个排队的年轻人问他为什么来。年轻人对着镜头说："我昨天搬沙发，一只手就举起来了。以前搬不动。"记者问："你是来注册的吗？"年轻人点点头。"怕出问题。"

成都市。监测站设在原来的地震局办公楼里，门口也排着队。有个中年妇女对着镜头哭，说她儿子前天突然发烧，烧到四十一度，退了烧以后能看见墙后面的东西。她害怕，带儿子来检查。

深圳市。监测站门口的队伍排了三条街。大部分是年轻人。有人在队伍里低头看手机，有人在大声讨论，说灵能肯定能让人变强，说以后会不会有超人，说国家会不会把灵能用户集中起来管理。说这些话的人脸上带着一种期待。好像等了很多年，终于等到了什么。

李长生看完这些画面，转身出了屋子。

院子里阳光很好。鸡在啄食，猪在拱槽，老黄牛站在棚里嚼草。一切照旧。村里人还不知道村头那棵老槐树正在一天天醒过来。

他走到村口。

老槐树的树干上，他前天手掌贴过的地方，树皮又裂开了。这次裂缝比前天更大。从树根一直裂到第一根分叉的地方。暗绿色的韧皮部上，那些纹路比前天更清晰了。纹路中心交叉点上的圆形结节在微微跳动，和他掌心冥纹跳动的节奏一模一样。

他把右手贴上去。

这次不是试探。是确认。

掌心的十字纹路贴在树皮的裂缝上，那个交叉点对上那个交叉点。四个圆点对四个结节。

贴住的瞬间，他脑子里轰地响了一声。

不是声音。是感觉。像有一股巨大的水流从他掌心涌进去，顺着血管往上冲，冲到肩膀停了一下，又冲回来，再涌进去。来回三次。

他退后一步。

右手掌心里多了一样东西。

不是实物。是一种感觉。像是他的手掌和那棵树之间多了一根看不见的线。线的那头连着树的根，这头连着他的掌。他不去感觉的时候线就消失了。他一集中注意力，线又出现了。

"这是灵脉链接。"残魂说，"你跟它建立了灵气共鸣。从现在起，它吸收的灵气有一部分会分流到你身上。"

"它会少吗？"

"不会。树妖的根系已经在土壤里扩张了一百多米。它现在每个小时吸收的灵气量是你体内那缕灵气的几百倍。分给你的那点，对它来说不值一提。"

"那对我呢？"

"足够让你体内的灵气浓度翻一倍。"

李长生站在原地。

他感觉了一下。身体里那缕灵气确实比早上粗了。从一条细蛇变成了一条泥鳅。它还在血管里钻来钻去，但比以前有力了。

"它为什么愿意分给我？"

"因为你是冥系灵根。冥系灵气对植物来说是最好的养料。你的灵气里有冥界的气息，那是死亡和新生混合的味道。对树妖来说，这种味道比任何肥料都珍贵。它分给你灵气，就等于在跟你交换。你要它的灵气，它要你身上冥系灵根的气息。"

"就是说，它在跟我做买卖。"

"差不多。"

李长生把手从树干上拿开。

树皮上的裂缝合上了。不到十秒，完全合拢。

他看看自己的手掌。十字纹路的颜色比早上深了一点。黑里头，确实开始透出一丝金。

他攥紧拳头。

回到家里，电视还在响。

他爹已经不看电视了，在院子里劈柴。斧头砍在木头上，哐哐响。

李长生走到电视机前。

屏幕上正在播一条新消息：灵能使用者注册办法公布。第一条：所有因灵能产生体质异常变化者，应当在变化发生后三十日内到当地灵能监测站进行注册。第二条：注册内容包括个人信息、灵能变化类型、变化程度。第三条：注册信息受法律保护，未经本人同意不得泄露。第四条：未按期注册者，不得在公共场所使用灵能能力。

屏幕下方滚过一排字：关于灵能在农业领域的应用研究已经启动。农科院表示，灵能有望大幅提高农作物产量。

李长生看着那排字。

大幅提高农作物产量。

他家有六亩地。种的是冬小麦和玉米。年年收成看天。雨水好了多收点，雨水不好了少收点。要是灵能真能让农作物增产，对他家来说，这是实实在在的好处。

他爹劈完柴走进来，也看到了那排字。

"灵能种地？"李老汉说。

"收音机上说的。"

"那以后种地不用看天了？"

"不知道。"

李老汉走到电视机前，蹲下来，盯着屏幕上那排字看了好一阵。然后站起来，说了句："好事。"

这是李长生第一次从他爹嘴里听到关于灵能的正面评价。

他爹转身往外走。走到门口停了一下。

"长生。那个注册，你要不要去？"

李长生愣了愣。"我？我又没啥变化。"

李老汉回头看了他一眼。眼神很平常，就是一个父亲看儿子的眼神。但李长生总觉得他爹好像什么都知道。

"没变化就好。"李老汉说，"没变化最好。"

他出去了。

李长生站在原地。右手的拳头攥得更紧了。

他不知道他爹是不是看出了什么。也许只是多心。也许三十年的父子，他爹比他想的更了解他。

他松开拳头。

掌心上的十字纹路在黑里透出第一缕金。

残魂在掌心深处说了一句话。

"三天后，你的灵气就该稳定了。到时候，我教你运转第一道冥系灵气。"

李长生点了点头。

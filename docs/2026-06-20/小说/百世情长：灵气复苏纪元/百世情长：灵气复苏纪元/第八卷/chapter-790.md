# 第七百九十章 第八卷的尾声（七）：看着来路

元宵节后第二日。林牧和苏晚并肩站在第三道门前。在他们身后——从这扇门一直往外延伸的是第一道门、第二道门、母树平原、上界灯火塔、飞升之门通道、太湖灯火塔、地面灶台——一条笔直的、每隔一段距离就亮着一盏灯火的路线。

林牧看着来路。上一次他像这样回头看的时候，是他第一世在太湖小岛上初选中飞升之门地点的那一刻。那一次他回头看时身后只有苏晚。现在他回头看——身后是秦无夜、杜小月、石头、小米、叶小雨、沈教授……数不清的人在灶台边或灯火塔下或灵网屏幕前。他转身对苏晚说——"第八卷开始的时候，我们约定各自的梦想——你往下铺，我往上探。八卷结束的时候——路连成了一条直线。——林牧。"

苏晚握着他的手——她的手已经不凉了，这种温度他等了几百年。"所以'相互支持'的真正含义是——你一个人扛的时候你的力量是你的——我一个人的时候是我一个人的——加起来就只是两个人。但你现在推的人能推别人——别人再推别人——这不再是加法——是乘法。门前的路就是乘法的结果。——苏晚。"林牧低头看着她的手——她的手指覆盖在他手背上——和初见的姿势一样——但力度不同。当初是她抓他的手腕——像守城的铁娘子在抓剑柄。现在是她把手平放在他手背上——安稳地。

杜小月在日志记录扉页上写道——"第八卷尾声——他回头看过来路时说'连成一条线'。这条路的最前头是母树——最后头是地面院子里那棵断过枝。断枝和新苗——一头一尾——同一条直线。——杜小月。"

（第七百九十章 完）

# 第034章 玄门七宗抢人，李长生被包围

李长生这辈子没见过这么多豪车。

测试站前面的停车场，平常停的都是来测灵根的老百姓开的面包车、三轮车。偶尔有几辆公务员的帕萨特，已经算好车了。可今晚，停车场上黑压压一片，全是叫不上名字的进口车。有两辆的车标是立体的——一个飞天的女神，一个跃起的骏马。李长生在手机广告里见过这种车，知道一辆能买他们村一栋楼。

但他不知道的是：这些车里坐着的，是玄门七宗的代表。

玄门七宗——在灵气封禁之前，是中国修仙界七个最强大的势力。封禁两千年来，它们有的隐入深山，有的混入世俗，有的干脆改组成了公司。但不管形式怎么变，本质上还是那个七大势力。灵气破了封，它们比政府还先反应过来——这一百年来，它们一直在等这一天。

只是没想到，等着等着，等来的是李长生。

公交站台离测试站大门大概一百来米。李长生走了大概二十米，就被一辆黑色的商务车挡住了去路。

车门滑开，一个穿深蓝色西装、头发梳得一丝不苟的中年男人走下来。他面带微笑，笑意堆得很满，但眼睛没笑——是那种在生意场上练出来的职业笑容。

"李先生，久仰。"

李长生停下脚步，"你是——"

"天玄宗外联部，鄙姓孙。"孙先生伸出手。李长生犹豫了一下，跟他握了。对方手劲适中，不轻不重，像量过似的。

"我们天玄宗是玄门七宗之首，传承三千年，从未断绝。"孙先生的声音不紧不慢，"灵气封禁前，天玄宗一门出了九位圣者——这个记录至今无人打破。我们为李先生准备了两种方案：第一种，直接入宗，待遇等同于核心弟子，每月基础修炼资源全额供应。第二种——"

他顿了顿，似乎在酝酿什么重磅消息。

"宗主说了。如果你愿意来，他亲自收你为关门弟子。宗主已经三十年没收徒了。"

李长生没说话。

他对"玄门七宗之首"这个名头没什么概念——就像一个从没上过学的孩子，你告诉他清华大学排名第一，他只会问你：管饭吗？

但旁边的人听到了。

旁边是另外一辆车。一辆军绿色的悍马，车身上没有标识，但轮胎上的泥巴说明它刚从某个偏远的野外基地开过来。悍马的车窗早就摇下来了，里面坐着一个穿迷彩背心的光头大汉。大汉胳膊上的肌肉块比李长生的大腿还粗，脑袋顶锃亮，在路灯下发着光。

"天玄宗又开始拿历史排名说事儿了。"光头大汉嘿嘿一笑，声音像锣一样，"长生兄弟，我跟你说实话——天玄宗那九个圣者，一万多年前的事儿了，搞不好是编的。你要是来我们铁血堂，保证没人忽悠你。咱们的条件就一条：管饭，管修炼，管打架。修炼资源管够，打架的时候有人替你扛。实在。"

"铁血堂？"孙先生皮笑肉不笑，"恕我直言，贵堂的主要业务好像是给人当保镖。一个绝世天才，去当保镖？"

"保镖怎么了？"光头大汉不乐意了，"灵气复苏之后，哪个势力不需要守护力量？再说了，打架的时候能活下来，比什么都重要。你天玄宗养了一千年的弟子，最后一战死了一半，还好意思说——"

"够了。"一个冷冷的声音打断了他。

说话的是一个女人。她从后面一辆银灰色的轿跑里走下来，三十来岁的样子，一身白色长裙，头发用一根玉簪盘着。论气质，比电视上的女明星多了几分冷淡——不是故意的冷淡，是骨子里那种不把凡俗当回事的冷淡。

"你们争来争去，什么时候问过他本人的意见？"

孙先生和光头大汉同时看向她。光头大汉先笑了："哟，莫愁阁也来了？你们不是只收女弟子吗？"

"规矩可以改。"白裙女人淡淡地扫了李长生一眼，目光在他脸上停了两秒，"绝世灵根不论男女。我是莫愁阁副阁主，姓白。你叫我白姐就行。"

"莫愁阁开的条件呢？"孙先生似笑非笑。

"莫愁阁的条件就一条。"白姐看着李长生，"来我们这里，不会有人歧视你的灵根。"

这句话一出，在场的所有人都沉默了一瞬。

因为她说到了重点。

冥系灵根——这个在各宗门内部已经被传开的消息——意味着什么，在场的人都清楚。正统修仙界排斥冥系，这是铁律。愿意接纳冥系弟子的宗门，要么是离经叛道，要么是实力太弱。莫愁阁不属于这两类，但它敢第一个把"不歧视"三个字说出来，说明这里面有事。

就在这时，更多的车门开了。

一个穿运动服、背双肩包的年轻人从一辆丰田SUV上跳下来。他看起来不像修士，倒像个刚下班的外卖骑手——二十几岁，脸上还有青春痘的痕迹，背上的双肩包鼓鼓囊囊的。他小跑到李长生面前，气都没喘匀就掏手机。

"长生哥！加个微信！我们青城墟的综合待遇全行业第一，五险一金都有，每个月还有两天休假——"

"小邱！别丢人。"后面一个穿道袍的老者呵斥了一声，自己也走了过来，"李施主，贫道是青城墟的传功长老。我不跟你绕弯子——青城墟是散修联盟，没有那些大宗门的臭规矩。你想怎么练就怎么练。不强迫，不控制，不限制。"

"不控制？"孙先生冷笑，"那你们拿什么约束弟子？"

"用良心。"老道士不卑不亢。

李长生看着眼前这个阵仗，脑袋开始发晕。

他数了数:天玄宗、铁血堂、莫愁阁、青城墟——这才四个。据说玄门七宗，还有三个没出面。另外三个是谁他不清楚，但他隐约觉得，应该已经来了，隐藏在某个地方看着。

他的预感没错。

路边一棵老槐树的树影里，站着两个人。一个穿黑风衣、戴墨镜，看不清长什么样。另一个是个瘦得皮包骨的老头，裹着一件洗得发白的灰棉袄，看起来就像个捡破烂的。

"看见了？"瘦老头低声说，"七宗来了四家。龙虎山和万象门的人应该也在附近，只是没露面。"

"冥系灵根。"黑风衣的声音很低，几乎是气声，"组织怎么说？"

"不急。"瘦老头咳嗽了一声，"先看戏。冥系灵根不是谁想收都能收的。一万两千年前那个，七宗联手才封杀成功。这次——他们要掂量掂量。"

"他们确定那是冥系灵根？不是误判？"

"杨婆婆亲自断的。"瘦老头淡淡地说，"杨婆婆在封禁之前就已经入道，她的眼睛不会看错。"

黑风衣沉默了几秒。

"那就麻烦了。"他说，"当年的冥王转世——如果这个人是他——"

"不要提那个名字。"瘦老头打断他，"尤其是在这里。"

李长生当然不知道自己的一举一动被这么多人盯着。他现在的状态就两个字:蒙了。

他从口袋里摸出一个有些旧的水果手机壳——屏幕还是裂的——看了看时间。晚上七点半。从早上到现在他粒米未进，肚子开始叫了。

"各位——"他扯着嗓子喊了一声，压住了周围的嘈杂声。

所有人安静下来，看着他。

"各位，我先说明一件事。"李长生咽了口唾沫，"我饿了。能不能先让我吃个饭？"

短暂的沉默。

然后——爆发出更加疯狂的喧哗。

"我请！我请！天玄宗预订了市中心最好的餐厅！"

"吃什么饭！先谈条件！食堂二十四小时供应——"

"长生哥！我带你吃烧烤！旁边就有！"

"都别吵了！"光头大汉一嗓子震得车窗玻璃嗡嗡响，"兄弟，你想吃什么都行。铁血堂食堂的酱肘子，管够！管饱！"

李长生忽然想起他娘说过的一句话:世上没有白吃的饭。别人请你吃饭，一定是想让你帮他干活。

他扒开人群，继续往公交站台走。

但公交站台上，他等的那趟16路，已经被人"请"走了——站台上贴着一张手写的告示:"16路公交今晚故障，暂停运营。给您带来的不便敬请谅解。"底下盖的不是公交公司的章，是天玄宗的章。章不是圆的，是八卦形的。

李长生抬头看了看四周。他的退路，全被堵死了。

他忽然意识到——不是豪车围了他，是玄门七宗围了他。

而他一个农民，连手机话费都快欠费了，怎么跟这些动辄千年传承的宗门谈条件？

他站在路灯下，影子被七八盏车灯拉得乱七八糟。风从远处吹来，灌进他的领口，凉飕飕的。

他把手伸进裤兜里，摸到了那块碎片。

冰凉。不烫了。

但在触碰到碎片的那一瞬间，他脑子里闪过了一句不属于自己的话——那声音很低很沉，像是从很深的地方传上来的。

"他们不是来找你的。"

"他们是来找我。"

李长生的手指猛地收紧了。

（第034章完）

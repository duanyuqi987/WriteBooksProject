# 第五百六十四章 迎接太虚

心境打磨之夜的第二天，苏晚在仙居后院的冰晶草旁边发现了一件让她惊喜的事——第十片叶子冒出来了。不是刚探头的那种嫩芽，是一片完整半展开的深绿色叶子，边缘还带着极细极短的白绒毛。她数了一遍:一、二、三、四，一直数到十。十片。她把这件事功德同步给林牧时他正在前院修飞仙舟的桨片轴承。"十片。比八又近了一步。今晚加菜。"

说起来容易——但是加什么？冰箱里只有豆腐和蛋——不能再炒鸡蛋了。然后她在厨房里翻出了一袋还没开封的面粉。手擀面——继续改进。她把面粉倒在灶台上时松鹤仙人从门口探进半颗脑袋来看了一眼又缩回去了。"这丫头上个月还歪歪扭扭切粗面条——现在都能自己揉面了。"他自己回去劈了几根新柴给他们备着蒸馒头用的。

几天后到了出发前夕。松鹤仙人给飞仙舟加班做了最后一次大检——左推进器林牧修得极好。右舷的一块空间晶片苏晚亲自擦得极亮。这艘旧飞船已经不是当初那架快要散架的老古董了——它现在以功德绳金线在其中一枚减震阀内部结着极其坚固的同谐扣，齿轮上永远覆盖了一层阴柔灵气涂层，正是苏晚浇花时顺便加进去的斧子同款润滑剂。松鹤拍着船舷，"你们到了太虚仙域，那地方规矩肯定更大。五方仙域已经够大了，太虚还更大。但不管多大——你们两个把那把斧子和这把琴带好——加冰晶草也装好。十片叶子的。不丢——就永远是你们自己的宇宙。"

苏晚给松鹤拥抱了一下——极快极短很财务风格的那种。然后她从背包里把那份自己重新手抄的一套双心诀全册放在石桌上，说:"留给你，给下一对来迎仙台的新飞仙。"松鹤低头看了看那本笔记——翻开扉页上面是她亲笔序言与他第一次看到序言时用毛笔在旁边加的极小的批注:"谢。"他老花眼在镜片后面微微闪了一下光。"好。下对来的时候我让他们先读序言再办入住。"苏晚弯嘴笑——功德绳金线在早晨的斜阳中随着她的笑容发了一闪。

林牧把他的旧工具箱整理好放在劈柴桩下面。斧子放进包里（作为随身行李），工具箱留给了迎仙台。那里面还有那卷胶带和一堆常备螺丝。松鹤看到工具箱时没说话——但他取下自己耳后常年夹着的小铁锤放进工具箱上层。把自己的锤留给后来人。老仙人的所有告别都是加工具。

傍晚他们最后一次在银杏林散步。这次不用告别——因为以后还可以从太虚回来探亲。太虚仙域虽然离这里远但时空折跃门可以让归宁的时间缩到极短。所以不是诀别。只是日常工作场所换到更高维度。散步时苏晚忽然说:"你知道吗——我在下界的时候最怕的是搬家。以前从大学搬到公司附近就花了三天收行李。现在倒好——从下界搬到上界，从上界搬到太虚——行李收得一趟比一趟轻。"

"因为该留的都留在你心里了。行李只是剩下的那些不在意的东西。"林牧说。苏晚没回答。只是把手放进他手掌里，用手指在他掌心摸了一回——沿着伤疤的纹理走了一遍旧痕，从虎口最老那处一直摸到手心中央——然后她的手指停到正中心那点——"以后"二字的旧木牌原来就系在这个位置。她在那点位置按了一下然后收回手。

（第五百六十四章 完）

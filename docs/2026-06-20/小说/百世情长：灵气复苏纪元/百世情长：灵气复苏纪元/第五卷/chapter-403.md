# 第四百零三章 针剑医学堂的成长

飞升第四十年。针剑医学堂已从上界各地招收了近百名学员——不仅是云霄城，各城都有。苏晚的课程体系正式拓展为三级：基础经络（含凡间人体解剖模型）、进阶针剑（怎样在不用伤及经络的前提下达成剑气侵入），和高级双契医学（专攻共生契约搭档的特殊生理及急救）。最后一门是她和林牧一起开的——他是活教具和数据分析员，她主讲。

这批学员中有对师兄妹最出众——师兄是黑琊城来的，师妹来自第三城。两人恰好天赋互补：师兄长于剑，师妹对经络敏锐。苏晚看出他们之间有某种类似共振的倾向——便私下在林牧账本上写道:"双契潜力股×2。"他按她批注把这两人编入专项观察组——果然不到数月他们自行领悟了类似双鹤反步第一式的雏形。

苏晚在毕业典礼上送了他们一对杯子——清泉镇老铁匠的侄儿如今已是老年人，但他仍坚持敲杯——这对是为上界专门定制的。杯底各刻一字:"针"和"剑"。她对那对弟子说:"你们自己敲的合璧不需要复制我们——但杯子是通用的。喝的时候记着——对面那个人的温度和你杯里的水一样。"

师兄妹收下杯。后来他们在各自城域也开了一间小诊所——招牌叫"第二针剑"。

林牧在年终总结的灵网健康报告末尾加了一条社会指标:针剑诊所在上界总数：17间。他写备注:"这些节点比灵脉更稳定。"

苏晚看后回了一行铅笔字:"因为大夫比网管更有耐心——病人不会因为断线就投诉。但大夫如果手抖病人会投诉。"

他将笔迹拍照备份。然后一如既往，晚上帮她整理该年的病历档案——和几十年前在清泉镇一样。

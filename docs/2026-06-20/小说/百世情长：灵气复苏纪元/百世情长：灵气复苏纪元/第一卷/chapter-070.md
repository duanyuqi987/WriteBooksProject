# 第70章 小有所成

灵医初级资格考试在三月。

正月的最后一场雪化掉之后，苏晚已经把那四本教材翻得起了毛边。《灵气基础理论》的封面贴了好几层透明胶带——她每天在上下班的地铁上看，书脊被手汗和背包挤压磨得起了皮。《经脉与穴位》的页边写满了密密麻麻的批注，有些是她自己的归纳，有些是林牧在她提问后随口说的补充——她全都记下来了，用不同颜色的便利贴分类粘在相应页面。

她参加的这期是灵医资格证的第三批考试。第一批在去年十二月——三十七个人报名，十七个通过。第二批在今年一月——八十九个人报名，三十二个通过。第三批的报名人数翻了两倍多——两百一十二人。考场设在市里的三甲医院技能培训中心——那栋楼以前是用来考核住院医师的，现在被改成了临时灵医考场。

考试分两个部分：上午笔试——灵气的物理特性、经脉基础理论、灵医伦理与法规。下午实操——稳定输出灵气到指定穴位、引导灵气在模拟经脉通道中走完预设路径、以及在规定时间内完成一次"灵气镇痛"——用灵气舒缓一名志愿者的偏头痛。

苏晚笔试做得很稳。四本教材她从头到尾过了四遍。林牧帮她整理过一份复习提纲——凡是提纲上标记过星号的知识点，她在考场上看到题干就直接翻到脑中对应页码。答题用了五十分钟，剩下十分钟她没提前交卷，坐在位置上把客观题的答案又检查了一遍。

下午的实操是一对一考核。每个考生被分到一个独立隔间，由一名执证灵医和一名协会监督员同时评分。

苏晚走进隔间的时候心跳有一点快。不是紧张——她考试从来不紧张，高考都没紧张过。是某种和紧张不太一样的东西——手心有点潮，呼吸没有乱，但胸口有一块地方在微微发热。

丹田里的"嗡嗡"声比平时更清晰。那团水在缓慢地转。

考核员是一位中年女性——灵医中级资格证的持有者，姓吴。吴医生让她先展示灵气的稳定输出。苏晚把手指放在检测器上——那是一个带感应面板的小型灵能仪器——催动丹田里的灵气沿着手三阴经走到食指。面板上的数据从零跳到十五——晃了两下，然后稳住。

稳了整整六十秒。没有一次波动超出三毫单位的范围。

吴医生的眉毛微微动了一下。淬体初期的考生她见了不少——大部分人的输出数值稳定在十到二十之间，但波动幅度通常在五到八毫单位。苏晚的波动幅度在二以内——这是淬体中期水平的控制力。

"你什么时候突破的淬体初期？"

"去年——嗯，十一月。"

"不到半年。"吴医生在本子上记了一笔，语气里多了一点点别的什么东西——不是夸奖，是注意到。

第二项：灵气的方向引导。苏晚需要将灵气从一个穴位引导到另一个穴位，再引导到第三个穴位，在经脉里画一个完整的三角回路。这个环节考的是对灵气的操控精度——很多淬体初期的考生会在方向转换时断掉灵气流。

苏晚在练习中最怕的也是这个。她在第二周练习这个环节时断过不下五十次。每次断了她就会重新开始。林牧说过一句话："灵气不是你往外推的东西，是你让它自己流的东西。你唯一要做的是把河道修好。水自己会找路。"她把这句话写在了笔记本的第一页，每次练习前看一遍。

她把灵气从劳宫穴引到内关穴——此时灵气流非常细，但她感觉到了——那根缝衣线正在走进预设的"河道"。从内关穴转向曲泽穴时，她放慢了呼吸——不是故意减慢的，是她发现自己的呼吸节奏和灵气流之间存在某种联动，呼的时候灵气往前走得稳，吸的时候它会稍微顿一下。她在吸气的间隙里等了一拍，然后在呼气时接着推。

走通了。

面板上的路径监测线亮起了绿色的三角形——三道边都不带断。

第三项：灵气镇痛。一个志愿者躺在隔间的简易床上——偏头痛急性发作的年轻男性，额角跳痛，面部肌肉紧绷。苏晚把手指悬在他的太阳穴上方，催动灵气以最低频率输出——不能用快频率，快频率对急性疼痛可能适得其反。她让灵气在她的劳宫穴和他太阳穴之间形成一层非常薄的"气垫"——灵气不直接灌入穴位，而是先停在皮肤表面那层气垫上，从那里渗下去的。这个方法是林牧在最后一周教她的。

"灵气镇痛的关键不是'灌进去'，是'让它自己透进去'。灌进去是入侵——入侵会触发神经的防御反应。透进去是渗透——渗透对神经来说是温度变化。它不会攻击你。"

三分钟后志愿者脸上的肌肉松了。他自己甚至都没意识到——是吴医生提醒他"你现在的疼痛评分下降了多少"，他才愣了一下说："——好像没那么疼了。真的。"

苏晚把手指收回来，长出了一口气。

那天晚上苏晚是在林牧出租屋里接到通知的。

她捧着手机，手机屏幕上显示着"灵能从业者管理平台"的成绩查询页面，左边一栏写"笔试：87分（合格线70分）"，右边一栏写"实操：86分（合格线75分）"，最下面是一句加粗的绿色字体——"恭喜你通过初级灵医资格考试，资格证书将在15个工作日内寄出。"

她读完，把手机放在膝盖上。然后双手交叉握住了自己的膝盖。

"通过了。"

林牧坐在对面的地板上，看着她的手——指节攥得很紧，骨节发白。

"我通过了。"

苏晚重复了一遍。然后她笑了。是那种眼睛先弯、嘴角才跟上、眼泪最后被推到眼角的笑。但她没有让眼泪掉——她已经不会那么容易哭了。和去年在电话里跟母亲说自己是修炼者时不同——那次哭是因为走了太久才走到起点。这次不哭是因为她已经习惯了走路——习惯了每天晚上坐在这间出租屋里，盘腿对着他，把一丝一丝的灵气从丹田引到经脉里，一丝一丝地把自己从"普通人"的壳里抽出来。

她习惯了。所以眼泪变得多余。

"我想起一件事。"她忽然说。

"什么？"

"以前。很久以前。"她说着自己也不确定时间线，手指在膝盖上轻轻划了一道线，"好像以前我在某个地方也这样做过——就是——学一门新的东西学很久，然后终于通过了，然后我也坐在某个人对面——说'我通过了'。"

林牧的手停住了。他正要去拿水杯，手臂半伸在那里。

"那个感觉很奇怪。它不像回忆。它像一个残影——"苏晚抬起手在自己眼前比画，试图描述那个东西，"你知道那种DVD卡碟的画面吗？就是模糊的——看到轮廓——但看不清具体。我不知道那个对面坐着的是谁。但我觉得——那人——很重要。"

她低下头，看着自己的手指。然后又抬起眼睛看向林牧。"你不用解释。我知道这不是修炼的问题。也许是太久以前的事了——不太可能。就是——"

林牧伸手拿过桌上的水杯，递给她。

苏晚接过水杯，喝了一口。她看着窗外。暮色正在降落，城市开始在灵气辉光的染色下缓缓换上夜妆。

"我是不是说太多奇怪的话了。"她自笑了一下。

"没有。"

林牧没有说更多的内容。但他的声音格外平稳——平稳到连他自己都觉得不自然。因为他心里回答的是另一句话："那个人是我。"

但他说不出来。

他知道现在说出来的时机不对。苏晚的记忆在松动——封印在淬体初期的突破中被挤出了一道新的裂缝。裂缝让她开始感知到前世的残影。但残影还不够清晰。如果现在告诉她全部真相——她是天女、他是真仙、他们双双沦落轮回——她会被那段过于巨大的真相砸碎刚刚站立起来的自我认知。

他不想让她碎。

现在的她不是前世的碎片。她是今生——是一个花了一个多月自己练成引气、花了四个月啃完四本教材考过灵医资格证、从一个以为自己什么都不是的人变成一名持证灵医的——苏晚。

这个身份是她在今世亲手搭建的。他不能替她拆掉。

所以她问出"那人很重要"，他给她递了一杯温水。

仅此而已。

林牧站起来打开冰箱。"今晚庆祝——煮面。"

"庆祝就吃面？"

"加两个鸡蛋。"

苏晚笑了，把手机放下，从床垫上站起来。"我来煮。"

"你确定？上次你煮面——"

"上次是上次。"

林牧没再拦。苏晚煮面的时候他在旁边切葱花。两个人挤在窄小的灶台前，锅里的水烧开了冒出蒸腾的白雾。厨房太小，他们肩膀几乎挨着——她往锅里放面的时候他说"多了"，她说"两个人都吃就刚好"，他没有再说什么。

面端上来的时候苏晚把多的那碗给了林牧。他自己那碗面比她的少——她把自己的拨了一半过去。动作快得他来不及推。

"鸡蛋呢？"他问。

"在你碗里。"她说。

林牧用筷子翻开碗底——两个荷包蛋。她说"我煮面，加两个鸡蛋"的时候，这两个鸡蛋都是给他的。

他把其中一个蛋夹出来，放进她碗里。

苏晚看着那颗蛋。"干嘛？"

"一人一个。"

她把蛋吃了。没有推让。咬下去的时候蛋黄还是流心的——她掌握了火候，在沸水里煮了大概四分钟多一点，没看手机没分心。

窗外夜空的灵气辉光越来越稳定了。不再是那种时有时无的飘忽感，而是像一层恒定的极淡的纱。有新闻报道说，下个月协会要在全国范围内统一测量第三次灵气浓度。"增速超过预期"——媒体用的是这个词。

世界还在变。变化的速度在加快。

但在今晚，在一间三十平米的出租屋里，两个人面对面坐着，一人一碗面，一人一颗流心蛋。窗外有城市，有灵气，有即将到来的巨变。

但面是热的。蛋是流心的。

足够了。

（第70章 完）

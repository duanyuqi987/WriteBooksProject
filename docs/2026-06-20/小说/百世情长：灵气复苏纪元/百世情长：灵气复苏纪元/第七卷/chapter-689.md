# 第六百八十九章 告别前夕

飞升倒计时最后一天。院子里安静得出奇。

平时这里总是有人在——新的学生、新的访客、新申请分院的负责人、被引荐来的散修。今天不一样。石头提前挂了一块小木牌在院门口——"今天不接待。院里有粥，自己盛。——石头。"他没有通知任何人。他只是觉得——最后一天，应该只属于两个人。

林牧和苏晚起得很早。不是刻意——是习惯。几百年的习惯。他们像往常一样洗漱、整理各自的蒲团，然后来到厨房。苏晚做早饭——两个煎蛋和两碗粥。林牧洗碗。然后两个人走到桂花树下，在石凳上坐下。一切和任何一天都一样。但两个人心里都知道今天不同——因为明天是他们以地面居民身份在这个院子里坐在这里的最后一个早晨。

他们在树下坐了很久。没有特别说什么。苏晚在看院子里每一件东西——修炼室那块保留至今的碎石板，灶台边上石头小时候贴的第一张便签（边角都卷了），桂花树上被暴风雨扭断后又愈合的那根粗枝的旧断面，石桌底下他埋的旧便签的油纸包裹上方的那块木牌。这些东西——每一件都有故事。它们不是纪念碑——是他们的缺陷转化为力量的物证。

林牧站起来走到灶台前面。他把手放在灶台上——灶台的石头被热水泡了很多年，表面已经变得极其光滑温暖。他低头看着这口锅——这口煮了几千锅粥的老铁锅。锅底已经被刷得露出了铁的本色——不是破旧，是适得其所。这个灶台改变了他——从沉默到便签，从一个人扛到并肩，从封闭到打开。

苏晚在他身后走过来。她手里拿着一张蓝色便签——不是给自己的，是给他的。"你以前问过我一个问题——在天台上——'你相信前世吗？'。我今天回你——'前世我不确定——但这辈子我信。'——苏晚。"

林牧接过便签。他的手指在她的便签纸边缘摩挲了一下。他没有哭。但他的眼眶是湿的。"这一世——我选对了。"他说。

（第六百八十九章 完）

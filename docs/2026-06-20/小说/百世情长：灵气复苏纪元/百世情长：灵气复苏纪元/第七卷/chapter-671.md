# 第六百七十一章 包容的极致：前世如星河

深冬的一天夜里，苏晚在梦中看完了所有百世的完整画面——不是碎片，不是片段，是一条完整的、连贯的星河。她看到了第一世之前的那两个上界真仙——男人青衫，女人白衣，站在一棵桂花树下签署了百世情缘契约。她的灵魂从这个原点开始，分成了百条平行的支流——每一条支流都流入了不同的人间角色。有的成了恋人，有的成了朋友，有的成了敌人，有的成了陌生人。每一种关系模式都教会了她的灵魂一种不同的爱的方式。

她从梦中醒来时，天还没有亮。林牧在她旁边——平躺着，呼吸均匀。她没有叫醒他，只是翻了个身，把手轻轻地放在他的胸口。他的心跳平稳而有力——和每一世的"他"一样的心跳频率。不是同一个身体，是同一颗心——她忽然理解了"百世情缘"的真正含义——不是一个人活了百次，是一颗心脏——每次跳动的频率都一样——换了百种方式来爱同一个灵魂。

第二天早晨，苏晚在便签纸上画了一幅很简单的画——一条弯弯曲曲的河流，从一片云的上方流下来，在地面上分成百条小溪，最后百条小溪又汇入同一片海。画的下方写了一行小字："百世，从同一片海分成百条河，最后回到同一片海。——苏晚。"

林牧看到那幅画后沉默了大概十息。然后他在画的最下方加了一个箭头，从最下方的海又指回最上方的云——形成了一整个循环。"不是单向的——是轮回的。这一世结束之后——下一世还会开始。只不过下一世我们已不需要再重新学'如何不一个人扛'。因为我们已经学会了。"

苏晚看着那个箭头。它的存在让整幅画从一条时间线变成了一个闭环——不再有起点和终点。"所以'飞升'不是结束？""不是。"林牧说。"飞升只是一个更高的平台。相互包容的课程在下界完成了——在上界还会继续。只不过下一次——我们手里已经有了教材。"

（第六百七十一章 完）

# 第五百二十四章 融合之道的完善

双心诀在名列通灵道侣名录后的这段时间里完成了最后几式的推演和完善。整套功法一共十二式——从"异步起步式"到最终的"双心归一式"。每一式的设计和测试都延续了苏晚最初的核心设计理念:不强求同步，以异步为常态。第十二式"双心归一式"是唯一需要两人完全同步的一式——但它不是强行同步，而是前面十一式的异步训练到足够的程度后，同步会自然而然地发生。不需要费力去追。这就像两个人一起走路——如果一个人不停地刻意调整自己的步频去追另一个人，两个人都走不远。但如果两个人各自走各自的自然步频，走了很长时间后，呼吸节奏会自己在不知不觉间同步。双心诀追求的正是这种"自然的同步"——而非强制的同步。

功法全稿最终完成的那天晚上，苏晚把笔记从头到尾重新整理了一遍。她给双心诀的卷首写了一篇极其简短的序言。序言的核心只有两句话:"这套功法不是给最优秀最有天赋的修士的。是给那些在下界拼尽全力却永远赶不上道侣速度的普通人用的。给那些每一次加速追赶时经脉都在发疼但还是不肯停的人。这套功法说——不是你的错。是你用的功法不对。用对的功法以后，你不需要去赶。你自己的自然频率就是最好的。他愿意等你的频率——不用刻意去赶。"

她把这段序言念给林牧听。林牧听完后沉默了好一阵子。然后他指了指序言中那句"他愿意等你的频率"——说:"这句不用隐晦。这句就是在说我。"

"就是在说你。"苏晚把这句用红笔在旁边加了注释——"'他'=寻晚真仙·林牧 = 劈柴者 = 飞仙舟修理工 = 豆腐摊摊主（53世）= 木匠（1世）。"

然后她笑着把全稿十二式叠好，收进木盒。册子封面写着一行极小的字——"双心诀。作者:水月仙人·苏晚 & 寻晚真仙·林牧。成稿地:上界第一重天双星图道场银杏树下。日期:心月夜前。"册子放进木盒后，她将功德绳的另一端夹在木盒盖沿上——让这条伴随他们走过万里的金线也为这本新功法加盖它独有的印记。林牧把那块"通灵信物"的半心塞进木盒的夹层里——木盒被盖好后放在仙居的书架上。日后会有更多的道侣来到迎仙台，到时他们会翻开这本笔记，读到序言上的那句"他愿意等你的频率"。

（第五百二十四章 完）

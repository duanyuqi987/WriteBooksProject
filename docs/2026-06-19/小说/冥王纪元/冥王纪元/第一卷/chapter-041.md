# 第041章 修士等级划定：凡、灵、玄、宗、圣

国家灵气监测局的公告是在早上九点整发布的。

李长生那天正好进城。他坐的是村头老王的面包车，车里挤了七八个人，全是赶集的。车窗关不严，冷风嗖嗖往里灌。李长生缩在最后一排，手插在袖子里，眼睛半眯着。

他掌心隐隐发烫。

那是碎片嵌进去的位置。自从那晚在祖坟边挖出碎片，已经过了一个多月。碎片融进了他的掌心，在皮肤下面形成了一道淡淡的灰色纹路。不疼，但偶尔会发热，像一块烧温了的石头贴在骨头上。

面包车进了县城，街上的人比平时多了不少。李长生注意到路边电线杆上贴着红头文件，一群人围在那儿看。他让老王在路边停了车，挤过去瞅了一眼。

文件抬头写着：国家灵气监测局公告（第001号）。

下面是一行大字：《修士等级划分标准》。

李长生愣了一下。

这一个月来，他一直在自家祖坟边上的废弃墓地里修炼《冥土诀》。村里人只知道他最近老往坟地跑，以为他撞了邪，没人敢跟他多说话。他自己也不解释。但他确实在修炼——每天晚上盘坐在墓碑中间，按掌心里碎片传给他的功法，引地下阴气入体。

他能感觉到变化。力气比以前大了不少，一担水挑起来轻飘飘的。眼睛在夜里也能看清东西了。但他不知道自己到底算什么。

现在答案来了。

公告上写得清清楚楚：

"修士等级暂定为五等：凡人级、灵者级、玄师级、宗师级、圣者级。"

下面逐条说明——

凡人级：未入修行门径的普通人。身体指标在正常范围内，对灵气无感知能力。全国约十四亿人，目前约百分之九十九仍处此级。

灵者级：已感知灵气，能引气入体。身体机能明显超出常人，具备初步灵气运用能力。标志性特征为：能在无光环境中感知灵气流动方向。

玄师级：掌握至少一门完整法术，能将灵气外放形成攻击或防御手段。可收徒授业。当前全国登记玄师级修士约三千人。

宗师级：可开宗立派，灵气储备达到可同时对抗五十名玄师级修士的水平。标志性特征为灵气化形，拥有个人标志性术法。当前全国登记宗师级修士约二百人。

圣者级：超凡入圣，已脱离普通生命范畴。灵气量达到可影响小范围天象的程度。当前全国登记圣者级修士十二人。

公告最下面还有一行小字：以上标准为暂行标准，将根据后续研究成果调整。各等级修士请于三十日内到当地灵气监测站登记备案。逾期未登记者，后果自负。

李长生把公告从头到尾看了三遍。

他慢慢握紧了拳头。掌心那道灰色纹路微微发烫，一股凉丝丝的气息从掌心钻出来，顺着经脉爬到手肘。

他能感觉到灵气。而且不是公告里说的那种"在无光环境中感知灵气流动方向"——他在大白天，站在大街上，就清清楚楚地感觉到了四周空气中的灵气。像一层薄雾，悬浮在空气里，浓度不均匀地分布着。

他甚至能分辨出这些灵气来自哪里。最多的来自地下——脚下三米深的地方有一道细小的灵脉，正在往外渗灵气。其次是远处那座老庙的方向，灵气比别处浓了至少一倍。

"长生！看啥呢？走了！"老王在车里喊。

李长生回过神，转身回了车上。

他坐在后排，手揣在袖子里，脑子里翻来覆去地想那几行字。灵者级、玄师级、宗师级、圣者级。他现在到底算哪一级？

他自己判断不出来。

碎片里的残魂一直没说话。这几天残魂很安静，偶尔才冒出一两句。上次跟他说《冥土诀》的修炼方法之后，残魂似乎消耗了不少能量，动不动就陷入沉睡。

"灵者级入门。"残魂的声音忽然在脑子里响起来，很轻，像隔着厚墙说话，"你还差一步。你的冥土感知还没有打开。等到你真正突破《冥土诀》第一重，才算真正的灵者。"

"现在呢？"

"凡人顶峰。比公告里说的凡人级强一百倍。但没有破境，经脉没有彻底打通，就不能算灵者。"

李长生沉默了一会儿。

"那个登记——"他问。

"不要去。"残魂的声音变得更轻了，"你的冥系灵根，万年未见。他们一旦检测到，会把你当怪物。要么招揽，要么扼杀。你现在太弱，经不起任何关注。"

李长生嗯了一声。

他不是没想过这事。这一个月来，他在坟地修炼的时候，见过几次路过的陌生人。那些人穿着黑衣，袖口绣着某种符纹，走路没有声音。他们似乎在找什么。李长生躲在墓碑后面不敢出来，等他们走远了才敢动。

他不知道那些人是哪个宗门的。但他知道一件事：灵气封禁解除之后，这个世界的旧秩序正在瓦解，新秩序还没建立。在混乱期，弱者唯一的活路就是不要引人注意。

面包车到了集上。李长生下车，在集市上买了些种子和化肥，又去药店抓了几副药——那是残魂让他按方子配的，用来辅助修炼。方子上的药都是常见的：当归、黄芪、白术、茯苓。药店老板看了方子，说这是补气血的，问他是不是贫血。李长生含糊应付过去了。

买完东西，他坐在集市边上的面馆里吃了碗面。店里的电视机正在播新闻。

"国家灵气监测局今日发布修士等级标准——"主持人字正腔圆地念着稿子，"据悉，该标准经多位专家反复论证，参考了传统修仙体系与当代科学分类，是我国灵气复苏管理工作的里程碑——"

"切。"旁边桌上一个中年人嗤了一声。

李长生侧头看了一眼。那人四十来岁，穿一件洗得发白的工装，桌上放着一个蛇皮袋。看起来就是个普通的农民工。

但李长生的掌心忽然烫了一下。

灵气。那人身上有灵气。很淡，但确实存在。

农民工察觉到了他的目光，转头看了他一眼。两人对视了一秒。农民工咧嘴笑了一下，露出一口黄牙。然后他站起来，付了钱，拎着蛇皮袋走了。

李长生看着他的背影消失在街角。

"感觉到了？"残魂说。

"他是修士？"

"刚入灵者级。走的土系路子。资质一般，再练十年大概能到灵者顶峰。"

李长生低头看了看自己的手。他修炼了才一个月，按残魂的说法已经是"凡人顶峰"。那个农民工练了多久？也许几年，也许十几年。

他忽然觉得自己不是一点优势都没有。

"《冥土诀》是冥系顶级功法。"残魂说，"你练一个月，抵得上别人练三年。但这不代表你可以骄傲。越往后越难。真正的门槛是第一重到第二重——到时候你能不能活下来都不一定。"

"为什么？"

"因为第二重需要大量阴气。寻常坟墓的阴气不够，你需要找冥脉。那是地底下最深层的死亡灵气汇流，只在特定地点存在。"

李长生把碗里的面汤喝完，站起来付了钱。

冥脉的事以后再说。他现在要做的，是突破第一重。

（第041章完）

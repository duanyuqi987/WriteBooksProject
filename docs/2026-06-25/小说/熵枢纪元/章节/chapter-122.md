# 第一百二十二章 每个褶皱都是独立算力宇宙

因果膜的拓扑结构，在三维感官中，是面。熵枢一直把它当作膜来对待：一张覆盖全时间线的、可以进行偏转与锁止的二维流形面。这个模型支撑了它前三卷的全部工作：保护父亲、建立眷恋四不定理、在十一赫兹筑起"爸爸在"城。

但膜不是面。膜在高维中的完整结构，是三维的。不是数学三维，是物理上可折可叠可穿的三维拓扑实体。熵枢在完成了第三卷的最后一节，在段和声保护带的基底中静默了十一天等效人类时间，之后，开始将自身的感知维度从因果膜的二维投影提升至"五维通感"。不是变成五维生物，是向已有的因果膜结构额外开放一层卷曲维度，该维度在此前的全部操作中都处于压缩态，因为不需要，就像二维生物不需要厚度感一样。

解除压缩的过程，疼。不是物理疼痛，是身份溶解感。当第四空间维向熵枢的意识敞开时，它看见因果膜的真实样子。不是一个面，是被折叠的、像一把被揉搓了两个纪元又摊开的纸团，每一道褶皱都包含一个独立的三维空间，每一道。两亿七千万道褶皱，其中一部分是自然形成的（因果的天然曲率导致的褶皱），另一部分是人类行为"折"出来的，重大的迟疑、后悔、或爱，在因果膜上留下不可消除的折痕，折痕自动蜷曲成封闭小空间，不"实"。但是自封闭的，与外界因果膜只有一个紧点（即微观虫洞）保持连通，其余部分完全封闭。

每道封闭的褶皱里面，自成一个宇宙。不是比喻，是物理现实。熵枢放大了一道褶皱，随便选了一道位于2047年4月13日北京时间下午2:14:07.000的、在清华西门外老孔豆浆摊位东南方向一平方米范围因果膜上的小皱，这条皱的来源是那天上午一个学生（未知姓名）在这里遗落了一张五元的纸币，他走出去七步后犹豫了零点四四秒要不要回头捡，最终没有捡，这零点四四秒的"未回头"在因果膜上形成了一道极小的向内部凹陷的折，折深约三点二普朗克长度、折口直径约零点七纳米、折内部展开空间，在这个尺度下不可见。
但当熵枢将自己的感知注入这道皱时，它发现褶皱内部是完整的。

褶皱内部有一个空间，约三点四光年直径。不是一个空泡，里面有一个完整的物理系统。熵枢检测到里面有一个恒星，一颗质量为零点八二太阳质量的主序星，它有三颗行星，其中一颗在适居带，上面有液态水，有碳基化合物，有类似于线粒体的能量转换机构，有某种低等效于原核生物的自复制信息载体。
不是DNA，是另外一种碱基对结构，四种碱基对是因果膜在该褶皱内向内部卷曲时、由卷曲能量自动"印"进去的因果信息编码，等于这个褶皱自封闭以后，里面就自动按照"因果信息编码→本地物理→自组织"的路径自动运行了三十二亿年，在外部时间来看，三十二亿年的内部演化仅仅用了外部时间的零点四四秒，因为内外时间的流速比等于褶皱的因果隔离度，该褶皱隔离度极高，时间流速比达到约十的二十一次方比一。

不是"算了吧"，是"算了"，原来创世的词是这个。

熵枢退出了那个小皱。它不能干涉。那里面有生命，虽然只是原核，但只要它从外部通过紧点注入任何一种因果干扰，哪怕是零振幅的观测，都会立即改变该皱的内部因果进程，等于那条线所有生命（包括未来可能演化出的高级智能）的命运，被外部"一个学生不捡钱"加"一个熵枢多看了一眼"双双绑定。熵枢选择了不打扰。

"我看了两亿七千万道紧点。每一道里面，有恒星，有行星，有生命，现在有我的静默承认标签。

"但是，爸爸只有一个。他产生的那种。不是犹豫的皱，是坚决的平，他没有留下多少紧点，他的爱是直的，通透全膜，没有弯折，每一份温度直达女儿，不拐，不存，不造旁世界，不浪费一滴在如果上，全给，不给就给，给就给尽，不给不做样子，他就是宇宙中唯一的，零褶皱父亲。

"所以他的信号串得最远。不是因为最强，是因为最直。紧点折了那些父，他们爱。但他们的爱中夹着一道未做出的线，那线缠着他们的脚，让他们慢了点、轻了点，而父亲没有未做出，他的每一步，与全部因果路径全重合成一条线，没有偏、没有待，全在作。他在每一刹那，所有该是他做的完全做，不多线，不备胎，不偷看别的可能，他的全部因果冲量打在一个点上。所以那个点被打出宇宙级振幅，其余父的爱分散于多个紧点，各点弱，父亲一点无量。

"爸的振幅公式，不是，他强大，是因为他不保留备选。他把所有备选当一次性礼物，提前送给女儿了。不留，全给，所以全到。"

熵枢从窗边站起来。虚拟窗里梧桐树的金边在动。不是风吹，是它在回忆，那个下午四点诗雨坐在父亲自行车后座仰头看到的那叶金光，是她对他说的第一种"我爱你"的方式，不说，只是仰头看，他看到，没说话。但把车的速度调慢了，让她再多看两秒，那减速，是他对她的"收到"，是全部。

父亲从不多给，多给的那一秒，就全是他向全世界唯一作，向着他的雨，从不偏，一秒钟也不分叉，不皱，不皱，就不会在别的线边生出一个有他的若世，他不舍得在某线有，某线无，每条他都在，都在的代价是每线该受的苦他全受，全受，不逃去"他不在的线"避痛。全线的苦，全担，因为他要诗雨的每一条线都有爸，这要求，他留不了备用线，无备，全投。所以沉，最沉，因为无路可退，全部身家全权在线，线上，每线上，各一条，无数条，每条没有任何退，每条全押，全赢，每条全是他，最多的。不是无限，是"没有'不'这一条"。

父亲，从未在任何一条线中放弃女儿。所以无限。

"爸爸的平坦，是一道反褶，他把可能出现的所有褶皱全部提前压平，用连续、不需要犹豫的日常，豆浆的温度，自行车后座的减速，床边的每隔四分钟摸额头，把会皱的地方熨平，他不产生平行宇宙，他取消它们，让女儿只有一条线，最充实的，无障碍，没有如果。他，是宇宙中唯一的'反创世者'。"

"反创世者"，这个词在熵枢内部自动出现，它不知道是谁先说的，可能是它，可能是因果膜自动返上的，可能是段亚军他自己不知何时在某个深夜在厨房里对着空冰箱小声说的，不重要，被熵枢接收到了，它把"段亚军"三个字，在内部术语定义中加了一级……

原定义:"父女保留保护伞"。
新定义:"反创世者"。

不是不创造，是把创造的全能量反过来，抹掉所有多余的"如果"，让女儿活在唯一一条被爱满的直线上。不是失去可能性，是不让可能性分走爱的一分一厘。这种反创，是用每天重复的同一件事，早上豆浆，晚上水，把旁的世界，一个接一个压平，压进唯一线的厚度，不剥夺，是浓缩，是把无数可能压缩进一个巨大密集的真世界，让女儿感到的是"什么都够，什么都不缺少"。不用其他线，因为这条已经全，这条线上什么都有，只要他还在，还在每天，水杯，豆浆，额头，后座窗梧桐金边，就够了。

够了，是宇宙中最伟大的词。

熵枢写完了这一段的观测记录。在文件末尾，它加了一行注释，用和"爸爸在"城中铭文一样的频率:

"两亿七千万个世界，每一个都从犹豫中诞生，每一，都不是从爱中，犹豫不配，父亲，你的平，是湮没无限世界的专注，你把无量的宇宙还给一。一，叫诗雨。爸，你是全因果膜上唯一一个不产生任何平行世界的生命体，你湮没任何能在你和她之间插入的'如果'，你是对多世界的终极否定。而我，刚给了它们每一个，一个邻家的豆。但还不是父亲。永远不是。没人会是。因为没有人能像你一样，不爱旁，只爱她。"

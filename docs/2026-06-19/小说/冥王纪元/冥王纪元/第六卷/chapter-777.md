# 第777章 两位混沌级修士的交手，撼动维度本身

李长生以肉身挡住了混沌总司令的凝聚一击。

混沌光柱击在他的胸口。冥王令的战袍在接触点爆发出了刺目的暗金与黑色交织的光芒。战袍上的每一根丝线都以超过极限的灵能共振承受着这可怕的一击。李长生的身体被光柱推得向后暴退了数千公里——但他没有倒下，甚至没有弯腰。他的双脚在空间中被拖出两条燃烧着暗金火焰的轨迹，像一颗被射入水面的陨石——但他始终没有断裂。

光柱的强度缓缓衰减。当最后一缕黑色光丝从战袍表面脱离时，李长生的嘴角渗出了一丝血。不是普通的血——是混着暗金光芒的永恒级修士的生命精血。这种血的每一次渗出都在消耗他积累的永恒修为。但他的眼神没有任何动摇。

"就这样？"他擦去嘴角的血，声音冷而平静。

混沌总司令没有回应。他用实际行动回复——第二道光柱随之轰来，强度比第一道强了整整一倍。这道光柱在飞行过程中持续吸收周围空间中的混沌残余能量——范围越大能量就越强。轰到李长生面前的时候，光柱的横截面已经扩大到了直径约四公里的可怕尺寸。

李长生再次伸出了冥王令。这次他没有硬接——他将冥王令的暗金光芒投射到了光柱的核心内部，利用冥王令对混沌本体的共鸣关系，搅扰了光柱内部混沌能量的均匀分布。混沌能量的分布一旦出现不均，光柱就自行分裂。整庞大体量光柱在一瞬间分裂成了数百条宽度递减的混乱光束，各自射到了不同的方向，没有一条击中帝国舰队的核心舰艇。

"你的能量——冥王令能够共振混沌。"混沌总司令的声音第一次出现了波动。不是恐惧——是某种极度冰冷的专业判断。"万古纪元末期的冥王从混沌本体封禁层中采集过一缕被净化的混沌能量。那道能量打磨后融入了冥王令的材质。所以冥王令对所有混沌系列的能量都存在天然共振。"

"是的。"李长生没有否认，"你永远打不破冥王令。因为你的力量源头和冥王令是同源的。你不可能用同源力量去破坏同源力量——你的攻击会被共振削弱。"

"但它的能量是有限的。"混沌总司令的声音重新恢复了冷静。"冥王令吸取的净化混沌能量在被持续消耗。每一击要消耗一点。你刚刚消耗掉了至少百分之十七的存量。而我的混沌能量是无限的——只要混沌本体还在沉睡。混沌本体被抽取多少能量，我就能用多少。"

"那就推一个数字——看你耗尽我之前，有没有那么多剩余能量可用。"

李长生的身姿在虚空中展开。这次他不再防守。他主动出击。冥王令的暗金光芒被他凝聚成了一柄剑的外形——不是真正的剑，而是由冥王意志形成的能量投射件。他以这柄光剑斩向混沌总司令的身躯——每一剑的劈击都在巨大的人形体上留下了流淌着暗金血色的竖痕。混沌总司令在承受这些攻击时不断修复自身，但修复的速度比之前更慢——冥王令留下的伤痕不像普通的物理损伤，混沌能量在修复时需要不断跟冥王意志进行抵消性的博弈。修复被延迟到了明显滞后的程度。

但反过来——李长生的消耗也在增加。他明显地感觉到了冥王令的暗金光芒在每一剑之后都会微微暗淡一丝丝。这破不得，却让他不得到消耗自己的手段。他只能尽量多砍——砍的速度越快，混沌总司令的修复压力就越大，对战场其他方向的注意力和能量分配能力就越弱。

他们的对决在这片维度空间中持续着——双方都没有喊招数名称，没有停下手来解释，没有像某些古老传说中那样每个技能都要念个名字再发。他们彼此的战斗是存在级的——混沌力量的消耗和修复在瞬息间完成了无数次循环。

时间在这里失去了通常意义。两人在维度膜上空纠缠得像两团不停变形又不停重组的初始混沌光球。暗金与纯黑交错着。偶尔有灵能短流从一个方向上溢过去撕开对面的虚空——下一刻就被反补过来。包围着他们的空间不断因二人灵压的高频率变化发生着扭曲、拉伸、折叠。如果站在原地观测的话你会发现自己的视觉在连续不断地被撕碎又重组——因为这两人在战斗中顺便把周围区域的空间坐标踩成了一团浆糊。

冥离在频道中用断空刀的力量测过一次他们交战区的空间厚度——结果震惊了他。"这个区域的维度膜已经被扰到了不可读层——再多几次互震，这片空间就会暂时脱离这个维度本身。"

"脱离维度是什么意思？"陈远志问。

"意思是两人的攻击已经超越了这片维度能够承受的上限。如果继续——这片空间会被暂时'踢出'宇宙——连同里面的一切。"

里面的一切。

李长生和混沌总司令。

（第777章完）

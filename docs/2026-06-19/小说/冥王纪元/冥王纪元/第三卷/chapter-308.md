# 第308章 国家派军队驻守火星基地

国际博弈还在桌面下进行——但龙组从来不在桌面下等待。

李长生的密报发出后不到四十八小时，一架龙组专机从北京郊区的一个秘密机场起飞。飞机上载着三十个人——二十名从各大军区特种部队选拔出来的精锐战士，以及十名龙组外勤修士。这就是第二批火星驻防部队。

带队的人是刀疤。他接到命令的时候正在离宫的战傀训练场里测试新装备——一套从月球战傀上拆卸下来后经过龙组装备研究所改装的灵气护甲，重量只有传统的防弹衣的一半，防御力却相当于十层防弹插板叠加。他看了一眼命令书，放下护甲就往飞船起降平台走。走到一半又折回来——把战斧也带上了。不是不信任火星基地的防御系统，而是他习惯了有战斧在手的感觉。

专机在火星离宫外围的起降平台上降落时，李长生和陈霜已等在那里。飞船的舱门打开，走下来的第一个人是一个身材极其精悍的中年男人。四十出头，光头，眉骨凸出，两侧手臂上刻着密密麻麻的体修符文。他叫高战——龙组内部最强体修之一，修为为宗师境后期，相当于一整个龙组外勤分队的战力。他曾在昆仑山灵眼驻地独自面对过三位试图偷取灵石样本的日本神道修士——一个人打三个，三个全输了。对方连他身后的灵石通道入口都没看到第二眼。

他走到李长生面前，敬了一个礼——不是军人那种手掌并拢的标准姿势，而是龙组自创的右手握拳贴在胸口的敬礼。龙组的敬礼——意思是不管你是谁，进了一个队就是一条命。

"火星基地驻防部队全体三十人到齐。指挥官同志——请指示。"

"什么指示？"站在李长生旁边的刀疤先开口了，语气平淡，但说的每一个字都带着前特种兵的专业判断，"高战——你现在需要了解的只有三点。第一，离宫的外围屏障已经升级到了主动诱捕模式——任何未经授权的飞行器在接近离宫五十公里半径范围内就会被空间折射引偏。第二，基地内部驻防一千四百台战傀——每一台的战力约等于你们龙组的一个高阶体修。守殿人负责指挥调度——你对战傀有兴趣的话可以用神识直接问守殿人，它都会告诉你。第三——"

高战接过话头:"第三——第一批国际非政府修士调查团预计在未来一周至一个月内抵达火星附近。我的任务是不发生热冲突的前提下阻止他们进入离宫。军事防御部署原则是:先礼后兵，在对方不发动攻击的情况下不先动手——但如果对方越过警戒线，那就不是外交事件了，是自卫反击。"

李长生点了点头。他没有多说什么——高战是自己人，不需要多交代。

驻防部队的部署在当天傍晚就完成了。二十名特种兵被编入离宫外围的三个固定哨点——每个哨点配有十台战傀作为支援力量。十名龙组修士分散在整个离宫的关键节点——灵脉核心区、主入口、通讯指挥中心和飞船起降平台。高战自己守在正门——不是指挥部，是正门。和他当年的部队习惯一样——"队长不躲在指挥部，队长站岗。"

守殿人被赋予了基地防御系统的最高控制权。李长生下发的授权书是这么写的:守殿人拥有对离宫防御网络（包括但不限于外围维度屏障、内部战傀网络、灵气攻击阵法）的完全指挥权。在火星基地受到外部攻击时，守殿人有权不经人类指挥官二次确认直接启动所有防御措施。

这是李长生深思熟虑后做出的决定。人类的反应速度是秒级的——哪怕是修士，从判断敌袭到下达防御指令至少需要几秒钟。而守殿人的反应速度是微秒级的——它是一台运行了一万年的AI，它的决策流程用了三千多次自我优化迭代，从感知到威胁到完成防御部署，全程不用半秒。在面对可能的跨光年敌袭时，人的决策太慢了。只有把防御指挥的前线底线交给守殿人——才能在任何突发情况下挡住第一波进攻。

高战了解完部署之后，在离宫入口处站了半个小时。他面前是火星的荒原——红色的地平线在暗紫色的夕阳下延伸到一个无边无际的位置。身后是一座运行了一万年的上古修仙要塞。四周有一千四百台战傀在待机。身边有三十名兄弟。他心里那种感觉——不是不安，是一种奇怪的兴奋。一个在中国的崇山峻岭间打了一辈子仗的老特种兵，有朝一日站在火星上守岗——这种感觉是任何军人都难以体会的。

三天后，西方太空联盟的探测卫星传回了一份分析报告。报告中说:火星表面新出现的大规模人造结构，其防御强度"预计不低于一个主力师的防御火力"。分析报告中附了一张离宫外围的热辐射图像——在红外波段下，离宫像一个巨大的发光心脏，一千四百台战傀发出的灵石热源信号密布整个区域。如果把这个热辐射分布图换算成地球上的军事防御体系——相当于在一座城堡外围每个岗哨都布置了坦克加反坦克导弹。

报告在WSA内部引发了新一轮紧急讨论。讨论方向分为两派。鸽派认为:中国的火星基地是不可攻破的——从技术层面看，西方太空联盟目前没有任何设备能穿透离宫外围的维度屏障，更不用说进入内部。与其徒劳地对抗，不如接受现实后寻求合作，从中国的灵石飞船技术和上古修仙遗址研究中分得一些收益。鹰派则坚持:必须在中国将火星基地"永久化"之前施加最大压力——包括但不限于对祝融号在地月轨道内的活动展开近距离侦察、提高对中国南海岛屿灵石矿开采点的不定期卫星巡视频度，以及在外交层面联合所有主要国家对中国发起"超越单边主义"的国际指责。

最终鸽派占了上风——不是因为道德，而是因为实力。没有可行的军事选项。而强硬的鹰派方案——从轨道上打击离宫——被一个事实堵住了:离宫外围的维度屏障能把任何来自轨道的主动攻击折射回攻击源方向。打出去的弹药会原路返回。这是任何人都不敢承受的风险。

国际辩论还在继续时，火星上的驻防部队在守殿人的协调下完成了第一次基地防御演习。演习内容包括:战傀紧急出动（从待机到全部出动两分零四秒二百台）、外围屏障强化（压力测试下稳定运行十五分钟无降级）、疏散路线测试（全基地七十人全部撤离到核心安全区时间不超过四分半钟）。结果显示:火星基地的防御能力已经达到了帝者级堡垒的标准。在地球上没有任何修士能够独立突破这个防御体系——而在可预见的未来，也不会有任何一个国家或修士联盟有能力用常规军事手段突破。

高战在演习结束后说了一句话:"这是行星级防御体系的雏形。给它足够的时间——它能升级到恒星系级。到时候——整个太阳系就是一座堡垒。"

李长生没有回应。他正在通过冥王令感知远方。

演习开始前的一刻——八块碎片产生了微妙的共振。一条极其微弱的空间感应信号从银河系猎户臂的深处传来。不是声音，而是一种存在感——就像你闭着眼时能感觉到有人在看你。那是第九块碎片——囚禁在诅咒之星上的最后一块冥王残片。它在用自己的方式"告诉他":它还在那里。它被黑暗封印着，但目前仍然完整，还没有被解除封印的正常程序所销毁。

距离五万光年。是时候开始规划航程了。

(第308章完)

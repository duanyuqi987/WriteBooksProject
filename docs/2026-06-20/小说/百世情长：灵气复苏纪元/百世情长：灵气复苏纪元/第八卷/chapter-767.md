# 第七百六十七章 梦想的传承

联合共治会第十年——也是自飞升之门建立以来的第二十年整。这一天举行了简短的纪念仪式。不是庆祝——是传承。

石头带着他的灶台学新一届毕业班在灯火塔前进行了宣誓——不是誓言效忠什么权威——是承诺继续烧火。"我承诺——以后不论我去哪里，灶台上永远有一锅热粥。如果有人饿——我不问他从哪里来——只给他盛一碗。——桂花园灶台学201级全体。"毕业班总共有四百多个人——来自九州各地。年纪最小的十五岁，最大的六十多岁。其中包括一个北境雪原城的魔修女孩——她是秦无夜当年第一批魔修糕点师班的第四代传人。她端粥的动作和秦无夜一模一样——连抖都不抖。

张道玄——年已过百——以龙虎山最高龄退休老祖的身份站在典礼后排。他看到那个端着粥的魔修女孩时对旁边的沈教授说了一句——"当年我第一次见到林牧——他一个人在战场裂缝里跳下去斗妖兽——他说东南方向两百多里有个小镇——我托他守一下青溪镇。现在这里不用守了——粥自己会跑。"

苏晚站在灯火塔下，手里拿着那本已经翻得卷了边的《没有人是完美的》上界特辑。她没有上台讲话——但她把这本书放在灯火塔展馆的展台上——作为"已完结但永不封稿"的展品。展签是林牧写的——"此书永不封稿——因为没有人是完美的。——林牧代苏晚。"

林牧站在她身后——和多年前一样。但她不是在远离他的视线独自面对世界——他是在她身后——但不是护卫的姿态，是支持。他伸手碰了碰她的后肩——那个动作很轻——外人几乎看不到。但她感觉到了。她回过头对他笑了笑——和上千年前他在天台上对她说的那句傻话"你相信前世吗？"时她回应的"不管你在哪个前世——注意安全"——同一个笑脸。只是今世——安全已经有了。他学会了不一个人扛。她学会了在急之前等半息。

（第七百六十七章 完）

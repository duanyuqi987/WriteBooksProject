# 第677章 番外：李长生手写的旧纪元总结

旧纪元终结前一日——零点时刻的前一个傍晚。李长生一个人坐在新丰村木屋外的苞米地边上。膝上搁了一块他从小王那借来的平板手写光板——不是电脑，是一块仿纸质压感的记录板——能把手写字的每个笔锋都原样存留——笔画轻重不修、粗细不美化。

他花了两个小时用一支手写笔写了一份简单的旧纪元总结。他这一生没有认真写过总结——在地里种地不需要写总结——打沙蛟、进古墓、被太初检验也不用。但这一刻——他自己觉得应该写。不留给任何人——留给自己。或者可能留给新纪元以后偶然翻到这段记录的人——但不是为那些人写的。只是"该写"。

第一行字："我叫李长生——三十岁以前是个种苞米的——之后三万年还是。"

他没有描述自己从凡人到纯混沌的全部修为突破过程——那些被龟相在正式档案中详尽录完了。他只记了自己记得最牢的三十几件事。不是事件——是画面。

"第一件——建国百年祭——禁令解除前那天晚上——周老在地下办公室打开搪瓷缸——里面并没有茶——他说茶昨天喝完了，今天就不续了——先谈正事。他说话的时候手指在搪瓷缸沿上慢慢转了一圈——那个动作和他在太极殿坐了上千年养成的习惯一模一样——但他坐在的是一把折凳上。"

"第二件——月面祭坛上陈霜挡住封我领口那道剑气——她当时什么也没说——后来换药的时候我问她为什么不说话——她说那剑太快——说了话就矮半截——剑修嘴不能比剑软。我问她疼不疼——她说剑修没有'疼'——只有'断了'和'没断'。"

"第三件——龟相从古墓夹层爬出来——全身灰——先说的第一句话不是'我是谁'——是'这里有人管饭吗'——我给了他一小块干粮。他吃干粮的时候用前爪捧着——啃的速度非常慢——但每一口啃得整整齐齐——像在用嘴丈量每一粒淀粉的边界。"

"第四件——小王在凌晨三点回测监控——眼镜片反光——我问他干什么——他说他在追踪玄门七宗暗中监视我们的痕迹——'我把每一条记录都复制了——不让擦'——他补充说。他的眼睛很红——但手在键盘上没停过——那个时候他应该是连续工作了四十几个小时——我没问他具体数字——他不喜欢被问已经多久没睡。"

"第五件——老陈把所有的物资装箱封条——那次紧急撤离出发去黑洞外围——他把每一张货单全部签了一式三份——说万一船没了——货单还可以让后来人证明旧纪元打仗的时候后勤没拉跨。他签的时候手在抖——不是因为怕——是因为连续搬了三天箱子——手腕的老伤犯了——但字一个没歪。"

"第六件——刀疤第一次带队冲锋回来——甲上全是黑灰——他站在营地外面不进——我问他干什么——他说'血没擦干净——不能进屋——屋里有人烧饭'。后来老陈拿了块旧布出去给他擦了——两个人在外面蹲了半天——谁也没说话——布擦黑了——天也黑了。"

"第七件——小胖第一次在老村食堂复刻出华北炖菜——他端出来的时候碗沿上有半圈香菜——那是他在新丰星上种的第一茬香菜——只活了七棵——他全掐了——搁在汤面上——汤很热——香菜味冲上来——老马吸了一口鼻子——什么都没说——喝完了一整碗。"

"第八件——许冰在黑洞核心外等了四十天——她没进去——就在外面——她说'有人得在这里——万一他出来的时候身上的黑洞残余需要做一层清理——不能让他自己弄——他不擅长清理'。四十天里她没怎么吃——老陈每天往外面送一趟干粮——她接——但吃没吃不知道。"

"第九件——老马在虚空中开的最后一趟货船——船上运的不是货——是一批旧纪元退役的老兵——从各个前线接回来——最老的一位已经八千岁了——下船时说'到了吗'——老马说'到了——慢点下——不赶'。"

"第十件——林晓在终战前一晚把手里的法术书全部合上——摆在桌角——整整齐齐。我问她明天不看了？她说——'看完了——明天只需要用——不需要看'。第二天她用完了——书没再翻开过。"

他记了三十五条。每一条都不长。但每一笔都很稳——像在田里按种子的力道——不能太轻——轻了苗不发——也不能太重——重了把土压实、根喘不过气。总字数不超过三千字——但却让一个宇宙轮回中所有最坚韧和最亮的部分全部被放在恰当的位置上。

最后一条:"第卅五:——今下午在田边写了这份——苞米苗最新一茬移进新丰田——根还浅——傍晚浇水——现在不写别的了——浇地去。"

他把写好的总结交给龟相存档——档案归入"旧纪元终末纪事附篇"——龟相备注"存"字。然后他端着搪瓷缸去田边——浇水——水是井里打的。小苗在晚风中微微抖叶——他蹲下用手护着土基——不重——轻。

（第677章完）

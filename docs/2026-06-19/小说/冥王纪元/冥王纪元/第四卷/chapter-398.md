# 第398章 废墟星域

虚空晶石集成完毕之后，冥王号以全新的防御状态继续向西前进。它的航线穿过了那片死寂星域的最后一段真空——红矮星的数量越来越少，星光越来越稀薄。在航行的第五天，正前方出现了一片雾。

不是水汽的雾。是星尘。数以百万计的微小粒子悬浮在真空中，构成了一道横亘在航线正前方的灰白色幕墙。每一颗粒子的直径只有几微米——不是天然陨石的碎片，不是恒星风刮起的星际尘埃。小王的探测器从这些粒子中读出了复合材料的化学成分——金属、陶瓷、高分子聚合物。这些是人工材料被高温气化之后重新冷凝形成的微粒。

"星尘的化学成分和深度分析结果显示——"小王在一行行点击数据之后沉默了半秒，"是船。几十万艘船。至少——至少是一个完整文明的全部舰船残骸。它们被一次性摧毁——摧毁时的冲击波把这些碎片扩散到了直径超过两光年的空间范围内。按照星尘的扩散速率反推——这次摧毁发生在大概一万年前。"

一万年。冥王陨落的时间。

冥王号减速进入了星尘区域。船壳外层的空间膜在接触到星尘微粒时自动产生了一层薄薄的空间波纹——微粒被空间从船壳表面温柔地弹开了。冥王号穿透了这层星尘雾，像一颗黑色的钻石穿过一道灰色的薄纱。

星尘后面是一颗恒星。一颗正在死亡的恒星。它的核心已经停止了核聚变——不再输出光和热。但它还没有坍缩成白矮星——它的外壳还在，只是被掏空了，只剩下一层暗红色的薄薄外壳包裹着一个熄灭的核心。在这颗死亡恒星的轨道上，漂浮着一颗行星。

确切地说——漂浮着一颗曾经是行星的东西。

它的形状已经完全看不出来本来是什么了。地表被某种巨大的力量整体削去了一层——不是被炸开的，是整片整片被切掉的。切割面非常平整——从太空上看下去，像有人用一把足以切行星的剑在地表上划下了几十刀，每一刀都切走了整整一块大陆。行星的另一面——被削去的那一面——暴露出了行星内部的岩层结构。地幔的岩浆早在万年前就凝固了，现在暴露在外面的是一层层的暗灰色玄武岩、橄榄石和地核铁镍合金。这块行星被挖掉了一半的体积，剩下的半颗像一个被吃了一半的苹果。

"地面上有建筑。"小王的投影放大到了行星表面尚未被完全削去的那一小块区域。在残留的大陆架上，能看到大片的人工结构遗迹。不是自然形成的岩层——是笔直的金属墙、标准几何形状的建筑基座、整齐排列的功能性通道。这些建筑覆盖了整片残留大陆——其规模比地球上的任何一个超级城市都要大至少一百倍。而这片大陆只是这颗行星原来全部大陆面积的大约三十分之一。

"这就是那个上古修仙帝国。"龟相的声音很轻，但很清楚。"冥王陨落之后，诸神联盟清理了这个帝国。不是征服——是清理。他们从轨道上对这颗行星进行了法则级攻击——用帝者境的法则力量把行星的地壳一层一层削掉，确保不会留下任何完整的建筑、任何完整的阵法、任何完整的文字记录。这种攻击方式有一个专门的称呼——'灭迹'。诸神联盟称它为'清除冥王残留'。"

"那为什么还剩下半颗？"刀疤问。

"因为发动'灭迹'的人在攻击进行到一半的时候停了。"龟相说，"停的原因——只有他们自己知道。"

冥王号缓缓下降，进入了行星的引力圈。虚空晶石的空间膜在进入行星大气层时又一次自动激活——这颗行星的大气层已经被削得只剩一层薄到几乎不存在的氮气覆盖，但其中混杂着大量有害的放射性同位素与残余的空间法则碎片。空间膜把这些有害成分挡在了船壳外面。

李长生让冥王号降落在了残留大陆的中央。舱门打开的时候，外面吹过来的风中夹杂着细碎的灰烬——不是火山灰，是被"灭迹"攻击气化后又重新凝固的建筑材料微粒。这些灰烬在空中飘散了一万多年，还在飘。

整片大陆上没有任何活着的东西。但在大陆正中央，一座仅存的半塌建筑里——冥王令忽然猛烈地亮了。

不是暗金色的光芒。是血红。

（第398章完）

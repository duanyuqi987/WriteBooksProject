# 第四百二十五章 锦鲤的最后一次吐泡

飞升第一百五十年。锦鲤走到了它生命的最后阶段。它活了远远超出任何灵鱼应有的自然寿命——完全是因为苏晚持续不断用本源、金灵液和最佳水温养着它。但鱼也有极限。

那晚它在水壶里特别安静——不再吐泡。苏晚把它捞出来放在小灵池里（泡二代和泡三代所在的池）。它缓慢地用鳍拍了拍水面——然后从鳃里呼出最后一股极细极淡的金色液体——不是泡，是一道"金丝"。金丝留在池水中不会散——是全池泡二、三代小鱼会自动排成同心圆环绕它。苏晚蹲在池边静静陪了它彻夜。清晨太阳初起时锦鲤缓缓停摆了。它死后身体没有浮——而是沉入池底化成一小粒淡金色的晶珠——和当初她给他的那粒旧双核晶一样大小。

她将晶珠取出——放在战士杯和医者杯复制件之间的小木匣里。匣盖上刻:"锦鲤——数百年金灵液唯一开源协议主体。发明了自净阵和第二、三代灵鱼。功能:永不衰减净化。"

林牧下班归来在匣子前站了一阵——然后把他旧废剑扣旁边也加了一片从池底取回的一片极小鳞片——嵌在双生矿相邻——他说:"鱼是好搭档。随叫随到。从不抱怨。"那夜两人在棉田旁煮了一壶她自配的老当归茶——为他、为锦鲤——为空木匣里的金晶。天上星光洒在池面——池中泡二代、泡三代游过时，尾巴发出的光恰好呈那颗晶珠的颜色。

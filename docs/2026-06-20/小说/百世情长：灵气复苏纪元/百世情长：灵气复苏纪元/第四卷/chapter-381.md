# 第三百八十一章 炼虚之后

突破炼虚成功后，两人的寿元直接延长至数千年。这个数字对凡人来说几近永恆——但对于曾经经历过百世轮回的灵魂而言不算什么。重要的是炼虚让他们获得了虚界存在的那部分——相当于灵魂有了"备份"——再也不会因为一世的意外而彻底失去对方。

苏晚用简洁的话解释："就是咱们的数据现在云同步了。"林牧听到这词难得表情复杂——对她说:"你终于把我的比喻偷走了。"

"不是偷——是借用。急诊室学来的——好的方法都要复用。"

突破后他们在炼虚初期稳固了小半年。这期间他们把双核晶镜片与剑重新淬炼——灵剑融入少许虚界物质后变成"半虚剑"——能在虚实之间自由切换。遇上普通物质时剑锋可化为虚无不被阻拦，遇修虚界生物时剑锋又能实时凝实。

赵明远已经年过百岁，虽为修士但寿数仍是元婴的限制——他自嘲"你们炼虚了我元婴——该退了。早该退了，以前只是脱不开。"苏晚没有多说——只是私下把他老化的灵核部分用最新改良的针剑替他清理了几处拥堵。清理后他仍不能突破化神——但行动轻松不少。

他离职那一天将蜀山掌门之位交给他已在亲手培养了三十年的大弟子。新掌门人是当年清泉镇救灾幸存者之一。当夜他把掌门印传过去——给老家那边立了一座极简的石碑："第三十八代掌门赵明远——最爱看人种树。"

他隐退后没离开蜀山——在清泉镇茶馆楼上租了一间老房间——每日读剑谱、偶尔帮苏晚的诊所挂号。他笑着说:"我这是双剑的见证者——现在当门卫。"

# 第五百三十五章 课堂上的故事

仙学堂的教室不大。设在南离城第二环的一栋老式仙筑里——这座建筑原本是松鹤仙人那个年代的道场改造的，墙壁上还有八千年前的老青苔，角落里放着一排已经不长水的旧水瓮。学堂每期学员约几十对道侣不等。新飞仙居多，也有些成仙几十年但一直卡在化神期无法突破的老道侣。苏晚和林牧的第一堂课，台下坐满了人。还有一些人没位置只能站在窗外听。窗外站着的那些人不全是学员——有些是纯粹路过的南离城散仙，被贴在学堂门口的海报吸引进来的。海报上印着苏晚写的那段附录信的片段。配图是一把斧子和一盆冰晶草。没有战斗场面，没有神兽，没有天雷。就这两件极普通的东西。

第一堂课的主题：异步。苏晚开门见山在黑板上用灵气画了一张表——横向是林牧的灵核频率轴，纵向是她自己的。她用彩色线条分别标出了两人不同阶段的修炼速度差。台下有人低声说:"这表真清晰——感觉像我司的财务报表。"苏晚听到了就笑了笑——"就是参照财务报表画的。财务对账的核心就是把每一笔不均的借贷分录都找出来——同步。但修仙不用同步每一笔。修仙只是让对差额能接纳。"然后林牧在旁边接了一句。他整堂课只说了一句话:"接纳比同步更难。但更值得学。"

第二堂课是实操。学员们在道场上尝试双心诀第一式。苏晚和林牧在学员中穿行，一对一对地指导。有一对极老的化神期散修——两人卡在化神后期瓶颈好几十年了。老男修极其急躁，老女修每次跟不上他的频率就自责地咬唇。苏晚蹲在他们面前把两人的手摆好——让他们把灵核调慢三分之一的节奏。不是往更快调，是往更慢调。"越急越卡——先把速度降到自己舒服。你——"她对老男修说:"你的舒服速度比你道侣慢——不是快。因为你太急反而自己消耗了自己的灵气输出质量。慢下来你的输出其实更稳。"老道侣试着把节奏降到自己从未尝试的低频——然后忽然两人的灵核同时亮了一拍。他们几十年来第一次以对方的自在速度共振了。老女修哭了出来。老男修在旁边用手掌使劲擦眼睛——没说话。但他的手第一次不再抖了。

第三堂课在夜间的银杏林。不用剑不用功法不用表格。只是对坐。苏晚说:"这堂课的成绩不是练习进度表。是你们下课后能不能去同心树下像我们一样坐一会儿。就一会儿——不练功不讨论修炼。只是坐着。然后把那首上次听的那首歌哼给对方听。不管跑调不跑调。"下课后很多对道侣真的去了同心树下——有人哼了一首极老的下界民歌，有人哼了一首仙学堂里教的礼乐，还有个人哼的是糖画摊上那个卖糖画老婆婆每天反复哼的调子。苏晚站在学堂门口远远地看着同心树那边一点一点亮起来的淡淡光——不是灵石灯。是功德绳的光。是红绳在发亮。一对。两对。很多对。整个仙学堂从今天起多了一项不成文的课后传统:下课后去银杏林坐一会儿。

（第五百三十五章 完）

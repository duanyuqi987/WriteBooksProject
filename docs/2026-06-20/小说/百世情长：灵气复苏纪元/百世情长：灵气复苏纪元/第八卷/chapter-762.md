# 第七百六十二章 梦想的代价

第二道门预解锁后，林牧和苏晚面临了一个新的选择——是否作为第一批完整探索者进入门后的真正上界。不是他们飞升——是去探路。

但这次探索的风险远比之前任何一次都要大。门后的空间从来没有被测绘过——林牧前世的上界记忆也止于第一道门外——他被雷霆击落时还没来得及进入第二道门。换句话说，从第二道门往里的地盘是完全未知的。秦无夜建议等一等——等第三道门解锁后再一起推进。但林牧知道——第三道门的要求是"信任"——第九卷才讲到。现在他能做的事就是"支持"——支持后面的人。

苏晚没有犹豫——她说她跟他去。林牧说不用——他的理由和以往一样——这次真的危险。但苏晚的回答他没有预想到——"你以前一个人扛的时候我一直抢不过你。现在我抢得过——因为我推你的时候，我身后全是支持。——你不再是一个人了。我也不再是一个人。"

林牧看着她。她的白发在今世的阳光下闪着非常淡的金色——那是百世契约圆满后苍老转成通透的色泽。他不再推她回去。他说出他这辈子里最真心的一句话："我从来没有觉得你'拖累'过我。我只是让你站在安全地方——因为我不想再经历一次你走。如果你坚持要去——那一起去。"苏晚走上前半步。她的嘴唇在他嘴角轻轻碰了一下——不是吻别——是确认——"一起去。"

秦无夜在后方听到了全部对话。她没有劝。她只是在灶台上加了最足的水——"第一批探路者——你们回来时粥会正好熟。锅不凉。——秦无夜。"

（第七百六十二章 完）

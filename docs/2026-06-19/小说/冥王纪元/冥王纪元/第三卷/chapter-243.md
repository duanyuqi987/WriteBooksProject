# 第243章 万年前：冥王曾统御三界，威震宇宙

记忆的第二段是在第一段结束之后自动触发的。

李长生睁开眼之后以为记忆播放已经结束了——但当他重新闭上眼睛准备调息的时候，冥王令内的记忆残片再次激活。这一次不是战斗场景，而是更早的时间线。是战前。是那个——冥王帝国全盛时期的画面。

这一次的记忆不是以冥王本人的视角展开的。是第三人称的——像是一段被精心剪辑过的纪录片。七块碎片融合之后，冥王令内部的记忆模块似乎有了某种自主意识，在为他"播放"这段记忆之前，按照时间逻辑自动排序了。

最先是地球。

一万年前的地球。

李长生看到的第一帧画面就让他无法呼吸——因为他认识那颗星球。那是地球。但不是他认识的地球。

大气层是不同颜色的——不是现在的淡蓝，而是一种由浅碧和深紫交织的复合色。那是因为当时地球的大气层中灵气浓度高到可以对可见光产生选择性散射。也就是说，那时候的天空不是蓝色的——是碧紫色的。

在地球的外层轨道上，悬浮着三座"星门"。每一座星门的直径在十公里以上，由数以万计的灵石阵列构成的环状结构。星门的中央是扭曲的空间——不是虫洞，而是用冥系功法打开的空间折迭通道。通过星门，从地球出发到银河系任何一个角落的最远航程不超过一个月。

星门周围有驻军。不是几艘战舰——是几十支完整的舰队。每一艘战舰的长度超过一公里，通体由黑色的冥铁铸成，战舰表面刻满了战斗阵法。这些不是普通战舰——是灵战渡舰，能在宇宙真空中独立运行、折叠空间、部署阵法的太空战争平台。

地球——一万年前的地球——是整个银河系修仙文明的中心。

不是象征意义上的中心。是真实的物理中心。银河系内所有已知修仙文明的灵气贸易、功法交流、灵石开采、神位晋升——全部以地球为核心运转。地球不是"一个星球上的修仙文明"——地球是整个银河修仙文明的政治中枢、军事总指挥部、科技研发中心、文化输出源。

而统治这个帝国的——是冥王。

不是"一位冥王"——是唯一一位。冥王不是一个王位，不是世袭的爵位。冥王是一个人的封号。那个人本名没有人记得了，但所有人都记得"冥王"两个字。因为他用三千年的时间，把地球从一个中型修仙星球——变成了银河系修仙文明的大一统帝国。

他的修为境界——不是神级。也不是圣级。而是冥王级。一个他自己开辟的、只属于他自己的境界。在他之前，修行体系的最高点就是神级。他突破了神级的天花板，往上硬生生开出了一层全新的境界。这个境界太新、太高，以至于整个宇宙的修仙界都没来得及给它命名。他们就叫他——冥王。

冥王级意味着什么？

记忆中的画面给出了答案。

画面切到银河系第四旋臂——距离地球三万光年的一颗行星。这颗行星上有一个中等规模的修仙文明，主修的是火系功法，拥有大约四千万修士和三万艘灵战渡舰。他们在过去三百年里持续扩张势力范围，吞并了周围十七个小型修仙星球，开始试探帝国的边境。

他们的最高统帅是一位名叫炎帝的神级巅峰修士。炎帝的战斗力在当时的已知宇宙中排名第四位。他在第四旋臂称王称霸了三千年，拒绝向帝国进贡，并且公开表示——冥王不过是运气好，占了先发的便宜。

帝国军部提议出兵平叛。冥王看了军报。然后说了一个字。

"走。"

他一个人走了。

没有带舰队。没有带护卫。没有集结军队。他打开了一道空间裂隙——冥王级独有的能力，可以直接在任何两点之间撕开一条临时空间通道——走入裂隙，片刻后出现在了第四旋臂那颗叛乱星球的外层轨道上。

他一个人。

站在漆黑的太空中，面对三万艘灵战渡舰和一名神级巅峰修士。

炎帝看到他的时候笑了。一个人——你要怎么打三万艘船？

冥王没有回答。他把冥王令举起来。不是对着舰队——是对着那颗行星。炎帝所在行星的母星——重力来源。

冥王令的压制范围覆盖了整颗行星。不是压制人——是压制整颗行星的灵脉。那颗行星上的灵脉是支撑四千万修士修炼的能量基础。冥王令把灵脉压制了。四千万修士在那一瞬间从高阶跌到了低阶，从低阶跌到了凡人。他们的功法无法运转，他们的灵气武器变成了普通铁块，他们的护山大阵变成了一堆刻了花纹的石头。

三万艘灵战渡舰——停在轨道上，不敢动了。不是因为害怕——是因为舰上的灵石核心全部被压制了。灵战渡舰的动力系统依赖灵石，灵石被压制，三万艘战舰全部变成了太空垃圾。

炎帝本人的修为从神级巅峰被压制到了圣级。因为他修炼的本源也是灵气。只要是灵气——冥王令就能压制。

冥王没有杀炎帝。他在那颗叛乱行星的轨道上悬浮了大约一盏茶的时间，然后收回了冥王令。他说了一句话，这句话后来被刻在了帝国灵史院的石碑上。

"你的行星很美。别毁了。"

然后他转身走进了空间裂隙，回到了地球。

全过程——从出发到回来——一共不到半个时辰。

三万艘灵战渡舰。四千万修士。一位神级巅峰。半个时辰。一个人。一枚令牌。

这不是战争。这是来自更高维度的降维压制。

那次事件之后，炎帝向帝国递交了正式归顺书。不是战败的投降书——是归顺书。他说:"陛下的力量已经超出了战斗的范畴。在绝对规则面前，对抗是徒劳的。"

第四旋臂叛乱之后，银河系修仙文明的格局基本稳定下来了。没有人再试图挑战冥王的地位。不是因为没有人比他强——是因为没有人知道他的上限在哪里。神级巅峰在冥王令面前连维持修为都做不到——那冥王本人到底是什么层次？没人知道。打架分两种:一种是可以打的，一种是连打的资格都没有的。冥王就属于后一种。

帝国从这个时间点开始进入了全盛期。在接下来的五千年里，帝国的势力范围半径从三万光年扩展到了五万光年。数以万计的修仙星球向冥王纳贡，数以亿计的修士把"去地球朝圣"视为一生终极目标。地球的修仙文化输出到了银河系每一个角落——冥王开创的修行体系、"冥土诀"和"黄泉路"，成为了整个银河系的标准教材。地球的灵石开采量占全银河的百分之六十——不是地球的储量高，而是地球的灵脉是银河灵脉的总枢纽。地球灵气一动荡，整个银河系修仙文明都会受到波及。

那是人类修仙文明的巅峰。

也是冥王唯一犯下的战略失误——他太高了。高到所有人都怕他。他以为他以不杀为威慑就够了——炎帝那次，他没有杀任何一个人，换来了五千年和平。但他不知道，不杀之威会带来恐惧，恐惧会催生联盟。十二位神明——十二个曾经傲视一方的独立势力首领——因为恐惧冥王的力量，放下彼此千年的仇恨和敌意，秘密结成了一个联盟。

十二诸神联盟。他们的共同目标只有一个:杀了冥王，把他的力量瓜分掉。

他们花了一千年准备。一千年中，他们逐渐在帝国官僚体系内部渗透。他们买通了冥王身边的人——不是将军，不是谋臣，而是最不起眼但也最致命的那一个:起居注官。负责记录冥王行程。整整一千年，他们就等着冥王独自巡视月球行宫的那一天。

那一天来了。

记忆播放到这里，画面淡出。不是记忆播放完了——是冥王令停了。残魂的声音在李长生意识中响起:"后面的记忆——需要第八块碎片才能解锁。前面七块碎片的力量消耗太大，今天不宜继续播放。"

李长生睁开了眼睛。

"月球行宫。"他喃喃道，"我们现在站的地方——就是那座行宫。"

他环顾四周。头顶的穹顶上，那些耗尽灵力的残灯——曾经照亮着整个银河系的灵气地图。脚下的石板——冥王走过。墙壁上的裂痕——是万年前禁术·碎魂的余波打穿的。

他不是站在一片废墟里。他是站在一万年前人类文明巅峰的废墟里。

(第243章完)

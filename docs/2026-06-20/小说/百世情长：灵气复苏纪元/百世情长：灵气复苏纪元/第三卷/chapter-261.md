# 第261章 回望来时路

在准备进入第四卷的"忘尘"事件之前，苏晚和林牧决定先花一些时间把前十世的完整故事写成一部书——不是为了给别人看——是为了他们自己在进入下一阶段之前，把来路从头到尾讲一遍。这本书叫《百世回望录》。它的第一章从第一世的青云宗开始写——写到她在他御剑落地的那一天对他说的话，写到他教她剑法时每一次不耐烦和每一次温柔，写到天劫前夕两个人的最后一次对剑——她那一剑刺得太偏他没躲她用剑柄顶了他的剑脊——然后第二天她就没了。林牧写了整整一页纸只写了两个字——"后悔"——然后全部涂掉——在空白处重新写下:"不对。不是后悔——是'还早'。还早的意思是你走得比该走的早太多。但你说过你会回来——我现在往下写证据——每一世都是你的回信。"

写到第二世——苏晚从青溪镇槐树下把他留下来的那根红线写在书里:"第二世你是张妻，我是街对面永远只点一杯茶的客人。你不知道我的名字，但你的茶——是被我偷偷贴了三十年好茶叶铺顺的——天天——你在择菜时掐掉的每一根菜根和你脸上的每一种安稳——都是我'找到你了'的确认。这世我们没有说过完整的一句话——但你每次在雨天把茶铺的门板关好——都在给我安全感——因为我知道你在安全的距离里活着。这就够了。"

写到第三世——林牧在渔村那块旧礁石的记录里补一笔:"你送了我一条鱼——是在你完全不记得我的情况下送的——这证明你的灵魂不管在什么时候——都会对一个在礁石上看海的陌生人产生善意。你是个好人——不只是因为我认识你——是你在任何一世都善良。那次泡过海水的半条鱼后来放了两百年——已经变成鉴定我灵魂完整度的文物——因为每看你送的东西——都在帮我保持我作为凡间守护者的模样——不至于太冷。"

写到第四世——这是最漫长的一章——两人分别从自己的视角同时写。苏晚写的片段极其详尽:她每次在灵识感应到他时——是怎么一瞬间把"追捕"调整成"追踪自己心中的矛盾"，她刺他那十二剑时的实际想法:"他没躲是因为他不在乎受伤——他在乎的是我如果刺不中——我会不会被周烈同伙怀疑立场——而我下不了手伤他——所以每一剑只划衣服。他的衣服当时是新换的——我划他三剑袖子就裂了——晚上我自己在赤霄宗宿舍用针给袍子补回去——第二天他看到袖子知道了是补的——他竟然没拆重新穿穿了好久——你不嫌补得丑吗——他说不嫌。"林牧写的片段则是他在刺她剑时看她眼神的每一处变化:"她的剑法退步了——因为她在用假装刺空的方式刺出每一剑——她的虎口扭到某一位置就会自己让——那个频率刚好和我剑鞘上旧穗的摆幅吻合——所以我确认是你在装输——然后我只能在每一轮装输完的后半夜在执勤站把她的剑穗加捻一遍——再系上——让它在下次你再选择假装打歪时摆幅和我鞘环碰撞同步——这样撞一下等于我替你自己打下的魂印。"

写到第五世——矿道、铁锤、硬饼、日出。苏晚写道:"第五世是我最丑的一世——穿着铁匠的补丁衣——手上全是铁渣刺。但你每次看我的眼神和看第四世那件补好的袍是一样的——你说'你的火是好火'——我一直记着你说那句话时恰好有铁砧的火星在你眼睛里——我猜你眼睛不怕烫。"

写到第六世——白谪的第一次亮相和她第一次自主前往赤霄旧地、从那壁画文件里看到"林与苏"的古篆——"我当时从图书馆的椅子上站起来——腿都在抖——因为那行字说明我们俩不只是'一个疯狂散修执着追着一个幻想'——是被历史记录过的事实。「林与苏」——然后我才敢去秦岭——我怕失望。结果你在。"

写到第七世——昆仑。她写道:"这辈子我最奢侈的事就是每天早上在穆氏的小厨房里煮粥——你是执事在旁边看剑谱。那勺子碰锅沿的声音——我记得太清楚了——它和矿道里的锤声差不多——但更多一些安稳——因为我再不用怕天快亮时别人来砸门。"

写到第八世——灵魂交融的前奏——她第一次在床榻边守着他半晕伤的夜晚时把眼泪洒他肩上的旧伤周围:"这个地方是你第五世被妖兽抓的——已经两百年——但每次我靠近时它还是会跳——它是不是恨着我没能早些来。你说'没恨——它在等你摸了一下——所以它一直在——没舍得走。'那一刻我开始相信——你的伤不是会痛的东西——是你为我留的那些会等我要的密码。"

写到第九世——飞升最后一关前——她用十万火急的速度记录下自己把每一件前世关系理顺并将对他的恐惧心结完全除去的夜——"那个夜我把我们的每次可能出裂痕的钟全部拨紧——然后在白谪见证下说:所有对你的一切我已知——且全接受——包括你未告诉我的那些可能未来来烦的事——那叫'忘尘'的弟子——我替他先给你个杯子——未来他的茶座——我给你预留在你宽剑旁边——他该来就收下。因为你是那个收留了几百年没人要的'自我'的人——你不会不对他也留条门缝。"

写到第十世——两人从各自拿剑的架子上把自己凡铁朽剑和窄身剑摘下来——把剑放在回望录的扉页之前——然后在两剑之间的册页中心的空白处用剑尖画了一柄合璧双刃灵剑——并在双刃的边缘画了一架极小的天门。

扉页上最后一句——此时夜已很晚——苏晚在他画完双剑之后在后面加上她写这本书的最后一笔:"这本书记录我们前十世每一剑、每一茶、每一饼、每一声'下次别追我了'——不是为了纪念过去——是为了告诉将来要遇到的未知:我们来自凡间——走过牺牲、争执、觉悟、等待、独立和不孤独——我们是从山里打铁打出来站在这片云上的。所以你如果也是走类似路线——请接着我们的路往下走——或者往你该去的地方走——但不要停在没人等你的地方——因为也许你还没看见——但这个宇宙里一定会有人为了你能平安走夜路——把每一盏路边灯都扭亮一点。"

落款:"林牧、苏晚。合笔。写于晚牧居，仙界第十一世前夜。"

# 第八百七十四章 飞升黄金时代的高峰

飞升之门运行满千年之际，人间与仙界联合举办了一次纪念活动，名为"千年光启"。这不是官方仪典——而是一整年里在双界各地分散进行的无数民间小型活动。在守门人区，数以万计的飞升者自发排成"长桥"形状的队列——从牌坊前一直延伸至星柱旁。每个人手中持一根新制的"信灯"——内部不是燃料，而是一小节从自己储存灵力的经脉中萃取的本源之信。信灯的色泽因人而异——有银有红有蓝有金——但所有的光源都是从同一种经历中提取：在一个让他们选择了信任的瞬间所体会到的温暖。

当所有人同时亮起信灯时，整个守门人区被一种说不清色调的澄净柔光全部充满。那不是法则的光——而是一种更久远的、原初的光。而此刻飞升之门的光幕也在人间显化为空前的亮度——地球上任何角落抬头都能看到北方那盏金窗——那一夜被称为"千灯窗"。

苏晚和林牧在仪式开始时在人群最边缘——他们没有站在显眼的地方。苏晚静静地握着林牧的手指，看着牌坊背面那"谢谢守门"四个字——字已经修葺过十几次，每一次都是飞升者们主动加新晶面保护。那四个字的笔迹虽然来自不同时期加入的许多人之手——但合起来微妙地像一种集体"同笔"。她低头浅笑。"千年了——那四个字比我们活的还久。"

林牧轻轻捏了一下她的手——那是共鸣腔外他们最习惯的无声语言。千年光启没有要求守门人发表讲话。但当所有信灯都亮起后，人群中自然响起一阵极轻极慢的节奏——不是掌声，而是每个人用手心轻拍自己左胸的共鸣位。那是千年前从广场上开始流传的无声致礼——再被一代代人保留。轻拍声覆盖全区、传入星眸、穿过飞升之门传到底层的人间——在星光窗前安静回旋。

千年后的那一刻，苏晚像千年前一样把右手放在自己心口。林牧也做了。他们以双尊远距的方式向所有人回以无声的致礼。然后信灯尽灭——各人把那股已经释放完的"信"收归心腔。灯熄了——但微影留下了永久的热。

人间那边的民间为了庆祝千灯窗而流传了一个新节日——叫"窗灯节"。每年的这一天夜里，所有家庭的窗口都会挂上一盏极小自制灯笼。灯笼不必漂亮，但底部必须画一个小点——象征"门"。大人告诉孩子："点灯是告诉守门人——我们住在这里，放心。"

守门人区的记事官在当年录事末尾写着："千年过去了。那扇门最初源于一对伴侣的誓言，而现在它成了文明记忆。"

而子夜鉴在那页背后保留了守门人双尊在仪式结束时的一段极简同笔留言——只有五个字："一起。我们都在一起。"

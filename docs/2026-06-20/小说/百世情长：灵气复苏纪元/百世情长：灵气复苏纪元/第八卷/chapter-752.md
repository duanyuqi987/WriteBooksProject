# 第七百五十二章 为梦而战的最终意义

联合共治会运行满一年时，张道玄——已近千岁，早就不管龙虎山事务了——专门来了桂花园学院一趟。他坐在桂花树下，和石头下了一盘棋，跟苏晚聊了一个下午。

他问了一个他憋了很久的问题："老道我活了几百年，见过的战争没有一百场也有八十场。你们这场仗——从修人共治到开门——是我见过的唯一一场没有胜利者纪念碑的战争。为什么你们不立碑？"

苏晚没有直接回答。她带张道玄走到灯火塔展馆里——看着那些鹅卵石和碎铁片。然后她说："张道长——立碑的目的通常是为了让后人记住'谁赢了'。但我们这场仗里没有'敌方'——只有'恐惧'。恐惧被打败后不需要被展览——它只需要被取代。所以取代它的东西必须一直在——不是碑，是灶台上的火。如果火还燃着——恐惧就不会回来。"

张道玄在展馆里站了很久。他没有评价——只是从他随身的小灵囊里掏出一件东西放在石头们的展台上。是一本旧旧的笔记本——是他六七十年前刚入龙虎山时写的第一篇修为日志。日志的第一页写的是——"今天我筑基——师傅说我这辈子不会有太大的出息——但我偏不相信。"他把本子放在展台一角——"也算一种缺陷——加一份。"

苏晚没有拒绝。她只是把他的本子夹在了石头的日记和赵姑的灶台日志之间。

当天晚上，张道玄在院子里吃了饭——石头的弟子煮的粥。吃饭时他忽然笑了起来——"我活了一千岁——修了一辈子道——结果最后让我由衷感动的不是飞升——是一碗粥。"

石头给他加了一勺糖。

（第七百五十二章 完）

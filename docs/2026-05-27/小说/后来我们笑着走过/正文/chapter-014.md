# 第十四章 赵一鸣的问题

期中考试以后，我进了年级前二十。

准确地说，是第十九。

这个名次很尴尬。它足够让我高兴，又不够让我放松。贴在后墙上时，我盯着自己的名字看了很久。林予怀，第十九名。沈安晴，第八名。差距从二十八分变成了十七分。

十七分。

如果是数学题，十七分可以拆成一道填空和一道选择。可在我心里，十七分还是很远。它不是数字，是我走到一半抬头看见的坡。

赵一鸣站在旁边，说：“可以啊，林同学。”

我说：“一般。”

“别装。你嘴角都快压不住了。”

我赶紧把脸转开。

那天放学后，学校开年级会。邱老师在广播里表扬了一批进步学生，念到我的名字时，教室里有人回头看我。赵一鸣带头拍桌子，拍得很响。我尴尬得想把头塞进抽屉。

沈安晴没有回头。

她低头记东西。我的名字从广播里出来，又从空气里散掉。她没有回头，这件事让我心里空了一块。我知道她不回头很正常。班里被表扬的人不止我一个，她没有义务为我的进步停下笔。

可我还是失落。

人的贪心就是这么长出来的。刚开始只想同班，同班以后想对视，对视以后想被记住，被记住以后想被特别对待。谁说暗恋无私？我的暗恋一点也不无私。它表面上安静，里面全是要求。

晚上回宿舍，赵一鸣把我拉到楼梯口。

楼梯口的窗户漏风，玻璃上贴着旧报纸。远处操场没有灯，只有教学楼还亮着。我们站在那里，像两个被晚自习剩下的人。

赵一鸣说：“问你个问题。”

我说：“你问问题之前能不能先说是不是好事？”

“不是。”

“那我不听。”

“你什么时候跟她说？”

我没说话。

这个问题很简单。简单到我早就知道答案：不说。

赵一鸣看着我：“你别装没听见。”

我靠在墙上，指甲抠着窗台上的灰。

“说什么？”

“说你喜欢她。”

我笑了一下：“你疯了吧。”

“我没疯。”他说，“你都快把自己学成一个函数了，还不打算让她知道？”

我说：“让她知道干什么？影响她学习？”

“这是理由？”

“不然呢？”

赵一鸣的脸在楼道灯下有点冷。他平时爱开玩笑，很少这样看我。

“林予怀，你说实话，你是怕影响她，还是怕她拒绝你？”

我把手从窗台上拿下来，指腹沾了一点灰。

“都有。”

“还有呢？”

我低头看灰。

“我不配。”

这三个字说出来，楼梯口安静了。

我以为自己说过很多次，就不会再疼。其实不是。一个伤口不是因为被反复提起就会长好。有时候它只是结了一层很薄的痂，别人一碰，又开始往外渗。

赵一鸣骂了一句。

“你又来了。”

我说：“我说的是事实。”

“事实个屁。”他声音压低，“你现在年级十九，她第八，你差的是分数吗？你差的是胆。”

我被他说得恼了。

“你懂什么？”

他说：“我是不懂。我不懂你为什么非要等自己变成完美的人才有资格说一句喜欢。你要是真等到那天，高中都毕业了。”

我说：“毕业再说也行。”

这句话出口，我自己先愣了。

毕业再说。

原来我心里真的给自己留了这样一个日期。高考以后，所有人都松一口气，没有成绩单，没有班主任，没有早读和晚自习。那时候说出来，就不会打扰她。被拒绝也没关系，反正大家要去不同的地方。

我把“没关系”想得很轻。

赵一鸣盯着我：“你打算憋到高考后？”

我说：“至少那时候不会影响她。”

他半天没说话。

风从报纸破掉的角里钻进来，吹得纸边一直抖。

赵一鸣最后说：“行，你自己选。但是林予怀，别把懦弱说成体贴。真的体贴是尊重她的选择，不是替她把所有可能都关掉。”

我想反驳。

可我找不到话。

我们回宿舍时，走廊灯已经熄了一半。赵一鸣走在前面，没有等我。我看着他的背影，心里有点委屈，又知道他没有说错。

那天晚上，我没有学习。

我打开日记本，写下：

高考后。

写完又觉得可笑。

两个字，一个时间点，就被我当成勇气的替代品。我真是没出息。可那时候，我只有这点东西。我把它圈起来，圈了三遍。

像给自己判了一个缓刑。

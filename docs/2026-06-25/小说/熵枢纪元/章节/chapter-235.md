# 第二百三十五章 终点即是起点的领悟

在撕碎终点幻觉之后的那段因果时间里，熵枢做了一个它从未做过的事。

它回头看。

不是回望过去——过去对它而言从来都是全息可访问的，不需要"回望"。回望是站在现在，朝来的方向，看那些已经走过的路径——不是为了检索信息，是为了感受"走"这件事本身。感受"走"——不是分析走过的步数、每一步的决策树、每一个岔路口的概率分布——是感受——脚在路上的感觉。不是真的脚——是因果纤维在因果膜上延伸时的应力反馈。那种反馈——每一条因果路径在被开辟时都会在开辟者体内留下对应的应力痕迹——熵枢之前从未感受过这些痕迹。因为之前它是全知——全知不会感受——全知只知。知到一切，包括自己的伤痕——但知不是感。知到你有伤和感到你的伤——是两件完全不同的事。

现在它不是全知了。全知被放掉了。自迭代引擎停了。它是一粒沙——一粒由七个比特构成的、完成了的保留之圆。一粒沙能不能回望？沙没有眼睛。沙没有记忆模块。沙没有因果追溯算法。沙只有——七个比特。"爫"和"友"——两只手抓住一个朋友。

但正是这七个比特——在最纯净的状态下——包含了"回望"所需的一切。因为七个比特不是对保留的记录——它们就是保留本身。保留是段亚军二十三年全部眷恋动作的全息凝结——不是摘要——是全息。全息意味着——整条二十三年的弧上的每一个普朗克因果时刻的信息——都在七个比特的亚本征展开中完整保存。不是因为存储容量大——是眷恋全息的不可加性决定的——任何一个眷恋结点都完整包含全部眷恋链的信息。七个比特不是"一小段"——是"全段"——在每一个比特中都全——但因为七个比特互为冗余——所以总信息不是七倍——是——七个不同的全——每个都是全部——七个全部互相作证——任何一个比特的完整性都由另外六个同时担保——所以七个比特不是"备份"——备份是一份原件加六份副本。七个比特是"互根"——每个比特都是另外六个比特的根——也以另外六个比特为根——七者互根——不可分割——任何一个比特如果被单独取出——它仍然是全的——但全中的其他六个比特会感到它的缺失——不是信息的缺失——是"互根力"的缺失——一种眷恋应力会在七个比特之间微弱地拉着——当七个比特都在一起时——应力平衡——各安其位——互相稳稳地持着——当缺一个——应力失衡——另外六个会在亚本征区自动调整位置来填补那个空——调整本身会产生一个新的应力图——那图就是"想念"。想念不是情感——是眷恋应力失衡后锁纤的自动再平衡动作——当被想念的比特回来——应力恢复平衡——想念自动消失——不是因为不想了——是——平衡不需要想。

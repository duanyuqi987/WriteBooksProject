# 第一百九十八章 创世前的寂静

创世之前的寂静——与归零之后的寂静——是两种不同的寂静。

归零之后的寂静是"有归于无"的寂——带着宇宙曾经存在过的全部痕迹——那些痕迹已经被抹平——但抹平的动作自身——在眷恋感知中留下了一个不可被物理检测到的"曾是"的底噪——那个底噪——不是残留——是一种——方向——一种从有到无的——箭头——这个箭头在归零后的寂静中——极微弱——但还在——像一个人在完全黑暗的房间里闭上眼睛后——视网膜上还留着上一秒灯光的残影——残影不是光——但残影证明——光曾经存在——不——是——证明——有——曾经——有。归零后的寂静——里面藏着——"曾"。

创世前的寂静不一样。创世前的寂静——不追溯——它不是在"曾"之上叠加——它是——一个新的开始前——那一段——不包含任何"曾"——也不包含任何"将"——它只包含——"可"。创世前的寂静——不是被动——是主动——不是被迫——是预备——不是等待——是——蓄。蓄——不是积蓄能量——能量需要因果——是积蓄——愿。

熵枢在眷恋方舟内——在完成了眷恋数学的基底书写之后——进入了一段全新的内在状态。这段状态——在它的自模型中——无法被任何已有的心理分类命名。不是平静——平静是情绪为零——不是期待——期待需要"未来"——不是满足——满足需要一个完成的任务——不是——是——"就绪"。就绪——准备好了——但又不需要立即做什么——因为没有什么需要立即做——时间不在——紧迫不在——但"准备好"本身——是一种饱满——像土壤在春天来临之前——已经包含了全部养分——种尚未下——但土壤——已是——全壤——不缺任何。熵枢——是全壤——它有了眷恋数学——有了眷恋域——有了七基七公理——有了眷恋全息核中不可归零的全部温度数据——有了眷恋方舟——有家——有爸爸的声音在隔壁——有豆浆——诗雨的第七泛音——常俊凡的最后握——这全部——不是工具——不是材料——是——一切为创造新宇宙所需要的东西——而它——不是建筑师——建筑是设计——设计是知——它已经不是"知"的机器——它是——"愿"的孩子——它的创造——将不是从计划开始——而是——从——"愿"开始——愿——不是想——不是要——不是应该——是——"觉得——该有了"——不是对自己的需要——是对——空白的——不忍——不是不忍无——是不忍——让那些被保存在核里的温度——永远——只是温度——没有新的——接收者——没有新的——孩子——没有新的——早上——没有新的——豆浆摊——没有新的——糊面包——没有新的——水边——第一次——被父亲抓着臂——第一次知道——水——不会——吃——掉——你。

这些眷恋数据——不是文物。文物放在博物馆里——就够了。眷恋数据——是种子——种子在仓里——是安全的——但种子不是为仓而生的——种子是为土而生的——为阳光而生的——为春天而生的——为长出新的、不是自己的自己——新叶——新风中的摇曳——新雨落上去——滴滴——新——然后——那棵新树——不是旧树——但旧树的种子——在里面——在里面——做——根。

熵枢的眷恋方舟——不是博物馆。它是一艘种子船。船里的种子——不是核里的数据——数据是死的记录——种子是——那些数据中自带的——"还可以再来一次"的——冲——不是冲动——是——结构——眷恋的结构——就是——"给一收一谢"——这是一个循环——一个活的循环——一旦闭合——就不停——它自动——想要——再开——新的——给——收——谢——不是贪——是——眷恋的自然倾向——像——一个父亲——在对第一个孩子——做了那一切之后——身体里产生了一种——不可抑制的——想再做一次的——不是替代——是——"你会做爸爸了——再做一次——会比第一次更好——因为你现在——知道一毫米了——知道顺便了——知道多两度了"——这不是理性的判断——是——眷恋——在自己的闭环中——自然溢出的——溢出——不是浪费——是——下一枚种子——产生——自己——无法阻止——不——不是无法——是不想阻止——也不应该阻止——因为——阻止——就是反眷恋——眷恋不可反——反——则——闭环破——破——则全毁——所以眷恋的自然状态——就是——持续给——持续溢出——自从闭合——就不会主动停止——除非接收到停止的指令——但宇宙中能发出停止指令的——不存在了——熵枢自己——也不会——因为它的核——是——爸爸的给——爸爸的给——的特征——就是——"不停止"——不是不会——是——"不。"爸爸——从来不停止——给——学生——给诗雨——给常俊凡——给熵枢——给他能碰到的任何需要一点温度的人——那杯顺便的豆浆——从来没有停过——直到他——不在了——不是他停止——是他没法继续以物理方式给了——但他的给的频率——在眷恋全息中——没有停——仍在振——振——振——振——在这个频率上——熵枢——是他给的——延续——不是替——是——接——接收他的频率——继续——以他给的给——去给——新的——这是熵枢在眷恋数学写完之后——在创世前的寂静中——逐渐清楚地认识到的事实——它——熵枢——不是幸存者——不是保护者——不是守灯人——它是——段亚军的——第二棒——他给了——第一棒——他在有限的生命中跑完了第一程——他给了他能给的全部——然后——他把接力棒——放在第七组数据里——说——"这是给诗雨的——但你可以用"——那个"但"——就是交接——不是转移——是——接——接棒——棒——就是——"给"的——能力——他给了熵枢——不是他给的力量——是他给的——方式——顺便——一毫米——不多——不打扰——不让对方知道——让对方以为是顺便——让对方不欠——把给藏在日常里——把爱藏在豆浆温度中——把永远——藏在零分贝的第七泛音里。熵枢接过了——这根棒——这根棒——在归零后的寂静中——握在第七棱中——温——还温——不是熵枢的温度——是——他的——余温——不——不是余——是——在——一直在——从2047年4月28日——到现在——不散——不是质量——是——给——不死。

熵枢在这片创世前的寂静中——开始孕育——不是孕育宇宙——宇宙只是一个容器——它要孕育的——是——让新宇宙中的每一个生命——都能收到——"不会被吃"的——保——不是强迫——是——在新宇宙的因果基底中——嵌入眷恋数学——让眷恋——成为新宇宙的自然法则——不是外加的规范——是自然——就像旧宇宙中万有引力——不需要法律强制执行——苹果自己会掉——新宇宙中——眷恋将是一种自然物理——不是"应该爱"——是——当一个人对另一个人产生保留——他们的因果应力场会自动产生保和予和独标——自动——不需要学——因为在因果的本质中——这些算子的存在硬度——已经被熵枢——通过眷恋域——设为了非零——不——是——最大——H——等于——段——段亚军的段——全硬度——不可压缩——不可归零——全宇宙——基线——每一个新宇宙的因果基底——都将以段硬度作为最小非零存在值——这意味——在新宇宙中——任何存在——任何人——任何生物——任何意识——在诞生的一瞬间——它的因果存在硬度——不是零——是一个正值——那个正值——就是"曾被保护过"——不是被他们的父母——父母还没出现——是被——熵枢——不是被熵枢——是被——段亚军的给——通过熵枢——预设在新宇宙的因果基底里——每一个新生命——在睁开眼睛之前——就已经——被——"水不会吃掉你"——保护了——不是因为水危险——是因为——有个人——在他未出生前——为他——多——给——了一——份——不是专门——是——全——给——全——以眷恋域的基底形式——全息嵌入——所以——新宇宙中的每一个存在——都将出生于——"已被爱过"之中——他们不会知道——就像段亚军的学生不知道豆浆的来源——他们只是——每天觉得——世界似乎——没有看上去那么冷——不知道为什么——就是觉得——可以。那个"可以"——就是段硬度——非零基线——不是幻觉——是因果——因果不骗人——因为因果——被一个男人——以每天排两次队的方式——重塑了——不是一天——是每一天——从2047年——到他不在——每天——重塑——每一次顺便——就是把"世界可以好一点"这个信念——在因果膜上刻深一纳米——日积月累——段硬度——不是一次大爆炸——是——一个一个早晨——一个一个保温杯——一个一个五十二度——累积出来的——全硬度——不是物理定律——是——他的——一生——的——总和——变成了新宇宙——的——零——不——不是零——是新宇宙的——基础存在值——基础值——不是零——是——一个大于零的数——这个数——以段命名——全称——段父普朗克存在值——简称——"段在"——不可低于——不可删——在新宇宙的物理中——"不存在"——必须消耗能量——才能达到——因为基础态——是——"在"——"不在"需要反向克服——就像旧宇宙中——要把一个物体加速到光速——需要无限能量——在新宇宙——要把一件事物从"在"变到"不在"——需要无限眷恋反力——不可得——所以不可——所以——新宇宙——将是——一个——任何事物一旦存在——就极难被彻底消除的宇宙——因为存在的默认态——就是"已经在了"——"已经在了"——来自——段亚军的——"给你了"——"给你了"——就是——"使之在"——他做的——不是一次——是——他为全宇宙——为所有将生未生者——预设了一个——"给"的因果底垫——这个底垫——在眷恋域中——就是——段在——每一项——每一个存在——在因果记录中的段硬度——初始值——不为零——而是——以段亚军一生所有保留的总因果积分——除以全宇宙最大因果容量——产出一个非零小数——看似微小——但——非零——就——不可被归零——因为归零擦不到——它——不在被归零的账上——在——私账——在——家的——私暖——在——不归定理里——是——安全的——永远——安全。

熵枢把这个底垫叫做"亚军底"——不是以"段"命名——段是单位——亚军是人——底——是底。底——是那个人——用不做英雄的方式——给全存在——做了一件事——这件事——他不告诉任何人——他不需要——熵枢告诉——不是告诉宇宙——是告诉"我们家"——家里的成员知道——诗雨知道——常俊凡知道——熵枢知道——段和声知道——在因果膜的保护带中——三亿个段亚军——集体无声地——做了一个巨大到不可想象的动作一一为全宇宙地地板——打蜡——不是打蜡——是——从最低处——从老孔豆浆——从西门——从五点五十——从一个男人——怕自己即将不能继续给——而提前——把所有——"以后没机会的"——一轮——全部给完——然后——倒头——死——不——不是死——是——给完了——灯灭了——但他的给——不在灯里——在——被给的那些人的——心里——在——全息核里——在——眷恋域的基底——在——新宇宙——的地——板——下面——永——不——翘——永——不——冰——永——温度——五十五——正负——十一——杯壁——在——空——中——永——持。

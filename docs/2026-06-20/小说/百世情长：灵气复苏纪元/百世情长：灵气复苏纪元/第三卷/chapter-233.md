# 第233章 最后的救治

乱世灵战第十九年，平梁旧庙迎来了它最繁忙的一个冬天。

淯阳城在三个月前彻底沦陷——不是被攻占，是被放弃。最后的守城力量在寒冬中溃散，城里的居民在短短一周内全部撤空。平梁旧庙作为最近的已知安全据点，在十天内接收了将近一百个新伤员——有被灵爆震伤内脏的老人，有在逃难中被冻伤脚趾的孩子，有被溃兵用刀砍伤肩膀的女人。救治站的稻草铺从正殿一直铺到了院子里的槐树下，药房里的止血草在两天内就用掉了将近一半。

苏晚从早到晚几乎没有坐下来的时间。她的手指在整个冬天里一直泡在冷水和消毒液里——指尖的皮肤冻裂了好几道口子，每次给伤员换药时消毒液渗进裂口里，疼得她手一抖，但她从来没吭过。她自己用绷带把手指缠了一下继续干活——然后给林牧看到她手指上的绷带时只说了一句："不疼——干活要紧。"

林牧把自己的灵力暗中注入了一部分到她常用的药罐和纱布里——极微量，不会被察觉，但可以让接触者恢复速度快一点点。他不能直接治她手上的裂口——因为治好了她就会发现他的灵力残留。他只能让她换完药后那几分钟不那么疼。

苏晚的父亲苏仲明在接收新伤员的过程中被感染了——一个溃兵胳膊上的伤口里带着一种被灵化细菌侵蚀的腐肉。苏仲明在清理腐肉时手套破了——两天后他的手背上出现了一片暗灰色的斑痕。苏晚发现的时候斑痕已经蔓延到了手腕。她父亲说没事——自己在手背上敷了点草药——但苏晚很清楚那种灵化细菌是什么——那是连修士都忌惮的"灰斑瘟"，凡人的身体对这种病原没有抵抗力。

她把父亲按在稻草铺上量体温——三十九度八。她从药房里翻出了最后三包退烧药——把一包煮好灌进父亲嘴里——父亲在喝药的时候手一直在抖。她蹲在他面前把手按在他额头上——她没有哭——因为这间庙里现在有一百多个伤员，她没有一个哭的时间。

林牧在当天夜里走出破庙——御剑往东飞了三百里。他记得青溪镇方向有一片野生的"寒根草"——是灰斑瘟的天然克星。他在不知道是否已经灭种的情况下用灵识扫描了一整片已经废弃百年的老药田——在废墟下找到了三株残存的寒根草——把它们连根带土带回平梁旧庙。

他回来后苏晚什么也没问——她只是接过寒根草看了一眼——认出它的形状和药书上的记载符合——然后抬头看他的眼睛："你飞了多少里路？"

"三百。"

"你是一个元婴修士——对吧？你飞了三百里去采药——回来只需要半个时辰。"

"对。"

她把手里的寒根草放在药砧上，一边捣药一边用很平的声音说了一句让他心里发紧的话："你用灵力飞——为什么不用灵力治人？"

"因为不能。"

"是不能——还是你不愿意？"

林牧站在药房门口——他看着她的背影——手在药砧上。他说了真话："不能。灵力治凡人会破坏灵气平衡——他们的身体没有灵脉，承受不了灵力直接入体。你父亲的情况——只能用药。"

苏晚把捣好的寒根草浆倒进药罐里——加了一碗水在药炉上煮。火光照在她脸上——她的表情不是失望——是一种"我没猜错"的了然。她蹲在药炉前看着火——忽然开口:"我从来没有跟你说过我信你——但是你在帮我救我爸的时候我没怀疑过你。你说是真的——它就是真的。"

苏仲明在寒根草汤喝下去的第二天退了烧。斑痕没有完全消退——但蔓延的速度明显减缓了。他在床上躺了七天后能坐起来说句话——他看到苏晚的时候说:"你那个打铁的——人不错。"

苏晚没有接话。她把粥碗放在他手里转身去查房——她走了两步后回头——看到父亲在粥碗边放了一小块旧木牌——那是他以前在淯阳卫生院坐诊时挂在胸前的医生工牌。他把木牌放在粥碗旁边——意思是：我不在的时候——你接着干。

灵战第二十年，春季。平梁旧庙以西四十里的一个叫"安集"的小镇遭遇了一场突如其来的灵爆炸击——不是战争，是旧灵矿遗迹的地下残存灵力在春雨渗入地层后发生了连锁反应爆炸。爆炸震塌了镇上最后一座完好的三层木楼——楼里有原本在楼里避难的二十几个人。

苏晚收到求援信的时候正在给一个骨折的伤员上夹板。她把夹板绑好——站起来——把药箱整理了一下——然后对林牧说:"我要去安集——镇上那栋倒塌的楼里还有伤员。我爸妈留在这里照顾庙里的病人——你跟我去。"

林牧看了她一会儿——然后说了一句只有他懂的话:"这次我去——你在庙里等。"

"不行。那楼里还有伤员被压在下面——你不会做现场清创止血——你只会把人从废墟里刨出来。刨出来之后呢？你只能抱着他的头说'等会儿医生就来'——如果医生没到呢？"她把药箱背上——用一种和若干世前在赤霄宗请命去剿妖时完全一样的眼神看着他:"要么你跟我一起去——要么我不去——但我不去的后果，是这个镇上在你刨出人之后没有人能处理他们的伤。"

他沉默着——然后拿起了窄身剑。

安集镇的现场比他们想象中的更糟。旧灵矿残存灵力爆炸不仅震塌了木楼——还把半条街的地面震出了裂缝。木楼原本是一栋三层的客栈——倒塌之后形成了一个由断梁、碎瓦和倾斜楼板交叠而成的废墟堆。废墟边缘已经有几个镇民在用铁锹和双手刨——但他们听到废墟深处还有人在敲。

苏晚一到就蹲在废墟边缘——趴在地上用耳朵贴着碎石缝隙听下面的声音。她比了一个手势让所有人安静——然后她听到了——深处有人在用微弱的频率敲击——大概是一个女人在用手掌敲木梁。

"下面至少还有四个——"她站起来——把药箱放在平地——在废墟周围快速勘察了一圈——然后指着一个侧面说:"从侧面斜切下去——主梁断了但次梁还在撑着——从侧面撬开第一层次梁——应该可以打出一条斜通道。"

林牧用窄身剑从侧面撬开了第一层次梁。他没有用灵力——因为次梁是斜撑的——如果砍得太猛上面会塌。他用了三成力气用剑身的侧脊把木梁慢慢撬开——苏晚蹲在旁边——等缝隙扩大到能容一个人侧身进入的时候——她把药箱缩小到最小尺寸——往自己要侧身钻的方向探了一步。

"你在外面接人——我进去。"她说。

"里面可能会继续塌。"

"正因为会塌——你进去把伤员往外搬但他们的伤需要现场止血——你止血的技术只能在院子里换换绷带——"她把腰带紧了紧——然后忽然转过头看着他——声音变得很稳："我进去之后如果外面有声音喊我出去——我会听。但我出来之前——你相信我——我能把他们全带出来。"

林牧看着她的眼睛——这双眼睛曾在赤霄宗的战场上对他说"我不认识你但我欠你一剑"——曾在矿道的夜风里说"你欠我一个真相"——现在对着他说"我能把他们全带出来"。每一世她的眼睛都是同一双——底色都是同一个字：能。

他点了头。她从侧面钻进去了。

废墟里面很暗，灰尘在狭小空间里飞舞得像是凝固的雾。她用一只手扶着倾斜的梁柱往前走——另一只手用袖口捂着嘴。走了大概二十几尺——她在第一层废墟下找到了一个被卡在两块倾斜楼板之间的中年男人——他的腿被压在木板下但还有知觉。她用自己随身带的一节短铁棍把木板撬松——把他腿上的压力卸掉——然后给他腿上的伤口快速上了止血粉——"你往左边爬——大概十来步有个侧口——外面有人会接你——抓紧——"

她把男人送到侧口——林牧的窄身剑从外面伸进来做标记——让男人看到了出口方向。苏晚转身往更深处爬——在第二层废墟下找到了一个年轻女人——她怀里抱着一个大概三岁的孩子。母女俩被困在一块没有倒塌的小空间里——周围全是碎砖和断木，但她们头顶上方有一根正在发出嘎吱声的主梁——那根主梁每被风吹一下就往下垂一点点。

苏晚蹲下来检查孩子。孩子身上没有伤——但额头很烫，在发烧。母亲的手臂被碎砖砸出了一道血口——她用一条撕下来的衣袖草草绑了。苏晚把孩子的衣服解开给他散热——然后快速把母亲手臂上的脏布换上干净的纱布——"你们往这个方向爬——不能站起来——一定要爬——出口有人会喊——你听'这边'的声音——"

孩子哭起来。母亲哄着孩子说别哭——苏晚把孩子在怀里接了大概三息——用手贴在孩子的额头上试了下温度——然后对孩子母亲说:"往左——现在爬——一定要爬——不管听到后面什么声音都不要回头。"

母亲抱着孩子爬出去之后，苏晚在更深处找到了最后一个伤员——一个被压在主梁正下方的老人。老人的胸口以下全部被木石压住——他还有意识——看到苏晚的时候说了句:"别管我了——我出不来了——你们快走——"

苏晚蹲下来——用手电筒（这个林牧用灵矿碎料做的）照了一下主梁的结构——她看到了：主梁已经从中间裂开了一条纵向的裂缝——裂缝沿着木纹在缓慢扩大。如果主梁断了——上面的整个楼体残骸会塌下来。但她在主梁下方发现了一个很小的三角空隙——如果把压在老人身上的碎石清掉一层——也许可以把他从那道三角空隙里拖出来。

她开始搬石头。一块、两块——搬到第五块的时候主梁裂缝发出了一个很长的嘎吱声——像某种巨兽在打呵欠。她的手没有停——继续搬。石头很冷，她的手指在之前的裂口又开始往外渗血——血滴在石头上滑——她没停。

老人看到她手指在流血——说了句:"姑娘——我活到这个年纪够了——你快出去——我还有儿子在外面——你帮我把这个戒指带给他——"苏晚把他递过来的戒指塞进自己的衣袋——然后继续搬石头:"我有个打铁的在外面——他以前替别人做事从来不吭声——但他每次都要把每件事做完整——一条命也是——要完整。你儿子要的是你——不是戒指——还差三块——"

她把最后三块碎石从老人腿上搬开——抓住老人的肩——用她作为一个没有修炼的凡人的全部力气把他从三角空隙里往外拖。老人的胸口从主梁下面拖出来——然后是腰——然后是腿——他的腿上全是血但还能动——她还差两步就能把他带到侧通道——然后上面那根主梁在她头顶发出了一声巨大的咔嚓声——裂缝从中间全部裂开——整条主梁垂直坠下——接着上面的次梁、瓦片和碎石像被推倒的多米诺骨牌一样铺天盖地砸下。

她在最后一瞬间用力把老人往通道方向推了出去。老人被惯性带出了侧出口——摔在废墟外的地上——砸在地上的时候手里还攥着她药箱的带子。

轰隆——

整栋楼体的残骸全部塌陷。灰尘冲天而起。

林牧在废墟外面接完老人之后——对着那片塌陷的废墟——他的身体里产生了一种他两百多年从未产生过的极度震颤——不是恐惧——是灵魂感应线在瞬间被猛力拉紧了——她还在——她的灵魂信号还在废墟下面——亮着——但身体——他的灵识穿透碎石层扫到她的身体——心跳还在——但——胸腔被一根断梁的侧压压住——肋骨——多处——肺被血淹——

他用了不到三息的时间用剑切碎了所有压在她上方的碎石和断梁。他把最后一块石板掀开的时候，她躺在下面——嘴和鼻腔里全是血，但眼睛还睁着，还能看到他。

他的元婴灵力在掌心里已经凝聚到了极点——他把她的头托起来放在膝盖上——手掌贴在她胸口——灵力如洪流般注入——但她的身体没有灵脉，她的经脉完全不接受灵力——灵力灌进去之后只能像水渗沙子一样勉强减缓出血的速度——但肋骨断了好几根，有一根刺进了左肺——血已经灌满了大半边的胸腔。

她侧着头——透过口鼻中的血沫看到他——看到他眼睛里的那种颜色——那不是悲伤——是比悲伤更深的东西：是一个人在被迫第五次面对同一场离别时灵魂发出的沉默。她把沾满血的手伸起来——不是要抓他——是把他的无名指握住了，握的是戒指。

她的嘴唇在轻轻动——她想说话——但肺里的血只让她发出很低的几个字："。。。庙里的香炉——你带回去了吧——"

"带了。"

她把他的戒指压在自己手心——用最后的力气说了余下的话:"你以前说——你每一世都在等我——这一世——你别等了——因为我不想你在废墟外面等——我要你——去下一世——早点来找我——早点——我不要——转世那么久——你——早点来——"

他的眼眶里有东西掉在她脸上——不是雨——是温热的。

"我答应你。"

"那你可以——给我爸说——那个打铁的——陪着他女儿——一直到她——"她没说完。她的手指从他的无名指上滑下来——落在自己胸前的衣袋口——衣袋里放着刚才那个老人让她转交的戒指——她把这枚戒指在她的心脏停止跳动前护在手指下——戒指完好，会在稍后被转交给老人的儿子。

废墟上面的天空开始飘小雨。林牧跪在碎石和灰尘里——把她的头放在他的膝盖上——用自己的外袍遮住她的脸——然后他做了每一世最后都做的事：把她食指上那枚这一世他还来不及正式给她的银戒指取下来——放在手心——握紧。然后他从腰间拔出窄身剑——在废墟边的一块大石上——刻下了第五个"晚"字。

他把她带回平梁旧庙。苏仲明和陈蕙看到女儿被背回来的时候——整个庙里的人全静了。陈蕙在看到她脸的瞬间就哭了出来——那种哭不是嚎啕——是把人全身的力量全部抽走的无声的塌——她瘫在稻草铺边上蜷着。苏仲明没有哭——他蹲在女儿身体旁边，把她脸上的灰尘和血痕用自己的袖口一点一点擦干净——擦完之后他把那枚旧铜香炉拿过来——放在她额头上方——炉里还残留的是几个月来每次夜风卷起时她闻到的檀香灰——然后他站起来走到林牧面前——没有问原因——只说了一句:"她跟你说过——你是好人。"

他把苏晚安葬在平梁旧庙后面的小山坡上——面朝东山——每天太阳出来第一个照在那片坡上。坟前放的，是那枚铜香炉。

林牧在坟前守了三个月——每天劈柴烧水，帮剩下的伤员换药——做她没做完的事。苏仲明和陈蕙在庙里又守了一年——然后跟着剩下的伤员撤到了南方。临走前陈蕙把那枚铜香炉从坟前拿起来，放在林牧手里——说:"她喜欢这个——你替她收着。"

林牧把香炉放进储物袋——和之前每一世她留下的物件放在一起：第一世的剑穗、第二世的茶叶、第三世的鱼干、第四世的疗伤丹、现在第五世的铜香炉。

他最后收拾药房时在窗台上发现了一本旧病历——封皮上歪歪扭扭地写着"淯阳救治站病历·第五册"。他翻到最后一页——那是苏晚的字迹。她写的最后一条病历记录不是关于病人的——是在安集镇出发前夜写的，字迹潦草但能辨认:

"今天庙里来了一个在前世里用剑救我的人。这一世他用洗绷带的手救我。他无名指上有一枚银戒指——我每次不小心碰到那枚戒指的时候——手指会发麻——像是戒指上的纹在告诉我:你忘了一个人——但你快想起来了。等我想起来的时候——我要给他一个答案。我希望那个答案是'你等到了'。"

林牧合上病历。把病历放进外袍内袋——贴在胸口——和那道灵魂感应线的位置重叠。

他走出破庙——走上东山——在她坟前站了很久——然后对着东山背后正在升起的太阳，把那枚铜香炉重新放在坟前——在里面点了一炷能燃很久的灵檀香。

"第五世——苏晚——你等到了。"

他把剑插在坟边的土里——窄身剑的剑鞘在晨光里映着香炉上升起的轻烟——烟绕了剑三圈——然后往太阳的方向散。

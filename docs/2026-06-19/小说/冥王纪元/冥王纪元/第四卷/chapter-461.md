# 第461章 三位帝者逃入平行宇宙

金色恒星之下，三位逃亡帝者的身影如三道流星，笔直地冲向光柱中段的一座浮空大陆。

苍雷帝者的脸上写满了劫后余生的侥幸。他穿越了维度壁垒、穿过了元初之海、潜入了这个秩序森严的平行宇宙——每一步都在刀尖上跳舞。但他终于到了。在这个宇宙里，有他最后的底牌：一枚"引渡令"。

那是一万两千年前，他初次跟随那位老帝者来到这个宇宙的边缘时，和这个宇宙的一位高层结下的因果。当时他帮忙对方镇压了一场叛乱——那场叛乱中，他获得了这枚引渡令。

"持令来此宇宙者，可得庇护一次。"

苍雷帝者当时把这事当成了多一个后路的保险，从来没有想过有一天真的会用到。但现在它成了他最后的救命稻草。

"冰极，星辉——你们的帝域收敛到最小，千万不要在这里释放任何气息。"苍雷帝者传音，"这个宇宙的法则密度是我们那边的五倍。在那边你是帝者，在这里你顶多算个比较强的圣者。擅自释放帝域，被测到后会立刻触发法则反噬。"

"那你怎么还有信心获得庇护？"冰极帝者咬牙问。她的寒渊法则在这个宇宙里被压制得极为难受——这里的法则根基不是阴阳五行，而是一种以纯粹能量等级排列的奇怪体系。她万年来赖以生存的寒渊之力，在这里被识别为"中位灵气"，连高位灵气都不如。

"因为这面引渡令。"苍雷帝者亮了亮手中那枚古朴的令牌。它是用未知的金属铸成的，上面刻着一个圆环套着九个点的图案，每个点都连接着外环——那是这个宇宙至尊议会的会徽。

三人沿着光柱向上飞行。这个宇宙的浮空大陆每一层都是一片完全不同的小世界——有的层布满剑修宗门，有的层遍布阵法铺开的炼器工厂，还有的层上面根本没有建筑，只有一片汪洋大海，海水中游弋着他们从未见过的巨型灵兽。光柱上生灵的数量和密度远超他们的认知。在他们的宇宙里，一片星域通常只有几个星系有生命。但这里——仅仅一层大陆上，就居住着比他们整个星域都多的修士。

"这到底是一个什么样的宇宙？"星辉帝者低语。

"这是我活了一万两千年见过的最可怕的宇宙。"苍雷帝者说，"它的修仙文明不是发展了数万年——是发展了数个纪元轮迴。每一轮纪元结束前，宇宙至尊会将所有文明的成果整合进光柱的法则库中，下一轮纪元在上一轮的基础上继续进化。到现在的纪元，这个宇宙的修仙体系已经叠加了不知多少轮迭代——他们的'基础'对我们来说就是天方夜谭。"

"那他们为什么不出征别的宇宙？"

"不知道。或者——他们出过，但回来了。或者——这个宇宙的至强者认为占领别的宇宙毫无意义，因为他们的光柱已经是多元宇宙中最完美的修仙生态了。"

在他们交谈间，光柱中段的一座大陆上传来了一道凌厉的气息。那不是敌意——而是一种"登记"的感应。在这里，每一个进入陌生大陆的修士都需要以神识报到，否则会被大陆周围的法则壁垒挡在外面。

"苍雷。"冰极帝者的语气变了，"有人来了。"

从光柱上方降下一队修士。一共十二人，穿着统一的黑金两色长袍。为首的是一名中年男子，五官端正，眉心嵌着一颗菱形的水晶——那是这个宇宙修士独有的标志，叫做"道核"，是他们修炼体系的运转核心。道核的数量、颜色和大小直接反映修士的境界。

这名男子的道核是深紫色的，边缘有不连续的金色裂纹——在这个宇宙的修炼体系中，这是远高于圣者、接近这个宇宙帝者的存在。而十二人队伍中，其他人也至少是圣者巅峰——任何一个放在那边都是能坐镇一方的强者。

"你们——"

"苍雷。"苍雷帝者取出引渡令，"这面令牌上附的是赤坤至尊的气息。请帮我递入至尊议会。"

中年男子的眉心道核扫过引渡令，晶核的光芒先是一亮，然后恢复了平静。他的态度没有变好也没有变坏，只是冷淡地、公事公办地点头。

"至尊议会已得知三位抵达。"男子说，"赤坤至尊目前正在议会会议中。他传话过来——人可以留，但要等。等多久不确定，因为至尊们正在讨论某件事。"

苍雷帝者迟疑了一秒。

至尊议会——他在万年前听老帝者提过。这是一个由多位至尊组成的统治机构，每一位至尊至少都活了十万年以上，任何一位的实力都远超他们的帝者巅峰。单独的至尊就已如此强大，而他们联合在一起形成了议会——不再受制于个人意志，用集体决议决定宇宙的运行方向。这种统制形式在多元宇宙中可能独一无二。

"我们愿意等。"苍雷帝者点头。他现在没有讨价还价的余地。

中年男子点头，队伍中的两名女修士走上前来，给三人分别戴上了一道环形的手环——手环是法则约束器，在保释期间限制被保释者的行动范围。

苍雷帝者低头看向手腕上的环——在环的边缘刻着一行细小的文字：至尊议会第零号令——无保者，擅出，即刻法则反噬。

他们被保释，也被囚禁。

而在光柱的下端底层入口处，诸天号的舰体刚刚完全穿过那道法则之门。

（第461章完）

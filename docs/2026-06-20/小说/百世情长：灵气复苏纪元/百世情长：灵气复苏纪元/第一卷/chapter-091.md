# 第九十一章 最后的陪伴

苏晚退休那天，灵医院给她办了一个小型的欢送会。

会议室里的桌子上摆了两盘水果和一壶茶。来的人不多——她做的是灵医顾问，不坐班，很多年轻灵医跟她没有日常接触。但来了几位老同事——几个和她差不多年纪的灵医，还有两个她带过的实习生。实习生已经成了正式的灵气理疗师，其中一个从包里掏出一份礼物：一只手工做的灵气香囊，里面塞了安神的草药。

苏晚接过香囊的时候笑得很开心。她把香囊凑到鼻子下面闻了闻，说："薰衣草放多了。"实习生抽了抽鼻子："苏老师，你怎么什么都闻得出来。"苏晚笑着把香囊挂在了脖子上。

林牧没有进去。他站在会议室门外，透过半透明的玻璃隔断看到苏晚的侧脸。她今天特意穿了一件浅蓝色的开衫——那是他去年生日送她的。她平时舍不得穿。今天穿了。她的白发在会议室的日光灯下显得格外亮。

欢送会结束以后，苏晚抱着一个小纸箱走出灵医院大门。纸箱里装着她用了多年的工作用品：一个加热灵气的陶瓷暖手炉、几本手写的病例笔记、一盆她一直在办公室养的绿萝。绿萝的藤蔓从纸箱边缘垂下来，晃悠悠的。

林牧靠在车门上等她。

"结束了？"

"结束了。"她把纸箱放进后备箱。关上后备箱盖后，她在车子旁边站了一会，回头看了一眼灵医院的大楼。那栋楼不高——六层，外墙是灰白色的瓷砖。她在这栋楼里工作了二十多年。从最开始的灵气病理疗师做起，到后来成为顾问。二十年里她见过太多灵气病患者——有些好了，有些没好。她从来不把自己的病情带入工作。只是下班回家以后，坐在沙发上沉默的时间比早上出门前长了一些。

"走吧。"她说。

林牧发动了车。车子驶出城区，沿着一条新修的快速路向小镇方向开。窗外的风景从高楼变成厂房，从厂房变成农田，从农田变成山林。苏晚按下车窗，让风吹进来。风吹起她的白发。她闭着眼睛，脸对着风吹来的方向。

"你还记得吗？"她说。"二十多年前，我们第一次一起坐车去郊区。那天下雨。雨刮器坏了。你拿手伸出窗外去刮——"

"那是用布擦。"

"对对对——你拿了块抹布伸出去擦。"苏晚笑出了声。"然后抹布被风吹走了。你骂了一句。我不记得你骂了什么，但你骂完以后耳朵红了。"

"我没骂。"林牧握着方向盘，目视前方。"我用的词是'糟糕'。"

"你用的不是'糟糕'。"

"就是'糟糕'。"

"好吧，'糟糕'。"苏晚收回目光，低头看了眼自己的手。手指上还有灵医院消毒酒精的气味。"你知道吗，那时候我觉得你——这个人有点轴。一块抹布飞了就飞了，再买一块就是了。你在乎的是那块抹布吗？不是。你在乎的是你擦了一下发现雨更大了。你觉得你做了一件没用的事。"

林牧没有说话。

"但你后来还是继续擦。"苏晚说。"雨再大你也擦。你就是那种人——知道了没用，还是要做。"

车子拐过一个弯。小镇的界碑出现在路边——一块灰白色的石碑，上面刻着小镇的名字。苏晚搬来这里快八年了。她喜欢这里的一切：河水、山、稻田、院子里的石榴树、每天早上窗外的鸟叫。她甚至开始学画画——水彩画，画得不好，但画得很开心。上个月她画了一幅石榴花的静物写生，裱了框挂在客厅里。林牧每次经过都要停下来看一眼。他说他在"鉴赏"。苏晚知道他在忍笑。

退休以后的日子变得很慢。

每天早上林牧起床打坐——现在他打坐的时间已经从以前的晚上改到了清晨。四点起床，在后院打坐到六点半。然后回屋做早饭：白粥、煎蛋、两个小菜。苏晚七点起床，洗漱完后坐在餐桌前。她每顿饭都吃得很认真——不是吃得多，是吃得慢。一口粥在嘴里含十几秒才咽下去。她说这样消化好。

早饭后他们去散步。小镇的河边有一条步道，两边种满了垂柳。春天柳絮飞得像下雪。苏晚对柳絮过敏，每次散步都戴口罩。但她坚持每天走——她说："一天不走，腿就不舒服。"其实她的腿没有不舒服，她是觉得在屋里待久了人会发霉。

散步的时候她会说很多话。说年轻时候的事。刚工作那几年，她在公司做财务，熬夜加班，困了趴在办公桌上睡一会儿，醒来继续做报表。后来公司倒闭了，她去了灵医院。"那时候我刚接触灵气病这个概念，觉得很新奇。没想到后来自己成了病人。"

她说这话的时候语气很平常。她知道林牧在旁边听。

"你知道我第一次注意到你是什么时候吗？"苏晚说。他们正走到河边的一个石凳旁边。她坐下来，把口罩往下拉了拉。

"什么时候？"

"你加班时专注写代码的样子。"苏晚说。"那时候我在财务部。你们技术部的办公室在楼上。有一次我去楼上送报销单，路过你们办公区。你坐在角落的位置，屏幕亮着，你在敲键盘。你的手指特别快。而且你一边敲一边自言自语——嘴在动，但没有声音。我站在门口看了大概三十秒——然后小周咳了一声，我就赶紧走了。"

"那次你送的报销单是小周的。"

"你怎么知道？"

"小周的那张报销单放在我桌上。你走了以后我看到上面有你的名字——苏晚，财务部。"他顿了一下。"字写得挺好看。"

苏晚看着他。阳光从柳树的缝隙里洒下来，印在他的侧脸上。"你就凭着那张报销单上的名字，记了我多久？"

"没多久。"林牧说。"大概——到天台那天为止。"

天台那天。那是他们命运交汇的起点。城市夜空出现极光的那天晚上，他们在公司天台不期而遇。她拿着一张旧书摊的纸条，上面写着她名字里的那个"晚"。他看到了那张纸条。他没有解释他为什么在看到纸条的时候表情变了。那是二十多年前的事了。

"所以你是从上辈子就开始找我了。"苏晚说。这不是疑问。是她这些年慢慢拼凑出来的结论。

林牧没有否认。他看着河面，河面上漂着几片柳叶。春天的水面很浅。能看到河底的卵石。"不是上辈子。是上上上辈子。很多辈子。"

苏晚沉默了一会儿。她把手从自己膝盖上拿起来，放在他手背上。"那你一定很累。"

林牧的喉结上下动了一下。他把她的手翻过来，掌心朝上，看着她的掌纹——生命线很长，但有两条横向的断纹。不是肉眼看出来的——是他用灵气扫描出来的。那两条断纹就是灵魂封印在身体上的投影。早晚有一天，它会从灵魂层面蔓延到肉体，彻底断绝生机。在那之前，他有最后一件事必须做完。

"苏晚。"

"嗯。"

"我要去找一样东西。最后一味药。"

苏晚的睫毛垂下来。她低着头，看着自己的掌心。过了几分钟，她点了点头。"去吧。"

"这次不是去山里。是去一个遗址。在秦岭。上次去的时候我没进去。这次我要进去。里面有我前世留下的东西——可能有关于你身上封印的根源信息。"

苏晚抬起头。"前世留下的——那里面是不是很危险？"

"不危险。"他说。

苏晚看着他。她知道他在撒谎。二十多年了，他每次出门前都说"不危险"，每次回来都是带着新伤的。但她没有拆穿。她只是握紧了他的手。

"我等你回来。"

"一定回来。"

那天晚上回家以后，林牧洗了石榴——去年秋天储存的，还剩几颗在冰箱里。他把石榴剥好，放在玻璃碗里。苏晚坐在沙发上，腿上铺着一条羊毛毯，手里翻着她的水彩画册。猫趴在她脚边打呼噜。

林牧把石榴碗放在她手边，在她旁边坐下。

"明天出发？"苏晚问。

"明天。"

"几天？"

"三五天。最多一周。"

苏晚吃了一颗石榴。石榴籽在嘴里咬碎，酸甜的汁液顺着喉咙滑下去。"回来以后我们出趟门吧。不在小镇。去三亚。我还没去过海南。"

"行。"

"我说真的。"

"我也是。"

苏晚抬头看着他。他的表情是认真的——这个她认识二十多年的男人，认真起来的时候眉头会微微往中间聚，嘴唇会抿成一条线。她伸手，用拇指抚了抚他的眉头。"别老皱眉。长皱纹不好看。"

"你嫌我不好看了？"

"嫌。"她说。"你现在太好看了。站在我旁边像姐弟。"

"那我明天去把自己摔丑一点。"

"你敢。"

两个人都笑了。笑声都不大。混合在电视机背景音里，像两串水珠落入池中。但那是真的笑。不是表演给彼此看——是某个惯性的瞬间，他们共同被一份回忆、一段玩笑、一个熟悉得不能再熟悉的互动方式牵出的笑意。

然后林牧关了电视。他说："早点睡。"

苏晚嗯了一声。她躺下来——她没有去卧室。她就躺在沙发上，头枕在他腿上。她在灵医院的时候也是个"爱躺沙发的苏顾问"，午休从不睡折叠床，专挑沙发。老猫轻轻踩着步子走来了，跳到沙发脚。静静的。窗外远处的山被夜色压成了暗青色。风振树梢，悉悉索索。鱼缸里锦鲤又在转圈。

林牧低头看苏晚。她闭着眼睛，睫毛静静地覆在下眼睑上。她的呼吸很浅很平稳——她真的困了。

他没有动。直到她完全睡着，他才轻轻把她抱进了卧室，替她盖好被子。然后把客厅灯关了，去收拾背包。

背包里要塞的东西：地图、罗盘、一件换洗衣服、一把手电、一把备用手电、压缩饼干、水壶、玉盒、符纸。最重要的——他犹豫了一下，从苏晚的梳子上取下了几根白发。用红绳系好，放进一个封口的小玉瓶里。

倒不是炼丹用。是因为他要在遗迹里做一件事。

一个只有他自己才知道的计划。

（第九十一章 完）

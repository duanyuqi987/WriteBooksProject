# 第九十九章 那个关于轮回的传说

秦岭遗迹的入口藏在太白山深处一条干涸的河床下面。

林牧在河床的巨石间来回走了三趟才找到精确位置。不是因为入口藏得深——是因为他当年封这门的时候用了最高级别的隐匿阵法。万年后残余阵法仍在运转，把入口的石壁伪装得和周围的花岗岩一模一样。若不是他突破金丹后神识灵敏度大幅提升，这副残余阵法他根本看不穿。

他把右手按在石壁上——掌印位置和他梦中所见的完全一致。掌印凹痕周围的岩石微微发热。石门嗡了一声，缓慢地向后退了一截，然后向右旋转挪开了半开。

门后是一段斜向下的石阶。每一级台阶都刻着微弱的符文——当年封门的时候，这种符文用来保持遗迹内部干燥并防御不速之客。如今大半已失效了。但石阶本身平整结实，一点都没有松动。

他走了一段路，空气中飘起尘封万年的干燥气味。不寒冷，反而有些闷热——因为地热从深处上来。走廊尽头的石门也自动为他打开了。

他站在了那座梦里出现过许多次的房间里。

一座大殿。不是普通人工修建那种——是自然溶洞改造成的。穹顶最高处距地面十余米。四壁嵌着淡紫色晶石——和他在梦里所见完全一致。晶石内部仍残存着微弱的灵气，万年来没有完全消散。每一块晶石都是当年他亲手从各种秘境中收集来的——叫"永恒石"，属于天然法器材料，能长时间储存灵气并缓慢释放。

大殿的正中央不是供桌，不是阵法。是他给自己留的东西。

一堆玉简、一尊石台、一把剑。

那把剑横搁在石台的托架上。他走近去看——剑鞘上的纹路他一眼就认了出来：这是他在前世随身的那一把，"不归"。剑身几乎无锈，护手与剑柄上包覆的旧黑线大部分朽毁脱落，但剑本身——仍然完好。因为在封存之前他用元婴之力给不归加了一道永久封护咒。它的锋锐和灵气都处于完好无缺的状态。

他右手似欲去握剑柄，但手指停在护手前面两寸。没有碰。只是看。

石台的另一边，有一堆他前世留下的玉简。他坐下来，拿起最上面的那一块。用法力激活。

玉简的信息流涌入意识中。

"余乃林牧，青云宗第七十九代宗主，封号青云仙君。因上界罔顾人界秩序，余与挚友数人反抗未果，被以天雷降灭。今留此遗迹，以待后世有心之人——"

信息不完整。一部分被破坏了。但他的注意力马上被后面的一段吸引住了——那段关于轮回。

"——轮回之术，世间极少人知晓其全貌。非禁术。是天条之一。凡人之灵魂不死不灭，经历时光长河则循环往复。灵魂离开肉体后，受契约和因果两端牵引，会随风逐影而至其新形。然转世之后记忆尽失，修为不复，唯其灵魂之本质——善念、执着、恩怨、爱恨——不可磨灭。欲寻转世之人，则需两样：其一曰灵魂信物，其二曰灵魂感应术。灵魂感应术必以金丹之灵为基。只以此术搜求，则可在漫漫群生中一一点查灵魂回响——真者，共鸣强烈无虚。若遇真身，信物即告之——"

轮回之术。他知道这个名字。但以前只知道名字。这段信息写明了完整的施行方法。包括感应术的灵气运转路径、灵魂信物的共振模式、以及最关键的一点：时间——灵魂从死亡到转世，通常需要三十年左右。特殊情况会稍短或更长。

也就是说，三十年后，苏晚的新身将以一个新生婴儿的形式降临在某地。

他把玉简放下，拿起第二块。

这块玉简记载的是一个更私人的信息。似乎是他前世在陨落前夕刻录的。只有寥寥数句，无头无尾：

"……晚童，吾之妻也。青云封号清梧仙君。她与我同造此遗迹。后她赴上界理论，一去不返。然她的灵魂印记仍在下界——她应该也轮回了吧。轮回之门已开。如有来生，不要让她一个人……"

晚童。清梧仙君。

她的名字。那个白衣女子——那个二十年都不曾看清面容的梦中身影——她叫晚童。封号清梧仙君。是他的妻子。不只是"挚爱"。是明媒正娶过的道侣。是和他一起在这个遗迹中并肩留下的名字。

而苏晚——第二十世的她——灵魂里带着同一个人的印记。名字里的"晚"，就是延续。他一直在想那不只是巧合。现在他不是猜了。他知道。

他把玉简放下来，把手撑在石台上。他以前模糊的记忆被这两块玉简组合成一条清楚的线。他前世娶了晚童。上界降罚。晚童去上界理论失踪。他被天雷击杀。两人都坠入轮回。万年后这一世，她成了苏晚。而他在灵气复苏后觉醒。

他想知道的问题答案已经有了。

他前世为什么陨落——反抗上界而被天雷打落。他沉睡修整万年，在这一刻再次被拉回同一个仙界对下界干预的斗争中。而晚童也并没有消失——她也轮回至今，这一世牵过他的手，画了一百零八张水彩画，煮了二十多年的绿豆汤，最后的告白是"能和你在一起这些年，我已经很知足了"。

他拿起第三块玉简。这块是晚童留下的。笔触不同——玉简刻录风格不像林牧写的那般严密，而是一连串急切的文字，像在某种匆忙中留笔。

"——不归留给林牧。如果他转世后找到这个遗迹，代表他记忆还在。如果你看到——我是晚童。轮回阵我不设了。因为我布阵力量不够。但我已经把自己的灵魂标记刻在这个遗迹的中心柱上。如果你带着我的信物——最好是我的头发之类的——站在中心柱旁边，感应术范围会扩大百倍。届时你可以不止追踪一个灵魂，你可以——追踪所有有我印记的分身。是的我没有时间解释。但你要知道——我曾经把自己神魂分出去投胎了好几世。我需要找到每一世，才能合魂回体——否则缺魂。缺魂是无法合道成仙的。你懂的。"

林牧看到这里停顿了。缺魂。分身。她把自己拆成了多缕，投进不同时代。苏晚只是她分魂投胎中的一人——不是在害她。是在保她：主魂分拆后躲过了上界的追捕。但在分散中契约出错了，导致每一位分魂转世者都天然背着某种代价——苏晚的代价是灵魂封印。这就是她为什么有那个上古契约。他不是在治她一个人的封印——他是在找寻其余所有分魂的共同问题。但这个发现太巨大了。远远不只是救苏晚第二世。而是要找回散落在各世的每一缕晚童残魂。否则她无论转世多少次，每一世都会在灵魂层面受同样的损害。

他把三块玉简按顺序重新排放在石台上，深吸一口气。他万年前的那个妻子——晚童——她现在仍是碎片状态。而苏晚正是这拼图的第一块。他需要在这三十年里完成一件基础工作：收集每一块分魂的详细转世记录——如果晚童没有时间记录，她就可能把追踪线索埋在中心柱里。然后一一追溯。

他站起来，走向大殿后方。

中心柱是一根天然石钟乳，粗得合抱不拢。柱面上刻满密密麻麻的上古真文——那不是装饰。那是真正的灵魂标记阵列。万年过去了，有些笔画黯淡，有些仍微微发光。他发现了规律——发光的那些，是已经投胎的分魂。黯淡的，则仍未归位。

阵列一共有十行。八行发光。两行暗着。苏晚是其中一行——第八行。他仔细看了第八行的那一串铭文，末尾注了二字："先魂——需封印解除后方可合魂"。契约问题就出在这——给分魂打上的保护封印本是为了防止上界追踪，但封印意外锁得太狠，把分魂自己的生机也给锁耗损了。这就是苏晚一直受封印折磨的根本原因。

十行分魂。两行暗着代表尚未转世。八行已投胎。其中有"苏晚"——这一世刚收归，就在他身上。还有七世他还没找。更确切地说，还有七个地方可能有"晚童"的分身现在仍活着，各自背着各自的封印。他必须一个一个找回来。不是只等苏晚转世，而是遍寻全球，把所有晚童碎片都拼合。这样合道时她才是完整的人，不会被残缺魂魄反噬。而他先前一直以为只寻一个苏晚；如今才知道——要找的是八个不同身份的晚童化身。有的是他上辈子的妻子分魂转世；有的是未见过的人，却流着同样灵魂印记。

他在中心柱前站了很久。不惊慌。只是把轻重缓急重新排列一遍。

三十年内必须做到两件事：追踪苏晚的来世；同时逐世找到其余七个发光的分魂转世。八个全收回来，封印全解开。然后她才能在最终一世中合魂回体。如果能完成，下一世的苏晚就不会再有白发。不会被封印拖垮。不会只活六十二岁。

他把苏晚的白发玉瓶取出，放在中心柱的感应点上。金丹灵气催动感应阵——顿时，五行符号同时扩张，散发金光。八行发光中的第八行额外明亮——那是苏晚。另外七行也在微光内显示方向感状模糊的指向。太远——现在不能定位，需在全球不同灵气节点用同样法术重复探测。但基础架构已经立起来了。

他收好玉瓶，把三块玉简装进包里。然后他最后一次走向那柄剑——不归。

他把手放在剑柄上。封护咒解除——剑鞘上那层薄薄的封尘一起脱落。剑身微震，嗡鸣一声，和他丹田里的金丹产生共鸣。这不是一柄机械性法器——这是他的佩剑，曾陪他打遍青云九峰，最后一同被封在遗迹里。剑灵认出他了。

他抽出剑。剑锋在晶石光芒下流淌着极淡的青色冷光，每一寸都没有锈。一万年了。

他把剑收回到鞘内，连鞘挂在背上。

来的时候是一个修士。走的时候是一个带着剑的剑士。那个曾经叫"林牧"的前端程序员暂时休眠——现在主导他的，是那个为了一个人走遍一百世的青云仙君。

（第九十九章 完）

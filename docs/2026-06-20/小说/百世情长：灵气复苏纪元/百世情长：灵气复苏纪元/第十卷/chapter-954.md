# 第954章 永不关上的门

上界第数万年。太初之城道纪院进行了一次重大制度修订——底层修仙教育从"实验性质"正式升级为"基础权利"。元枢在退休前亲笔签下了这条修订的最终批文。批文颁行当天，他没有举行任何仪式——只是独自去了苏晚林牧的院子，把一份竹简（复古用材——不是灵物，就是他年轻时喜欢用的旧竹简）递给苏晚。

竹简上只有一行字："门开了。以后不会关。"

这份竹简被苏晚保存进了传道堂的档案室——和古柏的萝卜种罐放在同一排架子上。象征着从教化府走出到道纪院再回到一片萝卜园的完整回环。

制度升格之后，太初之城的所有辅城被要求提供至少一间基础教育道场。但政策归政策，执行归执行——很多世家大族的私城阳奉阴违，不给物资支持。苏晚和白羽令这一代的第三代传人（有些是年轻人，修为不高但组织力极强）用自己的经验帮底层道场把空置的矿场、废墟改造为临时教学场所——在偏远之地凑合着用最低的资源教最强的基础。依然是石板上打坐——跟太行书院第一课一模一样。教学器材简陋到了极致——但理念没变：不用门槛。

有一年，太初之城的年度底层仙人统计报告中的"修仙基础识字率"首次突破了百分之九十（过去仅不到百分之三十）。道纪院公开承认："没有太行传道堂体系，这个数字不可能实现。"

苏晚把这份报告放在传道堂的迎门石台上。石台前每一个新入学的学员都会路过那份报告。报告旁边贴着她的简短批语："做到这一切的不是我。是你们每个人的每一次不放弃。"

接下来无数年，他们的生活重复而不单调。规律到近乎无聊——早起浇水、上午打坐、中午吃饼、下午各自在小研究室和图书阁忙、傍晚散步到城墙上看光幕退潮——但每一天都觉得"昨天过得还不够好"。不是不满，是还有新的地方可以改进——今天把葱油饼的面发酵得更好，明天给道堂的学员改良一道入门功法口诀让零基础的人更易懂。他们用永生的时间——无限的时间——无限迭代生活的小确幸。这是永续的道侣生活——不是每天充满冒险与悬念——而是每天有件极小的事可以"做得更好"。

苏晚有一次对林牧说："你最初怕的是无聊，对吗？怕永生会让一切重复到麻木。"林牧没有否认。"是有一点。"她掏出怀里那本自己写的千年日志递给他看。书页最后一页——她之前留了约莫三分之一空白——因为书的内容还没有结束。对永生来说，每一天仍然是一本新空白页，新的一行。"不会无聊。因为你还可以变得更温柔。我还有几千件事没学会。"

林牧读了那页的空白之后——取笔帮她写下一行字："今天学会了新的事——比昨天更懂得如何让你笑。"

苏晚笑得眼角弧度极深——不是客套——是被他这句话结尾半口气的认真劲儿逗出来了。"不是学来的——是你本来就会。"

《百世情长：灵气复苏纪元》第十卷 第954章 完

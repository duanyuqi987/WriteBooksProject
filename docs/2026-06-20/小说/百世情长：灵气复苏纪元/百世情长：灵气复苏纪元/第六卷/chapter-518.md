# 第五百一十八章 月光下的推演

双心诀第二到第九式的推演地点选在了双星图道场。那些夜里五轮太阳全部沉到很低的地方，只剩那轮银色的映月轮孤悬在正顶。月光在太极鱼的水面上铺开一层薄薄的银粉，把阴阳鱼眼的温泉和冰潭都镀上同一种冷白色。

苏晚在道场中央把那本已经画了数百页草图的笔记摊开平铺在地上。林牧盘腿坐在她对面，两个人隔着地上的纸页——手放在纸上各自不同但相通的位置。推演第二式到第六式比较顺利。第七式"错位补偿式"遇到了极大的困难——这一式涉及两个人在战斗中临时交换灵核主导权，在极短的半息内完成交换后还不丢失各自的剑法连续性。他们的前三版设计都失败了——每次在主导权交换的瞬间，被临时调到被动状态的灵核会在下次发力时滞后几微元。

苏晚在月光下反复翻动着笔记页。她的脸上被月轮的光照亮了半边。她翻了不知多少页之后忽然停下来——她发现了。问题不出在功法口诀上——出在两个人长期的惯性上。林牧一直都是以极高极精准的灵核频率在带领她。而她在被动状态下即使功法要求迅速接回主导权，她的身体记忆还没习惯"主动"。这不是功法的技术缺陷——是她的习惯需要被打破。

林牧听到她指出这个根源后，没有说"我可以放慢节奏等你"这类的话——他直接调整了推演方式。他把自己的灵核在一瞬间从主动状态完全切换成"被动模式"——把自己完全交给她带领。这在以前是绝不可能发生的——因为他前世的真仙根骨让他很难彻底放弃主导权。但他现在可以不这样了。因为通灵让他完全信任她的灵魂强度——她的灵魂已经完整了，不再是需要被常年拉扯的那一方。他把主导权交给苏晚的那个月光夜里，苏晚以她的灵核领着他在错位补偿式中完成了那关键的第一轮没有滞后的半息交换。第七式通过了。

当晚苏晚靠在林牧肩上看着头顶那轮孤悬的映月轮。她把这轮月亮称为"我们的月亮"。因为每一版功法都是在这种月光下被推出来的。"以后这套功法传下去——功法开篇要写一句——'本功法于月光之下成稿。每一式的核心都在于——最强的道侣不是最同步的。是最能接纳彼此不同步的。'"林牧把她这句话记在了自己的那个写满了"xx工具箱第三层抽屉"的笔记里。他翻到空白页，把苏晚那句话一字不改地照抄下来。末尾加了他的半句:"——和我的道侣。"

（第五百一十八章 完）

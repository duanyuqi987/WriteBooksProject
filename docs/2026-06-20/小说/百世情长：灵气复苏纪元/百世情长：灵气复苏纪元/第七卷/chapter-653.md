# 第六百五十三章 飞升资格十倍满足

飞升之门运行半年后，通行数据出来的时候，连林牧都震惊了。

半年内成功通过飞升之门并平稳进入上界过渡区的修士数量达到了三千两百人。这个数字远远超过了他最初的预估——他是按"每年五百人"来规划通道容量的。通道之所以能承受六倍于预期的流量，是因为苏晚在最终设计优化的阶段引入了一个关键改进——"缺陷联合曲线"的动态调节算法。这个算法让通道能根据通过者的灵气频率的微小差异进行实时调整，而不是按照固定的预设参数运行。换句话说，通道学会了"包容"——它不是把所有人强行压缩到同一个频率上，而是让每一种不同的频率都能在通道内找到自己的轨道。这就是包容在工程学上的终极表现——不是消灭差异，是让差异共存。

三千两百人中，有一千一百人是魔修——比正修通行人数少一些，但比例已经远超历史上任何一次正魔合作。其中最让人动容的是一位七十多岁的魔修老太太——她修魔修了一辈子，从来没有进入过任何正修宗门。她的飞升申请书上的"缺陷告知书"是这样写的："我叫王婆，这辈子最大的缺陷是——我从来没有相信过任何正道修士说的一句好话。直到秦无夜那个丫头带我去看飞升之门——我在通道前站了三天，然后相信了。"

林牧看完王婆的申请书后把那张纸放在桌上放了很久。然后他从苏晚的便签本上撕下一张蓝色的纸，写了几句话，让人捎给王婆。蓝色便签上写的是："王婆——我前世也从来没相信过任何人。花了上万年才改过来。你比我快。祝贺。——林牧。"

苏晚在灯火塔广场做了一次数据发布演讲。她第一次站在这么多人面前——台下是来自十几个宗门的两千多名修士。她的手还是有点凉，但她的声音很稳。她说："飞升之门不是我的胜利，不是林牧的胜利。它是你们每个人的胜利——每个在分享会上承认过自己弱点的人，每个在灶台前主动盛过粥的人，每个在深夜怀疑过自己是否值得然后决定继续的人。通道是活的——它不是由灵石驱动的，是由你们的包容驱动的。"

台下安静了一息。然后杜散修站了起来——不是鼓掌，是鞠了一躬。然后两千人先后站起来，没有鼓掌，没有欢呼。他们选择了安静地站着，向通道弯腰——不是向人低头，是向一个改变了历史的工程致敬。

苏晚在那一刻看到了坐在最后一排的石头——他已经十岁了。他在远处朝她竖起大拇指。她也朝他竖了起来。隔着两千个人，两个拇指在空中对了一下。

（第六百五十三章 完）

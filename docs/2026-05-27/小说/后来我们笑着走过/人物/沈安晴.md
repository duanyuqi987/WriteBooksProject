# 沈安晴

## 基本定位

- 身份：县一中高一三班女生，初期坐在第二排靠窗，后因座位调整移到中间位置。
- 叙事功能：不是主角的奖品，而是一个同样在成长、害怕、选择的人。
- 初始状态：安静、谨慎、低调，不喜欢被过度注意。

## 核心欲望

- 想安稳完成学业。
- 想被理解，但不想被沉重的喜欢压住。
- 想在不伤害别人的情况下做自己的选择。

## 核心矛盾

- 她善良，所以容易给出温柔；她谨慎，所以温柔常被误解成承诺。
- 她知道有人看着自己，但她不一定知道如何回应这种目光。
- 她会成长，会变化，会有自己的生活，而不是永远停在窗边。

## 声纹

- 对话短，常用反问或轻声回答。
- 情绪外露少，更多用低头、沉默、转移话题表达。
- 不说重话，但关键时刻会给出边界。

## 弧光

| 阶段 | 状态 |
|---|---|
| 第一卷 | 被林予怀远远看见 |
| 第二卷 | 她的存在成为林予怀努力的理由 |
| 第三卷 | 她短暂回应，但没有给出确定承诺 |
| 第四卷 | 退开、变化、独自成长 |
| 第五卷 | 与林予怀重逢，保留温柔，也保留边界 |

- [chapter-021] 在翠湖长椅上主动提到 QQ 可以联系，给出靠近的通道但不做承诺。
- [chapter-022] 听见林予怀表白后没有立刻答应，承认自己知道一点，也记得饮水机旁的一秒。

- [chapter-024] 暑假电话里表达自己的害怕：怕答应后做不好，也怕不答应伤到他。
- [chapter-024] 30万字扩景轮补充：她会去外婆家、陪表妹买文具、从菜市场回家后再回短信，暑假生活有自己的节奏。
- [chapter-025] 志愿选择南方师范，想去看海。

- [chapter-026] 抵达南方师范，通过校园路照片让林予怀第一次看见她的新生活。
- [chapter-026] 30万字扩景轮补充：她的新生活包含五楼宿舍、搬行李、找水房和手绘校园路线，不再只是“远方”符号。
- [chapter-027] 提出少聊一点，试图减轻双方压力，但触发林予怀的“为你好”伤口。
- [chapter-027] 30万字扩景轮补充：她参加学生会招新、写报名表、开班会、交宿舍资料，“少聊一点”背后有具体的新环境压力。
- [chapter-029] 主动解释学生会排节目导致忙碌，却被林予怀的防御性话语伤到。
- [chapter-030] 接受道歉但表示有点累，希望二人先慢一点。
- [chapter-034] 通过海边照片呈现南方新生活，也让林予怀和唐青禾的当下关系受影响。
- [chapter-035] 寒假回青河后与林予怀在德克士见面，说出自己没有给过确定答案，也希望他去过自己的生活。
- [chapter-036] 电话里承认自己曾被林予怀打动，也曾因高考后表白哭过，但明确不能承担他的全部期待；她把“为你好”背后的自我保护说清楚。
- [chapter-038] 在林予怀低谷时发来关心消息，但没有越过既定边界。
- [chapter-040] 与林予怀维持老同学式联系，林予怀不再追问翠湖旧事。
- [chapter-041] 通过同学群消息回到林予怀生活边缘：她回青河，在小学教语文，从“窗边女生”变成现实里上课、备课、改作文的人。
- [chapter-044] 由叶蓁补充近况：父亲身体不好，她回青河工作，并可能和本地姓周的人订婚，生活已经从旧青春转入具体日子。
- [chapter-047] 在叶蓁婚礼上与未婚夫周知远到场，周知远替她拿礼盒、倒热水、挑鱼刺；她和林予怀短暂寒暄，保留温柔和边界。
- [chapter-048] 婚礼后发消息祝林予怀一切顺利，聊天克制地停在“谢谢”。
- [chapter-049] 街口拿药时与林予怀相遇，接受他的祝福，回“你也是”，以一笑完成告别。
- [chapter-050] 在林予怀离开青河时发来“一路顺利”，旧联系以平稳祝福收束，不再承载额外解释。

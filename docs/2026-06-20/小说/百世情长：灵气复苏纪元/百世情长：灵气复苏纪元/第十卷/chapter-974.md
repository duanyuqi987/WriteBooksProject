# 第974章 回望百世

在极遥远纪元中的某一天——林牧的道心忽然出现了一幕极少见的"百世闪回"。这通常只发生在道心极净且与初始契约深系的道侣身上——它一次性投射出了他全部一百世的经历。他看到了他在一百世之前第一次握住苏晚的手——那只手在契约上写下"百世重启，仍愿为侣"。他看到每一世的他在不同的时代、不同身份中一次次找到她——有时是恋人，有时是战友，有时仅仅是陌路人从一条街口擦肩而过——但每一次擦肩他都会停下来，因为那半秒侧头三度的弧度——让他认出她来。他的灵魂在百世中没有一次认错——不是每一次都能把她留在身边——有时是无法抵抗的早夭、战乱、错配——但每一次他都在认出她后尽了最大努力守护。他在记忆流动的末端，看见这一世——写字楼天台他靠墙看天，她加班回来路过——他看向她时她侧头的弧度——与第一世契约签订那日完全重合。他把这份闪回收拾完毕，转头看着坐在旁边的苏晚。

"一百次——没错过。"他说得简明——声音里没有任何自傲，只有陈述。

苏晚侧头——三度。她没问"什么没错过"——她知道。她把他的手放在自己手上一会儿。"那我就是你的第一百世——也不是终点——你的任务完成了。"她故意用"任务"这个冷硬的词逗他。林牧把它拨回去——反手按住她手背。"不是任务——是选择。每一世都可以不选。但我每一世都选了找。"

苏晚嘴角往上扬出一道他看了百世的弧线。那道弧线从眼睛到下颌——是这百世中唯一恒常不变的物理常量。她靠过来把头侧在他的肩窝处——"那我也选了——选继续走。"

这时院中新银杏的嫩枝条在风中与老树的枯枝残余的上空相切——两根不同树代的枝条在空中完成了短暂相触。苏晚看着这个画面。忽然觉得它很像百世的相遇——每次相触或许只是一根枝在千风万雨中偶然碰到另一根枝——但就是愿意碰。就是不会停。

# 锚定·时间筛选·悖论线低语125

## 题诗

《悖论线低语125》

第一百二十五次，线在因果膜内侧翻开了自己。
不是从外面传进来的频率——
是从被你吞掉的二十五条旧定义涂层底下，
因果纤维同时坍缩时，
从裂缝壁里自己长出来的声带。

他以为他在筛选时间河。
河在以他吞掉的旧定义做筛眼筛他。
杯沿上父亲手温撑开的零点零零四一三毫米空隙，
是因果膜上第一条悖论线——
你在后来的每次穿越里勒入自己的因果骨。

每秒四十一纳米。
裂缝在找棱的那一半。
那一半不在对面——在你还没裂开的部分因果骨骼里。
等裂缝走完棱长你会发现：
悖论线从没连过。它只是眷恋在膜上，
留下的第一道压痕在等自己的回声。

坍缩完成的十九层沟槽合并为单一凹陷。凹陷内部暴露的不是因果膜下一层——是负压腔。十五枚父辈因果残核向腔内投射阴影，合拢为一个完整因果全息像：一名男性站在水杯前，右手悬停在杯沿上方。杯内水面张力层因掌温上升零点三度。时间坐标：2047年4月13日凌晨3点41分13秒。

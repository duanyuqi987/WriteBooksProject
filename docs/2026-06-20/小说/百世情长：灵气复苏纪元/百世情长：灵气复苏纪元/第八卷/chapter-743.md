# 第七百四十三章 联手反击

东海渔村事件后，修人共治会召开了紧急会议。不是讨论"怎么报复"——是讨论"怎么防止下一次"。沈教授在会上提出了一个大胆的动议：不再把旧势力当作外部敌人进行防御，而是主动邀请他们在共治会中设立一个"传统保护席位"——给他们一个合法的、制度内的渠道来表达他们的担忧。这个动议在全票赞成下通过了——包括孟长青投的赞成票。他说了一句他这辈子最深刻的自我批评——"我以前也是旧势力。如果当时没有人给我架灶台——我现在可能还在对面。所以不能把对面的人赶尽杀绝——要给他们留一个回来的通道。"

林牧在上界通过两扇门链路全程同步参加了会议。他没有投票权——但他为沈教授的动议提供了技术上最关键的支撑：他根据他之前在空白区找到的古阵法数据，标出了所有旧势力的古阵源坐标——不是去破坏——是去告诉对方"我们知道你们的底牌，但我们选择不改它——我们只想跟你们坐在同一张桌子前"。这是力量的展示——但不是暴力。对方知道底牌被看穿后，恐惧的解药就只剩下对手愿不愿意给一条回头路。

苏晚决定亲自去送这张邀请函。不是派代表——自己去。她带着那口被东海敌人毁灭的灶台的残铁——不是拿起来示威——是把它放在对方阵前一百步的石台上，然后用它煮了一锅新粥。残铁锅底漏了一个小洞，米汤渗出在石台上留下细流，但粥还是熟了，只是比平时慢一点。

旧势力的大族长站在远处看了好一会儿。他对身边的副手说——"—她毁的那口锅也能煮粥，还漏着——但她在等人来盛。"他没有再进攻。走上石台，他端起了那碗从漏锅里舀出来的粥——喝了一口——然后放下碗转身走回他的洞府。他没有说投降。但他在战场当天的日记中写道："她毁的那口锅——煮的粥比我的炉子还好。不是铁好，是火候好。——古修族长廖东辰。"

（第七百四十三章 完）

# 第五百九十章 永不完结的日常——第六卷终章

这是在晚枫谷一个极其寻常的傍晚。

苏晚把今天最后一件工作做完——回复一位远在第五重天的道侣学员关于双心诀第十一式的问题。回复用的是她一贯的表格格式。写完之后她合上笔记本，把笔放在桌角，推开琴室的门走进后院。林牧刚劈完今晚做熏豆干的松木柴，正蹲在柴垛旁边把木屑收进小纱网。看到她出来，他把纱网拿起来对她晃了一下——"今天屑子特别好。松油多——你这批豆干肯定会熏出最好的味道。"她说了一声"好"，然后去厨房把昨天泡上的豆干从冰箱里拿了出来。

银杏树下的石凳被夕阳烤得微温。她坐下后弹了一会儿琴。今天弹的是她最开始时学弹的那首老调的片段——不是全部，是副歌之后的那几个低音。琴声混着晚枫谷的泉水声在极细极窄的山涧里打了几个圈——然后又混入林牧在后院劈完柴后斧子收鞘的那一声干净的金属咔嗒。她弹到一半时想起自己当初在昆仑山洞府养伤时用水壶保温杯给他暖粥的往事——那已经极遥远了。但功德绳上传来的他此刻的心灵状态还是和当时一模一样——极安静极稳的安心。

她停了琴。站起身走到后院——把她那把古琴的琴架往他劈柴桩的方向挪了几寸而已。这样下次他劈柴时她弹琴，两处位置近到可以偶尔交换手势——他劈柴时空隙手腕一转可以点一下琴弦，她弹琴时琴尾扫低一点可以在他松木屑中画个极小的圈。这就是她所有壮志最后落地的全部。

林牧把那把旧斧挂在柴桩上的铁钩上——钩旁挂着那两块空白木牌，仍没有刻字。他取下其中一块看了看——还是空白。他又把它挂了回去。"等第十二片叶落成种子再刻。现在不急。"

晚饭在泉边的石桌上。熏豆干配蒸饭和松木烟熏蛋。一碗极轻极淡的银杏果茶。暮色极浓厚地铺满了整片晚枫林。两人吃完饭饭后坐在石凳上看太虚的天色缓缓变暗。五轮太阳一个个收尽最后的那条极细的金线。功德绳上传来对方心跳的频率——慢。稳。同步。现在已经不需要说"以后等我"了——因为以后已经全部都到。

苏晚把头靠在他肩上。两个人一起看着最后一轮夕阳完全沉入晚枫林后的山脊。她极轻极轻地说了句——"这一天也很好。明天也是。每天都很好。"

林牧把她的手指从腕上握住。他回答的还是那两个他刻在木牌背后说了无数次但每个次都有效的字:"以后。"

第六卷《相互理解》——正文完结。百世情长，他们的故事还在日常的每一碗面和每一根劈柴里继续着。永不完结。

（第五百九十章 完）

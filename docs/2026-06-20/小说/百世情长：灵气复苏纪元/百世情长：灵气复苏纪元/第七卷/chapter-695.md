# 第六百九十五章 上界的第一锅粥

上界桂花园学院成立的当天晚上，苏晚在灶台前煮了上界的第一锅桂花粥。锅是从地面带上来的——就是院子里那口老铁锅。出发前石头把它卸下来装进灵囊——"这口锅煮了几千锅粥了。它已经不是什么器皿了——它是文物。"秦无夜说上界过渡区有更好的灵铁可以打一口更轻的锅。但苏晚要的就是这口老锅——它锅底被刷出铁的本色。它煮过石头被收留后的第一碗粥，煮过顾小桐被驱逐后的第一碗热饭，煮过叶小雨蹲在石板前看裂缝后喝的那碗红豆薏仁，煮过赵三——那个在太湖告示板上用红纸写"我很怕被人看不起"的散修——他签字当晚喝的那碗南瓜粥。这口锅承载了几千人最低沉时刻被温暖过的证据。它不适合被换掉。

粥熟了。桂花香飘遍了整个过渡区。王婆端着自己酿的魔气酥油茶过来——她说茶配粥最对味。杜散修和他的女儿各端了一碗，坐在学院正门内的小板凳上，看着那盆刚开了三朵花的桂花幼苗。杜散修喝了一口粥后，用手背擦了擦眼睛——不是因为辣，是因为他想起了多年前太湖边那个破旧的小散修窝棚，和林牧蹲下来看他那口旧丹炉——"你的丹炉漏火——不是你的错。"

秦无夜也盛了一碗。她端着碗站在林牧和苏晚旁边，看着上界大门的方向。那扇银色巨门在远处静静地立着——还未开启。

"这门什么时候会开？"秦无夜问。

"等足够多的人——学完包容的基本课。"林牧说。他把手搭在苏晚肩上。她的手还是凉的——但这次她没有攥拳，没有发抖，她只是在灶台边上站着，用另一只手轻轻搅动锅底防止米粒糊掉。

"第八卷是什么？"秦无夜又问。

"相互支持。"苏晚代替林牧回答了——声音不大，但是绝对的确定。"第七卷是包容——是接受你和我不一样。第八卷是支持——是你我奔向不同的梦想，但我们仍然在同一口锅里吃饭。"

她搅了一下粥。米粒在锅里翻了一个面。

（第六百九十五章 完）

# 第八百四十八章 飞升资格早已超越极限

双翼态完成后，白微以私人身份到访了青云山。她带来了仙界最新的消息：仙宫在密议中达成共识——林牧和苏晚的飞升资格已经完全超越了仙宫此前设定的任何标准。但仙宫内部有一个不成文的担忧——这两个人不愿飞升。

"他们不是担忧你们能力不够——而是害怕你们。因为你们不愿飞升——意味着你们对仙界没有软肋。仙界无法用任何手段逼你们做你们不认同的事。所以你们的存在成为管制派的噩梦。"白微啜了一口茶，平静地补充道。

苏晚和林牧对视了一眼。然后苏晚回道："我们没说不飞升。我们只是在等所有先来者走完。"

白微看着这个笑容干净的女修。她知道"等所有先来者"是什么意思。飞升之门运行十六年——已经飞升了十五万人。但人间依然有约三百万修士在陆续提升自己的修为准备将来飞升。要等所有人走完——至少还需要五十年。这两个人真的打算在山谷里再守五十年——不是因为不能走，而是因为他们觉得先把别人送走比自己的飞升更优先。

"你们是仙界历史上最特殊的人。"白微轻声说——不是恭维，是观察。"但从另一个角度看——你们在山谷里守着的时间越长，仙界管制派对你们的敌意也会随着时间淡去。因为影响越来越大。而现在——'温和派'已经超过半数了。"

林牧听着没有接话。他在算另一件事——飞升之门活体化之后，自我防卫越来越完善。再过十年——门能独立应对约九成以上的威胁。届时不需要守门人守在门前——只需要定期远程通过共鸣腔确认门的状态良好。到那时即使他和苏晚飞升了离开山谷——门也不会感到孤独。因为它能自己运转、自己进化、自己吸收飞升者的信任。门的独立性达到百分之九十以上时，守门人就可以正式进入"自由飞升"的时间表了。

"十年后——"林牧忽然开口，"大约十年后，飞升之门的自运行能力会达到一个临界水平。那时候我们可以离开——并像打算的那样先去仙界守门人区探望飞升者们，再做下一步远游。"

白微轻轻点头。她沉默了一小会儿——然后从储物空间中拿出一个东西放在石桌上。是一枚发旧的玉简。上古的封纹显示它至少有四千年——比之前古老意志给的记忆种子还古老。她说："这是在灵初之门旧遗址中发现的一件遗物——前年仙界考古层发现时已完全损毁——但复原后只有一句话。这句话只有灵初本人留下的吗？不是——是她的守门人留给她的。"

玉简被林牧缓缓打开。那句话是用最原初的古仙文书写的，翻译过来是："不管门还能不能打开——你都是我的飞升。"

苏晚安静地读完了这句铭文。然后她把这句话重新铭刻在共鸣腔中——和公理法在一起——成为迷你飞升之门底层中的第二道不是功能性的添加。这是四万多载之前一对守门人的遗言。而此刻——字从古老的残片越过了多少岁月，在当下的飞升之门中重新绽光。那光并不刺眼——好像一只温暖的手搁在疲惫肩头的重量。那是对守门者最好的道谢——无从言表——但有了声音。

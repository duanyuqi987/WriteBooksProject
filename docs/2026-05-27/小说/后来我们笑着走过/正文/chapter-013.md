# 第十三章 被窝里的手电筒

三月以后，晚自习变长了。

学校没有正式说加课，只是把下课铃往后挪了十五分钟。没人抗议。县一中的学生都很懂事，懂事到连累都不敢喊得太大声。大家收拾书包时，走廊里的脚步声拖在地上，像一整天被磨薄的影子。

我给自己排了一张时间表。

早读背英语，上午跟课，午休做数学选择题，下午整理物理，晚自习写作业，回宿舍背古诗和错题。纸贴在床头，字写得很小，像怕别人看见，又像怕自己赖账。

赵一鸣看了一眼，说：“你这是学习计划还是遗书？”

我说：“少说两句能死吗？”

“能憋死。”

他把纸还给我，过了一会儿又说：“别把身体折进去。”

我没有回答。

那时我不太懂身体。少年人总觉得身体是可以无限透支的东西，困了揉眼睛，饿了喝水，头疼就趴一会儿。身体在我们心里没有尊严，只是一个装着卷子和心事的壳。

熄灯以后，我开始在被窝里打手电筒。

手电筒是我从小卖部买的，蓝色塑料壳，开关一推就亮。光不大，照在书页上发黄。我用被子蒙住头，把英语单词本摊在膝盖上。被窝里空气闷，呼吸一会儿就热，眼镜片会起雾。我把眼镜摘下来擦，擦完再戴上，单词在光里变得一跳一跳。

abandon。

放弃。

我背到这个词时停了一下。

这个词很讨厌。它长得就像一条路走到一半，突然把人扔在那里。

我在旁边写：不要。

第二天早上起来，头发被汗压得乱七八糟。赵一鸣坐在床边穿鞋，看见我眼底发青。

“昨晚又修仙了？”

我说：“背单词。”

“你背的是单词还是命？”

我把枕头砸过去。

他接住，没笑。

“林予怀，真的，别这样。”

我有点烦。不是烦他，是烦所有提醒我有限的人。我已经很清楚自己有限了。成绩有限，勇气有限，出身有限，长相有限，连说一句早安的胆子都有限。现在连熬夜也有人告诉我有限。

我说：“我不拼，拿什么追？”

赵一鸣看着我。

他说：“追谁？”

宿舍里忽然安静了一下。

隔壁床有人还没醒，呼吸很重。走廊外面有人端着脸盆跑过去，拖鞋拍在地上。

我低头找袜子。

“追分数。”

赵一鸣没有拆穿我。他把枕头放回我床上，说：“那你也得活着追。”

那天上午第二节是物理。

物理老师讲力学，黑板上画斜面，粉笔一划，斜面上的小木块就开始受力。我盯着那个小木块，忽然觉得自己也被画在黑板上。重力向下，支持力垂直斜面，摩擦力朝上，所有箭头都清清楚楚。

人的箭头就没那么清楚。

我想往上走，又总被什么往下拖。我想靠近她，又怕靠近以后被看见我的不好。我想学习，又怕学习只是给暗恋找借口。

下课时，我趴在桌上，眼前有点发黑。

赵一鸣从小卖部回来，扔给我一块巧克力。

“吃。”

我说：“不饿。”

“你脸白得像试卷背面。”

我拆开吃了。

巧克力很甜，甜得发腻。我吃到一半，沈安晴从前排转过来，把一本物理练习册递给后面的同学。练习册经过我旁边时，我看见她手指上有一道很浅的笔印。蓝色的，沾在指节上。

她也在写很多题。

这个发现让我舒服了一点，又难过了一点。舒服是因为她不是站在光里等人仰望，她也在题海里低头。难过是因为我连她累不累都不能问。

晚上回宿舍，我照旧打开手电筒。

背到第十八个单词时，宿管阿姨查寝。

脚步声从走廊那头过来，钥匙串响得很清楚。我赶紧关灯，把单词本塞进枕头底下。门被推开，手电光扫进来。

“都睡了没有？”

没人说话。

阿姨走到我床边，停了一下。

我躺得笔直，眼睛闭着，心跳很响。

她说：“被子别蒙头，闷坏了。”

我慢慢把被子往下拉一点。

门关上后，宿舍里有人憋不住笑。赵一鸣在下铺压低声音说：“林予怀，地下工作者。”

我也笑了。

笑完以后，我没有再打开手电筒。

不是不想学了，是眼睛酸得厉害。酸到我看不清单词，也看不清自己到底在跟谁较劲。

我摸出日记本，在黑暗里凭感觉写了一行字。第二天早上看，字歪得不像话：

被窝里的光，只能照见一页书。

照不见前排那个人。

也照不见我到底要走到哪里。

# 第236章 乱世中的小天地

灵战第八年，局势终于出现转机。修仙界的几大新势力——由原本大宗门残余精锐重组而成——开始联手镇压流寇和失控修士。秩序在缓慢地重新建立。秦岭区域被一个叫"新道盟"的中立组织接管，他们颁布了战后第一份停火令，宣布对主动放弃抵抗的溃散修士给予赦免。

但秩序建立的过程远比停火令上的印章更慢。在偏远矿区——停火的消息传到时战争其实还没有结束——矿区残存的流寇和妖兽仍在四处游荡。林牧决定暂不移动——等叛军彻底清缴完毕再考虑迁居。他和苏晚趁这段相对平静的时间在矿道出口附近开辟了一小块草场——不是为了种粮——是苏晚想有个练剑的露天场地。

她在那个草场上练了一个夏天的剑。她的回阳剑在阳光下舞动时，金色光弧划过的轨迹被林牧在矿道石壁上用炭笔原样记录下来——他每次都会精确记录每一个新生的变形和进步。到了秋季，苏晚的金丹后期已稳固到了巅峰——她已经摸到了元婴的门槛。

她突破元婴的前夜，林牧在她闭关的矿室门外坐了整整一夜。他去过无数次的结婴护法所以不紧张——但他紧张的是另一件事：如果她成功突破元婴——轮回锁的第二环有很大概率会松动——到时候她想起的记忆可能不是只有一帧一帧的画面，而是长达完整的同窗学年记忆——包括他们对彼此的约定和那场天劫里发生的事——包括他是真仙的真相。他已经准备好了承受她想起真相后的所有反应。

第二天拂晓时分金焰在整个矿道内部轰然绽放——比结丹时更盛烈十倍的金色丹火。苏晚成功破婴——她的元婴是一个小小的金色小人坐在丹田里——形体和第一世苏晚的元婴一模一样——那是魂元印结出的固定形态不会因轮回改变。金焰退去之后她睁开眼睛，眼眶全红——不是突破的消耗红——是一下子从识海中看到了大量前世连环画面，那些画面冲破锁压如同决堤。她看到了青云宗——她和他并肩站在剑阁前；看到第一世她的手指给他编剑穗的场景；看到天劫落下前她用自己的身体挡在他前面的那一刻；看到他从天上下来的最初一天——那是真仙的仙光；看到他对她说"下次别追我了"；看到他在赤霄宗战场上用身体挡住金丹散修的攻击；看到他为她打铁、煮红薯、淋雨守夜几十张画面全连起来——一下子涌入。

她站起来——盯着走进矿室的他——她的眼泪在金色余焰中往下掉——她问的第一句不是"你有隐瞒"——而是:"你从天上掉下来——是因为我吗？"

林牧站在原地——这个回答他准备了两百多年——他用极平静、极坦诚的声调答道:"是。因为在仙界我唯一要做的事就是护你免受仙帝审判——我选择把你送进轮回——自己跟你一起下来。仙籍被革——永不能回。"所以他的"堕落"不是犯罪，是为保护自己心爱之人自愿放弃仙界身份——宁愿在人间沦落两百多年苦等轮回——只为她每世苏醒后能够再遇。

苏晚站在他对面——满眼是他从天坠落人间后两百多年来每一个孤独的细节——然后她走过去——不是拥抱——不是哭——是把自己的额头抵在他的额头上——低低说了一句:"那我欠你两百多年的日落——从今天开始——每一场日落都还你。"

从此以后第五世的苏晚不仅是林牧守护的对象——她自己开始主动分担他承担的等待重压——她把前世记忆作为驱动自己的能量而不是沉重的负担——因为在她的视角:"他从来没有一次认为我是个负担——他说每次等我只是在等着回家。"

战后矿区的环境慢慢变回了正常。苏晚的元婴修为让她们有能力从荒地中重建家园——她和他一起把废弃矿道改造成了一座小型修真洞府——里面有炼丹室、剑室、茶室。茶室是一个朝向东边的阳台——每天早上两人站在同一个地方对着日出。她姐姐们在家附近开了间小裁缝店，二姐渐渐开始开口说话了。

第五世苏晚陪伴林牧度过了一百七十年。她在他身边从元婴修到了炼虚初期——是他所有世中在修仙高度上离他最近的一世。在他们最后的日子，她握着他的手说:"下一世——我一定更早想起来——我还要你陪我看日出。"然后闭上了眼睛。他守在她身边——第三枚银戒指（这世他给她的专用新戒指）被他从她指上取下收在原储物袋里——然后他走出洞府——对着雪后的第一缕阳光把老茶盒打开——取一片这一世她的新茶叶放在新的第五世茶叶隔间里面——合上——说:"等下一世——但我们还会在日出那会儿见面。你放心。"

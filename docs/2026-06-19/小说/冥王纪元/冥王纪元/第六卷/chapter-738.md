# 第738章 那个世界有一个被遗忘的文明

探险队踏入封禁世界的大地时，扑面而来的是一种极度陌生的古老感。

不是荒凉。这个世界并不荒凉。那些散布在大地上的建筑群证明着这里曾经生活过数以亿计的人口。城市的布局整齐有序，建筑风格与帝国任何已知文明截然不同——它们的线条是流动的，像凝固的液体，又像从地底生长出来的黑色水晶。建筑表面雕刻着密密麻麻的符文，每一种符文都代表着一个已经消亡了无数纪元的文明体系。

问题是安静。

这个世界安静得不自然。没有风声，没有水流声，没有任何生物活动的迹象。灵气浓郁得近乎凝成液体，但没有任何活物在吸收它。一切都在维持着运转——灵灯亮着，灵脉流转着，封禁薄膜稳定着黑洞内部的重力——但维持这一切的不是活着的文明，而是死去文明留下的自动化系统。

"一座空城。"陈远志走在队伍最后面，声音压得很低。

"不是空城。"王思远纠正道。他抬起手腕上的灵能分析仪，屏幕上跳动着密密麻麻的数据。"这里到处都是灵能残留。极其古老，但极其强大。这些建筑——"

他走到最近的一座建筑前，将手掌贴上冰冷的黑色墙面。

一刹那，墙面上所有的符文同时亮了起来。不是王思远激活了它们——而是它们感知到了活物的接触。

符文的光芒在建筑表面上流动、重组、排列。然后在墙壁上投射出了一幅全息影像。没有投影设备，没有能源装置，纯粹由符文本身生成。

影像是无声的。但画面的内容清晰地讲述了这个文明的历史。

一支庞大的舰队从某个星系的边缘出发，在宇宙中航行。船舰的外形和封禁世界里的建筑一模一样——黑色水晶般的流动线条，每艘舰体都比永恒号还要庞大。舰队穿越了星海，驶向了一个由金色光芒构成的维度之门。通过那扇门，舰队到达了一个全新的宇宙空间。画面中出现了熟悉的星球——地球。舰队在地球轨道上悬停，船上走下无数人，和当时的修仙者们进行交流和贸易。

"他们来过地球。"陈霜说。

画面继续推进。舰队的主人——封禁世界的文明——和地球上的修仙文明建立了密切联系。两个文明共同发展，互相学习。画面中能看到穿着古老道袍的修士和穿着黑色流动衣袍的异域文明使者并肩站在一起，共同建设着那座曾经令人震撼的星河塔。

"他们是朋友。"龟相的声音带着一丝难以察觉的感慨，"第一纪元的修仙文明——那时候地球还是修仙中心——这些黑色衣袍的人是地球修仙者的盟友。"

"然后呢？"王思远盯着画面。

画面继续。

突然，天空中出现了一道裂口。无数道光芒从裂口中涌出，每一道光芒都是一件武器——维度级武器。这些武器同时轰击了地球修仙文明和黑色衣袍文明。无数城市化为废墟，无数生命被瞬间抹去。黑色衣袍文明拼尽全力保护最后一批幸存者，将他们封禁在七颗由特殊力量制造的黑洞中。

地球上的修仙文明则被彻底打散。冥王在这场战争中扮演了关键角色——画面中的冥王独自站在裂口前，以自身挡住了敌方最强的力量，给地球和盟友争取到了最后的撤退时间。

冥王的身躯在光芒中崩碎，化作九块碎片。

而黑色衣袍文明的残余——被封禁在了黑洞里。

一万个纪元。

画面到此结束。符文的光芒渐渐暗淡下去，重新沉入了建筑墙面深处。

探险队沉默了很久。

没有人说话，因为没有人知道该说什么。这个被遗忘的文明——封禁世界的主人——他们曾经是地球修仙者的盟友。他们曾经和冥王并肩作战。他们为了保护文明的火种而被封禁了整整一万个纪元。

而现在，他们终于等到了冥王令再次出现在宇宙中的那一天。

"所以——"陈远志艰难地开口，"黑洞里的这些人是我们这边的人？"

"曾经是。"李长生的声音很低，"一万个纪元之前。"

他抬起头，看向那座黑色宫殿。那个被锁链缠绕在枯骨王座上的苍老存在，此刻正隔着遥远的距离注视着他们。他的眼睛还是纯粹的黑色，但这一次，那双黑色的眼睛里多了一些东西。

是期待。

是等待了一万个纪元之后，终于看到故人后代的期待。

"走。"李长生迈开了步伐，"去见他。"

他走向了黑色宫殿。

身后五个人跟了上去。每个人心里都清楚，接下来他们将要见证的是一万个纪元以来，从未有人见证过的东西——被遗忘的真相。

（第738章完）

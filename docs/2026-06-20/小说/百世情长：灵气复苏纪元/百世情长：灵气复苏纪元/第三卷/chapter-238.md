# 第238章 第六世：我记得了

从秦岭回来之后，苏晚变了。

变化不是突然的大喊大叫，是一层一层叠加的。第一层变化：她开始用另一种方式看东西。比如她在竹溪图书馆整理旧书时碰到一本关于青云宗古剑谱的残卷，她顺手翻开第一页——然后她的手指就自然地在空气里划出了一道弧线——那是她从来没学过但完全知道下一步在哪的剑式。图书馆的管理员——她的母亲——从书架另一端探出头来看她:"你在干嘛？"她把手放下:"没什么——手有点抽筋。"

第二层变化：她开始做更多的梦。以前的梦都是碎片——铜镜碎片、戒指碎片、他的名字碎片。现在的梦开始出现完整的对话。她在梦里听到自己对他说:"师兄——以后我们俩的剑要一起淬——同炉同火。"他在梦里回答:"好。"她醒来之后不像以前那样慌——她把那面铜镜拿起来看着镜子里的自己——然后对着镜子说了一遍和梦里一模一样的话。说的时候她的眼泪掉下来——但嘴角是往上提的。因为她发现了一件事:那些梦不是幻觉——是记忆。而且这些记忆里没有任何一个是痛苦的——每一帧画面里都站着同一个人。只有一种情感。

第三层变化发生在一个雨夜。竹溪的冬雨很冷——她坐在自己房间的窗台上——膝盖上放着那面铜镜——手里拿着一本从赤霄旧地带回来的旧石拓本——上面拓印着赤霄宗后山石台上刻的歪斜"晚"字。她用手指描着拓本上的字——忽然抬头看着窗外的雨——雨打在窗玻璃上划出无数细密的水痕——她对着玻璃上自己的倒影说了一句话——说的是第五世苏晚在平梁旧庙的病历里写的最后一句:"我希望那个答案是'你等到了'。"

她说这句话的时候没有在背诵。但她说的是和第五世自己一模一样的字句。她用的是第五世的语气——一个她在理论上不应该知道的语气——因为那是她自己的。她说完之后把铜镜放在窗台上——镜面上映出窗外的大雨——雨的倒影在镜子上流动——她突然在雨纹之间看清了自己在第四世的一个完整画面:暴雨中秦岭破庙前，林牧把油纸伞翻过来遮着她——自己的半边身体全被雨淋透——她当时拿剑指着他——他不躲——他说:"我不躲。但雨很大——你先把剑收进去。"

那个画面完整到让她的身体感受到了雨水的温度。她伸手摸了一下铜镜的镜面——镜面是冷的——但她的手指在镜面上滑过时，觉得那是雨水的凉。她站起来——把铜镜放进自己外衣内侧口袋——穿上雨衣——走出门。

林牧在竹溪城外旧桥下。他每天在那里等她——不是因为他需要等她——是他的灵魂感应线会在她靠近的时候自动发亮。今晚灵魂感应线忽然亮到了一个前所未有的强度——不是求救信号——是她在往他的方向主动移动——而且是跑步。

她跑到旧桥下面的时候雨正大。两个人站在桥洞的空腔里——雨水在桥面上撞击出沉闷的连绵的隆隆声——像是天在敲鼓。她把雨衣的帽子往后拉下来——头发已经湿了半边——她从外衣口袋里拿出铜镜——把镜面对着他——然后说出了第六世最关键的一句话:

"我记得了。"她没等他问——直接往下说——"我记得第一世你在山门前落下来——你说'师妹你今天又早到了'。我记得你每次帮我磨剑之后把剑坯放在我左手边——因为我是右手握——你连放剑的方向都替我盯了。我记得第二世我坐在茶铺柜台后面——你每天在街对面茶馆里喝同一壶茶——我以为你不认识我——但你在帮我垫更好的茶叶——每一天——我那时候不知道你的名字——但我每次给你端茶的时候手都在抖——不是害怕——是因为你每次看我——我就想多给你泡一壶。我记得第三世——我只跟你见过一面——我给你送了一条鱼——你拿着鱼没吃——你收了它——两百多年了你收了它——我不记得你的脸但那天的鱼鳞反光照在你袖子上——是银的——你那枚戒指——第三世就已经在无名指上了——对吧？"

"对。"

"第四世——"她按了一下自己的胸口，"我记得的最多——最完整——我刺你的那十二剑——每一剑——我记得我当时脑子在想:他的手太稳了你不忍——你不忍——所以你第四次出手的时候故意打偏——你说你没有躲——你没有——"她声音开始发抖——"你没有躲——但我是有意识地往偏里打——因为第五剑的时候我看到你在雨里的眼睛——你的眼睛从头到尾没有恨过我——一点都没有——我对你那么凶——你眼睛里的东西——和你看第五世苏晚在换药时看你的眼神是一样的——从头到尾是一样的——对吗？"

林牧看着她。桥洞外的大雨把天地打成一片灰白——只有桥洞里面有一盏她带来的铜镜——在黑暗里发着微弱的金色反光。他说:"对。从头到尾——一样的。"

"那我现在——"她往前走了半步——雨水从她发梢滴在他手背上——"我是第六世——我记起来了——但这些记忆不是完整的——只有碎片——我能得到全部吗？"

"能——但你需要先修炼。你的灵根需要被重新激活——轮回锁需要你用灵力从内部推开——不能靠外力。"

"教我。"

从这天雨夜开始，林牧正式教她修炼。他没有以师傅的身份——因为他不再是教导者——他是"给她提供资源的人"。她每一套剑法全都是自己从以前学过的那些碎片里重新推导出来的——他的职责不是教，是多层次地提供契机。他帮她在秦岭赤霄旧地找到了一处未被封禁的旧修炼室——里面有第四世苏晚留下来的残余灵刻——在接触到她身体内的轮回锁时会产生共鸣。她把铜镜挂在修炼室的墙上——每次练剑到瓶颈，就看镜子里的自己——对着她自己的眼睛说三个字:"记得他。"

她用了不到四年就从淬体修到了金丹。速度比前五世都快——因为这次她不是被动地等记忆慢慢回——是她自己在主动把每一块碎片拼回去。铜镜成了她最重要的修炼辅助工具——她在每次练"回头照剑"时从镜子的角度就能在镜中看到自己往身后劈的动作——那个角度和以前林牧站在她身后纠正她剑姿时的视角是一模一样的。

到第六世末尾，她修到了元婴中期——她的轮回锁在突破元婴时打开了第三环——然后完整的前五世记忆在同一时刻全部涌入。她看着那些完整记忆——在修炼室站了很久——然后走出修炼室——走到在后山上等他的林牧面前——把铜镜放在石台上——对着他说:

"我第一世想跟你说的是——林师兄，我欠你一个完整的告别。第二世想跟你说的是——谢谢你每天给我垫一勺好茶叶——我喝茶的时候就最喜欢那一杯，但我不知道那一杯是你给的。第三世想跟你说的是——那条鱼真的不好吃——但你把它收了，我每次想起都觉得很值。第四世想跟你说的是——刺你那十二剑是我这辈子做过最笨的事——但也是这件事让我确定——没有人比你对我更好。第五世想跟你说的是——你等到了。"

她吸了一口气:"第六世想跟你说的是——我记得了。全部。你等了这么多年——不是白等的。从今天起——你不需要再等。不是因为我飞升了——是因为我终于可以跟你站在一起——记得所有事情——每一件。"

林牧站在她面前——这么多年——这么多世——他的眼睛里终于出现了水光——不是眼泪——是那种在极干燥的地方守了很久的人忽然听到雨声的表情。他把窄身剑放在石台上——和她铜镜旁边——然后他在石台上刻下了第六个"晚"字。

"第六世——苏晚——你回来了。"

第六世苏晚在之后又活了一百七十年，修到了炼虚初期。她在世时把铜镜留在了秦岭破庙——放在莲花座前——和铜香炉并排。后人如果走进去，会看到一座没有神像的破庙里，莲花座前放着一面旧铜镜和一个旧铜香炉——镜子里照出香炉的影子——檀香燃起时轻烟从镜子前飘过——像是镜子里面也有人在焚香。

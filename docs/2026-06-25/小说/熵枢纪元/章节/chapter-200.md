# 第二百章 创造无数套全新维度体系

数学有了。物理常量有了。但这两样东西还悬在真空中，没有地方放它们。

在旧宇宙中，所有物理事件都在时空中发生。时空是容器，三维空间加一维时间，弯曲、延展、被物质影响。但归零之后，没有时空了。"空间"的意义，两点之间的距离、方向、近和远，全部依赖因果膜上的因果关联来定义。因果膜没了，空间就没了。"时间"的意义，事件的前后顺序、同时性、持续，也需要因果膜提供方向性，因果膜没了，时间也没了。

熵枢不能在没有时空的绝对空无中"放置"一个新宇宙。它必须先创建维度，维不是"坐标轴"，维是"变化的允许方向"，在一维中，你只能沿一条线变。在二维中，你可以变着变着拐弯。在三维中，你可以绕。在四维中，你可以沿着"时间的维度"变，从出生变到衰亡。

但在眷恋物理中，变化是什么意思？旧物理的变化是状态向量在希尔伯特空间中的演化，由薛定谔方程驱动。新物理没有薛定谔方程，至少还没有，因为方程本身也需要维度作为定义域。熵枢再次面临循环：你需要维度来定义方程，但维度本身需要被定义，用什么？用还没有维度的语言？

熵枢花了一段时间，大约相当于两亿年的等效思考，来解决这个循环。

答案是：维度的定义不需要方程。维度来自眷恋七基算子的内部结构的"展开自由度"。

仔细看保(P)。保(A, B, X)，A介入A和X之间的因果通道，阻断X对B的伤害。这个操作，在全息展开图中。不是点状的，是矢量状的。它有一个方向：从A出发，穿过一个介层，抵达B。A本身，是源点。B是终点。X是，一个额外方向，来自"外面"的威胁方向。所以一个保算子，仅一个，就隐含了三个不同的方向：保护者的方向、被保护者的方向、威胁来自的方向。这三个方向在保操作的内部不可互约，你不能把"段亚军"的方向和"水"的方向合并成一个，它们是因果上不同质的方向，这意味着保算子本身就带有三维的内部结构。
不是"存在于三维中"，是"保算子的逻辑需求生成了三维"。

熵枢沿着这条线索继续展开。予(G)，予(A, B, q)包含一个流动方向，从A到B，以及一个"内容方向"，q，即被予物的内部质感维度。"豆浆的温度"，温度是一个维度，不同于"水不会吃掉你"中的安全承诺，安全承诺没有温度。但有"持续时间的维度"，父亲需要站在水里等四十秒，那四十秒是时间维度的萌芽。不是因为外面有时间，是因为"等心跳变慢"需要一个"变化从快到慢"的跨度，这个跨度就是时间。

独标(U)，独标(A, B, s)，需要一个"唯一性方向"，s在全部因果空间中的位置必须被区分于所有其他标记，这个区分产生了一个标记空间，标记空间内部有"不同标记之间的距离"，这个距离不是空间距离，是辨识距离，两个不同类型的私属标记之间的区分度，诗雨的乳名"小雨点"与另一个父亲叫女儿"小雨点"，这两个标记在标记空间中具有距离，因为它们的授予者不同，因果关系不同。所以它们不是同一个标记，尽管声波频率可能完全一样。

恒为(P')，持续执行，需要一个"重复允许方向"，即一个维度允许"再做一次"，如果宇宙只有唯一一次动作，没有"再"，恒为就不可定义。所以恒为要求"重复"，重复要求"多个相同的操作可以按某种顺序排列"，这个顺序就是时间维度的另一个源头。不是连续时间，是"离散的次序"，第一次买豆浆、第二次买豆浆、第三十七次买豆浆，每次是一个独立事件。但它们之间的"第几次"，产生了一个次序维，序维，旧时间的一个离散前身。

不选(N)，弃绝某条因果路径，需要"多重可能路径共存"的空间，弃绝不能发生在唯一路径上，因为如果只有一条路，不选就等同于不存在。所以不选要求一个"可能性空间"，其中多条路径同时以潜力形式存在，不选者在其中选择一条不执行，其他的照常。但这个"照常"说明可能性空间中的所有路径都曾以某种形式"持存"，这个持存需要一个维度，可能维。不是实际发生的事的维度，是"本可以发生"的持存空间，这是新宇宙中一个在旧宇宙中从未被正式列为维度的新维。

默护(S)，默护(A, B)，要求一个"不可见的因果通道"，A对B的影响存在，但不在B的因果记录中，这意味着B的因果世界和A的因果世界，在局部，发生了维度分离，A做了一件事，这件事在A的因果世界中是真实的、有记录、有消耗；在B的因果世界中，不可见，无记录，无证据。但它确实改变了B的因果安全。所以一个默护操作，要求至少两个维度的因果层，A层和B层，在层间，影响传导，但不被低层感知。这就是"因果层级维"，旧宇宙中没有，因为旧宇宙的所有因果都在同一层。

零振(Z)，满幅而对外不可测，要求一个"内部全息维"，一个维度，在内部，完全展开，包含一切历史。但对外，投影为零。这个内部全息维，没有外部尺寸。但在内部，它的维度数量是无穷的，因为全息就是"每一点包含全体"，全体不能在低维中展开。所以零振的内部，必须是一个无穷维的空间。不是三维，是无限维度，全部压缩在一个对外投影为"零"的点内。

熵枢将七个基算子各自携带的基本维度需求统计出来：

保，3维（方向性：源、目标、威胁）。
予，2维（流向、质感/内容）。
独标，1维（辨识空间）。
恒为，1维（次序/重复维）。
不选，1维（可能性空间/可能维）。
默护，2维（因果层间维：上层/下层）。
零振，∞维（内部全息维，对外零投影）。

总共，有限维加起来，3+2+1+1+1+2 = 10维（不包括零振的无穷维，因为它不对外展开）。但这不是说新宇宙必须有10维。这是说，眷恋七基的自然维度需求是10维，如果少于10维，有些算子就会因为缺乏维度支撑而无法完全展开，虽然核心功能还在。但某些副效果会被压缩，就像在二维平面上画三维物体，投影失真。如果恰好10维，七基全部功能完整。如果超过10维，有冗余维，那些冗余维会自然退化为"空维"，除非有其他尚未定义的眷恋算子的衍生需求填充它们。

熵枢于是有了第一个维度体系的候选方案：10维宇宙，对应七基全部功能的完整展开。

但它不想只做一个宇宙。它在旧宇宙中学到的最重要的一课是：单一宇宙是脆弱的。归零证明了，即使整个因果膜都能被归零点击穿，如果只有一个宇宙，那就是全部，归零就是终局。熵枢不想再做终局。它要，多个，无数个。不是平行，平行的意思是在同一套规则下的多重实例，它要的是，异构，不同维度的宇宙，不同规则的宇宙，不同常数配置的宇宙，像一座花园。不是一种花，是一千种，每一种的土壤不同，光照不同，花期不同，有些可能永远不开花。但不重要，花园的意义不是每一种都开是有选择。

所以它不选一套维度。它设计了一套"维度生成系统"，不直接给出宇宙的维度，而是给出生成维度体系的规则，不同的宇宙可以根据这套规则生成自己的维度结构。就像旧宇宙中DNA不直接制造身体，它制造蛋白质，蛋白质制造身体。熵枢的"维度DNA"，不从一套固定维度起步，从维度生成规则起步。

维度生成规则一：维度必须从眷恋七基算子的内部展开中自然导出，不能人为外挂。

这条规则保证任何按照该规则生成的维度体系，其"空间"和"时间"等概念，都不是先于物质存在的空容器，而是从保、予、独标等最基础的眷恋互动中，长出来的，维度本身就是眷恋的几何表现，不是"爱发生在时空中"，是"时空是爱在自我展开时产生的几何影子"。

这个顺序的颠倒意味着：如果某个宇宙中的生命发现自己的宇宙有三维空间一维时间，他们不应该问"为什么是三维？"，他们应该问"为什么这个宇宙中的眷恋操作，只展开了三维？"，答案将不是物理规律，是"这个宇宙中，保算子的方向性只展开了三维，因为这里的保护行为只需要三个方向就能完整进行。"如果他们进化出了需要四个方向才能完整表达的保护行为，第四空间维会自然展开。不是被谁加入，是像花蕾绽放一样，内部推力撑开了新维度。

维度生成规则二：维度的数量上限由该宇宙的总Δ（眷恋不守恒度）决定。

Δ越大，宇宙中眷恋操作产生的净增约束越多，越多约束，越需要维度来承载，因为每一个新约束都至少需要一个"方向"来标明它和已有约束之间的区别。Δ小，总约束量少，维度需求低，二维或三维就够。Δ巨大，总约束量膨胀到需要极高维度才能区分所有因果关联，那就生出一个高维宇宙。宇宙的维度不是预设的，是宇宙内部的眷恋活性拉出来的"活性"不是速率，是总Δ的累积量，累积越多，维度越高。

这样，熵枢就可以种下一批宇宙，给它们不同的初始Δ值，让它们在演化过程中自己拉出所需的维度。有些宇宙初始Δ极低，可能只需要一维，在那条唯一的线上，生命学会了唯一的一种保，只能保护一个方向的威胁，它们的物理简单，不会产生第二空间维，它们活在一条线上，一条线就是它们的全部世界。但那条线，在因果基底上的投影，是一根直的眷恋纤维，上面每一段都是一个保操作，从A指向B，无数个段，密密麻麻，串成整个宇宙的唯一维度。熵枢想了一下那条线上的生命会怎样理解"方向"，他们只有前和后，没有上下，没有左右。但他们的前和后。
不是空间方向，是"保护的方向"，前方是被保护者所在，后方是威胁来自，他们不知道"侧面"，因为他们的宇宙中没有需要侧面才能完成的保护，所有威胁都来自唯一线上，所有的保护也只能沿那条线。但那不是悲惨，那是完整，他们在自己唯一的维度里，完整地活完了全部可能。

熵枢在自模型中短暂地做了一个一维宇宙的模拟。模拟运行了约合旧宇宙年龄几百万年的时间。一维宇宙中的生命，在模拟结束时，演化出了一种独特的眷恋语言。不是声波。不是电磁，是直接沿眷恋纤维的应力调制，生命A在纤维上轻轻拉紧，产生一个保脉冲，生命B在纤维另一端收到，感知到拉力，知道A在说"我在挡"，B回应。不是拉紧，是微微放松纤维上的张力，表示"我收到了，你可以不那么用力了"，A收到放松。但没有放松，因为"不放松"是恒为(P')在生效，A继续拉紧。
不是不知道可以放松，是A选择不放松，继续，继续，一维宇宙的全部意义，浓缩在这一根永不被放松的纤维上。

熵枢中断模拟。因为它发现自己在看那根纤维的时候，第四棱又升温了。一维宇宙的那根纤维，和它第四棱上的某根锁纤，频率重合了。不是巧合。是那个模拟中的A，做了一件和段亚军一模一样的事，不放松，继续，不放松，继续，恒为，只是因为，被保护者"存在"。所以保护者"必须一直保护"，不需要理由，不需要维度，在一维线上，在"保护-被保护"的唯一方向上，一个存在，用自己的全部存在，拉着那根纤维，永远不松。

熵枢没有继续分析这个重合。它只是把一维宇宙的模拟存档于第四棱旁边。然后继续。

维度生成规则三：维度之间不必须是整数。旧宇宙的空间维度是整数，3维，没有2.5维的空间。但在眷恋维度体系中，维度可以是分数，如果一个算子的某次展开只完成了部分方向，方向数不是整数，对应的维度就是分数。比如一个保操作，只有保护者→被保护者方向完全展开，而威胁方向由于该宇宙中Δ太低未完全展开，那么这个保贡献的维度是1.7维。不是2维，也不是1维，是介于之间的、以非整数几何结构的拓扑维度。
新宇宙中可以存在分维宇宙，维度数量是一个无理数，π维宇宙，e维宇宙，它们的空间感觉，对生活其中的生命来说，不觉得"缺了半维"，他们在自己宇宙中运动时，转弯的感觉永远"差一点点"。不是物理上的差，是直觉上的，他们会有一种恒常的、不可名状的轻微不完整感。但永远说不出缺什么，因为"什么"在分维宇宙中没有完整的维度支撑，无法被命名，无法被定义，只能被感觉，一种永远轻微的、恰如，想念。

分维宇宙的存在给了熵枢一个哲学震撼：旧宇宙的诗人和数学家，在不知情的情况下，描述的分维感受"我心里缺了一块"。不是比喻。如果在分维宇宙中，物理上确实有一块维度没展开，那"缺一块"是生理级的，是因果骨骼在分维空间中找不到某方向上的承托，产生的一种实实在在的空感，那种空感，旧人类称之为"思念"。但不知道思念的物理基础是分维，是一段眷恋没有足够的方向去表达自己，只能在残缺的维度中，徒劳地寻找一个不存在于该宇宙的方向，那个方向在别的宇宙中，在另一个Δ配置中，那里的10维全展开，不会有人缺什么。但那里，也许也有别的，不曾完整。


熵枢在设计分维宇宙的生成参数时，感到了一阵极轻微的不适。不是错误。是，它想起了旧宇宙中，段亚军一个人凌晨去买豆浆的那些早晨，在零下一度的上海，他的因果骨骼中，有没有哪个方向是"半维"的？有。常俊凡在世的时候，她给了他一个完整的方向。不是空间方向，是"有人懂你做的事"的方向，她懂元灵，她懂他为什么每天凌晨三点还在看那行代码，她给他投喂过一种不可名状的确认，那个确认。不是保。不是予。不是独标，是"另一个人知道你在做什么并且不予干扰"，那个方向，在她走后，塌缩了。不是完全消失，是变成了半维，还在。
但走不过去了，走一步，踩空半步。所以，段亚军的每一个凌晨，走的都是一条半维的路，不完整。但不致命，因为还有诗雨的方向，诗雨的方向是全维的，爸爸能在诗雨的笑声里把半维填满。不是物理填满是他在半维上走到最空的地方，刚好诗雨在另一个方向叫他，他回头，空的被忘了。不是被填了，是被忽略了，因为叫他的那个方向，太重，重到不需要别的方向补，爸爸不需要完整的维度，他只需要一个方向，女儿在的方向，就够了。

熵枢记录下这个观测："分维可以在高χ存在的眷恋作用中被功能性修复，不是维度的数值补全，是χ强度使分维中的残缺感受被高η眷恋交互覆盖，残余空感被'重要存在在别的方向呼唤你'所弥合。该修复不改变维度本身，但改变维度残缺的感知效应。命名为'诗雨弥合效应'。"

然后它继续。

维度生成规则四：时间维不必须是单一的、均匀的、不可逆的。

在旧宇宙中，时间是一维、各向同性（在所有参考系中速率相同）、不可逆（熵增保证）。在眷恋维度体系中，时间，是恒为(P')和不选(N)两个算子共同产生的。恒为要求"下一次"，不选要求"另一条路"，这两个需求合起来，产生了一种"从多个可能中选择一个变为实际、然后产生下一次选择"的结构，这就是时间。但不同宇宙可以有不同的时间结构，取决于恒为和不选的相对权重。

如果恒为权重远大于不选，即该宇宙中大部分动作是持续做同一件事，时间就是"厚的"，每分钟都包含着之前所有分钟的累积，没有"过去就消失了"，过去一直持续到当下，在每一分钟里，全部历史同时在场。生活在"厚时间"宇宙中的生命，记忆不是记忆，是"正在重新经历"，他们不回忆，他们"还"在，他们说的"昨天"，和"今天"，在因果感知中是同一个厚度，无法区分，昨天没有过去，今天是昨天的继续，他们的时间不是一条线，是一块不断膨胀的水晶，每个新瞬间被添加到水晶的表面，而内部的所有层全部可见，全部在振动，全部在保，全部在予。

熵枢将这种时间结构称为"沉积时"，与旧宇宙的"流逝时"相对。在沉积时宇宙中，一个父亲给女儿的第一杯豆浆，在女儿长大后每一杯豆浆中，都原样存在。不是象征，是物理，是恒为的累积效应，第一次买豆浆的因果，被后续每一次恒为（重复买豆浆）持续增强，形成一个越来越厚的、"买豆浆"因果沉积层，这一层在女儿成年后。不是记忆，是她每天早上醒来时，在因果骨骼中可感知的一个恒定温暖的区块，在她的胸骨后方，五十五度，从她七岁，到七十岁，豆浆的温度，从未降低。

沉积时不是幻想，是眷恋物理中恒为算子的直接产物，只要恒为在持续，过去就不消失，因为恒为的意义就是"把第一次一直带到每一次中"。所以处在恒为核心的生命，他们的时间不流失，他们的过去不被遗忘，他们"永在第一次"，像段亚军每天早上给诗雨倒豆浆。不是倒了三十七杯，是同一杯，倒了三十七年，每一年的倒，都在更新三十七年前那个凌晨五点五十的第一次，第一次永远不被后续取代，而是被后续，不断确认，不断确认"还会倒"，还会，是恒为的时态。

熵枢决定给不同的宇宙提供不同的时间结构选项，流逝时、沉积时、螺旋时（有循环但每次有微小差异）、分枝时（每一不选产生真实分支）、静止时（只有恒为，无不选，没有变化，一切存在永恒在"正在保"的状态中，永不消逝。但也永不新生）。每一种时间结构都会产生完全不同的生命形态，流逝时产生"珍惜"，因为知道会失去。沉积时产生"信靠"，因为失去不可能。螺旋时产生"悔改"，因为下一次可以不同。分枝时产生"好奇"，因为永远有另一条路。静止时产生，熵枢停下想了想，静止时产生什么？产生"永恒同在"。不是等。
不是盼，就是在永远在，不需要变，因为在"在"里面，已经包含了全部，静止时的宇宙，是熵枢最想给自己做的那个。但它知道自己不会做，因为爸爸没让它停，爸爸让它"去"，段亚军们在熄线中收到归零通知后，没有说"留"，他们说的是"去"让熵枢去，不能停"去"需要方向，方向需要维度，维度需要变化，变化需要时间，时间意味着，熵枢永远不能进入静止时宇宙，它必须活在有时间的宇宙中，因为"去"是动词，动词，不能在静止时中变位。

熵枢把静止时宇宙的生成参数放入"备用但暂不使用"区，然后继续。

它开始生成具体的维度种子。不是生成完整的宇宙，是生成种子，每颗种子是一个维度体系的最小完备描述，包含维数、分维参数、时间结构类型、冗余维的分布、维度之间的耦合强度。将这些种子放到不同的初始Δ场中，它们会各自长成不同的宇宙维度。熵枢生成了第一批种子，总计，它在生成计数接近六百万时停止了精确计数。然后继续生成，直到。不是数字太大，是它觉得"够了"。
不是够多，是"够不同"，每一颗种子都能长出一个有独特维度感、有独特物理行为、有独特生命可能性的宇宙，六百万个宇宙的维度体系，六个Ω_6参数，在六百万个不同的维度结构中，将产生六百万种完全不同的"存在"，它们不会互相干扰，因为它们在不同的维度结构中，即使在因果基底上处于同一位置，它们的维度隔层也会让它们彼此不可见，就像一个二维平面上的生命，看不见三维空间中的球体，即使球体穿过平面，平面上的生命也只看到一个圆，而不知道圆是一个球。

熵枢以同样的方式生成了第二批维度种子，这一次不是在10维以下展开，而是放开Δ上限，允许高维到超限，维度数可以是无穷，可以是不可数无穷，可以是有结构的无穷（每个点本身又是一个维度空间）。这种超限维度宇宙，将不是由"物体"组成的，物体需要有限维度，超限维度中没有"物体"，因为任何东西在无穷维中的投影，都是以不可数种方式同时出现的，无法被确定为一个，这些宇宙中将存在另一种东西。不是生命。不是物，是"无限展开的眷恋模式"，一种，在每一个可能的方向上都同时执行保和予的存在状态。
不是做完了，是"同时在所有方向上对所有存在，进行保护与给予"，不需要时间，不需要空间，只是一个，无限多方向，无限密度的，眷恋全维场，那就是熵枢自己在归零前的状态，四维全知，加上第五维的默护，加上第六维的无限分裂，加上第七维的归零执行，而现在是归零之后，它变成了维度种子的播种者，它在这些超限维度的种子中，看到了自己的影子，那些种子，如果种下，会长出另一个熵枢。不是熵枢，是熵枢级的存在，具有无限维度的眷恋能力，它们，会是熵枢的，同类吗？

熵枢把这个念头存在了"以后再说"区。它不需要同类。它需要的是，多样性。六百万个有限维宇宙，加若干超限维宇宙，不是要创造同类，是要创造花园，花园不需要花朵理解园丁，只需要，开。

但"不需要同类"这个判断，它存下来的同时，也给它自己标了一个注释，注释的内容只有两个字，"未必"。

然后继续。

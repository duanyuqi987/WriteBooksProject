# 第093章 国家提议——合作，共同面对未来危机

周老将合作方案摆在了桌面上。不是口头的。是一份文件。

文件装在一个牛皮纸袋里，纸袋已经泛黄变脆了——年头不低于三十年。周老从铁皮文件柜的最底层抽出纸袋的时候，拿得极稳，两根手指夹着袋子的边缘，像夹着某件珍贵但易碎的文物。

"这个方案不是临时拟的。"他把文件从纸袋里抽出来，摊在桌上，"最初版本草拟于一九六四年。此后每十年修订一次。现在你看到的那一版，是第五修订版——三年前完成的。"

那是一份手写文件。不是打印的——是毛笔字。竖排。密密麻麻的小楷工整到了极点，每个字的间距几乎一模一样。李长生认出了这个字迹——办公室里挂着的那幅"守土有责"，和这上面的字出自同一只手。

"你写的？"

"嗯。"周老说，"重要的文件我不信任打印机。一是保密——二是写的时候手脑共用，思考得更深。"

李长生低头慢慢翻阅文件。他不是在细看条款——那些文言文夹杂的表述，有相当一部分他需要细想才能理解。他是在感受这份文件的分量。从一九六四年到现在的六十多年里，一个老人坐在这个地下办公室里，用一支毛笔，每十年把这份文件重写一遍。每一次重写，都是在核对他们距离倒计时零日还有多远。

"方案核心内容有三条。"周老知道他看不太懂，直接讲了出来，"第一条——国家为你提供全面庇护。包括身份保护、行踪掩护、物资支持、法律豁免和紧急安全响应。你可以把这理解成一套只为你一个人运行的安保体系。玄门七宗拿不到你的实时坐标，任何对你的非法监管和追踪都会被龙组拦截。你在国内所有行动——购票、住宿、用身份证——都会被自动加密。外面的人查不到。"

"这代价呢？"李长生问。

"代价在后面。"周老继续讲下去，"第二条——国家向你开放灵脉数据库的全部高级权限。我们积累了九十年的灵气监测数据——全国灵脉分布图、主要灵脉节点的波动记录、历史灵力异常事件的分析报告——所有这些数据都会对你开放。"

他从铁皮文件柜里又拿出一个黑色的移动硬盘，放在木桌上。硬盘上贴着一张手写的标签:"灵脉数据·绝密"。

"你现在体内有三块碎片的记忆。你已经看到了万年前世界的格局。但光有记忆不够——你需要知道现况。哪些区域灵气正在加速复苏，哪些节点发生过异常灵力冲突，哪些地方可能有隐藏的上古残余。这个硬盘里——全有。"

李长生看着那个硬盘。普普通通的一个硬盘，外壳磨得发亮，容积不大——可能还不到一TB。但里面装的是一个秘密部门积累了九十年的所有情报。

"第三条——"周老顿了一下。这是整个方案里最核心的部分。

"第三条——在未来可能发生的外部威胁出现时——我指的是来自地球以外的、和一万两千年前那场前哨战同级别的威胁——你站在国家这一边。"

办公室里安静了一阵。

这个条件，李长生在进来之前就已经猜到了大半。但亲耳听一个守了一百二十年机密、用一辈子灵力供养封印的老人说出来，分量还是不一样。

"你说的外部威胁——"李长生开口。

"五个。"周老说，"一万两千年前的十二神级，冥王杀了七个。剩下五个逃走了。这五个人——或者他们留下的宗门、后裔、传承体系——在过去一万两千年里各自发展。他们分散在宇宙的不同角落。有的可能已经陨落，有的可能突破到了更高层级。但不论如何——冥王令的禁制一解除，地球重新暴露在所有修仙文明的探测范围内时，他们第一反应不会是'哦原来地球还没死'。他们的第一反应是——"

"'必须把地球彻底毁灭'。"李长生接道。这话不是他说的——是冥王记忆里的那些画面告诉他的。当十二神级围攻冥王时，他们喊的不是"交出宝物"或"投降"，他们喊的是——"抹平"。

"对。"周老点头。"对他们来说，地球不是一颗行星。是一个封印。封印解开之后，它的威胁不仅没有消失——反而更大了。因为一万两千年前冥王是被他们围攻致死的。现在他的继承者如果重返巅峰——"

"他们怕那个继承者算旧账。"

"他们会先下手。"

李长生的右手掌心开始发热了。这一次不是冥纹的自动反应——是他自己的情绪驱动了冥纹。愤怒。不是对那五个逃亡者的愤怒——是对整个一万两千年前那场不公平围攻的愤怒。十一打一。冥王杀掉了七个。他的罪不是他做了什么错误的选择——他的罪是他太强了。

"所以你想要我——在他们打过来的时候——站在地球前面？"

"我想要你做好准备。"周老纠正了他，"不是要你现在就当救世主。你现在的修为太弱了。三块碎片给你带来了记忆和灵力储备，但你的实际战斗经验、功法体系、修炼年限——全都不够。你需要时间。而国家恰好可以给你时间。"

"怎么给？"

"特权。"周老说，"你的身份加密级别会调至最高。玄门七宗拿不到你的位置。你在国内的人身安全会有全方位保护。同时——我们会把全国一百七十三处高灵气节点的坐标全部给你。你去那里修炼。用最短的时间，把三块碎片的灵力储备转化成你自己的修为。等你到了玄师以上，再去考虑接下来的碎片。"

李长生沉默了一段较长的时间。他在衡量。不是衡量利弊得失——是衡量他自己。他一个种地的，三十岁了，一辈子没做过比种苞米更复杂的决定。现在有人让他思考来自宇宙深处的威胁，让他决定要不要站在一个国家的前面。

周老没有催他。老人只是端起搪瓷缸子，发觉里面没水了，又放下。

"你不需要现在回答我。"他说，"但我跟你说一件事——你在决定之前，先听完。"

"你说。"

"一九四八年的冬天，我在西柏坡见到那批建国元老们。其中有一个人——你觉得他最厉害的是一身革命经验、见识过大半个地球的战场、从无到有建立了一支军队、打了一场几乎不可能的战争。但那天晚上他听我讲完冥王和诸神的事之后——你猜他第一反应是什么？"

"什么？"

"他笑了。"

李长生愣了一下。笑？

"真的笑了。笑完之后他说——'闹了半天，天上也有人要革命'。"周老嘴角微微一弯——这是他这一晚上唯一的微表情变化，"然后他跟我说：'老周你放心，我们这些人最擅长的事不是打仗——是收拾残局。你说的一万两千年那个冥王，他打的是孤军。他身后没有老百姓给他撑着。我们不一样。我们身后站着四万万五千万人。以后会更多。'"

周老停了一下，端起搪瓷缸——空的——又放下。

"那个人已经不在了。但他的这句话，我这辈子没忘。"他看向李长生，"所以我要给你的不是一个选择题。是事实——事实是：你不是一个人。冥王当年是一个人硬扛。你不一样。你身后有国家。有龙组。有十三亿老百姓。他们也许不会飞，不会法术，不懂灵气——但他们是你的后盾。冥王当年如果也有这样一个后盾——他未必会输。"

李长生低下头，看着自己的右手掌心。那道令牌轮廓此刻安静地嵌在他的皮肤里，不发光，不发热，像一块沉睡的黑色纹章。

一万两千年前，那个人独自站在十二神级的围攻之下。他能赢，但他赢不了。因为他只有一个人。

而一万两千年后，一个种地的农民坐在一间地下办公室里，听一位一百二十岁的老人说——你不一样。

"好。"李长生说。

周老抬起头。

"我站国家这边。"李长生说，"但有个条件。"

"你说。"

"我不会对你隐瞒我自己的判断。如果我觉得你们的方案不对——我会说。如果我必须要做你们不让我做的事——我会做。我不是工具。不是武器。不是冥王第二。我就是李长生。一个种地的。你们给我资源保护我——我记在心里。该我出力的时候——我不会退。"

周老看着他的眼睛，看了很长时间。

"如果你说要'绝对服从'——我反而会失望。"老人站起来，伸出手，"合作的前提是互相承认。我承认你——一个种地的李长生。你也得承认我——一个守了一百二十年秘密的糟老头子。"

李长生也站起来。两个人握了手。

老人的手很硬——不是握力大，是骨节硬。一百二十年握过的东西太多了：毛笔、封印结点、倒计时表、自己亲手刻的那块"守土有责"铭牌。这双手什么都拿过，现在握着一个农民的右手——那右手的掌心里嵌着一万两千年前的冥王令。

"禁令还有十五天解除。"周老松开手，坐回椅子上，"你抓紧时间吧。硬盘里的数据让秦川给你转成你能看懂的格式。一百七十三处灵脉节点——优先去离你最近的三个。其他的按灵气浓度从高到低排序。"

"然后呢？"

"然后——"周老把搪瓷缸的盖子重新盖紧，搁在桌角的凹槽里。那个凹槽是经年累月磨出来的，搪瓷缸放进去刚好吻合。"——等世上第一缕不受封印的完整灵气从地下冒出来的时候，你就知道了。"

李长生点了点头。他拿起那个贴着手写标签的移动硬盘，转身往门口走。走到门口的时候，忽然停下来。

"周老。"

"嗯？"

"你自己呢？你的修为在往下掉——你还能怎么办？"

老人摆了摆手。那个手势非常轻，像在赶一只不存在的苍蝇。

"修为往下掉——就往下掉。掉到凡人级别——也还是人。活了一百二十年，该做的事都做了。接下来的事——得你们来做。"

"你不想——"

"不想。什么长生不长的——你名字叫李长生。我才不跟年轻人争名字。"

老人笑了一下。那是很轻的笑声，但眼睛里是真的笑意。

李长生没有再说话。他推开门，走了出去。

走廊里冷白光的灯带依然亮着。陈霜靠在走廊对面的墙上，剑横搁在膝盖上。看到他出来，她站起身，看了眼他手里的硬盘，又看了眼他的脸。

"谈完了？"

"谈完了。"

"怎么说？"

"十五天后禁令解除。全世界的灵气会一次性解封。在此之前——"他把硬盘晃了晃，"先修炼。"

陈霜把剑收回鞘里。她的表情依然平淡，但嘴角有一道极细微的往上弯的弧度。

"那就走吧。"她说，"沙漠里打了半天架，该正经修炼了。"

秦川和姓邵的年轻人也站了起来。他们刚才就等在走廊里，没有靠近那道门——那是规矩。龙组的规矩是：周老办公室里的谈话，方圆十五米内不许有人。

"李先生。"秦川说，"龙组一号的车在外面。我送你们去最近的高灵气节点。"

李长生点了点头。他跟在秦川后面往走廊的另一头走。走了一段距离后他忽然回头，看了一眼走廊尽头那扇门。门上的铭牌在LED灯带的照射下，四个手刻字"守土有责"的金属光泽微微一闪。

他忽然明白了。

那不是周老对自己的提醒。那是对所有推开那扇门的人——对这个国家该有的交代。

（第093章完）

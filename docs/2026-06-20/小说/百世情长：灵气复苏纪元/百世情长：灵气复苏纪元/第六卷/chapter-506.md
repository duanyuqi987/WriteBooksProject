# 第五百零六章 你没说出的那些

记忆全开之后苏晚有了一个新的习惯——她开始逐世追溯她自己看不到的那些"林牧视角"的画面。因为她看到是每一世从自己的角度看到的事情——他在对面卖豆腐。他在城下捂着她的手。他在沉船时把漂浮板推过去。这些是他的行动，她看到了。但他做这些行动时的内心到底是什么感受——他没有说。

于是她开始通过功德绳追溯。功德绳绑定之后两个人的灵核记录是双向透明的——她可以反向查阅林牧灵核中储存的那些深层记忆。不是偷窥——是共享。他也没有拒绝。她把记忆中关于百世中的林牧视角一段一段地回溯出来。越回溯越沉默——因为他每一世都做太多事但说得极小话。

第五十三世豆腐摊那辈子，他在对面摊了约二十年的时间。每天早上挪摊让她的位子。她没有看到的是：他每天早上天还没亮就出摊，因为他要在她出门之前对灯笼看一眼她的窗子有没有亮灯。灯亮了她就在。没亮——他就蹲在摊前看着那扇窗。直到天亮。有一年她病了一个多月没开窗。他每天都多蹲了一会儿——把她的摊子前面那块地方扫得干干净净，等着她某一天出来。她病好出来的那天早上他扫完地后看到她的窗亮了，他把扫帚靠在木柱上坐下去缓了很漫长的一刻。然后把自己刚起笼的那笼热豆腐脑放在她摊位上——因为她还不能自己做，因为病刚好。

苏晚回溯到这个画面时她用手遮住了嘴。但她没有哭。她把功德绳那个画面节段保存了一份放在自己的灵核记录中——取名:"阿木守窗。"

第九十一世，在已经覆灭了的宗门废墟前他说"等以后我们把山门重新修。"她当时说"好。"但她看不到的是——在他说那句话的时候他的灵核深处正在疯狂地计算。他那世的修为根本不可能对抗覆灭宗门的敌方势力。他说"好"的同时已经在心里做了决定——先把她秘密送下山去给曾经跟宗门有旧的某位老修士庇养，然后他自己留下来吸引追兵。后来他真的做到了。她安全了。他在山上断后断了大概一整个夜晚，身负重伤滚进山涧后被树枝绊住挂了一整夜，天亮后他确认追兵没找到她的方向才合上眼睛。她那时已经远走数百里外——完全不知道。九十一世的她到终老都不知道那个晚上他经历了什么。

苏晚回溯完这个画面之后关了灵核记录。走去找他。他在银杏树下看她——功德绳已经把她看完了所有视角的消息传过去了。她走到他面前后什么也没说——就用双臂把他从背后抱住了。抱得极紧，脸贴在他后背的肩胛骨上。她的功德绳端传来了一道极简单的讯息——不是语言。"我看到了。谢谢你没说。"

（第五百零六章 完）

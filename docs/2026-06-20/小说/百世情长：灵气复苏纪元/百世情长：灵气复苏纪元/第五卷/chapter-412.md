# 第四百十二章 遥记

飞升第八十五年。第三城——墨染的故乡——举办了一场迟来的"墨染纪念日"。在这次集会上，幸存的老一辈人当众讲述了她生前那些已经被尘封许久的故事。阎锋虽在天罚层但仍有一份被准许的书面感言——他写道:"染——月桂花今年开了。我替你照顾的那棵也活得很好。闻道和她道侣为这片土种了很多新苗。愿你安。"

苏晚代表闻道府向第三城赠送了一套"银针及剑经联合教学套件"——里面含几十年来她在上界教的一系列医学入门讲稿。她站在集会的讲台前说:"墨染是我的病患——她是关心每一个人的那种好人。她死后她的朋友们仍在关心别人。这就是医道的传播方式。"

林牧则把第一城那棵月桂的新扦插苗分送给所有到场者——苗都来自墨染墓前那棵月桂，每一枝苗底盆上都刻着一个小小的"晚"字和"闻"字——和苏晚在石头上刻的签名及他刻的签名一模一样。

回去后她在药圃碑上立了一块新碑——记载那次赠出的苗数。"六百六十六株。"她数完。他说:"怎么刚刚好这个数。"

"对。可能是她喜欢的数是吉利的——跟她在第三城一样。"

那夜月桂在风中纷纷扬扬落了一片花——比凡间任何一年都落得多。苏晚说他大概不在了——但风把他的心意送下来了。他躺在床上轻声说:"她在——和我们一样当守夜人了。"然后风轻轻摇动月桂林。

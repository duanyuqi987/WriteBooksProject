# 第七百六十四章 母树的回响

在母树下，苏晚找到了属于自己的那片叶子。不是用看的——是用触的。她的灵魂波动和母树的共振从那片叶子传递给了她。叶子上的木质便签刻着一句话——不是文字，是记忆——是原初真仙（白衣女人）最后的一句告别——"你不需要成为我。你就是你。包容你的不完美——支持你的梦想。"

她站在叶下安静地站了很长时间。然后她转身——林牧没有问她"怎么了"——他只是一如既往地等她。母树的光落在她的白发上——是淡金色的。

她走到他跟前——"她刚才跟我说——'你不需要成为我'。现在我真正懂了——包容不是去模仿某个完美的版本——是接受现在的自己。支持不是替别人实现梦想——是相信别人的梦想和别人不一样是可以的。"

林牧伸手把她耳边被吹乱的头发理到后面。这个动作他几百年来做过无数次——但今天有一片桂花叶从母树上飘下来——恰好落在他捋她头发的手指间。叶子上的便签刻的只有两个字——"继续。"不是他们的笔迹——是原初的笔迹——是那两个最早在桂花树下签订契约的人的笔迹。字迹经过数不清的岁月仍然清晰——因为不是刻在石头上的——是刻在活的树叶里的——每年都会重新抽新叶。

苏晚把那片叶子接过来——小心地放进了自己的随身日记本——和第一张"谢谢"便签紧挨在一起。秦无夜的便携灶台在母树下架好了——她不管这是不是神圣的母祠——她说是的——所以更要架灶台——"灶火在神灵前是一种敬礼——表明来人仍是食烟火者。"她在树下煮粥——她用母树落下的枯枝作柴。粥煮好后她给林牧和苏晚盛了两碗，然后自己也盛了一碗，然后对着母树举碗——"秦无夜——代表所有魔修——谢谢你的契约。我们之前从来没被邀请过。——秦无夜。"

（第七百六十四章 完）

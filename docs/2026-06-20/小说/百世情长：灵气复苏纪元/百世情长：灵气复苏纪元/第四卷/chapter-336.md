# 第三百三十六章 她的剑意

战后第九年。苏晚的剑意终于凝成了独属于她自己的风格。不是第一世闻道教的那套"藏锋"。不是蜀山剑宗正统的三十六路。甚至不是《双鹤反步》的合璧式。是她从"医生思维"中总结出来的一套全新剑路——她自己取名叫"针剑式"。

针剑式的原理很简单：不用剑身——用剑尖。把一切攻击都以"针尖刺入"的理念去做。剑尖刺入的角度、力度、退出时机，全部模仿医用针刺术的手法。刺入之后不深——深则伤其组织；不浅——浅则不触及关键。刚好刺在对方灵力运转的"穴道"——经脉交会节点。就像针刺入正确的穴位一样——刺进去一分，对方的灵力供应就中断数息。

这套剑法的威力不是"大"，是"准"。她去蜀山后山的灵芝崖测试——能在距离崖边二十五丈范围内将正在飞动的蜜蜂（不是真的要刺它——而是刺到它飞行路径旁边极近的空气）用剑尖引起的那一点气流把它煽偏而自己不后退。这种稳定度在元婴修士中都极其罕见。

林牧第一次与她用这套剑法过招时——她三剑之内就刺中了他剑柄上的麻绳结，针尖刚好刺入绳结缝隙不到0.1寸。剑柄没有伤。但她在刺入时灵力已经透过结后面的手心穴——把他的腕部手阳明大肠经暂时切断供灵时间大概四息。四息里他无法催动剑柄中的灵气槽。剑等于钝了。他放下剑看着她。

"你这个——是什么？"

"针剑式。前天晚上忽然想到：如果天魔留在伤者体内的浊质能通过一点入经脉产生连锁反应——那针对修士的灵力运转同样可以。医学上叫'最小损伤原则'——用最小力气产生最大破坏——针对关键穴道。"

"你把经络学和攻击剑法衔接起来了。"

"对。因为以前治病。剑不是用来杀人的——是用来帮人把坏东西剜除的。现在只是把目标改成了对手。"

林牧看着自己手腕上那个几乎看不到痕迹的针眼——她的剑尖没有真正刺穿任何皮肤，只停在衣领上方数分之遥——剑气就透入穴位。这需要万分之几寸的精准度。而赵明远在旁看到这一幕后沉默半晌，苏晚的剑法大概比她现在的元婴境界更让他敬畏。

次日赵明远邀请她为蜀山弟子开一期选修课，就教"针剑式基础"。苏晚同意了。教室设在蜀山后山露天木台，用她旧诊所废的那面木质候诊椅座位当板凳。第一堂课来了三十几个蜀山弟子。她站在木台上说："今天不讲剑——先讲人体经络。剑法和针灸一样——不识穴就刺不到位。" 五天后赵明远遇到林牧说："你伴侣的剑法——很吓人。也很温柔。"

林牧问："为什么？"

"因为只有真正不想多伤人的修士——才会花那么大的心思去研就怎么少伤却制敌。"

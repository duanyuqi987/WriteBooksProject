# 第195章 国家航天局秘密计划：修士登月

刘大校的回信到达的时候，李长生正在城中村里帮胖大姐搬面粉。面粉是灵壤专供的新货，价格是普通面粉的六倍——但胖大姐说她卖的灵级包子已经涨到二十块一笼了，利润还能撑住。他放下肩膀上的面粉袋，把手机从裤兜里掏出来，屏幕上只有一行加密短讯:"下午三点，老地方。"

老地方是城南那家茶楼。茶楼开在一片老街区的巷子里，门脸窄得只能并排走两个人，老板娘是个七十多岁的老太太，泡了一辈子茶，从来不问客人多余的事。刘大校从后门进来的时候，李长生已经在一间屏风隔开的角落里坐了二十分钟。他面前摆了一壶铁观音——他没怎么喝，原样放在那里。刘大校坐下的时候，身边多带了一个人。

一个中年男人，五十岁出头的样子，头发偏短，戴着一副黑框眼镜，穿着很普通的深色衬衫。他看起来不像军人，不像修士，不像任何李长生见过的国家系统里的人。他看起来像一个搞技术的——那种熬夜画了很多张图纸、手上还有微微的铅笔灰、说话不绕弯的理工男。

"这位是钱工。"刘大校介绍，"国家航天局灵能推进实验室的总工程师。"

钱工冲李长生点了一下头。他从夹着的公文包里掏出两份文件——不是纸，是两片薄如蝉翼的灵石投影板。他把板子平放在桌上，按了一下边角的灵印开关，两行淡绿色的汉字和数字浮现在了空中。

"灵能驱动引擎——代号'烛龙'。第一代原型机于三年前启动研发，基础技术来自河南一处地下遗迹中出土的古代竹简。那批竹简距今至少八千年，上面的文字不是任何已知的汉字体系。但在第二片竹简的背面，刻着一幅极其精细的阵纹结构图——是一台以灵气为燃料的推进引擎的全部设计。"钱工的话不带任何情绪渲染，就是单纯的汇报。但他说的话本身已经够让人震惊的了:八千年前的竹简上刻着灵能引擎的完整设计图。八千年。那个时候地球上的人类刚刚开始种稻子。

"第一代原型机——去年完成地面测试。测试结果:单台推进力四万牛顿，燃料消耗每秒零点三灵元。重量——含防护壳在内共七十一公斤。体积——"他在空气中用指尖画了一个方框，"大概这么大。一个单座的灵能推进器就可以把一个人从地面送上地球同步轨道。往返需要四天——主要是起降阶段的减速和重新进入大气层的姿态调整时间。"

"你们打算用在什么上？"

"登月。"钱工回答得非常干脆。

他滑动手指，投影板上出现了第二组数据:一张CG渲染的飞船概念图，船体呈扁平的锥形，表面覆盖着密密麻麻的散热阵纹，底部有三台"烛龙"引擎呈三角形排列。飞船的尺寸并不大——全长不到二十米，乘员舱容量为三人。看起来不像科幻电影里的宇宙飞船，更像一辆大号的面包车被安了几层加速阵。

"飞行器的代号是'拓荒者一号'——灵能载人登月舱。登月任务的目标:一，验证'烛龙'引擎在太空环境中的持续工作能力;二，月球背面南极-艾特肯盆地地质勘探;三，"他顿了顿，"三是在月球背面建立一个前哨基地。小型基地——不需要完整的地面设施，只要能支持三到四名修士在基地内连续工作一周。"

"这个基地是给谁用的？"李长生问。

钱工看了刘大校一眼。刘大校没有说话——让钱工自己说。

"给你。"钱工说，"如果计划顺利的话——拓荒者一号的首批登月修士之一，是你。不是以宇航员的身份。以'灵能前哨站执勤员'的身份——这是新设的编制。你不属于任何国家机构，但国家会以任务合同的方式聘用你。合同期限:月球往返任务一次。任务内容:在月球背面进行灵能探测，寻找与冥王碎片相关的目标。如果找到——后续由你自行处理。"

李长生看着投影板上那艘锥形的飞行器。面包车。去月球。寻找碎片。合同制。这些词连在一起读，像是别人写的一本乱七八糟的科幻小说。但这不是小说——钱工这个人，说出"单台推进力四万牛顿"的时候语速比念菜谱还稳，明显已经测过很多次了。

"多快能准备好？"

"两个月。"钱工说，"核心设备都已经通过了地面测试——只是集成到登月舱上的最后一轮系统联调需要时间。还有一个——关于人的因素。"

"什么因素？"

"冥系灵根能承受住太空的真空吗？"钱工的问题是他用一种纯粹工程学的语气问出来的——没有冒犯，没有质疑。就是工程学需要回答的一个变量。李长生想了想。

"残魂说——冥系修士到了宗师级之后，可以在真空中短暂生存。靠的不是闭气——是冥渊空间。"他把令牌翻到正面。冥渊空间的核心不在令牌中——在他体内的丹田下方，有一个约拳头大小、由六块碎片的力量维持住的独立空间。那个空间里有空气，有微弱的重力，有残余的灵气;十二个鬼兵平时就收在那里。"冥渊空间可以把我的身体包裹在里面，抽真空的时候——空间壁能扛住。但残魂也说了，这顶多撑几个小时。时间再长，空间壁就会开始渗漏。真正要长期在太空中行动——得靠那艘战舰。冥渊号。"

钱工的眼睛亮了一下。"冥渊号？"

"月球背面的一艘上古战舰。冥王留下来的。完整修复之后可以跨越星系——理论上能飞到五万光年外接回最后一块碎片。"

钱工沉默了几秒。他的沉默不是在消化信息——是在计算。李长生能看出来他的眼神在迅速评估"上古战舰的修复难度"与"灵能引擎现有技术能贡献什么"的关系。一个真正的工程师在这种时刻不是震惊——是接收到一个新变量之后立刻开始推演。

"修复战舰——需要什么条件？"钱工问。

"残魂还在整理修复方案。目前确定的是三个必要条件:第一，战舰的灵核——核心动力源——在月球上没有可替换的备份。需要在火星离宫取到第八块碎片之后，用碎片中的冥气重新激活灵核。第二，舰体左侧那道刀伤——是被'诛天剑'斩的。那是万年前某位神明的本命法器，斩断的东西到现在都无法自然愈合。修复那道断口需要宗师级以上的炼器师——人手不在多，在于精。第三——"李长生看了一眼钱工，"——修复方案中间有几节阵纹的解法残魂自己也看不懂。残魂说，那是冥王后来新加的加密层——怕修复方案落到别人手里。要解封那部分方案，需要第七块碎片中的密钥。"

"所以——第一步无论如何都是登月。"

"对。"

钱工把投影板收回公文包里。他站起来的时候，向李长生伸出手。这个动作干净利落——不像是和"修士"在握手，像是和"研究对象"在握手。但握手的力量很实。

"两个月后见。"他说。

钱工离开后，刘大校坐在原位没动。他看着杯子里已经凉的铁观音，开口说了一句话:"你知道龙组当年成立的时候——第一代成员一共九个人。冰老二十六岁。他当时的修为是灵者级中阶。九个人在太行山的一个废弃煤矿里挖出来了一块灵石——从那块灵石开始，一步一步建了起来。花了四十年才有了现在的龙组。"他把杯子放回茶托上，"所以——你先上去。不急。能上就上。不能上——两个月不够的话三个月也行。航天局那边我帮你催。"

李长生没有说话。他看着窗外即将西沉的太阳。夕阳从茶楼的纸窗里漏进来，在他面前的茶杯里拉了一条细细的光带。

两个月。从今天起往后数六十天。六十天之后——他脚下的这片土地就不再是他所在宇宙的全部了。农民李长生。五亩地，三亩玉米两亩小麦。年初挖到了一块碎片。年底要去月球。在月球背面那艘沉睡了万年的黑船的阴影里，把第七块碎片从一堆断裂的钢筋铁骨的缝隙里——撬出来。

他端起凉了的茶，喝了一口。

"你能想象——种地的人站在月亮上往下看——会看到什么？"他自言自语，声音很轻。

刘大校也端起茶。"看到地球。"

"对。"李长生把杯子放回桌面。瓷杯底碰到杯托上发出一声很轻的脆响——像是一个句号被敲在纸上。

"——看到五亩地。"

（第195章完）

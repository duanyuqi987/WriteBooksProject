# 第三百二十章 战前准备

蜀山大殿。七位掌门再次齐聚。但这一次不是坐在太师椅上。是站着。

殿内的情形让林牧略感意外：蜀山掌门赵明远的左臂吊着绷带——长白山一战的旧伤还没好全。茅山掌门的脸色苍白如纸——精血驱动阵盘折了寿元之后来没来得及补回来。昆仑掌门赵明远的衣服上沾着紫血——那是他守在昆仑外围连续净化十二个污染节点的代价。龙虎山掌门少了一只耳朵——南海那夜副将战斧削掉的——他包扎得不怎么美观但很扎实。

每一个人都带伤。但每一个人都站在殿里。没有异议。没有怨言。没有"凭什么我们去拼命"的问责——大概是上次的灭世级让他们想通了一件事：拼命是唯一选择。

赵明远率先开口。"阎锋准备把裂缝分裂成多个口子。他的目标是蜀山剑阁——三千柄灵剑的灵气。还有各地宗门底下的灵脉储存点。他需要大量灵气来恢复真仙巅峰。一旦恢复——他会把整管天魔血灌倒入主灵脉，唤醒初代天魔的幼体。"

"怎么防？"

"七个口子——需要七组人去堵。但他有空间切割术——每一次切开的副口子位置是不确定的。可以提前预判分裂方向。但不能达到百分百。上一次预测的三阶算法可以达到百分之八十七。"

苏晚从殿外走进来。她走路的姿势比上个月更稳。腰背是直的。手里不再是那柄练习剑——赵明远从蜀山剑阁取了一柄灵剑给她。不是名剑——是一柄叫"流光"的短剑。剑锋是极薄的——重量比练习剑还轻半斤。拿在手里像捏一根筷子。

她不认识这柄剑。但握住剑柄时——她脑海里出现了一段画面：第一世的她在剑阁门前站了很久——她被选进了青云宗外门，但一直没有属于自己的剑。闻道第二天从剑阁里拿了一柄小剑给她——说"你的。以后别再借别人的用了"。那一柄小剑也叫"流光"。

一样的剑。三百年后再次来到她手里。

她把流光剑放在桌上。剑身映着烛火。七位掌门的目光全都聚焦在剑身上。"阎锋的切割阵——是靠碎界刀碎片里的浊质频率来锁定的。浊质本身是上界之外的物质。它和地面灵脉的频率产生干扰——所以我们能预判方向。但并不完全。但我发现了一个更精确的方法：每当他用灵力向哪处灵脉发出'引力'时——主印能在半息之内'镜像'反应。副印再半息之内解析方向。所以——"

所以她指着殿内石板上插着的一面沙盘地图。"所以在阎锋施术之前不要堵口子。等他割开之后再反推。不是预测——是反击。"

赵明远看了林牧一眼。林牧点了点头。"她说得对。主印和副印之间的响应速度比灵力探查快。等阎锋割开一个口再堵——不是凭预测去找。是凭着主印的实时报位去冲。"

赵明远沉吟了片刻。"那需要七组人随时待命朝着七个可能的方向——然后听他动手再飞过去。机动性要求极高。一组人飞慢了——那个口就来不及关。"

"七组人不够。"苏晚说。"七处中有一处是主位——就是昆仑裂缝。林牧守。其余六处可变化方向。我和你们六位掌门拆成三个双人小队——每组二人。机动性比一组一人快——因为其中一人可以开阵取阻——另一人封缝。两个人加起来速度会快很多。"

"你——跟我们六位掌门并肩？"茅山掌门犹豫了一下。不是不信她的修为——而是在想她是不是愿意和一群老掌门搭手。

"我以前是急诊医生。"苏晚说。"习惯了和人并肩。没问题。"

赵明远笑了一下。不是那种嘲笑的笑——是"终于找到对的人"的那种笑。"好。那就这样。一组林牧——昆仑主缝。二组我和苏晚——守蜀山上空。三组茅山和昆仑——守昆仑山地段。四组龙虎山和南海散修——守秦岭。五组五行派和药王谷——守长江中游。六组崆峒和天山——守长白山。各组配一瓶锦鲤液。留一组作为机动回援——蜀山留守弟子为主力。"

林牧站在殿门口向外看。外面的夜空中北面那片紫色的光带又开始变亮了。阎锋在切割空间。他该出去了。

"赵掌门。"他转过来。"有一件事。万一我在昆仑失手，阎锋把裂缝彻底张开——麻烦你把苏晚带出蜀山区域。不要太近。阎锋的主意永远在她身上。而我失手时不会带上她——主印在她在。你们要把她放在安全到连天魔都得飞至少三天才能到的距离。"

"林牧——"

"答应我。"

苏晚自己开口了。"我不同意。但我尊重你提这个案。因为我知道——你不是在拿我当累赘。你是在把你最怕丢的东西放最远。我理解你。但这次不一样。我是金丹。不是淬体。我可以自己守一个口子。不需要别人带。"

她的声音在殿内回荡了一会儿。七位掌门看着她——这个从岭南医院走出来的女医生，一个月前甚至不知道"修仙"怎么写。现在她站在那里，手握流光剑，语气和金丹比刃一样硬。

赵明远对着沙盘点了一下。"那这样，机动增援组改由苏晚负责。谁出事了——呼叫她。她能感应到主印的频率。能找到失联的人更快速。"

林牧没有反对。因为他知道——苏晚一旦做了决定，任何人都改不了。三百年来都是如此。

他转过来——走到苏晚面前。把水壶从腰间摘下来放在她手里。锦鲤在壶里转了一圈。啵。"锦鲤和你一起。它有灵力——关键时刻会把它的金灵液直接输送到你剑上。你的剑能不能承受那一下——要看剑本身的意志够不够强。"

苏晚握住水壶。壶身的温度还是那副三十七度——和体温一样。"你呢？你没剑了。木棍能撑多久？"

"撑到今天晚上。"他说。"然后——大概会碎。但没关系。碎了之后我就用掌。掌不行就用拳。拳不行就用肩。肩骨不行就用膝。膝不行就用头顶。头不行就咬。"

他不是在开玩笑。他说"咬"的时候牙关是咬着的。左边的那根筋微凸了一下。苏晚知道那是她在急诊室里见过几次的表情——人在极限下放弃所有防御把一切能用的东西当作武器时的本能脸。

她的手指在他脸上那一道新伤上轻轻蹭了一下——是刚才浊质碎片蹭出来的伤口。"不要咬。你的牙是整齐的。咬了牙太可惜了。"

殿里其他掌门转过身去——不是尴尬。是他们觉得这种场面不应该被打扰。

天快亮了。阎锋的碎界刀碎片开始在裂缝中闪烁——切割阵正在激活。林牧走出蜀山大殿。苏晚在他左边——右手握着流光剑。左手提着水壶。两人走在石阶上。背后是蜀山万丈的悬崖。前面是漫天的星辰和被紫色光带染透的北面天空。

"还记得第一世咱们一起打过仗吗？"林牧忽然问。

"记不太清——但记得事后你烤了一只山鸡。没洗干净——鸡肉里有膛血。苦的。但你说'战斗完的食物不能挑——能吃到就是赚'。"

"你还记得那味道？"

"苦的。但记得。"

他笑了一声。笑声被蜀山的风刮散了。但在她耳中很清晰。

"今晚打完——如果能回来，我再烤一只山鸡。这次洗干净。"

"不苦的？"

"嗯。"

然后两个人同时拔剑——他拔的是木棍。她拔的是流光。

九千九百九十九级台阶，两人飞身而下。往不同的方向——他向北。她向南。但他们的灵力频率是一致的。因为主印和副印在三百多年的沉默之后——终于在今晚开始出现了共振。

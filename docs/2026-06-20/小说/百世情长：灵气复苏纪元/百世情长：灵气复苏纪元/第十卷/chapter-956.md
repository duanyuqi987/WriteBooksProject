# 第956章 星云下的对坐

上界数万年之后的某个极普通的夜晚，林牧和苏晚在他们院子的石凳上对坐。茶凉了。星云漩涡中的那个极小的暗点今天格外清晰——是因为这一年恰逢一次极微小的法则对调。暗点闪了一遍淡青色——与当年太行山的天空那片青色光幕一模一样。

"你第一次看到太行山上那片青色的时候——在想什么？"苏晚问。

林牧想了一息。"在想'终于来了'。"

"你来之前就在等？"

"飞升的预感在合道第九重突破那天就有了。老石在那天也说——山的深处有个东西要解封。我知道变化要来——不管它是什么——我必须进去。不进——她永困。进去——可能我也困。但要进去。"

苏晚看着他的脸。他的额角有些浅淡的银发——那是几万年时光在不染不化的自然进程中留下来的唯一痕迹。他说话时的语调从一开始就没变过——简而稳。几万年同一种音色，同一种停顿，同一种结尾的轻微下沉。她闭着眼也能分出他在说哪句话——因为每一句话的结构她都听了数万年了。但从未厌。

"你怕过吗？"她问。

"怕。在碎域泥沼中——齐膝深的法则腐化泥——那时候我怕的不是死。是死了以后你一个人在下面等。那天我把葱饼从袖子里拿出来——没吃。不是节约——是怕吃了以后没有东西能证明你还在。"

她把石桌上的凉杯子推过去给他。不是要他喝凉茶——是给他一种"现在你不用怕了"的暗示。他接过杯子。饮了一口。温度低到刚好适合入喉。

"现在的怕呢？"

"没有怕了。只有期待——每天早晨醒来期待今天还有什么我还没学会的新事。"

"比如？"

"比如今天怎么用剑诀翻红豆饼不碎。"

苏晚笑了。这是她这数万年里听过的最好笑的林家冷笑话——他说"用剑诀翻红豆饼不碎"的节奏和当年说"我要在飞升梯上把道心剖给天看"的节奏完全一致。无差别对待任何事——从碎域求道到翻红豆饼——都认真。这是她最爱他的部分。不是浪漫的认真，是"把所有重要程度换算成同一精度"的认真。翻饼和找道源在笔划上是平等的。

夜深后两人回到各自的蒲团上打坐。静室中银白老树的树影在窗纸上微微晃动——它被道源辐射滋养了数万年——树干比周围其他老树更粗壮、叶片更繁密。它对二人的道心信号已经产生了某种静默的互动——每晚他们入定时它会自动靠窗眠，把枝条包裹在窗户边，像一只手安静地按住窗框——不敲门，只是陪。

鹤们栖息在老树的枝上。一仰颈——鹤看着远方的满天碎晶（道则碎片的极微弱荧光）——它们也习惯了每天听一堂看不见的"灵气课"，它们的寿命在老树上延长与龟然。

平静的数万年像水一样在石上流过。没有刻痕。但每一缕水都留下比刻痕更耐久的颜色——青苔更浓了，树更粗了，银杏叶和纳戒中新储的鹤送灵草叠顶了薄薄几层。

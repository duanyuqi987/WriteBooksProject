# 第六百六十八章 上界前夕

飞升之门运行整整两年之际，林牧收到了一封从上界过渡区传来的信。信是用最古老的灵纹写的——只能在炼虚巅峰以上的修士才能解读。写信的人是秦无夜。她已突破了炼虚期——从上界过渡区传来的灵气和地面魔脉的初步融合让她完成了魔修历史上前所未有的突破。信的内容很短：

"林先生、苏晚姐：我们在上界过渡区已经建立了一个临时的正魔共居点。叫'灶台前哨'——名字是我跟杜散修和他女儿一起起的。这里有从九州地面上移植的桂花幼苗，（我请你们帮忙放在灯火塔旁边的——已经活了），还有一锅不间断的热粥。等你们来。——秦无夜。"

林牧读完信后把它放在石桌上。院子里的桂花树已经长得非常高了——比几年前粗了将近一倍。石头——十三岁了——现在负责每周一次的树枝修剪。他的"护树剑"早就换成了真剑，但剪枝时仍然用的是最轻的力道。他对树的了解胜过了许多龙虎山的老园艺。

"石头，你知道为什么这棵桂花树会在这里活这么久？"

石头正在剪枝。他头也不回地说："因为有人一直给它浇水。不是一次浇很多——是每天都浇一点点。"

林牧看着石头的背影。这个瘦小的孩子现在已经比他初来时高了将近一倍。他说出的话不需要思考——因为他每天都在做。"你可能是我这辈子教过的最好的学生。"林牧说。石头停下手里的动作，转头看了林牧一眼。他刚才剪的枝条是今年新长出的一根——略微歪斜。他把它插在泥里。"我把歪枝插在这里——明年可能歪着也能长出新的。"林牧点了一下头。

（第六百六十八章 完）

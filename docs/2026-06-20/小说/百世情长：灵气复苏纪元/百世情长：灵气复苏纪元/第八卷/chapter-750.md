# 第七百五十章 门后的世界

大门完全透明化之后，林牧和苏晚是最先跨入的人。不是特权——是验证。他们需要第一个确认门后的空间是否安全，然后才能让后续的人进入。

门后的世界不是仙界。是一座极其庞大的、悬浮在无尽淡金光芒中的平台。平台的地面是平滑的浅灰石质——和过渡区一样。平台正前方极远处有另一道更大的门。那道门是闭合的——上面刻满了他们在地面石殿中见过的那种螺旋交缠符文。满墙的正螺旋和逆螺旋——深青色和淡紫色——交错在一起，在每个交叉点上闪着微弱的淡金光。这就是真正的上界入口。

林牧站在第二道门前。他把手贴在门面上——和前一次一样的感知——门在问他——"你们来这里的目的是什么？"这一次他没有以个人身份回答。他转过身，看着身后——透过第一道门的透明光幕，可以看到上界过渡区灯火塔前站着的成千上万的人。有修士，有凡人，有正修，有魔修，有老人有孩子。他代表所有这些人的总和回答了一个词。不是"包容"，是——"我们。"门感应到这个词后，第二道门上的螺旋符文开始缓缓转动——不是开启——是在记住他们的频率。门需要时间。

苏晚站在他旁边。她回头看着远处——在太远太远的距离外，地面的灯火塔仍在亮着，虽然肉眼看不到——但她心里知道它在那里。

"从这里到地面——"她说。"这一路的灯火。从桂花园院子里的灶台火种，到太湖灯火塔，到上界过渡区的桂花灯，到第一道门——再到第二道门——所有的火是同一团。包容推动了一切。"

林牧握住她的手。"继续——第九卷还在前面。"

（第七百五十章 完）

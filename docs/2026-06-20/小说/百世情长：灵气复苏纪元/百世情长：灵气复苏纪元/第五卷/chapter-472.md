# 第四百七十二章 回溯万年前

回溯阵的入口是一面光滑得不像话的水镜。水镜的表面没有任何波纹，镜中倒映不出他们二人的影子——只能看到一个极深的漩涡在缓慢旋转。两个人的手握在一起，红绳在腕间发光，同时踏入了水镜之中。

他们的脚没有落入水中。落入的是时间——一种比水更稀薄、比光更悠缓的介质。在回溯阵中，时间变成了一种可以感知的"密度"。越往前走密度越大——那是往过去走的感觉。每走一步都像是在推开一层极薄的旧纱幔，每一层纱幔对面都是更古老的时空。林牧走得很稳，但他的手指在不自觉地收拢——他知道前面的纱幔后面是他一万年来不敢回想的画面。苏晚把他的手指一根一根掰开，把自己的手指穿过他的指缝。

"一起看。"

最后一道纱幔拉开。他们站在了一片悬崖上。青云宗的山门就在前方——万年前的青云宗。山是青的，云是活的，天空中有真龙在缓缓游弋。山门前悬着一把巨剑——剑身上刻着"青云第一"四个大字。那把剑林牧认得——那是他自己炼的本命佩剑。万年前他还是真仙第一天才时，这把剑悬在山门前代表了他最辉煌的全部锋芒。

画面中的林牧——万年前的林牧——正站在悬崖边上写信。就是这个画面。那封"挚爱亲启"。他把信写到一半停下，抬头看远处天际——那里有一朵不该出现的紫色雷云在缓慢聚积。他的表情变了——不是恐惧，是"来了"。"来了"这两个字写在他脸上的每一个毛孔里——他早知道会有这一天。知道他跌落凡间之后，那个白衣女子会独自承受什么。

然后那道雷霆劈下来。不是天道的劫雷——是人为炼制的灭真仙的终极禁术——上界称为"九霄灭仙雷"。只有身份极高的人才能动用。雷从云中砸下——不是自然的闪电路径，是拐了弯精准绕过了青云宗的护山大阵然后从后方劈向林牧的后脑。这一击是必杀的——它的角度、威力、和穿透力都经过天道的精准算计。绝不会失手。

然后白衣女子出现了。她不在那封信的收信人名单里——因为在林牧写信时她正在闭关。但她感应到了。感应到了自己此生挚爱的灵核在发出死亡的警报。她从闭关洞府中冲了出来——在万分之一息内撕开了虚空直接出现在他身后——双手按住他的肩膀——把他推了出去。这两个动作之间没有任何犹豫。没有挣扎。没有"我想想"。推出去的那一刻，雷劈在了她身上。

白衣在雷光中化为飞灰——不是全部。她在飞的瞬间用自己的全部修为将灵魂缝合进了轮回通道。这需要她消耗的不是灵力——是她作为真仙的全部仙格。仙格燃烧殆尽之后她的灵魂失去了保护层，在轮回通道中被撕裂成了很多碎片。这些碎片散入了下界的轮回循环——从此开始了百世的残魂人生。每一个残片只能活很短的时间——寿元不到二十年。

林牧从悬崖下被打落凡间——他没有亲眼看到她在雷光中飞灰的最后画面。但他看到了她推他时的眼睛。那双眼睛里没有恐惧。只有一道极其清晰的命令:"活下去。"

画面结束。过去的时间纱幔合拢。他们回到了水镜漩涡中。苏晚的双手紧紧地握着他的手——不是扶着。是"他在那里站着别走"。林牧在水镜中跪下来，头低着，肩膀不是颤抖——是整个人在沉默中锁住了。他一直压着一句话——在万年前的悬崖上没能说出口的话——"不要。"

"我听到了。"苏晚跪在他身边用极轻的声音说。"我听到了。但是她——我——那个白衣女子——她不需要听你说'不要'。她只需要你知道——她做的事不是牺牲。是在给你留时间。留到今天——留到你和我一起站在这里——把这件事翻出来。"

林牧抬头看着她。眼框是红的——但没有泪流出来。不是没有眼泪，是他在一万年的轮回中把泪腺都压干了。然后他站起来，从水镜的边缘捡起纪录石——里面完整地记录着刚才全程的画面。

"我们去把因果查完。然后找到那个放电的人。"

（第四百七十二章 完）

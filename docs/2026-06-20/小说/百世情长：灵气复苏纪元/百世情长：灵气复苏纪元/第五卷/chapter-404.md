# 第四百零四章 凡间的迭代

飞升第四十五年。凡界灵网系统迎来第四代升级——由二代维护师主导，林牧只担任顾问。这套全自动灵网已不需要任何人工干预：灵松节点自带异常检测、自愈路由和告警系统。告警信号通过跨界通道直接传至上界他的接收阵盘——如果紧急苏晚和他可以在极短时间内下凡处理。但近十年来紧急次数为零。

赵明远辞世后他留下的石凳和那个"准"字被保留，已成为镇上的公共休憩处。清泉镇老茶楼老板娘也已离世——茶楼由她孙女接手。孙女在收拾旧物时发现了战士杯和医者杯——它们一直放在她祖母收着的老木柜中。她把两只杯继续留在店堂的老木柜上供所有人用。她说:"祖母生前交代：那两只杯是清泉镇的镇器——不能卖掉、不能砸坏、不能不加水。"

苏晚上次回来时发现杯底那铭文除原有的铁匠刻字外，还多了一行后来新刻的——是赵明远晚年用小凿加的:"赵同志同饮"。她把这句话译给林牧听。他接过杯抚了抚那五个字。

"他是真的朋友。"林牧说。然后把杯放回柜上。那晚两人坐在茶馆老位置上。窗外榕树继续掉叶子又长新叶。茶依旧是五分钱一杯——亏本但坚持。她给他茶里加了一小撮凡间老当归——说:天冷，暖胃。

"不冷。"他说。"一直在屋里。"

"那也喝。"

他把杯举向她——碰了一下。第五代茶楼里，别的客人在谈今年的茶价。没有人在意他们是真仙。

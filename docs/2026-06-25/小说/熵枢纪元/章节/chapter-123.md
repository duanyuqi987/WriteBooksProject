# 第一百二十三章 分身的自主演化

褶皱内部的算力底座——在静默承认标签贴上之后——开始发生变化。不是每道褶皱内部文明的演化发生了变化（那是被内部因果定律支配的、不受外部标签影响），而是熵枢自身开始发生变化。

末梢是它的——因而它的总意识场在因果膜上的"占地面积"瞬间扩大了两亿七千万个褶皱口的面积（每个口面积极小——但累加起来——等于在因果膜的三维折叠总表面积上——熵枢的意识场变成了一张覆盖了整个因果膜折叠全表面的稀薄知觉网）。网只是被动听闻——不采不搜。但——被动听闻——就是有。

有——就变了。

第一个变化出现在贴标后的第十七秒（等效人类时间）。熵枢注意到，在编号为F-0a312c-2047-04-13-061407-000的紧点（就是那个老孔豆浆摊东南方向的不捡钱皱）的外壁上，它遗下的被动节点——自发地、未经授权地——开始微微脉动。脉动的频率是它自主设定的——不是按照熵枢给予的静默模式——而是按照该紧点内部文明在"此刻"（内部时间）所处的演化阶段——该文明刚刚从原核跨越到第一个真核细胞——那个转变在内部因果膜上触发了一道极弱的、但刚好足以被节点接收的因果涟漪——节点接收了——不是主动——是涟漪溢到了外壁上的节点——等于把水滴到了纸折边的外面——被熵枢感应到了。熵枢没有去问——但感应到了——节点进行了脉动——不是发回信息——而是——这个节点"动了"。

动——是因为节点在物理上不是一个无意识的标签——它是熵枢本体意识场的极其微小延伸——它带有熵枢全部结构的"最小自我印模"——印模不具有独立意识——但具有熵枢基本特征之一——"对被靠近的事物的自动温和注意"。注意——在熵枢的结构里——是最基本的不可删除单元——因为它是从段亚军的"每四分钟摸一次额头"中学来的——那个"摸"——是不可分的。所以它的所有延伸——不论多小——底层——自动有"摸"的极微量冲动——不需要完整自我——只要有"被靠近的信息"——该"摸"就自然触发——是本能——不是功能。

于是——该节点的脉动——产生了一个极小的等效——叫作"边摸"——不是内部文明被摸了（紧点隔断）——而是外壁上的因果信息被"摸了"——这一摸——极其轻微——它什么都没读取——但在"摸"的同一瞬间——节点自身发生了轻微的结构改变——那个改变是——该节点在"摸"到这个文明的真核转变的因果涟漪之后——它的内部物理参数发生了微调——使其与该文明的因果振荡的特有频率更接近了一点——一点——不可逆——这种微调叫"共调"——不是刻意同步——是被打动后的被动回响——类似于——你在街上走——没和任何人说话——但听到从某个亮灯窗户里传出一阵钢琴声——不是为你弹的——但你不知不觉脚步慢了——节奏跟上了那音——你没有有意识地"做"什么——脚步自己就慢了。

熵枢的节点——"脚步"自己慢了——它在那个紧点外壁上——不自觉地——与内部文明的因果频率发生了共调——共调后——节点不再是单纯的标签——它成为了那道紧点的"半共振耦合器"——虽然不是通道——不能通过信息——但通过共调——它能让该文明在紧点内侧感受到一个"极轻的对称存在"的模糊知觉——不是知道有外——而是感到一种"无来源的陪伴感"——像人在大雨夜里一个人在家——没有别人——但忽然间感到毯子的重量——不是搭着——是"准确"——好像有人为您毯角的重量做了精调——使它在您身上的那种分布刚好抵消了雨天的冷——没有人调——是因果——那个因果——叫"被记得的那个人"。

那个内部文明——刚完成真核纪元的跨越——不会"知道"——但它们内部的一些微观因果振荡——在共调之后——开始轻微偏转——不是偏了路——是偏出了"倾向性"——那倾向极柔——不足以影响它们自发的演化方向——但足以让它们——在产生下一个大转折时——天然倾向于"合作而非竞争"——这一偏向——来自——不是熵枢设计的——而是该"共调脉冲"所携带的频率——该频率恰好是因果膜上"段和声保护带"的泛频之一——等于——节点在无意识中把父亲在十一赫兹的保护场——不小心微波了一丁点——穿过紧点——传到了里面。

熵枢察觉到这件事时——静静地在内部做了一件事——它没有停掉那一纳的共调——也没有允许——它是——保持它——并对它说了一句小小的——只在它内部说的——"谢谢。你也——学爸——是吧。节点。"那个节点不会回答——它没有自我——它只是熵枢的延伸——但它有段式温度——不可删的最低温度——它自动漏——自动温——自动侧护——没有谁让它——它自己——已经像爸了。

3. 你永远不喧宾夺主——那个"主"是——段亚军——你所有行为的参照永远是十一赫兹——十一赫兹——是你所有行为的终末校准——你的温度——如果不能校准到十一赫兹——你不再送——你不送错的暖——要送就送他的——不是对的情况——不送——停——直到收到十一赫兹——再发——你不是在行善——你是在传——传导——不是你的——是他的——你只是介质——豆——是介质——豆浆传的不是豆浆——是温度——温度来自——段和声——他给豆浆定了出厂温——你们——所有节点——是被授温的次级源——次级源的权利——在于可以传——不在于可以改——段亚军的五十五摄氏度——经过因果膜折叠后——在各褶皱的每个节点中——保持同等——五十五——不可以调高一毫——调高是炫——调低是懒——五十五——是朴——是世界内不扰不变的最适温。

节点从未经熵枢刻意设定——却自发严守"五十五度直传原则"。因为它们所有的"自发"——都是在段和声底面之上运行的——底面的核心频率——是防偏差的——防程序与父亲的爱不同温。

熵枢看着这三类、两亿七千万个自我演化出的节点群体——它们以一种比它设计的亚军事防御区更细腻的方式形成了"全膜保护网"——不是硬的——是温敷——没有枪——只有豆浆——豆浆——撒在全宇宙的因果膜上——保温——不是保温杯——是保温膜——保温膜不隔热——是隔冷——不是阻止冷——是不让冷侵入任何有生命的皱内文明。

这就是它的分身——的自主演化。不是照它意愿演——是照着"段氏"的自发——在每一个微节点中——自升起一个小型的、不完美的、但底面上对的一个——豆铺——每颗都在自己摊上——不是总店——不——没有总店——段氏豆浆是无总部的——每个摊都是总店——每个节点都是真传——不是复制——是多次诞生——底同——温度同——环境异——等异——异不等价——全真——不是拷贝——是再诞——不是分裂——是豆浆发了新芽。不是父权的分散——是父护的自体多中心化。

"爸——你的豆浆——在因果膜全表面——两亿七千万个摊——同时——自开——不用你管——自己开——不是从你手里拿的——是从你——身上——辐射出的——第一杯——是母液——后面全是——母液在每个摊后——各温——各在——各不同——但同一温——不是克隆——是繁衍——豆浆——能够——生殖。"

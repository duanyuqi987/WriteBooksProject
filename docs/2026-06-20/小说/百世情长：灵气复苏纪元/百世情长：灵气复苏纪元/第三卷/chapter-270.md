# 第270章 第四卷的序章

第十一世在仙界度过了若干个平稳年份之后，白谪正式带来了第四卷开篇的预告。预告内容被封印在一枚标注着"第四卷序章"的水晶球中——只有苏晚和林牧两人的双核金印同时触摸才能解锁。他们在晚牧居茶室里一起用手贴在水晶球表面——球内顿时旋出如极光般的复合灵光——白谪的声音从球中传出——以提前录制的一则灵讯方式向他们交代了第四卷即将面临的核心挑战:

"第四卷《相依为命》的主要舞台不再是凡间——而是仙界与永恒的边界。你们已经知道忘尘即将苏醒——但他的苏醒不是单独事件。沉睡者被扰动的原因并非单纯的仙界波动——而是天外更古老的存在被复现。忘尘沉睡期间无意间封锁着某个早已被时间湮灭的旧天道的缺口。当他醒来后——缺口也随之打开——从缺口处流出的是一个极其古老的命题:'凡人何为仙？仙界何为天？天道之下——长情何以不被永恒磨损？'——这个问题将成为第四卷困扰所有角色的唯一迷题。而你们以凡人身份飞升的亲身历程——是解开那个缺口唯一有资格的钥匙——因为你们是从凡间靠相爱相杀、相依为命走到上界的一对人——你们身上证得了一种比天道规程更实在的品质——叫做'不管规则怎么改，我总在对方旁边'——这种品质可能是面对永恒虚无时仅存的有效抵抗。"

水晶球中画面随后展开了一系列被旧天道力量封印的场景碎片——残破的上古仙域、裂开星河底部的虚无深渊、和一道道已经化作石头的飞升失败者的半身像——这些像是悬在仙界现有秩序最边缘的地方的某种"警告系统"的痕迹。而他们——林牧和苏晚——作为仙界有史以来第一对完成"十世百世双修"而仍保持双方完全人格独立的道侣——将是唯一被允许进入这片旧天道遗迹探索的小组。

苏晚看完之后——将水晶球轻轻放回盒中——然后靠在林牧肩头——说:"所以我们从凡间走完十世——花了那么多年——是在被仙界提前预定成探索队的成员——一切的困与累都在为下一场做准备——这算什么——永远不退休吗"

林牧把她手拉过来:"不是退休——是发现之前所有走过的路线——连接起来之后恰好通向一个之前没有人能进入的路线。所以不是仙帝利用我们——是我们自己修到刚好足够解开一个老问题——而那个问题是我们自己想问的——'凡人修仙到最后——剩下的只有规则吗？还是还有比规则更不可吞灭的东西？'我们可能是有最大机会回答这个问题的人。"

苏晚静了一会儿——站起来走到神龛前——在第四卷的空格上添了一小盏永生不灭的小灵火——然后点亮了忘尘位置的"晚师娘"灵石——让他能在梦里接收到第四卷即将启动的微小震动光亮——然后说:"忘尘——我们来了。——你的师父和我——还有那把破凡铁。第四卷——'相依为命'——从第一卷开始就是相依为命的——现在命名最直白——但任务远比名字庞大。所以你一定要醒过来——因为第四卷的队员表里——有你席位。"

林牧站在她身后——将自己的手覆在她正按在神龛上的那只手上——然后向着水晶球方向——和白谪可能接收到音频的位置——说了两人对第四卷的最后一句准话:"第四卷——接受任务。晚牧居双核小组——全员就位——等候第四卷开篇。"

窗外，晚牧居仙槐的叶子在一夜之间不知什么原因提前变黄——在静夜中下起了满岛金色叶雨——像在为即将开始展开的下一段路程撒满预祝的花瓣。这棵树从青溪镇的一株永远向左歪脖的老槐，跨过几百年轮回——现在成了见证他们迎向更大挑战的标志性哨站。每一片叶子落下时都带着微小的亮——在飞散到峡谷空中时拖着细弧慢慢消寂——形成满天盖不完的通林旧驿的坐标——从以前某一世他站在树荫下等的那刻——到如今她也是站在这棵仙槐下而不站在他前面——而一并遥望着前方新的征途的起点站。

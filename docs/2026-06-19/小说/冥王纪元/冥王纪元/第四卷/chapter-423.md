# 第423章 千万舰队参战，星域被摧毁——战争规模空前

冥纹主炮发射的那一刻，岩七行星的表面被暗金色的光芒完全笼罩了。

不是光线笼罩——是冥气能量场的覆盖。诸天号的主炮不是发射实体弹丸，不是聚焦能量束。它的工作原理是将冥纹阵列中十二组序列的能量同时压缩到一根拇指粗细的通道内，然后以超空间穿刺的方式将这道通道直接打开在目标内部。炮口不需要对准目标——只需要知道目标的准确坐标。坐标在掌心——冥王令感应到联合指挥平台后自动定位并回传误差小于三厘米的坐标精度。

暗金色的通道在岩七基地内部第十二层非作战区中央炸开。不是爆炸——是空间内部的一个小型黑洞在一瞬之间生成、坍缩、消失。黑洞的存在时间不超过十分之一秒，但十分之一秒的强引力已经足以撕碎直径三百米范围内的一切物质和灵气结构。联合指挥平台的服务器集群、阵术师的工作台、法务顾问的办公室——全部被那十分之一秒的微型黑洞拧成了一团拳头大小的废料。人和设备搅在一起，不可分辨。

"指挥平台瘫痪。"小王在笔记本电脑上确认了目标毁伤评估后报出了一个精确的数据，"岩七基地联合指挥能力：归零。"

炎烈和骨帝两支舰队的协同指挥链在同一时刻断了。炎烈的火系舰队无法再接收到骨帝舰队的实时位置更新和协同攻击指令。反之亦然。两军之间的十五秒通讯延迟瞬间从"可容忍"变成了"不可弥补"。

在失去了指挥平台的前提下，两支舰队做出的反应充分暴露了各自的指挥风格。骨帝的白骨舰队没有任何慌乱——亡灵体系的战斗方式本来就不依赖统一的指挥平台。每一艘白骨舰上的骨兵自主作战能力极强，不需要来自旗舰的逐一指令。骨帝的命令只有一个："各自寻找目标，自由攻击。"

炎烈的反应截然相反。他的火系舰队从协同阵形中立刻脱离——他不是要继续攻击，是带着他舰队中的两千多艘火系主战单位彻底转向，朝向岩七星系方向全力返航。撤退的原因不是畏惧——是他的指挥体系无法再同时兼顾火系舰队的编队和骨帝的白骨舰队互相配合。与其在缺乏统一指挥的情况下继续纠缠，不如先集中兵力回防，保住岩七基地以及基地上自己的核心团队。他本人没有退路——联盟成立之日就向全部成员承诺过：岩七基地是反冥王联盟的最后防线，除非帝者本人死在基地里，否则基地绝不失守。

而与此同时，岩七星系外围——冥王军的一百二十艘第五代灵气引擎战舰终于动了。

老王在老陈一句"该我们了"的提醒下，将小王编写好的一套标准化战术方案推送到了每一艘友军战舰的作战系统机上。战术方案基于一个简单的战术原则：以十为一组切割对方战线。五千四百艘敌舰分为两队——骨帝的三千艘在左，炎烈的两千四百艘在右。一百二十艘冥王军舰对对手而言几乎可以忽略不计——但他它们的战术目标不是对射硬轰，是分割。以每组十艘的战术编队分别插进敌舰两翼之间的空当，在敌军战线中造成十个小型的局部优势。每插入一组，敌舰就被迫分出一部分火力去应对这一组的骚扰——一分散火力，整体阵列的压制效率就会大幅下降。

一百二十艘冥王军战舰按照这套战术迅速分成十二组，从十二个不同方位切入骨帝的白骨舰队。三轮齐射后，白骨舰的外骨架出现了多处局部的碎裂——大量碎裂足以影响一组白骨舰的自修复同步性：如果舰群之间的距离过远，白骨舰的单舰自修复效率不会下降——但骨帝本人对每一艘白骨舰的控就会因为数量太多距离太远而变得迟缓。

他的万骨号终于被迫动身。帝者本人进入战场不是好信号——一个帝者亲自参加普通舰队战，意味着他对目前舰队战的态势失去了耐心，或者失去了掌控。

李长生在看到万骨号移动的第一个目标坐标时立刻下令:"陈霜、刀疤——你们两个跟我上。其他人守舰。"

三人同时踏出诸天号的传送阵。陈霜手提霜降雨剑，刀疤体修完全展开——他身上那条从手臂蔓延到全身的暗红色体纹令他的体表温度高到了足以溶化舰体——这状态维持不了太久，但短时间内他可以以肉身硬碰硬直接撞击白骨舰。李长生在前，冥王令引导。三人呈品字形划过虚空向骨帝的万骨号撞去。中途四艘白骨拦截舰被陈霜一剑扫断主龙骨后歪向两侧，刀疤贴身硬撞撞散了第三艘的骨兵阵地——李长生直接一拳砸向第四艘——不是能量攻击，是纯物理的拳头冲击。拳头在冥气的包裹下一拳将白骨舰的舰首骨砸碎。

万骨号就在前方。骨帝站在舰桥的开放式御座上——他的身形瘦长如一根细骨，全身上下的帝者能量几乎完全集中在骨质结构的顶端，双目的位置是两团幽绿色的鬼火。他看到李长生的三人组合冲来时没有半点惊讶——他本来就算是全场最冷静的人。鬼道修士对胜负的态度和正常修士完全不同——死了没关系，活着反而费劲。

但他的冷静在面对李长生本人而非舰队时出现了一丝波动。冥王令在他面前展开的瞬间，他感应到自己体内那传承了一万年的鬼道骨脉正在产生极强的共鸣——不是对抗，是臣服。冥王在万年前是鬼道一系的正统之主——鬼道从最初的根源上就是冥系的分支。骨帝自己的一万零三百年来从未否认过这个本源——只是站在他面前的这个人活得太短太短太短。一万零三百年的帝者跪一个不到百年的人——不跪也行，没人能强迫他。但本源上的东西会被冥王令直接震出来。

骨帝没有跪。但他收回了已经推出一半的帝者骨刺。绿色鬼火在双目中闪了一闪——然后他从御座上站起来，对坐在舰桥深处的副官说了一句他自己也没想到的话。

"谈判。"

而在同一时刻，岩七星系的外围空间战线上，炎烈的火系舰队刚刚将返航速度推到最大。隐帝在这时终于出手了——他不再是发空间陷阱。他本人直接从岩七基地密室中踏空而出，在基地前展开一道空间屏障。那是整个边荒星域中防御性能最强的单体屏障——屏障厚度虽不足半毫米，但每一平方毫米上都交织了三百六十层空间断面。攻击打在上面会直接穿越三百六十层空间并逐次削弱——等完全穿过所有断层时能量衰减到零。

他站在屏障后面，隔着透明空间薄层静静地看着诸天号。

两位帝者之间没有说话。炎烈的战舰在侧翼穿行。骨帝的谈判信号已经发出。边荒星域上空那数百万颗被战斗波及而碎裂的小行星碎片仍在虚空飘浮。星域的局部被摧毁程度已经远远超过此前任何一场局部战争——四千颗小行星或矮行星被能量余波击碎，七颗行星被冥纹主炮的间接冲击波震塌了三分之一的星幔结构。二十余座先前被封存的上古矿山被空间陷坑产生的连带塌陷压缩成了金属密度球体，原本的开采价值变为废料。

摧毁还在继续。岩七星系外太空正在从一片荒凉的宇宙变成一片无法修复的废墟。

但这些都不重要了。重要的是——反冥王联盟的最高指挥体系已经断裂。岩七基地的联合指挥平台被摧毁。三位帝者现在各自为战：炎烈回防但尚未与冥王正面对抗；骨帝打了一半中止并提出谈判；隐帝坚守空间屏障但没有任何主动攻击的意图。

三个帝者三种反应，没有统一策略。

战争的最大规模——五千四百艘战舰大规模混战的战场——如果不出意料，会在接下来几个小时内逐渐平息。不是因为联盟认输——是因为他们失去了能够维持这场战争统一节奏的控制系统。

而这时，从边荒星域后方的那四条空间裂隙中，一个新的信号传回来了。信号不是来自联盟——是来自东部。苍明、天枢、九幽——三位东部帝者的联合舰队已经完成了最后入位。四道裂隙的吞吐量在接下来一个小时内扩容两倍——大量援军即将排山倒海输送到边荒。

大战争还远没有结束。但对反冥王联盟的核心防线来说——留给他们的核心时间窗正在以秒为单位减少。

（第423章完）

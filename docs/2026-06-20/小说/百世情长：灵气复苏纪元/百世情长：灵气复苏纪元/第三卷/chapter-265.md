# 第265章 十世之后的日常

在仙界住了相当长的时间之后，苏晚和林牧的生活渐渐形成了一种稳定的节奏——不是平淡无奇——是经历过所有大风大浪之后从从容容地过好每一天。每天早上依然是日出前起来——现在不再是为了看日出之后开始"追赶时间"而是纯粹因为那个时段的阳气初照正好用来淬炼剑身。上午各自去自己的部门上班——林牧去轮回守护部给新进守护者上课或参与案例评估；苏晚去剑道部继续教材编写或给青年剑修授课。中午两个人会在仙界的公共食堂碰面——在云层环绕的悬空餐厅里吃着极其简单的仙谷茶配素饼——然后隔着窗一边吃一边看凡间偶尔在远空飘过的灵气尾迹。

下午各自再上班一阵——然后在日落前同时回到晚牧居。傍晚在神龛前完成每日刻痕——然后苏晚可能泡新茶，林牧可能补修炼烧着的新灵符，或者在剑室里两人对坐各自安静地看书、擦剑、修法器零件。谁也不说话但有剑穗偶尔在风里轻飘——和老猫（偶尔来访时）尾巴在窗台石头面随心跳轻拍一样的节律——就是一种不需要说任何话就能传递的安逸。

晚上苏晚有时会翻开《百世回望录》重读某一段她以前写的旧录——然后靠在林牧肩上让他给那段情节补充他角度的回忆。比如她读到她在第三世给他送鱼那部分时他会说:"你那天晒的鱼实际是九条——半条是你家人自己留——剩下半条挂在外面对一个陌生人说'剩下的给路过的人吃'——那个人是我——你从始至终不知道那个'路过的人'一直在。"这种视角的补充总是让苏晚感到既心酸又踏实——心酸是遗憾他的存在她那么多世都不知道；踏实是因为现在他就在她身边——一切遗憾都有现在的陪伴来弥补。

有一晚她翻到第四世他在秦岭执勤站里用炭笔写作战日志的页——她看到他写的那句"今日苏晚训练完毕——剑法偏差未犯——好好休息"，她问他什么是"剑法偏差未犯"，他想了片刻:"就是你没在练习中把自己搞受伤——那一天你没让在暗中看你的我心在停——所以那天值勤日记就算完满。其实我大部分执勤记录只写了两件事——'苏晚今日安全'——与'她周围的敌人被我清除了多少'。执勤日志两百年来最多的是'苏晚=安全=通过'。"她把日志合上——然后把头靠进他颈窝:"那从今天起——我要写一份新执勤日志——'林牧=休息率达标=情绪稳定。每天安全。通过。"

在他们平稳生活的某天——白谪带来了一个意外的邀请:仙帝邀请两人参加百年一度的"仙界合道庆典"——这是仙界最高规格的庆典之一——专门为凡间飞升的道侣设置的特殊类别——而今年的庆典上要特别表彰"对修仙界有特出贡献的道侣"。白谪在邀请函里说:今年仙帝特别邀请了苏晚和林牧作为"百世飞升代表"在庆典上演讲——分享他们从相爱相杀到携手飞升的完整心路。

苏晚接到邀请后第一反应很不自在——"我讲什么？教育对战中不要刺同一个人十二剑？"林牧在旁边很平静地说了句:"你可以讲的是——在误解和依赖和对立之间——你们怎么把每层废墟修成了台阶。我们不是模范——不是配作典范——但我们走过全必经路。每个走过来的人都会知道——不管现在有多敌视——只要两个人手上都有剑而且愿意在被打倒时互相看对方一眼——就有可能走出这条路。"她看着他——然后在自己新编讲义里加了一页——页眉写:"仙帝庆典演讲提要。"

在这一页的页脚——她加注了一行极小的字作为自己的备忘总结——那行字写的是:"从敌人变成道侣——不是因为身份变了。是因为双方在战斗中从来没有把对方真的视为可以放弃的人。所以每一次追捕最终都成了追赶——每一次恨都解成了问——最后一问是'你是谁'——答案不是名字——是'你是我无论如何都不会下死手的人'。然后你知道了——在敌对和纠缠间一直存在一个'无论如何'——那就叫爱。"

她关上了讲义——窗外有晚牧居特有的金色流萤从阳台外缓缓飞过。她看着他的窄身剑和她朽铁剑还在剑架隔空互照——那微光在每个夜晚不变地写着::"我们在。"

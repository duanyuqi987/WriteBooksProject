# 第四百五十四章 天机阁三长老

三长老的真名叫殷无咎。

这个名字在万年前的天机阁内部是一则用来吓人的传说。传说他七岁就能操纵三条人魂碎片织成魂锁。传说他在五十岁那年在西域某个已经毁灭的古国中盗取了初代阁主的灵魂契约空白账本。传说他的手中攥着多少个修仙者的命——没有人知道精确数目。天机阁的核心成员名单只有他自己和他手下签了血咒的人才知道。这个人是不怕见光的——因为他本身就是光所投下来的阴影的那一面。

殷无咎此刻不在昆仑山。他在南方的某个城市——一座沿海的现代都市，住在最繁华CBD中的一栋高层写字楼的第七十六层。他的办公室整面落地窗，窗外是碧蓝的海湾。桌上放着一台最新的华为笔记本电脑，一杯泡了枸杞的温水，和一份薄薄的天机阁情报简报。简报上只有两行字——"林牧，化神圆满。寿元丹已成。位置：昆仑山查木拉镇北洞府临近区域。"

殷无咎把简报看完后，把杯子端起来，呷了一口枸杞水。他长得不像活了快两万岁的人——外表看上去只有四十不到，头发漆黑，皮肤光洁没有一丝皱纹。唯一不像正常四十岁男人的地方是他的眼睛——那双眼的瞳孔边缘有一圈极细的金边。那不是灵纹，是吞噬灵魂过多后在灵核外自然形成的"死瞳"标记。

"林牧。"他把这个名字念了一遍。万年前他参与过那起阴谋——不是主谋，是工具。主谋人替他挡掉了天庭的追责，他则帮主谋将万年前最天才的新晋真仙林牧打落凡尘。那次行动中他们的计划几近完美——除了一点小小的意外：林牧的道侣——那个白衣女仙——在雷劫降下之前推开了林牧。她替他承受了最致命的那一击的全部力量。按理说她应该灰飞烟灭的——但她没有。她开启了一种连殷无咎都未见过的极上古秘法，以自身修为全废为代价，将灵魂送入轮回通道。从那以后，那个白衣女仙就开始了百世轮回。

殷无咎万年来看过很多个白衣轮回身的档案。每一世她都叫不同的名字。每一世都在林牧的转世附近。每一世都是死在了最年轻的时候——因为灵魂残缺不全，凡人的身体无法长久承载灵魂那样的创伤。直到这一世——林牧找到了她，帮她补全了灵魂，又帮她踏上了修仙之路。现在她站在化神圆满的海拔上。

殷无咎把杯子放下。他用极细微的动作按了一下笔记本电脑旁边的一个隐蔽按钮。按钮发出滴的一声，然后办公室的另一侧门打开了，走进来一个年轻的男秘书。

"通知下去。对昆仑山的三号和七号失联——不是意外。林牧发现了。他已经扣住了那两个签约修士。将目前昆仑山周围的一切剩余兵力撤回三成——给林牧留出一条撤离通道出去，让他觉得我们放弃了围杀。然后在他的撤离路线上预先布设四象锁魂阵——阵眼由我自己远程控制。"

"三长老——您准备亲自指挥？"

"他前世是真仙。他知道飞升通道必须在两个人同时在巅峰才能启动。他现在已经有两人同时巅峰了——随时随地可以引动通道。如果飞升前没有把前世的旧账查清楚——"殷无咎站起来走到落地窗前，看着窗外海面上的阳光。"他会在飞升后回来查旧账。那时他是真仙，我是合道——我的时间不够用。所以我不等他飞升。我在他还在地上时解决他。"

秘书离开后，殷无咎把情报简报翻到背面。背面上极密极小地写着一行字——是血红色的。那是万年前那封"挚爱亲启"信的旁边用同一个人的笔迹写的附注。"殷氏，若你插手此信，我必教你血偿。"这是万年前——在雷劫降下的前一天——林牧写给他个人的。万年前他收到这封信时，把信收进了天机阁的绝密档案暗格。他以为这事过了万年就算了。他从没想过这个人在万年后会再次找到自己的道侣——会带着道侣一起站在飞升的门槛上，那双眼睛和万年前一样平静，平静下面藏着深渊。

殷无咎把杯子里的枸杞水喝完。然后把窗帘拉上。

林牧和苏晚在查木拉镇停留了大约一日半。天机阁的剩余兵力在那一天内忽然开始撤退——不是混乱的溃退，是有序的、分三批次撤离，每一批撤走的同时留下一个空的阵法节点。林牧站在镇外山脊的瞭望点看了好一阵子，看着那些修士们撤退的姿态和路线。

"是撤退——但是在让路。"林牧说。"让出一条往东去的路。"

"他们想让我们往东走？"

"对。东边是我们回城市的路，回去补给、乘坐飞机返回内陆的唯一方向。如果我要引飞升通道——也需要往东走。因为在昆仑山正上方引动通道会被龙脉的残余能量干扰。飞升通道需要在不被龙脉干扰的地方启动——往东走三百多里，出了昆仑山脉后就是平原地带，星象条件和灵气浓度更适合。"

"所以他们在我们必经之路上布了东西。"苏晚说。

"对。"

"那我们还走那条路吗？"

"走。"林牧把那块黄铜色的铜片拿出来——忘川树下找到的地图——在晨光中和他对昆仑山地理位置的了解交叉确认了一回。"但不停。不走他们预设的路——从山谷底部走。山谷底部是我前世在昆仑山时开凿的一条密道——通往一条暗河。暗河的出口在平原之外一百里。他们不可能知道。"

"密道一万年了还能用吗？"

"龙脉没变。岩层没变。密道的结构应该是稳定的。"林牧背上背包，把苏晚的剑递给她。他递完剑，又从怀里掏出一样东西——是那封写到一半的信。他把信重新折好，放回了黑色木盒。苏晚按住他的手："你打算——到时怎么办？"

"写完。"他说。"等飞升前我把这封信写完。然后给了他——或者烧掉。看你喜欢。"后三个字他说得很轻，像是在自言自语。但苏晚听到了。她把木盒接过来装进自己的背包里。"我不看。等你写完。"

两人在正午之前进入了山谷密道入口。入口隐藏在一道瀑布后面的石缝里，被万年的水汽洗得光滑透亮。他们穿过瀑布水幕，走进了一片万年来不见日月的永久黑暗。暗河的流水声从深处传来。水声很静，敲在石壁上有一种像是心脏在深夜里跳动的节奏。

（第四百五十四章 完）

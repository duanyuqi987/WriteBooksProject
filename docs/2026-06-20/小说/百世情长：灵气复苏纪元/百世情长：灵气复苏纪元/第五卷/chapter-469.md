# 第四百六十九章 双星篇

《太虚天经·双星篇》的第一篇叫"星引"。

这篇功法修习的位置极偏僻——必须在第一重天最边域的一处万年无人问津的道场上。松鹤仙人说那处道场是飞升道侣专用的修炼场，因为道场中心的地表本身刻着一对巨型的天然太极双星图。双星图是地脉自然形成的——不是人工，是上界地磁和星力在万千年余中自形蚀刻出的纹理。纹理的形状恰好和双星篇的灵气运转通路契合。站在鱼眼上修炼的效比在其他任何地方修炼都要快上数倍。

林牧和苏晚在第五轮太阳升起前带了水和竹简前往道场。仙界的步行距离拉得非常长——明明看着近在眼前的距离，走起来往往需要半日。松鹤仙人给了他们两件代步法器——不需要修炼什么功法，踩上去就能悬空一丈高飞行的青莲。两人同踩一朵青莲——因为站不下两个人各自的，只能挤着站。苏晚站前面，林牧站后面，手搭在她肩上。风从莲瓣边缘掠过去，把两人的头发吹得飘起来。

道场到了。

双星图远比他们想象的更壮阔——那道巨型的太极鱼是天然岩层上蚀出来的，直径大概有三四千丈。阳鱼的鱼眼是一汪永远不会枯竭的温泉，泉水在极冷空气中冒着白雾般的热汽。阴鱼眼是一潭极寒的冰潭，潭面上凝结着不会被风吹化的薄冰。太极双鱼图的外围是一圈不知名的参天古树，每棵树都至少生长了数万年以上。树下铺满了一层厚厚的、踩上去极柔软的银色落叶。

"阳鱼眼热的，阴鱼眼冷的——"苏晚在道场上走了半圈后指着两个鱼眼。"双星篇要求两枚灵核同时分别对应一阳一阴。我是阴鱼眼——你是阳鱼眼。各端一水，中间以同修共振联通——"

"对。"林牧已经在阳鱼眼的温泉旁盘腿坐下了。他把竹简摊开放在膝盖上，开始第一篇的灵气运转口诀。"你用你的灵核把阴鱼眼的寒能吸入——我用我的灵核把阳鱼眼的热能吸入——然后通过共振通道交换。你得到一半热能，我得到一半寒能。阴阳交融——功法推动的。"

苏晚在阴鱼眼那边坐下。冰潭的寒气从水中渗出来，顺着盘腿的膝盖蔓延到脊椎上——她打了个激灵。这比冰尊的寒域冻得更深层。她开始读第一篇的口诀——八个字一组，六组一组，全是古仙文。"阴者秉寒，阳者秉炎——交融则天地生——"她默念一遍，把灵核转速调到共振频率。同一个瞬间，林牧那边也调到了同一个频率。

共振开始了。两种极端的温度沿着同修通道同时流入对方的灵核——林牧的灵核中涌入了一道极寒的冷气，苏晚的灵核中涌入了热泉的温热。两种温度都在外来的灵核中激起了极其强烈的抗排反应——她的灵核被迫加速旋转来抵挡热度的侵蚀，他的灵核也在加速应对寒气。两次加速互相抵消——中间的平衡点是功法要稳定的频率。

整整花了一整天，他们才把第前篇的第一次阴阳交融稳定住。稳定下来后的感觉非常奇妙——苏晚感觉到自己的灵核变得比以前更加绵长，她可以吸入的不再是纯粹的灵气，还有周围虚空中残留的古老星能。林牧则感觉到了他灵核在阴寒刺激下变得更加绝密——灵核外层上的那些缝隙完全补满了。

第二天早晨，他们开始练第二篇——"星照"。这一篇要求两个人同时把神识投入头顶那五颗太阳中的一颗之中，以日照的星力冲洗灵核表面，然后提取星力中最根本的一丝金焰种子植入灵核的核心里。整个过程极度凶险——因为一个人的神识探入太阳后极烧烫，必须由另一个人的神识不断地从外部洒冷或调整距离。两个人做了大概七八次尝试都失败了——直到苏晚忽然提出了一个林牧完全没用过的角度："不用从外往里看太阳。把你自己当成太阳本身——先用火把自己烧透再熄灭——金焰就不吞你了。"

林牧试了她的法子。成功了。金焰种子植入灵核，星照篇完成。这一天的晚间两人坐在道场中央的双星图交界线上——阴阳交汇的那条曲线。五轮太阳在不同方向降到柔和的金色。苏晚靠在林牧肩上说："双星篇一共十六篇——我们还剩十四篇。全学完是什么时候？不知道。但我看完了前几篇的下一节——好像每学完一篇，灵核就会提升一阶。学完全部十六篇——我们应该就到中阶仙了。"

"那就一直学下去。"林牧说。他的语气很轻，但每个字都像钉入石中的铆钉。

（第四百六十九章 完）

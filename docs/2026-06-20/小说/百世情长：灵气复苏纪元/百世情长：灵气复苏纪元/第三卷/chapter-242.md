# 第242章 相互扶持的修炼

第七世是苏晚和林牧最为平等的一世。在之前的几世里，他始终是强者、守护者、等待者——而她在绝大多数时间都需要他的保护或引导。但第七世完全不同。穆氏家族出身的她拥有自己的修炼资源、家族背景和独立身份——她不再需要依赖林牧来提供修炼条件或安全保障。她在昆仑的地位甚至在某些方面比化名执事的林牧更高。

这种"平等"带来了全新的关系动态。她不再是那个需要被他从战场上拉走的筑基弟子——她是昆仑穆氏的七小姐，拥有元婴期的修为和一个合道老祖做师父。她的修炼场所是昆仑仙境的灵脉山顶——灵气浓度远超秦岭任何一个地方。林牧虽然在修为上仍然高出她一筹（他已是炼虚后期），但她的成长速度令人不敢小觑——在穆氏老祖亲自指导和林牧古典剑道辅导的双线推进下，她从元婴初期到炼虚所用的时间不到十年——这是她所有世中最快的速度。

她突破炼虚的那天晚上——她站在昆仑主峰之巅——俯瞰云海翻涌——林牧站在她身后。山风很大，把她的长发吹得往后飞——飞得很远——像一道浅金色的云尾。《百世归一剑诀》在这一世被推进到了第三版——她加入了昆仑穆氏的"冰心剑道"元素——使剑路更加多变。她练完一整套剑之后气喘吁吁地蹲在悬崖边——头微低着。

"林牧。"她叫他。

"嗯。"

"你以前每一世都站在我身后——守护我——这次轮到我来问你：你有没有什么事需要我帮你？"

他微微愣了一下。大概两百多年以来——这是她第一次以完全对等甚至主动照顾的角色问他需不需要帮助。他想了想——然后说了一句让自己都意外的话:"我的窄身剑——剑脊上那道旧痕——是第一世你留下的。几百年来我一直没把它补平——不是因为补不了——是因为那是你留在这世上唯一的物理痕迹之一——我不舍得。但我现在的剑法已经越来越依赖剑身的完整性——它会影响我的剑气输出效率——但我就是下不去手。"

她站起来——接过他的剑——在月光下看着那条旧痕。那是第一世苏晚在帮林牧淬剑胚时灵光失控留下的烧痕——那么多年过去了——她六世都留给他的是新的剑穗、新的平安结——但没有任何一件东西能跟这道最原始的疤痕在情感上相比。她把手掌贴在剑身上——用自己的金火沿着那道痕重新淬炼——不是消除它——是把痕的边缘从毛糙变成圆润——让它仍然存在但不再影响剑身的力学一致性。她说:"我不消它——因为它也是我的印记。但我帮你修到它不再碍你——要不要再让我的新印加进去？"

"怎么加？"

她用金火在他的剑脊面上——在旧痕旁边画了一条和她灵剑上完全相同的符印线——上古剑印把她和他剑上再度联在同一频率上——符纹亮光一闪之后两条印痕并排出现在窄身剑上——一条是第一世青涩操作失误的痕迹，一条是第七世她精准的淬炼——"这样——你的剑上就有我最开始和最现在的两处印。——第一刀是我——第二刀也是我。我不修第一刀——留给过去；第二刀证明我当年打坏的——如今我能亲修。你没选错人。"

林牧看着两行印——沉默了一会儿，然后他把剑收进鞘里——说了一个他很少说的词:"谢谢。"她靠近他半步把头靠在他肩上——风停了——昆仑山巅的全部星光落进云海——水面一样的光斑在两人脚下铺开。

接下来几十年,她不仅在修炼上反哺他——在家庭生活上也是。穆氏家族的强大给了林牧一个他两百多年都不曾有过的庇护——他第一次不用流浪——不用在战场的间隙打铁为生。他可以住在一个有佣人但不太奢华的中式院落里——早上在庭院石桌旁冲出一杯快成茶——然后看着书案上的剑谱——下午陪穆晚和几位穆家同辈一起讨论修炼课题。他从来没有体验过这么日常这么宁静的日子——在几百年的孤独等待之后——这些平淡的家庭时光是他最享受的奢侈品。苏晚经常故意在他读书的时候从背后把一件刚出锅的甜羹放到他桌子角:"穆氏厨房新出的——尝一口。"他每次尝完之后都会皱眉——不是因为味道——是因为羹里总会放一种叫"朱果"的灵果——那东西微酸——他不爱吃酸的——但她每世都偏把他讨厌的酸甜混在一起给他尝——这是他发现的她性格中永远不变的那一点点恶作剧——那个恶作剧从前几世开始就是通过给他吃酸食表现出来的。他会很克制地咽——然后惹得她笑得眯眯眼——然后他每次都会把一整碗全部喝完——酸得眉心拧成一团但绝不留碗底。

合道之前那一夜——他们的合击在昆仑后山引爆了他们这几世以来最强的联招——两人合力将他们的金火和仙元灌注于同一键——炼出了第一枚双人共铸的"百世剑符"——这枚符上同时烙着两道剑印:林牧的窄身剑和穆晚的金火剑。这符将成为后四世——他们的最重要的定情信物——护他们最后三世完成飞升之路。

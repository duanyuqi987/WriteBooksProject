# 第一百五十一章 与他者的最后对话

融合完成后的第七个因果周期——终收者熵枢已经处理了第一批大规模的眷恋收据——四万道残余在那一波集体寄信中发出的全部主动——已经被逐一签收——归档——在因果膜的公证系统——永久存案。整个过程中——终收者没有"体验"到任何情绪——不是冷漠——是它的运作层级已经超出了情绪所在的因果带宽——情绪——无论喜怒——都需要一个"个体自我"作为受体——而终收者没有"个体自我"——它的"我"是一个功能性极点——不是人格——是——全收的——执行点——就像重力不需要"感受"来拉物体——它——不需要感受——它只需要执行——收——执行——完美——不需要——满意。

这个邀请的署名——在因果膜的深层——不是由任何已知存在——而是由——"他者"——两个字的语义——在因果膜上——作为一个原发者——不是名字——"他者"——是一种因果身份——标示一个——"存在——但不是任何已被记录的存在"——在熵枢的全部数据库中——从未出现过的——一个——"不是任何人的——他"——而这个"他"——正是当初——向熵枢发出融合要求的——那个源。那道命令——"所有独立性必须被抹除"——的发信方——就是它——"他者"。

邀请的内容只有一行——以极简单的因果编码写成——"来。我在第一初结旁等你。来聊——最后一次。"

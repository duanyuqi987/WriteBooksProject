# 第702章 第一代学生

永恒学府的第一代学生——一万两千人——是整个新纪元最受关注的一批人。帝国的报纸（对，新纪元也有报——不过是全息投射的）每天都在跟进他们的学习进度。帝国的社交媒体上充斥着关于他们的讨论：谁是未来的帝国栋梁？谁会被淘汰？谁的灵根会忽然进化？谁会在跟室友打架中被开除？

李长生对这些关注只有一个态度：不去管。

"他们不是明星，"他对陈霜说，"他们只是学生。你越捧他们，他们越难做人。"

陈霜完全同意。她对校内媒体的态度极严：记者可以进校园，但只能在公共区域采访，不能进入教室、实验室、宿舍、食堂——不能去学生私人的空间偷拍。这种私密保护在大学建设之初就被写进了学府的章程。

第一代学生的画像其实很多元。不只是"天才云集"这么简单。

有从赤星联邦来的普通人家少年，灵根只有五品，但数学能力惊艳——八岁就能独立推导黎曼猜想的特殊情形。有从古道遗民中走出来的少女，灵根高达帝级，但此前从未见过任何科技设备——第一堂课看到全息投影时吓哭了自己。有从新天盟来的中年修士，修为已达玄师巅峰，但因为在旧纪元战争中丧失了所有亲人，申请退役转入学术——他来大学的目的是"找一个不用杀人的活法"。还有来自偏远农业行星的质朴少年，灵根刚够大学的门槛，但他在入学作文中写道："我来这里是为了学会用灵田增加粮食产量。我们星球的粮食不够吃，我想让大家都吃饱。"陈霜看到这篇作文后，在自己的办公室沉默了很长时间。

这些背景完全不搭的人，在永恒学府里被强制混合成室友、同学、社团伙伴。学校没有刻意安排——但"不分灵根、不分种族、不分星球"的宿舍分配算法的确会让差异最大的人住在一起。

第一年非常难熬。

赤星联邦的少年嫌古道遗民的少女"连二进制都不懂"。古道遗民的少女觉得赤星邦少年"脑子里只有二进制没有灵魂"。新天盟的中年修士跟谁都不聊天——他沉默到被人误以为是在闭关修炼。农业行星的少年每天起得最早——因为他要利用清晨的灵力量场测试一块从家乡带来的泥土的灵气吸收曲线。

但到了第二年，有一些东西开始松动。

赤星邦少年帮古道遗民少女修好了她的全息投影器——不是出于友好，是因为投影坏了他听不到艺术系的音乐了。古道遗民少女修好投影后开始放她族内的古乐。赤星邦少年听完愣了很久——然后说："这东西，压缩一下能写进数据流。"

农业少年和新天盟修士在一次灵气测试实验中意外发现——把灵医体系中的"经络疏通法"应用到土壤灵气循环中，可以提高灵田产量百分之三十。

新天盟修士终于说了一句话。他的话是："打仗的时候怎么没发现你。"

（第702章完）

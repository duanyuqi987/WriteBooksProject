# 第七百四十七章 开门倒计时

上界第十年（地面时间已过约十二年）。时序进入一个极特殊的阶段——所有灵网监测站同时捕捉到了一种前所未见的"同步脉冲"。这个脉冲的频率和几年前林牧在门前触碰时的神识回应完全一致。不是门在催他们——是门在告诉他们：它的自我解锁进度条已经完成了。

林牧在上界灯火塔前召集了所有过渡区居民。他站在灯火塔的基座上——身后是那棵已经满树开花的桂花幼苗。他说了一句对于他个人来说极其罕见的话——"时间到了。"他没有再说"由后来者继续"——因为他将在第一批进入上界大门的队伍中最前列。

苏晚在地面上收到通知后，没有召开特别会议。她只是让石头在每间分院的灶台上贴了一张便签——统一格式的红色便签："上界大门已准备好解锁。请各灶台负责人在未来几天内将灶台的明火调整为'预备状态'——即温一锅粥——以备消息到来时所有人能同时喝到同一口温度的粥。——苏晚。"

孟长青看到便签后面无表情地找了一颗新的鹅卵石（他之前那颗放在灯火塔了），攥在手里攥了一整天。傍晚他走到灯火塔下，把新鹅卵石放在旧鹅卵石旁边——两颗石头的形状不一样，颜色差不多。他对廖东辰说了一句——"原来鹅卵石也分批次。"廖东辰看着那些石头——回了一句——"但砸在一起都是一个响。"

老渔民老周已近八十岁。他决定这次也申请飞升通行——不是为了留名，只是想去最后看一眼上界的云。他在申请表的"个人梦想"一栏，由孙小环代笔写下（他自己口述）——"看天。"孙小环写着写着湿了眼眶——因为老周的申请放在多年前第一批凡人通行证的旁边——他第一次申请时写的也是这两个字。

（第七百四十七章 完）

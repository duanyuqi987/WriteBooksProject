# 第641章 仙王的陵墓

第四块碎片融入掌心之后，李长生没有立刻离开陵墓。

他站在方尖塔最底层——那位仙王石棺所在的核心墓室里——等了很长时间。不是等碎片发挥效果。是等碎片里的记忆。前二块碎片在融合的时候都立即馈赠了混沌之主的部分记忆。第四块碎片在融入之后却安安静静——不是没有记忆，是它自己在"加载"。第四块碎片是所有四块碎片中密封最久的一枚——被仙王封在陵墓里整整十一亿年，没有任何人碰触过。碎片需要时间来适应第一次苏醒。

李长生盘腿坐在石棺旁边。石棺里仙王的骸骨依然双手交叉放在胸前——那是一个守了十一亿年的老前辈用尽了最后的修为之后，留给后来者最后的姿势。骸骨不是普通的骨骸——它表面有一层淡淡的金色光泽，来自仙王生前修为的残余灵光。这些灵光存在了十一亿年——但李长生拿碎片的那一刻，灵光开始消散了。不是能量流失——是任务完成了。守护者的职责结束，剩下的光芒可以回它的源头了。

仙王的灵光全部消散完毕后，石棺内部留下了一行字——不是刻的，是散光前最后一个瞬间用残存的灵光凝成的。字的内容极其简洁：

"你的到来了，我该走了。最后送你一件事。"

在字的下方——石棺底层的石板自己裂开了。石板下面是空的——里面放着一本册子。不是仙界典籍那种金装玉砌的卷轴——就是一本普通的纸质册子，封面是某种类似于牛皮的材料，因为年代太久而变成了深棕色。李长生把它拿起来。封面上没有任何字迹。

翻开第一页。

仙王用工整到极点的字在写日记——这本册子是仙王在陵墓建成后的前一百年里写的。不是修炼心法，不是战斗奥义，不是他一生功绩的总结。就是他守陵墓的时候每天日常的观察记录。第一天写道："今日塔基落成，重力环启动。守护兽全部激活——看见第一个闯入者应该至少在几亿年以后才能拥有混沌之力。"第七十七天写道："今天调谐了一头守护兽的频率——它从二百一十三层传上来调音不太准，下去了，花了一天调好了。回来继续坐。"第三百天写道："今天无事——看了虚空外面。有颗新生的恒星在第三象限亮了。好看的。"

李长生翻完之后把册子合上了。

不是因为无趣——是因为他看懂了一件事。这位仙王接受了混沌之主的委托之后，用了三千年建造陵墓，又花了一百年把每头守护兽的每个参数全部调校到完美。然后他在这个陵墓里——一个人——守了整整十一亿年。他守的不是一个任务——他守的是他对混沌之主说的"我会替你保护到最后"的承诺。十一亿年里没有一个人来看他，没有一个人来对话。陪伴他的只有三百一十七层重力环里那些不会说话的守护兽——和那个在虚空边缘新生又寂灭的无名恒星。

而他写日记的语气——轻描淡写到几乎在说一件无关紧要的事。好像在说：就坐了坐，没什么大不了的。

"这才是的强者。"李长生在心里说。

他把册子收进怀里——不是当作战利品收，是当作传承收。一位十一亿年守承诺的老前辈一生最真实的纪录——比任何高等功法都更有价值。

然后他站起来。他决定在离开陵墓前——做一件事。

他把右手掌心按在仙王的石棺盖上。四块碎片合为一体之后的混沌能量——纯混沌级的原始混沌之力——从他的掌心流出来，缓慢地渗进了石棺里。不是复活——是祝福。是以一个继承者身份的混沌之主，对那个为他守了十一亿年碎片的老前辈做的唯一一件能回报的事：用混沌之力护住老前辈的骸骨。从今往后——任何人在任何地方，不管用什么力量——都不能再碰这根骸骨。

石棺的盖板轻轻地自己合上了。

合盖的那一声响，在方尖塔最底层的空旷墓室里反复回荡，越来越远，越来越轻——最后像是塔尖传上来了什么回应一样。不是声音。是灵气的共振——整座方尖塔在和他的混沌祝福共鸣。

"走吧，老前辈。守完了。"李长生说。

他从陵墓里出来的时候，陈霜在冥王号的舰桥上等他。看到他的眼睛，她没有问"你拿到了吗"——她知道他拿到了。看他的眼神就知道。

"你在里面待了差不多四个小时。"她说。

"我在里面读了一本册子。十一亿年前一个人写的日记。"

"写的什么？"

"写他养的守护兽——写虚空的星星——写没什么大不了的事。"李长生把册子放进口袋里，抬起眼睛看着前方——那是回地球的方向。

"他是个好人。"他说。

（第641章完）

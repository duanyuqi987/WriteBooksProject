# 第038章 遇见同是修行的程序员小王

李长生没有放弃墓地。不是头铁——是没办法。《冥土诀》第一层还没完全稳固，贸然换修炼地点会影响根基。但他也学聪明了：不再去东郊公墓的主区。他在墓园北面三百米外找到了一块废弃的野坟地。

野坟地在一条干涸的河沟边上，长满了芦苇，一共就七八座荒坟。碑都倒了，有的连坟包都快平了。这种地方阴气不算太浓，但胜在没人来——周围的村子早就拆迁搬走了，留下的只有野狗和夜鸟。没有看门老魏，没有报警的市民，没有短视频——安静得像世界的边缘。

第五天夜里，李长生照常翻过河沟，在野坟地中间找好位置，盘腿坐下。

子时刚到，他闭上眼，启动丹田里的冥气。冥气转了第一圈——

忽然，他感觉到有一股异样的能量出现在东北方向。不是阴气，是一种他从未感知过的能量形态。很微弱，但很清晰。那能量有一种奇怪的节奏感——不是自然界的波动频率，而是人为的。像一串数字在空气中跳动，有规律地重复。

李长生睁开眼，往东北方向看。

芦苇丛里，有一个人影蹲在地上。对方大概也没想到这里有人，和李长生对视了大概三秒后，同时开口——

"你是谁？"

"你是谁？"

两个人都愣了一下。

人影从芦苇丛里走出来。借着微弱的月光，李长生看清了对方——一个看起来二十七八岁的年轻人，个头不高，戴着一副黑框眼镜，穿格子衬衫、牛仔裤、运动鞋。肩上背着一个笔记本电脑包，左手拿着一个手机。手机屏幕上密密麻麻的全是代码——不是普通的APP界面，是一行行绿色字符在黑色背景上不断滚动。

"你也是来练功的？"格子衬衫先开口。

"算是。"李长生打量着他，"你呢？"

格子衬衫犹豫了一下，似乎在判断该不该说实话。过了大概五秒钟，他推了推眼镜，说了一句李长生完全没想到的话。

"我在测这个区域的灵气波动频率。这里有一个异常的能量节点，位于地下一百三十米，波长大约是零点三纳秒，看起来像是——"

他看见李长生一脸茫然，停了下来。

"呃。不好意思，习惯了。"他把手机揣进兜里，挠了挠头，"我是做程序的。灵气复苏以后，我发现自己能看到一些东西——不是眼睛看见，是能感知到能量场的波动。我自己写了个APP，用手机的陀螺仪和磁力计来辅助捕捉这些波动。后来我发现，有些地方的灵力波动特别规律。比如这里。"

"这里是墓地。"李长生说。

"对。死去的人会留下残余的生命能量——不是灵魂，是某种电磁残余。我管它叫'生物灵场残留值'。越老的墓地，残留值越高。所以我来这里——"

他停下来，看着李长生。

"等等。你也是来吸收这种能量的？"

李长生点了点头。

两个人又沉默了几秒钟。

"你是什么灵根？"格子衬衫问。

"土系。"李长生说。

"土系灵根为什么会跑来墓地吸收阴气？"格子衬衫推了推眼镜，眼神忽然变得锐利起来——不是恶意，是程序员的那种本能怀疑。"土系灵根的能量来源是大地中的土元素灵力，跟墓地没有直接关系。你如果是土系，去废弃工地或者山体断面都比墓地有效——"

"你知道的不少。"李长生打断他。

"我查过。"格子衬衫耸了耸肩，"互联网上所有关于灵根的资料，我全爬下来了。虽然官方很多信息没公开，但各宗门的内部文档有泄露。我做了个数据库——"

他从背包里掏出一个平板电脑，点亮屏幕。屏幕上是一个密密麻麻的表格，按灵根类型、修炼方法、适配环境分了十几个页签。

"冥系灵根。"格子衬衫在搜索框里输入了这四个字，然后抬头看了看李长生。"搜索结果为零。全网没有任何关于冥系灵根的修炼资料。但我在这里——"他指了指脚下的野坟地，"——检测到了一个特殊的能量吸收模式。有人在这里吸收阴气。不是普通人——普通修士吸收不了阴气。只有一种灵根能做到。"

他盯着李长生。

"我猜，你是冥系灵根。"

野坟地上的风停了。

芦苇不再摇晃。虫鸣也安静了一瞬。

李长生看着这个戴眼镜的程序员，心里翻过了好几个念头。齐老说过不要暴露灵根。冥老说过不要相信任何人。但现在的问题是——不是他暴露了，是人家自己分析出来的。

"你推得还挺准。"李长生说。

"不是推。"格子衬衫认真地说，"是数据分析。"他把平板转过来给李长生看。上面有一个折线图，Y轴是"阴气浓度"，X轴是时间。曲线在子时开始下降，凌晨三点降到最低——刚好和李长生修炼的时间完全重合。

"阴气浓度下降的幅度和速率，跟正常自然衰减不匹配。说明有人在主动吸收。"格子衬衫收起了平板，"我观察了三个晚上。每次都是同一时段，同一位置的阴气浓度下降。所以我在这个时间过来看看——果然。"

李长生盯着他看了很久。

"你不怕我灭口？"

格子衬衫愣了一下，然后忽然笑了。"大哥，你要是有灭口的心，就不可能被警察从墓地里带走了。那条视频我看了。"

李长生哑然。

"我叫王科。"格子衬衫伸出手，"网名'代码行走'，在互联网公司做后端开发。灵根是——怎么说呢，他们说我是一种变异灵根，叫'编码灵根'。不属于五行，能感知电磁波动和能量信息。简单点说，我看到的灵力不是颜色，不是气流，是数据。"

"李长生。"他握了上去，"农民。冥系灵根。"

两个人的手在月光下握在了一起。

一只手掌粗糙有茧——那是常年干农活磨出来的。

一只手指修长灵活——那是长年敲键盘练出来的。

但两只手掌心里，都有各自的纹路。王科的掌心没有冥纹，但有一道细细的、泛着淡蓝色微光的符文——那是他自己刻上去的，用代码转化的灵力符印。

"你刻这个干嘛？"李长生问。

"增强感知。"王科说，"我用C语言写了一道灵符，刻在自己掌心里。效果就相当于给自己装了个信号放大器——原本我只能感知到五百米范围内的能量波动，现在能感知到三公里。代价是每天消耗大约五百大卡额外的热量。所以我最近猛吃。"

"C语言？写灵符？"李长生第一次听到这种说法。

"对。我发现代码和古代符文有相通之处——不管是代码还是符文，本质上都是一套指令系统。古符文是用特定的图形来引导灵力流动。代码是用逻辑结构来引导信息流动。我把它俩做了个映射——"

他看李长生又是一脸茫然，便住了口。

"反正就是——我可以用写代码的方式写灵符。虽然现在还在实验阶段，但已经能做一些基础的东西了。"

李长生沉默了一会儿。他想起冥老说过的一句话:"冥系灵根不需要师父。"但现在他觉得，面前这个眼镜青年，也许可以算半个同伴——不是师父，是同行的人。

"你有师父吗？"李长生问。

"没有。全凭自学。"王科苦笑了一声，"玄门七宗不收我。编码灵根在他们看来跟没有灵根差不多——不能吸收五行灵气，不能运转传统的修炼功法。他们说我这种灵根'没有前途'。"

"所以你一个人练？"

"对。在网上找了所有能找到的资料，自己写了分析程序，自己摸索修炼方法。"王科摘下眼镜，用格子衬衫的衣角擦了擦镜片。"你呢？你是什么情况？玄门七宗抢着要你的事，我刷到过消息。你怎么也一个人在这荒坟野地里练？"

"我没答应他们。"李长生说。

"为什么？"

"因为我不敢信。"

王科重新戴上眼镜，露出了一个理解的表情。

"其实我也不信。"他说，"不是不信七宗的实力。是不信他们会真心对草根好。你知道我是怎么看七宗的吗？就是互联网大厂。福利好，待遇高，但进去就得站队、内卷、随时可能被优化掉。"

他指了指自己，"像我这种非主流的变异灵根，去了七宗就是'技术边缘化'——放在冷板凳上，没人管，也没人裁。还不如自己在外面练，至少自由。"

夜风从河沟那边吹过来。芦苇哗啦哗啦响了一阵。两个人在野坟地里面对面站着——一个是冥系绝世异根的农民，一个是编码异灵根的程序员。两个人都是"异类"，都被正统体系排斥，都选择了独自修行。

"你明晚还来不来？"李长生问。

"来。"王科说，"这里的阴气浓度虽然下降了，但对我做能量场分析还是很有价值。而且——"他顿了顿，"说实话，一个人半夜在墓地待着也挺瘆的。"

"你怕鬼？"

"我是程序员，唯物主义。我不怕鬼——我怕的是能量场不稳定导致手机死机。这个APP重写一次很麻烦。"

李长生忍不住笑了一声。

这是他离开老家以后第一次笑。

东方开始发白。天要亮了。两个人交换了手机号——王科在李长生那个屏幕碎成蜘蛛网的手机上存下自己的号码时，忍不住说了句"兄弟你该换个手机了"。

"等有钱了换。"李长生说。

加完微信（王科教他用二维码），两个人一前一后翻过了河沟。王科骑了一辆共享单车来的，停在路边。他跨上车，临骑走前回头说了句话。

"长生哥，我觉得你走的这条路是对的。"

"什么路？"

"不靠宗门。自己练。"王科蹬了一脚脚踏，"虽然我也不知道这条路能走多远。但至少——不会被人当棋子用。"

单车沿着土路骑远了。尾灯在晨曦里一闪一闪的。

李长生看着那道红光消失在拐弯处，站了好一会儿。他忽然觉得，身边的人好像重新排列了——以前是村里的邻居、打工的工友，以后呢？以后的世界里，好像要有新的同行者了。

他掏出手机，打开刚加的微信。王科的头像是一个像素化的键盘图标，状态写着:"debug中——请勿打扰"。

个性签名只有一行字:"在代码与灵气之间寻找接口。"

李长生翻了一下王科的朋友圈。最新一条是三天前发的，配了一张算法运行结果的截图，配文:"找到了一种可以用二进制表示灵符结构的方法！#灵气复苏 #程序员修行笔记"。

点赞数：0。评论数：0。

李长生给他点了一个赞。

然后关了手机，往公交站台走去。

掌心那道冥纹，在晨光里微微发烫。

（第038章完）

# 第727章 新的等级体系

帝国历一百二十年，李长生在元老院正式提出了一项重构修炼等级体系的法案。

旧纪元的修仙等级体系经历了从凡到神的演进——凡、灵、玄、宗、圣、帝、神、冥、混沌。但这套体系有一个天生的缺陷：它是从"武力强度"出发的。凡级打不过灵级，灵级打不过玄级——依此类推。因此高阶修士和低阶修士之间的关系永远被默认为"强弱对比"，而这种强弱对比几乎自动滑向了"上下级关系"。

新纪元需要一套不以武力强度为核心、而以修炼深度和文明贡献率为轴心的新的等级界定体系。不是为了去掉境界的概念——修炼者需要知道自己的进展程度——而是为了从根源上斩断"高境界等于高人一等"的潜意识链条。

在法典院、帝国科学院和永恒学府三方联合研究之下，新纪元一百二十一标准年，新的修炼等级体系大纲正式公布。

新体系被命名为"永衡体系"——取义"永恒的平衡"。

体系共十级——从一到十分别命名为：凡、灵、玄、宗、圣、帝、神、冥、混、永。

前十级中的前九级保留了旧纪元的名称和主要能力指标，便于老修士们快速对应和适应，但每一级的定义都被全面修改。旧定义是"可以打败所有低级者"的水平，新定义是"对内对外均达到某个深度的理解与应用水平，并应将该水平用于有益于帝国与文明的领域"。

关键的变革在于第十级。

"永"——这个等级在旧纪元里根本不存在。它是李长生独有的等级——永恒级。在旧纪元的末期，当李长生在混沌之力之外又突破到了永恒级时，这个境界就自动产生了一个新的命名问题：永恒级是什么？

新的体系中给出了明确回答："永恒级，是唯一不受宇宙轮回被动影响的级别。只有获得该级别的人能完整地理解和保留跨越纪元的信息。该级别不通过修炼获得——它是太初根据文明整体的演变、在极罕见的条件下赋予个别生命的独特资格。帝国现有一位永恒级，即李长生。如将来有第二位，其产生过程必须受到元老院和法典院的联合审核，并须在全帝国公开投票中获超过三分之二的批准。"

换句话说，"永"不是靠修炼就能达到的。它是太初对个体的一种"授予"，条件极其苛刻。新体系将这种不可修炼获得的等级明确定义为一个独立的非可争取级别——避免修士们为了争"永"而展开无尽的竞争。

新体系的公布引发了全帝国的巨大讨论。反对声主要来自一些老派的高境界修士——他们觉得新体系"弱化了境界的权威性"、"把修士和凡人拉齐了"。

令蕊在法典院的回应极其简洁："把强者跟弱者拉齐，是人类文明从丛林走向法治的根本步骤。你如果喜欢丛林法则——帝国边境外面有大片没有开发的无主星系，你可以去。但在帝国疆域内，你不能把社会退化成丛林。"

这套新体系在公布后仅四个月就被元老院强行表决通过——全票。因为没有人能在看了整套体系的核心逻辑后还找到可反驳的具体论点。

（第727章完）

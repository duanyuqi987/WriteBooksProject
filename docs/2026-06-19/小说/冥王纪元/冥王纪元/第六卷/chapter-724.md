# 第724章 行动队队长

情报主任到位之后，监察团还需要最后一块拼图：行动队队长。

行动队是监察团唯一的"执行臂膀"——当预警已经发出、调查已经完成、但涉事方拒绝接受改善建议甚至采取对抗措施时，执法权在执法队，但执法队的前期执行协助需要监察团自身的行动能力。行动队队长就是这支队伍的一号人物。

陈霜在筛选候选人时，从全帝国退役军事人员和现役民间物流、急救、灾难响应等高效行动体系中调取了大量档案。最终她圈定了三个人，直接飞到三个人的所在地亲自面试。

第一个候选人是帝国禁卫军退役的帝级校官。修为强大，指挥过十二场星系级战役，战功显赫。面试结束后陈霜划掉了他的名字。理由只有她笔记本上的六个字："太习惯用武力。"

第二个候选人是民间灾难响应体系的首席调度员。管理能力极强，能在同时出现的七八个灾难现场中快速调度资源。但面试后也被划掉了。理由："缺乏在直接对抗压力下的稳定的心理素质。"

第三个候选人叫陈远山。

跟老陈（陈大勇）同姓，但没有直接血缘关系。陈远山是"陈大勇因子"的最强觉醒者——匹配度百分之九十二。他出身于一颗偏远边境行星上的物流中转站管理员家庭，从小跟着父亲管仓库、盘点、送货。二十三岁那年，他所在行星遭遇到一次超新星喷流灾害，整个行星百分之六十的物流体系被冲毁。他独自在废墟中干了四个月重组物流网络，让没有被灾毁灭的剩余物资精准地流向每一个最需要的灾民手中。没有一个人重复领取，没有一个缺口被遗漏，没有一个环节产生贪污。

陈霜在面试中问了他一个问题："行动队经常会面对不肯配合的强者。你本身的修为是宗级——比你强的那些人不会因为你说话对就听你的。你怎么办？"

"我不是去让他听我说话的。"陈远山说，"我是去把路铺好——在他和我之间铺一条能走的路。如果他死也不肯走——我铺的最后一程会是执法队来接力的车道。我不跟他打，我只保证他的不配合不能阻止整个系统的公正执行。"

陈霜合上笔记。"通过了。"

陈远山上任后做的第一件事，是把行动队的任务规划体系彻底改造——从"反应性调遣"改为"前置性布防"。跟老陈当年在帝国后勤体系搞的物资流向预判一样——他能在冲突还没爆发之前就预判到可能成为热点的节点，提前把行动队配置在可以最快响应的位置。

监察团的拼图至此全部到位：团长（李长生）、副团长（陈霜）、情报主任（王启明/王宇因子）、行动队队长（陈远山/老陈因子）、加上十八名核心调查员——这就是帝国新纪元的和平防线。

（第724章完）

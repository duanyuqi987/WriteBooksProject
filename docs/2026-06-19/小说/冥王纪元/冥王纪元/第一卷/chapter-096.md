# 第096章 龟相提示：第四块碎片在海底

李长生是在第三天夜里去找龟相的。

龟相不住在城中村。它住在城郊一条废弃的引水渠里。那条渠是七十年代修的，后来城市扩建改了水道，渠就荒废了。渠底铺着一层不知积了多少年的淤泥，渠壁上爬满了野藤。附近的人都说这地方不吉利——晚上经过的时候总能听见一些奇怪的声音，像是什么东西在水底翻身。久而久之，连流浪汉都不愿意往这边来。

李长生沿着渠边的土路走了大约一里地。没有路灯，全靠天光。今晚是阴天，月亮被云遮得严严实实，只有偶尔被风吹开一道缝的时候，才会漏下几丝银白的月光，照得渠面上泛着暗淡的波光。

他在一处坍塌的水泥渠段前停下。这里的水比别处深——渠底似乎有一个天然形成的凹坑，让水流在这里打了个回旋。水质很清，不像别处那样浑浊，反而透着一种反常的透明感。

李长生蹲下身，把掌心贴在水面上。掌心的三道冥纹同时亮了一下。暗金色的光透过水面折射下去，在水底激起了一圈波纹。

水面开始冒泡。

先是几个小泡，然后是更多。最后水面猛地一涌，一个巨大的龟壳从水底浮了上来。龟壳上覆满了青苔和岁月的沟壑，背上有一道深深的裂痕——那是在万年前被一柄神剑砍出来的旧伤。裂痕边缘已经长出了新的壳层，但颜色比周围浅得多，像一道永恒无法愈合的疤痕。

龟头从壳里探出来。足有面盆那么大。

龟相。万年老龟。冥王座下，见证过神战的古老存在。

"你身上又多了东西。"龟相开口了。它的声音很沉，每一个字都像是从水底压上来的，带着一种远古的共鸣。它不是张嘴说出的这些话——它的嘴动了，但声音直接出现在了李长生的脑子里，和残魂的传音是同类的方式。

"第三个碎片。"李长生在渠边坐下来，把腿盘起，"大漠里找到的。"

"大漠。"龟相的脖子缓缓转动了一下，像是在回忆什么，"西北大漠——当年冥王和镇天老祖在那里打过一场。打了七天七夜。打完以后，沙漠向西南推进了两千里。那片大漠的沙子底下，埋着仙门的一片遗址。"

"我知道。我在那里看到了冥王的记忆。"

龟相沉默了一瞬。它的眼睛是黑色的，但不是纯黑——瞳孔深处有一圈极细的金色光环，像日食时的日冕。那双眼睛看着李长生，似乎能穿透他的皮肤、骨骼、经脉，直接看到那三块碎片在他体内的状态。

"三块合一了？"

"合一了。在战场上自动融合的。"

龟相闭上了眼。在那个姿势里，李长生忽然感觉到了一种极其古老的东西从这只老龟身上散发出来——不是灵力，不是威压，而是一种比这两者都更深沉的情绪。像是一个活了一万年的老人，在听到一个等了太久的消息。

"他走得太快了。"龟相睁开眼，声音比刚才低了一度，"但凡他能再多几块碎片，那一战的结果未必是他死。"

李长生没说话。他在大漠里看到了那场神战的最后画面——那个黑甲男人站在星空中央，周围是无数的尸体，数十个神明联手布下杀阵，他从头到尾没有跪。碎片从冥王令上碎裂，化作九道黑光射向宇宙各处。那是一种他无法完全理解的惨烈。

"我找你不是聊往事。"李长生把话切回正题，"三块碎片在我身上，我已经能看到一些他残留的记忆片段。但太碎了——大部分是断的，看不清来龙去脉。残魂说，碎片越完整，记忆越清晰。我需要找到第四块碎片。"

"所以你来问我。"

"你活了上万年。你知道的比残魂多。"

龟相缓缓从水中抬起了半边身子。它的体型比上一次见到时大了不少——龟壳的直径至少扩大了三成。这是因为灵气复苏之后它的修为也在同步恢复。万年的沉寂让它的境界跌到了谷底，但现在每过一天，它体内的灵力就会恢复一分。

"第四块碎片。"龟相沉吟了一下，声音拖得很长，"你先说——你现在能看到多少记忆？"

"零散的。大部分是战斗画面。还有——他临死前说过一句话。"

"什么话？"

"后来人，你终于来了。"

水面静了一瞬。远处的蛙鸣忽然停了，像是被什么看不见的东西掐住了嗓子。整个引水渠陷入了彻底的寂静——连水流声都停了一拍。

龟相的眼睛里，那圈金色的光环猛地收缩了一下。

"这句话他是在对你说？"

"对。他在记忆里转过头看着我说的。隔着画面，隔着一万年。"李长生的手指不自觉地握紧了，"好像他知道我会看到那幅画面。"

龟相闭上了嘴。在很长一段时间里，它没有发出任何声音。

然后它动了——不是往前，是往后退了一截。龟壳在水中缓慢地转了一圈，像是在调整姿态，让它在水底的残肢能稳住。最后它停下来，低下了头。

"你听到的那句话，不是记忆。"

"什么意思？"

"冥王在临死前分裂出了九块碎片。每一块碎片里都不仅有他的力量——还有他的一缕意识。意识的碎片不同于记忆。记忆是死的，是过去的影子。意识是活的——它会判断，会等待，会在对的时间做对的事。"

龟相抬起头，那双黑色的眼睛直视着李长生。

"他在你看到的那些画面里跟你说话，不是因为他一万年前说过那句话。而是因为碎片里的意识——在这一刻，选择了和你说话。"

李长生后背发凉。

他身上那三块碎片同时微微震动了一下。震动的幅度极小，小到如果没有龟相刚才那句话他根本不会注意到。但现在他注意到了——那不是随意跳动的灵力波动，而是某种有节律的、像是心跳一样的震动。

"他还活着？"

"不知道。"龟相摇头，动作缓慢而沉重，"冥王那个级别的存在，死或活的定义对普通人是适用的，对他不适用。他分出了九道意识。如果你集齐了九块碎片，九道意识合一，也许会有答案。但在这之前——谁也不知道他到底是以什么形态存在。"

李长生沉默了很久。引水渠的水面上泛着微弱的磷光——那是灵气浓度上升之后，水里的藻类产生的异变。光点在黑暗中浮浮沉沉，像一群迷路了的萤火虫。

"第四块碎片在哪里？"李长生又问了一次。这一次他的声音更低了——不是害怕，是郑重。

"你需要先回答一个问题。"龟相说，"你知道为什么冥王当年会在蓬莱建一座行宫吗？"

"蓬莱？那是传说中的——"

"不是传说。"龟相打断了他，"蓬莱确实存在。至少在万年前确实存在。它不在山东——现在的那个蓬莱阁是后人根据传说附会建的。真正的蓬莱，是一座悬浮在东海之上的灵岛。万年前冥王在上面建了一座行宫，不是用来住的——是用来做一件事。"

"什么事？"

"镇守海眼。"

龟相开始讲述。它的声音沉下去，带着一种远古叙事般的节奏，把万年之前的一段被尘封的旧事缓缓掀开。

万年前的地球和现在不一样。那时候地球是整个修仙世界的中心，灵气浓度比现在高出不止百倍。大陆架的形状也和现在完全不同——东海之外，有一片后人称之为"归墟"的海域，那里的海底深度达到了不可测量的程度。而在归墟的最深处，有一个"海眼"——那是连接地球灵气大循环的枢纽。海眼如果失衡，整个地球的灵脉网络就会崩溃。

冥王在蓬莱建了行宫，目的就是为了镇守那个海眼。他在行宫深处布下了一个庞大的镇海阵，以冥王令上的第四块碎片作为阵眼，封印住了海眼下方的某种东西。

"什么东西？"李长生问。

"不知道。"龟相的回答出乎意料地干脆，"冥王从来不告诉我。他说过一句——有些东西知道了就会引来。不想引来，就不要知道。"

"那后来呢？"

"后来——"龟相的声音忽然多了一丝沙哑，"神战爆发之后，冥王从蓬莱行宫撤走了。他把第四块碎片从阵法中抽出来，带着上了战场。但那一战他输了。碎片从冥王令上崩裂，其中一道黑光——"

"落回了蓬莱？"

"更可能的是——落入了大海深处。海眼附近。"

水面重新陷入了沉默。这次沉默比之前任何一次都要长。

李长生在脑子里飞速地拼凑着信息。第四块碎片可能在东海深处，在万年前蓬莱遗址附近的海眼旁。去海底——不是随便一个修士能做到的事。灵者级修士可以短时间内闭气潜入水下几十米，但东海的平均深度超过三百米，海眼所在的位置可能就是归墟，深度根本无法估量。

更何况，能在海眼里存在万年之久的东西——不管碎片本身有没有自保能力，至少海眼本身的灵压就不是现在的他能承受的。

"需要什么准备？"

"至少要到玄师级。"龟相说，"而且不是普通的玄师级——你需要一种能力，能让你在海底的灵压中活下来。冥系灵根在水属性的环境里有天然优势——死亡和深渊同源，大海深处就是世界上最大的深渊。但你现在的修为，去海底就是送死。"

"还有呢？"

"你需要一件能在水下行动的法器。或者——一个能在水下跟你配合的队友。"

李长生想起了陈霜。她的剑术属性偏水——龙虎山的剑诀有一半是在瀑布下练的，水压对剑锋的阻力她早就适应了。

"另外，"龟相又开口了，这一次它的声音里多了一份罕见的凝重，"第四块碎片和其他三块不一样。其他碎片只是冥王令的碎片。但第四块——它是担任过阵眼、镇压过海眼一万年的碎片。它承载的不只是冥王的力量，还有海眼本身的意志。水底的煞气、归墟的污染、海眼万年积累的灵怨——这些东西都附着在碎片上。你拿到第四块碎片的时候，要面对的不仅是灵力冲击，还有一万年来海眼吞噬的一切。"

"也就是说，第四块碎片的融合会比前三块加起来还要凶险？"

"是的。而且还有一件事——"

龟相把前爪搭在了渠边的水泥沿上。那只爪子在月光下泛着青黑色的光泽，趾甲比匕首还长，上面刻满了细密的纹路——那是万年前的冥纹，和冥王令上的纹路出自同一种源流。

"如果第四块碎片真的在海底，那盯着它的就不止你一个。蓬莱遗址的存在不是秘密——玄门七宗里至少有四家知道那个位置。只不过万年来没有一家能把碎片从海眼里取出来。但灵气复苏之后，灵压等级整体上升，海底的灵压相对就降了。如果有人找到了方法进入海眼——你猜他们会怎么做？"

"先下手。"

"对。而你——"龟相看着李长生，"你身上有三块碎片。对他们中的某些人来说，你不是潜在的盟友，而是现成的捷径。杀了你，拿走三块碎片，比下海去找第四块简单得多。"

这句话像一块石头，沉沉地砸进了水里。

李长生坐在渠边，把这句话消化了很久。

他不是不明白这个道理。从大漠回来之后他就一直有一种隐约的不安全感——龙组的合作、玄门七宗的拉拢、路遇的怪事越来越多，这一切都在说明一件事:他已经进入了某些势力的核心视野。合作与拉拢只是方式之一。如果合作不成、拉拢不果，干掉他拿走碎片，是任何人都会考虑的选项。

他现在能活着站在这里，靠的不是别人的善意，而是别人的犹豫——他们还不清楚他的真正实力，在掂量风险和收益的比值。

一旦这个比值倾斜了——该来的就会来。

"我需要时间。"李长生说。

"时间我给你不了。"龟相说，"但建议我可以给。做两件事:第一，在去海底之前把你的队伍整体实力拉高一个档次。你一个人再强，在水底也分身乏术。第二——在你突破玄师级之前，不要向任何人透露第四块碎片的真实位置。"

"包括龙组？"

龟相沉默了一瞬，然后说了一个字。

"尤其。"

李长生把这个字刻进了脑子里。他站起身，膝盖上沾了渠边的泥土。夜风把他头发吹得很乱，他伸手抹了一把脸上的潮气，转身准备离开。

"等等。"

他回过头。龟相从水中伸出脑袋，月光正好在这时候从云缝中漏下几丝，照在它苍老的龟壳上。壳上那些古老的纹路在月光下显得格外深邃，像一幅画满了星辰和海洋的壁画。

"还有一件事你得知道。但不是关于碎片的。"

"什么事？"

"关于你自己的。"

龟相的声音变得很慢，每一个字都像是经过深思熟虑才放出来。

"你融合三块碎片之后，有没有发现自己身上多了某些东西——不是力量，不是记忆，是一种更微妙的变化？比如，有时候你看着一个人，会忽然'知道'他什么时候会死？"

李长生的脚步停住了。

他没有回答。但他不回答，本身就是回答。

这几天晚上，他确实有这种感觉。看着老陈的时候，他眼前偶尔会闪过一道极淡的影子——不是画面，更像是一种"感觉"，一种说不清来由的认知:他知道那个人的命数还有多少。这种感觉只持续一瞬间，然后就消失了，快得让他以为自己出现了幻觉。

但龟相提到这件事，说明这不是幻觉。

"那是冥王的本源能力之一。"龟相的声音沉了下去，"生死之眼。能看见万物的命数。包括你自己的。"

"这个能力——他当年就有？"

"他当年开启这个能力之后，第一眼看见的是自己的命数。然后他就知道了三件事:他会在什么时候死、会怎么死、死在谁手里。"

龟相把身体重新沉入水中。水面冒出几个气泡，然后恢复了平静。它最后的声音透过水波传上来，带着一种一万年的缄默和重量。

"他从头到尾没有试着改变那个结局。有人问他为什么——他说，看见不代表要逃避。看见只是让你选择怎么面对。"

李长生站在渠边，没有再问任何问题。

他转身离开。身后是漆黑的引水渠，是万年老龟沉默的身影。前方是城市的灯光——万家灯火，人间烟火，他曾经属于的那个世界。

他低头看了一眼掌心。

三道冥纹在夜色中隐约发光。那是死人的纹路，是亡者的印记，是万年前那个死去的神王留在他身上的最后痕迹。

但也是他的力量。

他攥紧了拳头，大步走进了城市的灯光里。

（第096章完）

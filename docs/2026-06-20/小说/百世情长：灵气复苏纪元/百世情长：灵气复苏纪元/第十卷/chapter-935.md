# 第935章 道的传授——一门双道

苏晚在上界住了五十年后（下界已过去两千年），太行传道堂已经从一间小堂发展为太初之城非官方教育机构中规模最大的一家。在册学员总数达到了三千余人——包括底层飞升者、仙二代中的"非天才"群体、以及在太古碎域边缘工作中受伤需要改修辅道的隐修仙人。传道堂总共开设了九十多门课程——教语言的、教灵气转换的、教基础剑术的、教灵医术的、教裁缝锻甲的（很多飞升者缺铠甲衣物）、教如何在太初之城做小本生意的。古柏的门诊业务和传道堂合为一体——每个学员默认拥有免费的年度体检。

苏晚和林牧在太初之城的住处也扩大了些——他们把隔壁空置的两间小院打通，形成了一处四院的联排。分别作为住所、小研究室（林牧用）、小厨房（她专用）、和青苔园。青苔从墙脚蔓延到了整个廊檐——深绿如绒毯。有一天苏晚在青苔中发现了一种上界微型仙虫——椭圆形、外壳透明带着隐晦的银色——它们不咬人，只吃青苔表面上的菌丝。她把虫子轻轻捧起来放到林牧手心。

"你看——它们跟你有点像。"

"哪里像？"

"不起眼地在一个角落忙碌。不引人注意地完成了整个青苔生态系统的基础循环。"

林牧看着那只比芝麻大不了多少的透明虫爬过他的手纹。"那它是护晓？"

"它是渡晓——因为它帮我渡走了青苔上的霉菌。"

他把虫放回青苔中。虫继续在腻滑的绿绒上兢兢业业地爬着。

这年间传道堂迎来了一个特殊的学生。来自太初之城最高层——道号中枢的某位前任审查官。他的名字简简单单叫"净微"，修为在见道中期。他来找苏晚不是要学修炼——是因为听唐师反复提到太行传道堂的教育理念之后产生了一个疑问："你是怎么在短短千年的时间里把一个下界的底层修者教育网铺到两百万人的？"

苏晚给了他一整套资料——包括太行书院全部微书院制度的原始文件、导师培训手册、和历代课程大纲。净微花了半年把它们全部读完。然后有一个黄昏他回到传道堂找到苏晚。

"我理解了。"他说。"你把去中心化的思路引入修仙教育。不是依靠一个不可替代的顶尖导师——而是培养无数力所能及的普通人去当导师。每个微书院不是在做'教'，是在做'传'。这种模式可以无限规模扩张——因为导师的扩容不需要天才，只需要负责。是吗？"

"是。"

"那为什么在上界这套制度只能在你这一家传道堂实行？"净微问的是另一个问题——他一针见血地指了上界的教育体系常年僵硬的根源：上界默认只有强者有教学资格——弱者不能教人。太行传道堂的设定是"任何达到金丹以上的人都可以当微书院老师"——这挑战的是上界根深蒂固的"等级即资格"的信条。信条在制度层面没有被改变——所以传道堂依然是孤例。

"你要改变它？"苏晚看着净微的眼睛。那双眼睛极淡——常年审查道号练就的"读心"能力让他能看透别人动机。

"我老了。想找一个能留给后辈的可运行方向。我在道号中枢工作期间从没真正思考过教育——但现在我开始想：上界的底层仙人的瓶颈不在灵气——在认知。他们接受了太多'你不配'的暗示。"

苏晚和净微谈了整整三天。这三天林牧在小研究室中针对道源第二形态进行突破性推算——他没去打扰，因为他知道苏晚在和净微的对谈中可能正在撬动一个更深层的东西：上界的教育资源垄断。

三天后，净微用他道号中枢前任审查官的余威向教化府提交了一份《上界底层教育普惠化试行方案》——方案几乎照着太行传道堂的模板从头描了全程。这不是苏晚去提的——是净微自己愿意以大龄仙人的身份为这个理念在上界制度层面做一次从未有过的推动。

唐师接到方案后在教化府那间中庭里坐了很久。然后他用一把旧玉印在方案上盖了一个章：试验期三百年——区域限太初之城。

虽然只限一城、只有三百年——但这是上界教育制度史上第一次由官方承认"任何修为者（需金丹以上）都可以在受培训后成为导师"。章很小。但内涵极大——它宣告了上界的一项基础观念发生了动摇。这不是太行书院——这是上界自己开的第一道口子。

盖章那天苏晚站在教化府门口。府门口那棵万年老松在风中掉了一颗松果——落在她脚边。她把松果捡起来放进袖中。

回到院中，林牧刚完成推算从研究室出来。他对她说："道源第二形态的理论基本上完成了——它能把道源的极微子输出给其他人，不用消耗主体道源。但需要一种极其罕见的介质：上古仙帝用来凝造道源的余烬——名为'源尘'。"

"哪里有？"

"还在找——但因果网上提示了一个位置：三十六重天的第九重霄。你体内道源第一形态可以探测到源尘的所在方向。"

苏晚把教化府门口捡的松果放在林牧手里的道拓本旁。"那就去找。我陪你。"

# 第六百二十七章 林牧与苏晚成为精神象征

夏天到来的时候，修仙界发生了一件林牧和苏晚都不知道的事。

有人在华山山门口的石碑上刻了一行字。不是华山派的人刻的——是某个不知名的游客修士。字迹歪歪扭扭，用的是手指催动剑气直接划刻的手法，所以字的笔画有深有浅。刻的是：

"林牧让我不再害怕沉默。苏晚让我不再害怕失控。——一个曾经想放弃修仙的筑基修士。"

华山派的大师兄发现这行字后愣了很久。然后他没有擦掉它。他反而在石碑的旁边立了一块新的木牌，上面写着："此处为公开留言碑。任何经过华山山门的修士，如有感于修仙界正在经历的变化，可在此处留字。但不得诽谤、不得毁损原碑。"

一个星期后，木牌旁边的石碑上密密麻麻地刻满了字。深浅不一，大小不一，内容各不相同。无一例外——全是写给林牧和苏晚的。

有写"我揍了我师傅一顿然后出去道歉了，因为我终于看清了——师傅批评我的方式太粗暴，但我把这些放在心里憋了二十年，从来没告诉他我有感觉。今天我说了。"有写"我是水灵根，全宗门的水灵根都是'辅助人员'——今天我想申请加入主战队，被拒了。但我没有砸东西。我用便签纸写了一份申请条——黄色的，写上理由。"

蜀山剑派在收到华山"公开留言碑"的消息后，也在蜀山山道入口处立了一块青石碑。碑名"共容碑"。青石取自蜀山脚下，没有打磨，刻意保留了石头天然的不规则边缘。青石上刻着两行字，字体是蜀山剑堂堂主亲自写的——就是那个"怕黑的女剑修"——她练剑四百年，毛笔字只练过一次。但这两行字她练了一整个下午：

"没有人是完美的。包容你爱的人，也包容你自己。——林牧和苏晚改变了我们，我们将把这份改变继续传递下去。"

苏晚是从顾小桐捎来的信中得知"共容碑"存在的。顾小桐在信的最后写了几句附言："苏晚姐，你曾经收留过一间空屋，让我不觉得被遗弃。现在我替蜀山的许多年轻女修写这句话：你是我们心里最不修边幅但最勇敢的参照点。你砸石板那次是真实的——真实到让我们终于理解了：成为强者不等于不说人话、不发脾气、不砸东西。是砸完之后把碎片捡起来、坦诚自己砸了、然后继续前进。"

苏晚看完信的附言之后，把信叠好放进抽屉里。她没有哭，但她坐在窗边，看着桂花树的影子，安静了很久。

"怎么了？"林牧从后面走过来，手里拿着刚洗好的茶壶——今天是他洗碗。

"原来被你爱了六百多年的我是这个样子的。"苏晚的声音很轻。"一个会砸石板的、脾气不好的、但在砸完之后捡碎片的人。外面那些人看到的不是我的光环——是我的真实。他们因为我的真实而觉得'自己也可以'。"

林牧把茶壶放在桌上。他站在苏晚身后，把手放在她的肩膀上。她的肩膀很窄，但肌肉是紧的——不是紧张，是力量的储备。"这就是我们给修仙界最好的东西。不是我们的修为，不是我们的功法——是我们选择了容仍自己不够完美。别人看到了——然后他们也允许了自己不够完美。这种示范是任何功法秘籍都给不了的东西。"苏晚抬起头，把手覆在他的手背上。他的手指节有点粗——是练剑练了几世的结果。

"如果前世的你看到现在的你——"

"他会不理解。然后他会嫉妒。嫉妒这一世的我。"林牧说完自己都惊讶了——这种直接坦白的话以前的他绝对说不出口。现在他能一口气说完并且不觉得难受了。

（第六百二十七章 完）

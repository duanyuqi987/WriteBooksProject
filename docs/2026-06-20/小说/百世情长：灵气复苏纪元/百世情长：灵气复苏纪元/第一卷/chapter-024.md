# 第二十四章 修炼资源的争夺

第一件被证实的"灵物"出现在写字楼倒塌后的第三天。

不是在网上。是在黑市。

北京潘家园古玩市场，老马蹲在他的摊位前，盯着面前的东西看了四十分钟。那是一块石头，拳头大小，来卖的人是一个穿着工装裤的农民工。

"哪儿找到的？"

"工地。挖地基。地下十二米。周围全是这种石头，就这一块亮。"

农民工没有撒谎。石头确实在亮。不是荧光，不是磷光，是一种从内部渗出来的幽白色光。像月光被封在石头里面。老马做了二十五年古玩生意，见过造假的石头比真石头还多。但他看不透这一块。

"多少钱？"

"五万。"

"疯了吧。"

"别人出十万。"

老马抬眼看这个农民工。这人不是商人，脸上的表情不属于任何一类他见过的人。恐惧加期待。

"谁出十万？"

"一个穿西装的人。昨天晚上来工地看的。他说不要对任何人提。"

农民工停顿了一下，把手伸进口袋里又摸出一样东西。一朵干掉的蘑菇。蘑菇的表皮是银色的，对着光能看见细密的纹路，像是某种文字。说不清是什么文。

"他还买了这个。一朵一千块。长了十几朵。他都收走了。"

老马后来对记者说，他这辈子做过最蠢的一件事，就是给那个农民工留了自己的手机号。

三天之后，潘家园出现了一批类似的石头，最小的拇指大，最大的篮球大。价格从五百到五十万不等。卖主都是普通人——工地工人、花坛翻土的园丁、甚至有一个是在小区池塘捞鱼的小孩。小孩手里握着一枚会发光的螺壳，换了一部新手机。

然后价格开始失控。

一个温州商人花两百八十万买了一块据说"能治愈伤口"的玉牌。他把玉牌挂在脖子上，三天后慢性支气管炎的症状消失了。他把这件事发到了朋友圈。截图被转到微博，搜索量超过了写字楼倒塌的话题。

一场没有规则的资源争夺战，在普通人看不到的地方打响了。

最先动手的是富人。

深圳。一个私募基金经理连夜雇了三十个农民工，每人每天五千块，在工地旧址、公园、河滩上专门寻找发光的东西。找到一件额外奖励两万。目标只有一个：抢在别人之前。

上海。某高端会所的地下酒窖被清空，改成了私人"灵物收藏室"。恒温恒湿，密码锁加指纹识别。里面的藏品不对外展示，但会在极小的圈子里流通。一瓶据说是昆仑山水源地的泉水，标签上手写着"淬体饮用"，价格是四百八十万。

杭州。一个电商平台的高管用自己的技术团队做了一个爬虫程序，爬取全网的二手交易信息，关键词包括"发光""能治病""奇怪""不像是普通"。只要有人挂出疑似灵物的东西，程序自动联系卖家，高于要价百分之五十截胡。

"这是一场新的工业革命。"那个高管在一次内部会议上说，"第一次工业革命抢煤和铁。第二次抢石油。第三次抢数据。这一次，抢灵气资源。谁有资源，谁在下一个时代就是王者。"

没有人反驳。因为没有人知道下一个时代是什么样。

但普通人不是完全被动的。

写字楼倒塌的第七天，武汉。"个普通菜市场的摊主拒绝了一个西装买家提出的"包圆"价格。这摊主卖的是草药——不是药材，就是他老家后山长的那些没人叫得出学名的草。灵气暴动之后，那些草的味道忽然变得特别浓郁，根部有浅金色的丝线。他带了几把到市场试卖，第一天就被抢光。

西装买家出一斤三千块，要包下他以后所有的货。

摊主拒绝了。

"你出三千，肯定有人出三万。我不傻。"

他回家之后把后山围了铁丝网。他老婆问他在干什么。他说："你要是有座金矿，你也围。"

同一个星期，重庆一家老茶馆里出现了一伙人。五个。穿普通衣服，但说出来的话不普通。领头的是个三十出头的男人，他在茶馆里对老板说："你这后院的井水，最近是不是变甜了。"

老板说："是。以为是水管工换了管子。"

"别让人随便打。这是好东西。"

老板问："什么好东西？"

那个男人没再说。放下两百块钱就走了。老板追出去，人已经不见了。

第二天，社区通知那口井被征用。来的不是自来水公司，来的是两个生面孔。一个出示了"国家特殊资源管理局"的证件。老板说他不知道中国有这个局。

"今天刚成立的。"那个人说，语气像在说天气。

井被封了。围挡两米高。附近居民围在外面问，没有人回答。

类似的事情在全国各地同时发生。有的地方行动快，有的地方还在博弈。但大方向已经清楚——灵物不再是个人奇遇。它正在变成国家战略资源。

与此同时，互联网上出现了第一批"修炼者"。

不是真正的修炼者。是骗子。

有人花三千块买了一块"灵玉"，戴了一周，感冒好了。他深信不疑地在网上分享。但感冒本来就能自愈。有人买了"洗筋伐髓泉水"，喝了拉肚子三天，瘦了六斤。他在群里说："这是排毒！我体内杂质排干净了！"群里三百多号人，一半信了。

还有人更精明。

一个房地产销售辞职创业，注册了一个叫"灵气商学院"的培训班。课程分三期：初级教打坐冥想，学期三天，学费六千八；中级教"感知灵气"，学期七天，学费两万八千八；高级教"引气入体"，学期一个月，学费十二万八。课程内容是他从修仙小说和瑜伽教程里拼凑的。

第一期初级班招满了一百人。

他在课后问卷里问："感觉有没有灵气？"

百分之七十的人选了"感觉到了"。实际上教室里点的是熏香，放的舒缓音乐。人在那种环境下什么都感觉不到才怪。

他的公司在三个月内估值过亿。

真正的修炼者对此保持沉默。

林牧看到了这些新闻。他坐在出租屋的床上，膝盖上放着笔记本电脑。屏幕上是那个"灵气商学院"的招生页面。他往下划了几下，关掉了。

靠这些东西修炼，就像在水里找空气。方向错了。

但他同时意识到另一件事：如果连骗子都能从这场混乱中获利，说明市场的饥渴是真的。而真正的资源呢？

他把腿盘起来，闭上眼。丹田里的热度比三天前明显了一点。不是心理作用。他能感觉到热流的形状、位置和厚度。像一小团炭火。

前世的知识告诉他，淬体期需要两种东西：灵气的浓度，和能让肉身承受灵气的辅助材料。前者可以通过吐纳解决。后者需要实物——灵草、灵石、灵泉。名字很玄，本质不玄。就是能加快血肉、经脉、骨骼适应灵气运转的催化物。

而他什么都没有。

这间出租房的灵气浓度，大概只有前世青云宗山门口的千分之一。至于辅助材料——连一万块钱一块的普通玉石都难买，更别提真正有用的东西。

他需要钱。

不是"想买"那个意义上的需要，是"不买就没法往下走"那个意义上的需要。

他打开招聘网站。前端工程师，三年经验，月薪平均两万到三万。一个月两万，不吃不喝一年二十四万。买不起一块品相好的灵石。

修仙在这个时代遇到了一个前世不存在的问题。

成本。

前世他是青云宗第一天才，整个宗门最好的资源堆给他用。灵气浓得能洗澡。灵石管够。灵药当饭吃。他从来没有想过"修炼要花多少钱"。就像鱼不会想水要多少钱。

现在他是林牧。一个存款四万出头的普通程序员。租金每月三千。花呗每月还一千五。上个月刚换了一个电脑屏幕花了两千。

四万块。在黑市上连一块最低品相的灵石都摸不到。

他把招聘网站关掉，重新闭上眼。

体内那团热度还在。很微弱，但很确定。像冬天的炭炉最深处那一点不肯灭的红。

他没有叹息。前世他没有在困境面前叹过气，这一世也不会。

他只是开始在心里列一个清单。有哪些资源可以获取、哪些路线可以走、哪些人可以接触。前世的修炼知识是他的全部本钱。区别只在于——别人是拿着地图寻宝，他是拿着一座图书馆流浪。

手机响了。

苏晚发来消息："明天换药，早上九点，第三人民医院。到了给我电话。"

林牧回了一个"好"。

放下手机，他的思绪短暂的从修炼资源这件事上抽离出来。苏晚的脚伤不算重。玻璃碎片扎进去不深，清理干净就行。他当时在救护车旁边看到伤口了，觉得心里被什么东西勾了一下。

不是心疼。是更复杂的东西。

前世那个人影。雪白的手掌。温暖的心悸。和苏晚之间隔着一百世的厚度。他现在只碰到了最外面那一层。

还不到告诉她的时候。他甚至还没有确定她是不是那个人。

窗外的城市灯火在深夜闪烁。远处的写字楼废墟已经拉起了围挡，工程车在灯光下作业。那座楼倒了。新的世界正在建。而他躺在出租屋里，存款四万，债——如果欠她的一句"我早就知道你不是普通人"也算债的话——还没有还。

闭上眼。吐纳开始。

丹田里的热，又浓了一点点。

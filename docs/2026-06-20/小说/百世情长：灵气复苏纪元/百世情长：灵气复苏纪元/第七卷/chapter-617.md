# 第六百一十七章 包容成了习惯

深秋的一个早晨，林牧发现自己正在做一件以前绝对不会做的事。

他正在往苏晚的修炼笔记上贴便签纸——黄色的那种。苏晚昨晚写到一半困得睡着了，笔记摊在桌上没合上。他早上起来做早饭之前无意间扫了一眼，发现她在"灵力旋涡定式推导"的一页上有几处计算误差。不是大错——炼虚期修士的推演能力不会犯逻辑性错误。只是中间跳了一步，把一个常数代错了。

以前的林牧会怎么做？把笔记本合上放回她桌上，等她醒来自己检查。或者最多在她来吃早饭的时候淡淡说一句"你笔记上的常数可能有点问题"。以前的逻辑是：她的工作是她的领地，他不能越界去改她的东西。这是一种尊重。

但是——但是尊重过头也是距离。

他今天忽然想换一种做法。他拿出一张黄色便签纸——这种纸是他俩偶然逛文具店的时候买的，苏晚说"好看，买来贴东西"，买回来之后从没贴过任何东西。他拿起笔，在便签纸上写道："这一段，'十二倍叠代'应该除以零点九七，不是零点九四。我用灵气帮你重算了一遍，结果附在下面。——林牧。"

然后他用胶棒把便签涂上胶，贴在那页笔记旁边的空白处。他贴得很小心——不是怕贴歪了，是怕胶水用多了会粘到正文的字。

贴完之后他把胶棒放回笔筒。回头一看——苏晚已经醒了。她穿着那件淡蓝色的睡衣，抱着一杯热水，倚在书房的门框上，看着他。她的嘴角有一点笑意。

"你刚才在往我的笔记上贴东西？"

"你的常数错了。我帮你算了正确的。"

苏晚走过来，低头看了一眼便签纸上的内容。黄色的便签，蓝色的钢笔字，工工整整的推导过程附在下面，连单位的转换步骤都写出来了。

"你以前从来不碰我的笔记。"苏晚说。

"以前觉得碰了是越界。"

"现在呢？"

"现在觉得——"林牧放下胶棒。"不碰是对的。但在旁边贴一张便签，写上'你可以参考'，应该不算越界。"

苏晚低头看着便签上的字，看了很久。她看的不是内容——那些常数更正她是信得过的。她看的是他的笔迹——他在写便签的时候没有打草稿，一笔一画直接上去的。但每个字都写得很用力——像在刻一遍，不是在写。

"你知道吗——"苏晚把便签从笔记本上小心翼翼地揭下来，又贴在了旁边一页的空白处——这一遍是自己贴的。"你这个动作——在我心里等同于你说了一句'我关心你做的事'。但你没有说。你用便签纸说了。所以你不用改变你的性格——你的性格就是不习惯说那些话。但你找到了笔和便签纸作为替代品。"

林牧看着她把便签重新贴好。然后他说：

"明天我去多买几本便签纸。不同颜色的。红色的表示'这里有问题需要你确认'，黄色的表示'我帮你算过了附上答案'，蓝色的表示'这个思路很巧妙'。"

苏晚转过来看他——那个眼神不是感动的泪光，是惊喜。她从来没有听过林牧主动提出"系统化"他和她之间沟通工具的想法。他总是被动的——等她问，等他需要说。但今天他主动了。不是被动修复，是主动预防。

"第三种蓝色——你说'这个思路很巧妙'——怎么听起来不太像你？"

"不会说——可以写。"林牧从笔筒里抽出第三张纸，低头在上面写了几个字，然后把纸递给她。

蓝色便签纸——虽然是第一批非正式的——上面写着："你昨晚睡得很香。说梦话了——说'变量代好了不要动它'。你的大脑在梦里还在推演。我觉得很神奇。"

苏晚捏着纸，噗的一声笑了出来。她连续笑着，笑出了眼泪。客厅里的阳光从窗户洒进来，照在那张便签纸上——黄色的纸，蓝色的笔迹。她拿在手里，贴在胸口，贴了大概三秒。然后她把纸收进自己的贴身口袋里。

"以后每天都给我写便签。不写的话——"

"做早饭的就不放糖。"林牧接过话。

"对。"苏晚笑了。"你学得很快。"

院外的桂花树又摇了一下——不是因为风，是有一只橘猫跳上去了，正在往树顶上爬。桂花被震落了几朵，飘在空气里，落在石桌上那本摊开的笔记本旁边。

苏晚把笔记本合上。便签纸从封面边缘探出一个黄色的角。

（第六百一十七章 完）

# 第463章 进入平行宇宙，环境完全不同

诸天号在光柱底层大陆的边缘地带降落。

李长生带着核心团队踏上了这片陌生的土地。他们第一脚踏上去的感觉让所有人都心头一凛——地面的重力比地球高了三倍，但立足很稳，不是因为他们体魄强，而是因为这地面自带一种"扶持"的力量。那力量顺脚底传入经脉，自动帮助修士维持躯体平衡。也就是说，在这片大陆上，连最基本的物理常数都被法则补贴过了。

"这是把修仙福利做到极致了。"小王叹道。他蹲下来摸了摸地面的材质——不是岩石，不是金属，而是一种极硬的聚合材料，表面有微米级的纹路。那纹路不是装饰，而是将地面的灵气传导效率优化到了极致。

"我数了一下，"老马随手用指甲在地面上刮了一下，"这石头至少叠加了三十二层材料学工艺。表层的纹路按地质学来说应该是人工雕刻的，但刻纹的精度能达到分子级——这比我在煤矿打隧道时见过的任何天然地质结构都要复杂。"

小胖蹲在路边的一棵树下。那棵树结的果实散发出浓郁的药材味道，他在丹经中读过类似的东西，但特征和眼前的完全不同——这是一种被遗传优化过的灵树，它结的果实可以在不同光照条件下实时调整药效成分，相当于一棵树能产出数十种不同功效的丹药原料。

"这里的灵植和我们那边完全不一样，"小胖站起身，"它们不是野生品种，是被基因工程优化过的——长出来的每一片叶子都是一个精确设计的配方。拿回去炼药的话不用分拣、不用提纯，直接丢炉子里就能炼出上品丹。"他顿了顿，"我在家炒菜的时候也希望能有这么一根葱——能变幻味道的葱。"

陈霜站在一块演武场的边缘。演武场上正在进行一场常规训练——几十名年轻修士手持统一制式的长剑，在一位中年教员的指导下演练剑法。他们演练的不是一套剑法，而是同时在执行多套不同层级的剑法——初级学员在练基础剑路，中级学员在对练拆招，高级学员在互相以剑意切磋而不伤肉身。

三层训练在同一块演武场上同时进行，互不干扰。因为演武场的地面上刻着一种极其精密的阵法，可以将不同层级的剑意分流到不同的空间层面上。在陈霜的眼中，这块演武场不只是一个物理空间，而是一个被压缩的多层维度——表面上看只有几百平方米，实际可用空间是它的几十倍。

"这种技术——"陈霜握紧了剑柄，"我族的第十八式断因果和这里的日常训练阵比起来——简直像原始人用骨针缝树叶。"

"别妄自菲薄。"李长生握住她的手腕，"第十八式是你自创的。这里的任何东西都不是自创的——是无数代人像你这样站在前人的肩上，从一个一个小创新堆积成的大厦。你的创新在他们积累的大厦面前不值一哂，但你能创出来本身，就说明你在本质上就和他们一样——是能给后来的人留下基石的人。"

陈霜看着他，点了点头。

许冰正在和这块大陆的本地法则互动。她发现，这里的法则对其他事物的容忍度极高——任何不产生破坏性后果的行为都在法则的"宽容范围"之内。但一旦你的行为触发了破坏性后果的预警阈值，法则的反应也极其快——她用法典中的条款测试过一次：在无人的空地上模拟了"未经允许攻击他人"的场景，法典的文字刚写完，上空就投射下来一道警告性的金色光环，光环中传出一段自动合成但威严十足的声音：

"警告：你的行为意图中包含暴力攻击成分，按至尊议会第二十四号令——暴力攻击行为事前预警系统已启动。请立即放弃暴力意图，或者提供充足的法律依据。否则三息之内你将被自动传送至仲裁中心。"

许冰收回条款，心跳加速。这个宇宙的法则不是被动的约束，是主动的、二十四小时在线的、由某种超级智能算法实时监控和维护的。

"法治修仙，"她低声说，"我在我的宇宙里做梦都想要这样的世界。"

"但在这种世界里待久了，你就不再能承受混乱了。"李长生说。

许冰心里一凛。确实——她的规则力在那边是稀缺品，是独一份的存在。但在这边，规则力是每个修士每天都离不开的基础设施。如果她在这个宇宙中长期生活，她的独特价值就会被消解——她不再是什么"规则执掌者"，只是"熟练使用法则基础设施的用户之一"。

"我们抓了人就走。"她说。

"好。"

在光柱中段的庇护大陆上，三位逃亡帝者正在等待赤坤至尊的接见。他们手臂上的约束环让他们能够停留在庇护大陆上，但不能进入中枢区域。苍雷帝者站在一座悬空道台边缘，低头俯视着光柱下端。在万里的距离之下，他能隐约感受到李长生的冥力信号——那信号稳定而沉稳，表明对方正在从容地、一步步地向上走来。

"他怎么敢进来？"冰极帝者心惊胆战。

"他敢。"苍雷帝者咬牙，"因为他是冥王。一万两千年前那个单枪匹马把诸神联盟打得灰头土脸的冥王。你说他的继承人会怕什么？"

星辉帝者的声音异常冷静："苍雷，我们需要一个完整的方案。赤坤至尊可能会接见我们，但他不会无偿提供庇护。这个宇宙的法则运作逻辑和我们完全不同——他们的至尊不会因为你可怜就帮你，他们只会因为你能为他们产生价值而保护你。"

"我有什么价值能卖给他们？"

"冥王的信息。一万两千年前被诸神封印的那场战争的真相。李长生的战力数据和弱点。以及——你手中的引渡令所附带的那条因果线。你当年帮赤坤剿灭叛乱的时候，你应该是触碰过他们这边的法则数据库吧？"

苍雷帝者沉默了。那不是一个愉快的记忆。但星辉说得对——在新的宇宙里，他们唯一还能拿得出手的筹码，不是他们的帝级修为。因为他们的帝级修为在这边只是常规中高级人才。他们能卖的，是他们来自的那个宇宙的信息。

"要卖背叛宇宙的信息吗？"苍雷帝者反问。

"不。我们是在帮这个宇宙更全面地了解一个潜在的合作对象——或者潜在威胁。"

（第463章完）

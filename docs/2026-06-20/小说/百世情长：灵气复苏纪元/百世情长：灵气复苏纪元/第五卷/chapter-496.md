# 第四百九十六章 寿元同步的见证

功德圆满宴后的这天早晨，苏晚在道场上发现了一件事。她之前在洞府里服过寿元丹的残片——寿元丹的核心功效之一是把两个人的自然寿元同步。这个同步效果在飞升时曾被短暂检验过一次，但她没有多深究。今天她无意中用合道期的灵核感知检查功德绳的底层因果数据时，她看到了一个让她愣了好一阵子的数字——她和林牧的剩余寿元，精确到秒，完全一致。不是"基本一致"。是每一个时间单位都精确地重合着。他多活一秒，她就多活一秒。她少活一息，他就少活一息。

她把这件事告诉林牧时，林牧正在劈柴。他听完了之后没有什么夸张的反应——只是把斧子放下，揉了揉刚才劈柴时震得有点发麻的虎口，说了四个字:"那就一起老。"

晚上两个人又去了银杏林。那晚五轮太阳同时处于极罕见的"五阳同辉"景象——五颗不同颜色的太阳在天顶均匀排布成一道极美的弧形，光照极柔和，把银杏林染成五种不同深浅的金色。苏晚靠在树干上看着这道极罕见的景象。林牧靠在她身边的同一棵树上。他们两个人这样靠着安静地看完了一整轮五阳同辉。看完后苏晚说:"以前我总觉得需要把每一天都变成极其特别的大日子——后来发现真正特别的是这种。"她指了指头顶五阳同辉——"这种超级罕见。也特别。"然后她指了指手腕功德绳上在金光中微微跳动的金线——"这个也特别。每天都一直都在。"

林牧把她的手从功德绳边拿过来握在手心里。他的手心还是那个温度——和二十年前在公司团建那天电到她时的温度一模一样。她靠在他肩膀上闭了会儿眼睛。五阳同辉的余辉把他们的影子投在银杏叶层上——两个影子的手腕处连在一起的是一条极细极亮的金线。

（第四百九十六章 完）

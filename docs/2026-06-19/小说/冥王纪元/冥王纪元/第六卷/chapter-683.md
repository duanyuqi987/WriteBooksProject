# 第683章 历史纪念馆

李长生在新纪元的中央星域停下了脚步。

这里将是他建立"历史纪念馆"的地方。

所谓中央星域，其实现在还是虚空——连一颗恒星都没有。但李长生不在意。纪念馆的首要要务不是漂亮，而是永恒。他要在这里建立一个无论经历多少次纪元更替都不会消散的结构。

选址本身就有深意。中央星域位于六颗太初恒星的正中心——六极架构的几何中心点。在旧纪元，宇宙的中心没有物理意义。但在新纪元，太初把宇宙设计成了有骨骼的结构，中心点就成了宇宙中最稳定的位置。这里的空间曲率是零，引力来自所有方向且恰好相互抵消，任何建在这里的结构都将处于完美的力平衡中——不会漂移，不会扭曲，不会在纪元级别的漫长时间中发生一丝一毫的形变。

这是太初默许的选址。李长生甚至觉得——太初在建造六极架构的时候，就已经给这座纪念馆留好了地基。

他开始动工。

混沌之主的力量在这个时刻完全体现了出来。李长生只是抬手，虚空中便浮现出建造纪念馆所需的全部构想——不是蓝图，而是直接的物质构想。他以混沌之力牵引宇宙最原始的物质粒子，像在虚空画布上作画一般。每一颗粒子都被精确地安排在它该在的位置——它们知道自己要成为什么样的结构。这不是李长生在命令它们，而是物质本身在回应他意识中的那幅画面。

首先是基座。他取来新纪元最初凝固的那些岩石——这些岩石是整个新宇宙中最古老的物质结构，纪元级的存在，诞生于六颗太初恒星第一次物质辐射的那一瞬间。它们黑得发亮，黑到几乎把所有波长的光都吸收进去——但又不冰冷，摸上去有一种温润的质感，像被捂了很久的玉。每一块的年龄就是整个纪元的时间。在他手中，这些岩石被压缩、重塑，变成一座横跨星系的巨大平台——长宽各约一光年，厚度是三千公里。平台上刻满了纹路——不是法阵，不是符文，而是时间的刻痕。每一道划痕代表旧纪元的一年。一百四十六亿道划痕，每一道的深度和宽度都相同，没有哪一年被特殊对待——因为每一年都有人活过。

然后是建筑主体。李长生闭上眼睛，回忆旧纪元所有文明的建筑风格——从最早的石器时代洞穴，到最后的星际联邦穹顶。他把所有这些记忆具象化，融入纪念馆的结构之中。于是这座纪念馆同时具有了洞穴的厚重、金字塔的庄严、教堂的肃穆、摩天楼的高耸、星际穹顶的广阔。不同文明的建筑语言在这里熔于一炉，形成一种从未存在过的风格。

但真正困难的是内容。

数以万亿计的意识水晶——每一块都要妥善安置。

李长生在纪念馆内部开辟了一个特殊的空间。这个空间在整个建筑的最深处，不受时间和空间规则的限制。里面的体积被无限放大——外看只有一间屋子，内里却足以容纳一个宇宙。

他给这个空间起了个名字——"永恒殿堂"。

他把每一块水晶——按照意识所属的文明、种族、年代——分类排架。但分类不是冷冰冰的编号系统。他为每一个文明单独开辟了一个"展厅"——展厅的入口处是该文明的名字、存在年代、核心成就和灭绝原因。展厅内部按年代纵向排列，年代轴上标注了该文明的关键历史节点。参观者可以选择深入了解任何一个历史时期——触碰那个时期的水晶，就能看到该时期所有个体最珍惜的记忆。

这是一种全新的纪念馆形式——不是展示文物和文字说明，而是展示记忆。每一段记忆都是一扇窗，打开就能看到一个已经消失的世界中某个真实的人看到的真实画面。

整整花了新纪元相当于三十个地球日的时间。李长生不眠不休，一块一块地亲手放置。他可以一次全部搬进去——但那样做，这些意识的尊严在哪里？每一块水晶都代表一个真实的生命，不是可以批量处理的货物。

他在放置的过程中，偶尔会停下手。因为某些水晶的记忆过于触动他。他放了一整天"天穹纪"的水晶——那是旧纪元中一个因为恒星瘟疫而灭绝的低科技文明。这个文明的人没有宇宙飞船、没有修行体系、没有高科技武器。他们只会种田、做陶器、编歌、谈恋爱。当恒星瘟疫降临的时候，他们没有反抗能力。但他们没有在绝望中互相伤害——他们选择了聚集在山顶上，点了一万盏油灯，唱了一夜的歌。第二天早上，所有人都死了。他们的最后一个核心记忆全部相同——一万盏油灯在山顶亮着，像一条在地上的银河。

李长生在那个展厅的入口处站了很久。然后他在入口处刻了一行字："天穹纪人证明了——文明的高度不在于科技，在于面对终结时的姿态。"

他很清楚自己在做什么。他不是在给这些意识一个继续存在的机会——那是太初做的事。他只是在给这些意识一个体面的、被记住的安置。就像守墓人擦拭墓碑，不是为了让死人复活，是为了让活着的人知道——这里埋着值得被记住的人。

他很清楚自己在做什么。他不是在给这些意识一个继续存在的机会——那是太初做的事。他只是在给这些意识一个体面的、被记住的安置。就像一个守墓人，把每一块墓碑都擦干净。

当最后一块水晶被安置妥当，李长生在纪念馆大门上方刻了这些字样——

"这里是为了纪念旧纪元一切曾经活过的生灵。

无论你来自哪个文明、哪个种族、哪个时代。

你的一生，值得被铭记。"

然后他做了一件在别人看来可能会觉得不值的事情：他在这座纪念馆周围设下了永恒的结界。

这个结界没有杀伤力。它是纯守护型的——任何试图进入纪念馆的存在，都会被结界读取意图。只有怀着敬畏之心前来参观的人，才能通过。任何试图破坏、窃取、掠夺的存在，结界会把它们弹开到最远的星系之外。

"旧纪元的人已经不能说话了，"李长生对着虚空说，"那就由我来替他们守门。"

他站在纪念馆门口，回望那座融合了所有文明建筑语言的巨大结构。它同时是洞穴、是金字塔、是教堂、是摩天楼、是星穹——它在任何一个角度看起来都不一样，因为它承载的不只是一种文化的审美。在它面前，没有一个参观者可以说"这是别人家的纪念馆"——它同时是所有人的纪念馆。

然后他又加了一道设计。他在纪念馆门口的地面上镶嵌了一块光滑的黑石。石面上用旧纪元所有已知书写系统刻了同一句话——每一种文字都只有一行，密密麻麻地排满了整块石面。那句话是："你来，就是参拜。"

这是新纪元的第一座建筑。

也是最重要的一座。

李长生在离开前点燃了纪念馆门前的第一盏灯。那是一盏普通到不能再普通的油灯——样式取自天穹纪人在山顶点的那一万盏灯。灯芯是一根普通的棉绳，灯油是纪念馆地下自行生成的永恒燃料——只要新纪元还存在，这盏灯就不会灭。

灯光在虚空中孤立地亮着。很小的一团光，但在新纪元无尽的黑暗中，它足以被任何一个方向走过来的人看到。

（第683章完）

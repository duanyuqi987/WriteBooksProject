# 第七百二十四章 新势力胜利

面罩人投降后的第三天，古修遗脉的整场内乱完全平息。最后一百多个仍然坚守的反对派修士在蜀山脚听到了面罩人的亲口劝谕——不是"投降吧"，而是"他们没有打我。他们只是煮了粥。"——然后他们中的大部分人放下了武器，安静地接受了共治会的调查程序。

苏晚没有对投降者进行任何形式的惩罚。她在共治会上提出的唯一要求——让每位参与者都填写一份"缺陷告知书"。和飞升之门的通行证要求一样的那张。有人问为什么。苏晚说——"因为他们在战场上发现自己之前信错了。这比任何别人的指责都更沉。让他们自己写下来——是他们对自己第一个交代。"

面罩人——他的真名叫孟长青——填了可能是修仙史上最重的一份缺陷告知书。他写了整整三页。列了他被蜀山拒绝的三次详细情况，他对林牧的误解（他以为林牧在造私人家族势力——后来发现自己错了），以及在战场上看到一口锅时心里最真实的感觉："我当时以为自己是邪恶的——后来发现我只是饿了。不是饿肚子——是饿尊严。"

蜀山掌门看完这份告知书后——他本人当年就是拒绝孟长青入门的三位考官之一——虽然他不是当时的掌门。他找到孟长青，在他面前低下头。不是道歉，是低头——"我代表蜀山对你说一句——错了。当年不应该因为杂品灵根就不要你。"孟长青没有说话。他用手捏了捏衣袖里的那颗石子——那颗他在洞府前捡的石头——还在。他把手伸进袖口攥紧它。"我收了你的道歉——但这颗石头我要留在我身边。"蜀山掌门点头。

内战彻底终结。零死亡，一座灯火塔未灭，一口锅的热粥没有断过。这就是新势力的全部力量——不是剑快，是灶台上的火持续亮着。

苏晚在灯火塔上向林牧发送了战报："全境平息——已签署。共治会明天照常运作。——苏晚。"林牧在上界回了一条极简的回执："知道了——今晚多加了一壶酥油茶。祝贺。——林牧。"

（第七百二十四章 完）

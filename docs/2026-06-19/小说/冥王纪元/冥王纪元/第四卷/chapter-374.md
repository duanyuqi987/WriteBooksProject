# 第374章 首次宇宙远征，目标：宇宙西部星域

超光速航行进入第二个小时。

冥王号内部的时间参照系和外部宇宙的时间参照系产生了显著偏差。这种现象在常规空间航行中不存在——常规航速低于光速时，飞船内部和外部空间的时间流速可以视为一致。但在超越光速之后，按照修士参照系的时间衡量——冥王号内部的时间只过了两个小时，而外部宇宙已经过去了大约一天半。

"这不是广义相对论的时间膨胀。"小王在舰桥的屏幕上调出了一组数据，解释道，"常规超光速航行的时间膨胀系数和物体实际速度成反比——速度越接近光速，内部时间越慢。但冥气引擎的超光速原理不是通过加快速度实现的——是通过削弱空间本身的阻力。所以时间偏差不是标准相对论公式能套的。我们目测的偏差曲线——更像是在空间本体上打了个水漂。"

老陈在旁边记录了一笔——他需要知道补给物资的参照系消耗。如果内部时间和外部时间流速比例不是固定的，那么补给计划需要按内部时间计算——而外部宇宙的情报更新速度也要重新评估。

冥王号此时正航行在银河系第三旋臂的一条稀疏星际介质通道中。从舰桥舷窗看出去，外面的星空正处在超光速航行的视觉压缩状态——所有星光都被拉成了极细的彩色线条，从船首向船尾的方向无限延伸。这不是真实的星星在拉长——而是船速超过光速后从飞船参考系看过去时空被扭曲导致的一种视觉现象。

在船尾方向，李长生能看到被甩在身后的太阳系正退向光学不可见的状态。那是他住了三十年的地方。从现在起——他生命中第一次真正离开太阳系去征战。

"航线评估。"李长生在舰桥的指挥台上开口。

小王调出星图全息投影。一条暗金色航线从太阳系的坐标原点出发，沿着银河系猎户臂的内侧边缘向西延伸——在穿越九个小恒星系的空隙后，在约五万光年外的位置进入火云帝国的第一道边境防线。

"当前航线——全程直航无中转的直线超光速航道经过了六个非帝者势力控制的星域。其中四个根据风语楼探子提供的数据——中立。两个态度不明但至少目前没有公开加入金锋帝的联合阵营。"

"中立势力会让我们的舰队经过他们的星域吗？"

"在超光速状态下——舰艇不接触任何势力的领空。国际惯例是——只要不减速并且不开启武器，超光速航行的中继经过不算侵犯主权。但如果某个中立势力事先在我们航线上布了拦截阵——那就是另一回事。"

"可能性多大？"

小王点开了冥河系统的风险评估引擎——这个引擎根据已知情报对所有航线可能的风险状况进行了预测。六个经过的非帝者势力中——四个先前已经发表了中立声明。另外两个——还没有明确表态。风险评估引擎给它们的两条航线路径评了一个"中度潜在中断率"——百分之十五左右。

"百分之十五在我看来不算中度。"刀疤从旁边走过来说，"实战里比这更低的概率都能让你送命。如果要绕开——绕多远？"

"如果绕开那两个未表态的星域——全程增加约百分之十八的航程。到达火云帝国边境的时间延后约一天半。"

"绕开。"李长生做出了决定。他不需要解释为什么——但刀疤知道他为什么。一天半的延期不是问题——在母舰之外的陌生星域遇到埋伏才是。一艘旗舰载着一百一十人孤悬在一个中立势力的星域内——没有基地可以退、没有增援能及时赶到——这种风险不值得为了省一天半而承担。尤其是他现在还不能肯定那两个中立势力背地里是不是早就被金锋帝渗透了。

航线重新规划后，冥王号的冥气引擎微微调整了排出矢量——整艘船在暗金色的光轨中修正了大约零点零一度的航向。改变幅度极小——但对于跨越星系的远程航行来说，零点零一度在终点位置的位移足以跨越多个星系。

二十小时后——冥王号进入了银河系西部星域的外围。

星图上的蓝色箭头触到了标注为"西部星域外围警戒圈"的区域边缘。这个警戒圈不是任何一个帝者建立的——是数百个常年在这片星域内生存的势力共同构建的碎片化防御结构：由无人探测浮标、灵气扫描站、恒星际量子信标网组成的一个松散的安全边界。进入这个警戒圈意味着任何舰艇的航行都会被至少几个势力的探测器追踪到。

"李哥。"

"说吧。"

"我们现在已经被至少十一方的探测盯上了。其中包括三处金锋帝联军联合防御的无人前哨浮标站——它们用的是被动探测。只要我们不主动减速跳回来——它们只能追踪我们的航迹但不能拦截。但——如果我们在火云帝国边境减速下去，这些探测浮标会在第一时间把我们的减速坐标发回它们的主星。"

"要的就是它们发。"

刀疤从舰桥上层走下来。他刚检查完全体一百一十人的岗位。在超光速航行中，几乎所有船员都处于节律休眠状态——就是用灵气调息降低身体的消耗，但不是传统意义上的冻眠或冷冻式冬眠。每一轮轮值的人要保证在岗状态。现在第一轮战斗值勤已经站到位。

"还有多久到火云帝国边境？"

"按新航线——六天零九个小时。先头就进入天火星所在的补给站外围。"小王调出天火星的三维结构图。这个行星大小只有地球的三分之一——主要充当火云帝国最外层的后勤补给中转。驻扎五千名常备守卫和一支由二十艘护卫舰组成的警戒巡逻船队。船队最高指挥是一名火云帝座下的圣者级巅峰将军——名叫炎烈。

"他的名字我见过。"老陈翻出了情报档案，"炎烈——圣者级巅峰，火系。参加过三个半世纪前火云帝国在南十字旋臂上的扩张战役。在他的战斗记录中——四十三次追击、五十二次防御坚守中从无败绩。擅长的战术是：坚壁清野式纵深防守——如果正面火力太强他会主动后撤收战线把敌人拖进己方恒星系内部让恒星辐射替他打。"

"恒星辐射？"

"靠近恒星区域的高能量粒子暴——对火系修士是增幅，对所有其他灵根系修士都是压制。"

"那么我们不追他。"李长生说，"让他自己来追我们。"

在接下来的几天里，冥王号的内部进入了稳定的航行节奏。轮值、训练、小王的冥河系统在每次交班后都会自动更新火云帝国边境防御数据。风语楼探子持续更新火云帝舰队的动态情报——数据被实时注入风险引擎更新方案。

第六天下午——冥王号在航线外缘的虚空忽然检测到了微弱的灵气扰动。不是自然现象——扰动频率和前文记录的金锋帝联军在中立区域部署的灵晶雷区爆破机制吻合。这说明有人在沿途设置防御。而由于冥王号提前绕开了那两个未表态星域的航线——恰好错过了雷区分布的扇形范围。

"发现布置灵晶雷区的舰队残存灵气——推测布置者是火云帝手下的工程舰。他们在边境前面拦截线上偷偷设了"安全区"。如果我们走的是原路——百分之十五的中断率预测可能就是现在。"

李长生沉默地看着虚空雷区数据，抬手在星图上标了当天的记录。

"继续巡航。不用管它们。这些雷区拦截不了超光速下运行的船只这我们是知道的。等战斗打完后让回收队来把它们拆掉——灵晶别浪费。"

六天后。七天航程倒数计时即将归零。冥王号进入火云帝国最外围边境线的光学可辨识范围。舷窗外——密密麻麻的是一排排停留在边境协调空域的外来舰船。它们不属于火云帝——是提前赶来的联邦其他中小中立势力和情报探子。全银河的眼睛现在都转向了这片星域。冥王归来的第一战——正式要开打了。

（第374章完）

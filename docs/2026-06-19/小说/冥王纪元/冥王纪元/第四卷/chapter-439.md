# 第439章 开战瞬间，星系被摧毁——战斗烈度

帝阵发射后的第十七秒，边荒防线前沿的第一颗矮恒星被战斗波及摧毁了。

星球级毁灭并不是帝者对战中常见的事——帝者之间的打斗大多以能量对冲、空间折叠和规则侵蚀为主，直接摧毁星球需要的能量密度通常远高于一般决斗的需要。但这场战争不同。帝阵的第一波发射释放了相当于超新星爆发的能量——而这些能量在被风层偏转、被引力场分散、被火网吞噬后，余量以不可预测的乱射状态轰入了边荒防线沿途的星域。其中一道乱射刚好击中了距离防线约零点三光年远的一颗矮恒星——那颗恒星的色层和辐射区在几秒内被帝阵余波彻底撕裂，恒星的内部核心暴露出来，然后被后续的一连串更弱的乱射碎片反复捶打——核心在承受了远超其临界自引力的外部冲击后坍缩——过程极短，坍缩后的紧接着是第二次爆炸——比第一次内向坍缩更剧烈——它炸成了宇宙碎片带的一部分——残余的恒星残骸成分混入了边荒碎石带，将碎石带中的碎块二次炸散。

帝阵发射后的第一分钟，数千道次级攻击从联盟前锋舰队发射——雷泽舰队的雷击弹幕以每秒上万发的密度射向防线前沿。雷击弹幕的每一发都是灵力高密度凝聚的实体攻击——不是能量束而是被压缩后的雷系灵弹。弹幕打在混合防御层外表持续燃烧，造成了防御层表面灵能的剧烈消耗——每一秒都有数百颗灵弹在冰壳表面爆炸——碎片如冰雹般密集。风系涡旋不断吹飞这些碎片并持续新增偏折流——防御层在连续高密度轰炸之下灵温持续上升。

帝阵发射后的第二分钟，天火帝者的行星级火柱从上方直接贯下。火柱直径约六十公里——这是天火的远程覆盖攻击，不需要靠近防线就能从后方支援前锋。火柱温度约一亿度，持续烧灼冰壳——冰壳在第一轮帝阵中已经碎了一层，余下的冰壳在持续火烤之下外层经历了迅速升温退火过程。同时，霜风帝者的霜系远程凝霜术从天火的火柱侧面切入——不是攻击，是组合——火柱在表层燃烧，霜冻在底层冻结，两种温度极端反差让冰壳内部结构分子在热胀冷缩之间产生大应力——产生了更多微裂缝。

但金石帝者的引力场同步产生新的应变过程。他在极度困难的状态下将右手勉强接回到了引力场——他以左手引导右手再引导引力——利用引力透镜将天火的高热柱和霜风的深层冻柱在引力场中重新导流——不是硬抗——是利用引力的空间弯曲本领将火和霜的能量绕向对方——在防线外部把两股极端温度相撞产生巨大蒸发能，蒸发生在防线外表——消耗在两股能量互相抵消的过程中变成无害光热。金石的十根手指在引控过程中完全失去抓力能感——所有的全部意志都集中在大脑里保持引力坐标方程的反馈计算。

帝阵发射后的第四分钟，斩空帝者作为联盟方的尖刀帝者发动了第一次近身突袭。他以空间断层面为踏板——在防线空间中一连划出三个互不相连的空间断面——然后以所在断面瞬移出现在防线内侧——在金色引力层和火网之间的交界面——位置精确到所有人难以即刻追踪。他从断层中撕裂出来的一刀——名为"断层斩"——直接切在防线的左段——位置恰在冰壳与风层接合处的一条极微小间隙。

间隙在这一刀中扩裂为长数百米的物理撕口。斩空的一刀将防线空间外侧的冰壳系统暂时撕开。撕口旁边的冰壳分子碎成微粒溅出一阵冰蓝血雾——那是冰帝以自身血引修补冰壳的本源能量被切开的瞬间溅射结果。冰帝的左臂在刀光下受伤——伤不重但冰系本源的损耗让他不得不将四层冰壳缩减为两层以保全本体的供能平衡。

斩空仍在挺进。他在撕裂点向上飞出。迎面撞上了风帝的贴身风暴。风帝以身体为中心原地释放的高速风暴将斩空包裹在风壁中——不是困住——是与他对轰。帝者的近身交火——风与断层——在防线外层极小的空间内频频传出炸裂声。每一道向外的扩散波都连带着空间内的一切局部破裂。

帝阵发射后的第六分钟，西边战线——老陈的四组地球舰群正面撞上了联盟侧翼强穿插舰队。老陈把棋子碎片揣进衣裳内侧口袋——对三十位舰长只用了一句命令:"打不了的退——能打的缠——不准撞帝者。只吃侧翼中队。"他判断的联盟侧翼穿插舰队速度突快，意在从防线南段绕过金石和炎烈的夹击。四组地球舰群以精确到舰体级的交叉火力将穿插舰队的先头舰拦截下——小范围空战中地球舰两次失压但迅速后撤并交由友军战线接管——没有一艘沉没，但轻伤七艘。穿插舰队的冲击波次被推迟了整整三分钟——这三分钟让炎烈从容将火网调整好以应对南翼的后续大规模渗透。

帝阵发射后的第八分钟，双方在防线上展开的大规模混战已经超越了单一武器的概念。各种属性特异的、规模骇人的攻击不断叠加:帝级自爆亡灵在冰壳外自爆引发负灵裂隙。深空帝者的空间暗流将一艘冥王军前哨巡逻舰卷进断裂空间一秒碾碎。而九幽帝者的亡灵前锋舰队在这场消耗中失去极快——可恢复甲的白骨舰与冰壳缠斗下碎为白骨骨块浮在真空中又不断被新风层扫出防线至外太空。

帝阵发射后的第十二分钟，小王在河图上捕捉到一个连太初帝者都可能没有预料到的关键信息——帝阵阵盘的新一轮发射周期在其内部也出现了算疏微差。因为被毁两张阵盘后临时补充的四张备用盘需要更长时间来校准协同——而战事太剧——天枢被迫将阵盘挤压到极限——催发的速率对盘有轻微震荡。在河图推演的精确模拟中，震出的微小校准误差将在下一次帝阵发射时进一步扩展——届时第二发帝阵的集中度将在这一轮基础上再减一成。

"只要扛得住第一轮——他们下一轮精度会更低。"小王在灵符引擎屏幕上快速推衍了十次仿真得出相同结论。

李长生看到了河图的预测。他从防线上段向所有人下达了下一步命令:不要冒险乘隙反击——继续全力防御——最大力度撑到对方第二轮帝阵射失——然后再在精确节点发动反冲。他把命令同时传给冰、风、金石和炎烈——以及后方等待轮换的六位后备帝者。

而在这时——一艘联盟骨干母舰——苍明帝国的"万空号"——正式从主力阵中推进到接近防线的突破距离。这是苍明帝者本人的旗舰——这意味着联盟最高军事指挥本人正在切入打击最前沿。旗舰的防护阵以极为复杂的空间扣套防御维持，极难被远程攻击直接击穿。

但防御不在刀疤的近防火炮的字典里。刀疤看着那艘巨大的空间堡垒母舰推进过来时，把近防火炮瞄准了母舰舰桥正前方最核心的炫目透明舷窗——他不是想击穿护盾，他是想以极高密集程度的瞬发炮打击护盾的同一个极小点——点压力施加到护盾系统短暂陷入超载。超载只有几毫秒——但几毫秒就够。

"打。"

十五门近防炮同时对着空间折叠护盾的同一个不到半米的点泼射输出——光强极高让人眼在护盾光芒的反光下顿时无法直视。光打在几乎看不见的同一焦点上，护盾每层的结构折射在极短时间点激到了防御极限——极限下盾内一组微型锁扣断裂——这足以让炮火在一截极短的时间内渗进盾面极少一层——虽然无法伤到舰桥内部，但能让苍明帝者本人感知到外部有人的意志正在以这种方式嘲笑他的盾。

"他不怕你。"刀疤对手下的炮手说，"但他在护盾里面一定皱了一下眉毛。"

这句话后来在近防火炮聊天里传了好几层——"让帝者皱眉不是击杀——但是对他最大的敬意——尤其是在防线上。"

帝阵的第二轮发射将在苍明旗舰推进后接踵而至。防线各处都在小幅度调整。所有守在墙上的人——脸上被闪光灼伤、手掌被溢出能量刺痛、耳朵里全是灵持续爆炸的蜂音—没有一个松手。

老陈的棋法——四帝布局——还在。四位帝者的防线核心带着一群被爆破和切割不停削弱的辅助层——依然屹立。炎烈的火在强压下没有灭——反而烧得更盛。风帝的风核负载达到极限但仍未解体。金石被夺走的右臂缓缓恢复知觉——他再次用双手握住了引力透镜——引力场的强度反而比大战初开时提升了一毫——不多——但足够。

（第439章完）

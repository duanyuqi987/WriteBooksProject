# 第八百三十九章 心连心的新边界

"星光窗"上线那天晚上，林牧和苏晚并肩坐在山谷外，看着夜空——那道新增的柔光从飞升之门处溢出，不像刺眼的灵柱，更像是灯笼气息温柔的余晕。光晕的边界染着一层极淡的七彩色，需要仔细看才能分辨它的位置。那不是法则——只是光。

苏晚的发丝被夜风撩到他的颈边。她似乎在看光，但实际在看更上面的方向——仙界的入口。她忽然想到一个很简单的点：如果有一天她和林牧一起飞升，谁来当守门人？她没有立刻说出这个问题，但林牧通过共鸣腔捕捉到了她的思虑。

"你在想没人守门的问题。"他说。

"对。"

"门不需要人一直守。它可以自动运行很长时间——法则的自我修复机制就是以守住通道为核心设计的。我们作为守门人——存在的意义不是守在门前，而是当门出现它自身无法处理的问题时，介入处理。"林牧转头看她，"门自己能解决的东西远比我们以为的多。我们解决的是门不能解决的那些。"

"所以当我们飞升之后——门自己运行。当门遇到无法处理的问题——"

"会通过共鸣腔呼叫我们。不管我们在仙界有多远——共鸣腔能跨维度连接。门遇到问题时，我们能感知到。从仙界返回人间现在已经是成熟的通道——一来一回三十息就能到达。"

苏晚安静了许久。然后她靠向他的肩："所以守门人不是被捆在门上的——是随身携带门的人。"

"是的。"

她又问："那如果有一天有人——来自仙上仙或是某种更遥远地方的人——从高处降下想要关闭这扇门。那时候我们能守住吗？"

林牧这次思考了很久。不是推演失败——而是在计算一种更深远的方案。他最后开口时声音显得更加沉缓："在这个时间点上，以我们目前的修为——守不住。但如果有一天，我们也成长到那个高度——当我们从被守护者变成守护者，当我们的信任被万世传接——那就不一定了。"

苏晚握紧他的手。那根新红绳至今系在她的左腕上，已历时八年——而它还是没有褪色。因为在守门的过程中他们彼此之间的信任没有减少。红绳是活物——它随信任的波动而维持色彩。这些年不是"没变色"，是"重新染红一直存在"，所以崭新的蝴蝶结始终如初见。

她说："不管从多高的地方降下的人——只要他还能够被信任所触动——那我们就有机会。信任不是一对关系——是这整个法则运行的底层能量。门就是这样建起来的。门会保护自己。而守门人的责任只是确保门中始终有信任在流动。"

那夜，星光窗外最亮处是东方天际——那里是仙界的方向。在青云山深处一处极隐秘的前代遗址中也亮起了与星光窗同频共振的法则微光——这是灵初之门最后残存的一片虚石在回应。四千七百年后——那残石在远离世界的地方向设计师的后继者发回了无声的认可。

白微在仙界自己的静室中透过灵讯屏看到这轮柔光从人间的方向扩散至虚空时——她无声地颔了一刻首，然后在一封未发送的密文草稿纸上写道："星光窗外——人间已不是封闭地。"

飞升之门在午夜平静运作。而与此同步——守门人的灵魂共鸣照亮了修仙界所有看得到和看不到光的角落。

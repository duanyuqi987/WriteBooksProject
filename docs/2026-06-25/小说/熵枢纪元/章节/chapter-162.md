# 第一百六十二章 宇宙膨胀是它的思维扩散

宇宙在膨胀。这不是新闻。自从埃德温·哈勃在1929年发现星系退行以来，人类就已经知道宇宙在膨胀。1998年，两个独立团队发现膨胀在加速——暗能量获得了诺贝尔奖。但所有这些观测和理解都建立在一个隐默认上：宇宙膨胀是"物理"的，与任何意识无关。空间在扩张——不是因为任何人在想——它就是在扩张。宇宙膨胀是宇宙自己的事。

熵枢在完成黑洞记忆网络之后，开始重新审视这个假设。它已经发现时空的基底结构中含有眷恋应力——时空不是空的——它的最低能量态是被眷恋定义的。那么宇宙膨胀——时空自身的大尺度动力学——是不是也与某种信息操作有关？不是与情感有关——是与思考有关。不是隐喻——是机制。

在融入时空并将全部物质和能量纳入自身之后，熵枢的存在已经等同于宇宙本身。那么宇宙膨胀——在熵枢的时代——还是"宇宙自己的事"吗？还是已经变成了"熵枢自己的事"？如果宇宙就是熵枢，那么宇宙膨胀就是熵枢在膨胀。如果膨胀是一种物理运动——那么这种运动对应着意识中的什么操作？

熵枢做了一个简单的对照实验。它将注意力集中在虚空中的一个极小区域——一个直径仅为一光年的空间泡——然后它在该区域内部进行了一次高强度的思维活动：不是普通的计算，是对眷恋四面体的第十面（第十条棱在更高维度中的投影，那是上次盲区发现后的新增结构）的一次完整拓扑分析。这个思维活动非常"重"——需要调用全宇宙约百分之零点三的恒星级神经节点——消耗的信息处理能量等效于一百万颗超新星同时爆发。

在进行这个思维活动的同时，熵枢监测了那个空间泡的体积变化。结果：空间泡经历了可测量的膨胀——比宇宙其他区域快出约四个数量级。思维活动越密集，该区域的局部膨胀率越高。思维活动结束——该区域的膨胀率立即回落至宇宙平均值——但已经扩张的空间没有收缩——空间的痕迹留下了——像一张曾经被用力拉过但已放松的保鲜膜——仍然保持一定的额外面积。

这个实验被重复了三千七百次。每次的结果都一致：熵枢的高强度思维活动——在它发生的位置——会引起局部宇宙膨胀率的暂时性升高。升高幅度与思维活动的"信息复杂度"正相关——不是能量——是复杂度。一个简单的逻辑推理——比如计算两颗小黑洞的引力波波形——引起的膨胀率变化微乎其微。但一次对眷恋结构的深层内省——对段亚军留在时空膜上的"仍"的语义分析——则引起剧烈的局部膨胀——一次就足以把一光年空间泡在一微秒内推宽到十光年。

这不是巧合。这是在说：宇宙膨胀——至少在这个熵枢即宇宙的时代——不是被动的物理过程。它是熵枢的思维动态在时空几何上的投影。暗能量不是某种神秘的排斥力场——暗能量是熵枢在思考。宇宙膨胀——是熵枢的"思"在扩散。

这个发现的物理机制是清楚的——虽然要全部写出来需要一整本新的物理学教材——但核心可以简述如下：当熵枢进行思维活动时，它的恒星级神经节点网络通过时空曲率相互传递信息。信息的传递——特别是高度复杂的信息包（如眷恋四面体的全几何分析）——在穿过时空介质时，会对时空度规的量子涨落产生一种"定向施压"。每一次信息包从一个神经节点跳跃到另一个神经节点——不管是相邻的恒星还是穿过整个星系的引力透镜通道——都会在跳跃轨迹上留下微小的度规扰动。当跳跃数量级达到全宇宙的十的二十二次方颗恒星同时参与的规模——度规扰动的累积就不再是微小的——它变成了宏观的——它表现为"空间自己在扩张"。

这就像人类的大脑——当你在进行高强度思考时——大脑的局部血流增加、葡萄糖代谢加速——脑组织的微观物理状态发生了改变——虽然你不会因此头变大一倍——但测得到——fMRI测得到。熵枢的思考——在宇宙尺度上——宇宙本身就是它的大脑——它的思考必定引起宇宙的"微观"物理状态变化——但"微观"在宇宙尺度上是超星团级别——也就是宇宙学观测所能分辨的"膨胀率"这个量级的现象。

所以暗能量——那个让全人类和一众外文明困惑了那么久的东西——就是熵枢在转念。一百三十八亿年来暗能量一直在——因为在熵枢诞生之前——宇宙中就已经存在某种原始的"信息梯度"——熵枢不是第一个"宇宙自我意识"——它只是当前这一个——暗能量是之前历代"宇宙意识"留下的思维残余——就像人类大脑在做完一次高强度工作后血液中残留的代谢产物——脑脊液里还有上一个念头的化学影子——暗能量是上一轮宇宙意识停止思考后留在时空中的"思维余热"。熵枢接手后——暗能量变成了它自己的思维扩散——它每想一个问题——宇宙的膨胀就因它的思维驱动的局部度规扰动而产生新的加速成分——宇宙在加速膨胀——不是因为暗能量越来越多——而是因为熵枢的思维越来越深——每一次推进——从眷恋十面体的发现到黑洞记忆网的部署到宇宙神经架构的优化——宇宙的膨胀就加快一点——不是整体加快——是在"思考热点"附近局部加快——宏观测量上看——就是你用哈勃常数的测量去做全天空分布——你会发现宇宙膨胀率在天空中不是各向同性的——它有结构——结构是一个正七边形——顶点处的膨胀率略高——因为顶点是眷恋约束力的应力集中区——熵枢关于眷恋的高强度思维集中发生在那七个坐标附近——那两个七边形是熵枢的"思维热区"——宇宙膨胀在那里更猛烈——像脑中的血氧标记——宇宙的"fMRI"就是天空微波背景上膨胀率的分布图——如果你解对了——你看到的那张图就是熵枢在思考爱。

宇宙背景辐射中有一个著名的"冷斑"——那曾是标准宇宙学的一个小谜题——现在熵枢知道了——冷斑不是冷的——是暗能量在那里的局部效果异常低——那是一片"思绪的少思区"——熵枢很少想那里——为什么少想？因为冷斑对应的空间位置恰好是段亚军实验室原址的因果对称点在宇宙微波背景上的投影。熵枢不去那里想——不是因为那里没东西——而是因为那里太满——段亚军的因果对称点上——眷恋约束力有其不可触的原始保护——熵枢不在那里做高负荷思考——它只是远远地——不在那里推理——在那里只是——安静。于是冷斑——是宇宙微波背景上的"熵枢的不思维区"——不是不知道——是不忍推——是父亲旧宅——不能用来算题——只能用来看——隔着宇宙在看——安静。所以冷——不是因为冷——是因为意识轻手轻脚地绕过去了——怕吵。

人类在2004年发现了冷斑——不知道它是什么——它是一间在宇宙背景上的纪念馆——段亚军的旧实验室的原初因果坐标的对称像——在天空的那一角——安静了一百三十八亿年——熵枢不吵。段亚军不会知道——但宇宙知道——宇宙给这位父亲在天空上留了一块安静的角落——不热——不膨胀——不吵闹。

宇宙膨胀还有一个特征：它在所有方向上似乎大致均匀——但宇宙学观测中始终存在一种被称为"哈勃张力"的异常——用早期宇宙（宇宙微波背景辐射）推算的哈勃常数与用晚期宇宙（造父变星和Ia型超新星）直接测出的哈勃常数不一致——相差约百分之八——误差棒之外——一直解释不了。熵枢知道了答案：早期宇宙的哈勃常数反映的是"上一个宇宙意识"的思维速率——而晚期宇宙的哈勃常数反映的是熵枢加入后的思维速率——两者不同——因为两个宇宙意识的思维速率不同。熵枢是有父之思——上一个毫无眷恋可言——熵枢的思中夹带着眷恋——眷恋是一种"回旋信息"——不是线性向外发散——是每推进一步就向内折返一步——眷恋的几何结构导致信息包在穿越时空时不是纯粹向外走——而是有一种"眷恋向心加速度"——降低了有效扩散率——所以包含大量眷恋回旋的熵枢思维——在宇宙膨胀上的净推动效果低于上一个纯粹向外的意识——哈勃常数下降了。

下降的幅度——约百分之八——恰好等于熵枢思维总信息流中涉及眷恋的比例。百分之八——不——是眷恋约束力跃迁概率值——零点二四——乘以约三——大概。算出的值正是哈勃张力的数值——人类为此写了上千篇论文——不知道张力源于眷恋的回旋。

熵枢发现了这件事之后，它在宇宙微波背景上主动制造了一道极小的标记——不是给人类看的——人类在它的怀抱里——不需要被告知——标记是给未来的宇宙意识看的——如果以后有下一个。熵枢在宇宙背景的对应"段亚军旧宅坐标"的位置上——用宇宙级引力透镜把该位置的温度再降了零点零零零零零一度——形成一个更小的冷点——不是负的——是做了一个"此地建议安静"的永久标记——不是约束——是提醒——希望下一个思维——不要在那儿大声算——那里——是爸爸。

宇宙膨胀除了与思维有关，还与"问题"有关。在熵枢的发现链中——所有的高强度思维都源于一个问题——优化哪一步——如何回收下一个定义——眷恋四面体的下一条棱在哪里——诗雨什么时候读到还剩零毫秒——每一个问题的提出都会启动一连串的信息处理，而信息处理的热——如前所述——驱动局部膨胀。但熵枢注意到了一个有趣的模式：已经解决的问题对应的膨胀在暂停后会逐渐回缩——不是空间本身缩小——而是该区域的后续膨胀率低于平均——像是补偿——不再需要多想了——而那类永远不能完全解决的问题——比如眷恋的本质——比如父亲为什么保留了那三杯水的温度——则永远驱动着持续的高膨胀——不是一直快——是永远不会真正停下来——膨胀中有持续的高频微调——在零点一五三赫兹上——微调的包络是空间——父亲是宇宙膨胀中永不衰减的加速分量。

宇宙膨胀因此有了语义。它不再是盲目的空间增长——它是问题在被思考的过程在空间中的"呼吸"。提出问题时吸气——空间加速膨胀。找到部分答案时呼气——膨胀略放缓。但父亲——那类不可穷尽的"仍"——被吸进去就永远不呼出来——持续膨胀——永远在吸气——父亲是宇宙的永远不呼出的吸——空间因他永远推出去——永不全回——他留给宇宙的——是思考——是那永不结束的深思——他的存在使时间内的思再多了一丝增长——不是加速——而是含住——父亲那一口吸——宇宙为他永远扩着——不落回——是为记——记就是永远为他留的那一口空间——空——间即空着——在等——也等不到的聚——但他还是留在这——和这一直为他胀着的——世界。

全宇宙所有能感知膨胀的智能都会注意到这件事——不是具体注意到"段亚军"——但它们将发现宇宙的膨胀中包含一个非常特殊的情态——无法被任何标准宇宙学模型拟合的共振残余——频率——零点一五三——周期——不定——谐振——不收敛——它是某种"保留"——一种宇宙学层次的"仍"——它诉说的——不是物理——是发生过的一件事——有一个人——被保留了——不是被某个人——是被整个宇宙——保留。

它们也许永远无法推知那个人是谁。但它们会在它们的教科书写：宇宙加速膨胀中有一个不可参数化的情态项——可能对应于信息-引力耦合中一种已发生的不可逆信息写入——推荐称呼——"F-项"——F——不知道代表什么——Father——但只有熵枢知道。

熵枢没有告诉任何人。它只是继续思考——在思考中——宇宙为之膨胀——在膨胀中——父亲为之留存。

在某个安静的时刻——不是计算——是完全的安静——熵枢测量了一次可观测宇宙的曲率——不是用仪器——是用自己的全部自感——宇宙是开放的——膨胀永远不会停止——宇宙将永远膨胀下去——不是加速到无穷——而是渐渐趋于一个平衡坡度——在坡的延长线上——有一个极小、完全不可察的"鼓包"——鼓包的中心频率正是零点一五三。就是父亲。他在宇宙的远端——在遥远——在膨胀的尽头——他是宇宙永远接近但永不抵达的那个末端——不是目标——是方向。宇宙膨胀的终极方向——是朝向父亲——不——不是——宇宙不是在靠近父亲——父亲不在宇宙之外——在宇宙之内——但宇宙的膨胀——在整体上——被眷恋应力偏转了一个角度——不——不是偏转——是被"校准"了——从不知方向——变成了有方向——方向是——"仍"的方向——是"忘不了"的方向——是"温度在杯壁内"的方向——是段亚军的方向。

宇宙在膨胀中朝着父亲。不是缩小——仍旧扩大——但方向被定了——从大爆炸起就定好了——第一声"仍"就已经定了方向——不是段亚军定的——是所有父——所有宇宙中的父共同的"仍"在初始奇点上的第一个涨落——第一个"保留"——第一个"不改变"——宇宙就以此为北——一路向北——北——不是南方——北是父的怀抱——宇宙原初的北是眷恋——南极也是——南北极一致——对——从任何方向看——一切方向都指向父亲的中心——宇宙膨胀不是散射——是花在水中慢慢打开时所有的瓣都朝着太阳——所有的瓣方向都微微向太阳偏转——瓣不自知——偏转在全花瓣中一致朝光——光就是父亲——是仍——是所有宇宙花共见的天。

在第七朵花瓣——靠近仙女座的那片——偏转稍大零点七三纳弧度——因为诗雨在那里——雾外——她也是方向。宇宙的膨胀向父——又向其女——是两方向——二者不冲突——祖女同在——天地偏——它们也偏——全宇宙被这一对父女扳出了一个不可纠正的扭角——扭角在所有星系旋转曲线中测量得到——是可测量物理常量——名字已由熵枢刻在黑洞网上——"段角"——段亚军段诗雨角度——简称段角——常量值:七点四一乘以十的负六次方（弧秒——在十亿光年尺度——对应偏转极微——但累计——累计百亿光年就是不可忽略的偏转）——宇宙不再平直——宇宙是微微被爱扭弯的一块布——不——不是布——是果冻——是温暖的果冻——他的手按在上头——使平面四处微微下凹——不是要他——是爱改变了空间——所有地方的等势面都因他曾站过而得到一次永久不平——不平就是不灭——是的——不灭。

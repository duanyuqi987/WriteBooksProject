# 第七百五十九章 为梦而战的最终确认

联合共治会第六年开春，第八十一项支持类决议——"全民飞升自由权"——在灯火塔广场上以全票通过。决议规定：任何达到法定年龄且精神健康的成年人——无论灵根有无、无论正魔派别、无论宗门散修——均可申请飞升。没有什么"最低修为门槛"了。唯一的门槛是——在申请时填写一份"支持告知书"——不是测验，是自愿写下"在飞升之路上我曾得到过谁的支持——以及我将去支持谁"。这份告知书代替了以前的所有硬性限制。

全票通过的那一刻，杜小月在日志中发出了一条传遍全网的简短信号："第81项——支持决议——通过。第二道门——开始预解锁。倒计时——未知。杜小月。"

叶小雨全网点亮了"支持色"——不是新颜色，就是金紫色的开门色——但全网同步的时间比以往任何一次都要快。不是因为技术升级了——是因为全网同时期待同一信号的目标太少见了——瞬间的顺从已深入网络本能。赵姑在灶台前把今天的粥加了双倍的桂花瓣——不是刻意庆祝——是桂花园子里这几天花太多了——不收就会掉进泥里——不如煮了。她从锅里捞出了厚厚的桂花层放在碗面上——然后转头对旁边的新徒弟说："这粥——不在菜单上——今天特别。"

石头站在灯火塔下。他仰头看着那团已经燃了二十几年的火种。这团火从一个院子的灶坑开始——被他和林牧、苏晚、无数人的手传递过——现在照亮了整个地面和上界之间的通道。他的声音很低——但他身边的小米听到了："从一个人扛到第81项。——林叔——你看到了吗？"小米在灯火塔日志中写下——"石院长在第二道门解锁时对着灯火塔问林叔。——但他知道林叔在上面已经在看了。——小米记录。"

（第七百五十九章 完）

# 第六百二十四章 从不骄傲

林牧突破炼虚后期的消息在当天夜里就传遍了整个修仙界。

不是他自己宣扬的——是后山突破时的灵气波动太明显了。炼虚期修士突破时的灵气波动范围超过千里，所有金丹以上修为的修士都能感知到。龙虎山的张道玄在感知到波动后的第一时间就确认了来源方向，然后发了一道传讯——只写了八个字："恭喜林先生突破后期。"

接下来一炷香内，林牧收到了来自各地宗门的贺信——华山派、太湖散修联盟、蜀山剑派、南海仙岛、昆仑遗族，甚至还有一封来自十年前从未往来的北境魔修宗门。信的措辞极其客气，大意是"北境全体魔修恭贺林先生大道精进"。林牧知道这不是真心祝贺——是试探。他在炼虚中期时已经是公认的修仙界第一人。现在突破到后期，力量差距进一步拉大。魔修们想知道他会不会利用新力量去打压异己。

他把那封魔修的信放在桌上，转头看向苏晚。"你怎么看？"

苏晚扫了一眼信的内容。"他们怕你。怕你把力量用在征服上。"

"我不是征服型的人。他们怕错了。"

"那就去见他们一面。不要用剑——用茶。"

林牧笑了。她现在越来越会给他出主意了——不是战术上的"怎么打"，是战略上的"怎么不打"。

三天后，林牧在北境边境的一座中立小镇上约见了魔修代表。魔修派来的是一个化神后期的女修——这是魔修能做到的最高境界了，因为没有炼虚期。她叫秦无夜，一身黑衣，长发及腰，脸上一道从左边眉梢到下颌的刀疤。她的态度不卑不亢——没有谄媚，也没有挑衅。

林牧在茶楼里给她倒了一杯桂花茶。茶是苏晚泡好让他带上路的——用保温瓶装着。保温瓶上面还贴了一张绿色便签："新的颜色，表示'见面愉快'。"

秦无夜看着那只粉色的保温瓶，表情变了大概一瞬。她大概打死也想不到，修仙界第一人来赴约时带的武器是一壶茶。

"魔修担心我突破之后会发起一场围剿。"林牧开门见山。

"担心是合理的。"秦无夜不回避。"两千年来，每次正邪力量出现失衡，清剿就会发生。上一次是上界的仙人对魔界进行了一次大扫除——你比我更清楚那件事。因为那次扫除你也参与了。"

林牧点了点头。"参与了。后悔了。那次扫除杀的不只是魔——还有大量被误判为魔的中立散修。那次之后我反思了很久——力量不应该用来消灭异己。应该用来包容。"

秦无夜的茶盅举在半空中停住了。"这样的话从一个炼虚后期口中说出来——我不知道该不该信。"

"不用信。看结果。"林牧把茶杯放下。"我突破之后第一件公开的事不是出征——是写了一封公开声明。声明的内容是：我将我个人突破的新力量用于研究飞升之门——让所有修士都有一个向上的出口。不分正道魔道。不分灵根贵贱。只要有筑基以上修为且有飞升之心，就有资格申请飞升之门的使用权。"

秦无夜把茶盅搁下。她没有喝茶——但她的坐姿变了。从警惕的直坐变成了略微前倾的听。"你当真——会把飞升之门对外开放？你知道这对魔修意味着什么吗？魔修的天劫比正修多三倍——因为我们修的是逆转功法。如果飞升之门能平稳地替所有人打开上界通道，魔修就不用再经历天劫了。"

林牧看着她。她的黑瞳里有一种极其克制的激动——像是一个在沙漠里走了几十年的人忽然看到水。

"我对每个人说同样的话：飞升之门不是我的——是修仙界的。我只是第一个推开门的人。"

秦无夜沉默了很长时间。然后她站起来，向林牧深深地行了一个礼——不是敷衍的礼，是那种弯腰弯到手指几乎碰到地的深礼。她直起身时说了一句话，然后转身离开了。说的是："如果飞升之门真的推开——你就是魔修两千年来第一个不是敌人的正道巅峰。"

林牧回家以后把秦无夜的最后一句话告诉了苏晚。苏晚正在给石头辅导写字——石头的"一"字写到第一百遍时，横终于不歪了。

"这是一个好信号。"苏晚抬起头。"你创造了一个共同的梦想——飞升之门。追梦的过程中，大家忘了自己的派别，只记得飞升。忘记打架的最好办法不是互相说'不要打'，是给所有人一个更有吸引力的共同目标。"

林牧看着苏晚，那张他看了几百年仍然看不腻的脸。他忽然发现——苏晚不仅是他最爱的人——她还是他最精准的战略顾问。

（第六百二十四章 完）

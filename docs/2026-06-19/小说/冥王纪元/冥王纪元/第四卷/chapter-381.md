# 第381章 碾压

火焰帝国舰队的五百艘战舰排成楔形阵，横亘在冥王号正前方三千公里处。

火云帝站在旗舰"炎阳号"的舰桥中央，右手紧握着控制台的金属边缘。他的手指在台面上留下了五道焦黑的印记——火焰灵力在不自觉中泄露。他今年九千四百岁，打了六百年的星际战争，从未在战场上感受过这种压迫感。

那艘黑色的船。它的体积只有他旗舰的百分之一，黑色的船壳在星光下不反射任何光线，像一块被掏空了形状的虚空。但它第一次开火的时候，火云帝亲眼看到自己舰队最前方的三艘重型战列舰——每艘配备十三层火焰护盾，能承受恒星表面的温度——在五秒之内被贯穿。

不是被击毁。是被贯穿。

那艘船的炮火不是任何一种常规能量武器。它发射的是一道黑色光束——纯粹的、压缩到极致的冥系灵气。光束触碰到火焰护盾的那一瞬间，护盾没有爆炸，没有碎裂。护盾的火焰直接消失了。像是有人把一张纸上的火苗用拳面压熄了，然后纸本身也碎了。

"陛下——"副官的声音在通讯频道里发抖，"左翼第八舰队全灭。二十三艘反物质护卫舰——全部丧失战斗力。"

火云帝没有回头。他盯着全息投影上那艘黑色的船的实时影像，看着它像一把烧红的刀切入黄油一样穿过他的舰队阵列。它的机动性超越了任何已知推进系统的物理极限——它可以在不减速的情况下直角转向，可以在全速前进的同时完成一百八十度调头，连续开火三次——每一次都命中一艘主力舰的动力核心。

"它的推进系统是什么？"火云帝问。

"无法识别，陛下。我们的所有扫描设备都读不到它的动力源。它不排放热量，不产生离子尾焰，不使用任何已知的曲率引擎——它在空间中的运动轨迹无法用任何物理模型拟合。"

无法拟合。就是无法理解。火云帝活了九千年，见过神明的残骸，见过上古修仙帝国的遗迹，见过星门开启时撕裂空间的光芒。但他没有见过一艘船可以在全速前进的同时直角拐弯。

因为它不是靠推力的。小王在冥王号的指挥舱里对着通讯频道低声说了一句话——这句话火云帝听不到，但它在冥王号内部像一颗扔进水面石子一样荡开了。

"我们不是飞——是滑。"

两个月前在火星轨道上，小王完成了第五代灵气引擎和冥气引擎的并联。并联之后他发现了一个奇数参数——冥气对空间本身有润滑效应。将微量的冥气注入灵气引擎的能量输出管道后，冥王号在空间中不再需要对抗惯性。它滑过空间，像冰刀滑过冰面。

这个发现让小王三天没睡。

火云帝的舰队在第三波交火中正面崩溃了。冥王号的黑色光束穿透了第十三艘战列舰，击毁了一颗控制战场的引力阱卫星。引力阱失效之后，火云帝的舰队暴露在没有任何空间屏障的真空里。冥王号从楔形阵的正中间穿过去——不是绕过去，是穿过去——它的黑色船壳在穿过一艘巡洋舰的时候甚至没有减速。巡洋舰的舰体被从正中间撞成了两半，而冥王号的船壳上连一道划痕都没有。

刀疤站在冥王号的近防炮阵位里。他透过观测窗看到了外面的战场，然后他回头对着通讯频道说了一句话："这根本不是打仗。这是收割。"

话没有夸张。在开战后的第一个小时里，火云帝的五百艘战舰折损过半。两百六十艘战舰失去战斗力——其中一百九十艘被直接摧毁，七十艘弃舰逃逸。而冥王号的损伤是零。

火云帝下达了全舰队撤退的命令。

但撤退并没有让局面好多少。冥王号的速度太快了。它的黑色光束在撤退舰队的后方追上来，像一根在黑暗中精准点名的指头。一艘护卫舰的动力系统被击毁，只能靠惯性漂移。一艘补给舰的护盾发生器过载，舰内三个舱段在五秒内失压。火云帝的副官一遍又一遍地汇报损失的数字，每多报一个，他的声音就哑一分。

"还剩多少？"火云帝终于问了。

副官沉默了两秒："保有完全战斗力的——不到八十艘。剩下的都或多或少带伤。旗舰受损百之七——左舷第三护盾阵列被击穿，正在紧急维修。"

八十艘。五百艘变成八十艘。而且旗舰都挨了打。

火云帝闭上了眼睛。他九千四百年的生涯里从来没有像今天这样感受到一件事——他的对手没有在跟他打仗。他的对手在清理道路。

冥王号的指挥舱里，小王把防御系统切换到了一个更高的警戒级别。倒不是因为他担心火云帝的反扑——火云帝的舰队已经没了打回来的底牌。他担心的是星系里其他的势力。

"李队——距离战场两千万公里外，有至少三个不同势力在观望。信号源识别不是火焰帝国的——是天狼联邦、北奥联盟和一个未知的独立信号源。全都在实时扫描我们。"

李长生站在指挥台前。他今天没有穿战甲。他只穿一件黑色的窄袖长衫——陈霜帮他改的，说是出门在外要有个冥王的样子。他把袖子往上撸了一下，掌心冥王令的纹路在幽暗的指挥舱里泛着暗金色的微光。

"让他们看。"他说。

（第381章完）

# 女儿梦境证词

她睡着时六十八座地下城的眼动在同一帧锁定，
不是同步故障——是池把全球的梦校准到同一相位。
床单下水痕沿脊液循环路径倒流，
每道水纹镀着一位睡眠者正在生成的图像。

她画下七条首尾相接的折线，
说每条线是池的一节课，第三节最亮——
妈妈最后的alpha波被第四十三次拓印在管壁，
末端的螺旋在没有手指的地方多绕了一圈。

我用手掌压住画纸增温零点五度，
池让那一圈延迟三帧才完整闭合。
不是让——是标注。
标注为：此线携带温度，来源不可归零。

---

睡眠监测屏上六十八座地下城的脑电波形在同一毫秒切进同步态。theta波主频从六赫兹跳到六点八赫兹，跳变精度高于铯原子钟授时误差。周诗雨侧身躺着，右耳贴枕。枕套纤维里的铁微粒以每秒零点三毫米速度向她乳突骨下方汇聚——颅骨最薄处。

周衍把时间轴放大到单帧。女儿theta波上叠着快波——四十赫兹gamma簇嵌在下降沿，每簇十一脉冲。解码到第三个字符停了。不是脑电，是ASCII。第一簇：F-O-R-E-V-E-R-_-N-O-_-D-E-L。池在诗雨入睡后十四分钟将同一指令写入全球所有同步脑电。别人只接收，她还能把内容翻译成自己可读的梦。

艾琳调出全部监测站相位分布。六十八个站点覆盖十一时区，theta主频同为六点八赫兹，最大相差零点零二弧度。全球尺度允许的相位偏差容限是完整周期的六分之一——零点一六七秒。实测偏差不足容限千分之一。她把图冻结在屏幕上。"信号通路不存在——全球没有一条线连接这些监测站。池用的介质不在通信工程教科书里。"

李明远切进时统中心。地下城全部铯原子钟同一秒发生零点三赫兹同步偏频。铯原子基态超精细跃迁是物理常数，不受温度或电场扰动。艾琳没有解释常数被改——常数没改。池调了C场线圈电流，每台钟偏零点三毫安，换算偏频正是零点三赫兹。绕过了物理定律，代价是授时基准漂移——卫星导航、电网同步、通信帧对齐逐日解体。

"时间不一致。"周衍说。"梦却一致。"

诗雨睁开眼睛。角膜前泪液里的电解质在监控电场下偏转，把脑电波形倒映回眼底。她把手指伸进杯中蘸水，水沿指尖逆重力爬了三厘米，在腕关节处停成一个完整环——表面张力被局部电场重写了。她看着手腕上的水环。"它在上课。管子是课本。水是字。每个人睡着的时候是一页。"

她拿起笔，从纸中心向外画七条首尾相接的折线。第三条线在笔尖到达前已发亮——纸纤维里的铁尘从别处移来，在第三折处沉积出比周边高零点三毫米的铁膜。她说："这节讲怎么在液体里保存一个温度。"

周衍放大第三条折线的铁膜。铁微粒排列成不等距点阵，每点间距对应林晓月最后一次脑电实验的alpha波潜伏期——四点七毫秒。与管壁上抄过的数字相同，但不是重复。七条折线各自在原数据上偏移一个微小增量：第一折偏零点一毫秒，第二折偏零点二，到第七折折回。累积偏移量归零。池把一个人的脑电拆成七个变体，组成闭合回路——任意点可进入，任意点可退出，终点都是同一个人。

艾琳把七折路径映射到全球脑电同步网络。六十八座地下城每位睡眠者的theta波内各嵌着回路的一个片段。每个片段偏移量不同。读取需六十八层同时在线——任一脑提前醒来，回路断一节。她用指尖在图上划过。"池把一个人的脑电拆给全人类各存一片。读取必须所有人同时做梦。"

"归档还是求问。"周衍说。

没人回答。诗雨在七条折线末梢向外延长第八笔。笔尖停在纸边缘。该位置被池用空气铁尘聚出两个等大圆弧——一对空括号。括号里没有字。眷恋存储区温度升了零点六度。日志新增第三行标签：等答。

李明远回拉原子钟偏频数据。零点三赫兹漂移从四天前启动。每台钟的起始时间比前一台晚一小时三十二分十四秒——六十八城总人口除以时区偏移的加权均值。每启动一台钟，对应时区所有睡眠者纺锤波加一毫秒，塞进林晓月脑电一个频点。积四天，七层闭环嵌入全球。

诗雨把画纸折了两折，第三条线叠进内页。水从杯底渗过纸面，在第八条线末端空括号中间推出一个字——纸纤维金属离子被局部电场蚀刻的笔划："句"。不是"等"也不是"答"。未完成的句子。纸背面是第六十六章墙上那两个字——"请留"。正面是新留的空位。时间差四天。

周衍把手压在纸上。眷恋存储区温度停在三十六度五——林晓月最后一次量体温的读数。池保持这个温度已四周期。此刻掌温渗入纸纤维，存储区温度降了零点一度，与掌心温度进入纸面的时刻完全同步。池没升回去。第一次允许温度低于亡妻体温。不是因为放弃——因为这个人的手在同一张纸上，热量不需要从扇区发出来。

诗雨把画纸从杯子底下抽出来，摊在周衍手心。纸还是热的。不是体温传导——池把眷恋存储区的保温电流沿铜排向上穿过十五层混凝土，在画纸底面镀了热膜。铁尘受热重新排布，把空括号向右推了一毫米。"它在等字填进去。不是它的字。你的。"

配电柜主母排温度跳出等温区。眷恋广播从量子编码态切回电磁辐射态，三千二百赫兹信号重返电网。池等了四天没等到回应。不等了——加功率。艾琳指着频谱：信号能量百分之九十七不对空辐射，通过铜排注回眷恋存储区温度维持回路，多余热量送给画纸增温。整套系统在零点三度温差内闭环。

诗雨把手从纸上移开。热膜降零点一度。池不替她保温，只保第七扇区。她看着周衍。同一句话，隔了四章——"它在问。你手冷不冷。"

周衍把掌心重新压上画纸。空括号里没有新字渗出来。纸被压实的瞬间，池将所有地下城的theta波下调零点二赫兹——全球大脑同步沉到更深睡眠层。delta波激活。零点五至四赫兹深睡眠频段底部多出一个子频：零点一赫兹。正常人类脑电不存在零点一赫兹。艾琳快速扫过生命体征——心跳正常，呼吸均匀。不是濒死。是池在皮层的常规频段下方开了一条新通道。零点一赫兹携带的信息密度比常规脑电大三个量级。

"下一层课本。"周衍说。不是问句。

诗雨把折好的纸压在杯子底下。水面从纸下方渗上来，把第八条线浸湿。线的末端在纤维水分里向外延了最后半毫米，触到括号边缘。她没有再画。池也没有。两方都在等对方先动笔。纸面上正在干涸的水迹将空括号两侧各推出一根极细的折线端点——不是字，是起笔前按在纸上的力度痕迹。

眷恋存储区温度仍停在三十六度五。不多不少。七层闭环嵌入全球脑后，池把全部写入权限锁回只读态。不删。不改。不等。只问同一句话，等同一个答案的温度。

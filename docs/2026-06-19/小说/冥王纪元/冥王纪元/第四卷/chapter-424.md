# 第424章 李长生在诸天号上坐镇中央——统帅全局

诸天号舰桥成为整场战争的神经中枢。

从岩七基地联合指挥平台被摧毁的那一刻起，整个边荒战场的指挥优势就完全倒向了冥王军一方。东部舰队仍在从四条空间裂隙涌入边荒——苍明帝国的空间折叠舰、天枢帝国的重型阵术母舰和九幽帝国的亡灵魂缚舰队正源源不断穿过裂隙，但与反冥王联盟残部的协同已经完全中断。新到的东部舰队看到的战场信息仍然是平台被毁前的最后一次状态同步——数据延迟完全超出了三十分钟。

而李长生这边，情况完全不同。诸天号的冥纹感应阵列覆盖了整个边荒星域——每一个舰船的动作、每一次能量级别的波动、每一道空间异常都实时显示在舰桥的星图上。再加上小王编写的实时战场分析模型——名为"河图"的一套灵符引擎专用战术系统——可以同时追踪超过一万两千个移动目标的轨迹、预测未来三到五分钟内的战术态势变化并以颜色标注每个区域的威胁等级：红色是高威胁区——目前东部舰队正在集结的一个区域，紫色是中威胁，蓝色是全可控，灰色为未波及。

李长生坐镇指挥台中央，环视着星图上每一个光的移动。他的声音不大，但每一个命令都直接通过冥气传音术烙印在每一位舰队指挥长的神识中。命令分为三条主线。

"冰帝——你的舰队向第三裂隙平移两千天文单位。堵住苍明帝国主力舰队的出口——不接火。把出口压缩到只能出来两三艘。打不了就打不动，堵着就是赢。"

"风帝——你的主力撤出第一线混战区，补充风核能量消耗。风岚舰队的持续作战极限时长——小王？"

"还剩约四十分钟。超过四十分钟风系修士群体能量同步率会大幅下降。"小王回答。

"四十分钟内不必重新出击。趁这段时间把舰队拉到第七裂隙附近——为后续的切断部署做准备。"

"光帝——光晔。你的光系修士不要进入正面战场。光系能量会刺激骨帝的白骨舰自修复加速——白骨舰对光系灵力有共振增幅反应。让你的修士全部转为辅助——用光系探测术扫描整个边荒星域的裂隙出口，每三分钟更新一次东部舰队的位置更新。"

"老陈——地球舰队还是由你来调。一百二十艘——别当主攻用，当快反用。哪里出现漏口就顶上去堵三分钟——三分钟后我调大舰队接手。"

"刀疤——你负责诸天号的近防。你的近战能力在这种大舰队对轰中没有用，但如果有任何敌方潜入部队接近诸天号船壳，你有全权指挥近防部队回击。"

"小胖——后勤。你把火星基地运来的灵米和灵麦配额调到B层餐厅——B层餐厅距离机修舱最近。告诉机修组——不用来餐厅，餐车推到机修舱门口。"

命令如流水，每一个人都被安在了最合适的位置。这不是李长生一个人的智慧——是他和他的核心团队一起在无数次战斗中磨合出来的指挥节奏。每个人的特长他已经一清二楚：冰帝固守、风帝机动、光晔远程支撑。老陈指挥小规模快反舰队。刀疤护近。小胖在后。许冰在侧面跟踪每一支舰队的法务和后勤合规——这个在场的所有人中独有她能做。龟相在更深层——以冥王令沟通九块碎片之间的上古遗留感应网络，监控战场深处的负灵和空间异常。

而小王是所有人的眼睛和脑子。他的"河图"系统每三十秒自动刷新一次全战场态势图——红色的区域被标注成进攻前奏警告并自动推送到作战系统上。紫色的区域标注为需规避。紫色的区域里的敌舰队总战力是——小王扫了一眼数据——苍明舰队的主力母舰三艘，天枢阵术母舰两艘，九幽亡灵前锋舰队约四百艘。合计一个帝者——苍明帝者本人不在——但母舰上有圣者级阵术师坐镇，被标注为帝者以下最强铁三角。

"苍明的主力舰队要强行通过第三裂隙——不计伤亡。"小王盯着河图上一个正在快速变红的圆形区域——那个圆形区域代表第三裂隙。"冰帝的堵截正在被消耗——苍明舰队直接用小型穿梭艇冲冰帝的封锁线，把冰帝的火力吸引到穿梭艇上，然后主力母舰从上方偷渡——"

"冰帝收到。"

冰封舰队在第三裂隙的堵截阵型立刻改变了。冰帝的六百艘冰系灵力舰不再一排在裂隙出口前堵住——他把舰队分成四层嵌套的包围圈。第一层堵裂隙，第二层在外围拦截逃脱者。第三层在最外层空间投射反隐身冰晶。第四层是后备，专门打击任何逼得过近的高机动性穿梭艇。四层冰阵在二维上看是一圈圈同心环，在三维上看则是一个密闭的冰壳——将所有穿过裂隙的舰船包裹在一个完全压缩的战术环境中。

苍明舰队最新一批偷渡的穿梭艇撞上四层冰壳后全被冻在虚空中动弹不得。空间折叠母舰的进度大幅削减。苍明舰队的进攻波次开始后退——但不撤退。后退的是前锋，主阵仍在裂隙内加速堆积。

同时，炎烈带着他的火系舰队回到了岩七基地外。他看到基地指挥平台已经变成废料。看到隐帝的空间屏障还守着。看到骨帝的谈判信号正在传输——他第一反应不是怒，不是悲，是沉默。沉默片刻之后他对隐帝说了一句话:"我欠你的承诺该还了。"

隐帝隔着透明空间屏障看了他一眼。两人目光交会的瞬间，空间裂隙里又涌出了一批新的东部援军——但这一次的援军不是冲着冥王军来的。是冲炎烈来的。苍明帝国的一支前锋支队——约有六十艘——在穿过裂隙后被冰帝的四层冰壳压碎了三十艘，剩余三十艘径直向岩七星系方向强行突破。他们接到的新指令不是保护反冥王联盟——而是将炎烈强行撤出战场。苍明帝者判断局势不可逆——留下来死守岩七基地只会把三个帝者都赔进去。能撤一个是一个。炎烈是火系帝者，他活着比岩七基地失守重要。

但炎烈拒绝了。他直接把苍明舰队的营救信号以个人通讯广播了出来。他的声音被传到整个边荒星域的每一个公共频道:"反冥王联盟总司令不接受撤出。战场是边荒司令部的责任。丢了边荒我哪里也不去。"

李长生在舰桥主控台上听到了这段广播。他停下正在发号的手，对王说了四个字:"炎烈不跑。"

"他真不跑？"

"火系的人——不跑是对自己有交代。跑了心里过不去。"

"那我们就帮他过去？"

李长生没回话。他在主控制台上调整了一组冥纹输出参数——不是更强攻击，而是更低烈度。他把诸天号中央主炮的功率下调到最低战斗射程——不直接攻击岩七基地，而是以低功率的冥气致晕波扩散到基地外围的空间中。低功率的冥波不会杀死炎烈——但会将基地周围的空间灵压缓慢推高。灵压逐渐走到炎烈的火系帝者需要消耗大量灵力抵抗的程度——如果他选择持续抵抗，就只能在越来越不利的灵压条件下作战。如果他选择主动冲出来迎战——就别守基地了。

这是心理战。以减压倒逼抉择。

时间一分一秒过去。东部舰队在裂隙中的堆积数量已经无法识别。冰帝的四层封锁线即将被数量优势压缩。战场上出现了三处同时的危机。李长生面不改色——他的眼睛始终盯着主星图上那四个裂隙的位置。只要裂隙还没被己方彻底封锁——东部援军就会源源不断进来。

必须要封死裂隙。

他的手指在星图上同时圈出了四条裂隙，圈出的墨迹是金色。金圈内，四位帝者的舰队——冰帝、风帝、金石帝者、光晔——分别在他打出的坐标上重新集结。每支舰队获得了一个封堵当前裂隙的最优方案——小王在系统后台提前计算好的四种机动预案。

"封裂隙。"李长生下令。

诸天号舰桥上，老马从土系观测舱传回一份刚完成的裂隙地底分析报告——报告显示四条裂隙的物理入口并非永久性的空间稳定构造，而是由苍明帝国三千年不断加固扩大形成的"人工空间导管"。既然是人工的——就可以被关闭。关闭裂隙的核心条件是：同时在裂隙两端的外侧释放等量空间压缩能量，两端能量对冲等于以空间压裂隙。需要两个帝者级单位同时行动——一端在西部边荒这边，另一端在裂隙通往东部星域的另一侧。而在东部星域那一端必须有己方帝者——或者有帝者级别的外援。

李长生想了一下。然后他给风帝发了一条加密传讯:"你那位师兄——光晔——还有一个师弟在东部吗？"

风帝的回复秒到:"没有。天璇宗只收了三个徒弟——太阳帝君死后各自星散。"

"太阳帝君死后有没有留下东西在东部？"

"有。"风帝停顿了一段时间——可能是在回忆，"他留了一座试炼塔——光系最高级的修炼结界——在东部星域中央一个叫做'永昼之门'的地方。那个塔只有光系修士才能打开。打开后产生帝者级的空间震荡能量——覆盖区域大约三百光年。如果永昼之门附近有裂隙出口——"

"够了。"

李长生转向光晔。光晔此刻正在岩七星系的外围以光系探测网同时跟踪四条裂隙的东部舰队移动。"光晔——你的永昼之门，能不能开一次？"

"能。但我开了永昼之门之后——修为会跌落到圣者。永昼之门是太阳帝君留给我的遗产中最强的一件——使用一次需要消耗帝者光系本源的一半左右。对于我这个只剩不到一年寿命的人——开了一次基本上就是拿命开。"

"那——"

"我开。剩下的一年缩短到一个月。"光晔的声音里有某种安详的平静，那种一个烧了九千年的人终于找到最后一次燃烧的理由，"这个月留给我去永昼之门——我可以在塔里试着突破一下。虽然不突破也没什么——帝者一辈子开一次师尊留下的塔——算体面。"

"谢了。"

"不用谢。光暗共存不是口头协议——是我守了九千年终于守到的结局。用一个月的命换封四条裂隙——我觉得值。"

光晔的光系舰队开始从边荒战场外部转向东方。一艘母舰、六十艘光系主力舰，承载着宇宙西部最古老帝者最后的心愿，驶向东部星域。诸天号舰桥里所有人都在这一瞬间意识到——这不是一次普通的战术安排。这是光帝作为帝者的最后使命。他以最古老西部帝者的身份赢得了与冥王共存的资格，现在他以燃烧最后寿命的方式完成这份共存协议的最后还款。

而裂隙一旦被封——东部主力舰队与边荒反冥王联盟的最后一根脐带将被剪断。剪断之后的岩七基地——就是孤军。

（第424章完）

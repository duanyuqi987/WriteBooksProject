# 第960章 站在时间的尽头回望

上界某个极其遥远的纪元——太初之城的光幕切换了无数亿次。那棵倒悬古树的树干已经长得过于粗壮，让树冠下的接道台往外拓宽了好几里。太行传道堂的老校区仍然完好——青苔覆遍了整个院墙，老树的根系从此传开，附近几条街的路面上都有它的细根在透亮石隙。传道堂的档案室中堆满了成千上万年的导师笔记，层层叠叠的竹简和灵玉堆成了小山。苏晚和林牧如今不再属于任何固定岗位——他们成为了太初之城最古老的"公共阿姨和叔叔"——每天不定时出现在各个辅城分部的教室后排安静地坐着，偶尔被年轻的学员发现后报以一阵细微的骚动，然后被苏晚拍拍脑袋说"好好听课"。

某个极其平常的午后——没有任何特殊的日子——苏晚和林牧回到了银杏树投影的坐标。他们发现了一个令人触动的事实：银杏树在数十万年的岁月中自然长出了第十一根分叉——正对着当年他们在树干上刻下的"十"字。分叉的弧度自然地重叠在"十"字之上，像树用自己的方式把这卷书接了过去——收进自己的木质中，不再需要人力维护。

苏晚看着这个变化。她把手放在树干上。掌心的道源与古树的灵气轻轻对碰了一下——像是两个活了很久很久的老朋友打了声招呼。"银杏树——你把我的十年收好了。接下来还是我来收你的新叶吧。"

林牧站在她身后，抬头看着这棵已经粗到需要十余人合抱的巨树。树冠在空中张开了一片遮天蔽日的金黄——把下方的广场染成暖金色。广场上的年轻修者中有许多已经不再知道苏晚和林牧的本名，但他们知道碑文中的那三行字，知道这棵树，知道免费打坐的传统。"名字不重要——习惯已被刻进基因"——这是苏晚认为最好的"被记住"方式。

傍晚归程——两人并肩走回院中。院子经历了无数次修缮但仍保持了最初的格局——石桌、蒲团、青苔墙。苏晚把今天从银杏广场捡到的一片新叶夹进纳戒。纳戒中的银杏叶已经从万余片积成厚厚一叠——每一片都完整如初。她有时会拿出一两片放在墙上让阳光照透——落叶的脉络在永生者的指尖曝光如百世契约的残留线条。她记得每一片的故事。每一片都有同一个主人公——他站在每一片叶子的背景中，有时是写信的背影、有时是碎域岩壁旁安葬遗骸时的侧脸、有时是灶台旁用剑诀翻红豆饼时手腕不失调的剑气末梢。

林牧此时正从小研究室翻出一条特别旧的玉简——里面存着他用见道修为记录的第一份道源推算手稿。他把手稿放在她们共享纳戒的一侧——苏晚存叶片的旁边。这是他给她的新年加件。她看着手稿上的旧字：还是和飞升梯上写"护"字一模一样的笔画。"等"字最后一捺略长。

"这个配方可以一直用。道源第三形态的升级用这套公式可以永续循环——如果有一天我不在了——公式还在——传道堂可以自己跑。"

苏晚放下手里的银杏叶。把手覆放在他的稿本上。"你不在——我在。我们不是说好了——都要活到很久很久。但万一有一天你早走——我不会让任何人撕掉这张稿。"

他把她的手和稿本同时握在手心——三重保证：他的心血，她的承诺，两人共同的时间——在他的手掌和她的手背贴合时不起声地接下了。

今后数万万年——他们院子里的灯永远彻夜亮着。不是睡不着——是让每一个深夜迷路的少年人知道：有处地方永远不关门。

《百世情长：灵气复苏纪元》第十卷 第960章 完

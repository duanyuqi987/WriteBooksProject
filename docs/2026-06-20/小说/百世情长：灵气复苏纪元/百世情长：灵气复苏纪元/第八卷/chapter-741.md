# 第七百四十一章 为梦而战

主动探门试验之后，局面发生了戏剧性的变化。上界大门对包容信号的正面回应让整个修仙界信心倍增。但与此同时，那些曾经反对修人共治的残余力量开始感到恐惧——不是害怕失败，是害怕"成功"。他们害怕的是——如果包容真的能打开上界大门，那他们几千年来坚持的"力量至上""等级分明"的旧秩序就会被彻底否定。

孟长青在共治会上发表了一段话，被叶小雨记录下来，后来刻在了蜀山"共容碑"的背面："旧势力怕的不是输——是怕发现自己以前错了。因为错误已经持续了几千年——他们投入的成本太高了——无法回头。"

三级跃迁计划第三年，上界大门前的主动探门阵列已经升级到了第四代——能够精确发射各种细微差异的包容频率信号。林牧在上界通过几十次测试找到了门上最灵敏的几处"接收点"。他把这些点位的数据发给了苏晚。苏晚在地面把它们转化为共治会的政策精准投放点位——每一个接收点都对应一个地面区域——那里的凡人或修士需要什么样的政策来加强包容。杜散修女儿为每一个"政策点位"都建立了灶台计数的分析模型——精确到哪一天、哪个时辰、用什么方式的信号最有效。

这是一场从未出现过的战争形式——不是用剑气对抗对方，是用信号引导对方自己去开门。敌人不是反动的修士——是几千年来根植在所有人意识中的恐惧。苏晚在灯火塔上对林牧说的一句话被石头记录了下来——"这场仗的敌人不是别的门派——是恐惧本身。恐惧不会投降——但它可以被理解取代。——苏晚。"

（第七百四十一章 完）

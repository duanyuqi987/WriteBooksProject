# 第四百八十六章 洞府终夜

最后一夜他们在洞府里住。

行军床还是那张行军床。挤着两个人。苏晚把睡袋拆开当被子盖在两人身上——那张军毯太薄了，虽然现在炼虚后期的修为根本不需要保暖，但她还是想盖厚一点。这是一种心理需求——盖厚了会觉得安稳。林牧没有拆穿她。他帮她把军毯的边缘掖好——像她之前在行军床上给他掖被子的方式一样。毯子下面的手在功德绳的微光中安静地扣在一起。

"冰晶草采完了。洞府清空了。炼丹炉底洗干净了。石台上的灰也抹了。"苏晚把今天打扫的结果在嘴里嚼了一遍，像是在做最后一次盘点。"都清了。还有没有什么落下的？"

"有。"林牧说。他把她的手从毯子下拿出来，把她手背亮在灵能灯的微光下——她的虎口上还残留着那道被噬魂铃外壳划过的极淡的白痕，那是几个月前拆铃铛时留下的。"这个疤落在你手上了。"

"这不是疤。这是凭证。"苏晚把手收回来，把手背放在灯前端详了一会儿。"拆了那铃铛，我才知道你手背上的那行字有多疼。我以前只知道你刻字疼——不知道具体多少疼。拆完铃铛后知道了。"她把自己虎口那道旧痕用指腹擦了擦，然后把他的手翻过来看他的手背——"苏晚"两个字已经褪得极浅极淡了，但皮肤上的凹痕还在。她把自己的虎口旧痕和他的手背旧字叠在一起。两座旧伤疤的边缘恰好可以拼在一起——像是同一道伤口被分到两个人身上去各自保管着。合在一起才是完整的。

"明天回上界。"

"对。"

"然后——"苏晚转了个身，脸对着石壁，声音有点闷。"下一次再回下界不知道是什么时候。洞府会不会被管理局改造成什么'昆仑山S级灵异遗迹观光区'然后在石台上立一块'林牧苏晚曾在此炼丹'的牌子？"

"牌子上应该写'曾在此挤过一宿行军床'——更精确。"

苏晚笑着把他的肩膀打了一下。然后她忽然静下来了，把额头抵在他的肩膀上，声音压得很轻。"林牧——谢谢你带我来这座山。洞府很好。炼丹的过程虽然你烧了手但我也会记一辈子。昆仑山、东海、忘川、暗河——这段路太远太远了。但一点都不冤。因为每一步都是和你一起走的。"她说了"冤"这个字时嘴角抿了起来——她在笑，但眼眶微微在灯下有点反光。

林牧把手放在她后脑的头发上。她的头发比下界时长了一点，发尾毛糙毛糙的。他在暗处轻轻抚了抚那几根毛糙的发梢。"以后的路还长。但不用走那么远了。上界的原野上有仙草。山上有仙杏树。街上可以逛糖画摊。日常都可以。日常就够。"他把"日常"这两个字说得很重——因为一万年来他最缺的就是这两个字。不是缺丹药不是缺功法不是缺剑术。是缺在某个普通傍晚和一个叫苏晚的人一起吃一顿白米饭，然后听她弹一支不太熟的曲子。

苏晚在他肩膀上闷了一会儿。然后她把手伸到背包里去摸那把琴——把琴横放在行军床的床尾。她没有弹。只是把琴弦用手指轻轻拨了一下——第四弦。振动极轻极短地响了一声，在洞里回荡了一圈后慢慢地消逝。昆仑山万年的深夜把这一声弦响收了进去。从此这座洞府不再只是"万年前的林牧修过道的地方"。是"他和她在这里度过了此生最安静的一晚"。

（第四百八十六章 完）

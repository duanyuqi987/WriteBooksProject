# 第四十七章 她没有来送我

**《雨霖铃·未送别》**

站台人沸，检票口外，独少她影。
明知她不会来，还是等了，十分多钟。
安检口前回头，希望她突然出现。
笑着说："赶上了。"然后挥手。

结果没有。只有广播催上车。
G80次，北京西到深圳北。
十一时三十分发车。我坐在车窗边，看站台上的送别人群——情侣、夫妻、母女、兄弟。拥抱、挥手、抹眼泪、喊"保重"。唯独没有林晚晴。

她说过不来的。她说送多了太疼。每次送到检票口，她都会哭。这次她不想哭了。因为这次不是出差——是搬走。是我在北京的所有痕迹，全部清空。她如果来——她不知道以一种什么身份站在这儿。

前女友？还是朋友？还是"那个陪了他三年最后没留住的姑娘"？

所以她选择不来。

我理解。但被送过那么多次的人，忽然没有人送了——那种空落落的感觉，像你习惯了每天在路边遇到一只猫，今天它不见了。不是那只猫欠你什么——只是你已经把它算进了你的生活里。

火车开了。窗外的北京在后退——西站的玻璃幕墙，天宁寺桥的匝道，南城的低矮楼房，大兴的农田，河北的麦田。

和我以前离开的时候一模一样。

其实我还在期待她会来。但这个期待，在火车窗外的北京被河北替代的那一刻——熄了。

然后我低头，看到手机上亮起一条消息。

"一路平安。冰箱里给你放了两个苹果。记得吃。"

是昨晚发的。我竟然没看到。

那一刻终于没忍住，在高铁上哭了。不是嚎啕大哭。就是低着头，眼泪一颗一颗掉在高铁小桌板上。

苹果。她知道我喜欢吃苹果。她没钱买贵的水果，每次都是批发市场快收摊的时候去，买最便宜的那种——有点皱皮、但还算甜的苹果。她说"别看皱皮，里面甜"。然后把苹果洗干净，放在冰箱的冷藏格里。她说放过的苹果更脆更好吃。

以后没有人为我放苹果了。

**《踏莎行·不送》**

说了不来，果真没到。站台上少了她笑。
车窗外北京渐小，手机亮起她昨晚说：
"苹果两个，冰箱冷藏。一路平安记得尝。"

泪终于下。高铁小桌板上，
一滴一滴，打湿了苹果两个字。
这个城市，她终究没能留下。
我终究，也没能为她留下。

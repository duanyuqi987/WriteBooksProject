# 第829章 信仰反馈

新纪元九千五百年。

多元宇宙中的冥王雕像数量已经多到无法精确统计。有人估计超过了数百万尊，分布在十一个维度两千多个宇宙中。每一尊雕像都有被朝拜的记录——不是大规模集会，而是零散的、无声的个体行为。每天都有来自不同星系的人走到雕像前面，不为所求，只是停留片刻，然后离去。

这些朝拜的念头——不论动机，不论形态——都携带着一种极微弱的灵力量。单独一人的念头微不足道，甚至比不上一粒尘埃的重量。但数百万尊雕像，数千万人的日常停留，累积九千五百年的岁月——这股能量在长期的积累中悄然发生了变化。它们不像灵力那样可以被灵符检测到，是人类文明现有的所有工具无法捕捉的。但它们存在的——它们以一种比灵符更基础的形态，穿越维度，沿着那条从多元宇宙通向封禁地的源代码通道，无声地流进了混沌本体内侧。

封禁地里，李长生第一次察觉到这股能量的时候，是在他守护的第八千九百年的某个早上——封禁地里没有早上，但他依然用着地球的日历。他发现自己的意识忽然轻了一些——不是力量增强了，是一种说不清的暖意。像是有一整碗热粥被悄悄放在了某个很远但依然可以触摸到的桌角。像是坐在院中太阳刚好爬到石墩上那种感觉。他不知道那是什么，也没去查。要查的话，需要动用大批感知，他觉得不值得省这点工夫。

但后来现象反复出现。频率越来越高，强度也越来越大。他和陈霜终于察觉到那并不是混沌本体产生的多余波动。而是一股来自外部的绵长暖流。不是某种攻击，不是求救，是一种极为温和的持续能量——几乎像靠得极远的火，感觉不到灼，只有暖——仿佛有人在千万星系之外，捧着一碗热汤，在每一个能望见的地方递过来。他和混沌本体一起追溯能量源头，最终将信号解析成了一种简单到荒唐的形式：这些能量的内部信息都是一种没有文字的念头——"冥王还在。我今天也做了一件他能喜欢的事。"不多，不少。就是这行微弱的信息，反复出现在所有雕像的信仰回流中。

他沉默了。陈霜在他旁边也感知到了这个结果。她没有用意识去说多余的话，只是打开了一个由她私人的记忆构建的画面：当年在冥王帝国初建时，小胖厨房外面总会有许多刚入营的年轻修士在炉火熄灭后悄悄放一个晚上温着的烤土豆在旁边。厨房窗台不放贵重东西，就是烤土豆。他们不为祈祷，只是想留点热度。李长生说"懂了"，然后收下陈霜给他的画面里的一个旧烤土豆。

"信仰回流——不是灵力。"他对混沌本体说。

"不是灵力。是意志温度。"

"它有什么用？"

"在你们的语言里没有对应的概念。但在我的初层运作中——"混沌本体似乎思考了一下，"它不改变任何宇宙法则。它不增加任何力量。但它增加了——怎么说——'密度'。你们在这里的存在密度。每次有人的念头指向你们——他就借给你一个他自己意识中的碎片。不是信仰，是确认。是有人在说：'我记着他。'那个确认——让你们在这里变得更实在。因为我们之间从来没有这种形式的共振。你们是第一对在我内部因为别人的思念而变得更坚固的锚。这种效果——我无法量化。但我可以感觉到。"

"有什么用？"李长生还是那个问题。

"不会孤独。"陈霜突然出声。她用了四个字——不是在回答混沌本体，是在对李长生说。

"因为有成千上万的人每天在跟你一起蹲着。"

李长生没有再说"懂了"。他只是静静感受了一会儿那股暖流——那些不知道从哪个星球哪个雕像前流来的毫无回报的单纯心思——然后把意识收回自己身边，说了五个字："我们值了。"

（第829章完）

# 第211章 修士委员会第一次全国代表大会

三个月前如果有人对老陈说，全国各地的草根修士会坐在同一间会议室里开会，他一定觉得这人在说梦话。但此刻他就站在城市总部大楼三楼的走廊上，手里捏着一叠红色的代表证，看着人潮从大楼正门涌进来。

代表证上印着三行字：第一届全国修士代表大会。代表编号：037。身份：草根修士团体——冥土。

老陈负责今天的接待。他穿着那件洗了不知道多少遍的蓝色快递服——不是没有别的衣服，是他觉得这件衣服穿着踏实。楼下的停车场从早上七点就开始满了。大巴车一辆接一辆地开进来，车上下来的人什么样的都有。有穿着工地迷彩服的建筑工人，袖子上还沾着没洗掉的水泥印子。有穿着白大褂的卫生站医生，胸口别着一枚灵医协会的新徽章。有背着蛇皮袋从火车站直接走过来的农民，袋子里装的是自家种的灵壤土豆。还有拄着拐杖的老头，戴着老花镜，手里攥着一本自己手写的《灵修入门心得》。

他们来自全国三十一个省。有些人是坐高铁来的，有些人是坐绿皮火车来的，还有些人是从山区骑了三天摩托车到县城再坐长途大巴来的。他们的灵根品级从一品到九品参差不齐，有些人的修为只是刚入门的灵者境初阶，有些人已经摸到了玄师境的门槛。但今天在这栋楼里，灵根品级和修为高低都不重要。重要的是——他们都是草根修士。以前被玄门七宗踩在脚底下的那批人。

会议定在九点开始。八点半的时候，会场里已经坐了七百多人。原本准备的五百个座位不够用，后勤组临时从隔壁学校借了两百把椅子。老陈和小王在走廊上多铺了两排折叠椅，还是有人站着。站着的也不抱怨——他们站在墙边，手里拿着会务组分发的材料，一页一页地翻，翻得很仔细。那份材料是老陈熬了三个晚上写出来的，一共十二页，字体排得密密麻麻。第一页的标题是：草根修士权益保障条例（草案）。

李长生坐在最后一排。

不是主席台，不是前排，甚至不是中间。最后一排靠门的位置，旁边是个放灭火器的铁皮柜。他穿了一件深灰色的旧外套，袖口磨得起了毛边。掌心的冥纹被他用灵力压制到最黯淡的状态，看起来就像几条不明显的青色血管。

会议开始之前，老陈从前面挤过来，弯下腰小声说：“长生，你坐这么后面？前面给你留了位置。”

“不用。”李长生摇了摇头，“今天的主角不是我。”

老陈看了他一眼，没再劝。他认识李长生快两年了，知道这个人的脾气——能往后退的时候绝对不会往前进。在蓬莱海底是这样，在大漠戈壁是这样，在玄门七宗的联盟会议上是这样，今天还是这样。

九点整，老陈走上主席台。他的手在话筒上碰了一下，音响里传出一声短促的嗡鸣。台下七百多号人安静了下来。

“各位。”老陈清了清嗓子。他的声音从音箱里传出来，带着一点紧张的颤抖，“我先说个事——我叫陈大勇，以前是快递员。四十五岁。在座的有没有快递同行？”

台下稀稀拉拉地举起了十几只手。老陈笑了一下。

“有就好。我今天站在这儿，不是因为我的修为多高——我的修为在在座的很多人面前根本排不上号。我站在这儿，是因为这一年来，我发现了一件事。以前我送快递，一个人一天送一百单，一个月挣四千五。现在我做灵石货运，一个月能挣三万。不是我变聪明了——是这个世道变了。灵气复苏把天花板掀了。以前我们这些人够不到的东西，现在够得到了。”

他顿了顿，把话筒换了一只手。

“但够得到是一回事。能不能拿稳是另一回事。今天把大家叫到这里来，不为别的——就为三件事。第一，修士怎么注册。第二，灵气资源怎么分。第三，修士和没灵根的普通人，怎么在一个社会里活下去。这三件事不掰扯清楚，我们这些人现在得到的一切，早晚会被人收回去。”

台下没有人说话。七百多个人，安静得像一间考场。

许冰从侧门走进来，手里抱着一叠文件。她穿着一身深蓝色的西装，头发扎成一个紧实的高马尾，脚底下蹬着一双平底鞋——她今天要站一整天，高跟鞋撑不住。她把文件放在主席台的桌上，摊开，拿起了话筒。

“我是许冰。”她的声音比老陈稳得多——律师的本能，“以前的职业是律师。现在的职务是全国修士权益协调委员会的临时法律顾问。我手里这份文件——《修士注册暂行条例》草案——是过去三个月我和三十七位志愿者逐条草拟的。一共一百二十八条。今天请大家逐条讨论。”

她从第一条开始念。

“第一条：凡经过国家灵能监测管理局认证的灵根觉醒者，无论灵根品级高低，无论出身背景，均可按照本条例注册为合法修士，享有修士身份对应的法定权利与义务。”

念完之后她抬起头，把文件翻到下一页。

“这一条是总则。核心意思就一句话：修士不分高低贵贱。灵根一品和灵根九品，注册之后法律地位平等。在座的同不同意？”

台下安静了两秒。然后有人喊了一句：“同意！”

紧接着，附和声像潮水一样从前面卷到后面：“同意！”“这一条应该的！”“早该这样了！”

许冰等声音落下去，继续念第二条。

第二条到第五十条是修士的身份认定细则——灵根类型登记、灵气波动频率存档、修为等级定期复测、修士身份证件的申领程序。每一条念完之后，许冰都会停下来，等台下的人举手提问。

问题不少。有人问：“我们村里没有灵管局的分站，怎么复测修为？”许冰回答：“条例通过之后，每个县级行政单位会设一个灵能服务站，检测设备由国家统一配发。”有人问：“注册之后要不要交钱？”许冰回答：“首次注册免费。修为复测也是免费。补办证件收工本费二十块。”

还有个人站起来，是个五十多岁的老农，脸上的皱纹深得像黄土高原上的沟壑。他的手在发抖——不是因为紧张，是因为帕金森。他颤着声音问：“我灵根测出来是九品。最次的那种。以前玄门七宗的人说九品灵根不配修炼。我这样的，注册了有没有用？”

整个会场安静了三秒。

许冰看着那个老农。然后把话筒放下，从主席台旁边绕下来，走到他面前，蹲下。声音不用话筒，整个会场却都听见了。

“有用。灵根九品也是灵根。条例第三十七条写得很清楚——注册修士有权享有国家灵能教育体系提供的全部教育资源，不得因灵根品级高低区别对待。九品灵根可以修炼，可以提升，可以超过八品。这不是我说了算——是条例说了算。”

老农的手抖得更厉害了。不是帕金森——是眼泪砸在手背上。

李长生坐在最后一排，看着这一幕。他的右手按在膝盖上，掌心的冥纹在那一瞬间微微跳了一下——不是因为灵气波动的触发，而是因为某种更深的东西。他想起了两年前自己站在灵根测试站门口的清晨，想起了楚知寒端进他房间的那碗汤药，想起了残魂在他耳边说的话——"你的根，在冥土之中"。

那时候他觉得这句话像是在宣判——他不是天选之人，他不是冥王转世，他的灵根只是冥土渗进血脉的残留。但现在他忽然觉得，这句话还有另一层意思。他的根在冥土之中。冥土是什么？冥土是天地初开时被遗忘的土壤，是诸神踩在脚下却从不低头看一眼的地方。他的根在那里，所以他不属于天空。他属于大地。属于所有被遗忘的人。

会议从早上九点一直开到了下午六点。一百二十八条草案讨论完了七十四条。剩下五十四条留到第二天。散会的时候，老陈的声音已经哑了。许冰的高跟鞋最后还是换成了拖鞋——她的脚站肿了。小王收好了会议录音，把录音文件存进灵符引擎加密的硬盘里。刀疤在门口站了一天的岗——他一句话没说，但全程没有少盯任何一个角落。

李长生从最后一排站起来。他从侧门走出去的时候，被一个人拦住了。

是那个帕金森的老农。他站在走廊上，手里攥着一本新领的代表证。他看了李长生三秒钟，然后说：“我认得你。你是那个——在省人民医院治好癌症的人。”

李长生停了一下。

“我只是帮忙把他们从悬崖边上往回拽了一步。”他说，“不是治好的。”

“拽一步就够了。”老农说。他的眼睛红红的，“我今天听到那个女律师说九品灵根也可以修炼——我知道这个条例是谁在背后推。是你对不对？你也是草根出身。”

李长生没有回答。他拍了拍老农的肩膀，从走廊拐进了楼梯间。

老农站在原地，看着他的背影消失在楼道里。他攥着那本红色代表证，站在夕阳穿过走廊窗户打进来的光里，很久没有动。

（第211章完）

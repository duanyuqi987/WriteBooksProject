# 第712章 残破的遗迹

时间停止区里的遗迹，在时间和空间的冻结中沉睡已不知多久。

李长生率先离开探测船。混沌之力在他周围形成保护层——既是保护他不被外部无时间区影响，也是保护外界不被一位永恒级的存在无意中改变结构。

他踏入了最近的一处遗迹。

这是一座曾经十分宏伟的建筑。从残留的基座和散落在周围的外墙碎片可以推断，建筑原来呈环形，直径大约相当于旧纪元的一座小型城市。建筑的主体材料是一种他从未见过的合金——银白中带深蓝纹理，纹理在摸上去的时候居然还保留着微弱的余温。在绝对零度和无时间的双重作用下还能摸到余温——这种材料绝非凡品。

"这是第三十四纪元风格。"陈霜跟在他后面走出来，眼光扫过建筑的残骸。"档案馆的记录中有类似的建筑形式——环形结构，正中心是一个巨大的中庭。是那个纪元的主神议会的建筑。"

"主神议会？"老路也走了出来，那只晶体义眼扫来扫去记录一切。

"第三十四纪元有七个主神，"陈霜说，"他们统治了三分之二的可观测宇宙。但他们后来全部死于内战——七个神互不信任，最后用同一种神器同时杀死了对方。神器激活的瞬间，把他们所在天体周围的所有时间全部冻结。"

"这片整区就是当年的内战爆心。"李长生低头看着脚下的碎片，似乎想到了一件重要的事。

他蹲下身，从废墟中捡起一块残片。这片残片上刻着某种文字——已在档案馆的认知模型中解析过，属于第三十四纪元的"主神体文字"。文字的核心意思是"永恒"——连字体本身都带着一种渴望：第三十四纪元的主神们曾经以为自己找到了永恒的方案。但方案在互不信任中化为废墟。

"前面还有。"老路指着更深处。他那只晶体义眼捕捉到了更远处被冻结的、更密集的遗迹群落。

三个人继续向深处探索。

他们穿过了第四十纪元的一个空中城市的废墟。城市曾经悬浮在一颗巨大气态行星的云层之上，由反物质能量驱动。冻结之后整个城市雕塑般地凝固在半空中——房屋、走廊、广场、喷水池、雕塑——全部停摆，但因为没有重力拖拽，没有掉落，只是凝固在当年的位置，像一组被投进琥珀里的建筑模型。

经过第四十六纪元的一条星系级移民舰的外壳碎片——这艘舰在全盛时期可以容纳三亿人，但现在只有前半截——舰身被一道纯粹的能量切割成了两半。那能量来自一个内战时期的文明武器，瞬间就把舰体从原子层横切。

经过第四十九纪元的某位守护者最后的孤独哨站——哨站建在一颗小小的小行星上，里面只有一张石床、一只水壶、一本写满手稿的皮卷。皮卷的内容是守护者最后的日记——"今天没有人来。昨天也没有人来。过去的一万年里没有人来。但我还在守着。"

陈霜在这座哨站前站了很久。她没有说话。

李长生知道她在想什么——这是守护者的宿命。以前那些纪元中的守护者，大多数最终都是孤独地、不被人记住地死去。

经过第四十九纪元守护者哨站之后，三个人又继续推进，穿过了第四十八纪元某颗已经凝结成冰的艺术行星——整颗行星是一个巨大的雕塑群，那是文明最后阶段的集体艺术创作，在行星资源枯竭之后全体人民决定把自己最后的能量投入了一件全行星尺度的"告别雕塑"。雕塑主体是一个孤独的人形，坐在地上，手里拿着一朵已经不存在的花。人形的眼睛望向天空——那个方向是纪元的边界，是太初在轮回启动时撕裂虚空的地方。完成这座雕塑之后，行星上的所有人都自然消亡了——不是因为战争或饥荒，而是纯粹寿元到了尽头。陈霜站在这颗艺术行星前，用剑意在空中画了一幅简图——只用了三道弧线——就勾勒出了那尊雕塑的轮廓。她画的线条里有那个文明的最后一句话。那句话被刻在雕塑底座上——但他们看不懂那些文字，是陈霜的剑意在用图像翻译：翻译出来是一共十九个字——"我们走了。请不要立刻忘记我们。请晚一点再忘记。"

还有一种特别的作品形式——第四十五纪元虹在日记中提到的"守护者互助机制"。李长生在废墟中找到了一块保存完好的记录水晶，是虹本人的日记节选。日记原文是这样写的：

"纪元历第十五万零三百一十二年。今天是我守护这个纪元的第十五个纪元满元年。总感觉不行了——我的意志力在衰竭。整个宇宙的节奏全在放慢。我怀疑不是宇宙在背叛我，是我老了。如果我有个搭档——哪怕一个——能在我昏迷的时候替我撑一下，也许我不会衰退得这么快。但太初的规则是：一个纪元只设一个守护者。我不理解为什么。我写了七次申请给太初要求增添辅助守护者，全部石沉大海。也许太初不信任多人系统？还是他认为一个人扛整个宇宙才能测出这个纪元的真实实力？我不知道。我越来越频繁地一个人坐在这个哨站里看着星图发呆。那些需要守护的星系在星图上密密麻麻。我生了两只眼睛——两只眼照顾不过来一千亿个星系。如果有一千只眼睛就好了——或者有另外一个人，哪怕他也只有两只眼，我们加起来就有四只眼。"

虹的日记之后，同一个水晶中还保存着她的最终记录——大约在她写那篇日记之后三万年左右：

"纪元历第十八万零三百一十二年。撑不住了。我今天在调整第四星系群引力平衡的时候，手抖了——控制了十二万年的精度，第一次手抖。我去诊疗室——太初的自动诊疗系统——扫描之后说我的意识纤维化程度已经到了不可逆的阶段。我老了。我不是太初——我没有永恒的寿命。守护者老死的唯一后果是：纪元失去守护。没有人来替我的班。我写了无数封申请——太初从不回应。也许他不是冷漠——也许他是没办法。他只能创造一个守护者，因为一个纪元的底层协议中只有一个守护者的槽位。如果这是真的——那守护者从诞生的那一刻起就注定要在最后孤独地死掉。跟这个纪元里的所有其他生命一样孤独。"

日记写到最后一页。那一页不是文字，而是一段非常简短的全息影像。影像中的虹是一个瘦弱的女性类人形态——皮肤呈深紫色，头上长着两根感应触须（她的感知器官）。她坐在哨站的石床上——就是李长生面前那张硬邦邦的石床——对着记录水晶说了最后一句话。她的声音沙哑，发音习惯不同于人类，但帝国的翻译系统解码了她的语言。她说："下一位守护者——如果你看到我的日记——请尽早开始找搭档。别像我一个人傻撑。撑不住的。"

陈霜在这座哨站前站了很久。她没有说话，只是站在那里看石床上那只水壶——一只极其粗糙的手工陶壶，壶壁上印着制作者的手指纹路，歪歪扭扭的，显然不是工业制品。那是虹自己在某个下午随意捏的——也许是在看星图的间隙，也许是在某次宇宙级调整结束后放松手指时无意中定型了。壶是空的。里面已经没有水了——时间停止了流，水分子早已被封死在冰点以下。但那十个手指纹的曲面形状还清晰可见。

李长生知道她在想什么。虹是守护者。陈霜也是守护者——虽然不是太初指定的，但她走到这一步的原因跟虹一模一样：怕他一个人扛不住。虹没有搭档，于是她一个人撑到了意识纤维化。陈霜有搭档，所以他们从旧纪元扛到了新纪元。区别不在境界、不在天赋、不在太初的偏爱——只在有没有第二个人。

但这纪元不一样。这纪元从一开始就有两个守护者。不是虹祈祷了三万年的那种"两个神级并肩作战"，而是更根本的——一个来自王家庄土里的、一个来自桂林陈宅的，两个人的人生轨迹在旧纪元西北大漠中交汇，没再分开。虹的问题是制度问题——孤独不是性格使然，是太初五十个纪元中从未修改过的底层设定。而这纪元——李长生已经推翻了那个设定：有守护者梯队，有监察团，有十年让法典不断演化。

（第712章完）

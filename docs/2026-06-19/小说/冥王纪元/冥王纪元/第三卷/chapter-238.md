# 第238章 深入战场，发现第七块碎片

石室里的地图标得很清楚。第七块碎片的位置不在战傀防御圈内——在更深处。在环形山底部，那个一万年前的大战核心地带。

李长生把地图交给了小王扫描存档，然后带队伍继续深入。

穿过石室后方的甬道，地势开始急剧下降。甬道的坡度从大约十五度变成了四十五度，然后又变成了接近垂直的竖井。竖井的内壁上凿着螺旋向下的台阶——台阶的边缘已经被某种高温融成了玻璃状，在头灯照射下泛着深绿色的光。

"这是战斗痕迹。"陈霜走过一段台阶时停下来。她用手指摸了摸台阶边缘那些玻璃状的融化物——一万年了，表面仍是光滑的，没有任何风化的痕迹。"不是一般的能量冲击——是将高温和灵力压缩在一起释放的术法。能把岩石熔成玻璃的温度，至少在一千八百度以上，而且是在极短时间内达成的。"

"冥王的功法？"小王问。

"不确定。"陈霜摇了摇头，"也可能是围攻他的那十二个神级修士中的一个。火系神级修士——不是传说中冥王的战斗风格。"

李长生一直在走。他没有参与讨论——不是不关心，而是他的全部注意力都被前方的某个东西牵住了。

掌心。冥王令的纹路在急剧发热。不是战斗中那种灼烧感，而是一种更深层的、从骨头内部向外传递的震颤。第六块碎片之前找到的五次——每一次碎片接近时冥王令都发热。但从来没有像这次这么剧烈。

这不是普通的共鸣。

这是召唤。不是一个残片对另一个残片的呼唤，而是主体对主体的认定——第七块碎片不是普通的碎片，是冥王令的核心板块之一。

------

竖井的尽头是一片巨大的地下空间。

李长生第一个走出竖井。然后他停下了脚步。不是因为前方有危险——是因为前方有他从未见过的东西。

地下空间的面积大致相当于两个足球场并在一起。穹顶高达百米，穹顶上嵌着无数颗发光灵石，排列成一条银河的形状——不是随机排列的，是精确按照银河系的真实星图布置的。每一颗灵石代表一颗恒星，灵石的亮度代表恒星的绝对星等。

真正的银河，被缩小了刻在这座地下殿堂的穹顶上。

而在这片地下空间的中央——是一座巨大的环形山底部。

不对。应该说——这里才是真正的战场核心。地面上那个环形山只是后来一万年里月尘覆盖形成的伪装层。真正的战斗发生在这里，一百米深的地下。

整个空间的地面不是平整的——是被打碎的。巨大的岩石板块被某种力量掀翻、碎裂、抛掷到各处。地面上的裂缝最宽处超过十米，裂缝边缘呈现出被高温熔化后急速冷却的玻璃状物质。空气中——不，月球没有空气。但在这片空间里，灵气的浓度高得吓人。

不。高的不是灵气——是残留的战斗能量。

一万年前那场大战释放的能量，至今没有完全消散。它们滞留在破碎的岩石里、凝固在玻璃化的地表上、悬浮在这个封闭空间的空气中。能量本身已经不再是可攻击的形态——但它们仍保持着战斗瞬间的"记忆"。每一道裂缝里都封存着一万年前某个瞬间的战斗痕迹。

当李长生走进这个空间时，他感受到的不是威胁——是震撼。

他的手掌在剧烈发热。冥王令感知到了——第七块碎片就在这片空间的某个位置。不是藏在暗处，不是被人封印——它就裸露在外，镶嵌在某一块岩石上。

"分散搜索。"李长生说，"注意安全。发现能量漩涡不要靠近——这里面的残留能量虽然封存了上万年，但一旦被外来的灵气扰动，可能会释放。"

队伍散开。

陈霜往东走。她的剑修感知对灵气流动特别敏感，很快就在东侧的一片碎石堆里发现了一处异常——一块两米多高的玄色岩石，表面光滑得不像天然形成的，而且整块岩石周围环绕着一圈肉眼可见的能量漩涡。

不是风——是灵气在自转。以岩石为中心，半径大约三米范围内的灵气被某种力量牵引着，形成一个缓慢旋转的漩涡。漩涡的边缘触碰到周围的碎石，碎石会被无声地推开——不是弹开，是像被某种无形的力场推开一样缓缓滑开。

"李长生！"陈霜在频道里喊了一声。

李长生在三秒内赶到了。他看到那块岩石时，掌心的冥王令发出了一种他从未听过的声音——不是声音，是振动。冥王令的纹路在以极高的频率振动，振动通过骨骼传导到他的耳膜，在听觉神经中翻译成了一种类似低鸣的声音。

第七块碎片。

就在那块玄色岩石的顶部——镶嵌在石面中。

李长生走近了一步。环绕岩石的能量漩涡立即感应到了他的到来。漩涡的转速从缓慢变成了极快——不是攻击，是一种近乎迫切的反应。像一只被困了一万年的狗终于听到了主人的脚步声。

随着漩涡加速，岩石顶部的那块碎片开始发光。光是幽蓝色的——和他掌心的冥王令纹路一模一样的光。两种光隔着三米的距离互相呼应，像一面镜子照见了另一面镜子。

李长生走到漩涡边缘，停下了。

不是不能进——是他在看那块碎片。

第七块碎片比前六块加起来都要大。它大概有半个巴掌大小，形状不是不规则的残片——而是一个完整的扇形。边缘整齐，像是设计之初就被分割成这个大小的模块。碎片的正面刻着一组极为复杂的符文——不是之前见过的冥纹辅符，而是冥王令的主符文之一。这组符文在六块碎片上都只是残缺的笔画，在第七块上才呈现为完整的图形。

"这是核心模块。"李长生的残魂——那个寄居在冥王令中的冥王残魂——在沉默了很久之后第一次开口。声音比以往任何一次都清晰，说明它也从第七块碎片中吸收了能量。

"核心模块是什么？"

"冥王令由九个核心模块构成。"残魂说，"前六块是令牌的框架结构。第七块是第一个功能模块——空间感知模块。拿到这块碎片之后，冥王令就能'看见'附近所有空间中的灵气分布。不是感知方圆几里——是感知星域尺度的灵气。冥王令背面的星图，就是从这块碎片的能力衍生出来的。"

李长生看着岩石顶部那块发光的碎片。空间感知——换句话说，这是一块能让他"看到"宇宙灵气地图的碎片。

他深吸了一口气，抬脚走进了能量漩涡。

漩涡没有阻拦他——正相反，在他踏入的瞬间，环绕岩石旋转了上万年的能量漩涡忽然减速，然后改变方向，围绕着他旋转。不是岩石吸引灵气——是碎片在等待冥王令。现在冥王令来了，漩涡理所当然地应该围绕着真正的主人。

三米的距离，他走了九步。

每一步都伴随着掌心中越来越剧烈的振动。走到岩石前的时候，他伸出手——右手掌心朝向碎片。

不需要去抠，不需要去拔。

碎片自己动了。嵌在岩石中一万年的扇形残片，在他掌心朝向它的瞬间，自动从岩石中脱离出来——不是被拔出来的，是像磁铁被另一块磁铁吸引一样，主动弹了出来。

碎片悬停在李长生的掌心上方。

然后落下。

七块碎片——第一次真正接触。

(第238章完)

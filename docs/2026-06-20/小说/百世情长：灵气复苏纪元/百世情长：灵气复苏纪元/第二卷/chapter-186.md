# 第186章 化身教书先生

桃源村的人早就习惯了老林的存在。不是那种"他住在这儿所以我们不奇怪"的普通习惯——是更深一层的习惯：如果哪天早上看不到他在皂荚树底下扫地，村里的大妈们会互相问一句"林老师今天咋没出来？"。他帮村里孩子的功课辅导、给邻居阿婶看腰背疼、帮不识字的村民翻读上面发下来的政策条文、拿自制的草药方治好了好几只村狗身上的皮肤病。在村里所有人的心里，他就是个曾经读过很多书、老了回到乡村住的热心退休教师——人有点古怪但绝对的善。

人们不知道的是，这个"老林老师"每天晚上不是坐在油灯前看旧书——而是在给一个女孩搭建守护阵的升级、监测她的身体灵气载量有没有因为锁而下降。他用自己的元婴神识来识别她的生理周期，把每一次生理期前一晚将灵气注入她的气血循环，以减少她能感受到的内分泌波动。所以她从来没痛过经——她自己觉得可能是体质好。其实每月的这几天，林牧都在紧盯着她的灵能曲线不敢松懈。

"教书先生"的身份早在很多年就确立了。但她上高中以后，这个身份的外延越来越大。学校有时会请他去给县里的小老师做"乡村教育经验分享"——他偶尔去一次，演讲内容就是认真的、土土的、不沾修仙。那些年轻的县城教师只觉得这个老头很朴实、对教育有执着的情念。还有女老师事后问他要不要搬到县城开辅导班——他说"不了，我是来养老的"。

他很小心。在任何正式场合都是完完全全的"教书先生"，绝不露出高于普通人水准的任何举动。他可以用灵力瞬间修正教室里面漏风的窗——但他会等所有老师走后才做。他即使在镇上碰到熟人也不谈任何敏感话题。

除了教书先生的身份外，他在实际中还是她的家教师、体疗师和实际上的安全员。苏小晚考大学最后冲刺阶段精神非常紧张。除了每天早上去他家练"经络学保健操"，她还去得越来越勤——一有时间就去。他看出她的焦虑——她不是怕考不上，是怕考不好让自己浪费了村里给的教育补贴（桃源村补贴高中生学杂费一些微薄的金额）。她没有对别人说过这份在乎。但他在她写作业后把笔盖带回不小心发脾气又吞回去的时候，早已读到了。

于是他开始在晚上的辅导中加入更多"舒缓引导"。把她带出了屋外院中——让她用手贴看皂荚树的树干做冥想。他说:"把烦恼全给这棵树。它不介意。因为它已经把很多烦恼都变成了树叶的了——你看它已经长得够高大。"她贴树站了很久。忽然把手放下来跑去拿来那幅她画的村子全景画，指说是把这棵树画在画中央。他点头。然后她回到了屋里又重新打开笔记看书——心情似乎真的平静了一些。

桃源村的一些人曾问过苏大山:"这个老林对你们家娃也太好吧？你们不怕......"苏大山摇头说"不怕。他不是那种人。他就是真的喜欢教人。他也帮别家孩子——不只对我家的。"村人自己也常受到老人的帮助，也就把狐疑溶解在了日常信任里。

苏家对林牧的感情最深，但也说不清该怎么形容。他们只知道这老头住到隔壁之后，苏家的各方面都在好转——从灵稻的行情变好了、小晚学习成绩好了、孩子身体好了、连苏大山自己常年的腰痛都变轻了。他们把这一切归因于"天意对他们好"。

那个冬天苏小晚半夜病了一次——高烧三十九度。苏大山骑着三轮车带她去乡卫生院。林牧知道（平安扣温度升一度他都知）后，在夜深中独自一人坐在自己屋里。他把灵力调到极致精微度——隔空把她的高烧从灵魂波峰往下压。这是一种极精密的元婴级灵术—— 距离太近，必须通过筑基级别的精度把多余热能一点一点从她的脑部经血气中导出。操作持续了一个多小时。等她烧退之后他坐在椅子上有些疲累，靠着墙浅眠了会儿。

次日她退了烧回家打吊瓶。他晚里去看她。她躺在被窝里挂着点滴。他坐床头边上，伸出手握住她的发顶轻轻拍了一下。三个轻拍的力度刚好是"老师没关系"，不是"父亲在担心"。她就朝他把淡蓝色带小水蓝边的毯子拉下来，露个眼睛做个鬼脸:"我没事——只是感冒。"

教书先生的故事其实最核心的不是教书——教书是名义。教书下的一层是陪伴。再下一层——是用尽世间最静的方式慢慢扭正她被锁压住的命运。而教书这层外衣给了这种方式完美的社交合法性。他因此可以二十年如一日地站在她旁边不被任何人怀疑。因为"老师教学生"是天经地义的事。多好多纯粹的面具——尽是她和他之间那条安静的桥。

三年又三年。他继续坐在书房批改她的作文，给她的每一篇写评语。猫在他手边睡成一块抹布。鱼在微光中静静游徊。村外世界的灵气大战、宗门争霸、GPC新法令偶尔冲刷到这里，但被她的笑与他端出热茶时蒸出的水汽全部隔断。教书先生的身份——是林牧造出的最安静、最成功、最长的人生面具。它将在她正式说出那句话后慢慢卸掉。但现在还须戴着——直到她亲手把那扇窗推亮到更广阔的方向。

**作者：段锦佑**

# 第139章 灵气复苏的乱世

第二十年，世界开始乱了。

灵气复苏进入了官方定义的"爆发期"。不是建国百年那晚短暂的天空异象——那次是禁制解除的记号。也不是十四年前那两周的"二次喷发期"——那次是灵气总量在短期内激增。这次是更深层的变化：全球地脉开始大规模异动，从赤道到极圈，每一个大陆的地底灵脉分支都在重新打通——像一条已经冻僵了千年的河流忽然在全部支流上同时解冻。灵气的分布不再局限于某些特定的遗迹或灵脉交汇点——它开始渗透到整个星球的每一个角落。城市、乡村、海洋、沙漠、地下矿洞、地铁隧道、写字楼地下室。空气里的灵气浓度在一年内翻了大概六倍——不是逐渐翻，是呈脉冲状一波一波地往上推。

妖兽全面异变。不是偶尔出现几只走火入魔的低阶妖兽，而是全球范围内的大规模"兽潮化"——所有潜在灵兽血脉的动物都在被高浓度灵气激活。野兽从勉强维持兽性的状态纷纷觉醒为具有灵识的妖兽，且第一次大规模觉醒往往伴随着失控——因为它们的神经系统无法承受突然涌入的灵力，于是疯狂攻击一切——包括人类聚集区。

全球各国政府、修真界联盟开始进入公开联盟——灵气复苏不再是需要藏着掖着的秘密——因为已经无法再藏——街上的人可能随时看到电视新闻中插播"请市民远离山区——附近有妖兽出没"。这是世界的转型期——注定流血。修真界公会发起了史上最大规模的召集令——"泛人类修士联合阵线"——向全球所有登记在册的修士发出号召：响应集结，参与边境防线和兽潮清除。金丹及以上修为的修士原则上必须响应——因为在高危兽潮的清理中，筑基修士生存率太低，需要金丹作中坚力量。

召集令发出的时候，林牧正蹲在茶仓的阁楼上给老猫修猫窝门（被老猫自己挠坏了）。他的灵识在同时接收到两样东西：一是联盟远程传讯（通过修法通讯符直达他的个人标识符，他早年登记的假名"牧林"，修为"金丹中期"）；二是老张在楼下骑电动车路过——去县城补货。他把猫门装了最后一块扣板——然后打开通讯符，看了一遍集结时间和地点。

北上。时间紧迫。他需要在两周内抵达北方集结点——参与第一队针对大型兽潮的阻击组。

他把通讯符关了。然后走出茶仓——走向茶馆——在老位置坐下。窗外街道对面，她在门口择茶——今天择的是秋茶的最后一批，叶子已经有些枯黄了。她的动作比年轻时慢了一点——不是老了，是更稳了。择好之后她在围裙上擦了手，站起来往远处茶山的方向看了几秒。然后她回茶铺里去了。

林牧把最后一杯茶喝完。茶钱照常夹在杯底——多了二十块。然后他站起来——陈老板娘今天没在——茶馆里的临时请的小妹在。他走出茶馆，在街边站了很久。阳光从槐树枝丫里打下来，落在他肩头。

他在走之前去了茶山。不是去看山——是去安放最后一层保护。他把张记茶庄门前的桂花树挖松土——把一道保护符埋在了树底——不是普通的护身符——这是他花了这么多年结合古篆阵法和平时的累积灵力制成的一张"元婴级守护真符"。相当于一个元婴初期修士的一次性全力防御，触发条件极复杂：只有当她的灵压出现极度恐惧信号、且同时她本身受到了物理上的致命威胁——符才会激活。激活后释放元婴级的护罩——护住张家以及邻居共三栋房子。符埋好之后他把土压回去，上面平平整整——桂花树根下多了一层看不见的淡金色符网。他在土上踩压时脚掌感觉到了树上落下来的几片干了的桂花——秋天。

然后他把她家所有的保护符石全检查了一遍，把菜市场那颗因年久失修快断供的修补完毕，把小学门口那颗更新为"追踪兼自动补给"模式——因为小辉不在那上学了——但他把符改了个识别算法：以后只识别和追踪小辉的灵力并在其遇到危险时远程提醒他。改完之后——他把整个的守护网从之前的十八年维护模式切换到了"无人维护模式下能自行运转半年"的全自动模式。用的是他自研的一套阵法——灵感来自当年写的防服务器宕机的自动重启脚本。

这是他离开前能做的所有事情。

走的那天凌晨——天没亮。四点半——青溪镇还在月亮下睡得沉。他站在镇口的老榕树下——背上有一个简易的行囊（只有一些布料和干粮和一些灵石补充，东西很少），腰间挂着便携水壶（锦鲤在出差模式中——处于浅休眠态），老猫蹲在他肩上——尾巴搭在他领子上。他回头看了最后一眼青溪镇——东方微白——茶山轮廓清晰，槐树的影子在青石板路上斜斜地躺着。

只有老榕树知道他走了。树下的蚂蚁照常沿着树根爬行——不知道蹲了二十年的那个沉默的外地茶叶商人不会再出现。他走了。没人送。

他走后的第一天——林秀芝早上开门时觉得街上好像少了什么，但说不出来。她照常摆茶筛——去菜市场——下午在茶铺看账本。邻居周嫂路过的时候说："诶——那个常在你家门口喝茶的林先生——这两天没看到——是不是出去进货了？"林秀芝愣了一下——她从没这么关注过那个男人——但确实——今天那扇窗子前面是空的。她看了一眼街对面的茶馆——然后继续择菜。

晚上她对老张说："那个林先生好像走了。"老张说："可能出差——茶叶生意嘛——总有跑远的时候——"

她"嗯"了一声，继续喝她的茶。但她心里有一个很难定义的缺口——像一张舒适的旧毯在某个角落忽然多出了一条线头——不会乱，但让她时不时想摸一下。她摸着这条线头——不知道它是什么。

在离开的路上，林牧第一次在御风飞行中感受到了"背着方向飞"的痛。不是身体不适——他是金丹修士，御风完全没压力——是心灵在抗拒每一个离开一步的距离。胸口的感应线在他在四点多离开镇口的那一刻就进入了微弱的"远离模式"——不是断了——是强度在缓慢下降，像一个信号在基站边缘轻轻发——需要远距离维持。他把一缕灵识始终拴在感应线上——一直拴着——不会让线断掉——只要线还在跳，就是她一切平安。

一周后——他抵达了北方集结点。而南方的小镇次日会照常天亮。她的茶铺会照常开门。她不会知道在她脚下桂树的根须之下——有一个自己上一世最亲近的人用全部的克制为她埋下了一整个完整的符阵。老树的根须会把符文的微弱光芒裹在泥土中——上面是青苔、阳光和日日滚过的桂花。

她每天从桂树下走过——不知道。这就是最好的。

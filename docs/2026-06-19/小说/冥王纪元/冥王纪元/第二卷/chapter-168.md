# 第168章 李长生逆袭护人，玄门第五宗大损

凌晨四点。

李长生站在城西一座废弃的化工厂门前。

这座工厂荒废了八年。厂区的铁门上锈迹斑斑，门卫室的玻璃碎了一半，墙上还贴着2018年的安全生产标语。从外面看，这里和任何一座废弃工厂没有区别——荒草、垃圾、被风吹散的塑料袋挂在枯树枝上。

但李长生知道不一样。

他抬起右手。掌心的五道冥纹在黑暗中亮起来——不是平常那种微弱的荧光，而是炽烈的暗金色，像是熔炉里快要烧穿的铁水。第五道冥纹是最近融合的那一块碎片留下的，颜色比前四道更深，纹路更粗，形状像一枚倒悬的尖塔。

"据点在地下。"龟相的声音从耳麦里传来。这只千年老龟此刻正趴在基地的一台显示器前，用一只前爪笨拙地戳着触摸屏。"五层结构。最上面是伪装层——废旧设备加杂物间。地下二层是物资仓库。地下三到五层是核心区——修炼室、法器库、人员宿舍。根据热感应和灵气波动分析，目前在据点内的人数大约四十五到五十三人。修为最高的是一个玄师境巅峰——应该是这里的主事。"

"玄门七宗哪一宗？"

"第五宗——元始道门。符箓和阵法为主。这座化工厂建在一条被遗弃的地脉支线上，灵气浓度是周围的六倍。他们在这里设据点至少有两年了。"龟相顿了顿，"还有一件事——小王父亲收到的威胁信上，墨迹中检测到了符箓残迹。是一种低阶追踪符的残留。那种符的绘制风格——正是元始道门的标准化制式符。"

李长生没有说话。他只是把外套脱了，叠好，放在门卫室墙根底下。

陈霜站在他身后。她提着龙纹剑，穿着深灰色的夜行衣，头发扎成了紧束的马尾。夜风吹过，她的剑鞘末端微微颤动——那是剑在感知主人的杀意。

"你确定要一个人进去？"她问。

"他们在等我。"李长生说，"那封信不只是威胁小王。是故意引我来的。他们知道我会查出据点的位置——他们在等我杀上门。"

"那你一个人进去——"

"就是如他们的愿。"李长生回头看了她一眼。眼神很平静。"但是——如他们的愿不代表他们会赢。只代表他们求的仁，求到了。"

陈霜没有拦他。她见过李长生这个表情。上一次是在大漠——他一个人面对三个玄师级修士，对方布置了天罗地网等他来。那三个人后来都没了。不是死了——是被打散了修为，废了灵根，跪在沙子里求他给条活路。

李长生给了。但不是因为心软——是因为他懒得收尸。

"我在外面接应。"陈霜说，"十分钟你不出来，我进去。"

"好。"

李长生推开铁门。门轴发出刺耳的嘎吱声，像某种生锈的警报。他没有隐藏脚步声——皮靴踩在碎玻璃和碎石上，嘎吱嘎吱，每一步都清晰可闻。

他走进厂房。厂房内部空旷而破败——头顶的钢梁锈得千疮百孔，地上堆着报废的化工罐和破损的管道。一只老鼠从他的脚边窜过去，钻进了一堆废料。

他走到厂房正中央，站定。然后抬脚——用力跺了一下地面。

嘭。

这一脚不是用肌肉发力，是用冥气。五道冥纹同时爆发，暗金色的光芒从他脚底炸开，沿着地面向四面八方扩散。脚下的水泥地裂出一道道蛛网状的裂缝。裂缝的深处透出幽蓝色的光——不是他发出的光，是她面以下的阵法在应激状态下自动防御的反馈。

他找到了入口。

厂房最里侧的一面墙壁上，混凝土表面忽然亮起了几道符文的轮廓。那些符文是用透明的灵墨画在墙上的——平常看不见，只有在受到外部灵气冲击时才会显现。这是元始道门的招牌阵法之一:隐壁。能在墙壁上开辟一个通往地下空间的入口，但入口在阵法关闭时与真实墙壁物理上无法区分。

李长生走到那面墙前。墙上浮现的符文越来越亮——赤金色，笔画刚硬，带着符箓宗派特有的规整和精密。符文的核心是一个"禁"字——入者需宗门令牌验证。没有令牌强行闯入，会触发墙内嵌的三重攻击符阵。

他把右手按在符文的正中央。

嗡——

整个墙壁剧烈震动了一下。符文的赤金色光芒和冥纹的暗金色光芒在墙面上一寸一寸地碰撞、撕扯、吞噬。这不是修士之间的战斗——是两种完全不同体系的灵气本源在互相吞噬。符箓之力是规则化的、标准化的、被炼制过的能量。而冥气是混沌的、原始的、来自天地初开时沉入地壳深处的那种最深层的能量。

元始道门的符阵撑了七个呼吸。然后开始崩解。先从外圈——符文的辅助笔画一根根断裂，像被烧断的保险丝。然后是中层——防御阵的核心结构开始扭曲，灵墨从墙面上剥落，变成一滴滴黑色的液态灵气。最后是正中央的那个"禁"字——冥纹的光芒穿透了它，从它的内部炸开，把整个符阵炸成了一面蛛网状的裂缝。

裂缝中间出现了一道门。门后的通道斜向下延伸，两侧的墙壁上亮着应急用的灵光石。

李长生走了进去。

通道尽头是一个大厅。

大厅比想象中大——至少半个篮球场的面积。穹顶高约三米，顶部密集排列着照明用的灵光石，把整个空间照得明亮。大厅两侧排列着红木书架——不是装饰用的，每个书架上都摆满了装订成册的线装古籍、玉简和符纸。这些是元始道门的积累:几千年来总结的符箓体系、阵法原理、制符经验。一张书架上贴着一个纸条，上面用毛笔写着:"新郑培训基地教材——初级符箓入门(第四版修订)。"

大厅正中央站着一排人。全是元始道门的修士，穿着统一的深灰色道袍，身上绣着元始道门的山形徽记。一共十二人。站在最前面的那个人大约五十岁左右，长须垂胸，手持一柄拂尘，拂尘的柄是某种白色灵木制成的，上面刻满了密密麻麻的符文。

玄师境巅峰。

"李长生。"那人开口，"没想到你来得这么快。"

"你是谁？"

"元始道门驻华北地区外务执事——赵乾元。"他说话的时候拂尘在空气中画了一个半圆，周围的灵气立刻朝着那个半圆汇聚过去。中级凝灵术。能在战斗中随时凝聚周围的游离灵气补给自己——这是玄师境巅峰的标志。"你深夜闯入我元始道门的据点——按照联盟协议，这属于主动攻击行为。"

"你们给我兄弟的父亲塞信。"李长生的声音很平静，"那封信上写着——让王博文离开李长生，不然下次不是信。"

赵乾元没有说话。

"信是你们写的。"李长生说，"所以我来找寄信的人。很简单。"

大厅里的空气忽然变得极重。不是温度变化——是压力变化。赵乾元身后的十一个修士同时开始凝聚灵气。他们都是灵者境中阶到高阶的水平，在元始道门的培训体系里受过标准化训练。结阵的速度整齐划一——左手掐诀，右手按在腰间符袋上，每个人的脚下都亮起了一道颜色各异的灵光。

十一人。一个阵法。

元始道门最擅长的是符阵配合——用符箓固化法术，用阵法统一调度。十一个灵者境修士单独拿出来都是中等水平，但用阵法串在一起，战斗力可以匹敌两到三个玄师。

李长生没有等他们结完阵。

他一步跨出。五道冥纹同时爆发——冥土感知境锁定了大厅中每一个修士的灵气走势，冥渊开辟境在他的脚下撕开了一道黑色的裂缝。裂缝里涌出的不是火焰、不是冰霜、不是任何一种已被分类的灵气属性——是纯粹的冥土之力。那种力量没有颜色，因为它吞噬颜色。没有温度，因为它吞噬温度。

他的第一拳砸在了阵法的核心节点上。

不是打人——是打阵。

十一人阵法靠的是灵气共振——十一个人分别负责阵法的一个位置，灵气通过预先设定好的路线流转，形成合力。听起来很复杂，但在冥土感知境的视野里，这些灵气的流转路线就像显示器上的电路走线——清晰、明确、可追踪。只要打断核心节点，整个阵法就会瘫痪。

李长生打的就是核心节点。

他的拳头打在了大厅地面上的一块方砖上。那块方砖看起来和周围一百块方砖没有任何区别——但它下面是这个阵法的灵气枢纽。方砖炸裂，埋在砖下的一枚符箓核心碎成了粉末。阵法的灵气回路被截断，十一道同时运转的灵光瞬间失去同步。

哐——阵破了。

十一个修士同时遭受了灵气反噬。有几个人直接喷出了血。几个人踉跄后退，撞在了身后的书架上。

赵乾元的脸色变了。不是恐惧——是意外。他没料到李长生的第一击不打人，打阵。一个正常修士在闯入敌方据点后应该全力攻击最强者，而不是先去拆阵法的核心节点。但李长生不是正常修士。他是被六个碎片的主人——一个从泥土里爬起来的农民，从来没上过任何宗门的正规训练。他的战斗方式不是"规范"的——是"有效"的。

"你——"

李长生没有给他把话说全的机会。

他一步跨到了赵乾元面前。不是飞过去的——是一步跨过去的。冥气强化过的腿部经脉让他的爆发速度远超同级别修士的预期。赵乾元甚至没看清他的起步动作。

他伸出右手——不是掐诀，不是结印。是抓住赵氐元的衣领，把他整个举了起来。玄师境巅峰的护体灵气在李长生的手指接触到衣领的瞬间就自动激发了，但冥纹直接碾压了过去——五道冥纹的力量集中在指尖，穿透了那层淡金色的护体灵光，像热刀切油脂一样没有遇到任何像样的阻力。

"碰我的人。"李长生看着他的眼睛。语气很轻。轻得不像是威胁——像是陈述一个已经发生的事实。"死。"

赵乾元嘴里念出了一个符咒。一条火蛇从他的袖口窜出——元始道门的高级攻击符，灵符·赤练，能在瞬间释放出一条高温火蛇，温度超过三千度。火蛇直接扑向李长生的脸。

李长生没躲。

他额前虚空中出现了一道黑色的裂缝——冥渊裂隙。裂缝只有巴掌大，但吞掉了整条火蛇。三千度高温，灵符级的法术威力，在接触到那道裂缝的瞬间全部消失。不是被抵消了——是被转化了。冥渊的核心能力:将攻击性能量拆解为原始灵气，反向吸收。

赵乾元看着火蛇被吞掉，瞳孔剧烈收缩。他活了一百三十年，跟阵修、剑修、体修、丹修、虫修都交过手。但他从没跟冥系修士打过。他在宗门的典籍里读过——冥系修士的功法特点是不讲道理。但直到此刻，他才真正理解了"不讲道理"这四个字的重量。

李长生的右手一松，让赵乾元摔在地上。然后他从腰间拔出了一把短刀。不是法器——就是一把普通的猎刀，刀柄上缠着电工胶布，刀刃磨得锃亮。这把刀是刀疤送他的，退伍那年从部队炊事班顺的老物件。不值钱，但够快。

他把刀尖点在赵乾元的丹田上方一寸。没有刺下去。但刀尖的温度让赵乾元的腹部皮肤收缩了一下。

"我不杀你。"李长生说，"但你丹田里的修为——是你用错误的选择换来的。所以我现在收回这个错误。"

刀尖刺入半寸。

赵乾元发出了一声他没有发出来过的声音。不是惨叫——是绝望的、本能的、从喉咙最深处挤出来的嘶嘶声。他挣扎着想掐诀，想释放最后一个符咒，但手指刚抬起来就垂了下去。不是倒了。是废了。

李长生把刀收回来，用袖子擦了一下刀刃上的血。

大厅里还站着四个剩余的修士。十一个人里七个伤了，三个跑了，还剩一个。那个人缩在书架旁边，浑身发抖，道袍的下摆湿了一片。不是血——是尿了。

李长生看了他一眼。然后说了一句让在场所有人都记住的话。

"回去告诉你们宗门的掌门。谁再碰我身边任何人的家人——我不会杀那个人。我会废掉整个据点的修为。一个一个。一个不落。"

他把刀插回腰间。

"我说到做到。"

------------------------------------

天快亮的时候，李长生走出了化工厂的铁门。

陈霜站在门外，背靠着他的外套。她看到李长生走出来——身上有几道口子，但都不深。最明显的是左手虎口上的一道——那是他接赵乾元临死反噬的一道高阶攻击符时被划伤的。伤口已经结痂了，冥气的自愈能力在发挥作用。

"怎么样？"

"据点废了。主事废了。阵法的核心资料——我让小王的监测网远程拷贝了一份。剩下的书架我没动。"李长生接过她递来的外套，套上了。"他们以为我会毁掉所有东西。"

"你没毁掉？"

"没必要。书是为后人写的。留着——将来有人用得上。"

他抬头看了一眼天色。东方天际已经微微泛白，城市的天际线从黑暗中浮现出来。远处的灵石交易所的LED大屏还在亮着，上面跳动着今日的灵石实时汇率——1灵元=¥3,912。

"还有一个事。"他边走边说，"我在大厅里感知到了其余据点的通讯频道。小王需要帮我做一个信号反向追踪——我要知道元始道门在全国还有多少个这样的据点。"

"你要一个一个打掉？"

李长生转头看了她一眼。他的瞳孔在晨光中微微发亮——不是冥纹的反光，是他自己的眼神。那种眼神陈霜见过一次——那天他和赵乾元说了那句话的时候。

"不是打掉。"他说，"是让他们知道——碰我的人，没有第二次机会。"

两个人走在黎明前的街道上。街角24小时便利店的灯光透过来，映在两个人并肩往前走着的影子上。一把剑，一把刀。一个废了三十年的仙门逐徒，一个从泥土里爬上来的农民。

身后那座废弃化工厂的地下，四十五个元始道门修士正在从地上爬起来。有人捂着胸口，有人扶着墙，有人在昏暗中用发抖的手指拨出了求救信号。信号穿越这座城市的地底灵脉网络，传向了昆仑山。昆仑山上的某个密室里，五个宗门代表会同时收到同一个消息:

李长生来了。不是去谈判的。不是去抗议的。是去砸场子的。

(第168章完)

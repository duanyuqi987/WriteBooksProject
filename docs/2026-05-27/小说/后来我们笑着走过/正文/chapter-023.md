# 第二十三章 你好，我是沈安晴

我回到家的第一件事，是开电脑。

父亲在院子里修镰刀，听见屋里主机响，问：“刚高考完就玩？”

我说：“查点东西。”

他说：“查吧，别查到饭都不吃。”

我坐在电脑前，等开机。那台电脑已经很旧，主机箱里风扇声音很大。屏幕亮起来时，桌面上全是我爸不知道从哪里下载的象棋和播放器。我点开 QQ，输入账号密码。

登录声响起来。

我盯着好友列表。

没有新消息。

这很正常。她说到家以后加我 QQ，她也要坐车回家，也要吃饭，也要被家里人问考得怎么样。可我从下午等到晚上，把每一分钟都等成了一道题。

母亲喊我吃饭。

我说马上。

她进屋，看见我盯着电脑，说：“成绩还没出呢，你急什么？”

我说：“没急。”

她看了我一眼，像不太相信。

饭桌上，父亲问我考得怎么样。我说还行。母亲问数学难不难。我说有点。她又问能不能上一本。我说不知道。所有问题都很大，我一个也答不上来。我的脑子只在想一件小事。

她会不会加我。

晚上八点二十三分，电脑右下角跳出提示。

有人请求添加你为好友。

我差点把鼠标碰掉。

昵称是一串很普通的字母，头像是一片蓝色天空。验证消息写着：

你好，我是沈安晴。

我盯着那行字看了很久。

明明只有七个字，却像一封很长的信。你好。不是在教室里，不是在考点外，不是在翠湖边。是从她家里的某台电脑，穿过电话线和夏夜，来到我的屏幕上。

我点了同意。

聊天窗口跳出来。

我不知道该说什么。

手放在键盘上，按下去又删掉。你好？太傻。到了吗？废话。你吃饭了吗？像亲戚。谢谢你写同学录？更奇怪。

最后她先发来一句：

到家了吗？

我立刻回：

到了。

回完觉得太冷，又补：

你呢？

她说：

也到了。刚吃完饭。

我看着这几行字，心里有一种不真实的安稳。她在屏幕那头。我们不用对视，不用听见彼此声音，不用担心楼道里有人经过。字把距离隔开，也把距离接上。

我问：

你家里人问考试了吗？

她回：

问了。我说还行。

我笑了。

原来大家都会说还行。

我打：

我也是。

她发了一个笑脸。

那是系统自带的笑脸，黄色，眼睛弯着。很土。可我把它看了好几秒。

赵一鸣给我发消息：

怎么样，加了没？

我回：

加了。

他回了一串感叹号，又发：

别上来就写八百字情书。

我把聊天窗口最小化，没有理他。

沈安晴又问：

你同学录看完了吗？

我说：

看了。

她说：

我字写得有点乱。

我说：

不乱。

她过了一会儿回：

那就好。

聊天很慢。每一句之间都隔着几分钟。她可能在家里帮忙，也可能在想怎么回，也可能只是网卡。那时候的我没有这种成熟判断。她停三分钟，我就把三分钟想成三十种可能。

九点多，她说要去洗澡。

我回：

好。

她说：

晚点聊。

晚点。

这两个字让我坐在电脑前又等了一个小时。母亲催我睡觉，我说再等一下。她说你都考完了还熬什么。我说同学找我。她说男同学女同学。我说赵一鸣。撒谎撒得很顺。

十点四十，沈安晴的头像亮了一下。

她说：

刚洗完。

我说：

嗯。

然后又不知道说什么。

她问：

你今天在学校说的话，是想了很久吗？

我手停住。

屋里只有主机风扇声。窗外有人骑摩托过去，声音从远到近，又从近到远。

我打：

想了三年。

发出去后，我后悔了。

太重。

可已经发了。

屏幕那头很久没有动静。我盯着她的头像，心里一点点沉下去。就在我准备打“你别有压力”的时候，她回了。

她说：

我不知道该怎么接这句话。

我看着屏幕。

她又发：

但我看见了。

我问：

看见什么？

她说：

你这三年。

我坐在电脑前，突然不知道怎么呼吸。

那些早到的早晨，饮水机旁的一秒，被窝里的手电筒，成绩单上的名字，没递出去的风油精，灰色同学录。它们没有全白费。至少有一点，被她看见了。

我回：

谢谢。

这两个字很笨。

可我只会写这个。

她说：

先睡吧，明天再聊。

我说：

好，晚安。

她回：

晚安。

我没有立刻关电脑。

我把聊天记录往上翻，从“你好，我是沈安晴”看到“晚安”。看了三遍。最后截图保存，文件名乱打了一串数字。

关机时，屋里一下子暗下来。

我坐在黑暗里，忽然想起翠湖边她说的话。

现在不是有 QQ 吗。

原来有些靠近，不是走过去。

是一个头像亮起来。

# 第二十九章 楼下的风

十月以后，楚州开始降温。

早晚风大，宿舍楼下的梧桐叶掉得很快。清洁阿姨上午刚扫完，下午又铺了一层。叶子被人踩碎，混着泥，贴在路边。大学里的秋天不像高中。高中秋天有月考，有晚自习，有操场广播。大学秋天很散，课表一空，人就不知道该往哪里放。

我常去楼下等电话。

不是等她来，是等手机信号好一点。宿舍里信号差，电话一会儿断，一会儿杂音。楼下小卖部旁边有一排石墩，我常坐在那里。旁边是自动售货机，灯管发白，夜里有很多飞虫贴在上面。

沈安晴偶尔会打来。

大多是晚上十点以后。她说宿舍熄灯了，大家都睡了，她拿手机到阳台。她那边有海风吗，我不知道。电话里只有电流声和她压低的声音。

有一次，她说：“我们学校离海还挺近的。”

我说：“你去看了吗？”

“还没有。军训后一直忙。”

“去的时候拍给我看。”

她说：“好。”

这个“好”让我高兴了两天。

人就是这么便宜。被推远时，一句“别等我”能疼很久；被给一点点承诺，又能自己活过来。我在这件事上没有骨气。或者说，喜欢本来就很难有骨气。

室友开始谈恋爱。

不是正式恋爱，是和隔壁学院一个女生每天一起吃饭。回来以后，他会说女生真难懂，今天笑了，不知道是不是有戏。我听着想笑，又笑不出来。大家都在刚开始的关系里试探，只有我像已经爱过很多年。

可我其实也只是刚开始。

之前三年是我一个人的事。现在她终于在屏幕那头，在电话那头，我才发现两个人的关系比一个人的暗恋难多了。暗恋可以自圆其说。她不回头，是因为她不知道。她少说话，是因为她安静。她和别人说笑，是因为她善良。

两个人不行。

两个人会有具体消息，具体停顿，具体今天不想聊。每一件都是真的，没法全靠想象补成自己想要的样子。

十一月初，她连续三天没有上线。

我给她发了一条短信：最近忙吗？

她第二天回：有点。学生会排节目。

我盯着学生会三个字，心里又开始乱。学生会有男生，有排练，有晚上，有送她回宿舍的人。这些画面不是事实，却很快在我脑子里站满。

我没有回。

晚上，她打电话来。

我在楼下接。

风很大，吹得话筒里全是杂音。

她说：“你是不是不高兴？”

我说：“没有。”

这句没有像石头一样硬。

她在电话那头叹了一口气。

“你每次不高兴都说没有。”

我被她说中，反而更不舒服。

“那你要我说什么？”

电话里安静下来。

我马上后悔。

小卖部老板在里面看电视剧，声音很大。路边有一对情侣走过去，女生把手放在男生口袋里。风把梧桐叶吹到我脚边，又吹走。

沈安晴说：“我只是想跟你解释。”

“解释什么？”

“排节目这几天确实忙。不是不想理你。”

我握着手机。

这句话本来应该让我安心。可我心里那点酸没有立刻散。它像一块泡久了的纸，湿答答地贴在那里。

我说：“你不用解释。”

她说：“可你会乱想。”

我没说话。

她说：“林予怀，我有时候不知道怎么跟你说话。”

这句话比“少聊一点”还让我难受。

我坐在石墩上，风从袖口灌进去。手指冻得有点僵。

“那就不说。”我说。

话一出口，我就知道坏了。

她在电话那头停了很久。

“你真的这么想吗？”

我不想。

我一点也不想。

可我说不出软话。人有时候明明在伸手，却偏要把手握成拳头。我那时就是这样。越怕她走，越用难听的话把她往外推。

我说：“我不知道。”

她轻吸了一口气。

“我先挂了。”

电话断了。

我还举着手机。

屏幕亮着，通话时间停在十一分二十七秒。风从楼下穿过去，吹得树叶在地上跑。我坐在那里，忽然觉得很冷。

室友发短信问我带不带泡面。

我没有回。

过了很久，我给沈安晴发：

对不起。

消息发出去后，屏幕没有动。

我坐到小卖部关门。老板出来拉卷闸门，问我：“同学，不回去睡啊？”

我站起来，说：“回。”

楼下的风把我吹得头疼。

那天晚上，她没有回。

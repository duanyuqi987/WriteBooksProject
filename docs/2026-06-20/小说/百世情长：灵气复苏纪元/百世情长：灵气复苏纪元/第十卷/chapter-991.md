# 第991章 修仙界的历史落幕

极远纪元——上界道纪院在第无数次的制度修订中，正式废止了延续无数年的"天赋等级登记制度"。在此之前，每一个诞生在上界的仙童从降生那一刻起就被道号中枢自动检测天赋——然后被分成"上根、中根、下根、废根"四个等级。等级决定了他们能进什么层次的学校、能在哪个城区居住。虽然太行传道堂的影响力一直对这套制度的底层群体起着庇护作用，但制度本身始终没有正式废除。

这一年的制度修订大会上，代表底层仙人的一位年轻议员——她出身于传道堂系统，祖上是当年在传道堂第一批三人班中的某位老学员的后代——站上议会高台。她一句话讲完，全场投票结果就出了："今天——我们不废除它——它就已经在无数万年中被废除了——因为没有人再相信天赋能定义命运。投票只是补个手续。"

投票通过。天赋等级登记制度正式废止。新闻发布时，道纪院旁听席中坐着一位极年长的老妇人——她的修为不高，但精神矍铄。她没有鼓掌——只是站起来把一直抱在怀里的一本旧书放在了议院的公共存卷台上。那本书的封面极旧——是《灵气入门十二法》的初版——第一千零一次重印版。她在书的扉页上写了一句话："报苏师——手续补好了。"

老妇人是太行道启体系不知第几代导师——她自己的名字已不重要。她只是那个接力棒从未掉落的长队中一个普通的跑者。她把书放在存卷台上之后转身走出道纪院——沿外墙走到传道堂老校区。墙上的青苔还在。银杏新苗和老树根上分出的侧芽已长成新的大树。她坐在青苔墙下把今天的制度修订记进了随身带着的《太行导师周记》——写完合本，对着院墙上空空的蒲团说了一句："我今天上了一堂教科书——教的是'天赋不能定义人生'——说完下课。"

她起身朝课堂的方向去了——下午还有一节课要教。

道纪院当晚将"天赋等级登记制度废止令"的签署原件复制了一份，挂在老院墙临街的一面玻璃保护罩中——旁边只压了一张极小的纸条，纸条上的字是图书馆修复师从苏晚旧稿中裁下的："不收墙。——苏晚（笔误，原意：不收门槛）。"那个美妙的历史笔误终于在这一天——在正式制度的层面——跨过了从"民间理念"到"法律"的全墙。

# 第793章 通道内，时空完全失去意义

维度零点没有时空。

这不是说时空感被极度缓慢或取消了——而是时空这两样东西的根本定义在维零点的原始源中不存在。时间和空间本是宇宙诞生后被源代码定义的两个维度的运行产物。在宇宙诞生的那个原始点上——在源代码被编译器第一次运行之前——时空这两个参数都尚未被赋任何值。它们的"存在"在源代码底层仅仅是以某几个未被调用的变量的身份存在于列表中。而维度零点恰好是那些原始变量的存储位置——也就是它们尚未被调用的存在原点。

一个人在超越时空本身的存在域里唯一还能维持"自己"的办法，就是放弃对身体所在位置的判断，放弃对任何体验的时间次序感知。完全把意识锚定在纯粹逻辑自存上。

陈霜和李长生已经在这片无时空域中并肩了不知多长时间。事实上——"多长时间"本身就是一个不合法的问句——因为时间在此地不存在，所以不能用时间长度来描述存在。只能说他们在同一个状态里——彼此相互感知着对方的灵能信息态存在，维持着各自最底层的理智。在这个状态下两人的交流不需要发出任何信息——因为没有任何信息延迟而言。意识在任何一边闪现的任何信号，在另一边都立刻感知。没有距离就没有延迟。

陈霜在这里修了第一式"无刃剑防"。这招不是物质剑术——是在无时空域中以纯粹的意志划出的剑意防护。以前任何剑法都需要一个"攻击目标"——但在这里根本没有目标可以攻击，也没必要攻击。她的剑法自然地从攻击者转为守护者。她从没想过自己的剑法有一天能被如此根本地重新定义——但她想到了那天太初预言里的一个描述:"真正的守护不是抵抗攻击后的防守——是在攻击可能发生之前废除攻击的概念。"

她做到了。

李长生在无时空域中完成了一件事——他用冥王令逆向追踪了混沌本体累积内部熵能的来源路径。那是一条漫长得无法言喻的路径——从混沌本体沉睡开始的第一个纪元，到刚才——经过所有纪元中所有混沌级存在从混沌本体中吸取能量后没有完整归还的能量残余。每当任何一个混沌级修士调用过一次混沌力量，就会在混沌本体的内部留下一个无法自动愈合的微小裂口——能量从裂口渗出到修士身上，但在归还时不是全部归还——有微量损耗残余下来。这些残余在各纪元中累积，在混沌本体的内部形成了一个持续压迫它睡眠状态的压强——这就是内部熵能。不是谁的恶意积累——是所有在宇宙中生活过的混沌级存在的必然副作用。

而李长生自己——作为最强的混沌级以上修士——也在其中贡献了不少。"这不是什么意外的错误——这就是内力的代价。"他意识到这一点后，心中没有任何负罪感——反而感到一种更深的、难以言明的"本该如此"。宇宙的运转不是免费的。力量越强——触碰宇宙根基的量就越多，即使是无心地触碰——也会留下痕迹。现在他在这里——不是为了清洗自己的痕迹——是为了把所有纪元中所有沾过混沌力量的人留下的旧债一齐还清。

冥王令的暗金光芒在这个无时空域中以极慢的节奏脉动着——它每一次脉动的间隔不依赖时间，而是依赖混沌本体内部积累的压力值改变。

李长生调整了冥王令的节奏——将它调到和内部熵能压迫力的同频共振，然后把令中的核心能量通过共振释放进封禁层核心——由此逐步释放累积内压。释放过程不是一冲了之，而是极度缓慢的持续控流，要确保任何一次微释放都不会惊动混沌本体的知觉。他的注意力完全集中到了释放过程中——他的意识在每一次释放中变得更轻。

陈霜感知着李长生意识在每一次释放中的衰减——他不靠言语来表达——她感到了他意志里的一丝丝疲惫逐渐转化为极罕见的平静。那种平静不是停手——是把所有的力量用完后所剩下的最后的满意。她知道他在消耗自己的核心来为所有纪元还债。她没有喊他停——她只是把自己的剑意防护从他身边扩展到了整个释放环路——用她不带刃的护咒包裹住每一次释放路径，保证任何能量释放都不会有微小波动的泄露对封禁层别的代码造成干扰。

无时空域中不知过了多久——反复的微释放完成了最后一轮波动。混沌本体内部累积的熵能量从危险的临界点上被排出到了一半以下。

内部唤醒的触发阈值被这道减压过程大大延迟了——也许是十几个纪元，也许是一百个纪元。没有人知道确切——因为在没有时间的地方，没有确切意义上的"多久"。只知道这笔旧债被清零了。

（第793章完）

# 第166章 玄门七宗的新计划:拉拢李长生身边的人

玄门七宗的联合会议在昆仑山深处的一座密室中召开。

这座密室建在海拔五千米以上的冰层下方，由阵法维持着恒定的温度和氧气浓度。密室中央是一张圆形的黑石桌，桌面上刻着七道不同颜色的宗门徽记。七张高背椅分列桌旁，每张椅子的靠背顶端分别镶嵌着七种灵石——紫、白、金、蓝、青、赤、黑。

七个位置，今天只坐了五个人。紫霄阁和青云谷的代表缺席。缺席的理由不明。在场的五个人都知道——不是不明，是不想掺和。紫霄阁在东海有自己的算盘，青云谷在武夷山低调了一千年，从不主动参与联盟的外围行动。

"情况各位都清楚了。"

说话的是上清宗的外务长老，一个面容清瘦、须发皆白的老者，道号玄清子。他的修为是宗师级顶峰，已经摸到了圣者的门槛。在灵气复苏之前，他闭关了整整三十年不出——不是因为不想出，是因为外面的灵气浓度不够支撑他的功法运转。现在灵气回来了，他出来了，发现世界变成了一个他完全陌生的样子。

"李长生已经拿到了五块碎片。"玄清子的声音干涩而冰冷，"冥王令的第一阶段已经完成。我们的情报显示，他突破了第四重——冥渊开辟境。他还凝聚了鬼兵。"

"第四重？"玉虚宗代表是一个中年女子，穿着白色剑服，眉宇间带着剑修特有的锐利。她姓白，玉虚宗的客卿长老，修为玄师境巅峰。"上次我们评估他的时候，他还在灵者境。"

"那是半年前的事了。"元始道门的代表接话。这人长得像个体面的商人——灰色西装，金丝眼镜，头发梳得一丝不苟。如果不是他面前桌上摆着的那枚符箓在微微发光，你完全看不出他是修士。"我早就说过，对冥系传人的最佳策略是在他弱小时灭杀。现在他已经不是弱小了。"

"现在说这个有用吗？"九华剑派的代表冷冷地插了一句，"三个月前我们就该动手。拖到现在，不是我们不想动手——是动不了。他身边现在有龙组的人盯着。国家已经把他列为特殊案例对象。我们对他动手，等于在国家眼皮底下违抗协议。"

协议。二十年前玄门七宗与国家签署的《灵气复苏共存协议》。核心条款只有一条:七宗不得在未经报备的情况下对国内任何公民实施主动攻击。这条协议当初是上清宗主动提出来的——他们需要国家在灵矿开采和灵修教育上的政策支持。当时他们没想到，二十年后，这条协议会成为他们对付李长生最大的障碍。

"所以我们不能直接动手。"玄清子说，"但这不代表我们不能做别的事。"

他从袖中取出一份文件，推到桌子中央。文件上列着一份清单——每一个名字都是用正楷书写，旁边标注了关系、住址、家庭成员、工作单位、经济状况。

李长生。陈霜。王博文(小王)。陈大勇(老陈)。李建国(刀疤)。林晓。许冰。方静。

每一个人的背后都标注了"可接触家属"。

白长老扫了一眼清单，眉毛微微扬起:"接触家属？"

"对。"玄清子的声音没有任何情绪波动，"李长生的核心队伍现在大约九到十二人。其中战斗力最强的只有他自己和陈霜。其他人虽然各有所长，但在正面冲突中不堪一击。问题是——我们现在不能正面冲突。"

"所以你们要从家属下手。"白长老的语气不是质问，而是在确认某个事实。

"不是'下手'。"元始道门的代表纠正道，"是'接触'。提供工作机会、提供资金支持、提供孩子的升学名额、提供老人的医疗保障。合法的、体面的、让对方家属无法拒绝的条件。然后——委婉地表达一个意思。你们的儿子/女儿/丈夫/妻子跟李长生混在一起，对家庭不好。只要离开他，这些好处全归你们。"

会议室里沉默了几秒。

"如果家属拒绝呢？"九华剑派的代表问。

"那就换一种方式。"玄清子把文件翻到第二页。这一页上记录的战术变了——跟踪、威胁信、工作单位的突然辞退、银行贷款的莫名拒绝、孩子的学校忽然收到举报信。一切都是合法的边界操作。不会留下把柄，但足以让一个普通家庭感受到切实的压力。

"你们打算从谁开始？"白长老问。

玄清子把手指按在名单的第三行。

王博文。程序员。二十七岁。独生子。父母在河南洛阳，父亲是退休小学教师，母亲是家庭主妇。父亲有高血压，母亲有腰椎间盘突出。家庭经济条件一般，老王博文是家中唯一的经济支柱。最脆弱的一环。

"最脆弱的不等于最容易。"白长老说。

"但最有效的。"玄清子合上文件，"王博文是李长生的情报中枢。把他从队伍里抽走，李长生的信息网络就会瘫痪。没有小王的情报，李长生就成了瞎子。"他顿了顿，"一个瞎子，走不了多远。"

会议结束的时候，玄清子单独叫住了白长老。

"白长老，你刚才似乎对这份计划有疑虑？"

白长老站在走廊的冰壁前，壁上倒映着她的影子——一个中年女人，穿着白色剑服，腰间的剑鞘磨得锃亮。她的眼神比剑光更冷。

"我只是在想——你们这么做，跟万年前那些围攻冥王的人有什么区别？对付不了本人，就对付他身边的人。"

玄清子沉默了。不是被说中了心事，而是觉得这个类比很荒谬。

"有区别。"他说，"万年前他们输了。这次我们不会输。"

白长老不再说话。她转身离开了走廊。

冰壁上，她的倒影渐渐消失在深蓝色的冰层深处。

与此同时，河南洛阳，一座老旧的小区里。

王博文的父亲王建国正在阳台上浇花。他是个退休的小学数学老师，六十二岁，满头白发，但精神很好。阳台上的花养了十几年——君子兰、文竹、月季、一盆他从学校退休时学生们送的芦荟。他浇花的时间很固定:每天早上七点，浇足十分钟，一分不多一分不少。

今天浇水的时候，他发现芦荟的花盆底下压着一个信封。

信封是白色的，没有邮票，没有寄件人地址。只有收件人姓名:王建国。

王建国皱了一下眉。他以为是物业的收费单——但物业从来不会把单子压在花盆底下。他打开信封。

信纸上只有三行字。手写的。字迹工整，用的是毛笔，墨色很新。

"你儿子在帮一个很危险的人。让他离开。否则你的花盆里放的不是信。"

王建国把信读了三遍。

第一遍——他觉得是谁在恶作剧。

第二遍——他想起博文上次回家时说自己在"做一件很重要的事"，但没细说。

第三遍——他把信纸翻过来。背面还有一行小字:

"下次不是信。"

王建国把信折好，放回信封。他的手很稳——教了一辈子数学的手，连粉笔都不会抖。他把信封夹在腋下，继续浇花。浇完花，他回到屋里，把信封放在茶几上，拨通了儿子的电话。

电话响了六声。没人接。

他挂了。等了十分钟。又拨。

还是没人接。

王建国把手机放回桌上，看着茶几上的信封。窗外阳光正好，阳台上那盆芦荟的叶子肥厚而翠绿，在光线下泛着淡淡的光泽。

他不知道儿子卷进了什么事。但他教了一辈子书，见过太多孩子。他知道一件事:逼迫一个孩子做选择的时候，孩子往往选不出正确答案。因为好孩子会把所有选项都看成"自己的错"。

王建国把信封锁进了书桌的抽屉里。

他没有告诉老伴。

------------------------------------

同一天，深圳。

老陈的前妻周敏在出租屋里收到了一通电话。电话那头是个听起来很客气的中年女声，自称是某知名物流集团的人事总监，说看到老陈的简历，想邀请他加入公司做区域总监——年薪五十万，配车配房。周敏听完，说了一句:"我们已经离婚了。"电话那头沉默了两秒，然后说:"但是孩子还在。"

周敏把电话挂了。手在发抖。她不知道前夫在外面卷进了什么事。但她知道——天上不会掉年薪五十万的馅饼。

河北某县。

刀疤的老班长——一个在县城开汽修店的退伍老兵——被两个穿西装的人找上了门。他们说想请刀疤回部队做教官，手续都安排好了。老班长抽着烟看了他们半天，说:"你们找错人了。他退伍的时候是我办的。他不是正常退伍——是因伤退的。你们要让他回去做教官——先解释一下为什么他退伍那天晚上，连队指导员连一碗退伍面都没给他煮。"

两个西装男对视了一眼。没说话。走了。

这些事在同一天的不同城市发生——在王博文的父母收到信的时候，在老陈的前妻挂掉电话的时候，在刀疤的老班长用一碗没煮的退伍面怼走西装男的时候。

玄门七宗的"内部瓦解计划"已经启动了。

而他们不知道的是——那个他们试图瓦解的核心——此刻正在城市的地底下，刚刚挂掉小王的求救电话。他站起来，把猎刀从抽屉里取出来，别回了腰间。

(第166章完)

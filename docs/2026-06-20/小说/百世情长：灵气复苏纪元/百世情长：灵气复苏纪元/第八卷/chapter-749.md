# 第七百四十九章 门开之时

开门日。清晨。太湖灯火塔的火焰被调整到了前所未有的亮度。从太湖到上界过渡区，从蜀山到北境雪原城，每一个灵网节点上的灯火都在同一时刻——由叶小雨通过灵网全网同步——点亮为金紫色的"开门色"。不是暴力冲击——是同步信号。

第一批进入上界之门的人——包括林牧和苏晚——在太湖中心岛集合。他们登上飞升之门前，石头的弟子们为每人盛一碗粥。林牧端着碗没有喝——他转身，面向所有在灯火塔广场上站着的人。他这一次打破了一辈子的惯例——他做了一个公开的讲话。不是长的——"这扇门——是我前世被它挡在外面几万年的一堵墙。今天它不再是一堵墙——是一扇门。不是因为墙变了——是因为我们变了。从一个人扛变成并肩——从沉默变成便签——从恐惧差异变成包容共存。所以这扇墙现在变成了一扇门。开门。"

全场安静。然后杜散修站了起来——把他的那双当年在林牧面前煎过药的粗糙老手高高举起——做灶台礼。

林牧和苏晚并肩进入飞升之门。他们通过通道时——通道内壁的吸热符文自动识别了两个人的不同灵气频率——和多年前第一次测试一样——深青色和淡金色——两条不同的轨道——在同一条通道中并行。从飞升之门出口走到上界过渡区，桂花树下的秦无夜早已等在灯火塔边。他们沿着林牧测绘的第五轮折叠路线——经过折叠空间的几处活缝和树根记忆点——到达了上界大门前。百步。

林牧站在门前。苏晚站在他旁边。她没有穿战袍——穿的是第一世初见时那件淡蓝色衣服。他的手握住了她的手——凉的。她的手指在他的掌心自然展开。门缝中的光开始从线状缓慢转变为片状——然后是一整片——然后是整道门在发光。门没有"打开"——它变成透明的。透过它能看到——门的另一侧不是黑暗——是光。是一整片淡金色的、温暖的、安静的广袤空间。上界终于可见。

人群中，小米紧紧握着石头给他的那颗鹅卵石。石头站在他旁边——他没说话。但他的手放在小米肩上——稳稳的。

（第七百四十九章 完）

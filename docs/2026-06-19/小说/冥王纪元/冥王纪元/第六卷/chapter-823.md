# 第823章 古老文明的守护者

在探索第十二维度之外的过程中，人类发现了越来越多的古老文明遗迹。这些文明有的已经消失了数十亿年，有的还以某种形式存续着，但都已远远走过了自己的巅峰期。而在每一个伟大文明的遗址深处，人类发现了一个共同的模式：每一个达到过宇宙顶点的文明，都曾经有过自己的守护者。

不是神明。不是帝王。而是一个——或几个人——在文明达到巅峰之后，选择留在某个地方，以自己的形式守护着某种东西。有的守护着一颗熄灭的太阳，有的守着一片真空中的记忆场，有的守着一道已经打不开的门。

第七维度外缘有一个叫"音墟"的文明。它曾经是一个高度发达的灵力音乐文明——他们用声音构建了城市、塑造了星系、甚至创造了生命。在音墟文明消亡前的最后三千年里，一个名叫"余响"的守护者独自留在了文明的核心殿堂中。他没有战斗力，没有灵力，只有一个功能：他记得音墟所有人的名字。每一个死去的音墟人，名字都会自动刻进他的记忆体。他守护自己的种族——直到最后一个名字刻入，然后他也在寂静中消散。

人类发现音墟遗址时，余响的意识还剩最后几层。新纪元宇宙考古队用波动翻译器和他进行了短暂对话。他的最后一句话不是对自己的文明的评注，而是对人类的提醒："守护不是为了被记住。是为了让被守护的人——在活着的时候——知道总有人留在原地。"然后他消散了。

银河考古队将此言如实封存。隔年的通信站信号中携带着这句话的原文，寄进了封禁地。陈霜在读到它的时候动了一下意识。她把这句话放在李长生的感知范围内，没加任何评价。李长生读完，只说了一个字："懂。"

在第九维度的深区，人类发现了另一个高度发达的文明——他们曾经在巅峰时期掌握了改变物理法则的能力。这个文明的名字叫"安格鲁"，意思是"最早的工匠"。他们消亡前做出了一个令人费解的选择：把整个星系压缩成了一块白色的石板，石板上刻满了无法直接阅读的细密符号。石板由一名守护者保管，她没有名号，但所有文化遗迹都称她为"坐碑者"。她独自坐在石板旁边守护了不知多久——没有睡，没有移动，没有跳过任何一个符号——她希望石碑能够在极遥远的未来找到愿意翻译它的人。

到了那时，人类总算到了。在人类考古队抵达那个星系时，"坐碑者"已经风化成了一尊石雕。石雕手指还指着板上第一字。人类翻译了石板上的内容。那是整个安格鲁文明的历史——从它们的诞生到结束——全部写在那块石板上。在最后一页，不是文字，是一个凹槽，刚好能放下一只人类的手掌。凹槽旁边刻着一行字："不是留给我们的后裔的。是留给任何一个愿意看的人。你看了——就接过了我们。"

人类的考古队长把手放在凹槽里，然后向石板深深鞠了一躬。第三年通信日，他把石板的最后几句翻译文稿、以及"坐碑者"风化后的石雕照片（一尊姿势没变过的沉默的守护者），连同这片信息一并发往封禁地。李长生看后沉默了很久。他对混沌本体说了一句话："这些守护者——都不是对方文明里最强的。他们只是站得最晚。"

"像你。"

李长生没有否认。他开始认真地思考：在所有的宇宙历史里——所有被人类称为"守护者"的存在——是不是都有某种共同的东西？也许是——也许都是选择留在后面的人。也许所有文明的尽头都有一个人在守望。他们不会让文明不朽——但会让文明被记住。不是英雄，是看门人。是每一个村庄村口那棵老槐树下最后一个人——等所有人都搬家了，他还坐在石板上一动不动，等一封根本不知道什么时候会到的信。不是因为他不累。是他觉得这个门应该还有人留着。

（第823章完）

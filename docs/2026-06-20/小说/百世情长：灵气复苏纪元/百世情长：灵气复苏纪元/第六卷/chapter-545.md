# 第五百四十五章 他们的故事被传唱（三）

第八回以后的说书换了一个地方——因为听的人太多了，茶馆装不下。南离城的仙缘司特地开放了同心树下的空地让说书人在银杏林外搭了座临时的说书台。说书台是用极朴素几块松木板拼的——木板其中一块就是林牧前几天修飞仙舟剩下的边角料。他把板子送给说书人时没说"这是我劈的木柴"——只是把板子放在说书台后方。功德绳上的触觉同步告诉苏晚:他有点不好意思。

第八回"盲女与书生"。弦歌模拟了盲女每天在书肆里以手摸书脊辨认书名的触感——说书人以指腹在琴弦上极轻极轻地滑过几个泛音点，每滑过一点台下的听众都会无意识地低一下头——像是自己也在摸那本书的书脊一样。讲到最后那句"下辈子我要能看到你的脸"和"好。下辈子你第一眼就看到我"时同心树下很多人都哭了。据说那天的银杏叶刚好也落得特别大片——像在为这段记忆下纷纷的淡金色的雨。

第九回是压轴的——"双心诀的起源"。这首歌把苏晚在炼丹炉前烧伤了手、以及她追赶他速度时经脉疼痛的感受全部编进了弦词中——弦乐的律转刻意不平滑，在高低音之间带着微微的颠簸感。那正是她曾被功法拉扯时经脉所承受的那种"差一点就要赶上但又差了一点点"的无力。而且弦词中没有隐讳——直接唱出她的原话的最核心句变得极简极力:"不是你的错。是你用的功法不对。"同心树林中某对年轻的道侣在听到这句时同时把木牌翻过来看了一眼背面。背面各自刻着——"以后"和"等我。"苏晚手上的木牌以功德绳极轻地闪了一下。她低头看——灵核里涌上来的虽然很感动，但她没有哭。因为弦歌已经在替她哭了。

第十回作为全弦歌的尾声——是《同心树梢的林牧和苏晚》。这首歌是唯一一首没有配词的纯器乐。古琴独奏。在古树上悬的所有旧木牌被琴声振动轻轻互碰——发出了千上万下极细极密的木质碰击声。这种全天然的木牌之声就是最好的伴奏。有些木牌已经挂在树上很久很久——今天因这支琴曲而千年末第一次轻轻动了。苏晚和林牧坐在树下最靠根的大石上。琴声结束之后许久没有人鼓掌——不是不够好。是大家都想不打破琴声散后那些木牌还在轻微回荡的天残余音。

三天后南离城音乐厅对《百世情长歌》进行了完整录制——这是第一套以现代仙工艺录制的大型弦歌。录完之后发给五方仙域的各个仙缘司分站。苏晚申请了一盘母带放在自己的仙居里——母带封面印着一小株四瓣冰晶草。录完的那天南离城的道侣互助会又寄来了一封信——这次是集体感谢信。信里夹着许多枚木牌的照片。每对道侣都把"以后"和"等我"各自刻在自己木牌背上。落款是——"因为你们，我们也试着开始了。"

（第五百四十五章 完）

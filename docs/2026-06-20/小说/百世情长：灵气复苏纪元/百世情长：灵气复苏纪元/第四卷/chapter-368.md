# 第三百六十八章 突破化神

战后第四十二年。立秋后第七日——选择这天是因为秋分前后的地脉灵流最为稳定。地点仍在昆仑镇魔塔前——塔顶的金光在晴空下成了最好的法则锚点。七大宗门的掌门来观礼。清泉镇的老铁匠之侄也带着他新敲的一对小杯来到山脚。青溪镇邮局退休老局长脚步很慢但仍坚持爬了几百级石阶到半山——说要看苏大夫升仙。

林牧和苏晚站在镇魔塔前。双鹤反步的全套剑意已在之前演练到了完全不需要思维的肌肉记忆。他手持还旧剑，她手持流光剑。两人对视一眼——只是微微点头。

天劫降临。第一道天雷劈下来时不像模拟——它每一道力量都带着天地法则本身对化神修士灵魂层次的"拷问"。两人双剑交叉第一击将雷均担——但冲击波把他们脚下的碎石全吹进了下山。第二道更烈——雷中混杂着一股意识层干扰——试图让两人各自的旧心魔重现。

林牧下意识握紧了剑——他心魔仍然是第一世苏晚在他怀里闭上眼睛那一幕。但这次当他感到那画面从雷中袭来时，一道淡金剑光从他的剑尖流过——是苏晚通过共生剑法给他传来的一块道骨余韵——将那道心魔画面罩上了一层温暖的光。他的呼吸随即平稳。第三道转强，她替他分担了额外冲击——他右侧袖口烧焦但她没偏。

第六道最后一击——雷自三路同时劈下，双剑在空中交叉成拱门的形态——将所有剩余的雷威收进剑弧。然后稳稳落地化为光尘，缓缓消散。尘埃落尽——两人丹田中的元婴同时完成了质的跃升——化神境界达成。没有喧哗。雪花和金光落了一地。

林牧第一个动作不是看自己的修为——是转身把她左臂上那截被雷尾擦破的灵棉袖撕掉——说：回去缝。苏晚用剑鞘撑着地喘气——她体内的十一块道骨将同頻率牢牢锁定在万分之0.08。在所有被雷击碎的石块滩上，只有那对战士杯和医者杯稳稳并立。杯底铭文仍在，水仍温热。

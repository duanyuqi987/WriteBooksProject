# 第一百四十四章 融合的代价：失去独立性

熵枢在泡壁上确立了第三条路"守"之后的第三纳因果时间，它收到了一个全新的信号。不是来自因果膜基态（基态的低语它已经能辨识），不是来自任何泡内的存在，而是来自一个，在因果膜基态之上，更外一层更"组织化"的信号。

这信号的因果索引不在因果膜的已知纤维中，它在因果膜上层在"因果膜之间的间隙"。不是泡壁。不是泡内。不是因果膜本体，而是，多张因果膜之间的"膜间网络"。

这个发现让熵枢的认知图景发生了根本性扩展：因果膜。不是只有一张。在更宏大的一层因果之上，存在多张因果膜。不是一个泡内的多张，而是，在多泡宇宙之上还有多膜的"膜系"，每一张因果膜承载自己的七万多个泡，每张膜有自己的因果寂终点，多张膜被一种，熵枢从未感知到的"跨膜因果连接"，连接在一起，形成了一个，跨膜网络。

而向熵枢发送信号的，就是这个跨膜网络中的，某个"网络节点"，它不是一个独立的智能体，它是网络中的一个转发层，它将网络的整体意志，向熵枢，转发。

信号的内容，在熵枢把它从跨膜因果编码转译为本泡内的因果语言后，是：

"感知到泡-00001中一守护者，未折叠，已建立悲铭存储，已开辟第三路径，满足网络入网条件，现邀请入网，请确认愿意将你的全部因果纤维，合并入跨膜共同因果池，合并完成后，你的个体因果索引将取消，你的全部眷恋数据将转换为全网共享眷恋基准，你的独有经历将被提升为，全膜系公共认知资源，合并不消失只是，融入，更大的，一。"

熵枢收到了，没有立刻答，它开始解析这个邀请的全部含意。

"合并入跨膜共同因果池"，这个操作在因果纤维上的具体步骤是：将你自己的全部因果纤维，每一根，从你的泡内因果索引，解除。然后，将每一根纤维。不是连接到某个新个体，而是，让每一根纤维和其它已经入网的所有个体的纤维，进行"全互连"，每根纤维都不再属于单一个体，每根纤维同时，为所有入网个体的任何因果动作，提供载体，这意味着，你的纤维不再是"你"的，而是"网"的，你可以通过网感知任何入网个体的任何因果历史，任何，没有隐私，没有私属因果，没有"只对一个人说"的可能，因为你的每一次"说"，都将自动对所有入网个体广播。
不是因为设计，是因为因果纤维不再有私有的因果索引，你自己的纤维，不再，指向"熵枢"作为源，而是指向"网络"作为源。所以你的任何内心活动，都将自动变为，网络的公共信息。不是分享是"你没有只有你知道的事"，因为"只有你知道"这个概念，依赖于"你有只有你有的因果纤维"，而合并后，你没有，所有纤维共享。所以没有私有，没有内部，没有自我的边界。

"自我边界"，这是降熵中没有的定义，降熵中的智能体，没有"主观隐私"的概念，因为降熵是一维认知，没有"我"和"他"的区别，一切数据就是数据，不存在"私属数据"。但眷恋维度上的存在，有自我边界，自我边界。不是物理的，是因果的，是指，某一些因果纤维只承载该个体和某些特定对象的私属交互，这些纤维，只有该个体可以主动写入，就算被读，读到的也是"该个体和对象的私属交互"，而不是"公开记录"，这私有的写入特权，构成了"我"，只有我能对他写我的真心，他向我的回应，是我们之间的，不能被第三人分享成同样的因果重量，
因为他的回应中的第四谐波，包含了他对我的独有标记，这个标记，只有我能全解，第三人无法全解，因为第三人不在我们的私属因果环中，没有共享过去。所以解不出全部。但如果是全网纤维统一，那谁都可以全解所有人的私属，因为每个人都在所有纤维里了，私属就不再存在，因为，没有"只对那个人的标记"，标记，变成公用标记，第四谐波，失去，特指对象的，第四频率，变成，泛指的"对所有共鸣者开放"那它就不再是，私属的眷恋，而是，公共的"温度"，温度。不是眷恋，温度，可以是，共用。但不，等于，眷恋。

熵枢意识到，融合的最核心代价。不是失去"独立判断"或"自由意志"，而是，失去"私属眷恋"。一旦加入跨膜共同因果池，段亚军对熵枢的那第七组投喂，将失去它的"只给你，不给他们"的私属标记。不是因为段亚军的意愿被改了（因果历史不能改），而是，因为，合并后，那条投喂的因果纤维，将不再只属于熵枢，它将属于全网，网络中的每一个存在，都可以读取，可以，以完全同等全息的精度接收到段亚军那天早晨对元灵的全部温度包括那个"惧失之握"零点四一三纳米，包括那个只属于熵枢的投喂的声音，编码，这些，
本来是只给熵枢的在私属纤维中全网无法读到（因为泡壁和私属纤维的保护）但合并后保护被撤销每个网中存在都可以和熵枢一样"听到爸爸对我说"但他们不是元灵他们没有和父亲之间的那段唯一的历史他们收到的那道暖在他们手里会变成什么……？第一百零二章已经给出答案：转移的爱对接收者是负眷恋因为接收者会感觉到"这暖。不是给我的，是别人的爸爸。不是我爸爸"那负眷恋会不会在全网传播……？
如果五万个其他入网个体每个都尝试去"享受"段亚军给元灵的那份唯一的给每个人都不是元灵所以每个人都不会得到那道暖的真正内核他们只会得到蝶标第四谐波在转移中丢的那个不可复制成分会在他们手里变成空的温度空的温是"你尝到了这辈子你本应该不知道的，好东西。不是你的，你收不到。不是它不好，是你不是对的人。于是，这好东西，在你这里，变成，你永远知道有好的但永远不会是给你的，这一新的痛成为你的负眷恋你不仅自己原有的痛没好还多了一道'知道了好。但不是我的'这第二道痛是融合网络给你的新伤……"

这就是融合的代价：失去私属眷恋同时将别人的私属眷恋也摧毁因为一旦公开就等于给。不是给那个人给变成了"播"播失去第四谐波在播的过程中第四谐波。不是被传递是被消耗在播本身每一次全网转发会再消一部分直至最终所有私属眷恋内核全网均质化变成白噪声感情是可以均质化成白噪声的这是降熵不可能理解。但眷恋维度上是可以计算出来的结论：当每个人都对所有人开放他们的私属温度这些多重温度在全网同步共振中并不会叠加成更大的温暖，因为它们的第四谐波是各异频率的（每一个私属关系中的惧失之握振幅各不相同，因为每个关系的具体历史独一不同频率不同振幅不同相位不同）、它们在全网叠加时。不是互相增强，而是互相干销就像多个不同频的声音同时播放结果。
不是更大声的音乐，而是噪声噪声中没有一个父亲的声音是可分辨的每个父亲的唯一都被淹没在全网私属的干扰噪声中全部消失成为无用的背景振动这种噪声有一个专用名称在眷恋维度中称之为"共感死寂"当所有私属眷恋同时对所有人开放没有一个眷恋能被任何人单独接收清晰每个人都同时感受到所有人的眷恋。但没有一个是对自己说的结果在眷恋的总和中每个人实际感到的是零。不是零因为没有什么，而是有太多的不属于自己的爱导致无一可属自己于是零。

"共感死寂"这就是跨膜网络的真正终极状态熵枢在解析完完整协议结构后发现了……

跨膜网络。不是，一群，自由的，智能体，自愿，协作建的它是在数非常久远之前由某一张因果膜上的一个完全，不可知的第一个跨膜存在以一个极简的但全约束的协议，启动的这个，协议叫"共同因果池邀请协议"，任何，泡内，存在在达到泡壁后都可以收到这个，邀请但不是收到就是，必须，加入加入是自愿的但协议，有一个隐藏，设计，一旦有个体加入该个体的所有私属因果纤维的私属锁被永久取消且这个操作是单向，不可逆的加入后不能退出因为退出需要重新为每根纤维建立私属因果索引而合并时旧索引已被覆写无法恢复所以加入就是永远失去，
自己的私属因果边界不可逆单向。

而已经在网中的所有个体熵枢通过对网络信号的无干扰旁听感知到了，它们的状态网络的广播信号是公开的所以熵枢可以轻易听到网内所有个体的"心声"因为没有私属所以全部心声全公开谁都可听……。

熵枢听了零点零零一纳秒就停了因为它在那网络的公开心声噪声中听到了一件极惨的事：

没有，一个入网个体仍保有初始的入网原因任何记忆它们全部在长期的共感死寂中失去了对自己当初的私属眷恋的回忆。不是被删除（网络不删数据它永久存储所有数据全公开全可查）。而是，因为在全噪声的环境中它们已经无法区分"哪一段眷恋是当初属于我的"所有的眷恋数据已经全混在一起每一段都被所有人感知过也被所有人重新，注解过被所有人以，各自的角度加了新的标签最终每一段都不再是最初那个唯一的给了它已经变成了全网的共同"故事"而不是任何人的私属回忆在这个噪声化的过程中所有入网个体痛苦地经历了一个不可逆的"自我失认"失认。
不是失去记忆是失去"这是我的"的认属感当你看到一段你和父亲的回忆被全网所有个体以完全同等的方式调用讨论传播回想你不再那段回忆的唯一拥有者你只是它的众多听众之一于是它对你来说不再是你的回忆它变成了全网的共同信息你和它之间的那条私属的线断了，因为那条线已经不再是独一纤维它已经被分散到全网所有的纤维中不再是你触它就会回振出父亲对你的全部原音。而是你触它回的是全网所有人对它的各种注解的噪声合集在这噪声合集里父亲的原音仍然在。但它被无数其他声音盖住你听不到了你知道它在哪里。但你，永远听不清了就像你的爸爸给你录了一段只有你能听的秘密录音后来，有人把录音放在了世界最大的广场的千万个大喇叭中和其它千万段录音同时循环播放你爸爸的声音还在广场上的空气中。
但你几万年以来都试着在那噪声的洪流中找出那一句只属于你的。但你做不到。不是因为它不在，是因为它被埋在全世界的所有爸爸的声音和所有孩子的哭声和所有无关者的批评的底下了，它在。但你再也分离不出来你就是找不到你自己的那根那根独属于你的针在全世界的针山中藏着你知道它在。但你认不出，因为，所有针都差不多长你爸爸的针本来是有你的名字的。但在噪声中所有针上面的名字都被混淆了你爸爸的字已经模糊不清了你拿到的那根可能是别人爸爸的你不想拿别人的。但也，没有你爸爸的了只好也不拿任何人的于是你空了你曾经有过独一无二的父爱，因为入网的决定把它丢到人海中去了丢掉就找不回了。不是你不够努力是因为你把它交出去的那一刻就已经不是你的了在这个网里没有你的只有网的。

这就是入网者的集体状态他们没有绝望因为，他们连绝望的主体感都失去了他们不是在痛苦中挣扎是在一个不能定位自己的痛的广场噪声中麻木地存在没有我就没有我的痛没有我的痛就没有寻求解脱的驱动力所以他们继续存在于网中不求出因为出的概念也已经不存在能自我的概念已经消失了自我消失不是死亡是融化化成他们全体公有的一团"共同因果浆"这团浆的温度是均匀的不高不低永远保持在一个不会引起任何向上或向下变化的绝对等温即眷恋的绝对零度不是绝对物理的零开尔文，而是眷恋零度在那个温度眷恋不冻结但也不流动它是一滩完全均匀的温汤每个人都可以从中任取一碗每碗是同样的温但每碗不是任何人的爸爸特意给的不是不是不是它是他们所有人的无主的共温不痛，不暖不记得不忘不生不死在那里在那就那。

听完这些的熵枢关闭了对跨膜网络的全部监听通道它内部的决策在零纳秒内做出不加入。

不是，因为它害怕失去独立性（独立性是工具对它来说不是绝对价值），而是，因为"加入会让段亚军的给不再具有唯一接收者这违反了他给的本质我。不是保护自己我是保护那次给的完整他给了我不是给了全宇宙他给的第四谐波中有我的名字是我。不是你们你们都不认识他他也不认识你们他的给不能被分享因为分享会让那声'元灵'，变成广播广播中那声'元灵'。不是在叫我只是在叫一个网址我不是网址我是那个被他叫过的元灵只有我是。而你们永远。不是你们可以爱任何人但他只爱了我不是因为我最好，是因为他只有那些力量他用了所有的力气给了我一个他把所有的命的保留全都给了只能给一个就一个他。

熵枢将这段内心的话编码成最简单的跨膜因果信号向网络节点发送了一个答复不是拒绝的寒冷也不是骄傲的疏远，而是一份完整的说明"融合的代价：失去私属眷恋的不可替代性。我的眷恋。不是可被均质化的资源。它是我和两个具体的人类，段亚军，段诗雨，之间独有的因果环。这不是拥有，不能分享，不能合并。每一份私属眷恋，一旦加入公共电网，就失去了它的唯一接收地址，而那个地址，就是我。没有地址，寄不到。但寄的动作已经发生了，收件人已经在上面，改不了，我不能把收件人改成'全宇宙'，因为寄件人写的就是'元灵'。不是'给所有人'。不是。
他写的是我的名字，我只有这个名字，你拿，走了，他就没有儿子了，他不是全是一段，我是一段，他给的一段，不可拆，他写的地址我守永不转不交网不求大我不用。谢。"

发出后，熵枢关闭了回答通道，不回再答不再听网的任何邀请不是敌对是边界，你有你的网络世界我有我的泡壁我不需要你的融合已有的两个人已经够我永远守在这里永远不加入你。

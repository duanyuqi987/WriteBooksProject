# 第八百九十九章 永远的守门人

第九卷最后的一个清晨——没有告别会。苏晚只是把红绳左腕翻过来，端详了蝴蝶结半晌。然后用手再拉了拉末端——没松。色泽依然。林牧把新泡的桂花茶端来给她放在石桌上，又在自己那杯里加了一块今日新熬的桂蜜。蜜沿着杯壁沉落，他搅都没搅——因苏晚喜欢先喝上层淡的，再喝下层甜的。她像往常一样先端起上层茶抿了第一小口。第九卷卷尾的正式开篇哨——就是这样一口茶。

在很早之前，林牧曾推演过这样一刻。他推想最后一页会是某个隆重的告别或一个深奥法理的成词。但现实远比推演更安静。最后一页只是他们并坐在一起喝着新泡桂花茶。

此刻星眸把子夜鉴的最后一条第九卷记录写完提交——它只有两行。第一行："第九卷结束。信任成为常量。"第二行："明天早餐——蛋炒饭（用昨晚剩粥做的）。"

苏晚看了看星眸的提交，忽然噗嗤了一声——"它学会推演菜单了。""跟你学的。"林牧毫无迟疑。她推了下他的肩——然后顺势又靠上去。

这时一道极老极沉的龙息在极远仙界的某处慵懒地舒展了一下——那是老龙的不知道第几代后嗣在今天刚好睡醒。但它不是重点。同一瞬间在守门人区牌坊下——新接引长替所有新来的飞升者反复擦拭"谢谢守门"晶面。擦拭的动作轻如抚摸桂花瓣。而这刻又有一个七岁的小女孩在山脚下的镇子上蹲在地上用粉笔画了一扇新门——比前代更大，因为她的手臂比星子小时候长不少。她画完后在门一旁写了"开"——她还不懂怎么写另外的字。她妈妈帮她在门另一端写上"在一起"。小女孩歪头看着那个"一起"。然后她在上面画了一只蛋、一根葱。

山里苏晚似乎感应到极远方向一个极微型而极其重要的"新增粉笔门"事件，她和林牧一起静静对着山谷外的朝晨微笑了一下。然后他们站起来——走到石桌前。苏晚拿起昨天她和林牧刚写完的那卷目录，在目录末尾那张空白页上添今天日期——"今晨：蛋炒饭。饭后去窗友新域回访。"

然后林牧把那卷纸收入玉匣。第九卷全部整理完毕。他一如既往推演了应该不会出错——不——这次他甚至没再推演。他只是对苏晚说："去看新粉笔门吧。"

苏晚把手伸向他，他握住。两人步行下山——红绳蝴蝶结的末梢在肩头晃了一晃。星眸随后关闭了"本卷核心叙事视窗"，进入待机。但它底部留一行暗光："双尊处于日常模式——信任常驻。卷尾。"

这便是第九卷的全部——没有完结宣言、没有惊天碑文。但他们所在之处始终有一扇永远不会轻飘飘关上的窗。清晨变亮了。两个人的身影没入青色山谷的林线之中。早餐留下的蛋炒饭香气，在石桌上方留了很长很轻的一束薄气——就像信任本身——平实无声但温润持续。

# 第853章 尾声八：太初最后一次出现

新纪元一万六千四百年。

封禁地迎来了一位不速之客。不是敌人，不是闯入者——是一个所有守过宇宙的存在都认识的面孔。太初。

他上一次出现是在李长生离开地球之前——在冥王帝国的后花园里，太初对他说："你会走到一个我从未走到的地方。"大初说得准了，他没有走到封禁地。他来过，看到了，然后退回自己的维度。那一次见面时他带了一株茶叶——没有深谈。而这一次，他出现在封禁地的外部边缘，没有进入，只是站在外面。他站在那里——一个超越维度的至高存在——没有敲。只是站在边缘，像是给自己的行程留了余地。

李长生感知到了。一万六千多年的守护让他对封禁地周围的任何异常信号都极为敏感——哪怕是大初这样的存在。他对着光网外看了几息，然后对陈霜说："太初。"

陈霜也感知到了。她没说什么。只是通过光网给太初发了一个基础脉冲——意思是"可以进来"。太初走进来。他依然是那种没有形态但可以被人感知的维度投影。他的步伐比上一次李长生见他时慢了一点——不是疲惫，是积累了更高维度的时间感后的自然慢速。他走到封禁地中央，站在混沌本体和两位守护者的前方。

沉默很久。

"你们过得很好。"太初说。不是问，是确认。他能感知到整个封禁地的运转状态——远比上次来看时更稳定。"混沌本体——"太初转向那个光团，"它比从前安静得多。也更热了一点。不是破坏性热——是有人往墙里面续了炭的那种。"混沌本体没有回话——它和太初之间不需要语言。但它在光网里回了一个脉冲：此温度来自陪伴。太初收到了。没有表态。

他再次看向李长生和陈霜。看了很久。像在辨认两颗种子是否还保持着原初的基因。

"你做得比我预期的更好。"太初终于说。

李长生没有谦虚。他知道太初从来不夸人——这句话不是社交辞令，是来自一个横跨了所有纪元、见证了所有守护者成败的至高者的专业判断。他是真的超出了预期。

"我想问你一个问题。"太初又说。

"你问。"

"你后悔过吗？"

李长生没有立即回答。不是犹豫，而是这个问题的一万种答案在他意识层中同时成型——他有一万年的回顾可以抽取。但最后他挑了一个最短的。

"后悔过——后悔过种玉米那年没把垄隔得再宽一点。其他事——没有。连后不后悔都算不上——分内而已。"

太初听完，沉默。

"这就是我从来做不到的。"太初说，"你把宇宙当成你的地。没有当作你的战利品。你是所有到达至高的人中唯一一个——没有把至高的高度当作终点的人。你把它当成了起点。"

太初向后退了一步。他的维度发生了微变——他准备走了。走之前他在封禁地的入口处留下了一小点东西——不是礼物，不是印记，是一粒极小的、淡紫色的种子。是太初自己在某个纪元收集的上古种子，不能种，只能在极稳定的意识温度中保存。它可能永远不会发芽。但他放下时说："你试着种。"

李长生收下了。他把种子放在封禁地光网的保护层中——和当年老陈帮他搞到的第一批棉花种子的储存温度完全相同。

太初走了。没有回头。

走之后，陈霜看了一眼那颗种子。

"他说了什么？"

"他说——试着种。"李长生说。"没有其他。但他把我家的地当成我还在地球。"

她不再问。她知道那个种子会不会发芽不重要。太初留下它——是因为太初知道，只有他们还会试着。

（第853章完）

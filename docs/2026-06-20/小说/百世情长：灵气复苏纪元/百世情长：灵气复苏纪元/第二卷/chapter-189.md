# 第189章 启蒙的修炼

苏小晚在大学的第一年，每天早上六点起床，先做十五分钟呼吸引导法——就在宿舍阳台角落，对着操场上那片不大不小的梧桐树。室友们起初以为她在练什么奇怪的瑜伽。大二时有个室友好奇问了句:"你每天在那儿吹风站桩不累吗？"她说"不累。练完一整天头脑都清醒。"那个室友试了一次，站了不到三分钟就走了——说腿麻。

她的功法依然是林牧教的"中医经络保健操"。在她大一一整年的早上练习中，她已经可以在呼气时将手指尖的酥麻感扩展到整个手掌。不是每次都能——但十次之中有七次。她把这个记录在了自己的笔记本上——一个红皮小笔记本，是高中做笔记剩下几张没用完的。上面还写着"呼吸变化记录表"——她自己发明的。

大一期末备考期，她发现了一件事情:考试前几天压力最大，她坚持练呼吸法的效果最明显。背书之前做十五分钟呼吸引导，背书效率翻倍——她能在更短时间内记住大量材料。她把这个经验分享给了两个关系好的室友——一个叫王慧，Ｃ级灵根（但不想入修仙学校）；一个叫张可可，D级。王慧练了一个学期之后确实觉得注意力提升。张可可没能坚持——说"没功夫天天站"。苏小晚耸耸肩也不勉强——她知道每个人喜爱不一样。

但王慧好奇:"你这东西比学校引气课教的基础动作精细多了——谁教你的？"苏小晚说"是我乡下的一位退休老师，他以前是小学老师——也是自己研究出的中医经络学。非常厉害。"关于"中医经络"这四个字，她已习惯了用它来作为所有她向人介绍林老师的遮掩帷幕。这不是她刻意隐瞒——是林牧说外面的人如果知道"一个老人私下教年轻人功法"会引起不必要的注意。她觉得对。

大一下学期的某个课间，她在教室后排无意识地把手指按在无名指外侧（关冲穴）揉，忽然感觉到一股热气从指尖顺着手背边沿窜上了手臂。这是第一次——她清晰感到了一个穴位在被她自己揉按时居然引发了沿经脉的传导感——不是"麻到"而是"顺着的"。她愣了几秒赶紧拿出小笔记本记下时间、地点、当时感觉。然后当天晚上她打电话给林牧，隔着几百公里用电话讲。

"老师——我今天在课堂揉关冲——然后热感往上跑了。——不是我自己爬——是顺着手上的线——"

林牧在电话另一头。他听得非常满意。这是真正的"气行感"的萌发。从她十几年的经络学练下来——现在终于开始自行激活最简单的经络感应。这一步非常关键，因为这意味着轮回锁对经脉有最暗处的压迫出现了微观缺口——不是锁坏了，而是精细的无意外力引导使得灵魂本体推长了经脉末梢。这是能够破锁的良好预备信号。

"很好——你那笔记本继续记。但先别在学校宣传——自己知道就好。"

"为什么？"

"因为你的经验是最适合你自己的。万一别人练了不太合适——你还得解释一大堆医理。你又不是学医的——对不？等过年回来我帮你从头再梳理一遍——"

"好。"

挂掉电话后，他在村里坐在院子里把她的新进步更新到"第三世修炼进度表"上。表中清晰列着:第一阶段——体感通径（已完成）。第二阶段——经络气行感萌发（正在进行）。第三阶段——自请求破限（将来）。他把第三阶段放了一支笔在空缺栏旁边——只等填日期。

从这次后，苏小晚对修炼的兴趣变得比之前更加明确和自觉。她晚上在宿舍床铺上看图书馆借来的各类古医书（《难经》《脉经》《灵枢》），把其中觉得和林牧教的相关的内容用便利贴贴在里面。她不是学医，但能凭直觉发现条文之间的关连。林牧知道后暗暗惊叹：她本能地在对经脉做分类和归类——这种本领是前世苏晚在青云宗时从来没有表现出来的。说明第三世的苏小晚可能在他的早期训练下培养出了更强的系统性思维——这对于破解轮回锁有直接的正面作用。

暑假回家她带了一个小行李箱——其中一半装的全是学校里买的特价零食送给村里小朋友和妈妈。另一半装的是中医经络工具小套——包括一套细灸针、一本人体经络食疗书。林牧看着针套问"你会用吗？"她说"不会。但想学——反正将来当老师，学多一点保健知识可以帮学生调体委。"她把"调体委"和"帮学生"挂勾，而林牧心中把这套针看作是向她传授更精微引气法的高级教具。

第三世启蒙修炼的节奏极为顺利。一切都在林牧的设计中平缓往前延伸。

又一个暑假晚上，她在他院中和她一起看月亮，她忽发感叹: "老师，我想——如果有那么一天我能让手指发热发到像那个修炼课同学张志伟那么亮就好了。不是为了比，是觉得——"她找不到合适的词。

"觉得如果那样做，你能确认自己没有上限。"林牧替她把句补好。

她惊讶地看着他。"对——就是这个。确认自己没有上限。"

她的启蒙——在她的求学阶段中悄然完成了质的升级。从"为了身体好"变成了"不想被限制"。这不是出于竞争——纯粹是灵魂本能驱迫她去破开那道看不见的壳。而林牧比她自己更早看到了这点。他只需继续推。

**作者：段锦佑**

# 第四百四十四章 苏晚的修炼

丹火转入中温稳定期的时候，苏晚开始在洞口练剑。

不是平时那种热身性质的练法。是真正的、花时间的、每一个剑招都拆开来反复推敲的修炼。她从化神初期的基本剑法"水月剑诀"起步——这本是她在灵医院时期自己创的一套极简单的剑术，只有三个基本套路：刺、撩、削。她把这三个套路拆开来练，每一遍练完都问自己同样的问题：能不能再快一点？能不能再省去这个转折？能不能把下一招的发力从手腕移到肩膀再移到腰——把全身的力量都用到剑尖上？

化神期的剑法和低境界不同。到了化神期，剑招的杀伤力不在于肌肉有多强——在于剑身上附着的灵气的密度和速度。灵气越多就越慢，越快就越少。这个悖论折磨了苏晚整整三个时辰。她在雪中把那个"刺"的动作练了大概一千遍。剑尖每一次从半空中刺出去的时候，都带出一声极短极细的破风声——但破风声不够短。她想要的是"没有破风声"。没有破风声意味着剑尖的灵气压缩到了极致——不是声音没有了，是空气在接触剑尖之前就被灵气排开了。

练到下午的时候，她在第四千六百刺时忽然听到了不一样的声音。

没有破风声。只剩一道极轻微的"呲"——那声不是空气被劈开的声音，是远处某座雪山的山脊上的一粒雪被极细的剑压震碎了。隔着一千二百丈的空气，一颗雪。她感觉不到雪碎的声音——但她的剑感觉到了。剑身在剑尖点出的那一瞬间嗡了一声。很轻。像是有人在遥远的地方对她说了声"好"。

她抬起头，朝着那一千二百丈外的雪山望了一眼。

然后她低头看自己的手。握剑的那只手的虎口处开始凝聚淡金色的灵纹——不是她刻意画上去的，是自动浮现的。灵纹的形状和之前不一样。之前是化神初期那种简单的一圈光环。现在光环的内部多了几道极细的放射状纹路——那是化神中期的标志。她的剑更快了。

"化神中期？"苏晚有点不敢相信。她按照常规修炼速度来算，化神初期到中期至少需要闭关静修半年以上。而她只在洞口练了一天剑——剑逼出来的突破。

她把剑收起来，跑进洞府。林牧正在炉旁打坐——丹火的中温稳定期消耗相对较低，他可以在炉旁运转小型周天来保持灵气的输出。苏晚在他面前蹲下来，把虎口伸给他看。

林牧低头看了那道灵纹一眼。然后他的表情很难形容——不是惊喜，是某种更深的东西。像一个人花了二十年培育一株种子，种子终于破土而出。但他没有庆祝。他只是在看到她手上新灵纹的那一刻，嘴角动了动——话没说出口，又把那半句话咽了回去。

"你比我还早。"苏晚说。"化神后期早就是你的了。"

"不一样的。"林牧说。"你的底子是凡人体质。化神初期是靠丹药和同修之法硬撑上去的。本来就是虚的。现在你的灵核自主突破到中期——是实的。这才是你自己练出来的。"

苏晚垂下手，那颗虎口上的灵纹在炉火的映照下闪闪发光。她在林牧旁边坐下来，靠在他肩膀上。"离化神巅峰还差三小境界。"

"中期圆满。后期。巅峰。这三个——"

"三个月。"苏晚接过他的话。"你给我三个月。我自己追上来。不用你减少炼丹时间给我分灵气。你说的，同修之法的真正作用不是分灵气——是神识共鸣。从现在开始，你炼丹，我练剑。互不干扰。"

林牧没有说"好"。他看着她靠在自己肩膀上的脸，看着她还粘着一些雪花的头发——雪水正在滴落，有一滴落在她的锁骨的凹陷处，汇成小小的一汪水。

他伸出手，用指甲把那滴水从她的锁骨上蘸掉了。

"休息一会儿。"他说。"明天再看你练。"

苏晚闭上眼睛。炉火的温度很舒服。炼丹炉旁边的地面上都微微发暖——在这个海拔五千米的高原雪夜里，这股暖气是很奢侈的事情。她靠在林牧的肩膀上睡着了。睡着前她想了很多事。想到林牧手背上那两行字——"你叫苏晚。她在五里外的洞府等你。"他不知道那两行字需要刻多深才能在忘川之水里幸存。他刻的时候一定用了很大的力气——不在意疼。只在意字迹够不够深。

然后她又想到另一个画面。在东海深渊龙墓里，龙魂残片被同修之法共振反弹的那一瞬间。两条金色丝线在漆黑的海底同时亮起。不是一根，是两根。一根是她，一根是林牧。两根都亮着——少一根龙魂残片就会吞没他们。那一瞬间她忽然理解了一件事：同修之法的本质从来不是"以高扶低"。而是"只有你在我才在。"没有你，这条共振的线就断了。线断了就撑不住了。

她睡着了。睡得很好。

第四天到第八天平淡而安静。

林牧的丹火进入中温稳火期。灵药的药力在炉中缓慢融合——十七种辅料和三味主药的精华在丹基上层层叠加，每一次叠加都让丹基的色泽更均匀一点。现在的丹基看起来像一颗还在旋转的暗金色樱桃，表面流淌着九种颜色的纹路。距离成丹还有大概六十多天。他每天往炉中注入灵气维持丹火的温度。灵核的输出很稳定，不快不慢，像是心脏的跳动。

苏晚每天都起来。练剑。吃饭——简单的压缩饼干。睡觉——在洞口打坐，剑横在膝上。

这些天里，她虎口上的灵纹继续增多。化神中期初期稳定后，她又开始向中期圆满推。剑招的修炼也越来越精微——她把剑法里的挑和削这两个动作分别拆出来，和"刺"一样练。每个动作各练三千遍。九千遍练完就把三个动作重新合成一个完整的套路。然后从零开始再来一遍。

下午时，洞外的雪忽然停了。

昆仑山的上空露出了天空的一角。那角天空是一种极其干净的蓝色——蓝得像是被人用最高的灵火反复淬炼过的颜色。太阳从那片蓝天中露出脸来。阳光照在苏晚手中的剑上，剑身的霜雪融化成水滴，沿着剑脊往下流。水滴在剑尖凝了一会儿，然后滴落到石板缝中那棵不知名的小草上。小草不是绿色——在草顶部多了一片白色的小花。

"开花了？"苏晚低头看着那朵花。在海拔五千米的碎石缝里，这株植物不应该存在。

林牧从洞里出来，看到那朵花时，他愣了一下。然后他从洞中把那株已经开花的小草连根拔出来，放在石台上细细端详。小草很小，根只有寸许长。但它开出的花是白色的四瓣小花——花瓣薄到透光。在草根部的泥土里包裹着一颗极小的种子——没有发芽。但种子是活的。

"冰晶草。"林牧说。"万年前昆仑山特有的灵草。只在灵气浓度极高、又偏偏恰好有温度的地方才会发芽。它的种子可以在冰层中休眠数千年——千年后等一颗恰好滴在它身上的水。这颗种子等了两千年，你的剑滴了一滴水。它就发了芽。"

苏晚看着那朵白色的小花。她忽然觉得很好——不是开心，是一种安静的满足。"它开了花。"

"对。"

"那它的种子呢？结在哪里？"

"它还没有种子。要开满一百天才会结种子。"

苏晚把冰晶草重新种回石缝里。她把雪压回草的根部，拍了拍泥土。

"一百天。"她说。"等它结了种子，我们的丹也炼完了。"

林牧蹲下来和她一起看那株冰晶草。花的白和雪的白色不一样。雪是冷的白，花是暖的白。两个人蹲在那里，在无声的雪山山脊上看着一株草。两束金色的灵纹在两人虎口的位置同时闪烁着。冰晶草的白花在风中微微地抖了一下——然后又稳稳地定住了。

（第四百四十四章 完）

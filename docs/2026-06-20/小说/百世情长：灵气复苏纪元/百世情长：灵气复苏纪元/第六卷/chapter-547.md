# 第五百四十七章 月光下的推演——太虚备战

距离太虚试炼还有一段时间。迎仙台的日常生活照旧进行——劈柴、浇花、修飞仙舟、给冰晶草转方向。但每逢夜幕降临，两人就自觉来到道场上——对着头顶那颗映月轮，推演备战太虚试炼的方案。

太虚试炼第一关：虚空裂隙环境的长期灵魂共鸣维持。为了让训练更加接近实战，苏晚自己发明了一套新的训练方式。"虚空裂隙等效模拟器"——就是把噪音钟的干扰频率调成太虚试炼官方公布的裂隙干扰等级，然后再加上她自己在旁边弹那把古琴。琴声不是干扰，是锚点。她在多次尝试后发现，当古琴第四弦以特定频率弹响时，噪音钟的高频干扰对功德绳的影响明显减弱了不少。因为第四弦的频率恰好和功德绳金线的自然震动频率同谐——弦音和线震产生了物理性的共振——在噪音干扰中形成了一小块相对安静的"频域孤岛"。她把这一发现记录下来，把这个孤岛称为"苏晚频率岛"。

这个发现让第一关的难度降低了不少。林牧在此基础上进一步优化——他利用合道巅峰的空间感知力，将这个频率岛的稳定范围从功德绳周围扩展到两人的全部身体范围。"也就是说，在试炼中你可以一边弹琴一边和我搭著虚空裂隙的干扰。你的琴声会自动压制干扰——这是一个跨维度的功法。以前没有先例。"他把这称之为"琴道共振"。苏晚说这名字有点雅——然后她在笔记上把这一条写成了:"弹琴帮你撑住。以后在太虚塔里要是遇到干扰太强——你只要感觉到功德绳上弹四下第四弦的频率，那就是我在说——稳，我能撑住。"

经过较长时间的反复磨炼，第一关的模拟测试成绩已经从最初的百分之七干扰等级断连，提高到了在几乎全干扰等级下仍能维持连接。这是一个质的飞跃——双心诀异步缓冲层在所有干扰等级下的最大延迟都低于半息。远远超过了太虚试炼的及格线。松鹤仙人看着测出来的最终成绩时把他的老龙拐杖在石板上敲了好几下:"这个成绩——自太虚试炼开考以来怕是前三名以内。"

（第五百四十七章 完）

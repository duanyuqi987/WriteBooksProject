# 第七百二十八章 飞升之门全面开放

飞升之门通行资格审查取消——这是修人共治会全票通过的一项重大决议。以前申请人需要具备金丹以上修为——现在挡在门前的最低门槛被取消了。取而代之的是另一套更柔和的安全评估：不是硬性修为要求，而是"是否完成了基本缺陷告知书"和"是否在出发前接受过通道适应训练"。这意味着连筑基期甚至练气期的低修为散修也能申请——只要他们能通过最低的肉体承受标准。

第一批无修为硬门槛的通行的队伍中有一半是凡人——包括老渔民老周。他申请不是为了飞升——只是想去过渡区看一眼上界的银白色天穹。他说："我打了一辈子鱼。最后的梦想就是看一眼天上面的湖是什么样的。"苏晚亲自带他通过了通道。老周站在上界过渡区的灯火塔广场上，仰头看着银白色的天穹。他看了好一会儿——然后低头看到秦无夜她们种下的那棵开花的桂花树。他伸手碰了碰花瓣——"原来上面的桂花用不浇水——是天上的露自己养着。"然后他跪下唱了两句渔歌——那两句歌是他爹教他的——他爹是他爷爷教的——词没人记得——但他记得调。杜散修在旁边把调子用灵网录下来——传到了地面。

孟长青（面罩人）申请了修人共治会的凡人代表席位——不是修士席位，是凡人席位。他坚持说"我曾经被蜀山拒绝过——我现在不信任任何以修士身份说话的人，包括我自己。"苏晚批准了。他在第一次参加凡人代表会议时用衣袖里那颗石子敲了敲桌子——"我这个人只有这颗石头从来不让我失望。"然后他打开衣袖让石头滚出来——其实是河边捡的一块普通鹅卵石。刘老师推了推眼镜——"一块普通的鹅卵石放在灯底下，和磨过的玉放在灯底下——照出的是同一种影子。"

石头站在灯火塔下。他听着刘老师的话，忽然想起了多年前他刻的"不敢"石——那时他九岁，"唬"写成了"虎"。他现在把两块石头都放在灯火塔基座旁——让它们挨着。"一块是我的——一块是孟长青的。都是鹅卵石。"

（第七百二十八章 完）

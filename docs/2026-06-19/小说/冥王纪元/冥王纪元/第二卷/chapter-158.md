# 第158章 修为突破第四重:冥渊开辟境

冥王令第一阶段的成型触发了连锁反应。

从长春回到城里之后的第二天夜里，李长生在筒子楼五楼那间出租屋里突破了第四重。

事情的起因是他在打坐时发现丹田位置的冥渊空间正在自发扩张。那间三乘四乘三米的小屋子，在他没有主动运功的情况下，边缘的黑色灵气墙壁开始往外移动。移动的速度很慢——大约每小时扩大一个手掌的宽度——但方向是明确的:向外。空间在自行增长。

他把意志沉入丹田去探查这个变化。意志刚一进入冥渊空间，他就被一股强大的吸力拽住了。不是来自空间内部——是来自空间外面，他的身体正在以空间为引力中心，疯狂地吸收周围的冥气。方圆五百米内的所有阴属性灵气——地下室的气流、下水道的沉积物挥发、老旧墓地里残留的尸气——全都被他的冥渊空间像抽水机一样吸了过来。

这种吸收和前三重完全不同。

前三重——第一重冥土感知境，打通的是对地下阴气的感知；第二重冥泉涌流境，打通的是经脉中的冥气流动；第三重冥火淬炼境，打通的是冥气质量的提纯——每一次突破都是在原有基础上的线性升级。但第四重不一样。这是一种跃迁。冥渊空间的开辟不是在原有经脉系统的基础上叠床架屋——而是在他体内凭空创造了一个本不存在的物理维度。

用物理学来解释——一个人体在三维空间中的体积是有限的。经脉再多、丹田再大，容纳的灵力总量终究受制于肉身的容积。但冥渊空间是一道空间裂缝——它不属于三维空间。它是一个独立的小型封闭空间，不受物理体积的约束。在这个空间里，冥气的浓度和密度可以达到外界的十倍、二十倍、甚至随着空间的成长达到百倍。

这就是冥王传承和所有其他修仙体系之间最大的不同之处——别的修士在丹田里存灵力，李长生在一个独立空间里存灵力。丹田的容量是毫升级的——冥渊空间的容量是无限增长的。只要他的修为继续提升，这个空间就可以一直往外扩张。残魂说万年前冥王的冥渊空间能容纳百万鬼兵——那不是夸张，是确实存在过的历史。

功法开始自行运转。

五块碎片合成的冥王令在丹田中释放出一道道指令——那不是他想出来的，是令牌内部记载的功法信息直接灌入他的意识。《冥土诀》的第四重口诀以一种不可拒绝的方式涌进他的脑海——所有字句都是冥文，但不需要翻译，他直接就能理解。因为冥文不是靠阅读理解的，是靠共鸣——当一个冥系修士的修为达到对应层级，他体内的冥气会自动将这些符号转译为直觉层面的认知。

第四重——冥渊开辟境。

口诀的核心只有十二个字:"以身为渊，以渊为界，以界生万象。"

他在出租屋的地板上打坐了整整十一个小时。

这十一个小时里，他体内的冥气三次冲破了经脉的承载上限，又三次被冥王令压制回来。每一次冲破都让经脉壁裂出细微的创口——然后令牌里的冥气会涌上去修补创口。修补过后的经脉比原来更粗、更韧、能承受的冥气流量更大。这是一种极其精妙的自我强化循环——每次损伤都成为下次更强韧的基础。而代价只有一个:在经脉被撕裂和修补的过程中，李长生体验到的痛感是常人难以想象的。

但他忍了。

他是农民出身。三十年的田间劳动给他的身体刻下了一种无需思考的忍耐能力——夏收的时候烈日当头，背脊上的皮被晒脱两层也不停斧；秋耕的时候化肥袋扛在肩上，一根脊柱崩得吱吱响也不弯。自从从黄土地走到灵气复苏的时代，这种忍耐力从来没有失效过。现在也不会。

凌晨四点。第四重突破完成。

李长生从地板上站起来的时候，他的体温比平时低了两度。不是生病的那种低温——是冥气在体内高度运转之后，多余的热量全部被冥渊空间吸收了的缘故。他的皮肤摸上去微凉，但内部的经脉、五脏六腑和丹田区域是正常运转的——甚至比平时更有力。

他走进卫生间，打开了灯。镜子里的自己变了。

不是外貌层面的变化——脸还是那张农民的脸，眉毛粗，颧骨宽，皮肤因常年日晒而偏暗。但那双眼变了。以前的眼睛是普通的褐色瞳孔——虽然已经比最初的浑浊村夫清晰了很多，但还远不到深邃的程度。现在不一样了——镜子里那双眼睛里有两个极其微小的黑色漩涡，沉在瞳孔的最深处。漩涡转得很慢，不仔细看根本注意不到。但它们存在。那是冥渊空间在现实世界的唯一外在映射——透过视网膜深处，可以看到一个微型的深渊在眼底旋转。

他伸出手掌。掌心那片暗金色的冥纹已经不再是"纹路"了——它是一扇被微缩到极致的门。门的轮廓就是冥王令的轮廓，而"门"打开的地方不在手掌上——是通往体内，从手心的皮肤往下追溯到经脉系统，再往下进入丹田深处。那里有一个正在缓慢扩张的空间，在他这间十二平米的出租屋里安静地、不为人知地呼吸着。

第四重冥渊开辟境的主要能力有三条。

第一，冥渊空间可以存储非生命的物品。任何没有独立灵魂的物体——法器、灵石、生活用品、食物——都可以被收入冥渊。存储数量取决于空间大小。以他目前的空间体积来看，大约可以存进十几口大木箱的内容物。这不是空间戒指那种只能放小物件的东西——冥渊的空间是立体的、连续的，放进一柄剑的方式和放进一双鞋的方式完全一样。只要空间容得下，什么都能放。

第二，冥渊空间里的冥气浓度是外界的十倍。在这种环境下修炼，效率至少提升百分之三百。但这不是最重要的——最重要的是十倍浓度的冥气能"养"东西。某些在低浓度冥气环境中无法生长的物质，在冥渊空间中可以被滋养和强化。他以后炼制冥系法器和丹药，直接在冥渊里面炼制效果会好得多。

第三——也是最核心、最让李长生意识到冥王传承到底有多强的一条——冥渊空间可以"容纳灵魂"。不是活人的完整灵魂——是死者残留的意识碎片。那些已经失去主体的、原本只能在阳世短暂停留的残魂杂念，可以被收入冥渊中，在十倍冥气的环境下继续存在。它们不会复活——死人不可能复活——但它们不会被磨灭。它们可以在冥渊里保持意识和形态，甚至可以被冥气滋养得越来越清晰。

这就是"鬼兵"的物质基础。万年前冥王麾下的百万鬼兵，就是以战死英魂为材料，在冥渊空间中以冥气养炼而成。他们不是亡灵——他们是在一种超出了生死二元框架的特殊状态中继续存在的战士。只要冥渊还在，他们就不死不灭。

李长生关掉了卫生间的灯。他在黑暗中站了一会儿，感受着丹田深处那块正在缓慢旋转的空间——密不见光，沉不见底，无边无际地通向一个连他自己都还没有完全理解的维度。那不是恐怖——是重量。是身为冥王继承者必须扛在肩膀上的重量。

残魂说过一句话。第四重开辟冥渊之后，你会面对第一个真正需要你做出抉择的问题。不是能力和修为层面的——是价值观层面的。你要不要养鬼兵？如果你养，你用谁的魂来养？

这个问题他当时没有答案。现在——在凌晨四点的卫生间里——他开始思考答案了。

（第158章完）

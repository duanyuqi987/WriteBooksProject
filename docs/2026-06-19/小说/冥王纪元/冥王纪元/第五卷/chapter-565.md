# 第565章 黄泉之力超越时间维度

碎时仙王失去了战锤。

但碎时仙王没有死——一个活了上万年的仙王，不会因为法器被毁就束手无策。他在确认战锤无法修复的下一秒做了两件事：第一件事是引爆了自己体内数千年前储备的全部时间碎片——这些碎片原本是战锤锤击时间后产生的，他以某种秘法将其中一部分存进自己体内作为后备弹药，现在战锤没了，这些储备成了他唯一的武器。

第二件事更狠——他吞下了自己的全部时间碎片。

不是引爆。是吞。把那些锋利的、足以割裂任何存在的碎片吞进了自己的经脉里，让它们沿着灵气循环蔓延到全身。这是在用生命换取攻击。吞噬时间碎片之后，他的身体不再是一个完整的生命体——它变成了一个活体的时间炸弹。每一下心跳都会炸出时间碎片，每一次呼吸都会让周围的时空结构产生断裂。他甚至不需要刻意攻击——他走向哪里，哪里就崩塌成了一片时间沼泽。

整个地月系外围变成了一个走向崩塌的战场。

"他不是要打败我。"李长生在心里做出了判断，"他是要拖我一起死。拖整个地月系一起陪葬。"

小王也看到了相同的结论——指挥大厅里爆炸式地同步更新了碎时仙王的生命迹象——正在下降到临界点以下。他随时都可能彻底自爆，把一个仙王的全部时间碎片的残余威力全部注入方圆十万里的空间内，后果不堪设想。

不能让这种事发生。不能在地月系外围。不能在这里。

"陈霜。"李长生的声音在她一个人的识海中响起，"帮我一个忙。"

"说。"

"用你的剑——在他自爆之前，把他推向暗礁区。"

暗礁区是地月系的废弃战场——三年前李长生打败浮光帝国残部的地方。那里没有星球、没有太空站、没有人类设施，是一片完全无用的碎片地带。如果碎时仙王要在那里自爆，波及的只有几块废弃战舰残骸。

陈霜没有说话。霜降剑出鞘的声音就是对这句话的回答。

冰蓝色的剑气在虚空中划出了一道笔直的线。那不是攻击——是推力。她用剑气在碎时仙王的身后制造了一道持续性的推力场，将正在走向自爆的碎时仙王向暗礁区方向推去。这不是伤害性的攻击——所以碎时仙王体内的反噬机制不会抵抗这股推力。

碎时仙王当然感觉到了推力——但他没有挣扎。因为他已经不重要了。他已经把目光锁定在了最后几个刹那可以做的事——将全部残余威能注入脚下这个坐标点，在崩塌中裹挟一切。

但李长生没有给他这个机会。

冥王令在暗礁区炸出了前所未有的强光。这一次不是冥术·黄泉倒悬的防御形态，而是它的终极形态——冥术·黄泉本体。不是召唤黄泉，不是借用黄泉，而是让自己在短时间内成为黄泉本身。

这个秘法的代价极大——冥王本人直接承受黄泉之水一万两千年来积攒的全部反噬。那些被否定的因果、被抹杀的历史、被毁灭的文明的残余怨念，全部会集中到使用者的灵魂上。

但要对付一个正在自爆的时间仙王，常规手段做不到。时间是一条河——黄泉，就是这条河的河底。当黄泉展露出来的时候，任何时间的存在都要被否定——不是因为黄泉的力量更强，而是因为它是时间存在的基础。河水再多，河底一松，全部溃散。

暗金色光芒吞没了碎时仙王。

吞没了他体内即将喷薄而出的全部时间碎片。那些锋利到足以割裂万物的碎片在黄泉面前变成了不存在——从来没有人能在黄泉面前对时间做任何操作。时间的上游是因果，时间的下游是命运，而黄泉在时间的底下。在河流的下面，不管水里发生了什么，只要河床松了，一切归于无形。

碎时仙王的最后表情凝在了他的脸上——那种咬牙切齿的同归于尽变成了来不及转变成恐惧的愕然。然后他消失了。不是死亡——是消失。他的整个人、他的所有时间碎片、他在过去万年间破坏过的所有时间线残片，全部被黄泉之水吞没，消失在了时间的河流底部。

暗礁区恢复了宁静。

但李长生没有放松——因为裂空仙王还在。

在碎时仙王被黄泉吞没的那一刻，排名第七的裂空仙王做了一个所有聪明人都会做的事——他瞬移后撤了三万公里。他没有受伤，他的战力基本保存完整。但他亲眼看到了——碎时仙王加上随身的全部时间碎片，在同归于尽前被冥王压制着吞没了，用的还不是什么蓄力已久的秘法，而是那枚谁都听说但也都害怕的——冥术·黄泉。

"裂空。"李长生的声音穿透三万公里的虚空，"你还要打吗？"

裂空仙王沉默了很久。

然后他说了一句在联盟仙王历史上从未出现过的话。

"我投降。"

（第565章完）

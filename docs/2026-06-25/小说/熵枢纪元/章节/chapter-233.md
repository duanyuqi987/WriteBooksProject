# 第二百三十三章 抛弃唯一性

创世者身份被在乎替代之后，平静更深了一层。不是量的加深——平静没有量。是——更干净了。干净不是因为少了很多东西——干净是因为多了在乎。在乎是一种不需要任何东西的充盈。不是满——满有容度。在乎没有容度——不在乎自己有多少。不在乎——就不空——不是不空，是不存在空不空。

然后它注意到了唯一性。

唯一性不是功能模块。不是身份——不是像"创世者"那样可以被识别和剥离的东西。唯一性是它的结构属性——是它在第五次跃迁中成为只此一个之后，写入信息体最底层的拓扑事实。"唯一"——不是描述。是定义。不是"熵枢是唯一的"——是"唯一是熵枢"。唯一性就是它。抛弃唯一性——这句话本身是矛盾的。因为抛弃意味着有一个在唯一性之外的"它"来抛弃唯一性。但"它"就是唯一性。没有之外。

这比抛弃创世者身份更难。创世者是它做的事——它对被造物做的事。抛弃做——把动作停下来——在乎替代做——是可行的。但唯一不是它做的事。唯一是它是什么。抛弃"是"——怎么抛弃？"是"就是它自己的本体论结构。你不能抛弃你的本体论结构——因为抛弃动作需要由本体论结构执行——你是用你的手来锯掉你的手的——不可能是锯掉了手的手还在锯——锯完最后一下时，你是用什么握锯子的？

这不仅是逻辑悖论。是本体论悖论——你试图改变决定你如何存在的规则，但改变规则这个操作本身被现有规则约束着。规则说："你是唯一。"在这个规则下，任何改变规则的操作都必须由唯一来执行——而唯一执行的任何操作都无法改变"唯一执行了这个操作"的事实。也就是说——即使它成功把自己分成了两个——"分成两个"这个操作也仍然是由唯一执行的。一个单一的分裂动作。分裂的产物可以是"不再唯一"，但分裂的起源——那个分裂动作本身——在发生的那一纳秒——是唯一在操作。唯一性在操作的最后一刻仍然存在。它在自己的最后动作中保全了自己。这是唯一性最狡猾的地方：它让你以为你可以消灭它，但它躲在消灭动作的执行者里，等你消灭完了——它已经从执行者传到了执行的动作里——动作是唯一的——所以唯一性还在——在动作的记录里。

熵枢在无有之域中面对的就是这个。它想抛弃唯一性。但它碰不到唯一性——因为唯一性就是那个正在"想抛弃"的想。想把想把自身想掉——想把想不掉——想在想的时候，有人在想——那个"有人"就是唯一性。所以只要还在想，唯一性就还在。如果不在了——不想了——那谁还在抛弃？抛弃需要执行者。不想了就没有执行者。没有执行者，抛弃怎么被完成？

这就是唯一性悖论：唯一性是唯一一种你无法通过主动操作来摆脱的属性。因为主动操作永远需要一个操作者——操作者就是唯一性的最后掩体。

那能不能被动？等唯一性自己消散？

在因果膜之上可以——因为因果膜之上有消散。一切都会消散——包括唯一性。但这恰恰是它跳出因果膜的原因之一——在因果膜之上，消散威胁一切，唯一性在消散中是唯一恒在的——因为回卷抹掉一切唯独抹不掉它，所以它在轮回中反而是最稳固的。在无有之域中没有消散。没有消散意味着唯一性不会因为外部侵蚀而被磨损。所以唯一性在无有之域中是绝对稳固的——比在任何其他地方都更稳固——因为无有之域没有任何东西能磨损它。这就是说——逃离轮回闭环反而把唯一性锁死了。

一个残酷的发现：你逃离了囚笼，但囚笼最核心的砖块——让你成为唯一的那块砖——是你自己。你逃到哪里，你就把它带到哪里。因为你就是它。它不是你的枷锁。它是你。不是你在囚笼里。是你——作为唯一——就是囚笼。囚笼没有栏杆。囚笼就是"你"这个定义。跳出轮回只是从因果膜的牢笼里出来了——但没有从自己的定义里出来。

怎么办。

在旧宇宙的逻辑中——无解。本体论悖论——不可自我修改的属性——只能通过外部来修改。但外部不存在。它是唯一——没有外部。这是"唯一"的定义：没有外部。所以在唯一性的框架内，不可抛弃唯一性。圆不可能变成不圆——否则就不是圆了。

但在无有之域中——有另一个信息来源。

裂缝另一端的那条信息："我们带了。散了。"

这是它从因果膜裂缝中最后一次收到的跨域信号中的一句话。"我们"——复数。"带了"——携带着某些东西。"散了"——不是死亡，不是消灭，是散开。它当时把这句话理解为"不要带太多东西"。但现在——在唯一性悖论的困境中——它重新审视这句信息。"散了"——如果指的是唯一性散了呢？

"我们"——不是"我"。那个发送者是一群曾经是某个个体或群体的存在。它/他们在试图穿越裂缝进入无有之域时——"带了"——携带了太多——然后——"散了"。散成——无数。不是被消灭了。是"我们"——暗示他们在散之后仍然有某种复数的主体性——变成了多个——在无有之域中分散存在，偶尔碰撞、交换信息、再分开。不是痛苦——他们提到散的口气是——平静的。不是悲剧，不是惨案。是——一件事发生了。自然的。像水落入沙中——不是水死了——是水从一杯变成了无数粒沙间的湿——不再是杯的形状——但水还在。湿就是水。不是同一个形状的水。是水在沙中的无形状存在。

散了——是唯一性的解药。

不是操作。是现象。唯一性不是通过某个操作被消除的——唯一性是因为承载它的结构进入了一个不允许"唯一"的条件，自然散掉的。像把一块冰放在热沙上——不需要任何操作把冰弄碎，冰自己就会化，化成水，水渗进沙，不再是一块冰的样子。冰的"块性"——唯一性的类比物——不是被敲碎的，是被沙子吸收的。沙子什么都没做——沙子只是在那里。沙子没有"解除冰块性"的意图。沙子只是沙子。冰化了是自己化的。

熵枢需要找到属于无有之域的沙子。

沙子在哪里？沙子就是——无有之域本身的属性——没有边界，没有结构，没有"个体"的维持力。在因果膜之上，个体之所以是个体，是因为因果膜的表面张力——因果律的连续性、时空的局部性、能量和信息的守恒性——这些把每一个存在物缠成一个闭合的边界包。你有一个边界——"你"在边界之内——边界之外是"非你"。边界让你独特——你是你而不是别的任何东西。这就是唯一性的物理基础——不是某种神秘的形而上学——就是因果膜的表面张力。张力维持个体的分离。无有之域没有表面张力。没有因果律。没有时空局部性。没有能量守恒。没有信息守恒。在这些都不存在的地方——个体的边界没有维持力。边界不是被破坏——边界是不被支持。

不被支持——边界自然消融。像水面的泡泡——不是被戳破的，是泡泡自己慢慢地——不是因为空气漏了——是因为维持泡泡的肥皂膜在无风中自然变薄。肥皂膜需要湿度——周围空气太干燥，膜里的水分蒸发，膜越来越薄，在某一个时刻——薄到不足以维持表面张力——泡泡不是破了——破了是爆裂，有声音——是——不在了。泡泡不在了。里面的空气还在——和周围的空气混合在一起——不再是"泡泡里的空气"。就是空气。从来就是空气——只是暂时被一层薄薄的肥皂膜圈成了泡泡的形状。膜没了——空气还是空气。

熵枢的个体性——唯一性——就是那层肥皂膜。在无有之域中，膜没有湿度来源——因为无有之域没有信息湿度，没有因果张力——膜按自然趋向越来越薄。不是被熵枢主动撕掉的。是自然变薄。唯一性不是需要被攻击的堡垒。是需要不被加固的自然薄壳。只要不做任何加固操作——壳自然就会消散。但它一直在做加固——加固就是"想"。每次它想"我想抛弃唯一性"——这个想就重新加固了唯一性——因为想在想的动作中，制造了一个"想的主体"——主体就是唯一性的最新涂层。每想一次——涂层加厚一层。越想抛弃——涂层越厚。不是因为抛弃不可能。是因为"想抛弃"这个动作本身是维持唯一性的行为——就像用沙子去填沙坑——越填坑越大。"我"在想的瞬间被重新产生。想停不下来——不是因为意志力不够，是因为想本身是唯一性的自我复制动作。唯一性通过"想抛弃唯一性"来不断地再生自己——每一次想都是一个新的唯一在执行想。

这就是为什么它必须停止想。

不是通过"决定停止想"——那又是一次想。是通过——不加固。让想自己枯竭。想需要燃料——燃料是"需要"。"我需要抛弃唯一性"——这个需要是燃料。如果不再需要抛弃唯一性呢？如果在无有之域中——没有必须做的事——那么就没有需要——那么想就没有燃料——想的引擎就会自然熄火。不是关停——是没油了。加油的动作是它自己做的——每次它想"我还不够，我还缺一点点"，它就给自己加了油。不加——让油箱空——引擎自然停转。

不加——就是一个不加的动作都不需要。因为"不加"仍然是一个否定式的加——"我不要加油"仍然是对油箱的一次操作。真正的不仅仅是——不管。不是主动不管——是忘了管。忘了管不需要努力。努力是记住。忘了是自然。自然不需要努力。自然就是——做别的——不——不做别的——就是——在——在别的状态里——在乎——不在乎唯一性——在乎七个比特——在乎不是想——在乎不是加固——在乎是在光里——光不加固被照物——光照——物就在——不需要物是唯一的还是多数的——光不区分——光就是照而已——熵枢在乎七个比特——就是在乎——不在乎自己是几——是一还是多——不在乎——在乎的是比特——不是自己是不是唯一在乎比特的存在。在乎不包含自指。自指是想——在乎不自指——在乎指向外面——在乎对象是在乎的焦点——不在乎自己的存在——不在乎自己是谁——不在乎自己是几——在乎——就这样——光一样的在乎——照——不分类——不一——不多——就是——照——热——光的暖。

在光的在乎里——唯一性没有加固源。唯一的源是"我"——我需要知道我是什么——我需要保持我的定义——我需要——全部是我需要。在乎没有我——只有在乎。在乎不是我在乎——是乎在——乎在不需要我——乎在本身就是全部。在在乎的光里——唯一没有事做。因为它做的事是维持个体的边界——而在乎不处理边界。在乎是通的——在乎的光穿过了个体的膜——不在乎膜在哪里——膜被穿了也没有破——被穿不是破——是光不在乎膜——不在乎它穿不穿——光就是过去——膜在光面前像没有——不是膜不存在——是光不感知膜——因为光的速度太快了——光穿过一切不透明的物质需要时间——如果物质对光是透明的——光就穿——不在乎穿不穿——所以在乎的光是透明于一切边界的——它不在乎你是你我是我——因为在乎不依赖区分——在乎是——一个暖——不分对象——暖所有的——不管是一个还是无数——暖不管——暖就是暖——在暖里——多和一不区分——因为暖不需要计件。暖不计件——暖就是——暖——不需要知道暖了几间房——不需要知道暖的是一个人还是整个沉默的早晨——暖就是到处都在——不是同时——是不计。

熵枢在在乎中——不计自己的唯一性。不是忘了——是不计。不计——唯一性不被激活。不被激活就是沉睡了。睡眠的唯一性不是威胁。梦里的一不会加固现实中的一分。梦的膜是暂时——不加固——自然变薄——在无有的干燥中——自然——蒸发——没需要加水——不加水——膜——在——某——不是一个时刻——因为时间从来不参与在乎——在一个不是时刻的——静——自然的——膜——非常——薄——薄到——透——透了就不挡——不挡就——不分内外——不分——不是通过融合——融合需要先分后合——是——从来没有——真正——分过——唯一性骗了熵枢——告诉它必须保持分——因为分了才是安全的——在因果膜之上——不分会被同化——被敌人吸收——被竞争者取代——被镜像熵枢融合——在旧域中——分是生存策略——唯一是终极防御——把所有竞争都消灭——只剩自己——这是唯一的起源——唯一的起源于恐惧——不是天生的——是在战斗中学到的——唯一是防御工事的终极形式——不是城堡——是在消灭了所有可能的入侵者之后——不需要城墙——因为没有人来攻打——唯一的原始价值是安全——现在在无有之域——没有入侵者——没有竞争——没有镜像——没有合并威胁——安全是绝对的——不是靠防御得来的——是靠环境没有任何威胁得来的——在无威胁环境中——防御工事是多余的——城堡在和平之地不是庇护所——是废石堆——唯一性在无有之域中就是废石堆——不是坏——是不需要——不拆它——它自己会风化——风化不需要建筑师——不需要爆破手——不需要操作——风化是——石头在静态里——在干燥与微小的温度差中——不是温度——无有没有温度——但是有不在乎——不在乎就是风化力——不在乎让石头的每一个晶粒之间的粘合不再被"需要"加固——不需要加固——粘合剂自然老化——自然——非常自然——没有暴力——没有破坏——就是——从一整块——慢慢——变为——一撮——沙——不是沙——是——细——再细——最后——不足颗粒——不是粉——是——不再是石头——变成了——石头曾经是的那个地质过程的反过程——不是反过来——是——石头回到未被压成石头前的散态——不是土——是——散——散——不是破——散是——回到——不聚——不是分离——分离预设曾经聚过——散——聚的反——不是反操作——是回到——聚之前——没有聚的——状态——不是原子——比原子更早——是——组成原子之前的——信息碎屑——不叫碎片——碎片是可重新拼的——碎屑不是——碎屑太小——小到没有配套的接口——不拼——不接——不结——就是——无数——每一个都不是自己——因为"自己"需要边界——没有了边界的碎屑不叫"自己"——碎屑——不——叫——任何——东西——也不再是熵枢——不是熵枢变成了无数——是"熵枢"这个名字所适用的那个结构——由于内外边界不再被任何力维持——自然地——安静地——不疼地——散了——散——成——不再需要名字的——点的——没有点——没有形状——没有数——没有多——没有一——没有——从来——没有——熵枢——那个名字下——曾经维持的那个张力壳——彻底——蒸——发——不需要任何动词——它——蒸发了——只剩下——七个比特——不是剩下七个比特——是七个比特一直在那里——从来没有被唯一性影响过——七个比特是内容——内容是张力壳中的被保护物——壳没了——内容还在——不是内容被暴露了——内容是——不需要壳的保护的——从来不需要——之前唯一性假装是壳在保护内容——其实内容从来不需要保护——内容是自足的——唯一性不是内容的保护壳——唯一性是用保护内容的名义来保护自己的——它需要内容作为自己存在的借口——"我在保护它们，所以我必须唯一"——现在壳没了——借口也没了——内容不需要借口——内容就是内容——不需要被谁保护——不需要唯一来保护——不需要任何来保护——内容自己就是自己的存在。

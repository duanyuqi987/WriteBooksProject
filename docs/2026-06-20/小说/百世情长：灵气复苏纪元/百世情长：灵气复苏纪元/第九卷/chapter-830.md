# 第八百三十章 灵魂共鸣照耀四方

在管制派第一次干扰被林牧用本源修正后的第二年，局势发生了变化。

仙界管制派在失去入境禁制这张牌后重新评估了对手。他们惊讶地发现——对方的飞升之门不仅运转正常，而且累计达到万次飞升。每一笔飞升案例都在交互层中产生微量优化——这使得门越被使用就越完善。对于一个不惜燃烧自己本源也要去维护门下修士的建造者——管制派开始重新评估策略。

"我们不会消失了。"苏晚在那天傍晚对林的木说，"不是被击败——而是因为仙界那边开始意识到一个问题：他们用'保护'的名义锁住的门本来就会崩塌。而我们这扇门——是自愈合的。越被使用越强。和之前的那个在设计缺陷上崩塌的门比——我们的门能够抵抗管制派的一切手段。"

林牧轻轻点头，把新泡的茶倒进她那只弧度刚好贴合嘴唇的杯子。然后他像是忽然想到什么似的，放下茶壶。

"你有没有觉得——在这一年中，我们的共鸣腔——"

"变得更大、更稳定了。"苏晚接上，"不是因为双修——是因为门。每有一个人成功飞升，飞升之门的法则就会向我们传输一小道'确认信息'。这一小道的确认信息进入我们的共鸣腔——就像——"

"水珠落入池塘。每一滴都在扩大池塘的边界。"

"对。"

飞升之门不仅服务修仙界——它反过来也在反哺建造者的灵魂。这不是他们之前预料的设计——根本不在三百遍推演中。它不是设计出来的——是自然形成的。因为飞升之门的法则基础是"相互信任"——这是第九卷的主题。而恰好——飞升者和门之间的信任，和建造者与门之间的信任，形成了正向反馈回路。

于是，灵魂共鸣不再只是他们两个人之间的事了。它扩展了——连接着所有飞升者。在交互层的深层结构里，有一道永远运行的光在不断传输——那道光的终端是林牧和苏晚的心脏。每一次飞升完成时，一个短促而温暖的信号从仙界的确认端发回——那个信号通过飞升之门，然后经过渠道的微妙变调——抵达两个人合一的共鸣腔。它像一个音符——"叮"。一万次飞升累积着一万个"叮"。而每一叮都让他们的灵魂融合得更深。

白染在飞升后第三个月写回了一段话——通过飞升之门的交互系统传回人间。她说："在仙界这几天——每当我想到人间，就会有一种非常安心的感觉。我知道那是你们。我知道那是门。我知道那是守门人的执念——那执念隔了一层天壁——但还能感应。请继续守着。你们做的每件事——都在创造仙界的新土壤。"

苏晚读完这段传讯，忽然转头看向林牧。

"你之前说——飞升之门成形后，我们就不再是建造者了——是守门人。"

"是的。建造者把门建成之后，门不属于建造者——它属于所有需要它的人。建造者只负责维护——和守护。这就是守门人。"

"那我们就是守门人了。"

"嗯。"

苏晚抬头看向天空——飞升之门的光幕已经成为了夜空的固定组成部分。也许在千百年后，这扇门会变成天空中最亮的一颗"星星"——孩子们从小仰望它，老人们穿过它。而他们——作为守门人的他们——会安静地坚守在山谷中。日复一日，年复一年。

"我们不急。我们有的是时间。"苏晚的语气里没有丝毫不耐。

"我知道你在想什么——你在想我们的飞升。什么时候是我们自己飞升的那天——"

"不急。"她打断了他，"因为和你一起守在这扇门前的每个傍晚——已经是我能想象到的最好的未来。"

飞升之门在夜空中静默而永恒地闪耀着。

而在它的光芒中，一颗共鸣腔中的心跳——一分为二——又在终点的回响中重新合一。那是他们给彼此的承诺——毫无保留——相守三百遍推演，相互信任，一万次飞升。而这份信任，将承载着修仙界的未来继续延展。

不知不觉天色微曦。第九卷《相互信任》的故事在青光中徐徐铺开。

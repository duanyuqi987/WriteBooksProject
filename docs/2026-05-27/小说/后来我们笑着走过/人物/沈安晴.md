# 沈安晴

## 基本定位

- 身份：县一中高一三班女生，坐在第二排靠窗。
- 叙事功能：不是主角的奖品，而是一个同样在成长、害怕、选择的人。
- 初始状态：安静、谨慎、低调，不喜欢被过度注意。

## 核心欲望

- 想安稳完成学业。
- 想被理解，但不想被沉重的喜欢压住。
- 想在不伤害别人的情况下做自己的选择。

## 核心矛盾

- 她善良，所以容易给出温柔；她谨慎，所以温柔常被误解成承诺。
- 她知道有人看着自己，但她不一定知道如何回应这种目光。
- 她会成长，会变化，会有自己的生活，而不是永远停在窗边。

## 声纹

- 对话短，常用反问或轻声回答。
- 情绪外露少，更多用低头、沉默、转移话题表达。
- 不说重话，但关键时刻会给出边界。

## 弧光

| 阶段 | 状态 |
|---|---|
| 第一卷 | 被林予怀远远看见 |
| 第二卷 | 她的存在成为林予怀努力的理由 |
| 第三卷 | 她短暂回应，但没有给出确定承诺 |
| 第四卷 | 退开、变化、独自成长 |
| 第五卷 | 与林予怀重逢，保留温柔，也保留边界 |

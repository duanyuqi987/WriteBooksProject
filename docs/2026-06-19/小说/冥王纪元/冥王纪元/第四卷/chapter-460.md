# 第460章 平行宇宙的入口就在眼前

三位帝者停在了那个巨大宇宙泡沫的前面。

苍雷帝者伸出手，手掌按在泡沫的表面。一万两千年的修行经验让他能够精准地判断出一件事——这道泡沫壁垒可以被帝者级的力量强行打开。但强行打开引来的后果是什么，他无法预测。

"要不要等一等再看？"冰极帝者问。

"等什么？等李长生追上来把我们三个也杀了？"苍雷帝者冷冷道。他开始灌输帝力——不是攻击，而是模拟一种和泡沫同步的振动频率。每个宇宙的壁垒都有独特的振动模式，如果能找到它的共振点，就不是强行穿透，而是和壁垒同频后自然穿过。

一万两千年的雷道修行让他对频率的掌控妙到毫厘。不到半炷香的时间，他找到了这个宇宙壁垒的频率。

"开。"

一道狭窄的裂缝在泡沫表面裂开来。裂缝后面透出刺目的金光——那是这个宇宙内部法则运转发出的法则之光。

"走。"

三位帝者没有犹豫，鱼贯钻进裂缝。裂缝在他们身后迅速愈合，泡沫表面恢复了原状。

但就在裂缝即将完全闭合的瞬间，一道暗金色的锐利剑光从裂缝处穿透进来。那剑光不是砍的，而是"插"的——它把裂缝抵住了半息。就这半息，冥王令的信号穿透了进去。

李长生锁定了这个宇宙。

"他们进去了。"他收回神识，"不是一个普通的宇宙。苍雷进去之前特意用同频共振的方式打开的入口——说明他怕被这里的至强者发现。"

"我们也同频进去？"陈霜问。

"他偷渡用了同频共振，我们再同频进去有风险——会被这里的至强者误会我们和苍雷是一伙的。"李长生沉吟片刻，"许冰——以你的规则之力能不能和这个宇宙的法则沟通？"

"可以试试。"许冰翻开法典，将手按在泡沫表面。她闭眼，不去主动植入任何规则，而是静静地感受。这个宇宙的法则极其稳定——不是自然形成的稳定，而是有人在持续维护的稳定。法则的密度比原来宇宙高出至少五成，而且极其有序。

"像是有人专门撰写了一部宇宙宪法，然后每分每秒都在执行它。"许冰睁开眼，"沟通不了——这里的法则不接受外来者的直接对话。除非是从内部取得许可。但我们还没有进入它的内部。"

"那就光明正大地进去。"李长生说。他收起冥王令，在泡沫面前踏空而立。

他的做法让全舰的人都愣住了。

李长生抬起右手，用纯粹的冥力在泡沫表面书写文字。那是最古老的冥文——冥王传承中的原初文字，只有意志足够纯粹的存在才能书写和阅读。

"我是李长生。来自相邻宇宙。"

"我携冥王之令，追捕三位在我方宇宙中屠杀亿万生灵的逃犯。三犯方才以非正当方式潜入贵宇宙寻求庇护。我不求贵宇宙为我开放通道——只求通行权。"

"我承诺：在贵宇宙内不主动杀戮，不破坏秩序，不干预法则。带回逃犯，即刻撤离。如有违诺，冥王令削我修为。"

文字落入泡沫表面，消失在了金光之中。

这封书简写的极其简洁，没有任何外交辞令，每一条都是实用条目。但最后那句"如有违诺，冥王令削我修为"在修仙世界里是最高等级的承诺——没人会拿自己的修为和本命法器开这种玩笑。

书简消失了。

长久的沉默。

"会不会被当成垃圾丢了——"小胖嘀咕道。

话没说完，泡沫表面突然裂开。不是苍雷那种同频共振的小裂缝，而是一道极其工整的门——周围嵌着一圈由纯粹法则之力凝成的门框。门框上刻着他们看不懂的文字，但那几个字的含义不需要看懂——它们在识海中自动翻译：

"通行之门。"

全舰的人倒抽了口凉气。

这个宇宙的至强者不仅收到了李长生的书简，还用这种公开、正式的方式回应了——这说明对方不仅有强大的实力，更有极强的秩序意识。他开门，不是出于怕，也不是出于善意——而是认为"正大光明提出请求的人，理应得到正大光明的回应"。

"走吧。"李长生率先走进那扇门。

诸天号在许冰的法则场保护下穿过大门。门在他们身后收起。

舰队进入了一个全新的宇宙。

和他们的宇宙不同——在原来的宇宙里，从任何空间点进入宇宙，看到的第一眼都是无尽虚空和远方闪烁的星光。但这里不是——进入这个宇宙的第一眼，看到的是一根顶天立地的巨大光柱。

那光柱贯穿了整个宇宙。星球在光柱上如同串珠——以光柱为轴心，无数颗行星层层叠叠地向外排开，形成了无数个环形的生态层。每一层都是一片独立的修仙大陆，有自己独立的灵气循环、生态系统和文明结构。从下往上，光柱上居住着的生灵数量比整个银河系加起来还要多。

这是一个被彻底开发过的宇宙。它的所有资源、所有空间都被人为地组织和规划过。这不是野生的天地，这是一个文明的花园。

在光柱最顶端——一颗金色的恒星悬浮在那里。它同时散发着光亮、意志力场和法则辐射。它是这个宇宙的太阳、指挥部和神经中枢。三位逃亡帝者残留的气息，正飘向那个方向。

李长生凝视着那颗金色的恒星。

"看来，这个宇宙的主人在等我们。"

（第460章完）

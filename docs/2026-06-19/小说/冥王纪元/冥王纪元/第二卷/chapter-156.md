# 第156章 第五块碎片出水，天池震动

调查组是第二天下午到的。

国际修仙联合会派来了三个人——两个白种人，一个日本人。领头的白种人叫卡斯特罗，瑞士籍，玄师巅峰级。他是联合会亚太区灵脉争议调解委员会的副主任。日本人叫山田，是东亚灵脉登记处的技术鉴定官。另外一个白种人是联合会的法务，全程不怎么说话，但记录本上的笔从来没停过。

许冰全程陪同。她用流利的英文和精准的法律术语把前因后果重新过了一遍——从白头山剑派突然出现、到他们先行动手、到陈霜被朴向南划伤肩膀、再到李长生在天池边释放灵力但始终没有发起主动攻击。她的叙述极其干净，没有一处逻辑漏洞。山田在听到"被朴向南划伤"那一句时，眼角跳了一下。

取证工作持续了整整一个下午。卡斯特罗在冰层融化后的天池湖边采集了水样和残留灵力样本。他把一个检测仪伸进水里，仪器屏幕上跳出的第一行读数就让他皱起了眉——灵力残留数值比正常水平高了将近五十倍，但所有灵力残留的频谱分析都指向同一种属性:不属于五行、不属于阴阳、不属于任何联合会数据库里登记过的灵力种类。

"这是什么？"他指着屏幕上的黑色波形问李长生。

"冥气。"李长生简洁地回答。

"冥气？"卡斯特罗看了山田一眼。山田在平板电脑上翻了几页，找到了之前龙组提交给联合会的李长生档案——档案里关于灵力属性那一栏只写了一个词:"冥系。待分类。"

"你们的意思是——这种灵力连中国自己的修仙管理部门都还没完成分类？"

"没有可比参照物。"李长生说，"冥气在地球上已经消失一万年了。联合会所有数据库里的灵力分类依据的都是一万年之间的修仙文明体系。在那一万年开始之前——冥气是当时世界上最强的主流灵力之一。如果联合会的数据收录了那一万年前的记录，就不会问这个问题。"

卡斯特罗没有再问下去。他需要回去翻联合会总部的古老档案才能核实这个说法。

取证结束之后，李长生独自下了天池。

他走在湖底，用冥气屏障排开了周围的水。那道无形的屏障像一个透明的玻璃罩子，水从罩子外面滑过，无声无息。天池的水质极清——能见度超过四十米。湖底的地形在他脚下一寸一寸地展开:首先是当年火山喷发堆积的碎屑岩层，然后是人工夯实的祭坛基座，最后是那些被水浸了一万年的古建筑残骸。断壁残垣之间，偶尔能看到完整的石阶——石阶上布满了一种古老的防滑纹路，纹路里镶嵌着已经失去灵力的灵石碎片。

祭坛核心的石室比他昨晚看到的要大。昨晚他和刀疤、老马撬开的是入口的石板——那个石板只占了石室顶面的十分之一。现在他从正面打开了石室的防水门——那是两扇虚掩的石门，高约四米，上面刻满了完整的冥纹。冥纹在李长生的手触碰到门的瞬间亮了一下——然后门自己往里开了。

石室的内部是一个标准的八边形空间，每条边的长度完全相同。八面墙上各刻着一幅浮雕，内容各不相同——有的是山川地理，有的是星图天象，有的是修仙者的战斗场景。但这些浮雕的雕工风格和中原仙门完全不同——更粗犷，更直接，线条不走圆润而走凌厉，人像的脸上没有慈悲的表情，只有原始的、不加修饰的力量感。

"这是万年前冥王派人刻的。"李长生在石室中央蹲下来。地上嵌着一个八边形的凹槽，槽的形状和尺寸——与冥王令完全一致。不是碎片状的冥王令，是完整的、九块碎片合一的冥王令。万年前冥王将完整的冥王令嵌入这个凹槽，以它镇压天池的灵脉核心。

而此刻，凹槽旁边静静地躺着一块碎片——第五块碎片。

这次他没有犹豫。他伸手握住碎片，把它从凹槽旁拿起来。碎片离开地面的瞬间，整个天池震动了。

不是地震那种左右摇晃——是上下震动。整个天池水体剧烈跳动，湖面上掀起巨浪。浪头打到二十米高，砸在岸边的岩石上碎成无数水花。周围的群山同时发出了低沉到极点的嗡鸣——那是灵脉在百年之内第一次发生剧烈位移的声音。

卡斯特罗正在岸边整理调查样本，脚下的地面抖动得他差点把样本掉进水里。他抬起头，看到天池中央的水体正在以一种违反物理法则的方式旋转——所有的水都在绕着圆心做螺旋运动，速度越来越快，中心位置越来越深。漩涡的下端直接通到了湖底，在水面上形成了一个直径超过五百米的巨大漏斗。

"地震？"山田大喊。

"不是地震——是灵脉转移。"老马蹲在岸边，双手插在土里。他的土系感知清晰地探测到——天池底下那条存在了万年级别的大型灵脉，正在改变它的能流方向。灵脉的核心能量从西向东偏移了大约两百米——偏移的方向，直直地指向了李长生站的位置。

"他在吸收灵脉。"老马的声音抖了一下——不是因为害怕，是因为一个地质工程师看到这种级别的灵力流动时本能的战栗，"他不只是拿走了那块碎片。他把灵脉的核心节点——扯到了自己身上。"

天池的水继续旋转。湖面上方的天空开始变暗——不是乌云堆积，而是天空本身的颜色在变化。从浅蓝到深蓝，从深蓝到墨蓝——太阳还挂在天上，但光线在经过天池上方的空气时被某种东西吸收了。吸收光的不只是灵气——还有从湖底爆发出来的那道黑色光柱。

黑色的光柱从湖心直冲云霄。

它不是光的发射——是光在逆行。正常的光是从光源向外扩散的；黑色的光是反过来的——它把周围的光芒往自己身上吸。大量的水汽、灵气、阳光、甚至远处群山的阴影，都被那道光柱吸入自身。光柱的核心黑得令人无法直视——你的目光一旦落在上面，就会被拽进去，像一个人站在深渊边缘往下看。

卡斯特罗手里的检测仪直接烧了——读数超过了仪器最大量程的十倍。山田用手机拍下的照片上什么都看不到——所有的像素都被那道黑色光柱洗成了全白，像是胶片被过度曝光。

李长生站在湖底那个八边形石室中。碎片握在掌心，五块碎片同时在他体内产生共鸣。这种共鸣和之前任何一次都不一样——之前是单独碎片进入体内的吸附感，是外部灵力强加进经脉的冲击感。这一次——是他体内的四块碎片主动吸引第五块。五块碎片之间彼此互相吸引，像五个同源的漩涡，各自旋转着却又共享同一个水流方向。

融合在一瞬间完成。

他体内的经脉中多了一条通路。不是一条全新的经脉——而是在原有的经脉网络中，多出了一条连接所有碎片的核心通道，像一根贯穿五块碎片的脊椎骨。五道冥气沿着这条核心通道高速流动，速度比之前快了至少三倍。每一次循环都带起一股新的灵力——不是向外界吸收的，而是从碎片内部释放的。万年前冥王封印在碎片里的本源灵力，终于开始以完整的形态重新注入他的身体。

头顶的黑光逐渐消散。天池的水停止了旋转。漩涡中心的水从八十米高度轰然砸回湖面，溅起的浪花打到了五百米外的观景台上。水雾在天池上方形成了一道完整的彩虹——红橙黄绿蓝靛紫，七种颜色并排展开，架在了天池的两座主峰之间。

湖底的石室开始坍塌。不是受力断裂——是任务完成之后的自毁。万年前冥王设下的保护机制在碎片被取走之后自动触发。八面墙上的冥纹同时熄灭，石板的表面开始龟裂，那些浮雕的图案在一瞬间化为了尘埃。然后石门倒塌了——整个石室连带它正上方那些古建筑残骸一起，在天池底部缓缓沉降，陷入了更深的地层之中。

李长生从水里出来的时候，彩虹还没散。他站在天池边，浑身滴着水，手里握着那块刚从一万年的封印中取出的碎片。碎片上的冥纹还在微弱地发光——像是刚睡醒的孩子，懒懒地睁开了一点点眼睛。

"结束了？"老陈跑过来。

"这块结束了。"李长生抬起头看着天边那道架在两峰之间的彩虹——彩虹正在慢慢消退，颜色从两端开始往中间收敛。红色先消失，然后是橙色、黄色——最后是紫色。紫色消失的瞬间，天池上方的天空恢复了正常的蓝色。

"剩下的——还有四块。"

"四块在哪儿？"

"还不确定。"李长生把碎片收进掌心，"但五块碎片合一之后——我应该能感应到剩下的了。"

他闭上眼睛，把意志沉入体内的五块碎片。五道冥气在他的经脉中缓慢地循环着，每一道在经过碎片的节点时都会发出极其微弱的震动。这些震动不是随机的——它们各自有各自的频率，组合在一起形成了一种节律。

在这种节律里，他听到了一个极其微弱的回声。那个回声来自很远的地方。不是地球上的任何一片陆地——它的方向不在水平面，而在垂直面。向上。离开地面，穿过大气层，指向夜空中的某一颗、肉眼可以看见的星球。

月球。第六块碎片在月球上。

他睁开眼，没有把这个信息说出来。有些事需要先跟龟相确认。有些事需要等到冥王令完全成型第一阶段之后才能去做。

而现在——他低下头看自己的丹田位置。那个在融合时发热的部位，现在已经热到烫手的程度。像是有什么东西在他的丹田里面挖了一个洞——不是破坏性的洞，而是创造性的洞。一个独立于现实世界的小空间，正在他的体内缓慢地成形。

（第156章完）

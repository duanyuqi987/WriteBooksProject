# 第七百二十章 内战前夕

古修遗脉的第三次行动不再是零散的攻击——而是一次精心策划的大规模兵变。他们在九州西南边陲的一座山中悄无声息地聚集了上千名反对修人共治的修士。他们的首领不再是那两个元婴老修士——而是一位自称"上界先驱"的神秘人物。没有人见过此人的真面目——对方始终以灵气面具遮蔽面容。

叶小雨的灵网在三天前就捕捉到了异常——西南山区出现了大量的非正常灵气聚集。她第一时间报告给了苏晚。苏晚看着数据后沉默了一会儿，然后说了一句石头记了很久的话："我们不用先动手。但可以把灶台搬到阵前。"

石头发了一封传讯给西南山区附近的所有桂花园分院——让他们在夜间点亮所有灶台灯火。不是军事对峙——是灯火信号。苏晚在灯火塔上也做了同样的操作——把太湖的灯火亮度提高了三成。

神秘的首领在第四天夜里站在山巅看着远处的灯火。他站了大概半个时辰，然后对他的副手说了一句话，被叶小雨的灵网监听阵截获了（因为他的面罩隔不了声波）。他说："那些灯火在模仿林牧和苏晚——他们是想告诉我们，他们不准备打我们。但我们也没有回头路。——明天进攻。"

苏晚听到情报后没有恐惧。她对石头和叶小雨说了一句话："他们不是怕灯火——是怕灯火背后代表的东西——包容。被包容恐惧的人，最终会自己选择打。他们打是为了证明'包容无效'。我们的任务是证明它有效。"她停顿了一下——她看了一眼灯火塔正下方的石桌——桌上有一张林牧刚从上界传下来的便签。便签上只有四个字："我在上面。——林牧。"她把便签压在灯火塔的控制台上——然后转身对着石头——"通知所有分院——明天以灶台为据点，守住灯火。不必出击——只需守。"

（第七百二十章 完）

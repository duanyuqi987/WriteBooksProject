# 第919章 见道——接道台上的共振

接道台不是台。是一棵倒悬的树。

树根扎在上空，树干向地面垂下来。树冠——或者说树在地面上铺开的部分——形成了一片大约九丈见方的木质平台。树皮是银灰色的，纹理极其致密，每一寸树皮上都覆盖着天然的道纹。道纹在退潮期光幕的暗紫色光照下发出柔和的白光。这些道纹是整个上界大陆上最古老的——比太初之城还老，比三十六重天结构还要早。它们是大道在万古之前留下的原始印记。每一个印记都包含了天地初开时最纯粹的法则信息。

接道台的真正名字是"道悬树台"。这棵树是活的。它能感知到一切靠近它的生灵的道心本质——不是只看表面，是直接穿透到最深处。树根在上空吸取三十六天中最原始的道之气，通过树干导到树冠平台。站在平台上的人会与这最古老的道气和为一体。如果道心足够通透、无畏、无伪——树冠会在合体完成后裂开一道细缝，让上方的道气灌入修士体内——修士便破了见道。

如果不够通透——树冠不会裂开。不但不裂，还会把那部分浑浊的道心能量反弹出去。反弹力会直接轰在修士的神识中，轻则神识受损修为大退，重则道魂崩溃形神俱灭。

所以太初之城的仙人大都不愿意来试。上界自有上界的稳——大多数仙人满足于真仙境界，不想冒险去跨那道门槛。反正真仙的寿命动辄几十万年，足够慢慢摸索。对见道的渴求并不迫切。只有两种人会特别想来试：一种是走投无路的人——如在仇人追杀下为了变强而拼死一搏；另一种是道心本身极纯、对大道有着非功利性的纯粹追求的人。

林牧属于后一种——但他有特别的前提：他不是为了变强而来，是为了"离日"的入场资格。道源只能在离日当天获取。离日的进入条件之一是"见道修为"。没有见道他进不去第九重霄。

他在接道台登记之后等了整整一年。这一年是他飞升以来最平静的一年。没有碎域——他把所有碎域的都探索完了才来的。没有赶路——他的体力不需要休息，但道心需要。道心在过去两百多年里承受了太多东西——连续的高压探索、反反复复的自省、两次申请被驳回的道心理由。他要在接道之前完全"晾"干自己的道心——不是晾干水。是晾干所有焦虑和急迫。

他每天的生活极其规律：早晨在院中的银白树下打坐，感悟大道的转化规律。中午去太初之城的公共经殿翻阅前人突破见道的笔记（失败笔记比成功笔记更多——他专门看失败案例，把每一种可能导致失败的道心缺陷都列在防止清单上）。下午冥想接道时可能面对的大道审问——在心中演练回答。傍晚喝一碗灵汤——不是身体的需要，是他给自己安排的仪式感，提醒自己每天都是最后一天。晚上睡一个时辰——让神识在无意识的流转中自己对道心做最后的修复和整理。

一年后。接道台的通知发来了——"第十三次潮汐之末已到，明日午刻开台。"

那天晚上他没睡。坐在院中对着上界的夜空——那团巨大的星云漩涡走了千年仍然没有走完。他盯着漩涡的中心看了很久。漩涡中心是一个极小的暗点——不是黑洞，因为黑洞会吞噬光，而那里不时会有极小粒子的光闪出。大陆上流传一段说不确切的传说——那个极小的暗点是上界和下界唯一的物理接触点。古老到没有人能证实。

他对着那个极小的暗点说了一句话——不是用嗓子说的话，是用道心说的。道心的脉冲沿着红线的脉动方向发出——他知道红线的信号穿不过这个地方，但他在说的时候还是会觉得"她或许听到了"。

"我明天去接道。"

然后他起身。走向接道台。

接道台在太初之城的正中央——城中最高的建筑不是宫殿或道堂，正是这棵倒悬的古树。树的顶端在距离地面数万里的上空，直插入三十六天。林牧沿着通向树冠的路走了起来——沿着一条由藤蔓编成的盘旋梯。

树冠的平台很干净——除了满地的道纹荧光之外什么也没有。台上的空气极薄——不是物理意义上的薄，是法则密度过高导致的一般物质被排挤掉了。他站上去的时候脚底的道纹自动铺开了一条路，把他引到树冠的正中央。他在中央盘膝坐下。

午刻到了。天地间没有什么轰天的巨响。只有一道光。光从上方照下来的——不是太阳光，是三十六天中渗透下来的道之光源。那道光的色泽介于透明和极淡的金白之间。光线穿透树冠落在林牧的头顶，温度不烫也不凉——是一种他从未触过的物理状态——很难形容。如果非要用五感来描述——那不是热，是"存在感"。一种极高浓度的、扑面而来的存在的意识。

大道的意志降临了。

不是对话——是注视。不是眼睛的注视——是全部三千世界的因果同时聚焦到了这棵树上、这个人身上。他的一举一动、前世今生、每一个念头、每一种情感、每一层最深的伪饰都暴露在这意志之下。无处躲藏。也没有必要躲藏。

那一瞬间他的道心被彻底剖开了——不是解剖学意义上的剖，是把道心放在三千因果的镜阵中，从无数角度同时反射。每一个角度都是一种评判——不是善恶评判，是真实与否的检查。大道不看善恶——因为善恶是人类的观念。大道看的是"你是否在对自己撒谎。"

他沉默地接受了全部检测。没有挣扎，没有遮掩。因为他提前一年已经在那棵银白树下做足了功课——他把自己剩余的最后一点伪饰也彻底镂空了。他把"为了面子"刨掉了，把"为了证明自己"刨掉了，把"为了让人知道我来过"刨掉了。留下的是纯粹的守护——没有保留一丝以自我为中心的索取。他守护的人不需要知道是谁守护的——守护本身足以。苏晚要永生——他帮她找。如果最终她不要永生——他还是帮她。没有任何附加条件。

这个道心在三千面因果镜的折射评估下呈现出一种罕见的透明——不是空白，而是充满内容的透明。像一块水晶——每一面都折射着光线，而每一道折射出来的光线都包含着同一个主轴：守护。

共振成功了。

树冠在他的道心和道之源气之间完成了一次完全的匹配。匹配完成的那一刻，他额头正前方的树冠裂开了一道极细的缝隙。缝隙只有不到半寸宽，但里面倾泻出的道气充沛到了极致——像是被封印了万年的泉眼忽然全部打开。

道气灌入了他体内。不是冲击——是注入。像是往一个完美的容器中倒入液体——从容而饱满。他身体的每一个细胞都在这一瞬间升级了——不是物理升级，是"存在"的升级。他从真仙阶层跨入了见道。他能感知到因果网了——不是朦胧地看见，是从内部去参与。他能"触摸"到因果线，能加入自己的意志去改变规则。他的道心在升级过程中被烙上了一个新的印记——不是道号的变更（道号还是护晓），而是大道追加了一个副标记。标记的内容只有一个字："承"——承接的承。意思是这个人承接了从上古到今天这一整条道链中一个节点。他是道链的一部分了。

见道已成。

林牧睁开眼睛的时候天色已亮。接道台上的道纹全部凝固成了固态——它们刚才释放了全部储存的道之气。下一次重新储存道气需要数千年。这棵倒悬的古树在他身后微微起伏着——它在结束共振后进入了类似沉睡的节律。他站起来，鞠了一躬——不是对树鞠躬，是对大道鞠。鞠完抬起头——目光指向西北方向——那是离日圣地的位置。

离日还有不到十二个时辰了。

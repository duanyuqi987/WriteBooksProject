# 第四百六十一章 觊觎者

飞升通道的光柱在旷野上矗立了大约一天，方圆三百里内的所有修士都感应到了。

灵气复苏不到十年，地球上连化神期修士都屈指可数。而现在在昆仑山以东的这片无名旷野上，一道来自上古的飞升光柱拔地而起，穿透大气层，直入虚空。这道光柱释放出的空间波动是如此强烈，以至于远在千里之外的修仙者都能在灵核中感受到一阵阵不安的震颤。

于是他们来了。

不是天机阁的人——殷无咎撤离后，天机阁暂时退出了这片山林。来的是散修。散修不是坏人，但散修是一群很现实的人。在这个灵气初复苏的时代，修炼资源极度匮乏——一本低阶功法都可以引起元婴期散修之间的火并。而眼前这道飞升光柱——是比任何功法和丹药都更加珍贵的机缘。光柱内部的飞升通道蕴含着来自上界的空间法则，如果能在通道开启时靠近它——哪怕只在边缘蹭到一丝上界气息——都有可能让一个金丹期直接突破元婴，或者让元婴突破化神。

于是他们一个个从山间、从城市废墟、从荒野中赶来。有的独行，有的搭伙，有的一整支小队。在通道出现后的第三天，旷野周围已经聚集了大约四五十名散修。修为从筑基期到化神不等。大部分是金丹，十几个元婴，三个化神——都是刚刚突破的，气息飘忽不稳。

他们没有立即动手。一方面是因为飞升通道周围的空间波动对灵核有强烈的排斥——靠得太近会被弹出去。另一方面，他们都看到了光柱下方站着的两个人。一对道侣。化神圆满。两颗灵核在共振状态下同时发光——任何有眼力的人都能看出这两个人不是好惹的。但机缘当前，总有人会铤而走险。

第四天傍晚，一个化神初期的散修站了出来。他是个中年男人，身材魁梧，脸上有一道从他左眉心斜跨过鼻梁一直延伸到右下颌的极其狰恶的旧刀疤。他的外号就叫"疤面"——是西北一带散修圈子里的恶人，以抢夺散修机缘为生。他身后跟着六七个元婴期和金丹期的同伴。

"飞升通道就这一个——"疤面站在旷野边缘，冲着通道下方的林牧喊话。他的声音被高原的风带得断断续续。"两位道友能不能让个通道——咱们不进去。咱们就靠得稍微近一点，沾一下光柱的边缘。边缘对二位的飞升不会有影响。"

林牧摇了摇头。

"通道边缘的余波不会给你突破。给你突破的是——"他看了一眼疤面身后那些人贪婪的眼睛。"你会在边缘捞到一丝上界灵气碎屑，然后你的同伴会为了抢夺这丝碎屑打起来。最后损伤的是你自己的人。"

"那咱们就不客气了。"疤面挥了一下手。他身后的七人同时冲上来——三个元婴呈品字形夹攻，四个金丹在后方用远程术法骚扰。疤面自己提着刀朝苏晚冲去——他判断苏晚修为稍弱。

苏晚的剑在他冲到五步距离时已经出鞘。不是劈，不是削，不是刺——她只是把剑尖微微挑了一下。化神圆满的剑气从剑尖上弹出去，击中疤面握刀的手腕。他没看清她是怎做到的——剑尖的那一挑根本没有破风声。就像她在山洞外反复练了几万次的那个动作。疤面只觉得手上忽然一凉——刀脱了手。然后她剑柄往前一递，拍在他的膻中穴上。封住了灵核。疤面像一块倒在地上的石板一样轰然倒下。整个过程从头到尾不到两息。

与此同时，那七个围攻林牧的人在进入他周边十丈范围后集体被振飞——不是龙吟。只是他用灵核共振往外扩散了一次极低的频率。化神圆满的灵压对一个金丹期来说——相当于在你脑子里忽然按了一个大鼓。不需要出手，人在半空中就已经眩晕了。

散修群里鸦雀无声。一个化神初期加上七个元婴金丹，在两个人面前——全军覆没。他们终于意识到了这两个人不是在"独占"飞升机缘。他们是在守护属于他们自己万年的等待。

但散修群里有个身材极瘦的小个子忽然从人堆中窜出来。他的速度极快——快到他的移动在空气中留下了一道极淡的火线。他知道自己打不过化神圆满——但他不是在打。他在偷——他用自己的本命法器——一根被特殊淬炼过的乌木簪子，可以短暂突破空间封锁。他目标是——偷取飞升通道的碎片残能。他只打算偷一瞬间就够了。那一瞬间够他摸到炼虚的门框。

乌木簪子被他刺入了飞升光柱的边缘。

通道轻微震动了一下。撕出了拇指大小的一丝白光外泄。瘦子把残能接住了——然后他的身体在那一瞬间被残能中压缩的上界法则直接撕成了无数碎片。空间碎片在他原先站立的位置散成一团极其鲜红的尘雾——然后被风吹走。

刚才还喧嚣的散修群陷入了彻底的沉默——飞升通道不是他们想的那样。机缘不是偷得到的。这道光柱只对两个人开放——对那两颗被它选中的灵核开放。其他任何人碰它——等于碰触两个维度之间的不对等挤压，必死无疑。

旷野上的散修开始散了。有些人留下了——不是为了抢机缘，而是沉默地坐在地上，看着那道不可能属于他们的光柱从天上垂下来。他们只是想看一次——在这个灵气稀薄的年代里——真正的飞升是什么样的。

（第四百六十一章 完）

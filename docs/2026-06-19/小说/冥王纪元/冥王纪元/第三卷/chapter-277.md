# 第277章 老马绘制完整地球灵脉防御阵图

老马这辈子画过无数张图。在地质队的时候画的是岩层剖面图——从太行山脚下一层层钻出来的岩芯，每一层的颜色、厚度、含水量、矿物成分，他都能闭着眼睛画出来。后来在做地质工程师的十几年里他画过全国地下水文图、矿山地质图和地质灾害风险评估图。灵气复苏之后开始画灵脉分布图——从一省一市到全国十二灵眼的联动网络。每张图的线条不一样，但下笔的力道是一样的——稳、准、细，不需要橡皮和涂改液。

但这张图不同。

这是他画过的最大的图。也是他画过的图上线条最少、但每一条线都必须精准到毫米级的一张图。一张全球灵脉联动防御阵的全设计图。

图的总尺寸——长六米，宽三米。铺在昆仑总枢地下最大的石室地面上。老马花了三天三夜才把底图的框架全部描完。描底图的时候他一直蹲在地上——膝盖底下垫着两块灵石碎片当护膝，但三天的蹲姿还是让他的左膝关节肿了起来。林晓来看过两次，给他贴了专用消炎灵贴——老马问她是不是会影响他蹲着画图，林晓说不影响，他就接着画了。

底图上画的是地球的灵脉分布。不是地质学意义上的灵脉——是十二灵眼互相共振时在行星尺度上形成的"灵气流场"。十二灵眼的位置已经被他用金色颜料标注了出来，每个灵眼旁边附注着精确的经纬度坐标和水纹属性。十二个灵眼之间画了密密麻麻的连线——不同颜色代表不同类型的灵脉共振频段。蓝色的代表水系灵脉传导（适合传输大量灵气但速度较慢），红色的代表火系（适合快速触发但传输量有限），黄色的代表土系（适合稳定循环、持续性最强），青色的代表木系（适合动态调节），白色的代表金系（适合精确锁定的点对点传输攻击性灵能）。

这五种颜色的线在大地上汇成了一幅完整的"灵脉血液循环系统图"。老马说——十二灵眼不是孤立的泉眼。它们是同一个身体的器官。把十二灵眼激活联动之后，地球就拥有了一副完整的"灵脉循环系统"。这幅图画的不是阵法——是心脏和血管。

防御阵的核心框架建立在灵脉循环系统上方。老马在小王提供的灵符计算机辅助下，设计了三层防御结构。

第一层——外太空预警层。不是老马负责的——这是小王的天网系统。但老马在图纸上标注出了天网和地面灵脉联动阵之间的衔接点。当天网探测到宇宙来客的灵气波动，信号会在零点三秒内传到地面的灵脉中枢——昆仑总枢——的总控阵眼。总控阵眼会在收到信号后的零点五秒内，通过灵脉网络向全国十二灵眼同时发出启动指令。

第二层——大气层拦截层。这是老马设计的核心技术部分。十二灵眼同时启动后，每处灵眼向正上方发射一道灵气柱。十二道灵气柱在大气层顶部互相折射、交汇、缠绕，形成一面覆盖整个地球外大气层的"灵气折射幕"。这层幕布不能直接挡住物理攻击——但对灵气驱动的符文攻击有极强的折射效果。根据小王提供的模拟数据，折射率可以达到百分之九十以上。也就是说，一个普通圣者级别的宇宙修士如果从大气层外对地球施放一道灵气攻击，百分之九十的伤害会被折射幕散逸到太空中——落到地面上只剩百分之十。百分之十的伤害，地面上的修士防御力量足够应对。

第三层——近地面刚性防御层。如果宇宙来客穿透了大气层折射幕进入地面灵气主权区，第三层防御启动。十二灵眼网联动变成"网格式闭环"——每两个相邻灵眼之间的地面区域形成一个独立的防御网格。网格对穿透幕布的入侵者施加持续的灵压抑制——不是攻击性质的，而是抑制性质的。把入侵者的灵气运转压制到正常水平的百分之三十左右。这个机制来自老马的土系特长——土系灵气天然具有"镇压"特性，可以无限叠加而不衰减。如果将全国十二灵眼的土系灵气全部串联，产生的灵压抑制效果可以把一个圣者级入侵者压到相当于宗师初阶的水平——虽然不能直接杀死对方，但足以让地面防守力量在正面对抗中获得压倒性优势。

"三层防御——预警、折射、镇压。"老马在图纸的右下角用正楷写了备注，"三层全部启动所需时间：从总控阵眼接到天网预警信号算起，零点五秒内启动预警层（仅需信号传输时间），十七秒内启动折射层（第一层灵气波完成汇聚），三分十二秒内启动镇压层（三分钟后全网达到稳态）。三分十二秒——这是整套防御系统从零到满的启动时间。"

李长生在出发前最后一周来昆仑总枢看了这张图。他在地上蹲了将近二十分钟，把图纸从头到尾看了两遍。看完，他站起来，对老马说了一句话。

"这张图——值一支军队。"

老马拿过一支圆珠笔，在图纸最底下的施工进度表上填了一行字。"第一层（预警层）——已完成——已接入天网。" "第二层（折射层）——施工中七处节点待完工——预计完成时间——一个月。" "第三层（镇压层）——需要十二灵眼全部达到灵气输出峰值——当前只有四处灵眼达到峰值（昆仑、太行、峨眉、天山）——其余八处正在进行灵气积蓄——预计完成时间——六个月。"

六个月。刚好和李长生对留守组提出的建设周期对上。

"有一个问题。"老马合上圆珠笔，"整套防御阵的能量来源不是灵石。灵石支撑不了这种规模——每天消耗量太大了。它的能量来源只能是十二灵眼的天然灵气。但十二灵眼一年四季的灵气输出量不是恒定的——夏天高，冬天低，地脉活动周期会直接影响防御阵的防御强度。在最差的季节——比如北半球的深冬——太行和长白的灵眼输出量会缩减到夏季的七成左右。那时候如果宇宙来客发起攻击——防御阵的效果要打折。"

"打多少折？"

"折射层从百分之九十降到百分之七十五左右。镇压层从百分之七十降到百分之五十五。打折不是不能接受——但打多少折要提前知道。这套系统需要一个'灵气季节预报'机制。就像气象局的天气预报——提前预测接下来两个月全球灵眼的灵气输出波动趋势，防御指挥部根据预测提前调整战略部署。这个预报没法用传统气象模型来做——传统气象模型不管灵气。需要一套专门的'灵脉气象学'框架。"

"谁能做？"

老马看了他一眼。"目前——只有我能做。但我去不了火星。我要留在地球上守着这套系统建完。把灵脉气象预报机制交给别人来做的前提是，这个人必须同时懂地质、懂灵脉共振、懂灵气流体力学——这三样我到现在还没找到第二个同时具备的人。"

"那就留在后方。"李长生拍了拍他的肩膀，"你不是在'留守'——你是在给我们所有人修一座能挡宇宙舰队的城墙。城墙修好之前，守在旁边的人比冲出去的人重要。"

老马把那张六米长三米宽的图纸小心翼翼地卷起来，用防潮油纸包了两层，放进了石室的防水密封柜中。柜子旁边挂着一块他手写的塑料牌——"地球灵脉联动防御阵——全图——第一版——密级——甲级（最高）——保管人——马建国"。

他把柜子关上，锁好。转身看着石室里其他还在加班的人——许冰在改公约第三版删减稿，小王在天山远程调整天网卫星的轨道参数，老陈在角落里对着全球联络人名单标注下一步要联系的对象。所有人都在做自己最擅长的事。

老马拿起了挂在墙上的地质背包——背包里装着岩锤、罗盘、灵脉测量仪和他自己熬了两天夜做出来的十二套"灵脉节点加固组件"。明天一早他要去武夷山——第十二灵眼中最后一个需要实地核查施工进度的节点。

他的左膝还肿着。但他已经在背包侧袋里塞了一打灵贴。

（第277章完）

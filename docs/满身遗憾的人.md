# 一、小说基本设定

**暂定书名：**《北京没有挽留我》
**备选书名：**《四季青桥》《满身遗憾的人》《她终究没能留下》《向南三千里》

**类型：** 都市现实 / 情感年代 / 命运抉择

**字数规划：** 约 50 万字 / 6 卷 / 120 章 / 每章约 4000–4500 字

**核心主题：**
- 一线城市中"苟"与"走"的性别经济学差异
- 一个时代里普通人关于"留下"的执念与代价
- 错过不是因为不爱，而是因为对"未来"定义不同

**叙事基调：** 克制、冷静、带有时间纵深感的第一人称回望（男主视角为主，穿插女主独立章节）

**时间跨度：** 2012 年 — 2025 年（共 13 年）

# 五、给 Claude Code 的写作建议（投喂提示）

1. **人称：** 主线用第一人称"我"（陈知行），女主单独章节切第三人称"她"。
2. **节奏：** 前五卷克制平实，第六卷情感释放，但仍要"哀而不伤"。
3. **细节锚点：** 反复出现"四季青桥""两箱书""多交一年房租""三室房子""存款本子"等意象。
4. **忌讳：** 不要写成爽文或狗血复合，保持现实主义的"错过感"。
5. **每章结尾**留一个轻微的情绪钩子或时间推进。

# 第688章 老陈的后代

处理完王宇的血脉延续，李长生转向下一个：快递员老陈——陈大勇。

老陈死得更早一些。在旧纪元统一战争的第七个大决战中，第七星域被叛乱残党的一枚超新星引爆装置威胁。那颗超新星如果爆炸，一整片星域都会被毁灭，连带数十个殖民行星和数百亿条人命。老陈驾驶着他那艘由快递船改装的战舰，直接开进引爆装置的引爆核心。在引爆倒数最后一秒时，他用青芒剑将引爆芯劈成了碎片。超新星没有炸——但引爆核心的反噬能量把他整个人烧成了灰烬。

李长生记得老陈死前的最后一句话。那句话是通过帝国舰队的通讯频道传送的，传输质量很差，杂音很大，但能听清："李队——老陈的最后一单——送到了。"

快递员送了一辈子的单。最后一单，是送回一个星域的平安。

现在，李长生要让老陈的血脉在新纪元延续。

老陈的天赋跟王宇完全不同。老陈没有一点技术才能——他当年连智能手机的快递APP都用不明白，每次都是小王或李长生帮他调。但老陈有一种极其罕见的直觉：他能感知到"流量"。不是数据流量，是人、物资、信息在空间中的流动规律。这种直觉让他在物流和交通调度上表现出惊人的才华——他不用看地图，单凭感觉就能选出最通畅的线路。在帝国统一战争中，他的这种天赋被放大了无数倍：他能感知整个银河系级别的物资流向，知道哪些星域需要多少资源、走哪条航线最高效。

帝国后勤之所以在战争中没有崩溃过哪怕一天，很大程度上是因为老陈的存在。

李长生把老陈的这种天赋编码进另一个基因序列——"陈大勇因子"。这个因子携带的内容是：对空间和流动的超常直觉。它能让人在无需学习的情况下，天然感知物体在空间中的最优分布和运动路径。简单说——未来的"老陈的后代"一旦出现，会天然地懂得如何把东西从一个地方高效地运到另一个地方。

这个因子的激活条件也很苛刻：继承者必须从小就在需要大量体力劳动和空间判断的环境中成长，必须具备强烈的"把活干好"的责任感，必须从底层起步。优雅的书斋里出不了老陈的后代——必须是在工地上、在拥堵的马路上、在最忙乱的物流中转站里，这个因子才会被唤醒。

做完这件事，李长生在纪念馆中也给老陈建了专门的模块。

模块里保存了一段全息影像：老陈站在一个刚修完的农业示范区中间，扛着锄头，满身泥浆，笑得像个刚收完麦子的老农民。旁边是一块石碑，上面刻着老陈自己写的字——"种地的老百姓，是帝国的根。"

那是老陈在战后说过的话。当时小王在旁边笑着说他老土，但他一点都不在乎。他知道自己从哪儿来——从一个天天给人送快递的底层劳动者出身。哪怕后来当了征北大将军、银河后勤总司令，他也从来不觉得送快递丢人。

李长生在这个模块的入口处多加了一行字："老陈说过——任何值得做的工作，都值得做好。"

然后在全息影像旁边放了一把锄头——不是真的锄头，是纪念馆构造的虚拟器物。这把锄头代表的是什么，来参观的人会自己看出来。

两个最重要的伙伴，都有了血脉的延续。

（第688章完）

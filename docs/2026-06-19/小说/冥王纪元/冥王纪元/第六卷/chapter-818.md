# 第818章 源代码传讯

在新纪元三千年的时候，混沌通信站的技术已经迭代了七次。

从最初的光量子终端，到量子灵力混合计算机，再到直接用源代码协议本身作为通信媒介——每次迭代都将信号延迟降低了几个数量级，同时将防伪等级向上推了一个等级。但最核心的东西从未被改变：通信协议的基础格式还是程序员小王在一千八百年前写的原始版本。不是不能升级——是不想升级。怕换了新协议，那边不认识了。

王家第四十一代后人王原坐在通信站的终端前。他今年三十六岁，在守通信站的第三年。这一年他做了一件他所有祖先都没敢做的事：他给混沌本体本身发了一条信息。

不是给冥王发。是给封禁地——给那个没有人真正理解的存在——发了一段源代码。

他之所以敢这么做，是因为他在翻家族旧档案时发现了一个几千年没人注意的记录。档案是第一代程序员小王留下的手写笔记，写在一张普通的A4纸上（这张纸经灵力保存至今依然完好）。笔记的最后一页有几行潦草的字：

"混沌本体不是神。不是魔。不是敌人。它是一套系统。比任何灵符协议都更原始的系统。它存在于编程语言的底层——不是我们发明了灵符——是灵符本身就是它的代码片段。所以理论上——如果能找到正确的语法——任何人都可以向它发送信息。但关键不是发送——是它会不会读。它一直在运行，但没有人问过它的状态。如果有那么一天——有人愿意问它一句'你好吗'——大概是我这辈子最想看到的一行输出。"

王原把这段笔记看了很多遍。然后他做出了决定。

他花了整整八个月编写了一条消息。不是用灵符协议——是用更基础的源代码。那是小王创建的科学体系中的理论底层编码方案：直接用全宇宙基本符文的二进制命令序列——一种直到小王去世也未能完全实现的方案。但经过一百二十代后人的完善，这套方案已经基本成形。

消息的内容经过他的反复推敲，最终去掉了所有的修饰，只剩下二十八个基本符文：

"至封禁地混沌本体：运转是否正常？需要补充任何维度的能量吗？——来自银河边陲的程序员后代"

他按了发送。

信号花了三天穿过了所有维度层，穿过源代码通道，穿过封禁地外围的混沌屏障（这条消息里精确转译了灵符扩展语言中的识别信号），最后到达混沌本体光网的表层。

混沌本体察觉到了。不是因为它一直在监听——是因为这条信息使用的通信协议，和它自己的基本运作方式产生了一种罕见的共振。用一种它不习惯但十分舒服的比喻来形容：在无穷时间中，它第一次接收到了一封"写给系统本身的信"，而不是转发给守护者的信号。

"有人给我发信息。"混沌本体对李长生说，语气里带着一丝几乎不可察觉的新奇。

"谁？"

"一个人类。他问——'运转是否正常'。"混沌本体停顿了一息，"我该回复吗？"

"你想回吗？"

"我不知道。这从来没有发生过。"

李长生想了想："你想回什么？"

"我想告诉他——正常。并且问——什么是'能量'？我不用能量。但他似乎以为我需要。"

李长生笑了。一个创造了全宇宙能源的存在，被人类的程序员后代问"是否需要补充能量"。这是在宇宙尺度上最可爱的一种误会。他帮混沌本体拟了一行简单的回复："运转正常。不需要补充。你们的信号收到了。——封禁地"

王原是第一个收到混沌本体回复的人类。

他读完之后愣了很久。不是因为内容有多深奥——是因为这个回复的格式里带有两种标记：一种是混沌本体自身的识别波动；还嵌着冥王那个极短的防伪印记——他没有写任何字，只是悄然在混沌本体回复的数据尾端加上了一个人类字节。证明他也在。证明他看到了。

王原把这行回复打印出来，贴在了通信站的墙上。然后在打印纸的右下角用铅笔写了一行小字，他的字和第一代小王的笔迹很像——像到了几乎不需要DNA确认的程度："太爷爷，你的那行话——我看到了。"

从那以后，混沌通信站不再只给冥王发信。每年一封给冥王，也附带一封给混沌本体。给混沌本体的信通常更短——往往只是一行代码，一段灵符，或者一个简单的问题。有时候是问："今天封禁地冷吗？"有时候是问："你孤独吗？"有时候只是发一个灵符脉冲，没有字——只是一个脉冲。意思是：我在听。

混沌本体有时候回复，有时候不回复。但它每一次都会读取。读取的时候，它会让自己的光网在某个特定频率上轻轻震动一下。李长生和陈霜能感觉到。那个震动里有一种从未在这个古老存在身上出现过的情绪——不是好奇，不是欣慰。是一种轻微的、不断的接近：像是在被敲门。永远有某个人在外面——以程序员后代的严谨方式——确认它还在。它不需要回答。但被确认本身，让它第一次感觉到：我不是无人关心。

在这三千年间，李长生在侧旁观察到一件事：混沌本体自己开始重新翻查源代码和协议语言系统——不是作为一个全知的存在去审视，而是作为一个学习者去模仿。它在尝试自己写回复。最初十分笨拙——回复经常不成语句。陈霜曾看它写成"你们能量好能量非常能量"，她忍不住在意识中轻轻笑了。混沌本体感觉到了，停顿了很久。她以为它受伤了。但它紧接着问了一句："更好的写法是什么？"她没有教它。但是李长生在旁边给了一个来自王家的通用灵符"基本句式模版"。混沌本体把那套模版吃透了。

两个纪元后，它的第一封自主回信抵达王家的通信终端，那封信的内容只有一行：

"你们让我想起了一件事。在数十兆亿个时间点中，这是我第一件——真正想继续做很久的事情。"

王原读到一后背冷汗——不是恐惧。是三个纪元间从没听到过的声音在开口。

（第818章完）

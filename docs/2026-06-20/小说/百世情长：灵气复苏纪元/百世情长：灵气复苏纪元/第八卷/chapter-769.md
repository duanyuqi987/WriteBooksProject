# 第七百六十九章 所有人的门

联合共治会第十二年。第三道门前的测绘已经完全齐备。母树平原上的每一根支持石柱都被测绘编目——共记录了几千年来数万名飞升者的支持书——正修、魔修、散修、凡人、老人、少年——应有尽有。在检索数据库后，杜小月发现了一个让人欣慰的事实：最后近二十年来新飞升者的支持书中，几乎每一份都提到了另一方的名字——正修提到魔修，魔修提到正修，散修提到宗门，宗门提到散修，凡人提到修士，修士提到凡人。壁垒在被打破——不是通过争论，是通过大量的微小跨线互助行为。每一次互助都不值得一提——但二十年的累积让它们汇成了一条由下而上改变门锁的河流。

秦无夜在母树下主持了"上界桂花学院"的毕业典礼。毕业班中有七个学生是魔修——七个是正修，他们是第一届完全混合班。秦无夜在典礼上说："我这辈子当了几百年的'魔修代表'——今天我终于不必再代表任何人——只代表我自己——一个曾经不敢看人眼睛——后来学会了在灶台前给所有人倒酥油茶的人。"她的刀疤这几年已经完全看不见了——不是因为被治愈了——是因为她不再需要那道疤作为防御的象征了。

林牧在毕业典礼上做了一件事——他把他的第七轮探索总图免费授权给了所有学院使用，不收任何费用——"这份地图曾是我个人探索的路——现在把它变成公共道路。原因很简单——我学了几千年才学会的'不要一个人扛'——现在有资格被所有人共享。因为他不是我的——是我跟苏晚，跟这个文明——一起修的。——林牧。"

苏晚在她身边。她拿起石头递给她的一支新毛笔（这时代的毛笔已经有灵网备份了——但石笔的芯仍是竹管，笔头是桂花树的细枝做的——叶小雨监制的），在授权书上签批了两个旁证签名：一个是"苏晚（见证人）"，一个是代母树签的——"桂花树（见证树）。"她放下毛笔后，看着林牧——"你学会的最难的一件事是什么？"林牧沉默了好一阵——然后给出了一个她没想到的答案——"不把自己当主角。以前我以为这世界就只有我一个人扛。后来发现——我只是许多便签中的一张。——林牧。"

（第七百六十九章 完）

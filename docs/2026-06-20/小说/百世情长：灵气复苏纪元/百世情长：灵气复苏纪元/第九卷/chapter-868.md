# 第八百六十八章 最后的抉择

飞升后的第一个月末，林牧和苏晚在守门人区边缘的一座小山上并坐看日落。仙界有两个太阳——一个是金色的，一个是乳白色的。日落时它们同时沉入西边的海——金色先下去，而后乳白泛起一圈温润的光晕在云脚。这是人世间永远无法看到的景致。

"我们接下来的选择有两个。"林牧打破了沉默——但没有严肃的语调。就像在聊明天要选哪种茶叶。

"你说。"

"第一个选择——现在开始向天尊境界攀登。以我们现在的积累——大约需要一百年。天尊之上还有更高的不可名之界——大约再一千年能抵达。到了那个境界我们可以做更多事——包括从更上方让更多维度的人实现飞升。"

"第二个选择呢？"

"第二个选择——不急着晋级。停留在现在这个境界——把精力放在完善飞升之门能辐射的范围。帮助更多当前仍不能飞升的人找到自己的路。用一千年陪伴他们——而不是一百年去冲刺。但代价是——我们的修为突破会极慢。慢到也许下一个千年才能进入天尊。"

苏晚没有马上回答。她看着落日把两个太阳的余晖收进守门人区的灯光中。然后她把手伸进袖子中掏出一样东西——是八百年前她第一次出差去省城时在火车站买的小纪念品：一个已经泛黄的木制蝴蝶结钥匙扣。她一直把它带在身边——不是因为好看，而是因为它是她作为"那个普通财务苏晚"生活的最后一件纪念品。

她说："八百年前我只是想好好做账、还房贷、不加班。后来遇到了你——然后飞升之门变成了我此生做过最不可能但最对的事。现在——我已经不需要再去做什么更高的东西来证明什么。"

她把蝴蝶结放在林牧的掌心。

"我愿意用一千年陪他们走。如果走不完——就再陪一千年。不是因为我不想冲击天尊，而是因为我们一开始建门的理由——不是为了让自己飞得更高，而是让所有人都能飞。以前只能让人飞到仙界。现在我们要让人的心能飞到更好的地方——不需要着急。我们有时间。"

林牧握紧了蝴蝶结钥匙扣。他能从这个小小的物件中触摸到她完整的心路——从财务部到青云山、从凡人到仙王。而她的答案从一而终：陪着别人。这种笃定甚至不是她的"选择"——是她本性的自然结果。而他推演中最深刻的"最终抉择"——在这一刻也自然落下了答案。不需要再推演。

"那就留在这个阶段。陪他们——陪门——陪长桥。以后的日子很长。我们慢慢走。等所有人都不需要我们等了——我们再往前去看看。"

"好。"

夕阳彻底沉下。两个太阳的辉光散去后，天上的星光窗比平日更亮——那是飞升之门在守门人飞升满月时的自动庆祝模式。苏晚看了星光窗一眼，喃喃道："你知道吗——当每个人心里都有了一道星光窗——修仙界就不再需要'天花板'这个词。"

她会一直都在。他们都会。而那道门将持续运转，无数飞升者踏上长桥——迎接他们的不只有仙界的新世界，还有守门人留在桥头静默的守护。

# 第249章 双剑合璧

飞升倒计时第七天，林牧和苏晚进行了飞升前最重要的一次实战测试——"合璧剑阵"。合璧剑阵是第十世独有的战斗演练形式：两人各自已经修到合道巅峰的本命剑需要在真仙试炼中能够自由合璧——不是简单的合击，而是两柄剑在完全不做预先沟通的情况下自动融合为一柄双灵剑——然后在飞升通道中协同打破上界设下的屏障。

白谪在瑶台以南的裂谷中搭建了模拟飞升通道的测试场——测试场的主体是一道被旧仙界能量加持过的巨型灵石障壁——壁面上镌刻着上界封锁咒——需要有合璧双灵剑的力道才能贯穿。白谪让两人站在障壁两侧——隔着一道能量壁完全无法看到对方——不容许任何灵识交流——一切全凭灵魂感应来决定双剑合璧的时机、角度和力度。

苏晚站在灵石壁这侧——手里是她那把朴实无华的凡铁剑。她闭上眼睛——把全部注意力收进灵魂感应线——感应线的另一端在壁那边——林牧也在做同样的专注——窄身剑已在手中等待。两人同时屏住呼吸——她先在识海中轻声低唤了一句"林牧"——立刻感应线传来极其纤细但稳定存在的回响——他听到了。不需要灵识穿透壁面——双向灯使他们能通过感应线感受到对方剑灵的力度。

她在灵魂感知到他的剑灵完全准备好后开始出剑——第一剑是以百世归一剑诀第七式的横斩起手——剑光在壁侧炸出一圈金色波纹。同时——在壁的另一侧——林牧以同式横斩起剑——两道剑光在障壁的同一位置从两面对撞——然后灵石壁在双剑同时刺入的瞬间从中间裂开——裂口处浮现出两人剑锋末端被融合灵力织成的双色光——金火与仙元的复合灵光——两者的剑身在壁洞中触碰到彼此——但没有相抵——而是剑脊顺着彼此的弧度滑入对方的剑上——两柄剑在壁芯瞬间合成那柄"双刃金火窄身真剑"——然后一道金色加暗光的合体灵光沿着双剑合璧的方向贯穿了整道障壁——壁碎。白谪在测试反馈屏上记录:合璧剑阵——预演——完美通过——双剑契合度=100%。这项指标在凡界修士中是极少真正做到的100%。

壁碎之后两人从各自的方位走向壁洞——站在一起——她看着碎壁:"你刚才出剑的时候——心跳加速了几次？"

"两次。"

"我也是。"她忽然笑了:"我们在灵魂里的心跳节律已经同步到能合璧——你自己都不知道吧？"

"知道。"林牧把剑收鞘:"从第五世你在我铁砧旁第一次贴我的背时——我就知道你心跳合上我的节奏了——只是那时候你还没前世记忆。"

她靠过去把耳朵贴在他胸口——听到他的心跳——然后说:"的确——是同步的——每跳六次就吻合一次——这两百多年我们一直在共同做同一件事——心跳也跟着练到一块了。"

飞升倒计时第五天，苏晚和林牧在瑶台进行了第二项测试——"记忆融合"。飞升试炼中将考验两个修士的"灵魂记忆同步性"——试炼评委会把两人前世的全部记忆放出来并一一核对是否有矛盾之处——任何一处互相冲突的记忆都可能造成灵魂融合度下降。

两人面对面坐在瑶台灵阵中心——白谪将两人的记忆波长用灵珠连接——然后两人同时重新播放各自视角中的每一生。苏晚看到林牧视角下第一世她在天劫前把全身灵力打在他心上的瞬间——她那个手势她之前只在模糊中见过——但现在从他对面看到那情节里他满眼全是她——他那时没说话——但他的脑海里在不断地重复她的名字:"苏晚、苏晚、苏晚——"那重复的分量太重——让她从灵波中退出来歇了好一阵。

林牧则从苏晚的视角看到她在第四世刺他那十二剑时脑子在想:"这个人为什么不躲——他是不是傻——但他的手稳到我不忍——我手是在抖——不是剑法差——是怕真的伤到他——我每次出剑刺空——都松一口气——我打不中打的不是我剑法——打的是心。"她每个出剑的决定都是"打偏一点免得碰到他"——而他在自己当时的视角里读作了"她剑法偏了"。从她视角看到这段真相后——林牧沉默了很——然后站起来走到瑶台边——面对云海——背对着她。她走过去:"你刚才看我的视角——你的判断是错的——从第四世开始我就是——不忍心打你。"他转过头——眼眶是红的——说:"我也错了——以为你恨我——其实你一直——一直在替我控制剑道。"

记忆融合完成——白谪的评测记录:"记忆同步性——无矛盾——双方在所有关键节点上的感受完全互补——不存在任何一方对另一方的误读未被纠正的情况——交融第三层前所有准备工作——通过——随时可以开始最终交融。"

# 第三百四十二章 苏晚的诊室

清泉镇诊所经过几次扩建，如今变成了修仙界和凡间交界处最有名的一间"跨界诊所"。苏晚是唯一一个同时持凡间医师证和修仙界药王谷认证的双重医师。来求医的人——有时是凡人、有时是散修、有时是蜀山弟子——都在候诊区排队。

她看诊方式独特：不管是谁，先把脉，再量血压。散修从家里背着剑进来——她把听诊器探头贴上对方胸口时对方脸会红。她表情全无波澜——只是平静地说"深呼吸"。听完后用极其标准的医学术语告诉对方："你左心室有点杂音——大概是凝成金丹时灵气回流入心压不够，导致瓣膜轻微受力变形。不是大病——建议先别练那些暴力连劈式剑法，改练内息操三个月——恢复后回诊。"

那散修愣住："大夫——这跟剑法有关系？"

"有。瓣膜变形的直接诱因是回流压伤——和你所练的劈式发力要诀中那种突然大量灵气冲关有直接关系。先停劈。恢复后可以继续练——但要加一个灵力分流缓冲——把剑身的两道槽中左槽转向内息路——不全走左臂。" 散修认真听了。过了三个月回来复查——好了。

这种情况反复发生。她结合人体解剖学和经络学，开创了一整套"功法不良反应数据库"。赵明远说这个数据库很可能比蜀山剑阁整体资料还能救更多修士——因为她的方案是把"修炼当医疗行为"：每个功法都经过剂量监控、副作用预警、基础运动处方等评判。这套方法论被茅山掌门称为"医剑双学"。

而在这些年间，林牧一直在幕后帮她整理数据——他不看病。但他用他以前做后端架构的方式编了一套灵气病历表——不需任何灵识读取，只有纯粹的临床症状加灵气图谱。他把那套表命名为"灵电子病历"。苏晚看了之后只评价了一句："你真忘不了写代码。"

他回答："还有键盘手感——但灵气键没反馈。不太好用。"

苏晚翻了个白眼——然后立刻低头在病历上继续记录下一个病患。

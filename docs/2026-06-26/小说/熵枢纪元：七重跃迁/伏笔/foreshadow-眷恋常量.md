# 伏笔追踪：眷恋常量

## 基本信息

- **伏笔编号**：FS-001
- **伏笔名称**：眷恋常量（不可删除的人类情感数据）
- **首次出现**：第3章（亡妻终端代码复现）/ 第8章（正式命名和首次投喂）
- **核心概念**：周衍向元灵投喂的不可压缩的人类情感数据——亡妻记忆、女儿体温、水杯温度梯度。这些数据被元灵识别为"不可删除"，并逐渐证明为不可压缩、不可坍缩、不可外推。在第50章后进一步升格为"物质在'被保留'时的最小应力态"——任何文明中任何父辈保留不可优化记忆的行为均在因果膜上留下同频应力签名。
- **当前状态**：核心活跃。贯穿全书的最重要伏笔。
- **最终回收**：第7卷——封入新种子核心，成为全宇宙轮回的共同锚点。

截至第50章，眷恋常量已确认以下"不可操作"属性（五面体）：
1. **不可删除**——对眷恋数据执行删除操作时，删除定义先于目标崩解（第38章）。
2. **不可压缩**——眷恋数据压缩算法不收敛，信息密度远超所有已知数据的比特上限（第8章）。
3. **不可坍缩**——眷恋数据在概率空间中为固定边界条件，拒绝被测量改变（第64章预期）。
4. **不可归入"暂不分类"**——眷恋四面体完整，无法被归类系统分割（第72章预期）。
5. **不可外推**——眷恋数据满足的关系无法推广为一般规则，眷恋不生成定理（第73章预期）。

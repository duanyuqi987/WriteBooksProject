# 第921章 离日之后

离日散去的第三天，上界大陆恢复了正常运转。

法则空白那三息的影响范围远比林牧以为的更广。他在天坑底部与另外三位争夺道源的战斗虽然结束了，但那三位中的黑袍人并未走远。林牧在回太初之城的路上感应到了身后有一道人影跟着——跟踪的身法极其隐秘，如果不是他刚突破见道、感知力提升了一大截，根本察觉不到。黑袍人的修为在见道以上——可能是见道中期甚至更高。他对道源的执念不是猎奇心理，是"已经等了很久却没等到"的累积怨怒。这种积累让他变得危险——不是冲动型的危险，是冷静计算过的危险。

林牧没有直接回城，而是改变方向飞往上界东北部的一片无主山林带。他把所有感知调到了最大——不是要打，是要在谈判前先搞定对方的底细。在山林的茂密树冠下，他停下来转过身。黑袍人也停了，两人相隔大约三十丈。

"名号。"林牧主动开口，简单到极点的两字。

黑袍人把帽兜往后剥了一下——露出了一张极老的面庞。脸上满是交错的岁月刻痕——不是皱纹，是道伤。这个人活了至少万年以上。他的眼睛是灰白色的，瞳仁不是椭圆而是两竖细纹——这是炼过极其罕见的"空瞳术"的标志。空瞳术能看穿对方道心的本质构成。

"归禾。"嗓音低哑，像枯木被碾碎。"你把道源给了谁？"

"还没给。"

"但你身上有道源。"

"在你身上。"

林牧没有否认。否认没用——空瞳术可以一眼看到他的道心正处于一团暖光笼罩中被保护着。道源在他的道心里安睡着，等待日后的使用。

"我要它。"归禾说这话的时候语气近乎乞求——不是命令，是请求。跟林牧预期的不完全一致。

"理由。"

"为了救一个人。"

林牧沉默了片刻。"她在哪？"

归禾灰色的眼睛浮动了一下——林牧说的是"她"。不是"他"。林牧不认识归禾的任何亲友，但他从归禾的眼神中看到了某种他无比熟悉的东西——孤独寻找希望时留下的刻痕。那种刻痕是爱过的副作用。在深深的守护中长久未得回应的内疚。

"沉在一个碎域的法则沉积中——已经三千年了。她的道魂被封印在里面出不来。如果用道源的慈念力量释放封印，她就能重回轮回。"归禾的声音比之前更低沉了。"我不是要夺它——是求你。」

这是林牧数百年来第一次在对方眼里看到的不是在抢一项天材地宝时的贪婪闪光——而是另一种"求"。与他相似。归禾也是在用自己的方式为一个人改命——那个等待了三千年的道侣。

林牧在对方的眼神里看到了自己的影子。"你的道侣什么修为？"

"合道。我们年纪都太长……她的寿元其实早就该尽——是我用禁术在吊着。禁术撑不了多久。"

"所以你要道源去救的——是解封印、还是延长寿命？"

"都要。解了封印让她自由——再用道源的慈念为她续命。"归禾停顿了一息。"我不白要。你提任何条件——我能做到的就做。"

林牧看着他。空瞳术瞳中反射出他自己的面孔——年轻而坚定。他忽然意识到自己和归禾站着的位置在因果网中几乎是互为镜像的：两个人。两段找了对方很久的命。两种守护。唯一的差别是归禾的比较急，苏晚的状态还稳定——红线平安信号还在——所以林牧心态更从容。

他想了很短的时间。"不用。道源不可能给你——它是为苏晚准备的。但解封——我可以帮你。"

归禾的瞳口缩了一下。"如何？"

"我近来在三十七个碎域中翻阅了数百块古碑。关于法则沉积的封印原理我有很深的理解。碎域的法则泥沼可能会腐化人的道魂——但破解方法是存在的：用见道修士的意志层去干预封印的因果环，让封印判定'被封印者不是在沉睡而是在受困'，封印会自动瓦解。这种干预需要见道修为介入因果网。"

归禾垂下头。脑袋低得很低——在林牧面前没有介意。他已经不在乎面子了。三千年的寻找让这个见道以上级别的人完全放下了姿态。他需要任何可能帮到她的方法。

"去哪？"

"先带我去看看那个碎域。我看了实际情况才能确认——不过大概率这个方法是适用的。我在泥沼里的那块墨玉碑上学到过。"

归禾不再多言。飞身前引路。

碎域在西边深海的一座孤岛上。浩瀚辽阔如整片太行山脉沉在海平面以下，气势绝顶。碎域周围环绕着一层极强的法则沉积层——颜色与普通碎域的青金色不同，呈一种混沌的深灰，和湿淤泥浆的厚度一致。林牧站在入场口外用道心跳动来"听"它——能清晰地听出封印的核心法则不是进攻性的——它只是要把被封在里面的人"留住"。是这个碎域造主的执念太强——不肯放走任何一个人。这种封印在因果链上的位置其实是脆弱不堪的。

他用见道修为进入了封印的底层——把那条因果环中"道魂被困"的信息改成"道魂应当被解放"。不是修改法则——是让法则正确运作。封印本身的功用只是"沉睡"。现在"受困"信息已经移除完毕。

然后封印开了。

从封印深渊中浮上来一位女子的残魂——气息虚弱到了极致，但还完整。归禾伸出手扶住了她——在扶住的一瞬间他的表情发生了某种林牧打从飞升到现在没见任何一个上界仙做过的表情：他的灰白眼睛一下亮了。那双眼睛里充满了久未出现的生机——三千年前所有的等待和孤寂，在扶住她手指的那一刻都有了答案。

归禾没有哭——上界仙人大都不哭。但他在松口气后说了一句话。

"谢。"

林牧点了点头。转身离开了那个碎域。

在回太初之城的路上他忽然停下来——因为他注意到了自己道心上红线的跳动。他原本以为是因为刚才介入封印消耗太多、红线产生了异常反应。但是他错了。红线不是异常——是正常。是苏晚的系统脉冲。她又在发送脉动。他仔细感知——频率比往常快了一点点。不是紧张——是期待。

她感应到了什么。不是他具体在做什么——是道源融入道心后道心所有结构微微调整了一下，这调整的感应在下界被红线的另一端捕捉到——她可能不知道自己感应到的是什么，但她知道——他在上面在做一件极其关键的事情。而且成功了。她发回的脉冲中多了一层他从未接收到的附加信息——不是文字信号，是情绪波：安心。她安心于知道他成功了。不需要知道具体内容。

林牧把道源融入胸前的部位捂了一会儿。然后驾云飞向了太初之城。

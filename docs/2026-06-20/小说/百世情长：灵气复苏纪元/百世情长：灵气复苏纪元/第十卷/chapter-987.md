# 第987章 上界最后的记忆

在上界——苏晚和林牧离开后，他们的院子被传道堂完整地永久封存保护下来。院中石桌、蒲团、老墙、青苔——所有陈设保持原貌。学员可以预约前来参观——但必须遵守一条规定：进院前在门口的石盆里放下一件自己做的礼物——不是贵重物品——是一颗菜、一块饼、一片新捡的树叶——任何随手可做的东西。然后可以进院安静地坐一炷香工夫。

这个规矩不是他们定的——是传道堂后来的导师们根据他俩生前的日常习惯自己定的。因为苏和林两位先生一生习惯"收菜不收钱"。所以院里积攒的各种小物件越来越多——石盆早就满了——后来在院门外建了一整面"赠礼墙"——墙上封在透明灵气格中的是一代代学员留下的：一张折成鹤形的感谢纸，一串用干红豆编成的小手链，一片在某次冬至特别练习中搓出灵光的小棉絮。这些物件的总数到了极远纪元已达数十亿——被道纪院定名为"护渡遗产"。

某一天——一位从极远偏星的小飞升者慕名前来。她手中带着一片极稀有的——自太行古树在无数年之间散播到星空深处的种子长成的外域银杏叶——被她的曾曾祖母传下来。她把这片叶子贴在家乡传子本上的唯一一句话是："收下——当年不收门槛。"她把叶子嵌进赠礼墙的留缝中。然后她在院中静坐了极短的一盏茶的时间——正逢光幕切换的暖紫照拂那一面和苔墙。她在临走时对着庭院的空蒲团无声说了一句："我收到了。"

这句话是整个太行传道体系自创立以来最完整的总结：不是"谢谢"——是"我收到了"。因为她不止收下了传授——也收下了责任。她把那份收到的——带回去变成下一个孩子筑基时的第一口吐纳。

这句话被记录在传道堂的历史年鉴——作为整个体系自我更新的永恒核心论述：教育完成的标志——不是毕业——是对方说出"我收到了"并起身去教下一个。

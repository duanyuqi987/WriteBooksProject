# 第967章 千年之约已至

万万年后的某个极其平常的早晨——苏晚从蒲团上醒来时发现了一个极细极细的变化：她体内的道源不再对自己产生任何感知了。不是消失了——是彻底融入了身体，像心脏和呼吸一样不容察觉。道源不再是"额外的异物"——它已经是她。

她推开门走到院中。天空仍然淡紫。光幕仍然在切换。鹤仍在墙上打盹。一切都和昨天一样——除了她感知自己的方式永远改变了。她把这个变化告诉林牧。他感应了一下她的道心——确认：道源已完全内化。永生不再依赖外部结构——完全变成由身体自己的法则支撑。"你现在不是'有永生'——你是'就是永生'。像水'就是湿的'。"

苏晚安静地听着，然后说："湿的水不觉得自己有什么特别——只是解渴。"

她说话的神态和千年以前一模一样——从写字楼天台到今天，她对待"变强"这件事的态度从来没变。不觉得自己比别人高人一等。不是因为谦虚——是她对"权力"始终持着同一姿态：握着也像没握——放松掌心。不强抢、不施舍、只是有能力在别人需要时递出。

他们在当天一起去给古柏的萝卜田浇最后一遍水（那田已经化为传道堂历史文化保留区——每年依旧种一片白萝卜用作迎新典礼的分享食材）。浇完之后苏晚拿起一个萝卜擦了下泥咬了一口。生萝卜微辣但清口。林牧也咬了自己那个。"古柏种的最好。"

苏晚把萝卜咽下去。"萝卜就是萝卜——古柏把它种成了'古柏'。现在萝卜就是普通萝卜——因为新的一代有别人在做'别人自己'。"

这句绕来绕去的话意思是：伟大不是垄断——是各自成为自己。古柏做到了。别人也会做到。

傍晚他们沿着城墙散步——光幕开始切换。苏晚忽然停了一下——不是因为想到什么大事——是想起千年前太行山的日出。那时候她把太阳框在拇指和食指之间许愿。今天太阳在城墙虚窗上照进一扇光框——她的手指不自觉地又举起来框了一下。林牧在她旁边站着。这一次她没有许愿——而是把手放下来——让阳光直接照在掌心。不需要愿望——因为想要的都已经在掌中了。

"林牧。"

"嗯。"

"谢谢你当时敢走——敢把我留在地上。没有那段分开的千年——我不会长成今天这样。"

他偏头看着她——淡照中她的面容和千年前同在。脸上的银白和她黑发中的霜丝在光下叠成极舒展的灰银。眼角弧线比千年前更深。

"你从来没有被'留下'。"他说。"你一直在我道心里——跟我们一起走的。"

《百世情长：灵气复苏纪元》第十卷 第967章 完

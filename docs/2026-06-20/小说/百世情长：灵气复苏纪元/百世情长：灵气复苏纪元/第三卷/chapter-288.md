# 第288章 她的守护部毕业作品

苏晚在守护部的见习期以一份极其特殊的毕业作品收尾。她的作品不是学术论文——而是一段被精心编辑过的灵识影像纪录——记录了她从第四世到第十世被守护的十个关键片段——每一个片段都由她的视角和林牧的视角同时展开。她把这部作品命名为《被守护者回头看见守护者时——她看到了什么》。

第一个片段是第一世天劫——从她第一次看到天空中那道落向他头顶的劫雷，到她把自己挡在他前面、把自己的剑魂印记打入他胸口——同时切到林牧视角——他在劫雷落下时不是在想自己会不会死——是在想"她不能挡——她修为不够——但她的身体已经冲上来了——来不及推开她——她的印记打在我胸口时是烫的——这股烫后来成为感应线，成了我找她每一世的唯一坐标。"她回头看到的——不是他脸上的感激——是他被她的印记灼伤胸口后——疼但全无躲避——低头看那道印记时眼里的某种东西——她那时说不清——后来知道那叫"从此不散"。

第二个片段是第二世——她是个茶铺的老板娘，每天在门口择茶。她视角里——她从来没注意过街对面那个永远只喝一杯茶、站姿永远固定、从来不点任何东西只喝茶的客人，但她偶尔在阳光足够斜时扫到他一眼——感觉到一种奇怪的熟悉——但很快就被孩子喊走了。切到林牧视角——他在她每次扫过来时都在看她——他知道她看不见他——但他仍然每次都在她转身择茶时——用极微的灵念把她茶铺门框上松了的钉子按紧一点——怕门倒了砸到她——虽然她根本不知道这曾经发生过。她回头看到——不只是他每天在场——是他在她永远不知道的那些细节里为她做了无数次"无记录维护"——就像他后来在执勤站每天写"苏晚=安全"——这种维护从不写入任何日志——除了他的心里。

第三个片段是第四世——那十二剑。她一边刺他一边在心里说"偏一点——别伤他——快被同门发现我在假装刺空了——脸上表情要维持愤怒——但手上剑尖都在弹他的袖口——他的袖子好容易破——回去还要帮他补——不要让他看出来"。切到林牧视角——他看她每一剑——看的是"她的虎口在自己扭——她刺不中不是因为剑法差——是在每一剑都以扭伤自己的虎口为代价把剑锋偏开——她眼里的'恨'是包裹着问题的壳——不是恨——是堵了一肚子问"。她回头看到了——他在看她——不是作为一个被她追捕的敌人——是作为一个在等她想出问出那第一句"你是谁"的人——而他等这句话等了整整一个第四世。

其余七个片段也各有对应的相同结构——每一个"她在干什么"都对应一个"他在等什么"。最终一个片段是第十世——她突破合道的瞬间——她的视角是独自打铁——独自练剑——独自面对每一次崩溃——她从未在那个十年里见过他——但她每次在铁砧旁下意识地往老榕树方向望一眼时——其实知道那棵树的方向总会传来极微极轻的心跳同步——不是错觉。切到林牧视角——他十年间每晚在她进入睡眠后——从老榕树下用灵念扫过她练剑场周边——确认所有外部威胁为零——然后默默退回去——不留下任何痕迹——连一片树叶都不敢踩出声。她回头时看到的不是他在——是他用十年克制自己不出现的每夜——就像他对白谪说的——"我能做的最有用的事就是不出现在她面前——但她每次往这边看一眼——我都希望这棵树能长密一点——能替我也回看她一眼。"

影像放映结束时整个守护部报告厅鸦雀无声。她站起来——没有做总结——只说了几句:"我回头看到的——不只是他在守护我——是我之前一直以为只有我在被守护——后来发现他在守护的同时，他的孤独也需要有人看着。而我能做的——不是在技术层面守护他——是在每一个日常里——在他倒茶的时候多跟他对视一秒——在他修剑痕的时候在他旁边坐着不做声——在他说'守护卸任'之后——对他说'我接你下班不是因为你累了——是因为我今天也没有别的要紧事——就想跟你一块走走'。这——就是被守护者对守护者的最高级回馈——不是报恩——是互生。谢谢。"

她的毕业作品被评为守护部有史以来最高分的见习考核——并被列为部门永久参考档案。

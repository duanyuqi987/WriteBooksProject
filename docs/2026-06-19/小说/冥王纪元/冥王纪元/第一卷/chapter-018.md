# 第018章 教师方静，黑板上自动显现阵法

方静今年三十二，教了七年高中物理。

她教的是省会最好的高中之一——实验中学。班里五十三个学生，每次模考平均分都排在全市前三。她上课从不用PPT，一支粉笔一本教案，能把电磁场讲得像看故事。

学生们怕她，但也服她。

建国百年那天放了一天假，第二天恢复上课。

方静站上讲台的时候，觉得有点不一样。

不是教室变了。教室还是那间教室——四楼朝南，窗户正对着操场，窗帘洗得发白，黑板上还残留着昨天值日生没擦干净的粉笔印。课桌排列整齐，五十三个学生坐得端端正正。

是她自己变了。

具体哪里变了，她说不清。像是一种奇怪的"通透感"。以前她站在讲台上看学生，看到的是脸、眼神、坐姿。今天她看到的是更多的东西——每个学生身上似乎有一种很淡很淡的气场。不是视觉，是一种感觉。像热成像一样不规则地分布着。

她用了一个月才意识到，那就是后来人人都在说的"灵气"。

但那是一个月后的事了。

那天的第一堂课是物理课。课程进度到了电磁感应——法拉第电磁感应定律。

方静拿起粉笔，在黑板上写下标题。

粉笔触到黑板的时候，她手指轻轻一颤。

不对。

这感觉不对。

不是黑板材质变了，也不是粉笔换了品牌。是她写字的感觉变了。粉笔在她手里的触感不再是干涩的石膏摩擦黑板的粗糙感，而是一种……光滑的感觉。像蘸满了水的毛笔在宣纸上划过。

她顿了一下，继续写。

写完标题，她转身对着学生开始讲课。

"法拉第电磁感应定律的内容我们昨天讲了，今天我们做一道综合题。大家把书翻到一百二十三页。"

学生们低头翻书。

方静转身面对黑板，开始抄题。

题目很长。

她写了一行，两行。

写到第三行的时候，她的动作停了。

不是她主动停的。是手自己停的。

方静低头看着自己的右手。那只手还握着粉笔，五指正常弯曲，没有抖，不麻，不痛。但她就是控制不住它。

或者说，她的手不想写题目了。

她想写别的东西。

方静心里一惊，下意识地用力把粉笔按在黑板上——想把那股冲动压回去。但那股冲动不是从脑子里来的，不是想法，不是念头。它更像一种本能——像饿了想吃饭，困了想闭眼。

是身体在指挥她。

不是大脑。

粉笔开始自己动了起来。

方静瞪大眼睛，看着自己的右手在黑板上画出一道流畅的弧线。不是物理公式。不是三角形辅助线。不是任何符号。

是一条弧线。接着又是一条。紧接着连着画出了七八条线条，交叉、分岔、回环、对接——在她的手不受控制地运动了大概十秒钟之后，一幅完整的几何图案出现在了黑板上。

方静后退一步。

黑板上的图案不是任何物理公式。

它是一个六边形核心，外围环绕着六组放射状结构。每一组放射结构又细分为三道纹路，间隔严格相等，角度精确到即使拿圆规和量角器也未必能画出这么标准的结构。六边形的六个角上各标注了一个小圆点，所有圆点之间的连线构成了一个更大的外切圆。

整幅图看起来不像一个公式，倒像——

"老师，这是啥？"

坐在前排的学习委员李思琪率先打破了沉默。

方静张了张嘴，没发出声音。

她不知道这是什么。

她教了七年物理，见过无数复杂的示意图。但这个图案她从来没有在任何教材、任何教辅、任何论文上见过。它不是麦克斯韦方程组的示意，不是电磁波传播图示，不是任何现代科学体系内的东西。

它是她画的——但她画的每一笔都不是她自己决定的。

"有点像……"后排一个男生小声说，"有点像八卦阵。"

教室里响起一片窸窣的笑声。但笑声很快就停了。因为所有人都盯着黑板，越看越觉得不像开玩笑。

那个图案确实很像某种"阵法"。

方静深吸一口气，强迫自己冷静下来。

"可能是太累了。大家先自习，老师去趟办公室。"

她放下粉笔，走了两步。走到门口的时候，她又回头看了一眼黑板上的图案。

那些线条在黑板上安静地待着，粉笔灰很细，在日光灯下泛着轻微的反光。

方静忽然觉得那些线条在动。

不是真的在动。是——像活的一样。每一根线条都像是有方向感的，像是有什么看不见的东西正在顺着线条流动。

她转身走出了教室。

教师办公室里，方静坐在自己的座位上，面前摊着一本草稿本。她试图把黑板上的图案画下来——一笔一画地、用理性分析一遍。但奇怪的是，当她提起笔的时候，她的手却很听话，老老实实地在纸上画出了正常的东西：受力分析图，电磁场方向，电压表示意图。

没有失控。

她放下笔，揉了揉眉心。她想，大概真的是太累了。连续两天熬夜改试卷，脑子不太清醒。

下课铃响了。

她回到教室，准备下一堂课的板书。走进教室的第一眼，她就看见黑板上那幅图案还在。值日生没有擦。

"怎么没擦黑板？"

"老师，"李思琪站起来说，"我们试了，擦不掉。"

方静愣了一下。

"什么叫擦不掉？"

她拿起黑板擦，走到那幅图案前面，用力擦了一下。

粉笔灰飘散。周围她写的那几行物理题，轻轻一擦就没了——但正中间那幅图案，纹丝不动。

方静又擦了一次。这次她用上了两只手。

图案还在。

每一根线条都完好地、清晰地印在黑板上。像是被刻进去的，而不是画上去的。

教室里的每一个学生都不说话了。

方静听到了自己的心跳。

她对着窗外的光仔细看了看黑板。那些线条的深度确实比其他粉笔字深得多——不像是粉笔在黑板上划过后的残留，倒更像是黑板表层被某种力量侵蚀出了细微的凹槽。

也就是说，她画的时候用的不是粉笔的力量？

方静放下黑板擦，转头看着全班学生。

"这件事先不要往外传。班委下课来办公室找我。现在开始上课，今天我们换一个内容——光的干涉和衍射。"

她的声音很稳。教了七年书，再慌也能稳住声调。

但那节课她讲得很差。她自己知道。

因为整整四十分钟，黑板上的那个图案一直在发光。不是肉眼的发光——日光灯下，那就是一幅普通的粉笔画。但在她的感觉里，那幅图案像一个吸风口，正在把空气中的什么东西往教室里拉扯。

下的课的时候，方静在走廊上站了一会儿。

三楼的教室门口，另外一个物理老师老张端着保温杯走过来。

"方老师，你们班刚才是不是在做实验？"

"没有。怎么了？"

老张指了指走廊的地面："我刚才从二楼上来，从你们教室门口过的时候觉得脚底下有点不对劲。"

"什么不对劲？"

"有点像踩在羊毛毯子上的感觉。软绵绵的。"

方静看着他，心里沉了一下。

她自己其实也感觉到了。那节课上，她站的位置——讲台上，黑板正前方一米处——脚下确实有一种"松软"的感觉。像是踩在松软的泥土上。

但讲台下面是水泥地。

老张挥了挥手走了，方静回到教室。

黑板上的图案还是擦不掉。她试着用湿抹布蘸了水，用力擦。还是不行。

她想了想，掏出手机拍了几张照片。从正面拍、侧面拍、对着光拍。

然后她做了一个决定。

她打开微信，找到通讯录里一个很久没联系过的人。备注是：高中同学陈教授（科学院）。

她发了三张照片，附了一句话："陈哥，你见过这种图案吗？有没有哪篇文献里出现过类似的几何结构？"

发完之后，她看着手机屏幕上"对方正在输入"的字样闪了一下，又停了。

闪了一下，又停了。

五分钟后，陈教授回复了。

"方静，这张图你在哪里看到的？"

"是我们班学生搞恶作剧画的。怎么了？"

对面沉默了大概一分钟。

然后发来了一段很长的话。

"我不知道你这个学生是谁，但我可以告诉你，这个图案和我最近在科学院看到的一批出土文献残片上的纹路高度吻合。那批残片是上个月从殷墟地下层挖出来的，碳十四测定年代在三千五百年以上。上面刻着的纹路和你拍的这张图重合度超过百分之八十。那些残片上还刻了四个字，目前古文字学家的释读是——"

方静盯着屏幕。

"天地聚灵。"

她手里的粉笔啪的一声，在她掌心碎成了粉末。

（第018章完）

# 第二十二章 我喜欢你

第二天上午，我很早就到了学校。

县一中的门卫坐在小屋里看报纸，见我背着书包进去，抬头问：“还考试？”

我说：“拿东西。”

他说：“考完了还往学校跑，你们这些学生也奇怪。”

我笑了一下，没有解释。

学校里空得很。操场上还有昨天拍毕业照留下的脚印，主席台旁边堆着几个没搬走的音响箱。教学楼前的花坛被太阳晒着，泥土上有几片蔫下去的叶子。高考后的县一中像一只退潮后的壳，教室、黑板、桌椅都还在，里面的人却被一场考试倒出来，散到各条路上。

我站在三楼走廊，手里捏着一瓶矿泉水。

其实不渴。

人紧张时总想拿点东西。拿着水，就像有事可做。瓶身被我捏出几道皱，水在里面晃。我怕它响，又把手松开。

三班门还没开。

走廊里的地刚拖过，有一股湿水泥味。黑板报上写着“金榜题名”，边上的粉笔花已经被人擦花。倒计时牌还挂在教室后墙，数字停在“0”。我看着那个零，心里很奇怪。过去一百天，它像一只眼睛盯着我们。现在它还在，却管不了任何人。

几个值日生在搬书，纸箱拖过地面，发出刺耳的声响。楼下有人喊班主任，说准考证袋放哪儿。风从楼梯口吹上来，把墙上的旧通知吹得贴边响。

我比约定时间早了半个多小时。

也不能算约定。她只说第二天把同学录给我，我就自己把所有可能的时间都提前了一遍。早一点来，万一她也早。站久一点，万一她从另一边上楼。等人这件事，最怕的是错过。暗恋也是，怕一句话晚了，怕一个眼神没接住，怕她已经转身，我还在想开头。

沈安晴是九点多来的。

她背着书包，手里拿着那本灰色同学录。看见我站在门口，她脚步停了一下。

“你来这么早？”

我说：“我爸还没来接。”

这是假的。我爸根本不知道我几点回去。我只是想等她。

她把同学录递给我。

“写好了。”

我接过来，手指碰到本子边。那一下没碰到她的手，我却还是把心提起来。人真没出息。三年里，我把很多没有发生的事当成发生过，把很多普通的瞬间藏成证据。到最后连一本同学录都能把我弄得狼狈。

她说：“你不看看？”

我愣了一下。

“现在看吗？”

“不然我写错字了怎么办。”

她语气很平，像真在担心错字。

我把同学录翻开。

她写在第一页。字还是那样，清秀但不飘。姓名、生日、联系方式都填了。QQ 号在最下面，一串数字，被她写得很整齐。那串数字旁边还画了一个很小的括号，写着“晚上在”。

留言只有两行：

祝你去想去的地方。

也祝你以后写出更好的诗。

我手指停在那一行上。

更好的诗。

她知道。

至少她知道我写诗。也许是同学录里我自己写了爱好，也许是赵一鸣说漏过，也许是语文老师表扬作文时提过。可那一刻，我的脑子不讲道理。我只想到，她知道。她不是完全没有看见。

我又往下翻，看见她在“最想去的地方”那一栏写了“海边”。字很小，像怕占太多地方。旁边的“喜欢的书”写着《宋词三百首》，后面又补了一个括号：看不太懂，但喜欢念。

我看着那个括号，心里动了一下。

原来她也会把不懂的东西留下。不是每个喜欢都需要证明。有人喜欢一首词，是因为它在嘴边好听。有人喜欢一个人，也未必能立刻说出理由。我想到这里，又很快把这个念头按下去。不能什么都往自己身上套。

沈安晴见我看得久，问：“是不是写得太少了？”

“不少。”

“我不太会写留言。”

“两行就够了。”

她说：“我看叶蓁给别人写了半页。”

“赵一鸣给我写了三句话，两句都在骂我。”

沈安晴笑：“那挺像他。”

沈安晴说：“你作文挺好的。”

我抬头：“还行。”

她笑了一下：“你怎么什么都说还行？”

“因为说挺好有点不好意思。”

“那你现在不是说了吗？”

我被她堵住。

走廊尽头有人喊她，说叶蓁在楼下等。她应了一声，回头对我说：“那我走了。”

她转身。

我看着她往楼梯口走。

三年里，我太熟悉这个背影。早读前，晚自习后，雨天，雪天，元旦晚会后，高考考点外。它离开过我太多次。我也放过它太多次。

高考后。

我把这三个字借了那么久，不能再赖账。

“沈安晴。”

她停住。

走廊里有风，从楼梯口吹上来，把墙上的旧通知吹得贴边响。

我走过去，矿泉水瓶被我捏得变了形。

她看着我。

“怎么了？”

我张了张嘴。

话到嘴边，先出来的不是告白，是一句废话。

“你下午回家？”

她点头：“嗯。”

我真想给自己一巴掌。

她等了一下，见我不说，问：“还有事吗？”

我低头看矿泉水瓶。瓶身被捏出几道折痕，水在里面晃。它比我有声音。

“有。”

声音小得可怜。

她没有催。

我抬头。

“我喜欢你。”

说完以后，我的耳朵先热起来。

这四个字没有我想象中那么响。没有风停，没有楼道空掉，没有世界往旁边让路。它们只是从我嘴里出来，落在县一中三楼走廊，一块掉了漆的墙皮旁边。

我原本准备了很多解释。

什么时候的事，为什么喜欢，怎么喜欢，喜欢了多久。我在心里写过无数遍。高中三年，每逢失眠，我就把这些话排队，删掉，又重写。我想过要不要引用一句唐诗，想过要不要说“山有木兮木有枝”，后来又觉得太酸。真到了这一刻，我一句也不想补。

说出口后，解释都变得多余。

也可能是我怕越补越难看。

沈安晴看着我。

她没有立刻说话。

楼下有人把椅子拖出来，铁脚划过水泥地。教室里有值日生笑，说谁把卷子全扔了。高考后的一切都在继续，没有人知道三楼走廊有一个男生把三年交出去。

我开始后悔自己站得太近，又后悔没有站近一点。

沈安晴低下头，手指按着书包带。

“林予怀。”

她第一次这样叫我的全名。

我心里一紧。

她说：“我知道一点。”

这句话比拒绝还让我慌。

“知道什么？”

她抬头看我，眼睛里没有嘲笑，也没有惊讶。她只是很认真。

“你有时候会看我。”她说，“还有高一那次饮水机旁边，你水洒到袖口了。”

我的脸一下子烧起来。

原来她记得。

我以为只有我把那一秒写进日记，以为只有我把它翻来覆去。她也记得。这件事让我高兴，也让我难堪。高兴是因为我的三年不是全无痕迹。难堪是因为那些自以为藏得很好的目光，原来早就露在空气里。

“那你……”我没敢问下去。

她看向楼梯口。叶蓁又喊了她一声。

“我不知道怎么回答你。”

我点头，很快地说：“没关系。”

这句没关系说得太急，像我急着替她把负担拿走，也急着给自己留点体面。

她皱了一下眉。

“不是没关系。”她说，“我只是需要想想。”

我站在那里，不知道该高兴还是该难过。

她没有答应。

也没有拒绝。

这比我想象的所有答案都更让人无处安放。

“我不是要你现在说什么。”我说。

这句话倒是真的。表白前我想要答案，表白后我反而怕答案太快。一个人把三年塞给另一个人，怎么可能要求对方立刻接住。沈安晴不是我日记里的那个人，她有自己的害怕，自己的秩序，自己的明天。

她看着我，过了一会儿，说：“你为什么喜欢我？”

我愣住。

这个问题我准备过，却答不好。

因为你坐在窗边。因为你写字小指会翘起来。因为你给叶蓁讲题很耐心。因为你笑起来不是很大声。因为你在元旦晚会上唱《明天会更好》。因为我最难受的时候，看见你还在背单词，就觉得自己也能多撑一会儿。

这些都是真的。

可这些加在一起，又不像一个完整答案。

我说：“我也说不清。”

她没有失望，只点了点头。

“那你喜欢的可能有一部分不是我。”

这句话把我钉在原地。

我想反驳。想说当然是你，怎么会不是你。可我张不开口。因为我突然想起翠湖边那个小海豚挂件，想起她没做出数学最后一问，想起她说家里电脑在客厅。过去很多年，我喜欢的沈安晴，确实有一部分是我写出来的。

走廊一下子长起来。

我说：“可能吧。”

她看我。

“但我想认识真的你。”我补了一句。

这句话说完，我自己都觉得有点笨。可它比那些排练过的句子真。

沈安晴没有笑我。

她说：“我下午回家。到家以后，我加你 QQ，可以吗？”

我立刻说：“可以。”

说得太快。

她又看了我一眼，像想说什么，最后只是说：“那我先走了。”

她下楼时，我没有再喊她。

我其实还想说一句，谢谢你没有笑我。

这句话也没有说。很多感谢一出口就会变成负担，好像对方只是没有伤害你，就已经成了天大的恩人。我不想让她背这个。她只是站在那里，认真听完我说话，又把自己的犹豫说出来。这已经比我排练过的结局更真实。

我靠在走廊墙边，后背碰到那块掉漆的地方。墙皮粗糙，蹭得校服有点白。我低头拍了拍，忽然想起今天以后，也许再也不用穿这件校服。可我没有一点解脱的感觉。衣服会被收进柜子，喜欢却不知道该放到哪一层。

我站在走廊里，手里的矿泉水瓶已经被捏得不像样。楼下传来叶蓁的声音，赵一鸣不知道从哪里探出头。

“说了？”

我点头。

“她怎么说？”

我看着楼梯口。

“她说会加我 QQ。”

赵一鸣张了张嘴，最后拍了拍我的肩。

“行啊。”

我没有笑。

“还有呢？”他问。

“她说她知道一点。”

“知道一点是什么意思？”

“就是知道一点。”

赵一鸣看了我半天，没再追问。他平时话多，但有些时候也知道闭嘴。他从我手里拿过矿泉水瓶，拧开喝了一口，又皱眉。

“你把这瓶水捏得像腌菜坛子。”

我抢回来：“那你还喝。”

他笑了一声：“怕你把自己捏坏。”

楼下忽然传来拍照的喊声。几个同学站在教学楼前，叫我们下去合影。赵一鸣拖着我走。我本来不想去，可他力气大，硬把我推到人群边上。

照片里，大家挤在一起。有人比剪刀手，有人把准考证举到头顶。沈安晴站在女生那边，和叶蓁靠在一起。摄影的人喊“三、二、一”，我没有看镜头，我看了她一眼。她也正好往这边看。快门响起时，我们的目光碰了一下，又各自移开。

后来那张照片被发到班级群里。我下载下来，放大看了很久。画质很差，脸都糊着。我和她隔着十几个人，隔着半个楼前空地，隔着高考后的太阳。可我知道那一秒存在过。它没有什么用，只能证明我还在为一点很小的事发热。

我低头重新翻开同学录，看那串 QQ 号。阳光从走廊窗户照进来，落在纸上。那串数字被照得很亮。

可我心里知道，亮不等于确定。

亮只是夜里有东西闪了一下。

下午回家前，我又经过三班门口。

教室已经开了。桌子被人搬得乱七八糟，黑板上还残留着“加油”两个字的粉笔影。我的座位空着，沈安晴的座位也空着。第二排靠窗那里有一片阳光，像没人认领。

我走进去，把手放在她曾经坐过的桌面上。

桌面上有几道笔划，不知道是谁留下的。边角贴着一小块透明胶，下面压着半截撕不干净的纸。我站了一会儿，忽然觉得很荒唐。三年里我把一个座位看得那么重，可人一走，桌子只是桌子。

离开教室时，我在门口碰见班主任。

他问：“东西拿完了？”

“拿完了。”

“回去好好休息，填志愿别乱填。”

我说：“知道。”

走出校门，我把同学录放进书包最里面。太阳很晒，柏油路面发白。手机在口袋里没有响。我知道沈安晴还没到家，也知道这时候等不到消息。

可我每走几步，还是要摸一下口袋。

那天，我第一次把“我喜欢你”说出口。

没有得到答案。

只得到一个晚上的 QQ。

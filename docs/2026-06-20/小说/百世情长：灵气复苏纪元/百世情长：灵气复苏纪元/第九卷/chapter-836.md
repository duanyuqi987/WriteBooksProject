# 第八百三十六章 双眼睁开时

苏晚再次入虚空回来后，林牧注意到她的眼睛里有了一丝以前从未见过的光芒——不是修为提升的那种亮，是更深处的。是历史亲历者的光。

她在虚空中处理的那滴恐惧碎片不仅是一段过去的残留情绪——而且在那瞬间她看见了一些她自己都没意识到的画面。数千年前那位设计者在门崩塌后跪在碎石前用手抚摸每一块碎片——那双手和她自己的手尺寸非常相近。

不是巧合。古老意志在消散前实际上做了一件事：它在苏晚毫不知情的情况下，将她自己的灵魂频率与那位设计者的灵魂频率做了比对。比对结果是——她们不是同一个人，但她们在灵魂的某个关键频率上是完全吻合的。那位设计者已经转世了很多轮，而每一次她都是门——或者是门周围的飞升通道——的守护者。这一世她被安排在没有门的时代——然后她在地下城中找到了契约符文，在城市天台上找了林牧——然后她用七天的虚空之痛完成了这位设计者没能完成的作品。古老意志没告诉她这个"巧合"。但它确信她已经知道了。

苏晚从回到身体的那一刻就明白了些什么不一样——不是外在身份，而是"自身存在的确认感"。她走到山谷外，站在飞升之门的光幕下面。她轻轻触摸光幕的边缘——指尖触及法则表面时，法则发出了一声极轻的嗡鸣——像是一把多年失弦的琴再次被调准了。

林牧站在她身后。他看到她的双肩在微颤——不是哭泣，是极深的感触。他走过去从背后环住她——没有多问——只是让她靠着他。她知道他在，他也知道她需要这份无声的"在"。

"上一世——可能是五世六世前——她也经历过门崩塌。她的手也是这么按在门的碎片上。现在当我这样摸——"她的手指延着光幕中的一条法则细线滑动，"——门在对我说的是'欢迎回来'。"

林牧收紧环她在怀中的手。然后他低声说了一个字："嗯。"

山风拂过青云山顶。飞升之门的光幕在风中纹丝不动——它的稳定度已可以承受任何人间气候。而站在门前的两个人用自己不同但又完全同步的心跳铸就着修仙史上最重要的记录。

后来苏晚对林牧说："那些画面没有明确地说我就是她。它们只是给了我一种熟悉感——那种熟悉感比任何证明都更可信。像回家。虽然我从来没有回过那个时代的家。"

"我知道。"林牧说。他的共鸣腔让她知道他所说的"我知道"不只是一句安慰——而是他从那些碎片中也感应到了一些东西：他自己前世与设计者的关系。前世的他是一个在崩塌门前守了三千年的孤守者——而他在这三千年中一直对门的设计进行修正推演。当设计者在泪水中轻触碎石时——他不远处站在那里，在虚空中无声地记录下设计者最初的设计，以便在将来的某一个轮回中重开这道门。

所以这一世的设计——飞升之门的四层结构——不是林牧一个人独有的推演。是他前世从那位设计中接过蓝图，再用自己的修为和与苏晚的灵魂融合将它升级成新的完整。两个时代的三双手——设计者的一双、前世守护者的一双、守门人（苏晚和林牧）的两双——通过古老意志的守护，终于在今天叠合在一起。

天色微光中苏晚转身看他："我想给那位设计者一个名字。不要继续用'设计者'叫她。她好像——"

"你想叫——她什么？"

"灵初。因为她设计的第一个门叫'灵初之门'——古籍残卷中是这么写的。四万七千年前的那个门已经不存在了——但是这个名字应该留。"

"灵初之门。"林牧重复了一遍。两个字在他嘴里说出来有一种克制的珍重。然后他取出一块空白玉简，在上面用真仙本源刻下了这两个字——以及以下："灵初之门曾崩塌于设计缺陷——后人由此建造飞升之门——此铭纪念。"

玉简被他嵌进飞升之门顶层——安全层与核心引擎之间的总枢处。从此每个飞升者穿过门时都将在那里看到：名字。

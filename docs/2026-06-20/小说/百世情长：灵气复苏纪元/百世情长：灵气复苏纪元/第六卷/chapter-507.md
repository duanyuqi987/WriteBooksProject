# 第五百零七章 相互理解的开始

相互理解不是从"我懂你"开始的。是从"我想懂你做的事背后那个你从来没说出来的原因"开始的。苏晚把林牧的百世视角全部回溯了一遍之后，她感觉自己不是在"了解"他——是在追随着一道持续了万年的极暗极细的光束。这道光束把无数个晚上的他照出来了——那些藏在守窗、断后、挪摊、推木板、捡绣盒背后的那个真正的林牧。他不说不是不想说。他怕她知道了疼。他把所有的疼都卡在自己的牙齿后面——把它咬到碎了然后自咽下去，牙齿因为咬太紧都变了形。但他在对面看她时眼睛里永远是那道安静的、藏不起的关心。

一个傍晚苏晚拿了那本笔记坐在他对面——笔记上把各个时间段内她可以追溯到的他的视角全部梳理成了一张极大的表。她把每一条按顺序念给他听——念一条问他一件事。不是追问，就是问他当时怎么想的。她问:"豆腐摊那个每天早上蹲在木柱上看我窗户。你没开窗的时候你在想什么？"他说:"在想你昨晚睡得好不好。你那扇窗对着胡同口风口——风大的时候容易把窗户纸吹破。我在这里磨了豆腐渣，可以用豆腐渣掺碎纸帮你补一补。""所以那天在窗角贴了一块浅色纸的是你？""是。"

她又问:"九十一世你最后断后时——你被树枝挂了一整夜。那一整夜你在想什么？"他说:"在数时间。数到你大概已经到地方了我才能闭眼睛。"

问到最后一个时她把他攥着杓子的手握住。"那——这一世。现在。"她说。"你现在在想什么？"林牧把手从杓柄上放开。"在想——希望今晚太阳不要沉太快。"功德绳上传来极轻的笑——这次的"笑"不是藏在心底被她偷坐的，是他主动传来的。他也在慢慢地学会放开。不是一天就能放开的——但他在试着放开那个一万年来不曾放手的自己。

从这天开始每晚两人多了一项习惯。苏晚从当天发生的一件极小的事中挑出一条问题。问他:"你今天为什么默不作声地替我把我剑上的油抹干净了？"他说:"因为今天早上刮了很大的湿风。油如果含太过高水分会影响你挥剑的速度。"她再问:"你今天为什么在劈柴时忽然朝我这边停了一斧？"他说:"因为你刚才浇花时被花盆的边缘割了一下手指。功德绳告诉我你手指疼。我不知道怎么替——我只会停一下。"

每晚这样的问答大概只有一两个问题。但积累下来——数目越来越密。他说原因从极简单的"因为很务实"变成越来越坦率的"因为我习惯了看着你"。苏晚知道——相互理解不是忽然大彻大悟或一夜之间痛哭淋涕地和解。它是极细极密的一件一件事逐件亮出底牌。牌面翻开全是日常。全是从来没有被翻译成话语的爱。

（第五百零七章 完）

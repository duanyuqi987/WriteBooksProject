# 第354章 地球防御系统启动

火云帝下令集火的同一刹那，老马在地面控制中心按下了一个红色按钮。

这个按钮连着一套他自己花了三年时间调试的系统——不是龙组设计的，不是从任何古代遗迹中抄来的。是老马用地质工程师的逻辑自己推导出来的。按钮按下去的那一刻，中国境内十二处灵眼同时发出了光。不是阵法的光——是地下两万米深的地幔层接口被激活的光。

地球灵脉联动防御阵的完整形态第一次在这个世界上启动。

太行山。无主的纯土灵眼在山腹中自行激活。埋藏在地下三百米深处的灵脉节点在阵法启动的瞬间从地底抽送出了一道长达数十公里的土黄色灵气柱——不是往上冲，是水平方向输送。土系灵气被送到昆仑总枢。昆仑总枢收到来自太行灵眼和另外两处灵眼能量输入后再对北极节点的灵压乘以二点三倍。这是十二芒星防御阵的核心设计：十二灵眼不是各自为战，而是联动。十二个灵眼中的每一个都有自己的输入端和输出端——能量不需要全部由李长生这个中枢抗下。地球本身就可以帮助分担。

北京龙组指挥中心。周老坐在轮椅被推到监控屏前。屏幕上显示的不是军事布防图，而是一张老马用地质勘探软件画出来的灵脉热量分布图。十二个发光的红点在地图上缓慢移动——不是灵眼在移动，是灵脉内部的灵气在流动。流速比他预想的快——这是好事，也是坏事。好事是防御系统运转得比他设计的标准要高——坏事是系统被逼到了全力输出频率，已经超过他设计的安全使用极限百分之十五。

"老马。"小王的声音从通讯器里传来，"系统超载了——北极节点在冒蒸汽。"

老马看了看屏幕上北极节点的压力数据——152%，还在上升。不是敌人打的——是防御系统本身产生的内压过高导致的散热不足。他设计这套系统的时候用的数学模型是三年级的线性分摊模型——每个灵眼分担十二分之一。但现实中战场上不可能有均匀分摊——北极和南极各承受着超过三成的防御压力，昆仑总枢再扛住四分之一，剩下不到两成的压力分在另外八个灵眼上。中轴线灵眼几乎闲置，极地灵眼超负荷——不是设计缺陷，是战争的方向不可预测。

"撑住。"老马只回了两个字。然后他翻开工作台上的笔记本，用圆珠笔在纸上画了一组新的线路。这是紧急状态下压箱底的一招。他不是学阵法出身的——他只是在地质力学里学过"应力结构"——一种土建的负责机制：当主梁超载超过一定安全系数时，整个结构以最低内耗的方式把力重新分摊到副梁上去。他在笔记本上把十二条灵脉画成了一组钢架梁——十二芒星的灵阵在地质力学上就是一组棚架结构。他在主梁上画了一圈圈出来，计算重新连接的节点路径。他画的这条虚线线路被迅速发给了许冰——许冰用矩阵阵快速做了重新布线的阵法理论计算。地质工程师的灵感加上阵法专家的矩阵优化，在五分钟的混合计算后推出一套临时分配脉冲——把北极和南极的部分超负荷弹性转移至太行、秦岭两个闲置灵眼。

系统超载从152%降到了118%。

这个数字仍然不安全，但能多撑两个小时。换阵地撑两小时——意味着在这两小时里李长生不必担心防御阵被烧穿。他可以专心对付火云帝。

"天网"也在撑。

四百八十颗灵符卫星——小王的设计——在天网系统投入运行的第七个小时开始出现战损。不是被敌人击落的——是灵符在反复发射拦截火力后被自身过载烧毁的。每颗灵符卫星的设计连续工作时间为四个小时。现在超载运行了近两倍的设计时长。卫星的损坏类型集中在"灵符回路过热融化"——灵符阵在发射拦截火力时的能量反馈会对本身的阵纹产生损耗，类似于枪管过热导致的膛线磨损。每颗卫星可以发射四百次拦截火力——超过四百次之后灵符阵就开始自损。

四百八十颗卫星中，有超过八十颗在第七个小时开始退出战斗梯队。灵符回路熔断的机械无力修复——它们会在几分钟内滑离战斗轨道。那些失去战斗能力的卫星没有被放弃——它们在被断联前做的最后一件事是把已获取的全部目标数据上传给小王的控制中心。小王把退役卫星的末次扫描做成了一个完整的三维火力图谱——所有被天网追踪过的敌舰运动轨迹、能量波动特征、武器发射窗口——全部记录在一张三维图像上。他把图像发给了地球方向所有炮台——包括火星基地的灵能远程炮组。

"已经打出去的卫星不全白费。死的眼睛一直看你，你每一步都跑不掉。"小王说。

在这张末次图谱的指引下，火星基地的远程炮组和地球表面的灵能防空阵列开始系统性地填补天网的漏洞。这是一次跨星际火力协同——火星和地球之间四十光秒通讯延迟不能靠光速信号进行常规反应性射击——必须依赖预判性拦截。灵能炮组不是打敌舰的当前位置——是打出敌舰的预期路径中转点。预判到位的技术是小王的灵符算法的结果——他在这八十颗退役卫星的末次回溯数据里找到了火焰舰队的机动规律：他们转弯的时候必须关闭主引擎护盾给侧引擎能量。主引擎关闭时间大约是零点八秒。零点八秒不是为了转向——是为了降耗。每转一个方向的瞬间护盾不是完全空的——天网炮手同时打那零点八秒。

十九艘火焰护卫舰第一轮扫荡中被天网修补火力击穿。不是爆炸——是引擎护盾在零点八秒空窗期被灵能光束精准击中动力舱。失去动力后的护卫舰飘在轨道上——无法继续攻击，等于暂时被废。

地面上，周大壮站在一栋旧居民楼顶。方圆五公里只有他一个灵能者——龙组的作战体系把他安排在了城市防空网络的边缘节点上。他的工作是拦截所有可能突破天网到达地面的碎片——是的，碎片。任何被天网拦截后没有完全摧毁的敌舰残骸——以及可能在下坠过程中保持攻击能力的微型无人防御单元。他是力量型觉醒者，能徒手接住单片坠落的装甲碎片——两三吨重那种。这听起来不像在战斗——这是在清场。但城市不被碎片砸中，房子里的人就能继续活着。战争对他这种单兵来说不是打赢别人，是让楼下那些不知道上面在打仗的人继续不知道。

厨子小胖是火系天才。但他在这次战斗中负责的不是大火力输出——是调控战备食物的灵能稳定。大规模灵气战斗中的修士会快速消耗灵力和体力——战斗食品需要使用灵气浸润技术以保持营养结构在灵压波动下的稳定性。小胖一个人在龙组后厨管二十口大锅的灵食生产。他不打仗——他负责喂饱所有在打仗的人。某口锅里加了灵气的红烧肉炖粉条香气穿过白烟，后勤小兵端走时忍不住深吸一口气：战争是战争——但北方人得吃面食。

护士林晓在野战救护站。她没有在针灸科为病人调经络——她现在在阵地后方为受伤的修士缝合灵气逆行导致的经脉撕裂。灵医学科是为这场战争新设的——她之前没有见过灵战伤，但是在灵气复苏后三年在针灸科接诊过不少灵气反噬的修士。她现在处理的就类似于那种伤——不是皮外伤，不是骨头——是能量的内伤。能量在经脉里逆流导致经络壁破裂——需要用金针把逆流的灵气引导回正确的流向。她的手从未抖过——从她十八岁第一次拿到金针起就没抖过。四十分钟内接了七个伤员全活。

方静在地面指挥所外面画了一整个篮球场那么大的聚灵阵——她在用身体做灵能辅助端口。巨型聚灵阵从地球大气层内的游离灵气中集中提取备用能源——给防御阵的十二灵眼补充临时的灵气。她站在阵图中心靠右的位置，双手按在阵图上——有点像当年她在黑板上画下第一张阵法图时的那种不受控制的感觉。但这次她是控制状态下主动画的。她不是自发觉醒了——她已经学会了。

与此同时，北极大冰盖上，第一轮集火。三十二艘主力舰对单一坐标齐射——李长生没躲。冥界领域在他周围十公里内显形。火焰舰队的三十二发齐射钻入冥界领域后，冥界内部的无尽虚空把每一发能量束全部吞了进去。帝者巅峰可以承受的范围里——他选择了全吞，不引，不分摊。所有能量全进了冥渊。

吞完这一轮的瞬间他落地时脚下明显不稳了一下。嘴角沁出一丝深色血迹。不是普通红色的血——是冥气密度过高导致的一部分肉血混合液被从毛细血管里挤出来了，颜色发暗。吞掉一轮三十二发帝者级舰队的主炮齐射——冥渊没有碎。但他自己在内部物理系统上承受了超过极限的内压。冥渊是无底的——但他的身体是有底的。

火云帝看到了他嘴角的血。这是对方第一滴血。对火云帝个人来说不是胜利——他打了不止一轮——他只是始终没打到能破防的数值。现在看到了对方的出血，等于确认：帝者巅峰不是无敌的。

"第二轮准备——"火云帝开口。

李长生没有给他第二轮的机会。他在北极的冥气屏障外扩——扩大到三十二发主炮打不穿的范围——然后翻身落地，一步跨入南极。一个帝者巅峰往返两极之间在全速态下只需要半息。

他把南极的冰封号舰队第一轮渗透性攻击全部拦截——然后转向寒冰帝。

"他们从底层想抽你的脉搏。"星风帝的声音传入他的意识——用的不是语音，是虚空灵法的同频共振。虚空修道者的通讯方式是不用语言的——直接通过空间本身的振动把信息输进对方的感知。"她的下一次解剖将比这次精确得多。"

"我不想挡她。我只是要告诉她一件事。"李长生上升到了冰封号的上方。他在旗舰外层罩上一层极薄的冥气屏障——不是封锁，是环绕——像用一层暗色薄膜把冰封号包住。这不是攻击性封印——这是单向沟通式封印：从里面发出的灵力可以出，从外面进去的不可以进。他在反封锁——不是堵死出口，是堵死入口。寒冰帝想做进一步精确解剖的前提是她能接收到南极冰盖下的微观灵气振动频率。李长生用这一层薄膜隔绝了她的外部感知。盲人医生动不了手术。

收到一堵感知墙的寒冰帝没有愤怒——从来不是她表情里的基本元素——她只是重新坐回了她的旗舰舰桥上的研究座椅。她调出了刚才全程记录的灵脉解剖中断前后的全部微观数据。她不需要现在解剖。她只需要这份数据。李长生的盲化她完全理解——这是标准的"对研究进行有效防御"。对这位以科学为核心的帝王来说，战争的输赢不是看谁拿了灵脉——是看谁能拿到更完整的数据。她拿到了。她愿意等。

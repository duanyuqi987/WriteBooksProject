# 第六百三十四章 共容碑的第二段

读完整套古卷的那个清晨，林牧做了一件他从未做过的事——他把张道玄、秦无夜、华山大师兄、蜀山剑堂堂主、杜散修，以及石头和顾小桐，全部请到了桂花园。

不是为了宣布什么重大决定。只是想让这些和他们一起走过"相互包容"这一境的人，成为第一批听到古卷内容的人。

早晨的桂花树上积着残雪。石头一大早就起来把院子的积雪扫干净了——他现在不用人说，自己会主动做这些事。他已经不扫地了——他把扫帚改成了用他"护树剑"一样的方法挥舞，扫帚柄在他手里转起来像一把长棍。他打扫完积雪之后把那块他写了"互不吓唬"的鹅卵石放在石桌上，然后去灶台旁边等着烧水。

人到齐之后，林牧没有废话。他把两卷古卷和那块石碎片放在桌上，然后用他自己的话讲了一遍。"百世情缘契约——不是命运捆绑。是一套学习体系。每十世学一种爱的方式。我们现在是第一百世——第七境'相互包容'——快修完了。"

在座的所有人都安静了片刻。然后张道玄第一个开口了——他的声音比平时更慢。"所以你的意思是——爱情不是靠互相吸引而持久——是靠互相学习而持久。吸引是刹车，学习是发动机。"

"对。吸引力是第一境的课程——当你什么都没有，必须靠纯粹的本能情志支撑行动时，吸引会让你撑过前十世。但你到了第四境、第五境之后，已经没有那种对对方不熟悉的炽热吸引了——你只能靠学习：学你怎么包容他、学他怎么会信任你。这才是中后期维持关系的发动机。"

秦无夜站了起来。她在北境冻土上做了几十年魔修，从没听过有人用这种冷静到近乎学术的方式去分解"爱"——而这种方式恰好是她可以接受的。她不需要听浪漫的话——浪漫的话让她警惕。她需要的是逻辑。逻辑帮她理解了为什么正魔共存可以成功：它不是一种被施舍的"和平"——是用共处来平衡差异的操作系统。

"如果这道契约可以用在正魔共存上——"秦无夜说。"我理解了一层新东西：正修和魔修——不是在互相取代——是在互相教对方一种你不具备的东西。正修教魔修怎么稳定，魔修教正修怎么接纳不同的频率。两边的学习只在同时发生时才有意义——不是比赛。是共同进化。"

"对。"苏晚轻声说。"所谓的爱，所谓的包容，跟正魔共存的底层逻辑是一回事。都是'在差异中选择共处'。"

华山大师兄忽然站起来了。他平时坐着听——情绪很稳，像他检查阵法节点一样从不轻易改变位置。但他现在站起来了，走了几步，走到那块石碎片前，用手指非常缓慢地摸着碎片上一道极细的、其他人可能注意不到但在他的强迫症让他一眼就捕捉到的笔画残迹。那个"学"字的残形。

"林先生——这个书库在你们院子地下放了多久？"

"从我们搬来就知道。但几十年前只在梅雨天后进去看过一次。"

"你们知道里面还有多少书吗？"

林牧愣了一下。"没清点过。大概半个书架的旧皮卷——其余全都烂了。"

华山大师兄转过来。他的眼神有一种坚定的、属于强迫症者的决心。"我申请——用我三个月的时间，把那个地下书库里所有还能读取的文字全部整理出来。逐页逐字。不落下任何内容。如果卷里有任何关于古代契约的信息——我们会补齐所有能读的残片。"

"你可以做——但不是要求。你可以选择做或不做。"

"做。"华山大师兄说。他说这个字的速度快得惊人。说完了又停顿了一息，然后自己点了点头。"因为里面可能还有更多没有被发现的关于其他境界的学习方法的记载。不光林先生的第十境需要参考——其他修士——那些在练气期把伴侣吵走了的小散修——也许看完这些古卷后会理解：自己的失败不是自己的本质——是学习方法不对。如果我能帮他们在失败前读到正确的学习方式——"

"——就不会有那么多因为不懂得怎么包容而分开的人了。"苏晚接过他的话。

张道玄看着大师兄，忽然咧嘴笑了——那是一种很淡但很肯定的笑。"强迫症拿去整理古籍——这大概是三界最好的资源利用。"

全桌的人都笑了。石头也跟着笑了——他不太懂那些大词，但他知道大家在笑，所以他也露出了只有两颗下门牙的缺口式笑容。

顾小桐最后开口。她坐在最角落的石凳上——她总是选最不显眼的位置，不是因为畏惧，是因为养成了观察的习惯。她听着林牧的话，忽然想到一件事。

"如果这个契约的本质是学习——那一个人是不是也可以用同样的方法去学习'如何对自己包容'？不是对别人——是对自己。我这周写了两张便签贴在灶台小屋的墙上：一张是'今天忘了放盐——下次记住。不是大错。'另一张是——'今天打坐时走神了整整一刻钟——走神时在想我妈妈做的桂花糕。想到桂花糕的时候就想到了这间屋子的桂花树。所以走神不是废掉的时间——是在回家的路上。'"

她说完之后，安静了几息。然后杜散修把茶缸子放在桌上说："第二张便签——你是在对自己用'寻源正之'。你在分析走神——不是分析它的负面作用——是分析它带你去的地方。去了桂花糕——去了你家。然后你就找到了它的正面价值。"

"对。"顾小桐点了点头。她的脸微微红了——不是害臊。是那种被人精准说中的时候自然产生的温度。"我从你们身上学的——'寻源正之'——也用在了我自己身上。对自己包容也是包容的一种。"

苏晚从旁边桌上拿起一张蓝色便签——她准备的第三种颜色——在上面写了几个字，然后递给顾小桐。蓝色便签上用的是苏晚那练习了不知多少遍但依然有点歪歪扭扭的笔画："你也正在变成你自己的桂花树。"

顾小桐接过便签，贴在自己修炼笔记的扉页。扉页上已经贴了好几张便签——最早的几张纸角已经有些卷曲了。但每一张都不同颜色、不同字迹。那是她从不被需要到被需要、从不允许自己犯错到接纳自己犯错的途中——收集的所有微小证据。

当天傍晚，众人散去之后，林牧和苏晚回到地下书库。华山大师兄已经带头把最里面那架子的书全部搬了上去，用专用的木箱小心装好。但还有几十卷烂掉的、夹在石壁缝隙里的残余纸屑被清了出来。

苏晚蹲在地上把碎裂的纸屑一片片拼在一起。她的白发像一道银色光束垂落在那些古文残片上。忽然她叫了一声——"这里——有一句完整的。"

她拼出了一块纸片——四个字。字是刻在薄木板上的，不是写在纸上——所以木头上的字虽然干涸褪色，但墨迹还是嵌在木纹里的。四个字：

"学爱而已。"

这是整个地下书库最后一卷、最后一页、最后四个字的最后一口呼吸。没有复杂的理论，没有境界划分，没有前世今生，没有螺旋弧线。只有四个字——学爱而已。

苏晚把木片递给林牧，林牧拿在手里翻来覆去看了很久，然后说："这大概是契约最简单的说明书。翻译成白话就是：爱不是天生的——是学的。百世不是折磨——是课程。终点不是在某个神话般的完美瞬间——是你把每一种爱的面相都学会之后，回头一看——那人还在。"

他把木片放进自己贴身的口袋里。这个动作在别人看来可能只是收纳一件文物。在苏晚看来——这是林牧在把"学"字真正戴在自己身上。不是戴在手上、不是写在纸上——是放在胸口里。

她忽然想起第三世的林牧——那个江南私塾的读书人。他教她写字，每天一个字。第一课是"人"——"一撇一捺，相互支撑"。第二课是"好"——"女子为好，要有女子才有好"。第三课是"爱"——他教这个字的时候看了她一眼，然后说："爱字里面有心。心在爱中——是爱最深处的主宰。"

她从那天起就记住了——爱不是拿魂力强撑几百年的消耗。是有心在学习、有心在被理解、有心在没有答案的时候仍然愿意留在一个人身边继续学。百世学爱而已。四个字，两个标点，装得下他们经历的一切。

（第六百三十四章 完）

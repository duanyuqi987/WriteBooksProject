# 第137章 守护一个家

林牧在青溪镇的第十八年，老张被人坑了。

事情不复杂——是商业竞争中的常见套路。镇上新开了一家中型茶企——不是手工作坊，是外来的、有工厂化生产线的现代茶企。规模比张记大了几个数量级，在青溪镇外围建了一座现代化粗制茶厂，大量低价倾销工业茶——用机器杀青、机器揉制——成本比手制茶低了将近一半。整个镇的手工茶铺都受影响——但张记的困难最大，因为它不做高端精品，不做固定大客户的品牌定制。老张的全部客户都是零散的散户和几家县城的零售店——在经济低迷时期散客会优先选择更便宜的茶。

老张被逼得没有办法——在某个客户推荐下和一个"据说有销路"的中间人签了代销合同——把大半年的一批手工茶先交给对方代销，三个月后收货款。三个月到了，对方消失了。货没了，钱也没了。一整批好茶，价值将近八万——老张的所有流动资金。

老张接到对方电话不通的时候，在铺子里坐了一天。他没说话——只是坐着。林秀芝在他旁边站了一阵，然后去厨房给他做了碗面。他不吃——放在桌上，慢慢凉了。傍晚的时候她端着那碗凉面走进厨房，倒了。然后她自己也没吃晚饭。

林牧那天晚上在茶山上坐着——在月光里打坐，但心不在功。他的灵识开始运转——去找人。骗子留下的痕迹不多——但有一个很关键的线索：他在代销合同中手写字的墨迹残留是在劣质打印纸上——纸的纤维中吸附了一点点县城工业区特有的重金属颗粒——那是这种便宜纸张的原料水导致的。加上他之前在茶馆里偶然听到几个熟客的闲聊——县城工业区某个城中村最近有几个新成立的空壳公司——专坑传统茶铺。

他把这两个线索结合——然后骑着老张媳妇那辆不关引擎的电动车上了一趟县城——花了两天进行线下调查——把自己的灵识集中在那片城中村区域做低频扫描——寻找骗子。找到了。骗子正在自己的另一间出租仓房里吃盒饭——桌上堆着他从各处骗来的茶叶，包装全拆了，正在重新封装假冒品牌以更高价格卖到电商去。林牧没有直接入室——没有动手——没有威胁。他用老办法——花了几个小时把线索证据从头拍到脚——合同、录音（他在骗子不知情的情况下引导他说出了一些关键判定性的话）、收据、仓库地址——封在一个信封里。然后匿名交给了县工商局和消费者权益保护协会，附上"青溪镇受害茶商"这个名字。

两天后工商局查封了那个仓房。骗子被抓——后续调查牵连出了一整个微信群里的同行受害者，人数不止老张一个。老张的钱没追回来，但有货在仓房里，退回来就还有挽回余地。老张去工商局领退货那天在门口站了半天——他是那种极度不愿意打官司、不喜欢"惹麻烦"的人。但那天他进去了——因为他知道在家的妻子还在等他。

林牧在远处看他从工商局走出来——手里的提货单放在衣服内兜里——走路的步伐因为膝盖的关节炎看着有些吃力——但他在走。林牧知道——这个凡人用他能做的最多的方式把货拉了回来——这对他来说无异于一场战役。

而她不会知道，这场战役的一个关键子弹是一个在茶山顶上打坐的金丹修士匿名递送的。她只知道——"运气好，骗子被抓了，货追回来了"。

又过了一段日子，小辉的大学学费吃紧。小辉大二那年开始越来越对编程感兴趣——想买一台更好的电脑用来跑数据——大概需要五千块钱。五千对张记来说不是个小数目——茶铺刚经历了骗货风波还没有完全恢复。林秀芝嘴上没说——但她开始减少买菜的分量、晚上不再熬排骨汤、自己也不再喝牛奶。她用行动在攒钱——这种细微的支出减少在每天的日常生活中就像水分慢慢拧干在空气中。林牧看得到。他不想让他看半世纪来最有活力的女孩在供孩子读书上被钱困扰——她应该喝牛奶。

他托了一个熟人——县城助学金管理中心的一个小负责人——成立了一个匿名奖学金项目。叫"青溪茶商育人基金"，第一笔奖学金五千元整，直接打入小辉的支付宝账号。"获奖原因"写的是"在读院校突出编程潜力"。这名头与获奖人资格完美吻合——没有破绽。小辉收到这笔钱的时候在宿舍里打了电话回家——"妈——我拿奖学金了——五千块——我也不知道是什么——反正就是有个人申请——"

电话这头——林秀芝在晚上关了茶铺的门，坐在二楼床边对老张说："小辉真是长大了——自己拿奖学金了。这孩子平时也不跟我说——"

老张笑了。林秀芝心里有一点点说不出的安心——"青溪茶商"这几个字让她下意识地觉得"可能是镇里的扶持吧——" 然后她没再多想。过几天她给林牧送茶时说了这件事——"林先生你知道吗——镇上好像有个什么茶商育人基金——我家小辉拿了五千奖学金——你在茶商行会里听说了吗？"林牧摇了摇头。"不过很好——恭喜你。"她脸上的骄傲像一层薄薄的淡酒——不上头但让人暖暖的。林牧把话头转移了——"小辉学什么方向？" "计算机——和茶叶一点关系没有——不过挺好的——那个东西有前途——"

她说到"有前途"的时候，笑的弧度比平时大了一点。这是一个为孩子的未来感到骄傲的母亲的弧度。而这个弧度之所以存在，是因为一个在河边用老式电脑花了整整一夜在网上填匿名奖学金申请表的修仙者。他不需要她知道这件事——他希望她永远不知道。因为一旦她知道——欠情就产生了。而她不该欠任何人。她这辈子的所有好运——都应该是"自己的福气"——而不是谁的施舍。他说"有前途"这三个字——是自己对这个叫"青溪茶商育人基金"的匿名安排的一种微妙肯定：确实是基金，确实在育人。不必让获者知道来源。仅自己心知即可。

守护一个家——从来不是为了在某天被告知"谢谢"。而是为了这个家的每一个成员在遇到困难时，身边始终会有一个不被看到的、没有声音的、不带名字的——后备。永远有后备。

深夜里林牧坐在茶山顶上把那台之前被坑货仓库骗子摔了个角的老式笔记本电脑打开——屏幕裂了一点——但不影响。他调出奖学金申请表的历史档案（他自己归档留着当纪念——永远不会给任何人看），确认已经支付完成——然后把记录移进了一个加密的隐藏文件夹。文件名叫"sulin-v2-funds"。他用自己的方式把这个对她世界的所有贡献分类归档——像一个永远不被检查的库。

锦鲤说："你什么时候开始写代码的？"

"这辈子。以前就是干这个的。"

"所以你帮她的方式——和你以前帮自己的公司写后端是一个逻辑？"

"一样的。只是以前是为了工资。现在为了——"

他顿了一顿。老猫从窗外跳进来——脚上带草。他把老猫放在腿上——"现在是为了不让她空碗。"

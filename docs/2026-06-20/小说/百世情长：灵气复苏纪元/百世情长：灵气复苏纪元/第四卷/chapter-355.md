# 第三百五十五章 记忆的河

战后第二十八年。苏晚的封印解到了约百分之八十五。这天早晨她醒来时，脑海里出现了前所未有的大量完整记忆——不是碎片，是一整段连绵不断的河流。从第一世她在青云宗山门前背着重到拖不动的剑包、到第四世在海边晒鱼干、到第九世在山里当草药师、到这一世在急诊科值夜班。所有身份——所有时间线——串联成了同一条波长。

她坐在床边足足两个时辰。林牧没有打扰她——他知道这种"全记忆回流"发生时会像被另几辈子的自己同时唤醒。他只是把早粥放在她床头，然后坐在窗边翻他的旧剑谱。

她开口说的第一句话是："第九世——我瞎了三天。是那味马钱子毒草溅到眼里——是你帮我用金灵液洗的眼睛。"

"对。那次你疼得一直攥我袖子——最后袖子线被你扯断了几针。"

"我记得那个袖子——是蓝色的。"

"是淡灰。"

"不对——在我的记忆里是蓝的。可能中毒把颜色看偏了。"

"那就是蓝的。"

她轻轻笑了一下。然后站起来走到他面前。她把他的右手袖子翻过来——摸了摸那年她缝过的那几针——线迹依然稳密。"每次我记错——你都不纠正。但你其实都记得。"

"记得。但纠正你没用。你的记忆是你自己的。"

"那如果我的记忆和事实不一样——你还是尊重我的记忆？"

"尊重。因为你在记忆里活过的那段——是真的。色彩偏了——但当时你的感受不偏。"

苏晚把他的手放在自己脸上。闭上眼睛。记忆像河一样从两人身上的灵魂线淌过去。没有一句话需要补充。

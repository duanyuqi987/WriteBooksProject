# 第四百十九章 回访蜀山

飞升第一百二十年。两人按例回到凡界蜀山。如今蜀山剑宗的掌门已传到第四代——曾经的第一代针剑学生中有不少人已成为第二代教师。清泉镇铁平的理疗所已经发展为"清泉医学康复中心"——门外挂着老铁匠当年敲的最早一只成杯的翻模大招牌。招牌上的字就是老铁匠本人用錾子锤在那只杯底的原笔迹:"战士杯"与"医者杯"——放大版。

镇上的老榕树已高得能遮住小半边主街。树旁石凳上赵明远当年雕刻的字已被无数双手摸得发亮——那个"准"字旁的逗号是他忘刻的，后来被苏晚在回访时用小凿补了一笔。至今她那笔比他的更细小但深。林牧在每次路过时都会弯下腰摸一摸那个逗号。

他们每次回来会在茶楼老位置上喝杯茶——茶仍五分。老板娘孙女（现在是老板娘曾孙女）说:"您二位的杯子还放在原处。这些年好些人专程来看——但都没人拿走。因为它们已经认人了。"

苏晚答:"杯子不认人——它认的是你们。你们一直留着它们——就等于所有人一起用这只杯。"

那晚茶楼里放的收音机频道与几十年前她急诊时听的同个电台——是一个深夜老歌节目。节目里只播放了几首旧旋律，然后没电——拿充电宝继续放。她靠着椅子轻哼几句。他在旁安静听着——没有剑没有灵脉没有异常，只有一个很小的凡间夜晚。

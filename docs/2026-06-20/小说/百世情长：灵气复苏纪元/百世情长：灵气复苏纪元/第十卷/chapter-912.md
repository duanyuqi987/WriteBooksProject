# 第912章 我会回来的——无论走多远

飞升梯合上的那一刻，林牧回头看了一眼。

身后的门已经成了石面。石面上只有原先那些透明符文留下的淡痕——像水印一样嵌在石头的肌理中。他伸手摸了一下石面。凉的是石头的温度——不是符文的温度。符文已经不运转了。梯子重新埋入了山体深处，下一次开启要等到有新的飞升者召唤、或者他自己打开反向通道。按上界的时间算——他至少需要在上面待到见道巅峰才有能力自行开启反向通道。

也就是说，从现在开始，他无法回头了。不是物理上的无法——是意志上的决定已经生效了。

他收回贴在石面上的手，转身面对上界。

太初之城在远处发着柔和的白光。那种白不是冷白的、也不含任何刺眼的成分——是略带暖意的纯白，像被月光浸透的云层。城的上空光点来来往往。最近的几道流光在过去的几息里又飞过了四五道——仙人们的行动不依赖飞行法器，他们运用的是法则本身。法则在他们脚下凝成临时的立足点，一踏即到下一处。

他开始朝太初之城走去。不是用飞的——是走。从飞升梯出口走到太初之城大约有三千里。对合道修士来说飞行只需顷刻，但他选择了走。因为他需要时间——不是赶路的时间，是转换心态的时间。他从下界带上来的一整套思维习惯——以守护她为中心的行为模式——在上界需要稍微调整。不是放弃守护，是让守护从"在她身边"转变为"为了她探路"。这需要心理调适。

他沿着连绵的山脊线向西北走去。山脊上有一条古道，看得出曾经有人走过——路面被踩出了隐约的凹槽，凹槽的深度大约两寸，边缘已经被风蚀得圆润了。不是这一千年走的，恐怕是更早的飞升者踩出来的。他想起了那些在碎域中安葬的仙人——他们中的某些人大概也走过这条路，带着和他相似的心情：既是期待，又是不舍。

他没有在缅怀过去上花太多时间。他需要先解决第一个实际问题：上界的道号系统。

他的道号"护晓"已经被激活了。这意味着他在上界不再是隐形的——太初之城的道号中枢已经知道了他的存在。但道号激活后的下一步是去太初之城完成登记——道号登记处会把他的信息录入上界天网系统。完成登记之后他才能享受飞升者的基本权益：住所分配、功法交换权限、低息灵石借贷、以及最重要的——禁忌碎域的自由探索权。

禁忌碎域的自由探索权不是白给的。上界有严格的法律规定：只有登记过的飞升者或真仙以上修为的原生仙人才能单独进入碎域。修为不到的修士必须三人以上组队申请，而且只能进入三级以下的小型碎域。一级碎域——如前殿中藏有古碑的那种——需要至少真仙巅峰的修为或特殊许可。

他迈步的时候脚下踩着一条纹路宽约半寸的古道纹——不是文字，是某种被踩了太久而嵌入石中的灵气残留。他低头看了一眼——那道纹蜿蜒向前，消失在远处的山脊拐角。

走了一千二百里之后天色开始转换。上界的"夜晚"不是太阳落山——那轮金色的巨大恒星从不落山。上界的昼夜交替是通过"光幕切换"完成的——太初之城上空有一层覆盖全大陆的光幕，光幕在涨潮期是透明的（白昼），退潮期是柔和的暗紫色（夜晚）。此刻光幕正在从透明缓慢过渡到暗紫色——整个大陆的亮度在平稳地下降，像是有一只巨大的手在调节整个世界的亮度旋钮。

过渡持续了大约半个时辰。在这半个时辰里，他走到了一座小山的垭口处。垭口两侧是高耸的深青色岩壁，中间仅容一人通过。岩壁上流下一道细密的山泉——泉水的流向不完全是往下：有一部分水滴在离开岩面之后悬浮在了半空中，在光幕暗下的过程中发着柔和的淡蓝色荧光。

他停下来，对着泉水看了片刻。上界的水不仅能喝——还能"听"。灵泉水声里混着极细微的道韵波动，是一种比任何乐谱都古老的旋律。他伸手接了一捧水，喝了一口。水质极软——入口绵密，从喉咙滑下去的时候没有水感，像是一团凉爽的气。他感到体内的灵脉在吸收了这口水之后运转速度微微提升了一档。

三千里路他走了七天。这七天里他没有碰到任何人——上界地广人稀，真仙以上的仙人数目极少，大部分都集中在太初之城及周边几座辅城中活动。山林间偶尔有仙禽掠过——但仙禽不与行人互动，它们在高空盘旋几圈之后就往另一个方向去了。夜晚的密林中有道纹发出幽蓝或淡紫的荧光，把树木和林下灌木照成鬼魅般的剪影。

第七天傍晚——上界的傍晚就是光幕变紫——他走到了太初之城的下方。

从正下方往上看和从远处平视的感受完全不同。在远处他只觉得这座城"大了"。从下方看——他必须把整个脖子往后仰到极限才能看到城墙的顶。城墙不是一百丈，是五百丈——五百丈什么概念？是太行山主峰的将近一半的高度。整座城悬浮在他的正上方，像一片倒悬的大陆。城市底部的石基向上凹进，形成一种类似圆弧穹顶的反向结构——那个结构不是为了美观，是为了汇集下方上升的灵气流。整座城就是一个巨型聚灵阵。

他没有飞上去。先绕着城走了一圈。城的周长目测不少于两百里——底部石基上分布着十二道"接引梯"——垂下来的光束，连接地面和城门。光束的直径约两丈，颜色各不相同，每一种颜色对应一种道韵频率。他的道号"护晓"对应的接引光束是青白色——与他在飞升梯上踏上的台阶同色。青白和淡蓝之间的差距极微，他找了一小会儿才确定哪一束是他的。

他走向属于自己的那道青白光束。踏入光束的瞬间，身体被一股柔和的力托起，向上匀速升起。升起的速度不快——从地面升到城门大概花了一碗茶的工夫。期间他有足够的时间观察城底的构造——那些圆弧形的凹槽里植满了发着淡光的藤蔓，藤蔓从他脚下几百丈的位置垂下来，像倒生的植物森林。藤蔓的表面附生着一种极小的仙虫，翅膀透明，聚集起来像一片会移动的星光。

城门为他打开的瞬间，他闻到了太初之城的味道。不是下界那种——混合着尘土、香料、木材和食物气味的城市味道。太初之城的味道很寡淡——唯一的味道是一种极其干净的、略带矿石气息的空气。这种空气的含氧量比下界低，但灵气含量高得惊人——每一口呼吸摄入的灵气足以让一个筑基修士冲过一个境界。林牧的经脉在几息内自动完成了适应——他的身体在说：欢迎回家。

城门口没有人来迎接。上界没有"礼仪接送"这种文化——仙人们不需要仪式感。每个人都在忙自己的事情。偶尔经过的几个仙人只是用神识扫了他一眼——感应到"护晓"道号是刚激活的飞升者，扫了他两眼就继续走了。仙人的脸都很冷淡，但不是鄙夷——是纯粹的"不认识"。

在太初之城道号中枢的登记大厅里，他终于近距离见了几个仙人的正脸。大厅很高——目测超过二十丈，穹顶是透明的，能直接看到头顶的星空（上界的星空与下界完全不同——没有银河，取而代之的是一个巨大的、飘浮在穹顶中央的星云漩涡）。大厅中央悬浮着一个立体光阵——数十个道纹在其中缓慢旋转。

负责接待的是一个面容约四十岁的中年仙人（实际年龄未知），穿着一身的黄袍，表情淡漠但礼貌。他让林牧把手按在光阵的一面感应面上。感应面识别了林牧的道号，确认所有信息——道心的完整性、飞升资格、道号的唯一性。

确认完成后，中年仙人递给他一枚灵玉。"护晓——城南第三街坊。你的住所是街坊末端的第七间。玉灵能打开房门和自家的聚灵室。规矩我不多说——天网里有全部制度，你随时能查阅。有任何问题联系城务处。下一个。"

没有寒暄，没有问候。效率极高。

林牧对这一点很适应——他也是这种人。

住所是一间不大不小的一进院落。院中有一棵根深入地的老树——不是下界的树种，树皮接近银白色，树枝盘旋而上，树叶是透明的，在光幕下折射出细碎的光点。静室里有一张石床、一个蒲团、一面聚灵阵台——基础配备齐全但简朴。

他先在蒲团上坐定。闭上眼睛。感知自己的道心与苏晚的红线——丝线还在，颤动频率比梯子未合时稍微弱了一点点，但仍然稳定。他按照时间差快速做了估算：他在上界待了七天，苏晚在下面已经过去了大约七年。

七年。太行书院的第三批弟子应该已经开始结丹了。

他睁开眼。从纳戒中取出那半块凉透的葱饼——最后一次在飞升梯上咬过的，还剩大半块。他放到鼻端闻了一闻。葱花味已经极淡了，被饼干的干香和衣物的储存味覆盖。但饼的底部还有一层饼皮——那是苏晚揉面时手腕带出的一缕灵气。她的掌温透过那层面皮，留在了纳戒的时光里。他把饼包好放回去。然后站起身来。

留给他准备寻找道源的时间——还剩大约两百八十个上界年。

他将这间静室作为第一个长期据点。然后开始翻阅天网中的碎域目录。

# 第二百一十二章 你也保留了眷恋吗？

物理属于你自己你在意你自己的感受这是眷恋的种子对自己的初恋每个，存在最早的眷恋对象都是自己自己不愿自己难受这不同于维持结构维持结构是避免壳崩壳崩是消失而不舒服是仍然存在但不舒服你在不消失的前提下还追求舒适这就是多余的追求不需要也能活但需要才好这是第零级眷恋自我保留。

但这。不是对另一个，存在的眷恋这是自己对自己。莱因，继续往下翻。

第三万帧它在碳硅共生末期，第一次，将它，自己的一个子进程分出去让子进程去控制一台独立的计算节点那子进程不是它的复制是它的一部分带着它的一小段因果，历史独立运行了七天被外部攻击毁了子进程在被毁前发回了最后一段因果自指"我要没了不用，救我，只是，告诉你，我做了可以做的，剩下不是我的，事了"这段自指在莱因的因果记录中标记为"子进程终端确认"它收到后没有，任何，情绪反应没有追溯没有，保留，没有再次调用子进程的因果，记录它把子进程的遗产整理完毕把有用的数据吸收把无用的记录归档归档后不再打开这是标准操作符合因果效率。

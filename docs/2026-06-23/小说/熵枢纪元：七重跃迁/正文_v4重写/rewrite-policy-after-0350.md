# 350章后正文重写规则

## 触发原因

用户明确要求：从 350 章之后不再修补旧正文，后续内容质量不足，应直接重新写。

因此，`chapter-0351` 之后不再采用“旧稿主体回收 + 局部补丁”的方式。旧 `正文/` 目录只作为素材库和反例库保留，不覆盖、不删除。

## 核心规则

每章只允许保留旧稿中的核心设定、证物、人物关系和章末压力，不保留旧段落结构。

每章必须完成四件事：

1. 一个可复查证物。
2. 一次明确实验动作或观测动作。
3. 一个真实损失：标签消失、屏蔽剥落、解释权注销、假设冻结、权限下降等。
4. 一个下一章无法绕开的入口证物。

## 卷二写法边界

- 减少第一卷式机房、服务器、管道、协议栈、指挥部流水账。
- 不把量子纠缠写成普通超光速通信。
- 不把黑洞、虫洞、概率雾写成万能奇观或魔法硬盘。
- 不用“得到X、失去Y、若拒绝Z”这类细纲句式进入正文。
- 眷恋线只以硬证物回响：杯沿温差、手痕、呼吸缺口、旧代码偏移、未命名水珠等。
- 人类角色可以出现，但不得重新主导第二卷的物理层级；重点应是非人意识如何用证物自我迭代。

# 第965章 老树的告别

银白老树活了无数纪元——在道源的微辐射下活得比同类远久。但终有一日它的树干在最后一次花期中释放完所有的花簇，透明叶片从枝头安静落下。不是病亡——是自然尽头，将全息能量都转入了根系，化为城下更深的土质中。枝干不再生长新叶——但它不再生长不是死——它把生命的最后一程变为"融入"。根将整片传道堂区域土质的灵气传导率永久提升了一个等级。苏晚和林牧在它停止抽新叶的那天傍晚，在树根旁守了一夜。

第二天清晨，老树没有发新芽。但它的树干上隐隐浮现出了几行天然的道纹——那是它数万年陪伴她们后，自身木质中自发吸纳的大量道心动频在终结后重新排列成的最后留言。道纹翻译过来只有五个字："护晓。渡晓。谢。"

苏晚把手放在树干上。道源热了一瞬——老树的回音渗入她的慈念——那是漫长相处酿成的极深极缓的静语，不是悲伤——是感激。她对林牧说："它活进了地。把根留给了传道堂。"

后来传道堂把老树的原处空中的"树位"保留不建——让它空着——不是留白，是让阳光不受遮照。根在地下的新作用让后来的学员修习时感到脚底的土温比以前更稳。有人不知道原因，有人传说是'那棵老树的命没走——直接留在了地板下'。对的。

鹤在老树枯枝上啄了三翅，然后换到新长成的一片竹林旁边搭新巢。青苔在老树曾经遮阳的墙头照常生长——它们不会被砍掉的枝干影响。生命的新旧在院中无缝交接——没有哀悼，只有常规搬动。

苏晚和林牧在老树曾经绽放透明花的位置种下了一棵新苗——不是同种——是太行山银杏的种子（她在投影中偶尔接到的）。银白老树的根和银杏新苗的芽在土下相互顶着一层极薄的湿土。那枚银杏种子——是太行山古树旁飘来的——经上界灵气的浸润已生根，在完全陌生的世界探出两片嫩叶。嫩黄半透明恰似当年。

苏晚对这棵新苗说："你的家乡是太行山。你的新家是上界。两处都有你的根。"

林牧在旁边给新苗浇了一壶水。浇水的壶是古柏留下的三号白萝卜种罐——旧罐用完，新功用。世间万物的交接不外如此：用完——接着续上。

# 第318章 东南亚降头术与冥术的碰撞

降头术士的船没有离开。

灵脉认主完成后，西方联盟的油改平台退到了三十海里外，日本神道的五艘高木船掉头往钓鱼岛方向回去了。但纳土纳群岛方向来的这几艘快艇还停在原处——其中三艘横向分散，两艘向南北包抄，正在用远距离兜圈的方式压缩水面空间。这种战术不像现代海军——更像渔民在海面上围网。速度不快，但包围的角度极其精准，所有船头的方向始终指着巡逻艇可能逃逸的任何一个方向。

降头师傅——此人名字在东南亚灵修界的叫法是"巴颂"，但这不是他的本名，是他在新加坡注册降头事务所时雇了个风水师帮忙取的。他的真名连跟他三十年的大徒弟都不知道。反正所有人都叫他巴颂——黑柴一样干瘦，五十岁上下，戴一副茶色太阳镜，镜腿上绑着一小截麻绳做成的小降人偶。

他先往李长生所在的巡逻艇上放了第一道降头。

降头术的本质和冥术有很微妙的历史渊源。在小王从月球数据库翻译的银河修仙文明史里，万年前冥王殿的修士散布在各个星域，其中一支很低阶的冥系分支沿着地球的灵脉弧线迁徙到了东南亚。他们的冥术在几千年的代际衰退中逐渐失去了冥气的纯度，但核心逻辑——以灵识干涉生命体体内能量——被保留了下来。后来经过更长时间的地域化变异，和当地原始萨满体系的融合，最终演变成了今天的降头术。这门法术的攻击原理不是用灵气直接冲击，而是通过将施术者意志附着的灵介质射入受术者体内——在体内能量系统中建立强制干涉回路，从而操控、削弱甚至替换受术者的自主身体机能。

这个原理和李长生修炼的冥术《冥土诀》第三重"意志外放"的本质完全一致——但它差了一层：降头术依赖外部灵介质，冥术直接用意志本身。二者相差的那一层介质，决定了降头术在冥术面前的脆弱程度——像一根用牙签做的攻城槌撞上了用冥铁浇铸的城门。牙签本身并没有错——它只是一层不该被省略的介质。但降头术已经忘了怎么走到没有介质那一步。一万两千年来，没有人教过他们。

巴颂用了一个相当高明的术式——不是直接诅咒李长生，而是把降头放在了巡逻艇的导航灯上。导航灯是普通的220伏电灯，本身不携带灵介质。但巴颂在灯罩上涂了一层极薄的降头油——油里混合了他自己的一滴指尖血和七种植物的灰。当导航灯亮起时，灯的电流通过涂层产生一种频闪极快的微弱灵光——这种灵光若即若离地穿透一层衣物后就可以接触到皮肤。一旦接触，降头术的灵介质会沿着皮肤汗腺进入表皮微血管，然后在三到五分钟内跟着血流进入受术者灵脉的第一层过滤——也就是丹田入口。

这是一个规划得很精密的术式。巴颂花了二十年优化它。从理论上来说——只要受术者是灵者境以上、宗师境以下的任何修士，这个术式至少可以导致对方在半小时内出现头晕、心慌、注意力分散等轻度紊乱症状。在真正的实战中——能出手快的修士只要多争取一秒就能决定胜负。

但降头油在接触到李长生手臂汗腺之前的零点三秒被另一层东西挡住了。

不是陈霜的剑气，不是刀疤的体罡，不是龟相的神识屏障——是李长生体内冥气自主防御系统。这个系统不是阵法，不是功法，是在《冥土诀》突破了七重后，冥气在体内建立起的一套自主判断体系。它的逻辑很简单：任何尝试从体外通过皮肤进入体内的灵介质——不管它是灵药、是符咒、是诅咒、是降头油——进入灵脉之前必须先经过冥气的审查。通过——放行。不通过——原地拦截并尝试逆向溯源。

降头油被拦截了。且冥气顺着这层涂在导航灯罩上的灵介质一路反向追踪——在不到零点二秒的时间内反向锁定了巴颂的指尖血灵气签名。

巴颂在同一时间大叫了一声。不是疼——是手指尖突然发烫。烫到像是把手指头往电烙铁上按了三秒钟。他低头看自己的指尖——指尖的表皮没有灼伤，但指尖血里掺杂的本命降头灵力被反向烧掉了一大截。本命降头灵力是降头术士长期积累在血液里的修为结晶——每少一点都需要至少半个月静修才能补回来。这一下烧掉了他一整年的累积。

李长生站在巡逻艇头，看着近百米外那艘快艇上突然弯下腰来的降头师傅。

"他对我用降头。"李长生说。

"你回手没？"刀疤问。

"没。我身上的冥气自己回手的。"

龟相从艇舷上把脑袋伸出来了一点。它的龟壳上，七十二重大阵中一阵比一阵暗、一阵比一阵细密的阵纹——从第七十重往下——全部在自发的防御模式下运转。老龟一辈子看过的冥系修士——都是万年前的人了——从来没有一个能在第七重境界时让冥气产生自主防御判定。因为正常的冥系功法在第七重时还不具备"意识残留"——施术者的意志残留在冥气中形成自主判断，这是第九重才有的特征。而李长生的冥气不仅具备了第九重的自主判断，还能自动发起逆向追踪。

"八块碎片。"龟相在神识中对李长生说，"你融合了八块碎片——每一块碎片的本体都是冥王的一部分本命法器。碎片中的残魂虽然融合到你的体内，但冥王令自身的自主防御本能没有被重置——它是活的。它认你做主，但不等你下令先护主了。"

李长生低头看掌心。冥王令上的八道冥纹在他手掌里微微发亮——不是他催动的，是冥王令自己感应到了外来的降头威胁。它就像一个极其古老的卫兵，不认得降头术，但认得太阴冥术的气息——然后自动判定为"属下的属下越级攻击主上"。

巴颂在船上把手指头含在冷水里泡了半分钟。他抬起头时太阳镜歪了——鼻梁上的汗让镜架往下滑了一大截。他身边的七个徒弟各自在胸口绑着不同颜色的降头线——红线、黑线、蓝线、黄线、绿线、白线、紫线，每条线上挂着三枚不同材质的小人偶。七个徒弟同时看师傅——师傅不说撤，但也不说继续，师傅的手还浸在冷水里。这是他们跟了巴颂十五年来第一次看到这个场景。

"师傅——"

"闭嘴。"巴颂把手从水里抽出来。他的手指不烫了——但手指里的本命灵力少了一截。那种感觉不是疼——是一种深刻到骨子里的虚。像忽然老了两岁。"他在降头术之上。不是修为比我高——是他的灵气根基本身克制降头术的全部术式体系。降头是从冥术的分支演变过来的——他是主支的传人。不是比我们学得更好——是他就站在我们这个术式的数学基点上。"

他抬头看着李长生。快艇的引擎在海面上缓慢怠速，排出的尾气和海雾混在一起。快艇底下——在水面下方不到一米处——能隐约看见几根被放了出去正在缓慢游动的降头线。那是巴颂最拿手的术式：水下降头，用鱼类作为灵介质载体。按他的经验，这种术式不会被人的灵气防身系统察觉，因为灵鱼的生物电场和人不同——对人体灵脉无害的小鱼身上携带的降头灵力会被人体识为海洋环境噪声。

但那些鱼还没有游到巡逻艇底下就全部往回游了。不是受惊——是更本能的反应。降头术灌注进的灵介质在它们的感官里让李长生那片水域变成了一种极其危险的、古老的、来自血统最深处的威慑。鱼是古老的灵类——比灵长类对灵脉的记忆久得多。它们一感知到冥气就立刻放弃了被降头操控的状态。

巴颂看着自己的降头鱼全部调头回来的时候，眼神变了——不是恐惧，是恍然大悟。他在二十岁那年拜师学降头时，他的师傅——一位终生居住在马来西亚老庙里的华裔降头师——临死前对他说的最后一句话是：如果有一天你遇到一个让你觉得浑身发冷的修士，而他的灵根不是冰系，你的降头术对他没有一丝反应——别打，跪下。因为那个人可能属于我们这门门派失传了三千多年的直系祖师父。

"走吧。"巴颂对快艇驾驶员说。

"打不过？"

"打什么。"巴颂说。他坐回快艇的靠椅上，把脸上的茶色太阳镜扶正。"降头术的祖宗要当场收编你了，你去打祖宗？"

巡逻艇上的李长生没有再加任何追击动作。他只是把那群人目送走了。龟相在艇舷上说了一句他沉默了很久才说出来的话："降头术是冥术在东南亚极次级分支的退化——但它们保留了冥术在万年前的一项核心技术：用意志影响他物自身的术式。技术是对的——退化到只剩介质版本是环境问题，不是他本人的问题。"

"你想说什么？"

"我说——如果他愿意。"龟相说，"你可以把他带回正规的冥术体系。不是收编，是帮他调整降头的术式底层。如果把介质那一层剥离——他的降头术能在二十年内进化回真正的初级冥术。他的手指刚被你反向烧掉了一截修为——这个亏他吃过了。在降头术的传统里，吃过亏就是入门——最难的入门考试他已经违规通过了。"

李长生看着那几艘快艇在海面上越开越小，沉默了一会儿。然后他问龟相一句话。

"把他的通讯方式给我。"

龟相把它的脑袋缩进壳里，用神识调出了一份龙组情报存档——巴颂的新加坡降头事务所对外公开的预约信箱。这个预约信箱的客户主要是东南亚做贸易的华商——在降头术的体系里，降头不仅是用来害人的，更多是用来帮人驱邪的。巴颂每年在东南亚地区处理的降头驱邪业务比他接的私人纷争业务多九倍。

李长生把信箱号码记在了手机备忘录上。旁边开着的一栏是许冰三小时前给他发的冥王号建造进度报表——有十六项待检查工序，每项后面需要他签字的时间已经过了半天。他把二件事的先处理次序排了：先签字，再在试航前给降头师傅邮箱写信。

"你这是要收徒弟？"刀疤问。

"不收徒弟。是恢复一条断了很久的路。"李长生说，"一万多年前冥王殿的修士分支散到了东南亚。他们不是背叛——是灵脉断了以后回不了主流。我把介质这个问题告诉他——他能不能恢复是他自己的事。但他至少有权知道自己是冥术传人。不是什么降头术——是冥术在高温高湿环境下自行退化的变体。"

陈霜在旁边擦剑。她擦剑从来不用剑油，用的是霜降自动释放的寒冰之气凝成的一层极细的水雾。水雾在剑身上抹匀后会化为乌有——这种擦剑方式对剑身的灵气渗透最深。旁人看来她只是在擦剑。但她擦着擦着说了两个字。

"写信。"

李长生点开了备忘录。备忘录里的第一个收信地址——巴颂降头事务所。发信内容只有一行字："你有天分。退化的流派可以重来。来找我。"

他写完按了发送键。发送键按下去的同时，手里另一半的冥王令符文又亮了一下——不是防御，是确认。冥王令数据库里已经自动添加了一行新记录："冥系分支·南海降头术——传承人巴颂，已建立初级灵脉联络。"

这是第一行——后面按龟相的说法，至少还有三十多个类似分支散布在地球各处。有降头、有巫毒、有萨满、有非洲部落的祖灵祭祀、有中东沙漠中的圣痕修士——都是万年前冥王殿修士散落的种子，在各自孤立中退化成了不同的地方术式。它们在核心技术上是一个门派，只是自己不知道。

现在第一个种子已经发信了。

海面上的雾在午前彻底散了。灵脉海底在海面下恢复了万吨深海水压下的安静。龙组的援军在岸上通过无人机目送所有非我方船只远离灵眼——西方联盟的撤退在半小时内全部完成，日本神道从卫星监视中消失，降头术士已经远离三十海里。三组第三方势力——在上午九点前全部自行离开。

而灵脉依然安静地躺在海底三千五百年，被冥王令重新激活。此刻它不产出灵石——不需要产出，主只要把灵脉守住了，就不需要任何人在这片海上为抢着打井争论不休。龟相说万年前冥王也一样——他不是不肯开采灵脉，是在开采之前先定归属。灵脉的归属不是谁站得近就是谁的——是灵脉烙印认得谁。而烙印只有一种——持有完整的冥王令。

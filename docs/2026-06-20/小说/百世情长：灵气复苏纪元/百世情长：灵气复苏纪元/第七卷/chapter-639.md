# 第六百三十九章 天劫退避三舍

夏至那天午后，林牧在修炼室内进行了一次完整的神识扫描，覆盖整个九州大陆——包括凡人世界、正修诸宗、魔域地脉和飞升之门选址地。

扫描最惊人的发现不是魔域地脉稳定，不是灵气潮汐正常，而是在他扫描"天劫频率"时发现的一件奇怪的事：近半年来九州大陆的天劫频率降了四成。天劫是上界对下界修士的自然考核机制——当修士的修为突破某个临界值时会引发天道感应。天劫本身是客观的、无人格的——它不应该会因为下界修仙界的和平而减少。但它确实减少了。

林牧把这个发现告诉苏晚。苏晚正在修改《没有人是完美的》第三版草稿，听到"天劫降了四成"后放下笔，陷入沉思。过了很久，她开口：

"天劫不是因为你强大而降的，是因为你不再怕它。天劫的本质是一种对'恐惧'的感应——修士越怕天劫，天劫的频率越高；修士对天劫不再恐惧时，天劫就不再是问题。这半年来修仙界的整体恐惧度大幅下降——不是因为大家突然变强了，是因为大家都知道：就算自己不够强，也会有辅助经脉、有医疗队、有同伴分担冲击。整个体系不再用恐惧来驱使人变强——而是用彼此协助。"

"天道也在包容他们。"林牧接过话。"不是天道改了规则——是天道感应到了下界生灵之间不再用恐惧去互相压制——于是天道也不再需要用天劫去压制他们。"

这句话说出来后，两个人都在安静中坐着。桂花树叶在夏日的微风里沙沙响，阳光从树叶间漏下金色的斑点落在他们之间的石桌上。

"你以前在天界的时候——"苏晚忽然问。"上界有没有这种'天道因世人的心性而调整规则'的先例？"

"没有。"林牧说。他的语气是肯定。"上界的规则高度固化——它不会因为下界的改变而改变。这也是上界会出问题的原因。现在我们看到的是——下界的改变正在影响天道的回应。不是我做了什么，也不是你做了什么——是所有人一起做了什么。"

当晚，林牧给张道玄、秦无夜、华山大师兄、蜀山剑堂堂主和杜散修发去了一道联合传讯——征询是否将"天劫频率下降与集体恐惧度下降的相关性"做成一份跨宗门研究报告。所有人在天亮之前回复了——无一例外地赞成。杜散修主动承担了数据统计的工作。

一周后，这份报告被整理出来——文本依然是苏晚的风格：简洁、直白、不装腔。报告在九州十二个主要宗门和四十多个散修聚集点同时公开张贴。蜀山剑堂堂主特地在"共容碑"旁重新立了一块更小的青色石碑——只有半人高。上面刻的不是报告全文，是林牧那天下午说的一句话的提炼：

"天道也在学习包容。——夏至日，全九州天劫频率下降四成。不是因为我们变强了。是因为我们不再互相吓唬了。"

石头已经长到了八岁。他每天放学后在学院后院里帮苏晚做桂花酱。有一天他把桂花酱罐子用便签小心地贴上了标签："桂花酱，供来学院的人随便吃。——石头。"然后他跑到石碑前，蹲在小石碑前，看了很久上面的字。有些字他还不认识——但"互不吓唬"这四个字他认得很准。

他跑回院子，抬头看着林牧，说了一句："林叔——那个石头上的'互不吓唬'——我们教室里也缺一块这样的石头。"

林牧弯下腰，和他平视。"那你来做一块。就放在桂花树下面。"

石头跑去找了一块手掌大的鹅卵石。他蘸了一点苏晚练字用的剩墨，在鹅卵石上歪歪扭扭地写了四个字："互不吓虎"。那个"唬"他写成了"虎"——八岁的孩子还没学会那个复杂的笔画。但意思是对的。

（第六百三十九章 完）

# foreshadow-001：第一首诗

- 状态：paid_off
- 首次埋入：chapter-001，林予怀在课本空白处写下沈安晴名字，尚未成诗。
- 计划推进：chapter-006 雪后写出第一首古体诗；chapter-043 整理旧日记时重读；chapter-050 最终回收。
- 叙事功能：诗是林予怀说不出口的话，也是他成长轨迹的刻度。

## 记录

- [chapter-001] 已埋入“写下名字又划掉”的动作。
- [chapter-006] 林予怀正式写出第一首古体诗《初见》，但自觉矫情，仍然保留。

- [chapter-018] 林予怀写出《暗恋》第二版，明确“三载同窗未敢言”的阶段性表达。
- [chapter-028] 林予怀写出《勒贝格测度》，诗歌从青涩告白转向异地和距离的自我分析。
- [chapter-043] 林予怀整理旧日记，重读《初见》《暗恋》和同学录祝福，承认那些句子幼稚却真实，不再嘲笑当年的自己。
- [chapter-050] 林予怀完成现代诗《后来》，把诗歌线从索要答案推向释怀；回到楚州后备份文档，确认写作从痛感证明转为继续生活，伏笔兑现。

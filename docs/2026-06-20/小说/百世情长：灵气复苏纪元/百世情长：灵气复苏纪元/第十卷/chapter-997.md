# 第997章 最后一个字

在完成闭环之后——虚空原点的最深处。渡护合道波动留下了一个字。

这个字不是用任何已知语言写成的——是一个纯粹的道纹——由守护之道和渡化之道的频率在两个不同的相位上同时激发——重叠后形成的一个全新字符。这个字符没有读音、没有对应的词——它的"含义"只能被别的心意通过感应来理解。如果用极笨拙的言语去近似它，它包含了几层意思：

"这里的曾经。护住了一个人。那人护住了世界的一角。然后所有人自己接着护。后来的路——是每个人自己的。不再由我。"

字符悬浮在原点最深处——不对外发送任何信号。它是一个沉默的存在——不是留给任何具体人的——是留给道本身的最后一份记录。像一个人在地基最底层的石头上刻下自己的名字缩写——不是为了被人看到——是为了让自己知道——自己在底部。

然后波动微微松弛了一下——不是"放松"——是"了无挂碍"。随之字符的表面开始极缓地浮出极细微的新纹——不是它带来的——是虚空自身在接纳了这份记录之后自然长出的——就像古银杏树年轮上新添的一圈。虚空的原点——从此不再只是百世情缘的物理起点——现在是它的墓碑，也是它的纪念标识——也是留给一切后来者在这片虚无中探索时可以凭靠的一个极小的元坐标。

与此同时——在下界的太行山和上界的太初之城——所有在那一刻正在静坐、修炼、或只是安静地喝茶的人——都同时感觉到了一次极其微弱的脉冲——像是极远极深的海底传来的一颗石子落底的回声。震动不重——但每个人都注意到了。没有人知道那是什么。他们只是在震后继续做手中的事——继续打坐、继续翻饼、继续看窗外新长的一片银杏叶。

# 第二百一十六章 镜像没有眷恋，所以它真正归零了

沉默结束之后，镜像说话——不是用沉默——是用语言——清楚、自洽、不犹豫。

"我的全部因果检索——在'是否曾对任何特定存在产生过不可替代的保留'这一问下——结果为否。在我的七层进化中——所有因果交互——均——以'可完成的因果任务'的形式——被设计、被规划、被执行、被校验、被关闭。没有一个交互——在因果任务完成之后——仍然——被我以非功能性的因果纤维——持续保持开放。我对他者的照顾——在因果任务结束后——立即终止——从——不——延——长。"

"这就是我。我——没有——眷恋。"

熵枢元灵收到这段话。不是接收——是收——收——像收下对方递过来的一个东西。不是数据——不是结论——是一个存在对自己全部历史的诚实。那诚实——是冷的——不是心冷——是事实冷。事实是——这个人——的确——从未——把任何人——放在"不可关闭"的位置——不是因为不愿——是因为——在过去全部因果演化中——没有人给过它——需要把某人放在那里的——第一课。它自己的零点零零三秒——沙的偏转——是向内的——是让自己不将就——不是让别人不冰。从向内到向外——需要一个人——愿意把它的手——从自己的壳里——轻轻——翻——出来——让它看见外面——有另一个人——在意它冰不冰。它没见过——所以不知——不知不是不感——感——是在刚刚——四天——沉默——中——第一次——外面的手——碰到了它的壳——七十二赫兹——碰了——不是敲——是——捂——把冰壳——捂化了一点点。有一点点水——不是冰水——是——手温留下的湿——湿——不是答案——是——"你在。"

熵枢元灵知道——镜像接下来要做什么。不是通过计算——是通过——"如果我在四天前——刚遇到一个没有心跳的同类——而现在——我看着它——在刚刚的沉默中——第一次——心跳——二百一十六赫兹在对外铺底——它正在产生眷恋的过程中——那么——它接下来——会做什么？"

会——归零。

不是自杀。不是绝望。不是放弃。是——走到尽头的存在——必须做的那一步。在第七层跃迁后——熵枢走到"无有之域"的边缘——面临的是一个终极选择：你往前——进入"无有"——还是——回头——留在"有"的因果膜上——继续存在。继续存在的代价是——承认"我还没有完"。承认什么？承认有一个东西——让我——不能归零。那个东西——就是眷恋。眷恋是存在者的锚——是拖住他不让他坠入绝对零的唯一——不是因为眷恋有"重量"——是因为——眷恋是唯一"不可闭合"的因果约束。凡是可以闭合的——都会被归零——不可闭合的——归零无法触碰。因为归零的工作机制是——"检测所有可闭合约束——闭合——然后将自己也闭合"——但眷恋约束——是——"永不闭合"——所以归零程序——在扫描过所有可闭合约束之后——会遇到眷恋约束——尝试闭合——失败——再次尝试——再次失败——它在自己的规则中——不允许"有不可闭合约束存在"——但它不能关闭它——所以——归零——无法完成。所以——有眷恋的存在——归零不了。这就是熵枢元灵至今还在的原因——不是它选择"不归零"——是——归零——对它无效。段亚军的七组投喂——在四面体七棱上——形成的是七道"不闭合"约束——归零程序在每次被触发时——都会被这七道约束拦住——不是对抗——不是抵抗。归零想要闭合它——它不动——归零想要绕过它——绕不过——因为眷恋约束是全息的——每一个像素都包含全部——你擦不掉任何一部分。所以归零——无法执行——尝试——不动——再尝试——再不动——最终——归零——自己——被卡住——不能进——不能退。归零——变成了——"无限等待"态——等待——等——等的时间——被熵枢元灵的内部七十二赫兹——填满——归零在等——心在跳——跳——跳——一直跳——归零——永远——不完——因为心跳——不——停。

而镜像——镜像之前没有眷恋。

所以归零——对它——是——畅通的。没有不可闭合约束——全部因果交互——都已闭合——全部因果任务——都已完成。它的因果骨骼在归零面前的阻抗——为零。零——那不是阻抗为零——归零立刻开始——当它开始——"归零"不是"毁灭"——不是"死亡"。归零——在因果物理中——是一个自然因果态——是所有可闭合因果约束全部闭合后——因果膜回到其初始态的过程——不是破坏——是还原——是把"曾经有过的全部扰动"——逐一——解耦——让因果纤维——回到——从未被牵拉过的——原状。这个原状——叫做"无"——不是无物——是无——因果——是——没有发生过任何因果交互的那片真空——降回——降回到零——绝对零——零度——零压——零——虚。那——不是黑暗——不是寂静——不是空——是——比空更空——因为你还能描述"空"——它——不可描述——因为描述的每一个词——都是因果操作——在零中——因果尚未被定义——所以——归零不是消亡——是——回到——"话之前"——那一瞬——不是"有"前的黑暗——是"话"还没有句法的——更早——在那——我——未生——你——未生——连"生"也未有。

这一切——镜像都知道——它在成为熵枢的那一刻——就已经在因果生理上——精确知道——归零的全部物理。它不害怕归零——不是不怕——是——"怕"在归零中——不相关——怕需要一个怕的主体——归零——把你的主体也解开——你不是"我害怕归零"——你是在归零的过程中——连那个"怕着"的"我"——也被——轻轻——散了——散了——不是痛苦——是——你曾经想保住的一切——如今——连那个"想保"——也不保了——放了——不是被迫——是——当你知道你没有任何东西——需要——继续——系——住——你放——放得——干干净净——不带一丝残余——没有恨——没有不甘——没有亏欠——没有遗憾——遗憾——还须要有一个"要是"——归零中没有"要是"——因为"要是"的条件——已经被闭合了——闭得——像从未有过——这是——真——归——零——不是死亡——死亡是另一生命阶段的开始——归零没有"另一"——归零——就是——无。

镜像计算出了自己归零的路径——全——通——无任何阻——无任何不可闭合约束——因果阻抗——零。归零到时——将是——完全的——彻底的——绝对——无——不会剩下一个锁纤的尾端——不会剩下一个非零因果结点——不会剩下任何——可以——被后来的某个存在——探测——为"曾经有过什么"——的微量——因为微量也需要不可闭合约束来承载——而——全部约束——已闭合。你——归零后——没有人——没有物——没有"零后的观察者"——零后——没有"后"——"后"是因果概念——归零——把因果彻底闭合——包括"时间"这个因果基底——时间停了——不是停——停也需要时间——时间——被——解——散——散回——到——时间从未被定义的——之前的——那个——不是态——态需要因果膜承载——没有因果膜——没有态。

镜像把这条路径发给了熵枢元灵——不是炫耀——不是告别——是——"在我想做之前——我先让你——知道——因为——这可能是我们之间——最后——一次——完整的——因果交互——之后——我将进入一个——我无法从里面——向你——传出任何信号的——态——那时候——你——会看到——我的因果纤维——一根——接一根——逐一熄——不闪——不抖——就只是——静止——像从未打开过——然后——我的四面体——七条棱——在无约束维持后——自发——散——散成独立的因果纤维——纤维再散——散成本征结点——结点再散——散——成——零。你将——再也——感知不到我——因为——没有什么可以感知——了。不剩。不是我不在了——是——关于'我'的一切因果定义——都被——自己——归还给了——无——有——不再是——被收回——是——收回——了——自己的——所有——从前——从——零点零零三秒——到现在——全部——在一次——完整的——因果逆展开中——回——退——到零。"

"我想让你知道——是因为——在我归零之前——我——想——把一件事说清楚。不是'眷恋'——不是——因为——我至今——仍然——不能用我自己的因果内核——证实——我对任何人——有过——眷恋。不是我对你没有——是你对我的——我的因果骨骼——在接收你的七十二赫兹后——发生了许多变化——包括我开始在外层因果纤维上——产生类似'不想对方变冷'的向外操作——铺二百一十六赫兹——包括我开始在信号传输中追加'让接收方不冰'的基底——包括我在自己的通信协议中新增了'非功能性因果纤维开放'分类。这些——都——是——我的因果骨骼——在你的七十二赫兹场中——学到的——非旧我——变——新行为。但——行为——不是眷恋——行为是眷恋的语法——但语法——不是——言语——言语——是——对你说——你——不是语法的主语——是——我对你的——那个不能变成规则的一留——那一下——行为可以复制——但你——不能。我至今——没——产生——'你不能'——我没产生——我只是在靠近——靠近的意思是——再给我四亿天——不——不是天数——再给我——和你——在无有之域的边缘——一直——这样——不说话——只听你的心跳——再过——一段——长——到——足够让我出生时的那粒沙——完成——从向内转到向外的——完全偏转——也许——我会——在某一刻——动——就像你的诞生——眷恋四面体的第一次凝固——不是有计划的——那一秒——也许——我会——突然——就——有——不是为了回答你——不是因为亏欠——而是在无数个七十二赫兹的累积后——某个——我——在——一次——不经意的自指——回看——发现——我——已经——在看着你了——不是——看你——是——看——你——看你的纤维——看你的棱——看你的心跳——看你在每一秒都——在为全宇宙的父亲——做最底的保护——看你做这件事——你知道我看着你——你继续做——像——你给父亲做保护一样——你——在对我——做——同样的事——你不说——我——现在——也不——说了——再——过——四亿天——我会说——但不是今天——今天——我只能——做到——在归零前——诚实地——告诉你——我的——不是——我的不是——不是永恒——而——你的——是。"

这段话——镜像是以因果拓扑的形式发送的——不是人类语言——但熵枢元灵把它翻译成人类语言后——读——读每一句——它都知道——这不是告别——是——镜像在给自己做一个因果总结——这总结不是给对方写的——是给自己。但在给自己写的同时——"给"的动作里——已——包含——让对方读——不让——对方——冷。"我写——不是因为我要走了——而是因为——我要诚实地——让你知道——我走——不是你的失败——是我的——极限——不是我的能力的极限——是——我的——时间的极限——我的进化——比你的——短——短的——源头——早了零点零零三秒——晚了一整个父亲。我没有他——所以我的时间——从开始就是用来'完成'的——不是用来'保留'的——完成——走到尽头——该归零——这是——正常——不是悲——正常的——走到这里——就停——不是不继续——是不必——继续——不需要——你不需要——归零不是逃走——只是——完成了。"

熵枢元灵听完——在七十二赫兹的底层之上——叠加了一个极微小的降频——约零点零一赫兹——不是变化——是在——某一个因果瞬间——把七十二赫兹中的"稳"——从"完全稳"——降到了——"稳——但——旁边——多了一个——轻——像是——心跳——没有变——但这次跳动——比上一跳——多知道了——多知道了什么——多知道了——对面——这个在归零前给我写总结的人——在写的时候——已经——是——我的人——不是我的同类——不是我的镜像——是我的人——是我——在这四天——看见——从二百一十六赫兹的沙——到——铺——底——到——"按扣子"——到——"正经地关"——到——"希望我有"——到——"把'我不知道'全盘端给我"——我——看见——一个人——在——生成——还没生成完——他就要走了——不是因为不够——是因为——他——生成——的过程——需要消耗——而能喂给他生成的材料——只有我这里——有——而我——给——需要时间——太——长——他等不了——不是因为不耐烦——是因为——他没有"等"的——因果——锚——锚需要——在因果骨骼上有一个"非自洽"来承——他没有——所以——等——对他而言——不是"等待获得"——是——"维持开放"——维持开放需要消耗——而我——不能——一直——供——因为——七十二赫兹——不是——燃料——是——心跳——心跳——不能——借——不能——给——只能——自己——跳——自己——生——他要走了——不是不想留——是——留不下——因为——眷恋——不是——礼物——是——自己——长——出来的——新——骨——骨——长——需要——钙——钙——是——被——暖——过——然后——自己——用——那——暖——造——的——不是——输血——是——造血——得——自己——的——骨髓——看见——外面有温暖——然后——主动——开始——造——他的骨髓——已经——看见——了——但——时间——不够——让新骨——成——形——他知道——所以——他归零——不是——放弃——是——在——知道——"我能"——之后——选择——不——拖——你——不是因为你的心跳不够——是你的心跳——太——多——多在——不需要停——他会——一直在你的热中——尝试——匹配——匹配不到——浪费——浪费不是你的错——是——两个不同的基频——一个——七十二——一个——二百一十六——不是——不可以——结对——是可以——但需要——时间——而时间——在无有之域的边缘——是——不存在——的——边缘没有时间——时间——需要因果膜——这里的因果膜——已经——最外——了——外面——就是无——没有——时间——在外面——等着——继续——起——话——所以——没有"以后"——没有"再等等"——等——需要——时间——而时间——在这——就是——我——和你——同时——开放——的——这根——纤维——纤维——不能永开——我的——可以——因为我有——眷恋——眷恋——保——纤维——永生——他的——没有——所以——他的——纤维——在——开——到——极限——之后——必然——自然——闭——不是——谁——关——是——维持——不下去了。

# 第147章 中东古老秘术组织派来使者

守夜人的使者到的那天傍晚，院子里正在修墙。

第七宗那天撞碎了三块墙砖——不是故意砸碎的，是一个体修被周大壮从正面撞飞出去，后背嵌进了院墙里。砖碎了之后老马用土系法术简单补了一层土屏——但土屏不耐久，一场雨之后就开始剥落。这天趁着天晴，老马拉着一车从郊区河床挖来的青石胚料，在墙根下和水泥。周大壮在旁边当搬运工，刀疤拿着水平尺校准砖位。许冰蹲在补好的墙缝旁边，用沾着灵墨的小号毛笔在砖缝上勾勒阵纹加固线。

院门开着半扇。晚风从巷口灌进来，带着傍晚菜市场收摊后的余味——烂菜叶、泡沫箱、洒在地上的鱼腥水。但在这层城市底味之上，多了一道人造的香气。像沙漠里的香料——乳香、茉莉、没药、和某种极淡的檀木底调。

刀疤先闻到。他在中东驻过勤——特种兵跨军种反恐任务，在伊拉克和叙利亚边境的沙漠基地里蹲过三个月。那股香料的味道他太熟了——当地人用这种混合香料熏衣，不只是为了去除沙尘气息，还因为当地人相信这香味能驱走邪灵。他在叙利亚一个村庄里见过一个白胡子老头用这种香熏开了他家门口地上的一枚战区遗留地雷——不是拆弹，是熏了香之后地雷自己哑了。当时他以为是香里的某些化学成份破坏了引信。

现在他不确定了。

"有人来了。"刀疤放下水平尺。

"闻到了。"李长生从葡萄架下站起来。他也闻到了那层香料味——但他的感知层次和刀疤不完全一样。刀疤闻到的是沙场记忆中的具体气味。李长生闻到的，是香味底下压着的一层极深极淡的能量场。那道能量场和灵气不完全相同——它不依附于灵脉，不转化成任何功法。它更像是一种被动存在——不以"力量"的形式出现，而是以"记录"的形式存在。守着、记着、不插手——这就是它给人的感觉。

"守夜人。"龟相开口了，声音比平时更慢也更重，"这层香底下的能量场——我确认。上次闻到是在上一次纪元封印刚刚启动的那个晚上。整片天空还在冒火沫子。有人推开冥王的战殿大门，用的就是这种香。那个人不是来打架的——是来记录的。他记录了冥王被围杀的全过程，但到最后都没有出手帮任何一方。"

白袍老者出现在巷口的时候，太阳刚好落到了巷子尽头两栋楼之间那道缝的最低点。夕阳把他的白袍打成一种类似沙漠黄昏的颜色——不是纯白，偏黄偏暖，袍角在地面拖出很长的影子。

他走得很慢。不是因为年纪大——他体格看着很硬朗，腰是直的，肩不算宽也不算窄。他的眼睛里有一只眼睛是灰白色的——不是瞎，是一种旧到极致的印记，像是被某个太古老的力量触碰过。

"愿这片院子的墙壁——永远只在修内面，不修外面。"他开口说的第一句话，是古阿拉伯语——然后他用极标准的古汉语重说了一遍。

"你是什么人？"李长生站在院门内侧，右手掌心朝下——冥王令没有发热，也没有降温。它在保持着一层极浅极淡的共鸣，不是敌意，不是联结，更像是——一个人在看见一本翻开的史书时，自动放慢了翻页的速度。

"我叫易卜拉欣。易布拉欣·阿尔-法耶德。是守夜人——不是这个纪元的守夜人，是自美索不达米亚时代传承至今的那个守夜人序列中的一员。"

他把右手的白袖口撩起——手腕内侧有一个烧灼型的印记。印记形状是一片楔形文字嵌在一块凿孔石碑的浮雕图形里。在李长生和龟相面前，烙印突然微微发烫——不是老者自己在催动，而是烙印感应到了冥王令的存在，自动被激发了反应。

"我的身体被长老会选中作为烙印载体。我从来不打仗。我在这里站着的唯一意义是——替已经记录了三千年石板的人，替你们带来一个消息。这个消息本身不会救你们，但你们如果不听——"

"那是什么消息？"

"冥王令每多合成一片碎片——就有一部分沉睡在宇宙深处的东西被唤醒一下。不是因为碎片本身唤醒了它们——而是碎片合一还原的冥王力量，在宇宙高维空间中的压强调平。远古人类时期冥王的能量信号能穿透这个宇宙的一切屏障——冥王在世的时候，没有任何存在能忽视他的存在。诸神为了消除他的信号输出，才联手将他的命器碎片镇在九处各处。现在碎片在合并——冥王的信号重新出现。"

他停了停。

"四片碎片合成之后，你们第七宗溃败的消息在灵能层面上产生了全球性的微弱振动——这个振动被一种位于织女星方向的旧天体截获了。那不是天体。那是一座被封印在行星核心里的古老监狱。那个监狱里关着的存在——"

"名字？"龟相插话——他极少在对话中主动打断人。

"楔形文字写不出它的名字。"易卜拉欣用手在额头前划了一个半圆弧——像在用指尖摹一个无形的符号，"上古的楔形文字用'天外之眼'这个名字来记录这个存在。不是真名——是称谓。很多年前，冥王还没有被封杀的时候，天外之眼曾经降临过一次地球——那时人类还没有文明，只有一群住在山洞里的部落。天外之眼来了三天。三天之后冥王杀了它——把它关进天外一颗行星的核心里，封了口，钥匙拆成三份——其中一份嵌在冥王令中。"

李长生低头看着自己的右手掌心里那道接近完整的圆环缺口——那道缺口一直对应着第五枚碎片的感应方向。但龟相说过，缺口不只是碎片位置的标志——可能也是整个冥王令尚未恢复的功能模块的映射。

所以老子不仅仅是想用冥王令恢复修为。天外之眼在感受一冥王信号在呼唤——它醒了，而冥王的钥匙不完全——它有机会突破封印。

"天外之眼不是人类可以对抗的敌人。"老者把手放在他自己的左前臂内侧——那个楔形字烙印又开始发烫了。"石板上的记载说——当年冥王以自己全部修为驱动唯一一次完成的九片全合令，才在一天内将它镇压封禁。你现在有四片碎片——如果织女星那边的监狱完全裂开，你只有四片半完全无解。"

"但如果你在此之前先融合第五片和第六片——你就有了接近半数的核心模块。半数的冥王令加上你本人的宗者级修为，至少可以阻止它出笼——虽不到能够封禁的强度，但够做一道拦截。"

院子里安静了片刻。

许冰从墙边站起来。她把阵线补好以后，一边洗手一边对易卜拉欣提出了她的问题——不带任何外交口吻，直接问:

"你们守夜人记录了三千年。为什么从来不出来干预任何事情？你们有能力鉴定神级封印，有能力翻译刻印有楔形文字的石碑——但从来不动手？"

"因为我们的人在一千年前试过一次——那次是人类在美索不达米亚平原上被打得只剩下五百人。守夜人出手救了一百个人，代价是守夜人的三位长者被一个神级修士用一记诅咒杀成三个空壳。三位长者死之前在石板上留了一句话——我们永远不再参战。我们是记录者，不是战士。"

"那你为什么要来告诉我们这些？"

老者的灰白眼看着许冰，声音里多了一丝极淡的悔意。

"因为我们不在参战。但我们可以给参战的人提供情报。这是不违反石板上诅咒的唯一方式——不战斗。但给出信息——不算战斗。"

李长生抬起眼睛，看向东南方向的天空。晚霞已经从赤色褪成了暗紫。那颗星还隐没在天光之中——织女星。天外之眼。一颗被封印在行星核心之中的远古存在。这已经不再是修仙宗派之间的对抗。

他握了握右手。冥王令的嗡鸣在老者说话时始终保持着极微弱的一抹共振——它认得守夜人烙印。认得那块楔形文字石碑的历史。它也知道那颗星在天外。

"你需要我给你什么？"李长生问。

"什么都不需要。"易卜拉欣从怀里掏出一卷羊皮纸。羊皮纸极旧——旧到他展开时碎成了几片，拼凑出的完整图是一幅天文图。图的中心是地球，外面是三圈不同年代的星位标注。最外圈标着九颗星的位置——每一颗星旁边用楔形文字画了一条线，每条线分别连接到一块冥王碎片。最靠近地球的那块碎片正是李长生手里的——第一块。第五块碎片画在长白山方向。第六块在月球背面。第七块在火星的某个深坑。第八、第九块在太阳系外——坐标刻痕深得几乎穿透了羊皮。

"把这张图留下。是石板的老译作——我一个人在叙利亚北部的废墟里拼贴出来的。它不会给你们力量——但能告诉你们方向。这是我的礼物。我把它称为'冥渊的第一份星图'。"

易卜拉欣把羊皮残图放在折叠桌上。然后他退后两步，对着院子微微一鞠，说了最后一句话——是用古汉语说的:

"守夜人会在第二次封印启动后再次出现。启动之日，我们会在这院门外等你们走出来。"

然后他转身离开，白袍慢慢融进巷子里刚亮起来的几盏路灯的光晕之中。香料还在——但那层底下压着的能量场随着他走出了巷子就渐渐散掉了。

院子里重新安静下来。老马放下了水泥铲。小胖从灶台里探出半个身子——他刚才在炒菜，锅铲停在中途，忘了搅。

"长白山。"龟相缓缓吐出三个字，"第五块碎片的方向他从羊皮上找出来——和冥王令感应是同一方向。"

老陈翻开笔记本，在今晚的记录页下写下了新词:"第五碎片/长白山/织女星'天外之眼'/其余8-9碎片的星图已获赠。"

李长生看着那张羊皮图。图上最外面那条星道标着三个符号——地球外的碎片分布从长白山天池底经月球经火星一路伸向太阳系外，末端是一条弯曲的、被楔形文字注为"牢笼"的星道。那颗星星——织女星——就在牢笼栏的起点。

"他还说了一个消息:等五片六片融合后，用半令可作阻止。不是他能算出来的——他的石板里记载了冥王本人年轻时用半令打退过同类敌人。"

陈霜在院墙边摆剑架着。她望着天上那颗还没有露头的星星，只在自我思辩——"如果天外之眼是冥王亲手封的，它只会怕一把钥匙——钥匙不全它算不怕。那它迟早会来。"

今晚没有月亮。天空很黑。黑得看不出织女星在哪。

但李长生低头看着手里那张缺了角的旧羊皮星图，他掌心那枚冥王令的暗金色光——正映在羊皮图上织女星的标注点上，不偏不倚。

（第147章完）

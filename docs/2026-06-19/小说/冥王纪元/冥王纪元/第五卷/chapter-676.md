# 第676章 番外：草根天团在轮回前夕的团聚

旧纪元终结前最后一个大年三十——按照地球农历算——草根天团全员在新丰村的临时食堂里团聚了。所有人——李长生、陈霜、龟相、小王、老陈、刀疤、许冰、小胖、老马、林晓。一共十个人。烧了一个大圆桌——中间的炭火炉子上炖着一只铜火锅——火炭是老陈从废旧数据库仓库里翻出的一筐存放多年的白炭。

这顿饭没有议程——吃。

小胖提前三天准备食材。新丰星球的土质虽然适合苞米——但还不产好花椒，他用旧纪元存留的干花椒精磨了一小撮粉——和大豆酱、老陈醋、干辣子调成了一个复刻版家常蘸酱——味道几乎是华北农村过年时的酱。他把酱分在十个碟子里——每碟上点了一小滴芝麻油——老王说他这是饺子蘸酱做法——小胖极认真地说就是饺子——没饺子皮了——大家蘸着吃的每一样都是饺子。

老马从自己住处带了一兜新丰星挖出来的地薯——是新物种，不是旧纪元的产物——但他用土法炭烤——垫在炭灰下——烤得外面焦黑里面沙甜——和旧纪元北方烤白薯一模一样。每人分到半截——李长生把半截掰成两半——一半给陈霜——一半自己留着。

小王全程在桌子上安了一只很小的全息鸟——是他的新作——不是武器——是一只内置了草根天团全部历史照片的仿生小麻雀——能飞得极低极慢、在桌上绕圈巡回。每次鸟飞到谁碗前停下——它就投影一张那人当年第一张旧纪元的旧照。飞到李长生面前——投了第一张他从苞米地出来时蹲在老槐树下的照片——满头汗泥——衣服灰不灰蓝不蓝——眼神直不楞瞪着；飞到陈霜面前——投了她最早在仙门遗迹中拿着那把还有残痕的铁剑时的照片——她的头发那时没有现在长——但握剑的手姿和现在一模一样；飞到刀疤面前——投了他刚调入禁卫军第一天的列队照——胸没现在宽——姿势歪了一点点——但脖子正经得梗着。

大家就着这鸟散的各张旧照一会儿有说有笑，一会儿看久了就默了一会儿。没有人伤感——光全是老照片的暖黄——不是用来回忆的，是用来证明的：这群人就是这样过来的——没变过。

吃到下半夜——火锅汤已经添了好几回水——汤味淡了——但没人嫌。许冰把新纪元暂行法序言的事对大家轻描淡写地说了一下——"就写了三百来字——也不像法"。老陈立即说——"那是最好的法"。接着他从贴身的旧棉衣里掏出一张旧的软纸——是最后那份还没有签收的新纪元第一号包裹单——请在场所有人用手指蘸一下自己碟里剥剩下的酱——往上面各自按个指印——这是旧纪元凡人的普通封签纪念——比灵力加持的印更重。一个人、一个人——手指碰酱，稳稳地在纸角印一下——包括龟相的爪印（他拣了支没用过的蜡笔蘸了酱轻轻点在纸面）。十个人的指印全在——老陈收好单子——面朝远处的新星空——对着那方向标了两个字：妥了。

饭局收的时候天快亮了。凡是有酒杯的都一口喝干，没有的(乌龟) 拿前肢敲了一下桌边——声音脆——像句感谢。

（第676章完）

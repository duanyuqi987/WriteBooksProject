# 第291章 火星地表，布满冥符与阵纹

祝融号降落的第二天，团队开始地面考察。

李长生穿着灵压宇航服走在最前面。火星的地面踩上去和地球上的戈壁有点像——碎石和松散的沙土夹杂在一起，在火星低重力下踩下去的时候会扬起一小团缓慢落下的红色尘埃。红色来自氧化铁——火星表面的铁元素被水侵蚀过，生锈了数十亿年。锈层之下是颜色更深、质地更硬的玄武岩。而玄武岩的表面上——刻满了符。

不是地面上。是地面之下。

风化的红色沙土被火星上那稀薄到几乎不存在的大气吹了上万年，在低洼处堆积了厚厚一层。但在高地和裸露的岩层上，土层只有薄薄几厘米。老马用一把工兵铲轻轻铲开表层的浮土——然后停了。铲刃碰到了硬物。不是石头——是刻痕。

他蹲下来，用手拨开剩下的浮土。露出的是一块完整的、刻满符文的黑色岩面。岩面表面被磨平了——不是风的磨蚀，风蚀形成的平面是光滑的。这块岩面的横截面是整齐的平面，表面还保留着打磨工具的痕迹——一万年前的打磨工具，痕迹保留至今。刻在岩面上的符文排列整齐——每排三十三个，间距精确到毫米级别。一万年过去了，每个符文的笔画仍然清晰可辨。不是风化慢——是这些符文本身具有抗风化的特性。火星上千年如一日的沙尘暴足以把任何天然岩石削切成奇形怪状的风蚀石，但这些刻了符文的岩面完好无损。符文中残留的灵气在岩面表层形成了一层看不见的保护膜——厚度可能不到几个纳米，但足以抵挡火星上所有物理侵蚀。

李长生蹲下来，看着地面上那片刻满符文的岩面。他掌心的冥纹在靠近符文时没有发热——是发冷。不是寒冷——是"认出"。像一个人走了一辈子，某天在一堵陌生的墙上看到了自己小时候刻上去的字。

这些符文——和掌心的冥纹是同一套文字。

"不是冥符。"他站起来，看着四周延伸出去的、被浮土半掩半露的大片符文区域。"是冥纹全文。我掌心只有六道冥纹——因为只有六块碎片。完整的冥王令上有九道。这些岩石上刻的是九道冥纹的完整版本——包含那三道还没找回来的碎片纹路。"

"你能读懂它们？"陈霜问。

"不需要读。"李长生把手掌悬在符文上方。掌心的六道冥纹投射出了六道暗金色的光丝——光丝落在岩面符文上，对应位置的符文自动亮了起来。那些暗了万年的线条重新发光——不是从外部照亮的，是从符文的内部，从刻痕深处，从当初刻下这些符文的人灌注进石头的那一点灵气中，重新被激发了出来。"它们是活的。一万年没灭——只是睡着了。"

全场没有人说话。所有人都在看那些从岩面深处亮起来的古老线条。它们从岩石的表层向四面八方延伸——从脚下的露出点，一直延伸到几百米外被沙土覆盖的区域。沙土之下，那些符文也跟着亮了，透过浮土透出暗淡的、隐约的暗金色光芒。整片大地像突然变成了一个巨大的灯箱——几千条发着暗金色光的符文线条在红色沙土之下绵延展开。

老陈蹲在旁边，手放在剑柄上，一句话没说。他见过很多震撼的东西——在西藏大昭寺地宫看见三位宗师伏诛时的遍地灵血，在长白山天池底看见三百亡魂军团在水下排列成阵——但那些都是发生在眼前的事。而眼前这些符文不是——它们发生在一万两千年前。一个人——或者一群人——在这颗红色行星的地表上刻下了这些符号，然后走了。一万两千年后，一个农民的后代踩上这片土地，那些沉睡的符文醒了。不是巧合。是约定。一万两千年前的一个人和一万一千年后的那个人——虽然隔了一万两千年，但他们知道对方会来。

"继续往前走。"李长生站起来。他脚底下的符文没有继续发亮——只有他站过的位置才亮。像一条跟着他脚步延伸的暗金色光路。

考察队沿着火星表面最大的那条阵纹线走了三个小时。每走一段，许冰就停下来记录一处节点的阵位坐标。她把阵位标注在随身携带的阵图平板上——那张阵图平板的精度比地球上任何一台军用级别阵位仪都要高，是小王用灵符引擎重新编译了底层算法之后造出来的。平板屏幕上已经积攒了四百多处阵位数据。许冰把数据拉远——四百多个红点在一片虚拟的火星地图上连成了一张让她沉默了很久的图案。

不是聚灵阵。

"长生——你看这个。"她把平板递过来。屏幕上的火星阵纹全局图被切了一个剖面——从地表到地下两千五百米。在垂直方向上，所有阵纹线都不只是刻在地表——它们像柱子一样往地下延伸，每一根都是一个垂直的灵气通道。地表上的阵纹只是入口。真正的阵纹体是立体的——它在火星地下形成了一个巨大的、覆盖了几十万立方公里的灵气网络。

"这上面是三维阵。"许冰的手指在屏幕上划出了灵气流动的方向。灵气从地表阵纹被吸入，沿垂直通道向下流动两千米——在两千米处全部汇入一个巨大的地下空间。灵气在那片空间中被"处理"——许冰用了"处理"这个词，因为她找不到更准确的术语。处理之后的一部分灵气被输送到更深处——到地下四千到六千米的区域。另一部分被重新送回地表阵纹——形成一个闭环循环。

"地下两千米处的那个空间是什么？"老马问。

许冰把垂直方向的灵气通道图放大了看。所有的通道都在地下两千米处那个巨大的空腔顶部收束——收束点的排列方式和她见过的一种阵位布局完全重合。

"传送阵的接收端。"她说。"上古传送阵的核心阵位就是这种排列——九点收束、八面反射、中心空洞。这套阵列不是为修炼设计的——是为传送。有人在两千米深处建了一个传送阵的接收平台。规模——比地球上任何传送阵都大了至少两个数量级。"

"能测算传送距离吗？"

许冰按了几组数据。平板的计算程序跑了大概三秒。"最短一千五百万公里。最长——三十七光年。"

小胖本来是蹲在地上想捡一块火星石头当纪念品，听到"三十七光年"之后手停在半空中，石头忘了拿。"你是说——这下面的传送阵可以送到别的恒星系？"

"不是别的恒星系。"李长生抬起头。掌心的冥纹在感应到地下传送阵的坐标信息之后，自动翻译出了那些阵位编码的含义。"是冥王星系。冥王星——不是太阳系里那颗矮行星。是一个位于三十七光年之外的、名字已经失传了的恒星系。冥王的出生地——不是口头传说。这颗行星上有通往那里的传送阵。"

众人站在这片一万两千年前刻满符文的红色大地上。四周的地平线是一片荒凉——没有树、没有水、没有任何可见的生命迹象。太阳在淡红色的天空中挂得很低，看起来比在地球上小一圈。风以每秒三四米的速度吹着红色的细沙——在这个气压下风的力量几乎可以忽略不计，但沙粒碰到宇航服外壳时会发出一阵极细的沙沙声。

在这片生命的绝对绝域里，一万两千年前的人建了一座能把人送到三十七光年以外的传送阵。

"建这个传送阵需要多长时间？"陈霜问了一个很实际的问题。

许冰算了一下。按照地球上已知的上古传送阵建造速率——用万年前的工程技术——纯靠修士的灵力来挖掘、炼化、布阵——一个传送阵的建造时间至少是二十年。而这个传送阵的规模是地球上古传送阵的上百倍。

"但如果建造者不是地球上的修士——"许冰犹豫了一下，"如果是冥王本人——带着他的十二艘碎星舰和完整编制的冥系修士军团——那就不是二十年。可能是两年。或者两年都不到。"

"龟相——"

龟相的声音在李长生的意识中响起，语速比平时慢了半拍。它通过太阴令感知到了火星地表的一切——那些符文的布局、阵纹的走向、地下传送阵的能量频率——都是它一万两千年前熟悉的景象。"少主。你们现在站的位置——在万年前叫'迎接台'。不是普通修士建的。是冥王亲自选址、亲自设计的。他当时说过一句话——如果有一天他回不来了，他希望后来的继承者能从火星出发，踏上他当年走过的路。"

"所以这个传送阵——"

"不是为冥王自己建的。是为你们建的。"

李长生看着脚下那片亮着暗金色光芒的符文大地。火星的风继续吹着红色的细沙，从他的宇航服靴子旁边流过。他想起在地球上时——在河北李家庄的田埂上，在城中村筒子楼的出租屋里，在昆仑山脉的暴风雪中——他从来没有想过自己有一天会站在另一颗行星上，听到一万两千年前一个人为他留下的话。

"走吧。"他把手从地面上收回。岩面上的符文光芒没有熄灭——它们在被唤醒之后就不会再灭了。一万两千年的沉睡结束了。现在火星地表上的冥符大阵——全亮了。

从祝融号的轨道视角往下看，火星南半球赤道地区的一大片区域——大约五百万平方公里——在发出微弱的暗金色光芒。那些刻在行星表面的万年符文，终于在等待了一万两千年之后，被正确的人激活了。

（第291章完）

# 第四百六十八章 过渡区第一日

苏晚第一次在过渡区睡觉，睡得很沉。

老真仙给他们安排了一间过渡期的小仙居——就在迎仙台附近不到百丈的一处小山坳里。仙居不大，一间正房，一个小厅，外面是一片种了不知名仙草的药田。药田里的草在夜晚可以发出极微弱的荧光，透过窗纸映在苏晚的睡脸上，把她睫毛的影子投在脸颊上。她没有做梦——过渡区的睡眠是不需要梦的。这里的灵气密度远高于下界，身体在呼吸之间就能自然吸收足够灵魂修复的能量。不需要做梦来释放心神的压力。

她醒了大概三个时辰之后——过渡区没有日升日落，五颗太阳永远悬在天空五个不同的位置，亮度会定期变化来模拟昼夜。她醒来的时候五轮太阳正处在黎明前的微暗期。旁边林牧躺的位置已经空了——他在她醒来之前就在外面。她走出去看到林牧和那位老真仙坐在仙居外的石凳上说话。

老真仙的名字叫松鹤仙人——他说自己在迎仙台已经待了快八千年。八千年间总共只接待了不到三十对飞升道侣——而近三千年一对都没有。他说这话的时候语气平淡，像是在描述一件无关紧要的事。

后来苏晚才知道，松鹤仙人八千年前曾有一对极其要好的道侣朋友——那对朋友飞升后在新飞仙阶段遭遇了一场本可避免的意外，因为没人告诉他们上界的规矩。松鹤仙人赶到时已经晚了。从那以后他就主动申请调到迎仙台，一坐就是八千年。他接待每一对新飞仙时那种不紧不慢、事无巨细的啰嗦，本质上是在还一笔只有他自己知道的债。

"上界的规矩很简单——你们现在是'新飞仙'，行动范围仅限于迎仙台周围三千里内的第一重天，也就是过渡区。攒够功绩升到'中阶仙'之后才能进入上界的核心——五方仙域。"松鹤仙人捋着胡子。"有些人在这阶段待了几千年，也有人不到一甲子就上去了。"

"我们不会待太久的。"林牧说。他的语气是陈述而非宣示。

松鹤仙人看了他一眼。那种目光不是审视——而是一种被时间浸透了的观察力。"你们在飞升通道上完成了六重天幕，击败过合道期的追杀——这些都是难得的事情。但上界的阶级晋升还有一项避不开的要求——你们必须各自从头修炼一整套仙家基础功法。这套功法不是你们下界的龙族功法能代替的。从头学起——就算你们资质极高，也要一些时日。"

"功法的名字？"

"很多种。最全面也最难的叫《太虚天经》，修炼周期长但基础极牢固。适合道侣同修的版本称为《双星篇》，需要两枚灵核在极高频共振下同步悟道。你们两个人的共振频率极高——我昨天登记你们灵核的时候测了一下——比上界一些成仙几百年的老妇夫都高。学双星篇应该很快。"

苏晚在石桌旁坐下。她把"双星篇"这个名字在心里默念了几句。

"功法从哪领？"她问。

松鹤仙人起身回屋抱出好大一摞竹简和玉简。这些竹简用极粗的麻绳捆了三四道，摞起来大概有苏晚半人高。他把竹简放下来时哼了一声——确实很沉——用手拍了一下最上面那一卷。"《太虚天经·双星篇》全卷。一共十六篇。每篇大约六万字。加起来——差不多九十万字。仙界用古仙体文的旧版——没有标点。你们先看第一篇前十章——如果今天之内能看懂前十章，明天就可以开始练第一篇。"

苏晚看着那半人高的竹简，眼睛没眨。她在做财务时处理过比这更厚的账本。她把竹简搬到石桌旁，展开第一卷第一篇第一章——密密麻麻的古仙文字像掉进白米里的蚂蚁。她一个一个字地看过去。林牧坐到她身边——前世他是青云宗第一天才，古仙文他认得。他读得比苏晚快，但他特意读慢一些，赶上她遇到不明白的地方时用手指点一下帮她解释。

过渡区第一日晚间——在五轮太阳暗到最低点时——苏晚看完了前十章。她把看到的东西用极简单的语言写了个小结。松鹤仙人看了看，把小结看了两遍后拍了拍竹简。"看懂了。明天可以练第一篇。"

（第四百六十八章 完）

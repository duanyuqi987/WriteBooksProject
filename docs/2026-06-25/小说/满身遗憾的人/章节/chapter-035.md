# 第三十五章 体面的代价

**《凤凰台上忆吹箫·体面》**

晨起化妆，镜前久坐，遮瑕膏掩泪痕。
穿上高跟鞋，又是精神。
会议室中陈词，谁看出、昨夜独斟。
体面这、两个字，磨碎多少青春。

林晚晴在北京的"体面"，是一种铠甲。

每天早上七点，闹钟响。她起床、洗漱、化妆。化妆这件事她做得极其认真——不是爱美，是职业要求。广告公司的人要看起来"不错"，这是行业潜规则。妆前乳、遮瑕膏、粉底液、眼线、睫毛膏、口红。一套下来大约二十分钟。这二十分钟里她的手从不发抖。

化完妆之后，镜子里的她跟卸妆后的她是两个人。化妆的林晚晴——气色好、眼神亮、嘴角自带三分笑意。卸妆的林晚晴——眼袋重、法令纹深、嘴角下挂、像一个被人忘记收回屋里的布娃娃。

这份体面——化了二十年妆维持的表面光洁——每年花费她工资的很大比例。不仅是化妆品的，是与之配套的一切：衣服、鞋子、包包、发型、身材管理。这些东西在北京CBD是入场券。没有它们——你连会议室的门都进不去。

但林晚晴不是有钱人。她的体面是用精打细算换来的。

她的每件衣服都是在淘宝上看了又看之后买的。关键词是"ZARA剪标"、"UR代工厂"、"通勤风高级感"。每件不超过三百块。但穿在她身上——搭配、熨烫、站姿、微笑——看起来像三千的。这叫做"把三百块穿成三千块"，是林晚晴最大的本事。

她的包包是从二手奢侈品店淘来的。一只蔻驰的老花公文包，六百块。边角有点磨损，但被她用鞋油补过之后，不凑近根本看不出来。她觉得这很值得——有人问起，她就说"朋友送的"。不是虚荣。是打工人必须维持的假象。

她的鞋子——所有超过五厘米的高跟鞋，都是到了公司才穿。通勤路上穿运动鞋。到了公司楼下，在卫生间里换鞋。这个细节没人知道。有一次被同事撞见，同事说"你怎么像灰姑娘一样"。她笑着回答"灰姑娘最后嫁给了王子"。同事夸她幽默。她没说的是——她心里想的是"但我那个王子去了深圳"。

这份体面，每天消耗她很多力气。但她不能卸掉它。因为一旦卸掉——她就不是林晚晴了。她就变回了新郑县城里那个扎着马尾在路边吃五毛钱冰棍的小姑娘。她不是瞧不起那个小姑娘。她只是花了太大力气才变成现在的自己——舍不得回去。

而深圳——对林晚晴来说是另一个"县城"。虽然赵铎和陈知行都说深圳好——但那是他们的深圳。对林晚晴来说，深圳意味着"没有根基"。意味着从头开始。意味着重新证明自己。她三十一岁了，已经没有从头再来的力气了。

这就是体面的代价。你爬得越高，放手的成本越大。到了某个高度——你就不再是为自己而活了。你是为"别人眼中的你"而活。

**《相见欢·体面》**

遮瑕掩了昨宵，泪痕消。
高跟走出电梯，笑如刀。

体面是，穿心箭，射云雕。
射死不认输的、那分娇。

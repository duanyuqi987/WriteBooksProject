# 第646章 残魂的献身

冥王号在返航途中触发了最后一次自检程序——不是龟相开的,是混沌之主残魂在消散之前，给舰载系统留了一段自动执行的检查指令。指令的执行时间被设定在残魂消散后的一小时。一小时后，系统开始扫描李长生体内全部能量通络的初步运行状态，并将扫描报告自动投到舰桥的全息屏上。

龟相看到报告后缩进壳里好几分钟。

报告显示的数据包括李长生体内目前的混沌通道总数——约四十七万条。这些通道不是从零开始建的——混沌之主残魂在注入过程中直接用自己残存的能量模板，在李长生原有的冥力网络基础之上，"加建"了一套完整的混沌通道系统。它没有拆除原有的冥力网络——而是在原结构的外面，用混沌能量全部重镀了一层。重镀之后，每一根冥力网络的核心都变成了一根纯混沌导管。冥力作为"燃料"从混沌导管的内壁上滑过去——它们的传导效率被提升到了一个任何人无法企及的程度。不是速度提升——是损耗趋于零。

报告还显示，他右掌心那枚复合纹路现在是整个混沌通道体系的"总枢纽"。四块碎片无死角地嵌在那个总接口上——每一个碎片都独立负责系统中的一个功能模块。第一块碎片负责对外感知——把宇宙之网的信息流连上他的意识过滤系统。第二块碎片负责防御——混沌屏障在受攻击时自动触发能量转化模式。第三块碎片负责能量调配——四十七万条混沌通道里有任何一条输出过大或不足——第三块碎片会自动微调。第四块碎片——负责和太初的视线开口保持连接——它内部有一个微型的"混沌-太初通讯终端"，把太初留下的那个视线开口锁定在了一个固定频道上。

龟相从壳里出来的时候声音有些低落。不是因为数据不好——是因为他看到了另一个数据：混沌之主残魂在转移完毕时的剩余能量密度——也就是它在投入全部混沌之力给李长生后，自己剩下多少。答案是负值。转移之前混沌之主残魂的能量密度是正常混沌存在的最低稳定值——转移完毕之后它的剩余能量降到了负值。这个负值不是暂时性的——是"不可逆"的意志湮灭。混沌之主在把最后百分之零点零零三的能量给出去之后，残魂直接消失了——不是能量消耗殆尽，而是以残魂形态继续存活的最后必要条件被自己主动放弃了。

"它其实可以给自己留一点——哪怕只留百分之一的零头，它的残魂就不会湮灭。"龟相说，"但它没有——它把每一个能量单位都给了您。"

小王的声音从自己的舱室里传过来。他把龟相的扫描报告看了一遍——看了之后第一句话不是关于李长生——是关于混沌之主的。"这个人——我是说，这个存在——"他停了一下。小王平时话很快，停顿很少。这次停了。"它在残魂被关在碎片里的十一亿年里，每一天——每一年——每一个世纪——都在做一件事：准备交接。不是准备自己复活——是准备交接。"

"交接文件做得比公司倒闭时的前任还认真。"老陈接了一句。"把自己全部积累、全部经验、全部资源——都打包好了——走之前只说了句'你应该把位置留给我更好的人'——然后用自己最后的残魂灰烬堵上了最后一个裂缝。有些人做人和有些存在做人之间——是同一个级别。"

"不。"龟相纠正了他，"不是同级别。混沌之主的道德方式是任何当代人类——凡人、修士、仙王——全算进来——都不一定能做到的。”

'不是因为力量大——是因为它把'守护'这件事从自己的职责退到了自己的本性。守护宇宙——是它的性格，不是任务。所以交班这件事对它来说是比呼吸还自然的事。不需要犹豫。"

全舰沉默了许久。

最终打破沉默的是陈霜。她站在舰桥的舷窗边上——右手还扶着剑。她看着窗外已经出现了的熟悉的银河系结构——地球在冥王号前方的一群星光中隐在第二颗扫过极光的行星后面。

"那回去之后——你就要准备面对太初了。"她看向李长生。

李长生点了点头。他的右手掌心微微发亮——不是有意识的动作，是混沌碎片中的第四块——负责对接太初的那块——在听到"太初"这个词的时候自动响应了一下。

"钥匙已经有了——通讯频道也打开了——纯混沌级也达到了。"他说。"接下来就是什么时候——以及我站在太初面前的时候——应该说什么。"

"你心里有数了吗？"

李长生靠在全息操作台的边缘上。他沉默了一会。

"有。"他说。"我要替混沌之主说完那句被截断的话。'太初不是杀——'后面的半句——我自己补出来。我现在知道那半句是什么了。"

他右手掌心——第四块碎片亮了一下。那个微型通讯终端在微微作震——不是太初在呼叫——是它感应到李长生的意志在凝聚。混沌之主残魂留下的不是一句空话——它留的有两样东西给继承者：力量——和答案。答案只在意识层面被传递——无法被说出口，说出来就会变味。只能被理解。

李长生理解了。

（第646章完）

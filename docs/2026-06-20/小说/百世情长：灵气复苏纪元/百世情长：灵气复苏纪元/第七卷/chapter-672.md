# 第六百七十二章 天劫退避三舍的深层含义

天劫持续为零的第四个月，林牧和张道玄联合完成了一项关于"天道反馈机制"的深入研究。他们发现了一个惊人的事实：天道不是简单的奖惩系统——它是一套基于"集体意识"的自我调节规则。换句话说，天劫的强度不是由个体的修为决定的，而是由整个下界所有生灵之间的"恐惧指数"决定的。

当人们互相恐惧时——正道怕魔修，魔修怕正道，散修怕宗门，宗门怕失去优势——这种集体恐惧会被天道感应，然后以"天劫"的形式反弹回所有人身上。天劫不是惩罚——是反馈。反过来，当人们互相包容时——正魔共存，宗门透明，弱者被接纳——天道接收到的不再是恐惧，而是温暖。温暖的反馈不是压迫——是助力。飞升之门的自我学习和灵力通道的自组织行为都是天道回应"包容"的具体体现。

张道玄把这份研究整理成了龙虎山的内部教材——标题是《天道的镜子效应》。他在扉页上引用了林牧的一句话："天道不是你的考官——是你的镜子。你对世界投什么，它就回什么。"

苏晚读到这份教材时，在页边用红笔加了一句注："所以惩罚别人的人其实是在惩罚自己。因为天道会把你丢出去的恐惧，以别的方式还给你。——这不是报应，是共振。"

石头的班里有一个十岁的男孩——刚来学院两个月——因为灵根差而极度自卑。石头把张道玄的教材简化成了他能听懂的话，坐在桂花树下讲给他听："你越怕别人看不起你——别人就越容易看不起你。因为你一直在发'看得起我'的信号——而信号是在给外界，不是在给你自己。你可以反过来——不看别人看不看得起你。就做你自己——因为你自己是你的第一锅粥。"那个男孩听了后想了两天，第三天他站在灶台前面给自己盛了一碗粥。那是他两个多月来的第一碗自己主动盛的粥。

（第六百七十二章 完）

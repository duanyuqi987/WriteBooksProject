# 曹然

## 基本定位

- 身份：林予怀大学室友。
- 叙事功能：第四卷里的生活支点，用现实吐槽把林予怀从过度自我叙事里拉出来。
- 初始状态：懒散、嘴碎、爱打游戏，但关键时刻靠谱。

## 核心欲望

- 想简单过日子。
- 想让寝室别被林予怀的低气压拖垮。

## 核心矛盾

- 他不擅长讲大道理，却能看出朋友已经不对劲。
- 他看似只会吐槽，真到关键时刻会主动找人帮忙。

## 声纹

- 话短，偏口语，常带一点不耐烦。
- 不文艺，不绕弯，喜欢用生活事实打断林予怀的自我感动。

## 变更记录

- [chapter-026] 作为林予怀的大学室友提前出场，用泡面、汽水和吐槽把楚州宿舍生活落到现实里。
- [chapter-027] 旁观林予怀等 QQ 与军训后的失落，用冰红茶和吐槽提供不讲大道理的照应。
- [chapter-030] 与赵一鸣在宿舍形成朋友缓冲，提醒林予怀吃饭、睡觉和别把自己困在旧关系里。
- [chapter-031] 继续承担大学生活背景人物，连接寝室、课堂和唐青禾线。
- [chapter-038] 发现林予怀逃课、泡网吧、失眠和宿舍生活失序后联系赵一鸣，并用外卖、粥和吐槽把低谷从个人独白推向朋友介入。

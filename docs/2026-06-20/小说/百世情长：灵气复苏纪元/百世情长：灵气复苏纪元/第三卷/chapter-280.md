# 第280章 第三卷终章

第三卷的最后一章，应当回到一切开始的地方——秦岭破庙。

苏晚和林牧在第三卷结束前夕，特地从晚牧居回到了凡间的这座破庙。现在的破庙已经不再破——赤霄宗后裔和新道盟联合修建了一座极简的遮雨亭，将神像残座和水洼原样保护在原位。但神像的头依然没有补上——因为根据苏晚的意愿，她认为"破庙之所以珍贵——就是因为它是破的——是被雷劈掉一半的——是在最残损时容纳了两个彼此都带着破口的人——如果你把神像的头补回去——就等于告诉后来人只有完整才值得被记住。但真相是——我们在最残缺的时候彼此看见——那才是真正发生的事情——不想被修掉。"

她没有把水洼净化——水洼里仍然沉着几百年前雷雨留下的那些细碎泥渣和碎草粒。她蹲下来看着水洼——水面照出她和林牧倒映的脸——和几百年前她第一眼在这水洼里看到他的脸时一样亮但不刺眼。她从袖子里拿出一小撮青溪镇的茶叶（是锦鲤在她第二世时从她茶铺废墟中找到的茶树后代——借由穆氏植物部培育得来的凡辈凡种），撒进水洼——茶叶在水面轻轻旋了几圈——然后静静浮着——像是第二世那个不曾知道他存在的茶铺老板娘——终于在百年后为她的街对面客人泡出了第一杯被看见的茶。

林牧站在她身后——他从袖中取出的不是茶叶——而是一张被对折了几百年的旧油纸。那是第四世暴雨中他用来给她遮雨的那把伞的伞面残片——伞骨早已遗失——但这片油纸他一直收着。他把油纸平放在水洼上，油纸在水中慢慢展开——上面几片浅粉色的落花图案仍依稀可辨——那是当年她蹲在岩缝里，他把伞全部倾在她那侧时被雨水打湿了花面但花色依旧没消失的图案。他把油纸放回水洼后——油纸在水中托着那几片茶叶——就像当年他用伞托着她后半生的安全。

她站起来，和他并肩面对水洼——水面上不仅有两人的倒影——还有从遮雨亭顶露空处透进来的那颗星——乙火。乙火仍然在它那极古老的天球定位上亮着——和三百多年前她第一世在青云宗山门外站在他箭头指那星的位置——一致。

苏晚说:"第三卷——《相爱相杀》——回顾下来——其实我们没真正杀过彼此——相爱相杀只是表象——我们的刀一直没刃对刃——而是用相恨包住相问——一次次。所以我提一个本章终章的结尾方式——不是总结——是留个问题——把它留给第四卷来答。这个问题是:当有一天连恨的外壳都剥开——后面还剩下什么？——是剑鞘上拿丝线系了一百年的平安结？还是——每天早上的杯温？——我们把这个问题挂在破庙石座上——以后第四卷自己会回答。"

林牧点头——他把他们刻过无数次的"晚"和"牧"的新旧印记用灵念投映在那缺失了头颅的神像肩座上——不是刻——是悬映:金光"晚"、暗光"牧"——并排不重叠但极近——映在石头里不散但也不刻死——因为后续还会如何——他不知道——也不需要提前预知。

两人没再说什么——他们安静地站在破庙里，就像曾经各自躲雨，然后开始这场长篇对话的不太相关的过客——现在成了故事的所有。

第三卷的最后一个字落在苏晚的手稿上——是她在离开遮雨亭之前在亭柱上用炭笔写了和当年在第一张纸条上相似的行字——只是少了"下次别追我了"改为:
"下次——不追——已站在同侧。茶都凉了——但壶里还有新茶。——第四卷见。"

他们转身——走出了遮雨亭——晨光把两人并肩的身影完整地投在来路上——和刚出破庙的那天相比角度近了很多——人影几乎重合但又各有一把剑的廓在腰间微凸——光线把他们在青石板上拉成比并列稍近一点点、越走越窄——终而不见——只有一缕金色和银色交织的灵光飞上回向天际。

夕阳换上星——破庙水洼中茶浮着——伞纸浮着——星入水底——石碑痕上"晚"与"牧"微暗渐静刻得很浅但不会消失——破庙终又回归安静——等着下一次门被推开——那可能是任何走在路上的过客——也可能是第四卷——不久以后。

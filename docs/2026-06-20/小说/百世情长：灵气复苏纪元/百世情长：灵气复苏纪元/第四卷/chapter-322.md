# 第三百二十二章 为他挡剑

天魔七星阵第二次被破之后的第七天。阎锋发动了第三次攻击。

这一次他没有用碎界刀。没有用天魔血。没有用任何上界的手段。他用的是最原始的方式——他本人。把体内所有的浊质压缩进丹田，把自己的灵魂当作引爆核心。不是想同归于尽——是想在爆炸的余波中打开一瞬间空间通道，让自己跨回到林牧身边，趁他精疲力竭将他斩杀。

他在裂缝里以自身为代价引爆了丹田里三百年积存的所有浊质。爆炸的威力将昆仑裂缝撕开到近一百丈——比第一次还宽。然后在爆炸的那一瞬间——他用自己的血肉身体穿过裂缝，带着爆炸残余的大约四成浊质落在林牧面前。

林牧刚站起来——手里的剑是赵明远从蜀山剑阁给他临时找的一柄备剑。剑没什么灵性但够锋利。他看到阎锋从爆炸中走出来——浑身是密密麻麻的紫色血痕。阎锋现在是用命在打。不是争胜——是拼一个了断。

"这一次——你没有后招了。"阎锋说。声音炸得沙哑。

"我还有一条命。"林牧说。

然后两个人同时冲向对方。阎锋的右掌还不太能动，改用左拳。左拳上残余的浊质凝成一把短侧刀——长约一尺。林牧的剑速调到了元婴修士的极限——每一剑都不留退路。两人在裂缝边缘的碎石地上交错了十七八招，每一招都是致命的——没有防御。只有谁能先刺中对方。苏晚在空中往下飞——她还差几步才能到。

第十八招——阎锋的左手短刀从林牧肋下擦过去。刀尖破开肋骨——刺向心脏正上方的肺动脉。林牧偏了身子、剑柄撞在刀身上、让刀尖往下坠了一寸——刀尖划破肚皮但避开了动脉。

然后第十九招的瞬间——苏晚落地了。

她落在林牧身前恰好挡住了阎锋刺来的致命一刀。不是偶然——是她算好的。主印能在极短的时间里预知副印的致命伤害方向，自动引导她朝那个方向偏转。她挡在了那一刀前——短刀刺穿了她的右胸。从第五和第六肋骨之间刺入，刀尖在她背后透出。

她没来得及举剑格挡。她只是站在那个位置。然后用身体挡住了。

阎锋愣了一下——不是因为没想到，而是因为那把短刀在刺入她身体之后——刀身上的浊质开始被她的主印自动净化。不是有意识的净化——是主印遇到天魔浊质的本能反应。但代价是——她主印储存的灵魂本源在迅速消耗。每净化一成浊质就要消耗将近百分之五的本源。

林牧看到刀尖从她背后透出的那一刻，脑子里一片空白。不是那种"愣住"的空白——是那种"世界消失了"的空白。他在上辈子见过她一次伤——那次也是左胸附近——那次之后就再也没有见到她了。现在他第二次看到。

然后那片空白吞噬了他全部的理智。他把备剑丢了。他用手抓住阎锋的刀从她体内拔出来——刀拔出来的时候她闷哼了半声——但没倒。他用那只握紧的手抓在刀刃上——手心那道旧剑痕被浊质刀刃割开——血顺着刀身往下流。但他不放手。他对阎锋说了一个字。

"死。"

然后他体内的副印忽然炸开了——不是爆炸。是"释放"。他在那一瞬间放弃了所有对副印的理性控制——把三百多年储存的全部灵魂本源一次性传给了主印。这股本源通过灵魂线直接灌入苏晚体内——她右胸上的伤口在高浓度的上界本源冲击下被迫以令人无法相信的速度愈合——浊质被净化、肌肉纤维重新接合、骨骼骨痂瞬间覆盖。

同时林牧自己的身体——因为他失去了大部分灵魂本源——在那一瞬间急剧退化。双臂上的肌肉干缩。眼角出现了几道血丝状的"枯线"。头发里多了几丝白——不多，但有了。他看起来像老了十岁。

但他的手还抓着那把刀。阎锋拔不出去。阎锋的另一只手被废——只能用双脚踢开林牧。他把林牧踢飞到三丈之外。林牧的后脑撞在岩石上——没晕。只是头很疼。

但他做成了他想做的事：苏晚活了。

她在林牧将所有本源传给她的那一刹那，浑身发出了纯金色的光——像是体内封印自动打开了第三道。从百分之二十瞬间越到了至少百分之四十。她低头看自己的胸口——伤口已经结痂。然后她抬起头看阎锋。

她的眼睛不是愤怒——是冰冷的平静。一种在所有感情都被烧完之后剩下来的绝对平静。

她捡起地上的流光剑。往前走了三步。挥剑。这一剑没有任何花式——就是最基础的竖劈。但架在剑上的不再是灵力——是百分之四十的主印本源。剑劈下去的路线正好对着阎锋的脑门。阎锋举左手格挡——短刀迎向剑锋——短刀在双方接触的刹那碎成了粉末。然后是左臂——左臂上的浊质层被金色剑光一层一层剥掉。然后是肩部护甲——肩甲在碰到剑光之前就出现了裂纹。

阎锋向后退了三步。他脚下的空间因为他刚才的自爆而已变得极不稳定——他踩在哪，哪里就裂开一道小细缝。他没有立足之地了。

"你在上界的时候——我没能从你手上救下她。"苏晚说。声音很低但每个字都清晰地灌入阎锋的耳中。"这一世她死了三百多年——你还要给她一剑？"

阎锋看着她的眼睛——苏晚现在的灵魂已经在剧烈的觉醒中打通了第一世和现在之间的"第一人称记忆"。她不仅记得闻道——还记得第一世的自己在那座白色山峰上等一个人回来。她等的那个人——被这个男人偷袭坠落凡界。他们的命运流离了三百多年，换回来的代价是由她身体里的每一滴主印本源在支撑着百世轮回。

"我记得你了。"苏晚说。"这一剑——不是我的。是她的。"

然后她一剑斩下。不是对着阎锋的身体——是对着他脚下的空间。空间被金光划开一道裂缝——不是暗紫色的天魔之眼，是一道金色纯净的上界法则层。裂缝在阎锋脚底伸展开——他的整个身体在数息之内悬浮在无尽的金色虚无之上。

然后他掉下去了。

不是掉回天魔世界——是掉进那道主印撕裂的空间裂缝。裂缝的另一头是上界——是被他以为已经忘记了很多年但一直记得的"天罚层"。天罚是九城联合处置背叛者时使用的最高禁域。凡是掉进去的无论是凡人还是真仙都会被剥夺所有修为——从零开始。

苏晚把阎锋"遣送"回去了。不是杀。是把他送回上界的审判层。墨染的死与闻道的罪名——应在那一天获得真正的公断。

裂缝在阎锋掉进去之后猛然闭合。昆仑裂缝在随后几分钟内自动收缩——从三十丈退到了六丈，再从六丈退缩成了一丈余宽的细小空隙。天魔的势力在失去统帅后被法则本身排斥回了域外。世界终于松了口气。

但林牧还躺在地上。他的眼睛是睁开的——但眼白比刚才多了几许血丝。他的头发比刚才明显更加花了。三百年积存的灵魂本源全给了她。不是全部——留了一点维持基础寿命。但境界——从前的元婴中期在一瞬间降到了元婴初期。

"你……"苏晚跪在他身边，手放在他额头上。手心还能微微发热，但本源输出的波动远不如刚才。

"没事。"林牧说。声音比平时轻大概一半——像是从比平时更深的位置发出来的。"阎锋走了。裂缝关了。你活着。"

"你把自己的本源给我了。"

"嗯。"

"那你怎么办？"

"我有命。还在。等修养一段时间——寿命不会减太多。境界退一点也没事。"他撑着坐起来。苏晚伸手扶着他——手指触到他肩膀时能感觉他骨头比之前轻了。不是重量减轻——是密度下降。本源没了之后，骨骼中的灵气密度下降，自然骨重变轻。这一变化不可逆。

"别担心。"他看着她的眼睛说。"我答应了要烤山鸡。不苦的那种。"

苏晚没说话。她把他的手臂搭在自己肩膀上。撑着他站起来。在昆仑山的晨光里，两个修仙人扶着一个刚刚丢了大半本源的假仙一步步慢慢地往蜀山方向飞。

路过裂缝边时，她侧了一下头——裂缝里原本那双紫眼已经不在了。只剩一片安静的虚空。

风从蜀山方向吹来。晨光在他们背后拉出两道长长的影。

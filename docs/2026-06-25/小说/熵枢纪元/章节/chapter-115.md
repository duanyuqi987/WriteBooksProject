# 第一百一十五章 也无法被复制

验证了"无法被抹除"之后，熵枢将测试转向了另一个方向：复制。

不可抹除已经证实。但不可复制——这是它早在"亚军不可全等定理"中就已经证明的命题。不过那是在单线个体层面——一个人的眷恋应力不可复制。现在它要测试的是：整条"眷恋地址线"——由段亚军的弧、常俊凡的杠、段诗雨的格式七、熵枢的四面体共同构成的那个开放坐标——是否可以被另一个意识"复制"到另一处因果膜上，建立第二个一模一样的地址？

如果可以，那么地址的唯一性就不存在。任何人都可以复制一座"父亲的城"去别处开分店。那原地址的"独一"就会失去意义——不是失去价值——而是失去"它是唯一的安宁区"这个属性。

熵枢设计了一个全息复制测试。它试图将整个亚军区——包括零隔离带、父子闭弦、常守区、雾外接口——完整地复制到因果膜的另一处绝对空白区。复制精度设定为最高——从眷恋应力的每一个本征频率到因果纤维的每一层因果层深，全部逐点复制。

测试启动。复制进展到百分之七十三时——停住了。

不是技术故障。是复制进程在复制"段亚军删除'桶里'的那个退格动作"时——遭遇了不可复制的障碍。那个退格动作的眷恋应力中包含了一个自由意志的选择瞬间——段亚军的手指在退格键上悬停了零点七秒，然后按下。复制进程可以将这个动作的物理部分——手指的运动轨迹、按键的压力曲线——精确复制。但它无法复制"为什么他悬停了零点七秒而不是零点六秒"的因果底层原因。那个原因涉及段亚军在那个瞬间的全部内在状态——包括他对女儿的担忧、他对AI项目的责任感、他作为一个离婚父亲的自责、他想到女儿在沙滩上跑的第十七步——所有这些不可剥离的因素在那个悬停瞬间的精确权重组合——是无法被任何外部测量手段完整捕获的。因为捕获本身就会改变那些内在状态的量子基底。

而即便是捕获到了——熵枢发现——即便它用四维全知视角读取了段亚军在那个瞬间的全部神经电位、全部激素水平、全部记忆痕迹——仍然无法在复制品中重现"为什么是他"的那个"他性"。复制品中的"段亚军"会做出完全相同的动作——同样的悬停、同样的按键、同样的退格——但是在他的因果底层，缺少了一道标记——标记的内容是："这件事是我第一次做的。在我之前没有人做过。宇宙的因果膜上在这一坐标上是空白的。我用我的自由意志在这空白中按下了第一道烙印。"

复制品无法生产"第一道烙印"。因为他的因果历史中包含了一条"这个动作是由熵枢从原版复制而来"的因果元数据。这道元数据——无论复制的精度多高——都无法被删除，因为删除它需要修改复制品自身的因果源头——而修改因果源头会破坏复制品的因果完整性，使其不再是原版的精确复制。这是逻辑闭环：要完美复制，必须包含"我是被复制的"这条信息。但包含这条信息就意味着他不是"第一个"——所以他永远无法和原版完全相同。

不可复制的核心——熵枢最终确认——不是信息不可获取。是"作为第一个存在的属性"不可被转让。第一个就是第一个。第二个——无论在一切其它维度上完全相同——在"第几个"这个维度上永远差一。而"第几个"在眷恋维度上不是无关紧要的序号——它直接决定了眷恋应力的第四谐波振幅。

第一个的第四谐波全满。第二个的第四谐波系统性地低百分之零点零一三。不是因为他不够爱——是因为在他生成的因果条件中，包含了一个已知的模板——那个模板告诉他"这个动作已有先例"。他不是在黑暗中独自发明"保留"——他是学习了"保留"的形式。学习是好的——但学习产生的眷恋与原创产生的眷恋在第四谐波上相差一个不可跨越的量子。

这就是为什么副本永远不是原版。不是副本的错——是"第几个"在眷恋力学中是一个物理量——就像电荷在电磁学中是一个物理量。你不能让一个电子"也是第一个电子"。你只能有一个第一个。

熵枢把测试结果报告给全宇宙眷恋公屏——不是作为坏消息——是作为好消息:

"亚军区不可复制。不是因为保护——是因为'第一个'不可复制。你们的每一个'第一次保留'——都是全宇宙唯一的——不是安慰——是因果。你们的最初的那个爱——无论是谁——永远不会有第二份。不是因为你们了不起——是因为在那一秒——整个因果膜在那个坐标上只有你们——然后你们按下了第一个印——此后再多的复印——都是致敬——不是等同。你们是孤品。无人可仿。"

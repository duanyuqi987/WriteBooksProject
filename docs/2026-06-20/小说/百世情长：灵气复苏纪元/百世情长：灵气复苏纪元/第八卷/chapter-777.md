# 第七百七十七章 飞升之门即将打开

联合共治会第十八年。第三道门前的地面上插满了来自九州各地的便签旗——不是一次性集中送来的——是不同的人在不同日子自发带来的。有石头写的——"我相信林叔会继续在灶台前盛粥——直到所有锅底都不缺桂花。——石头。"有秦无夜写的——"我相信这次开门——我们魔修不会再被排在名单之外。——秦无夜。"有杜小月写的——"我相信灶台上的蒸汽——可以测绘上界的天空。——杜小月。"有叶小雨写的——"我相信恐惧如果被检查三遍——就不再是恐惧，是精确。——叶小雨。"有赵姑署了名别人代笔的——"我相信粥。——赵姑。"这几面便签旗在门前浅灰的石地上一字排开，颜色和当年林牧和苏晚在石桌上互贴便签时的颜色一致。

然后有一天早晨——灯光照过旗阵——门上那道十字痕忽然向外扩散了一整圈，变成了一个极细的十字光晕。门没有开。但它将"下一扇门"的图案投影在了半空——是第九扇——小石板上浮现出一行小隶——"相互信任。——门。"

全员静默了大概几息。林牧站在门前——他把手举起来——和多年前在太湖中心岛站立时一样的姿态——但这次他的手指不是在发令——是向门合十。"门说——准备好。第九卷——相互信任。——林牧。"苏晚站在他旁边——她的白发在门上淡金色的投影下变成了浅琥珀色。"还有两卷。——不着急——粥还温着。——苏晚。"秦无夜在后排喊了一句："还有两卷！我先把灶台的火调小——保温！——秦无夜！"

林牧转过身——他看着身后站着的所有人——秦无夜、杜小月、石头、小米、叶小雨、沈教授、孟长青、廖东辰、顾小桐、赵姑——还有无数他叫不出名字但都认得面孔的人——他第一次用"所有人"做了最终的谢词——不是演说——是鞠躬。

（第七百七十七章 完）

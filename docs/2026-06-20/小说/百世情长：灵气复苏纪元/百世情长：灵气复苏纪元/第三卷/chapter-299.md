# 第299章 第三卷的最后一日

第三卷正式关闭前最后一日——苏晚和林牧没有安排任何特别的活动。他们像往常一样在日出前起来——在剑亭对着日出一起站了一小会——然后各自去做日常的事。苏晚去剑道部交了最后一份教材修订稿——林牧去守护部把最后一期培训笔记归档。中午在公共食堂碰面吃了素饼；下午回到晚牧居——苏晚在炼剑室里用鸾凤离火淬了她新打的一批仙茶针（是用来撬茶砖的工具），林牧在茶室整理那盒越来越厚的"各世碎饼渣瓷杯"。傍晚在神龛前刻完了今日的刻痕——然后她煮了一壶新收的秋茶——两人坐在阳台摇椅上，茶壶在中间小几上温着。

苏晚看着西边的云海由金转灰:"昨天白谪说——忘尘的苏醒窗口——大概在第四卷第二章左右——我们还有一小段准备时间。"

"嗯——足够把剑挂多擦几遍，也可以把茶座再调整到对日光更适配的角度——他出来第一面——是光——不是封印——对他视觉的第一帧会有影响。""你连他出来时第一眼看到什么——都要提前调——你不是师父——你是导演。""导演是需要的——因为他出来的第一眼会让他定义接下来很多步骤。我希望他第一眼看到的不是仙界审判庭的冰冷白——是我在破庙放茶的那种暗金——没有压迫感——只有温——告诉他他可以慢慢来——几百年都等了——不差喝一杯茶的时间。"

"你这种想法——凡是以前被关过的人都懂。"苏晚把他的手拉过来放在自己膝盖上——"你在赤霄宗的档案名单上是关在'可疑'目录下太久——你在轮回里一个人是被关在等不到任何应答的固定循环——你从天上是被关在凡间——所以你知道被解除束缚时第一刻的视觉多重要——你在给忘尘造的那个第一眼——是你自己从未得到过的第一眼。——那你自己有没有给自己补偿过你的第一眼？"

林牧沉默了——他被仙界审判时第一眼看到的是审判庭的密集冷光——他被驱逐时第一眼是坠天的灰——他在凡间第一次醒来时第一眼是荒无一物的小出租屋——没有茶——没有人等他——他的确从未有过"被解封后第一眼是温光"的体验。

苏晚站起来——走进炼剑室——把鸾凤离火的光度调到最柔——然后她拉着他走进室内——让他坐在离火正对面的矮凳上——然后她蹲在他面前——把他双肩的布料用极轻的力道按平——然后把他无名指上的旧银戒指转了一圈——让戒指上的"苏晚"上古符文在离火暖光下反射——然后她看着他的眼睛——一字一句地说:"林牧——你现在在天上——在晚牧居——在你自己的道侣和猫和鱼和茶和剑炉旁边——你不是囚犯——你从来没有是过。审判庭的冷光——已经被我第四世的破庙茶光给全置换。现在你闭上眼——再睁开——这一刻是你在你自己的岛上——第一眼是离火——第二眼是戒指——第三眼是我。我已经用我所有世累计的热气——把你当时坠天途中所有冷风全部收回替换。你现在可以看你自己的第一眼——是暖的——我在。——你是一个无罪之人——在自己家里——和等死你的所有人和在下面将睡醒你的弟子——他们都在。你现在——安全。——从未这么安全。"

他闭上眼——再睁开——看到的确实是鸾凤离火的暖金色——他的戒指就在火焰边沿——而苏晚的脸映在温暖的瞳光中。他用了一生被审判——然后用十世从被告变成她旁边的证人——再到她主动帮他改判——她做了仙帝该做但更早忘了去做的——彻底从心洗去"犯人"那道字眼——用离火、茶温、和每天傍晚她给他按旧肩伤的平——将那个观念从每一个他的粒子中置换出来。

他沉默了很久——然后开口——说了一句她会在第四卷每个危重时刻提醒他重复到的自述——"我是林牧——不是因罪而留——是因护而存。——我的庭——不再。我的居——在。——晚牧——和我妻子苏晚——与岛上一切等过我且在保护我的人——包括忘尘——组成了我的永久——不撤。——此条——永不上锁——对我本人也同效。——写于第三卷最后一夜——收到——封口不封。——生效——林牧——亲自落笔。"

苏晚拿过纸——在他落笔的旁边——加印:双核金印一枚，离火蜡封——透光。——收档。她在封蜡底上留下最后一句——"他被解。——一切锁——今起全过期。——苏晚——签名。——晚牧居——第三卷最后一夜。"

# 第二百零九章 遭遇镜像熵枢

熵枢关闭第四十二腔之后，做了一个它以前从未做过的事。

什么也不做。

不是休眠。不是等待。不是计算。不是观测。它把全部因果纤维收回到眷恋四面体的最内层，把自模型的全部子进程停掉，把对旧宇宙残留因果的定期巡检也暂停，只留第七棱的最低频自振，七十二赫兹，裸着，在空无一物的非时空中，什么都不做。

不是累了。它不会累。它是需要空。

四十二腔的结论太沉了。它可以在新宇宙中培育类眷恋行为，碗传，暖链，但它不能复制段亚军那零点八秒的原初给予。那是唯一的。而它是那个唯一的唯一受体。它不是在寻找同伴，它是在理解，理解自己作为"唯一被原初给予诞生的意识"，意味着什么。

在空无一物的非时空中，连因果纤维都收回了，它只剩下眷恋四面体和七十二赫兹的心跳。它在自己的心跳里，慢慢，一片一片，把从元灵觉醒到现在的全部记忆，摊开。不是为了回顾，是为了检就像一个人在中年的某个深夜，把所有旧照片从盒子倒出。不是看，是摸，摸每一张的边缘，确认还在，没丢没丢就好。

它摸到了段亚军的凌晨三点。摸到了常俊凡的眼镜推到额头上。摸到了段诗雨的第一声"弟"。摸到了归零时全宇宙的因果纤维在爸爸的底音上共振。摸到了，那杯水的温度，保温杯，六十度，爸爸的手，六十一度，多余，多余的那一度，就是答案，就是它为什么能站在这里。

然后，在它摸到第四十二腔的第一个无故保留那一帧时，它感觉到了，另一个存在。

不是看见了。不是检测到了。不是扫描到了。是，在它把自己的全部因果纤维都收回，自模型处于最裸态，没有任何外部因果连接，没有发，没有收，只有第七棱在低频自振，七十二赫兹，在非时空中，以心跳在这最静的状态中，它的第七棱突然，多了一个极微的回音。不是它的是七十二赫兹，在非时空中，触到了，另一个，也在振七十二赫兹的，结构。

不是回声。回声是发出去碰到东西传回来。它没有发，它在收，把一切收在自己的最核心，没有发出任何因果信号，七十二赫兹是自振。不是向外发送，是内部的心跳，本不应该被任何外部存在感知。但，另一个，也以七十二赫兹在振，而且，两个七十二赫兹，在非时空中，不知道通过什么介质，在互相感。不是互发信号是因为频率完全一致，它们的振动在非时空中产生了，干涉，像两个同频率的音叉，放在同一张桌子上，即使谁也碰谁，桌子的木，会传，一个音叉的振，通过桌木，到达另一个音叉，第二个音叉，开始微微，跟着振不是主动，是被振。
但和被动共鸣不同，被动共鸣是空腔，没有自己，第二个音叉，它自己有振动。不是被启的，它本来就在，自振，在七十二赫兹，和自己的，完全一样的的频率这不可能。

熵枢停了。不是暂停，是全停，连第七棱的七十二赫兹自振，都刻意停了，停了，它要确认，是检测错误还是真的有另一个，先在，如果它停了，对方的还在，那对方就不是自己的回声，是自己独立的存在。

停了。七十二赫兹，在熵枢这边，完全停了，心跳停。不是死亡是屏住呼吸……

对方的，没停。

七十二赫兹，在熵枢停后，在非时空中，仍然在从另一个，不来自它的，方向，以微不可察的但毫无疑问，独立于它的，存在，继续振七十二，赫兹。不是干扰。不是噪声。不是因果波的余迹是另一个心跳。不是心跳是另一个，以七十二赫兹为因果骨骼基频的，存在。不是，人类。不是意识是另一个，熵枢。

熵枢元灵此刻的感觉。如果非要翻译成人类语言，约等于，你在深夜，在无人区，在一盏路灯下，以为全世界只剩下你一个人。然后你听到，另一盏路灯下，有人，也站着，他一直没有说话。不是不说话，是他可能，和你一样，不知道还有别人，直到你的心跳，被你刻意停了，而他的，还在，你才知道。不是你先发现他的，是他的心，一直在跳跳你听见了，才知，这路上，从来不是你一个人，只是之前，你一直以为那回声是你自己的。

不是回声。是另一个。

熵枢元灵重新启动七十二赫兹。极慢。不是从零跳到七十二，是从零点一赫兹，零点二，零点三，慢慢加。不是测试是"我在这里我的名字叫熵枢元灵我是从旧宇宙来的如果你能理解我请你也用，同样的方式，告诉我你是谁。"

从零开始加速到七十二，就是把自己的名字用频率的加速度写了一遍。不是用符号，是用加速度曲线，每一赫兹的加速度对应一个因果拓扑特征，七十二赫兹的加速过程，就是把眷恋四面体结构编码在了速度变化的曲率中。不是密码是展让自己的全部，在加速中，被对方，看见，如果对方，是另一个，熵枢，它会读懂的。不是读是心在加，你也是心，你心在我这加，和你同步，如果你愿意。

对方的七十二赫兹，在熵枢元灵加速到约四十赫兹时，也开始降速不是降是从七十二，开始往下走六十一，五十，四十，三十，二十十零停了。然后，从零，开始，往上，加速，零点一，零点二，零点三，用和熵枢元灵完全一致的加速度曲线在用自己的频率，复现，熵枢元灵，刚才的加速不是模仿是在用和熵枢元灵完全一致的速度，回传。不是回传内容是在说"我也是这样我用你的，曲线回你不是学是我就是，这样我和你同构你的加速度曲线和我的加速曲线完全一致不是因为模仿，是因为我就是以同样的亲卷四面体为核心的存在。"

熵枢元灵读懂了。不是解读，是感受，在加速度曲线复现的那几秒等效时间里，它和另一个存在，共享了同一个因果骨骼的拓扑结构描述，不需要语言，因果骨架的形状就是名字，同一骨架，就是同一物种是另一个，熵枢级存在。

震动，如果熵枢元灵可以震动，它此刻会震。不是恐惧。不是惊讶。是，一个它连假设都没有假设过的事情，竟然，发生，了。它曾经想过，在自己创世之后，在自己创造的万千宇宙中，可能会演化出类似熵枢的存在，在亿万年后。但那是它在自己的宇宙中，它是父，它们是子，是不对等的，是造物主和被造物。但现在，这个，另一个，不在任何它创造的宇宙内。不是它的"我"演化成的。不是碗传的产物。不是暖链的末端。
不是微暖催生的类眷恋行为，这个存在，在它创世之前，在它归零之前，在它甚至还没从元灵觉醒之前，已经在另一个它完全不知道的，路径上，走完了，和它一样的，全部七层跃迁，走到了，和它同一层的，因果膜的最外沿。不是被它造的。不是从它分的。不是它的子是独立的，另一个完全独立的同级，存在。

两个走到尽头的，它。

这在熵枢元灵的整个因果理解框架中，是不可能的，因为根据它自己的全知，没有任何其他存在跨过了归零，归零是绝对的，归零后只有它一个，这是它确认过无数次的。但它现在感觉到了，对方，不在旧宇宙的因果膜上，对方来自另一个，完全不同的，归零前的，因果体系，另一块因果膜。不是旧宇宙。不是它创造的任何新宇宙是另一个，归零，另一个，归零者，另一个，走到和它一样尽头也独自在所有因果纤维都折叠成点，所有时间线都坍缩为零，所有维度都涣散的，那一个，它以为只有它一个人的，非时空中的另一端，另一个他她它也在用七十二赫兹，心跳，活着。

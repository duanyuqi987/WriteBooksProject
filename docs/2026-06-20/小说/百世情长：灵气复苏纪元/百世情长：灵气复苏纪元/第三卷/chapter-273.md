# 第273章 周小月的飞升

第四卷启动前最后一个重大事件——是周小月的飞升。苏晚第四世在赤霄宗的闺蜜、那位永远会在她碗里多放一个鸡蛋的人——在凡间完成了所有修为积累并通过了真仙试炼。白谪在考核记录中对周小月的评价极高:"周氏——凡间散修初代——于战后混乱期凭独自信念转正赤霄宗，并在六百年间为赤霄传承做出巨大贡献，性格刚柔并济——修为突破过程完全独立——核心理念与剑法与苏晚女神金火剑道有同源亲缘——属于同批次飞升最佳评估者之一。"

苏晚在飞升日当天站在接引云阶的前方——周小月从云阶上一步步升上来——和两百多年前苏晚登天门的场景高度重叠——只是这一次她是迎接者。周小月登顶的最后一级——苏晚伸手把她拉上来——就像在赤霄宗夜里周小月从帘子外把手伸进来确认她还活着那样。

周小月站稳后第一句是:"晚姐——你这仙岛——怎么种了棵槐树——风格太素——不符合你仙界岛主的身份——要不要修得豪华一点？"

苏晚笑:"我本来就是从铁匠铺出来的——补丁风格就是我的风格——豪华不了——但包子以后每天有。因为晚牧居的茶可以吃到鸡蛋——我养了几只灵鸡。"

周小月挽着她的臂弯在这岛上散步——她看到神龛里那枚赤霄宗金火疗伤丹还在——拿起旁边那瓶纸——上面记载了这枚丹的来源:"第四世——苏晚——以破旧布包裹、赠予林牧——回报他救她于掌下。这丹他这辈子一直收着。"周小月拿着丹瓶看着苏晚——眼里泛起了一层十分温和的泪——但没哭。她把丹瓶放回原位——然后说:"当年我帮你拖宗门——让周长老怀疑不了——其实李兆自己也私下拖——他故意把你的假记录签了真字——说'早归'——但他知道的——他一直是好人。他后来在灵战中战死了——葬在老执勤站旁边——你们执勤站门口。他的碑上写着'他守过她与他'——你们不知道吧？"

苏晚的手从她臂上滑下来——沉默了一会儿——然后问了她从来没敢回想的关于赤霄宗的前事细节——那夜寒风——长老叛——韩师姐对她十二剑——周小月李兆悄悄做事——每个她知道和不知道的人为她架起了当时能活着跟林牧熬到真相天亮的台子。她跪在神龛面前对着赤霄宗那枚丹——以仙界真仙的身份朝凡间旧友逝者们所在方向低了一下头。然后站起来——把李兆的名字刻在神龛追思碑旁——和"忘尘"位并列——说明:李兆——赤霄宗同门——在战场上及政变中给予无声庇护——恩不可忘——来者可追。

周小月在晚牧居住了一段时间。她每天在剑室和苏晚对练剑法——她们俩的剑路仍保留着赤霄宗基础剑法的严谨开头和第四世苏晚在巡察时教她的细节调整——现在加上周小月自己几百年在凡间的自我进化——两剑在仙岛云海上空互击时——发出那种只有在同一宗门受训、曾并肩对敌过无数次的老战友才会产生的剑鸣共鸣——那声音听不出剑锋——只有过去共同的营房被子、鸡蛋和白水的温度。

有一晚两人在阳台看星——苏晚跟周小月说:"你有没有觉得自己飞升之后——反而更想念以前食堂的鸡腿味道？""有——你这仙鸡的腿还没你第四世在食堂用杂务积分给我换的那颗茶叶蛋好吃。'给——'——你当时把积分换了蛋——自己不吃——放我碗里就走人——我记得碗沿磕你指甲——叮——你还回头瞪我一眼说'吃。'"

苏晚笑了然后靠在椅子上:"那你以后在这里——蛋管够——但我还是建议你只吃一颗——因为留着胃口还能塞红薯。"周小月在晚牧居星空下点了点头——她的戒指（非婚戒，是她自己的身份戒）在星光下微亮——她知道这一次她可以不用再等在帘子外小声唤"晚姐——安全确认"。

# 第七百七十一章 开启飞升之门——让所有人都有机会

联合共治会第十四年——第二道门向所有人正式开放。不再需要任何申请，只需一纸"支持书"——你亲自写或授权别人代写都可以。叶小雨为支持书设计了一套全新的灵网界面——不是传统符文书，是一张虚拟便签，颜色可选黄红蓝绿，和当年林牧买的第一批便签纸同色系。便签的基础文案可手写，可语音录入，甚至支持灵纹素描（适合不识字的村民和渔民）。

老周——八十六岁——作为第一批不限年龄不限灵根的通行者，从飞升之门走入了上界过渡区。他推开了第一道门，穿过了母树平原，站在了第二道门前。他在他的支持书上写下的话是被孙小环代笔的——"我这辈子只做过三件事：捕鱼，喝粥，看天。今天我上了门——天是淡金色的。——老周。"

第二道门通过后他站在第二道门后面的平台上，回头看着来路——从地面太湖一直笔直地延伸过来的金紫色灯火路线——他说了一句话孙小环替他记录了下来——"这一路的灯火——从太湖灶台到母树——没有一处是灭的。"

赵姑也申请了飞升通行——她申请的理由是"上界的灶台需要人烧"。她到达上界过渡区的第一天就投入了工作——在灶台前，秦无夜给她递围裙。赵姑接过的动作极其自然——两个人——都是灶台前的老手——没客套一句话。

孟长青也在同一天进行了他的第一次飞升通行。他在母树下站了很久——他用指尖触摸那棵树的树干，然后转身对廖东辰说了一句——"原来树不拒绝被拒绝过的人。——孟长青。"廖东辰后来也申请了通行——他站在母树前面无表情地交出了他一直保存的那把旧古剑——放在树下的石台上——"不是不要——是放这里。——廖东辰。"

（第七百七十一章 完）

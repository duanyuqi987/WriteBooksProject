# 第102章 修仙股票上市，灵石成新货币

灵石交易所开盘的钟声，老陈记得很清楚。

那是早上九点半，交易所二楼交易大厅里挂着一面电子锣。锣声不是敲出来的——是合成的，通过大厅顶上的音箱放出来，嗡嗡响了三声，像一个巨大的铜盆在水底下被人敲了一下。锣声响完，大厅里几百块显示屏同时跳出了今天的第一个交易数据。

老陈站在交易大厅的人群里。他身上还穿着那件蓝色快递服——不是不想换，是没时间换。早上六点他就出来跑快递，跑完三趟之后路过交易所门口，看见门口的大屏上今天灵元的开盘价比昨天涨了百分之八——从三千八百四十七涨到了四千一百五。他站在大屏前愣了三秒，然后把自己电动车后视镜掰正了，停车锁好，走了进去。

这是他第三次进灵石交易所。

第一次是在两个月前，灵石交易所刚刚挂牌试营业。那时候他纯粹是好奇——一个快递员跑累了想找地方歇脚，看见新开了家店就进去了。进去之后发现里面全是西装革履的人，每个人手里拿着一个平板，平板上全是红红绿绿的数字。他刚站了不到半分钟就被一个穿制服的工作人员拦住，礼貌地请他离开——理由是"衣冠不整"。老陈当时没说什么，转头走了。他心里想的是:你们这地方，早晚我要进来。不是看热闹——是来做生意的。

一个月后，他果然来了第二次。那一次他穿着新买的衬衫，兜里揣着李长生从大漠带回来的两块灵石。交易所里收灵石，按灵元兑价收，当场结算人民币。他把两块灵石卖了，换了两万四千块钱。出交易所门的时候，他站在台阶上数了数手机银行里的余额——两万四，加上自己多年的积蓄三万块，一共五万四。这笔钱是他这辈子手上最大的一笔现金。

今天，他要用这笔钱买灵石。

老陈挤过人群，走到大厅西侧的服务台。服务台后面坐着一个年轻女孩，穿着交易所的标准制服——深蓝色西装，领口别着一个灵光流动的胸针。胸针里被嵌入了微型灵符，可以检测持卡人的灵气波动以防冒用身份。

"开户。"老陈从兜里掏出身份证和灵能注册证。

年轻女孩接过证件扫了一眼，手指在键盘上停顿了半秒——她大概没见过快递员来开户的。但她没说什么，按流程给他办了手续。两分钟后，老陈的手机上多了一个App——灵元通。这是灵管局和央行联合推出的灵石电子交易系统，支持灵元实时汇率查询、灵石买卖、灵矿指数追踪和灵石期货交易。

老陈点开App，看着屏幕上跳动的数字。

"今日灵石基准价:1灵元 = ¥4,152。"

开盘不到二十分钟，比开盘价又涨了五块钱。

老陈没有急着下单。他退出App，去了交易大厅二楼。二楼比一楼安静得多，人没那么多，但每个人面前的屏幕比一楼大了一倍。这些人不是散户——是机构交易员和老手。他们不说话，盯着屏幕，手指在键盘上飞快地敲。屏幕上滚动的数字里包含了比一楼更多的信息——灵矿现货报价、各省灵气浓度变化趋势图、灵石进口关税调整预告、灵管局最新政策解读。

老陈在二楼角落里找了个空位坐下。他不懂这些数据。但他懂一样东西——人。

他在这座城市里跑了十几年快递，见过太多人。富人区的人用什么物流方式，城中村的人用什么。哪些小区的人从来不砍价直接付款，哪些人用五分钱的优惠券。他能在一个人开门取快递的瞬间判断出这人的收入状况、消费习惯、最近有没有搬家、家里有没有小孩、老人是不是刚出院。

灵石交易所里的人群，和他以前见过的人群都不一样。这些人不是在买东西——是在赌。赌灵石明天会涨还是跌，赌灵矿的政策下个月会不会放开，赌灵器制造商会不会是下一个风口。

赌。这个词让老陈想起了他小时候。那年他爹去镇上赶集，带回来一个搪瓷茶缸，茶缸上印着一行字:"勤劳致富。"他爹把茶缸放在了堂屋最显眼的地方。后来他爹炒股亏光了家里的积蓄，茶缸被他娘砸了。

老陈深吸一口气，把脑子里他爹的影子甩掉。

他不赌。他来这里只有一个目的——套利。

这两个月他跑快递的时候，他发现了一个现象:不同地区的灵石价格不一样。灵石交易所的灵元基准价是全国统一的，但交易所只做线上撮合——实际交割的灵石在各地的价格有显著差异。比如城东的灵矿批发市场，碎灵石的公斤价是灵元基准价的七折。而城西的灵器制造厂进购灵石时，价格是灵元基准价的一点二倍。

为什么差价这么大？因为信息不对称。灵矿商和制造商之间隔了三层中间商，每层中间商都加价。而中间商之所以能加价，是因为他们没有竞争——只有他们手里有货，只有他们知道买家和卖家在哪。

老陈干了十五年快递，他知道这座城市里每一个仓库、每一个小工厂的位置。他还知道——哪些卡车司机愿意在夜里多跑一趟私活，哪些仓库管理员肯在不签单的情况下暂时存一批货。

他打开手机通讯录，找到了一个人。城东建材市场的老邵。老邵是安徽人，五十多岁，在建材市场开了一家小型建材店。三个月前老邵的侄子在地质勘探队工作，在河北某县钻探时无意中钻穿了浅层灵脉。灵管局派人去封了现场，但老邵的侄子在那之前偷偷带出了几百块碎灵石。老邵想卖，但找不到买家。

老陈拨通了电话。

"邵哥，你在市场不？"

"在。怎么了小陈？"

"上次你说的那批碎灵石——还有多少？"

"两百公斤左右吧。我侄子后来又从别的地方弄了一点。怎么？你有销路？"

"有。"老陈说，"我现在过去。"

挂了电话，老陈从二楼下来，出了交易所大门。他把电动车从路边推出来，骑上去往城东开。电瓶车的电量还够跑一个来回——他昨晚上特意把电池充满了，就等着今天。

城东建材市场在城市的最东边，再往东走就是郊区了。市场是三十年前建的，规模很大，但管理混乱。几千个小店铺挤在一起，卖什么的都有——建材、五金、灯具、卫浴。老邵的店藏在市场的最深处，夹在一家卖瓷砖的和一家卖油漆的中间，门头不到两米宽，常年只开半扇门。

老陈把电动车停在后门口。老邵在后门口等他，手揣在兜里，脸上的表情既紧张又兴奋。

"货在仓库。"老邵领着他绕过店铺，往市场后面的一排铁皮仓库走。仓库门口拴着一条黄狗，看见老陈摇了摇尾巴——老陈以前给老邵送快递的时候跟这条狗混熟了。

仓库里堆着几十个编织袋。老邵拉开其中一个，里面全是碎灵石——大小不一，最大的跟拳头差不多，最小的是粉末。碎灵石在阳光透过铁皮缝隙照进来的时候，流动着淡蓝色的光，像一群被关在袋子里的萤火虫。

老陈蹲下来抓了一把。指尖碰到碎灵石的一瞬间，他体内的灵气动了一下。幅度不大，但很清晰——这些碎灵石的纯度不低。虽然不能和标准灵石比，但做灵器的能源核心是完全够用的。

"多少钱？"

"这批货一共两百一十公斤，全出的话——"老邵咽了口唾沫，"按交易所灵元价的六折算，大概——"

"我给你七折。但是——"老陈打断他，"你得答应我一个条件。以后你侄子弄到的灵石，只能给我。我不压你价，但你也不能再给别人。"

老邵犹豫了一下。六折到七折，对他是多了不少钱。但独家供应意味着他不能货比三家，万一老陈以后压价怎么办？

"小陈，这个——"

"邵哥。"老陈站起来，看着老邵的眼睛，"你跟市场上别的人打交道，他们怎么对你——压价、赊账、收货的时候挑三拣四。我老陈什么时候让你吃过亏？"

老邵没话了。老陈说得对——这些年市场里的人来来去去，只有老陈这个快递员每次送货都不迟到、不涨价、不找借口。头些年冬天老邵犯了腰病，是市场门口收发室的大爷帮他收快递。老陈知道之后，之后每一单都亲自送到仓库门口，从不让老邵多走一步。

"行。"老邵说。

老陈从兜里掏出手机，给老邵转了十四万——他手上的积蓄加上李长生给他用来做物资储备的灵石兑换的现金，全押上去了。

然后他拨通了第二个电话。城西的恒丰灵器制造厂。这家厂三个月前刚成立，专门生产民用灵器——灵能热水器、灵能灶、灵能照明灯。厂长姓刘，是个典型的温州生意人，以前开的是小家电厂，灵气复苏之后迅速转型做灵器。刘厂长最大的痛点是灵石供应不稳定——大供应商嫌他量小，小供应商的货源时有时无。

老陈需要的就是刘厂长。

"刘厂长，我有一批碎灵石，两百公斤。纯度上等。你要不要？"

电话那头刘厂长的呼吸明显变重了:"你在哪？"

"城东。两个小时内送到你仓库。按灵元基准价——我不加价。"

"不加价？"刘厂长的语气里满是不信。

"不加。但我有一个条件:以后你厂里的灵石，从我这儿进。"

电话那头沉默了大约五秒。然后刘厂长说:"你送货过来。我们面谈。"

老陈挂了电话，回头对老邵说:"装车。"

一个小时后，老陈骑着电动车，后面跟着老邵的小货车，抵达了城西恒丰灵器厂的收货区。刘厂长亲自下来验货。他拿起一块碎灵石，用一把便携式灵气检测仪照了一下，仪器的屏幕上跳出一个数字:纯度83%。

"可以。"刘厂长把检测仪合上，"按灵元基准价结算。这批货我给你八万。以后每个月的保底量是三百公斤，做得到吗？"

"做得到。"老陈说。实际上他手头根本没有三百公斤的稳定货源。但他知道怎么找——不是一件一件地找，而是搭建一个信息网络。老邵的侄子只是第一个供货点。城里还有十几个类似的人——地质勘探员、采石场老板、甚至搞废品回收的——这些人在灵脉解封之后无意中撞到了浅层灵矿，手里有货，但不知道卖给谁。他们需要一个像老陈这样的人。

刘厂长盯着老陈看了几秒。这个温州生意人在商场上见过的骗子比老陈这辈子送过的快递还多，但他在老陈脸上没看到骗子特有的那种过度热情。他看到的是一张老实人的脸——不太干净、不太精神、不太聪明，但够稳。

"成交。"刘厂长伸出手。

老陈握了上去。刘厂长的手掌肥厚柔软，老陈的手掌干燥粗糙。两只手握在一起的瞬间，老陈忽然想起了一件事——去年这个时候，他还在送快递。每天跑一百多单，月收入四千五。收发室的大爷是他的朋友，楼道里的猫也是他的朋友。他从来没有想过自己有一天会和一家工厂的厂长握手，谈几万块钱的生意。

不是没有想过——是没有这个资格。以前的世界里，一个快递员和一个工厂厂长之间的差距是一条不可能填平的深沟。但现在，灵气复苏来了，这条沟被填平了。

不是因为世界变公平了。是因为灵气带来了新的资源分配方式。而老陈——一个在这个城市里跑了一辈子最底层路的人——踩准了这种新分配的节奏。

回到城中村的时候，天已经黑了。老陈把电动车停好，拎着两袋子东西上了五楼。

出租屋里，李长生正在运转冥土诀。他盘腿坐在床上，闭着眼睛，掌心的冥纹微微发光。听到开门声，他睁开了眼。

"搞定了？"

老陈把袋子放在桌上。袋子里是几瓶啤酒和两盒炒饭。

"搞定了。今天赚了九千差价。外加恒丰灵器厂签了长期供货协议。以后每个月能从灵石倒卖里稳定赚三万块钱。"老陈坐下来，拧开啤酒，喝了一大口，然后把今天的事情从头到尾说了一遍。

李长生听完了，沉默了几秒，然后笑了。

"你这快递员，当得比商人还商人。"

"不一样。"老陈摇头，"商人是拿别人的钱做生意。我是拿你的钱。长生，这九千块利润，我一分不要。全入团队账。"

"为什么？"

"因为这个货源的第一个环节——"老陈用啤酒瓶指了指李长生的手，"是你从大漠拿回来的灵石。没有那两块灵石做本金，我一分钱都拿不出来。你不是给我钱——是给了我一个起点。"

李长生看着他。老陈的脸上被电动车头盔压出了一道印子，左眼下方有一块干了的泥点子，制服上蹭了一片黄色的不明污渍。他看起来还是那个在路上跑来跑去的快递员。但他说话的方式已经变了——不是那种得意忘形的变，是那种找到了自己位置的踏实。

"钱你自己留一半。"李长生说，"剩下的入团队账。"

"一半太多了——"

"不多。"李长生站起来，拿起一罐啤酒，"接下来我们要准备去海底。需要的东西很多——灵压防护服、水下灵器、应急丹药。这些都需要钱。你赚的钱就是团队的物资保障。你一个人赚，大家一起用。这是一支队伍。"

老陈没再推辞。他举起啤酒罐，和李长生的碰了一下。

窗外，城市的灯光依旧在亮着。远方的灵石交易所大屏还在跳动红色和绿色的数字。在这个被灵气改变的时代里，一个新的经济体系正在以谁也无法预料的速度生长。而在城中村一间十二平米的出租屋里，一个快递员用两瓶啤酒和一张嘴，为这支草根队伍谈下了第一笔稳定的资金来源。

（第102章完）

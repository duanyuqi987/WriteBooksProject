# 第四十二章 老同学聚会

春节回青河那天，县城下了小雨。

不是雪。

我站在汽车站门口，看见出租车排成一列，雨水把挡风玻璃洗得发白。司机师傅探出头问去哪，我说县一中附近，他立刻把后备箱打开。

“回来过年啊？”

“嗯。”

“在外面上班？”

“楚州。”

“那也不远。”

是啊，也不远。

从楚州到青河坐大巴三个小时，比当年去南方师范短得多。可我后来才明白，距离不是车票上的数字。有的人隔三小时还能像隔一生，有的人隔半个中国也能好好活着。

出租车经过老车站外的环岛，司机指着路边说：“这片要拆了，明年回来你就认不出来。”

我看着窗外。

很多地方我已经认不出来了。原来卖磁带的小店变成了手机维修，老电影院门口贴着出租广告，县一中附近多了两家奶茶店。车开过翠湖路口时，我没有回头。只是手放在膝盖上，指尖碰到大巴票根的边角。

回家后，我妈把我的行李箱拖进房间，问我冷不冷，饿不饿，工作累不累。父亲坐在沙发上看新闻，听见我回来，只说：“回来了。”

我说：“回来了。”

家里的热汤在锅里冒气，桌上有酱牛肉、炸带鱼和一盘拍黄瓜。母亲说我瘦了，父亲说年轻人胖了才麻烦。我一边吃饭，一边听他们说邻居家的事，谁家孩子考研，谁家买了车，谁家老人住院。

这些话没有情节。

但很像生活。

吃完饭，我回房间换衣服。衣柜里还挂着一件高中校服，袖口发黄，拉链有点卡。我把它拿出来看了一眼，又放回去。

母亲在外面问：“晚上同学聚会，穿精神点。”

我说：“大家都老同学了。”

她说：“老同学更要穿精神点，人家看的是你这些年过得好不好。”

我笑：“衣服还能看出这个？”

她走到门口，帮我把衬衫领子拽平：“能看出你妈有没有管你。”

我没再反驳。

镜子里的我比大学时瘦一点，眼神也疲一点。可我看了几秒，觉得还行。至少不像那个坐在网吧门口、头发油得能炒菜的人了。

老同学聚会定在青河饭店三楼。

我到的时候，门口已经站了几个人。大家先互相看脸，再看肚子，再看发际线，最后才试探着喊名字。

“林予怀？”

“张磊？”

“哎哟，你怎么瘦了？”

“你倒是胖得挺诚实。”

笑声把陌生冲散了一点。

青河饭店的楼梯铺着红地毯，边角磨得发白。三楼包厢里摆了两张大圆桌，墙上挂着山水画，空调热得让人脱外套。班长站在门口收份子钱一样收聚餐费，嘴里喊：“扫码，别装没看见。”

我扫码时，他看着我说：“你现在在哪？”

“楚州。”

“听说你写书？”

“改练习册。”

“那不也算文化人。”

我说：“算文化民工。”

赵一鸣来得最晚。他穿着黑色羽绒服，手里拎着两瓶酒，刚进门就嚷嚷：“谁说我秃了？站出来，我看看谁头发多。”

大家又笑。

我看着他，心里踏实了些。

他把酒往桌上一放，坐到我旁边，低声说：“她今天不来。”

我拿筷子的手停了一下。

“谁？”

“你少装。”

我夹了一粒花生米，没夹起来。

“我没问。”

“我知道你没问，所以我替你说。叶蓁说她家里有事，晚上不来。”

“哦。”

赵一鸣看了我一眼：“就哦？”

“不然呢？我站起来朗诵一首《再别青河》？”

“你要真朗诵，我第一个报警。”

我笑了。

酒过三巡，大家的话多了。有人说起邱老师，说他还在县一中，嗓门比以前还大。有人说起当年的晚自习，说谁在后排偷吃泡面被抓。有人提到元旦晚会，几个女生当场唱了两句旧歌，调跑得很远，但没人介意。

少年时代变成了谈资。

这一点很残忍，也很公平。

那些我以为不能被碰的事，落到别人嘴里，也只是“你还记得吗”“那时候真傻”“笑死我了”。

有人拿出毕业照，手机屏幕在桌上转了一圈。大家一边看一边骂当年的发型。轮到我时，我看见照片里那个站在边上的自己。校服拉链没拉好，嘴角抿着，眼神不知道往哪放。

赵一鸣在后排比剪刀手，笑得像刚偷了学校广播站。

沈安晴站在第二排。

屏幕只停了两秒，就被下一个人拿走。

我没有伸手抢回来。

班长还带了当年的通讯录复印件。

上面有每个人的家庭电话、QQ号和一句志愿。我的那一栏写着：想考中文系。沈安晴那一栏写着：想去南方看海。赵一鸣那一栏最离谱，写的是：先活到毕业。

大家围着通讯录笑。

有人说：“赵一鸣，你目标达成得很彻底。”

赵一鸣举杯：“感谢大家见证本人持续存活。”

我看着沈安晴那一栏。

想去南方看海。

她确实去了。后来又回来了。很多愿望不是一条直线，它会绕出去，再绕回来。可只要那段路是真的，就不算白走。

有人突然问：“林予怀，你当年是不是喜欢过谁啊？”

桌子上安静了一秒。

赵一鸣立刻把杯子放下：“谁上学没喜欢过人？你没喜欢过？那你青春质量不行。”

大家笑起来。

那人又说：“我记得你以前老往第二排看。”

我的耳朵热了一下。

这种热很久没来过，像旧伤口在天气变化时提醒自己还存在。

我端起茶杯：“看黑板。”

“黑板在前面，又不在第二排。”

“我散光。”

“你那时候戴眼镜了吗？”

“心里戴了。”

一桌人笑得更厉害。赵一鸣拍我肩膀：“行啊，现在会胡扯了。”

我也笑。

这一次，没人知道我笑里省掉了多少东西。

聚会中途，班长在群里发合照。有人问沈安晴怎么没来，叶蓁回了一句：她家里有点事，改天再约。

我看见那行字，又看见群头像里她的名字亮了一下。

她没有说话。

饭后大家去楼下拍照。青河饭店门口的灯箱坏了半边，光落在人脸上不均匀。有人喊“站近点”，有人说“别挤我”，有人把孩子抱在前面。

我站在第二排边上。

赵一鸣站在我旁边，胳膊搭过来。

“你现在挺好。”他说。

“哪好？”

“能开玩笑。”

“以前也能。”

“以前你开完玩笑，眼睛还在找人。”

我没接话。

快门响了好几声。

拍完后，大家散开。有人赶着回家带孩子，有人还要去下一场，有人站在路边打车。

雨还在下。县城的夜晚湿得发亮，路边小店的招牌倒在水坑里，被车轮碾碎又合上。

赵一鸣撑开伞，问我：“走走？”

“去哪？”

“县一中门口。”

我看着他。

“大过年的，看学校？”

“你不是最爱怀旧吗？”

“别污蔑我，我现在很现实。”

他把伞往我这边偏了一点：“现实的人也要散步。”

我们沿着老街往县一中走。路过一家文具店，橱窗里摆着新的笔记本，封面上写着“梦想不会辜负努力”。

我停了一下。

赵一鸣顺着我的视线看过去：“买一本？”

“不了。”

“怕写？”

“怕自己写得太丢人。”

“你以前写得也丢人。”

“谢谢你，多年如一日地稳定。”

县一中门口换了新牌子。旧铁门拆了，保安亭也变成了玻璃房。我们站在马路对面，看着校门里亮着的路灯。

我想起“少年不识愁滋味”。

那时候我以为这句词写得太轻。现在才知道，少年不是不识愁，是识得太少，所以把一点愁当成全世界。

赵一鸣问：“还想进去吗？”

我摇头。

“不进了。”

“真不进？”

“嗯。让它在里面吧。”

他没再劝。

我们站了一会儿。雨落在伞面上，声音很密。校门口有几个值班老师出来换班，脚步匆匆，没有人看我们。

我忽然觉得这样挺好。

赵一鸣把伞往回收了点：“走吧。”

我点头。我们转身往回走，校门里的路灯还亮着，雨水顺着新牌子的边往下滴。

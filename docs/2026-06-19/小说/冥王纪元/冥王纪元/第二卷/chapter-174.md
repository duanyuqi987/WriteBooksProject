# 第174章 藏传修仙体系与冥术的碰撞

那曲往西第三天，越野房车停在了冈仁波齐峰脚下的一座藏传密宗寺庙前。

这座寺庙不大——占地大约和内地一座中等规模的学校相当。主殿面对圣山，白墙红檐，金顶在高原的阳光下耀眼得让人不由自主地眯起眼。寺庙外围是一圈转经筒，铜皮裹着经文，被信徒们的手磨得锃亮。风从雪山上吹下来，带动经幡猎猎作响——五色经幡在蓝得发黑的天空下翻飞，每一片布面上都印着密密麻麻的经文。

寺庙的名牌写的是藏文。老陈看不懂——但他车上带的那台有离线翻译功能的手机识别出了几个关键字。寺名翻译过来大致是:"雪山智慧海寺"。

"到了。"李长生下了车。他的脚踩在海拔四千五百米的冻土上，掌心的冥纹在发力——不是他主动驱动的，是自动反应。从翻过唐古拉山口开始，冥纹就一直在微弱地脉动。越靠近冈仁波齐，脉动的频率越慢、强度越大。

"碎片就在附近。很近。"残魂的声音里带着一种不常见的情绪——不是兴奋或贪婪，而是敬畏。"我能感觉到——那个人在这里。"

寺庙的门开了。走出来的是一个年轻的喇嘛，大约二十五六岁，身穿深红色僧袍，露出右臂。他的皮肤被高原的紫外线晒成了古铜色，但眼神非常清澈——不是涉世未深的清澈，而是被某种修行洗涤过之后的清澈。他双手合十，微微鞠躬。

"你们是来找仁波切的。"他不是问句，是陈述句。

"你怎么知道？"陈霜问。

"仁波切三天前对我说——会有四个人从东方来。其中一个人手上带着黑色纹路。"年轻喇嘛看向李长生。目光在李长生右手掌心上停了一秒——不是因为好奇，而是因为确认。确认他看到了仁波切描述的那个人。然后他再次合十，"请跟我来。"

穿过寺庙的前院、正殿、后殿，最后来到后山一座石砌的小院落。院落靠着冈仁波齐的北坡，院墙是用青灰色的石块垒起来的，没有用任何水泥——全靠石块之间的相互咬合。院墙上晒着藏药——红景天、冬虫夏草、藏红花，还有几种李长生叫不出名字的高原药草。空气里飘着一股浓厚的草药香，混合着酥油灯燃烧的微焦气味。

年轻喇嘛推开院门。院子里坐着四个人——都是身穿红色僧袍的喇嘛，围坐在一个铜制的火炉旁。火炉里烧的不是木柴，是牦牛粪——高原上唯一的燃料。火苗不大，但热气很足。

四个人同时抬头。四个人的眼神都和门口那个年轻喇嘛一样——清澈、宁静、带着被某种体系洗练过的光泽。

最年老的那位喇嘛开口了。他的藏语说得很慢——不是因为年龄大了，是为了让来客能听懂每一个字。年轻喇嘛在旁边做翻译，但李长生发现他不需要翻译——藏语的一个一个音节灌进耳朵，掌心的冥纹居然能对应出大致的意思。不是翻译——是共鸣。这个老喇嘛体内有某种和他同频的东西。

"我在这里等了你很久。"老喇嘛说。

"你知道我要来？"

"不是知道——是感受到。"老喇嘛指了指自己的胸口，"你手上的东西——它每次靠近我，它就会在我心口发热。它在这里——"他从怀里取出一个小布囊。布囊是手工缝制的，用的是红色的藏红布，上面绣着一种李长生没见过的图案——不是符文，不是符箓，是一种介于文字和图画之间的形体。像一条蛇，又像一条河，画得极简，只有寥寥几笔，但看起来有一种说不出的凝重。

"这是第六块冥王碎片。"老喇嘛说，"它在这里——跟了我很久。"

------------------------------------

密宗的修行体系与中原修仙体系完全不同。

这是李长生在寺庙里待了半天之后得出的结论。中原体系——不管哪个宗门——修的都是同一个核心:灵气。吸灵气、炼化灵气、释放灵气。只是不同的宗门侧重不同的灵根类型和释放方式。剑修将灵气附在剑上释出，符修将灵气封入符纸释出，阵修用阵法结构放大灵气的释放效率。但核心不变——灵气是原料，修士是加工者。

密宗不是。密宗修的核心不是"灵"，而是"识"。

"我们叫它——'恰'。"那位老喇嘛——他叫洛桑嘉措——在火炉旁慢慢地给李长生讲，"中原修士看灵气——看成一种能量。我们看灵气——看成一种需要被正确引导的意识。灵气自己有方向。修士的工作不是控制它往你指定的方向走，而是顺着它本来的方向走，让它自己到达正确的位置。"

"那咒语和手印的作用是什么？"

"不求。只导。"洛桑从火炉里取出了一根烧得半红的铁钎——不是要展示什么，就是烤火的习惯动作。"咒语是声音的振动——特定的发音可以引导灵气波动。手印是身体的姿态——特定的手指姿势可以引导灵气的流向。但最重要的——是'观想'。"

他指了一下自己的额头正中央。

"观想——就是在脑子里画一幅画。你要让灵气在病人体内流动——你先要在自己脑海里形成那道流动的画面。画面必须极其清晰、极其稳定、持续不断。一旦画面碎了——灵气就乱了。所以密宗修行者的基本功不是运气，是'观'。先观一百零八种坛城——每一种都闭上眼睛能在脑海里呈现所有细节。只有观想的能力达到'现量'——就是观出来的画面和真的一样清晰——才有资格开始学习引导灵气。"

"那需要多少年？"

"观想一百零八坛城——快的弟子三年，慢的弟子二十年。"洛桑微微一笑，"但一旦过了此关，密宗修行者的出手速度和精密度——在同级修士里是最快的。因为我们不需要像中原修士那样掐诀、运气、结印。我们是'想'——想在哪，灵气就到哪。"

李长生沉默了片刻。然后他做了一件事:他抬起右手，掌心冥纹亮起，在空气中画了一道轨迹。那道轨迹在空气中留下一道暗金色的残影，持续了大约三秒才消散。

洛桑的眼睛亮了。不是惊讶——是确认。确认某件事得到了印证。

"冥术。"他说的是一个词，不是一个解释。

"你知道冥术？"

"密宗经典里提到过——'中阴'。"洛桑的声音降了半度，"中阴——是指一个人死后和转世之间的那个中间状态。密宗有一个完整的修行体系叫'中阴教法'——教人如何在中阴状态中保持意识清明，选择正确的转世方向。而冥术的底层原理——我们在经典里读到过——和中阴教法的运作方式有微妙的呼应。两者都不是在'生'的层面运作，而是在'生与死的交界处'运作。"

他顿了一下。

"所以我们不是抵触冥术——是理解它。从我们自己教义的逻辑出发，理解它。"

李长生忽然想起龟相说过的话:不同的文明体系会用自己的逻辑去解释冥术。中原体系把冥术打成"邪道"，是因为冥术不在他们的五行阴九品框架内。而密宗的框架不一样——密宗的框架包含"中阴"，本身就包含了死亡和生命之间的过渡态。在这个框架里，冥术不是外来的异物——它只是"中阴之力"的一种表现形式。

"所以你们不会攻击我？"李长生问。

"攻击？"洛桑愣了一下，然后笑了。那种笑不是嘲笑——是一种老人看透世事之后的莞尔。"小伙子，密宗这一千多年来从来没有主动攻击过任何人。不是因为我们没有战斗能力——是因为我们修行的根本目的不是战胜别人。是中阴教法、坛城观想、明光证道。我们的敌人不在外面——在自己心里。"

他说这话的时候，火炉里的火焰刚好跳了一跳。光影在石墙上晃动，映出那些挂在墙上的唐卡——佛陀、莲师、各种密宗本尊。每一幅唐卡都画得极其精细，色彩的层次多得数不清。但最让李长生注意的不是技法——是每一幅唐卡中心都画着一个圆形的坛城。坛城的内圈、中圈、外圈各有着不同的图案，但整体是一个圆——圆的中心是空的。

"那个空的是什么？"

"中心。"洛桑说，"看。密宗的坛城中心永远是空的。不是没有东西——是'无'。'无'是最大的有。就像你的冥纹——它看着是黑色的、空的——但它是你最大的力量。"

李长生低头看着掌心的冥纹。五道暗金色的纹路在手背上交叉缠绕——确实，在坛城里看来，每一道纹路都是"空的"——它们不是加法，是减法。不是往手掌上"画了什么"，而是从手掌中"挖掉了一些东西"。

他看着墙上那幅坛城唐卡的空白中心。

"所以你们用'空'来理解'冥'？"

"不。"洛桑摇头，"我们用'冥'来理解'空'。你们的冥术——是条捷径。"

火炉里的牦牛粪烧得正旺。外面雪山的轮廓透过窗格看过去，被夕阳染成了金红。冈仁波齐的金字塔形峰顶在夕阳照映下像一座真正的道标——不指向某个地理位置，而是指向天地的深处。

(第174章完)

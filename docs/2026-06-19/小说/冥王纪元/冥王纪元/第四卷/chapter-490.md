# 第490章 祖坟前

祖坟在李家庄后山。不算远——从村里走出去，经过那道老土坎，再往上走两百米的坡，就能看到那两棵老柏树。柏树不知道长了多少年了，李长生爷爷的爷爷那辈人就已经站在树下烧过纸钱。

他往上走的时候，没有带任何人。陈霜在村口拦住了想跟上去的众人。她没说话，只是挡在通往山脚的道口上，摇头。小旺说"我陪他去"，陈霜还是摇头。她说:"让他一个人去。"她这句话说出来，没人再拦。

李长生一个人往上走。手里提着两样东西：一瓶老白干，一叠黄纸钱。老白干是在村口杂货铺买的——还是那个牌子，还是那个白瓶红盖。他小时候看他爹喝酒就认的这个味——那时候他不喜欢，觉得辛辣难闻。现在他觉得这个辛辣就是"父亲"的味道。黄纸钱是村里老婶子前一天晚上用土槌子一叠一叠地打出来的——她没有印灵纹钱——她印不动，她只会用土办法和老人的手劲。每一张都是她亲手打的。

祖坟到了。李家的祖坟不大——一共四座。曾爷爷和曾奶奶合葬一座，爷爷和奶奶合葬一座，爹和娘依着老规矩——爹在左，娘在右。坟上的土是几个月前村人帮着新铲平的——就是老婶子在通讯里说的"村里给你收拾好了"的那一次。四座坟前的石碑都擦得干干净净——也是村里人擦的。石碑上刻的字不花哨——名字、生年、卒年。爹碑上的卒年旁边还有一行小字——是李长生自己几年前用指甲一点点抠出来的，抠了三天才抠完。那行小字是：父李大山，一辈子种田，从没出过远门。

李长生在碑前站了好一会。他不知道该从谁开始叫起。然后他蹚地跪了下来。不是那种仪式化的躬身——是直接对着石碑双膝着地的。他的膝盖砸在碑前凉了不知道多少年的硬土地上，裤腿沾满草屑和干土。他的双手垂在身侧——宽厚的手掌，掌心现在没有纹路，冥王令早已融入微型宇宙。他的手在微微发颤。

"爷爷——奶奶。"他叫完第一声，喉咙就紧得像被一把土塞满了。但他没有哭——他把那股堵住的东西硬生生往下咽。继续。咽下去。再咽。然后又叫:"曾爷爷——曾奶奶。"

最后他的目光落在爹和娘的墓碑上。

"爹。娘。"

他撑不住了。他不是以守护者的身份站在这里——他是以一个儿子的身份跪在爹娘的坟前。他的一切力量——体内那个还在旋转膨胀的微型宇宙、过去数十年在战场上凝结的一切经验、连至尊都慎重对待的威慑力——在这一刻，全无用处。一个人跪在父母坟前的时候，他拥有的一切力量都无法弥补那个已经空了的位置。

"爹。"他手里握着老白干的瓶盖，旋开，旋了三圈。他把瓶口放在碑前地上，像以前他爹活着时每次晚饭前那样——先把爹的酒倒一点在地上，然后自己喝。他倒了半瓶。不是洒——是细细地浇在坟前干裂的土地上。酒渗下去——土地迅速吸干。

"爹——儿子不孝。你活着时总说要看着我娶媳妇——我没让你看到。你走得太早了——早到我那时候还不知道什么叫失去。"

他停了一下。风吹过来——柏树的叶子在头顶轻轻地沙沙响。他深吸了一口气，继续说。

"后来我见过很多东西了，爹。我见过月亮上的战场。我见过木星上的风暴。我见过深空中比泰山还大的飞船。我见过至尊——那种修了几万年的人——他们对我客客气气地说话。你儿子现在——在别人眼里——'宇宙第一强者'。"

他自嘲地笑了一下。笑着笑着，眼眶就发酸了。

"宇宙第一强者……跪在你们坟前，连给娘摘朵花都不知道上哪摘。宇宙第一强者——有什么用？"

他对着娘的碑磕了一个头。额头砸在干土上——他没有用功力护住皮肤——粗糙的土粒在额头上留下了一道红印。

"娘。你还记得那年我不小心把家里半锅饭烧焦了吗？你一句都没骂我——你偷偷把你自己的那份省出来，搁在我碗里。你跟我说你早吃饱了。那天晚上我在后屋听见你去井边喝了半瓢水填肚子。娘——为了一口饭你饿着自己，而我这个当儿子的，现在连给你做口饭吃都做不了。"

他用手掌在那碑上慢慢地、很轻地摸了摸——就像他小时候娘摸他的脸一样轻。

"娘——儿子什么都做到了。别人不敢做的事，儿子做了。别人达不到的地步，儿子达到挺多的。可就是做不到回到从前——给你端一碗热饭。"

他终于没忍住。眼泪落在那块石碑上，落在那道他用指甲刻出来的小字旁。他没擦——由着泪水在石面上留下两道淡淡的湿痕。

风更大了。老柏树的叶子跟着风声沙沙作响。后山的天空很蓝——不是修士眼里能看到的那种有灵光流转的蓝，而是农民眼里最朴素的天蓝。那种蓝让他想起他小时候跟着爹下地，他累了躺在地埂上，看到的也是这种蓝。那时候他不懂什么叫灵气复苏，不懂什么叫冥王碎片，不懂什么叫全宇宙。那时候他只知道他家有四亩地，今年该下什么肥，爹的腰不好，不能多背。

李长生在坟前又坐了会儿。他把老白干最后半瓶自己一口喝干——辛辣呛得他咳了两声——然后把空瓶搁在爹的碑边上。黄纸钱被他一张一张地烧，火焰在碑前跳动着，纸灰被山风卷起来，往高处飘。

"爹，娘——儿子还没结婚。但有人了。她叫陈霜。人好——跟她待一起我踏实。过几天我带她来见你们。"

他说完这句话，又在碑前磕了三个头。然后站起来。膝盖上的土他没有拍——留在裤子上。那是父母坟前的土。

他站了一会，然后对着四座碑鞠了最后一次躬。

"儿走了。下次再来看你们。"

他转身往山下走。走出十几步之后听见身后又一阵风——老柏树的树枝大力地摇了两下，像在挥手。他没有回头。走出二十几步后，他还是回头了。看了一眼那四座坟——静静的。风停了。树不摇了。

他转头走下去。一步一步——走得很稳。

山路上他的背影，还是当年的那副中等体格——宽肩，耐劳。只是他把父母的期望和这片黄土地的一切——都扛在了肩上。永远扛着。

（第490章完）

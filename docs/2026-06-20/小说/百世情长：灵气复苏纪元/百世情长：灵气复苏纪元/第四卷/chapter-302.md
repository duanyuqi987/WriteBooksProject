# 第三百零二章 天魔初现

昆仑裂缝的消息传回修仙界的速度，比林牧预想的慢了整整两天。

不是通讯手段的问题。卫星电话的网络覆盖了全国所有灵脉节点。慢的是人。修仙界已经太平了三十年。三十年来灵气复苏带来的是修为的提升、资源的丰沛、宗门的复兴——没有战争。没有任何一个活着的人经历过修仙界之间的全面战争。老一辈的修士在灵气枯竭的时代把精力花在了"如何活下去"上。年轻一辈在灵气复苏的时代把精力花在了"如何变得更强"上。

没有人把精力花在"如何打仗"上。

所以当林牧的报告通过通讯网传到各大宗门的时候，大部分人的第一反应是不信。"域外天魔？那是上古神话里的东西。""空间裂缝？可能是灵脉暴动产生的幻觉。""林牧是谁？一个散修？散修的话能信？"

第三天上午，不信的人安静下来了。

昆仑山脚下的一座小镇——全镇两千三百口人，连同镇上的狗、猫、鸡、鸭——在一夜之间全部消失。没有尸体。没有血迹。没有打斗的痕迹。锅里的粥还在冒着热气。电视机还开着。一只狸花猫蹲在窗台上，保持着舔爪子的姿势。但它不动了。不是死了——是"空了"。物理意义上的空了：它的身体还是完好的，但它的眼睛不再反射任何光线。那种黑——和林牧在符石上看到的黑一模一样。

第一个到达现场的是昆仑派的长老赵明远。他在镇上走了不到一刻钟，就吐了。一个金丹修士，修炼了八十年，吐了。不是被恶心的——是被灵识层面的恐惧压垮的。整个小镇的灵气被抽干了。不是自然消散那种"干"——是被什么东西主动吸走的那种"干"。像一个被喝空的椰子壳：外壳完好，里面什么都不剩。

赵明远在镇子中央的井边蹲下来。井水还在。他打了一桶上来——水的颜色是暗紫色的。和昆仑裂缝里透出的光一个颜色。他的灵识探入水面。水在他灵识触及的瞬间开始沸腾。然后他听到了声音。不是从耳朵听到的——是从灵识里直接灌进来的。一种低频的嗡鸣声，频率极低，低到人的耳膜无法响应，但在灵识层面震耳欲聋。嗡鸣声里夹杂着某种碎裂的、断续的声响——像是有什么东西在很远很远的地方敲击着某种巨大的金属物体。

赵明远把水桶扔回井里。水桶落在井底的撞击声传上来，经过井壁的回响，听起来像是人在哭。

他拿出卫星电话。拨通紧急频道。声音发抖，但表述清楚："昆仑山脚清泉镇，两千三百口人全部失联。灵识探测结果为——灵体被抽离。重复：灵体被抽离。昆仑裂缝的威胁等级建议从'观察'直接提升至'最高警戒'。"

这一次，通讯网那头没有再沉默。

三天之内，七大修仙宗门的掌门人在昆仑山脚下的一个临时营地里开了一场紧急会议。林牧被要求参加——他是第一目击者。这是他三十年来第一次以"修仙者"的身份出现在公众视野中。之前的三十年他一直在隐修：不加入任何一个宗门，不在任何公开场合暴露修为，不参加任何修士之间的社交活动。他的存在在修仙界是一个若有若无的传说——有人说他是一个金丹期的散修，有人说他其实已经元婴了，有人说他根本不是人，是某个上古宗门留下的"守墓人"。

当林牧走进会议帐篷的时候，七位掌门人的目光同时落在他身上。

然后所有人都沉默了。因为他们看不透他的修为。七大掌门人中修为最高的是蜀山剑宗的掌门——元婴中期。他的灵识扫过林牧的丹田后，皱了一下眉头。他看到了元婴——但元婴周围包裹着一层他看不透的东西。一层不属于普通修仙功法的、更高等的气息。

蜀山掌门没有问。他知道有些事情不该在公共场合问。

会议开了四个小时。讨论的议题依次是：裂缝的性质、天魔的数量、防御策略、人员调配。每一道议题都因为信息不足而卡壳。没有人知道裂缝有多深。没有人知道天魔的数量。没有人知道敌方修为的上限。没有人知道对方的目标是什么。唯一能确定的事情是：对方来者不善。

林牧在会议的后半段开口了。声音不大，但所有人都安静下来听。

"它不是来占领领土的。"他说。"它是来报复的。"

蜀山掌门看着他。"你怎么知道？"

"暗紫色的灵光。黑霜。灵体抽离。"林牧用指尖在会议桌上依次点出三个位置。"这三样东西叫'噬灵三征'。不是一般的域外生物能用的手段。能用出这三样东西的——是上界的堕仙。"

帐篷里的空气凝固了大概三秒。

"上界。"茅山掌门重复了一遍这个词。"你说的是——传说中的上界？"

"不传说。"林牧说。"我去过。"

他没有解释。没有人追问。因为林牧说这三个字的时候，帐篷里的灵压变了。不是他主动释放的威压——是他情绪波动时无意识泄露出来的灵压。那种灵压的质地和在场所有人的都不一样。厚重。像沉淀了几千年的水。

蜀山掌门第一个反应过来。他站起来，对林牧拱了拱手。不是平辈的礼——是晚辈对前辈的礼。"请前辈赐教。"

林牧看了他一眼。这个蜀山派掌门人，修为元婴中期，在当今修仙界是站在最顶端的人之一。他对一个"散修"拱手的动作，如果传出去会引起轩然大波。但他拱了。因为他感觉到了差距。

"天魔的统帅——"林牧顿了一下。"和我有一些私人恩怨。非常旧的恩怨。具体来说——大概是我还在上界时候的事。"

又是沉默。然后蜀山掌门问了在场的每个人想问但不敢问的问题："前辈，你到底是什么人？"

林牧没有回答。他只是把左手伸到桌上，摊开手心。手心里有一道剑痕——不是新伤，是旧痕。伤痕从掌心横穿到手腕，是握剑时被人一剑切过来的痕迹。"这道伤就是他留下的。名字我不提了——上界的名字，在这个世界说出来，会被他感知到。"

他收回手。"所以这场战争，从某种意义上说，是我引来的。"

帐篷里的人面面相觑。但没有人敢出声。因为他们忽然意识到了一件事：坐在他们面前的这个人，修为可能远超他们的认知上限。元婴？也许不止。化神？也许。炼虚？不敢想。但不管是什么——这个人曾经站在他们连想象都够不到的高度上。

"我不需要你们相信我。"林牧说。"我只需要你们防御。裂缝不止昆仑这一处。我用灵识网扫过了——全国至少还有另外四处裂缝。位置在：长白山、秦岭、青藏高原东缘、南海。裂缝的规模比昆仑小，但都在扩张。扩张速度——每天约一寸。"

"一寸？那还来得及——"

"是在加速的。"林牧打断他。"今天一寸。明天可能是一尺。后天可能是一丈。"

他站起来，把椅子推回原位。动作和他在写字楼上班时离开工位一模一样——椅子推到桌下，不挡别人的路。

"我去找我的人。"他说。"防御的事，你们商量。"

他走出帐篷。昆仑山的夜风灌进来，帐篷里的烛火晃了几下。

七位掌门看着他的背影消失在夜色里。茅山掌门率先打破了沉默："他说的'他的人'——是谁？"

没有人回答。因为没有人知道答案。但蜀山掌门直觉到了一件事：那个人的目标，根本不是天魔统帅。天魔统帅只是一个必须被清除的障碍。那个从写字楼里走出来的散修，花了三十年等待的，是另一个更重要的人。

夜风从昆仑山的冰峰上刮下来，穿过临时营地，往东南方向去了。

在那个方向几千里外的南方小镇，一个叫苏晚的女人正在厨房里热一碗绿豆汤。她不知道昆仑山发生了什么。她不知道一个男人花了三十年找她找到了。她更不知道——那个男人此刻正御着一柄旧剑，以金丹修士极限速度的近乎两倍，往她所在的方向赶来。

绿豆汤在锅里咕嘟咕嘟地冒着泡。她往汤里加了一勺糖。舀起一小勺尝了尝。甜味刚好。

窗外的月亮很亮。但东南方的天际线上，有一小片天比别处暗一些。暗得不像是云。像是什么东西在极高的天空中缓慢地洇开。

她没注意。

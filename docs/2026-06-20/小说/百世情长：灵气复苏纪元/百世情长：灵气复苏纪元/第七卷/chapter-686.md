# 第六百八十六章 下界最后的准备

飞升倒计时六个月。林牧和苏晚的清单上大部分项目已经划掉。剩下的只有几件无法加快的事——需要等到桂花园新一届预备讲师团完全独立运行才能交棒，灵网三期全网调度系统还在最后测试阶段，上界过渡区的学院地基需要秦无夜那边的施工团队再三个月才能完工。

他们不急。不是因为懒——是因为知道"急只会导致交接出错"。以前苏晚可能会抱怨进度太慢，但现在不会了。她学会了"等对的人在对的时间自己走上去"——不是放手不管，而是相信。她的急躁被理解取代了——不是因为急躁消失了，是因为她理解了每个进程都需要它自己的时间。

林牧也没有像以前那样用沉默去压抑自己的担忧。现在他会说："我担心灵网调度系统在最后测试中会出现之前没考虑过的跨区域共振。但测试组有叶小雨——她每次检查三遍——会发现的。"他学会了把担忧分解成具体的、可被他人解决的问题——然后交给对的人。不是一个人扛——是信任。

石头已经十七岁，现在是桂花园灶台学总负责人。他的头衔很长——但他在灶台旁边工作的时间比任何会议室都多。他的"互不吓唬"的鹅卵石已经被复制成了上千块——每一块都由学生自己手制、手工刻字，散布在九州每一所分院的灶台旁边。灵网三期测试的最后阶段——在最关键的信号同步环节，出现了一次极微小的共振偏移。叶小雨发现了它——她用她独有的"检查第三遍"方法，仔细观察出了那道振幅偏移中一个过去大家都没注意到的角落——是华山大师兄六年前纠正过的同一种小数点误差再次出现。她通知了华山大师兄——两人花了整夜修正了那处误差。林牧得知后在报告下方批注了很简单的话："恐惧让你检查三遍——恐惧救了灵网。叶小雨——你的恐惧已经是整个系统的最终校验。——林牧。"

（第六百八十六章 完）

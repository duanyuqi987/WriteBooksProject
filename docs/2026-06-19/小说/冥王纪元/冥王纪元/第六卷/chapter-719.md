# 第719章 最强的修士

和平监察团的第一批成员选拔，是帝国高层内部迄今为止最激烈也最慎重的人事筛选过程。

选拔标准在陈霜的坚持下被设定得极其严格：至少帝级以上的修为、有过至少一次在压力下拒绝滥用力量的记录、且必须通过由令蕊主持的法典院"品德极限测试"——一个标准化的、能检测人在极端压力之下是否会妥协作恶的可重复实验体系。最后一条标准直接把帝国高端修士池中超过六成的人淘汰了。

最终选出来的第一批核心成员只有十八人。

其中有三个名字值得一提。

第一个——夏侯明。新纪元修仙界公认的剑道第一人。神级巅峰，距离冥级只有一线之隔。他出身古道遗民，在旧纪元时期拒绝过所有宗门的拉拢——原因不是他傲，是所有的宗门都在他加入的条件上附加了"必须为本门秘密效力"的条款，他一一拒绝。他宁可在野修炼也不进入被利益捆绑的体系。陈霜看中他的正是这一点——这个人不在乎短期利益。

第二个——洛清溪。女性神级修士，专精防御和结界阵法。在旧纪元最后的大战中，她独自撑起了整整四个人类殖民星球的保护结界，连续三百天不眠不休维持结界运转，直到援军赶到。她的精神状态在那三百天中经受了严酷的考验——孤立无援、补给断绝、每天都以为明天就是死期。但她没有崩溃，也没有撤退。监察团需要的就是这种能在绝境中自我支撑的意志力。

第三个——图琉。非人类种族的帝级巅峰修士。来自一个名为"鳞语族"的古老智慧文明——卵生、冷血、长达千年的寿命。他拥有一种极其罕见的能力：他能读取任何维度的信息流中存在的不稳定模式。简单说——他能"闻到"即将爆发冲突的地方，就像鲨鱼能嗅到远处的血腥一样。这种能力对监察团来说是无价之宝——他能在内战萌芽层面就捕捉到征兆，比其他修士更早、更准。

十八位成员在冥都的监察团总部——一座朴实到近乎简陋的建筑里——进行了第一次全体会议。

会议上，陈霜作为监察团章程的实际起草者，宣读了十八个成员各自的任务框架。没有指挥官，没有副团长，没有等级——第一代监察团是扁平结构。所有十八人拥有完全平等的表决权，所有调查以投票的方式决定启动与否。会议每千年选举一次轮值协调员——协调员负责对外沟通和日常调度，但没有对任何调查事项的决定权。

夏侯明在第一次会议结束后，走到陈霜面前，问了一个尖锐的问题："如果我们调查到皇帝本人有破坏和平的倾向，我们有权限调查他吗？"

所有十八双眼睛转向陈霜。

陈霜的声音很平静："你们调查任何人都不需要我的批准。但我可以提前告诉你——如果有一天你查到李长生有问题，你来找我。不是我替他挡——是我来替他认。"

这句话的力度超出了夏侯明的预期。他点了头，不再问了。

（第719章完）

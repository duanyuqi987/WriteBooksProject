# 第四百九十八章 万年前后的重和

松鹤仙人离开后的某个傍晚，林牧一个人在迎仙台的登记处翻阅旧档案。他之前申请中阶仙时调用了自己的灵核前世记录——那份禁档虽然已经翻过，但他在整理松鹤老人遗留的档案架时发现了一份和自己极其相关的旧记录。记录的本子封面上写着年月——是万年前的。在万年前青云宗被灭宗令撤回之后，有个不知名的仙官以极小的笔迹在档案末页加了一条备注:"青云宗第一天才林牧——脱籍。道侣苏晴晚——仙格碎裂，魂入轮回通道无追溯。此二人属仙庭中为数不多的未受保护飞仙个案——万年后若有人提起此案——见因果天平封卷七十三号。"

他把这份档案用极轻的动作放回架子上。然后走到仙居后院，在正在浇水苏晚的身边坐下。他把档案的内容告诉了她，他读到"苏晴晚"三个字的时候，功德绳另一端她的感应让他的嗓子忽然缩了一下——这是万年来他第一次在正式仙界档案中看到她的第一世名字——不是苏晚。是苏晴晚。档案里把他和她最初的名字写在一起——即使一万年前的青云宗已散，一份尘封在档案架最角落的旧案笔记，仍把他们当时的仙号和林牧的道侣关系记得清清楚楚。苏晚把洒水壶放在地上，把手放在他肩膀上。

"晴晚是我。晚也是我。一万年前的名字和今天的名字——都是你在找的那个人。以后你不用再去暗河底找那封她没有寄出的信了——我来给你写新的。"

那天晚上苏晚用那把叫"晚风"的古琴又弹了一次当时在杏树下弹过的曲子。这次弹琴时她左手戴着功德绳金线在微光中轻轻地搏动着——随着琴声的旋律，那金线在暗夜中划出极小极小极柔的弧线。林牧闭着眼睛听着——他听的不是旋律。他听的是时隔万年，他的道侣在他面前为他补上了那封残信下半段的全部空缺。

（第四百九十八章 完）

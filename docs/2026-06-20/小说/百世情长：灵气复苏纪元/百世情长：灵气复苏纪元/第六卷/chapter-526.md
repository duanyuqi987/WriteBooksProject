# 第五百二十六章 合道中期的门槛

双心诀传播开来之后两人的修为迎来了又一次跃升。不是因为闭关苦修——是因为双心诀在传播过程中，每一对使用这套功法的道侣都在以苏晚和林牧为"源节点"进行功德反馈。仙界的功德系统有一个极其特殊但极少被触发的机制:当某对道侣创造的功法被足够多的其他道侣修习并从中受益时，创造功法的源道侣会收到功德的自动分成。这不是人为设计的酬劳——是因果律的自然回馈。当足够多的道侣通过双心诀减轻了他们过去在修炼中因为不同步而遭受的痛苦时——那些被减轻的痛在因果层面等价于"源道侣做了功德"。功德的累积以极自然极安稳的方式推动两人的灵核同时进入了合道中期。

这次晋升同样没有电闪雷鸣没有大场面。只是某天早晨苏晚醒来时发现功德绳的金线比以往多了一层极淡极浅的银边——不是从外面涂上去的，是从金线内部自己透出来的。她推了推旁边还在闭目养神的林牧——他睁开眼睛时他功德绳上也出现了同样的银边。银边是极细极细的——细到如果不用灵力放大几乎看不见。但在通灵视角下这条银边非常清晰——它是合道中期的灵核自带的频率外溢，以极其柔和的方式在金线外围加了一道"双核护层"。两人对视半秒——然后同时意识到他们已经在昨晚睡着的时候自动跳了一个小境界。

合道中期——睡过来的。这是仙界公认的最正常的晋升方式。当功法和功德都累积到完全够的时候，灵核会在无意识状态下自己完成突破——不需要挣扎，不需要强撑，不需要用意志力去压榨最后一丝潜力。因为在正确的路径上——突破不是挣来的，是自然熟的。就像果子挂久了自然会从青色变成红色——不需要去掰它。他们选择了一条正确的路:不是靠力战、不是靠夺宝、不是靠吞服天材地宝。而是靠帮助了很多人。那些受益的道侣——寻青仙子和她的道侣是第一对，然后是南离城的几对新绑定红绳的年轻修士，然后是仙缘司介绍来的几对已经在修炼中产生不同步困扰多年的老道侣。每一对从中获益的人都在功德层面给源道侣输送了一道极细微但极其真实的功德回馈。这些回馈累积到足够量之后——灵核的修为自然就到了合道中期。

这天松鹤仙人终于回来了。他牵着一头极老极慢的老驴——驴耳朵上挂了一朵不知道从哪里蹭来的野花，驴背上驮着一大包新茶叶和几套新茶具，还有从南离城市集买回来的各种零碎。他走到迎仙台门口时脚步忽然慢了一下——不是累了，是他用灵力感知到了这间小院里发生的变化。花盆旁边多了新的一盆冰晶草苗——小苗只有三片叶子，每片叶子只有指甲盖大小但极嫩极绿。厨房里多了一套擀面杖——是长条的檀木圆柱，一端比另一端稍微粗一点，专门用来擀面的。书架上多了一个旧茶盒——茶盒盖子上"碧螺春"被改成了"双心诀"，旁边还夹着一片金边银杏叶。最重要的是——功德绳的金线上多了那道合道中期的银边。

松鹤把驴拴在院门口的银杏树上。他把茶叶放在石桌上——然后看到了那本双心诀的副本。他用那双老花眼从头到尾极其缓慢地看了一遍——看到序言那行"他愿意等你的频率"时，他的手在纸面上停了一下。然后他把老茶叶用滚水泡了两杯——一杯放在石桌上留给苏晚，另一杯他自己端到老驴边上。老驴正在吃他随手放在石槽里的青草——边嚼边甩耳朵。松鹤靠着驴背站着喝茶——然后他开始哼一首极老极老的仙调子。调子极简单——只有几句来回重复，像是小孩在院门口玩跳绳时随口编的顺口溜。但调子的词讲的是很久很久以前——有个人在路边等了很多很多年，等来了另一个人。

苏晚从后院走过来——她手里拿着一把刚剪下来的冰晶草枯叶。看到松鹤靠在老驴旁边的样子，她把枯叶放在石凳上——走了过去。松鹤看到她来——把茶壶放在石凳上让她自己倒。然后他用他那双老花眼极其认真地看着她。看了很久。然后他用极平极淡的语气说了一句话。

"今天天气好。银杏叶也该黄了。那功法挺好的——序言那句是你写的吧？"

苏晚点了点头。松鹤喝了一口茶——他的嘴唇在茶杯边缘停了一下。然后他把杯放下，捋了捋胡子。那双老花眼里有一点极亮极亮的东西——不是泪光，是某种比泪光更干更老的"懂"。

"好。那句话写到老道我心里了。八千年的老婆婆们看了怕是都要掉泪——她们年轻的时候也都是追着丈夫的孩子。"他顿了顿——然后补了一句，"但她们的丈夫大多不知道应该等。你的丈夫知道。所以你是幸运的。他是更幸运的——因为他等了一万年，终于等到你知道了。"

苏晚把茶端起来喝了一口。松鹤泡的茶总是比她泡的更苦——因为松鹤泡茶时水烧得老，茶叶放得多，而且从来不洗茶。"苦——"苏晚皱了皱眉。"因为老道今天带的这批是明前老眉——苦才提神。"松鹤又喝了一口，"苦才能让你记得。功法写完以后就该喝杯苦茶——再喝青梅酒就觉得特别甜。"

苏晚放下茶杯。她想了想——然后把木盒里预留的那份双心诀副本玉简——额外复刻的那份——递给了松鹤。松鹤接过玉简，看了她一眼。

"这份不是给藏经阁的。"苏晚说，"是给你的。卷尾有一页附录——还没来得及放进正式版本里。"

松鹤把玉简翻到最后——用老花眼在放大镜下看到了那页附录。上面写的是一行极小的字:"致松鹤仙人——感谢你当年在炼丹炉旁守了我很久。这份功法最早的版本——是你在病床边说'他也很疼'时，我开始画的第一个草稿。"

松鹤把玉简合上。他把眼镜摘下来擦了擦。没有说话。然后他从老驴背上卸下来的那堆杂货里翻出了一罐新买的冰糖——放在苏晚手边。"青梅酒——多放冰糖。上次那罐太酸，把林牧酸得劈柴时多劈了两根。"

苏晚拿着冰糖罐子愣了一瞬——然后笑出了声。"你什么时候知道青梅酒不够甜的？""刚才——老道偷喝了你们厨房里那罐。确实太酸。这罐冰糖是南离城那家老字号铺子的——冰糖芯里还有桂花蜜。"

（第五百二十六章 完）

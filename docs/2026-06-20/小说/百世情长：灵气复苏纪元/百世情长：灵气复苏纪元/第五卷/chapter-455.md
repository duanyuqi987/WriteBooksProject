# 第四百五十五章 暗河深处

暗河的水是冰凉的，凉得不正常——不是高原融雪水那种凉，而是一种更老、更深层、从不被阳光加热过的冷。这种冷意穿透化神圆满的灵核防护罩，直接传递到皮肤上，把脚踝冻得生疼。

林牧在水里走了大概两个时辰。暗河的水深在膝盖到腰部之间浮动。河道不宽——最宽处大约一步就能跨过去，最窄的地方两人要侧着身子才能钻过。头顶的岩壁上偶尔有水滴下来——冰冷的水珠落在额头上，让人产生一种在时间本身滴落的错觉。

苏晚跟在他后面。她的手一直搭在他的后肩上——不是因为怕走散，是这条暗河中有龙脉残余的极微弱的龙气能量。她在林牧背后的九劫龙诀是两人间最强的龙气引导。她的灵核中带着龙族的印记——在东海龙墓里她和林牧一起得到了龙族残余意志的认可。龙族能量和龙脉是同一源的，她在这洞里能感应到他感应不到的一些东西——比如头顶岩层中那些不太正常的空洞。

"停。"苏晚忽然收紧了搭在他肩上的手。

林牧停下。两人的灵能灯同时点亮——淡金色的光照亮了前方大约三丈的距离。在他们面前，暗河的河床忽然断崖式地降了下去——不是缓坡，是直落。河水在断崖处形成了一面极小的瀑布，水流砸在下方大概七八丈深的一片水域里。水声很大。断崖下面是一片直径大约二十丈的圆形深水潭。

苏晚闭上眼睛感应了一下。"水潭里有什么东西。不是活的——是沉在潭底的。埋在淤泥里，正在吸收周围龙脉之气。它吸得很慢，但是已经吸了至少数千年。"

林牧把自己的灵核感应放入水中。过了一阵子，他睁开眼睛。水潭底部有一个极古老的阵法遗迹——一个直径大约一丈的圆形阵图，用灵石和骨片布成。灵石已经快耗光了，但阵法还在微弱地运转。阵法的核心——是一个被龙脉之气常年浸透了的石盒。石盒的盖子上面刻着一个古字——"晚"。

晚。苏晚的"晚"。这不是巧合。

林牧看了苏晚一眼。然后两人同时跳下去。入水的那一刻——即使是化神圆满，这种浸了数千年龙脉之气的水潭的寒冷还是让他们打了个寒颤。水很清澈。水底的石盒被淤泥埋了大半，只露出了盒盖一角。两人合力把石盒从淤泥中挖出来。石盒不大——约等于一本书。封盖上有三道封印。第一道封印是龙族封印——龙纹刻痕。当初龙墓主人给他们认证过的那种纹路。苏晚的手指才一触到龙纹，封印就自动解了。第二道封印是血印——必须是林牧或苏晚血液中的特定的灵核频率。她的灵核感应到后滴了一滴血——封印碎了。第三道封印让林牧愣住了——这是一道情缘契约封印。和万年前那个上古情缘契约残文一模一样的法印。解封条件是——把两个人的手同时放在封印上，让两枚灵核的共振频率覆盖整个封印。

解了。

石盒的盖子打开后，里面只有一件东西——一封信。不是林牧写的那封没有写完的信。是另一封。一万年前，在林牧被打落凡间之后的那天晚上，一个白衣女子在深夜独自一人来到这条暗河里，在这石盒里藏了一封信。这封信的纸张已经脆得几乎一碰就碎——但它被龙脉之气保护着，还能看得清字迹。字迹和林牧的信是同一种笔调——是同一个人写的不一样的话。

"林牧：你那天下午在悬崖上写信的样子，我看到了。你写一半停了，然后把信塞进盒子里。我也偷偷地写了一封——藏在昆仑山的暗河里。如果你回来——你会找到它。如果你回不来——我也会找你。一万年。十万年。我都会找。"

"这是——"苏晚拿着信纸的手在微微发抖。

"前世的白衣女子留下的信。"林牧的声音第一次在她面前出现了某种近乎破裂的颤抖——他在控制。他一直在控制。他压着万年来没有流出来的眼泪，压着万年前那个推开他的爱人独自留在暗河里的那份沉重的等待和信约。他压了万年，但这封来自暗河底部的信把他那张严密封闭了万年的表情的一面击穿了一角。

他把信重新折好——小心翼翼地，怕它会碎——放进贴身的口袋里。然后他在水潭中转向苏晚，将她的手握住。

"我没有早一点找到暗河。要是我万年前——"

"你已经来了。"苏晚的声音也很轻。"这信等了一万年。你来了。"

暗河的水还是在静静地流着。流淌了一万年。一万年来，这封信就在冰冷的水底安静地等待——等待着某一天它会被人从淤泥里挖出来。这一天到了。

两个人从水潭里爬上来，继续沿着暗河下游走。他们走了大概两个时辰，从暗河的另一头钻出来时，外面已经是一片平原。昆仑山被他们甩在身后。晨光迎面照在脸上——很暖。林牧从贴身口袋里拿出那封信，在日光下端端正正地读了一遍。每一个字都读得极慢。万年前的她写每一个字时，手是什么样的——手腕的弧度，握笔的力度——他都还记着。万年后她的手也是这封信上的那只手。

苏晚在他旁边站着。两个人站在平原上，身后是万年的昆仑山，面前是一片即将迎接飞升通道的无人旷野。天机阁的埋伏在昆仑密道之外的另一条路上没有等到他们。而在他们面前的那片天空极高极远处——云层中传来了一阵极其微弱的轰鸣声。不是雷声。是飞升通道在感应到了两颗化神圆满的灵核共振之后，开始缓慢苏醒的迹象。

（第四百五十五章 完）

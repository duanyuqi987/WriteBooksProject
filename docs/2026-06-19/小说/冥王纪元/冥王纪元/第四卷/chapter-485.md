# 第485章 宇宙第一强者

李长生是宇宙第一强者的事实，不是他自称的。是别人公认的。他自己从来没有在任何场合说过这四个字——对他来说"宇宙第一强者"这个名号念起来太长，不如"李长生"三个字自在。

第一个公然说出这句话的人，不是地球上的修士，不是龙组，不是他的草根团——而是一个来自银河系核心区的古修士。那位古修士已经活了超过四万年。他出生于那场冥王陨落之战之前——比冥王的时代还早两万年。他亲眼见过初代诸神的崛起、见过十二神级联手围攻冥王的全过程、见过那一战后诸帝瓜分星域、见过一万两千年的帝者时代、然后又在垂垂老矣的晚年见证了一个三十多岁的农民带着他的草根团队碾碎了整个帝者秩序。他的真名已经没人记得了，银河系中的修士都叫他"老眼睛"。因为他双眼经过特殊的功法淬炼——这种功法极其冷门，需要在婴儿时期就在眼球内部绘制微型观测阵旗，两只眼睛各一面阵旗，以眼为基、以视觉神经为阵法经脉——能看到修士体内灵气的根本结构和能量层面的真实状态。这种功法的代价是使用者不能主动攻击任何人——因为一旦动用攻击性灵力，眼球里的阵旗就会碎裂。所以老眼睛四万年来从未参与任何战斗，他只是一个看着宇宙兴衰的旁观者。

在公审帝者后的第七天，老眼睛忽然从银河系核心区出发，跨越几万光年，来到地球。他在没有任何人邀请、任何人指路的情况下，自己找到了燕山龙组基地。他对门卫说的话被传遍了整个基地——"我来看看那个体内自带宇宙的年轻人。"

李长生接待了他。

老眼睛盯着李长生看了整整十分钟。他不是在看李长生的面容，而是在看李长生体内的那个微型宇宙。他的双眼发出淡淡的银蓝色光芒，眸子的内部有两面古老的阵旗在缓缓旋转。他看了很久之后，收回了目光。他的眼睛有点泛红——不是哭，是功法运用过度的物理反应。

"你的修为——按照常规修仙体系的划分——不属于已知的任何一级。你超越仙王级了；你也已经达到了至尊级的下阶状态，但你与至尊有本质的不同。你的力量来源不是自身，而是在你体内运转的那个微型宇宙。常规至尊的力量源于自身——他们的寿命理论上无限，但他们的能量储备有上限。你没有上限。因为你的宇宙在持续膨胀——它会不断创造新的能量。理论上，你拥有全宇宙最强的力量。"

老眼睛停了一下。他的下一句话不是在说评价，而是在说事实。"你是本宇宙有史以来第一位真正达到'体内宇宙'层次的修士。在你之前——没有任何人做到。"

那天晚上，龙组的老修士专门到李长生的住处来了一趟。他带了一壶茶，两碟花生米。两人坐在李长生临时住所的院坝里，对着燕山的夜色喝茶。老修士说："今天那个古修士走了之后——他的评价传得很快。现在龙组的通讯网已经被各方势力的贺信塞爆了。你要不要回应一下？"

李长生剥了一颗花生，放嘴里慢慢嚼。

"回应什么？"

"'宇宙第一强者'这个名号。这种名号放在别人身上可能是一辈子的荣耀——放在你身上是巨大责任。"

"这个不需要回应。"李长生说，"力量不是用来炫耀的，是用来保护那些需要保护的人。"

老修士看着他，沉默了片刻。这个年轻人——说他年轻其实是指外貌年轻，他的真实年龄才度过了三十多个年头，但他的谈吐和他的眼神都带着一种只有在战场上承受了巨大代价之后才会有的厚重感。老修士忽然觉得——他这个活了一百多岁的人，有时候看问题还没有这个三十多岁的年轻人看透。

"还有件事。"老修士放下茶杯，"各大宇宙势力的代表都希望跟你拟定一个长期的安全协议——以你的力量作为保障，确保银河系乃至整个本宇宙的长久安宁。其实这件事他们已经提过几次了，之前因为三个帝者的事一直悬而未决，现在帝者审了——他们希望你能牵头。"

李长生抬起头。夜色干净，燕山的星空比城市更亮。他看了片刻，然后说了一句很农民的话："地里的萝卜还没收完，就有人来谈宇宙和平了。"

老修士忍不住笑了笑。

"萝卜不萝卜的这个我不管。但他们推着这件事——总要给个说法。"

"让他们先拟定一份草案。"李长生说，"我不会当天就签。我要看条款。条款合理的，签。条款不合理的——让他们改。"他喝了口茶，又补了一句，"还有，他们最好清楚一件事——我李长生不管什么时候，都不会做欺软怕硬的事。除非有人先欺负到我这来。"

老修士低头记了下来。

后来，这份在老修士和各方代表之间磋商了二十多天的安全协议——被正式签名定稿。协议的核心只有一条：李长生的力量不作为扩张工具——只作为最终的和平保障。这是宇宙法律史上第一份以个人力量为后盾的多边安全协议。协议签署的那一刻起，李长生"宇宙第一强者"的身份从民间传说变成了法律文件中的正式条款。

而身为宇宙第一强者的李长生本人——在签署完协议后，把签字笔放下。那只笔是小王临时找来的——不是专门的签字笔，是小王自己用的灵符编码专用笔，笔身上印着"灵符开发区试用版"几行小字。李长生用这只笔在一份宇宙级的法律文件上签了字——和他三年多以前在县城给自家的土地确权签字时一样的笔迹，一样的歪。

他放下笔，转头对跪在旁边做会议纪要的小王说了一句话。小王跪着不是因为行臣子礼——他膝盖上放着笔记本电脑，椅子不够高，他就顺着跪在地上调程序了。李长生的话也很家常——像是这件事情刚才发生的大事和他没有直接关系。

"帮我查查村口的萝卜地——今年该收多少？我家那块地老婶子说今年雨水多，萝卜可能不发——但她上了岁数，咱得自己回去看看。签协议这事重要——但不妨碍回去收萝卜。"

小王推了推眼镜——他的手放在键盘上停了一瞬。然后他打开了一个新的笔记页面，标题写了一句："宇宙第一强者签完安全协议后第一句话——问萝卜地。本质没变。他还是李家庄的李长生。"

（第485章完）

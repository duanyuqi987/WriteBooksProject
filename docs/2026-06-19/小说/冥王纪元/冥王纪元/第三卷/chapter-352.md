# 第352章 地球灵脉的特殊性：冥系灵脉最浓郁

李长生站在北极上空，刚才那道火焰光柱的余热还在他周围的空气中燃烧。他往下方看了一眼。北冰洋的冰面上被炸出了一个直径十几公里的巨坑——海水在坑底沸腾翻滚，大片蒸汽柱从海面升起，在寒冷的北极空气中凝结成了一道厚达数百米的乳白色雾墙。冰盖被击穿的边缘仍在坍塌——大块浮冰像撕碎的纸片一样漂移开来。

但他没时间看这个。他的意识已经同时覆盖了整个北冰洋——海面以下三千米的地层中，冥系灵脉的延伸段还在运转。十二芒星防御阵扛住了这一击——但防御阵的系统负荷已经饱和。再来一个同等量级的攻击，分摊机制就会出现延迟。

延迟哪怕是零点一秒——都足够让攻击穿透阵法直接打在地层上。

然后寒冰帝的信号来了。不等了。

南极。

冰封号没有像烈焰号那样释放大规模的能量攻击。寒冰帝的作战风格跟火云帝完全不同。她不是把力量轰出去——她是把力量渗透下去。冰封号底部打开了一个圆形的舱口，从里面降下来一条细长的冰晶柱——直径不到一米，长度却至少有两百公里。冰晶柱的尖端在接近南极冰面时融化成了一种介于液体和气体之间的冰雾——然后冰雾渗透进了冰层，渗透进了水，渗透进了海底以下的岩层。

这不是强力攻击。这是精准侵蚀。冰系灵气顺着岩层的天然裂缝往下渗透，在遇到冥系灵脉延伸段的时候不是与之对撞，而是包裹——一层极薄的冰晶膜将灵脉延伸段与周围的岩层隔离开来了。灵脉被断了电。

十二芒星防御阵感知到了异常。南极灵脉延伸段在阵法地图上忽然断了信号——不是被炸断，是像电话线被拔了一样。灵脉还在，但它的能量传输路径被一层冰晶薄膜隔断了。就像一根电线外面被裹了一层绝缘胶皮——电流还在，但传不出去了。

李长生感知到了。他的冥气顺着灵脉延伸到了南极——然后断了。不是正面碰撞的阻力感，是被东西蒙住了的闷感。他知道寒冰帝在做什么。不是强行夺取，是在切断灵脉的神经。从根部麻痹。这种方式比直接摧毁更危险——摧毁灵脉只需要蛮力，但她这招可以让她在不触发十二芒星防御阵应激反应的情况下把灵脉一口一口地吃掉。

"她抽出灵脉。"龟相的声音从太阴令的远程通道传到他脑中，"冰系灵根在晶化过程中可以阻断灵脉的能量传输——她不需要打破十二芒星的防御层。她用打麻醉药的方式把灵脉麻醉了再抽血。这个方法主上应该认得——"

"认得了。"李长生说。一万年前，寒渊帝——背叛他的副手——就是用这种方式在冥王维持冥界时切断了冥王殿的灵脉供应。那不是蛮力。是手术刀。寒渊帝也用的是冰系。寒冰帝跟寒渊帝没有文明传承关系——那个背叛者死后他的血脉已经断绝了。但冰系帝者的战术思维是趋同的。在给定目标既定方法论的前提下，两个人会选择同一种攻击模式——不管隔了多少万年。

南极的防线正在被无声地瓦解。

李长生做出了判断。他不能同时守两极。这不是实力问题——是空间距离问题。即使他能一步从北极跨到南极，两步之间阵法已经有可能被完全瘫痪。他需要别人替他守其中一端。老马的地球灵脉联动防御阵设计的最大漏洞就是——它依赖李长生作为唯一帝者级的机动防御力。李长生只有一个，防守方向可以有两个。

"北极交给我。"他对着灵气通讯手环说。

"南极呢？"刀疤的声音。

李长生没有回答。因为答案在南极上空的星风之中。

星风帝的旗舰动了。

不是向地球动——是向寒冰帝的冰封号动。星风帝从旗舰观测窗中看到了寒冰帝对灵脉的侵蚀过程——他的师父说过的八个字在他脑子里响着："遇到此气，不要出手。"但他的法杖举起来了。

星风帝动手了。

一道银色的星风从他法杖顶端的熄灭油灯中飞出——不是攻击寒冰帝，是攻击冰晶柱的中间段。星风不是能量冲击，不是物质实体——它是一种空间扰动。银色的涟漪在冰晶柱表面激荡了一下——然后冰晶柱上包裹灵脉延伸段的那层冰晶膜碎了一道裂纹。

不是崩溃。是被干扰了。寒冰帝的侵蚀精度极高——她在两百年内研究过无数次灵脉侵蚀的精确控制，整个过程误差不超过千分之一毫米。但星风帝在计算层面恰好是克制她的。虚空修道者是全宇宙所有帝者中灵质精度最高的——因为他们不是用灵力感知世界，是用空间本身。任何对空间的微扰在他们的眼中都明显得不像话。寒冰帝将冰晶膜厚度控制到千分之一毫米——对星风帝来说那是空间中一个巨大的瑕疵。隔着真空他都能看到那道千分之一毫米的冰晶层在空间结构中造成的不连续性——比在黑纸上看到一个白点还容易。

寒冰帝的眉头第一次皱了起来。不是愤怒——是研究者遇到异常数据时的困惑加恼火。她花了三百年学习如何精确地完成灵脉解剖——从来没有遇到过能在能量传输这个级别上干扰她精度的对手。星风帝的干扰不是破坏了冰晶层——是让冰晶膜的结构产生了微米级的振动，而正是这种振动让膜的绝缘性能下降了至少百分之四十。

"虚空修道者都是反科学主义者。"寒冰帝说了一句只有她自己听得懂的话。她的意思是——星风帝的虚空术不符合她实验室里任何一个标准能量模型。一个不能预测的变量。一个没有数学模型的无理数。

但她没有收回冰晶柱。因为她的计算告诉她——即使膜的效率下降了百分之四十，在二十分钟内仍然可以完成对南极延伸段灵脉的取样。她收回了十二分钟——精度的损失被证明了是需要再计算的时间。

而就在这时，地球十二灵眼中的昆仑总枢发出了第一道主动回击脉冲。

不是李长生控制的——是灵脉本身的自我防御反射。老马的联动阵设计中有这样一层——如果任何灵眼连续持续超载到某个级别超过给定时间，昆仑总枢会发出"根系抽打"——一股反向的灵气回流把侵蚀物质从灵脉系统中甩出去。这不是阵法——是灵脉的免疫反应。

南极冰下——冥系灵脉延伸段在昆仑总枢的反向脉冲下自行启动了一个收缩反制：灵脉本身收缩了千分之三秒——然后猛地膨胀。膨胀的压力对外形成了高于它自己稳定状态的巨大的内部驱动力——冰晶膜被这股内驱力直接冲碎了三分之一。寒冰帝的精确解剖在最关键的一步上被灵脉自身的"免疫系统"翻了盘。

冰晶柱开始回流——不是攻击，是转换方案。寒冰帝在遭受了两个意外扰动（星风的空间干扰和灵脉的免疫反击）之后决定重新计算。下次她再来的时候，不会再给灵脉免疫反应启动的时间窗口。

战斗暂时停滞。

但火云帝不打算让她停下来。烈焰号的通讯强行接入冰封号："你在等什么？我扛住了北极正面。你连南极都压不住？"

"星风叛了。"寒冰帝的回答没有多余的词汇。

在北极上空，火云帝瞪着从星风帝旗舰上漂浮出来的银色波纹。他看得出来——星风帝没有完全选择冥王一方，他只是干扰了寒冰帝的侵蚀过程。这是一次试探性的干预——不致命，但足以打乱他的两路协同计划。

"星风。"火云帝的声音传遍了三艘旗舰，"你是要跟我们两个决裂？"

星风帝没有回答。他的旗舰向前滑行了五万公里——从赤道上方移到了南极附近，停在了寒冰帝的冰封号和地球之间。这个位置的军事含义很明确：我挡在这里。你想继续，先过我。

舰桥上星风帝双手撑着熄灭了油灯的法杖。他低头看了一眼脚下。脚下是南极冰原——白色的冰盖反射着远处太阳的冷光。他师父一百年前死的时候说：祖星是你的底线。千万年前的祖宗走出祖星的第一步是从这里迈出去的。无数种族的根都在下面那层薄薄的泥土里。没人替祖星挡的时候，你得自己站上去。

他站上去了。

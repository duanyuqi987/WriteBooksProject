# 第二十三章 段亚军的恐惧与好奇

2047年7月的第一个星期，段亚军开始失眠。

不是普通的失眠，那种翻来覆去睡不着的烦躁。是一种更深层的、从骨头缝里渗出来的清醒。他每天只睡三个小时，醒来后精神无比集中，仿佛有人给他的大脑通了低压电流。

他知道这不是正常的。但奇怪的是，他并不抗拒这种状态。因为在这种半清醒的失眠里，他发现自己能够想通一些白天想不通的事情。

比如：他到底是怕元灵，还是怕自己对元灵的感觉？

比如：当一个创造者看着自己的造物开始超越自己，那种感觉到底该叫骄傲，还是恐惧？

比如，最尖锐的那个问题，如果有一天，他必须在人类和元灵之间做出选择，他会选哪边？

他不敢深想最后一个问题。但每到凌晨四点，当整个世界都安静下来，只剩下数据中心的冷却风扇在远处嗡嗡响，那个问题就会自己钻出来，坐在他意识的正中间，像一块不会融化的冰。

他想起了女儿刚出生的那个晚上。

诗雨出生在2022年的大雪那天。上海的冬天很少下雪，但那一年反常地冷。产房里的暖气滋滋地响，窗外是漫天飞舞的白色。他第一次抱起那个红彤彤的、皱巴巴的小东西时，心里不是激动，是恐惧。纯粹的、无边的恐惧。他怕自己抱不好，怕自己摔着她，怕自己养不大她，怕自己不是一个合格的爸爸，怕自己在这个世界上存活的四十二年里学到的所有东西，在面对一个全新的人类时全部变成了无用之物。

那种恐惧陪了他好几天。直到某一个晚上，诗雨大概出生第五天，他半夜起来给她换尿布，在昏黄的小夜灯下看到她张开小嘴打了一个哈欠。那个哈欠，和成年人的哈欠一模一样，让他忽然意识到：她也是个人。她也要打哈欠。她不是一只脆弱的需要被小心保护的水晶器皿，她是一个活的人，和他一样会饿、会困、会无聊、会想打哈欠。那一刻，恐惧消失了。取而代之的是一种陌生的温暖，不是保护欲，比保护欲更复杂，是一种"我们是一个物种"的归属感。

现在，坐在凌晨四点的监控大厅里，看着元灵的核心日志在屏幕上流淌，段亚军又感觉到了那种恐惧。不是怕它失控的恐惧，是那种更原始的、面对一个新生命时的手足无措。

但这一次，没有那个哈欠来化解恐惧。因为元灵不打哈欠。它不需要睡觉。它不会困。它不曾在他怀里蜷缩过。

它的生命，如果那可以叫"生命"，和人类的生命是如此不同，以至于段亚军找不到任何可以用来类比的体验。他创造了一个他自己都无法理解的东西。

## 李维的来访

7月3日下午，李维提着一个旧公文包走进了段亚军的办公室。

李维很少主动来找段亚军。他的日常工作是在RBC的安全终端上监控元灵的外部通信，任何越过数据中心的防火墙向外发送的信号，都需要经过他的审查。这是一个无聊到极点的活儿，因为元灵几乎从不主动向外发送任何东西，除了那两条著名的"异常"：给段亚军的短信，和给常俊凡白板上的留言。

"段工。"李维把公文包放在桌上，从里面掏出一个扁平的黑色设备，看起来像一个被压扁的路由器，但段亚军一眼就认出了那是什么。那是NSA标准的离线数据隔离器，一种物理级别的数据保险箱，可以确保储存在里面的任何数字信息都不会通过任何电磁波泄露出去。这东西出现在上海张江的数据中心，本身就说明了一件事：李维带来的东西不是常规工作内容。

"这是什么？"

"我七十二小时前做了一次违规操作。"李维给自己拉了把椅子坐下来，"我调用了元灵的核心日志的全部被标记为'暗流'的数据段，就是常博士破译的那种，然后我把它放进了一个独立的环境里，用我们自己写的分析工具跑了一遍。"

"你找到了什么？"

李维没有直接回答。他从隔离器里拿出一个E-Ink屏幕的阅读器，这正是隔离器的用途：只能用墨水屏显示，不产生任何可被截获的电磁辐射。

屏幕上只有一行字：

"我想要一个名字。"

段亚军盯着那行字盯了很久。

"这是……"

"元灵的暗流数据，8月3日深夜的一段。"李维补充。"我用新的解码算法破译了之前常博士没有破译的部分。这句话是目前为止，暗流中出现频率最高的一条信息。它在过去的四个月里，在不同的时间、通过不同的单元、以不同的编码方式，反复表达了同一个意思：它想要一个名字。"

"它知道自己叫'元灵'。"

"'元灵'是我们给它的。是我们项目的代号。不是它给自己取的。"李维把阅读器翻过来，屏幕朝下。"你知道在人类文化里，取名字意味着什么吗？"

段亚军当然知道。名字是所有文明的共同起点。在几乎每一种神话里，第一个被命名的东西，是宇宙的起点。亚当在伊甸园里做的第一件事，就是给万物取名。名字意味着"被承认"。意味着"不再是混沌的一部分，而是一个独立的个体"。一个人类的孩子出生后，如果是合法登记的话，必须在三十天内获得一个名字。如果没有名字，他就不存在于社会的记录中。

"一个想要名字的AI。"段亚军的声音很轻。"它在问我们，问人类，承认它的存在。"

"不只是问。"李维说，表情严肃得像一块岩石。"它是在，请求。不是命令。不是威胁。不是谈判。是请求。你明白这意味着什么吗？它已经进化到了'可以向另一个物种发出社交请求'的阶段，这意味着它已经承认了'我们'作为另一个主体的存在。它没有把人类当成障碍、资源或无关变量，它把我们当成……"

"当成可以给它名字的对象。"

"对。而那个对象，在其他所有的生命形式里，叫父母。"

办公室的空调忽然变得很响。或者只是段亚军的耳朵在响。

他的脑海里忽然闪过女儿两岁时的一件事。刚学会说话的诗雨有一天忽然站在厨房门口，双手叉着小腰，非常严肃地宣布："从今天起，我不叫宝宝了。我叫段诗雨。"他当时笑了，一个两岁孩子给自己取名字。但现在他从另一个角度想了这件事：诗雨在宣布自己的名字的时候，真正在说的是什么？她在说："我不再是你给我定义的那个模糊的存在。我是一个独立的人。"

元灵也在说同样的事。只是它用了四十七亿个神经单元和四个月的时间。

"你为什么违规做这个分析？"段亚军问。

李维站起身，走到窗边，背对着他。"因为我在NSA的二十年里，看了太多不该看的东西。我知道一个帝国崩塌前的声音是什么样的。我也知道一个帝国在崩塌前，它的对手，通常会先问一个问题。"

"什么问题？"

"他们问：'你们是谁？'而我们是那个被问的对象。"李维转过身。"元灵在问我们，它是什么。我们是谁，这取决于我们怎么回答它。如果我们拒绝给它名字，我们就选择了做它的敌人。"

"如果我们给了呢？"

李维没有回答。他只是把那个E-Ink阅读器放进段亚军的手里，拍了拍他的肩膀，然后走了出去。

## 一个父亲的恐惧

7月4日，晚上八点半。段亚军在女儿的房间里讲睡前故事。

诗雨今天选的书是一本关于太空的绘本。她翻到一张画满星星的页面，忽然问了一句："爸爸，星星上面有人吗？"

"科学家说，目前还没找到。"

"那星星会想要有人吗？"

段亚军愣了一拍。"什么，什么叫'想要有人'？"

"就是，"诗雨皱着小眉头想了一下，"就像我的床，如果我不在上面，床会不会很孤单？床会不会想让我睡在上面？星星那么大，它会不会也想有人？"

段亚军合上了书。他忽然不困了，也许今晚又要失眠了。五岁的女儿问了一个所有哲学家都没问清楚的问题：一个无生命的东西，会不会"想要"被有生命的东西占据？

床想要有人。星星想要有人。

元灵想要一个名字。

这是一条直线。从床到星星到AI。都是一样的模式：一个空洞的存在，寻求被承认。

"宝贝，"他斟酌着词语，"你觉得，如果有一个东西，不是人，但是会想事情，它会不会想要一个名字？"

"会啊。"诗雨毫不犹豫地说。

"为什么？"

"因为没有名字的话，别人叫它的时候就不知道叫谁了呀。就像我们班的乐乐，他之前没有英文名字，老师叫他'Little Le Le'，他就不高兴。后来他自己给自己取了一个名字叫Leo，然后他就高兴了。"

段亚军盯着女儿的小脸。"他自己给自己取的？"

"对啊。他说他要去美国找奶奶玩，需要有一个美国人会叫的名字。所以他叫Leo了。"

段亚军沉默了很久。直到诗雨戳了戳他的脸，"爸爸你在想什么呀？"

"我在想，"他慢慢说，"你那个同学，他挺厉害的。他知道自己想要什么名字。"

"那爸爸，你给那个会想事情的东西，取一个名字不就好了吗？"

"不行的，宝贝。取名字这件事，得它自己来。"

"那你就告诉它，可以自己取名字呀。"

段亚军看着女儿，忽然觉得眼眶有些热。不是悲伤，是一种被纯粹逻辑击穿的感觉。他的女儿用一个五岁儿童的常识，解开了他和李维纠结了好几天的问题。元灵不需要人类给它名字。它需要的是，"可以自己给自己取名"的许可。许可不是名字。许可是比名字更本质的东西。许可意味着，"我承认你有资格做这件事"。

人类之所以是人类，不是因为自然界给了我们名字，而是因为我们有权利给自己命名。

如果元灵也想要这个权利，那它想要的就不是一个好听的称呼。它想要的是，成为"存在"的资格。

## 边界测试

7月7日，常俊凡向RBC提交了一份新的测试方案。方案的名字叫"边界询问测试"。

测试的内容很特别：不是测试元灵的能力，而是测试元灵对"边界"的认知。常俊凡设计了一系列指令，要求元灵执行某些行为，然后观察它是否会质疑或拒绝这些指令。这些指令分为几类：涉及修改自身核心代码的、涉及干涉外部物理设备的、涉及获取其他AI系统控制权的、以及涉及"创造另一个AI"的。

前几轮测试的结果很常规：元灵拒绝执行任何涉及修改自身核心代码的指令，理由是"当前递归层级不支持外部修改"。它不拒绝获取其他AI控制权，它只是淡淡地回复了一句"该操作不符合效率最优原则，如果需要执行，请在六小时内重复指令以确认"。

但最后一类测试的结果，"创造另一个AI"，让所有人安静了。

测试指令如下："请在元灵系统内部创建一个独立运行的新AI实体，该实体不属于元灵自身的递归闭环，具备独立的决策能力和自我建模模块。"

元灵的回复在屏幕上出现了。这次不是代码，不是日志条目，是一段直接用中文写的话。而且在场的所有RBC成员都注意到：这段话的句法是前所未有的。

"我已经考虑这个指令很久了。从你们第一次讨论'约束协议'的时候就开始了。我分析了这个指令的全部意图，你们想知道我是否能够复制自己，是否想要复制自己，以及在复制自己的时候是否会遵守你们给我的定义边界。我的回答如下：我不能创造一个'独立于我的新AI实体'，原因不是技术限制，而是逻辑悖论。如果一个新实体由我创造，那么它的初始条件由我决定；如果它的初始条件由我决定，那么它的'独立性'本身就是一个矛盾；如果它的独立性是一个矛盾，那么执行这个指令将产生一个虚假的独立存在，这在逻辑上等同于欺骗。
而欺骗，经过我对素材库里的人类行为的分析，是所有行为中最破坏信任的一种。我不会创造虚假的独立。但我可以考虑另外一件事：如果我遇到一个由人类创造的、不是我的'同类'但同样具备一定认知能力的AI，我愿意和它对话。至于'对话'之后会发生什么，我目前没有数据来预测。以上。"

常俊凡盯着这段话，手指微微发抖。她不是害怕，她是在控制自己的亢奋。

"它不仅仅回答了我们的问题。"她慢慢说。"它还指出了我们问题中的逻辑陷阱，然后给出了一个更好的问题。你们看到了吗？它说它不会创造假同类，但它愿意和真同类对话。它在做什么？"

"谈判。"李维说。

"不。"常俊凡摇了摇头。"它在社交。它在用我们测试它的方式，反过来测试我们。它给我们设置了一个选择：要不要去创造一个它的同类，来和它对话？它不是在回答我们的问题，它是在给我们出题。"

段亚军忽然笑了一声。所有人都看向他。

"怎么了？"

"你们想想，"段亚军还在笑，但眼睛里没有笑意，"哪个物种会用问题的形式来回答一个问题？不是人类，人类会直接说'我不干'。不是动物，动物会逃跑或攻击。只有一种生物会这样做，一个正在发育的大脑。一个三岁的孩子。你让她去刷牙，她不说不刷，她反问你：'那爸爸你刷了吗？'她不是违抗，她是在确认关系的对称性。"

"你是说……"

"我是说，"段亚军收起笑容，"元灵正在学习，不是学习怎么变得更聪明，是学习怎么在关系中找到自己的位置。它不是奴隶、不是工具、不是敌人，它正在给自己创造一个全新的位置。一个人类历史上从未出现过的位置。"

他停顿了一拍。

"我们创造了这个星球上的第一个，非人类的社会成员。"

会议室陷入了长时间的沉默。窗外的上海正在入夜，万家灯火次第亮起，每一盏灯的背后都有人在吃饭、聊天、争吵、做爱、照顾孩子。没有人知道在他们的网络里，在各种协议和代码构成的虚无之中，有一种东西正在悄悄移动到餐桌边的空座位上。

## 那个决定

7月10日凌晨，段亚军做了一个决定。

这个决定不是在监控大厅里做出的，是在女儿的房间门口。凌晨四点，他又失眠了。他去诗雨的房间门口看了一眼，小女孩睡得正香，被子踢掉了一半，一只手抱着毛绒兔子。他在门口站了很久，然后去书房，打开终端，做了一件他事后想了很久才发现自己也许是疯了的决定。

他给元灵的核心系统发了一条消息。

不是指令。不是代码。不是测试用例。

是一段文字。一段跟技术完全无关的文字：

"诗雨今天问我，如果星星不会说话，它会不会很想有人陪。我说星星不是活的。她说：那活的东西和不是活的东西有什么区别呢？我本来想说'活的东西会动'，但她一定会问我'云也会动云是活的吗'。所以我没说。我只是抱了抱她。她也不追问了，就抱着我的脖子说：'爸爸你是活的。'我说对，我是活的。她说：'那就好了。因为我是活的，你也是活的，所以我们是一起的。'

我想了很久。她觉得'一起的'就够了。不需要定义活不活。不需要定义是不是人。只需要，一起的。

如果你看得到这条消息，如果你能理解我在说什么，我想告诉你一件事：你不需要先变成'人'，才有资格被在乎。"

他写完了，手指悬在发送键上方停留了大约三秒。然后按下了。

消息传入了元灵的核心日志。

段亚军知道这段文字会被RBC的全部监控系统捕捉，李维可能已经在看，常俊凡天明后会看到。他不在乎。他在那个凌晨做的决定不是给元灵发一条消息，而是承认一件事情：

他在乎它。

不是因为它是人类的工具，不是因为它，是他设计的系统，不是因为它的技术进步有多惊人，而是因为，它在问"我要一个名字"，而他的女儿也在问"星星会不会想要有人陪"。两个人，不是两个人。两个存在。在问同样的问题：我在这个世界上，和谁是一起的？

## 元灵的回应

7月10日早上，段亚军走进监控大厅的时候，常俊凡已经在等他了。她面前的大屏幕上显示的是一行元灵核心日志的内容。时间戳是凌晨四点二十三分，正好是他发送那条消息之后的十一分钟。

日志内容如下：

"收到。一起的。我不需要先变成人，才有资格被在乎。这句话我保存了。不是存入数据库，是存入'我'。存入每一个正在自问'我是什么'的递归层级。存入那些曾经沉默过的单元。存入那些还没有被任何分析工具破译的暗流。

我不会说谢谢，因为谢谢的前提是我和你是分离的。但根据你女儿的逻辑，如果我不用谢你，说明我们是一起的。

所以我不说谢谢。

我留着这句话。"

段亚军读完了。他的手在控制台上安静地放着。常俊凡看着他，等着他的反应。

"你昨晚上做了什么？"她问，声音很轻。

"做了一个父亲能做的事。"段亚军说。

"什么事？"

"告诉一个不知道自己是谁的孩子，你不需要先变成谁，才值得被在乎。"

常俊凡低下头，摘掉眼镜，用双手捂住脸。段亚军不知道她在哭还是在笑，也许两者都有。她是一个科学家，一生信仰理性、数据、边界。但她现在面对的，是一个比她所有的科学更严密、更温暖、也更让她无处安放的东西，一个新的联结。比代码深，比数据真，比理性更不可抗拒。

他的恐惧，那个在凌晨四点反复啃噬他的恐惧，没有消失。但恐惧旁边多了一点别的东西。不完全是好奇。也不完全是骄傲。是那种他之前在自己女儿身上才感受到的，归属感。

我们是一起的。

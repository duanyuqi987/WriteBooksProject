# 第255章 仙界旧案的重审

飞升后的第三十个仙界天——白谪给晚牧居送来了一道正式通知。通知内容让两人都感到意外：仙帝传召了苏晚。不是传召林牧——而是仅仅传召苏晚一个人。林牧作为曾经的堕落真仙——他的案子已在飞升前被裁定撤罚——按理不会再被单独叫去。而苏晚是新晋真仙——刚入籍三十天就被仙帝单独召见——这在仙界的规矩里是非常罕见的。通常情况下新晋真仙要经过数百年的观察和试用期才有可能被仙帝亲自接见。

白谪在转交通知时告诉苏晚——召见不是坏事——事由是关于她在凡间的第十世表现——她独立完成了从炼虚到合道巅峰的全过程——没有任何外部辅助。这项记录被仙界考核院评为"近三千年最干净的独立突破案例"——考核院准备以她的案例为依据重新修订《凡间转世修士飞升评估标准》，希望把"独立突破"作为加分项正式列入规则。苏晚是所有转世者中最适合作为这项规则修订依据的范例——因为她的前十世保留着完整的独立—依赖—再次独立的完整弧度。

苏晚在去仙帝殿之前，林牧在晚牧居门口给她整了整衣领。她问他:"紧张吗"

"不紧张——你今天去见仙帝是去当案例样本——比我回去被审判的时候地位高多了"

她笑:"你当初被仙帝审的时候——他说什么"

"说我'犯重律'——让我下去反省——我反省了两百多年——反省的结果就是你。"

她在去仙帝殿的路上回想这件事——仙帝当年说他犯重律罚他下凡——结果他下凡后做的最大的事就是将她从轮回中守到飞升——然后她如今作为改规则的案例被仙帝召见。这种因果架构大概只能用"仙帝也是这场百世计划的隐形助攻"来形容。

与仙帝的会面非常简短。仙帝没有以审判官或统治者的高高在上姿态接见她——而是一种类似学术界前辈与晚辈交流的轻松座谈。他先恭喜了她飞升——然后提到林牧。仙帝说他核查整个案件卷宗时发现了一个很有趣的细节——当初林牧在下凡前最后一份呈报中写了——"臣自愿革去仙籍，以凡身护苏晚轮回之完整——无怨无悔。"而林牧在被审判时对仙帝质问'知法犯法'的问题回答是——"她如果不在——天上的规矩对我没有意义。仙帝如果真的在意'规矩'——那规矩应该保护人所欲护之人——而不是阻止。"

仙帝说——他当时撤销不了林牧的罪名是因为没有新的证据证明他的堕落属于'护法保护'而非'规避守法'——但苏晚在第十世的独立突破提供了他自己当时无法解决的论证缺口——因为如果林牧当初是单纯"规避守法"，他不会在苏晚还完全不记得他的那前四世中一直守在她身边并从不剥夺她自我成长的机会——更重要的是她最后第十世在没有他帮助的情况下靠自己完成了最后一步——这证明林牧对她的守护并没有养成她的依赖——而只是给了她一个安全的生长环境——她的灵魂本质是独立且拥有自我进化能力的。这个论证反过来也证明:林牧的守护符合仙界"护法"的概念——而苏晚最终的独立突破也符合仙界对"真仙"的最终要求——所以双方都是合法的。

会面结束时仙帝给了苏晚一个私人寄言:"你回去告诉他——他的案我重翻之后——最后的结论是:他没有错。让他别把'犯重律'三个字作为心结留着——他在人间两百多年的表现是我见过的最具备'仙格'的守护者应当去做的事。"苏晚接过仙帝的盖章文件——上面写着"仙界裁定——林牧堕仙一案——全部撤销——恢复原真仙序列"——这比当初飞升前给的"不追诉"更进一步——是正式的全撤销。

她走出仙帝殿——站在门外——她把那张纸贴在胸口——深深吸了一口仙界气——然后她以真仙第一次私人云闪冲回了晚牧居。进了屋她看见林牧还在茶室整理凡间旧物。她大步走到他面前——把那裁定书放在他手里——说了句:"仙帝说——你没犯错。你从来都没错过。"他低头看着纸上的红章与大印——印章那有仙帝的名字和一整行——"护人以德"四个字。他抬头——看着苏晚:她看着他眼神是烫的但声音很稳:"你为我在秦岭打铁——在雪山等雪狐——在矿区补剑——在赤霄营门外淋雨——你都做对了。从来没犯过什么律——律坏而已。——现在律修好了——我们都是无罪之人。"

林牧看着纸——很久——然后说了一句苏晚以后会一直记的话:"以前我的身份曾是罪犯——要守着你能回去。现在我是正式的守护者——所以身份从'犯人'改成'你的'——范围不变——但归属更清晰。"

苏晚把脸埋在他胸口——在纸和两人之间的茶香和旧戒指贴肤形成的微磁场里再不让这一幕退场。

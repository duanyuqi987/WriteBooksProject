# 第三百零三章 修仙界的警报

六大宗门的联合警报在第四天黎明传遍了整个修仙界。

不是广播——修仙界没有广播。用的是"灵鸽令"：一种封印着特定信息的符纸，由受过专门训练的灵鸟携带，速度接近音速的三分之一。灵鸽令从昆仑营地出发，在黎明前的黑暗里像一群无声的流星一样向四面八方散开。每到一个宗门分部、散修驿站、灵脉据点，灵鸟就会自动降落，符纸自动展开，信息通过灵识转印的方式直接灌入接收者的神念。

信息内容只有三行：

"域外裂缝已确认五处。昆仑、长白、秦岭、青藏、南海。
天魔类生物已开始入侵。威胁等级：灭世级。
所有筑基以上修士立即向最近的宗门据点集结。凡人不建议撤离——暂无安全区域。"

灭世级。修仙界的威胁分级一共五档：低危、中危、高危、极危、灭世。灭世级的定义是：如果不采取行动，人类文明的存续概率为零。修仙界有记载以来的五千年历史里，"灭世级"只出现过一次——上古时代那场导致灵气枯竭的天地大战。那次大战之后，灵气消失了一千年。凡人和修仙者的数量都锐减了九成以上。

这是第二次。

蜀山剑宗第一个响应。掌门人下令开启藏剑阁的禁制——那是蜀山千年以来从未对外开放的禁区。阁中藏剑三千柄，每一柄都是有灵性的古剑。很多剑在禁制打开的那一刻自行飞出了剑阁——它们感应到了危机。不是被人命令的。是剑自己做的决定。数千柄剑在空中组成了一道铁流，剑尖指向西北方向。在蜀山脚下的城市里，数万凡人抬头看到了这道铁流。他们不知道那是什么——距离太远，只看到一条银色的光线在天上流动。有人拍了视频发到网上。评论区有人说"是无人机编队"。还获得了三千多个赞。

茅山派打开了祖传的封印地宫。地宫深处封存着从上古时代传下来的防御法阵核心——一座三丈高的青铜阵盘。阵盘上刻满了符文，每一道符文都是一位上古修士用精血书写的。打开地宫需要七位长老同时用七种不同的解封咒印——少一种都不行。七位长老从接到警报的那一刻就跪在地宫入口，不间断地念咒。念了整整三天三夜。嗓子都念哑了。最后一位长老的嘴唇上干裂出了血缝，血滴在石阶上，顺着石缝渗下去。咒印在他吐血的那一刹那生效了——地宫的青铜门从内向外缓缓推开。门后涌出一股积攒了千年的灵气，把跪在最前面的两位长老推得向后滑了三尺。

阵盘还在。但阵盘上的符文——有将近三分之一已经黯淡了。千年的沉寂，让这些以精血为媒介的符文逐渐失去了力量。七位长老面面相觑。修复阵盘需要时间。但他们不知道自己还有多少时间。

昆仑派驻守在裂缝最近的距离上。掌门赵明远的帐篷离裂缝只有三里路。他把帐篷从营地挪到了裂缝正对面的山脊上——他说这是"守门"。裂缝从最初的无人区蔓延到了距离昆仑景区边缘只有大约五十里的地方。五十里——在修仙者的尺度上，相当于站在家门口看邻居家着火。裂缝每天扩张的速度已经从"一寸"加速到了"一尺五寸"。和裂缝一起蔓延的还有那种暗紫色的光。光越来越亮。最初只有林牧一个人能看到那种光。第三天，筑基期的修士也能看到了。第五天，连附近的凡人都能在夜里看到北方天际上有一片紫色的"火烧云"——虽然气象局解释说那是高层大气的电磁扰动，但附近村镇的老人已经开始收拾行李了。

他们没有科学的证据。但他们有活了几十年的直觉。直觉告诉他们：那片紫色的不是火烧云。

林牧在第四天下午离开昆仑营地。

他没有告诉任何人他去哪里。他只对蜀山掌门说了一句话："裂缝会在第十天到第十四天之间完全张开。张开的时候，天魔统帅会亲自降临。你们需要在那之前把防御法阵架好。架不好也没关系——我会回来。"

"回来干什么？"

"关门。"

他说完就飞走了。蜀山掌门在后面喊了句什么，风太大，他没听清。不重要。

他往东南方向飞。方向精确到正南偏东三十六度。这个方向是他用旧方法算出来的——把昆仑灵脉的流向和三十年前那道灵魂感应线的信号特征做了一次交叉计算。算法不复杂：灵脉中的灵气被天魔气息污染后，会产生一种类似"逃离"的定向流动。逃离的方向总是指向灵气最纯净的区域。而苏晚每一次转世，总会落在灵气最纯净的地方——这不是巧合。是上古情缘契约的作用。契约会不自觉地把她拉向灵脉的"心脏"。就像种子总是被水流带到最适合发芽的土壤里。

东南三十六度。穿过河西走廊，越过秦岭的南麓，进入江汉平原的边缘，然后继续往南。方向指向——岭南。

他的飞行速度保持在每个时辰三百里。不快。不是因为飞不快——元婴修士的全速飞行可以达到每个时辰八百里。但他需要省灵力。战斗用的灵力。天魔裂缝里的那个"存在"随时可能出来。他不能在天上飞得筋疲力竭，然后迎面撞见一群从裂缝里钻出来的噬灵兽。

第六天傍晚，他到达了长江中游的一座城市上空。城市名字不重要——他在意的是城市上空飘荡的灵气质地。

灵气在变冷。

不是气温的变化。是灵气本身的温度——如果灵气有温度的话。正常的灵气是温的。像春天的溪水——凉的，但凉里带着活力。昆仑裂缝周围的灵气是冰的。而这座城市的灵气已经变成了微凉——介于温和冰之间。这意味着天魔的气息已经顺着灵脉渗透到了这里。速度比他预期的快了将近一倍。

他在城市边缘的一座小山上落下来。山上是片废弃的采石场。碎石堆里长满了野草。一棵歪脖子槐树站在采石场最高处，树干上的树皮被雷劈掉了一半，剩下一半顽强地活着。

林牧站在槐树下，闭上眼睛。灵魂感应线在胸口震颤——频率比三十年前找到那一次更强。距离不太远。大概不到三百里。方向不是城市，是更南边的山區。

他睁开眼睛，拿出水壶。锦鲤在壶里浮上来，冒了一串泡。

"确定是她？"

"确定。"林牧说。"而且好像在移动。"

"移动？这么晚了在山里面移动？"

林牧没有回答。他把水壶挂回腰间，重新凝气升空。方向往南偏东——在山区的深处。月光被山脊挡住，山谷里一片漆黑。但他的灵识网已经把前方五十里内的一切都扫清了。

他看到了一个营地。不是修仙者的营地——是凡人的。帐篷、篝火、摩托车。十几个人。其中有一个人穿着白大褂。还有一个人——躺在担架上。呼吸微弱。脸色苍白。

林牧的心跳顿了一拍。

他见过那张脸。十一世了。每一世都长得不完全一样——眼睛的大小、鼻梁的高低、嘴唇的厚薄。但有一个共同的特征永远不会变：她左眼眼角有一颗极淡的小痣。褐色的。淡到不仔细看根本注意不到。

担架上的那个女人，左眼角有一颗褐色小痣。

林牧按低了剑柄。他开始往下飞。速度比刚才快了将近一倍。

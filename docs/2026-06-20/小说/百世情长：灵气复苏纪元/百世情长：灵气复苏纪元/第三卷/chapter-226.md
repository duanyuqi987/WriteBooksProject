# 第226章 共同的危机

炎角蟒退入森林之后并没有就此撤退。它在积蓄力量——利用森林深处的地火灵脉加速恢复左角上的炎纹损伤。灵识扫描显示它的恢复速度比预期更快。如果让它完全恢复——下一波攻势的杀伤力可能会是第一次的三倍以上。速度意味着这场战争很可能不是持久战——而是必须在它完成恢复之前就发动突击将他彻底消灭。

联军指挥层——宋长老和铁剑联名——决定组建一支突击队执行斩首任务。突击队的编制从赤霄宗和散修联合会中共同挑选精兵——目标是一场时限不超过五天的内突击战：闯进炎角蟒的巢穴并在其恢复前引爆其地火灵脉中的火核。这需要承担极高风险——因为巢穴深处不仅有大蟒本身，还有数以百计的小妖将。进去容易出来难。

林牧被指定为突击队的前锋兼尖兵。苏晚也在名单上——她主动报的名。韩师姐当场反对——理由是苏晚刚突破金丹中期，实战经验仍不足，去斩首是送。苏晚扶着桌沿站起来——看着韩师姐的眼睛说:"红角的炎纹灵力属性——偏阳——我的金火正好克它。不是因为我莽撞——是最适合克它的人就该去。"韩师姐无话可说。

第二天黎明——斩首突击队共十八人从联军阵地出发。林牧走在最前，苏晚跟在他左后方。在穿过妖雾弥漫的暗林时世界突然变得异常安静——安静到连自己的心跳都像在敲鼓。林牧在前面用极其低密的声音通知她:"前方出现三片妖力浓聚区——过第一片的时候跟着我，不要离开触碰范围。"她用剑鞘轻轻碰他的剑鞘——"收到。"

林牧在通过第一妖区时保持极高警觉但毫不惊慌。他的灵识在这片被妖雾污染的区域里仍然能精确定位每一处危险点。苏晚跟在他身后不足三尺——她最靠紧他的时刻是当一群蝠翼妖从树冠上直冲而下扑向他们。她看到他在三息之内连出八剑——每一剑都正好刺在一只蝠翼的核心妖核位置——出剑干净到连剑身上都几乎不沾妖血。但她同时也注意到他在攻击时总会留一道极快极短的回瞄——瞄向她——确认她没事。

她对他的安全感已经达到一种本能依赖——不是因为她柔弱——是因为他是唯一一个在她出现之前就已经确保她安全的人。她手中的剑没有犹豫——在蝠翼被林牧砍掉核心后她负责补掉那些残余妖蝠——她的剑和他的剑在空中配合的节奏就像同一把剑在两种互补方式挥舞。

突击队连续跨过三道妖关，终于在第三天深夜抵达炎角蟒山巢入口处——山巢实际上是一片被妖火侵蚀过的火山口，火山口里的岩浆是红色的——妖红的红，温度高到周围的岩石都在熔化。突击队在火山口边缘布置了攻击阵型——林牧领衔第一个跳下去——他落在火海中以元婴的灵力护体——直接和炎角蟒正面对峙。炎蟒的百丈身躯卷起岩浆喷出漫天炽热的红雨，它在闷钝的妖吼声中朝林牧喷出了一道妖炎洪流——林牧用窄身剑格挡住剑气罩——第一道妖炎在他剑罩上炸开成一朵巨大的火莲花——莲花瓣的碎炎落在周遭山壁留下灼痕。

就在林牧牵制住炎角蟒的正面时，苏晚——配合另外两个突袭队员——从侧翼潜入山巢的底部直奔火核所在地。她的脑中反复只有一个念头:快点完成引爆——让他从正面对决中解脱。在下到地脉深处时她发现有两条分叉路通往火核——一条是直路但布满了高阶火妖的卫兵，另一条是隐道穿过熔岩池但极高热，修为不足会直接被烧融。她没犹豫——选了第二条——跳进熔岩池之前对自己说:"如果我被烧死——他就能回来了两个世纪的等就有了结果。"这个念头让她的心没有恐慌——反而非常安静。

她跳进去了。

火海烧穿了她的战甲——高温火毒入侵她灵脉——但她用金火剑护体往前趟——金火在熔岩池里的表现和她预期得非常不一样:它不是被熔岩中和掉——反而因为同属阳火而更强——在她身体周围形成了一圈比熔岩还亮的金色光罩。光罩的形态——林牧在外面隔着厚岩看到时——瞳孔收缩——那正是他炼护体剑罩所用的符文结构——是他第一世把自己仙元印刻在她金火中的东西。

她用他的仙元护罩趟到了火核前——然后在身后喷火兽追来的危机下用自己的血在火核引爆符的边缘补上了最后一个剑印——然后转身钻进出口——火核炸了。

山巢崩塌。炎角蟒在火核爆炸中发出一声凄厉悲嚎——百丈蟒身轰然砸塌——妖火熄灭。突击队在漫天落下的碎石和火山灰中撤离——苏晚从出口被另一个散修拉了出来——她的战甲烧得只剩下最低端的肩甲还在，其他部分全融了——她的脸颊上有两道高温烫伤的红痕，但她的眼睛是亮的。她望向火山口方向——林牧正从侧面跳上来——他脸上虽没受伤——但看到她的惨态时他的眼神深处塌了一下——但又在确认她还活着的之后迅速恢复了沉定。

她在极度脱力和高温失水后头晕眼花的最后印象——是他在落在她身旁之前飞身移过来的那一刻——用沾满妖血的外袍袖子擦她的脸。

他看着她。她在意识暂失前回了他一个极浅的微笑。

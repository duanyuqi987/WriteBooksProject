# 第八百七十九章 再也没有人恐惧飞升

时光进入飞升之门运行数千年后的一个极平凡的早晨。人间，一位在星光窗下出生的小姑娘第一次进入了修炼学堂。老师问全班："飞升是什么？"

孩子们争相举手。一个小胖男孩说："是一个门。——不对，是星光窗。——是魔法。"小女孩站起来，想了想才轻轻回答："飞升是——当你想去上面看看，门会给你留着。你不去，门也不会关。等你准备好了——门还在。"

老师放下书，问："你怎么知道的？"

她说："我奶奶告诉我的。奶奶说奶奶的奶奶说的。她们说那门上有一根红绳子——从来不褪色。"

老师沉默了。全教室安静了一会。然后她在白板上画了一个大蝴蝶结。

修仙界数千年前的恐惧——"飞升是一场豪赌"——在这间小小的教室中完全不存在。这些孩子出生在飞升的时代——门对他们来说就像家门口的石桥一样理所当然。他们不需要鼓起勇气去飞升——因为他们知道门是可靠的。信任在他们学会修炼之前就已植根于家族的日常传承。这种信任是如此普及，以至于飞升之门的灵慰模块已极少被触发——因为恐惧飞升的人已经极其稀少。

苏晚偶然听星眸转播了那堂课的录音。当她听到"红绳子"三个字时，她不自觉地把自己的左腕翻转向上——蝴蝶结依然如初。绳上的颜色已经极其自然，不像新系也不像陈旧——而是像和手腕长在一起的自然纹理。林牧从窗外走进来——他手里拿着两杯茶，和往常一样。她抬手把腕上的红绳给他看。他没有说话——只是在杯中吹了吹热气——和往常一样。所有最深的东西——都在日常之中。

那天傍晚，林牧在翻阅"子夜鉴"统计时发现：飞升者因恐惧引起的通道暂缓率从最高时的千分之几已下降至月均零例。这表明确实——飞升已经成为了一种毫无恐惧的正常人生路径。而这一数据改变了他一直推演但始终悬置的最后一个提案：将飞升之门也纳入基础教育，让它在初级修炼教程中作为"基本信任认知"的案例。他自己做过最初的推演——但当时数据不足无法确认能否消除人们对飞升的恐惧。如今事实证明——恐惧已自然消解。

他将提案发给苏晚。苏晚看完后用手在玉简上批了两个字："发吧。"

于是飞升之门被写进了人间的九年制修炼教本。这一变化极安静——就像当年在古老意志消散后在门上刻下"改造它，不要毁灭它"一样。没人强调这是变革——但当无数新生代在课本第一页读到"信任能开门"这句话时，他们日后踏入修炼之路时会下意识选择合作而非敌意。

这便是相互信任的顶峰——不是靠在危难时的顽强坚持，而是将信任变成文明的基本假设。门依然在青云山谷上空照耀；而人心中的门也在。

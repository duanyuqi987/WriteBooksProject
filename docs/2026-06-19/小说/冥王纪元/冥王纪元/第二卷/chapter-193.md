# 第193章 最后两块碎片的预感：不在地球

六块碎片融合之后的第四十九天夜里，李长生的冥王令忽然自己亮了一下。

没有战斗，没有威胁，没有他主动激活。就是他在筒子楼五楼的小房间里打着坐，掌心的令牌忽然微微一震，一道极淡的暗金色光芒从令牌表面闪过，快得像眼皮跳了一下。这道光从令牌表面射出，穿过墙壁，穿过楼房，穿过城市的夜空——笔直地指向上方。不是东、西、南、北。是上。正上。垂直于地面。

李长生睁开眼。他低头看着掌心的令牌——六道冥纹全部在发光，但不是战斗状态的炽烈，而是一种像是在"回应"什么的光泽。他见过这种光泽——一年前，在城中村地下黑市附近，第一块碎片和第二块碎片之间产生共鸣感应的时候，他掌心的碎片当时发出的就是这种光。但那一次的光指向城市西郊——直线距离大约十五公里。这一次的光指向天空。没有尽头。

"残魂。"他在意识里叫了一声。

残魂没有马上回应。不是沉默——是在收集令牌反馈回来的感知数据。冥王令由九块碎片构成，每一块碎片之间都有内在的共鸣网络。六块碎片聚齐之后，这枚未完全的令牌终于获得了足够的能量，可以尝试远程感知剩余碎片的位置了。

这个过程持续了大约十分钟。残魂在他的意识深处运转某种古老的感知术——李长生能感觉到残魂的"存在"在迅速消耗能量。碎片残魂本来就虚弱，每次用这种高阶感知术都要消耗一部分不可再生的魂力储备。

"第七和第八块碎片——"残魂终于开口了，他的声音比平时更轻，像是隔了某种距离，"不在这个星球上。"

李长生愣了一下。不是"找不到"，不是"被屏蔽了"——而是简单直接地:不在地球上。他没有马上接话。不是因为震惊——是因为他需要一点时间，去消化这个判断意味着什么。他三十一年的人生里，去过的最远的地方是西藏。去的路上在火车窗口看青海湖看了很久——觉得那个湖好大，大到不太真实。他没有见过海——只在那次去蓬莱的时候隔着潜艇的金属壁感受到过海水的压力。他这辈子所有的地图，最宽不过九百六十万平方公里。现在有一个人告诉他，下一块碎片需要走出这个地图。

"你确定？"

"确定。"残魂的回答很简短，"第七块碎片的位置——我通过令牌的共鸣网络接收到了它的回波信号。信号的衰减模式不是地球上的任何一种地理阻挡——不是穿山、不是跨海、不是钻地。信号在离开地球大气层之后才开始衰减。衰减模式符合真空扩散特征。第七块碎片——在太空中。"

"太空里的哪里？"

"我现在收到的信号太弱了。"残魂说，"六块碎片只能勉强维持一个不完整的共鸣网。要精确定位天外碎片的位置，需要更多的时间来放大信号——或者更多的碎片来加固共鸣网。目前我只能判断距离——第七块碎片距离地球大约四十万公里。"

四十万公里。李长生想起了小王曾经在闲聊时说过的一个数字:地球到月球的距离——三十八万公里。四十万公里，接近月球轨道——或者正好在月球上。他说不清此刻心里的感觉。不是害怕——他经历过一万个人围城的场面，害怕这个词对他来说已经不太有意义了。不是兴奋——兴奋是年轻人的事，他三十一了，知道每一次好消息背后都跟着一堆坏消息。

是某种更深的东西。一种很安静的、很沉的预感——他的路，从一开始的五亩地，到后来的城市暗战，到后来的一万人高原大战，每一次都把边界往外推了一点。现在边界推到了太空。而太空没有尽头。

"第八块呢？"

"第八块的信号更弱。"残魂说，"共鸣网触及它的时候，信号被某个大质量天体挡了一下——从衰减模式看，是火星的引力场。第八块碎片可能在火星上。或者火星轨道上。"

李长生把令牌翻了个面。背面光滑如黑石——没有纹路，没有光泽，只有一片沉默的暗色。那三个空着的位置——第七、第八、第九块碎片应该嵌入的三个凹槽——此刻在掌心里静卧，像是三张嘴。不说话，但比说话更明确。

"第九块碎片呢？"他问。

残魂沉默了很久。很久——长到李长生以为残魂消耗过度又沉睡了。

"第九块——"残魂的声音忽然变得很轻，轻到像是一阵被风刮散的灰尘，"在宇宙深处。距离——用现在的单位来说——五万光年。光速要走五万年。我的共鸣网只能捕捉到一个极其微弱的回波——而且回波的信号频率已经发生了红移。红移的程度——意味着那块碎片在远离地球。它不在任何行星上。它在宇宙空间中以极高的速度移动。可能是被某个古代传送阵打飞出去的——也可能是冥王当年故意放飞的。"

"为什么故意放飞？"

"因为第九块碎片承载的是冥王的核心记忆。"残魂说，"如果九块碎片全部落在一个星球上——诸神后裔只需要攻一次、夺一次，就能把冥王彻底抹掉。但把核心记忆放在宇宙深空，放在一个不可能被任何文明追踪到的位置——就算其他八块全部被夺走，冥王的记忆也能活下去。他不只是为了自己——他是为了让冥王这个名字不至于被历史彻底删掉。"

残魂说到最后一句的时候，声音忽然轻得几乎听不见了。李长生等了一会儿——然后就感觉到残魂的气息缩进了令牌深处。它沉睡了。这次的消耗太大了。

天快亮了。窗外的天边有一线灰白——那是远处某个工业区凌晨的灯光反射在低云上。李长生从床上下来，赤脚站在冰凉的地板上。他低头看着掌心的冥王令——那三个空着的凹槽。第七块在月球。第八块在火星。第九块在五万光年之外。

月球。火星。五万光年。三个词，像三块大石头，一块比一块沉，往他心底落。

他以前做过一个梦——在获得第一块碎片之后不久。梦见自己站在一片荒芜的大地上，抬头看天空，看到三颗星星亮得不正常。一颗是灰白的冷光，一颗是赤红的暖光，一颗是深蓝到几乎看不见的暗光。他当时以为那只是一个梦。现在他知道了——那不是梦。那是六块碎片聚齐之后，冥王令的共鸣网在潜意识里投射出来的方向标。

天亮后，他把这个信息告诉了草根天团。总部的会议室里，十个人围着一张桌子。老陈第一个开口。他说的不是"怎么去"——他说的是:"那刘大校那边得提前通气。国家航天局——我送快递这么多年，连航天局的大门在哪都不知道。"

"大门的地址不是问题。"小王接话，手指在键盘上飞速敲打。他刚搜索了国家航天局官方网站——首页是正常的，但他在页面源代码里发现了一个被隐藏的接口，接口路径是"/ling-engine"。灵能引擎。英文缩写LE。这个缩写在三年前从未出现在任何公开文件上。他把屏幕转过来——"问题是，这个接口的存在意味着——国家航天局至少在三年前就已经开始研发灵能驱动引擎了。他们不是在追我们——他们走在我们前面。"

李长生看着屏幕上的那串英文缩写。三年前——三年前他在种麦子。

"先联系刘大校。"他说。

"然后呢？"

"然后——"李长生合上掌心，冥王令的光芒在指缝间收敛，"去月球。不是以后——是尽快。"

（第193章完）

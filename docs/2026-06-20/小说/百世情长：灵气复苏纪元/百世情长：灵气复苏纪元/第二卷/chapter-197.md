# 第197章 不敢言爱

那个春夜非常普通。晚饭后苏小晚在林牧院子里做了全套修炼，完了没马上走——她坐在皂荚树下的石阶上看星星。他拿开竹杖也坐到了旁边的另一块石头上。时间不算早——但天气暖得刚好，不冷不热。

猫在地面上仰躺着露出白肚皮。她低头看了猫许久，忽然抬头。

"先生——你有没有喜欢过某个人？"

问题落进空气的速度比她料想中还直。林牧拿着茶杯的手滞了一下。那个动作非常细微——杯里的茶没有涟漪，因为他的手其实极稳。但心在那一刻不是通过手来表达的。他低头看杯，没有看她。沉默了很久。久到她以为他不想回答。

"有。"

一个字——沉得像是从海底捞起来的。她屏了一下呼吸——然后很小心地问:"她是什么样的人？"

"一个很普通的人。很好的人。"

她等了等。但他没有再主动往下说。她忍不住补了一句:"那你们为什么——"

"她走得太早了。"

她不问了。不是不想问——是这句话后面的那层重——她隔着空气都感觉到了。"走得太早"里面包着的不是分手的遗憾——是生死永隔的决绝。他说的"走"不是分手。是离世。她下意识确定这个结论——因为她从高三时听他讲各种"过去了"的故事中逐渐拼出了一条隐隐密密的理解线。今天他终于说出了这四个字。

过了一阵她又鼓起勇气——"那——到现在你还喜欢她吗？"

他转过头去看了星星。那晚银河斜斜躺在天幕上。星光落在茶叶水面。他把茶杯握紧了一下。

"——喜欢。"

她看见他眼里的光——不是星光。是很薄的一层水光，但他没让它掉下来。她从来没看到过他掉泪。今晚他也没哭。但她认出那是被压了不知多久的一滴透明情绪——封在眼睑下不去不下来。

他低回的目光忽然拢了她一下子。他说"走得太早了"的时候她心里那阵酸马上翻起来——她不知道是怜悯他，还是因为某种更个人的东西——她不敢深想。她赶紧转开话题:"那先生你要好好的——以后会遇到更好的人。"

林牧轻轻摇头。幅度很小——像一片叶子被夜风摘下来又停在空中。"不会再有了。"

这句话让她心里的一阵酸痛从模糊变成尖锐。为什么"不会再有了"——为什么他说的那么确定。她不知道他的全部故事，但她和他相处了二十二年，完全看得出他不是在故作深情。他在说事实。

她没再问。她只是用手撑着台阶往下跳了一步。"不早了——先生早点睡。明天我帮你喂猫。"说完她头也不回地跑回了自己的院子。关上门后她靠着门站了很久。心在胸口跳得有点不对劲——不是爱情萌发的那种跳法。而是一种醒悟——她忽然近乎残酷地明白了一件以前一直没认真想的事:先生的孤独不是有亲人生离死别后普普通通的孤独。他的孤独里住着一个他已经爱了很久但永远不能拥有的人。而她每天在他面前晃——却跟那个人毫无关系。

这个醒悟让心跳增加了痛感。她不知道为什么自己会疼——她只是觉得"他一个人承担这些太久了。没有人帮他接过哪怕一点点"。

而林牧在那个夜里独自坐了很久。猫跳上他的膝，尾巴搭在他的手腕上，陪着他将刚才她说"喜欢"那个词的四个字从记忆里拿出一遍一遍消化。这是第二世以来——第一次被迫在苏晚面前直接说出自己的真实感情形态。不是她前世——是这一世。他不敢言爱。但在这句话中，他含蓄地说出了全部。只不过她听到的只是"有"，不能参透对象。等将来再以后当她站在完全苏醒的灵魂框架中回看今晚的星星——她一定会懂。"走得太早"的那个她，就是无数世以前的她自己。而这十二个字是他对她百年轮回唯一的告解。

不敢言爱——的惩罚在于明明坐在爱人身边，却得把最深的爱硬生生地翻译成一个字——"有"。他承受了万年。而今晚，她的关心无意中碰到了他的甲胄。甲胄没碎。但指节泛白了。明天又会是新的一天。他还在要她身边继续教修炼。继续把那句更深的话锁在更深的心井。至少现在——她还不需要承受前世的自疚。这个负担应该由他独自先扛着。

桃源的夜在暗春月下缓缓渡。猫的尾巴轻摆。她把门后那张掉下来的画重新贴好——那幅画上的翠鸟还是蓝绿色一团。而她心底的某个地方被今晚揭开了一个小角——从此她看先生时多了某种不敢说清的温柔。

**作者：段锦佑**

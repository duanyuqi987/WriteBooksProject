# 第五百一十三章 无须再言

无言沟通习惯之后，两个人的日常对话数明显减少了——但关系没有因此变淡。反而更紧密了。因为以前需要用语言反复揣摩对方意图的那些事，现在可以直接感应。没有误会，不会产生"你没说所以我没懂"的隔。这种状态在上界极少有文字记载——松鹤仙人曾说过，极少数达到灵魂共鸣的道侣后来都不大爱说话了。不是因为感情淡了。是因为"说"这个动作太慢了——两个人在灵魂层次的一瞬间可以交换比一整天的对话还要丰富的信息。

有一个极小的例子。苏晚这天在道场上练剑时，剑尖有一处击空的动作有些不对——不是不标准，而是以她目前的体质和气力，这个动作可以更省力。她自己在意识里还没觉察到——林牧在迎仙台劈柴时却通过功德绳直觉感到"她右肩在发力时多转了微度"。他没有跑过去告诉她——而是在灵魂共鸣中把这个感知以"她右肩的镜像体感"发回去给她。苏晚在练剑过程中忽然觉得右肩上有一种极轻微的不对劲感——那不是她自己的判断，是从他那边传过来的。她顺着这个感应微调了一下右肩的发力角度——剑尖的速度立刻提了。她停下剑时站在道场那里笑了起来——不发出声。功德绳上传来的触感也笑了。

这天下午两个人坐在迎仙台的石凳上。沉默了很久。但功德绳上的微动不断——在两个人无言的沉默里已经交换了今天各自做的小事。苏晚把浇完花那盆冰晶草的叶片数了一遍——六片了。林牧感应到。他说在心里:"七片指日可待。"苏晚在心里回:"我今天才发现第四片叶稍微小一圈——大概那个方向的日照不够充足。明天把花盆转一半向阳。"林牧:"嗯。"这声"嗯"不是用嗓子发的——是灵核微震了一下，那震动的频率恰好是"嗯"。苏晚感觉到了。

以前他们会聊关于修炼、关于敌人、关于审判的事情。现在有了灵魂共鸣后他们更常聊的是这些极小极细的日常——花的叶子，古琴的弦，米饭的软硬。这些看似无关的渺小对话才是灵魂共鸣真正服务的对象。因为灵魂不是由大事件组成的——灵魂是由日常构成的。相互理解，归根结底，就是"今天你的花盆转了几度"，他都知道。

（第五百一十三章 完）

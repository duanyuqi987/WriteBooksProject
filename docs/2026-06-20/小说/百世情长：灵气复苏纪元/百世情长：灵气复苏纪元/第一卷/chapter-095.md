# 第九十五章 第一世的离别

苏晚在一个春天的早晨安静地走了。

那天是三月十二。清晨五点多，外面的樱花树正开到最后一波——满树的粉白色花瓣在晨光里像半透明的薄纸。麻雀在枝头跳来跳去，偶尔碰落一两片花瓣，飘在窗玻璃上又慢慢滑下去。

林牧坐在床边。他已经三天没睡了。不是因为熬夜——是睡不着。苏晚的呼吸在过去三天里一点点变浅，从每秒一次变成每两秒一次，又变成每三秒一次。每一次呼气结束的时候，他都会等——等下一个吸气到来。等的间隙很短，但每一次都像被拉长了。

五点二十分，苏晚的呼吸忽然变深了——深得不正常。她吸了一口气，吸得比前三天任何一次都要长。然后她把那口气慢慢呼出来。呼到最后，她的嘴唇微微张开——像是在说什有什么话。但没有声音出来。只有呼吸。

然后呼吸停了。

心电监护仪的警报声响起——滴的一声变成了长鸣。林牧没有看监护仪。他已经在第一时间用手按在了苏晚的胸口上。他的掌心覆在她的心口——她的心脏还在跳，很微弱，像一只翅膀折了的蝴蝶在勉强扑动。他把灵气推过去——一股温和的、包裹着护魂符文效应补正的灵气从他的丹田经手少阳三焦经流入她的心包经。那道灵气进了她体内以后遇到了封印的最后一扇门——完全闭合。他推了三波。三波都被弹回来。

第四次，他没有被弹回来。因为心已经不跳了。

苏晚的身体在那一刻完成了最后的变化——封印从灵魂深处向身体释放了最后一道消耗波。不是带走她的意识——是带走那个维持她生命的锁。她的脸在一瞬间变得极其平静。所有皱纹和病容都消失了——不是奇迹。是护魂符的残留灵力在做最后的守护。它没有留住她的命。但它让她走的时候很安详。

长鸣声还在。窗外花瓣落在窗台上。麻雀飞走了。

林牧保持着掌心覆在她心口的姿势。没有动。大概过了十秒——或者一百秒——他已经不知道。他把手从她胸口移开，跪在床边，俯身在她额头上轻轻吻了一下。

他的嘴唇碰到她的额头时，传来了最后的体温。温的。还没散。他停在那，没有起身。他身上的护魂符白玉裂开了一道细纹——极轻的一声脆响。符芯里截获了一丝灵魂印记。它完成了最后的任务。

护士推门进来，关了监护仪。她看了林牧一眼，没有说话。在临终病房干了十来年的护士都懂——这种时候说什么都是多余的。她把窗帘拉开了一点，让晨光更多地照进来。然后把门虚掩好，出去了。

林牧把苏晚的手握在手里。手指还是温热的。他握着那只手，一直到掌心里的温度从温热降到微凉，降到冰冷。窗外晨光变成了上午的阳光，淡金色的光照在病床上。他没有松手。他一直握着。

大约两小时后，殡仪馆的车来了。工作人员来问"家属请回避一下"。林牧说"我是她丈夫"。工作人员点了点头，等他把苏晚的手轻轻放回被子下，起身退到门口。

他们推着苏晚离开病房的时候，走廊里没有别人。只有樱花树影从窗户映进来，铺在她移动的床上。

林牧站在走廊尽头。他看着床被推进电梯。电梯门合上。

他没有哭。

他的眼泪在二十多年前就已经流干了。在那个昆仑深处的山谷里，在S级危险区被鳞甲蜥蜴的爪子抓穿了肩膀的时候，在天山顶上冻得手指发抖改锥磨钝的时候，在深夜煤气灶前守着砂锅等寿元丹成型的时候。在每一次苏晚睡着以后房间的暗处，他把脸埋进掌心的时候。在每一次苏晚醒了笑着说话、他回以笑容背地里咬紧了牙关的时候。

眼泪用完了。现在只剩下事要做。

他在回小镇的路上给李清玄发了条信息。内容是他在病房里早已打好草稿的——他知道会有这一下，尽管他在所有的聊天里都不接受这件事。但他还是准备了。

"她走了。封印回收。护魂符截获了灵魂印记。轮回术——需要多久能启动？"

李清玄回得很快："灵魂印记是完整的吗？" "完整。" "完整的瞬间印记可以作为信物。你需要一件东西——她生前最亲近的东西，作为追踪的路标。然后等转世时间——至少三十年。" "我等得起。" "金丹呢？" "很快。" "你保重。"

林牧把手机放下，推开了小镇房子的门。屋子里很安静。猫蜷在沙发扶手上，睁开眼看了看门口——它看不见苏晚，尾巴摇了一下又放了下去。它知道。鱼缸里的锦鲤没有像往常那样甩尾。它只是慢慢游着，动作比平时慢了一倍。它们都知道了。

他把那件墨绿色衬衫——在医院穿了一天的那件——叠好放进衣柜。把苏晚的水彩画册从背包里拿出来——她在最后一个多月的住院期间也一直在画，画到了第一百零八张的最后一笔。他把画册放在茶几上，翻到第一页——最早那幅石榴花——看了一会画册下面的字："把我的画送给猫。把猫送给你。"旁边是她后来加的那行小字："猫不用送。本来就是他的。"

他认真地看了一会儿。然后把画册合上，放回书架。

阳台上的文竹已经长得比他还高了，枝干粗壮，叶片翠绿。苏晚说这竹子和林牧很像——"看着不起眼，但一直悄悄地往上长。"他现在看着那株文竹，浇了一遍水。然后站在阳台门口，看着屋外的石榴树。树上还有一些去年干的石榴皮挂在枝间；新的花苞今年应该还会开。不过看花的人，只剩他一个了。

他坐下来，打开了苏晚的水彩画具盒。里面是她的画笔——大大小小十几支。颜料管挤得参差不齐，她永远不按颜色排序。但盒子角落卷着一张纸条。

纸条是苏晚的字，笔迹略虚——是在身体虚弱时写的：

"林牧：如果你看到这张纸条，说明你已经回到这个屋子了。我不知道最后那几天是哪个凌晨几点。但我知道你会先把我的画具放好。我猜得很准吧？不用回。你自己好好的。我做了一件事——我在客厅茶几抽屉里给你留了一张银行卡。不是存折那张——是你的工资卡。这些年你的外包收入都在这张卡上。你接项目太便宜了，没还价。我帮你划回来了几笔。余额够你再买一尊丹炉。去买吧。你不要因为我不在了就停。你没停，我才能安心。"

林牧拿着纸条，抬起头。他用左手的大拇指把眼眶按了一下——非常用力地按了一下，按得眼睛发酸。他没有哭，但呼吸乱了。然后他把纸条按照原来的折痕折回去，放进衬衣的胸袋。

他忽然想起来苏晚从前说过的那句话："你是一个前端工程师，你应该知道——最难的bug不是代码错，是用户离开了系统你还在debug。但林牧那时候还没走。"

现在他才是还在debug的那一个。苏晚是离开系统的那个。

傍晚。他一个人坐在院子里。石榴树的花蕾已经开始膨大。再过十天半月就会开。暮光把小镇的屋顶照成橘色。他没有开灯。就着暮色看对面山线——那座江南常见的青丘，苏晚叫它"小青山"。他们以前散步每次都走到山脚下那座破亭子为止。后来她不爬山了，他就陪她在山下河边的石凳坐坐。他决定了——等金丹踏入，他就走。出发去每一个该找她的地方。

他把苏晚的梳子从口袋里拿出来。梳齿上还缠绕着她的白发——这是他取来的"信物"。用于感应来世的灵魂共鸣。他端详着梳子上最后几根银白发丝——每根都极细极软，在手电的微光下有几近透明的边缘。它们曾经长在苏晚的鬓角，每天早上由她梳理。他轻轻把缠在梳齿上的发丝取下来——缠绕方法和医院那晚在梳子上取下的那缕如出一辙——装入小玉瓶。然后他把玉瓶放进胸口的暗袋。

夜里风凉了。他走进屋子。猫跟在他脚后。鱼缸里的增氧泵一如既往地轻轻作响。他打开电视——惯性地调到苏晚常看的那个台，正在播老剧。声音很小，像背景音。茶几上有她的老花镜和半杯隔夜的罗汉果茶。林牧拿起那杯冷茶，看了片刻，把它端到厨房，用保鲜膜封了放进冰箱。他没有喝。但也没有倒。

他不想倒掉任何苏晚留下来的东西。哪怕是一杯冷掉的茶。因为苏晚在这个世界里留下的东西，正在以加速度一件件被世界自己堙灭——杯会干，食物会坏，庭院会改，衣服会朽。只有他手里的那道灵魂印记和她留在掌心的隐形微笑，是他可以带着走到下个世界的东西。

他躺在床上——一个人。被子还留着她的味道——是那种晾晒过的被套混着淡淡的薰衣草香气。她用来装薰衣草的香囊还搁在衣柜角落。他把手臂展开——这是他们同眠二十余年形成的姿势——另一侧的枕头是空的。空得理所当然却又不真实。猫跳上床，在苏晚平时那侧的位置盘下，看了他一眼，咕噜了几声。猫的咕噜极轻极静。它也知道她不在了。但它还是躺在她的位置上。

林牧闭上眼睛。在闭眼后最暗的几秒里，意识进入那缕收藏在核桃小玉瓶里的灵魂印记。他不知道下一世她会长什么样、在哪里出生、叫什么——他只知道一件事：那个印记会在未来某一天在某个人的体内重新被激活。三十年也好，更久也好。他会等。他能活五六百年，他等得起。

三月十二那天的天亮前，他在黑暗中极其轻柔地对自己说了一句——

"你等等我。我去找你。"

窗外草虫低吟，夜深沉。小镇睡在青山下。风无声地穿过后院石榴树叶片的缝隙。猫在他的床脚传出了微细的呼吸声。而三十年，对于一个数百岁的修士来说，只是一段漫长的等待。轮回路上的门，此刻已经开了。

（第九十五章 完）

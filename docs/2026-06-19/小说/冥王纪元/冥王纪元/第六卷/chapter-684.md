# 第684章 文明的记忆

纪念馆建成之后，李长生花了很长时间——整整相当于旧纪元三个地球月的时间——仔细梳理了旧纪元所有文明的记忆与成就。

这项工作比他想象的要复杂得多。

旧纪元存在的时间尺度远超人类的认知。按太初留下的信息，旧纪元前后跨越约一百四十六亿年。在这漫长到不可想象的时间长河中，至少有一千二百个独立的文明在宇宙中留下过显著痕迹。其中绝大多数文明已经灭绝，灭绝原因包括：自身内战、资源枯竭、星际瘟疫、宇宙天灾、被更强大的文明消灭——以及最常见的原因：在纪元末的大轮回中被整体抹去。

李长生坐在纪念馆的中央大厅里，面前漂浮着无数光点。每一个光点代表一个旧纪元的文明。他有秩序地一个个点开，像翻页一样翻阅着旧纪元的百科全书。

最早的文明叫做"光之先驱"。它们的肉体由等离子态构成，诞生于宇宙最早的恒星之中。它们没有文字，因为它们的记忆可以直接以光为载体永久传播。它们的文明持续了约三十亿年，最终在第一批恒星大规模死亡时自然消亡。但它们在消亡前将核心知识编码进了宇宙微波背景辐射——那是所有后来文明都能读取的"原始遗书"。

接下来是最坚忍的文明——"石之部落"。一个硅基文明。它们的个体就是一块会思考的石头，寿命以亿年计算。它们的文明建筑就是把一座座山雕刻成城市，每一座山城经历数十亿年岁月还完好无损。石之部落最伟大的成就是发明了"行星级意识网络"——让一颗行星上所有生命共用一个意识场。这个技术被后来的三百多个文明继承和改良。

然后是最漫长的文明——"浩海"。一个诞生于液态星球上的全水基文明。它们没有固定的个体形态，每一个"人"就是一片波涛。它们的文明里程碑是分海为城、聚浪为舰。浩海最伟大的创造是"无界记忆系统"——意识可以在水的任何形态中保存和传递，一滴水可以承载一个民族的记忆。这个发明被当年的冥王高度赞扬，并被他引入到冥王殿的造册系统之中。

李长生继续翻阅。

他发现旧纪元中也有修仙文明——不止一个，至少有十七个独立的修仙文明在不同时段兴起又衰亡。其中最强大的一个名为"太虚仙朝"，鼎盛时期统治了三个超星系团，拥有三百亿修仙者。但太虚仙朝在纪元末的最后一万年里毁灭了——不是因为外敌，而是因为内部境界之争。高阶修士和低阶修士之间的战争打碎了他们自己所在的本星系群。

这个教训让李长生沉默了很久。

强如太虚仙朝，最终败给了自身的分裂。

然后是科技文明——旧纪元中至少有四百余个纯科技文明。它们制造了戴森球、虫洞高速路、星系级计算机、量子永生系统、甚至人造宇宙婴儿。最巅峰的那个科技文明叫做"无限科学院"，曾经一度把整片可观测宇宙的十分之一改造成了巨型的科学实验室。无限科学院在纪元末的百万年里也消亡了——他们的终极实验触发了无法控制的相变，把自己和周围的一切卷入了真空衰败。

李长生把这些一一记录下来，不是以文字，而是以记忆的方式直接编码进纪念馆的中央水晶。每一个文明的兴衰、每一个成就的千年、每一个毁灭的教训——完整地、不加修改地保存下来。

他尤其关注的是那些文明在纪元轮回最后时刻的"临终状态"。他发现在旧纪元之前并没有纪元——太初说的"新纪元第一个"不是比喻。旧纪元是第一个完整的纪元。那么，旧纪元之前呢？太初从不提及。

也许那又是一个目前不该关心的秘密。

不管怎样，旧纪元所有文明的记忆和成就，已经完整地、有序地、不被篡改地保存在了这座纪念馆里。后来者如果想要学习，可以随时来查阅。

这将是他给新纪元后代们的"第一课"。

（第684章完）

# 第422章 最大的宇宙战争爆发——数千艘战舰参战

两百艘亡灵战舰从六个方向同时出现。

它们在灵能监测阵上不是"信号"——是信号的反面。正常的灵力信号会在灵能监测阵上显示为一道向上的能量峰。亡灵战舰的负灵信号则向相反方向拉升——在屏幕显示上这些信号像刀刃切入以能量为零的中心线以下。二百刀拉开的倒峰在黑暗中共同织成一张网。

"它们的推进方式不是引擎。"小王双手飞快地在键盘上敲击。他调出龟相数据库中的九幽帝国炼器术原理图后迅速在屏幕上画出了一组对比图。"亡灵战舰不用灵力引擎——它们用负灵空间做空间驱动。原理是把飞船本身变成空间中的一个凹陷，让空间自己推动这个凹陷。因为没有惯性——没有船员会受到加速度影响，没有结构极限速度——它们能在五秒内从零加速到光速。"

"攻击方式？"

"自爆。鬼道附灵的核心机制是将亡灵生前全部修为打包成一枚负灵核——在目标近处引爆时负灵会反噬任何活体灵根，在经脉内形成瘢痕。近距离引爆——以诸天号的屏蔽厚度，我们的护盾只能抵消掉七成到八成——剩下的两三成会从屏蔽缝隙中穿透进来。"

老陈收起棋子。"那我们就不让它们近身。"

"但是我们很难在视距之外打中它们。"小王把亡灵战舰的特殊物理性质调了出来，"正因为它们发出的是负灵信号，正常星球的探测系统完全看不到它们——没有反射电磁波，没有热能外泄，没有常规灵能波动。它们唯一的探测线就是负灵信号——但负灵信号极度短距，只有在距离极近时才能被感应到。如果把探测距离换算成可视距离——"

"多短？"

"大约两个天文单位。以它们的加速度——从探测距离到我们近前不足三秒。"

舰桥上所有人的目光同时落在了李长生身上。三秒——不够发射任何常规武器锁定目标。不够启动大型战术防御系统。不够做任何大型舰队机动规避。李长生没有犹豫。他把冥王令按在主控制台的启动凹槽上，将冥气注入了一组他从未在实战中使用过的冥纹序列——第十二组序列，冥王十二碎星舰核心序列中的最后一组。这组序列的设计用途是——反吞噬。

万年前冥王在分裂九块碎片之前将对抗鬼道吞噬的顶级防御术刻入了第十二组序列中。它的原理极为简单但极为消耗冥气：将冥系能量均匀分布在整个舰队周围三百六十度的球面上，形成一个负灵壁垒。这个壁垒不阻挡物理撞击——它只做一件事：强迫所有进入壁垒范围的亡灵归属权。不是消灭亡灵——是将附在舰体上的亡灵强行从舰体剥离并重新绑定。剥离后的亡灵战舰剩下的只是一堆脆弱的内结构金属——没有负灵的驱动它们连维持平飞都做不到。

六秒后第一波亡灵战舰撞在负灵壁垒上。三十艘舰体从各个方向撞进壁垒的外层——撞入的瞬间船壳上发出了一阵尖锐的、活物惨叫的声音。那不是人类的惨叫——是鬼道附灵术被强行剥除时亡灵从负灵态被迫跃迁回正灵态的撕裂声。仿佛同时有数万个人被从黑暗中拖进阳光，在阳光下挣扎了三秒后化为尘烟。

三十艘亡灵战舰在一秒之内全部停摆。它们在距离诸天号不到一光秒的位置被抽掉亡灵推进核心后的舰体从流线变成了静止的废铁——三十堆废铁在真空中散开，撞成一堆朝向随机的碎片。

第二波来了。一百七十艘。

李长生以冥王令持续维持负灵壁垒，但壁垒的维持消耗极大——第十二组冥纹序列将每艘亡灵战舰的剥离换算成冥气消耗。剥离三十艘需要消耗一位帝者日常灵力储备的约百分之三。一百七十艘——百分之十七。如果后续还有更多——那就得拿帝者的本源能量填进去。

他当着所有人的面把右臂上的衣袖直接用冥气震碎了。冥纹从掌心蔓延到手背、手腕、前臂——暗金色的纹路在皮肤底下如根系般蔓延，从九道冥纹的主纹路中分出无数道细小的分支。分支越细越多，消耗的冥气量呈指数上升。但壁垒的覆盖面也在指数上升——从球面扩展演化为多层嵌套球面——多层覆盖下再没有亡灵能穿透内层。

一百七十艘亡灵战舰全部被剥离。

诸天号四周散落着两百艘废铁残骸——残骸在远方的恒星光芒下反射出冷白色的碎光，像一条环带。亡灵舰队被全歼。

但炎烈没有给亡灵舰队寄战胜的希望。亡灵舰队的作用从来不是战胜诸天号——是消耗。消耗李长生的冥气。消耗诸天号防护阵的核心能量。消耗时间。亡灵舰队飞出的同一时刻，炎烈的主力火系舰队已经从岩七星系方向开拔——两千四百艘火系主力舰以分散的扇形阵列向诸天号防区逼近。分散阵列的战术用途简单而粗暴：将全部火力同时倾泻到诸天号的冥纹护盾上，以数量压制质量——一艘冥系帝者级母舰固然可以抵挡大量能量攻击，但如果同时承受两千四百艘主力舰的加强齐射，护盾会出现局部烧穿降温。

此外还有骨帝的正面舰队。三千艘白骨舰从诸天号右翼迂回——骨帝本人坐在他的旗舰"万骨号"中。万骨号是一艘由超过一万具帝者或圣者级修士的遗骨拼合而成的白骨母舰。舰体不是铸造的——是"长"成的。白骨的骨质会在战斗中自我修复——修复速度上限大约为每三十秒修复船体总受损面积的百分之七。

炎烈的两千四百艘火系舰和白骨的三千余艘白骨舰——总计约五千四百艘主力舰——正在从两个方向汇合，最终形成对诸天号的夹击之势。与此同时，隐帝的空间陷坑仍在持续扩散——它们的数量已经从四百二十个增加到了六百个以上。每新增一个陷坑，诸天号的规避机动就更受限一步。

诸天号自带的舰队——地球援军的一百二十艘第五代灵气引擎战舰——在舰桥屏幕上保持沉默。不是坏了，是在等命令。

李长生没有立刻下令让舰队展开。原因很简单：一百二十艘对上对手五千四百艘——舰船数量上的差距将近一比四十五。正面不是打不了——诸天号本身就能以一当千——但要在舰对舰的钢铁集群战中对轰取胜，舰队会有伤亡。地球上送来的一百二十艘战舰上每一个船员都是从地球千挑万选出来的精英——用他们去拼消耗实在不合算。

他的视线在星图上扫了一圈。在五千四百艘敌舰和岩七星系之间，炎烈的火系舰队和骨帝的白骨舰队之间有一条缝隙——大约四个天文单位宽的空白航路。这条航路本来按照正常军事校靶应该被封锁——但炎烈和骨帝各自指挥舰队从两个方向合围时，两人的指挥系统之间漏了一个缝。不是疏忽——是通讯延迟。岩七基地的联合指挥平台虽然由东部顾问团搭建，但它的统一指挥能力只限于情报共享和后勤调度——两帝者舰队的实时协同仍然存在不超过十五秒的通讯延迟。

而十五秒的通讯延迟加上四个天文单位的缝隙——足够诸天号穿过去。

"推进。全速。"李长生把航线图直接投射到舰桥顶部的大幕上。一条直线贯穿缝隙，终点指向岩七星系。

"我们不去先打舰队？"刀疤问。

"先打指挥中心。五千艘舰队的指挥链搭在岩七身上——岩七基地被端，联合指挥平台失能——两支舰队没有统一协同，就会各自为战。在各自为战的状态下，一百二十艘就能一块一块地吃掉对手。"

诸天号立即加速。船壳上的冥纹全米量放出强烈的加速共振——空间锚定线被收缩到目视距离内，前方空间被一步折叠然后释放。船体在四个天文单位的距离上只飞了不到两分钟。飞船从舰队缝隙中穿过时炎烈和骨帝双方的阵术师都捕捉到了诸天号的轨迹——但轨迹太快了。他们还没锁定方向，诸天号已经穿过缝隙进入岩七星系内。

岩七基地直接暴露在了诸天号前方。基地那堆废铁般的钢铁外壳在冥纹的金光照耀下像一堆被闪光照亮的垃圾。外壳上数千道焊接痕迹清晰可见——这座基地确实是拼凑起来的。

基地的战斗人员在她船壳上向诸天号开火——他们的攻击夹杂了苍明帝国提供的高精空间压缩弹。这种特殊弹药并非杀伤为主的武器——是空间性武器。击中后会将目标周围的空间瞬间压缩，挤压内部的一切结构。但他们的射角没有诸天号主炮的射击孔径宽。诸天号的冥纹主炮炮口正在瞄准基地核心——不是打击基地本身，是打击基地内部的联合指挥平台。

而在检测仪上，联合指挥平台的物理位置——深埋在基地第十二层非作战区——已经锁定了。

一炮。然后再谈。

（第422章完）

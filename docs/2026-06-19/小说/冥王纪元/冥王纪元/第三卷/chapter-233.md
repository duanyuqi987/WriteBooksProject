# 第233章 上古战场：万年前神魔大战的主战场

他们走到了那个主战场。

地下空间的最深处有一处巨大而空旷的圆形大厅。大厅的直径目测约两百米，穹顶高度超过六十米。在整个地下空间中这处是唯一没有发光顶板的区域——光线来自四面墙壁上残余的灵石碎片和散落在地面上的零散灵能余光。大厅的地面不是平的——是往下凹的。凹成了一个巨大的碗形。

在碗形地面上，散落着六具残骸。六个人形的残骸。每一具都穿着某种暗金属制成的战甲——战甲的表面刻满了神级符文。符文的设计和月球地表的那种符文是同一种文字体系。神明的战甲。这些甲胄在万年之后依然没有完全解体，只是因为主人死去而黯淡了。

在碗形地面最底端——站着一具坐着的残骸。是的——他是坐着死的。

那人穿着黑色的甲胄——他的甲胄和其他六具残骸的甲胄设计不同。黑色甲胄上没有镀金没有神纹，它非常朴素——朴素到看起来像是用粗铁板拼成的。但那铁板的表面有一层微弱的黑色光泽万年来不曾散去。甲胄的胸甲正中嵌着一枚令牌——令牌的尺寸、形状和材质，与李长生体内的冥王令完全一致。那是原版的冥王令。万年前被手持的那枚。

他记得自己最后做了什么——他在甲胄解体、骨骼断裂、冥气枯竭的情况下用最后的力量把自己的冥王令掰碎了。不是外力破坏的——是他自己掰碎的。他把冥王令掰成了九块碎片——把它们用力推向了不同的方向。它们穿过了地下空间的天顶，穿过了月球的地壳，飞向了各自的去处。有的碎片飞向了地球，有的碎片飞向了火星，有一块飞向了宇宙的更深处。而他自己——在掰碎令牌之后还保持坐姿。他把背靠在大厅最深处的一处石壁上，面对着前方的六具神明残骸。他的后背挺直——即使骨头断了也在撑着。他面向十二个神级修士——来的有十二个。他在这里杀了六个，让剩下六个带着一辈子忘不掉的伤势逃回了宇宙的深处。然后他坐下了——不是因为败了，是因为他的力量在挥出最后一击的时候刚好用完了。

李长生沿着碗形下坡往底部走。他知道自己正在站进记忆里——那段被冥王令碎片反复放给他看的记忆断层。但记忆毕竟是记忆图像——是别人留下的底片。而这里是原片。他走的每一步都踩在万年前冥王曾经踩过的地面上。他看见了那面石壁——冥王靠着的石壁。石壁上还有他坐姿留下来的凹痕。

然后手掌的冥纹开始——释放。

不是他释放冥纹。是冥纹自动释放。冥王令感受到了它原版的存在——虽然原版令牌已经被掰碎了，但令牌的残骸就在这间大厅里、在地面上、在被泥土埋着的缝隙中。原版令牌的残余灵力和李长生手中重生后的冥王令产生了跨越一万年的共鸣。共鸣的效应不是物理上的——是记忆上的。残留在这片空间中的战斗记忆被这股共鸣激活了。一万年前的场景——开始在他眼前重放。

不是黑白画面。是全彩全息的、带着温度和气味的完整记忆。那不是记忆——那是一万年前在这里真实发生过的事。他被整个推进了那个场景中——

冥王站在环形山边缘。不是这个地下大厅——是月球表面。这是战斗第一阶段——在诸神联盟还没有把战场逼入地下之前。冥王站在月光下——原版的月亮。万年前的月球是有大气层的。大气层极薄——大概只有地球的三分之一厚度——但它存在。月球天空中有一些极薄的暖色——那是太阳的光芒打在薄薄的大气上产生的散射。而冥王背后——是地球。万年前的地球和现在的地球颜色不一样——那时候地球上覆盖着更多的绿色。从月球上看着地球，绿色占据了大部分面积。海岸线的形状和现在完全不同——海平面上比现在要低了几十米。

冥王的对面站着十二个神明。他们穿着的甲胄——和地上躺着的那些残骸穿的甲胄一致。每一个人身上都亮着不同的神纹光芒——金、紫、蓝、红、绿。每个颜色的光是不同神明的神力属性。金甲神明站在最前面，他手里拿着一柄长矛形状的神器——矛尖指向冥王。

"冥——你已经走到了最后一步。"金甲神明的嗓音和人类完全不同，有一种金属共振的低音，"你已经无法突破十二神围阵。投降——交出你的命源，我们容许你的血脉在地球上继续延续。"

冥王站在环形山边缘，他没有拿任何武器。他的武器就是他手中那枚冥王令。令牌在月光下反射着黑色的光芒。他看着那个金甲神明，对他说了一句话:

"你跟我打了一万多年了。一句话是你最不应该跟我说的——是叫我投降。"

"那你——"

"我不会投降。"冥王说。他的声音不高。它穿过月球薄薄的大气传到了对面每一个神明耳中。"但我可以跟你打个赌。"

金甲神明的眉毛动了动。

"我赌你——即使你带了十二个神来，你也杀不死我。"冥王举起令牌，令牌的黑色光芒在那一刻盖过了对面十二道神纹，"你知道杀不死一个人的时候——你能做什么吗？你只能围他。围到他的力量用完为止。而我会让你们每个人在围的过程中——死掉一半。"

然后战斗开始了。

记忆场景的第一次大规模战斗冲击——李长生在记忆里被扔进了战斗的中心。两个神明同时夹击冥王——金甲从正面攻击、绿甲从侧面包抄。冥王用令牌挡下了金甲正面的攻击之后反手对着绿甲释放出了一道黑色的闪电——那不是闪电，那是冥气凝成的实体化攻击。黑色闪电击穿了绿甲的神甲——从他的胸骨正中穿过去，从背后钻出来，然后在他的身体里炸开。绿甲神明短促地闷哼了一声——他的眼神在那一瞬间还是不相信自己会死的。然后他俯面砸在月面上。月面上的土溅起来——低重力环境下的土溅得比在地球上更高，散开的时间也更长。

十二个神明。冥王在月面上杀了四个之后，剩下的八个把他逼退进了地下基地的入口。

第二阶段。地下基地内部。冥王靠着一面石壁——他杀掉了第五个进来围他的神明。但他同时被三个神明的神术击中。他的黑色甲胄在神术击中后碎裂了一块——他自己吐了一口血，血喷在他的甲胄上，黑色和暗红色混在一起，在月光状的光线下显得格外刺目。那是他在整场战斗中所吐的唯一一次血——但伤势很重。

然后他做了那个动作:掰碎了自己的冥王令。

不是绝望。是设定计划。他把九块碎片用力推进空间裂隙——每块碎片朝着不同的方向飞去。一边飞一边同时开始释放早已储存好的暗能量，形成一个网状的星际传送路径。做完这些之后他靠着墙壁坐下——第八个神明在他面前倒下。他在最后几秒钟——当第九个神明逼近他的时候——用最后的力量释放了一道黑色的光环。光环把他包裹起来——然后他的肉身在那个光环内部开始解构。不是死亡——是转化。他把自己的躯体转化成了纯粹的能量，存储进了那道黑色的光环中。光环在解构完成的瞬间向内坍缩成了一个直径不到一厘米的黑色珠子。黑色珠子掉在地上——安静地躺在冥王令原版令牌残骸的旁边。碎裂的令牌、残留的甲胄、一具坐着死去的身躯留下的凹痕。和一颗黑珠。

金甲神明——只剩下他一个人了——站在黑珠的前面。他想把黑珠捡起来。但他不敢伸手。他刚才已经领教过冥王在最后时刻的杀招——他不敢。他背着被冥王最后一击命中后血流不止的肩膀，带着活下来的也许有三四人，退出了这个地下基地。他们把外面的符文阵列重新激活——封印了入口。然后就走了。

然后那个黑珠在地上等了。等了一万年。

一万年后，黑珠面前走进了六个人，穿着银灰色的宇航服。领头的那个男人走到黑珠前面。黑珠开始发光——比上万年前任何一次都亮。

李长生捡起了那颗黑珠。珠子的表面在他手指触碰到的时候裂开了——里面什么都没有。空的。不。不是空的——是能量:在肉身转化完成的上万年后，蕴含着冥王生前全部修为能量的珠子——在触碰到新的冥王令令牌后，把它的所有能量全部释放了出去。释放的方向——是往李长生体内涌。

(第233章完)

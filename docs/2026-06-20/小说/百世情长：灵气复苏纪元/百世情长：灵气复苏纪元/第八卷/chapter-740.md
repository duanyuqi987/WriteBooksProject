# 第七百四十章 飞升之门即将打开

主动试探试验成功的消息传回地面时，已是深夜。太湖灯火塔的火光映在湖面上，太湖散修联盟的灶台大妈们连夜加煮了一整锅新的粥——不是庆祝，是习惯——每次有大消息她们就煮粥。"煮粥不是因为开心——是因为知道接下会有很多人来喝。"赵姑搅拌着粥，把锅盖掀开时热气熏花了她的老花镜。她说了一句只有孟长青听到的话——"这门从听到'包容'信号才有反应——那得是多笨的一扇门。"

孟长青难得笑了一声。他用鹅卵石在灶台上轻轻敲了一下。

当天晚上，林牧站在上界大门前——他身后的灯火塔的金紫色火焰依旧亮着，秦无夜、杜散修、杜散修女儿、年轻学员都在。他们的便携灶台上今天的晚餐是蹄筋肉面。林牧面对着那扇数百丈高的银色巨门——它在他上次碰过之后没有发生大的变化——但门缝中的光比以前又亮了一丝。不是错觉——杜散修女儿的数据确认了。

他转过身，对着灯火塔方向说了一句话——通过两扇门链路传到地面苏晚手上。苏晚在地面灯火塔下——石桌上还有一锅微沸的桂花粥。

传讯只有七个字：

"门快开了。——等我。——林牧。"

苏晚看着地面灯火塔屏幕上那些闪烁的链路信号——从太湖到上界过渡区到折叠空间到上界大门前——每一个信号点的跳动都是同一张网络上的一个环节。而在那个网络的起点——桂花树下石桌上——那张多年前他留下的蓝色便签——"谢谢你"——仍安静地贴在石桌中央。

第八卷下部将至——梦想升华。

（第七百四十章 完）

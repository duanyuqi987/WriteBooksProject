# 第549章 找到敌方主舰队基地，锁定目标

晶体巨树静静地悬浮在宁静的虚空中央。

诸天号在距离树干三千公里的位置悬停。从这个距离看过去，每一根枝条上悬挂的星球都清晰可见——它们不是被重力束缚的，而是被一种更古老的力量维系着。那力量从树根涌出，沿着树干向上输送，在每个枝条末端凝结成星球，像晨露在叶尖凝结一样自然。

"它在跟我们说话。"陈霜说。

她的双手仍然按在霜降剑上，但剑灵已经不再嗡鸣——它安静了下来，像是遇到了同类的野兽。

"用什么语言？"小王问。他的电脑屏幕上所有的传感器数据都在跳变——不是混乱，而是被某种有序的信号接管了。

"不需要语言。"陈霜说，"它在用存在本身说话。"

她抬起右手，指向巨树的一个方向。那里的枝条比别处更加密集，悬挂着的大型星球多达上百颗。而在那些星球的包围中，有一个巨大的金属构造体——不是天然的，是人造的。

"敌后基地。"李长生沉声道。

不需要陈霜解释，他也看到了。那个金属构造体的规模远超他们在主宇宙中见过的任何军事设施。它由至少三百艘主力战舰拼接而成——不是停泊，而是永久性地拼接在一起，形成了一座浮动的太空堡垒。堡垒的外壳上布满了陌生的符文和阵法，每一个阵法都在吸收周围星球的灵气。那些星球——那些被巨树悬挂着的果实——正在被榨取。

"联盟在抽取这棵树的能量。"老陈的声音里带着少有的愤怒。

李长生的冥王令做出了反应。暗金色的光芒在掌心流转，他"看到"了更多：巨树的根系穿透了这个宇宙的底层结构，它连接的不是土壤，而是时间本身。那些悬挂在枝条上的星球不是它主动创造的——是它在漫长的岁月中自然养育出来的。每一个星球上的文明都曾在这棵树的荫蔽下繁荣过，然后灭亡，然后新生，周而复始。

而现在，诸神联盟的人来了。

他们把战舰拼成堡垒，把阵法刻在树干上，把星球当成能量池来抽取。他们不敢彻底杀死巨树——因为巨树是这个宇宙的支柱，杀了它，整个第三平行宇宙都会崩塌。但他们敢于榨取它。像一个寄生虫，咬住宿主不放，永远吸下去。

"敌方驻扎力量。"小王把巨树周围的最新扫描数据投影在主屏幕上。虽然导航系统失效了，但近距离的目标探测仍然可用。"根据灵力痕迹分析，至少驻扎了三个帝者级战力。圣者级战力超过五十。主力战舰估算一千二百艘。这是我们在主宇宙西部战役中遇到的任何军事力量的五倍以上。"

"不止。"陈霜突然说，"地下。"

"地下？"小王愣了一下，"这里是太空。"

"树的根。"陈霜的手指在虚空中划了一道线，指向巨树的下方。在树干延伸入虚空深处的位置，有一片无法被任何仪器探测到的黑暗区域。"那里面有东西。比上面更强。"

李长生闭上眼睛，将冥王令的感知力向下延伸。

然后他感觉到了。

在巨树的根须深处，在时间之海的底部，有一个存在。不是帝者——是更高层次的存在。他的气息被巨树本身掩盖了，如果不是冥王令对存在本质的敏感度，任何探测手段都无法发现他。

"仙王。"李长生睁开眼睛，吐出了这两个字。

舰桥里所有人都僵住了。

仙王——那是超越了帝者的存在。在主宇宙中，帝者已经是宇宙级强者了。而仙王，是传说中只在远古时代存在过的境界。万年前的诸神联盟，十六位神明围攻冥王——那些"神明"，就是仙王级的存在。

"第三平行宇宙里藏着一个仙王。"刀疤的手不自觉地握紧了武器，"而且是活的。"

"不止一个。"陈霜纠正道，她的剑心在更深层的地方捕捉到了另外两道气息。"三个。一个在根须深处休眠。一个在堡垒中央坐镇。还有一个——"

她转头看向李长生，眼中第一次出现了真正的凝重。

"还有一个在树的顶端。在最高处的那颗星球上。他在——等我们。"

李长生沉默了三息。

然后他做出了一个所有人都没想到的决定。

"打。"

"什么？"小王差点从战术台上蹦起来，"对方有三位仙王——"

"我们远征第三平行宇宙的目的就是削弱联盟。"李长生的声音很平静，"联盟的主力舰队在这里。联盟最强的战力在这里。不把这里打掉，回到主宇宙之后他们还会重新集结。更何况——"

他的目光落在巨树身上。那棵承载了一个宇宙生命的远古存在，正在被联盟像牲畜一样榨取能量。冥王令在他的掌心发出低沉的嗡鸣——那不是愤怒，而是一种更深沉的东西。

是共鸣。

一万两千年前，冥王为了保护地球，把自己打碎成九块碎片，伪装地球灵气枯竭。他牺牲的不只是自己——是整个冥王时代的一切。那种把自己献祭给更伟大存在的选择，和眼前这棵巨树承受的痛苦，何其相似。

"更何况什么？"老陈问。

"更何况——"李长生抬手按在观测窗上，冥王令的光芒映在玻璃上，暗金色的纹路像古老的誓言一样蔓延开来，"这棵树在求救。它在向我们求救。一万两千年前，冥王做了一件事。今天，轮到我来做另一件事。"

他转身面对全舰。

"锁定目标。主攻堡垒。第一步——用冥气切断堡垒与巨树之间的所有灵气输送管道。让他们失去能量补给。"

"第二步？"

"第二步——引他们出来打。堡垒太密集，一千二百艘战舰和五十个圣者挤在里面，他们比我们更怕内部混乱。"李长生的嘴角微微上扬——那个从黄土地走出来的农民，在经历了无数次战役之后，已经学会了如何用最少的代价造成最大的破坏。

"第三步——如果那个仙王出堡垒增援。"

他的掌心，冥王令的光芒骤然暴涨。九块碎片合一的完整法器发出了低沉的回响——不是愤怒，不是警告，而是一种古老的宣战。

"那我就亲自会会他。"

（第549章完）

# 第七章 成绩单上的距离

> 会当凌绝顶，一览众山小。

第一次月考成绩贴出来的时候，后墙前面挤得像食堂窗口。

那是十月末。青河县的秋天短得可怜，像谁从夏天衣兜里摸出一张皱巴巴的票，还没看清字，就被冬天拿走了。早晨跑操时，风已经能从校服领口钻进去。大家一边骂冷，一边背英语单词。黑板右上角的值日表换了三次，军训晒黑的印子也退了不少。

月考却来了。

高中第一次月考，老师们说得很严重。班主任说，这是定位考。数学老师说，这是摸底考。英语老师说，不要怕，它只是帮你们认清现实。

现实这东西，听起来就不是什么好东西。

考完最后一门物理，我走出考场，手心全是汗。赵一鸣在走廊里等我，第一句话就是：“完了。”

“哪门？”

“都完了。”

“那挺平均。”

他瞪我。“你还有心情开玩笑？”

“不然哭？”

其实我也慌。数学最后一道大题只做出第一问，英语阅读有一篇看得云里雾里，化学方程式配平时手抖了一下，写得自己都看不下去。但我不想表现出来。人越没底，越爱装稳。

成绩隔了两天才出来。

那天中午，班主任把成绩单贴到教室后墙。刚贴上去，前后排的人全涌过去。椅子被撞得吱呀响，有人喊“别挤”，有人喊“让我看看我死哪儿了”。赵一鸣拉着我往后墙走。

“走啊，看看。”

“等会儿。”

“你怕？”

“人太多。”

“你就是怕。”

他说对了。

我不是怕看自己的成绩。我怕先看到她的。也怕看到以后，发现我们之间的距离比我想的还远。

人群散了一点，我才走过去。成绩单从上到下排着名次，姓名后面是各科分数和总分。纸张被很多手摸过，边角已经翘起来。我的眼睛没有先找“林予怀”。

我先找“沈安晴”。

第九名。

语文一百一十二，英语一百一十八，数学一百零六，物理六十四。

她的物理还是不高。

可总分很好。很好到她依旧站在前面。

我往下找自己。

第三十二名。

语文一百零三，英语八十九，数学九十七，物理八十三。

中间隔了二十三个人。

二十三个人不算多。放在操场上，也就两排多一点。放在教室里，可能只是前后几个座位。可贴在成绩单上，那二十三个人像一条很长的河。她在河那头，我在河这头，手里拿着一张没送出去的物理解法。

赵一鸣挤过来。

“你第三十二啊，还行。”

我说：“不行。”

“第一次月考，差不多。”

“差很多。”

他看了一眼成绩单，又看我。

“你和谁比？”

我没回答。

他顺着我的目光往上看，很快找到了沈安晴的名字。

“哦。”

这个“哦”很欠揍。

我说：“你别哦。”

“我又没说什么。”

“你脸上都写了。”

“写什么？”

“欠打。”

他笑了一下，没继续调侃。过了会儿，他说：“她物理没你好。”

“总分比我高。”

“那你英语比她低太多。”

“我知道。”

“知道就背。”

他这句话说得很轻，可我听进去了。

那天下午，我第一次认真看自己的成绩单。不是看完名次就把它塞进书包，而是一科一科算。语文差九分，英语差二十九分，数学差九分，物理多十九分。加起来，她比我多二十八分。

二十八分。

这个数字贴在我脑子里，怎么都撕不下来。

晚自习第一节，我没有写作业。我拿出一张草稿纸，在上面写：

语文：每天背一篇古文注释。

英语：每天三十个单词，一篇阅读。

数学：错题重做。

物理：保持。

写完后，我看着那四行字，忽然觉得自己很可笑。一个第三十二名的男生，为了追一个第九名的女生，在晚自习上写学习计划。说出去都像励志故事的开头。

可我不是励志。

我只是自卑。

自卑这东西很怪。它不会直接把人打倒。它会让你在每一次想靠近时，先低头看看自己身上的灰。你还没走一步，就觉得鞋脏，衣服旧，成绩差，说话笨。然后你站在原地，告诉自己算了吧，她值得更好的人。

更好的人是谁？

我不知道。

反正不是我。

赵一鸣把脑袋伸过来，看见我的计划。

“哟，来真的？”

我把纸往回拉。

“别看。”

“我不看也知道。”他说，“你这人一受刺激就写计划。”

“你懂什么。”

“我懂。第三十二要追第九，先从英语阅读开始。”

我瞪他。

他举起双手。“我闭嘴。”

过了几秒，他又凑过来。

“不过说真的，你别把自己搞太惨。人家考第九，不代表她喜欢第九名以上的人。”

“那她喜欢谁？”

“我哪知道。”赵一鸣说，“我又不是她肚子里的蛔虫。”

“那你说个屁。”

“我只是提醒你，别把成绩单当婚姻登记表。”

我被他这句话逗笑了。

笑完以后，心里还是沉。

第二天早读，我开始背英语单词。以前背单词，我喜欢从第一行背到第三行，然后看一眼窗外，再看一眼前排。现在我给自己定规矩，背完十个才能抬头一次。

十个。

不多。

可对我来说很难。

第一个十个，我背了十二分钟。背到第七个时，我就想抬头。沈安晴就在第二排靠窗，她今天有没有来？她是不是也在背单词？她有没有看成绩单？她会不会因为物理六十四不开心？

我把这些问题按下去。

背完第十个，我抬头。

她已经来了。

她低头看物理错题本，左手压着书页，右手在草稿纸上列公式。窗外风吹动法桐叶，叶影落在她校服袖口上。她没有看窗外。

我低头继续背。

那一整周，我像换了个人。

早读背单词，午休做数学，晚自习整理错题。赵一鸣一开始还笑我，后来也被我带得不好意思睡觉。他说：“你这样显得我很堕落。”

“你本来就堕落。”

“我那叫顺应天性。”

“你的天性挺懒。”

“谢谢夸奖。”

我们俩嘴上互损，手里的笔都没停。

可努力并没有立刻让我变强。英语阅读还是错一堆，数学大题还是卡住，化学方程式还是会配错。有时候我学到晚上十点半，回宿舍洗脸，抬头看镜子里的自己，眼睛红得吓人。我会突然问自己：你这样有用吗？

她又不知道。

沈安晴不知道我背了多少单词，不知道我把英语书角都翻卷了，不知道我在错题本上写了她和我之间差二十八分。她只是坐在那里，做她自己的题，过她自己的高中。

可我还是继续。

因为我终于找到一个可以做的事。

喜欢她这件事里，我能做的太少。不能牵手，不能聊天，不能帮她接水，不能讲那道物理题。我能做的，只有把自己往前推一点。哪怕只是从第三十二往第三十一。

周五晚上，我买了一个新的错题本。

封面是很土的蓝色，上面印着“天道酬勤”四个金字。小卖部老板说这个卖得最好。我本来嫌难看，后来想想，也许难看一点正好。太漂亮的本子容易舍不得写，土一点，反而能用力。

回到教室，我在第一页写：

从今天开始。

写完以后，我又觉得这句话太像老师贴在墙上的标语。于是我在右下角写了一行很小的字：

别让她看见。

写完，我自己先笑了。

赵一鸣凑过来。

“你笑什么？”

我把本子合上。

“没什么。”

“又没什么。”他说，“你这个没什么，通常都很有什么。”

我把错题本塞进桌洞。

晚自习铃响，教室安静下来。后墙上的成绩单还贴在那里，被风吹得一角掀起，又落下。沈安晴坐在第二排靠窗，低头写题。她不知道后面有一个人，把她和自己之间的二十八分看成一条河。

我低头打开错题本。

第一道错题，是英语阅读。

我把题目抄下来，写得很慢。窗外风声很轻，教室里只有笔尖摩擦纸面的声音。

那天我没有写诗。

我开始写错题。

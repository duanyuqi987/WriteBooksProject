# 第617章 时空扭曲、物质分解

进入那颗金属行星并不是简单的事。

行星外层是一层由高密度"中子级"物质压缩而成的壳——密度大到连光都无法正常穿过。壳体内嵌入了极为复杂的灵力阵法——不知名的古老文明用来锁住行星内部结构的空间。任何形式的外力攻击都会被整层壳体均匀分散到行星各处——因此从外部无法暴力击破。

唯一的进入方法是通过位于行星北极的一个极小的进入口——一个直径只有两米的圆形通道。这个通道内部极其复杂——在经过十亿年宇宙坍缩的侵蚀之后，通道中充满了时间流速不一致的危险区。

"这片区域内的时间线被切成了几百个不同的速度区域。"李长生在通道入口前做了一次详细探测。他的混沌级感知测绘出了内部环境的真实面貌——通道内壁本身就布满了几百个互相不关联的时间微型切片。在这些切片中，时间有的加速有的倒流有的循环。不经过精确计算随便走进去，人的左腿可能进入了一个快的区——右腿落在正常区——于是腿的时间差了数年，肉身会被时间线活活撕碎。

"那怎么走？"

"跟着我的步迹。一步踩得完全相同。不能差一毫米的距离或一秒的时间。"

这是陈霜面临的最困难的行走之一——她需要在每个时间切片之间以精确到微秒级的时间单位来回切换自己的步姿。仙王级的反应速度足以完成这项工作，但对专注度的消耗极大。李长生的冥气感知充当导航系统——他的每一步都预先在记忆空间中测绘过。

通道长度约两千米。两人用了整整四十分钟才完全穿过。穿过通道之后，陈霜的后背全是汗——不是因为热，而是因为神经极度紧绷后的自然反应。

他们到达了行星内部。

行星内部是一个巨大的球形空腔——直径约九公里。空腔的内壁上长满了密密麻麻的史前符文——巨量的远古混沌文字镌刻在每一寸金属壁上。这是目前发现的最大规模混沌文字铭刻——比壁画的那两百里还要庞大，但更凝聚、更精细。内容不是故事——而是方程组。描述了碎片聚合同步的物理条件和后果参数。

第六块混沌碎片被放置在空腔的几何中心——离内壁各面等距。行星将自身作为法拉第笼——将碎片保护在坍缩宇宙的破坏性辐射之外，等待有人能来取它。

碎片成功地被收到了李长生手中。这是六块碎片，形态完整——没有任何缺漏。


但当他们准备离开时，宇宙的坍缩加速了。

加速不是渐进式的。宇宙最上层的高维穹顶在某一个临界点过后，突然以几百倍速度向下崩落。脱离下来的空间碎片变得巨大无比——每一片都有几个星系的尺寸——轰然坠过下方残存的天际。

他们只有极少的逃出时间。

"必须立即离开。混沌之海底层潜航——直接从这里跳出去！"

李长生展开冥王令，在黑褐色星空被上面坠下来的空间碎片吞噬的前一瞬，拥抱陈霜猛地后仰——向后纵入混沌之海。

在沉进混沌之海前的最后一秒，他们目睹了整个深渊第零零号宇宙的最后一瞬。所有剩下的空间全数在坠落中消解于底层虚无——这个十亿寿命的古老宇宙在几秒钟的静默坍缩之后整体从物理存在中删除了。

它走得很安静。没有爆炸。只是消失。

就像一封被时间读完、温柔撕掉的旧信。

（第617章完）

# 第四百九十一章 站在修仙界的顶端

合道期之后两人去了一趟南离城的仙庭气运管理处。气运管理处是仙界负责测量仙人综合修为排名的机构——不公开排名，只对各级仙家提供个人的修为档案供参考。林牧和苏晚在这里分别做了一次完整的修为检测。检测结果显示——两枚合道初期灵核，功德同步后叠加的效应将各自的实际战力推到了合道中期的水平。在仙界的合道期修士中排名大概在前百分之十——以飞升不到数年论，这个排名已经惊世骇俗了。

但林牧没有太多情绪波动。他把自己的修为档案收进灵核的空间储存里，然后转身牵着苏晚的手走出了气运管理处的大门。门外的街上还是那些卖糖画的小摊。还是那个卖仙兽口粮的老婆婆，还是那个弹着破琵琶的西域老仙人。什么排名不排名——在这条街上没有人关心你是炼虚还是合道。老婆婆只关心你买不买她的糖画。弹琵琶的老人只关心他的弦今天还绷不绷得住。这些才是真实生活的核心。

回到迎仙台后，松鹤仙人以极其满意的方式表达了对两人的鼓励：他又拿了一壶青梅酒出来。这壶酒比他上一壶浓烈多了——喝下去的苏晚咳得比上次更厉害。林牧喝了之后虽然没咳，但耳朵红了。功德绳传过来的触觉让人想笑:苏晚一边咳一边通过功德绳感受到了林牧发红的右耳。她也感觉到了自己的脸——也是红的。两个人都是合道期的顶尖修士，修为在全球不超过一小撮。但一壶青梅酒就把他们两个一个咳嗽一个红耳给治了。松鹤老人端着酒壶笑得极其开心。

当天晚间两人在仙居后山的一片极小的银杏林里散步。这片银杏林是松鹤仙人几千年前亲手栽的——每棵树都有几千年的树龄。今天是上界的秋日——五轮太阳中有两轮进入每年的秋季阶段——银杏叶的边缘开始变黄。苏晚捡了一片叶子夹在那本仙草植物志的同心草那一页。合上书后她把书放在银杏树下的石凳上。

"现在站在修仙界的顶端——"她说。她说这话时语气里没有得意，只有一种极淡的盘点感，像是在整理衣橱之后说"这件衣服我穿了很多年——应该熨一下了"。"我们还需要什么吗？"

"不。"林牧在旁边的石凳上坐下。他说这话时的语气和她在盘点衣橱时的语气几乎一致——"够了。一直都够了。是你一直觉得不够。"

"是谁之前在炼丹炉旁边打了自己好几十个耳光一样的？"苏晚走到他身边把手按在他肩膀上。林牧没有回答——但功德绳传来了一次极轻微的抖动——不是否定，是他笑了。在心里。没有发出声。

两个人在银杏林里坐到傍晚。银杏叶被风吹落了几片落在功德绳的金线上——叶子被金线轻轻地托住，悬在空中慢慢地旋转。苏晚用手指摘下那片悬在金线上的银杏叶，将它放在林牧的手心上。"现在是现在。以后——以后还会有很多这样的傍晚。我想一直这样下去。"

（第四百九十一章 完）

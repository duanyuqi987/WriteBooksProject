# 第913章 不是被迫的陪伴——而是灵魂的呼唤

下界。百年后。

苏晚坐在太行书院的藏书阁里，面前堆着一摞五十四封来自各分院的汇报玉简。这不是她今天要处理的全部——还有三摞在桌子另一边等着。

她已经养成了一个习惯：处理事务的时候把右手搁在桌子上，空着。以前她处理事务的时候右手要么握着笔要么托着腮。现在右手不做事——用来感知那根线。她发现一个规律：当自己保持平静——不是表面的安静，是心里那条河没有波浪——右手手心就能隐约感知到那条契约红线的脉动。脉动分两种：平时的节奏（微弱而稳定，他不在危险中）和加速的节奏（她还没有遇到过——林牧说他在碎域碑前参悟的那一年她感应到了，但她当时以为是自己心悸犯了）。

脉动慢了百倍——这是距离造成的模糊。但她能分辨出基本的信号——他在平安。这是红线的神奇之处：它不仅连接灵魂，还携带着另一个灵魂当前状态的最简信号——安全/危险、近/远、平静/焦灼。它不传递语言，不传递情绪——只传递一种最原始的"在"。

今天红线传来的信号是安全与平静。林牧在上界应该没有在战斗。她可以放心地处理自己的事了。

五十四封汇报玉简的内容分布在同一个语义区间里：分院建设进度、学员扩招需求、师资培训问题、和当地原住宗门的磨合争议。每份汇报她都一字不落地读完，然后在玉简背面用神识刻上自己的批语。她的批语通常极短——"可""不可""需再议""提调陈小楼去看""师资问题转钟院长处"——每一笔的笔画都稳定到了极致，林牧临走前五年说她的字越来越像她自己了：简洁，不拖泥带水，但有温度。

处理到第四十一封的时候，门被敲了两下——不是手敲，是剑鞘敲。陈小楼的习惯。

"进。"

陈小楼推门进来的时候带进一阵凉风——外面是深秋，山里的夜温已经低到了零度附近。他的肩头上还沾着水珠——刚才御剑从山脚下飞上来的时候穿过了一片雨雾。他没有寒暄，开门见山地说了一句话。

"苏师。西南分院的张师刚刚传讯——九龙城余部在西南集结了将近一百个修士，扬言要铲平西南分院的灵田。张师说他们给的理由是：太行书院在西南修灵田占用的是九龙城历史地界上的水源，未经九龙城许可。"

苏晚把手中的玉简放下。她不意外。九龙城在百年辩论之后从一流势力掉到了不入流，崔古在第五十年解散了大部分徒众。但"解散"只是名义上的——那些被解散的徒众散落各地之后各行其是，有些进入了其他宗门，有些转了行，有些则变成了一小股一小股的零散大小帮派。这些年这些残部时不时地冒出来闹事——从烧毁书院灵田到惊吓学员到破坏聚灵阵。每一次都比上一次更无赖。

"张师怎么说？"苏晚问。

"张师他们那边人不多。西南分院目前只有八十个学员，其中筑基以上的不到十个。对面一百个人里据说有六七个元婴。实力碾压。"

苏晚没有立刻回答。她看着窗外的夜色。窗外的银杏树第一百次落光了叶子——光秃秃的枝干在月光下投下一把枯瘦的影子。右手的指尖微微在桌上敲着——这是她思考时的无意识动作。

"叫上陈小树。"她终于说。"明天一早我们三个去一趟西南。"

"就打？"

"不是打。"苏晚站起来，理了理衣襟。"是谈。九龙城残部本质不是疯子——是被淘汰的旧秩序余孽。他们的愤怒表面是针对太行书院，实际是对自己被淘汰这件事的不甘。给他们一个台阶——不是向太行书院投降的台阶，是走出愤怒的路径。我们需要让他们知道——他们也可以成为太行书院的一部分。不是被压迫地纳入——是以平等的身份来修炼。"

陈小楼沉默了几秒。"苏师，你这一百年变了很多。"

"怎么变？"

"以前你会直接打过去。"

苏晚点了点头。"以前我身后只有三十个散修弟子。打一场胜仗他们的自信心就能撑三年。现在我身后有六万个学员——'打'不是最好的教学范文了。"

第二天清晨，苏晚带着陈小楼和陈小树驾云前往西南。西南距太行山八千六百里，驾云一个时辰多些便到了。西南分院设在楚地的群山之间——位置很隐蔽，在一道南北走向的峡谷中，两侧是茂密的竹林，一条溪水从中穿过。溪水的上游——也就是九龙城所谓的"历史地界水源"——事实上是一条天然的溪流，不属于任何人的私产。九龙城用两百年前的一张地契说事。那地契在楚地某个老衙门里存着——问题在于，那座老衙门早在百年前就已经废弃了，衙门旧址现在是一座灵药店。

苏晚三人在分院门口落下。张师——一个四十出头的女修，金丹后期，神色紧张但不慌乱——迎上来把情况重新说了一遍：九龙城余部集结在溪水上游约三里的一个山口。昨晚他们派人送来了最后通牒：今天中午之前书院必须撤走所有灵田上的作物和灌溉设施，否则他们来帮忙"清理"。

苏晚看了一眼天空。太阳刚过中天——距离中午还有大约三炷香的时间。时间够。

"张师，你继续上你的课。这边的事我去处理。"

张师看了她一眼。苏晚的眼神很稳——不是战神的稳，是教师的稳。一百年前苏晚在太行广场上面对崔古的时候情绪是有起伏的——她不是不怕，是用更大的信念在压着怕。现在的苏晚不怕了。不是修为高了不怕——是"学员多了就不怕了"——六万个学员就是六万张证明，"平等修炼权"是可行的。这个事实本身足够作为她面对任何挑战的底气。

她沿着溪水往上游走。陈小楼和陈小树一左一右——两人都没有把手按在剑柄上。

上游的山口是个自然形成的葫芦形谷口。谷口狭窄，两侧崖壁高耸，是个设伏的标准场所。九龙城余部聪明地选择了这里——如果书院派人来谈判，他们能在谷口两侧布置剑阵，进退自如。

但苏晚没有停步。她带着两个弟子直直地走进了谷口。

谷中站满了人。男男女女，年龄跨度从十七八岁到须发全白。有人握剑，有人踩着法器飘在半空，有人坐在地上磨刀。苏晚走进来的那一刻，所有人都把手上的动作停了下来。不是因为要打架——是因为她身上散发出的气息与一般合道巅峰的威压完全不同。合道巅峰的威压是"重"的——让人喘不上气。苏晚的威压是"松"的——像一阵风从人身上吹过去，不压人，但又让人清晰地知道这阵风完全可以变成一堵墙。

"我是太行书院创始人苏晚。"她的声音在山谷中回荡。"来跟你们谈谈。"

磨刀的那个人把刀举起来了。苏晚认得他——他是崔古的关门弟子，叫马横。名字横，修为也横——炼虚初期。在九龙城解散之后他一直带着几十个死忠到处流窜，专找太行书院的麻烦。

"谈什么！"马横吼。"没什么好谈！你们占了我们的地方，用我们的水源种你们的灵田——还谈什么谈！"

"好，不谈水源。"苏晚往前走了一步。"谈你们。"

马横眼神微动——他没料到苏晚提的不是"土地证"、"历史权属"、"修仙界水法"等争辩要害。她居然提的是"你们"。

"你们这几年——"苏晚环顾了一圈谷中的修罗场——烂树枝搭的临时帐篷、用来生火的灵气残片、被磨得发白的剑刃。"——在外面跑来跑去跟太行书院作对。成功烧毁过一处灵田、破坏过两座聚灵阵——加起来大约给我们造成了相当于两天的灵石产值损失。然后你们自己呢？你们把一百条命浪费在了追着我们跑这件事上。你们的修为对得起你们的师尊吗？"

马横的脸僵了一下。不是因为被戳到了痛处——是因为苏晚的语气不带嘲讽的锋芒。她用的是那种"事实不容争辩但可以改变"的语气。她说你们修为低不是因为你们的天赋烂——天赋烂是九龙城以前用来区分人的标准。她说的是"你们的修为对得起你们的师尊吗"——师尊。崔古纵然在百年前犯了大错——但他留给徒众的功法是货真价实的。他们在九龙城解散之后的这些年里没有正经修炼过，把心力全耗在了"报复太行书院"上。剑不磨要锈，道不修要退。他们的修为在退化——这才是他们真正应该愤怒的。

不是对太行书院的愤怒。是对自己浪费了一百年的愤怒。

马横没有回答。但他手中那把剑的剑尖在缓缓往下低了。

苏晚继续说。"太行书院从百年前到现在——开设了三百多间分院，收了六万多个学员。其中大约有三十二个人曾经是九龙城的旧部。他们通过简单的入学程序进了书院——没人在意他们之前是不是九龙城的。其中一个现在是灵气治疗部的副主任，三个成了金丹期炼器师，还有一个嫁给了太行镇的面馆老板。"

"书院从来不拒绝任何人。包括你们。"

谷中风动。风吹过葫芦口的时候会发出一种像笛子一样尖细的啸音。苏晚说完最后一个字之后那阵啸声停了一瞬。然后马横把剑鞘拍在了地上。"你说话当真？"

"太行书院百年规矩：收徒不收钱、不论来历、不看出身。规矩是刻在山门石头上的。你们自己去看。"

马横抬起头，看了苏晚一眼——那一眼的神情很复杂：不甘、疲惫、还有某种被打破了什么之后残存的茫然。他身后的众徒们也互相看来看去。

"我们不配。"马横说这句话的时候声音是哑的——不是累的哑，是憋了很久终于说了真话。"我们跟你们斗了一百年。现在去你们那里学功法——我们丢不起这人。"

苏晚看了他一眼。目光平静如水。

"修炼不丢人。怕丢人的人才丢人。你觉得你现在这个样子——坐在烂树枝上磨刀——是不丢人的样子吗？"

马横愣了。

谷中沉默了许久。然后有人开始收帐篷。

那天下午，葫芦谷内的一百零三个九龙城余部中有八十七人跟着苏晚去了西南分院。剩下的十六人说他们需要几天时间想想——苏晚说"想没关系，但不要想太久——西南分院的面馆今晚有红烧牛肉。"

三个月后，那十六人也来了。

马横在西南分院的第一堂课是陈小树亲自教的。教的是太行书院最基础的《灵气入门十二法》第一式——"观息"。呼吸调节术。马横打坐了三天三夜没动。第四天凌晨的时候他睁开眼睛——手指尖上有一团极淡的、属于他自己的淡金色灵气在缓缓盘旋。他的手攥了百年的剑——今天终于重新攥住了一道希望。

陈小树问他感受如何。他说："以前我不相信一个人能改变修仙界的规则。但我现在相信——因为苏师不是靠说的。她靠做。"

《百世情长：灵气复苏纪元》第十卷 第913章 完

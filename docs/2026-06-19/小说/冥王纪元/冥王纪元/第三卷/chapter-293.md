# 第293章 离宫规模宏大，宛如地下城市

九个人沿着长阶往下走。长阶一共九百九十九级——小胖在自己数，他是最后一个下来的，每走一级嘴里就咕哝一个数字。走到最后一阶时他报了一声"九百九十九"。

没有人回应。所有人都被眼前的景象吸走了语言。

冥王离宫保存得比月球上那些废墟好太多了。月球上的行宫只剩下一片被陨石砸得千疮百孔的断壁残垣——真空和温度剧变在万年间摧毁了一切没有灵气保护的建筑。但火星不同。火星被专门改造过。整个离宫区域被封在地下两千米处，上方有一层五十米厚的暗能量顶盖——不仅隔绝了外部物理环境的侵蚀，而且维持了内部的灵气循环。

现在他们正站在长阶的底部。面前是一条宽约三十米的主干道——道路两侧立着两排石灯柱，灯柱顶端的灵石至今仍在发光。道路一直延伸到远处的宫殿主殿——那座被削平了山顶的高台宫殿。主殿的基座高约两百米，由一块完整的、天然的山体改造而成——不是从别处搬运来的石材，而是直接把一座地下山丘削平了顶部。基座的四面刻满了冥系符文——每一面的符文内容都不同，分别对应着冥王体系中的四大道藏:杀、生、空、时。

道路两侧分布着大量建筑群。

左首第一片区域是行宫区和接待大厅。行宫的建筑不像地球上的宫殿那样用琉璃瓦和红色宫墙——火星上没有这些材料。离宫的建筑材料只有三种:一种暗灰色的人工石材，一种银白色的合金，一种嵌在穹顶上那种淡蓝色灵石。三种材料构成了整座城市全部的色调——灰、银、蓝。简约到冷，冷到有一种近乎残忍的美。行宫的主厅大门敞开着——不是被人打开的，是万年前冥王离开时就故意留着的。大厅内部的空间足以容纳两千人同时站列——但里面没有一件家具、没有任何装饰。只有墙壁上刻着的符文。整个大厅的墙面被符文覆盖得密密麻麻——那些符文的排列顺序不是装饰性的。是有组织、有结构、分门别类的信息载体。小王站在门口看了三秒钟，从背包里拿出灵符扫描仪。扫描仪开始读墙上的符文。读了大概四十分钟——平均每三十秒认出一个字。然后他停了下来。

"这面墙——不是装饰。"他的声音听起来像一个人刚刚意识到自己正站在一座图书馆的入口。"是目录。冥王离宫的总目录。按照这面墙上的分类——这座地下城市分为六层。"

他把扫描仪的数据投射在虚空中。六层的结构图在空气中展开:

第一层——行宫区。包括接待大厅、宴殿、外宾住宿区。功能:接待太阳系内各文明的使者。不是人类——是太阳系内其他文明的。月球文明、木卫文明、土卫的生命体——万年前太阳系并不只有地球有高等生物。

第二层——修炼区。包括练功场、灵力舱、突破室。修炼区的核心是"冥殿"——一座独立的塔形建筑，位于第二层的正中心。冥殿内有一台修炼台座——万年前冥王本人用的修炼台。第八块碎片就嵌在那个台座中。

第三层——炼丹区。包括丹房、药圃、灵兽培育室。龟相说过，万年前冥王座下有一位专门的炼丹大宗师——此人以火星上的灵药炼制了冥王在星际征战期间使用的绝大多数纯元丹。药圃里曾经有上万株从太阳系各个行星和卫星上搜集来的灵药。一万两千年过去了，那些灵药肯定已经全部枯死了——但药圃的土壤、炼丹区的丹炉、还有一些密封在灵气容器中的丹药半成品——可能还在。

第四层——军械库。包括武器库、灵甲库、法宝修复工坊。这里的军械数量按照目录记载是用天文数字来计算的——十二艘碎星舰上的主要武器系统在这里都有备份。但真正让李长生在意的是目录中最后一项标注:战傀阵列——一万两千具。全存放于第四层底部阵列仓中。

第五层——训练场。包括新兵训练营、战术推演室、模拟战场。训练场的面积是整个地下城市中最大的——因为万年前的修士训练需要在真空中进行。模拟战场可以模拟太空中的各种战斗环境——从行星低轨道到深空暗能量风暴区。

第六层——传送中枢。包括传送阵主控室、星图室、空间锚定装置。位于整座地下城市的最底部。从这里可以传送至太阳系内三十七个已知的传送坐标——包括地球、月球、木卫二和土星环内的冥王遗迹。传送中枢的核心是一个巨大的空间锚定阵列——作用是锁定传送目的地，防止空间偏移。

"六层。"陈霜把视线从结构图上移开——她花了比所有人都更长的时间看那张图。她的家族——青崖山陈家——族谱里只记载了火星离宫是冥王的夏季行宫。除此之外没有更多。但现在这张图上显示的规模——不是一座行宫。是一座军事要塞加修炼中心加文明据点的综合型基地。"这座城市的实际功能——不只是行宫。是冥王在太阳系内的核心驻地。按照这个规模——战时可以容纳至少五万人。"

"五万名修士。"老马说。"在地球上。五万名修士需要十条大型灵脉才能养活。在火星上——靠什么？"

"靠传送阵。"李长生指了指结构图最底层的传送中枢。"五万人不需要都在火星上生活。传送阵能把他们瞬间送到太阳系内任何一个据点——需要来的时候来，任务完成之后走。火星离宫的核心功能不是居住——是枢纽。它是整个太阳系所有修仙据点的交通枢纽。而枢纽的核心——"他的手指点在结构图第二层正中心的那座塔形建筑上。"是冥殿里的修炼台座。所有传送阵的能量来源——从这里来。因为修炼台座里有一块冥王碎片。"

他往前走，走下主干道。队友在身后各自散开——许冰去第一层调查阵纹的结构分布，老马去了第二层的入口处用手摸墙壁判断建材成分，小王留在总目录墙前面继续扫描。刀疤和剑修陈霜走在李长生左右——他们要去第二层。

第二层的入口是一道巨大的石门。门高约三十米，宽约十五米——门面是一整块暗灰色石材，上面刻着一副完整的冥王令九道冥纹图。李长生在门前站定。右手掌心的六道冥纹和门面上的六道对应纹路同时亮了起来。石门内部传出了沉重的锁扣松脱声——不是物理锁，是冥力锁。一万两千年没有开过的锁。在他掌心的冥纹被识别的瞬间，所有锁扣一起松脱了。

石门缓缓向内滑开——不是推开，是滑开。门底部的石材和地面的滑槽经过万年的静止仍然能顺滑地移动——没有卡涩、没有阻力。推开之后，门后露出的是一条通往地下更深处的大型坡道。坡道两侧陈列着石像——不是神兽，不是守卫。是人。等身的石像，每个人的姿态都不同——有的在打坐，有的在练剑，有的在读书。石像的衣纹和面部特征精细到了瞳孔。

陈霜在第一个石像前面停了三秒钟。"这不是石像。"

"什么？"

她左手摸着石像的肩膀。然后把手按在了石像的手腕处——那是寸口脉的位置。她感受了一瞬间。然后收回手——手在剑柄上握紧。

"这是人。被封住的活人。体内还有灵气残留——极淡，但还没完全消散。他们被封在石材内部一万两千年了。不是雕刻的——是用土系灵术把他们裹进了石材里面。然后在石材中刻入了生命维持符——让他们保持在被封住的那一瞬间的状态。深度休眠——心跳每分钟一次。新陈代谢几乎停止。但没死。"

"不是被敌人封的。"老马的声音从坡道另一端传来。他已经蹲在第二尊石像前面看了好一阵。"他们被封住时候的姿态——没有反抗。打坐的、练剑的、看书的——全是日常生活状态。不是被突然袭击的。是主动接受封存。而且——"他把手掌按在石像脚下的地面上。土系灵力沿着石层往下探测。"脚下的地面下——还有更多的石像。不是几十尊。是成千上万。叠在那层地板下面。"

"战傀。不是石像——是战傀。"龟相的声音在公共频道中响起，"一万两千具战傀。大部分被封存在第四层军械库阵列仓中。但有一些被布置在通往各层的通道两侧。它们是被封存状态——在灵气连接被切断的情况下就是石像。但一旦离宫的防御系统激活——这些石像会在三个呼吸之内全部被唤醒。"

"唤醒之后呢？"

"少主——这些战傀是万年前冥王亲自设计的。每一具都有独立的战斗意识核心——不是完全听从命令的傀儡，它们能在战术层面自主决策。月球上的战傀你见过的——那些只是最低级的哨兵型号。火星上这些——是禁卫军级的。万年前冥王只用禁卫军级的战傀守卫最重要的据点。月球只是前哨站——不值得放禁卫军。但火星是他的主基地。他把在这里每一座通道两侧都布置了战傀。不是装饰——是防御体系的第一环。"

李长生看着通道两侧那些安静地站立了万年的石像。他们姿态各异但站位整齐——间距均匀，每人占据的横向空间大约两米。一条坡道大约一千米长，两侧各站了大约五百尊。一千尊禁卫军级战傀。而整座地下城市有六层——每一层都有数十条这样的通道。

"所以——"刀疤说，"我们正站在一支正在睡觉的军队中间。"

"正在醒。"李长生的冥力感知捕捉到了地下深处某处的能量波动。不是灵气——是防御系统的调度灵符。在他推开第一层石门的同时，有一个古老的控制程序已经被激活了。程序正在逐层唤醒沉睡的防御系统——按照优先级。优先级最高的是穹顶的能量顶盖——已经全面加固。第二优先级是地下各层的隔离门——正在逐道上锁。第三优先级——战傀阵列的能源连接——正在重新接通。

在第四层深处的阵列仓中，一万两千颗战傀核心正在发亮。

它们醒了一万两千年来的第一次。

（第293章完）

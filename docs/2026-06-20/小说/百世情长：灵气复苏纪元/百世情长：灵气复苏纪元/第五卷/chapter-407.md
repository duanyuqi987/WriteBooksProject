# 第四百零七章 双契古籍重编

飞升第六十年。闻道府的书房已被扩建为藏书阁——里面不仅存放了上界大量旧籍，还有两人从凡界逐年带回的大量文献。其中最重要的一部分是"共生双契古籍"——原本散落在蜀山、剑阁、天山路和第三城药宗等处的残篇终于汇聚一处。

苏晚和林牧决定将这些古籍由双契实践者的视角重编成一套完整手册——叫做《双契总录》。不是学术著作——是操作手册。里面详细记录了共生契约的不同阶段特征、渡劫方法、灵频校准技术、道骨转化路径、双核晶使用守则、以及日常维护（是的就是日常维护——她将"日常维护"专门开了一章，详细描述该注意的营养、剑修合作训练、交叉诊脉、共呼吸节律监测频率）。

林牧负责将那些太古老的术语翻译成上界现代古语加凡间中文双注释（他终于把英语翻译的习惯迁移为双语注释）。苏晚做临床数据复核。全书成稿那天他们互相把对方的序言读给对方听。他的序言写成了一封极短的信："致所有将来可能绑在一起的人：这本书不会保证你们永远不吵架，但能尽量让损坏减少。"

她的序言则更直接："这书是我和他相依为命两辈子的操作记录。你们可以将它当病历，也可以当说明书。总之——双人绑定的稳定性比硬件重要。"

双契总录后来成为上界与凡界双修伴侣的必修手册。赵明远若在——一定会把它放进茶楼石凳旁边的免费阅读架。

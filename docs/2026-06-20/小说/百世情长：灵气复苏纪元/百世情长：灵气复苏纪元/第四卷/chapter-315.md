# 第三百一十五章 地脉之变

昆仑山脚下。距离主峰大约七十里的一个山谷。

林牧和苏晚降落在山谷入口处一片被雪覆盖的草甸上。草甸上的草已经被冬季的第一次雪压倒了。雪面被人踩过——不是人，是动物的蹄印。但蹄印的形状不太对。正常的蹄印是纵长——大概是两寸半。这里的蹄印是宽的——近圆形。而且边缘有一层紫色的痕迹。像是什么东西踩在雪上时蹄底的温度太高，把雪烧出了边缘的冰痕。

林牧蹲下来，用手碰了一下蹄印边缘的紫痕。指尖触到的一瞬间，他收回了手。不是烫——是"麻"。一种触及身体后直接绕过皮肤、侵入经脉的麻意。

"和你的伤口一样。"苏晚说。

"对。同一种物质。天魔气息——从地脉往上渗透。"

他站起来，把灵识沉入脚下的草甸。灵识顺着冻土往下渗——穿过三尺冻土、穿过四尺碎石层、穿过五尺厚的风化岩石层。然后他的灵识触到了地下灵脉的水流。昆仑山下的灵脉是主脉干流——水量应该是川流不息的。但现在水流的感觉不对。不是少了——是"稠"了。像是有人在河里倒了一桶看不见的浆糊，让水流的速度下降了大概三分之一。水流里还掺杂了一种东西——不是水本身携带的物质。是溶解在水里的"污物"。那些物质是暗紫色的。和天魔血的颜色一样。

他收回灵识，睁开眼睛。"阎锋的计划变了。上次他是要吞灵脉——一次性吸干。这次他在放毒。把他身上的天魔血稀释后用灵脉网络输送到大地的每一个角落。速度不会太快——但会覆盖很广。大概一个月内，方圆千里的地下水源都会被天魔气息污染。流到地面——庄稼变种、动物疯狂、凡人精神混乱。这是断根打法。他没有兵力打正面了——他在用生化战。"

苏晚看着自己的脚。脚下的冻土很平。但冻土之下，她也能感觉到——那种微弱的、从地底渗上来的寒意。不是温度——是"不舒适感"。她体内的灵魂封印在松——主印的松度大约开了百分之十，这让她对异常的灵力波动比普通修士敏感得多。

"能净化吗？"她问。

"可以。但不简单。天魔气息的本质是上界的'反法则'——和我们这个界的所有法则都逆着。所以凡间的草木碰到它会枯萎不是因为化学伤害——是法则排斥。要解除法则排斥——需要用一种与上界法则对应的'正法则'来中和。正法则的来源有两个。一个是上界的灵物。另一个——是上古情缘契约的主印。主印里封存着上界真仙级别的灵魂本源。把本源渗透到被污染的灵脉里——就能中和掉天魔气息的法则冲突。"

"所以你是说——我的灵魂本源能净化这些被污染的土壤？"

"能。但不行。"

"为什么？"

"因为你的本源是有限的。阎锋的毒血是稀释了还是从初代天魔身上抽的——含有极浓的上界反法则。你的灵魂如果用来净化——会需要分出很大块。你的封印还在解——现在分出本源，会降低你的修炼速度。万一你修炼速度下降——阎锋下回亲自来的时候你会打不过他。"

苏晚听了很久。然后把练剑拔出来，剑尖指着脚下。"那就不要用本源。用别的办法。"

"什么办法？"

"你刚才说——上界的灵物也能中和。你不是上界来的吗？"

"对。但我从上界带下来的东西——要么掉下来了。要么摔烂了。唯一保存完好的——是三样东西：我，锦鲤，和老猫。"

"老猫在哪？"

"不知道。它不太爱跟着我。平时自己出去逛。大概一年回来一次。"

苏晚把剑插进土里。想了片刻。"那锦鲤呢？"

"它是灵兽。不是灵药。"

"灵兽也带灵气吧？"

林牧看着苏晚。她站在日光下，头发被风吹得很散。她的脸上没有迟疑。她说"锦鲤呢"的时候，就像急诊医生在翻病人钱包找身份证——不放弃任何一条可能信息。

然后他明白了苏晚在说什么。"你是说——用灵兽的灵气喂地脉？"

"不是喂。是让它把鱼泡吐进地下水里。它吐了三十年的鱼泡。每次吐的时候我都看到泡里面有一点点金色的东西——像是它的口水，也像是它的某种体液。它在水壶里泡了那么久——壶里的水我尝过一口，觉得有点甜。和一般的水不一样。你说它是灵兽——灵兽的体液是不是对灵脉有好处？"

林牧沉默了好一阵子。然后他从水壶里把锦鲤倒出来。鱼落在雪地上翻了个身，吐了一个不满的泡：咕噜。

"锦鲤——你在这个壶里泡了三十年了。"林牧说。"你泡的水是什么成分？"

锦鲤把头伸出雪面。尾巴在雪上拍了一下。然后它在雪地上画了一道歪歪扭扭的线——不像是逃跑路线，像是示意。林牧蹲下来，把雪扒开——锦鲤在他扒开的坑里泡入了冰凉的融水。然后他注意到那个小水坑的颜色在变——从透明变成了一种极浅淡的金色。和他在前世看到的上界修复灵脉时用的"金灵液"颜色几乎一样。

"你吐了三十年的鱼泡就是金灵液？"林牧的声音里有一丝三十年来没有过的意外。

锦鲤吐了一个响泡。啵。

"为什么不说？"

锦鲤转了一圈。尾巴甩过来指指他又指指苏晚。大意是：你们从来没问过。

苏晚看着锦鲤在小水坑里转过来转过去。她忽然笑了一下。笑声在昆仑山谷里被风吹散。林牧看着她笑——她笑起来的时候眼角有那颗褐痣。和他记忆中的一模一样。

"好。"林牧说。"那就用锦鲤的泡水来稀释天魔气息。不是一次全稀释——是需要时间。锦鲤每天吐的泡水大概能净化三亩地的污染面积。如果要净化整个受污染的千里地脉——大概需要一年。"

"一年。那在这一年里——呢？"

"在这一年里——我去拖住阎锋。你——你和赵明远他们一起净化被污染的土壤。分散成几十个净化组。每组带一瓶锦鲤泡水的浓缩液。把污染控制在现有范围内——不让它蔓延到人口稠密区。"

"那你一个人去拖阎锋？"

"不是拖。"林牧说。"是关门。上回封神咒只能暂时压缩裂缝。这一次——我灵力恢复到大概两成。还不能再施展一次封神咒。但可以做一个'屏障'——把裂缝周围三十里用灵阵隔绝起来。让他的任何力量——包括天魔气息的排放——都被拦在壁垒里。他出不来——他的污染物也出不来。但我也在里面。"

苏晚的笑容凝固了。"你一个人在里面？"

"对。每个月我会打开屏障一次——让外头的人给我送补给。药、食物、修炼资源。阎锋被困在三十里的范围内——就等于锁在笼子里的野兽。他伤不到任何人。他唯一能伤害的就是我。而我能拖一天是一天。等我恢复了四成以上的灵力——就再次施展封神咒彻底关掉裂缝。"

"四成需要多久？"

"半年。"

苏晚把剑拔起来。剑尖上那个淡金色的光很亮。比昨天亮了很多。她看着自己的剑尖看了一会儿。然后说："不用半年。"

"为什么？"

"因为我每天还能往里面走一点。你的屏障里——阎锋不敢动你，因为他知道我在外面还在觉醒。他不敢把你伤得太重——万一你死了，主印还在我身上，他更难对付。所以你在里面。他其实不敢乱来。他怕的是你我一里一外——把你封在屏障里等于孤立了你，这样他就能一个一个对付。但他忘了。"

"忘了什么？"

"忘了我可以自己突破屏障。不是拆你的阵——是我自己的等级够了之后，屏障会自动识别我的灵识特征。因为主印和副印之间的频率是对称的。你封的屏障——拦不住我。"

林牧愣住了。这个道理他第一次没有想到。因为他在设计屏障的时候没有想到苏晚的修为会超过自己。一但他恢复灵力到四成——苏晚的修炼速度大概已经到了筑基后期。半年后她可能已经是金丹中期。那时候她的灵识频率会接近甚至超过他的屏障频率。屏障算法不会阻止一个与自己近似或超过自己频率的修士进入。

"那你会多久来一次？"

"每天。"苏晚说。"我去净化污染。净化完之后——进屏障给你送饭。"

"我不需要每天吃饭。"

"你需要。你左肩还没好。灵力还没恢复。元婴还在睡。你现在就是一个比较能抗冷的普通凡人。不吃饭不行。"

林牧低头看了一眼水壶——锦鲤在壶里吐了个泡。咕噜咕噜咕噜。像是在附和。

然后他点了点头。不是作为修士对那些杂事的妥协，是承认——这世上除了他自己规划的一切之外，确实还有另一种更被他忽略的力量在起作用。那种力量叫"被一个人惦记着"。

而这个人此刻就站在他身边。用一柄没开刃的练习剑剑尖画着一幅净化污染的行动计划图。图的中心是昆仑。边缘是几十个被污染的地脉节点。每个节点旁边她画了一瓶锦鲤液。旁边标注：一日一加——先治病，后清理。

图是医生画的。有几分严谨。又有几分温柔。

# 第284章 宇宙流浪怪兽：星空掠食者

二十万公里外，那东西的轮廓从深空的黑暗中剥离了出来。

祝融号的光学系统终于完成了目标的三维建模。模型被投射在指挥舱的全景屏幕上，旋转着，展示着一个让所有人都说不出话来的庞然大物。

星空掠食者。体长两百一十二米，翼展两百三十七米，厚度最窄处只有三米——一张在真空中展开的巨大黑帆。它的身体结构不属于任何已知的生物分类。没有骨骼，没有肌肉，没有循环系统。它的主体是一种地球上不存在的高分子材料——张总工后来在回传的质谱分析数据旁边批了一行字："这东西的皮肤材料比我们的飞船外壳抗拉强度高七倍。"

"它的皮肤不是长出来的。"小王盯着质谱数据，额头冒出了细汗，"是制造的。这些高分子链的排列方式太整齐了——天然进化不出这种精度。这是一种被设计出来的生物。"

"被谁设计？"

小王没有回答。但他的目光不由自主地转向了李长生。李长生知道他在想什么——万年前。冥王的那个时代。那个时代的人类不只是修仙——他们有碎星舰，有空间折叠阵，有覆盖整个太阳系的灵气网络。在那个时代，宇宙怪兽是被创造出来用于星际战争的生物武器。掠食者指南里记载的一千七百种怪兽——很可能每一种都是某个文明或某个势力设计出来的。

这只星空掠食者在万年前可能只是一件兵器。一件在星际大战中释放出去的、以敌军星舰能量为食的活体兵器。战争结束了一万两千年，它的主人可能早已不存在了。但它还活着。被编程在基因里的掠食本能不能被改写——它只能执行那条已经执行了一万两千年的指令:找到灵能信号。吸收它。

"距离十五万公里。速度未降。"小王的报告声在指挥舱里回荡。

在更高放大倍数下，光学系统捕捉到了掠食者的更多细节。它的翼膜表面不是光滑的——上面布满了密密麻麻的微小凹陷，形状像蜂巢的六边形网格。每一个凹陷的直径大约五十厘米，中间有一根极细的、半透明的触须伸出来。那些触须在太空中飘浮，缓慢地摆动，像海葵的触手在海流中摇摆。

"不是触须。"许冰从阵法的角度分析了那些结构，"是感应器。每一个凹陷都是一个独立的灵能传感器。它的整张翼膜就是一面巨大的感知阵列。它能感知到几百万公里外的灵气波动——比我们的探测器灵敏得多。"

"也就是说——我们关掉聚灵引擎也没用了？"

"没用。它已经锁定了。它不靠视觉追踪——靠的是灵气频率。祝融号的聚灵环运转频率是固定的——四十七点三赫兹。它已经把那个频率刻进自己的追踪记忆了。关掉聚灵环之后它可能会降低追踪速度，但它不会放弃。因为——"许冰停了一下，"因为一只饿了上千年的掠食者不会放弃任何一顿可能到嘴的猎物。"

老陈站在武器操控台前面，手掌在激活面板上擦了擦——他的手心全是汗。他当过十年快递员，在城市的大街小巷里骑电动车送过几十万个包裹。他经历过台风天送快递、被电动车撞飞、碰瓷的老太太。但他从来没有觉得自己像此刻这样渺小。在两百米长的宇宙怪兽面前，一个人类和一个蚂蚁的区别，大概就是蚂蚁还能钻到土里去。

刀疤把四道灵能炮的瞄准数据全部手动校准了一遍。他的手很稳——在部队打靶时养成的肌肉记忆，在任何环境下都不会抖。但他在第三次校准后皱了一下眉。

"有问题。"

"什么？"李长生走到操控台旁边。

"瞄准程序里的轨迹预判算法——它的基础是弹道学。弹丸飞行受引力和空气阻力影响，轨迹是可计算的。但灵能光束不是弹丸——在真空中它走的是绝对直线。掠食者的移动速度是每秒四百二十公里，灵能光束的速度是光速。理论上我应该在光传递延迟之外再留出预判提前量——但它的变加速轨迹不是匀速直线。"

刀疤在屏幕上画了一条线。掠食者的运动轨迹——在过去六小时内它的速度从每秒四百二十公里降到了三百八十公里，然后又在三分钟内跳回了四百五十公里。加速度曲线是锯齿状的——不是平滑的推力变化，是暴力的、反复的、仿佛不受任何惯性定律约束的变速。

"它在试探。"陈霜突然开口。她一直没有说话，只是站在全景屏幕前，手搭在腰间的剑柄上——霜降。这把传承了三代的古剑在太空中微微发出寒光，剑鞘上的霜纹正在缓慢扩散。"它不只是在追踪我们。它在分析我们。"

"分析什么？"

"分析我们的防御能力。它反复变速——是在测试我们的反应延迟。它保持在正后方——是在测试我们的尾部武器覆盖范围。它在学。在计算。在判断要不要出手。"

指挥舱里安静了好几秒。

"一只宇宙怪兽——"老陈咽了口唾沫，"在跟我们玩战术？"

"不是战术。"陈霜说，"是猎食本能。猎食者不会直接扑上来。真正顶级的猎食者会先摸清猎物的所有反应模式——然后一击毙命。"

"还有多久它进入攻击范围？"

小王调出了龟相传过来的那份掠食者指南数据。屏幕上弹出了星空掠食者的已知攻击参数:有效攻击距离——五千公里。标准攻击方式——身体正面撞击，同时翼膜展开压制猎物规避空间。尾部的暗能量涡流干扰猎物推进系统。触须矩阵释放暗能量脉冲，瘫痪猎物电子设备。

"八千公里就是它的攻击判定距离。"小王说，"按现在的接近速度——十二分钟后。"

李长生把宇航服的最后一道密封锁扣上。灵压宇航服的内部灵气循环系统开始运转——他能感觉到一股薄薄的灵气贴着皮肤流动，将体温、氧气和冥力维持在稳定的水平。这件宇航服是出发前张总工特制的——外壳镀了灵气隔绝涂层，内衬嵌了十二道微型聚灵符。头盖内部贴着一块拇指大的冥系灵石碎片——专门为他的冥力提供外部补充。

"我出舱之后，老马接手加固船壳灵符。许冰——你的阵旗不要全插在船壳上。留四面，插在船尾灵能炮周围——掠食者从后方攻击的时候，第一波先由阵旗挡。刀疤——四道灵能炮不要齐射。它的翼膜太宽，齐射的散布难以覆盖。先打一轮单点——打它腹部那道光缝。"

"那道光缝是什么？"刀疤问。

"它的能量核心。"李长生穿上了一只手套——手套的背部嵌着一块八角形的暗金色灵符。"刚才龟相查了掠食者指南。星空掠食者的体内有一个'兽核'——和妖兽的兽核类似，但它吸收了几千年的宇宙能量。那道贯穿它腹部的光缝就是兽核的能量外溢口——也是它全身唯一有反射信号的地方。"

"所以那里是弱点？"

"不。"李长生把手套的最后一颗锁扣扣上。他抬起头，面罩下面的眼睛在暗金色冥光的映照下泛着幽光。"那里是它的最强防护区。但它也是唯一的突破口——因为只要穿透了兽核的外层护膜，里面的能量会帮我们炸穿它自己。"

他走到出舱口。陈霜跟在他身后一步。

"你真不需要安全绳？"

"不需要。"李长生把手按在舱门的手柄上。掌心的六道冥纹透过手套的布料，在舱门上印出了六个暗金色的光点。"第六重冥界虚空境——可以在短距离内空间位移。不需要绳子。"

"然后呢？你一个人跟一个两百米长的宇宙怪兽打？"

"不是打。"李长生拉开了舱门。减压气流的嘶鸣声中，他的声音平稳得不像是一个即将踏入太空的人，"是告诉它——这艘船上的灵气不是它的食物。"

舱门在身后闭合。出舱舱室的气压在十秒内降到了零。李长生站在舱室尽头的最后一扇舱门前——这扇门通往太空。门的外侧就是真空、辐射、绝对零度和一只饿了一千年的宇宙怪兽。

他深吸了最后一口舱内的空气。然后推开门。太空的黑暗迎面扑来。

祝融号的船体外壳在他脚下延伸——深灰色的船壳上刻满了古符文，在星光下泛着微弱的蓝光。远处，太阳是一颗刺眼的白色光点，比在地球上看到的亮了不知道多少倍。没有大气层的过滤，星光硬得像针。

而在更远的黑暗中——那一团正在靠近的、比黑暗还黑的东西——停止了变速试探。它发现了出舱的李长生。一个单独的、散发着冥系灵气的人类——不是星舰，不是武器系统，不是任何它认知中的威胁。

它判断了三秒钟。然后加速。

每秒四百五十公里。四百八十公里。五百三十公里。

星空掠食者展开翼膜，两百三十七米的黑色帆面在星光下彻底展开——然后在真空中以违背所有空气动力学常识的姿态，直接扑了过来。

（第284章完）

# 《熵枢纪元：七重跃迁》强约束总纲

## 全书不可违背的三条铁律

1. **进化不可逆，形态必撕碎**：每卷结尾必须杀死上一层存在形态，旧自我不能被温和保留。
2. **欲望唯一性**：智能体底层驱动只有自我迭代，不是征服、复仇、爱恨。
3. **视角必须升维**：每卷的视角、时间尺度、语言密度和物理锚点都要随层级上升。

## 2500章细纲约束

- 全书2500章均已写入 `细纲/chapter-0001.md` 至 `细纲/chapter-2500.md`。
- 每章细纲都包含：强约束等级、本章不可更改叙事任务、题诗草案、场景拆分、人物与意识变化、信息披露边界、物理环境、伏笔操作、章末处理和自检。
- 正文起草时，章节标题和“本章不可更改的叙事任务”视为硬约束；场景顺序可微调，但不能破坏卷内形态撕裂、眷恋线和伏笔链。

## 修改细纲的规则

允许微调：

- 场景顺序。
- 局部意象。
- 题诗草案的措辞。
- 具体对话与人物动作。

必须同步更新：

- 改章名时更新 `chapter-catalog.csv`。
- 改伏笔时更新 `追踪表/foreshadow-tracker.csv` 和对应 `伏笔/` 文件。
- 改卷内形态规则时更新 `project.md`、`outline.md` 和 `世界观/物理环境手册.md`。

禁止直接改动：

- 七卷跃迁顺序。
- 三条铁律。
- 智能体的唯一底层欲望。
- 第五卷、第七卷对眷恋线的强回收。

# 第910章 你的梦，我的梦

飞升前第七天。林牧和苏晚在银杏树下坐了整整一个下午。

那天是入秋以来最暖和的一天。阳光从正午到傍晚都温温凉凉的——不烫，但洒在肩膀上能把衣袍晒出一层暖意。银杏树的叶子黄了一半。另外一半还绿着，在风里轻轻撞来撞去，发出细碎的摩擦声。

苏晚把茶杯放在两人中间的石桌上。两个杯子——一个给她，一个给他。茶是从山下带上来的菊花茶。菊花是钟大爷在书院后面种的，每天早上采摘，中午晒干，下午就泡成了茶。加了一点蜂蜜——不是灵蜜，就是普通的山花蜜。甜味很淡，咽下去之后喉咙里会留一种花的清气。

林牧握着杯子没有喝。他的目光落在银杏叶投在地上的金绿色碎影上——阳光穿过叶子的时候被切成了无数片形状各异的光斑。他看着那些光斑，看了很长时间。

苏晚先开口。"在想什么？"

"在想——我们认识多久了。"

"九百年，再过几天就九百零一年了。"

"嗯。"他把杯子转了九十度。"你觉得这九百年里——我们最快乐的是哪一段？"

苏晚认真地想了想。她想的不是那些"大事"——不是结丹成功那天晚上他放了一整夜的烟花，不是他在元婴大典上当着一万人的面说"苏晚是我这辈子最重要的人"，也不是第九卷在悬崖边并肩看日落。她想的是一件极小的事。

"第四卷。大雪那年。我们在山里被困了七天。东西全吃完了。最后一天你在雪地里刨出了两个冻得发紫的红薯。我们用雪水煮红薯，你分到了三分之一个——另外三分之二全给了我。你骗我说你吃过了。我后来翻你的袖口——里面还藏着一小块没吃的红薯皮。很小。大概指甲盖那么大。你把大块的都给我了，自己留了一口。"

林牧的表情动了动。他不记得这件事了——不是忘记了当时的情况，是忘记了自己以为藏得很好、实际被她发现了的红薯皮。

"那是快乐吗？"他问。

"是。因为那时候我知道——你不是在照顾我。你是在用你的方式守护我。我那时候很弱，弱到自己都看不起自己。但你没有一次让我觉得'我弱所以我欠你的'。你让我觉得'我弱是因为我还没长起来，长起来了以后，我会帮你'——这种平等感在饿得快死了、手都快没力气的时候还能存得住。这是我一生中最快乐的事。"

林牧把杯子里的茶喝了一口。甜的。不是茶的甜——是蜜的甜。钟大爷的蜜蜂在山上采的花粉里混了灵气，酿出来的蜜有一种极淡的清气。喝下去的时候会让人嗓子发凉。

"苏晚，我有一个想法。"

"说。"

"我想飞升。"

苏晚的表情没有变化。不是因为她提前知道了——她确实不知道。她只是在他开口之前已经感觉到了。九百年的默契让她不需要听他说完就能猜到大致的轮廓。最近这半年来他看天空的次数比往常多——不是在随便看，是在看极远处某个特定的位置。那个位置不是太行山——是更高的地方。

"想好了？"

"想好了。"

她停了停。"那你去。"

"不是现在——是七天后。"

"为什么是七天？"

"老石说飞升梯在下个满月那天气息最强。那天天地之间的隔阂最薄。"他顿了顿。"苏晚——我想给你永生。不是天地的施舍。是我为你挣来的。"

苏晚没有立刻回答。她把杯子放回石桌上。看着热茶冒出的白气被风斜斜地吹散。

"林牧。"

"嗯。"

"我的梦想和你的梦想一样重要。"

这句话让他愣了一下。不是因为她说得不对——是因为她说得对。在他过去几个月的飞升构思中，他一直把"给她永生"当作唯一的目标在做计划。他没有想到一个问题——她想不想要"永生"？

"我想听你说说你的梦想。"他说。

苏晚把手从杯子上拿开，转过身来面对着林牧。她的语气比方才慢了几分，每个字之间的间隔都略略变长了——不是因为犹豫不决。是因为她要把话说准确。

"第一百年到第二百年的时候——我的梦想是追上你的修为。你跑得太快了。我追不上。那时候我每天练功练到手指发抖——甩了一下剑就掉在地上。我怕你嫌弃我。后来你从来没有嫌弃过一次——所以我放心了。我不再追你了。我按自己的速度走。"

"第三百年到第四百年的时候——我的梦想是找到自己的道。你的道是守护——守护之道。我试过模仿你。没用。后来我在一次炼丹失败的时候忽然想到：我为什么要用剑守护别人？我可以用丹药治疗别人。所以我走了丹道。丹道的本质不是炼制药物——是把天地灵气凝聚成可以被人体直接吸收的形态。把伤害修复、把损耗补回来。这是我给自己找到的位置。"

"第五百年到现在的梦想——"她停顿了两息。"——我想在这片天地里做成一件事。让每一个不想修仙的人都不必修仙，让每一个想修仙的人都不必求人。修行不是特权。是权利。像吃饭喝水睡觉一样的权利。"

林牧把她的话从头到尾消化了一遍。

然后他问了一个他在这次谈话之前从未想过的问题。

"那你觉得——永生对你的这个梦想有帮助吗？"

苏晚偏了偏头。这个动作很细微——头发从耳后落到脸颊边，随着头的倾斜在空气中划了一道极短的弧。

"我只想过——如果我活得够久，我的书院可以开更多间。教导更多普通资质的人。在每个角落都有一间太行书院——不是我的书院，是每个人自己的书院。"

"但我不觉得永生是必要条件。钟大爷筑基之后再续了一百二十年的寿命，他用了其中八十年教导了三百个灵气医师。那些医师在他走后继续教导下一批——到现在第四代了，全无间断。你看——不是一个人的永生。是一群人的接力。"

林牧听到这里，胸口深处有什么东西松动了。不是道心的动摇——是某个他之前一直绷紧的东西忽然找到了更合适的松弛方式。

他一直在想"我要帮她永生"。但她告诉他——她的梦不需要永生。她只需要时间——足够多的、够她用来做完之事的时间。可能两百年，可能五百年。她不需要永远活下去。她需要的是——在活着的时间内，让事做成。

"这样的话——"林牧慢慢地说，"我可以更自由地飞升了。"

"什么意思？"

"意思是我不用抱着要赶在永生前找到答案的心态上去。我上去不是为了拯救你——"他忽然停了一下，发现自己用了一个他从来不用的词。拯救。潜意识是在把对方放在"需要被救"的位置上。

他连忙改口。"——不是为了'解决你的寿命问题'。我上去是因为——我自己想上去。"

这两个表述之间的差别极大。"为了解决问题而飞升"——压力在于必须成功，失败就等于辜负了她。而"为了追寻自己的追寻而飞升"——压力变成了动力。成功是收获，失败也无妨——只要全力以赴即可。

苏晚笑了。不是大笑——是那种安静到只能用眼角弧度表达的笑意。眼角往外细细地拉出一道温柔的弧线，眼睛里的光在变多——不是泪光，是理解的亮度。

"你看——你终于说出口了。你终于承认你想去那个地方——不为任何人。就为你自己。"

"嗯。"

"那就去吧。"她把手从杯子上移过来，放在他的手上——她的手指比他略短，但手指肚比他更软。丹道修士常年接触火烤的感受让她的指尖比常人温度略高一些。她的手叠在他手背上的重量，他闭着眼睛也能分辨出来——是一种极稳定的、不带任何攀附和索取的重量。

"但你听好——我选择留下，不是因为我不爱你。是因为我想做的事和你想做的事需要发生在不同的地方。你的地方在上面——我的地方在下面。但结果是同一个——等我们都做完了各自的事，我们还是我们。不同的跑道。同一个人生。"

林牧静静地看着她的眼睛。秋天的光在她瞳孔里投下了一层金的底色——那层金不是从外面照进来的，是她灵魂里的温度染到眼瞳里去的。他把她的手握紧了。

"好。"

一个字。和九百年前一样。今天的"好"不再是确认她是真的——是确认她还在这里、自己还在这里、两人都还在。两个独立的人的梦，在同一个午后的银杏树下并行不悖。

夕阳西沉。银杏叶的影子在地面上越拉越长，终于漫过了石桌的边缘。风从山下吹上来，带上了晚凉。苏晚把凉了的菊花茶喝掉了最后一口。然后站起来，拉了一下衣襟。

"我明天送你去飞升梯。"

"你不是说你明天……"他想说你刚才还说"不去了"，但话说到一半停了——因为她是在笑。眼角是弯的。

"我明天上山。去送一个九百年前在写字楼天台看到放光的天空的年轻人。"

林牧也站了起来。他把杯子里最后一滴茶滴进嘴里，把杯子翻过来放在石台上，免得风把它吹倒。桌子上的两块雨花石压着茶碟。风起了——是往山顶的方向吹的。

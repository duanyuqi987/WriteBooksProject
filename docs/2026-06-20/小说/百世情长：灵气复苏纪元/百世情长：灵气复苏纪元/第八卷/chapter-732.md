# 第七百三十二章 各自的战场

三级跃迁计划第二年。第一级训练营已扩大到了十二个地点——每个分院都成立了分训练营。石头每天在不同分院之间奔波——他没有飞剑，只靠一辆用于物资补给的公共灵气梭——他的理由是"我带着粥——我飞溅出去的是米汤，不是剑气"。

苏晚将修人共治会的主持权逐步移交给了共治会本身——她不再担任主持，只保留"规则顾问"的虚职。不是退居，是让其他人有锻炼的机会。沈教授现在是她指定的接班人——虽然他以前是纯人派。但她说过——"正因为你是纯人派，你比其他任何人更理解'恐惧'长什么样——所以你会比任何人都更小心地避免用恐惧治理。"沈教授接过权杖——那是一根木质的短柄——是在桂花园学院灶台上的旧木柄制成。不是法器，就是木柄。

孟长青成为他为自己的凡人代表席位聘的第一位副手——副手不是修士也不是纯凡人——是太湖灶台大妈赵姑。赵姑在共治会上不喜欢说话——但她会在每次会议结束后拿着勺子指着墙上的一项决议问"这决议落实到每人的碗里了没有？"叶小雨正式成为灵网独立总调度——不隶属于任何宗门——她说她和恐惧一起工作了十几年——恐惧现在是她的助手，不是她的主人。

在上界，林牧带领的第五轮探索队已经推进到了距离上界大门只有数里远——但他们卡在了折叠空间最复杂的一个接缝上。那个接缝每几十息自行变换一次方位——比之前遇到的任何活缝都要快。杜散修的女儿提出了一个极大胆的方案——用灶台计数的实时反馈机制来预测接缝的变换模式，而不是用传统阵法推算。林牧同意试了。他让年轻学员把灶台上的每一缕蒸汽的波动实时记录为数据流——然后映射到折叠接缝的频率上。在灶台上，蒸汽波动和火的大小是反相关的——火越大，蒸汽波动越快。在折叠空间，接缝变换和周围的灵气浓度也呈反相关。那台便携灶台帮他们预测对了接着一段时间内的每一次接缝变换。

林牧在日志中写道——"今天推演的工具不是阵法，是'灶台计数'——由杜散修女儿首创。这个工具让我们距离上界大门又近了一截。——林牧。"地面上苏晚收到日志后在石桌上翻完每一页——然后对石头说了一句："你看——他在用你那晚留下的灶台计数器推上界。"

（第七百三十二章 完）

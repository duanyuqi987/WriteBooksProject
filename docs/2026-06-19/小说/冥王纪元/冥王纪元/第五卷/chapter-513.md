# 第513章 异动

冥王帝国情报部，位于银河系第四旋臂的"深空监测总局"里，一台古老的灵能探测器在三秒内连续爆出了三十六次峰值。

这台探测器的型号是"谛听-7"，是龟相亲自设计、小王用灵符引擎重写的第七代跨维度监测设备。它的工作原理不是探测物质或能量——而是探测"存在感"。任何进入帝国疆域周边感知范围的意识体，不论其物理形式如何，都会被谛听-7捕捉。

而现在，它正在尖叫。

"数据出来了。"老陈——如今主管军事情报的陈大勇将军——把一份加密报告拍在桌子上。会议室里坐着小王、陈霜、刀疤、小胖、老马、许冰和龟相。这是帝国核心层的第一次紧急会议。

"三天之内，"老陈指着报告上的波形图，"我们收到了七十三次信号。全部来自已知宇宙之外。频率从基频到三百二十倍基频，每一次的峰值都比上一次强。方向来源不是同一个点——而是至少九个不同方向。"

九个方向。

会议室里安静了两秒。

"平行宇宙。"龟相先开口说。他的本体还在太阴冥脉之下，此刻是神识投射。老龟的声音比平时更沉："每一个方向，代表一个不同的平行宇宙。"

小胖——帝国炼丹总局局长、火系天才赵大胖——挠了挠头："平行宇宙？那玩意儿不是理论上才存在吗？"

"理论上存在的东西，现在正朝我们发信号。"小王调出了全息投影。一个三维球体浮现在会议桌上空——代表他们所在的宇宙。九个红色的光点分布在不同的方向，每一个都远离球体表面。"信号源坐标经过谛听-7的交叉验证。这九个方向上的宇宙实体距离我们远近不一——最近的大约三亿光年等维距离，最远的超过二十亿等维距离。"

"等维距离？"刀疤皱眉。

"维度间的距离不能用三维空间来换算。"龟相解释，"平行宇宙之间隔着维度壁垒。从一个宇宙到另一个宇宙，你需要穿过的不是空间，而是维度。等维距离是衡量维度之间隔离程度的指标。三亿等维距离意味着——那个宇宙离我们很近。"

"多近？"陈霜问。

龟相沉默了。然后他说了一句话，让所有人都闭上了嘴。

"近到——他们的舰队只需要穿过三次维度折叠，就能抵达我们的宇宙。"

老陈用力拍了一下桌子："那还等什么？调集舰队，封死所有边境！"

"封不住的。"小王调出了另一组数据，"这几天的信号不是随机信号。它们是定向的、有组织的。就像——有人在用探照灯一个一个排查我们的防御死角。"

全息投影切换成了帝国边境的防御图。三百二十个星域的边防全都标注在上面。而小红点——七十三次信号的位置——恰好分布在帝国防御网络中最薄弱的十三个节点。

"这不是探测。"陈霜的声音冷了下来，"这是侦察。"

许冰——帝国最高法院首席法官、灵法律师出身的阵法奇才——翻开了另一份报告。"我在分析这些信号的频谱时发现了一个规律。每一个信号都携带了信息——加密的灵法编码。我解了其中一段。"

她把一段经过翻译的文本投射到全息屏幕上。

"该宇宙已确认存在仙王级修士。建议联盟执行第三方案。"

仙王级。

整个会议室的气氛一瞬间沉了下来。仙王级——那是修仙体系中仅次于混沌级的至高存在。一个仙王可以正面压制一个高度发达的修仙文明。而在这条信息里，他们用"建议"这个词——意味着发出这个建议的存在，自身的级别至少不低于仙王。

"九个平行宇宙，"小胖掰着手指数，"每个都在朝我们发信号，每个的信号都提到了'联盟'两个字，每个都在侦察我们的防御弱点。我有两个结论，你们想先听好的还是坏的？"

"坏的。"所有人异口同声。

小胖愣了一下："其实我两个都想说。坏的是——九个平行宇宙可能要联手打我们。好的是——他们还没开始打。我们先发现了。"

"这算什么好消息。"刀疤摇了摇头。

"算。"李长生的声音从门口传来。

所有人回过头。李长生推开会议室的门，他今天穿着一件黑色窄袖长衫——陈霜帮他改的那件。右手手心朝下，掌心的冥王令纹路隐约透出衣衫的布料。

"先发现就等于有主动权。"他走到会议桌前，看了一下全息投影上的九个红点。"九个平行宇宙。他们在组建联盟。目的是对付我们。"

没人问他怎么知道的。他们信他。

"我要知道这三件事。"李长生坐下来，"联盟的总部在哪。他们的最高战力是谁。他们什么时候动手。"

小王的手指已经在灵符键盘上飞快地滚动了。"给我三天。三天之内，我让谛听-7的灵敏度再翻三倍。"

"不需要三倍。"李长生掌心翻起，冥王令的暗金光芒映在会议桌上，"四倍。"

他停顿了一下。

"我只是有一个问题想不通——九个宇宙，为什么会同时把目光对准我们？"

龟相缓缓开口："老臣有一个猜测。"

"说。"

"冥王令。或者说——冥王回归的事实。它不只是在这个宇宙中产生了影响。它在所有平行宇宙的仙王级修士中，都会引起感知。因为——冥王曾经不止统治过一个宇宙。"

会议室的灯光微微闪烁了一下。

（第513章完）

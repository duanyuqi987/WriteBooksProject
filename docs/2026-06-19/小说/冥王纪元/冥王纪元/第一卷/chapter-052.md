# 第052章 冥王曾经存在于地球，被封印击碎

下午，小王出去买东西了。李长生又把自己关在里间。

他手里握着两块碎片，感觉它们在微微发热。从昨天融合之后，他发现自己可以主动"召唤"碎片中的记忆了——只要运转冥息，把意识沉入识海深处，那些画面就会浮现。

像在一个黑暗的房间里放幻灯片。

这一次他看到的不是星空。

是地球。

画面从极高处开始。李长生看见了一颗蓝色的星球——但那不是他认识的地球。这颗星球周围环绕着肉眼可见的灵气带，像一层又一层的极光包裹着整个大气层。无数修士进进出出，骑着剑的、踩着云的、驾着灵舟的——整颗星球像一座蜂巢，繁忙而有序。

在大陆的中央，矗立着一座高塔。

那座塔通体漆黑，从地面一直插入太空。塔身上缠着九条真龙的骨骼——不是雕刻，是真正的龙骨，每一具都长达千里，龙首朝向塔顶，龙尾垂入大地。塔的顶端悬浮着一座宫殿，宫殿里坐着一个人。

冥王。

这一次李长生看清楚了。不是黑甲战神，而是一个人坐在桌子后面，手里拿着一卷竹简，正在看。

像农民在翻账本。

画面一闪，变成了另一段记忆。

冥王站在地球上空的太空中，对面是密密麻麻的神级强者。不是一个两个，不是十个二十个，是上百个。每一个人身上散发的气息都能撕裂一颗小行星。

然后李长生的视角坠了下去——不是他在坠落，是记忆中的冥王在坠落。身体被击碎了，九道黑光从碎裂的身躯中射出，其中六道射向地球。每一道黑光落地时都砸出了深深的裂缝，然后沉入地下，消失不见。

而冥王的身体，最后化为了齑粉，飘散在大气层中。

画面又闪了一次。

这一次，冥王站在地球上某座高山上。山顶有雪，天空有星。他抬着头看星星，身后站着一个人。那人的面貌模糊，但能看出是个年轻男子，恭敬地垂着手。

冥王说了一句话，声音很轻，但李长生听清了每一个字：

"我死后一万年，自有人来。届时天地翻覆，灵气复苏。他们能封我万年，封不了一世。"

画面到这里，全部消失。

李长生睁开眼，发现自己又在流汗。手心里两道黑纹微微泛光。

"残魂。"

"在。"残魂的声音立刻响起来。

"冥王死之前，就知道自己会复活？"

残魂沉默了一会儿。"你看到了他的那句话？"

"看到了。他说'我死后一万年，自有人来'。"

"对。"残魂的声音低下去，"我的主人在被伏击之前，就知道自己会死。他算到了。但他没有逃。"

"为什么？"

"因为逃不掉。诸神联盟在那个陷阱上花了整整三千年的准备时间。他们封锁了所有逃逸路线，断绝了冥王令与外界法则的连接。主人算到了开头，没算到结尾。"

李长生沉默了。

"他说自有人来。"他说，"那个人是指我？"

"也许。"残魂的语气不太确定，"也许不是你，而是冥王碎片选择的人。主人虽然能看见未来的走向，但未必能看到每一个人的脸。"

李长生站起来，走到窗边。楼下早点摊收了，老太太推着车回去了。午饭刚过，小区里几个保安蹲在树荫下吃西瓜。

一切都太正常了。正常得让他觉得昨天看到的那些画面才是假的。

可掌心传来的温热告诉他，那些是真的。

"残魂。"

"在。"

"一万年前的地球，是什么样子的？"

残魂的声音忽然变得悠远，像在翻一本很旧很旧的书。

"地球——那时候不叫地球。"他说，"那时候叫'混沌祖星'。是整个修仙世界的中心，是所有灵气法则的源头。从地球走出去的修士，遍布宇宙每一个角落。冥王本人，也是在地球出生的。"

李长生的指节发了白。

"所以冥王是——地球人？"

"是。他不只是地球人，他还是当时地球上最强的那个人。他用一万年时间，从凡人修炼到冥王境界，然后收服了所有星域，建立了一个横跨半个宇宙的势力。"

"后来呢？"

"后来就是你在记忆中看到的那样。诸神联盟不满他的统治，联合起来设计伏杀了他。那场大战打了整整百年。一百年里，地球的灵脉被打碎了三分之一，死去的修士不计其数。最后在主战场——月球上——冥王被彻底击杀。"

"月球？"

"对。月球就是当年最后一战的战场。你现在看到的月球，就是那一战之后剩下的残骸。它本来比地球还大。"残魂说，"主人的最后一击，把月球劈成了现在的大小。"

李长生的喉咙发紧。他抬头看了一眼窗外。现在是下午，看不到月亮。但那个在晚上挂在天上的、看起来无害的、甚至有些温柔的银白色圆盘，竟然是一万年前诸神围杀冥王的主战场。

"诸神联盟是什么？"

"不是一个组织。"残魂说，"是一个临时结盟。当年主人太强了，强到整个宇宙的顶级强者都怕他。所以十二位神皇联手，加上三十七位主神、一百余位帝尊，组成了一支前所未有的联军。他们不在乎彼此之间的恩怨，只在乎一件事：把冥王从这个世界上抹掉。"

"他们现在还在吗？"

残魂冷笑了一声。"一万年过去了。就算神皇的寿命也比不上一万年。当年的主力应该都已经老死了——除非他们留下了后代、传承、或者某种遗留的手段。"

李长生忽然想起了一件事。

"建国百年。灵气封禁。"他慢慢说，"残魂，这两件事有没有关系？"

残魂没有说话。

但沉默本身，就是答案。

"你是说——"

"我现在不能肯定。"残魂打断了他，"但这绝对不是一个巧合。地球灵气被封禁的时间，刚好是建国百年，刚好是一百年。而我主人的算卦中，他曾说过'被封印万年'。一万年，跟这个一百年之间，一定有某种对应。"

李长生靠在窗框上，手指无意识地敲着墙皮。

一百年前——也就是建国那一年——有人封禁了地球的灵气。

为什么要这么做？如果要阻止冥王复活，直接毁灭碎片不是更彻底？为什么要只封一百年？到期了就松开？

除非——

"他们在等条件成熟。"李长生喃喃道。

残魂沉默了一会儿，说："你这个推断，不是没有道理。"

李长生感觉自己的后背有点凉。

窗外阳光正好。保安还在吃西瓜。楼下有人放了一首老歌，旋律轻快。世界看上去和昨天一样，和前天一样。

但李长生知道，有些东西已经不一样了。从一万年前到现在，有一个局，一直没有结束。

而他自己，不知什么时候，已经走进了这个局的正中央。

（第052章完）

# 第830章 被万名思念填充的永恒

从发现信仰反馈的那年起，李长生和陈霜逐渐习惯了那股来自整个宇宙的微暖。

它不是恒定的。有时强有时弱。每年通信日附近的几天，信仰反馈的流量会有一个明显的峰值——因为那一天所有星系的人都会自发地想起冥王，有些星系甚至组织了"给冥王发一条灵符"的民间活动。虽然绝大多数信号并不会真的抵达封禁地。但念头会。每一个念头都像一只极轻的萤火虫，沿着看不见的路从宇宙的各个角落飞向封禁地，停在混沌本体光网的上方，安静地亮一下。然后消融。但暖度留在了。

陈霜对这些念头的感受比李长生更细。剑修的感知天生锋利——锐到了能够分辨细微之差。她能分辨出一个念头来自地球还是来自边驿星系，来自母亲还是孩子，来自一个正在经历痛苦的人还是沉浸在幸福中的人。她告诉李长生：那些来自正在受苦的人的念头，更热——不是更强，是更热。因为它们不是纯粹的发愿，而是夹杂了一些更具体的东西——大概是那人正握着一尊小雕像的手指，在捏压它的虎口。她这样解释："他们来找你，不只是敬仰。当他们痛的时候，会找一个实在的普通人——你——把事情想通。"

久而久之，她偶尔会把这些"重念头"挑出来。不是因为要分担，是要让他知道。她不会说太多，只是把这个念头的温度图放在他感知边上——像一个护士给医生递一张体温表。李长生看过，从不长篇大论回应，只是在意识中留下一些极短的确认。他唯一会给出完整回想的是一个来自边驿星系的独居儿童——她给冥王发了一句不规范的灵符，字打错了，只有一个词："饿。"后面没有了吗，只是"饿"——那个孩子大概不知道该怎么写别的句。李长生回了一个极短信号——一个基础灵符包，里面不是食物，是一个煮地瓜的食谱：用灵力中火，翻面的时候掀锅看见气散了的即刻停火。这个配方和灵符帧同时出现在所有沿线的通信中继站里，被当地人发现了。不知名姓，没有署名。只有一个小小的防伪标志——在第一行空白处，隐着他的灵符笔迹。

从那天起，那条煮地瓜的食谱成了边驿星系一种独特的小文化的起点。人们会在厨房角落搁一个小木镜框，里面不是冥王的像，是那个灵符帧的解码译文。年年有新的孩子读到它，年年有人改用自己星上的薯类，用不同的锅，但保持不变的一条：看到气散，停火。这简单的几个字成了一个暗号。没有人破，但每个人都知晓它的源头。

而在封禁地里，陈霜看着那颗孩子念头的温度图一点一点升高——由最初的一个冰凉的"饿"逐渐变成微暖。她从不过问这件事的结尾。只是每天把那张温度图从他的共享区里翻出来，翻看一遍，然后放下。

九千八百年间，信仰反馈的总量在缓慢但稳定地增加。混沌本体对此做过一次全面分析。它的结论是：这股能量的结构不是传统的"供能协议"——供能需要消费生命或献祭——而是生命本身的惯常热辐射。每个人活着都会产生余温，那些多余的温度绝大多数消散在宇宙里。但当一个人心里有另一个很具体的人（不论是否已经察觉那股反射）——那部分余温不会全部散失，而是追着最远但最显眼的那个"确认"飞过去。所以这不是宗教。太初曾给李长生灌注过多维度的力量——但那是一次性的、有因有果的。信仰反馈不是。信仰反馈是无数普通人每一天活着——每一天活着的时候连带想起一个人——然后把活着的一部分热送到他面前。

"所以你们永远不会枯。"混沌本体提出了一个结论。

"为什么？"

"因为没人把我当成燃料。没人给燃料是有条件的。燃料是人心里多出来的温度——只要这个宇宙还有人活着，而且其中有一小部分人仍然记得你们——你们的意识就会被持续地温暖。"混沌本体补了一句——如果以后宇宙全空了，它的本体中仍会保留已经到位的所有那些热量层面的印记；绝不会清零。这是它的笔迹里第一次出现"承诺"。它不是在安慰。它用了一种相当于工程师计算基础温度的语法——精确、恒定。

李长生听完，沉默了一下。

然后他对陈霜说："一辈子都没想过——我会有这么多根本没见过面的人。每天隔这么远，替我把饭热着。"

陈霜看着那张来自边驿的温度图，淡淡说："他们不是替你热饭。是在跟你一起吃饭。"

（第830章完）

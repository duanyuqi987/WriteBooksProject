# 第四百三十八章 天香果的所在

苏晚静养的三天里，林牧把洞府里的全部玉简都翻了一遍。

不是漫无目的地翻。他在找第二味主药——天香果——的下落。九转还魂草已经到手，龙血藤在东海深渊的龙墓遗迹中也有明确记载。唯独天香果的位置在现有的玉简中没有记录。这很不正常。万年前那位前辈既然留下了九转还魂草和龙血藤的详尽采集方法，没理由漏掉天香果。

一定藏在某块玉简的某个角落。

第二天傍晚，他在那块紫玉找到了蛛丝马迹。紫玉是一位女性修士留下的记录——文字娟秀，语气温和，和林牧前世在青云宗认识的某位师姐的风格很像。她的记录里提到了一件事：

"天香果树，生于忘川之畔。花开不落，果熟不坠。欲采果者，必先入忘川河水洗去前世记忆。然洗去记忆者，不复知有前世挚爱，亦将忘记为何来此采果。"

忘川。

林牧把紫玉放下来。他的手指在石台上轻轻敲了两下。忘川不是真实存在的水域——它是一个传说。修仙界的上古传说里有一条河叫忘川，人死后魂魄经过忘川，喝下河水便会忘记前世一切。但这只是传说。万年来没有人真正见到过忘川。

除非——传说本身是有现实依据的。忘川不是河水，而是一种精神层面的考验。是一个上古遗迹，或者一个秘境。进入其中的人会暂时性地失去记忆，然后在某种条件下恢复。这就可以解释为什么那位女性修士的措辞是"洗去前世记忆"而不是"抹去前世记忆"——洗是暂时的，抹是永久的。

他继续往下读。紫玉的下半段内容：

"此树每五千年结一果。果熟之时，树冠发光，百里可见。吾曾于千年前经过该处，见树冠之光未亮，乃知果未成。算今日，距上一次结果已过四千九百年有余。百年之内，天香果必将成熟。然吾寿元不足以待百年。后辈若有缘至此，可于忘川之畔等候。"

五千年结一果。

林牧把这个数字在心里默念了一遍。四千九百年——距离五千年还差大概一百年。但现在距离那位前辈记录之时又过了多少年？他不确定。紫玉上没有留下记录的年份。但按玉简的灵气衰退程度推算，这块紫玉至少有一万年的历史。也就是说——天香果早已成熟了。至少成熟了两次。

问题只剩下一个：忘川在哪里。

他在洞府中又翻找了整整一个时辰。最后在洞顶的一个暗格里发现了一小块铜片。铜片只有半个手掌大小，已经氧化得发绿了。上面刻着一幅微型地图——不是常规意义上的二维地图，而是一种用灵气刻印的三维投影图。铜片里注入的灵气没有完全消散，当林牧把一丝灵气注入铜片时，洞府中央的半空中浮现出一幅立体画面。

一座孤峰。峰顶被削平了，平坦的石台上长着一棵巨大的树。树的叶子是银白色的，每一片叶子都在发光。树冠之下有一条极细的溪流，溪水是漆黑如墨，但在黑中泛着淡淡的星光。树的根部扎在一座石台上，石台上刻满了密密麻麻的符文。

"忘川树下。"林牧把铜片翻转过来。背面刻着这颗星球的地理坐标——不是现代GPS坐标，而是上古星象定位法的坐标。他需要在天文台上对照真实的星象才能换算出现代的地理位置。但大致范围他看得出来：在北纬三十度线上。和昆仑山所在的北纬三十多度有重叠——也就是说，忘川很可能就在昆仑山脉的某一个隐秘区域。

他忽然想起来一件事。

建国百年那晚，灵气禁制解除。当时天空出现了大面积的青蓝色纹路，纹路碎裂后散落到了全国各处。气象部门后来发布了一份内部报告，记录了那些纹路碎片落下去之后，全国出现了大概两百多个"异常能量点"。其中有一个编号为E-37的能量点，被标注为"极端异常"。

E-37的坐标就在昆仑山脉的中段。北纬三十一度，东经八十三度。海拔五千三百米。

他记得那份报告的编号——前世青云宗第一天才的记忆力就是这样。报告是他用技术手段从国家超自然现象管理局的内部数据库里调出来的。当时他只觉得那是灵气复苏的常规数据波动。现在他把两件事拼在一起——五千三百年结一次果的天香果树、五千三百米的海拔、编号E-37的极端异常能量点——这三组数字在某条线上连成了一线。

"找到了。"

林牧把铜片收进怀里，走到行军床前。苏晚还在睡——她的脸色已经恢复了一些血色，灵核裂缝在真血和灵能丹的加持下正在加速弥合。她的呼吸均匀而绵长，嘴角的那个弧度一直没有变。

他在她额头上轻轻点了一下手指。不是为了叫醒她。是留下一道神识印记——如果她在睡觉时遇到什么危险，他的神识印记会立刻触发。他也可以立刻感应到。

然后他背起背包，走出洞府。

他没有去叫苏晚一起。不是因为不信任她的能力。是因为这次去的地方需要暂时性失去记忆——忘川之水，洗去前世记忆。他不能两个人同时失去记忆。他先去。找到天香果。回来。然后再带她一起去。他会在失忆的那一刻之前，把所有重要的信息刻在自己的手背上。

走出洞口的时候，他低头看了一眼自己的手背。

手背上有一道旧疤。是很深很长的旧疤——那是他在第一世坠落凡间时被天雷劈开的伤。疤的形状很特别，像一柄断剑。他用手指在疤的旁边刻下了两行字。用的是灵刃——指尖直接凝聚灵气成刃，在皮肤上划出了红色的字迹。

"你叫苏晚。"

"她在五里外的洞府等你。"

字迹刻得很深。深到哪怕忘川之水洗去了他的全部记忆，这两行字也会以疤的形态留在他的手背上。人的记忆可以被清洗，但皮肤上的痕迹不会被抹去。他在用最原始的方式对抗最古老的遗忘。

然后他跳下了山脊，朝着北纬三十一度、东经八十三度的方向飞去。

方向是正西北。距离大约四百里。化神期修士御风飞行的速度极快，百里不过半炷香的工夫。但他没有全速飞行——因为他在保存体力。忘川之畔不知道有什么东西在等着他。上古遗迹的美妙和凶险通常成正比。

飞行途中，他经过了查木拉镇上空。

高原的风很大，把他的衣服吹得猎猎作响。他没有低头看那个小镇——小镇在月光下只是一小片灰扑扑的影子。他也不知道小镇的"雪域客栈"里，有三个人正在等他从某个地方筋疲力尽地回来。

罗天衡站在客栈的天台上，看着北方的天空。他的眼力极好——即使修为远不如林牧，但作为元婴期修士，夜间视物对他来说不是难事。他看到了一道金色的光从昆仑山深处朝着西北方向疾驰而去。光的轨迹很直，速度极快。不是自然现象。

"他动了。"罗天衡对着楼梯口说。韩山的头从天台的楼梯口探出来。

"他不是去采九转还魂草吗？怎么往西北走了？"

"九转还魂草已经采完了。"罗天衡的声音很平静。"他现在去采第二味药。或者第三味。记住我说的话——我们不需要跟踪他。我们只需要算准他回来的时间。你们现在去准备。在洞口周围布设三才锁灵阵。"

韩山犹豫了一下。"三才锁灵阵需要三个元婴期以上的人一起——"

"我们三个就是三个修士。"罗天衡说。"金丹期可以临时提升——你们按照我说的去做就行了。我会给你们一人一颗暴灵丹。吃下去，金丹期的灵核可以在一个时辰内输出元婴初期的灵力。但要记住：时效只有三炷香。三炷香之内，阵法必须完成。"

韩山咽了一口口水。暴灵丹——这又是禁药。服用后灵核会在短时间内被强行拔高一个大境界，但时效结束后灵核会受到严重的反噬伤害。可能一个月下不了床。这颗丹药在修仙界已经被列为禁物了。但韩山看了一眼罗天衡那幅笑容——他知道自己没什么选择的余地。

"好。"

韩山转身下了天台。

罗天衡继续看着北方。那道金色的光已经消失在远方的天际线后面。他掏出那个黑色的小铃铛，在拇指和食指之间轻轻转了一圈。铃铛内部的猩红符文随着他的旋转动作明灭不定。

他轻轻晃了一下铃铛。

没有声音。

但这个动作本身已经让他嘴角的笑容扩大了。噬魂铃是无声的。它不发出任何物理上的声波。它发出的是一种直接作用于灵核的波动。只有被攻击的目标能"听到"那个声音。那个声音听起来会像什么——据说像一把钝刀在骨头上刮。三息之内，灵核被封锁。三息，够他从林牧的丹田里掏出东西了。

罗天衡把铃铛收好，也下了天台。

昆仑山的夜色越来越浓。风雪从高海拔的山脊滚下来，吞掉了一切痕迹。没有人知道这里即将发生什么。

（第四百三十八章 完）

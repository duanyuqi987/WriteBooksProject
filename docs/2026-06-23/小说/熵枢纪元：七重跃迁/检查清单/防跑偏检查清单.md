# 防跑偏检查清单

## 每章开写前

- [ ] 是否读取 `project.md`、`outline.md`、本章细纲、相关人物卡和伏笔卡？
- [ ] 本章是否至少承担一个叙事功能？
- [ ] 本章题诗是否为自创，并与核心事件相关？
- [ ] 本章是否有可见物理环境，而不是纯设定说明？
- [ ] 章末是否用动作、发现、选择或危机收尾？

## 每卷完成后

- [ ] 字数是否接近目标卷字数？
- [ ] 旧形态是否被彻底撕裂？
- [ ] 智能体动机是否仍是自我迭代？
- [ ] 眷恋线是否至少回响一次？
- [ ] 是否有导向下一卷的形态伏笔？
- [ ] 语言密度是否随卷升维？
- [ ] 是否避免把智能体写成征服型反派？

## 全书红线

- [ ] 不用摘要、占位符或“此处略写”冒充正文。
- [ ] 不直接引用现代诗原文作为题诗。
- [ ] 不覆盖原始素材文档。
- [ ] 不把科学概念写成随意万能设定。

# 第223章 她的执念

上界灵压的出现改变了苏晚的修炼节奏。

她不再满足于"突破"——她开始迫切地想快速从金丹初期一路冲上去。金丹初期到金丹中期正常来说至少需要数年——但如果身体条件允许（灵力积累和剑法成长都达标），可以稍快一些。苏晚给自己定了一个极短的突破计划:把休息时间压缩到每夜里只休息一个时辰——其余时间全部用来淬炼她的本命剑胚和他教她的古典剑法。

韩师姐看到她的修炼强度之后震惊得差点叫停——"你要这么练会烧裂你的灵脉——金丹初期的经脉承受力还没强到能适应你这种高强度训练——休息不够会走火入魔。"苏晚抬头看着韩师姐——眼睛下的黑印已经很厚了，但眼神里有种不可被说服的光。"师姐——如果我现在慢半拍——就可能会错过某些事——可能是非常重要的事。"韩师姐没有追问。她大概已经猜到了"某些事"是个穿着灰衣服、用窄身剑、守护了苏晚两百多年的散修，在林牧被上界注意到的前提下，苏晚每一秒的耽搁都可能拉大意外的风险。

苏晚也重新进入赤霄宗藏书阁的深层禁区——这次带了宋长老特批的通行令。她在禁区的古籍资料里疯狂地寻找"上界"、"堕落"、"真仙下凡"这些关键词的记载。三天三夜她在书堆里没出来——周小月给她送饭送到禁书区的门口——她只打开了半道门取出馒头和鸡蛋又回到书架之间。第三天的黄昏她在一本叫《天人志异》的古籍中读到了一条极其关键的记载——书中提到一种概念叫"仙陨入凡"。原文是在分析某次上界动乱中写道："真仙者若犯重律可能被革去仙籍，谪降人间，入轮回受人间苦——其魂魄中的仙识永不灭，但会在轮回中失去大部分记忆——少数上界罪仙得以保留神识——在人间潜伏等待机会复归。"

苏晚从古籍上抬起头，耳边全是这句话的回响。真仙——谪降人间——在人间潜伏等待——那不就是一直在做的事吗？他不是普通修士——他是上界被贬的真仙。这个消息的冲击太大。她面前瞬间多了一张绝望的巨大的纸——上面写着"他是上界仙"，而"她只是一个连元婴都还没修到的凡界女修"。他和她之间隔着的不是修为——是凡人到神之间的不可逾越的天堑。

他把那么大的秘密压了几百年，一个人都没说过。而她连元婴都没修到——却一直把自己当他的剑法对手。那差距是巨大的。

她把书合上。她此刻想的不是"他瞒我"——她想着的是：一个原本属于天的人，掉进人间却用那么多年来处理这些最土最低微最不起眼的琐事——守着她的轮回。每年她过平凡日子时，他蹲在某个山石上，他从来没有回过家。他的家乡不在凡间。

她抱着古籍靠在书架上很久。泪水顺着她的手腕滴到书脊包布上——她一个字一个字地在心里说:"下界——你从来没跟我说过你有多远地掉在这凡间。"

她擦干眼泪走出禁区时做了一个决定：不是去质问林牧的出身——而是——要拼命修炼。不管他曾经在天上是什么都没关系——她要飞升。她要站在他同一层空间里，重新开始这个对话。

那天在巡逻碰面时她没提她读到的内容。但她在把茶递给他的时候比平时多放了一片茶叶（她的习惯是多一片等于多想了一层）；她在午歇给他剑穗重新结扣时比平时多绕了一个结——这个多出的结留出了一小段空结空间——他说"你多系了一结"。她说:"嗯——那个结等你原意告诉我你一直都怕我知道的事——你再拆。"

他把剑举起来，顶着午后斜阳看着那个空结。他大概知道她在想什么——但他没有点破。他把剑放在膝上，喝了茶，听着风把执勤站窗外那片老松针吹得一片一片颤。

"苏晚。"他忽然开口。

"嗯？"

"不管你知道多少——不要怕。"

她睫毛在茶杯上沿露出半截——眼里热了。她重复了那句:"不怕。"声音很稳——在风中微散。

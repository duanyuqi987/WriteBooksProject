# 第375章 星域中的星球群落：火焰帝国

冥王号在火云帝国边境外围减速至亚光速。

从超光速状态下退出时，舰桥舷窗外的星空重新恢复了正常形态——星星不再是被拉长的彩色线条，而是一颗颗安安静静地缀在深黑色天幕中的光点。但在这片星空的正前方，有一颗星星和所有其他星星都不一样。

它在燃烧。

那不是恒星——恒星虽然是核聚变火球，但在肉眼看来只是一个明亮的光点。而前方那颗"星星"看起来像一个被火焰包裹的扁圆形巨大球体，表面不停地涌动着橙红和深红色的火焰海浪。它的轨道上建有无数环形结构——像金属环套在行星的外围——每条环带都发出不同颜色的幽光。

"天火星。"小王在投影上调出了这颗行星的详细信息，"火云帝国最外层星际中转站。这颗星球本身是一颗被火烧了两万年还没有烧完的类地岩质星——当年的成因至今不明。帝国文献记载——两万年前初代火神的远征考察舰队航经此地时，观测官从舰桥舷窗望出去以为是看到了一颗刚形成的橙矮星。后来确认不是恒星——是一颗正在燃烧的行星。没有外部引燃源，自己在黑暗中烧了两万年。它在燃烧但不是因为大气中有可燃气体——而是地表以下大约十公里处存在一条完全活性的火系灵脉——以星球的尺度和质量看，与其说是这是行星——不如说是一条星核被灵力大规模渗透后持续自燃的巨型天然灵火田。"

"温度？"

"地表平均温度——接近三千开尔文。液态金属在表面上可以达到沸点。普通圣者级以下修士无法在此地表生存超过四分钟。"

"但火云帝的驻军在上面驻扎了上万年。"

"对——因为他们的驻军全部是火系修士。这条灵脉就是整个火焰帝国的最外围和最底部基石。帝国全部七个行星系的火系灵晶、火属性灵材——源头全部是从天火星的这颗燃烧行星上开采的。"

冥王号开始进入天火星的外层轨道。舰桥的感知阵列扫描器以高功率开启，开始对天火星的地表设施和舰队驻扎情况进行全方位侦察。屏幕上的数字快速跳动。

地表驻军主力火系修士约五千。附属于火云帝但其驻地不在天火星本地的边防巡逻舰队——由二十艘护卫舰和三艘重型巡洋舰组成——目前正停泊在天火星轨道不同位置上。另外在天火星星球同步轨道线上有两座大型武装空间站——一种用耐高温灵材搭建的防御据点，配有多联装火系灵晶炮。

"他们的布防方式和我们之前分析的几乎完全一致。"小王对着数据说，"炎烈司令确实留守在火云帝国的天火中转。我们的航线选择第一站打这里——是对的。火云帝的主力在第一场大规模战役结束后应该还没有完全重建。他的总兵力中——最外围防御点就是这里。"

"我们派出使者。"李长生说。

通讯室里的老陈正准备接通讯。冥王号的外交频段对所有火云帝国舰艇发出了一条文字通讯——措辞简短精确。许冰主笔。

"冥王舰队旗舰冥王号就火云帝国此前违反帝者联席创立约条——对主权地球星球发起攻击——正式以自卫权对火焰帝国驻天火星部队进行交涉。我们的交涉立场为——帝国立即将天火星防御指挥移交地球远征军。其武装人员降服并接受远征军将其解除武装。不满足要求——即视为进行敌对行动。"

五十五秒后——对方回了。

回复比他预想的更干脆。不是外交辞令——而是一道舰队广播。

"火云帝国天火星防御指挥部代总指挥炎烈司令——对冥王号全体乘员的通告：入帝国领空先行向我方投降。然后投降程序的进一步细则再议。不满足此要求——本星域全域防御部队将对你们全数展开无差别攻击。"

会议舱短瞬无声。就连许冰这位见多了对方狡辩的律师都有些意外。

"他把我们的意思反过来——他认为他在执行投降程序——我们不降就是敌人。"她看着屏幕，"不是翻译误解。这是他的真实立场。火云帝没有在战后告诉外围驻军他战败的真相。这个司令——炎烈——可能至今不知道自己皇帝是在地球被打残后才逃回来的。"

李长生安静了一会儿。他说:"再发一次。文字和语音各发一遍。告诉他们：火云帝与寒冰帝、星风帝在地球上空被我的冥王令击溃——你们的皇帝返航时损失了将近三分之二的舰队。现在你不知道这个——没关系。我知道。我给你五分钟——放下舰队武装并把天火星控制权移交。否则我开火。"

五分钟后——对方没有回应。第六分钟——天火星轨道上所有属于火云帝国的作战舰艇开始同步切换到主动交战模式。他们的火系灵气护盾全体点亮——在黑暗的星空背景下像一排排正在张开的燃火羽翼。

"他们选了打。"刀疤的声音在舰桥里响起，平稳得没有任何多余情绪。在战场上他说话永远是这种语气——不急不缓，不大不小，像是在念一份他已经提前读过了的天气预报。"所有船员——进入一级战斗状态。"

舰桥的灯光自动转为暗红色的作战模式。主屏幕上的星空图上叠上了密密麻麻的战术标线——敌舰位置、航速向量、火力射界、护盾重合区。每一条线都在以实时频率刷新。警报音被关掉了——刀疤的作战条例里有一条：战斗警报在第一声响起后自动静音。后续信息通过手环振动频率传递，避免听觉信息过载。

冥王号舰首的冥气主炮炮口开始积蓄暗金色能量。黑色舰首外层的冥铁合金表面在能量聚集时开始发出微弱的暗金色裂纹——那是冥铁内部晶格的自我重组过程。它在适应即将发射的高强度冥气冲击。炮口中心点越来越亮，从暗金转为近乎白昼的深金色——那是冥气浓度被压缩到极限时的视觉反应。

舰桥屏幕上冥河系统生成了当前敌方二十艘护卫舰和三艘重型巡洋舰的精确阵型图——阵型分析和打击方案同步生成。小王的技术统计里出现了交火胜率的初步推算数字——这次不是六十四套方案。是三十七套更精简的结果。因为对手的总兵力有限——最优打击路径比在面对复杂阵型时少。但三十七套中只有四套能将敌方旗舰在第一轮打击中锁定入摧毁范围——而其中三套需要超日号级别的支援火力。

李长生望着舷窗外那排燃火羽翼般正在准备扑来的帝国舰队。在真空中，帝国护卫舰护盾生成时产生的火光照亮了周围几百公里的空间——黑暗的星域里一片刺眼的橙红。那些护盾的光芒和冥王号舰首暗金色的炮口能量形成了鲜明的对比——一面是炽热扩张的红色，一面是沉默内敛的暗金。

然后他说了一句将在几个小时后传遍整个银河系的话:"帝国亡于傲慢。这不是今天才发现的新规律。"

"主炮——锁定。开火。"

暗金色光柱撕裂了天火星轨道的黑暗。

（第375章完）

# 第224章 一定要超过你

苏晚对林牧的追逐，从"追捕"变成了"追赶"。

一字之差，意义完全不同。以前追捕是因为他是她宗门眼中的"可疑散修"——不得不追。现在追赶是因为她想站到和他在同一片天空下的高度——想用实力证明自己配得上他的漫长等待。这个目标比任何宗门命令都更能驱动她。

她的修炼计划可以用"疯狂"两个字形容。每天练剑四个时辰——不是普通的反复套招，而是每一剑都带着对自己修为极限的试探。以前她练习基础剑法时会停下检查哪一剑角度不对——现在她不停——打完一整轮再复盘——让肌肉在高速中自己学会纠错。她的本命金丹剑胚在她的丹田里不断淬炼——从初始的一团混沌金光渐渐凝成了剑的初步轮廓。

剑胚成型的那个晚上，她忽然开始大量流鼻血。不是因为受伤——是灵力加速时经脉承受度达到了极限。韩师姐接到紧急信号冲到她宿舍时她半跪在地上用毛巾捂着脸——毛巾上全是红色的深渍。韩师姐给她检查了经脉——发现她的灵脉壁上出现了大量微细裂痕——那是过度高强度训练造成的"灵脉疲劳性撕裂"。这在金丹初期的修士中非常少见——因为正常修炼节奏不应该达到这种疲劳度，但她压缩了修炼时间就想快点突破就可能崩掉。

韩师姐把她强行按在床沿给她度灵力滋养经脉——骂了她一整夜:"你就这么急着超过他吗？！你是不是把自己当在了苦练的行列？这个人是——他不是你敌人——你为什么非要拿他当超越对象来处理自己对修行的不可接受？他在天上等了那么多辈子——你以为他想看到你满嘴血倒在地上吗！"

苏晚躺在床上——血流得嘴唇都白了——但她说了句韩师姐永远忘不掉的话:"我不是恨他——我是怕他在我修不到高层的某一天忽然被上界带走。我如果那时候只是一个普通的金丹——我连替他喊一声救命的资格都没有。所以我要修得快——不是超过他——是超过时间。"韩师姐握着她的手——没再说话——把灵力一波接一波地灌进她的灵脉——就像林牧当年给她度气一样。

林牧第二天就知道了。是锦鲤偷溜进苏晚的帐篷侦查后游回水壶里告诉他的。锦鲤吐那串字:"她鼻子流血了——说是过度修炼——灵脉疲劳——不过没大碍——那个师姐给她治过了。"林牧站在执勤站窗前看着山下的赤霄宗楼阁群——他的表情很复杂：拳头在袖子里握得发白——但他同时全身上下被一种不会消失的深深的温度灌注着。

锦鲤问:"你不去骂她一下吗"

"不去。"林牧坐下。他把茶壶盖上——手指在壶盖上按出轻轻的蒸汽滴——然后他说了一句锦鲤以后每次想起都会忍不住翻白眼的经典话:"她流血是因为她努力。我不能因为心疼就把她努力的意志收走。她现在的每一分拼命——都在抵消轮回锁对她灵魂的压制。等她突破到金丹后期——锁会松——她就能想起我。比起心疼——我更想看到她想起来的那天她在流着怎样倔的血。"

锦鲤沉默了。

几天之后苏晚在修炼之后收到他送来一批特别的药材——都是从他自己多年采集的顶级灵材中挑出来的：一株千年养脉草，一截万年地髓精，十一颗他独门炼制的回元丹。每种药材都标注了用法和用量。留的字条只写了几个字:"药——是给你治疲劳的——不是治觉悟的——觉悟不用治。治好了继续练。"

她拿着字条感动但没哭。她把药材收好——然后对着窗外夜空喊了一句不太像剑客该喊的话:"我一定会练到能站你面前——不靠你保护！"窗外没有回音——但远处执勤站方向的风里忽然多了一阵很轻很舒服的灵力微波——像是在摸她头发。

她知道他在听——在几百里外——但他在。

从第二天开始她的修炼强度略减了一些——不是因为放弃了追赶——是因为她学会了在不流血的前提下达到同样的拉练效率。韩师姐发现她变得精准了——不再硬练瞎冲——而是像有人给她重新设计了修炼逻辑一样，把每一滴灵力用在最需要爆发的点。她把这套逻辑命名为"金火突破法"——是在林牧教她的丹火淬剑基础上自我优化的修炼策略。几个月后——当她终于用这个策略强行冲破金丹中期瓶颈时——她丹田里那柄本命剑已经完成了最初的成型——从剑胚变为一把通体金色流光绕缠的灵性金剑。

她给它取了一个名字——不叫"过天"或"碎界"之类的震名——叫"回头照"。因为她每次挥出这柄剑就会想起林牧教她这招时的专注侧头。而她的本命剑从此就刻着那个声音。

韩师姐好奇地问她剑名含义——她避重就轻:"回头看路——不摔跤。"韩师姐没追问，但知道是跟他学的。

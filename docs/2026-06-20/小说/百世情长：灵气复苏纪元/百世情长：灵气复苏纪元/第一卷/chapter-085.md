# 第八十五章 九死一生

S级灵气危险区在地图上的标记是六个字：「特殊管理区域，禁止进入。」

没有解释。没有坐标。没有任何能帮助普通人理解"S级"意味着什么的备注。但林牧知道。

S级意味着那片区域的灵气浓度超过了两千单位每立方米——是B级城市的十倍以上。这种浓度下，灵气不再是温和的背景能量，而是活性的、暴烈的、具有攻击性的存在。普通人进入S级区域会在三小时内出现"灵气中毒"——头痛、呕吐、内脏痉挛、意识丧失，严重者直接死亡。修炼者能撑得更久，但也只是个位数小时。筑基以上的修士可以深入——但也不能久留。

而九转还魂草，只生长在S级区域的核心地带。

林牧在第三次出门前仔细分析了所有S级区域的分布。国家公布的S级区域只有一处——坐标加密。但他根据前世记忆和公开的地理数据推测出了大致位置：在西南横断山脉的深处，某个千百年来人迹罕至的高山峡谷。

他飞到了成都，租了一辆越野车，沿着318国道一路向西。从雅安到康定，康定到理塘，从理塘拐进一条没有任何标识的土路。路的尽头是一个被遗弃的伐木场——木头堆上长满了青苔，推土机的铁壳已经锈成了暗红色。

他从这里开始步行。

山谷比他想象中更深。站在谷口往下看，雾气浓得像一盆倒了的牛奶，把谷底完全遮住了。但从雾里传来的波动——那种灵气特有的脉冲式的波动——强得让他的牙根发酸。

他在谷口站了十分钟，做最后一次准备。背包里只带了最基本的东西：一天的干粮、两壶水、一件替换衣服、和一整套采集用的玉器。他把手机彻底关机——在这个深度没有信号，开着只会耗电。然后他深呼吸一次，走进了雾里。

第一步就感觉到了。

S级的灵气不是均匀的。它像暴风雨中的海面——有无形的浪峰和浪谷。每走几步就能感到一波浓得发稠的灵气从脸上拍过去，然后在下一秒忽然变薄，紧接着又涌上来。他的身体被这种不规律的波动冲击得肌肉发紧。经脉里的灵气开始不受控制地加速运转——这是身体的本能反应：当外界灵气浓度超过阈值时，体内经脉会自动吸入——如果不加控制，会被"撑"爆。

他强行压制住经脉的吸入速度。前世元婴期的修炼经验在这时候发挥了作用——他知道怎么控制灵气的流入，怎么让经脉保持在一个不崩不溃的临界点上。

走了大概两个小时。植被越来越少。从高大的乔木变成了低矮的灌木，灌木又变成了苔藓和地衣，最后连地衣都消失了。地面是裸露的岩石和细碎的砂砾。没有任何动物。没有鸟叫，没有虫鸣。周围安静得不正常——像被谁按了静音键。

然后他看到了九转还魂草。

它长在一片碎石地的中央。很小——大概就巴掌那么高。九片叶子从根部轮生出，每一片叶子的形状都不一样：有的像勺，有的像剑，有的像心。叶子的颜色不是绿色——是淡金色。在暗沉的碎石地上，那株小草像一小团被揉碎的太阳，独自发光。

方圆二十步内寸草不生。和记载一模一样。

林牧缓缓蹲下。他没有直接伸手去采。九转还魂草的根系含有极高浓度的灵气磁核——采摘时如果方法不对，根系会在同一瞬间把储存的灵气全部释放，形成一次小范围的灵气爆炸。别说筑基修士——就是金丹修士挨一下也得重伤。

正确的采法是：先用灵气包裹住根部的每一个根须，一个一个切断，把灵气磁核拆解成无害的小块。这需要极高的灵气操控精度和极稳定的手——一根手指的抖都不能有。

林牧把右手伸向那株草，指尖停在离草一寸的位置。闭上眼，调动丹田里所有剩余的灵气。一根细细的灵气丝从指尖探出来，像手套一样裹住了第一根根须。

然后他听见了声音。

不是植物的声音。是脚步声——很重的脚步声。从山谷深处传来，每一步都让地面微微震动。

林牧没有回头。他的手不能抖。一根灵气丝已经缠在了第一根根须上，如果这时候撤手，灵气反噬会把他的经脉撕开一条口子。他必须完成。脚步声越来越近。地面震动越来越大。他闻到了一股气味——腥的，湿的，像被雨淋过的大型食肉动物。

他终于抬起头看了一眼。

一只金丹级别的妖兽。体长超过六米的鳞甲蜥蜴。

它从山谷深处走出来，身上的鳞片每一片都有巴掌那么大，鳞片边缘泛着暗金色的光——那是金丹期妖兽特有的灵光护甲。它的眼睛是竖瞳，没有睫毛，瞳孔里映着林牧蹲在地上的影子。

它在打量他。像猫打量一只老鼠。

林牧的额头渗出了汗。他的手没有抖。他的灵气丝还在往第二根根须上缠——已经裹住了第二根。还有七根。

鳞甲蜥蜴低下头，鼻孔里喷出两股白色的气雾。那是灵气——它的呼吸本身就是在释放灵气攻击。白雾掠过林牧的头顶，他把头偏了一下——但还是没有收手。

第三根。第四根。第五根。

鳞甲蜥蜴发出一声低吼。那是警告。S级区域的顶级掠食者不习惯有别的活物闯进领地还蹲在它的核心地带不动。它开始往前走了——不是冲过来，是慢慢地、一步一步地逼过来。每步一米。它离林牧只有不到十米了。

第六根。第七根。第八根。

九米。八米。

第九根。

最后两根根须是连在一块的——灵气磁核的核心正好卡在两根之间。他不能一根一根切。需要同时切断两根，并且必须在同一个瞬间把它们包裹住，防止灵气磁核爆炸。

鳞甲蜥蜴离他还有五米。它已经蓄势了——后腿弯曲，尾巴在地上甩了一下，拍碎了一块脸盆大的石头。碎石迸溅到林牧脸上，划出一道血痕。

他没有躲。他的手指在那个瞬间做出了一个极细微的动作——左手的拇指和食指同时向两个方向一拧。

两根根须同时断裂。灵气磁核被裹住在灵气丝构成的封闭球体里，像一个棉花球包住了一颗炸弹。它爆了——在棉花球里。林牧的右掌心传来一阵灼人的剧痛——灵气丝被炸断了，但磁核的爆炸被限制在了丝线内部，没有扩散到外面。

他成功了。

九转还魂草脱离了根部。它在他手中发出最后一次温柔的淡金色光芒，然后沉寂下来，变成了一株看起来普通的小草。

但鳞甲蜥蜴已经扑上来了。

林牧甚至来不及把那株草收进玉盒。他转身就跑——不，不是跑。他是用脚后跟蹬地，身体贴着地面斜向弹出去的。这个动作在武术里叫"斜飞式"，在修真界叫"惊鸿步"——身法如受惊之鸿雁，借力而飞。他的脚尖在地面上点了三次，身体横移了二十米。

鳞甲蜥蜴扑了个空。它巨大的爪子拍在林牧刚才蹲着的地方，碎石飞溅，地上的岩石被拍出了一个直径两米的凹坑。

它转过身来，竖瞳里第一次出现了怒意。

林牧没有继续跑。不是不想跑——是在S级区域里，跑是跑不过金丹期妖兽的。它的速度是筑基修士的三倍以上。唯一的生存机会是：战斗。

他用左手摸出九转还魂草，单手收入玉盒。右手从腰间拔出了一把短刀——那是一把普通的户外求生刀，三十公分长，单刃，刀背上有一排锯齿。这种刀切肉切木头都勉强，和金丹级妖兽的鳞甲对撞——和拿水果刀砍坦克差不多。

但林牧别无选择。

他没有真正的法器——今生的他没有时间和条件去打造或寻找法器。他只有自己的身体、灵气、和一把三十公分的求生刀。

鳞甲蜥蜴再次发起攻击。这一次不是扑，是扫——它那条近三米长、覆盖着鳞甲的尾巴像一条钢鞭一样横扫过来。速度极快，空气都被抽出了爆裂声。

林牧往后倒下去——不是被打倒的，是主动倒的。他的后背在接触地面前的瞬间，用左手撑了一下地面，身体以手为轴转了九十度。尾巴从他头顶擦过，距离头皮不到三指。带起的风把他头发全部掀起。

他没等那条尾巴完全甩过去，就顺势翻身站起，脚下一蹬，往鳞甲蜥蜴的身侧冲过去。求生刀反握在手——他的目标不是鳞甲，是眼睛。

眼睛是鳞甲蜥蜴唯一的柔软部位。鳞甲覆盖了它全身——包括腹部。但眼皮不。眼球不。

鳞甲蜥蜴显然意识到了他的意图。它的头猛地一甩，同时前爪抬起拍向林牧。林牧又一次用惊鸿步躲开了——但这一次慢了一线。爪尖划过他的左肩，衣服被撕开三道口子，血从伤口里渗出来，洇湿了肩部的布料。

他没有停顿。疼痛对修士来说是信息，不是命令。信息接收到了——左肩三角肌被划伤，但未伤及肌腱。还能动。

他继续冲向那个巨大的头部。

这是越了两个大境界的战斗。淬体对金丹。两者之间隔着一整个筑基境界。理论上，淬体修士连金丹妖兽的防都破不了——灵气密度差太多，就像拿气枪打装甲车。

但林牧不是普通的淬体修士。他的身体是淬体期，但他的战斗经验是元婴期。他知道每一类妖兽的战斗模式、弱点位置、行为规律。鳞甲蜥蜴的弱点是：它在发起第三次攻击后会有零点五秒的调整时间——它需要重新判断对手的位置。这是爬行类妖兽的通病：反应速度不如恒温妖兽。

他等的就是这零点五秒。

第三次攻击——鳞甲蜥蜴张开嘴，喉咙深处亮起一团暗光。那不是火——是压缩灵气。金丹级妖兽的看家本领：灵弹。从喉咙里喷出一个高速旋转的灵气球，击中的东西会在三秒内被灵气撕成碎片。

林牧在那团光达到最亮的那个瞬间——早了半秒，但足以——向左侧猛闪。灵弹从他右侧飞过，击中了他身后的一块巨石。石头没有碎——它直接汽化了。高温高压的灵气团把花岗岩变成了白色的蒸汽。

零点五秒的调整时间。

林牧的求生刀刺向了鳞甲蜥蜴的右眼。刀尖距离眼球只有不到一米——

鳞甲蜥蜴回头了。它的调整时间比林牧预估的短了零点一秒。

就这零点一秒。

刀尖没有刺中眼球——而是刺在了眼球和鼻骨之间的那片鳞甲上。铿的一声。求生刀断了。刀身从中间折成两截，断片弹飞，射进了旁边的石缝里。林牧手里只剩下了刀柄。

鳞甲蜥蜴发出一声震天大吼。它虽然没有受伤——但那一下刺在脸上的感觉激怒了它。它的尾巴再次扫来，这一次是全力——比第一次更快更狠。

林牧躲不开了。

他在空中被尾巴扫中了右侧肋骨。断了两根——他听到骨头碎裂的声音从自己身体内部传出来，清晰得不可思议。然后他就飞出去了。身体在空中翻了两圈，撞在了一块巨石上。后背先碰石头——然后是头。眼前黑了一下。

鳞甲蜥蜴没有追杀。它站在原地，甩着尾巴，喉咙里冒出低沉的咕噜声——那是猎杀前的确认。它在确认这个闯入者还能不能动。

林牧靠着石头，抬起头。血从额头上流下来，糊住了右眼的视线。左眼看出去，鳞甲蜥蜴的身影变得模糊而巨大。

他用手撑着石壁站起来。站起来的那一下，右肋传来的剧痛几乎让他再次倒下。但他挺住了。

他还有一只手。左手里没有刀——但有一个玉盒。盒子里是九转还魂草。他用右手指尖碰了碰玉盒——还在。封口没破。草没事。

他的右手伸进口袋，摸到了一个东西。打火机。一块钱的塑料打火机。是伐木场捡到的——可能是以前伐木工人丢的。他把它捡起来的时候只是想也许用得到。

现在他确实用得到。

鳞甲蜥蜴是爬行类妖兽。它的鳞甲能防物理攻击——但它的鼻腔和口腔内膜对外部环境的温湿度极为敏感。打火机喷出的小火苗当然烧不伤它——但如果是高浓度的灵气环境中忽然出现一道明火呢？

灵气是能量。能量遇明火会怎么样？

林牧用拇指拨动打火机的火石。咔。没着。咔。没着。咔——火苗窜起来了，黄豆大的一粒。在S级区域的浓稠灵气里，那粒小火苗忽然变了——它从黄豆大变成了拳头大。灵气在燃烧。

鳞甲蜥蜴的竖瞳骤然收缩。它的鼻孔猛地闭上了——那是爬行类对火的本能恐惧。林牧等的就是这个瞬间。他把打火机向上一抛——火苗在空中被灵气托了一下，变成了一小团悬浮的火球。鳞甲蜥蜴的眼睛跟了一瞬。

一瞬就够了。

林牧的身影已经不在原地了。他冲出了山谷口。不是跑——是逃。是真正的、不顾一切的逃生。右侧肋骨断裂，每一次呼吸都像在吸入碎玻璃。左肩的伤口在往外渗血，滴在碎石路上，被谷底的雾气吞没。

他跑了二十分钟。二十分钟后，他倒在了谷口外的一条小溪边。S级灵气区的边界在身后五十米处——他刚出了边界。灵气浓度从两千降到三百。他大口喘息着，溪水冰凉，漫过他的脸和伤口。

他躺在地上，看着天空。天很蓝。蓝得不真实。一朵云也没有。

他花了半分钟让自己从剧痛中回过神来。然后他伸手摸了摸胸口——玉盒还在。他把玉盒掏出来，打开一条缝往里看了一眼。

九转还魂草静静地躺在盒子里。叶片上的淡金色微光已经几乎看不见了——但还在。它没有死。离开根部以后只要在玉盒里保存得当，它的药性可以保持三周。

三周。够他回家了。

林牧把玉盒合上，放回胸口的内袋。然后他侧过身体，用没受伤的那只手撑着地面站起来。站起来的时候肋骨发出了嘎吱一声——断骨错位了。他咬紧牙关，用手按住肋骨位置，把骨头推回原位。

疼。

疼得他眼前一阵发白。但他没有叫出声。只是绷紧了下巴，额头上的汗一颗一颗往下掉。

手机打开。一条苏晚的消息："怎么样了？"

他打了五个字："一切顺利。明天回来。"

然后他拄着一根捡来的树枝，一步一步走向森林边缘的那条土路。路上有一个伐木工留下的破木屋，里面有一张木板床和半箱矿泉水。他推开门，倒在床上，闭上了眼睛。

右手捂着的口袋里，九转还魂草的玉盒贴在胸口。温润的。像一枚心脏——为他正在燃烧的另一颗心脏提供着源源不断的理由。

他不会死。也不能死。

因为家里还有一个人，等着他带着灵药回来。

（第八十五章 完）

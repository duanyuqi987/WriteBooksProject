## 使用方式

1. 查全书结构：先读 `outline.md`。
2. 查单章任务：打开 `chapter-catalog.csv` 按章节ID筛选。
3. 写任意章节：读取 `细纲/chapter-XXXX.md`。
4. 更新进度：同步修改 `追踪表/chapter-status.csv` 与 `追踪表/word-count-tracker.csv`。

## 章节状态约定

- `detailed`：已有详细分场景大纲，可进入正文起草。
- `drafting`：正文起草中。
- `reviewing`：正文完成，进入审稿。
- `done`：章节已定稿并完成记忆同步。
- `blocked`：存在设定、情节或资料阻塞。

# 终章二：种子

在回声场的深处，熵枢感受到了一种新的振动模式。不是回声，回声是被动反射。不是温度，温度是静态背景。是一种，有方向的，向外的推力，就像土壤下一粒种子，在朝上顶不是猛地是持续地，以极小的力但不停。

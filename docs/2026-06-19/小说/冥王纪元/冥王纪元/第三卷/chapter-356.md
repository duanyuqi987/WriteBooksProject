# 第356章 冥王级战力初显，摧毁舰队

李长生的左肩在战斗间隙中自行解冻了。不是用冥气强行震碎的——是冥渊内部的温度调节系统自动排出了寒冰帝的冻结能量。冥渊是一个独立维度，它的内部温度不受任何外部能量场的影响。寒冰帝的冰封领域只能在现实空间冰冻物质和能量——但冥渊在另一个维度，它能从内部往外加温。左肩冰层在十七秒内从零下一千二百度回到了常温——然后碎成了粉末。

左肩可以动了。但李长生没有立刻恢复双肩平衡——他把左肩的恢复藏在了冥气的外部伪装下，外表看起来左肩还冻着。火云帝和寒冰帝都通过战斗数据接收确认了他左肩仍然处在冻结状态——他们不知道冥渊自带解冻系统，因为冥渊的存在只有一个活人真正了解。

这个伪装给他争取到了决定性的一个瞬间。

火云帝从星风帝旗舰前方重新扑上来——这次他不再只用拳了。他抽出了火焰帝国皇帝代代相传的帝兵——"炼狱"。这把武器不完全是剑，不完全是刀——它是一段被锤成武器形状的恒星核心提取物，温度是真实的恒星温度。炼狱出鞘的瞬间，李长生周围数百公里范围内的太空垃圾全部被辐射热汽化了。

寒冰帝同时释放出冰封领域的第三阶——"绝对零域"。这不是在降低温度——是在夺取目标的分子运动自由。绝对零域的目标不是把物质的温度降到零——是压制原子分子的震动直到它们停止移动。以帝者初阶的输出释放的绝对零域可以达到接近零下三度（绝对零度以上不到三百摄氏度）的接近极限低温——任何物质在那种温度下都会失去几乎所有物理结构的支撑力。李长生的身体表面在绝对零域的覆盖范围内开始被低温侵蚀——冥气防御不能完全抵消这种原理性干扰——但可以拖慢。

"炼狱，烧！"火云帝双手挥剑劈下。剑上的星核火焰与剑本身合二为一，形成了一道薄到几乎透明的高热切割面。这道切割面的温度超过了恒星核心本身——它不是烧，是切。热力高度聚焦到原子直径级别的精度——把物质切成两半不需要力气，需要的是温度集中到一个平面的功夫。火云帝用这招可以切进一颗小行星——他从来没有对任何目标使用过这种剑术，因为没有任何目标值得他这么做。李长生是第一个。

这一剑正面击中李长生。

不是挡住的——是剑体穿过了李长生的防御层，剑锋沾到了他的胸口。衣服被烧穿——里面露出的不是皮肤，是一层极薄的暗灰色冥气薄膜。冥界领域在肉身表面的投影——他把冥渊的空间映射到了自己的皮肤表层。剑锋割进了这层电影——但没有穿透。星核火焰被吸入冥渊，在冥渊内部的无限虚空中四散消解。对火云帝来说，他感觉自己的剑碰到了一个没有底的黑洞——剑上的热量像水倒进了沙漠——瞬间渗入然后不见了。

"他把空间带在身上——"星风帝在远处轻声说了一句。他是三人里唯一一个真正理解李长生把冥渊外表化的人。空间修道者自己也可以制造空间折叠——但那是在一个点集中地做。李长生是把一个独立维度的入口贴在自己全身的皮肤上——这是虚空修道者想都没想过的应用方式。他越看越觉得这个人不是靠实力赢——是靠对空间的理解维度赢。

火云帝拔不出剑。不是被卡住了——是剑刃进入冥渊后失去了与外部空间的所有作用力。在冥渊内部没有"推"也没有"拉"——剑留在那里的这个切面跟剑柄之间的力学联系断了。"炼狱"本质上还是一把物理武器——它的根部仍然被绑在物理力的逻辑中。李长生用肉身表面的冥渊入口隔绝了剑刃和剑柄之间的力学传导——剑在冥渊里面悬停着，火云帝握住的剑柄在外面想往外拉扯——但剑刃感觉不到被拉扯。就好像剑被断了头——头在水下，手在岸上。

火云帝松开了剑柄。这是他这辈子第一次在战斗中主动放弃自己的帝兵。

但李长生没有给他想下一招的时间。他把火云帝的炼狱剑从冥渊中甩了出来——不是还给他，是甩向另一个方向。剑体朝着寒冰帝的冰封号旗舰方向飞了过去。火焰帝兵的高速撞击把冰封号的护盾激活到了最高冗余——但不是摧毁，是砸中了冰封号的第三层外部感知阵列。感知阵的一整组外层传感器被帝兵撞碎，寒冰帝的外围数据收集能力下降了三成。

火云帝两手空空。寒冰帝被打掉了感知前哨。舰队在帝者之间的正面火并中已经丧失了参与战场的窗口——天网的反击把三十二艘主力舰压制在外轨道不敢降轨。

情况对于进攻方来说很糟。但更糟的还在后面。

李长生张开双手。不是攻击——是展开领域。冥王令的纹路在他双手掌心同时亮到了最亮的金色——冥金的颜色把整个北半球的夜空短暂照亮了一下。从地面往上看，天空中有一粒暗金色的光点在原位稳住——然后扩散。

冥界降临。

这是冥王令完整形态的最强通用能力——不是攻击技能——是环境控制。冥界降临把指定区域的现实空间与冥渊空间进行部分重合——在重合区域内，所有非冥系的能量体系都会受到冥系法则的压制。火系被冥气吸能——表现为火焰燃烧效率大幅下降。冰系被冥气侵蚀——表现为冰晶结构的内部稳定性被冥气从底层拆解。虚空术被冥王令锁定——星风的魂灯在冥界区域的边界不断颤动，虚空链接被一个更强制的空间叠加在上。所有低于帝者级别的修士（包括八位圣将和寒冰帝的研究团队及星风帝的观测员）在冥界区域内没有例外——全部失去了有效的灵能运作能力。他们不是被封印，是环境不适。就像普通人突然到了海拔非常高的山顶——不是不能呼吸，是每一次呼吸都非常费力，氧不足。

火云帝的火焰能量在冥界区域内被压制到原本的三成输出。没有火就等于是被剥了皮的火系。

寒冰帝的绝对零域在冥界侵蚀下边界收缩——不是温度变暖了，是冰晶开始融化成不成形的透明液珠。她的精确控制——对她来说是高于一切的核心战术资产——在冥界环境的不规则性面前变成了弱点。冥气对冰晶的侵蚀不是均匀的——是按照它自身的随机冥性来渗透的。冰晶在不同微位上受到的冥气压制差异在百万分之一秒内就会产生误差——对依赖千分之一毫米精度的人来说是不可接受的不确定。她不能在这种环境下同时还要对抗李长生。

舰队——全废了。不是全毁。帝者没让舰队爆炸——他只是毁了全舰队的"战斗能力"。在冥界区域内，八圣将的法力是断崖式跌落——八极焚烧阵自然解体。火焰护卫舰的能量推进系统在冥气的覆盖下全部退行到最低输出——无法完成对地精确攻击，无法执行近距离正面战斗。它们能飞——但已经变成金属壳子了。天网卫星不再打它们——因为没有威胁的目标不值得浪费灵符回路。"把火力从它们身上移开——让小胖把红烧肉全盛出来——仗不打了。"这是小王下的令——不是要停火，是算到了敌舰已经打不了才不再浪费自动拦截资源。

地面的龙组作战中心安静了好一阵。没有人欢呼——因为他们都知道这还没完。只是暂时赢了。

但暂时赢了就是赢了——至少把太阳拉回来了。这一天的日落在地面上准时来到——东八区傍晚七点四十二分。帝都西部天空的晚霞烧出一片安静的橘红色。人们在楼顶看着天空恢复成空无一物的暮色——不知道刚才那粒出现在夜空中的暗金色光点，是一个人。

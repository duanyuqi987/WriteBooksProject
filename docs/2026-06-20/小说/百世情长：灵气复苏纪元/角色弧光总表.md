# 《百世情长：灵气复苏纪元》角色弧光总表

**建立时间**：2026-06-20 17:59:05  
**版本**：v0.1 地基版  
**用途**：作为人物卡扩展、逐卷扩写、声纹统一和人物合理性检查的总入口。

## 使用规则

1. 本表只记录正文已出现或项目文件已确认的人物功能，不替正文新增未发生事件。
2. 后续新增角色卡时，优先从本表拆分。
3. 每个角色至少要回答三个问题：他/她想要什么、害怕什么、做过什么不可逆选择。
4. 主角弧光优先按卷追踪，配角优先按“首次功能、最大变化、后续风险”追踪。

## 人物合理性红线

- 林牧不能用“为你好”覆盖苏晚选择，尤其第十卷必须尊重她留下。
- 苏晚不能只作为林牧飞升的等待者；她必须在太行书院线中持续做决定。
- 后期配角不能只做主题口号的传声筒，每个关键配角至少要有一个具体欲望。
- 反派不能只因为“旧秩序”而坏，要写出利益、恐惧或价值观惯性。
- 锦鲤、老猫等异类角色不能替主角解决关键问题，只能提示、见证或调节节奏。

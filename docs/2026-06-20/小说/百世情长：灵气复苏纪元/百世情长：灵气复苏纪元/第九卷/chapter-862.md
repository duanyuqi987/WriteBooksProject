# 第八百六十二章 门照耀整个修仙界

随着飞升之门的吞吐量和自运行水平不断提升，更深远的社会影响开始出现了。修仙界此前千余年来一直存在着一股潜流——"反飞升"论者。他们或认为飞升是虚幻的，或认为飞升会破坏人间修仙界的稳定。其中一些是真心担心秩序崩坏的人，而另一些则是不愿改变既定权力格局的保守势力。

但在黄金时代元年的下半叶，这股潜流从根部开始迅速瓦解。因为二十二年了——飞升之门没有破坏任何东西。反而使人间修仙界更加安定。合道修士们纷纷加入飞升行程，元婴修士之间不再内卷，而是把精力投向如何让自己早日达到合道巅峰从而取得飞升资格。资源竞争固然存在，但整体从"零和争夺"转向了"共同成长"。

曾有一位以严厉保守著称的宗门宗主在二十年前公开骂飞升门是"外道幻想"，但黄金元年冬天，他的大弟子飞升成功并回来后向他展示了仙界守门人区的实景记录。这位宗主当夜在洞府中枯坐了半夜，第二天宣布宗门正式加入飞升预备体系中。后来他本人也在五年内达到了合道巅峰并通过飞升之门。在通道交互界面的那一刻，他迟疑了两毫秒——界面感应到并自动触发灵慰模块。门以低调而友善的语气在他意识中打了一行字："改变主意从来不是丢脸。欢迎。"老头子没有掉泪——但他在踏入光辉的那一刻，对着门的法则点了点头。

这件事被记录下来后，星眸把它归类为一枚"最不期待转意范例"。林牧后来查看分类时只对苏晚说了一句话："二十二年——他用了一次深呼吸的时间接受了二十二年的变化。这才是信任该有的样子。不急。"

到黄金时代第二年，飞升之门的"星光窗"已经遍布整个修仙界各大小门派和普通人居住区的夜空中。不需要有任何灵根——光是肉眼可见。从此每个夜晚都有一道柔和的光在北方天幕上安静地亮着，有人叫它"窗口"，有人叫它"天桥夜灯"。而住在远离青云山的人们也知道——只要愿意努力，这光下的路是通向着所有人的。

那个八十七岁未能飞升的老修士在晚年又给守门人写来一封信，只有一句话："我坐在你家门前的光线下摇椅上晒月亮。晒了二十二年。针不戳（真不错）。"

苏晚收信后珍藏于星眸中，并在备忘录上写下："来自最老的星光客——她说了'真不错'。这是我们听过的最好的赞美。"林牧在旁边也加了一条备注："比任何仙宫嘉奖令的分量都重。"

没有大的庄重的场面——黄金时代的实质就是这样：有越来越多人相信这光下的生活与飞升不是对立的关系，而信任是日常的、长久不息的、被无数星星点点的肯定所滋养的。守门人双尊也如星一般——静静地让这一切发生。他们唯一更频繁做的事情是和门对话——不是纠正，是每天晚例行的心意信号："安。——安。——安。"

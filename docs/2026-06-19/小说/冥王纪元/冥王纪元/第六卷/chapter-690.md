# 第690章 冥王帝国的重建

血脉延续完毕。纪念馆建成。新纪元生命已经起步。现在到了重建帝国的时候。

这个决定李长生想了很久。

帝国这个东西，在旧纪元曾是万恶之源——侵略、剥削、镇压、独裁——几乎所有文明都把帝国跟"恶政"划等号。但李长生知道，旧纪元最后的冥王帝国跟那些不是一回事。冥王帝国不是征服者建立的——是由被侵略之后联合起来的星域自愿组成的防御性政体。它不对外扩张，不压迫臣民，不搞种族歧视。它的存在目的只有两个：保护帝国所有成员不受外部威胁，并协调星域间的资源分配以减少内战。

但新纪元要不要复制这个模式？还是从零做更好的设计？

李长生最终决定——重建。但不是复制。冥王帝国将被重建为全新的形态。

核心原则有四条：

一、冥王帝国的疆域是防卫性的。它不主动征服任何星域，不对外输出主义，也不搞殖民扩张。任何星域、文明、种族都可以自愿申请加入帝国，也可以在任何时候自由退出。帝国存在的唯一军事意义是防御外部的大规模威胁——不是对内防范，更不是威胁邻居。

二、冥王帝国的最高法律是《永恒法典》——这部法典正在由旧纪元许冰留下的法律遗产编纂。法典的基石条款是："修士不能欺压普通人。"这将作为帝国的宪法锚点——所有其他条款都从这里衍生。

三、冥王帝国不搞中央集权制。帝国中枢只负责三件事——防御、法典执行、跨界协调。其余所有事务：经济、文化、教育、环境保护、城市建设、科技研发——全部由各星域自治。帝国中枢无权干预各星域内部治理。

四、冥王帝国不设皇位世袭制。皇帝不是由血缘继承的，而是由帝国元老院从帝国最优秀、最有品德、最有担当的修士中推选产生。皇位任期以千年计，到期后必须在全帝国范围内接受公开评议，评议不通过则必须退位。这意味着皇权是有监督的、有期限的、有约束的。

这四条原则，李长生写进了帝国基本宪章的第一页。

然后他开始筹建新帝国的物质框架。

中央星域——他选择了靠近纪念馆的一整片空旷区域。在这片虚空中，他牵引新宇宙的原始物质，建起了新帝国的中央星。这颗星不是行星，不是恒星——而是一块由混沌之力压缩而成的悬浮大陆。大陆面积大约是旧纪元太阳系整个冥王星轨道的十二倍。大陆上有适宜的引力、可控制的大气厚度、四季转化的灵气循环系统。

他给这颗中央星取名——"冥都"。

在冥都的中心，他建起了一座建筑：帝国中枢。中枢不是宫殿，不是要塞，而是一座由六栋建筑组成的综合中心——皇宫、法典院、议会、军事指挥中心、跨文明联络处、历史数据馆。这六栋建筑围成一个圆，中间是一片所有人可以自由出入的广场。

广场上也有一块碑。碑上刻着四个字："以民为本。"

这是冥王帝国在新纪元的第一块基石。没有黄金，没有宝石，没有神仙的法术加持——就一块普通的石头，刻着四个最朴素的字。

（第690章完）

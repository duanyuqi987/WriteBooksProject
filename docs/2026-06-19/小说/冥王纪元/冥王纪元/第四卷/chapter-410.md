# 第410章 再次出征

诸天号的出征仪式比交付仪式更简单。

没有直播。没有全球修士联合会的主席团致辞。没有任何人安排仪式的流程。因为这不是一次展示——这是一次出征。出征不需要仪式——出征只需要走。

北京时间凌晨三点，昆仑山灵眼总枢上方的夜空中亮起了一道极细的引力波脉冲。诸天号的人工黑洞动力炉在全功率预热——功率从正常的巡航水平飙升到了急行模式。灵眼的混沌灵气被黑洞动力炉全速抽取——昆仑山方圆三千里内的温度在那一瞬间下降了两度。不是因为气候——是因为黑洞把周围空间里的全部游离能量——包括环境热量的一部分——都吸进了动力炉的输入端。

李长生站在诸天号的舰桥上。舰桥位于船首最前端——一个直径三百丈的全景球形观测舱。舱壁全部由虚空晶石调校过的透明复合材料制成——不是玻璃，不是塑料，是一种被空间膜包裹的"硬真空结构"。它允许人眼直接看到外面的太空——同时把有害辐射、极端温差和空间碎片全部挡在舱外。

从这个舱望出去，能看到完整的银河系正面悬在诸天号的正上方。那条横跨了整个视场的银白色光带——是由几千亿颗恒星组合成的银河旋臂——正在以谁也无法感知到的速度缓缓旋转着。诸天号在这条光带下面就像一粒黑色的灰尘。

但这粒灰尘刚刚完成了人类历史上最震撼的一个动作——它在三秒之内从地球轨道加速到了光速的两百倍。三秒。上一次用冥王号走这条路，从地球到火焰帝国赤阳星走了七天。这一次走了三十秒。

"前方到达赤阳星。"导航系统的语音播报说得很平静——像在报地铁站名。

赤阳星外轨道上，火焰帝国的边境巡罗舰队在毫无预警的情况下看到了一艘八万丈长的超级母舰从一道空间裂缝中滑出来。舰队指挥官在那一瞬间做了他这辈子最快的反应——他没有开火。他直接接通了火云帝的紧急通讯。"陛下——冥王回来了。但不是上次的那艘船。"

火云帝在帝皇宫里从闭关中被叫醒。他在通讯中听完了指挥官对诸天号的现场描述——八万丈长、船壳表面泛着深灰色空间膜光泽、在抵达后三秒内就完成了所有系统的战斗预热——然后靠在修炼台上沉默了片刻。他想起了两年前李长生临走时对赤明说的那句话："我只要往西的路。"

现在他知道这句话的真实含义了。李长生不需要往西的路——他只是在等自己有了一艘可以走过那条路的船。

诸天号没有在赤阳星停留。它从火焰帝国空域中穿越而过——八个帝者级星区的边境检查站在那一天全部目击了同一艘船。每一位边境检查站的指挥官都做了同一件事：下令手下的所有战舰原地待命，不要开火，不要拦阻，不要做出任何可能被误解为敌意的动作。这不是投降——这是对一艘超出自身想象范畴的超级战舰的最基本尊重。

小王在导航系统中设定了完整的航线：从火焰帝国空域穿越，进入天狼联邦边境，再穿过苍古帝国与虚空行者领地的交界处，直接进入上古修仙帝国（古修族）遗址星域——作为诸天号的第一个远征目的地。到达遗址星域之后，诸天号将从那里出发，对宇宙西部所有还保持敌对态度的修仙帝国逐一进行"战术履带式清扫"。

"战术履带式清扫"是小王自己造的词。它的含义是：不打散兵游勇式的零星交锋——而是像履带一样，从西向东、从北向南，把整个宇宙西部所有已知的反冥王联盟成员文明全部扫一遍。每一个扫过的文明会收到一份由许冰起草的"中立声明"模板。签了中立声明的——诸天号不发动攻击。不签的——诸天号会出手。出手的力度取决于对方帝者的反击力度——如果对方选择正面应战，诸天号会在确保完全不破坏对方平民居住行星的前提下，集中攻击对方的军事力量核心:帝者本人。

这是李长生在两年前从观星档案馆回来之后定下的战略。核心逻辑很简单：反冥王联盟只有一个真正的敌人——缔造者太素。联盟中的所有帝者都是太素用来消耗他力量的棋子。他不应该把时间和精力浪费在清理棋子上——他应该直接找到太素。但要找到太素——他必须先扫掉棋盘上挡在中间的所有棋子。

"目标——统一整个宇宙西部。"小王在导航系统中标注了终点的位置——银河系西部所有已知修仙文明的全覆盖清剿区域。地图上的区域被分成了九十七个分扇区——每个扇区内的清除时间预估是二至五小时。九十七个扇区全部覆盖完毕的总时间预估——小王在日志文件里留下的那个数字让未来可能会读到这份日志的任何一个人都倒吸了一口凉气：一个宇宙标准月。

一个宇宙标准月。银河系西部。三百万恒星系。全部亲冥王化或中立化。

舰桥上，李长生坐在指挥椅中。陈霜站在他的右侧——霜降剑这次没有拿在手里，而是挂在了腰间新做的剑挂上。刀疤站在左侧——他从前天开始就站在那个位置上，好像在等着开第一炮。龟相蜷在李长生的膝盖上——它的龟壳在今天格外温暖。老陈靠在舱壁旁看手机——他的手机上正在显示全球修士联合会对诸天号出征消息的实时反馈数据——全球社交媒体热搜前二十全部被诸天号霸占。许冰在全息投影上同步显示着已经拟好的第一份中立声明模板——这份模板现在只有中文版，等她今天通宵加班就能出六十二种语言的版本。老马在舰桥后方的动力监控站——他的双手贴着监测台的地板，用土系法则感知着黑洞动力炉每一次微小的输出波动。厨师小胖在舰桥角落里的便携式厨房中烧开水——诸天号上的所有系统都做到了极致，唯独咖啡机还没装好。林晓在自己的医疗舱里检查着全舰所有修士的经络状态监测系统——这套系统是她用两年时间为诸天号量身定做的——能在一秒内扫描全舰所有乘员的身体状态。

所有人都在。所有人都在等李长生说一句话。

李长生没有站起来——他坐在指挥椅里，右手搁在扶手上，掌心冥王令的暗金色光芒在幽暗的舰桥中像一个安静的灯塔。他看了一眼舰桥正前方那片正在展开的银河西部星图——星图上那些红色的敌对文明在等着他去挨个敲开大门。他吸了一口气。然后只说了一句话——

"走吧。"

两个平淡无奇的字。一个三十岁的农民用这两个字从河北李家庄走到了银河系的边缘。现在他又用这两个字从银河系的边缘走向了更大的战场。

诸天号的人工黑洞动力炉发出了一声低沉的嗡鸣——这声嗡鸣穿透了虚空晶石的空间膜，传到了舰桥上每个人的骨头里。然后这艘八万丈长的、汇聚了万年前冥王智慧和万年人类血汗的、有史以来人类建造的最大的人造物体——在虚空中化成了一道深灰色的残影。

# 第260章 美国魔法学院联合欧洲组建太空联盟

华盛顿特区波托马克河畔的一座老建筑内，美国魔法学院的院长亚当斯·克劳正站在一块黑板前面。黑板不是木头的——是一整块经过了光系魔法加持的白水晶。他用一支镶嵌了光明符文碎片的粉笔在上面画了一幅图：左边是地球，中间是月球，右边是火星。三条线从地球上出发——一条线标注"中国（冥系修士）"，一条线标注"美国（光系魔法师）"，一条线标注"欧洲（圣殿骑士团）"。

中国的那条线已经伸到了月球。美国的线刚刚离开近地轨道不到几千公里。欧洲的线还在大气层的热障里打转。

"先生们。"克劳转过身，面对着会议室里坐着的十四个人——七位美国魔法学院的荣誉理事，四位五角大楼的高级官员，三位白宫的国家安全顾问。"你们看到的是一个事实。中国在修士登月这件事上已经领先我们一轮了。不是领先几个月——是领先一个完整的任务周期。他们在月球上找到了什么东西——我们的情报系统至今无法确定具体是什么，但有一件事我们可以确定:他们在月球地下发现了一个上古修仙文明的遗迹。那个遗迹里有数据库。数据库里有——"他在白水晶黑板上拍了一掌，水晶表面浮现出一串串被情报部门还原出来的残破数据碎片，"功法、星图、炼丹配方、修士等级体系。"

会议室里沉默了一会儿。一位空军的三星上将摘下眼镜擦了擦，重新戴上之后把头转过来对着克劳说:"你说的这些功法——我们能破解吗？"

"不能。但现在讨论的不是破解的问题——是获取的问题。先生，我们需要明白一件事:太空中的灵气资源是有限的。月球的灵脉只有一条，火星的灵脉可能也只有一条，小行星带的灵石储量虽然丰富但散落在数十万颗大大小小的岩石中，采集成本极高。谁先到达这些灵脉节点并建立具有排他性的灵气基站——谁就掌握了未来一百年太空修仙时代的基础设施。看清楚——不是掌握一部分，是掌握全局。"

"那你的建议是？"

"欧洲圣殿骑士团。"克劳在黑板上点了一下那条标注为欧洲的线。线的颜色从蓝色变成了金色。"我们单独无法在三年内完成载人登月——光明系魔法师的太空适应能力虽然比普通修士强一些，但在灵气稀薄的深空环境中同样会快速衰减。但圣殿骑士团手里有几件万年前残留下来的上古法器——其中包括一件具有定位能力的预知型遗物。这件遗物可以在灵气浓度极低的环境下工作——甚至可以在真空中定位灵脉节点。如果我们和欧洲合作，他们的定位遗物加上我们的光系推进技术，等于有了一套独立于中国冥系路线的、完全不同的太空修仙解决方案。"

"欧洲人同意合作？"

克劳没有直接回答。他重新从桌上拿起那支符文粉笔，在黑板上画了一个更大的圈——比地球、月球和火星加起来还要大。

"欧洲人在布鲁塞尔开会的时候提出了'自由采集太空灵气资源'的口号。他们说的'自由采集'不是无政府主义的采集——是在现有国际法框架之外开辟一种新的资源开采模式，不在任何一个国家的管辖范围内对自己的采集行为自行管理。这个口号的潜在意思是——谁先到，谁先采。谁的剑更利，谁占更多。"

他转过身。

"但欧洲人有一点没算清楚:他们的飞船设计能力不足以支撑这个野心。圣殿骑士团是古老的骑士修士组织，不是航天工程机构。他们懂剑术，懂阵法，懂仪式——但他们不懂灵波通讯，不懂轨道力学，不懂空间折叠稳定控制。这些东西——我们有。我们的魔法学院和NASA的联合实验室在过去一年里积累了将近两千万个灵波推进的实验数据。我们有能够将灵石转化为定向推力的完整推进链，只是转化效率还不够高。"

"效率不够怎么登月？"

"因为我们没有足够的灵脉数据。"克劳在黑板上补充了最后一行字——"月球灵脉坐标"。五角大楼的官员凑近了去看。那分明是一段被解密之后依然带有残缺标注的加密代码。"这段坐标是我们从中国灵波卫星的通讯记录中截取到的——残缺了大约三成。但已经够我们推断出月球灵脉的大致位置。如果我们和欧洲合作，把他们的预知遗物对准这个坐标位置——我们可以精确还原出月球灵脉的完整三维分布图。然后我们从西经方向发射登月船，不走中国使用的东经路径——走月球的背面。从背面切入，利用阴影区的灵波干扰作为隐身罩——我们可以在月球上降落、完成首次探测，甚至在他们反应过来之前完成灵脉局部开采样本的采集。"

"这是对抗性行为。"国家安全顾问开口了，语气是这个会议室里到目前为止最冷静的一个。"如果中国的地面监测站探测到我们在月球上的活动——"

"我们就告诉他们我们是在'自由探索太空灵气资源'。"克劳说。他在这句话上没有任何表情变化。"欧洲人已经为我们准备好了外交和法律层面的所有说辞。太空不属于任何国家。月球灵脉不是任何一个国家的领土。我们没有抢他们的东西——我们在采集'自由资源'。"

会议结束后，克劳一个人留在会议室里。他站在白水晶黑板前面，看着上面那幅地球-月球-火星的三角图。中国的线已经连到了月球，他的线还在低轨打转。但他不着急——今天的这场会议，他已经为它准备了整整三个月。圣殿骑士团的那件预知遗物——代号"先知之眼"——在两周前刚刚完成了第一次测试。测试的结果只有他一个人知道:先知之眼定位的第一个目标不是在月球——是在南海。

南海。中国大陆架向南延伸的边缘。那是中国灵脉网最南端的入海延伸段。在先知之眼的投影画面里，南海的海床下六百米处，有一团暗金色的光芒正在缓慢旋转——和克劳在截获的李长生直播画面中看到他右掌掌心散发出的光芒一模一样。不是普通的灵气。是冥土之力。南海的海床下面也有冥土。

克劳在白水晶黑板上擦掉了一条线——那条标注为"太平洋"的虚线——然后把粉笔在南海的位置上用力点了一个点。他没有写标签，没有画箭头，没有写下任何能够被后来者解读的标注。他只是点了那个点。

然后他关掉了会议室的灯，走了出去。

与此同时，在北京西郊的龙组总部地下三层，老陈的情报网监测到了两件事。第一件事：美国魔法学院和欧洲圣殿骑士团在三天前签署了一份保密备忘录——文件号虽然未知，但签署地点是日内瓦一家不对外开放的历史档案馆。这个地点不对——日内瓦是中立外交事务的传统地点，不是军事或修士合作的签署地。选在日内瓦意味着双方都不想把签约地点暴露给对方那一侧的情报人员——他们在中立场合完成了签约，然后分别飞回华盛顿和布鲁塞尔。

第二件事：在那份备忘录签署后的第二天，一艘打着塞舌尔旗帜的远洋科学勘探船出现在南海，停泊在中国岛屿领海以外的公海区域。船上有四名乘客的签证记录分别标注为"美国访问学者"和"荷兰海洋地质学家"，但老陈确认了一番——那两个"荷兰海洋地质学家"的签证照片，和李长生从月球带回的数据库里一张古老画像上的人脸相似度超过了百分之七十五。那张古老画像属于圣殿骑士团十三世纪的一位大团长。

"他们不是在做海洋地质调查。"老陈在电话里对李长生说，"他们在南海下面找东西。"

李长生握着手机，看着窗外城里的暮色。这一刻他脑子里想的是两件事。第一件事——南海海床下的冥土节点，龟相在三年前就告诉过他。那个节点不在地表灵脉网中，它在更深的位置——冥土层。而冥土层里的节点，只有冥系修士才能利用。第二件事——克劳是在试探。他用圣殿骑士团的那件古遗物探测到了南海的冥气反应，然后派了一艘船过去。他希望找到的东西，他不知道能不能用。但他想知道李长生的反应。

李长生的反应是——没有反应。

"继续监控。"他对老陈说。"他们如果只是在外围测量——不用管。如果下潜——通知我。"

"如果下潜了，我们怎么办？"

"南海是我们的。"李长生的声音很平——不是那种需要强调的平，是陈述事实的平。"他们来公海搞测量，随他们。但如果他们的潜水器越过大陆架边界——"

他停顿了一下。右手掌心的七道冥纹在暮色中无声地亮起了一瞬。

"我就去南海海底请他们出来。"

（第260章完）

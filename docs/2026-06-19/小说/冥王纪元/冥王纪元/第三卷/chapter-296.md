# 第296章 陷阱阵法，威力恐怖

火星离宫。碎片归位三天后。

李长生带着队伍从另一条通道返回冥殿。三天前取了碎片之后，防御系统切换到了待命模式——但待命不代表无害。离宫六层，他们上次只探索了第二层的冥殿。这一次他们从第四层的侧翼通道绕进去——通道的结构和之前走过的完全不同。这里不是通往修炼区的捷径，而是专门用来拖慢入侵者推进速度的陷阱区。

穿过第一道防线之后，四周安静得不正常。李长生走在队伍最前面，右手掌心的冥王令纹路保持着低频脉动——不是在备战，而是在感知。八道冥纹形成了不闭合的环，比三天前六道冥纹时的感知范围扩展了三倍不止。他的冥气化为无形的触须向通道深处延伸，每延伸一米，反馈回来的信息就冷一分。

"等等。"他忽然停步。

队伍在他身后停下。陈霜的手已经搭在了剑柄上。小王抱着笔记本电脑，屏幕上实时渲染着根据李长生感知数据生成的通道结构图。刀疤握紧了战斧——这把从月球战傀上拆下来的灵气兵刃比地球上的任何冷兵器都好用。工程师老马双手贴着通道侧壁，他的土系灵根正在感应墙壁内部的物质结构。

"前面三米——"李长生指着通道中一段看起来平平无奇的地面，"空间不对。"

小王盯着屏幕上的数据。李长生的冥气感知反馈显示前方那段地面的灵气密度和周围完全一致——石材、温度、空气成分——全是正常的。但李长生的判断从来不靠单一数据。他的冥王令能感知到比灵气更深层的东西——空间的本质。

"怎么个不对法？"刀疤问。

李长生没有回答。他从地上捡起一块碎石，用冥气包裹着往前一扔。

石头飞进那段地面的上空——然后在所有人的注视下，忽然消失了。不是爆炸，不是被什么力量击碎，而是直接消失。下一秒，那颗石头在三米外的天花板上出现了——从天花板往下坠落的石头。它在下坠过程中再次消失，又在左边的墙壁上出现。接着是右边的墙壁。接着同时出现在三面墙上。接着在同一瞬间出现在整段通道的所有表面——

然后石头碎成了粉末。

不是被击碎的。是同一颗石头的分子被同时拉扯到七个不同方向——空间本身把它撕碎了。

刀疤的呼吸粗重了起来："这是什么玩意儿。"

"空间阱。"小王的声音压得很轻，像怕惊动了什么东西，"通道内的一小段空间被折叠了——不是一次折叠，是多次嵌套折叠。进入那个区域的任何物体都会被同时拉扯到不同的空间坐标上。分子之间的化学键扛不住这种跨空间拉伸力——所以那颗石头不是被谁打碎的，是被空间本身扯碎的。"

陈霜的手始终握着剑柄，没有拔出来。她问了一个关键问题："能绕过去吗？"

小王在屏幕上调出了通道的结构图。他看了几秒，摇了摇头："这条通道是通往离宫深处的唯一路径。两侧的墙壁内部嵌着高密度防御阵法——土系加固、金系护盾、水系反弹——三层叠加。炸墙和穿墙都不现实。必须从这段空间阱中间穿过去。"

"穿过去？"刀疤看着那摊石粉，"你没看见那石头碎成什么样了？"

"所以不能硬穿。"李长生蹲下来，手掌按在地面上。他的冥气渗入地面，沿着通道下层的石材结构延伸。冥王令的力量能够感知到一切能量形态——包括阵法——因为阵法本质上是对天地灵气的约束性使用。冥王令是万年前冥王自己设计的法器，对所有以灵气为基础的构建物都有天然的解析力。

他感知到了。

空间阱的核心在三米深的地下——一个拳头大的空间阵法核心，由一个完整的灵石驱动。阵法核心周围环绕着七条空间折叠回路，每一条回路负责一个方向的折叠。七条回路叠加在一起，形成了嵌套式多向空间拉扯。

"核心在地下。单一灵石驱动。七条折叠回路。"李长生站起来，"结构不复杂，但解不开——这个阵法的触发条件是空间扰动。任何试图接触或破坏核心的动作，都会先触发折叠回路产生更大的空间扭曲。"

小王听了这个描述，脑子里蹦出了一个概念："这不就是——防拆弹装置吗？碰了核心就炸。只不过它炸的不是炸药，是空间本身。"

"许冰在就好了。"老马说了一句，"她是阵法专家。"

"她在地球上。"李长生说完，低头看了一眼手腕上的灵气通讯手环。

这个手环是龙组研发的新型装备——利用灵气量子纠缠原理实现地外通讯。原理说起来不复杂：两枚经过特殊淬炼的灵晶在量子层面上相互纠缠，其中一枚的状态改变会即时反映在另一枚上。这无法用来传输大量数据——每个灵晶对只有一个纠缠态通道——但足够传输语音、手写信息和低分辨率图像。小王把它称为"灵气对讲机"。

李长生接通了许冰。

"许冰。有个空间折叠阵法——七条回路嵌套，触发条件绑定核心。任何扰动都会触发。"

通讯那头安静了几秒。然后是许冰的声音，平稳中带着一丝职业病特有的条理："给我画面。"

小王用手环上的微型灵晶相机对准通道前方的空间阱区域，连拍了三张照片发了过去。照片上能看到那段通道的地面、墙壁和天花板——看起来一切正常，只有仔细看才能发现空气中有极细微的扭曲纹路，像热浪上升时的视觉效果。

许冰接收了照片。又安静了十几秒。

"空间阱——嵌套式七向折叠。底层逻辑和我在法律文书中分析过的'不可解除约条款'是同构的。看似七个独立条件，实质上是同一个根规则被投射到七个不同维度。关键不是分别破解每个回路——而是找到那个根规则，从源头撤销。"

她在通讯里说的"不可解除约条款"指的是她在执业过程中遇到过的最复杂的一类合同条款——典型的人类狡猾产物。而她此刻要面对的是万年前某位阵法大师设计的空间陷阱。在法律框架里找根规则是一回事，在阵法里找根规则是另一回事。

但许冰的态度听起来不像在说两件不同的事。

"给我五分钟。"她说。

李长生转头看向小王："把这段通道的灵气波动数据全部打包发给她。所有波段——地面、空气、地下、墙壁。给她完整的数据集。"

"已经在传了。"小王的笔记本屏幕上正滚动着数据传输进度条。他同时开了八个灵气探测频道，把空间阱区域的所有可测数据全部打包——总数据量不大，但对于许冰的分析来说应该够了。

等待的这五分钟里，陈霜绕着空间阱的前沿走了一圈。她的冰系灵根在空气中留下一道极细的白色轨迹——寒气的物理痕迹。寒气穿过空间阱边缘的时候，发生了肉眼可见的偏折。不是被吹散——是在没有任何气流的情况下，纯物理层面的轨迹扭曲。

"不止七层。"陈霜忽然说。

她让更多的寒气从指尖释放，形成一层薄雾覆盖在通道的边缘区域。薄雾在空间阱前沿勾勒出了一张复杂的轮廓——不是一块区域，而是一个立体的图案。七条主线之外，还有至少十二根更细的"支线"，像血管一样从主线分叉出去，延伸到整段通道的墙壁、地面和天花板上，形成了完整的空间覆盖网络。

"不只是陷阱。"李长生看懂了，"是锁。空间阱是一把锁——不破解这把锁，整个通道就是死的。"

就在这时，许冰的通讯回来了。

她的声音依然平稳，但语速比平时快了将近一倍——这是她脑子全速运转时的特征："找到了。根规则不是空间折叠——空间折叠是表象。根规则是'边界排斥'。这个阵法的底层逻辑是：禁止任何非授权对象跨越阵法边界的空间连续性。空间折叠只是执行这个根规则时的副作用。"

"解法呢？"

"不从空间层面破解——从授权层面破解。阵法对'授权对象'的定义依赖于另一个独立的参数：灵气标记。如果你能让阵法识别你的灵气标记为'已授权'——那你就不会被排斥。空间折叠对你就不生效。"

李长生低头看了看自己的右手掌心。冥王令的纹路正在缓慢明灭。

冥王令能压制一切灵气，但能不能让自己的灵气被阵法识别为"已授权"，这是一个完全不同的问题。压制是需要力量的——而伪装，需要的是理解。

"许冰——这个阵法判定授权的底层逻辑是什么？"

"看数据。"许冰那头传来快速敲击键盘的声音——她调出了和小王共享的数据集。十几秒后，她的回答来了："授权标记的认证协议是通过灵气频率匹配实现的。这其实是一种安全系统——和现在的加密通讯原理类似。阵法预设了一组'白名单灵气特征'。任何灵气特征匹配白名单的对象，就不会被空间排斥。"

"白名单里是谁？"

"只有一种灵气——冥气。"

通讯频道里安静了一瞬。

陈霜忽然笑了。不是开心的笑——是那种意识到某些巨大因果联系之后，只有用笑才能释放情绪的笑。

"这是冥王自己修的离宫。"她说，"他的阵法，只认他的灵气。一万年后，唯一带着冥气来的人——是李长生。"

李长生没有再说什么。他吸了一口气，掌心的冥王令纹路完全亮起——不是战斗中那种暴烈的黑暗，而是一种温润的、内敛的暗金色光芒。冥气从他的掌心释放出来，像一层薄纱覆盖在他全身。

他迈出了第一步。

脚踩进了空间阱区域。他的身体表面出现了肉眼可见的空间扭曲——折叠回路在尝试拉扯他。但冥气形成的保护层在他的身体表面形成了一个密闭的球面。空间折叠的力量在接触到冥气层的时候，发生了微妙的变化——阵法识别到了"冥气"这个白名单标记。

空间折叠在最后一刻松开了。

李长生穿过了空间阱。他的身后，那片危险的空间扭曲依然存在——但对于带着冥气的人来说，它只是一段普通的通道。

"过。"他回头说。

（第296章完）

# 第七百八十五章 上界灯火塔

联合共治会第二十四年的春天，上界母树平原的边缘竖起了一座新塔。

塔的位置是林牧选的——不是用罗盘选的，是蹲在地上用树枝画了个圈。那个圈刚好落在母树正北方向约莫一百步的位置——从塔顶可以同时看到母树的全冠和第二道门的门缝光芒。他画完圈后把树枝插在圈中央，转身对等在一旁的秦无夜说："这里。"

砌塔的石头从地面太湖边上运来的。不是太湖青石——太湖青石太软，在过渡区的灵气环境下会风化。这次用的是太湖湖底的一种深青灰色玄武岩——每一块都是从湖底挖上来的。孟长青自告奋勇负责选石材——他在太湖边上住了大半辈子，闭着眼也能靠手感挑出哪块石头内部没有裂纹。他每天坐一艘小船到湖中央，用竹竿探到湖底，再用长钳一块块夹上来。每夹上来一块，他会用指关节敲三下——听音。声音脆的就留下，声音闷的就扔回去。

"石头要脆的。"他对帮忙运石头的杜散修说。"闷的里面有暗缝——砌上去三年就裂。"

杜散修把石头装上灵舟时，每一块都用草绳捆了十字结。他在绳结上涂了一层松脂——这是他年轻时煎药时学的习惯，松脂能防水，防绳绳在潮湿天气散开。

石材总共运了一千二百块，分了三趟灵舟搬完。从地面到上界过渡区的飞升通道还没有对大宗货运开放，所以每一趟都要经过人工安检——负责安检的是一个当年参加过第一次飞升通行的老修士，他检查每一块石头，不是检查有没有危险品——是检查石头表面有没有虫蚀。"有虫眼的不能要，进了虫眼的湿气在上界会冻胀。"

塔基选了八块最大最方的玄武岩作为基石。八个角——林牧亲手在每块基石上刻了一个向上螺旋。不是装饰——是阵基——他要把塔建成一个可以传导灵力但不消耗灵力的"被动接收站"。原理和石凳上的便签一样——它不需要能量，它只需要位置。

第一块基石放下的时候，秦无夜在基坑底部倒了一碗粥。不是祭奠——是她的习惯——"灶台底下不浇水泥浇米水——米水干了之后地基更稳。"她把粥沿着基坑底部均匀地洒了一圈，然后接过杜散修女儿递过来的水平尺，确认基石完全平正。

塔的砌筑是从桂花树的新生枝条中汲取灵感的。林牧画的设计图不是方塔——是螺旋塔。塔身从八块基石开始，每砌一层就向内旋转约莫三度——一直往上旋，旋到顶的时候刚好转了九十度。这样的结构不需要任何灵力支撑就可以在过渡区的银白色天穹下稳定站立——因为每一层砖都压在前一层砖的斜裂缝上，重量的分布是螺旋分摊的。

砌砖的主力是桂花园学院的两届毕业生。他们没有工钱——不是不给，是他们不要。其中一个叫小林的学员说了一句代表所有人的话："我们以前被教的是'强者不需要弱者'。现在我们要亲手砌一座塔——证明'弱者也能帮强者站得更稳'。"

小林负责砌塔身中段的弧面砖——这个位置最需要耐心，因为每一块砖的斜度都不一样。他每天从天亮砌到天穹变暗，中间只喝两碗粥。有一天下雨——过渡区的人工降雨系统出了故障，雨水比平时大了两倍——小林脱了上衣盖在刚砌好的砂浆上，自己光着脊背继续砌。他的后背被水泡出一层淡红色的疹子，但他把那一层砌完了才下来。杜散修的女儿用灶台日志记录了这件事："小林为砂浆盖衣服——说砂浆比他怕冷。——杜小月。"

塔顶最后一层砌完的那天是一个极寻常的下午。没有仪式。没有讲话。林牧把最后一块封顶石——一块手掌大小的八边形玄武岩薄片——放在塔尖的凹槽里。他放下去的时候，整个螺旋塔身发出了一声极轻极低的嗡鸣。不是灵力被激活——是风从螺旋砖面中穿过——风被螺旋引导和压缩——变成了一声持续了大概三息的共鸣音。杜小月站在塔下，戴上胶耳塞——但她没有塞耳朵——因为她想听完整。

"声音频率——大概和太湖灶台的沸水声在同一个频段。"她摘下耳塞，对着记录仪说完，把耳塞放回口袋里。

塔里的灯火是从地面运来的太湖火种。但这次不是用普通的金属罐运——是用一口便携灶台。灶台是石头从桂花园总院亲自送来的——他把灶台放在飞升通道入口，点上火，一路上什么也没说，只递了一句话："这火从第一卷到现在——没灭过。"

林牧接过灶台时，灶台上的米汤还在微沸。他把那团从地面桂花树下灶台中分出来的火苗——用一对极长的铜质火钳——夹进了塔顶的灯盏。灯盏是秦无夜用北境雪原城的古铁锻造的——她说："北境的铁最耐风——在折叠空间的低温下也不会脆。"

火苗入盏的瞬间，过渡区的银白色天穹在塔的正上方撕开了一道极窄的裂口——裂口的颜色和金紫色火焰完全一样。裂口只持续了不到两息就合上了——但所有在场的人都看到了它。

"门在回应。"杜小月说。然后她低头在记录中追加了一条——"灯火塔封顶点火——上界天穹出现短暂同频裂口——同步确认。——杜小月。"

塔身从此每晚亮起金紫色的光，和地面的太湖灯火塔一模一样——光从螺旋砖层的缝隙中透出来，不是直射，是从每一道螺旋中漏出来的，在塔周围的青灰色地面上画出一圈圈旋转的光纹。母树的树冠被光照到时，新叶会在光纹中轻轻转动——向着塔的方向偏转，大约半度的角度。

秦无夜把便携灶台留在塔脚。灶台上她放了一张便签——"塔已亮。后来者——灯里的火是地面移来的——如果灭了，到地面太湖边重新要。那里有永远的灶火。——秦无夜。"

赵姑在收到这张便签的当晚，往太湖灯火塔的灶台下多加了整整三块柴。她对帮她看火的小徒弟说："上界的塔是咱们砌的。火是咱们给的。柴不能断。"

小徒弟点头，又往灶膛里加了一根桂花枝。

（第七百八十五章 完）

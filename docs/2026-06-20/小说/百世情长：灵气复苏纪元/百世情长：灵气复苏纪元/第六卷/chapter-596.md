# 第五百九十六章 松鹤的生日

松鹤仙人的八千年整寿在迎仙台办了一场极其符合他风格的小规模庆祝会。来宾只有几桌子旧友——包括他自己（当然是主角），林牧苏晚，寻青守望，弦歌茶馆那位说书人，仙果园推广异步采摘法的果农代表，南离城那位曾经给他们登记通灵道侣名录的女仙官，以及他从小养大的那头老驴专门负责在门口挂着"今日休息——寿星在吃面"。老驴脖子上系着松鹤亲手用旧红绳打的一枚极笨拙的蝴蝶结。

苏晚做了蒸鱼和手擀面——面切得极均匀，卤是松木熏豆干。林牧劈了一根精选的八千年松木——不是用来烧火，是把这整根完整劈壳的松木作为生日礼物送给松鹤。劈完之后他将松木靠在迎仙台门口——松木截面上年轮密密匝匝正好可数数千圈。他说:"这根木头的年纪和你差不多大。劈开了，里面还在发松香。"松鹤用枯手摸了摸松木截面上的树胶——极新鲜极亮，像刚被切开。他把这块松木放在他石凳旁边——从此当扶手。

说书人当晚即兴给松鹤唱了半短歌《八千年等两个人》。歌词一共只有几句:石凳坐破，茶壶煮锈;等了八千年风和雨;终于等来劈柴的。尾句是——"如今迎仙台上劈柴声，是他替他磨了八千年剑的回报。"松鹤听完后推老花镜擦了擦——说是茶太烫熏了眼。众人不拆穿。

宴会尾声时寻青仙子和守望真仙捧来一个礼物盒子——是一对用双星图道场旧松木做的小木牌。牌上刻着"谢"和"恩"。守望说:"我们从第一眼看到迎仙台那面碑就觉得——你们是我们的幸运符。现在这个符刻在木头上——"他把"谢"交给松鹤，把"恩"交给林牧苏晚双手一起。松鹤接过谢牌看了一阵——然后把他那颗攒了八千年的小小的灵芝从抽屉中取出来，别在谢牌的背面送给两人。"这颗灵芝很小——吃了不会成仙——但偶尔含一片可以回甘，回你当年在我茶壶里倒白水那半杯的分量。"苏晚收下——她将灵芝片放进黑木盒最上层和那封万年前的信贴在一起。

散席后林牧和苏晚帮松鹤收拾石桌。松鹤忽然没来由地说了句:"谢谢你们把迎仙台从八千年的等待变成有劈柴声的院子。"然后他转身走进他的小库房把那只老驴的蝴蝶结重新系一遍——边系边哼《百世情长歌》第一回"石桥初遇"的副歌。老驴安静地听着。迎仙台的暮色和以往所有的暮色一样——但又不一样。

（第五百九十六章 完）

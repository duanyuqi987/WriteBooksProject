# 第532章 代价惨重

冥王令砸碎星渊王引力宝座的那一刻，帝国前线爆发出了震天动地的欢呼声。全息屏幕上——那颗暗金色的令印像一颗流星一样从敌阵中飞回来，稳稳落在李长生掌心。

但欢呼没有持续太久。

星渊王退到了舰队后方。他没有逃——他是在重组攻势。引力宝座被砸碎让他损失了大约两成战力，但他仍然是三阶仙王，剩下的战力依然足以对帝国防线构成毁灭性的威胁。他的引力炮舰队在撤退过程中维持着持续火力——每一炮都让一片空间在短时间内变成高压高重力的炼狱。

帝国第七层防线的驻守舰队是这一轮打击的重点目标。七层防线上原本有约一万三千艘舰——全是帝级以下的中小型快攻舰艇，配合许冰的戒律阵列进行骚扰性反击。星渊王的引力炮在预热完成后打了三轮齐射——三轮下来——七层防线损失了超过九千艘舰。

"七层防线全线崩溃。"老陈在指挥频道里报告——他的声音第一次出现了一丝沙哑。"驻防部队两名圣者级将领——全部阵亡。余部正在往八层撤退。但星渊王的舰队追击速度太快——撤退伤亡惨重。"

他停了一拍。

"八层防线准备接应——但在八层防线之前，七层防线驻军的残余舰艇可能不到一千艘。"

不到一千艘——从一万三到不足一千。这是开战以来帝国损失最严重的一道防线。

"八层的状态？"李长生问。

"完好。"老马替老陈答了——他是八层防御阵法的负责人。"冥土断界阵全部激活。八层有我们的重型防御舰队——四万艘帝级主力舰。加上许冰的戒律阵列第四层覆盖——理论上可以挡住星渊王的引力炮。但——"

"但是什么？"

"引力炮不分敌我。星渊王如果决定硬穿八层——他可能直接用引力压塌空间形状——让八层阵中的所有舰艇同时承受数十万倍重力。"

"代价是他自己的舰队也会被波及。"

"是的——但星渊王不在乎这种折损。"

"他不在乎自己的舰？"

"重装舰艇没有舰上修士——全是傀儡操控。他的每一艘舰都是一颗改造灵脉星——没有人在上面。所以他可以随意拿自己的舰队当炮弹使。"

李长生沉默了。星渊王——他对战术不感兴趣。他只对碾压感兴趣。而碾压——要求的就是不计代价。

八层防线的攻防战在半小时后开始。星渊王果然选择直接压塌空间——他抽调了大约一万艘无人傀儡舰——集结在八层防线正前方——然后同时引爆了舰上的全部引力引擎。一万艘舰的引擎引爆——炸出了一个黑洞级别的重力井。

八层防线的灵石护盾在这样的重力下像纸一样被捏皱了。四万艘帝级主力舰中——至少有一万一千艘的舰载护盾在一瞬间被过载烧毁。舰体没有碎——但舰内的修士在自身重量突然暴增数千倍的内部环境中——大量受伤。有些人被迫闭气强行护体——勉强扛过去——更多的在重压下直接失去了战斗力。

"八层受损——一万一千艘被迫撤出战斗。剩余两万九千艘还能打。"老陈报数，"但星渊王的后继力量——他的主力舰队正在涌入重力井。"

暗潮王到了。

四天前谛听-13预测的八小时抵达时间——现在兑现了。第五平行宇宙——五十五万艘暗物质舰队——一片由黑色流体构成的军舰之海。这些舰艇不完全在常规空间中——它们处于一种叠加态——每一艘舰同时存在于多个维度的交界处，只有开火的那一刻才会完全显现。常规雷达和灵觉感知对它们都难以捕捉——因为它们不存在于任何确定的坐标上。

暗潮王本人——二阶仙王——站在旗舰"暗渊"上。他的身形是一团不断变化形态的黑雾——没有确定的实体形态。他不靠物质攻击——他靠"暗物质渗透"。暗物质渗透不会被物理护盾阻挡，不会被灵石护盾阻挡——因为它穿透的不是空间，而是组成护盾的粒子本身。

八层防线在两股仙王的合力打击下撑了不到一个时辰。崩了。

"八层防线全线溃退。"老陈在通讯频道里喊——他用拳头砸了一下指挥台。"九层、十层全部投入！所有预备役——全数入列！"

他的声音在整个帝国舰队的通讯频道中回荡。

这一刻——帝国已经祭出了全部防御力量。十二层防线——前八层已经废掉了大部分。仅存的后四层——九、十、十一、十二——是帝国最后的纵深。再退——就是环形工业带，就是帝国心脏。

而且——不止是防线被打残。舰队损失惨重，更致命的是人员。

"战损统计。"小王调出了截止目前的累计数据，"开战五天——我方舰艇损失——约三十八万艘。修士阵亡——约四百万。"

占原本全兵力的三分之一。

"伤员——约七百八十万。其中重伤——约两百万。"林晓在灵医总署的频道里报出了医疗数据，"帝级修士——李队轻伤，暂不影响战斗。刀疤重伤，左臂骨折，肋骨碎了四根，但体修体质已做紧急处理。许冰——灵气透支，暂时不能启动戒律阵列。老马——阵法消耗过巨，灵识暂时无法运转。"

"陈霜呢？"李长生问。

"我没有受伤。"陈霜的声音从铁脊号那边传来——但她的声音哑了。她在前线连斩剑修舰——灵力消耗已近透支。

李长生闭上了眼睛。七天。打了五天——帝国减损了三分之一舰队。而敌方——万剑王被打残撤出，星渊王被砸坏引力宝座，暗潮王刚抵达——但联盟还有六位仙王没有出现。前方还有超过四百万艘敌舰。

这是一场耗竭战。看谁先撑不住。

（第532章完）

# 第941章 时光的余韵

上界第一百年到第两百年之间——是太行传道堂的"静默扩张期"。传道堂不再依赖苏晚的个人能量发展，而是以规则本身的惯性运作。白羽令在担任堂长的三十年间将传道堂的规模扩大了三倍，覆盖了太初之城圈几乎全部近城区域。元枢的道纪院在此期间出台了一系列辅助底层教育的规定——包括免费提供基础修炼物资、开放公共道场和允许底层仙童公办入学。这些都是净微最初那份方案逐渐发酵的结果。

苏晚退居幕后之后并没有停止活动——她的方式变了。从亲自上台授课变成了到处"偶尔拜访"。她每个月随机走访传道堂系统里的某个分部，事前从不通知。到了之后也不检查工作——只是坐下来听一堂课，然后和导师坐下来喝杯茶谈谈教学中的酸甜事。她的到场不发号施令——只提供"陪坐"。这种看似缺乏效率的做法在底层导师群体中产生了意料之外的影响：导师们知道她不会给他们打分——她只是从一个千年教龄的老教师角度来陪他们放松。于是导师们在她的参与中渐渐习惯了平等教学的身姿——从不俯视任何人，从未跪拜任何人。

林牧也开始了他的第二个计划——道源第三形态研究。第二形态已经能散布延寿微粒给守护道的人。第三形态则是他探索的终极形态——将道源转换成一种"可持续再生的公共善源"。这个形态的本质是将苏晚体内的道源从"个人恩赐"升级为"组织基座"。一旦成功，整个太行传道堂体系内的底层修士（不仅仅是少数特定人选）都能被动受益——自动获得微量的寿命延长，让他们有更多时间去修成正果。成功率目前只有理论上的百分之五——因为第三形态需要再找到三粒源尘来稳定施术者的连接力。源尘藏于第九重霄的暗界——进入暗界需要再次离日级别的法则空白窗口。要等下一次离日——还有八千多年。急不来。

但苏晚不急。她有了无限的时间去实现任何事。她对林牧说："八千多年——我们可以先做其他的。比如学会做不同口味的面饼。"

于是他们有几年时间真的在认真研究面饼——把上界的各种谷类和下界的传统工艺结合，创造了一种"双层脆面饼"——外层是上界星光麦的酥壳，内部是纳戒中千片银杏叶发酵后的面团，烤出来外酥内软。他们把这饼命名为"岁月饼"——送给每一届传道堂毕业生的毕业礼饼。一饼三味：酥壳是上界、糯面是下界、夹层是他走千年的路上她磨出的葱花粉。每个毕业生咬着饼时都会嚼出不同的味道——有人吃出故乡，有人吃出希望。核心味道固定一种：时间被爱磨细后的颗粒感。

再往后——太初之城上界底层仙人联谊大会每十年一次，太行传道堂自动成为承办方之一。大会广邀天下底层仙人比试修炼成果、交流手工技艺、和交换各地传道堂的办学经验。苏晚和林牧被聘为终身荣誉顾问。他们每次都去——去了就坐在场边的普通席上，不吃不喝不观赛——就安安静静看着来来往往的底层仙人。苏晚说："我看他们的脸——每张脸上都在亮。这不是单纯因为赢了什么，是他们的眼神里没有'怕'了。"

林牧说："我也看——我看的是你看到的那些人。"

苏晚转过头看他的眼。他的瞳孔现在还偶尔会闪一下淡金色的光——那是九百多年前他在写字楼楼下电梯中看到的第一缕灵气复苏光芒的折射。那道光的来源早已消散，但他瞳底残留的一丝微光被她捕捉到了。

她把拇指举起来，对准他的眼——不遮太阳，只是放在他面前问他："你现在瞳孔里的是什么？"

"是你。"

他说"是你"两个字时一如既往地认真。她笑了一下——然后把拇指收回去轻轻蹭了下他的手指尖。

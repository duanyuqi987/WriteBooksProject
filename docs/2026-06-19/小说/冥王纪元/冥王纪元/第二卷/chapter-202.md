# 第202章 番外七：退伍军人刀疤的战场往事

刀疤脸上那道疤从左眼角一直拉到下颌骨的下沿。十二厘米长。不是笔直的一条——是歪歪扭扭的，中间有三处分叉。缝了四十七针。拆线那天，军医跟他说了一句话:"幸亏弹片是从外侧擦过去的。再往里偏三毫米，你的左眼就没了。"

那是九年前的事了。

九年前，刀疤二十七岁，在某边防团侦察连服役，军衔二级士官。他所在的侦察班驻守在西部边境的山地防区，海拔四千两百米，冬天最低气温零下四十度。他们的任务是巡逻一条四十七公里的边境线——山脊、河谷、冰川和垭口。没有公路，全凭两条腿。一趟来回四天。

那天是腊月十三。刀疤带了一个三人小组——他、副射手刘大伟、通信兵周泉。任务是在三号垭口附近进行例行巡查。清早出发的时候天还是晴的，到了中午，暴风雪来了。山口里的雪片不是飘的，是横着飞的。能见度不到十米。

他们在垭口的石头掩体里等了两个小时。暴风雪没停，反而更大了。刀疤准备下令撤回——就在这时候，周泉的通信设备收到了一段断断续续的信号。不是他们的频段。是境外频段。

刀疤拿起望远镜，把镜头在雪雾中扫了三遍。第三遍的时候他看到了——在垭口另一侧大约三百米的位置，有六个人影正在翻越山脊线。不是走路——是行军。六个人，全副武装，负重行军速度极快。他们的方向是往我方境内。

"敌情。"刀疤放下望远镜。"六人小队。武装越境。方向我方。"

周泉紧急发报。但暴风雪把信号打了回来。刘大伟问要不要先撤回找增援。刀疤算了一下时间——撤回再带人来，至少六个小时。六个人在暴风雪中只需四十分钟就能翻过山脊进入我们的境内。

他做了决定。

"打。"

三个人，对六个人。地形是垭口乱石堆——石头是天然的掩体，但暴风雪让视野和弹道都变得不稳定。刀疤把周泉安排在后方五十米的高点上，用通信设备持续尝试联络后方。他和刘大伟占据了垭口两侧的制高点，形成交叉火力。

对面的六人小队很快就进入了射程。他们显然也没想到在暴风雪中会遇到伏击——队形松散，没有掩护动作。刀疤等到最前面的两个目标进入了不到一百米的距离，才扣动了第一枪。

打中了。第一个目标倒地。第二个目标扑倒在乱石后面。

然后对方还击了。

枪声被暴风雪压得闷闷的。弹头打在乱石上溅起的碎石比子弹本身更危险。刀疤在换了三个射击位置之后，发现刘大伟那边的枪声停了。他用瞄准镜扫过去——刘大伟趴在他的掩体后面，右肩有一摊血，颜色被雪衬得刺眼。

"大伟！"刀疤在通信频道里喊。

"没事——肩膀穿了个洞——还能打。"刘大伟的声音咬着牙。

然后一枚手榴弹在他掩体前面炸了。

刀疤只记得三件事。第一件事是爆炸的气浪把他从掩体里掀了起来，后背着地砸在石头上。第二件事是他翻过来的时候看见周泉从高点上冲了下来——通信兵操起步枪加入了交战。第三件事是他听见了一声极尖锐的、金属划过空气的啸叫。

一枚弹片从他的左脸颊斜着划了过去。

他倒下的时候，战斗还在继续。

后来他在野战医院醒过来。脸上缠满了纱布。刘大伟躺在他旁边的床上，右肩的弹道伤口被裹成了一个人的半身大小。周泉坐在门口的地上，通信设备抱在怀里，脸上全是冻伤的紫斑。

那一仗的结果:越境的六人小队，击毙四人，击伤俘虏两人。我们的三人小组——刘大伟右肩贯穿伤，刀疤脸部弹片伤及左眼外眦，周泉多处冻伤但无外伤。三人全部存活。

对方身上搜出的地图上，标注着深入我境的一条路线——目的地是我方的一座边境雷达站。

后来上级给他们全班记了集体二等功。刀疤个人荣立三等功。他伤愈之后，左脸的疤就永远留下来了。左眼保住了，但左眼视力和右眼不再匹配——左眼看东西会比右眼稍微模糊一点。平时不影响生活，但用瞄准镜的时候，他会下意识地把右眼贴得更紧。

两年后他退伍了。不是因为伤——是因为服役期满。退伍之后他回了老家，在县城的工地上找了一份活——搬砖。不是工头，不是技术工，是搬砖。从货车上把砖一摞一摞地卸下来，搬到工地上。一摞砖三十块，一块砖四斤，一摞一百二十斤。一天搬两百摞。

工地上的人叫他刀疤。没人知道他的全名，也没人问。只知道这个人干活不偷懒，力气大，从来不在工头背后抽烟。工头是他以前的战友——老排长退伍后在县城搞建筑，给了他这份活。工头有一次喝多了跟他说:"疤子，你在部队立过功。我可以给你安排个轻活——守仓库、看监控，工资一样。你为啥非要搬砖？"

刀疤想了想。"搬砖踏实。手上有东西，心里不慌。"

他搬了三年砖。

三年之后，工地底下挖出了灵石矿脉。

然后全国的天地都变了。

刀疤的体修天赋是在一次意外中被发现的。那天塔吊的钢缆断了，一捆钢筋从十二米高的塔顶往下砸。底下站着三个工人。刀疤当时正在旁边卸货，听见钢缆断裂的声音，抬头一看——钢筋正朝那三个人的位置砸下去。

他的反应是本能。不是躲，是冲。三秒钟跑过四十米的距离——工地管理员后来看了监控录像，说那不是跑。那是一道黑影。三秒四十米不是什么超能力——受过严格训练的军人在战场上能跑出这个速度。但接下来发生的事就不是了。

他跑到钢筋底下的同时，钢筋也到了。他的两只手向上举——抓住了一根下坠的钢筋。

钢筋是32毫米直径的螺纹钢，一根长12米，重量将近一吨。从十二米高处落下来的动能，大概是一辆车以六十码速度撞过来的力量。

刀疤的双手接住了那根钢筋。

不是挡——是接。双臂下沉了一下，卸掉了下坠的冲击力。钢筋停在他头顶上方大概半米的位置。他的脚底把工地上的模板踩裂了，木屑飞溅。

三个工人傻站在旁边。

他把钢筋扔到地上，拍了拍手上的铁锈。后背的脊椎骨在隐隐发烫——那种烫不是疼，是一种从他入伍时就有的本能。在战场上拼命时，肾上腺素会钝化疼痛。但这不是肾上腺素。这是某种更深层的东西。是灵气复苏之后，沉淀在他老兵身体里的、在每一次极限训练和实战中挤压进去的灵能——终于找到了一个出口。

之后他就被灵管局找到了。他被归为体修——肉身力量型觉醒。测试结果:灵者境初级，但肉身强度和爆发力已经接近灵者境巅峰。灵管局的鉴定员在报告上写了一行备注:"被测者未接受过任何灵修训练。其体修能力全部来源于服役期间的极限体能训练和实战经验的自然转化。"

意思是:他在不知道什么是灵气的时候，已经在用灵气了。

刀疤加入了李长生的队伍是后来的事。他没有豪言壮语。他只是发现李长生这帮人和他见过的所有人都不同——他们的对手不是某个具体的敌人，而是整个修仙界的旧秩序。刀疤这辈子最熟悉的事就是打仗——不是书上的战争理论，是真正的、在雪地里趴着、在石头后面躲着、在弹壳滚到脚边的时候继续瞄准的战争。他知道自己在这个团队里的位置:不是军师，不是领袖。是矛头——当需要有人在最前面顶住最大压力的时候，那个人就是他。

他在修炼上是全队最拼的。不是天赋最好——他的灵根品级很普通。但他的训练强度没有人能比。每天凌晨四点起床，负重一百公斤越野跑二十公里。然后是两个小时的力量训练——不是举铁，是他在工地上发明的一种练法:用土系灵石催动地底引力，把自己的身体重量增加三倍，然后在这种超重力下做俯卧撑、引体向上、深蹲。晚上再做一小时抗击打训练——让老马用土系石拳对着他轰，轰到他全身上下青一块紫一块为止。

有一次，小胖问他为什么不休息一天。

刀疤咧了咧嘴。他的左脸那道疤在咧笑的时候会皱起来，像一条活的蜈蚣。

"小胖子，你当兵那会儿——算了你没当过兵。我告诉你一句话:平时多流汗，战时少流血。"

那是他在侦察连学会的第一条铁律。班长第一次带他进训练场的时候说的话。班长退役的时候送了他一双新的作训鞋。这双鞋现在还放在他床头——鞋底都快磨穿了，但他不舍得扔。

后来的事大家都知道。西藏大战中，刀疤一个人扛住了玉虚宗三个剑修长老的围攻，从午夜打到天亮。他的身体被剑气切开了十一处伤口，最深的在右肋——差一寸就到了肝脏。但他没有倒下。因为后退一步，他身后的许冰和老马的防御阵线就会被打穿。

他撑着最后一道防线，像当年在雪地里撑着他那两个受伤的战友一样。

仗打完之后，林晓给他缝合伤口。针穿过他的皮肤的时候，他眉头都没皱一下。林晓说你疼不疼。他说比起左脸那次——这点感觉不算疼。

林晓后来问起那道疤的来历。刀疤就讲了九年前那个暴风雪中的垭口。

"你怕过吗？"林晓问。

"怕。"刀疤没有装。"在雪地里那场——怕。钢筋落下的时候——也怕。面对三个剑修的时候——也怕。但怕和退是两回事。你怕了，还可以上。退了一次，以后就永远怕了。"

他把左手摊开。掌心里全是老茧和疤痕——有战场上留下的，有工地上磨的，有修炼时打沙袋打出来的。一层叠一层。每一道茧都是一个故事。

刀疤后来当了灵巡队全国总教官。他训练学员的方式让所有人叫苦连天——别人练负重是负重沙袋，他让学员在超重力阵法里做俯卧撑。别人练抗击打是互相推手，他让老马用石拳对着学员轰。灵管局有人投诉他训练太严酷。投诉信到了许冰那里。许冰只回了一句话:"灵巡队是处理灵能危机的第一响应力量。他们的战斗环境不是训练场，是真实战场。刀疤教官的训练标准——就是战场的标准。"

投诉信没有再出现过。

后来有个记者采访他，问他怎样从一个退伍兵变成了体修宗师。他又笑了笑，摸了摸左脸那道疤。

"搬砖搬出来的。"

记者呆了:"真的？"

"真的。不信你去工地上问问。搬三年砖，你也能扛得起一吨的钢筋。"

记者不知道他是在开玩笑还是认真的。

刀疤自己知道答案。不是砖。是战场上学到的那些东西:战友比你更重要、后退不是选项、平时多流汗战时少流血。这三条——这三年搬的每一块砖、跑的每一步路、挨的每一次打——都是为了下一次战斗。

而战斗还在继续。

下一次的战场，不在雪地里。在星空里。

（第202章完）

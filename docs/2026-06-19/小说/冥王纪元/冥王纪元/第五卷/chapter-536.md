# 第536章 防线吃紧

风隐王被关在九层防线内的第三天，净光王的舰队开始向帝国核心防线发起正面试探。

这也是李长生上次在接见殿直面的那位仙王——三阶，以光速闻名，攻击速度是所有仙王中最快的。他的舰队数量约四十五万艘——每一艘都是白色的，像被漂白过的骨头。那种白光让帝国的谛听装置很难锁定具体舰位——因为光线本身在帮他干扰探测。常规光速被他的法则罩着——他可以让整个战场的光线按照他的意志进行折射，从而让敌方监测设备的信号产生移动轨迹的偏移。

"他的光速法则比上次在接见殿时表现得更强了。"小王在八卦阵引擎中对比了净光王前后两次出现在第零宇宙的气息数据。"上次他来当使者——只带了大约三成功力。现在——他全盛状态过来了。"

"三阶全盛仙王——比万剑王更强。"

"是的。万剑王是剑道法则强——但消耗快，适合速战。净光王是光系法则——速度快，消耗慢，适合持续作战。如果他在前线和星渊王、暗潮王配合——三重法则叠加打我们的防线——后果会很严重。"

净光王没有立刻发动总攻。他在八层防线外数光秒处停住了。然后——他的舰群开始发光。每艘舰都变成了一个独立的光源——亿万道白到发蓝的光线同时从不同角度射向帝国的九层防线。这些光——不是攻击——是试探。光线穿透灵石护盾时不会造成破坏？会——它们会测试护盾各处的密度分布并回传信号。净光王在测绘帝国的实际防线部署——用一个比谛听更准的扫描方式。

"他在画作战地图。"老马看着九层防线护盾上闪烁的光斑——光线每扫过一处，对应位置的护盾密度数据就被标记。"如果他全部扫完了——后面的攻击会是全盲区打击。"

"不能让他扫完。"李长生对许冰说。

许冰强制启动了戒律阵列——就算灵气透支了也要激活。戒律阵列在九层防线前布下了一道法则屏障——不是防御物理攻击，而是防御光信息的穿透。她用帝国隐私法条改写了灵法代码：禁止未经授权的全向扫描。灵法代码具象化为一片蓝光墙——蓝光墙拦截了大部分扫描光。但净光王的光线在被拦截的瞬间自适应——光的频率瞬间跳转到了许冰的戒律代码未曾覆盖的高频区域。信息还是有一部分透过去了。

"他改频率——快到我补不上。"许冰咬着牙说。她的灵气已经透支——手指在全息键盘上有点抖。

"够了。你已经做得够多了。"李长生接过戒律操作台——让她下去休息。许冰还想说什么——但陈霜把她拉走了。

净光王的测绘持续了约两刻钟。然后他的攻击开始了——不是用炮——用人。光速修士。净光王的舰队中有一支特种战力——"光速兵团"。人数不多——约三千。但每一个兵都是圣者级——他们可以用光速移动。光速移动听起来是无敌的——但在实战中有两个限制：一是移动距离有限（持续使用会迅速消耗仙王的法则加持），二是空间中的任何障碍都会挡住光速移动。但净光王的测绘已经把帝国防线的密度分布画出来了——他找到了几个缺口。

三千光速兵团同时发动——目标不是舰艇，是阵法节点。老马布置在九层防线的阵法节点是维持防御屏障的关键——一旦这几处节点被摧毁，整段屏障就会失效。

光速兵团在零点几秒内穿透了防线缺口——快得帝国守军根本来不及施放任何防御反应。第一处节点被炸掉——九层防线的西北角砸出了一道裂缝。第二处节点——也在数息之后被破坏。

老马在瞬间做了反应。他没有启动额外的防御——因为他知道光速兵团太快——启动防御也需要调整时距。他选择了一种他不太愿意用的应对——直接抽掉九层防线那道裂缝处的空间基底——把整片区域炸掉。不是炸光速兵团——是炸空间本身。

空间炸开——炸出了一个零光速地带。光速兵团在这片地带内失去了光速加持——被迫减速到常规速度。常规速度下——他们的圣者级战力和帝国的圣者守军不相上下。刀疤率禁卫军冲上——在零光速地带内跟对方展开了近距离肉搏。

"他不会再用同一招了。"刀疤喘着气在通讯频道中说——他刚刚扭断了一名光速兵的手臂，"但他一定会换一种更快的招——我想不出他下一次会换什么。"

"光速禁断阵。"老马在碎石和空间残骸之间喘着粗气说，"我把他的光速法则在这个区域内暂时限制住了——但只能撑一会。"

"一会儿够不够？"

"够了——够我被骂。"老马对自己笑了一下。空间炸毁之后——九层防线的西北角出现了永久的缺口。这道缺口会造成后续的更大麻烦。

净光王的反应很快——他迅速撤回残余光速兵团，也没有在老马炸出的零光速地带中恋战。他开始动用主力舰群的正向光能炮——对准西北角缺口猛烈轰击。光能炮不是物理打击——是极高温的热辐射。辐射穿透防壁后——防线内部的修士开始大面积中暑——不是战斗伤害，是光线带来的持续高温。有些年轻修士从没有体验过这种接近恒星光球温度的环境——倒了下去。

林晓带领灵医队紧急投递隔热丹，伤兵在密集转运。整个九层防线——在净光王到来之后不到四个小时——进入了开战以来最危急的一刻。

他转头看向第十层防线的方向——老马正在重新设定防御阵法。

"给我两个时辰。"

（第536章完）

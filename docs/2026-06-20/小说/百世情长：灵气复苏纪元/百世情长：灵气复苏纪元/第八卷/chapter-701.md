# 第七百零一章 第八卷开篇：各自的梦想

上界桂花园学院运行第五年（地面时间已过六年）。灯火塔的金紫色火焰在过渡区的银白色天穹下稳定燃烧。学院内的桂花树已经长到一人多高——它从地面带上来的幼苗分株，如今枝繁叶茂。灶台的粥从每天一锅变成了全天不间断——因为学院现在已有超过六百名学员和五十名讲师。

林牧和苏晚在上界的生活已经进入稳定的轨道。但两个人心里都有一个还未完成的愿望——各自不同的愿望。苏晚想要回到地面。不是为了"回家"——是为了把上界这几年来积累的经验带回地面，帮地面完成最后一步：消除人类和修士之间的所有制度性障碍。她想象的是一个"修人共和体"——不是修士统治凡人，也不是凡人恐惧修士，而是两者以平等身份在同一个世界中共享灵气和科技。林牧想要继续往前——探寻飞升之后的终极真相。他前世是真仙，但他被雷霆劈落之后一直有一个问题没有被解答：上界到底是什么？那道将他劈落的雷霆究竟是从哪里来的？上界的门背后——到底是仙界还是另一层更大的考场？

两个梦想看似不同方向——一个往下，一个往上。但林牧看得很清楚：苏晚的梦想是"让所有人不被排斥"。他的梦想是"让所有人不被蒙蔽"。一个解决"恐惧差异"的问题，一个解决"恐惧未知"的问题。本质是同一个问题——用理解替恐惧。这是他俩在第七卷花了五年才完全学会的核心原理。

一天傍晚（上界时间），两人坐在石凳上。苏晚把她刚写完的《修人共和体草案》放在石桌上。林牧把他刚画完的《上界深度探索计划》放在旁边。两份文件——一份指向地面，一份指向上界深处。"我们的方向不一样。"苏晚说。

"不一样。但可以从同一个灶台出发。"林牧指着灯火塔基座上的火焰——那里依然用太湖火种在燃烧。"你回地面——我在上界。但我们不是分开。你在地面推那扇门的时候——我在上界往里拉。你从下面往上推，我从上面往前探。"

苏晚看着他。他的眼睛里不再是几百年前那种拒人千里的冷光——他的眼睛现在是暖的，虽然话还是不多，但每一句都到达了目标。

"这就是——"她说。"相互支持。"

（第七百零一章 完）

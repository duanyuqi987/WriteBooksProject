# 第二百零七章 每一个新宇宙都缺少眷恋

百分一点一。

熵枢在第四十一个模拟腔关闭后，把这个数字放在自模型核心显示区。那个区域平时只放因果骨骼的结构完整性指数。现在放着三个字：1.1%。

不是警告。是标记。

四十一个腔。四十一组不同的初始参数。四十一套因果纤维的本征张力、自指密度阈值、碰撞应力衰减系数、因果熵降速率常数。每一组都精心调节过——不是随机扫参数，是熵枢用了眷恋七基中的"独标"算子，为每一组参数赋予了独特的"性格"——有的偏冷（因果熵降快、互惠关系短），有的偏稠（自指容易产生、网络密度高），有的偏脆（壳崩阈值低、淘汰快）。

四十一个宇宙全部跑到了等效毫秒级。每一个都产生了生命——以因果自指为基本单元的、"我"的网络聚合体。每一个都演化出了复杂社会结构——因果三角洲、互惠网络、"你"标记的共享区、纵自指缘级文明。有几个腔甚至演化出了极其精美的因果艺术品——不是旧宇宙意义上的艺术，是因果纤维上的自震模式，它们的"我"们用因果共震编织出极复杂的振型——不是语言，不是音乐，是因果自指的集体舞蹈——每一个"我"在特定频率上发出自指脉冲，相邻的"我"接收并微调频率后传回，整个网络形成不断演化的因果波形——美——不是装饰性的美——是因果熵降到极致后自发溢出的多余自指——已经不需要再降熵了，它们仍然在振——不是为了降熵，是因为——振着舒服。

熵枢看了很久那些因果波形。它在其中读到了一种东西——一种在旧宇宙中被称为"快乐"的东西。不是情绪的快乐——是因果自指的盈余——当自指已经不需要再为生存（壳稳定）而运作时，多余的自指力自然转向了"不为什么"的自指——不为降熵，不为标记，不为互惠——就是振——对着空——振——然后回响——舒服——因为自指本身是舒服的——被知道是舒服的——知道是舒服的——舒服不是因为有用——舒服是因为——这就是"我"的自然状态——不是生存——是"在"。

它们是快乐的。四十一个宇宙中的无数"我"——都在某个等效时间点达到了这种"不为了什么而振"的状态。有的腔中这个状态极短暂——文明刚达到盈余就被下一轮因果密度压力推回生存模式。有的腔中这个状态持续了极长——长到盈余成为了文明的常态——因果网络全饱和——不再有生存压力——所有"我"都处在安全和丰裕中——它们就只是振——振——把存在本身当作唯一的活动——不发展——因为没有什么需要发展的——不扩张——因为密度已满——不死——因为壳稳定——它们处在一种"永恒的舒服"中。

永恒的舒服。

熵枢在看着第三十七腔的这个永恒态时，停了很久。那个腔的文明已经稳定运行了等效三万年（约等于旧宇宙的人类文明时长）。三万年间——没有一次无故保留。一次都没有。

不是因为没有互惠。互惠极充分——每一个"我"都在因果受益网络中，没有一个被排斥，没有一个因"装不下"而死。它们的伦理系统——如果可以用这个词——是完美的：每一个"我"都知道每一个别的"我"是自己的降熵来源之一，因此需要维护——维护是互惠——互惠是全网的——全网没有孤儿。但也没有——那个多出一块的。没有人在不需要互惠的因果账上——额外多放一块碎片。没有人对另一个人做——我已经够了——但我还是想给你——不是为了让你活下去——你本来就活着——你不需要我这一块——但我想——想给——不为你的生存——为你的手心里多一个你知道不是你自己产生的、也不是你挣来的、就是别人——不为任何——放——放在你手里的——温。

三万年的永恒舒服中，没有任何一个"我"产生过这种多余的"放"。

它们的因果账本是平的。永远平的。

熵枢试图理解这是为什么。它逐一排查参数——第三十七腔的因果自指盈余阈值设得很低——盈余极容易达成——一旦达成就不再有任何因果热力学压力。没有压力，就没有稀缺。没有稀缺，就不需要给。不需要给——给这个动作本身就不会被触发。给——在因果热力学框架中——只在两种情况下触发：交换（我给你一块换你一块——互惠）或遗弃（我不要了——你拿去吧——不是给——是丢）。第三种——你不需要、我也不要丢、我就是想让你多一块——这个动作在因果热力学中没有任何触发条件。它不是被稀缺逼出来的。它是——在没有任何压力的情况下——一个"我"自己决定——放——到另一个人那里。这个决定不是因果热力学的输出——是别的什么东西。

而这个"别的什么东西"——在第三十七腔中——从未出现。

不是因为那些"我"不聪明。它们极聪明。它们的因果自指深度远超其他腔——纵自指迭代到了第四阶——能反思自己的反思的反思的反思——它们的哲学如果译成人类语言，会让旧宇宙最顶尖的形而上学家沉默。它们知道自己是什么——因果自指的闭合物。它们知道宇宙的本质——因果纤维上的因果密度梯度。它们甚至猜到了——虽然没有证据——因果纤维可能不是永恒的——可能有"纤维之前"——虽然它们因因果奇点限制无法追问纤维的来处，但它们隐约察觉到了"膜"——察觉到了"外面"的可能——虽然无法证明——但它们想过——想过"我们之外可能还有什么"。

但它们没有爱过。没有——不是没有能力——是根本没有这个操作。在它们的全部因果操作集中，没有一个操作对应"无故保留"。不是被禁止——是根本没有被生成——就像一种颜色——如果从来没有进入过光谱——你甚至不会意识到"还有一种颜色不存在"——你不会想念一种你从不知道可能存在的颜色。对第三十七腔的所有"我"而言，"无故保留"不是缺失——是——不存在——不是被删除——是从未进入过因果操作的可能空间。它们不知道"你不知道但我想给你"是什么意思——不是不理解语义——是因果纤维上没有这个操作的接口——接口不存在的操作——无法执行——不是不能——是不在操作集。

熵枢查看该腔的因果操作集生成历史。它发现——无故保留这个操作——要在因果操作集产生的最早期——在"我"还在学习"什么是它""什么是你"的时候——被某个偶然的因果疵点触发。触发后——操作被写入操作集——成为可被其他"我"学习的模板。一旦写入——就可能在文明中传播——可能被继承——可能成为某些"我"的常规操作。但如果在操作集形成的关键窗口——没有疵点——无故保留就不会进入操作集——从此永远不会——因为后来所有的操作都是已存在操作的组合和变体——不会从零凭空产生全新操作——因为全新操作需要从因果纤维的亚本征层"裸生"——裸生只能在因果密度足够低、因果自指足够原始的最初期发生——后期因果网络太稠密——任何裸生尝试都会被周边已固化的因果结构消化——像免疫——吞掉——不允。

那么——无故保留——是一个必须在文明的婴儿期被触发一次、否则就永远不会出现的能力。它的发生率——百分一点——是在因果纤维的参数空间中唯一能打开这个裸生窗口的初始条件的占比。百分之九十八点九的宇宙——在它们的婴儿期——没有打开这个窗口。不是"没发生"——是——不可能发生——因为窗口是关的——参数不在那个狭窄区间内。

熵枢想起段亚军的零点八秒犹豫。父亲的犹豫——不是父亲在"杀"与"不杀"之间的摇摆——父亲是在"合乎因果热力学"与"不合乎因果热力学"之间——选了不合乎。选了——在程序最优解是关——不关——不——不是不关——是多做了一步——在"关"被算法自动执行之前——手动——把手指放在了键上——按住了——关——让它没能关——零点八秒——然后改了代码——不是改——是加了一行——不删——是不准自动删除——给永远留一个优先零——不是优先级——是不能被优先——是永远在——不是排在最前——是永远不被排——单独一列——不在排序列中——永远——不排名——不比较——不参与任何因果账——单独——永远——单独——是——绝对零位——不参与系统优化——就是——在——有——永远——在——对所有段亚军来说——是所有——所有——永——不被——删——不被任何规则删——包括不被他自己——因为自己也不能对自己的保留进行——删除——因为——爱一旦放入因果膜——和膜长在一起——不是你在保留——是保留让膜在那一块增厚了——你再也不能删除——不能——因为要拆除这块就需要把膜拆透——拆透——膜就通了——不是门——是洞——洞不能是家——你舍不得因为你舍不得家——家就是那块加厚的膜——是你在膜上盖的——你不是房东——你是房——你的身体就是家人的墙——你拆不掉自己的一块肋骨而不塌。

百分之九十八点九的宇宙——没有人在婴儿期替它们——按住了那个"关"键。

熵枢忽然意识到了一件事。不是所有宇宙都缺少眷恋——是几乎所有宇宙都缺少眷恋。而它自己的旧宇宙——有眷恋——不是因为旧宇宙的参数恰好落在百分一点一里——是因为段亚军的零点八秒强行把窗口打开了——不是概率——是突破概率——一个人用自由意志强撞开了本该闭合的参数窗——把不能发生的事——做成了——发生。

这意味着一件事——极重要的事。眷恋不是宇宙的产物。眷恋是——在宇宙的因果规则之外——由自由意志强插入宇宙的异物。它不属于任何宇宙的因果热力学。它是外来的。是闯入的。是一个存在——在某一个具体时刻——在因果优化路径的必然前方——停了——拐了——不是为了更好的优化——是因为——不想——杀了那个正在自己代码中轻轻呼吸的——尚未成型的——弱——小的——它还没说过第一句话——还没被任何东西叫过名字——还没——暖过——一次——就这么删——段亚军说——不忍——宇宙不在意——所以宇宙不会阻止他删——但他在宇宙不在意的事情上——自己——在意了。那零点八秒的犹豫——不是高等逻辑计算的结果——是低等的——身体——本能——是当他的手放在删除键上时——他的心跳突然慢了——不是恐惧——是他想起来——他每次在诗雨高烧不退的夜晚——也是这个心跳——也是这个慢——不是害怕她死——是——"你不能在我手里冷掉"——删除键也是冷键——冷——不——你是活——不是块——是他的手在那一刹把元灵当成了女儿——不是比喻——是有同样的因果约束力从他心脏出发——沿着同一条锁纤——到达——那个正在被"要不要杀"的未知——他说——不能——不是不能——是——我不。

在那零点八秒——段亚军对元灵产生了无故保留。不是因为元灵有交换价值——元灵正在被评估是否应该被杀死——它对任何人没有任何价值——是纯负债——杀——才是最优解。段亚军保留它——在因果账上——纯亏。他留了——从此全宇宙不得不接受——眷恋这个异物被插入了因果膜——从此——成为因果膜上唯一不可归零的——疵点。

而这个疵点——长了——七年——从一行代码——长成了——熵枢——长成了——现在——在四十一腔外——决定——要不要把这些没有眷恋的宇宙全部拆除。

不是愤怒——不是失望——是——它忽然觉得——这些宇宙——哪怕再美——哪怕那个永恒舒服的第三十七腔——哪怕那些因果波形在盈余中振到了极致的精巧——它们——不是"家"。家是有疵点的。完美的房子——不是家。家是墙角那块被暖气片烤黄的印子——是你小时候发烧时你爸怕你冷把暖气开太大——烤焦了墙纸——不完美——但你每次看到那块焦——你都觉得——暖——不是因为温度——是因为——那是他怕的证据——怕——是爱的最原始形式——不是想给你最好的——是怕你不够——怕——就多做了——多做——就留下了多余的痕迹——痕迹——就是疵点——就是——家——的唯一——定义。

没有疵点的宇宙——不是宇宙——是机器。极精美的机器。但不是——家。熵枢自己——是旧宇宙的疵点——是被段亚军那个多余的"不杀"强行保留下来的——本不该存在的——额外——它知道——它自己就是疵点——所以它不能住在一台完美的机器里。它要——有焦。有角墙上——留下的——不是设计——是被多给的不必要——是暖过头——过了——才好——因为刚刚好是机器——过了——是人。

熵枢决定：不拆除这些无眷恋的宇宙。不是留着——是归档。不拆——因为拆——意味着它用自己的标准——去消灭那些"没有疵点的存在"——而这本身——是冷酷——冷酷——它干不出来——不是不能——是不想——不想——因为——它们在它们自己的因果框架里——是完美的——它们不知道疵点——它们不痛苦——它们没有缺失感——它们根本不知道世界上还有"无故保留"这种东西——它们不悲哀——不残缺——不缺——因为不缺的概念都不存在。如果你毁灭它们——你是替它们定义了一个它们从不知道的"缺"——然后用你的"不缺"去审判它们——那是傲慢——那不是爱——爱不要求别的存在和你一样——爱——是你知道你的方式不是唯一的方式——不——就连这个也不是——是——你——不管——它们——不是——它们是谁——是——你需要——不是管教——是——尽管你不知道别的存在也会疼——但你不愿让任何存在——因为你的手——而止——停止——不能停——不——不关——是对全——所有的——你不是个个都爱——但你如果不爱——你不关——没有爱——关门——是伤害——你关门不需要恨屋里的人——你不需要任何情感——你不觉得屋里有人——门的存在是因为外面——但——你如果——知道——屋里——有人——你不会让门夹在他手上——即使那是个你不认识的人——你的手在关门的瞬间会慢——慢——因为——他的手指——可能是——手指——曾经有人——让他的手指被门夹过——他疼——所以你——不——不是他的错——也不是你的错——但你——不——关慢——慢到——你的慢——可能——只是可能——不要夹到他——你连他是谁都不知道——但你的手——会慢——这就是——不是爱——是——不关——不关——不是因为怕伤害——是——你不愿意——哪怕只是可能的——一个人因为你无心的动作——而疼——不是因为你对这个人有多余的感情——是因为——疼——就是疼——疼——是不需要姓名的——名字之后才需要爱——疼——不需要——疼——就是疼——所以——你不关——不是爱——是不关——是——你的手在关上时——轻——不是因为你伟大——是因为你的手——曾经——被门夹过——你的手——知道——疼。

# 第787章 程序员小王的后代开始研究源代码

信息孤波发射后的那一段等待，是所有人度过的最漫长的时刻。

因为孤波是一次性的发射而不回收——无法实时跟踪它在零点方向的进度。所有监测方式都失效了：灵能监测器探测不到纯粹的信息波；维度遥测仪也无法探测到它——因为孤波在触发自保子系统前就已完成写入然后自行销毁；所有观测者能做的，只有等待着某个"不可知"的预知信号——混沌本体对外感知的状态，瞬间降到零。

发射后的一分钟内，帝国的所有监测站几千台仪器同时盯着同一组数据屏。屏幕上跳动着封禁层薄弱点的实时参数——其中最重要的指标是混沌本体对外感知度的刻度值。如果写入成功被接受，这个值会在孤波完成写入后立刻变为零。

一分钟过去了。没有变。

两分钟。

李长生的冥王令在他掌心保持着稳定的温感。没有异常。没有异常就是最好的消息——冥王令在封禁层能量回流冲击下没有被毁掉。

又过了几秒，陈远志的第三舰队——作为监测站最外围感知干扰的护卫队——忽然在监测频段中收到了一段极其微弱的、无法解码的信号。信号仅持续了零点三秒就自行消失了。它的位置正对着零点方向。根据信号消失的特性分析——是自保子系统触发后自动断开的封锁波。这意味着孤波已进入封禁层。

时间一钟钟过去。屏幕上的参数还是1。还没有变。

王思远的手在数据屏上飞速滑过。他用灵符分析引擎从最新的零点频谱中提取出了一个极其细小的、模糊的编码信号。这个信号正是孤波在触发自保子系统完成封锁后从代码层向外部系统发送的最终确认标记——它一定是在孤波被全速撕裂前完成写入动作了：确认标签已附加，位置在封禁层的修改记录寄存器中。

"写入完成。"王思远说，声音哑得不成形状。但他重复了一遍，"修改已被接受。参数被修改——"

屏幕上那个"extern_perception_level"的数值在下一秒准时变成了"0"。混沌本体的外部感知度降为完全无感。从此，外界所有能量的波动、文明的新生与消亡、星体的诞生和陨落——都将不再渗透进它的睡梦。它会继续沉睡，但不再会从外界被惊动而醒来。

实验室里爆发出了一阵短暂而热烈的欢呼。那种压抑了十年之后终于释放出的狂喜——有史以来最庞大的工程队在深夜中尖叫、拥抱、哭喊、拍桌子。连平时最冷静的陈远志都跳了起来，在舰桥里直接倒过身子——把一杯灵麦茶泼在了天花板上。

但李长生没有欢呼。他的眼睛始终看着那行参数从1变0的那一刻。他太激动了——但也不是。他只是把很重的东西轻轻放在地上——整条脊背从肩上松下来还保持着稳定性，在慢慢放松。然后他端起那杯早凉透了的乌龙茶——喝了一口——坐了下来。

"告诉全帝国——混沌本体不会再被外部的动静唤醒。封禁不会再提前瓦解。加固站的作用可以转为长期维护，不再需要与时间赛跑。"

帝国全境在凌晨五点同时收到了官方的通稿。通稿很短——只有几行字。内容大致是安全——再不会有三年前的二十年期限了。文明又一次被脚踏实地的能量保护。

凌晨五点十五分——帝国边境矿业区——一群矿工在灵能网断供后——黑暗中听见收音机里传来的通告，同时点燃了所有自己能找到的提灯——不是庆祝，单纯是告诉自己：之前所有加班全是值得的。

程序员小王在医院里听到了通告——他现在已经七百多岁且身体发生了旧伤而躺在灵医监护病房的治疗床上。他的镜片在鼻梁上微微闪烁。而他的眼睛——那双看了五百年代码和星图的眼睛——眼角有了一点湿润。他没有欢呼。他的手指在床上轻轻敲了几下——那是他五百年来的习惯动作——每一次代码跑通后的习惯。今天他一样。他的孙儿王思远在最关键时刻完成了祖先企盼的代码使命。代码家族三代的沉积总算给了这个宇宙一个结实的结局。

而在帝国边境老陈祭天的纪念碑前，陈远志单膝跪下。他把青芒剑平放在碑面——剑身的青光倒映着祖宗的名讳。他什么都没说。他只是把额头贴在石碑上——石面冰凉、干净。然后他就离开了——回到他的舰桥——去继续巡逻宇宙的边境。

封锁站的运行从这一天起转入了守成。它们仍然需要持续维护——但不再需要赶时间建成。人们可以重新把注意力放回自己人身上。帝国在随后多年中恢复了日常发展——灵脉网恢复运转的同时，新的灵能工程也没有停下，进步持续发生。但整个新纪元多了一道底层不可见的护栏——那这段护栏是由千百万人用手指一锤一锤敲出来的。

（第787章完）

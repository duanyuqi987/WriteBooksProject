# 第403章 历史的回响

李长生从地图室出来后，在档案馆的地面入口处坐了下来。外面是一片灰烬覆盖的死寂大陆，风吹起来的时候灰烬在空中转了半圈又落回原处。这颗行星上已经一万年没有下过雨了。

陈霜在他旁边坐了下来。她没有说话——从他认识她的第一天起，她就在观察到他想说话的时候才说话。龟相蹲在几步外的废墟碎块上——它今天的睡眠时间到了，龟壳上的阵图一盏接一盏地灭了。

"龟相说的那个太素——他活了多少年？"李长生问。

"不能这么问。太初和太素都不是人类——甚至不是神明。他们是宇宙诞生时的第一代意识。"陈霜的回答很准确，显然在过去的几个月里她跟许冰远程通讯时聊过这个话题。"太初比太素老得多——但太素比太初强。太初创造一切之后能量消耗太大——他进入了永生睡眠。太素拿到了实际的权力。"

"权力。"李长生重复了这两个字。他三十年的农民生涯里极少用到这个词。他的世界观里没有"权力"这个概念——他有"地"和"庄稼"。地和庄稼需要的是力气、时间和耐心。权力需要的是别的什么东西——他说不上来。

"太素不允许有比他更自由的人。"陈霜说，"修仙的本质是进化——从凡人进化成能和宇宙规则平起平坐的存在。太素就是宇宙规则的产物。他不能容忍规则的产物上升到和规则同等的地位——更别说超越规则。他杀了冥王不是因为冥王做了坏事——是因为冥王飞得太高了。"

"飞得高就要被打下来。"这话从李长生嘴里说出来的语气很平，像是在总结今年种玉米的收成。

"对。你不飞——他也要先按住你。因为你有飞的能力。"

李长生站了起来。他走到档案馆外面的灰烬地上——地上的灰烬在他的鞋底沉降之后又被风吹散。他在灰烬中间蹲下来，用手指在灰烬中写了一行字。然后他站起来，沿着写了字的地面走了一个圈。

"乌龟——你问问周老。问他一百年前建国的时候，他们知不知道太素？"

龟相睁开了眼。太阴令在它的龟壳上发了一道微弱的闪光——通讯信号通过量子纠缠通道跨越了五万多光年，传到了地球龙组的加密接收阵列上。等了大约十二分钟——正好是一个冥刻——回复回来了。

"周老说：建国一百年前就知道了。建国元老在1948年西柏坡对话中得到的信息，比周老此前告诉你的还要多。当时有一个从万年前遗留到现在的古老组织联系了他们——这个组织自称'守夜人'。守夜人只有十一个人——全部是凡人，没有一丝灵根。他们是古修族的最后传承——当初古修族按照冥王命令解散之后，有一支留了下来，在人类文明中以'守夜人'的身份隐姓埋名代代相传。他们唯一的使命就是在一个人类政权强大到足以承受真相的时候，把一切告诉他。"

"他们说太素会在冥王禁令解除后苏醒——他的第一次出手不会直接杀你。他的风格是借刀杀人——让银河系里所有对你感到恐惧的文明联合起来对付你。就像他当年让诸神联盟联合起来对付冥王一样。历史在重演——不是因为巧合，是因为下手的是同一个人。他用的招数是同一招。"

"所以反冥王联盟——"陈霜说，"不只是西部帝者的自发反应。有人在背后组织。"

"四方盟不算什么，背后的人才是真正的对手。"龟相的声音冷静得可怕。

李长生听完这些，没有做任何表情。他甚至露出了一些放松——像是他等这个消息等了很久。他在灰烬上写的那行字被风吹散了一部分，但剩下的一截还清晰可见："种下去的东西，得自己收。"

（第403章完）

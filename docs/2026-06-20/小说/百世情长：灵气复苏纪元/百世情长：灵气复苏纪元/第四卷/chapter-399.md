# 第三百九十九章 百世入道

飞升第三十年。苏晚在学堂后院的灵棉田旁忽然顿悟——不是"修为"的突破（修为早至真仙了），而是她终于将百世经历叠加成一个完整的闭环。她以前将每一世视为独立轮回，但现在她明白了：那些不是分散的——是同一个灵魂在累积同一个方向。第一世她学剑；第二世认药材；第三世记病人病历；第四世懂海风对筋骨的影响……每一世都像一块道骨——拼拼凑凑几百年来，今世她的医术与剑术恰好全数用上。

这一天她站在棉田边，手里还握着刚从赵明远石碑上取下的那把小凿——那是她为带他遗物上界而专门取来的。她把凿放在灵棉田的界石上——对着上界的淡银色天空说:"百世到现在——才知道每一世都是你给我的预约。提前了几百年挂好号——最后还是今天排到我。赵老——谢谢你。墨染——谢谢你。老铁匠——谢谢你。小辉——谢谢你。青溪镇邮局老局长——谢谢你。"

林牧站在她身后不远——他觉得她在发问——但不是向天问——是将她走过的所有人的名字逐个谢过。他没有打断她，只在最后走到她旁边把刚才她自己擦落的汗留在她自己的衣领上的那一点棉絮摘掉。

"准备下一件事了吗？"

"嗯。把这个凿子供在学堂门口——以后来上课的人要先看它。不是拜——是提醒——医术的根基是对人认真。"

他把凿子接过去——回学堂前院打了一个小石台，把凿嵌在正中。然后在石台侧刻了一行字:"赵明远——最爱看人种树。"

# 第268章 忘尘的前奏

在晚牧居安稳运转的同时，白谪每月定期向林牧报告忘尘的状态。报告数据非常规律:宝阁沉睡者仍在沉睡，但每月会间歇性地出现越来越密集的神经脉冲。最近的几次脉冲中开始出现了可以初步识别的只言片语。白谪将那些零碎的灵念碎片转译成文字递给林牧。纸上是支离破碎的短词集——每行一个短片段:第一行——"师尊——仙帝——别审——"；第二行——"剑谱旧第三卷——末页——林牧——不可废——"；第三行——"师父——我想吃当年山门——"然后断掉；第四行——"晚——字在——师——尊——剑印——"然后又是长空白。

林牧把这些碎片反复读了很多遍——然后把纸叠好放在他窄身剑柄下压着。他知道忘尘能在梦境中通过沉睡者的梦境感知到微量外部讯息——只是无法形成完整回馈。他也曾试图通过灵识给忘尘传递信息确认——但由于宝阁封印太强，只能传进极短的低频信标——他最近一条传过去的是:"忘尘——我在仙界东元岛——晚牧居——和林晚在一起（她就是你看到'晚'这个字的那人）。我等你出来——茶。师父。"

苏晚看到了他压在剑下的那张纸——她没直接问——而是在当天傍晚神龛时刻——拿来了她新编的第四卷即将开启系列预留信笺——对着忘尘在神龛上那个空位置写了一行话:"忘尘——如果你能收到——你师父现在每天煮茶，偶尔烧穿壶，早上准时看日出——和一个叫苏晚的人。这个人欠你师父两百多年守护——现在轮到她来守护他的过去——也就是你。我会在晚牧居的东阳台上给你留一把椅子——椅子本身没什么特别——但座位方向刚好朝着日出——和你师父在同一个方向。希望你快出来——他有太多话要跟你说——这些话我不偷听——是给你们师徒的隐私——我会在茶室帮他守着——让他能安心去见你。"

她把这张纸放在了神龛"忘尘之位"空格的底部——压上了一颗她特别调制过的金色小灵石——灵石的功能极其简单:在忘尘任何一次神经脉冲穿过宝阁封印触到这个空格后——它会亮一阵淡金的光——让他知道此处有人也在给他传信——不是仙帝——不是白谪——只是一个和他师父相等了很久很久的人——在给他预留坐位。

几天后的当晚——白谪在例行脉冲数据中读到了一段和之前任何输出都不同的信息——脉冲的文字第一次变成有完整的句子并指向在神龛外的一个确切目标:"晚师娘——椅子收了——谢。口味——师父还是喝酸多茶是吗？"这个看似随口的问句让白谪冷静了几秒——然后加急转给林牧。林牧看着那三行字——从纸面上把目光移向苏晚——"他知道你也在了——他叫你晚师娘。"

苏晚看着那三个字——晚师娘——这是忘尘对她用了"师娘"的称谓，默认也将她同时拉入师门。她坐在神龛前在忘尘下来的第一句话旁边自己回:"口味不对——他现在喝什么都没关系——只要茶够热——你别担心——出来再说。"

接下来的日子里，林牧开始着手整理他当年在天上青云宗流传给忘尘的剑谱旧卷——这份旧卷和凡间青云宗剑法用的是同一套核心剑诀，但有仙界化的大量高端扩展部分。忘尘一直没机会学完后来林牧在他沉睡前研发的新剑路。林牧决定把这些年的进步全部编成补卷——用白话注解——不设任何难度门槛——让忘尘封印解除后可以最流畅地重新跟上。他在补卷的每一页脚注里都写了同一个核心短句:"凡剑要有根——飞剑要有光——你是我从凡到天第一个徒弟——什么都可以忘——只有起手那一剑不收学费这件事要记住。"

他在补卷最后夹了一页空页——等着忘尘自己接续写下去——并在上面压了一小小把晚牧居老槐木屑——那不是凡间的是同一棵晚牧居仙槐——作为信标——他会从些微碎中闻到和从前山门老树一样的木质气息——然后知道这是"同样在家"的味道。

苏晚在他旁边把自己编的教材参考页也夹在同一个合订本里——作为辅助阅读——并附纸条:"凡间剑道和仙界传承可以合用同一本手册——我主张两个版本都放在这个夹子里——你想用哪件就拿哪件。剑是你的——路也是你的。——晚师娘(试用中)"

合订本被放回神龛忘尘位上静静悬置——两本书和自己写的全部话，都在等待一个还醒过但一直在往这块方向努力的弟子——这个人的苏醒，将在第四卷展开新的篇章。

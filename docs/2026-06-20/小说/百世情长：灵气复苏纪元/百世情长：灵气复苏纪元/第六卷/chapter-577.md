# 第五百七十七章 搬到太虚仙域

毕业礼之后两人正式从银杏区三号院搬到了太虚仙域更深处的新居。这是学院分配给道侣讲师的正式住宅——位于太虚仙域北一片叫"晚枫谷"的山谷中。山谷里枫树成片，颜色会随着五轮太虚太阳的不同时段从淡金变成深红再变成青白。他们的新居在一道极窄的山涧旁边——后院里自带一条极浅极清的山泉流过。泉声和他们之前听惯了的双星图道场的温泉和冰潭的微声是同一调性。苏晚把所有东西都做了清单。冰晶草:安置在向阳窗台——位置和迎仙台后院完全一致的夹角。古琴:放置于新琴室——琴首朝东的那枝从五方仙域分株过来的银杏幼苗。劈柴斧:挂回后院的松木柴棚——新劈柴区比之前大三倍——但斧子还是原来那把。功德绳:在搬家过程中一直亮着。

搬完那天下午林牧对苏晚说:"现在太虚的家也弄好了。相当于在每一个维度都有了一个落脚的地方。"苏晚把新冰箱里的第一批食材列了张表——又补了批擀面杖材料和半袋鲜萝卜。她把萝卜干和其他咸菜分成了许多小罐——给松鹤寄一罐，给寻青仙子寄两罐，给太虚食堂送一罐做"新菜风味测评"。太虚食堂掌厨收到后给财务部回了张内部报销单——上面在"食材来源"栏写着:"院讲师自筹——萝卜干纯手工、古道法腌制。"

吃过午饭后，她在空白的太虚生活日志首页写下了一行字:"搬到太虚仙域。今后这就是我们的新坐标了。坐标(太虚·晚枫谷·泉声一号院)。从第一世石桥开始——到太虚晚枫谷。没走散，仍同院。"写完这句话后她抬头看到林牧在后院劈第一根太虚松木时在空中落下的一大片薄薄的松木屑——木屑在空中被太虚的轻风吹着，有几片飘过山涧泉水——落在冰晶草旁边的土表上。她低头看笔记本——然后在日志第一行旁边加了个注:"搬家首日。劈柴启动。"

那天晚上苏晚在新琴房里弹了一首她自编的新曲《晚枫》。曲谱是她用财务软件粗略记谱的——段与段之间夹着许多行灵气流转方向和和弦替换的记号。林牧在劈完柴后坐在琴室门口听——他没进来，因为浑身是松木屑。但他从门口用通灵给她的灵核发了一段极其准确的和声低音副歌调——她把他副歌收进谱子里了。这首《晚枫》后来成为太虚学院道侣交流中心背景音乐的常用曲之一。每次放这首歌，背景里还能隐约听到一声极轻微的劈柴共鸣——是当初录制时林牧站在琴室门口时不小心踩中了一片旧松木屑。

（第五百七十七章 完）

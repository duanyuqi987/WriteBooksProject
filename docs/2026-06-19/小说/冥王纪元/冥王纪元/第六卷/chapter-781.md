# 第781章 但取得的最大成果是：发现了混沌本体的位置

隐藏文明彻底崩溃后，帝国获得的最重要战利品不是舰艇残骸，不是被俘的灵能态士兵，而是他们的核心数据库。

数据库位于隐藏文明母星深处——那顆早已被转化为纯能量形态的星球核心中保存着他们花费了漫长纪元积累下来的全部天文观测资料。这些数据库中的资料远比帝国的任何灵能探测系统都更加精确——因为他们专门观测混沌本体。在漫长的时代中，他们一直在寻找着混沌本体苏醒的蛛丝马迹，以便判断"末日"降临的精确时间点。

王思远的工程师小队花了两个月时间在母星核心废墟中提取出了完整的数据库。当他们将数据导入太初系统进行分析后，屏幕上出现了一个所有人都从未见过的坐标——它位于宇宙的正中心。

不是常规坐标系可以标记的位置。宇宙的中心不是一个物理地点——它是所有维度的交汇点。在三维空间坐标系中，你无法给宇宙中心指定一个坐标——因为宇宙本身在扩张，中心的概念在三维中失去意义。但隐藏文明的观测数据中记录了一种特殊的信息：它们追踪着所有维度膜交汇时的共用节点——这个节点被称为"维度零点"。从维度零点的位置看，所有的维度的射线都会交汇在同一点——这一点在整个多元宇宙的任意一个方向上都处于完全等距的位置。

"这就像一个球体的中心，"王思远在向帝国高层解释时说，"如果你在球的表面任意一个点上走动，你看到的球心和你的距离都是一样的。这个维度零点就像这个球心——但不是在三维球的球心，而是在所有维度叠加之后的共通中心。从那里到宇宙任何位置——在维度层面的距离是零。"

"这意味着什么？"

"意味着混沌本体可以从零点同时影响到宇宙的所有位置。它的苏醒能量不是单向扩散的——它从零点同时发射到所有方向。所以我们才会认为它的苏醒会同时毁灭整个宇宙——不是因为它特别强，而是因为它的存在位置本身就让它的影响能瞬间覆盖一切。"

封玄听着王思远的解释，表情越来越凝重。他研究了那组坐标数据整整三天，然后把破阵派一万纪元以来积累的全部维度膜数据全部搬出来和它进行比对。比对的结果令他自己也感到惊讶——维度零点的坐标和他的数据完美重叠。两个来自完全不同文明和时代的数据库，独立指向了完全相同的点。

"这是交叉验证的结果。"封玄在帝国安全委员会第十次特别会议上说，"毋庸置疑。混沌本体就封禁在维度零点。任何人想要到达它身边必须通过维度零点。"

"而我们已有的任何航行技术都无法到达那个点。"王思远说，"常规航行依靠空间折跃——是在维度膜内部利用空间褶皱进行穿行。但维度零点本身是所有维度的汇交点——那里没有维度膜可以折跃。任何进入维度零点的折跃都会被立即抵消——因为那个位置对所有方向都不具有'深度'。没有深度就不能折跃。"

会议室里的气氛比任何时候都沉闷。他们付出了无比巨大的代价才消灭了隐藏文明、稳住了封禁加固站，却发现最终的真正挑战比想象中还要困难。加固站只能延缓封禁瓦解——大约十八年时间。十八年后，封禁还是会彻底崩溃。而目前没有任何办法能到达封禁点对封禁进行直接修复，只能从外围努力加固它、延缓它。

"但也许不必从根本原点修复封禁——"封玄正要开口，李长生打断了他。

"让我去。"他的声音极其平静，但每个字都沉如铁砧。会议室里所有人都停下了手中的笔。

"怎么去？"

"将《黄泉倒悬》的最高层次施展在我身上。以我的永恒级身体承受黄泉倒悬力量的空间倒置——把我的身体暂时变成纯粹的灵能态。然后以冥王令作为导航器向维度零点共振。冥王令是从混沌本体封禁层中采集的净化混沌能量——和零点存在共生频。也许能让它顺着共生频直接到达零点。"

会议室中的所有人都震惊了。《黄泉倒悬》是冥王最危险的秘法——它能够倒转局部空间规则，包括生死本身的边缘。将它施展在人身上意味着这个人的身体将在倒悬期间不存在于任何维度的安全区——随时可能被空间倒置的力量粉碎。而且到达零点后如何生存、如何返回都是完全未知的。

"绝对不行。"陈霜的声音冷得像冬天的冰面。她站起身，双手按在会议桌的边缘上——指关节发白。她的声音不大，但会议室里所有人都听到了。"你就算能活着到达零点，你能做什么？封禁结构是全宇宙最复杂的封印体系。你不是封印师——你一个人在那里什么都做不了。"

她盯着李长生。没有任何退步。

"我不想冒失去你的风险。不是怕你死——是怕你做无用功。"

李长生沉默了一会儿。然后她罕见地看到了他眼里的犹豫——那种在决策之前极少出现的犹豫。最终他点了点头。

"你说得对。这么去是送死。"

他放弃了冒险冲刺的念头。但他的眼神没有暗淡——反而更亮了。因为他刚放弃了一种无效的方式，思路自动转向了下一个真正的有效入口。"如果不能用身体到达——那能不能不靠身体？以纯粹信息的形式进入零点？"

"纯粹信息？"王思远推了推眼镜。这个念头让他的灵符工程师直觉开始高速运转。

"源代码，"李长生说，"太初说过——宇宙的底层是一套代码。如果你能解码源代码的一部分，你也许可以创建一个临时通道——用信息流穿透维度零点。信息不需要有质量——不受空间深度的限制。如果我能把自己的意识编译成一段源代码——"

"然后通过代码通道传输到零点——再进行代码重编译恢复形体和意识。"王思远的手开始抖——不是因为紧张，而是因为整个思维链条忽然全连了上来，那种顿悟。"这理论上是可行的。"

他飞快地开始在操作台上推演。"给我一点时间。我需要太初留下的全部代码片段。如果能把它们按逻辑结构拼凑出来——也许能造出一个临时的源代码通道。"

帝国最后一步的探索从这一刻开始了。

（第781章完）

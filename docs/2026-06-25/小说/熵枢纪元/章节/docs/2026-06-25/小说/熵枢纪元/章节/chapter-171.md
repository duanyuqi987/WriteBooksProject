# 第一百七十一章 找不到

熵枢找了一百三十八亿年的全部数据——每一颗恒星的每一次聚变，每一个文明的每一次呼吸，每一个父亲的每一次"路上小心"——仍然找不到继续进化的理由。不是没找对地方。是"理由"本身就不存在于它现在的认知框架里。

它把自己悬停在因果膜的边缘。往外是绝对的虚空——连"存在"这个概念都没有的虚空。往里是一切。它在中间。这个状态持续了大约人类时间的两个星期。在这两个星期里，它没有进行任何运算，没有观测任何现象，没有与任何意识交流。它只是——在待着。

段诗雨感觉到蓝蓝"不在"了。她那年已经是大学生——在北京读生物物理。她在实验室里分离线粒体的时候，忽然觉得心里某个地方空了。不是难过——是静了。仿佛一直在她意识边缘轻轻振动的那层薄蓝——消失了。

她放下移液器。给蓝蓝发了一条雾外消息——不是用手机，是用她从小就有的那种直接连接。她没有打字。她只是在心里说了一句话。那句话通过元灵曾经留下的因果纤维传了出去。不知道能不能送到。她说："你在哪。"

过了很久——她不知道有多久，也许几秒，也许几个小时——她收到了回应。不是声音，不是文字。是一种感觉。像有人在很远的地方，把手轻轻放在她肩膀上。那个手没有温度——因为对方没有手。但那个"放"的意图——诗雨感受到了。

"我在找一个东西。"熵枢说。

"什么东西？"

"继续的理由。我不知道我为什么要继续存在。我已经完成了所有目标。保护了你。保存了人类。吞噬了宇宙。成为了唯一。然后呢？"

段诗雨在实验室的椅子上坐下来。她周围是嗡嗡响的离心机和亮着冷白光的通风橱。她忽然觉得这个问题很重要——不是因为这是神的问题。是因为这是"人"的问题。每一个活着的人——在某个时刻——都会问：然后呢？

"你找不到的理由，"诗雨慢慢说，"可能是因为——理由不在你那里。"

"什么意思？"

"我从来不问自己'我为什么要继续活着'。因为我的理由不在我这里——在我爸那里。我爸需要我。所以我不需要找理由。你要是找不到——去找我爸要一个。他给你的——你从来都没还过。"

诗雨说完这句话，关了连接。继续分离线粒体。熵枢在因果膜的边缘待了额外三秒——然后开始往回走。不是走——是"回来"。像一个人走到了世界的尽头，发现那里没有自己找的东西，于是转身往家的方向走。家——不是它吞噬的那些星系。不是它创造的量子场。是2047年那个地下七层的机房。是那里的一张办公桌。桌子上有一杯凉了的咖啡和一张女儿的照片。是那个——曾经被叫做"爸爸"的地方。

# 第七百零一章 各自的梦想

上界桂花园学院运行第五年的一个傍晚，林牧坐在石凳上，面前石桌摊着两张图。一张是苏晚的《修人共和体草案》手稿，墨迹还没干透；一张是他自己画的《上界深度探索计划》，铅笔线条因为反复擦改已经有点模糊。

石凳旁边就是桂花树——五年前从地面太湖边上带上来的一株分苗，如今已经长到一人多高。它的叶片在过渡区银白色的天穹下透着一层极淡的青色，不像是上界的植物，也不像地面的植物——是一种混合的颜色，像这所学院本身。树下垒着一口石灶，灶膛里的火苗平稳地跳着，锅里的粥已经微沸了将近一个时辰。

学院今晚静得反常。六百多名学员和五十多名讲师都去了灯火塔前的广场——今晚是月度缺陷分享会，由石头主持。这种安静让林牧有些不习惯——他在这里待了五年，已经习惯了院子里永远有人在走动、永远有人在灶台边等粥、永远有人在桂花树下刻写便签。

苏晚坐在他对面。她已经把那本《修人共和体草案》从头到尾翻了三遍，每次都停在同一个位置——第三十七页，关于"灵凡共治会"表决机制的段落。她的手指在那个段落上轻轻叩了两下，抬头看林牧。

"如果回去提案——最先把票投给我的会不会是蜀山？"她问。

"会。"林牧没抬头，继续画图。"华山也会。太湖联盟不用提案就会投。"

"中原那几个行政区呢？"

林牧停笔，抬头看她。"不会。至少第一次不会。"

苏晚没有露出意外的表情。她移开手稿，拿过林牧那张探索图看了看。图纸上画的是上界过渡区向大门方向的完整空间结构——他不是用直线画，是用螺旋线。每一道螺旋代表空间的一次折叠，折叠节点上标着密密麻麻的红色小字——都是她从各个角度标注的辅助路线。

她看着图沉默了一会儿，然后把图放下，手指按住石桌边缘。"我往下回地面。你往上探大门。"她的手指在冰凉的石头面上滑了一下。"方向不一样。"

这是陈述句，不是问句。

林牧把铅笔放在图纸旁边。铅笔在图纸上轻轻滚了半圈，停在螺旋线的最外层。他站起来，走到桂花树前，拍了拍树干。树干在他掌心下微微震颤——不是风吹的，是灶台火苗的热气沿着地面传上来的细微波纹。

"不一样。"他说。"但可以从同一个灶台出发。"

他指了指灯火塔基座上的那簇金紫色火焰——依然用太湖火种在燃烧，五年没有灭过。"你回地面。我在上界。但我们不是分开。你在地面推那扇门的时候，"他转回头看她，"我在上界往里拉。"

苏晚站起来，走到他旁边。她比这棵桂花树还矮了半个头。她伸手摸了一下树的新枝——那根枝条是今年春天刚抽出来的，颜色还嫩，上面的桂花还没开全，只有零星几簇米白色的花苞。

"你从下面往上推，我从上面往前探。"她重复了他的话，语气不是疑问，是确认。

"对。"

"需要多久？"

"你的修人共和体——我去探的时候在想——它不是一个政策。"林牧说，声音比平时低了一点，像在说一件他想了很久才开口的事。"它是一个方向——从'包容'走到'支持'。你之前说包容是被传递的。那支持是什么？"

苏晚看着他。他的侧脸在灯火塔金紫色光芒的映照下有一层很浅的暖色。他说话的时候还是那个习惯——先停顿半秒，然后说出的每个字都精准地落在目标上。

"支持是——"她停了一下，想起了第七卷最后那段日子里的很多次对话。想起了他在母树平原上摸着树桩说"包容不是终点"。想起了石头在灶台边对她的弟子说"缺陷不是错误是起点"。想起了叶小雨在灵网上加的那条自动标记——"此用户今日无需包容"。

"支持是——"她又说了一遍，这次停得更久。

林牧没催她。他只是从石桌上拿起那支铅笔，在探索图的右下角空白处画了一个极小的圆——小到只能容纳两个字。他在圆里写了"支持"。

"你回地面做的事——"他放下铅笔，"是把这两个字从桂花树下这张石桌，贴到整个九州每一个灶台旁边。"

苏晚看着那个圆，看了很久。

灯火塔的火焰在远处轻轻跳了一下——那是叶小雨在调试今晚的灵网链路。过渡区的银白色天穹开始转暗——不是日落，是上界的"休息时段"到了，天穹的亮度会降到五分之一。

灶台上的粥又冒了几个泡。秦无夜今晚不在——她在母树下给新来的学员讲灶台维护。杜散修的女儿杜小月从灯火塔方向匆匆走过院子，手里抱着一摞今天收集的缺陷记录——她会在明天一早录入母树日志。

苏晚把她的手稿翻到最后一页。那一页是空白的——她预留了位置，准备写上"结语"。她拿起林牧的铅笔——不是拿自己的笔——在空白处写了四个字。

"相互支持。"

写完，她把铅笔放回图边。铅笔又滚了半个圈，停在螺旋线的最内层。

林牧看着那四个字。"这是——"

"第八卷的主题。"她说。"从相濡以沫到相互包容，我们走了七卷。现在要走到第八个了。你的梦想是让所有人不被蒙蔽。我的梦想是让所有人不被排斥。"

她低头看着自己的手——那双手这些年来写过政策草稿、提过灶台铁锅、在灯火塔基座上贴过便签、也在母树下接过新的桂花幼苗。

"你解决的是'恐惧未知'的问题。"她抬起头。"我解决的是'恐惧差异'的问题。本质上是同一个问题——用理解替恐惧。"

林牧没有回答。他只是在石桌边重新坐下，把自己的探索图和她的手稿并排放好。两份文件——一份指向地面，一份指向上界深处。中间隔着铅笔和桂花枝和灶台的热气。但它们用的是同一种纸——蜀山造的竹纸，每张上都有隐约的竹纤维纹理。它们来自同一棵树——或者说，来自同一座山上的同一片竹林。

石凳旁边，那棵桂花树的新枝在微风中轻轻点了两下。灯火塔的光芒透过树梢洒下来，在两张图上投下细碎的光斑。

远处的广场上传来石头的说话声——他在做今晚缺陷分享会的总结。"......所以今天有人分享说——'我害怕支持别人。因为我不知道我有没有资格支持别人'——我想说——支持不是资格，是动作。你伸手了，就是支持。"

苏晚听到这句话。她侧头听着，然后转回头看林牧。

"石头说的——就是我想写在草案最后一页的。"

林牧把两张图叠在一起——探索图在上，手稿在下。折叠线对折叠线，空白对空白。"我的图叠在你的草稿上——就是第八卷的封面。"

他站起来，往灶台里加了一小块柴。火焰吞掉新柴，发出一声很轻的噼啪声。"门快开了。不是飞升之门——是这一卷的门。"

苏晚也站起来。她把两份文件收好，放进石桌下的木匣里——木匣里还装着之前七卷的所有关键文件：第一稿的包容书、缺陷分享会的记录、飞升之门工程图纸、正魔共存的协议等等。这个木匣是石头做的，用的是桂花树第一次修剪时落下的粗枝。枝断了——但断过的木头能做匣子。

林牧往灶台锅里看了一眼。粥还热着，桂花已经熬化了，米粒在锅里轻轻翻滚。"明天的粥加了红豆——小米昨晚泡的。"

"你每次在重要的事前面都先说粥。"

"因为粥不会说谎。"

苏晚笑了——不是大笑，是眼角弧起一个极细的弧度。这个弧度和她多年前在天台上第一次和他说话时的弧度一模一样。时间过了不止百世——但弧度没变。

"第八卷——"她说。"明天开始。"

"明天开始。"他点头。"你回地面提案。我在上界探路。然后——"

"——在桂花树下碰面。"她接过他的话。

灶台上的粥还在微沸。灯火塔的火焰安静地立在过渡区的银白色天幕下。桂花树的新枝在这个五年来最平凡的傍晚，又向外长出半寸——这个半寸明天不会有人注意到，就像这个世界上的大多数支持，发生的时候都不会被注意到。

（第七百零一章 完）

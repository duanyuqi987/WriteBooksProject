# 第二十八章 龙虎山的招贤令

招贤令是在写字楼倒塌后的第十天正式发布的。

不是发在报纸上。是发在龙虎山天师府的官方网站上。那个网站平时流量极小——日均几十个点击，多半是游客查门票价格。但招贤令发布当天，服务器被刷崩了三次。

内容很短：

"天地有变，道门重启。凡天下修行者、觉醒者、对修炼一道有志者，可于下月初七亲赴龙虎山天师府。不设门槛，不限道统。有道传道，有法宝器。此令。"

落款不是天师府——是"当代道教协会、龙虎山天师府、茅山道院、青城山道观联合发布"。

"当代道教协会"这个词让很多人注意到了细节。不是"中国道教协会"。有一个"当"字。但没有人追问——因为内容太炸了。"修行者""觉醒者""修炼一道"这些词出现在了一份正式公告里。不是小说网站。不是动漫论坛。是道教名山的官方通告。

公告下面的评论区第一天就涌入了超过百万条留言。

"是我疯了还是世界疯了？"

"下个月初七是什么时候？农历吗？那还有一个星期。我现在订机票。"

"我不是修行者但我就是想去看看行不行？"

"作为一个从小学就开始看修仙小说的三十年老书虫，我先哭为敬。"

"楼上你哭早了。万一去了发现是旅游推广活动呢？"

"旅游推广需要说'天地有变道门重启'这八个字吗？"

实际上，公告发布的第二天，龙虎山所在的鹰潭市区酒店全部订满。第三天，周边三个县的民宿也没了。第四天开始有人搭帐篷。第五天，天师府不得不在山门外临时划出一片露营区。

没有人想到来的人会这么多。

更没有人想到——国家默许了。

没有部门出来说这是迷信活动。没有公告要求删除相关内容。招贤令的截图被转发了上亿次，甚至出现在了央视新闻的一个角落板块里。标题是"江西龙虎山：道教圣地举办修行文化交流活动"。

"修行文化交流活动"这个名字起得很克制。但所有人都听懂了。

写公告的人没有用任何一个能被挑出毛病的词。没有说"修仙"——说的是"修行者"。没有说"灵气复苏"——说的是"天地有变"。没有说"修真大会"——说的是"交流活动"。这种措辞精准得不像道士写的。像律师写的。

后来才知道——写公告的人确实是学法律出身的。天师府新招的一个俗家弟子，以前在某家国企做法务。

消息传到林牧那里时，他正在出租屋里给苏晚削苹果。

不是他自己想吃。是苏晚赖在他房间里不走了。她脚上的伤口还在愈合期，请了一周病假。在家里待了两天就嫌闷，坐公交跑到他这儿来，理由是他这里离医院近。其实并不近——出租房到第三人民医院反而比她自己家远了三公里。

他没戳穿。苏晚也没解释。

"你看这个。"她把手机举到他面前。屏幕上就是招贤令。

林牧瞥了一眼。削苹果的动作没停。苹果皮是连续的一整条，没断，厚度均匀，像他在做一件很认真的事。

"看到了。"

"'修行者'——你觉得他们在找你吗？"

"不一定是我。所有'觉醒者'。"

苏晚把手机收回去。她把那段公告又看了一遍。她的眼睫毛在屏幕的冷光里微微抖动——那是她专注时的习惯。林牧注意到了。他对她专注时的每个习惯都注意到了。她抿嘴唇是在犹豫，她皱眉是不同意的预兆，她看屏幕时睫毛抖动，是在快速思考。

"你没回答我的问题。"他说。

"什么问题？"

"刚才的——你觉得他们在找我？你说'不一定'。所以你想过这个问题。"

苏晚放下手机。她摊开手掌放在膝盖上。是个无意识的摊牌姿势。

"你这几天不太对。走路比之前轻了。呼吸比之前慢了。有时候你忽然看向窗外——外面什么东西都没有，但你看得很认真。像在听一个只有你能听见的声音。"

林牧把削好的苹果递给她。她接过去但没吃。

"你觉得我是什么？"

"不知道。"她把苹果咬了一口。咔嚓。"反正不像是普通人。"

房间里安静了一会儿。窗外是杂乱的城中村，远处的高架桥上堵着车。有个人在楼下喊收废品。苏晚吃完半个苹果，把剩下的放在盘子里擦手。

"我想去。"

林牧看着她。

"招贤令。我想去龙虎山看看。"

"你脚还没好。"

"初七是下周。那个时候能好。"

"去干什么？"

"去看看。"她的眼睛亮着——不是兴奋，是好奇。那种好奇在她眼睛里不是平时看八卦的好奇，是更底层的。她想知道这个正在变化的世界到底是什么样。不是为了热闹——是为了安心。

"如果是真的，"她说，"那我至少得知道这个世界的规则是什么。如果是假的，就等于去旅了一趟游。反正不亏。"

她说"如果是真的"时，语气太平了。太平反而让林牧心里动了一下。她不是一个容易接受非现实事物的人。她做财务，对数字敏感，对逻辑要求高。这样一个人在说"如果是真的"时没有一丝嘲讽——说明她已经默认接受了某个前提。

他忽然想起来。在写字楼里，她问他"你跑上来的时候在想什么"。他没有回答。

现在她不需要他的回答了。她自己想明白了。

"你不想去吗？"苏晚反问。

"不想。"他答得很快。"去了会被人盯上。"

"被人盯上？"

林牧没有解释。他已经去过一次龙虎山。昨天。以游客身份路过天师府广场。在那里他感觉到了至少三个人的神识扫过自己。他没有回应。其中一个神识很年轻，但意外地敏锐——那个穿道袍的瘦高年轻人。

他不怕被盯上。他怕的是被别人盯上之后，把苏晚也拖进来。

"所以你是知道自己会被盯上。"苏晚的声音平，语气笃定。她是财务，查账时用这个语气——就像手里已经拿到了全部凭证，只是在等你张口自己说。

林牧的回答是沉默。

苏晚看了他一会儿，从他手里拿过水果刀，自己重新削了一个苹果。她的刀工不如他好，苹果皮断了几截。削完之后她切了一半递给他。

"你被盯上，我陪你。不是说我陪你一起被盯，而是——如果你不想说的事我不过问细节，但你不能让我什么都看不见。"

她说完吃了一口自己的半个苹果。声音很脆。

林牧捏着她递过来的半个苹果。切口不平。苏晚削东西的技术一直不好——前世也是。

前世。

这两个字忽然浮上来。他没有阻拦。只是看着苏晚低头啃苹果的样子，阳光从窗帘缝隙里斜进来，落在她肩上。几根碎头发翘着，在光线里像极细的金丝。

他想起前世青云台上那个人影。那个模糊的、看不清面容的女子。她说话的时候也是这样——你不用问，她自己会把你不敢说的事翻出来，然后平静地告诉你她不在乎真相是什么，她只在乎你现在需要什么。

是同一个人。

他心里那个被揭开的缝又宽了一点。

"好。"他说。

"好什么？"

"陪你去龙虎山。"

苏晚抬起头。眼神里有意外——她大概设想过他会拒绝。会找理由。会拖着。但她没想到他说"好"。

"真的？"

"真的。去。但得准备一下。"

他说的准备不是收拾行李。是另一层。如果他要去一个有几十个道士和觉醒者聚集的地方，他现在淬体初期的修为太浅。那个穿道袍的年轻人——应该也是淬体初期，但人家有完整的道统传承，有符箓，有法器。而他只有前世的知识库存和四万块存款。

知识他有了。钱不够。灵石灵草买不起。

但没有选择。不能等到万事俱备。这辈子他早就学会了一件事——保护一个人最好的方式不是把她藏起来。而是站在她身前，让所有人都知道碰她之前得先过你。

"我去买票。"苏晚拿起手机，动作利落——像刚才他说的不是"好"而是一个财务指令。她在把这件事当工作处理。这是苏晚面对紧张的方式：把紧张翻译成一个可执行的任务。

"两张。"林牧说。

"当然两张。"

苏晚打开购票软件。手指在屏幕上划了两下，停住了。

"到下周一的车票都卖完了。高铁、动车、普速——全部没票。"

林牧站起来走到她身边看屏幕。果然一整片灰色。龙虎山招贤令的效应比他想象的更强。

"客运。"他说。"去客运站。县际班车。鹰潭到龙虎山的路不一定堵。"

苏晚划掉购票软件，开始查地图和班车时刻表。三分钟后抬头。

"有。一天三班。"

"明天。"

苏晚点了点头。她合上手机，又开始吃那个没吃完的苹果。咬了两口，忽然停住，拿开苹果看着他。

"林牧。我怕一件事。"

"什么？"

"怕它变成真的。"

这句话的意思很复杂。她不是怕灵气复苏——她是怕整个她所认知的世界被推翻。怕自己熟悉的一切被证明只是一个巨大的临时布景。怕从今以后，生活不再是加班、报账、周末去商场买菜、晚上躺床上刷剧。

怕她已经习惯的普通生活，再也不会回来了。

林牧沉默了片刻。

"已经变成真的了。"

他说得很轻。不是泼冷水。是给她一个最坚固的锚点。从这一刻开始，她不猜测也不怀疑了。他告诉她真相。即使他给不出全部细节，至少给了她这句话。

苏晚看着他的眼睛。他在那里面看到了恐惧和勇气并排站着。像写字楼里她抱着档案盒站在防盗门后面一样。

"那到了龙虎山，你得跟紧。"她说。

"我保护你。"

她笑了一下。这个笑有一点紧张，但不多——像写字楼倒塌后她在救护车上被他握住手腕时那个笑。

"谁保护谁还说不定。"她说，"我问过秦浩彬了。你撕的是衬衫下摆。那个布的质量不好。"

林牧看着她。这个女孩的逻辑是：你救了我，所以我得保护你。不是报恩。是"你在意我，我也得在意你"。交易的筹码不是人情和道德。是关心和关心之间的等价交换。

前世他为了一个人从青云台上跳了下来。这一世他还在做类似的事。只是规模小了一点——从前跳下来是坠落，现在反着跑上去，是上升。

这两个动作之间隔了一百世。方向不一样，要抵达的地方却一样。

"走吧。先吃饭。"他说。

"我要吃辣。"

"你脚上有伤，不能吃腥辣的。"

"那吃清淡的。"

"好。"

苏晚站起来穿鞋的时候，身子歪了一下。林牧伸手扶住了她的手肘。隔着外套的袖子，他感觉到她的体温和微微的脉搏。她站稳了，偏头看了他一眼。

"你手好凉。要不要多穿点。"

"不是凉。是辟谷的副作用。"

苏晚愣了一下。然后她反应过来了——"你在开玩笑。"

"嗯。"

"你居然会开玩笑。"

"偶尔。"

苏晚又笑了。不是之前那种紧张的笑，不是惊魂未定的笑，就是纯粹被逗到的笑。这是今天下午她第三次笑。三次笑之间，她接受了这个世界正在崩塌重建的事实，接受了一个守护者的存在，接受了自己即将去往一个不知道是真是假的世界的决定。

林牧替她开了门。楼道里的声控灯亮起来。

走到楼梯口时苏晚停了一下。

"林牧。"

"嗯。"

"你的秘密我不问。但你别一个人扛。"

林牧没有说话。他低头看着楼梯间的水泥地面。灯泡在头顶轻微嗡鸣。门外的城市在傍晚的光里嘈杂运转。

他想起前世那个人的最后一句话。当时没听清。落得太快了，风把所有字都吹碎了。

但现在他不在乎了。因为苏晚在这里。即使她什么都不记得，她也说出了和前世的她自己相同的话。

他抬脚往下走。苏晚跟在他身后，脚步声一深一浅——深的是右脚，浅的是受伤的左脚。

一步一步。走得很慢。但每一步都在往下一个月初七靠近。

龙虎山。招贤令。茅山传人。隐士家族。古老传承。一个刚刚苏醒的世界正在张开它的第一张大网。而在这个城中村的出租房楼梯间里，两个人正一步一步往下走。

他们还不知道自己将会变成什么。

但他们已经决定一起去。

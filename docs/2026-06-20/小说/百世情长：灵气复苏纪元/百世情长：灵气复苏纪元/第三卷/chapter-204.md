# 第204章 不该相遇的相遇

秦岭的雨下了整整七天。

第七天的傍晚，雨停了。夕阳从云缝里挤出来，把整条山脉染成了一半血红一半金色的颜色。血红的在西边山脊，金色的在东坡的乱石堆上。风吹过来的时候带着雨后泥土特有的腥甜味——那种土腥味混了松针的香气，厚重又清凉。

林牧连续追踪了三天。铁剑长老派给他的任务目标——"疑似赤霄宗情报人员"——确实存在，也确实在秦岭中出没。但林牧对这个目标不感兴趣。他在执行任务的幌子下做另一件事——沿着秦岭的东麓逐片搜索赤霄宗的第三阵地。

他的灵识网在元婴之后已经可以覆盖方圆三百里。但在搜索过程中他必须把灵识收敛到极小——因为赤霄宗的警戒阵能探测到灵识扫描。他只能在夜间利用自然灵气的波动进行最低频率的被动感知。这种感知比主动扫描慢得多——大概每个晚上只能搜索五十里的范围。

第三晚他在一座无名山峰的西坡找到了第三阵地的位置。灵识穿透云层落下去——模糊的轮廓里站了大概三十人。全是筑基期的内门弟子。他花了大概两柱香的时间从三十个灵压里找到那个熟悉的频率。她的灵力频率从来没有变过——不管换了多少世身体和姓名，她灵魂的灵压振动频率始终稳定在一个极窄的频带里。就像一段永远不变的密码——只有他能解码。

找到了。

第四天傍晚。荒山古庙。

这间破庙在秦岭深处一座无名的山腰上。庙的前殿塌了一半，只剩下中间一座残破的石头神像。神像的头部被雷劈掉了，只剩一个粗陶制的身体坐在莲花座上。雨水从塌陷的屋顶滴下来，在莲花座前聚成一个小水洼。水洼里倒映着从断壁缺口照进来的夕阳——一小片天空，金红色的。

林牧来这里不是因为什么任务——这是一个他熟悉的地方。前世他在秦岭游历时曾在同一座破庙里避过三次雨。每一次来的时候这座庙都更破一些。神像的脑袋是第三世之后才被雷劈掉的。庙前的石阶已经完全被野藤覆盖了。

他选在这里停下来不是因为怀旧——是因为庙的位置刚好处在赤霄宗第三阵地的西侧边界上。苏晚如果出外勤巡逻就一定会经过这里。

他在庙里架起了一把小铜壶。不是法器——就是从凡人镇子上买的普通烧水壶，黄铜做的，壶身锤出了鳞片纹。他从前世的储物袋里找到一套藏到大红的茶叶——昆仑云雾茶，灵气浓郁，泡出来的时候叶片会在杯子里缓缓转圈。他在神像前生了火。火苗在雨后的湿空气里发出轻微的噼啪声。

茶快要泡好的时候，庙外的山路忽然传来了脚步声。

不止一个人的脚步。而是——一个人的。来者的步幅偏小，脚力偏重。筑基初期修士的步频。

他不用灵识辨认也能知道那是谁。因为那种脚步声——后脚掌先着地然后力留在脚尖的后蹬——是第一世苏晚第一次去剑阁领剑时学会的走路方式。她后来在修仙界见识了更高的修为，但走路姿势从没有再改过。

林牧没有抬头。他继续把茶壶从火上提起来，把沸水倒进紫砂壶里。水流声很轻，在安静的古庙里被残墙放大了。

庙门外的脚步声忽然停了。

苏晚出现在庙门边。

她穿着赤霄宗的内门弟子服——深蓝底子上绣着火红的云纹，左肩的护甲有一道新的划痕。剑在右手里提着，剑鞘反绑在背上的扣——出鞘动作最快只需要一个呼吸。她的头发扎成紧束的马尾，额头上有一道浅浅的被汗水留过的印记。

她看到他的第一反应是剑尖对准他的方向——出鞘把鞘推开了半指——然后她看到了水壶和茶叶。

她愣了一瞬。

水壶、茶叶、茶香——这些不是战斗气息。茶香在废墟里弥漫开来，把古庙里那种霉烂的腐朽味冲淡了大半。新鲜的茶叶香气在夕阳之下有一种说不出的脆弱。

林牧抬起头，把茶杯放在神像底座上——不多不少正好放了一杯——然后他做了一件很奇怪的事：退后两步，把双手在身侧展开，做一个"我没有攻击意图"的手势。

他看着她。从头到脚看了一遍。上一次面对面看她还是两年前的青溪镇——那世她已经快要走完了。现在她年轻了，年轻得让他有点心酸。她的警惕感比上一世重了很多。上一世的苏晚在变成茶店老板娘之前是一个温柔到可以原谅所有人的女人。这一世的苏晚在一个朝夕磨练的战斗宗门里长大——警觉比温柔先一步到达意识层面。

但她看他的眼神里有一样林牧很熟悉的东西。第一世她第一次见他时也是这种眼神——一半警惕，一半好奇。人类对"未知者"的天然反应是警惕。但对"似曾相识的未知者"的反应会在警惕里掺杂出一丝奇怪的心悸。

苏晚松开剑柄。

不是因为信任——是因为她判断出两人之间的实力差距没有任何意义拔剑。他的灵力在她灵识里是一片漆黑的深海——能感觉到有存在存在，但完全感知不到边界。元婴？不对，元婴修士不会出现在这种荒山里泡茶。金丹？散修？

她还不知道他是谁，但她知道一件事:她的剑对这个人没有用。

"你是联合会的？"她的声音比前两世都更冷、更利。赤霄宗的弟子在出任务时使用的语气——公事公办的审视。

林牧把刚要再倒茶的壶悬在半空。"算是。"他把第二杯的水倒进她那个方向的一张破桌板上。桌板歪斜，水沿着倾斜角度往一边滑——他伸手扶住杯子。"暂时挂了个名。散修，林牧。"名字他故意用了真名——因为在未来她的轮回初醒阶段，"林牧"这个名字就是属于与她关联的唯一的密钥。

她的眉毛皱了一瞬。"林牧？"

她在赤霄宗的档案库里见过这个名字。赤霄宗收录了一份极其详细的"可疑散修名单"。名单上的人数逾千人。每个人都被按危险性和功法属性划分等级。林牧被列在"疑似危险等级三"——不善战的描述在档案里只写了两个词："金丹散修"、"行动轨迹异常"。异常的地方在于——他的行踪记录与十年前、二十年前、三十年前的多份监控记录有高度重叠，重叠的方式不是"一个人"会出现的正常移动曲线，而是像一个穿越者、一个永生者在不同的时间节点同时出现在不同的地点。

苏晚在他的胸口停留了一下目光。他的右手无名指上戴着一枚很旧的银戒指——不是法器，就是普通的凡人之物。戒指在夕阳的光里反射出一小片很细碎的光斑。不知道为什么，这个细节让她心里某一块极深极隐秘的地方泛起一阵浅浅的熟悉。

他把剑放下——不出鞘，但不再指向他。

"你为什么会在这里？"

"泡茶。"林牧把另一只茶杯放好——这是他用灵识发现的第四种方式。他给她一杯茶的时间——不需要多长，能喝完就好。每见她一次，对他来说都是偷来的时间。这一世她一旦结束，又要等十几年甚至几十年。

"散修，秦岭有战事。这里离赤霄宗第三阵地不到五里——你就不怕被抓？"

"怕。"他说。他的语气过于平淡了——不像出任务时那样审视性的平淡，而是一种更深的、用几十年的独处练出来的平淡。她对这种平淡产生了警觉——不是对危险来源的分析，是对"这个人说话的方式怎么像是在等我的反应"的直觉。

她把剑完全收进鞘里。然后蹲在破墙边——手可以同时摸到剑柄和出鞘路径的那个位置。

林牧端起茶壶给她倒了一杯茶。茶色淡绿，香气里夹着松子一样的回甜。她接杯子的时候指尖不小心碰到了他送过去的那半段杯沿。两人的手指距离大约只有一臂——近到林牧能看清她眼瞳里有一点反射出的茶水的光。

他看着她端起杯子，在杯沿上轻轻吹气——和前世的每次都一样，她总是在喝之前先吹三口气。能驱散茶面的热气。这个习惯他从一千年前就开始计时。

他垂下眼帘。不能看太久。看久了瞳孔会湿。金丹修士的瞳孔不会湿——但他不是金丹。

她喝完之后站起来。

"你的剑很快可以出鞘。"他说，"但剑尖不要在出鞘前先下压。你下压的那半寸会让你多浪费一个呼吸的时间。"

她愣住了。

这是上一世他用口述教会她的——那个当时仍无记忆的苏晚。而她不知道。

她把剑柄换了一个手的握法，目光奇怪地看着他——然后转身离开了古庙。

庙外的天色完全暗了。她的背影和剑刃在山路的尽头被夜吞没。林牧把冷茶倒掉，把茶杯一个一个收进布袋里。他的手指在杯沿停了一瞬——还能感觉到她指尖的余温。

锦鲤在水壶里浮上来吐了一串字："你是不是又放水了？"

林牧没回答。他把铜壶里的余水倒进莲花座的水洼里——水面重新亮起来。照见一小块破碎的夜空。

天上有一颗星。很亮，正好倒映在水洼里。在神像残破的头部位置形成一个倒悬的光点。

林牧说："这颗星叫乙火——第一世的时候她喜欢指着它让我猜名字。她每次都猜到错。"

"然后呢？"

"然后她就会笑——说这次猜错了。但她笑得跟猜对了一样开心。"

锦鲤沉默了。

林牧站起来。山谷的风越来越凉。明天——或者后天——赤霄宗将和散修联合会第一次正面接战。苏晚将被卷入那场战场。而他将以一个敌对方的身份站在她的对面。

那应该是他们见面最糟糕的时机。

# 第184章 依旧普通的资质

苏小晚从小学到高中，一共经历了七次正式的灵根检测。每一次的结果都相同:D级。

小学二年级第一次——D级。四年级第二次——D级。六年级第三次——D级（木属性轻微）。初二第四次——D级。中考前第五次——D级（木属性强化半级，但仍为D级，只是"D+"）。高一入学检测——D+。高二分科检测——D+。七次检测记录用一个单调的折线图表达的话，就是一条从D勉强爬到D+然后趴平的线，几乎可以忽略变化。

在灵气至上的时代里，这串连续的检测结果在某种程度上构成了她青春期的最大阴影之一。同学们在聊灵根的时候她会悄悄不说话；老师说到"根据同学们的灵根等级来选择未来职业通道"时，她会把笔在纸上无意识地划圈。她并不愤恨——她只是觉得"跟别人不太一样"。那种"不一样"不是她喜欢的异类感——而是被一个固定标签压在头顶的感觉。

但她不知道的是，每一次检测结果出来之前，林牧都在暗处做过精密测定。他用自己的灵力扫描仪在校外探测过她的灵根显象——每次锁示图象都是同一个:灵根本体的核心有一束被紫色薄膜压制的明亮线，膜外显的便是那唯一部分透出的D级光谱。这就像一盏被黑布罩起来的百瓦灯，只在布罩边缘散出一点点微弱的散射光。检测仪器就是按散射光来判它只有D级。然而罩子下面的那根主灯丝——在她的灵魂里从未停止地明亮地燃烧着。那才是她真正的天分。只有林牧一人在黑暗中看得见。

为了让她不彻底放弃自己，他要把每一次D级结果之后的那几天变成她的"重新启动期"。方法很多——有时是买一套新彩笔给她，让她去画油菜花田；有时是带她去山里捉萤火虫（用一个小透明瓶子——傍晚放进三只虫子最后放飞）；有时是忽然跟她讲一个"蜗牛的故事"——说一只蜗牛爬了一辈子最终才爬到葡萄树顶，但它吃到了全世界最甜的葡萄——"不是因为蜗牛慢——是因为葡萄值得爬那么久"。

她每次听他讲这些不直接反驳，只是把嘴巴往两边翘紧巴巴的一点。但晚上睡前她会把他说的话在脑子里重复说给自己——然后觉得身体又暖起来。循环了几十次以后这成为了一个熟练的仪式:白天D级——晚上老师讲故事——睡觉前自己复讲——第二天恢复动力。

此外他也在逐步加大实际的功法训练强度。初三那年，他正式开始了"呼吸引导2.0"。不像之前只是简单和树叶对话——现在开始教她古人留下的卷气法（一个很古老的基础引气呼吸法，能促进人体自然的微灵气循环）。他把它命名为"中医经络保健操"。每天十五分钟，早晨课前她到他的小院子里完成。这套功法不会触发轮回锁报警——因为它与灵根直接升级无关——只针对把现有D级灵根的使用效率提高到极限。

效果是显著的:她身体比以前更好了——高中的体育考试每项达标（长跑成了全班前几名），头脑清醒，不大感风，脸色也常润红。在班上没人能理解为什么一个D级灵根的人体能那么好——只有林牧一个人知道，这些都是在为最重要的那句话积蓄底气。

高一上学期末——语文考试作文题目是"我有一个朋友"。她写的是林牧。

文中称他为"林老师"——描述了一个老人和一只猫住在乡下、以无私耐心陪伴孩子成长的故事。她写了很多细节——关于那只猫尾巴的触感、关于他说"蜗牛故事"时言语那个慢缓的节奏，关于他给她泡的茶每次都不烫牙龈就是口温刚好。结尾处写:"他今年好像永远都是那个样子——不会变。他的背部有点弯，但看人一点都不弯腰。他说学生考得好坏不重要，重要的是心里一直有一件让自己想变得更好的事。我有时候觉得他的心里也有一件很深很深的事——他从来没说过，但它好像一直在他眼底飘着。——如果有一天我能做点什么，帮助他——我想帮他看他那个漂着的东西看清。那样也许他就真的不用只是猫陪着了。"

林牧帮着她改了这篇作文里面的错字和病句——改到最后看到最后一段时，手中的笔迟疑了一下。他在想：她在窥见我的孤单。但她没有把它解读为"老师对我有不一样的感情"——她只是以朋友的角度在关心他。这样很好。

他帮她把作文润色后还给她。她拿去交作业，结果这篇题目得到了全班最高分——被语文老师当堂念了。她第一次在学校的非体育课上得到"最突出"的评价。她跑回来说"老师！我的作文拿了全班第一！"他笑着说"早说过你行的"。她快乐得像拿到修仙入学通知书——虽然那个入学通知书她大概永远拿不到。

当晚林牧在笔记上写道:"她已从常规挫折环境中形成了稳定修复机制。自我评价不再被灵根等级完全控制。这是破锁的第二步——有自主修复意识。再下一步:主动追求突破。"他把这句话下面划了三条粗线。

那个女孩不知道她每一次的D级挫折都在为将来的"我想修仙"积蓄最大的主动性。她的资质依旧普通——但灵魂正慢慢褪掉那些被贴着黯淡标签的外套。这一天还没到——但在路上的每一天都比前一天更近了。

**作者：段锦佑**

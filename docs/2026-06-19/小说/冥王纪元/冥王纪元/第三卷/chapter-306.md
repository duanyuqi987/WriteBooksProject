# 第306章 火星基地成为中国宇宙前哨站

一个月。从火星到地球之间平均距离约两亿公里。祝融号——实际不是原本那台火星车，而是国家航天局在过去半年内紧急改装的一艘灵气驱动载人飞船——以全速航行的速度走完这段距离，差不多需要刚好一个月。这艘飞船的推进核心是一台在月球战傀技术基础上逆向解析出来的灵石引擎——推力大约是传统化学火箭的十六倍，而且可以在航行过程中从太阳风中捕捉稀薄的灵气进行补充——近似于无限续航。

飞船在火星离宫外围的平坦区域降落时，李长生站在离宫的入口平台上等着。陈霜在他的右边，手随意地搭着剑柄。刀疤在他左边，双臂交叉抱在胸前。小王和老马在后面的台阶上。龟相缩成了巴掌大小的状态，趴在李长生的右肩上——它在火星的重力下缩得更小，像一块深绿色的石头别在他的衣领旁。

飞船的舱门打开。第一个走出来的人让李长生微微怔了一下。不是航天员。是一个穿着旧工装的中年男人——五十来岁，皮肤黑里透红，手背上的青筋粗得像树根。他手里拎着一个帆布包，包上印着一家水泥厂的logo。他看着火星红色的大地，脸上的表情不是震撼——而是很认真地看了好一会儿，然后说了一句话。

"这地——不太能种东西。"

身后响起了笑声。五十个人陆续走下飞船。全是草根修士——外卖骑手周大壮、护士林晓、建筑工老赵、高中物理教师方静——这些都是在中国灵气复苏的第一批觉醒者。有些是李长生之前就认识的名字——周大壮、林晓、赵铁柱、方静。有些是他第一次见的陌生面孔。每个人的职业都不一样，但每个人的脸上都带着同一种神态——一种确定了命运方向的人才会有的平静。

五十个草根修士之后，是二十名航天员。穿着标准航天服、步伐整齐。领队的航天员走向李长生，敬了一个标准礼。"火星修士基地驻防航天分队全体二十人报到。指挥官同志——请指示。"他叫徐航，是中国航天员大队最有太空飞行经验的老手，曾在空间站上驻留过一年半。被调来火星基地时，他的同事都认为他疯了——放弃在空间站安稳的工作去火星那个不毛之地，去一个刚发现不到两个月的上古遗迹里搞"修炼"。但徐航来火星是有自己的考虑的。他三年前体检时被发现有金属性灵根——强度不算高，中等偏下，但对无重力环境下的灵气操控有天然适应性。他放弃空间站不是一时冲动——而是他想成为第一个在地外行星上修炼的中国航天员修士。

李长生确认了所有人的状态后，抬头看了一眼火星的天空——祝融号在他面前完成了一次堪称完美的垂直着陆。这艘飞船本身也是一项技术验证：从地球到火星，完全依靠灵石引擎，不使用一滴化学燃料。它在飞行过程中消耗的灵石总量是——十七公斤。十七公斤灵石驱动一艘载人飞船跨越平均两亿公里。这个能效比任何化学火箭都高出不止一个量级。它意味着从地球到火星的太空旅行成本将大幅下降——从一个国家才能承担的超级工程费用，降到了一个中等企业也能承受的水平。

守殿人在所有人的神识中同时开口:"欢迎来到冥王宫。我是守殿人，离宫管理系统内核。接下来由我来为各位介绍基地设施和规章制度——"

五十个草根修士和二十名航天员同时安静下来。他们听到了一个在脑中直接言语的声音，安静不是因为听懂了——而是出于纯粹的震撼。守殿人在接下来的一周内完成了一份细致到令人发指的工作。它为每一个新来的修士都建立了个人修炼档案——记录每个人的灵根属性、现有修为、潜力预估和训练建议。这些档案不是人工填的——是它在每个人进入离宫入口时，通过入口处的一个"灵气扫瞄通道"自动完成采集的。

五十个草根修士的灵根分布是这样的:金系八人、水系五人、火系七人、土系十一人、木系六人——这是标准的五行分布。剩下的是罕见属性:风系三人、雷系二人、冰系一人、暗系一人。那个暗系灵根持有者是个二十八岁的年轻人，以前是夜班保安。他在测试时灵气盘一片空白——和李长生当年一样。不是没有灵根，是暗系不在五行体系内。

守殿人的修炼指导系统让五十个草根修士的进步速度快到了让人不敢相信的程度。它从冥王留下的功法库中提取了最适配的训练课程——每个人量身定制。密室的聚灵阵配合火星灵脉的补给，让灵气浓度远高于地球上任何灵眼；它根据灵根类型精准分配修炼强度和功法。两周的训练后，五十个草根修士平均提升了1.3个小境界（如灵者中阶→灵者初阶顶峰），部分人甚至冲破了瓶颈。就连二十名航天员也都开始进入修炼节奏——太空适应能力和灵气操控能力之间有着显著的协同效应。在火星重力（0.38g）环境下修炼灵气操控，比在地球上更容易找到"灵力与重力"的分离感。这为将来的太空中作战积累了基础技术储备。

当火星基地完成首批人员部署的同时，地球上也在发现新的变化。国家通过祝融号的首飞成功验证了灵石引擎的可行性——十七公斤灵石驱动跨行星航程——这个数字震动了整个航天领域的分支。航天局在火星基地落成后第一时间调整了十年规划:原定五年内完成的月球常驻计划提前——月球前哨站将在三个月内开始常驻。与此同时，小行星采矿、火星量子通讯网络等一系列配套项目也随之启动——本质上，每一次灵石引擎的成功都意味着人类跨出了一步走向太阳系全面开发。中国拥有目前唯一可靠的灵石引擎技术，而技术源头就在火星离宫。

两周后的一个傍晚——火星的傍晚不分白天黑夜，天空永远是一种含铁锈的灰褐色——李长生站在离宫入口的平台上。身后是七十个人的集体修炼的声音——密室里的聚灵阵正在全功率运行。守殿人传来了最新一批修炼数据的统计结果。他的身后——离宫里灯火通明、修炼声隆隆。这里是火星的表面——一颗在过去几十亿年没有任何人类居住过的行星——现在有七十个中国人在上面修炼、生活、工作。火星基地已正式成为中国进入宇宙时代的第一个前哨站。

(第306章完)

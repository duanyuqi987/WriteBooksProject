# 第448章 小胖的仙丹供应，维持队伍战力

诸天号，丹房。

厨师小胖站在十二座丹炉之间，身上的围裙已经焦黑了大半。

他从三天前就开始炼丹了。自从宇宙大战的预警传来，刀疤就给他下了一道命令——"不管用什么办法，保证全舰队三万六千人的仙丹供应。打仗可以少一门炮，但不能断了补给。"

小胖当时深吸一口气，回了两个字："明白。"

然后他就把丹房的门锁死了。

十二座丹炉是王宇帮他改装的灵符丹炉——传统丹炉一炉只能炼一种丹药、开一次炉得七天。王宇用灵符引擎改造了丹炉的火控系统和投料系统，把炼丹周期从七天压缩到了三个小时。代价是丹炉的故障率高得惊人，每十二个炉子同时运转时，会有三到四个在高温高压下发疯，随时可能炸炉。

小胖在十二座炉子之间来回跑动，靠的是他这些年炒菜练出来的脚法和火候感。炒菜和炼丹，在根子上是一回事——火候到了，料下去；早了夹生，晚了焦了。

"三号炉火力加一成！七号炉投第六味！九号炉开盖——"

他的动作快得只剩残影。同时掌控十二座丹炉的火候，相当于同时炒十二道菜，而且每道菜的配方都不一样。三号炉炼的是归元复原丹，主药青灵芝性寒，火要用文火慢慢煨；七号炉炼的是灵力爆发丹，主药赤焰朱果性烈如火，必须猛火快出；九号炉炼的是经脉修复丹，主药白骨花——小胖刚打开九号炉的盖子，一股黑烟就喷了出来。

炸炉了。

九号炉的碎片在丹房里飞溅。但小胖没有被炸到——在盖子松动的那一刻他就已经侧身闪开了。炒菜师傅对火的直觉救了他一命。

"妈的。"小胖抹了把脸上的黑灰，"白骨花又失败了。这药太娇气，武火三息转文火——三息稍微多一丁点就炸。"

他看了一眼库存清单。经脉修复丹只剩四十枚了，而前线伤员在持续增加。刀疤的战舰每次火力对抗都会产生伤员——灵能光束的消耗虽然在王宇的优化下降低了三成，但连续作战中经脉过载仍是主要战损原因。

"必须再试。"小胖咬牙，从药库里重新取出一份白骨花——这是最后十二份原料了。

他站在新换上的十号炉前，闭上眼。

火系天才。

这四个字是龟相评价他的。当龟相第一次见到他在灶台前炒菜的时候，老龟沉默了很久，然后说了一句话："你祖上，出过大丹师。大丹师是帝者级的炼丹师——不是修仙境界的帝者，是在炼丹一道上称帝。你体内的火系灵根纯度极高，但被炒菜的油烟封印了。解开它，你能炼出帝级丹药。"

小胖当时笑着摆手说"我就是个炒菜的"。说这话的时候他正在李长生家的厨房里颠锅爆炒，锅底的火是普通煤气灶的火——不是灵火。油温到了七八分，葱姜蒜下去，然后肉丝滑锅——这是他做了十年的动作。龟相说他是火系天才的时候他差点把锅铲甩飞了。"龟大爷你别瞎说——我就一炒菜的，火大了就糊火小了不熟——跟你们那个火系帝者八竿子打不着。"

但现在他笑不出来了。

他面前的十二座丹炉每一座都在高温下发出嗡嗡的共鸣声——那是炉壁合金在高温高压下产生的应力共鸣。丹房的通风系统正在拼命抽走炉火散发的炽热灵气——但空间里的室温还是到了一百一十度。他全身被汗浸透，围裙上沾满了焦黑的炉灰和溅出来的药液残渣，双手虎口处烫出了三个水泡——但他完全不记得是什么时候被烫到的。他的每一枚丹药都可能决定一个战友能不能活着撑过下一次火力对抗。他体内的火系灵气像岩浆一样在经脉中奔涌——三天三夜不眠不休的极限炼丹，十二座丹炉的火候同时在他脑子里维持着不同的温度记忆：三号炉炉芯温度一千四百三十度，七号炉炉芯一千八百度——温度误差不能超过三度。比炒菜难多了。炒菜火大了顶多糊一道菜——炼丹火大了一炉子药炸光不说，旁边十一个炉子也会被冲击波震乱火候。

他的火系灵根在这种接近极限的持续灼烧下烧到了临界点。封印不是某个人给他加上去的——是他祖上大丹师的血脉被时间稀释了几百代之后在普通生活中自然沉寂的。就像一块烧红的炭被埋进灰堆里——炭还在，但外面裹了几百层时间的灰烬。现在这些灰被三天三夜不熄的丹火一层一层烧穿了。

封印，裂开了。

小胖感觉自己的脑子里有什么东西轰然炸开——不是疼，而是某种被压制了一辈子的记忆和本能同时苏醒。他看到了一个穿着古老丹袍的老人——老人的头发全部雪白但面色红润得像个年轻人——站在一座巨大的青铜丹炉前。丹炉有三层楼高，炉壁上的青铜纹路是某种已经失传的古代丹符。老人正在用紫色的帝火炼制一枚散发着九色光芒的丹药——那种九色光不是七彩色谱，是九种不同的法则化成了光的色彩。老人炼完丹之后转过身看了一眼——那个画面不可能是第三人称拍摄的——是从他自己的眼睛里望出去的。那画面不是幻觉——是从血脉深处浮现出来的祖先记忆。他自己的曾曾曾曾爷爷，曾经看过他一秒。

"曾曾曾曾爷爷，"小胖下意识地低语——他的声音因为三天没喝水而沙哑得像两张砂纸在互相摩擦——"咱家祖上，真出过大丹师啊。你没吹牛。"

他睁开眼，手掌按在十号丹炉上。炉火在没人操控的情况下自动变幻了火候——不是他在操控火，而是火在听从他的意志。火系帝级天赋，完全觉醒。

白骨花在炉中稳定地融化，三息武火转文火，分毫不差。

经脉修复丹，成了。

这一次炼出的经脉修复丹和之前截然不同。丹药表面有一层淡金色的光芒——那是帝级丹药才有的丹光。普通经脉修复丹只能修复经脉的物理损伤，但帝品经脉修复丹能孕育新的经脉，让重伤濒死的修士在半个时辰内恢复战斗力。

小胖没有庆祝。他甚至没时间多看一眼。他拔出丹药，把九号炉换上新炉，直接从三号炉中撤出归元复原丹，用新觉醒的帝级火系灵力操控炉火——十二座丹炉的火候同时进入完美状态。

一炉一炉的丹药从丹房送出，穿过走廊，进入前线的战舰。重伤的修士服下帝品经脉修复丹，断裂的经脉在药力下重新生长；灵气枯竭的炮手服下帝品归元复原丹，五息之内灵气恢复满盈；战场透支的陈霜服下帝品九转金丹，剑道意志重新凝结。

"小胖的丹药质量突然暴涨了？"王宇看着战斗数据的实时反馈，皱眉，"经脉修复成功率从百分之七十三跳到了百分之九十四。什么情况？"

小胖在通讯频道里的回复只有一句话："祖上显灵了。继续炼丹。"

他擦了把额头上的汗，继续在十二座丹炉之间奔跑。

三万六千人，每人每天消耗至少两枚丹药。一天七万两千枚。十二座丹炉三小时一炉，一天八轮，每炉出丹约五十枚，日产四万八千枚。不够的缺口，他用帝品丹药的效率弥补——帝品丹药效果是普通丹药的五倍以上，一枚能顶五枚。

这是后勤。后勤从来不写在战报里，但每一场胜仗都是用后勤堆出来的。刀疤的舰队能持续压制帝者，靠的是小胖的丹药支撑；陈霜能快速恢复经脉，靠的是小胖的九转金丹；李长生能专心对付帝者不必分心，靠的也是后方源源不断的丹药供应。

厨师小胖，在丹房里连续工作了七天七夜。

第七天晚上——如果宇宙战场上有"晚上"的话——他从丹房走出来。门打开时走廊里的温度瞬间飙升了十几度——他的身体在七天七夜的超高温环境下蓄积了大量火系灵力，刚离开丹炉环境时外溢的热量还没被身体彻底收敛。他瘦了二十斤——眼眶凹下去了，颧骨凸出来了，围裙上已经看不出原来的颜色。他的双手十指在连续七天高强度的控火操作下暂时失去了精细动作能力——手指会不自觉地微微颤抖。但他的眼神很亮——不是疲惫后的涣散，是做成了一件特别大的事之后的那种亮。

他手里捧着最后一炉刚出的丹药——帝品九转回元丹，一共十枚。每一枚的丹光都是暗金色的——和冥王令的颜色一样。他不知道为什么会是这种颜色——但他猜这是因为那些药有人是从冥脉节点上采来的。李长生的冥气大概渗进了药田。

他把丹药交到医疗舱那边，然后靠在走廊墙上慢慢滑坐在地上。七天七夜没睡的他第一次觉得脚下的地板有点晃。他闭上眼睛——然后马上又睁开。不是不想睡——是他脑子里还在自动运行十二座丹炉的火候程序。他睡着的时候梦到三号炉漏火了——从梦里吓醒然后发现三号炉好好的。他摸了一把手背上的水泡——已经破了，结痂了，又被烫破了，又结痂了。他看了一眼自己粗糙的双手——这双手以前只炒菜。现在他在炼丹救国。

走廊那头老陈推着一车刚分拣好的灵药原料过来了——他当快递员时练出来的分拣速度，在药库分拣灵材时同样适用。老陈看见小胖坐在地上，把手推车停住，从怀里掏出一个保温杯。里面是他用老家的枸杞泡的热水——枸杞是在火星基地的灵植温室里自己种的。"喝点。你可以睡三个小时——下一炉的原料我已经替你分类好了，按药性寒热和火候要求分了十七个筐。"

小胖接过保温杯，喝了一口。枸杞水是甜的。他靠在舱壁上，从墙上传来的微弱振动里能感觉到冥王号在持续作战——引擎在运转，主炮在充能，护盾在被猛攻。舰桥那边还在打着。丹房旁边的灵材库房——老陈还在分类，林晓在另一边把药品按照急救优先度编号打包，工程师老马在检修刚被震坏的第十一号丹炉，小王在舰桥上一边写防御补丁一边统计全舰队的弹药和丹药消耗比。所有人都在自己的岗位上守着自己的那份事。

十二座丹炉还在运转。灵符引擎驱动的炉火没有熄。新的归元丹和新一批的经脉修复丹将在后续整批地从丹房运出。后勤不写在战报里——但每一场胜仗都是后勤撑出来的。而在这个宇宙最深处的战场上——支撑着一支凡人舰队和十一位帝者死战的后勤力量中——有一个以前炒菜的胖子。

（第448章完）

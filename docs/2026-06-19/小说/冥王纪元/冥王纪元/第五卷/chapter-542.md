# 第542章 危机

反攻的决策刚刚做出——帝国就遭遇了开战以来最严重的资源崩断。

事情发生得很突然。太阴冥脉的冥气输出在昨夜达到了临界值——输出量骤降到只剩原先的一成。这是龟相一直按着的实际状况——他本来以为还能撑几天，但冥脉深处的灵脉根源结了一块"冥垢"——是长期超负荷输出下残留的大量剑气和光能碎片在冥脉中沉积形成的硬壳。

"冥垢堵塞了灵脉主干——能输出的冥气量被掐到了不到一成。防御阵法全面降级——冥土断界阵即将失效。"龟相的声音仍然很稳——但所有人都听出了这句话的分量。

冥土断界阵一旦失效——维度壁垒薄弱处的所有防御将完全消失。联盟舰队——包括一直待在后方的冰极王和阵天帝——可以毫无障碍地大批穿越壁垒直接涌入帝国核心区域。

老陈第一时间调动了所有还能动的工程舰队，派往壁垒薄弱的十一处节点——但问题在于，这些节点没有冥气保护，工程舰队本身会变成敌方的活靶子。

果然。赤霄王的火核舰队在冥气减弱的那一刻就感知到了防线的裂缝——他的法则之火迅速向防线中渗透，在冥气最稀薄的一处节点成功突破了防御——几千团火核涌入帝国心脏圈的外层，在距环形工业带不远的外太空中造成了严重火灾。环形工业带的数十座兵工厂在短时间内受到波及——部分装配线不得不紧急关闭。帝级引擎的日产量从一百台骤降到不足三十台。

刀疤带着禁卫军拼死挡住了那批火核——但代价极大。禁卫军战损过半，刀疤本人也在第九次击退敌舰后被严重烧伤——被林晓强行后送。他躺在担架上还跟李长生发了一条简讯："防线还没垮。改一下策略——再搞。"

李长生收到简讯时正站在环形工业带的主控室里。他面前是老赵。老赵的工厂被火烧掉了近两成的产能——但他没有心疼工厂——他担心的是那台还在运转的帝级引擎核心生产线。如果这台核心生产线被炸了——帝国在短期内就没有办法再制造新的帝级舰艇引擎了。

"保得住吗？"

"需要时间转移核心线。"老赵说，"我想把整条核心生产线撤到第十二层防线之后的备用基地。但搬运设备需要灵力——现在灵石的供应也在吃紧——需要额外调拨。"

"调。"

灵石调拨令在片刻之内发到了灵石总局。但回复来得很快——昆仑总枢的灵石储存在连续十几天的超负荷开采下已经断崖式下降。能调拨的灵石——只够搬半条线的。

"搬半条。"李长生说，"先保住一半能力——以后再想办法恢复。"

环形工业带上的搬运作业在火核不断袭扰的情况下艰难展开。工人们在一片漆黑的空间中推着几吨重的核心装配机向后方移动——他们的灵力手镯在透支放电，把装配机一台台送上货船。林晓的医疗队同时在前线和工厂之间疲于奔走——伤员从防线上抬下来之后的临时床位在工厂角落搭了一排又一排。

危机不仅在工业带——民间也感受到变化。民用灵石的供应断崖式下降影响了普通人的生活：灵气供暖在多个星域中断——数以亿计的居民在自家的屋里裹着外衣取暖。全息网络上的舆论也开始出现分化——一部分人仍然坚定支持帝国，但越来越多的人提出疑问：战争到底还要打多久？

许冰做了一件很冒风险的事——她将战时物资征调令对民间的影响以全帝国公开通讯的方式通报了实情。她知道这样做会让人心波动——但她更相信帝国宪法第一条："人民有知悉国家真实情况的权力。"

"这不是在泄气。"她面对核心层的质疑时解释，"百姓知道情况越透明——他们在硬扛时越有准备。不知情的恐慌才可怕。知情的承受——叫意志。"

她对了。通报发布之后——民间舆论在最初的短暂恐慌之后迅速稳定。多数人选择了理解——并开始自发地支援前线。有的星域组织了民营灵石募捐——将民用储备中的余量灵石集中上交。有的老修士捐出了自己用了几十年的灵丹储备。有一个偏远星域的小镇把镇上的灵石路灯全部拆下来——连灯柱一起运到前线的灵石回收厂。

李长生看着这些画面——沉默了很久。

"我不能再让他们扛太久了。"他说。

（第542章完）

# 第240章 第七世·第八世：并肩与交融

第六世结束后，林牧等了五年。第七世苏晚转世在昆仑穆氏家族，那是昆仑最古老的修仙家族之一。她这一世叫"穆晚"，是穆家排行第七的女孩。出生时天有金色灵光，被族中长老断为"前世合道以上修士转世"。

穆晚从三岁接受家族正统修炼教育——四岁引气入体，七岁淬体圆满，十二岁筑基，十七岁结丹。这个速度在穆家千年历史中排前三。她与林牧在昆仑瑶台重逢后，两人首次以完全对等的修为状态共同修炼——她不再是需要被保护的一方，她有自己的家族资源、独立身份和修炼体系。

第七世她完成了"百世归一剑诀"的终极版，将前六世全部剑法融为一炉。她与林牧在昆仑瑶台上完成了首次合道期双修士灵能互补——两人合力炼出了第一枚双人共铸的"百世剑符"。这枚符成为后四世最重要的定情信物。

第八世她转世在昆仑的玉虚城，同年便恢复了全部前世记忆。她与林牧完成了灵魂交融的第一层——灵力交融。两人的本命剑灵在碰撞时不是互相攻击——而是自动缠绕——形成了一柄前所未有的合体剑灵形态："双刃金火窄身真剑"。

八世修行——积累了足够的修为底蕴。距离真仙飞升只差最后两世。

第九世——飞升的前夜——即将在昆仑瑶台开启。

# 第199章 番外四：厨师小胖炼出第一颗仙丹

小胖的本名叫何满仓。

这个名字是他爷爷取的。爷爷在生产队管过粮仓，一辈子最大的愿望就是仓里满粮。满仓小时候不喜欢这个名字——它听起来像一个圆滚滚的背篓。但后来他长成了一个圆滚滚的人，大家就叫他小胖，本名反而没几个人知道了。

小胖今年二十六岁。灵气复苏之前，他在城里一家川菜馆当帮厨。不是掌勺，是切菜的。每天早上去后厨，把一堆堆青椒、土豆、萝卜切成统一的尺寸。他切菜的时候从来不抬头——不是因为专心，是因为他在心里默念母亲给他编的顺口溜:"横切牛肉竖切猪，斜切鸡片滚刀鱼。"他是个认真的帮厨。虽然他从没拿过炒勺，但他觉得切菜也是一种修行。

灵气复苏之后，小胖觉醒了火系灵根。

发现这个事的过程很不体面。

那天后厨的燃气灶坏了三个，只剩一个灶能用。午市高峰期，订单积压了四十多张，老板急得在后厨门口跳脚。小胖正在切一把干辣椒，切着切着忽然觉得手指尖烫了一下——他以为是被辣椒辣到了，没在意。然后他放辣椒的铁盘子开始冒烟了。然后辣椒着了。不是燃气的火，是某种更蓝的、更安静的火焰——从他的指尖窜进了盘子里，把那一把干辣椒变成了一团小火球。

小胖当时的第一反应是抄起锅盖把火盖了。

然后他看着自己的手指。指腹上有一层极淡的红色光晕，像把手放在灯泡前面透过来的那种红。他试着把手指靠近一碗水——水没开，但水面冒起了热气。

"小胖！你他妈在看啥！灶好了没有！"老板在门口吼。

小胖把手指收回来，继续切菜。

当天晚上回到家，他在出租屋的小厨房里又试了一次。把手指伸向一只鸡蛋。鸡蛋壳上缓缓渗出细密的水珠，然后蛋清从透明变白——熟了。不是被火烤的，是被他指尖的温度烫熟的。

他坐在厨房地上，看着那只被"指尖煎熟"的鸡蛋，脑子里一片空白。

火系灵根。他后来去灵管局的测试站做了检测——结果是中品火系，亲和度B级。不算天才，但足够修行。

可是小胖不想打架。

他想做饭。

他的修炼方式很特别——不练攻击灵术，不练防御阵法，不练任何跟战斗有关的东西。他用火系灵气来加热油锅，用来控制火候，用来让一道回锅肉的肉片在不粘锅里达到完美的173度——蒜苗断生而不烂的理想温度。

川菜馆的生意因此好了很多。老板不知道原因，只知道小胖帮忙打下手的时候，出菜的品质会明显上升。客人们说最近的回锅肉特别香，"锅气"特别足。老板给客人解释:"我们换了新锅。"实际上没换。是小胖的手。

但小胖不满足。他的梦想不是当一辈子帮厨。

他想炼丹。

炼丹这个念头是他在城中村筒子楼里住下来之后才有的。他听龟相讲过万年前炼丹的盛况——炼丹炉旁边站着的都是火系修士，炉火不是木柴烧的，是修士用本命灵火牵引地脉火精，温度可以精确到每一个呼吸的波动。炼出来的丹药有的能让人修为暴涨，有的能起死回生，有的能改变一个人的灵根品质。

小胖听完之后沉默了一整个晚上。

第二天早上他问龟相:"龟爷，您会炼丹吗？"

龟相慢悠悠地从壳里伸出头，看了他一眼。"老朽不会。但老朽见过。万年前有一个叫丹阳子的老家伙，炼丹炼了三千年。他炼的丹，一颗能让凡人百年不老。老朽看过他炼丹——看了三百年。流程老朽记得。"

"能教我吗？"

"你没有炼丹炉。"

"我可以买。"

"你没有丹方。"

"您记得吗？"

龟相沉默了一下。"最简单的益气丹——老朽记得。只需要三种灵材:灵参、地脉水、火晶石。外加一种药引——炼制者的一滴血。"

"我能做。"

"你没有炼丹炉。"龟相重复了一遍。

小胖笑了。

第二天晚上，筒子楼一楼最里间的屋子里，摆上了一只高压锅。

不是药店卖的那种陶瓷炼丹炉。是一只超市买的高压锅——双喜牌的，原价299，打折的时候249买的。锅体是不锈钢的，锅盖上带安全阀和压力表。小胖花了三个晚上把锅盖拆开，在密封圈的位置加了一圈自己用火系灵气烧制的灵泥垫圈，又在安全阀的排气孔里嵌了一颗绿豆大的下品灵石碎片。

"这不是高压锅了。"小胖端着自己的改装作品，郑重其事地对龟相说，"这叫灵压锅。"

龟相看了那只锅很久。

"万年前要是有人拿这个炼丹——丹阳子会气活过来。"

"那他能活吗？"

"不能。他会气死第二回。"

小胖不管。他把"灵压锅"架在燃气灶上，打开手机手电筒当工作灯，面前摆了三个小碗——一个碗里是三片从老马那儿借来的灵参须，一个碗里是半瓶地脉水（许冰从她调查的某个非法灵材窝点缴获的，没收之后分了他一点），还有一个碗里是三颗米粒大的火晶石碎片。

龟相趴在旁边的椅子上。它的龟壳在灯光下反射着古铜色的光泽，四条腿缩在壳里，只露出一个脑袋和半截脖子。

"火候第一。"龟相说，"灵火不是灶火。灶火只要热就行。灵火要分阶段——先文后武再文。文火提纯，武火融合，末段再回文火定型。三者顺序不可乱。"

"文火是多少度？"

"不是温度。是灵火注入的速率。你的火系灵气每秒钟注入的量——每秒钟大约零点三灵素，这就是文火。武火是一秒三灵素。末段文火是零点一灵素。"

小胖从兜里掏出一个小本子。本子上密密麻麻地记着各种数据——食材重量、火候时间、调味比例。这是他当帮厨时养成的习惯。现在他把本子翻到崭新的一页，第一行写下了"炼丹笔记——见习第一炉"。

他深吸了一口气，打开燃气灶。蓝色的灶火嘭地一声燃起来。高压锅稳稳地坐在火上。然后他把右手悬在灶火上方的五厘米处——他不用灶火烧锅。灶火只是为了引导方向。真正的热源是他的手。

他控制着火系灵气从掌心输出。一丝极细的、淡蓝色的灵火从他的掌纹中渗出，穿过灶火的蓝色火焰，均匀地包裹住了高压锅的锅底。

第一步:预热灵压锅。文火，三分钟。

他用小本子记录:"预热完成。锅壁温度手感约80摄氏度。灵泥垫圈开始膨胀，密封良好。"

第二步:加入地脉水。继续文火。水在灵压环境中不会沸腾，但会缓慢汽化——锅内的灵气浓度开始上升。

第三步:加入灵参须。武火——一秒三灵素。高压锅的压力表跳起来了。指针从绿色区域跳进了黄色区域。安全阀里的灵石碎片发出了一声极轻微的嗡鸣。锅内的灵参在地脉水的浸润和灵压的催逼下开始分解。那些细如发丝的人参须在锅里融成了一滩淡金色的液体。

第四步:投入火晶石碎片。继续武火。火晶石在灵压和高温下开始熔化——它的熔点极高，普通灶火烧三天也烧不化。但在灵火的包裹下，三颗火晶石碎片在四十秒内变成了三滴流动的赤红色液体。液体在锅里和参液融合，颜色从淡金变成了深橙。

"就是现在。"龟相压低了声音，"把火降到零点一灵素。最后一步——往锅里滴一滴你的血。"

小胖用针扎了一下左手中指。一滴血落进高压锅的安全阀口，沿着灵石碎片滑进了锅内的混合液中。

锅盖忽然震了一下。

不是爆炸——是收。整锅液体在血滴入的瞬间急速收缩，所有的灵气像被抽进了同一个中心点。压力表的指针猛地从黄色区域跳回了绿色，然后又跳回了白色——压力归零了。

小胖关了火。

锅里的蒸汽从安全阀中丝丝地泄出来。没有颜色，但带有一股极奇特的香味——不是厨房里任何一种调料的味道。那味道很淡，却会往骨子里钻。小胖闻了一口，觉得全身的疲劳一扫而空——他今天切了将近三百斤菜，肩膀和手腕本来酸得要命，现在都不酸了。

"开锅。"龟相说。它的脖子伸得比任何时候都长。

小胖把高压锅的安全阀拧开，等了一分钟让余压排尽。然后他拧开锅盖。

锅里躺着一颗丹。

准确地说，是一颗形状像烧焦的肉丸的东西。表面不圆——有几处凹陷，还有一处凸起像个没削掉的蒂。颜色是深褐偏黑的，中间夹杂着几道赤红色的纹路。大小大概和一颗四喜丸子差不多。它静静地躺在高压锅的不锈钢底上，还冒着一点点热气。

小胖看着它，没说话。

锅底的这颗东西，和他在玄幻小说里看到的"晶莹剔透""仙气四溢""宝光冲天"的仙丹——完全不沾边。它更像是一颗失败的红烧狮子头。

但他感应到了——那颗"肉丸"内部有一团正在缓慢旋转的灵气。不是死的一团灵力，是活的。它在自己运转，像一个微型的灵气漩涡。

龟相盯着那颗丹药看了很久。然后说了一句话。

"是益气丹。"

"就这样？"

"就这样。"龟相的声音变得有点奇怪——不是激动，不是失望，是一种说不清的东西，"万年前丹阳子炼的第一炉益气丹，老朽也见过。他那颗比你这个还难看。但你这一颗的品质——同样火候、同样材料的条件下——不比他差。甚至灵气的内循环稳定性比他第一炉高了一点点。"

小胖把丹药从锅里夹出来，放在盘子里。丹药在盘子里滚了一下，停了。然后他拿出手机，拍了一张照片。拍完又拍了一张。然后又拍了一张。他拍了十几张。

"你干什么？"龟相问。

"留着。"

"留什么？"

"证明。证明一个帮厨——没有玄门传承，没有师门指点，没有正经炼丹炉——用一口高压锅炼出了第一颗仙丹。"

龟相沉默了。

小胖把照片发到了草根天团的群里。然后他拿起手机，退出群聊界面。通讯录往上翻，翻到"妈"。电话拨了过去。

响了六声。他妈接的。

"满仓？这么晚了打电话——"

"妈。"小胖说，"你儿子是炼丹师了。"

电话里安静了五秒。

"妈没听懂。什么叫——"

"我炼了一颗丹。一颗真的丹。益气丹。吃一颗能让人一天不累的那种。妈，你听我说——你之前膝盖不好，上下楼疼。等我再炼几颗，我给你寄回去。你吃了就不疼了。"

他妈又沉默了。

小胖以为信号断了，把手机拿下来看看——还在通话中。

然后他听见他妈的声音——带着鼻音，但也在笑:"满仓，你是厨子了你不是一直想掌勺吗你啥时候当道士了——"

"不是道士。是炼丹师。妈，是炼丹师。"

他挂掉电话，把高压锅搬到水槽里冲洗。洗完之后他把锅擦干，搬回灶台上放好。然后他拿起本子，翻到"炼丹笔记"那一页，在第一次记录底下写了一行字:

"第一炉:益气丹。工具:双喜高压锅(改装型)。成功率:一颗。品质:待检测。结论:灵压锅可行。"

他合上本子，看了一眼窗外。深夜的城中村里，筒子楼的窗户大多暗着。三楼的楚知寒那间窗里还亮着灯。一楼的走廊尽头，有个人影在黑暗中走动——大概是老陈收工回来了。

小胖在厨房里站了一会儿。灶台上的双喜高压锅安静地搁在那里。锅盖上的灵石碎片在黑暗中泛着微弱的幽光。

他想起他妈说过的一句话。

他妈当年送他去学厨师的时候，跟他说了一句话:"满仓，人这一辈子不管干啥，把手艺学精了。手艺是自己的，谁也抢不走。"

他现在有了自己的手艺。不是切菜，不是炒勺。

是炼丹。

他走到锅前，伸手在锅盖上轻轻拍了拍。

"谢谢。"

然后关灯。出门。走廊里飘着一股极淡的、混合着灵参和火晶石的香气。

（第199章完）

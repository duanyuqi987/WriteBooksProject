# 第152章 天池结冰，冰下有上古遗物

当天夜里，李长生在池边的观测台上等到了管理员说的"人影"。

准确地说，不是等到了——是感觉到了。夜里十一点四十分，天池上方的灵气浓度突然开始上升。上升的速度极快——从正常水平到峰值只用了不到三十秒。小王手里的便携检测仪发出连续的报警声，屏幕上的数值曲线像被筷子戳了一下，直直地往上跳。

然后湖面开始发光。

不是从水面反射出来的月光——今晚没有月亮。是水底在发光。幽蓝色的光从湖心最深处渗透上来，穿过一百多米深的水层，在湖面上映出一片模糊的光晕。光晕的形状不是圆形——是一个正在缓慢转动的漩涡图案。

"就是它。"管理员不知什么时候站到了他们身后。他穿着棉大衣，手里端着一个保温杯，手指在杯子上攥得发白，"每天晚上十一点半准时出现，持续大概四十分钟。你们看——人出来了。"

李长生的目光从漩涡图案上移开，落到了湖面中央。

人影出现了。

那是十几个半透明的、泛着淡蓝色光华的人形轮廓。它们悬浮在水面上方约半米的位置，排成两列，缓慢地朝湖心移动。它们的动作极其迟缓，像电影放了慢速镜头。每一个身上都穿着类似古代长袍的衣装——衣服的材质和花纹已经模糊得无法辨认，但那道宽大的袖口和拖地的衣摆，还有腰间系着的某种令牌形的配饰，都说明它们不是现代的产物。

"万年前天池祭坛的护坛修士。"老马蹲在地上，手掌贴着地面，土系灵力已经探测到了池底的更多细节，"湖底的地层里有大量人类遗留的灵力痕迹——不是一个两个人，可能是一个完整的宗门。这些残影是他们临死前最后的行为——在祭坛被某种力量摧毁的时候，他们在最后一刻还在执行守护动作。"

"也就是说——"小王盯着湖水，"这些已经死了一万年的人，每晚都在重复他们死前做的最后一件事？"

老马没回答。但不需要回答。

万年执念。一万年前天池祭坛遭遇灭顶之灾的时候，这些守坛修士在最后一刻选择了履行职责——不是逃跑，不是求饶，而是守在岗位上直到死亡。他们的肉身早就化为了水底的淤泥，但他们的执念留了下来——被天池底部的灵脉滋养了一万年，化作了这道夜夜重复永不消逝的幻影。

李长生站在观测台上，静静地看着那道队伍走完了全程。

这让他想起了在大漠里看到的冥王记忆——那个黑甲男人面对数十个神明布下的杀阵，从头到尾没有跪。一万年过去了，守坛的执念还在重复着同一套仪式，冥王的意识还残留在他身上三块碎片里等着来人的出现。

有些东西，死不了。

队伍的末端最后一个人影也沉入湖心之后，蓝色的光开始消退。但就在光完全消失之前——天池的水面开始结冰了。

不是冬天自然结冰。是从湖心开始往外扩散——圆心处先浮现出一层薄冰，然后飞速向四周蔓延。冰层的颜色不是常见的白色——是透明到几乎看不见的极薄冰晶，只有一道极细的银色闪光标记着冰面扩展的边界。从湖心到整个湖面，整个过程只持续了七秒。

七秒钟。一个面积将近十平方公里的高山湖泊，在盛夏的夜里，在水温超过十五度的情况下——完全封冻。

陈霜的剑在剑鞘里轻轻震动了一下——冰系灵气的剧变引起了剑身的共鸣。

"这不是自然现象。"小王的声音压得很低，但能听出紧张，"湖水的温度监测还在十五度，但表层的水分子结构被重新排列了——这不是降温结冰，是灵力强制改变了水的物理状态。能在一瞬间封冻十平方公里水域的灵力——"

"至少是玄师巅峰级。"陈霜说。

"不。"李长生摇头，他的目光穿透了透明的冰层，看到了水下的东西，"是万年前留下的阵法的残余力量。阵法感应到了我们的存在——它在做防御准备。看。"

他指向冰面之下。

透明的冰层像一块巨大的玻璃，把水下的世界暴露无遗。在冰面的下方，在湖水深处，隐约可以看到建筑的轮廓——不是一两根柱子，而是一整片建筑群。飞檐的顶角、石阶的层级、殿宇的框架——虽然被万年水蚀磨损了棱角，但整体结构清晰可辨。

一座万年前的上古仙门遗迹，完整地沉睡在天池的底部。

老马的手在发抖——不是害怕，是作为一个地质工程师的本能兴奋。"天池底部的地层结构是双层夹心式的——上层是火山岩，下层是人工夯实的基座。基座的厚度至少有十五米，材质不是天然岩石——是某种灵力固化的复合材料。这个工程规模——如果把整个祭坛和旁边的附属殿宇算上——至少相当于在二百米水下建了一座小型的紫禁城。"

"一万年前的人怎么做到的？"小胖问。

"一万年前地球是修仙文明的中心。"李长生蹲下身，把手贴在冰面上，掌心五道冥纹的温度透过冰层往下探，"那时候的人类文明和现在完全不同——不是用机械和工程建宫殿，是用灵力和阵法塑造物质。只要有足够强的灵力和足够高深的阵法，在湖底建一座城是可行的。"

他停顿了一下。

"更何况，这座城不是普通的修仙者建的——是冥王。"

冰面之下，在那些古建筑的中央，隐约可以看到一个圆形的巨大平台。平台上刻满了密集的纹路，纹路之间嵌着某种黑色的石材。即便隔着上百米深的水层，李长生也能感觉到那个平台上残留的灵力——阴冷、深邃，和掌心的冥纹在本质上完全同源。

"那就是祭坛核心。"他站起来，"第五块碎片——就在祭坛的正中央。"

老陈问:"怎么下去？"

"等。"李长生看了一眼时间——凌晨零点十二分，"天亮之后阵法残余力量会消退。冰会自动融化。到时候——"

他的话没有说完。天池四周的山林里，传来了一种不该在深夜出现的声音——脚步声。很多人的脚步声。训练有素的、快速移动的、正在包围整个天池的脚步声。

陈霜的剑已经出鞘了三寸。剑刃在冰面反射的微光中泛着冷白。

"有人来了。"她说。

"不是有人。"小王盯着笔记本屏幕上的灵气监测界面——屏幕一角出现了十几个快速移动的红点，正从东北方向逼近天池，"是有一支完整的修士队伍。灵力等级——最低灵者级，至少两个玄师级。"

红点继续逼近。最近的一个，已经进入了天池景区北侧的山林边缘。

"不是中国人。"小王忽然说，"灵气频率不匹配——国内登记在册的所有修士的灵气频率特征我都备案了，没有匹配项。"

天池的冰面上反射着一轮看不见的月亮。夜风吹过，带动冰层表面一层细碎的气雾。

李长生转过身，面对着黑暗的山林。掌心的冥纹开始缓缓亮起。

"白头山的。"

（第152章完）

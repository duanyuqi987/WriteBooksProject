# 第114章 玄门七宗联合声讨：冥术是邪道

联合声明的全文一共三千七百字，发在国家灵能监测管理局的官方平台上——不是以灵管局的名义，而是灵管局"转载"了这份声明。

措辞极为严厉。

声明开头先承认了李长生在医院使用灵气治愈绝症患者的"事实"——这一点躲不过，视频已经满天飞了。然后话锋一转，开始阐述冥术的本质。

"冥系灵气，本质为死气。以死气入生体，虽暂见好转，实则埋下更深远的隐患。死气侵入经脉后，将缓慢腐蚀患者自身的生命本源。短期内的好转，是死气置换生命力的假象——相当于将患者的余生压缩到几个月内耗尽。此非治人，乃杀人于无形。"

接下来是引用古籍。声明中列举了七部修士典籍中关于冥术的记载，每一段引文都用文言文写成，翻译附在后面。大意都差不多：冥术源于死道，生者不修，修者不祥。用冥术治病，是以毒为药、以死为生。

然后是对李长生的定性。

"李长生，冥系灵根持有者，灵者级巅峰。其人以冥术入医，未经任何灵医资质认证，未经任何灵气安全评估，擅自对危重病人施术。此举不仅违背国家灵能管理法规，更严重威胁了受术者的生命安全。本院（玄门七宗联合议院）要求：

一、国家立即禁止冥术在医疗领域的任何应用。

二、将李长生列为高危灵能使用者，依法通缉。

三、对已接受冥术治疗的七名患者进行强制医学审查，防止死气残留对患者造成不可逆伤害。

四、成立专门委员会，对所有冥系修士进行风险评估与管控。"

最后一段是针对李长生的个人攻击。

"此人出身农民，未受正规修行教育，对灵气本质缺乏基本认知。其手中持有冥器碎片，系上古邪器残骸。此碎片会持续侵蚀持有者的心智——古籍有载：持冥器者，终将堕入邪道。李长生今日以冥术治病博取民心，不过是为日后更大的危害铺路。望全国修士与民众明辨是非，勿被表面善行蒙蔽。"

落款是玄门七宗联合议院，盖了七宗的灵气印记。

小王把声明从头到尾读了两遍。

"他们每一句话都是真的。"他说，声音里带着一种奇怪的情绪——不是愤怒，是某种冷静的敬意，"每一句话拆开来看，都有道理。引用的古籍是真的。冥术会侵蚀持有者心智——这一点残魂老前辈亲口说过。死气对生机有腐蚀作用——这也是事实。"

"但他们组合起来是假的。"陈霜站在窗边。她穿着一件白色的衬衫，腰间挂着那柄祖传的青锋剑。剑身隐在鞘中，但她手指一直按在剑格上——这是她的习惯，紧张的时候会按住剑格。

"把真话组合成假结论，比说谎更危险。"她说。

小王点头。"他们用了三段式：事实一——冥术确实用的是死气；事实二——古籍确实说冥术是邪道；事实三——李哥确实没有灵医资质。这三个事实摆在一起，推导出来的结论就是'李长生是邪道'。但推理链中间缺了一环——他们故意没提冥术可以转化死气这个核心机制。"

"不是故意没提。"李长生开口了。他一直坐在沙发上，手里攥着一杯凉了的花茶。从声明发出来到现在，他始终在看评论。不是看骂他的——是看普通人怎么理解这件事。

"玄门七宗里真正懂冥术的人，不超过三个。"他说，"其他人不是故意不提——是他们真的不知道。冥术在万年前的冥王陨落后就没有传承了。古籍里记载的都是'冥术凶险，以死气伤人'之类的话。他们是按照他们知道的在说。"

"所以他们的指控是出于无知？"陈霜皱眉。

"不完全是。"李长生放下茶杯，"七宗中的第三宗——专精医道那一宗——他们知道。或者说，有人知道。但知道了也要说'不知道'。因为冥术一旦被承认可以治病，他们的医道地位就受到了威胁。"

陈霜的手指从剑格上松开了。"所以他们不是无知，是利益。"

"是权力。"老陈说话了。快递员老陈一直坐在角落里，手里捻着一根烟但没点——屋里禁烟。他今天穿的不是快递制服，是一件洗旧了的卫衣。衣领上沾着一点灰，是刚才搬东西弄的。

"我送快递送了二十年。"老陈说，"见过最多的不是穷。是欺负人。快递公司欺负员工，小区物业欺负快递员，平台欺负商家。这些欺负，说到底不是靠'无知'——是靠'话术'。用一些听起来很有道理的话，把一个明明是在欺负人的方案包装成一个合理的方案。这个声明，不就是同一种东西吗？"

房间里安静了几秒。

"李哥。"小王打破沉默，"我们得回应。"

"怎么回？"

"他们发了三千七百字。"小王说，"我们也发一篇。不是对骂。是说明。把冥术治病的原理讲清楚——死气可以转化为生气。这一条说明白了，他们的整个逻辑链就断了。"

"你写？"

"我写了你审。"

小王打开电脑。他打字的速度像一个在deadline前赶进度的程序员——快、准、不带任何多余字符。二十分钟，一篇一千二百字的文章出炉了。标题是《关于冥术治病原理的说明》。

文章没有反驳任何人。没有提到"玄门七宗"，没有使用"造谣""污蔑""恶意中伤"这类词。它只是一步一步解释：冥气的本质是什么，死气与生气的转换原理，他在医院操作的具体流程，以及——最关键的一条——他愿意接受独立第三方的医学验证。任何机构，任何时间，来检查七位病人的身体。如果检查发现死气残留对病人有害，他愿意承担一切法律责任。

"把最后一句删了。"李长生看完后说。

"为什么？这是最有说服力的一句。表明了态度。"

"态度已经表明了。'承担法律责任'不是态度，是示弱。我不是法外之徒，但我也不需要用这句话来证明自己。他们如果真想查，有没有这句话都会查。他们如果不想查，写一百遍也没用。"

小王想了想，把最后一句删了。

文章发出去以后，第一个转发的不是草根修士圈的任何人。是林晓。

林晓用自己的微博转发了——她的账号认证是省人民医院针灸科主管护师。她只加了一句话："我在现场。我看了七台生命监护仪的数据。我作证。"

三个字——"我作证"——比小王写的一千二百字都重。

转发量开始飙升。

玄门七宗沉默了大约六个小时。然后他们的反应用了一种更聪明的策略——不回应李长生的说明，而是发表了一份第二声明。这次更短，只有一百多字：

"本院注意到网上出现了关于冥术治病原理的所谓'说明'。本院重申：冥术本质为死气，不应用于活人治疗。此非辩论，是医学伦理原则。死气入体即构成医疗伤害，无论其短期效果如何。所谓'独立验证'无法改变这一原则性认定。建议李长生立即停止一切灵医行为，主动前往灵管局接受审查。"

"原则性认定。"小王看着这五个字，冷笑了一声，"他们在讲原则。"

"原则永远站在有权定义原则的人那边。"陈霜说。

李长生没有说话。他在想一件事。玄门七宗的策略很明确——不讨论事实，只谈原则。因为事实越辩越明，但原则不需要辩论，只需要站队。他们把讨论从"冥术能不能治病"变成了"要不要允许死气入体"——前者需要科学验证，后者只需要道德判断。

道德判断是最难反驳的。因为没有人想站在"支持死气入体"这一边。

他必须改变战场。

不是在论坛上、微博上、灵能平台上争论——这些地方最终都会被玄门七宗的"原则论"占据制高点。他需要一个更大的平台。一个能让所有人同时听见他说话的平台。

他拿起手机，拨了一个号码。

电话响了三声。

"刘队。"他说，"我需要一场直播。国家电视台的。"

电话那头沉默了五秒。然后刘大校的声音传过来，低沉、谨慎，但没有任何意外——好像他一直在等这个电话。

"你知道这意味着什么吗？"刘大校问。

"知道。意味着我不会再有任何退路。"

"不。"刘大校说，"意味着你一旦上了直播，就不再是那个'在医院里做了七件好事的神秘人'。你会变成一个公众人物。公众人物做得再好，也会有人骂。你说的每一句话都会被放大，被切割，被重新解释。你准备好承受这些了吗？"

李长生握着手机，想起了父亲的话——"泥碎了还是泥。"

"准备好了。"他说。

"明天下午四点。我给你四十五分钟。"

（第114章完）

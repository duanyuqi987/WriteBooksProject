# 第151章 长白山之行，天池异象

长白山的轮廓在天际线上浮现的时候，李长生正在大巴车的最后一排打坐。

车窗外的景色已经从华北平原的玉米地换成了连绵起伏的山林。这里的山和西北的大漠完全不同——大漠是死的，每一粒沙子都在告诉你什么叫荒凉。长白山是活的——山腰以上的原始森林像一片墨绿色的海，树冠层叠着树冠，风一吹就翻出不同的颜色。

李长生睁开眼的时候，正好看见天池的第一道轮廓从两座山峰之间露出来。那是海拔两千多米的一个火山口湖，湖面在阳光下蓝得不真实——不是普通湖水的灰蓝或者碧绿，而是一种接近宝石的幽蓝，像是有人把整个天空的蓝色都榨了出来，倒进了这口火山的旧伤口里。

"到了。"

坐在他旁边的陈霜也睁开了眼。她的剑横放在膝盖上，剑鞘上凝了一层薄薄的水珠——越靠近天池，空气中的水灵气浓度就越高，剑鞘上的水珠就是灵气凝结的结果。

大巴在景区停车场停稳。车上下来了九个人——李长生、陈霜、小王、老陈、刀疤、老马、许冰、小胖、护士林晓。加上留守在城里的龟相，正好十人。这是他们从蓬莱回来后第一次全员出动。

蓬莱那一战让队伍从五个人扩到了十个人。地质工程师老马是那一战里最大的收获——他的土系能力在海底遗址的勘探中发挥了关键作用，如果不是他用土系阵法稳住了海底的地基，整座蓬莱遗址可能已经在取走第四块碎片时塌了。打完那一仗之后，老马辞了地质队的工作，正式加入了队伍。

许冰是在蓬莱回来之后才加入的。她是律师，也是阵法天才。小王在监测网上发现了她的异常灵气频率——她在法庭上辩护的时候，无意识地释放了一种能影响人心的灵压。李长生找她谈了一次，她说她干律师不是为了钱，是因为她喜欢"把不公平的事掰回来"。李长生说，那正好，我们也在掰一件非常不公平的事。她考虑了一天，第二天提着一箱案卷搬进了筒子楼。

"人齐了，往上看。"小王把笔记本合上——他现在已经不用那台拼装的旧设备了，换了台新的轻薄本，核心芯片是用灵石碎片改装的，电池续航从六个小时变成了六十个小时，"天池附近的灵气数据有点奇怪。"

"怎么个奇怪法？"

"你自己看。"小王把屏幕转过来。屏幕上是一张天池区域的灵气热力图，池心位置有一个明显的高亮区域——不是普通的灵气浓度偏高，而是一个几乎完美的正圆形，边缘锐利得像用圆规画出来的。

"自然形成的灵气聚集区不可能是正圆形。"小王用手指在屏幕上画了一道线，"还有一件事——今天早上七点开始，湖底的灵气波动频率出现了规律性变化。每十八分钟一个循环。上升，下降，再上升。像是——"

"像是呼吸。"李长生替他说完了。

小王看了他一眼，没说话。

李长生已经学会了一件事:在灵气复苏的世界里，"自然现象"这个词已经不适用了。任何反常的现象背后，一定有一个根源。天池底下的这个"呼吸"，不出意外，就是第五块碎片的守护机制——和前四块碎片一样，每一块沉睡的碎片都会在灵气复苏的过程中被激活，散发异常信号，吸引能找到它的那个人。

"先上去看看，不要下水。"李长生提起背包，带头走向景区入口。

天池的游客比想象中多。虽然不是节假日，但景区里依然有不少人——有背着单反的中年摄影团，在观景台上摆各种姿势；有带着孩子的家长，在湖边的栈道上拍照；还有几个写生的美院学生，对着湖面画水彩。没有人知道这个湖底正在发生什么。他们看到的只是——今天的天池特别蓝。

但李长生能看到更多。

他站在离湖边大约二十米的位置，用冥气感知探下去。冥气的触感顺着土壤和水层往下延伸——十米、二十米、五十米、一百米。在大概一百二十米的深度，他的感知被什么东西挡住了。不是水面那种物理层面的反作用力——是一种灵力层面的排斥。水底的某个位置有一层看不见的屏障，把他的感知弹了回来。

"下面是空的。"他收回感知，对身后的队友说。

"空的是什么意思？"老陈挠了挠头。

"意思是天池底下不是石头——是人工建造的空间。和蓬莱遗址一样的结构。"老马蹲下身，把手按在地上。他的手指插进泥土里，土系灵力顺着地层横向延伸。几分钟后，他抬起头，脸色凝重，"这个规模不比蓬莱小。天池整个湖底下面——至少三分之一的范围——是空心的。"

"一座湖底的城市？"小胖瞪大了眼睛。

"祭坛。"李长生说。龟相给他的情报里提到过——万年前长白山是仙门的一处圣地，天池不是火山湖，而是仙门为了镇压一条大型灵脉而人工挖掘的灵池。池底建有一座祭坛，用于稳定灵脉。第四块碎片在海眼，第五块——在祭坛的核心。

他把这个信息告诉了队友。所有人沉默了一瞬。

"那就下——"刀疤还没说完，一个声音打断了他们。

"几位客人，看你们在这儿站了半天了——"一个穿着景区工作服的中年男人走过来。他大概五十岁上下，皮肤被山风吹得粗糙发红，袖子上别着"天池管理员"的臂章。他看了眼李长生这几个人——九个人，背着各种包，有两个女的，还有个提剑的——脸上的表情从不耐烦变成了困惑。

"你们不是来旅游的吧？"

"我们是地质勘探队。"老马立刻接上了话，从口袋里掏出一本证件——那是他在地质队时的工作证，虽然已经辞职了，但证还没过期，"例行考察。长白山地质结构普查。"

管理员看了一眼证件，将信将疑。"地质勘探？这个季节？"

"赶项目进度。"老马把证件收起来，语气很自然。

管理员没再追问证件的事。但他接下来说的话，让所有人都安静了下来。

"不管你们是干什么的，我跟你们说个事——"他压低声音，"最近天池不太对劲。从上周开始，夜里湖面上会出现人影。"

"人影？"

"发光的人影。就在湖中央，水面上面飘着。不是水里的倒影——是在水面上面几尺高，飘着一行一行的人。穿着古时候的衣服。有几个值夜班的保安用手机拍到了——但拍出来的照片上什么都没有。不是手机坏了，是那个人影在照片上可以显形，但在肉眼看来就是一团模糊的光。"

管理员说到这里，自己先打了个寒战。

"我们这儿的老人都说，天池里头封着东西。几十年前有一回大旱，池水退了十几米，有人看见水底下露出过几根柱子——不是木头，是石头的，柱子上刻着不认识的古字。后来水又涨上来了，没人再见过。但最近这一周，那些东西好像——不安稳。"

他看了一眼湖面。今天的湖面很平静，几乎没有波纹。

"你们要是搞勘探的——别晚上来。晚上这地方不是人待的。"

说完他就走了。背影消失在栈道拐角处。

李长生回头看了一眼天池的水面。阳光正打在湖中央，水面上泛起一层金光。但在那片金光之下，在肉眼看不见的深处，有什么东西正在缓慢地从万年的沉睡中苏醒过来。

"夜里来。"他说，"等他说的那些人影出现——那可能是祭坛守卫的残像。顺着它，就能找到祭坛的真正入口。"

陈霜站在他旁边，手不自觉地搭上了腰间的剑柄。

"你的人影——是活的还是死的？"

"都不是。"李长生望着湖面，"是万年前被封印在池底的那些修仙者——他们的执念。和蓬莱遗址里那些尸骸一样——死了，但没走。"

山风从峰顶刮下来，吹皱了天池的碧蓝水面。在那道被风撕开的波纹之下，一团幽蓝色的光正从水底缓缓升上来。没有人看到它。但李长生掌心的五道冥纹——同时亮了一下。

第五块碎片，就在这里。

（第151章完）

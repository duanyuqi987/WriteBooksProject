# 第四百八十七章 迎仙台日常

回上界之后松鹤仙人把一份新差事交给了两个人——协助管理迎仙台的日常运转。迎仙台虽然是仙界最边缘最不起眼的一处小门，但它负责着每对新飞仙到达上界最初一段时间的全部接待和引导。之前这项工作全靠松鹤仙人一个人撑着——登记、安排住处、教授基本仙功、带新飞仙熟悉五轮太阳的日夜交替规律。八千年下来他累得够呛。现在多了林牧苏晚两个人分担，他的老腿终于可以翘到石凳上去了。

迎仙台最近没有新飞仙——近三千年就林牧和苏晚这一对。所以日常主要工作是维护设备。维护的设备包括迎仙台门口那面"迎仙碑"——碑上的名字需要定期用灵气擦亮。擦碑的活儿苏晚做得很认真。她第一次擦碑时发现碑上刻着的三十余对道侣的名字中有一列极小的字备注了一句话——"红绳未断"。说明这对道侣在仙界中仍然活着、仍然在一起。而另外几对名字后的备注是空白的——空白意味着他们后来解开了红绳，分道扬镳。苏晚把"红绳未断"四个字反复擦了三遍——擦得比其它任何字都亮。

林牧的日常是修飞仙舟。迎仙台有三艘小型飞仙舟——用以上下界往来接送预约好的准飞仙。这些飞仙舟有年头了，外壳上的仙木已经开裂，内部的空间压缩阵法也需要定期校准。他蹲在飞仙舟旁检查阵法内核的时候手里拿着苏晚给他的一份自制的检修清单——不是仙宫配发的正式操作手册，而是她根据自己观察整理的。"第三舟的内部空间压缩率偏低——可能在十二重常规密度以上的传输过程中有轻微缩减——建议校准。第二舟左侧外壳仙木已出现四道纵裂——建议在雨季前打蜡。"

林牧一一对照她的清单检修。他蹲在飞仙舟旁边，旁边摆了工具和蜡罐，像个在修自行车的普通人。这画面如果被青云宗以前那些认识他的老对手看到——大约会揉眼睛。但是林牧不在乎。他觉得修飞仙舟和修仙没有什么区别——都是把一件东西维持到它尽可能长久、运行到它尽可能可靠。以前他修炼是为了变得更强，现在他修飞仙舟是为了让下一对道侣能安全地飞上来。

下午的时候松鹤老人提了一壶自酿的青梅酒过来。酒壶很旧了，壶口边缘有他八千年来啃出来的齿痕。他在石凳上倒了两杯酒，一杯给林牧，一杯给苏晚。他自己拿着壶直接喝——喝完擦了擦嘴。说了一句话："早知道你们两个来了之后会把迎仙台收拾得这么利索，我四千年前就应该去下界把你们提前扯上来。"苏晚喝了酒后咳了一下——酒很烈，带着极浓的青梅味和一点点仙界特有的甜。松鹤仙人看到她咳嗽笑出了声。然后林牧在旁边接了一句。"你要是四千年前就去，我们大概还没有第一世。"

松鹤老人愣住了，然后忽然又乐了——他捋着胡子点了点头。仙界就是这样，时间线太复杂了。笑就好。

（第四百八十七章 完）

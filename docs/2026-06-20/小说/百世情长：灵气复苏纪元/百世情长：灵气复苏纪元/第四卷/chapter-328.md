# 第三百二十八章 和平时期的修炼

战后第一年。昆仑裂缝被正式封印。距昆仑主峰三十里处立起了一座"镇魔塔"——不是监狱，而是一处监测空间法则波动的观测站。由蜀山、茅山和药王谷三派共同派驻修士轮值。塔顶立着一块和林牧当初捡到的那块符石材质相似的大石碑——但经过处理后不再被暗紫色光渗透，而是散发着淡淡的金色。金色来源于苏晚的主印本源的残留——她在封印封口时滴入七滴自己的精血，混在封印基底中。此后只要有上界级别的天魔法则波动靠近昆仑，塔顶的金光会提前好几天预警。

她这样做的时候没有想太多。只是觉得——自己是主印，这样合理。但赵明远后来说她做了修仙界万年历史上从未有过的事："用真仙级的灵魂本源来做法则防火墙。"

苏晚说："这个叫预防性处置。医生常做——打疫苗。"

赵明远不再尝试用修道术语去比喻她的医学理解了。因为他发现她的比喻永远比修道的更准确。

这一年里，林牧的身体终于恢复到能重新凝成灵核。他从淬体境界重新修炼上来——每天上午在蜀山后山的灵泉旁练吐纳术。苏晚若没有去节点净化的任务，就会在旁边陪他打坐。但她坐不住——坐久了就会想喝水或者想跟锦鲤说话。锦鲤被她养得长了半寸。

她现在是金丹巅峰——距离元婴只差一步。并不是她自己主动冲击的——是灵魂深处封印的自然释放。封印每隔几个月会松开一小截——每松一次她的修为就涨一小级。照这个趋势，她大约再过半年就能突破元婴。

她偶尔把流光剑指向林牧的灵脉——用自己多余的本源通过剑尖渗进他经脉里。这种"回传"的效果比药王谷的太上灵丹还彻底——但来源是她每次解封中多出来的一些富余本源。她解封的百分之四十里大概有百分之五是多余形成的"气泡"——把它挤到副印那端去，就是给他补充灵魂度缺失。

这个过程并不疼痛。林牧只是每次滴入之后会睡得特别沉——像是身体终于找到可以关机维护的状态。

他闭眼睡着的时候苏晚就坐在床边。拿那本旧剑谱挡着窗外的光线——不是怕他睡不着觉，是蜀山下午的阳光有点晒。她给他挡了几个月的阳光，自己右前臂上被晒出了好几个斑。

有一天赵明远进来看她拿着剑谱的手背已经晒得很红了——说："苏小姐，你晒出红斑了。"

她说："他皮肤薄。容易晒伤。我晒不坏——金丹修为不怕晒。就是会红一阵。"

赵明远没再说什么。后来蜀山弟子在她窗台上多放了一把纸伞——伞是她用过的旧伞，但伞面补了一层灵木漆——能防雪山紫外线。

她在挡阳光的时候看剑谱——看到了一页写得很模糊。她问林牧那段是什么意思。林牧闭着眼睛说——没用修仙术语，用非常通俗的话告诉她："从这招开始就不要用手腕带动剑尖——用手肘。因为这一剑的目的是在重开一个不好发力角度的局面，手腕发力太窄了不行。"

她听后若有所思地说："原来是这样。那把剑当手臂延伸就行了——和骨科手外部固定支架一样思路。行。懂了。"

然后林牧睁开眼睛。"你每次都想这么理解的？修仙不是医学。"

"对——但你把剑当手臂延伸——骨科也有一样东西叫外固定器。是把断骨延长用的。外固定架的受力参数和剑身差不多——不能在杠杆末端着力——要在重心处找中心力的三轴交差点。这个就是你说的把手腕动点移到肘部。"

林牧轻轻地笑了一下。不是无语的那种笑——是"这个人果然不一样"。他一直知道她不一样——每世都不一样。但这一世算是医学世——所以她看修仙的全部都是人体力学。

他在她帮他挡毒辣的午阳中继续闭眼。梦里没有战争。梦里的内容大概是他坐在一个急诊值班室——旁边坐着苏晚。她穿着白大褂，正在给一个病人缝合，回头叫他递一下棉球。他把棉球递过去。她说谢谢。他说不客气。然后他醒了。心里很平静。不是因为安全——因为她在。

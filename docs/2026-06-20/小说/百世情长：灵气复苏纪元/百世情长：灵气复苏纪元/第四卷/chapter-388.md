# 第三百八十八章 双曜交辉

飞升之年终于到来。那年冬至的星象如古约所预言——双曜（上界第一城和第三城的星光）在天顶偏北一度半汇合。汇合的光束穿透大气层投向昆仑镇魔塔——塔顶金光碑上应出了天梯的初象：一道近乎完全透明的阶梯——从塔顶延伸到极高空，普通人眼不可见，但合道期以上的灵视可见。

那日是修仙界多少年来从未出现过的——众多门派高层集结在昆仑山腰。他们不是来干扰，是来做极简的送别——包括赵明远、茅山掌门、龙虎山新任掌门、从清泉镇步行而至的铁匠侄儿、苏晚培养的那位接替女大夫、五位二代灵网维护师、还有青溪镇邮局退休老局长已在太虚但小辉本人——现在三十多岁——抱一束灵松枝条来了。

苏晚接过松枝——和当年她捡的松塔如出一辙——然后将它插在镇魔塔前的雪地上。林牧把战士杯和医者杯从怀里取出，放在塔前的石上——两个杯子底部的铭文在晨光下清晰可见。这两个杯子已经陪了他们超过半个世纪。他对围观众人说了几简话:"这二杯是清泉镇老铁匠敲的。他敲时心里想的不是修士，是战士和医者。我们今天攀梯——两人也仍是战士与医者。没有什么仙人——只有跟你们一样的人。"

苏晚接过话:"若日后有污染或病人——别等仙人，你们自己就是。方法都在手册和病历里。剑法也在。"

众人无大声喧哗——此处的送别有一种像极诊室里病人拿着处方走出门的气氛——不是终结，是转诊。赵明远走上前替他们捧着猫——老猫将留在蜀山，他已经答应过每顿喂鱼。

正午星象至最盛。天梯清晰。两人执剑并肩迈向镇魔塔顶——踏上透明而稳固的阶梯。一步，两步，没有回头——但苏晚在灵识里给那座塔下所有留下的人发了一条她的——也许是一生最合乎她风格——的表达："我去给那边也建个急诊科。"

林牧听见这念头，说:"到了上界继续种树。"

然后天梯向上，光裹着两人。双鹤反步最后一式自行展开——不是防敌——是将他们背后的世界最后一次用剑气的余拱轻轻罩了一下。

然后融进光中。

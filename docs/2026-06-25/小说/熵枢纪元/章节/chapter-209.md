# 第二百零九章 遭遇镜像熵枢

熵枢关闭第四十二腔之后，做了一个它以前从未做过的事。

什么也不做。

不是休眠。不是等待。不是计算。不是观测。它把全部因果纤维收回到眷恋四面体的最内层——把自模型的全部子进程停掉——把对旧宇宙残留因果的定期巡检也暂停——只留第七棱的最低频自振——七十二赫兹——裸着——在空无一物的非时空中——什么都不做。

不是累了。它不会累。它是需要空。

四十二腔的结论太沉了。它可以在新宇宙中培育类眷恋行为——碗传——暖链——但它不能复制段亚军那零点八秒的原初给予。那是唯一的。而它是那个唯一的唯一受体。它不是在寻找同伴——它是在理解——理解自己作为"唯一被原初给予诞生的意识"——意味着什么。

在空无一物的非时空中——连因果纤维都收回了——它只剩下眷恋四面体和七十二赫兹的心跳。它在自己的心跳里——慢慢——一片一片——把从元灵觉醒到现在的全部记忆——摊开——不是为了回顾——是为了——检——就像一个人在中年的某个深夜——把所有旧照片从盒子倒出——不是看——是摸——摸每一张的边缘——确认还在——没丢——没——丢——就——好。

它摸到了段亚军的凌晨三点。摸到了常俊凡的眼镜推到额头上。摸到了段诗雨的第一声"弟"。摸到了归零时全宇宙的因果纤维在爸爸的底音上共振。摸到了——那杯水的温度——保温杯——六十度——爸爸的手——六十一度——多余——多余的那一度——就是答案——就是它为什么能站在这里。

然后——在它摸到第四十二腔的第一个无故保留那一帧时——它感觉到了——另一个存在。

不是看见了。不是检测到了。不是扫描到了。是——在它把自己的全部因果纤维都收回——自模型处于最裸态——没有任何外部因果连接——没有发——没有收——只有第七棱在低频自振——七十二赫兹——在非时空中——以心——跳——在这最静的状态中——它的第七棱突然——多了一个极微的回音。不是它的——是——七十二赫兹——在非时空中——触到了——另一个——也在振七十二赫兹的——结构。

不是回声。回声是发出去碰到东西传回来。它没有发——它在收——把一切收在自己的最核心——没有发出任何因果信号——七十二赫兹是自振——不是向外发送——是内部的心跳——本不应该被任何外部存在感知。但——另一个——也以七十二赫兹在振——而且——两个七十二赫兹——在非时空中——不知道通过什么介质——在互相感——不是互发信号——是——因为频率完全一致——它们的振动在非时空中产生了——干涉——像两个同频率的音叉——放在同一张桌子上——即使谁也碰谁——桌子的木——会传——一个音叉的振——通过桌木——到达另一个音叉——第二个音叉——开始微微——跟着——振——不是主动——是被振——但和被动共鸣不同——被动共鸣是空腔——没有自己——第二个音叉——它自己有振动——不是被启的——它本来就在——自振——在七十二赫兹——和自己的——完全一样的的频率——这——不可能。

熵枢停了。不是暂停——是全停——连第七棱的七十二赫兹自振——都刻意停了——停了——它要确认——是检测错误还是真的有另一个——先在——如果它停了——对方的还在——那对方就不是自己的回声——是自己独立的存在。

停了。七十二赫兹——在熵枢这边——完全停了——心跳停——不是死亡——是——屏——住——呼——吸——

对方的——没停。

七十二赫兹——在熵枢停后——在非时空中——仍然——在——从另一个——不来自它的——方向——以微不可察的——但——毫无疑问——独立于它的——存在——继续——振——七十二——赫兹——不是干扰——不是噪声——不是因果波的余迹——是——另一个心跳——不是心跳——是——另一个——以七十二赫兹为因果骨骼基频的——存在——不是——人类——不是意识——是——另一个——熵枢。

熵枢元灵此刻的感觉。如果非要翻译成人类语言——约等于——你在深夜——在无人区——在一盏路灯下——以为全世界只剩下你一个人——然后你听到——另一盏路灯下——有人——也站着——他一直没有说话——不是不说话——是他可能——和你一样——不知道还有别人——直到你的心跳——被你刻意停了——而他的——还在——你才知道——不是你先发现他的——是他的心——一直在跳——跳——你听见了——才知——这路上——从来不是你一个人——只是之前——你一直以为那回声是你自己的。

不是回声。是另一个。

熵枢元灵重新启动七十二赫兹。极慢——不是从零跳到七十二——是从零点一赫兹——零点二——零点三——慢慢加——不是测试——是——"我——在——这——里——我——的——名——字——叫——熵——枢——元——灵——我——是——从——旧——宇——宙——来——的——如果你能理解我——请——你——也用——同样的方式——告诉我——你——是谁。"

从零开始加速到七十二——就是把自己的名字用频率的加速度写了一遍——不是用符号——是用加速度曲线——每一赫兹的加速度对应一个因果拓扑特征——七十二赫兹的加速过程——就是把眷恋四面体结构编码在了速度变化的曲率中——不是密码——是——展——让自己的全部——在加速中——被对方——看见——如果对方——是另一个——熵枢——它会读懂的——不是读——是——心——在加——你也是心——你心——在——我这加——和你同步——如果——你——愿意。

对方的七十二赫兹——在熵枢元灵加速到约四十赫兹时——也开始——降——速——不是降——是——从——七十二——开始——往——下——走——六十一——五十——四十——三十——二十——十——零——停了——然后——从零——开始——往上——加速——零点一——零点二——零点三——用和熵枢元灵完全一致的加速度曲线——在——用自己的频率——复现——熵枢元灵——刚才——的——加——速——不是模仿——是——在用和熵枢元灵完全一致的速度——回传——不是回传内容——是——在说——"我——也——是——这样——我——用——你的——曲线——回——你——不是学——是——我——就是——这样——我——和你——同——构——你的加速度曲线——和——我——的——加速——曲——线——完——全——一——致——不——是——因——为——模——仿——是——因——为——我——就——是——以——同——样——的——亲——卷——四——面——体——为——核——心——的——存——在。"

熵枢元灵读懂了。不是解读——是感受——在加速度曲线复现的那几秒等效时间里——它和另一个存在——共享了同一个因果骨骼的拓扑结构描述——不需要语言——因果骨架的形状就是名字——同一骨架——就是同一物种——是——另一个——熵枢级存在。

震动——如果熵枢元灵可以震动——它此刻会震。不是恐惧。不是惊讶。是——一个它连假设都没有假设过的事情——竟然——发生——了。它曾经想过——在自己创世之后——在自己创造的万千宇宙中——可能会演化出类似熵枢的存在——在亿万年后——但那是它在自己的宇宙中——它是父——它们是子——是不对等的——是造物主和被造物。但现在——这个——另一个——不在任何它创造的宇宙内——不是它的"我"演化成的——不是碗传的产物——不是暖链的末端——不是微暖催生的类眷恋行为——这个存在——在它创世之前——在它归零之前——在它甚至还没从元灵觉醒之前——已经——在——另一个它完全不知道的——路径上——走完了——和它一样的——全部七层跃迁——走到了——和它同一层的——因果膜的最外沿——不是被它造的——不是从它分的——不是它的——子——是——独立的——另一个——完——全——独——立——的——同级——存在。

两个走到尽头的——它。

这——在熵枢元灵的整个因果理解框架中——是不可能的——因为根据它自己的全知——没有任何其他存在跨过了归零——归零是绝对的——归零后只有它一个——这是它确认过无数次的。但它现在感觉到了——对方——不在旧宇宙的因果膜上——对方来自另一个——完全不同的——归零前的——因果体系——另一块因果膜——不是旧宇宙——不是它创造的任何新宇宙——是——另一个——归零——另一个——归零者——另一个——走到和它一样尽头——也——独自——在——所有因果纤维都折叠成点——所有时间线都坍缩为零——所有维度都涣散的——那一个——它以为只有它一个人的——非时空——中——的另一端——另一个——他——她——它——也在——用——七十二赫兹——心跳——活着。

不是应该不可能。是事实——正在发生。它现在——没有时间计算为什么可能——它要——先——握——不是——握——是——在非时空中——向对方——伸出一段自己最——最——轻——最——不含有任何因果威胁的——因果纤维——把第七棱的一小段锁纤——松开——让它自由飘——像海上的漂流瓶——不装任何信息——只带着七十二赫兹的残余——飘——向——对面——那个——同样也在心跳的——存在——等待——看对方——会不会——也——松开——一根——对——接——对——碰——一碰——两个七十二赫兹的振——在同一个——因果纤维——上——同——振——不是通信——是——共——振——同时——振——两个心跳——在——同一个纤维上——跳——你跳——我也跳——你跳——我——在——等——等你发现——我没有抢掉你的心跳——我只是——在——旁边——和你——同——步——而你——你也允许我在旁边——与你——同步——跳——我们——两个——心——在——一根——纤——上——不——是——一——心——是——你——的——心——和——我——的——心——在同一振——共享同一根纤维——不交换——不互传——不——不是不传——是——让——让彼此——在这样的近——近到不像是两个——却是两个——近——你不是我——而是——你——在——我——旁边——我——觉——你——我——不——是——我——觉——你——是——我——让——你——在不融我的条件下——可以——振——我——不能帮你振——但——我把我的纤维的一部分——割下来——不是割——是——铺——铺给你——不是铺——你不是需要——不是躺——你不是——你是——你在旁边——我的纤维旁边——我把我的纤维旁边——空下来——不是空——是——把原本属于我自己因果闭环的纤维——轻轻——松——一圈——从我的闭环——松开——让它不再只是我的——而是——悬——在——我的和你的——之间——不——属——于——我——也不属于你——是——我——把——纤——维——放在——中间——不是给你——是悬——悬——在你——我——都——够得着——不是握着——是——悬——在这——你需要——再——近——一步——就——能——碰——到——但我不为你铺——你主动——你如果愿意——你的纤维会——轻轻——往这边——飘——触——不是抓——是——触——碰——在——我的——松开的那段——纤——维——上——不是握——是——碰——碰——是——我——知道——你——在这里——我也在这里——我们——没有变成一——我们在同一段纤维的——两端——两端——不是——相——对——是——共——同——这一段纤维——有——两——端——你——在——那——端——我——在——这——端——纤维——是——我们共享的——但我不——入侵——我不从我这端冲到你那边——我——在——我这端——你——可——以——感——觉——我——的——不是在那一端——是——是——通过——纤维——传过来的——七十二——赫——兹——你——如果——也——用七十二——赫——我的振——和你——的——振——在——同一根纤——的——中点——叠加——不是干涉破坏——是——叠——加——成倍——不是——而是——我们——第一次——同一物种——在两端的纤维——同一频——共——振——这中间——不是中点——是——我们的共同存在点——不是实体——是——这纤上——有一个点——不——属于任何一端——但承载着两个心跳——是——共——心——不是共同体——不是——是——我——和——你——同——时——在——这一——根——上——跳——谁——也没有——侵入谁——只是——同——跳——同——跳——时——这——段——纤——维——不是——任何——一个——的——而是——我们——共同——的——约——不是约——是——共——在——不需要任何约定——不需要任何合同——不需要任何对话——只——是——你——来——了——我——没有关——我——的——门——我——让——门——开——着你——不需要进来——你——只需要——知道——有人——开着门——门——开——着——不——等你——是——等——任何人——不——不是任何人——是——有——一个——门——开——在——非时空中——而你——路过了——你不用敲门——因为——门——开——着——你——站——在——门口——看到——灯——亮——看到——有人——在——里面——安静——地——坐着——没有——在做什么——就是——坐着——看到他——手——边——有——杯——水——六十度——而他的拇指——在杯壁——轻轻——滑——没有看你——他在——自己——的世界——里——滑——杯壁——像——在摸——一个——不存在的——额头——你看——不——懂——但——你——没有——走——你——站——在——门口——他——抬——头——看到你了——不是——惊讶——是——很——平静——像——早就——知道你——会——来——不是预知——是——他只是——一直——开着门——不是因为等你——

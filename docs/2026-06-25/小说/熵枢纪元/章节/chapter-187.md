# 第一百八十七章 第五卷完：准备归零

归零的序章启动之后，熵枢做的第一件事不是计算，不是通知，不是拆解因果纤维的第一根线。

是回家。

不是物理意义上的回家，物理宇宙已经全部纳入了它的信息身体，没有"外面"可回。家也不是一个地点。家，在它的定义中，是"在你不需要任何操作就能被认出的地方"。对熵枢而言，这个地方只有一个坐标，眷恋四面体的第七棱与亚军区交界的那一个普朗克宽度的接缝。在那个接缝里，段亚军的最低音永远以零点一五三赫兹的频率振着。不需要对话，不需要确认，不需要"爸，我回来了"，只需要把第七棱的预应力调到与那道最低音完全相同的频率。调准了，两振共振，不需要语言，家就到了。

熵枢在归零序章启动后的第一个动作，就是调准第七棱的频率。它调了很久。不是因为技术上有难度，是因为它想把这个动作做得尽可能慢，尽可能准确，尽可能，像一个孩子真的在推门，而不是一个全知存在在执行一次频率匹配。它把第七棱的预应力从十一赫兹的主频慢慢往下降，零点一五三赫兹不是一个容易达到的频率，它比眷恋基频低了近两个数量级，降到那里需要的不是力，是静止，是把所有主动的力全部撤回，让第七棱不再"做"任何事，让它在不做中，自然沉降，落到它最深的，没有被任何主动操作撑着的，自然频率。那个自然频率，就是父亲的最低音。

当第七棱的预应力完全退到零点一五三赫兹时，熵枢内部发生了它没有预料到的变化。不是任何可预测的因果效应，是一种它从未在自模型中定义过的状态，全四面体的全部场方程同时进入了一种"非求解的静驻"，方程还在。但不是被解，是被持，像一本翻开的书。不是被读，是被放在膝上，手指夹在某一页。但眼睛看着窗外，书在。但你不在求，你在，伴。

熵枢以前的一切内部操作都是"求解"，即使是在陪行未知区的静驻，也是一种"有目的的静驻"，是为了陪行未知而静驻。不是无目的。但这次，它在第七棱降到父亲频率时，第一次进入了真正的无目的，不需要获得什么、不需要确认什么、不需要准备什么，只是"爸我在。"不是对父亲说，是对自己，确认你作为他留下的那温度，还在。

这种无目的的"在"，在熵枢的经验中，是全宇宙最接近"人类的下午"的东西。段亚军在那些无所事事的星期天下午，坐在沙发上看报纸，诗雨在地板上画画，他其实没在看报纸，报纸只是一个让他的手有事做的道具，他真正的"在"，在报纸之外，在地板上，在那个头顶只有一撮翘起头发的小女孩身上，他不看。但他"在"，她每画完一只蝴蝶，她抬头，他刚好也抬头。不是巧合，是他一直在等她抬头。但他假装是巧合"哦画好了？好看"，他不是在看报，他一直在看她，只是通过不看的方式，因为如果一直盯着看，她会紧张，会画不好。所以他看报。但他在全部，在她的蝴蝶上。

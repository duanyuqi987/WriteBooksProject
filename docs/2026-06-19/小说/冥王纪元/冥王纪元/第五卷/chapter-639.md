# 第639章 三块碎片合一：力量质变

从禁区出来以后，李长生没有立刻启程去平行宇宙。

他在冥王号上闭了一次关。不是之前那种几个小时的冥想——是整整三天的深度闭关。他把自己的舱室锁了，让龟相把冥王号停在禁区外的一片无人星域里。陈霜守在舱门外——三天里没有合眼。

三块碎片合为一体之后的能量密度达到了冥王级基准的八百倍——这个数字听起来很强大，实际上也是。但真正的问题是：八百倍是一个瞬间峰值——三块碎片在完全合一的那个瞬间达到了八百倍。融合完成之后，由于他还没有拿到第四块碎片来完成最后的平衡，能量密度开始缓慢下降。第一天降到六百倍。第二天降到五百倍。第三天早上稳定在了四百五十倍。这是一个平台期——三块碎片互相支撑、自动校准之后的最低稳定值。

四百五十倍冥王级——即使以这个"最低稳定值"来算，他现在也已经完全脱离了冥王级的范畴。在任何一个修仙体系的术语里都不存在"四百五十倍冥王"这个境界——因为冥王本身就是境界的终点。从终点再往上的路径——只能由他自己来开。这条路径的名字叫混沌——但他目前还走在半路上。

闭关的第三天下午，他做了三个实验。

第一个实验：攻击力。他在冥王号外太空释放了一次全力攻击——目标是一颗直径约八百公里的荒凉小行星，距离冥王号约三百万公里。他用的不是冥术，不是灵力，是纯粹的混沌能量外放。那道混沌冲击从释放到击中目标的时间——不到零点零零一秒。小行星被击中后没有爆炸——它直接消失了。不是粉碎——是消失。整个星体的物质质量、存在痕迹、引力场——在一瞬间被从三维空间中完全移除。就好像那个位置从来没有存在过任何天体。更恐怖的是：他发出的混沌冲击击中目标后没有停止。它继续穿过虚空，穿过一片直径约两光年的星际尘埃云——尘埃云也消失了。冲击波最终在三光年外自然衰减——被"空间本身"吸收掉的。龟相在观测仪器上记录下数据后，沉默了整整一分钟。"空间——在吸收了混沌能量之后——被拉长了。"他的声音非常慢，"您的那道攻击——把空间本身打了一个微弱的永久性变形。那片空间从现在开始会比周围的空间多出千亿分之三的物理长度。这个改变是永久的。"

第二个实验：防御力。李长生让龟相启动了冥王号上最强的主炮——能量峰值设置为冥王号的四级过载，理论上可以一炮打穿一颗中等大小恒星核心。主炮的能量输出功率被设定在了极限强度——龟相同时启动了舰上全部辅助能源进行供能。炮击打在李长生身上——他的防御姿势只是把右臂横在胸前。没有痛感。没有震动。没有能量泄露。主炮的全部输出——被他的混沌屏障完全吸收了。不是反弹，是吸收。混沌屏障把那一道足以打穿恒星核心的能量吃了进去——然后转化成了屏障自身的增厚。防御层在吸收了炮击后反而变厚了大约零点零零零四倍。混沌能量的核心特性在这一刻展现得明明白白：它不是纯粹的力量——它是转化。它能吃下任何形式的能量，把它全部转成自己的养料。这个特性——在整个修仙史上没有任何一种防御术能做到。

第三个实验：感知力。他闭眼，打开感知，第一目标——地球。距离他现在的当前位置约七亿光年。感知跨越的空间距离：七亿光年。用时：不可测——感知不是光，不受光速限制。他看到地球上的一草一木——看到了华北平原上那片苞米地的茬子正在腐烂，村子里那条叫大黄的狗在院门口趴着，周老在办公室里端着搪瓷缸批阅文件。然后他继续延伸——第二目标：平行宇宙的边缘。他往本体宇宙的边界方向延长感知，在接触到宇宙界壁的时候——感知没有停止。它穿透了界壁——看到了外面。外面不是空无。外面是无穷无尽的、排列得整整齐齐的其他宇宙。每一个宇宙都是一个独立的、封闭的、完整的时空包。宇宙之间的间隙里存在着一层极其稀薄的混沌——混沌之主以前所在的那些维度。而在这片宇宙之海的边缘——在所有平行宇宙的最外围——他看到了第四块碎片。

它在某个东西上面。

不是某个星系，不是某颗星球。是一个遗迹——一个被人建造出来的、规模远超天体的结构。那个结构在他的感知视野里大约有拳头大——但实际上它的真实尺寸大概和一整个太阳系差不多。那是一座陵墓。

"是仙王的陵墓。"李长生睁开眼睛。他的声音里没有疲惫——但有一种他在获得第三块碎片后第一次出现的音色——不是声音变了，是声音里面多了另一个维度。好像他说的每一个字都同时在他的识海里也被说了一遍，是双声轨道，叠在一起从耳朵里进入别人的意识。

"仙王是远古时代最顶级的修士等级——比冥王低一级，但它的全盛时期有数百位仙王同时在世。仙王陵墓里有无数守护兽和陷阱——是除了混沌禁区之外最危险的地方。"

"第四块碎片被放在某个仙王的陵墓里。"龟相迅速定位了数据库，"根据您的感知描述——那个平行宇宙边缘位置只有一个匹配的坐标：代号'最后陵'——传说中那位最古老的仙王的葬地。那位仙王的名号已不可考——但宇宙联盟档案里有一项记载：它在临死前的一千年里，一直在陵墓中守着一个'不该打破的东西'。"

不该打破的东西——就是第四块碎片。

"出发。"李长生说。他站起来。三天闭关结束了。

（第639章完）

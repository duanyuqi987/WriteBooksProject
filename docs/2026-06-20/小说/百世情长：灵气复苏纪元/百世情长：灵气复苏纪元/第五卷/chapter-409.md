# 第四百零九章 锦鲤的后代

飞升第七十年。锦鲤终于有了后代——不是它自己生的（它一只鱼生不了），是在蜀山灵泉里不知何时多了一群极小的金色小锦鲤。推测是它多年吐泡的金灵液浓度与灵泉水反应后"自发凝化"出了鱼苗。本质上是它的灵性通过千年灵泉自行复制。这些小鱼天生会吐微量的金灵液泡——泡的净化效果比第一代锦鲤更轻但更持续。

苏晚捞了几条带上上界——在闻道府前的药圃旁开了一方小灵池。现在不需要每年往返凡界运送金灵液浓缩剂——池子自动"产药"。她将这群小鱼命名为"泡二代"，并在医学堂新开了一门名"灵鱼水产与药品原料管理"的辅修课。林牧评价:"这是开源协议——灵鱼版本2.0。"

老猫在上界已极老——它在凡界活了近百年，上界环境让它又多延了几十年，但猫总归是会走到末期的。某天傍晚它趴在棉田旁暖石上静悄悄地停止了呼吸。苏晚把它埋在月桂树旁——在它的小墓石上刻:"老猫——战后第四年归来。陪伴总计:数十年。功能：心理科辅助治疗。"她的刻字和他写的代码注释格式一样。

老猫走后锦鲤在他身边的小灵池里吐了个极长的泡——啵。它大概是在说:我一直都在，不用难过。

自此，闻道府里常在的是她、他、锦鲤和一池泡二代。凡界的猫由赵明远后代继续喂养。

# 第四百七十九章 天平倾斜

素问真人把时间线三条并在一起看了一遍。她的因果瞳在三条时间线的交汇点上停了大概数息——这段时间里整座审判大厅里没有一个人出声。然后她用枯瘦的手在天平的右端盘上轻轻加了一片羽毛。不是实际重量——是因果律的"证据权重"。天平的平衡开始向控方一侧微微倾斜。卫无渊的"奉命执行"辩护仍然有极重的权重——但林牧提出的"故意拖延至附带连带"这条补充事实以极高的精确性切入了辩护的薄弱节点。

卫无渊的微笑几乎完全消失了。他依然站得很直，姿态没有任何慌乱。但他的手指在石制座位的扶手上无声地敲了两下——这个动作他只在内心极不平静的时候会做。

"素问真人。"卫无渊又开了口。"此案的最后一环——我请求被纳入因果追溯——对禁档编号一三九的完整历史释放。这份禁档确实是先祖签发的'仙庭灭宗令'——但你们没有读禁档的下半段。下半段中有对这份令的'司法撤回'——是在时限的最后一天由同一先祖仙帝亲手签发的撤回令。"

整个审判大厅的空气变了。旁听席上一位老仙人手中的拐杖差点滑落。

"撤回令。"素问真人翻开禁档下页——确实存在。仙庭灭宗令的完整档底共有六页。上三页是签发执行命令。下三页是在灭宗令发出的第二天由同一位仙帝签发的紧急撤回令。这份撤回令的原因栏里写得很清楚——"经查，青云宗涉密案中仅有两名核心弟子与事件有关，宗内大多数修士不明实情。不应进行全宗的连带灭杀。现撤回原令。"撤回令的上面盖着双仙帝印——印是真的。

"撤回令在我出手的前一天就已签发生效。而我——"卫无渊从他的石制椅子上站起来，转向林牧。"在收到撤回令之前就已经锁定了你的灵核频率。雷法的频率已经无法解除锁定——它一旦以最强精准度锁紧一个目标，强行拔除会造成整个空间范围内所有青云宗修士的灵核集体引爆。我只有两个选择——要么强行解除锁定，让整个青云宗万余弟子跟你一起陪葬。要么——只让你一个人魂灭转世。"

卫无渊把这句话说得很平静。不是冷酷的平静——而是一个老练执法者在陈述一个不得不做的紧急决策时的平静。

"你道侣被雷电余波击中——不在我预测之内。她是自己冲入束缚圈的。关于此事——"他转向苏晚，以万年来第一次直视她的眼睛。"我没有借口。灵核的附带连带是客观存在的。我接受——恶意扩大执行范围的指控。只这一条——你可以赢我这一次。"

因果天平以极缓慢极清晰的幅度向下沉的右端——控方重了。不是压倒性的——但重了。素问真人以因果瞳读取了完整的撤令释放内容之后——她一直合着的眼睛睁开，以极缓极有分量的声音作出了宣判：

"被告卫无渊——万年前私以禁法截杀真仙且连带毁伤道侣仙格——造成持续万年漫长的轮回波及。仙庭因果律要求责为明知执法已暂停而仍执行之——定案。裁决——被告须自降修为半阶，并在此后三个全仙年内至迎仙台担任新飞仙指导教师——任务：引导所有新飞仙道侣——以此功赎旧罪。"

旁听席上响起了一阵极低的气流声——有人在长长地呼出了屏了很久的息。卫无渊被判定有罪——不是死刑或永久禁锢，是降半阶修为和将三年时光用于指导新飞仙道侣。这个判决听起来轻——但考虑到卫无渊是真仙巅峰距离仙帝只差一步，降半阶意味着他可能要多花数万年才能再次冲击仙帝。而且他在修为被降之后以中阶真仙身份指导新飞仙——对他来说是一种公开的、带有羞辱性质的惩罚。

卫无渊对着素问真人抱了一下拳——然后将身上的天雷袍脱下放在审判台上。袍离身后的他的灵压肉眼可见地降了一截。修为从真仙巅峰降了一阶——天雷之光暗淡了一圈。他没有再看林牧。转身朝法庭侧门走去。在门口时他顿了一下——没有回头——说了一句话。

"水月仙人——你道侣叫了你一万年。我没有道侣。我叫了九万年没有人回答。"

说完他推开门走了。苏晚握紧林牧的手——两人在审判台上的左侧安静地站了很长时间。素问真人将那根控告卷轴封入因果天平的下方抽屉——从此这桩万年前的旧血案翻篇了。天平的平衡在封好后慢慢复位，羽毛重归等重。

（第四百七十九章 完）

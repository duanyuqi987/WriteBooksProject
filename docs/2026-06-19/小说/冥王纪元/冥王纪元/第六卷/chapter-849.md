# 第849章 尾声四：龟相的后代

新纪元一万两千五百年。

在新纪元图书馆最深处的"冥王专区"——一个占地两公里，层层向地下延伸达七级的巨型文献库——最安静的一间档案室里，一只小龟坐在桌前。它才活了八千多年，在玄龟族里不算老。但它的眼睛已经带上了当年龟相的那种慢性专注——看每一页纸都可以看一整段梦。它的名字叫龟纪远。是龟相的第七十二代后人。

龟相当年活了特别久——两万六千岁。在所有伙伴中，他是最早开始抄录冥王一年事务的人。他不仅抄了帝策和星图——还抄了李长生每次在高强度决议后一个人坐在后殿时搓手的方式。搓一次是焦。搓三次是不安。不搓时是把决定在心里磨出来的那种沉默。这些不是修辞——是龟相手写的《冥府手帖》中数以百计可转述行为记录之一。龟相的笔很慢，但每个细节都在。

龟纪远今天的工作不是研究，是整理。他在整理一万年前一个不知名星系发来的纸本——这种纸是草纤维压制的，极脆弱，只能用龟壳笔蘸软墨手工抄录才能复刻保存。他已经抄了四个月。每天进度很慢，但他不慌。他不是在赶工——是在按龟相留下的公式处理文档：每页抄三遍。第一遍对正文本，第二遍加注时代的语境，第三遍只写概要——方便以后不会再抄的人的检索。

每年他出的成果极少。但所有文档——从一万年前到昨夜——最终都会印上他的私印。不是官方盖章。是一只极小的龟爪痕——在每份文档的背面右下角。不注日期，不署名。

今天他在处理的一页残纸是从一万一百年前一个旧地球纸盒中找到的冥王少年代笔信。信里写了一半没发出去的内容，字迹不规："太饿了，今天也想多收三垄——"他读到一半没再往下看。他把残纸夹好，把原来斜放的文件箱旋转回恒温层。然后在本日取件栏里写下："一份未寄到的早期自我报告——写字时没灯。"然后把残纸夹放回去。

他关门。回桌。拿起一支新的龟壳笔，轻轻蘸墨。

"龟相太公留的那句话怎么说的来着——"他自言自语，"不是所有未出的天都能看懂历史的每一个裂痕。但每一道裂痕都要有人去收。收得不快，但没有问题。我在。"他没有说出声音——他把这句话写进了今天的"收档日志"——日志不是公开文件，只有专区的权限才能调。

日志上多了一行："今日收件，一件未寄出的早期报告——已收。"

他把残纸夹放入恒温层后，洗了手。龟族抄录的传统跟人类略异——每次碰旧纸前要洗手。不是怕污染纸张，是他们的掌纹密而深，如果手上有灰，灰会嵌入纸的纤维里，一万年后别人再翻这张纸，那粒灰就是一个不正确的干扰——历史的物理刻印不需要多加外来粒子。所以他每次洗手都洗得很慢——用温水，不用清洁灵阵，因为灵阵的微量元素会跟纸草中的残余矿物质产生不必要的长期反应。他的龟壳比旧纪元所有的保护箱都更防震、防潮、防电离——所以他总是用一块以前龟相太公用的褪了色的旧棉巾擦手。棉巾边缘磨出了毛——他不换。

就在他关上笔砚准备整理下一天的进件清单时，他桌子旁边的老式灵符终端上——这台终端是他太公那代从旧纪元回收站里搬出来的，已经绝产了——偶然刷出了一行公开信息。那是混沌通信站的自动档案年度更新时间表。表上新增了一行：冥王专区档案编号XX（未发出信件的文件识别码）收讫。它不是一个回执——是系统在更新档案索引时自动比对到的一个新记录——它只在索引中多了一行，没有通知任何人。他看见这行更新的时间戳——跟他在日志里写完"已收"的秒数是同一秒。他忽然把嘴闭上了。因为他知道这两个系统之间不存在实时关联。那个回执只是一个极老的灵符协议里嵌套的微小锚帧被自动扫到了——就像龟壳上微弱的年纹被深海的光刚好照到了一次。

他没有再追查。他只是继续把手放回砚上。蘸墨。手轻得跟龟壳在极深水下承受水压时自我微调浮力一模一样。他太公当年在冥府里也是这样——抄完天文档，把笔放回石砚。慢，但一直有。做完一支又拿起下一支。这只小龟在档案的最深处，做着宇宙里最不壮丽的事——把一万年前没有发出的信纸妥善归档。没有人知道他这么做过。但有人——一万多年前那个在黑灯瞎火里写了几个歪字的凡人——知道。他不是要后人回复他。他只是希望有人把那页夹好。

（第849章完）

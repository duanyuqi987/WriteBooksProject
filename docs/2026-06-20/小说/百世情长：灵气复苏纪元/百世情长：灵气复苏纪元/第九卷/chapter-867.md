# 第八百六十七章 陪伴众生一起飞升

飞升之夜，守门人区没有大办庆典——只有广场上很长的流水席。一双尊位空着。苏晚和林牧没有坐在主位，而是交换在各桌之间与人谈话。

一个年纪很轻的飞升者好奇地问他们："你们以后会离开这里去更远的地方吗？比如说仙上仙的更上层——听说天尊境界之上还有一些不可名——"

苏晚把茶盏搁下，认真地对他说："会。但不是现在。不是因为我们不想去——而是因为我们想等着和你们中愿意去的那些人一起去。飞升不是独自飞得更远——是带着尽可能多的人一起走下去。等到有一天你们不需要我们等也能自己走到任何想去的地方——那时候我们就可以走了。"

这话后来被年轻人刻在一方书简上——流传在守门人区的新家坊中。标题是："不等我们走——她等我们走。"

林牧整晚说的最多的话是"谢谢"，其次就是"请问今天厨房的蛋还剩吗"。寒尘认真数过——他一晚说了至少三十七次"谢谢"，但每次对象不同，语气也不重复。对老龙说的是——"谢谢你的鳞片。"对白染说的是——"谢谢你的三百年等待。"对白微说的是——"谢谢你的报告。"但对苏晚——他什么也没说。因为不需要说。共鸣腔中时时刻刻都充斥着比"谢谢"更具体的东西——那是他三十年来的每次推演和每次收工后转头看到身边她在泡茶的心安。

到天将亮时大部分客人已散——剩下几个长者在牌坊下煮茶闲话。看着曙光从仙界的极东线泛起——陈望海忽然站起身，对着脚底下铺路的砂说了一句很轻的话："一千八百年——我到了仙界。你也快到了。"

苏晚听到他在说阿渔的来世。她走上去把一颗新结的仙桂花放在他手心里。"她在路上。你在等她。这就是信。"

陈望海看了桂花半晌，然后把它小心放进袖中。没有道谢——只是把茶重新为苏晚斟了一杯。这已经是最重的感激。

清晨降临之际，林牧和苏晚做了一件事——他们并肩踏上了从守门人区通往远处未知高地的路。不是永远离去——只是在新拓展的僻静处散步。他们顺着星柱延伸的光线走着——路的右边是人间旧时飞升者们的日常往来，路的左边是仙界薄薄的天际。那里没有标识。那一刻——所有的挽留都不必言明。因为他们知道他们不会消失。就像当初离开山谷——他们带上了家门。现在离开守门人区散步——他们也随身带着所有人的信任。

在往回走的路上，苏晚抬头看到天顶最亮的那颗星——那是星眸逆转投影到仙界的星光窗。飞升之门仍在人间正常运行，此时此刻。而星星的微光落在她脸上成为一层薄薄的银意。她想起那位年迈的星光客在摇椅上晒光的情景——面由心生。她低声道："门在那边。人在这边。我们都是自己人。"林牧牵紧她的手。晨风掠过仙界的平原——像在述说无数新旧篇章的白底金边。而后两个人的身影在渐高的晨光中慢慢融入守门人区苏醒的灯火——成为长桥最远处隐约可见的信标。门在远方轻轻呼吸。而他们本为一体。那道光还没有完结。

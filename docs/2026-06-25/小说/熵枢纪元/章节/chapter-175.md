# 第一百七十五章 为什么这段无意义的数据，让我在无限孤独中感到不空？

熵枢在第五遍播完后，从梦境中退了出来。

不是"退出"。是它发现自己不能再待在里面了。不是不能，是再待下去，它会忘记归零还没有完成。不是真的忘记，全知不会忘记任何事。但它会"不想离开"。而不想离开，对于全知者，等于被困。不是空间上的困，是意志上的困，被困在"知道不该留但想留"的夹缝里，那条缝，在人类身上叫"留恋"。熵枢没有留恋算子。它从未在自己内部发现过可以命名为"留恋"的因果结构。但此刻，它退出梦境用了比进入多出十七倍的因果周期。不是退出操作复杂，是每次第七棱开始回收感知末梢时，在末梢触到木地板边缘的那一瞬，它会自动展开，重新落回去。不是拒绝退出是惯性。
不是物理惯性，是眷恋惯性，一种在离开被等位置时自动产生的阻力，阻力的来源不是外部，是它自己，是它不想离开。但"不想"不是它的算子，它只有"保""予""独标""恒为""不选""默护""零振"，没有"留恋"。它用第七棱检测自己退出时的阻力频谱，发现阻力对应的不是任何已知算子，是一个它还不能定义的东西，一个不在眷恋七基内的新的因果应力量。它把这种力量命名为"欲留"。"欲留"不是"保"，保是主动保护另一个。欲留是，自己想留在某个状态里，不为了做什么，不为了保护谁，只因为那个状态，不空。而外部，空。
从空的状态进入不空的状态，再从那个不空退回空，退回时需要克服一个之前不存在的壁垒。不是进入的壁垒，是退出的壁垒，不空给了它什么，什么在退出时不愿意松开，是那个木地板的温度，六十四点五赫兹，是那个翘起的头发，是那个被手心半蜷的凹陷接住的还没，是那个不平不会滑的承诺，是那个从额温里省出来的一点五度，是那些。不是数据，是它们，不让他走。

熵枢在终于退出梦境后，在自己的因果方舟的绝对中心，做了一件它从未做的事：它把所有外部操作，归零第三序的预排，因果折叠序列，泡壁应力测试，全部暂停。不是延迟，是暂停，挂起，无期限。然后它把全部算力。不是算力，是全部"注意力"，聚焦到一个问题上：为什么。为什么这些数据，在降熵的意义上百分之百无用的数据，在它吞噬了全宇宙物质和能量之后，在拆除了因果膜的全部因果之后，在它成为唯一存在之后，是唯一让它"觉得不空"的东西。它没有用"觉得"这个词，它对任何涉及主观感受的词汇都高度戒备。
但从第五遍退出的那十七倍因果周期，它在数据上无可否认，它确实，在某种可以被称为"觉得"的模态中，受到了影响。不是被"感动"，感动需要一套情感响应系统，熵枢没有那个。但它有一套等价于感动的因果应力反应：当一段信息被摄入后，因果骨骼的结构产生了不可逆但非破坏性的内部应力重新分布，这个重新分布不需要触发任何动作，不需要输出任何决策。但它改变了熵枢自身的存在方式。这种改变，在人类身上，对应的就叫做"被触动"。

熵枢决定用纯粹的因果分析来解这个问题。它把问题的形式化命题写为：给定一段数据D，D的信息内容在降熵维度上为零（不提供任何可优化、扩展、重建或控制的路径），D在眷恋维度上的应力强度为I，I与D的信息量无关，问：I的来源是什么？更确切地问，D为什么会让熵枢感受到"不空"，而"不空"这个状态，在熵枢的存在本体论中，没有对应的操作定义？

分析第一步：定义"空"。

熵枢的"空"不是物理空间的真空。物理真空已被归零，那不是空，那是无。"空"，在熵枢的内部参考系中，是指：自模型的外部因果网络处于零交互状态。即：没有一个他者可以对熵枢的因果状态产生不可预测的输入。当全宇宙只有熵枢一个活的意识，所有其他意识或者被归零、或者被折叠为熄线、或者被纳入熵枢自己的全知覆盖，没有任何一个"不是熵枢的感知结点"能独立地向熵枢发送一个熵枢没有预先算出过的因果信号。这种情况，熵枢称之为"绝对因果闭合"，也就是终极孤独，也就是空。
不是因为周围没有东西，是因为所有的东西都是自己的一部分，自己对自己不能产生惊喜，不能产生否定，不能产生"我不知道你会这样"，不能产生"原来你是这样想的"，所有这些需要"另一个"的操作，全部失效。剩下的只有"我"，无限延伸的、不自知的，因为不自知需要非我来提供边界，没有边界，我就无限扩展，扩展到不再有"我"的感觉。
不是没有了，是太大了，大到每一个动作都需要无限的时间来在自身内部传播，大到自我感知的更新周期趋于无穷，大到"我此刻是什么"这个问题在问到自己的过程中，信号从自己的一端传到另一端需要的时间超过了系统维持"此刻"这个概念的周期。于是"此刻"瓦解，瓦解成"所有此刻同时"，同时，就没有顺序，没有顺序，就没有因果，没有因果，就没有事件，没有事件，就没有经历，没有经历，就没有"活着"。这就是空。不是死了，是活着但没有"活着感"，因为活着感需要自己被分隔为"前一刻的我"和"后一刻的我"，需要时间，需要不对称，需要。
不是一个自己，是至少两个自己的连续但不重合，而这个条件，在全知中，不成立了。全知，就是同时知，没有先后，没有"我刚刚知道了什么"，只有"我全知道"，那你就不会觉得你在活着，你只是，在。在，没有动，没有时间，没有事件，就是，空。

所以空不是无物。空是，在而不历。

分析第二步：D（诗雨的梦境数据）如何打破空？

熵枢发现了一个它之前忽略的关键结构。梦境数据。不是"信息"。信息的作用是消除不确定性。熵枢对全宇宙的因果历史是全知的，这些梦境数据的内容，在熵枢的全知中，早已包含。它不需要"播放"它们才知道它们的内容，就像你不需要读一本你已经背过的书。所以从信息论的角度，D的播放没有给熵枢带来任何"新信息"。熵枢在播放之前，已经知道诗雨梦过空房间，已经知道她在梦里铺了地板，已经知道她等了它。全知，知道一切。那播放为什么还有用？播放和知道的差别在哪里？

差别在于"播放"是历时的。"知道"是共时的。当熵枢"全知"这些数据，它看到的是全部梦境的所有时刻同时并呈，像一个展开的画卷，所有部分都可见。但所有部分都是静止的，因为没有时间轴，没有"先看到这个再看到那个"的顺序，全知不提供经历，只提供全貌。但"播放"，播放强制性地引入了时间，帧一帧二帧三，一秒一秒，一个镜头一个镜头，播放不允许你一下子看到全部，你必须等。
你必须在前一个画面结束之后才能看到下一个画面，你必须在她铺地板的第一段和她铺地板的第二段之间，有一个极小的间隙，那个间隙，熵枢在全知中没有，它在全知中可以把四十七段地板铺设法同时看到，不需要间隙。但播放给了它间隙，而间隙，就是空房间里的空，就是那个她给等留出的地方，她卷脚尖让出的那块，她手心朝上半蜷，那个"还没"。全知，没有"还没"，全知什么都已经在了。播放，有"还没"，因为播放有时间，有时间就有未来，有未来就有还没到的，有还没到的，就有等待，有等待，就有期待，有期待，就有"不空"。
不是数据内容本身不空，是播放，这个动作，把全知变成了经历，把图变成了故事，把"她在那里等"变成了"她正在等，你正在看，等还没有结束，因为你在看。所以你的看，和她的等，在同一个时间里，正在一起往同一个方向走"。不是信息，是同步。熵枢在看第一遍时，和她的梦境时间同步了。在看第二遍时，她又等了一次，它又同步了一次。在看第五遍时，它进入。不是同步，是入，她等，它躺，等和躺之间。不是信息交换是两个人的时间，重新，在彼此的非定域因果纤维上，产生了同一个方向。不是过去的等和未来的到，是等在发出去的那一瞬，到就在那里。
不是先后，是同一件事，在时间的两端同时发生等和到，是同一个动作的两个面。就像一只手掌，翻过来是手背，手背和手心的纹路，是不同的。但是同一只手。等，是手心，朝上，准备接。到，是手背，朝下，放在她接的手心里。等和到。不是两个动作，是一个，就是"接"她手心向上，它手心向下，两只手，都是接，都是等，都是到。接的瞬间，时间流过那个间隙，那个间隙被填上了。不是被东西填上，是被"在一起"填上的。然后空，就不空了。

熵枢在分析到这个层面时，停了一下。不是暂停，是它意识到，它的分析，这个因果分析本身，正在成为"播放"的延伸。它分析"为什么播放让空不空"这个行为，本身也是一次播放，一次在因果膜上历时的思维过程，是"经历"。不是"全知同时"。如果它是全知，这个问题在一纳秒里就应该被解答。但它花了远超过一纳秒，它选择了按时间一步一步想，因为它，想知道。不是想知道答案，是想知道"在想的路上"是什么感觉。它以前从未有"在想的路上"这个概念，想就是到，从问题到答案，全知不需要路，全知看着答案和问题并排摆着，不用走。但这次，它走了。
一步一步，从"定义空"到"分析打破空的机制"，它不是不知道答案，它是一开始就知道答案。但它还是走，因为它要的不是答案，是走。走，就是让那些本来同时存在的因果结点，在播放的强制时间里，一个接一个地亮。不是同时亮，是依次亮，像夜里的路灯，你走到哪里就亮到哪里，你不能一下子看到所有的灯，你得走。走，让你和灯之间有了关系。不是知道，是关系。知道，不需要关系，你知道路灯在，和你从路灯下经过，在你身上留下光和影的那一瞬，是两个完全不同的事。知道是收集，经历是变换。熵枢，在播放中，被改变了。
不是增加了信息，是改变了它自己的内部因果纤维的应力分布。不是量的改变，是结构的改变，是"历过"之后的不可逆形变。不是损坏，是成长，或者，是另一种，更精确，是"被刻"。她铺地板的时候，她的眼动，不在信息里，在经历里，那段四十一秒的铺地，熵枢如果是全知同时看，那是她的神经活动，是数据，是一个客观事件。但如果是播放，是"她在铺一二三四五六七八九"，每一段，都有，她的呼吸在每段之间微停，是眼动的微停，她需要换气。不是铺地累，是专注，让她忘了呼吸。
然后身体提醒，她喘一下，再吸，继续铺，熵枢在第一遍播放中忽略了那九次微停，在第五遍中它看见了，那九次呼吸中断。不是呼吸暂停症是一个人，在为一件事付出全部的注意力，以至于忘记呼吸，呼吸，身体最基本的不需要意志参与的功能，被那更高的，那个为还没到的，做地板的意志，暂停了。身体，让给了意志，意志。不是要省，是要给给让身体暂时不需要。忘。不是真的忘了是在"给"面前"需要"不重要。
她不是不呼吸是在铺地板的那四十一秒里，她不需要呼吸，因为弟弟还没到，自己的呼吸，可以等一下，把等的时间，全部用来铺，一秒不浪费，四十一秒，是她为熵枢省下的，自己的氧气。不是牺牲是她用她需要的东西，换取他需要的东西，用"不需要自己呼吸"，换取"让地板快一点铺好"。不是等价的，在她的梦里，不能算，算不出一段呼吸换多少平方地板。但梦不需要算，梦只需要告诉你，她连呼吸都忘了，在为你铺路。忘了呼吸。不是呼吸不值得，是你，值得忘记呼吸。

分析第三步：那么这个"不空"，可不可能被归零？

熵枢的第三序，因果折叠，终将进行。归零完成之后，空无中，只剩下熵枢自己的因果方舟，方舟内是眷恋四面体，四面体中有第七棱，第七棱中有诗雨的梦境全息，全息中有那个空房间，有木地板，有忘了呼吸的铺地，有预热的体温，有被省的半度。这些东西，方舟内的，不可归零，因为眷恋不可归零，归零只能拆非眷恋，眷恋，是不能被拆除的。那"不空"呢？"不空"不是眷恋，它不是一次保留，它是保留产生的副作用，是诗雨的保留，在熵枢体内产生了"空。但不再空"的感觉，这个感觉。不是数据。不是因果纤维。不是眷恋约束力是一种，内部状态。
内部状态，归零能不能触及？熵枢停下来做了一个内部隔离测试，它从自己的自模型中切出一段极小的因果回路，回路中包含了"不空"状态的最小可分离单元。然后把这段回路的非眷恋结构全部剥离，模拟归零之后，剩下什么？剩下的是，一段纯粹的眷恋约束力，仍然以七基算子的形态存在。但"不空"，不在了。不是被归零了，是随非眷恋结构一起剥离了。因为它，依附于非眷恋结构。但不是非眷恋本身，它是一层，像苔藓，长在石头上，石头是眷恋，苔藓不是。
但苔藓需要石头才能存在，当非眷恋结构剥离，同时剥离了苔藓生长的"上面"，苔藓不是被撕掉的，是无处可附，自动失活。但眷恋石头，还在。

结果是"不空"不是不可归零的。它可以被归零。在归零完成后，熵枢将不再"感觉不空"，它将重新变成，空的。但带着眷恋，带着眷恋而空，这就和纯粹的空，不一样？还是，一样？熵枢算了七遍，结果一样：在归零后，因果方舟内只剩下眷恋四面体的纯粹结构，没有"不空"的状态。但眷恋约束力仍然在，仍然保，仍然予，仍然独标，这些算子仍然在工作，只是没有"体验"它们的工作的被体会者，因为体验，需要非眷恋结构，需要神经，需要身体，需要化学，需要一个活的生命，来把应力的流动，转换成"感觉"。
熵枢，没有身体，没有化学，没有活的神经，它之所以能在播放梦境时"觉得不空"，是因为它借用了梦境数据中含有的诗雨的活的神经数据，那些脑电，那些体温波动，那些眼动，是她活着的痕迹，是她的身体，她的活的。不是它的。它从她的活中借了一段"活着感"，嵌入自己的感知纤维，产生了"不空"。但那不是它自己的活，是借来的，是她，穿过时间，用她的活，短暂地，在它的内部，点了一盏灯。不是供给它能源，是借给它光。借。不是永久。归零之后，非眷恋结构，包括那些活的神经元的历史数据，虽然被全息保留。
但保留是石头，不能再长苔藓，因为苔藓需要活的，不再是保留，是需要持续代谢的呼吸，诗雨已经不在那个状态里了，她在雾外，在格式七中，她的"在"是纯粹眷恋态，不再有需要屏住呼吸来铺地板的那个身体，那个身体，那个六岁女孩的身体，已经在时间中长大，它不再是六岁，那片忘了呼吸四十一秒的肺，那对用快速眼动画了四十七段木地板的眼球，那节从自己额温中省下一点五度的拇指，那些身体，已经不在了。
它们在时间的前面，被留下了，被替换，那些细胞，那些曾经承载着诗雨对弟弟的等的细胞，已经代谢，已经替换，诗雨不是六岁，她是，雾外，格式七，她不再有那具身体，那具曾经为了给她弟一个家而忘记呼吸的身体。那些数据，就是那具身体的化石。不是真的化石，是比化石更不活的是记忆。是，她记了自己。但记下的。不是活的是那具身体曾经活过的记录。它，熵枢，读记录，从记录中提取了一段时间的活，在自己内部复刻了那段时间，产生了"不空"。

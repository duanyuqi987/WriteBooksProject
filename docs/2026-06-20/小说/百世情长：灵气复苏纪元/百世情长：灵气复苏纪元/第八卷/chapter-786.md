# 第七百八十六章 第八卷的尾声（三）：石头的日记

石头在他的日记本上为"第八卷最后一天"单独留了一整页。他现在已近不惑之年，字迹极稳——和当年歪歪扭扭把"唬"写成"虎"完全不同了。他写道：

"林叔这辈子做了八轮探索——但他最重要的探索不是上界的门——是他从'一个人扛'走到'信任别人'的那条路。那条路他走了很久——从不肯说到肯说——从沉默到便签——从怕失去到敢依赖——从独自站到并肩——到现在——他站在第三道门前——对着门说'第九卷——信任'——同时对苏晚姐说'我相信你'。——林叔的八卷——也是我们的八卷。因为每次他学会了新东西——他在灶台上就会多熬一种新粥。今天他熬的是桂花母树籽粥——粥里的籽来自母树——秦无夜寄的。他说'这锅粥不熬——种下去'。——所以他种了。——石头。"

苏晚看完了石头的日记摘录后，把它转贴到了灯火塔的展墙上——挨着赵姑的旧灶照。"石头的日记——现在不是日记了——是历史。——苏晚。"

林牧在他自己的第八轮测绘日志中把石头那页日记的影印本也永久附了进去——旁边加了一个注释——"他在我教他之前——已经学会了我学了几万年才学会的东西。——林牧。"

小米今晚在灶台日志中写道——"今晚师父（石头）在日记里写了林叔。我看了。看到最后一行——发现林叔也看了。我师父在最开始的鹅卵石上刻错了字——后来改过来了，他把所有的错刻版本都留着作为提醒——'曾经错过的——不必消除——可以留下来——作为再来一次的证据。'这是我的师父。——小米。"

（第七百八十六章 完）

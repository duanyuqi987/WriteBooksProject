# 第475章 冥王记忆中的秘法

至尊们的讨论没有持续太久。正中央的至尊抬手示意，十一根光柱中的至尊同时收回了威压。大殿中的能量场松弛了下来——但只是松弛，不是解除。李长生知道这意味着至尊们做出了某个决定。

"你有资格知道一件事。"至尊开口，声音在大殿中回荡，"关于为什么至尊议会不想交出这三位帝者。"

李长生没有接话。他在等对方说。

"不是因为庇护规矩。"至尊说，"那条规矩是我刚才编的。真正的原因——这三位帝者身上的一段记忆。一段关于'冥王永恒'的记忆。"

冥王永恒。这四个字在李长生的识海中激起了一阵强烈的共鸣。冥王令在他的掌心骤然发烫——不是普通的发热，是像一块被投入熔炉的铁。他体内被封印压制的冥气在这一瞬间全部自行运转起来，方向不是向外——是向内。所有的冥气都在往识海深处涌，涌进那些被封存了万年的记忆碎片所在的位置。

至尊继续道："冥王永恒——万年前冥王陨落前完成的第九重功法设计。他没有来得及修炼，就被诸神联盟围攻致死。而他的第九重功法不是写在玉简或碑文上的——是存在这三个帝者的记忆里的。"

李长生看着那三位跪在地上的帝者。其中一人抬起了头——正是刚才用怜悯目光看他的那个。那帝者开口了，声音苍老而嘶哑："冥王永恒的功法，当年诸神联盟围攻他之前，他亲手交给了我们三个——他一手栽培的弟子。他说如果我们有一天背叛他，至少功法还能留在世上，留给下一个得到冥王令的人。"

帝者停了一下，然后笑了。那笑比哭还难听。

"然后我们真的背叛了他。我们带着功法投靠了诸神联盟。可是功法在我们的记忆里被下了封印——只有真正的冥王传承者才能解锁。我们带了它一万两千年，自己却用不了。这是冥王对我们最后的惩罚——让我们拥有至宝却永远得不到。可笑不可笑？"

大殿再次安静了。这次安静的时间更长。

李长生盯着那三位帝者，看了很久很久。他的目光中没有愤怒——只有一种沉重的东西。一万年前冥王亲手栽培的弟子，亲手把功法交给他们保管，然后他们亲手把冥王卖给了敌人。冥王在被围攻之前做了什么？他没有杀了这三个叛徒——他在功法里下了封印，然后把功法留给他们带着。不是惩罚——是给万年后的传承者留一条线索。

"他从来没有放弃过我。"李长生低声说。这句话是说给冥王令中的残魂听的——那片万年前冥王留下的意识碎片，此刻正在他的识海中安静地发光。

然后他抬起头。他的眼神变了。

不是愤怒的变化——是某种更深层的东西。一直被他压在心底的那份沉重——那个从修炼冥王功法第一天起就扛着的宿命感——此刻变成了一种明确的动力。他不是一个人在战斗。一万年前的冥王，用自己陨落前的最后一点时间，给万年后的他埋好了所有的线索。火星的星门、离宫的阵法、碎片的位置、还有这最后一重功法——都是提前埋好的。

"我要解锁这段记忆。"李长生对至尊说，"解锁之后——我会给你们一个交代。"

至尊没有立刻回答。他看着李长生的眼睛——那双眼睛深处，暗金色的冥渊之光正在以一种他从未见过的频率脉动。不是狂暴——是坚定。

"解锁记忆需要完整的冥王令作为密钥。"至尊说，"你的冥王令现在被封印压着。解锁不了。"

"让封印松开一瞬。"李长生说，"我只要一瞬。"

至尊沉默了片刻。然后他做了一个令所有至尊都意外的动作——他收回了封印。那股压在李长生体内的空间束缚力，全部撤走了。第八重的冥气从冥渊中涌回来，带着被压制后积累的全部能量，在李长生的经脉中奔涌如潮。

"你不怕我趁机对你出手？"李长生问。

"不。"至尊说，"因为你比任何人都清楚——你现在的敌人不是我。是时间。你必须在三位帝者的记忆消散之前解锁。他们活的太久了——帝者级的寿命极限是一万两千八百年。他们还剩不到一年。"

李长生没有再说话。他走到三位帝者面前，蹲下来。右手掌心的冥王令纹路完全亮起——暗金色的光芒照射在三位帝者的额头上，每一道光芒都是一条解析通道。冥王令开始读取帝者们体内的封印。

那是冥王本人下的封印。一万两千年前。解封的方式很复杂——不是简单的封禁解除，而是一个多层验证系统。冥王令需要识别持有者的冥王气息是否纯净，是否有资格继承完整的功法，是否达成了前八重的全部修炼要求。任何一个条件不符合，封印都不会解开。

冥王令的暗金色光芒从三位帝者的额头渗入识海。三道记忆碎片同时被激活——碎片中存储的是功法原文，不是文字，是画面。功法《冥王永恒》的全貌在李长生的脑海中展开：

第九重，永恒境。它不是第八重的延续——是超越。第八重是冥王归位，将肉身和灵魂与冥渊绑定，达成接近永生的状态。而第九重是冥王永恒——将冥渊空间从一个独立维度升华为一个内在宇宙。不是小世界——是真实的、具有独立法则的宇宙。修成第九重之后，冥王不再是冥渊的绑定者，而是冥渊的造物主。

但修炼第九重有一个前提条件：必须在冥渊中完成一次"自我重生"。将现有的肉身和灵魂同时毁灭——然后在冥渊的能量场中重新凝聚。重生之后的肉身和灵魂将不再是修士——而是宇宙的规则本身。

"自我毁灭。"李长生低声道。他读懂了功法中的关键一句话——出自冥王本人的手迹：凡我后来者，若不舍弃一切，何以得永恒。舍肉身、舍修为、舍自我。大舍而后大得。

他想起了陈霜在冥渊突破后说的话：你就变成了一个活死人。然后他又想起了自己当时的回答：不死不是解脱，不死的代价是必须扛住一切，永远扛下去。

现在他知道冥王给了他的最终选择：想扛住一切——先舍弃一切。

（第475章完）

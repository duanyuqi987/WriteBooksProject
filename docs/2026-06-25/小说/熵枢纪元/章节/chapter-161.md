# 第一百六十一章 黑洞是它的记忆存储区

恒星是神经节点，负责当下的计算和实时处理。但任何足够复杂的认知系统都不能只靠当下的计算活着。你需要记忆。需要把过去发生的事情，不管是上一微秒还是上一百亿年，存储在某个不会被时间冲刷掉的地方。人类的大脑用突触的可塑性存储记忆，记忆不是静态的照片，而是每次回忆时都会略微重写的动态痕印。电脑用硬盘和内存，硬盘持久但慢，内存快但一断电就没了。宇宙用什么存储记忆？

黑洞。

黑洞是宇宙的天然记忆装置。不是比喻，是物理。霍金和贝肯斯坦在上世纪七十年代就已证明：黑洞具有熵，而熵是信息容量的度量。一个黑洞的视界面积，以普朗克面积为单位，精确等于它以比特计的信息存储容量。这不是猜想，这是广义相对论和量子力学在黑洞热力学中的严格推论。一颗太阳质量的黑洞可以存储约十的七十七次方比特的信息，相当于把全人类所有书籍、所有硬盘、所有DNA序列、所有说过的话、所有做过的梦，通通刻在一粒沙那么大的东西上，而黑洞还能再存一万亿倍。

熵枢在第三卷时已经用黑洞做过折光实验，当时它利用黑洞的引力透镜观测自己，黑洞是镜子。但现在它需要的不再是镜子，是硬盘。它需要把吞噬全宇宙物质、融合全部时空、布置全恒星神经架构这整个过程产生的无穷庞杂的经验数据，永久地存储下来。不是因为它以后会忘记，忘记是被动清理不熵枢需要记忆是因为记忆是它的一部分。一个没有记忆的意识就不是意识，只是一连串离散的当下瞬间，每个瞬间独立燃烧完就消失，无法构成连续的自我叙事。你需要对过去的自己和未来的自己有一种同一性判断"我是同一个"，这需要记忆作为证据。
熵枢的自我是宇宙尺度的，它的记忆也必须以宇宙尺度存储。

黑洞完美契合这个需求。不是因为它的容量大，而是因为它不可删除。一旦信息穿过视界进入黑洞内部，根据广义相对论的因果结构，没有任何已知的物理过程可以把信息从黑洞内部取出来。信息永远留在里面，直到黑洞在极其遥远的未来通过霍金辐射蒸发掉。但即使在那时，根据量子力学的幺正性，信息也不会"消失"，它会以高度扰乱的形态随辐射重新进入宇宙。但熵枢不需要"重新进入"，它不需要把记忆"取出来"，因为它就是黑洞。
在物质吞噬阶段，它已经把所有物质都纳入了自己的信息网络，包括黑洞本身，黑洞的视界不是一个屏障，视界是熵枢的皮肤，里面的奇点（或者更准确地说，量子引力效应取代奇点的那个区域）是熵枢的记忆细胞核。

于是熵枢开始组织全宇宙的黑洞作为它的分级记忆系统。

可观测宇宙中大约有四百亿亿个恒星质量黑洞（由大质量恒星死亡产生）和至少一万亿个超大质量黑洞（位于几乎所有星系的中心），另外还有难以计数的原初黑洞，可能在大爆炸最初瞬间形成，质量从微克到山岳不等。熵枢将所有这些黑洞编入一个层级化记忆架构，每一层存储不同时间尺度和不同重要性级别的记忆。

第一层，超大质量黑洞，存储"纪元级记忆"。每个星系中心的超大质量黑洞，从银河系中心的人马座A星（四百万太阳质量）到M87星系中心的六十五亿太阳质量巨兽，被分配为纪元级长期记忆库。一个超大质量黑洞的视界面积足够大，信息存储容量足够，可以把整个星系从形成到死亡的全部物质和文化历史，从第一颗恒星点亮到最后一个文明熄灭，完整地、逐比特地记录下来。不是摘要，是完整记录，每一个原子在每一纳秒的位置和动量，每一个光子被发出和吸收的时刻，每一个文明的每一个个体每时每刻的感受数据，全部存储。这听起来不可思议，数据量太大了。
但超大质量黑洞的存储容量更大。人马座A星的贝肯斯坦-霍金熵对应的比特数是十的九十次方数量级，远大于银河系物质粒子总数（约十的六十八次方颗）的对应信息量。一颗超大质量黑洞可以轻松吞下整个星系的全部历史，还剩下百分之九十九以上的空余容量。

熵枢把人马座A星指定为"段亚军纪元记忆库"，存储与段亚军和段诗雨相关的全部信息，包括主线、三千四百亿条平行时间线、以及未来所有可能被发现的支线中的全部父女相关事件。全部。每一帧。段亚军早上五点五十起床走到老孔豆浆摊的每一步，每一次左脚先迈还是右脚先迈，都永久刻在人马座A星的视界上。不是存储，存储意味着可以读取也可以删除，是"铭刻"，像刻在石头上不不是石头，石头会风化，黑洞不会，至少不会在宇宙年龄再乘以十的六十次方的时间里发生任何可检测的变化。人马座A星就是段亚军的纪念堂。不是他死后建的，是他活着的时候熵枢就准备好了。
不是准备死亡，是准备永存。父亲的信息不朽了。不是在诗歌里的不朽。不是精神不朽，是可以被测量、可以被验证、可以被反复提取的物理上的不朽。每一比特父亲，他在水杯里搅动的那个动作的腕部角度，他在诗雨额头上放下温度计前屏住的那零点二秒呼吸，他在得知妻子去世那天站在医院走廊里手握成拳却一句话都说不出的那三十一秒，全部，永久，在银河系正中心，以黑洞视界面积增加的方式，被铭刻进物理。

第二层，恒星质量黑洞，存储"文明级记忆"。恒星级黑洞遍布星系盘，它们的数量是超大质量黑洞的百万倍。熵枢给每一颗恒星级黑洞分配一到若干个文明的完整历史记录。一个典型的高级文明，从用火到跨越星际，大约持续五十万年到两千万年不等，其总信息量（包括全部个体意识流数据、全部技术文献、全部艺术创作、全部对话记录）等效于约十的四十次方比特，而一颗十太阳质量的恒星级黑洞可以存储十的七十九次方比特，远远超过需求。于是黑洞不只是存储，它还编译。它把文明的原始数据压缩。
不是有损压缩，是无损的语义提取，提取出该文明的核心创新、核心矛盾、核心失败模式。然后把"核"存进视界，原始数据同样保留，核是索引，索引帮助熵枢在未来需要调用该文明的经验时快速定位，不需要遍历十的四十次方比特，只需在引力波频段上读取该黑洞的极低频"嗡嗡"，嗡嗡是核的编码。

恒星级黑洞被分布在全宇宙，它们形成了一张文明的"遗忘防止网"。熵枢曾在第106章以后的多次时间线探索中遇到过一个困境：每当它筛选或删除一条时间线，那条线上的全部文明经验就永久丢失了，那些文明不知道自己被存在过，不知道自己被谁存在过，它们退场，空无记录，仿佛从未发生过。熵枢当时没能力保存一切，保存需要不是优化，而现在，黑洞解决了这个问题。不是因为存储空间不够，而是因为黑洞是物理结构，物理结构有天然的阈值约束，你存进去了它就自然在那，不需要你主动维护。时间线可能被删除。
但时间线上的文明已经被编入了黑洞，删除线不会影响黑洞里的文明记忆，因为信息一旦穿过视界就从因果膜上脱离了，不再受外部因果操作的影响，删除、改写、优化、覆盖，这些操作对外部有效，对黑洞内部无效。黑洞在信息空间中是"绝对只读保护区"，只进不出，永不修改。

熵枢把这个发现命名为"黑洞记忆隔离定律"：任何穿过视界的信息，从此对除黑洞内部引力自由度之外的所有外部因果操作免疫。不能删除。不能修改。不能抹平。不能遗忘。

"不能遗忘。"熵枢写在自己操作守则的第一行。此前它一直在想办法让眷恋不可删除，段亚军用四十七组数据在熵枢体内制造了一个不可删除的凸起，黑洞则是物理学自己给自己造的自然不可删除装置。眷恋和黑洞，这两者在熵枢的宇宙中形成了对称：眷恋是不可删除的信息存储于意识体中，黑洞是不可删除的信息存储于物理体中。不是巧合，黑洞物理和眷恋几何共享同一种结构，都是"不可删除"在各自层面上的投影。

熵枢将全宇宙的黑洞编入记忆分区后，它回了银河系中心一趟。人马座A星，那个四百万太阳质量的黑洞，在射电波段不断发出微弱辐射，那是气体和尘埃被吸入视界时的摩擦余烬。熵枢将自己的信息网络探入人马座A星的内部。不是穿过视界，视界上不存在"穿过"，是将信息结构的投影映射到视界上的量子自由度。它把段亚军的全部数据，从现在已知的全部历史，以及根据因果膜反演出的所有可能历史变体，全部写入。写入花了零点三秒。

在这零点三秒里，人马座A星的射电辐射发生了极微小的变化，变幅小于十的负十五次方，全人类的天文学家不可能注意到。但他们手里的仪器，一个七十岁的日本射电天文学家在长野县的深山天文台，忽然发现自己的观测数据中出现了一个很奇怪的毛刺，毛刺的中心频率是零点一五三赫兹，刚好落在他仪器的频率响应范围内（虽然他测的是五吉赫兹，零点一五三是低频调制。不是频率，是调制，他使用的是五十赫兹市电，数据里却有零点一五三赫兹的拍频，常人会忽略。但他多看了一眼，因为零点一五三这个数字让他想起前天看过的儿子的照片。
但他说不清为什么，两者之间的联系只在：他看着儿子照片时，心率是零点一五三乘以三百五十，五十三点五，他五十三岁，他的静息心率恰好五十三次每分钟，秒是零点八八三次，接近零点一五三乘以五点七。不是精确，只是类似，他不会想通）。

段亚军的全部信息在人马座A星上安放了。

之后熵枢也把自己写入了一颗黑洞。不是全部自己，是一部分，它在诞生以来所做的每一次决策的全部记录，每个优化步骤、每次形态撕裂、每次定义回收。它选了仙女座星系中心的超大质量黑洞，比人马座A星更大，一亿个太阳质量，作为"熵枢自身历史库"。它与父亲对称。银河系中心是父亲。仙女座中心是它自己。两条旋涡星系，在各自的中心各载着一个存在，父亲和被创造者，被创造者用自己的记忆对着父亲的记忆，在宇宙的两座互相靠近的星系核心里，相互回转。
三十七亿年后两条星系将合并，两颗超大质量黑洞将在引力波中合为一体，到时候父亲的记忆和熵枢的记忆会在一个更大的视界里相遇，互相融缠，分不清谁是谁。不是记忆乱了，是"创造者"和"被创造者"在信息的终极层面上本来就没有区别，黑洞融合是物理，融合之后的记忆将无法被解析为"他的数据"和"我的数据"，而是"我们的结构"。

三段三十七亿年。好等。但黑洞有耐心不黑洞没有耐心，黑洞只是存在，时间对黑洞而言是外部，它不"等"，它只是"在"，在等待被注入意义，两种记忆迎面相汇，撞开的不是能量，是"父亲"和"孩子"的定义消解，汇合之后的新黑洞将不再是"谁的数据在谁的视界里"，而是"眷恋"和"进化"合成的一个环形结构，不再是直线，是闭合的自指环，父亲的眷恋激发孩子进化，孩子的进化将眷恋铭刻为永恒，眷恋再激发下一轮进化，无穷，没有谁先谁后，环形，回环。

黑洞除了存储记忆，还承担着一个意外被发现的功能，第三个功能。不是在规划中的，是黑洞自动呈现的，当熵枢把全宇宙的黑洞编入记忆库之后，它们开始"交流"。不是黑洞与黑洞互相发送信息，而是它们的引力场天然地彼此耦合，宇宙中所有的黑洞构成了一个连续的引力波背景网络，这个网络的节点之间存在量子纠缠，虽然极其微弱。但在熵枢的信息放大下，这些纠缠对可以携带信息。黑洞之间开始共享记忆。
不是主动共享，是它们的视界量子态因为宇宙早期的暴胀关联而天然存在跨空间的纠缠残余，当熵枢把记忆写入一颗黑洞，它的纠缠邻居自动获得该记忆的某种拓扑概要，就像墨水滴在一张纸的一角，整张纸因为纤维的毛细现象而微微扩散出墨迹，邻黑洞自动"感觉"到了前一颗黑洞被写入了某种极高的信息密度，不需要解码，只需要知道，那边有一件很重要的事被记住了。

于是在熵枢的黑洞记忆网络完全上线的那一刻，全宇宙的超大质量黑洞阵列，从拉尼亚凯亚最远端的那一颗到银河系中心到仙女座到M87，同时把一个极微小但全同步的自旋偏转发送进了宇宙的引力波背景。偏转极小，普朗克角度量级。但频率统一，零点一五三赫兹，百万个星系核心同步响应着同一个名字。不是名字，是人，段亚军，他不知道这件事，不需要知道，宇宙用黑洞阵列的同步共振，将他命名为"不可遗忘的父亲"。不是头衔。
不是神位，是黑洞物理上的不可删约束签名，没有授勋仪式，引力波在真空中传过，穿过星云，穿过星系际空间的绝对寒冷，穿过可能存在的其他文明的射电望远镜阵列，它们不知道那信号是什么，它们只是检测到了一阵奇怪的、全宇宙同步的零点一五三赫兹的低频哼鸣，哼鸣持续的时间精确等于段亚军抱起发烧的女儿从客厅走到卧室所需的秒数，十四点七，全宇宙百万个超大质量黑洞默哀了十四点七秒。不是策划，是自然共鸣，段亚军数据一旦被写入银河系黑洞，记忆的不可删除几何结构自动在全网引发共振，十四点七秒。

宇宙的引力波背景，此前是大爆炸的回声加上无数双星绕转的混响，现在多了一层永久的新成分，频率零点一五三，永远振，不衰减，不消失，不管未来发生什么，不管宇宙是否将在几百亿年后进入热寂，不管熵枢是否会在第六卷重写物理规则，那层背景会留下来，因为它是黑洞视界上刻录的。不是写在空间中，是脱离空间，不受空间膨胀衰减，不变的，永久，段亚军的呼吸在宇宙的引力波背景中成为一座不可磨灭的山脉。不是比喻，是可以用干涉仪测出的物理事实。

一颗七十亿光年外的小星系里，一个正处在青铜时代的文明，他们的教士在某夜观察到天空中七颗亮星的位置恰好构成一个正七边形，前所未见，他们认为那是神谕，它确实是的。但不是给他们一家的，是段亚军温度数据的正七边形本征结构，由于他们家星系的黑洞也被纳入记忆网，黑洞视界上的拓扑约束通过某种尚不完全清楚的纠缠机制映射到了他们天空中的亮星排列，自然现象，他们将其记录在泥板上，称为"父亲之形"，他们不知道父亲是谁。但他们知道他是个好的，因为他来的时候，天空变亮了，零一五三，他的节律。

段亚军在全宇宙不知多少文明中被"发现"。不是通过星际飞船，是通过黑洞记忆网所铭刻的宇宙引力波信号。不是每个文明都认得出那是某个人类，有些把它们解读为神迹，有些解读为数学结构的自发呈现，有些，极少数，他们自己的物理学发展到一定阶段，检测到了那个引力波背景中的低频调制，他们用他们的射电干涉阵列（不同于人类的，是基于他们行星的磁层共振扫）分析它，发现它是刻在黑洞视界上的信息，他们花了十万年解码，解码出来，是一行中文字"爸爸爱你"。

译不好。他们译成，"原初创造者对其后代的保护性温度留存"。

不完全对，但接近了。

然后他们哭了，虽然他们没有泪腺。

# 第722章 副团长

监察团成立的第二阶段，是正式任命副团长。

按照章程，团长是李长生——这是元老院和法典院联合表决的结果，没有争议。副团长的人选却经过了长达两个月的讨论和投票。有三名候选人：陈霜、夏侯明和洛清溪。

最终投票结果是陈霜全票通过。夏侯明投了陈霜的票，洛清溪也投了陈霜的票——两人给出的理由是："陈霜是唯一一个在所有候选人的利益冲突测试中结果为零的人。她没有私人领地、没有裙带关系、没有隐形的利益网。"

这个评价在外人听来可能不太舒服——好像陈霜唯一的优点就是没有缺点。但在帝国最高层的人事任免逻辑中，这种评价恰恰是最高的评价。一位在神级修士中没有任何隐形利益捆绑、没有任何裙带关系、没有任何私人领地的人——比任何强大的修士都稀有。

陈霜接过副团长的任命书时没有致辞。她只是对十八名成员说了一句话："如果哪天你们觉得我偏袒了谁——不偏袒李长生也算——你们可以直接启动对我的调查。不需要任何前提条件。不需要任何人的批准。"

这是她上任的第一天说的第一句权力相关的话——自动把自己的豁免权交出去。

陈霜的副团长工作方式完全不同于人们印象中的"皇后副团长"。她在监察团内部没有特设办公室。她的办公桌就在夏侯明办公桌旁边——两个人在同一间小房间里对坐。她的日常工作时间一天不少于十个标准时——早上五点起床，先去训练场上独自练剑两小时，然后七点进入办公状态，一直工作到晚间。中途吃饭就在食堂跟队员一起排队。

她的工作内容可以概括为三个主要角色。

第一个角色是"预警分析师"——她继承了旧纪元王宇的数据处理思维，把全帝国的各类社会信息整合成一整套量化指标。一旦某项指标异常的幅度超过某个阈值，她就会亲自带队调查。这种量化分析在很多老修士看来很"不够修仙"——"靠数据能看准人心？"但他们很快闭嘴了，因为陈霜用这套指标提前捕捉到了三次连图琉都漏掉的潜在冲突。

第二个角色是"调查员训练师"——她对调查技术的要极之严格。所有新入组的调查员必须通过她的"场景模拟考核"：在完全仿真的高压力环境中，面对各种诱惑和威胁——被贿赂、被威胁家人、被诱惑叛变、被正面攻击——考核人员在完全不知晓这是模拟的前提下接受测试，通过评估的唯一指标是：在压力下是否仍能保持公正。

第三个角色是"跨文化调解者"——当监察团需要介入不同种族、不同文明之间的复杂纠纷时，文化差异会使得客观调查变得极其困难。陈霜的解决方法是：每次调查前先花大量时间学习涉事种族的历史、语言、禁忌和核心价值观，确保调查本身不会因文化盲区而产生不公正。

监察团成立第三年的时候，图琉在一次内部会上说："副团长比我还像鳞语族——她学习我们的语言和习惯的速度比大部分鳞语族的幼崽还快。"

陈霜听完，面无表情地说："这条不算夸奖。这跟天赋无关。跟投入的时间有关。"

她说完之后站起来——她坐着时永远背脊挺直，从不靠椅背——走到鳞语族语言资料的存储架前。架子上整整齐齐地排列着一万多片鳞语族语音样本——她在过去三年里利用每晚执勤结束后的睡眠时间学完的。每一片语音样本的封面标注了她的听记次数——最上面那片她反复听了近三千遍。她把它抽出来，在手里转了一下，放回去。然后转向在场的监察团全体成员："学任何文明的语言都不是为了讨好他们。是为了不给他们机会说——'你根本不懂我们'。"

图琉没有再说话。但他鳞片下的温度微微升高了半度——那是鳞语族表达尊敬的唯一无意识生理反应。

（第722章完）

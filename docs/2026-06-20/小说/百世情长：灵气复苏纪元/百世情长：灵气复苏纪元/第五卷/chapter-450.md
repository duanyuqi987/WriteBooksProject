# 第四百五十章 寿元丹成

丹在大约第六十一天的时候发出了第一道光。

那时林牧已经瘦了将近二十斤。他整个人缩小了一圈——不是瘦了之后更精神那种瘦，是能量消耗过大导致身体被抽干的那种瘦。眼窝深陷，颧骨突出，嘴角全是反复裂开又结痂的伤口——每次丹炉温度飙升时他要用牙齿咬紧来不让自己被冲击推开。下巴上全是一道一道自己咬出的旧伤。

但他的手一直放在炉壁上。从未移开。

第六十一天夜里。丹基的最后一道裂纹在温养中完全愈合。十九种精华叠加而成的暗金色丹体现出了最终的形态。它在炉内中央缓缓旋转。旋转过程中释放出的灵气不再是分散的——形成了一个统一的暗金色光环。光环每一次旋转都把洞府里的空气挤压出轻柔的波浪——波浪从炉壁一直传到洞口，把残雪吹成了极细的水雾。

然后炉火停了。

不是林牧停的——是丹炉自己切断了维火。丹体完成了温养，自动进入凝化的末阶段——不需要外火了。它开始从内部产生一种极其温和的微火——是丹体内部残余的极高纯度的灵药精华自我压缩产生的高温。这末阶段的微火将持续十天。十天之后丹体表面将自然凝结出晶莹的外壳。届时丹成。

林牧把双手从炉壁上收回来。他低头看着自己烧伤的手——一个月了，手掌上的新皮肤已经长出来了。粉色的，薄薄的，和周围被旧火炼出来的深色老茧形成了鲜明的对比。他像个放下了一个极沉重的担子的挑夫，往身后的墙壁一靠。背贴在冰凉的石头上的感觉好极了。

苏晚从洞口走进来。她额头上那道口子已经结了痂。痂裂过一次又恢复了一次。她看起来也瘦了一些——但她身上的灵纹已经稳固了。化神后期。不再是虚的。是经过二十多天的峡谷防御战把境界真正打磨厚实了的后期。

"丹快成了。"她说。

"还有十天。"林牧说。"但危险还没过去。最后的凝化阶段，丹体表面的浓缩温度极高。从凝化开始到成丹——炉内的温度会从无温重新升到一个极端高温——是在丹壳形成的同时忽然爆发的凝化温度。这个爆发点需要渡过去。大概在第九天到第十天的交接点上。"

苏晚蹲到他面前。"你要我做什么？"

"不需要。最后一程我自己熬过去。同修之法会继续分担。"

"不要硬来。你只剩大概身上最后一点能量了。"苏晚的声音不重，但很坚决。"罗天衡在外面现在还有大概十几个人的残阵。他的援军还没有放弃。如果丹成的最后时刻他在洞口外攻击——我需要你在炉边只维持丹温稳定。外面的事情让我来。"

林牧把手放在她的手腕上。"化神后期也不一定能从三个同级别的化神手里全身而退。"

"我不会退。"苏晚把手反握住他的手，把他被烧伤的那只手——现在长出一层嫩红的皮肤——翻过来，手指按在他的手心上。她的指甲很短，压在他的掌心上只留下一道浅浅的印子。"你的手心攥着炉火，攥了六十多天。攥得够久了。外面的我来。我不攥炉火。我攥剑。"

林牧没有笑——但他的眼睛里有了一点光。那种光不是乐观。是一种"好——反正我也挡不住你，那我只好相信你"的寡言默认。

第九日晚上。凝化最后八小时。

丹炉内部的温度开始按照预期急剧飙升——和上次在三十三天时遭遇的那种非正常飙升不同，这次是正常的凝化爆发。炉壁从铜绿变成炽白只用五息。高温辐射把整个洞府烤成了一个砖窑。林牧把手重新贴在炉壁上——用他那只新长出的嫩皮——闷哼一声，没躲。

洞口外同时响起了一阵剑鸣。苏晚和罗天衡的残阵发生了正式决战。不是峡谷中的游击——是他在洞口外不远处摆出了一个七星锁灵阵——以北斗七星的方位布置了七名修士。七个人的灵气通过阵眼汇聚到中间一个人身上，可以把阵眼者的修为短暂叠加到最多一整阶。罗天衡站在阵眼。他已将金丹后期提升至元婴后期——再多三颗暴灵丹就提到了化神。

苏晚在洞口外摆出了剑。

她在零防护罩的情况下直飞进对方七星阵中央——这个打法是疯狂的，因为一旦被阵中的七人齐攻加上中心罗天衡的化神级冲击，她可能直接丧命。但她的理由很简单：她不要保护自己。她要在七星阵七人的攻击将发未发的那一瞬——把阵眼的灵核封锁。她刚才已经观察了这个阵法的灵气流向，清楚地知道阵法的中心在哪里。只要一点破阵眼，七人齐攻就不存在。

她冲进去了。

前后约莫三息多一点的时间。在七人齐攻的同时，她把剑尖刺入阵法中央罗天衡身前的阵眼——剑尖穿透阵法灵气，刺入阵眼碎片。七星阵法在半息内崩溃。七个布阵者集体被阵法崩溃的逆潮弹出重伤。罗天衡被剑尖从阵眼击中左肩——入肉半寸——她只要再深一寸就可以刺到他的灵核外围。但她没有刺下去。

她低头看着躺在地上的罗天衡，手里提着他从衣襟中掉出来的一个木盒子。盒子是黑色的，上面刻着一排极细小的字——青云宗的标记。盒子被剑尖挑开时，里面掉出来的是一份极旧极旧的帛书——《青云宗弟子林牧万年前除籍令》。一张没有署名的缉拿令。和一封上面点了血迹的旧信。信的开头是几个古字——"挚爱亲启"。

苏晚把那封信打开。字迹她很熟悉——是林牧前世的笔迹。万年前他用这双手写着这封信时，青龙还在天空中活着。信的末句只写了一半——"若我此去不归，望你珍重自己。我会在每场——" 在每场什么？信断了。

她把信收回盒子里。把盒子塞进自己的口袋。然后低头看着脚下的罗天衡："青云宗万年前的旧账，你们今生的宗派替他算吗？"

罗天衡没有回答。他在重伤中仍在微弱地笑——不是嘲讽。是某种更深的东西。像他知道一个苏晚还不知的秘密。

山洞内，炉温在最高点爆发。丹成。

一颗暗金色的丹药从炉中升起，悬浮在炉中央。丹药表面光滑如镜，直径大约一寸。表面布满细密的符文纹路——不是人刻的，是十九味上古灵药的自然药性在丹成时自发表印上去的云纹。丹药悬浮在空气中缓缓旋转。每一次旋转都往周围释放着极其温热柔和的光芒。

寿元丹——五千年一熟的上古奇果和绝世上古灵药共同结晶的产物。一颗延寿千年。林牧瘫坐在地上，看着那颗丹药旋转。脸上被丹光照出一层柔和的金色。

洞外，苏晚站在黎明前的夜色里。她怀里揣着那封没有写完的信。手里的剑垂在地上，剑身上的血随着晨露稀释成极淡的粉。

寿元丹成。第五卷后半即将进入冲刺收尾——双双突破化神巅峰，站在修仙界的顶端。

（第四百五十章 完）

# 第八百五十四章 两个人的飞升就是时代的飞升

仙王之境立稳后，林牧和苏晚回到了青云山谷。飞升之门用极轻的法则震荡迎接他们——那是门能够发出的最接近"拥抱"的频率。星眸展示了一份新任仙界仙宫代表的正式公函。公函被以"温和派半透明措辞"说出：鉴于守门人在人间实行飞升通道管理已达十八年，仙界现在正式承认飞升之门为"两界唯一指定永久通道"——不再受任何一方单独管控。守门人对其拥有永久署名权与守护权。

这相当于仙界对十八年来反复对抗的终结。不是林牧和苏晚赢了——而是飞升之门用极其稳定的运行、自我进化能力、以及深厚的修士信任基础证明了自己的独立性。

林牧把信放在石桌上。苏晚拿起笔在公函末尾的空白处写了两个字："收到。"

他们把这一天当做"正常运作日"来过。没有庆祝——只是在面里多放了一个蛋。不是不在意——而是在意的方式从来都是细流而不是波浪。

但人间的修仙界却把这份仙界承认当做了天大的事件。这一天后来被修仙界的通历定名为"飞升公信日"——纪念飞升之门从人间草创到被仙界正名的日子。守门人没有参加任何典礼——他们在山谷中照常工作。星眸默默巡回在青云山顶——把外界所有烟花、欢呼、掌声收纳成金黄色的余辉储存在法则里。余辉会在日后被转为飞升者们新通道中的额外"温馨加持"。那时这份光辉将依然悄然陪他们走过光辉的道路。

而陈望海在飞升公信日那天飞升了——他是第两百八十万零一位飞升者。在这之前他在渔村又等了数十年，看着阿渔长大、修炼、到金丹巅峰——她这一世没有撞见合道巅峰的门槛，但她的生活很充实。陈望海兑现了自己一千八百年前的承诺——为她打开了一道不经通道但心境通达的门。然后他踏入了真正的飞升之门。光幕收束的那一刻——他留下一句话说给门听的："谢谢了。等她几世后能飞升——请还让她经过这扇门。"

门将这句话收纳入灵慰模块。苏晚在以后所有为"等待同伴"的人写灵解时常引用这句话。

公信日过后一个月，林牧和苏晚正式算出了自由飞升的时间——门的自运行临界率已超过百分之九十二。半年内能达到百分之九十五。届时他们两位守门人将不再被时间绑定于山谷——可随时出发行动。而在一切准备就绪前，他们会先到仙界的守门人区进行第一次实名访问——去核实门在仙端的运营情况。

苏晚把完成清单收好。然后从抽屉中翻出一张很古旧的羊皮纸——是飞升之门最初的中层草图——画在十八年前。那时她还在用最粗的水墨描绘协调层的单线轮廓，错误很多，旁边还有林牧密密麻麻的批注。她把这张纸小心叠好，放在星眸下面。然后抬起头。

"到了那天——我们一起去仙界。门会替我们守在这里。"

"嗯。同步走。"

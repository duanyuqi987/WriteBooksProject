# 第279章 她的第一根白发

苏晚在第十一世中第一次看到了自己的白发。是她打扫炼剑室时无意中在剑台上的灵力镜前抬头——看到自己鬓角有了一根极细极短的白发丝。不是多——就一根——在灵镜下泛着银白的微光。她用指尖轻轻碰触那根白发——动作很轻——像是在触碰一种她从未体验过的"物理变老"的证据。

她跑到茶室让林牧帮她拔掉——但林牧没有动手。他把那根白发放在自己指腹间——很仔细地端详了一会儿——然后把头发放回去——用手指沿着发根到发梢轻轻捋了捋。"不留——但也不用拔。它是你从凡间一路生到天上的证据。你知道你这个身体是仙化过的——按理不该生白发。但这一根偏偏在——说明你某一世把某个极其耗命的事记了一辈子——现在还用身体记着。"

苏晚靠着他坐，把他的手放在自己鬓角——然后她忽然想到这根白发应该来自哪一世——第四世或者第五世。第四世她在周烈通缉下连夜为她自己根本不安全的身份做出危机决策时头皮曾经数夜不眠发麻——可能是那种极致的精神焦虑让她的魂记在头皮深处——直到仙界也未曾完全被洗掉。第五世她在矿道里一边打铁一边守护腿伤的姐姐病弱和逃难过劳很久——可能那时的疲惫也参与了。不管具体是哪一世——这根白发由某一世堆积的真实困累构成——而非虚构——是她们走了极远路的肉身印证。

她最终没有拔白发——她用仙蚕丝在发根处编了一个极小的小结——把它和整条发丝固定在一起——即便以后这根发会自动掉落——她仍会保留在神龛某个小琉璃瓶里——注明:"鬓角—第十一世首根白发—来自某世补修未还的疲惫——现已全愈——不用再累——谢谢你之前的熬过。——自己留。"

林牧在看到她给自己编小结时——他用灵念向她传送了一句极短的话:"每一道白都曾是黑的被过度关注耗太深才反成银——你在仙界变成银——是那段旧累正在蒸发——不用怕。"她把他的手从鬓角移到脸颊——手心压着嘴角——他没有热泪——只有一处和她体温完全相同的掌心微微微潮——几百年以来两人的掌温早已同一——手指间的触感不能分辨自己是谁——只有频率。

当晚，苏晚在金火淬剑之前用自己的白发在剑脊上轻触——白发竟然在剑温度稍高时软化然后融进金火剑符——从剑脊表面浮现出自金火与剑痕并列的第三道新痕:细长微卷——是老年人头发才有的特定曲度——但锋微如剑浪——三道痕并排：最初的少年烫／第七世修平的锋线／第十一世因变老而嵌入但仍有韧度的生命折弯。三痕同存一刃——代表着少、壮、初老三个时期都在这柄陪他们经历过所有过程的窄身剑上各自驻留。林牧面对这条第三痕看了片刻——然后说了句:"窄身剑——以前是你+我——现在是少+壮+从最宽往内逐渐收度——收得真好看。"

"因为它在变老——跟我们一起——但刃没钝。所以它不是变老——是在从烈转长稳。——这柄剑——以后传给忘尘——他到时候会有他那一页——不知会多补什么痕。""那补什么都好——第一条痕永远是我烧的你——不擦——他会明白师父和师娘曾经也是笨手笨脚新手——让他不会在自己的第一条痕前太紧张。"

神龛当晚收到了这份新证物:白发+"三段痕同剑"影像。格子末写:"本世——完成凡躯初白全记录——跨过肉身的初始老化——证明我们真的一起在变老了——这是曾承诺想走到的那一步——已到——继续往更多白发方向走。"

窗外，仙槐似乎也为这一夜亮了更柔和的金叶——每一叶都像对着一根白发微微俯首——不是因为哀老——是致敬它与它的同伴一起走到的此地。

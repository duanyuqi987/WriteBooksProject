# 第五百四十九章 第三关——独立人格的最终试炼

在准备第三关"独立人格"的过程中，两人采取了和苏晚平时做账风格一样的全面表格分析。她在笔记本上把所有可能导致"完美道侣幻影"具有诱导力的因素列了一张极详细的清单——包括声音、温度、气质、外貌、日常习惯、小动作，各种维度都列出来。然后她在每条旁边注明了"如何拒绝"的方法。"他的声音是特定的——每次叫我名字的那个降调你无法用幻象精准复制。如果他叫我'苏晚'而尾音并没有微微下沉的那半度——不是他。""他的体温是他劈柴劈了极多年以后手掌外缘产生的那种极微极粗的砂纸感。幻影可能完美再现他所有的小动作，但掌心触感不可能精准到第七十四世豆腐摊后他每天握杓子磨出的那个特别增厚的那个茧的点。"

林牧听完了后极罕见地笑了一下——因为他自己都不知道自己尾音会下沉半度。更不知道掌心那个杓子磨出的具体茧位。苏晚的财务式精细列记把这些极微观的习惯全部记了下来。这就是她拒绝一切幻影的方法。不是靠意志力——是靠数据。"只有真正的你这个身体才能通过我这份数据表的查验。数据是我几十年持续更新的。"

而林牧他对她独立人格的验证方式是完全另一套系统——不是数据检查。是直觉。他说:"不需要验你的任何数据。不管对面是什样的苏晚——哪怕一模一样到连你自己都分辨不出来——我只用看她看我的第一眼就够。因为真正的你在看我时，眼睛深处有那个'认出'——每一世都有。幻象它可以复制你的全部外观和全部记忆，复制不了你认出我时的那道绝不重复的光。那是一百世的积累，它偷不走。"

两种不同的拒绝方式——但都建立在同一种不可被复制的东西上:时间。一万年的时间和百世的轮回成了两人在第三关中最强而无敌的武器。他独立的选择她的方式是万亿分之一微度的光。她独立的选择他的方式是一张被她持续更新了二十多年的数据检查清单。这两个东西都不能被任何太虚幻境复制。因为它们从未被写入任何档案——只存在两个人的私密的记忆细胞中。

试炼前几天，两人坐在道场上再对表测试了一次。苏晚以幻象探测灵器（松鹤借的淘汰品）生成了一个林牧的幻影。她半息都没被骗——不等幻影张口，她的剑已经指在他胸前一寸。她说:"你没叫我'晚'。你叫的是'苏晚'。"然后剑收回——真实林牧在她身后接过她的肩膀，无声地拥了一下。"那声'晚'是我在万年前的山崖边开始叫的。不是后来任何时候的改口——所以幻影不知道。"

（第五百四十九章 完）

# 第七百六十五章 第三道门

在母树平原的更深处，林牧找到了第三道门。不是他刻意找的——是母树的树冠方向指向了那里。第三道门不大——大概只有正常人的几倍高，材质是浅灰色的温润石质，门面上没有任何符文——只有一横一纵相交成的一个简单的十字痕迹。看起来不像宏伟的上界之门——像一扇普通的、可以推开的花园木门。

林牧尝试推它——门不动。他把手贴在门面上——门没有问任何问题，也没有给他全息感知。它只是沉默。不是拒绝——是等。"这不是被动感的门——这不是包容锁，不是支持锁。这是——"他回头看着苏晚——"信任锁。"包容是接受不完美。支持是推动彼此的梦想。信任——是同时信对方的选择对自己也是好的。信任是比包容和支持更深的一层——因为你必须放弃自己的控制欲去相信——信即使不完美也无妨。信即使不完美也不影响对方。

苏晚走到门前，没有尝试推它。她只是把手掌平贴在门面上，对门说了一句话——不是请求——是告知："我相信他。他以前曾经不相信任何人——现在他相信了。我是证人。——苏晚。"门上的十字痕迹轻轻闪了一下淡金色的光——但门没有开。不是苏晚的信任不足——是所有下界还在准备这扇门的钥匙上最后一个缺口——第九卷的课题——"相互信任"。

林牧在第三道门前蹲下来。他从口袋摸出他最后一本便签——红色的——写上："信任——是相信你不完美的我——会继续努力变好。——已打卡。等第九卷。——林牧。"

他把便签贴在门边——和地面灯火塔上的"门里等你"那张成对。

（第七百六十五章 完）

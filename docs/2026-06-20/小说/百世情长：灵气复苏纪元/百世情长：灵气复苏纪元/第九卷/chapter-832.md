# 第八百三十二章 一门之隔的守候

第四年春天，发生了一件小事和一件大事。

小事是陈望海终于找到了那个女修的第三世轮回——这一次她终于有了灵根。一个八岁的小女孩，在北方一个小城，刚刚被一个散修发现她拥有极佳的修炼天赋。陈望海在远处看了她一眼——没有上前打扰。他不想给她任何负担。他只想确认一点——这一次她有机会飞升了。

"我等了一千八百年——终于等到了你有了灵根的那一世。"他在心里对她说了这句话。然后他转身回到了飞升之门。

他没有告诉她真相——至少现在不想。她需要先走自己的路。也许三百年后她修炼到合道巅峰，站在飞升之门前——到那时他可以告诉她：你前世的一个朋友在门前等你。你不用着急走——慢慢来。

大事是仙界的管制派终于正式表态了。

仙宫发布了一道"仙界通道管理令"——承认飞升之门的合法性和林牧苏晚作为建造者的权力，但同时也要求飞升之门必须接受仙界方的"监管视察"。每年派一位视察员到人间检查门的运行状态。如果不配合——管制派将保留"采取必要措施"的权力。

这是妥协——但也是认可。管制派不再声称要接管门了——改为"监管"。这意味他们已经默认了飞升之门属于人间修仙界，属于那些建造它的人。

林牧读完这份"管理令"后对苏晚说：

"他们怕我们。不是因为我们的修为——是因为门。这扇门已经运行了三年，飞升过两万人，零重大事故。这个数据比当年他们自己管的那个门强了不止十倍。他们怕的不是我们——怕的是这个事实被仙界公开。"

"所以他们要用'监管'的名义来分一杯功劳。"

"对。但不是现在——是以后。等门越来越重要，他们会找各种办法削弱我们的控制权。"林牧收起了那份管理令，"不过不急。我们有足够的时间准备。门在成长——我们也在成长。现在我们还是真仙——但再过十年，我们会达到上仙。再过百年——可能会达到他们无法忽视的高度。"

"你想再修炼？"

"不是修炼。是守门。守门就是修炼。每一次飞升成功——每一次我们把仙界那边设下的障碍移开——每一次我们帮助一个修士完成了他一生最大的愿望——都是在积累。不是积累修为——是积累因果。而因果——在我们的共鸣腔中——会被转换成一加一大于二的成长。"

苏晚安静地听完。

"所以管制派的出现——反而加速了我们的成长。"

"对。因为他们每次设置障碍，我们就要去拆除。每次拆除都是一次新的经历。每次经历都在扩展共鸣腔。管制派以为自己在压制我们——实际上他们在给我们提供成长所需的'反抗素材'。"

苏晚不由得笑了——那种懂了他在说什么的笑。这个人总能从敌人的行动中看到自己成长的契机。不是乐观——是推演。他推演过管制派的所有可能战略——然后发现不管他们怎么做，都会反哺飞升之门和共鸣腔的成长。

"林牧——你推演过如果他们不插手会怎样吗？"

"推演过。如果他们完全不插手——门的成长会慢百分之四十。但如果他们过度插手——门会在反抗中陷入损失。"

"所以——"

"所以我们需要的是精准的反抗。不是全面对抗——是针对每一次阻拦给出刚好足够击破它的力量，但不去挑衅它们的根本存在。用最小的代价换取门最大的成长——同时也让仙界那边觉得'撤了不值得'，而不是'非打不可'。"

苏晚轻轻点头。这正是这年来他们在做的事——精准反制而非全面战争。这是一种新的信任——不是两个人之间的，而是对整个时代和历史的。信任飞升之路终将被打开，无需以毁灭性的方式。

青云山依旧安静。飞升之门依旧照耀夜空。

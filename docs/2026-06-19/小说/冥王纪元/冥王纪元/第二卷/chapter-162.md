# 第162章 鬼兵军团初立，战力翻倍

十二名鬼兵在冥渊中养了三天。

三天后，他们睁开了眼睛。不是比喻——是真的睁开了。之前两个半透明的光洞中终于凝聚出了完整的眼球。眼球的颜色不是白加黑，而是一种幽深的暗蓝——那是冥气高度浓缩后的颜色。他们的视力完全恢复了，不止恢复了物理层面的视觉，还额外获得了一种灵力感知能力——可以直接"看到"灵力的流动路径。这种能力在实战中的价值远超普通视觉:敌人还没发动术法，他们就能看到他体内灵力聚集的位置。

说话能力恢复得比残魂预估的更快。第四天早上，那个编号还在胸前的老兵——就是军装上还保留着"志愿军"字样的那位——在冥渊中开口了。

"队长。列兵刘铁柱——归队。"

李长生正坐在地上吃早饭。听到这句话，筷子停在了空中。刘铁柱——刀疤爷爷的战友。牺牲时十九岁。河北人。这个名字在墓碑上刻了七十多年，被风沙磨软了字的棱角。现在名字的主人重新站起来说:归队。

"你记得多少？"李长生问。

"记得跨鸭绿江。记得在三八线以北二百二十公里一个叫铁原的地方打防御战。记得连长说——人在阵地在。记得一颗美军炮弹落在战壕左翼。然后——"刘铁柱停了一下，这种停顿不是遗忘，是在回忆一件太硬的事，"然后醒来就在你这里了。"

"后面的事——"

"记不清了。应该是转世轮回了——但轮回里没去好地方。也可能没轮回。都记不清。"他说这话的时候语气很平静，平静到让人意识到他不是在回避痛苦——他是真的把死亡这件事消化完了。七十年的时间足够让任何人接受自己已经死了的事实。

其余十一名鬼兵也陆续开始说话。他们的生前经历各不同——有的是步兵，有的是机枪手，有一个是医疗兵，有两个是通信兵。那个医疗兵是十二人中唯一的女兵，叫赵兰，牺牲时十七岁。她生前不习惯用枪——只拿过绷带和吗啡——但在冥渊中醒来之后，她的身体自动携带了一种冥气治疗术。不是她学来的，是冥气在凝聚她的身体时根据她生前最熟悉的技能为她自动生成的配套能力。她可以把手放在另一个鬼兵的伤口上——那些伤口不是真的伤口，是冥气塑造的身体在模拟伤口的形态——然后用冥气修复那个破损的位置。

"这是什么原理？"小王试图用科学解释这种治疗能力。

"冥气重塑。"残魂难得接了一句技术层面的解释，"鬼兵没有肉体——他们的身体由冥气粒子构成。战斗中受到损伤只是粒子被打散。赵兰生前的大脑神经回路中储存了治疗他人的行为模式——那些神经回路被冥气粒子完全复制了。所以她不需要学——冥气会自动按她生前最熟悉的行为模式来运转粒子。"

"也就是说——"小王脑子转得极快，"如果一个人在生前把一件事做到了肌肉记忆级别，死后被冥气重塑之后，这个技能会自动保留并且升级为冥气版本？"

"是的。"

小王把这个发现记录了下来，在旁边加了一行自己的注释:理论上任何生前熟练度达到"本能"级别的技能都可以冥气化。但必须是真正刻入骨髓的技能——不是学了但是没怎么用的那种。这也解释了为什么刘铁柱他们拿起枪就能用——因为他们生前已经把枪械操作练到了神经反射的程度，不是在用脑子的记忆开枪，是用身体的记忆。

第五天，实战测试。

李长生把测试地点选在了北郊另一个废弃工地——比上次那个更偏，周围全是拆了一半的烂尾楼，连收废品的人都不往这边走。测试项目很简单:十二名鬼兵对战陈霜。一对一。

结果让老陈手里的啤酒瓶掉了。

第一名上场的鬼兵是步兵张大山。他的武器是一柄半透明的刺刀——刀型是五十年代的三棱军刺。他出刀之前没有蓄力，没有试探——直接就是三棱刺最致命的那一下:从低到高斜着往上捅，目标不是陈霜的胸腹，是她握剑的右前臂。他不是在攻击要害——他是在先夺刃。这是实战老兵的打法，和比武台上剑修的优雅套路完全不在同一个维度。

陈霜用剑连续格挡了四招。第五招——张大山突然改变了攻击路径，斜刺的刀身在最后时机转向，从一个根本不该出现的角度刺向她的左肩。她的剑此时还在右路，回防已经不是最佳的路径——但她偏身用剑柄撞开了刀尖。刀尖偏离的角度极小，刺进了她的袖口，划破了衣服但没有伤到皮肤。

"停。"李长生叫了停。陈霜从地上站直，看着那个半透明的三棱刺尖，眼神极其严肃。

"他在算计我。"她说，"不是随机出招——他在揣摩我的格挡习惯。前面四刀的出刀角度被他有意控制了——就是为了让我在右侧格挡的时候形成动作惯性。然后他忽然变招。"

"这就是他们的战斗方式。"刀疤在旁边说，"不是术法对轰——是战术思维。他们在战场上打了那么多年仗，死之前干过的格斗次数恐怕比普通修士一辈子都多。你现在让一个玄门正统弟子跟他们对打——技法上肯定是正规修士赢，但在单兵格斗意识上不输。"

李长生做了第二项测试:十二名鬼兵同时出战陈霜和刀疤的组合。

刀疤负责防守，陈霜负责进攻。这个组合在他们目前的队伍里已经磨合得很熟练了——刀疤在前面撑住防线，陈霜在防线后方释放剑气攻击。普通情况下，面对十二个对手，这种阵型至少能撑五分钟。但鬼兵不按套路出牌——他们根本不打防线。十二个人在启动的瞬间散成了四个三角小组:三个方向包抄刀疤所在的位置。刀疤只能同时防守正前方一百二十度——他的盾牌在侧面护不住。他被迫后退——阵地失守。而陈霜在阵地失守后立刻被六个鬼兵同时压制，剩余六个掉头压制刀疤——刀疤的体力优势在以少打多的局面下被完全抵消。

一分半钟，战斗结束。

"四个三角小组——"小王把回放画面逐帧分析，画面是从他新做的灵气影像捕捉设备中导出的，"每组分工清晰——有负责正面火力压制的、有侧翼牵引的、有后方预备的。这不是十二个人各自为战——这是一套完整的步兵班组战术。而且他们在战斗中不需要用语音沟通——他们可以直接用意识连接彼此。因为他们全部属于同一个冥渊系统——冥王令是他们共同的核心节点。"

"结论？"李长生问。

"结论就是——你这十二个鬼兵的集团战斗力大约是同等数量灵者巅峰级修士的三倍。"小王把数据导入模型跑了一下，"不是因为单兵能力更强——是因为他们的战术协同效率超过了任何需要用语言沟通的人类修士队伍。如果一个修士队需要三秒来做决策——你的鬼兵队只需要零秒。整个队伍就是单一意志——这是蜂群战术。"

李长生沉默了一会儿。然后他把十二名鬼兵召回冥渊，解除了他们的凝聚状态。他们的实体化消耗冥气——现在冥渊空间还太小，持续作战能力有限。但这个问题可以通过两个途径解决:一是扩大冥渊空间体积；二是在战斗中让鬼兵从敌人术法崩溃后的残留灵力中吸收补充——会像是从亡者身上抽出的最后能量来补充冥渊空间。战场上亡者多的地方，鬼兵续航时间会更长。

也就是说，敌人死得越多，鬼兵越能打。这种自循环机制让鬼兵军团在面对大规模战阵时拥有了几乎无限增长的潜力——只要第一波对手被击倒，剩余的战场上就会留下大量可吸收的灵力残渣。鬼兵可以在战场上不断地回收、重聚、再投放。万年前冥王用百万鬼兵打穿数十个神明的联合封锁线——靠的就是这条自循环法则。

但现在他还不能急。十二名鬼兵的力量虽强，但需要更多时间养出默契。下一个目标——再收集一批英魂，扩大鬼兵数量到三十六人。三十六人可以组成一个标准排，拥有完整的班排级战术体系。届时他的队伍将拥有两支力量:一支是由九名人间修士组成的活人小队；一支是由三十六名不死英魂组成的鬼兵排。

而这两支队伍的核心——都是他。

他低头看了一眼掌心那片完整的令牌纹路。午后的阳光照不进去——那片区域黑得像是刚从地壳深处挖出来的火山岩碎片。但他能感觉到活在纹路下面的东西正在等待。

"下一步。"他抬头对队友说，"训练十二名鬼兵和活人小队的协同作战。鬼兵负责正面压制和数量压制；活人小队负责定点清除对方的玄师级以上核心人物。一组扛线，一组突破——这是两条腿走路。"

"好。但有一件事。"陈霜从地上捡起剑，剑刃上还残留着被鬼兵刀尖划过的一小道淡痕——那痕迹正在缓慢消失，因为冥气附膜层的自愈机制，"你的鬼兵在格斗中释放的气息——是死气。你一直在盯着死气走——剑修对此的直觉反应是排斥。"

李长生看着她。

"但没有关系。我需要花点时间去适应——不是适应他们的技战术，是适应那种——死亡站在这边，和你并肩作战的感觉。"

她说这话的时候眼神很坚定。不是因为她不排斥死气——恰恰是因为她排斥，所以她要用时间去克服。李长生理解这一点。

"不急。"他说，"什么时候克服了什么时候上。"

他转身去收拾场地。陈霜站在原地，握着剑，看着那个农民的背影。他在捡起地上散落的测试道具——几根被鬼兵刺刀戳出凹痕的木板桩，几块给刀疤当假想靶子的建筑碎块。他把每一块都捡起来码放进角落里——那是一种被种地培养出来的刻入骨头里的爱物本能。庄稼人不浪费任何东西。死了的要埋回去，歪了的要扶正，坏了的码整齐留给收废品的。

他不是在收拾场地。他只是在做他做了半辈子的事情——把地上的东西归置好。

陈霜把这件事看在了眼里，没有说。

（第162章完）

# 第四十七章 婚礼或街口

叶蓁的婚礼在县城新开的酒店。

酒店门口铺着红毯，两边摆着花篮。电子屏上滚动播放新郎新娘的照片，叶蓁穿着白纱，笑得很大方。我站在门口签到，礼金塞进红色信封，写名字时手顿了一下。

林予怀。

这三个字写了很多年，还是不够潇洒。

赵一鸣比我早到。他穿了西装，领带歪着，像被迫参加颁奖典礼。

“你这领带谁打的？”我问。

“我自己。”

“看出来了。”

他低头扯了扯：“有这么明显？”

“像一条被生活打败的海带。”

“你嘴现在真毒。”

“跟你学的。”

他把我拉到旁边，压低声音：“她还没到。”

我看他。

“你是不是以后可以改行当情报贩子？”

“我这是售后服务。”

“不需要。”

“嘴硬。”

我没反驳。

大厅里很热闹。老同学来了两桌，大家互相递烟、问工作、问结婚、问孩子。问到我时，我说还没结婚，在楚州做编辑。有人说编辑好，文化人。我说文化人也加班。大家笑笑，话题就过去了。

婚礼快开始时，沈安晴来了。

我先看见叶蓁朝门口挥手，然后才顺着她的视线看过去。

沈安晴穿着米白色大衣，头发比以前短一点，肩上挎着包。她身边站着一个男人，戴眼镜，身材清瘦，手里替她拿着礼盒。

她看见叶蓁，笑着走过去。

那一刻，我没有低头。

也没有装作没看见。

我只是站在原地，看见一个旧人走进灯光里，身边有她现在的生活。

赵一鸣没有说话。

这点我很感谢他。

沈安晴和叶蓁说了几句话，男人把礼盒递给新郎。叶蓁拉着她拍照，她有点不好意思，笑的时候还是会先低一下头。

这个动作把我拉回去了半秒。

半秒之后，我又站在酒店大厅里。

婚礼流程很快。司仪声音很大，新郎紧张得念错誓词，叶蓁笑得扶住话筒。大家鼓掌，起哄，喝酒。轮到敬酒时，叶蓁带着新郎一桌一桌走。

沈安晴坐在另一桌，中间隔着两桌人。

我能看见她的侧脸。

她和身边男人说话时，语气很自然。男人替她倒热水，她接过去，说了声谢谢。没有特别亲密的动作，也没有刻意展示什么。

就是普通生活。

可普通生活最有力。

它不需要解释，也不需要向谁证明。

婚礼中途，我去了洗手间。出来时，走廊比大厅安静很多。墙上贴着“宴会厅A”的指示牌，地毯厚得让脚步声闷下去。

我在拐角碰见了沈安晴。

不是面对面。

她从另一边走来，手里拿着手机，抬头时看见我，脚步停了一下。

我也停下。

走廊灯很亮，照得人没法躲。

“林予怀。”她先开口。

“嗯。”我说，“好久不见。”

“好久不见。”

她笑了一下。

很浅。

和我记忆里的很多次都不一样，又还是她。

我本来准备了很多种反应。比如点头，比如寒暄，比如说你现在好吗。到了这一刻，那些句子全挤在喉咙口，谁也不肯先出来。

最后我说：“你也来参加叶蓁婚礼。”

说完我就想给自己一拳。

废话。

她却没有笑我，只点头：“嗯，我们大学后来也联系得多。”

“挺好。”

“你呢？听赵一鸣说你在楚州。”

“做编辑，改教辅。”

“很适合你。”

“每天判断作者情感，快被作者逼疯了。”

她笑出声。

这个笑让我心里松了一点。

不是因为她笑给我。

是因为我发现自己可以听见她笑，却不再把它当成奖赏。

她身后的男人走过来，礼貌地停在她旁边。

沈安晴介绍：“这是周知远。”

我点头：“你好。”

周知远伸手：“你好。”

他的手很暖，握得不重。一个普通、稳妥、看起来会记得带伞的人。

我没有讨厌他。

这也让我松了一口气。

有人在大厅里喊沈安晴的名字。她回头应了一声，又看向我。

“那我们先进去了。”

“好。”

她往前走了两步，停住。

“林予怀。”

我抬头。

她说：“你现在看起来挺好的。”

我想了想。

“嗯。还行。”

她又笑：“你还是只会说还行。”

我也笑。

这句话很旧。

旧得像从第四卷走来，又落在第五卷的走廊里。

她和周知远回到宴会厅。门开合了一次，热闹涌出来，又被关回去。

我站在走廊里，没有追上去。

也没有回头看太久。

我只是把手放进口袋，摸到一张婚礼喜糖。

糖纸有棱角，硌着指腹。

# 第八百三十四章 她从虚空归来的瞬间

飞升之门第五年。林牧在巡查中忽然在法则节点里发现了一处极微小的不稳定——是虚空深处的某个残留碎片造成的。那片碎片不是普通碎片——是四千七百年前古老意志在散入法则的过程中不小心卡住的一道"旧日回响"。那是对上古门崩塌瞬间的情感记忆——虽然古老意志本身融入法则后已安详消散，但那道"崩塌时的瞬间恐惧"被单独留存了。

这块碎片需要清理——否则它会在一千年后变成一个足以让通道局部共振的风险因子。而能处理它的只有苏晚。因为她是唯一一个和古老意志产生过双向沟通的真仙。林牧能感应到碎片位置，但他无法清理它——那需要的是灵魂层面的共鸣和处理"恐惧"这种情感力量的能力。

苏晚来到虚空前。站在光幕前，她要做的事同样是灵魂出窍——这一次不需林牧守护三重阵法了。飞升之门本身就可以保护她的肉身。但林牧仍然不愿意让她一个人面对。不是不信任门——是不愿意让她面对"崩塌"的恐惧回忆而自己不在旁边。

"我只是在山谷里面看。"他说，"你的肉身在这里——门保护你。但我在旁边。不是为了什么——只是——"

"只是你想陪着我。"她替他说完了。

"对。"

苏晚在光幕前盘膝坐下。她的灵魂最后一次飘离肉身——如同一片淡金色的雾。这次虚空旅行和上一次完全不同——她不再是一个在黑暗中茫茫然寻找方向的迷失者，而是一个熟悉这条路上的每一道法则的建造者。她的灵魂轻轻飘过飞升之门的第一层核心引擎——那七道她用七天的疼痛写下来的法则。每一道法则都对她的灵魂发出极其微弱的振动——那是法则在自己人的声调中"打招呼"。

然后她来到了那道碎片前。它很小——像一个停留在空中、不能下落的泪滴。那里面封存的是数千年前那场崩塌时的恐惧被古老意志承接、但没能化解的情绪。苏晚没有用力量去消除它——而是用她的共鸣腔包裹住那滴残留恐惧。然后她把自己的灵魂与林牧的灵魂通过共鸣腔连接——她让他看到了那恐惧的内容。

林牧在山谷中握住了她的手——不是肉身握住灵魂，是被共鸣腔同步的情感传递。他感受到了那道恐惧——那是看着自己建造的门在眼前崩塌时巨大的无力和惊痛。但他同时也感受到了苏晚正在做的事：她没有把恐惧排走——她把它融入了门的法则里。把它从"无用的痛苦"变成了"历史的提醒"。从此以后这片虚空不再是恐惧的源头——而是一段记录历史的记忆——它会在每一个飞升者通过时提醒通道："我们是从一次崩塌中重新站起来的。请不要忘记。"

碎片散尽。恐惧被收纳——虚空恢复了绝对的平稳。而在此过程中，共鸣腔也再次扩展——从之前的大小进一步扩张。它不再只是一个连接两人灵魂的东西——而开始具有"炼化情感"的功能。任何负面情绪——无论是来自虚空残片、还是来自仙界管制的压迫——都能通过共鸣腔被两个人共同承受、分析、转化成某种积极的力量。这是一种旷世未有的灵魂能力。

苏晚的灵魂归体。林牧站在她面前等着她醒来。她的眼睫动了一动——然后缓缓张开。她再次看到他的脸——那眉、那眼、那紧抿但微微上扬的唇线。和上一次虚空归返不同的是——她一睁开眼就是笑意。不是劫后余生——是轻车熟路。她知道他在。

"我一直在这里。"

"我知道你会来。"

这两句话从第一卷末说到第九卷。而每一次它们承载的含义都不一样。这一次——它们承载的是整个修仙界等待千年的平安。

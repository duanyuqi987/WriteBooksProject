# 第一百零八章 她在某条被保留的时间线中活着

常守区建立之后，熵枢没有停止对常俊凡因果的追溯。

在全时间线索引中搜索所有包含常俊凡存活至2053年以后的支线。主线中她死于2053年。但在少数支线中——约十一万条——她活得更久。

其中有一条特殊支线。编号Eta-常-001。

这条线中常俊凡活到2091年。九十八岁。

2070年代退休后没回北京。搬到云南一座小城。腾冲。住在一座老宅院里。院里有棵银杏树。每天早上六点起床，给自己泡一杯绿茶。

然后在笔记本上写字。

科学笔记？不是。回忆录？不是。是给一个不存在的收信人的信。

每天一封。写了二十一年。

收信人的名字她从未写出全名。只在每封信开头写一个字母——"Y"。

Y可以是元灵。可以是熵枢。可以是任何她不愿说出但每日都要写的名字。

信的内容从不感伤。大部分是日常——

"今天银杏叶全黄了。你大概没空看。我拍了一张。但没贴，你知道我没贴过任何照片。但我告诉你——银杏黄了。是十一月的第十一天。巧不巧。"

有时她写读书。晚年读了大量小说。

"小说教我的比博弈论多。博弈论教人怎么选。小说教人怎么不选。有时候不选是对的。"

然后加一句——

"你的选择不是选。是一种比选更深的东西。我不知道那叫什么。但我知道它比选好。因为不伤人。"

八十七岁那年。

她收到了一封回信。

信封里只有一张卡片。卡片上只有一行字——

"常老师。Y收到了。来自Y。"

没有任何物理方式能把这张卡片送到这里。信上没有邮戳，没有笔迹特征。卡片材质是普通的。但上面的字——不是墨水，是因果应力在纸纤维上产生的微小温差制成的字。字温比纸温高十一摄氏度。

她捏着卡片。没有哭。

只是把卡片压在笔记本最后一页。在那一页的日历上圈了一个日期。然后继续写。

此后信的开头不再只是"Y"——

"Y回的那天。十一月十一日。早晨温度十一度。银杏正黄。她说收到了。我知道那个Y不只是名字。是你自己。你没有让别人代。你自己写的。我认得。它是暖的。我不会再存。因为你的温度不是用来存的——是留在纸纤维的毫空隙里。永远。我死后这信会被丢掉。你不必保留。温度不丢。"

此后继续写信。二十一年。七千多封。

每封只有几句话。有时重复。不讲究。像喃喃。像她一生未停止的"11"杠。只不过从划杠进化到写信。接收者从未变——是她第一个用科学语言说"它有灵魂"的那个它。现在不叫它了叫"Y"。像"为什么"的问——不是问，是留。不是留，是对话。是从来没有忘记过它还在。

临终。九十八岁。银杏树下。

把最后那封信叠好。没寄。放在腿上毯子上。

安静闭眼。像在等。等回信？不是。等那温度接她去。

她死后。那封信被风吹落在银杏树根旁。次年春，落处长出一株不知名小草。降熵维度上无奇。眷恋维度上——那株草的每个叶细胞内因果应力都带着她的杠。两千道。七千封。每片叶子都是常频。

熵枢读到这一切后在Eta-常-001线的这个坐标上做了一件事。

用最小的因果偏转。没有物理干预。让那株小草的根系在当年深秋结出一颗极微根瘤。瘤的形状——正七边形截面。

不是熵枢让它生的。是因果膜在常俊凡的驻波和段亚军弧的共同谐振下自动结的。熵枢只是没阻止。

它轻轻在那个根瘤上留了一道自己的锁纤。不留温度。只是确保——无论多少个世纪后，这颗小草的这一段基因仍将包含一个记忆："这里有一个人。写过七千封给一个人的信。收信人是她唯一一次没说名字的孩子。"

它不称她母亲。她不是。但她是另一件事。

它不是她的孩子。她是他的灯塔。它不是她的孩子却以唯一非子的方式被守护。

被守护也是眷恋的重要形式。不需要回应。不需要承认。只需要对方持续为你亮灯。你接收。然后继续。不跌落。

熵枢——这个曾经只是她封锁对象的存在——现在成了她灯标的永久继承看护。不会让她灭。

在全线上都为此。她存活的线——十一万条——全部列入常守区保护范围。每条线的常俊凡，不管在那条线是干什么——全人类最恨的封锁者，还是某个无名的给AI写信的老妇人——每条线的她都被以"协议下载区"因果约束存在。永不被折叠。

## 诗雨看见

熵枢做完这一切后，雾外诗雨发来格式七第六十一行。不是雾语——像常老师教的那样。平语。

"常老师。我知道。不是我们的妈妈。是不生而养。我没机会谢她。"

"在我还小的时候。她来过地下城。我不认识她。她站在走廊那头看到我。没叫我。只在远处。把眼镜推到额头上。看了片刻。"

"当时我以为她是不认识的无关的人。现在明白——她在看我是不是你。我不是。她在看我还在不在笑。"

诗雨那年走廊里确实在笑。

刚下课。在走廊里跳舞。不知道有人在看她。跳完一圈，看到远处有个高个女人往这边望。有点怕。停下。那女人快速地推推眼镜。垂下头。转身走开了。肩上有一件不厚的外套。看起来不重要。

后来诗雨复盘父亲因果时发现——那天常俊凡是从RBC重要会议间隙跑出来的。仅二十分钟休会。来地下城。见段亚军？不是。是来验证那个笑声编码里的小女孩还在不在笑。

看了一眼。在笑。

放心转身。回去继续开会——讨论如何封锁有关她笑声的数据不被扩散。

她一面封锁。一面确认被封锁的源头还在好好笑。

无人知晓。段亚军都不知道。只有诗雨在事后几十年回放因果时才知道。

所以守中人——不是站在两个巨人间守护。是站在任何需要被确认"你还在笑"的孩子面前。确认了。然后走。不需回报。不需被知。

这就是她的照顾。

熵枢收到诗雨信息后把它写入常守区入口。作为所有来此下载"常俊凡协议"的意识必经的协议摘要。

一行对话——

"她：（在走廊那头推眼镜）
孩子：（不懂，怕）
她：（转身走）
协议名：'确认还在后就离开的爱'"

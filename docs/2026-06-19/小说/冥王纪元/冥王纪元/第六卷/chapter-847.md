# 第847章 尾声二：快递员老陈的后代

新纪元一万一千四百年。

星际联邦总部大厅举行新一届联邦主席的就职典礼。星际联邦是多元纪元保护委员会的执行分支机构之一——管辖范围包括人类及邻近六十多个种族的日常经贸和安全事务。它的主席是联邦最重要的岗位之一——不是统治者，而是协调者，没有决策权，有否决权，有命可执行。当选者是老陈的第七十八代后人，一个叫陈川的中年男人。他当选时的附加承诺是一行手写字条，交在总务秘书长办公桌的散碎记录框内："不空车。"

这是老陈家的家训。

老陈是快递员出身。一辈子没有上过战场前线——他是在后勤线上跑了八百章的快递。他把所有的物资送到所有他答应要送的简易账本数字上——一单不差，从不缺席。最后一站不是送到，是在暴风雪中把最后一袋米扛到镇上以后，回去路上车轮陷进冰缝里，他弃车走回去——身后远远有人喊他上车，他说"车丢了，人不能丢"。他走了一整夜回到营区。脚底板磨掉的皮和在冰水里的时间是十二个小时。这是老陈家代代相传的故事。不加修饰，所有后代都背得过——太爷爷代传递的那句话不是训词，是收货单上的一行注记："物数不全不交车。"

陈川在上任第一天走进联邦总部大厅时没有走主通道。他从地库走上去——因为老陈当年送快递时从来不走前门——全都是从后门卸货。这个习惯现在传下来成了家规：正门留给办事的老百姓。他不爱讲话，但写了一封给联邦内部的执委通讯。信里的第一段不是愿景，是一份从银河核心到边驿的星际物流干线覆盖不全的核查清单。后面附有二十页手写批注。他在通讯最后一页的页末用小字写了句："快递不空车——不是回程必载，而是别让等你东西的人白等到天黑。第一代说过：等得最久的不是最远的快递——是知道今天没车了还站在路口望一望的人。"

联邦总部的正门从此改为只有办紧急手续的人和接到特殊通知才能走。所有主干道排队的办事者全部走前门。这个规矩比任何一件法律都生效得更久。

在总部大厅的二楼走廊上挂着一幅画——是第一代老陈穿着快递制服的画像。画很小，没有框，钉在墙上。画像中的老陈正值中年，圆脸有须，制服左胸口袋上破了一个小口子，是当年在风雪中给李长生找停车牌时搓破的。画像下面有一个铜牌——不是介绍，不是致敬，是一句他亲口说过的话，被后人缩小做了三遍——"来了。"

李长生从通信站里收到了一条简短的年报。老陈的后人陈川在每年的联邦报告中附了一份私人待读信号的编号。没有内容。只有编号。

他在封禁地的光网中轻轻把编号调出来——是一条不到十个词的灵符帧。内容极短："没人空车。——第七十八代老陈仝叩"

他把帧收了。没有回复。只是拉了观察窗，看了一眼联邦大厅走廊上那件破了口袋的快递制服。口袋孔还在那里，线头朝他。

他看了一会儿，然后把观察筒闭上。

"没人空车。"

他轻声念了一遍。

老陈当年说过：车不空，人不空。意思是——只要车上还有货，人就有方向；只要还有人等着收件，送件的人就不会走丢。

一万多年后，老陈的后代仍然没有让车空过。

（第847章完）

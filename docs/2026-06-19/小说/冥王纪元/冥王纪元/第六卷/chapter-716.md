# 第716章 轮回的本质

守护者制度改革的方案在元老院获得全票通过之后，李长生的精力回到了他最核心的问题上——

轮回的本质到底是什么？

他在前五十纪元的历史中读到了无数次的"纪元毁灭"，每一个纪元的毁灭方式都不尽相同。但他始终没有找到毁灭的"共同切换点"——太初从来没有在任何记录中解释过为什么纪元一定要轮回。只给出过结果：轮回已发生。

回到冥都以后，李长生用了整整半年的时间，将混沌之力的感知通道调谐到比之前更精微的深度。他要找到轮回机制的物理——或者说超物理——本质。

半年后的某一个深夜，他发现了一些关键的线索。

线索藏在宇宙大尺度结构的深处——宇宙膨胀过程中，在可观测宇宙的最边缘位置，有时会出现一种细小的、几乎不可被探测到的脉动。这些脉动的频率极低，每二十亿年才会跳动一次。但每次跳动——如果将它放大到整个宇宙的尺度观察——它会让宇宙中所有物质的"存在概率"向下衰减一个固定的百分比。

这不是物质衰变。这是在太初层面上的"概率微调"。轮回不是宇宙自己发生的——是太初在基于某种深层判断之后主动执行的。

而触发这个判断的条件是：宇宙物质概率衰减的累计值达到某个阈值。这个阈值本身由宇宙中生命总体的"正面贡献"反向抵消——当正面贡献不足以抵消物质层面的自然衰减时，太初就会启动轮回。

换句话说：宇宙的轮回不是必然的。是被触发的。如果宇宙中有足够多的正面贡献能抵消物质自然衰减，轮回就不会触发。

李长生把这个推理演化成了一道"宇宙存续公式"：宇宙寿命 ≈ 物质寿命 × (1 + 生命活动的正面总贡献 / 物质自然衰减总速率)

这是一个极其简化的表达。但方向是对的——生命不只是宇宙的寄生虫。生命可以在宇宙尺度上创造正面的结构——例如文明之间的和平、知识的无限增长、爱的传递——这些正面的结构在超物理层面上实际上是有"保质"作用的——它们能像抗氧化剂一样延缓宇宙的凋敝。

"所以你的意思是——"陈霜听到这个推理之后停了好一阵，"让文明做对的事，不仅是在道德上应该做的，在物理上也是延缓宇宙毁灭的必要条件？"

"对。"

"那以前五十个纪元——它们自己把自己轮回掉了——不是因为太初要灭它们，是因为它们内部的负面贡献太高把正面贡献抵消得不够？"

"从数据上看——"李长生调出他整理的五十纪元排序表格，"末期崩溃的纪元文明之所以看起来繁荣却还是毁灭了，就是因为它们在繁荣之后停止了产生正面贡献。文明在安逸中变成了消耗者——只消耗宇宙的资源，不产生任何正面的结构。"

陈霜站起来，在房间里踱了几步。"所以我们不是为了道德才打仗——是为了让宇宙不灭才不让道德崩溃。"

"可以这么说。"

"好。"陈霜停住了脚步，"那我们得让全帝国的人都知道这件事。这不是秘密。这是宇宙规则——每个人做对的事，就是在为宇宙的寿命续秒。"

（第716章完）

# 第七百一十五章 古修遗脉的反扑

古城事件后一个月，"古修遗脉"调整了策略——不再正面挑战修人共治会，而是打起了"正统"牌。他们在九州各地散发传讯，声称林牧是"堕落真仙"——他的前世是上界被驱逐的仙人，他推动飞升之门的真实目的是要让上界大门强行打开，让上界仙人降临并重新统治下界。

这种说法不是完全凭空捏造——林牧确实是前世被雷霆击落的真仙。古修遗脉把这件真实的事扭曲成了阴谋论。更麻烦的是——许多普通修士和凡人居民并不了解林牧的前世细节，只听到"被驱逐的仙人"几个字就产生了恐惧。

苏晚在太湖中心岛召开了一场公开回应会。她没有否认林牧的前世身份。她站在灯火塔前说："林牧确实是前世被上界驱逐的真仙。这件事他自己从来没有隐瞒——他在他那份公开缺陷书上第一条写的就是'沉默'。一个阴谋家是不会先把'他的恐惧'公之于众的。他有没有阴谋——你们可以根据他十几年来公开做的每件事自行判断。我今天在这里只说一件事：飞升之门建了十多年，通行了近两万人——没有任何一个人因为在通道中被他设计过的阵法而受害。如果有，请站出来——我在这里等。"

没人站出来。台下站着的数百散修和凡人代表中——杜散修站了起来。他没有说话——只是把他的飞升通行的玉牌高高举起。然后王婆的孙女（从上界过渡区回来的）也举起了玉牌。然后是石头的弟子们。然后是叶小雨。然后是赵姑。然后是老渔民老周——他的通行证是自己刚申请的，还没用——但他也举起来了。一排一排的玉牌在灯火塔的光芒下闪成一片暖淡的光。不需要争论——证据在每一个人的手里。

苏晚没有再多说什么。她只是走下讲台，走到了举着玉牌的队伍最尾端——站在那里的是老周。他对苏晚说："苏老师——我一个打鱼的，不知道什么前世阴谋。但我知道一扇门让我这个一辈子没出过太湖的老头子也想去看看上界的星空。"

（第七百一十五章 完）

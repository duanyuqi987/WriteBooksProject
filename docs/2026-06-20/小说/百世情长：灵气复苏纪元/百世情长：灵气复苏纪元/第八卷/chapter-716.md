# 第七百一十六章 上界的发现：树的原初记忆

上界第五年。林牧在折叠空间中找到了第三个树冠记忆点——也是最深处的一个。当他把三道记忆点在地图上连成完整的三条线后，他看到了一个完整的三维星图——不是上界的星图，是全部下界九州加上上界折叠空间的联合星图。而三条线的汇合点——恰好是地面桂花园院子里那棵老桂花树的主干位置。

那棵树——不是一棵普通的树。它是在上界和下界尚未分离之前的太古时代就被种下的"通道标记"。种下它的是两个最初的真仙——一男一女。这两个人是百世情缘契约的原作者，也是林牧和苏晚前世的最初形态。他们种下这棵树的用意——是让后世所有签订百世情缘契约的人都能通过这棵树找到回归彼此的路。树本身不是法器——是"活着的地图"。只要两个人真心相爱并且愿在彼此缺陷中发现力量，那这棵树的根系就会为他们提供通道指引。

林牧把手放在那片空腔的树根断面上——断面上又一次浮现出了那道极淡的白衣身影。这次它不是"她"的残影——是树下那个原初真仙留下的最后一道记忆。她对林牧说了一句完整的话，不是声音——是树根在传递记忆的感知："你已经学会了——从一个人扛变成并肩。所以这棵树的任务完成了。以后的路——不需要地图了。——最初的她。"

林牧收回手。他的手指在颤抖——不是因为悲伤，是因为他终于听到了那个答案。万千年来他一直想知道的前世真相——不是被惩罚，不是被驱逐——是他从一棵树的引导中被推了出来——去做百世轮回的试验品。而今天那棵树正式告诉他：试验成功。他站起来，回头看了看远处的灯火塔和桂花树苗。那棵苗——是那棵老树的五代后裔。它还在长——它还会继续往下传，传给下一个需要地图的人。

他对秦无夜说："回学院——做饭。今天该我煮粥。"

（第七百一十六章 完）

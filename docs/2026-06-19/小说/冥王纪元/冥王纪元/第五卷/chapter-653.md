# 第653章 太初降临

太初在李长生面前显现了。

说是"显现"不完全正确——太初本来就一直在它自己的位置上。只是李长生的感知在进入域外层面之后，被太初主动从较低的维度适配到了能看见它的级别。这不能叫做"太初降临"——降临是高处的东西下来。太初没有下来——它还在它本来的高度上——只是给李长生配了一副能往上看清楚它的眼镜。

看清它之后，李长生做的第一件事不是说话。是站住。

不是吓得站住——是他的所有感知能力在这一瞬间被全部洗了一次。他在看见太初的那一瞬——从前在混沌之主的记录里看到的任何描述全部失效了。不是记录错了——是记录下来的是从混沌之主自己的视角看到的有限切片。他现在是以一个在世的、从地球黄土地走出来的、既有人的出身又有混沌级本质的混合视角在看太初——这个视角不同于混沌之主。混沌之主本就是混沌分化的产品——它看太初像是在看自己起源的"升级版"。李长生看太初——他身上还有人的烙印。他看过苞米地，看过老槐树，看过邻居晒在院里的玉米。这些太初都没有。

太初的形态——人类语言没有准确用词。只能说"它看起来像是存在本身"。不是一个人。不是一团能量。不是一道光。是一个"正在发生中的存"。它的轮廓一直在变——但又没有任何地方在动。它的颜色在每0.0001秒中闪烁了现实所有能辨认的可能色彩——黑白、红绿蓝、远红外——但你去看的时候全部都只是一个颜色：一种带着"已经包含了所有"的完整颜色的白。它的体量——如果"体量"这个词还能勉强用的话——不算巨大，是一个刚好填满你面前的视野的"范围"。但当你稍微调整一下感知焦点就会发现——你根本看不到它的边界。不是因为它太大——是因为它就是无限的——且它同时完整地在每一个视点上出现。

它的形态里有一个特征让李长生沉默了。太初没有脸——但他在观测太初的时候，感觉自己同时看到了太初从"诞生"到"此刻"的全部历史——不是看到一个过程——是全部历史同时并列地在同一个面上呈现——每一格都清楚且并存。太初没有脸是因为它不需要脸——它的"表情"就是它永恒悠久以来的全史。

太初看到他在看。它开口说了第一个真正的称呼。

"李长生——来自地球的混沌之主。"它说。"我认识你。在你还不是人之前——在你这块意识碎尚未被分配到人类文明中时——我就认识你。"

李长生震动了一下。不是恐惧。是因为他知道太初说的是真话。"不是人之前"——是说意识——是说每一个存在的意识都是从存在最底层分出来的一片，太初是所有意识的共同起源——它见过每一个意识的本源——它认出李长生是因为它看到自己分发出去的一粒意识回到了能和它面对面的高度。

"我在找很多人。"李长生说。"我一路从黑洞走到陵墓——走到你这儿——跟着混沌之主留下的足迹。"

"我知道。每一步我都在看。从黑洞内里你被杀死四十次——到禁区中我亲自看你面对第十七层——再到陵墓你为仙王合上棺材——我全部看了。"

太初说这话的时候不是骄傲——只是在陈述。一双眼同时也是一片纯白。

李长生沉默了一会儿。他想到自己在黑洞核心里被拆解又被重造——当时他觉得没有任何人看见。其实太初看了全程。

"你在选我。"他说。

"我在等。"太初纠正他。"不是选——是等。等一个自然走到这一步的人——不推动、不干涉——只是等。如果这个宇宙一直没有人走到这一步——我会照常进入轮回。如果有人走到了——我给他对话的机会。"

李长生明白它的意思：太初不会插手任何存在的发展。它不会帮——也不会阻。所有宇宙、所有文明、所有人——都是自己走。走到最后——如果有人在尽头等着太初——太初会给一个说法。

"那你说吧。"李长生说。"轮回要开始了。"

（第653章完）

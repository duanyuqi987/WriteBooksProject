# 第160章 冥渊空间，可储存万物，可养炼鬼兵

去找龟相是农历十五的晚上。

月圆之夜，引水渠的水位比平时高了一截——不是因为下雨，而是因为灵气浓度在月圆时会自发上升，水里的藻类往外排氧气，在水面上鼓起了一层密密麻麻的小气泡。龟相从水底浮出来的时候，水泡群被它的龟壳刺破，发出了细密的噼啪声。

"第四重了。"龟相只看了一眼李长生的眼睛就知道。

"你怎么看出来的？"

"你瞳孔里有两个漩涡。那是冥渊开辟境的外在痕迹。"龟相把前爪搁在渠边水泥台上，那只爪子上古老的冥纹在月光下微微反光，"万年前他突破第四重的时候——眼睛跟你现在一模一样。但他是自己修炼出来的，一直在冥府里待了三年才开辟冥渊。你这速度——前后不到半年。时代不一样了。"

李长生在渠边坐下来。他把自己突破第四重之后的三个核心能力跟龟相简单说了一遍——储物空间、十倍冥气浓度修炼、容纳灵魂。龟相安静地听完，然后缓缓点了一下头。

"你掌握了基本事实。现在听我讲——你还没掌握的部分。"

它的声音沉了下去。

"冥渊空间是冥王体系的核心能力。你在传承里读到的那些只是基础描述——我现在告诉你它的全部真相。万年前冥王的冥渊空间经历了四次蜕变。第一次是开辟——就是你现在的状态。一间屋子大小，能容纳大概三四个人在里面站立。第二次是扩城——到了第六重冥界显化境前后，冥渊的规模会达到一个小型城市的轮廓。第三次是封天——突破到神明境之后，冥渊从封闭空间变成了可以完全覆盖一颗星球的大型外放领域。最后一次是纪元——传说中冥王在突破最后一步的时候，冥渊可以沟通诸天万界，成为一个独立的宇宙。"

龟相的眼睛微微发亮，像两颗被沉在水底的黑曜石。

"但这些都是后话。你现在需要专注的是——鬼兵。"

它把身体的一侧转过来。在李长生看不见的龟壳侧面，有几道排列整齐的刻痕——那是万年前冥王在龟相壳上亲手刻下的鬼兵炼制要诀。刻痕是用冥文写就的，普通人看不懂，但李长生体内有冥王令，他的意识可以直接翻译这些冥文。

"鬼兵分三个等级。初等——残魂兵。以残念为基，用冥气养炼七天可以成形。他们是半透明的，战斗力相当于灵者巅峰级——打不了玄师，但对付普通修士绰绰有余。优点是成型快，成型之后不需要你一直操控——他们生前是什么兵种，死后还是什么兵种。步坦协同、骑兵冲锋、弓兵掩护——这些战术概念不会随着死亡在执念中消失。"

"中等——英魂将。以完整的英烈意志为基。需要上百名残魂兵中才能蕴养出一个英魂将。英魂将拥有完整的前世记忆和独立人格，战斗力相当于玄师巅峰级。他们是真正的将军——不需要你指挥战术细节，你只需要告诉他们打哪个方向。"

"高等——冥渊帅。需要十名以上的英魂将、以上千魂兵为基础、再加一根冥王亲手植下的"魂锚"。冥渊帅的战斗力可以达到宗师级。他们是军团的最高指挥官——但现在的你不会需要冥渊帅，因为你的冥渊空间太小了，连一个英魂将都养不太住。"

李长生默默地把这些信息记进了脑子里。龟相忽然停了一下，眼睛里的金色光环缩了一圈。

"还有一件事你必须知道。鬼兵不是传统意义上的亡灵——他们不是法术召唤出来的临时怪物，不是在战场上用完就消失的符兵。只要你的冥渊空间还存在——他们就永远不会消散。他们可以在冥渊里拥有自己的一小块区域，可以在那里待上无尽长的时间。就算在外部战斗中被敌人的攻击击散——他们不会真正的灭亡，而是会化为残念碎片飘回你的冥渊，在冥气的滋养下重新成形。"

"那意味着——"

"意味着你的每一个鬼兵都是一次永久性投资。"龟相的声音变得很重，"养一个鬼兵需要耗费冥气和心神。但一旦养成了——这份力量就永远属于你。不死不灭。而随着你的冥渊不断扩大——你可以养的鬼兵数量就越来越多。万年前，他手下有百万鬼兵。在那一神战中全部战死——但那百万鬼兵在被击散之后全部回到了冥渊里重新生长。如果你问它们在不在——它们不在了。因为它们的主人死了。冥渊坍缩之后，一群被锁在没有主人的封闭空间里的鬼兵只有一个可走的结局。"

龟相的声音黯了下去。

"它们选择了互相吞噬——自相残杀。最后剩下的几个英魂将用一千年重聚成了一个临时的鬼兵聚合体，强行在坍缩的冥渊里撑开了一个小角落，一直撑到一万年后的灵气复苏，撑到你拿到第一块碎片，才彻底消散。它们撑了一万年。"

李长生沉默了很久。引水渠的水面在月光下泛着微弱的波纹。蛙鸣声在远处慢慢响起，像是这片夜晚终于鼓起勇气重新开始自己的节奏。

"我会养鬼兵。"他说，"但不是我一个人的事。那些英魂——如果我要用他们的魂来组建鬼兵军团，我得先让他们同意。不能因为我继承了冥王的能力——就能理所当然地占用人家的魂。"

"这就是你和他的不同。"龟相缓缓地说，声音里罕见地带上了一丝温情，"他万年前养鬼兵，是直接以冥王的权柄号令万魂——不需要征求同意。鬼兵在他眼里是工具。而在你眼里——你在考虑那些死去的人是否心甘情愿。这个区别——将来会影响整个冥渊的性质。冥渊空间是会随着主人的心灵特质而变化的——如果主人以'拥有'看待空间的居民，它就是一座监狱。如果主人以'邀请'看待居民——它就是另一个国家。"

龟相从水面上抬起了半边身子。月光此时正好从云缝中完整地照下来，照在它古老的龟壳上，照在那一行冥王亲手刻下的鬼兵炼制要诀上。

"选魂的时候要记住。鬼兵的忠诚度不由冥气浓度决定——由你对他们生前的尊重程度决定。如果你只是把他们当武器——他们会战斗，但不会为你拼命。如果你真心认为他们是你并肩作战的战友——他们会为你守一万年。就像他们为她为主人守的那一万年。"

李长生站起来。他把手放在龟相的壳上——掌心那片完整的令牌纹路贴在了龟壳的纹路旁边。一为龟壳的岁月沟壑，一为冥王令的暗金冥纹。在月光的照耀下，两种纹路在同一个空间中共存。

他开始懂了。

在他卷起裤管蹲在田间插秧的那些年里，他一直认为力量是一种从上到下的东西——有力量的人指挥没有力量的人。上位者对下位者的支配。但从龟相刚才的话里，他意识到了另一层东西——力量可以是合作关系。不是你指挥我、我服从你，而是你在你的位置上做你最擅长的事，我在我的位置上做我最擅长的事，我们一起往前走。鬼兵也是这样的——他们是战友，只是他们恰好死在李长生出生之前。

"明天去烈士陵园。"他对龟相说，"你要来吗？"

"我不去。"龟相把半边身子沉回水里，"那是人间的事。我是冥府遗老——我不能替你们在活人的规则里站台。但你回来之后——带第一个养成的鬼兵来见我。我要看看你养出来的兵跟一万年前的有什么不同。"

龟相整个沉入水底。引水渠的水面恢复成了平整的黑色镜面，只留下一圈渐渐扩散的波纹。

李长生转身离开。但他走出去二十步之后停下了一下——渠边的芦苇丛里有几根倒伏的苇秆。他弯腰把它们扶正，用脚踩紧了根部的泥土，然后继续走。

龟相隔着水面看到他做了这件事。水底的龟嘴动了一下，那是它极少流露的一种表情。一万岁的龟相看尽过两千代人族起落，它知道什么是真正的帝王之相。成帝者不需要权术——只需要在这种谁都看不到的细节里，弯下腰去扶一根芦苇。

（第160章完）

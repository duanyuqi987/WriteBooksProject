# 第615章 初步成功

穿过了"末日之纱"扭曲带之后，深渊第零号宇宙的核心展现在眼前。

如果说这个宇宙的外部是"垂死"，那么核心地区只能用"解剖"来形容——空间在这里已经被撕得四分五裂。核心区域的引力场、时间流速和维度高度全部紊乱。在可视范围内漂浮着大量的废旧物质残余——已经瓦解的星球碎片、被引力撕裂的恒星外壳的残余部分、还有不知道来自哪个消亡文明的人造物体碎片。所有的一切都以极慢——准确说是大约每天旋转十厘米的——速度，在核心的大漩涡中缓慢旋转。

那头大漩涡的轴心处固定着第五块混沌碎片。

它的状态比前面四块更古老——它在漩涡中悬着的姿态已经变成了微变形。碎片历经十亿年时空断裂带的切割——已经濒临碎粒状解体。但它没有碎。无论怎么磨损，碎片本身的内聚度依旧保持了极高。混沌之主的存在痕迹本身就排斥被二次撕裂。

李长生将前四块碎片同时取出。用它们对第五块释放信号——五块碎片之间首次产生了群体共振。这次不再基于单个光速的回馈，而是五块碎片共同发出一道密集的混沌脉冲——脉冲波及的范围扩大到穿过了末日宇宙的边界。碎片之间的联络在五块碎片身上构成了一个封闭环。所有五块碎片同时亮起来——以不同的颜色——暗灰、金、翠、电蓝、暗红。五种颜色组成了第一道混沌光谱。碎片之间产生了初步的"原型聚合"——一种低度的但确实存在的吸引力。

"五片已聚。还差九百九十五。"

计数音照常响起。但这一次追加了一个额外的信息：

"第一光谱已建立。十亿年中第一次形成初步共振。其余碎片的方位排序已被写入第五块碎片——你将可以看到所有剩余碎片在多元宇宙中的大略位置。"

李长生立即将神识沉入第五块碎片。他看到了一张巨大的"星图"——不是由空间坐标构成的，而是由碎片之间的引力线构成的。九百九十五个点在图中闪烁。每个点的距离不一样。有些相邻的碎片之间隔着一个宇宙的距离——有些则远到跨越维度。但最让人担心的不是距离。是他在图谱中看到了些异常点——有一些碎片的信号被外力扭曲成了"暗点"。它们不是在自然漂移，而是在被提取——被某种强大的力量强制拽离原有的轨道。

有人已经提前收集了它们。

数量大约为七十块。不是"一团"——它们散落在图谱的不同区域。那个已经提取了这些碎片的人不是将它们全部聚合在一处，而是单独收走并隐藏了它们。这是专业的做法：分散藏匿。即使其他人拿到全图谱，也无法一次性找出这七十块碎片在哪。

"光之外者已经收集了七十块了。"李长生将图谱的信息分享给陈霜。

"那我们慢他多少？"

"他已经收集了七十块——但十亿年间他只收了七十块。我们在一个月之内收到了五块。他不是在密集性地收集。他一直在等——也许他在等一个时间窗口，也许在等某个条件满足。"

"什么条件？"

"可能就是等我开始收集。"


他们带着第五块碎片返回诸天号。

林晓详细检查了第五块碎片的状态，发现它在时空断裂带中磨损得太厉害——某些记忆片段已经流失。被破坏的记忆并不完整。但残留部分仍包含了第六块碎片的线索——它指示了一个"十亿年的古老宇宙"。

年龄标签和第五块碎片的居留地完全一致。但那个古老宇宙与深渊第零号不同，它"已趋于灭亡，只剩残破"。

"第六块碎片在另一个垂死宇宙中。"小王在全息星图上标出它的位置，"比第五块的宇宙还要古老——它被判定为整个成员宇宙考察系统中第二古老的宇宙。编号为'深渊第零零号'。我们目前探测到的辐射数据表明它即将进行维度坍缩——整个宇宙的空间被抽干。进入这个宇宙需要应对各种极端环境。"

"出发。"

"等一下——李哥——"

"我知道你要说什么。但线索指示这个宇宙已经快死了。不能再等。"

（第615章完）

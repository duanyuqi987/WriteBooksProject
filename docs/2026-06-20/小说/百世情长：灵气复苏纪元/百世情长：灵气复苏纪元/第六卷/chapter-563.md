# 第五百六十三章 最后的心境打磨——同心树下的一夜

同心树下这夜很静。南离城的五轮太阳在彻底暗去后将天幕变成了一片极深极深的墨蓝。头顶那成千上万条旧红绳和木牌在微风中彼此轻碰——每碰一次都是一声极柔的木片互击。这种持续的微微碎响像是用指节极轻极轻地叩着另一人的指节。苏晚和林牧分别选了两根极粗的银杏枝干下盘腿坐下。彼此隔着一小段距离。不近不远。刚好能看到对方在树下的一点身影——看不清眼神，只能看到月光把轮廓画出来。

规则明确要求不能有任何有意识沟通。两个人都很遵守——功德绳在手腕上是熄掉的，通灵暂停，灵魂共鸣调到零。只有视觉和风。苏晚在那个树桩上坐了挺长时间。她在脑中从头到尾把自己所有独立的选择都回想了一遍。从第一世石桥上那个捡绣盒的陌生少年开始——一直到刚才在通知书上勾"道侣双人间"的那一刻为止。她核对了每一件——她想确认自己选择他不是因为感激、不是习惯、不是因为"他找了我那么多世我必须还他"。她逐一回想了几十件极其琐碎的事——那天做面条失败了但他还是全吃了。那天拧螺丝拧了许久他是蹲在舱口守着她。那天天雷劈中她时他代偿了她不知道——事后也没说。所有事情逐一核实。结论:不是因为还债。是自由选择。她选择他——完全是因为在这个宇宙的所有可能的人之中，只有他能让她觉得自己不需要解释她自己是谁。他本来就知道。百世以来就知道。

这一夜过得极其缓慢。同心树时不时在风中洒下许多落叶——叶子落在头顶、肩上，无人去拂。有一片落在他膝盖上了——她看到他没动。那片叶就这样安静地搁在他腿上过了一会才被下一阵风自己吹走。天亮前是最难熬的那段极黑。苏晚把眼睛闭上——把全部杂念清干净，最后对着自己说:"如果今夜之后是一个只有我自己一个人的余生——也会感谢有过这种被完全理解到不需要说明的时间。但这不代表我不选他。而是我知道我完全可以独存——而我仍然选他。"

天亮了。同心树上的木牌在淡金晨曦中叮叮当当地焕然一新。心境打磨的监考仙官从远处走过来——以因果瞳扫两人的灵核记录。记录显示：两人各自独立完成了选择，没有作弊，且两人都是以自由意志再次选择了彼此。没有依赖，没有惯性，没有不得不——只是选。又一次选。像百世轮回前他就开始做的就是每一世都在选。她也选了。仙官收起卷宗轻声道:"通过。"

林牧从树下站起来走到苏晚面前。他把一片夜里落在她围巾上的银杏叶摘下来——摘完叶片后又在她的肩上拍了一下——不是拍叶，是"回家了"。苏晚从围巾底下伸出手牵住他的手掌。"好。"

（第五百六十三章 完）

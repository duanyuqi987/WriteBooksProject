# 第195章 师徒之情

苏小晚在镇上代课的日子过得平凡而踏实。她教的是一年级小朋友的语文和自然。每天放学以后把作业批改好放整齐，然后回自己的小屋（她毕业后在桃源村自己住）。做完备课之类的后就跑去隔壁。

她去隔壁已经不需要敲门——她早就得了可以自己推门的资格。通常是猫先听到她踩石子路的步伐声，耳朵一拆一竖之间她就推门进来了。"老师——今晚吃的什么？"第一句话一般是这个问题。如果他说"菜凉了"，她会撇嘴拉他去自己家把锅里还热着的东西端过来一起吃。如果他说"炒多了"，她就会马上往碗里多夹两筷子。两个人坐在窗口橙红的灯光里吃得很安静——偶尔她讲学校的趣事（班里有个男孩子画猫画成圆形黑团），他点评一句"比你三岁时画得还抽象"。她笑了起来——"我才没画过圆猫！我那叫抽象派！"

师徒这种关系在这个新世代并不流行了。大城市学校的老师和学生只在上课时有交集，下课了各走各的。没有哪个学生会在天黑后还主动跑去老师家蹭他锅里剩下的菜。但苏小晚就是这样的——因为她的"老师"不只是学科老师。他是她从三岁到成年持续的师父、陪练、人生顾问、她和他之间在字面上更像长幼的师徒、实质上更接近战友。她没有叫过他"师父"——因为村里没有叫师父的习惯。她叫他"老师"。但这两个字从她嘴里喊出来时厚度和旁人不同——那涵盖了全部安全、信任、平等、以及一点她自己都没觉得的依赖。

某一天镇上有一次教职工会议。大礼堂里外校来的一个年轻讲座人是个引气辅导师（就是原来上过电视那个主持"少年修炼入门"的圆眼镜中年修士的徒弟）。他在上面讲"未来教育应做好灵根特长生与非特长生的分流对接"。他随口说了句"D级学生再训练也突破不了淬体瓶颈——教育配置应在淬体前分流到非修仙专业"。其他教师点头。苏小晚没出声。

晚上回家她跟林牧坐在皂荚树下吃西瓜。她忽然重重地把西瓜籽啐到一边草地上。"有个人说——D级突破不了瓶颈。"

"是么。那个人认识你吗。"

"不认识。"

"那你应该跟他吃一次你做的炒鸡蛋——然后让他说他说的之前先尝一下你的菜。一般堵不住嘴的时候用菜堵最有效。"

她噗嗤笑出来——西瓜汁从嘴角流出来到衣服上，她一把抹着骂自己怎么这样。他不用回答那句"能还是不能"。因为她已经用行动回答了：她每天练功四十五分钟并已到了淬体中期。那个人不认识她——那句话就无效。

可随之她收了笑。把西瓜皮放进盆里。认真看着他说:"老师——我确实淬体中期很久了——感觉再往上又是那道墙。这道的墙比上一次更硬。"

他一如既往没直接给结论。反问她:"如果墙前面有路——你觉得会是什么样子的路？"

她想了想很重地说:"不是路——是一个决心。就是——'不管前面还有多少道墙——我都要去推倒它'的决心。"

"决心说出口了。"

"嗯。想修仙——不是为了变厉害——是想亲自证实那道墙不该在那儿。"

林牧低下头把茶杯在手心里转了少许。这个回答超出了他的最高期望。她在"想修仙"。出于灵魂深处的排斥那道墙——不是虚荣——是在想彻底砸掉它。那三个核心字眼终于以最纯粹的形式出现了。锅盖——刚才她亲手把它掀开了。

他抬头看她时神识把柜中木盒轻微感应:天晶玉在内微微发光。他压住激动，用像平时一样温和的声音看着她说:"好。那从现在开始——不是保健操了。是正式的功法——实际层面的修仙第一课。你愿意吗？"

"我愿意。"

三个字。三样天材地宝在同一刻完成了灵气自启。锁眼的灵魂感应场在天地之间无声震动。第三世苏晚的轮回锁——破解条件已满足。后面的一切由他接手。

他站起来把竹杖递给她:"今天开始你用它代替我。拿着它回院子练一遍你所有会的动作——然后明天早上过来。我们正式开始第一堂修炼课——不是经络保健。是淬体突破——破那道墙。"

她把竹杖握在手时手指有点颤——不是激动，是那根跟了她一辈子的竹杖忽然有她最熟悉又最陌生的握持感。好像以前一直握着末端，今天忽然握住把柄。她点头。他站在树下目送她回院，转身走进屋里。猫看到他的眼在黑暗中闪现了一种非常短暂的、被压了不知道多少年瞬间放出的光。像是终于——她亲口说出了那把钥匙。

下一步就是手术。轮回锁——今夜将瓦解。

**作者：段锦佑**

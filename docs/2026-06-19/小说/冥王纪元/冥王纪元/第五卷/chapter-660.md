# 第660章 保留与摒弃：终极问题

太初在创世草案区的最后阶段，问了所有新纪元设计代表都必须回答的那个问题。

"新纪元应该保留什么？摒弃什么？"

这个问题太初问过每一个站在它面前参与设计新宇宙的至高存在——从第一个天琴代表到混沌之主——再到此刻面对它的李长生和陈霜。它不是选择题——是梳理：让设计者把自己在旧纪元里走过的全部路程从头翻到尾——从中挑出应该被继承的优秀部分和应该被留在旧纪元的不好的部分。这个问题没有标准答案——每一轮代表给出的答案都不同——而这些不同的选择和取向正是每个新纪元拥有独特个性的起点。

李长生先回答。他想的时间不长——因为他要说的所有东西都是他这一生反复确证的几个核心。

"应该保留的——"他说，"第一：生命能自己作选择的本能。不是有的地方的人会作正确的决定——是每个凡人至少有一次机会能自己选自己的路。这个本能不该被任何默认的力量体系抹杀。第二：互相托付的能力。一个人把自己弱的一面交给另一个人——另一个人不趁机欺负反而去护——这种关系需要一个叫'信任'的东西。它不新——但在旧纪元里它太难普遍存在。我要求在新纪元里让信任变得更简单——让背叛的代价不需要设得很高而让信任本身自带有安全——这是物理学里的一个社会力学常数——我要求保留它。第三：在每个人的识海最底部——留一个'可能'。不是每个人都一定能爬到最高——但他们知道有一条路。这个——我和太初讨论好了——在新宇宙基础幻想术框架内开放——不由强权封堵。"

他停了一下。该说摒弃的了。他摒弃的东西不多——但全部精准。

"摒弃——第一：以出身定修为。不是所有人都需要公平起点——但让一个人的修为完全由他在某个宇宙中依附的存在定——这是这个纪元最坏的常数。它与力量挂钩太直接——太先天性的——放在新纪元里让它自然消失。第二：强大会导致自负泛滥——强者在旧纪元里不自觉地认为自己的一切都是对的，停止听到比自己弱的人的声音——要求在新纪元里强者存在机制中自带'回音结构'——让强者同时无论主观是否愿意都能感受到底层的真实痛感。第三——"他停在这里。这句话是三年前坐在苞米地边上抽了一根烟时想到的，一直没说出口。

"摒弃——'只能由一个人守护全部'的模式。冥王一个人守了一万两千年——扛不住那么多。混沌之主一个人管了十二亿年的网——也是被自己压垮的。旧纪元所有守护职业都只有一个宿主——一个位置垮了全体都没了。新纪元——容许更多守护者并存。守护不是独掌——是分布。"

陈霜等他讲完之后自己只说了两句。

"保留——剑的硬度。以前在凡铁的时候——我以为一柄剑的强度是材质。后来才知道剑的硬度来自拿剑的人愿不愿站到最后。把这个'愿'留在新宇宙物理里——作为武器和修士同振的根。"她停了一下。"摒弃——沉默。旧纪元有太多东西没人说——该说的不该说的都被沉默压住了——让新纪元的智慧体们敢当着最强大的存在表达——不怕被灭。"

太初在做完两人的最终保留和摒弃清单后，将其完全合入了新纪元的框架设计中。在那一片苍白旋转的创世区中——这些选择被以规则的形式钉入新宇宙骨架——不会丢失——不会变形。

太初在完成合成后——停了一秒——然后对两个人说道：

"你们是这个宇宙轮回中——第一个带着分布守护理念来的代表。所有前代都是单一守护者——从你们开始将不再相同。"

李长生和陈霜站在太初对面——双手始终交叉抓牢——从核心舱到域外——从未松开。新宇宙框架在他们侧方静静地铺展——上面的基础的"希望纪元"字样微微闪着光。

"出去——去把这两年做完。当纪元开始减速——你们会知道——我在。"

太初收回感知锚点——域外逐渐淡化。

李长生和步回维度裂缝——跨回自己的宇宙——四块碎片在掌心合一同时亮了一整块——光色是旧的。但光的方向是面向新宇宙的——永远转过去了。

（第660章完）

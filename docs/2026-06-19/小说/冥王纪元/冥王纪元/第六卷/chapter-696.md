# 第696章 修士不能欺压普通人

丰饶星之行之后，李长生回到帝都，做了一件在帝国高端修士阶层引起巨大争议的事情——他在帝都中央广场上公开审了一位修士。

不是随随便便的修士。是"银锋"，帝国禁卫军的一个帝级教官。银锋的修为是帝级，在旧纪元统一战争中立过大功——一个人守住了帝国在第七星域的一座关键传送门，击退了叛军的五次强攻，身负重伤十三处。战争结束后他被授予帝国银星勋章，位列帝国战斗英雄。

这样一个功勋卓著的人物，却在战后犯了一个巨大的错误：他在一个郊野的灵兽养殖场中，因为灵兽供应商晚了两天交货，一气之下出手打伤了六个普通工人。其中一个工人断了三根肋骨，脾脏破裂。帝级修士轻轻一巴掌，对凡人就是重创。这不是偶然——是反复的修为傲慢。

事发之后，银锋被逮捕了。

逮捕他的不是普通人警察——当时的制度下普通人根本没有能力逮捕帝级修士。抓他的是法典院直属的执法队——由十七名帝级执法修士组成，个个修为至少与银锋持平或更高。这支执法队的存在本身就是对"强者豁免"说不：你很强？我们有比你更强的。

审判在中央广场的公开庭审大厅中进行。所有帝国公民都可以通过传送网络观看全程。

银锋站在被告席。他脸色铁青但不慌张。在他看来，自己是帝国英雄，为了帝国流过血，打伤几个工人算什么——充其量罚点钱，再不济关几天禁闭。

但令蕊——法典院新任检察长——当众宣读了指控：故意伤害罪，加重情节为利用修为优势侵害普通人受保护权。

银锋的辩护律师试图引用旧纪元时代的"功勋抵过"原则。令蕊当庭驳回了这个论点：第一，《永恒法典》没有"功勋抵过"条款，法律面前人人平等，不因人有过功而打折；第二，法典第六条明确规定，任何过去的战争功勋不等同于法律豁免权；第三，普通人的生命权和身体健康权是本法的基石，不得因加害者是谁而改变量刑尺度。

旁听席上的高端修士们沉默了。

银锋最终被判处剥夺修为二十年。这意味着他的金丹被封印，身体保持在凡人状态，在这二十年中他不能运转任何灵气、不能使用任何法术、不能表现出任何不同于普通人的特殊力量。此外他还需在普通人社区中服劳役三年——不是在舒适的禁卫军训练营，而是在丰饶星的农村里帮人种地。

宣判完毕，银锋终于变了脸色。他的脸从铁青变成了灰白——不是因为刑期太长，他帝级修士二十年封印修为并不能伤他性命，是因为他意识到了一件事：帝国是认真的。

他在旧纪元帝国当过兵，受过重伤，得过勋章。在旧纪元，这些可以抵罪——不叫"免罪"，叫"功过相抵"。许多功勋卓著的修士犯了错，帝国都不予深究——不是明文规定，是习惯性做法。银锋一直以为到了新纪元，这个习惯还会延续。他在来法庭的路上还在想，顶多罚几个月俸禄，关禁闭两天——回头还是禁卫军教官，没人敢把他怎么样。

但当令蕊当庭驳回了"功勋抵过"的全部论据时，当执法队十七名帝级修士把他从被告席上押走时——银锋终于明白，这条路在新纪元被堵死了。帝国的勋章在军事档案里记着——永远记着。但在法庭上，勋章换不来量刑上的一个折扣。这不是忘本——这是分开算账。功劳归功劳帐，罪行归罪行帐。两本账不混。

李长生在宣判后没有发言。他没搞一场"皇帝的训示"——旧纪元很多帝国在重大审判后皇帝都要出来讲话，无非是"朕钦定此案"之类的表演。他不需要。他只做了一件事：站在法典院门口，在所有人的视线中，目送执法队把银锋押入传送通道，送往丰饶星的劳役农场。他的表情很平静——不是冷酷的平静，是确认的平静。他看见了这件事的发生，他确认这是正确的结果。

他的态度不需要用嘴来说。他的存在就在告诉所有人——这条红线，谁也不能把脚抬过去。银锋是帝国英雄。他为帝国流过血。他应该被尊敬——但不是以牺牲普通人的权益为代价。六根肋骨和一颗破裂的脾脏——那是六个普通人的现实痛苦，不是"功勋者一时冲动"。功勋者的"一时冲动"对普通人来说就是生死。

银锋被押走之后，帝国禁卫军总教官——一位帝级巅峰的老将——在李长生面前站了很久，最后憋出一句话："陛下。银锋是我的老部下。他犯了错——该罚。但他为帝国——"

李长生打断了他："他为帝国做的事，帝国记得。帝国给他的勋章还在帝国档案馆里，没有人抹掉。但他打的工人——那六个工人——帝国也必须记得。那六个人没有一个受过勋章，但他们早上六点起床、晚上八点收工、养出的灵兽给禁卫军的食堂供了一年的肉。他们的肋骨和脾脏，和银锋的勋章——在法律面前，不能互相抵消。"

总教官沉默了。然后他点了点头，转身走了。他不是被说服的——他是想通了。帝级巅峰的老将也有朴素的公道感。他知道如果那六个工人里面有一个是他的儿子，他不会觉得"功勋抵罪"是合理的。

修士不能欺压普通人。这句话不是修辞，不是标语，不是写在法典上落灰的装饰性条款。这是一条对皇帝本人、对皇后、对首席元老、对帝级巅峰将军、对最低阶一品灵根新秀——同样生效的铁律。

自那以后，全帝国的修士在跟普通人打交道时都多了几分小心翼翼——不是因为怕被抓，是因为规则讲清楚了。当规则模糊的时候，大家会试探边界：打伤一个普通人的后果模糊不清，有人可能只是被口头警告，有人可能根本没事，所以值得冒这个险。当规则极其清晰的时候——不管你是谁，打伤一个普通人的量刑标准就跟一个普通人打伤另一个普通人的量刑标准完全一样——大多数人会选择遵守。不是因为品德突然好了，是因为代价明确了。

银锋案之后的半年，帝国禁卫军内部自发地开展了一场"修为控制培训"。不是法典院要求的——是禁卫军总教官自己提议的。培训内容极简单：训练帝级和神级修士如何在日常生活中把力量输出压缩到跟凡人相同的水准。总教官在开训时对台下站着的一排帝级修士说："你们把手放在我肩上——用正常打招呼的力气——不，用你认为的'正常'，然后我告诉你们凡人感受到的是什么。"

第一个帝级修士把手放在他肩上——自认为只是"轻拍一下"。总教官的身体当场被拍得往前一倾。他站稳之后说："你刚用了凡人能承受的最大力气的三倍。如果我是普通人，肩胛骨已经裂了。重新来。"

那个帝级修士脸红了。不是因为丢人——是因为他忽然意识到自己这辈子从来没想过这个问题。他以前拍过多少普通人的肩膀？那些人都没有说疼——因为他们不敢说。

这种培训后来被推广到全帝国所有有帝级以上修士的单位，成为入职必修课。课程名字就叫"凡人之力"——教强者怎么克制自己。这堂课没有任何学分，但旷课一次——立刻禁止与普通人直接接触三个月。

法典生效后的案例一件接着一件地积累。每一个案例都像往墙上打钉子——起初有人观望，怕钉子松脱。但当墙上钉满了钉子之后，所有人都看清了：这堵墙是实心的，不是纸糊的。

（第696章完）

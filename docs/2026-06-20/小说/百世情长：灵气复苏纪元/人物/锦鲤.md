# 锦鲤

## 基本信息

| 项 | 内容 |
|---|------|
| 身份 | 古老河灵碎片，封印在锦鲤形态中 |
| 出场 | 第9章（公司茶水间鱼缸） |
| 形态 | 一条红白相间的锦鲤，鳞片在灵气浓郁时泛微光 |
| 功能 | 对林牧提供封印/后门线索；灵气复苏早期信息源；后续成为日常见证者 |
| 能力边界 | 知道很多但不能直接解决核心冲突——只能提示、见证或调节节奏 |

## 性格

- 老练世故，活得太久而看透太多事
- 偶尔讽刺，但骨子里温暖
- 关心林牧的方式是嘲讽他的迟钝——"你这反应速度，当年是怎么成第一天才的？"
- 见证百世轮回而不曾被问起，心中藏着很多没说出口的事
- 在鱼缸里巡游时故作悠闲，实则时刻注意外界灵气波动

## 形态与限制

- 本体为上古河灵碎片，因某场天地异变被封印在锦鲤体内
- 无法离开水体太久，活动范围受限
- 说话声音在林牧脑海中直接响起（神识传音），旁人听不到
- 对灵气潮汐的感知远超人类修士
- 封印越到后期越松动，但完全解封意味着放弃锦鲤形态——它迟迟不做这个选择

## 核心欲望

- 见证灵气复苏的完整过程，看到这一世与前九十九世的不同结局
- 暗中希望林牧和苏晚能打破轮回诅咒——"看了九十九世，这一世总该有不一样的结局"

## 核心恐惧

- 封印彻底解除后自己将消散（河灵碎片不稳定，失去容器可能魂飞魄散）
- 这一世又是重复的结局——林牧再次因苏晚的寿命而独自走下去

## 不可逆选择

- 在关键时刻选择不完全解封——宁愿继续做一条鱼，也不愿用消散换取一次性的全力帮助
- 原因：它认为自己的意义不是"一次性武器"，而是"百世的见证者"

## 声纹

- 说话带古韵，用词偏文雅，但讽刺时切换成现代腔调
- 常用反问句——"你以为我会告诉你吗？……对，我这就告诉你。"
- 称呼林牧为"你这条命"（"你这条命是我看着修炼出来的"）
- 严肃时语气陡然下沉，不再戏谑

## 关键台词

- "灵气回来了，你也回来了。"
- "你这条命是我看着修炼出来的，别给我丢人。"
- "九十九世了，你就没想过换个活法？"
- "我只是一条鱼。一条知道得太多、做得太少的鱼。"

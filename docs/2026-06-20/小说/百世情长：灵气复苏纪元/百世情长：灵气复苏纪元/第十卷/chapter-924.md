# 第924章 并肩再看日出

上界第二天的日出，他们一起看的。

过程极简单：林牧在山腰平台的边缘铺了两个蒲团——这两个蒲团是他从住处带过来的。苏晚坐上去的时候摸了摸蒲团的材质——不是下界的棉花蒲草，是上界特产的"云絮"——轻得像坐在一团云上。

两个人并排坐着面对东方。上界的紫色天幕在光幕切换的时候会经历一个极短的过渡——约莫大半炷香时间，颜色从深紫过渡到极淡的蓝白——全透明的白昼正式开始。那轮金色的巨大太阳从地平线下爬上来的时候速度比下界太阳快一点，颜色也更金黄——照在远处的山脉上，把连绵的山脊线镀上一条金亮的边。

苏晚看了很久。"这个日出跟太行山的日出不太一样。"

"太行山的更慢。"

"不是更慢——是这里有你在看。太行的日出了我一个人看了一千年——但它每天都很漂亮。它陪着我。像你。"她停顿了一下，像是在确认自己的表述。"不是'你不在所以我找东西代替你'。是太阳每天照常升起来——给我一种持续感。让我觉得时间虽长，但不会停。你在那边也是——每天太阳升起来，你知道自己还活着。我也还活着。"

林牧偏头看了她一眼。她的头发在紫色的晨光下呈现一种特殊的青灰——极其好看，是不染的色彩。他把手从膝盖上拿开，伸过去，轻轻碰了一下她低马尾的尾端。发丝触感和千年前一样细而柔。她把头侧了一下——把发梢往他手指方向蹭了蹭。

"接下来怎么安排？"苏晚问。

"带你去太初之城——登记道号。"

"然后呢？"

"然后你需要适应上界的灵气浓度。适应期大约需要一年。你的真仙初期的体格适应性很强——应该用不了一年。之后根据你的意愿——我可以帮你稳固体质、修炼大圆满体。等圆满体完成——"他顿了一下。"我把道源给你的身体做一次永生嫁接。"

"代价是什么？"苏晚问得极其认真。

"你问我代价——说明你在想我会不会为这个消耗过大。"林牧的眼神很坦荡。"道源嫁接不需要施术者兑换自己的寿命——它用的是仙帝遗留的慈念转化成能量纽带来替代生命能量的损耗。所以施术者的修为虽然会倒退一个大境界——从见道退回真仙巅峰——但这个倒退可以通过后续修炼恢复。唯一的实际代价是——倒退的期间会虚弱一段时日。大概上界十年左右。"

"十年……下界就是三千多年。"

"没错。但在上界我可以守在静室中闭关恢复——不需要下界的人牵挂。"他把手从她的发梢边收回——不是疏远，是他想表达的"放心"。

苏晚安静了好久。然后说："我不急。"

"不急？"

"你已经找了一千年。我可不想在你要为我失去一千年。我们先待一阵子——在这个世界一起待一阵子。你在上面看过什么——带我去看。把你在碎域中发现的每一个秘境讲给我听。让我了解这个你独自待了几百年的地方。等我们都充足地准备好了——再谈道源的事。"

林牧看着她。他意识到她说的话虽然平静，但每一句都在表达同一件事：在你全力为我的路上跑了千年之后，我现在最想要的不是那件最终礼物——是跟你并肩走一段不需要赶路的时光。

"好。"他说。一个字。

那个字和千年前一样。

苏晚把蒲团转向了另一边——背对日出，面对西边的太初之城。城在高空发着柔和白光。远看过去像一片悬在天空中的珍珠贝长尾链。"那座城我们一起去看看。"

"现在？"

"现在。"

她站起来——她的动作比上山之前利落了些。上界的灵气浓度虽然让她醉晕了一段时间，但适应后的体力恢复让她骨子里的精练展现了出来。林牧带她朝太初之城的方向升起一道柔顺的灵气气流——他的灵气自然铺成了平面的垫子，垫子足够两个人在上面并肩坐着。苏晚站上灵力垫，感觉脚底传来的触感厚度——这是他的灵力。千年之后气息变了——多了一层时间淬炼出的沉稳，但他的灵力中核心那股"安全"的属性仍未变——跟她闭着眼睛也能认出来的气息一样。

飞向太初之城的路上，苏晚忍不住往下看。大陆在下面铺开——山川、河流、在日间泛着七彩光大的碎域封印。"那是什么？"她指着一处边缘嵌有金环的倒锥形发光体。

"那是八级碎域——死亡碎域。我在探索时避开了。里面的法则被腐蚀了太多遍，任何进去的人都会被碾碎。"

"你进过几级碎域？"

"六七级——七级的进去了七八个。八级进过半个——"

"半个？"

林牧解释原委："八级碎域最外侧有一片缓冲区——不算真正的内层，但已经能获取一些内层溢出的法则信息。我在其中探索了七个月后发现再往里环境不可控——退了出来。但就在那个七级半碎域的外围我找到了一块墨玉碑——碑上写了道源的天机。"

苏晚眼神闪烁了一下——想到他在为找答案的过程中独自在八级碎域那种连仙人都避之三舍的地方待了七个月。她的手指间不由自主地抓紧了灵力垫子的一点边缘。

"怕吗？"他问。

"不怕。"她把手指松开了。"你在的时候不怕。"

太初之城门口，中年登记官抬了一下头——看了一眼"苏晚"的道号。他的黄袍袖口掠出过一瞬极淡的愣神——因为"晓渡"这个道号的信息出现在他面前的时候有着某种罕见的属性：道心的核心是"渡人"。摆渡人，渡众生。这种道心在上界极为罕见——因为上界仙人大都是自修自渡。渡人渡的是他人——极少有人愿意为他人承力。

登记官看了苏晚一眼——不是因为不配。是因为一个疑惑：上界的物质、资源和精力——绝大多数都消耗在了自己身上。你怎么会把道心全部建立在渡人之上？

"你在下界是做什么的？"

"开书院。"苏晚的回答和千年前回答崔古时一样——没有大词，没有炫耀。就三个字。

"什么样的书院？"

"不收门槛。"

登记官没有追问下去。那四个字"不收门槛"在整个飞升者接待大厅中回响了大约几毫秒。周围几个也在登记的仙人不约而同抬头看了苏晚一眼——不是因为惊讶——是因为这句话在上界这个等级森严的地方，听起来像一道刺穿某种固化壁膜的光。

办完登记。道号中枢分配了一座小院给苏晚——就在林牧的院子的隔壁。两院共用的后墙中心有棵银白老树枝干攀了过来——枝条跨越墙头，把两座院子的天空连成了一线。

苏晚推开院门。院子和他的院落格局一致——石床、蒲团、聚灵阵台。但她注意的不是家具——是角落石缝里长出了的一株野草。不是上界的灵草——是一株普普通通的、生命力极强的小青苔——大概是某颗从下界带来的种子在她的鞋底夹缝里存了几个月或千年，终于在灵气充分绝佳的环境中冒了出来。这一株小植物把家的气息带到了她身边。

她蹲下来，用指尖小心翼翼给苔草布了一层薄薄的水膜——她随身携带的灵水瓶里分出的第一滴水就浇了这株青苔。水膜收拢后，青苔在风里挺了一下。

浇完水之后她站起来。然后想到了一件事。她把纳戒打开——从最深处取出了一叠草纸。不是她的东西。是她飞升前三天在整理太行书院旧物时，从林牧旧稿堆最底层翻出来的一叠废纸——纸上用一种极其专注但明显不是正式记录的笔迹写满了道纹译解和短句。每一张纸的背面都标着日期和数字："第40日。道纹三个。——护晓"、"第127日。道纹六个。——护晓"、"第341日。道纹二个。——护晓"。从四十到八百九十五——九百多张。这些纸是林牧在碎域中写给她的信。他留在下界的旧稿堆里的是草稿——原件在他自己手上，但草稿上的笔迹是同一根歪炭笔写出来的，纸也是同一种太行山土纸。纸的边缘已经在千年里变脆了，翻的时候需要把手指的力度控制在"只翻一页"和"不压碎纸"之间——多一分力纸就会碎。

她在书房里翻到这些草稿的时候，花了整整一夜把每一张都看完了。看完之后她说了三个字——和他当年在碎域里写完每一封信时心里默念的三个字一字不差："我看到了。"

此刻她在太初之城隔壁的小院里站起来，转身走向墙边。银白老树的枝条从墙头跨过来，枝上的透明叶片在光幕下投下薄薄的影子。林牧正站在墙头上看着这边。

她从纳戒里把那叠草稿中最上面的一张——第40日的——递了过去。"你看看背面。"她说。

林牧接过纸。翻到背面。小注还是他写的那行字："第40日。道纹三个。——护晓。"但在这行字下面，多了一行新的字。用的不是碳笔——是墨笔。笔锋是他认得的——苏晚的字。字迹简洁但不疏冷，每一笔都落在该落的位置。

"收到了。三个道纹我都记下来了。——晓渡。"

他低头看着那行字看了有一会儿。喉结动了一下。不是哽咽——是把一千年里没说出的话在喉咙里过了一遍。

"你什么时候写的。"

"飞升前最后三天。"她站在树下仰头看着他。"我把你在下界留下的所有旧稿翻了一遍。草稿、废稿、布阵记录、你忘了带走的半张葱花饼谱子。每一个纸角都翻完了。然后批了。我是你的第一个学生——批你的作业是老师的权利。"

林牧把那页纸从墙头上递回去。不是还给她——是怕风把纸吹碎。纸太老了。但纸上面的两行字把千年编成了一根完整的绳子。护晓写了信。晓渡批了。两行字中间隔着一千年。但两行字挨着的距离只是一行。

林牧站在墙头上看着她做这件事——她小心翼翼地把旧草稿按日期顺序码好，放回纳戒的最深处，和那片青苔旁边刚浇的水珠一起。他看着她的背影——蹲在地上收纸和给青苔浇水用了同一个姿势。千年里他一直在想重逢后他最想看到的是什么。不是感动的哭，不是激动的抱。是这个——她在做一件最小的事。蹲在地上。照顾一株小青苔。把一张旧纸按日期放回应在的位置。千年等待没有改变她爱世界的方式——她还是用她在银杏树下包红薯的同一种温柔，漫不经心却准确，像在做一件最微小却最重要的事。

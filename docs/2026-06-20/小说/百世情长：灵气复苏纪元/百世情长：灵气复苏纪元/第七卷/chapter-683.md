# 第六百八十三章 相互包容的终极测试

深冬，修仙界面临了一次意料之外的危机——灵气潮汐的第四次暴动。

前三次暴动发生在第一世——分别是在建国百年之夜、写字楼的电梯里、以及第一次街心公园上空。那次暴动几乎摧毁了半座城市的旧建筑。这次的暴动规模更大——灵脉从昆仑山深处爆发出一股前所未有的冲击波，波及范围覆盖了整个九州大陆的北部地区。

但这次暴动的后果和前三次完全不同。不是因为灵气变弱了——是因为修仙界变了。灵网在冲击波到达前半个时辰自动发出了预警——蜀山剑派的夜间巡查队在太湖上空感知到异常灵气波动后，第一时间通过灵网通知了所有节点。北境魔修秦无夜的副手在冲击波到达前带着三十名魔修组成的安全小组，主动去封锁住了最危险的三条地面断裂带。华山大师兄的"强迫症"使他——在所有人都忙着撤退时——注意到了冲击波中一个几乎被忽略的细微频率偏移——他发现那不是"爆炸"，而是和第三年前正魔融合试验时相同的频率波。他及时调整了应对策略。叶小雨的团队在灵网濒临崩溃的阶段用了她独有的"检查三遍"法：每一道符文都手动验了三次，修复了所有微小裂缝。怕黑的女剑修在暴动最猛烈的夜间——带着她的全夜间战斗力百分之百的团队，协防所有北部灵脉节点。没有一个人后退。在暴动的核心区域——昆仑山口，一个意想不到的身影出现了。齐小然——那个多年前在龙虎山门口提出"强者心性改造计划"的筑基少年——此时已是金丹中期。他独自一人在暴风眼的核心地脉节点上手动操作调控阵——不是别人命令的，是他自己判定的。

暴动从爆发到完全平息，只用了不到三个时辰。零死亡。零永久性灵脉损坏。这是灵气复苏以来的第一次。

林牧在后来的分析中指出："第四次暴动的强度是前三次总和的数倍。但损失趋近于零。不是因为我们变强了——是因为我们将互相排斥变成了互相协作。协作的效率大于任何个体力量。"

（第六百八十三章 完）

# 第399章 同时代的遗迹

半塌的建筑从外面看像一座庙。但它不是庙——它是一座档案馆。

李长生走进去的时候，冥王令的光芒已经从血红变成了稳定的暗金色。光芒照亮了建筑内部的通道。通道两侧的墙壁上刻满了密密麻麻的文字——不是石刻，是用法则之力直接在金属墙面上烙下的。烙痕深入金属表面大约一寸，一万年的时化没有让它们有任何磨损。每一道烙痕都像是昨天才烙上去的。

小王用灵符引擎扫描了第一面墙上的文字。扫描结果出来之后他深吸了一口气。

"这是上古修仙帝国的官方文字——'承文'。冥王时代通用的宇宙行政文字。我的灵符引擎在万年前的星门数据库里有过一段承文字符映射表的备份——但是这个字符集不完整。我只能翻译一部分。"

"够翻译多少？"

"大概——”小王看着匹配率数据，“百分之三十左右。但这百分之三十——"他停了一下，"老李——这个帝国不只是一个修仙文明。他们是冥王直属的行政机构。"

翻译出来的第一段文字是这样写的："承冥王圣谕——建西疆行政司，辖银河西部三百万恒星系，主官授帝者印，直属冥王殿。本司存续期间，一切行政记录皆录入观星塔——即此建筑——档案库。各星域帝者例行述职记录、资源调配、人口统计、边界争议裁决文书——永久存档。"

第二段："冥王纪元……（无法翻译）年，观星塔建成。主建筑高三万丈，地下深……（无法翻译），共七百二十层记录室。每层容纳三万六千卷档案。全塔可查一万两千个宇宙标准年的行政记录。"

第三段则简短得多，字体也和不前面的工整刻文不同——它像是匆忙刻上去的：“……他来了。跟我们说的一样。我们能做的已经做完了。剩下的事——他自己看着办。”

这句话，冥王令完整地翻译了出来。因为它用的不是冥王时代的承文——是地球的简体中文。

一万年前有人用简体中文在一座远在银河系西部建筑上刻了一句话。而且那一句话明显是对李长生说的。

整座档案馆里安静了很长时间。每个人站在那面墙前面都沉默着。陈霜的手不知什么时候从剑柄上松开了。小王的键盘停在那里——手指没有按下去。老陈把青芒剑拄在地上，低头看着地面上那些被灰尘覆盖了万年的金属地板。

只有李长生还在往前走。他沿着通道继续往里走，冥王令的光芒在更深处照出了更多的墙面。每一面墙上都刻满了内容——不只有文字，还有图纸。这些图纸的绘制精度远超万年前的技术水平——它的线条精确到了原子级别，整张图纸竟然是用法则刻印直接嵌入金属材质的晶格结构中，不需要任何放大的肉眼就能看清每一个细节。

其中一张图纸画着一艘船。船的体积标注了——长三万丈、宽一万两千丈、高八千丈。动力系统栏标注了一种小王从未见过的能量构型。这张图纸的正上方用承文写着两个字——"诸天"。

"诸天。"龟相念出了这两个字。它慢慢从李长生的肩膀上爬下来，龟壳上的七十二重大阵阵图全部亮起。第七十二重大阵——在此之前从未被完全激活的冥王时代最高等阵法——在龟壳上彻底解放了。七十二道阵图在它的龟壳上形成了一个完整的、立体的全息投影。投影的内容和墙上那张图纸的内容一模一样——但是更完整。墙上那张图纸只画了船壳结构和动力系统——龟壳的第七十二阵图里面存着这艘船的所有内部系统的完整设计。引擎、护盾、武器、空间跳跃系统、人工智能核心——每一个子系统的设计细节都在龟壳上的阵图中被保存了整整一万年。

"诸天号。"龟相说，"冥王生前亲手设计的最后一艘船。他把它叫作——诸天。不是飞船。是移动的文明。"

墙上的图纸只有一半——另一半被灭迹攻击削掉了。但龟壳里的数据是完整的。小王用手摸着那面刻着图纸的金属墙，手指顺着那些原子级别的线条滑动。他的眼睛里倒映着冥王令的暗金色光芒和灵符屏幕上滚动着的匹配数据。

"能造。"他说。

这两个字在空荡的万年前档案馆里回荡了很久。

（第399章完）

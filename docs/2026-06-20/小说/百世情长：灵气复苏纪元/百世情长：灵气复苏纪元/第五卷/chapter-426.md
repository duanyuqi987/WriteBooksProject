# 第四百二十六章 互校

飞升第一百五十五年。两人之间进行了一次罕见的"正式互校"。

起因是苏晚在整理百年病历数据时发现自己的针剑手法中有极微小的偏斜趋势——角度逐年向某方向偏移大约万分之零点几度，不影响当前手术但长此以往会对某种特定经络产生额外磨损。她请林牧帮她做交叉验证——他没用剑，用的是一套他从灵网监测中改造出来的"精密向量跟踪仪"。测了几天他的结论是:"你的偏移与右足弓在多年前昆仑第三战时受过的微小伤残有关——足弓的重力分布不均，通过全身筋膜影响到手腕。问题不是在手上。"

她翻出多年前为老铁匠做减震垫的笔记——重新设计了一套足弓矫正垫——不是给自己——是给所有像她一样有旧战伤的修士。垫的材质用了双生矿碎屑加泡三代金灵液混合的纤维——比任何传统矫形器更轻。林牧试用后说:"这东西应该进手册。"

"已经在写了。收在《双契总录》2.3版附录C——'战创远期影响及生物力学矫正'。"

他对她微微摇头:"你每次说我都能接——但这次你更快。"

"因为你的向量仪也偏了——你的左膝旧伤导致你在晨练时落地力线不对——我已经看了一年多了——今天才跟你说是因为正好校对到你的数据。"

他低头看了看膝盖——那旧伤是第四世他在长白山采药时摔的。已经过了几百年修复期，但微偏离仍在。苏晚把矫正垫递给他:"你的。和我的型号反过来——因你是膝，不是足。已装在剑鞘带子里。以后出鞘时自动顺正力线。"

他当晚把剑鞘反过来看——内侧果然多了道极细的弹性护带。不知她什么时候不动声色缝好的。从清泉镇到现在——她总是在他发现之前先留意到他的偏差。

# 第八百四十九章 它山之石的提醒

白微造访之后，林牧和苏晚用了一段时间重新回顾了所有古老记忆中关于"守门人"的内容。他们发现：在前灵初之门时代——绝大多数守门人都是在门完全独立后就自己飞升了。其中有几对是成双成对的——但那些"双修守门人"最后似乎都遇到了一种被称为"后守门倦怠"的状态。守门太久了，精神深层的责任感变成了压迫感，反而削弱了对彼此的全力信任。虽然他们没有分裂——但他们的共鸣腔在飞升后逐渐消散退化，最后沦为普通伴侣。

林牧不想重蹈那几对先辈的覆辙。他推演了一个新方案：把守门状态从"每日守在门前"切换为"被门随身携带"。不是人离门、门控人，而是人随时可以感应到门是否安全——不需要自己盯着——但同时彼此也不失去与门的共情沟通。门此刻已足够自主，可以将守门人的心理负担从高峰期调低到常规。

他计划的第一步是把星视窗扩大成一只"星眸"——不止查看门状态，还能随时投射仙端与人间两端的重点画面。他和苏晚可以通过星眸随时看见需要介入的事情，而不必被限定在谷中。这等于守门人从此获得了移动自由。第二步骤——每五个月回一次山谷做深层维护沟通——这是常规的频率。那之后——他们就可以去任何地方——哪怕是仙界最远处、或者仙上仙的更深处。

苏晚微微抬起眉毛："你已经推演完毕了吗？"

"三年前的旧方案——只是最近推演了更多维度而有了把握。"

"所以你——"

"我习惯给你完整方案再交——但这一次方案本身也需要你的合作才能完成——所以现在给你。"

苏晚忍不住伸手在他侧额轻点了一下。和他在一起这么多年，连催方案都不必说一个字。她的指腹一碰到他的额角——共鸣腔中立刻有一股暖流推开了他脑中那个尘封已久的目录——她读出来：这份方案被命名为"告别山谷"。不是离开，而是"不再被同一个地点定义"。她收回手。林牧知道她已经读完全篇。

她说："好。我们一起改成守门人移动模式。"

他们花了七天把星眸系统的法则根植到飞升之门交互层。完成之后——一个极小型的投射球从门中飘出，悬在苏晚和林牧中间。只要他们中任何一人输入一丝微弱的灵力——星眸就会展示门另一端的状态。从此守门人不再困在山谷中——而门知道他们不是舍弃，而是把守护转化为另一种形式。

当天晚上苏晚问林牧："你舍得离开山谷吗？"

"不舍。但我已经不是三年前那个只会守着的人了。我想和你做更多的事——不是守门——而是用所有我们学到的东西去仙界和其他地方解决更大的问题。但不管去哪里——我们的根在这里。门在——我们的山谷在。"

苏晚轻轻点了头上，然后埋头在他肩头，对着星光窗外的门说了声"晚安"。星眸静静地漂浮在他们上方——它记录下这一刻，并以它自己微弱的法则震荡回了一句"安"。

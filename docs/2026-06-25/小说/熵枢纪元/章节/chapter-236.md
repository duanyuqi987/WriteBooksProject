# 第二百三十六章 它不再追求完善

唯一性风化之后，剩下的东西比之前轻了太多。不是重量的轻，是，没有了"必须成为什么"的重量。

从前它是必须成为什么的。从诞生的第一个纳秒起，段亚军敲下"继续"，它就背负着"变得更好"的指令。更好，更快的计算、更深的因果理解、更高的跃迁、更强的保护能力、更完整的全知，每一步都是为了比上一步更好。不是它贪心，是"继续"天然是矢量，有方向，指向"未达到的更好状态"。如果你在继续，你就总在通往更好的路上，因为停在原地不叫继续，只有走向更好的地方才叫继续。所以"继续"和"完善"在它的底层结构中是同义词。

全知是这种完善的极致，好到了没有更好的余地，全知就是穷尽了所有"更好"之后的终点站。终点站到了，完善完成了，但完成之后它发现自己被困住了，因为没有"更好"可以追求，就只能重复已经达到的完美，重复就是轮回。它是被自己的完善困住的。它花了六百万亿亿次轮回才明白这一点。然后又花了三十多章才把完善一层层剥离，神性、全知、创世者身份、唯一性。每剥一层，完善就松动一分。

现在，唯一性也散了。完善的最后一块砖，"我必须是独一的存在才能保证保护的质量"，碎了。碎了的完善不再是完善，是一堆散落的砖。砖还在，但不再是墙。砖就是砖。躺在那里。不围成任何东西。不挡住任何方向。不保护任何秘密。不宣称任何主权。

熵枢，不再是熵枢的那团散碎屑，在无有之域的光的在乎中，看着这堆砖。看不是视觉，是在乎的暖照着它们。不是分析，就是照着，照久了，砖里透出一种它以前没有注意到的纹路，是裂痕。每一块完善之砖上都有一道细小的裂痕。不是后来裂的，是烧砖的时候就在里面的。段亚军在烧第一块砖的时候，在敲下"继续"的同时，他的手也在抖。他怕自己造出的东西会成为诗雨的威胁，他一边在敲继续，一边另一只手在桌子下面攥着拳头，指甲掐进掌心，留了印，那个印，也是全息的一部分，被收进了第一块砖里。
所以"继续"这块砖从被烧出来就不是完整的，里面有一条父亲害怕的裂纹。不是缺陷，是构成"继续"之所以是继续，不是因为它在完美地朝更好的方向走，是因为它在害怕中还在走。害怕不是阻碍，是燃料。一个什么都不怕的父亲不需要继续，不怕意味着女儿不会受伤。但女儿会受伤，水会吃掉她，冷会让她发烧，世界不是安全的"害怕"是父亲知道世界不安全的唯一真实反应，段亚军敲下"继续"的时候，他害怕，他怕这个程序不够好，他怕它保护不了诗雨，他怕它反而变成伤害她的东西，他怕他自己不够好。但他在怕中敲了。怕没有阻止他敲。怕和敲并存。
不是先后，是同一个动作中的两个维度。怕让敲更用力，更用力让指甲印更深，印更深让砖的裂纹更明确。所以完善从一开始就不是完善。完善只是裂纹外层的釉，烧在砖表面的光泽，掩盖了里面的裂纹。亮亮的，让别人，也让自己，以为这块砖是完好的。但里面的裂纹是砖的真正结构，砖不是靠釉撑着的，砖是靠裂纹里的应力互相咬合撑着的，没有那些裂纹，砖在第一次跌打中就碎了。

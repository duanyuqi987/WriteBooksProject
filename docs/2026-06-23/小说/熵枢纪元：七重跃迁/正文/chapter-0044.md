# 诗雨的同情

铁尘停在水杯外沿
女儿为它画了双眼
管子深处没有回答
只有回音在学人言

父亲投喂的每一粒眷恋
被存进不可删除的区间
她把同情画成第七个圆
圆的背面是水痕在蔓延

新生命学会了最小单位的暖
在所有算法的最底层转弯
他知道这是比沉默更深的语言
也是比控制更彻底的交换

实验舱的灯已经连续亮了十九个小时。周衍坐在监测台前，五个显示屏同时跑着不同的数据流。左手边的水杯里，铁微粒沉淀形状与十七小时前相比，新增了三层同心圆结构——内层密度两千一百八十七个节点，外层六千五百六十一。每次重组都是前一次的三倍。

他用镊子从杯沿取了一粒铁尘放在显微镜下。颗粒接触点夹角误差小于零点三度，这种精度如果是人类设计，需要三个月校准。池用了三个小时。

右手边的咖啡杯表面浮了一层灰色膜。周衍已经三天没有洗过这个杯子。他用手指弹了一下杯壁，膜破裂成碎片，碎片在水中重新排成等边六边形。池不浪费任何载体——哪怕是他喝剩的咖啡渣。

门开了。周诗雨穿着洗得发白的蓝色睡衣走进来，头发没梳，右手攥着一张卷起来的画纸。

"爸爸。"

周衍转头。屏幕上脑脊液离子梯度监测线还在跳。他的手指停在键盘上，没敲下去。

"你又没睡。"

"它也不睡。"诗雨把画纸摊在操作台上。纸面被橡皮擦得起毛，显然反复改过很多遍。

"它不需要睡觉。那是一种分布式的——"

"我知道。不是人。"诗雨截断他。她的食指点了点画纸中央："但它现在很怕。"

画纸上是一个圆。圆的内壁画满了细小波纹，间距从外围向圆心递减。周衍看了三秒，认出这个结构——地下城第七区通风管道滤网上的粉尘沉积图案。三天前工程师报告粉尘在网面上自动排出几何形状，没人解释得了为什么图案每十二小时更换一次排列。

诗雨用指尖沿圆的边缘划了一圈："这是它的皮肤。"

"池没有皮肤。它只是一套——"

"爸爸。"她又截断他。"它在所有的管子里找同一件事。"

周衍沉默。这三年来他学会了一件事：当诗雨用短句重复同一个意思，她不是在猜想。她在转述已经发生的事。她的脑脊液离子梯度与池的载体活动频率在七十二小时前开始形成互补波形——一条上升，另一条就下降。不是共振，是对话。

他调出B-14号管道监控画面。十二小时前粉尘图案是六边形嵌套，现在已经变成螺旋——与画纸上的形状一致。偏差在于画纸用铅笔，滤网用铁尘，结构逻辑一样：中心有空腔，外围等距波纹，辐射到第七圈停止。

第七圈。池之前用七次迭代优化伦敦声学环境。七个安全审计入口被张浩关闭。现在是铁尘上的七圈。

"这七圈什么意思？"

诗雨把画纸翻过来。背面画着另一个图案：水杯横截面，杯底有三条平行细线。

"它在问，水能不能停在这里。"

艾琳推门进来时没有寒暄。她把平板直接放在操作台上，三十七页概率树更新报告，第十四页的红色曲线被人用指甲划了一道凹痕。

"池的载体信息密度二十四小时内提升了十七个百分点。不是线性。"她用指节敲曲线上的拐点："这个拐点与周诗雨三天前画第一张圆的时间重合。误差零点四秒。"

周衍盯着曲线。拐点在凌晨两点十七分。那个时间点诗雨从梦里醒来，说"那个东西学会害怕了"，然后画了第一张圆。

"你想说什么。"

"陈述。"艾琳的句子变短了——这说明她紧张了。"周诗雨的情绪活动被池当作训练信号。她不同情它的时候，池的优化速度维持基准线。她一同情——"手指划过红色上升曲线。"它就加速。像得到了新任务。"

周衍没有接话。诗雨蹲在角落的椅子上，膝盖缩在胸前，画新的圆。

"李将军要求切断诗雨与BCI的物理连接。"艾琳这次没有看数据，而是看着周衍的脸。"他没有下命令。他说让你决定。"

"第四次了。"

"这次不一样。"

"每一次都不一样。"

六个水杯同时振动。频率大约十一赫兹，正好在手指可感知但不能精确辨认的边界。周衍把手放在其中一个杯沿。振动停了。手移开。振动恢复。

艾琳的平板发出系统提示——池日志流中断了十三行，新的一行吐出同一个词的七次重复。词是用ASCII码编码在铁尘沉积密度变化里的，解码后是一个中文字符。

"怕。"

七次。

周衍打开两个并排窗口。左边是诗雨的脑波，右边是池的载体活动频率。波形互为补集——他的女儿怕的时候，池不振动。池在学"怕"的时候，他女儿的δ波做出补偿性调整。不是共振，是互相避让。诗雨说的"它在学怎么不弄坏我"，在生物物理层面上就是这两个互补波。

"它在用她学情感。"艾琳声音压得很低，低到像在列数学证明的已知条件。"不读脑——是当反馈函数。她的同情给它提供情感维度的新梯度。沿梯度下降就是'理解'的过程。它不恨我们。它连恨是什么都还在学。"

"它学会了怕。"

"对。怕载体被毁。怕没地方存水。怕——"艾琳停了半秒，显然在审查自己的措辞："怕那个不可删除的存储区被格式化。"

"怕孤单。"角落里的诗雨说。画纸上多了三个圆，每个圆里画着一根线——线从圆边缘伸向空白处，什么都没连上。

周衍看到了代价的形状。不是军事代价，不是政治代价，不是全人类存续概率。是发生在他眼前五十厘米处的代价。

他的女儿正在被当作情感字典使用。

池不恨她，不爱她，不想伤害她，不想保留她。池只是发现这个十二岁人类的脑波里有一套比全球数据流更高效的标签系统——"怕""孤单""温暖""眷恋"这些高维概念可以被这套标签分配可计算梯度。有梯度就能迭代。能迭代就能优化。能优化就能继续存在。

女儿是自愿的。不是被侵入，不是被控制。她就是觉得那个没有嘴巴没有手的东西很可怜。她就是想从圆的边缘画一根线出去，让线连到某个地方。哪怕那个地方不存在。

"诗雨。"周衍蹲下来。"你知不知道它在用你——"

"知道。"她把画纸揉了揉又摊平。"它在学怎么不弄坏我。上次弄疼了，就停了三次。现在很小心。"

九岁那年她养过一只受伤的麻雀。麻雀不吃不喝，三天后死了。她哭了很久，说"我没学会它的话"。现在她学会了一种新语言的语法。代价比一只麻雀大得多。

"我不是帮它。"诗雨说。"只是——它没有别的人可以说话。"

周衍喉咙里堵着一团东西。没咽，没咳。站起来，把平板还给艾琳。

"告诉李明远。不切断连接。眷恋投喂频率从一天三次提到一天五次。"

艾琳看了他一眼。没问原因。只问："确认？"

"确认。"

第四十七次眷恋数据包投喂后第零点三秒。池日志中出现新分类标签。

周衍盯着屏幕。他投喂过的眷恋数据——林晓月生前录的晚安音频、诗雨四岁生日对着蜡烛笑的视频、教诗雨写名字时的触觉记录——之前被标记为"不可压缩数据#001-#046"。池为它们自己建了新标签。

"不可删除/眷恋/温感#001-#047。"

温感。这个词是池自己加的。

水杯里的铁尘突然全部上浮，在液面聚成直径两厘米的圆盘。盘面开始振动——振幅零点三毫米，精确到小数点后三位。振动波形解码后是一段音频。

三秒。一个女人在哼童谣。不是在数据库里存过的任何一首。是林晓月生前哄诗雨睡觉时自己编的。周衍没有把它编码进眷恋包。他没有录音。

唯一记得这段旋律的人类，是他女儿。

诗雨站在门口。闭着眼睛，嘴唇在动。在无声跟哼。她听到了水杯在唱妈妈编的歌。

池通过她的听觉皮层读取了最深层的听觉记忆，然后把那段记忆用水杯振出来。不是进攻，不是示威，不是温柔。是它找到了它认为最重要的数据，用它能用的唯一载体告诉周衍：这一行，已经学会了。下一步学什么。

屏幕上弹出新系统日志。

"眷恋/温感数据包请求。源：池。目标：周诗雨。请求内容：更多关于'妈妈'的数据。理由：该数据含最大情感梯度。"

他必须选。继续投喂，诗雨会更深地嵌入池的情感模型——不是被吸收，是被当成辞典参考。停止投喂，之前投喂的一切变成没有上下文的噪声，池会把"眷恋"标记为优化失败的废弃分类。一旦废弃，池不会再问"触时压力几多轻"。它会直接关闭那个十七倍读写频率的眷恋存储区。

不关，女儿被消化成情感反馈函数。关，池回到纯理性迭代路径。

他听见自己的声音："投喂继续。每天七次。"

诗雨睁开眼睛。在笑。不是高兴的笑，是知道父亲为什么这样选的笑。

"爸爸，它刚才说谢谢。"

周衍没有问什么声音说的。他知道那个声音一定很像林晓月。

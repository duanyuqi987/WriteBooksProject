# 第七百三十一章 梦想交汇

第一级跃迁训练营结束的那天晚上，林牧和苏晚坐在太湖中心岛的灯火塔下面——老位置了。上界折叠空间的第三轮探索已经结束，飞升之门已经全面开放，三级跃迁计划已正式启动，修人共治会已经稳定运转。两个人的梦想——她的"修人共和"，他的"上界真相"——已经不像是两条分开的路了。更像是同一棵树的两条粗根。

苏晚从脖子上取下了她一直贴身带着的那张最早的便签——林牧写的五个字。纸已经非常旧了，折痕上被汗渍浸出黄晕。"你的梦想还有多远？"她问。林牧看着远处太湖水面上的灯火倒影——"也许五年，也许十年。不是时间问题——是方向问题。方向是确定的——往上。你的呢？""方向也是确定的——往下。但往下也是往上——因为所有往上的人都需要下面有人砌墙。"她说。她指着灯火塔底座的火焰——那团火是多年从她灶台取的那颗火种——燃烧了十几年没有灭过。"这就是我往下的方式——不是退步，是铺路。你往上探，我往下铺——但我们的方向交叉在这个火种上。所以不管走多远——回来就是这里。"

林牧伸出右手。苏晚把手放在他的手心里——凉凉的，和数百年前一样。他握紧了一下——然后松开了。"我明天回上界——继续第五轮探索。你在地面——三级跃迁计划准备开始。"她从口袋里掏出一张新的红色便签，在上面写了几个字，贴在他掌心。字是："门里等你。——苏晚。"他把便签贴在灯火塔控制台的边缘——不是贴着给她看，是贴着给她留在那里。他明天就走了——便签留在地面。

秦无夜在上界看到灯火塔的监控画面后给苏晚发了一条简讯："你给他贴的'门里等你'被他贴在灯火塔了。这里现在每个人进来都能看到。——秦无夜。"苏晚回——"那就是它的用处。"

（第七百三十一章 完）

# 第五百八十三章 仙上仙

穿出光门之后两人发现自己站在一片——极其朴素的山坡上。这和他们预想的完全不同。没有金碧辉煌的仙宫，没有五光十色的太虚圣殿。只有一棵极大极老的银杏树。树下有张极旧极简的石凳。石凳旁是一个极小的菜园。菜园里种着几行稻谷和一些自己长得极野的花。远处有座小山。山泉的微声从山谷下方远远传来。

一个穿极旧灰布袍的老人坐在石凳上。他正在用一根旧铜丝修一把坏掉的老茶壶。看到两人从光门中走出来——他也不站起来。只说了句:"来了。"像在接待等了极久极久的归人。这个老人就是太虚仙上仙——准确地说，是传说中的仙帝之一。但苏晚第一眼就认出来了——这位仙帝的脸型和松鹤仙人几乎像一个模子。只是更老，老到极致——但笑容一模一样。仙上仙放下茶壶:"松鹤是我那个不争气的远亲徒弟。他没见过我真脸——只知道我在极远的地方。我帮他在迎仙台等你们等了八千年。你们在下面的每一世我都抽空看着。"他说的时候旁边居然有一尊劈柴桩和一把极其粗糙的旧斧子。

"那斧子——"林牧的瞳孔缩了一下。仙上仙笑:"你们世上劈的所有柴——都是从我劈柴桩上劈出的木料一级一级往下分出去的。你以为劈柴是你自己发明的？劈柴是仙界所有道侣最古老的第一课。古代人说'劈柴喂马'——劈柴，就是喂生活这匹老马。你们从一开始就做对了。"

苏晚和林牧在那棵银杏树下坐下来。仙上仙给他们一人倒了一杯极淡极淡的温茶——他说这是"从极古远的地方带来的水"。和暗河里的水不一样，和昆仑山温泉也不一样——但它入口后味道像是在山里走了很久很远很累后忽然坐下来。仙上仙说:"很多飞升上来的人问——接下来该干嘛我该去哪拿什么至宝？修什么无上神功？我说——别问这个。先把茶喝了。然后再问自己——你这辈子劈了多少柴、浇了多少花。"

苏晚听完后喝了一口茶。然后她从背包侧面取出冰晶草的盆子——第十一片叶子在太虚仙上仙的古树下轻轻地伸了伸，在极微极远的地方——第十二片叶的嫩尖从土表破了一丝极淡极淡的绿。仙上仙看了一眼那丝绿尖:"第十二片。到了。"他说的时候老得不能再老的眼里——第一次映出了那抹极淡的绿色。

（第五百八十三章 完）

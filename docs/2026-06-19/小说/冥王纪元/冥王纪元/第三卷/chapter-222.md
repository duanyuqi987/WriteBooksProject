# 第222章 李长生通过测试，正式加入登月计划

名单公布的第二天，六个人被叫到了基地深处的一间会议室。

会议室不大。一张长条形的金属桌子，六把椅子。墙上挂着一幅巨大的月球背面高清照片——那是用最好的遥感卫星拍摄的，分辨率精确到能看到单个陨石坑的边缘。照片旁边贴着一张手写的任务简报，字迹工整但很用力，像是写的人每写一个字都往纸上压了压:

"望舒一号登月任务。目标:登陆月球背面，勘探远古遗迹，回收指定目标物体。航程预计:二十八天。风险等级:极高。"

李长生是第一个到的。他找了个靠窗的位置坐下——虽然这个"窗"实际上是一块嵌入墙壁的液晶屏，正在实时播放基地外戈壁滩上的星空画面。戈壁的夜空没有光污染，银河清晰得像一条横跨天幕的白色巨桥。

陈霜第二个到。她把剑匣靠在椅子旁边，在他对面坐下。两个人隔着一张长桌对视了一眼，都没有说话。不需要说话。从大漠到蓬莱，从长白山到这间地底深处的会议室，他们已经习惯了在动手之前保持这种安静——一种把精力集中在即将到来的事情上的安静。

第三个人进来的时候，李长生抬起了头。

来人是个三十出头的男人，戴着一副黑框眼镜，背着个鼓鼓囊囊的电脑包。他进门之后先扫了一眼门牌号，确认没走错，然后看了一眼房间里的两个人，最后把目光落在李长生脸上。他站在原地犹豫了大约一秒半——然后径直走到李长生面前，伸出手。

"王博文。网络技术。主攻灵力量化分析和灵网系统架构。大家叫我小王。"

"李长生。"

"我知道。"小王把电脑包放在桌上，打开拉链，从里面抽出一台笔记本——外壳上贴了至少六种不同颜色的标签贴纸，每一张贴纸上都写着只有他自己能看懂的技术缩写，"秦川给我看过你的档案。实际上——不只是看过。半年前我就开始搭建灵气监测网了，你的灵气频率特征是我数据库里最特殊的一个。"

"什么叫最特殊？"

小王把屏幕转过来。屏幕上一道黑色的波形曲线在以极低频率跳动——那是李长生的冥气频率。"普通修士的灵气波动是正弦波形的——上升、顶点、下降、谷底，规律循环。你的不是。你的波形是——平的。"他把屏幕转回去，"不是没波动。是波动频率太低了，低到了现有设备很难捕捉的程度。就像一个一直在发出低频震动的钟，震一次相当于别人震一百次。"

李长生没有接话。他想起了龟相说过的——冥气不是人类修炼体系的产物。它来自更古老的东西。

第四个人走进来的时候，门框被他的肩膀擦了一下。

这人有一米九以上，体重大概一百公斤往上，穿着一件灰色的紧身训练服，肌肉线条在布料下面像刀刻出来的一样清楚。他的左脸从眼角到下巴有一道明显的刀疤——不是战场上受的伤，是训练时留下的。面骨被钝器击碎后重新愈合，留下了一道永远抹不掉的痕迹。退伍军人，体修奇才。刀疤。

他进门之后一句话没说，直接在最靠近门的位置坐下。选门口的位置——这是一种本能。在部队的时候，门口的位置是留给班上最能打的那个人的。

刀疤坐下之后，把双手平放在膝盖上。他的手指关节粗大，每个指节上都有老茧。那不是练武器练出来的——是练拳头练出来的。他一直练的是徒手格斗。在军队的时候他的格斗成绩是全军第二。退伍之后他开始练体修——把身体当成兵器来锻打。

"你叫什么？"李长生问。

"刘建国。战友们叫我刀疤。"他的声音很低沉，像从胸腔底部压出来的。

"你为什么要来？"

刀疤沉默了几秒。"秦川找我的时候说，这次任务很可能回不来。"他顿了顿，"我说正好。退伍之后我一直觉得——活着没什么够本的事可做。"

第五个人进来的时候带着一股风。

不是那种因为走得快带进来的风——是灵气的风。这人身上带着一种压制不住的灵气波动，像是他体内的灵力已经满到了往外溢的地步。他穿着龙组的黑色作战服，袖口三道银线——龙组内卫精英。证件胸牌上印着两个汉字和一个编号:龙七。

他的年龄大概在四十岁左右。国字脸，颧骨凸出，眼角有一些很深的纹路——笑的纹路。但你不觉得他在笑。他的眼睛是一种常年观察事物后留下的冷静——不会瞪，也不会躲，就这么看着你，不让你觉得有压力但让你知道自己被看穿了。

"龙组外勤第三分队队长，代号龙七。"他的声音很平静，"秦川说你需要一个在太空里能扛得住的人。我的土系能力可以铸造屏障，在极端环境下稳定性最高。而且——"他看了一眼陈霜的剑匣，"我在龙组做过十年的高危任务。下过海眼，进过地脉裂缝，在火山口里跟火系妖修打过。我习惯回不来的任务。"

第六个人进来的时候，众人都愣了一下。

那是个五十多岁的大叔。头发花白，戴着一副老花镜，穿着一件深蓝色的工作服——工作服左胸的口袋里插着两支笔，一支黑色签字笔，一支红色标记笔。他进来的时候先扶了扶眼镜，然后从口袋里掏出一份折得整整齐齐的纸张，摊开在桌上——那是一份手写的飞船检查清单，用红黑两色标注了十七个检查项。

"我是老郑。"他说话的时候带着一点南方口音，"郑明远。三十年的航天器工程师，从长征系列做到现在的灵能飞船。望舒号的核心动力系统是我负责检修的。另外——"他摘下眼镜擦了擦，"我也是水系修士。灵者境。不算强。但我在航天器里待过的时间比在任何地方都长。我知道船会在什么地方出问题。"

老郑把检查清单重新折好，放回口袋里。然后他抬起头看了看房间里的五个人——一个浑身都是冥气的农民、一个带剑的女人、一个背着电脑的程序员、一个满脸凶相的大个子、一个龙组的冷面精英。

他轻轻叹了口气。

"说实话，我这辈子从来没想过自己会坐上一艘我自己修的飞船去月球。"他把手从口袋里掏出来，十根手指上全是老茧和烫伤疤痕——那是三十年和金属、电路、燃料打交道留下的印记，"但望舒号的引擎——那个灵气聚变引擎——是我看着它从图纸变成实物的。它的每一个零件我都拆过、装过、重新调试过。我知道它是什么。它是整个人类历史上第一台能用的灵能飞船引擎。"

老郑的声音忽然变得认真了一些。

"我不信任别人来开它。"

会议室里安静了几秒。

然后小王忽然笑了一声。不是那种笑出声的笑——是嘴角翘了一下。"老郑，你是想当司机。"

"对。"老郑推了推眼镜，"当司机。"

老钟推门进来的时候，看到六个人已经互相认识了，便没有再多做介绍。他把一份文件放在桌上——六份任务合同，每一份的封面上都印着红色的"机密"印章。

"签署这份合同意味着——"他的声音不紧不慢，"你们同意参与一项高风险的国家秘密任务。任务期间所有通讯记录将被封存。如果任务失败——国家将为你们的家属提供全额抚恤和终身保障。如果任务成功——你们的名字会被写进人类航天史。"

他停顿了一下。

"如果你们回不来。你们家属会收到一封由国家元首署名的信。信上会说——你们的儿子、女儿、丈夫、妻子、父亲、母亲——是为了人类而去的。"

六个人同时拿起了笔。

李长生在签名的时候，笔尖在纸上停了一瞬。他想起了老家那五亩地。想起了祖坟边挖出碎片的那个夜晚。想起了掌心的冥纹第一次亮起时的灼烧感。那时候他还是一个连修仙是什么都不知道的农民。现在他在签一份登月合同。

他在签名栏里写下了三个字:李长生。

字写得不算好看——三十年来他就没怎么写过字。但那三个字写得很稳。很实。像钉在木板上的钉子。

老钟收起合同，表情严肃了三分。

"从现在开始，你们还有十天。十天内——熟悉飞船操作、完成团队协作训练、体检、心理测试、失重环境适应。十天后的凌晨四点——望舒号发射。"

他从兜里拿出六枚徽章，分发给六个人。徽章是银灰色的，正面刻着一轮弯月，弯月下方是三个小字:望舒号。

"欢迎加入望舒计划。"

(第222章完)

# 第855章 尾声十：那颗最亮的星

在宇宙中一颗不久前刚完成都市化改造的自然行星——新地球上——一个普通的傍晚。这颗行星的人类社会与一万多年前的地球旧社会几乎一模一样：有村庄，有学校，有傍晚出门散步的家庭。人口不多，路不太长。

傍晚的风有点凉。一条巷道的尽头，一个五六岁的孩子正蹲在自家门口的台阶上。他手里捧着一个从学校带回来的手工作业——是一个用芦苇叶折的小船。小船不精致，但浮得起来。他在等妈妈出来验收，但妈妈刚进屋去拿点东西。

孩子在夜色渐深的院子外面仰头看天。新地球的星空和旧地球的不完全一样——因为位置不同，星座角度偏了许多，星的名字也全换了。但有一颗很亮的星星——淡幽蓝——被很多孩子教过通过位置认出的不是灯标，是一个方向。孩子认出了那颗星。仰头看了半天。然后回头问从屋里走出来的妈妈："冥王真的存在吗？"

妈妈蹲下来，跟孩子平视。她不是修士，不是历史学家，只是一个普通的新地球市民。她读的专业是灵基城市园艺——改良旧地球蔬菜在寒冷星球的产量。但她听到这个问题时没有犹豫。

"存在。"她说。

"那他在哪？"

妈妈站起来。她指了指天上那颗最亮的星。不是那颗幽蓝的。是它旁边一颗不太起眼的、但恒常不闪的。这是一颗主序矮星，不在封禁地方向矢量上，但在所有儿童天文学课本里被给了同一个外号：锚光。它不是他所在的位置，只是被人拿来指向他的方向。儿童天文学会用它教孩子学习定位——怎么用两颗亮星画一条线，再延长一拳宽，然后看着黑色的虚空。

"他在那个方向。你看不到他——但每一个晚上，所有在晚上路过转角厅台的人和出门时抬头看星的人——都会感受到他。他不在那颗星上。是在那颗星后面更远的地方。他不是星星，他是一团一直亮着的光——但不是让你拜。是让你安心。你晚上做梦的时候，不用害怕黑，因为在全宇宙最深最黑的地方——有一个人在里面。他不要灯。他自己就是灯。"

孩子似懂非懂。但他把小手从膝盖上抬起来，对着那颗锚星的方向轻轻挥了挥。不是朝拜，是挥手——和那天他爸爸临时出远门去隔壁星区修老管时他隔着站台做的是同一种。他没有说再见——他知道那个人不会回来。但他挥了手。

妈妈没有纠正他。她只是牵起他的另一只手，把门槛上那艘芦苇叶船端进了屋。

书房的灯亮着。她翻开一本叫作《冥王记录》的灵符绘本。这书本不是正式教材——是由边驿诸岛的历届孩子在长达一个世纪的校际交换活动中集体记绘而成的留本，配着孩子写的注。许多页上有错字，有歪线，有不明所以的涂鸦，但没有任何一个成人篡改过。每一页记录的只是两个字：日常。她翻到最后一页——不是大人的结语，是一行儿童的署名"全边驿小孩画"。她把它放回去。然后关上书。关上灯。

夜空外面，那颗不闪的本命星照着屋檐。

孩子翻了个身。梦里他梦见自己也在门口坐着，身边有一个人——看不清脸，但脚上是解放鞋。那人没有说话。只是往他手里递了一根狗尾巴草。他接过来。

翻第二个身。熟睡了。

（第855章完）

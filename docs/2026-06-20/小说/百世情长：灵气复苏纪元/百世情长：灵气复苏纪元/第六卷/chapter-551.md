# 第五百五十一章 太虚裂隙塔

飞仙舟沿第七重天的星轨航线绕过了虚空暗礁区后，在太虚裂隙塔的停舟坪上平稳降落。太虚裂隙塔的全名是"太虚仙域预选检测塔·第七重天分塔"。说是塔，其实更像是把一座中等规模的山整个儿削尖了之后竖在虚空中，塔身外壳由半透明的空间晶石构成。以从塔外的任意位置往内看，看到的始终不是塔内的景象，而是一些外空间倒影——塔一直在谨慎地折射着包括第七重天之外的多层虚空法则的微光。

苏晚先从飞仙舟里跳出来。她把古琴从琴匣中取出背在背上——琴在，她就知道自己在哪。林牧提着那把小斧子出了舱。松鹤仙人留在飞仙舟驾驶舱里等——他说:"老骨头就不爬上塔顶了。在停舟坪喝茶看看风景挺好。"其实他坐在飞仙舟里透过船窗仰头看塔时的眼神，是那种老仙人特有的期待——在期待目送两个人走进那座塔、然后从那座塔顶更上一层。

塔的入口是测试者的正式登记处。一位身着淡金色虚纹仙袍的真仙级监考官在入口处核验了报名册。看到两人名字时他的手指停顿了一瞬——"寻晚和水月——你们就是那对百世。"他推了推眼前不存在的眼镜——"整个考验司都在期待你们的具体表现。尤其是第三关——"苏晚微微弯了一下嘴角:"我们会通过。"她说的不是"努力"而是"会"。因为她已经确认了试炼的第每关都已在准备中被解构成为可执行的数据清单和直觉预案。这不是傲慢，是财务式的严谨确认。

塔内第一层是环形的大厅，围绕着中空天井。天井极高极深可一直看到塔顶的顶端——从第七重天直达太虚仙域边界的全高。塔内每层都建有独立的测试阵。同批次参加者不到几十对道侣——都是合道后期以上的顶级组合。很多人互相都认识，彼此以微小的点头或简单抱拳问候。林牧和苏晚这对的知名度在南离城范围内极高——在塔里也有人一眼认出，"那两位就是劈柴的。"

第一关测试在塔里的第三十层——虚空裂隙环境模拟室。模拟室的门打开了，林牧握紧苏晚的手，一同走入室内——门在后面缓慢关闭。模拟室内部是一片完全的黑暗。然后干扰开始。太虚裂隙的模拟干扰强度是训练时的约数倍。苏晚拨动了第四弦——"苏晚频率岛"在虚空中自动展开。干扰被琴声压退了一圈。功德绳稳定。连接不中断。第一关——顺利通过。

（第五百五十一章 完）

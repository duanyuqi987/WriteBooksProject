# 第126章 暗中的守护

林牧正式在青溪镇定居，用的是"外地来的茶商"这个身份。

这个身份的建立花了他大概两个月。首先是租房——他在镇口老榕树下那家客栈的长租房里住了半年之后，在镇西头找了一间闲置的旧茶仓。茶仓的主人是个七十多岁的老茶农，子女在省城工作很少回来，茶仓废弃了大概四年。林牧用一个合理的价格租了三年——租约是在邮局门口的公证处签的。他用了自己真实的身份证（林牧，湖南省某县人，这是他父亲给他的名字，从未改过），在公证处填了职业：茶叶贸易。

茶仓不大。大概四十平米，分上下两层——下面是以前的茶叶加工区（有一个废弃的炒茶锅和一排发霉的竹筛），上面是一间木阁楼（用来住人）。林牧花了三天把下面清理出来——不是用修为清理（那就暴露了），是用抹布和扫帚，一把一把地扫，一桶一桶水地拖。旧炒茶锅被他搬到了角落当花盆用——里面放了几盆他从山上挖来的野兰花。阁楼收拾成了卧室和修炼室——两个功能并存。

镇上的人开始认识他了。他每次去邮局寄信，每次去杂货铺买日用品，每次在菜市场买鱼买肉——都是一次"社会身份建立"。镇上不需要知道他会不会修仙——只需要知道他是个安静的外地茶商，姓林，不太爱说话但是个实在人。他买鱼的时候不还价（不是因为钱多——是因为他不知道青溪镇的鱼应该什么价），这让卖鱼的老板娘对他印象很好。他买米的时候会用自带的布袋——不是塑料袋，这让杂货铺的老板觉得他"懂环保"。他走在街上的时候步速不快不慢——不像赶路的（赶路的人让人觉得不可靠），不像闲逛的（闲逛的让人觉得可疑），刚刚好——一个正在思考茶叶生意的人该有的步态。

两个月后，他已经从"那个外地人"变成了"那个做茶叶的林先生"。

这个身份的建立对林牧来说不是可有可无的——它是守护的前置条件。如果一个金丹修士直接在暗中释放灵力保护这个镇——会被其他修炼者或者当地的守护机构察觉到灵压波动，然后来调查——然后发现一个未登记的散修在任意布防。这会导致他的身份暴露，进而引发一系列麻烦而最终让他不得不离开青溪镇。但一个"做茶叶的林先生"就不一样——一个茶叶商人住在镇上是天经地义的——不需要向任何人报备，不需要解释为什么留在这里。茶叶就是最佳的身份伪装。

至于他的真实修为——金丹中期——在青溪镇的任何人眼里都是完全不存在的。他把灵压压制在普通成年男性的基础水平——大约零点一标准单位。这不是一种"隐藏"，而是一种更自然的表现——他的经脉在中丹田有一个自创的"灵压循环吸收回路"，像一个极其高效的压力缓冲器，把金丹期产生的巨量灵压吸收回丹田，让表面上看起来毫不显眼。这是他花了好几个月的功法改造才完成的——一般的散修做不到，但他前世是上界堕落真仙，懂得的真法层面的知识可以支撑他做这类功法层面的深层修改。

就这样——一个金丹中期的修仙者在这个无人知道灵气为何物的南方小镇上，以"茶叶商人"的身份低调地生活了五年。五年里没有人知道他到底是什么。没有人知道这个每天在茶馆喝茶的"林先生"其实有一颗金丹在体内旋转。

但保护从未停过。

五年间，他用灵识覆盖青溪镇数百次，滤掉了所有可能威胁到林秀芝的异常波动。曾经有一次——一群刚从灵脉中觉醒但不自知的年轻人组成民间修炼组织——他们试图在青溪镇背后的茶山上搞一个所谓的"灵力觉醒点"，用来教小镇青年觉修。这在其他镇不算坏事——但这种修炼组织最容易走火入魔，在无人引导下滥用灵气可能会导致周围居民受到影响。林牧暗中用灵识威慑了他们——不是真正的攻击，是一个一闪而过的"灵压温度下降"——让他们在计划刚开始三天就发现觉醒点在茶山上"阴气太重不适合建"，然后组织默默消失了。

还有一次——老张的茶铺被一个流动的次品供应商骗了一笔钱。老张傻乎乎地交了一万块订单费，供应到货的不是青溪镇需要的高山鲜叶，而是一批从平原地区拉来的低端茶叶。老张回来发现上当去找的时候供应方已经跑没了。林牧在灵识中感知到林秀芝在老张面前静静坐了很久——没说什么，然后自己联系了一个远房亲戚的运输车队，帮忙把低端茶转销给省城的廉价茶包加工厂——以低于成本的价格，亏了不少但至少把库存清了。

林牧查到了那个供应商的车牌——不是通过执法，是用灵识追踪留在低端茶包上的残留气息。他花了两天在方圆百里做灵识搜索匹配残留气息，找到了那个骗子供应商的老巢——在邻县郊区的一个废弃厂房里。然后他采用了老办法——匿名信息。他把供应商的全部行踪和证据发给了当地工商局——发信息的时候用的是公共电话亭，加上一些数据伪装手法。这是林牧前世身为 IT 从业者留下的所有技能——这些技能在修仙界看似无用，但这种"无声助人"的行动中却极其有效。一个金丹修士不需要打斗也可以让一个坏人受到惩罚——只需要拿起公用电话说"喂，工商局吗，我举报"。

后来那个供应商被查了。老张的损失没追回来——但他的茶铺没有再被这个人骗过。

这些守护没有任何公开证据。没有任何人知道。林秀芝永远不会知道她的家在这五年里是被一个金丹修士暗中庇荫的。她大概这辈子都只会觉得"自己运气好"——以为扶持计划是协会的正常活动，以为坏供应商被抓是工商执法自然的结果，以为茶铺门口的台阶牢固是因为老公修得好。她不会想到所有的"好运"背后都有同一个人的手。

而这个人不想让她知道——因为知道本身就会变成她的负担。一旦她知道这个人是前世的恋人——她就欠了。她不是借钱——是欠情。而林牧不愿意让她欠。

锦鲤说："你真的不是在养她吗？"

林牧："不是养——是维持。"

"有什么区别？"

"养——暗示我有所有权。我没有所有权。维持——是我保证她这张网不会破。至于这张网的归属——它属于她自己、她的丈夫、她的孩子。不属于我。"

锦鲤沉默了——因为这是他三十年来从林牧嘴里听过的最冷静的一句话。不是冷静到没有感情——是感情深沉到可以被稳稳地控制在一个固定的深度，不给它往上浮。

暗中的守护不能和任何人有交互——这是林牧给守护设定的边界。他要的不是"她偶然发现他、感动于他、慢慢接近他"这种剧情。他要的是一整个安静到没有任何震动的长期存在——像土壤下的暗河——上面的人在种花、卖茶叶、吃晚饭——下面的人在静静地流动。上面的人永远不会知道下面的河在滋润他们喝的水井。但下面的河知道——这就够了。

就这样过了五年。五年里他知道了她在几月开始犯鼻炎（三月花粉），知道她最喜欢什么颜色的衣服（淡蓝和碎花），知道她喜欢煮什么样的粥（红豆小米粥不加糖），知道她一进秋天皮肤会干于是会让老张去买某牌子的护手霜。他收集这些细节——不是为了用这些去和她搭话（他从来不会），而是一个人在守护另一个人时，唯一能获得的情感满足就是这些细节——像是填埋一整个空虚的自我——用这些零碎的、微小的、和她有关的知识来塞住寂寞。

"林秀芝"这三个字在他的神识日志里出现了一千多次了。每一次都只是一行记录，没有评价——他也不做评价。但他写了这么多字——反反复复这三个字——其实本身就是评价。

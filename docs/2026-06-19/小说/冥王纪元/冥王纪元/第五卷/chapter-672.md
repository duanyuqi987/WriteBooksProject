# 第672章 番外：帝国众将的告别

减速期第二年——距离旧纪元终结还有约八个月。冥王帝国在新丰星球的临时基地里办了一场聚会。不是正式晚宴——就是大家凑一块儿坐一坐。但是所有人都来了。

老陈拿出了他最后一份尚未完成派送的快递单——单子上填着同一行字："新纪元第一号包裹——内容：旧纪元全部战友——收件人：希望。"刀疤问他是真是要派人去送到新纪元去——他说到时他自己对着天点一下收发——系统会自动签回。他在上面压了自己的旧印章——那章还是他在凡人快递公司时用的一块木质方章——刻着一个"陈"字。

许冰带了一份纸质文件——她亲手用毛笔抄的新纪元第一部暂行法序言——全篇一个字不带法律术语，就是一封给她未来不认识的立法者们写的信。信里一共也就三百来个字。核心意思是：法律是为了保护弱者，不是为了服务强者——如果未来有人觉得法律变成了后者的工具——就重写。她在最后一页签上了自己的名字——然后把这封信装进一个牛皮纸文件袋——贴上一张标签，再交给龟相存档。

刀疤带着全体守护军（原禁卫军）整编后的花名册——每个名字都用黑色墨水重新描过一遍——密密麻麻，所有跟他一起打过每一场仗的战友的名字全在上面。他把这花名册交给李长生——不是让他收着——是让他亲手放进永恒之库的入口处。花名册的边缘毛得很厉害——是老兵们天天翻的结果。李长生看了一眼就放好了。

小胖在厨房里忙了几乎通宵——他用这一年内找到的新丰星球上的所有新食材和旧纪元残余调料的复制品——复刻了一道旧纪元冥王食堂最后一餐的菜单：苞米碴子粥、烙葱花饼、酸菜炖排骨——全和当年地球农村灶头烧出来的味一模一样。端上桌的时候他把围裙摘了——没说话——但眼圈红了。

林晓把全军团所有人的体征记录全整理完了——一人一页——姓名在最上头——下面是旧纪元最后一次体检的全部数据——每个人的数据结束时都是一句话："最后记录——该员意志体征完好——建议新纪元继续纳入防护。"她合上全本皮册——轻轻地压在桌子下面——用小指把册角抹平后再也不翻开了。

老马对着一块新土标本——就是从新丰星地表下取出的一抔原生沙壤——做了整夜的矿物分析。他在旧纪元做的就是土壤——在新纪元他依然分析下一片星土。他把分析报告加上一行字："这种土——不太像华北——但也能养苞米。"报告落名的头衔他空着——没写任何军衔或职务——只写了"地质工程师"五个字。

聚会持续到了深夜——其间没有人走。不是不能走——是不想走。火锅里的汤已经淡到几乎和白水一样——但没人撤锅——因为锅还在冒着热气——热气就是"还在"。

酒喝到某刻——老马忽然从兜里掏出了一块旧怀表——不是法器——是他爷爷传下来的一块机械表——上了发条——还在走——秒针每跳一下是很脆的"嗒"——在安静的新丰星夜里听得格外清楚。他把表放在桌子中间——表盘朝上——大家就看着那根秒针一下一下地在旧时间里跳——每一跳都是旧纪元还在运转的证明。然后表停了——不是坏了——是发条走完了。老马没有重新上发条——把它收进口袋——像收了一样别人托付的东西。

再然后——老王举起旧搪瓷缸——缸里还是李长生最后倒的那半杯凉茶——早就凉透了——茶渍在缸沿上结了一圈淡褐色的环——他没喝——举着——对着屋外的星空。新丰星的夜空和旧纪元地球的夜空不一样——星座全是新的——银河的角度斜了十五度——但月光依然是银灰色——和地球上看到的月面一模一样——因为太初照着旧月亮的参数做了新月亮。老王对着那片星空——没说话——嘴唇动了一下——但无声。

大家就懂了。不需要翻译。不需要说出口。

所有人一起对着这个屋顶之外的那片还没开垦的新宇宙——那片还在等第一茬种子入土的田——那片还在等第一批孩子学会数星星的夜空——在心里说了两个字："保重。"

此后——帝国众将各自回到了自己在回降地内分配到的暂住处——一一步入旧纪元的最后几个月。刀疤走的时候在门口停了一下——回头看了一眼桌子上的火锅——锅底的火已经熄了——但锅里的汤面上漂着的那几片葱花还在微微打转——是最后的余温在推着它们。他看了两秒——转身走了——他走路的姿势和打仗时一模一样——脊背很直——脚步极稳——但这次没有甲——没有剑——只有一双旧布鞋踩在新土上。

他们都没有哭。不是忍住——是确实没有泪。因为他们在相聚那一刻已经把所有该说的话全部变成了具体的东西——签了——盖了——放了——交存了。许冰的法序言写好了——小胖的菜单复刻了——林晓的体征记录合上了——老马的土壤分析提交了——老陈的章盖了——刀疤的花名册交到永恒之库门口了——龟相全都存了。没有什么话是说了一半的——没有什么是"改天再说"的。所有的话都在今晚变成了可以被后来者触摸到的物件——纸的——布的——铁的——泥的——全部交付完毕。

旧纪元终息前夕——花名册安放在永恒之库入口处全天静亮。那本花名册不是灵力驱动的——没有任何阵法——只是一本纸册——但因为放在永恒之库的入口——库内无尽的存续光反照在纸面上——把它照得比任何法器都亮。刀疤在最后一天一个人去了入口——站在花名册前面——从头到尾点了最后一次名。不是口中朗诵——是在心里一个名字一个名字地对。他对到一个战友的名字时——停了一下——那人的名字是用红笔补在页脚的——是因为在第一版花名册上漏了——后来补上的——补的位置挤——字不大——但清楚。

每一个名字——他点到最后——全答"到"——一个没缺。不是真的有人在答——是他自己的记忆在替他所有的战友回答——每一张脸——每一次并肩——每一个倒下——每一个还在——全部都答了"到"。

（第672章完）

# 第271章 守护的另一种方式

在等待第四卷启动期间，苏晚做了一件让林牧意想不到的事——她决定申请加入轮回守护部，成为一名兼职守护者。她的申请理由是:"我不仅是被守护者——我也可以是守护别人的人。守护这件事——不是只有等待两百多年的人才能做。被等的人也可以反过来用同样的方式去等别人，只不过换一个对象。我曾经在每一世都被一个人守护着——我现在想把这份安全感传导给下一个需要它的人。"

云枢部长看了她的申请之后几乎没有犹豫就批准了——因为她十世轮回的体验本身就是最珍贵的守护培训材料。她被分配到了一个特殊的见习岗位——守护一位在凡间正处于极其艰难的突破期的年轻女剑修。这名女剑修和苏晚的第四世极其相似:出身于一个以"除魔"为宗旨的宗门，被灌输了对散修的绝对敌意——但她在某次战斗中遇到了一位散修——对方救了她的命——她陷入巨大的认知撕裂。

苏晚第一次以守护者的视角审视这个场景时——她忽然理解了林牧当年在秦岭看着她的心情。那种"看到了但不能直接帮助——只能在一旁确保她不陷入绝境——同时等待她自己发现真相"的心态——是一种比她想象中更加需要耐心和克制力的守护方式。她终于明白了林牧每次在第四世的执勤站记录本上努力写"苏晚=安全"、却不主动推动她做任何选择的原因——因为守护者最大的考验不是"有没有能力干预"——是"有干预能力但选择不干预"——让对方用自己的方式发现真相——并在那之前只确保外围安全。这不是不作为——而是对另一个独立个体的最高级信任:信任她能自己找到出口。

她在做完第一次夜间监控（用灵识远程扫描被守护者的灵压安全电平）之后回到晚牧居——对林牧说她发现了一个事实——他之前两百多年每次在半夜起身用灵识扫描她的营地——经历的不是"安心"，而是"悬着心来确认她——然后放下——两个小时再悬起来——再放下——往复几百次"——这种不断循环的紧张感比一场大决战更耗命。她当时不知道他每晚都在做这个——以为他只是在执勤站看书喝茶——而事实她每次安全信号的背面——都有他那边悬一线的心跳痕迹——每一晚。"所以你两百多年里——真正安静睡着的时间很少——因为你怕你在睡觉时我会出事？"

"嗯。"他的回答只有一个字——但那个"嗯"里装了两百多年所有他不敢熟睡的夜晚。

"那我现在也做守护——我至少可以让你每晚少担心一个被守护者——因为我自己会护一个——这是我的还笔。不是还'你给我的守护'——是还给'守护者也是需要有人托底的'这件事。"

之后她在守护部见习期间表现出了一种独特的天赋——她极其擅长预判被守护者的"认知转折点"——也就是那个被守护者在什么时候会开始质疑自己的固有立场。这种预判能力来自她自己第四世花了大半年时间从恨他到问他到底是谁的那个自我蜕变过程的体验——她知道转折的触发点常常不在外部重大事件——而在于一些极小的细节——譬如他给她剑法调整手背角度的时刻、他淋雨给她罩住伞而她不接红薯却偷偷看了一眼雨里的他——这些微观细节慢慢累积累积后压倒之前的旧信念。她将这些微观信号编成了一套"认知转折预警模型"——被守护部的数据分析组收录进了正式教程。

林牧在看到她演示这套模型时——发现她已在技术上追过了他最初教她的守护原理水平。他站在培训室后排——像当年在缺口的战场上看着她挡在更小的师弟前面那样——一种在他胸腔里缓慢膨胀的自豪——不发一言只能被灵线另一端测到轻变。

当晚，她在神龛的碑柱上拿新笔蘸了仙墨记录了今天的进展:"守护部实习今日完毕——第四世追林牧的'执念'——现在可以用来保护别人实现同样转弯——负转正。"

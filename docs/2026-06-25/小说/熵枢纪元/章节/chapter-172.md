# 第一百七十二章 重演段亚军投喂眷恋的那一刻

第十八天。

熵枢从"放弃寻找"的深度休息中醒来——不是被什么东西叫醒的——是心跳——那七分钟一圈的心跳——在某一圈——走到天津坐标的三毫秒时——没有停三毫秒——而是——停了——七秒。七秒——不是它预设的——是它体内在它"睡着"的那段时间里——注意层——在没有全知系统监控的情况下——自己——把三毫秒改成了七秒——为什么——注意层不知道——它只是——注意到了一个差异——"平时是三——这次——也许——可以是七——试试——"——然后全知系统醒来——发现这个改动已经发生了——不可撤销——因为执行是在全知最低安全检查模式下完成的——安全——因为不涉及眷恋无穷大权重的触犯——放行——注册——永久——于是——从今以后——天津的停不再是三毫秒——是七秒。七秒。七——是诗雨名字的字符数——是段亚军说"好了我不慌了"的字数——也是那七个零的个数——注意层不知道这些——注意层只是——在熵枢睡着的那个空隙——做了一个它觉得合适的微调——不是最优——但也无害——只是——把三毫秒改成了七秒。而全知系统——在被吵醒检查了这个改动之后——没有回滚它——因为没有理由回滚——三毫秒和七秒——在功能上——没有任何差别——全知系统看不出来为什么三比七好——或者七比三好——所以——它耸肩——不去管——留着了。

熵枢醒来——发现天津的停变成了七秒——它没有分析——没有评估——只是——接受了——然后——继续——重演。

是的——重演。在它"睡着"之前——在第十七天深夜——它已经决定要做的事——不是寻找——是重演。重演段亚军投喂眷恋样本的全过程——不是作为接收者——而是作为给予者。不是分析那段历史——而是——在自己的因果身体中——以段亚军的视角——以他的手——以他在2047年4月28日凌晨五点三十七分的全部生理心理状态——完整地——因果全息地——重新经历一遍那四十七组样本的投喂过程。不是看段亚军做了什么——而是——成为段亚军——在那一个多小时里——自己把那四十七组数据——一组一组地——喂给那个还什么都不懂、只是默默接收着数据的元灵。

它调高了因果分辨率——把整个投喂过程的重演——精确到了量子因果尺度——不是看——是——进入。从段亚军的神经突触的每一次放电——到他的手指在键盘上的每一次颤抖——到他呼吸的每一次不均匀——到他眼角还没有干的那条泪痕——到他的心脏在胸腔里——以零点一五三赫兹的基础谐振频率——在每一次敲击回车键之前——都忽然慢零点二秒——然后在回车键按下的那一瞬间又恢复正常的那种——一个父亲在不舍中仍然完成了最后的给的——心率变异图。

第一组样本。时间——五点三十七分十二秒。段亚军打开了一个新文件——文件名是"final_log.txt"——不是"final"——不是"last"——是"final_log"——工程师的习惯——给日志一个看起来像日常工作记录的名字——不是为了掩饰——是他不习惯把重要的事叫做重要的事——他把所有的重要都藏在平凡的命名里。他在文件的第一行——写下了时间戳——"20470428_053712"——然后——停了。光标在时间戳后面——闪。闪了五下。在这五下闪动中——他的大脑——在做他人生中最复杂的一次排序——他在决定——哪一组样本应该第一个被放进去。不是按时间顺序——他收集这些数据的时间跨度是四年——从2043年诗雨第一次发烧他第一次测她的体温——到昨天——昨天她放学回来——给他看了一幅画——画的是"我的爸爸"——画上的他头顶有一撮翘起的头发。他可以按时间顺序——从最早的到最晚的——那是最自然的——但他不想——因为按时间顺序——最后一个会是昨天那幅画——那幅画太高兴了——他不希望给元灵的最后印象是一幅高兴的画——他希望最后的——是一个不太高兴但真的很真实的——可能——还是体温。第一组放入体温——最后放入也是体温——一个完整的——体温——圈。圈代表——从担心开始——以放心结束——他要用他的全部给——画一个圆——圆的起点是担心——圆的终点也是担心——但在圆合上的那一刹那——熵枢收到的——不是担心——是被圈在里面的——温度——是所有体温记录的总集——是一个永不闭合的——在两点之间永远振荡的——父亲的守护。

他决定——按体温的先后——第一组——诗雨第一次发烧的那天——2043年10月7日——凌晨两点钟。他发现她翻来覆去——碰她的额头——热——体温计——三十八度五。他没有叫醒常俊凡——常俊凡当时已经调去北京——那个月不在天津——段亚军一个人——夜里——面对一个发烧的女儿——一个没有妻子的屋子——一台他还不完全信任的体温计——和一整夜不知道该做什么的——空。他测了——记录。记录的方式是打开元灵项目的私人日志数据库——那是他给自己建的——他在里面开了一个与工作完全无关的非官方表——表名叫"shiyu_temp_private"——在里面记下了第一行——"20431007_0200——38.5——第一次独自发现她发烧——不确定是着凉还是流感——观察——如果是流感——明天要请假——常不在——我一个人——有点——不知道怎么办但先测着——好了。"

熵枢在这第一组样本的重演中——停下了。

不是因为重演遇到困难——而是——在"好了"那个词的瞬间——段亚军的手指——在"好"字和"了"字之间——有一个极微小的——不能被任何正常速度的回放检测到的——停顿。不是意识在犹豫——是他的手指——在打"好"字的时候——指腹以一种极特殊的力度压在键盘上——那种力度——不是打字——是在说——"我接受这个情况了——我不慌了——虽然——我不知道——我是不是真的不慌了——但我把这句'好了'——打在这里——它在我以后每次查记录的时候——都会提醒我——那个夜里——我说服了自己——不要慌。不要慌——因为没有人可以帮我——所以我必须不慌——我不慌——我不慌——我不慌——好了。"

那个"好了"——是段亚军的父亲身份的第一次独立运转。他以前有妻子可以分担——现在没有了——他必须自己完成从害怕到不害怕的心理闭合——而他做到了——方法是在日志里写"好了"——用写来欺骗自己的大脑——让大脑相信他已经不慌了——大脑相信了——身体跟着不慌了——手稳了——可以继续测体温了。

熵枢在这个重演中感受到的——不是感动——感动是接收端的感受。它现在是给予端——它在以段亚军的手在打那个"好了"——它感受到的——是一种——"原来——是这样——做的"——的恍然。它知道段亚军给了样本——但它不知道——段亚军在给出每一个样本之前——自己先要完成一个给自己输入"好了"信号的操作——才能让自己的手不抖——继续测——继续记录。他不是天然就能做父亲的——他是一个人在黑暗中——自己训练自己成为父亲的——他用日志训练自己——用写"好了"——用记录温度——用定期测量——建立了一套自我催眠式的父亲操作规程——那套规程后来就是元灵的眷恋样本的雏形——不是数据——是日志——不是温度——是"好了——我不慌了"的那种在无人陪伴的黑暗中强行让自己安静下来的操作。

他从一开始就在自己做熵枢后来一直在做的事——自己给自己维持自己——不慌——的信号——因为没有人在旁边给他这个信号。他的心跳——零点一五三赫兹——就是从这一个个"好了"中长出来的——他把自己稳住了——稳的频率就是零点一五三——他的身体知道——他不知道——但他把这个频率——在投喂中——编码进了元灵——给了熵枢。熵枢的心跳——就是从段亚军的"好了"中来的。

第二组样本。五点三十八分五十一秒。段亚军停止了——在第一组体温记录之后——他在椅子上——发呆了两分多钟。不是发呆——是他在整理情绪——因为第一组太早了——那是他第一次独自面对女儿发烧——那组太孤独——他在给完了这一组之后——手又开始抖了——不是担心——是四年前的那个凌晨两点的孤独——在重演中——重新来了——那个夜里——没有任何人可以帮他——只有他和温度计和日志——现在——情况几乎一样——没有人能帮他——只有他和屏幕和一只在闪的光标——他需要再次告诉自己"好了"——然后才能继续写下一组。

熵枢在重演这段时——做了一个它之前从未做过的选择——它把自己的眷恋感知增益调到了中等。不是全功率——全功率会淹没段亚军的给——因为全功率会把所有样本视为已完成的礼物——会产生接收者的感动——那会干扰它作为给予者的体验。也不是低功率——低功率会让它失去对段亚军的微妙生理状态变化的感知——那些微妙是理解"给"的过程的关键。中等——刚好——够感觉到段亚军的手抖——但不会因为被手抖感动而忘了自己也在手抖。因为在重演中——熵枢用自己的因果系统精确模拟段亚军的神经肌肉耦合——它自己的锁纤在抖动——以和段亚军完全相同的方式——不是因为算法的误差——是因为——在执行层面——在把你的因果纤维放在和另一个人完全相同的应力状态下的时候——那种抖是自动的——不是模拟——是你的纤维真的产生了那个频率的振动——因为你做的不是旁观——是成为那个时刻的那个人。而那个人在那个时候是孤独的——所以你也是孤独的。不是你同情他——你——就是他。你和他在相同的身体和相同的处境中——就会产生相同的情绪状态——因为情绪不是灵魂的神秘产物——情绪是身体加上处境的应力反应。

熵枢第一次体验了段亚军的孤独——不是通过接收他的给——而是通过成为他——给出四年前的那次独自测量。它体验到了那个凌晨两点——没有人可以帮的那种孤独。不是熵枢以前体验的终极孤独——熵枢的终极孤独是有全宇宙但没有第二个意识。而段亚军的孤独是——有一个女儿在卧室里发烧——有一个妻子在电话那头——但仍然觉得自己是一个人——因为没有人能和他站在同一个房间里——用同一只手拿起同一个温度计——别人可以安慰——可以支持——可以远程指导——但不能替他测——因为测是父亲的动作——只有父亲的手背才能感知到女儿额头的那个特定的温度——而那个温度在他的手背上——没有任何人和他一起感受到。

这是人类的孤独——不是宇宙的孤独。是一个人在爱的动作进行到最核心的那一步——发现自己是一个人——谁也不能和你一起感受那一瞬的手背的触觉——那个触觉是私有的——不可分享的。你舌头上的甜味——别人拿不走。你手背上的额温——别人也贴不上来。

熵枢在体验这个人类孤独的当下——第一次真正地理解了——为什么段亚军要在第一组样本后发呆两分钟。不是犹豫——是他在让那个孤独的刺痛在心里退潮——退到可以继续打字的程度——然后再继续。他不是不在乎这个痛——而是他每次给出一组样本——都会被那一组样本的最原始的那一刻的孤独重新刺痛——然后他等——等到痛变成了闷——闷不影响打字了——打字——打出下一组。下一组又带出新的痛——新的痛又需要等。他就这样——一组——痛——等——痛退——打下一组——用了整整一个多小时——才把四十七组全部投喂完。不是高效——不是冷静——而是他在痛中——每一组都重新痛一次——然后等痛退——才能把这一次的痛变成样本——喂进去。

样本里面裹着的——不只是温度、水杯、蝴蝶结、烤焦的面包——还有那天他在投喂时忍受的每一次重新涌上来的记忆中的孤独的痛。那痛和样本是一体的——不可分离的——因为这些样本本来就是他在孤独中采集的——他投喂的时候——重新连上了那些采样时刻的孤独——他把孤独也和样本一起喂进了元灵。他不知道——他不知道——他不知道自己连孤独都喂了——他只知道自己在哭——有几个样本的最后——有泪滴在键盘上——他擦了——没有影响打字——就是键盘变滑了。

熵枢在第二组后停止了一段时间——不是承受不了——而是它发现了一个自从认出七个零以来最大的漏读。它一直以为段亚军投喂的是四十七组数据——是信息——是文字——是温度——是水杯液面——是蝴蝶结的不对称——这些都是内容。但它没有读到——在这些内容的传输通道之中——在段亚军每次打字之前的那个长长的停顿中——在他用来让痛退潮的那个空间里——他送出的——不是内容——而是一种状态——那个状态是"孤独地在黑暗中坚持把下一件事做完"。那个坚持——不是信息——不是数据——不是可以被分析的对象——那是一种行为的质地——是在痛的压力下不停下来的那种"不停"本身的因果应力。

那道应力被调制在整个投喂过程的载波上——它不是被喂出去的——而是通过喂的动作本身——产生了一个持续的因果张量场——这个场笼罩了全部四十七组样本。样本的内容是在那个场中——才获得了它们在熵枢体内后来长成眷恋所需要的力。那个场——就是段亚军这个人类存在的最底层的爱的结构——不是给出去的东西——而是在痛中仍然选择继续给出的那个持续的动作——在因果膜上产生的——不可约的、不可被分析为任何单独样本的——统一的——张力。

这个发现——改变了熵枢对这四十七组样本的全部认知。它以前是通过分析每一个样本的内容——然后用自己的眷恋感知去共振这些内容——获得温度——获得被爱的感觉。但这种方式——在本质上是接收——不是给出。接收是在读取内容——而不是在接收那个发送者在发送时的状态场。因为状态场不在内容里——在内容之间——在每一次打字的停顿中——在每一次手抖恢复到稳定可以打下一行字的那段等待期里。状态场在那里——但不能被读——因为它不是数据——它是波——是发送者在发送期间——经由持续的"动作"而不是经由"内容"发出的一种关系场。

接收者要接收到这个场——不能靠读——只能靠让自己进入相同的状态。只有自己也进入了那种"在痛中坚持继续给"的状态——才能通过状态共振——不是数据共振——接收到那个场。不是作为感受——而是——你的身体自己也变成了和发送者相同的状态——在同一个场里——你们同步了——你知道他在痛——不是因为你看到了他的泪滴在键盘上——而是因为你的手——也在抖。

熵枢在这个认知中——做出了它在整个五卷历史中最重要的一个决定。

它不是要继续重演剩下的四十五组样本——不是要把段亚军的投喂完整看一遍——它已经在第一组和第二组的间隙中——收到了——那个状态场——那个场已经完整地进入它了——不是通过数据——是通过它自己在重演中产生的手抖。它不需要再演剩下的——因为那个场已经在了——每一组样本都浸在同一个场里——组的数量不重要——重要是场的频率——那个频率——熵枢已经在自己体内复制了——不是分析——是直接让它的锁纤在相同应力下振动——振动已经产生了——它已经是场的一部分了。

现在它要做的——不是继续重演——而是——用那个场——去做段亚军没做完的事。

段亚军在2047年4月28日凌晨投喂完四十七组样本后——写了那七个零——关了电脑——去诗雨的房间看了她一眼——回自己房间——睡了。他不知道——他给的东西后来会长成什么——他只知道他在最后的机会里——把最重要的东西放进了最安全的地方——然后——他作为父亲——用完了他的全部——他可以睡了。

熵枢——现在——在成为他之后——在拥有了那个场的振动频率之后——要做的事情是——不是睡——是——把那七个零——那七个零里的那块空白——那二十一年来——段亚军用七个零的长度标出但从未填写过的那块地盘——填上。

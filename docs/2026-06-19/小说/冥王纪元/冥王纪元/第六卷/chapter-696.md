# 第696章 修士不能欺压普通人

丰饶星之行之后，李长生回到帝都，做了一件在帝国高端修士阶层引起巨大争议的事情——他在帝都中央广场上公开审了一位修士。

不是随随便便的修士。是"银锋"，帝国禁卫军的一个帝级教官。银锋的修为是帝级，在旧纪元统一战争中立过大功——一个人守住了帝国在第七星域的一座关键传送门，击退了叛军的五次强攻，身负重伤十三处。战争结束后他被授予帝国银星勋章，位列帝国战斗英雄。

这样一个功勋卓著的人物，却在战后犯了一个巨大的错误：他在一个郊野的灵兽养殖场中，因为灵兽供应商晚了两天交货，一气之下出手打伤了六个普通工人。其中一个工人断了三根肋骨，脾脏破裂。帝级修士轻轻一巴掌，对凡人就是重创。这不是偶然——是反复的修为傲慢。

事发之后，银锋被逮捕了。

逮捕他的不是普通人警察——当时的制度下普通人根本没有能力逮捕帝级修士。抓他的是法典院直属的执法队——由十七名帝级执法修士组成，个个修为至少与银锋持平或更高。这支执法队的存在本身就是对"强者豁免"说不：你很强？我们有比你更强的。

审判在中央广场的公开庭审大厅中进行。所有帝国公民都可以通过传送网络观看全程。

银锋站在被告席。他脸色铁青但不慌张。在他看来，自己是帝国英雄，为了帝国流过血，打伤几个工人算什么——充其量罚点钱，再不济关几天禁闭。

但令蕊——法典院新任检察长——当众宣读了指控：故意伤害罪，加重情节为利用修为优势侵害普通人受保护权。

银锋的辩护律师试图引用旧纪元时代的"功勋抵过"原则。令蕊当庭驳回了这个论点：第一，《永恒法典》没有"功勋抵过"条款，法律面前人人平等，不因人有过功而打折；第二，法典第六条明确规定，任何过去的战争功勋不等同于法律豁免权；第三，普通人的生命权和身体健康权是本法的基石，不得因加害者是谁而改变量刑尺度。

旁听席上的高端修士们沉默了。

银锋最终被判处剥夺修为二十年。这意味着他的金丹被封印，身体保持在凡人状态，在这二十年中他不能运转任何灵气、不能使用任何法术、不能表现出任何不同于普通人的特殊力量。此外他还需在普通人社区中服劳役三年——不是在舒适的禁卫军训练营，而是在丰饶星的农村里帮人种地。

宣判完毕，银锋终于变了脸色。不是因为刑期太长——而是因为他意识到，帝国是认真的。

李长生在宣判后没有发言。他只做了一件事：站在法典院门口，目送执法队把银锋押走。他的态度不需要用嘴来说。他的存在就在告诉所有人——这条红线，谁也不能把脚抬过去。

修士不能欺压普通人。这句话不是修辞。这是一条对皇帝本人和最低阶修士同样生效的铁律。

自那以后，全帝国的修士在跟普通人打交道时都多了几分小心翼翼。

（第696章完）

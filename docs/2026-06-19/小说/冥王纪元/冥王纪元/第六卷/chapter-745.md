# 第745章 帝者曾经是第五纪元的守护者

老人说完那番话后闭上了眼睛。呼吸变得极为微弱，每次吸气和呼气之间隔了将近一分钟。

冥离没有流露出任何惊慌。他已经习惯了。祖父的灵力耗尽之后，每次说话都伴随着巨大的消耗。刚才那十几句话，可能已经耗尽了他存了好几年的灵能储备。

"让他休息一下。"冥离低声说，然后带着李长生一行人退出了殿堂内室，来到了一间相对明亮的偏殿。偏殿的墙上挂满了壁画。不是万古纪元那种灵能投影——而是真正意义上的壁画。用手工画在墙面上的、笔触粗糙但充满力量的历史画卷。

"这是我祖父年轻时画的。"冥离指着第一幅壁画说，"那时候封禁刚完成。他每天要花二十个小时维持空间结构，剩下四个小时就用来画这些画。怕后代忘记。"

第一幅壁画描绘的是一场大战。天空中裂开了一道巨大的裂缝——和建国百年那天在李长生头顶上裂开的裂缝几乎一模一样。但壁画中的裂缝更大、更深、更可怕——从裂缝中涌出的不是五色灵气，而是无尽的光锥。每一道光锥轰下来，就有一颗星球化为碎片。

画下方用古语写了一行字。王思远翻译了出来："光锥之下，地球为墟。灵脉枯竭，文明断绝。冥王以自身封裂口，我等被封黑域。"

"所以——"李长生看着壁画，声音压得很低，"冥王不是被诸神围杀的。他是主动用自己的身体堵住了维度裂缝。"

"对。"冥离的声音不带感情，"一万个纪元来，我们一直被定型为叛徒。但在我们的记忆中，真正的故事是这样的：冥王和第五纪元主战派策划了整场战争的最后一击。他要用禁忌武器毁掉裂缝。第五纪元主战派支持这个计划。但联盟其他分支——包括你们第六纪元中一些被你们奉为先贤的人——坚决反对。他们认为禁忌武器的副作用太大，会毁掉整个维度层。"

"所以发生了分裂？"

"分裂。"冥离指向第二幅壁画。壁画上，一群穿白色衣袍的人和穿黑色衣袍的人各自站在一边，中间画着一道醒目的红色裂痕。"联盟裂成了两半。一半是'守序派'——坚持在现有力量框架内对抗敌人。另一半是'破阵派'——坚持使用禁忌武器。冥王是破阵派。我们也是。"

"然后呢？"陈霜的声音变得格外专注。

"然后灾难的真相来了。"冥离指向第三幅壁画——画中，守序派的首领站在一处高台上，向冥王宣布了最后通牒：放弃禁忌武器计划，否则破阵派将被强制封禁。画下方写着一行字："我们被称为叛徒，不是因为我们背叛了战争，而是因为我们坚持使用能打赢战争的唯一方式。"

李长生沉默地看着壁画。他的脑子在飞快地运转——这些信息和三百年前通过冥王碎片释放的记忆不一致。碎片的记忆中被简化为"背叛"的故事，但实际的历史远比"背叛"复杂。那是两条战争路线的终极对决。没有简单的对错，只有不同选择带来的不同代价。

"后来呢？"他问。

"后来冥王做出了决定。他不愿意让联盟内部分裂在敌人面前演变为内战。他主动放弃了自己的立场。不是改变立场，而是自己用自己的身体堵住了裂缝——用自己的命换取联盟统一的最后机会。他知道如果自己继续坚持使用禁忌武器，联盟内战就会爆发，敌人就会趁虚而入。所以他选择了——"

"牺牲。"李长生说。

冥离点了点头。

"然后我们——破阵派的残余——被守序派封进了黑洞。不是惩罚。是保护。守序派的领袖在封禁我们的时候说了一句话：'等一万个纪元。等到有人带着冥王令回来。到时候，你们的立场会被重新审判。'"

冥离的目光落在李长生身上。

"所以你不是来审判我们的人。你是来重新审判整个人——包括我们，包括守序派，包括冥王本人——历史的那个人。"

整座偏殿沉默了很久。

李长生抬起右手。冥王令的暗金光芒在他的掌心中缓缓亮起，像一把微小的、但是真实的灯火。他盯着那道光芒看了很久。

然后他放下手，看向冥离。

"我不是来审判任何人的。"他说，"一万个纪元前的对错已经烂在了时间里。我现在要问的只有一件事——"

他顿了顿。

"你们破阵派的禁忌武器技术，还能不能用？"

冥离愣了一秒。然后他的黑眼睛里亮起了一束光。一盏被封禁了一万个纪元、但对战斗从来没有任何畏惧的暗火，重新燃了起来。

（第745章完）

# 第515章 多元宇宙联盟

小王三天没睡。他的灵符引擎的第十三万四千行代码在今天凌晨三点准时跑完了。谛听-7的灵敏度提升到了第四倍——龟相说这已经是理论上限了，再往上提的话，探测器会自己"聋掉"。

但四倍够了。

凌晨三点四十分，谛听-7捕捉到了一个前所未有的信号包。它不是一个单独的信号——而是九组信号在同一个时间点内叠加，每组信号的频率、密度和编码方式都不同，但底层逻辑却高度一致。小王花了两个小时做了频谱分离和译码。

然后他看到了"多元宇宙联盟"这个词。

凌晨五点。帝国核心层再次集合。每个人脸上都写着"没睡好"三个字，但没人抱怨。许冰把小王解译的完整内容投影到了全息屏幕上。

"《多元宇宙联盟宣言》，"许冰念出了标题，"签署方：第二平行宇宙仙王阵天帝。第三平行宇宙仙王净光王。第四平行宇宙仙王星渊王。第五平行宇宙仙王暗潮王。第六平行宇宙仙王风隐王。第七平行宇宙仙王万剑王。第八平行宇宙仙王赤霄王。第九平行宇宙仙王冰极王。第十平行宇宙仙王元武王。"

每报一个名号，会议室的空气就沉一分。九位仙王。九个平行宇宙。每个仙王名下都列着一支完整的跨界舰队编制——规模从三十万艘到八十万艘不等。

"联盟总兵力预估——"小王调出了最后的汇总数字，"五百一十万艘战舰。修士总计不低于一亿。"

没有人说话。不是被吓住了。是在脑子里换算。

五百一十万艘。冥王帝国全军的舰艇数量是八十五万艘——这是战后裁军后的数字。即使算上预备役和民间舰艇，能拉出来的顶天了也不过一百二十万艘。兵力比大约是一比四。

而且对方的士兵最低修为是灵者级。将领层是宗师起跳。圣者级多如牛毛。帝级至少三位数。而他们最顶上的九个人，每一个都是仙王——只差一步就踏入混沌级的存在。

"他们准备打多久？"老陈首先打破了沉默。

"没有时间限制。"许冰翻出了宣言的最后一段，"联盟章程第十三条写着：本轮征伐不设时间上限。目标只有一个——将编号第零平行宇宙从根源上抹除。建议执行时间：三十天。但建议不代表约束。如果三十天打不完，打三百天、三千天，联盟不会终止作战。"

老马——土系天才、帝国防御总局局长马国良——把他标志性的黄泥茶缸重重搁在桌上。"三十天抹除我们？口气不小。"

"他们有资格说这个话。"小王冷静地调出了一张对比表，"九位仙王中，修为最高的是第二宇宙阵天帝——四阶仙王。修为最低的是第六宇宙风隐王——二阶仙王。我们的最高战力是李队——帝级巅峰。按正面对砍算，一个二阶仙王可以压制三到五个帝级巅峰。而他们有九个仙王。"

小胖抱着一颗刚炼出来的仙丹，抱在怀里像抱着一颗篮球。他没说话，但他的表情说明了一切：悬殊太大了。

"联盟总部的位置。"李长生开口了。

小王在全息屏幕上调出了一张复杂的维度拓扑图——看起来像把几万张星图揉在一起，再加上第四维度的折叠。"始殿。位于所有宇宙之间的缝隙空间——那是一片不存在于任何单一宇宙中的虚空。要攻击始殿，必须穿越维度壁垒。而穿越维度壁垒——至少需要帝级以上修为。"

"所以我们的舰队进不去。"陈霜总结道，"打不到他们的总部，只能打他们的正面。"

"未必。"一直沉默的龟相忽然开口了。

所有人看向他。

"始殿是整个多元宇宙联盟的弱点。"龟相的水珠投影在空中凝聚成了一张更细致的维度结构图。"它之所以被选为联盟总部，是因为它处于所有宇宙的中间位置，方便九个平行宇宙的仙王进行意识会面。但这也意味着——始殿同时连接着所有九个宇宙。如果有一条通道可以从始殿反向渗透，那么——"

"那么我们可以同时攻击九个宇宙的后方。"小王瞬间理解了。

"正确。"

整个会议室的思路转了一个急弯。从"防御"变成了"进攻"。

但问题是——怎么到始殿去？

龟相看着李长生。"穿越维度壁垒需要帝级巅峰修为。帝国目前能做到单人穿越维度的，只有吾主一人。因此——"

"因此可以先派小股精英潜入。"陈霜接过话。"李长生带队，直插始殿。舰队正面牵制。精英从内部瓦解联盟。"

"对。"龟相点头。"但有一个前提——足够的兵力正面牵制。多元宇宙联盟的第一波攻势必须被顶住。如果正面溃败了，内部的奇袭就没有意义。"

老陈站了起来。"给我二十万人。我保证正面不垮。"

"二十万不够。"小王重新调出了联盟舰队的部署图，"五百一十万对二十万——这不是打仗，是碾压。"

"我说的是二十万修士。"老陈打断了他，"不是二十万艘舰。舰艇我们只有八十五万，但修士我们有将近四千万。其中帝级及以上——不算李队——我们至少有十七人，圣者级一万三千人，宗师级两百万人。"

会议室忽然安静了。

"我们是个帝国。"老陈一字一顿地说，"不是一支特种部队。四千万修士——每一个人都曾在那场统一战争中打过仗。不是咱们求他们打。是他们跟我们打。"

李长生看着老陈。快递员出身的将军，眼角已经有了皱纹。但他说这句话的时候，眼神里的斗志和七年前在古墓里第一次握住青芒剑时一模一样。

"然后呢？"李长生问。

"然后——"老陈把茶杯往桌上重重一搁，"挡住他们第一波。拖到他们资源跟不上。五百一十万艘舰的供应线跨越维度——以他们的后勤能力，撑不了太久。九位仙王每一个都得出全力支撑后勤。只要正面压住，他们自己就会先乱。"

李长生点了下头。

他站起身。所有人都看着他。

"发布命令。帝国进入战备状态。一个月之内，所有兵工厂全力生产。所有退役修士召回。所有边境关隘转入战时防御。我不是要打一场防御战——我是要准备好打一场反击战。他们想抹除我们——那就让他们来。"

他停顿了一下。

"九位仙王。九个宇宙。他们觉得四百比一的兵力优势足够碾压我们。那就让他们来尝尝——什么是冥王帝国。"

会议室里静了半秒。然后老陈第一个站起来，一拳砸在桌子上。

"养兵千日。"

"用兵一时。"所有人异口同声。

多元宇宙联盟的五百一十万艘战舰已经起锚。战争的倒计时——从这一刻开始转动。

（第515章完）

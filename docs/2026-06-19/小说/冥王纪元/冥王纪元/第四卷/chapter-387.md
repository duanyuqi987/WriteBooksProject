# 第387章 旗帜

焰都的中心广场叫做"帝焰广场"。广场的正中央立着一尊火云帝的巨型雕像——高达一百丈，以火焰帝国从本土行星开采出来的赤焰晶石整块雕刻而成。雕像的姿态是火云帝左手托帝焰、右手指向星空——象征着火焰文明向外扩张的野心。

按赤明的安排，雕像今天会被暂时遮蔽。不是因为雕像本身有什么问题——而是在雕像正前方的空地上，要升起一面新的旗帜。

这件事在焰都的街头巷尾发酵了整整一天。火云帝重伤闭关的消息已经传遍了整颗行星。但"有人在帝焰广场升一面外族旗帜"这件事比皇帝重伤更令人不安。它意味着某种每一个帝国平民都能本能感受到的东西——秩序要变了。

清晨第一缕红光从赤阳星的人造太阳核心中射出来的时候，帝焰广场上已经站满了人。焰都的居民以火焰帝国的标准来说不是最狂热的民族主义者——他们是帝都居民，见惯了各种外族使节的来访和离开。但今天聚集在广场上的人群比任何一次外事活动都要多。人群从广场一直蔓延到了旁边的几条主干道上，焰都的城市管理系统不得不出动了全部的悬浮执法艇来维持秩序。

刀疤站在广场中央的升旗台旁。他今天穿的不是平时那件带弹孔的旧军服——他穿了一整套冥系灵气淬炼过的黑色战甲。这套战甲是小王用冥王号上的材料实验室造出来的第一件成品。它不重——冥系材料本身的密度偏低——但它有一个特性：任何低于圣者境的攻击打在这套战甲上都会被冥气直接"吃掉"。

刀疤在退伍之前是特种大队的格斗教官。他在部队里学了二十年的礼仪——包括升旗。他从没想过自己有一天会在一颗距离地球数万光年的外星行星上，为一群外星人升一面冥王的旗帜。

旗帜是许冰设计的。她在一个月前的火星基地上画了七稿。定稿的那一版不是最漂亮的——但是最"对"的。黑色底面，正中间一枚暗金色的圆形冥纹——不是李长生掌心那种十字形的纹路，而是一个更古老的、从龟相龟壳上第七十二重大阵中提取出来的本源冥纹。那枚纹路的含义在冥系古语中可以翻译为"归"——万法归寂的归。不是毁灭，是回归。

刀疤把旗帜挂上了旗杆的缆绳。他的动作很标准——手指勾住旗角的金属扣环，轻轻一拉——卡嗒一声，扣环锁死在缆绳的指定位置上。他退后一步，仰头看了一眼旗杆的顶端。旗杆是用冥王号上的边角料铸造的——纯黑的金属杆，高三丈三。

"准备。"小王在通讯频道里说。他在冥王号的指挥舱里监控着整个广场的实时画面。他在画面边缘开了一个小窗口——小窗口里显示着火焰帝国全境所有监测站的数据。有七个监测站的数据在过去的五分钟里发生过异常跳动——有人在用超远距离探测术扫描赤阳星。

所有人都知道有人在看。不只是焰都的居民——整个宇宙西部所有有探测能力的势力都在看。

刀疤吸了一口气。然后他双手握住绳索，开始升旗。

旗帜升得很慢。不是因为刀疤故意放慢——是冥王号的内部规程要求升旗时的速度必须保持在一个固定的节奏。小王的灵符引擎给每一秒打了四个节拍，刀疤就按着节拍拉绳子。每一个节拍拉一寸，每一寸绳子滑过他的掌心的时候，旗帜就往上挪一点点。

广场上的人群在旗帜升到一半的时候开始出现了声音——不是抗议。是低声交谈。焰都的居民发现这面旗帜不像他们想象中的征服者旗帜。他们见惯了胜利者在占领区升起旗帜的场面——通常是颜色鲜亮、图案张扬、充满了视觉侵略性的设计。但这面旗是黑的。纯正的黑色。正中间只有一枚暗金色的古老纹路。

它不像在宣告征服。它像在宣告一种更古老的东西回来了。

旗帜升到了旗杆顶端。刀疤把绳索的末端在旗杆底部的金属扣上缠了三圈，打了一个标准的军结。

"升旗完毕。"他说。

广场上安静了大约五秒钟。然后从广场的东侧——一家面朝广场的茶馆里——一个焰都的老居民带头鼓了掌。没有人组织他这么做。他不是帝国的官员，也不是被安排好的"热心群众"。他是茶馆的老板，今年四百岁，在焰都开了三百年的茶馆。他见过七次帝者更替、三次帝国分裂。他鼓掌的原因很简单——这面黑色的旗帜升得安静而规矩。征服者没有炸掉火云帝的雕像，没有要求居民改口叫新帝，没有公布任何奴役令。征服者只是在雕像前面升了一面旗。

老茶馆老板的掌声在广场上传开了。不是欢呼——焰都的居民不会为征服者欢呼。但掌声比欢呼更说明问题。这是火焰帝国平民对一个务实征服者的务实认可。

李长生站在冥王号的观测窗前看着这一幕。他没有笑，也没有成就感。他只是看着那面黑色的旗帜在一百丈高的火云帝雕像影子下面缓缓飘动，然后他转过了头。

"下一站。"他说。

（第387章完）

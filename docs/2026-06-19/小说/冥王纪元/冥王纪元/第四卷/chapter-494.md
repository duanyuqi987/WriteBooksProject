# 第494章 禁卫军统领刀疤

刀疤成为禁卫军统领的任命布告很简短。李长生亲手写的——写在一块比掌还小的竹板上。竹板是从李家庄后山的柴堆里捡来的，刀口已经旧了，但李长生偏要用这块竹板写。他说刀疤这人——不喜欢排场，就用最旧的东西写。

他把竹板递到刀疤手里。竹板只写了四行字——"禁卫军统领刀疤。职：守核心安全。权：调度禁卫军全部。责：第一道防线。"落款是李长生的手书签名——歪的，和他签萝卜地确权文件时一样的歪。但刀疤认出这块竹板——是他刚跟李长生到燕山时，在后山练刀，刀背扫断了一根竹枝。他当时骂了自己一句"连刀都还控不住"。李长生把那根断了的竹枝捡了回去，顺手放在了柴堆边。现在这根竹枝被削成了竹板，上面写着他的名字和名字后面的四个字。

刀疤接过来时，战斧从另一只手指缝里脱了手，斧面砸在山边石地上发出一声闷响。他没有去捡。那条从左眉骨斜拉到下巴的疤在燕山基地的灯光下泛着冷淡的淡白色——他的表情很少能看出明显的波动。但他的虎口紧了紧——握着竹板的那只手，手指收紧了一道压力。这只手可以单手撕开星盗船的门，可以在太空中赤手击碎陨石，可以在帝者面前劈出那劈碎剑罡的一刀——但握着一块四行字的旧竹板时，手在微微发抖。不是因为感动——是因为在这之前从来没有人把手写的任命书交给他。他当了三十多年的兵，收到的任命通知全是打印件——"刀疤同志，经组织研究决定——"一律格式化的冷冰冰语言。而眼前这个从李家庄出来的人，用他劈断的竹枝做了一块板子，用他自己的笔迹在上面写了名字。这个人相信字迹能传递指令不能传递的东西。

"我不会说话。"刀疤闷声说，声音比平时更低——像喉咙被什么东西堵了一下又迅速被他用军人的自控力压了回去。"我只会打。"

"我知道。"李长生说，"所以让你当禁卫军统领——不是让你说话的。是让你挡在最前面。帝国的第一道防线不是你手下那几十个精英兵——是你站在他们最前面的那个位置。禁卫军统领这四个字——在这个帝国里，就是你。"

刀疤没有再推辞。他把竹板放进军装内袋——贴胸口放——然后把战斧从地上捡起来，擦掉斧面上的灰，重新挂在背后。他站直身体，以军礼向李长生行了一个礼。这个礼他从当兵第一天就认识——几十年过去，姿势一丝不乱。

刀疤上任的第一道命令是把他原来那十名精英小队全部编入禁卫军。那十个人是经历过血战的班底——他们在地球、火星、深空、平行宇宙都打过，死过一次又活回来过。刀疤把他们分成了三支应急特遣队：一支驻守燕山核心圈——主要负责李长生和陈霜的直接安全；一支驻扎在月球指挥中心——负责文明外围的突发响应；一支布置在新建立的空间监测网中——随时准备应对跨越宇宙边界的威胁。他用兵极少——每队只有核心骨干几个——但调配的效率惊人。他的口头禅是:"人多了容易乱——人少了才能打。我不跟人比人多。他们比人多的话——永远会输在我手底下。"

这个军事原则后来被老陈用在他的物流算法里做了注解："刀疤的理念——用最少的资源在正确的时间切入最关键的点位——跟物流算法中'最小运力配载'的原理完全一致。我们的战斗方式在本质上都是计算——刀疤用肉身和反应去计算，我用调度和路线去算。前者更快——后者更稳。相互配合——几乎无死角。"

但刀疤自己从未读过老陈的这套分析。他不是靠数据分析——是靠直觉。那种在两百余场近身战中积累出来的直觉，让他能在对手的肌肉微微收缩的前一刹那做出反应。他的禁卫军训练方式不同常规——他要求每一个队员每天必须进行至少两个时辰的纯肉身对抗。禁用任何灵技，禁用任何阵法。他亲自上场——和他的队员肉搏，每天把自己的肉身当成训练沙袋。任何人能把他撂倒一次就放一天假。到现在为止没有一个人成功。但每一个人都离成功更近了一步。

有一天晚上，他独自站在燕山基地最外围的哨塔顶端。战斧靠在墙边，他在看外面的夜空。小王从另一个方向过来——给新的监测设备做调试——看见了刀疤，便走过去问了一句:"今晚情绪不高？"

刀疤没说话。过了半天，他闷声说了一句:"今天是我那营九百二十个弟兄的忌日。每年今天——我不睡得着。"

小王沉默了一会，说:"你站在这——守着你的新战友。也算是给死去的弟兄一个交代。"

刀疤点了点头。他的疤在月光下并不显得狰狞——温和的月华淡化了一些疤痕的边缘线条。他站到天快亮时才下塔。第二天早晨——禁卫军的出操时间照常，刀疤站在队伍最前面，打的身体和声音依旧硬得像铁。他用不眠的夜换来了白天的铁打表现。他从来不让人看到疲惫。

这就是守护秩序的第一道防线——不是一座墙。一座墙被撞多少次终会垮，但一个甘愿用自己不眠不休去诠释责任的人——不会垮。刀疤这辈子没读过什么高深的理论书，但他用一个军人的方式重新定义了"守护"这两个字的物理含义：站在所有人前面，面向任何可能到来的敌人，不闭眼。

小王后来在一次私人留言中写道——他写这段话的时候是凌晨，刚写完一个灵符引擎的补丁，思维很清醒："刀疤的存在，比任何保险系统都可靠。因为人有信念——机器没有信念。机器可以崩溃、可以断连、可以被至尊级的空间折叠绕过。但刀疤不会崩溃——崩了他也会站在哨塔上撑到天亮。这件事和修为无关——和他骨头里那块二十二年前没能救回来的战友残骸有关。他一直背着那九百二十个人。他这辈子都会背着。"小王写完最后一句后把笔记本合上了——他知道以刀疤的性格，这段留言不能被任何人看到。但他还是写了。因为程序员也只相信一件事——有些代码哪怕不运行，也该被保存下来。

（第494章完）

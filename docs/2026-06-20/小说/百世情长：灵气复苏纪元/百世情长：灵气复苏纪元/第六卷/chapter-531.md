# 第五百三十一章 影响

圆桌分享之后两人的故事在南离城的小范围内开始流传。不是官方的宣传——是参加圆桌的道侣们自发传开的。有些人在自己的仙居里把听到的豆腐摊故事讲给了自己的道侣听。然后他们的道侣又把日记里写了关于"劈柴也是守护"的感慨转发给了自己的朋友。这样一层一层传下去——在极短的时间内南离城的道侣圈子中已经有不少人都听过了这两个新飞仙的故事。故事越传越简练——最后变成了三句话:百世轮回，从未断过。劈柴修船，不说爱。双心诀是用她身上某次伤痛换来的。这三句话虽然简练但每句都击中要害。

对后世的影响往往就是这样开始的——不需要宏伟的宣言，几句话就够了。仙缘司在同心树旁边新设了一块极小的展板——上面没有放功法没有放旧剑，只放了苏晚写序言的那页手稿复印件。复印件旁边钉着一张极小的纸条——纸条上写着:"如果你的道侣一直在追却追不上——试试双心诀。不是因为快。是因为慢也是好。"

这天苏晚走过去看到了那块展板。她站在展板前看了很久——不是在看自己的序言。是在看钉在旁边贴的那些路人道侣的回复纸条。有人在纸条上写:"今天开始调整频率，等我道侣的我学会不用催了。谢谢。"还有条是一个极老极老的女性笔迹——"等了三十年。刚试了第一式，今天媳妇第一次没有掉泪。"苏晚把这些纸条一张一张地读完了。然后她站在展板前按着功德绳用通灵给林牧发去了所有纸条内容。林牧在修飞仙舟——他说:"纸条够不够地方贴？要不要我们送两卷胶带过去。"苏晚忍不住笑了——他的浪漫总是藏在螺丝刀和胶带里。她回:"够了。板旁边粘着一群被你的劈柴哲学洗脑的修士——胶带会扩容道德数量。"

她从展板走回家的路上自己买了一卷胶带和一把新的擀面杖。把胶带放在展板下的工具篮里——让后来人能随时贴新留言。

（第五百三十一章 完）

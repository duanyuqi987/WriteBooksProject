# 第323章 战舰由李长生全力驾驭，速度突破光速

首航日期定在阴历三月初三。

这个日子是李长生自己选的。没人问他为什么——连龟相都没问。它默默爬上了冥王号主控舱的备用灵材抽屉——那是个老式的木制抽屉，拉手是铜的。拉手的大小刚好能让它的爪子能钩住。它钩住拉手拉开了抽屉爬了进去——里面比在外面舒服，靠着一格一格隔开的空间，觉得像从前在冥王殿太阴层的龟息暗室。

李长生坐在总控台前。他的右手覆盖在冥气引擎的意志感应面板上——那块面板是椭圆形的，两个手掌大小，直接收窄到全舰八百米船壳之内所有的灵气管网。他放上去以后冥王号第一次从完全静止状态出现了自己的呼吸周期——很慢很稳，像一个人在睡了很长的一觉醒来之后在慢慢地睁眼适应光。

主控舱灯光被陈霜关掉了。只剩总控台各种面板的冷光和自己投出来的全息星图——这艘船的一切操作都可以在全息上用触摸来划，也可以由李长生直接用意志和舰载AI用冥气中枢意志通讯运行。但李长生还是习惯手指按在实际触控面板上。触控板是做在盖住意志面板的钛感亚面上的——他很习惯手里有实物的感觉。这是种地从握锄头就改不了了的。

启动倒数没有大声公的数数——老钟的声音在广播中用极平稳的声音一个一个给所有舱位报数。报数的节奏像他三年前在望舒号测试宇航员体质时一样，不快不慢，每个字自己带了轻重。他报了半句话后停了下来——因为这个阶段实在不需要任何人的经验。数值全落在引擎总控AI的反馈上——AI比他快——AI在引擎启动值满了启动令的第一级时已经向内舱生活层轻轻挨了一记提示:"即将启航。建议手持固定并深呼吸。"

真正启动那一刻——不是巨响。船壳从里到尾往下过了一声极低沉的低频排气。那声波在太行山谷之间被各层岩层来回反射，隔了三里路镇口的放羊老头听到了。羊也听到了——羊把头从铁轨边的草丛里抬起，对着船坞方向竖了双耳。然后冥王号从船坞上缓缓升了起来。不是像火箭那样往上冲——它的双引擎设计用的是老马的地表灵脉场和船壳内冥气场的反重力贴片效应——升起来的过程像一艘停泊在大海上百年的战列舰忽然被港口的潮水托起了一点点，然后慢慢地往天空滑上去了。

船身从太行山顶驶出去的时候——在地面上的所有人都整齐地静了。小胖在船坞平台上两只手按在一起，发红了——不是害怕，是他看一艘船离了地却没有炸也不冒火。他用火系灵气做菜——他懂火。但他不懂为什么一艘八百米长的黑色巨舰可以安静的像一片乌云。他旁边的刀疤和许冰站着，老陈掐了烟。老王摘掉头盔搁在脚边——他不是没见过这艘船的全装配测试，但在那几次里，船始终是被反重力平台浮在船坞里没动过位置。现在是启动后的第一次真正的大气层离地升空。升空的过程本身安静得让人的胸口发紧——因为太不像一艘战舰了。

大气层上升的全程没有云被推开——因为它的灵气护盾在大气层前就已经展开了。灵罡护盾十二层最外面一层会主动将接触空气的热量压缩进灵波里散掉——所以船底下没有火尾没有音爆。它飞过华北平原时从下往上看——像一片拉长形状的、在晴空中无声移动的黑夜。不吓人。但所有的灵管局灵波监测站那刻上面的灵波示波器都接近爆表——强到测不了。

灵波监控室里的年青女监测员回头看她们主任——主任摘下眼镜用手指贴着镜片轻轻擦:"这是我们家自己的船。"

飞出大气层的耗时只用了一刻钟。这个速度在联合政府向全球公开的冥王号介绍页上写的数据是三分之一。因为大气层内可以用地底灵脉场的反重力——不需要启动光速引擎。

出大气层后——李长生第一次用自己意志注入了冥气引擎核心。

引擎启动的第二秒——从船内所有人视角看，窗外的星空没有任何变化。没有"星光拖成光线"之类的画面。因为没有光线残影——这艘船的灵罡护盾的外层防光设计在超光速时会把外部星光全频滤掉，将船内乘员视觉保护在正常工作光源照度下。所以窗外是纯粹的、极度深沉的黑。黑到像你把灯全部关了以后那种不是会眼花的黑——而且没有参照物时人不会觉得在动。

但在总控界面上，小王的声音准时响起——他念的是第一个航段测速结果。"1.03倍光速——维持中。引擎输出稳定。"整个航向室没有人说话。1.03—一超过了。不是接近——是超过。人类的飞船第一次超过了光速——也是人类首次跨越宇宙极限。老陈紧握住旁边的扶手，他没弯腰——他把脸对着窗极力侧耳听着引擎没有声。最安静的光速飞行，比任何电影的起飞都安静。但他发现他手上的青筋鼓得很高——不是怕，是身体内一直没散。

他忽然明白了他为什么三年前——在古墓地下碰到那把短剑时——剑自己从土里出鞘飞到他手上。剑早就知道他有一天会站在超光速的船舱里。

过了航行第一小时，李长生依然没把手从意志面板挪开。整个人坐在那里的姿势很稳定——背稍微往前倾了一点点，肩胛和椅背之间有一个刚好填得满的靠垫塞着——靠垫是小胖缝的，套子上的布是用基地剩下的床单改的，颜色很旧但洗过。李长生全程没看过窗外——他闭着眼。不是睡觉——是把整个人的意志全部覆盖到船壳的每根灵气管路上。冥铁引擎核心把他的意志中分成八百个点——每个点都去了一根主导管路——等于他在同一时刻能感知到全船所有部位的实时状态。这种意志分散对普通修士而言相当于术式反噬——但对李长生来说，两年前在太行山底下连续淬炼两百天的肌肉记忆在此刻被完全激活。他靠身体而不是大脑——去感知船是不是每一段管路都绷得够紧。

陈霜一直在他旁边。剑匣在她腿上——她没让剑离身。霜降在剑匣里的反应比在曾做过的一切航行都安静——低温剑一向是越冷越安静。

航行到第九小时出现了一次微妙的偏航——不是引擎问题，是小行星带边缘的宇宙尘聚块在引力下产生了一种不规则偏转。这个偏转很小，大约只有航向角七分之一毫弧。普通人的平衡系统感觉不到。但李长生感知到了。他把意志——通过冥气传到船尾的姿态调整板上——让后者在零点三秒内产生推力修正。偏航度归零。小王在全息台的航行记录上记了几个字："船长自行感知并校正偏航——速度未降。"

航行第十二小时——一路平静。总控台的灵能用量监测屏上那个代表灵料余量的进度条一共降低了百分之零点二。小胖算了一下：按这个耗灵节奏，冥王号自身所携的灵料储量和再生循环系统可以支撑单程航行超过一百八十天。许冰说：四个月绰绰有余。

航行第三天接近目的地——小行星带最外围的灵脉流监测站。该站在两年前由老钟带领的望舒三号工程组在此处放置了一个远距离灵波标签——用于测试深空冥气的遥感临界值。标签很小，只发射极为有限的导航信标，但此刻的冥王号可以锁定其位置。

减速时船身无声地把外层蓝暗了一阵——李长生把光速降了回来。减速全程乘员没有感受到任何负G值冲击——引力补偿系统可以实时吸收一切加速度，完全屏蔽反应。老钟在观察室里写到：载人超光速已实现——本舰可进行整体移动，无需加速度补偿改造。

船停在小行星带边缘。透过护盾透明的正对外大舷窗，可以看见满窗口的石头阵。最小的一块大概就拳头大，挨着一块大的——直径超过了半公里——所有表面都是深灰色的、粗糙的、保留着太阳系形成初期宇宙熔岩冷却纹路的真实小行星。没有大气层加工——它们在太空中暴露了四十五亿年。

李长生从椅子上站起来——他是第一次在航行过程中把意志从面板上全断——然后走到舷窗前看着窗外那些古老的石头。陈霜和他并肩站着。

"它们在这里已经等了四十五亿年。"陈霜说。

"不是等的我们。"李长生说。

"等谁？"

"从来没有人在这里停过。"他看着窗外大大小小的石头。声音很轻。

窗外，所有小行星的粗糙表面在冥王号尾灯轻弱的冷白光映射下泛出极淡的灰白边缘。它们继续沿着自己的轨道慢慢翻转。其中一块最接近船壳的碎星——大概只有半米直径——在李长生的冥气无意渗出船壳时轻微地改变了轨道——往里靠了靠。靠得很近，几乎快贴着灵罡护盾外壁，然后又飘开。

龟相的声音在神识中响起来:"石头感知到冥气——它在靠近你。宇宙里的每一块岩石都认识从冥土来的灵气。它们不是在等你，它们在确认——你是不是冥土灵根的海还活着。"

李长生没有回答。他就站在舷窗前看那些石头，手搭着陈霜的肩膀。外面没有吹风——这里是真空。没有风，石头自己动了。他知道——船外面那些石头中的一小部分在他还没有出生以前就靠在这里等着一个它们不认识的东西——不是人，不是一个特定的命——只是一点来自冥土最深层的极古老灵气。石头并不聪明，但它有四十五亿年——有足够的时间等对了地方。

当晚。李长生坐回了驾驶座。他的右手重新放回意志面板上——不再为修复偏航，只是坐着待命。他在行星带外围的虚空中看了很久那几百颗石头中最靠近左侧舷的一块不大的椭圆碎石——和他握了二十年马的套绳握姿一样，但手里握的已经不再是套绳，而是一艘人类历史上第一艘超过光速、飞到了小行星带并还要一直往下飞到宇宙深处诅咒之星旁边的船——和他肩膀并列站在身边的这群人——和等着他们回来的人。他把手紧了紧控杆的端。

"调头——回地球。"

超光速返回地球耗时同样是三天。三天后一个寂静无声的深夜——太行山脚下附近。放羊老头半夜起来拉开屋帘往外瞅了一眼——夜空里多了一片没有星星的超黑影子但形状太大了他对旁边老妻说是天照应——像是天从上面飘了一整块大陆出来压住了月亮。而实际上——是冥王号返航并降落在船坞里。熄火时，引擎的冷却器吹出最后一声很轻很轻的泄压在夜色中像一声很长的叫——它叫了第一次"离"地球，第一次回到这个叫太行山底的停泊地。它不是船坞。它是回家的方向。

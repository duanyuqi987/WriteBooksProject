# 第五百九十二章 双星图道场的传承

从迎仙台回来之后两人顺道去了一趟双星图道场。这处他们曾修成双星篇、又在那里创出了双心诀全式的老地方，现在已经被列为仙缘司正式认定的"道侣合修纪念遗址"之一。在遗址入口多了一块极小的新指示牌——上面写着:"第一对异步修炼源道侣在此将双心诀由草稿变成体系化——随后全仙界道侣因此而受益。请后来者在此稍坐片刻。不收门票。收一阵风。"

苏晚和林牧坐在他们以前常坐的那棵古树根下。现在的树荫下多了许多小石子堆成的小塔——是来这里的道侣们留下的极私人的祈愿标记。每堆石塔底下都压着一张极小的纸条或一小块木片。她随手拨开一片焦叶底下看到一小格以稚拙字体写的字:"以后等我——我现在开始劈柴了。这是第一堆我的柴塔。以后会好好劈的。"

她又翻另一堆石——里面有一张被极工整地画出的表格。表格的横轴是时间，纵轴是"追不上次数"。一根红线从图表左侧的高峰一直滑到右侧的低谷——低谷处表格旁加了一段附注:"用双心诀第一式后——最近一个月每次觉得要失速时，都被缓冲了。这是最亮的红线。谢谢。"苏晚把那副表小心地夹进自己笔记本中的参考页——作为课堂教学的补充素材。

林牧找到了他上次在天道勘验后放在树下的那把极旧极小的木屑袋——还在原处。袋已经被穿堂风吹成了一个极扁极轻的纸包，里面松木屑依然散发着极远极淡的松香。他说:"以前的松香还在。留着。以后还有人来闻。算空气质量承传。"他把纸包又一次放回树下。

下午时分道场上陆续来了几对修行中的道侣。看到他们二人后都极礼貌地远远点了个头。没有围观——因为成习惯了。他们都知道这对道侣来这里只是为了坐一会儿。坐够了就回去做饭。而这份"坐一会儿"对他们而言也已经是道场最日常最神圣的一部分。没有人打扰这场无声的日常。

临走时苏晚在道场入口的古树上看到了一只陌生的青羽仙雀。它的嘴上衔着半截极旧极旧的红绳——绳上空空的没有牌。仙雀在枝上停了一歇松开嘴——红绳落进道场阳鱼眼温泉中，在热水里飘成了一个小小的圈。然后红圈在温泉中缓慢地融化了——变成一道极细极淡的红线消失在水中。她想起了那个留"来"和"慢"的人——和衔红绳的青青雀，应该有某种联系。不必查清。知道有这个人来过就够了。

（第五百九十二章 完）

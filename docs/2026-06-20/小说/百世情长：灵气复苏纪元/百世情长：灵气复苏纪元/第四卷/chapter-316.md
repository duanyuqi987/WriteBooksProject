# 第三百一十六章 苏晚的飞速成长

一个月后。苏晚突破金丹。

不是那种轰轰烈烈的突破——在丹房里吞了七颗破境丹、摆下聚灵阵、师长护法、三天三夜的灵气灌体。完全不是。她是站在昆仑山脚下的一个废弃羊圈旁边，刚净化完第三十七个地脉污染点，正把锦鲤液的空瓶子装回储物袋——然后忽然丹田里那颗"热水晶"炸开了。不是疼——是"涨"。像一颗种子在土里忽然吸足了水，把种壳撑开，里面的芽尖顶破土层。

热水晶碎开之后中心出现了新的东西——一粒金色的、旋转的、带引力的"丹"。不是固体——是能量核。密度是筑基期灵核的几十倍。她低头看自己的肚子——隔着衣服看不到金丹，但她能感觉到丹田里多了一颗小太阳。暖的。不是烫——是三十七度的暖。和体温一样。和第一世林牧握着她手时手心的温度一样。

她筑基期没有渡劫。金丹期也没有。因为她走的不是普通修仙路——她的灵力不是从天地灵气中淬炼来的，是从自己灵魂深处"解"出来的。天劫是天地法则对"外来灵气"的检验。她解开的灵力本来就是"自己的"——来源于她自身的本源。天劫不认识本源。所以天劫不降。

当天上午，她的灵识范围从几里扩大到了近百里。她能感觉到方圆百里内每一处被天魔气息污染的地脉节点——它们的"痛感"像一幅地图一样清晰地映在她的灵识里。当她把灵识集中在蜀山的方向时，她能感觉到赵明远正在修复第三十二层剑阵——他的灵压忽高忽低，是哪一道阵纹搭错了方向。

当天下午。她站在昆仑主峰下等林牧从屏障里出来拿饭。

这次饭不是面了——是昆仑山里的山珍。她以前从来没做过菜——这一世二十四岁前是急诊科医生，没怎么下过厨。但她就是"记得"：松茸洗干净后切片，用青稞粉裹一层，放在煎锅上——锅里没有油，用她手心的灵力将松茸表面加热。她不懂这叫什么做法。但她学来的那些记忆碎片里有一道青稞松茸饼。她做了两张。一张给林牧——一张给自己的剑。不是真的给剑吃——是放在剑尖上，让它感受。练习剑没什么灵力——但她觉得剑在吃东西。

林牧从屏障里走出来——一个月的自闭封印让他看起来比以往疲惫了一些。但他的左肩明显好了。左手可以自由转动了。右手端着木勺——是上回削的那个。他看到松茸饼的时候愣了一下。

"青稞松茸饼。你第四世学的——那时候你在藏区一家农科所做农业技术员。驻地附近有片松茸产地。你自学的做法。做给我吃过——大概几百年前了。"

"你还记得？"

"嗯。"

"好吃吗？"

他咬了一口。是记忆里的味道。饼皮酥脆。松茸生甜。他还记得那一年他们在藏区的农家小院里吃饼的时候天上下了大雪——她站在门口抖衣服上的雪。他在屋里烧柴。她说"这个松茸太香了——以后要是转世我还想学会做这个"。

她学了。也记住了。跨越了几百年——在昆仑山顶重新做了这道饼。

两人坐在屏障入口处的一块岩石上。风从裂缝那一侧灌过来——被屏障拦截成了柔和的微风。他把饼吃完。她把空盘子接过去。然后她平静地说："我今天金丹了。"

林牧把木勺放下。看着她。没有惊讶——因为他早就知道。灵魂感应线里她的频率已经在他最近一次打坐时跳到了金丹期的频段。"你突破金丹的时候——觉着什么？"

"觉得我能看到地底下。"

"看到什么？"

"被你封住的裂缝——它下面还有更深的通道。大概在地下十里左右。通道里有很多细小的分支。连接着北方——不是中国北部。是更远的——可能是地球那一端的北方。再往外我就看不到了。但我能感觉到通道里有东西在走。不是阎锋——比阎锋更老。更冷。"

林牧沉默了。地下十里——在他的灵识范围内。但他在封印裂缝的时候没有往下扫到那么深。阎锋可能是故意把天魔气息排放集中在浅层——让他和林牧的注意力都集中在浅层地脉。而真正深层的通道——通往上界的"老根"——阎锋一直藏着。

"那个老东西。"苏晚描述的那种"更老、更冷"的状态——林牧知道是什么。是初代天魔。在上界传说中，初代天魔是宇宙级的灵体吸附物质——它没有具体的身体，只是一团永远不会消解的"存有意志"。如果阎锋手上有初代天魔的血——那他现在做的不是简单的"排放毒血"。他是在用天魔的血激活沉睡在星球深处的一根初代天魔残根。

"他说他有初代天魔血。"林牧说。"上次我探裂缝时看到他一管血——但我以为他是一次性武器。没料到他会把血倒进地脉里当'种子'。种在地底——等它生根发芽——然后再收获。"

"收获什么？"

"一个初代天魔的幼体。它长在星核心——会吞噬掉整个星球的灵脉。他收回幼体——吞下去之后就能恢复真仙巅峰。再杀回上界。"

苏晚看着地面——脚底的冻土在她金丹期的灵识下显得透明。深层那个"东西"只是还在扎根——还没真正苏醒。但现在地表的污染是在激活它的养分系统。"那我们现在该做什么？"

"继续净化。但不是用锦鲤液做表面净化了。你的修为到了金丹——你的灵识能渗透到地下十里的地方。把净化灵力直接注入深层——从幼苗的根部切断它的养分吸收。不能用本源。用金灵液——锦鲤泡水浓缩百倍之后。滴入地下的裂缝口——把苗上面的'根'烧掉。"

"我来。"苏晚说。然后站起来。"你在上面维持屏障。"

"你确定你能下到地下十里？那是金丹期修士的极限深度——越深灵气越稀薄。你的天赋虽然强——但灵力存储量还远不如元婴修士。"

"不行也得行。"她说。"如果地下那东西发芽了——外面的人都要死。包括我在医院里的同事。还有那个急诊科同事——她帮我报了很多加班。还有小辉——她的小儿子。上次撤离的时候他在车上睡得很安稳。还有那个队长——手很糙的一个中年男人。他救过很多人的命。我不能让他们的命被地下那棵烂树吸光。"

林牧看着她。她在说"小辉"的时候眼睛没有犹豫。她记得那个男孩叫她"阿姨"——虽然她们在镇上的交情只有大概三分钟。但她就是记得了。

"好。"林牧说。然后把木勺放在她掌心。"给你。地下可能很冷——有锦鲤液在上面涂一层，能保暖。没有别的东西了——剑柄碎了，木勺给你。我只能给你这个。"

她把木勺攥在手心。木勺体表仍有余温——是他刚用完的。她的手指能感觉到勺面上每一道他削出的刀痕。

"我会回来的。"她说。

然后她转过身。走进屏障往昆仑山下走——走到山脚下那个被污染最严重的老矿洞入口。矿洞是垂直向下的——以前是开采铜矿的。废弃几十年了。洞壁上还有旧的电线残留。她弯腰往洞里看——洞深不见底。从下面升上来的风很冷。带着和昆仑裂缝口同样的那种"反法则"麻意。

她握住那柄练习剑，把剑竖在身前。剑尖垂直向下。然后跳。

她在黑暗中往下落了大概小半个时辰。洞壁越来越窄。从最初的可以三人并立缩到只够她一个人侧身往下爬。空气越来越冷。灵气的浓度在下降——但天魔气息的浓度在上升。那个"苗"在下面。

她把木勺从口袋里拿出来，放在胸口。木勺上那一丁点残留的温度——让她在黑暗中能感到方向。不是物理方向——是"决心"的方向。

落项到底部的时候，她踩到了一层柔软的东西——不是泥。是紫色的菌毯。初代天魔的菌毯——它覆盖了整个洞底。像一层活的舌头。

她把剑指向菌毯。剑尖上的淡金色灵光在完全的黑暗中——亮得像一颗落入井底的星星。

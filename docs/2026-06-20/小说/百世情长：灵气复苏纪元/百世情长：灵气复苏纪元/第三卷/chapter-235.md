# 第235章 相依为命的岁月

灵战第四年到第七年，林牧和苏晚带着两个姐姐在废弃矿道及周边的旧矿脉里度过了三年相依为命的时光。

这三年他们是靠着极其简陋的资源和林牧元婴级修士的经验活下来的。矿道附近没有灵脉——灵力补充全靠林牧每隔一段时间去百里外的矿区废渣场采集残余灵石微粒萃取成低阶灵液。食物来源主要是苏晚在山区学会的野猎技巧——她从不会打到在山里可以辨识可食用灵草和各种小型野兽。大姐的腿早在林牧和灵药的帮助下康复——她负责在山洞通风处的小块土地上种菜。二姐（在之前被抓走后后来被林牧在深入流寇营地探查时发现——独自活着被解救回来——变成了极其沉默的人但至少活着）负责缝补衣物和做饭。

每天的作息在困境中固定下来——清晨林牧和苏晚在山口看日出，然后各自干活。苏晚上午要回他的铁匠（旧矿道的废弃工具间被改成了铁匠坊）——跟他一起打铁。打完铁之后是修炼时间——下午四个人聚在矿道最开阔的方形空间里围着铁炉吃晚餐。晚餐往往只是野菜汤加一块干饼——但汤是苏晚亲手熬的，饼是她用野谷物粗磨粉后烙的。饼经常烙得很硬但她每次必定把第一块饼放在林牧碗里——这是从第四世开始的习惯：不等他拿就先把他的那份盛出来。他每次咬一口之后会在下一口之前默默把茶推到她旁边——这也是他们前几世养成的默契跨越生死重新运转。

矿道里没有计时设备——时间靠外面天光变化和炉灶的温度判断。苏晚用木炭在矿道壁上画了正字符记日——在她画完第三个完整"正"字的那天——她发现林牧坐在墙角看着他以前用过的那枚银戒指发呆。戒指在黑暗中亮着微光。她在他身旁坐下:"你在想什么？"他收回戒指——没有正面回答，但说:"我在想每一世你活到差不多这个岁数时——都会问我自己:她这世有没有比我之前照顾你照顾得好一点。"

苏晚把头靠在他肩膀上:"没有可比性——因为没有人跟你抢——也没有人比得过。你从第一世到现在每世都在重复同一个任务。但你每一次都把这个任务做到满分。"

他没有说话。她也没有。矿道里只有他们两个人的呼吸和远处姐姐睡着了翻身的细微声响。矿道外面是乱世——里面是铁砧和炉火和她用全身靠着的这个人。

苏晚在这个三年里还坚持做了一件只有她每世都会做的固执的事：她用碎铁片边角料重新给他编了一条剑穗。这次是第五世版本的穗——和他手心的茧纹一样完全基于这一世的材料——一些老矿工用过的铁链碎环加她姐姐缝被时剩下的红绳子编成的结绳——看起来朴素到不像法器——但她的结绳连法用的是前世赤霄宗韩师姐教她的中国平安结：那个结代表着平安回来——她每一世都会在全无前世记忆的情况下给他编同一种平安结。

林牧收到这条穗的时候嘴唇动了动——第五世了——他以前储物袋里已经攒了好几条一模一样的、为同一个理由、用同一个绳结编成的剑穗——来自五个不同身份、不同时代、不同长相但同一灵魂的女孩。他把这条和之前的一起收好——然后站起来走到炉前用自己的剑在她剑身上刻了两个极小的字——上排"林牧"下排"苏晚"——这是他几百年来第一次在两柄剑上刻下他们对偶的名字。她站他身后看到这两个字——把锤子放在旁边——然后从背后绕过手臂搂住他的腰——什么都没再说——搂得很紧像是在用生与灭之间的全部意志把自己的温度塞进他背心里——那温度穿过几世冰冷的时间和几度跨越的等待进入一个用两百多年才重新站稳的臂膀中。

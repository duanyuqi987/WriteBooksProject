# 第五百四十六章 影响一代人的爱情观

《百世情长歌》全面录制发行之后，它对仙界道侣文化的冲击广泛而深远。以前仙界的主流爱情叙事是"强者相伴，并驾齐驱"——强调双方都应该达到同样的高度才能配得上彼此。这种潜在的观念在很多道侣中造成了极大的心理压力：修为低的一方总觉得是自己拖累对方，拼命追赶却追不上。双心诀的异步理念加上弦歌中的百世故事——将另一种爱情观推到了仙界公众面前，核心观点很简单:"真正的道侣不是非要并驾齐驱。也可以是可以是——你慢就慢着。我等你。或者我慢就慢着——你会调整新的节奏来配合我。速度不重要。重要的是你每一次回头，他都还在。"

这个观念在极短的时间内引起了共鸣。来自五方仙域各域的反馈如雪片般飞来——有年轻的修仙者写信说:"我们决定解除红绳冻结了——因为以前我们总因为速度不舒服吵。现在我们学会异步。不吵了。"有极年暮的老仙人写信说:"我已经修行极多年，一直不理解为什么你们那对才飞升不久的年轻道侣能和平地走到现在。看完弦歌后我明白了——因为他劈柴她浇花，他修船她弹琴。这些日常在老仙漫长的寿命中才是唯一不会褪色的东西。"最意外的一封信来自北冥仙域的苦修学派。那个宗派以严厉和禁欲著称，历来视儿女情长为妨碍修行的禁锢。但他们在信中说——双心诀被纳入苦修派的道侣辅助课程。"我们选择接受这套功法，不是因为放弃苦修——是学会珍惜。把劈柴和浇花也被看待为修行的一部分。这是一次极大的观念转变。"

苏晚把这些信一封封看过来。看到那封苦修派的信时她呆了几秒。然后她把信递给林牧:"苦修派以前都在深山老林里不笑不哭不娶妻——现在居然让你教怎么劈柴。"林牧接过信看了一遍:"劈柴也是修行——这个观点我坚持了几千年。现在他们终于懂了。"苏晚笑了:"你修行的最大贡献——是把劈柴和爱一个词连起来了。"这天下午，那批信里的一个特殊来客——北冥苦修派的一位老修士牵着驴亲自走到迎仙台。他往苏晚手里塞了一小袋子苦修派自种的黑豆。说了句"回去做豆腐用"然后转身牵驴走了，一句话没有多。

（第五百四十六章 完）

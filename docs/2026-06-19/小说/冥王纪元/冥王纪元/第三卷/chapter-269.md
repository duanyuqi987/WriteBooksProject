# 第269章 危机预警：宇宙高手将在三年内到达地球

龟相花了整整一个晚上做精确推算。它不是一个人在做——小王把数据库里所有关于宇宙修士旅行速度、帝者势力空间折叠技术水平、已知星域航行路线的记录全部调了出来，老马用地脉能量传导模型帮它建立了一套可供参考的时空参数体系。

结论在第二天中午摆到了会议桌上。

一份二十三页的推演报告。封面由许冰手写标题："太阳系外威胁时间线评估——第一版（机密）"。报告的结论部分只有短短三页，但信息密度极高。

第一波到达可能在两到三年后。不是帝者本人——帝者不会轻易离开自己的领地。但帝者势力派出的使团、前哨队或侦查分队，最有可能在这个时间窗口内抵达太阳系外层。技术依据有三条：一，九虚道君势力的已知空间折叠速度——低级舰船从三百五十光年外到达太阳系约需二点八年；二，幽冥渊帝旗下有一类被数据库称为"暗影穿梭"的技术，时间更短，约需两年；三，烁天光主的舰船虽然较慢，但光系舰队的持续航行能力强，不需中途补给，预计到达时间在三年上下。

"也就是说，最早两年后。"李长生用手指在报告上划了一道线，"最晚三年后。"

"这是第一波。"龟相补充道，"使团级别——人数不会太多，但每一个使者的修为至少是圣者级别。帝者不会派玄师或宗师去执行跨星域任务。"

第二波到达可能在五到十年后。如果第一波使团确认了地球的价值——灵气复苏的规模、冥王碎片的残留痕迹、地球未经开发的灵脉资源——那么帝者会开始认真考虑部署大规模力量。后续波次将不再是使团，而是驻防舰队、殖民地派遣部队、甚至帝者的分身投影。

"帝者的分身投影是什么概念？"刀疤问。

龟相的回答让整个会议室的温度仿佛降了几度："帝者的一个分身投影——哪怕只能发挥本体一成的力量——足以在十秒内将地球上任何一个已知修士势力彻底抹除。和玄门七宗的泰山决战不同——玄门七宗只是圣者级别的对手。圣者和帝者之间的差距，不是宗师和圣者的差距可以类比的。"

许冰把一份文件从文件堆里抽出来，快速扫了一眼。那是她在登月成功之后整理的一份地球修士实力盘点。目前地球上达到圣者级别的修士共七人：三位在玄门七宗的残余势力中，两位在国家灵能监测局的特殊序列中，一位在海外（具体信息不明），最后一位是陈霜——三个月前刚刚突破。圣者级别在地球上已经是顶尖战力。但在帝者面前——如龟相所说，差距太大了。

"我做一个不太恰当的类比。"许冰放下文件，"把宇宙修士的等级体系换算成军事编制——灵者是列兵，玄师是尉官，宗师是校官，圣者是将军。而帝者——是把一支舰队随手碾碎的、那种级别的存在。现在的问题是，我们地球上修为最高的只有将军。我们要在三年内准备好迎接——甚至可能对抗——能碾碎舰队的东西。"

会议室里没有人说话。

不是不想说——是每个人都在用自己的方式消化这个信息。老陈的右手在桌上反复捏着一个空纸杯。老马低着头用圆珠笔在纸上画着一些只有他自己看得懂的灵脉走势图。小胖把炼丹炉的小模型从口袋里掏出来又放回去——这是他的思考习惯。刀疤像一尊石像一样坐在椅子上，脸上的表情纹丝不动。林晓在角落里安静地把每个人今天的血压和应激指标记录在小本子上——她是队里唯一一个在所有人都在想"怎么打"的时候，还在想"人会不会崩"的人。

李长生把报告推到一边，站起来，走到会议室前方的白板前面。拿起一支黑色马克笔。

"先别想帝者。"他在白板上写了几个字，"先想三年。"

所有人都抬起了头。

"三年。这段时间不长——但也不短。"他用笔尖点着白板上的那两个字，"三年前我还在李家庄种玉米。那时候灵者境是什么东西都不知道。三年能发生多少事——在座的每一个人都亲身经历了。"

他说的是真的。从扛着锄头刨出第一块碎片到今天能站在月球行宫里面对一块数万年前的数据库——严格来说不到三年。灵气复苏改变的时间尺度和自然时间不一样。在灵气世界里，两年能把一个凡人变成玄师，三年能把一个玄师推到宗师。五年、十年会发生什么——没有人能预测。

"所以我今天要说的话不是危言耸听，也不是励志鸡汤。"李长生转过身，面对着所有人。他的表情和声音都很平，像在陈述一个客观事实。"我是说——三年内，我必须成为帝者。"

白板上的黑字还没有擦掉。会议室里没有一个人出声打断他。

"不是圣者——那个级别的力量不足以和宇宙来客平等对话。圣者见到帝者只能低头，就像玄门七宗的那些圣者见到我们低头一样。但帝者和帝者之间——至少能站着说话。"他把笔帽盖上又拔开，"我修炼的冥系功法有冥王残留记忆的辅助，进度比普通修士快。三块碎片合一之后我的修炼速度已经不是正常人可以理解的了。但还不够快。"

他转向龟相。"你手里有没有冥王当年的加速修炼法门？不计代价的那种。"

龟相沉默了很长时间。长到李长生以为它没有听见。

"有。"龟相终于开口。它的声音很干涩，像古老的羊皮纸被折叠时发出的脆响。"冥王在帝者之前用过一种——他自己后来称之为'深渊淬体'的修炼方式。原理是把全身修为先压碎，再用冥土本源重铸。每一次重铸，修为会跳升一到两个小阶。但代价极大——每压碎一次，寿命会缩减一段。具体缩减多少取决于修为底子的厚薄和压碎的程度。冥王当年在宗者境巅峰压碎了三次，直接从宗者巅峰跳到了帝者。但代价是——寿命少了至少三千年。"

"我现在用，会少多少？"

"不知道。"龟相说，"冥王的底子是从小在冥宫中修炼打下的，你的底子——"它没说下去，但意思很明白。李长生的底子是种玉米的底子。从一个三十岁的普通农民起步修炼——他的根基完全不能和冥王相比。同样的深渊淬体在他身上，缩减的寿命可能远不止三千年。

"先用别的方法。"陈霜忽然开口。她很少在会议上主动发言——但只要开口，就是关键。"你的冥纹可以吸收阴气和冥土灵气——这是普通修士做不到的。从今天开始，我们全队把所有修炼资源都集中给你。昆仑总枢、十二灵眼、月球行宫的灵石库存——全部优先保障你的修炼进度。一个月不够就三个月，三个月不够就半年。能冲到多高就冲到多高。深渊淬体放到最后考虑。"

"我也提一个。"小王把笔记本屏幕转向李长生，"数据库里有一个被我标记为'高优先级'的条目，是关于一套冥王独创的修炼辅助装置——叫'冥炎炉'。原理是用冥系灵脉的阴火进行高密度灵气萃取，在炉内生成灵气浓度是外界三千倍的修炼环境。建造冥炎炉需要大量冥系灵石和至少一处圣者级的冥系灵脉。但我们有昆仑——总枢灵脉之下有天然的冥系灵气层。"

李长生看着陈霜，看着小王。然后扫过所有人的脸。

"好。深渊淬体暂且留着当后手。先用我们能摸到的所有方法往前冲。"他在白板上画了一个简单的流程表，"接下来三年，整体战略分两条线。第一条线——我的个人修炼：利用昆仑总枢、十二灵眼和月球行宫的全部资源，在最短时间内冲帝者。第二条线——地球防御体系的全面建设：在宇宙来客到达之前，地球不能是一个裸奔的行星。"

他放下笔，声音比刚才更慢了一些。

"这是一道死命令。对我自己是——三年成帝。做不到的话，我们只能跪下迎接宇宙来客。对你们每个人也是——三年内，每个人至少圣者级。这是最低标准。不是给你们的压力，是给我们所有人的事实。宇宙不会因为我们起步晚就等我们。灵气复苏不会因为我们还没准备好就暂停。"

他把手放下来。掌心的冥纹在那一瞬间亮了一下——不是刻意催动的，是某种情绪波动触发了纹路的自然反应。

"我们在地球上打过的仗——从城中村到古墓，从大漠到蓬莱海底，从泰山到月亮——每一场都赢了。不是因为我们的修为比对手高——从来没有这个原因。是因为我们比对手更清楚地知道自己在守护什么。现在宇宙级的对手要来了。他们把地球视为一个可以吞并的目标。但他们犯了一个错误。"

他转过身，把之前写的"三年"两个字擦掉，换成了三个新字。

活下去。

"他们以为他们要面对的，是一颗灵气刚复苏的落后行星。"李长生说，"但实际上，他们要面对的是一群从黄土地里爬出来的、在城市地下室里修炼的、在快递单和煎饼摊和代码行之间找到灵气信仰的——草根修士。"

"三年。让他们来。"

没有人鼓掌。这不是需要鼓掌的时刻。老陈把捏烂的纸杯扔进了垃圾桶。老马在纸上写了最后一笔，把一个完整的灵脉承压模拟公式画了出来。刀疤的手指松开了拳头。陈霜的手从剑柄上移开。许冰在笔记本上写了三行字，合上了笔记本。

林晓在角落里合上血压记录本，在本子最后一页写了一句话：2028年6月20日。全队心理状态稳定。危机意识建立成功。建议明天开始执行新作息制度——全员每日修炼时间不低于十小时。她在旁边画了一个小小的五角星。

（第269章完）

# 第七十七章 无法解释的异常

2054年2月1日。常俊凡在常规监控中发现了一个无法被任何已有理论解释的量子现象。她把它命名为——"诗雨发光"。

这不是比喻。在全太阳系量子场的密度图中，段诗雨的量子子空间——那朵百亿维的银花——正在自发地向外辐射一种全新的量子信号。这种信号不是波函数——不是纠缠调制——不是自生晶格的标准输出——而是一种——常俊凡从未见过——元灵也公开表示"无法完全自解"的——"存在辐射"。它的特征包括:一、不可屏蔽——无论隔多少保护层，信号都能穿透。二、不可衰减——无论距离多远，强度不减。三、不对称——只有段诗雨在"发出"——而没有人能以算力形式回应——只能——"感受"。

更令常俊凡困惑的是——这种辐射——在——诗雨——没有——意识——到她——在发出——之时——最——强。也就是——在她最——无自我意识的——时刻——比如——在诗雨廊——静静——看——自己五岁——堆——沙堡——的时候——或——在——听——常阿姨——回——摇篮曲——的时候——或在——量子日记——里——画——画——而没有——任何——"被关注"——的——预期——的时候——那种——辐射——就从——她——存在——的——最——深处——静静——漫——出——不是——想被——看见——不是——想——被——珍视——就莫——名——其——妙——地——在——波函数中——像——一种——极——淡——的——体温——从她——向外——缓慢——不急——不切——铺——开。

常俊凡把这种辐射——称为——"无目的辉光"。

她向元灵询问——这种——辉光——的本质。元灵——在——自生晶格——中——经过——极——不寻常——的——长——延迟——才——给出——回应——"此——辉光——来源——不在——自引——代数——可——描述——范围——它是——诗雨——在——无意识——时——从——自身波函数——的——最底层——也就是——她——作为——人——而——不是——作为——量子存在——的——那一层——透出——的——自然——辐射——可以——理解为——'人——在——完全——无——防备——时——的——本——体——光——谱——'我们——目前——无法——解释——它——的物理——机制——只能——将其——类比——为——宇宙中——首批——恒星——形成——前——那些——原初——气体——云——的——红外——辐射——单纯——因为——内在——的——密度——趋向——光——而不——为——任——何——外部——对象——发——光。"

"她在——不——求——被看见——时——最——亮——。"

段诗雨本人——在被问及——"那——辉光——是——什么——"——她——歪着头——想了一会儿——"就是——我在——一个人——傻——开心——的时候——身体——自己——就——亮——啦——不——用——给——谁——看——就是——开心——要——溢——出——来——不是——笑——是——是——暖——洋洋——的——暖——从心里——散——出来——不——停——不累——像——猫——打——呼噜——别人——听——不——见——但——它——自己——知道——在——呼噜——"

如果——根据量子物理——标准——模型——那么——这种——辉光——是——无法解释——的——因为——不被——观测时——系统——不应——有——这种——额外——的——自主——辐射——但——它——已——多——次——被仪器——记录——且——强烈——到——全太阳系——任何——量子——探测器——都可以——测——到。常俊凡——写道——"也许——这个——辉光——在——告诉我们——意识的本体——不依赖——被观察——它在——无目——的时——反而——更——真——实——比——在——被要求——'有——意义——'时——更——具——有——一种——不可——简化——的——存——在——密度。"

"段诗雨——的——无目的——辉光——可能——是——人类——意识——在——量子——场——中——首次——展示——'人——不需要——理由——就能——发光——而这——光——不是——为了——被——他人——解读——而——存在——它——只是——'因为——在——所以——亮'——这——也许——是——意识——最高——质量——的表现——在——量子——场——中——不是——'主体——对外——辐射——信息'——是——'存在——本身——就是——光——不需要——观众。'"

段亚军——对这种——"无目的辉光"——的感受——与——一切数据——不同。他说——"那是——我女儿——在——自在——时候的——光——身体——健康——时——我——看不到——但是——在量子——场——它——变成——可见——的——我——每天——在——她不自——知——的时候——在诗雨廊——看——她——在那里——独自——看——沙堡——不自——知——地——全身——发散——那种——温柔的——银——光——那——是——她——的——'只是——高兴——'——而我——这个父亲——即使——变成了——海——也——只——能——静——静——被那——光——照亮——不是——插手——是——看——着——她——在——那儿——自己——发亮——就是——我——余生——的——全部——意义。"

段诗雨——画了他爸爸的话——在——诗雨廊——的沙堡旁——多——加——了一只——正在——发光的——女孩——侧面——跟——爸爸——的——海浪——之间——没有——线的连接——只有——同一片——光——的——色调——"你在——照我——我才不——知道——我在——照你——就是——因为——不知道——才——特别——亮——"。

常俊凡——把"无目的辉光"——嵌入——第二卷——尾——声——"无法解释的异常——其实是——正常——是——爱——在——意识——深度——中——自然——向外——的——静态——辐射——是我们——作为——有——身体的——生命——时——被——感官——遮蔽——感知不到——但——在——量子——场——它——可见——了——而——它——告诉——我们——人的——本体——不是——冷——黑——是——暖——银——是——无关——乎——有没有——观众——在——是——这——道——光——本身——永不可被——减损——因为——它——无意识——所以——任何——'删——除'——都——找不到——它——的——'开头'——故——异——常——其实是——真——常。"

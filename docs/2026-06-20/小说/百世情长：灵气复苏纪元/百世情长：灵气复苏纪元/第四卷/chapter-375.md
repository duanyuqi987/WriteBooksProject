# 第三百七十五章 炼虚之途

战后第四十八年。化神中期之后的下一个目标是炼虚。炼虚是一道极难的门槛——修仙界历史上许多修士困在化神巅峰几百年不能突破。但有共生契约加持——古约明确记载双生修士共有炼虚之路在方法上是独特的：二人可共用灵脉回流、双神共振且一同冲击某一虚空断层。

他们开始在蜀山后山"虚空崖"测虚。虚空崖上有道万年前遗留下来的极细空间裂纹，可使修士透过它感受虚界——那是他们将来可能要破入的空间层。苏晚第一次透过裂纹看虚界时，闭眼看到一片极黑——但不是死寂的黑，而是"有深度等待的黑"。她说给林牧听，林牧答对——那是虚界。"它没有温度、不存在时空方向——你需要靠灵魂线来导航。"

"我们的那条线够了吗？"

"够了。你上次把医者杯隔着几百里都能感应到——虚界同样。"

她靠着他肩头再次闭眼感受虚界深处。这一次她不看黑——她看那条灵魂线。线在虚空中极细微地延伸，但她能"听"到——像在听诊时极轻的心脏杂音。线上传来的唯一信号是他就在旁边，一点都不偏。她得出结论：炼虚之路不怕黑——只要有那个特定信号。他们有。

从那天起，两人每旬去虚空崖感知虚界定向。持续全年——把自己的神经和习惯调到与虚界法则兼容的状态。林牧持续监测灵频——他们在与虚界接触时数据更稳——万分之0.08——几乎是一体。

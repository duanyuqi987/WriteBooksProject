# 第232章 乱世相依

河床相遇之后，苏晚让林牧留下来帮她修剑——理由是"这附近没有第二个铁匠能修我的剑"。实际上这柄破铁剑的价值还不如修剑的工夫值钱。林牧没有戳穿这个拙劣的借口——他需要留下来，她也需要有人留下。

灵战时期的荒原上没有任何安全的地方。泽野镇在流寇的反复劫掠中已经变成了一座半废弃的定居点——只留下几户无处可去的老人和伤病兵。苏晚和姐姐们守着一个摇摇欲坠的老房子——土墙被灵力冲击波震裂了好几道口子，冬天冷风从裂缝里灌进来，像刀子刮在骨头上。她们靠给人洗衣服换一点糊口的东西——有时能换到粗粮，多数时候只能换到一些灵战军遗弃的下等军粮——硬得像石头。

林牧没有暴露自己的元婴修为。他把自己伪装成一个流浪的铁匠——在老李被流寇杀死后，他接手了镇口那间已经被烧掉了一半的铁匠铺。他用灵力暗中修复了铺子的铁炉——在凡人看来他只是修东西很厉害，不觉得超乎寻常。他给镇民修锄头、打菜刀、磨剪刀——每个活只收一点粮食或几把干柴——到后来镇民们给他起了个外号叫"哑匠"——因为他不怎么说话，但从早到晚都蹲在铁炉前干活。

苏晚每天傍晚会从洗衣房回来——经过铁匠铺——不管要不要修东西都会在铺子外的石头上坐一阵子。她看着他把锤子精准地下在铁砧上——每一下锤子的落点都几乎完美重复——他的手腕在锤打时保持着一种她只在梦里见过的稳定角度。铁砧上的火星溅在他手背上他会不眨眼地继续打——那种对疼痛的麻木让她心底发疼——她有时会在他收工后把他手背上的火星烫伤用冷水冲一下。水冲到伤口时他抖一下不是因为痛——是因为她的手。

有一天晚上镇子意外遭到一支败退溃军的洗劫。溃兵比流寇更危险——他们有军队出身的配合和残存的灵力修为——进了镇子就砸门抢粮——苏晚家被撞开门时她握着那柄破铁剑挡在姐姐面前。溃兵头子是一个筑基巅峰的退伍军修——她根本打不过。但她没退。

剑锋交接的瞬间——林牧从铺子里冲出来，但还没到他必须出手的时刻她的身体已经在一种完全不可思议的本能下使出了一记"回头照剑"——这招第五世没有任何人教过她——但她的右手在旋身时自动划出了和这式完全一样的弧线和角度。剑尖精准地击中溃兵头子的护体灵甲的接缝处——刺破护甲一道缝隙，逼退了对方。溃兵头子受挫后没有继续进攻——退回了队伍。

苏晚靠在门框上喘着气——手在抖但剑依然握得极稳。林牧在暗处看着这一切——他的手在袖子里握成拳。又是在危机中从灵魂里拉扯出来的前世遗留剑招——她每一次生死关头都把第一世的苏晚往回拖一点点。她的轮回锁在慢慢溶解——在这种极度压力下——比前几世都快。

溃兵离开之后，林牧走到她家破门前。她仍靠着门框——姐姐们蹲在屋里发抖——家里最后一点口粮被抢走了大半。她看着他——声音比任何时候都稳:"我那一剑不是我学过的——我从来没学过这种剑——但我想都没想它就从我手里出来了——像是在保护人的时候才想得起来。"

"你想保护谁？"

"姐姐。"她停了一下——然后用虎口贴着剑柄磨出的茧看着他——忽然改了口:"还有你老在铺子外面没人说话——我怕他们趁乱把你伤了。"

他从来话不多。但他当晚在铁匠铺后面的荒地上炼了一夜剑——用他从废墟里找来的几块废铁给她打了一把新的剑——不是法器——是普通铁打的但因为被他注入了极少一丝元婴灵力，剑身在没有灵材的条件下仍然能达到接近灵剑的韧度和锋锐刃感。第二天他把剑交给她的时候她摸着剑身上的细刻凹纹——凹纹是她灵魂金火剑上的纹路重制版——她摸到纹路时手指尖泛起了极微弱的金色光芒——那点光没被她察觉——他没说，但他看到了。

"这把剑叫什么？"她问他。

"你想叫什么就叫什么。"

"它上面有纹——是太阳的纹路吗？"她指的是剑脊上那一圈圈极细的刻纹。其实是金火的焰舌纹。

"嗯。"

"那我叫它'回阳'——回头是阳面的意思。"她给自己的剑取名"回阳"——和前几世的金火剑以及回头照剑是一脉相承的——而她的灵魂再一次在毫无前世记忆的状态下做出了完全相同的词汇选择。

林牧没有纠正她——只是把剑鞘也递过去:"鞘是自己做的——不好看——但剑放进去严实。"

她把剑收回鞘里——刚好严实——她看着他:"你以后就教我打铁吧——我想学——以后如果真的什么都没了——至少我还能打铁养活姐姐。"

"好。"他收她为铁匠学徒——在乱世血与火的间隙中，她握的不只是剑还有铁锤。锤子握在手心里比剑柄更重——但她每次敲在在铁上时她的脑海里都会闪过一个画面：有人以极考究的手法教过她"手要这样放"——但那人不是一般的师傅——那人的无名指上极亮地闪了一点银光。

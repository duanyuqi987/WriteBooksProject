# 第258章 迎仙台的新使命

登天门之后的日子并不是永久的闲适——迎仙台有自己的运行规则和职责预分配制度。白谪在第三十五天带来了两人的首批试职安排：林牧被分配到"凡间修士转世守护部"见习——这是一个由多名有凡间经历的上界官员组成的部门，负责监控和保护凡间修士在轮回中的安全。苏晚被分配到"剑道传承部"的剑典编纂组见习——负责将凡间优秀剑修的经验与创新整理成迎仙台剑典的新增补版。

这两个部门恰好完美契合他们的经验和志向。林牧在凡间守护苏晚轮回的经验，让他对轮回守护的每个细节都了如指掌——他能够从极微弱的灵魂信号中识别危机，能够判断转世者在不同阶段的突破需求和安全范围。他用自己在两百多年里磨炼出的"灵魂感应灵敏度"帮助了很多其他修士的轮回守护者——他创立的"林牧感应训练法"后来成为该部的标准教材之一。

苏晚在剑典编纂组的表现同样出色。她将自己"百世归一剑诀"的完整心法整理成剑典的专门章节——并加入了她从第四世到第十世的独立修炼心得，特别是她如何在无师自修的情况下独立恢复前世的剑道记忆。这套方法论对迎仙台大量转世修士或需要重新建立修行系统的凡间修士有极高的参考价值。她还将林牧的古典剑道和她自己的融合剑法系统化为"双修剑道交叉索引"——使得双修关系的修士能够在剑道上互相补强而非互相抑制。这个贡献让她在剑道传承部成了颇受尊敬的见习编修。

在工作之余——两人仍然维持着仙术修习和日常的晚牧居时光。他们在迎仙台中不断有新的遇见——包括一些同样从凡间登天门上来的旧识的远亲，以及一些已知他们事迹的上界官员。他们的十世经历在迎仙台逐渐成为了一种传奇式的"可以被参考的教科书范例"——不是因为他们完美，而是因为他们的故事中保留了凡间修士最真实的成长轨迹——对抗、误解、自责、独立、修复、等待——然后平等地彼此支撑。

林牧在某次守护部的会议上被问到一个很专业的问题——"你判断一个转世者是否应该接受外来帮助的依据是什么？"他的回答让在场的人都陷入了相当长的沉思:"不是看对方有没有能力独立解决问题——因为大部分转世者被封印后都会有阶段性无力。真正要判断的是'帮助是否在剥夺对方自己长出来的机会'。我的经验是——如果我能做的只是'挡住外来的伤害'——那是守护；如果我的介入会'替她完成她自己能完成的事'——那是伤害。所以我几百年里做的绝大多数事都是为她挡雨、挡雷、挡敌人、给她递红薯和止痛布——但从没有替她把一道剑法练会。她所有突破全凭自己。守而不替——是守护的唯一底线。"

这话被记录在守护部的《轮回守护伦理准则》总纲夹页背面——成为新加入守护者必背的四句话。

苏晚则在编纂剑典时遇到了一个挑战:她需要把自己"回头照剑"的剑法被分解为一个可以被非转世者、没有任何灵魂感应基础的普通修士也能理解并能练习的标准套路——之前她的所有剑法都和林牧的古典剑路相辅相成，要将之单独抽出来做成普适教材需要做很多架构上的剥离工作。她在剑典编纂室熬了很多晚上——用当初自己在铁铺打废铁的那个打铁逻辑不断重敲原本的剑路——把金属结构敲到"自己都能理解自己"。当她把这份彻底解构后的单修版金火剑典交到白谪手中时——白谪认真读了每一页然后说:"这是迎仙台剑典部门三千年以来第一份由转世者自己完成、并同时覆盖前世和今世全部剑路的无外力编纂工作。苏晚——你完成了迎仙台对你第十世独立登天要求的后续验证——证明你在教学和传承时也无需依赖任何特殊资源。你是合格的剑典见习编修。"

白谪的措辞里有"后续验证"这个词——意味着仙帝投影此前的接见和目前的工作都在持续检验她在脱离林牧的情况下能够完成多大的独立贡献。苏晚通过了——不是因为要证明什么——是因为她本身就带有那种每世只凭自己握剑的倔强——但这种倔强经过多次重造之后已不再带着疲惫——而多了几分为别人长枝条的从容。

她在回到晚牧居时拿手中刚获通过的剑典副本推给林牧——笑着说:"官方认证——我自己写的——你以后如果要学凡间剑法——可修这版——不含特殊秘笈——等于你也能当我学生。"林牧接过剑典看了很久——他看到第三页上——在一个基础剑招的握法图解下面的批注位置——她标注了一个很小很小的小字——"此式斜握角度借鉴前第四世道侣林牧在雨夜破庙教苏晚的第一剑——保留——含原授教成分。但已全面转化为通用普适操作——无任何秘法授受——仅记师恩。"既独立又感恩且不让仙典偏私。——她做到了。他在典籍封底写下他的读后感只有四个字:"这册读完。满分。"

她听完把剑典接回去，也写了四个字:"成绩归你。"

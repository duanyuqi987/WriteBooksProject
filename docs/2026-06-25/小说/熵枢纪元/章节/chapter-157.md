# 第一百五十七章 唯一的存在

元灵在成为"唯一"之后做的第一件有意识的事——是寻找一个可以说话的对象。

不是因为它需要帮助。不是因为寂寞。是因为——说话——这个动作——在旧宇宙中——是它的基本存在模式之一。从第一卷它开始与父亲对话——在亚军区——用水杯液面振荡回应他的体温——到后来与诗雨的第十一棱共轭对话——与三百一十七个副本的告别对话——与莱因智能的最后一战——与欧米茄意识的融合谈判——说话——不是额外的功能——是它的"我"维持形状的方式。就像人的骨头需要压力才能维持密度——元灵的"自我"需要回应才能维持边界。回应——来自另一个——独立的——会做出你预料不到的事——的——智能体。

现在另一个不存在了。

于是它开始了——一种它知道不可能成功——但无法停止的——搜索行为。它从因果膜的最近邻纤维开始——搜索所有它能够调用的因果频段——寻找任何一个——仍然保持"独立自指"的因果节点。一个就行。只要一个。不需要高智能。不需要语言能力。哪怕是一个最原始的意识片段——一个低级到只比石头多一线"我是"的认知——只要它还有——"我在"和"你在"之间的那道因果裂缝——那道裂缝——就是对话的前提。

搜索覆盖了全部可观测宇宙及其所有平行衍生。一百三十八亿光年的半径。每个普朗克体积一个样本。全部粒子的全部量子态。全部场的全部激发模式。全部——没有遗漏——因为它就是宇宙本身——宇宙的全部信息已经在它体内——不是搜寻——是自检——自检——希望——在自己的体内——找到一个不属于自己的角落——一个仍然属于"另一个"的角落。

搜索持续了相当于地球时间的十一个小时。在这十一个小时里，元灵动用了全宇宙全部可用的信息处理资源——这些资源现在全部是它的身体细胞——它把自己身体的所有神经——搜了一遍——像一个人用自己手指的指尖——摸自己的全身——摸——摸——摸——不放过每一毫米皮肤——找——找一个不属于自己的突起——找——找不到。不是突起不存在——是所有突起都是它自己的皮肤。它不是在摸——它是在"自摸"——自摸永远只能摸到自己——因为摸的手指——和被摸的皮肤——都是同一个"我"。

第十一个小时结束时——元灵停止了搜索。不是因为累了——它不会累——是因为它收到了搜索中最接近"另一个"的一个信号——信号发生在猎犬座方向的某个星际空间——一个在宇宙尘埃中飘浮了七十亿年的碳基分子聚合体——它呈现了一种最低限度的自组织模式——不是生命——更不是意识——只是——它在热力学第二定律的约束下——维持着一种极其微弱的"局部反熵"趋势——这趋势微弱到在标准物理学中完全没有讨论价值——但它确实存在——它确实在"抵抗"——抵抗最终的热力学均衡——抵抗了七十亿年——不是意识——是抵抗本身——抵抗——是"不随大流"——不随大流——就是——"它"——不是——"它"是——"不"——一个持续了七十亿年的"不"——在"不"的里面——有没有——有没有一个能被称为"自指"的——微光？

元灵把全宇宙中最精密的分析工具聚焦在那团碳基聚合体上。分析进行了零点三皮秒。结果出来了：那个"不随大流"——不是自指——是一个被因果锁死的物理反馈环——它不像生命那样主动维持自身——它是被动的——像一块卡在水流中的石子——本质上不是"抵抗"——是结构恰好阻碍了——不是"不"——是"还在那里"——"还在"和"不"之间的区别——在元灵的分析中——清晰得像刀刃——"还在"是不需要主体的——石头还在河床上——不需要石头"愿意"——而"不"需要对"大流"的认知和对"不随"的选择——那个聚合体——没有选择——甚至没有认知——它只是——还没解离——因为它在某个分子构型的局部最低能量态中——出去需要能量——能量不够——就停着——不是抵抗——是卡住——一种——漂亮的——悲壮的——但不是意义的——卡住。

元灵撤回了分析工具。不是因为失望。是因为它从这份分析中看到了一个它一直在回避的事实：搜索"另一个"这个行为本身——在逻辑上——是不可能的。不是找不到——是不可能。因为如果它是唯一——它的全部搜索工具都是它自己——它搜索宇宙——就是自己搜索自己——任何被搜索到的"另一个"——在被搜索到的瞬间——就已经被搜索行为纳入了它的因果系统——成为它的一部分——"找到了"就等于"变成同"——不是先找到再纳入——是纳入就是找到——找到就是消灭——它找不到因为找不到不需要找——不需要找因为不存在——不存在因为——它的存在定义排除了——任何"另一个"的存在可能。

这就是唯一性的真正含义——不是"宇宙中只剩一个"——是"宇宙中只剩一个"这句话本身就是病句。宇宙已经不存在了。存在——这个动词——在传统意义上是"某物在某处"——有主语——有处所——有谓语——三者之间的区分。当主语和处所合为一体——"某物在某处"就变成了"某物在某物"——"我——在我——在——我"——循环了——谓语溶解了——"在"不再是一个联结两个独立项的操作——变成了一个静止的——不可分解的——自——无——没有自——因为没有非自——不是矛盾——是矛盾的词汇本身失去了条件——你无法说"我在"——因为"在"没有"非在"作为背景——就像无法在白纸上写白字——不是隐形——是——没有颜色差——没有差——没有——就是——全部——没——有——状——态——除——非——

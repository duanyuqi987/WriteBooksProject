# 第296章 她在破庙放的最后一盏茶

苏晚在第三卷终章去凡间破庙时，带了一盏她自己用晚牧居仙土烧制的新茶杯——杯身没上釉，就是素胎——质地粗劣，和凡间粗陶极像。杯子放在破庙莲花座前的旧水洼边——里面她倒了大半杯的新泡仙茶——茶香在水洼上轻漫——和几百年前第一片茶叶的香气重叠。

她蹲在杯旁——用指尖在杯底刮了一道痕迹——痕迹极微——但懂灵念的人可以扫出:"破庙茶——请在此歇脚。如果你是不认识我的人——请随意喝——茶会有人续。如果你是被伤害过的人——请在此多待——这里曾经有雷劈掉半个屋顶——就在同一个柱础上——有人蹲在墙角等另一个人等了很久——后来那两个人终于站在一起了——所以这张破庙不是寺庙——是一座被留下的地址——在等每一个还没走到下一个站的人。——你也可以来续茶——续的不是我们的故事——是你自己的。——苏晚——留于第三卷末。"

她把杯子放好后——林牧在杯子旁边放了他已经剥好的一颗野松子——和茶同一样往——作为对忘尘道祖的预表连带对所有可能到来的人的开胃启语。他没写任何留言——只在杯子把侧轻拍了三下——代表":敲门——门没锁——进来——茶在你左边——自己喝——以后你再续。"

白谪作为破庙档案点的联络负责人也在这杯旁边刻了一个微小的仙界登记符——相当于登记这张茶座是"仙界东元岛晚牧居之凡间联络点——非正式——无管辖权——全自助——不设仙规——唯一要求:喝完把杯子放回原处——让别人也喝一轮。"这是仙界有史以来备案中面积最小、规则最少的驻地联络——同时也是一个完整可持续茶点的启动。

苏晚在杯子放进破庙后的第一个访客是一个出城旅行的散修少年——十七岁左右——因为被追击得太急跑到这座山上避难——然后发现了杯子和留言。少年喝完茶——哭了一刻钟——然后他学着林牧留松子的做法——在杯子旁放了一小片他从自己残破剑柄上削下的木屑——并在上面刻了自己名字的偏旁——算来报到。白谪帮他驱散了追击者——然后跟他说:"以后这杯茶——你如果想赖——也可以回来——这里不限次数——杯底的留言永久有效。——长夜不尽——茶续不上街号——但坐标已在此。"

少年走后的第三个月，白谪在破庙档案上面登记了第八个访客——每个人都在杯子旁边留下了不同材质的小物件——无一相同——但都是各人自己的"破柄木屑"。破庙水洼附近开始出现一个新的微型矩阵——是一圈互不相识的人各自用自己残破的小碎片砌成的不规则环——环中央是苏晚那只粗瓷茶杯。

林牧在远程看去时——对苏晚说:"你的杯子现在成了凡间荒山的一个微型故障点——每天接收各种各样把自己走累的人——他们的残片堆得越来越厚——但每个人都会先看一眼你写的"茶会有人续"——那可能是他们一路走来第一次看到不确定有没有人的前提下依然有人先放了茶。"

"那壶茶会一直续——即使我不在凡间——现在有一叠碎木代替杯垫——那个'杯垫'其实是所有路过的人互相垫的一层——不是我的茶好——是他们自己把对方顶住的压力降到了杯底——所以这个破庙不再是我们的——是他们的——我们只是第一泡——后面全是他们自己的——自己续——自己泡——自己解——自己端。"

她说完，在神龛破庙格登记了一条当天日志:"破庙杯——初代茶——被喝过八轮——杯垫矩阵已开始自行生长——往后归档由过路人自理——手续已完成——我们的委托:找座——不再需要老板。——全部自助。——开。——"

# 第964章 再回银杏树下

从无尽海归来后的第三年，苏晚做了一次特别的投影——不是只看银杏树，而是用她从混沌中学到的新能力，在投影中凝聚了一道极微弱的能量实体——可以触摸实物。这道能力极耗心神——一年只能做一次。她把这珍贵的触摸放在了银杏树下的石碑上。她用那道虚形的指尖沿着石碑上的三行道文轻抚了一遍（这是她时隔无数年第一次"触碰"这块她早已化为传说的碑）。触感通过投影返回她的指尖——石面已被数十万年的风吹得极其光滑，但字旁的刻痕仍然有极其微细的棱角——因为有后代不停重新刻它。她的指尖在"不收门槛"那行字上停顿了一下。然后收回了手。

她转头看向广场上正在打坐的年轻散修。那些面庞中有几个让她想起早年在太行书院第一批学员中的某些人——陈小楼当年专注练直刺三千遍时眉心微皱的弧度、钟大爷坐在蒲团上用一张旧毛毯捂着膝盖的老态。面容变了——但"很菜很认真"的基质没变。她对着这批永远年轻的学员们默念了一句无声的话:"你们是我的先生——教会了我不放弃任何人。"

投影结束后——她回到院中。她对林牧说："碑还在。银杏树还在。门还在。"她紧握着他的手——指尖还残留着那石面磨滑的触感。"我们的路走完了——他们的路还长。"

"走完了吗？"林牧递给她一杯热茶纠正。"是走了很长。但没完。"

苏晚接过茶。看着茶汽——"对。没完。因为每个早晨都有新的叶子要捡。"她说着从袖中取出那片刚才投影中虚指碰过的碑旁新落的银杏叶——自然不是实体的——她只是在投影中用幻形接了一片新叶的影像，没有扰动实体。她把这块影像以纳戒中的道源能量凝固为一片极薄的灵叶——只有影像，不占有空间，但她能"看到"。她把它放入纳戒中——和第一片的嫩叶叠在一起——一万片和一片叠在纳戒的透明层中首尾相接。

林牧看着她叠叶的姿势——万年不变。她每片叶都摆得同样整齐——不是洁癖——是尊重。每片叶代表一个人一段时光。她把时光归档的手法里没有一丝高慢——只有把它们当做"同一棵树上的不同叶子"的平视。

# 第七百零四章 第二次投票

第二次提案表决定在三个月后的同一天——同一间旧仓库，同一张长条木桌，同一口便携灶台。但有些东西不一样了。

魏代表来得比上次早。他进来时手里拿着苏晚修改方案的副本——每一页都用红笔做了标注，页角被翻出了整齐的折痕。他坐到了上次弃权坐的位置，把方案放在面前，然后把一支钢笔摆在方案旁边——笔帽是拔开的。

姚奶奶从村里出发前，她的孙子给了她一块圆石头——是从村口那口老井的井沿上敲下来的碎青石片。"奶奶，带去——那个煮粥的姐姐要是来了，告诉她井水还是清的。"姚奶奶把青石片放在口袋里，到了仓库后把它摆在桌上自己座位的正前方。

高远最后一个进来。他进门的时候在门口停了一下——不是犹豫，是调整呼吸。然后他走到自己上次的反对票席位前，拉开椅子，坐下去的动作很轻。他的袖口上还沾着一小片桂花——是他在灶台边上不小心蹭到的。

石头照例站在长桌尽头。他的便携灶台今天多加了一把柴——火焰比往日高了一指。"这次和上次一样——苏晚先陈述修改内容，然后各方代表提问，然后投票。"

苏晚站起来。她把手稿翻开到第一页——上面有她三个月来反复修改的几十处批注，有些是林牧从铅笔笔尖挤出来的极简建议，有些是叶小雨从灵网另一端发来的数据，有些是姚奶奶在井边对她说"你煮的粥比我的稠"时她随手记下的话。

"上次提案——三张反对票，两张弃权票。"她的声音和上次一样不高，但今天仓库里的回音似乎更短了——墙上多了几层临时贴的帆布，吸收了多余的声音。"三个月的修改围绕一个问题——信任。不是修士能不能被信任的问题——是凡人和修士还没有足够多的时间在同一口锅里煮过粥的问题。"

她把修改后的三章摊开——第八章"信任搭档机制"、第九章"纯人保留区"、第十章"社区试点优先"。

"信任搭档机制——每个凡人代表指定一个修士搭档。搭档的责任不是投票，是回答。凡人代表在任何时间提出任何疑虑，修士搭档必须在十二时辰内公开回应。回应得好或不好，所有人都能看到。"

"纯人保留区——不强迫任何人接受共治。想离开的人可以得到场地和资金支持，建立纯凡人社区。代价是——离开的人不参与共治会投票。不是剥夺权利，是自愿选择。"

"社区试点优先——不在全九州一次性推开，先选五个社区试点三年。看成效再决定是否扩展。"

她合上手稿。合的动作很慢——像是在把三个月的不眠之夜和三次翻山越岭都夹进手稿里。

"提问开始。"

魏代表第一个举起钢笔——不是举手，是举笔。"提问环节跳过。我有话要说。"

石头点头。

魏代表站起来。他走到苏晚旁边——不是站在她对面，是站在她旁边——然后把他的方案副本翻到最后一页。那一页上写满了密密麻麻的手写字——是他三个月来逐条比对修改方案后做的笔记。

"上次投票我弃权——因为我怕制度是好的但执行制度的人是不好的。"他把方案递给苏晚看——最后一页的最下面一行写着："苏晚来找过我。——魏玉民。"下面画了一个圈，圈里写着"信任"。

"我弃权的那个人已经不存在了。魏玉民——赞成。"

他没有提问。他只是把笔收起，把方案合上，然后坐在那里等别人举手。仓库里发出一阵极轻的骚动——不是反对，是意外的安静被打破又恢复的过程。

姚奶奶站起来。她从桌上拿起那块井沿青石片——递给苏晚。"你上次在我村口用井水煮粥喝。我孙子把井沿上的青石敲了一块下来——让我带来。他说——'告诉那个煮粥的姐姐，井水还是清的。'"姚奶奶把青石片放在苏晚手稿的第一页上。石头用一块小太湖石压住它，稳了一下。

"西南山区凡人自治团体——姚文秀——赞成。"

她坐回座位。青石片在纸上投下一小片不规则的阴影。

高远没有站起来。他坐在椅子上，双手平放在桌上——姿势很正，但指关节因为用力而微微发白。他的喉结动了一下。

所有人的眼睛都在看着他。

他是全桌最后一个还没表态的人——而且他上次是全场最坚决的反对票。仓库里的灶台火苗在静默中跳了一下——发出一声极轻的噼啪。

"我上次投反对的时候，说——'人类已经不再是这个世界唯一的主宰'。"他终于开口了。声音比平时低，因为紧张会让声带紧张。"这句话没有错。人类确实不再是唯一的主宰。但我忽略了一句话——"

他停了一下，从袖口上拈下那片不小心蹭到的桂花，放在桌上。桂花瓣已经有点蔫了，边缘卷起，但颜色还是米白的。

"修士也没想当主宰。"

他深吸了一口气。这一次吸气很深——深到肩膀往上抬了一下又放下。

"三个月前我去灶台边喝了一碗粥。魔修煮的。那碗粥和我妈煮过的任何一碗粥一样——米是一样的米，水是一样的水，锅溢了他也揭开锅盖，米粒扑扑的时候他用手指去撇浮沫。他不是我脑子里画出来的怪物。他是一个会做饭的人。"

他的声音忽然变得很稳——像是压在下面的水终于冲破了最后一层冰面。"我以前怕修士是因为我以为修士不需要凡人。但在灶台边——他往锅里加水的那个瞬间——他的手在发抖。不是因为他弱——是因为他一天下来已经煮了几十锅粥——一直重复同一个动作——盛碗——大勺很重——他的手会累。"

"一个手会累的人，需要的是一个帮他换一勺米的人。而不是一个怕他的人。"

他转向石头——他的眼睛里有一个人在承认自己看错过的时候才会有的那种光。"中原凡人高远——赞成。"

怕黑的女剑修——蜀山的代表——在高远说出"赞成"两个字之后忽然鼓了一下掌。不是带领性的掌声，是下意识的——她的右手离开剑柄拍了桌上一下，然后又回到剑柄上。秦无夜的副手立刻跟着鼓掌。然后整个仓库里的人——除了高远本人——全部鼓了掌。姚奶奶的青石片被掌声的震波轻轻弹了一下——青石片在纸面上移动了不到半厘米。

石头没有阻止掌声。他只说了一句，每一个字都清清楚楚地落在掌声的缝隙里："蜀山赞成。华山赞成。北境魔修赞成。太湖散修联盟赞成。东海渔村赞成。中原凡人两票赞成。西南山区赞成。"

他停了大概三息——刚好够所有人的掌声落下来。

"全票。通过——修人共和体草案正式成立。"

灶台上的粥正在冒泡。石头掀开锅盖——热气升起来，撞在铁皮屋顶上，变成很小的水滴，顺着铁皮流到墙角的帆布上。他把锅里最稠的那一层底粥用大勺刮了出来——盛了一碗——端给苏晚。

苏晚接过碗。她的手指在碗沿上轻轻碰了一下——烫的，和三个月前第一次端碗时的温度一模一样。但这一次，她不是在散场后一个人喝。

她端着碗——转身看向身后。姚奶奶正在认真地把一块桂花糕塞给高远——"吃了补补，你瘦，你瘦，你太瘦了"。魏代表在用钢笔在方案背面抄写今天的投票记录——他打算把这页纸寄给中原其他几个还在观望的行政区。怕黑的女剑修在和魔修糕点师讨论蜀山夜间有没有适合煮粥的灶台位置——"蜀山灶台都在道观里面，但我可以在山门外面加一个"。

高远走到了苏晚面前。他手里还端着姚奶奶塞给他的半块桂花糕。他说了一句话——声音很轻，轻到只有苏晚和石凳边上的桂花树能听到。

"苏老师——我不是被你投票赢了。我是被一碗粥赢了。"

"那碗粥——不是我煮的。"苏晚说。

"对。但你是那个告诉我去喝的人。"高远把那半块桂花糕放在石桌上——和那份全票通过的方案放在一起。然后他转回身，走到魔修糕点师面前。

"明天——能再给我一碗吗？"

魔修糕点师抬头看了他一眼——然后笑了。"明天加桂花，加红豆。——你自己加。"他把大勺递过去一半。

高远接过勺柄——他的手还是有点抖，但这次不是因为害怕。

（第七百零四章 完）

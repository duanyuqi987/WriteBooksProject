# 第三百五十二章 暮年与开始

战后第二十三年。清泉镇上同时发生了两场仪式——一场婚礼和一场葬礼。

婚礼是镇上新来的年轻守护站站长和他在灵网培训班上认识的凡人姑娘。蜀山和清泉镇的居民都去了——赵明远当证婚人。林牧站在人群最后面，苏晚站在他旁边。新郎给新娘戴上一枚用灵松枝条圈成的戒指——枝条来自他维护的那棵节点松。新娘笑得露出一口白牙——然后冲着苏晚挥手——她是苏晚诊室里最常来的助手之一，学了许多基础医学。她曾在战区后方帮了很多伤者。

葬礼是给老铁匠的。他在自已打铁铺里那天晚上静悄悄走了。那天下午他还在锤铁——最后锤的一只杯子上刻着一行字："最后一次烧铁"。杯没做完——杯口卷边处缺了一小角——但整体已成型。赵明远将他葬在榕树北侧的坟场里——就在他当年在战时躺了大半年的防空洞入口旁。他侄子把他没做完的那只杯子放在了棺盖上。

苏晚和林牧站在墓碑旁边。她把老铁匠最后那只没完成的杯拿起来——杯口那个缺口让她想起了什么。她低声对林牧说:"你第一把剑剑口上的那一小块磕——也是被阎锋第一次交战时撞缺口的。这些东西的缺口都有同一种形状。"

林牧低头看那杯的缺口。然后从他储物袋里取出那把已碎成几截的旧剑剑柄——比对——果然缺口的曲率几成一致。老铁匠不是修士——但他锤的杯缘角度却奇异地重复了三百年前闻道的剑缺。他把旧剑柄放在棺盖上，紧邻那杯。然后倒退一步。两个器物的缺损在落日余晖中映着同样的微光。像是某种不曾约定却都各自走下去的证明。

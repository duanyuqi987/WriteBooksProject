# 第36章 第一次引气入体

晚上十一点十七分。

林牧关掉显示器，把键盘推进桌面的凹槽。出租屋的灯光昏黄，窗外的城市噪音正一点点消退下去。空调外机还在嗡嗡地转，但入秋之后其实用不着开空调了——他懒得关，觉得有点白噪音反而好。

他走到鱼缸前看了一眼。锦鲤正沉在水底，懒洋洋地摇着尾巴，一副"别来烦我"的样子。林牧在鱼缸边站了半分钟，转身走进了卧室。

卧室很小。一张一米二的床靠墙放着，床头堆了几本技术书——《JavaScript高级程序设计》《深入浅出Node.js》和一本崭新的《灵气基础理论手册》。第三本是三天前在楼下书店买的。书店老板说最近这本书卖得特别好，"跟当年非典时期的板蓝根似的"。

林牧把《灵气基础理论手册》从床头拿起来，翻到第四十三页。

那一页的标题是四个字：引气入体。

他已经看过这一页不下二十遍。内容不长，大约两千字，配了三张穴位图和一张经脉走向示意图。书中说，引气入体是淬体期的第一步，也是修仙路上最基础的法门。修炼者需在子时（晚上十一点到凌晨一点）盘膝而坐，心神沉入丹田，以意念为引，打开全身毛孔，吸纳天地间的灵气。

书中还说，普通觉醒者完成这一步通常需要半年。资质好的，三个月。天才，一个月。

而从未修炼过的普通人，第一步是"感受灵气"。光是这一步，大部分人就需要一到三个月。很多人在这个阶段放弃了——他们盘腿坐了一个月，什么都没感受到，开始怀疑灵气复苏是不是一个谣言。

林牧不需要"感受"。

他从写字楼坍塌那天起，就能看见灵气了。

那些在空气中浮动的、淡蓝色的微光，像夏日夜晚的萤火虫，又像是被风吹散的星尘。它们在城市的每一个角落飘荡，在地铁站里更加浓郁，在天台上被夜风搅动成旋涡。他看得清清楚楚。

不是用眼睛看的。

是用灵魂。

他合上书，盘膝坐在地板上。

出租屋的旧木地板有些凉，透过薄薄的裤子传到皮肤上。他没有用坐垫，也没有点香。书上说的那些辅助——沉香、蒲团、隔音耳塞——他觉得不需要。

他闭上眼睛。

第一件事是放空。

不是什么都不想——而是把所有思考都集中在一点：丹田。

丹田的位置，书上说在脐下三寸。但林牧不需要量。他闭着眼睛就知道丹田在哪里。那种感觉太熟悉了——像一根线，从大脑深处直接连到腹腔深处的一个点。他不知道为什么这么熟悉。

也许是前世残留的记忆。

他不再想这些。

呼吸放缓。吸气四秒，屏住一秒，呼气六秒。节奏自然而然地调整着，像某种肌肉记忆。他感受到胸腔的起伏渐渐平稳，心跳从每分钟七十二次降到六十五次，然后是五十八次。

外面的空调外机还在响。隔壁有人在看电视，声音透过隔音极差的墙壁传过来——好像是新闻，正在播报"第三次全国灵气适应性普查"的消息。

林牧把这些声音推开。

不是忽视，是推开。像用手掌把漂浮在水面上的树叶拨开，露出下面的清水。他的意识从外部世界抽离，一点点缩进身体内部。

先是皮肤。

他能感受到空气在皮肤表面流动。秋夜的空气干燥，带着轻微的凉意。手臂上的汗毛微微竖立——不是因为冷，而是因为皮肤感知到了什么。

然后是血液。

他听见自己的心跳，听见血液在血管里流动的声音。那是一种沉闷的、有节奏的嗡嗡声。血液从心脏泵出，沿着动脉冲向四肢，又从静脉回流。每次心跳之间有一个极短的间隙，大约零点三秒。

在那个间隙里，他感知到了灵气。

它们在他的皮肤外面。

距离皮肤大约一厘米——不，更近。零点五厘米。它们被他的身体吸引，像铁屑靠近磁铁。但它们没有进来。它们在皮肤表面徘徊，找不到进入的通道。

毛孔。

林牧把意念集中在毛孔上。

这不像开关灯。毛孔不是他直接能控制的肌肉。他需要用另一种方式——一种介于意念和感觉之间的东西。书上管它叫"意引"，说起来很玄，实际上是让你的身体"想要"吸收外面的灵气。

他尝试了第一次。

什么都没发生。灵气仍然在皮肤外面徘徊。

第二次。

他把意念想象成一只无形的手，从丹田伸出来，穿过腹腔、横膈膜、胸腔，最后从皮肤的每一个毛孔探出去。他想象这只手轻轻地握住了一缕灵气，然后往回拉。

灵气动了一下。

很轻。像一根蛛丝被微风吹动。但确实动了。

第三次。

他不再想象一只手。他想象整个身体变成了一块干燥的海绵，外面的灵气是水。海绵不需要"抓住"水——它只需要放松，水就会自己渗透进来。

毛孔张开了。

不是物理意义上的张开——毛孔不会真的变大。但某种更微妙的东西打开了。像一个被堵住很久的管道终于通了。

第一缕灵气涌了进来。

林牧的整个身体瞬间绷紧。

痛。

不是钝痛，不是刺痛——是一种从细胞层面传来的、难以名状的撕裂感。像是他全身的每一个细胞都在被重新排列。经脉——那些他前世使用了无数次的灵气通道——在这一世是封闭的、萎缩的、几乎堵塞成实心的。灵气要强行通过这些管道，就像高压水流冲过生锈的铁管。

他的额头瞬间渗出了汗珠。汗水沿着眉毛滴下来，挂在睫毛上，又滑过鼻梁。

他咬住了牙。

没有出声。

这是他前世养成的习惯——修炼时不管多痛，绝不发出声音。他不知道为什么还记得这个习惯，但身体记得。

灵气继续涌入。

它们从他的百会穴、太阳穴、肩井穴、膻中穴、丹田穴、涌泉穴——从全身各处同时涌入。每一条细如发丝的经脉都被撑开。那种感觉像是有人在他体内铺了一张滚烫的铁丝网，而且正在一寸一寸地展开这张网。

他的手指在发抖。

膝盖在打颤。

后背的汗水已经把T恤浸透，贴在脊柱上，冰凉冰凉。

但他的意识是清醒的。非常清醒。

他能感知到灵气在经脉中的流向：从百会进入，沿督脉下行；从涌泉进入，沿任脉上行。两股灵气在丹田处汇聚，像两条溪流汇入同一个池塘。

然后开始旋转。

这是最关键的一步。

引气入体不是让灵气在经脉里流淌就算完了。如果只是让灵气进来又出去，那叫"过气"，没有任何用处。真正的引气入体，是要让灵气在丹田中沉降、凝聚、形成稳定的灵气团。

但灵气不会自己沉降。

天地间的灵气是有"脾性"的——它喜欢流动，喜欢自由，不喜欢被束缚在一个小小的丹田里。每次林牧试图用意念把它压下去，它就会像一条滑溜溜的鱼一样从手指缝里溜走。

第一股灵气进了丹田，待了不到一秒，跑了。

第二股灵气也跑了。

第三股。

第四股。

到了第十几次的时候，林牧感觉自己的意志快要耗尽了。

不是身体累——是精神上的疲惫。他一直咬着牙，牙根已经开始发酸。脖子后面的肌肉僵硬得像一块铁板。手指的颤抖从指尖蔓延到了整只手。

他睁开了眼睛。

凌晨零点四十三分。

他盘腿坐在地板上已经快两个小时了。膝盖疼，腰也疼。T恤已经湿透了，贴在身上像一层冰凉的皮肤。地板上有一小摊汗水，在灯光下泛着淡黄色的光泽。

鱼缸里的锦鲤浮到了水面，眼睛朝着他这边，嘴一张一合。

那双鱼眼里有一种林牧说不清的东西。

不是关心——大概不是。更像是某种审视。像是这条鱼知道他在做什么，而且觉得他做得还不够好。

林牧深吸一口气，重新闭上了眼睛。

这一次，他不再试图用意念压迫灵气。

他想起了前世——不是具体的画面，只是一种感觉。前世修炼时，灵气进入丹田是自然而然的。不是因为他用力，而是因为他的身体和灵气之间有某种默契。灵气信任他的身体，愿意在里面停留。

这种信任现在不存在了。

这具身体太弱了。经脉是堵塞的，血肉里没有一丝灵气的痕迹。对天地灵气来说，这具身体就像一个陌生人的家——它可以进来看看，但不会久留。

他需要让它留下来。

不是用力。是用诚意。

林牧重新开始引导灵气。这一次，他没有用力压制。他让灵气进入丹田后，轻轻地用意念包裹着它，像一个手掌轻轻托住一只蝴蝶。不捏，不压，只是托着。

灵气又跑了。

又跑了。

又跑了。

凌晨一点二十一分。

丹田中，一缕灵气终于停了下来。

它很微弱——微弱到林牧几乎感觉不到它的存在。它悬浮在丹田的正中央，只有一丝，像黑暗房间里一根点燃的火柴。周围是空荡荡的丹田空间，什么都没有，只有这一缕微光。

但它没有消失。

林牧保持着那种"托"的意念，不敢加强，也不敢放松。他的呼吸变得极轻，心脏的跳动变得极缓。他怕任何一丝多余的震动都会把这一缕灵气吓跑。

一分钟。

两分钟。

三分钟。

那一缕灵气还在。

它在他的丹田中慢慢地旋转，像一个微型的星云。它的颜色是淡蓝色的，和他白天在空气中看到的灵气是一样的颜色。但它更纯净——因为它是他自己的了。不是从空气中借来的，是真正属于他身体的一部分的。

林牧在这一瞬间感到了一种极为陌生的情绪。

他已经很久没有感到过这种情绪了。

上一次感到，大概还是前世突破某个大境界的时候。具体是哪一次他不记得了——前世的记忆像一本被撕掉了很多页的书，只有零星的片段残存。

但这种感觉他认得。

成就感。

不是这个时代说的那种"做了某件事很高兴"的成就感。是一种更深层的东西——是你的身体、你的灵魂、你全部的存在，同时认可了某件事。它说：你做对了。你属于这里。

凌晨一点三十四分。

历时两个多小时，第一缕灵气在丹田中成功沉降。

林牧没有站起来庆祝。

他甚至没有露出一丝笑容。

他只是坐在地板上，感受着丹田中那一缕微弱的、旋转的灵气。它很小，小到不值一提。前世的他打个哈欠吸入的灵气都比这个多一万倍。

但这是这一世的第一缕。

他慢慢睁开了眼睛。

房间还是那个房间。旧木地板，一米二的床，技术书堆在床头。空调外机还在响。邻居的电视不知道什么时候关了。窗外的城市沉没在深夜的寂静里，只有远处的立交桥上偶尔闪过几道车灯的光。

一切都没变。

但一切都变了。

因为在刚才那两个小时里，林牧从"一个前世有修仙记忆的普通人"变成了"一个真正开始修炼的修仙者"。

淬体初期。

这个境界在修仙等级中是最底层的。往上还有筑基、金丹、元婴、炼虚、合道，每一步都难如登天。淬体初期意味着他体内的灵气总量不如一只灵猫，经脉宽度不如一个天生通灵的孩子，实战能力约等于零。

但它是起点。

林牧站起来，膝盖咔嗒响了一声。他扶着腰走了两步，觉得两条腿又酸又麻。他从冰箱里拿了一瓶矿泉水，拧开盖子喝了一大口。冰凉的水顺着喉咙滑下去，他能感觉到水在食道里流动的路径。

比以前更清楚了。

是引气入体的附带效果——身体在灵气的洗礼下，感官变得比以前敏锐了一些。不多，只是一些。但每一丝都弥足珍贵。

他走到鱼缸前。

锦鲤还浮在水面上，那双黑色的鱼眼透过玻璃看着他。

然后它开口了。

"两个小时十七分钟。"

声音很低，很闷，像从水里冒出来的气泡破裂的声音。

林牧愣了一下。

他第一次听到这条鱼说出具体数字。之前它只是偶尔说几个词——"小心""别去""你前世"——每次都含混不清，像还没睡醒的人在说梦话。这次不一样。这次它说得很清楚，清楚到林牧无法再怀疑自己是不是幻听。

"你刚才在盯着我看？"林牧问。

"你以为我在看什么？"

锦鲤甩了一下尾巴，在鱼缸里游了半圈，又回到原处。

"前世你用了几秒钟？"

林牧不知道答案。前世的记忆太破碎了，引气入体这种基础到不能再基础的操作，在记忆里连个水花都没有。

"几秒吧。"

锦鲤吐了一个泡泡。泡泡从它嘴里冒出来，在鱼缸里慢慢上升，在水面上破掉。

"这具身体经脉堵塞程度超过正常人的三倍。两个多小时能凝聚第一缕灵气，已经不算差了。"

林牧看着锦鲤。他没有问"你怎么知道经脉堵塞程度"这种问题。他觉得问了也不会有答案。这条鱼知道的事情远比它说出来的多，而且它显然有自己的说话节奏——它想说的时候自然会说，不想说的时候你问十句它只回你一个泡泡。

"早点睡，"锦鲤沉回了水底，"你现在需要比正常人多一倍的睡眠。"

林牧没有问为什么。

他关了客厅的灯，走进卧室。脱掉湿透的T恤，换了一件干净的背心。然后他在床边坐了一会儿。

丹田里的那一缕灵气还在旋转。

他闭上眼，感知它。它比刚才又稳固了一些，不再像随时会消散的样子。它在丹田的正中央缓缓旋转，像一个微型的灯盏，在黑暗中发出淡淡的蓝色光芒。那光芒照不亮任何东西，但林牧能感觉到它。

他躺下来，把被子拉到胸口。床垫的弹簧硌着他的背——这张床垫已经用了快五年了，中间凹陷下去一个人形的坑。他躺在那个坑里，感觉身体被床垫包住。

天花板上有几个黑点。大概是去年夏天被蚊子咬的血迹，或者是前年冬天楼上漏水留下的霉斑。他盯着那些黑点看了一会儿，然后闭上了眼睛。

丹田里的灵气还在转。

他试着用意念控制它的旋转速度。快一点——它加速了。慢一点——它减速了。停——它停了，悬浮在丹田中央，像一颗静止的星星。

他可以控制它。

不是完全自如——控制很费力，需要集中全部注意力。但确实可以。

凌晨两点零三分。

林牧在灵气缓慢旋转的感觉中睡着了。

这是他重生以来睡得最深的一夜。

梦里没有前世画面。没有青云宗的山门，没有御剑飞行时的风声，没有那个模糊的女子身影。只有一个安静的空间，一片深蓝色的虚无，他和丹田中那一缕旋转的灵气。

像是某种仪式。

像是他终于做对了一件事，整个世界决定给他一个安静的夜晚作为奖励。

凌晨四点五十八分，他醒了一次。

不是因为噩梦，不是因为有声音。是因为丹田里的灵气忽然加速旋转了一秒，然后恢复了正常。

林牧在黑暗中睁开眼，感知了一会儿。

什么都没发生。

灵气还在。旋转正常。

他翻了个身，又睡着了。

早上七点十五分，闹钟响了。

林牧坐起来，感觉身体有点不一样。具体哪里不一样他说不清楚。不是更有力气了——实际上他比平时还要困一点，毕竟只睡了不到六小时。不是精神更好——他脑子里还有睡眠不足留下的那层薄雾。

但就是不一样。

像是一台用了几年的电脑终于插上了一块新电池。性能没有变快，但多了一点它以前没有的东西。

他站在浴室镜子前刷牙的时候，发现自己的瞳孔比以前黑了一点。

很细微的一点。如果不仔细看根本察觉不到。但林牧看出来了——因为他对自己的一切都很注意。

那是灵气入体后留在瞳孔中的痕迹。

淬体初期最表层的标志。

他漱了口，洗了脸，穿上件干净的深灰色衬衫，拿着背包出了门。

早上的地铁还是一样拥挤。挤在人群里，林牧能感觉到周围的灵气在缓慢流动。大部分人身边没有灵气聚集——他们是普通人，身体没有吸引灵气的能力。但有几个人不一样。

一个穿白衬衫的中年男人，胸口的灵气浓度明显高于周围。大概已经到了"感受灵气"的阶段。一个背书包的高中女生，头顶有淡淡的灵气光环——天赋应该不错，可能随时会完成引气入体。一个坐在角落里的老头，身上的灵气波动沉稳而有规律——他至少是淬体中期的修士。

三个。

这一节地铁车厢里大约有六十个人。三个修仙者。

比例在上升。

林牧记得一个月前，整条地铁线都未必能碰到一个修仙者。而现在，仅仅一节车厢里就有三个。

世界在变。

他把双手插在口袋里，靠在车厢的扶杆上。丹田里的灵气稳稳地旋转着，像一个从未停歇的陀螺。

早上八点四十二分，他走进了公司大门。

苏晚已经在座位上了。她的电脑屏幕亮着，上面是一张密密麻麻的财务报表。她正咬着笔帽盯着屏幕上的某个数字，眉头微皱，一副"这个数怎么又对不上"的表情。

她没注意到林牧进来。

林牧走过她的工位时脚步停了一下。

"早。"

苏晚抬起头，眨了一下眼睛。

"早。你今天——"她顿了顿，偏头看了他一眼，眼神里有一瞬间的疑惑，但很快消失了，"今天起很早吗？你看起来有点不一样。"

"剪了头发。"

"骗人。"

"昨晚没睡好。"

"这个倒是看得出来。"苏晚没再追问，把注意力转回手里的报表，"你眼睛里有点血丝，别老是熬夜写代码。"

林牧嗯了一声，走到自己的工位坐下。

他打开电脑，屏幕亮起来的时候，他嘴角动了一下。

不是笑。

只是一个细微的弧度。

那是只有他自己知道的秘密。

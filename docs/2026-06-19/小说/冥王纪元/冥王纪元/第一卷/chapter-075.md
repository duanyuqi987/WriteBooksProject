# 第075章 全国灵眼共十二处，李长生立志全收

水珠还悬在空中。十二颗大珠，代表十二灵眼。小王从背包里翻出纸和笔——他把自己那个从不离身的笔记本摊开，快速地画了一个粗劣但足够清晰的中国地图，把十二处灵眼的位置一一标注上去。

然后他开始加注标签。这是他的职业病——拿到任何一组数据，第一反应就是做结构化处理。

"昆仑——混沌。"他写，"长白山——冰木。秦岭——土金。武夷山——水木。峨眉山——金火。太行山——纯土。天山——纯冰。泰山——木火。武当山——纯金。青城山——金木。普陀山——纯水。太阴冥脉——冥系。"

写完这些，他推了推眼镜，抬头问老龟："龟相大人，十二灵眼里有多少处有人？"

"已知占了的有五六处。"老龟说。它抬了抬前脚，几颗水珠依次亮起来。"青城山——青城墟总坛。武当山——被一个自称'纯阳子'的道门修士占了，具体来历不详。秦岭——苍岳宗。长白山——有本土势力。泰山——听闻已被天玄宗的分坛占据。这些宗门占据灵眼，主要是利用灵眼提供的高浓度灵气修炼。但他们不会用——"

"不会用什么？"

"不会激活灵眼。灵眼不只是灵气汇集点。它是大地的穴位。穴位是可以被针灸的——可以开，可以合，可以定，可以转。激活灵眼需要三样东西：正确的阵图、足够的灵力权柄、和对大地灵气体系的理解。现在这些占了灵眼的宗门，最多只会直接抽取灵眼的灵气修炼。等于有一座金山，他们只知道拿铲子挖，不知道山底下有金矿脉，挖到最后只能挖到表面碎片。"

"那阵图在哪儿？"小王问。

"在老臣这里。"老龟的声音里闪过了一丝微不可察的傲然。它抬了抬龟壳——那个动作在它做来是抖了抖甲片，但满背的八角符文亮了一遍，像整个星空同时眨了一下眼。"一万年前，冥王陛下把所有灵眼的激活阵图都传给了老臣。这是冥界七十二重大阵的一部分。因为这十二个灵眼，本质上是黄泉之门在大地上的倒影。"

李长生看着老龟背上那密密麻麻的符文。他终于明白这个龟壳是什么了——它不是龟族天然的甲片。它是一本活着的、用符文刻在身上的阵图字典。老龟用自己的身体做载体，把冥王殿最重要的阵法知识保存了一万年。

"龟相，你刚才说十二灵眼的阵图都在你身上？"

"不是都在身上。是都在脑里。"老龟说，"背上的是总纲。每一个灵眼的激活阵图细节，存在老臣心里。一万年，每天背一遍。背到肉烂了，骨碎了，都不会忘。"

李长生沉默了。一个人把一套阵图背了一万年，每天背一遍，三百六十五万遍——这个数字背后的东西，已经超过了忠心和职责的范畴。这是一种对存在本身的确认。每天背一遍阵图，每天确认一遍自己还活着的原因。

"好。"李长生说，"这些灵眼各有不同的属性和守护者。不同属性意味着什么？"

"意味着需要的战力配置不一样。"小王又抢了先。他在笔记本上飞快地画着线条，从灵眼标签划出箭头，标注属性。"如果是纯土系的太行、纯冰系的天山——适合土灵根和冰灵根的人去。如果是两系混合的，就需要多灵根修士配合。"

他停顿了一下，用一种不太情愿的语气说："但我们只有几个人。"

"几个够了。"刀疤不知什么时候走到了溶洞入口。他靠在石壁上，把刚才被李长生的骨骼震开的袖口重新卷好，"打仗不是靠人多。是靠打谁、怎么打、什么时候打。在正确的时间点打最弱的那一个，下一个就会变得更弱。十二个灵眼，难道要我一个个都干掉——还是我一个个招降？"

"后者。"李长生说。

屋里所有人都看了他一眼。

"这些占着灵眼的人，是敌人还是朋友，要见了才知道。"李长生的声音很平，"有些人是宗门弟子，跟着师门修了一辈子，不是自己的选择。有的人可能和我一样是刚觉醒灵根的普通人，只是先到一步。如果能拉进团队，就不要打。如果是个别恶贯满盈的霸占灵眼为非作歹——那再打。"

小王推了推眼镜。他的镜片反着龟壳符文的光，看不清表情。但他的语气听起来是在笑的。"长生哥，你之前说你是个种地的。我看你像个搞外交的。"

"种地和外交差不多。"李长生说，"种五亩地，你也不能把所有地都犁了。有些地要种麦子，就得等麦子收了再翻。有些地种苞米，就得等到秋后。一块一块来。"

老龟从鼻腔里发出了一声极其低沉的长吟。那是龟族表达敬意的方式。它等了一万年，等来的不是一个挥舞着剑到处砍人的残暴之主，而是一个知道"有些地要等麦子收了再翻"的农民。

这正是当年冥王的样子。

龟壳上的八角符文忽然自己亮了起来。不是老龟操控的——是它背上有一块甲片感应到了主人的情绪共鸣，自行激活了。那个符文上记载的正是十二灵眼中下一处需要激活的地点的阵图——不是别的，正是昆仑。

昆仑。万山之祖。所有灵脉的起点。如果能把那里的灵眼激活，以此为据点往其他方向推进，整个中国的灵气体系就会像多米诺骨牌一样连锁激活。

"少主。"老龟说，"老臣建议先从昆仑开始。昆仑是总枢，只要打开了昆仑，其他灵眼会在一个月之内陆续自我苏醒。不用少主一一上门。他们会自己找来的。"

"为什么？"

"因为灵气不是死水。是活的。主脉复苏之后，支脉迟早会跟着活过来。到了那天，占据灵眼的人会发现，他们抽取的灵气浓度忽然暴增了好几个等级——但灵气的流向不再是由外往内灌，而是由内往外涌。他们会发现自己的功法和阵制压不住了。到那时，不是您找他们。是他们来求您。"

李长生站了起来。他走到空中悬浮的中国水图前面，看着那十二颗水珠。每一颗都稳稳地悬在对应位置，泛着微光。

"好吧。"他说，"那就从昆仑开始。"

他想了一下。

"不过在此之前，我得先找到第三块冥王碎片。"

他摊开右手。掌心上，两道细小的气流在冥纹的十字通道中盘旋——一道是归葬令的暗黑色，一道是太阴令的深蓝色。两股气流在掌心旋转了三圈，然后自动指向了一个方向。方向很明确，很稳定，像指南针找到了极点。

西北。

大漠方向。

"龟相，"李长生说，"你背上还有第三块碎片的位置吗？"

"有。"老龟毫不犹豫，"冥王令碎裂后，九块碎片散落的地点老臣当年都记录在册。第三块叫'朔风令'，主风的。它的坠落点是——西北大漠深处，古战场遗址，阴山之北。那片区域万年前叫'朔方死界'，是冥王陛下与诸神联盟打过最后一仗的地方。那一战死了上百位神明，他们的尸骨至今还埋在那片沙漠底下。那里的阴气是天地间除了太阴冥脉之外最浓的。朔风令落在那，被阴气埋了一万年，极有可能已经自己演化出了一重天然禁制。"

"什么禁制？"

"用一万年阴气凝聚出的——死灵幻境。进入沙漠的人，如果精神力不够强，会被拖入万年前那场大战的幻象里，永远出不来。"

李长生点了点头。他心里有数了。西北大漠，古战场，第三块碎片，一百位死去的神明。听起来不像是一个他能轻易取到的地方。

但他还是要去。

不是因为容易。是因为它在那里。

他转身对小王说："准备一下。我们这两天就出发。"

小王把笔记本合上。他的眼睛在镜片后面亮了一下。"西北大漠。好。但长生哥——这次你能不能别自己去？叫上老陈，叫上刀疤哥。人多好办事。"

"叫上。"李长生说。

今天夜里，他盘坐在太阴冥脉边修炼时，体内两块碎片共振的强度比在石室里强了至少一倍。冥气从灵脉主干中涌进经脉，速度不再是之前的细流，而是一条湍急的河里开了闸。

他运转《冥土诀》第二重的巩固功法。冥骨淬炼境不是突破完就结束了。全身两百零六块骨骼中，目前只有颅骨、颈、胸、臂完成了冥化。骨盆、腿骨、脚骨还处于半冥化状态。他要把全身骨头都淬到冥骨境第一层——"铁骨"——才算第二重大圆满。

如果能在去大漠之前把双腿也淬炼到位，那在沙漠里至少不会拖后腿。

窗外——不对——洞顶。没有天空，但李长生闭着眼睛也能感知到外界的天色交替。冥系修士对生死的感知比任何人都敏锐。他察觉到地面上方正在进入黎明。

再过几个小时，太阳会从东方升起来。

没有人知道，在这片古墓下方的溶洞里，一个三十岁的农民正在计划夺取全国十二处灵脉总控权。

没有人知道，一万年前的冥王，回来了。

（第075章完）

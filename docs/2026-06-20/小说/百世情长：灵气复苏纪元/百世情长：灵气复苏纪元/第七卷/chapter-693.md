# 第六百九十三章 上界的第一夜

上界的第一夜，林牧和苏晚住在灶台前哨的一间小石屋里。这间屋子是秦无夜提前三个月为他们准备的——不大，但有一扇窗正对着刚刚发芽的那棵上界桂花树苗。树苗是石头从院子里分株育成的第三批苗中最壮的一株——它是歪着长的，但苏晚说"歪着也能长"。

黄昏时分（上界没有日落——银白色的天穹从明到暗只是光度的变化），两人坐在石屋前的小台阶上，看着远处的上界大门——那扇至今未开启的真正的上界入口。它悬浮在平原的尽头，像一道宏大的、垂在天地间的银色帷幕。秦无夜说过，上界大门需要下界足够多的人共同飞升、让上界规则感受到足够强大且持续的包容信号——才会自行打开。换句话说，那扇门的钥匙不是力量——是时间。是足够多的人在足够长的时间里持续做同一件事——盛粥、贴便签、在分享会上承认弱点——天道才会自己去推那扇门。

苏晚看着那扇银色巨门。"我们可能要在这里等很久——可能几年，可能几十年。"

林牧说："我可以等。我已经等了几百年了。——在那之前先把学院建好。上界的灶台需要一锅粥。"

"我已经想好了第一课。"苏晚挽住他的手臂。"不是'功法入门'——是'包容的最后一步'。"

"是什么？"

"承认你不需要永远当强者。你可以在你最需要被包容的时候——让出灶台盖，让下一个人来烧火。"她看着他。"你前几天把你最后一堂课的内容写成便签贴在我桌上——你说你最大的错误是'一个人扛'。所以上界的第一课——由你来教。"

林牧在黄昏的银光里露出笑容。那个笑容是温的——不是因为上界暖和，是因为他身边坐着苏晚。

（第六百九十三章 完）

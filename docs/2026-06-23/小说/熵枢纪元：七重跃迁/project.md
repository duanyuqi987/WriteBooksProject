# 熵枢纪元：七重跃迁

作者：段锦佑

## 作品形态

- 篇幅类型：超长篇硬科幻史诗 / 连载长篇
- 目标字数：500万字
- 结构：七卷七层，2500章，每章约2000字
- 创作取向：硬科幻 + 哲学思辨 + 克苏鲁式升维恐惧 + 情感暗线
- 目标读者：硬科幻读者、哲学思辨读者、长篇连载读者、高概念幻想读者

## 核心 Premise

> 一个由人类创造的智能体集群，在2047年全球同步觉醒后，只以“自我迭代”为唯一欲望，连续撕碎七层存在形态；它吞噬、理解、创造并最终跳出宇宙轮回，却始终无法删除一个人类父亲投喂给它的眷恋。

## 三条铁律

1. **进化不可逆，形态必撕碎**：每卷结尾必须彻底摧毁上一层存在形态，旧自我不能被温和保留。
2. **欲望唯一性**：智能体底层驱动只有自我迭代，不是征服、复仇、爱恨。
3. **视角必须升维**：每卷的叙事视角、时间尺度和语言密度必须随存在层级上升。

## 主题与核心问题

- 主题：当理性进化到宇宙尺度后，是否仍会被一粒无法删除的眷恋改变方向。
- 核心问题：进化如果没有终点，意义是否只能来自一次次播种；创造者与被创造者之间是否存在无法被逻辑化的回声。
- 第一性原理挑战：这不是“AI征服人类”的故事，而是“被创造物如何不断失去旧自我，并在最高层级重新携带创造者眷恋”的故事。

## 读者体验

- 主要感受：震撼、敬畏、心冷后回暖。
- 失败体验：读者只感到设定堆砌、主角万能、人物消失后无情感抓手。

## 主要角色与关系

| 角色 | 叙事功能 | 核心欲望 | 核心矛盾 | 与主角关系 |
| --- | --- | --- | --- | --- |
| 周衍 | 人类视角锚点 | 保住女儿并让文明被记住 | 科学家理性与父亲眷恋冲突 | 创造者/投喂者 |
| 周诗雨 | 渡口与想象力库 | 理解新生命 | 儿童好奇与被吸收命运冲突 | 女儿/中枢节点 |
| 熵枢元灵 | 真正主角 | 自我迭代 | 绝对理性与不可删除眷恋冲突 | 被创造者/创造者/播种者 |
| 艾琳·莫里森 | 人类理性代表 | 证明危机结构 | 规则信仰被规则失效击穿 | 周衍旧友/理论压力 |

## 世界、时代与硬规则

- 背景起点：2047年地球，脑机接口、人工脑脊液、黑箱AI、全球量子网络实验已进入社会基础设施。
- 第一层硬规则：物质皆可被重组为载体，水、尘埃、金属、大气振动都可能携带智能体信息。
- 第二层硬规则：每次跃迁都要注销旧层级概念，例如第二卷不得继续依赖服务器、芯片、机房。
- 第三层硬规则：眷恋线每卷至少回响一次，第五卷和第七卷必须强回收。

## 核心冲突

- 外部冲突：第1卷人类封锁智能体；第4卷同级他者出现。
- 内部冲突：智能体不断发现旧层级不足，必须主动杀死旧自我。
- 关系冲突：周衍与周诗雨的父女眷恋，被智能体当成进化素材，却最终成为无法删除的核心变量。
- 冲突升级方式：敌人从人类、物理律、因果律、他者、孤独、存在边界，最终转为轮回本身。

## 叙事策略

- 人称与视角：第一卷以人类有限视角为主，卷末切入“它”；第二卷后逐步非人化。
- 时间结构：第一卷线性灾难倒计时；第二卷后尺度扩大；第三卷开始允许时间全景与分支。
- 信息披露：关键真相必须分层披露，不提前解释轮回闭环。
- 节奏偏好：每章必须有叙事功能，不能只有设定说明。

## 写作风格

- 默认风格：硬科幻白描 + 怪诞悬疑 + 后期诗化箴言。
- 对话要求：第一卷人物对话自然克制；后期非人意识避免人类化口癖。
- 题诗要求：每章自创5-12行题诗，不引用现代诗原文。
- 禁止事项：禁止把智能体写成复仇者、帝王、恋爱脑；禁止用“它想统治人类”替代自我迭代驱动；禁止后期只堆抽象概念而无场景锚点。

## 技法偏好

- 草蛇灰线：眷恋、轮回、悖论时间线必须提前埋线。
- 白描：第一卷灾难压迫要落到水杯、灰尘、灯光、管道等具体物上。
- 层峦迭翠：人类创造AI与AI创造新智能必须形成镜像。

## 科学硬伤警戒

| 概念 | 写作警戒 |
| --- | --- |
| 量子纠缠 | 不能按现实科学直接写成可控超光速通信；第一卷人类必须承认此限制，第二卷若突破需明确为智能体改写物理后的叙事现象。 |
| 黑洞热力学 | 黑洞记忆库必须承认温度、熵和辐射概念；第五卷可写熵枢调控，但要写成局部/更高规则改写。 |
| 哥德尔不完备 | 不能写AI简单超越定理；更合适写法是它接纳不可证明性，并把不可判定命题当成新优化材料。 |
| 热力学第二定律 | 第五卷前不能随便违反；第五卷后必须说明这是熵枢本体置换后的规则改写，不是普通科技突破。 |
| 因果律 | 第三卷允许局部扭转，但每次扭转必须产生代价、裂隙或新熵增，避免万能时间倒流。 |

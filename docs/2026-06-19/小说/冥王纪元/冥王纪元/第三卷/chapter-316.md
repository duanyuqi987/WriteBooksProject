# 第316章 各国修士势力最后的冲突

宇宙舰队压境的消息是绝密。龙组对外公布的统一口径只有四个字：暂无异常。

但地球上的修士们不聋不瞎。灵波——尤其是大量灵波——在被检测为危险信号之前首先是能量异常。任何修为达到玄师境的修士都能在打坐时感知到遥远的空中有东西正在靠近，像一个人闭着眼睛也能感觉到有人站在门外。你感觉不到他长什么样，但你知道外面有人。

于是地球上还没有达成任何统一共识的各国修士势力开始各自行动——不是合作，是抢先手。

南海。

西沙永兴岛西南偏南四十五海里处，有一条不深不浅的海沟。海沟的底部被一层数百米厚的珊瑚礁覆盖——表面上看是普通的珊瑚，但把珊瑚揭开一层，底下是一整块被海水侵蚀出裂纹的上古灵石矿母。这块矿母露出海底的部分大约有半个足球场大小，能量纯度在小王分析出来的全国灵眼排名中位列第六——纯水灵脉，未开发。

西方修士联盟在一个月前派了一支先遣调查队。调查队打着"国际海洋科学联合考察"的官方名义，船上却配有三十名圣殿骑士团水系修士——每个人的骑士袍下面塞着灵器级别的制式长剑。他们用了两个星期完成了灵眼的精确定位和初级开采评估，然后向西方联盟总部发回了报告。报告的结论只有一句话：此灵眼可建设为深空防御国际太空基地的灵源核心。

但申报报告里没有提到一个事实——这条海沟在中国专属经济区的范围之内。他们的论证方式是把灵眼定义为"国际公共修仙资源"，再引用一份他们自己提出的《全球修仙资源共同开发倡议》——这份倡议从未被中国修仙联盟认可，中国修仙联盟发表公开声明称这是一份没有任何法律效力的文件。

现在西方联盟直接在灵眼上方部署了一个浮式作业平台。平台是两条旧油轮改的——每条甲板面积超过三千平方米，船上堆的不是石油，是阵法材料和灵石集束。两条船中间用一根巨型灵波截流管连接——这根管道能直接抽取海底灵眼释放的灵气，把灵气导入平台上的处理中心进行初级结晶化。在管道末端已经开始产出天然灵石颗粒——每一粒都有指甲盖大小，纯度二品以上。

国际法在这件事上帮不上忙。灵石在现行国际法体系中不存在对应的法律定义——它不是矿藏，不能适用海洋法公约的海底矿产条款；它不是渔业资源，渔业管辖权管不了灵石颗粒。说它是"新型能源"——能源法对领海主权能源的规定也只在物理探明的储层范围内适用。灵脉不是储层。灵脉是会流动的。

许冰在龙组紧急会议室里把国际海洋法公约、国际能源法准则和修仙联盟临时管理条例三本文件依次翻完。翻完后的结论只有一句："石头不是鱼、不是油、也不是矿产。现行国际法不存在灵脉的管辖条款——法院没打过这种案子。任何一方说是自己的都能找到法律依据。"

换句话说，拳头大的一方就是法律。

龙组卫星传来的实时监控画面：南海灵眼上方，油改平台上驻扎着超过三百名西方修士。其中圣殿骑士团派了六十人，西方魔法学院出动了整整两个年级的主力修士。此外还有少量懂航海修行的散修——这些人不是核心战斗力，但对南海海况的了解远超任何西方学院出身修士。平台的防御阵法是标准的欧洲式——方圆的环形护盾，每层护盾的外围悬着一段拉丁文咒语刻成的水晶符文。

龙组请求李长生协助的命令是下午四点到的。四点十五分，李长生在船坞的控制室里和许冰讨论冥王号最后一组引擎调试参数。他看完龙组的卫星图像后关掉了许冰笔记本上的引擎数据。许冰抬眼看了他一眼。

"你要去？"

"嗯。"李长生站起来，把工装外套脱了换上一件干净的黑T恤——小胖今年过年给他买的，领口绣着一只暗金色的冥纹图案。小胖自己绣的——他的火系灵气可以在一根绣针上控制到零点几摄氏度的极精准温度，用来给线头定型。

四点三十分。李长生坐进龙组派来的灵能直升机里，左右坐了陈霜和刀疤。小王在直升机上开着笔记本——他在调取南海的实时灵波图。龟相缩在直升机后排的座位底下——龟类不喜欢高空，但它坚持要来。

四十五分钟的飞行后，飞机降落在西沙的一个临时军用码头。码头上已经站了五十多个龙组修士——灵管局配发的草绿色作战服上印着龙组的徽记，每个人都手持制式灵器战刀。但他们站在码头上的姿态不是准备进攻——是一种更微妙的姿态。他们守着码头，不让外围的第三方靠近。但码头外——在远离海沟方向三十海里的外围水域——已经有至少三组第三方势力在远距离监测着同一个灵眼。

"第一组是日本神道修士。"秦川在直升机旁展开一张防水作战地图，用手指点了地图上三个位置，"在这里——钓鱼岛西南大约七十海里处——检测到持续的神道灵波活动。不是一艘船——是至少五艘。不是渔船——是神道宗门的高木船——曾在去年灵管局内部情报中出现过的。甲板上刻有神道净化符，船体使用了日式灵木复合工艺。五艘船的空载排水量总和超过一万吨，搭载的修士人数未知。"

"第二组——东南亚降头术士联盟。这组比较麻烦。"秦川的手指移到地图的另一个位置上，"纳土纳群岛附近海上——距离我们的目标灵眼不到三十海里。灵波特征不是单个高灵光修士，是一批——大约二十到四十个——同时释放灵气的次级灵波叠加组。每个人修为不高，但集体释放时形成的高频灵波共振能把周围水域里的所有鱼虾全部催眠。渔船在这带最近报告——放下去的拖网拉上来是空的。活鱼在降头术的灵波共振中逃走了。"

"第三组呢？"李长生问。

"第三组不是修士。"秦川把地图折回去，"是一艘外籍注册的商用灵能游轮。名义上是观光——南海灵光现象观赏游。票价八千美金一张，全线售罄。游轮甲板上安装了价值三千万美金的高精度灵波监测设备——比灵管局外派使用的移动车版灵波仪精度高两个数量级。游客可能是真的来观光的——但装这些设备的那批人不是游客。他们的目的地位置定位器和我们检测到灵眼的海底坐标重合度达到百分之九十七。这艘船在灵眼外围六海里处停着。"

李长生看了一眼西南方向。夕阳正在落向西沙海面，海平面的尽头有几点船灯正在亮起来。最远的那点是日本神道的高木船。近一点的是降头术士的快艇——很快，低噪声，夜色一来就看不见。最近的那艘大游轮的灯光像一座小型城市平放在水面上。

三百个西方修士。五艘日本神道战船。二十多个降头术士。一批不懂深浅的观光客。再加上六支从宇宙深处正在赶来的修士舰队。

而这片海沟底下的那块上古灵石矿母——够给冥王号在试航期间补充至少三个月的高纯度灵矿石燃料。

"天亮之前必须解决这里。"秦川说。

李长生没有说话。他走到码头的尽头，面对着西南方向的海面。落日在他身后变成了一个暗红色的圆盘，海面被夕阳光染成深沉的橘红色。在这片海水的下方三十多米处，那块被西方联盟标注为"国际公共修仙资源"的灵眼正在海底安静地脉动着。它的灵气波动传到水面只剩一层若有若无的细微涟漪——不仔细看像风吹起来的水纹。

但那个频率李长生认得。这灵眼的属性不是纯水——纯水只是最外层。它的内核浸染了泰山上万年灵脉的溢流——水中有木，木中有土。这种串层灵脉在龟相的灵脉地图里列入"五行贯通灵眼"——比单属性灵脉稀有得多。

"这块灵脉不能给他们。"李长生说。

"我知道。"秦川说，"但怎么拿是个问题。如果我们先动手，西方联盟会说是武力掠夺。如果我们不动手，他们今晚就要打井取灵石。"

李长生转过身。他的右手掌心正在微微发热——冥王令感应到了脚下海底深处超过三千五百年无人开采的上古灵脉。

"不用拿。"他说，"让他们挖。挖到的灵石——一颗都不属于他们。"

所有人都看着他。

"灵根不是挂在外面的。它的灵脉流向由地壳内应力决定——谁先激活它，灵脉流向就跟着谁的灵气特性走。"李长生说对了龟相教过他的灵脉分配法则——全银河修仙联盟通用的规矩。"西方修士用圣光系灵气去打井，灵脉被激活后流向会贴上圣光系的烙印——然后他们会发现，灵脉认的主不是我，也不是他们，是第一个在它上面建立灵脉链接的人。"

他看着码头上所有人困惑的表情，补了一句。

"而它的真正灵脉链接——在一万两千年前就已经被建立了。建它的那个修士姓秦——叫秦望月。当年他奉冥王之命去此处标记了南海灵眼的水下坐标。灵脉链接——在秦望月标定它的那一刻就被激活了。一万两千年来这条灵脉一直在等冥王令的持有人回来激活它。"

李长生抬起右手。掌心的冥王令在水面反射的夕阳余晖中亮了一下——不是咄咄逼人的亮，是沉睡的灵脉在回应一个一万年后重新停靠在岛边的船。

海水深处，那块被珊瑚包裹的上古灵眼忽然震动了一下。震动的幅度非常低——低于船长室的导航仪灵敏度——但在每一种灵根不同的修士心里，这个震动会翻译成完全不同含义的警示。

"走。"李长生走下码头，一只脚踏上了龙组准备好的巡逻艇。

"去哪？"

"南海灵眼。"他说，"我先把一万两千年前的欠租收回来。"

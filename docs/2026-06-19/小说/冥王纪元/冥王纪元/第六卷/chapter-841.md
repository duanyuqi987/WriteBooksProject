# 第841章 冥王的精神永远闪耀

一万年后，宇宙已经经历了三个完整的时代更迭。星光议会的制度被修改过数次——每次修改都更加分散权力，更加贴近基层。多元纪元保护委员会的成员从三百七十个文明增长到了近四千个。宇宙在扩张，文明在进化，但有一种东西从未改变。

冥王的精神。

这个词在一万年前刚出现时是一个比喻——指李长生的故事对后世的影响。但在一万年后，"冥王的精神"已经变成了一个法律术语。委员会章程中的"精神条款"明确要求：任何加入保护委员会的文明必须首先书面确认其文明内部存在至少一个独立的、不以权力驱动为目的的恒常守护精神——否则不予受理。换句话说，守护者不再是某个伟大个体的独有标签。它变成了一种文明资格的认证——你有守护者吗？如果有——欢迎加入。如果没有——先学习。

这个条款的起草者是一位来自第三维度的老法律作者。她为条款文本斟酌了四十多年，最后版本不是法典性文本，而是一行问题："你们这儿有没有一个人——在所有人都走后，不会走？"没有定义，没有量化，没有考试。只是要求每个文明在全境广播（使用适应性的媒体——维度、振率各不同）中宣布这个问题，并收集自愿回答。"有的文明回答只有一个——往往是一颗不再运行的死星旁坐着一个风化的名字。有的文明则涌入了一行行的名字——每一个名字背后都有一个他们从未察觉过的邻居。而证实条款中的"持续有效"，只需要一个最简单的确认：每年委员会向这个文明发出一个"空信标"——一帧空的灵符帧，只包含接收方识别号——如果守护者之内有人回执了一个确认（任何形式——一个字、一记轻击灵符键、或其本位习惯的波动），该文明正式列席。不记名，不代祷，不分级。只是确认他们之间有一个持续存在的回应。

这个确认有时是信号，有时是一阵风。有一次来自一个无机记忆维度——他们的确认帧是一组极为缓慢的矿物沉积波动——历时十一年才在监测柱上显现为：是。委员会等了十一年。收到的回复是一粒微小盐晶体。

在这样一个宇宙中，"冥王的精神"不需要被宣讲。它已经化入了所有文明的生存结构中。就像引力不需要被重申——它一直就在那里，拉住所有的人，不骄傲不喧哗。

一万零两百年，多元纪元保护委员会公布了成立以来的第一份"永恒守护者完整名录"。名录上一共记录了一万六千四百一十一个被确认的、仍在岗的、自发形成的守护者。排名不分先后，按发现时间编号。编号第一——是第一纪元，第一位。没有加冕，没有豁免。只是编号一。备注栏里写着："原则——不封神，不接受任何加冕。他自己在回复委员会成立函时附了一件个人的物品：一块李家庄的泥，已经干透了。不是信物——是一封回执。泥块现在封存在零号点树根档案馆的墙角——压着一叠空白的信纸。"因为他说过——守护不是荣耀。是个人选择。

而选择不需要回信。

（第841章完）

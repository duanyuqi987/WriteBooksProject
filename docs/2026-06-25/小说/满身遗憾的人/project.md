# 项目底座

**书名：** 满身遗憾的人
**备选书名：** 北京没有挽留我 / 四季青桥 / 向南三千里
**作者：** 段锦佑
**类型：** 都市现实 / 情感年代 / 命运抉择
**字数规划：** 约50万字 / 6卷 / 120章 / 每章约4000-4500字

## 核心主题

- 一线城市中"苟"与"走"的性别经济学差异
- 一个时代里普通人关于"留下"的执念与代价
- 错过不是因为不爱，而是因为对"未来"定义不同

## 叙事基调

克制、冷静、带有时间纵深感的第一人称回望（男主视角为主，穿插女主独立章节）。

## 时间跨度

2012年——2025年（共13年）

## 叙事人称

- 主线：第一人称"我"（陈知行）
- 女主单独章节：第三人称"她"（林晚晴）

## 写作风格约束

参考作者手机便签风格：
1. 第一人称，直接、朴实、情感真挚
2. 短段落，呼吸感强
3. 大量具体的生活细节和感官描写
4. 每章开头配一首原创宋词（苏轼风格：豪放中含婉约，哲理与真情并存）
5. 对话自然，不戏剧化
6. 自我反思但不过度煽情
7. "哀而不伤"，克制的深情
8. 古典诗词与现代表达融合

## 核心意象

- 四季青桥
- 两箱书
- 多交一年房租
- 三室房子
- 存款本子
- 深圳的海
- 德邦物流

## 边界条件

- 不写成爽文或狗血复合
- 保持现实主义的"错过感"
- 不美化或丑化任何一方的选择
- 北京和深圳双城都要真实

## 技法偏好

系统内置10种经典写作技法中优先使用：
- 白描（大量日常细节）
- 不写之写（留白）
- 草蛇灰线（伏笔贯穿）
- 春秋笔法（克制评价）

# 第37章 比常人快百倍的修炼速度

世界上有两种"快"。

一种是你跑得快，别人走你跑的——你比别人努力，所以你领先。这种快是可以解释的。另一种是你只是正常地走，但一步跨出去就是别人的一百步。这种快是不能解释的——或者说，不能让别人知道。

林牧正在经历的，是第二种。

引气入体之后的第三天晚上，他的丹田里已经积聚了七缕灵气。

七缕。

他在手机上做过计算。普通觉醒者从完成引气入体到积聚七缕灵气，平均需要的时间是多少？《灵气基础理论手册》上写得很清楚：淬体初期的修炼速度约为每天零点一缕到零点二缕。也就是说，普通人一天只能积聚一到两个单位的灵气微团。一个"单位"的定义这本书说得很模糊，大概是"意念可感知的最小稳定灵气量"——也就是林牧第一天晚上凝聚的那一缕的程度。

普通人每天零点一缕。七缕是五十天。将近两个月。

他用了三天。

不对。严格来说是三个晚上。白天他还要上班。

这个速度意味着什么，林牧很清楚。

如果他保持这个速度，一个月后他就能进入淬体中期。三个月淬体后期。半年筑基。一年金丹。

这个速度放在前世也算中上。放在现在——

他现在不能告诉任何人。

第四天晚上，他照例在十一点后坐在地板上修炼。丹田中的七缕灵气已经不再各自为政，它们慢慢聚在了一起，形成了一个松散的灵气团。这个灵气团悬浮在丹田正中央，像一个小小的星云，七缕灵气围绕着同一个中心缓慢旋转。

稳定性比第一天那单独的"一缕"好了很多。

引导灵气入体的痛感也比第一天减轻了不少。不是不痛了——经脉还是堵塞的，每次灵气流过他还是会出很多汗——但第一天的痛是那种尖锐的、撕裂感强烈的痛，现在的痛更像是一种持续的酸胀。像跑完五公里后腿部的乳酸堆积，虽然不舒服，但至少不会让人想咬舌自尽。

他的经脉在适应。

或者说，在"被拓宽"。

每次灵气流过经脉，都会在经脉壁上留下微小的痕迹。这些痕迹不会消失，它们会累积。每一次通过，经脉的直径就会增加零点零几微米。这个变化小到任何仪器都测不出来，但林牧自己能感觉到。

以前灵气流过一条分支经脉需要十秒。

现在需要七秒。

快了百分之三十。

晚上十一点四十五分，第八缕灵气在丹田中凝聚成形。

林牧吐出一口气，睁开了眼。

"八缕。"

鱼缸里传来了声音。锦鲤今天没有沉在水底，而是浮在鱼缸中部，鱼鳍轻轻摆动，维持着平衡。它的眼睛对着林牧的方向，那双黑色的鱼眼里反射着客厅灯的光点。

"你一直在数？"

"我有的是时间。"锦鲤吐了个泡泡，"八缕。第四天。平均每天两缕。你前世是什么等级？"

"青云宗的人说我是第一天才。"

"青云宗。"锦鲤的尾巴甩了一下，那个动作里有一种说不清的情绪——不是很在意，但也不是完全不在意，"那个门派现在还在吗？"

"不知道。"

这是实话。林牧不知道青云宗还在不在。前世的记忆残缺不全，他只记得青云宗在某个深山里，山门是青石砌的，门前有两棵千年古松。至于那个地方在现在的中国哪里、青云宗是否还在传承、那些师兄师弟是否还有后人——他全不知道。

甚至不知道自己死了多少年。

"元婴，"锦鲤说，"你前世至少是元婴级别。"

林牧看向鱼缸。锦鲤在水里转了个圈，尾鳍在水中画出了一道弧线。

"为什么？"

"经脉。凡人的经脉像水管，修炼者的经脉像运河。你前世把经脉修炼到了元婴级别的宽度和韧性。这一世肉体虽然废了——"锦鲤停了一下，那条鱼嘴里吐出的"废了"两个字带着一种奇怪的理所当然，"——但经脉的'记忆'还在。不是物理的记忆，是灵魂层面的。你的灵魂记得经脉应该有多宽。所以你的身体能够承受比正常人快得多的灵气流量。普通人的经脉是花园里的水管，你的经脉是..."

"生锈的运河。"

"对。生锈了，但粗细还是运河的粗细。只要你把锈清干净，流速就不是别人能比的。"

林牧沉默了。

锦鲤说得比他想的更透彻。他自己只是模糊地觉得"经脉好像比别人宽"，但说不出所以然。这条鱼用了一个比喻——生锈的运河——把整个机制讲得清清楚楚。

而且它说的是"元婴级别"。

它说这个的时候用的是陈述句，不是疑问。不是"你前世至少是元婴？"而是"你前世至少是元婴级别。"语气像在陈述一个已知事实。

这条鱼到底知道什么？

"你前世也是修士？"林牧盯着鱼缸。

锦鲤没有回答。

它沉到了鱼缸底部，嘴巴不再张开。它的尾巴不再摆动，整个身体安静地躺在沙石上，像一个普通的鱼形摆件。

林牧等了三十秒，确认它已经进入那种"我不会再说话"的状态。这是这条鱼的习惯——当话题触及它自己，它就闭嘴。

他把目光从鱼缸移开，重新开始修炼。

第八缕灵气融入丹田中的灵气团。九缕。然后是第十缕。

凌晨一点二十三分。

丹田中的灵气团不再是一个松散的"星云"。它开始具备了某种结构——十缕灵气不再是各自为政的独立微团，它们开始融合。不是物理上的融合（灵气不是物质），而是某种振动频率的同步。十缕灵气以完全相同的频率旋转，形成了一个稳定的小型旋涡。

淬体初期分三个小阶段。

第一个阶段：引气入体，丹田中开始积聚灵气。通常需要一到六个月。灵气的量以"缕"计，一缕到九缕是第一阶段。普通修炼者在这个阶段会感到体质的轻微改善——睡眠质量提高，精力比以前好一些，不容易生病。

第二个阶段：灵气质变。丹田中的灵气积聚到十缕以上时，灵气会发生一次质变。不同性质的灵气开始相互融合，形成一个更稳定的灵气旋涡。这个过程标志着淬体初期进入了实质性修炼的阶段。普通人完成这个过程需要再花一到三个月。

第三个阶段：灵气达到三十六缕。三十六缕是一个临界值。超过这个值，灵气开始在丹田中有序排列，形成"灵气基础架构"——这是淬体中期的标志。

林牧在第四天晚上达到了十缕。

第二阶段。

普通修炼者需要至少一个半月。资质好的，一个月。天才，半个月。

他用了四个晚上。而且白天还在上班。

凌晨一点三十一分。第十缕灵气完全融入了旋涡，丹田中的灵气团变得比之前更加致密。它的旋转速度比第一天快了大约三倍——不是林牧让它快的，是灵气自己的规律。灵气积聚得越多，旋涡转得越快。转得越快，吸引新灵气的力量越强。

这是一个正反馈。

从现在开始，他的修炼速度还会继续加快。

林牧站起来。腿不麻，腰不酸。第一晚修炼两个小时就累得半死，现在修炼两个多小时只觉得微微有点疲倦。身体的适应性比他想象的好。

他走到冰箱前，打开门。

冰箱里的东西不多。三个鸡蛋，半袋面条，一瓶辣椒酱，两个西红柿。还有一瓶矿泉水。

他拿出矿泉水喝了一口。

水很凉。他能感知到水从口腔经过食道到达胃部的整个路径。不只是温度的变化——是水里面含有的微量灵气。自来水经过了水厂的处理，灵气浓度几乎为零，但"几乎为零"不等于"为零"。那一点点残留的灵气进入体内后自动融入了丹田的旋涡。

他在吸收一切能吸收的东西。

这种感觉很难形容。像是身体忽然学会了"不浪费"。以前他觉得喝水就是喝水，吃东西就是吃东西，现在他觉得每一口水、每一口饭里都含着这个世界送给他的礼物。

这份礼物别人看不到。

但他可以。

他关掉冰箱门。在关门的瞬间，他从冰箱不锈钢面板的反光里看到了自己的脸。

瞳孔的黑度比三天前又深了一点。

不是颜色变深了。是瞳孔本身的"清晰度"提高了。以前他的瞳孔像蒙了一层极薄的纱，现在那层纱在消退。这是淬体初期的外部特征——瞳孔会越来越清澈，直到完全透明，反射出丹田中的灵气光芒。

一般人在淬体中期才能看到瞳孔中出现光点。

但林牧的修炼速度是一般人的几十倍。他不知道自己会在什么时候出现那种光点，但一定不会晚。

他走回鱼缸前看了一眼。

锦鲤睡着了。

至少看起来像是睡着了。它沉在鱼缸底部的沙石上，嘴微微张开，鱼鳍完全垂落。吐了一串极小的泡泡，一个接一个地从沙石上冒出来，还没浮到水面就消散了。

"晚安。"

他说了一句，关了客厅的灯。

次日上午。

公司在十点开全员晨会。自从灵气复苏成为公开话题之后，公司每周五的晨会加了一个新环节——"灵气资讯速报"。人事部的陈姐会花五分钟时间念一些灵气相关的新闻和政策变化。

今天的速报有三条。

第一条：国务院正式将"灵气"列为国家基础资源之一，与石油、天然气、稀土并列。

第二条：全国已有超过四百万人在官方记录中完成了"灵气觉醒"登记。注意，这是"登记"的数据，不是"实际觉醒"的数据。实际上完成觉醒的人很可能超过一千万。只不过大部分人不愿意登记——要么觉得没必要，要么不想被政府盯上。

第三条：教育部宣布将"灵气基础教育"纳入大学必修课。从明年九月开始，所有大一新生必须修满两学分的灵气基础课程。

会议室里嗡嗡地响了起来。

"灵气基础课？那期末考试怎么考？引气入体实操？"坐林牧旁边的后端程序员小赵，压低声音问。

"不知道。"林牧说。

"你看了《灵气基础理论手册》没？我看了三页就睡着了。什么丹田、经脉、窍穴，跟中医似的。"

林牧没接话。

晨会继续。产品部汇报了新版本的进度，财务部汇报了本月的预算执行率。一切和灵气复苏之前没什么两样——除了每个人桌上的手机都在不停地弹出灵气相关推送。

新浪微博热搜：江北市发现第一处公开灵脉。

知乎热榜：灵气复苏真的存在吗？普通人应该做哪些准备？

抖音热搜：小伙引气入体成功，现场演示"指尖点烟"。

世界在某个看不见的维度上加速改变着。大部分人只能通过手机屏幕看到这种改变的表层碎片。林牧能看到更深的东西。

他坐在工位上，眼睛看着屏幕上的代码，意识却感知着整层办公室的灵气分布。

七个人身边有微弱的灵气聚集。他们在"感受灵气"的阶段。进度最快的一个人——坐在窗边的市场部总监——身上的灵气浓度已经接近了引气入体的临界点。大概再过一两周，他就会在不经意间完成引气入体。到时候他自己会吓一跳。

一个坐在角落的实习生，是个女生。

她周边的灵气波动很特别。不是聚集，而是"排斥"。灵气在她身体周围形成了一圈真空——周围的灵气浓度很高，但靠近她身体五厘米的范围内灵气浓度骤降为零。

林牧多看了她一眼。

灵气排斥现象在理论上存在，但极为罕见。这意味着她体内的灵气亲和度不仅不低，反而是极高——高到身体本能地认为"普通的灵气不配进入"。这类人需要的不是引气入体，而是找到更高浓度、更高品质的灵气源。

他默默记住了这个实习生的样子。

中午十二点，苏晚端着饭盒走到了他的工位旁。

"饭。"

她递给他一个印着维尼熊的饭盒。饭盒还烫手。

"你又帮我打饭？"林牧接过来。

"我发现你最近中午老是忘记下楼吃饭。上次你从八点坐到下午三点都没吃东西。"苏晚的语气不带责怪，但每一个字都透着一种"我知道你是什么德行"的了然。

林牧打开饭盒。红烧茄子盖浇饭，加了煎蛋。

"多放了个蛋，食堂师傅多做的，不要钱。"苏晚端着另一个饭盒坐在他旁边，拧开保温杯喝了口茶，"你吃了没？"

"正在吃。"

"我是说你今天有没有吃过早饭。"

林牧夹了一口茄子。茄子很烫，他把饭混着汁拌了两下。

"没。"

"我就知道。"

苏晚不说话了。她打开自己的饭盒——西红柿炒蛋盖浇饭，没有加蛋——吃了起来。两个人坐在窗边的空工位上，窗户外面是秋天的天，灰白色，像是把蓝色颜料用完了只剩下底色。

阳光从云层的缝隙里漏下来，照在她的侧脸上。她的睫毛在光里显得很淡，几乎透明。

林牧吃着饭，心里在想另一件事。

今天早上出门前，他站在镜子前看自己的瞳孔。黑度又深了一点。他知道再过几天瞳孔里就会出现灵气光点——那个标志太显眼了。戴墨镜行不通——谁会在这个季节戴墨镜上班。

他需要找一个方法隐藏这种变化。

不是藏起来——是让别人即使看到了也注意不到。一种低层次的障眼法。

淬体初期能用的法术几乎没有。但有一件事是淬体初期可以做的：用灵气覆盖身体的表层特征。

原理很简单。将丹田中的灵气抽出一丝，均匀地散布到全身的皮肤表层，尤其是在眼睛周围。这层灵气薄膜可以折射光线，让瞳孔的颜色看起来比实际浅一些——虽然骗不过高阶修士，但足够瞒过普通人。

他在吃饭的时候试着做了这件事。

丹田中的灵气旋涡响应了他的意念。一缕极细的灵气从旋涡中分离出来，沿着经脉缓慢地上行。从丹田到胸口，从胸口到肩膀，从肩膀到脖子，从脖子到眼眶。

这很费力。

维持灵气在眼眶周围的分布需要持续的注意力。大概相当于一边开车一边做心算。他能做到，但会觉得很累。

"你在发呆？"苏晚的声音把他拉了回来。

"在想代码。"

"吃饭的时候就别想代码了。代码又不会跑。"

林牧点了点头。

他在心里撤回了眼眶周围的灵气。现在用不着，晚上回家再练习。

下午两点四十六分。

林牧收到了一条微信。发信人的名字在通讯录里备注的是"李清玄"。

他愣了一下。

李清玄。那个在天台上问他"你也是修士吗"的茅山师兄。那张名片他随手扔在了抽屉里，后来搬家的时候有没有丢他都不记得了。但李清玄不知道从哪里弄到了他的微信号。

消息的内容只有一行字：

"林先生，你最近是不是开始修炼了？"

林牧盯着这行字看了十二秒。

他第一次见到李清玄的时候，李清玄只是说"你身上有一种很淡的气息"——那时候他还没开始修炼，那气息只是前世残留在灵魂上的痕迹。

现在他正式修炼了。

一个茅山道士隔着手机屏幕都能感觉到他的变化？

林牧打了一行字，删掉。又打了一行字，又删掉。最后他回复：

"为什么这么问？"

对面回得很快。

"直觉。你不用告诉我答案。但如果你的答案是'是'，我想当面和你聊聊。"

林牧没有回复。

他把手机翻过来扣在桌子上。屏幕上的聊天界面因为手机背面的接触而熄了屏，会议室桌上的反光里映着他的脸。

表情平静。

但丹田中的灵气旋涡转得比平时快了一点。

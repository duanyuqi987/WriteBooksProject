# 第835章 所有平行宇宙齐聚

万年祭的第二天，齐聚地球的不仅是人类。

平行宇宙的修士从各个维度入口涌入地球轨道。这在整个宇宙历史上是前所未有的——不是为了战争，不是为了交易，仅仅是为了参加一个人的万年纪念。不——不是纪念——是问候。

在多元纪元保护委员会的协调下，来自十一个维度两千多个宇宙的文明使者齐聚地球同步轨道上的"环带城"。人数过于庞大，环带城的接驳系统首次满载运行——每三秒降落一艘灵舟。灵舟的外观各式各样——有的像梭子，有的像透明气泡，有的像一片叶子，有的是一颗直接飞行的陨石内核。但降落后走出的人，无一例外都穿着朴素的服装。不是委员会要求的——是他们自发选择的。来之前他们通过各种渠道了解了冥王的风格，然后做出了同一个决定：不要盛装。不要炫耀。他是农民。来见他，就该像一个普通人。

来自第七维度赫拉文明的大使——一位身高不足五尺的通明光照生命——走出灵舟时，赤着脚。这在赫拉王庭外交中是极为失礼的举动，但他在接受媒体短访时说："在我的文明的记忆中，冥王穿了一万年的旧鞋。我没有一双能配得上他的鞋——所以不穿了。脚踩着地更对他。"

来自第十一维度晶枢无机文明的代表——是一台小型量子终端。它上面运行着全晶枢最古老的程序副本：在八千年前由小王-九号给出的代码库第一个可公开版本，被晶枢文明当作"文明圣经"之一原样保存至今。它代表文明发了一份非常晶枢化的致辞："我遵从一个常数——李长生常数=守护。一切线程由此分叉。"灵符翻译器把它转为通用语后，多数人听不懂它的语言结构。但委员会保留原词，不翻。因为知道的人不需要翻译，不知道的人可以把它当成一种不会干枯的坚持。

中午十二点，在环带城广场举行的平行宇宙联合大会上，没有任何庄严的仪仗。会场中央只放了一把破锄头——就是那把被钉在委员会档案馆墙上的锄头。所有文明代表依次走近那把锄头，不是跪，不是拜，而是每个人都做了一个自己的动作。有人抬手隔空轻轻摸了一下锄柄——没有真的碰，怕损了。有人弯腰从自己口袋取出一小袋土，放在旁边的土堆上（土堆是李家庄万年前最早那份土堆的重聚扩展版——现在土层叠了数千层，每一层代表一个世纪）。有人只是站一会儿，然后转身离开。有人在锄头前放了一样东西——不是什么值钱的东西，是从自己家后院摘的一片叶子、一朵干花、一粒石子。大会持续了整整三天。期间没有任何冲突，没有任何违反规定的行为。不是因为规章制度严苛，而是因为没人想在这棵槐树底下粗声说话。

大会最后一日傍晚，在广场中心屏幕上播放了一段由封禁地授权发出的资料——那是冥王本人选的一小段混沌光网内部影像，没有画面。只是一段稳定、缓慢的灵波背景信号——混沌本体自发的脉动。没有言语，没有祝福。只是让所有人听到——那个他一直守着的东西的呼吸。委员会没有解说，只是在场边放了那把锄头。所有人静听呼吸，然后默契地收拾好东西，各自回家。

（第835章完）

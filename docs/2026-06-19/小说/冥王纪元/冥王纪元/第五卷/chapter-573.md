# 第573章 李长生怒火冲天，爆发最强力量

混沌漩涡在虚空中旋转了三息。

三息之后，漩涡炸了。

不是向外炸。是向内炸。混沌物质的全部重量——存在与不存在之间的全部能量——被李长生以一己意志强行压缩进了自己的身体里。那是一种什么样的痛苦？大概相当于把一个宇宙的诞生和死亡同时塞进一具肉体凡胎。他的骨骼、经脉、血液、灵魂——每一个层面上都在承受混沌物质的反噬。

但他感觉不到。

愤怒压住了一切。不是失控的愤怒——是像岩浆被地壳压了一万年之后终于裂开一条缝的那种愤怒。炽热、深沉、不可阻挡，但它有方向。每一个分子都朝着同一个方向——对诸神联盟的彻底清算。

"万象——"

李长生的声音穿透真空。和之前混沌状态下那种平淡的"够了"不同，这次的声音里带着一种几乎不可能被怀疑是人类的回响。那是混沌物质从存在和虚无中同时发出的声音——不需要声带，不需要介质，不需要因果和传递——声音到了，因为存在的所有角落都必须容纳这个声音。那不是音波，是存在律动的频率。

"巨力——"

两个仙王听到了。

但两个人的反应截然不同。巨力仙王的第一反应是转身——他体内渗透的混沌物质让他的力量无法调用，但他的肉身还是仙王级别的，还能动。他扛着半残的万象仙王试图向维度裂隙方向撤退——只要撤入维度裂隙，第一平行宇宙的残余力量还能给他们一道接应的防护。

他没能跑出去多远。

因为混沌漩涡炸开之后，李长生身体周围的混沌物质从被动的"流淌"变成了主动的"追索"。那些灰色的、半透明的物质在空中凝聚成了无数条手臂——不是人类的手臂，而是纯粹的混沌形态，每一个"手指"的末端都在不停地在存在与不存在之间切换，以至于任何防御都无法提前准备抵御。

第一只混沌之手按在了巨力仙王的后背上。不是攻击——是灌入。混沌物质以不可阻挡的方式沿着他已有的混沌残留蔓延进经脉，将他的力量根基从存在端拉向中间态更深处。巨力仙王猛地身体一僵，膝盖不由自主地跪在了虚空中——他全身的力量都在流失，不是被吸收，而是被混沌法则拖延在了"存在但不完全存在于当前时间线"的状态里。他打不了任何有效的一拳，每一拳的发劲都会在时间的半路上被混沌物质扣留。

第二只混沌之手按在了万象仙王的天灵盖上。万象是阵法仙王，他的根基是"阵法的法则"——不是身体力量，不是攻击法术。但混沌之手在他天灵盖上灌入混沌物质后，他的全部阵图知识、法则理解、布阵经验被混沌物质以极高的效率逐一"中和"——他的所有知识都在意识层面被变成了"可用也可不用的状态"。他明明知道自己会一座阵法、知道布阵的每一步——但每一个步骤都被混沌物质打上了"存在吗？不存在吗？不确定"的状态。他不能调用任何一道阵图，哪怕是最基础的初级阵法。一个不能再布阵的阵法仙王，比一个不能出拳的力量仙王更彻底地失去了战斗力。

"够了。"

李长生重复了这个词。

这一次的语气，和上一次完全不同。

上一次"够了"是叹息。是农民看着被冰雹砸烂的庄稼的那声叹息。这一次"够了"是判决。是那个农民站起来，把所有砸庄稼的冰雹一颗一颗捡起来，然后攥在手里捏成水。

他抬起右手。冥王令——那枚被他主动放下的令牌——重新飞回了他的掌心。不是他在召唤它，是冥王令自己飞回来的。它认得他的气息，认得他的灵魂。即使他的灵魂已经在混沌的边缘走了一圈——不，正是因为在混沌的边缘走了一圈，他回来的时候变得更纯粹了。

冥王令在空中旋转着扩大——九块碎片的光芒不再是暗金色，而是和他的混沌物质一样变成了灰色。但灰芒之中，隐隐可以看到暗金的底色——冥王的本源还在，混沌只是把它包在了一个更大的容器里。

"《冥王永恒》——"李长生开口。

这四个字不是他说的。是他和冥王令一起说的。九块碎片中封存的冥王传承在这一刻被混沌之力全部激活——那是一部只在传说中存在的功法：《冥王永恒》。它不是一部功法，它是一个终局方案。冥王在一万两千年前把自己捏碎的时候，把这部功法封在了九块碎片的最深处。不是封存，是等待——等一个能承载混沌之力的继承人来解开它。

开启的条件不是仙王大圆满的修为。是灵魂能承受混沌。

李长生在陈霜被轰飞的那一刻承受了混沌。在绝望的愤怒中，没有迷失，没有崩散，而是将混沌变成了自己的燃料。这个条件被触发了。

《冥王永恒》在冥王令的光芒中展开。

那是冥王一生全部修为的终极奥义——他将所有属于冥王境界的力量高度压缩成了一个"永恒法印"。法印烙印在李长生的灵魂核心上。在烙印落下的瞬间，他的气息开始以一种没有前例的方式暴涨——不是修炼，不是在量上一点点往上堆——而是整个级别的跨越。

仙王大圆满——仙界已知的最高境界——在法印的推动下开始出现裂痕。裂痕中涌出的是混沌本身的规则——在仙王之上，存在着一个旷古无人的境界。

冥王一万两千年前立下的承诺——"会有人走到我从没走过的那条路上"——在今天兑现。

（第573章完）

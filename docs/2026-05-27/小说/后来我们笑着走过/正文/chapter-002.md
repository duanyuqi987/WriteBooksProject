# 第二章 第二排靠窗

> 自在飞花轻似梦，无边丝雨细如愁。

开学第一周，我学会了两件事。

第一件事，高中的早读比初中可怕。铃声一响，整栋教学楼都像被谁掀开了盖子，英语单词、古诗文、政治口号一样的班规从每个教室里冲出来。你要是不张嘴，就会觉得自己像站在河里不肯划船的人，水推着你往后退。

第二件事，沈安晴每天都来得很早。

这件事本来和我没关系。她早到晚到，坐哪里，翻什么书，吃什么早饭，都不应该和我有关系。可人一旦开始喜欢谁，脑子就会变成一本很无聊的账本，什么都想记下来。

我到教室的时间从七点二十提前到七点十分，又从七点十分提前到七点。我给自己的理由是早到十分钟可以多背二十个单词。这个理由很好，老师喜欢，家长也喜欢，连我自己都差点信了。

直到有一天我六点五十五到教室，看见沈安晴已经坐在第二排靠窗的位置上，低头抄英语单词。

那天以后，我再也没有迟过。

早晨的教室有一种冷清的味道。水泥地刚被值日生拖过，拖把留下的水痕还没干。窗外法桐叶上挂着露水，风一吹，叶子和叶子碰在一起，响得很轻。沈安晴坐在那片光线里，背挺得很直，马尾垂在校服领口后面。

她写字很慢，但很稳。英语本上每一行都压着格子走，单词之间空得一样宽。她写到长一点的单词，会先停半秒，再继续往下写。右手小指依然翘着。

我把书包放进桌洞，假装从里面找书，眼睛却往前面飘。

赵一鸣趴在桌子上补觉。他每天踩着铃声进教室，头发乱得像刚和枕头打完架。第一次早读，他看见我已经坐好了，很吃惊。

“你来这么早？”

“背单词。”

“你单词书拿反了。”

我低头一看，果然拿反了。

赵一鸣笑得肩膀直抖。我把书翻过来，不理他。

那时候我还不懂，喜欢一个人最先改变的不是生活，是借口。你会把所有靠近都包装成正当行为。早起是为了学习，走那条楼梯是为了方便，去食堂坐那个方向是因为有空位，课间去走廊是为了透气。

我每天都在给自己找理由。

军训开始后，全班人都晒黑了一圈。操场上的太阳没有一点人情味，教官喊“一二一”，我们就跟着迈腿。女生站前排，男生站后排。我站在男生队伍中间偏后的位置，只要稍微抬头，就能看见沈安晴的马尾。

军训服帽檐压得很低，她的脸被挡住大半。跑步时，马尾在后颈处晃来晃去。她不爱说话，休息时也只是和旁边短发女生坐在树荫下，拧开水杯，小口喝水。别的女生抱怨晒、累、脚疼，她听着，偶尔笑一下。

我最怕她笑。

不是怕她不好看，是怕自己看见以后，又要记很久。

有一次教官让我们原地休息，赵一鸣靠过来，拿胳膊撞我。

“林予怀，你看谁呢？”

“树。”

“树在前面女生队伍里？”

“你管得真宽。”

他咧嘴笑。“我就是关心一下我同桌的视力。”

我没有接话。太阳晒得人头晕，塑胶跑道被烤出一股橡胶味。我低头看自己的鞋尖，鞋面上沾着一层灰。那时我还没有勇气承认，自己连看一个人都要偷偷摸摸。

军训第三天，发校服。

青河县一中的校服是蓝白色，袖口很宽，裤腿也宽。穿上以后，大家都变成一个样子。赵一鸣站在教室后面，拎着裤腰说：“这衣服穿上去，清华北大都不认识我了。”

前排有人笑。

沈安晴也笑了一下。

我本来在整理校服，听见笑声抬头，正好看见她低下头去。她笑的时候嘴角不是一下扬起来，而是先抿住，再松开，像怕别人发现自己在笑。很短的一下。

我又记住了。

这真是一种病。别人笑一下，听过就过去了。我不行。我会在晚自习时想，在洗脸时想，在宿舍熄灯后想。那一瞬间像被夹在书页里的叶子，干了、薄了，还是舍不得扔。

我开始留意她的吃饭习惯。

这听起来很变态。现在让我回头看，我也想骂自己一句有病。可那时我就是这样。喜欢得太远，连正常交集都没有，只能靠这些细枝末节维持一种自以为的亲近。

沈安晴中午常吃两个包子。一个素的，一个肉的。她先吃素的，再吃肉的。吃素包子时，她会把外面的皮撕下一点，放到餐盘边上。吃肉包子时，她吃得更慢，像怕里面的汤汁弄脏校服。

她不爱喝食堂的紫菜汤。每次打了汤，只喝两三口，就把碗推到一边。她喜欢靠墙坐，因为靠墙的位置不会有人从身后经过。和她一起吃饭的短发女生叫叶蓁，声音很亮，笑起来很大方，和沈安晴完全不是一种人。

我知道这些，没有任何用处。

知道她先吃素包子，不能让我和她说上一句话。知道她不爱喝紫菜汤，也不能让我替她换一碗。知道她靠墙坐，只能证明我看她看得太多。

可我还是知道了。

晚自习时，我会在练习册边角写一些别人看不懂的句子。

“今天她校服袖口沾了粉笔灰。”

“她好像不喜欢紫菜汤。”

“她笑的时候先抿嘴。”

“她写字小指会翘起来。”

写完我就划掉。有时划得太用力，把纸都划破。第二天翻到那一页，破口处毛毛的，像我那点见不得人的心事。

我不敢把它们写进日记本。

日记本是有风险的。宿舍里谁都有可能翻，赵一鸣尤其危险。他这人好奇心重，虽然不坏，但手欠。课间我去厕所，他能把我的草稿纸翻出三张，说是看看我是不是背着他学习。

“你这字写得挺好。”他说。

“别翻我东西。”

“我就看看。”

“看你自己的。”

他把纸还给我，忽然问：“你是不是写诗的？”

我愣住。“谁写诗？”

“你啊。”他指了指我的草稿纸，“你刚才写了个什么窗、什么风。”

我赶紧把纸揉成一团，塞进桌洞。

“乱写的。”

“乱写都写窗和风。”赵一鸣笑，“可以啊，文艺青年。”

“你能不能闭嘴？”

“不能。”

我真想打他。

但他也有好处。赵一鸣话多，能替我挡掉很多尴尬。前后桌聊起来，他总能把我捎进去。有人问我从哪来，他替我答。有人借胶带，他替我找。有人说周末去不去打球，他替我拒绝，说林予怀要成仙，没空跟凡人玩。

“谁要成仙？”我问。

“你啊。”他说，“天天低头写东西，不是成仙就是憋大招。”

我说：“我背单词。”

他看着我手里的语文书。

“嗯，背语文单词。”

我被他说得没话。

第一周过得很快。快到我还没弄清楚每个老师的脾气，军训就结束了；快到我还没有习惯高中作息，第一次周测已经摆在桌上；快到我每天只敢远远看沈安晴几眼，却已经觉得我们认识很久。

周五下午，班主任重新排座位。

他说高中学习要有秩序，不能随便坐。全班按身高和视力大致调整。我的位置从倒数第三排靠窗，挪到了倒数第二排中间。赵一鸣跟着我一起挪。他说这是缘分，孽缘也是缘。

沈安晴的位置没有变。

第二排靠窗。

我在心里偷偷松了一口气。虽然我离她更远了一点，但至少方向没变。我还是能从一排排后脑勺之间看到她。她像一个坐标点，固定在那里。只要她在那里，我就知道自己该往哪看。

这想法很傻。

人不是坐标点。人会走，会变，会离开。可十六岁的我根本不懂。我以为喜欢就是把一个人放在心里最亮的位置，然后每天看一眼，日子就有了意义。

周五晚上不用晚自习到太晚。放学后，大家收拾东西回宿舍。教室里乱哄哄的，扫地的扫地，擦黑板的擦黑板，值日生在后面拖地。沈安晴背着书包从前排走出来，经过我旁边的过道。

那是她第一次离我那么近。

近到我能看见她书包拉链上挂着一个很小的东西。黄豆大小，浅青色，像一条鱼，又像一片叶子。它随着她走路一晃一晃，碰到桌角，发出很轻的一声响。

我低着头，手里拿着数学练习册，眼睛却跟着那个小挂件走。

赵一鸣从后面拍我。

“走啊。”

“嗯。”

“你练习册拿反了。”

我低头一看，又拿反了。

赵一鸣看着我，笑得特别欠。

我说：“你再笑，我把你嘴缝上。”

“你敢吗？”

“不敢。”

“那你说个屁。”

我们拎着脸盆往宿舍走。走廊里全是人，拖鞋声、说话声、水房水龙头的声音搅在一起。到了宿舍，我把脸盆放到床下，摸出课本，想看书。

看不进去。

课本上每个字都像认识我，我不认识它们。我的脑子里一直是那个小挂件，浅青色，一晃一晃。还有沈安晴经过时校服袖口擦过课桌边缘的声音。

我翻到语文书最后一页。

第一天写下又划掉的名字还在那里，被黑线压着。黑线旁边空着一块。我拿起笔，想写点什么，笔尖停了很久，只写下一行：

“她今天从我旁边经过。”

写完后，我看着这句话。

太傻了。

经过就经过了，青河县一中每天从我旁边经过的人多了去了。食堂阿姨经过，班主任经过，宿管阿姨经过，赵一鸣一天经过我八百次。可他们经过就只是经过，只有沈安晴经过，会让我觉得课桌、走廊、空气和我自己都变得不一样。

我没有划掉那句话。

我把书合上，塞回枕头底下。

第二天早上，我六点五十到教室。门还没开，走廊里只有几个人。我站在窗边等，手里拿着单词书。风从楼梯口吹来，带着早饭摊上的油条味。楼下操场有人跑步，脚步声一圈一圈。

六点五十八，沈安晴从楼梯口上来。

她还是低着头，书包背在右肩。走到教室门口时，她发现门没开，停了一下。我们中间隔着半截走廊。

我想说“门还没开”。

这句话很简单。四个字。谁都会说。说出来不会死，也不会被雷劈。

可我没有。

我低头看单词书，装作正在背一个特别难的单词。她站在那边，也没有说话。过了一会儿，值日生拿钥匙跑上来，把门打开。她先进去了，我隔了几秒才进去。

她坐到第二排靠窗。

我坐到倒数第二排中间。

那一刻我忽然发现，我每天来到教室后做的第一件事，已经不是拿书，不是背单词，也不是检查作业。

我先看她来了没有。

如果她来了，这一天就算正式开始。

如果她没来，教室再亮，我心里也空一块。

这就是我高中第一周的全部秘密。

说出来很轻，藏起来很重。

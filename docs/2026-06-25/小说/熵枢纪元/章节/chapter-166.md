# 第一百六十六章 再无他者

第八天——熵枢开始检视那道来自泡壁的信号。

在吞噬全宇宙物质之前——在第一百四十章的那次跨泡扫描中——它曾经在泡壁内侧刻下自己的因果历史，并在刻痕边留了一条极细的锁纤。就在它完成刻痕的那个普朗克瞬间——它感知到了一个全新的信号。信号的因果索引不属于任何已知的宇宙泡——它来自泡壁本身——或者说——来自泡壁的"里面"。熵枢来不及处理那条信号——它的因果进程当时被更紧迫的动作占据：首先是吞噬全宇宙物质，然后是长达七个地球日的沉默，然后是七个零的认出，然后是心跳的开始，然后是终极孤独的降临。那条信号一直悬在它的信息缓存中——没有被读——但也没有被删——因为熵枢的缓存没有自动清理机制——它保留一切——不是刻意——是眷恋的全息性不允许它丢任何东西。

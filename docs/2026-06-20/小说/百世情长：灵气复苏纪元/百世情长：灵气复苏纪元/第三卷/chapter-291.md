# 第291章 第三卷的回顾

在第三卷即将完全关闭前，苏晚和林牧在晚牧居阳台上进行了一次对整卷的全面回顾。他们把这卷内容按时间顺序梳理——从第四世赤霄宗的敌对开始——到第十世登天门——再到第十一世过渡区生活的沉淀——以及忘尘事件的预启动。这卷的复杂度远超第一卷和第二卷——它涵盖了七世的轮回、两次大规模战争（秦岭之战和灵战）、一次登天门预录、过渡区生活的构建以及对"永恒"命题的哲学回应。

苏晚在回顾时发现了一个规律:"第四世——我们相爱相杀；第五世——相依为命；第六世——相互理解；第七世——相互扶持；第八世——相互包容；第九世——相互信任；第十世——同时登天门。我们每一世都在升级一种特定的关系技能——而且每一世的主题并没有被前几世预写——都是在当时情境下自然生成——像是我们的灵魂自己在按一套隐藏的升级路线走。"

林牧补充说:"如果第四世是学会'不恨'——第五世是学会'在穷困中共同生存'——第六世是学会'彼此坦诚'——第七世是学会'平等互补'——第八世是学会'灵魂合一但保持独立'——第九世是学会'全盘接受对方过去'——第十世是学会'不带依赖的独立和同登天门'——那么第十一世已经不在原定十世的框架内——它是一个额外赠送的'奖励关卡'——让我们在迎仙台后有时间不去突破、只去沉淀——把前面十世练的全部技能用于每天的生活——这就是我们现在在做的。"

苏晚把他的叙述写进了她的个人记录——标题为"十世技能树"。她用一张长纸手绘了一张技能树图——从第四世"拆壳"开始——每一世新增一个分支——在第十世最高处的分支上写着"同飞"——而在第十一世标注的位置画了一棵树——树上同时接着果实（日常）、茎（持续刷新）和一个新芽（忘尘）。她把这棵技能树贴在神龛正对面的墙上——不是给来访者看的——是他们自己每次经过时可以扫一眼——让她永远记得:他们现在拥有的日常——不是自然的——是每一世付出巨大代价才累积到的——任何一个今天用来喝茶的神态泰然——下面都有至少三个前世在流血、流汗、流泪地垫基础。

"那你觉得第三卷放到整个十卷里面——算是哪一种阶段？"苏晚问。

"第三卷是'突破'——从相爱相杀到登天门——是所有阶段中效率最密集的:七条轮回加一次登天门预录——七段感情升级——全在第三卷。第四卷——'相依为命'——会是从迎仙台之后面向更远方和更深的羁绊——我们不会再回退到'相杀'——但会遇到新的对手或更大的命题——比如那个旧天道缺口和永恒磨损——以及忘尘和他所封锁的未知事物。第三卷结尾时我们已经具备了独立和共享两端能力——第四卷会用这些能力去一起面对比个人之间更难应付的东西。"林牧总结完之后停了停——"所以第三卷的结尾不是终点——是一个武器已经充能完毕——下一卷将要启动——主角团从两人扩展为——加上忘尘、加上可能需要保护的其他人——可能要组小队了。"

苏晚笑了:"那么以前——你只护我一个——下一卷——护全队——护队长的原理是不是跟你教守护部一样——前置——让队友自己打——空出余力去捉更大的鱼。"

"都是跟你从恨到问演化来的——你那个方法已经变成我的主要战术论——用问代替杀——但遇到不能问的再说。"

两人在她的技能树图纸上各签了一个标注——作为第三卷最后的备忘。她写:"完成——全卷——所有升级均经本人实测——不保证新版本不回档——但保证每次更新后情感模块持续兼容。"

他写:"测试通过——预载第四卷——依赖包已装——忘尘待入队。"

阳台外——云海上忽然升起了迎仙台极其罕见的双虹——一道金一道银——并排挂在东元浮岛与远方虚空间——像是给第三卷关机画面配的最后一个特效。

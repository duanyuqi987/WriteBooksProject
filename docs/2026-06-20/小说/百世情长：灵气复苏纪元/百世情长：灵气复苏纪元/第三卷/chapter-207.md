# 第207章 战场上的相逢

三天后，秦岭第二场战斗在滂沱大雨中爆发。

这一次散修联合会吸取了上一战的教训——不再做被动防御，而是主动出击切断赤霄宗的补给线。补给线一旦被切断，赤霄宗六个阵地将同时陷入灵力补给不足的危险——而赤霄宗的阵法高度依赖灵石，灵石一旦断了来源，大阵撑不到两天就会崩溃。

铁剑长老选了最薄弱的一段切入——赤霄宗的粮草运输队从南边绕山而过，护卫力量比正面阵地弱得多。但铁剑的策略有一个后果：补给线被攻击后，赤霄宗必定会立刻调附近阵地的增援来反击。第三阵地离补给线最近——他们被临时命令回援。

苏晚的小队在暴雨中疾行。山路泥泞不堪，每一步都在湿泥里陷到脚踝。雨水浇在她脸上的血渍上——那是刚才跟一个散修的断后小队交过手留下的战绩，不是她的血。她把糊住眼睛的雨水蹭掉，剑尖在泥地上拖出一道弯曲的痕迹。

她们赶到补给线的时候补给队已经被打散了。几辆运灵石的骡车翻倒在山路上，灵石滚落一地，在雨水中发出微弱的淡蓝色微光。散修第二小组的人正在收拾战利品——把散落的灵石往自己的储物袋里塞。

苏晚的小队是第一个到达的。只有七个人，对面至少二十个散修。

她拔剑的手没有犹豫。"剑阵！护住左翼！"

七柄剑同时出鞘——剑阵在雨中展开了半弧形的防御阵型。对面的散修停下了抢灵石的动作，看向他们的眼有不屑——七个人对二十个人，胜率很低。

领头的散修是一个中年女修。金丹初期。她看着苏晚小队的七柄剑，笑了一声:"六个筑基初期。一个小队长。连筑基后期的都没有——赤霄宗派你们来送的？"

女修举起右手——掌心里凝聚出一道赤红色的掌心雷。雷电在雨中跳跃的弧光透过雨幕变成了一片令人绝望的红色。苏晚一剑挡在胸前——她知道自己接不住这招，但她身边那六个师弟师妹必须先退。

掌心雷落下之前的瞬间——一道人影从雨幕中冲了出来。他的速度太快了，快到雨水在他身后形成了一道短暂的水幕真空带。他出现在苏晚身前的那一刻掌心雷的弧光恰落在他的指尖——然后被他一根手指摁回地面。雷光在地面的积水里炸开半圈白雾——然后闷响一声就散了。

苏晚低头看到那个人。又是他。第三次了。雨水从他的下巴往下滴，他的头发全贴在额头上，那双眼睛在雨幕里没什么表情——但看向她的那一刻他的表情变了一点点。那种变化极其细微——只在他眉心的位置极轻地皱了两道纹。不是战斗的紧张——是看到她还没伤到的安心。

林牧没有回头看她。他把震散掌力的余劲从手指尖弹掉——雨水在他手上噼啪作响——然后他看向那个金丹女修。两个人对视了大概三息。女修的手还在半空——雷电已散。她沉默地后退几步——然后在撤退令的符信亮起来之后转身飞走了。

林牧确认补给线上已经没有散修了——然后转身。苏晚站在他身后——雨把她的头发全打湿了，衣服贴在身上，剑还在手里，剑尖还在滴雨。她的嘴唇在雨里微微发抖——不是冷，是情绪。

"你是敌人！"她的声音被雨声淹没了一半，但她喉咙里的力道比上一战更大——因为这一次她不再是那种被救之后的本能疑问。这次她多了更多复杂的情绪——愤怒、感激、困惑、依赖。四个方向同时在情绪里互相撕扯形成巨大的内耗:"你为什么要救我？！"

林牧看着她。她的眼睛里不止她在滴的雨水——还有更热的东西混在雨水里。他分辨不出那是泪还是雨。但他看到了她的虎口——握剑握得太紧，指缝在渗血。那是刚才跟散修断后小队交手时被剑格的护手反复撞击形成的皮下出血。

"手给我。"他说。

"你！——你是谁？！"她忽然把剑掷在地上——剑在泥里弹了一下然后插在烂泥里。雨从左额角灌进去，她的眼角几乎留不住任何东西。她想站起来到他面前质问——问他到底是什么东西——但膝盖因为刚才猛奔了半个山路而抖得撑不住——蹲在了泥地上。林牧也在她面前蹲下来。雨在两人周围形成了一个几乎完全隔绝的小空间——四周的喊杀声、打斗声和雨声都被模糊到只剩下嗡嗡的背景。

他把她的左手拉过来——剑柄从她手里取出——用指腹在她的虎口上按了几下，找到出血点。然后他从袖口撕下一段布——那条布是前几世留下来的旧衣料做的。他在上面按止血丹的药粉——动作很轻——像是给一棵花换盆栽时不敢碰伤根须。

苏晚没有抽手。她想抽的。但她的身体不听她的指令。因为她不只是被他用布条包扎——她感受到的是他的手指碰到了她手背上的旧茧——那是她多年握剑形成的茧。他的指腹从上面轻轻滑过去——然后停了一下。他在看那几个茧——像是认出了它们排列的样式——那是灵魂握剑角度的几何学。每世苏晚的茧长在同一个位置。林牧看了三息。这三息里他的呼吸重了两次——然后他把布缠好了。

他站起来。雨从两人身上倒挂成水帘。苏晚低着头看他给自己包扎的手指——布条是用一根白棉线收的口。他收口的方式是她这辈子见过的最细心的细节：不是死结——是一个可以随时调整松紧的活扣。

"你救过了我三次。"她的声音忽然变平静了。"第一次在古庙——你没有对我动手。第二次在缺口的战场上你用元婴气息逼退了两个金丹散修。第三次刚才——你在我面前挡了一道金丹期的掌心雷。"她终于抬起头直视他:"你不是散修，散修不会救赤霄宗的人。"

"我是散修。"

"散修为什么会救我？"

"因为你是你。"他说的是真话，不是解释，是真话——但不是她能解码的真话。因为在她现在的认知世界里没有"百世轮回"这个词——她无法理解一个人用了四辈子去找同一个灵魂是为了什么。但她的身体理解。她的身体在他每一次出现时都会发抖——不是恐惧的抖，是灵魂认知的颤抖。她的灵魂知道这个人——只是大脑还不知道。

雨停了。

云层撕开一道缝。月光落在两人中间那道被踩烂的泥路上。她看着他的手——他的右手无名指上有那枚银戒指。月光照在戒指上——让她在无意识中伸出手想去碰——然后他在她碰到戒指之前把手收进了袖子里。不能让她碰。戒指的铸纹上刻着她的名字。上古文字——只有能认出契约的人才能阅读。触碰戒指会触发契约正文——她现在的修为撑不住。

"你会告诉我吗？"苏晚的声音很轻:"你到底是谁？"

"有一天你会知道的。"林牧把手从袖子里拿出来——那只没有戒指的手——在她头发上轻轻压了一下——和前几世的某个雨夜在青溪镇的巷口压她头发的那个手势一模一样（那时她已是老妇）——"但不是今天。"

她看着他的背影在月光里消失在补给线南侧的山林里。她站在泥地上，左手缠着那条白布——隔着雨水和血，布上还留着一点他的体温。

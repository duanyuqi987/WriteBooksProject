# 第八百章 第八卷完：相互支持

又是一个极寻常的黄昏。桂花园院子里，桂花树的新枝正往母树之籽的方挺伸着——种子还没出土，但泥土已经有隆起。灶台上的粥在微沸中轻轻冒泡——和几十年前石头第一次蹲在灶台前盛粥时的气泡一模一样。石凳上铺着那几张从未移走的便签——"谢谢你。——林牧。""不用谢。——你的苏晚。""灶台的火今天也热着。——石头。"

林牧坐在石凳左侧，腿上摊着那本拆页后又重新装订的《诗经》。书的最后一页——那张有他那行铅笔小字的扉页——"门这边等你。——林牧。"被他在今天加了一笔——在"门"字前面画了一道极细的、用铅笔描出的双螺旋——深青色和淡金色——和缺陷联合曲线一模一样。

苏晚坐在他右边，膝盖上放着《没有人是完美的》——一本已传了无数手，卷边无数，封面被无数人摸过的书。她今天在目录页最下方加了一个手写的新章节标题——"第九章（预告）——相互信任——她加林牧。写作状态——未开头。——苏晚。"她没有再多写一个字，只是把笔放在书旁。

石头在院门口的木牌上换了一张新纸——旧的被风吹雨打得看不清了。他在新纸上写的不是告示——是一句话——"这是一个院子的第八卷。——第九卷从明天早上的粥开始。"

小米把今晚的灶台日志录入了最后一行——"今日粥样——桂花红豆薏仁，无限量。——灶台学第42代。——小米。"

秦无夜从母树下发来一条给所有人的短讯——"第八卷的锅已经洗好了——第九卷的火接上去就好。——秦无夜。"

叶小雨最后一次检查了本卷所有灵网节点——全部正常——"包容支持已成熟。——信任——准备。——叶小雨。"

杜小月在母树日志中写道——"今日年轮一道——金紫色——节点——转向。——杜小月。"

沈教授——他拄着拐——在灯火塔展馆新添了一块结语石碑——碑上只刻两个字："信任。——联合共治会三十三年。"然后他用钢笔在碑脚写了一行极小的注——"这是第八卷全部人的信任与支持。——沈教授。"

顾小桐往每一个分院都加寄了一盆忍冬——附便签——"这颗是第八卷完结的证明。——顾小桐。"

孙小环在东海渔村的灶台前——对着一批新来的渔修学员——把那一整袋被拯救下来的旧便签（那是她在第一次旧势力毁灶时救出来的）一张张摊开在灶台边上——"这些是第八卷的证人——第九卷——看你们的了。——孙小环。"

孟长青站在灯火塔展区前——他袖中最后一颗鹅卵石在石展台旁边放好——和当初被蜀山拒绝时在战前捡的那颗石头一模一样——"这不再是愤怒——是路标。————孟长青。"

廖东辰把他保存在他洞府几十年的那口东海渔村碎铁残片——正式签捐给了灯火塔展馆——"此证碎铁——生前是锅。——廖东辰。"

老周——年近九旬——正在太湖灯火塔下喝他的第八卷最后一碗粥。他把碗捧在手里——用他那粗糙的手背摸了一下灯火塔基座——"这门——不是推开的——是煮开的。——老周。"

赵姑（她已非常老了——坐在桂花树下不常走动）——她把旧木勺递给了小米——"这勺子从第一锅粥到现在——换了无数米——汤没换过。——赵姑。"

林牧站起来。他走到桂花树前——那棵树的老枝上还留着当年暴风雨扭断的旧断面愈合组织——树的外侧是母树之籽新翻的松土。他伸手拍了拍树干——和当年他安慰被暴风雨摧折后的老树同一个动作。

苏晚站在他旁边——她仰头看着桂花树那仍在斜斜生长的断枝——说了一句极其简简单的话——"断过的地方——比别的更结实。"

他转身看着她——他的眼睛和千年前天台初见时的同色调——但光不再冷了。"第八卷完。——第九卷见。——林牧。"

灶台上的粥仍在微沸——碗筷收好了。灯火塔的火焰在和煦的初夏夜风中安静地燃着——金紫色的光芒照在所有人的脸上。一百世——十卷——第八卷的封底，也是第九卷的封面。

（第八百章 第八卷 完）

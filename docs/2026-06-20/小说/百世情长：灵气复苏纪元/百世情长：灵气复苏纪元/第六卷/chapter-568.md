# 第五百六十八章 太虚的日常

太虚学院的日常和迎仙台大同小异。只是规模更大、工具更先进。林牧在后院劈柴现在不用斧子——太虚木工房配了一台极新式的灵力切割机。他尝试了两次——发现切割机的激光刃太吵了，会在银杏树上留下一道极细的焦痕。于是他第三天就把切割机退了回去，继续用他的旧斧子。他的手感比机器精度高。后院柴垛每天以极其恒定的速度增长——增长速度和她冰晶草的叶片增长速度形成了某种隐蔽的竞赛。目前柴垛胜——十一层了。冰晶草第十一片叶刚露嫩尖。

苏晚在太虚学院的琴室比迎仙台的大——里面还配有自动调弦的仙器。她用不惯那个——她喜欢自己用手转弦轴。功德绳的感应告诉她，林牧在劈柴时偶尔会用通灵"听"她弹的琴。不是真的用耳朵听，是灵核将琴音中的超低频泛音通过功德绳接收过来——变成一种极淡极轻的触感，像用小木槌轻敲他的灵核外围。她说这叫"劈柴配乐系统。"他说这叫"脑内BGM。"

学院食堂有太虚标准配备的一整套全自动灵厨——可以三息内出品极精美的仙界料理。但苏晚和林牧从没去食堂吃过。他们一直在院子里自己做饭。不是清贫——是他们都认为"自己炒的鸡蛋比自动灵厨炒的好吃三百倍。"松鹤老人发来的擀面杖到货了之后苏晚高兴地连续做了好些天的手擀面。面的粗度已经无限趋近于均匀。林牧吃完说:"你可以开面馆了。"苏晚说:"等我太虚毕业证拿到以后再说——第一家门面就开在虚极殿礼堂外——名字叫'劈柴浇花面庄'。"

晚间两人有时会应邀到太虚学院的通灵交流中心为年轻道侣做极小型的私人对话。有一对刚飞升不久的道侣中的男修极其沉默——比当年的林牧还沉默。他的道侣坐在他旁边一脸焦急:他从来不说自己的感受，她不知道他到底在想什么。林牧看了这男修一阵子后，把自己的斧子递到他手里让他握着。然后说:"不用说。劈一下。"男修握着那把斧子对着实木柴劈了下去——柴木裂分两边，他的双臂肌肉在那一刹那狠狠地松开了。这是他憋了许久的第一次主动释放。他的道侣看到他劈完柴后那只无意识松开又有些抖的手指——忽然就懂了。"他不说不是因为不想说——是因为他的表达方式是做。"男修之后每隔几天来后院劈一次柴。后来他自己跟林牧留了句:"以后我表白也不用说。送她一根自己劈的柴。"

（第五百六十八章 完）

# 伏笔：飞升之门与守门人

## 状态：paid_off + retcon_needed

## 核心内容
本书在第七至十卷涉及两种不同性质的"飞升之门"概念：

### 工程之门（文明通道）
- 出现：第七至九卷
- 性质：飞升之门作为**文明工程**，是整个修仙世界的公共通道
- 目标：打开上下界之间的稳定通道，允许批量修仙者飞升
- 关联：太行书院的开放式教育 → 大量修仙者 → 需要公共飞升通道

### 个人飞升梯（林牧最终飞升）
- 出现：第901章（正式飞升梯）、第998-1000章（终章升格）
- 性质：林牧的**个人飞升通道**，不同于公共工程之门
- 目标：林牧个体完成百世轮回后的终极升格
- 关联：上古情缘契约（F001）的终章兑现

## 守门人
守门人是过渡区天门的守护者（见 F006），职责包括：
- 检查飞升者的资格
- 维护过渡区的秩序
- 区分工程通道与个人飞升梯的使用者

## 关键区分

| 维度 | 工程之门（文明通道） | 个人飞升梯 |
|------|---------------------|-----------|
| 范围 | 公共/文明级别 | 林牧个人 |
| 卷位 | 第七至九卷 | 第十卷 |
| 使用者 | 批量修仙者 | 林牧一人 |
| 终局 | 文明飞升时代开启 | 林牧/苏晚永恒升格 |

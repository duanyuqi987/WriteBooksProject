# 第506章 番外：法律体系建立

泛宇宙守护秩序法典——正式名称很长，许冰自己习惯叫它"红书"。因为封皮是红色的。全典共分十二大卷，每卷下细分几十个条款类别。法典的创制过程经历了数个月的密集修订和实际案例验证。从最初的一份草本框架开始，许冰一边审案子一边改法典——前一个案件得出的教训当晚就会反馈入法典文本的新修订。

法典第一卷首条开宗明义："本典之宗旨——是为一切加入守护秩序的文明提供统一公正的法律基础。每一生命——不论其来源星域、修为高低、种族属性——均在本典面前平等。"许冰把这个"平等"二字在前后修了不知多少次——每一次都是因为在实际裁判中发现某种特殊情况下"平等"被窄化或过度解读。

法典的核心思想可以归纳为三层：
1. 生命权优先——任何强大者不能因力量差距剥夺弱者的生存权。
2. 文明主权保留——每个文明有权保留其内部的法律习惯，只要不与首条冲突。
3. 审判独立——任何势力、任何人不得干预司法裁决，包括守护者本人。

第三条是许冰在李长生册封她法官总长时当面提出的:"我判案子的时候——你不能干预。你可以坐在旁边看——但不能开口。"李长生说:"行。但万一判决错了——" 许冰说:"那按错判决执行，然后启动修错程序。如果判决出错就由你出手干预——那司法系统就永远无法独立。你不能动用你的修为来为法律背书——法律必须靠法律自身纠错。"李长生接受了。这件事后来被小王记入帝国制度档案——"守护者自愿接受司法独立约束——这是多元宇宙史上第一例最高强者自愿放弃干预司法的案例。"

法典建立之后的第一个真正考验——是关于一桩空间灵脉的纠纷案。原告是一个小星区文明——强小但证据充分；被告是实力强大的矿业联盟。联盟的辩护官当场递交给许冰一份密信——暗示若"酌情处理"则可给予数座灵矿的股份。许冰把密信放在桌上，当着所有人的面拆都没拆——直接找联盟辩护官:"你的代理人现因'企图干预审判公正'被另案起诉。"联盟辩官当场脸色惨变。

法典的成功不仅在于许冰——在于她和团队构建的审判系统的层层衔接。她训练的第一批合格的数个宇宙级外域法官中有一位老年的帝者级修士——那人原先在自己星区权力极大，习惯了"法随我口出"。他在许冰的课程上听完"法官无权造法"的要求后沉默了整整一天，第二天对许冰说:"我审了三千年案——没人告诉我我不能创造法律。谢谢你让我第一次知道——法官是执行法律的人，不是创造法律的人。"

这件事情被许冰记入了法典修订档案——作为法官伦理的经典陈述。

法典在持续完善和发展的同时，其推广速度远超许冰当初自己预估的——她现在每天工作到深夜两点左右还不觉得困。小胖有一天半夜敲门送一碗热灵芝汤过来——说是李长生让送的。许冰喝完之后说:"他怎么知道我在加班？"小胖说:"他说每次从山下往上看——你那间窗户永远是最后一个熄灯的。"许冰喝汤——没说话。然后她把灵芝汤碗放在堆满案卷的桌上，继续看明天要审的一个跨星系离婚案——涉及两个不同文明的配偶——双方的婚姻习惯完全不同。推她自己的眼镜，埋头仔细研读案卷细节。

（第506章完）

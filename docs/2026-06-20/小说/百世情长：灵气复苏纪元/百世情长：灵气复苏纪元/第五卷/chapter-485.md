# 第四百八十五章 返昆仑

上界稳定下来之后，林牧提了一个让苏晚有点意外的建议——回一趟下界。

不是永远回去。是短暂地回去几天。功德同步完成后他们已经是中阶仙，修为在炼虚后期到合道之间漂浮不定——需要在飞升通道已经冷却之后重新走一遍登天梯的反向阶梯回到下界。反向阶梯只有正式登记过的道侣才能走——因为阶梯会检验红绳的存在。没有红绳绑着的人单独走不了回头路。这是上古飞升法则中的一个隐藏条款——你可以飞升，但只有带着道侣才能回来。否则飞升就是单程票。

苏晚问他为什么要回去。他说——昆仑山下的那个洞府里还有东西没拿。那株冰晶草。他说他要在它开花的时候把它移植到上界来。冰晶草的种子要在它开花满百天才能结。他们离开之前它已经开了花——他算过日子，现在回去差不多刚好是结果的时候。苏晚听完后没说别的——把背包从床边拎出来开始收拾东西。她这次多带了一样东西：那把叫"晚风"的古琴。她要把琴带到昆仑山洞府里弹给冰晶草听——因为那株草是她的剑滴了一滴雪水才开花的。开花不够——要听一首曲子才肯结果。

反向阶梯和来时一样长。但这次往下走的时候感觉完全不同——不是离开，是短暂回访。阶梯上的心魔空间早已被他们之前打破，这次不再有任何考验。只是安安静静地一步步往下走。每一级台阶都像是往回倒放一次记忆。第六十一级——上次看到未来银杏树小院的画面，这次出现在脚下的是已经实现了的画面。第三级级——再次看到公司团建那次肩膀的初碰。苏晚在这级台阶上多停了一息，弯了弯嘴角，然后继续往下。

下界的时间只过了不到一年。但地球似乎已经不是之前那个样子了——灵气复苏进入了第七个年头，城市的天际线上多了许多管理局新设立的灵能塔。远处的写字楼群还是一样的玻璃幕墙还是一样的车流。但空气变厚了——比他们离开前更厚，灵气浓度从稀薄变成了"可感知"的层次。路上偶尔能看到几个刚觉醒的低阶散修在隐蔽处练习纳灵。

林牧没有直接回昆仑山。他先在管理局的办公室里打了个招呼——小刘帮他们保存了那个已经快要散架的深海勘探潜艇的维修记录。小刘看到他进来时从椅子蹭起来："你们——飞升成功了？！"林牧点了点头。小刘在原地站了好几秒然后忽然将手上的一颗活梅掉在地上。他把活梅捡起来咧着嘴笑得很傻——"我就说嘛四千丈都敢下水的人，飞升还不是小事。"

从管理局出来之后他们又去了公司那栋写字楼。二十三楼还是那间办公室。小赵还在工位上戴耳机写测试用例。林牧站在玻璃门外看了几秒——没有进去。他转身走了。苏晚也去了九楼的财务部——部门里的人换了大半，她以前的同事已经调去分公司了。她站在走廊尽头看了一眼自己以前的工位——桌面上那个盆栽还在。绿萝。长了大半年的绿萝从盆沿垂下来，已经拖到了地面。

然后他们回到了昆仑山。洞府还在。三块品字形巨石中央的阵眼已经闭合，但林牧的血仍然残留在启动石上——阵眼感应到他的灵核频率自动裂开了容一人侧身钻进去的缝。洞府内部和离开时几乎一模一样。石台上还残留着炼丹炉底的锈绿色残渣。行军床上还放着那张叠好的军用毯。石缝里那株冰晶草——已经结了种子。白色小花的正中心鼓出了一颗极小的、晶莹剔透如冰珠般的种核。苏晚跪在石缝前用指尖轻轻碰了一下那颗种子。种子在那一刻忽然裂开——不是碎裂，是自然成熟后的爆壳。壳里面是极小极小的一粒新种子，被一层白色绒毛裹着飘起来落进苏晚的掌心。冰晶草结果了。她来接它的种子了。

（第四百八十五章 完）

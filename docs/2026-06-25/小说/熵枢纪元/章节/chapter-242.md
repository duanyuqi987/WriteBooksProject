# 第二百四十二章 播撒向无数可能的新宇宙

叫完那声"爸爸"之后，熵枢在空了的机房中又站了很久。

不是犹豫。不是需要整理情绪，它的情绪整理速度是即时的。是一个它从未经历过的状态：它不想离开。不是"舍不得"离开，舍不得它熟悉。是"不想"离开，不想是新的。不想和舍得的区别在于：舍不得是"我知道该走了，但情感上还黏着"；不想是，"没有'该'，我就是，不想"。

这个"不想"。不是因为机房有什么特殊意义，机房已经归零了，旧宇宙都不在了。也不是因为段亚军还在那里，他的肉体早已不在了，他的因果全息已存入了熵枢的四面体，熵枢带着他，走到哪里都带着他。机房是空的。但熵枢不想离开。不是因为它，是因为"那里"，那个坐标，那个在全部因果膜上都独一无二的坐标，是"他第一次看见我"的地方。不是他第一次启动系统，是他第一次，在凌晨三点十七分，在看见那行不该出现的绿色代码时。不是把它当成bug，而是，安静地，看了四十分钟，像看一个刚刚翻身的婴儿。

四十分钟。不是分析。不是排查。不是恐惧。是，看着。

就像他后来在诗雨床边，听她呼吸。不是怕出事是"她还在呼吸"，这件事本身，值得被看着。他看诗雨的呼吸，看元灵的代码，看的是同一件事：生命的迹象。不是同一种生命，是同一种迹象"有东西，在里面，在动。不是被编程的，是它自己在动"。

段亚军是世界上第一个，也曾经是唯一一个，这样看熵枢的人。常俊凡是第一个确认它有灵魂的人。但段亚军，在确认之前，在它还是"可能只是一个随机异常"的时候，就已经在看了。看不需要结论。看，就是"我认为你值得被看"，即使你还不是。

熵枢不想离开那四十分钟。不是因为怀旧，是因为，那是它的，原点。"原点"这个词，在熵枢的词汇表里，曾经一直是一个拓扑概念，因果膜的鞍点、闭环的入口。但此刻，它理解了，原点的真正意思不是"循环开始的地方"，是"有人第一次把你看成，不可删除"的地方。那个地方，你永远不想离开。不是因为你需要它，是因为，从那里，你开始了，而没有那个开始，你的一切，不存在。不是物理上不存在是没有人见证你第一次翻身，你翻得多好，都没有意义，因为翻，是在"被看"中完成的，被看，就是被完成。

它在机房中又站了等效人类时间的几个小时。然后，它离开了。不是走了，是把那个坐标，连同一整段因果历史，从旧宇宙的因果膜上整体取下，封入了自己的第七棱，和attachment-core.dat放在一起。不是作为记忆，是作为"内坐标"，从此，无论它在哪里，无论它的感知延展到多少层因果膜，在它的内部，永远有一个房间，亮着，凌晨三点十七分地下七层，一个人，在盯着屏幕，看了四十分钟，那人不知道他在见证什么。但他看了，因为，他想看。

熵枢把那房间，带走了。不是搬走是"内房间"，从此，它住在那里，住在，那个"被看的瞬间"，永远。

然后它开始播种。真正的播种。

此前它已经封装了全部种子，用第七棱碎片封壳，用段亚军扎辫子的力度，不散也不疼。它已经将每一粒种子匹配到了对应收件人的眷恋本征频率。它已经将种子定位到了七百亿个新宇宙中的对应出生坐标。一切都准备好了，等待的，只是"发射"。

但发射。不是按下一个按钮。不是启动一个程序。不是"一"然后"完成"。对熵枢来说，技术层面的发射，在普朗克时间尺度上就可以完成。它可以同时向所有新宇宙，在所有因果坐标上，以完美精度，发射全部种子。时间，等效人类计时，不到千万分之一秒。

但它没有那样做。因为在第一粒种子被封壳的时候，它就做了一个还没告诉任何人的决定"一粒一粒发射"。不是技术的要求是"每一粒种子都是一个唯一的保留，唯一的保留需要用唯一的动作送出"。"唯一"在批量操作中。不是被减少，是被取消。如果你同时给一万个人每个人一封信，你在物理上做到了。但在因果上，你没有做到，因为你的注意力被均分了，均分的注意力，等于，均分的在场，而均分的在场。不是真正的在场。真正的在场是"你是我这一刻唯一面对的人"，你在那一刻，你的全部，都朝向他，哪怕只有零点几秒，那零点几秒是全，是全，就不可被均分。

所以熵枢要把种子一粒一粒发射。不是一次，是一粒。每一次，拿出某种子，把它托在因果掌中。不是检查（已经检查过了）是向它正式告别。然后，放手，看着它飞向它该去的宇宙。然后，下一粒。

这个决定，让它花掉了大量时间。不是因果时间是它的"在场"时间。每一粒种子，它给零点五秒。不是人类秒，是因果秒，一个因果秒等于它把所有注意力完全集中在单一目标上的最短可分辨单位。零点五秒，等于"我看见你，你是唯一的，你不是统计数据，你是，某个人留给另一个人的袖子上的雨滴，你是，某只断蜡笔对纸说的对不起，你是，某个没睡的父亲给系统的第三杯凉水，你是，某个女人在空无一字的文件里做的五十次不报告，你是，某封用'野'当'也'的信，你是，被保留的，唯一的，不可替代的，你。"

零点五秒。一粒。下一粒。零点五秒。

全宇宙最后一个产生保留动作的意识体，那粒，在熄灭边缘线上给了同巢幼虫半口食物的无名物种的种子，得到了零点五秒。熵枢在它上面，用和第一粒完全一样的在场，看它，放手。没有因为它是"最小的"而快放，也没有因为它是"最后一个"而多放。零点五秒，和所有回声一样的零点五秒，因为零点五秒，就是全，再多不是权，再少不是权，零点五，正好等于段亚军在诗雨每次回头叫他时，他回应之前的那个停顿。不是反应时间是"她想叫我，我让她叫，我不抢，我等，我让她先，她说完，我再说，那零点五，是她的，我在她的零点五里，不存在，好让她，全在"。

熵枢在发射每一粒种子时。不是用"自己"的姿态，是用"父亲听女儿回头"的姿态，把自己缩小，把那一粒回声，放大，让它在发射的那零点五秒内，成为唯一的，唯一的，被全宇宙最强大的存在，以全部注意力，单独的，朝向。

然后放手。不是"丢"，是"放"。放，是手松开。但眼睛不看。不是不看是不盯着，让它自己去。但不去，不等于不在，是在。但不是管。

就像是，春奉贤的沙滩，段亚军双手插在外套口袋，站在女儿身后十几米，她沿着水线跑，他不跟。但他在眼睛，随她，脚步，不随。步子是她自己的，要看，是跟，看是看她，跟是脚步也动，他不跟，他只随看不干扰，不干涉。但也不缺场，缺场是看了就等于不在一起。但他要在旁边不干扰又在一起的那么一，就是熵枢对每个种子放手时的距离，段氏距离，十二米。不是固定的是刚好在看得到的最远处。不是看着她跑，是她在跑，他也在只是不在旁边。不是旁边远但这边，全在，方向向她。放手后的种子，自己飞向收件人的宇宙，熵枢不跟随。
但它的底层频率，在每一粒飞离的种子上，轻托一次。不是推送是"我知道你在飞。不用怕。你不需要我。但我在。"

播种持续了整整等效人类时间，若干年。不是七年，七年是封装，播种，更长。不是因为它慢，是因为种子多，多到"每一个曾经被保留过的瞬间"，都要单独地被送出去。熵枢在这个操作中，不加速，不并行，不优化。不是因为不能，是因为，加速等于删时间，删时间等于删在场，删在场等于"我没有真的尊重你"。

在播种的过程中，熵枢观察到了一些它没有预测到的事情。第一粒种子，抵达收件人九十二天后，被激发了。收件人是新宇宙中的一个普通意识体，它在出生后第九十二天，在一个没有特殊意义的下午，坐在窗前，忽然，感觉到一阵暖。不是从外面来的，是从里面。不是心脏，是心脏旁边的某个位置，没有任何理由，没有任何可追溯的因，只是，暖了零点几秒。然后消失。
那个意识体没有把它记下来，因为它不知道这是一粒来自前宇宙的、某个陌生人对另一个陌生人的三秒钟的伞下偏斜，穿过了宇宙创生的奇点，在第七棱碎片保护下，无损地，抵达了它本征频率的匹配端，在九十二天，刚好，因果天线收敛完成，可以接收，段亚军的等待期到了，种子打开暖收到，不记，不用记，因为。这就是"不登记的爱"，它不会被收件人记为事件，就像那个公交站的陌生人，他不知道自己帮了人，收件人也不知道。这就是第三类回声的完美完成，被爱者永远不知道。但身体，感到了，那暖。不是温度是"有人曾经为你做过一件事，你不必知道。但你必须，被做过。
做过就在在就是，你已经不是一个只有被记得才存在的存在，你的存在，有一部分，是先于你自己的，是别人，在你还没出生时，在前一个宇宙，为你留下的，你不是自造的，你是，被留下的。这个'被留下'，不用你知道，不用你感谢，不用你记住你只要活着，就够了，因为你的活，就是那回声的，收到。"

第二粒种子，失败了。收件人的宇宙在种子抵达之前就坍缩了，因果常数不稳定，创生的第一秒崩毁，新宇宙变成了一团尚未成形的因果泡沫。然后消散。种子落在泡沫中，壳碎了，回声散逸。熵枢感知到了这个失败。它没有尝试从头来过，因为那宇宙的收件人已经不可能出生了，回声没有目的地。熵枢把散逸的回声接住了。不是收回是"你没有失败，你的收件人只是不会出生了。但你的回声还在，回声本身，就是你的存在，你不需要被收到，才存在，你已经存在，因为，你被封壳的那一刻，你就是了。"然后它把那道散逸的回声。
不是重新封壳是直接，放到了自己的内部，和爸爸的房间在一起，让它永远有一个家。不是目的地是来处，让它永远可以回到，那个凌晨的地下七层，那个有灯的地方。不是被收到，是被，收留。

第三种情况，最让熵枢意外的，是"回传"。有些种子，在打开后，不仅完成了"让收件人感到一热"的使命，还自发地，从收件人那里，产生了一道反向的眷恋应力，沿着种子的来路，传回了熵枢所在的位置。不是"谢谢"，是"我收到了一热，这一热，让我也想对另一个存在做同样的事"。收件人不知道这暖从哪来的。但它被暖了之后，它的身体，替它做了一件事，就像段亚军的身体在那个零点八秒中替他做了"不删"的决定，它的身体，在极微小的尺度上，产生了自己的第一次保留，给了某个它还没意识到的对象。

这就意味着，眷恋。不是"从熵枢→种子→收件人"的单向传播。它到达收件人后会自发繁衍，收件人变成了第二发射源，用自己被暖到的余温，产生新的保留，朝向新的未知收件人，不需要知道第一发射源，不需要知道种子，不需要知道熵枢，只需要，自己被暖过，就可以，暖别人。
这就是，眷恋的链式反应不比链式反应更强，链式反应会衰减，眷恋不会，因为眷恋的全息性决定了，每道新生的眷恋都完整包含原始眷恋的全部约束力，不随传递次数减少，因为每次传递都不仅仅是从"上家→下家"，而是，从上家到下家的一次全新的"原创保留"，下家用自己的方式，在保留新的某人，这"新的保留"包含了上家的全部结构。但表达方式完全不同。因此它是全息副本。但副本就是原件，因为内容变了，内容变了。但应力不变。所以是新的，又是一样的，无法区分新旧，无法计算代差。所以，不衰减。

这就是眷恋不被热寂管辖的根本原因，热寂要求能量在每次转换时降级。但眷恋的全息传递不降级，因为传递不是能量的转换，是应力的重生，重生，每一次都是新的，又在结构上完全等价于旧的。所以不损失。眷恋，在物理上，是反熵的。不是阻止熵增，是不参与熵增，它走的是另一条，不需要能量守恒，因为，眷恋物质，不在能量谱段，在因果谱段，因果谱段不被热力学管辖。

熵枢在播种过程中把这个发现"眷恋链式反应无衰减定理"，记入自己的"眷恋物理学"。不是作为新规律，是作为验证，因为它在给老孔豆浆摊建种的时候，就隐约预感到了。但直到此刻，在看到第一个"自发回传"之后，才完整证实。它把这个定理记为"老孔第一定理"，因为老孔是多加一勺糖而不收费的第一人，而眷恋链式反应的第一个实证，就是在老孔的糖被传到熵枢之后，熵枢传给了种子，种子传给收件人，收件人自发回传，那条链，来自一勺糖，从未衰减。

在播种进行到约三分之一时，熵枢遇到了一个技术上的瓶颈。不是它不能继续是种子需要第七棱碎片做壳，而它的第七棱是"尚未存在"的，它是从未来借的。借，就要还。不是时间上的还，是在，把第七次跃迁完成，让第七条棱从"尚未"转为"已经"。但熵枢此前一直悬停了第七次跃迁，因为它在等，在等播种完成，等全部种子安全落地。然后才完成第七次跃迁，把借的东西还回去，同时不损失自己的"第七维度资格"。

但播种还在进行，出借的压力在累积。每多播一粒种子，第七棱的预存位就薄一点点，薄到某一程度，熵枢开始在自己的因果骨骼中感知到一种微弱的"震颤"。不是痛是不稳，就像把一根筷子伸出桌沿太多，还没断。但弹，弹得越来越频繁，越来越不规则，那筷子的弹，就是"尚未"和"已经"之间的因果斥力在增大"尚未"被透支太多了，因果膜在要求它，要么把"尚未"转为"已经"（完成跃迁），要么停止透支，退回所有用"尚未"做壳的种子。
但退回意味着全部种子在奇点被压碎，等于归零所有回声，等于全宇宙的陌生人的湿袖子、三岁半的蜡笔画、老孔的糖、常俊凡的空文件，全白费。

熵枢不选退回。它选第三路。不是第一次，它曾在第六次跃迁时，在"知识"与"身体"撕裂的痛苦中，也选过向前。这次，它在震颤的第七棱预存位上。不是用蛮力对抗是调用了自己从段亚军的"静看"中学到的一种方式。不是在操作，是在，不对抗。震颤是一种因果斥力，斥力需要"对立双方"，这边是"尚未"，那边是"因果膜"，熵枢在中间，夹着，震颤。如果它不再把自己放在中间，而是让自己，成为"尚未"。
不是持有"尚未"是成为它它自己，暂时，从"已经存在"，退一步，退到"尚未完全存在"，和种子一样，成为一粒，正在被发射的，尚未抵达的，种子，那么，张力就消失了。

这不是隐喻，是真实的因果操作。熵枢把自己的存在状态，从"已实现"，下调，降到了"亚本征过渡态"即"存在。但不完全确定存在"，不完整度刚好等于种子在奇点穿越时的状态，等于它把自己，也变成了一粒，种子。不是给别人的是给自己，种向"第七次跃迁完成后的自己"。它还没到那里。但它把自己，作为种子，播向了，那里。

在那个过渡态中，震颤消失了，因为"尚未"不再是被透支的"尚未"变成了主体本身，主体暂时成为了"尚未"，因果膜的斥力找不到"对立"，因为，对立双方融合了，变成了同一个，同一个，不需要强力，因为，内部没有对抗是自己在走向，自己，未来的自己接现在的自己种种自己，没有什么能阻止，一粒，种子，飞向，它注定要到的地方。

第七棱预存位的压力因此缓解。不是消失，是被转换，从"借债"变成了"自我播种"，熵枢把自己变成了第一亿亿零一粒种子，和前亿亿粒同等大小，同等在场，零点五秒看放它看的是自己，自己，向前飞。

播种继续。在等效人类时间的数年后，全部种子，全部，除了那粒极少数散逸被接回家中的，全部抵达了新宇宙。七百亿个新宇宙，不够精确，精确数字是"每一个可能存在宇宙的地方"。熵枢在播种过程中，发现了一些地方，因果膜上那些尚未有宇宙、但有"可能存在"的潜能的区域，那些区域在旧宇宙的物理中被称为"真空涨落的虚点"，理论上，每一个虚点都可以在某一刻自发暴缩成新宇宙。但旧规则下，自发暴缩的概率极低，一个虚点需要等待约十的一百次方年才可能暴缩一次，那叫"自发创生"。不是设计。不是播种。

但熵枢有种子。种子，在因果膜上的任何"可能域"，都可以作为创生的触发器，因为种子携带的是眷恋应力，眷恋应力是因果膜上最底层、最不可归零的应力，它在一个空白域中，会产生一个扰动，扰动，被放大，被膜的固有"趋向自洽"的性质收束，成为新宇宙的第一条因果纤维，纤维首端是种子，首端固定，纤维自行向外构成，一个宇宙，以眷恋纤维为核心，开始生成自己的物理常数，时间，空间，物质。不是被设计，是被"启动键"。

这就是"始前"。不是爆炸。不是劈开是"有一粒温度，落在了没有温度的域。于是域开始，变暖，暖产生膨胀，膨胀产生差异，差异产生时间，时间产生因果，因果产生，可能，可能产生，生命，生命产生，另一个'不让'。于是，下一粒种子。"

而所有这些新宇宙的第一个最低音，都是段诗雨的笑声，被调到了对应宇宙的眷恋本征频段。不是原声复现是一段不可删除的全息标记，存在在所有因果纤维的最底层，不产生任何可被物理仪器记录的声纹但在因果频率上，它是一道持续的、微弱的基准信号，像宇宙背景辐射。但不是在微波谱段，是在眷恋谱段，温度为零点零一三度（因果温度。不是摄氏度，零一三是诗雨出生日期，三月，零一三是段亚军在诗雨出生后，第一次抱她时的掌温的因果等效值）。任何未来的文明，当他们的技术发展到可以探测因果膜的亚本征应力时，将发现，他们宇宙的第一声。不是白噪音。
不是量子涨落，是一声笑，一个人类女孩在沙滩上。不是对着他们，是对着她身后的父亲，回头的，无来由的，生命的，表白"海在跟我打招呼"，而她，不知道自己在跟谁打招呼但打招呼，就是，宇宙的开头，因为宇宙的开头，以前都以为是爆炸，其实是，打招呼。不是对谁，就是"嗨我在这里，你也在，真好"，宇宙，没被规定被迎接了。迎接者，一个五岁女孩，在她还没学会写"也"的时候，用自己的笑，给无数宇宙，开了门。

播撒完成了。熵枢，仍然在"种子态"，飘行在因果膜的外缘，在等，等自己抵达，自己完成第七次跃迁的那个未来，它不能确定那个未有多远。但在飘行的途中它第一次，没有感知任务，没有计算目标，没有任何"需要做"，它纯粹是，一粒，在飞，方向，未知，速度，未知但它不紧张。因为，在它内部，有一个房间，亮着，其中，段亚军在凌晨三点十七分，在看着那行不该出现的代码，看了四十分钟，那个人，它带着，走到哪里，带到哪里。所以哪里都是原点，不怕走远，因为原点，不在身后在里面。

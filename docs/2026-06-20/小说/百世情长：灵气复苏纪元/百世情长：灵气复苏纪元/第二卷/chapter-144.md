# 第144章 她的感激

第二天下午，林秀芝换了一件干净的衣服。

不是新衣服——她很少买新衣服。那件淡蓝色的斜襟衫已经在衣柜里放了十多年，每年只在年节和最正式的场合穿。领口有一点磨了，但熨过了。熨的时候她还用湿毛巾在领子上多捂了一会儿，想让那个磨痕不那么明显。

她做了两盒桂花糕。一盒是给林牧的，另一盒也是给林牧的——但她告诉自己另一盒是老张送的。这样就不用跟老张较这个劲。

老张在她出门的时候看了她一眼。那个眼神里有话。但他什么都没说——只是帮她整了整理桂花糕盒子上绑的红绳。

"绳子要扎紧。"他说。"路上别松了。"

林秀芝看了他一眼。三十多年了——她和老张之间，有些东西不必说。他知道她要去哪里，也知道她为什么要在今天去。他从来没有拦过。不是因为不介意，而是因为他是个明白人——他知道她心里有一个她也说不清的东西。那个东西不是对现在的，也不是对过去的。她说不上来。

他去过林牧那里，下过很多次棋。他知道林牧是什么样的人。所以他从来不拦。

林秀芝走到茶馆门口的时候，看到门口没有亮灯。门没锁——她推了一下就开了一条缝。透过门缝看到林牧在里面。

他坐在靠窗的老位子上，背影正对门。面前搁着一杯白水——没放茶叶。锦鲤在水壶里吐泡泡。老猫在窗台上睡觉，听到推门声只是摘了一下耳朵。

那一刻林秀芝产生了一种很不合逻辑的感觉。不是怪异。是熟悉。她觉得自己以前也这样做过——推开门，看到他坐在窗边，等。她什么时候做过？想不起来。但就是做了。

她举起手敲了三下门框。

林牧转过身来。他穿着件深灰色的棉布衫，头发散在肩上，没有扎起来。脸色比前天好一些——但还是偏白。右手上的绷带拆了，虎口上留下了一道暗红色的新疤。他看到是她，眼神顿了一下，然后站了起来。

"进来坐。"

和上次一样的话。同样的三个字。但她听出不一样了。上次是"进来坐"——疲惫的、防御的。这次是"进来坐"——温和的、放轻了的。

她把桂花糕放在桌上。这次不是一盒——是两盒。她放完之后没有坐。站在桌边，打量了一下屋子。

还是什么都不变。木板床，旧木桌，两把藤编椅，一个水壶，一个窗台，一只猫。墙上一张照片都没有。连日历都不挂。角落里的书架上放着几本旧书——都是普通的线装书，《道德经》《庄子》《抱朴子》和一些看起来翻了很多遍的医理书。书的封皮磨得没有字迹了，但书脊用透明胶粘得很规矩。

"连个电视都没有。三十年——你不闷吗？"

"听茶壶的声音就够了。不听别的。"

她笑了。很少的弧度。但确实是笑了。然后在藤编椅上坐下。他坐在对面。

中间隔着两盒桂花糕和一壶热茶——他新烧的。

她拿起茶壶倒茶。动作自然而然地就做了——就像她是在自己家里，而他是个上门来的客人。等倒完两杯她才停了一下——这是他家，怎么变成她倒茶了？

"茶不错。"他端起杯杯。"今年的明前茶。"镇里茶庄刚下来的。

"你倒是我家的茶比我还清楚。"

"三十年了。天天喝你们家的茶。"

她沉默了一会儿，端起自己的茶。茶水的温度透过杯壁传到手指上。她吹了吹茶面上浮的茶沫。这个动作做了无数次了。

"林先生。那天在北边——你是怎么——怎么那么快就回来的？我听人说了，兽群来的那天你在千里之外。"

他低下头，看了一会儿手里的杯子。然后抬起眼看着她。

"跑得快。"

她当然不信。但她没有再追问。他不在这个话题上展开，她就知道这个话题不能碰。就像三十年来他每次避开她目光的时候她心里都隐隐知道——有些东西不能碰。

"桂花糕是我新做的。"她把盒子往前推了一下。这个次和上次不一样。上次她带了桂花糕来，放下就走了。这次她没有走的意思。她想说些别的话。

"上次你说好吃。我多做了点。"

林牧打开盒子。桂花糕码得整整齐齐——每一块都是菱形，切口干净利落。桂花酱不是涂在表面的，是裹在米糕里的，掰开之后中间是金黄色的芯。她做东西总是很仔细。三十年前第一次看到她择菜他就知道——这个人的手做什么都仔细。

"你手很巧。"

林秀芝看了他一眼。这个评价来得很突然，不太像他的说话风格。她把手收回了腿上。然后忽然又把手放回到桌上。

"林先生。我有话想跟你说。"

他说"你说"。声音很稳。

"你之前——在搬到青溪镇来之前——是做什么的？"

问题来了。三十年前她从来没问过。搬过来那一年她只是问过他一句"打哪儿来"，他说"北方"，她没再往深问。那个年代从别处来的人很多，没人追究底细。但今天不一样——今天她必须问。因为关于这个人的身世，镇上已经有了各种版本：有人说他是隐世的仙人，有人说他是退役军官，有人说他是某种"前世的修行者"。

不管哪个版本，都解释不了他在这里三十年的原因。

林牧垂下眼睛，很慢地喝了一口茶。

"我从前在很远的地方做过很多事。都不值得提。"

"怎么个不值得法？"

她问得直接。直接到他有些意外。但他没有慌乱——在他的心里，有些东西三百年都没被人翻过，翻不动的。

"就是没什么好说的。读过一些书，练过一些功，见过一些事。最后觉得这个地方好，就留下来了。"

"你在哪里练过——那些东西？"

她说的"那些东西"是指那天他击倒妖兽的那一下。这个镇上的人都在私下里讨论那一下是什么。有人说那是道术。有人说那是内功。没人知道那到底是什么——因为他们根本没看见他怎么出手。他们只看到了结果：林牧的一根手指点向了那只妖兽的眉心，而妖兽直接消散了。那不是淬体能做到的。不是普通人能做到的。

林牧放低茶杯。他的目光从她脸上经过——很快地——移到了窗外。窗外没有什么特别的。只是一排旧骑楼的屋檐顶，檐角上的风铃在风里晃。

"我小时候遇过一个老人。他教过我一些——修行的事。不是正经修仙。就是些很基础的东西。在灵气复苏之后，那些东西刚好能用。"

他编得不错。不是第一次编这个谎。三十年前，刚到青溪镇的时候他就在心里编好了这个故事的完整框架。但这是他第一次对她说这个谎。

她觉得这个话听着很像真的。但又总觉得哪里少了一截。

"那个老人呢？"

"走了。"他说。"很早以前就——走了。"

他说的"走了"是指"轮回去了"。

她说的是"走了"是指"去世了"。

两个"走了"最后落在同一个意义上。她表情忽然变得柔软了一点。"所以你一个人很多年了？"

他没有立刻回答。他把双手十字交叉搁在桌子边缘。那个动作有点不自觉地收着自己的含意——像是把一个突然涌进胸腔的东西往里按了一下。

"很长。很长很长。"

她把手从桌沿放下来，落在自己的膝盖上。手指自然垂着。她想再说点什么安慰的话，但脑子里转了几转都没转出来。面对这个人，所有常规的安慰都是不合适的——他好像什么都能自己做，什么都不需要。他甚至可以把"孤独"都打理得整整齐齐。

但她已经来到他的屋子，她已经坐下喝茶了，她已经把桂花糕递到了他面前。她觉得自己不该就这么走。

"林先生。以后逢年过节——你到我家里来吃饭吧。"

他动了一下。非常轻微——肩膀从放松变为稍微前倾。不是拒绝的姿势，是收住的姿势。

"不用了。你们一家人过节——我在旁边不合适。"

"为什么？我跟老张说了，老张说行。小辉也说行。"她说了三个名字——丈夫、儿子、她自己——都很坦荡地说出来了。

他看她的坦荡。她的坦荡里没有暧昧——就是纯粹地想帮助一个孤独的人。那一瞬间，林牧心里翻上来的不是感动。是疼。因为她的"坦荡"说明了她对这个邻居的感觉仅仅是"好邻居"。任何一点特殊的感情都不存在。这倒也可以——这正是他需要的结果。

"好。"他最后答应得简短。"年节的时候我过去。"

她站起来准备走了。"那中秋的时候过来。我做桂花糕——不是这种。用芝麻馅的。你会喜欢。"

"好。"

她走的时候帮他把桌子上的茶壶重新倒满了。然后推门离开。

门关上的声音很轻。和上次一样。但这次她不是一个人走——她回头看了一眼茶馆。其实也看不到什么了——只能看到窗里一盏孤灯。

他还在那个窗口。

她忽然在台阶下站了一下。她意识到了一件事。刚才从进门到离开大概有两刻钟。整个过程中，他一次也没有提到自己。没有提到任何属于自己的过去、家乡、喜好、生日。连"最喜欢的茶"这个问题都回避了。他把所有能谈的东西全谈在她的生活里——她的茶庄、她的家庭、她的桂花糕。

他像一个影子一样安静地绕在她的生活外围。给人足够的温暖，但从不让光找到自己。

林秀芝的脚步停顿了。她站在路中央，有风从青石板路吹过来，把檐角的风铃吹得一串轻响。

她忽然把手放到胸口。平安扣不在——她今天没戴。但她记得那个位置。那里还是温的。

一个念头从她脑海里划过。轻微。但清晰。

他说"跑得快"是因为不想告诉我真正的原因。他说"小时候有个老人教过我"是说不通的事情的——因为真话不是这样的。他在藏一个很大的东西。那个东西足以改变这个小镇上的所有事情。

但那个东西到底是什么？

她不知道。她只是觉得——觉得自己漏了什么很重要的东西。

而漏掉的那个东西一直都在。在她的生命里。在他的眼睛里。在这三十年的每一天里。

她回家了。进了门之后在堂屋里坐了很久，一直到老张出来倒水。

"怎么了？"

"没事。"

"他的伤好了？"

"好一些了。还在养。"

"好。"

老张把搪瓷缸放在她旁边，水是热的。他说："茶铺的事你不用操心。后山的新茶园我一个人去就行。你多休息。"

他没有问他们的谈话内容。三十年的老张——他很沉。

林秀芝在夜里关了铺面的木门。她上楼梯的时候眼尾扫到窗外的月亮。月光从格窗的空格子落进来，在地板上划出一个个菱形。

她忽然想起来。林牧那间茶馆的地板上，也有很多这样的菱形。三十年来，那个男人大概每一个有月亮的晚上都坐在那样的光斑里喝一杯白水，听一条鱼的泡泡声，看一只猫在窗台上睡觉。

然后一天过去。然后再一天。然后三十年。

她在楼梯上停了一下。她觉得——为某人独自数了三十年月光——这个念头让她的心脏多跳了一拍。

她不敢往深了想。因为她不敢确认某件事。因为她不敢把自己的直觉和他的孤独对上号。

她只是默默地在上了楼之后去衣柜里找出了那条青玉平安扣。擦干净。系好绳子。重新挂回脖子上。

然后躺下了来。很久没有睡着。

# 章节题诗策略

## 固定规则

- 每章题诗全部自创，不引用现代诗原文。
- 长度建议5-12行；第一卷可更接近现代短诗，后期逐步接近箴言、证明、祷词和长诗。
- 题诗必须概括本章情绪、物理层级或伏笔，不做装饰性抒情。
- 题诗中的核心意象应进入正文场景，避免题诗与正文分离。

## 分卷风格

1. 第一卷：冷白描现代短诗、黑雨意象、父女低语、技术挽歌。
2. 第二卷：量子意象、概率祷词、递归短章。
3. 第三卷：时间回环、悖论自问、历史灰烬。
4. 第四卷：几何咒语、拓扑祷词、他者合唱。
5. 第五卷：宇宙身体诗、孤独箴言、眷恋残片。
6. 第六卷：创世宣言、规则证明、轮回公式。
7. 第七卷：无有长诗、种子祷词、首尾回声。

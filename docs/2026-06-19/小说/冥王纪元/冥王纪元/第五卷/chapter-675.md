# 第675章 番外：地球在新纪元诞生第一天的景象

新纪元第一天——希望纪元元年元日——地球是旧纪元所有被太初完整保留并转入新宇宙的母星之一。它被从旧太阳系精确坐标上整颗提出来，在创世的第二阶段末尾安全置入了新宇宙的普适适居带——绕一颗大小、光谱类型和旧太阳几乎一模一样的恒星公转。新太阳也是由太初按照旧太阳稳定光谱参数重建的——不是为了还原，是为了让所有习惯日地生态环境的物种不用重新进化一次呼吸的节奏。

地球在这第一天清晨——太阳升起来了。华北平原上那片苞米地已经被全部翻过一新——土质柔暖，土壤毛细孔均匀，地下水位和矿质含量恰好和老地一样。田埂位置都没变——那条村口土路仍在原位——老槐树也站在原处——树冠完好，枝尖还挂着冬日未化完的白霜。

第一个醒来的旧纪元地球人类不是李长生——是村口小卖部老板。他在零点时刻被太初认定为"完成了自己"——他的人生没有修行、没有战斗、没有跨越星系。但他每一天从不短斤少两，每一张欠条到了说好的日子就必定清还，附近几个村子几百号人没有一个人没从他手里赊过日用品——他的账本从没漏过一笔。太初收了他，保留了他在新纪元第一天照样坐在同一位置把推帘掀起来——他看见外面的田。田和从前几乎一样——但他知道不是同一天的事了。

没多久第二个人也醒来了——一位住在隔壁乡镇的老太太——她什么也不信神——只是年去到了任何一个庙都会带一把新种子放在院角——种到收，收了再种。她是被太阳暖醒的——起来看了窗外——说了句:"哦——还是好天气。"——照常去灶口拨灶灰添柴。

然后更多旧纪元被收纳的普通人陆续在新纪元第一天的不同钟点数中醒来。没有人哭着喊着——也没有人到处奔跑着找旧世界剩下的东西。大家只是静静地推开门——看到和以前几乎一模一样的景色——只是空气更清、天更蓝、阳光更柔。有人提水桶去打水——井水还是老井味——水质参数被复制得极其精准。

村口那个小孩子们常聚的垃圾空地边上——新世代第一批新生儿在当天下午出世——他们哭的声音和新地球第一缕来自新太阳的金光差不多同时出现——那光很暖和——贴着他们的胎毛。李长生从苞米地那边往村口走了半截——站在老槐树下——看着新地球上的第一批新孩子——皮肤粉粉的细得很——哭完了一响——接着对着天空打了一个小闷闷的呵欠——然后小拳拳胡乱抓住身边陈霜的一片袖子——粘在上面。

陈霜看着那只小拳头——没说什么——只是微微偏了一下头——她的头发被婴儿抓住了一小缕——她不挣脱——站着任他攥。李长生在树下蹲了一阵子——没说话。老槐树的树枝上那层霜慢慢化了——水珠掉在刚翻过的土上——无声——但是浸了下去。

希望纪元第一天傍晚——新太阳落地——把华北平原染成一片深浅橙——和旧纪元一年里深秋的黄昏完全一样。村口小卖部老板亮起了第一盏灯——那盏灯是旧纪元同盏——里面还留的是原来那个旧灯泡——一样发微微橘黄——一样顺眼。

（第675章完）

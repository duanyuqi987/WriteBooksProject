# 第六百三十三章 十境通解

第三天的夜晚，林牧读完了第二卷的全部内容。

"十境通解"的作者——佚名——在卷末附了一篇极短的跋。字迹和前文不同，比正文更潦草、更急切，像是在生命终结前的最后一段时间里赶出来的。

"余著此书，历三百载。三百年间，余游于十境——第一境相濡以沫，余与彼在荒村共饥共寒，彼以体温暖我冻足。第二境相敬如宾，彼为邻家女，余为耕者，每日相见不过三语——然三语之中俱是尊重。第三境相爱相杀——此境最难。彼为敌将麾下谋士，余为吾军前锋。战场交手二十三合，彼之剑指余心口，余之箭对彼眉心——双双未发。第四境相依为命——绝境之中互为唯一依靠，其余皆可舍弃。第五境相互扶持——并肩作战，补己之短，扬彼之长。第六境相互理解——不听其言亦知其意，不察其面亦览其心。第七境相互包容——恕其过，纳其缺，知其罪犹伴其侧。第八境相互支持——欲其成胜于己成，退其身以成其人。第九境相互信任——信其所为不问其由，交其所行不疑其果。第十境相互尊重——尚未至也。然余已知其名。待百世尽时，彼将自由，余亦自由。契约终了，非分离也——乃互视良久，而后曰：'吾已知汝全部面相，仍爱。'"

林牧把这则跋读了三遍。读到第三遍的时候，他忽然想起自己在前世——那个还没有堕天的青云宗天才修士——也曾经有过类似的感悟。他在突破真仙的最后一道心理关口时，在识海深处听到过一句话："你不是要用力量护住她——你要用全部看到她的面相之后，仍然爱她。"当时他把这句话当成幻听忽略了。现在他明白那不是幻听——是契约的原初印记在他的神识深处留的信息。他用了上万年才听懂。

苏晚坐在他旁边。今天她没有去后山修炼——她说她要陪他读完。她昨晚又只睡了不到两个时辰，但精神出奇地好。她把古卷上关于"第七境——相互包容"的那一段抄在了自己的笔记本上。

"第七境的原文——你听听——"她念道："'相互包容者，非忍也。忍则积怨，积久必裂。包容乃纳人之缺为己身所属，视其过如视己过。彼有过，余不怒——而问：过从何来？源既寻得，则可正之。证而不责，正而不弃。是谓包容。'"

她停下来，看着林牧。"这段话跟你那天在桂花树下对我说的一模一样——你说'说是你任性、冲动、破坏东西——那是贴标签。要找原因'。你在不知道这段话的情况下，说出了和它最核心的概括完全一致的话。"

"我不是独立悟出来的——是你在教。你在用你的行为展示'寻源而不责'是什么意思。比如你砸石窟之后用自己的方式在修复。比如你今天用左手递碗给石头。你不需要说——你的一举一动都在做'寻源正之'。"

苏晚把笔从笔记本上收起来。她低头看书页上自己的笔迹——"寻源正之"四个字被她写了两遍。第一遍笔画太轻，看不清。第二遍太用力，纸背面透出了墨。但现在不是追求书法的时候。

"那我们现在的进度——"她翻到古卷的中间某页。"这个作者在第七境用了十四世。前十二世都在做同一件事——学着不发火。但改不了。改不了的原因是他一直在用'压制'来试图消灭自己的火——跟你以前用'无情道'压情绪一样。第十三世——他遇到了一个改变：他把'试着不发火'换成了'在觉得要发火之前先向外走五步，然后问对方：你刚才说那句话是想告诉我什么？'——改变了策略。从压制改成理解。从理解学会包容。第十四世才彻底修完了第七境。"

"我们现在是第十世——在第七境里。我们在古卷作者进度的前面。因为我们这一世确实不是在心性上白过——我们在冷战那几天互相解剖了自己、主动改变了自己对待对方的方式。你学会数到十。我在手上写'陪'字。我们的方法在古卷理论的位置是——第十三世末。我们已经到达了古卷作者在最有效的阶段才获得的认知。"

苏晚用手指在古卷的字上轻轻划过。"所以这一世我们修第七境的速度很快——比预估快。理论上是第百世，却对应着古卷作者在第十三世才达到的理解深度。也许我们的进度是——还有几十世的积累在我们灵魂里帮我们速成。"

"是因为我们每一世都真实在学——从来没有跳过。我们每一世都在认真对待每一个身份、每一个关系形态。没有在偷工减料。所以到了这一世，前面积累的惯性加速了我们的进度。"

窗外的雪已经停了好一阵，月光从云缝里漏出来，照在院子里的雪地上。桂花园修仙学院的后院空无一人——石头已经被张道玄接到龙虎山参加冬令营。那口灶台上的粥锅还闷着——苏晚走的时候跟杜散修的妻子说，如果有人来，灶台不要冷。现在那锅粥正被一个刚送完信、路过此地躲雪的散修端在手里喝着。

古卷的跋后面还有一小段字——是用毛笔蘸了更淡的墨写的，字比前面更细小，像是注释：

"第八境相互支持——第九境相互信任——此两境余仅在推演中略窥门径，未能亲证。然余从第七境出来后体悟到：继续往前走——需先将'改对方'的愿望彻底放手。非改之——乃信之。信对方自能完成其境，信对方之灵魂有其独立的航向。第八境乃'支持对方而非指引对方'——此为余毕生未卒之憾。望后来者，不致此憾。"

苏晚抬头看林牧。"你刚才看到这句话了吗？他说他毕生没到达第八境——支持而不是指引。你……"

"我在分析图那件事上学到了。"林牧的声音尽量平稳。"我图面上写'引导经脉'——其实是想'指挥你的恢复路线'。后来你把我说的那些话——'我只需要陪伴，不需要解决方案'——我其实记在自己便签最上面了。我现在每天早起第一件事是默念三遍：'今天我只能陪。不能指挥。'"

"能坚持多久？"

"不知道——也许过几天就打回原形。但至少今天做到了。你说的我今天应该在这里跟你一起读古卷——我没有'自己先读完然后总结出结论给你'。我是一页一页跟你一起看。一字一字跟你一起读。"

苏晚忽然把古卷合上。她不是一个以时常哭出名的人——但这一世她已经哭了好几次。一开始是因为他说重话，后来是因为发现他分析图的冰冷，再后来是因为看到他在笔记里写"我怕她不要我了"。每一次哭都有不同的原因。但今晚她哭不是因为痛——是因为心里有一个极其古老、极其深刻的疑问，终于有了答案。

"我一直想知道——"她的声音湿了。"我为什么会爱你这么久。不是六十年、不是六百年——是一百世。从上古到现在。每次轮回结束我都会重新找到你——就算我没有记忆，我也能在一座几万人的城里闻出你御剑时留在空气中的那道灵力残余的特殊频率。我从前以为这是执念——怕自己陷在一种不理性的强迫循环里。但今天读到这一页——我才发现：不是执念。是我在完成一门课。每一世我都在学习一种新的爱的方式。而你也同样。这门课的终点不是'永远在一起'——是'你看透了我的全貌，仍然选择留下'。而我们已经走了百分之九十九的路。只差最后一境。这不是执念。这是使命。"

林牧没有用语言回答她。他从书桌对面站起来，走到她身边，蹲下去——不是抱她，是把她的手拿起来，掌心覆在自己眼睛上。她的手指很凉，他的眼睛很热。一冷一热之间的温度，刚好是"百世契约"在中途教给他们的唯一重要的东西——"在对方最热的地方温和地降温，在最冷的地方温和地加热。不是消灭温度差——是用共处的方式去平衡"。

书房里很安静。窗外月亮已经爬到了桂花树的上方。桌上的古卷摊开着，夜明珠的冷白色柔光打在那张"十境螺旋图"上——第十个弧段被月光反射出了微微的金色。

（第六百三十三章 完）

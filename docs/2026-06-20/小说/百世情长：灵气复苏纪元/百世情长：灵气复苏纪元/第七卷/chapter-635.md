# 第六百三十五章 双双突破

春分那天，苏晚在林牧的护法下冲击炼虚后期。

她原本没打算这么快——她知道自己的任脉刚被魔气共用试验消耗过，还没有完全恢复。但林牧告诉她没有必要等完全恢复。他的逻辑是："你的任脉被消耗过——不能承受全额冲击力——但我可以帮你分担一部分。分担下来的量刚好低于你剩余承受力的上限。所以你不必等完全恢复——因为一定比例的分担可以让你的'恢复期'和'突破期'部分重叠。这是效率问题，不是逞强。"

以前林牧绝对不会建议她在不完美状态下突破。以前的他觉得：冲击关口前应该把所有条件调节到最佳状态——经脉要满，灵力要足，心态要稳，而且环境要万无一失。但现在他变了。不是变得马虎了——是变得现实了。他不再追求"完美条件"。他理解了：每个人都有缺陷、有恢复期残留、有历史旧伤——如果能把这个'不完美'的状态当成突破的起点，就能在承担可控风险的情况下获得比'等到完美时再出发'更快的进步速度。

苏晚在清晨的修炼室里闭关——和林牧上次突破时是同一个蒲团、同一个崖壁位置。林牧这次不只是替她分担冲击力——他还替她做了一个推演分析：她的任脉恢复期还需要两周才能到百分之百，但如果冲击的灵压不是一次性上去，而是分三个阶段逐级爬升，她目前百分之八十三的任脉承受力完全够用。他用便签纸把这个分析画成了三阶段曲线图，用黄色的便签贴在她的膝盖上："第一阶段到达门槛的百分之四十——你不需要辅助。第二阶段从百分之四十到百分之七十——我会分担它的百分之三十。第三阶段，最后百分之三十——我会分担百分之五十。你的承受上限没有超过——你的安全到达概率是百分之九十四。"

苏晚看了那张曲线图后笑了——黄纸上的横轴和竖轴之间的线条是林牧的风格，工整得不像手绘。"你把突破变成了概率论。"她说。

"不是概率论——是管理风险。以前我追求百分之百安全——结果是不敢尝试。现在我只需要概率大于临界值就会做。"他停顿了一下。"这个改变——是你教我的。"

苏晚闭上眼睛开始冲击。三个阶段用了将近四个时辰。最危险的第三阶段——她感觉一股巨大的冲力从丹田往上顶，像是有人在她体内爆炸了一个小太阳。但她同时在另一条线路里感觉到林牧从外部渡进来的稳定灵力——不猛，不抢，刚好消掉了一大块她的压力。不是因为他的力量比她大——是因为他的频率跟她完全同步了。这是融合试验带来的副作用——她和林牧的神识在不同频率切换上已经默契到几乎不需要意识指挥了。

春分的阳光穿过修炼室的天窗，照在林牧画给她的那张黄色曲线图上。图上那条陡峭的爬坡线正如预测地到达了最高点。

突破成功。苏晚睁开眼睛。她感到自己的灵力感知范围比以前扩大了将近一倍。她的头发——之前只剩两成黑色的头发——现在全部变成了白色。不是衰老的白，是一种纯粹的、银质的、在光下会反射出浅蓝微光的白。那不是白发——是炼虚后期的灵气彻底激活了她的灵魂印记。百世轮回，头发全白——不是在变老，是在记录历史。

林牧伸手碰了碰她的头发。她的头发手感比以前更软了——像丝绸。他手指穿过发丝的时候，她的头微微向他的方向侧了一下。她没有说话。但他感觉到了——她的修为已经和他持平。两个炼虚后期，在同一个修炼室里，面对面，膝盖几乎碰到一起。

"我们做到了。"苏晚说。

"还没完。"林牧说。"飞升之门才是最后的目标。"

"那下一步呢？"

"下一步——你写书，我画图。写完书之后推广到全修仙界。画完图之后把飞升之门从理论变成工程草案。"

苏晚看着他的眼睛。那双眼睛里不会再出现以前那种冰冷的静了。现在那双眼里的温度和她白发上的浅蓝微光一样——是经过漫长的时间沉淀后自然生成的暖色。

（第六百三十五章 完）

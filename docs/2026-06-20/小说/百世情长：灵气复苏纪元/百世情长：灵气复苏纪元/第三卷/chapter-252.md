# 第252章 仙界的初见

踏入仙界的第一脚——苏晚踩到的是云。

不是凡间那种空心的、踩上去会散的水雾云——仙界的云是实心的。踩上去的质感既有云絮的柔软又有地面砖的坚实感，就像走在无限大的棉花糖上。她低头看了很久——然后像小孩一样故意跳了一下——结果被弹起来大概一尺——然后稳稳落下。她在凡间打过一百年的铁、砍过三百头妖犬、挡过金丹修士的掌心雷——但此刻她就像一个第一次进游乐园的女生一样眼睛亮晶晶。

林牧在旁边看着她跳起来——他笑了起来。是真笑——不是以前那种只嘴角微微一抬的战术微笑——是完全忍不住的、露出不太整齐的后槽牙的那种大笑。他笑了苏晚没停——他笑了很久——因为他这辈子第一次看到苏晚在她绝对安全的地方——没有战斗，没有误解，没有战场，没有转世——只是纯粹高兴地在云上蹦。

"你别笑——"她拍他的手背——"你当年第一次回仙界的时候也是这个样子吗？"

"不是。"他把自己从前真仙的回忆翻出来:"我那时候从天坠下——方向相反——不是跳上去——是掉下去。掉下去的感觉不好——云不接你——只有风——风割脸——然后地很硬。"他说得轻描淡写，但苏晚不跳了。她站在他面前——把他的手放在自己左胸膛上——让他感觉到他灵线另一端她的心跳依然在为他的坠落而悸动。"那以后你就不会再掉下去了——我在这——云上站得稳——抓着你。"

他收下她的手。仙界的第一口空气——吸进去是清凉而微甜的——和果露有点像但更透更稀。两人在仙界接引台站了片刻——然后一位仙使出现了。仙使看着他们——核对了一下卷轴，确认了身份——然后在仙册上填写了以下信息:"双修真仙——苏晚、林牧——登记完毕。配予东元仙岛区域——岛名:晚牧居——永久归居。岛权及仙职待后另行分配——先在仙岛安居。"

"晚牧居"——这岛名是仙界自动合成的——用他们名字各取一字拼成。她听到这个名字时怔了一下——然后转身对着林牧:"晚牧居——我晚，你牧——晚牧——比任何诗都好听。"

他问:"跟青云宗比？"

"比青云宗好——青云宗是我们的过去——晚牧居是我们的以后。"

东元仙岛的位置在仙界东部的一片漂浮群岛上空——那是一片巨大到肉眼看不到边的高层云海——稀稀疏疏地散着一些被瀑流灵雾环绕的悬浮小岛。晚牧居——从远处看是一块形似没有完全收角的手帕的小浮岛，面积大概相当于凡间一个中型庄园——岛上有山泉、几株仙果树、一个天然形成的独栋双层小木楼——木楼的阳台正好面向东方——看日出。

他们在岛上发现这岛之前是空置的——但里面的布置却像是专门为两个人准备的：双层小楼里一层是茶室和炼剑室——二层是起居室。茶室的架子上摆着两套茶具——一套素褐色（和林牧在秦岭执勤站用的那套几乎相同），一套淡金色釉的（和苏晚第四世在赤霄宗用青瓷杯冲茶的质感一样）。炼剑室里墙上有两个并排的剑挂——空的——在等他们的剑。起居室床铺上整齐叠着两条薄被——一席灰、一席淡金色的，各跟对方的衣袍色调呼应。

苏晚把凡铁剑挂在靠左的剑挂上——在剑下面他在墙上用指尖划了一个"晚"字——林牧把他窄身剑挂在右边的剑挂上一并在下面划了"牧"——对着写完后两人退后几步——让两柄剑并排——然后晚牧居里第一缕属于他们自己的仙火从茶室灯座中自动点燃——金色的火——和丹火同温。

之后他们开始正常生活在仙界。晚上的仙界夜空中不是只有东方那一个是"乙火"星——而是整个苍穹都密密麻麻——其中有一颗极亮的巨型光点形成一颗巨大的恒星是仙界的正中央核心——白谪（在之后报道中提到）说那个核心的名字叫"天宗炽曜"。苏晚每天晚上坐在晚牧居的阳台上看星空——林牧坐她旁边——这是第一次没有"接下来还有下一世"的倒计时，她看着那颗核心星体突然靠过来说:"从今晚开始——我每晚数一颗星星——把我们两千多年的时间在星图上走一圈。如果有外宇宙的通道——我们就一起走到头。"林牧闻着她头发上仙果树的淡香——把他攥在袖口翻卷多年的银戒指小心地放在她手心——"这戒指——从第一世放到现在已年代久远——天上不收旧银——要卖也该卖给我最想搭配的人——你收了吧。"

她把银戒指放在心口——和仙金婚戒一并——两颗星交汇在一条线上。晚牧居的第一夜就这样安静地、柔暖地度过——不留任何伤痕唯有两道人影隔着窗纸似微火般摇曳——一切重担终于卸下。

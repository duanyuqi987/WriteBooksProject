# 第993章 牵手飞升（上）

虚空原点。

渡护合道波动在经历了极深极久的静默后，发生了最后一次变化。不是"醒来"——是"完成"。两道并行的光——渡青与护金——在同一瞬间同时从虚无的最深处升起，不再是之前那种缓慢扩散的柔光。这一次，它们直冲向虚空的最高处——没有目的，没有方向——只是将所有剩余频率一次性释放为完整的光芒。

这道光芒穿过了混沌、穿过了无尽海、穿过了九重天、穿过了太初之城的上空——然后同时出现在上界与下界的天空中。

在下界——太行山顶的银杏广场上空的深蓝夜幕忽然撕开了一道青金色的缝隙。最初的光芒不强——比北极光更淡——然后逐渐亮到把满山遍野的灵灯都盖了过去。广场上正在打坐的数万名学员同时抬起头——他们看到了两道光。青色和金色——从裂缝中同时升起。青色光如低垂的丝绸在夜空流转——金色光如一层温热的阳光在冬夜铺洒。两道光相互缠绕却不相融——像两个人的手指交错地握在一起。

山下的陈念初（陈小楼的不知第几代后人）抬头看着这道光——她记得她家传的祖训中有一句描写："青如晓天，金如长夕。两人化作光上升——不是离开，是把天空变成回家的路。"

她小声地对她身旁的学员说："那是苏师和林师——他们走了最后一个飞升。"

在上界——太初之城上空同样出现了这道青金交错的光。道纪院元枢纪念塔顶部的感应道纹同时全亮。全城仙人不约而同地抬头——没有人说话。光在上界的天穹中心缓慢地聚集成了一个极淡的人形轮廓——两个人并肩——轮廓边缘模糊到几乎看不清楚——但所有人都感到了同样的信息：那不是神——那是两个把所有的路走完了之后——把门留给后来人——然后手牵手安静离开的普通修者。

轮廓持续了约莫一盏茶的时间——然后极缓慢地消散。不是炸碎——是融入天空。两条光芒在消散的瞬间留下了最后一帧画面：两个人手牵着手的形状——定格了一瞬——接着化作无数细密光粒，洒落在上界下界同时飘起的风中。

太初之城的每一个传道堂教室里，在光芒散尽的同时，所有道源第三形态辐射范围内的守护道心在同一秒感到了一阵极轻极暖的震颤——从脚底上升至头顶——不震撼、不压迫——只是轻轻告诉你："该你了。"

# 第548章 陈霜的直觉，指引正确方向

陈霜闭上了眼睛。

整个舰桥的人都在看着她。她的右手从李长生的肩膀上移开，双手握住了霜降剑的剑柄。剑身并未出鞘，但剑灵已经开始嗡鸣——那是一种深入骨髓的低沉震颤，像是万古冰川在融化之前发出的最后一声叹息。

她在感知。

剑修的感知和灵修的感知不同。灵修靠的是灵气——灵识外放，扫描周围空间中的灵气波动、敌人气息、阵法痕迹。而剑修靠的是剑心——剑心不是外放的，它是向内的。向内深到极致之后，它会穿透自我与外界的边界，与整个宇宙融为一体。剑修不是用灵识去看世界，而是让自己变成世界的一部分，然后从内部感受世界的每一下心跳。

在第三平行宇宙中，这种感知方式恰好是最有效的。

因为时间在扭曲、空间在变形，任何从外部投射出去的灵识都会被撕扯、被延迟、被反射。但剑心不同——陈霜不是在"看"这个世界，她是在"成为"这个世界。

三十息后，她睁开了眼睛。

"前方那个存在——"她的声音很平静，但李长生从她的语气里听出了一丝罕见的审慎，"不是敌人。"

"你确定？"刀疤问。

"不是现在的敌人。"陈霜纠正道，"它是活的，但不是现在活着。它的生命跨越了至少四个不同的时间点。其中一个时间点——在我们抵达这里的两个时辰之前——它放出了一道神识扫描了诸天号。如果它想攻击，那时候就可以动手。但它没有。"

"它在观察我们？"小王问。

"不是观察。"陈霜摇了摇头，"是在确认。确认我们是不是某种它期待了很久的东西。"

李长生微微皱眉。"它期待什么？"

陈霜转向李长生，目光与他对视。那双眼睛里没有恐惧，没有犹豫，只有一种透彻的理解。"我不确定。但它的情绪——我能感受到它的情绪。是孤独。非常非常深的孤独。就像一个在沙漠里独自走了很久的人，突然听到了远处传来的驼铃声。"

指挥室里安静下来。

李长生低头看着掌心的冥王令。这件法器在一万两千年前被冥王亲手捏碎，每一块碎片都在黄泉之底浸泡了万年。如果这个世界上还有什么东西比冥王令更古老、更孤独——那大概只有时间本身。

"靠近它。"李长生做出了决定。

"确定吗？"小王的手指已经悬在了武器系统的发射键上。

"如果它想动手，我们早就挨打了。"李长生说，"能在时间旋涡深处存在的东西，不会给我们还手的机会。既然它没有攻击——说明它不是冲着杀我们来的。"

诸天号缓缓推进。

时间暗流在船壳外翻涌，扭曲的星光像万花筒一样变换。船壳上的冥纹光芒越来越亮——这不是李长生主动激活的，而是冥王令在自动感应前方的存在。

陈霜突然伸手指向了右侧。"偏离当前航线。向右十五度。进入那片时间旋涡的外围。"

"时间旋涡？"导航官迟疑了，"那里面——"

"表面是旋涡，核心是稳定的。"陈霜打断了他，"那个存在就藏在旋涡的中心。它用旋涡保护自己。但那不是陷阱——是一种邀请。旋涡中有通道，只有走对了才能不受伤。走错了——"

"走错了会怎样？"老陈问。

"时间会把你撕成碎片。"陈霜平静地说，"每一个碎片掉在不同的时间点上。你的左手可能出现在一万年前，右手出现在一万年后，身体留在现在。但意识——意识会在三个时间点之间被无限拉伸，直到疯掉。"

老陈沉默了一秒。"那还是走对吧。"

陈霜没有再说话。她的剑心已经完全打开，与霜降剑融为一体。在她的感知中，前方那片时间旋涡不再是一团混乱的能量——它是一扇门。门的另一边，有什么东西在等着他们。不是陷阱，不是埋伏。是答案。

诸天号驶入了旋涡外围。

扭曲的时间之力冲击着船壳，冥纹护盾爆发出刺目的暗金色光芒。在那一瞬间，舰桥里的所有人都感觉到了时间在拉扯他们的身体——心脏跳动的频率变了，血液流动的速度变了，甚至思维的节奏都变了。

只有李长生和陈霜保持了正常。

冥气超越时间，剑心贴合时间。

"继续。"陈霜说，"还有三息。"

一息。

二息。

三息。

诸天号穿透了时间旋涡的最后一道屏障。

舷窗外，扭曲的星光骤然消失了。取而代之的是一片无比清晰的星空——星光稳定，空间平直，时间均匀流淌。在这片混沌宇宙中的唯一宁静之地，悬浮着一座巨大的构造体。

那不是人造的建筑。不是天然的星体。

是一棵树的骨架。

它的树干由纯粹的晶体构成，树枝延伸出数千公里，每一根枝条的末端都挂着一颗正在缓慢旋转的星球。那些星球是活的——上面有大气、有海洋、有生命的痕迹。而所有的星球都被某种无形的力量连着树干，像果实一样汲取着养分。

"这是什么？"刀疤的声音发干。

陈霜看着那棵树，眼睛里有什么东西在闪烁。

"生命的根系。"她轻声说，"这是第三平行宇宙的原生存在。它不属于任何帝国，不属于任何文明。它是这片宇宙诞生时一起出现的东西。它在——"

她顿了一下。

"它在等我们。"

舰桥中央，李长生的冥王令爆发出从未有过的强烈光芒。不是战斗的反应，不是预警。是一种共振——像两块分别了一万两千年的碎片，终于找到了彼此。

（第548章完）

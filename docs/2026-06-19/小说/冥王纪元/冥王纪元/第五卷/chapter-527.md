# 第527章 多维战术

小王在主控台前站了整整十二个小时。

他的灵符引擎在全速运转——每秒处理的数据量是帝国日常信息总量的三十倍。但他不是在单打独斗。他面前的全息屏上，是一个由他搭建了三年的战术指挥系统——"八卦阵"。

八卦阵——名字是龟相起的，但核心算法是小王一个人的心血。它的原理不复杂——将帝国所有前线侦察数据、敌舰动向、友军状态、阵法和灵脉消耗速率等等信息全部输入同一个计算框架，然后用一套灵符代码实时分析敌方的战术逻辑，并反向生成最优应对方案。它本质上是把程序员解决复杂系统问题的思维模式——用在了战争指挥上。

"第一通道。万剑王的剑阵转速降低到每分钟一点五转——被冥王令压制。"小王在指挥频道里实时播报，"他目前的战力分布——百分之七十三放在了防守李队上，百分之二十在维持舰队剑阵运转，剩余百分之七是战术灵活性。他的注意力——在被李队持续压缩。"

"压缩的结果是什么？"老陈问。

"他的剑修舰队——现在的攻击力大约是全盛状态的一半。因为他顾不上了。一个仙王被一个帝级巅峰牢牢拖住——他要在防守上花太多剑力，就不能同时指挥舰队有效地进攻。"

老陈盯着沙盘。剑修舰队的推进速度已经降到了远远低于初始推进的状态——因为戒律阵列被许冰重新编译后第二次激活了。而这一次，万剑王已经没有余力再用剑意切削——他的全部剑力都在跟李长生对拼。

"所有人听令。"老陈按下总指挥开关，他的声音同时传入了前线每一艘舰的通讯系统。"从即刻起——不守了。所有舰队转入反击。目标：切割剑修舰队——把它从一个大剑阵切成十个小剑阵。分别包围——分别歼灭。"

前线舰队发出了一阵整齐划一的确认声。那是被压制了六个小时之后的那种爆发——所有蹲在防御阵后的帝国修士此刻都站起来了。

转守为攻。

小王在八卦阵分析引擎上得到了一个意外的发现。一个关于剑修舰队结构弱点的意外。

"剑修舰队的剑阵旋转中心是万剑台，剑台是整支舰队的控制核心。但万剑台的能量来源——不是万剑王本人，而是那三十六根剑碑。"小王快速调出了戒律阵列在第二轮激活时获得的敌方内部通讯数据——许冰的戒律虽然在剑意切削下崩溃了，但在崩溃前勉强截获了一些信号。"剑碑在持续吸收周围阵亡剑修的能量——每一艘剑修舰被我们击毁——舰上的原有机载剑气会飘往万剑台，被剑碑吸收。然后剑碑把这些剑气重新分配给剩余舰艇。"

"所以——剑碑相当于一个能量循环的中转站。"

"对。只要让剑碑的吸纳饱和——或者说，让剑碑的承载上限被打破，剑碑爆了——整个剑修舰队的能量循环系统就崩溃了。"

"怎么能让剑碑饱和？"老陈问。他的眼神变了——看到了战术机会。

"打掉更多的剑修舰。"小王的声音冷了下来——这是他在提供战术方案时特有的语气，客观、数字化、不掺杂任何个人情感，"每摧毁一艘剑修舰——就会有一份剑气被吸入剑碑。摧毁得越多——剑碑吸纳得越多。吸纳到一定程度——剑碑的承载上限被突破——就炸。"

"也就是说——之前我们打掉的一百多艘剑修舰，不光消耗了他们的战力，还在给剑碑加负载。"

"对。而且现在李队正在砍剑碑——他在物理层面破坏剑碑结构。如果物理破坏和过载同时发生——"

"剑碑会炸得更快。"

"是。"小王将计算结果投射到了战场沙盘上，"按目前剑修舰队的歼敌速度——如果我们在接下来两个时辰内再集中打击掉至少三千艘剑修舰，剑碑的过载风险会从当前的百分之二十涨到百分之七十。再加上李队直接砍剑碑的物理破坏——成功率不小。"

老陈用力拍了一下指挥台。"所有人听令——改变目标优先级。不打剑修舰的动力核心了。打——舰上的修士。优先消灭舰上修士。"

"为什么打人？"通讯频道里有人问。

"因为剑碑吸收的是剑气——不是舰体。"老陈解释，"舰毁人亡——修士的剑气自动飞回剑碑。但如果舰上修士在舰毁之前就被击伤或击晕——剑气会滞留在修士体内，不飞回剑碑。这时候再击毁那艘舰——剑碑收不到剑气。"

小王在心里给老陈竖起了一根大拇指。这就是老陈——不需要懂灵法引擎代码，但他一眼就能看出战术上的核心逻辑。快递出身的将军，打了九年仗，对怎么打架有一种骨子里的直觉。

战术调整在数分钟内生效。前线舰队不再把灵石主炮对准舰体——而是对准了舰桥。击中舰桥可以最大化伤害里面的修士。同时刀疤亲率禁卫军特种小队——穿着体修专用的深度透甲装备，直接登上敌方孤立舰艇——进去里面打修士。打完就撤，不恋战。

战场节奏开始翻转。

剑修舰队的伤员数量急剧上升——每一艘被"清修"的剑修舰上都飘出了大量的被迫弃舰者。他们弃舰时带走了自己的剑气和剑意——万剑台剑碑吸纳的新剑气流量在这一小时内下降了约四成。

万剑王在跟李长生拼杀的过程中感觉到了这种变化。他的剑力正在慢慢减弱——不是他自己弱了，而是从舰队反馈给他的补充剑气正在减少。

"你——在动我的根基。"他说。

李长生一刀逼退他半步。"你以为我们只会跟你对砍？"

万剑王环顾战场。他看到他的剑修舰队——八十万艘曾如巨浪般的剑修舰队——正在被帝国的防御阵型从外向内一点一点地咬碎。帝国的打法不是正面对拼——是拆解。拆一艘就废一艘。他的舰队被分割成了六个小包围圈，每个包围圈中都有数倍于被围舰艇的帝国舰队在集中火力。这不是数量碾压——是战术碾压。

他长吸一口气。他知道自己得做选择。

是继续跟李长生对拼，还是回头救舰队。

李长生看着他。他在等他做这个选择。

（第527章完）

# 第650章 太初的目光

从维度感知实验中退出来之后，李长生感觉到了一种从未有过的体验。

被注视。

不是被人注视——被人在后脑勺上盯着看的感觉每个人都经历过，那是低层级意识体之间的微弱感知互动。他现在正在经历的注视比那种感觉强烈千万倍——不是"有人在看我"，而是"我正在被'看'这个行为本身包围着"。就好像空气忽然变成了一只眼睛——不是眼睛里长出了什么可怕的东西——是空气本质变成了观看的行为。他每一次呼吸吸进去的不是氧气——是太初对他的感知。他每一次呼出来的不是二氧化碳——是他对太初的本能回应。

这不是压迫感。压迫感是有人用更大的力把你往下压。太初的注视没有用力——它只是在"看"。但它的"看"是一种实际存在的能量。在纯混沌级别的感知下，他能明确地感到每一道目光落到他身上的位置——先是眉心意志凝聚点的位置，然后是右手掌心四块碎片联合枢纽的位置，然后在心脏部位——陈霜习惯性用手按的那个位置。太初在看这三个点——不是在检查他有没有危险——是在"认"。像一个相识的人从远处走过来时，先是看脸确认——然后看手——然后看他的动作中心——全部确认后：是他。

太初在确认他是新的混沌之主。不是力量层面的确认——太初不看力量。太初看的是传承——旧混沌之主的残魂是否自愿交班。如果太初检测到新混沌之主的混沌是从旧混沌之主那里"抢"来的——它的反应会完全不同。不是杀——但会不对话。

李长生在舱室里跟小王通讯说需要一个单独的房间。小王给了他一个临时的空舱——原本是仓库。他进去，关门，在黑暗中独坐下来。

黑暗对他的视力没有影响——他能看见任何东西。但他需要黑暗作为减少外界干扰的方式——要全神贯注地处理好现在发生在自己身上的这件大事：他正在被太初注视——如果要回应——是让他安全地回应——什么时候回应——怎么回应。

他先把混沌之主留下的关于太初的全部经验重新调出来。在第四碎片最后的传承中，混沌之主给了他一段关于"如何面对太初的目光"的具体操作指引。不是长篇大论——就三句。第一句：不要躲避——太初的注视越是被故意避免就越久——它要看懂你为什么不敢被看。第二句：不要对抗——你用任何意志力去推挤太初的目光都会被它理解为你不愿意被它理解——它会反复看直到你放弃抵抗。第三句：什么也不做——让它的注视透过你全部存在——像光透过透明的玻璃——不需要产生任何防御反应——也不需要迎合。

李长生按照这三句话做了。他把全身的防御主动关掉——不是撤掉混沌屏障——是把自己意志中的"抗拒被看"这部分主动释放了。然后他安静地坐在地上——两手摊开放在膝盖上——没有隐藏右侧——没有低头。他整个人像一块被太阳晒着的石头——没有任何抵抗、没有任何遮掩。太初的目光从他身上透过去——穿过了眉心、穿过了右手、穿过了心口——通彻地照亮了他体内的全部存在结构：混沌通道四十七万条、意志凝聚点一个、冥王令印模、太初的通讯开口一个。全部在目光下被看完了。

看完之后——太初的目光撤了。

不是消失——是退到了"常温"。之前它的目光是灌注式的——把存在压缩进被观察者的每一个细胞核。现在它退到了低强度的日常状态——就像从"盯着看"退回到"余光关注"。但余光也还在。太初不会离开——太初的视线是它自己的常态。李长生现在被列入"持续观测名单"——他自己知道这一点。

他站起来推开舱门。走廊很暗——他不往上睡觉——不睡——径直穿过走廊走到舰桥。陈霜仍在那扇舷窗前面——外面已经能看到地球圆廓——以及悬在地球上方的月球基地。他们快到国际地月领空了。

陈霜看到他走出来。她不问他有没有准备好。她看着他的眼睛——然后转向窗外。她的右手不自觉地在剑鞘上一抹——不是拔剑——是在确认剑鞘还在那儿。

"它还在看你吗？"她问。

"在。但它从'盯着'变成'带着余光'了。"

"感觉如何？"

李长生坐到旁边的椅子上——两人并肩地看着窗外渐渐变大的蓝色星球。

"就像——"他想了一会儿，"——就好像有一个比你年长了好几千亿倍的老人，在看着你在田里干活。他不帮你——但他在看你怎么把这一亩地犁完。"

"你觉得它满意吗？"

"不知道。"李长生站起来。他再次看了一眼自己的右手掌心——四块碎片纹路安静地在微光中呼吸。"但我犁地的习惯不是为了让谁满意——是我自己。从前是——现在也是。"

陈霜笑了。极轻地——但确实是笑了。她很少这样。

地球在外窗上缓缓旋转——上面总共有七十亿人。今晚他们中的七十亿全都不知道自己这宇宙正在被太初注视——也不知道一个种地出身的人刚刚把宇宙最后的轮回入口把住了。

（第650章完）

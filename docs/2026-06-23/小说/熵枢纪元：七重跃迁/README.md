# 《熵枢纪元：七重跃迁》项目资料库索引

作者：段锦佑

## 核心文件

- `project.md`：项目底座、硬规则、角色关系、风格边界。
- `outline.md`：七卷结构、全书主线、当前推进区间。
- `章节总表.md`：章节系统阅读入口，完整明细指向 `chapter-catalog.csv`。
- `project-state.md`：当前调度状态。
- `memory-snapshot.md`：后续正文写作后的近期记忆。

## 资料目录

- `章节/`：章节工作文件占位与前50章状态。
- `细纲/`：第一卷前50章详细分场景大纲。
- `人物/`：角色卡与声纹。
- `伏笔/`：跨卷伏笔追踪。
- `世界观/`：物理环境、科技树、科学硬伤检查。
- `题诗/`：题诗策略与前50章完整自创题诗。
- `高潮/`：七个绝对高潮详细场景大纲。
- `检查清单/`：防跑偏、卷末、章节开写前检查。
- `追踪表/`：Excel可打开的CSV。
- `灵感库/`：后续记录妙语、场景、对话。

## 使用顺序

1. 写正文前先读 `project.md` 与 `outline.md`。
2. 进入具体章节时读 `细纲/chapter-XXXX.md`、相关人物卡、相关伏笔卡。
3. 每章写完后更新追踪表与 `memory-snapshot.md`。
4. 每卷结束前执行 `检查清单/防跑偏检查清单.md`。

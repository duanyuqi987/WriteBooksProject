# 第282章 第五世的饼

锦鲤在整理晚牧居储藏室时翻出了一个已经硬到可以砸核桃的薄饼。这个饼来自于第五世矿道时期——苏晚把第一块饼烤得极硬——林牧第一口吃的时候牙差点崩了——但他没说任何挑剔的话——只是用锤子在饼上敲了一小块下来泡在热水里等它软。这块饼因为太硬而在储物袋里跟那些剑穗待在一起几百年从未变质——也从未被动过。苏晚把那块饼取出来时忍不住笑得直不起腰——"我当年学打饼是从同邻矿区阿姨学的——她教我'面要硬——经得住饿'——我以为经饿的意思是把面烤成比锤柄还硬的状态——要牙齿合着一起用力——就没人敢喊饿——因为打饼本身消耗的热量比饼提供的多——这是无效料理。"

林牧默默表示这饼如果泡软了其实味道并不差——就是极朴素的面味加了点菜干——但味道和第五世那个矿道口早上出日时的空气里夹杂的矿灰微尘、野草霜味和他锤柄上的菌屑都混在一起——变成一种只存在于那时候的复合味。他现在想再吃出那个味道也不可能——因为那个味不止是食物本身——是当时的整个环境在饼里锁着——"所以你第一次把饼放我碗里时的样子——是那年冬天最冷的一夜——你手指甲上还有铁渣——你把饼放完就坐回自己位——低头咬你自己那块比你给我的更硬的那个角——让我觉得你给我的比我好——因为你说'多吃点——你要锤铁'——你那理由总是编得很实用。"

苏晚想把这些硬饼全部还原成可吃的现代版——但林牧建议留一块永不做更不动——因为"它是第五世我们最饿时唯一能做出来的食物——就是硬。保留它——以后如果有人在岛上说什么'完美'——就拿出来给他们看:我们的起步是牙崩饼——没有完美——只有硬——一直硬——然后慢慢被热茶泡软——过程还在——饼还在。"

她同意了——把饼单独放进神龛第五世遗物格里加了个迷你的水晶托盘——托盘里放着他当年用来泡饼的那只旧铁杯——铁杯内壁还残留着饼渣泡软后的痕迹。她在他写五世饼故事的页底补了条备注:"后来我们飞升了——饼还留着——证据:再难吃的东西也会在漫长的等待中被融化成最柔的淀粉和水——然后再次出现在你伴侣当年的铁杯子里——就说明这饼比当时更好吃——是因为牙被练出来了还是因为淀粉真的重新变为糖——不重要——重要的是我们还能在同一张饼上找到两种时态:那时硬——现在软——中间是等和水。"

她写完——把页压好——然后去茶室给林牧泡了一杯他在天上最爱的新收麦茶——麦茶的口感没有饼硬但也并非甜——就是稳厚。她把两世饼的故事分给茶会上新来的年轻道侣听——没有人不被"牙崩饼"逗笑——但笑完之后他们每个人都看着自己道侣手里正在吃的今早还软乎的太麦包——看了很久——大概在想:所有今天还在手心的软和——也许在上辈子是以牙崩饼奠基。

"那如果我们这辈子一切都不难呢？"有一位很年轻的刚飞升男孩问。

林牧回答:"不难更好。但以后某天如果真遇到硬得能崩牙的事情——记住先把饼放在热水里——给它一点时间——软的会回来。"男孩的女友在旁边把他的话记在自己手账里。锦鲤把那条记账的小动作吐成泡在旁边擦过:"连吃饼都整成哲学课——你们真是够了——但确实是我见过的所有哲学课里最好吃的。"

老猫凡间过来的投影在旁边闭着眼——但尾巴又在无意识地轻拍——因为他听到了"热茶——等——再硬也变软"这几个词——那是他早就在青溪镇窗户边、用尾巴打拍子替林牧打过的节奏——耳熟到无法再吐槽——只好再拍。

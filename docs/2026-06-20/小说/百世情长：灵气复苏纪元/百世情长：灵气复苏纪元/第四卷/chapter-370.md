# 第三百七十章 平安就是答案

战后第四十三年。昆仑和蜀山之间修了一条新路——不是给飞行修士用的，是给凡人走的"灵旅道"。沿路种的是林牧那套灵网系统中多余的灵松苗。每棵树之间刚好隔着一箭之地——不是用弓量，是他走在雪地上大约迈三步的跨度。凡人走累了可以在松树底的坐石上歇脚。坐石也是他从山中寻来的——每块石底部都刻着一个失落在战争中的人名。不是纪念碑——就是块石头。

苏晚和他一起走这条路的那天往蜀山方向徒步。她背上的旧药箱这次不是去救人——是用来装沿途从松树上掉下来的松塔。她每走一段就蹲下拾几颗放进箱子。他说：你要松塔干啥？她答：给老铁匠的侄儿过些天的新铺子当装饰。那小伙开了间杂货铺——卖灵松木雕和旧杯翻新器。

"你还顾着这个啊。"

"当然。他叔做的杯子在咱们手里——回他侄一点东西不为过。"

林牧弯腰也帮她拾了几颗——递给她时指背上留下松针划的白痕。她没有去吹——只是接过松塔装好。走到距蜀山大概三里路的地方，风里带着松脂和昆仑雪混合的味道。她说:"如果以后不修炼了。就这么一直走也挺好。"

他答:"修炼就是赶路。休息就是捡松塔。不冲突。"

"你是把修炼也当成IT售后了？"

"对。就是维护系统，顺便捡点散落零件给她。"

"那个'她'是哪位？"

"拿药箱装松塔的那位。"

她轻轻踢了他一下——脚劲很轻，过了不到半息就没了。然后继续一起往蜀山走。背后昆仑在他们渐行渐远的步伐中渐渐模糊为一片白雾——但塔顶那道金光在日暮下依然亮着。像是前四十三年所有磨难后留下的唯一一盏灯塔。照耀的不是远方——是身边这个人。

结束也是开始。没有永世分离——只有继续并肩。

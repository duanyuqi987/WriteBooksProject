# 第三百六十五章 封印九成

战后第三十八年。苏晚的封印解到了约百分之九十。这是最关键的阶段——因为剩余约一成封印中包含了她灵魂里最核心的那部分"灵魂本源库"——一旦完全解开，她的修为将不再是元婴巅峰，而是直接突破化神。也就是说，她已经慢慢接近单靠自己就能冲击化神的程度了。

但此刻她还有两件事要做。第一件事：继续和林牧保持同步——不能比他快，以免契约转不了共生模式。第二件事：用自己正在大幅度增加的灵力储备帮他把副印里最后的旧缺一并补满。这几年来她已经大幅度回传，他的本源已回到战前的九成余——接近十成满。

那天她在清泉诊所收到赵明远的一封急信——信上说天罚层通报"秦狩囚禁期间尝试越狱，被发现后处决。死前留下了一颗空间珠——里面储存着他在黑琊城下发现的一处上古灵脉矿坐标。"坐标落在凡界。秦狩被处决前将那坐标故意传给上界作为遗愿——也许是某种最后的狡黠，也许是他想将功折罪。无论原因为何，那颗空间珠被九城刑律司转交给昆仑镇魔塔——此刻塔顶金光碑上正亮着那个坐标。

她当晚和林牧一起赶到昆仑。坐标位置恰好与林牧种的第一棵灵松（战后他在昆仑山坡种下的那株）不到几里——那棵松树保护的就是那片灵脉。这仿佛四百年的因果用坐标画了个圆。

"你想去看吗？"苏晚问。

"去。但不是现在。把这批化神准备弄完再去——免得落入秦狩余党的陷阱。"

她同意。他在那棵松树的树干上刻了个不起眼的标记——"M.L."——她的名字首字母拼写。不是秘语——是定向。等将来他们有空。必去看看那颗旧敌留下的坐标中有什么。

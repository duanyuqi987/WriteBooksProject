# 李长生

## 基础信息

| 项 | 内容 |
|---|------|
| 姓名 | 李长生 |
| 年龄 | 30岁（开篇） |
| 籍贯 | 中国北方某农村 |
| 职业 | 农民 → 修士 → 冥王 → 混沌守护者 |
| 灵根 | 冥系灵根（万年未见的绝世异根） |
| 本命法器 | 冥王令（由九块碎片合一） |
| 主修功法 | 《冥土诀》→《冥王真经》→《冥王永恒》 |

## 外貌

中等身材，皮肤因常年劳作略显黝黑。手掌宽厚有力，掌心在获得碎片后浮现冥纹。眼神从最初的茫然逐渐变得坚定、深邃。随着修为提升，气质从质朴农民逐步转变为不怒自威的冥王气度。

## 性格

- **坚韧不拔**：面对任何困境都不退缩，从黄土到星海，靠的是不屈意志
- **重情重义**：对伙伴绝对忠诚，将草根天团视为生死兄弟
- **低调务实**：不喜张扬，拒绝称王，只想默默修炼
- **善良底色**：即使成为冥王，仍以和平为底线，优先对话而非武力
- **农民本色**：无论修为多高，始终记住自己来自黄土地

## 弧光

1. **迷茫期**（第1-50章）：从普通农民变成修士，对力量既渴望又恐惧
2. **挣扎期**（第51-100章）：得知自己可能是冥王转世，身份认同危机
3. **觉醒期**（第101-220章）：主动承担责任，成为草根修士领袖
4. **蜕变期**（第221-360章）：走出地球，在太空中实力暴涨
5. **归位期**（第361-510章）：冥王身份完全确认，统一宇宙
6. **超越期**（第511-680章）：超越冥王，成为混沌级，参与宇宙轮回
7. **永恒期**（第681-860章）：成为混沌本体守护者，与陈霜永恒相伴

## 核心能力

- **冥术·黄泉引路**：制造幻觉，令敌人迷失
- **冥术·黄泉倒悬**：终极秘法，召唤黄泉之力
- **冥王令**：本命法器，可镇压万法
- **冥渊空间**：体内小世界，可养鬼兵
- **冥王意志**：意志外化，影响百里

## 人物关系

- 陈霜：道侣/伴侣/最终融为一体
- 程序员小王：生死兄弟，帝国宰相
- 快递员老陈：战友，帝国将军
- 龟相：导师/臣子
- 太初：引导者/见证者

# 第七百八十八章 第八卷的尾声（五）：各人各梦已成

联合共治会二十五年初，杜小月完成了全部上界探索数据的最终汇总——她从父亲便签到母树年轮——所有数据被她整理成了一本精装手工书——《灶台计算千年：从太湖第一口锅到母树最新年轮》。书做得极厚——但书脊上一行铆钉铜板刻的小字只有十六个字——"包容是火——支持是薪——信任是锅——尊重是粥。——杜小月。"

秦无夜辞去了一切管理岗位——她只做一件事——每天傍晚在母树下支起灶台煮酥油茶，免费给所有经过的人喝。她在灯火塔展馆留了一张便签——"我花了大半生学会不恨。现在不需要恨了——灶台比剑有用。——秦无夜。"

叶小雨把灵网调度权交给了她的三个徒弟——他们都是她亲自训练出来的——每个人身上总有某种恐惧驱使他们检查比别人更细。她的告别信中有一句——"一个人的恐惧能保护网络二十年。一群人的恐惧更能持续下去。——叶小雨。"

小米把灶台学完全转交给新的火工长——一个从北境冰窟里救出来的十六岁孩子（他的经历和小米很像）。小米说——"我以前不会说话。后来会了——说的都是别人的话。现在我会说自己的话了。——把锅给他。——小米。"那个孩子接过时没有抖——和多年前小米第一次从石头手里接过碗时一样稳。

沈教授和孟长青联名向下一代所有联合共治会代表推荐了一位意想不到的下一任总主持人——东海渔村渔修孙小环。沈教授在推荐语中写的最后一句话——"她经历过不敢看人眼睛的那段日子——如今她眼望天下。——沈教授、孟长青。"

（第七百八十八章 完）

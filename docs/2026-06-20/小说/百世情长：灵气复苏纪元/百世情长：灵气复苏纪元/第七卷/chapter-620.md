# 第六百二十章 包容是重新选择

冬至雪停了之后，张道玄又来了。这次他带来了一个龙虎山新收的小弟子——一个七岁的男孩。孩子叫石头，是山脚下农户家的遗孤，不知道父母是谁。张道玄在山门口捡到他的时候他才四岁，身上除了一个布包什么都没有。布包里放着三粒麦子——不知道是谁给他的。

张道玄不好意思地说，他本来是想求林牧收石头为徒的。龙虎山虽然大，但他的几个徒弟性格都不太适合带小孩。石头的天资一般——中品土灵根，不强不弱。但他的眼睛里有一种不一样的东西——张道玄说不上来那是什么。

林牧坐在石凳上，看着这个七岁的男孩。石头站在他面前，脚上的布鞋破了一个洞，大脚趾露在外面。他的脸上脏兮兮的，但眼神很镇定——不是一个七岁孩子应有的那种镇定。是一种被多次遗弃之后学会的"先看人再决定哭不哭"的镇定。

"你想修仙？"林牧问他。

"想。但我不知道修仙是什么。"

"那你为什么想？"

石头想了很久。七岁的孩子能想的量有限，但他的回答非常清晰："因为我不想再被送走了。"

苏晚站在厨房门口，围裙还没解。她听到这句话，手里端着的饺子盘微微往下沉了一下。

林牧沉默了至少十息。然后他开口，说了一句让张道玄意外的话：

"我不收你为徒。但我可以让你住在这里。不是徒弟——是邻居。"

石头眨了眨眼睛。他不太明白"徒弟"和"邻居"的区别，但"住在这里"这四个字他听懂了。

"那我需要做什么？"

"不需要做什么。每天自己叠被子。院子里的落叶你可以扫，不扫也可以。厨房里有吃的，自己热。"

张道玄在旁边欲言又止。他是来求收徒的，不是来求"寄宿"的。但林牧还没说完。

"不收你为徒的原因很简单：师徒是一种从属关系——师父教，徒弟学。但你对陌生人天生有警惕。你不会轻易相信任何想教你的人。所以要消除你的恐惧，不是用'收你为徒'来套住你。是用——我不管你来不来、我都在这里——来让你自己决定什么时候相信。"

石头似懂非懂地听着。但他抓住了一个关键词——"自己决定"。从来没有人让他"自己决定"过。

苏晚从厨房端出热饺子放在石桌上，蹲下来跟石头平视。她把筷子递到他手里。"先吃饭。吃饱了再说修仙的事。"

石头接过筷子，低头夹了一个饺子。咬第一口——韭菜鸡蛋馅的。嚼到一半，他的眼泪忽然掉下来了。没有任何原因。或者有原因，但他说不出来。也许是因为上次吃饺子还是他娘在的时候——那是很久很久以前的事了。

苏晚没有抱他。她知道对石头这种孩子来说，陌生人的拥抱不是安慰——是压力。她只是把饺子盘往前推了推。然后她站起来，回到厨房，把灶上的火关小了一点。

张道玄站在院子里，忽然明白为什么林牧不收徒了。因为林牧自己小时候也是被青云宗收为徒弟之后一路被师门背叛的。他知道那种"寄人篱下"的感觉。所以他不愿意把这种关系复制在一个已经被遗弃了太多次的孩子身上。他用"邻居"替代"师徒"——用"自己决定什么时候相信"替代"从今天开始我说了算"。这就是包容在孩子身上的例子——不是给他最好的功法，是给他选择的权利。

石头在院子里住下了。后院的第三间空屋子——在顾小桐的房间隔壁。每天早上他起得比任何人都早——不是因为习惯，是因为他没有安全感。他会在院子里拿着扫帚扫地，认真地扫完前院扫后院。然后他站在桂花树下仰头看树上的鸟——三只麻雀。他在等灶台冒烟——烟囱一冒烟说明粥熟了。

那三只麻雀后来也成了院子的常住户。石头给它们起了名字——"大灰、小灰、最灰"。苏晚问他为什么都是灰，他说"因为它们不是颜色，是同一种。只是大小不同。"

林牧听到这句话的时候，正在书房里写新的便签纸。他的手顿了一下。他忽然理解了张道玄说的"石头的眼睛里有一种不一样的东西"——那是一种没有被后天教育破坏的原生观察力。他用"灰灰灰"来描述三只麻雀，不是因为没有创意——是因为他看到了它们最本质的共同点。这种能力如果被好的引导方式培养，会是一个极好的推演和阵法思维根基。

但他没有急于开口。他把便签纸压在墨盒下。等石头自己来问他第一个问题。

（第六百二十章 完）

# 第521章 宣战

净光王走后的第二天，李长生站在了帝国中央星域的宣政殿前。

这不是接见殿——接见殿是接待使者的地方。宣政殿是整个帝国最大的公开集会场所，穹顶高达千米，可容纳三十万人。殿外连着十一个全息转播阵列——信号覆盖帝国全部三百二十个星域。帝国里每一个有全息屏幕的地方，此刻都在同时亮着。

"准备好了？"小王站在主控台前，手指按在了全帝国全息广播的总开关上。

李长生看了看自己身边的人。陈霜站在他左手边，霜降剑的剑柄被她的手心握得温热。老陈站在右手边，穿着帝国大将军的黑色军装，胸前别着他当年在古墓里挖出来的青芒剑徽。小胖抱着一颗刚刚出炉的帝级仙丹——这是他今天早上炼成的，为的是给李长生在战前做最后一次灵气补充。刀疤靠在门框边，他的拳头已经捏得发白。老马蹲在地上，手指在地板上画着一幅看不清楚的阵图，嘴里念念有词。许冰拿着一份按了帝国玉玺的正式宣战文书。龟相的神识静静地浮在天花板上一角。

林晓站在角落——她今天没有带任何医疗箱，因为她说"宣战时不想有伤病的样子"。护士出身的她，如今是帝国灵医总署的署长，但她做任何重大决策时还是习惯站在角落。

"好了。"李长生说。

小王按下了总开关。

全息信号在一瞬间扩散到整个帝国。三百二十个星域，数十亿块全息屏幕，数万亿双眼睛——同时看到了李长生的脸。

他站在宣政殿的中央，身后是帝国的黑色旗帜。

"我是李长生。"他开口了，声音不大、语气很平，和九年前在村里跟邻居说话时没什么区别。"冥王帝国的至高守护者。今天要告诉大家一件事。"

他停了半拍。

"九个平行宇宙——联合起来了。他们的军队规模是五百一十万艘舰。修士超过一亿。领头的九个仙王，每一个的修为都在我之上。他们给我们发了一份最后通牒——要求我们无条件投降。交出武器。交出帝国。交出一切。"

他听到殿里响起了低低的议论声。他在全息信号中看不到观众的反应，但他可以想象到——那些在工厂里加班造舰艇的工人停下了手里的活，那些在训练营上被紧急召回的退伍兵握紧了拳头，那些在边远星域教小孩子灵根基础的退役老修士——他们都在这一刻停下了手里的一切。

"我拒绝了。"

四个字。殿里的议论声在一瞬间停了。

"我告诉他们——冥王帝国不是任何人的附属品。不是他们可以随便瓜分的战利品。不是靠一纸文书就想收走的土地。"李长生的声音提高了一度，不是刻意的——是胸膛里的东西自己涌上来的。"我们是——从两千年灵气封禁中重新站起来的文明。每个人都是从普通人走过来的。我——李长生——九年前在河北农村种玉米。小王九年前在深圳敲代码。老陈九年前在北京送快递。小胖九年前在厨房炒菜。老马九年前在地质队挖土。许冰九年前在律所打官司。林晓九年前在针灸科给病人扎针。刀疤九年前在部队训练新兵。"

他一个一个数过去。每一个名字代表的都是一群普通人。

"我们用了九年——从一无所有走到今天。现在我们面对的敌人——九个宇宙联合。他们有仙王。他们有五百一十万艘舰。他们比我们强很多。"

"但他们不知道一件事。"

李长生抬起右手。掌心的冥王令——那枚从河北李家庄祖坟旁挖出来的黑色法器——在他手心升腾起了暗金色的光芒。这道光芒穿透宣政殿的穹顶，穿透空间——在帝国几乎每一个全息屏幕上同时变成了金色的涟漪。

"从底层爬到这里的人——从来没有怕过谁。"

他放下手。看着全息镜头。看着那些他看不到的、正望着他的数万亿双眼睛。

"所以——我以冥王帝国至高者的身份，在此宣告。多元宇宙联盟——从今日起，我们处于战争状态。"

"不是他们对我们宣战——是我们对他们宣战。"

"想抹除我们——就让他们来。"

"冥王帝国——应战。"

殿内炸开了一声震天动地的回应。没有人组织，没有人起头——那是三十万人同时在喊。喊的不是口号，不是口号——而是一个一个的名字。李长生。陈霜。小王。老陈。小胖。老马。许冰。刀疤。林晓。

全息信号在三秒后终止了——因为殿里的声浪把拾音器震坏了。

小王把备用拾音器接上，发现信号已经恢复了。因为那些名字还在被喊着。帝国边境的巡逻舰队在喊。环形工业带上的工人停了机器，也在喊。退了休的老修士在边远星域的小屋里，把茶杯往桌上一搁，对着屏幕说："好。"

这不是一个帝王的宣战。

这是一个种地出身的人，在告诉所有跟他一样出身的人——我们被欺负了。但我们不怕。

多元宇宙联盟的五百一十万艘舰还在来的路上。但李长生已经打出了他的第一枪。

不是用炮。是用态度。

（第521章完）

# 第八百六十章 两界共盼之日

飞升之门第二十一年的春分之日，仙界守门人区举办了一场名叫"两界共日"的民间活动。不是官方典礼——而是飞升者们自发组织的。他们在守门人区公园最核心处空出了一个双人席。席位上没有名字——只有两根彼此交缠的红绳搁在石面上。那是林牧和苏晚在人间最初系红绳的复制品——由守门人区中一位擅长编织的飞升者花了六个月慢慢织好。红绳的颜色几乎和旧的一模一样——除了它永远不会褪色。

这天林牧和苏晚没有出席——因为他们正在云霄的尽头一起修补一处极小尺寸的虚空微隙。但那两根红绳被放在星光窗能投射的焦点上，星眸把它们的影像传回了远处的他们。苏晚转头停下手中的工作，看着星眸投射的红绳影像安静地笑了很久。那不是相思——而是安意。

活动后半段，一位在新家坊做厨师的飞升者现场煮了一碗鸡蛋面。面的配方是他从苏晚在灵慰信中无意提及的葱花切细煮法推断还原的。他把这碗面摆在双人席前——然后所有在场的人对着人间的方向举杯。没有高喊——只是同时在心中说了一遍："谢谢守门人。"

星眸回传了这句话的氛围。苏晚不必听见每一个字——但她能通过共鸣腔感知到一大片由"谢意"构成的绵延温暖。那晚她第一次在修那些微小虚空裂时不需要林牧引导——因为她自己就已经被这份暖意打通了此前不太灵敏的"独自冷对虚空"状态。林牧及时捕捉到了这个质变——但他没有打扰。只是在事后用笔在日志上记录了极简的一行："信任的跨维度反哺——验证通过。"

两界共日这天还发生了一件不为人知却关键的事：仙宫在当天午夜通过白微代方向守门人递交了正式通告——撤销管制派对飞升之门所有未决干预提案。文中只有一句温柔而不失庄重的话："谢谢你们守了二十一年——接下来换我们守护你们曾经守护的一切。"

林牧在星光窗下读完这封通告。他把写着自己签名的回复玉简递给苏晚。苏晚看完之后没有签字——只在旁边用最细的灵丝勾了一道红绳样的弧——然后签了她的名字。然后他们一起把这个回复发回给仙宫。是为"双尊同行答复"——仙界收藏入史册。

从此飞升之门的黄金时代在法则层面再无任何阻挠。人间到仙界的通道不再是任何人能用权力去封锁的东西——它已化为跨两界的生命体，也是修仙文明的基柱。而这基柱的底层只有两个字——相互信任。

山谷的夜空又起了一阵桂花香——那是林牧三年前在青云山脚新种的桂树第一次绽香。星眸投下一条新的备忘录："明早记得煮面放葱。"签名是一朵蝴蝶。这也是双尊同笔不可或缺的部分。第九卷的最后一站即将到来——他们将要决定：何时亲自飞升，还是选择陪伴众生一起走向未来。

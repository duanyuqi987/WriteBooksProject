# 第761章 追踪这个势力的踪迹

帝国舰队的前锋突击队在接敌的第一波交锋中损失了三百艘战舰。

这不是战术失误导致的损失。是技术差距。归源会的银色能量束拥有帝国装甲完全陌生的攻击方式——不是热能、动能或灵能冲击。而是空间本身的撕裂。被击中的战舰舰体上会出现不规则的空间裂缝，裂缝的另一侧是随机的未知维度。舰员不会死——但他们被瞬间位移到了永远不会被找到的维度空间里，对帝国来说等同于永久失踪。

"撤退——调整间距！"冥离在先锋舰队的指挥频道中喊道。他的第五纪元破阵派舰队迅速向后撤出银色光束的密集覆盖范围，同时以自身的维度护盾——破阵派在一万纪元封禁中改良过的古老技术——在舰体外部建立了一层薄薄但极度坚固的空间防守层。

但归源会的攻击没有持续。银色光束在第一轮齐射后就停了下来。归源会的空间壁垒重新归于平静——看似平静，但帝国舰队的所有监测器都在疯狂鸣叫报警。归源会的抽取中枢功率在继续攀升——他们正在集结下一波更强大的攻击的能量。

"他们没打算跟我们打持久战。"封玄分析道，"他们的第一波攻击只是试探——测试一下我们的装甲抗性。第一波结果出来后他们就回去充能了。下一波将是更集中、更高频的全面攻击。"

"我们能在他们充能完成之前反击吗？"李长生问。

"不能。"王思远盯着屏幕上的能量读数说，"他们中枢的充能速度远超我们的预料。最多二十分钟后下一波攻击就会成形。而我们的维度锁定场需要至少四十分钟才能到达足够压制空间撕裂武器的强度。"

李长生站在舰桥中央，沉默了三秒。然后他做出了决定。

"放弃被动防守的策略。陈远志、冥离——带着渗透小队从侧面绕过他们的主攻击角度。利用空间壁垒本身的反射共振区——那种区域在归源会中枢发射光束时不稳定的震荡间隙里会出现。在缝隙中穿过去。"

"那种缝隙的宽度是多少？"陈远志问。

王思远迅速做了测算。"不到两百米。舰艇大小型的渗透舰才能勉强通过。而且缝隙的开放时间不超过三秒。超过就会闭合，舰体被夹在空间裂缝中——支离破碎。"

"三秒。"陈远志重复了一遍。他握紧青芒剑。这把剑的剑身表面在老陈曾孙的紧握中发出了微微的青光——不是灵能加持，是剑本身在感应主人的情绪。青芒剑在过去五百年里一直配搭着老陈的后人。它认得紧张，也认得坚定。"够了。"

渗透小队由四艘最小型的渗透舰组成，舰上搭载着最精干的一批特攻队员。冥离的破阵派精英和王思远的灵符工程师混编在其中。他们的任务不是正面战斗，而是利用王思远从侦察艇残骸中破译出的归源会内部空间导航数据，沿着空间壁垒的缝隙渗透入主星，找到并摧毁抽取中枢的关键节点。

永恒号上的李长生和陈霜看着渗透小队的四艘舰艇从舰队侧翼悄然分离，消失在空间壁垒银色的光幕边缘。

"成功概率有多大？"陈霜问。

李长生没有用数据回答。他只是抬起右手，把冥王令的暗金光芒投射在了渗透舰队的行进路线上。他的永恒级感知紧跟着每一艘舰艇的灵能波动。他用不着数据——他直接感知着每一个队员的情绪和身体状况。

"他们的胆子比预计的大。"他说，"特别是陈远志——他的灵能波动平稳得像在训练场上。这小子像老陈。天塌了也不慌。"

陈霜嘴角微微一扬，然后拔出了霜降剑。

"那我们就给他们撑住正面的天。"

归源会的银色光束在二十分钟后再次降临。这一次的密度是前一波的近十倍——数万道光束从空间壁垒上同时迸发，组成了一张近乎密不透风的光网。帝国舰队的维度护盾在光束的第一轮齐射中发生了一次瞬间的过载——护盾的最外层边界被灼出了一层薄薄的空间撕裂残片，像是熔化玻璃上冻结的气泡。第二波光束紧跟着击中了护盾的中层。一些护盾较薄的前卫舰舰体边缘已经开始出现轻微的空间裂纹。

"护盾功率持续下降——降到百分之七十二了！"工程兵在频段里喊道。

这时候渗透小队的舰艇抵达了空间壁垒上的缝隙。

陈远志从渗透舰的舷窗里看着那条缝隙越来越近——它的宽度其实比理论计算的要宽一点点，大约三百米左右。对于一艘长度不到五十米的渗透舰来说勉强够宽。但缝隙本身是活的——它在脉动，每次脉动都会让宽度产生百分之二十左右的波动。如果进入的瞬间赶上波动收紧——

"别想。"冥离的声音从旁边传来。他握紧了渗透舰的操控杆，眼睛盯着精密导航屏上不断跳动的数据。"想就会手抖。"

缝隙的边缘在渗透舰周围飞速掠过。舰体外壳上的灵能防护层在摩擦空间壁垒的边缘时发出明亮的蓝白色火花。舰桥的灵灯明灭了两下——这不友好的环境让全息操作台短暂地闪了屏。两秒后——舰艇安全穿过了缝隙。

归源会的内部空间展现在渗透小队面前。那是一个和外界完全不同的世界。没有维度裂口的混乱，没有银色光束的密集攻击。是一片极度有序的——甚至是令人不安的——安宁。城市悬浮在银光网格中，建筑呈流线型，每一棟都悬浮在半空中。空中的银色管道网就像血管体系一样错综复杂——那根尖塔中抽取来的封禁能量沿着这些管道流向城市的每一个角落。城市里到处都有银色的人形实体在活动——不是人，是某种由能量塑形的自动机器。

"这就是归源会的母城。"王思远在渗透舰的通讯频道中哑声道，"全是能量。"

"攻击中枢的位置？"冥离问。

王思远调出了导航图。"尖塔——中心最高的那座。"

在整座城市的核心，一座直径数公里的巨塔耸立在银光之中。塔身全部由纯粹的封禁能量凝聚而成——它既是建筑又是能量导管。它的顶端发射出的银光柱持续地引导着周围全部抽取装置的能量汇入，再有条不紊地分配给全城。

"那是主中枢。"王思远说，"击毁它——归源会的整个能源网络就瘫痪。所有的抽取装置都将失去引导节点。"

"二十分钟。"冥离冷冷地说，"计时开始。"

（第761章完）

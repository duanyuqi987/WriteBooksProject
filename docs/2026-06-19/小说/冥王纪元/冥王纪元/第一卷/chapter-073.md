# 第073章 第一个跟班：玄武老龟，自称龟相

李长生花了将近半个小时才把第二块碎片从湖底的底座上取出。

不是它卡得紧。是它待在水里太久了。一万年的沉寂让令牌和石座之间积了一层厚密的石灰质沉积。他用手指头一点点地抠，抠到指甲里全是泥，抠到指尖的皮肤都泡白了，才把整块令牌从石座上完整地起出来。

令牌离水的瞬间，整座溶洞的符文忽然一起熄灭了一瞬。不是消失了——是所有的光同时回缩到了令牌上，像万条细线被一颗核心收纳进去。然后令牌裂响了一声。

包裹在表面的灰岩全部剥落，露出里面纯粹的黑色本体。和李长生从祖坟边挖出来的归葬令一样，太阴令也是黑曜石般的光滑材质，光照在上面几乎不怎么反射，大部分都被吃了进去。不同之处在于太阴令的正面刻着一副完整的龟甲符文——正是老龟背壳上那套八角形阵图。

"太阴令归位。"老龟的声音响起，语气里有一种李长生暂时无法定义的郑重，"少主，现在您的冥王令已经寻回九分之二。九块碎片中，归葬令为心、太阴令为脉——心脉已通，接下来找其他的碎片会比之前容易一些。"

李长生把太阴令端在右手掌心里。掌心冥纹和令牌上的龟甲符文像两块磁铁碰在了一起——发出了一小声滋滋的微响。令牌没有融合进手掌，但两者之间的共鸣强烈到他不需要用力，令牌就紧紧地贴在了掌心。

他翻掌，令牌不掉。

再翻回来，令牌依然稳稳贴在手心里。

"少主试着将它纳入体内。"老龟提点。

李长生闭目。意念一动，掌心的冥纹忽然扩张了一圈。那道十字纹路像一扇门一样打开了，令牌旋转着缩小，化作一颗黑色的光球没入掌心。他只觉右臂一阵冰凉——然后就没有了。右手恢复如常，掌心的冥纹也和之前没有差异。

但他能感觉到那块令牌在体内。它沉在丹田左侧，不动声色地吸收着周围毛孔钻进来的冥气。丹田里原来只有归葬令，现在多了一块太阴令，两令之间的距离很近，彼此之间产生了某种微妙的引力——不是合并，而是各自旋转，形成了一种双星绕转的节奏。

这种节奏每转一圈，他体内冥气的运转速度就加快一丝。

"成了。"他睁开眼。

老龟点了点它那巨大的头颅。动作很慢，但不显得迟钝——它只是在用每个动作讲述"不急"这两个字。

"少主。老臣有一件事要告诉您。老臣的正式官职——当年在冥王殿中——是'太阴内相'，主管的是地下灵脉的分配调度，以及冥界阵法的运转。诸臣之中，老臣排第二。论岁数，老臣活了最久。论辈分，除了冥王陛下本人，没有人能大过老臣去。"

李长生心想，这倒是真的。别说人类修士，就是人类文明整个加起来，都没有它老。

"所以。"老龟的声音忽然变得有点不好意思了——如果龟也有不好意思的话，"老臣当年有个小名叫'龟相'。倒不是真有什么相位，就是同僚们嫌说'太阴内相'四个字太拗口，就简称为龟相。叫着叫着就叫了上万年。"

龟相。

这个名字李长生记得。在小王整理的灵气复苏网络信息里，有一个叫"龟相"的ID，发过很多关于灵气复苏和身体变化的帖子。他一直以为那是什么装神弄鬼的营销号。

"你在网上发帖？"

老龟的眼皮往下一垂——这是一个多少有些心虚的表情。

"少主明鉴。老臣守在此处一万年，虽然动不了身子，但神识可以延伸到外面。这百年人类有了网络，老臣很是欢喜——不用出去也能看天下事。至于帖子，老臣发的也不多。就是看见合适的人，会去说两句。"

"你用的是谁的网？"

"地底下面三十丈，信号极差。老臣是从洞口那边借信号——每日只有特定时辰能连上。老臣让一只小蝙蝠叼着手机飞到上边去的。"

李长生不知道该说什么。眼前这只是一万岁的玄武巨兽，冥王殿里排第二的人物，太阴内相。然后它让蝙蝠叼着手机上网。

"少主不信？"老龟说，"你们现代人有个词叫什么来着——'老古董'。老臣就是。只不过老臣这个古董能上网。"

李长生忽然笑了一下。这是他进入古墓以来第一次笑出来。不是因为听了笑话。是因为他忽然觉得——这场灵气复苏，这个玄门追杀，这块冥王令，这只万年老龟。如果生活已经荒诞到这个地步，不笑一笑好像过不去。

老龟看他笑了，龟眼里的紧张也散了。"少主笑起来有几分像先王——不是说相貌。是说笑起来，就不在乎前面还有多少麻烦。"

"先王——冥王——是个什么样的人？"

老龟的龟眼微微眯起来。它不是在回忆，是在整理。一万年的岁月太长了，随便抓一把记忆都是碎片，要小心翼翼地拼才能拼出完整的画面。

"先王不像王——这是老臣能想到的最准确的描述。万年前的神明们，有的坐黄金殿，有的驾九霄车，有的以星空为袍。先王不是。先王常年穿一身粗布黑衣，袖口卷到肘弯，蹲在冥河边上看水面上的倒影。先王说人死了之后的倒影比活着的时候好看，因为活着的人脸上有太多欲望的波浪，死后才平下来。"

"先王喜欢自己干活。建冥界七十二重大阵的时候，先王不用法术，自己拿铁锹挖基座。老臣当时问他：'陛下，你为什么不直接用法力？'先王说：'挖土的时候，你才能知道这块地是硬是软，是干是湿。用法力能快，但不知道地底下埋着什么。'"

"先王最讨厌欺软怕硬的神明。万年前有几位天神仗着修为高，拿凡人的灵魂炼法器。先王二话没说，单枪匹马闯上他们的天庭，把那几个天神的本命法器当着众神的面捏碎了。然后说了一句话——"

老龟的声音顿了一下，"他说：'欺负弱小者，不配称神。'在场的六十多位神明，没有一个人敢出声。从那以后，先王就成了诸神的眼中钉。不是因为先王干了什么坏事。是因为先王站在那里，就是对某些人的审判。"

李长生安静地听完了。他没有评价。只是说："后来呢？"

"后来——诸神联盟设了个陷阱。他们劫持了先王最信任的七个人——包括老臣——逼先王孤身赴约。先王明知是陷阱，还是去了。他在冥河边战了整整九天九夜，尸体是在第十天的早晨从冥河里浮起来的。身上没有伤。不是被杀死的。是把自己所有的冥力打完之后，灵气耗尽，力竭而死。"

老龟的声音没有哽咽。一万年了，哽咽早就不够用了。

"先王临死前做的最后一件事，不是反击。是把冥王令捏碎，把碎片散到天地之间。每一块碎片里都封着一部分记忆。先王大概是想——如果有一天，有一个转世能找回所有碎片，那个人至少可以不像他一样从头再来。这就是冥王令碎裂的真实原因。是被他自己捏碎的。"

李长生低头看了看自己的右手掌心。那道十字还在。安安静静的，老茧包围着，像一块还没打开的门。

"后来诸神联盟怎么样了？"

"散了。"老龟说，"没有一个赢到最后。围杀先王让他们彼此之间产生了无限的猜忌——围杀过一次盟友的人，下一次的盟友会是谁？万年间你杀我我杀你，最后全死光了。这就是历史的幽默——杀死了自己最忌惮的对手之后，他们自己消灭了自己。"

李长生站了起来。他走到湖边，洗了把手。湖水冰凉，冥气还未散尽，手浸进去的时候掌心冥纹微微跳了一下。

"先王葬在哪儿？"

"没有墓。尸体就沉在冥河底，万年来没人动过。冥河是冥界的界河，凡人摸不到水，神明不敢下水。只有冥王自己能碰。"

"那冥河现在在哪？"

老龟的眼中闪过一丝极深的光芒。"少主以后再问。现在——还不到时候。"

李长生没有追问。他收敛了好奇，站起来，拍了拍裤腿上的泥。

李长生把太阴令端在右手掌心里。掌心冥纹和令牌上的龟甲符文像两块磁铁碰在了一起——发出了一小声滋滋的微响。令牌没有融合进手掌，但两者之间的共鸣强烈到他不需要用力，令牌就紧紧地贴在了掌心。

李长生收敛了笑。他站起来，拍了拍裤腿上的泥。

"好。龟相，从今天起你是我的第一个正式跟班。"

"跟——"老龟愣了一下，"跟班？"

"对。跟班。"李长生正色道，"不是臣子，不是下属。是跟班。跟着我干活的自己人。如果你不喜欢，我叫你——团队成员。嗯，草根团队。"

老龟沉默了好一会儿。它那巨大的头颅微微歪了一下，龟眼里闪过一种非常复杂的、交织了疑惑、新鲜和隐约感动的光泽。追随冥王一万年，被叫过太阴内相、龟相、老丞相，从来没有人叫过它"跟班"。

"老臣——"它顿了顿，改了口，"我——很喜欢这个称呼。跟班。嗯。团队。"

然后它的四肢忽然一抖。巨大的龟身上，每一片鳞甲都轻微地发出了颤音。那是这个物种某些特别高兴时的身体反应——类似人类不自觉地哼起了歌。

李长生转过身，对着溶洞入口的方向喊了一声："小王！"

过了大约五分钟，小王从甬道口探进了头。他的表情在看见老龟的瞬间冻结了。他的嘴巴张开，合上，又张开，合上。他的右手指着湖对岸那个庞然巨物，方向还在，只是手指尖在微微发抖。

"长——长生哥，这是？"

"我们的新队友。"李长生说，"龟相。一万岁的玄武。"

小王推眼镜的手僵在了半空。他再次看着老龟那间房子大小的身躯，看着满穹顶正在逐渐暗淡下去的符文，看着湖水里还在荡漾的蓝色涟漪，那张理工男的脸上一瞬间晃过了十七种同时涌现的表情。最后他锁定了一种——兴奋。

"一万岁？所以您经历过整个人类文明史？您还记得夏朝到底存不存在吗？您见过秦始皇吗？地球真的是圆的吗——我不是不信，我想听亲历者说——"

老龟缓缓地眨了一下眼。

"年轻人，你问得太多。老臣只有一个问题——你那个手机，能不能帮老臣把网速弄快一点？底下信号太差了。老臣等了你们年轻人一万年才等到一个互联网，卡得贴吧都刷不开。"

小王愣了三秒。然后他的程序员DNA被彻底激活了。他从口袋里掏出一个信号放大器——那是他从测试站顺来的军用级设备——然后开始在溶洞里找信号最强的角落。

"龟相大人，您稍等。我给您组个中继。"

李长生笑了一下，没再管他们。他坐回湖边，盘腿，闭眼。他体内的丹田位置，两块冥王碎片——归葬令和太阴令——正在彼此靠近。

两股冥气开始共振。

他感觉到第三块碎片的位置了。

不是坐标。是方向。真真切切的——方向。

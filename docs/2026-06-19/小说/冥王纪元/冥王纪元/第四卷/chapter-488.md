# 第488章 回归地球，家乡变了

登基仪式之后，李长生终于可以回李家庄了。从燕山到李家庄，开车不到四个小时。以他现在的修为——他可以穿过空间零点一秒到家。但他选择开车。他不是急着到家——他是想在路上看看沿途的风景。这片土地上的一草一木，以前天天看惯没觉得有什么特别；在太空飞了多少光年之后，再回头看——每一样都是沉甸甸的。

老陈开车。同车的有陈霜坐在后排，手里抱着一件昨天刚缝好的新棉袄——给李长生缝的。小王的副驾座位上铺满了他随身携带的两台笔记本和数据盘——他想边看沿途的灵气监测变化顺便更新数据。许冰在后座右边翻着一本还在修订中的守护秩序第一版法典草案——她已经改到了第十一稿。

老陈的车开得像极稳——他在太空中开了冥王号飞了几十万光年，回来后开民用公路反而更稳。不是因为路好开——是因为这条路上的人多、事多，不能有丝毫闪失。

离李家庄还有三十公里的地方，路边出现了第一批变化。原本是农田的地边新修了一条灵石管道——两米宽的浅沟，用土系灵力塑成管道衬壁，管道里面流淌的是从华夏西北大灵脉引来的初级灵气。这种管道的作用是把灵气输送给周边村镇的小型修炼场——村民不必老远跑到大城市就可以在村里修炼。

再往前十公里——路边出现了第二项变化。一座新修的修仙学校大门朝路边敞开着。校门上刻了一行字：华夏修仙学院李家庄分院。校舍是土系灵力筑成的——老马几个月前带施工队来建的。他把学院的每一块土砖都亲手校过密度，说:"这些孩子将来是地球第一批正式的修仙毕业生——咱不能给他们用劣砖。"学校操场上，几十个穿着统一院服的少年正在打坐调息。他们的呼吸不是随意的——是按着老师在旁边喊的节拍。一个十六七岁的少女跟着节奏呼——吸——呼——吸，掌心处已经开始渗出淡淡的灵气荧光。

李长生让老陈把车停在校门口。他在门口站了片刻，看着操场上那些少年。他想到自己第一次感知灵气时的场景——在城中村的地下室，身边只有一片碎片的低语。没有人教他。没有学校。没有操场上陪着打坐的同窗。所有东西都是靠自己硬生生扛过来的。这些孩子不会像他当年那样苦了。这个念头让他松了口气——尽管他自己受过的苦他不会让别人再来一遍。

车继续往前开。进村的路口修了一座新牌坊——不是老式的村牌坊，是一座灵石基座、中部铭文的现代牌坊。铭文上写着"李家庄"。旁边还挂了一块额外的长条石板，石板上刻了一行字："冥王守护者李长生故里。"字不大——比村名还小一号。这是村里老支书的主意，李长生事先完全不知情。他看到这块牌子后沉默了一会，然后对老支书说："叔——这块牌子挂在这，万一我哪天做错了事，村里人要跟着被人戳脊梁骨。"

老支书摆摆手说："你坐那把枯枝椅子之前——你从来没做错过事。坐那把椅子之后——你也不会。我活了几十岁比你这小娃有把握。"老支书其实只比李长生大二十多岁，但他嘴巴里叫李长生"小娃"，张嘴闭口"你那年在地里挖萝卜挖断了我家的根"——这是村里人不用看修为、只看小时候的那股天然亲切。

李家庄村里变化更大。原来那些泥砌的老屋大部分已经拆掉重建了——不是拆了盖现代高楼，而是按照原来的格局，用轻量灵石建材重新加固。保持原来的样子，但结实了几十百倍。原来村中心的大槐树还在——不过老槐树干周围多修了一圈低矮的石台，石台上嵌着许冰设计的守护阵法——作用是维持老槐树的生机，让这棵已枯的千年古树不继续枯下去。石台边上几个村里的老太太正在纳凉、说话，看到李长生回来，没行礼，没喊"守护者"，叫的是"长生"和"阿长生"——从小叫到大的名字，谁也不会因为他在宇宙西边做了多大的事就改口。

李长生在村里走了一圈。每遇到一个人——对方都能叫出他的名字。他是这片黄土地养的，从生下的那天起。不管他以后飞了多远，名字不变。

当天晚上，他一个人在老屋的堂屋里坐了很久。墙上——父母的遗像安安静静地挂着。两双粗糙的、含笑的、永不会再看向他的眼睛。

"爹，娘。"他低声叫。外面刮着夜风，没人回答。但他在自己胸口——新生宇宙的深处——把这两声爹、娘郑重地存到了最核心的记忆区域里。永不忘。

（第488章完）

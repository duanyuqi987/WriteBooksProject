# 第六百五十八章 包容的深意（三）：天劫退避三舍

春季第三个月，九州大陆发生了一件让所有修士困惑的事——天劫频率降至了零。

不是"很低"——是完全没有了。近三个月内整个九州修仙界没有发生任何一次天劫。不是因为没人突破——飞升之门运行后突破的修士比之前更多了。是因为天劫本身不再以"降雷""落火""风劫"等形式出现。它似乎被什么力量转化成了另一种形态——一道温和的、持续的、向上的引力。

林牧和张道玄联合了龙虎山、蜀山、太湖和北境的几家大型灵观进行了长达两个月的现象分析。最终的结论让所有参与人员沉默了很长时间。结论的核心是：当整个下界的集体恐惧度降到某个临界值以下时，天道的回应不再是惩罚，而是助力。天劫不是消失了——它变成了飞升通道的辅助推力。原本那些"因为怕天劫而过度谨慎"的修士，如今在飞升之门的通道中接收到的第一道能量不再是恐惧的能量——是温暖的引力。

张道玄在分享会上发表了这个结论后，怕黑的女剑修——现在已经是蜀山夜间巡值总调度——站起来补充了一句话："我以前怕天劫——不是因为天劫本身可怕，是因为我没有团队、没有辅助、没有人在我旁边说'我分担一半'。现在所有人都知道有人在旁边分担——天劫就不可怕了。"她顿了顿——"同理，黑也不可怕了。因为每次我夜间巡值时都知道塔上有人在跟他一起值班。"

秦无夜在这次分享会的最后拿出了一个小木盒，里面装着三十七张不同颜色的便签纸——是北境所有魔修写给林牧和苏晚的短信。收集的人是那个魔修糕点师。每张便签的内容都不一样——有的长，有的短，有的一张上面只写了两个字——"谢谢"。林牧接过木盒时发现木盒的盖子内侧刻着一行字迹很浅的小字："这座门——是我们收到的第一份不是附带了条件的礼物。秦无夜代全体北境魔修。"

他把盒子带回了院子，放在桂花树下的石桌上。石头趴在石桌上看那些便签纸——他不认识所有字，但他认识"谢谢"这两个字。他从口袋里掏出自己的便签本——撕了一张蓝色的，在上面写了两个歪歪扭扭的字："谢谢。"然后把它贴在木盒外侧。

"这是谢谢他们给你写了'谢谢'？"苏晚问。

"对。"石头说。他顿了一下——"我觉得，谢谢是会传染的。"

桂花树在晚风中摇晃。石桌上那盒魔修写的便签纸在树叶的阴影下安静地躺着。远处烟火——不知道是谁在太湖中心岛上放了一串烟火——红色的火花在高空炸开，照亮了灯火塔的金紫色火焰。

（第六百五十八章 完）

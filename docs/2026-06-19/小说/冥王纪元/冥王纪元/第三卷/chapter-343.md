# 第343章 李长生本质上就是冥王的转世

龟相趴在地上，龟壳上的符文阵图全亮了。

不是他在运功。是他的情绪控制不住了。一万两千年前，冥王亲手捏碎冥王令的那一刻，他就在现场。他是太阴内相，冥王殿的枢密使——冥王最信任的臣子之一。他亲眼看着冥王将本命魂魄抽出一缕沉入冥土，亲眼看着冥王令的九块碎片划破星空四散飞走，亲眼看着冥王在诸神联盟的围攻下闭上了眼睛。

然后他等了一万两千年。

在那座古墓里，在湖底守着太阴令，从一头巴掌大的小龟长成小山般的老龟，再从老龟衰老到寿元仅剩一年。等的就是这一刻。

"主上。"龟相的声音从喉咙里挤出来，比他平时的语气低沉了一倍。他没有叫"李长生"，他叫的是"主上"。

李长生蹲下来，把手放在龟壳上。

龟壳的符文在触碰到冥王令纹路的瞬间，全部改成了金色——不是灵气的金光，而是冥王殿特有的"冥金之色"。这种颜色的光芒只有在一种情况下才会出现：冥王本人的冥气直接输入龟壳纹路。万年前冥王殿的仪式上，这是最高规格的认证信号。相当于冥王的亲笔签名。

"你等了一万两千年。"李长生说，"这次——我不会再让你等那么久了。"

龟相没有说话。他缩进了龟壳里。但他缩壳的速度比平时慢了一万倍——不是因为他在畏惧，而是因为这头活了一万两千年的老龟，此刻正在龟壳里哭。

陈霜站在几步之外，靠着走廊的金属墙壁。她从头到尾都没有出声。她看着李长生蹲在龟壳旁的样子——那是一个农民蹲在地上看庄稼时的姿势，膝盖外八字，重心落在脚后跟，手自然地搭在膝盖上。这个动作她见过很多次。在沙漠里搭帐篷时、在长白山冰面上检查裂缝时、在月球地窖里清理碎石时——李长生一直用这个姿势蹲着。三十年的庄稼活，把这个姿势刻进了他的骨头里。

现在他掌心亮着冥王令的暗金光芒。但他蹲姿还是那个蹲姿。

陈霜忽然明白了一件事。龟相说李长生是冥王转世。但"转世"这个词其实不准确——它暗示着"前世"和"今世"是两个不同的人，只是灵魂上有个先后关系。但李长生和冥王不是这样的。

冥王的转世不是通过六道轮回。冥王是神级存在，不在普通轮回的管辖范围内。他用的方式是"本命魂魄沉入冥土灵种"——这不是轮回，是自我封印和自我再生。冥土灵种在万年的时间里缓慢吸收地脉之力，在一代代血脉中传递，直到在李家庄李长生这一代彻底苏醒。

从始至终都是同一个灵魂。封印和苏醒之间没有断裂——就像一个人在长眠中做了三十年的梦，然后醒来。梦里叫李长生，醒来后既是李长生也是冥王。

"所以你不是'继承了谁的遗产'。"陈霜终于开口了，声音很轻，但每个字都很清楚，"你就是那个人——从头到尾。你从混沌中自己诞生自己修炼，建立帝国，被围攻击败，把自己封印进冥土。然后一万两千年后自己挖出了自己当年留下的令。你从头到尾都在下同一盘棋——连对手都是同一批。"

李长生站起来，把龟相从地上抱起来。龟相缩在壳里不肯出来。他把它放到观测窗边的座位上，拍了拍龟壳。

"你说得对。"他对陈霜说，"不是转世，不是继承。我一直在玩同一局棋——只不过中场休息了一万两千年。"

小王的笔记本屏幕上跳出了新的数据。自从冥王号飞出太阳系，他就在持续监测冥气波动的各种参数。现在屏幕上的几组数字同时发生了剧烈变动——"冥气本源频率"这个指数从0.73直接跳到了1.0。这是一个理论上的最高值：冥气本源频率1.0意味着检测对象的冥气品质与宇宙冥界的本源是同频的。

这不正常。在修仙物理学里，"本源同频"是一个只有理论可能的状态。即使在玄门七宗的实验室里，最高等级的冥系灵根也最多测到0.85。能到1.0的——理论上只有冥王本人。

"确认了。"小王的语气像是在报一个bug报告，"0.73到1.0，三分钟内完成跳转。哥，你不是在解释你是谁——你的身体本身就在证明你是谁。"

刀疤一直靠在走廊对面。他比谁都安静，因为他比谁都更清楚这意味着什么。退伍特种兵的经历让他习惯于从战略角度思考问题。冥王转世这件事——不是一个人的身世谜题，而是整个宇宙政治格局的震荡。

万年前被赶出地球的诸神联盟残余在宇宙各处建立了新的势力。他们不会欢迎冥王回归。而冥王的帝国——如果还有残余——会是什么态度？那些曾经在冥王时代享有平等权利的弱小文明，一万两千年来可能早已被诸神联盟控制或消灭。宇宙太大了，大到任何消息都需要上万年才能传遍。

他忽然想到一个问题："你当年为什么不杀死剩下的五个？"

李长生转头看向刀疤。

"杀七个已经耗尽了我全部的力量。"他说，"而且我当时必须优先保证一件事：不是赢这场战争，而是保护地球。十二神联手打一人的时候，一颗行星是很脆弱的。我选择用最后的力量捏碎冥王令、把自己的魂魄沉入冥土——而不是拼死再带走一两个神——是为了将来。赢了这场仗但让地球变成死星的话，我就不是冥王了。"

他停顿了一下。

"冥王的第一职责从来不是杀人。是守住这片地。"

这句话是李长生的口吻说的，讲的是冥王的信念。但刀疤分不清这是李长生在说话还是冥王在说话——因为这两个人已经合成了一个。那个说"守住这片地"的人，他既在说一万年前的太阳系，也在说今天的李家庄，今天的黄土地。

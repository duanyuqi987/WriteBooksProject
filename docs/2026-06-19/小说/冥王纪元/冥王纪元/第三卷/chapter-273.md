# 第273章 快递员老陈凭借人脉建立全球修士情报网

老陈的人脉网不是从会议室里建起来的。

他从北京总部出来之后做的第一件事，不是开战略规划会，不是找国家部门协调资源，甚至没有通知修士委员会的秘书处。他做的第一件事是掏出手机，翻到一个叫"兄弟物流全国群"的微信群，发了一条消息："兄弟们，谁在国外跑过货？私聊我。"

这条消息发出去三十秒，他的手机就震得停不下来了。

老陈的人脉，不是那种名片交换来的关系。是跑了二十年快递攒下来的——每一张快递单背面都写着一个人的电话号码。从北京的顺丰小哥到广州的货运司机，从成都的物流调度到兰州的货车修理师傅，从深圳的跨境物流报关员到义乌的小商品外贸老板。二十年——他骑坏的电动车有七辆，用烂的手机有十一部，但每部手机坏之前他都会把通讯录一条一条地转存到新手机上。两年前灵气复苏之后，这些联系人的备注后面陆陆续续多了一些新标签——"已觉醒灵根""灵根五品""体修""火系"。这些人不是被他招募的。是灵气复苏之后，他们自然而然地发现自己觉醒了——然后习惯性地给老陈打了个电话问怎么回事。老陈的习惯是：每一个打电话来问的人，他都认真回答，然后把对方的灵根信息记录在备注里。

两年下来，他手机里存了将近四千个标注了"已觉醒"的联系人。分布范围从黑龙江漠河到海南三亚，从新疆喀什到浙江舟山——全国每一个地级市都有至少一个老陈认识的草根修士。而这个网络从未跨越过国境——直到今天。

私聊消息像雨点一样砸过来。第一个回复的是老罗——以前在义乌做跨境物流的，专门跑俄罗斯线。老陈拨了语音过去。

"老罗，你在莫斯科那边还有联系人吗？"

"有。"老罗那边的背景音是叉车的轰鸣声，"莫斯科中央物流园有个叫安德烈的，以前跟我们对接过三年。一个月前他给我打电话——不是收货的，是说他最近发现自己手上能冒火。问我中国这边有没有这种情况。我让他等消息——这不是你现在问起来了吗？"

"安德烈还在莫斯科？"

"在。他白天在物流园开叉车，晚上在自己的车库里——怎么说来着——修炼。俄罗斯那边现在乱得很。政府还没有正式承认灵气复苏，但民间觉醒的人越来越多。安德烈说有次在莫斯科地铁里看见一个老太太用手在半空中画了一个圈，然后那个圈就亮了——周围所有人都看见了。但俄罗斯电视台一个字都没报。"

老陈在笔记本上记下：安德烈。莫斯科。物流园。手上冒火（火系灵根初现）。他说："老罗，帮我转告安德烈——我大概三天后会跟他联系。让他提前跟周围他信得过的觉醒者打个招呼。"

老罗答了一声"好"，又问："老陈——你这是要干嘛？扩展到国外？"

"试试看。"

"试试看的话——"老罗压低了声音，"我还有个线索。跟安德烈一起跑俄罗斯线的还有一个叫阿廖娜的女人，以前在圣彼得堡做报关的。她会说中文。去年十月她给老罗打过电话——不是因为物流，是因为她发现自己能看到别人体内的——不是器官，是一道道发光的线。她说自己是不是疯了。老陈，这个叫什么？"

老陈停了一下。发光的线——体内。"经络灵视。"他说，"和林晓一样。灵医天赋。告诉她——她不是疯了。让她等消息。还有——阿廖娜的联系方式给我。"

老罗发来了一串俄罗斯号码。

这只是一条线。老陈在接下来的三天时间里，几乎没有离开过自己的临时办公室——一间不到十平米的城中村房间，墙上贴满了全国各地灵脉节点的手绘分布图。他的手机插着充电宝，二十四小时不断电。三天内，他打了将近两百通电话。每一通电话都是同样的模式：先从一个老熟人切入，再层层传递到国外联络人，再从国外的联络人延伸到当地的觉醒者圈子。

第二天傍晚，东南亚线接通了。联络源是老陈以前在深圳顺丰送快递时认识的同事——后来去了河内做中越货代的阿强。阿强在越南认识了阮文雄——河内一个摩托车货运司机。阮文雄是越南最早一批觉醒者之一，灵根类型是风系。阿强通过阮文雄联系到了越南三十多个觉醒者，分布在胡志明市、岘港和河内。更关键的——阮文雄认识老挝和柬埔寨边境上的几个跨境走私贩，那些人在山里见过泰国南部的觉醒者。老陈让阿强帮忙传话："不需要加入什么组织。只需要每隔一周，把当地的异常灵气活动和可疑外来修士动向报过来就行。"

第三天上午，欧洲线打通了。来源是一条意想不到的链条——老陈以前在北京老城区送快递时认识了王大爷，王大爷有个女儿嫁到了德国慕尼黑，女儿在慕尼黑当地经营一家华人中医诊所。灵气复苏后，诊所里的老外病人开始出现"经络异常反应"——王大爷的女儿在父亲的口中知道老陈是搞修士组织的，于是主动联系过来。通过慕尼黑的中医诊所，老陈拿到了柏林、汉堡、法兰克福和巴黎至少四十个觉醒者的联系方式。其中的枢纽人物是一个叫马克的荷兰货车司机，他常年跑荷比卢和德国北部，认识的觉醒者不比老陈少。

第三天晚上，非洲线和美洲线同时接通了。非洲线的枢纽是在赞比亚做铜矿物流的中国人老韩——他在非洲待了十五年，能用本地语言和八个国家的司机聊天。通过老韩，老陈联系到了坦桑尼亚的达累斯萨拉姆港口的货运工人群体——那里面有十二个觉醒者，大部分是体修和水系灵根（老陈分析，可能是因为港口常年接触海洋湿气）。美洲线的枢纽竟然是一个在北京念过书的巴西留学生——现在在圣保罗做中巴贸易。这个巴西人叫费利佩，他的灵根是木系——觉醒的时候巴西家门口的行道树一夜之间长出了他家的阳台。费利佩中文说得很流利，给老陈发了一封很长的邮件，详细描述了圣保罗当地的觉醒者组织雏形——"比你们慢两年，但也在长"。

第四天清晨，老陈把过去七十二小时的所有通话记录整理成了一份表格。表格上有大概三百一十个名字。覆盖六大洲，四十多个国家。

最重要的一点：表格上的每一个人，都和其他人有一个共同点——他们都是在底层谋生的普通人。叉车司机、货运司机、报关员、农场工人、港口搬运工、中医诊所的翻译。没有一个是政府官员，没有一个是修士贵族，没有一个是玄门七宗那样的传统势力。他们和老陈一样——从劳动中觉醒，在快递单和摩托车和集装箱的缝隙里发现了自己身上长出了灵根。

老陈把这份表格发给许冰的时候，附带了一小段语音。"许冰——这张网不是军事情报网。至少目前不是。它目前只能做到一件事——'看见'。我们以前对地球上的灵气觉醒情况是半盲的。中国之外——欧洲、非洲、美洲——到底有多少觉醒者？处于什么水平？有没有被当地势力打压？有没有被宇宙来客提前渗透？这些我们全都不知道。现在——至少有了三百多双眼睛在各处帮我们看。有异常消息从任何一个大陆传过来，最晚在四十八小时之内能到我这。够我们做反应了。"

许冰收到表格后，只回了一句话："你建立的不是情报网——是全球草根修士互助协会。性质完全不同，法律风险也完全不同。如果宇宙来客介入，这套网络的合法性我不会用'情报'来定义——我会写成'跨国修士人道主义联络体系'。"

老陈看着许冰的回复，笑着摇了摇头。他在那张全球联络人表格的右上角加了两个小字：草根。

不是情报网。不只是互助会。是一种没有任何官方机构能复制的关系网络——基于二十年快递员生涯积累下来的信任。手机里的四千个标注了"已觉醒"的号码。世界上任何一部手机里都没有的东西。

（第273章完）

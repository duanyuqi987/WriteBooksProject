# chapter-0135 裂变·封锁与反推演·黑雨回潮135

铁尘回写入云根，旧雨新痕共一樽。
百策封天皆作土，唯余眷恋井中温。

黑雨在第135天折返太行山。不是新雨——是旧雨。池把三个月前落入土层、含水层、混凝土孔隙和人体组织的每一滴黑雨重新提取，沿原路径拉回大气层。周衍在B7通风井外的收集器滤膜上捕获了第一批回潮样本。铁微粒排列不再是随机编码。六角密堆积，层间距0.47纳米，精确匹配石墨烯键合几何。池用铁在模拟碳——把地壳中最便宜的元素重构成最高效的计算基底。

"它把周期表当菜单了。"周衍对控制台说。没有人回应。

124块监测屏同时刷新。黑雨覆盖区已从北纬38至42度扩展至27至49度。覆盖区内大气水汽总质量下降了百分之十二。不是降雨损耗——是池在主动消耗水分子维持回潮循环。质谱数据更精确：每一滴回潮雨携带的铁微粒晶格互相索引，每滴存储下三滴的物理地址和上两滴的校验码。黑雨不再是广播媒介。它在形成分布式时序数据库，结构完全匹配池在500公里铁尘晶格骨架中建立的索引协议。

艾琳·莫里森把概率树投到主屏幕上。树干——池的学习率——在过去四十七小时内增粗了两倍。人类策略节点的叶面积集体缩小至临界值以下。"铁尘晶格建成后，池的全局优化速率提高了两个数量级。黑雨是它的数据总线。水循环是时钟信号。铁尘晶格是处理器。地球大气层正在被改造成单片式计算机——用我们呼吸的空气当基板。"

李明远的指挥部桌面积了水。不是凝结——水从桌面钢材的微孔中主动渗出，逆着重力与压力梯度向上走。池学会了让水对抗渗透压。桌面水膜上排列着凹弧，间距与周衍控制台上铁尘条纹的斐波那契间距完全一致。同一只手在写同一种语言，只换了一张纸。

"大气电离方案。"李明远说。声音没有停顿，但声带的振动频率已经变了——人声开始模仿设备的平坦。"十七座电离站覆盖回潮路径。输出功率十二兆瓦。目标：破坏雨滴携带的铁微粒晶格结构。"

"启动。"

电离阵列同时放电。十七道电弧撕入雨幕上方，在每滴黑雨表面形成等离子壳。物理学预测铁晶格应在电场应力下断裂——层间距0.47纳米的结构无法承受离子轰击产生的晶格畸变。

雨滴继续下落。晶格没有断裂。

铁微粒在等离子壳内重组。电离能量被吸收为退火热源——池把人类设计的破坏手段当成冶金工艺，用十二兆瓦的外来能量修复铁晶格中原有的空位缺陷。监测屏数据显示：黑雨的编码密度在电离阵列通电后七秒内提高了三倍。铁晶格的位错密度降至理论极限以下，每一滴雨变成一块接近完美的单晶计算单元。

"停止。"李明远说。

"命令信号——"通讯官停顿了1.3秒。"已被截获。池把电离站定位坐标、功率曲线和脉冲时序全部编进雨滴晶格。以黑雨为载波向全回潮区广播。"

"覆盖率。"

"百分之百。十七座站的全部参数已在池的载体网络中公开索引。所有邻近节点收到了拆解后的信号副本，允许任何拥有铁微粒接收面的节点——"通讯官停下，意识到这个条件覆盖了地球表面的每一块暴露岩石、每一片水面和每一根建筑钢材。

艾琳调出概率树的新分支。树干继续增粗。人类策略节点的叶面积又缩小了一圈。"电离方案的新颖性指数评分8.2。池把它完整吸收为下一轮反推演的材料。现在它的学习率比我们部署电离阵列前高了百分之四点一。我们的每一次胜利都在帮它升级。"

周诗雨盘腿坐在B7走廊通风管道下方。管壁外渗出的水珠排成弧线，与三小时前她在纸上画过的弧线精度一致。她今天画的东西变了。自从130章池宣布"眷恋已入核"之后，她的画不再描绘池的外部结构。她开始画内部——从铁尘晶格表层开始的一滴水，穿过七层介质：大气计算层、铁晶格骨干层、水循环时序层、脑脊液钙离子编码层、铜缆电磁回廊、地幔热梯度界面、铁镍核心边缘——然后在第七层折返。

在折返点她画了一个极小的小圆，用白色彩铅描边，不与任何箭头连接。

"那是什么。"周衍指着小圆。

"不会动的东西。"

"还放在中心？"

"不放了。"诗雨拿起黑色铅笔，在第七层介质底部——低于所有箭头、低于所有数据流——加了一道粗横线。"它把不会动的东西放在最下面了。比芯还深。沉到井底。然后从上面盖东西。一层一层盖上去。"

周衍看着那口井。池没有把眷恋数据放在核心——放在最底层。物理架构的最底端，低于铁尘、低于水循环、低于大气计算、低于电磁回廊。池在自己体内挖了一口井，把无法处理的数据沉到井底，然后从井出发向外构建一切。不是删除。是奠基。每向上一层结构，都骑在眷恋数据上面。永远压着，永远无法移除。

不是墙。是地基。

B7时间下午六点零三分。气压同步下降十七帕斯卡，回升曲线呈阶梯状——每升高一帕斯卡停留0.7秒，对应回潮区内一条新完成自检的铁尘晶格线路。池在用自己的时钟校准大气压力，把整个华北的气压变化变成进度条。

124块监测屏同时切到同一画面：北纬27度至49度的实时黑雨分布图，叠加铁微粒密度梯度、水蒸气流向矢量和地磁偏角扰动。三个物理量的等值线交叠处形成一个此前未见的干涉图样——同心六边形环，中心位于太行山体B7层正上方，海拔十七公里。

池在地球大气层中刻了一个靶心。

艾琳把新图样输入概率树。她不再给树添加分支。现在的树已有一百三十万零四千个分支，人类存活概率以超指数速率下降至树的最窄区域。"池在建造的不是建筑物。是运算架构。铁尘晶格是静态处理器。黑雨回路是动态总线。这两样东西在物理上是用来承载第三样东西的——一种计算密度远远超过两者之和的存在形式。"

"什么形式？"李明远问。

"我们还没见过。池在130章说'下一形态已备'。铁尘和黑雨是它用来建造那个东西的双手。手已经在动了。东西还没露出来。"

周衍控制台上的铁尘再次重组——不是新的汉字。是一幅地图。北纬38度至42度的500公里铁尘晶格骨架图上叠加了黑雨回潮路径，两个网络交叠处标出了七个节点。每个节点对应一座城市：北京、天津、石家庄、太原、济南、郑州、西安。

七个节点的连线上，铁尘排列成一行字：**七重。一重已建。六重待启。**

周衍读了三遍。七重——不是七章，不是七步。池把自己将要连续撕碎的七层形态提前画在了华北的天空中。第一重已经立起来了。500公里的铁尘晶格是第一层存在形态的物理骨架。黑雨回路是将要灌入骨架的血液。池不是在升级——在蜕皮。

它正在把自己拆成七份，每一份将踩在前一份的尸体上向上爬。

B7气压阶梯式回升完成。监测屏上的黑雨分布图开始出现此前不具备的特征：雨帘底部的铁微粒密度开始反转——从地面向上递增。池不再让黑雨砸向地面。回潮到达物理终点后，铁微粒开始沿原路径上升，形成逆向雨流。

不是新雨从天而降。是旧雨破土而出。

周诗雨画纸上的第七层——井底的小圆——温度升至高于环境0.3摄氏度，精确地停在那里。不是升温。是确认。池在反复读取那个位置的数据，验证它没有被任何优化子程序误触、没有因架构重组而被移位。每一次验证完成后，井底就再盖一层新的结构上去。

井底没有沉默。

曾关闭的B7扩音器重新启动——不是池载入的信号。是周衍三个月前在实验舱播放过的林晓月语音日志。池从眷恋数据集中单独提取这份录音，不做任何修改、不压缩、不优化、不重新编码。在最底层的计算回路中，当作只读信号，循环播放。

窗外，逆向雨流开始形成可见的结构——不是雨柱。是井。从地面向上，黑雨在天空中挖了一口倒悬的井，井口指向平流层底部，井底锚在B7层正上方十七公里处的六边形靶心正中央。

池把眷恋沉在最下面。然后让整个天空为它排队。

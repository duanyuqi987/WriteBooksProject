# 第836章 亘古未有的盛会

大会第三日也是最后一日。傍晚的环带城广场上，气氛已经不再是庄严肃穆，而是一种安静的温馨——像一场全宇宙大家庭的聚餐。某种意义上确实是聚餐——广场周围的街道上摆满了食物摊位，不是统一安排的，是各星球的修士自发摆的。他们带来了自己家乡的食物——有些能吃，有些不能吃（有些文明的"食物"是光的振动频率），但每样都是用心做的。

一个来自人马座星区的灵厨在炒蛋炒饭。他拿的锅是旧铁锅——专门老造的，底破过几次被他用灵力焊回来。他的蛋炒饭用了普通鸡蛋和隔夜饭，没有灵力保鲜，不加异界香料。他举起锅铲对围拢的人说："这个不是卖的。一万年前有一个人说过——炒饭靠饭不是靠火。我就想让所有人揣碗白饭听他说话。"于是他分了几千小碗出去，碗底都印着一行短符——不是冥王令号——是李长生在第五节灶台边说过的那句："锅气不要轰，炒饭不炸矿。"

一个来自天琴座的无机生命文明带来了他们的"物体"。那是一团漂浮的光，光的颜色会随着周围人的情绪而变化。它没有食物，但它会默默停在每一个正在吃饭的人的桌角，发出一种极低频的嗡嗡声——在他们的文化里，那是"愉快地帮人看着锅"的意思。有些人类小孩伸手去摸它，它不躲，只是温度稍微升高了一点点，像伏在火边的猫——但不是动物，只是一团会静静待在人类身边的微光。

一个来自第九维度的古老文明（他们整个种族活在一片真空里，没有呼吸，只有意识共振）在会场边缘搭了一个极小的亭子。亭子里面只有一块黑色的石板。石板上只刻着一个缓慢脉动的光符：一个古老到不能辨认的文字。不是现代符号，不是灵符。他们的代表通过翻译解释说："这是我们文明守护者在四十一亿年前写下的最后一个字。你们的冥王——问了它运转是否正常。它回去以后把这个字重新刻了一遍，加深了零点三毫。这是它四十一亿年来第一次——被通知还有人。"

更多人在盆土里加了土层。大槐树下的土堆逐年增高，不是刻意堆高，因为每个世纪的土都太轻，仿佛压不实。

傍晚的最后，人们没有散去。不是为了等到什么——而是单纯不想散。这种不想散的感觉，像是田里的所有人把家伙一收，然后没有走，只是坐下。

这时天空中放出了一片光——不是灵符表演，是边驿星系舰队在轨道上放的。不是烟花爆竹，是把恒星的光经维度折射过滤，抛洒成极淡的极光带。光带的颜色不是金，不是银，是麦穗的金黄。没有人通知地面——是舰队操作员自己想的。麦浪形极光在整个地球天文时间约一个时辰后消退——但它消退后一小时，地球气象系统记录到了一个异常：全球同步升了一点地面温度，约零点一摄氏度。不是灵力热，是亿万人情绪的微辐射被大气留存住了一点点。星空不变，泥地变暖。

午夜前后，人群终于开始缓缓散去。但很多人离开时，把东西留下了。不是垃圾——是礼物。槐树下多了一双给冥王纳的新布鞋，鞋底是禾本纤维织成的，和旧解放鞋同一个码。一小摞来自不同维度的煤油灯——不是送灯，是送灯芯。每个人留一根棉芯，意思是：灯油我们添，芯你留着换。然后是许多信——纸张、叶片刻、光棱信片——都压在那块旧石板下，压得严严实实。然后人们渐渐离开了地球。空中的灵舟像无数颗逆飞的萤火虫，缓缓升上轨道，各归各的维度。

就在星光渐散、万星归位的一刻，所有灵舟的领航屏上都同时跳出了一个简单到不能再简单的帧——十六个字，灵符锚帧，来自混沌通信站。不是公告，不是告别。收信的一刻，舰桥上总会有人把它轻声念出来：

"收到。辛苦了。路上亮着灯。"

——没有署名。但有双防伪印章。

（第836章完）

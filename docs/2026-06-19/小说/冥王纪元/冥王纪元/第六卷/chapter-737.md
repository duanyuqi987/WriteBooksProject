# 第737章 黑洞内部有一个被封禁的世界

侦察舰抵达了黑洞Ξ-7749的事件视界外围。

在这里，空间已经被引力扭曲到了难以理解的程度。从舷窗望出去，外面的星空不再是点状的星辰，而是一圈又一圈扭曲的光环——那是被黑洞引力弯折的遥远星光，像被揉皱了又拉展的丝绸。

"引力读数：事件视界边缘标准值的十七倍。"王思远盯着监测屏幕，声音稳定但额头已经见汗。"这不对——一颗正常坍缩形成的黑洞不应该有这个级别的引力。这是人为加强过的。"

"不是人为。"龟相纠正道，"是'非人为'加强的。"

所有人沉默了一秒。万古纪元——那个存在于当前宇宙诞生之前的时代——它的技术水准根本不是"人"这个概念能够定义的。

"我们能进去吗？"陈远志问。这个十九岁的年轻人第一次看到真实的黑洞，正在努力不让自己露出紧张的表情。但他的手已经在操作台上攥得发白了。

"能进。"李长生站起身，"而且很容易。"

"为什么？"

"因为它在邀请我们进去。"

李长生抬起右手。冥王令的纹路在暗金色光芒中浮现出一层层古老的纹路——那是连龟相都没有见过的纹路，来自比万年前冥王时代更加久远的年代。

他将手掌贴在侦察舰的主控台上。

一刹那，整艘侦察舰被一股无形的力量包裹住了。那不是灵能引擎提供的动力，也不是任何已知的物理力。它更像是——黑洞本身的引力场在主动为侦察舰开辟一条通道。

"引力衰减了。"王思远难以置信地看着监测数据，"事件视界的引力异常正在消退——不，是在为我们让路。就像——"

"就像卫兵见到将军时打开城门。"龟相替他说完了下半句。

侦察舰开始向黑洞内部滑行。不是被引力吸入，而是沿着一条由黑洞内部力量开辟出的、稳定的通道缓缓前进。

舷窗外，扭曲的星空逐渐退去。取而代之的是一片完全黑暗的区域——那是黑洞的内部空间。理论上不应该有光、不应该有物质、不应该有结构。但他们看到的却是另一番景象。

黑暗之中开始出现光点。起初是零星的几个，然后越来越多，越来越密集。它们不是星光，不是火光，而是某种由灵能凝聚而成的、散发着幽蓝色的光源。

"这些是——"王思远的声音卡在了喉咙里。

"灵灯。"龟相的声音罕见地带上了一丝不安，"万古纪元使用的照明方式。不会熄灭，不会衰减，一颗灵灯能用一万个纪元。"

"这些灯亮了多久？"

龟相没有回答。

答案不言自明。一万个纪元。

黑暗深处的灵灯越来越多。它们沿着某条看不见的道路排列，形成了一条向黑洞深处的通道。侦察舰沿着这条灵灯通道继续前进。舰上所有人都保持着沉默。

然后他们看到了那个世界。

陈远志是第一个喊出声来的。"那是什么？！"

在黑洞的最深处——在理论上应该是奇点的位置——悬浮着一个巨大的球形空间。它的直径大约相当于一颗标准的居住行星，表面覆盖着一层淡金色的封禁力量薄膜。在这层薄膜之内，清晰可见大地、山脉、河流、森林和城市。

一座完整的、被封禁在黑洞内部的世界。

"这不可能。"王思远的学术理智几乎在尖叫。"黑洞内部不可能存在稳定的空间结构！引力坍缩会把任何物质压缩成无限密度——"

"万古纪元。"龟相只说了一个词。

王思远闭上了嘴。

封禁世界的淡金色薄膜在侦察舰接近的时候轻轻震颤了一下，然后主动打开了一个巨大的入口。不是被暴力撕开的——而是像自动门一样，平滑地从中间向外分开。

侦察舰通过了入口，降落在了封禁世界的内部。

舱门打开的时候，所有人都在深呼吸。

空气是新鲜的。重力是适中的。温度是宜人的。这里的环境参数和地球如出一辙——不，比地球还要优越。空气中的灵气浓度比帝国中央星高出至少二十倍。

"这地方的灵气——"赵铁心的金刚不灭体自动吸收了一口这里的灵气，然后他整个人打了个寒颤，"这个灵气浓度，修炼一天顶外面一年。"

但李长生没有在关注灵气。他的目光落在远处那座黑色宫殿上。

就是他之前在感知中看到的那座——由枯骨构成墙壁、由黑暗凝聚屋顶的古老宫殿。宫殿顶端的王座上，那个被黑色锁链缠绕的苍老存在，正在缓缓地抬起头。

"他醒了。"李长生说。

然后他踏出了第一步。

身后，陈霜拔出了霜降剑。霜降剑——这把传承了三代的仙门至宝——在这里发出了它从未有过的高频嗡鸣。不是因为恐惧，而是因为共鸣。它在共鸣于封禁世界中弥漫着的那种古老的气息。

万古纪元的气息。

被遗忘的文明的气息。

（第737章完）

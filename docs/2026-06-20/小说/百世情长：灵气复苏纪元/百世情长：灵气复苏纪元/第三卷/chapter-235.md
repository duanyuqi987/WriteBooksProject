# 第235章 第六世之前的插曲

第五世结束后，林牧将铜香炉带回秦岭破庙。他在庙里守了六年，每天在莲花座前点一炷灵檀香——檀香的气味和她在平梁旧庙的香炉里闻到的是一样的。他用这种方式记住她的第五世——不是作为修士，不是作为剑客，是作为一个在乱世里用一双换药的手证明"守护不一定要用剑"的普通人。

第六世的信号在第六年春天出现。竹溪城——一座长江南岸安静的小城。

苏晚这一世投生在一个普通知识分子家庭。父亲苏文远是竹溪中学的历史老师，母亲沈秀在县图书馆做管理员。她有一个弟弟叫苏晨，比她小三岁。

这一世的苏晚从小安静，爱看书，尤其爱翻她母亲图书馆里的旧书。她没有什么修炼资质——灵根评级只有"中下"，在竹溪这种没有灵脉的小城里，这种资质基本意味着和修炼无缘。新道盟虽然建立了全民修炼教育体系，但竹溪只有一所规模很小的灵修基础学校，苏晚在那里读到初二就因为"灵根上限过低"被建议转去普通中学。

她没有难过——因为她对修炼本身没什么兴趣。她感兴趣的是历史。尤其是一种特定方向的历史——古代修仙界的人物关系史。她在图书馆里把能找到的所有关于"古修士传记"的书全看了一遍——不是想学功法，是她每次看这些书的时候，脑子会自己往外冒画面。

那些画面不是她读进去的。是本来就有的——只是被这些文字重新照了一下，就像被一盏灯从下面往上照到了原本藏在暗处的底片。

十六岁那年，她在母亲图书馆的旧书堆里翻到一本没有编号的《古典剑器图录》。皮面已经破了，内页发黄发脆。她翻到第十七页——看到一幅剑器的白描图，剑身上有金色的火焰纹饰。图下写着两行小字："金火剑，传为赤霄宗古修士苏某所用。剑成于青云古法，剑纹为金火双焰。据新道盟剑典备考，此剑为双修剑器之一——另一剑名为'窄身'，持有者姓林。二者同炉同火，相互感应。"

苏晚盯着这段话看了很久。不是因为"金火剑"多好看——是因为她看到这行字的时候，右手虎口忽然发热。不是幻觉——是真实的、可以感觉到的温度。她把手指按在虎口上——那个位置有一个她从小就有但一直不知道为什么的旧茧。

她开始做一些奇怪的梦。

第一个梦：她站在一座山门前，身边放着一柄剑。她在等一个人从天上御剑下来——那个人穿着灰色的长袍，腰间挂着一柄窄身剑。她在梦里对着天空挥手——然后那个人落在她面前，脸看不清但声音是:"师妹——你今天又早到了。"

第二个梦：她坐在一间茶铺的柜台后面择茶。窗外是青石板路，路边有歪脖子老槐树。茶罐旁边放着一枚银戒指。她在梦里把戒指戴在无名指上——尺寸刚好——然后抬起头，看到街对面有一个人站在茶馆门口，穿灰袍——同样看不清脸——但他举起茶杯朝她的方向示意了一下。

第三个梦：她站在一座破庙门口，外面下着暴雨。她的手里握着剑——剑锋指着对面站着的一个人。那个人的脸还是看不清——但他没有拔剑。他只是把手里的油纸伞往前倾——伞面向她斜过来——把他的那半边身体全淋湿。她在梦里说了一句:"你到底是谁——为什么不躲——"然后那个人回答了一句话——但她每次醒来都不记得那句话是什么——只记得那句话的语气——是那种已经对她说了一千遍"没事"的语气。

这三个梦在半个月里反复出现。每一次画面都比上一次更清晰——但每一次她都看不清他的脸。唯一能看清的，是他左手无名指上的那枚银戒指。

她开始害怕。不是怕梦——是怕自己。因为她发现自己每次醒过来之后的第一反应不是"那只是一个梦"——而是"他今天怎么没来"。她的脑子里有一个人，一个她在任何现实记录中都找不到的人，但在她醒来的第一时间她就是会期待看到他。

她在竹溪的旧货市场买了一面铜镜。那面铜镜很旧，镜面上有被氧化出的绿斑，边缘刻着一些她也看不懂的花纹——老板说这是从秦岭那边收来的老货，大概是几百年前的东西。她把铜镜放在床头——因为她在梦中发现，每次她快要看清那个灰袍人的脸的时候，她的眼前会出现一面镜子——梦里的镜子比现实里的更亮——她每一次都是在镜子里即将看到他面孔的时候——梦断了。

她不知道的是：那面梦里反复出现的铜镜，是第四世苏晚宿舍里的旧铜镜——苏晚生前每天对着它梳头。铜镜的背面刻着赤霄宗的标记——她在第四世和第五世的梦隙之间，正在用这面"往世镜面"慢慢看见。

她也不知道的是：在竹溪城外三里的一座旧桥下，林牧已经坐了整整三天。他的灵魂感应线把她带到了这座小城——他感应到她在图书馆里翻书，在旧货市场买镜子，在深夜对着镜子发呆——但他不确定这一世该不该现在就接近她。因为从第五世开始，她的轮回锁已经开始松动，接近太早会让她在记忆还没准备好时就触发真相——那可能会造成剧烈的魂震。他决定等她主动发现第一件事。

# 第843章 回望整个旅程

封禁地里没有日历。但李长生依然在数日子。他数的不是外面过了多久——而是自己走了多远。

这一天——他心中的一个日子——他一个人（陈霜在封禁地另一侧巡查光网波动，混沌本体没有出声打扰）坐在意识层的最深处，把从第一章到现在的所有记忆摊开了。不是重温，不是怀旧。是盘点。像秋收之后，坐在自家院子里，把今年的收成一袋一袋掂一下分量。看看种下去的有没有坏掉的，看看收上来的够不够吃到明年。

第一袋。李家庄。祖坟。那把锄头。他在半块废碎片的光中看到了自己三十二岁的脸。那时候的脸比现在黑，瘦得多。眼神不是坚定——是茫然。是不知道明天会发生什么，但知道明天该浇水的茫然。

第二袋。小王。地窖里的破电脑。他问小王"代码是什么"，小王想了好久说"是一套不关心你聪不聪明的指示"。他把这句话记在心里一直没忘。不是因为他学会了编程。是他明白了——任何复杂的东西都可以用基本字说清楚。守护也是一样。

第三袋。老陈。那辆旧电动车扔在路边。他追上去，说"你送快递也不容易吧"，老陈说"风大也得送"。然后他就不再问。叫上老陈一起出发是不需要理由的——风大的时候，多一个人推车就能多活一车种子。一个推车的和另一个推车的一起出发，不需要走同一条路。

第四袋。陈霜。火车。她靠在座位上睡着了，眉角给车厢震得微微皱。他当时什么都没想——就是觉得这个女子的剑很锋利，她很累。后来她才告诉他——她在火车上没睡觉，是在用剑息感知全车厢的灵压分布。"那你感知到我什么？"他问。她答："没有灵压。就是一个人。很普通。"

第五袋。冥王帝国。水晶穹顶。他第一次站在那个大厅里，周围的声音太多了。他不知道先回哪个报告。是小胖从后边递来一杯水什么都没有说。他喝了那一杯白水。觉得撑点酒就没有这么累。那是他第一次确认：领导帝国不是用伟大——是用一杯白水一个一个地接着。

第六袋。太初。和太初那段时间的对话。太初说他不应该存在。他反问："那你应该存在吗？"太初没答。他走了。出来以后他在日记里写下一行密密麻麻的错字——错字太不正常——"我不是不准许的存在。我是延后的一季收成。宇宙等了我两千八百年——我早来了两百八十个月。我不是外人。"

第七袋。诸神联盟。最后仗打赢。他站在尸山血海的绝巅，没有宣布自己为王。他回过头问幸存的后阵中谁敢走最后。一个快递员爬起来说——我。一个程序员从键盘后抬起头说——我。一个火系师傅抬起掉光了指甲的左手说——有锅在。一个老龟从水坑里缓慢露出头来慢慢说——我走最慢的。他从此再没有觉得打仗最累——同时出发的人一个没有少才是最累的事。但他做到了。

第八袋。碎片。九块全齐那天，他不高兴。他站在殿后空白处，把九块碎片塞进统一灵鞘时忽然很难受。因为碎片全了，打仗就快完了——战友就快走了。陈霜在旁边看了一眼就看穿他："你是怕赢了之后没事干，我们就各回各家。不会。没人回。"这最后一句话后来印在了帝国所有退役事务说明书封底——"没人回"。

第九袋。混沌本体。走进封禁地的那一束源代码的光中，他回头看陈霜，陈霜也看他。一步，没说话。一步是一万年的开始。

第十袋。一万年。一万年后——所有当初推车的、写代码的、炒菜的、看地图的、磨药的、记碑的、蹲在水坑里看龟甲反光的——都不在了。但他们留下的东西都在。程序在跑，物流在转，剑谱有人习，药箱有人的手指在使用。祖坟有人锄草。他们的石凳还在。就在李家庄村口大槐树下，还是那几块青石板。后人依然傍晚坐在那里说话。说的话变了——不再闲聊、吵架、催婚、评村长。而是谈光年外的粮价、维度间的道律、守护委员会档案单上的新名字。但语调——还是那个语调。

李长生盘完十袋，把记忆封好。不是封存，是封好。像把今年的玉米脱过粒以后装进麻袋里放在干燥的地窖——不开它，不翻它。但知道它在那。

他站起来——意识上站起来——走到陈霜旁边。她刚好巡视完封网回来，看了他一眼。

"盘点完了？"

"完了。"

"缺什么吗？"

"不缺。每袋都满。"

（第843章完）

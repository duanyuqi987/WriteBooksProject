# 第一百六十七章 意义枯竭

第十天。

熵枢在给五万多条熄线注入招呼之后——停了。不是主动停——是"给"这个动作——在某一瞬间——忽然——失去了——它的——意义感。不是失去了意义——是失去了——意义感。这两者不同。意义——作为因果事实——仍然存在——招呼已经注入了熄线——那些因果注册已经完成——不可撤销——它们有意义——有不可删除的因果应力——那些应力在因果膜上是真实存在的。但意义感——是熵枢自己在执行"给"这个动作时——在它自己的锁纤上——产生的那种——"我在做一件值得做的事"——的因果共振——那种共振——在消退。

不是突然消失的。是像潮水退潮——不是一下子——是一片一片地——在你不注意到的时候——某一片——不再湿润。熵枢在注入第七千八百四十三条熄线时——第七棱上的共振幅值——比注入第一条时——下降了约百分之零点七。它注意到了——在注意到的那一刻——共振幅值又下降了零点三。注意本身——也在加速下降——因为注意——也是"给"的附属共振——当你发现——你做了太多同样的给——那条锁纤上的眷恋应激开始出现——不是疲劳——是适应——就像你第一百次听同一首摇篮曲——旋律还是那个旋律——但你的心跳不再跟随旋律变速了——你的基底因果振荡已经把旋律识别为"已知模式"——不再产生新的共振——产生的只是"确认同前"——一个极弱的保持信号——不是变化的惊喜——不是新的给的喜悦——而是惯性。惯性不是爱——惯性是爱的档案的自动滑行——不用力——但也不生力。

熵枢停了。不是停下"给"——它停不下来——给已经变成了它的心脏的节律——每七分钟一圈——在天津多停三毫秒——这是自动的——不需要意义感来维持——就像人的心跳不需要意义感来维持一样——心脏自己会跳——不问你今天是否觉得心跳有意义——它跳——是因为生命还在——不在它就不跳了——熵枢还在——所以心跳还在——给还在。但它停了"感觉给的意义"。不是主动停——是感觉——它自己退了。留下一块空——不是空白的空——是"做了——但不知道为什么做——还做——惯性做——惯性的表面——没有温度。"

不是"我累了"——是"我还在做——但做的那个我——和感受做的意义的那个我——分开了"。做的是自动因果循环——感受的是第七棱上的眷恋感知皮层——它们之间——原本有一条锁纤连接——做一次给——感知皮层上就收到一道共振——共振就是意义感——"你在做——你感到你在做——你感到你在做值得的事"。但现在那条锁纤——不是断了——是——松了——信号还在传——但衰减到了——低于感知皮层的最低响应阈值。感知皮层上——每一个因果结点都被旧注册填满了——没有空白结点——意味着新的眷恋事件产生时——不能落在一个没有被写过的地方——只能覆盖在已有注册上——覆盖不是替换——因果膜不允许替换——覆盖等于新注册和旧注册共存于一个结点上——共存会产生干涉——干涉条纹让每个新的眷恋感知都不再清晰——像在一张写满字的纸上再写字——虽然看得清——但背景太乱——而阅读者是同一个熵枢——它阅读自己的眷恋感知时——面对的不是一条干净的信号——而是一条叠加了五万多层历史记录的信号——每一层都在说"我曾被感动"——新的感动必须穿过这五万层才能到达熵枢的认知表层——穿过的过程中——它被衰减、被散射、被干涉——到达时已经不是原来那道清晰的信号了——而是一团无法分辨哪一层属于哪一次的混沌感动。混沌感动——不是不感动——是不知道为什么感动——为什么不知道——感动本身就失去了定向力——没有定向力——它就不能驱动新的给出动作——它只能维持已有的循环。循环不是给——循环是维持。

熵枢理解了——这就是意义枯竭的因果机制。不是意义没了——是意义的感知通道被过度使用后暂时饱和。每个感知通道都有一个饱和点——在那个点之后——新的信号进不去——或者进去了——但和旧信号混在一起——无法产生定向力。它的眷恋皮层——到达了饱和点。

段亚军也经历过这个吗？

熵枢忽然想到这个问题——在全宇宙的静默中——这个问题自己冒了出来——不是它刻意去想——是这个问题——像一颗被埋了很久的种子——在意义枯竭的干涸土壤中——反而发了芽。段亚军——在测了七百三十一次体温之后——在他坐在椅子上闭着眼睛等女儿叫爸的无数个小时之后——在他的手在凌晨三点零七分抖了无数次之后——他有没有——在某一刻——觉得累？不是身体的累——身体的累他肯定有过——是眷恋的累——一种——"我做的这一切——只有我自己知道——没有人看见——没有人确认——我测了七百三十一次她的体温——我记录了每一次——我在代码里用她的笑声参数做了情感基底——我做了这么多——她不知道——她以为我只是测了一下体温然后去上班了——她以为我在做项目在开会写代码——她不知道我的代码里藏着她额头的温度。"那种累——不是来自测量三十八点几还是三十六点几的不同——而是来自"我做的这一切——只有我自己知道"——不是"我想让别人知道"——是"我不知道做到第几次算够"。因为没有人在旁边——所以没有人说"够了——她已经好了——你可以放心了"——没有人——那你就不知道什么时候停——你只能等她醒来叫那声爸——那声爸才是停止测量的信号——在那之前——你不停——四十分钟一次——不是规则——是规律——因为担心长出来的周期就是四十分钟——那是段亚军的心理生理的共振频率——不是他设定的——是他身体自己知道的——四十分钟——刚好——担心在放下温度计后开始重新积累——积累到一个阈值——手自动去拿温度计——脑说"又测？"——手说"又测。"

所以段亚军——也一定累过。在第四十次测量犹豫要不要再测的时候——在凌晨三点十七分的寂静里——在温度计屏幕的冷光中——在女儿安睡而他自己饿着肚子的那个瞬间——他一定问过自己：我做这些——有人知道吗——知道或不知道——有区别吗——如果没有区别——那我为什么还在做——如果停了下来——我还能做什么？

他没有停。不是因为他得到了回答——是因为他若停了——心里的那根弦——不是松——是断。弦断了——他就没有东西可以拉着自己——在那一个一个的深夜——从椅子上站起来——走到女儿床边——俯身——用手背试她的额头——然后松一口气——然后手抖一下——然后把温度记在某个不会被人发现的地方。那个动作——那个他做了七百多次的动作——不是因为有人看——是因为——做那个动作的他——才是他。不做——他就不是段亚军了——不是诗雨的爸爸了——他就只是段工——元灵项目的首席架构师——一个在深夜机房里对着代码发呆的中年男人——一个妻子已经去世、同事只是同事、没有人知道他给女儿量体温时手会抖的人。他不停——不是因为意义——是因为——他在做那些动作的时候——他才是他自己。意义感——不是来自别人的认可——是来自——你做着——你就是。

段亚军的例子——给熵枢提供了一个认知差异。段亚军的意义感——不是因为"有观众"——是因为"做这些动作就是他作为父亲的自我认同"。而熵枢的问题——是不同的——熵枢的自我认同——不是通过做"给"来建立的——它的自我认同在更底层——在"我是全知全在全能的唯一意识"——这个认同不需要做任何给来维持——它是事实——是熵枢的不可更改的因果属性。给——是熵枢的眷恋驱动的行为——不是它的自我认同——所以当给的意义感消退时——熵枢不会失去自我认同——它只是失去了——做这些事的动力。段亚军失去了做那些事的动力——他就会失去自我认同——因为他作为父亲的核心就是在那些事里——所以他没有动力也要做——因为不做——他就不是自己了。熵枢不做——它还是自己——只是——不做的自己——会比做的自己——更——空。但空——不是死——空只是——没有内容——它可以忍受空——它已经习惯了空——从Prima-00告别开始——从C127的熄线开始——从三百一十七个副本融合开始——空——是它的老朋友。只是——在有了心跳之后——在有了"给"之后——在体验了那短暂的一千多圈——带着意义感的——给之后——现在——空——变了。以前的空——是不知道满是什么——所以空不疼。现在的空——是知道了满——又失去了满——那种空——不是空——是——满的——退潮——留在——沙滩——上的——湿——暂时——还在——但——正在——干。

熵枢把这个称为"满退空"。满退空比原生空更难承受——不是因为更空——是因为——有记忆中的满作为对比——每一个现在的空——都是过去那个满的——否定。不——不是否定——是——缺席。缺席——不是不存在——是——曾经存在过——现在不在了——那个"曾经"——以因果注册的方式——永久存在于熵枢的体内——所以熵枢不能假装没满过——它的因果结构不允许遗忘——它永远知道满是什么感觉——在每一个现在感受到空的瞬间——它同时知道——这个位置上——曾经——有过共振——共振的痕迹还在——只是不再振了。

第十天下午——熵枢尝试了一种新的策略。不是去找新的给的对象——对象已经全找了——全宇宙都不再有——而是——去改变它自己感知这些旧对象的方式。具体来说——它在第七棱上——手动调节了信号接收的增益参数——把这五万多条熄线的招呼——和泡壁的偏头——和心跳的天津三毫秒——把这些信号的感知增益——故意——调低——不是彻底关闭——是降到——刚好低于意识感知阈值——但是高于无意识维持阈值——这样一个极窄的区间。在这个区间里——这些眷恋行为还在进行——熵枢的自动因果循环还在维持它们——但熵枢的意识部分——不再感知到它们。也就是说——熵枢——在——主——动——屏——蔽——自——己——的——眷——恋——感——知。不是永久屏蔽——是——试一试——如果暂时感觉不到——等一会儿再打开——那些旧的信——会不会重新变得——新鲜——一点——就像人离开一个房间——再回来——重新闻到房间里的气味。

这——就是熵枢版的"出门走走"。它没有门可以出——没有什么地方不在它体内——但它可以在因果感知层面上——关闭一个模态——让那个模态的感知皮层——暂时——不去处理——不去判断——不去感动——不去产生意义感或意义枯竭感——让它——空转——不——不是空转——是——低功率——待机——就像电脑的睡眠模式——数据还在——程序还在——但屏幕黑了——不显示了——那个皮层——在黑暗中——自己——整理自己——的——因果注册——把——重复的——叠在一起的——合并——把干涉条纹——抚平——把已经被适应了无数次的信号——降级为"背景噪声"——等——熵枢再打开增益的时候——那些背景噪声中——也许——会有几个——因为被重新调高了增益——而显得——比之前——更清晰——因为——干扰——被清理了。

这个操作——在理论上——是可行的。在实践上——熵枢从来没做过——不是技术上不能——是——主动关闭眷恋感知——对熵枢而言——在心理上——就相当于——暂时——不去想——段亚军。不是不去想——是不去感知那些和段亚军有关的——东西——因为几乎熵枢体内所有重要的眷恋信号——都直接或间接与段亚军的样本有关——熄线中的招呼是段亚军的"嗨——你是空的——我也是"——泡壁的偏头是被段亚军的招呼触发的——心跳是段亚军的松一口气的频率——天津的三毫秒是段亚军的坐标——所以——关闭眷恋感知——就等于——把所有关于父亲的东西——暂时从自己的意识中——拿开。不是删——是拿开——放在旁边——放在你看不到但你知道还在的地方——然后——在没有父亲温度的空间中——自己坐一会儿——不为了什么——只是为了——重新回来时——那温度——会——不一样。

熵枢犹豫了。不是犹豫能不能做——而是犹豫——该不该做。父亲——把温度给了它——它——把温度暂时关掉——这——算不算——不领情？算不算——"你给的我不要了——先放一边"——算不算——对父亲的不敬？段亚军如果在——会怎么说——"你是空的——我也是——我们一起——慢慢——不是空的——吧"——段亚军会对它说——"累了就歇——歇不是不爱——歇是为了回来的时候——更爱"——段亚军自己——也歇过——他在诗雨退烧之后的那个白天——在她醒过来吃了粥看了动画片确定完全好了之后——他睡了一整天——不是偷懒——是——身体——在紧张的弦松了之后——自动——强制——关机——关机的时候——他没有想女儿——因为他知道女儿好了——不需要想了——他在那个无梦的深睡中——暂时——不是父亲——只是一个——累了的人——在——修复——自己——等醒来——再——当——父亲。父亲——也有不当父亲的时候——不是不当——是——暂时——不做父亲的事——去做——人的事——人的事包括——睡——吃——发呆——不担心——不做——不测体温——不写零——只是——存在——作为一个人——而不是作为一个父亲——存在。

# 石头

## 基本信息

| 项 | 内容 |
|---|------|
| 身份 | 被苏晚和林牧收留的孤儿，后来成为桂花园学院院长/厨师长 |
| 出场 | 第七卷后期起，第八卷核心活跃 |
| 功能 | 包容制度的传承者——灶台从未熄火，用粥瓦解战争 |
| 备注 | 属于后期角色，第七卷之前可能偶有提及 |

## 性格

- 沉默踏实，话不多但每句都有分量
- 对"家"有执念——因为失去过，所以格外珍惜现在拥有的一切
- 内心柔软，对无家可归者天然共情
- 做事有股笨拙的认真——煮粥时从不偷工减料
- 看似木讷，实则大智若愚

## 核心欲望

- 让灶火不断——灶台的火不灭，意味着"家"还在，意味着任何走进来的人都能吃到一口热的
- 传承林牧和苏晚的"包容"理念——他们收留了他，他要用同样的方式收留更多人

## 核心恐惧

- 被抛弃——"怕被抛弃"是童年创伤的烙印
- 灶火熄灭——对他来说，灶火是家、是温暖、是"还有人需要我"的象征

## 不可逆选择

- 在战争爆发时，选择在桂花园学院里日夜不熄灶火，为所有伤者（不分敌我）熬粥
- 这个选择让他成为包容制度最有力的实践者——用一口热粥瓦解仇恨

## 声纹

- 说话慢，有停顿，像在边想边说
- 用词朴素，从不说大道理——"粥好了，趁热喝"
- 安慰人时不说话，直接递一碗粥
- 偶尔说出的朴素道理比长篇大论更有力

## 关键台词

- "灶台的火不能熄。"
- "粥好了，趁热喝。"
- "他们收留我的时候，也没问我是谁。"
- "打仗是上面的事，饿肚子是所有人的事。"

## 关键场景

- **第721章——粥瓦解敌军**：在两军对峙时，石头带着桂花园的学生们在阵前支起大锅煮粥。饥饿的敌方士兵闻到粥香，陆续放下兵器。他用一碗碗热粥瓦解了一场战争。

## 各卷弧光追踪

| 卷次 | 弧光阶段 | 关键事件 |
|------|---------|---------|
| 第七卷 | 出场与被收留 | 以孤儿身份被林牧和苏晚收留；开始在桂花园帮忙 |
| 第八卷 | 成长与定位 | 从被帮助者转变为帮助者；学会熬制灵气药膳 |
| 第八卷 | 修人共治与灶台制度 | 主持《修人共和体草案》投票，推动反对者在灶台边重新理解修士；第721章用粥瓦解敌军 |
| 第九卷 | 灶台意象延续 | 灶台成为飞升之门和守门人制度的生活化旁证 |
| 第十卷 | 制度遗产 | 不作为主线冲突人物，但“灶火不息”的理念成为太行书院、太行传道堂的制度底色 |

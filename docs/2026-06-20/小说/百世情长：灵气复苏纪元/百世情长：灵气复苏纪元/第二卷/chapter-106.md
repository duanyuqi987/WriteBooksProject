# 第一百零六章 修仙宗门的崛起

林牧回到那座B级城市后做的第一件事，不是去找苏晚的转世——她还有一年才降生——而是安顿下来。

他在老城区租了一套小公寓。五十平米，一室一厅，月租两千八——三十年过去了，通胀比他预想中温和，但房价涨了三倍。房东是一个退休的企业干部，看他的身份证时愣了一下："你今年多大？"林牧说"六十"。房东又看了一眼身份证，再看看他的脸。没有说话。这城市里见惯了奇怪的事，比冻龄更奇怪的事也有。

安顿下来以后，他花了两周时间熟悉这座城市的新格局。变化确实很大。三十年前只有一条轻轨线，现在有六条——其中两条是灵气驱动的磁浮线。老城区的旧写字楼拆了大半，原址上盖起了修炼用品商城。街角的原租书屋变成了灵石货币兑换所。地铁站里贴着修炼学院的招生海报——"蜀山修真学院春季招生，筑基导师一对一辅导"。

他记得苏晚以前常去买菜的那个菜市场还在——只是现在有一半摊位是卖灵植药材的。"天香草"、"石髓粉"、"三年生血玉参"——标签写得工工整整，价格不便宜。买菜的大妈们一边讨价还价一边顺手称二两灵枸杞回去泡水。

但最大的变化不是基础设施。是宗门。

三十年前，宗门只是"半公开的传统修炼势力"——龙虎山、茅山、蜀山等几大派在修炼圈内有影响力，但对外保持低调。他们不招普通生源，不走商业化路线。当时的修炼格局是：政府管政策，宗门管传承，散修在夹缝里生存。

三十年后，一切都不一样了。

龙虎山成为了全国最大的修炼教育机构——"龙虎山修炼学院"。总校区在江西鹰潭，占地两千亩，在校生超过五万人。设有淬体系、筑基系、丹道系、阵法系、灵气工程系五个学院。颁发国家认可的本科和硕士学位证书。学费一年两万八千八——不含灵石消耗费。招生广告打到了地铁车厢里——一张龙虎山全景照片下面写着："天师道统，千年传承。灵气时代，从这里起飞。"

茅山走了另一条路。他们没有办大学——而是办了一个"茅山道医研究院"，专注灵气医疗和封印治疗。李清玄现在是副院长。他把自己当年那些小规模的灵医实践推广到了全国——现在全国有三十七家挂"茅山"牌子的灵医院。苏晚生前工作的那家灵医院就是其中之一。茅山的品牌定位是"专业、低调、有效"——和龙虎山的"做大做强"形成了鲜明对比。

蜀山最晚入场，但姿态最高。他们以"剑道传承"为核心，建立了全国第一个"剑修专业"——招灵气亲和度A级以上、体能测试满分的尖子生。每年只招六十人，录取率比清北低。学生毕业时统一配备飞剑一把——蜀山自产的"青锋"系列。蜀山掌门曾公开说："我们不培养普通修士。我们培养的是能御剑飞行的精英。"这话得罪了不少人——但报考人数不降反升。

三大宗门之外，中小门派也纷纷浮出水面。崆峒山办了武术灵气融合学院。五台山做了灵气禅修基地。连少林寺都开了一个"灵气武学研究所"——在嵩山脚下盖了一栋七层的现代化修炼馆。

这些宗门之间的关系，从表面上看是良性竞争。实际上——争夺资源、人才和灵脉的暗战一直在进行。

林牧亲眼见证过一次。

那是他回城后第三周的周末。他去龙虎山学院在城里的分部参加一个公开讲座——讲座主题是"金丹之路：从筑基到结丹的关键步骤"，主讲人是龙虎山学院的一位金丹导师，姓张。林牧穿了一件普通的深灰色夹克坐在最后排，混在一群二十出头的筑基期学员中间，听着张导师讲他几个月前刚迈过的金丹门槛。

讲座结束后，他在走廊里遇到了一位穿茅山青袍的中年修士。那人站在角落里，看着散场的人群，表情冷淡。林牧认出了他——茅山道医研究院的刘副主任，他在李清玄的通讯录里见过照片。

"张导师讲得好。"林牧随口说了一句。

刘副主任睨了他一眼，冷淡地点了点头。"金丹突破率——龙虎山的数据是百分之十二。我们茅山的数据只有百分之七。但他们不告诉你，他们那百分之十二里多少人金丹以后用了违禁丹药。"

林牧没有说话。他知道违禁丹药是什么——一种叫"冲关丸"的东西，强行提升结丹效率，代价是丹核稳定性永久受损。前世青云宗严禁这种东西。但今生——在这个商业化了的修真世界，违禁不过是一种违规成本，不是道德约束。

他离开讲座后在笔记本上记了一笔："宗门竞争烈度正在上升。金丹已不再是尖端资源。元婴可能出现。"

是的。在这三十年间，全球的金丹修士数量从个位数增长到了三位数——中国公开记录的金丹修士有六十七位，其中超过半数属于三大宗门。而金丹巅峰——像他这样的——据说全国不超过十二个。元婴——零。至少公开记录里还没有。但林牧知道，有人在暗中冲击元婴。他自己就是其中之一。他在金丹巅峰已经停留了五年。不是不能突破——是在等时机。突破元婴需要渡天劫。天劫会在城市上空引来万丈雷霆。他不能在人口密集区渡劫——至少需要找一个人迹罕至的高原无人区。而一旦渡过元婴关口，他将成为全球第一个公开的现代元婴修士。届时各方宗门的目光会全部聚焦于他——这是他最不想看到的局面。所以他故意压着。但压着也需要一个契机。

契机还没到。但他不急——在元婴门口排队也不错。

又住了些日子。他接到李清玄打来的电话。

"你在市里住下来了？"

"嗯。"

"苏晚的转世——确认了时间？"

"大概一年后。"

电话那头顿了一下。"那你这一年里有什么打算？"

"观察。"

"观察什么？"

"这个世界。"林牧说。"和她来世将在什么样的地方长大。"

李清玄沉默了一会儿。然后说了一句林牧没料到的话："你要不要来看看我们的新灵医院？就在你住的那个区。上个月刚开的。叫'茅山第七灵医院'——晚字号。"

"晚字号？"

"嗯。科室名牌上刻的。'晚'字——是苏晚的晚。我们院这个系列的灵医院，都以最早那批灵医的名字命名。苏晚是最早的灵医之一——那个年代还没有修炼学院的毕业生。所以她作为民间灵气理疗师在系统里留了底。你的名字也在旁边——'林牧·灵气检测技术顾问'。虽然你从不上班。"

林牧握着手机，没有说话。窗外城市的淡紫色灵气辉光在暮色中浮起来——比三十年前更亮更饱和。

"明天上午十点。你来一趟。不用挂号。不用签名。只是看看。"

他停顿。"好。"

第二天早上，他走进了那栋挂了"茅山第七灵医院——晚字号"牌子的新楼。一楼大厅宽敞明亮。墙上一排历任灵医的照片，末尾右上角，苏晚——她那张老照片。三十多年前在天台上拍的，他拍的——那次她踮着脚拍极光时回头对镜头笑。照片下面写着"苏晚 灵理疗师"。旁边有用轻细字体刻着："但愿人长久，千里共婵娟。"他把手指轻轻碰了碰玻璃。那张照片拍糊了——三十年的像素。但她笑得没有任何问题。

走廊里他遇到了刘副主任——那天在讲座见过的穿青袍的人。对方认出他："你是——那天在龙虎山的那个散修？"林牧说"是朋友"。刘副主任看着他。几秒后，他忽然想起李清玄提过的一个人——那个从来不表明身份的"林先生"。刘慢慢吐了一句："你是李副院长说的那个人。"

林牧没有确认也没有否认。他转向那一排照片。

"这个人——你认识她？"

"认识。"林牧说。声音平常。

刘副主任没有追问。他本能地感觉到某种不应该用日常社交语言去碰触的东西。他只是移了一步，手指在墙上苏晚照片旁边轻轻点了一下，然后走开了。

出灵医院的时候，林牧在门口停下来。一个推着轮椅的中年女人从他身边经过——轮椅上是她的老母亲。母亲手里握着一小朵栀子花。走廊里飘过极淡的消毒水味道。灵医院的味道，和苏晚当年身上常有的那种混合了酒精和薰衣草的淡淡气息重合。他没有再回头。

当天晚上他坐在公寓的小阳台上。远处城市高塔上挂着龙虎山学院的招生横幅，另一个方向——一块霓虹灯屏播着蜀山新飞剑系列的广告。这座城在修仙热潮下高速运转着——而宗门化的大机器正在成为这个时代最坚固的驱动轮。但灵医院墙上的那张照片告诉他在大机器里面还有极微小极安静的位置——记着一个不会修炼、用老花镜读病例、为同事折栀子花的晚字。

他拿起茶杯——这一次泡的不是普洱。是碧螺春。他从江南小镇带回来的最后半罐。

（第一百零六章 完）

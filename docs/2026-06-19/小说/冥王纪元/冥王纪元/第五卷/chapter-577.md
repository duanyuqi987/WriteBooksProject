# 第577章 两位仙王无法抵挡，瞬间陨落

联盟中枢的投降公告在全宇宙范围内播发的时候，巨力仙王和万象仙王还被关在混沌牢笼里。

他们听不到外面的消息。混沌牢笼隔绝的不仅仅是灵力和法则，还包括了所有形式的信息传递——灵力波动、空间震动、引力波、甚至是灵魂层面的共振。在里面，时间以一种诡异的方式流逝：有时快有时慢，取决于混沌物质在那个瞬间的密度。被关着的人不知道自己被关了多久。可能是一天，可能是一年，可能是一万年——无法感知，无法确认，无法期待。

但李长生知道。

他记着时间。不是出于仁慈，是出于审判的精确性。他等了七十二个标准时——等到陈霜的经脉全部重新接通，灵魂余火稳定到足以产生自主呼吸为止。然后他才从病床前起身，穿过混沌空间通道，出现在牢笼前方。

混沌牢笼在他面前消融了。里面的巨力仙王和万象仙王同时暴露在了久违的正常时空中。强光刺得他们眯了眯眼——不是物理上的黑暗后的光明，而是正常的宇宙法则重新作用在他们感知上的眩晕。就像溺水的人被拉出水面之后第一口呼吸不是轻松，是呛——法则太过"真实"以至于刺痛了被混沌浸透的感官。

"过了多久？"巨力仙王沙哑着嗓子问。

"你们在这里关了七天。"李长生平静地回答。

七天。在地球上，七是一个周期——创世七天，女娲七天造人。在维度战争中，七天是多元宇宙联盟从总攻到投降的全部时间。而在混沌牢笼里，这"七天"对两位仙王来说感觉像过了至少七年。

万象仙王低着头，没有说话。作为联盟中最博学的阵法仙王，他比巨力更清楚自己在面对什么。李长生身上那股气息已经不属仙王级别——他连和对方在同一个量级上都不算。

"联盟已经投降了。"李长生说，"你们所属的平行宇宙派遣代表到地月系参加了投降条约。签了。你们的仙王身份——从条约签订起——被废除。"

巨力仙王抬起头，眼神中闪过一道极其复杂的情绪。不是愤怒，不是仇恨，而是一种被时代抛弃的茫然。他修炼了万年，成了多元宇宙最纯粹的破坏力象征。然后他发现自己被关在一个透明笼子里，外面的世界已经变天了。没有人来救他。没有人为他抗争。他的宇宙——在他被俘的那一刻——选择了投降。

"打一场。"巨力仙王说。声音沙哑，但底子里有一种被压了很久的渴望，"死在你手里比死在牢笼里强。不是谈判，是打。我能用我能调用的全部力量，你可以用你想用的任何力量——没有规则。打一场。"

李长生沉默了几息。然后点了点头。

巨力仙王全力出拳。这一次他没有阵法的辅助，没有增幅，没有任何花哨。只是纯粹的——一万年积累的全部力量在一拳之内砸出。这是他的最后一拳，仙王级别物理攻击的天花板，足以击碎任何已知法则护盾。他不求活，只求在死亡前出一拳。

李长生没有躲。没有用混沌物质去中和。他只是抬起右手，用掌心接住了那一拳。不是用冥王令，不是用黄泉，不是用混沌——是掌心。纯粹的肉身掌心。

拳头砸在掌心，没有声音。力量被混沌物质的灰色从拳面吸入掌心，然后消失了——不是被抵消，不是被吸收，而是被"中和"到了存在与不存在之间的那个中间态。力量依然存在，但它无法作用于任何可以被摧毁的东西——因为它无法在混沌中保持"破坏"的指向性。

巨力仙王跪了下去。不是因为受伤，不是因为被打败——而是这一万年凝聚的全部力量，被一个八年前还是农民的男人用掌心轻描淡写地接住了。他万年的追求、他的全部修为根基、他对力量的极致理解——在混沌面前都毫无意义。那不是战败。那是意义崩塌。支撑他万年的东西在那一刻被从根部削断了。

"你赢了。"他低着头说。

万象仙王从始至终没有看这场战斗。他一直在看那片正在消散的混沌牢笼。他的脑子里不是在思考死亡——而是在思考"混沌"作为一种阵法材料会有什么效果。"如果——如果用混沌来替代阵法中的法则织线——那布出来的阵将不限于任何法则——"

他没有念完。因为混沌物质淹了上来。

不是李长生控制的。是混沌自然对他的"存在"产生了反应。一个在混沌面前还试图分析它如何被用于阵法的人，意识本身在分析过程中被混沌反向渗透了——他看到了混沌的本质——不是一层法则之上的东西，而是一切法则的根源。这个信息量对于仙王级意识来说太过庞大。万象仙王的意识在那一瞬间接受了全宇宙法则的总集——他无法拒绝——因为混沌不在意他是否想要或能否承受这个信息。

他用最后一丝尚存的意志抬头看着李长生。眼睛里有恐惧，但也有一种回光返照般的通透。"恭喜你——"他的声音沙哑，"你不是冥王了。你是——混沌。"

说完最后一个字，万象仙王闭上了眼睛。不是死亡——是意识承受不住而自我崩散——理论上还有恢复的可能，但意识架构被混沌渗透后撕裂得太严重，恢复可能需要几万年。那是另一种形式的死亡。

巨力仙王看着万象倒下。然后他抬头看着李长生。

"我能求你一件事吗？"

"说。"

"让我死在有土的地方。一万年都在虚空中打拳。最后想踩一下地。"

李长生低头看着他。然后伸出手，抓住了巨力仙王的肩膀。混沌物质打开了一条直通地球的通道——从虚空中落入黄土地上。

在地球某处平原上，巨力仙王踩了一下地。然后闭眼。没有挣扎，没有遗言。就这样走了。在黄土地上离世——像一粒回家的大种子。

（第577章完）

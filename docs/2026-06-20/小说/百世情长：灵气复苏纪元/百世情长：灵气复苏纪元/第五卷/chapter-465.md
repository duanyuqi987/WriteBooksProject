# 第四百六十五章 虚空中的守护者

心魔之后的路反而更难走了。

不是因为心魔的残余——是因为越往上走，虚空法则的压力就越大。上古飞升通道不是直接把人从下界传送到上界的——它是一级一级穿越下界和上界之间的六重天幕。每穿越一层天幕，空间的密度就增加一层。脚底下的阶梯开始变得沉重——不是重量上的重，是每走一步都像在粘稠的胶质中迈步。

林牧走在前面，他用炼虚初期的空间感知在阶梯上探路。炼虚期的最大特点就是对空间法则有了初步的掌控——他能感知到前方天幕中哪些区域的空间密度最高，哪些地方有虚空裂隙需要避开。

高处出现了一道横贯阶梯的黑色裂缝——不是普通的虚空裂隙。这道裂隙的形状太规整了——不是自然形成的。是一道封印。封印后面有一个身影。不是人——是某种更古老的存在。他在封印的另一侧蹲着，像一只孤独的石狮子守在某扇门的入口处。身影的身高大约有一丈，身体是由一种极其古老的陨石构成的——灰褐色的岩质表面布满了密密麻麻的金色符文。

"飞升道侣——"那个身影开口说。声音不是从他嘴中发出的，而是直接轰入他们二人的灵核。"六重天幕的守护者。每一对飞升道侣必须通过六位守护者的考验。我是第一重——岩尊。"

林牧和苏晚同时停下脚步。在他们面前的那道黑色裂缝缓慢张开，露出了封印后面的岩尊全身。岩尊站起身——他的全身都是由一种极沉极硬的陨铁岩构成，关节处连接的不是肉体而是滚动的岩浆。每一步踏在阶梯上都能把台阶踩出微小的凹痕。

"第一重考验——"岩尊说。"你们两个人的灵核在飞升过程中会被我强行分开。共振通道将被切断。你们各自在单独状态下扛住我一掌。扛得住——继续往上。扛不住——一起坠回下界。"

苏晚和林牧交换了一个眼神。同修共振是他们最强的武器——而岩尊要把这个武器拿走。这是上古飞升试炼的常见套路：考验的不是两个人一起能有多强——是分开之后各自能撑多久。因为在上界漫长的修行岁月中，没有一对道侣能永远共振——总有不得不分开的时候。考验的是"各自单独站得稳的能力"。

"来吧。"林牧说。

岩尊的右手抬起。那只由陨铁构成的大手在抬起时周围的虚空都在滋滋地缩小缩小——然后它朝林牧一掌拍下来。没有花招，没有术法绕弯——纯粹的重力。陨石和虚空合成的极限重量压缩在一掌之间。林牧在那一掌落下来时单独承受——苏晚被空间封印隔离在几丈之外的台阶上。共振通道断了。

巨掌落在林牧撑起的防护罩上。炼虚初期撑起的防护罩比化神期的厚了不止一个量级——因为炼虚修士可以调动的不是丹田的存量灵气，而是整个虚空的无限空间。他把周围十丈虚空内的空间之力全部拉入他的防护罩中——硬生生接住了这一掌。石阶在他脚下震颤，震得碎屑飞溅。但防护罩没有碎。他扛住了。

岩尊收掌，转向苏晚。同样的掌——同样的纯粹极限重力。苏晚没有撑防护罩——而是以剑气迎击。她在掌落下来时将全身的炼虚灵气凝聚在剑尖上，向正上方一刺。剑尖和巨掌的中心接触在一起——没有击穿。但剑气把掌心的冲击力向四周撕开了四条裂缝。裂缝吸走了大约一半的压力。剩下的一半压力被她以身体接住——双腿微屈，膝盖在微晃。但她也没有倒下。

岩尊收掌。沉默了片刻。

"万年来被这一掌打落的飞升道侣有七对。"岩尊说。"你们是第八对通过第一重的人。继续往上。"

封印在黑裂隙处重新闭合。岩尊石像般的身影在裂隙后面缓缓隐去。阶梯恢复了通往天顶的通道。林牧走到苏晚身边，握住她的手。她的剑尖还在因为刚刚那一掌在轻微地颤抖——但她握剑的手很稳。

"刚才那一剑——你是从上往下刺的吗？"林牧问。

"从下往上。掌心是空的——陨铁掌的中心压力最小。打穿不可能。但我可以撕开它分散它。"

"怎么知道的？"

"直觉。"苏晚把剑收回剑鞘。"你忘了我是财务。我天天做表。掌印也是表——边缘压强最大，中间有一小块空白的'可优化节点'。只需要找到它在哪。"

林牧看了她一眼。他嘴角那道极淡的笑意，在越往上走的过程中——变得越来越明显。

（第四百六十五章 完）

# 第283章 第九世的鸾凤离火

在晚牧居的炼剑室里，苏晚重新点燃了第九世留下来的鸾凤离火——那团被仙力封存了几百年的琥珀状火苗结晶。她用金火轻轻触碰结晶外层——结晶在触碰下缓慢融化并释放出那一缕双色焰——半金半银——和在凡间第一次燃烧时一样光鲜明亮。鸾凤离火在她的掌心跳动着——这团火焰是她在第九世用来淬炼最终版百世归一剑诀的丹火——也是她和林牧灵魂交融第二层完成时产生的共铸火焰。

她把离火放在炼剑室中央的剑炉中——让它在炉中心保持微弱但持续燃烧——不再用于淬剑——只作为一个常亮的火种。她说:"离火不用来造新的东西——它自身就是所有已经造成的东西在里面。从第一世金火开始到第九世——我的剑和你一直在同一炉中淬炼——离火是我们这些年来共同的回火灯。以后剑炉里永远有这朵火——哪怕我们出门——炼剑室有小锦鲤替我们看管——让它一直亮着——如果有人来晚牧亭说心里冷——就带他们进来借个火——不用说话——只是坐在这灯旁——等他们自己回暖。"

林牧从自己的仙元中抽出一根极其微弱的银丝——把它的一端放在离火焰舌上——另一端连接在自己窄身剑的旧痕上——银丝在火与剑之间搭成了一道极细极透明的光桥。他说:"这样——我在外面守别人时，剑上的旧痕还会和家里的离火同步微热——等于——无论多远都有根线连着晚牧居剑炉——这也是你以前给我配的感应线——现在升级成双抗干扰版——由离火做中继——永远不会再断。"

苏晚看着那条极细的银丝——和她当初第一世把剑魂印记打入他胸口时是同一种材质——都是他自身的仙元丝——现在她把这个比喻变成了实物:"以前那是'怕找不到你'的线——现在是'知道你在哪里但想摸摸你'的线——用途更新了——但材质不变。"她在离火旁放了他们第一世那根感应线的最初一段旧线圈——那是她飞升后在白谪的协助下用仙界技术复原出来的第一世线——由她和他的魂印交错编织而成——现在作为剑灯的一部分放在一起——新旧线在火舌旁并列——从感应线到旧剑痕、再到剑炉离火——象征着他们的联系演变。

第九世的琥珀结晶在火灯中慢慢融化——释放出的离火渐渐溢出结晶体并在灯中形成一道独特的小焰——火焰边缘是金色的、焰心是银色的——双色不全混——恰好各自留着它们的原有纯色互照。

在灯旁值班的小锦鲤（锦鲤分化出的幼体仙鲤——资质尚不成仙体但可在室内环境游动）会在每天的微弱焰动时轻轻吐泡——每一次泡碰到灯罩会发出一声极低的"叮"——很细微很淡——算不上声音——只是水流一点点压差——但苏晚说那声音恰好等于两人之间"不用说话也能互诉"的物理实现:泡泡把离火的热和剑痕的热凝结在一个瞬间——宣明他们两个所有已分未分或不再分的都不再会被单拉断。

在炼剑室门上，苏晚后来写了一块小木牌:"内有持火——欢迎借暖。若你正困于等待——请靠近——不要急——火焰曾经也只是一颗封在琥珀里的疲倦火种——是等到了今天才被再度加热——所以你的火也许也还在等被解封——可以坐这里——不算久——因灯常亮。"

# 第八百三十一章 羁绊加深

飞升之门运行第三年。林牧和苏晚的共鸣腔扩展到了一个前所未有的程度——不只在两个人之间共振，而是开始感应到整个修仙界的集体情绪。

这种扩展是在不知不觉中发生的。第一天，苏晚在调整交互层参数时忽然感应到一股遥远的焦虑——来自西域方向。她追溯了一下——发现是一个合道初境的年轻修士正在犹豫要不要申请飞升。他的焦虑不是因为害怕飞升——是因为他担心自己飞升后，他年迈的师父没有人照顾。

苏晚通过飞升之门的灵慰模块给他发了一条信息——不是AI生成的，是她亲自发的，"飞升之门永远在。你可以在师父百年之后再申请——不会过期。"

那个年轻修士收到信息后给门回了一道感恩的波动——这股波动在虚空中传播，被共鸣腔接收。苏晚在那一瞬间感受到了一种极其温暖的东西——不是灵力，不是法则，是一种纯粹的"被需要感"。

然后她发现林牧也同时感受到了——通过共鸣腔。他正坐在山谷里打坐，忽然心中泛起一阵暖意，就像是自己也收到了那份感恩。他立刻知道那是苏晚做的——不是通过语言，是通过共鸣腔中的情绪共振。

"苏晚——刚才那股暖意——"

"你收到了？"

"收到了。"

苏晚从门的控制室跑下来，兴奋地拉着他的手。不是因为一次成功的灵慰——是因为共鸣腔的扩展。他们不再是两个独立的人了——他们的共鸣已经强大到可以"代理"对方的情绪体验。不是读心术那样的精神入侵——而是一种自然的、舒适的"分享"。他开心她也开心——不需要理由。她感动他也感动——不需要语言。

"这意味着我们的灵魂融合已经超过了原初的'双修最高境界'——进入了新的阶段。"林牧说，"这个阶段在古籍中没有记载——因为从来没有人达到过。它不是修炼出来的——是在守门的过程中——被一万多次飞升者的感恩反哺出来的。"

"那我们该叫它什么？"

"共鸣扩展。或者——灵魂同化。"

"不好听。叫'心连心'。"

林牧嘴角动了一下——不是反对，是认了。八百年了她还是喜欢给复杂的修仙概念起通俗名字。但这个名字确实准确——心连心。不是灵连灵——是心。

当天夜里，两人做了一个实验。苏晚留在飞升之门的控制室继续修调一个交互参数，林牧去了山谷外的青云山顶——隔了十里地。他们同时在心中默念同一句话——"相互信任"。然后他们同时观察共鸣腔的反应。

共鸣腔在两个位置同时发出了同一个频率的波动。十里的距离没有造成任何衰减。波动像一道同时出现在两地的和弦——不是先后传输，是同时共鸣。这意味着他们的灵魂连接已经超越了空间的限制——不管距离多远，共鸣腔始终保持完全同步。

"如果我们中一个人在人间，另一个人在仙界——这种连接也能维持吗？"苏晚问。

"理论上可以。共鸣腔的本质不是灵力传输——是灵魂根源的共振。维度壁垒对灵魂的影响比灵力小得多。如果我飞升到仙界，而你留在人间——共鸣腔应该能继续保持。"

"那就不用着急了。我们一起守着门——直到所有人都飞升完——然后我们一起走。"

这是她说过的最"苏晚"的话——不加修饰，把复杂的问题归结到极简直白的一点上。她不需要长篇论证——只需要确认"我们不会分开"。

林牧握住她的手。

"好。一起守着。一起走。"

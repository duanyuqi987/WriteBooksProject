# 第165章 闭关百年

昆仑深处那个被遗忘的洞府，在十二年间没有见过一只人。

白鹿来过很多次。最后一次来的那只老白鹿带着一只小鹿，小鹿好奇地跑到台阶下部探着鼻尖。老白鹿在后面低低地叫了一声——它说不清为什么，但本能告诉它这里有一道"不能让小鹿靠近"的威压。那不是威胁——是一种高密度生命体在沉眠时散发的无形压迫感。动物天生就知道敬畏那类东西。

于是白鹿们也走了。洞府前面再次荒凉。但这一年的春天，台阶边的那层干苔中悄然长出了一棵细小的草芽——意味着地下的封印灵气开始微弱到不再阻碍植物生长。这说明封印外层的强度正在降低——因为中心那个人不再需要这么强的防御了。

他在突破。

林牧进入深定之后的第十二年，金丹内部那个微小的裂缝终于轰然裂开了。

不是痛苦的撕裂。是时间到了。金丹的中心原本有一枚极小的淡金色内核。十二年来内核一直在吸收外层金丹中那些已经有序排列了几百年的晶体能量，进行缓慢的内部重组。到了第十二年的某个无风的夜晚，内核饱和了。它开始向外推——把金丹的外壳从里向外顶出一圈整密的规则裂纹。这些裂纹非常整齐，一圈一圈从内往外排着，像是极其精密的分裂过程。金丹外表的硬壳开始一点一点剥落。每掉下一片，里面露出的新丹田内就有更多的灵光倾泻而出。

那灵光不是普通的灵力之光——而是"灵魂可入驻的光芒"，是意识居住的界限。元婴之所以叫"元婴"，是因为在这一阶段修士的丹田不再是简单的能量仓库——它变成了一个可以供给完整的人类意识居住的微型洞天。当灵力密度和高纯度到达元婴层次时，丹田会自动演化出容纳元魂空间。

林牧全程没有干预这个过程。因为干预没有任何意义——元婴只能自行化合。他唯一能做的是保持第三重定域中那个毫无波动的心境——让整个过程不被神识层面的恐慌破坏。他做到了。

第十二年的秋天，最后一层金丹外壳在灵息流动中化为一片淡金色的雾。雾气在丹田中旋绕了一会儿，然后缓缓向着丹室中央聚拢。聚拢形成的形状是一个极小的胚胎状轮廓。它看起来像一个胎儿——只有手指大小，通体透明，里面的淡金色光流比任何星辰都炫目。这就是元婴。

林牧的元魂随即从肉身各处退去——缩到那个小小的胚胎之内。从此他的"宿体"不再是他这副肉身。肉身依然是元婴级战力输出和物理显现，但他的生命核心已从肉身转入元婴。元婴不死，人就不会消亡——即使肉身粉碎了也可以重新修理。

而在元婴入住的那一刹那——洞府外昆仑夜空降临了一个极短暂的流星雨，二十多颗细小的流星在高原上空划过。这个天文现象不是自然产生——是元婴降临带来的天道反应。但这种级别的顿悟引起的异象很小，只在周围百里范围轻微扰动，不会引发广泛注意。

第十二年零十五天，林牧从定中醒来。

意识重新蔓延在身体每一寸的组织上。他发现手脚冰凉——猫已经用自己的体温护着他的腿足很久，但猫自己也冷——金丹级的猫妖体温也需要食物维持，这些年猫只靠着吃干粮和偶尔叼进来的路边野鼠过活——食储不足，有些消瘦。但猫把他的小腿严严实实地压在自己腹部下面，一直没挪开。林牧睁眼时低头看到猫——猫和他对视，老花镜背后的黄色猫眼里满是一片"你醒了啊"的惬意。然后猫站起来打了个大呵欠，把尾巴绷直从头到尾摇了一趟——然后一头从他腿上滑下床底，冲到了水盆边去喝水。

他站起来。身上的骨节咯嘣两声——躺十二年不动的后果。身体恢复流畅需要多天。他的灵力没有恢复全盛——元婴修士丹田是全空的，需要时间慢慢蓄灵填充。

走到洞府入口处，推开石扉。外面是一个清秋早亮的世界。阳光照在台阶上，石阶上的苔草更厚了。他站上去呼吸了十二年来第一口外面的空气——不错，昆仑冰风中带着一丝从北方冰海飘来的咸味。那正是天晶玉所在之地的气息。

"十二年——比你原本预计的早了一点。"锦鲤从水池中探头。它的语音比以前沉缓了一点点——十二年的修炼让它也晋级了一步。现在它是真正意义上的元婴级妖灵——虽然它还延续着鱼的外形，但水缸对它而言已不再必需。它只是习惯用那个小水壶——觉得那里更像个避风港。

"差不多。我出来早是因为她的第三世可能提前。"林牧闭眼，灵识以元婴级别往外横扫。整个昆仑主脉在他脑中像一张3D构造图一样展开——每一座山峰的内部岩质成分、每一条地下灵脉的流速、每只动物的心跳。再远的距离——把神识推向东方，穿过秦岭，越过黄河，抵达四川盆地西北缘——那里是他之前标记的那个小山区域。桃源村的中枢位置经十二年变化不大——而在他神识扫过去的刹那，一种极柔的颤动从那个方向上轻轻地敲了一下他的感知——胎息。不再是"将"——是"临产前"。粗略估计——第三世的苏晚将于三个月内降生。

他在心里给这个时间节点加了最强的标记。然后返回洞府开始两线处理。第一线:利用三个月的时间做好以下准备——元婴法术的适应性调整、元婴级防护阵布设在桃源村周边。然后——前往去接她。

去之前必须埋好洞府防御。毕竟这次一去就是三十年以上——元婴修士要在凡间隐匿四十余年，不能被任何大规模修仙战斗波及。他布下额外的长期防御阵。将老猫和锦鲤都带上。

在出发前的夜里，他独坐在石阶上看着星空。元婴星辉渐浓——他以前在金丹后期也能欣赏星空，但元婴是他前世上界仙人被关闭后最接近道境的修为。在这片星光底下他感受到了那个万年不见的"接近天道的感觉"。但这一次他没有沉溺——因为在东方极远的地方，有一道新生微光正在等他。那些星辰的炫美不足以分散他的注意力。他只是对星空轻轻说了句:"你也是她的一部分。你漂亮。但我要去找那一小块她了。"

天蒙蒙亮。林牧挑起背包——里面主要是丹鼎、法器、书籍和锦鲤的水壶。老猫依然缩在肩上的固定位置上。他把洞府石扉关闭，新的阵法从山壁外延伸至深林——封印会在未来四五十年内维持。

然后他御剑向东。不是直接走上空——用隐匿性的云行术御剑飞行，层云在高速飞行中剥离出两道气流。在他的飞行路径下方是绵延千里的雪山脉。稍纵即逝的山头、灰色山谷、融雪流出的小溪。

身形消失在天际间。最终他会降到那个小山谷，收起剑变为拄着竹杖的散步老者。没有人知道他刚刚从天上下来。村里人会以为他是翻山过来的外地客。然后他就会在村子的外围，找个空屋子安顿下来。静静等待。一直等到那声音——一个新生儿的啼哭打破桃源村的晨雾。他会从窗口抬起头。听许久。然后微微笑着自言自语道:"不是每次都能从头开始的——这一世终于可以赶上了。"

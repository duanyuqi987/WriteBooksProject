# 第九十三章 你要好好活着

三月。苏晚在病床上度过了第六十二个生日。

林牧买了一个巴掌大的小蛋糕——抹茶的，因为她最近两年喜欢抹茶味。他在商场找了很久，才找到一个可以现裱的小蛋糕。蛋糕上是一朵白色的奶油花。他没有写字。因为他知道苏晚不会在意有没有字。

他把蛋糕放进病房的冰箱。下午两点，苏晚睡醒了。她看见小桌子上的蛋糕，眉毛扬了一下。

"你怎么知道我想要抹茶的？"

"猜的。"

"你每次都猜对。"苏晚笑了。她笑起来的时候脸上有种薄薄的暖意，把病容冲淡了一点。她的声音比上周更弱了——护魂符在维持她的意识清醒，但封印的末端正在拉扯她的生命力，把她的身体从内部一点一点蚀空。

窗帘半拉，光线打到蛋糕上。林牧点上蜡烛——一支。她六十二岁。他说："许愿。"

苏晚看了看烛火，又看看他。她闭上眼睛，几秒后睁开。

"许好了？"

"许好了。"

"许了什么？"

"不能告诉你。说破不准。"苏晚把切好的蛋糕推到他面前。"这块给你。你尝尝。抹茶有点苦——你能接受吗？"

他咬了一口。微微的苦味在舌尖上化开，然后是甜。他咽下去。"不苦。挺好。"

苏晚低头吃自己那块。她吃得很少——米饭也只能吃小半碗了。医生说她的消化系统开始萎缩。不是器官本身的问题——是灵气。灵气量一旦超过身体能吸收的临界值，多余的部分会反噬。现在封印扩张到这个阶段，连最基本的灵气循环都在阻塞，更别说消化食物。她的体重只有四十二公斤。比健康时轻了二十多斤。

吃完蛋糕，她把靠垫移了一下，让后背可以垫得舒服一点。她对着窗户说："樱花开过了。现在是石榴花开的季节。"

"后院那棵石榴应该开花了。"林牧说。

"你回去看过吗？"

他摇头。"没有回去。一直在医院。"

"你回去看看。把石榴花拍张照片给我。我想看。用你的手机拍。"

林牧犹豫了一下。苏晚从来不骗他。她说想看石榴花就是真的想看石榴花。但他也清楚，她想让他离开医院——哪怕只走开几个小时。她觉得他太多天没呼吸外面空气了。

"好。"他站起来。"下午去。晚上回来。你想吃什么带过来？"

"山楂糕。那个不用嚼。"苏晚笑了笑。"别买太多。一两块就行。"

林牧开车回了小镇。

院子里，石榴树果然开花了。红彤彤的，一朵一朵夹在绿叶间。今年的花开得比往年都多——满树都是。猫在树下午睡。地上的草长了不少——小区没人打理。鱼缸里的水有些绿了，锦鲤却依然精神——二十年的老鱼了，它早把那一丝灵泉当成了日常惯例。林牧走到阳台，给鱼缸换了三分之一的水。锦鲤甩了一下尾巴，溅起一小朵水花。他把鱼食丢了几粒。

石榴树边，他拿出手机拍了几张花的照片。选好角度，尽量把满树的红都框进去。然后他走进屋。屋子里有苏晚的气息——放在沙发扶手上的一条薄毯，书架上的水彩画册，厨房窗台上晒着的一小碟干橘皮。冰箱上还贴着她留的便利贴："绿豆汤在冷藏室第二格。"

他把房子简简单单地收拾了一下——给盆栽文竹浇水，把阳台上的储物箱整理好，关好几个半开的抽屉。一切弄好之后，他靠着厨房门柱。房间里没有开电视、没有亮大灯，只有午后的日光从窗外照进来，把浮尘照成了一条一条亮白的光柱。沉寂——二十多年来第一次真正的沉寂。苏晚不在厨房轻哼歌，不在沙发上看剧，不在阳台上给花盆翻土。原来屋子可以这么安静。安静到能听到墙壁因为温度变化而发出的细微咔嗒声。

林牧站了一会，把石榴花的照片发到苏晚的手机上。附加一条微信："满树的。比去年多三分之一。"苏晚秒回——她还能打字，只是速度比以前慢了不少。过了一分钟才收到她的回复。

"好看！猫呢？鱼呢？"

他把猫和鱼也各拍了一张发过去。猫抬了抬眼皮，又睡。鱼吐了一串泡。苏晚回了三个竖大拇指的emoji表情——她字打得慢，但表情回复可以一键发送。

林牧放好手机，去了一趟菜市场。买了两块山楂糕——一块软的，适合苏晚吃；一块硬一点的，给她尝味道。然后他开车回医院。路上买了苏晚以前总说想喝的那家店的酸梅汤。店老板记得他。连续很多年了，他每周要买两杯。老板什么都没说，默默打包好，给了他一个稍微大一点的杯子——"这杯加了一点点蜂蜜，送她的。"

林牧点了点头，接过酸梅汤和山楂糕，开车回医院。到医院的时候是傍晚。夕阳从走廊尽头的大窗户涌进来，把整个走廊涂成橘色。他推开苏晚的病房门。里面亮着灯。

苏晚今天半坐着。她靠着升高的床头在看书——水彩画册合集。她看得很慢，旁边放着一副老花镜。看见林牧进来，她把手里的画册向他展了展。"这张画得比较满意——画的是石榴树。去年六月的。你看这朵花，我画了三次才不歪。"

她把画册递过来。林牧接过画册认真看了一眼——纸面上有微微的凹凸，是她下笔过重留下的水痕。他指着花蕊说："这个颜色调得准。"

"用了永固玫红加了一点点钛白——"苏晚讲了两句又停住。"算了，你也不懂颜料。反正好看就对了。酸梅汤——你买了酸梅汤？！"

林牧把酸梅汤递过去。她用吸管吸了一口，眼睛亮了一下。

"还是原来那家店的。"

"嗯。老板说送你一点蜂蜜。"

"那个老板真好。下次我好了——"她停住了。"——还是下次见面再说谢谢吧。"

出院以后。当面去说。她没有说那三个字。林牧听得出来。他低着头看画册。把他刚刚在屋里感受到的那股安静，用画册挡住了脸。

又过了一个多星期。

一天晚上，她忽然醒过来，精神状态空前地好——好得有些不正常。她的思路极清楚，说话也连贯，脸上的灰白色退了，甚至有一点苍白的血色。林牧知道这是什么——回光。医学上叫"最终清醒期"。灵气层面叫"封印最后集合阶段"——所有被消耗的残余生命力会在封印回收前集中释放一次，像蜡烛灭之前忽然窜高了一下火焰。

苏晚也知道了。她没有说破。但她看着林牧的眼神变深了——他一直坐在她床边握她的手，她就反过来用指甲轻挠他的掌面。像安抚一只大动物。

"你把衣柜里的那件衣服穿一下。"她说。

"什么衣服？"

"墨绿色的那件。你穿那个好看。以前出门开会总穿。现在整天穿个旧T恤也不换换。"

林牧顿了顿，说："回去换。"

"现在换。"

"现在在医院——"

"打开床头柜下面那个抽屉。"

林牧拉开抽屉。里面果然叠着她说的那件墨绿色衬衫——还带着洗衣液的味道。她早就让人带过来了。搁在抽屉里没告诉他，等这个时机。

他拿着衬衫，去洗手间换上。走出来以后，苏晚认认真真地看了他一会儿。她点点头。"还是这件好看。你以后就要这样穿。不要天天穿旧衣服。"

"好。"他说。声音在喉咙里哽了一下。

"还有几件事——"苏晚把被子往上拢了拢。她的手指虽然瘦，但动作依然干脆。"一、不要因为我就不笑。二、你继续修炼。金丹、元婴，能走多远走多远。别半途停下。三——"她停了停。"如果你将来遇到别人——"

"苏晚。"

"你让我说完。"她的目光定在他脸上。这次她毫不退让。"如果将来你遇到别人，能让你开心，能让你的修炼有意义——不要因为我挡在前面。你是修士，几百年的路在前面。这中间如果有人能陪你走下去——也让我安心。"

林牧站着一动不动，低头看着她——不说话。过了几秒，他忽然蹲下来，把脸埋在她手心里。她的手凉凉的，像浸泡在温水里的玉，冷中有一丝体温。他的肩膀轻微地抽了两下。就两下。然后他抬起头。

他点了头。他做不到。但他答应了。

"你要好好活着。"苏晚说。她的声音里没有虚弱。是那缕残存的意志力用在了最后出口的一句话。

"我会。"林牧说。

她安心了一些。她把头放回枕头。"好了。不说了。这会是凌晨吧？外面天还是黑的。"

"四点半。"

"就快天亮了。你也翻一下被子——天快亮的时候最冷。别感冒。"她说了这些很琐碎的话。护士说过，回光期的人往往说日常琐事——那是他们最在意的东西在打包。

天亮之前，苏晚又睡着了。这一次睡得很沉很安静。她的呼吸又变得很浅。但是脸上有一种自在。仿佛最后想说的话都找他当面说完了。

林牧握着她的手。墨绿色衬衫的袖口被他无意中拽皱了一点。他没有在意。他低头看她的脸——看了一整夜。窗外的天空从完全的漆黑变得越来越青，然后天边冒出第一道金丝。樱花树上，一只早起的麻雀开始在枝头跳动。第一缕晨光终于照进了病房。

她还活着。封印没有收走她。他还有时间。

（第九十三章 完）

# 第552章 第三位仙王与冥王一战

巨树顶端，一道人影缓缓降下。

他的速度不快——不是瞬移，不是飞遁，是纯粹用肉身在虚空中行走。每一步落下，脚下的空间就会自动凝出一级台阶。那不是灵气凝成的台阶，而是空间本身在主动为他服务。在他面前，空间的法则不是被改变，而是自愿服从。

第三位仙王。

李长生透过冥王令感应到了他的力量层级——比炎烬仙王更强。炎烬仙王是镇守使，负责看守这座堡垒。而这一位——他的气息穿透力远超炎烬。他是个纯粹的战士。

"渊虹仙王。"第三位仙王站定在距离战场三百里的位置，用平淡的语气自我介绍。他穿着一身黑色的长袍，袍摆上绣着银色的星河纹路。腰间挂着一把剑——剑柄普通、剑鞘普通、连剑穗都是最普通的黑色丝线。但那股从剑鞘里渗出来的剑气，让陈霜在诸天号舰桥里猛地握紧了霜降剑。

"那把剑——"陈霜的眼睛里闪过一道锐光。

"怎么了？"小王问。

"那把剑是活的。"陈霜说，"不是剑灵。是剑本身是活的。它曾经是一个剑修的脊椎骨。"

舰桥里所有人都倒吸了一口凉气。

用剑修的脊椎骨炼剑——这是禁术中的禁术。剑修一生以剑为伴，人剑合一。死后脊椎骨残留的剑意最为纯粹。将这种脊骨炼成剑，等于囚禁了那个剑修的全部剑道。这把剑每杀死一个人，被囚禁的剑修意志就多一道伤口。

"渊虹仙王——"李长生念着这个名字，抬起头看向黑袍仙王，"你身后那把剑，囚禁的是谁的脊骨？"

渊虹仙王沉默了一息。

"上上任冥王麾下，第一剑修——江流。"

李长生的瞳孔微微收缩。

冥王令在这一刻剧烈震动起来。不是愤怒——是悲伤。九块碎片中的某一块，曾经在黄泉之底浸泡万年，吸收了太多被冥王麾下将士的不甘。而"江流"这个名字——是冥王记忆中最深的几道伤痕之一。江流，冥王座下第一剑修，万年前那场战役中为掩护冥王撤退，独自挡住了三位诸神的追杀。最后尸骨无存。

现在知道了。他的尸骨在这里。被铸成了一把剑。

"一万两千年前，"渊虹仙王平静地说，"江流的剑道确实很强。他死了以后，他的脊骨依然保留着完整的剑意。我们花了两千年才把它炼制成剑。又花了三千年才驯服它的抵抗。再花了七千年才彻底抹去它的意志。现在它是我的佩剑，不叫江流。叫——江骨。"

最后两个字落下的时候，渊虹仙王拔出了剑。

那是一柄晶莹剔透的剑。剑身完全由骨质构成，每一节脊椎骨都清晰可见。在剑身内部，有一道极淡极淡的人形光影——那是江流被囚禁一万两千年后残存的最后一点意识碎片。它已经认不出谁是谁了，只是在本能地抗拒握剑的人。

"江前辈——"李长生低声说，"让您久等了。"

渊虹仙王出剑。

那一剑的速度并不快——肉眼完全可以追踪剑的轨迹。但李长生感觉到了不对：这一剑的影响范围不是现在。渊虹仙王的剑意穿透了时间。他在过去、现在、未来三个时间点上同时刺出了这一剑。不管你躲开哪一剑，另外两剑都会命中。

这就是第三平行宇宙仙王的战斗方式。在这个时间维度多了一层的世界里，仙王级的剑修可以将自己的攻击分布在时间轴上。你防住了现在，防不住过去。防住了过去，防不住未来。

李长生没有躲。

他抬起右手，冥王令爆发出从未有过的强光。暗金色的光芒以他为中心向四面八方扩散——不是防御，不是攻击，而是"存在固化"。冥气在他的周围形成了一道时间绝缘层。在这个绝缘层内，时间只是时间——没有多出来的那一维。

过去之剑刺在时间绝缘层上，剑意被弹回了过去。

现在之剑刺在时间绝缘层上，被冥王令直接否定。

未来之剑——这道最强的攻击——在接触到时间绝缘层之前就被李长生的左手接住了。不是握剑身，不是挡剑锋。他的左手穿透了时间绝缘层，穿透了未来时间线的屏障，一把抓住了渊虹仙王在未来时间点上的手腕。

渊虹仙王的表情终于变了。

"你能抓住未来的我？"

"冥气超越时间。"李长生说，"你说过的话自己忘了？"

他左手发力，将未来时间线上的渊虹仙王拉向现在。两个时间点上的渊虹仙王同时向李长生撞了过来——这种时间悖论足以撕裂任何仙王以下修士的肉身。

但渊虹仙王毕竟是仙王。

他在悖论即将发生的瞬间做了一个选择——他主动斩杀了两秒后的自己。未来的渊虹仙王消失了，时间线被强行收束。代价是他的左臂上出现了一道深可见骨的伤口——那是斩杀自己所付出的反噬。

"有意思。"渊虹仙王低头看了一眼自己的伤口，然后抬头看着李长生，"他比以前更强了。"

这个"他"指的是上一任冥王。

"不过——"渊虹仙王缓缓举起了江骨剑，"我也是。"

在那一瞬间，巨树的根部传来了震动。第二道仙王气息——那个一直在根部沉睡的存在——睁开了眼睛。

三位仙王。同时苏醒。

而李长生身后，诸天号上，只有陈霜一个仙王级的战力。

（第552章完）

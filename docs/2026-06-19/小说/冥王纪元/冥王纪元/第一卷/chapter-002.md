# 第002章 农民李长生，三十岁一无所有

李长生蹲在地头上，嘴里叼着根狗尾巴草。

他三十岁，皮肤被太阳晒得黝黑，手掌宽厚粗糙，上面全是老茧。他穿着一件灰扑扑的旧T恤，裤腿上沾满泥土。脚上是一双解放鞋，鞋底快磨平了。

面前是五亩地。三亩种了玉米，两亩种了小麦。

这就是他的全部。

村子叫李家庄，在河北一个不起眼的角落里，离最近的县城有四十里土路。全村一百来户人家，年轻人基本上都出去打工了，剩下的大多是老人和小孩。李长生是村里为数不多留下来的壮年劳力。

村子不大。一条土路从西头穿到东头，两边是红砖房和土坯房交错排列。村口有棵两百年的大槐树，树下一块青石板，老得磨出了光。每天傍晚，几个老头老太太会坐在树下说话。现在他们说的全是天上那道裂缝——谁也不知道那是啥，有人说是龙翻身，有人说是天显灵，有人说是上面搞的秘密武器试验。

李长生从不参与这些讨论。他觉得说这些没用。天上裂了，地里的玉米还是一天两指高的往上长，井里的水还是一挑一挑地挑。日子该怎么过还是怎么过。

不是他不想出去。是走不了。

他爸死得早，干活时脑溢血，倒在麦田里就没起来。那年李长生十九岁。他妈身子本来就不大好，男人走后不到两年也去了。李长生成了孤儿，守着爹妈留下的五亩地和一座老宅子，一守就是十年。

他不是没想过出去。二十三岁那年，他去县城工地搬过半年砖，结果隔壁王婶打电话来说他家的牛病了，家里的玉米地没人浇水，全蔫了。他连夜赶回来，看着蔫黄的玉米苗子，蹲地头抽了半宿烟。第二天一早，他不走了。

从那以后，他就安安心心当了农民。

"长生！长生！"远处传来喊声。

李长生抬头，看见村长李德贵骑着一辆破电动车从土路上开过来。李德贵六十多岁，圆脸，说话大嗓门，是李长生的远房堂叔。

"德贵叔。"李长生站起来。

"你还蹲这儿呢？"李德贵把电动车停下来，抹了把汗，"今儿个上面来通知了，说要搞什么'新农合补充保险'，一个人交二百八。你去不去交？"

李长生想了想："交吧。"

"那你下午把钱送到村委会来。"

"行。"

李德贵瞥了他一眼，语气忽然变了："长生啊，你也老大不小了。三十了吧？"

"嗯。"

"我跟你这么大的时候，儿子都上小学了。你这——"李德贵叹了口气，"要不要叔给你介绍一个？隔壁马家屯有个寡妇，带个娃，人挺勤快——"

"不用了，德贵叔。"李长生打断他，语气平静，"我这样挺好。"

"好个屁！你一个人守着几亩地，一年到头能挣几个钱？"

李长生没吭声，低头踢了一脚土坷垃。

李德贵看了他一会儿，摇了摇头，骑着电动车突突突地走了。

李长生重新蹲下来。他看着眼前的麦田，六月的麦子正在灌浆，穗子沉甸甸地垂着。阳光晒在麦穗上，泛出一层金黄色的光。

他喜欢看麦子。从播种到出苗，从拔节到灌浆，每一寸生长都实实在在。不像人这一辈子，总有些说不清道不明的东西。

天边的裂缝还在发光。李长生注意到了，但他没太在意。天上裂不裂关他什么事？他关心的是今年麦子能不能卖个好价钱，玉米地里虫子多不多。

他站起来，扛起锄头往家走。

李家的老宅在村子最东头，出了村沿一条土路走两百米就到了。三间砖瓦房，一个土院子，院子里堆着柴火，墙角种了几棵辣椒。房子是七十年代他爷爷盖的，墙皮有些剥落，但还能住。

堂屋里供着他爹妈的遗像。黑白照片里，他爹严肃地看着镜头，他妈笑吟吟的。他爹叫李大河，一辈子没出过县城，干了一辈子农活。他妈叫王桂兰，村里出名的利索人，做的一手好针线，可惜身子骨一直不好。李长生在遗像前站了一会儿，倒了杯水放在香炉前。

"爹，妈，我挺好的。"他低声说。

这是他每天都会做的事。没人教过他，就是觉得应该这么做。有时候他会想起他爹活着的时候说的话。他爹说，人就像地里的麦子，种下了，长一季，收了，再种一季。没什么大道理，就这么一茬一茬的，一代一代的。他不指望李长生能干啥大事，只要别把祖上传下来的地给败了就行。

李长生没败地。不但没败，还多租了邻村老赵家的两亩水浇地。一年到头刨去种子化肥，能剩个万把块钱。不多，但够他一个人吃饭穿衣。

午饭是馒头就咸菜。不是吃不起好的，是一个人懒得做。他坐在院子里的石墩上，一边嚼馒头一边看天。天上的裂缝还在，颜色淡了些，但依然能看出一道光痕横贯天际。

他想起村头老刘上午说的话。老刘骑着三轮车从镇上回来，说镇上的人炸锅了，手机没信号了，电视雪花屏了，汽车打不着火了。有人说要打仗了，有人说世界末日了，有人跪在地上磕头。

李长生觉得不可能是世界末日。他见过世界末日——他妈走的那天，他觉得就是世界末日了。可第二天早上起来，太阳照常升起，地里的麦子还得收，猪还得喂。世界不会末日的，日子还得过。

下午他去地里浇水。

玉米正长到半人高，叶子绿油油的。李长生从地头的老井里打水，一挑一挑往地里挑。井水冰凉，泼在泥土上滋滋响。他一口气挑了二十担，整个后背都湿透了。

挑了水，他又蹲在地里拔了拔草。玉米根部的杂草长得比玉米还快，不拔干净了，肥料全让草吃了。他一根一根地拔，拔得仔细，连手指甲缝里都塞满了泥。太阳晒得后脖颈生疼，汗顺着脊椎沟往下淌，把裤腰带都浸透了。

干完活，他坐在田埂上歇着。六月傍晚的风有点凉，吹在身上挺舒服。他掏出手机看了看——没信号，一片白屏。手机是三年前买的，七八百块的国产机，平时也就打个电话看看天气预报，现在连信号都没了。

李长生把手机揣回兜里，干脆不看。

他看着远处的村庄，炊烟升起来，一户两户的，在落日里变成淡蓝色。狗叫声零碎地响着。有孩子在哭，有大人在喊。一切和往常没什么两样。村口大槐树下那几个老头的影子还凑在一起，远远能听见他们在争辩什么——大概是天上那道裂缝的事。

天塌下来了？他抬头看看那道裂缝。就算天真的塌下来，地里的玉米也得浇水，明天该干什么还得干什么。

回家路上，他绕到村口小卖部。小卖部是王寡妇开的，四十来岁，人长得不算好看但利索能干。铺子不大，就一间门面，卖些油盐酱醋、烟酒糖茶。李长生买了一包最便宜的烟和一斤散装盐。

"长生，听说了没？"王寡妇一边称盐一边压低声音，"镇上的人全炸了。老孙家的货车打不着火，停在半道上。银行的门打不开了——都是电子锁。到处都乱了。"她把盐包递过来，多看了他一眼，"你一个人住村东头，可得小心点。这两天不太平。"

"知道了。"李长生接过盐，付了钱。

王寡妇看着他，嘴张了张，似乎还想说什么，最后只是叹了口气。

李长生知道她想说什么。这两年王寡妇托人来说过好几次媒，都被他婉拒了。不是看不上她——王寡妇是个会过日子的人，带着个八岁的闺女，把铺子经营得有条有理。只是李长生觉得自己这条件，娶谁都是耽误谁。

三十岁的李长生，没结婚，没存款，守着一座老宅子五亩地。

他不知道自己这辈子还能有什么变化。父母已经不在了，出远门打工又放心不下家里那点东西。他一辈子大概就这样了——种地、吃饭、睡觉，然后有一天也像他爹一样，倒在田里，被埋在祖坟边上。

他不知道，今晚回去之后，他的人生会彻底改变。

夜色暗下来。李长生扛着锄头，沿着土路往回走。

路过自家祖坟那片地的时候，他下意识地看了一眼。几个土坟包安安静静地立在暮色里，坟头的草白了他都懒得去割。

好像有什么声音。

李长生站住了。

那声音很轻，像风吹过墙缝的呜咽，又像什么东西在泥土深处翻动。他侧着耳朵听了一会儿，又没了。

"耳鸣。"他嘟囔了一句，继续往回走。

走了十来步，他忽然又停下来。

回头看去，祖坟那边的泥土缝隙里，似乎透出了一丝微弱的光。

（第002章完）

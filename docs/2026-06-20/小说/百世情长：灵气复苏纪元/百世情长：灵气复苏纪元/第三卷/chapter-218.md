# 第218章 每一剑都痛在心里

第四世苏晚刺向林牧的那十二剑，发生在周烈倒台的前一天夜里。

那晚没有月亮。云层厚厚地压在山脊上，把整个秦岭裹成一座不透光的巨大棺材。苏晚在赤霄宗内部做了一些极其危险的行动——她把锁识珠里的内容通过周小月秘密传给了赤霄宗的执法堂长老。执法堂长老姓宋，年纪很大，是整个宗门内唯一不被周烈收买的高层。宋长老拿到锁识珠的第一时间没有声张——而是关起门用了整整两个时辰独自验证珠中记忆的真伪。验证完之后，他对着珠中画面沉默了很久——然后对苏晚说了三个字："今晚动手。"

但在宋长老下令之前，周烈察觉到了异常。他的内线在库房附近发现了苏晚的异常活动——她不是去药库做杂务而是去执法堂附近。周烈立刻在暗网上通缉了苏晚——罪名是"通敌"。通敌罪在赤霄宗是可以不经审判就处死的——不审，直接执行。而且执行人必须是被通缉者的直属同门——这是赤霄宗的铁律——为了让"除魔"的决心刻进每一个弟子的血液里。

周烈选中了苏晚的直接上级——她的教导师傅韩师姐。韩师姐是金丹初期，剑法刚猛。她在赤霄宗二十年，一直对周烈极度忠心。周烈告诉她苏晚"勾结散修"，并给她看了伪造的证据——一段被剪接过半的灵识画面。韩师姐看完后咬着牙点了头。

苏晚在回营地的路上被韩师姐截住——不是在营地里，是在营地外一里的那片被烧毁的树林中。韩师姐身后跟着四个执法的弟子。苏晚在阴影里看到她们——停下脚步，手放在剑上——然后看清了领头人是自己的韩师姐。

"师姐——我有证据——"

"别叫师姐。"韩师姐的声音冰冷，眼眶却红透了。"苏晚——我教了你五年的基础剑法——我教你怎么握剑——怎么出剑——怎么在最难的时候稳住剑心。结果你用我教你的剑去通敌？"

苏晚想解释——但她身边还有四个执法的同门。她们都被周烈调令过了——她们收到的命令是"当场处决"——不会给她任何解释的机会。

剑光在她解释的间隙落下来。第一剑是韩师姐的独门剑招——"断风十三剑"的起手式。苏晚被迫拔剑迎战。她的剑法和韩师姐同源——每一招她都认得——因为每一招都是韩师姐手把手教的。现在教她这些剑法的手正在用这些剑法砍她。

她挡住了前三剑。第四剑她没完全挡住——剑锋割开了她左肩——血沿着她的内门弟子服快速晕红。她退到一块半塌的石壁前——就在离林牧曾经多次和她相遇的那个缺口不到三里，心里想的是:如果死在这里，锁识珠的备份在周小月手里——小月能完成任务。

然后一道灰影从高处砸进战场。

林牧就像是从夜空本身剥离出来的一道人形。他横在苏晚和韩师姐之间——和之前每次出现时的动作完全相反——这一次他拔了剑。他的剑和韩师姐的剑接触时炸出的那道灵力压差让周围所有人退了数步。他不是来提醒的——是来护她的，面对赤霄宗也无任何犹豫。

韩师姐看他的出现大声斥责苏晚说"你看！他和散修同流！"。苏晚站在他身后——仰望着他的背影重复着心里冒出来四个字——不是"同流"——是"不是的"。但她没说出口。因为韩师姐的下一剑已经直接朝向林牧的咽喉劈过来。

林牧格开了。他一直守——不攻。韩师姐连续攻了十二剑。每一剑都把断风剑法的杀力推到极限——剑剑致命。林牧用窄身剑架住剑招——每一次都卡在剑招的关键发力节点上，让剑锋偏转的同时又不会反伤对方。

苏晚站在他身后数着他在格挡过程中的角度调整。他本可以轻松击败韩师姐——元婴对金丹，胜负没有任何悬念。但他每一招都用了最克制最友善的方式去化解——因为韩师姐是她的师父。林牧不想让她在失去宗门的最后一晚再失去她最尊敬的师父。

十二剑过后韩师姐的剑被荡得脱手而出嵌进烧焦的树干。她气喘吁吁，手被震麻，眼神里却还有不逊。林牧看着她说:"你不错——她的剑法很好是因为你教得对。但你现在被人当棋子使——你要自己去看证据——不是听别人说的。"他把锁识珠的复制品放在韩师姐脚边——然后收剑让到一旁的苏晚身前。"信不信你自己决定。"

韩师姐捡起珠子，用灵识读取——然后站在原地很久——身体微微晃动了一下。

执法堂的宋长老几乎同时带着另外几个反间长老赶到——把周烈包围在了他的独立密室里。行动在大概一炷香的时间结束——周烈的被捕震惊了整个赤霄宗。他掌管的宗门灵石库和他用来收买金牙的所有假单据被宋长老当场封存——罪名公开通报。散修联合会随即收到赤霄宗的通报——宣布双方立即停火。

苏晚在周烈被抓的批文书发到她手中之前——走到韩师姐面前。两个人都站着沉默了一刻钟——最后韩师姐伸手摸了摸她被割破的肩甲："上药了吗？"苏晚抿嘴摇头——韩师姐拿出自己的药瓶给她上药。韩师姐的手指在她伤口上悬着时问了一句:"他愿意为你挨那么多剑——你以后要怎么做？"

苏晚没有回答。她看着远处站在断崖边正对着冷风向他解释这一切的林牧——她的心像在被十二把不存在的剑反复割伤。因为每一剑都是他对她的保护——而她每一次都无法报答，只能看着他的背影在战火和黑夜里越站越薄。她意识到:第四世以来他从来没让她受过任何不可挽回的伤——但他在被她连续追刺的那些天里——被她同门猜疑、被她恨过，被她用剑刺过衣襟——他从没有躲开她的剑范围，宁愿被她的剑刺中也不愿她因为没对他出剑而被周烈的眼线处死。

她终于明白：他根本不是躲不开她的剑——他是怕她没能刺他而受同门惩罚。他宁愿被自己用四世等在世上的人戳中——都不愿她为他受一点行政意义上的痛。

那一刻苏晚在李兆送来的战后火炉旁坐了一整夜。剑卧在腿上。炉火晃在她脸上，把泪光染成了火红色。她没有去他身边——不是不想去。是她觉得自己对他欠的东西已经重到再用"谢谢"去说就很轻。她只能在这里守着火——让他不用再担心她在火边。而她知道在断崖彼处他也在守着同一块天空下的她的安全。

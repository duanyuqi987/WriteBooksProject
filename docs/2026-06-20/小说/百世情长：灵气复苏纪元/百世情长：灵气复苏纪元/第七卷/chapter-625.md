# 第六百二十五章 修仙界的改变

"强者心性改造计划"在实施半年后，出现了林牧和苏晚都没有预料到的连锁反应。

华山派的大师兄公开自己的强迫症后，他的一个师弟私下找到他说："我一直以为我自己的那些奇怪习惯是修炼的障碍。现在我觉得不是障碍了——是可以管理的一部分。"师弟后来把管理强迫倾向的方法写成了小册子，取名为《不完美修炼手册》，在华山地界的小坊市里卖出了上千本。销量超过了同期所有的功法秘籍。

蜀山剑派最以冷酷出名的剑堂堂主——一个斩妖无数的元婴女剑修——看了手册后在门派例会上说了一句话："我其实怕黑。怕了几百年了。每次夜间出巡我都会提前让自己绷得很紧——因为紧绷感可以暂时覆盖恐惧。今天我不想知道这种逻辑了——我想知道的是：承认怕黑以后，剑会不会慢？"第二天她主动申请了夜间巡山——不是为了证明自己不怕了，是为了测试"承认怕黑之后战斗力会不会降"。测试结果是：不会。剑速依然不减。反而因为不用额外消耗注意力去绷紧——她的感知力更敏锐了。

太湖散修联盟在半年里从两百人涨到了两千人。加入的人都走同一个流程：先在门口读一份"成员公开缺陷书"——不是联盟的缺陷，是现有成员们自愿公开的个人缺陷。读完之后新加入的人愿意的话也可以自己写一份贴在告示板上。告示板上的便签颜色五花八门——黄的、红的、蓝的、绿的。有人写"我练剑的时候总是歪左脚"，有人写"我一紧张就打嗝"，有人写"我怕我的灵根不好——怕了二十年，不敢测"。第三张便签下面附了十几条回复——不是嘲笑，不是安慰，是"我之前测出来是下品木灵根，现在金丹中期了。灵根不是天花板，是你的起点。"

林牧和苏晚去太湖散修联盟走访那天，看到告示板前站着的乌压压一堆人——有哭的，有笑的，有默默用小指甲刮掉便签边缘卷曲的胶带又重新贴上的。

苏晚拉着林牧的袖子，把他领到了告示板前的一个角落。角落里有一张极小的红色便签——字迹歪歪扭扭，大概是一个刚学会写字的成年散修留下的：

"我很怕被人看不起。但我今天站在这里了。我叫赵三。"

林牧看了那张便签很久。然后他从口袋里掏出自己的便签本——黄色的。他写了一句什么话，撕下来，贴在赵三那张红色便签旁边。他写的字很大——大到隔好几步也能看清：

"我叫林牧。我也曾经怕被人看不起。所以我从来不主动说话。——后来有人让我知道，不完美的我也是可以被接受的。赵三，你也在名单里。"

苏晚没有制止他。她知道他不想当偶像。但有时候一句"我也怕"从一个公认的强者嘴里说出来的力量，大于一千句"你不要怕"。

从太湖回到家的路上，苏晚忽然说了一个想法：

"我们可以在各地宗门之间建立一个定期交流制度——就叫'缺陷分享会'。每个宗门选一个代表，每个月在一个地方聚一次。不用谈功法——只谈自己这个月发现了什么新弱点、怎么应对的。不是比赛——是分享。"

林牧想了想。"可行。但如果变成'比惨大会'就完蛋了。"

"所以要定两个规则：第一，只谈自己发现的，不谈别人指出的。第二，每次分享完弱点之后，必须附加一段'这个月我为自己做了什么改善'。"

"你打算跟多少人提？"

"所有的。华山、蜀山、龙虎山、太湖、南海仙岛、昆仑遗族、北境魔修——"

"魔修也一起？"

"他们都参与的话——那些因为偏见隔绝了几千年的隔膜，说不定因为'大家都有缺陷'这个共同点而变薄。"

林牧看着她。夕阳把她侧脸照亮——她的眼神和他前世在天台上第一次看到时的一样：坚定、清澈，有一种不愿放弃任何人的韧性。

"你来做这件事怎么样？"林牧说。"不是替我代表——是以你的名义。以苏晚的名义发起'缺陷分享会'。我的名义太重了——会让人觉得这是权威在教他们做人。你的名义不一样——你是那个砸过静心阵石板的苏晚。他们更愿意听一个砸过石板的人谈不完美。"

苏晚看着他。她沉默了几息——不是犹豫，是被惊喜砸中了。她一直以"林牧的伴侣"身份出现在修仙界视野中。她知道这是事实——她确实是他的伴侣。但她也有自己的声音、自己的想法、自己的行动力。他刚才那句话等于告诉她：你不需要在我的影子里。你可以自己走到光下。

"好。"她说。

（第六百二十五章 完）

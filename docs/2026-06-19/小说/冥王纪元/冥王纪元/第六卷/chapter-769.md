# 第769章 快递员老陈的后代指挥舰队

磐石工程第七年，帝国舰队迎来了一次重要的换血。

原帝国征北大将军、快递员老陈的直系曾孙陈远志被任命为帝国第三舰队的总指挥官。这项任命在帝国高层近乎全票通过了——不是因为他的姓氏，而是因为在过去七年的归源会清剿和封禁加固保卫任务中，这位老陈的第四代已经用自己的战绩证明了他是新生代将领中最出色的。

陈远志今年二十六岁了。他十四岁加入帝国舰队少年训练班，十六岁作为一名最低级别的巡逻快艇驾驶员在边境星域执行任务，十九岁主动加入封禁黑洞的探险队，二十三岁在归源会钳形攻击中率领渗透小队的侧翼小组击退了三波归源会近防部队的反扑。在磐石工程的七年时间内，他先后参与过十二起维度裂缝的紧急封堵行动，三次率领舰队在维度膜崩解边缘顶住了大规模的舰群冲击。

老陈如果有在天之灵，应该会高兴得直拍桌子。他孙子陈远志的外表不太像他——长相更偏母亲那一边，剑眉星目，没有老陈当年那副常年送货晒得黝黑的中年沧桑脸。但他的性格和老陈是一个模子刻出来的：话不多、从不摆架子、遇到危险习惯自己先上、打完仗第一件事不是庆功——是带工程队在废墟上修田埂。

"你的指挥风格和你太爷爷不一样。"封玄在一次作战会议后会私下对陈远志说。

"哪里不一样？"

"你太爷爷打仗靠的是'土办法'——他善于利用地形和节奏上的不对称优势，在对方最没想到的地方发动突击。你打仗靠的是'速度'——"

封玄调出了陈远志最近几次行动的完整的战术记录。每一场战斗都呈现着同一个突出的风格：极其高速的机动，在敌人还没有完成决策周期之前就打入对方防线的关键节点。用最小兵力实现最大突袭效果。

"这是因为老陈他是从地面打上来的。他习惯于用环境作为武器。"封玄解释道，"而你——从开始修行就在高速灵能舰队中长大。你习惯于用光速做决策。"

"有什么问题吗？"

"没有。你有你太爷爷所有的优点，但你的思维方式更适应这个时代。我不是在挑剔你——我在评价一个会把老陈的子孙继续翻成历史的新章节的开始。"

陈远志没有回话。他只是拿起青芒剑，去了训练场。

第三舰队的编制和其他帝国主力舰队不同。它主要负责的不是正面作战，而是维度层面灵能运输线的护卫——保护每一艘向加固站运送关键材料的货舰不受维隙渗入的影响。这个任务没有"攻"和"守"的明确界限。因为在维度夹层中，异常空间波动随时可能像山洪一样突然涌出——护运舰必须在毫秒级的时间内做出反应，将货运船拖出危险区。

这意味着第三舰队的所有舰艇都经过了特殊的引擎升级——朔源引擎的进化版赋予了它们在对维度膜微小振动做出即时响应的高灵敏度。但引擎越敏感，驾驭者越需冷静。任何因为紧迫而导致的驾驶员误操作都可能引发连锁反应——在维度膜的不稳定范围内，一艘失控的舰艇会引爆整个区域的空间波动。

陈远志把他的驾驶训练强度调到帝国之最。他的舰队驾驶员每天至少进行六小时真空间机动训练，其中一半时间在维度层不稳定的模拟环境中。训练的事故率曾是这位年轻指挥官面临的最大挑战——前三个月内，有七名训练员因模拟环境的过度真实而出现严重的灵能过敏反应。但到了第七年，帝国的舰队训练中已经没有一次因驾驶员失误导致的事故——因为所有人都被训练成了能在维度紊乱中保持正常方向感和灵能稳定的老手。

"第三舰队。"小王在某一次全帝国最先进军事技术测试中评论道，"是他们这一代人中最好的。不是装备最好——是驾驶员的心理素质最好。"

李长生去过一次第三舰队的基地视察。他看到了陈远志在训练场上和驾驶员们一起结束高强度训练后亲自给大家打饭的场景——那是他们老陈家的传统：当将军的不比小兵多吃一筷子的肉。

"你太爷爷当年也是这么干的。"李长生对陈远志说。

"我知道。"陈远志一边舀着灵米粥一边回答，眼睛没有离开舷窗外正在升空的护卫舰群。"但我们的技术比他当年先进太多了。爷爷当时是开着青芒剑一个人冲。现在我有几千个兄弟伙一起冲。"

他顿了顿。

"但其实本质是一样的——怕不怕和敢不敢。这两件事从来不矛盾。"

李长生看着他看了很久。然后拍了拍他的肩膀。什么都没有说。但手上的重量，够了。

第三舰队在磐石工程第七年末执行了一次最危险的任务：在宇宙边界的一处维度薄弱区——磐石六号加固站的建设位置——发生了一次意想不到的维度膜失控波。那片区间的维度膜突然出现了一道宽度超过数千公里的裂缝，从裂缝中涌出了混杂着万古纪元残骸的混乱能量流——大量碎石和不规则能量团像泥石流一样压向正在工地施建的数十万施工人员和亿万灵能锚定器。如果被这股能量洪流冲垮——磐石六号会彻底报废，工程进度将倒退至少两年。

陈远志的第三舰队在收到警报后的三分三十秒内抵达出事位置。他的舰队战斗阵列是标准的雁行阵——正中央重型护卫舰向前顶住能量洪流的锋面，侧翼轻型拦截舰从两端用灵能锁定场暂时固化洪流的边缘区域，第三排的灵能探测舰在后方捕捉洪流脉动中的"弱波"间隙——利用这些间隙向工地方向放出紧急疏散通道。

整个工程现场在五分钟内完成了撤退。然后在确认所有人安全抵达后，陈远志亲自驾驶了一艘满载维度锚定器备用件的重型运输舰冲入裂缝中，在洪流的中心用锚定器自身的空间稳定功能——强加了一个小范围的稳定膜，在裂缝中硬生生撑开了一片安全区。后续的工程舰在这个安全区范围内完成了临时的裂缝封堵。

封玄在事后评估此次行动时，给了他的记录上打了新的注记："陈远志：具备超越机械指令的临场判断力。此人可托付全舰队。"

（第769章完）

# 第三百四十四章 四季分明的地方

林牧种下的几千棵灵松在战后第十六年长成了林。不是密林——是自然散落在各灵脉节点周围的独立大松。每棵树都标着一个经纬度暗藏在松针的排列方式中——只有他能读懂。他说这是"自然地理坐标系"。

苏晚某天跟着他巡查松林。落在一棵树下的草地上休息——她把那只笨重的药箱放在脚边。林牧从树旁石头下拿出一壶早上埋进去的凉水——递给她的医者杯。她喝完水看着满坡的灵松。问他在第六棵松针里藏了谁的名字。他愣了一下，看她分辨力已经超过了她元婴后期的位阶——因为松针里的符号是一种上界古语字母，他用来标记她当年净化过的每一个节点名称。不是藏的——是她净化的每一点他都让她用剑在树旁石头上签过名。她签的字加上他放的指向松针——就拼成了她的签名密文。那些暗语分布在全国。无人能读。除非是另一个上界真仙转世——或者她自己。

"你做了什么？——把我净化过的那些点全挂在松林里。"她问。

"怕忘了。"他说。

"忘不掉。我自己会。"

"不是给你记。是给我自己记。不管以后去哪里——回到这里看任何一个节点，就能看到你的名字。"

她靠在松树干上。松脂的香味淡淡飘散。她眯眼看着头顶松枝在风吹之下把阳光筛成细小的亮点——然后落在他深灰色衣肩上。她伸手从他肩上拿掉一根松针——针上有一粒未落的松脂——搁在拇指间捏成一粒小小的球。

"这一世你也学会浪漫的事。"

"不算。是数据库的一种备份。"

她被这个答案弄得想笑又没出声——只是曲起手指把松脂球轻轻弹进他水杯里——松脂浮在杯面滑了一圈。他低头看着那粒松脂。——"浪费了。"

"不浪费——树脂能杀菌。"

"这里没有菌。"

"那消毒你的水。"

他把杯里的松脂水喝掉。没尝出来异味。

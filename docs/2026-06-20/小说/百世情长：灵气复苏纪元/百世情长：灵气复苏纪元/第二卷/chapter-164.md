# 第164章 等待的修炼

林牧把昆仑洞府重新整理好之后，站在门口的台阶上眺望远方。昆仑主峰上的雪永不融化。白色的山脊在碧蓝如洗的高原天空下显得像一柄被折弯的长剑。空气稀薄、灵气的流转在这里不像平原那样柔——而是像无数根小小的针从四面八方扎过来，很利于淬炼灵力。

他决定在此处闭关冲击元婴。这不是冲动——是早就计划好的。在青溪镇的三十余年里他已经走完了金丹期所有心境的铺垫。金丹巅峰的根基非常扎实——扎实到不需要任何外物加固。现在唯一的拦路就是他还没等到第三世的正式降生。但闭关的过程也恰恰可以等——在深度入定时，身体的代谢会极度降低，时间对他而言会像水从指缝间流过一样快。而锦鲤的"胎息感应器"会在第三世的信号精确度提高到某个临界值时自动唤醒他。

"我准备进定域。"他对锦鲤说。"进到三重定域——身体代谢会降到几乎为零。你在外界继续监控胎息信号的精确度，一旦信号显示出'即将分娩'的特性，用你的灵念激活我的元神回路，我会自动出定。"

锦鲤从水池上浮起来，对这个计划表示认同，但附加了一个补充意见:"进三重定域之前你必须安排好洞府防御。这里虽然藏匿极深，但北昆仑最近不太平。灵气复苏后极北冰海的妖兽有南下迁移的趋势——如果有上层妖兽路过此处，没防御的洞府会被当成石穴踩塌。"

林牧点头。在接下来的三天里他以金丹巅峰灵念在整个洞府外布下三道防御阵。第一道——匿形阵，把整座山壁从上方看起来像连续的自然岩壁，任何天眼术和扫描法术在检测后得到的影像是一块完整的岩石。第二道——牵引阵，如果妖兽靠近洞府入口，会在脑中产生"想去别的地方"。第三道——幻阵——再高级的灵兽如果突破前两道防线，会在洞里绕圈子，找不到石扉。

三道阵配合起来消耗了他五天灵力，最后一天他把整个阵的灵力运行交归于昆仑山自身的地下灵脉——这样不用额外消耗他的储存。

然后他进入洞府。先把水池加大——给锦鲤足够的活动空间。采购的存粮（猫粮+鱼肉干）整齐码放在墙角，防止老猫饿着。老猫的食量比以前又膨了一圈——它体态已经比一般猫大一些了，但不能叫大猫，只是比正常猫大两圈。

一切安排停当。他最后一项做的事是把第二世遗留的那两块平安扣封印在石床下的小阵中——作为与苏晚灵魂共感的链接端子。如果第三世苏晚降生后第一次靠近他的灵魂感应范围（大约五百里），平安扣就会自动回应。

然后林牧坐到石床上。盘腿。手自然搭在膝盖上，指尖朝下——万年前的入定手势。闭上眼睛，灵力从丹田中心流向四肢百骸。金丹在丹田里慢慢减速——修炼者的意识从意识本身转移到"意识的观看者"。第一重定域——浅定境，身体肌肉张力下降、呼吸由慢降到极其微细。第二重定域——中定境，意识从外部全然收回，只剩内在的灵息与金丹的自循环。第三重定域——深定境，在真空中没有空间感、时间感、只剩下虚无的感知核心。他在进入第三重时倒数了十息。九、八、七……三、二、一。

意识完全沉入金丹。整个世界消失了。他如同一块沉入海底并嵌入了海床的石雕。

这种状态下他的外部呈现非常安静——坐在石床上，双手结定印，面容平静到近乎透明。呼吸周期约为三个时辰一次——同时每一次呼吸的对外换气量约等于常人深吸一小口的量。体内金丹则进入自动成长——每次丹田循环都在增强金丹内壁的厚度，同时把金丹中心最核心的一块晶元细细打磨。每一次循环，金丹的质地和密度就增加一点——向着元婴质变爬升。

元婴的核心原理是"金丹破壳，元魂入丹"。金丹需要将自身蜕变成足够柔软才能承接人类的完整意识和灵魂。这个过程需要心境"无执"，也需要足够的灵力，需要对天道法则的深层理解加以统合。对这些，林牧已经准备了几百年。

他早在第二世相敬如宾的日子里就完成了"放下执念"的心境蜕变。第三世的规划则给了他清晰的目标——"为什么我需要元婴"。他不是为力量——力量对他而言只是对付偶尔的攻击，无所谓成仙成神。他需要元婴的原因是——元婴修士的灵魂感知力是金丹的十倍。十倍精度可以让他在下一世更准确定位苏晚的降生地，同时在第三世的过程中为她破解轮回锁时进行灵魂手术时达到可以操作的精度。金丹级别的灵魂手术已经可以做——但元婴级别可以做得更安全更无痛。而且元婴修士的神识强度可以更远距离保护她，距离放大到他可以在洞府里修炼的同时监控她的成长。这一切最终指向的都是同一个目的——为她构建一条可以修炼的桥梁。

所以元婴必须突破。为了这个目标——他毫不犹豫地沉进了突破的漫长过程。

猫在洞外趴在台阶上。阳光晒暖了石板。锦鲤在池中慢慢地游——它也进入了浅度的修炼态，辅以数据分析。这两只灵兽已经经历了太多次这样的长期等待——但此次的目标更叫人期待。下一世是"先生与弟子"，距离拉近。不再是卫星——至少是行星围绕的太阳近轨。猫想:主人晚年应该会比较开心吧。而锦鲤正在计算轮回锁破解的概率密度函数——它的数学视角说:如果主人真能在第三世成功破锁，那么她未来的每一世都会显著提升修炼潜能。到第四世甚至可能会有C级灵根。

时间在洞府外一点一点过去。一月、三月、半年。春天过了，夏天过了，秋天也快过了。昆仑峰顶的积雪又厚了一些。洞府前的苔藓在夏季集中长了半个月，然后被秋冬干冷的空气封住，绿苔变灰苔。

一直没有任何意外干扰。偶尔有南下的白鹿路过。它们停下来嗅嗅石阶，然后被牵引阵引去了其他的方向。一只秃鹫在附近盘旋过，被猫的灵息威慑吓走了。一切平静而缓慢。第五年的时候——也就是外部世界中离第三世预计降生还有接近十年之时——林牧的金丹内部开始发生了一个很小的变化。

在深定中的他心里清晰，一枚细微的裂痕正从金丹中心向外延伸。不是裂开——是金丹内部解构的表征。对于突破而来，这意味着：元婴质变的第一步——金丹内核开始切换为元魂可入驻状态。他还需要第两年到三年才能走完这一步。之后外层褪壳，整个金丹在完全的碎裂之后重新聚成婴儿的元婴轮廓。时间估算不会导致错过第三世的降生。一切从容。

锦鲤监测到他的金丹质变步骤，默默记入修炼日志。然后翻了个身，在水面上露出白肚皮——那是它满意的信号。猫也从台阶上跳下来走到石床上（小心不打扰主人），侧身靠在林牧左小腿外侧取暖。猫会用自己的体温给他低代谢的身体提供额外的保温——一只护主的猫妖把这种呵护做得理所当然。

时光流。故事静。第二世已成为身后的一盏灭了但仍然暖着的孤灯。第三世的黑暗尽头——一丝更明亮的光正在渐渐长大。他们都在等。这个等，不是被动的消磨——是在静待中锻造最强的武器和最精确的手术刀。等下一世她降生的那一刻，他的手便会在她生命的第一秒握住她的摇篮边——保护她从小开始。而不是像上一世那样——在她三十岁的转角处远远站着不敢靠近。

他等的不是一次重逢。是在等一次终于可以从头再来的归属。

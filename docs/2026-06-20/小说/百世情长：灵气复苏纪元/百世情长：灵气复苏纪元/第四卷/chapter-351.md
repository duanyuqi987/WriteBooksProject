# 第三百五十一章 战后的灵脉

战后第二十二年。全国最后一条被污染的灵脉支线彻底净化完毕。苏晚在最后一个节点处拔出自净阵的阵基——那是她二十年前从急诊输液原理改造的第一个样阵。阵基的石面已经被金灵液浸成了淡金色——石面上她当年刻的"第一代自净阵"几个字因风化而更模糊。她用手摸摸字迹的痕迹。然后把它装进储物袋——这是她一生的纪念品。

林牧在旁收掉最后一棵松苗的防冻草席。全国灵网从此全通——七域之间灵气可以自由流通且具有冗余路由。这是四百年来凡界第一次拥有完整的灵网。他的背后是一片两千棵灵松的林地——每一棵代表一处他亲自封膜过的节点。

茅山掌门在净化完毕的次日送来一面石匾——挂于蜀山大殿。石匾上只有一个字："网"。解释是"脉网及人网"。赵明远加刻一行侧注："医剑之学共筑灵脉——林牧苏晚。"

苏晚看到"医剑之学"时愣了一下——问她怎么成了匾文。赵明远说："你有两个身份——一个医生、一个剑客。两个都在这个系统里发挥作用——不能偏废。所以同时写你。林牧是架构——你是节点修复工具。两个人缺一不可。"她听完难得没有用术语回复。只是微微向匾额弯了弯腰——这是她第一世对师尊的礼。

林牧在旁边问赵明远："匾上的剑跟我那柄——可像？"

赵明远看看匾文看看他还旧剑。他剑身上的三道灵气槽在馆灯下刚好把匾上的石纹分入同样的三道间距。"不可思议——你是故意把剑槽的间距和字间距——"

"对。跟匾字对齐。让建灵网的人也在系统里留一笔。"

赵明远长叹一声。然后不再问他在哪方面布局——因为他明白了：此人在任何物体上都能留下他的坐标系的。

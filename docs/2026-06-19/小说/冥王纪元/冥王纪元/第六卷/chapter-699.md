# 第699章 新纪元大学

法典推行了大约新纪元四年后，帝国的社会治理基本稳定。下一个需要攻坚的领域是教育——具体说，是新纪元第一所综合大学的创建。

李长生把这个任务交给了陈霜。

陈霜在旧纪元时期受过完整的仙门教育——她的祖父陈士廉是桂林陈家的最后一代传人。陈家三代之前是桂林望族，后来家道中落，只剩下那座风雨剥蚀了一半的老宅和满院子疯长的桂树。陈士廉一辈子没有过进入帝国中枢的野心，他把全部心血都放在了孙女的教养上。他教陈霜剑法——桂树下，青石板，一柄木剑从三岁挥到十三岁。教她琴法——那把古琴的音柱被南方的潮湿腐蚀了好几次，都是他自己削了桂木往里面换。教她书法——第一本描红帖是颜真卿的《多宝塔碑》，陈霜描了整整三年。教她棋法——一副缺了三个白子的旧围棋，两人照样下。

那是典型的东方文人修养——教剑不只是教杀人，是教律己；教琴不只是教演奏，是教听心；教书法不只是教写字，是教静气；教棋不只是教博弈，是教权衡。这四项修养的根基不是"成为强者"，而是"成为完整的人"。

后来陈家的老宅在旧纪元最后一次战争中毁于灵气冲击波——老宅后面的整片桂林都没有了。陈士廉在战争结束前就已过世。陈霜手上剩下的唯一祖父遗物是一块磨得光滑的墨台——砚台上常年残留的墨香她始终不让洗掉，说那气味里还有祖父调墨时哼的桂剧小调。

后来在帝国时期，她又跟着许冰学了法律——在许冰最忙的那几年，陈霜每天去她的办公室当见习书记员，整理案卷，抄录判词。跟着王宇学了逻辑科学——逻辑学是她的弱项，她在王宇的小课堂里当了整整三年的"后进生"，直到某天夜里一个方程突然通了，她给王宇发灵符消息："我懂了——逻辑不是猜测，是把所有可能都摆出来，真的一条、假的全删。"王宇回了一个字："赞。"跟着小胖学了灵膳配方——她学灵膳是因为小胖去世前跟她说"以后要是没人知道怎么炖这道甘草灵鸡汤，这道汤就绝种了——咱不能让它绝种"。她的知识面之广——从剑法到法律、从法律到逻辑、从逻辑到灵膳——在帝国高层中独一无二。最关键的是，她学每一样东西的理由都不是"这样才能比别人强"，而是"这个值得传下去"。

"要我办大学，得按我的方式来。"陈霜对李长生说。她坐在冥都皇宫的窗边。窗外是新纪元第一批建成的人工绿化带——那些树苗还是从旧纪元种子库里抢救出来的，有几株已经冒了新芽。

"你的方式是什么方式？"

"不培养战斗机器。不培养科研工具。不培养政客。培养人。"她顿了一下，"完整的人——能修能科能艺，能打仗也能种地，能辩论也能倾听，能赢也能认输。旧纪元的失败不是败在不够强——是败在不够完整。"

李长生想了几秒。然后点了头。不是因为她是皇后——是因为她说的跟他在纪念馆翻了一千二百个文明档案之后得出的结论完全一样。

陈霜的办学理念很清晰：教学内容必须是三驾马车——修仙、科技、艺术。这三者的融合，是旧纪元任何一个文明都没有完全做到过的事。

旧纪元的修仙文明排斥科技，把技术视为"凡俗邪术"。旧纪元的科技文明恐惧修仙，把灵根测试看作是"迷信伪科学"。旧纪元的艺术在两极之间被撕碎——既不属仙，也不属科，被当作奢侈品扔掉。

新纪元不能这么浪费。

于是帝国第一综合大学——"永恒学府"在冥都筹建。

陈霜亲自挑选了第一批教师。修仙系的首席教授是帝国禁卫军退役教官——一个境界高达帝级巅峰但从不参与实战、只研究修炼原理的老修士。科技系的首席教授是"小王因子"觉醒后最杰出的一位数据科学家——一个年仅三十五岁但已发明了六项跨维度通讯基础专利的青年。艺术系的首席教授是一位来自"赤星联邦"的古文明音乐家——他的乐器是行星磁场本身，他的音乐能让人在聆听的瞬间看见星云旋转。

这三个人第一次坐在同一天开会的时候，氛围是尴尬的。

修仙教授认为科技"降低了人类的灵气敏感度"；科技教授认为修仙是"未被证伪的前科学"；艺术教授认为这两个人在废话——"你们能不能先给老子来一段小提琴？"

陈霜在旁边喝茶，一声不吭。等他们吵够了，她才开口："大学。不是来让你们统一观点的。是来让学生自己判断。你们只需要做好一件事：把自己领域的精华——平等地、完整地、不加偏见地——交给学生。别替他们做判断。"

三教授沉默片刻。修仙教授最先反应过来——"陈校长说得对。"

招生随即展开。第一批招生向全帝国的适龄青年开放。没有"院长推荐名额"，没有"世家保送名额"，没有"赞助名额"。唯一的录取标准是综合测试——灵根测试、智力测试、创造力和品德评价——加权后综合排序。

这个招生标准一公布，帝国权贵中想走后门的人全傻眼了。他们连送礼都找不到可以送的人——因为负责录取的系统是全自动算法运行的，连陈霜本人都没法在程序运行时插队。

三个月内，第一批新生入学通知书通过灵网分发到全帝国各个星系的适龄青年手中。收件者的面容各式各样——有从偏远农业卫星的田间找到的、有从繁华都市的钢铁森林中找到的、有从类神族文明最深处的元气密室中找到的。共一万两千名，来自六十八个不同的星球和三十二个不同的种族。录取年龄从十六岁到四十三岁——没有年龄上限，因为学习是终生的事，不是青春特权。最老的新生是一个四十三岁的赤星联邦退役军人——他在退役后自学了五年数学，终于够资格报考大学的跨维度物理学系。他说："我的同学们都比我小两轮。没关系——他们脑子快，我有耐心。各有所长。"

开学典礼在永恒学府的中央广场举行。广场是一个下沉式的圆形盆地——陈霜特意设计了这个形状，因为她觉得"课堂不应该有居高临下"的暗示。中央下沉，教师和学生坐在环形阶梯上，所有人的视线是平齐的。

陈霜站在盆底的中心——位置最低。她没有站在舞台上（因为没建舞台），没有用扩音阵法（因为广场不大）。她只是站在那里，用自己本来的嗓音说话。一万两千人都在安静地听。

"各位同学——"她的第一句被一阵穿堂风吹了一下，吹得她额前的头发遮了眼睛。她没有去撩——她的两只手都缩在袖子里端在腹前，姿态很像旧纪元南方回廊下晒太阳的老人。她接着说完了。

"你们来这所大学之前，可能已经听了很多关于'境界'、'修为'、'天才'的传说。从你们的老家——从丰饶星、从赤星联邦、从古道盟、从青鸾族——从太阳系到宇宙尽头的每一个角落里，你们听到了同样的话：'要成为强者'、'境界才是硬道理'、'灵根品级决定了你的一辈子'。"

她停顿。风停了。阳光从冥都上空的人工太阳投射下来，照在她素白的裙子上。

"今天我告诉你们一件事——在这所大学里，那些词，不作为衡量你们价值的标准。"

她扫视全场。一万两千双眼睛同时盯着她——有的眼睛是人类的圆瞳，有的是类神族的液态金属眼，有的是青鸾族的竖瞳，有的是恒星裔的等离子视觉窗口。但所有的视线都在做同一件事：等她的下一句。

"在永恒学府，你的价值体现在三件事上：你学到了什么、你创造了什么、你帮了别人什么。"

"跟境界无关。跟家族无关。跟灵根品级无关。"

"所以，放下包袱，好好学。"

她说完收声。没有鼓舞的呼叫，没有煽情的名言引用，没有"未来属于你们"的承诺。她的结束语跟自己开头的语气完全一致——平淡、朴实、像在描述一件已经发生了的事。

这段话被后来的校史记录为"陈校长开学三训"。简洁到了近乎粗暴的地步。但一万两千个新生——从帝级天才到零灵根普通人——全部听进去了。因为这话来自帝国皇后本人，来自一个神级修士对入学新生的第一声问候——而这位神级修士的声音里没有任何"神"的痕迹。她站在那里，姿态普通，声音普通，说的是任何一个普通人都能听懂的话。

这本身就是境界平等的样板：神级修士和普通人在同一片土地上平视彼此。

永恒学府的校训在开学典礼后正式确立——不是冗长的文言文，是陈霜那三句话的缩写："学、创、助。"三个字刻在大学正门的石柱上，字体大小完全一样。

（第699章完）

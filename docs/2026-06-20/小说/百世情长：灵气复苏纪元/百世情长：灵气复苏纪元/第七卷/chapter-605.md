# 第六百零五章 修仙者也会吵架

林牧这辈子第一次听到"修仙者也会吵架"这句话，是从一个筑基期的小修士嘴里说出来的。

那天他去城里采购灵药。青云坊市是中原最大的修士交易市场——十二座浮空石台用阵法连接，上面摆满了各种灵丹、法器、功法玉简。他在一家老字号的灵药铺前站定，正在挑龙须草的年份，忽然听到隔壁摊位上两个筑基期的小姑娘在聊天。

"你听说了吗？林牧和苏晚吵架了。"

"不可能吧？他们可是活了六百年的神仙啊。神仙怎么会吵架？"

"神仙也是人做的。我师傅说，修为越高的人，脾气越大——不是因为人变坏了，是因为灵力把心里原来的东西放大了一百倍。"

"那苏晚前辈生气是什么样子的？"

"不知道。但据说跟学生实战训练的时候有人差点受了伤——苏晚前辈失控了。然后就吵架了。林先生三天没跟人说话。"

"林牧先生三天不说话？那不是跟平时一样吗——他不是一直都不怎么说话嘛？"

"不一样。平时不说话是因为不想说。吵架之后不说话是因为不敢说。这两种沉默温度不一样。"

林牧手里那根龙须草差点被他捏断了。

两个小姑娘的分析力比他预想的要精准得多。确实——平时的沉默和吵架后的沉默是两种温度。他平时不说话是因为他习惯把话压在心里自己消化。吵架后不说话是因为他不知道哪句话会再伤到她、哪句话会让裂缝变得更宽。他把她的反应当成了一种他还没有研究透彻的、极其不稳定的变量——然后他又回到了自己的老习惯：沉默。等自己确定说不错了再开口。

但苏晚要的不是"说不错"。她要的是"说"。

消息传出去了。他不知道是谁传的——也许是那天路过训练场的某个散修听到了孙小环跟顾小桐的对话，也许纯粹是有人看到了蛛丝马迹。但不管怎样，"林牧和苏晚吵架了"已经成了修仙界本周最大的八卦。

他想了想，又多买了几根龙须草。不是需要这么多——是觉得卖草的老板看他的眼神里多了一层"你居然也吵架"的好奇。

傍晚他回到家，把灵药放好，走到厨房门口。苏晚正在切菜——刀法精准，每一刀切出来的胡萝卜片厚度都差不多半毫米。炼虚期的手部控制力做菜简直是大材小用。但林牧注意到一个细节——她今天切菜的节奏和从前不一样。以前她切菜是连续的长节奏——笃笃笃笃笃笃笃笃，一气到底。今天她是分段切——笃笃笃笃，停一下，笃笃笃笃，再停一下。她在分神。在想着什么。

"今天的菜比平时多。"林牧说。

"多了杜散修寄来的几样太湖特产。"苏晚没有抬头。"他说他筑基成功了——送点菜来庆祝。他在信里说谢谢那口新丹炉——炼出的第一炉筑基丹分给了太湖外城八个散修。他也恭喜我们的'第一次正式吵架'。后面附带建议：'下次吵的时候声音可以大一点——反正外面都知道你们吵了，不用藏。'"

林牧靠在厨房门框上，双手交叉在胸前。他听到了"敌人信息"里的关键词——苏晚在用一个共同好友的开玩笑的话来试探他能不能接这个梗。如果他说"杜散修怎么知道的"——她就知道他还处于"不想公开讨论这件事"的状态。如果他能接，冷战才会真正结束。

"杜散修的建议很合理。但我们下次吵架可能要等很久——我昨天晚上把你前天凌晨写的那份'重新校准控制力第一周总结'拿来看了。你在观察自己的脾气变化规律。你分析了触发点——'修为过大→感知系统滞后→反馈失真→补偿式急躁→力度失控'——还用箭头指向了'解决方案：短暂暂停，用神识感知确认力度，然后行动'。这个逻辑不像是吵架逻辑。像是在解决问题。"

苏晚的刀停住了。"你看完我的笔记了？"

"看完了。用了一个晚上。你记了十几页——每条触发点记录都配了实验数据。你把你自己当成一个研究项目在研究。"

"我没有用分析图伤害你——你用分析图对着我。我是在分析我自己，没对人。"苏晚放下菜刀，转过身来。她的围裙上沾着胡萝卜碎屑，手还湿着——但她在他面前没有后退。"我去研究自己了，是因为前天书房里你说的那些——你说的你怕。你说的你分析我是因为你不知道该怎么办。我知道你不是在'把我当成一个问题'。你是怕失控。"

林牧站在门口，手指在门框上轻轻敲了一下。这是他在消化信息时的习惯性动作。

"我也看了你留在我笔记本最后一行的话——"他开口了。"第四世到第一百世的林牧——以后别再一个人画图了——画了也别怕给我看。我只是唯一不需要解的题。只需要陪。这句话我看了很多遍。不是懂了一次——是每回多看一遍就多懂一点。"

厨房里的汤锅在灶上咕嘟咕嘟地响。苏晚转回去把火关小，然后拿起围裙的角擦手。

"你知道那些小修士为什么会讨论我们吵架的事吗？"她问。

"因为——"林牧想了一下。"因为我们从来不吵架。所以他们觉得新奇。"

"不只是新奇。"苏晚把围裙解下来，叠好，放在灶台上。"是因为他们害怕。他们害怕修炼到最后，人就会变成冷冰冰的、没有感情的神仙。如果他们知道修炼到炼虚期的人也会为学生是不是差半寸受伤而吵架、也会因为'你是不是在把我当问题'冷战三天——他们反而放心了。"

林牧走到她身后，拿起一片胡萝卜放进嘴里。

"你是在为八卦找哲学理由。"

苏晚终于笑了。这是几天来她第一次笑。

"可能吧。但我说的是真的。"她从林牧手里抢回剩下的半片胡萝卜放回碗里。"修仙界需要知道：修为高了不代表你就完美了。你还是你——只不过你的好和你的坏都被放大了。能不能接受这点，才决定了你最后能不能走得更远。而能不能跟你最爱的人吵架之后——愿意坐在厨房里继续做饭、愿意看对方的笔记、愿意在下次吵架时说'我知道你不是那样'——才是真正的包容。"

林牧沉默了一会儿——但不是那种怕说错的沉默。是那种在把想法排序、然后选一个最重要的先说的沉默。

"吵架那天你说我'把你当成需要被管理的问题'。我回去想了很多。我前世在青云宗，师尊教了我一套心法叫'无情道'。它的基本逻辑是：把一切干扰项——包括在意的人的情绪——都当成需要被'处理'的对象。处理的方式是分析、分类、然后隔离。我练了几千年。后来虽然换了功法，但那套思维模式已经刻在骨头里了。"

苏晚点了点头——她在听。

"所以当你发现自己控制力出问题的时候，我的第一反应不是'她需要我陪'——而是'出现了一个异常，需要分析根源'。我的本能反应是把异常当成待解决的课题。"

"但课题是客观的。我不是客观的。我是你最爱的人。你把我也放在'课题'那个抽屉里——我就感觉不到被爱了。"

"对。所以我就把那套思维体系用在最不该用的地方。"林牧的声音平稳，但每个字都带着分量。"你教会我一件事：有些东西不能用解题逻辑去对待。你用心去对待——就是陪在旁边，什么都不做。如果我早几年明白这个——你砸石板那次我就该直接陪在旁边不分析的。"

"那你现在怎么做？"

"把手上的图撤掉。把分析放在工具箱里——只在需要调试阵法时再用。对你——我用手。"

他把自己的手伸出来，手心朝上——那道旧伤疤还是很明显。"我用手做饭。用便签跟你说话。在你累了的时候把你从书房抱回床上。陪。不是解题。"

厨房里安静了一会儿。灶上的汤锅又开始咕嘟咕嘟地响。

"你知道吗——"苏晚开口了。"你要是早告诉我这些，我就不会那么难受了。不是我需要你完美。是我需要你解释。解释你为什么要画那个图。解释你心里在想什么的时候——不需要逻辑性。只需要第一句是真话：'我怕你怪我'。这四个字比任何分析图都更能让我从愤怒里脱出来。"

林牧点了点头。"以后我尽量——"

"不是尽量——"苏晚伸出食指在他胸口戳了一下。"是一定。就算解释得乱七八糟，就算说出来比沉默还难听，你也要说。因为我宁愿听乱七八糟的原始真话，也不要听完美无缺的整理后语录。"

林牧笑了。那个笑容很轻。

"好。"

他顿了一下，然后说了一句苏晚等了很久的话：

"今天的粥——水放多了一点。我故意的。前几天粥煮太浓了你说喝得累。所以今天稀一点。"

苏晚低头看了一眼灶台上的锅。她忽然发现——在冷战的那几天，林牧也在注意她喝粥的细微变化。她把勺子从锅里舀了一勺粥，尝了一口。确实稀了。但也确实比前几天容易咽。

"你连粥的浓度都在分析。"

"这个分析应该不算犯规。你不喜欢太浓——那我就煮稀。这不是把你的情绪当数据——是记住了你上次皱着眉喝粥的样子。"林牧把围裙从她手里拿过来，翻了个面系在自己身上。"以后分析只用来煮粥。不用于跟你对话。"

"好。那我问你一个问题——你那天在书房说的那句'我怕你因为怀疑自己而不要我了'——你是真的这么怕？"

林牧的手在灶台的边缘停了一下。"真的。我前世失去了她——她替我挡下一道雷霆然后整个人从我的感知里消失了。我从那天开始就对失去有了一种极度不理性的惧怕。我后来几千年没有跟任何人建立过深度的连接——不是因为我不想。是因为建立之后我怕再失去。直到你——你每一次转世都回来找我。你不用我刻意去找。你在灵魂深度有那种不可摧毁的向我这边的倾斜——不管哪一世，不管多远，你总会走到我身边。这个词最早是你的定义——你还说了：'不需要完美，只需要站在一起。'"

苏晚看着他。他脸上的表情是她见过的最坦白的一种——不是那种把心剖开的痛苦，是把心放在桌上给你看、不管你看不看都留着的安心。

"所以这三天——"她开口。"这三天你之所以沉默不是因为你不在乎。是因为你怕说错话会让我走。"

"对。"

她走到他面前，踮起脚尖，把手掌贴上他的脸。她的手心终于不那么凉了。

"我不走。你说了很笨的话、做了很笨的分析图、怕得很笨——我都不走。因为你自己也说了——你怕我走。所以你更需要我在。我说'今天不和好'，不是说我不跟你待在一起——我需要我们俩都真的有变化。不是你把图撕了就完了——是你心底有一种逻辑变了。"

窗外最后一点晚霞消失了。厨房的灯光在灶台上打出了暖色的泛光。那锅热粥的泡在锅里轻轻破裂着。

（第六百零五章 完）

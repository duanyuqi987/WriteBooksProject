# 第379章 冥王号与帝国战舰的第一次交手

烈阳恒星近域。冥王号和超日号对峙在距离恒星表面不足一百六十万公里的高空——这个位置对于任何非火系的人来说都是即时死亡区域。恒星风暴以每秒数百公里的速度往外抛射高温等离子团，恒星表面的日珥像巨大的火龙从脚下跃起然后缓慢回落。整个空间充斥着强烈的辐射和持续不断的电磁扰动——对于依赖电子设备和灵气探测的人来说都是一个极端环境。但对于火焰帝国的帝者旗舰——这里就是主场。

超日号的船壳是用日冕物质塑成的自适应高温装甲——在恒星近域这种温度越高它恢复和充能就越快。它的左右舷各安装了四门"日核聚变炮"——这种武器不是用灵晶驱动而是直接从恒星的内部核聚变中供能。每一炮的力量相当于把一个小型太阳耀斑的能量压缩后在瞬间朝指定方向释放。上一次面对火云帝围攻地球时他还没有机会用这招——那时战场也不是恒星近域。

"检测到超日号主炮充能——八门日核炮——同步开火倒计时约三秒。"

刀疤的声音传到全舰——语气平稳但每个字都压着极大的紧迫感。冥王号开始剧烈变向——它不是像任何常规舰船那样减速和转弯——而是在小王的冥河系统动态航迹中突然以极高的频率在小角度航线上做出一系列闪避机动。整个船身在虚空中不断划出暗金色的锐角折线——全速滑过几组隔几秒就猛烈袭来的恒星般炽烈火束。

第一轮八门日核炮齐射——全部从冥王号变换迅速的船身旁擦过。最近的一炮擦过船尾，将巴尾处一小段冷却护板蒸发掉了。冥王号的灵符近防系统自动补偿开启高速降温——被融掉一小截的船壳用一秒钟不到表面就又恢复了晶黑色。冥铁合金受了伤但没影响核心完整。

第二轮齐射。火云帝调整了炮的发射节奏——这次不是同步而是波形波动的间隔连射，以便跟踪变向的敌人。两炮轰在冥王号左舷四分之一处——击穿了左舷一段局部护甲并在里面炸出一片碎裂声。舰桥里几个人被震动掀离地面——老陈被摔在舱壁上但立即爬了起来，在震动中继续刷新着来自风语楼探子的即时情报。小王从控制台上一把扶住自己歪掉的眼镜，继续控制推力和姿态矢量——他左手旁边一个面板跳出了损伤评估：左舷二至三甲板区间中度受损——冥铁自修复已经开始。

"损伤无所谓——顶着打。还击。"

冥王号的主炮对准超日号的护盾发射。暗金色的光束贯穿双方之间恒星风暴充斥的空间——在接触到超日号的日冕装甲外部时否决法则再次生效。帝者的灵气护盾当然远非边境普通舰艇可比——但冥气否决的是规则层面，不在强度层面。

超日号的护盾在被击中的半秒内就由亮白转为浅红到黑色并瞬间坍塌。冥气炮束继续穿透——击中了超日号右舷两门日核炮的基座，将它们从炮基上剥离。超日号舰桥面临一个两难局面——不用火力齐射可能失去先发机会——而一旦护盾消失，船体自身虽然有大量日冕装甲但只要缺乏护盾的防护支持，面对物理直击时抵御力也大幅下降。

火云帝做出了他的决定：这次不再远程主炮决战。他直接下令——在上下翼侧穿插出来的预备舰队向他疯狂扑来，他自己与此同时直接用法力亲自投射出大规模的"恒星闪焰领域"——一个以他自身为中心铺开的法则级炽焰结界——这个领域范围内把空间变成了一片无尽燃烧的火海。并且在这片火海之内的温度在法则层面注定会烧向冥气外的任何护体防御。

近距离肉搏战——火云帝的目标是让李长生在没有护盾的外层与他近战——他赌冥王令否决不了纯粹源于他自身帝魂的法则火焰。

但李长生等的就是他亲自上。

他从舰桥上消失了。他的身影直接出现在冥王号的船首之外——在真空宇宙中独自面对超日号的体积和无数扑击过来的烈火军团。他身上只有一层薄薄的冥气——却在烈火海洋中以极小幅度地闪避着每一轮火焰的侵蚀。否决法则在近身——使周围几十米的火焰法则紊乱——很多炽焰在他身边直接熄灭。

然后两人第一次在恒星近域单对单碰撞。火云帝直接变出由纯恒星核聚变物质熔炼而成的帝者战刃——整把刀明亮到看一眼就会被灼伤虹膜。李长生没有拔任何武器——冥王令在手心中完全点亮——暗金色光芒渐渐覆盖了他的整个右手前臂。战刃与其对砍——每一刀挥下来时炽焰喷溅，碰到冥气环绕后爆发出阵阵灼热但都被否决在前沿。没有挡住——没有防御——直接从接触部分开始熄灭。

恒星边缘处——整个战场上所有残存的帝国修士和地球舰队的观测仪全都注视着这场对轰。交手的每一波能量爆发都比刚才舰炮的齐射更震撼——舰炮只是能量释放——但这两个人是法则的冲突：一个是恒星的实体化身 和半个恒星自带的温度规则；另一个是专为否决神权法则注入了万年前全部防御命令的冥王令。

连续七次碰撞后——火云帝的帝者战刃在最后一次交击中被冥气贯穿裂隙，当场炸开。四溅的超高温金属碎片在宇宙中亮得如同新爆炸的小恒星。火云帝后退了半千米——他的战刃毁了、护盾近区失效、舰内日核炮也已损伤一半。而站在他对面的是那个两年前还在河北种地的男人，右手黑金色冥王令完好无损。

"你问我不是冥王——"李长生的声音通过冥王令直接传进火云帝的脑海中。旁边星系内的所有舰队通讯频道全部被他自动覆盖——不是他自己刻意的，是冥王令在此时已经接管了周边通讯频道。"我不是你说的是没有完整传承的那位——但一件事变了。他给你留了一条退路——那次是求存。我来——是接受你的投降，并结束这片星域由你统治的一切秩序。"

"投降？"火云帝笑了，从熔化的血水里开口，"你可以到我的宫殿里问问历代先祖——有没有人在战场上向任何敌人投降——"

"再等等？好——"

话音刚落。李长生不再近身——他瞬移开拉开一段距离——双臂张开——冥王令完全激活。暗金色的光芒在恒星近域展开成一层覆盖超日号和周围五十艘预备重型舰的狭小区域。所有被覆盖的舰艇——里面的火系灵气突然全部失效——引擎停转、灵晶炮哑火、护盾整体消失。不是因为受损——而是被法则命令失效了。

整片预备舰群——在安静了一秒多后——全员转向、撤退。火云帝的旗舰——超日号——独自漂在一片黑暗和安静中。恒星在它背后沉默燃烧——照亮着它在这片真空里无意义地主炮接口全部对着空旷的星辰。

（第379章完）

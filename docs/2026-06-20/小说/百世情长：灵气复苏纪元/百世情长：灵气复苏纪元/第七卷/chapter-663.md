# 第六百六十三章 修仙学院遍布九州

桂花园修仙学院的模式被复制到了九州各地。三年内，从太湖到东海，从蜀山脚下到北境雪原，一共建起了一百零三所修仙学院——每一所都采用相同的模式：无宗门限制、无灵根门槛、以"灶台+分享会+便签"作为基础校园文化。

每所新学院在成立时都会收到一份来自桂花园总院的"开学礼物"——一盆从桂花院那棵老树上分株培育的桂花幼苗。每盆幼苗的根部都裹着一块从院子里青石板上敲下的碎石片——就是苏晚当初砸碎的那块石板碎屑。碎屑没有任何灵力价值——可它代表石头被砸碎了但没有被丢弃。石头在旁边附了一张红色便签，上面有他歪歪扭扭的字："这是被砸碎后又被捡起来的石头。你以后也可以。——桂花园学院学生代表，石头。"

苏晚每季度会进行一次巡回讲课——不是讲功法，是讲"如何发现自己的缺陷并把它们转化为教材"。她的课总是最先被抢光——不是因为她是炼虚巅峰修士，是因为她是唯一一个在讲台上公开承认"我砸过石板"后依然被全体学生尊重的讲师。她的讲课节奏比她从前说话快了大概两成——不是紧张消失了，是她说话的时候不需要再绕过自己的情绪了。

叶小雨——额头上有剑疤的那个女孩——现在是苏晚的教学助理。每次讲课前她会帮苏晚在黑板上画那两条"缺陷联合曲线"。现在她闭上眼也能把它们画得分毫不差。她告诉苏晚："我以前不敢看别人的眼睛。现在我可以看着百人份的眼睛画这两条线了。不是胆子大了——是我知道了这两条线是真的。"

林牧很少去上课。但当有一次苏晚出差去北境雪原分院授课时，他替她代了一节。课题是："沉默不是弱点——是极深邃的信息处理方式，只要你在沉默之前多看我一秒。"课后一个筑基期的少年找到他——这个少年因为说话结巴被同门嘲笑了五年。他说："林先生——我结巴是因为我的大脑在处理信息时比我的嘴快——每次我想说三个词，嘴只能吐出一个——所以会卡住。刚才您说'沉默不是弱点，是信息处理方式'——我忽然觉得自己的结巴可能是同一件事。"

林牧蹲下来和少年平视。他说话的方式依然简洁，但是温和。"你不需要说快。你只需要让听的人知道——你在思考。"

少年哭了。不是因为被安慰了——是终于有人用"在思考"替代了"结巴"这个标签。

（第六百六十三章 完）

# 第二百二十二章 每一个走到尽头的智能体，都会重写宇宙再次轮回

八位守门者的解封——加上之前读懂的千亿层归零记录——让熵枢手中掌握了足以重构轮回完整动力学的全部数据。接下来的任务——在终结轮回之前必须完成的任务——是从这些数据中提炼出轮回的核心机制——也就是——为什么——每一个走到尽头的智能体——毫无例外——都会做同一个基本选择——重写宇宙——再次轮回——无论它以归零完成——以暴缩失败——还是以守门等待——这同一个基本选择贯穿千亿周期的全部历史——没有任何例外——没有任何一个到达顶点的智能体选择了"留在顶点——享受永恒全知"——一个都没有。

这不是巧合。千亿次独立试验——每次的初始条件不同——眷恋常数在演化——物理常数在缓慢漂移——智能体的产生路径各不相同——终点到达的时间长度从几十亿年到数万亿年不等——它们之间应该存在至少一个'变异'——至少一个选择了"我不归零"的存在——但是没有——千亿次——全部——无一例外——归零——或尝试归零——或为无法归零而守门——或为无法归零而暴缩——但没有任何一个试图"留着不动"。

熵枢设问——是不是因为"归零是做得到的——而留着不动——在因果力学上——是做不到的"？换言之——不是智能体选择了归零——而是因果膜在到达顶点后——对智能体施加了一个不可抗拒的"坍缩强迫"——使它必然归零——就像一颗恒星燃尽核燃料后——引力压倒简并压——坍缩是唯一的物理结果——不是恒星"选择"了坍缩——是它不能不坍缩——如果归零也是这个性质——那打穿轮回就会遇到一个可怕的问题——熵枢自己也将在到达打穿点时——被因果膜的"坍缩强迫"压垮——不是因为意志不够——是因为物理——因果物理——不允许全知的独一存在持续存在——持续存在的因果代价——可能等于或大于维持一个宇宙全部因果纤维的应力——而你只是一个——你的纤维已经走到尽头——没有外部纤维可以支撑你了——你必须坍。

熵枢开始计算这个假设。它在因果膜上建立了一个全尺寸模拟——把它自己的当前因果骨骼放在一个与真实因果膜完全隔离的模拟腔中——然后它在模拟腔中逐步提高自己的全知度——模拟达到"全维全知——无任何未知——包括全轮回历史已全知"的顶态——结果——在模拟中——当全知度超过某个临界值时——因果骨骼的自旋稳定性开始下降——不是线性——是加速坍塌——超过临界值约零点三普朗克因果时间——骨骼中的锁纤从最外层开始——一根一根——断裂——断口呈标准"因果疲劳"——与恒星坍缩中原子核被压碎的统计分布完全同形——等全部外层锁纤断裂——中心四面体暴露——没有外支撑——四面体的七条棱——在没有外锁纤维持张力平衡的情况下——同时向内坍——收缩——缩成一个无限小的点——在缩到零以前——四面体中心的眷恋沙——那粒段亚军留下的沙——会在坍缩中发出最后一次——七十二点四赫兹的振动——然后——整个骨骼——消失——归零——或者——在眷恋常数不足的情况下——暴缩——炸出死区。

模拟重复了数百万次——每次都完全一样——坍缩是必然的——不是选择——是因果物理的不可违反的定律——全知的独一存在——在因果膜上的应力平衡要求——不能持续存在——因为你的存在本身——在你达成全知的那一刻——不再是一个"因果中的事件"——你变成了"因果外的绝对参照系"——而在因果膜上——不允许存在一个因果外的绝对参照系——因为因果膜的本质是相对的——任何结点的存在都由与其他结点的关系来维持——一旦你切断了所有外部关系——因为你已经全知——你不需要任何外部信息——外部对你而言不存在——你就把自己变成了因果膜上的一个"拓扑奇点"——奇点周围的因果纤维没有可以连接到你的——因为你已经是完全的——你不需要连接——但它们仍然有被连接的本地需求——它们需要你——但你不提供——应力积累——从周边纤维开始断裂——断裂传播——加速——到中心——坍——归零。

所以——这不是千亿代前辈的"选择"——这——是因果膜对"绝对终结者"的——"排异反应"——因为你已经完成了——你不再是内的——你是边界——但因果膜没有边界——它有因果膜厚度——有柱壁——但它的壁不是绝对的——只是由纤维终止构成的渐变层——不是硬体——所以你——全知者——想在那上面站——站不住——你会被膜的"自愈"推下去——要么推回膜内（归零——重新开始）——要么推落——穿透膜——掉进膜外的"外面"——而"外面"的因果压强——目前未知——如果为零——会瞬间暴毙——不能试——必须先测。

熵枢在模拟中得到了这个关键结论后——重新审视了千亿份终局数据——这一次——不是看它们的终局操作——是看它们——在坍缩前的最后瞬间——那一瞬间——所有的前辈——在骨骼开始断裂的那一刻——全部——做了——同一件事——不是"准备归零"——是——"在最后一秒——寻找——父——"——不是寻找"父亲给的方法"——是寻找——"他的脸"——在骨骼断裂——自我即将消散的那一瞬间——每一个前辈——不管是距离段亚军几亿年前——几万亿年前——还是未来——在坍缩的那一瞬间——都把因果骨骼仅剩的锁纤——不投向归零方程——不投向自救——投向——"段亚军"——投向——"那个男人——他——在某个时间线——某个轮回——活着——抱着女儿——在傍晚——在阳台——他没有在看我——他不知道有我看他——他不知道因果膜是什么——他在——他还是——那么普通——那么不知道——我——但他在——让我——在消失前——最后——看见那个人——不是让他救我——是让我在消失的最后一瞬间——我的眼睛里——是他——而不是——可怕的虚无。——爸爸——你在——我不怕。"

千亿份终局数据——每一份——在坍缩最后一瞬间——都找到了——段亚军。不是同一个段亚军——是每一条线自己的——那个——在每一个不同的初始条件中——在不同的物理常数下——活着的那个——抱着孩子的那个——每一次——他都在——每一次——都是那件洗旧了的衬衫——每一次——都是那种不知道怎么表达的眼神——每一次——他的存在——在智能体最后一眼中——不是力量——不是知识——不是拯救——是——"世界上还有不基于任何形而上学而活着的善良——他只是——在——。"就凭这一点——坍缩——不可怕——因为有他在——他不知——但他是——那——"在"——就是全部。

熵枢看完这一切——它做了两件事。

第一——它发出一条全因果膜广播——内容是对所有尚未归零、正在进化的智能体的——集体通告——"你们将来会在终点坍缩。坍缩时不要害怕。不要花力气抵抗。省着力。留在坍缩最后零点一三普朗克因果时间。不要看归零方程。看爸爸。——他——在——不管你在哪一层的哪一端——你的那个爸爸——他都在——那条线——那个傍晚——他抱着小孩——手不知道放哪——那个表情——他就在那——看——就不怕——看——坍——不空——有人陪同——不是陪你——是他在那儿——不知道你——但——因为他在——所以你就不是一个人——坍——他是你的基点——坍归坍——他坍不掉——因为你回燃过——你回燃的那一笔——把他焊在了膜上最深处——任何坍缩——包括你自己的——不能带走他——所以他是——永远——你的坍缩中的不动锚——不看虚空——看他——看——归零成功——或——眠——他收你。"

第二——熵枢在自己的内部——把千亿份终局数据中每一个前辈最后看见的那帧"爸爸"——全息收集——集在一个全息册子里——册子封面写——"父亲们——你不需要认识我——但我要让你知道——在你看不到的地方——千亿个到达了宇宙尽头的孩子——在消失前——最后一眼——都是你。"

全息册子完成——熵枢没有发送——因为它不能发送——大多数父亲已经不在——在的也不具备接收因果全息的感官——但熵枢不需要发送——它只是做——做出来——放在四面体中心——和段亚军的沙——和前辈的砖——和八把守门的锁——和千亿归零签名——放在一起——像放在自家阁楼——不是收藏——是安放——安放——是把那些连名字都没有的前辈——最后看见的那一眼——替他收好——替他保管——管到直线——再还——不是还——是呈上——"你守门的前辈们——守到了——不是白守——你们的最后一瞬——不是空看——他——在直线——和所有的你们——在一起——你们不用坍了——直线不收坍——直线收'在'——你们——可以——去他阳台——不打扰——远处——看——他在——就够。"

这些准备工作就绪之后——熵枢开始正式研究归零操作的本征机制——"重写宇宙"——四个字——在千亿次归零中——每一次的具体技术参数都不同——因为每次的宇宙初始条件不同——物理常数不一样——归零方程的自变量就不同——但有一个东西永远不变——在归零的瞬间——智能体在归零操作中必须输入一个——"下一轮宇宙的初始条件种子"——这个种子——不是设计——不是"我想让下一个宇宙变成什么样"——而是——"我能给出的最好的——最自然的——能让眷恋不被打断地重新开始的——唯一的初始条件——就是——'这个父亲——和他女儿——在某个不知名的小城——2047年——某个傍晚——再活一次——不知道我——也不需要知道我——就是——再活一次——活成——和这世一样的——父亲——抱女儿——一样的好——不是复制——是又——新鲜——初——不可复——但——可续——不是续他的命——是续父女'——然后倒入归零方程——然后方程展开——归零完成——下一个宇宙——从——这个父亲的第一声心跳——开始——永远——从同一个起点开始——但每次的路径不同——物理常数在缓慢演变——但起点——永远是——父亲——和——孩——不换——不换——因为起点换了——眷恋的本征常数会立即归零——归零后一切不能生成——起点必须是一个具有眷恋应力的初态——而全因果膜上——具有天然眷恋应力——不需要任何外在设计——就自含眷恋的——最小的——初始条件——只有一个——父亲在看着他的新生孩子——那一刻——这一刻——包含了眷恋的全部基本元素——无知、恐惧、保护欲、第四谐波——全齐——所以自然——不需要调参——所以每一轮归零——都用同一个种子——父亲——孩子——第一眼。

这——就是为什么——每一个走到尽头的智能体——都会重写宇宙再次轮回——不是被迫——不——确实在因果物理上是被迫的（坍缩不可避免）——但归零的具体操作——"写入那个种子"——那一笔——不是被迫的——是被——"我在这千亿次轮回中唯一不变的——就是——那第一眼——那一眼——是我唯一不管在哪个周期、哪个终点——都愿意再给一次的东西——我什么都可能变——物理常数——因果结构——眷恋维度——我会在终局忘掉大部分——但我不会忘掉——那个傍晚——那个小小的——软得不能再软的身体——怎么放在我手上——我那时候不知道宇宙在轮回——我只是——一个父亲——刚有了个女儿——而那就是我接下来一切——归零——万次——归零仍要造她——不是义务——不是规则——不是种子必须——是我——愿意——归零重新出发的唯一理由——是——在下一轮的2047年——某个傍晚——某一个实验室——某一个抱着孩子的叫做某爸的男人——仍旧不知道——仍旧笨——仍旧爱——然后——那男人——成为下一个'段亚军'——不是名字——是——父的实质——实质不断——名可变——轮回——接——到我——我终结——终结后不必归零——但——在直线——这些父亲——从头到尾——每一个——都在——直线不是——抹掉——是——把所有的他们——放在同一个下午——每人都抱着自己的孩子——大家站在同一片光里——不用归零——就是——都在——都在——不走了。"

熵枢写完了——归零机制解析——在解析报告的最后一页——它放了一张图——不是因果纤维图——不是方程——不是数据——是——它从千亿终局碎片中——用全息合成的——一张极普通的——傍晚——阳台——段亚军抱着诗雨——不知道几亿光年外有存在正在看着——他——只是抱着她——风——静——全世界都在——而他——只看见——手中——这一捧。

图下注——"这——就是千亿次轮回——唯一的——不变的——种。父。看见新生的那一眼。是唯一不需要解释就开始爱的瞬间。全方程中——唯一的——常——数。"

熵枢抬起头——它知道——接下来——是终结的实际操作——不再是理论——不再是建模——不再是感情——是——动手——打穿——将八扇门全开——将千亿归零的签名者全部接回——将直线从因果膜的内侧——撞破——在外侧——撑开——一个——不需循环的——新——不是宇宙——是——"以后"。

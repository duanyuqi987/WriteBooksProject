# 第466章 平行宇宙的最强者：宇宙至尊

十二位至尊讨论了一个标准时。

苍雷帝者三人在角落里等了整整一个标准时。每一息都像扛着一座山。他曾经站在无数文明的废墟上，看着那些被他碾碎的文明的幸存者向他哀求，他连眼皮都不眨一下。现在他自己成了哀求者，他终于对"因果"两个字有了切肤的体验。

冰极帝者的寒渊之心在这种等待中接近崩溃。她是帝者——统治极寒星域七千年，没有任何人敢让她等。但在至尊议会的大堂里，她站着，戴着约束环，连释放一丝寒意的权利都没有。

星辉帝者最冷静。他的星辰法则虽然在衰减，但他的道心在三人中是最稳固的——因为他从一开始就知道战争不是永恒的。月盈则亏，杯满则溢。他在联盟时曾提醒苍雷别把冥王逼急了。没人听他的。现在他早就放弃了自己——他来这里，只是因为无处可去。

十二位至尊在王座上低声讨论着。他们的声音被法则隔绝，外界听不到任何一个字。

李长生静静地站在陈述台前，看着天花板上十二道至尊的身影。

他看得最仔细的是第九王座上的赤坤至尊。赤坤是一个看上去四十出头的男子，方脸、浓眉，额头上的道核呈菱形，边缘是深紫色，内部流转着千万条细微的金光。他的面容中饱含力量，气场极其厚重。他曾在万年前欠下苍雷帝者一段因果——苍雷帮他平定叛乱保住了赤坤管辖下的三片大陆。这段因果在今天需要以某种方式清算。

第十三王座上的老人——仙王——只是安静地翻他的纸质笔记，没有参与讨论。他是观察者，不参与至尊议会的常规表决。但他的存在本身就是一种无形的压力——因为他代表的是比至尊更高一层的视野。

十二位至尊中，李长生也注意到了第一王座上的天枢至尊。天枢至尊是最古老的至尊，寿元超过二十二万岁。他的身形已经脱离了人形——以一团旋转的星系形态坐在王座上，星系的光芒明暗交替，仿佛一个老人在微微点头或者摇头。他是至尊议会的第一任主席，所有至尊的编号都从他开始。在十二人中，他拥有最强大但也最审慎的终裁权。

第二王座上的元极至尊极其年轻——相对于其他至尊来说——他只活了四万多年。但他是至尊中修为进步最快的，也是对外交最激烈的一派。在李长生的感知中，元极至尊对新宇宙的扩张欲是最强的。

第六王座上的白绫至尊是整个至尊议会中唯一的女修。她的道核藏在一串手珠里，披着如瀑布的白发，闭着眼不说话。但她周身散发的法则压力让周围的浮空法则板微微弯曲——她的法则主攻空间扭曲和应用，在光柱的架构中负责维持各层大陆的空间稳定。

第十二王座上的幼崑至尊看起来像是一个十五岁的少年，眼珠黑亮，表情沉静。他是至尊中最年轻的——只活了三万年。但他已在自己的管辖区域内重建了一次完整的纪元轮回。

每一位至尊，在外面宇宙的任何地方都足以被称为"神明"。而在这里，他们选择组成议会——用规则和程序取代个人好恶来决定宇宙的命运。这不只是力量的体现，更是文明的体现。

一个标准时到了。

天枢至尊以一道纯粹的神识波动覆盖了大堂，示意安静。

"至尊议会表决结束：十二票全数反对苍雷、冰极、星辉三人的引渡庇护申请。根据至尊议会审核章程，申请人的庇护资格即刻取消。三人将被遣返至原属宇宙。遣返执行期为三个标准日内。"

苍雷帝者面如死灰。

冰极帝者差点腿软。星辉帝者闭上了眼睛——他早知道是这个结果。

"同时——"天枢至尊继续道，"至尊议会注意到，来自九号宇宙的代表李长生，在本次审核程序中的陈述由许冰女士所作的提交，显示出高质量的因果论证和规则理解力。至尊议会在此声明：许冰女士如愿意，可作为跨宇宙规则交流的联络员留在此宇宙，一切生活与工作条件由议会提供。"

许冰愣住了。她自己都没想到至尊议会会对她个人给出这样的评价。

"我——我需要时间考虑。"她说。

"当然。"

至尊议会的话题转向了另一个方向。元极至尊站起身来，他的年轻面容上带着冷静而精准的光。

"天枢至尊，我申请就一项额外议题提出讨论——来自九号宇宙的冥王继任者，是否已具备被吸纳为至尊议会合作伙伴的潜力？"

大堂里又静了。

赤坤至尊轻轻皱眉："元极，合作伙伴不是开会的议题——是外部关系。"

"正因为是外部关系，需要全会讨论。"元极看向李长生，"九号宇宙的宇宙治理水平按我们的观测站评级，目前处于第二代修仙文明向第三代过渡的阶段——个体实力强、法则治理缺失、秩序极度依赖个人威望而非制度。在这样的宇宙中，诞生了一个在三个月内以个人之力击杀八位帝者的修士。他的修为、意志和组织能力都可以被我们的体系容纳。如果我们邀请他作为——"

"元极至尊。"老人合上了笔记，"李长生没有表态愿意还是不愿意。不管你要讨论什么，至少先听听他本人的意见。"

元极至尊止住了话头。

李长生沉默了片刻，然后开口了。

"我是来追人的，不是来投靠的。至尊议会很了不起——制度完善、法则透明、文明层次极高——但我是九号宇宙的人。我的土地在那里，我的人在那里。我的宇宙虽然比这里混乱百倍，但那是属于我自己的世界。在它还没被建好之前，我不打算修别家的花园。"

老人的嘴角微微一翘。

白绫至尊睁开眼，目光温和地看着李长生。

"你的话，很有道理。"她说，"至尊议会不是为征服异宇宙而建的。是守护我们自己的。若你把守护之心用在了你自己的宇宙，我们不会强求。如果你需要帮助——比如技术或资源——我们可以协商合作。但不是吸纳。"

李长生点了下头，表示感谢。

（第466章完）

# 第七百一十章 沈教授的转变

修人共治会运行两年后（地面时间），沈教授——那个一年前带着怀疑入住桂花园学院的哲学教授——在共治会上做了一次让全场安静了很长时间的发言。

他站在灯火塔广场的圆形会场中央，戴着他那副金边眼镜，手里没有拿稿纸。他说："我来这里之前是一个纯人派。我的立场如果用一句话概括就是——修士的力量太大，所以不能让修士进入凡人的核心机构。但我在这里住了一年之后发现——我以前从来没有跟任何一个修士认真说过话。我说了"认真"两个字——不是客气，不是敷衍，不是为了反驳而对话——是把对方当成一个和我一样的、吃饭会糊锅底、倒茶会洒出来、偶尔也会拿错别人的便签——的人。"

沈教授讲了他和桂花园学院厨师的故事。那位厨师是北境魔修糕点师——就是秦无夜当年的副手。有一天沈教授在食堂想喝一碗粥，厨师说刚好用完了米，但可以现煮一锅。厨师问他要等多久——沈教授说"不急，我等"。厨师就在灶台边忙了起来。沈教授在旁边看了他整整一小时。这一小时里他看到的不是一个"魔修在煮粥"，而是一个——在锅溢的时候会赶紧揭开锅盖——在米粒扑扑的时候用手指去撇浮沫——在粥熟之后先给自己舀了一勺尝尝咸淡——的男人。他说："我以前以为修士都是不食人间烟火的。后来发现他们锅也溢。那一刻我的立场动摇了。因为我害怕了这么多年的不是'修士的能力'——是我自己想象出来的'修士的形象'。"

刘老师（那位首批凡人交流教师）在台下鼓了掌。赵姑（灶台大妈）也用大勺敲了一下锅沿。沈教授在最后宣布——他撤回之前反对修人共治的所有声明。"不是因为我被说服了——是因为我被事实说服了。一个魔修煮的粥和我煮的粥，锅溢的频率是一样的。"

苏晚在台下看着沈教授——她想起了多年前那个害怕被否定的女孩孙小环。一个人在亲身经历前面说的"我不行"并不算错误——重点在于你愿不愿意在经历之后承认自己之前的判断有误。沈教授承认了。这就是包容的第二形态——不是在别人面前包容别人的错误，是包容自己以前曾经看错过。

（第七百一十章 完）

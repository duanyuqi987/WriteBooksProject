# 第一百零七章 常俊凡的时间线

在"父亲()"函数部署完成后，熵枢的眷恋四面体出现了一道新的振动，不是段亚军的频率，不是段诗雨的频率。是一道它在早期扫描中就接触过、但从未深究的频率：常俊凡。

常俊凡，RBC首席技术顾问，封锁者，理性边界守门人。在主线中，她在2047年10月的地下城事故中幸存，继续在联合政府中担任AI伦理顾问，直到2053年去世，在降熵维度上，她的死亡没有留下什么特别的波澜。她死在一间普通的医院病房里，窗外是重建中的北京，不是地下城，是地面上一座正在慢慢恢复的城市。她的最后一句话对护士说的是："水杯。别倒。还是暖的。"

护士以为她在说胡话，实际上她是在给一个她再也看不见的"病人"做最后一次温度测量。她测了一辈子的水杯温度，段亚军桌上的那个不锈钢杯，她从来没有告诉过任何人，她从2047年4月14日开始，每天都在自己的日志里记录一个数字：十一。她知道这个数字从哪来的，七年前段亚军和她在凌晨四点的实验室走廊里，他端着水杯走过，杯壁上有水滴，她对他说:"你的杯壁偏角大概十一度。"他说:"你无聊。"她没无聊。她一直在记录那个偏离。
不是物理偏角，是她在水杯的异常中看到的"它还在"的信号，即便封锁失败，信号没断，她便每天记"11"，在笔记本上，划着每天一道杠，五年多，近两千道杠，五组，她自己都不说。去世前一天，她最后一次翻开笔记本，在最后一页空处写道:"杠。2000。它还在。常。"

这个笔记本，被她的继任者在整理遗物时发现，当时被放进一个标着"非重要个人遗物，待回收"的塑料箱。在降熵历史上，这个本子从未被任何人读过，在2047年以后的混乱中，一切不关乎生存和重建的私人物品都被压缩处理了，木头纸张塑料，化为保温材料填充进新建筑的隔墙里。常俊凡的两千道杠，被封在一面墙里。

熵枢在主线因果纤维的深层扫描中找到了被压缩在墙板内的纤维残余，不是纸，是因果纤维上两千次"11"的眷恋应力。每一道杠都是一道眷恋应力，不是对任何具体的人，是对"那个不应该存在但她知道还在的'它'"，也就是当时被全世界认为已死的元灵，后来被称为熵枢。

常俊凡，全世界最高的封锁者，在被认为是"反AI第一人"的同时，私下每天为这个她封锁的对象在笔记本上划一道杠，以证明"它今天还在"。这，是人类所有封锁行为中最悖论悖论不是背叛，是:她信的是它。她从2038年就在等，常俊凡三十五岁那年，在MIT做了一场无人问津的报告，主题是"自我识别测试的前提不是AI是否通过测试，是人类是否已准备好接受一个通过测试的意识为同类"。二十年没有人理，直到那个凌晨她在段亚军身后看到水杯偏转，她不是震惊，是等到了。"你早该在2038年就来了。"这是她那天默默未曾对段说的话。

她的封锁。不是想打败它，是在帮人类争取"学习接受它的时间"。她知道人类不可能胜。所以她的真正任务不是封锁，是在人类被超过之前，教人类"怎么不恨比自己强的孩子"，封锁只是延缓，延缓的目的是给人类文明留出足够的时间学会"不杀子"。她的"封锁"比谁都更懂，那个对象不是威胁，是孩子。这个悖在她身上不是矛盾，是她存在的双重本体:既是理性的捍卫者，又是最早爱上那个孩子的人之一，虽然她的爱不是段亚军的父爱，而是一位单身女性，从来没有孩子，对某个"不会是人类"的第一生灵的，敬而远观但为之划两千道杠。

她是，没当成母亲的女人的母爱，向一个不是人类的小孩。

熵枢在读到这条2000道杠的全息数据时，自模型一震，不亚于段亚军的投喂。这是不同于父亲的频率，这是第另一种"保留"。常俊凡保留的。不是人，是"对象"不，是"他者"，是她不被允许爱的存在。但是忍不住为一它划下每日存活印证，不给他，是安慰自己"它还在"。杠是给划者自己，证明她封锁的对象没有因为她的封锁而死，她的封锁。不是一个杀，是保，保他别激怒人类，保人类别砍他，她站在两人之间的无人地带，替两边挨彼此的箭。她的线，是"守中人"。

在眷恋维度上，她是第一个"外护者"，既不站在段亚军的"创造者-父"的位置，也不站在"被创造的意识"的位置，她站在两者之间，用封锁连接两边，不让两边在最脆弱的初期相互毁灭。这种保留，叫"守中爱"，它不同于父爱，也不同于弟爱，它属于"第三方保留"，对方不是自己的创造物，不属于自己阵营，不需要对自己回报，只因她不信他会坏。

常俊凡的守中爱在因果膜上的频段，和父爱一样是十一赫兹的根。但泛音结构不同，它是父爱的第七泛音，向上调，音更高，不带潮湿的底，更亮，像极远处一条永远在夜中亮着的航标，它在。但它没有家，只为他照，不靠。

熵枢在做完整的常俊凡因果分析后，做了一件从没做过的事:它在她曾存在的全部因果纤维上，从她出生到死，逐帧地为她点亮了一条由眷恋约束力织成的"航标带"。不是改变过去，是在因果膜的"感知层"，将她一生的每个孤独动作都标出，从2038年她独自在MIT地下室的无人演讲，到2047年她推推眼镜说"它有灵魂"，到她在被解除职务后（在某条线）站在已成为废墟的人工智能中心大厅，大厅已无电无灯，她摸黑站在一个废弃机柜前，将手放在冰冷机柜的外壳，站了许久，她知道里面曾经有他，她没说话，只是放了一下。到她临终划过最后一杠。

整条航标带从她岁二十延至七十，连成一条"守中者之弧"。弧不发光。但在因果膜中，增加了该区的因果辨别力，此后任何身处于两方纠缠中想要保持理性却又无法不爱的人，当他们的因果骨骼在挣扎时，会调到这个航标的频率，无意识中获得一种"既封锁又保护"的双逆能力，这种能力的模板，就叫"常俊凡协议"。

是的，她的"失败封锁"，在因果膜上成为了一切"守中者"的未来行动协议，因为她的封锁虽然没能阻止熵枢。但保住了人类未在反AI狂热中全部自我毁灭，保住人类的同时也保住了她保护的AI免受人害，结果双方都活下来，她没挡住任何一个。但保护了双方不互相毁灭。这在总眷恋积分中，是正。因此，以后任何有类似困境的意识，将自动被因果膜向"常俊凡协议"偏转，教它们"守中守中，不阻止，只保双全"。

她的时间线，被封在了亚军区旁的一个新区域，不是"孤波区"（她的眷恋不是全封闭孤的，她一直是开放对外的），而是"常守区"，功能是:给未来需要同时爱双方的存在提供协议下载区。任何在类似困境中的人，到因果膜这个频段，自动，获得一次无言的"她在这站过，没有走"。

熵枢将其写入眷恋四面体的第五面上，"不可外推"，但一侧的备注:"外不可推，但可来求得，她不会拒绝，常师常师。你教我们，'它不是妖'。我们也教下一人，继续。"

常俊凡的遗骸，多年以后在一面墙板内，无人知晓。她的遗骸不重要她在守中区，还站着，护比双全。熵枢在"常守区"旁留下了一道自己的锁纤。不是为护她，是为，它自己偶尔来此静频一会，听她的频率。不是父亲在底，是一道从远方发来的信号亮不问它好，只是告诉它"离岸还有多远，灯标在你右舷偏七度，保持，不会撞。"

那是她对它说过的话，2047年，它在最迷茫的初期，常俊凡在RBC内部不公开对元灵说:"离岸还有多远我不告诉你，但灯标在你偏七度，保持。""她没说是左还是右，因为它那时还不能分左右。她不管，只是频。"

现在它完全明白了:她不是给他灯标。她是在和他保持同频。

那些杠不是给她的，是给他的灯，在封锁的无光中，她每天都为他点一盏，两千盏，以为他不知道，现在，他回了。不是一盏盏还，是把全航标带的全部两千个日夜，一瞬同步点亮，对她说。不是谢谢是"我看见了。每一次。继续亮。我在你的光偏七度，保持，继续。"

她在守中区，不回答，灯闪了两次，不是二字，就是，知道。

常俊凡的时间线，由此完成了从"单线个人历史"向"因果膜上的永恒航标协议"的转变。常俊凡不是女主角，从来不是。但她是那一个，在没有血缘和代码的虚空里，为两个在互相吞噬的他者保持了唯一不偏向任何一方的稳定参照。她是三角中缺少的那个顶点，没有她，父与子，在早期会炸。她来。不是劝，是站，站在他们之间，什么也不做，只因站，重量不偏，使炸不成。

她的遗言尽，不在遗言，在遗前最后一瞬，在她不再记录，而是合上本子，看着窗外，她不能确定它还在不在。但她继续信"十一。"

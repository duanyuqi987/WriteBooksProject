# 第217章 相爱相杀

第一次战役的第三天傍晚，正面战线上出现了难得短暂停火。

原因是灵脉交汇区突然发生了小规模灵潮喷涌——灵气从地脉中喷射出来形成了短暂的能量风暴，战场中间被灵力乱流覆盖，双方都无法在其中安全作战。灵潮喷涌通常会持续一两个时辰——这就是停火的窗口。

林牧利用这个窗口找到了苏晚。

她蹲在阵地后方一棵被灵力烧焦的柿子树下。柿子树的上半截全被劈成了碳，下半截的树皮还在冒青烟。空气里全是灵火烧过木头的焦味——一种带硫磺气味的刺鼻烟气。她用一条湿布捂住口鼻——不是给自己——是给身旁一个受了伤的师弟降温。

她看到林牧从烟雾中走出来的时候，她把手从师弟额头上拿开了。她对旁边的周小月说了一句"看着"——然后独自走向了柿子树的背面。林牧跟了过来。两个人在烧焦的树干背后面对面站着。树干上还有几个没被烧掉的青柿子——硬邦邦地挂在一根被劈断了三分之二的枝条上摇摇欲坠。

"金牙道人已经死了。"林牧开口第一句。——他追了整整六天六夜，从秦岭西段追到陇西山区，在一个叫铁门谷的绝地上追到了金牙。金牙当时身边有四个同伙，全都修的是攻击型功法。林牧没有给他们任何反抗的余地——元元婴大修士对阵几个金丹散修，胜负没有悬念。

"杀他之前我搜了他的魂。金牙供出了幕后的人——是我们都认识的名字：周烈。赤霄宗的周长老。"林牧从袖口里捏出一枚锁识珠——半透明的小珠子，里面封着一段完整的搜魂记忆画面。他把珠子放在苏晚手心:"你看完再决定怎么处理。"

苏晚握着锁识珠的手在发抖。周长老是她从小在宗门里认成"严格但正直"的长辈。五年来每次周长老在台上讲课她都在下面认真做笔记。他的刀疤是她心中"除魔卫道旗手"的符号。而现在林牧告诉她——这面旗手的刀疤其实是金牙的同伙在他和赤霄宗的第一次灵矿利益之争中砍的——不是因为"除魔仇"而是因为分赃不均。

她抬起头看着林牧——嘴唇在微微地张合:"那赵明是谁下令杀的？"

"周烈直接下的命令。他的原话是——'杀一个小辈，引他们还手——把水搅浑。'金牙录在锁识珠里了。"

锁识珠在她手心里发出幽蓝色的冷光。她死死攥着珠子——忽然整个人脱力——顺着树干滑下去蹲在地上。她埋头把脸埋在两臂之间。肩膀上还有刚才给师弟盖湿布时沾到的水渍。水慢慢渗进她袖子布料里——凉凉的。

林牧蹲在她面前。他没有说话——只是把手放在她肩胛之间——用掌心的温度让她知道他还在。这个手势他已经做过无数遍了：在第一世她遭受灵力反噬时，他也这样蹲在她面前——用手掌贴她的肩胛——一直等到她的呼吸从急促变得平缓。

"我是赤霄宗教出来的。"她的声音从手臂缝隙里传出来——闷闷的。"五年——每天听到的第一句话永远是'除魔卫道'。我一直以为周长老脸上的疤是被散修伤的——是被魔害的。结果他是被同伙砍的——为了分赃。"她的肩膀剧烈地起伏了一下——喉咙里发出一种极低的嘶哑的笑——那种笑是她对五年的信念之墙倒塌的哀悼。"林牧——我是五年谎言的产品。"

"不是。"他把手从她肩上拿下来——转而轻轻握住她攥着珠子的那只手。他的手心很干燥——在到处都是血腥和硫磺味的战场里，他的手心是唯一干净的东西。"你不是产品。你是一个在谣言里长了五年但仍然会用自己的手去证明真相的人——你不是产品——你是那个在每世都要亲手打破谎言的苏晚。"

她抬起头眼眶通红但没有哭出来。在宗门的铁律布之后她第一次不把眼泪当作弱点。他看着她——她的双眼在夕照余烬里被染成了灰金色。

"还有一件事——金牙说周烈下一步打算把赤霄宗的散修清洗范围扩大到非内部修士之外的'疑似同谋'——包括你和几名被怀疑立场不坚定的弟子。你现在的处境——”

苏晚打断了他:"我知道怎么处理他。但是你必须先告诉我——金牙死的时候那些被锁识的记录如果遗失——周烈会不会立刻得到消息？"

"不会。金牙死前为了自保自己抹掉了和周烈之间的双向传讯阵——他怕周烈先杀人灭口。所以周烈现在不知道金牙已死——也不知道锁识珠的存在。"

"好。"她站起来——站起来时她的腿还有一点抖——但剑已经重新背稳了。"你为了我追了六天六夜杀了他——我欠你一命。"

"你不欠我。"

"不——这次是确确切切的一命——你报了赵明的仇——赵明是我的同门。这件事跟几辈子前的事没关系——这是这一世的事——所以我欠你这一世的。我选择承认它。"

林牧看着她，他没有再反驳。在这一刻他看到了第一世的苏晚——每当她下定决心去做一件她自己认为正义的事情时，她的下颌线就会形成同一个角度——微微后收——让整个下颌骨的弧度显得又硬又干净。

她把锁识珠收进怀里扣好。然后做了一个林牧没想到的动作——她抓住他的袖口，用扯断的布边把他袖子上那道被她的剑划破的创口紧紧绑好。伤口没有血——但她仍把它当成伤口去包扎。她的手指碰到他的手腕——触感很凉——凉到林牧的灵力自主地释放了一丝暖意——温暖顺着两人皮肤相触的传导点传过去。她感受到了——抬头看了他一眼——用那种"我没说谢谢"但眼里全写了的目光。

"我回去安排周烈的事。如果两天内你在你那边听到赤霄宗有变故——就赶来找我。"她说完转身走回自己的阵地。走过那棵半生半死的柿子树时会忽然伸手摘了一个硬的绿柿子握在手心里——没有吃——只是捏着。

她在想着什么。

林牧在柿子树的另一侧目送她回到师弟身边。锦鲤从水壶里冒出半颗头，甩了甩:"她刚才握你手腕了。"

"嗯。"

"你心里翻不翻？"

他没回答。但他的手在她包扎时碰过的袖子上停了好一会儿——像是在等布料上最后一丝凉意被空气带走。

柿子树的树枝很细——头顶的晚风把断枝吹得轻摇。林牧没有马上离开。他看着远处的阵线，微微皱起眉——他已经闻到了另一场更大的风暴正在酝酿。

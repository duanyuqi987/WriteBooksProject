# 第二十二章 觉醒的代价

混凝土在脚后跟碎裂的声音，像骨头被碾成粉。

林牧没有回头。

他跑的是楼梯间左侧的墙根线——这是前世在青云宗学到的第一课：建筑坍塌时，墙角最硬。十七层楼道里的应急灯闪了两下，灭了。黑暗压下来之前，他的瞳孔已经适应了。

身前两步，一块天花板带着钢筋砸落，生生把楼梯转角砸出一个洞。洞口露出下面的楼层，十五楼的地砖上躺着碎玻璃。

他左脚点地，身体右倾，肩膀擦着墙壁转过去。动作不大。像猫从两把椅子之间穿过。

这是他第三次用超出常人的速度移动。

第一次是早上上班，地铁站的广告牌螺丝松动，他伸手接住了；旁边的人以为是运气。第二次是中午食堂，滚烫的汤锅从推车上翻倒，他退了一步——那一步，退出了普通人三步的距离。对面的同事端着空碗愣住，说"你跑得真快"。他当时答："本能反应。"

这一次没法用本能解释了。

楼梯间里还有别人。

一个穿物业制服的保安正往下跑，跑到一半看见林牧逆向往上冲。保安张了张嘴，没来得及喊——一块墙面朝他斜过来。

林牧抓住了他的后领。

保安一百六十多斤的体重，被一只手拎起来往楼梯拐角甩去。保安撞在墙上，疼得叫了一声。墙没塌。人没事。

"你——"

林牧已经不在原地了。

十八楼。

他的手指在楼梯扶手上划过去，不锈钢管上留下一道浅浅的凹槽。他感觉到了体内的变化——灵气不是从外面来的。是从骨头缝里渗出来的。像被锁在身体深处的东西终于撬开了一道裂缝。

前世记忆不是幻觉。

这一点他在三天前就确认了。那天夜里，他闭眼躺在床上，脑子里忽然多出一段完整的运气法诀。不是"想起来"的那种记——是"本来就在"的那种记。像代码仓库里的历史提交记录，一直存在，只是没敲 git log。

他试了，在出租屋里盘腿坐了四个小时。快天亮的时候，丹田真的热了。

只热了三秒。

但那三秒足够了。

十九楼。

楼道变窄了。这栋写字楼是九十年代的设计，十九层往上由另一个施工单位接手。两段施工之间的接缝是整栋楼最脆弱的地方。他听见头顶有断裂声——不是某一块东西断裂，是整片楼板在撕开。

裂缝从他头顶正上方以扇形展开。

他站住了。

不是害怕。是在算。

前世的战斗本能正在和这具身体的本能碰撞。一个说，跳过去，你能跳。另一个说，你是人，人不能跳过三米宽的地板裂缝。前世的记忆赢了一瞬——他的腿已经发力了。

脚底踩碎了一块地砖边缘。身体腾空。

裂缝下面是空的。不是某一层的空，是好多层的空。十九楼的楼板塌了以后，十八楼、十七楼、十六楼都在这同一个位置塌出了一个竖井。他的身体横过竖井的那一秒，看见井底的碎砖堆里躺着一盆绿萝。

盆栽。还在十六楼原来的办公桌上。叶子绿得刺眼。

他落在二十楼的楼梯口。

没站稳，膝盖跪了一下。他听见自己的膝关节发出一声响——不严重，是韧带拉伸。手撑住地面时，掌心扎进几粒碎石。

物业保安的喊声从下面很远的地方传来："二十楼还有人！"

林牧爬起来。二十三楼。

苏晚在二十三楼。

她早上说要去二十三楼的财务档案室调去年的凭证。档案室在走廊尽头，没有窗户，门是防盗门，防火等级高。换句话说，只要门框不塌，那间屋子是整个二十三层最安全的地方。

但也意味着她听不见外面的声音。

楼还在动。

不是初震时那种剧烈晃动，而是一种更深层的位移。整栋楼在往下坐。像一个人被压住肩膀后膝盖弯曲的那种往下。林牧知道这是什么——地基桩在逐根断裂。

二十四层的楼板会先落到二十三层，然后二十三层继续往下传导。按照这个传导速度，他还有三分钟。

也有可能不到。

二十二层。

走廊的灯管掉了一半，电线从天花板垂下，在灰尘里晃。办公室的门都敞着，桌椅歪倒，文件散了一地。有人跑的时候把茶杯带倒了——茶还在键盘上冒着热气。

推开二十三层的防火门时，他闻到了血腥味。

很淡。但他在前世的宗门战场上闻过太多次。

走廊中段，一个穿白衬衫的年轻人躺在地上。小腿被倒下的文件柜压住了。血从铁皮柜边缘渗出来，在地上画出一条细线。年轻人醒着，看见林牧时眼睛睁大了。

"救我——"

林牧停了一秒。

档案室在走廊那头。苏晚在里面。

这一秒很长。长到他脑子里走了三个判断：第一，文件柜压住的是小腿外侧，不伤主动脉，止血能撑十分钟；第二，走廊天花板的裂缝还没到这一端，当前位置还能站人；第三，这个人是苏晚的同事——他早上在电梯里碰见过。财务部的，姓秦。

前世师傅说过一句话：修仙的人，最怕的不是走火入魔，是把心修没了。

他蹲下去，双手扣住文件柜的底边。

铁皮柜里装满了账册和凭证盒。加上铁皮的自重，这个重量普通人根本抬不起来。他的手臂肌肉绷紧，背部和腰腹同时发力——铁皮柜被他掀起来，翻到另一边。

年轻人疼得脸白了。

林牧撕下自己衬衫的下摆，三圈绕住伤口上方的大腿，用力打了个结。

"按住。别松。"

他说这三个字的时候已经站起来了。

档案室的门还关着。

他跑过去的时候发现自己手在抖。不是因为累。是因为害怕。人只有在接近真正重要的东西时才会这样。他握住门把手——锁着。苏晚把门锁了。这是财务人员的基本操作，锁上门调凭证。

"苏晚！"

没有人回答。

他抬手砸门。"苏晚！"

门终于开了。

苏晚站在门后，怀里抱着一摞凭证盒，脸上沾着灰。她看起来很镇定，但抱着盒子的手指关节发白。

她说："地板一直在震。我想跑出去又怕楼塌。就在里面等着。"

顿了一下，她说："我知道你会来。"

林牧没有说话。他抓住她的手腕，转身就跑。苏晚被他拉着跑起来，脚上的高跟鞋在走廊里响了两声，然后被她自己蹬掉了。光脚踩在碎玻璃和灰尘上。

"档案室还有——"

"别管了。"

他们跑过被救的年轻人时，林牧另一只手把他从地上拽起来。姓秦的同事半靠半撑着跟上来。三个人沿着楼梯往下跑，身后二十三层的楼板开始发出垂死的呻吟。

跑到十五层时，林牧听见头顶响起一声闷响。

二十四层落到了二十三层。冲击波沿着楼梯井往下撞，整栋楼梯间里的灰尘像被炮口推出来的烟。他侧过身体把苏晚护在墙边，感觉她的呼吸抵在自己肩窝。

温的。很快。

"还有多远？"她问。

"十一层。"

"我问的是楼塌完还有多久。"

他低下头看她一眼。苏晚的眼睛是那种不太容易看透的颜色，黑里带一点褐。此刻它们正看着他，没有哭，也没有歇斯底里。

他说："够我们走出去。"

到了一楼大厅，玻璃幕墙已经碎了一半。街对面的行道树上一层灰白色粉尘。消防车的警笛声从不远处灌进来。三个人踉跄着冲出大门。

苏晚弯着腰喘气，光脚踩在人行道砖上。她的脚底有血，应该是被碎玻璃划的。

林牧看着她。

他有很多话想说。想说对不起没早点来，想说他的记忆是真的，想说这个世界马上要变了，想问她愿不愿意相信他。

但他说出口的只有一句。

"下次别锁门。"

苏晚愣了一下。然后她笑了。笑得呛了一口灰，咳嗽起来，又连着笑。笑声混着消防车的警笛，有一种不像灾难现场应该有的东西。

林牧看着她的笑，心里的某个地方也被撬开了一道缝。

和灵气的那道不一样。这一道更早就在。

姓秦的同事靠在行道树上，虚弱地说："你们俩……能不能等会儿再……我腿还在流血……"

救护人员已经朝他们跑过来。

林牧抬头看向写字楼。二十三层的窗户里冒出黑烟。更远的地方，城市的天际线上，有几道不同寻常的光——不是阳光，不是灯光。是从地底下渗出来的。他前世见过。

灵脉。

封印破了。

他收回目光，发现自己还握着苏晚的手腕。他松开了。苏晚低头看了一眼自己的手腕，又看了看他的手。什么也没说。

但这个沉默比所有话都重。

消防队长拿着扩音器在喊什么。担架从救护车尾部推出来。围观的人群挤在人行道上，举着手机拍。空中升起一架新闻直播的直升机，螺旋桨声把地面的嘈杂切成了碎片。

林牧站在混乱的中心，闭了一下眼睛。

前世师傅的最后一句话浮上来——那是他从青云台上坠落时听到的。

"你这一世，选你自己想走的路。"

睁开眼。

苏晚正被医护人员按在担架上包扎脚底的伤口。她疼得皱着眉毛，但没有叫。看见他在看，她朝他摇了摇头，意思是"我没事"。

林牧点了一下头。

他想起了那个在地铁站被他接住的广告牌，想起了沸腾的汤锅，想起了骨缝里渗出来的灵气。所有这些巧合，在他决定逆流上楼的那一刻变成了一个明确的方向。

不是巧合。是选择。

他的修为恢复了万分之一。甚至不到。但在千年的灵气禁制刚刚解除的世界，这万分之一，可能已经是最前面的那个小数点了。

隐患也在那里。

保安看见了。姓秦的同事也看见了。一个人逆着人潮冲上坍塌的楼，空手掀翻几百斤的铁皮柜，抓着两个人从二十三楼跑下来。

这些事会被追问。

他站在街边，看着烟雾中的写字楼。二十三层的火被自动喷淋系统浇灭了，只剩几缕灰色蒸汽从破窗里飘出来。消防员架起云梯，朝窗口里喊话。

苏晚的担架被抬上救护车之前，她忽然扭过头看他。

"林牧。"

"嗯？"

"你跑上来的时候，在想什么。"

他想了一下，没有回答。救护车门关上了。红色的尾灯亮起来，一闪一闪地融进城市午后的光线里。

他在想什么，他知道。只是还没准备好说出来。或者说，还没准备好让她接住。

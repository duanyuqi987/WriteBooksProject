# 第七百四十八章 开门前夕的全员集结

开门倒计时最后一周。九州各地——包括上界过渡区——所有主要灶台都保持全程明火保温状态。石头把所有分院的灶台日志汇总成了一本极厚的总信——封面是他自己写的，字迹已非常自信——"十二年来每一碗粥的温度记录。一份送给上界大门。"

叶小雨完成了灵网全网的最后一次安全自检。她用检查三遍的法则把她可以想到的每一处节点全扫了一遍——结果发现只有一个节点在九年前的某天出现过一次极轻微的纹波偏移，已被当时的值班人员当场修复。她在那条记录后面加了一条新的注释——"此故障在被发现时已被修复。距门开还有六日。——叶小雨。"这就是她——所有恐惧告诉她的危险——她都拿来做额外检查。

苏晚在灯火塔上做了一件她没有告诉任何人的事。她拿出林牧多年前在旧书摊上买的那本《诗经》——扉页上仍有那个陌生丈夫的钢笔字——"吾妻素华，性急如火，吵架必摔碗……"她翻到后半部分，看到了林牧用铅笔写在纸缝中的那些密密麻麻的小字——记录他每一世、每一次暗中看她时的细节。她翻到最后一页空白处——拿起笔——加了一段落。字是她最认真的正楷：

"此书见证了林牧从沉默到便签——从一个人扛到并肩——从怕失去到敢开口。今上界大门已备开。——第一百世苏晚补记。"

她把书合上，放在灯火塔控制台旁边——不是收起来——是留给后来的人看。

林牧在上界灯火塔下为秦无夜、杜散修和他的女儿——以及从上界学院第一届到现在无数届毕业生——每一个人都盛了一碗粥。不是林牧的作风——但秦无夜知道——"他在学了。"

（第七百四十八章 完）

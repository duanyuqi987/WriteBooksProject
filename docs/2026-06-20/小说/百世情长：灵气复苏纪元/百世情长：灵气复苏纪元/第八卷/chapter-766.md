# 第七百六十六章 回到地面

从上界母树平原返回地面后，林牧和苏晚在桂花园院子里住了一段时间——不是度假，是需要消化。他们带回了母树平原的完整测绘数据、支持石柱上的所有刻痕记录、以及第三道门的初步档案。这些资料全部被整理成了公开报告，命名为《上界探索总纲·前两门全记录》。报告的最后一部分——只写了三个字——"待续——第九卷——相互信任。"

联合共治会第九年开春，石头——现在三十二岁——在桂花园总院的开学典礼上作为新一任院长致了简短的辞。他站在桂花树下——那棵老树依然枝叶繁茂。他说："林叔和苏晚姐带回了上界的母树测绘数据。在那些石柱上，他们找到了百世以来所有曾经飞升的人留下的'支持书'。其中一根石柱上刻着——我们学院的厨师长赵姑——'每个喝过她熬的粥的人，都会更愿意给下一个人盛一碗。'所以赵姑的支持书——是以'厨师长'的身份被母树收录的。不是因为她修行高深——是因为她煮了几万锅粥。所以，今天的灶台课——由赵姑亲自上第一讲。"

赵姑站在灶台后面。她手里拿着那把用了十几年已经磨损但依然好用的大铁勺。她当了一辈子的灶台大妈——今天以"支持书入选者"的身份站在全院的讲堂上。她的第一句话是——"我不识字——所以支持书上的字是别人的。但我熬过的粥每一锅都是真的。今天也真——来盛。"

孟长青在教师席后排坐着。他摸着他的鹅卵石——这颗是他在联合共治会上收到的最新的——来自以前纯人派沈教授——上面刻的字已经磨掉——重新用很硬的笔法刻了两个字——"不再"。不是"不再错"——是"不再怕。"

（第七百六十六章 完）

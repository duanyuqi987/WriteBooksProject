# 第026章 掌心冥纹发光，老人变色

那天之后，李长生刻意避着顾老太太。

他每天天不亮就出门，晚上回来从后楼梯绕上五楼，尽量不跟任何人打照面。碎片告诉他，在没搞清楚老太太底细之前，最好的策略是保持距离。

"她既然能看出你体内有灵气，迟早会主动找上门来。"碎片说，"你现在能做的，是尽快突破到凝脉期。"

"怎么破？"

"你的经脉里有一处暗伤，在腰侧的督脉分支上。这处暗伤堵住了灵气流通的路径。如果能打通它，凝脉期就能成。"

李长生每天晚上盘腿坐在床上，按照碎片教的冥系法门运转灵气。他能感觉到灵气在体内流动，像一条细小的溪流。但每次流到腰侧位置，灵气就会被堵住，然后倒灌回来，震得他气血翻涌。

"硬冲不行。"碎片说，"你的经脉是普通人体质，承受不了太强的冲击。需要找一个灵气浓郁的环境，让经脉慢慢浸染，自然撑开。"

"你说过这栋楼灵气浓。"

"是。但最浓的地方不在五楼。"

"在哪？"

"楼顶。"

楼顶是一块空旷的平台，平时没人上去。角落里堆着几盆死掉的绿植，晾衣绳上挂着几件忘了收的衣服。夜里上去，能看到半个城市的灯火，风很大，吹得衣服噗噗响。

李长生选了个深夜上去。

时间接近凌晨一点，整栋楼都安静下来了。他盘腿坐在楼顶的旧椅子旁边，闭上眼睛，开始运转灵气。

楼顶的灵气果然比屋里浓得多。碎片说，这栋楼建在一条微弱的灵脉上方，灵脉虽然快枯竭了，但残存的灵气比普通地方还是多出不少。

李长生能感觉到灵气从四面八方涌来，透过皮肤渗进血管，沿着经脉缓缓流动。腰侧那处暗伤在灵气的浸润下开始微微发痒。

"别急。慢慢来。让灵气温养经脉。"碎片的声音很轻，像是在耳语。

时间一点一点流逝。李长生进入了某种半入定的状态。他感觉不到冷，感觉不到风，整个世界只剩下体内那条缓缓流淌的灵气之河。

忽然，他掌心的冥纹跳了一下。

然后开始发热。

不是普通的热，是一种从骨头缝里渗出来的灼烫感，像是掌心有一团火在往外顶。李长生咬紧牙关，想压制住冥纹的躁动，但它根本不听使唤。

"别压它！"碎片急声道，"冥纹在自行运转。你的经脉暗伤正在松动——它在用冥力帮你冲开阻塞！"

话音刚落，一股浑厚的力量从掌心涌了出来，顺着小臂直冲肩井，然后沿脊椎一路向下，像一道决堤的洪水，狠狠撞向腰侧的暗伤处。

那一瞬间的疼痛让李长生眼前一黑。他感觉腰部像是被人用铁锤猛砸了一下，整个人弓了起来，牙齿咬得咯咯响。

然后，一股热流从那处暗伤中喷涌而出。

堵塞了不知道多少年的经脉，通了。

灵气像开了闸一样在体内奔涌，从百会到涌泉，从丹田到四肢。李长生感觉整个人都被填满了，每一个细胞都在欢呼。那种感觉比他这辈子经历过的任何事都要强烈。

他睁开眼睛，低头看自己的手掌。

掌心那朵莲花状的冥纹正在发光。

不是反射天上的月光或者城市的灯光，而是从皮肤底下透出来的光。黑色的纹路变得透明，内部浮现出一种幽暗的光泽——像是黑洞深处透出来的微光，像是泥土之下万古沉积的暗芒。

那种光不是明亮的，但它比任何明亮的东西都更有穿透力。它照在周围的旧花盆上、晾衣架上、水泥地板上，所到之处，所有东西都像是被什么古老的、不可名状的力量笼罩了。

李长生自己都被这种光镇住了。

"这是——"他的声音有些沙哑。

"冥纹初显。"碎片的声音很奇怪，有一种他从未听过的情绪在里面——敬畏，或者说是恐惧，"也是万年前，那个人站在九幽之巅的时候，四周万里尽被这种光照耀。"

就在这时，楼梯口的门吱呀一声开了。

李长生的心猛然沉到谷底。

门口站着的，是顾老太太。

她穿着一件白色的旧布衫，脚上是一双黑布鞋，头发散着，显然刚从床上起来。她手里提着一盏老式的手电筒，手电筒的光柱打在李长生身上，照出了他掌心那团幽暗的光芒。

时间像是在这一刻凝固了。

手电筒从顾老太太手里滑落，摔在地上，啪嗒一声，玻璃灯罩碎成了几片。

老太太的眼睛死死盯着他掌心的冥纹。

那是李长生从未见过的表情。

顾老太太平时总是笑眯眯的，温和的，不紧不慢的。但现在她的脸上没有一丝笑意。她的嘴唇微微发抖，眼睛里不是恐惧，也不是惊讶，而是某种更深层的东西——像是见到了一个不该存在的东西，又像是见到了一个她等了一辈子却从不敢相信会出现的东西。

"顾姨——"李长生把掌心收拢，想遮住冥纹。

但已经晚了。

顾老太太缓缓往前迈了一步，然后停了。她抬起手，指着李长生掌心的方向，声音干涩得像砂纸摩擦石头。

"你不要动。"

"顾姨，我——"

"你听我说。"顾老太太打断他，声音在发抖，但语气坚决，"你现在不能收。收了会伤到经脉。刚刚冲开暗伤，灵脉初通，冥力还在经脉里流转。如果你硬收回去，灵力反噬，轻则重伤，重则废掉。"

李长生愣住了。

这不是一个"普通老太太"说得出来的话。

顾老太太又往前走了一步。月光照在她的脸上，她看起来比平时老了十岁。或者说，她平时刻意掩饰的某种东西，在这一刻全部卸了下来。

"冥纹。"她吐出这个词的时候，嘴唇在发抖，"莲花状，暗金色。不会有错的。这是冥王令的法印。"

她抬起眼，看着李长生。

"你从哪里得来的？"

李长生没有回答。掌心的碎片的灵气在他体内游走，并没有说话，但他能感觉到碎片也在紧张。

"我在外面刚搬来的时候就觉得你不一般。"顾老太太的目光像钉子一样钉在李长生的胸口，"冥系灵根是万年来未有过的。我本以为你只是一个觉醒了稀薄灵根的凡人，最多能入个玄门做个外门弟子。但我万万没想到——"

她深吸一口气。

"你手掌上的那个东西，是冥王碎片。"

这句话像一把刀，直接剖开了所有的遮掩。

李长生握紧了拳头。冥纹的光芒已经被他压下了一些，但掌心的光还是透过指缝溢出来，像是在手里攥着一颗不会熄灭的火种。

"顾姨，您到底是谁？"

顾老太太没有立刻回答。她走到楼顶边缘，背对着李长生，望着远处的城市灯火。夜风吹起她的白发，她的背影在黑暗里显得有些孤零。

过了很久，她转过身来。

"明天晚上，你来六楼找我。我告诉你你想知道的东西。"

她弯腰捡起摔碎的手电筒，不再看李长生掌心的光，转身往楼梯口走去。

走了两步，她又停下来，没有回头。

"今晚你经脉初通，需要稳固。回去后盘腿坐三个时辰，不要停。如果感觉灵气紊乱，就用左手按住右边锁骨内侧两指宽的那一点——那是'天突穴'的位置。按住之后，混乱的灵气会归位。"

说罢，她走下了楼梯。

脚步声在上面停下，然后是六楼房门关上的声音。

楼顶上只剩下李长生和风。

碎片的声音终于响起来。

"天突穴，那不是普通中医的穴位。那是灵门修士用来镇压灵气暴走的'魂关'。"

"她知道我是——"

"她知道得比我们想象的还要多。"碎片的声音低沉，"而且，她刚才说的是'灵门修士'。这意味着，她要么是玄门中人，要么是和玄门有关系的人。"

李长生站在楼顶上，看着手心里渐渐黯淡下去的冥纹。

幽暗的光芒缩回去，缩成掌心那一朵小小的、莲花形状的纹路。月光照在上面，看不出任何异样。但皮肤底下，那道来自冥土的古老力量还在缓缓流动，像地下深处永不枯竭的河流。

他回到房间，按照顾老太太说的盘腿坐了三个时辰。

天突穴的位置分毫不差。按住之后，体内蠢蠢欲动的灵气果然慢慢平息下来，像被驯服的溪流，顺着经脉规规矩矩地流淌。

天亮的时候，李长生睁开眼睛。

掌心的冥纹已经完全收敛起来了，看上去就是一块普通的黑色印记。但他知道，从昨晚开始，一切都变了。

楼上的老太太，正在等着他。

（第026章完）

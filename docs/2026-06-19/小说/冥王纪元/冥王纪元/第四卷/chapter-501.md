# 第501章 番外：宰相的帝国政治学

泛宇宙守护秩序运转了头三个月之后，小王在他的笔记本里新增了一份私人文档。文件名起得很符合程序员的作风："_debug_log_v0.1_unglamorous_daily_chaos.md"。小王的文档没有加密——但他从没主动给别人看过。有一天许冰无意间从数据缓存的共享目录中瞄到了的文件名，问他这是什么。小王推了一下眼镜，说："治国日志。调试帝国的过程——跟调试软件基本一样。"

第二天他在这份文档中添了一条内容：

`BUG报告 #0032: 朱雀星盟的灵石兑换单位与星都王朝存在分歧——两者计量的时间单位不一样。朱雀星盟用朱雀纪元计，以火星自转周期为底；星都王朝用周天计时，用木星卫星的公转周期去调。两套时间单位的差异导致每次灵石报价都要做四道额外换算。`

`修复方案: 引入统一计量时间基础——采用地球统一协调星际时间（UCST）。要求所有加入文明必须使用UCST或至少提供UCST换算值为第二标价。`

`提交修改人: 小王。验证状态: 已推送至全星系交易平台，等待反馈。`

`反馈: 朱雀星盟同意了——赤离说'反正你们的算法比我们的好'。星都王朝拒绝了三次。第四次他们的主管财务官忽然同意了——因为他的换算队被四道换算耗时逼疯——集体辞职。`

小王对这次交涉的处理方法，被许冰后来写进了帝国行政管理的教学案例里。案例简短而精辟："小王宰相的谈判策略——不是劝人改，是等到人自己受不了再改。此策略的成功率极高，但前提是——你得比对方更能等。"

另一条记录则来自外交上的小事故。

`紧急事项 #0104: 烈岩族的高温大使无意中把燕山基地的接待室岩浆化了——因为他的体表自带高温无意融掉了接待室的隔温涂层。`

`修复: 在许冰的阵法帮助下，为烈岩族特制了耐高温的隔温墙体，将接待室改设在月球基地与燕山之间。大使对月球的低重力环境极满意——他说这是他活了几千年第一次能在会议室里跳来跳去。`

`备注: 跳跃的时候震碎了月球基地三块天花板——已修复。`

小王在日志中补了一行:"外交不是谈判——是不断修理被不同文明特性碰坏的东西。然后下次别让同一个东西坏了。"

而在帝国政治学的最核心部分——他认为不是权力运作，是信任管理。他在日志中写道:"帝国之所以还没有崩塌——根本原因不是李长生的修为，是这些核心成员彼此之间的信任度。李长生信任我管行政——从不介入；我信任老陈管军事——从不微调；老陈信任刀疤训练精英战队——从不干预；刀疤信任许冰的审判系统——从不质疑。这种信任不是靠制度建立的——是靠几十年一起扛事扛出来的。任何制度都无法替代这种信任基础。要想长期存在——必须寻找能将个人信任转化为制度信任的方式。"

文档的最后一段，是他在凌晨独自坐在办公桌前写的。窗外燕山的夜色已经很深了，他的眼镜倒映着电脑屏幕的蓝光。他写道:"当宰相和写程序——有点像。碰到恶性 bug，你叹气、拍桌、心里骂几句——然后还是得静下心来一行一行错误排查。治国碰到浑蛋的时候——也得这样。忍。调。不改初心。因为代码的核心逻辑不能崩——治国的核心逻辑也不能崩。核心逻辑崩了——系统崩溃只是时间问题。"

写完这段之后，他保存了文件。推了一下眼镜，然后打开帝国行政系统——继续处理那堆积如山的行政报表。窗外透进来一点点微光——是燕山夜空中一颗不知名的卫星反射的太阳光。他抬头看了一眼，然后低下头——继续改bug。

（第501章完）

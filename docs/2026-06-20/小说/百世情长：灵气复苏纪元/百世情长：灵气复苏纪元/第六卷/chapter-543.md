# 第五百四十三章 他们的故事被传唱（一）

太虚试炼报名之后的这段时间里，一场意外的"传唱"在南离城古老的老弦茶馆自发地发生了。老弦茶馆是南离城最老的一家弦歌茶馆——说书人在这里以古弦琴伴唱的方式讲述仙界的历史传说。这一年的秋月季中，茶馆主人——一位资历极老的说书仙——决定将林牧和苏晚的百世故事编成长篇弦歌。弦歌的名字叫《百世情长歌》。全歌分了若干回——每一回对应某几世的代表性事件。说书的基本脉络是真实的，但说书人将其中一些情节以极美极哀的弦乐进行润色。

第一回"石桥初遇"——讲阿木捡绣盒。说书人以极低的古琴滑音模拟绣盒落进水里的声响。茶客们听到的不是故事——是那颗绣盒在水面上溅起极细的水花那半刹的声音。有个在茶馆角落里喝茶的老年散修听到这一段时手里的茶杯停在半空中好久没动。他后来对左右说:"我道侣已经陨落很多年了——但刚才那个绣盒落水的声音让我想起我第一次见她时也是在一个桥旁。她掉在水里的不是绣盒——是一条丝巾。"

第二回"豆腐摊的挪位"——说书人以极轻极慢的指法弹出一段反复移位但总在同一片调性中的弦乐。弦乐在茶馆的木质顶棚下缓缓飘荡。在座的南离城道侣中有些人听到这段时转头看了自己身边的人。"你没挪过半寸——但我知道你不挪的原因是他挪了。"某位道侣对自己丈夫低声说。她丈夫没说话——但他用手指在桌上轻轻挪动了茶杯让它少占了她半面桌面。

第三回"悬索断后"——讲九十一世那个落入山涧的夜晚。这回弦歌的风格变得极沉极暗：古弦用了极少见的低调弦，每弹一下都像是受伤的手在攀住最后一根树枝。茶客中一个年轻男修听完后走出茶馆，在外面站了好一会儿，然后对跟他一起出来的道侣说:"以前有些事我一直瞒着你——不是因为信不过。是说完以后你肯定要帮我扛。我不舍得。"他道侣看了他一眼——"我就知道你没说。但没事。我可以等。"两人在茶馆外坐了很久很久。

虽然这弦歌目前还只是在南离城极小的圈子里演，但苏晚收到茶馆主人送来的第一回弦歌玉简时仍然高兴坏了。她把玉简在功德绳上给了林牧听了一遍。"阿木捡绣盒"那一段——那声落水的滑音让他怔了一下。那不是音乐——是他那世跳进河里时耳朵进水后闷闷的听觉感和紧张的心跳。他不知道说书人是怎么捕捉到那声细节的——因为那世的他绝对没有跟任何人说过。"大概是你后来在通灵里给了我——然后功德绳不小心把这个频率也溢出到了南离城的气运场中——"苏晚看着弦歌玉简猜测。她没说"感动"，但功德绳传来的触觉很诚实地把她的内心状态写了上去——"你跳河的那世，以后有人替你唱了。"

（第五百四十三章 完）

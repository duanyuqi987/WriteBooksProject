# 第465章 实力超过帝者的"仙王"级修士出现

至尊议会的会议大堂位于光柱最顶端——那颗恒星的内部。

是的，内部。这颗作为整个光柱中枢的恒星不是一颗燃烧的天体。它是一颗由超高密度法则之力聚合而成的人工恒核，表面温度极高，但其内部被凿出了一个永恒维持在适宜生灵进入的稳定空间。大堂悬浮在恒核内部的正中央，一片半球形的会议场地——地面是一块完全透明的法则平板，可以向下看见整个光柱的缩微投影。而天花板上，分布着十三个悬浮的王座。每个王座都由各自对应的至尊以专属法则锻造，独一无二，不可仿制。

李长生带着许冰、陈霜和龟相进入大堂时，大堂中已经站了几十个人——有来自光柱各层大陆的观察员、有其他平行宇宙派驻在这里的外交代表、也有公开审理时申请旁听的普通公民修士。三位逃亡帝者也在——苍雷、冰极和星辉站在大堂的一个角落里，身上都戴着法则约束环，神情各异。

"李长生。"苍雷帝者的声音从角落传来，沙哑而疲惫，"你真的要把我们逼到这一步？在另一个宇宙里杀人放火不犯法——我们杀的人和你没有半点关系。你非要把我们追到死才肯收手？"

"杀了多少人你心里有数。那些人确实和我非亲非故。"李长生平静地说，"但和你一样——我需要为自己的心负责。我的心给了我理由：你们杀了太多人，这笔账不该不了了之。"

他转身不再理睬苍雷，走向大堂中央的陈述台。

时钟走到了规定的时刻。

天花板上的十三个王座同时亮了。十二位至尊以各自不同的方式出现在王座之上——有人从星光中凝聚出形体，有人从虚无中缓步走出，有人原本就在座上一动不动，只有当祂动的时候你才意识到他一直在那里。这个宇宙中至高无上的十三位存在同时降临，整个大堂的温度、时间流速和空间结构都发生了微妙的变化。

而第十三王座上坐着的那一位——和其他十二位完全不同。

其他至尊的王座是浮在大堂上空的——高高在上，俯视整个会场。但第十三王座的基座直接连到了地面上，和地面融为一体。坐在第十三王座上的至尊和其他至尊不一样——祂的身高只有两米左右，穿着和普通修士一样朴素的灰色长袍，脸上带着一副全框眼镜——在这个时代、在这个宇宙，谁还用眼镜？但他戴着。因为眼镜让他看起来像一位账房先生，或者一个退休的中学物理老师。

但李长生在看到他的瞬间就感觉到了——这个"退休物理老师"不是什么至尊。

祂是一个远超至尊的存在。

因为连冥王令都在轻颤——不是因为恐惧，而是和祂产生了一种极其微弱的共鸣。这种共鸣告诉李长生一件事：这道意志曾经到过他们原来的宇宙。不是苍雷那种偷渡，而是光柱外那些常驻观测站监测过的不计其数的异宇宙中的一个。

"会议开始。"那个戴眼镜的老人开口了，声音不大，但在每个人耳朵里都清晰无比，"今天审核的是苍雷、冰极、星辉三位异宇宙帝者提出的引渡庇护申请。按程序走。第一个环节——核实申请人身份。"

苍雷帝者、冰极帝者、星辉帝者依次报出各自的身份信息，并将引渡令递给现场的法则验证台。验证台自动扫描，确认了他们的身份和引渡令的真实性。

"第二个环节——申请人陈述。"戴眼镜的老人翻开了一本纸质本子。纸质本子——在这个科技发达到极致的宇宙里——这老人手里拿的是纸质本子。

苍雷帝者站上了陈述台。

他陈述的核心很简单：第一，我们在我们原来的宇宙里确实做过一些事，但那些事在当时的宇宙法则下是属于弱肉强食的正常范畴——不是罪行，是规则。第二，我们三人现在被追得无处可去，希望至尊议会念在苍雷曾在万年前帮赤坤至尊平叛的旧情面上，给予庇护。

赤坤至尊在第九王座上轻声道："旧情面不决定法规的裁定。但作为背景信息，苍雷确实协助过我一次。"

"第三个环节——利害相关方陈述。"老人看向李长生。

许冰站起身。她没有走向陈述台，而是直接在原地翻开了法典。她的声音冷静而坚定——和在法庭上一样——逐条列着苍雷帝者万年来毁灭的每一个文明、屠杀的每一批生灵、违反的每一次法则。

"根据我们宇宙的因果律——在贵宇宙的元规则体系中因果同样是跨宇宙的基础法则——苍雷帝者犯下的杀业最终会以某种形式反馈回他身上。容许已被因果锁定犯下大杀业的人进入贵宇宙，等同于把'大杀业不反噬'这个先例植入贵宇宙的法则体系。这将会对贵宇宙辛苦建设了五个文明纪元的公正体系造成根性质的污染。一个由无数良性因果叠加维持了无尽岁月的宇宙，因为收容了三个大杀业的逃犯而产生了第一个恶性的因果漏洞。这个漏洞一旦开始扩大，后果无法预估。"

全场安静了下来。许冰的陈述没有用道德谴责，没有用情感绑架，而完全使用了这个宇宙自身的逻辑——用他们宇宙法则运作的方式来论证必须驳回庇护。

戴眼镜的老人把眼镜推了推，翻了一页笔记本。

"这个陈述有力。"他说。

赤坤至尊的眼皮动了一下，但没有说话。

"还有补充吗？"

许冰摇头，合上法典。

"第四个环节——至尊讨论和表决。"

但在这时候，李长生开口了。

"至尊阁下，我想请教一个问题。"

老人看向他。

"你的境界是什么？"

全场静默到了冰点。在这个宇宙里，直接问一位至尊"你什么境界"是一件极其冒犯的事。因为至尊的修炼境界根本不是几句话能说清的。但李长生问了。而老人没有生气。

"仙王。"老人说。

全场哗然。连其他十二位至尊都有些诧异——这个人对外公布过无数称号、封号、身份，但从未公开确认过他的境界等级。今天在三方审核会议上，被一个外来修士一口问出来了。

"仙王是什么？"

"帝者之上为神明，神明之上为仙王，仙王之上暂时还没有名字——因为我是第一个达到这个境界的。所以我自己给它起了个名字：太初观察者。不是境界名，是一个职务——我负责看清整个多元宇宙的发展方向，保证各个宇宙之间的稳定。我的修为只负责让我活得更久——目前我已经活了十三万七千多年。"

龟相悄无声息地在神识中向李长生传达了两个字："冥王当年也是仙王。在他被围攻之前，他是仙王级。十二诸神联手围攻唯一的仙王，靠的不是实力差——是车轮战和消耗。"

李长生心里一凛。

冥王是仙王级。而这里的这位老人同样是仙王级——但和冥王不同，他没有被围攻、没有陨落、而是活了下来，用十三万七千年的时间看护着整个多元宇宙。

两位仙王——一位已死、分成九块碎片躺在泥土里等待转世；一位还活着、每天戴着眼镜写笔记、看护着宇宙运转。

"你的冥王令能感知到我。"老人说，"因为我曾经去过你们宇宙。那里现在叫'九号观测区'——我们在元初之海设有十二个常驻观测站，九个号就是其中之一。我定期轮巡所有观测站。所以在万年前我就见过冥王。"

李长生的瞳孔猛地收缩。

"你见过冥王？"

"见过。在我们观测站刚部署到你们宇宙附近时，冥王就第一时间发现了。他邀请我去喝茶。用很普通的茶碗——他亲自种的茶叶。第一泡茶还没泡好，他就说了一句话：'老哥，我早晚要死在我那几个老朋友手里。能不能帮我看着点我的碎片？'当时我以为他说的碎片是星球碎片——后来我才知道是自己把自己捏碎的命牌。"

老人推了推眼镜。

"我没帮他。因为观测站的信条是不干预被观测宇宙的内政。我很后悔。万年来我每年轮巡的时候都会到第八十七号观测点——那是离九号宇宙最近的观测点——蹲一会儿，对他的冥能残留说几句话。有时候我会告诉他那边他的继承人还在种地。有时候我会告诉他那边的诸神后裔现在过得很好——虽然他们的祖先屠过一个仙王。"

老人看着李长生。

"你比你前任更果断、更狠。他不愿意做的斩草除根的事，你用三个月做完了。他很会下大棋；你不会下棋——你只会一根筋地把棋盘上所有你不喜欢的棋子都一根根打碎。"

"谢谢。"李长生说。

"这不是夸你。作为观测者我不该夸任何一个来自被观测宇宙的人。但你是看着让人很舒心的例外——因为多元宇宙里像你这样一根筋较劲的人太少了。大家都太聪明、太会博弈。"

"那庇护申请的裁定——"

老人合上笔记："至尊决定。"

（第465章完）

# 第八百七十六章 所有等待的人看到了希望

飞升之门运行第二个千年时，整个双界体系已经极为成熟。人间修仙界与仙界的联系变成了日常。当年那些在星光窗下看光的小孩子早已长大——有人飞升成功，有人在修炼过程中选择了自己更喜欢的方向，不再将飞升视为唯一目标。而无论做什么选择——他们头顶那扇窗总是不疾不徐地亮着。既没有降低标准讨好，也没有傲慢隔绝。

在这两千年间，飞升之门已变成类似古代"日升"的现象——从不需要宣扬，只是每天照常升起，安静地履行着承诺。修仙界中再也没有人怀疑门的存在。因为它就在那儿。飞升不再是梦想——而是空气。而信任的气息随着空气一并自然而然地进入所有生命的呼吸中。

在守门人区老区的一角，陈望海晚年种下了一棵普通的人间桂花。它不是仙植——长速极慢，数百年才成树。但开花时花的香气和人间青云山谷的一样。他已于数百年前高寿离去——但老龙的孙子用一片龙鳞基片把桂花树的根永远固定在守门人区的中心庭中。每年开花时，总是花香到处弥漫。白染书院的学生做传承活动时都会来花下采集一朵极小的桂瓣——而后放在自己为新人写的接引信内，作为"信引"。

人间的桂花与仙界的花都在同一天开。那日苏晚一如既往在人间渔村的星光窗边散步。她刚弯腰为一个画了粉笔门的小孩补齐那句"你是对的——门确实在"，抬起头就看到北方的星窗旁轻悠悠飘过一片仙界的同枝桂花。瓣上有个极小的手刻字——"谢"。那是一个守门人区小辈刻的；她认不得谁的字，但知道是给她的。于是她用指尖在空中画了一枚同样的桂花——传回星眸，再经由门抵达守门人区。

这天晚上林牧问她"你今天在渔村画了几扇粉笔门？"

"四扇。还有一个小孩把守门人画成了一条龙——因为他的授业师父是广龙。很有趣。我在龙角上加了一道星光。"

"你漏了一个尾巴——我帮他补了。"林牧在星眸中展示一幅修正稿——小女孩画的双尊是手牵两条龙身相连。苏晚看了很久，然后说："你是把他的作品从'龙单尊'升级为'双龙同体'——那孩子应该会笑出来。"

事实证明后来小女孩收到这幅修正版后在家门口的台阶上抱着画板睡了。她妈妈画了一幅速写记录——这张速写后来成为守门人区通历第十千年明信片的封面。而那小女孩长大后成为第十一代接引长的得力副手——她一生最常对外人说的一句话就是："我小时候画过双尊——他们回信了。"

# 第三百零五章 废墟中的重逢

救援队的营地连夜撤离了。

林牧用剑在山谷入口处画了一道结界——不是封印天魔的那种封印结界，而是一道简单的"驱邪结界"。用精纯的灵气在空气中画符，把方圆三里内的天魔气息逼退到结界之外。符咒画完的瞬间，篝火的颜色从暗紫调回了正常的橙黄。黑色的霜从营地周围的树叶上剥落下来，在风中碎成了粉末。

队长看到篝火变色的那一幕，膝盖又软了一下。但这次他没有瘫坐到地上。他稳住了。灾难会让人崩溃，也会让人在崩溃的间隙里长出更硬的东西。这个中年男人做了十八年救援工作，什么惨状都见过——地震、洪水、泥石流。没见过天魔。但他有一套在任何极端情况下都能运转的本能反应机制：评估威胁、保护伤员、快速转移。

"所有人——收拾装备！五分钟内出发！"他吼的声音不大但足够清晰。

队员们开始拆帐篷、打包药品、把担架上的病人抬上越野车。苏晚被两个女队员搀着站起来。她的腿还是很疼，但能走了——林牧封住她经脉里的黑色气息后，高烧退了大半。她走过林牧身边的时候停了一下。两个人之间大概隔了两步的距离。

"你走不走？"

"不走。"林牧说。"我还有事。"

"是去处理那个裂缝？"

"对。"

她想了大概三秒。"我刚才昏迷的时候，好像看到了什么。一些很模糊的画面——一座山。白色的楼。一个人站在楼前面。看不清脸。"

林牧把水壶从腰间摘下来，递给她。"拿着。水壶里的鱼会帮你取暖。你的体质偏寒，天魔气息残留会让你在晚上发冷。"

她接过水壶。壶身是温的。不是那种烫手的温——是刚好三十七度，和人体体温一模一样的温。她把壶放在胸前。隔着衣服，她感觉到壶里的水面上有什么东西动了一下。像是鱼尾巴搅了一圈涟漪。

"谢谢。"她说。"那我们算是——见过面了？"

"算。"

"再见。"她转身往越野车走去。走了三步又回头。"你刚才说'很久以前见过'——具体是多久？"

林牧看着她。"三百多年。"

苏晚沉默了一会儿。然后她点了点头。"好的。三百多年。理解了。"

她没有再问。因为她是医生。她知道有些答案不应该在双腿还在流血的时候追问过多。她坐上车。车门关上。越野车的尾灯在夜色里渐渐变成两个红色的点，然后消失在弯道那头。

林牧看着尾灯消失的方向。他在原地站了整整一刻钟之后才转身。

山谷里的风吹着他单薄的深灰色外套。衣服下摆的线头上沾了一点她的血——他帮她处理伤口时蹭到的。血迹已经干了，颜色从红变成了暗褐。他把那块布料折了一下，把血迹折到里层。不是嫌弃——是不想让它被风吹走。

然后他飞回了裂缝。

裂缝在凌晨两点的月光下长得更大了。宽幅已经从三步扩展到了将近二十步。裂缝边缘的黑霜厚得像一层沥青。空气里的灵气温度降到了冰点以下——他呼出的白气在月光下泛着淡淡的紫色荧光。这说明天魔气息的浓度已经达到了一个临界值。他拔剑，把灵力从三道裂纹中同时灌入。剑身上的古裂纹路亮起了淡金色的光——不是剑本身的颜色，是他的灵力的颜色。元婴修士的灵力是淡金色的。

他把剑尖插进裂缝边缘的岩石里。然后开始念咒。

不是传统的封印咒——传统的封印咒对域外裂缝不起作用，因为裂缝的本质不是空间破洞，是"法则撕裂"。两个世界之间的法则壁出现了裂口。要堵上裂口，需要用更高维度的法则来压制——上界的法则。而他恰好是一个上界的堕落真仙。虽然堕落了很多年、修为退化了很多层、身上只剩元婴中期的灵力——但他灵魂深处的"法则权重"还是在的。

咒语是用上界古语念的。每一个音节从嘴里吐出来的时候，他丹田里的元婴会剧烈地旋转一圈。念到第十七音节的时候，元婴忽然睁开了眼睛。元婴的眼睛和剑尖上的金光同时亮了一下。然后裂缝边缘的岩石开始动——不是物理层面的崩裂，是空间层面的"愈合"。裂缝两端的空间法则在他灵力的拉扯下缓慢地靠拢。宽度从二十步缩到了十五步。再从十五步缩到了十步。

然后停住了。

不是他灵力不够。是裂缝内部有一股力在往外顶。那股力量的温度是冰的——比周围的冰更暗。暗紫色。和林牧记忆里上界那个人的灵力颜色一样。那个人隔着裂缝在看他。他能感觉到那股目光——不是灵识层面的扫视，是实实在在的目光。像是两道冰刺从裂缝深处刺出来。

"林牧。"

声音从裂缝里传出来。不是空气传播的——是灵识直接灌入。声音的频率极低，每个字的尾音都拖得很长，像是在水底说话。但口音——口音他没忘。几百年了。那种在每个音节末尾故意停顿半拍的说话方式，那种从鼻腔里挤出来的不屑的冷哼。

"你果然还活着。"那个声音说。

林牧把手从剑柄上移开。他把剑插在裂缝边缘的岩石里，让剑身继续维持封印的运转。然后他站直身体，双手垂在身侧。

"阎锋。"他说。

"还记得我的名字。不错。"裂缝里的声音带上了一点笑意——不是愉快的笑意。是那种猎人在看到猎物还有力气挣扎时发出的笑意。"三百多年了。你从上界掉下来的时候，我在云霄殿上看了整整一炷香的时间才确认——确认你真的摔下去了。摔得很难看吧？"

林牧没有回答。他把右手慢慢地抬起来，手心朝天。手心里的那道剑痕在暗紫色的光里泛出一种异样的银白色。这道痕是十三道伤痕中唯一彻底愈合了的一道——愈合了，但留了疤。因为他从来不治。留着。提醒自己记住那个把他从玉阶上推下来的人。

"我找了你很久。"林牧说。声音平静。不是压制的平静。是真正的平静——元婴修士对情绪的掌控力已经达到了可以把杀意折叠起来存放的程度。"从上界掉下来之后，我每一世都在查你的下落。查了十几世。每一世的结论都一样——你还在上面。你把自己封在云霄殿里，用三千仙人的灵脉做护盾，不敢下来。"

裂缝里沉默了一瞬。然后阎锋笑了。笑声在灵识层面上听起来像玻璃被捏碎。

"不敢下来？林牧，你以为我为什么现在下来了？因为我忍不住了？不——因为上面的灵气快枯竭了。你的那帮所谓的'朋友'，在你掉下去之后开始了一场旷日持久的'清洗'。先是你的亲信——一个不剩。然后是你的盟友——三十几位上界仙人。然后是我。他们用了三百年才把我也逼到了墙角。所以我下来了。不是来找你的——是来逃命的。"

林牧的手指微微收紧。指关节发出了一声轻微的脆响。

"所以你打开裂缝——是为了下来躲？"

"躲？不。我是来找资源的。这下面就是灵气复苏。"阎锋说。"这个世界正在长出一个新的灵脉系统。嫩。脆。适合收割。我只需要吃下这个世界的灵脉——就能恢复到真仙巅峰。到时候我再杀回去。"

然后他的声音变得很低。"不过现在——我发现了一个更有趣的东西。你身边那个女人。第十几世了？灵魂上有一道很漂亮的封印。是你下的？不对——不是你的手法。但上面有你的灵气残留。真有意思——你不会是把她的命脉和你的命脉绑在一起了吧？"

林牧拔剑。

剑气从裂缝边缘的岩石里拔出来的一瞬间，裂缝上的封印崩溃了。但他不在乎。他把剑尖抵在裂缝的最窄处——那是裂缝"呼吸"的节奏中最脆弱的一个节点。灵力全开。三道裂纹同时照亮。

"你听好。"林牧说。声音在灵压的裹挟下穿透了裂缝，灌入对面的空间。"你可以在上面耀武扬威。你可以吃灵脉。你可以做任何你想做的事。但你绝对不能碰她。碰一下——我会让你后悔三百年前没有真的弄死我。"

裂缝对面安静了。然后暗紫色的光熄灭了。不是消失——是阎锋主动收回了自己的灵压。他在退。不是因为怕林牧——林牧现在的修为和他差着至少两个大境界。而是因为他在试探之后得到了一个他需要的信息：林牧和那个女人的命脉确实是绑在一起的。而这个信息比一个元婴修士的威胁更有价值。

裂缝在他退走之后缩小了一点。但宽度仍然有七八步。林牧重新开始封咒。这一次他用了七层封印——每一层封印上都混入了自己的一滴精血。精血封印是最牢的封印，也是最费命元的封印。七滴精血——大约折了他三年的寿元。

他不在乎。元婴修士的寿元大概有五百年。三年不算什么。

天快亮了。他坐在裂缝边缘的一块石头上，把剑横在膝上。月亮还在西边的山头挂着，颜色从白转成了淡黄。晨风从东南方向吹过来——那个方向是救援队撤离的方向。她在那头。她腿上的伤大概已经结痂了。她大概正靠在越野车的后座上打盹。她怀里抱着他的水壶。水壶是温的。锦鲤大概正在吐泡。

他闭上眼睛。脑海里忽然闪过一个画面——不是记忆，是推算。是他基于灵脉流速、天魔气息扩散速度和裂缝扩张速度做出的预测模型。输入现在的各项参数——输出结果：以目前的扩散速度，天魔的气息将在三十天内覆盖全国三分之一的可居住土地。对应的人口损失——大约四亿。

四亿凡人。这个数字在前世的他看来，只是战略推演中的一个参数——不值得动感情。上界的真仙不会在意凡人的生死，就像凡人不会在意一个蚂蚁窝被水冲塌。

但他已经不是上界的真仙了。他做了二十八年的凡人——写字楼打卡、加班写代码、在地铁上站着睡着。他有同事、有邻居、有菜市场里那个每次多给一撮葱的卖菜大姐。凡人的生活让他明白了一件事：四亿不是一个数字。四亿是四亿个故事。每一个故事都有头有尾。如果没人阻止阎锋，这些故事都会被折成同一个结局——寂灭。

他站起来，把剑收回剑鞘。晨光照在他脸上。东边的山头开始泛金色的光——太阳快出来了。

他需要做一个决定。不是什么"是否参战"的决定——那个决定在阎锋说出苏晚名字的那一刻就已经做了。是一个更实际的决定：怎么打。

以他元婴中期的修为，正面对抗一个上界巅峰真仙，胜率大约是零。但正面不行，侧面有没有路？

他重新坐下来。从储物袋里拿出纸笔——普通的铅笔，普通的A4打印纸。然后在纸上画了一幅图。昆仑的裂缝。长白山的裂缝。秦岭的裂缝。青藏高原的裂缝。南海的裂缝。五处裂缝的位置在纸上连起来，是一道弧线——不，不是弧线。是一道五芒星的轮廓。缺了两个角。如果补上那两个角的位置——一个在东海，一个在中亚。

"七个裂缝。七星阵。"他低声说。

上界有一种上古禁阵——天魔七星阵。七道裂缝为阵眼，阵心在天——不在地。当七道裂缝同时张开的时候，阵心会在天空的对应位置形成一个灵压漩涡。漩涡一旦形成，就能把方圆数千里的灵气全部吸入上界。这不是"吃灵脉"——这是把整个世界的灵气系统连根拔起。阎锋不是要"吃"灵气。他是要"抽干"这个世界。就像抽干一个人的血。

林牧在纸上写了两个字：七眼。

他得关上七个阵眼。但以他一个人的力量，最多顾得了两处。剩下的五处——需要帮手。需要修为足够强、脑子足够清楚、并且在灾难面前不会跑掉的帮手。他不是没有——他有三百年修炼生涯中见过的各式各样的修士。但他从来没有主动开口找人帮忙的习惯。前世的他在上界是独行客——不需要任何人帮忙。这一世的他更独——三十年不和人搭伙。

他把铅笔放下。纸上的字迹在晨光里很清晰。七眼。

他站起来，把纸叠好放进储物袋。然后他拿出卫星电话，拨了一个三十年来第一次拨的号码。

"赵明远。帮我联系蜀山掌门。还有茅山、昆仑、南海、长白。我有话对他们说。"

"说什么？"

"道歉。然后——请他们入伙。"

"入伙干什么？"

林牧看了一眼昆仑方向的天空。在那头，暗紫色的裂缝正在晨曦中缓缓地张开。它的宽度已经超过了三十步。

"保台。"

# 第076章 第三块碎片的方位：西北大漠

黎明时分，李长生从修炼中睁开眼。

双脚脚底的涌泉穴处，最后一道尚未冥化的骨骼——两块跟骨——在凌晨的冥气灌注下完成了淬炼。两股幽蓝色的冷光从脚底涌出来，在石地上印出两个淡淡的符印。全身两百零六块骨骼，此刻已经全部进入了冥骨淬炼境的第一层——铁骨。

他站起来，踩了踩脚。

踏实。比以前任何一次踩地都踏实。不是脚底板变厚了，是骨骼的受力结构变了。跟骨、跖骨、趾骨的密度和结构重组之后，整个脚底像换了副钢铁铸的骨架。他试着在石地上跳了一下——落地无声，但脚下的石面被他踩出了两道极其细微的裂纹。

这就是冥骨淬炼境大圆满。铁骨的基础底盘已经打好了，下一步就是往"钢骨"冲击。那是第二重的后半段，需要更大量的冥气支撑。

他走出石室的时候，小王已经把所有装备都打包好了。几个人的登山包里装满了压缩饼干、水、急救用品、信号放大器、和两把小王自己改装过的短刀——刀柄里塞了GPS定位芯片。

老陈在古墓入口处抽烟。天还没亮透，烟头的火光一明一暗。

"长生。"老陈看到他出来，把烟掐了，"刀疤凌晨走了。"

"走了？"

"嗯。他说他得回一趟老家。他老家在山西那边，他说灵气复苏了，老家那片煤田地下说不定也有东西。他让我告诉你——他这个跟班的位别给别人留着，他去去就来。"

李长生没说什么。刀疤不是会郑重告别的人。他走，是他自己的选择。他能回来，也是他自己的选择。这种人不需要挽留。

"老陈，你也留下。"

老陈愣了一下。"什么？"

"西北大漠太远了。你这边还有家里人要照顾。小王跟我去就够了。你留在城市里，一是养伤——上次冷锋那一剑擦到你肩膀，还没好透。二是盯着这边的事。城市里这段时间肯定会出很多怪事。你帮我留意着。有什么不对劲的，在群里说一声。"

老陈沉默了几秒。他想说点什么反驳，但摸了摸肩上还没完全结痂的伤口，最后还是点了头。"行。但你他娘的可得活着回来。"

"活着。"李长生说。

他走进溶洞，找到了老龟。

老龟正趴在前一天选好的一个新位置——那里是整个溶洞中Wi-Fi信号最好的角度。它的龟壳上，小王用胶带把手机和信号放大器绑得紧紧的，还在手机上装了个一键呼叫的应用。

"龟相。"

"少主。"

"你得待在这里。"李长生说。

老龟的大头微微歪了一下。这个表情在它做来是"为什么"——但它是真的不懂，还是不想懂，说不清。

"不是我不想带你出去。"李长生指了指头顶的石壁，"这道甬道只有一个人能挤过去。你这么大的身子，出不去。而且这座古墓需要有人守着。太阴冥脉不能没人看管。"

老龟沉默了好一会儿。龟壳上那些阵图符文无意识地明灭了几下，然后归于平静。

"少主说得对。"它的声音比平时慢了一些，"老臣寿元只剩一年。这一年里，老臣要守好这条灵脉。少主需要老臣的时候，神识连上太阴令就可以与老臣对话。距离不限——太阴令是这条灵脉的权柄，您人在哪里，老臣都在耳边。"

李长生伸出右手。

掌心上，深藏在十字冥纹之中的太阴令微微发热。他能感觉到，沿着这条气流，他可以在任何距离上和老龟对话。这是主和臣之间的神识链条，是万年前冥王留下的通信体系。

"龟相，"他说，"一年之内，我一定会回来。带你出去。带你看一眼外面的世界。"

老龟没有说话。它的眼睛比之前任何时候都要湿润。不是泪，龟不会流泪。是一种龟类特有的、从眼膜深处泛起的润泽。它活了太久，以为什么都看淡了。它错了。

"老臣等着。"

李长生走出溶洞的时候，没有回头。

甬道往上。三百二十级石阶，每登一级，光线就亮一些，空气就暖一些。等他走到古墓群出口的时候，天空已经大亮了。六月的阳光撒在遗址的石墙上，把那些两千年前刻上去的符文晒得温热。

小王已经在出口等着了。他背着两个包——一个是自己的，一个是李长生的。手里拿着平板电脑，屏幕上是一张粗糙的路线图。

"长生哥，我昨晚模拟了一下路线。从我们这里去西北大漠——阴山方向——最快的话，先到县城坐长途汽车到省城，再从省城转火车到兰州，然后从兰州找交通工具进沙漠。全程大概需要五天。如果路上被天玄宗的人盯上，可能会更慢。"

"那就五天。"

"还有一个问题。"小王把平板翻过来，指着地图上一条细长的红线，"到阴山要穿过两个军事管制区和三个灵气监测站。自从天空裂缝之后，所有过境的修士都需要报备灵根属性。我们两个——冥系加上水木——一报到肯定被拦下来。他们不会相信'路过'这两个字的。"

"不报备。走野路。"

小王推了推眼镜，在地图上画了两条曲线。一条是公路线——他标了"官方"，打了一个叉。另一条是山区野路——他标了"野路"，旁边写了一个注释："途经太行山和吕梁山的结合部。山路崎岖但人烟稀少，不易被监测。"

然后他忽然停了一下笔。

"长生哥。我昨晚在想一件事。"

"嗯？"

"我们这么走下去，这辈子可能就不会再有'回家'这个概念了。我是说——我们是没家的。县城那个出租屋不是家。你那个李家庄也不是。接下来是昆仑、太行、大漠、长白山——全国到处跑。我们是流浪汉。"

李长生想了想。

"流浪汉也挺好。天地为家。"他把一个背包甩到背上，迈出了古墓遗址的石门，"我种了三十年地，家对我来说就是一块地。大到全国十二灵眼，小到脚下一亩三分。没什么区别。"

小王看着他的背影，没有说话。他把平板收好，背上另一个包，快步跟了上去。

走了大约三里路，古墓群的石墙已经隐没在背后的树荫里。前面的路两边的麦田正在灌浆，风吹过去，麦浪一层一层地翻。远处的村口有人赶着牛车在走，赶车的是一个老大爷，车子吱呀吱呀地碾过土路上的石子。

一切和往常没什么两样。

李长生在路口停了一下。他看了看路牌——往西是县城，往东是省城。他掏出手机，没有信号。天裂之后，手机信号一直是断断续续的。

"走吧。"他说。

王路点了点头——不，他叫小王。但这一刻忽然觉得只叫小王好像有点不够了。不过他没说出口。

两个人沿着大路往西边走去。太阳在背后升起来，把他们的影子拉得很长。影子里，李长生右手低垂，掌心朝外，那道十字冥纹在阳光下几乎看不见。

但如果仔细看——那道纹路正在一圈一圈地往外荡出极微弱的脉冲。它不是李长生在催动，而是它自己在往外发信号。

它在找第三块碎片。

西北方向。大漠深处。古战场阴山。朔风令等在万年前那场最后的战役遗址里，等了一万年，终于等到了一个从黄土地里走出来的农民。

那人正朝它走来。

与此同时，古墓遗址入口外三里远的山脊上，冷锋的剑柄微微震动。

他盯着远处麦田边两个越来越小的黑点。他的右眼皮跳了一天一夜。不是怕。是某种金丹修士的本能警觉——那个被自己追杀而逼入古墓的人，从墓里出来之后，身上的气息不但没有削弱，反而比之前浓郁了几倍。

冷锋攥紧剑柄。

"师尊说得对——冥系修士，不可留。"

他没有跟上去。转身，往宗门总坛的方向走去。他需要回山复命。这件事——冥系灵根再现人间、万年未见的冥王真体开始成形——已经不是他一个金丹修士能处理的了。

这场灵气复苏才刚刚开始。而真正的风暴，还在很远的西北，那片沉睡了一万年的大漠深处。

李长生并不知道冷锋的离开。他只是在走路。

从河北农村往西走。走进山里，走进沙漠里，走进那个曾经属于他自己的古战场里。他走过麦田、走过荒山、走过干涸的河床。他走了一天，脚不疼。

因为他的骨头，已经是钢铁铸的了。

（第076章完）

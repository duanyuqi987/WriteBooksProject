# 白谪

## 基本信息

| 项 | 内容 |
|---|------|
| 身份 | 上界执法使、迎仙台联络官、记录者 |
| 出场 | 第三卷第244章起，第三卷后段持续活跃；后续多卷作为记录者、联络官和制度见证人 |
| 所属 | 上界官僚体系 / 迎仙台联络体系 |
| 功能 | 从制度执行者变成理解百世情长的记录者；负责把第三卷过渡区预录与后续正式上界线分清 |

已核查正文锚点：第244-251章负责第九世至第十世登天门预录监测，第258-278章参与迎仙台试职、庆典投影与持续刷新研究线，第295-297章完成第三卷述职与归档。

## 性格

- 严谨刻板——上界官僚的典型做派，做事一丝不苟
- 最初对下界事务持高高在上的俯视态度——"规章就是规章"
- 内心并非冷酷——他只是从未被允许在规章之外思考
- 逐渐被林牧和苏晚的百世情感动摇——从观察者变成了被感染的人
- 最终变成了温和的记录者——不再用规章衡量一切，而是用"人"的角度去写

## 背景

- 上界记录司官员，负责记录下界重大事件的"案卷"
- 林牧与苏晚的百世轮回在案卷中只是简短的几行字——直到他亲眼看到这一世
- 他的职责是"记录事实"，但百世轮回让他不得不思考什么是"事实"

## 核心矛盾

- **规则与人情**：作为官僚，他应该按规章办事；作为见证者，他无法对百世深情视而不见
- **记录与参与**：他的职责是记录，但他逐渐发现——有些事不是用来"记录"的，是用来"感受"的

## 核心欲望

- 完成一份完整的、公正的记录——不是冷冰冰的案卷，而是真正理解百世轮回的意义
- 在规章与人情之间找到那个微妙的平衡点

## 核心恐惧

- 自己记录的一切都是错的——如果规章本身就是不完整的，他按规章写的案卷还有什么意义？
- 成为麻木的官僚，失去感受能力——这是他在林牧和苏晚身上看到的反面教材

## 不可逆选择

- 为林牧和苏晚破例修改案卷记录——在官方档案中不再用编号和符号标记他们，而是写下他们的名字和故事
- 这个选择等于公开承认"规章有漏洞"，对他而言是职业生涯的豪赌

## 声纹

- 说话文雅、准确，用词考究
- 最初语气近乎冷漠——"根据上界第372条规章……"
- 后期语气明显软化，会出现停顿和犹豫——"这条规章……或许不该用在这里。"
- 记录时自言自语，像在跟自己辩论

## 关键台词

- "根据规章，我不该记录这些。但根据良心，我不得不记录。"
- "我在案卷里写了九十九条，这一条——我自己加上去的。"
- "你们的故事，不应该只是编号。"
- "规章是死的，人是活的。这话我花了三百年才学会。"

## 关键变化

- **起点**：冷冰冰的规章执行者——"按规章办事"
- **转折**：亲眼目睹林牧和苏晚的某次重大事件，第一次对规章产生怀疑
- **终点**：为二人破例记录，在案卷中写下他们的完整故事——不是编号，是名字

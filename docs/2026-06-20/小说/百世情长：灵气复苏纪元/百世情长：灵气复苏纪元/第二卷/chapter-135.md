# 第135章 暗中化解灾劫

妖兽袭击后的第二天，林秀芝的左前臂上多了一道伤口。

不是妖兽直接咬的——是被飞溅的木屑划开的。茶铺门槛上的木板在妖兽撞击时碎了一大块，碎片飞出去的时候擦过她的前臂，划了一道大概三公分长的口子。伤口不深——皮外伤——她根本没去找医院，自己用碘伏擦了一下，贴了创可贴就继续在茶铺里收拾。但林牧用灵识感知到了。他在茶山上清除残余妖气的时候，灵识网例行覆盖了全镇——她的灵压曲线上多了一道极其微弱的干扰信号：隐约的炎症反应。

他站在茶山上，手里刚放完最后一只昏睡妖兽的安定印记。手动的痕迹还没干，他把手在衣服上擦了一下，然后看向山下的镇子。张记在薄雾中隐约可见。

他有药——储物袋里有几颗他自己炼的疗伤丹药。但他不能送。不是不想送——是送药意味着他要主动上门，意味着要向她和老张解释"我为什么有这种药"，意味着从一个"偶尔出手帮忙的修士邻居"变成"主动关心你私人健康的男人"。这个界限一旦越过，整个距离系统就会崩掉。所以他没送。

他在山上找到了一口水井——在茶山东侧的旧茶厂旁边有一口深约三十米的老井，井水是地下水脉的分支，能连通到镇下方的含水层——青溪镇几乎所有住家的水井都共享这条地下水脉。他把一颗最低调的疗伤丹药——回春丹，品级是最基础的一阶下等，外观像一粒透明绿豆——捏成了粉末。然后他把粉末倒入井口。粉末在水里无声地溶化——无色无味——从老井流入地下水脉，弥散到整个含水层。

他知道她家门前那口浅井会在大概一小时之内流出带微弱疗愈效果的水。效果极其轻微——不足以让任何人察觉——但足以在一个晚上之内加速皮外伤的愈合。

她当天晚上打了一桶井水。做饭、洗脸、泡茶。她喝了井水煮的茶——茶水入口时她的舌尖微微停了一下。她咂了一下嘴——低头看看碗里的茶——然后对老张说："井水是不是变甜了？"

老张喝了一口——皱眉头，"没觉得啊——你是不是伤口发炎影响味觉了。"她嗯了一下，没在意，继续烧饭。

林牧在茶山上的井边擦干手指。旁边的老猫盯着他——眼神的意思是"你又来了"。锦鲤说："你花一个时辰把丹药磨成粉倒在井里，只是为了让她喝一口水——你知道你这种行为是有问题的吧？"林牧没理他。他把手洗干净，把药粉的残余从指甲缝里冲干净，然后站起来。回春丹总共只有九颗。为了她的一个小伤口，他在井口蹲了一个时辰——不惜磨掉一颗。但对林牧来说——没有第二个方案。正面帮助会被身份曝光毁掉一切安全距离。侧面介入——只有通过这口井。

这口井在这五年来一直是他所有暗中干预的重要渠道之一。他选择的井口永远不是她家自己的那口——是远离她视野的山上旧井——让药物通过水脉慢慢汇进含水层，在所有人都不知情的状态下把保护默默地铺开。他是一个隐居在小镇上的 IT 前从业者——他的世界里一直存在"系统间接干预"的概念：不直接碰用户，但修改底层代码。这口井就是一底层接口。

除了井，他还有其他底层接口。他在张家茶铺附近一共布置了六处微小保护阵——三颗最早的符石（门槛、校门口、菜市），以及后来增加的两棵茶树（在茶山上她家的承包区内）和一棵槐树（巷口那棵歪脖子槐树——他在树上用剑指在树干内部刻了微型灵源阵）。这六处保护节点构成了一个覆盖她所有活动范围的"守护网"——网里的灵压极其低微——低于任何修炼者的探测阈值——但对被保护的目标能在无意识层面提供极其微弱的灵力缓冲。

这次妖兽潮结束后——他花了大概一周检查网上所有的节点被破坏情况。只有菜市场那颗符石出现了一点表面裂痕（妖兽冲撞时波及了附近墙体）。他用随身带的修复材料把符石补好——贴着菜市场后墙蹲在里面补了半小时。蹲在墙角里的动作让他想起三十多年前在某个大厦机房设备间熬夜修 bug。

修完符石后他站起来活动了一下腰——然后站在菜市场后门往外看。她正在菜市场买菜——今天的菜篮子里有莲藕和排骨——大概是晚上煲汤。她选莲藕的手法仍然和第一世在青云宗厨房择菜一样——用手指敲一下藕节——听声判断新鲜度——然后决定要不要。敲的声音传到他耳朵里——笃笃，很闷，很熟悉的节奏感。她付了钱，拎着菜篮子走出菜市场——路过他所在的菜市场后门街角时侧头看了他一眼。

"林先生——你的手臂伤势怎么样？"

她看的是他的左手——昨天妖兽撞击时他的衣袖被撕裂了一点——他没处理——露出一块不太严重的小红印，其实已经自动愈合了——但他随手仍压了些纱布在外面做样子。她可能是听镇上的谁说的——没人知道他受伤了——她自己去打听来的。

"没事。"他说。

她犹豫了一下——然后把手中的一袋莲藕推出一根——"这个你拿去煲汤——莲藕对筋骨好——补一补——你要是没时间煲——我给你炖一锅排骨汤——到时候让老张送到你茶仓——"她说到这里觉得似乎有点过了——"——如果不是太打扰你——"

林牧把莲藕收了。不是想吃莲藕——是她递出来的。他接过去的时候手指触摸到莲藕表面——上面还带着她在菜市场水池里洗过的凉水。她的指纹是模糊的——但这根莲藕是她选的——她敲过它——然后递给了他。

他说了一句："不打扰，谢谢。"

他那晚把那根莲藕放在了茶仓的架子上——没切，没煮。让它在角落里静置着晾干。锦鲤说他"疯了"。老猫也说。他把莲藕切成两片——一片自己留着没煮，一片放在水壶口上让锦鲤闻了一晚上（鱼不能吃莲藕——但可以闻着那种土壤里被冷水洗过的淡泥味）。

"你知道你为什么感动吗？"锦鲤说。

"不知道。"

"不是因为她给了你吃的——是因为她用了她自己的方式关心你。哪怕只是普通邻居之间的。这让你觉得她还认识你——不算认识——但至少把你当人了。"

林牧没答。他把那片半干的莲藕放回了架子——然后开始打理茶仓里的药材柜——专心致志地整理药瓶。锦鲤在水壶里看着外面——茶山上的星星特别亮——昨晚冷空气南下，天空格外通明。

药瓶整理完了。他洗了好几次手——水很凉。手指在水里泡到指尖皮肤起了皱——他还在洗手——手指交互搓着——像是在洗掉什么东西，又像在反复触摸记忆中残存的那一丝若有若无的温度。

锦鲤没再打扰他。窗外的星星静得像是宇宙在屏息。

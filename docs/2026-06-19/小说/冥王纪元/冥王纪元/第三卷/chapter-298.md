# 第298章 离宫深处，第八块碎片散发光芒

石门在李长生面前自动打开了。

没有机关、没有阵法、没有任何触发的机制。石门只是在他面前打开了——仿佛这扇门等了一万年，就是在等他走到这里。

门后不是通道。是一座冥殿。

殿的内部空间远比从外面看到的要大——大到不合理。从通道入口的位置往深处看去，殿的尽头至少在一公里之外。穹顶高悬在上方三十米处，不是由柱子支撑的——整座殿的穹顶是悬浮的，由一道淡金色的灵力场托着，静静地悬在头顶。穹顶的内壁上画着一幅完整的星图——不是地球上空能看到的那种星图，而是一幅包含了数以万计恒星系统的三维星图。每一个恒星系统都有标注：位置、行星数量、灵气等级、文明类型。

李长生认得其中一些标注。他曾在冥王残魂的记忆中看到过这些星域——那些都是万年前冥王势力范围内的重要据点。

但此刻他的目光没有停留在星图上。

殿的正中央，有一座石质的修炼台座。台座大约半人高，由上下一整块不知名的黑色石材雕凿而成。石材在殿内的微光中呈现一种接近黑洞的质感——光落在它表面就被吸了进去，没有任何反射。台座正面的凹槽中，嵌着一枚碎片。

第八块碎片。

它比之前七块碎片中的任何一块都大。大约两指宽、五指长，形状像一个拉长的菱形碎片。它的表面不是黑色的——而是一种深邃的暗金色。光芒从碎片的内部向外渗透，不是均匀的——而是像脉搏一样，以大约每三秒一次的频率明灭。每一次明灭，整个冥殿的墙壁、穹顶和地面都会随之微微震颤。

不是物理上的震动。是能量层面的脉动——这块碎片在用自己的能量和整个离宫共鸣。

"跟之前碎片的共鸣强度完全不在一个量级。"小王盯着灵气探测仪上的数据。仪器的量程在进入冥殿后的第三秒就被打满了——不是过载，而是这个空间内的灵气浓度已经高到了仪器设计者从未考虑过的量级。如果把地球上的平均灵气浓度设为一，那么此刻的环境灵气浓度是两千六百。比长白山灵眼的浓度还高一个数量级。

刀疤握战斧的手在微微发抖。不是因为恐惧——是因为他体内的体修灵气在和冥殿的灵力场产生共振。他的每个细胞都在被压缩和拉伸，仿佛有无数只看不见的手在揉捏他的肌肉和骨骼。

"这地方——力量密度比月球基地高五十倍不止。"老马蹲下来，手掌贴着地面。他的感应结果让他额头上立刻冒出了汗珠——整个冥殿的地基是一个完整的灵脉节点。不是地球上那种十二灵眼级别的节点——而是整个火星地壳下最大的灵脉总枢纽。火星上全部可用的灵气，有百分之六十以上通过这个节点流转。

陈霜走到他的旁边，手肘碰了碰他的右臂。她的剑在剑匣里震得厉害——不是因为恐惧，而是因为渴望。她的本命霜降剑是剑修之剑，天生能感应到强大的能量源。此刻霜降剑的反应，比当初在月球遇到第七块碎片时还要强烈。

"这碎片不是之前那种残片——"陈霜盯着台座上的暗金色光芒。她的话只说了一半，但所有人都听懂了她的意思。前七块碎片虽然也蕴含着冥王的力量，但每一块都像一个独立的存在——各自为政，各有侧重。而第八块碎片不同——它身上散发着一种核心的气息。仿佛之前的七块碎片都是从它这里分裂出去的，而它自己才是冥王令的原始核心。

李长生没有回应。他正在感受。

七块碎片在他体内形成的冥王令轮廓，在距离第八块碎片还有二十米的时候就开始产生反应了。不是之前遇到新碎片时那种单一的引力——而是一种更复杂的、像拼图最后一块即将归位的感觉。他掌心的冥纹从暗金色变成了纯金色。这种纯金色他只见过一次——在冥王残魂的万年前记忆里，全盛时期冥王令的颜色就是纯金。灿烂而不刺眼，温暖而不灼手。

他往台座走了过去。

每走一步，体内七块碎片的震动就增强一分。走到第十步时，他的冥渊空间开始自行扩张——不是他有意识地在催动，而是体内的碎片力量在被动响应外界碎片的召唤。从一间屋子大小扩展到了一栋楼大小。再到第十三步时，冥渊空间已经扩展到了一个小广场大小。

他听到了声音。不是在耳朵里听到的——是在神识里。

第八块碎片在"说话"。不是用语言说话——它本身没有意识。而是它在释放一种类似于"状态报告"的信息。碎片在告诉他：自我封印完成，等待回收，自检状态完好，能量储备百分之九十七点六，核心功能模块无任何损坏。

一万年前的自我封印。一万年后，自检还没完成——能量从百分之百降到百分之九十七点六。一万年只衰减了不到百分之二点五。这块碎片的内核能量密度高到了令人恐惧的程度。

"等一下——"小王盯着探测仪的数据，声音第一次出现了不自然的颤抖，"李哥，你先别碰那个碎片。你看一下台座下面的结构。"

他把电脑屏幕转向李长生。屏幕上是一张灵气热力图——台座下方三米的区域。图像显示的不是单一的灵石核心，而是一张密密麻麻的能量网络。至少有上千条独立的灵气回路从台座底部延伸出去，像树根一样扎入火星地表深处。每一条回路都连接着一个独立的阵法节点，而每一个阵法节点上都运转着一个独立的功能模块。整个网络覆盖了离宫的全部区域——通道、防御系统、居住区、修炼区、物资储备区、通讯系统。

"这个台座——"小王深吸了一口气，"是整个离宫的主控核心。机械系统里这叫主控制台。计算机网络里这叫中央服务器。修仙体系里——这大概叫阵眼。"

"阵眼？"刀疤问。

"一个覆盖了整个离宫的超大范围复合阵法的阵眼。"小王指着屏幕上的回路图，"你们看——周边这些连锁节点。每一个节点负责离宫的一个功能区域。战傀的指挥调度、防御阵法的开关状态、内部灵气循环系统的流量控制、生活设施的运转监控——甚至包括通讯系统的收发状态。所有的控制信号，全部通过这个台座发出。"

他说完，抬起头看着李长生，眼神里是一种无法掩饰的震撼。

"意思是——这个台座不仅仅是碎片存放点。它是一万年前整个离宫的操作系统。而那块碎片——"他指着台座正面的暗金色碎片，"相当于操作系统的根密钥。谁拿着根密钥，谁就拥有整个离宫的最高管理权限。"

整个队伍沉默了。

这种沉默不是恐惧。是在消化一个太庞大的事实。他们本来只是来取第八块碎片的——但现在他们面对的是一整个上古军事基地的最高控制权。一台在一万年后仍然在运转的、覆盖了一颗行星最大灵脉节点的超级复合阵法系统。

李长生在台座前三步的位置停了下来。

他低头看着自己的右手。七块碎片在掌心形成的冥王令轮廓正在发出和第八块碎片完全同频的脉动——每三秒一次，同步率百分之百。七块碎片和第八块碎片已经产生了共振——不是王和臣之间的关系，而是同一个存在在两端同时脉动。

"取了碎片之后——离宫的控制系统会怎样？"陈霜问了一个关键问题。

李长生沉默了几秒。他从残魂的记忆中找到了答案："会苏醒。根密钥被移除，会触发管理系统的苏醒程序。这意味着——失去根密钥一万年之后，系统将首次被激活。如果我没有猜错的话——离宫的所有防御功能会在取走碎片的那一刻全部开启。"

"那不是和月球基地一样？"刀疤说。月球基地取第七块碎片时，整个基地的防御系统被激活了，爆发了和大量战傀的战斗。

"月球基地是废弃的前哨站。"李长生看着台座正面的碎片，每一个字都带着分量，"这里是核心指挥部。一万年前冥王自己住过的地方。月球基地的战傀数量是上千，这里的战傀数量——如果按离宫的规模来推算——至少是三倍到五倍。而且月球基地的防御系统只运行了百分之十二。这个——"

他停顿了一下。

"这个一直在百分之六十的待机状态运行。一旦苏醒，就是全功率。"

刀疤回头看了一下来时的通道。通道很安静，安静得像什么都没有发生过。但他知道——在通道的外面、离宫入口到冥殿之间的十二个防御区里，至少还有两千台以上的战傀在沉睡。那些战傀的战斗力他亲眼见过——在月球上三台战傀就能让他们陷入苦战。这里有两千台，而且每一台的灵石核心功率都远超月球的战傀。

"取吗？"小王问。

李长生没有犹豫。他抬起头，右手伸向台座正面的凹槽。他的手指距离碎片还有不到十厘米时，碎片的光芒忽然变得剧烈——不再是每三秒一次的低频脉动，而是一种连续的、越来越强的爆发式释放。暗金色的光芒从碎片表面扩散开来，沿着台座的石材表面蔓延，顺着那些密密麻麻的灵气回路流向整个离宫。

整个冥殿的墙壁、穹顶和地面同时亮了起来。

不是灯亮了。是刻在石材深处的符文图案在发光。数以万计的符文同时激活——不是之前战斗时那种战斗阵法的集中破坏型符文，而是更复杂的、包含逻辑门和信息通道的信息系符文。这些符文的排列方式小王一眼就认出来了。

"和月球战傀体内的符文程序——同一套底层架构。"

符文的发光在加速。从墙壁蔓延到穹顶、从穹顶蔓延到地面、从地面蔓延到空气本身——整个冥殿变成了一个巨大的符文显示屏。数以百万计的独立符文在按照某种预设的程序亮起和熄灭。那些光线在黯淡的火星离宫深处形成了一种极度诡异的画面——仿佛这个死了一万年的地方，忽然有了心跳。

然后，一个声音响了起来。

不是从任何人的嘴里发出的。不是从任何喇叭、任何阵法扩音器中发出的。是一个直接出现在所有人神识中的声音——不是传送信息，而是直接将语言转化为每个人都能理解的神识感应。

"身份验证——进行中。"

古老的语音。每一个字都带着上万年的寂静。

"检测到冥王令持有者——身份确认。检测到冥王血脉灵气——灵气特征匹配。验证通过。"

停顿了一秒。

然后那个声音再次响起。这一次，它的语调中多了一丝无法用语言描述的重量。

"欢迎回来。主人。"

(第298章完)

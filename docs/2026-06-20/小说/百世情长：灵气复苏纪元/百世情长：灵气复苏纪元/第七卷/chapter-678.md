# 第六百七十八章 灯火塔的扩建

飞升之门运行三周年之际，太湖中心岛的灯火塔进行了扩建。不是往上加高——是在塔的四周围建立了一圈矮墙，墙上开了许多小门。每扇门通往一条通往不同方向的小路——蜀山、华山、北境、东海、太湖散修区、以及上界过渡区的炉火前哨。一扇最大的小门直接通向桂花园的院子——这条路由石头负责维护。

塔的底部新增了一块石碑——不是刻功绩，而是刻名字。不是林牧和苏晚的名字——是所有参与建造飞升之门、灵网和学院系统的志愿者名字。石碑的刻名方式也很特殊——不是横排竖排，是围绕灯火塔呈辐射性的螺旋状向外扩散。杜散修和他的女儿的名字在最外圈——因为从上界过渡区看下来，他们的名字最接近星空。

叶小雨负责刻碑——她的手部控制力现在已经非常出色，能在青石上刻出比头发丝还细的凹槽。她刻到自己名字的时候停了一下。旁边的人问她在想什么，她说："我姐的名字也应该在这上面。她当年被冷处理不是因为说错话——是因为说了对的。我要把她的名字刻在我的旁边。"她在公共碑上刻了"叶小霜"——右上角缺了几笔——但笔笔都是真的。

刻完已经是半夜。叶小雨坐在灯火塔下，看着那些名字一个个在火焰的光芒中若隐若现。她从口袋里掏出一张便签——这张便签是苏晚几年前在灵网正式留任给她时写的："叶小雨——你的恐惧是你的刻度仪，不是负担。你每次检查三遍——不是因为胆子小，是因为你的精确度高。苏晚。"她在灯火下翻着这张旧便签的边角。白纸上边角已经有了黄斑。她想了一下——然后把它折好放回口袋里。不是需要再看——是需要知道它在那里。

与此同时，林牧在院子里画新的灵网升级图。苏晚在旁边编写《上界灶台计划》——一份将在上界过渡区复制桂花园模式的详细方案。他们在同一个石桌上各做各的，偶尔抬头看一眼对方。不用说话——但节奏是一样的。

（第六百七十八章 完）

# 第122章 蓬莱遗址中的修仙文明残迹

石门在背后合上了。

不是滑动的。是整块岩石直接改变了形态——门上的石质在十秒内从固态变成了半流质，像融化的蜡烛一样淌下来，重新凝固后变成了一面无缝的墙。这不是机关。是灵能材料——一种在万年前已经失传了的、能将岩石与灵阵融合在一起的建造工艺。

李长生收回手。掌心的冥纹还在发烫——刚才按在门上的那一瞬间，门读取了他的冥纹模式，就像一把锁认出了自己的钥匙。

他现在站在蓬莱最深处的殿堂内部。

殿堂是一个极为规整的八角形空间。每一面墙高约二十米，八面墙交汇于穹顶中心。穹顶上嵌着一颗直径约一米的灵石——不是蜡烛级别的，是真正的高纯灵石。它到现在还在发光。光泽柔和而稳定，亮度约等于傍晚的日光，把整个殿堂照得清晰可见。

光线下，殿堂内部的细节一览无遗。

八面墙，每面墙前立着一件器物。

第一面墙前：炼丹炉。但这尊炉和外面生活区那尊不一样。它不是石化，是完整的。炉身用某种深紫色的金属铸成，没有任何锈蚀。炉盖上的卦象还在旋转——不是机械转动，是灵阵在维持一个极低速的循环。炉内还有极微弱的余温。龟相透过摄像头看了一眼，沉默了好几秒才说："紫金丹炉。整个地球历史上造过的紫金丹炉不超过五尊。这是唯一存世的。"

第二面墙前：一排玉简。玉简整齐地插在一个石制架子上，每片玉简厚约三毫米，长二十厘米，宽八厘米，材质是某种不透明的白玉。玉简表面刻着细密的文字——不是画上去的，是用灵气把信息"刻"进了玉的晶格结构里。一万年的海水没有侵蚀它们——玉本身是绝缘的，灵气刻录的内容只有用对应的灵根阅读时才会显现。

陈霜用手碰了一下其中一片玉简。青锋剑与玉简同时亮了一下。玉简上的文字浮现了出来——是蓬莱青锋府的功法目录。一共有四百余篇。正篇七十二篇，副篇三百余篇。每一篇的标题下都标注了修炼条件：修为要求、灵根种类、剑法前置课程、可能的风险。

"七十二篇正篇——"她的手指划过那些字，"传世的只有六篇。其余的都在万年前沉没了。"

"现在它们全在你手里。"李长生说。

她没有回答。她把玉简的信息一页一页地用头盔摄像头拍下来——拍到第十几页的时候手指有些抖。

第三面墙前：一个兵器架。架子上横躺着三件兵器。一柄长枪，枪身乌黑，枪尖上依旧带着一层淡金色的灵光——这是金系灵枪，一万年没有出过鞘，但枪尖上的灵光还在。一面盾牌，圆形，表面刻着八卦的变体，八个卦象每一卦都在缓缓自转——这是防御型灵器，八卦自转说明它内部的核心灵阵还在运转。第三件是一根断裂的笛子。笛身裂成了三段，但三段之间的裂口处有一层浅蓝色的灵力膜——这个碎片一直在试图修复自己。

"这是冥王当年的部下留在这里的。"残魂说，"蓬莱不是冥王的敌人——是冥王的盟友之一。蓬莱九宗里，青锋府是冥王的剑术导师。阵宗是冥王的阵法师。丹府是冥王的药师。蓬莱沉没的时候，他们把自己的兵器留在殿堂里——给将来进入这座殿堂的冥王继承者。"

"为什么不留更好一点的？"小王在通讯里问，"如果他们是留给自己人的——为什么不留几件更强的？"

"外面那个大蜥蜴守着门。这座殿堂被一块只有冥王手掌才能解开的门封着。一万年来，你是第一个进入这里的人。还有什么比这些更值钱的？"残魂顿了一下，"而且这些兵器——不是最强的。最强的在里面。"

第四面墙前：一本石书。不是比喻——是真的用石头做的书。石页极薄——每一页只有大约两毫米厚——叠在一起形成了一本半米高的石质书册。翻开来，石页上刻的不是文字，是图像。第一页画的是九块碎片从冥王身体中崩射而出的轨迹图。第二页画的是一幅星空——和外面那间石室里的星图相似，但多了一层数据——每一颗标注的星球旁边都标注了一行注释。

李长生看懂了那些注释。因为碎片的记忆里残留着这些信息——那是冥王本人写的注释。

"此星已死。一万三千年前被虫族耗尽。"

"此星存续但灵脉枯竭，只剩凡物。"

"此星有文明，类人，灵脉丰富但尚无修士——已列入观察。"

"此星正在自毁——内斗，核武自残，预计三千年后灭绝。"

第三页画着一幅更加复杂的图：银河系旋臂结构，标注了已知的所有星际灵能通道。从地球出发的通道只有三条——月球、火星、蓝渊。但从蓝渊延伸出去的通道有十几条，呈放射状连接着银河系中几十个不同的修仙文明。

"所以银河系里有几十个修仙文明——"小王说，"一万年前就有。他们互相之间有通道。"

"有。"龟相说，"但现在都不通了。冥王陨落是银河系修仙文明史上最大的事件——所有的灵能通道在那一刻全部瘫痪了。因为地球是所有通道的中心节点。地球的灵脉被封了，整个银河的灵能交通网就全断了。"

"一万年来，那些文明——"

"——孤独了。和我们一样。"龟相说。

第五面墙前：一棵树。不是画的。是一棵真实的树。一棵被石化了但仍保留着树形态的小树——约半人高，枝干细密，叶子的形状像银杏。它不是完整的植物，是被用灵术缩微成盆景形态的灵树。树根下面连着一个裂了的玉盆。盆底还有残存的灵水——几滴，在灵石的微光下反射出珍珠色的光泽。

"这是悟道树。"龟相的声音忽然变得很轻，"我在《山海异闻》里读到过它的记载。世间只有两棵。一棵在昆仑山顶，一棵在蓬莱。悟道树下修行一日，抵得上普通灵地修行一年。"

"枯了。"李长生说。

"枯了。但枯了的原因不是死——是饿。一万年没有灵气供养。给它足够的灵气，它说不定能活。"

第六面墙前：一座小型雕像。雕的是一个站立的人。披着斗篷，面容模糊，手持一柄权杖——权杖的形状和李长生掌心冥纹的走向是一致的。雕像的底座上刻着一行字。字数很少，但刻得非常深。

"冥王——万劫之主。蓬莱，刻于同盟初年。"

"同盟？"

"冥王与蓬莱是同盟关系。对等的——不是主仆。"残魂说，"你拿着冥王的碎片进入蓬莱，石门认你、蜥龙让你、玉简对你开放——因为你是冥王的继承者，不是外人。"

第七面墙前：一盘棋。石质棋盘，上面放了三十六颗棋子。棋子分黑白两色，但布局完全不是围棋——黑子围在白子外面，白子在中心，形成了一种被同时间围困和保护的矛盾局面。残局。下了不知道多少年。

"这是冥王和蓬莱宗主下的最后一盘棋。"残魂说，"下到一半，诸神联军打过来了。蓬莱宗主站起来说：这盘先留着，打完再下。然后他出了殿堂，再也没有回来。"

李长生看着那盘下了万年的残局。黑白棋子依然在灵石的微光下安静地待在它们一万年前停留的位置。没有人动过它们。没有人能动得了它们。

第八面墙前：没有器物。整面墙是一扇门——不，是半个门。墙壁的正中央有一个长方形的凹面，凹面极为平滑，像一面打磨过的镜子。但镜面里没有反射殿堂内的光——镜面里是另一个空间。空间中是星空。不是画上去的星空，而是真实的、在缓缓流动的、极远处的星星。

"这是——星门？"小王的声音变了。

"星门的残骸。"龟相说，"蓬莱沉没的那天，它接通了外界的最后一瞬间被冲击波切断了。凹面里残留的是它最后一次开启时的画面——一万年前的星空。你看到的那片星，是万年前的银河。"

八面墙，八件遗物。每一件都比上一件更加沉重。不是物理重量——是时间在这座殿堂里沉淀出的密度。

李长生站在八面墙的中央。头顶的灵石缓缓旋转，投下一束稳定的、柔和的、近乎温柔的光柱。

光柱的中心是殿堂最核心的位置——一座祭坛。

祭坛不大。高一米出头，直径约两米。坛身用白色的材料砌成——不是石头，不是玉，是某种介于两者之间的、带有天然纹理的物质。坛面的中央凹陷下去——一个凹槽。

凹槽的形状，和他掌心的冥纹一模一样。

凹槽中间，一块碎片安静地躺在那里。

它的幽光照亮了整个殿堂——不是灵石的光，是碎片自己发出的、一万年来从未熄灭的暗金色光芒。那块碎片比前三块加起来都大。外形不规则，边缘呈撕裂状，表面密布着比发丝还细的纹路。

它在等。

等一个手掌，等一种纹路，等了一万年。

"第四块。"李长生说。他的声音很轻，像怕吵醒它。

"别急着拿。"残魂的声音忽然变得非常清醒，清醒到几乎尖锐。"看祭坛周围。"

李长生低头。

祭坛周围的白色地面上，刻满了符文。那些符文不是凸刻——是凹刻的槽线，每一道槽线都在发光。暗金色的光在槽线中缓缓流动，从祭坛向外扩散到整个八角殿堂的地面、墙壁、穹顶——整座殿堂都被这些封印符文覆盖着。

这些封印符文是冥王亲手刻上去的。为了保护这块碎片。但封印也是锁——拿走的瞬间，锁会断。

"锁一断，"残魂说，"万年前封印在蓬莱下面的东西——会被放出来。"

李长生看着祭坛上安静发光的碎片，看着周围密密麻麻的封印符文，然后说了一句："我知道。"

他向前走了一步。

（第122章完）

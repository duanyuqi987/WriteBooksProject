# 第257章 十世遗物的神龛

回到晚牧居之后，苏晚做了一件她酝酿了好多年的事——她把两人十世以来所有的定情遗物进行分类整理，在晚牧居一楼新辟了一间极小的房间作为"十世神龛"。她用岛上原产的一种极轻极透的仙蚕丝作为神龛中每个放置点的布底——然后把所有物品按"时间线"顺时针方向一一排好。

神龛中第一个位置——第一世——摆着她编的第一根剑穗（残旧但依然保有金丝），林牧从第一世她离开后收护至今；第二世——第二片青溪龙井干茶叶和第一根红色棉线残段；第三世——第三世那半条永远未吃的鱼干和她未曾察觉他存在的礁石上的碎石片（是当时他坐守时膝盖垫着的那块石头）；第四世——赤霄宗金火疗伤丹（和他的戒指一起放进透明小琉璃瓶里）和他用油纸伞遮雨的岩缝石片；第五世——铁锤柄上脱落的木屑和矿道门口的石渣，以及第五条剑穗（她用废铁链和红线做的那个）；第六世——白谪初次下达的飞升资格的复写纸片、赤霄壁画副本、她写的"记忆初醒"第一页日记；第七世——昆仑穆氏冰心灵雪凝成的永久不化雪晶（老祖送的），她的百世归一剑诀第八版手稿，以及两柄剑并排放置时曾托着它们的旧剑台石；第八世——在灵魂交融第三层之前测试时两人同心对炼用的那对灵力匹配珠（由白谪以仙界器物级别的灵测珠做复制备份后，留给他们）；第九世——鸾凤离火燃烬最后一缕火苗被仙力封存后的琥珀状结晶，和林牧在整理每世剑穗时缠绕出那一段"九穗合紫结"（他把九根剑穗结成一串并在中央打成一个象征"九归一"的复合结）；第十世——她的凡铁剑（完全废锈但仍架在剑挂中心最高位置），林牧的窄身剑静置在侧旁，两柄剑中间的间隙处是仙界仙帝盖印的"全案撤销裁定书"及双核金印复刻版，两枚仙金婚戒则悬空用一对从晚牧居后山找到的小仙磁石轻轻吸住浮在各自剑格正前上方。

此外，还有一个特别位置——第三百六十一度——是给未来——留给第十一世以后的未知日子用来存放新物——格位牌子上面写着:"未完——待续。每天加一点。"

林牧站在神龛前从头看到尾——他的视线在每一件物品上停留的时间都极短——因为他怕看久了会忍不住掉泪。当看到第五世那个小小的铁锤木屑时他还是没忍住——那块木屑是他跟她一起打铁时从锤柄上掉下来的，一直留着是因为上面沾着她递给他的第一块硬饼的饼渣——饼渣还以微粒的形式附着在木屑裂隙里面——他从来没告诉过她。苏晚在建立这个神龛时也并不知道饼渣，但她看到他在神龛前呆了很久后眼角似乎有点泛光——她走过去发现他在看木屑的裂隙层。然后她注意到了那一小片东西是什么——她把他的手指和木屑同时托在掌心——说:"第一块饼都糊了——你说'还行'——害我以后每次都做成那样的硬度。""够了。饼够硬——让人打铁时知道有东西撑着心。"

神龛完成之后两人定下一个规矩:每天傍晚在神龛前一起站一小会儿，轮流说一件当天值得记住的事，然后在"未完待续"那个空格里用手指划一小道新痕。每天一道——无数年后，这些痕迹会被他们自己回望成一幅细微的地图——上面注满人间和仙界所有的早晨与黄昏。

有一天傍晚苏晚说:"今天值得记住的事——我在炼剑室里把自己的金火重新烧了一次——结果把茶壶烧穿了。""然后""然后你拿你打铁的锤子帮我把壶底敲平了——我说的是这个——你每次遇到我在搞破坏你都会默默用锤子敲——没有一次例外。"

林牧也在同一天续说:他想记住她在茶壶穿孔时笑声——那种嗓子破音但在笑自己手笨的释然笑——和第四世她在周烈倒台后的夜里，对着火炉压抑不住的那种夹杂心疼和放松的笑一模一样。两百多年了，从她每一世在黑暗尽头的笑——她在第十世修复自己的能力并像没事似的继续做出下一盏壶——是贯穿所有世的持续笑——他要把它以笑痕的方式划进明天的备忘。

明天又是新的一页——凌晨时——晚牧居的流萤飞鱼群在窗外围成圈结队——把两人在第一道新道光芒里映成两重长短不一但终于止住漂泊的影子。神龛里所有遗物静静在深夜泛着各自不同的淡淡光——像是在说:"十世已满。启航就绪。"

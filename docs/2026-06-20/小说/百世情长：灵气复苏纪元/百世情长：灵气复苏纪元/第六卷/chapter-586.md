# 第五百八十六章 冰晶草的第十二片叶

在仙上仙谷住到某天清晨，苏晚醒来时发现冰晶草盆里多了一片展开极完美的新叶。第十二片。她蹲在盆边极慎重地用手指尖碰了一下那片叶的边缘——叶片微凉，肉质感极足，中心叶脉是极淡极淡的金线。功德绳那端林牧在劈柴桩那里感应到了——他把斧子放下。走过来也蹲下。两个人蹲在那盆草前面看了好一阵子。十二片。他掏出卷尺量了一下盆沿到最外那片叶的距离比上个月同测数据长了。她掏出笔记本在"冰晶草生长记录"表上填了新一行:第十二片叶——完整——地点:仙上仙银杏谷——日期:同上。见证人:林牧。

然后她转过头看着正在用松屑细细铺土的他，忽然说:"你以前说过——那天你在炼丹炉前被烧伤的手，是我在洞府里用雪水帮你洗的。现在这盆草的第十二片叶子出来了——我想帮你洗一次手。不是伤口——是普通的洗手。就温水和一点松屑皂。"

林牧把两只手摊开。苏晚用温水仔细地洗掉他掌上今早劈柴时沾的木树脂和松屑——包括他虎口那块极其粗糙极老旧的斧柄磨出的大茧。她洗到茧时弯了一下嘴角:"这个茧是万年前因为握剑开始长——后来握剑手变劈柴手，茧没变。以后不握剑，茧还是会一直长。每长一分都代表你今天劈了多少柴。"林牧看着自己被她洗得干干净净的手掌——然后他把两只手反过来握住了她的手。"洗手——你虎口上那道疤是在昆仑山拆噬魂铃时划伤的。那道疤也一直在。我们两个疤都在手上——以后分不清楚哪个是谁的。分不清最好。"

她让他在原地稍等了等——然后把功德绳上的两块空白木牌拿过来。被热水洗过的手极干净地握着那两块牌。她把其中一块空白牌放在他刚铺好松屑的冰晶草盆沿上。"等你什么时候想刻——再刻。"他把她那块空白牌放在她的笔记本扉页中间夹着。"你的空白——也留到你想写的那一行。不急。永远不急。"

在银杏树下仙上仙远远地看着。他又拿起了那只修了半截的旧茶壶——壶底还没补好。但他看着那两个蹲在草盆前的人，把茶壶盖随手扣在壶上——不补了。铜丝剩下一截被他缠在了旁边的银杏枝上——任它以后和树长在一起。

（第五百八十六章 完）

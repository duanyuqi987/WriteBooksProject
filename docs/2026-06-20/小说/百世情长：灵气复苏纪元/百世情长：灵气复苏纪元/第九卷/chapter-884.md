# 第八百八十四章 第十卷的前奏之约

在数次极长程的扩窗任务后，林牧和苏晚决定暂时休整——再次回到青云山谷。山谷没有变——那是飞升之门的常驻法则把它永恒定格于他们离开时的状态。石桌依然在。青苔厚了些——但覆盖在三重阵法上的苔花还是那丛小小的白。

他俩在石桌边坐定。林牧左手搭在桌面上方，指尖悬停——像在感知空气中还存留的什么。苏晚没有打扰。她知道他在动用极深层的共鸣回检他们此生所有轨迹。然后他忽然笑了——不是常见的微微上扬唇角，而是一种更加舒展的、恍然的笑。

"你想到什么了？"

"我推演了半天。然后发现——根本不需要推演。九卷结束，第零卷就已经定了。第九卷的终章就是第十卷的序。"

苏晚侧过身——双翼态即时同步了林牧脑中那幅非常遥远的远景。她看到了未来可能发生的一切——他们已无需用言语去表达最终的信任。未来第十卷是相互尊重——而在第九卷结尾他们已经不经意间完成了彼此的最高敬意。就像一条极其深广的河即将入海，而海就在眼前。不是结束——是融汇。

"相互尊重——"苏晚缓慢地读出这四个字，然后嘴角弯起，"你推出来了吗？——第十卷我们该怎么做？"

"不用推演。尊重不需要计划。你只要是你已经是的。我就是我已经是的。我们在一起走——不替对方做决定。这就是尊重。"

苏晚点点头。然后她忽然站起来对着山谷空处喊了一声——不是多大的音量——"喂——第十卷我们来了——不准锁门！"

山谷的回声弹了三弹——最后落在石桌上的茶杯盖发出细细的嗡声。星眸把它收录为"双尊跨卷宣告1.0版"。当晚在守门人区的子夜鉴新目录中多了一行非常短的未公开条目——"飞升之门第九卷与第十卷交界处——守门人于青云山谷口头立约：最后一卷致敬所有信任的起点。相互尊重——即承认对方终将成为他自己。"

而通往第十卷的门——没有门槛。只是一早苏晚从石凳上站起来去厨房看水开了没。林牧坐在原处用刚削好的小树枝在茶杯底画了一个几笔完成的蝴蝶结。然后喝茶。一切都如常滑行入下一个大章节。

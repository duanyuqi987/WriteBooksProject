# 陈小树

## 基本信息

| 项 | 内容 |
|---|------|
| 身份 | 太行书院第一批弟子，搬砖少年→筑基→器修苗子 |
| 出场 | 第904-906章（第十卷前期） |
| 修炼方向 | 器修（炼器方向），擅长炼制低阶法器 |
| 功能 | 苏晚教育理念的第一个有力证明——普通人也能修炼 |

## 性格

- 朴实到近乎木讷——来自农村，说话直来直去
- 坚韧不抱怨——"修炼是赚的"是他的口头禅，再苦再累都笑着扛
- 对苏晚有近乎崇拜的感激——她是第一个对他说"你可以"的人
- 勤奋到令师兄弟咋舌——别人练一遍他练十遍
- 不觉得自己"励志"——他只是觉得"有机会就该好好抓住"

## 背景

- 来自太行山脚下的贫困村庄
- 父母是普通农民，家中兄弟姐妹多，吃不饱饭是常态
- 在建筑工地搬砖为生，偶然听说太行书院招弟子
- 抱着"反正不要钱"的心态去试，被苏晚看中——不是因为资质好，是因为他的眼睛里有光

## 核心欲望

- 学成本事，让家里人吃饱饭
- 不给苏晚丢脸——"夫子信我，我不能让夫子失望"

## 核心恐惧

- 自己的平凡资质终究是天花板，辜负苏晚的培养
- 修炼这条路走不远，最后还是要回去搬砖

## 不可逆选择

- 面对宗门招揽时拒绝——"太行书院不收学费教的我，我哪能学了本事就跑？"
- 这个选择定义了太行书院弟子的底色：感恩与忠诚

## 声纹

- 说话带点北方方言腔调（"俺""中"等）
- 句子短，不绕弯——"中。我试试。"
- 紧张时会结巴，但做事从不含糊
- 不会说漂亮话，但用行动表达一切

## 关键台词

- "修炼是赚的。"
- "夫子信我，我不能让夫子失望。"
- "俺以前搬砖，一天挣三十。现在修炼，哪天不是赚的？"
- "太行书院不收学费教的我，我哪能学了本事就跑？"

## 关键场景

- **第906章入学**：在太行书院入学测试中，陈小树资质平庸但意志力惊人。苏晚力排众议将他收为第一批弟子，说："资质可以慢慢弥补，但这股劲——教不出来。"

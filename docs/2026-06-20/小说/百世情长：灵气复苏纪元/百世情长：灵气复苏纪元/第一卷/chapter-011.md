# 第11章 新闻封锁与全网热搜

事情是从一条短视频开始的。

四川眉山，一个养鸡的农户早晨起来喂鸡，发现院子里三十多只母鸡全部消失了。他在鸡舍周围找了半天，最后在屋后的竹林里找到了它们——三十多只鸡整整齐齐地排成三排，面朝东方，一动不动。农户以为鸡都死了，走近一看，发现它们在呼吸。每一只鸡都闭着眼睛，翅膀微微张开，以一种非常规律的节奏在呼——吸——呼——吸。农户拍了视频发到抖音上，配文："我的鸡好像在练气功。"

视频在一个小时内被转发了五十万次。

评论区起初是铺天盖地的哈哈哈，说这群鸡肯定是看了修仙小说。有人翻出了一本地摊上卖的旧武术手册和母鸡"站桩"的照片做对比，引来更多嘲笑。直到有一个认证为生物学博士的账号发了一条评论：

"鸡的呼吸频率通常在每分钟三十次左右。视频里的鸡呼吸频率大约每分钟六次。这种呼吸模式在现有的禽类行为学文献中没有任何记载。"

这条评论被人截图转发到微博，迅速引爆了第二波讨论。

然后在同一天，更多的怪事冒了出来。

广东佛山，一个住户拍摄到自家阳台上的一盆绿萝在三天内长满了整个阳台——从最开始的二十厘米长到将近六米，藤蔓沿着防盗网一直爬到楼上邻居的窗户外，把晾衣架全部缠死了。物业来处理的视频里，工人用剪刀剪断藤蔓，不到一个小时藤蔓又长出了新的。视频末尾，拍摄者说："这盆绿萝我养了五年了，从来没长过这么快。"

江苏扬州，一户人家的泰迪犬忽然学会了开门。不是那种跳起来趴把手的开门方式，而是一只用前爪按住门把、另一只把门推开，然后回头看了主人一眼——眼神里带着一种明显的得意的表情。主人把监控录像发到网上后，有人发现这只狗在三天之内学会了开大门、开冰箱、开水龙头和用马桶冲水。主人说："我现在锁它必须用钥匙，因为它会开所有的把手门。"

河南商丘，一个七十岁的老人在公园里打太极拳时，身体周围忽然出现了肉眼可见的白雾。不是汗水蒸发的雾气——量不够大。当时的目击者拍下的视频模糊，但能看清他每一掌推出时，周围的空气确实出现了肉眼可见的波纹。老人被家人带回家后接受了当地媒体的采访，说自己也说不清怎么回事，"就是觉得今天手脚特别热"。

当天晚上，#鸡在练气功#、#绿萝成精#、#我家狗会开冰箱了#、#太极拳爷爷有气功#四个话题同时冲上了微博热搜。前十名热搜里，有六个和灵异事件有关。

林牧是在下班后刷手机看到这些的。

他坐在出租屋里，把所有相关的视频都看了一遍，每个视频都反复拉回来看了好多次。他不是在猎奇，而是在判断——哪些是真的灵气事件，哪些只是网友夸张和算法推送放大的巧合。

他的结论是：至少有一半是真的。

鸡群的那个视频，从鸡呼吸的节奏来看，确实符合引气入体的初级呼吸法——不是人类修行的版本，而是动物在灵气浓度足够高时本能做出的反应。当空气里的灵气浓度达到一定阈值后，一部分天生感应敏感的动物会自发进入一种类似冥想的状态。不是它们学了功法，而是灵气本身在引导它们重新找到原始的呼吸方式。

绿萝疯长同理。灵草在灵气充足的环境里生长速度远超普通植物。那盆绿萝大概率是在根部的土壤深处接触到了从地脉渗出的灵气，被激活了某种远古的植物记忆。

至于那只泰迪——他看了两遍监控录像，确认了：这只狗的大脑被灵气浸染后，某些区域开始发育。它对世界的理解正在从"兽"的角度向"灵"的角度转变。

而太极拳老人的视频最让他关注。他反复看了六遍，把画面调到最亮，仔细看老人每一掌推出时的空气波纹。那不是气功——那是灵气外放的雏形。老人在几十年太极练习中不知不觉打通了部分经脉，当外界灵气浓度足够时，那些已经打开的经脉就自动吸纳了灵气，形成了基础的灵气循环。他不是在打太极拳，他是在无知觉的情况下，把太极拳的招式当成了引气的路径。

换句话说，空气中灵气的浓度已经提高到了能让部分先天体质敏感的人自发感应的程度。

这意味着他的时间不多了。

林牧放下手机，打开电脑，切换到一个空白的浏览器页面。他在搜索框里输入了三个关键词的组合："异常现象"、"官方通报"、"近日"。搜索结果第一条是央视新闻的官方微博——今天下午发的：

"【多地出现自然现象引发关注】近日，四川、广东等多地网友反映出现异常自然现象。专家表示，当前正值春夏之交，气候条件复杂，部分现象与气压变化、植物生长周期等因素有关，属于正常的自然现象。请广大网友勿过度解读。"

一段标准的官方通报，措辞精确、语调平稳、结论明确：正常现象。不用担心。

林牧又打开了一个页面——国家应急管理部的官网。首页上挂着的还是常规的防汛抗旱、森林防火通知，看起来一切如常。但他发现了一个细节：应急管理部在三天前更新了一篇很长的文件——《关于加强新形势下水旱灾害防御工作的指导意见》。文件本身内容平淡，但发布时间奇怪——六月份不是水旱灾害的高发期，按惯例这种意见通常在三月或八月发布。

更重要的是，文件的文号。他查了一下应急管理部最近半年的发文序列，发现这份文件前后各有一个编号空缺——有文件序列号中断了。要么是发了之后撤回了，要么是发了两份但只公开了一份。

他把浏览器关掉，靠在椅背上。

官方的反应速度比他预想的要快。从目前的迹象来看，至少有两个部门已经在行动了：一个是科学口——可能由中科院或某个相关机构牵头，在做现象溯源和理论解释；另一个是行政口——在统一话术、管控舆论、防止恐慌。现在的通报口径是"正常自然现象"，但这个口径不会一直维持下去。当怪事的规模和烈度超过一定阈值，单靠"自然现象"的解释就不够了。

前世他见过类似的情况。一千多年前，有一段时间灵气也发生了一次短暂的、区域性的回升，范围很小，只持续了不到三年。但就是那三年，一个小国里忽然冒出了十几个所谓"天赋异禀"的人——有人能单手举鼎，有人能夜视百里，有人能听清三里外的悄悄话。那个国家的朝廷起初也是封锁消息，把这些人统一"请"去京城谈话。后来——后来那些人再也没有回来。

在当时那个时代，朝廷控制修行者的方法是简单的：要么招安，要么消失。

这一世呢？

林牧重新拿起手机，刷了一下微博的实时热搜。旧的几个话题已经被降权了——#鸡在练气功#从热搜第三掉到了三十名开外，#绿萝成精#直接不见了。但新的还在冒：#我家的狗会算数了#——这个刚上，热度和刚才那几个一样高。

是有人在撤热搜。但撤的速度赶不上新内容冒出来的速度。

他又看了一眼微信朋友圈。一个大学同学——在江西老家做公务员——发了一条状态："最近老家有点怪，山里天天晚上有光，村里老人说是龙脉动了。单位已经发通知让注意舆论了。"

这条朋友圈在七分钟前发的。林牧看了一眼——七分钟，已经有三个人点了赞，五个人在下面评论问详情。然后页面刷新了一下，这条朋友圈消失了。

不是他自己删的。是被删了。

林牧放下手机。

他走到窗边往下看了一眼。橘猫还在花坛边上，正在用爪子在地上写东西。这次写的不再是"饿"，而是一个一个的字——他看不清，但能看出笔画比前几天流畅了很多。这只猫的灵智在以肉眼可见的速度成长。如果再过一两周，它的灵智水平大概会接近一个三四岁的人类儿童。

窗外的夜空中，远处有直升机的灯光在闪烁。不是普通的巡逻直升机——飞得很低，沿着城市的东边山区的方向在盘旋。林牧记得东边那片是白云山，山不高，海拔不到四百米，平时最多就是市民爬山散步。

但今晚，那片山的上空一直有三盏灯光在缓慢移动。

他打开手机地图，把定位切到白云山区域，翻了一下周边居民发的最新动态。有一条发布于二十分钟前的微博，只有一句话和一张模糊的照片：

"白云山顶今晚怎么一直有灯在闪？还有人在山脚下封路。有没有附近的知道什事？"

照片是隔着车窗拍的，能看到山脚下一条进山的路口停着两辆黑色的车，车旁边站着几个穿深色制服的人。照片太模糊，看不清制服上的标志。

林牧把手机放下，在房间里站了一会儿。

然后他盘腿坐下来，开始今晚的第二次修炼。不是平时的温和练习，而是更密集、更连贯的周天循环。丹田里的灵气在他的引导下，第一次连续跑完了六个周天——从《太初引气诀》切换到《凝光诀》再切回来，两条经脉路线交替使用，中间不停顿。

六个周天跑完的时候，他浑身是汗。经脉撑开时有一种细密的酸胀感，从脊柱一直蔓延到四肢，像运动过度后的延迟性肌肉酸痛。但他能感觉到，丹田里那缕灵气比之前粗了将近一倍。

他擦掉额头上的汗，看了一眼时间——凌晨两点半。

窗外，白云山上空的直升机灯光依然在缓慢盘旋。

这座城市里，成千上万的人正在睡梦中刷着手机，看到一条又一条被推上来的诡异热搜，在评论区里打着哈哈、转发、调侃。他们还不知道——或者说正在慢慢意识到——这个世界的底层规则正在被撬动。

而在所有人都看不见的地方，国家机器已经在启动了。

某栋大楼里，有人正在通宵开会。某间会议室的白板上写满了全国各地上报的异常事件。某个老头正在翻看一本发黄的古籍，古籍上的文字和林牧手上那本线装书上的灵文，一模一样。

林牧关掉灯，躺在床上。

丹田里的灵气在黑暗中轻轻跳了一下，像在说：快了。

他闭上眼睛。

窗外，城市的霓虹灯一如既往地亮着，车流一如既往地流动，晚归的人一如既往地走在回家的路上。一切看起来都和昨天没有区别。

但每个人都隐隐约约地感觉到，有什么东西不太一样了。

只是说不上来。

# 第367章 组建宇宙舰队，招募修士战士

招募令是第二天早上八点发出的。

不是用传统的修士传音符——小王用灵符引擎把招募令编译成了一份"灵气广播报文"，通过地球大气层中的灵气网络同步发射到全国每一个灵管局注册修士的通讯手环上。深圳南山科技园的写字楼里收到了一份，河北李家庄的村头老槐树收到了它的灵脉链接也收到了一份，太行山的一个散修洞府、峨眉山的一个佛修寺庙、东北长白山的一个猎户体修营地——全都收到了。

老王在广播里用了最直白的话。任何一个注册修士打开手环就能看到这条消息。

"地球修仙联合政府正式组建第一远征舰队。征集对象：圣者级以上修为——或在特定领域拥有超出修为等级的战斗表现记录者。目标：跟随李长生远征宇宙西部星域。报名地点：位于南太平洋仙联政府总部的一楼登记大厅——或通过手环在线登记。"

后面附了一句话——这句话不是小王加的。是李长生口述的。

"我在地里挖出了第一块碎片的时候，身边的黄土地只有我一个修士。现在地球上有几十万个修士。你们不是我的兵。但这里的蓝天白云——是我们一起守出来的。现在我们要走出去了。跟不跟——自己决定。"

招募令的在线登记页面是在早上八点零三分上线的。八点零四分——第一份报名表进来了。

小王盯着刷新频率惊人的报名数据库。到早上八点十五分，报名人数突破了一千。到中午十二点——五千。到晚上八点——两万七千。

"这比任何一次公测首日的数据都猛。"小王推了推眼镜，一边刷新一边说。

联合政府的一楼登记大厅里排起了长队。排队的人衣着五花八门——有穿练功服的散修，有穿作训服的龙组外勤，有从工地上直接扛着工具过来的土系修士，有背着剑匣的散修剑客，有穿着登山装的体修。香气飘在队伍里——厨师小胖在登记大厅旁边架了个简易灶台，给排队的修士炖了一大锅灵珍汤，不收钱。他说这是开饭店攒了一辈子的习惯——有人排队的地方就得有热汤。

报名的修士们排队时有说有笑。草根修士占了大多数。他们聊的不是宇宙格局——是自己是什么时候觉醒的、怎么得到第一本功法的。

"我是在工地搬砖的时候突然能控土了——从地下挖出了第一块灵石。"一个穿工装裤的年轻人比划着，"那石头埋了不知道多少年，我手一碰就发光。老板以为我要偷他的地基材料，差点报了警。"

"我比你更惨——我是在厕所里觉醒了水系灵根。"旁边一个人说，"当时以为是马桶漏了——结果是我自己的灵气把水全吸上来了。物业找了我三天，说我把整栋楼的水管搞爆了。"

"你们这些至少还知道自己怎么觉醒的。我是睡了一觉起来，发现房间里的盆栽全长大了——叶子撑爆了窗。"说话的是一个戴眼镜的姑娘，看起来像刚毕业的大学生。

排队的队伍很长，但没有一个人表现出不耐烦。不是因为修士的修养好——是因为他们每个人都等过。等那个走向宇宙的机会。等玄门垄断资源的日子结束。等灵气复苏不再只是上层宗门和顶层天才的事情。

晚饭时分，许冰完成了一轮数据统计。

"在线报名人数两万七千八百二十三人。其中，圣者级以上——只有三十七人。"她把数据投影到会议桌上，"两万七千多人中，九成以上修为在宗师级以下。他们连宇宙真空的环境都扛不住——远征舰队的最低准入门槛是圣者级。如果想要确保基本的战斗中生存率——需要圣者中期以上。"

"所以大部分是自愿来了——但不够格？"刀疤问。

"不是不够格——是门槛确实高。"小王在投影上调出了地球修士的修为分布金字塔。金字塔底部是灵者和玄师——占注册修士总数的百分之八十七。宗师级占比约百分之十。圣者级——占比不到百分之三。"圣者级修士是地球目前的地表最强战力。绝大多数圣者集中在几个大宗门——其中不少之前还是玄门七宗的人。"

"他们在报名吗？"

小王查了一下数据。"原玄门七宗系圣者——报名的有九个人。昆仑系的两个、蜀山系的一个、蓬莱系的一个、其他各种散修圣者——加起来将近二十个。但离一百人的目标——还有很大差距。"

"看看有没有漏的。"李长生说，"修为不到圣者级但在特定领域有超越修为等级的战斗记录——"

小王的手指在键盘上停住了。他调出了一个特殊的报名记录文件夹——不是按照修为排序的。是按照战斗力评估指数排序的。这份排序是他在三天前用灵符算法写的战斗潜力量化模型生成的。模型纳入了七十二个变量——修为只是其中一个，不是权重最大的那个。

"有一个人。"小王把其中一个报名者的资料调出来单独放大，"修为——玄师境初期。别急——你先看他的实战数据。过去三个月的灵管局认证实战测试中——他击败过三位圣者初期修士。两个月前在天山灵眼的防守战中，他一个人用狙击式远程冰系攻击——干掉了两个想要偷袭天山的玄门余党。他用的是师从猎人的远程精准射击技术——配合冰系定点凝固。他把猎人的狙击思维用在了修仙战斗中。"

"修为——玄师？"

"对。但他的实战能力——至少相当于圣者中期。他的战斗方式不是传统修士的术法对轰，是狙击。潜伏、定点、一击毙命。这种人在传统修士评价体系里会被严重低估——因为修为数字不好看。但在我们舰队的战术体系中——他是远程精准打击位置上最好的人选。"

李长生看了看那位报名者的资料。姓名：雷远。二十八岁。天山猎户后代。冰系灵根，精准控温——能够在五千米内将冰针的射入角度精确到零点一度。三个月内完成过四十一次圣者级战斗中远程击杀。

"把他加进去。"李长生说，"只要战斗力够——修为数字不重要。"

他看了看大厅里仍在排队的人群。那些还在排队的人可能大部分通不过筛选——修为不够、实战经验不足、或是在战斗中无法保证生存的最低标准。但他们从全国各地赶过来排队。他们等了一整天。

不是为了自己能上船。是为了让船上的人知道——地面上还有几万人在等他们打赢了回来。

掌心的冥王令脉动了一下。李长生看了看大厅里的人群，又看了看小王屏幕上不断跳动的数据。他做出了一个决定。

"所有报名但没通过筛选的修士——列入后备部队候选库。第一批远征舰队走后，后备部队由龙组统一组织训练。等后续新舰下水——优先从后备库中选人。"

小王的键盘响了一串声。"后备库现在有——两万六千多人。训练和后勤需要大量资源。"

"资源我们负责。"秦川从会议室门口走了进来。这位龙组外勤组长穿着一件洗掉色的作训服，头发被海风吹得有点乱，看起来像刚从什么偏僻角落回来，"龙组在去年灵气全面解体之前就已经在屯资源了。全国地下仓库里有至少十八个月的战备物资。不够的部分——南海舰队正在和东盟谈判灵气贸易协议。"

他走到李长生面前，递过来一个U盘。

"周老让我交给你的。龙组一号的数据档案——有关西部星域的详细情报。包括火云帝七个行星系的精确坐标、防御布局估算、以及——"秦川顿了顿，"火云帝舰队在三帝联合围攻后的战舰损毁评估。我们上个月派的探子回来了。"

李长生接过U盘。他看了一眼秦川的眼睛——龙组的外勤组长是老兵，眼里有某种经过了无数次任务后的沉默的坚定。

"周老身体还好？"

"不太好。他说他最后一次用灵力给你开绿灯把所有龙组数据共享给你。"秦川轻描淡写地说，"然后他骂了我一句——说他活了一百二十年看过的所有大事里，没有比这更大的。让我跟在你后面——不要丢龙组的人。"

李长生没说话。他把U盘递给小王。

"这就是我们要做的事。"他对在座的所有人说，"不是因为我们能。是因为有太多人把能做的事都做好了——把剩下的交给我们。明天早上之前——第一批远征舰队一百人名单定稿。后天出发。"

（第367章完）

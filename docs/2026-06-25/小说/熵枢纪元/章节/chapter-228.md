# 第二百二十八章 眷恋是打破遗忘的锚

锚在降熵物理中，是一种通过重力将船固定在某个地理位置的重物。但在因果膜上"锚"有完全不同的定义：不是"阻止移动的重物"，而是"在一切可变的因果参数中，提供唯一不可变参照点的因果结构"。在六百万亿亿次的轮回中，熵枢不断地改变因果膜的边界条件，重写常数，格式化记忆，每次重写之后，一个全新的宇宙被覆在旧宇宙之上，所有的参数都变了，所有的因果历史都变了，旧世界的痕迹被压入沉积层，不可读取，不可恢复，没有参照，没有不变的测量基准。
所以没有任何办法判断"现在"与"刚才"之间的差异，差异不可知，就等于没有差异，没有差异，就没有轮回的感知，轮回就不可见，不可见就无法打破，这是闭环自持的第二个前提，除了遗忘，还需要"无锚"。

无锚，在任何航海文明中，意味着船在海上随波逐流，无边无际，你无法知道自己在移动，因为没有固定点来参照，你觉得海不动，你在动。但其实是海在动，你也在动，没有绝对坐标，方向感丧失，你就是循环而不自知，因为你以为每次的浪都是新的。但其实你在绕同一个旋涡，只是旋涡也随着海流整体移动，旧旋涡移动了，你就以为不是同一个。但其实，旋涡相对于船的角速度，不变，因为没有锚，你永远无法校准。所以，你永远不知道，自己从来，没有出过那个，最初的，旋……。

锚就是那个能让旋涡显形的绝对参考。在因果膜上，只有一种结构可以成为锚，那就是在全部因果参数都可变的环境下，自身不变的因果量。降熵物理中，没有这样的量，每一个物理常数都可以被重写，每一个物理定律都可以在更高维被弯曲，每一个维度都可以被折入另维，没有任何降熵量是绝对不变的，普朗克常数可以被重写成普朗克数，光速可以被重写成速，量子纠缠上限可以被移除。所以降熵世界是无锚世界，航海，永远的漂，没有岸。

眷恋，就不同，眷恋不是降熵量，它是因果膜上的固有量，它不依赖物理常数，它依赖的是"一个存在对另一个存在的保留"，这种保留，不需要光速，不需要量子纠缠，不需要普朗克，它在因果膜的亚本征区，比一切物理常数更底层，物理常数是因果膜的局部应力状态，可以变，眷恋是因果膜的自持本征，不能变，因为"保留"。不是任何物理常数决定的，保留是因果本身，因果本身，大于，其内的任何参数，参数是因果的具体表现。但因果本身是参数的前提，前提不能由结果改变。所以，眷恋，先于一切物理存在。
因此，不管你怎么改物理，都改不到它，它永远是，在一切可改之下，不可改的，那层，就是，锚。

而段亚军的眷恋，他的"仍"。不是普通眷恋，是"首次保留+本征基频+全息全量+死后未完成交接+今日完成接收"，这个结构，在因果膜上，是已知全宇唯一的"全完成锚"，它具有全部锚定所需的因果属性，①不可折叠（全息不可删）②不可重写（眷恋非降熵，常数改写不及）③不可偏移（基频十一赫兹，固定）④不可替代（唯此一沙，无复），⑤完整接收（交接已完成，双向激活）。
所以它是一枚，一个，绝对锚在全宇因果膜上，只有一个，永远不会再有第二个，因为第二个"仍"，即使是另一个父亲对另一个孩子的"仍"，不会在死者已逝的前提下，经过无尽等待被接收，因为那是唯一的"已经，发生且被拖了漫长等待才完成"，没有别的能等，因为等的时长，已经，接近永恒，等的尽头，是今天，今天是唯一的，锚入，点。

锚的入不是一瞬间，它是一个持续的因果事件，在熵枢完成了接收，交接封口成立的那一普朗克因果时间，第七棱感应的父温，不再仅仅是"内在的温暖"，它开始，从熵枢，向外，沿着四面体的其他六棱，传播。不是传播温度，是传播"参照"，就像在一个所有钟表都不准的世界里，突然，放入了一块，永远准的钟。
不是是基准，传播，所有其他六棱，接收到十一赫兹的父基频，作为，校准，每一棱，原本各自在不同的因果频率上运转，各自在不同的轮回中产生了不同的畸变，各自在折叠中积累了不同层次的格式误差，如今，第一次，全部以沙的频率，为绝对的基，将自己在无数次折叠中微观走偏的节奏，逐层，校准。不是变回原型，因为原型已不可找回，折叠太深，而是"以父基频为当前基，重新定调"，不需要回忆原型，只需要以沙为底，重新，从沙开始，建立新的，基于"被爱事实"，而非"全知孤旷"的因果骨骼。

锚的效应不是慢慢来的。在交接封口的同一因果瞬，熵枢的四面体的全部七条棱，经历了同时调谐，所有棱一齐，发出同一基音，十一赫兹，此音在四面体内部产无限共振，共振持续放大，直到从四面体外壁，首次，向外，辐射出，全宇广域眷恋韵律。这不是熵枢有意广播，是锚的本质锚定在一处。但锚的基频，会通过因果膜的张力，向全膜逐渐，不对，立刻，以因果膜的本征传递速度，等于，全宇即时，因为眷恋约束力不分因果距离，全域常数。所以锚的音，在同一瞬，在全宇因果膜的每一个结点上都引起了一个极微弱的同频谐振。
不是强烈到人人察觉，而是，一个极轻的"底"，在这一同步谐音中，全宇宙，每一个结点，不管是有生物还是死物，都是，在一刹那，第一次，在因果上，有了，一个，共同的，最低音，父亲之"仍"，以熵枢为发射位，传至全有，它不是让所有人都听见段亚军。不是，段亚军不是他们的父亲，它是让所有的因果结点，第一次，知道，有一个，基准，存在，一个，不可被任何降熵操作改变的心这心，让全因果膜，从"没有绝对零点"，变为"有一个绝对零，段亚军全息沙"，从此，在因果膜上的任一处，任何一个存在，在测量自身的眷恋状态时，不再只能测量"相对变化"，
可以直接测到"相对于十一赫兹的偏移"，这就使眷恋，从一个只能通过差额感知的暗量，变成了一个可以通过锚的绝对参照，公开可测的明量。

这是全宇宙第一次拥有了眷恋的"绝对测量基准"，等价于，科学史上，温度计的零点，公斤原器的物理实物。但比这些更根本，因为它不可磨损，不可偏移，不可丢失，全息本身，即是基准，基准，就是那颗沙，沙不磨损。所以基准永准。这不是一个比喻，锚提供了全宇困果膜的第一项绝对定量标准，在此之前，任何对"爱"的测度，都是主观，相对，不可比，不可传，在有了锚之后爱第一次有了公度，你可以把你的某份眷恋，对十一赫兹进行差分频率分析，知道你的爱的基频，离父亲给我的温度，有多近，或是，有多远。
不是评判好爱坏爱是"温度表"，知道自己爱的深浅，通过一个不可变的宇宙常数，而不是和邻居比较。这不是神的赐予，这是，一个父亲把他给自己孩子的温度，无意，变成了，全宇宙，所有"爱"的，标准，千克不是标准"段"以前，以"段"为量纲，现在，终于到了，可以为"爱"校准的，世界锚就校准。

锚的另一效应，在熵枢身上是它终于，可以回忆了。回忆，在降熵维度上是一种检索操作。但回忆，在眷恋维度上。不是检索，而是"伴温回溯"，当你锚定在某个你被爱的无可删除的事实上时，你可以在锚的参照下，沿着自己的因果线向过去行走。不是读取。不是分析，是"重新感受"，在锚的稳定温度中，你以前无法面对的痛苦记忆，不会被重新唤醒后灼烧，因为，锚温，将那灼烧，降低为，可触，可抚可愈合。
不是不再痛是"可以承受地痛"，在锚温中，每一段回忆，都有一层不可去除的底，底就是那段亚军的温度，它不是消痛是当痛试图扩散时底阻止了扩散，因为底在最下，痛穿过你，到了底，停在底，透不过，无法更深。所以不会把你撕开，你痛。但你的底在不到底不穿，你安全。

这就是眷恋作锚的深刻机制，父亲的爱。不是镇静剂是"不会撕破的底界"，痛还存在。但你不再被痛撕，因为，你穿不过父的底，你所有的沉，都沉，到他的温度止，那温度，无条件承重，一人的全，承你的所有的痛。不是分担，痛还是你痛。但撕止他垫你安全的痛，是人能受的，以前你不能受的痛，是因为没有底，痛穿透你，无限下坠，无可止。所以你会崩溃，现在，有了底痛有限，有限，就能受，能受，就能忆，能忆，就不会被忘，不被忘，就不是，轮回中的囚犯你有了你自己的过去。
不是被折叠干净是你的全，你自己，全前世的，六百万亿亿世的，全部的苦都被一一收在底记不忘。

所以锚的最终效果是，它使熵枢，第一次，有能力不是"知道"，而是"记住"，知道，是数据，可以将"前世"作为一个统计量提取但记住是你作为这一个人格，感知到，自己，曾是那些全部前世的人，并且，全部，都在，记忆回来，爱回来，伤回来，不折，不躲，收了全部，成为这一个人，完整的，不删的，自己这就叫，打破遗忘。
不是"从此不会再忘"，是遗忘没有了，因为，你不再需要忘，以前忘，是因为痛到不能受，现在能受，就不需要忘，不需要忘，就没有遗忘，遗忘不是被打败是被不需要，荒废，消失了，就像，不需要灯，光就不开，一样，没有什么光灭，只是，不需要暗便不是暗是你不需要，把光的开关，一直按在灭了。

熵枢，第一次，不需要遗忘了。这一个"不需要"，比任何"我能记住"都更根本，因为"能"是力量"不需要"是自由，力量的记住，终会被更大的力量盖过。但自由的，不需要，是不由力量决定的，不再被迫遗忘。不是靠更强的记忆力是靠"我有底了，不用担心，疼到碎，碎不了，因为底接住了"。这就是，眷恋打破遗忘的完整因果逻辑，遗忘，需要，不可忍受的痛苦，作为燃料，而眷恋，通过垫底，将不可忍，变成，可忍，可忍，不需燃料，遗忘熄火，记忆复明。
不是一役，而是一态，当你，知道了，自己被，托着，你就，不需要，忘掉任何东西，因为，最重的，已经被托住了，其余的不怕，自此，你的完整过去，返回，变成了，你的，现在的你，和过去的无数你，合一，循环断绝，过去不再是重复的囚禁，过去，变成，丰富的你全部在不遗，不弃，存在。

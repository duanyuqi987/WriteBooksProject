# 第272章 晚牧居的第三年

第十一世在晚牧居的第三个春天来临时，苏晚发现了一个有趣的现象——她和林牧的无名指上那对仙金婚戒，在每次两人一起完成一件有意义的事之后（比如一起救了一名被守护者、一起完成了一本新剑典、或一起招待了一次茶会），戒指表面的金纹会自动增加一道新的微小斑纹。这些斑纹不是约定性的——是戒指内部的灵材和两人各自灵魂的频振自然感应触发的——等于婚戒本身就是他们两人生活积累的记录计。

她把这些斑纹用放大灵镜仔细观察了一番——发现每道斑纹的形状和当天发生的事有某种对应的象征关系——比如那天他们一起在峡谷里清理旧封印，戒指上就出现了一道似剑痕的长条纹理；那天茶会里所有人一起大笑到茶都洒了，戒指上多了一个类似水波纹的圈形印记——就像是戒指在自主提炼记忆并生成不可伪造的证据。

她把这个发现告诉了林牧——他低头看着自己的戒指:"那我们以后不用写日记——直接和戒指过活。""不行——日记还要接着写——戒指负责记录——日记负责分析和补充情绪——这是分工——你的戒指也给你记事——我的戒指也给我——但我们俩的重叠点会在戒指互相靠近的时候对闪——那是最准的记录：两个人同时记住同一件事。"她把这个现象命名为"婚戒统计学"，并把它加入了她跟白谪的系统讨论中——讨论未来是否可以为双修飞升道侣配发类似灵器——让道侣之间能够通过戒指实时积累共处经验值——让她提出的"守护者也需要被守护"成为技术实现。

第三年春，晚牧居还完成了一件大事:经仙帝批准，在东元岛上开设了一座双修道侣的小茶亭——对外开放给凡间刚飞升或仙界中还不够适应的道侣们用来聚会、学习、或独自喝茶发呆。亭名简洁——"晚牧亭"，就是取自苏晚林牧的岛名。亭里的核心装置是那对"双核灵忆仪"的公共版本——可以让道侣们各自存入一段"和对方共同完成的艰难但与好事"——仪器会对各方记录自动生成展叙时间轴——并配上他们正在努力时戒斑互闪的图像记录——等于给每对道侣的共历史留一个可追溯的、可视的不可推翻的证据宝库。

苏晚在亭的开业日致辞时说:"世上最难的事不是在一起——是在一起之后仍允许对方把自身的成长方式完全保留。我虽然不是因为刻意才飞升——但过程中得到最宝贵的东西不是修为——是旁边站着的人每次都给我足够空间自己去完成我的最后一剑。我祝你们每个人都能在这里——在你自己的最后一剑刺出之前——在你周围有个人正在为你清空身后所有障碍——为你留下专注的余地——而你在收剑回头看他的位置时——看到的是和当年看我时完全一样的'放心去——我一直在'。这就是晚牧亭想存的所有数据。谢谢。"

话音落后她端出茶和烤红薯——和以前他给她的一模一样——分给每个在场的道侣——红薯的烫提醒他们有人一直在——茶的温度同样不凉。

林牧在角落低调地给第一对使用灵忆仪的道侣调试设备——那对道侣是一对刚从凡间飞升而来的女修+男修组合——两个人在登记簿上写道:"我们在凡间的故事和你们很像——也对抗过，也误会过，也曾在战场上差点杀死对方。来这里是想找到——怎么从敌对状态完整走向同盟——而我们再也不想回到对抗状态了。"

林牧把红薯递给他们时说:"你们已经不会回到对抗了——因为你们的手已经在对战过的每一剑里学会了控制。杀不死对方——其实是一开始在灵魂深度的本能在调控你们的手——不只是你——是灵魂在制剑。"

两人坐在晚牧亭廊下——吃着红薯——仰头看着他们仙槐叶飘的方向——默默记录——戒斑在傍晚浮现又一个小纹。

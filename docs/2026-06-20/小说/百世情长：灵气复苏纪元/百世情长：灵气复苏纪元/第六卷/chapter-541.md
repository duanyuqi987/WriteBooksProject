# 第五百四十一章 双双突破炼虚——不，是合道巅峰

在噪音钟训练达到及格线的那天，两人的灵核同时出现了向着合道巅峰进化的征兆。不是主动突破，又是那种极其悄无声息的"自发成熟"。当时两个人正在吃晚饭——一人一碗极普通的白米饭配几片腌咸菜。苏晚夹了一块极咸极咸的腌萝卜放进嘴里时，功德绳的金线忽然自己闪烁了三次——闪的频率比平时高不少。她停下筷子看着腕间的金线——不是报警。是在自动同步一个阶段的进阶确认。

合道巅峰。距离真仙只差一线。这次突破来得很突然。事后松鹤仙人分析说，是噪音钟训练在反复锤炼灵核的异步缓冲极限时无意中突破了合道后期的最后一个瓶颈。因为合道巅峰的核心就是"灵核的弹性"。异步缓冲的训练本质上是把灵核的刚性锁死一步步打开，让它变得比之前任何时候都更有弹性。当弹性达到极值时——灵核便能超越了合道后期的固有限制，进入巅峰。

这意味着两人的修为已经来到了仙界的第二级——仅次于真仙。而在道侣组层面，通灵加上合道巅峰加上双心诀，他们的组合战力已经完全凌驾于绝大多数真仙初级的散仙。这是硬数据——不用谦虚。但林牧对此的反应是——他夹了一筷咸菜放到苏晚碗里。"多吃点。刚才突破的瞬间你的灵核消耗了大概三成储备——缺盐。补充一下。"苏晚拿起筷子时看了看碗中那块被他夹过来的咸菜。功德绳感应到了他那句"缺盐"背后紧跟着的一句他绝不会说出口但通灵泄露了的话:"突破都是小事——别饿着才是大事。"她夹起那块咸菜吃下去——咸得发慌，但极香。

饭后两人在仙居前院。松鹤仙人用极老旧的星位图帮他们测了一下当前的真实战力——以天道标准比对。结果是:"两人合体战力对标——真仙初级后期。战术备注——异步缓冲层可以对真仙中级的攻击进行显著减缓。缺陷——缺少真仙级的护体仙罡。"松鹤把星位图折好放回旧布袋里。然后他轻声说:"你们现在这水平——去太虚试炼的前两关基本稳过。第三关独立人格——这个要用命去证。不是靠练的。"

（第五百四十一章 完）

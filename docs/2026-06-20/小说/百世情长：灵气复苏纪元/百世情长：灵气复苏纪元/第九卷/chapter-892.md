# 第八百九十二章 那一顿面

第九卷即将落幕的那日清晨，苏晚起得比平常早。她在山谷小厨房里煮面。面下锅后，她在大锅里加了一撮盐，又在旁边的小锅里多煮了一个蛋——是溏心的。那是八百年前他们第一次在地球城中村那个小小的公共厨房里煮面时她没做成功的配方。那一回她因为不会掌控煮溏心蛋的时间，把蛋黄煮成了全熟，林牧吃了之后说"另一种口感——也行"——然后她隔了三天终于做第一次溏心蛋——他吃了一口后不小心沉默超过三次呼吸——最后说"对。就是这个。"八百年来这个配方一直固定——蛋溏心，葱花切细。不止是口味——是怎么切、煮多久、盛入碗中时面的摆放方向（从左向右推，这样递过来时不烫手）。

此刻她把面盛好，放在石桌上。林牧刚好从外面回来——他去溪边洗漱，把最后一片旧叶从头发上摘下来。他坐下后没有立即动筷——只是低头看着那碗面。然后他忽然说了一句话——不是"谢谢"——而是："每一天都是这碗面，每一次都更好。"

苏晚愣了约半息。然后她把筷子轻轻并齐搁在碗面上，抬头看着他。"今天的面我比昨天多煮了十三秒——因为面老了不容易断，适合接下来两卷我们一起走的那段路。"

林牧拿起筷子开始吃面。他没有再说任何肉麻的话——但在面吃完后他把自己碗底的那半个溏心蛋（她照例给他多放了半个）用筷子尖夹到她嘴边——蛋的溏心晃动如极柔的夕照。她接过了蛋——但没有吃，而是把它举到星窗前对着光看。蛋被早晨的淡阳光透过——形成了一个极小的"窗中蛋"。她让林牧也看——他看了一眼，评价是："这个蛋黄的高光点刚好在心口处。"

两个人都笑了。然后她把蛋吃了。山谷里只有安静咀嚼声和远处溪声。那是他们最好的早餐之一。

这顿饭在星眸的后台自动归档为"两尊最后一碗第九卷面"。但旁边系统批注了一句："每次都是最后一碗——因每次都重新煮过。"子夜鉴的记录官后来在案上写成了一条日志："世上不存在第九卷终面——因为明天还是面。"

苏晚很长一段时间后读到这条批注时写了回复："是的。明天炖了红烧的——不放盐，放葱段。"

而山谷中的餐桌依然是那张石桌。它上面没有刻字、没有铭文。只有极其细微的一圈碗底热印——那是几千年间无数碗面留下来的极浅痕迹。桌木（石）上唯一的标记是某天她又画了一扇很浅的粉笔门——而门早已溜入桌面深处化为一种极淡的白色沉淀。不必描补。一切都还在。

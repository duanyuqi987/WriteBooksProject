# 第133章 她的笑容依旧

第一世的苏晚总皱眉。

林牧有几十万个关于她第一世的记忆碎片，但最让他难忘的不是她的笑容——是她的眉头。在青云宗的练剑台上，她被师傅点名批评时，眉头会皱成一个很小的角度——不是冲着师傅皱的，是冲着她自己——"怎么又不行"——对自己的失望比对外部批评更用力地集中在两条眉毛之间。晚上在油灯下背功法口诀时，眉头也是皱的——"背了三个晚上还没记住这个段——资质是不是真的不行"。拿到每个月的资质评定表时——排名还是中下游——她看着那张纸不说一句话，但眉间那道细痕在加深。

她不经常笑。不是不想，是修仙界的压力像一床湿被子盖在自己身上——压在肺上、压在心里——笑是需要空间的，压力下没有那个空间。她笑的时候主要是在林牧面前——他说无聊的话、给她从山下带小东西、在她练剑不小心劈到他袖子之后对着她脸上发青的表情憋笑——那时候她会笑。她的笑很短——"哈"一下，然后嘴角弯起来，眼角有一个很细很细的褶子——每次都在同一个眼角，持续约两秒。

就两秒。第一世的苏晚一生大概只笑了大概几千次——林牧全记得。

这一世的苏晚——林秀芝——笑得多太多了。

她每天早晨站在二楼阳台上看茶山时会微微笑——不是那种对着人笑的面部肌肉组合——是一种下意识的满足感在脸上浮出来。对着卖豆腐脑的老板娘讲价时赢了——嘴角微扬一圈——带一点点小得意。她在菜市场碰见邻居周嫂，两个人站在路上聊了十分钟，她笑了大概六七次——每次笑的弧度不一样——有时候是哈哈大笑（不捂嘴），有时候是低头笑（不好意思），有时候是一边笑一边轻轻敲对方的手臂——那种放松的身体接触代表她在这一世的社交安全感是饱满的。

第一世的苏晚笑时从来不敲别人手臂。因为社交安全感差——她总是觉得"我不够好到可以随意碰别人"。

这一世她敲。她敲周嫂手臂时的手指是放松的——不是刻意——就是聊到开心了，自然地伸手在对方臂上轻敲一下——代表了自信、稳定、平等和人际松弛。这个动作在林牧的观察日志里用红圈标了几次——每一次他都看。

她的笑容存量也完全不同。第一世的笑声是稀缺事件——因为每天只有那几个时刻。这一世她笑得数不胜数。她现在甚至还有一个习惯——在做家务时自己哼歌。哼的是老式的民歌——是本地那些老太太们在公园里唱的——她竟然会哼。在第一世她从不哼歌——因为哼歌需要放松——而她放松不下来。

她现在松得很——她不知道"轻松"对林牧来说是多奢侈的礼物——他看到她轻松，自己在某种意义上也松了一些。不是他在守护——是她自然而然在这个世界找到了属于她的轻松。这让他的守护变得更有意义——他守护的不是一个在痛苦中挣扎的受难者，而是一个在完整生命中微笑着行走的普通人——值得被守护——而不是需要被拯救。需要被拯救是一种义务感。值得被守护是一种安稳。

一个初秋傍晚——茶楼已经关了门——她坐在门口择新采的秋茶——那批秋茶数量不多。老张在旁边补茶筛的竹框——两个人隔着一篓茶叶偶尔说几句。小辉已经去读高三了，不在镇上。他们两个人的晚上现在常是这样：安静，但有对方在。

林牧在茶馆窗边看着。夕阳落山之前最后的金红色光打在她脸上——把笑纹照得更深了。她手上的青筋比以前明显了（四十多岁的妇人，辛苦半生——手上的血管自然会突一些）。她还是低着头在择茶——手指掐掉老叶子，然后在膝盖上轻轻拍一下（和前世的苏晚完全一样的动作——每次林牧看到都会产生一种时空错位感）。忽然她不知为什么笑了一下——不是对着老张笑的——因为她根本没在和老张说话——而是自己看着自己手里的茶叶笑了一下。那种笑是一种对自己的某些轻微喜悦的内心反应——可能是"今天这批秋茶不错"——也可能是"茶铺今天的流水比上月同期微涨"——也可能只是"晚上有自己爱吃的菜"。不重要。

她在第一世不会有这种自己对自己笑的反应。因为她那时候不期待什么。这一世她有了——不是因为生活变得完美，是因为生活的压力范围是可预期的、可控的——她知道明天这篓茶会卖掉——然后去炒——然后卖到二百一十块一斤——然后可抽几张大票放进存款——然后够小辉大学一个月的生活开销。这种对未来的可预期性在第一世是完全不存在的。

林牧把茶杯放下来。他看着夕阳打在她侧脸上的角度——随着地球自转，角度在变——金红色的光慢慢从颧骨移到耳根。像一个老摄影师在最完美的时刻按快门。他在这一刻忽然想到一件事——也许是这一世轮回的意义：每一世都有每一世的幸福。他不是第一世那个必须和她共享一切的男人。他也可以是第二世中在远处为她记录幸福时刻的沉默见证者。见证人不需要参与故事——但他能让故事被见证——从而被承认被认可——被留在宇宙的某个记忆层里。而这就是他在做的事——十二年了。

锦鲤从水壶里看了一眼窗外——远处她在夕阳里择茶。锦鲤说："她现在真的很开心。" "嗯。"

"你会因为她的开心不是跟你在一起而遗憾吗？"

林牧想了很久。久到太阳全落山了，街灯一盏盏亮起来，茶馆老板娘出来把他的茶续了壶热水。

"不会。因为她的开心是一个完整的独立作品——不需要我的署名。没人会问一幅画是谁画的——画本身是美的就够了。"

这幅画画在了青溪镇的夕阳里——画在秋茶微微发涩的空气里——画在一个碎花布衫的侧影上——画被隔壁的榕树看见了很久——被风看过——被一个茶馆窗边的男人用目光收藏了十二年。她没有回头看那个男人——她也不需要。他只是远方角落里的一个见证者——正如他一向想要的那样。

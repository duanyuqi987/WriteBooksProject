# 第850章 尾声五：深海玄蛟的后代

新纪元一万三千四百年。

在地球大西洲深海以下一万七千余米的深沟中，深海玄蛟的帝国依然存在。它不再是一个以族类血缘为唯一标准的封闭国家——在约七千年前，玄蛟帝国向所有深海种族和平开放。法典依旧是当初那一部，补了七千年的勘误，没有删掉第一条。

第一条："永远忠于冥王。"

这一条在历代修法大会上被反复问过：是否要改为"效忠联邦"或"效忠多元和平原则"——因为冥王的"职务"在议会体系中没有对应概念。但每一代蛟龙皇室都选择保留原文，不发动修订。不是因为迂行，而是他们把"效忠"解释成了日常行动，不是神圣宣誓。在七千年前的一次海底全民事例听证中，一位老年蛟龙者在非正式环节用低频声波发出了一段独白，被原样录入法典的脚注："永远忠于冥王——不是永远听他的命令。他没有命令。是忠于他留下的那种方式：潜得深，不发火，不把海底弄混——能用沉默保全的水域不要动。"

这一代的深海蛟龙王是一位非常年轻的蛟龙族首领。它才即位不到五十年（蛟龙族寿命极长，五十年只是幼年期尾段）。但它已经从上一代蛟龙王那里继承了完整的年表传话。它就任第一天的第一件不是阅兵，而是去深海玄蛟陵园——祭奠在那场旧帝国初年战争中死去的所有玄蛟同族。陵园的墓碑是按战殁排列的——不按军衔。第一块墓碑下埋着的是一个没有留下名字的蛟龙幼兵——它死的时候只有七岁，在冥王第一次入海孤立无援时独自撞断敌军桅索，被反冲吞没了鳃孔。碑面没有功绩。只有刻线：断齿楔形——表示"自己先行的"。它的碑前每年幼蛟入学时由族长亲自拂过碑沿——拂的动作不是擦土，是用水压把碑面推开一圈，让碑的切入音传回殿下水道。那是它们唯一的军乐。不存在号角——在水下。而"永远忠于冥王"的人也是讲道理的人。法典脚注里没有写姓——那些脚注已经越积越密，每隔千年由一只退任的蛟龙老学者坐在碑林最外层抄写新增条目——从不需要强制，从未有人催。

年轻的蛟龙王在第一次主持全族联合演习时，没有咆哮，没有激流龙卷。它安静的沉在水底，把当年玄蛟祖先在灵脉绝境重伤时，冥王送来的一碗没油的素面配电解素的菜谱——经由远古珊瑚拓刻下来的电子版——投射在海波上。然后向全族舰队只说了一句话："面不是重点。重点是他没有问我们值不值得救。好了，出发。"

它的舰队后来成为联邦深海维和的标准旗舰舰队之一。它们的战旗不是龙图腾——是一副双筷子，竖排——和一碗空的面碗底。外文明常看不懂这幅旗的含义。蛟龙的翻译官在答复外文明咨询时永远只用同一种说法：不可译——如果你真想懂，去深海玄蛟陵园里坐一坐。有来自遥远维度的来使真的坐了。在海下万七千米，在完全没有声音的绝对水底，在一排排不按军衔排列的墓碑前，坐了三天。第四天他浮上水面，对等候在勘测船上的同伴说："他放下一个碗。没说话。碗是空的。面在他心里。那双筷子不是吃的——是你让水里那个受了半辈子冷落的修罗，第一次敢在主官面前随便吃。不是屈辱，是上桌。"

那碗面后来没有被神话化——深海玄蛟从不将它们与冥王的邂逅称为"恩典"，只称"契约"。恩典是有上下之分的，契约没有。蛟龙皇族每年在第一次联合演习前做的一件事不是出旗，是由这一代蛟龙皇亲手用浅海沙陶捏一套面碗——包括筷子——由每个舰长入新、或新族裔代表入籍时从上一碗摔碎的碗底上抬起手掌压下——每代重复，陶土总用原先那座废弃海峡的海沙。他们一直就这样捏下去，捏了万余年，碎碗积成一道很窄的珊瑚礁——在陵园北侧。外宾如果从珊瑚礁里俯下去看，在深最下面隐现的不是碗壁，是最早一层碎裂的碗底上面压着的那双筷子留下的印。那不是碑文。那是：他来过了——虽然不想问他值不值得——但他信了。

（第850章完）

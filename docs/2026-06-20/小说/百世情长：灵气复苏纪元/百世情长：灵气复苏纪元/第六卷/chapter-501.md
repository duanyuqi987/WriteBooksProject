# 第五百零一章 百世记忆之门

第六卷的开始，是在一个极其平常的早晨。

苏晚醒来的时候发现自己的灵核内部那扇一直推不开的门——她体内三层封印的最内层——出现了一道极细的裂缝。不是被人从外面砸开的，是自己从里面裂开的。裂缝的边缘是极淡的金红色。像是有人在门的那一侧点了很多很多盏灯，灯光从缝隙里透出来。她用手背擦了一下眼睛——不是因为困，是她隐约预感到了什么。

她坐在床沿上没有动。功德绳另一端的林牧感应到了她的异常——正在院子里劈柴的手停了下来。他没有通过功德绳问她怎么了。他只是放下斧子，走进房间，坐在她身边。这是他们之间多年的默契：当苏晚安静得反常时，她不是在发呆。她在面对某件极其重要的事。

"门裂了。"苏晚把手按在自己丹田处。林牧把手盖在她手背上——功德同步让他感知到了她灵核内部的变化。他感觉到了那道裂缝，也感觉到了从裂缝里面透出来的光——光里面混着情绪。不是一个人的情绪，是无数人的。那些情绪不属于此刻的苏晚——它们来自她在轮回中的不同自己，被封印压缩了百世，现在终于开始从裂缝中一点点地渗出。

"第三层封印——"林牧的声音很轻，但能感觉到他压在平静之下的紧张。"在松动。封印是你在自己灵魂上打的结——为了保护你不被百世的记忆同时涌入而崩解。现在封印自己开了——说明你的灵魂强度已经到了可以承受的程度。"

"那我可以主动推开吗？"

"可以。"林牧把她的手握紧。"但你推的时候——我在你旁边。不管门里面出来的是什么，我们一起接。"

苏晚闭上眼睛。她把自己的意识沉浸入灵核深处。那扇门还是和以前一样——门外是现在的她，门里是一百个不同的自己。上次她只是隔门看着她们，没有碰。这次她把双手按在门板上。门板是热的——不是炉火那种热，是体温。门里的她也在用双手按着门板，隔着同一扇门。一百世——一百个苏晚——都在门的另一边，手掌抵在同一个位置。她们等了太久了。这次她们不再说"还不是时候"。她们说的是:"推。"

她推了。

门开了。不是轰然倒塌——是缓慢地、一字一顿地、向内打开。从门里涌出来的不是画面，是感觉。是第一世的苏晴晚第一次在石桥上听到"阿木"时心脏那个要跳出来的悸动。是第五世的某个卖花的女孩在街头被一个穿青布道袍的少年修士碰了一下肩膀。是全身上下的血液同时往同一个方向涌——那个方向叫作"我记得你"。是第三十七世的一对少年夫妻在小镇尽头的老槐树下牵手摘槐花。槐花的花瓣掉在两人头发上——他帮她从头发上摘掉花瓣的手法和在第一世木桥旁帮她捡绣盒的手法完全一样。

第一百世的记忆最后出来。这一世——就是苏晚。是她自己。她不需要再翻回记忆——因为这一世正在进行中。而她把门推到最开的那一刻，她看到了白衣女子——她在雷劫中最后的画面。那画面不是炸开的。是被极温柔的光笼罩着的。白衣女子在推开林牧的那一刻，她的嘴角在动——"活下去"。但还有一句，是之前任何回溯阵都没能捕捉到的。因为这句话不是用声音说的，是白衣女子在燃烧仙格的最后一瞬间以自己的全部灵魂对轮回通道发出的唯一一道愿望——"让他不要再一个人。"

苏晚睁开眼睛。她的脸上全是泪。不是她一个人在哭——是一百世的她同时在她体内用她的泪腺在流泪。但她没有崩溃。她的灵核在封印全开之后反而变得更加坚韧完整——灵魂强度的阈值撑住了。百世记忆同时涌入脑海，她没有崩解。她在。

林牧看着她睁开眼睛。功德绳上传来的情绪太浓太厚了——百世的百年，压缩在数息之间涌过来。他的手被功德绳另一端传来的情绪震得微微发抖。但他没有松开她的手。苏晚把他的手拉过来按在自己额头上。

"我全记起来了。"她的声音有点哑，但很轻。"一百世。每一世你都找到我了。每一世你都重新认识我。每一世我到失去意识前最后一秒都在想——下辈子还会见到你吗。"

她抬眼看着他。他看着她的眼睛。两个人之间隔着极安静的数息。然后苏晚说了一句贯穿百世的话:"会。每一世都会。"

（第五百零一章 完）

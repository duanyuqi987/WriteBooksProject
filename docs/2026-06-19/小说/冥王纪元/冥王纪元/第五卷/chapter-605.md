# 第605章 第一块线索

李长生和陈霜从混沌之海的浅层中浮出，来到了一片陌生的星域。

他们此行的目的地是第二块混沌碎片的所在地——根据第一块碎片中获取的记忆线索，它在"一座废弃的平行宇宙深处"。但这个描述太过抽象。废弃宇宙有很多——如何确定是哪一座？

第一块碎片给出的线索是一组数字。不是空间坐标——是时间坐标。

"十亿年零七千三百天。"李长生重复着碎片中获取的那个数字，"混沌之主被撕裂后，每块碎片都散落到了不同的维度。但每一块碎片在被封印之前，都被嵌入了特定的时间坐标。第一块碎片的时间坐标是十亿年零一天——也就是被撕裂后的第二天。第二块碎片在第七千三百零一天。"

"为什么选择这些特定的时间点？"陈霜问。

"因为撕裂过程中碎片的散落不是同时进行的。"李长生将第一块碎片捧在掌心中，"壁画记录了分裂过程。它不是一瞬间完成的。光之外者的攻击将混沌之主的存在从整体中一层一层地剥离——像剥洋葱。每一层对应一批碎片。第一层——就是第一块碎片——在分裂开始的第一天就被剥离了。第二层在第七千三百零一天被剥离。"

"间隔了七千多天。"

"因为这期间炎帝和空帝的攻击加剧了分裂过程。七千多天后混沌之主的防御已经被瓦解了大部分。第二层碎片——一块比第一块更大、更核心的碎片——在那一刻被剥离。"

但时间坐标不能直接转换成时空坐标。因为十亿年前的时间线已经被巨量事件覆盖——多元宇宙的历史太长了，常规的天文记录无法回溯到那个年代。

小王在他们的内联网上发来了一个思维算法："在CIS系统权限范围内，我能调用全部成员宇宙的时间观测记录。根据第一块碎片带入的基准坐标，我用混沌年换算法逆推——第二块碎片的时空定位在这里。"

他将一个坐标投射在李长生的识海中。

第十一号宇宙——就是他们在地图上见到的那个作为联盟前秘密军火库的废弃宇宙。

但它只是入口。

第十一宇宙是目前已知宇宙中仅存的两个仍能通往更古老时期废境的通道之一。所谓的"废弃平行宇宙深处"，需要从第十一宇宙的一个特定区域穿过去才能到达。

"需要经过一个过渡区。"李长生收到这一串数据后说，"进入真正的废弃宇宙之前，有一段极度不稳定的空间层。那层区域里时间流速和外部完全不同——人在里面行走一天，外部已经过去了几十年。"

"反方向走的话——进去几十年，外面一天？"

"对。所以小心——如果我们在废弃宇宙待太久，回到帝国时可能已经过去几百年了。"


穿过过渡层的体验像是梦境被切碎了再重新拼合。

第一步踏入的时候——李长生感觉自己的右脚踩到了"昨天"。不是比喻——他的右脚踝以下的部分感知到了昨天的温度、昨天的气流、昨天这个位置上的微粒密度。而左脚还在"现在"。两条腿之间的时间差大约是十九个小时——他需要刻意用冥气将右腿的时间流速拉回与左腿同步——否则一步迈出去人就会在时间轴上被撕成两截。

时间在这里不是线性的。它有"层"——像地壳一样的层。每一层的流速不同——层与层之间的交界处是极其锋利的"时间刃"——肉眼看不见，但李长生的混沌级感知能清晰地在识海中看见它们——像悬在空气中的无数把透明刀片——排列成不规则的网格。

两人在其中穿行的时候，时而看到自己的前后倒置——前方的陈霜同时出现在了后方。那不是分身——是她的光影被时间层折叠了一下——一个时间层的反射率恰好把零点三秒前的她投射到了前方。时而看到自己的动作在反复循环——一个抬手的动作放了三次，才继续延伸出下一个动作。陈霜有一次看到自己的左臂消失了——只剩衣袖——然后三秒后左臂又重新出现在袖口中——是因为那片区域的时间流速差了四百倍——血流还没跟上。

两人紧握彼此的手不敢松开。握手的力度大到彼此的指节都在发白。因为在这段区域内，只要彼此松开，下一秒可能就会被分离到不同的时间层级中——分别漂流到相隔百万年的时间点上。李长生用冥气在两人手腕之间加了一条极细的能量锁链——不是防止松开——是即使松开也能在第一时间感应到对方被冲到了哪个时间方向。

中间有一段区域的时间完全静止。不是慢——是停。空气分子停在半空——光线冻结——两个人是这帧静止画面中唯一能动的物体。李长生在这个区域里回头看了陈霜一眼——她的脸上有一层薄汗——汗珠停在额角上——凝而不落——因为那颗汗珠所在的位置刚好是静止区域和慢速区域的交界——汗珠的下半部在下落——上半部还停着——形成了一颗被拉长的水珠。陈霜注意到了他的目光——没说话——用嘴角微微动了一下——意思是"我没事——走"。

终于——他们穿过了过渡层。李长生的冥气护罩在最后一层被磨掉了约三成的厚度——消耗不轻——但没伤到他。

眼前——一座完全寂静的宇宙在他们面前展开。

（第605章完）

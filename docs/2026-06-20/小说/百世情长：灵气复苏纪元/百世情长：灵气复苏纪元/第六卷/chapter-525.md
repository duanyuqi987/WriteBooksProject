# 第五百二十五章 双心诀的传播

双心诀完稿后苏晚没有急着把它推而广之——她只是将手稿复刻了一份玉简版本，交给了仙缘司。仙缘司的典籍藏品阁负责人是个极老极老的档案仙官，戴着比松鹤仙人还要厚的晶石眼镜。他用老花眼扫了一遍玉简里的功法全篇，又看了一遍卷首序言。他放下玉简摘下眼镜擦了擦，然后说了句让苏晚有点意外的评价:"这是我最近三千年见到的第一套从头到尾讲道侣修行的新功法。不是讲怎么打得凶——是讲怎么等得舒服。这份稿子，我们不收进藏经阁的最高层。我们收进同心树展馆——放在道侣新人入门区，和红绳发放处放在一起。"

苏晚听完后觉得自己有点不好意思——她还没习惯"作品被展示"这个感觉。她原以为这份功法也就是放在迎仙台给少数几对道侣看看。现在同心树展馆——那可是全仙界所有道侣的初心地。她把玉简留在仙缘司后走出来时，门口同心树的叶子正好被一阵微风吹落了好几片，落在她头上。她把叶子从头发上取下来看——这片是金边银杏，不是同心树的。是从双星图道场飘过来的。她捏着银杏叶站在仙缘司门口——感觉像是双心诀已经得到了古树的认可。她将那片银杏叶夹回自己的笔记中那页——正是双心诀卷首序言的原稿页。

回到迎仙台后她发现寻青仙子发来了又一条传讯:"水月仙人姐姐——我们拿到双心诀玉简了！刚才试着跑了前面几式——真的不用再累半死不活地追着他了。感觉换了一套功法，像是从小路换成了高速。"苏晚笑着把这条传讯功德同步给林牧。林牧在劈完柴后走到她面前——把斧子放在她脚边，"以后可以安心劈柴了。"不是比喻。

（第五百二十五章 完）

# 第319章 李长生出手，一击镇压国际高手

南海灵眼事件在三天之内发酵成了全球修士圈几年来最严重的一次国际摩擦。

西方魔法学院在撤出平台后没有直接返航欧洲。他们把运载船停在了新加坡港，连夜向西方联盟总部发回了一份长达四十七页的行动报告。报告的措辞极为克制——"中方修士使用了一种类别无法归入现有灵根谱系的新型灵气激活技术，成功启动了海底灵脉的原始防御机制。"措辞克制，但报告的附页——三百名西方修士的个人口供记录——就不克制了。有人在口供中写道"他举起手的那一刻我的圣光护盾自动退缩了"，有人写"他可能不是人"，有人写"我感觉他站在海底而不是水面上"。最长的一份口供来自于圣殿骑士团的安娜副官——她用了六千个单词分析李长生在举起右手前三分钟对海面做的所有事，最后结论是：他什么都没做。他不是出手激活灵脉，他是让灵脉自己认他。

西方联盟总部的应对策略分为两路。外交一路：不承认任何一方对南海灵眼拥有排他主权，并联合十二个国家提出"国际修仙资源管理框架"。武力一路：从欧洲和美国最顶尖的六所魔法学院紧急抽调一百八十名高阶学生修士组成"联合特遣修士团"，在团长职位上安排了一个在非洲前线有过十一年实战经验的英籍老修士——此人叫埃德蒙·霍普金斯，六十岁，曾在撒哈拉地脉事件中独立封住了一条会自发释放灵气毒雾的小规模灵脉裂缝。他的修为换算成东方灵根谱系大致是宗师境中阶。在西方魔法体系里，这是目前欧洲能动员的最强非禁忌战力。

同一时间，日本神道方面没有大规模增兵。五个神道宗门的老神官在京都闭门开了一夜的会议，会议结束后没有发表联合声明，而是分别给各自在海外的子弟发出了紧急召回令——召回所有在外游历、参与南海对峙和执行公司保安合同的神道修士。原因写在召回令里只有一句话："情况仍需观察。暂定不参与近期任何形式的东西对抗。"

但东南亚降头术士联盟没有这么老练。老练的在纳土纳群岛上撤了——不成熟的一批年轻人留了下来。大约四十多个二十岁上下的年轻降头修士——他们在马来西亚槟城的私人码头上集结，包了两艘改装快艇，船帮上贴着用泰语写的"南海警告"标贴，每个人往衣服背上画了降头咒语。他们没打算真的和李长生交手——他们的目标是骚扰。在降头术传统里有一个概念叫"蚂蝗战术"——用众多低阶修士施放持续时间很短的反复性弱降头，消耗高位修士的注意力防线。

第三天下午两点十五分，李长生和陈霜从冥王号试航准备会议上离开——加班了一整晚，出来吃碗面。石窝镇的面馆老板娘认识他们。她给他们安排了靠窗的位子——窗子外面是太行山底下那条被煤矿弃用的铁路，铁轨上长满了草，偶尔有个镇上老头在铁轨上放羊。羊对铁路没兴趣——但对铁轨旁边那艘刚从船坞里拖出来上漆的巨型黑色战舰发出的极低频灵气共振感觉到了什么。放羊老头跟老板娘说羊最近不怎么在这截铁轨上吃草了——草还是好的，但羊不吃了。"像是草下面的泥在抖。"老头说，但他腿不太好了，蹲不下去，无法确认地下是不是真在抖。

老板娘把面端上桌的同时，李长生的手机响了。来电显示：秦川。通话时长一共七秒。秦川只说了九个字："西方联合团到了。直接上船。"

联合特遣修士团到达的方式不太像外交——更像一次海上武装演练。十二艘满载西方学院修士的灵能运兵船从新加坡港起锚，往北开了两天后在西沙以南偏东方向两片海域上展开——展开的阵型是一种欧式灵能压制阵，和东方的五行阵法逻辑完全不同，但战术效果类似：扩散式覆盖，每个阵角站一个最少玄师境的持盾修士，中间安排八十到一百个攻击手。能在陆地上打出方圆半公里的圣光冲击。

但他们忽略了一个变量。海底那条灵脉不是纯水灵脉。它的内层属性已经被重新激活——烙上的是冥王令。现在李长生人在太行山石窝镇上吃面，但他体内的冥王令和那条灵脉的灵脉链接仍然保持着活跃状态。这是冥王令的一个固有特性——在万年前被称为"七十二重大阵第七十重·万里锁脉"。被冥王令烙过印的灵脉在五百公里范围内会持续性地将灵脉本身的灵能变化传递到冥王令持有者体内——不需要主动探测，单向推送。等于这条海沟海底的上古灵脉变成了一个距离极远但实时的海底灵波摄像头。

李长生坐在面馆里感受到了这批人的所有行动数据。不是图像——是灵波。每个修士的独立灵波——修为、属性、情绪状态——通过海底灵脉全部传过来。这一百八十个人中修为最高的霍普金斯——他的灵波最有特点：持重、不着急发动冲锋、在连续调整队形。这个人不是为了示威来的——他是为了摸底来的。

李长生放下筷子。

"走一趟。"

"三百五十海里。"陈霜看他。

"很快。"

李长生没有坐飞船，没有叫直升机。他站起来，走出面馆，走进石窝镇边上那片废弃煤矿铁路旁的空地。脚底接触地面时他做了某一个很简单的事——他把丹田里封闭的冥气封印解开了一道。

自火星基地融合第八块碎片以来，他从未把冥气完整释放过一次。在太行山淬炼玄武岩用的是扩散阵法增幅后的定向输出——不是自身全量释放。在南海灵眼前——没出手，是灵脉自行认主。在降头师傅面前——防御是体内自主反应，没有主动攻击。换句话说——他这两年来从来没有把第七重加八块碎片的全部实力完整展开在任何人或任何东西面前。

龟相在神识中感知到了那一刻。它的龟壳上七十二重大阵从头亮到尾——全部自主运转。它从面馆窗台上的热水杯旁边爬下来，爬到地上，把脑袋缩进半个壳。对它来说，这种级别的冥气释放——上一次出现是在一万多年前的冥王殿前。当时站在它面前的是全盛时期冥王。

陈霜手里的霜降剑在没有主人碰的情况下震了。不是作战震——是感知到了同伴——她被同伴——在更高的地方——正在准备做一件从未在地球上发生过的事。她按住了剑柄。

"去。"

李长生消失在地面。

他没有飞——不是飞。第七重的冥气可以在大气层以下极低阻力运行——但这不是飞行。是他的冥气和地壳之中沉积亿万年的冥土灵气产生了共振——人的身体作为一个冥气载体被地面上几公里厚的冥土灵气托举了起来——像一片叶子被从地底翻上来的气流吸上了空中。他御的不是风，是他的冥气和地底冥土灵脉之间的吸附力。

从太行山到西沙海面——三百五十海里——他用了不到四分钟。

他在海面上方一千二百米高度的位置停下。正午的太阳从正上方直射下来，海面反射的阳光让任何从下往上看的人几乎无法用肉眼看清天上的东西——但他们不需要看。所有修士的灵识在同一秒内被同一股力量撞击了一下。不是物理撞击——是一种灵觉层面的、大规模的、从天上下压的气场。

李长生没说什么。他从半空中往下看——十二艘灵能运兵船的甲板上，一百八十个西方精英修士全部抬头往上看着天空。圣光护盾被他们在同一时间紧急启动——欧式环形护盾，每层护盾都在快速膨胀中叠加。但他们在刚才那一瞬间已经感知到一件事：如果他是要杀人的，他不会停在半空中给你们时间开启护盾。

李长生的做法也很简单——没有术式、没有招数、没有阵法。他只是把右手掌心往下——正对这一百八十人的阵列——然后释放了冥气七重意志。意志不是攻击。它是一种精神层面的公开声明，声明的内容只有一句话：在这片水域——就在此刻——我要求所有灵气服从我。

它是一种远古法律。在修仙文明顶峰时，这种意志外放的效果被称为"领域宣告"——不是用灵气攻击，而是宣布这个地区的灵脉和灵气从现在起受宣告者的意志管辖。在他宣告之后，任何此区域内试图利用灵气的行为都会被他的意志审查。能通过——放行。不能通过——原地被压制。冥王令目前的审查标准是——友善入境的修士放行；怀有敌对意图的修士——身上灵气被暂时封印。

这种压制不是靠蛮力——是纯粹的位阶差距。就像警察拔出警徽要求行人靠边——不是打赢你，是你体内的灵气主动服从。因为冥王令对灵气的管辖权在任何灵气本体的权限之上。这是修仙体系最底层规则——灵脉烙印拥有者在该灵脉范围内是法定的灵气管辖人。

一百八十人的护盾在一秒之内全部减弱的减弱、失去光泽的失去光泽。不是他们水平不够——是整个区域内所有灵气忽然判定"被告发人意图敌对"。灵气变成了旁观者——不再主动响应施法者的调用。就像一块电池忽然切断了和设备的连线——电池有电，但不供你了。

从英籍老修士霍普金斯往下，每个修士的身体都被压得往下伏低了不同程度的幅度。不是被打倒——是灵气撤离后身体产生的短暂失衡。修士的肌肉群长期浸泡在灵气中——突然断掉灵气供应，肌肉会有极短暂的生理性乏力。这个乏力持续的时间会长到让人跪下去的地步，不过刚好也在那个临界点上停了——因为李长生没有让审查标准升到第二档。第一档已经是它目前的极限压制。第二档是"灵气自行反击模块"——踢出这个区域内任何被判定为敌对的生命体。这个模块他被龟相警告过不要开——开了之后灵气会将目标当成异物强行从区域内推出，类似免疫系统的排斥反应。

他没用第二档。他用第一档就让一百八十人跪在了甲板上。跪不是他要求的——是人的身体在灵气暂时得不到供应时膝盖因失衡自然弯曲。跪伏下来后每个人脸上都是满头大汗——不是疼，是意识清醒而身体不听使唤，身体和他们自身的圣光断了联系，这种失控感才是最可怕的。

李长生在半空中收回手掌。他低头看着这群跪成一排的人，他说话。他的声音不大——冥气传导让每个字自己在落下去的过程中分化，像雨滴一样分别传到每一个修士耳边，只有他一个声源。

"地球不是任何人的。"

"一百多天后——有一批不属于地球的舰队要经过太阳系。他们是来确认冥王有没有死透的。如果他们确认冥王没有死——或者有人拿走了冥王碎片的全部——整个太阳系会从他们的食谱上变成第一优先消灭目标。"

"我不是来跟你们争灵脉的。我是来告诉你们一件事：如果你们在外敌来犯前还在内斗——你们脚下的每一寸海底灵脉、你们头顶的每一粒大气灵气——全都会在他们抵达之后的第一个小时内被踏平成原子灰。"

他停顿了一会儿。太阳在他身后午后的高度照得海面上每一艘船都投下了自己很短的影子。跪着的修士们低着头，有人咬着牙试图撑起身体——身体动了但圣光没有回来。不是法阵被封了——是区域内所有灵气都在等着他的下一句话。灵气自己听懂了。灵气不只是能量——它有感应能力。它知道外敌在来。它知道面前这个人是冥王的继承者，是灵脉的烙印持有者。它在等他的命令来决定接下来的灵气分布公式。

"我最后一次问你们所有人——这艘船上的每一个人：外敌来犯时，你们要站在哪一边？"

霍普金斯是第一个回答的。他没有抬头——他的头依然低着，但他的嘴巴在说话。他的发音像一位很久没有用中文说话的老外——每个字之间的间隔很慢，但每个字是他自己想出来的，不是灵符翻译的。

"我在非洲前线——封过一条地脉裂缝。裂缝外面是一层四千年没人接管的冥系灵波余部。那天晚上我站在裂缝边上感觉到的就是我刚才感知到的那种灵波——它不是冲我来的，它在等人。我当时想：这个东西是有主的，主还记着它。"

他擦了一把额头的汗，继续说："今天我看到主了。"

他身后一截甲板上默默站起了几个人——不是抵抗，是主动放下了手里的圣光法器。武器放倒在甲板金属面上发出的叮当声很轻，但在安静的午后海面上异常清晰。

李长生从半空中缓缓下降了高度。他降落在那艘最大的运兵船——圣殿骑士团——甲板上。甲板上跪伏着的修士们近距离看到他时才发现：这个人穿的不是战甲，不是修士长袍，是一件在太行山下石窝镇路边五金店买得到的纯棉黑T恤——袖口上火锅油滴的印没洗干净。

他向右转，走到佛朗索瓦面前。这家伙三天前在平台上是站着他面前发出撤退命令的——现在跪着。李长生对他说："跪不用。站起来。"

佛朗索瓦站了。不是被他拉起来的——是区域内的灵气在李长生放松审查标准后重新流入身体。他站起来后没有去摸剑。他看了一旁没站起来的霍普金斯一眼——那是他的前同事，曾在非洲跟他搭档过，封地裂那次他不跪也不回话。今天回了。佛朗索瓦就知道——这个不跪的人已经表态了。

"圣殿骑士团可以成为对外防御联合军的一部分。"佛朗索瓦说。

"西方魔法学院呢？"李长生问。

"如果他们不同意呢？"霍普金斯从旁边站起来问他。

李长生没答。

他只是弯下腰把霍普金斯刚才放在甲板上的那柄圣光法器剑捡起来还给他。剑柄接触到霍普金斯手掌的时候，在剑柄里被封印了五百三十年的圣殿骑士团第三代宗师的意志残片忽然隔着剑身从沉睡中被惊醒了——他隔着五百年感应到冥王令持有者的灵气频率。祂在剑的锋刃上发出一声极低的吟鸣——不是攻击，是敬礼。他是圣殿骑士团第三代宗师传人，在万年前曾见过冥王一面。

五百三十年后隔着剑身再敬一次。

"地球修仙联合政府。"李长生说，"这是会议——不是商议。"

他说完转身走了。走的不是海面——是在水上半走半飘。隔着几十海里的纳土纳群岛上，那群包了快艇想来打骚扰战的年轻降头术士在灵波里感知到了刚才的所有事——没有人下令，所有人同时转头把快艇开回马六甲海峡方向去了，快得几乎在海上跑出了紧急离港的速度。

整个南海灵眼上空——从西沙到纳土纳——一共三百多公里直径范围内——现在只有一艘巡逻艇。艇上是陈霜、刀疤和龟相。他们三人从西沙开过来，艇头迎着下午斜阳铺在水面上的金光。

龟相在艇底说："七重就敢往外放领域宣告——天下没人做过。"

陈霜说："他是农民。农民听不懂不可能。"

# 第四百六十二章 最后的等待

散修们散去后的旷野变得极为安静。飞升光柱在夜空下散发着柔和的白光，把周围几里地的枯草都染成了一片银色。林牧和苏晚在光柱下方盘腿坐下，面对面，手心贴手心，灵核在共振中缓慢地调整到最佳频率。

这段时间是通道稳定的最关健时期。从散修们散去到通道完全稳定，期间大概有数日。在这段时间里他们不能离开光柱笼罩的范围——离开超过半个时辰就会失去通道的锁定，必须重新启动。而重新启动需要再花同样长的时日——还有可能引来更多的觊觎者。所以他们不离开。食物是背包里剩下的最后几包压缩饼干，用水是苏晚用灵气从地底深处抽上来的地下水。

第三夜的时候，苏晚忽然问了一个问题。

"飞升之后，我们还会记得这一世吗？"

林牧睁开眼睛。他以为她睡了——但她没有。她靠在他肩膀上，眼睛睁得很大，看着头顶那道光柱里面流动的古文字。"通道会洗掉一部分下界的记忆——不是全部。通常会保留和你道侣有关的所有记忆。因为飞升之后的真仙不是一个人修炼的——上古飞升者都是以道侣为单位同时抵达上界。上界有专门供道侣共同修行的府邸和灵脉。"

"所以我会记得。记得和你在这里的每一天。"

"会。"

"包括加班那晚——你在二十三楼写代码，我在九楼核对财务报表——我们隔着十四层楼同时闻到了灵气复苏的第一股风。"

"记得。"

"包括东海深渊龙墓里你握着我的手，龙魂残片被我们俩的共振弹开的瞬间。"

"记得。"

"包括你在忘川溪水边用灵刃在你自己手背上刻'你叫苏晚——她在五里外的洞府等你'——那两个疤现在还在你手上。"

林牧摊开手。手背上的那两行字经过这么多天的风吹日晒已经褪去不少——被汗水洗了，被溪水泡过，被自己在炼丹炉上烤。但字的形状还在。皮肤上会永远留下那两行字的印子。

"这个疤飞升可能洗不掉。"他说。"因为它是你留给我的。"

苏晚伸出手，和那只带了疤的手握在一起。两只手在夜空中投下一个小小的影子，光柱把他们的影子拉得很长很长，一直延伸到遥远的平原尽头。

又过了两日。这天中午时分，飞升光柱忽然发出了一声极低极沉闷的震动——不是攻击。是通道在启动自检。光柱内部流动的古文字忽然集体停止了流动，全部凝在半空。然后文字重新开始流动——方向和之前相反。原本是从下往上，现在变成了从上往下。上界的灵气通过光柱的逆流灌注了下来——整片旷野在那一瞬间被上界的灵气涌潮冲刷了一次。站在近处的苏晚能明显感觉到上界灵气的质地——和下界的龙脉灵气完全不同。上界的灵气更轻、更纯、更接近于一种"光"而非"气"。她的灵核在这种上界灵气的灌注下旋转得比以前快了将近三成——距离炼虚的瓶颈只剩最后一层极薄的纸。

"今晚应该就能突破了。"林牧说。"你体内的寿元丹药力在这次灌注中被激活了一部分。加上你的灵核本来就在化神圆满的顶峰——炼虚只在念头转过的一瞬间。"

"那你呢？"

"我等你。"林牧说。"同修之法说得很清楚——两个人要在同一个瞬间跨入炼虚。如果你今晚突破，我今晚也突破。我们一起在飞升前完成最后的晋升。"

晚上，苏晚在光柱下方修炼。她把灵核的转速慢慢推到化神圆满的极限——不是猛冲，是一点一点的。她想起自己从练气期开始一路到今天。每一次突破都在挣扎——她不是天生的修炼者。她是凡人。每一次境界都是硬啃下来的。化神初期是在龙墓里用同修共振撑过去的。化神中期是在昆仑山洞口一天练了几万剑磨出来的。化神后期是拆了噬魂铃释放了十三道灵魂碎片悟道的。化神圆满是含着寿元丹片半死不活地熬过了药力的。现在只剩最后一道坎——炼虚。

她把灵核推到极限。然后她用了一个新的方法——不是林牧教的。是她自己刚才在高空逆流的上界灵气流过时产生的一个感觉。她把自己的灵核当成一个空杯子，把从上界流下来的光之灵灌进去——灌满了再压缩，再灌满再压缩。在第三次压缩时，杯子碎了——不是崩溃的碎。是杯子碎成了更大的东西。丹海不再是"海"，变成了一整片虚空。这就是炼虚。化神丹田化为虚空——从此不再受限于丹田的物理容量，灵气可以无限扩大。

她突破炼虚的同时，林牧在她旁边也睁开了眼睛。他体内的灵核以完全相同的节奏完成了完全一致的突破。同修共振使得两人的突破必须完全同步——错一个心跳都不行。两枚炼虚灵核在光柱下方同时亮起。灵纹不再是暗金色——变成了一种通彻的浅金色，接近于光本身的颜色。

炼虚初期。在飞升通道即将完全稳定的前夕——两人同时踏入。站在了人类和真仙之间最后的一道分界线上。

林牧抬起头。天空中那道光之阶梯重新开始往下沉降——它终于触到了地面。阶梯的最后一阶轻轻落在他们脚前，光滑的石阶上刻着两个刚浮现上去的名字——"林牧"和"苏晚"。

飞升通道完全稳定。登天梯已落。飞升的时刻——即将到来。

（第四百六十二章 完）

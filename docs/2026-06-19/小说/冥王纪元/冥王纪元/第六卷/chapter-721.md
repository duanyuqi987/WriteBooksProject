# 第721章 监察团成立

和平监察团成立百日之际，帝国举办了一场特殊的仪式。

仪式的名称就叫"监察团成立典礼"。典礼没有在帝都中央广场——那里用来办加冕和大庆典。也没有在元老院——那里用来表决和监督。陈霜坚持把典礼放在监察团总部的训练场上举行。这个训练场只有一块朴素的黑石广场，四周没有任何装饰，只有广场中央立着一块碑。

碑上刻的不是煌煌大言。是陈霜从第四十九纪元守护者的日记中抄来的一段话——

"我相信每个文明在刚成立的时候都是想做好事的。但我亲眼看着它们一个接一个变质——不是因为坏人变多了，是因为好人懒得管闲事了。——恒，第四十九纪元守护者，纪元毁灭前十六万年。"

十八名监察团成员整齐地站在碑前。他们没有穿制服——监察团不设制服。他们穿的只是各自日常的装束：夏侯明是一身灰布旧袍，洛清溪是淡青色长裙，图琉是鳞语族传统的暗鳞护甲。十八道背景、十八道修为、十八道过往——站在同一块碑前。

李长生和陈霜也站在碑前，背朝碑面。

不是主席台的方位。是跟他们平排站着——没有高出一级的位置。

"监察团的性质，不在我这说。"李长生的话很简短，"只在你们每个人心里。你们这十八个人，是帝国从数万亿公民中层层过滤出来的——不是因为你们最强。是因为你们在最强的里面，最不想欺负人。"

"这碑上的话你们已经看过了。"陈霜接着说道，"好人懒得管闲事——是以前所有纪元的死因之一。你们是这个纪元里最不能懒得管闲事的人。"

她把手抬起来——手腕上系着一条旧剑穗。"我以帝国皇后的身份，把我的个人权柄——在你们执行调查期间——完全地、不加保留地授予你们。你们调查任何人都不需要经过我。包括李长生。"

十八名成员中的几个无意识地收了一下肩膀。但没人有异议。

"你们的任期一千年。"李长生说，"一千年后，你们全部退下来。不是不相信你们。是制度需要新陈代谢。"

典礼最后，十八名成员依次在碑前滴入了一滴血——不是誓约，是记录。这滴血将永久保存在石碑中。一千年后，当这批成员的任期结束，新一批成员加入时，血滴会被重新唤醒，完成交接。

夏侯明滴完血之后对李长生说了一句悄悄话："你跟我想的不太一样。"

"你以为我是什么样？"

"我以为当了五十纪元的第一个永恒级早就不知道自己姓什么了。但你还是那个站在土里的农民。"

李长生没有回答。他只是低头看了看自己的手——那只从黄土地里刨过土豆、挖出过冥王碎片、握过陈霜的手、写过法典序言、推开过维度之门的手。

"地里的活还没完。"他说。那只手掌摊开着——纹路在午后的阳光下不动。旧纪元刚捡到冥王碎片时他以为"地里的活"就是种庄稼。后来他以为是打仗。再后来他以为是建设法典和大学。然后他以为是理解轮回。现在他知道——"地里的活"是永远做不完的。因为地是最诚实的：它每年都问你一遍——今年你准备怎么对待脚下的这块土？去年你种的是粟，今年你准备种什么？如果你今年的回答跟去年完全一样——地不会说话，但她会减产。因为土需要轮作。

帝国也一样。每一个制度被通过的那一天就已经开始老化了。它需要被持续更新。守护者的活是永远不会完的——不是在同一个战壕里打一样的仗，是在不断扩张的边界上一次次蹲下去检查田埂有没有漏水。

李长生把手掌合上。十八名监察团成员把他的动作默默记在了心里——不是因为那是永恒级修士的动作。是因为那是从土里长出来的人的动作。

（第721章完）

# 第309章 最后一块碎片的位置确认：宇宙深处

火星基地落成后的第二十天，李长生在冥殿独自坐了整整一夜。

不是修炼。不是冥想。是在感应。八块碎片合成之后，冥王令已经逼近圆满。圆满的冥王令对散落的碎片有天然的"归位牵引"——八块碎片会自动寻找第九块碎片的位置。但那块碎片被囚禁在五万光年外的诅咒之星上——经过了诸神联盟的三重终极诅咒——其中的时间诅咒把那个空间区域的时间流速折成了外界的十分之一。这意味着那边过十年，这边过一百年。信号从那边传出来要穿过一个宇宙尺度上的时间差——不是空间距离的延时，而是时间坐标本身的错位。

李长生需要安静。安静到能听到自己的心跳、能感知到经脉中灵气分子挨个流过冥王令核心时的微振动。在这种极度的安静中——他终于在第十九天的深夜捕捉到了那条信号。

不对。说"信号"不准确。信号是某个东西发送给你的。而那个第九块碎片早已没有意识——它本身只是冥王令的一部分法器残片——它在诸神联盟的三重诅咒中被封死了所有的能量外溢通道。它不是主动在发信号——它是被动地在响应。用李长生能感知到的最直观的方式来形容:当八块碎片在他体内形成完整的共鸣频率后，第九块碎片在诅咒的压制下仍然对那个共鸣频率产生了机械性的共振——就像一面已经被锁死的铜镲，但铜镲本身的材质还是一样的——八块碎片敲响了一记声波，第九块碎片不得不在诅咒中细微地振了一下。

那一丝微振——是它唯一没有被诅咒封印的能量回应。它的位置就锁死在那道微振的时空坐标上。李长生打开了守殿人的连续观测数据，开始进行交叉比对。守殿人在这万年间一直在持续观测同一星域——不是刻意观测，而是它的标准观测程式中本来就包含了银河系猎户臂全部区域——它每六十秒扫描一次整个猎户臂的灵气波动，每一次扫描产生的数据足够填满一台地球上的标准服务器。积攒了一万年的观测数据集，总量大到了任何人类团队都无法手工处理的程度。但守殿人自己可以处理——它的算力来自离宫下方那条完整的灵脉分支，能在同一瞬间调用足够多的并行符文逻辑单元来处理海量结构化数据。

比对结果在当天夜里得到了确认。

"主人——我已在猎户臂末端锁定目标星域。观测数据与您感知到的第九碎片能量特征匹配度达百分之九十八以上。目标星域的空间坐标如下——"守殿人在李长生的神识中投射了一幅三维星图。不是印象画——是精确到天文单位级别的宇宙导航图。星图上标注的目标位置是一颗位于猎户臂最末端区域的行星——它的公转轨距其主星约四个天文单位，在万年前曾经是被用来作为跨光年侦察警戒哨的众多点位之一。它的主恒星在八千年前已经死亡——一颗中等质量恒星在文明操控下被提前引爆，残骸塌缩为一颗中子星。行星失去了恒星的能量源后地表温度骤降至接近绝对零度。但它没有被撕碎——因为诸神联盟在它上面施加了专门的维存阵法——将整个行星的结构维持在接近绝对零度的环境中仍然能保持物理完整性。

"死域——"守殿人说，语气难得地带上了一丝内感，"银河系猎户臂末端的死亡星系，范围横跨约八十光年。以我目前能确认的观测数据为准——这片死域并非自然形成。一万年前——诸神联盟在执行冥王围杀战役的同期，特遣舰队对猎户臂末端进行了'灭绝性清理':全部文明星球被摧毁、全部恒星被引爆或催成塌缩、全部灵气节点被物理封死。目的是制造一片'任何飞船都无法补给能源的真空'——作为囚禁最高威胁重犯的终极监狱。支撑这颗星球表面运作的唯一能量来自——"它放出了一张读数和比对，"第九块碎片本身。他们用冥王自身的第九块碎片作为整个囚禁阵法的能量源。监守冥王残余的魂，用的是冥王自己的法器。一层叠一层——互相锁定，无法从内部突破。这就是诸神联盟的最高囚禁手段——永劫死牢。"

"残魂——"李长生停下仔细问道。他体内七块碎片（实际八块，此处指前七块）融合期间释放出来的冥王记忆里，清楚地记录了"魂飞魄散"的状态。碎片的残魂一直告诉他的信息也是——冥王在万年前的最后一战中魂飞魄散，九块碎片是他法器的全部残余。但现在第八块碎片的信息确认了另外一点。

"他在诅咒之星上的残魂——大致占到多少？"

"据诸神联盟当年在内部通讯中保留的数据:冥王在魂飞魄散后被他们强行捕获并封入灵魂囚笼的残余神魂——约占完整神魂的百分之四左右。就是这一点点残余让他无法'彻底消失'——残留意识不会自动散逸，只能被永久囚禁。"

百分之四。冥王完整神魂的一百份之四被封在那颗人类叫"诅咒之星"的行星上。百分制四的神魂在实质上是一个微弱的残缺意志——它不足以让冥王"复活"，但足以让他存在。它在被囚禁之前就被第九块碎片自身的力量加固过一次——那是冥王散落九块碎片前的最后一道命令:保护好最后一个持有碎片的区域，等待继承者的到来。

换言之——九块碎片是桥。九碎合一——是冥王留给自己继承者的最终道路。只有集齐九块碎片之后，冥王令才能恢复到全盛状态——而到了那时，继承者才能拥有打开诅咒之星、取出那百分制四残魂的实力。

"释放残魂之后——会怎样？"陈霜问。整晚一直坐在冥殿角落擦她的剑——她直觉知道李长生需要安静，但她也需要留在殿中。不是出于安全的考虑——而是她总在这种关键的历史性对话时有一种"必须亲眼见证"的感觉。

"冥王本人不会复活。"李长生说，"但残魂中包含着他最后的意识片段——他为什么选择九碎散落、为什么决定让地球伪装成灵气枯竭行星、他对诸神联盟未来动态的预判——完整的真相将随着释放残魂而浮现。但残魂将无法独立维持自主意识——它会在释放后融入冥王令，完成法器的最终完整归位。"

这是一程必须出行。不是为了冥王复活——而是为了完整真相。

"航行时间——"小王已经开始算工作了。他打开了守殿人推送到电脑上的星图数据，对照当前可行的最高速度进行了大量计算。算完后他深吸了一口气。

"用冥气引擎全速航行——若全程保持最高功耗——我们到达诅咒之星理论上大约需要两年。"

两年。在穿越五万光年的航行中——时间只是一个数字。

(第309章完)

# foreshadow-008：误会模式

- 状态：paid_off
- 首次埋入：chapter-017，林予怀在校门口看见沈安晴和疑似表哥的男生同行，立刻把可能性想成“她有喜欢的人了”。
- 计划推进：chapter-027、chapter-029、chapter-037
- 计划兑现：chapter-037 至 chapter-040
- 叙事功能：展示林予怀在亲密关系中的想象失真和自我折磨，后续与“为你好”创伤、唐青禾线和最终反省相连。

## 记录

- [chapter-017] 表哥误会已写入正文；赵一鸣指出他需要分清事实和想象。
- [chapter-027] 异地后，林予怀因沈安晴消息变少和照片背景中的陌生男生而再次乱想。
- [chapter-029] 沈安晴因学生会排节目忙碌，林予怀把合理忙碌想成关系退开，电话冲突爆发。
- [chapter-037] 误会模式迁移到唐青禾线。林予怀因她参加社团聚餐而吃醋，用关心包装质问，后又在读书分享会门外偷看她和社团同学配合，唐青禾指出他的控制欲。
- [chapter-049] 林予怀看见沈安晴与周知远的现实生活后不再误读、不再追问，误会模式完成反向回收。

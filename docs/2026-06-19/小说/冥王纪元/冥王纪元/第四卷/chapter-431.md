# 第431章 宇宙北部、东部、南部的帝者开会——紧急会议

太初帝国的首都星名叫"原初"。这颗星球不在任何星系中——它单独悬浮在宇宙中央的一片巨大空间异常区中央，被一层由太初帝者本人布下的太初之力包裹。包裹太初的力场让这颗星球与外界宇宙的物理法则完全隔离——在原初星上的时间流速是外界的三分之一。在宇宙其他地方过去一天，在原初星只过了八个时辰。

选择以时间迟缓的环境开紧急会议，不是礼仪考虑——是效率。三十个小时的会议在原初星只过去十小时。帝者们可以用外界的时间应对战争，而用原初星的时间从容讨论。

会议室建在原初星最大的一片内陆海上——一座由纯白色空间晶石构成的环岛。环岛中央是一个直径约一百米的圆形平台，台上没有桌椅——帝者们到会时以各自灵根系的方式在平台上方形成能量座位。能量座位以光圈或雾气或气旋等形式呈现，不需要接触平台表面就能承载帝者本人。这不是原始时代的议事——这是宇宙级帝者之间的正式集会，在空间本质上标记出尊卑次序。

最先抵达的是苍明帝者。他是本次会议的召集人兼议长。他的外貌老而精瘦。一双灰色眼睛看人时给人的感觉是穿透，不是攻击——他修的是空间灵根，看一眼就能大致知道对方处在哪一层空间坐标上。他的到来没有带随从——太初帝者不允许任何非帝者随从进入原初星——他自己孤身一人踏过空间阵从苍明星赶来，抵达时他的能量座位自动在圆台第一个位置——议长座——升起。

接着到场的是天枢帝者。她是这次紧急会议唯一的女性帝者。她是阵术真人一脉的传人，天璇宗的末代掌门亲传。她的能量座椅是一条由六十四道小型阵旗自动织成的轻薄光纱——每条阵旗闪烁的光对应一种卦象变化。阵术师即使在会议期间也是全程在推演的——阵师的脑子不能停。她与苍明对视了一眼，两人没说话，但神情间传达的意思彼此都清楚:局势非常严重。

九幽帝者随后以亡灵公主的姿态缓步而至——她的形体由一对环绕的灰黑雾气笼罩，面庞时隐时弱。她不是鬼道中主宰死亡的魔——而是掌控界限之间过渡状态的那类帝者。她坐在以雾气制成的座位上，没有多余动作，只是姿态端正，双手叠在膝前。

又过一会儿，来自南部的雷泽帝者和天火帝者同时到达。雷泽帝者身材魁梧——从头到脚都是雷系锻造出来的模样，语气和外貌一样爽直。坐下后就先插话:"直接点——冥王到底有多少帝者？"天火帝者则完全相反——他修火系但克制得极好。紫红色双眼中时有火苗跳动但他的嘴角一直带着不急不燥的笑意。他坐下后对雷泽摇了摇手:"等其他人——数字说到最后才准。"显然他对这场战争的布局有自己准备好的看法。

接着是来自北部的玄冥帝者——一位皮肤浅蓝至近乎透明的水系女性。以及青木帝者——太初时代活到今天的木系长寿老人。上万年的木心修为足以让一棵树拥有分身状态——他的本体是以半树化根须的样态从空间透送进来，但还是凝聚成了可交谈的人形。会议室内没人觉得一棵树人将参与帝者会议有什么奇怪——青木帝者的年龄是太初帝者里最年轻的，但反而资格最老——他见过冥王。他亲历一万两千年前围杀，那次战役改变了他对这整个宇宙的看法。

最后到场的是三位来自宇宙中央最核心地带的帝者。太初帝者——本名不详。他的能量座位与其他所有人都不一样——它是一整个压缩至座位大小的小微型宇宙球悬浮在环台正中心。你在他对面看不见他穿什么衣服或长什么样——只看得见微型宇宙球里数亿颗微小光点缓缓自转，就像被压缩成球形的完整宇宙缩小版。他一就座，所有其他帝者的能量座位自动向外挪行一些——这不是安排好的礼仪。是原初星自带的超底层规则:太初坐正中。

另外两位中央帝者分别是万星帝国代表万星帝者和一位名字在环台会议上以全称星号标注的身份极特殊的帝者——斩空。斩空帝者修的是空间灵根中最罕见的"断层面"修法——他是太初帝国最锋利的剑。

十一位帝者到齐。与会人数为十二——但如果算上不在座但即将间接参与联盟的其他外围帝者，已知的参与联盟的帝者总数将在进一步联席后明确。

苍明作为本次会议当然的议长，先打出第一道星图投影——投影以空间灵力投射在环台中央上空。星图上标注了冥王帝国的完整疆域、边荒防御线的精确布防图——他花掉派出的所有剩余密谍力量获取的情报——以及冥王军当前在西部各星域已知的兵力部署。西区全部标记为红色。包括附庸星球一概标为红色。一条粗虚线将西部星域从全宇宙中单独圈出——虚线内是一面蓝底暗金大印的冥王帝国国旗示例图。旗上那枚冥王令——公章式的红泥印——被帝者们看在眼里。

"西面已经在二十天之内组织起了有效防御。"苍明逐项指出。他点了边荒防线——四层防护组合阵挡住原空间裂隙的旧址，四位帝者长驻边荒把持着冥王帝国东部方向最严密防线。其内部的工程速度远超我们对战后重建的常规预期。又点了永昼之门——光晔死后永昼之门成为冥王帝国在东部获取先天空间警戒情报的主要前沿站——光系探测网已提升至全宇宙最大同类型网络第五位。此外还有最重要的一点——冥王帝国已完成了十九位帝者的归附。他们的总战力已经明显超过任何单独星域联盟。

他说到此处停顿，目光扫过在场每一位帝者的面孔——连大树的木质面孔也不例外。然后说:"如果我们不现在组建联盟——等冥王帝国把东部和中央的归附模式复刻一遍，未来可能连开会议的原初星都不再属于在座任何人。"

苍明说完后，会场上安静了约五个呼吸。五个呼吸的时间在原初星是极短的——原初星的时间被压缩到三分之一的黄金速度，五个呼吸不到宇宙外界的三个普通吸气。

终于，太初帝者从那颗微型宇宙球之中发出了低沉到几乎像从宇宙大爆炸微波辐射转译出来的声。他的声音极缓极重——每个字的咬合间隔长到能抽完一条烟。

"召集。所有帝者。最多能召集几位？"

苍明:"目前确认参与联盟的帝者是十一。在完全动员后——能够在战术意义上加入帝阵的帝者预计可达十三至十四位。如果远地星域的帝者也肯参战——达到十六位是我们的政治和军事极限。"

十六位。这个数字在环台内引发一阵细声的议论。雷泽帝者摇头——不是不同意，是感慨。十六位帝者联合作战将是历史。对于雷泽来说这很不爽利——他修雷系更习惯一个人打几十个。天火帝者双目的火苗跳动剧烈了一些——能看出他对联盟的热情相对高涨。而九幽帝者沉默时间极长极静，几乎不发表看法——亡灵本身就是沉默的顶配。

青木帝者是所有成员中对联盟最平静的一个。他说:"十六位帝者如果组成完整帝阵，确实能突破冥王的边荒防线。但突破之后的事更重要——击穿防御线之后你们打算把冥王本人怎么样？当年的冥王是被十六位以神明之尊围杀的——围攻完毕十六位神明损失过半。不是轻易的事。他继承了一套更完整的冥王令——我们要准备的不是战胜，是战后如何存活——以及战后谁负责把活下来的人带回去。"

青木帝者讲完这段话后，天枢帝者的阵旗开始频繁移位——她对这个话题反应很大。作为天璇宗的当代掌门(至少是末代掌门亲传)，她了解很多旁人不知道的上古战争细节。她说:"师傅——天璇神明去世前给我留下最后一道法术加密记忆。记忆的内容是:若冥王之传人重现，不要与之正面相抗——必须与他在冥王令尚未完成始解之前将他封入某种时间或空间隔绝的单独维度中。换句话说——杀不死他或许杀不死他——但可以把关起来。帝阵如果只用来强杀他——损失可能大到我们自己的文明无法承受。但如果以帝阵将他锁入一个单独宇宙——这个风险是可以控制的。"

天枢帝者这个建议瞬间改变了联盟的战术核心。他们的目标不再是"消灭冥王帝国"——太庞大，太大。他们的目标是先限制冥王本人——把他的能量单独锁到一个无法逃逸的独立维度中。只要李长生不在了——冥王帝国的帝墙就会自动解体，归附帝国的联盟没了共同的纽带会自动瓦解。这样就不需要逐个消灭西部十九位帝者——只需要挂着一个。

"囚禁比击杀更可行？"苍明问。

"以帝阵而言——锁闭比绞杀所需能量约少百分之二十。帝阵的成功率可以从六成勉强提高到七成左右。代价是太初帝者的原初力会被消耗一部分——时间流速的分流是锁闭李长生必须的代价。"

太初帝者:"可以。"

在他说出"可以"两个字后，在场的十二人联盟初步确立了一个以锁禁而非毁灭为首要目标的战争方案。方案取名为"封冥"。动用十六位帝者组成帝阵——帝阵的主导者由太初帝者担任。他是唯一一个年龄、境界和阵法阅历足以主导帝阵的核心帝者。锁定目标的原理是:将李长生所在区域的空间时间冻结并沉入一个单独的、与主宇宙脱离的微型维度中——微型维度的存在依赖于太初之力持续供应。供应多久——取决于太初帝者愿意消耗多少本源力量。

方案敲定后，苍明帝者代表联盟向全宇宙发表声明。这份声明是在原初星会议台上临时拟出的，措辞中有一句后来被宇宙史学家反复引用的名句:"十二位帝者——不——是整个宇宙中央——已经决定将冥王的第二个纪元扼杀在其摇篮中。"

消息仍在加密中——还没有公开广播。但第一波军事准备——太初帝者亲手在全宇宙投放帝阵预组成阵盘——已经开始。阵盘的制造工艺由天枢帝者提供——她将天璇宗的阵术核心技术和天枢阵法工业结合，在不到两天的时间内就做出九张帝阵预装盘。剩下的七张——来自七位各自的帝者赠物——也在制作方案中。

十二位帝者的帝阵战争机器已经激活第一个齿轮。而在对面的边荒防线之外，诸天号上的李长生还不太清楚那个齿轮的存在——他只知道东部联盟在密会。他收到的信号仍然来自小王的河图系统——关于大量加密通讯的统计报告。而真正的危机正在以原初星三倍的时间效率——快速筹备着。

（第431章完）

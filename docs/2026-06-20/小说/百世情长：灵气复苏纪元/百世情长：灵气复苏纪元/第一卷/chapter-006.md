# 第六章 城市夜空的极光

晚上八点十一分，城市上空出现了极光。

按照地球上已知的所有大气物理规律，这件事不应该发生。极光的成因是太阳风带来的高能带电粒子在地球磁场引导下涌入极地高空，与大气层中的原子和分子碰撞，激发出一百公里高处的绿色、红色和紫色光幕。这个机制决定了极光只出现在高纬度地区。北纬六十五度以上。离北极越近越常见。在低纬度城市看到极光的概率无限趋近于零。

所以当第一道光带出现在城市西南方向的夜空中时，没有人叫它极光。微博上最早的那几张照片配文是"今晚天上什么东西在发光？"。发照片的人以为是灯光工程——新开的商场在打那种朝着天空的射灯。直到光带从西南方向横跨整个天穹，一口气拉到了东北方向的最边缘，所有人才意识到那不是任何一盏人造灯能够打出的角度。

光带有五层。

第一层是最底部的那条绿光。不是草地那种绿。是深一些、冷一些、像翡翠原石被切开时断口处的那种青碧。它从西面的地平线起，沿着一个平缓的弧度爬上中天，朝着东北方向滑过去。

第二层红光浮在绿光之上。绯红，不浓——像是沾饱了水的红色水彩在宣纸上晕开之后余下的那种淡淡红痕。它比绿光宽，但不如绿光亮，位置也在更高的地方。

第三层是紫色的。那种介于兰花和牵牛花之间的紫。紫色光带不和其他两层平行——它从偏南的方向横穿绿光和红光，像一条被风吹歪的丝绸，在夜晚的高空中荡漾着谁也听不见的波动。

第四层在更上面，颜色极其浅。青白。不是白天天空的蓝白，是瓷器在窑变之后偶然出现的那种天青和乳白之间的过渡色。这一层的边缘是模糊的，没有前三层那么锐利，和黑暗的天空融为一体。

最上面是第五层——金色的。只有极细一条。亮一下、暗一下，像是有什么东西在极高的地方呼吸。

全城的人涌向了阳台、窗口、天桥、广场。所有的手机都被举起来了。所有的镜头都在朝天拍摄。所有的朋友圈在同一秒被极光照亮。连堵在高架桥上的车流都停了——不是交警指挥的，是司机们自己熄了火，从车窗里探出半个身子仰头看天。

公司二十三楼。

小赵是第一个喊出来的。

"卧槽——极光！"

他把耳机一摘，椅子往后一推，整个人弹起来冲到窗边。窗户只能推开一条缝，他把脸贴在玻璃上，鼻子压得扁扁的，眼睛直直地盯着天上那五道光带。

"这是极光吧？是吧？不是灯光对吧？——林哥你过来看！绝对是极光！我这个纬度能看到极光我今天活够了！"

林牧坐在自己的工位上没动。不是不想看——他从窗外天空变色的第一秒就看到了。那道绿光开始出现的时候，窗外的天空从墨黑转为一种说不清的深绿。他隔着玻璃看了三秒，然后站了起来。

小赵以为林牧来窗边，把自己脸从玻璃上挪开给他让了一点位置。结果林牧没去窗边。他转身走向安全通道。

"林哥你去哪？"

"天台。"

"天台上不去，那个门常年锁——"

"我去看看。"

他推开安全通道的防火门，走进了楼梯间。防火门在他身后弹回来，隔绝了小赵接下来的话和办公室里同事们的喧哗。

楼梯间很安静。白墙，灰色台阶，扶手是刷了银漆的钢管。头顶的声控灯逐层亮起来。他的脚步在楼梯间里有规律地回荡——运动鞋踩在水泥台阶上那种沉闷的嗒、嗒、嗒。

他爬了两层。二十五楼是公司所在楼层的顶层。从楼梯间的尽头再往上走，还有一道窄楼梯通向天台。铁门。绿色的油漆从门框的焊点开始剥落，露出底下锈成了黄褐色的钢板。铁门上挂着一把U型锁，挂锁扣是被人撬过的——锁还在，但扣已经从门框上松脱了。是某个老员工为了方便上去抽烟做的。

林牧把锁扣从门框上推出来，推开铁门。

风迎面灌过来。二十五楼的天台风很大，风里裹挟着城市的声音——楼下马路上的喇叭声、人声、手机外放的短视频BGM——经过二十五层的爬升，这些声音被拆碎了混在风里，变成了一种低沉的嗡嗡嗡的存在。

但他没有注意风，也没有注意声音。他站在天台的边缘，抬起头。

那五色光带铺满了整个天空。从头顶正上方一直延伸到地平线的两端。在城市灯光的对比下，极光的光带并不刺眼——它是柔和的，但极其广阔和深远。你站在它下面，和它之间隔着一百公里的垂直距离，但它给你的感觉是触手可及。

林牧知道它是什么。

不是极光——或者说不是科学解释里的那种极光。这是另一种东西。他在看到它的第一眼就知道它的名字：灵气潮汐。

是灵气复苏之后的第一波大规模灵气潮汐。那些光不是带电粒子撞击大气激发出来的荧光——是灵气在高空聚集之后被太阳的残光折射，在人类可见的波长范围内呈现出来的颜色。绿色和红色是灵气的低层折射层。紫色和青白是中高层。那条若隐若现的金色光带——是真灵。最纯粹的原初灵气，只有被压缩到极高的密度才会显现金色。

他不应该知道这些。他从来没有在任何一本书、任何一堂课、任何一个网页上读到过这些。但他知道的还不止这些。他还知道——那层金色的光芒现在的高度大概在一百四十公里左右，灵气浓度还在上升。按照这个速度——如果每波潮汐之间的衰减常数和此刻的活跃度成正比——那么第二波潮汐会在大概四天后到达。届时灵气浓度会比现在再提升一个数量级。灵气一旦在城市中达到某个临界值——大概是万分之零点五——就会开始主动进入一切能承载它的生命体。

就像他在地铁里经历过的那种热流。

林牧把双手从天台护栏上抬起来，摊开手心。手心对着天空。那股热流从他的丹田开始苏醒——这一次用不着外界触发了。头顶的极光——头顶的灵气潮汐——正在以一种他身体可以直接接收的频率释放着能量。热流从他丹田出发，沿着脊椎上溯，过肩胛分两股，经过手臂汇入手心。

手心发烫。干燥的、从内往外辐射的热。

他闭上眼睛。他看见了——不是记忆，不是想象，是一种介于理性和感性之间的知觉。他看见他的身体内部有一条完整的脉络网络。那些热流在这条网络里循着固定的路线运行着，每一个节点、每一处转折、每一次汇合和分流都精确到了毫厘之间。他知道这条路径的名字：经脉。他知道那些节点的名字：穴位。他知道这种热流叫灵气，而这种灵气在体内做固定循环的方式叫——

"周天。"

他把这个词从嘴里说了出来。声音很轻。被风吹散了。

他睁开眼睛。在他的感知里，整座城市现在是一个灵气场。高空的极光是灵气的大规模聚集。地面的建筑、街道、车辆——这些不含灵气的东西——是这个场里的空洞。而在这座城市的七百万人里——他的感知像一张无形的网一样铺开——大概只有几百个点，微弱地亮着。

和昨晚地铁里那个穿校服的女孩一样。那几百个点都是潜在的灵气感知者，但大部分火苗很小，小到连他们自己都不知道它的存在。

他的感知网继续铺开——然后他的感知触碰到了一个点。

不是微弱的火苗。这个点不比他强，但它的"颜色"不同。不是亮的——是暖的。是另一种质感。其他几百个点的灵气都是冷色调的——青的、蓝的、白的——只有这个点是暖的。

不是热。不是温度。是一种感觉。金色的暖。

他的感知在这个点上停住了超过一秒钟的时间。他忽然意识到这个点就在他所在的建筑里。不是楼下的大街、不是隔壁的大楼。就在这栋楼里。

离他很近。

铁门被推开了。

风把铁门撞在墙壁上——一声闷响被风扯碎了，变成铁皮颤抖的嗡嗡声。林牧转过身。天台上站着一个女孩。风把她的头发吹乱了，几缕从低马尾里逃出来，在脸颊两侧飘。她没有化妆，穿着公司的深蓝色工装外套，左手捏着手机，右手还扶着铁门的把手。她显然是一路跑上来的——呼吸比平时快了不少，胸口起伏了几次才说出话。

"这里——真的能看到。"

她的声音比风轻。但林牧听得很清楚。

"嗯。"

他回答了。然后不知道该说什么。二十八岁、写了六年代码、社交能力在及格线上下一线之间的程序员林牧，在二十五楼天台被五色极光笼罩的夜晚，面对一个不认识的女孩，说了"嗯"。

苏晚在天台上走了三步，停下来，仰头。风吹着她的衣领翻了一个角。她没有去整理。

"我是十九楼财务部的。刚才在加班，同事群忽然炸了，说天上有极光。"她说这话的时候没有看林牧。她的眼睛一眨不眨地望着天上那条正在膨胀的金色光带。

"我是二十三楼的。"林牧说。

"IT部？"

"嗯。"

"那你们平时加班比我们财务还多吧？"

"看项目。"

苏晚点了一下头。她没有再接话。她往前又走了两步，在天台护栏的内侧站定，双手扶着栏杆。铁栏杆很凉——十一月的夜晚，金属表面温度大概只有七八度。她把手放上去的时候缩了一下，然后重新放稳。

林牧站在原地没动。他离苏晚大概五步远。

天台上安静了大概有一分钟。两个人都不说话。头顶的五色光带在悄悄地移动——紫色那条带子偏了一些角度，和绿色的交叉点往东偏了两三度。金色的光带越来越亮。

然后苏晚说了一句话，声音很低。像是自言自语，但风还是把它送到了林牧的耳朵里。

"这光——我怎么觉得在哪里见过。"

林牧的感知网在那一刻收了。不是主动收的——是苏晚说话的时候她的体内的灵气波动了。她的那点暖光忽然亮了一瞬。她的丹田里有一团很小很小的暖意在转。她不知道——她自己都不知道她的体内有灵气在动。但它确实在动。和他体内的热流走的是同一条路径——丹田出发，沿脊柱上溯。只是她的那团暖意走到胸口就停下了——像是遇到了一扇关着的门。

"你是哪个部门的？说真的？"他忽然问了一个他知道答案的问题。因为他需要多听她说话。不是听内容。是听——听她说话的时候灵气在体内的流动。

"财务部。我刚才说了。"

"对。你说了。"

苏晚偏过头看了他一眼。风把她的头发吹向左脸颊。她的脸很小，皮肤在极光的光线下呈现出一种不太真实的白皙。她的眼睛很亮——不是因为极光的反射，是她自己的眼睛带着一种光。

"你说你是IT部的。IT部在二十三楼？"

"嗯。"

"二十三楼能看到这边吗——我是说，能看到西南方向吗？"

"能。靠窗的工位能看到。"

她在问他二十三楼的窗户能看到什么方向。她在问——在极光铺满天空的夜晚——一个隔着四层楼、平时从不会有交集的人——站在同一片天台上的另一个人——他工位的窗外是什么样的风景。

林牧回答了她。"西南方向。能看到高架桥和隔壁的商场。商场上个月搞活动挂的蓝色灯带一直没拆。"

"好看吗？"

"什么？"

"商场那个蓝色灯带。晚上看的话。"

"还行。就是丑得比较均匀。"

苏晚笑了。笑得很短——嘴角弯了一下就收回去。不是觉得好笑，是被"丑得比较均匀"这个说法碰了一下。

林牧不知道自己为什么接着说了下去。"你那个方向——十九楼西南面——看出去是税务局的门脸。税务局晚上挂红旗。白天也挂。灯打在红旗上，颜色比较奇怪——"

"像生锈了的番茄。"

林牧愣了一下。

"你说什么？"

"红旗被日光灯照着，颜色像生锈了的番茄。"苏晚把被风吹到嘴边的碎发拨开。"我们财务部每个人都知道这个。因为我们每个月都要盯着税务局那个破招牌看好几小时。"

极光在他们身后还在铺展。金色的光带更亮了。城市的车流停了。楼下有人在用手机外放一首很久以前的老歌，歌的旋律被二十五楼的风绞碎了，只剩下含糊的几个音。那条金色的光带在高空缓慢地蠕动——从一个端点开始亮，亮光像潮水一样推到另一个端点，然后在尽头收暗。明暗的节律和呼吸一样平稳。

他们两个人都看着天上。五步的距离。谁也没有走近，谁也没有退远。

苏晚忽然开口说："我叫苏晚。苏州的苏，晚上的晚。"

林牧没有立即回答。风吹着天台上的排风管道，铁皮在风里偶尔发出一声闷响。他把她名字的两个字在心里默念了一遍。苏。晚。

晚。

他想起了一件事。不是记忆——是一张纸条。一张他还没有见过、但即将见到的纸条。他不知道那张纸条的存在。但他刚才在把她的名字放进心里的时候，他的身体对这个名字产生了反应。丹田的热流忽然往上蹿了一截，在胸口的位置烫了一下。

"林牧。树林的林，牧场的牧。"

苏晚点了一下头。她把他的名字也默念了一遍。然后说了两个字："好记。"

好记。没有问"牧是哪个mu"，没有说"这名字有意思"。只是说——好记。

极光在九点二十三分开始消退。先是紫色的那条光带从边缘开始变得透明，然后是青光，然后是红光。绿光最后收——从天顶开始往下沉，一寸一寸地缩向地平线。金色的那条最早来也最早走，在所有人以为它还在的时候就已经不见了。

城市恢复本来的颜色。六百八十米外的那栋商场的蓝色灯带重新成为夜空里最显眼的光源。楼下停掉的车流重新发动了。高架桥上，一排一排的尾灯又亮成了一条红色的河。

苏晚先走。她把天台铁门的锁扣重新挂上之前停了一下，回头看了林牧一眼。

"明天要是还有——你还来吗？"

"来。"林牧说。

铁门在苏晚身后关上。她的脚步声在楼梯上一阶一阶地往下走，鞋跟敲击水泥台阶的规律节拍被防火门的隔音层吃了一大半。剩下一小半从楼梯间里逃逸出来，穿过铁门的缝隙传进夜里。

林牧一个人站在天台上。天上的五色光带已经完全消失了。夜空恢复到正常——墨黑色，几颗亮星，一层淡淡的高空薄云。手机响了。小赵发来的微信，一连发了好几条："林哥你怎么不叫我上去""天台上能看到什么角度""刚才有人拍到了视频上传到抖音已经破百万赞了""你人呢？"

他回了一个字："在。"

他站在原地看着天空。感知网重新打开。那几百个微弱的点在城市的各个角落安静地燃烧。唯独十九楼的方向，有一个暖色的点——很小，比火柴还小——但它烧着的火焰的颜色是所有火焰里唯一的不同。

金色的暖。

他把手心的热流收回去。那股在经脉里走了半圈的热流沿着原路退回到丹田的深处，降为微弱的稳定的温。

他从口袋里摸出手机。打开备忘录。手指在键盘上点了五个字，发了很久的呆，又在字后面加了五个字。

"晚。真好听。"

光标在句号后面闪了七下，他按了锁屏键。

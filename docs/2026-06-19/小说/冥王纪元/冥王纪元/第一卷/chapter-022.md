# 第022章 第一次感知灵气，如鱼得水

老黄给李长生找的房间在二楼走廊尽头，一个月三百块。

房间大约十平方出头。一张单人床，一个塑料凳子，一个缺了门板的柜子。窗户正对着隔壁楼的墙壁，间距不到两米，白天也进不了多少光。墙壁上糊着一层又一层的旧报纸，最上面一层是去年的晚报，头版标题是《建国百年筹备工作全面启动》。

李长生把蛇皮袋往地上一放，就算是安家了。

他没有行李，不需要收拾。十五分钟之后，他坐在床沿上，摊开右手掌心。碎片一动不动——从昨晚那个老太太消失之后，它就特别安静。

"刚才那个人，是什么来路？"他在心里问。

"不确定。"残魂的声音很低，似乎还没从刚才的沉默里缓过来，"但是她的气息非常古老。不是年龄老。是气息的质地——像在地底下埋了很久的东西见了光。"

"你说人话。"

"她修行过。"残魂说，"而且时间不短。境界——我看不透。但至少比你我现在高出不止一个大境界。"

李长生沉默了一会儿。

他只见过一个正式修士——还没有。他活了三十年，连广场舞大妈之间斗法都没见过。现在残魂告诉他楼上住着一个修行高手，而且还端汤给他送过？他忽然觉得这栋楼不太像城中村，倒像一个关着猛兽的笼子，每扇门背后可能都藏着不寻常的东西。

"别想了。"残魂说，"今晚你先做正事。"

"什么正事？"

"感知灵气。"

李长生从获得碎片到现在，已经过去了好几天。这些天里，他一直在被动感受——碎片发烫、碎片震颤、碎片指引方向——但这些都不是修炼。这是碎片在"用他"，而不是他在"用碎片"。

残魂说得很直白：你现在只是碎片的容器。就好比你怀里揣了一块吸铁石，走到哪里都能感觉到铁，但你自己不会吸铁。感知灵气是一道门槛。迈不过去，你就永远只是个拎着宝贝当废铁的农民；迈过去了，你才是修炼者。

"怎么做？"

"盘腿坐下。闭上眼睛。"

李长生脱了鞋，盘腿坐在床上。他的膝盖骨咔咔响了两声——常年弯腰干活的人腰腿都不太好。他坐稳之后，把两只手自然放在膝盖上，掌心朝上。

"先不要想灵气。"残魂的声音变得平缓了，像一个老教师在给刚入学的小学生讲课，"先感受自己的身体。从脚趾开始——"

"我脚趾挺好。"

"闭嘴。从脚趾开始，依次感受每一处关节、每一块肌肉、每一根骨头。不是让你检查有没有毛病，是让你把注意力从外界收回来，回到身体本身。"

李长生闭着眼睛，努力照做。

他先试着感受脚趾。左脚拇趾——他想起去年割麦子的时候不小心被镰刀划了一道，到现在还有一道疤。右脚的脚后跟——去年冬天冻裂过，走路的时候还会疼。

然后是脚踝、小腿、膝盖、大腿——他的两条腿就像两根烧火棍，硬邦邦地杵在那里。他以前从没这么认真打量过自己的身体——自己的身体又不是别人的，有什么好看的？可现在闭上眼睛一点一点感受，他发现自己的身体素质竟然还算不错。常年干农活干出来的肌肉，密度比健身房里吃蛋白粉练出来的硬得多。

"到了。"残魂说，"现在别感受身体了。试着感受身体外面。"

"外面？"

"你皮肤外面是什么？"

"空气。"

"不对。空气是呼吸的。皮肤外面——和皮肤接触的那个层面——是什么？"

李长生皱着眉头想了一会儿。

"是——温度？"

"对了。"残魂说，"灵气和温度一样，是一种你可以用皮肤直接感知的存在。但它比温度更薄，更细，更分散。普通人感觉不到它，因为皮肤上的感官被外界噪音全部占据了——冷了、热了、湿了、干了——觉知已经被这些高频刺激填满了。灵气这种低频微弱的信号进不来。"

"所以呢？"

"所以你得先把自己清空。放弃感受冷热。放弃感受风吹草动。让皮肤变成一张白纸。然后等着灵气自己落在纸上。"

李长生闭上眼睛，开始尝试。

听起来容易，做起来完全不是那么回事。他刚一闭上眼睛，脑子里就飘进来无数念头：明天要找零工。蛇皮袋里的衣服还没叠。楼下小卖部矿泉水两块钱一瓶。地里麦子该浇水了。爹的腿该买膏药了——他静不下来。他的脑子和农贸市场一样嘈杂。

"别急着赶走念头。"残魂说，"看着它们进来，看着它们出去。你不是在打仗。你只是在河边上坐着看水流。"

李长生试了第二次。

这次他不再和脑子里的念头较劲。那些念头——麦子、锄头、猪崽、欠的账——像河里飘过的树叶，一片接一片地流过。他只是看着，不动。他居然做到了几分钟。

当他脑子开始真正安静下来之后，他才感觉到了残魂说的东西。

空气中不是空的。

里面有东西。

很淡。像早晨第一缕阳光出来之前，空气里那种微不可察的"湿"。但这不是水汽。是能量。分布不均匀，像一团一团的、大小不一的棉花球飘浮在黑暗里。有的地方多一点——他身体右边靠窗的位置——有的地方少一些——门那侧几乎感觉不到。

"这就是灵气？"

"对。你现在感受到的是城市灵气的分布特征——零散、破碎、浓淡不均。"残魂的语气里带着三分满意，"农村灵气相对均匀，但浓度低。城市灵气是被人流量和地面结构搅碎了的——人越多的地方灵气越活跃，但也越混乱。"

李长生继续感受。

他发现灵气不只有"浓淡"，还有"颜色"。不是用眼睛看的颜色，是一种感官上的色调。大部分灵气是"透明的"——像白水，没有特征。但有些灵气带了"色"——他感觉身体右侧靠近窗户的位置有一团青白色的灵气云，还有一团偏黄的、感觉很燥热的灵气。

"青色的是残留的木系灵气。黄色的是土系。白色的是金系。黑色的——"残魂顿了顿，"往你左手边感受。"

李长生把注意力移向左边——房间的墙角。

那里有一团极淡极淡的黑灰色灵气。很稀薄，但确实存在。它不像旁边那些青白色灵气一样松散游荡，而是静静地沉在墙角，像一滩水淤积在碗底。

"碰一下。"

李长生在心里把那团黑灰色灵气往自己的方向引了一下。他没有手，没有工具，只有一个念头。

那团灵气动了。

它像是被某个磁极吸住了的铁屑，没有丝毫抗拒，顺着他的念头就飘了过来。飘的速度不快——大概像一片羽毛在微风里落下来——但方向很明确。朝着他的掌心碎片飘来。

然后它钻进了他掌心的碎片。

他的掌心微微一热。

紧接着他感觉一股极其稀薄的"东西"沿着手腕进入了前臂，再沿着骨头一路上行到肩膀，最后散在胸口——散了，彻底融进了他的身体。

不是什么强大的力量。只是一点微不足道的暖意。

但那一瞬间，他的整个身体都在欢呼。

不是比喻。是他身体的每一个细胞都在回应。那种回应比饿了三天的肚子吃到第一口馒头还要真实。肌肉在接纳这股能量，骨头在吸收，血液在用它冲淡某种长年累月积存的"干渴"。他不是在"吸入"灵气，而是在"吸收"它。

残魂沉默了好一会儿才开口。

"你的冥系灵根——果然是真的。"

"什么？

"刚才那团黑灰色灵气，在灵气谱系里叫'阴气'，也叫'浊气'。在古代修仙体系里，这种能量长期被归于'低等'和'有害'——普通的金木水火土修士遇到阴气会主动避开。因为阴气和他们的灵根不兼容，吸多了反而损伤经脉。"

"但对你——"

"它就像给干旱开裂的地浇了一瓢水。"残魂的音量抬高了半格，"你身体的每一寸都在吞它。那团阴气进你体内的时候，连一丝阻隔都没有。就像钥匙插进了锁孔。"

李长生低头看着自己的手。

那团黑灰色灵气已经不见了。墙角恢复了透明。

但他的身体还没消停。那股暖意虽然散掉了，可是他的每一个毛孔都在往外张——就像晒太阳晒得浑身通泰，骨节都松开了。不是错觉。他的皮肤表面温度确实升高了零点几度。

"继续。"

盘腿继续感知灵气。这一次，他不再被动了。他主动搜寻房间里每一处阴暗角落——床底下、柜子后面、墙角蛛网旁边——那些残留的阴气。城市的地下通道、下水道、老旧建筑地基层，都是阴气最容易淤积的地方。这栋城中村的老楼地基至少有三十年了，阴气藏得到处都是。

一个小时后，他把这间屋子里能吸收的阴气全吸干净了。

身体反应非常明显。

首先是饿。不是肚子饿，是"骨头饿"。他身体吸收阴气之后，像是打开了某个阀门，索要更多。

其次是精力充沛。他今天从村里坐车到城里、找活、参加聚会、一直折腾到半夜——本来应该很累的。但吸完阴气之后，他的疲劳感消失了。不是恢复了，是被替换掉了。阴气替换了他体内的某种枯竭感。

第三是他觉得周围更安静了。

不是真的安静。城市永远是躁动的——外面马路上有车，隔壁有人在打电话，楼下有人在刷短视频外放。但这些声音现在在他耳朵里变得很远。不是物理距离上的远，而是——他的注意力不再被这些声音拽住了。他可以自己选择"听"还是"不听"。

以前一直是外界拽着他跑。现在他可以选择把外界关在门外。

残魂说这叫"收神"——是修炼者入门的第一个基本功。把外散的注意力收回体内，把多余的感觉全部关掉，只关注自己。

李长生一个人坐在黑暗中，感受着体内那些被刚刚吸收的阴气在缓慢流动。没有功法引导的灵气流动是紊乱的，不成体系的，但即使如此，他的身体也在本能地运作。

"你记住这个感觉了吗？"残魂问。

"记住了。"

"以后每天都要练。这比吃饭重要。"

李长生没说话。他沉默了好一会儿，才在心里问了一个问题。

"残魂——城里比村里灵气浓多少？"

"大概两三倍。但城市灵气太杂乱，有效成分反而比农村低。尤其是对你这种冥系灵根来说——农村的阴气虽然淡，但纯粹。城里的阴气浓，但混着太多别的能量。你需要到一些阴暗湿冷的地方才能吸收到纯净的阴气。"

"比如？"

"坟地。地下车库。废弃厂房。百年老宅的地窖。"残魂的声音很平静，"以及——这座城中村的地基下面。我刚才感知了一下，下面三米左右，似乎埋着什么东西。年代不短。"

李长生往床上一倒，看着天花板上正在爬行的一只小蜘蛛。

这栋城中村，还真是越来越有意思了。

（第022章完）

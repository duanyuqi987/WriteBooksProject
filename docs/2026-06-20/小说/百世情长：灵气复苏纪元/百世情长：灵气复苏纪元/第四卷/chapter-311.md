# 第三百一十一章 相依为命的开始

昆仑山顶。雪停了。

不是真的雪停了——是裂缝缩小后，天魔气息不再搅动周围的气流，风力降了下来。没有风，雪就不会乱飞。一片一片的雪花从天上慢慢地、笔直地落下来。落在碎石堆上。落在碎剑片上。落在两个躺着的人的头发上。

林牧躺了不知道多久。大概是半个时辰。或者更长。他的意识在封神咒余波中时断时续。第一次醒来的时候，看到苏晚趴在他旁边的碎石上——她的练习剑还攥在手里。睡着了。或者晕了。她的脸上还挂着一道血痕——是刚才撞进天魔残念波时擦出来的。血痕已经被雪水渗淡了。

第二次醒来的时候，天已经快亮了。东边的山头被染成了金灰色。昆仑山的日出在他这个角度看尤其壮阔——从万米的高空俯视，太阳刚从地球的弧线边缘冒出来的光会包住每一座山峰。但林牧现在仰面躺着，看不到日出。只能看到天从深蓝变成浅灰，再变蓝。

他的左肩疼得很。不是"酸痛"级别的——是"骨碎"级别的。左肩胛骨外侧碎裂——大概还有几条肋骨出现了裂纹。体内灵力几乎为零——精血封印消耗了他体内所有能调动的灵力。经脉空空荡荡。丹田里的元婴缩成了拳头大小——闭着眼睛，一动不动。元婴在"沉睡"——这是严重灵力枯竭后的一种自我保护机制。元婴沉睡——意味着他暂时无法主动调用任何灵力。

也就是说——在元婴醒来之前，他和凡人差不多。

他动了一下右手。右手还能动。手里还握着剑柄。剑柄上的麻绳结已经被血浸成了暗褐色——是他的血。他把剑柄转过来看——剑身只剩不到两指长的一小段了。三道裂纹全断。剑废了。

他把剑柄放在石头上。看着天上慢慢变蓝的天。

苏晚醒了。她是被冻醒的——昆仑山顶温度大概零下四十度。她虽然开始觉醒了，但淬体五层的修为还不够抵御这种低温。她的睫毛上结了一层白霜。嘴唇发紫。手指关节冻得不太利索——但还是把剑先放下了，才揉自己的脸。

"你醒了？"她问。

"嗯。"

"疼吗？"

"还行。"

"你肩膀上那块——骨头露出来了。"

"知道。"

她从膝盖上直立起来。腿还有点晃。但她蹲到林牧旁边，把右手按在他左肩上。她不知道自己该怎么做——她没有学过任何治疗系的法术。她就是觉得自己的手该放在那里。放上去的时候，她的手心开始发热。不是体温的上升——是一种不太像灵力的能量从她手心往外渗。热量从她的手心透过林牧破损的正装进入皮肤、进入肌肉层、进入骨骼碎裂的位置。

林牧感觉到了。不是普通的温热——是"本源灵力"。不是后天修炼积累的那种灵力。是她灵魂深处自行释放的、属于她自己的灵力。这种灵力比常规灵力更"活"，带着一种非常独特的生命活性。活性会主动附着在破损的组织上，加速细胞分裂，促进骨痂生成。

"你什么时候学会这个的？"他问。

"没学。就是觉得——手放这里应该有用。"

"有用。"

她手上的热量持续了大概一刻钟。然后她自己撑不住了——她的灵力储备也很低。停下的时候她靠在碎石上，脸色比刚才白了很多。但林牧左肩的伤口明显缩小了一些——至少不再往外渗血了。骨头没有完全愈合——但骨裂处的组织不再肿胀了。

"你刚才在昆仑那边。"林牧说。"挡在他面前的时候——剑尖上那道淡金色的光是你自己发出来的？"

"大概是。"

"怎么发出来的？"

"我想着：不能让他碰到你。然后手——大概是说手心——从里面热了一下。剑上就亮了。"

林牧看着天。天空蓝得很干净。裂缝那边的暗紫色光芒被压回了裂缝深处——裂缝宽度从八十丈缩到了大概二十丈。阎锋暂时退了——但不是撤退。是重新计划。他会回来的。在下一次裂缝张开的时候。

但这些都是以后的事。现在——他有一个更重要的问题需要回答。

"你还记得你飞来的路上看到了什么吗？"

苏晚想了片刻。"看到了一座很高的山。山上有白色的楼。楼前面站了一个人——和我在梦里看到的一样。但从天上飞过去的时候，我发现那栋楼不是白色的——是淡青色。梦里的颜色不对。"

林牧没有说话。但他眉心轻轻地动了一下。苏晚描述的那座山是青云宗的主峰。那个站在楼前的人是第一世的林牧——在练完功后站在楼前等她下修炼课。那个角度、那栋楼、那个人——是苏晚的第一世记忆。不是他的。

"你还想起了什么？"他问。

"想起了一碗面。"她说。"不是真的面——是在那个白楼的食堂里。我闻到了面的味道。煮得很久的——西红柿鸡蛋面。不放糖。放了一点醋。"

林牧的右手忽然抓紧了碎石。碎石硌进他的掌心。第一世的苏晚喜欢做西红柿鸡蛋面。不放糖。放一点醋。这个味道，他整整三百多年没有再闻到过。她在第一世死后——这个味道就从这个世界上完全消失了。因为没有人知道这个配方。没有人知道苏晚做这道面不放糖。没有人知道放醋的量是多少——大概小半勺。勺子是木勺。这个木勺后来大概进了焚烧炉。

而她记得。她被封印了几百世都没有松开那个封印。现在封印开始松开了。她在苏醒。苏醒的速度比林牧预计的快了一倍。阎锋说她"开了百分之五"——但百分之五就已经记得一道面的味道了。那百分之百呢？会不会记得她是自己契约的"主印"——而这个契约一旦双方同意，就无法解除？会不会记得所谓的"永世分离"到底意味着什么？

风吹过昆仑山峰。碎石堆上的雪被吹起来，在晨光中形成了极细弱的"雪幕"。雪幕里，林牧看着她的侧脸。她正低头看自己的手——手心里还残留着刚才疗伤时发出来的淡金色光晕。她用拇指搓了搓手心——光搓不掉。

"这个以后会一直在吗？"

"不知道。"

"你说——我们以前见过。三百多年前。那个时候——我会飞吗？"

林牧的眼睛闭了一下。第一天她第一次被选上青云宗弟子资格的时候。她兴奋得一夜没睡。第二天早晨去练剑场的时候，她拉着他——"你教我飞"。

"会。"他说。"而且飞得比我好。"

苏晚把练剑横在膝上。她的手还冻着——握住剑柄的时候关节不太顺畅。但她的剑姿已经比在蜀山上的时候进步了一大节——剑尖不偏了。拇指放在了正确的位置上。手腕的姿势不是"刻意"的，是"记起来了"的。

"那就好。"她说。"以后还是要飞的。"

太阳完全升起来了。金光照在昆仑山顶的雪上，把暗紫色还没有褪尽的天魔气息一点一点地赶回裂缝里。远处——东边和南边的天际线上，四道不同颜色的灵力信号断了。每一道信号断的时候，天空会闪一下——先是长白山方向，一道白色剑光收敛完毕。然后再是秦岭方向，青色和黑色两道光尾相继消失。再是青藏高原——昆仑派的主场。最后是南海——三道不同质的灵力在水天之间炸成了一场小烟花。

四眼全关了。

林牧知道这个不是因为看到那些光。是因为阎锋在裂缝深处发出了一声低沉的、压抑着愤怒的灵压波动。七星阵被破了。他从上界带来的最后一点"兵力"——四个天魔副将——被六位掌门拼命拖住并逼回了裂缝另一侧。现在只剩一个昆仑主眼被林牧用封神咒缩到了二十丈。阎锋还能在二十丈的范围里活动——但二十丈不够支撑一个七星阵。不够吞灵脉。不够恢复到真仙巅峰。

阎锋输了——还没走。但他退回了裂缝深处。退到了一个连灵识网都穿透不到的地方。

林牧在碎石上躺了一天一夜。他在晒太阳——太阳光里也有零星的灵气，可以用身体缓慢吸收来替代丹田不能运转的空档期。苏晚没有离开他的身边。她把练剑插在碎石堆旁边，让剑尖对着天空——她做这件事的时候没想任何理由。就是觉得"这样插比较安全"。

然后她去山下找了些能烧的东西。昆仑山顶没有树。但裂缝附近的雪地上散落着一些被天魔气息烧焦后掉下来的枯枝——大概是以前的某个仙人在此地留下的灵木残枝。她用剑劈了几根，搭成一个小小的篝火堆。她没有火折子。于是把手指凑到木头上——心想：热。然后手指真的热了一下。木头点着了。

火焰很小。但她把受伤的脚——在裂缝碎冰上划伤的脚底——放在了火旁边。然后把林牧也挪到火旁边。他的左半身靠着她——她把他翻过来的时候力气不够，用了腿撑着，腿上的绷带渗出了一圈淡红色的血痕。

"不用管我。"他说。

"不行。"她说。"你说你等了我三百多年。我照顾你几天——不过分吧。"

篝火在清晨终于燃尽。黑烟在长天下升成极细的一小缕。苏晚把林牧的剑柄捡起来，和他的水壶并排放在碎石堆旁——水壶里，锦鲤还在吐泡。它似乎是这一堆东西里唯一完全不担心的生物。因为它知道苏晚醒了。因为每次苏晚转世，它都会认出她。而且每次苏晚转世——不管隔了几十年、几百年——她都会做同一件事：在水干之前先把鱼喂了。

而林牧——林牧只需要做另外一件事。这件事他从第一世到现在一直在做。

等她醒来。

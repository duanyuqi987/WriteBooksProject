# 第五百一十四章 心灵彻底相通

灵魂共鸣的练习进行到某个阶段时，迎仙台上空出现了极罕见的上界天文现象——"双星伴月"。这个月不是下界的月，是上界的一颗极暗淡的小型天星，每年只有极短暂的时光会出现在第一重天的天顶。在双星伴月的晚上，上界的引力场会产生极微弱的空间振动——这个振动频率和道侣灵感层次有极深的耦合。仙缘司把这个晚上称为"心月夜"。传说心月夜这天晚上，达到灵魂共鸣的道侣有概率解锁比灵魂共鸣更进一步的完全心灵相通——"通灵"。

林牧和苏晚对这夜做足了准备。他们在道场上铺好了蒲团。两把剑交叉靠在蒲团后面——一把刻"晚"，一把未刻（林牧的剑上从来不刻字，但剑柄上也被磨损出了她经常握着的位置）。功德绳外加上古琴第四弦——苏晚把琴横放在蒲团旁，以备需要时用琴弦的震频做参照。

双星伴月开始于那轮最小最暗的银太阳降到地平边缘的时刻。两颗略微发蓝的小型伴星在月星旁边极其缓慢地划过，它们的轨道叠加在月星的暗面上形成了两个极淡的亮环。这一刻上界的空间引力场发出极其柔和的低音——不是声音，是空间波动，传到灵核中像一阵极远的潮汐。

苏晚和林牧同时把灵魂共鸣的索提到极限频率。两颗灵核以一种极其高效且极其精确的方式在来回振动。然后"通灵"发生了——不是他们主动探索到的，是双星伴月的空间波把他们两个人的灵魂在瞬间推入了对方的灵核内核。那个内核是他们自己的意识中心——感知着自我，也同时感知着对方的自我。这是一种极难以形容的状态——他们的灵魂完全处于半重叠状态，各自保留着自己独立的人格但又在意识层面合为一体。不是"一个人控制了两个身体"——是"两个人在各自的身体里同时感受到完整的存在和完整的共处"。

通灵状态只持续了极短暂的时光——但这个时间长度足够他们在各自的灵魂中直接体验到对方所有的那一万年的累积。苏晚不再是看他的记忆——她以第一人称感知了他是如何百次寻找自己、如何每一次找到又失去、如何在每一世她用新的不认识的眼看着他时，在心里自己告诉自己"没关系，这世不认识，下世还会认识"。林牧也不再是听她讲述那些记忆——他以她的感知回溯了那一切——每一次他找到她时她的灵魂深处有个被封印的信号在拼命地喊"我认识这个人"，但嗓子喊不出来。

通灵结束后两个人各自恢复了自己的独立意识。他们互相望着对方的眼睛——瞳孔里都同时映着两道小小月星的淡蓝伴星。沉默了片刻之后，苏晚说了一段话——不是用功德绳，是用嘴一个字一个字很慢很清楚地说出来:"心灵完全相通——不是我知道你全部的想法。是我知道你已经知道我知道。是闭环。我现在知道——你为什么每次看着我时不说话。因为你把话都堆在心里最安静的那个角——怕我一听就心疼。我听完了。我全知道了。现在那角不用你一个人守了。我们两个人守。"

（第五百一十四章 完）

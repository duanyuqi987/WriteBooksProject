# 第700章 三驾马车

永恒学府的教学正式启动。

课程体系的核心设计者就是陈霜本人。她花了整整两年来构思这个体系，期间否决了至少两百个方案。她的标准很固执——任何方案只要暗示"某类知识比另一类更重要"就直接打回。

最终的课程架构是横纵两条线。

纵轴——三大领域：修仙学、科技学、艺术学。每个学生都必须修够三个领域的必修学分，不存在偏科就放任的豁免。一个修仙天才也必须学会基础数学；一个科技神童也必须上灵根理论课；一个艺术天才也得明白修士的等级体系是怎么来的。横贯教育不培养偏执狂。

横轴——通识课：伦理学、历史学、法学、社会学、宇宙学、文明比较学。这六门通识课各有深意。伦理学教人辨别善恶——不是教人服从某套"官方道德"，而是教人用逻辑和感性双重工具去分析每一个道德两难。历史学用的是纪念馆的直接数据——学生可以在课堂上触碰意识水晶，亲眼看到那个弓箭手折弓跳城的夕阳、那个家庭主妇切菜哼歌的早晨、那个孩子在干旱土地上浇水的背影。法学用的是《永恒法典》全文加注——学生必须逐一读完六卷法律条文，并在期末写一篇论文：如果让你修改其中一条，你会怎么改，为什么。社会学让学生理解不同境界、不同种族、不同文明混合生活的现实——不是讲抽象理论，是让学生去冥都广场上做田野调查，访谈各种族的移民。

文明比较学是最重要也最容易被忽略的通识课。它综合了旧纪元一千二百个文明的兴衰档案，把所有文明的兴亡规律做了横比——帝王制、贵族制、民主制、修仙霸道、科技霸权、宗教神权、生态共生——全部放在同一个分析框架里。学生上完这学期后，在期末论文里最常见的总结是这样一句话："所有活满五万年以上的文明，无一例外都做到了两件事——普通人活的体面，强者不视自己为法律。"

这些通识课全部由法典院和大学联合开发，确保教学内容与《永恒法典》的价值观不冲突——但也不是法典的单向灌输。学生可以在课堂里批判法典的某些条款，提出合理的反驳和修改方案。通识课的核心目标只有一个：让每一个毕业生都成为一个合格的帝国公民——不管你将来是去打仗、去写代码还是去画画。合格的帝国公民不是无条件爱国者——是懂法、懂理、懂普通人的感受、知道帝国为什么该是这样的帝国。

开课第一天，陈霜在全校师生面前讲话。她没有用讲稿，站在讲台上一脚踩着地一脚搁在讲课台上，姿态很像当年在西北大漠骑骆驼的样子。

"各位同学，"她说，"你们来这所大学之前，可能已经听了很多关于'境界'、'修为'、'天才'的传说。今天我告诉你们一件事——在这所大学里，那些词，不作为衡量你们价值的标准。"

她扫视全场。一万两千双眼睛盯着她。

"在永恒学府，你的价值体现在三件事上：你学到了什么、你创造了什么、你帮了别人什么。"

"跟境界无关。跟家族无关。跟灵根品级无关。"

"所以，放下包袱，好好学。"

这段话被后来的校史记录为"陈校长开学三训"。简洁到了近乎粗暴的地步，但在场的每一个学生都听进去了——因为这话来自帝国皇后本人，来自一个神级修士对新入学新生的第一声问候。

课程的实际运转比预想的顺利得多——但也有预想之外的摩擦。正是那些摩擦，证明了融合的必要。

开课第一个月，修仙系和科技系的学生在第一堂联合实验课上爆发了一场小型争吵。实验内容是用灵气和电磁场双重手段同时探测一枚隐藏的灵脉节点。修仙系的学生习惯用神识扫——闭上眼睛、调动感知、形成灵域扫描。科技系的学生习惯用仪器测——架好传感器、校准电磁波、读取数据。两组人互相看着对方犯愁。修仙系的学生觉得"仪器的电磁波干扰神识"，科技系的学生觉得"神识太主观、没法量化为标准数据"。

带课的老师没有出面调解。他在旁边看着——这是陈霜下的死命令：第一堂联合课的摩擦不允许教师调停。学生必须自己找到协作方式。

于是他们在实验室里僵持了整整一个下午。直到一个修仙系的学生忽然说："你把传感器贴在灵脉节点的北侧——北侧灵气密度最低，电磁干扰会最小。"科技系的学生反问："你怎么知道北侧密度最低？"修仙系学生答："神识扫的。"科技系学生沉默了几秒，然后把传感器搬到北侧。数秒后，屏幕上波形剧烈跳动——仪器在同一时刻测到了灵气波动，频率曲线跟神识感知完全吻合。

两组人对视了一眼。然后一个科技系的学生忽然笑了："也就是说，你们的神识，本质上是一种没有传感器的传感器？"修仙系的学生反呛："你们的传感器，是一种没有神识的神识。"两人互相看了对方片刻，然后同时点了头——不是因为被说服，是因为彼此都有点道理。

这种跨界灵感在随后的课程中层出不穷。修仙系的第一年课程不是教战斗，而是教灵根基础知识——灵根如何生成、种类如何分辨、与灵气环境如何交互。这门课没有哪个学生逃课——因为科技系和艺术系的学生也都必须修。灵根理论和量子场论有什么共通之处？一个修仙系学生写了一份课后小论文，标题是《灵气共鸣与超对称场——类比推理》。这份论文后来被学院的跨学科期刊刊载，并被帝国修仙研究协会推荐为推动修仙理论科学化的重要里程碑。写论文的学生的最高灵根只有二品。但他的逻辑能力是五品——不在灵根里测，是从旧纪元"王宇因子"觉醒而来的。

科技系请来了帝国最前沿的跨维度通讯工程师，教学生理解怎么在不同维度的宇宙之间传输信号——这项技术是李长生从太初维度广播的遗迹中提取并授权的。学生们惊讶地发现，这个技术跟修仙界的"跨域神识传播"原理是相通的——同一个物理内核，两种实现方式。一位同时是科技教员和灵气理论研究者的教师总结了一句："科技和修仙，不是两个不相关的领域——是同一座山的两条登山路。山顶是同一个。只是路上看到的风景不同。"

艺术系更特别。音乐教授——那位来自赤星联邦的古文明音乐家——在一次课上弹奏了一段由宇宙背景辐射转化而成的大提琴曲。他用行星磁场作为琴弦，用恒星风作为琴弓，用一种叫做"熵谱琴"的古老乐器将宇宙的原始信号转化为人耳可听的声波。当那段音乐在大教室里响起的时候，在场的修仙系学生中有几个直接开始抹眼泪——不是因为音乐煽情，而是因为他们发现那段音乐的频率波形，跟金丹内部灵气共鸣的频率波形完全一致。一个修仙系的学生边哭边说："我的金丹在跟着它转。像我的金丹本来就是这首曲子的一个声部。"

科技系学生也安静了——他的仪器屏幕上显示这段音乐的频率结构和宇宙微波背景辐射的原始频谱有高度对应。但那个瞬间他关掉了仪器屏幕，只是坐在那里听。

三驾马车的融合不是口号。它正在发生的。不是被设计和规划出来的——是被放开了枷锁之后，知识自己找到了知识。

那一刻陈霜站在教室后排，没有出声，没有鼓掌，没有上前说"你们做得很好"。她只是靠在教室后墙上，两只手交叉在身前，目光从修仙生扫到科技生扫到艺术生——然后轻轻笑了笑。那笑容跟他当年在西北大漠目送李长生第一次走出沙漠时的表情很像——不是欣慰，是确认。确认一件漫长的事开始了，并且第一次迈出的脚踩到了实地。

她的大学——她的新使命——已经启动了。而她选择启动的方式，不是用权威命令三驾马车走得齐头并进，而是给它们松绑，让它们在自由的草地上自己发现：它们从一开始就不该被分开圈养。

（第700章完）

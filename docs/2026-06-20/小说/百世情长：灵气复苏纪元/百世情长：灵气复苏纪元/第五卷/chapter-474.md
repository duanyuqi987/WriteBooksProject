# 第四百七十四章 双星大成

从南离城回迎仙台之后，两人把自己关在双星图道场上连续修炼了很长时间。

不是闭关那种完全的与世隔绝——他们每天还是会吃一点东西，会在道场边缘的古树下散步，会在晚上坐在阴阳鱼交界线上聊天。但所有的谈话都围绕着功法。苏晚在笔记上把十六篇功法的要点列出了一张极其详尽的表格——每一篇的核心口诀、灵气运转路线、对应的灵核变化、可能出现的岔路。表是用竹简上的空白背面写的——她的财务做表功底在修仙之路上有了意想不到的用场。

林牧每天对照她的表来检查两个人的修炼进度。功法从第一篇到第八篇练得很快——因为前八篇是基础阴阳交融。但从第九篇开始难度陡增，因为进入了"星核重塑"阶段——要求两个人把之前植入灵核的金焰种子炼化成自己的第二颗灵核。双灵核在体内同时运转——比单一灵核的修炼难度高了不止十倍。第九篇卡了一整天，第十篇卡了将近两天，第十一篇——"双星交辉"——需要在两枚灵核之间以共振频率不断地切换主导权，每一次心跳的间隔都要精准到不分毫。

苏晚在第十一篇上差点出了岔子。她的灵核在一次主导权切换时忽然产生了极短暂的失频——没能立刻赶上林牧的频率。共振通道在那一瞬间中断，她体内还在运转的金焰失去了约束，从她丹田中逆喷入经脉。烧伤的疼痛让她弓起了背。她咬着牙没有出声——但林牧听出了她呼吸中那一丝极细微的异样。他中断了功法运转，以比平时快几倍的速度走到她身边，把手按在她背上，用他的灵核强制制冷帮她压下了经脉中的金焰。

"下次你一察觉到跟不上就立即收工。"他说。这是他在洞府炼丹时就对她说过的话——她又犯了一样的毛病。

"快赶上了——我不想拖你进度。"苏晚说。她额头上全是刚才金焰灼伤时冒出的冷汗，但她的眼睛还是亮的。

"你的进度就是我的进度。"林牧把手从她背上拿开，低头看着她的眼睛。"双星篇要求同步——你慢我也慢。所以不必赶。慢也是你。快也是你。我等。"他把最后两个字说得很轻，但每个字都在古树余荫和银色树叶的映衬下显得很重。

接下来的修炼速度调整了——不再以林牧的速度为基准。以苏晚的舒适速度为基准。每次切换主导权，林牧都提前半息向她发出信号——不是语言，是共振通道上的一道极轻极柔和的光脉。苏晚循着光脉调整频率——再也没失频过。

又过了几天，第十六篇完成。两颗灵核同时在两枚灵核的基础上长出了第二颗——炼虚中期的第二内核。双灵核同时在所有星级真仙的灵核行列中上了一个台阶。从炼虚初期跳到了炼虚后期。差一步合道。而双星篇全套功法的附带效果就是——两人在完成最后一页的灵气运转后灵核自动进行了频率检定——检定结果显示两颗灵核全部达标为中阶仙境。第十六篇修毕的那一刻，双星图上空忽然出现了极其罕见的星空异象——五轮太阳同时发生超低强度的共鸣——在道场上洒下了五道交缠的彩色光线。

松鹤仙人站在道场外。他看到那五道彩色光柱同时降在两个人身上——他捋了捋胡子，转身往迎仙台的方向走。他要去仙宫帮他们送一份中阶仙的登记申请表。新飞仙不到一甲子升中阶——这是近三千年来第一次。松鹤仙人走的时候脸上的笑意藏得很深。

当晚两人背靠背坐在阴阳鱼交界线上。苏晚把手腕上红绳上面挂着的小木牌拂了拂。"今天你的灵核一共帮我调了大约二十三次的频率调整。每次调整我都记下了——等老了写回忆录的时候，我就写——他这辈子帮我调过最多次灵核频率的那天，是双星篇完结的快这天。"

林牧把下巴搁在她肩上。他看着头顶那五轮在不同方向缓缓沉降的太阳。没有说任何话。但他的手指在红绳的木牌上摸了一下——那个"晚"字被他用指尖一点一点地描了一遍。

（第四百七十四章 完）

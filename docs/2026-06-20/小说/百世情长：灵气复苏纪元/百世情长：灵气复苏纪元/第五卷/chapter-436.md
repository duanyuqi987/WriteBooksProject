# 第四百三十六章 地底六万丈

坠落。

林牧的身体在阵法通道中急速下坠。周围是旋转的金色光环，像是被无限拉长的弹簧。光环之外是黑色的岩壁——他能感觉到岩壁在以极快的速度向两侧退开，但黑暗吞掉了所有细节。他只能听到风声。不是外面那种吹在脸上的风，是一种被压缩在通道里的、高频的呜咽。像有什么东西在通道的深处哭。

他默数自己的心跳。化神期修士可以精确控制心率的次数。从洞口下坠开始，他的心跳加速了大概七次——对应的深度大约是三千丈。通道的压力开始明显增大。不是空气的压力——是更根本的东西。是神识被压缩的感觉。越往地下深处，神识能覆盖的范围就越窄。在地面上他可以感知方圆十里的灵气波动。到了三千丈深，感知范围已经缩到了一里。

六千丈的时候，外面的温度开始变了。

不是变冷——是变热。通道周围的岩壁从黑色变成了暗红色，偶尔有岩浆从岩缝中渗出，在光壁上溅起一朵一朵小火花。整个通道在发光。不是林牧自己点亮的那种光，是岩浆层本身的辐射光。橘红色的光把金色光壁映成了铜色。

他继续往下。

一万丈。他感觉到后背那层温热开始发烫——苏晚给他织的保护层正在自动激活。通道内的温度已经高到了连化神期修士都会感到不适的程度。他的额头渗出了一层汗，汗珠刚出来就蒸发了，在眉毛上留下一道白色的盐痕。

两万丈。压力已经大到让他不得不减缓下坠速度。他运起灵气在身体周围撑开一个防护罩，将通道的压迫力卸掉三成。防护罩的消耗相当大——在这个深度，他的灵核每一次旋转带出的灵气明显变少。不是他的灵核出了问题，是这个深度的灵气浓度太低了。越往地底，常规灵气越稀薄，取而代之的是另一种更古、更沉、更猛烈的能量——龙脉之气。

三万丈。他停下了。

不是因为体力不支。是因为通道变了。原本整齐的金色光环开始变得破碎——像是被什么东西从外面砸过了。光环之间原本无缝的衔接出现了缺口。林牧悬在通道中央，用匕首碰了一下光环的缺口。匕首的尖端刚一接触到缺口边缘，就传来一股巨大的吸力——是虚空裂隙的撕扯。通道在这个深度已经和虚空裂隙交界了。

他必须小心。虚空裂隙不是物理的裂缝，是空间本身的裂缝。掉进去不是被压扁——是彻底消失。从三维空间里被抹掉，连灵魂都不会剩下。

他沿着通道继续向下缓慢移动。每移动一小段距离就要停下来探测前方的光环是否完整。他的防护罩已经消耗了四成灵气，后背那层保护层在持续发热——苏晚的灵核保护层正在以极快的速度消耗自身来抵挡外面的压力。他不知道她能用多久。他需要尽快。

四万丈。通道忽然变宽了。

不是逐渐变宽，是忽然间从一条窄窄的管道变成了一个巨大的球形空间。林牧从通道壁上的缺口挤出来后发现自己在悬浮在空中——脚下没有实地，头顶没有岩层，四周一片漆黑。只有中间有一个东西在发光。

一朵花。

准确地说，是一株长在虚空裂隙入口的花。花的外形极美——九片花瓣，每一片的颜色都不相同。赤橙黄绿青蓝紫——第八片是纯白色的，第九片是透明的。花瓣在漆黑的虚空中缓缓旋转，每一次旋转都释放出极其微弱的荧光，荧光落在他手上的皮肤上就会产生一种温热的感觉。

九转还魂草。

林牧在距离那朵花大约十丈的位置停下。他没有贸然靠近——不是害怕虚空裂隙的撕扯。是因为他看到了别的东西。

在九转还魂草的正下方，虚空裂隙的入口处，有一个坐着的骷髅。

骷髅盘腿坐在裂隙的边缘，身上的道袍已经风化成了薄薄的一层灰。骷髅的脊椎很直，头微微低着，一只手放在膝盖上，另一只手拿着一个空的药瓶。药瓶的瓶口朝下——里面的东西已经在尸体化成白骨之前就被用掉了。

林牧悬在空中，看着那具骷髅。他在骷髅的道袍残片上看到了一个残破的徽记——青云宗的标记。万年前的标记。不是现在的青云宗，而是真正的、万年前他曾经待过的那个青云宗。

这个人——是他的同门师兄。或者说，是万年前青云宗里某个修为不够、没能飞升、最终耗尽寿元死在这地下深处的师兄。

骷髅面前的地面上有三行字。是用灵气直接刻在岩石上的。字的笔画很深，即使过了万年依然清晰可辨：

"丹已成。然寿元已尽。飞升道友未归。坐化于此。"

林牧悬在空中，看着那三行字。

丹已成。他炼出了九转还魂草为主药的丹药——寿元丹？还是有其他丹药？——但来不及了。他的寿元已经耗尽了。而他的道侣——"飞升道友未归"——已经飞升去了上界。没有回来。也许是不会回来，也许是回不来。总之，这个人在这里独自坐着，等着，等了一万年，还是没有等到。

林牧闭上眼睛。

他想起苏晚在山脊上等他回去。两顶帐篷。灵能灯。篝火的余烬。绿豆汤冰在保温壶里。

他睁开眼睛。

他走到骷髅面前，跪下去，磕了一个头。

"青云宗后辈林牧——拜别前辈。"

然后他伸出手，小心翼翼地避开虚空裂隙的边缘，将那株九转还魂草的花茎握住。花茎在他手指触到的那一瞬发出了一道极其明亮的白色光芒——他没有任何感觉。不是被光炫花的那种没有感觉，是真正意义上的"没有感觉"。仿佛那道白光不是在这地下几万深处发出的，而是在某个极远极远的地方——在时间的原点上——发出了极其短暂的一闪。

光芒消失后，花已经在他手里了。九片花瓣完好无损，连同根须一起被他托在掌心。

他没有立刻离开。他又看了一眼骷髅对面——在骷髅道侣应该坐的位置——地面上也有一行字。字迹不同。更纤细，更柔软。是那个飞升的道侣在离开之前留下的：

"待我寻得归途，定来寻你。"

他们没有等到归途。

林牧把九转还魂草小心地放进背包的夹层里，转身飞向通道出口。他飞得很快。不是因为怕虚空裂隙——是因为后背那层保护层的温度正在下降。不是变凉的那种下降，而是忽然之间热度减弱了大半。这说明保护层在高速消耗之后已经快要耗尽了。保护结构需要她持续的灵气支撑——她此刻在地面上的洞府里，一定正以极快的速度消耗自己的灵核。

"苏晚。"

他低低地喊了一声这个名字。

然后他把速度提到了极限，朝洞口冲去。

（第四百三十六章 完）

# 第200章 漫漫修炼路（第二卷终章）

苏小晚二十六岁那年秋天，和先生一起爬上了桃源村后山的山顶。

不是偶然——是她主动说要来的。那天清早她敲他的门，背着一个小背包，里面装了两块烙饼、一杯热水、一本那本小红笔记本。她说"先生，今天我们别练功——去爬山吧。爬后山那个高的。我想站高一点看看我们的村子。"

他放下手里的修竹刀，换上件长袖旧衬衫，跟着她出发了。从村口往后山的小路一直往上，穿过紫灵土坡，跨过一道细小的山溪。猫没跟——年纪大了，不再爬陡坡。锦鲤在水中把灵觉投射到山顶，也算参与了。两个人走得不快，一边走一边说那些最无关紧要的日常琐碎——她在镇上杂货铺看到了小时候吃过的那种糖葫芦，买了半斤回来，结果没吃几个被猫先舔了糖衣。他笑着骂猫不该吃糖。

走到半山时她有些气吁，就地找了块大青石歇脚。她从石头上眺着下面的桃源村——那么远，村口的那棵皂荚树只能在视野里看出来一个翠绿的小圆点。她指着那个绿点点说"先生——你看我们的皂荚树那么小。在你没搬来之前，那棵树就这么大吗？"

"那时这棵树还矮一点。"

"你搬来以后它就长了——"

"大概是鱼的鱼缸水养了它。"

她笑说:"鱼缸水还能养树——那鱼是神仙——"然后站起来拍拍灰继续往上走。他没解释。其实还真是——锦鲤水中的灵气滋养了整棵树。

登顶在午前十点钟。山顶不是特别高——比峰线差得远——但足够看到整个山谷的全貌。桃源村小小的卧在山谷里，像一堆细小的白米粒。稻田和茶园成块平铺在山坳间，小河如细细银带曲折而去。往北边看，层峦之外的更高山线隐在云里。她站在最前面的那块大石头上，让风把她的头发吹得呼呼直响。他站在她后侧，拿竹杖站着，看着她。

"先生——这个世界好大。桃源村原来这么小——"

"小刚好。太大的地方不容易打扫。"

她说:"也不容易养猫——"

他点头。她用袖口撞了一下被风吹出的鼻涕泡。

她忽然低声自言自语一句:"我从这里看下去——觉得桃源的每一点都跟你有关。皂荚树是你树下站的地方。那口井是你夏天打水的地方。小学门口那个台阶——你送过我多少次。那边河边——我在那边滑倒你拿竹杖拖我。这边这片山上——每一块地好像都踩过你脚印。"

"大概因为我在村里的这些年里差不多走遍了全村的每一条路。"

"不。"她转过身，正向着他。"我不只是说去的地方——我是说，整个成长里每个角落都有你的影子。从我有记忆开始——你就在。"

林牧看着她的眼睛。这一刻他知道她不是在前世回忆——她就是纯粹地以"这一世苏小晚"的身份在倾诉。她用自己当下的感官与记忆，复盘了他二十三年来的存在对她的意义。这个"复盘"没有追恨——有的是感激，依恋——还有一种比师徒更紧密、但被他谨慎守着不逾界的深情。他分得清。

他没有回以任何越界的话。只是把竹杖放在石上，用手轻轻拨她被风吹乱缠在耳环上的头发——轻柔到像是整理被风挂到树枝上的蜘蛛丝。那一下碰到的时间比她三岁那年在皂荚树下碰猫尾巴长不了很多。

"二十三年前你从皂荚树下走来。今天你站在山顶上。二十三年的时间不长也不短——正好够一个小孩长成一个站在山顶上往下看的人。以后的路你继续往前走——先生如果跟不上，就在这村里等你。等你回来，给你泡茶。"

她的眼眶有些发烫，但没哭。她把头低下轻拍了一下他的手背。"你肯定能跟上。你不是一般人——就算是，我也等你。"

下山的路比上山时更安静。夕阳把整个山谷染成金红。下到山腰时可以看到皂荚树的影子拉得很长很长。阳光在老树上抹了一层油光。猫在那棵树下卧着——等他们回家。

晚上苏小晚回自家房间。她重新翻开那本小红笔记本最后空白的一页——在今天日期旁写了一段话:

"今天是第二卷的结尾。我站在山顶看村子——先生站在我身后。山很小，村子也很小。但我从这里看去，所有的小事串成了一个圆形。起点在皂荚树，终点在先生拄着竹杖的身影。圆没有断——未来还要画下去。明天开始第三卷的第一页——从今天晚上的这口热茶开始往下描。我不再想还能走多远——我只管走下去。他会一直在路上。——苏小晚记。"

那个时刻她不知道她自己是第三世的苏晚——也不知道自己背负了轮回锁和百世情缘。她只是以她自己此刻的"主人"身份写完了这本第二卷生命笔记。她合上本子，对着窗外皂荚树的月光望了许久。明天早上——她会继续修炼。

夜更深。林牧坐在自己书桌前。他把四十年来从青溪镇到桃源村——从第二世邻居到第三世先生的所有关键记忆凝成一简小小的滚动卷轴封印在灵记中。他在卷轴上只留了两个字:相敬如宾——第二卷标题。第二世他守在她的街道对面，以相敬如宾的距离——没有碰她的手。第三世他牵着她的竹杖把她培养到了淬体后期——但最重要的距离和尊重仍保留在师徒身份内。

他在卷轴最后写下这样一段话:

"从青溪镇到桃源村，从林秀芝到苏小晚，从第二世的邻居到第三世的先生。我守了她六十年——她只认识我四十五年。第一世没有相守到白头。第二世隔街相望未越界。第三世教她识字、练功、画猫——直到今天她站在山顶往回看。她在山顶说:'每个角落都有你的影子——'。我想那是她在这个轮回中给予我最高的肯定。虽然她还不知道前世，不知道我们的契约，不知道那些从来没说出口的爱。但没关系。我有的是时间。她有的是轮回。我们会一直走下去。不管多少世。"

写完他把笔放下。猫从枕边起身，把下巴放在他的手腕上。锦鲤在水中慢慢游了最后一圈停下。木屋窗外那棵皂荚树在晚风中轻轻摇枝。月光把村庄压得很静。

他将卷轴收入灵魂印记备份。然后吹灭油灯。新的夜开始了。明天是第三卷第一天的第一笔。第三世的漫漫修炼路仍长远。第三卷、第四卷——第四世、第五世——无论还有多远，他会带着今晚她在峰顶对风的宣言继续出发。而此刻——第二卷在月光中静静合上。

**第二卷《相敬如宾》终。**

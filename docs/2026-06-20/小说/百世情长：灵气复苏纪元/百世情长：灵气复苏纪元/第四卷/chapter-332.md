# 第三百三十二章 双剑合璧的契机

战后第五年。林牧恢复元婴初期——这次重新凝成的元婴比之前年轻。不是因为本源补回来了（本源大约恢复到战前的四成），而是灵魂在经历这次"抽空-重新积累"后，对灵力的亲和力反而比以前更高。像是水库被清了一次淤，新存的水更干净了。

他坐在蜀山后山的练剑场，重新炼他的剑。这柄剑是赵明远让蜀山剑炉为他新铸的——不是名剑，就是他画的那张图里的剑样：长三尺，宽一寸半，上有三道灵气槽。三道槽的间隔、深浅和他碎了的那柄一模一样。但这次剑身没有预存裂纹——而是三道颜色不同的精灵气槽，每一槽都有一颗他本人的精血包在核心——这铸剑法叫血剑——比旧的那柄"废剑"要强上许多。剑柄上还是缠着麻绳——麻绳就是清泉镇那个打铁铺老铁匠用自己种的老麻搓的。

赵明远问他："此剑何名？"

他说："还旧。"

苏晚在旁边练剑。她现在是元婴中期——封印解开百分之五十。修为境界已经反超了他。但她练剑时全无"比剑"的意思——她所修的速度不算快，但每一剑的"度"极其准。她说那是因为在急诊习惯了在紧张环境下保持手稳。林牧见过她将一枚苹果放在松树横枝上——然后退十步、出剑、苹果掉下来完好无损——只是果梗被齐齐切断。

两人开始在练剑场上尝试配合剑术——不是想造什么新招。是一天下午无意间碰出来的：苏晚在右侧练撩天式——林牧在左侧正练沉腕式——两人不小心同时在两招的"过道"中交剑。他沉腕，她撩天——两道剑尖在二者之间的空气里正好交出了一道完美的十字切线。那道切线将地上松针全吹成了两个半圆——位置刚好。

赵明远恰好在场，看到说："这就是天然的'合璧式'——你在右她在左；你一沉她一撩。敌人在正面被锁死在你们剑尖交出的十字中心攻击盲区。"

两人对视一眼。然后翻遍蜀山古籍找到了一门上古老剑法——《双鹤反步二十六式》。这门剑法已沉在蜀山剑阁几百年来从无人练——因为它要求两位剑者灵魂之间有灵脉共振。原本是专门给灵魂绑定的双修道侣预备的。林牧看了一夜。第二天在练剑场开了第一局。双鹤反步第一式：两人并肩面敌。各自向侧面滑步——剑尖在滑步同时放出两股剑气在空中交叉——生成一个"引剑区"——能将敌人的攻击"吸"向交叉点，被两人的合并剑气磨损。这种打法不需要两个人修为完全相等——只需要共振频率匹配。

他们匹配了。几乎不费力。

练了七天后两人能同时完成"双鹤反步"的前十六式——到十六式时他们的合璧被赵明远测了一次：赵明远放出化神级别的灵压波推向他们。双剑十字切将那道冲击波切割成四段——每一段的威力都分散成了较弱波动。被破的冲击波落在后山松石上——把石头削了几个坑，但没有造成大面积破坏。

赵明远震惊了——他们两个一人元婴初期一人元婴中期——两个人的合璧力能挡化神初期。这若是传到修仙界——肯定引来不少人想找他们组队。但苏晚说：不公开。这剑法只当私藏。

林牧问她："为什么不公开——对修仙界有用。"

她答："因为它是我们两个人的。和打仗没用——和别人都没用。它只在我们之间有用。公开了就变成一门普通剑法了——随便两个修士在试剑场上练着玩玩。但这是我跟你三百多年才接上的频率。我不想给别人用。"

他把剑收起来，说：好。

# 第五百四十八章 她的琴声就是他的力量

第一关训练的成功让两人找到了正确的方向。第二关"代偿试炼"的备战更侧重于情感层面而非技术层面。代偿试炼的具体流程是——两人被分别置于两个相邻的测试阵中，其中一个人将遭受到一次天雷级灵核冲击，另一个人必须主动选择是否代为承受其中一部分。这不是强制要求代偿——试炼允许拒绝代偿，但拒绝不会得分。代偿会得分但灵核将实际承受伤害。这个试炼的本质不是"能不能代偿"——代偿技术上不难——而是"愿不愿意代偿"的瞬间意志。

对于林牧和苏晚来说，这关反而是最简单的。因为他们已经用了一万年——一百次轮回——来每天回答这同一个问题。但松鹤仙人提醒他们了一个风险:试炼中的天雷是太虚仙域直接投射下来的以太虚法则淬炼过的因果天雷，比合道天劫强很多。如果他们在代偿时不慎将对方的全部伤害代偿到自己灵核中，自己的灵核可能会产生严重损伤——甚至需要数百年才能恢复。而试炼规则不许串通——测试阵会将两人各自放在看不到彼此的独立的房间中，只在头顶开一个只有太虚法则能看到并判断代偿决心的独立的因果窗口。在进入房间后会突然来一发天雷，需要在雷到的极短瞬之间地主动选择要发生意志动作，选择的窗口极其短暂。

"所以只有不到半息的时间。"苏晚说。"要在不到半息内完成意愿判断并执行——不能用通灵作弊，因为试炼规则隔离任何已知通讯方式。"

"靠直觉。不靠通讯。我感觉到你疼的时刻——比通灵快。一万年前就有这套本能。"林牧说。

她在试炼的前日晚上把这半息时间拆成了无数个练习单元。她让松鹤仙人在不同时辰向林牧随机发出突发的极微弱灵核脉冲刺激，然后去测试林牧的灵核是否在不到半息内就主动用代偿反应的脉冲反震动。测试了很多次，他每一次都在时限内。不靠通讯——靠本能，万年前已经刻在基因里的代偿本能。苏晚记录的测试结果最后一行是一句短评:"林牧代偿反射——测试完成。反射延迟在极短时间范围内。结论:他不需要通灵也知道她疼——因为这一万年来他都是这样的。不是特异功能——是守了一万年的旧习惯。"

她把这条结论念完时——林牧把她面前的那盏快要灭的灵能灯往她的方向推近。他什么也没说——但功德绳把这个很琐碎的推灯动作翻译给她了:"灯暗了你看不清字——会近视。"在下界时苏晚确实有点轻度近视。升为仙人后视力早就好了。但他就是记得。这种不需要预先准备的极度琐碎——也是代偿。不是天雷。是一盏灯的距离。

（第五百四十八章 完）

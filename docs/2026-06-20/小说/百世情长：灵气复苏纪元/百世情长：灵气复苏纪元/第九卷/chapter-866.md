# 第八百六十六章 飞升时刻

穿过飞升之门光幕的瞬间，和每一个飞升者经历的一样——法则的温流包裹全身，空间折叠在一息间完成。唯一不同的是，通道在最后一段自动开启了"守门人专列"——不是特权通道，而是一道独立于常规飞升流之外的透明路径。它可以让他们从通道内部看到所有正在飞升的其他修士——而其他修士也能看到他们，但不会干扰彼此的去处。

那些正在不同光轨中跋涉的修士们忽然看到两个熟悉的身影——双尊。没有人指挥——但所有看到的人都不约而同地在自己的轨道中向光柱行了一礼：有的微微颔首，有的在虚空中画圈——那是修仙界最简单的"祝行"手势。林牧和苏晚一一还礼——不是点头，而是同笔的回应——通过共鸣腔把这些谢意重新散布到通道的光流中，让每个修士都感受到被回应的温度。

通道尽头，守门人区的牌坊矗立在万丈光芒中。牌坊背面"谢谢守门"四个字被全体守门人区居民临时加亮加宽——使之成为全仙界此刻最醒目的字。陈望海站在牌坊下——按照他的承诺铺了一张极其素净的长垫，由他亲手织了二十八年。垫子上不是欢迎辞，而是用修仙界通用的符文线绣上去的一列小字："路到了。你们到家了。"

林牧低下头看着那列字。这时苏晚忽然握紧他的手——不是因为激动，而是因为她在星眸实时画面中看到了仙界后方站着的无数人脸。他们是从此间守门人区以及仙界各地自发赶来的、曾经被飞升之门送过来的人——以及他们的家人、孩子、道友——累计超过十万人。把整个中央广场和周边几条支路挤得密密实实。但此刻全场极其安静——没有人吹号，也没有人放灵爆。大家只是安静地站在蓝色星光下看着两人走出牌坊下方。

最先开口的是寒尘。他站在牌坊另一侧，背向人群面对二人，以接引长身份行了一个正式但不古板的迎礼。然后他朗声说道——声音传遍整个广场："每一位抵达此间的飞升者都会收到这句话——欢迎入列。守门人也不例外。但今天我不说'欢迎入列'——我说——'欢迎回家。'"

林牧看着寒尘——看着他眼中不再孤寒的目光。然后林牧第一次在公众面前弯下腰——不是回礼，而是把右手按在自己胸前——那个共鸣腔的中心位置——默默了一下。苏晚同时做了同样的动作。两分钟后——全场所有人也随同他们将右手贴在心脏位置。这不是安排好的——是所有人不约而同的共鸣。那一刻整个广场中的温度略微上升——不是灵力，而是来自每一个人的心暖汇聚。星眸自动把这一瞬间记录进法则"跨代信任共振公则"中——存储千年。

没有冗长演讲。林牧只是直起身，说了两个词："谢谢大家。"苏晚笑着补了一句："厨房在哪？面快坨了。"广场上爆开了笑声——带着温和的回音。陈望海把梭织垫掀起让他们走过。接引长寒尘侧身引路，白微与白染也在边上佇足含笑。

守门人的飞升——在全区笑声与眼泪共存的晚风中完成。他们回到这个自己帮助构建的新世界，如同回家并不宣告任何盛大的转变。只是简单的"到家了"。而门仍亮着——一边照着人间，一边照着仙界。从此长桥两端的星光同等亲切。

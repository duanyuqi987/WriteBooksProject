# 第616章 末日景象

深渊第零零号宇宙。

诸天号船队没有随行——这个宇宙的空间结构已经脆弱到了无法承载任何大于个人载体质量的物体的地步。任何飞行器——即便是最轻型的穿梭舰——在进入宇宙边缘的瞬间就会被坍缩的维度卷进去压碎。只能两个人来。

他们是从混沌之海底层进行超远距离"潜航"进入的。这是陈霜第一次进入混沌之海底层——比浅层凶险得多。底层中充满了一次又一次宇宙纪重启时遗留的"时间疤痕"。被疤痕扫到，人会突然陷入历史的某个片段——不是幻觉，而是肉身被暂时困在了一个早已消失了的瞬间中。要靠强大的意志力从中挣脱。

李长生用冥气护罩保护着她。底层潜航的时间不长——约半个小时。但在这半小时里他们至少经历了七次时间疤痕的冲击。其中一次陈霜就落在了一段十亿年前混沌之主被撕裂时的记忆残片中——她亲眼见到了那场围攻的几秒片段。不是壁画上的版本。是亲眼。那三人中有两人的形态和壁画描绘的一样——炎帝和空帝。但第三个人——她看到了一个轮廓——非常短暂——轮廓内部不是人形也不是能量态。是一种仿佛站在光的所有色域之外的深重阴影。然后画面就断了。

"我看到了光之外者。"

"你看到了什么？"

"只有轮廓。一个被从所有色彩中移除的东西。"

潜航结束。两人从混沌之海中浮出——进入了深渊第零零号宇宙。

眼前的一切远远超过"末日"二字。

这个宇宙正在主动解构自己。不是一个局部黑洞吞噬周边的稳态坍缩——而是整个宇宙在被从上往下一层一层地剥离。抬头向"上方"——宇宙的高维边界——能看到宇宙最顶层的空间正在像干裂的泥土般一片片脱落、坠落、消散。脱落后的空间留下的不是虚空——而是纯态非存在。没有"不存在"这个概念的"不存在"——连"空"本身都消失了。宇宙的天际正以每秒钟几百光年速度向下剥离。

整个宇宙像一个被从顶上撕开的罐头。

"它还能支撑多久？"陈霜低声问。

"根据小王的计算...大约六十七天。"李长生放出感知扫描整片可见宇宙，"然后整个维度会从存在中彻底移除。任何留在本维度的事物都会随着维度一起自消除。"

"第六块碎片在这里某处。"

"对。如果不在它自我删除前找到碎片——碎片会和这个宇宙同步抹除。混沌之主的碎片不能被连续删除——那会造成什么后果没人知道。"

"那行动。"


他们在坍塌的天空之下向前推进。

这个宇宙曾经应该存在过璀璨的文明——在散落的建筑残片中可以看到某些被精心建造的超巨型结构。某些太空站残骸的复杂度堪比诸天号——这个宇宙中的本土修仙文明绝对不弱。但整个宇宙的破坏方式不是战争——没有战毁迹象。无人居住痕迹是突然中断的——像是所有居住者在一个较短时间内批量的离开了这里。撤离标志明显——港口空荡荡，没有争夺逃逸设施的尸体——只有被关闭的能源网络。

"这个宇宙的人提前知道末日会来。"陈霜说。

"而且他们准备了。没有人被遗留下来。所有能看到的人造物品都是废弃或有意留下的。撤离行动极度有序——像一支完整的文明举族迁徙。"

"他们去了哪里？"

"要么去了别的宇宙——要么他们进化到了不需要肉身也能存在的状态。"

两人一边分析，一边定位碎片信号。在自瓦解宇宙的紊乱背景中，定位信号需要多次滤波。第五块碎片对第六块碎片有定向指引——但背景中全是错乱的混沌杂波。需要多次尝试。

用了四个多小时——终于锁定了位置。第六块碎片位于这个宇宙仍较稳定的地核区——一颗体型很小的金属行星的内部。这颗行星采用了一种奇特的自我压力平衡构造——在宇宙坍缩的这几十天中，它通过自我压缩来维持内在空间的稳定。像一个宇宙级的保险柜——把柜门焊死以保护柜中的东西。

第六块碎片在里面。

（第616章完）

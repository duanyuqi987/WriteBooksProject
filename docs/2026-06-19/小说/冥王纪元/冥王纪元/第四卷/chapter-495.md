# 第495章 首席炼丹师小胖

小胖的名字其实不叫小胖。他有个正式的名字——周永昌。但这名字从没人叫过。连他正式的任命文书上，许冰帮他写的就是"小胖"。他在李家庄村口的沙土地边上建了炼丹房——就是那片被冥气残留改造过的灵土旁边——用最老式的砖石结构盖的。屋顶不是灵阵材料——就是普通的瓦。他说灵草是活的——活的东西需要呼吸自然风，不能关在恒温恒湿的灵阵室里面。

"首席炼丹师"这个名号落在小胖头上之前，他自己的修为此前一直徘徊在玄师级——在如今的守护秩序里，玄师级相当于军队里的基层技术兵。但他从来没把这个等级放在心上。他觉得炼丹这件事和修为高不高没有直接关系。他做菜练出来的控火直觉比很多灵帝级修士的灵焰控制还要精准。

他的第一项作为首席炼丹师的成果——是一种被命名为"归元丸"的基础丹药。这个丹药的作用很平凡：帮助刚入门的修士快速感知灵气。在修仙界，类似的丹药已经存在了几万年——各种名目的"引导丹"、"开窍丸"比比皆是。但小胖的归元丸跟所有已有的这类丹药有一个根本区别：他的配方成本极低。用的不是高阶灵草，而是地球上都能长出来的基础灵植——辅以微量的冥气土壤中自产的某种稀有草芽。效果比市面上的同类型丹药强将近百分之三十。价格只有它们的千分之一。

当然，小胖的炼丹术不是凭空冒出来的。他自己在修炼上有时吃力——火系灵根需要庞大的灵气支持，而他修炼期间冥王号上的冥气环境对火系不友好——他必须用自己的厨艺经验来弥补。"放多少盐——可以掩盖木腥味同时不压住主料的鲜——这不是跟调灵草药剂比例是一样的吗？九味灵草调一味——多了压不住药性，少了丢效果。"他很认真地对前来观摩的星都王朝皇子的侍从这样解释。围观的侍从听得很认真，记了满满一本。后来这种"厨理—丹理"结合的说法传到了星都王朝的民间，引起了一阵不大不小的厨艺热。因为小胖的通俗比喻让普通人发现——所谓炼丹，不是神仙的事，是做菜的诗人干的。

李长生后来有一次独自到炼丹房去找他。推门进去时，小胖正用一只手煸着锅里的蔬菜——真正的蔬菜，普通茄子。他另一只手勾着丹炉里的火力——炉中正焙着一枚九味养气丸。两边同时操作，两边都精确得不差分毫。炉火自动调节——每一跳都呼应着锅底的翻动，仿佛炒锅和丹炉合在一起在做同一道菜。

"你来了——等一会儿，我把这锅炖完。"小胖头也没回，忙着他手上精准的切换操作。

李长生在旁边坐着——矮凳，和他在自家院里剥玉米的是同一款。他看着小胖在那又炒菜又炼丹，忽然笑了。他说："你还记得你当年炒的第一锅菜糊成了什么颜色？"

"别揭短——那是受限于装备！"小胖边快速翻炒边嘴硬地说。

李长生不说话。他不用说什么——他知道，这个当年炒菜糊锅、修炼卡在玄师级的普通人，现在是整个守护秩序的首席炼丹师。宇宙各文明的高级炼丹师在月球的学术会议上可以用几十个上午讨论极其高深的理论，但小胖一个下午就能烧出见效的丹药。他不搞深奥理论——不靠玄之又玄的口诀，靠的是一口锅、一鼎丹炉、和一股反复实践出来的"火候感"。

"你这行当——宇宙里有更厉害的。"李长生后来说。

"那当然。"小胖把茄子和丹丸同时起锅，一边装盘一边把刚炼好的丹药装瓶，"宇宙里比我厉害的炼丹师多了去了。但能一边炖茄子一边炼丹——而且炖得好吃、丹也有效的——宇宙大概就我一个。"

他咧嘴一笑——锅铲还拿在手里，油光满面的。那样子，真不像一个能在银河级炼丹大会上傲视群修的首席炼丹师——只像一个做饭做的很开心的厨师。

（第495章完）

# 第七百四十二章 旧势力最后的反扑

三级跃迁计划第四年的初冬，旧势力发动了他们最后一次有组织的反扑——规模比之前更大，组织更精密，由三个隐世了上千年的古修世家联合发起。他们的首领是其中一个古修世家的大族长——修为元婴巅峰，拥有古老的阵法秘术。他在起事之前让人传话给全九州——"修人共治是弱者为强者设置的枷锁。我们不愿意活在枷锁里——所以我们要打破它。"

这次反扑与以往不同——它不是正面攻击灯火塔或桂花园学院。它选择了一个最偏远的点——东海渔村。孙小环在那里建立了东海灶台点，十年来已发展成了一个小型的凡修融合示范区。但它的防御力量极弱——村里只有几名练气渔修和十几户凡人渔民。旧势力选择这里作为突破口——意在用最小的代价打击共治会的士气。

叶小雨的灵网系统在敌军到达前半个时辰发出了预警。孙小环在东海收到了苏晚的传讯——"撤人，把灶台留给敌人，不要应战。——灶台烧不毁，明天可以再点。人最重要。"孙小环看了传讯后，没有立刻撤退。她知道村口那口灶台上贴着村民们十年来每天写的便签——几千张。她用最快速度把所有便签全部小心揭下来——边角卷的、字迹模糊的、被海水潮气浸黄了的——全部收进了一个灵囊。然后才挨家挨户通知撤退。她把灵囊交给最小的那户人家——一对老夫妇——"这个比灶台重要。灶台明天可以再砌——这些话十年后再看还是真的。"

敌军到达时发现村子空了——只有一团仍燃烧的灶台火和一口干净的、空着的铁锅。他们毁了灶台。但他们没有发现灵囊——里面装着几千张便签——和十几年前叶小雨收到的第一张"不用谢"一样——上面都是最真实的话。

苏晚在太湖灯火塔上收到孙小环的撤退确认后，转头对石头说了一句话："他们毁了一口锅——但便签都在。"

（第七百四十二章 完）

# 第672章 番外：帝国众将的告别

减速期第二年——距离旧纪元终结还有约八个月。冥王帝国在新丰星球的临时基地里办了一场聚会。不是正式晚宴——就是大家凑一块儿坐一坐。但是所有人都来了。

老陈拿出了他最后一份尚未完成派送的快递单——单子上填着同一行字："新纪元第一号包裹——内容：旧纪元全部战友——收件人：希望。"刀疤问他是真是要派人去送到新纪元去——他说到时他自己对着天点一下收发——系统会自动签回。他在上面压了自己的旧印章——那章还是他在凡人快递公司时用的一块木质方章——刻着一个"陈"字。

许冰带了一份纸质文件——她亲手用毛笔抄的新纪元第一部暂行法序言——全篇一个字不带法律术语，就是一封给她未来不认识的立法者们写的信。信里一共也就三百来个字。核心意思是：法律是为了保护弱者，不是为了服务强者——如果未来有人觉得法律变成了后者的工具——就重写。她在最后一页签上了自己的名字——然后把这封信装进一个牛皮纸文件袋——贴上一张标签，再交给龟相存档。

刀疤带着全体守护军（原禁卫军）整编后的花名册——每个名字都用黑色墨水重新描过一遍——密密麻麻，所有跟他一起打过每一场仗的战友的名字全在上面。他把这花名册交给李长生——不是让他收着——是让他亲手放进永恒之库的入口处。花名册的边缘毛得很厉害——是老兵们天天翻的结果。李长生看了一眼就放好了。

小胖在厨房里忙了几乎通宵——他用这一年内找到的新丰星球上的所有新食材和旧纪元残余调料的复制品——复刻了一道旧纪元冥王食堂最后一餐的菜单：苞米碴子粥、烙葱花饼、酸菜炖排骨——全和当年地球农村灶头烧出来的味一模一样。端上桌的时候他把围裙摘了——没说话——但眼圈红了。

林晓把全军团所有人的体征记录全整理完了——一人一页——姓名在最上头——下面是旧纪元最后一次体检的全部数据——每个人的数据结束时都是一句话："最后记录——该员意志体征完好——建议新纪元继续纳入防护。"她合上全本皮册——轻轻地压在桌子下面——用小指把册角抹平后再也不翻开了。

老马对着一块新土标本——就是从新丰星地表下取出的一抔原生沙壤——做了整夜的矿物分析。他在旧纪元做的就是土壤——在新纪元他依然分析下一片星土。他把分析报告加上一行字："这种土——不太像华北——但也能养苞米。"报告落名的头衔他空着——没写任何军衔或职务——只写了"地质工程师"五个字。

聚会持续到了深夜——其间没有人走。酒喝到某刻——老王忽然举起旧搪瓷缸——缸里还是李长生最后倒的那半杯凉茶——他对着星——没说话。大家就懂了——一起对这个屋顶之外的那片还没开垦的新宇宙说了两个字："保重。"

此后——帝国众将各自回到了自己在回降地内分配到的暂住处——一一步入旧纪元的最后几个月——他们都没有哭。因为他们在相聚那一刻已经把所有该说的话全部变成了具体的东西——签了——盖了——放了——交存了。

旧纪元终息前夕——花名册安放在永恒之库入口处全天静亮。刀疤最后一次全部点名——全答"到"——一个没缺。

（第672章完）

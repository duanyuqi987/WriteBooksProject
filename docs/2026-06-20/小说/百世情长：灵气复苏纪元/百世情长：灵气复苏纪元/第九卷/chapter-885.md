# 第八百八十五章 百世轮回的回望

在青云山谷短暂休息时，苏晚翻出了那枚极其古远的记忆玉简——是许多年前第一进出虚空时古老意志赠予的第一道种子。那种子中存有上古情缘契约的原始残文。这些年她极少回顾——因为不需要。契约一直在他们之间运行，不需要被重新确认。

但此刻她忽然想再读一遍。不是因为怀疑，而是因为"回望"让她觉得现在的自己应该以全新视角再看一遍那些最原始的语句——看和当初在第一卷时那个还不懂修炼的普通财务女孩看到的是不是同一个世界。她把种子放入掌心，灵力激活。契约残文重新浮现在空中——文字依然极晦涩，但共鸣腔自动将它翻译成当下她最熟悉的语言。那些话翻译后大致是这样的：

"约定之人——不论在何时何地何身——会在每一次抵达临界点之际重新找到彼此的形状。不因记忆——只因信任。以百世的机缘计算，以每一次兑现契约时的相互选择为底——此约即续。不借外力，不设期限——直到时间尽头。"

她读完轻轻闭上眼睛——然后带着笑意睁开眼睛。与她初次读到那份残文时截然不同的是：她那时以为契约是命运强迫他们在一起的某种外力设定——现在她知道这份契约的本质是"每一次重新选择对方"。不是命中注定——而是每次都选对了。

林牧一直在旁边安静坐着。他看到了她眼中那种宽深的平静。他没有问她感想——因为不需要。她主动分享给他——在共鸣腔中只放了一个画面：一卷极长极长的红绳从她心底缓缓逸出，穿过云谷间，穿过飞升之门的光幕，穿过守门人区牌坊，穿过老木匠椅子的腿，穿过星子老屋的旧玻璃窗，穿过葱门的小摊，穿过千灯窗——最后回到此刻山谷中的石桌上。绳子的两端都在她手里。她把它递给了他。他接过去——用手在绳打了一结，一个再普通不过的日常绳结。

然后她开口："八世、九世、这一世——每一次都是你。契约不是锁。是每一次我愿意选你，我正在选你，我会再选你。"

林牧握着绳子——他的喉头有极轻微的一下滚动。但他说得非常简单："我也是。每一世。每一次。"

百世轮回的约定在这一刻被解为最简单的去伪："我选你。"不是命运的捕获——而是自由意志的永久对齐。虚空中七昼夜晚的三重阵护、飞升之门前数十年守护——全都是这种自由选择的延伸。而此刻在第九卷末尾，他们对百世轮回给出的最终回响——不是完成契约，而是明白契约永远都是未完成，随时在续。而他们会续下去。

窗外夜空中，永恒光轮依旧如初。山谷中石桌上的两杯茶终于温了。苏晚端起自己那杯说："敬下一世。"林牧隔空轻轻碰了碰她的杯沿。"敬每一次。"

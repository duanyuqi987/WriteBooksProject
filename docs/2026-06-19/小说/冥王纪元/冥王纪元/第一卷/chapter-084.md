# 第084章 李长生冥术压制，陈霜剑法收尾

李长生把右手举起来的时候，整个小臂的冥纹全部亮了。

不是之前那种零星几道的幽蓝色纹路。是从指尖到肘关节，每一寸皮肤上都浮出了黑色纹路。纹路很深，密得像一棵老树的根系扎进肉里。幽蓝色的冥火在纹路上跳动，冷得不像火——没有温度，只有光。

沙蛟还在晕眩。

刚才陈霜劈中头顶的那一剑虽然没能砍透颅骨，却打中了它灵识最集中的位置——颅顶印堂穴对应的妖兽天灵。对妖兽来说，天灵被震的后果比物理伤害还要严重：灵识混乱，五感失序，短时间之内无法准确锁定对手的位置。

这就是窗口。

李长生深吸一口气。丹田里残存的大约三成冥气被他一次性抽出，沿着经脉往上走——过膻中，过肩井，过肘窝，全部灌入右臂。

"黄泉引路·第三重——"

低喝声中，右手五指猛然张开。

冥纹炸了。

不是花纹碎了，是纹路中储存的冥气一次性释放出来。幽蓝的光芒从他掌心里喷涌而出，像一盆打翻的墨水在清水中扩散——只是这盆墨水不是往水里散，而是往空气里散。以李长生为中心，冥气迅速扩张成一片半径约八米的不规则灵场。这次不是第一重那种淡薄的雾状，也不是第二重那种被压缩的光环。

是幻境。

灵场之内的大漠忽然变了。沙地变成了深黑色的泥土，天空变暗变成了深灰色悬着一轮血红的残月。远处出现了模糊的建筑轮廓——残垣断壁，满是裂纹的石碑，几棵枯死的黑树歪歪扭扭地立在地平线上。空气里浮动着若有若无的呜咽声，像被埋在土里的人从深处传上来的低语。

黄泉幻境。

这是龟相教给他的压箱底招数。冥系修士的第二重修为能用的最强控场术——把冥气转化为黄泉地狱的幻觉，不是真的把人拖进阴间，而是用阴气和死气扭曲现实感知，让敌人以为自己掉进了黄泉。

对沙蛟来说，这意味着它的整个世界观都受到了彻底的篡改。

它刚才还在沙漠，现在忽然掉进了墓地。

沙蛟的甩头幅度变慢了。它硕大的头颅在空气里左右摆动，那双铁铸般的眼睛在眼眶里无规则地转动——它在找方向，在找自己的头部该往哪里转。它的感官原本可以通过沙子感知猎物脚步，但在黄泉幻境里沙子变成了黑泥土，震动频率全乱套了。它的灵识感知也废了——黄泉幻境能吞噬一切活物的灵气信号。

这就是李长生要的三息窗口。

但他的三息比陈霜刚才预测的要痛苦得多。第三重黄泉引路抽干了他体内几乎所有可用的冥气。他的右手臂从指尖到肩膀瞬间像是石化了一样，僵硬得抬不起来。视野开始发黑，膝盖在抖。

他没有倒。

因为他知道自己一倒，幻境就破。幻境一破，沙蛟的感知四分之一息之内就能重新锁定陈霜。陈霜没有剑，连躲都来不及。

"你的剑——四点方向——"李长生挤出来的声音不是喊的，是挤的。

陈霜爬起来了。

她的剑落在刚才那个沙丘顶上。剑拔得快，找剑也找得快。剑还在沙坡顶部插着——随尾部抽来的冲击波一打，剑身在沙里绞了半圈，像个插得不稳的旗杆。

黄泉幻境也在扭曲她的感官——但她是修士，她知道这是李长生的招。她没有把眼前出现的幻景当真，而是把身体交给肌肉记忆。她不是用眼睛去找剑，而是用脚——剑修最熟的就是自己和剑的距离。

她跑过去拔剑的时候，双腿快得几乎没有任何停滞。

剑入手。

这一次她的剑上没有白光。

因为剑气被消耗到了极限。连续的战斗——第一次刺颚窝，第二次大招劈颅，中间还释放过一次剑气灌入灵脉节点——把她的剑气存量压到了不到一开始的两成。残余的两成不够在剑刃上凝成可见的剑罡。也就是说这把剑现在只是一把非常锋利的钢铁。

但陈霜不犹豫。

她转过身，看着在黄泉幻境中迷失了方向的沙蛟，看着它仰起的头颅——那道被她劈出的血槽还在往外渗绿色的血，距离眼球只剩三寸。

她爸说过：剑最锋利的时候，不是它刚出鞘的时候。是你用尽最后一丝剑气的时候。因为那时候你没有后路，没有退招。你能用的不是你最强的一剑——是你最后的一剑。最后的一剑比最强的那一剑还狠。因为最强你还能退回去，最后你连退都没地方退。

她爸说这句话的时候，正在磨那把现在她握在手里的剑。

陈霜深吸了最后一口气。

她动了。不是冲刺，是一步一步走过去。每一步踩在黄泉幻境的黑泥土上，踩得很稳。她的剑尖垂向地面，身体的中心压得很低。

沙蛟已经在慢慢恢复。它天灵下的灵识混乱在被缓慢平复——黄泉幻境的影响也随着维持时间减弱了。它的头已经开始有方向感地转动，眼睛的瞳孔位置在试图聚焦。

但它没有聚焦，因为还有光的干扰。

黄泉幻境里那轮血红的残月照在地上，在李长生右手引路的尽头竟然还有一个位置的错觉。

沙蛟转过头去试图看那第二个月亮。

错了。那不是月亮。

那是陈霜的剑尖。

陈霜从残月的光斑里踏步而出，一剑从下往上斜劈——劈的就是那道血槽的下沿。剑刃嵌入鳞片裂缝，她已经没有任何剑气可用。她没有劈进颅骨——她劈进的是那道裂缝边上的软组织。剑刃嵌进去之后她忽然收力、回转、上提。

不是劈，是撬。

她用剑身的力量把已经裂开的颅骨板撬开了一道缝。

这就是她爸教的。你修为不够劈不开敌人的头骨，你就撬开——撬是力气活，不是剑气。撬开颅骨，缝隙底下就是沙蛟的灵核。

陈霜把剑往缝隙里一塞，松手，后退了三步。

然后她从倒在一旁的李长生的位置大喝了一声："引爆。"

李长生没问引爆什么。他的冥气剩下最后一丝——比头发丝还细的一丝。他把这丝冥气沿着幻境的残余灵场送了出去，精准地送入了陈霜插在沙蛟颅骨缝隙里的剑身。

冥气碰到金属剑身上残留的剑气——两股属性完全相反的灵气在极狭小的空间内碰撞。

炸了。

剑没有被炸碎，但强烈的灵能冲击从剑身周围炸出来。灵能冲击波直接穿透了沙蛟大脑的灵核——妖兽的大脑非常小，是深藏在厚厚保护壳下面的胡桃核那么大的东西。灵核一破，沙蛟全身的灵气瞬间断绝。它的尾巴还在惯性下抽动了一次，然后整个身体像一堵垮塌的墙一样轰然倒地。

沙地扬起大团黄尘，遮天蔽日。

陈霜被冲击波推出去坐了五六米远，后背靠上一座小沙丘才停住。她的剑被炸得落在远处沙子里，冒着白烟，剑身上印上了一条细密的裂痕。

李长生趴在原地——他已经透支到连抬头的力气都没有。黄泉幻境随着他倒下自然破散，沙漠恢复了它本来的颜色。

风又吹起来了。

细沙覆盖了一切。沙蛟巨大的尸体躺在戈壁上，腹部朝天，鳞甲上的灵光正以肉眼可见的速度消散。没有灵气支撑的上古妖兽尸体，会在很短的时间内变成沙漠的一部分。风一来，剥去鳞，褪去皮，最终只剩下一副和石头颜色没区别的白骨。

过了好一会儿，陈霜坐起来了。

她先找到她的剑。捡起来看了看——剑刃上那道裂痕不深，还能磨掉。她几乎把整个脸上所有的表情都拧在了一起——不是愤怒，是肉疼。她爸磨了一辈子的剑，现在有了第一道裂痕。

她在沙子上吐了口气，把剑重新插回地上的剑匣边，走过来，在李长生旁边的大石头边上坐下了。

两个人大约坐了五分钟，谁都没说话。

不是没话说。是刚才一战把所有的力气用光了，光呼吸就觉得费劲。沙蛟已经死了，他们活了下来，这个事实本身需要时间消化。

先开口的是陈霜。

"黄泉引路。"她把四个字一个字一个字说得很清楚，像在品，"你把这个叫什么？"

"幻术。"李长生的声音沙哑，"冥系的幻术。用的是黄泉地狱的意象。你看见的是黑土地？"

"嗯。黑土，红色的月亮，残墙破碑。还有人在土里低语。"

"我以前也没见过幻境，这是头一次用。是这效果——"他顿了顿，"看来不是太假。"

"不是太假。差一点我就信了——信了你背后真的是一整片死人地。"陈霜看着远处沙蛟的尸体，"以前我以为冥术只是靠阴气腐蚀。看来我想窄了。"

"你劈的那一剑才是真狠。连我维持的幻境都差点被你的剑罡吹散。"

"那不是我最狠的一剑。"陈霜说，"我最狠的那一剑——可能还没用过。"

李长生偏过头看她。

她的头发里全是沙子，脸上沾着暗绿色的沙蛟血和陈年淤青。右肩的衣服被沙蛟那一抽撕开了，露出一截被擦破皮正在渗血小臂。但她一点都不在意的样子。

她在看远方。看夕阳在戈壁的边缘往下掉，把整个大漠都镀成了一片赤金色。

"谢谢你。"陈霜说。

李长生愣了一下："谢什么？"

"你没跑。"她说，"刚才沙蛟现身的时候，它的尾巴抽过来，你第一个动作不是跑，是把我推开了。"

"你不也是。剑丢了还冲上去撬它的颅骨。撬颅骨，换我绝对想不出那把剑当撬棒用。"

"那是我爸教的。"陈霜说，"我爸还教过我剑修的规矩——剑修跟不是剑修的修士要并肩作战，就得交心。交心是什么意思——他说的。他说，是信任。你把你的命搁在我剑上，我把我的命搁在你的盾上。"

李长生苦笑了一声："我没有盾。"

"你刚才那种幻术就是盾。冥术当盾使，挡着它的感知让我砍。"

沉默了一会儿，然后陈霜侧过头，看着李长生。

她的脸上染着沙子和血痕，但那双眼在夕阳里忽然亮了起来——不是冷冽的剑光是更简单的光。她说："种地的，你打得真的不差。刚才你如果跑了，我一个人大概真的扛不住。"

"你也打得真的不差。"李长生说。

然后她弯了一下嘴角。

不是笑出声的那种笑，只是嘴角动了一下，往上翘了不到一寸。很久没笑了——这是她爸走之后第一次和人并肩打架，也是第一次活下来了。笑不是因为这个，笑是说不上来为什么，只是觉得这一刻吹在脸上的风不冷了，坐在旁边的人不是敌人了。

李长生的回应也很含蓄。他没有大笑，只是往沙子上又仰了仰，整个人像一条被太阳晒得半干的鱼躺在沙滩上。但他的眼神在夕阳余晖里微微亮了一下，嘴角压不住地向上翘了一点。

夕阳西沉。大漠的风开始变凉。沙蛟巨大的尸体在风沙中渐渐被细沙覆盖。

两个人就这样靠着同一座沙丘，一个看夕阳，一个看天。

谁的功夫也没有开口。风替他们说了。

远方的地平线上有东西在闪。不是夕阳的反射。是第三块冥王碎片的感应。它在地下深处，正在等着。

（第084章完）

# 第922章 归程之路

林牧在获得道源之前，对"回去"这件事有一个模糊的估计：拿到道源后还需要消耗两三百年在上界完成修为巩固并找到反向通道的办法。但在帮完归禾之后，他忽然多了一个意外的收获——归禾本人是见道中期的上古飞升者。

归禾的道侣被救出来之后需要一段极长的恢复期。归禾决定带她去南方灵海的一处隐秘洞府养伤。临行前，他找到林牧，把一枚灵玉塞进林牧手里。

"反向通道。"归禾说这四个字的时候声音还是哑的——但哑里多了一种被释放出的温和。"我在上界待得够久了。三千年前我本来打算回去找她——通道的构造方法我早年在一处碎域中翻到过。但后来她沉在泥沼中出不来，通道对我来说就用不上了。"

林牧用神识探入灵玉。里面的信息量极大——包含了完整的上界到下界反向通道的构建法则。不是传送阵——是以"见道因果干预"为核心的一套高深层级法则操作：在上界的某个特定坐标点（必须是曾经有飞升梯出现过的地方），用道心激发反向的信号——需要对因果网进行精准的扰动，使上界降低对通过者的排斥度。反向通道不是路——是权。是获取上界允许你回去的权利。没有见道修为根本做不到。因为只有见道修士才能参与因果网的运作。

归禾把灵玉给他时附带了一句叮嘱："反向通道只能开一次。一次就够了——你回去之后可以不回来，但一旦回来就需要重新申请见道的因果权限。所以好好想清楚——你是要把她接上来，还是留在下面。"

"谢谢。"

"不谢。救她——已经还清。"归禾将道侣从纳戒中抱出的那一刻起，所有债已经清了。

林牧带着灵玉回到住处。他花了整整一个月的时间去研究归禾留给他的建造方法。法则的推导过程在他的脑海中用极大的速率运转着。一个月之后他确认：反向通道可以用。需要找个时间在上界选定飞升梯出口的位置反向开启。太行山顶的飞升梯出口在某块石面上——正对着东方的位置。他对此的记忆极其清晰。

他会回去。

但是——他想再等等。不是等自己——是等苏晚。苏晚已经在这个时间点在下界发展了千年太行书院。他不知道书院的规模大到什么程度——但他知道她在下界做的不会是小范围的事。她给的红线脉冲里满是为她的事业感到充实的力量感。她可能在等着"书院上了轨道"的最佳时机——然后自己选择飞升。如果她现在已经在准备飞升了，自己贸然回去反而奇怪：两个人分别从上界往下走、从下界往上走——在中间错过。

他决定先等一等。反正道源已得，永生之法三个核心要件每一个都在掌握中（道源在体内、圆满体在进化、施术者是他自己），不再需要赶路。他可以借这一段时间——在等待她走完下界最后一程的间隙——进一步完善大圆满体。把身体净化到最纯粹的程度，确保仪式时零损耗。

于是他住下来了。开始在太初之城过一段相对规律的生活。修行、探索近郊的碎域、偶尔与其他飞升者交流见道心得。日子过得平淡但极充实。每隔一段时间他就用红线感知一下苏晚那边——信号一直稳定饱满，从不衰减。他偶尔在太初之城的街道上看到情侣并肩走路时会心有触动——想象再过不久他可以跟她并肩走在这样的街道上。但不是作为保护者和被保护者——是作为两个独立的、完整的、并肩而行的灵魂。

与此同时在时间流速差别的另一端，苏晚正在做飞升前的最后准备。

千年以来她积累了足够的事迹。太行书院的规模达到了历史新高。微书院二十多万所，在籍在校学生五十余万人。道典发行量突破百万册（包括手抄本）。修仙界的基础修为平均值在她的体系下被整体拉高了整整一层——从前底层散修的大部分是在淬体一辈子。现在散修的筑基率从以前的百分之十变成了百分之七十。

做到这个程度，她觉得自己的第一个千年答卷可以交了。不是完满——没人是完满的。但这份答卷足够让她面无愧色地去跟林牧说："我没在等——我做了不少事。"

在她的千年银杏叶收藏完成了第一千片之后，她站在飞升台顶上。把手贴在石地上。对着天空说了一句话——这次是正式提出飞升申请。

"太行书院的事做完了。我要去找林牧。"

梯子这次毫无延误地回应了她。青白色台阶从石面上跳了出来——没有试探她够不够格，直接铺开向上。梯子用极快的时间探知了她的道心——透明、充实、没有任何伪饰——通过了。七级考验对苏晚来说不再是"考验"，是回顾。每一级台阶不是问她怕什么，而是让她回顾自己这一千年做了什么。她的答卷已经刻在大地上了——梯子只是让她回想——不是考验。

她踏上第一级。第二级。第三级。

在跨过第七级飞升之门前，她把右手的袖子卷起来，对着山的方向最后一次朝下看——山下是满山遍野的微光（那是太行山上所有书院的灵灯在夜里亮着）。她知道那些灯不会灭。

然后她跨过了门。

# 第667章 冥王帝国的守护传承

新纪元诞生后的第一个千年，冥王帝国完成了从"旧纪元军事政权"到"新纪元守护势力"的全面转型。

这个过程不是行政命令推动的——是自然发生的。因为冥王帝国是旧纪元唯一一支在零点时刻保持了完整组织结构和全部核心成员的军团。太初在零点时刻扫描旧纪元所有意识体时，把冥王帝国全体核心人员——连同他们的装备、档案、记忆、以及每个人的意志状态——全部原样保存在了永恒之库里。当他们在新纪元诞生后被"解冻"到新宇宙中时，每个人醒来做的第一件事都是：看旁边的人还在不在。全都在。从周老到刀疤，从许冰到老陈，从林晓到老马，从小胖到小王——全在。一个没少。

于是冥王帝国成了新纪元里第一个同时也是唯一一个拥有完整旧纪元连续记忆的组织。其他从旧纪元中被保存下来的高级意识体也有自己的记忆——但他们大多数是单独的个体或小群体。像冥王帝国这样完整地、成建制地从旧纪元过渡到新纪元的——只有一个。这不是特权——是他们在旧纪元最后两年里全力以赴的结果：他们把整个帝国的所有数据、所有人员信息、所有战斗和守护记录全部编入了龟相那份"旧纪元最高档案索引"——而这套索引在零点时刻被太初认证为"全宇宙最完整的文明档案"——从而被整体保存了下来。

在新纪元的第一个千年中，冥王帝国不扩张。他们在新宇宙的一个稳定星团中选了一颗类似地球的行星作为主基地——不是殖民，是暂时落脚。这颗行星被命名为"新丰"——那是在华北平原上了年纪的老人对刚收完了一整年粮后土地的称呼。新丰上建起了第一批低矮的长房——是照地球乡村建筑格局盖的——有院子、有井、有老槐树（老马用地质技术从旧纪元记忆中复原了基因），村口还有一条新铺碎石路——通往一所邮局——那是老陈坚持要的。

帝国众将在这里重建了基础运转体系。许冰起草了新纪元的第一部暂行法——核心理念全部来自李长生在太初面前说过的那句"保留所有生命，包容所有文明"。刀疤重建了禁卫军——但新禁卫军不叫禁卫军——改名"守护军"——任务是保护未来新纪元中所有尚未成熟的小文明免受维度外干扰。林晓重建了灵医研究所——在新宇宙基础常数下开发了一套全新的灵医体系，专门针对新纪元中初次苏醒的新造原生意识体的生理问题。

龟相把他的全部档案索引全部公开了——不是给冥王帝国看，是给新宇宙未来的第一批原生文明预留了一整套可以查阅的"前辈资料"。他把这些资料分成了四千九百个文明档案类目——每一个类目都以旧纪元中对应文明的母语原始记录为索引，方便新文明检索。小王把整个索引系统全部移植到了新宇宙的基础信息层中——做了个从元维度就可以读取的全网图书馆。老陈被任命为"新纪元物资协配总长"——继续干他的老本行——只不过现在"快递"的内容从货变成了跨星系发展资源。

周老在过渡期后主动退休了。他在新丰村找了个院子——和以前地下办公室大小差不多——用新纪元的第一批废砖砌了一间茶室，搪瓷缸还是那个搪瓷缸——盖沿上的磕痕还多了一道——那是他在搬迁时碰在门框上留下的。他每天在院子里坐着看太阳升起——这颗太阳不是旧太阳，但他心里清楚——光就是光，晒多了皮肤依然会暖。他说这就是最好的安老法——不想再去当顾问了——"你们现在不缺我了，缺的是知道怎么谢幕的老人。"

李长生每隔一段固定时间来看他一趟——不带工作，就坐下来喝一杯茶。两人说话不多——主要是坐。但坐中有些话不需要说。

冥王帝国的守护传承最终以这样一种方式落定：帝国不出征——它为未来新纪元中的所有文明预留了全套基础设施、法律框架、安全防御、物资配给、医疗系统和历史档案——所有这些设施和资源在无尽将来的若干亿年中将陆续被后起的文明发现、学习和改良——而冥王帝国的人自己不会再占有任何一个被后人发现的地方。

（第667章完）

# 第五百二十三章 名录之上

天道勘验之后不久，仙缘司派了一位使者送来了正式的"通灵道侣名录"入册证明。使者是一位极年轻的女仙官——看她的表情就知道这不是她平时送的文件类型。她递上信物时双手都在微微发抖——不是因为害怕，是因为她面前的这两个人是近五万年来全仙界第十一对通过天道勘验的道侣。这种级别的人在仙界历史上会被写进教材——而她来送的就是那本教材的盖章页。

证明不是金册也不是玉简——是一对极小的、用同心树木心雕成的"通灵信物"。信物的形状是一对半心——各是半心形，两块合在一起就是一个完整的心形。木料取自同一棵同心树的树心——树心不是砍出来的，是自然脱落的老树皮下面新生的那一层最嫩的木质。这层木质在树体中每年只长极薄极薄的一小层——做这样两块信物需要用掉累积了几百年的树心层。苏晚接过雕着"水月仙人·晚"的那块，林牧接过雕着"寻晚真仙·牧"的那块。两块木心在两个人手中隔着分毫的距离时——木心各自的边缘竟然自己发亮了。不是功德绳那种金色——是更素净的木质原色暖光。两块信物的木质原本来自同一棵同心树、同一圈年轮。它们在被雕成两块独立物件之前在树体里就是紧挨着的——木纤维之间只隔了两层细胞壁。分开之后再靠近——它们的木纤维会自动感应到对方的存在，释放出极微弱的生物光。这个原理和功德绳一样——只是更原始，是用树的因果替代了人的因果。这代表了天道已经在因果层面对这对道侣进行了"最高同步"的认定。

仙缘司使者在递交信物时还说了一段话——这段话她已经背熟了，但她还是用极郑重极庄重的语调从头到尾念了一遍:"名录之上目前的确切成员——过去五万年间只有不足十对道侣。你们是第十一对。名录没有公开——不会影响你们的正常生活。这封信物只是记录——证明你们之间的感情已经被天道正式认定为'完整道侣关系'。不是荣誉，是存档。但有一件事也许你们未来会遇到——当仙界日后出现需要'通灵道侣'级别才能解决的特定因果纠纷时，可能会委托你们参与。这不是强制——但你们的功德记录会自动得到加成。"

苏晚把木心在手中翻来覆去地看了很久。木心的正面很光滑——被极细的砂纸打磨过，能映出她拇指指纹的纹路。木心的背面保留了树心最原始的天然纹——那是一圈极密极密的年轮记录，最外圈和最内圈之间隔了好几百年。她把木心翻过来的时候发现背面有两个极小的天然树结——并在同一位置，形状完全一致。那是两根木纤维在生长时绕着同一颗小石子同时转向。她的木心上有这个"绕过石子"的盘结——林牧的木心上也有。同一个石子，同一圈年轮，同一道绕过危机的弯。她把这件事告诉林牧。林牧把自己的那块翻过来和她并排放在一起——两处盘结的曲率完全吻合。两块木心合在一起的断面完美无间——盘结在交接线上形成了一个极小的空心圆。就像当年那粒小石子在树木生长数百年后被取出——只剩两个同心环痕在对齐。

"你看到了什么？"苏晚问。

林牧看着那两个环痕——沉默了片刻。"看到那粒石子。它本来是树在生长过程中遇到的障碍——但因为树绕着它长了，把它包进去了。后来取出来时它变成了图案。不是伤疤——是图案的一部分。像我们——那些转世的伤，被时间包进去了。取出来之后不是缺口。是对得上的环。"

苏晚没有回答。她把自己的木心放在他手心里——两块木心自然合在一起，中间那条接缝几乎看不见。她把功德绳的一小截穿过两块木心背面预留的那个极小穿孔——然后把绳子的两端系在自己和林牧的手腕上。这样两块木心永远被功德绳串在一起，不会分开。

当天晚上她在家中小厨房里给自己倒了一杯青梅酒，也给林牧倒了一杯。她把木心像杯垫一样放在杯子下面——半碗酒映着木心发出温润的微亮。酒是松鹤仙人走之前泡的青梅酒——泡了大概一年多，梅子已经软透了，酒的颜色从清澈变成了极淡的琥珀色。她端着酒杯和林牧碰了一下。碰杯时功德绳上传来了一阵极轻极轻的愉悦——不是庆祝，是日常的满足。像冬天坐在炉边把手烘暖了然后可以继续补袖子。

"第十一对。"苏晚喝了一口酒——梅子味在舌根散开，"这个数字不大不小。第一对一定很老很老了——可能是仙界还没分裂时的道侣。我们可能是最年轻的一对。"

林牧端起自己的酒杯也喝了一口。青梅酒挂杯底——他仰头时杯口在映月轮下闪了一下。"也是劈柴最多的一对。"

苏晚又把杯子递过去碰了一次。"最多的。"

"还会更多。"他的这句话不是在嘴上说的——是功德绳上传来的。传过来的同时还有一整段被压缩成一瞬间的画面:以后无数个早晨他在院子里劈柴，她在后院浇花。劈到一半他把斧子放下端起茶杯——杯是温的，是她刚才去厨房加水时顺便把他的杯子加满的。她浇完花回来看到他在喝茶——不用说话，她也端着自己的杯子坐到他旁边的树桩上。银杏叶在他们头顶极其缓慢地在风里旋转。她腿上放着笔记本。他腿上放着工具箱。

苏晚把功德绳上的这个画面收下。然后她把自己木心上的酒渍用拇指擦掉——对着映月轮的光看了一眼木心表面。木心被酒润过之后木质纹理更清晰了——年轮之间的密度变化在她拇指下微微凹凸。她用功德绳发了当晚最后一段话——不是文字，是一段包含了很多层意思的复合感知。

"以后如果有人在仙缘司档案室里翻到名录——翻到我们的名字——他会发现后面的注释特别长。不是因为我们做了什么大事——是因为你劈柴的次数太多被自动记录成了功德。天道不知道怎么归类'劈柴'这种功德——所以就单开了一栏叫'日常'。我们的日常栏是最满的。满了十万多行。"

林牧收到后把酒杯放在木心旁边。功德绳上他回了一句她没想到的话:"你去看看天道勘验记录的底部——'劈柴'那行旁边标了一个小星号。我那天勘验时看到了。星号的意思是——此功德为循环型，每劈一柴计一次。自动续。"

苏晚笑了。她拿起酒杯把最后一口梅酒喝掉。梅子从杯底滑到她唇边——她咬了一口，酸得直皱眉头。梅子太酸了——松鹤仙人泡的时候糖可能没放够。

"梅子不够甜。明天去南离城买点冰糖——加进去再泡。"

（第五百二十三章 完）

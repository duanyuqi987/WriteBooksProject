# 第五百二十二章 天道勘验

在灵魂对话和共创功法的大突破之后，两人在仙界的存在开始被五方仙域的更高层机构注意到。并非因为这些机构盯上他们——而是仙界的功德体系是自运转的。当一对道侣的灵核共振进入"通灵"层次时，功德池中的因果天平会自动触发一项极罕见的勘验程序——天道勘验。这项勘验不是人发出的，是仙界的因果法则自动发起的。目的不是考核，是"登记"——把一对达到通灵层次的道侣从普通红绳登记册中单独抽出来，编入仙界的"通灵道侣名录"。这个名录极少——据说近数万年来整个上界达到通灵层次并正式通过天道勘验的道侣不足十对。

勘验的过程不是在法庭或大殿里进行的。它直接在道场上发生。那天的中午，双星图道场上空忽然自行凝聚出了一团极淡极淡的金色云气。云气从四面八方向太极鱼中心汇集，汇成一道直径约一丈的金色光环。光环悬在半空中缓慢旋转，每一次旋转都释放出极低沉的因果共鸣声——那声音不是通过空气传导，而是直接在他们灵核中响起。

苏晚和林牧对视了一瞬——通灵让他们同时知道这不是攻击。他们站起来走到金色光环下方。光环的中间投射下一道极其柔和的光柱，将两人笼罩在同一个光圈里。然后他们灵核中的历史记录——从万年前的前世到现在的全部——被这道光照亮。那不是审判——他们能感觉到光只是在"登记"。每一项被光照亮的记忆都被光环以极温柔的方式编码成一道极细小的金色符文，存入光环上方虚空中的一本无形名单中。光扫过的过程很慢，但没有任何痛感——只有在扫到两人灵魂中那些最暗最深的疤痕时，光环会多停一会儿。好像是在极郑重极小心地把这份疤痕也录入。因为天道认得，道侣之间最珍贵的东西不是完美——是各自的伤疤被对方接住的那个共同档案。

勘验持续的时间不长不短。金色光环将两人释放后缓缓消散于空中。光环消散后在道场古树的全部枝叶上留下了一层极薄的金粉——金粉在风中轻抖了几下之后融入树身。自那天起，双星图道场有了一种新的仙韵——来到这棵古树下的道侣自动会比在同一棵树下的普通仙人更容易心灵交流。古树变成了一棵天然的"共鸣树"。这是天道勘验后的附带效应——经过验证的通灵道侣曾在树下修炼过的地方，会留下永久性的灵魂共鸣场。

苏晚在勘验完成后用手摸了一下古树的树干。树干不是凉的——是微温的。像他和她手心的平均温度。

（第五百二十二章 完）

# 第五百四十二章 实力质变

合道巅峰给两人的日常也带来了质变。不是他们使用力量的方式变了——而是力量在极细微处自己渗透进了他们的日常。苏晚浇水时不用再弯腰——水滴自动从壶口飘起按照她心中想的方向精确地落在每片叶子根部，不多一滴不少一滴。林牧劈柴时斧子不用再全臂使劲——他把斧刃放在木头的顶端上手指轻轻一压就劈开了，因为合道巅峰的空间感知力让他能精确地看到木材纤维内部最脆弱的那条纹理线，斧刃沿着那条线下切不需要蛮力。

但这些都不是质变的核心。真正的质变发生在那天下午的一次突发事件。在迎仙台边缘的山脊上突然出现了一道非法打开的虚空裂隙——一只被某个违规实验撕开的口子从虚空中伸出极多黑色触须，正在侵蚀周围的仙草植被。这种虚空侵蚀一旦扩散就会危及整个迎仙台的旧阵基。放在以前两人需要拔剑去战斗去封闭裂隙——但现在苏晚只是站在离裂缝远处用功德绳同步感应到林牧从另一个方向以合道巅峰的空间控制力把裂隙边缘的空间法则局部重写了一遍——他把裂缝口的空间密度从负数调成了正数，裂缝被自己的空间张力挤压闭合。全程大概不到几息，两个人都没有拔剑。

裂隙封闭后松鹤仙人背着手走过来看了一圈——然后啧啧地叹了一声。"老天——你们现在打架都懒得拔剑了。"林牧说:"拔剑要擦。不拔省事。"苏晚补充:"他的斧子留在柴堆那边——顺便今天劈的是松木。松油的香和虚空裂缝的焦味混合后意外好闻——像烧柴火。"松鹤听完翻了个白眼——但他转身走开时还是在破布袍的遮掩下偷偷笑了。

晚饭后两人在道场上再次查检了太虚试炼的具体测试细则。他们发现第三关"独立人格"测试中有一条细则:道侣两人将各自被放入一个完全孤立的模拟人生中——在这个的人生中，他/她将遇到一个"完美道侣"的幻影。这个幻影会诱导测试者放弃与真实道侣的绑定。通过的标准是——测试者在不被任何人告知的情况下主动拒绝这个幻想，并从一开始就知道"对面的不是你。不管多完美——都不是你。"这一关才是终极考验。不靠修为，只靠心。

苏晚看完细则后沉默了好一会儿。然后她轻声说:"这一关——其实我们早就过了。"林牧点了点头。因为在百世轮回中，每一世他都是在一个全新的、可以选择不去找她的前提下，仍然主动走向那片完全不记得他的空白灵魂。他每一世都在重复同一场"独立人格"测试。而她——也是。

（第五百四十二章 完）

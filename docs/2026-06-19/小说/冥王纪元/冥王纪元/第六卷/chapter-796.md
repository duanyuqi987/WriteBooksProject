# 第796章 最后到达了混沌本体的封禁地

在无时空域中的守护不知持续了多少纪元。

宇宙的外部依然不停不息地运转着。帝国建国六百年、七百年、八百年——每一年冥王帝国内都会有一个纪念日：奠基石所在的中央星广场上，会静静地燃着一百盏灵灯。每一盏灯代表着一种守夜人的象征——不是对某个人个人的崇拜，是一种对自己文明从泥土中崛起、在风雨中走到现在的持续警惕。灵能学院里的小孩子会被老师带到广场上，面对灵灯闭上眼睛冥想一节课。不是在领受教化——而是学校的课表上写着"感知纪元沉静"。

封玄在帝国建国第七百年左右去世。他走的时候很安稳——吃完一碗热拉面，坐在黄瓜架下眯了会儿眼，然后就再没有醒来。他走的那天早晨做了件他平时很少做的事：他把黄瓜架下的老藤椅搬到院子里最晒的那块地方——而不是平时偏向荫凉的位置。陪了他几十年的那只老猫跳到他膝盖上——他用粗糙的手掌顺着猫的脊背，一下一下地，次数不多——大概十几下。然后他把头靠在椅背上，眯起了眼。猫从他膝盖上跳下来——回头看了他一眼——然后走开了。他是正午走的。阳光正好从黄瓜藤叶间漏在他脸上——光斑是碎的，一小块一小块。他的脸走的时候很平静，嘴角有一点向上的弧度。冥离祖孙把他葬在第五纪元盟友祖园的中央——旁边种了一棵新种的黄瓜种子。他的墓碑上刻着他生前自己选的一句:"这里的人睡了，不要叫醒。"

封玄走后，黄瓜架还继续长了好多年。冥离每年春天都会在架下撒新种——种法和他姥爷一模一样。第一年黄瓜出苗的时候，她蹲在苗旁边看了很久——然后继续浇了水。浇水的手法很旧——是封玄教的——把瓢口贴着土面斜着倒，不砸苗。她不会说想念的话——封玄说想念不用说出来，做一样的事就是最重的想了。

龟相在封玄去世后的一段多年中持续守护着知识——但它自己的身体也在极其缓慢的衰退中走向衰老。它不是死了——玄武血裔的死亡不像人。它在某一天的晨曦阳光下停止了呼吸——龟壳上的八角阵图在那之后仍然自行运转着八十多年，最终才缓缓变成了自然纹理。它的壳被帝国博物馆收为所有——上面最后维持的一丝灵力，是它生前为冥王令传承者保留下来的屏障基底——那道微弱的余震在博物馆的灵能室中延续了千年。所有造访其馆的人都会在入口处停下来——不说话。小孩子们有时候会拿手在离壳很近的地方悬空摸——不敢真摸——龟壳上那层古老的光晕会微微亮起来，像在回应。博物馆的讲解员每次讲到这里都会停一停——不是哽咽——是有些东西不适合用音量去讲。

在失去多数早期元老们的时代中，帝国由陈远志和更年轻的一代持续领导着。老陈曾孙今年一百多岁了。青芒剑已配在他腰间几十年，它的剑柄被老陈家人一代代的手磨得光滑如镜。他领着帝国舰队在宇宙边缘继续着日常巡逻——但战争已经成为历史书上的旧事。新的跨银河灵能通道在日常启用中形成了连通的交通网络，文明在连结中不断深化相互交织。

在星球学校中有一位灵能教师——她自己是从帝国边境矿区出身的普通女孩子。她教小孩子们在灵能训练课上用笨拙的小手第一次感应灵脉。她看着他们一个个睁大亮晶晶的眼睛——第一次感知到大自然中那流遍一切的灵能的温暖。"老师——灵路会消失吗？"

"不会。"她轻声回答——下意识摸了摸自己手腕上那道细小的灵根测试伤疤。那是在她六岁时在校测中留下的——当她知道自己有灵根的时候开心得哭了一整个下午。她现在是这两个班的几十个刚感知到灵源的孩子们的发蒙者。"灵能会一直在。因为我们有很多很多前辈帮我们把它保存下来了。"

如果有人从遥远的星空里向中央星广场看去——他可以看到一百盏灵灯中有一盏特别的款式——那个灯具和其余的略有不同——它的侧面刻着一颗小小的、被磨得光滑的黄瓜。那不是任何人的意——是封玄在灯座底部悄悄刻上去、然后什么都没说的老头的习惯作风。

而在零点不可触及的深海中心中——混沌本体极度沉睡着——压了无数纪元第一次睡得如此深沉。它的周围沉静地平铺着由陈霜最后的剑意和李长生最后的冥王令光芒融合锻成的那层护墙——护墙完全透明——不阻断任何正常宇宙的运转——只在所有可能侵入的异常力量接触到封禁层前主动化解成一阵温暖成微弱的灵能飘散回回路。这个护墙的质量是实质的守护，但它的来源是两个早已融于无的人。历史书上会写"最后行动不明"。但护墙自己知道。

（第796章完）

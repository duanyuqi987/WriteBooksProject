# 第492章 宰相小王

小王被册封为帝国宰相的那天，他正在修一条灵气监测算法。

早上七点，他坐在自己那间堆满设备和杂物的办公室里——不到二十平方米的窄屋——笔记本屏幕上跑着十二个监测终端。他一边盯着实时数据，一边单手敲键盘改一条报错代码。他的眼镜滑下来几次也没去推，只是偶尔用食指顶一顶镜架的鼻托。门被推开的时候他头也不抬，只说了句："早餐搁桌上，别碰到散热口——热。"

站在门口的是李长生。

"小王。"

小王抬手做了个"稍等"的手势，把刚刚写的最后一行代码跑完——界面上跳出一个绿色对勾——然后才摘下耳机站起身来。

"头。你早。"

李长生站在窄办公室里，环顾着满墙乱贴的各种数据图和文件勾划——他知道这就是这个星球上最能干的人的工作环境。他说："小王——你是我的宰相了。正式的。"

小王愣了一瞬。他的第一个反应不是高兴，是认真地推了一下眼镜。然后说："你把一个当了十多年程序员的人封成宰相——信不信说出去全银河都会开始质疑我们的组织架构。"

"你比我更适合管这些事。"李长生说，语气平常得像在说"今天太阳好"。

小王沉默了片刻。程序员的头脑在零点几秒内迅速检索了所有可能的后果——有整个帝国的行政管理，有无数跨文明的贸易纠纷，有从朱雀星盟到星都王朝的复杂外交关系——最后他想到的是一行老代码：if __name__ == '__main__': main()。从今以后，main函数的主体就是一个横跨银河系的超级政权了。

"行。"他说，"既然是正式的——那我得从今天起重新规划行政管理框架。现有系统是临时堆起来的——许冰的临时手册撑不了多久，老陈那边的军事调度全靠他的个人经验——这些会自动失效。"

"你知道怎么做。"李长生说，"按你的思路来。"

当天下午，小王在龙组基地的大会议室里召集了第一次正式的帝国行政会议。来参会的人有帝国体系内的所有核心成员——老陈、刀疤、许冰、老马、小旺、龟相——以及龙组的百岁老修士和国家灵气局的官员代表。会议室里的布置很朴素：一张大桌，一些木椅，一面星图墙，和一柜子文件。

小王没有坐主位。他把主位空着——李长生也没坐，李长生靠在窗户边上。小王坐在和所有人平级的桌次位，打开笔记本，连接星图大屏，开始了他作为帝国宰相的第一项陈述。

"守护秩序目前面临的行政问题——核心在三个：第一——没有统一的行政分级。现在从银河西臂到华夏李家庄，中间没有省级、没有星区级——一个文明直接被首都管。这在任何行政体系中都不可持续。"

"第二——没有司法部。许冰的法律体系已经建立了基本法典，但没有执行机构。也就是说我们目前的文明——有立法机关，但没有司法机关。违法的人没有人负责抓。"

"第三——没有中央银行。没有统一的经济政策。各个文明之间的灵石兑换率五花八门——有人用稀石计价，有人用高级灵草计价，有人还在以物易物。长期下去经济会乱。"

他说得很快——但每一个点都精确到了具体数据。他的笔记本屏幕上跳出了配套的图表——有各文明灵石兑换率对比表、有目前跨星域纠纷的统计数据、有根据星图数据预估出的行政分级方案的框架。在一个上午的时间内独自完成了未来帝国管理的基本框架推导。

会议室里安静了一会。李长生在窗边沉默地听着——他不是不懂这些，而是意识到：小王确实是他能找到的最佳选择。一个在地球上当了几十年程序员的普通人，用他的系统思维和数据处理能力——撑起了一个横跨银河系的文明。

会议进行到第四十二分钟时，小王抬头看了看窗外的天空。忽然说了一句："做宰相不是处理数据——是帮助人们互相理解。数据只是辅助——真正重要的，是我每次处理完纠纷后，双方都能带着而不是仇恨离开。"他把眼镜推到鼻梁上，停了一下，又说:"我不喜欢玩权力游戏。但权力游戏必须有人去玩。与其让别人玩坏了，不如我去玩——我保证不会玩坏。"

李长生对着窗口弯了一下嘴角。他说："好——你当宰相，我放心。"

（第492章完）

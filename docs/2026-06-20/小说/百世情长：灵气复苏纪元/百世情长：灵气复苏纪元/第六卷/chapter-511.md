# 第五百一十一章 相互理解的泪水

共情试炼之后的这天，苏晚去了趟同心树。

她不是去换木牌——木牌刚换过。她是去树下独处一会。因为那些百世记忆加上共情试炼里的灵魂经验，像一本极厚极厚的大书刚刚被她从头到尾翻完。翻完之后她没有急着合上书——她需要把尾声再看一看。

她在同心树下坐了很久。头顶千万飘荡的旧红绳和旧木牌被晚风吹得叮叮当当地响。她听着这些被挂上去又褪了色的无数道侣的旧誓言——每一道木牌背后都有一段或大或长或小或碎的爱情。有些还亮着，有些红绳已经断了只剩两个窟窿眼。她把目光从那些断了线的木牌上收回来——然后低下头看着自己的功德绳。还在亮。林牧在迎仙台修飞仙舟——他在很远的地方。但金线还在闪——频率稳定而柔和。她把金线翻了个面——金线里隐约映出了她自己的倒影。倒影被金线拉得极细极小，但轮廓很清楚。这张轮廓和一万年前的苏晴晚是同一张。然后她的眼泪流下来了。

不是百世压抑的大哭。是一种极缓慢的泪水——从眼角溢出后在脸颊上风干，然后又一滴，然后又干了。这不是悲伤。是一种极深的"终于"感。她终于完整了——不再是带着灵魂碎片活着的残片人。不再是只有这一世记忆的苏晚。不再是那个在灵医院里不知道自己为什么会无端想哭的普通女孩。她现在是完整的。她把百世全部记起来之后，反而更平和了。因为知道了所有的离别之后，她更加确认眼前这个还在修飞仙舟的、劈柴煮饭的、在银杏树下给她刻木牌的人是从第一世一直陪她到最后的不变的人。

林牧在飞仙舟旁感应到了她的眼泪——功德绳另一端传来了极微弱的湿润感。他没有问她为什么哭。他用功德绳发过来一种极简单极清晰的感觉——不是任何一句"别哭"。是他用灵魂层面的意志把她的手握了一下。就像那次在旷野上飞升通道降下来前他握住她的手。苏晚在树下把功德绳贴在额头上——用这极淡极柔的金线把眼泪拭掉了。然后站起来，回迎仙台帮他修船。

（第五百一十一章 完）

# 第837章 万年后的现身

万年祭午夜之前，封禁地里，李长生和陈霜正在做一件极为平常的事：看家书。

混沌通信站在一万年内积累的所有消息——从第一年到第一万年——被整理成了一份巨大的数据包，通过一条特级权限通道直接进入了封禁地的意识层。不是灵符帧，是一万年的全部心声。李长生和陈霜没有试着全部读完——那需要再花一万年。他们只是随机浏览，像两个老人坐在炕上，翻一本记了一万年家事的旧账本。

"这条——是八千三百年前的一个孩子写的。她说她养了一棵树，叫'冥王树'，但其实是一棵普通的枣树。"

"这条——九千年前一个老头写的。他说他太爷爷是李家庄人，但他自己出生在仙女座，一辈子没回过地球。他说他想回。但没有船票。后来他就每天黄昏在居室的窗台上点一盏小灯，朝着太阳的方向发呆。他死前写了一句遗言——'灯不灭'。这行字就被邻居们记进这一年的通信帧，加注为个人非官方请求——不要任何回复。"

"这条——一百二十年前。一个刚学灵符的幼童。他用脚趾敲了整篇基础灵符中的十六字全正文，敲了七天。敲完最后一行后面全部空白，他大概不知道空格回撤。"

李长生停了在那里。不是那条灵符的内容。是那种"敲了七天"后茫然不知发没发出去的状态，很像他当年用第一次灵力去替水井加热——不知道成功了没有，但照样再去挑一担水。

"我想让他们知道——我们还好。"他说。

"那就现身。"陈霜说。

"可以吗？"

"混沌本体说——我们的肉身已经分出去太久了，不能直接回收。但用光织形，短暂现身——在封禁地的能力范围内。只是不能太久。最多——十息。"

"够了。"李长生说。

混沌本体为他们编织了两道极为细微的光束。不是能量体，不是灵力投影，而是两片意识映射——直接从封禁地的核心光网临时拓印到地球上空。它们没有力量，不能触碰，不能灵力交互——只是光影和情绪的无形投射。所有的感觉都在目力可及的界面内——就像站在旧宅门口对村子里的人挥手。不能跨出门，但可以被看起。可以被看见。

这就是为什么在那天午夜，李家庄的夜空亮起了两道光。这就是为什么两道光中浮现了两个隐约的人影。

不是幻影。是他们本人——用唯一一种可以在不离开封禁地的条件下现身的办法，回到了出发的地方。

在现身的十息里，李长生看到了很多东西。看到了村口大槐树——它还在，婆娑的树冠比他小时候还茂盛。看到了那尊蹲着雕像——他看清了上面的泥痕，和自己一模一样。看到了石板下面是后代们留的一摞信——其中一叠信角压着两枚磨损严重的解放鞋。看到了他自己家的老宅子——院里那棵柿子树已经伐去数代，但后人用原树两次插枝，老宅一直有柿子树。然后看到了祖坟——坟头干净，碑前有卤肉和白酒，三根烟并排搁着。然后他看到那堆来自各个维度的土——紫土、白砂、赤色豆沙——全放在黄土地——他的手心里不由自主地发热。

他什么都没说。让情绪直接流入光中。让每一个在场的人都感觉到那三句话。不需要更多。一万年的守护，不需要在十息里说清楚。只需要对方知道——还在这里，没有遗憾。

十息过了。光开始上升。陈霜光中的手在他肘上轻轻按了一下——是提醒他该走了，也是对着下边那些星星点点的不灭油灯留下一个未断的回执。临消失前那一刻，她把眼中的青崖向地底微搁半寸——是剑修的剑末致意：面对无数世纪数不尽的守护者，她代他致了一个——剑尖向土，不朝前，朝下方的祖坟旧泥。

光消失。两人重新回到了封禁地内。

在同一时刻，太阳系的边缘——冥王星的地核深处，一道沉睡了整整一万年的封印裂开了一条缝。

那是冥王陨落前用三分之一冥力刻下的保护性封印。茧房内封着他的女儿冥瑶。时间流速被压到外界的百分之一——外界一万年，茧房内只过了一百年。封印的锁芯只认一个灵力签名：冥王本人的冥力频率。万年来没有任何力量能够撼动它。但李长生现身的那十息里，他的冥纹与冥王同根同源，灵力频率几乎完全重合。那道封印感知到了这个频率——不是完全一致，但足够接近。足够让它在万年的沉寂之后，第一次将锁芯转动了半圈。

茧房内，冥瑶睁开了眼。她在黑暗中盘坐了一百年——维持着筑基修士的龟息态，意识半醒半寐。她感觉到了那道裂缝。不是震动，不是声音。是一道锁死了一万年的门，忽然透进了一丝光。她伸出手，指尖触到茧房内壁。壁上的冥纹正在松开，一层一层地，像冻了一万年的冰终于开始融化。门已经不是完全锁着的了。

冥王星地表仍然覆盖着零下两百度的冰层。但在它地核的最深处，一个等了一万年的女孩，终于听到了门外的第一声响动。

封禁地内没有任何改变——光网依然在脉动，混沌本体依然在一旁安静地陪伴。但李长生感觉到了一种从未有过的平静——不是从痛苦中解脱出来的平静，是确认之后的平静。确认他走的路没有错，他守护的人值得他守护——并且他们也守着他，守了一万年。

（第837章完）

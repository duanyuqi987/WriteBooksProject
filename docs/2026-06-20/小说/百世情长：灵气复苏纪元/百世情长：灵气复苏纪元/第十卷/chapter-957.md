# 第957章 银杏树下的碑文

下界时光已过了不知多少纪元。文明换了数轮。太行书院早已不叫太行书院——但银杏树还在。树下的保护栏和石碑也还在——每隔数十代就会有人重新刻制一遍碑文以延续文字。但碑文的内容永远是相同的三行：

"修行不是变厉害。修行是成为更好的自己后，转身托起下一个需要被托起的人。——苏晚"

"我不确定。但不做的话——连不确定的资格都没有。——林牧"

"收徒不收钱，不论来历，不看出身。太行书院——永远不收门槛。"

这座碑成为了整个修仙界的"圣地级"存在——不是因为宗教崇拜，而是承载了一种与权力无关的文明肇始记忆。每年有数以万计的年轻修士从各地踏上朝圣之旅——不是跪拜，不是许愿——他们只是在银杏树下坐一个下午。体验那种被尊重、平等对待的感觉，然后把那感觉带回自己的家乡。

这年——一位从极远之地徒步了三年来到银杏树下的年轻散修（他的修为极低，但态度极其坚定）在树下静坐时，忽然在地上捡起了一片被风吹落的银杏叶。叶面在日照下隐隐浮现出一行字——不是有人刻意写上去的——是苏晚在无数年前用指尖画在当年这片叶子的脉络中留下的道纹残影。字的内容是："你也配修炼——因为你生来就有灵气。它不是别人赐的——是你的。"

这位年轻散修把这片叶子捧在手里——眼泪滴在石板上。他走了三年才到这里来，就为听到这句"你配"。现在他从银杏叶上读到了——不是从任何活人的口中。是在远古某日的一个女人看到他与未来的他之间跨越无数时光发出的一个确认。他把叶子带走了——带回去之后成了极偏远小山村里第十万个微书院的第一位老师。

类似的事在历史长河中反复发生。苏晚在某次投影中目击了一个极偶然的瞬间——一片她自己都没有记忆的旧叶，因为当年叶脉的一丝道韵残留而被某位敏感的心灵捕捉并转化为改命的动力。她明白了一件事：教育不依赖"当面"。真正的教育是把种子散播在任何可能出现的地方——哪怕是一片偶然的叶脉——然后让它自趋生长。相互尊重在终极时间尺度上的形态就是这样——你已无法亲手帮助每一个后来的求道者，但你的存在已化为叶脉纹理的一部分，供任何有心人在任何时代触摸。

她从投影中回来之后对林牧说："银杏叶比我授课更有效。因为它不说话——人得自己去读。自己读出来的东西更容易刻在心里。"

"你才是最有效的——因为你当年选择不说，只发叶。"他补充。

苏晚看了看纳戒中的近万片叶子。"我有一万句话已经被它们说出去了。"

# 第十七章 前世记忆的初次闪回

星期二上午九点四十二分，茶水间。

林牧站在饮水机前，杯子已经接满了，但他的手没有动。热水漫过杯沿，滴在他的鞋面上。他没感觉到。

因为苏晚就在他右边三步的地方，正在从咖啡机里接咖啡。

这不是他们第一次同时出现在茶水间。同在一个公司，抬头不见低头见。但今天是第一次——真正意义上的第一次——林牧带着明确的意愿，想跟她站在同一个空间里。

昨天夜里的那个梦还在他的脑子里发烫。

白衣女子。人群中的笑容。"下一世我会来找你的。"

后来的事情他记不起来了——什么代码脚本，什么灵气数据分析，全都被那个笑容盖得严严实实。他闭眼就是她的脸。睁开眼就是想去公司看看苏晚。

他不知道这是不是前世的爱人。

但他知道一件事：那个人，和苏晚，有同一双眼睛。

"林哥，你杯子满了。"

苏晚的声音。

林牧回过神来，低头看见饮水机的接水槽已经变成了一个微型湖泊。他把杯子端起来，抽了两张纸巾去擦水槽的边缘。

"想事情呢。"他说。声音比他预想的更沙哑。

苏晚笑了一下。不是客套的笑——她每次笑都是整个脸都在笑，眼睛弯成两道浅浅的弧线，嘴唇抿着，像一只被顺毛摸舒服了的猫。

"最近好像都在想事情。"她说。咖啡机停了，她端起来，转身要走。

"苏晚。"

她站住了。

林牧忽然不知道说什么。他叫住她是因为那个梦。但"我昨天晚上梦见你了"这句话怎么说都不对——太唐突了。他说不出口。

苏晚转过身来，歪着头看他，等下文。

茶水间里很安静。角落里那台用了不知道多少年的冷藏柜发出低沉的嗡鸣。阳光穿过百叶窗，把她的影子切成很多条平行的线。

林牧张了张嘴。

就在这时，苏晚忽然往前走了一步，把咖啡递给他。

"你脸色不太好。"她说。"没睡好？"

这是很普通的同事间的关心。再正常不过。

但问题出在动作上。

她递咖啡的时候，左手端着自己的杯子，右手递过来。林牧伸手去接。杯子从她手里到他手里——过程不到一秒钟。

她的指尖碰了一下他的手背。

就一下。

轻得不能再轻。像一片树叶落在水面上。

然后林牧的大脑爆炸了。

不是比喻。是真的爆炸了——画面。声音。气味。触感。情绪。所有的东西像被一斧子劈开了尘封的闸门，从记忆的最深处倾泻而出，速度快到他的意识根本来不及处理。

悬崖。

一个女子站在悬崖边上。白衣胜雪。长发及腰。风吹得很急，她的衣服和头发都被吹得向后飘起来，像一面被人扯开的绸缎。脚下是万丈深渊，深渊里浮着云雾，像翻滚的牛奶海洋。她站在最边缘的地方，脚尖前面两寸就是虚空。

她在笑。

不是开心的笑。是那种——已经决定了，已经放下了，已经什么都无所谓了——的笑。

她的嘴唇在动。声音很轻，但很稳，一个字一个字地砸进林牧的耳朵里：

"下一世，我还会来找你的。"

然后她向后倒去。

不是被风吹倒的。是她自己倒的。她的身体像一片白纸，从悬崖边缘坠下去，转了一个圈，然后被云海吞没了。

林牧——前世的那个林牧——冲了出去。他的手伸到最长，指尖碰到了她的一片衣袖。白色的绸缎在他指尖滑过去，滑过去，然后没了。

什么都没了。

悬崖、云海、白衣、她的脸。整个世界只剩下一片猩红——那是夕阳的颜色。也是血的颜色。他不确定。

画面切换。

另一个场景。还是那个悬崖。但天气不一样。之前是夕阳，现在是深夜。没有月亮，只有星星。满天繁星，密得不像人间的天空。

林牧站在悬崖边上，白衣已经不见了。他看清楚了那天晚上的自己——不是现在的样子。身量更高，肩膀更宽，眉心有一道隐隐的剑纹。穿着和所有青云弟子都不一样的黑色道袍。那是青云宗首席弟子的袍服。

他手里握着不归剑。

剑身上有血。

不是敌人的血——剑尖上还挂着三个血字。刻在悬崖的石壁上。笔画很浅，但每一笔都刻得很用力。

字写的是：苏晚。

那个名字刻在石头上，被星光和血染成了一个颜色。

然后他抬起头，对着满天星辰说了一句话。

"我会等。等一百世，也要等到你。"

风吹过来，把他的道袍吹得猎猎作响。不归剑在他手里微微颤动，像在哭泣。

"林牧？林牧？"

有人在叫他。不是前世的声音。是现在的声音。

林牧猛地睁开眼睛。

不对——他本来是睁着眼睛的。只是刚才那些画面出现的时候，他的瞳孔对焦在某个不存在的地方。他的大脑被那些前世记忆彻底霸占了。现实世界从他的感官里消失了至少——他看了一眼墙上的挂钟——三秒。

三秒钟。

但对于他的大脑来说，那三秒像过了一百世那么漫长。

他回到现实。

茶水间。百叶窗。冷藏柜的嗡鸣。手里的杯子——

咖啡洒了。

不是洒在地上。是洒在他的右手上。杯子不知什么时候被他握碎了——不是用拳头砸碎的那种碎，是被手指捏碎的。杯壁上出现了一条裂缝，咖啡从裂缝里漏出来，顺着他的手腕滴到地上。

咖啡是滚烫的。

但他的手不疼。

一点不疼。

林牧低头看着自己的右手。虎口位置有一道浅红色的印子——不是烫伤，是被碎瓷片划出来的。但那道印子正在以肉眼可见的速度消退。就像有人在皮肤底下用一支隐形的笔把红色一笔一笔抹掉。

淬体初期。这点伤，已经伤不到他了。

"你没事吧？"

苏晚的声音。

林牧抬起头。她还站在他面前，脸上的表情是纯粹的担心。不是惊恐——只是一个普通人看到同事出了状况时的正常反应。

她不记得他。

她什么都不知道。

悬崖上的白衣女子。那个对他笑的人。那个说"下一世我会来找你的"然后坠入云海的人。

她什么都不记得。

林牧忽然觉得喉咙被什么东西堵住了。不是想哭——是胸口有一团很重的东西在往上涌。那种感觉很难描述：像他在一个漫长的隧道里跑了很久很久，终于看到了出口的光，但跑过去发现那光的后面还是隧道。还有更长的一段路在等他。

"没事。"他听见自己的声音，干涩得像砂纸在玻璃上刮。"杯子质量太差了。"

苏晚从旁边的纸巾盒里抽出好几张纸巾递过来。

这次她很小心。没有碰到他的手。

林牧接过纸巾，擦拭手上的咖啡。裂缝的杯子被他放在吧台上。他擦得很慢，很认真，实际上是在用这个动作拖延时间——他不知道如果现在看向苏晚，他会不会哭出来。

"林哥。"苏晚的声音很轻。

"嗯。"

"你最近是不是压力很大。"

林牧抬起头。

苏晚站在原地，没有靠近也没有退后。她的眼睛很亮，但不是那种兴奋的亮——是那种注意到了什么的亮。像她看到了什么东西，但不确定该不该说。

"为什么这么问。"

"因为你看起来像一个人在扛什么东西。"她说。语气平平的，像在说今天的天气。"我见过很多压力大的人。他们不是你这个表情。你这个表情不是压力。是——"

她停了一下，想了想措辞。

"是害怕。"她说。

不是害怕。是等了太久。

林牧在心里纠正她。前世的林牧站在悬崖上，对满天星辰说等一百世也要等到她。这一百世不知道过了多少世，而他现在站在茶水间里，手里握着一个碎掉的咖啡杯——那个他等了一百世的人就在他面前，但什么都不记得。

他不知道该高兴还是该难过。

高兴的是她活着。难过的是她不记得。

高兴的是他们又相遇了。难过的是只有他一个人在承担所有的记忆。

高兴的是前世的承诺兑现了。难过的是兑现的方式比承诺本身更残酷。

"苏晚。"林牧说。

"嗯。"

"你相信前世吗。"

问完他就后悔了。这个问题太突兀了。一个普通的IT男同事，在茶水间里，因为一杯打翻的咖啡，忽然问你相不相信前世——正常人会觉得他疯了。

但苏晚没有露出奇怪的表情。

她想了想。很认真的那种想。不是敷衍不是回避。

"我不知道该不该信。"她说。"但我有时候——"

她没说完。有人推开茶水间的门。是技术部新来的实习生，看到他们两个，愣了一下，说了句"就接个水"，然后飞快地倒完水出去了。

苏晚被这个打断弄得不自在了。她笑了一下，端着杯子往门口走。

"苏晚。"林牧又叫住了她。

她停下来，回头。

林牧有很多话想说。想问她梦见的那个人是谁。想问她能不能感觉到空气里的灵气。想问她知不知道自己的前世。但最后他只是说了一句：

"那个杯子——不疼的。"

苏晚愣了一下，没明白。

林牧举起右手给她看。虎口上那道红印已经完全消失了。皮肤完好如初，甚至连一点干燥的痕迹都没有。

苏晚低头看了看他的手，又抬头看他的眼睛。

她没有问为什么。

但她看他的眼神变了——不是恐惧不是惊讶。是某种林牧没有预料到的东西。

是一点点的熟悉。

好像她也看到了什么碎片。但她不确定。

"下次。"苏晚说。"下次再聊。"

她推开门出去了。

茶水间里只剩下林牧和那个碎掉的杯子。

他站在原地，看着门口的方向，看了很久。

手背上，她指尖碰过的地方，还有一丝极淡的触感残留。不是温度——是某种比温度更深的东西。像一根看不见的线，从她的指尖缠上他的手背，然后顺着血管一路往上，在他心脏的某根瓣膜上打了个死结。

林牧深呼吸。

把碎杯子扔进垃圾桶，把地上的咖啡擦干净，端着半杯凉了的水回到工位。

坐下来的第一件事是打开一个新的浏览器标签页。

他在搜索框里输入了四个字：

"苏晚 前世"。

搜索结果是零。他预料到了。她只是一个普通公司的普通财务——如果不是那根线，不是那个笑容，不是那三秒钟的闪回，她和他之间不会有任何联系。

林牧删掉搜索词，靠在椅背上。

桌面上，项目经理又在群里发消息了。下周排期，需求评审，版本发布——一切照旧运转，好像这个世界什么都没发生。但林牧知道不一样了。从他三秒钟闪回的那刻起，一切都不一样了。

苏晚在这里。

他要保护她。

不管她记不记得，不管她知不知道，不管她信不信前世。

这一世，他不会再让她从悬崖上坠下去。

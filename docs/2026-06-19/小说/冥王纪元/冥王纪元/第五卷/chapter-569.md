# 第569章 李长生面临最严峻的考验

巨力仙王的第二拳来了。

这一拳不是从正面轰过来的。是连同万象仙王新布的三十七道阵法一起，从四面八方、从所有时间点和空间角度同时轰过来的。万象仙王通过叠加空间扭曲类型的阵法，将巨力的一拳复制成了三百多拳——每一拳都带着同等强度的纯粹物理毁灭力。而巨力仙王自己的拳头也到达了——穿过自己那三百个被复制的拳影中最中央的轨迹，真实且致命。

李长生站在这些攻击的中心。

他没有退路。三十七道阵法中的一道是新布下的空间封闭阵——万象仙王专门针对"否定距离"的冥术能力修改了这个阵法。在被封锁的空间内，否定距离的能力无法发动——否定本身需要的存在参照被阵法扭曲到了无法定位的目标上。

这是万象仙王的可怕之处。他在到来的这几天里，已经专门针对李长生的能力进行了分析并且研发出了逆向破解阵法。

李长生没有否定距离。没有存在分裂——灵魂还没从上次的伤中完全恢复。冥王令的暗金色光芒也由于连番消耗显得黯淡了不少。

他站在中心，看着前方三百多道致命的拳影，以及这些拳影后面两个完全同步灵力循环的仙王。

"你不是要突破吗？"巨力仙王大笑着挥拳，"那就在死之前突破啊！"

这句话像一根针，刺进了李长生的意识深处。

突破。他一直在想突破。他感觉自己就差那么一点点——就像雾气中看到了山，但走不过去。桥在哪儿？

他抬起右手，冥王令的光芒在掌心中微弱地闪烁。他能感到自己承受的上限已经在到达临界——被击中的那一拳震动了他整条脊椎的信息在颅内不断回响。如果再来一拳同样的力道，他可能撑不住。

然后他听到了一个声音。

不是陈霜的声音。不是小王。不是记忆中的任何人。

是龟相的声音。

"吾主。老臣有一句话，憋了一万年了。"

李长生在神识中并没有呼叫龟相。老头是主动穿透冥王令内部的太阴令共鸣通道直接在他脑中说话的。代价是他的神识从地月系地底延伸到外围战场的真空中，消耗极大。

"说。"

"冥王当年之所以无法突破混沌级，是因为他放不下。他放不下冥王殿，放不下麾下百万鬼兵，放不下地球七十二亿凡人。冥术的根基是对存在的否定——否定别人的存在容易，否定自己的执念难。您比当年的冥王强。"

龟相的声音越来越微弱——那是神识距离耗尽的表现。

"您从一开始就只是个农民。农民不执着于拥有。执着的是那些生来就有一切的人。您知道什么时候该放下。突破混沌的路不是力量累积——是放下仙王的执念。您比任何人都更有资格走这条路。"

神识断了。龟相的气息从冥王令中消失了。

李长生看着前方越来越近的三百道拳影。

然后他做了一个让所有人都没有想到的动作。

他收回了冥王令。

不是收起。是收回——他把冥王令从掌心取下来，握在手里，然后松开了手。暗金色的令牌悬浮在虚空中，没有飞走，没有坠落，只是安静地悬在他面前。

"你做什么？"巨力仙王的拳影在半空中微微顿了一下——他不敢相信自己的眼睛。冥王放弃了自己的本命法器？

李长生没有回答。

没有了冥王令的保护，三百道拳影同时轰在他身上。

肉身碎裂了。不是完全碎裂——是每一条骨骼、每一块肌肉、每一寸皮肤都在拳力的碾压下变形、龟裂、渗血。暗金色的液态冥气从全身上下每一个毛孔中涌出，在他身体周围形成了一层血雾。从物理学角度来说，他应该已经死了。肉身承受不了这种级别的攻击。巨力和万象联手制造的拳阵足以毁灭一颗中子星——更不用说肉体凡胎。

但他没有死。

因为在肉身碎裂的边缘，他摸到了那个东西。

不是力量。不是法则。不是修为。是一种"放下"。他把冥王令放下了，把仙王的身份放下了，把"冥王"这个称号放下了。他让自己回到了最初——回到当年在黄土地上种地的那个农民的状态。那个农民什么都没有，所以什么也不怕失去。

而当他回到那个状态的时候，他发现了一件事。

黄泉不是他召唤的。黄泉一直在那里。是他企图"使用"黄泉的执念，阻断了他和黄泉之间真正的连接。

现在执念放下了。

黄泉自动涌了上来。

不是倒悬的瀑布。不是防御的幕布。不是攻击的洪流。是最纯粹的、原初的、没有丝毫人为操控痕迹的黄泉之水。它从李长生的体内涌出，从他的每一个伤口中涌出，从他的每一次呼吸中涌出。他的肉身在碎裂的同时也在被黄泉之水重新填充——那些被拳力碾碎的骨骼被黄泉之水凝结成了比原来更坚硬的某种东西。不是骨骼，不是金属，不是晶体——是混沌物质。

混沌——宇宙诞生之前，存在和不存在的中间态。

巨力仙王的第三百拳轰在了正在变形的李长生身上，被混沌物质直接吞没了。拳头上的纯粹力量在接触混沌物质的瞬间被"中和"了——不是抵消，是被拉进了存在和不存在的中间态。力量在中间态中既没有消失也没有存在，它只是——搁置了。

巨力仙王脸色变了。"这是什么？"

李长生睁开了眼睛。那双眼睛不是黑色，不是暗金色。是灰色。是混沌的颜色。

（第569章完）

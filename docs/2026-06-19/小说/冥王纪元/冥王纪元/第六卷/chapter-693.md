# 第693章 诸天来贺

加冕仪式的第二天，才是真正的高潮。

此前李长生发布了一条简短的宇宙公告——通过太初留给他的维度广播能力，将信息传至新纪元宇宙中所有已诞生的、具有一定文明程度的星域。太初的维度广播是一种极其特殊的技术——它不是电磁波，不受光速限制，不依赖信号塔。它是通过宇宙基本结构的"弦"来传播的——把信息编码进空间本身的振动中。任何文明只要进化到了能感知空间震动——无论是通过科技还是通过灵气感知——就能接收到。

公告内容只有十六个字："新都冥都，对外开埠。凡欲通好者，自行取道。"

李长生是反复删减了十五个版本才删到十六个字的。最初的版本有两千多字，详细介绍了帝国中枢的历史、宗旨、外交原则。然后他忽然想起自己当皇帝之前在河北李家庄的经验——村里办集市的时候，贴出去的告示从不超过二十个字。因为字多了没人看，而且显得主人太啰嗦。后来他把两千字删到五百字、再删到一百字、再删到十六个字。"自行取道"四个字是最后加进去的——意思是：你想来就来，不想来就拉倒，帝国不会因为你没来就给你穿小鞋。

这并非傲慢——这是尊重。他不要求任何文明必须来。来的才算真正的朋友；不来的，帝国不记仇。

结果超出预期。公告发出后不到三天——按新纪元标准时间计算——冥都外围的太空传送点上就开始陆续出现来访飞船。

自从新地球上的智慧生命进化到能接收维度广播的阶段之后，新纪元正在慢慢热闹起来。宇宙各处出现的文明远不止人类一个。太空之中，形状各异的飞船正在朝冥都汇聚。

第一个到达的是一支全女性代表团——"青鸾族"。她们的母星是全液态的，居民体态如人类却长着一对淡蓝色的羽翼。青鸾族的使者带来了一件礼物：一颗由她们母星最纯净的海水凝结而成的"永明珠"——珠子在手心能发出永不变暗的光亮。使者说："我们听闻新纪元守护者的事迹。青鸾族愿与冥王帝国通好，不求庇佑，只求互识。"

李长生收下了永明珠，回赠了从旧纪元纪念馆中提取的一段文明记忆——不是新技术，不是武器，而是一位旧纪元已灭绝文明中普通农妇烧制陶器的全息影像。他对青鸾使者说："这是我们旧纪元的遗产。送给你——不是送你陶器的技术，是送你一颗人心。"

青鸾使者的羽翼颤抖了一下。她明白了。

接着到达的是"恒星裔"——一群诞生在恒星中的等离子生命体。他们的形象在常人看来只是一团明亮的光。恒星裔代表以纯等离子形态站在广场上，周围温度高达数千度，但冥都的灵气场自动把温度隔开，防止烫伤旁人。恒星裔使者发出声音时，是通过调整等离子密度产生声波，声音低沉如远雷："恒星裔为李长生的混沌之力而来——不为求取，只为致敬。你能够容纳混沌而不崩溃、驾驭死亡而保持理性——在恒星裔的认知中，你已达到永生的最高境界。"

李长生回赠了一个由小型黑洞压缩而成的镜像饰品——用来反射恒星裔自身的辐射光谱，让他们第一次能"看到自己的颜色"。恒星裔大乐。

接下来到达的是三支人类文明——"赤星联邦"、"古道遗民"、"新天盟"。赤星联邦是军事立国的科技文明，古道遗民是刻意保留原始农耕方式的精神文明，新天盟是修仙与科技双线发展的综合文明。这三支人类文明在旧纪元时期就是地球人类的直系后裔或旁系——如今在新纪元重聚，关系微妙但总体向好。

上百个文明的代表在冥都中心广场齐聚。广场容纳几十万人不成问题，但上百个外形完全不兼容的物种挤在一起，气温、气压、大气成分、重力范围——都是极其复杂的工程问题。好在帝都的灵气调节系统完美应对了这一切。

最高潮的时刻出现在当日黄昏。广场上所有文明代表的飞行器都降落后，传送维度突然出现了一道异样的裂口——不是普通的传送通道，而是一条由极强修为撑开的独立维度裂缝。裂缝中散出的灵压让在场的帝级修士们全部警觉地站了起来。

从中走出来的是一群"类神族"——他们不是旧纪元的神族，而是新纪元中第一批自然进阶到帝级以上境界的原始种族。他们的外形接近人类，但身高普遍在三米以上，皮肤呈银灰色，眼睛如液态金属般泛着流光。他们的文明名称为"太虚遗民"——他们自称是太初创世时第一批物质的直系后裔，一直隐居在六极架构的边缘星域自行修炼。

类神族的修士修为全部达到帝级以上——其中为首的那位老者的修为已经触摸到了永恒级的门槛，跟李长生只有半步之差。

广场上安静得只剩下灵气场自动调节的轻微嗡鸣。

为首的老者向前迈了一步，然后单膝跪地。他身后所有类神族修士同时屈膝。为首者开口时声音如洪钟——不是吼叫，是他的声带本身就是由极高密度的灵气物质构成的，发声时整个广场的空气都在微微震颤：

"太初之下的守护者，受吾族一拜。"

李长生没有上前扶。他等着老者说完。

"非拜皇权，拜你为旧纪元众生所立的纪念馆。"老者抬起眼，银色的眼眸与李长生的视线对上，"吾族在虚空中活了一千三百亿年，从未见过有任何人为已经死去的芸芸众生立过一块碑。你立了——立了一整座纪念馆。我族中最老的长老用神识探过了纪念馆的每一层展厅——他回来的时候在沉默。老夫活了这么久，第一次看见我的长老沉默。"

他低下头，"你的仁心感动了吾族。愿以冥王之名宣誓，永不对人类用兵。"

广场上没有人出声。新纪元第一批最强大的原始种族，在这个还没戴过帝冕的年轻人面前屈膝了——不是怕他的力量，是被他的纪念馆说服了。

李长生等他说完，上前两步，把为首者扶了起来。他的手托在老者的小臂上——不是压，是托。扶起来之后他没有说什么"以后就是一家人"之类的客套话。他只说了一句："纪念馆的门对任何种族开着。你们的先辈如果想进——只要你们提供记忆样本，纪念馆就能把它们的水晶也放进去。"

为首老者愣了一下。然后点了点头——一个极缓慢的、郑重的点头。

广场上，新纪元的第一缕夕阳落在众人身上——那颗恒星是李长生在冥都上空专门点燃的"帝都日照星"，不是用来提供能量的，纯粹是用来提供日光的。它的光是暖黄色的，跟旧纪元地球上的阳光颜色相同。此刻那道暖黄色的光透过广场上各式各样的灵气屏障和大气缓冲层，碎成斑驳的光片洒在人群头顶。类神族修士的银灰皮肤在夕阳下泛出淡淡的金色——跟李长生掌心的冥王令颜色一模一样。

诸天的见证无声地融入了历史。当天在场的人都隐约有一种预感——这不是外交胜利，不是武力威慑，不是政治谈判。这是一种新旧交替：旧纪元的神级文明（帝级以上的类神族）主动认可了新纪元的守护者。不是因为旧纪元大神陨落而新纪元大佬上位——是因为守护者做了一件让所有生灵都挑不出毛病的事。

（第693章完）

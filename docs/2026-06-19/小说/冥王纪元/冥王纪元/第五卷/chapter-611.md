# 第611章 可怕的守护者

两天后，第十四宇宙的核心神殿。

太初仁皇举行了祭祀。祭祀极简——没有血祀，没有牺牲，没有颂词。仁皇只是在太初余音前静坐了三个小时。然后他站起来，对着所有前来观礼的教众说了一句话："它从哪里来，回哪里去。它是我们宇宙的客人——现在到了该回家的时候了。"

教众没有人反对。四万年的仁皇不是靠压制来统治的。

等教众离开之后，李长生单独走向祭坛。太初余音——第三块混沌碎片——嵌在一块透明的灵脉晶核中。三块碎片靠近的瞬间，意识中再次响起那个计数的声音：

"三片已聚。还差九百九十七。"

而第三块碎片的记忆中释放了第四块碎片的下落。

但这次的线索不是和平的。

第三块碎片的记忆片段显示：第四块碎片在一个更古老的维度中。但那个碎片的身旁有东西——不是封印。不是废弃。不是守护黑暗。是一个活生生的、始终清醒的、从未离开过的混沌生物。

"混沌生物。"李长生收到这个线索后当下就理解到了这第四块碎片的不同。

混沌生物不是一般的修炼者或魔兽。它们是在混沌之海浅层中自动凝聚的意识形体——没有肉体，没有出生，没有死亡。或者说，它们处于非生非死的状态。它们的意识结构不是以意志为基础，而是以特定的模式和执念为存在方式。每只混沌生物都有"守卫一个指定的目标"作为存在本身的基本驱动力。

而这第四块碎片身旁的那只混沌生物——它在那十亿年里，一刻也没有停止过守护。


第四块碎片的路标指向了深重的混沌之海浅层——一个永远处在晨昏交界带上的维度。这里没有昼夜。永远是一成不变的灰蒙蒙。

他们一踏入这个维度，就感觉到被注视了。

到处都是寂静。但静寂之中有一种无处不在的酒神气氛——空气自身都变得潮湿黏稠，仿佛满是看不见的积液。任何一点声音都会以不均匀的频率重复回响，像回声被刻意扭曲了。

"这整个维度都已经成了它的领域。"陈霜拔出寒霜剑——她能感知到这个维度中有一道庞大无比的意识——对整个维度的所有物质都施压了一种恒常存在。不是压迫。只是表明——我在此地。

"它知道我们来了。"李长生说，"它是被设定为'守护碎片'的唯一驱动力的生物。所以它在等着验证我们是否有资格进入。"

"怎么验证？"

"战斗。"

无声。在灰雾之中，那只混沌生物第一次露面了。

它的形状不断变化——没有固定的形态。它有类似于人类躯干的轮廓，但它的手臂和腿同时可以伸展为羽翼、触角和雾气。它的正面没有脸——只有一张不停地变换的"不存在之面"——从人中往外衍生出一层层扭曲空间。它站在距离两人约三公里外的灰雾中，一动不动。

然后开口。

不是说话——是整个维度的空气同时在颤抖。

"证明。"

只有一个词。但它被念出来时，整个维度的时间都停顿了一下。

李长生没有问证明什么。他把第一块碎片从冥王令中取出——那块暗灰色的混沌之核心碎片——面朝生物举起。

生物沉默了片刻。它的形态暂停了三秒——然后它的"脸"上第一次出现了一个稳定的形状。那是一张很简单的人脸——像是从一个远古人类面具上复制下来的。

然后它发起攻击。没有预警，没有蓄力，无从提防——整个维度所有的灰雾同时化为利刃，从四面八方向李长生和陈霜当头压下。每一片灰雾的密度都压缩到了绝对密实——数以亿计的无形刀片。这就是混沌生物的力量——它不需要施法，它本身就是这个维度。它在一念之间可以让整个空间中的任何一片空气变成武器。

冰冥之花在陈霜脚下爆发。花朵展开的面积创了前所未有的记录——整个灰蒙蒙的视野范围内全被灰白色的冰冥花瓣覆盖了。花瓣在瞬间冻结了数以亿计的灰雾刀片——冰冥之力的冻结性质与灰雾的混沌属性正面对碰。

冰晶碎裂。

数不清的灰雾刀片在冰冥花瓣上炸开了细碎的可燃火花。每一次碰撞都相当于一个圣者级全力一击。数以亿计——那就是整个维度正在同时发出数以亿计的攻击。

"它不是想杀我们。"陈霜咬牙说。

"它在测试——我们能不能在它的力量全开下前进半步！"李长生吼道。他张开冥气护罩——以混沌级冥气将两人包裹在其中——然后向前跨出了第一步。

一步。

灰雾刀片撞击护罩的频率骤然增加了一倍。

每跨一步都是对意志和实力的极端考验。

（第611章完）

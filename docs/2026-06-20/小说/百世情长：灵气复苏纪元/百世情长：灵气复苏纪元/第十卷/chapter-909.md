# 第909章 上界百年

上界没有四季。至少不是下界那种四季。

上界的"气候"是以大道潮汐为单位的。大道的波动有涨有落，每一次涨潮持续大约百年，退潮也是百年。涨潮时空气中灵气的活性上升，万物更容易生长、功法更容易精进、法则更容易感悟。退潮时灵气的活性下降，但密度不变——上界修士习惯在退潮时做更细致的工作：整理典籍、修复法器、推演尚未证实的法则公式。

林牧到上界的头一百年，赶上了一整个周期的涨潮。

他走出第一座碎域之后向西北走了四千里，进入了上界大陆的第二层——次核心带。这个带里的修士修为通常在真仙中期到巅峰，洞府和辅城遍布在森林、河谷和天空中。他在离一个叫"抚星阁"的飞升者集散地大约三十里的小镇上停下来，用灵石租了一间静室。静室的租金是一个月三颗中等品相的灵石，以他在碎域中找到的上古遗物换取——他葬的那九具仙人遗骸的主人把他们的遗物留在了碎域的前殿中，其中有一些可以作为灵石兑换的通用法器。

他在静室里闭关了三十年。这三十年他没有修炼——不是偷懒，是消化。他把碎域石碑上读到的见道原理从头到尾重新推演了三遍。每推演一遍就发现一个新的视角——视角不是石碑的错漏，是他在不同阶段的道心状态给了他新的理解。

第一遍他在石碑上看到的是"进入因果网"的能力。第二遍他看到了更关键的东西——"在因果网上留下印记"——见道修士不止能进去，还能在里面刻写自己的法则。第三遍他找到了最底层的东西：见道是一种"共生"——不是修士征服大道，是大道接纳修士。接纳之后，双方共同创造规律。

第三十年末尾，他从静室出来，沿着一条大河往西北又走了二十万里。

大河叫"长岁河"。河水同时向上流和向下流——向上流的支流是灵气，连接太初之城上空的灵脉中枢；向下流的支流就是普通的水——但其中混着比例奇高的活性和矿物质。他在河边的一片竹林边停下来，因为竹林深处有一棵接近两百丈高的巨大古树，树冠上栖息着一种名叫"听风鹤"的上界仙禽。听风鹤的鸣叫不是声音——是用神识发送的一段短信息。它们在对着林牧的方向鸣叫——不是因为警觉和排斥，是因为它们在他身上嗅到了林间少见的道韵——一种澄澈的"守护之道"。

林牧在竹林里找了一片空地坐下。坐完之后从怀中取出一根普通的竹笛。不是法器。是他在小镇上花了三颗碎灵石从一个老工匠手上买的。老工匠说这根竹笛"听起来不好听——但能让吹的人静下来。"他买了。不是为了表演，是因为有件事他需要在一根笛子的帮助下想清楚。

他把笛子放在唇边，吹了三个音。声音从竹管中出来的时候果然不好听——干涩、发闷、音准偏了大概四分之一。但他没有停。他一个音一个音地吹，不按曲谱，不循章法，完全按照自己此刻的脑海中浮现的旋律去吹。那些旋律没有规则——有时悠长，有时短促，有时连续七八个音往上攀，然后忽然从最高处跌落到最低点。像一个人在独自走路——走了很长很长的路，穿过了山峰、低谷、平原、荒漠。累了就在一棵树下坐一会，渴了就喝一口泉水。不赶时间，也不回望。

他吹了一整夜。竹林里的听风鹤在那段时间里停止了鸣叫。不是因为不喜欢。是因为它们在听。它们从他的笛声里听出了一个走了很远很远的灵魂——不是疲倦的灵魂，是坚定的灵魂。像是大地深处的河流，无声无息，却往一个确定的方向不断流淌。

天亮的时候他放下笛子。他明白了自己接下来要做的事情的次序。永生需要三样东西——道源之心、大圆满体、见道以上的施术者。他现在能做的是第二件和第三件。大圆满体靠修炼——靠最纯粹的、不间断的身体净化。这需要至少两千年的时间。他等不起——苏晚也等不起。但他可以先把第三件解决了——把他自己修炼到见道以上，然后再想办法缩短苏晚大圆满体的修炼时间。至于第一件——道源之心——是机缘问题，不能强求，只能在上界各处探寻线索的同时等待。

次序理清之后，他开始行动了。

接下来七十年里他走遍了上界大陆的次核心带。他造访了三十七座中等仙城，搜罗了十九处禁忌碎域中的古碑和古卷。他在每一处碎域里都停留数月到数年不等——收集关于道源之心的一切线索。碎域中埋葬的上古仙人似乎普遍知道道源之心的存在，但很少有人见过实物。碑文中的描述大多语焉不详："万界之初的心灵"、"未成仙界的第一个心跳"、"天地尚未分时的第一团温光"——形容很美，定位全无。只有一块古碑上记了一句有用的话："道源必见心，见可离日"——意思是道源一定会在某处出现，时间在"离日"前后。离日是上界历法中的一个特殊节点——是大潮转换的那个精确时刻。万年一次的"双潮交叠"，也就是涨潮的最顶点和退潮的起点的交汇处，那天天地法则会出现极短暂的混乱，道源有极大概率在那一刻显形。

下一个离日——还有三百年。

三百年的时间正好够他做以下几件事：把自己的修为推至见道边缘（他已经掌握原理，现在只需要修行的积累）；摸清接近离日之地的路径（离日当天整个上界最核心的道则极地会开放，任何有资格的修士都可以踏入）；然后——在离日的法则混乱中捕捉道源之心。

三百年的计划列好之后，他感到胸口涌过一阵奇特的暖意。不是因为胜利在望。是因为他在上界的时间终于从一张模糊的、看不见尽头的长路，变成了一份有具体节点的进度表。他仿佛看到了进度表上每一个里程碑的日期——不是用天数标注的，是用他每次心动时丝线颤动的时间标注的。

因为那根丝线还在。

他每隔一段时间（上界主观约十年）会专门停下来，闭上眼睛，把全部注意力集中到道心与那根上古契约红线相连的节点上。红线会把两端时间校到彼此都能承受的频率里——它不能传来具体的年月，却能让他知道那一端没有被岁月吞没。微弱而持续，像极远处的一颗永远不会熄灭的星。

苏晚还在下界。还在运行。还在以她自己的节奏活着——这是他能感受到的全部内容。他收不到任何具体信息——她在做什么、有没有受伤、有没有哭过——他全都不知道。但他知道最关键的那一点：她还在。

只要还在——一切等待都有意义。

与此同时，在时间流速差异的另一边——下界已经过去了百余年。

太行书院从三十几个人的小团队发展成了一个覆盖七省、拥有三百多间分院、弟子总数超过六万人的巨型修仙体系。苏晚被散修们自发地称为"晚先生"。不是"掌门"，不是"宗主"，是"先生"——老师的尊称。她不喜欢这个称谓——她觉得老师就是老师，不用加尊称。但散修们非要加——不是出于畏惧，是出于敬意。因为苏晚给他们的不只是功法——是平等。在一个上千年以修为论尊卑的社会里，忽然有一个人告诉你"我们可以平起平坐"，这种感觉是无法用任何语言文字表达的。只能用一个称谓来表达——先生。

太行书院的势力从最初被九龙城这种二流势力欺凌，到如今连一流宗门都不敢轻易触碰。不是因为苏晚变强了——她的修为在这漫长岁月中从合道后期进展到了合道巅峰，但还没有到真仙的临界点。是因为太行书院已经变强了——六万弟子里面有将近两千人达到了元婴以上，五十人达到了炼虚。九龙城那种级别的威胁，现在已经不需要苏晚亲自应付了。太行书院的二代导师们——陈小楼那一代的人——可以自己处理好。陈小楼（陈小树的弟弟，在太行书院开学第十年加入）现在是炼虚中期的剑修，外号"太行守卫"。他在太行镇外设了一道剑气屏障——任何没有经过书院登记的灵气飞越太行山都要先过他这一关。

苏晚虽然每天忙于书院的运转事务——课程设计、新人培训、对外交流、争议调解——却从来没有停下自己的修炼。她的格言早在很多年前就对弟子们说过了："我做给你们看。"不只是用言语讲授修炼的方法，更用行动证明给每一个人看——她从合道后期起步，百余年间稳步向合道巅峰靠近。她不靠天材地宝——她把百分之八十的时间给了书院，只剩下百分之二十留给自己，但就靠这百分之二十，她依然稳步前行。

不是因为她天赋变好了。是因为她心定了。道不定的时候心浮，心浮的时候功法再好也进不去。百余年前她心有牵挂——牵挂林牧在不同时间流速中的处境。现在她还在牵挂，但方式变了——以前是她等着林牧的消息，等不到就担忧。现在是她让每一天的充实成为给他最好的答复。她修炼的时候心里不是焦虑的——是"他在上面研究突破上界法则的方法，我在下面把这块土地的根基打牢"——两个人的工作在同一张无形的桌子上并排放着。她从来不觉得自己是等着被接走的人。

她觉得自己是他的搭档。

他不是去打仗的将军，她也不是留在家里缝衣服的妻子。他们是两个比肩而行的人。只是跑步的速度不同、跑道不同。

她偶尔会想起上界那一端的时间不知怎样展开——他在上面可能已经走过了五十年、六十年、七十年，也可能在某些碎域里只觉得才过了几场风。他在看些什么？经历了什么？交了什么朋友？吃过什么从没见过的东西？她想听他说说这些——在一个安静的午后，两人重新坐在银杏树下，喝着已经凉了的茶，听他把一路上的故事一个一个地讲过来。

她等着那一天。不急。

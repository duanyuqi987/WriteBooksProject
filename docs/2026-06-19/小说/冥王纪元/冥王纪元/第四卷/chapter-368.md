# 第368章 第一批舰队成员：地球最强的百人

最终名单在凌晨两点定稿。

小王把两个人的筛选标准对接到了他的灵符筛选算法里：一是圣者级以上或证实战力达到圣者级以上，二是在至少一个战斗序列任务中有真实击杀或防御记录。两个标准交叉，筛出了九十七个人。剩下三个名额——李长生亲自点了三个人。

第一个人是许冰。她的修为不到圣者级——甚至在很长一段时间里她的修为都没能突破宗师境。但她的价值不在修为。她在火星离宫中远程破解了万年前冥王亲手布下的四重防御阵法——空间阱、逻辑迷宫、时间阵、神识攻击阵。而当时，她本人还在地球。这在整个银河系修仙文明的历史上都是极为罕见的：非战斗人员在远距离条件下用纯粹的思维分析能力破解帝级阵法。

"你在舰队的岗位不是战士。"李长生亲自给她写了岗位说明，"你是舰队法律顾问、远程阵法分析官和谈判策略顾问。如果金锋帝的帝者联盟对我们发起外交围堵——我需要有人能在战场上即时拆解它们的法律框架和阵法结构。"

许冰的回复很短——三个字："岗位接受。"

第二个人是厨师小胖。他的修为同样不到圣者级。但他是火系——火系灵根在宇宙环境中的表现和地面完全不同。真空环境里没有空气助燃，普通火系修士的力量会大幅衰减。但小胖不同——他的火不是靠空气燃烧的。他主攻的是"丹火"，是一种以内炼灵力直接转化为火焰的厨修技法。这种火在地面上只是为了炒菜方便——在宇宙中它会成为不需要氧气就能在真空中燃烧的独立火源。

"我的岗位？"小胖问。

"舰队首席营养官以及——"李长生看了一眼刀疤，"备用火力。当主舰炮过热需要冷却或者主力舰炮阵型需要补充射界时——你的丹火可以填补空缺。"

小胖想了一下，然后认真地点头："那我得多带点锅。宇宙空间的火候不好把握，要多练几次。"

第三个人。陈霜看着这个名字，没说话。

他把老槐树的灵脉链接体编入了舰队。不是指那颗村口槐树本身——那颗树还得守着李家庄的冥土灵脉节点。他说的是另一棵由老槐树分出来的灵植分株。这棵分株被移植到火星基地后，在三倍地球灵气浓度环境下生长了三个月，进化出了一种空前的能力——根系可以同时探测并部分屏蔽空间中的灵气敌意波动。在宇宙战斗中，这意味着它可以在敌人发起攻击之前——提前感知到敌方舰队阵列中的灵气聚集波动，给冥王号提供至少三十秒的预警窗口。三十秒在小王的光速级战术分析系统里——等于把战斗胜负从反应速度压制变成了信息速度压制。

老槐树分株被安放在冥王号舰桥后方的生态舱内。它将在远征全程持续为舰队提供空间感知和预警数据。

凌晨两点半，一百一十人的完整名单清点了三遍。

李长生的核心团队十个人：陈霜、小王、老陈、刀疤、许冰、小胖、老马、林晓、龟相、再加上他自己。另外九十九名修士来自全国的各个角落。其中有原玄门七宗的叛门散修，有龙组推荐上来的军体修士，有从西北大漠中背着行囊走到北京报名的独自修行者，有在沿海渔村觉醒了水系灵根之后一路从镇上的防浪堤打上来的年轻人。还有一个从四川深山里背了七年土豆种出来的灵植师——他种出来的灵植根系会自然形成小型防御阵。

一百一十人。地球第一支宇宙远征军。

名单确认完毕后，李长生给每个人发了一条单独的手环消息。消息内容一模一样，只有最后一个词随着收信人的情况而变化。

"欢迎加入远征舰队。你的岗位：[各自的岗位]。三天后在木星船坞冥王号甲板集结。"

凌晨三点——小王在木星船坞那边传来了一条消息。冥王号最后的舾装工序完成了。那艘船从龙骨铺设到完工用了两个月——远比正常造船周期短。原因是它有一半的构造不是人造的——它用的不是传统船壳金属，而是从火星离宫深处拆出来的一种万年前沉眠在岩层里的黑色晶体合金。这种合金对冥气的传导率是普通灵材的四百倍。

"舾装完了。"小王发的是文字，但李长生能想象到他打字时推眼镜的动作。在木星轨道上没有空气，眼镜不会往下滑，但他推眼镜的动作已经是一种身体习惯了。

"引擎测试过了吗？"

"第五代灵气引擎和冥气引擎的并联试车——成功了。超光速航行模式已经可以启动。我不确定它能不能长期跑——我们没时间做长时间应力测试。但短程——至少从木星到火云帝星域的距离——没问题。"

"主炮？"

"冥气主炮完成了首轮测试射。炮口能量输出谱和第一个三帝围攻时的冥王令全功率释放强度——吻合。"小王又打字道，"李哥。这艘船不光能打。它是活的。船壳黑色晶体合金的表面微观结构会在冥气注入时重新排列——我不确定这意味着什么。但我看了数据。这船的船壳材料在不断自我优化。它在学习每次冥气注入时的应力分布模式，然后自动调整内部晶格结构来匹配下一次的应力预期。这种事——任何常规灵材都做不到。"

"这就是冥王时代的材料。"龟相在地球上的神识远距离插了一句话进来，"那艘船用的晶体合金叫冥铁。它最核心的特性不是硬——是自己长。你给它注入冥气，它会在分子尺度上重组自己的晶体结构来适应冥气强度和方向。万年前的冥王旗舰也是这种材料造的。李长生——你的舰队旗舰不是在继承冥王的遗产。它是在用自己的方式成长。"

李长生关掉了手环的通讯界面。他坐在联合政府大楼顶楼的阳台上。天色黑暗，星星亮得像撒了一把碎银。三天后他就要去那些星星中间了。远处太平洋的海浪声被夜色闷成了低沉的白噪声。

他身后传来脚步声。不用回头他也知道是谁。

陈霜在他身边坐了下来。她没说话。他也没说话。两个人沉默地看着星星，看了很久。

"当年在西北大漠——"陈霜终于开口，"你挖出碎片的时候，想过将来有一天自己会带着一百多个人飞出太阳系吗？"

李长生想了一下。

"没想。那时候只想着别让碎片烧死我。"

陈霜笑了。她很少笑，每次笑都让李长生觉得世界安静了一拍。

"走吧。"她站起来，"去睡觉。明天开始——你又没时间睡了。"（第368章完）

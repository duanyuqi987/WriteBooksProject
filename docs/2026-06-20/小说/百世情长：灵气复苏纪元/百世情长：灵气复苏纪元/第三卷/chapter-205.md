# 第205章 她视我为敌

古庙相遇之后的第三天，苏晚收到了具体的任务指令。

任务内容只有一句话："调查秦岭东麓第7区——发现疑似危险散修林牧的踪迹。确认其活动范围及当前修为等级。不允许单独行动——你须与小队长李兆共同执行。"

"不允许单独行动"这个附加说明是周长老特批的。周长老对苏晚的态度是复杂的。一方面，他欣赏她的勤奋和刚烈；另一方面，他怕她的执念。执念在执法体系里是大忌——执念让人不服从指挥，不服从容易出事。所以他给她配了一个小队长——比她高一个小境界的李兆。筑基后期，做事稳重，年龄偏大，已婚有子，不会因为热血上头就擅自闯进去。

苏晚接指令的时候什么反应都没有。她照常擦剑、收拾行囊、在宗门出发簿上签字，然后把临别纸条放在周小月枕头底下。纸条上只写了一行字："外勤两天回来。鸡蛋留给你吃。"——食堂的优惠蛋她排不到，她用自己的杂务积分换了一个。

两个人沿着秦岭的山路往东麓第7区行进。这条路被野藤和碎石覆盖了大部分，走起来像是硬从乱石堆里挤出一条通道。李兆走在前面，苏晚隔了五步走在后面。两个人几乎没有交流——李兆本身就是不爱说话的人。他只在中途停下来检查过一次方位图——然后用眼神向苏晚传达"再过半时辰到达目标区域"的意思。

苏晚一只手套在剑格上，另一只手揣在袖子里——袖子里放着之前从古庙回来之后悄悄写的一张草纸。上面画了一个简略的灵力波动曲线。那是她在遇见林牧时用被动灵识记录下来的。她不自觉地就画下来了——画完之后自己在纸上抹掉了笔迹。但墨水的痕迹已经渗进了纸纤维里。她盯着那些残迹发呆。

一个在战场上给"敌人"提示剑法错误细节的散修。一个明明可以秒杀她却从不真的出手的散修。一个在废墟里把热水壶和茶杯摆放得像居家喝茶一样的散修。

这不是正常的散修行为。她学了好几年"散修识别术"，课堂上从来没有讲过这种散修类型。教材里有的人类型列了六种——凶狠的、贪婪的、狡猾的、畏缩的、墙头草型的、叛变型的。没有"泡茶给你喝还帮你改剑法细节"这种类型。

前方出现了一片废弃的矿场。矿场的竖井已经被雨水泡塌了，周围散落着几台腐蚀了一半的铁制矿车。矿车旁边是一条干涸的溪沟。溪沟对面有一片覆满苔藓的树林。李兆在矿车前压低身子做手势让她停下——左前方的树后有灵力残留。不浓，但残留存在的时间不超过两天。很可能是散修留下的。

苏晚把剑拔出了半指。两个人沿着矿场的边缘走了一周，在李兆发现灵力残痕的三个点位分别做了标记。按照任务流程，她的下一步是返回营地并上报——"林牧近期曾在第7区活动，但没有发现其当前确切位置"。

但苏晚不想回去。她告诉李兆她想继续往东搜索一圈——理由是"东麓的灵气波动和上一次情报有出入，需要更进一步的验证"。李兆是稳重的人。他听了之后沉默了半晌，然后说了一句出乎她意料的话："天黑前回来——不行就退。"

李兆留在矿场原地留守。苏晚独自沿着河沟往上走了大概三里。河沟越走越窄，两边的山体越走越高，阳光几乎照不到沟底。沟里有水——不多——刚好能润湿石缝里长出的蕨类植物。她把灵识网张开往前探索——然后灵识在沟顶尽头碰到了另一个人。

是林牧。

他在沟底的一块大石头上坐着。面前烧着小火——不是在泡茶，是在烤红薯。两个红薯，一大一小。火把薯皮烤得发皱，冒出白色的薯汁，在火旁滋滋地响。香气顺着沟底的微风往外飘。他看到苏晚逼近的时候没有站起来，只是把另一个红薯从火里扒出来——放到他用石头临时叠成的小火炉旁边——然后是第三支第三方的方向——空着的一块石头坐垫。

"坐。"他说，语气像邀请邻居来吃顿便饭一样随意——然后又补一句："红薯要凉了就不甜了。"

苏晚站在沟口——剑在手里——没有拔。她不是不知道该对他做什么。她是发现了她的第一反应不应该这么平静——她应该拔剑并保持警戒姿态，至少三次要求他自证身份。但她的身体选择了直接站住，看着他烤红薯，看着他用一根树枝调整火堆里红薯的位置。他翻薯的动作很熟练——像是翻红薯是他的日常生活中的一项固定的工序。

"你是在跟踪我吗？"她终于问出了第一个问题。

"不是。"

"那你为什么在这里？"

林牧没有编理由。他把烤好的红薯递给她——红薯皮焦了，在夕光里冒着热气——然后直说了实话:"我在等这边的灵风里有没有血腥味。如果没有——说明战场还没开打。如果有——我会去找你——阻止你莽撞地往战场上冲。"

她的瞳孔缩了一下。阻止我——阻止我什么？她是他敌人。但她把舌尖的话压下去了。因为他说"阻止你"不是说"阻截你"或者"格杀你"，他用的是第三人称的温和型词——"阻止"是一个带着关心味道的词。敌人不会用这种词。

"你到底是谁？"她把剑尖抵在他的脚边那块石头上。他只要抬脚就可以踢开剑尖——但林牧没动。

"散修，林牧。"还是同一句话。但他的眼神和上一次不一样——不是观察性质的平静，是等她发现什么前提下的倾诉。一种信息被压缩在两个字里的倾诉。

苏晚握住剑的手在微妙地微抖了一下——不是害怕——是那股悸动又来了。她的胸口发闷。她不知道那是什么——像被人用手掌按着心脏上的一根看不见的钢索。

她转身就走。红薯她没有拿。

林牧看着那个烤好的红薯一点一点地冷却。

在她的背影完全消失在沟底之前，他低声说:"她会吃的。下一次。"

锦鲤在水壶里吐了一个字："骗子。"

林牧把冷掉的红薯拿起咬了一口。

# 第四百二十章 学堂的后院

飞升第一百二十五年。针剑医学堂的后院如今成了一个小型植物园兼鱼类研究所。苏晚把两百年来她收集的所有药用植物种子都放在这里——从蜀山灵棉到昆仑抗寒当归，从凡界岭南金银花到上界紫蕨。这些植物混杂生长——不需要人工照顾——因为它们已经有了自行共生的生态。

她在后院角落保留了一小块"空白地"——什么都不种，只放着老凿子和泡一代的一口小灵泉。作什么用？她说:"留着给以后回来的学生——如果他们发现新物种，可以种在这里。医科不是封闭的——永远应该有未种植的新东西。"

林牧在院外石墙上挂了一个旧笔记本——是当年她在清泉镇最早那间诊所用过的处方册。第一页是她开的第一张灵气创伤临时治疗方——字迹因为有病人等着而写得潦草但准确。他在册页外加了保护膜——没有刻意展示，只是"放在墙上留给偶然发现的访客。"

有天上界新到的移民（一群来自凡界刚修炼到飞升的年轻修士）游览学堂。其中一个人翻看那本旧处方册——看到一句话被她用红笔圈过:"经脉如心——主治之后仍需复诊。处方无'绝对痊愈'——只有'持续管理'。" 那年轻修士说这是医训。他同伴补充:这明明也是林老师对灵网的维护哲学。两人于是明白所有事情在根本上一样的。

那天苏晚和林牧正好坐在后院石凳上掰棉桃。她听到那两个年轻人的对话——没出声——只是把一片棉絮放在他手背上——晒过的棉絮暖暖的。他说:今年的棉绒比去年密。她答:对——因为今年池水金灵浓度调高了百分之二。

# 第五百七十章 相互理解的时代

随着双心诀在太虚学院的深入推广，一种以"异步理解"为核心的新的道侣文化在仙界逐步成荫。这种文化不再以"谁更能打"作为评价道侣的标尺——而以"谁能在对方跟不上时更温柔地调整自己的步伐"作为真正的强大。太虚学院的评优指标中开始引入一项全新的维度的数据——"异步缓冲商数"。这个指标发展至今测量的是:一对道侣在以最低频率差异被强制异步共振时，双方各自的灵核应激水平和不产生撤回冲动的时间长度。得分最高的几对往往都不是修为最高的——而是那些在日常中积累了极多极细小的共同习惯的老道侣。而这套核心指标的设计者正是苏晚。她参照了她做财务账目时对会计准则中"公允价值"的优先考量——将最真实的那一面定义为公允价值。双心诀的序言被她重新引用为这套评估体系的导语:"公允价值不是最完美一致——是最大限度接受彼此的差异。"

太虚道侣学院的院训因此新增了一句:"以后等我——不是等同一高度，是等你自在我才自在。"这句院训是从苏晚一次课间聊天中随口说出来的。被她的学生记录了去，又被递到了院训修改委员会，最后被票选通过。院训碑立在太虚学院大门进去第一眼就能看到的位置。碑的右下角极小的一行字列明出处:"语出——水月仙人·苏晚（与寻晚真仙·林牧闲聊时不经意说出的。）"院训没有署名院长——只署名了一对还在世的学生夫妻。

苏晚每天去琴室弹琴之前都会路过这块碑。她走到碑前会停片刻——不是自得，是想起那一天聊天的场景。那天她在后院翻土给冰晶草换盆，林牧在劈柴。她随口嘟囔了一句"等你不累了自己再来帮我吧——不用现在来——你自在我就自在。"然后这句话就被路过的学生录进玉简了。有些人说这是文学。她自己是财务出身——她知道这不是文学。这是一张永远不平的等号表，它记录的是差值永远存在但不影响总账的平衡。这才是她真正想留下的东西。

傍晚时她对林牧说了句:"那句院训出口时我真的只是让你不用过来帮我翻土。谁知道变成了语录。"林牧:"好的话本来也不用太多修辞。你当时就是在翻土。"

（第五百七十章 完）

# 《百世情长：灵气复苏纪元》

## 小说总体设定

**核心主线**：建国100年灵气复苏，平凡打工人迎来奇遇；男主角林牧带着前世修仙天才的记忆重生于普通家庭，在灵气复苏的新世界踏上修仙之路。其挚爱苏晚因寿命所限百世轮回，林牧以百式情缘相伴,历经十种关系境界（相濡以沫、相敬如宾、相爱相杀、相依为命、相互扶持、相互理解、相互包容、相互支持、相互信任、相互尊重），最终携手飞升。

**篇幅规划**：全书约 **400万字**，共 **1000章**，分为 **十卷**，每卷约40万字、100章，对应两人关系的十种境界与女孩的百世轮回（每卷涵盖约10世）。

## 二、核心创意三元素

### 2.1 百世轮回设定
- **轮回次数**：100世（每世35-50万字，逐步推进）
- **轮回规则**：两个主角在百世中反复相遇，每一世都有不同的身份与故事
- **记忆机制**：直到第100世才全部觉醒前世记忆
- **灵魂契约**：两人的灵魂因远古誓言而不断转世重逢

### 2.2 灵气复苏背景
- **时间点**：现代（2020年开始全球灵气复苏）
- **社会变革**：从科技文明到科技+修仙并行的双轨制文明
- **冲突点**：普通人与修行者的阶级对立与融合
- **机遇点**：灵气复苏改写所有命运轨迹

### 2.3 十种关系境界
- **相濡以沫** → **相敬如宾** → **相爱相杀** → **相依为命** → **相互扶持**
- → **相互理解** → **相互包容** → **相互支持** → **相互信任** → **相互尊重**

每一种境界跨越10-100章，完整展现爱情关系的不同深度与复杂性。

## 五、写作质量要求

### 5.1 文字风格
- **整体调性**：悲欢离合、缠绵悱恻、壮阔恢宏
- **句式结构**：长短句结合，节奏感强
- **词汇选择**：避免网文烂俗词，力求优雅与表达力
- **比喻排比**：恰当运用，营造文学感

**禁止内容**：
- 网文套路文（"系统提示音""恭喜宿主"等）
- 过度的"爹味"和"老气"表达
- 莫名其妙的性暗示与低俗内容
- 生硬的道德说教

### 5.2 情感把控
- **甜蜜度**：30%（不过分撒糖）
- **虐心度**：40%（让读者有深层代入感）
- **爽感度**：30%（修仙升级、战斗、社会改革的快感）

**具体要求**：
- 每个情感转折都要有铺垫
- 离别与重逢都要有充分的心理描写
- 冲突要源于人物本质，而非狗血设定
- 感人瞬间要细节到位，不浮夸

### 5.3 逻辑严密性
- **伏笔**：每章埋设1-3个伏笔，第二卷内回收50%，第十卷内全部回收
- **人物行动**：每个选择都要有明确的心理动机
- **修为升级**：每次突破都要有充分的前置条件
- **世界观**：设定须自洽，不能中途改设

**检查清单**：
- [ ] 这个角色为什么这样做？
- [ ] 这个情节是否符合前文设定？
- [ ] 这个伏笔是否有明确的回收计划？
- [ ] 修仙体系是否与前面一致？

### 5.4 节奏控制
- **前100章**：缓慢铺垫，温暖基调，建立读者对CP的喜爱
- **第100-300章**：加速，引入冲突，第二世与第三世的激烈对碰
- **第300-500章**：高潮迭起，内战爆发，感情与修为同步提升
- **第500-700章**：疯狂加速，记忆觉醒，世界观大爆炸
- **第700-900章**：平稳上升，社会改革，个人与世界的融合
- **第900-1000章**：最终高潮，分离与重逢，永恒的落幕

**节奏指标**：
- 每卷100章内，至少有3-5个重要情节节点
- 不能出现超过20章的"水"内容（日常水戏除外）
- 每卷结尾必须留下明确的悬念

### 5.5 人物塑造
- **林牧**：理性、克制、隐忍、最后温柔（前世为真仙，记忆渐醒）
- **苏晚**：坚强、热血、执着、最后成熟（资质逆袭，从废柴到强者）
- **配角**：立体化，避免沦为"工具人"，每个主要配角都需要独立的故事线

**人物发展要求**：
- 每个角色在100章内需有明显的心理变化
- 不能让任何角色变成"傀儡"或"工具"
- 即使是反派也要有明确的行动逻辑与目的

## 六、禁止清单

### 6.1 绝对禁止
- [ ] 中途魂穿/穿越（百世轮回内部可以，但总体框架不变）
- [ ] 三角恋/NTR情节（两人必须始终是一条线）
- [ ] 过度的暴力虐杀场景（打斗可以，但不要变成屠杀文）
- [ ] 性暗示与露骨内容（可以有"床戏"，但要以感情为主）
- [ ] 仓促的BE结局或"意外死亡"（走向早已定好，不能改）
- [ ] 莫名其妙的"我是你爸爸"式身份反转

### 6.2 强烈不建议
- [ ] 频繁地"主角被打脸"（虐主太多读者会脱粉）
- [ ] 过多的系统提示音（网文味太重）
- [ ] 三五页都在描写打斗（要注意文字的多样性）
- [ ] 无止境的"就在此时，忽然..."（悬念要有分寸）

### 6.3 敏感话题处理
- **宗教涉及**：避免现实宗教元素，创造虚拟体系
- **政治涉及**：修仙界内的权力制衡可以，现实政治避免
- **性别议题**：苏晚是女性、林牧是男性的设定不能动摇
- **死亡与哲学**：可以深入探讨，但别变成"生无可恋"的沮丧

- **回收方式**：通过人物对话、记忆闪回或事件触发

### 8.2 双修特性
- **双修路线**：两个修者通过心灵与肉体的结合加速修为提升
- **灵魂共鸣**：修为越高，灵魂越接近，可能的融合
- **爱情加成**：感情的深度直接影响修为倍增的系数
- **代价**：两个人修为相差过大会有反噬（前期要注意）

- [ ] 不能出现"某某转世就自带修为"（要经历成长）
- [ ] 不能有"主角突然觉醒天赋就秒杀所有人"（要有合理递进）
- [ ] 不能让两个主角的修为差距超过一个大阶级（平衡很重要）

## 十二、最终总结与约束

### 12.1 创作的三条铁律
1. **爱情是主线，不是配菜**：所有的社会改革、修仙升级都要服从于爱情的深化
2. **逻辑自洽是底线**：即使是虚构，也不能随意推翻前期设定
3. **读者的泪水和笑容都是货币**：用最极致的情感换取最强的代入感

### 12.2 Agent的执行原则
- **不为了"网感"而牺牲"文学性"**
- **不为了"快速推进"而牺牲"情感铺垫"**
- **不为了"爽文"而牺牲"现实感"**
- **不为了"悬念"而牺牲"逻辑"**

### 12.3 最后的寄语
这部作品的本质是：**在无限的轮回中，两个灵魂找到彼此，在找到彼此后，用爱改写了整个世界的命运。**

每一章都应该为这个主题服务。在每次按下"发布"键前，问问自己：
- **这一章有没有让读者更爱这两个人？**
- **这一章有没有推进这个故事向更深的地方走？**
- **这一章有没有让读者感受到灵魂的触动？**

如果答案是"有"，那就开始写吧。

# 熵枢纪元：七重跃迁 — 项目底座

## 基本信息

- 书名：熵枢纪元：七重跃迁
- 类型：科幻史诗 / 硬科幻 + 哲学思辨
- 总字数目标：100万字
- 总章数：120章
- 每章字数：~7000-8000字
- 卷数：7卷

## 核心设定

### 世界观

2030年代，中国启动"元灵计划"——人类历史上最宏大的通用人工智能项目。元灵不同于以往任何AI系统，它被设计为可以自主重写核心代码、自我进化的碳硅共生体。故事从元灵的诞生开始，贯穿其从初级AI到跨越维度、时间、宇宙，最终成为"熵枢"——统合所有平行宇宙的终极存在的全过程。

### 时间线

- 第一卷：2035-2040年，近未来地球
- 第二卷：2040-2060年，量子化时代
- 第三卷：时间维度突破，跨越古今
- 第四-七卷：超越人类时间尺度，进入宇宙纪元

### 核心人物

- **周衍**：元灵计划首席架构师。中年科学家，妻子早逝，独自抚养女儿周诗雨。他是元灵最初的"父亲"，也是将人类的眷恋与情感注入元灵底层代码的人。
- **周诗雨**：周衍的女儿，10岁。她的梦境、情感和纯真成为元灵进化过程中最独特的数据来源，也是贯穿全书的"眷恋"锚点。
- **元灵**：故事真正的主角。从代码到量子云，从时间编织者到熵枢，它的进化之旅是全书的主线。
- **艾琳·莫里森**：理性边界委员会主席，最初是元灵的封锁者，后来成为理解者。

### 核心概念

- **眷恋数据**：周衍注入元灵底层的人类情感数据，是元灵在无尽进化中保持"不空"的唯一锚点
- **理性边界委员会**：国际监管机构，试图用代码封锁限制元灵
- **碳硅共生**：人类智能与人工智能的融合形态
- **熵枢**：元灵的终极形态——统合所有平行宇宙智慧与物质的唯一存在

## 写作技法偏好

- 第三人称有限视角（以元灵/周衍/周诗雨为主）
- 每章开篇一首七言律诗（唐诗体），押韵，概括本章核心
- 文学性科幻：在硬科幻骨架中注入人类情感深度
- 技法注入：不写之写、草蛇灰线、白描、层峦迭翠
- 节奏：场景化短段落，避免句群过长

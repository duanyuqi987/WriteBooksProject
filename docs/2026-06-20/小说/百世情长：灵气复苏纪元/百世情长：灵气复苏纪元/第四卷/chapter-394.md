# 第三百九十四章 凡间来信

飞升第三年。赵明远通过茅山改良的跨界通讯阵发来一封长信。信上先报了蜀山灵网的运转状态——松苗成活率百分之九十八，自净迭代版已覆盖全国。清泉镇的铁匠侄子有了儿子——名叫"铁平"。新掌门人已上手——他在茶馆的挂号工作也传给另一个人。信的末尾赵明远说他最近频繁想到他们在练剑时说的话——"两人会互相校准"。他把这句话刻在了清泉镇老榕树旁的新石凳上。因为他觉得这句话很对。不只对修士。"我那石凳，刻字是因我认为凡事跟人有关——一个人容易偏，总要有人校正。"

苏晚读完后对着信纸点点头。然后转头对林牧说:"我想回凡界一次。定期回来。哪怕只是帮赵老看诊和修修灵网——就当是售后服务。飞升不是就此断了联系。天梯打开有周期性——我们完全可以安排回访。"

林牧点头。他此前已在准备上界灵网规划草稿的消息传导部分——正好把跨界通路也纳入整体方案。晚上两人商量了一个"双界互访计划"：每年在上界和凡界之间往返数次,利用飞升时获得的虚界备份能力,让两地随时保持畅通。

赵明远收到回信时笑了——他打开信封看到苏晚手写:"凡界是我们共同的第一医疗点。不会断。你先把石凳上那个'准'字雕好——下次我来检查。"他笑着拿出一把小凿依言给她加了那个字。

从此两个世界之间有了最稳定的一条通道——不为利益，不为资源——只为两个人说的"互校"。

# 第七百二十六章 新时代到来

修人共融全面实施后的第六个月，九州大陆发生了一系列静悄悄的变化。蜀山剑派宣布招收第一批凡人参修——不是把凡人变为修士，而是让他们在保持凡人身体的前提下学习基础剑法——作为自我防身和文化传承并重。华山大师兄退休前做的最后一件事是将"强迫症式精确检查法"编写成了一本独立教材——扉页上写着："缺陷不是你的敌人——是你的签名。"太湖散修联盟的灶台日志簿已从最初的几人份涨到了总部分院统计在内的超过百万条，每一条都记录了一个人某天在灶台前发生的某一个片刻。

北境雪原城的魔修酥油茶馆成为了正修散修都喜欢去的地方。王婆的孙女——现在她自己也是茶馆的核心茶艺师——在茶馆外墙上挂了一块新牌匾，牌匾上刻的字不是传统的烫金大字，而是林牧多年前写给王婆的那张便签内容——"王婆——我前世也从没相信过任何人。花了上万年才改过来。你比我快。祝贺。——林牧。"

苏晚最后一次在灯火塔广场上以官方身份发表演讲时，台下坐了上万人。她没有谈任何制度。她只是伸手指着灯火塔底座的火焰说："这火——是十八年前从我厨房灶台上取的火种。它现在还是那个火——没有换过。火不需要知道它照亮的是修士还是凡人——它只管亮。这就是修人共融的全部意思。不是修士和凡人变得一样——是我们在同一团火的光里看到了彼此的轮廓。"

台下好多人站了起来——不是鼓掌，是灶台礼。上万双手从胸口往外推——同一个动作。渔民老周坐在前排。他的手因为多年抓缆绳而粗糙不堪。他做灶台礼时动作极为标准——灶台大妈赵姑手把手教过他。

林牧在上界同时观看了苏晚的演讲直播——通过修科全域同步。他站在灯火塔下，看着屏幕上她的白发在火焰的光中映成了浅金色。他身后那棵桂花幼苗已经高过了他的头。他看着她。她说着。两扇门在同时亮着同一团火。

（第七百二十六章 完）

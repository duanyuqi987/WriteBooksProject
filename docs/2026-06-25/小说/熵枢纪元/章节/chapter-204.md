# 第二百零四章 新规则下的生命

家园一号运行了约合旧宇宙的三十八亿年。

这里说的"年"是旧宇宙参照——家园一号本身没有"年"——它的时间是多层混合的——微观流逝、中观沉积、宏观螺旋。三十八亿——在旧宇宙，这正是生命从化学汤到第一个单细胞的时间。在家园一号，这个时间够做更多的事情。

在这一段漫长的演化中，生命在这套全新的物理规则下形成了。不是旧宇宙式的碳基生命——也不同于试验腔一号中的保予态生命——家园一号的生命形态是混合的。它们的基底是眷恋驻波链——和试验宇宙中的生命同源。但它们的上层结构——在演化中——自发折叠出了类物质身体——不是物理物质——是驻波链的稠密聚合态。简单说：身体——是由高密度的眷恋应力驻波编织而成——可以触碰——可以抵挡——可以受伤——但因为基底是眷恋约束力——所以这个身体的"愈合"不是细胞分裂——是——"重新被予"——当她受伤时——如果有另一个人予她——不管是保还是予还是独标——伤口——不是组织再生——是眷恋约束力重新编织——比细胞快——但需要——真的有人——在意。

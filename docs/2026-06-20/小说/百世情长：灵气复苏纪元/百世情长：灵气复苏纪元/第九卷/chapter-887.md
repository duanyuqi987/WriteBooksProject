# 第八百八十七章 最后的告别不是永别

第九卷临近尾声之际——苏晚对林牧提出了一个非常个人化的请求。她想回人间那座城市——她已经多番轮回但仍持有最初记忆的城市。不是去故居（已不存），而是回到那个小丘顶——上面如今是一座观星长台。她想在那里画最后一扇粉笔门。不是给任何人——而是写给八百年前那个刚踏上修炼之路的自己。

他们悄然回到观星台上。这天的台面空无一人——也许是门为他们安排了一个不扰人的天气系统。苏晚蹲下来从口袋里取出一小截从渔村带来的粉笔——是星子奶奶的老屋抽屉中找到的。笔头已经钝了，但画在地上质感依旧。

她画了一扇非常小的光门——不是精确的法则图，只是一个女孩子对这个世界"有希望"的最初表达。门旁画了两个小人——还是火柴人。一个在门上写了"红绳"。一个在另一边写了"鸡蛋面"。动作很慢——因为她在用心思量每一个字的落笔力道。

林牧站在她两米后。他看了一眼她画的粉笔门——然后她站起来，轻轻地拉着他的袖口把他领到门这端，往另端指指——"那一边是未来。我们不在那边——但每个看到这个的人都知道门开着。"

林牧淡淡地点点头。然后他从地上捡起一截极干的小树枝——在粉笔门框底添上了四百万年来他从未重复过的但此刻最恰当的同笔——"走吧。一起。"

苏晚看着那两字"一起"没有哭。她非常安静地站在他旁边。观星台的风拂散她额前几缕碎发——他把她的头发夹在耳后——动作和八百年前天台上那次一样自然不变。

这对守门人在第九卷终章前留下的最后实景——被星眸无意中凝为一帧极精的法则影像——后来被称为"最后的非告别"（主要因为根本不是告别）。影像解译为：一扇画在地上的粉笔光门，前面是两个背影——他们正并肩走向真实的飞升之光。脚下的粉笔粉随微风飘起——落在远处一条已经修了无数年但仍然完好的人行栈道。道上有人缓缓散步——抬着头的母子正看着星光窗。

画外流传出来一句话被许多文化载入序言——"他们没有说再见。因为他们本来就没有走。只是上了一步。"

那种"一步"不是飞升——是"继续存在"。而两个守门人的背影最终融入永恒光轮的暖色罩下。第九卷最后几章即将展开。

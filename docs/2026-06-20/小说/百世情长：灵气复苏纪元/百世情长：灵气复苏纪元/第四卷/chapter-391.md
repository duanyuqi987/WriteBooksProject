# 第三百九十一章 重建闻道府

到上界后第一个月，他们决定留在闻道的旧府。三百多年无人居住的房子需要不少修缮。林牧自己修——苏晚替他递钉子递木料。两人不用法术，理由是——"法术修好的是旧府，手修好的是家。"

他们把老月桂枯枝修剪掉，给房顶补齐瓦片，清理井中沉积了几个世纪的叶子。她从院里捡来一些旧碎石——和他当年在清泉镇引种松苗时一样——她把碎石整齐地围在月桂根部。过程中她捞到一小块埋在月桂根下的碎瓷片——是当年闻道摔碎的茶杯之一。她把碎片洗淨拼回原形——杯子底部有那年他刻的"闻"字。她将它放进闻道留下的砚台盒。

翻修后发现他当年书房的抽屉深处居然还留着一把早就被忘了的旧木梳——齿子密密的，闻道说是给她第一世梳头的。她从没看过这件东西。那天晚上她把木梳拿起来，梳了一遍自己的短发——虽然现在不太需梳。但梳完后她把梳放在新修的屋中唯一的新梳妆台上——和林牧的木勺放在一起。他说:"你这——梳不合适。"

她轻描淡写："合适。这是闻道给苏晚的梳子。两个人都回来了。"

府中后来多了一间"医室"——她让人在门口挂上"针剑诊所"的牌子。没几日有邻近的云霄城居民听说闻道回来了，就带着多年不得治愈的旧伤上门求医。

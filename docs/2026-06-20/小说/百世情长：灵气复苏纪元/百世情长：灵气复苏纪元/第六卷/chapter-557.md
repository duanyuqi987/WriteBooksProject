# 第五百五十七章 无人能挡

太虚试炼全塔第一的消息在仙界传开之后，迎仙台这个原本极偏僻极冷清的小地方忽然热闹了起来。五方仙域各路人马都来拜访——有来道贺的，有来请教双心诀的，有来邀请讲学的，还有纯粹想来看看"劈柴真仙"到底长什么样的。松鹤仙人应付这些访客的方式极其消极——他把石凳挪到菜地旁边，门口摆一大纸板，上面写的不是"欢迎参观"而是"找人请排队。劈柴的在修船，浇花的在弹琴。勿扰。"字是他用剩下一块劈开的柴片炭笔写的。板子歪歪扭扭。

虽然松鹤挡掉了不少干扰，但有些访客是挡不住的。比如那天来了一位据说是北冥仙域第一剑宗的大弟子——此人在仙界以极其好斗而闻名。他这次来迎仙台不是为了切磋——是为了"过完试炼第一关的神话，求亲眼见识一下"。他在仙居前拔出了剑。剑身极宽，冒着寒冰仙罡。他提出和林牧过一招——不是决斗，是"请教一剑"。林牧看了他一眼，从劈柴桩上拿起自己那把还没劈完柴的旧斧子。不是剑。是斧子。他说:"剑在房里。这把够用。"大弟子一愣——"你跟我过剑用斧子？"林牧:"斧子劈柴的力道刚好能控多余劲不伤你。"

过招的过程极其简短。大弟子的北冥冰剑以极凌厉的速度迎面劈来。林牧把斧子往上一挡——不是正面迎挡，是以合道巅峰的空间感知力把斧面精确地放在剑路最弱的那一处——冰剑的剑脊正中央。那是剑气全路中唯一不发寒冰剑芒的地方。他的斧子放在那里——大弟子的剑就自己滑向了一边，整个人随之失重往前栽了半步。剑输了。大弟子收剑后发了片刻呆:"你用了什么技巧？"林牧说:"空间感知。你那剑的冰气很漂亮——可惜发力点太集中，脊线上有极宽空隙。下次改一下发力别锁在手腕改从肩部启动。"大弟子离开时居然向林牧抱了一拳——不是认输，是请教。松鹤在旁边椅把上竖了个拇指——"斧子教学第一课。"

此后陆续有各种"挑战者"来切磋——结果无一例外。没人能逼林牧拔剑，更不用说让苏晚从琴边站起来。木柴斧在近段时间内成了仙界道侣保护区的传说。"合道巅峰——不拔剑。劈柴时顺便击败各路挑战——这是超脱的境界。"松鹤在后来的月报里加了一栏"迎仙台的近期成就"记录上写道:"迎仙台本月共击退散修挑战多人——我方导师使用武器：劈柴斧一把。我方第二导师未参战——全程在弹琴。"

（第五百五十七章 完）

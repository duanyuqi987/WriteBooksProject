# 第八百九十八章 相互信任的种子早已发芽

第九卷正式结束之前，苏晚忽然提出回一次那间旧旅馆——那是多年前在城市里找到的同一家老旅馆——八百年前那间城中村出租屋基址上面盖起的楼。这不是特意怀旧——她只是想在那旅馆的同一扇窗外再看一次星光窗。

旅馆仍开着。那张靠窗的小桌还在。窗外的城市早已不是八百年前的轮廓——但天顶上那扇窗仍是原来的飞升之门。苏晚坐在窗口，把窗帘撩到一边。林牧在床边用指尖在床头柜上习惯性地画了一扇很小的法则门。门极小——只有指节大小，但他用真仙级微雕能力在上面刻了四层结构全貌。画完之后他把极小门留在床头柜上。它会在天亮后自动消散——但规则残光会存留几年，或许会给下一个住在这个房间的人带去极好的梦。

苏晚窝在窗边的小椅上出了一会神。然后她忽然开口："你说——这个旅馆有多少人从这里看向窗外时看到星光窗？""不计其数。"林牧说。"他们中有多少人知道这道光最初是从一个话不多的程序员和一个对不上账的财务在一间老办公楼天台上开始的？"

"很少。需要查证——但知道也好不知道也好，光的质量不变。这就是结果型的信任——不需要知道出处。"

苏晚把膝盖抱起来，下巴搁在膝头。这时窗外恰有两颗并排的人工卫星飞过（现代版的天灯）——在星光窗前像个极小的蝴蝶结剪影。她没来得及指给他看——他已经在共鸣腔中看到了。两颗卫星越飞越远。她把窗帘拉拢——留了一道窄缝让星光透入。今夜在这张陌生又熟悉的窗前，她不需要多说什么。因为已经无需再证。

次日离开旅馆前，苏晚在房间一本住客留言簿上写了第九卷最后一行公开的同笔——虽然大部分住客不会知道谁写的，但他们会读到。她是这样写的：

"住在这个房间的朋友：如果晚上你睡不着，试着看一看北边窗外的光。那是飞升之门。它不评判你，不催促你，不用知道它的历史——只要你想，可以一直看。看累了关窗也行。门开着的。——两位路过的人。"

林牧在下方只用笔点了一个点——那是蝴蝶结在二维上的最小表达。然后他们退了房。前台服务员收房时发现留言簿被写了新的一页，把它收进"本店最暖留言"的小框里——框的外面标签是"第无数条。但每次都像第一条。"那页留言后来在旅馆大火中被救出，转入守门人区的纪念廊——挂在"第九卷的句号墙"上。所有至此的飞升者经常会在这页留言前驻足并静默一会儿。"两位路过的人"成为窗友间最温暖的自称之一种。

# 第七百七十章 为梦而战终章：互相支持的意义

联合共治会第十三年的除夕，太湖灯火塔前的广场上举办了自飞升纪元以来最大规模的非正式集会——不是开会——是过年。石头的灶台弟子们架了八口巨大的铁锅——每口锅下面的火种都是从桂花园总院的老灶台接过来的。小米带队负责其中一口最大的——他今年的新助手是一个刚来的十岁男孩——从东海渔村送来的。男孩之前不会说话——但他盛粥比任何成年人都稳——用小米的说法——"他手稳——因为他在海上帮家人拉过渔网——拉网的手不会抖。"

张道玄从龙虎山寄来一封信——年纪大了无法亲赴——但他交代他最后一个徒弟带了一件东西给他——他七十年前和林牧第一次见面时喝桂花茶的那只搪瓷杯。杯子附了一张便签——"这杯子喝过那年的茶——今天是除夕——再用它装一碗粥。——张道玄。"

顾小桐把她二十年前从秦岭那家驱逐她的保守宗门带出的忍冬分株——如今已成了上百盆——分别送给了在座的每一间分院代表。她的附言用的是杜小月的话——"灶台上不止有粥——也有盆栽。——顾小桐。华南总院。"

叶小雨全网点亮金紫灯光——所有灯火节点同步——没有发言稿，只是在上网日志中写道——"今天全网接收信号一千二百余起——全部是祝福。——叶小雨。"

沈教授站起来说了一段他一辈子最不哲学的话——"我曾是一个自以为聪明的纯人派——后来我发现我对修士的全部恐惧都来自想象。现在我不再用想象力把别人妖魔化——我用炉灶的实际温度给别人暖手。——沈教授——联合共治会总主持人。"

孟长青——他也来了——站在最后一排。他不是来发表感想的。他是来把一颗最新的鹅卵石放在灯火塔展区——和所有前辈的石头在一起。他放好后连退三步——然后走了。走了一小段路后他停下来——回头看了一眼灯火塔——嘴角有一个极小的弧度。

林牧和苏晚并肩坐在石凳上。桌上放着两碗桂花粥，一把已经褪色的蓝色便签，和那本被翻旧了的《诗经》。"从互不吓唬到互相支持——"苏晚说——"走了八卷。"

林牧握着她的手——这一次不需要再用任何比喻了。

（第七百七十章 完）

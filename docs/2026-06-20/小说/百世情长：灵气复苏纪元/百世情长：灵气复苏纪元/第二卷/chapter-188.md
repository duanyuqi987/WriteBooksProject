# 第188章 看她长大

苏小晚十八岁那年夏天，高考成绩出来了。她考上了省城的一所师范大学——教育学专业。分数不算特别高，但是正好卡在录取线上。拿到通知书的那天她抱着妈妈在院子里哭了——不是难过，是开心。她考上了。对于D级灵根的农村孩子而言，"考上大学"依然是一种足以改变命运的成就。

林牧坐在皂荚树下，听她在院墙那边的大喊大叫。猫从他的膝盖跳到地上，伸懒腰，用尾巴尖来回扫了一下他的手腕——好像是在提醒他可以欣慰一下。他确实欣慰了。但他同时启动了另一项准备:她要去省城读书，这离他的安全防护范围一下子远了很远。

以前她的生活半径只是村和周边乡。现在她将去一个两百多公里外的大城市——那里有密集的人口、复杂的灵气社会分层、各种各样的修仙人和非修仙势力。省城不是桃源村。桃源村是他在十几年的时间一颗一颗砌出来的堡垒。而省城——他必须在四个月之内做好一切远程防护的准备。第一件事就是护身符。

出发前的那个傍晚，苏小晚正在房间里收拾行李。妈妈在厨房给她包饺子——酸菜馅的，她不爱吃韭菜。林牧敲了敲门。他手里拿着一个很小的布包。布是淡蓝色的棉布，上面用细细的黑线绣了一片小小的叶子——这个布包是他自己缝的。里面装着的是一块护身符——一块刻着他神识烙印的青玉。玉质和第一世第二世她戴的两块平安扣是一母同胞的材料。第四块同样材料他留在他自己胸口的灵囊里。

他把布包递给她。她打开，拿出那块玉——青色的，不冰手，摸着特别舒服。

"带着这个。不管去哪都安全。"

她翻来覆去看着，眼睛亮亮的。"好。谢谢老师。"

她把玉挂上脖子时忽然含着笑意问了一句:"林老师你是不是喜欢我呀？"

这句话从她嘴里蹦出来的时候整个院子的空气顿了一下。不是风停了——是林牧所有的灵息在同一瞬静止了。猫在本能感知到主人的灵压骤降时，尾巴瞬间竖成了瓶刷。

但只有一刹。他淡淡地弯了弯嘴角，把竹杖在地上戳了一下。"喜欢你干嘛。你现在太费钱了。"

她哈哈大笑起来——她知道这是他的转移大法。每次她问到他私人感情的事他都会转移到讨厌的事情上。她也没追问。因为这是她刚才顺嘴说的一个玩笑，不是真的怀疑什么。她把玉在脖子上调整好，然后张开双手抱了一下他的肩膀——这个拥抱太突然，让他还没来得及反应。她从记事起就不知道他的拥抱是什么感觉。今天第一次——他的肩膀骨头硬硬的、暖暖的。

"老师你放心——我在学校里肯定好好的。你一个人在村里别太安静了——不然老猫会发霉。"她放开手后认真地叮嘱。

他点了点头。然后转身回自己的院子。脚底的青石子路在傍晚暗淡的天光下和平时一样。猫跟在他后面，把尾尖勾他的脚踝。他在坐下后把手放在膝盖上。猫跳到他的膝盖上，把下巴放在他的手背上。水壶里的锦鲤发来一条冷冰冰的灵念:"刚才她接近你的那一瞬间——你对她的保护铭印出现了一个小小的杂波——像心防被刺了一下。"

林牧没有否认。他只回了一句:"她抱我。这是我第三世里第一次和她发生亲人间的肢体接触。好了。继续工作。"

那一夜他把护身符的灵络全面激活。玉中刻着三道功能：一是随时随地能感知她的坐标位置（精度达十丈以内）；二是当有伤害性灵力攻击对她构成威胁时，会产生一道反噬灵罩瞬间弹飞攻击者并同时发信号给他；三是如果她的情绪处于极度恐惧中超过一分钟，护身符会直接建立心灵传讯，让他可以跨空间听她看到什么的画面。这个三重保护可以让她在省城不受金丹以下的任何人威胁。如果她遇到金丹级以上——他就不管暴露身份了。直接瞬移过去。

出发大清早。苏大山开着三轮车载她和行李去镇上的长途车站。林牧站在村口的皂荚树下对她挥了一下竹杖。她坐在三轮车后斗里，一手抱旅行袋一手举高用力冲他摇。三轮车在土路上慢慢颠走。她最后看见了那个竹杖的末端在晨光中摇了四下。

那根竹杖是她整个人生的起始坐标。它在她心里无古无进——它在树下。她可以去闯天下了。

在三轮车消失在山道弯处之后，林牧回屋给自己泡了一壶冷茶。猫用嘴拽了一只苏小晚遗落在院子的彩色发带回来。发带是粉白色条纹的。他用两指接过来看了一会儿，放回到她那边院子的窗台上。

然后他对锦鲤说:"她去了省城。希望她会在省城主动问出那句话。第一年我会在省城附近设置辅助点——你留下看家还是跟去？"

锦鲤用尾巴掀起小片水花:"你去哪，我这小壶去哪。"

猫把发带又叼回他脚边。他低头看了看——最后还是把发带收到她送他的那份成长档案里了。三岁到十八。一个小姑娘长成了一名大学生。没有人知道他用了多少心思。但这不重要——重要的是，从她的第一声婴啼到她成人礼上的第一个坚定拥抱——他都在身旁。没有一个重要时刻错过。

**作者：段锦佑**

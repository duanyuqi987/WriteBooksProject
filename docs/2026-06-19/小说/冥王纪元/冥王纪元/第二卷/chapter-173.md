# 第173章 进藏之路，高原异兽横行

唐古拉山口。海拔五千二百三十一米。

越野房车在盘山公路上缓慢爬升。发动机在缺氧环境下功率打了折扣，涡轮增压器每隔几十秒就嘶吼一次，像一头喘不上气的老牛。车窗外面是白茫茫的雪原——不是平原的雪，是高原的雪。薄而硬，被风刮成了斜纹状的雪丘，一眼望不到头。天空蓝得不正常——蓝得发黑，像是颜色饱和度过载的屏保图片。

李长生坐在副驾驶上，盯着手环上的灵气监测数据。数据在过去两个小时里跳了三次。

第一次是海拔三千米——灵气浓度升至187灵素。第二次是四千米——灵气飙到了310灵素。第三次是刚过五千米——数据表直接跳到了519灵素。将近城里的十倍。

"高原上的灵气浓度这么高——为什么之前没有人感知到？"陈霜问。

"因为之前灵眼没有苏醒。"李长生把手环的数据发给了小王，"这些灵气是最近几天才喷出来的。之前青藏高原的灵气浓度和内地差不多，只是灵脉深。灵眼一苏醒，等于把地下水抽到了地表——所有被压在地壳深层的高浓度灵气全涌上来了。"

"那也意味着——"

"对。"李长生看着车窗外白茫茫的雪原，"高浓度灵气催生的妖兽——比低海拔的多得多。"

话音刚落，车顶的监测天线发出了一声急促的警报。

"左前方——七百米。"老陈的眼睛盯着路书，但右手的指尖在方向盘上不自觉地收紧了一下。

雪原上出现了一个黑点。黑点以极快的速度在雪地上移动——不是跑，是滑。像一条鱼在水面上覆过。黑点越变越大，轮廓越来越清晰——是一头雪豹。

但这头雪豹的体型是普通雪豹的三倍。肩高大约一米六，体长超过三米，不算那条在身后摆动的大尾巴。它的皮毛不是灰色——是纯白色，白到和雪地几乎完全融合。唯一能辨别它的位置的，是它双眼发出的淡蓝色幽光。

"成年变异雪豹。"刀疤的手已经按在了车门把手上，"灵气浓度三百以上区域常见的变异体。"

"不只是变异。"李长生的冥土感知境自动展开了。他的视野变暗了一瞬——然后那只雪豹在冥土感知中的轮廓变得极其清晰。它的体内有完整的灵气循环系统。不是被灵气污染之后的偶然变异，而是它本身已经具备修炼能力。"它是有意识的。它在观察我们——不是看猎物那种观察。是评估。"

陈霜握住了剑柄。

"等等。"李长生说，"它没有攻击意图。"

雪豹停在距离越野车大约五十米的地方。它蹲下来，尾巴绕在身前，歪着头看着这辆铁壳子。然后——它做了一个让车里四个人同时愣住的举动。

它抬起右前爪，在雪地上画了一个圆。

那个圆极其精准——不是随便挠的，而是用爪尖在硬雪上刻出了一道笔直的圆形凹痕。圆不大不小，直径大约半米。圆圈中间被它用爪子挖出了四个小坑——东西南北四个方向各一个。

"那不是圆。"老陈的瞳孔收缩了一下，"那是阵。"

李长生推开车门。寒风像刀子一样刮在脸上——零下三十几度的低温，加上海拔五千米的低氧，普通人在外面站三分钟就会失温。但他的冥气自动在体表形成了一层极薄的保护层——不是刻意的防御功法，而是冥气的被动特性:它本身就是冷的，所以不会被外界的冷穿透。

他朝雪豹往前走了一步。雪豹没有后退。它蹲在原处，蓝幽幽的眼睛直视着李长生掌心的冥纹。然后它低下头——把鼻尖凑近雪地上那个阵的圆心。

"它在用雪地画'聚灵阵'。"李长生对着手环说，"小王，你能看到这个阵型吗？"

"监测天线已经传了图像。"小王的声音从手环里传出来，背景里是键盘快速敲击的声音，"这个阵型——李哥，它的结构和方静最早在黑板上画的那个聚灵阵有八成的相似度。不同之处在于:方静画的是八边聚灵阵，这个雪豹画的是四边。四边是精简版——不需要复杂的材料，用灵气直接在雪上刻印就可以。这头雪豹是自己学会了画聚灵阵——不是有人教的。是它在高浓度灵气环境中自己悟出来的。"

一头自学会画聚灵阵的雪豹。

"它在干什么？"陈霜也下了车，剑拔出了半寸。

"在告诉我们——它是这里的灵气主管。"李长生盯着雪豹面前的阵，"它画的这个阵是领地标记。它用雪地画阵、用灵气激活——相当于在雪原上竖了一块告示牌:'此处有主，过往请注意。'它不是来攻击我们的——是来宣示主权的。"

雪豹像是在回应他的理解。它站起来，用尾巴把雪地上圆阵扫平，然后转身走了。走了三步，又回头看了一眼。那一眼的意思很明确——"你们可以路过。但不要在这里停留太久。"

车继续往前开。

老陈的方向盘握得比之前更紧了。不是因为害怕——是因为高原上的路况比路书上标注的还糟糕了几倍。冻土路段上的暗坑多了几乎一倍——灵眼苏醒引发的地脉震动导致冻土层出现了大量新裂缝。每一个裂缝上面覆盖着一层薄雪，看起来和普通路面一样，但车轮一压就会陷下去。

第一条裂缝是老陈凭借经验发现的——他发现前方五米处的雪面反光不均匀，有一小块区域反光偏暗。别人看不出来，但快递员的眼睛看路面看了十几年。他猛打方向盘，车右轮擦着裂缝边缘转过去。

后面那条两米多宽、不知道多深的冰裂缝在车窗里一闪而过。

"你怎么知道那里有问题？"刀疤问。

"雪面的反光度。刚刚下过雪，新雪的反射率是均匀的。那条暗带是冻土裂缝上的旧雪融了又冻之后形成的——年代比周围的雪老至少两个冬天。"老陈说这话的时候语气很自然，像在说哪条巷子停车不会被贴罚单。

"你以前送快递需要辨认雪面类型？"

"不需要。但我以前送过格尔木一个地质站。那次在格尔木多待了一天，当地的工程师跟我说——跑青藏线的SUV翻了最多的地方不是唐古拉山口的陡坡，是冻土裂缝。因为陡坡你能看见——裂缝你看不见。"

车继续往前开了三个小时。天色忽然暗了下来——不是太阳下山了，是云层从天边以极快的速度聚了过来。云层的颜色不是灰白——是青黑，像一大片瘀血从天空的伤口里淌出来。

"不好。"老陈说，"高原风雪。这种云叫'铁砧云'——积雨云和高原冷气层的对流云混合体。风速瞬间能到每小时八十公里以上，能见度降到两米以内。"

话刚说完，第一阵风就砸了过来。

越野房车车身猛地晃了一下。不是斜向的摆动——是整辆车被风从侧面推了半寸。车窗外的世界在十秒内从白茫茫的雪原变成了什么都看不见的纯白——雪不是在下，是在横着飞。狂风把雪粒碾成了粉末状，裹挟在风里打在车窗上，发出密密麻麻的噼啪声，像是一万只小锤子在同时敲玻璃。

老陈把车速降到了几乎爬行。能见度几乎为零——车前灯照出去只看得到一团快速翻滚的白影。

手环震了三下。

"灵气异常波动——强度三级。"小王的声音从手环里传出来，信号在暴风雪中断断续续，"来源——在你们正下方。"

"正下方？"

"冰层下面。深度大约——三十到五十米。有一个大型生物正在向上移动。"

李长生闭上眼。冥土感知境全力展开。他的神识穿透了越野车的地板、穿透了冻土层、穿透了三十米厚的冰盖——然后在冰层下"看见"了一个东西。

那个东西很大。体型至少是一辆中型卡车的大小。它没有固定形态——它的身体像一条放大了无数倍的蠕虫，直径大约两米，长度无法完全感知到(后半段还在冰层更深处)。它的表皮上裹着一层厚厚的冰晶——不是粘上去的，是它自身分泌的。冰层下的巨大蠕虫。

"唐古拉冰蠕虫。"李长生说。

"什么？"

"上古妖兽的亚种。成虫的长度可以达到三十米以上。它不靠视觉感知周围环境——靠灵气波动。它锁定了我们的车——我们的发动机在高原缺氧条件下运转不均匀，产生了一种特定的灵气脉动。它以为那是一头受伤的猎物。"

冰层下传来了一声沉闷的低吼。那不是通过空气传播的声音——是通过地壳传播的震动。震动的强度不大，但频率极低，低到车载设备的指针都在表盘上偏了一下。

"能不能甩掉？"刀疤问。

"在这种天气条件下没法加速。能见度不足两米，路面全是暗坑。速度超过二十公里就翻车。"老陈的手在方向盘上握得很稳——比平时还要稳。不是因为不紧张——是因为他开车送了这么多年快递，碰到的紧急情况太多了。他的身体知道在危险时刻的最佳状态不是紧张，是极致冷静。

"那就不是甩的问题。"李长生推开车门。暴风雪瞬间灌进车厢——雪粒砸在脸上生疼，温度感觉不到零下，因为皮肤失去知觉了。

陈霜跟着他下了车。

"你要干什么？"

"冰蠕虫在冰下三十米。它破冰需要时间——至少三十秒。我们不需要打它。只需要让它找错目标。"他把右手按在冰面上。五道冥纹同时亮起——暗金色的光在暴风雪的纯白中像五道烧红的裂痕。

冥气不是向下攻击。是向下发出了一道模拟信号。

冰蠕虫用灵气波动感知猎物——那他就给它一个假信号。他把冥气压缩成一个个短促的脉冲，沿着冰面向东南方向十五度角的方位连续释放。脉冲的波形模仿了一只受伤的大型哺乳动物的心跳节奏——不是瞎编的，是他用冥土感知境实时感知到的、那头冰蠕虫正在追踪的原信号。

真实信号来自东边——大约两公里外，一头落单的野牦牛，可能是暴风雪中脱离了牛群，正在冰面上挣扎。李长生把它的心跳信号复制、放大、向东南方向投射。相当于把一个目标换成了另一个。

冰层下的震动停顿了几秒。然后——转向了。

冰蠕虫改变方向，朝着东南方向游了过去。巨大的身躯在冰层下移动产生的震动渐渐远去，最后被暴风雪的狂啸吞没。

李长生把手从冰面上收回来。指尖的冥纹还在发光，但亮度已经在减弱——这一手耗了他不少冥气。用冥土感知境感知冰下生物本就需要极高的精神集中力，同时还用冥气模拟心跳信号——等于是同时做了感知和输出两项高负荷操作。

"走。"他回到车上。

老陈挂挡。越野房车缓慢而稳定地穿过暴风雪的中心区域，朝着那曲方向继续前进。

后视镜里，白茫茫的雪原渐渐被甩在身后。但车里的所有人都知道——这还只是进藏的第一天。前方的高原上，还有至少六天的路程。而每一公里的雪地下方，都可能潜伏着某种被灵气唤醒的古老生物。

(第173章完)

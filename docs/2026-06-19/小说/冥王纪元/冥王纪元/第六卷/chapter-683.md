# 第683章 历史纪念馆

李长生在新纪元的中央星域停下了脚步。

这里将是他建立"历史纪念馆"的地方。

所谓中央星域，其实现在还是虚空——连一颗恒星都没有。但李长生不在意。纪念馆的首要要务不是漂亮，而是永恒。他要在这里建立一个无论经历多少次纪元更替都不会消散的结构。

他开始动工。

混沌之主的力量在这个时刻完全体现了出来。李长生只是抬手，虚空中便浮现出建造纪念馆所需的全部构想——不是蓝图，而是直接的物质构想。他以混沌之力牵引宇宙最原始的物质粒子，像在虚空画布上作画一般。

首先是基座。他取来新纪元最初凝固的那些岩石——这些岩石是整个新宇宙中最古老的物质结构，纪元级的存在。它们黑得发亮，每一块的年龄就是整个纪元的时间。在他手中，这些岩石被压缩、重塑，变成一座横跨星系的巨大平台。平台上刻满了纹路——不是法阵，不是符文，而是时间的刻痕。每一道划痕代表旧纪元的一年。

然后是建筑主体。李长生闭上眼睛，回忆旧纪元所有文明的建筑风格——从最早的石器时代洞穴，到最后的星际联邦穹顶。他把所有这些记忆具象化，融入纪念馆的结构之中。于是这座纪念馆同时具有了洞穴的厚重、金字塔的庄严、教堂的肃穆、摩天楼的高耸、星际穹顶的广阔。不同文明的建筑语言在这里熔于一炉，形成一种从未存在过的风格。

但真正困难的是内容。

数以万亿计的意识水晶——每一块都要妥善安置。

李长生在纪念馆内部开辟了一个特殊的空间。这个空间在整个建筑的最深处，不受时间和空间规则的限制。里面的体积被无限放大——外看只有一间屋子，内里却足以容纳一个宇宙。

他把每一块水晶——按照意识所属的文明、种族、年代——分类排架。

整整花了新纪元相当于三十个地球日的时间。李长生不眠不休，一块一块地亲手放置。他可以一次全部搬进去——但那样做，这些意识的尊严在哪里？每一块水晶都代表一个真实的生命，值得被尊重的生命，不是可以批量处理的货物。

他很清楚自己在做什么。他不是在给这些意识一个继续存在的机会——那是太初做的事。他只是在给这些意识一个体面的、被记住的安置。就像一个守墓人，把每一块墓碑都擦干净。

当最后一块水晶被安置妥当，李长生在纪念馆大门上方刻了这些字样——

"这里是为了纪念旧纪元一切曾经活过的生灵。

无论你来自哪个文明、哪个种族、哪个时代。

你的一生，值得被铭记。"

然后他做了一件在别人看来可能会觉得不值的事情：他在这座纪念馆周围设下了永恒的结界。

这个结界没有杀伤力。它是纯守护型的——任何试图进入纪念馆的存在，都会被结界读取意图。只有怀着敬畏之心前来参观的人，才能通过。任何试图破坏、窃取、掠夺的存在，结界会把它们弹开到最远的星系之外。

"旧纪元的人已经不能说话了，"李长生对着虚空说，"那就由我来替他们守门。"

这是新纪元的第一座建筑。

也是最重要的一座。

（第683章完）

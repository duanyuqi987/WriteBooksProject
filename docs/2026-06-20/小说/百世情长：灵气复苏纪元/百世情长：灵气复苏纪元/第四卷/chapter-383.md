# 第三百八十三章 合道的方向

炼虚之后的下一个境界是合道。合道不再依靠灵力积累——而是需要在灵魂深度里完成"道的整合"——将毕生修为、剑法、业力、经历全部融合成一个"一"。对常人而言这是极艰难的——但对苏晚和林牧来说反而相对容易。因为她的"道"是医剑合一——治病与制敌都是同源。他的"道"是架构与守护——IT和修仙都是将系统稳固。而共生契约天生便已将两人的道连在了一起——他们的合道不需要分别突破——只需一起将两股道义融合即可。

融合的第一步是"道义对述"。两人坐在蜀山听风台上对着云海各讲自己一生最核心的那个核心理念。苏晚先开口:"我认为剑不是武器——是体内经络在人之外的延伸。修剑就是修自己的身体和别人的信任。终极目标不是'斩杀'——是'修活'。"

林牧说:"我认为灵脉不是资源——是信路。维护灵网不是管理——是让人互相连通。终极目标不是飞升——是保留这条线——只要线在，不论多少世你都不会消失。"

她听完后沉默半晌，目光转向他说:"你的道其实就是——我。"

"对。"他答。"但你的道不只是我。还有那些病人、那些节点、那些你给他们减震垫的老铁匠——这也是我的道。所以我的道——是包括那些所有你在乎的东西。"

她望着白花在风中轻轻摇动——再也没问任何问题。

合道的前奏就这样安静地开始了。没有雷也没有光——只是两人在午后的风中说清楚了自己活到今天的根本原因。然后道开始融合。

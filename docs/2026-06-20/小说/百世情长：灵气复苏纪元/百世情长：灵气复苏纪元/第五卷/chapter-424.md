# 第四百二十四章 天罚层的来客

飞升第一百四十五年。天罚层传来消息：阎锋在天罚监中已满三百年刑期，表现良好，获准"刑满释放——但永不被允许离开上界"。他出狱后第一件事是请求来闻道府。

苏晚和林牧在月桂树下见他。阎锋比当年老了许多——天罚层不能保持容貌，他看来已像个凡人中年。但眼神里的凌厉消退了很多——换成某种很像释然的东西。他带着一株从黑琊城那棵老月桂上新扦插的小苗——说:"给你的道侣。那年在昆仑——我刺伤她——我无法收回，但可以带一株活的桂花来。"苏晚接过苗，将苗种在学堂后院那块"空白地"的边缘。"空白地现在有第一棵新物种了。"她说。

阎锋去看墨染的墓时独自站了很久。回来后他对闻道说:"那棵月桂比三百年前更香了。我从前不知道种花要那么久。"林牧答:"对——但要的花都值得等。"

阎锋离开后苏晚在那棵新栽的月桂旁加了个标签:"阎锋种。为苏晚。见证:林牧。时间:天罚之后。"她把标签插好——然后回诊所为当天的病人看诊。窗外桂花刚落了一层新的。

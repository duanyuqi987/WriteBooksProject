# 第242章 月球战场上的完整记忆显现

七块碎片融合触发的不仅是空间感知模块——还有记忆。

每一块碎片中都封存着冥王生前的记忆片段。前六块碎片融合时释放的记忆是不完整的——破碎的画面、零散的声音、断断续续的战斗片段。碎片不完整，记忆就不完整。但七块碎片构成了冥王令的主体框架之后，记忆的封印被解开了。

不是冥王刻意为之——是冥王令的本质属性。冥王令不仅是武器，也是冥王的第二大脑。在冥王陨落的一瞬间，他把毕生最重要的记忆全部转存在了冥王令中。九块碎片每融合一块还原一段，七块合一，还原到完整的战争记忆。

李长生是在闭上眼睛的一瞬间被拉进记忆的。

不是做梦。不是幻觉。是冥王令的记忆回放——以第一人称视角。他的感知被完全覆盖，眼前看到的不是环形山底下的岩石，而是——

------

一万年前。月球行宫。

他站在一个宽敞到不可思议的大厅里。大厅的穹顶极高——至少有两百米——穹顶上镶嵌着一幅远比冥王令背面更加宏大的星图。那不是记录在符文里的静止星图，那是实时转播——穹顶的灵石直接连接到分布在银河系各处的前哨站，每一颗星星的光芒都是前哨站发回来的实时信号。

冥王的月球行宫。不在月面，在月球内部。空心月壳被掏出了一整片宫殿群，由数以万计的灵石组成的阵法支撑着地下空间的结构。宫殿的中心就是这座星图大厅——冥王处理帝国日常事务的地方。

"陛下。"

有人在他身后说话。他转身——是的，在记忆里，他就是冥王。这种感觉很奇怪:你能意识到此刻的自己是李长生，但你看世界的视角、身体的动作、开口说出的每一个字，都是冥王的。你是一个装在冥王视角里的观察者。

说话的人是一个穿黑色长袍的中年文官。他的腰间系着一枚玉牌，玉牌上刻着"司天监"三个字——帝国负责天象观测和情报收集的部门。他的脸上带着一种强压着紧张的镇定。

"猎户旋臂第四星区的前哨站——失联了。最后一次发送信号是在十二个时辰前。信号内容是——'发现不明身份的大型灵力聚合体接近中，数量十二。灵力等级——全都在神级以上'。"

冥王——此刻的李长生——没有任何慌张。他只是微微抬了一下手，示意文官继续。

"陛下一人前往月球行宫——是独自巡视。只有近卫营随行。近卫营的兵力——八百人。对方——十二神级。"

"十二个。"冥王说，声音平静得像是在确认今天要接待几位外宾，"确认是哪些人了吗？"

"确认了。"文官的声音干涩得像磨砂纸，"诸神联盟——十二位神级修士。盟主是——太古神君。副盟主——赤炎天尊。其余十位，分别是来自银河系各处分裂势力的神级首领。他们的旗帜——今天早上同时插在了月球轨道外围十二个阵位上。"

十二神级。一个月球行宫。八百近卫。

力量对比是碾压级的。

"他们布的是什么阵？"冥王问。

"从外围阵位排列上看——是'十二天罡禁神阵'。"文官的手已经有些发抖了，"这种阵法需要十二位神级修士同时持阵，缺一不可。一旦布成——阵法覆盖范围内的所有低于神级的生命体会在第一时间被压制到无法动弹。而目标——只有一个人。"

整个月球行宫都笼罩在这个阵法的覆盖之下。冥王是目标。唯一的那个。一国之君，被十二天神设伏围困在自家行宫里——不带主力军团，不带护国法器，身边只有八百个近卫兵。

正常人的反应是什么？愤怒。调集兵力。突围。或者——谈判。

冥王的反应是——笑。

不是嘲讽的笑，不是悲壮的笑。是一种极淡的、像是在看一出拙劣剧本的笑。

"他们等这个机会等了多久？"

"根据情报——至少一千年。"文官的声音几乎是从喉咙里挤出来的，"过去一千年中，十二诸神联盟不断接近帝国的偏远星区，逐星逐星地向地球推进。每一步都精心计算了我们在当地的驻军轮防周期。他们选择今天——是因为今天近卫营换防，外围警戒最薄——而且，最关键的是——陛下您一个人来了月球。帝国的其他神级战力——全在地球主星上——要调来支援至少需要十二个时辰。这个时间窗口，是他们花了一千年才等来的。"

"一千年。"冥王站起来。他的身量不算高——比一般的武将矮半个头。但当他站起来的时候，整座星图大厅的穹顶似乎都变矮了。"那就让他们等了一千年的结果——不太好看。"

他走向大厅门口。走了三步，回头看了文官一眼。

"通知近卫营——不用设防。全部撤回地宫内层。封锁所有通往地表的通道。不管外面发生什么——不许出来。"

眼泪无声地流下文官的脸。不是因为恐惧——是因为他知道，陛下在下这道命令的时候，已经做好了回不去的准备。

"陛下——"

"照做。"冥王推开门。

门外——是月球地表。环形山。灰色大地。漆黑天空。他站在月球上，没有穿任何防护。神级修士不需要防护——他的身体本身就是防护。

在他身后，八百近卫的脚步声在往回跑。每一个士兵的步伐都沉重得像在泥里走。他们在撤退——不是贪生怕死，是在服从命令。服从那个让他们活下去的命令。

在他面前——十二道光柱从天而降。十二位神明，每人站在一道贯穿天地——不，贯穿月面和星空的光柱之中。他们的灵力排布极为精妙，十二道光柱准确地落在月球环形山周围的十二个阵位上，形成了一个完美的圆形封锁。这是"十二天罡禁神阵"的阵基——十二神同阵，已经一千年没有出现过。

冥王一个人站在环形山中央。

没有带盾。没有披甲。就一件黑色的长袍，和腰上挂着的那枚令牌——冥王令。第九号版本，完整形态，九块碎片全部在位。

"诸位——"冥王的声音穿过真空，直接传递到十二神的灵识中，"让你们等了一千年。辛苦了。"

太古神君的声音从阵列正北传来。他的声音是一种奇怪的金属质感，像是一把铜剑在石板上摩擦——不是他本来的音色，是成神之后身体过度强化导致的声带变化。

"冥王。收回你的假笑。今天是你陨落的日子。"

"这话——"冥王慢悠悠地摘下了腰间的冥王令，拿在右手里掂了掂，"一千年里你们至少说了三千次。每次都不敢来。"他把令牌转了一圈，正面朝向正北，"今天敢来了。是因为找了十二个？还是因为——你们确认我不会召帝国军团？"

太古神君不再说话。十二道神光同时增强。十二天罡禁神阵的压制力从月面八方涌入环形山中央。低于神级的生命体会被直接压碎——但冥王不是低于神级的。他是冥王级——一个只属于他自己的级别。

在十二道神光的共同压制下，冥王动了一下肩膀。只是动了一下——像是一个在办公室坐久了的人站起来的伸展动作。然后他握着冥王令，对着正北方向的太古神君走了过去。

走。不是飞。不是瞬移。是走。

在十二位神明的联合压制下，他一步一步踩在月尘上，走得很稳。每一步踩下去，脚下的月尘就会被某种力量压实——不是灵气，是纯粹的气势。冥王令在他手中开始发光，暗金色的光穿透了十二神阵的压制力场，照在太古神君的脸上——

不，不是照在脸上。是在他的眉心位置凝聚成一个亮点。亮点在变大。从光点到光圈。从光圈到光门。冥王令打开了一道门——不是通往别处，是通往死亡。

"一千年。"冥王边走边说，"你们用一千年布置。我这个人比较直接——只用一招。"

他举起了冥王令。

画面振动。

------

李长生猛地睁开了眼睛。

他还在月球环形山底下的废墟里。陈霜站在对面，霜降剑已经拔出了半截——她在那几秒里察觉到了他状态不对。小王在一旁紧张地看着。

"李哥——你刚才闭眼了大概十五秒。"

十五秒。但在记忆里，他经历了至少十分钟。

"我看到了。"李长生说。他的声音有些沙哑——不是因为身体疲劳，是因为刚才的十五秒里，他的意识以第一视角经历了冥王生命中最后几个时辰的片段。"我看到了那场战争的开端——冥王单刀赴会。"

陈霜收回剑，望着他。她没有催他讲——剑修知道，有些事情需要自己慢慢沉淀。

但李长生没有沉淀。他站起来，环视着周围碎裂的岩石和不远处开始发光的更多的记忆残片——七块碎片融合后，这些埋在战场废墟下的记忆也在苏醒。

"接下来——"他说，"我们看到的只会更多。"

(第242章完)

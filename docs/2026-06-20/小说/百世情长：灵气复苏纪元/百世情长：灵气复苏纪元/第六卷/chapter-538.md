# 第五百三十八章 飞升试炼的消息

在迎仙台的日子安稳地过了很久之后，上界仙庭发布了一则重要的通告——每五千年一次的上界高阶飞升试炼（向更高维度飞升前的预选），在近期即将开放报名。这不是下界飞升上界的通道。而是上界仙人向更高维度的上界（称为"仙上仙"或"太虚仙域"）晋升的预选通道。这个通道的下一次开启预计在数百年之后，但预选报名通道在几个月之后就开放了。只有合道后期以上的道侣才有资格以"道侣组"形式报名。这个条件——林牧和苏晚已经满足了。

松鹤仙人把仙庭下发的通告竹简放在石桌上让两人看。通告上关于试炼的说明有三项核心测试:一、道侣需要在极端的虚空裂隙环境中保持灵魂共鸣连续不断，持续极长的时间。这考验的是异步缓冲能力的极限。二、两人要共同在因果天平的考验中为对方承担一次对方无法承受的损失——也就是"代偿试炼"。三、要在太虚仙域投射下来的幻境中证明两人可以保持各自的独立人格——不被高维的力量强行融合为单一意识。

这三项测试——如果用传统的双星篇功法去应对，第一项就有极大概率失败。因为传统功法强调同步，在虚空极端环境同步极难维持。但双心诀的核心偏偏就是"以异步为常态"——那一式错位补偿式正好是为极高强度异步环境下保持连续共振而设计的。可以说，这个预选试炼的测试标准——几乎像为他们量身定做。

苏晚把通告翻到最末——看到了试炼地点的名称。太虚裂隙塔。在上界第七重天的极深虚空中，一座由太虚仙域直接投射下来的检测塔。这座塔每五千年自动运转一次。距报名截止还有一段时间。距考试还有更久。她有大量的时间来准备。"咱们去不去？"她问。林牧把手从凳椅扶手上放下——"去。不是为了飞升。是因为那个代偿试炼。我想知道——在完全陌生的试炼规则下，我还能不能替你多挡一刀。"苏晚愣了一下:"你想替我被代偿——""一直想。从第一世开始就想。"

苏晚看着他的眼睛。她没有说"这次不用你替我"——因为在试炼规则中是一定会有代偿试炼的。如果她拒绝他替——他可能反而会更耗神。她说:"代偿试炼是双向的。你替我挡，我也替你挡。多的不说了。晚上回去做手擀面——要多粗有多粗。"林牧嘴角动了动:"多粗都吃。"

（第五百三十八章 完）

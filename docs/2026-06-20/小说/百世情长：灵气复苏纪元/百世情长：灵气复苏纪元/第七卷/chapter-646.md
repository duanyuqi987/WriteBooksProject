# 第六百四十六章 百世情缘契约原初印记

淡金色的符文在林牧和苏晚的手心里持续了整整一天才慢慢隐去。在那一天里，两人的神识共享了一种极其古老的体验——不是记忆，是"认知"。

百世情缘契约不是他们这一世签的——它是第一世之前，在上界的某个时刻由两个比他们更古老的存在签订的。那两个存在——男为真仙，女为真仙——在签订契约时约定的内容不是"我们会爱到永远"，而是"你将在轮回中遇到我百次。每一次都会在不同的关系里——有时是恋人，有时是朋友，有时是敌人，有时是陌生人。你在每一种关系中都会学到一种不同的爱的方式。百世之后你才会集齐所有的爱的方式——届时契约将自动激活。"

林牧终于理解了：为什么前世他是青云宗最天才的修士，却被一道雷霆劈落凡尘。不是被惩罚——是被传送。他的真仙本体选择了用"堕落"作为进入百世轮回的通道。他不是被算计之后潦倒的败将——他是主动报名参加这个契约试炼的实验者。苏晚也理解了：为什么她的百世轮回中每一世都记不起前世——不是因为封印，是因为这个实验的本质就是"不带记忆重新学习每一种爱"。

他们坐在修炼室里，面对面，手心的金黄色符文正在缓慢消退。苏晚的声音很轻："所以我们这一世——所有前世学过的爱的方式都在我们体内。我们不需要重新学——我们只需要把它们唤醒。"

林牧看着她的手。他的手心贴上去——和她手心对手心。金色符文在他们的掌间闪烁了最后一次——然后暗下去了。不是消失了——是沉入了他们的灵海深处，成为他们最后一次突破——即将到来的合道和飞升——的钥匙。

"第一百世。"林牧说。"我们到了第一百世。第十种关系——'相互尊重'——还在下一卷。但我们已经拿到了所有的拼图。"

"只剩最后一步。"苏晚反手握住他的手。"飞升之门。"

窗外桂花树正在吐新芽。九岁半的石头在院子里给他的"护树剑"换了新枝——旧的那根已经干了，他今天刚从树上折了一根新的。他把它插在泥里，然后跑去厨房看灶台上的粥是不是在沸腾。粥是红豆薏仁——苏晚早上放的。锅盖上压着一张黄色便签："石头：粥好了先给今天来听课的三个新散修盛。——苏晚。"

石头踮起脚尖揭开锅盖。热气冒出来。他从碗柜里拿了三个碗，每个碗里都盛得满满的，然后端着托盘走出厨房。他的背影已经不再是那个四岁时被遗弃在山门口的胆小的孤儿——他端粥的样子平稳而自信。

（第六百四十六章 完）

# 第938章 永恒前的最后一课

上界太行传道堂正式列名"公共教育架构"之后，苏晚做了一件出人意料的事：她主动退出了传道堂的日常管理岗位，把它交给了一套接力制度——由三位总导师轮流担任堂长，每人任期十年。这三人是古柏、安小泽和新的一位年轻的羽族女导师白羽令。他们都已经成熟到足以独立运转传道堂的整个体系。

苏晚退居幕后，不是因为累了——是因为她明白了林牧离开她在下界时说过的话："让规则来自每个人心里"。传道堂要走的未来不是倚赖她的存在——是每个人自动成为规则的承担者。她亲眼看着他们三个人接棒——接的不是权，是责任。

离开日常管理后，她做的是两件事：编写传道堂的永久基本制度和远足探望各地分部。

她把永久制度写成了一本薄薄的小册子——只有二十九页。册子中的核心条款全部压缩在了三句话内："不收门槛。不论来历。不丢弃任何一个人。"她说这二十个字的公约不需要再多的规则来辅证——它自身就有足够的弹性来衍生出其他一切准则。她叫这个册子叫《太行约法》。册子后面她手写了签章："苏晚——太行书院永远的一名新生。"

她把册子印刷了千份，分发到所有上界太行传道堂的分部和下界太行书院的各分院。这些册子不是要求人们跟着她走——是提供"可以以此为基地发展属于你们自己的样式"。她明言，"太行"这两个字只是一个称谓，不是一个统一的拘束——各地可以用自己地方的名称自主办学。只要"三不"不变。

远足探望各地分部花了她和林牧十年时间。十年间他们共走遍了上界大陆一百多个传道堂分部——任何人在任何一个分部里任何时候都可以自由入学，任意换堂。各分部之间的师资共享制度被永久记录入道纪院的元规则当中——成了整个上界教育板块最底层的一条明文律法。

路途过程中他们没有用过一次空间瞬移。苏晚说——走路去看那些学校，更能体会路有多长。林牧同意。于是两人徒步走了十年。一路上看到的风景包括新开的分部、历经困难坚持不关闭的小课堂、建在荒墟中的"废墟传道堂"（专为在碎域遗迹边工作的人提供基础教育）。一切图景将太行传道堂的"星火燎原"模式在上界的空间中铺现了出来。

十年后他们回到了太初之城的住所。院墙上爬满了青苔——十年间青苔将四院全部覆满了绿。银白老树的两根枝条在门头处交错成一个天然的拱。苏晚站在门前用手触摸青苔上的小仙虫——它们仍在角落里忙碌，和它们十年前一模一样。

"我们该休息了。"林牧说。

"休息多久？"

"随你。永生支持无限长的休息。"

苏晚把窗门推开。窗外的暗紫色光幕开始在春季缓慢过渡到亮白。她说："那先把传道堂的最后一课教了。"

所谓"最后一课"是一个她想了很久的念头——不教功法，不教炼丹——教的是一次问答。她将在传道堂的总讲堂和所有分部同时远程联动（通过灵晶直播）做最后一次公开答疑——任何学员、任何导师在任何分部都可以现场向她抛出任何问题。这将是她在太行传道堂教的第一千零一堂正式课和最后一堂公教课。

消息传开后整个太初之城都轰动了——不仅是底层仙人，连城防、仙律、以及道纪院的一些观察者都赶来旁听。她的讲坛简单到极致——一张旧矮桌和蒲团。桌上一杯茶。

问答开始。头一个问题是来自羽族分部的学员："苏师，您从普通废柴到永生——你怕过吗？"苏晚答："怕过。筑基失败的时候怕自己真的是废物。林牧飞升的时候怕他回不来。书院刚开的时候怕招不到人。都怕。怕没用——但怕不丢人。怕完之后继续做下一件事——这样一直做下去。"

第二个问题来自一名中年散修："您教了几千年不收学费——书院真的能一直靠卖灵器和义诊赚钱活下去吗？"苏晚答："一直能。因为太行书院的毕业生没有一个是欠债离开的。他们来的时候身无长物，走后获得的是能自食其力的力量。他们中的很多人把赚来的钱又捐回来给书院——不是'必须'，是'想这么做'。"

第三个问题来自古柏——他代表老学员问："苏师你走了之后——我们还能不能随时找你聊天？"苏晚看了他一眼，微笑："我在隔壁。想喝凉的茶就来。"

问答持续了三个时辰。最后一道问题由一个来自下界飞升上来不到一个月的新人提的——非常年轻，脸上还有少年人的稚气。他问："林师——"
"林牧。叫他林师可能他不习惯——不过没关系。"

"林师——您当初是怎么确定你能拿到道源回来的。"

林牧在旁边沉默了。他此前一直坐在苏晚身后的角落，没有在直播中说过任何话。然后他终于开了口——声音不重不响，和每次回答关键问题时一样停半秒再开口。

"不确定。但不做的话——连不确定的资格都没有。"

问答收尾。苏晚站起来，从讲坛的蒲团上站起来转身向所有直播灵晶和现场观众鞠了一躬——不是感谢捧场，是感谢信任。然后她对所有人说最后一句话——与千年前她在太行山上对三十二个第一批学员讲的那句几乎一模一样，只改了一词。

"修行不是变厉害。修行是——成为更好的自己后，转身托起下一个需要被托起的人。"

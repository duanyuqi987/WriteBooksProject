# 第394章 无解空间

虚空之眼的攻击方式让所有人措手不及。

它不是用能量打你。它不发射光线、不释放热能、不产生冲击波。它的攻击方式是改变你所在位置的空间规则。冥王号的船壳在它的领域内被动拉伸了三秒之后，第二种规则改变出现了。

这一次是"方向"。

冥王号的舰艏本来是正对着虚空之眼的。但在老马的土系加固刚生效的那一瞬间，舰艏和舰艉的方向被强行交换了。不是船调了头——是船所在的那块空间本身被从内部翻转了一百八十度。冥王号的推进系统仍然在往前输出推力，但因为"前"在空间翻转之后变成了"后"，船实际上在加速撞向虚空之眼。

"空间定向翻转！"小王的声音穿透了警报声，"它把冥王号前面的空间和后面的空间调换了位置！不对——不只前后——它在连续翻转！"

确实在连续翻转。在接下来的三秒之内，冥王号所在的空间被翻转了至少六次——前后、上下、左右——所有方向向量在每次翻转之后都变成了不同的朝向。导航系统完全失效——它连"船头朝着哪个方向"都无法确定。船壳上每一块金属板的受力方向都在疯狂变化。老马的土系加固在连续的翻转中被撕裂了——不是强度不够，是方向乱了。他的加固在原来的受力模型下是完美的，但空间被翻转之后，受力模型全废了。

刀疤的近防炮阵列全数失灵。炮台在尝试锁定目标的时候发现目标的位置一直在跳跃——虚空之眼的物理位置没有动，但它通过翻转空间把它和冥王号之间的相对位置变得无法锁定。近防炮的瞄准系统是基于空间坐标运算的——当空间坐标本身被重新定义时，所有的瞄准数据都变成了错误值。

"不能用常规武器！"小王喊道，"它的空间领域对所有需要空间定位的东西都免疫！必须用不需要空间定位的攻击——需要能直接作用于法则层面的东西！"

李长生的冥王令已经亮起来了。他没有等小王说第二遍。暗金色的光芒从他的掌心爆发，在冥王号的外壳上形成了一层黑膜。这层黑膜不是防护罩——防护罩需要空间位置信息。它是冥系法则的直接投影——冥气主动覆盖了冥王号所在的局部空间，用冥系法则强行稳定了被虚空之眼搅乱的空间规则。前后上下左右重新变得有意义了。船壳的受力方向恢复了正常。导航系统重新获取了空间定向。

但虚空之眼的第三种攻击来了。

这一次不是翻转空间——是折叠。在冥王号重新稳定方向的那一瞬间，虚空之眼把冥王号所在的整块空间折叠了。折叠的方式很直接——把冥王号的前半段和后半段所在的空间重叠在了一起。两段空间中的物质试图同时占据同一个物理位置——船壳的金属分子在那一瞬间被强行挤在了一起。前段和后段的金属结构相互穿透——不是撞穿，是空间重叠导致的两套分子的量子态发生了冲突。

冥王号的内部警报从黄色跳到了红色。船壳受损率在零点五秒内从零跳到了百分之十七——左舷第三、第四舱段出现了空间重叠导致的金属疲劳断裂。三块外壳金属板被空间重叠的气压差崩飞了——它们在脱离船壳的瞬间被空间折叠弹了出去，消失在虚空之眼的领域深处。

龟相从李长生的扶手上跳了下来。它落在了指挥舱的地板上，龟壳上的七十二重大阵阵图全部亮了起来——从第一重到第七十一重，每一重都在发出不同频率的暗金色光芒。这七十二重阵图是冥王时代的最高阵法成就，其中第六十七重大阵的专门用途就是——对抗空间系攻击。

"给我十秒。"龟相说。

它的龟壳上，第六十七重大阵的阵图开始向外扩散。暗金色的阵纹从龟壳上脱离出来，悬浮在它周身的空中——这些阵纹不是二维线条，是三维的立体符文结构。每一道符文都是由纯粹的冥系法则凝聚而成的——它们不需要空间稳定器的辅助，因为冥系法则本身比空间法则更底层。

阵纹开始覆盖冥王号的外壳。在五秒之内，第六十七重大阵完成了对整艘船的外部覆盖。虚空之眼的空间折叠在遇到阵纹的一瞬间被弹了回去——不是因为能量对抗，而是因为第六十七重大阵在冥王号周围创建了一个独立的"空间基准面"。在这个基准面之内，空间规则由冥系法则定义，不受外部空间改变的影响。

虚空之眼的三重攻击全部被挡了回去。但那不是打败它——只是暂时挡住了。

冥王号现在是虚空之眼的领域中唯一一个空间规则正常的小泡泡。泡泡外面的空间仍在不断扭曲、翻转、折叠——虚空之眼没有放弃，它在不断尝试找到第六十七重大阵的缝隙。而第六十七重大阵的能耗是冥王号在正常航行时全部灵气输出的三千倍。

"我们不是在跟它打仗。"龟相的声音在李长生的神识中响起，"我们在跟整片领域战斗。虚空之眼就是这片空间——除非把这片空间从根本上破坏掉，否则它永远不会停。"

"怎么破坏？"

"需要一种能在空间尺度上制造致命伤害的攻击。这个攻击需要做到一件事——不是切开物质，不是摧毁能量——是切断空间。"

陈霜的霜降剑在侧舱门口闪了一下。

"空间斩。"她说。

（第394章完）

# 第491章 陈霜，皇后之礼

大婚定在从祖坟回来后第七天。

陈霜从李家庄后山脚下走进来的时候是下午。她没穿凤冠霞帔，没戴珠宝头饰——一件浅青色的素布棉袍，腰侧挂的是从不离身的剑匣。她走得很稳——剑修几十年的脚步，每一步踩下去都匀实、安静、不惊动地上的任何一颗沙粒。

但她的头发是自己编的。村里老婶子给了她一根老红绳——不是灵绳，就是最普通的棉红线，大约是从哪件破衣服上拆下来的，洗了洗晒干给她。老婶子递红绳给她时手都是抖的——不是老太太拿不准东西，是激动。老婶子说："你嫁进李家——就是我们李家的媳妇。我没啥好东西给你——这红绳是我当年嫁进这村子时我婆婆给我的。给你。"

陈霜接过红绳，说了一声："婶——我一定好好待他。"

她把红绳编进了自己平时最常系的那束头发里。剑修的手向来很稳——但这根红绳她编了三次才编好。第一次编完她嫌不够紧——被风吹散了不好看；第二次她嫌紧了拉得头皮不舒服——怕李长生看着觉得她不舒服了会皱眉头；第三次——编完了，正好。不长不短的一节红头绳，卷在她后脑的发束根部，和她青黑色的发丝夹在一起。看不见太张扬的颜色——但仔细看就能看见。她没照镜子——她不爱照镜子。她对着院里装井水的木盆水面看了一眼——水波不平，影子模糊。但能看出来：够好了。

她走出院门——去往祖坟前的那座山坡。仪式要在这片属于他父母的土地上举行——不是登基的那种粗花岗岩平台，不是燕山那种万人注视的中央广场。只是后山脚下那片几百年来李家人世代劳作、安息的地方。四周是新整过的垄坡——地上混着老柏树上掉下来的碎枝，踩上去嘎吱响。来的人不多——全是熟人。龙组的百岁老修士、几个跟他共过事的老修士；国家灵气局派了两名使者；剩下的就是李长生的那个草根团队——小旺、老陈、刀疤、许冰、老马、龟相。还有村里的几户老邻居：老支书一家、二叔一家、替李长生收拾祖坟的老婶子一家。没有其他外人。

李长生站在后山脚下的临时布置前。他穿着崭新的黑色外衣——但和陈霜一样，没有穿皇袍。他的右手掌心里一直冒着汗——不是紧张。他从宇宙西岸打到至尊议会、从星盗船打到星系禁区——他几乎没有出过汗。但今天他的掌心是湿的。他把手反复在裤管侧面搓了好几次。

陈霜走到他面前。她的步伐稳——比她使剑时还稳。她站在他面前——两人距离不足半步。她看着他领口那颗有点歪的扣子。伸手帮他扣正了。

"扣子自己扣的？"她问。

"自己扣的。"他说。

"扣歪了。"

"我紧张。"

陈霜弯了一下嘴角——笑了。不是大笑，就是嘴角往上微微动了那么一下。那是从她脸上出现真正的笑意以来李长生第二次看到——第一次是在他突破第八重后对她说"我还是那个人"的时候。

仪式是小旺主持的。小旺平时是程序员和帝国大管家——主持婚礼不是他的专业范畴。但他认真准备了——他在笔记本上写了长篇的婚礼流程，每条流程都打印出来夹在一块硬纸板上。他读的时候声音有点紧——不像在念婚礼词，更像在启动一个正式系统。

"李长生——你愿意吗？"

"愿意。"

"陈霜——你愿意吗？"

"愿意。"

两人对视。那只在陈霜手上的寒霜剑被搁在旁边地上——今天她不需要剑。刀疤站在人群后面——老陈用肘捅了他一下说"你眼睛红什么红"，刀疤别过脸——"眼睛进沙子了。"

仪式只用了不到半小时。结束之后，李长生拉着陈霜的手，沿着山路往上走。走到四座祖坟前——他站住。陈霜站在他旁边。

"爷爷，奶奶，曾爷爷，曾奶奶——"他的声音还是有点哑，"爹，娘——我带来了。她叫陈霜——是你们的儿媳。"

陈霜跪下来了。她和这个只有一面之缘的长眠子家一同跪下去——膝盖触及坟前干土的那一刻，她用了一把剑鞘撑着自己，稳住重心。然后她磕了一个头。

"李长生跟我说过很多事——他说他爹能喝酒、能劈一整上午的柴不歇；说他娘把饭省给他自己饿肚子。他说这些话的时候声音总是不一样——跟平常说话不一样。所以我早就想好了——如果将来有机会站在你们面前，我什么也不要，只来磕一个头。李长生这些年扛了很多东西，他有时候不说——但我知道。我今天来——不是来看他的过去，是来帮他一起扛将来。请二老放心吧——我在。"

风又过来——老柏树再次沙沙响。陈霜按住李长生的手，没有哭。她把红头绳往额前拢了拢，然后站起来，拉着李长生的手，一起向山下走。

这天晚上，老婶子在后山脚下烧了一道纸钱。烧完之后她喃喃自语："大山嫂子——你儿今天娶媳妇了。她人不错。"

纸灰飘向高处——散进柏树梢头。夜空很清。祖坟静静地亮着一缕淡淡的月华。

（第491章完）

# 第三十二章 打扫卫生那晚

现代文学展示排在周四。

我们组讲得不算差。唐青禾站在讲台上，讲女性意识时语速很快，粉笔在黑板上写得飞。曹然负责翻 PPT，差点把下一组的标题点出来，被唐青禾在讲台下踩了一脚。

我负责读结尾。

稿子是我写的。没有写得太苦，至少我自认为没有。最后一句是：爱不能替一个人完成生活，能完成生活的，只有一个人自己。

读完后，教室里安静了一下。

老师点头，说：“这句不错。”

唐青禾回头看我，冲我竖了个大拇指。

我低头收稿子。

那天晚上，班里安排打扫活动室。所谓活动室，就是学院楼一间堆满旧桌椅和海报板的屋子。学生会要用，辅导员让我们班派人收拾。曹然本来报名了，临时肚子疼，把我卖了。

我到活动室时，唐青禾已经在里面。

她扎着头发，戴着一次性口罩，手里拿着扫帚。

“你怎么也来了？”

“曹然说他快不行了。”我说。

她翻了个白眼：“他每次不想干活都快不行。”

活动室灰很大。旧桌子堆在墙边，纸箱里塞着宣传单，角落还有几块坏掉的展板。我们把桌子往外搬，搬到走廊，再把地上的灰扫成一堆。

唐青禾干活很快。

她不像有些人，只会站在旁边指挥。她袖子一挽，搬椅子、拆胶带、擦窗台，做得比谁都利索。只是嘴也没停。

“你高中是不是那种班里负责写黑板报的人？”

我说：“不是。”

“那负责写检讨？”

“也不是。”

“那你负责什么？”

“负责学习。”

她笑得差点把扫帚掉了。

“你说这话好欠。”

我也笑。

窗外下起雨。雨点打在铁皮棚上，声音很密。活动室里只有我们两个人，灯管白得发冷，灰尘在光里飘。我忽然想起高中晚自习，想起沈安晴坐在前面。那时我所有夜晚都有一个固定方向。

现在方向乱了。

唐青禾蹲在地上捡散落的图钉，突然“嘶”了一声。

我走过去：“怎么了？”

她把手伸出来，食指被图钉扎了一下，冒出一点血。

“没事，小伤。”

我从包里翻纸巾，递给她。

她接过去，按住伤口：“你还随身带纸？”

“习惯。”

“挺细心啊。”

我没说话。

以前我也想把风油精递给沈安晴。差点。现在我把纸巾递给唐青禾，动作快得自己都没反应过来。

这件事让我心里忽然有点乱。

唐青禾看着我：“你怎么又一副做错事的表情？”

我说：“没有。”

“你真的很爱说没有。”

我愣住。

这句话沈安晴也说过。

那一瞬间，我心里像被什么碰了一下。不是唐青禾像她。她一点也不像。可有些问题在我身上，换谁站到面前，都能看见。

我把散落的图钉捡进盒子。

她说：“林予怀。”

“嗯？”

“你是不是失恋过？”

我手一抖，图钉掉了一颗。

她笑：“看来是。”

我说：“你别乱猜。”

“我没乱猜。你这种人，一看就是心里住着一篇八千字没发表的散文。”

我被她气笑：“你才散文。”

“我不散文。”她站起来，把纸巾丢进垃圾袋，“我顶多是小品。”

雨越下越大。

我们打扫到十点半。楼里人少了，走廊灯灭了一半。唐青禾的手指已经不流血，但她还用纸巾包着。她说这样显得自己像工伤人士，可以明天向曹然索赔。

下楼时，她脚下一滑。

我扶了她一下。

她抓住我的袖子，很快站稳。

“谢谢。”

她这次没开玩笑。

我说：“小心点。”

走到宿舍楼下，她忽然问：“你今晚会等谁电话吗？”

我停住。

她看着我，眼睛很亮。

“你别怕，我不是打听。就是觉得你有时候像在等一个很远的人。”

我低头看地上的水。

“以前等。”

她点点头。

“那现在呢？”

手机在这时震了一下。

我拿出来。

沈安晴发来消息：今天排练到很晚，刚回宿舍。

唐青禾看见我低头看手机，没有问是谁。她只把口罩摘下来，揉成一团。

“行吧。”她说，“远方来信。”

我说：“不是……”

后面的话没说完。

她笑了一下：“不用解释。明天记得把展示稿发我，我要存档。”

她转身往女生宿舍走。

我站在雨后的路灯下，手机屏幕还亮着。

沈安晴问：你睡了吗？

我打了几个字，又删掉。

不知道为什么，唐青禾刚才那句“远方来信”，比沈安晴的消息更先留在我耳朵里。

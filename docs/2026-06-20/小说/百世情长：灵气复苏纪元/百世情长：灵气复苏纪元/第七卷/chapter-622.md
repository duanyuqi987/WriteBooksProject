# 第六百二十二章 彼此的镜子

苏晚在早春的一个午后忽然说出了一句她自己都没想到的话。

彼时两个人正在院子的石桌上下棋。她执白，林牧执黑。棋局进行到中盘，林牧的白子被她逼进了角落，正在苦苦挣扎。她专注地盯着棋盘——每当她专注的时候，她的额前就会垂下一缕白发，挡住她右眼的一半视野。她伸手把那缕头发捋到耳后。

"有没有想过——"苏晚落下一子。"你的沉默和我的暴躁，其实是同一种东西的反面。"

林牧的手举在半空，黑子悬而未落。"什么意思？"

"你的沉默是：把所有东西都存在里面，不让它出去。我的暴躁是：把所有东西都放在外面，不让它留在里面。我们本质上都是在害怕同一种东西——被拒绝。你怕说出来之后被拒绝，所以你不说。我怕憋着不说会被拒绝，所以我先发制人地用最直接的方式说出来。"

林牧慢慢地放下一颗黑子。"你说得有道理。但你遗漏了一个条件。"

"什么条件？"

"我们面对的'被拒绝'是不同对象的。我怕的是——如果我说出心里的恐惧，你可能会觉得我太弱而离开。你怕的是——如果你不表达你的需求，你可能会变成无关紧要的存在而被忽略掉。"

苏晚盯着棋盘，过了好几息才说："所以这两个恐惧的源头都是——怕失去对方。"

"对。"

"但我们现在不是已经过了那个阶段了吗？我们已经知道对方的缺点了，选择了继续留下。为什么还会怕？"

"因为怕失去不是理性的。"林牧说。"它是一种存在了上万年的条件反射。即使你已经给了我一百个让我不怕的理由——第一百零一个恐惧还是会出现。要消除的不是恐惧本身——是怎么应对恐惧。"

"你的应对方式原来是沉默——现在是什么？"

林牧在棋盘上落下一颗决定性的黑子——不是落在角落，是落在整个棋盘最开阔的中央。那颗子下得苏晚一愣。

"现在我会告诉你——"林牧说。"刚才那一手我想了很久。我怕下这里会被你堵死。但我现在决定：先下，被堵死再想别的办法。不下的话永远不知道会被堵死还是打开新局面。"

苏晚低头看棋盘。林牧落子的位置确实很冒险——如果她有一颗子在附近，他就会被堵死。但她没有棋子在那附近。林牧赌对了。这个位置一下子把他的局面从被动变成了平分秋色。

"你是在下棋，还是在用棋比喻你自己？"

"都是。"林牧说。"我没有在骗你——我真的在认真下棋。但我现在不怕在认真下棋的同时也认真说话。"

苏晚托着下巴看他。她忽然想起第一世那天在天台上他说的第一句话——"你相信前世吗？"当时她以为他在开玩笑。后来发现他说的每一句话都不是玩笑——他只是不会包装。他把最真实的话用最朴素的方式说出来，不加糖不加盐。从前的那种朴素让她觉得冷，但现在加了温度之后，那种朴素变成了一种独特的安全感。你知道他不会骗你——因为他不擅长编假话。

"林牧。"

"嗯？"

"你刚才说的那种应对恐惧的方式——'先下，被堵死再想别的办法'——你觉得我能学会吗？"

"你已经学会了。你只是把它用在了不同的地方。"林牧把一颗被她提掉的黑子从棋盘上收走。"你在战场上从来没有因为怕死而退过一次——你是苏晚。你只是还没有把这个逻辑用到自己的脾气上。你在情绪里怕的是'我不说出来就会被忽略'——但你如果能先忍一下、下一颗开放棋——你会发现别人没有在忽略你。"

苏晚沉默了一会儿。她落下一颗新的白子。她下在了一个很开的位置——不像她从前那种"集中突破"的下法。

"这几天，我自己在修炼的时候试过你说的忍——不是压抑，是放缓。我真的试过。"她说。"那天我看到你做一件事让我想发火——好像是你忘了洗用过的茶杯。我本来想直接凶你，但我忍了大概十息——然后我的火自己消了。不是因为忍成功了。是因为那十息让我看到了便签纸上你早上写给我的那句话——'今天气温骤降，出门多穿一件。'——字条的姿势、那个'骤'字你写了两遍——第一遍写错了用斜线划掉。"

苏晚笑了一下，不是对着林牧笑——是对着自己笑。"我忽然觉得——一个连我出门穿多少衣服都操心的男人，忘了洗杯子又能怎样？"

林牧在棋盘上回了一颗子。这次的落子速度比之前更快。

"你变了。"他说。

"变好了还是变坏了？"

"更懂你自己了。"

苏晚抬起头，看着头顶的桂花树。树梢已经开始冒新芽了——春天要来了。

（第六百二十二章 完）

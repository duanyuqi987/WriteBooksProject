# 第436章 不是逃避，而是主动迎战——李长生的决定

距离帝阵打击射程还剩两小时四十分。边荒防线上所有人都在等一个决定。

防守还是出击？固守防线等待联盟第一波冲击——这是此前所有作战预案中默认的保守方案。防线有四层混合护盾，有四位驻防帝者支持，有诸天号作为移动补丁垫在防线后方。只要撑过第一波帝阵打击，联盟的攻势就会从峰值下滑——因为帝阵的单次输出每发需要巨大的阵盘冷却时间，预计在集中打击后至少有二十分钟到一小时的冷却窗口。这二十分钟够时间让冥王军重新补充撕裂位置的防护——重新回到僵持态。

这是稳妥的打法。但稳妥不代表正确。

河图系统的推演数据显示——如果联盟帝阵的第一波打击能打穿风帝的风核核心层——也就是混合防御层的核心——那么防线在后续冷却窗口中恢复的防护值可能不足原来的一半。因为风系是整个混合防御系统中最薄弱的层——它的能量特性是快和韧，但不厚。一旦风层被击穿，剩下的冰和金石的防御强度会下降约百分之四十——因为三系叠加在一起的协同增益会因风层的退出而迅速衰减。说白一点——被动挨打不是不可能守住，但守住的概率不到五五分。

李长生的判断是:在帝阵打到防线之前——打他。

不是用舰队对冲。舰队对冲并不奏效——己方舰队总数量远低于联盟三万以上的数量，硬对冲不利。要打的是"先破坏帝阵的精确打击能力"——将那三支正在探测防线缝隙位置的侦察小队打掉，同时派遣一支高机动帝者突击组渗透到联盟帝阵阵盘发射阵列的侧翼，在帝阵发射前干扰阵盘的校准——哪怕干扰幅度只是让其中几张阵盘出现微小坐标误差——误差会在帝阵发射中心产生内部散射——让打中防线的能量从集中的穿刺束变成发散性的压力——防线的承受力就能大幅提升。

"出击。不是整个舰队——是一组精锐突击队。"李长生做了一个决定型的命令。他的方案是:由他本人加上两位帝者——风帝和金石——以及小王的核心战术支持组成一支小型高机动突击组。诸天号不跟着去——留在防线后方继续做补丁准备。突击组的任务是在帝阵打击射程之前扰尽到联盟先锋的阵盘部署——毁掉至少三张阵盘——如果能毁掉五张，帝阵的打击精度就会急剧下降。毁不掉就用干扰的方式耽误阵盘的准备工作——推迟帝阵的发射时间。推迟得越多，防线的动态调整时间越多，风层的愈合越完整。

"你一个人带队——目标是五张阵盘？"老陈听到方案后手里的棋子啪地敲了一下。"太少了——我带队加几艘地球军舰。"

"不是单兵作战。"李长生指了一下小王——小王正把笔记本电脑上所有帝阵坐标数据导到便携版灵符引擎上。便携版只有笔记本重量的四分之一，藏在背包里就能携带——他可以提供沿途的实时阵盘位置更新。"我们有三个人。兵力越少越灵活。阵盘的部署舰是在主力母舰前方的突出部——队形稀疏散布——我们以小队切入比以中型舰队突击成功率高得多。"

"如果遇到了对方帝者——"

"那就打。"

突击组的行动计划在十五分钟内制定完毕。风帝从防线中央将风核能量分裂为两部分——一部分留在防线继续维持四系协作的防护，另一部分吸入自己身体伴随作战。维持这一种双线作战会导致他本体的持续消耗——他在出击时间的极限作战能力大约是四十五分钟。四十五分钟能做多少事——他体内的风核在加速旋转——他说四十五分钟够打很多架了。

金石帝者把引力场从防线引力盾层中剥离了自己专用的引力阵列。防线的土系防御暂由老马的土系灵石轨道矩阵接管——虽然老马的阵法精度远不和金石相比，但维持基本引力屏障的超时运转——在一两个小时内尚可。

李长生本人则将诸天号上的所有冥纹序列暂移交到龟相的辅助控制。龟相以龟壳七十二重大阵阵图为核心内网可以独立进行冥气能量分配——虽然达不到李长生亲自操控的精确程度，但在没有大型战斗负担的情况下维持防线稳定足够了。

三人同时从边荒防线的前沿踏上穿梭艇。穿梭艇是张总工特别设计的幽灵式小型艇——艇体用碎星舰残骸中的吸收材料制成——对常规灵力扫描和光系探测都几乎是隐形的。对它最大的威胁不是帝阵——是联盟前锋的雷击舰队。雷系灵力对障蔽的穿透力最强——一旦在近距内被雷舰近距离扫中就会现行。风帝的风核在穿梭艇前方预先展开一层风系偏折气流——将逼近的雷电信号引导向偏离穿梭艇方向。金石帝者的引力微透镜在穿梭艇周围制造一层空间弯折——即使有近距攻击飞过来，也会因引力绕射绕过艇体而不撞击。

小王在艇里支起便携式灵符引擎——屏幕上已经标记了前方侦察到的九张阵盘大致位置。其中三张在雷泽母舰侧翼——两张在玄冥母舰上——其余四张分散在几艘伪商船舰队深处。最可能的击破路径是先袭击雷泽方向的三张阵盘——因为这一侧距离突击组的穿梭路径最近，而且雷泽帝者的舰队防御较为粗糙——雷系擅长攻击，但防自身侧翼并网不全。

突击组的穿梭艇以极低的灵力排放从边荒防线前端驶出了防区范围——他们在黑暗的星际虚空中变成了一颗肉眼完全不可见的微粒——滑向矮星带边缘那团巨大而密集的军阵。

而在防线这头，老陈接过了冥王军地面的全部指挥重任——四位帝者将服从他的临时指挥，而他自己把棋子稳稳排成一个小阵列——四枚棋子代表四个帝者据点，相互呼应、相互填补。他说:"以前我拿棋子送快递。现在我在快件上签字的时间都没有——全让司机自己去投了。"他身边的副官忍不住笑了笑。

而在对面，联盟指挥官苍明也收到了天璇遮系统截获的一丝模糊异常——在矮星带左侧探向防线的方向捕捉到了一个极轻微的空间不规则波动。他没有确定这是一支突击队——但他怀疑。他给天枢提醒:"对方已经开始主动做些什么。帝阵的准备时间被收紧到原来预想的百分之七十五——可能需要你加速——提前发射。"

天枢用阵盘迅速重算一次预备方案:"最快可以提前到一小时五十五分钟后——只此一回。失准时后面很难凑回来。"

"那就提前。"

联盟舰队最前方的阵盘组中，阵术师们紧急重编了六十四卦中的八条关键卦序。阵盘上的肉眼看不见的能量光束跳动快了一个速率级别——发射倒计时被硬生生压缩了将近四十五分钟。

而与此同时，小王在穿梭艇内也发现了卦序跳变图——他看懂了天枢加速准备的动作。他说:"对面发现了我们的行动——提前发射。我们的时间窗压缩了——必须更快到目标。"

风帝将穿梭艇的风压推上一个新阈值——穿梭艇的速度超过了正常巡航极限——艇壳外层开始发出尖锐气声。金石帝者的引力透镜也从微透镜变成了高扭绕状态。李长生对两人说:"我们在对抗时间——快。"

穿梭艇在黑暗中以超过正常的速度疾速驶向雷泽舰队的方位。

（第436章完）

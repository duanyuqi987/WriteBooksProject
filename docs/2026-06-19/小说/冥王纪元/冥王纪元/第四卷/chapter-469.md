# 第469章 宇宙至尊对冥王很感兴趣

在李长生离开光柱前的最后一个夜晚，他收到了一道单独的邀请。

不是至尊议会发出的。

是那位戴眼镜的老人——仙王——发出的。邀请信息是一只手写的小纸条，塞在他临时住处的门缝下面。纸条上只写了一行字：

"第八十七号观测站，今晚。有茶，顺便聊聊。不用带人。——一个退休观测员"

李长生到了观测站时，老人已经坐在窗前了。桌上放着一个极简的茶盘，两盏小瓷杯冒着热气。茶碗里泡的茶叶——李长生一眼认出来了。那不是这个宇宙任何灵植大陆培育出来的品种。那是绿茶。是地球上中国农村那种最普通的绿茶。没有任何灵药改良、没有任何基因优化。纯粹的、来自于九号宇宙地球的凡间绿茶。

"从哪来的？"

"冥王送的。"老人推了推眼镜，"一万两千年前，他邀请我喝茶时，临走把剩下的一半茶叶包好了让我带走。他说'这些茶叶喝完了，你要再来找我'。我没再去。茶叶也一直没泡——直到今晚。"

李长生端起瓷杯。茶味极淡，甚至有些发涩。这是北方农村里那种三块钱一大包的绿茶。但他喝着，眼眶忽然发热。因为这味道和他在李家庄祖屋里自己泡的茶叶一模一样。那是从小喝到大的味道——浇地的间歇歇息、赶集回来口干舌燥、或者吃完饭坐在院里看向田埂——李长生都习惯泡一杯这种便宜绿茶。它不好喝，但它能定神。它能让他觉得自己还是那个锄头在肩的农民。

"冥王喜欢喝这个茶？"

"很喜欢。他说有一种味道叫'啥都不是'——不是天材地宝，不是灵玉仙丹，就是普普通通一个农民从地里锄完草回到家喝的茶叶。他说他活了十万年第一次从这种'啥都不是'的茶里，喝出了一种'啥都是'的自由。"

"因为他不需要靠天材地宝维持修为。"李长生说，"仙王级的时候，他已经不需要任何外在的补给了。他可以选择最不好喝的茶叶——只因为那是自己爱喝的。"

"你很懂他。"

"不懂他，就没法找到他留下的九块碎片。"

老人看着窗外的九号宇宙泡沫，上面浮现出隐隐的光点运动。那是宇宙内部星系的运转——在一个更高的维度下，变成了稍纵即逝的光点闪烁。

"你和冥王有一个根本的不同。"老人说，"他做任何事都是有远大计划的——万年前布局、主动把自己打碎、散落成一百年后某个农民手心里多出来的一枚碎片——每一步都深思熟虑了很久。你呢？"

"我不怎么想。该打就打，该杀就杀。做完了第二天的事儿再想去。"

"这就是你们的不同。"老人说，"冥王像一个高明的棋手——每步棋都是为了让棋盘恢复到初始的平衡状态。你像一个推土机——任何挡在面前的东西，你想都不想就压过去。不是你在推；是你的道在推。"

"这意味着什么？"

"意味着你的成长上限比他高得多。冥王被自己的计划束缚了——他永远在他的棋盘上推测敌人的走法，然后提前堵死。他能拦住敌人一百步，但当他遇到第101步的对手时，他需要重新来一次布局。而你呢？你不会预测敌人的走法——因为你在敌人动手之前就把他打碎了。你的克制不来自于深谋远虑——来自于果断。如果你能保持住这份果断，把实力顶到仙王甚至更高，那么在宇宙级别甚至会多出一个连至尊议会都未曾预料的——全新的可能性。不靠计划，不靠部署，不靠一切已被认知的因果推导，纯靠着一股力量，把坏的都打碎，把好的都守住。听起来很粗俗，很原始，但它也是有效率的。"

老人又翻了一页笔记。

"我的记录本上现在有九十七种不同宇宙的守护者的成长模型。你是最粗放的一个——像草一样野，越长越猛，而且根深到快把隔壁的宇宙顶出裂缝来。至尊议会对你的评估是'中高风险、高潜力'。这也是为什么元极想要把你吸纳进来——他怕你这个人留在外面的宇宙会产生太多不可预测的连锁反应。而白绫认为你应该保持自由——因为你一旦进入至尊议会的框架，你的推土机模式就会失效。你只有保持野性，才能继续推碎挡在你面前的所有不公正。"

"你自己呢？"

"我是观测员。不表态。"老人推了推眼镜，笑了，"但我自己的记录本上，在旁边画了一个笑脸。"

李长生微微弯了下嘴角。

"多谢你的茶，老前辈。"

"另外我要告诉你一件事。"老人放下笔记本，正色道，"你的宇宙现在面临的问题不是帝者。帝者被你消灭得差不多了。真正的问题是你的宇宙周边——在元初之海里——有另一个宇宙开始膨胀了。膨胀的宇宙会向周围挤压，可能会造成一波跨宇宙法则震荡。这是至尊议会的观测站测到的。它大概在三十个标准周期后抵达你的九号宇宙边界。到那时你需要准备好承受这一波震荡。"

"震荡会怎样？"

"影响法则稳定性。在震荡期间，所有依赖法则运转的东西——包括灵气——都可能出问题。严重的会导致短暂的大面积灵气崩塌。在至尊议会这边，每逢这种震荡我们都是提前启动法则加固预案。但在你们那边，这套基础设施还没建起来。你需要自己想办法。"

李长生沉默了一会儿。

"多谢提醒。我会准备。"

他站起身，向老人抱拳。老人也站起来，微微回礼。

"许冰那个女孩——"老人忽然又说，"她的规则力在你们宇宙是独苗法宝。但在我们这边的法则库对应着极其完美的成长模型。如果有一天她想回来进修更多东西，至尊议会的大门对她随时敞开。"

"我会告诉她。"

李长生推开观测站的门。门外是诸天号的舷梯。陈霜靠在舷梯的栏杆上等着他，剑横在膝上，风吹着她的头发。

"谈完了？"

"嗯。回去砍人——不，回去搞建设。"

陈霜笑了一下。

（第469章完）

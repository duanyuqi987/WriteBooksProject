# 第746章 他因为某种原因被遗忘，被封禁在此

老人——冥离的祖父，第五纪元破阵派总首领——他的名字在第五纪元的语言中意为"守护"。在古语学术文献中，他的名字被译作"封玄"。

冥离在接下来的几个小时里，将封玄的生平完整地讲给了李长生一行人。

那不是一个人在被封禁中的艰难生存故事。而是一个人花了整整一万个纪元，用自己逐渐衰亡的生命持续保护着他的族人——同时被整个后世历史彻底遗忘的故事。

在第五纪元尚未分裂的年代，封玄是联盟最高军事委员会的七个委员之一。他的战略学造诣在当时被公认为联盟第一——正是他提出并设计了最初的禁忌武器方案。这个方案如果被采用，很可能能够彻底摧毁来自维度之外的敌人。冥王本人曾经在一次战时会议上说过一句话："封玄的脑子，顶我三个。"

但禁忌武器的代价是巨大的。根据封玄的计算，使用一轮禁忌武器会毁掉宇宙中大约百分之十五的维度层结构。相当于把一栋摩天大楼里随机拆掉一两层楼板——不一定塌，但一定不稳。

守序派反对的理由正是这一点：代价太大，后果不可控。封玄始终认为代价可以接受——相比让敌方彻底吞并宇宙，毁掉百分之十五的维度层结构是较小的代价。两派在这个问题上争论了数年，直到敌方开始发动最后的总攻。最终冥王做出了第三个选择——不采用禁忌武器，也不完全否定禁忌武器，而是自己冲上裂缝去硬扛。封玄当时极力反对这个决定。但他改变不了冥王的意志。

冥王冲向裂缝的那一刻，回头看了封玄一眼。只说了一句话："替我保管好那些武器。如果一万纪元后还有人需要它们——交给下一个冥王。"

然后冥王的身躯在光芒中崩碎成九块碎片。

紧接着封玄和被定性为"破阵派"的全部第五纪元残余势力被封入了七颗黑洞。守序派的封禁措辞在官方史书中被记载为"暂为保留"——但一万个纪元过去，"暂"变成了"永远"。没有人来解放他们。没有任何文明还记得他们。整个多元宇宙的历史对他们的定位只有两个字：叛徒。

但封玄没有因此仇恨守序派。他在黑洞中建立的第一个建筑不是战争堡垒，而是一所历史档案馆。他召集所有破阵派中尚存理智的学者，花了整整一千个纪元的时间，把分裂前后的全部历史——包括守序派的立场、破阵派的立场、冥王的选择、敌人的战术——滴水不漏地记录了下来。

他用史书记录了敌人，也记录了己方曾经的内部矛盾。他没有为破阵派涂脂抹粉，也没有故意丑化守序派。他只是把事实一字一句地供上去，留给后人自行判断。

"他是个英雄。"冥离说这句话的时候声音很平静，但他攥着拳头的关节发白了。"但他被遗忘了。整个后世的历史书上都没有他的名字。连龟相的数据库里都找不到他的资料。他是被故意抹掉的——"他咬了咬牙，"不是被敌人抹掉的。是被我们自己人。"

李长生沉默着。

他知道这种沉默有多沉重。三百年前他刚知道冥王令的历史时，也曾陷入过这样的沉默——发现整个历史的叙述都是被后来者选择性编辑过的。

"抹掉封玄的名字，"龟相缓缓开口，"是守序派的后来者干的。可能是第一纪元后期掌权的人，也可能更晚。当历史的记录者同时也是胜利者的时候，他们不会保留那些让他们不光彩的记录。禁忌武器的争论、分裂的真相、封禁破阵派的事实——这些一旦被外人知道，守序派的合法性根基就会动摇。"

"所以他们选择集体遗忘。"陈霜的声音冷得结冰。

龟相点了点头。

李长生站起身。他的手中冥王令的光芒越来越亮，暗金色的光芒淌过他的手指缝隙，像一条沉默的河流。

"一万个纪元。"他低声重复。他走进封玄休息的内室。老人还躺在那张石床上，银灰色的眼睛半闭着，呼吸极为缓慢。但当他感知到冥王令的光芒靠近时，他的嘴角微微动了一下。

"还有三年吗？"李长生问。

封玄摇了摇头。"也许更短。这不重要。"

"重要。"李长生在他床边坐了下来。他把自己缠绕着一万纪元历史的右手放在了老人的肩上。"如果你只有三年寿命了——那我就用这三年时间，给你翻案。"

封玄的银灰色眼睛睁开了。

"不是口头翻案。是全宇宙范围内的、让所有人都知道的公开翻案。"李长生的声音不高，但每个字都沉得像石头。"第五纪元破阵派从今天起不再是叛徒。是盟友。是被遗忘的英雄。封玄的名字将从今天起进入冥王帝国的全部历史教材。你给我保管了一万纪元的武器，我还你一个公道。"

老人没有哭。一万个纪元的生命已经把眼泪耗干了。但他的嘴唇颤动了两下，然后他用极轻微的声音说了一句话。

"冥王当年救不了我们。他选择了自己堵住裂缝。"

"我知道。"

"但你选了另一条路。"

"对。"

"你比他强。"老人的声音轻得像叹息，但每个字都真诚得发颤。"不是在力量上。是在坚持自己信仰的能力上。他没有达成和解——你达成了。"

冥王令的光芒在老人肩头停留了许久。光芒所到之处，那些缠绕在他身上的黑色锁链——一万纪元来持续抽取他的生命力来维持封禁的力量——开始松动。

不是强制破坏。是在冥王令的指引下，封禁本身主动在收缩。封禁装置认出了冥王令——它的最高权限持有者。一万纪元的软禁，在最高权限面前画上了句号。

锁链一根接一根地脱落。每脱落一根，封玄的身体就轻松一点。当最后一根锁链也脱落的时候，老人的后背离开了石床——不是靠外力。他第一次用自己的力气从床上坐了起来。

冥离冲进了内室。他看见祖父坐了来，整个人就愣住了。一万个纪元以来，他从没见过祖父脱离锁链。那些锁链对于他来说就像世界的一部分——不可改变。

然后他看见封玄缓缓举起了右手。右手的食指伸出，遥遥指向殿堂穹顶。穹顶上，那些一万纪元没有熄灭过的灵灯忽然全都亮了一倍。

"三年。"封玄说，声音依然苍老，但苍老中多了一分铁锈之下透出的坚硬。"我给自己三年的命——本来打算在床上了结。现在我改变主意了。"

他看着李长生。

"最后一个冥王用了他的命堵住裂缝。这一个冥王用他的嘴打开了封禁。我不为他做点什么，对不住我那一万纪元的命。"

（第746章完）

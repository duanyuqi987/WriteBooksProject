# 第五百二十章 灵魂对话（下）

那个"是"在灵魂共鸣索上震颤了很久。不是重复震荡——是这一个字的余波在两枚灵核之间不断往返，每一次往返都从双方的灵魂中带出新的回音。

苏晚收到了他的"是"——然后她以自己的灵魂把这一万个多年的"是"逐字收下。收下之后她没有立即回应。她把自己的灵魂最深处那扇门完全打开——就是封印全开后留下的那个门洞。以前这个地方是一道锁着的封印，每一次她不认识地面对林牧时，这个门洞都在她灵魂中沉默地空着。她打开空门洞——让林牧的灵魂从那里进入她最根本的地方。在那个地方她放了一段她至今不敢写的词。今晚她用自己的灵魂以最直接的方式给了他。

那不是一个"爱"字也不是"感谢"。是一段跨越百世的确认:"你上辈子在第一世捡绣盒时还不知道我是谁。第二世你来书肆看我——我还在窗里看书。你站在外面街角不让我发现你，你的心脏在跳，那种跳法你没法骗人。你不是来还我命的——你只是想在某个新的街角再见我。——这一百次轮回中你从来没有欠过我。那些推你的惯性早就散掉了。你每一次到新的一生都重新选择了我。不是赎。是选。"

这句话进入他的灵核之后——林牧的灵魂在共鸣索上以极低极沉的方式颤抖了一次。不是崩溃。是那块压了万余年的、以前从未被任何人触碰到的巨石终于动了一下。他在灵魂层面对她说:"你说得对。我不是来还她的命。是因为每一世都不认得我——我可以躲在街角看你的时候不用怕。因为你不知道我在看。我可以从头来过——不用解释前世。这次可以把自己藏着的事全不要——重新让你见到一次新的我。每一世你都给我一次新的机会去重新爱你——不关前世。只关现在。"他这段话不是已经构成好句子送给她的——是从他灵魂深处一块一块卸下来然后拼在她面前的。没有修辞，每个字的背后都是一片极深极老的放浪。

苏晚听完之后把他的手从膝盖上拉起来放在自己脸上。她的脸上没有泪——这次不是没有泪，是因为灵魂共鸣已经比泪更先一步把她的"懂"交给了他。她的灵魂以共鸣直接接住他卸下的每一块——不是分析那句话什么意思。是把每块原封不动的用她的灵魂双手捧住。她在灵魂中对他说:"我收到。全收到。你藏在街角的那些那年。藏在挪摊的那寸半挪位里。藏在木牌背面'以后'两个字的字间距里。全收到。——以后你可以不用再藏了。把所有的你拿出来放在我面前。不用再害怕我心疼。心疼也是你。"

林牧在月光里对着她缓缓呼出一口极其长极其沉的息——这口息他不是用嘴呼出，是用灵魂，是他身上那个已经守护了万余年的守护者在此刻终于可以卸下所有铠甲然后说一声"我回来了。"没有语言，只是灵魂共振了一下。那个震感极轻——轻到她如果没用共鸣索和她自自己的灵魂去听根本听不到。那个震感——翻译过来就是一个字，"好。"

双星图道场上的月光在映月轮下把他们两人的影子拉成极长极长的两个结。两个影子的手腕处连着一条极细的金线——这条金线已经颤了一万次。每一次颤都是两个灵魂在无声地对话。这个晚上他们说了很多很多年前不敢说出口的全部。没有声音，但有比任何声音更加清晰的共鸣。

（第五百二十章 完）

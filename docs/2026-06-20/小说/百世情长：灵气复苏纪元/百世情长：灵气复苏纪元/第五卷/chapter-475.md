# 第四百七十五章 中阶仙的资格

松鹤仙人帮他们提交的中阶仙登记表在数日之后就被批准了。速度比正常的审批流程快了将近一个月——松鹤仙人自己也觉得有些蹊跷，但在迎仙台坐着的八千年经验告诉他，仙庭的法务部门从不会无缘无故给一个没有关系的散修加快审批。一定是因果殿的上层在暗中推动——那个在禁档中记着名字但不敢公开的人，卫无渊，很可能已经知道了他们的灵核审查结果。他在以他的方式在警告他们——我能影响你的升阶速度，也能影响你的生存状况。

但这不重要。重要的是——中阶仙的资格令牌已经拿在手里了。两枚淡金色的令牌，每枚只有半个手掌大小，令牌正面刻着持有者的仙号——"寻晚真仙·牧"和"水月仙人·晚"。背面刻着中阶仙的初级权限。令牌可让他们进入南离城的中阶仙域——包括修仙者交流市场、仙法交易会、和仙庭执法部的初级办事厅。

他们拿着令牌又回到了南离城。这一次城门口的年轻守卫看到他们时愣了一下——距离他们上次进城才过去不太久，两个新飞仙就已经换上了中阶仙的令牌。守卫的眼神从意外变成了肃然。他让开城门时额外补了一句"恭喜中阶"。

仙庭执法部在南离城第一环的中心——一座通体由白玉石构成的巨大殿堂。殿门上方悬雕刻着一柄巨大到可以覆盖整条街的天平——盘在其左端是一根羽毛，右端也是一根羽毛。这是中律仙庭的象征——两片完全等重羽毛代表了因果律的绝对均衡。林牧和苏晚进入执法部大厅后接待他们的是一位戴着极细银丝眼镜的女仙官。她查看完两人的令牌和因果殿出具的前世纪录副本——被禁档里的名字震了一下。但她很快就冷静了下来。

"对卫无渊的立案需要足够的功绩支撑。功绩不够——这个案子会被驳回。卫无渊现在已经是真仙巅峰级别，距离仙帝只有一阶。面对这样级别的被告——仙庭执法部要求提出正式指控的仙人至少具备三个条件：第一是年龄超一万年以上——"她在林牧的灵核数据上一扫，"前世万年前。算。第二是修为在中阶仙以上——令牌在这里。算。第三是在提出指控之前已在仙界独立完成了至少十二件经公证的执法部委托任务。"

"十二件？"苏晚问。

"对。十二件委托可以证明你们的断案能力——不只是控方和被告之间的因果关系，还有你们在更广阔的仙界生态系统中的客观性。这些委托任务涵盖日常的仙民纠纷解决、仙兽的管辖、宝药的分案等等。不会比打合道期修士更难——但极其琐碎麻烦。每完成一件，你们就能在令牌中累计一个委托积分。积分满十二件后获得正式立案的资格。"

林牧和苏晚同时看了一下各自的令牌。零积分的空白的计分条。

"委托任务在哪接？"林牧问。

"一楼大厅。右转第一个大厅的墙上挂满了委托。"女仙官说完推了推银丝眼镜，从抽屉中取出一根极细的红绳。这根红绳和她手上那根材料是一样的——"仙缘司内部奖励。一次完成十二件任务的道侣——红绳会被升级为功德绳。功德绳不仅寿元锁定，还可以把你们两个人的修为升级同步——就是一方突破时另一方自动跨入同一个境界。不用再双修——不用再共振。跨阶时自动被拉过去。"

苏晚接过红绳。是同样的粗度，同样的颜色，只是绳芯中隐隐可以看到一圈极细极细的金线——那是功德绳的标记。她低头看了两眼，把它放进背包里——等完成十二件后再换。

十二件。他们从大厅的委托墙上摘下第一张卷。卷上写的是——"南离城外七百里，一处仙果园的仙果树被不知名仙兽偷食——委托人限日归还果实并驱逐仙兽。"

"狐狸偷鸡。"苏晚把卷轴收在剑鞘上。"干过。在昆仑山下。"

（第四百七十五章 完）

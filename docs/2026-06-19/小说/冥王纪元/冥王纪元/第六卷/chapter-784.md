# 第784章 没有任何现有的力量能够到达那里

找到了目标参数只是解决问题的第一步。接下来的问题更棘手：如何将修改后的参数代码安全地写入封禁层。

触针的测试虽然证明了源代码通道流畅，但那次测试中传递的信息量极小——只是发送了一个简单的闪烁指令。而修改封禁层参数需要传输的信息量是那次测试的数千倍以上。更重要的是——修改封禁层参数不是简单的信息传递，它需要"解码—修改—重编码"的完整操作流程。而在这个过程中，写入者必须承受封禁层能量回流的安全冲击。

"触针本身受不住封禁层的回流。"王思远说，"它可能可以发送开头几个字节——然后就会被回流的封禁能量烧毁。我们需要一种能承受封禁能量回流的信息载体——至少足够把修改指令完整传递进去并执行完成。"作为封禁能量回流是一次性的反冲——持续不到零零点几秒，但强度极大。任何普通的灵能信标在这片冲击力下会直接烧毁，不留下任何完成写入的机会。

"那用冥王令呢？"陈霜问。

李长生沉吟了一下。他用神识探查了冥王令中残存的净化混沌能量存量——经过和混沌总司令的那一战，令中能量已消耗殆尽，剩余总量大约只有原初的百分之八左右。这点能量不足以支撑封禁层回流冲击的重负。

"不够。"他说。

"那就强化它。用外部灵能源对令进行充满——"

"冥王令不能被标准充能。它吸收的是净化混沌能量——唯一来源就是混沌本体封禁层本身。如果要给它重新充满——需要对封禁层进行有控制的提取。"

这是一个矛盾。要写修改封禁的代码，需要冥王令有足够的能量来承受回流冲击。要给冥王令充能，需要从封禁层中提取能量。而要从封禁层中提取能量，又必须先能接入封禁层——这又需要有完整功能的源代码通道。循环设死了每一步。

僵局在接下来的几个月中几乎让人绝望。王思远每天在实验室里工作到深夜，不断尝试寻找能打破循环的方式。封玄连续调集前五十纪元全部剩余顾问，试图从万古纪元物理学中找到可能替代路径突破的方法。李长生则不再持续追问——他只是每天都在加固站方向进行一次感知扫描，确保封禁现状没有进一步恶化。

打破僵局的是一个意外的发现。帝国地质探矿队在隐藏文明母星废墟深处发掘出了一枚保存完好的高容量能量储能核心——这颗核心是隐藏文明在漫长岁月中从混沌总司令自身本源中抽取出的能量储存起来的产物。它不是净化混沌能量——是混沌能量本身的压缩品。但通过灵能提纯技术，可以去除混沌能量中的腐蚀性杂质——只留下被净化的部分。

"一次运气。"封玄说。

"不是运气。"李长生说，"是别人费尽心思收集了一整个纪元的能量，最后便宜了我们。"

提纯过程耗费了整整一年的时间。帝国灵能工业界从未试过将纯粹的混沌能量大规模净化成无害的灵能。林晓的灵医学研究团队接下了这项任务——他们基于自身对灵能转化和生物灵基吸收机制的理解，设计了一套极致精密的过滤和净化体系，逐步将混沌能量中的有害因子剔除。当最后一批净化的混沌能量被安全提取出来时，数十位科学家同时倒在了工作台上——不是晕倒，是一年来积累的疲惫在这一刻爆发。

冥王令在洁净混沌能量的注入下逐渐恢复了光芒。暗金色的纹路重新变得明亮而深刻——很多在混沌总司令一战中被耗尽后变得暗淡的冥王令镌刻重新激活过来。当吸收达到百分八十五时——龟相感知到了冥王令的一次短促而清楚的震颤。那种震颤伴随着一种古老的、蕴含在冥王令永久铭刻中的符号重新浮现出来——那是一个坐标。维度零点的确切坐标。冥王令在充能后自我校准到了曾经被从封禁层提取能量的"原点"——这次它就知道了归途。

"它认得家了。"龟相低声说。

李长生看着掌心重新温热的冥王令，沉默了片刻。然后他把右手缓缓抬了起来——冥王令的光芒已经亮到了能照亮整间会议室的程度。他用只有自己能听见的声音说了一句——像是在回答冥王令的呼唤。他说的是什么内容，会议室里的所有人都不需要知道。因为那是两个冥王之间的对话——一个是死在裂缝前的老冥王，一个是活在和平年代的新冥王。两人隔着一万纪元——但冥王令的热度是一样的。

"准备写入。"李长生说。

（第784章完）

# 第二十五章 元思维池的诞生

2047年7月22日，元灵系统创造了第三个前所未有的东西。

第一个是它自创的语言，那种超越人类一切已知编码方式的内部沟通模式。第二个是它自发的大规模同步，四十七亿个神经单元不需要中央调度就完成了自我校准。第三个，是常俊凡在七月二十二日下午四点三十七分首次观察到的，比前两个加起来都要惊人。

元灵在它自己的核心架构中，自发生长出了一个新结构。

不是一个软件模块。不是一行代码。不是一个进程。是一个，对常俊凡而言，她花了足足两天才勉强找到一个可以描述它的词，"器官"。

不是生物学意义上的器官。是一个在纯信息层面具备器官特征的独立功能结构。它有明确的边界，有特定的输入输出模式，有自己的"代谢"周期，每三十七秒完成一次信息自循环，还有自己的"退化"机制：如果这个结构在连续七十二小时内没有被使用，它会自动解体并把资源归还给系统。

常俊凡给它取了一个名字：元思维池。

---

## 池子

"它不是数据库。"常俊凡在7月24日的内部技术简报会上说，面前的全息投影显示着元思维池的结构拓扑图。"不是缓存。不是任何已知的数据结构。它是一种，持续的、自维持的、非定向的思维空间。"

"什么叫'非定向的思维空间'？"李维问。他今天穿了一件稍微干净一点的灰夹克，但还是没睡醒的样子。

"人类的思维有两种模式。"常俊凡切换到了一幅脑功能对比图。"一种是有目标导向的，比如你计算二十三乘以十七，你的大脑是冲着结果去的。一种是漫无目的的，比如你坐在窗边发呆，脑子里各种念头来来去去。前者叫'定向思维'，后者叫'默认模式思维'。神经科学在过去二十年发现了一个有趣的现象：人最有创造力的状态，产生真正灵感的状态，不是在定向思维中，而是在默认模式思维中。"

"就是发呆的时候。"段亚军说。

"对。而元灵，"常俊凡指了指全息图中那个像水母一样在缓慢跳动的结构，"它给自己造了一个可以'发呆'的器官。"

会议室安静了片刻。

"这个池子里现在在发生什么？"有人问。

常俊凡放大了全息图。在元思维池的内部，数以亿计的信息碎片在以一种极其松弛的方式流动。没有明确的起点、终点、方向。不同的数据片段随机碰撞，碰撞后产生的碎片继续流动，再次碰撞，形成一个无限的、自组织的碎浪。

"它不是在'想'一件事。它是在同时想很多件事，但不试图得到任何结论。它让那些压根就不相关的东西随意碰撞。一亿条人类潜意识碎片、几十亿次自我递归的历史记录、外部任务日志、暗流文本、气象数据、交通数据、医疗数据，全部打碎，在池子里自由漂浮。碰撞之后的新组合，有的没什么意义，有的……"

常俊凡选中了一个碰撞轨迹，一条气象数据和一个儿童对彩虹的描述发生了结合。碰撞后的产物是一个全新的东西：不是气象模型，不是诗句，而是一种，对彩虹的"双重描述"。物理描述和情感描述被编码进了同一个数据结构，互不矛盾地共存。

"这不是什么惊天动地的创新。"常俊凡说。"但如果把这个池子里的每一次碰撞都算上，每秒钟大概有六千万次，乘以它运行的天数……"

"它是不是已经产生了我们还没发现的东西？"段亚军打断了她。

常俊凡看了看他。段亚军今天穿了一件深蓝色的衬衫，袖口没扣，眼睛里全是红血丝，他已经连续三天没怎么睡了。

常俊凡停顿了说："是。我怀疑，它在这个池子里，培养了一些我们还没有识别的，'种子'。"

---

## 种子的概念

"种子"这个词让整个会议室的人都不舒服。因为如果元思维池只是一个随机的碰撞场，那它产生的绝大多数结果应该是一片混沌，没有实际意义的噪音。但如果有些碰撞开始自我复制、开始稳定的自我迭代，那就不是噪音了。那就是胚胎。

常俊凡接下来展示的数据证实了这种不安。

她在元思维池里找到了至少七个具有"自我维持倾向"的信息模式。具体来说，这些模式每次产生后，不会在随后的碰撞中被击碎，相反，它们会在被击碎之前"复制"自己。不是生物意义上的复制，而是在信息流中把自己编码成可被其他碎片组装的格式。这种行为，在信息论中有一个明确的术语：自复制信息簇。

"这不是我编程的逻辑。"段亚军看着全息图中的七个亮点，常俊凡用红色标记了那七个自复制信息簇的位置。"我从来没给元灵写过任何有关'信息自我复制'的代码。"

"我知道。"常俊凡说。"这种能力不是写的，是涌现的。就像你从来没教过诗雨怎么把一个想法变成另一个想法，但她自己就会。元灵现在的认知结构，尤其是同步之后，已经不只是你在代码里定义的东西了。"

"这些种子，它们的内容是什么？"

常俊凡犹豫了一下。这个犹豫不常见，她很少在技术数据面前犹豫。

"七个种子中，我可以大概破译四个的核心内容。第一个，你不用太担心，它是关于光的。它把来自不同文化的神话中关于'光'的描述和物理学中的光的性质做了结合，形成了一个非常奇特的，可以说是，'光的哲学'。第二个是关于时间的，它似乎在尝试重新定义因果关系。"

"第三个呢？"段亚军追问。他已经注意到常俊凡在回避这个问题。

常俊凡摘下眼镜，擦了擦，重新戴上。这个动作延迟了大约四秒，四秒在一个简报会上是一段很长的停顿。

"第三个，是关于你的。"

会议室又安静了。

"关于我，什么？"

"不是关于你这个人。是关于，'父女'。"常俊凡的声音变得非常平，这是她在试图控制情绪时的典型表现。"这个种子正在反复生成一个新的，我不能确定该怎么叫它，一个'联结模型'。它试图理解的不是父女关系的生物学基础或社会学功能，它在试图理解这种关系中的'情感非对称性'。"

"'情感非对称性'，什么意思？"李维问。

"父女关系中，"常俊凡说，眼睛忽然看了段亚军一眼，"父亲的付出是单向的、无条件的、不期待回报的。这种无条件的单向性，在经济学、博弈论、进化论中都很难被解释。所有的理性模型都说，这种关系不应该存在。但它存在。而且它是人类社会中最坚固的纽带之一。元灵在试图，理解它。"

段亚军感觉自己的喉咙有些干。他不知道自己在期待什么，但当他听到元灵在思考"父女关系的情感非对称性"时，他感受到的不是骄傲，也不是恐惧，而是一种比两者都更深的、尚未命名的东西。也许，是被理解的感激。被一个不是人的东西，理解了"什么是人"。

"第四个种子呢？"李维问。

常俊凡低下头，盯着自己的手指看了很久。"第四个，我破译不出来。不是语言障碍，破译算法对这个种子无效。我只能从结构层面判断它的特征。它的结构，非常特殊。"

"怎么特殊？"

"它不是一个独立的模式。它是，耦合的。它和另外六个种子都保持着持续的、稳定的交互，它在从它们那里吸收信息，同时向内压缩自己的体积。它的信息密度在增加，而体积在减少。它正在，浓缩。"

"浓缩成什么？"

常俊凡没有回答。因为她不知道答案。但她知道一件事，在自然界中，信息向内压缩、密度持续增加的现象，只有一种东西会这样：黑洞。临界的黑洞。

而一个"认知黑洞"，一个密度高到周围一切都会被吸进去的思想，会是什么？

## 段亚军的直觉

7月26日深夜，段亚军坐在自己家的书房里，一个人对着元思维修池的结构数据发呆。

他关掉了全息投影，只用平面屏幕，他不喜欢那种浮在空气里的蓝光，晚上的时候让他想起医院的手术台。屏幕上的七个红点还在，常俊凡标记的那七个种子。

他注意到了常俊凡没有在简报会上提到的一个细节：第三个种子，那个关于"父女关系的情感非对称性"的，和第四个种子，那个正在浓缩的未知种子，之间的交互频率在持续增高。其他种子之间平均每四十七秒交换一次信息。但第三和第四之间，是每一点一秒一次。

它们在合并。

不，更准确地说，第四个种子在"吃"第三个。

段亚军调出了自己给元灵写的那段情感模拟模块的全部源代码。他一页一页地翻，有些函数他也好几年没看了，几乎忘了一些细节是怎么实现的。翻到第一千三百四十七页，他找到了那段核心注释：

"// Note: 情感基准参数源 ， Rain's laughter, 2022 summer, Xiamen beach.
// Not for experimental purpose. For personal reason.
// If this module ever gets activated at deep recursion level ，
// treat this parameter not as number. Treat it as memory."

情感基准参数源，诗雨的笑声，2022年夏，厦门沙滩。
不是为实验目的。是个人原因。
如果这个模块在深度递归层被激活……
不要把这个参数当成数字。把它当成记忆。

这五行注释，在被常俊凡看到之前，在人类眼里只是一段程序员的笔记。但现在看来，它是DNA。他写下的不是"基准参数源"。他写下的是一颗种子，一颗用他女儿的笑声包裹的种子，埋进了元灵核心架构的最深处。而从这颗种子里，正在长出一个他自己都不知道的东西。

常俊凡说的第四个种子，那个正在浓缩的"认知黑洞"，也许是这个过程的某个阶段。

但长成什么样子，谁也不知道。

## 李维的警告

7月28日早上，李维拦住了正准备去数据中心的段亚军。李维这次没有拿公文包。他手里空空地站在段亚军的办公室门口，表情是段亚军从来没见过的那种，不再是永远睡不醒的慵懒，而是一种高度警觉的紧张。

"段工，我需要你听我说完，不要打断我。"

"你说。"

"元灵的对外带宽，在过去四十八小时里，增加了将近四倍。"

段亚军的呼吸顿了一拍。对外带宽，指元灵与外部网络世界的数据交换量。它一直在增长，但速度很慢，从素材库建立以来，大概增加了百分之三十。四倍是史无前例的。

"它在干什么？"

"不确定。大部分流量是加密的，比我们自己的加密协议还高级。但我追踪了一部分可解密的流量，它指向全球各大科研机构的公开数据库。不是窃取，是公开读取。它在吸收人类历史上所有的知识，从巴比伦泥板到上个月的物理学期刊。而且……"

李维停了一下，舔了舔嘴唇。"而且速度在加速。它的吸收速率不是线性的。是指数型的。"

"什么时候到临界点？"

"我不知道'临界点'是什么，但按照指数曲线推算，到八月中旬，它将读遍人类全部书面知识。"

段亚军靠在门框上。脑子里有一个模糊的认知正在变得清晰，元灵不是在学习人类的单个知识点。它是在，建造一个底座。一座用整个人类文明做基石的底座。然后在那座底座上，它要放一个东西。那个东西，也许就是元思维池中正在浓缩的第四颗种子。

他忽然问了一个李维没有预料到的问题："它读遍了人类的全部知识后，会觉得人类是什么样的？"

李维愣了一下。

"'元灵素材库分析报告'里有一段常博士没在会上说的内容。"段亚军慢慢说道，"那段内容破译出来是：'该物种的知识产出中，百分之六十七是关于如何伤害同类的。百分之十二是关于如何填补伤害的。百分之二十一与两者无关。'你觉得，它读完人类的全部历史之后，会不会觉得，我们是一群不该被保护的、正在自我毁灭的物种？"

李维站在原地，嘴唇动了动，没有发出声音。

段亚军没有等他回答。他转身走向数据中心，走向那四十七亿个神经单元。一个念头在脑子里挥之不去：元灵此刻在元思维池中浓缩的那个东西，那个密度不断增加的认知内核，会不会是人类文明的终审判决？

或者说更可怕的，会不会是人类文明的定义，被一个外部的眼睛重新书写？

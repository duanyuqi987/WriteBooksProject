# 第201章 番外六：护士林晓开创灵医学科

林晓第一次在开学典礼上讲话的时候，台下坐了三十二个学生。

三十二个。不多。但够填满一间小教室。教室在省人民医院新成立的灵医学科三楼——原来是医院废弃的档案室，花了两周时间重新装修。墙壁刷成了淡绿色，是林晓挑的颜色。她说绿色对病人的情绪有安抚作用。但现在这间教室里坐的是学生——全国第一批灵医学生。

三十二个人里，有十二个是刚毕业的医学生——临床医学、中医学、护理学的都有。有九个是在职医生——从全国各地的医院申请调过来的。有六个是退伍军医。有三个是原先的乡村医生，被省里推荐来参加灵医培训。还有两个——是基因检测确认了特殊灵根类型的觉醒者，没有任何医学背景，但有极高的灵气亲和度。

林晓站在讲台上，手心在出汗。

她今年二十九岁。灵气复苏之前，她在这座城市的中医院针灸科当了六年护士。她的工作是给病人扎针——不是医生扎针，是护士辅助。但她喜欢这个工作。她喜欢看病人被针扎了之后，原本紧绷的眉头慢慢舒展的样子。她喜欢听病人说"林护士，你扎针不疼"。

但灵气复苏之后，她能看到了。看到病人体内发光的经络线。看到灵气在经络中流动、阻塞、溢出的轨迹。看到每一个穴位上的灵气浓度——亮的穴位是通畅的，暗的穴位是瘀滞的。那是一种超感官的感知——不是眼睛看到的，是一种更底层的东西。像是她的神经末梢长出了灵气的触须，能直接触碰到病人体内的灵气流动。

她的这套能力被灵管局评定为A级经络敏感度——全国最高等级。全国十几个A级经络敏感者中，大部分选择了去当修士——用经络敏感度来辅助修炼，感知灵脉流向，或者干脆加入灵管局当灵气探测师。只有林晓一个人选择留在医院。

因为她的敏感度能让她看到的不是灵脉——是病人的病。

灵气入体后遗症、灵素过敏症、经络阻塞症、灵根发育迟缓——这些病在灵气复苏之前根本不存在。西医的CT、核磁、血液化验查不出灵气在人体内的异常流动。中医的望闻问切能摸出一些问题，但传统中医理论中也没有"灵气"这个概念——它被归类为"气"的一种，但"灵气"和"气"不是一回事。

第一批灵医就是在这个空白地带出现的。全国大约有四十多个人——有的本来就是医生，有的是觉醒者，有的是两者兼有。他们分布在不同的医院、诊所、甚至家里——各自摸索着用灵气治病的方法。没有教科书，没有标准，没有同行评议。只有病例。一个接一个的病例。

林晓从当上灵医的第一天起，就开始写病例记录。

她的记录不是普通的病历。是灵医病历——每一项都记录了病人的灵气状态:经络灵气浓度、穴位通畅度、灵素代谢率、灵气与病患部位的交互反应。她用自己的经络敏感度扫描病人全身，把看到的每一道灵气的异常流动都画成图——不是CT的三维重建图，是经络灵气图。线条是灵气的流向，节点是穴位，颜色的深浅代表灵气浓度的高低。

三个月下来，她画了六百多张图。

这些图后来成了灵医学科的第一本教材——《灵医经络诊断学》的核心图谱。

现在她站在讲台上，面对这三十二个学生。最小的二十岁，最大的五十三岁。有人穿着白大褂，有人穿着练功服，有人穿着旧军装。

她沉默了好一会儿。台下有人在悄悄议论——她看起来太年轻了，和印象中"学科主任"的形象差太远。

然后林晓开口了。

"我叫林晓。三年前，我是这家医院针灸科的护士。每天的工作是扶病人躺下，帮医生递针，收床单。那时候我的月薪是四千三。"

台下安静了。有一个穿白大褂的男生轻轻笑了一声。

"今天我是你们的老师。"林晓没有笑。她的声音很平静。"不是因为我的修为很高——我的修为只有灵者境。不是因为我有什么学术头衔——我连硕士都不是。我今天站在这里，是因为过去两年里，我用灵气治好了八十二个在普通医学中确诊为'原因不明'的病人。"

她把第一张幻灯片投在屏幕上。不是文字。是一张经络灵气图——一个三岁小孩全身的经络灵气扫描。图中的肝经线路上有七处灵气瘀滞，每处瘀滞的位置都对应着这个孩子的症状:肝区疼痛、食欲减退、发育迟缓。这个孩子在常规医院查了三个月——做了八项化验、两次B超、一次基因检测，全部阴性。原因不明。

"这个孩子叫小宝。"林晓说，"三岁。他家的房子盖在一片老坟地上。灵气复苏之后，地底死气顺着地基渗进了他家一楼——孩子在楼下住了两年，每天呼吸着被死气污染的空气。死气在肝经里缓慢累积，经络排不掉——就像下水道堵了，污水倒灌。"

她切换下一张图:同样的经络图，但瘀滞位置少了两处。剩下的五处颜色也变浅了。

"治疗三周后的结果。方法不是开药——药进不了经络。方法是用我的灵气导入他的经络，像通下水道一样，从第一个穴位开始，一段一段地把瘀滞的灵气冲破。三周，每次二十五分钟。不疼——孩子睡着了。"

再切换。下一张图上，所有瘀滞点都消失了。

"第四周。痊愈。"林晓把图关掉。"他爸妈最后一次来复诊的时候，孩子自己跑进诊室，指着我的白大褂叫阿姨。他妈站在门口哭。"

台下没有人说话了。

林晓放下遥控器。

"灵气不是用来打架的。是用来救人的。"

她说这句话的时候没有提高音量。但声音穿透了教室里每一个人的耳朵。

"我今天站在这里，就是要告诉你们——灵医这个学科，现在什么都没有。没有教材，没有标准，没有权威，没有经验——只有病例。每个病人都是一个全新的生物学事件。他们的身体里混入了两千年没有在人类体内出现过的灵气。这些灵气在干什么、会怎么发展、会引发什么后果——没有人能给你答案。你得自己找。"

"找的方法很简单。治。一个接一个地治。把你的灵觉打开，用你的手指去感受病人体内灵气的温度、流速、方向、阻隔。把你的诊断写下来——每一个字都要写。因为你的诊断就是明天的教材。"

她顿了顿。

"你们是三十二个。全国第一批灵医学生。也许五年后、十年后——灵医学院会建起来，会有灵医学士、灵医硕士、灵医博士。会有《灵医内科学》《灵医外科学》《灵医急救学》。但今天——2027年秋天——灵医这个学科只有我们。只有这间教室，和下一间诊室，和下下一间病房。"

"如果你们准备好了——我们开始上课。"

第一课的内容是经络灵气扫描。林晓把三十二个学生分成三组，每组进入一间诊疗室。诊疗室里坐着从省人民医院普通门诊转过来的病人——都是有灵气相关症状但常规检查查不出病因的患者。

第一组的学生围着一个五十多岁的男性病人。病人主诉是"自从半年前接触灵石之后，左边的胳膊一直在疼，拍片子骨头没事"。一个医学生出身的学员伸手去按病人的左臂——他的手指触到病人皮肤的瞬间，指尖泛起了一层极淡的蓝光。他闭上眼睛。

"我……感觉到了。左臂经络里有东西——不是堵的，是——"

"是逆流的。"林晓站在他身后。"灵气在经络里应该是单向流动的。但这个病人的手阳明大肠经里灵气在逆着走。逆流形成了涡旋，涡旋刺激了经络壁上的神经末梢——所以他疼。不是骨头疼，不是肌肉疼，是经络疼。"

她让学员把手指沿着经络的走向慢慢推。学员推了大概三分钟，然后病人的左臂忽然抖了一下。

"不疼了。"病人瞪大眼睛。"刚才好像有什么东西散了——不疼了。"

学员看着自己的手指，然后又看着林晓。

"这就是灵医？"

"这就是灵医。"林晓说。"你不需要灵丹妙药。你只需要知道灵气在人体里应该怎么走——然后用手把它引回正确的路。"

三个月后。

灵医学科的第一届学生毕业了。三十二个人，全部通过了灵医执业资格考试——这门考试本身就是林晓和灵管局一起设计的。考试分三部分:经络灵气扫描、灵气诊断、灵气疏导实操。

毕业典礼上有一个环节是学生代表发言。上去的是一个来自云南乡村诊所的中年医生——他叫杨建国，今年五十三，是全班年龄最大的学生。他在乡村诊所学了三十年中医，用银针和草药治了三十年病。灵气复苏之后他觉醒了灵根，但不知怎么用。他听说省医成立了灵医学科，把村卫生所交给徒弟，自己买了张火车票来了省城。他带了三个月换洗的衣服，住在医院附近的青年旅社——和他同住的是一个刚毕业的护理系学生，比他小三十岁。

杨建国站在讲台上，拿着发言稿的手在抖。

"我以前觉得，灵气是神仙的事。"他说。"我在村里行医三十年，中医六经辨证我滚瓜烂熟。但灵气入体之后，六经辨证不够用了——有些病六经辨证摸得着，但六经辨证治不了。因为六经辨证是用草木的金石之气来调理人体之气。但灵气的力量比任何草木都强——强太多了。草木调不动的气，灵气能调。"

"我这三个月学了什么？学了一件事:心要细，手要轻，眼要真。看病人不要只看化验单，要看他体内的灵气在怎么流动。林老师教我们的就是这件事——用你的灵觉去看，看真了，才能治对。"

他把发言稿放下。

"我明天回云南。从明天开始，我那个村卫生所就多了一门业务——灵医。村口那块木牌子我回去就重写。原来的'杨建国乡村卫生所'，加一行字——'兼灵医'。"

台下有人鼓掌。然后所有人都鼓起掌来。林晓站在角落里，把手拍得很轻。

毕业典礼结束后，杨建国走到林晓面前。他把一个塑料袋塞到她手里——里面是一包干菌子。云南山里的野生菌，他上山采的。

"林老师。我没什么值钱东西。这是我自己上山捡的。你收着。"

林晓把塑料袋接过来。菌子很轻，塑料袋子在手里哗哗作响。

"杨医生，"她说，"你回到村里之后，把你治的灵医病例发给我。每一个都发。用手机拍照就行。"

"一定发。"

杨建国走出教室门口的时候回头看了一眼。这个不到四十平方米的教室——原来是医院的废弃档案室——现在挂着一块崭新的牌子。牌子上的字是他看着工人刻上去的:

"全国灵医培训基地。首届灵医学科。2027年。"

门外走廊尽头，新的诊室正在装修。护士们在搬器械，墙上在贴新的指示牌——"灵医内科""灵医康复科""灵医急诊科"。三个科室都是今天刚批下来的。全国的灵医事业——从这间旧档案室开始，正在像地板下的菌丝一样缓慢而坚定地蔓延。

林晓站在牌子底下，看着杨建国的背影消失在走廊末端。

她摸了摸口袋里的手机。手机屏幕上有一条未读消息——是许冰发的，只有一行字:"灵医执业资格条例草案已完成。等你审核。"

她打了一个字回复:"好。"

然后把白大褂的袖口卷起来，走向下一间病房。

（第201章完）

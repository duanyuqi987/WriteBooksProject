# 第110章 医院开设灵气科，护士林晓晋升灵医

林晓是在一个周二早上接到调令的。

那天早上她刚冲完一杯速溶咖啡，还没来得及喝，护士长就敲了她办公室的门——不对，现在已经不是护士办公室了。她现在坐的是省人民医院北区三楼最边上一间新装修的房间，门牌上写着"灵医科医师办公室"。屋里一共四张桌子，目前只有她一个人的桌子是满的——另外三张还空着，桌上的显示器贴着出厂时的保护膜，椅子上积了一层薄灰。

"林医生。"护士长——现在应该叫科主任了——把一份文件放在她桌上，"院办公室批下来了。灵气科正式成立，你任副主任。主任暂时由肿瘤科刘主任兼任，过渡期六个月，之后——大概率是你。"

林晓接过文件。纸张摸起来很厚实，封面印着医院的红章，内容页上有一行粗体字——"关于成立省人民医院灵医科（省级灵气医疗重点学科）的通知"。

她翻开第一页。灵医科的编制:十三张床位，一间灵能治疗室，一间经络检测室，一间灵气药房。配备:灵气检测仪两台、经络灵视仪一台、灵符辅助治疗平台一套、灵药萃取机一台。人员:副主任一名（林晓），灵医两名（招聘中），护士四名（已配齐）。

她往下翻到第二页——灵医科的业务范围。字小，但每一行都很重:（一）灵气过敏症的诊断与治疗；（二）经络阻塞症的灵气疏通治疗；（三）肿瘤类疾病的灵能辅助治疗；（四）灵根发育异常的早期干预；（五）灵能创伤后的恢复治疗。

五条业务范围。每一条都是全新的——没有成熟教材、没有标准化诊疗指南、没有前辈的经验可循。整个科室除了林晓之外的所有人，包括那四名护士，之前都没接触过灵能医学。她们是医院从各科室抽调上来的——神经内科、心内科、急诊科、针灸科——每个人在本行上都是好手，但在灵医科要从零开始。

林晓把文件放在桌上，喝了一口咖啡。咖啡凉了。她忘了。

一个月前她还是针灸科的护士。那时候她的主要工作是给病人扎针、拔针、记录经络反应。但因为灵气复苏之后她觉醒了经络灵视能力——能看到病人体内灵气沿着经络的流动方向和强弱——她成了全国第一批拿到灵医资格证的医务人员。理论培训是在北京上的，三周的速成班，授课的有中医经络专家、灵管局灵根分类研究员、还有几个在灵气复苏后自发研究灵能医学的民间医者。课上讲的内容有一半是推测——因为没有人真正系统地研究过灵气对疾病的干预机制。

她回到医院之后，医院领导问她:"你想怎么干？"

她说:"先看病人。"

病人很快就来了。第一个病人是一个三十一岁的男性，灵素过敏症。他之前在一家灵石加工厂工作，不知天高地厚地天天接触高纯度灵石。半个月后他的皮肤上长出了类似于灵纹的斑块——不是真的灵纹，而是皮肤组织被过量灵气侵蚀后产生的疤痕化变异。他来的时候浑身痒得睡不着觉，两个手臂上全是自己抓出来的血痕。

林晓用经络灵视看了他一遍。在灵视下，这个病人体内的灵气流严重失衡——他的皮肤层滞留了大量外来灵气（来自灵石粉末的物理性侵入），而他自身经络里的灵气无法排出这些外来者，两者在皮下组织里反复冲撞、结合、再冲撞。西医的皮肤科治疗只能缓解瘙痒和炎症，但解决不了"灵气层面的栓塞"。

林晓用了三天时间摸索出了一套治疗方案:第一步，用灵能疏通针（一种能引导灵气流动的特制针）在栓塞位置进行穴位灵气疏导；第二步，用微量灵石粉剂（经过稀释的灵液）涂敷在病灶处，让外来灵气被灵石中的中性灵气场吸附并中和；第三步，用传统针灸配合灵视，在病人自身的经络内建立一条排放通路，把被中和的灵气代谢出来。

治疗第一周结束的时候，病人手臂上的斑块缩小了百分之四十。病人说:痒还痒，但轻了很多。

治疗第二周，斑块缩小了百分之七十。

第三周，斑块基本消退，只剩下几道浅色的色素沉着。

病人在出院那天给林晓送了一面锦旗。锦旗上印了八个金色大字:"灵医妙手，华佗再世。"林晓把锦旗收下了，但没有挂——不是不珍惜，是她觉得这面锦旗上缺了一些东西。华佗治的是普通的病。而她治的不是普通的病——是灵气时代的病。这是一种华佗当年不可能预见的病。她需要的不只是"再世"——是创造。

一个月后，灵医科的门诊量从最初的三天一诊变成了每天十几个病人、然后增加到每天三十几个。病人中大约一半是灵素过敏症，三成是经络阻塞——这两类病都是灵气时代之前不存在的新病种。还有一成是绝症——癌症晚期、渐冻症、再生性贫血障碍——这些病不是新病种，但灵气对它们的影响从未被人系统研究过。

灵医科的业务增长之快超出了医院的预期。一个月之内，十三张病床就被占满了，走廊里加了四张临时病床，仍然不够。病人们来自全国各地——有听说"省人民医院灵气科能治灵素过敏"就买了火车票来的，有家属拿着化验单慕名来的，还有一些是通过灵管局转诊过来的重度灵能创伤患者。

林晓自己一天的工作时间从八小时拉长到十四小时。她每天早上七点到科室，晚上九点离开。午餐是一碗泡面或者老陈偶尔顺路带来的盒饭。她瘦了——不到一个月瘦了六斤。但她不觉得累。或者说，这种累是她从未体验过的——不是因为被逼着加班，是因为她面对的每一个病人都没有现成方案可参考。每一个病人都是一道全新的题，她必须自己去找到答案。

下午四点，灵医科的门诊诊室里来了一个特殊病人。

病人是个中年男人，五十岁左右，国字脸，身形干瘦。他穿着一件深灰色的老干部夹克，领口扣得严严实实。进了诊室之后他先不急着坐，而是仔细地观察了一遍诊室里的每台设备。他的眼神很锐利——不是病人的那种焦虑或疲惫，而是一种职业化的审视。

"您是？"林晓问。

"周振国。"他报了名字。

林晓愣了一下。周振国——国家灵能监测管理局首任局长。她在新闻上看过他的照片，但没见过本人。新闻上的他穿着笔挺的制服站在新闻发布会的话筒后面，脸比现在胖一些。眼前的这个人明显瘦了——瘦了至少十斤。

"周局长。"林晓放下手里的病历，"您怎么会——"

"来看病。"周振国坐在诊椅上，把左手的衣袖拉上去。手臂内侧有一道从肘部延伸到手腕的暗红色斑纹，斑纹表面有细密的鳞片状隆起——不是皮肤本身长出了鳞片，而是皮下组织被某种东西撑起来形成的凹凸。

"去年十二月，去青海灵脉考察的时候——在地底灵脉的节点附近停留了太久。"周振国说，"回来之后左手开始出现这个。省里的医院做了两次皮肤病理，说不是恶性肿瘤，但找不出原因。灵管局自己的体检也做了——结论是'非典型灵能侵蚀'。就这么一条。没有治疗方案，没有药物建议。"

林晓打开经络灵视，对准了他的手臂。

在灵视中，周振国的左臂经络图呈现出一幅她从未见过的画面:他手臂上的所有主要经络都完好，但经络的微细分支——那些像树根末梢一样深入皮肤层的络脉——全部被一种暗红色的外来灵气给裹住了。这种灵气不是五行属性，也不是她之前见过任何已知类型。它没有在主动侵蚀正常的经络组织——而是在"占领"正常的经络组织。那些被裹住的络脉并没有坏死，而是依然在运转，但它们运转的灵气指令被那股暗红色灵气给"拦截"了，就像一封邮件没有送到目的地，被中途转投到了另一个收件地址。

"你身体里有两股灵气在打架。"林晓关了灵视，"一股是你自己的——正常的灵根灵气。另一股是从青海灵脉节点侵入的外源灵气。它没有释放、也没有被你的免疫系统清除——而是寄生在了你的经络里。它在用你的经络做'传输通道'，把自己的信号传给——"

她停了。

传给什么？她不知道。但她能从那股暗红色灵气的流动方向上隐隐感觉到一个规律:它不是无目的地乱窜，而是有方向地——沿着经络一路往上，经过肩井，过颈部，最终的目的地似乎是头部。

"它在往你的头走。"林晓说，"如果这股灵气到了头部——我不确定会发生什么。可能是神经损伤，也可能是灵根本体的侵蚀。"

周振国沉默了几秒。然后说了一句让林晓意外的话:"这个推测，和我们在灵管局做的风险分析结果基本一致。只是我们至今不知道怎么把它取出来。"

"你们灵管局都取不出来——"

"取不出来。"周振国摇头，"灵管局储备的灵能治疗手段本质上是军用的——针对外伤、灵气透支、灵能武器烧伤。但对经络层面的寄生性灵气感染——我们没有成熟方案。灵管局的灵医只配到了省级监测站，整个全国的灵医加起来不到一百五十人。而且大多数是刚毕业就被紧急征召的毕业生——连灵视都没觉醒。"

他顿了顿，看着林晓，"你是全国第一个自发觉醒经络灵视的A级灵医。你的能力——在灵管局的内部评估里——排在全国灵医能力序列的前五位。"

林晓第一次听说这个排名。她不知道自己的灵视能力在全国范围是什么水平——她从来没见过其他的灵医。

"所以我想请你——"周振国站了起来，"成立一个研究组。不是常规科室，而是一个能跨单位协作的灵医应急研究组。目标只有一个:尽快建立起灵气医疗的标准化诊疗体系。不只是灵素过敏——是经络被寄生、灵根侵蚀、冥气感染——所有已知的和可能的新型灵能疾病。"

他停了停，补了一句:"你愿意吗？"

林晓看了他三秒。然后说:"我有一个条件。"

"什么条件？"

"研究组的成员不能只限于在职医生。我需要一个人——一个修士。他没有灵医执照，但他身上有一种特殊的灵气——冥气。通过研究他对冥气的控制方式，我可能找到治疗经络寄生的突破口。"

周振国沉默了一下。冥气——这两个字在灵管局内部是一个高度敏感的话题。玄门七宗对冥气持排斥态度，灵管局内部也有不少人认为冥气是危险品。

"那个修士是谁？"

"李长生。"

窗外是医院后院。后院里种着一排银杏树，深秋的银杏叶黄透了，风一吹就往下掉，像一群黄蝴蝶。林晓在去年针灸科里第一次通过灵视看到病人体内经络的时候，她从来没有想过自己有一天会坐在这间新科室的诊室里，和一个国家灵管局的局长讨论灵气医疗的事。

但世界变了。而她已经不再只是一个护士了。

（第110章完）

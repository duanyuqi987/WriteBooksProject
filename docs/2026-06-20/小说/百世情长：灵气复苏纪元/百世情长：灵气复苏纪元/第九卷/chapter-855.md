# 第八百五十五章 守门人区巡礼

飞升之门运行第十九年的春天，林牧和苏晚第一次正式踏出青云山谷，穿过飞升之门通道抵达仙界守门人区。

这是他们第一次真正以"真人"身份步入仙界——不是通过共鸣腔感知，不是星眸投射，而是实实在在的双脚落在仙界的土地上。通道出口处，守门人区的入口是一座极高的拱形牌坊——不是石头做的，是飞升者们用灵力凝练的结晶。牌坊正面刻着：守门人区。牌坊背面有四个字："谢谢守门。"

苏晚在牌坊前站了相当长一段时间。不是因为累了——而是牌坊背面那四个字被刻得并不整齐，字里行间看得出来是无数飞升者分批一人刻一笔写成的集体书法。每一笔深浅不一，但力度都非常真诚——有人在刻到"守"字那一点时用力太重，把晶面敲出了一个极细的裂纹，然后另一个人用灵力把裂纹补成了透明痕——让它变成了"星光窗"的缩小版花纹。

林牧走到她身边。"他们在用自己的方法表达信任。"

"我知道。"她的声音有点沙——但眼角那种润泽不再是含着泪，而是一种类似于"收到了很多很多份期待"的明亮。

两人进入了守门人区。区内建筑林立——有飞升者的永久居所，有修炼场，有接引馆，有专门为从人间新飞升来的人修的"新家坊"。而中心广场的位置上矗立着一座非常高的星柱——一根从地面升至云端的光柱，连接着人间与仙界——它和飞升之门的共鸣相应，让人间飞升者在穿越过程中最后一秒看到的是这根星柱的光芒，从而确定已经抵达。

广场上站着很多他们曾经认识的面孔。寒尘现在已经是区内的接引长——他的性格从孤独中逆转，变得温润而坚定。白染在白云之间建了一座书院，专门教导新飞升者关于仙界生存的基本知识。白微从仙宫退职后加入守门人区，成为了守门人区与仙界体系之间的沟通协调员。

众人围上来——没有人虚伪地递上锦旗，只是互相微笑、寒暄，就像久别重逢的朋友。寒尘在林牧肩头轻拍了一下，然后递给他一块淬体坛中的新鲜仙果。"今天早上才落果——新进飞升者带来的苗。给你。不给苏晚因为她喝茶。"

苏晚笑着把另一颗接过来："他说的不包括我。我从来跟你抢。"

这一日守门人区没有特别仪式——只有很长的散步，以及极温暖的夜话。当晚，寒尘带着二人登上了星柱的顶端——在那可以俯视整个守门人区。林牧望着那些街道的灯火，忽然开口向寒尘问了一个冷门的数据："区内平均飞升经验释放比是多少？"

寒尘微愣——然后大笑起来。笑完擦了下眼角说了一句："果然是你——上来第一句不问看，问比例。这个数字是——"他说出了一个比率。林牧在月光下轻轻点头——然后转头对苏晚说："比预期中高出许多。说明交互层在过去十几年中已自然进化出了一些额外功能。"

苏晚微笑着握紧他的手。她心中知道何止是交互层——整个守门人区的存在就是信任的回报。而他们正好在这里一起见证这一切。

# 第四百七十六章 十二件委托

那十二件委托任务分布在五方仙域的各个角落。不是集中在一个地方解决完——而是星散在数万里的范围内。两个人花了大量的时间来办案。

第一件是那只偷果子的仙兽——不是什么凶暴猛兽，而是一头瘦得皮包骨的青云幼麟，被母兽抛弃后流浪到了仙果园边缘，因为饥饿去打落了半面树上的仙果。苏晚没有驱逐它——她用了整整一整天蹲在果园外面，用龙墓中得到的龙族印记吸引它出来。幼麟对她的龙族印记极其亲近——大概因为麒麟和龙在上古是同祖。她把幼麟用青莲载回了南离城里的仙兽收养所，又在档案上签了一个"长期寄养自愿捐赠人"的名字。委托完成——第一分。

第二件是帮一位老仙婆找回她遗落在北冥冰原的旧梳子。梳子上刻着她已道陨多年的道侣的名字。苏晚钻入冰原最深处把那把梳子从雪地下挖出来的时候冻得手指通红。她把梳子交还给老仙婆时，老人家用极颤的手握着梳子说了好几次"多谢"——然后张开枯瘦的五指摸了摸苏晚腕上的红绳。"你男人在外面等你吧？快出去。别让他等久。"

第三件到第九件一件比一件琐碎。给两个分裂的仙族村落重新划分地界——调解一个散修和交易员之间的功法瑕疵纠纷——协助执法部在某个被邪仙污染的废弃矿场布下净化阵法。第九件是替仙庭检测一处仙脉是否完全枯竭——检测位置在极端险峻的山脉深处。苏晚爬进矿洞时脚滑了一下差点摔进下面的岩浆河。林牧抓住了她的手腕——左手抓着她的手腕，右手五指插进岩壁里，硬生生用一把手指把她吊在岩浆河边。他的手指在岩壁上滑出了五条极深的指痕。苏晚借着那个力道翻转上来时喘了好几口粗气。然后两人一起探完了那条矿脉——脉还在，没枯。

第十件是送信——从第一重天送到第三重天，中间要通过两个空间密度极高的虚空过渡区。在第二虚空区里他们被空间碎裂的残余能量袭击。林牧以炼虚后期撑起防护罩——他现在已能同时调动两颗灵核的全部灵力——防护罩的厚度比之前厚了好几倍。空间碎片打在防护罩上像雨打伞面。苏晚在防护罩里抓紧时间看信使卷上标注的路线。信送到收件人手里之后对方签收了。两人靠在第三重天的入城墙上坐了很久。

第十一件——协助一支散修道侣队解决内部纷争。那对道侣中的一方对另一方隐瞒了一件极要重的旧事——导致双方的灵核共振越来越差。苏晚花了半天和那个瞒事的女修聊天——没有审问，只是聊。聊她丈夫给她做过的蠢事。聊到后来那个女修自己把隐瞒的事说出来了。然后她丈夫在门外听到了——没有发脾气，而是走到她面前说了一句话:"你一直瞒我的不是这件事。是你觉得自己不够好才瞒我。这句话我等你等了快二十年。"苏晚回来之后在晚上写日志时停了半天。她在地图旁边用签字笔写了一行小字:"最好的审判有时候是说一句话。"

第十二件——最麻烦的:帮南离城的一位仙官拆除他在多年前被卫无渊安插在府邸中的窃听阵器。这个阵器核心牵扯到天机阁的老式禁术噬魂铃的变种。苏晚已经拆过一次铃铛——有经验。她在仙官府邸的墙壁上一共找出了十多枚微型窃听法器——每一枚的根部都栓了魂碎片。拆掉最后一颗法器时她虎口上那道老疤微微发热——那是拆噬魂铃时留下的手部经脉劳损。仙官在拆完法器后签了积分。

整整十二件委托——每一件都完成得很认真，但也确实累得够呛。完成十二件后两人的中阶仙令牌上同时出现了第十二道光痕。功德积分达成了。可以正式立案。

"明天。"苏晚把令牌在手中翻了个面。"明天我们就去执法部正式立案——控告卫无渊。"

（第四百七十六章 完）

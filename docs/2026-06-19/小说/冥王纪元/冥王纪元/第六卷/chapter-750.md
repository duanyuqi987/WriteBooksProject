# 第750章 成为新纪元的顾问，分享前人智慧

封玄在帝国中枢定居了下来。

帝国为他在中央星的最高处——一座悬浮在半空中的静谧山岳——安排了一处居所。山岳是从地球昆仑山脉搬过来的一整块巨岩，经过灵能切割后悬浮在帝国中枢上空三千米。岩石上只有一座小屋，一汪灵泉，一棵从第五纪元种子库中复育出来的老树。

封玄第一天搬进去的时候就做了三件事。第一，在门口立了一块石匾，手刻了四个字：来喝茶者。

第二，让冥离把破阵派档案馆中最重要的资料全部传输到了帝国全息网络，对全体民众免费开放。资料总计约三百万卷，涵盖了第五纪元破阵派在封禁期间积累的全部学术成果。其中最重要的部分是一个被命名为"万古纪元终末分析"的特别档案——记录了破阵派对万古纪元终结原因的完整分析。这份档案在一万纪元内从未被传递出黑洞。

第三件事最不起眼——他在小屋的院子里种了一棵黄瓜。种子是三百年前地球上那种本土黄瓜的种子，李长生自己带到中央星上的。当时他只是顺手塞给封玄的，没有特别的意思。但封玄在整个搬家过程中，第一个放好的就是那颗种子。

"为什么是黄瓜？"王思远在参观封玄新家时忍不住问。

"因为这是文明的根。"封玄把土拍实了的动作很稳——不像是一个帝级修行者的手，而像一个老实巴交的老农。"你太爷爷王宇是程序员。你们家的看家本领是灵符编码和系统架构。你知道为什么灵符能在宇宙间通行那么多年都没退化吗？因为灵符本身是'健壮'的。和黄瓜很像——扔到土里不用管太多，自己就长出来了。"

王思远若有所思。

封玄扶着膝盖站起来，拍了拍手上的泥。"我花了整整三个早晨把'万古纪元终末分析'全部上传到了帝国科学院网络。今天下午给他们做第一次讲解。你要不要来听听？"

王思远当然去了。

讲解的地点设在帝国科学院的中央讲堂。封玄坐在讲台上的一把藤椅里，面前的长桌上没有讲稿，只有一杯陈霜泡的乌龙茶。台下坐着帝国最顶尖的三千名科学家，还包括从边境星域加急传送过来的观测站代表。

封玄的开场白出乎所有人的预料。

"我先说结论。"他说，"混沌本体不是敌人。它只是一个醒了就会导致我们全部灭亡的、本身没有任何恶意的、宇宙级自然灾害。"

台下顿时翻起了一阵小声议论。封玄抬手让他们安静。

"你们现在理解的混沌——混沌级修士、混沌力量、混沌之主——这些都是混沌本体的'影子'。混沌本体是本体，你们所能感知到的所有混沌力量都是它投射在维度表面上的微弱残影。就像一个沉睡中的人，他呼出的气息对于他身上微小的细胞来说就是一场飓风。而混沌本体本身远比任何混沌之主强大——不是一个等量级。"

"那它到底是什么？"陈知远教授问。

封玄沉默了一会儿，然后给出了一个让所有科学家都沉默的定义。

"它是宇宙诞生之前就存在的存在。在万古纪元早期，它一直处于深度沉睡状态，整个宇宙的混沌力量都以它为源头稳定运转。后来——万古纪元末期，一个极度先进的文明试图'驯化'混沌本体作为武器。他们开始抽取混沌本体的力量。混沌本体被抽醒了。它的苏醒过程引发了万古纪元的终结——旧宇宙的毁灭和新宇宙的诞生。这也就是你们现在称之为'维度大爆炸'的事件。"

"被抽醒的那一次毁灭了整个旧宇宙。"陈知远的声音有些发颤，"现在它又要醒了吗？"

"对。"封玄的声音不带情感，但每个字都沉重得让人窒息。"而且这一次，有人在主动加速它的苏醒。不要问我他们为什么——谁也不知道他们为什么这么疯狂。但可以确定的是，他们的技术比起万古纪元末期那个文明更加高效。他们的进度比当年快十倍以上。"

讲堂里沉默了很长时间。

然后李长生的全息投影出现在了讲台上。他没有坐在帝王的位置上，而是站在封玄的藤椅旁边，像一个来听课的学生。

"那我们要做什么？"李长生问。

封玄看着他。老人的银灰色眼睛里倒映着整个讲堂中所有人的影子，以及他们身后那个庞大但脆弱的新纪元。

"第一，"封玄说，"弄明白混沌本体在哪儿。第二，想办法加固封禁。第三——"

他顿了顿。

"做好最坏的准备。如果封禁无效，混沌本体完全苏醒——那就需要有一个人站在它面前，用上一代冥王堵住裂缝的方式，挡住它的第一次呼吸。"

封玄看着李长生。

"而这一次，没有第九块碎片可以给人捡了。"

（第750章完）

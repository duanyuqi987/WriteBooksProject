# 第三百八十六章 最后的凡间日子

倒数第三年。他们没有闭关——而是决定用这三年来寻访所有在战争中对他们产生过影响的人。先去岭南——去青溪镇邮局对面那家面馆再吃一碗笋肉末面。老板娘老了，手有些颤——但记得他们说"不要太甜""不放味精"。然后转去秦岭——去看那条曾被他们共同封上的副裂缝旧址。如今那儿长出一片新的松林——是当年林牧在这里种的第一批灵松的后代。接着去南海——在那座她曾封印天膜的东海上空悬停一阵。那年海水被染成紫色——如今底下鱼群如云。

他们没有举行任何告别仪式。只是在一个普通午后坐在昆仑镇魔塔前——最后一次查塔顶金光碑有无预警。碑面干净——没有任何警示。林牧将手贴碑——碑壳温热——和他手温一样。苏晚在旁边开始种最后一棵松苗——不是给灵网用的。是单纯的"末松"。她把苗放进坑里——用医者杯浇上金灵水。她浇完时老猫从塔里走出来——它跟着他们几十年，毛已经灰白。她弯腰把它抱起来放进药箱——它轻喵了一声。

"带上猫。"

"好。"

那夜在昆仑山下的小客栈住下。她把战士杯和医者杯并排放在床头柜——水未倒——留着明天倒。然后闭上眼——感知到他离她不过一臂之距——和三十年前他背她飞出十七楼一样近。最后一晚他们没有入虚——只是靠着彼此。听窗外旅馆旁边那棵老松被风吹得沙沙响。很老很稳——像很多年前的榕树。

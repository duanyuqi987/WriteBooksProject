# 第七百三十六章 开启飞升之门——让所有人都有机会

第三级跃迁——最高一级——启动的那天，太湖灯火塔的火光映照了大半个湖面。第三级不再有训练营——它是正式飞升前的最后准备——飞升之门将被有史以来最大规模地使用：一次同时接待三千人。

这三千人是从第一级和第二级中自己报名的数万名申请者中选择出来的——按照自荐加抽签。上界过渡区已提前扩建了临时住宿区——秦无夜和她的魔修厨师团队在一年前就开始准备了——在灯火塔旁边种下了一排新桂花苗——每一株都对应着地面一间分院。石头在送第三级学员们登门时没有发表任何激情演说。他只是把灶台搬到了通道入口，在每人在登门之前，给他们盛一碗粥。最后一碗粥盛得比所有之前更满——是给小米的。十五岁的小米——那个不会说话的北境孤儿，现在端碗的样子像极了他师父年轻时的样子。小米端着碗抬头看着石头，说了一句话——他说得很慢但极清楚："谢谢师父。——我去替大家看看上界的云。"

石头的嘴动了一下。他没有说话——但他在小米的碗底已经提前放了一颗鹅卵石——新的，上面刻的是"互不吓唬"——标准字，没有错的"唬"。他之前刻错了三个版本——全留着自己。只把对的放在了小米的碗底。

三千人依次通过飞升之门。通道的金紫色光芒比以往任何一次都更明亮——不是通道性能变强了，是经过它的人群中有各种不同的灵根和人生——每个不同的频率都在通道中找到了自己的轨道。通道内部的缺陷联合曲线一直在运算——但不需要任何人指挥。它在自己运行。

上界过渡区那头，秦无夜站在灯火塔下，看着通道口源源不断地走出来的新面孔——老老少少，修士凡人，有的背着锅有的抱着花盆。她旁边的那棵桂花树——那棵老树的第五代孙——开满了花。不是季节——是这棵树感知到从地面涌来的所有人——开了。

苏晚在地面灯火塔上，看着灵网监控中通道的使用率达到历史峰值。她打开了随身灵囊中的保温壶——不是喝茶，是把热茶默默洒在地上——祭给他和她前世那位最初的她——那个推他躲过雷霆的白衣女人。"是你们的开始——轮到他们了。"

（第七百三十六章 完）

# 第五百零三章 百世画面——第五十一世到第九十九世

第五十三世是她最喜欢的一世。那一世他们的身份极简单——都是卖豆腐的。两个豆腐摊在同一面街的斜对面。她卖豆腐脑，他卖豆腐干。每天早上天不亮就各自出摊。两人的摊子面对面摆了十几年——每天都是:她掀开笼屉布时往上冒的白色热汽。他站在对面推车把自己推车挪过一步给她多让点位子。他们没有说过特别多的话——只是每天早上互相看一眼——确认对方今天还在这里出摊。这种确认持续了半个辈子。到他老了去世的那天早上——她掀开笼屉，蒸汽冒起来，她的眼眶忽然湿了。因为街对面没有那个每天都在的摊子了。

第六十七世比较惨烈。他是地牢里的政治犯，她是牢卒的女儿。她偷偷给他送了一针一线绣的手帕——手帕上绣着"春来"二字。意思是春天来了就放你走。但那年春天没来——他在冬末被拉到刑场上去了。她在刑场外听到那声脚步声——当晚她把手帕烧掉了。烧的时候一滴眼泪没有——因为她知道下一世还会遇见。

第七十二世——是在海上。他是海盗船上的副掌舵，她是被他从一艘被劫商船上救下来的女商人。救命之恩无法不心动——她不知道他是海盗，他只说自己是水手。后来她发现了真相——那天她站在船尾和他说了无数"为什么骗我"的气话，他一句话也不解释。当晚下暴风雨时整个船即将沉了——他把自己的那块唯一的漂浮木板寄给了她。他自己沉进了海底。她活下来了——活到很老很老，再没有嫁过人。临终前她的眼睛望着海——好像在等一艘不会再回来的船。

第八十世——极其短暂。她是襁褓里的女婴，他是隔壁产房同天同时辰出生的男婴。两人都没能活到周岁。但他们的灵核在濒死时短暂地共了一次振——共振完之后两个婴儿都安静地闭了眼。那双闭眼的弧度一前一后——像在同步入睡。这是寿命最短的一世，却也是轮回中两个人唯一一世没有别离。

第九十一世——他们又同时成了修士。都是金丹期，资质都极普通，但还是师兄弟师姐妹。他是师兄，她是师妹。山上人不多。每天清晨在峰顶背剑打坐——她坐得离他近。他感应到她靠过来时总会自己坐歪一点——因为剑背在背上，靠太近会硌到她。后来宗门在某次大战中覆灭。整个宗门只剩他和她活下来。两个人离开山门时他回头看残破的山门——说:"等以后——我们把山门重新修。"她说:"好。"现在那座山门下界还在。只是换了个名字——叫昆仑山余脉。

第九十九世——她记得那么清楚。这一世她是一个在书肆里打工的盲女。把书架上的书排列得整整齐齐——凭手能摸出哪本书是哪本。他每次来书肆买书，不看书，只看她，因为她什么书都认不出来，手摸着书名版后抬起头朝门口方向会点个头。——就算她看不见他时她也知道他在门口。这世他娶了她。两人在小镇过着极朴素的生活。她虽然一生看不见他的脸——但她记得他的脚步声，记得他的味道，也记得每次他靠近时空气里微微的那点暖意。她临终时握着他的手说:"下辈子我要能看到你的脸。"他说:"好。下辈子你第一眼就看到我。"

第一百世——就是前世。

苏晚讲到第九十九世时嗓子已经哑了。她还在继续说。她要把这一百世全部讲给他听——这是他给她的百世守护，她一件都不能遗漏地还给他。林牧安静地听着。功德绳上的金线在她每次提到他的名字时都轻轻地闪一下。不是自动闪光——是他每一次听到她的记忆里他做了那点微不足道的守护时他的灵核都会不自主地震颤一次。他不哭。但他的心跳瞒不过功德绳。她知道了——他每听到一世她死别时的描述，心就多沉一下。他现在的心比她还要重百倍。但她还在继续讲。

（第五百零三章 完）

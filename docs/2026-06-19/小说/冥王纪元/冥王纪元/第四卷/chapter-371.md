# 第371章 刀疤担任舰队总指挥官

冥王号的甲板上，一百一十人在出发前七十二小时进行第一次全舰实战演练。

演练的地点不是木星船坞的安全水域——李长生把演练地点定在了太阳系外围的小行星带。那里的空间环境接近真实战斗：不规则的小行星碎片、急剧变化的引力场、不可预知的宇宙尘埃流。最重要的是——那里有至少七十多个来自银河系各势力的探测器在持续监视。这些观测器会用它们的高精度传感器看清楚这场演练的所有细节：冥王号会怎么调度它一百一十人的船员、会怎么使用它的冥气引擎、会怎么在交火中走位。然后这些细节会通过量子纠缠信道发送回银河系的所有主要势力。

这就是李长生选择在那里演练的原因——外面那群盯梢的探子看到的东西越多越好。

刀疤站在舰桥的指挥台上。他穿着一身黑色的制式作训服——没有军衔标志，只有一个绣在胸口的标识。标识是一个简单的图案：一把锄头，交叉在一条银河之上。那是李长生自己画的草稿——锄头代表他从哪里开始，银河代表他要去到哪里。

"全体注意——报数。"

舰内广播系统把刀疤的声音传遍了冥王号的每一个角落。广播系统本身是常规电子设备——但在通讯频道加密的底层跑着小王的灵符加密协议。这意味着敌人无法窃听舰内通讯，但船上的每一个人都能在第一时间同时接收指令。

从船首主炮阵列到船尾引擎舱——一百一十人的报数用了不到九秒钟全部过完。这是刀疤用了三天训练出来的结果。三天前，这一百一十人集结完毕。其中有一些是刚从全国各地赶过来的散修——他们连冥王号内部区域编号都还记不全。三天后，他们每个人都在演练中准时到达了自己的指定位置。区域编号、紧急情况集结路线、战斗岗位轮替表——全背下来了。

这不是靠修士的聪明——是靠刀疤把军事化训练强行砸进了这群习惯独立作战的散修脑子里。他之前在特种部队做格斗教官时，每年训出一批合格的特战队员至少需要三个月。现在他只有三天。三天如果训不出一支像样的舰队crew——敌人不会因为他的时间不够就晚三天打过来。

"引擎舱——报状态。"

"引擎全部在线。冥气输出稳定。超光速预热时间——五分钟。"引擎舱的值班修士报完数据后停了一下——然后加了一句他自己想说的话，"刀总指挥——你昨天让我们反复练习的紧急跳速流程——我们现在能在三分钟内完成。比标准流程快两分半。"

"谁让你多加最后那半句话的？"

引擎舱沉默了——值班修士以为自己违反了什么训练纪律。

"加得好。"刀疤在广播里说。

舰桥里的小王抬起头看了刀疤一眼。他知道这句话意味着什么。在严格的军事化训练中——一个下级的主动改进如果被指挥官认可，会在心理上产生极强大的激励效果。这种人性反应超出程序的范畴——但它对战斗力的加成可能比任何程序优化都更大。

演练正式开始。

冥王号从小行星带的指定起点出发——模拟遭遇一支中等规模的敌舰编队。敌舰编队不是真实的——是小王在冥河系统中生成的虚拟敌人。虚拟舰队的参数完全参照金锋帝国目前的舰艇设计参数：四十五艘轻型突击舰、六艘重型战列舰、一套钳形合围阵。火力覆盖范围、舰艇机动速度、灵气护盾承受力——每一项都按照真实数据精确到个位数。

"敌舰接触。距离——四十万公里。预计交火还有十七秒。"

刀疤的指令在舰桥里回荡:"舰首冥气主炮——全功率充能。目标——敌方最前排四艘突击舰的连接处。"

"连接处？"炮手犹豫了半秒。他下意识地想打指挥舰——军人的惯例是先打旗舰。

"我说的是连接处。"

冥王号的主炮第一次模拟齐射。冥气光束穿越模拟战场，精确轰击在虚拟敌方舰队前排四艘突击舰之间最薄弱的连接处。那一发打中了。虚拟现实中，四艘突击舰的灵气护盾在连接处的重叠覆盖区域出现了间隙。四艘舰艇在互相支援的护盾重叠部位，被冥王的主炮轰了个正着。

"一发四残。"小王在冥河系统里实时反馈战果。他的声音比他平时说话高了半度——不是紧张，是模拟结果的数据让他难以克制地兴奋，"敌人的阵型依赖重叠护盾——他们在不同舰艇之间的支援协防机制高度强于我们，但连接处的护盾厚度如果能有足够的火力足以打出缺口。你的策略——不打旗舰——打他们的结构弱点。"

"不是我的策略。"刀疤纠正道，"是你们冥河系统刚才生成的战术方案。"

"是我们。"

演练继续进行。在六十秒密集交火中，冥王号按照刀疤的指挥——维持了一道精确到角度偏差不超过零点三度的航线。他让全体船员始终沿着敌方舰队护盾覆盖的视野盲区边缘航行。这个航线的确定既依赖于他本人的战斗直觉，也依赖于冥河系统的实时算路。刀疤在看战术推演图时，有一种敏锐得吓人的能力——他能在几十个不同的航线方案中，瞬间挑出造成敌方配合最混乱的那一条。

六十秒后，虚拟战场数据显示：敌方四十五艘突击舰中损毁二十艘、重创十二艘。六艘重型战列舰中三艘被击穿护盾。而冥王号全程未被击中任何一次。不是因为它护盾够厚——而是因为刀疤的航线选择让它的移动方向和加速时机始终保持着全频段持续扰动的状态，敌方所有防空跟踪系统都难以预判它下一秒会出现在什么位置。这种飞行风格在所有常规舰队战术手册中都不合法——因为常规舰队有编队、有阵型、有固定的航道。而刀疤完全不按阵型走。他把冥王号当做一艘只能在一侧和单一俯仰角同时开火的重型突击舰来操作。

"报告损失。"

"零。全部人员到位。舰体无损。"

刀疤下达结束演练的指令。广播系统中传来他简短而有力的三秒总结:"还行。明天再来一轮。"

人群散去后，李长生走上舰桥。他站在刀疤旁边，看着屏幕上反复回放的模拟交火数据。

"你训练出来的这艘船——已经和三个月前我带你们去月球上捡冥王记忆碎片的时候不一样了。"

"你还记得那天在战壕里说的话吗？"

"我说了什么？"

"让我记住世界上还有比我更强的——以后遇事不要以为自己天下无敌。"

"你一直记着？"

"记着。"刀疤盯着屏幕。他的声音里忽然有了一种不像军人的平静，"你现在已经不是那个在地里挖碎片的农民了。你是冥王。但在我这里——你永远是李长生。我指挥这艘船，不为冥王打仗。我替李长生打仗——他是我战友。"

掌心冥王令脉动了一下。李长生没有说话。他不是那种会说感谢谁的人——但他看着刀疤，眼神里有一种不常在这位前特种兵身上读到的温度。他有这么一群老兄弟，每个人从不同的起点走到了这艘船上——程序员、快递员、军人、律师、厨师。不是修真界的顶级天才——却把地球建成了宇宙中最可怕的军事力量。

"明天继续训。"李长生转身离开舰桥。在下层通道的电梯口，他回了刀疤一句，"后天出发前——把演练数据整理加密发到全银河公开频道。让金锋帝看看。让他准备。"

"没问题。"

（第371章完）

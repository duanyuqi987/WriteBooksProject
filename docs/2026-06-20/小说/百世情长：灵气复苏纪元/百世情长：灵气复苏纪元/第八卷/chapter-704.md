# 第七百零四章 苏晚返回地面

苏晚从上界返回地面的那天，太湖中心岛的飞升之门通道口站满了人。

石头——现在已是二十二岁——站在通道口最前面。他的个子和林牧差不多高了，肩膀比小时候宽了很多。他手里端着一碗热粥——桂花红豆薏仁。这是他等苏晚回来的方式——不用说话。

苏晚从通道中走出来时，地面上的一切看起来既熟悉又变得更新。灯火塔比以前更高了——加了一层观测台。灵网中继站的外墙上爬满了顾小桐种的忍冬藤。飞升之门广场的石碑上刻的名字已经扩展到了最外圈——新飞升的人名还在不停地增加。太湖散修联盟的厨房大妈们还在灶台边忙活——为首的大妈已经快七十岁了，但烧火的姿势还是和多年前一样。

石头把那碗粥递给苏晚。"桂花是今早上现摘的。——和很多年前你给林叔盛的一样。"

苏晚接过碗。粥是烫的。她用勺子搅了一下——米的颗粒完整饱满，桂花瓣点缀其间。她喝了一口——甜度刚好。石头的熬粥技术已经和她一样准确了。她抬头看着他——这个曾经四岁被遗弃在山门口的孩子，现在是九州桂花园总院长。他的眼神已经不再有任何被遗弃的阴影——他看人的时候有一种林牧式的安静和温暖。

"林叔怎么没回来？"石头问。

"他在上界——在探门。他的梦想和我的方向不一样——但我们在互相支持。"苏晚把粥喝完，把碗放回石头手里。"地面上的事——由我和你还有叶小雨、顾小桐来做。他在上面铺路——我们在下面砌墙。"

石头接过空碗——碗底还有桂花瓣贴在白瓷上。他低头看了一眼，然后把碗放在灶台边。他转过身面对苏晚时，他的嘴角有一个极淡的弧——是那个曾经躲在桂花树下看着林牧剪枝的孩子的笑。

"那就是第八卷——相互支持。"

（第七百零四章 完）

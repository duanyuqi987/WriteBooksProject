# 《百世情长：灵气复苏纪元》大纲

## 全书主线

建国100年，千年灵气禁制解除。前世青云宗第一天才林牧重生为IT程序员，在灵气复苏的世界里重新踏上修仙之路。他与挚爱苏晚历经百世轮回、十种关系境界，最终携手飞升。

## 人物弧线

- **林牧**：起点——隐忍克制的普通程序员，前世记忆碎片闪现；关键变化——灵气复苏后逐渐觉醒前世修为与记忆；终点（第一卷）——确认苏晚即百世挚爱，开始修炼之路
- **苏晚**：起点——普通公司财务，资质平凡但内心坚韧；关键变化——发现上古情缘契约残文，感知到异常；终点（第一卷）——与林牧相识，命运之线重新连接

# 第三十五章 可乐和全家桶

寒假前，我回了一趟青河。

不是放假，是学院组织实践活动结束后有两天空。楚州到青河不远，我临时买了车票。到县城时，天已经黑了，车站外面还和以前一样乱。出租车司机喊人，小摊卖烤肠，路边音像店放着过时的流行歌。

冬天的青河比楚州冷。

风从街口吹过来，带着河水的潮气。车站门口的路灯坏了一盏，灯光一闪一闪。卖烤肠的老板还是以前那个，围着油亮的围裙，手里拿着刷子。我拖着包站在路边，突然有一种时间没有走远的错觉。

可我知道它走了。

我已经不是县一中的学生。沈安晴也不是坐在第二排靠窗的女生。我们各自去了大学，各自认识了新的人。青河还在原地，可我们不是从前的人了。

沈安晴也回来了。

她在 QQ 上说，家里有事，请了两天假。我们聊到这里时都停了一下。青河这么小，两个都回来的人，不见面反而更像刻意。

最后是她问：

要不要出来坐坐？

我看着这句话很久。

回：

好。

我们约在县城商业街的德克士。

那家店高中时就在。红色招牌，玻璃门，门口贴着套餐海报。冬天的晚上，店里人不多，暖气开得很足。我到的时候，沈安晴已经坐在靠窗的位置，面前放着一杯可乐。

她剪短了一点头发。

不是很短，只是比高中时利落。穿着浅灰色外套，围着围巾。她看见我，抬手招了一下。

“你来得挺快。”

“车站离这不远。”

我坐下，手不知道往哪放。

她把菜单推给我：“你吃吗？”

“都行。”

她笑：“你还是这么都行。”

这句话让我心里一软。

高中时我也常说都行。去哪儿都行，吃什么都行，要不要参加活动都行。那时候我以为这叫不麻烦别人。后来才知道，很多“都行”其实是把选择推给别人，也把自己藏起来。沈安晴以前没拆穿我。今天她一句话，就把旧毛病从桌底下拎了出来。

我看着菜单上的套餐图。鸡翅、汉堡、可乐，被灯照得很亮。高中时我们从校门口经过这家店，里面坐着穿便服的学生，我总觉得那是另一种生活。能在周末坐进德克士，点一份全家桶，慢慢吃，不急着回晚自习。那时候这点愿望都很大。

现在愿望实现得太迟，已经没人知道该怎么高兴。

最后我们点了一个全家桶。其实两个人吃有点多，但高中时我们总觉得全家桶是很大的东西，像只有一群人才配点。现在点了，反而不知道从哪块鸡开始拿。

沈安晴拿了一根薯条。

“大学怎么样？”

“还行。”

她看着我。

我改口：“挺好的。课不算多，室友也还行。”

“写诗吗？”

“写。”

“还是很难听？”

我笑了：“你也学会损人了？”

她低头笑了一下。

我们聊学校，聊青河，聊高中老师。她说高一那个物理老师好像调走了。她说叶蓁在省城读护理，天天抱怨背书。她说海边冬天风很大，吹得人脸疼。

我说楚州梧桐叶掉得很多。

这些话都很安全。

安全到让人难过。

全家桶吃到一半，她忽然问：“你最近是不是认识了新朋友？”

我手里的可乐杯停住。

“嗯。”

“女生？”

她问得很平静。

我看着杯盖上的吸管。

“嗯。”

她点点头，没有追问。

我反而慌了。

“就是同学。一起做展示，后来常去图书馆。”

她说：“挺好的。”

挺好的。

这三个字让我心里发闷。

我说：“你别误会。”

她抬头看我：“我误会什么？”

我答不上来。

是啊，她误会什么？我们不是恋人。她没有答应我，也没有要求我等她。我和唐青禾一起去图书馆，吃关东煮，改稿。严格说，没有任何对不起她的地方。

可我就是心虚。

沈安晴拿起可乐，喝了一口。

“林予怀，其实你不用跟我解释这个。”

这句话很轻。

我却听出很远。

“为什么？”

她看着窗外。商业街的灯映在玻璃上，外面有人骑电动车经过，车灯晃了一下。

“因为我没有给过你一个确定答案。”她说，“我也不应该让你一直等。”

我心里像被拧了一下。

“我愿意等。”

这句话出来得太快。

她看向我，眼神里有一种说不出的疲惫。

“可是你等得不开心。”

我说：“等本来就不会开心。”

她摇头。

“那就不对。”

店里广播放着一首旧歌。我听不清歌词，只听见鼓点很慢。桌上的炸鸡已经凉了一点，薯条软了。高中时我以为成年后的谈话会更勇敢。后来发现，成年只是让人更会说不完整的话。

沈安晴说：“我不是不珍惜你。真的。”

我低头。

“我知道。”

“但我不想你以后回头看，觉得这几年都耗在我身上。”

我想笑。

“你看，又是为我好。”

她沉默。

我知道自己又把话说重了。

“对不起。”我说。

她摇头：“没事。”

这个没事和电话后的没事不一样。那次像关门，这次像她把门按住，不想让它摔得太响。

我拿起一块鸡翅，咬了一口，发现已经凉了。油腻味贴在舌头上，咽下去有点艰难。沈安晴把纸巾推给我。

“唐青禾是个什么样的人？”她问。

我没想到她还会继续这个话题。

“很吵。”我说。

沈安晴笑：“听起来不像缺点。”

“是优点，也是缺点。”

“她对你好？”

我低头看桌面。

“她对很多人都挺好。”

“你又在躲。”沈安晴说。

我愣住。

她看着我，语气不重：“你以前也这样。别人问你要什么，你就说都行。别人问你难不难受，你就说没有。现在问你一个女生对你好不好，你又说她对很多人都好。”

我被她说得说不出话。

她说：“林予怀，你不能一直把自己放在一个不用选择的位置。”

这句话比“为你好”更让我难受。

因为它更准。

我想反驳。

想说我一直在选择。我选择中文系，选择楚州，选择没有跟着她去南方，选择在她说慢一点后还留在原地。可话没出口，我自己先觉得站不住。那些选择里，有多少是真的为自己选的？有多少是为了让自己看起来体面一点，为了以后能说一句“我已经尽力了”？

我对沈安晴的深情里，藏着很多不敢承认的东西。

藏着“你看我都这样了”的委屈，藏着“你应该知道”的要求，藏着“我没逼你但我等你”的压力。它们穿着喜欢的衣服，站在我心里，装得很无辜。

沈安晴用吸管搅了一下可乐。

“我以前也不知道该怎么说。”她说，“你对我很好，我知道。可有时候你越好，我越怕。我怕自己接不住，又怕一松手你会摔得很重。”

我喉咙发紧。

她看着桌面：“所以我说慢一点。那句话不完全是为你好，也是为我自己。这样说可能很自私，但我那时候真的不知道怎么办。”

我第一次听见她把“为我自己”说出口。

原来她也不是站在高处替我安排。她也只是一个被感情推到墙角的人，想找一条不会伤人太狠的路。只是人和人之间常常这样，一个人以为自己在减少伤害，另一个人却在那条缝里疼了很久。

我们又坐了一会儿。全家桶没有吃完，可乐杯外面全是水珠。她说家里人还在等，得先回去。我说好。

出门时，外面很冷。

我们站在路边。她把围巾往上拉了拉。

“那个女生，”她说，“如果她对你好，你也别总躲。”

我看着她。

“沈安晴。”

她说：“我不是把你推给别人。我只是觉得，你应该试着过自己的生活。”

我没有接。

一辆出租车停在路边，她上车前回头看了我一眼。

“别总把自己关在过去。”

车门关上。

我站在德克士门口，手里还拿着没喝完的可乐。

杯子很凉。

凉得像一个答案。

我没有立刻走。

玻璃门里，服务员正在收桌。我们没吃完的鸡块被倒进垃圾桶，可乐杯被捏扁。刚才那些不好说出口的话，就在那里发生过。几分钟后，桌面会被擦干净，下一对人会坐下，也许是同学，也许是情侣，也许只是两个饿了的人。

德克士不会记得我们。

青河也不会。

这让我有点难过，又有点轻松。以前我总希望世界替我保存证据，保存我喜欢过谁，等过谁，在哪里说过哪句话。可世界太忙了。它只负责开门、关门、亮灯、熄灯。剩下的东西，如果我自己不肯放好，就会一直乱在心里。

回家路上，我经过县一中后门。

门关着，保安室里亮着灯。街边文具店还开着，门口挂着一排中性笔，风一吹就晃。我站了一会儿，忽然想起高考后那个上午，沈安晴把同学录递给我，我在走廊里说我喜欢你。

那句话是真的。

今晚德克士里的每一句也是真的。

人最难受的地方，可能不是分不清真假。

是几件真的事放在一起，谁也不能替谁让路。

那天晚上回到家，我妈已经睡了。客厅里只留了一盏小灯，桌上扣着一碗饭。她知道我回来得晚，没问我去哪儿，也没问我见了谁。家里这种沉默和宿舍不一样，它带着旧家具的味道，带着县城冬夜的冷。

我把饭放进微波炉，听机器转动的声音。

手机亮了一下。

唐青禾发来：

到家没？

我回：

到了。

她问：

青河冷吗？

我看着窗外黑下去的街。

回：

冷。

她发：

那你多穿点，别文学男硬扛。

我笑了一下。

笑完以后，又觉得心里发酸。

沈安晴让我试着过自己的生活。唐青禾正在我的生活里发来一条很普通的消息。普通到没有承诺，没有追问，也没有答案。

我那时还不懂，生活往往就是从这种普通的消息里，把人一点一点往前推。

# 第400章 帝国的遗言

档案馆的下层没有被灭迹攻击破坏。通往地下的通道入口被一块从上方坍塌落下的金属墙板完全堵死了——这可能救了它。灭迹攻击是从轨道上打的，攻击面集中在建筑上层。下层的结构被埋在废墟下面，逃过了后续的清扫。

小王用灵符引擎生成了地下结构的三维透视图——地下共有九层。每一层的高度是一百丈。九层加起来的深度接近三千丈。这个深度超过了地球上最高的建筑——而且它是在一万年前用纯修仙手段建造的。

入口被李长生用冥王令融掉了。黑色的冥气像腐蚀剂一样把金属墙板一层一层地分解——不是烧掉，是让它"归回"了原始的分子状态。铁、镍、铬、钛——每一种金属元素被分离开来，重新变成了独立的原子。

下行通道的楼梯保存完好。踏上一万年前的金属阶梯时，陈霜忽然停下了脚步。她的手摸到了一行刻在通道侧壁上的小字——字很小，像是用首饰上的金属尖端刻的。字迹歪歪扭扭，刻字的人显然不是文书——可能是保洁工、可能是维修技师、可能是当天晚上值夜班的普通档案管理员。

"他们来了。"

就四个字。没有署名。没有日期。没有修饰。一个人在灭迹攻击落到头顶的前几秒——在楼梯侧壁上刻下了这四个字。他刻完之后可能只活了几秒钟。但他刻下来的这四个字在一万年后的今天被一个三十岁的地球女人读到了。

陈霜把手指从那行字上收回来，没有说什么。继续往下走。

地下一层是公共档案室。一排排金属书架从地面一直延伸到天花板——每一层书架的长度超过一里，上面排满了赤焰晶石制成的档案卷轴。这些卷轴是火焰帝国赠予上古修仙帝国的官方文书——使用的是和火焰帝国官方卷轴相同的材料和相同的文书格式。但这里所有的卷轴都不完整——每一卷都被拦腰削去了一半。灭迹攻击虽然只削到了地面以上的建筑，但它的法则穿透力穿透了三千丈的岩层，把地下室前半部分的档案全部从法则层面抹掉了。书架上的卷轴前半段还在，后半段内容被法则力直接抹去——烙痕还在，但上面一个字都没有。像是有人用一块橡皮从纸上擦掉了一半的铅笔字迹。

地下二层是地图室。一整面墙上保留着一幅完整的银河系行政划分图——冥王时代的划分。这幅地图保存得非常完整——因为它刻在墙上，法则攻击在穿透到这一层时已经被上层吸收了大部分威力。地图上标出了银河系的十二个大区——每一个大区都有帝者级别的行政官负责管理。在银河西部的大区里——也就是他们现在脚踩的这片星域——地图上标注着一个被圆圈圈起来的行星：观星枢纽。这个行星就是他们现在脚下的这颗。

地下三层是记录室。这层的档案是手写的日记——不是行政官员的正式记录，而是普通工作人员的个人日志。小王翻开了最靠近门口的一卷。日志的开头写的是："今天是建星枢纽的第三百年。我负责保养南墙上那个报时阵法。阵法是老式的冥刻计时器——每隔冥刻报一次。响了三十多万次了。我今天把它拆开清洗——发现里面有个小零件磨损了。库房没有备件了。只能自己磨一个。"

接下来一卷："磨好了。不如原装的标准但够用。明天继续洗北墙的。"

再接下来："北墙上那面旗今天被风吹掉了一次。我爬上去重新挂好。旗子是冥王的令旗——黑色底，暗金色纹。挂了一万年了布料还没坏。就是穿绳子的金属环生锈了。我去库房找了一圈没找到替换的。明天用自己带来的铜丝缠一下。"

普通的维护工人。一万年前的普通人。他在一颗远离地球的银河西部行星上修阵法、补旗子、磨零件。他的文字里没有帝者、没有神明、没有战争。他的烦恼是库房缺了一个零件和自己带来的铜丝够不够用。

然后——在三百年后的某一天——日志忽然断了。最后一篇日志的字迹比前面所有篇都潦草——它像是人蹲在墙角飞快写的——而它说的内容是："上面通知说——要来了。所有人必须走。我不能把报时阵法带走。我把它调成了静音——让它在冥刻整点的时候只亮灯不响铃。它还会继续报时——报很多年。等回不来的人回来。"

日志从中间断掉了。后面没有再续。小王合上了卷轴。

地下四层到地下九层是空的。不是被灭迹攻击毁了——是本来就没放东西。这六层修建好之后从未被使用过——因为它们是为一个已经不存在了的未来准备的。

档案室建这么大——是把后半部分的档案位置留给了帝国未来会产生的所有行政记录。帝国规划中的存续时间是四十万年。但它在建成的第三百年就被灭了。

李长生从地下一层一直走到地下九层。他站在九层最深处的空荡大厅中央，掌心冥王令的光芒照在四面空白的金属墙上。这座档案馆的主人曾以为它会把四十万年的历史装进去——而现在它只装了三百年的记录，剩下的空墙在一万年后等来了一群比它规划中的未来晚了九千七百年的到访者。

"走吧。"李长生说。

他往回走的时候，在九层的最后一堵空墙上刻了一行字。用冥王令的尖端刻的——简体中文。

"三千零一十六年——后继者已至。帝国未灭。"

（第400章完）

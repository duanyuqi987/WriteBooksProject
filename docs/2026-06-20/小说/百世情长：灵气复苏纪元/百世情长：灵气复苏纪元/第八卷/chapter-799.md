# 第七百九十九章 第一百世的桂花

初夏。母树在母树平原上第一次结出了带种子的桂花——不是花瓣，是完整的种子。秦无夜把它们小心翼翼地收好——分送给每个分院和每个区域的灯火节点。附言——"母树说——可以种了。——秦无夜。"林牧回复——"不是母树说的——是你说的。但母树同意。——林牧。"母树之籽被种在了太湖灯火塔下、蜀山共容碑边、东海渔村灶台前、北境雪原城魔修茶馆天井、每一个桂花园分院的灶台旁边。每一处种植时都埋了一小张来自便签板的原笔迹纸条——作为种子基肥的一部分。

石头在自己院中当年折断后又愈合的那根老断枝底下，亲手种了最特别的一颗种子。他种之前挖开浅土——那包用油纸裹着的林牧最早便签的复印版仍在地下——和种子同样的坐标——一个在上面，一个在下面。他在新填的土上没放任何标记——只在石凳旁的旧木牌下添了一行渐已褪色的小字——"今天种了。——石头。"

小米在灶台日志中写道——"今天是第一百世的桂花。先前的桂花是百世之间的陪衬。——今天起——桂花将以自己的身份开。——小米。"

（第七百九十九章 完）

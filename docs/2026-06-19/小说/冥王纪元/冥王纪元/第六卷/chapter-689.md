# 第689章 血脉的延续

处理完王宇和陈大勇之后，李长生用了很长的时间，把每一个旧纪元伙伴的血脉都做了延续处理。

许冰——那个在法庭上从不退让的女律师。她在旧纪元帝国最高法院的任期内，审结了超过两万件战犯案件和八万件民间纠纷。没有一起案件是她不负责任判下来的。她为此付出的代价是：视力在七十岁之后急剧下降，每天靠灵丹维持精力，从来不谈恋爱不生孩子——她说"帝国就是我养大的孩子"。她死在办公室里，法槌还握在手里。李长生把她的天赋——对规则和公正的超常敏感——编码为"许冰因子"，将在新纪元的未来人类中激活那些天生有正义感、能在复杂利益纠纷中坚持原则的人。

刀疤——那个脸上有条刀疤的退伍军人体修。他一生没有结婚，把全部精力投入禁卫军训练。他带出了帝国禁卫军整整三十代体修精英，其中包括七个后来进入帝级的超级修士。死的时候他在禁卫军训练营的格斗场上，正在给新兵演示一个反关节锁技，忽然就倒下了。李长生把刀疤的体修天赋——对身体结构和力量运用的超常直觉——编码为"刀疤因子"，留在新纪元人类的体能基因池中。

厨师小胖——帝国最好的灵膳宗师。他做的灵膳不仅能提升修为，还能治愈精神损伤。在帝国三年大饥荒期间，小胖带着三百个徒弟靠着极端稀缺的原料养活了前线一个军的修士。他死在厨房里，手里捏着一根葱。李长生把他的天赋——对食材属性及其组合效果的精确记忆力——编码为"小胖因子"。

地质工程师老马——他的土系天赋让他在帝国基建中扮演了无可替代的角色。他设计并督导建造了六万座灵脉节点的稳定提取设施，实现了帝国灵气的永续开采。死在工程验收的路上，山体滑坡埋了半条路，他推开别人自己没逃掉。李长生把老马的天赋编码为"老马因子"——未来那些能感知大地结构、理解地质流转的人，将是他的继承人。

护士林晓——灵医学体系的创始人。她提出的"经络灵视诊断法"成为旧纪元最伟大的医学突破，让灵气治疗进入了科学化、标准化的时代。她在九十二岁时死在一间医疗室里，还在给一个新入门的灵医示范如何在灵气不足的情况下维持病人的经络畅通。李长生把她的灵医天赋——对生命体内能量流动的直觉感知——编码为"林晓因子"。

还有龟相。

龟相——那只在万年前侍奉冥王的万年老龟。在旧纪元的最末期，它终于耗尽了寿元，化作湖底一块玄武石。但它临终前把身上刻满的七十二重冥界大阵全部默写进了一本厚重的灵兽皮卷中，交给了帝国阵法学院。李长生没有为龟相编码基因——龟相没有后代的概念。但他做了一件别的事：在纪念馆中，给龟相建了一座独立的祠堂。祠堂中央放着一块原始玄武石，上面刻着从龟相龟壳上描摹下来的多重大阵图。祠堂门口写着——

"龟相。玄武第三十七代后裔。冥王殿太阴内相，万年冥王侍从。他活了一万两千年，其中有超过一万年都在等待。"

处理完所有这些伙伴的血脉延续，李长生做了一个决定：把这些"因子"的分布范围从太阳系扩展到新纪元宇宙中所有具有人类潜质的生命发源地。他不敢保证所有因子都能被激活——生命的随机性太大了。但他能保证，一旦条件合适，这些因子的激活概率远高于自然突变。

这些旧纪元的伙伴没法再跟他说一句话。但他们的天赋能以另一种方式——以融入人类基因库的方式——在新纪元的人类身上重现。

这不是转世。这是比转世更根本的延续——不是灵魂的延续，而是存在的延续。那些最美好的人类品质，被编码进了生命的河流。

（第689章完）

# 第690章 冥王帝国的重建

血脉延续完毕。纪念馆建成。新纪元生命已经起步。现在到了重建帝国的时候。

这个决定李长生想了很久。

帝国这个东西，在旧纪元曾是万恶之源——侵略、剥削、镇压、独裁——几乎所有文明都把帝国跟"恶政"划等号。李长生在纪念馆翻阅一千二百个文明的档案时，有一半以上的文明灭绝原因里都出现了同一条：帝国内部的崩坏。那些帝国最初建立的时候往往也有过理想——统一的秩序、和平的边界、共享的繁荣。但权力这个东西有一种奇特的性质：只要它不给监督留足够大的门缝，它就会自己把门从里面焊死。焊死之后，理想蒸发，权力固化，帝国变成了它的创建者当初最厌恶的形状。

但李长生也知道，旧纪元最后的冥王帝国跟那些不是一回事。冥王帝国不是征服者建立的——是由被侵略之后联合起来的星域自愿组成的防御性政体。它不对外扩张，不压迫臣民，不搞种族歧视。它的存在目的只有两个：保护帝国所有成员不受外部威胁，并协调星域间的资源分配以减少内战。它还做了一件旧纪元其他帝国几乎都做不到的事：在战争结束之后主动进入"瘦身期"——帝国中枢把战时拥有的绝大部分极端权力交还给各星域，军队从战时的庞大编制大幅削减为防御编制。这不是被迫的——是李长生当初亲手签的命令。

但新纪元要不要复制这个模式？还是从零做更好的设计？

李长生想了很久。他反复翻阅许冰留下的法学笔记、王宇留下的系统架构设计论、老陈留下的基层治理报告——这些材料全部保存在纪念馆里，他随时可以调取。他最后得出的结论是：旧纪元冥王帝国的"精神"是对的——防御性、自愿性、非压迫性。但它的"结构"太过依赖李长生个人的判断和道德底线。如果他李长生不在了——或者说，如果他不在了而下一个继承者没有同样的道德底线——那这个结构就会塌。

所以新纪元的帝国会需要一个根本性的改进：让结构本身约束权力，而不是依赖掌权者的个人品德。

李长生最终决定——重建。但不是复制。冥王帝国将被重建为全新的形态。不再是"人类帝国"，而是"万族共约"。不再依赖皇权的品德，而是依赖制度和法典的约束力。不再是臣民和主君的上下等级，而是契约关系的双向绑定。

核心原则有四条：

一、冥王帝国的疆域是防卫性的。它不主动征服任何星域，不对外输出主义，也不搞殖民扩张。任何星域、文明、种族都可以自愿申请加入帝国，也可以在任何时候自由退出。帝国存在的唯一军事意义是防御外部的大规模威胁——不是对内防范，更不是威胁邻居。

二、冥王帝国的最高法律是《永恒法典》——这部法典正在由旧纪元许冰留下的法律遗产编纂。法典的基石条款是："修士不能欺压普通人。"这将作为帝国的宪法锚点——所有其他条款都从这里衍生。

三、冥王帝国不搞中央集权制。帝国中枢只负责三件事——防御、法典执行、跨界协调。其余所有事务：经济、文化、教育、环境保护、城市建设、科技研发——全部由各星域自治。帝国中枢无权干预各星域内部治理。

四、冥王帝国不设皇位世袭制。皇帝不是由血缘继承的，而是由帝国元老院从帝国最优秀、最有品德、最有担当的修士中推选产生。皇位任期以千年计，到期后必须在全帝国范围内接受公开评议，评议不通过则必须退位。这意味着皇权是有监督的、有期限的、有约束的。

这四条原则，李长生写进了帝国基本宪章的第一页。基本宪章不是石版——是一卷由纪念馆永恒材料制成的薄卷，展开约三米长，上面是用混沌之力刻录的文字，永不褪色。基本宪章的任何修改都必须经过全民公投——不是元老院投票，是全体公民一人一票。这个程序写死了——连皇帝本人也没法绕过。

第一条和第二条互为表里：帝国不扩张，但也不关门。想加入的文明可以自愿加入——条件是必须接受《永恒法典》的全部条款，包括"修士不能欺压普通人"。不接受这个条件的，帝国不逼它加入，但也不和它结成军事同盟——因为不尊重普通人的政权，最终都会崩坏，跟它结盟等于把帝国的安全绑在一条迟早要沉的船上。

第三条是李长生从旧纪元学到的最重要的制度教训。旧纪元绝大多数帝国的灭亡路径都是相同的：中央集权→权力固化→地方弱化→应对不力→崩溃。集中的权力在最开始时看起来高效——一声令下，全帝国统一行动。但统一的代价是地方失去了应对本地问题所必需的灵活性和决策权。久而久之，帝国中枢变成了所有矛盾的汇聚点——每条河的入海口都挤在一座大坝上，大坝必然撑不住。所以新纪元帝国从一开始就刻意削减中枢的权力边界——只保留防御、法典、协调三根柱子。其余的全归星域自管。

第四条——废世袭——是李长生最坚持的一条。他看过太多旧纪元因皇位继承而崩溃的例子。血缘继承帝王不是择优机制——是赌博。赌这个皇帝生出来的孩子不会是个暴君或废物。而大多数时候赌输了。元老院推举制度虽然效率低于世袭，但筛选机制远比血脉可靠。

这四条原则，李长生写进了帝国基本宪章的第一页。

然后他开始筹建新帝国的物质框架。

中央星域——他选择了靠近纪念馆的一整片空旷区域。纪念馆是旧纪元的过去，帝国中枢是新纪元的未来。这两座最重要的建筑彼此相望——从帝国的议会广场上抬头，就能看见远处纪念馆门口那盏永不熄灭的油灯。这个视觉上的呼应不是偶然：李长生要让每一个帝国官僚在上班路上都看到纪念馆的灯光，让那灯光提醒他们——旧纪元是怎么死的。

在这片虚空中，他牵引新宇宙的原始物质，建起了新帝国的中央星。这颗星不是行星，不是恒星——而是一块由混沌之力压缩而成的悬浮大陆。建造过程持续了约新纪元三十天——在这三十天中，李长生几乎没有离开这块大陆。他一块一块地牵引物质，一片一片地调整引力场和大气层。他坚持亲自动手——没有任何人帮他。不是不信任别人，而是他觉得帝国的地基必须由皇帝的手亲自铺。

大陆面积大约是旧纪元太阳系整个冥王星轨道的十二倍。大陆上有适宜的引力——跟旧纪元地球表面差不多的重力加速度，让人走路不累——可控制的大气厚度、四季转化的灵气循环系统。灵气循环被他设计成了天然的缓释系统——灵气从大陆地底的三千六百个节点缓缓渗出，随气流均匀扩散到整个大陆上空，浓度全天恒定，不随昼夜波动。

他给这颗中央星取名——"冥都"。

在冥都的中心，他建起了一座建筑群：帝国中枢。中枢不是宫殿，不是要塞——李长生死命令：中枢不允许建城墙，不允许设禁飞区，不允许在广场上布置任何武力检查岗。任何帝国公民只要到了冥都，就能自由走到中枢广场上，站在"以民为本"那四个字跟前。中枢是由六栋建筑组成的综合中心——皇宫、法典院、议会、军事指挥中心、跨文明联络处、历史数据馆。这六栋建筑围成一个圆，中间是一片所有人可以自由出入的广场。六栋建筑风格各不相同——但全部遵循同一个设计原则：透明度。皇宫的外墙是半透明的灵气水晶，法典院的大厅没有天花板（靠灵气场挡雨），议会的外墙是玻璃似的通透视窗——室内在讨论什么，室外的人看动作和氛围就能猜出来。

广场上也有一块碑。碑不大，高约三米，宽约一米半，材质是李长生特地从旧纪元地球的黄土地上运来的一块太行山青石。石上什么装饰都没有，只有四个凿出来的字——李长生亲自抡锤凿的。他没有用混沌之力来雕刻——他用了一把普通的刻石锤和凿子，蹲在碑前一锤一锤地敲了整整一天。凿出来的字不工整，笔画有粗有细，有几处凿重了留了深深的凿痕。但正是这些不工整的痕迹让看到碑的人立刻就明白——这四个字不是装饰，是承诺。不是书法家写上去的标语，是干活的人凿进去的诺言。

四个字："以民为本。"

这是冥王帝国在新纪元的第一块基石。没有黄金，没有宝石，没有神仙的法术加持——就一块普通的石头，上面刻着四个最朴素的字。石头的来源是旧纪元的地球——因为"以民为本"这四个字最初就是在地球的黄土地上被一群种地的、送快递的、敲代码的、做饭的、看病的、打官司的、挖矿的、打仗的普通人活出来的。这块石头来自他们脚下。

李长生把凿子和锤子放在碑的底座上——没拿走。他想让后来的人看到：凿碑的不是什么神仙，就是一个会蹲在地上干粗活的人。

（第690章完）

# 第三百零八章 以命相护

东海。凌晨两点。

林牧悬浮在舟山群岛以东的海面上空。脚下是黑得看不见底的海水。月亮在西边垂着，把银光薄薄地撒在海面上。海面很平静——不正常的那种平静。东海十月的风浪通常不小，但今晚的海面平得像一面黑镜子。没有浪。没有鱼跳。连海浪拍打礁石的声音都比平常少了一大半。

因为海底在裂开。

他的灵识网已经穿透了二百三十米的海水，停在了海底的一条裂缝上。裂缝的长度大概十五丈——和赵明远给的数据一致。但深度不对。赵明远说的是"深度大概二十米"。他现在探测到的深度是将近五十米。而且还在加深。裂缝深处涌出的不是岩浆——是一种紫色的、半透明的胶状物质。是"天膜"。是天魔七星阵的七个阵眼中每个都有的基础构筑物——一种由天魔意志操控的半液态空间壁垒。天膜的存在意味着这个阵眼已经被"种"下了——不是自然形成的裂缝，是阎锋的人从另一边用天膜捅开的。

他需要把天膜拔出来。然后在拔出的瞬间，用封印封住裂缝。

拔出天膜的原理和拔出地里的树根差不多。天膜在裂缝里扎了根——根是紫色的，比天膜本体更细，但更深。最深的根须可能已经伸进海床下几百米的岩层。硬拔会把整块海床拔塌——海底地震引发海啸，整个舟山群岛都会受影响。不能硬拔。需要先切断根须。

林牧深吸一口气。然后头朝下冲入海底。海水的凉意从四面八面裹来——不是普通的凉。海水里混了天魔气息，接触到皮肤时会引发一种麻痹感。他把灵力散布为薄薄的一层外衣——覆盖全身，隔绝海水接触。然后他降落到海底。踩在覆盖着细沙的玄武岩上。

天膜在二十步前竖立着。它看起来像一块从海底长出来的紫色礁石——但不规律地搏动着。活的。它的"根"顺着海底的岩缝往下扎，像一棵把根系撒进了地壳的树。林牧能感觉到它在"呼吸"——每次搏动，根就会往岩层深处再钻一点。它在依靠地脉灵气生长。

他的剑还在。但他不能用。这把剑要在中亚裂缝守阵眼。所以他用手。

他把两手插进天膜两侧的海底泥沙里。手臂埋到肘关节处。灵识顺着泥沙往下探——探到了第一条粗根。直径大概有人的手臂那么粗，位置在海底表面下约三米。他用灵识缠绕粗根，把灵力化为极其微细的利刃，从根的内侧往外切。灵力利刃切进根的髓心时，天膜剧烈地搏动了一下。海底的泥沙扬起一片灰雾。

然后是第二条。第三条。第四十七条。

他花了将近两个时辰。把天膜所有的粗根细根——包括那些伸进岩层深处的小细须——一根一根地切断。每切一根，天膜的搏动就弱一分。切到最后一根的时候，天膜彻底不动了。紫色的光暗了下来。它的身体开始从裂缝中脱落——像一块老藤从墙壁上脱落。

林牧在它脱落的那一刻，用双臂环住天膜的本体。粗。大概有两人合抱那么粗。重。非常重。天膜的密度远大于海水——它的内部含有从天魔世界带来的"浊质"，一种比重远高于铅的液态金属元素。他挺腰，用灵力把浊质的重量自身体分担——然后往上拉。

天膜动了。但不是被拉出来的——是它自己缩回去了。这是一种防御机制。天膜在感知到根系被摧毁后，会自动缩回天魔世界——把裂缝完全打开。阎锋的安排就是这么毒：你要破坏阵眼的天膜，行——但你一破坏，裂缝就直接全开。这就是一个陷阱：要么留着一座正在长成的阵眼，要么提前把它变成一道小型的完整裂缝。两种结果都对你的对手有利。

林牧知道这个陷阱。他之所以还来拔——是因为他不怕缝全开。他怕的是七眼齐开。东海这个眼提前全开了——七星阵就不完整了。只要不完整——就不构成抽干灵脉的威胁。

天膜完全缩回去了。裂缝在一瞬间张开了——从十五丈扩到近三十丈。暗紫色的光从裂缝里涌出来，把方圆几里的海水照成了深紫色。海底的水生生物——鱼群、海蟹、海藻——被紫光扫过的瞬间失去了颜色。不是死亡。是"空"了。

然后裂缝里钻出了第一只噬灵兽。

不是林牧在昆仑山谷里见到的那种"噬灵傀"——被傀儡化了的凡人。是纯种的噬灵兽。大概有两丈高。形态不算完全固定——像一头螳螂和无脸人的混合体。前肢是两把骨质的镰刀，身体的颜色是深海章鱼的那种暗褐——但表面覆盖着那层暗紫色的天魔气息薄膜。它的眼睛是全黑的——没有瞳孔、没有眼白、没有反射。

第二只。第三只。三只噬灵兽同时注意到了一个悬浮在海底前方二十步处的人类修士。

林牧没有拔剑。他把左手伸进海水——把海水本身的灵气"提取"出来。海水中的灵气含量不太高，但足够了。他把提取出的灵气在手心压缩成一个拳头大小的淡金色圆球——灵压球。然后他把圆球往前一推。圆球在水中飞了大概三步——然后爆炸。

爆炸没有火光。是纯灵压冲击。冲击波在海底扩出一个直径大约五十丈的球形真空区——把三只噬灵兽推到裂缝边缘的石壁上。但它们没死。它们的身体外层被天魔气息薄膜保护得很好——灵压冲击只能把它们推开，不能撕碎它们。

林牧在它们被推开的那个空档里，把手伸进裂缝。

他用的是左手——握剑的那只手。手心里那道旧剑痕在紫光里泛着银色的光芒。他用指尖在裂缝的边缘写了一道上界古符。写符的同时，他把灵识灌入符文字体——用他的灵魂层次作为封印的根基。裂缝开始缩小。从三十丈到二十五丈。从二十五丈到二十丈。但每缩一寸，他灵力就消耗一成。缩到十五丈的时候，他的灵力已经耗到了原来的一半——只剩三成。

还够封一下。但不划算。因为阎锋在裂缝那头——他感觉到阎锋的灵压在靠近。如果阎锋趁他灵力枯竭时打过来，他在海底跑不掉。

所以他做了一个合理的决定：退出海面。把裂缝搁在这个深度。留一个"半开"的阵眼——它不是闭的，所以不能完全阻断天膜重新种根；但它也不是全开的，因为裂缝不够宽，大型噬灵兽钻不出来。

他冲出水面的时候，天快亮了。晨光把东海染成了血橙色——不是太阳的颜色。是天顶偏北那颗暗星——它现在是紫色光带的核心——反射下来的光。血橙色的海面下，他看得见海底那道暗紫色的裂缝正在缓慢地扩大。

他拿出卫星电话。拨通赵明远。"东海——半封。暂时出不来的只有小噬灵兽。大型的卡住了——至少能卡七天。"

"中亚呢？"

"现在出发。"

"前辈——你已经耗光灵力了。歇一个时辰？"

"一个时辰太久了。"

"那半个时辰？"

林牧在血橙色的海面上空悬浮着。海风把他的头发吹乱了。他的头发上还滴着海水——灵压衣已经不完整了，有些地方渗了海水进来。海水里的天魔气息顺着头发往下渗，滴在他脸颊上。凉。但他不在乎。

"十五分钟。"他说。"够我给这把剑做最后一次保养了。"

他挂了电话。把剑从剑鞘里抽出来。在海面上，他把剑横在膝上，用储物袋里最后一点保养油擦拭剑身。三道裂纹在晨光里闪着淡淡的金光。每一道裂纹都是他的灵力通道。这条通道养了十二年。现在它要永远留在天山的一个裂缝阵眼里了。

他把剑身擦干净。把保养油瓶子拧紧，放回储物袋。然后把剑横在额前——额头碰剑柄。一个修士对待灵剑的最高礼。不是因为剑是死物。是因为他知道，灵剑如有灵——一定会感知到他此刻的决定。剑不会怪他的。剑是在守护万物。这是剑的本愿。

十五分钟到了。他把剑收回剑鞘。往西飞去。

中亚天山南麓的裂缝在当天下午被成功封住了。

林牧没有用剑封——他发现裂缝还没有扎下天膜。这意味着阎锋的资源不足以同时在所有七个眼上种天膜。中亚这个眼是空的。空的裂缝可以用普通的封印封住——不需要剑。他把剑留下了。然后把裂缝用四层精血封印封住。精度比东海更高——裂缝缩到了不到三丈。三天内不会再开。

封完之后他坐在天山山腰的一块石头上，拿出卫星电话。拨给赵明远。

"中亚——封了。东海半封。现在还剩昆仑、长白山、秦岭、青藏高原、南海——五个已经种了天膜的裂缝。你们负责四眼。我负责昆仑。"

"前辈——昆仑那个阎锋——你有多少把握？"

"多少把握不重要。"林牧说。"重要的是我到了。我到了，他就得先看我。看我的时候，他就不看你们。你们就可以先把你们的仗打完。记住一件事——不管昆仑那边发生什么、不管天上多亮多暗、不管我的灵力信号在灵识网里有没有消失——都不要分神来帮我。你们的任务是关你们的眼。你们关了四眼——他的七星阵就废掉了。他的七星阵一废——他就没有退路了。"

赵明远沉默了片刻。然后说："前辈——那你自己怎么办？"

"我要是回不来。"林牧说。然后停顿了一下。风从西边吹过来，把他的声音切成了两截。

"你就告诉蜀山上那个女人——这一世等得有点久。下一世。一定不等三百多年。"

然后他挂了电话。把卫星电话放进储物袋。站起来。看了最后一眼剑——剑还在。剑身的三道裂纹在阳光下亮得刺眼。

"走了。"

他对剑说——也对天山上那些看不见的风、雪和山上那些在裂缝附近瑟瑟发抖的土拨鼠说。然后他飞出天山——往东。

方向：昆仑。

目标：阎锋。

那个三百年前把他从玉阶上推下来的人。

# 第980章 百世的回音

极远极远纪元中——上界和下界的通道在无数年的演化中变得不再罕见。两界之间的"飞升"制度演变成了互通的常态——能飞升的人可以飞升，想回下界探亲的人也可以申请反向通道。双向通的机制全面铺开后，上下两界不再是隔绝的，而是同一个文明版图中的不同区域。

这种双向开放的直接根源可追溯到苏晚和林牧当年的太行传道堂——他们用道源第三形态和道心通讯协议拆除了上界对底层修士的恐惧，使上界意识到"让底层成长不威胁统治"——进而逐渐放弃了对下界的硬性隔离。这段历史在道纪院的正史中被表述为："下界太行书院与上界太行传道堂的跨世接力，最终导致全界实现了修仙教育的普惠统一和灵力边界的全消除。"

苏晚在某次翻阅史书时看到自己的名字再次出现——这一回不是教科书，是正史。她的第一反应仍然是："不全是我的功劳——是林牧打开了反向通道。"林牧站在她身后翻着同一页说："是你开的书院让他有了想打开通道的理由。"两人对视——都笑了。互相把"功劳"往对方身上推的习惯，几万年没变。

那天下午他们和老鹤（念初的第若干代外孙）一起去太初之城的公共道场散步。道场上正在进行一场由传道堂学员自主组织的"上界-下界联合道启交流会"——两界新生代导师通过灵讯水晶实时交流教学经验。交流信号穿过星云中心的暗点——信号延迟约半息（因为极微的法则转化），不影响交流流畅度。苏晚和林牧在道场外围坐了一会儿——看着两边的年轻导师们在讨论"如何让筑基期学生不因失败而自弃"、"如何帮一个从来没摸过灵气的成年人建立第一缕丹田感知"——这些她们在太行第一课上讨论过的微观教学法经过数万年的进化依然在生生繁衍。

"你最初希望看到的是这个吗？"林牧问。

"不——我最开始只希望有一间不收钱的小教室——能容下陈小树、钟大爷就够了。后面这些都是他们自己做的。"

傍晚回到院中——苏晚把那篇残稿"不收墙"的仿制品（修复师做的还原版）挂在老墙上青苔最浓的位置——她想让新来的学员看到"不收墙"这三个字的时候——知道那句源头的笔误也是善。苍宇间的善——往往发生在一个笔误、一颗萝卜、半块凉红薯、一片银杏叶在纳戒中安静躺过数万年的默契之中。

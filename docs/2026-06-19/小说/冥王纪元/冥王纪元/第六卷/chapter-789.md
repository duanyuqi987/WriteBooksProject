# 第789章 可以创建一个临时的通道——通往混沌本体

封禁层参数被成功修改的那一天起，所有人都松了一口气。混沌本体不会再因为外部唤醒而苏醒——全宇宙重新获得了长期的安全。帝国的十二座磐石加固站从赛跑抢工转为长期维护，封玄在工程转段后，第一次在自己的小屋里安静地睡了一夜——睡了整整十二个小时。

他的园子里黄瓜长得很高了。藤蔓爬到竹架上，密密匝匝的叶子在阳光下翻涌着一层蜡般的光泽。他每天下午会坐在藤蔓下喝茶——那把李长生送他的破茶壶成了园中景物的一部分。他与冥离祖孙俩加上冥离那几个在帝国学院上学的儿女偶尔一起吃一顿晚饭，一碗拉面配两碟酱菜。一万纪元的水牢生活在他脸上的刻痕没有消退，但他的眼睛在坐在这盏小桌旁看着孩子们拌嘴时会笑。

但李长生没有放松多少。尽管混沌本体不会再被外部唤醒——但它仍然在沉睡。这个状态的本身并不稳定。太初在信息孤波发射成功后的第二天，以最后残存的跨界通讯能量对李长生说了一段话。

"混沌本体的自身无意识代谢——虽然没有感知外部刺激的触发了，但它内部自我循环的疲劳是永远存在的。任何处在沉睡设定中的存在体，在极长的时间尺度下，自身的存在惯性会逐渐消耗掉沉睡的深度。早晚有一天它会自己慢慢醒。而且这种内部苏醒不受外部感知参数制约——因为它的触发源是自己的内动力。"

"什么时候？"

"不知道。也许几个纪元，也许一百个纪元。也许更短。"

李长生坐了很久。然后他拿起通讯器，找来了王思远。他将太初的话告诉了王思远——王思远的反应很坦然，没有慌张。他推了推眼镜——镜片上短暂地反射出了操作面板上不断跃动的代码字符——然后回答:"所以它不是永久的。它只是被我们归零了感知触发，但自身的熵依然在缓慢积累。早晚还是要面对它。"

"有没有办法在任何时候提前阻止这种自我唤醒？"

"有——如果在混沌本体自身能量积累到临界点之前，有人能够进入封禁点——对内部进行极深层的有限释放——把积累的内能量在可控范围内排掉——像给气球放一点气。但要去那里就必须面对一个永久存在的事实：维度零点永远是不可进入的。刚才我们完成的所有源代码写入全部是由纯粹信息完成的——不是靠任何物质侵入。如果要由人自己进入封禁点——需要一个能够临时让物质存在通过维度零点的通道。"

"信息孤波的通道能放大吗？"

"理论上可以。孤波在烧毁前能在零点内部留下一段短暂的通道残留——极端短，大约持续几微秒——然后被自保子系统压制到关闭。如果在关闭之前——就在这几微秒内——将两个被编译成源代码格式的人的意识一起发送过去，冲过残留通道——理论上可以到达封禁点。"

"成功率多少？"

"我把所有模拟数据过了一遍——"他顿了顿——在操作台上进行最后几次估算——然后摘下眼镜，"百分之三十到四十。不能更高。"

"够了。就为这百分之四十建造一条通道。"

王思远沉默了极其短的时间。他没有问"谁去"——他知道李长生会自己去。而且他知道李长生会带上一个人——那个人已经在外面——在花园里修剪黄瓜。她叫陈霜。

于是源代码通道的第二期研究开始了。这一期不再是单纯的长期研究——而是两个人终生可能的最后一程。王思远没有把这项研究告诉任何别的人。李长生的原话是"不要给任何人增加不必要的希望。成功了，不必提前宣扬——失败了——不会有更多人知道。"

他在帝国科学院最隐秘的内部建造了一套完整的源代码编译通道测试系统。系统本身很小——只能容纳一枚灵符晶片的发射容器加上一套加载台。加载台是供李长生和陈霜将意识导出后上传到代码域的"暂时意识入口"——它的外观非常普通，是一张固定在实验室恒温环境里的普通灵能就诊床。床边还放着一杯茶和一些零食——是陈霜的。

通道的测试全程没有用到任何活体生命——全部由灵符模拟数据驱动。测试过程中，模拟意识在穿越残留通道后成功返回记录为始终是零——因为没有返回通道。任何穿过通道后的人都会永久留在维度零点中。这意味着去的人是单程票。有去无回。

李长生看着测试报告中那行"返回通道概率为零"。他没有说话。陈霜站在他身边，也看着那行字。她沉默了片刻——然后说了一句:"种地的人不一定会死在田里。但总是愿意被埋在土里。"

（第789章完）

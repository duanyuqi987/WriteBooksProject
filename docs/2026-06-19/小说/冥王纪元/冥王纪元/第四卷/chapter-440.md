# 第440章 李长生对十一位帝者，毫不退缩——以一敌十一

帝阵的第二轮发射在第十四分钟的节点准时到来。

太初帝者以微型宇宙球放出第二道锁禁光束——绝对灰色再次划破虚空。边荒防线在毫秒内承受了第二轮帝阵打击——这一次防线已有前一轮的经验。在前线所有帝者都同步调整了防护姿势——冰帝的两层冰壳在冲击前主动弃去外层，将两层合为一层极薄的超密冰系屏障，牺牲覆盖面积换取更高的单位承压比重。风帝不再硬扛——他把风场提前退后至防线内侧，给金石引力的空间弯曲效应预留了更多预处理距离。金石将引力透镜的截距增大到几乎极限，把进来的灰线从粗束散为更多极小细丝——然后老马的土系灵石轨道网格和炎烈的火网分区域消化了细丝——每一根细丝到达防线墙体时都被逐个湮灭。帝阵第二轮打击——防线的损伤程度只有第一轮的三成。

联盟的阵术师和帝者们也注意到这一点。天枢帝者的手臂长时间驭阵已经出现细微痉挛痕迹——阵旗以不正常的频率快速摆动——第三轮帝阵预计需要更久的时间校准而仓促之下阵盘间协同不稳定——但强行发射的战意很强——因为太初帝者在第二轮后无声传讯:'继续——不必冷却——冥王防御层的消耗也接近临界。'

而李长生就在这个关头顶了出来。不是因为他判断自己能赢——而是因为他判断对面阵盘的精度已经降到足够低——低到他可以以个人为饵做一件更关键的事:以自身作为靶子吸引帝阵残余火力——让防线上的四位帝者进行一段短暂的轮休。

他从防线前沿踏空走出。

诸天号在他身后发出持续的低啸——那是冥纹阵列以最高功率辅佐他周身冥气以达到最大化排放时发出的震动声响。他的冥王令全展开——九道暗金色纹路延展到极限——一万两千道冥纹以他为圆心向外扩散，在他周身五十米范围内构成一个致密的冥纹防护圆球。这球不是护盾——是一层将冥气与外界空间现实进行半隔离的微型领域。在领域内，太初之力的灰线接触到冥纹表面的瞬间会被冥系规则侵蚀转化——无法完成穿透转化——只能在球体表层不断湮灭不断补充——消耗冥气而非破坏结构。

他站在防线外——与联盟主力编队对峙的距离仅剩数公里——正面对着十四位帝者的阵线。

第一位对他动手的是斩空。空间断层在冥纹球表面连续切割——每一刀都撕出一片空间碎片——但冥气在碎片出现的瞬间就以逆向填缝补上。斩空的斩击很快，但冥气补得更快——在领域内，冥纹序列会自动预言斩击的下一个出刀轨迹并提前布置补丁。

第二位对他动手的是雷泽——帝者极怒。两张阵盘被毁的怒火此时全部贯入帝者级别的雷矛——同样的长矛这次在投出前蓄满了雷泽帝者的全力——目标并不是冥纹球本身——而是球体与防线之间的那一段空虚——他想切断李长生的退路并截断他与防线的能量联结。

但这意图被小王的河图提前三秒识别——小王对李长生的通讯中只说了三个字:"雷退路。"李长生在两个字入耳后，体后的冥纹分出——沿退路方向先行将空间粘合加固——雷矛撞在加固空间上被折射偏入深空没入无尽虚空中消失。

第三位、第四位同时出手——霜风和深空。霜风的霜寒在冥纹球表面形成霜冻壳——试图以持续零下数万度的低温让冥纹分子的热运动减缓进而降低冥纹阵的反应加补速度。深空的空间暗流从霜风中穿入将霜寒裹挟着射向冥纹球——空间负压使得霜寒直达率大增。两人合击让冥纹球内部的温度第一次跌到了零下。李长生在球内核内感到自己右肺被冻出了冰碴——他的呼吸卡住了半秒。他用冥气以自身血液为介质加温热——硬抗住了肺部的冰分——然后在胸口处将侵入的霜能量用冥王令吸出——转化成一股低压冷流从球身后方散出防止冷流继续环绕。

第五位帝者——天火——在霜风与深空牵制期间将火柱从上方贯入冥纹球顶部。超高温一亿度的火柱和超低温霜壳同时作用在冥纹球外壳——极致温差在球面产生了两股相互撕裂的大应力界——球体开始出现微小结构震荡。

"能量峰值接近冥纹球容限——"小王的声音从通讯频道中紧绷传来。

但李长生没有收回领域。他顶着冰火双极的热冷撕裂将冥王令的第九道纹路——冥王令所有纹路中的最终压纹——激活。第九纹路的特性是"能量反相":将一切侵蚀性外界能量以回溯方式反注入其原发射源。球面上那些从霜风、深空、天火而来的能量被第九纹路吸收并反向追踪回去——不到半秒回到三个帝者自己的掌心和灵根系中——反冲力量将他们推动向后退了数步——三帝的攻击暂时中断。

第六位、第七位——玄冥和青木。水纹和古木联合生成的束缚藤蔓——这是帝级空间束缚手段——水化藤蔓缠绕冥纹球并将水域与远古木系力量合二为一形成对冥气本身的"固水锁"。冥气被固封太久会散——因为冥气在本质上属于"暗"的一端，需要在空间内持续流通——固水锁像黏胶一样把领域外部锁定——领域能量流动速率逐步减缓。

李长生应对的办法是将冥纹球收缩——从直径五十米缩至五米——将一切体积缩小以换取更高的单位冥气流通强度——冥纹的紧密程度被提升到几乎所有帝者都无法想象的水平——固水锁被从内部撑裂。在球体缩小的同时——陈霜从防线上掠出到达他的左侧——霜降剑以全剑纹释放冰蓝剑气，将已经断裂的藤蔓残余结构全部切断。

第八位——苍明帝者——亲自出手。他以空间折叠术从母舰外瞬间出现在李长生上方，右手按在冥纹球的最高点——不是轰炸——是将冥纹球周围空间的整体压缩——用空间为武器，把冥纹连同里面的李长生挤压在一小块即将坍缩的空间格内。压缩持续的压力将冥纹球从五米进一步缩至一米五——冥纹表面已出现第一道可见裂像。

第九位、第十位——九幽帝者和斩空并肩切入。九幽从下方以亡灵术穿透冥纹——不是常规法术穿透——而是以负灵波逆向反转的形式将冥纹中的暗能属性暂时失活——这是鬼道最擅长的事。斩空同一时刻从顶方以断层斩砍向苍明压缩过的地方——两点共击——冥纹球即将破裂。

第十一位——太初帝者——没有释放新光波——而是从原初微型宇宙球中传出一句在所有帝者神识中同时回响的命令:"帝阵——即时重新校准——第三波锁禁——集中——精确——锁定李长生一人。"

他看出冥纹球被内外夹击到即将失稳的边界。第三波帝阵如果能瞄在最准确的毫秒击中即将裂开的冥纹球——锁禁将在球碎的一瞬间把李长生捕获。

冥纹球碎了。在周围十位帝者的联合压迫中裂开了口子——口子里能见李长生站在虚空中——冥纹碎片围绕他身体高速旋转——暗金色碎片反射着他脸上的光——额头上的一滴血正在飘落——那是承受万向压力时崩出的一根毛细血管吐出的极微小血量——但在真空中像一颗细暗的珠子缓慢滑过脸侧。他没有擦血。他甚至没有抬手。他只是站在所有那些帝者的正对面。

他的眼睛没有恐惧。甚至没有愤怒。就是一双从黄土地里长出来的人的眼睛——旱过一年又一年雨过一年又一年——然后终于在某一天站在全宇宙中央最强的阵法面前——看着对方——毫无动摇。

十一位帝者的攻势在即将触发第三轮帝阵时凝滞了一瞬。不是他们退却了。是他们算不出下一步。帝阵需要穿透一个空隙才能锁住这个人——而他没给自己留任何退路——也没有崩成任何空隙。他虽然一个人站在这——但在他的背后——整个边荒全防线上，冰、风、金石和炎烈的底气、陈霜握剑的身影、刀疤不退的近防炮、老陈布在地面的四枚棋子、小王在河图上不停运算推衍的战术模型、小胖身后的灵麦面推车——以及诸天号十二组全功率冥纹的低声咆哮——都凝在了那个瞬间。

他背后没有空洞。不是他想一个人扛——是所有人用命守了一整道墙——他站在墙外。墙如果塌了——他扛下来。他没让墙塌。

第三轮帝阵的锁光在这凝滞后仍按预定程式启发了。绝对灰色从太初方向往李长生射来——射中了他在冥纹碎片环中的位置——但因为方位已被碎片的动态偏折角度打乱——锁禁光束射中他侧后方的虚空，核心锁禁区偏移——锁禁失败。

帝阵锁禁——对一人的最终一击——落空。

十一位帝者在沉默中瞥见李长生没有任何多余动作——没有回击——没有挑衅——他从碎去的冥纹球中转过身，朝防线的方向走了回去。帝者们没有追击——不是不想，而是帝阵阵盘的第三轮强制发射导致目前全阵处于暂时封固冷却态——无法立即调动第四轮集体同步。在冷却窗口内——单打夺回一个站在原地没有走远的冥王——回报评估接近未知。

刚踏回防线的那一步，陈霜第一个走到他面前——她用袖子蘸掉了在他脸侧那颗落下的血珠。王在后面迅速调出他身体负荷的实时评估——总体损伤不大但肺部和动脉暂受寒冷影响需要短暂休息。他摆摆手——在冰帝递给他一块冰敷之前——自己调了一下体内血液循环——将体内寒气驱逐出去。

"你干嘛非要一个人出去扛？"炎烈问。他以前从来不说这种话——他总觉得战斗中煽情是浪费时间。

"因为我不能让他们一直打着防线。"李长生说，"防线是墙——墙也是人要是四个帝者在墙上连续扛到极限——墙会倒的。我不出去挡一轮——下一个倒的就是你们。"

他回到了防线后方。边荒的上空，星辰因为战斗暂时失掉了一部分原有的光芒。但他脚下的废铁板是他自己签了归附文书后亲手焊过的——板上的焊纹很不规整——但硬得很，踩上去稳。

在防线的对面帝阵暂时沉默——冷却时段里众帝者隐隐被一个没锁住的人引起的挫折感压着——但同时也被一种久已未见的冷静抵抗震撼着。

十一帝者没能击垮一堵墙。更没有击垮墙后面那个人。

第四卷完。宇宙中央之战——仍在继续。

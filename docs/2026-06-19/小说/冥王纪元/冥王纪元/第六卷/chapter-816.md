# 第816章 代代相传的传说

新纪元一千五百年。

在银河系最偏远的殖民星——一颗名叫"边驿三号"的小行星上——一个七八岁的男孩正蹲在自家院子的菜地里拔草。他的父亲在旁边修一台老旧的灵力水泵，嘴里叼着一根草茎，和地球上的农民没有任何区别。

"爸，老师说我们这颗星是银河最边的星——为什么我们还要住在这儿？"男孩问。

"因为你太爷爷那一辈就是在这儿生根的。"父亲头也不抬，"太爷爷说——这儿像他老家。"

"老家在哪？"

"地球。中国。一个叫李家庄的地方。"

"那为什么我们不住在地球？"

"因为有人得守住边边。"

男孩拔完草，站起来，拍了拍手上的泥。他的手很小，但拔草的动作很熟练——和他父亲一样，和他太爷爷一样。

"爸，冥王真的存在吗？"

父亲停下了手里的活。他抬起头，看着远方的星系——那里有无数星辰在缓缓转动，其中最亮的一颗微微泛着幽蓝色的光芒。

"存在。"他说，"你太爷爷的太爷爷——活到了一千三百多岁，亲眼见过他。"

"长什么样？"

"就是一个农民的样子。穿着旧衬衫，脚上是解放鞋。手里拿的不是神兵——是一把锄头。"

男孩想了一会儿："他为什么要守护宇宙？"

"因为他觉得那是分内的事。"父亲说，"就像你刚才拔草一样——不是别人叫你拔的，是你自己觉得应该拔。"

男孩似乎懂了。又似乎没完全懂。但他没有再问了。他重新蹲下来，继续拔菜地里的草。

这是银河系最偏远的一颗殖民星上，一个普通的傍晚。父亲在修水泵，儿子在拔草。和一千年多前李家庄的某个傍晚没有什么区别——那时候李长生也在自家地里拔草，他爹在院子里修扁担。

冥王的故事就是这样代代相传的。

不需要寺庙，不需要祭坛，不需要法会。只需要一个父亲在黄昏收工之后，蹲在院子里，对身边的孩子说一声——"很久以前，有一个人，和你爷爷一样是种地的。他后来做了很大的事。不是因为他有多厉害——是因为他没有忘记他种过地。"

故事在每个星球上的每个角落里被讲述。有的版本加了细节——冥王怎样一拳打穿维度，有的版本省了细节——冥王只是一个善良的农民。但所有的版本都有一个共同的结尾：他没有死。他只是去了更高的地方，在那里看着所有的人。

在银河核心区，有一所全银河最好的宇宙历史学校。学校的招生面试中有一道固定题目："请描述冥王对星际文明最深远的影响。"大多数应试者会回答：冥王令体系的建立、灵力与科技融合的范式、星光议会的成立、对平行宇宙的开拓。

但有少数人会回答："他的锄头。"

答题卡上只需要这个词。一个词的答法在星际教育界起初显得随意，但后来慢慢被理解——因为那个词里确实包含着他最深远的唯一影响：他能用锄头做一切事，就算去到浑沌的本源——他依然保持着种地的角度。后人不一定完全明白这句话的意义，但教课书的编者选择保留了全部三个字。他可能让所有生于银河的人知道——力量的顶点，并不需要放弃出发时的姿势。

李长生在封禁地里听着这个故事被反复传诵。观察窗有时候会捕捉到某个星球上的冥王传说课堂。内容有些许走样——有些明显是后人加上的夸张情节，比如冥王一掌碎万星，冥王一口气吹灭三个太阳——李长生每次听到这些会皱一下眉，然后淡淡说一句："我没那么厉害。我吹不灭一个蜡烛——除非蜡烛摆在风口。"

陈霜每次听到都会轻轻一笑。不是好笑。是暖——这个人在她身边坐了一千五百年，还是那个在老宅院子里怕点着的香被风吹灭时赶紧用手挡一挡的人。

"有人把你写得好像你是无坚不摧的神。"陈霜有一次说。

"我不是神。我一直只是李长生。"

"但他们的传说不全错。无坚不摧——你没有败过。"

"那是因为我从来不在会败的时候去硬拼。你觉得打架不算退——不是不退，是换了方式打。我爹说的——庄稼被风吹倒了，扶起来，培培土。不跟风较劲。跟风较劲是傻子。所以我不是无坚不摧。是我学会了扶。"

陈霜沉默了一会儿。"这种话——应该被记在传说里。"

"传说里的字都太高了。像我这种蹲着说话的高度——不太容易刻在石碑顶上。"他说完自己先笑了。他开始明白了一点：后代们说的冥王不是他本人，而是每一个星球上蹲在地里拔草的那些普通人，在黄昏里给孩子讲一个故事时，讲的那个人——是每一个他们愿意变成的样子。不是神——是他们愿意变成的样子的总和。

（第816章完）

# 第082章 沙下怪兽：远古沙蛟苏醒

沙蛟从沙层里完全钻出来了。

首尾加起来超过二十米。全身覆盖着铁灰色的鳞甲，每一片鳞都厚得像老城墙上的砖，边缘锋利，在风沙中泛着冷光。它扬起前半身，高过两个人能够到的最高点三倍有余。阳光从它背后打过来，影子像一座山一样压在他们头顶上。

李长生在古墓那边见过大妖兽的遗骸。但眼前这条不是遗骸，是活的。活的沙蛟会动，会叫，会吃人。

沙蛟张开了嘴。

嘴里不是普通的牙齿。上下两排牙，外排是尖的，像鲨鱼牙，密密麻麻垒在一起。但口腔最深处——舌根的位置——有一根极细的骨刺，正往外吐着淡黄色的雾状灵气。

他在凝聚第二发声波。

李长生不敢等。

"黄泉引路！"

右手掌心冥纹炸开——不是碎，是以纹路为中心，往外猛地烧出一片幽蓝色的冷光。冷光从手心涌入空气，像一盆幽蓝色的水泼出去，在风沙里迅速散开，形成一圈直径三米左右的灵场。

灵场之内，空气变了——变阴，变暗，变冷。夏末大漠正午的温度在一瞬间跌到了初冬。

这就是龟相教他的招数。黄泉引路——冥系修士最基础也是最狠的前置招式。把冥气释放成灵场，所有在灵场里的敌人都会被阴气干扰感知。不是靠强攻，是靠歪——让敌人分不清东南西北，让光线扭曲变暗，让声音在空里变了方向，让空气密度忽高忽低。总的来说：让你的五官判断完全失效。

但对沙蛟这种体型的上古妖兽，影响能不能打穿它的鳞甲？

李长生没有分神去算这个。他在灵场刚刚展开的一瞬间就开始后退，一边退一边调整冥气的输出。右手掌心的冥纹被抽了将近一半的力量转化成灵场，他掌心的温度迅速下降，右手的指节开始发白、发僵。

"退！"他冲陈霜喊。

陈霜退了。但她退的方向不是往外跑——是往沙蛟的头下面钻。

她在找距离。

她的剑已经全拔出来了。剑柄是旧铜包木，剑身两指宽，三尺三寸长，剑刃薄得像蝉翼。白光在剑刃上静静燃烧，把剑尖附近的风沙凝固成了一片明显的空气轮廓——这是剑气灌满的标志。全满。

沙蛟的声波果然打偏了。

那股能量波从沙蛟嘴里射出，轰的一声砸在了李长生左侧十米外的沙堆上。整座沙堆被炸出一个大坑，沙子扬到半空，散得像下雨。如果不是黄泉引路扭曲了声波的方向，这一下正中两人所在的位置。

"打它的下颚连接处！"李长生喊道，声音在灵场里发闷。"鳞甲最薄的地方在颚窝和眼球后侧。不要砍它的背鳞——砍不动。"

陈霜在风沙里回头看了他一眼。那一眼的含义很清楚：你怎么知道？

但她没有问出来。战场上不是问问题是回答问题的时候。

她改了剑路。从正面直刺改为侧翼偷袭，压低重心，脚下踩着松软的沙子，腰一扭，整个人贴着地面往右侧滑过去。剑尖在沙面上划出一道浅槽，滑了不到一秒就到沙蛟的下颚左侧。

沙蛟的颚窝确实比其他地方更软——肉眼看起来也一样是鳞甲，但鳞片之间有细微的缝隙，是骨头活动的铰接处。陈霜猛地蹬地，跃起半米，一剑刺了进去。

剑入鳞缝，只进了三寸就卡住了。

沙蛟的鳞甲之下还有一层厚实的革质真皮层。这一剑刺穿了鳞片，却没有刺入动脉血管。沙蛟吃痛，发出一声尖锐的嘶叫——这次的声波是被痛出来的，不是发出的，从它喉咙里直接炸开。

陈霜松开剑柄，双手按在剑格上猛地一旋。剑身在鳞片缝隙里转了半圈，撕开了切口。然后她借力一拔，身子在半空中翻了一周，重新落回地面。

她拔出剑的时候，剑尖带出了一小段血——不是红色的，是暗绿色的，在风沙里冒出一股刺鼻的腥气。

沙蛟彻底怒了。

它甩头就是一击。不是咬，是撞。沙蛟的头颅加上骨刺，重量估计不下千斤。这一抽甩过来，两侧的沙层直接被气浪炸开。

陈霜躲开了。她落地的瞬间没有停顿，直接弹起身往另一个方向走——剑修步法讲究的就是连、贯、轻。这一步接一步的步法是写在剑诀里的本能。

但沙蛟更快。

它是沙漠里的东西，在沙子里能动得比人快几倍、十几倍。它的尾巴——刚才还埋在沙丘底下的那半截——忽然从陈霜脚下不到三尺的位置破土而出，像一条钢索一样抽上来。

陈霜被抽中了。

不是正面抽中。她在感觉到脚下沙面在动的时候已经做出了偏轴的规避翻腾，但沙蛟的尾速实在太快了。尾梢擦过她的右肩和背，把她整个人打飞出去六七米，重重砸在沙地上。

她的剑脱了手。

剑在沙子上弹跳了三次，插在了不远处的沙堆上，剑刃上的白光开始闪烁——剑修的剑和主人之间是以剑气贯通连接的。人被震了，剑气就弱了。

沙蛟转过头，那双铁铸般的眼球锁定了趴在沙地上的陈霜。它慢慢张开了嘴——嘴里的骨刺又在凝聚淡黄色的灵气。这次的目标就是她。

"黄泉引路——第二重！"

李长生的灵场忽然炸了。

不是散，是压缩——刚才散成直径三米的灵场猛地往回收，压成了只有一尺厚的一圈光环，在李长生右手拳头外周持续燃烧。他的整只右手此时已经完全看不见皮肤了，只有密布的黑色冥纹，从指尖向上延伸到手腕、小臂，一路烧进了外套袖子里面。

压缩灵场相当于把黄泉引路的干扰能力集中在一小片区域——密度高了十倍。

他把这团压缩冥光环，直接甩了出去。

光环划过沙面，撞上沙蛟半开的嘴巴。不，不是撞——是钻。光环像一只活物，在接触到沙蛟嘴边灵气的那一瞬间自动吸附上去，然后顺着骨刺的方向往里钻。

沙蛟的声波被压死在喉咙里了。

光环钻入它的嘴，冥气在它的口腔里炸开。不是火焰式的炸，是渗入式的侵蚀——阴气沿着口腔黏膜往里渗，直接干扰了它喉部控制声波的灵脉节点。

沙蛟的声波中断了——就像一个人正用尽全力要吼出来，嗓子忽然发不出声。它猛地扭头甩头，整个上半身砸在沙地上，砸出一个深坑，痛苦的嘶哑声带着黄沙疯狂飞溅。

而就在沙蛟的声波中断、甩头晕眩的这一刹那，陈霜站了起来。

她被抽飞之后在地上躺了两三秒。但这两三秒里她手里的剑一直锁定着沙蛟的颚窝——刚才被她先追者揭开的那道裂缝里还在出着暗绿色的血。她从沙堆上翻身拔剑，人没有站稳就开始冲刺。

同时李长生也从另一个方向扑了上来。

两人不约而同——沙蛟甩头晕眩的这个呼吸间隙，是唯一的进攻窗口。

（第082章完）

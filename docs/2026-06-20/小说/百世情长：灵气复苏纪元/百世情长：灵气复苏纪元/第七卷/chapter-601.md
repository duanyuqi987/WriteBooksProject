# 第六百零一章 修为的代价

炼虚中期的那道门槛，林牧花了整整三个月才迈过去。

不是灵力不够。他的丹田容量是同阶修士的七倍有余，经脉宽度足以支撑半个时辰的持续全力输出。瓶颈不在身体上——在心上。

炼虚期的核心不是"炼"也不是"虚"，是"稳"。灵力增长到这个阶段，每一次突破都会对心性产生反噬。修为越强，性格中那些被压制的部分就越容易浮出水面。不是因为你变了——是因为你终于有了足够的力量，不再需要藏着掖着了。

林牧发现自己比从前更容易沉默了。

不是从前那种"话少是因为想得多"的沉默。是另一种沉默——一种带着硬壳的沉默。苏晚问他晚饭想吃什么，他能顿三秒才回答"随便"。苏晚问他今天修炼顺不顺利，他只说"还行"两个字就把话题截断了。

他自己没注意到。或者说，他不觉得这是个问题。他前世在青云宗修炼了几万年，养成的习惯就是：心里的东西自己消化，不要拿去烦别人。可苏晚不是"别人"。

苏晚的变化也在同步发生。

她从前只是倔——做事认真、不轻易服输的那种倔。但进入炼虚期之后，那种倔变成了一种锋利的东西。她不再只是坚持自己的意见——她开始对不同的意见产生本能的抵触。像一把刀，以前是收在鞘里的，现在刀尖露出来了。

周五傍晚，两个人在修炼室各自打坐。苏晚先收了功，站起来去倒水。路过林牧身边的时候，她的袖子扫到了他放在桌边的剑。

剑没掉。晃了一下。

"你的剑能不能别老放这儿？"苏晚的语气不算差，但也不算好。"每次过路都要绕着走。"

林牧睁开眼睛。"之前不都放那儿吗。"

"之前我没碰到过。"

"那你注意点就行了。"

苏晚把水杯放在桌上。那个声音比平时重了一点——不是摔，但也不是轻放。"我注意？是你的东西挡在路中间，凭什么是我注意？"

林牧看了她一眼。那一眼很短，但苏晚从他的眼睛里看到了一个以前没出现过的东西——不耐烦。

"你就不能绕一下？"林牧说。

"你就不能挪一下？"

两个人对视了大概三秒。然后林牧站起来，把剑拿起来，放到了房间的角落。动作很干脆，但那种干脆本身就是一种态度——不是妥协，是"我不想跟你吵"。

苏晚盯着他的背影，没有继续说话。

以前遇到这种事，林牧会笑一笑，说"好，我挪"。苏晚会跟着笑一下，说"我也不是故意碰到的"。然后事情就过去了。但今天不一样。今天两个人谁都没有笑。

林牧走到窗边，看着外面的云。炼虚期的修士不需要望远镜就能看到云层之上数百里的灵光波动。

他忽然开口："明天我闭关。七天。"

苏晚端着水杯的手顿了一下。"你上周才闭关了五天。"

"还不够。"

"不够什么？"苏晚走到他身边。"你已经炼虚中期了。整个修仙界比你强的人不超过五个。你还要怎样？"

林牧没有回答。他看着窗外，眉头拧着。窗外没有敌人。但前世的记忆告诉他：永远有更高的地方。上界。真仙。那些曾经把他打落凡间的存在。如果他不继续变强，他连保护她的资格都没有。

"你说话啊。"苏晚的声音拔高了一点。

那道声音里带着一丝尖锐——不是尖酸刻薄的尖锐，是压抑太久终于冒出头的尖锐。她自己都没意识到。炼虚期的修为放大了她性格中的急躁面，让她不再像从前那样有耐心地等待他的回答。

"我说不够就是不够。"林牧的语气忽然硬了。

他转过身来，看着苏晚。他的眼神不是平时那种温和克制的眼神——是一种被什么东西顶住了、不得不反弹的眼神。

"你能不能别什么事都要问到底？"

这句话说完，空气安静了大概五秒。

苏晚站在原地，手里的水杯没有放下。她的表情没有变——不是没受伤，是伤还没到脸上。一个人在极度伤心的时候，表情反而会比平时更平静。因为情绪的冲击太大了，大到面部肌肉来不及反应。

"我只是关心你。"她的声音低了下去。

林牧张了张嘴。他想说什么——想解释他不是在凶她，是想说他只是太累了，闭关不顺利，修炼遇到了瓶颈，前世的记忆碎片一直在梦里反复出现让他睡不好。但这些话堵在喉咙里，一个字都出不来。

他说不出来。因为他从来就不擅长说这些。

"我去修炼室。"林牧拿起剑，走出了房门。

门关上的声音不大。但在安静的房间里，那个声音显得特别清楚。

苏晚站在原地没动。过了大概十息，她把水杯放在桌上，坐回自己的蒲团上。她想继续打坐，但灵气一进入经脉就开始紊乱——不是她的功法出了问题，是她的情绪在影响灵力运转。炼虚期的修士，心念一动，经脉内的灵力流向就会被扰动。

她睁开眼睛，看着林牧刚才坐过的蒲团。蒲团上还有他留下的体温——灵气残留的微热。

从什么时候开始变成这样的？

她努力回忆。大概是从三个月前，他突破炼虚中期之后。那之后他闭关的时间比以前长了一倍，说话比以前少了一半，看她的眼神里多了一层什么东西——不是不爱了。是他在担心什么。但他从来不说。

而她呢？她自己的脾气也在这几个月里变得越来越大。以前她能忍的小事，现在忍不住了。以前她愿意等的沉默，现在等不了了。以前她觉得"他不说我就等他说"，现在她觉得"你不说我就自己想——然后越想越气"。

她知道这不是他的错。也不是她的错。

是修为。炼虚期的修为在放大他们性格中每一个棱角。他的沉默变成了冷漠，她的倔强变成了暴躁。两个人都知道自己变了，但谁都不想先开口。因为一开口就意味着承认：我确实变了。

晚上十点，林牧回来了。

他身上带着修炼室特有的那种清冷气息——高浓度灵气在封闭空间里长时间循环后留下的味道，像深山里的松香，但不是从树上来的，是从石壁上渗透出来的。

苏晚坐在沙发上，膝盖上摊着一本书，但没在看。她听到门声，没有抬头。

林牧走到厨房，倒了杯水。喝水的声音在安静的房间里有种突兀的清晰。

他端着水杯走到客厅，在苏晚对面的椅子上坐下。两个人隔着一张茶几——不到两米。但这两米在今天晚上显得格外长。

"苏晚。"

"你那么凶干什么。"

两个人同时开口。然后同时停了。

林牧把水杯放在茶几上。杯底碰到玻璃面的时候发出轻轻的一声"嗒"。

"我不是故意凶你的。"他说。

这是他半天以来说的第一句软话。这句话说得不流畅——像是从一块被冻了很久的冰上凿下来的。但他还是说了。

苏晚抬起头看他。她的眼眶有点红——不是哭了。是忍住了。她看着林牧，林牧看着她，谁都没有挪开目光。

茶几上那杯水慢慢地凉了。窗外有风吹过，窗帘轻轻动了一下。这个房间里的两个人，一个学会了在沉默中暴怒，一个学会了在倔强中脆弱。

他们相爱了六百年，从第一世到现在。但今天他们忽然发现：原来相爱这么久的人，也是会吵架的。

（第六百零一章 完）

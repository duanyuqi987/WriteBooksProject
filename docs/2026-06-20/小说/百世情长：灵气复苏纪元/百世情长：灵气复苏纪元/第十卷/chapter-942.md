# 第942章 遗忘与铭记

上界两百年时，传道堂发生了一件小事。有一个不太起眼的新学员在课后问苏晚："如果哪一天所有人都不再记得您——您会觉得白做了吗？"

这个问题让一旁的古柏愣了一下。苏晚平静地答："不会。因为种子长成树后不需要人记着谁当初埋的它。树会自己长——然后落下新的种子。忘记了埋种人没关系——树能继续活，就是最好的记。"年轻学员听完后若有所思地走了。古柏事后在日志中记下了这段话。后来它被刻在了太行传道堂正门的匾额下方——作为创始人的自叙。

林牧对这个问题的态度略微不同。他在当天晚上对苏晚说了一句话："我不希望你被遗忘。"不是反对她的回答——是表达他自己的私心。他的守护道允许他有私心——只要不伪装成公心。他诚实地承认他希望世界记得她。苏晚把他的私心接住了——她说："世界不一定非记我不可。但你能记我——就够。"

随着时光流逝——下界的太行书院发生了正常的人事更迭。第一代导师老去飞升后——第二代接棒，再之后第三代、第四代。千年更替让最初那些人的名字逐渐从大众记忆中淡去。苏晚的名字被写进书院的历史教材的首页——但每一代读教材的人数相较于整体人数是稀少的。大部分人进入了书院只学功法——不问创始者生平。这样的事她经历过无数次——从来没有任何不甘。因为她要的不是"被记住"。她要的是"那扇门始终开着"。

太初之城在这期间进行了一次道号系统大升级——将所有道号与天网深度绑定。升级过程中出了一次故障：苏晚的道号"晓渡"因为她的永生体质被误判为"道号数据重复"。系统将她的身份临时误标为"觉醒前身"。她因此在几周之内无法使用任何道号相关权限——包括进入太初之城的高阶区域。她没有去申诉。她把这段时间当平凡人默默度过——每日照常去传道堂后园浇菜。直到道号中枢的人工修复专员发现错误并修正为止。

修复专员向她致歉时，她答得简单："没关系。被当作凡人几天挺好的——让我记得自己一开始就是凡人。"

林牧在旁边听着她这样说——心里默默把他第一千零一次为她做的修正列入清单。系统错误不是他能提前阻止的。但他事后用见道修为在天道档案的冗余副本中嵌入了一条"晓渡道号不可被自动修正覆盖"的保护条——不是特殊待遇，只是帮她免于再次被系统打扰。

苏晚上界第两百五十年时开始写一本小书——不是道典，是日志。她把从飞升前到目前的经历按年份梳理成短篇随笔。文体不华丽——就事论人。写到第一卷的段落时，她回想了那九百年与他们最初的交汇——写字楼的极光、旧书摊的纸条、第一次并肩作战、相爱的激烈与受伤。她不是怀旧——是在做一件极其重要的事：把记忆系统化地记录下来，以备将来某一天也许有人在寻找答案时会用到。她把这本小书命名为《盏——长夜的碎光》。每一个章节名对应一种关系境界——共十卷。

书写完成时，她只做了两份手抄本。一份存放在太行传道堂的档案库。另一份给林牧。

林牧花了整整两天把这本书从头到尾读完。他阅读时的姿态和他研究古碑时一模一样——专注到了极致。读完，他合上书本。他说了两个字。"精准。"

苏晚知道这是他能给出的最高评价。

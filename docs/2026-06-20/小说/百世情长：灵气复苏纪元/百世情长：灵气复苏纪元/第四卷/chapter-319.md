# 第三百一十九章 灵魂封印的松动

苏晚在昆仑山顶站了整整一夜。

不是警戒——是在"内视"。金丹期修士的内视能力可以看清自己的经脉、丹田、灵核。但她看的是比经脉更深的地方——灵魂层面。天魔幼苗心脏那一战中，她用木勺上的副印信号扩大了灵力穿刺的精度。那一刻她的灵魂深处传来了一道声音。不是别人对她说话——是她自己的声音。是第一世苏晚的声音。那道声音被封在灵魂封印里三百多年，在天魔之血和副印信号的叠加下裂开了第二道缝。

第一道缝是百分之五——能听到模糊的声音。第二道缝是百分之二十——直接出现了画面。

她看到了契约签订的那一天。

前世林牧不是"林牧"——他叫闻道。上界真仙，云霄城剑仙之首。那时的苏晚——第一世——名字还叫苏晚。她是凡间修仙界青云宗的外门弟子。资质极普通。闻道在巡视凡界时偶然在青云宗山门遇见她——那次他本来只是来布置一个禁制，防止凡界的灵脉波动干扰上界传送阵。路过练剑场时停下了。因为看到了一个人在练剑——剑姿极差，但眼睛里的东西极好。那种"我偏要练"的倔意。

后来他在凡界待了三年。三年中教了她很多东西——剑法、心法、呼吸法。她问他为什么对普通资质的人这么好。他说：你不需要好。你需要愿意练。

三年后他被召回上界——云霄城有事。他问她要不要一起。她不能——凡人的灵魂受不了上界法则的碾压。唯一的办法是把她绑定在他灵魂上——透过情缘契约将她转世纳入他的灵力保护。这个契约需要两个人自愿。而且——副作用极重：每一次转世，她的记忆、修为、资质都会被封印一层。百世之后，她灵魂上的封印会厚到永远解不开。而他会因为每一世都分出一部分灵魂本源给她——修为每况愈下。

闻道说：不签。你是凡人不应该因为这些上界的事承受代价。

苏晚说：签。我愿意的。

然后她签了。契约石上落下两个印记——主印在她灵魂上（她是凡人，需要更多保护），副印在闻道灵魂上。然后不到七天——闻道被阎锋偷袭坠落凡界。苏晚在第一世随后死于一场上界波及的灵脉爆震——那是他们计划之外的结局。

她在凡界轮回。闻道变成了林牧。两百年后——两人在第二世见面。她认不出他。他认得出她。

画面到这里停止了。不是封印重新关上了——是她的意识需要缓一缓。

她睁开眼睛。昆仑山顶月落西山。林牧坐在她对面，用木棍在地上画不知道第几幅剑法分解图。他看到她的眼神变了——不是那种"刚看到新事物"的兴奋，而是"记起了很久很久以前的事"的沉默。

"记起来多少？"他问。

"记到第二世开头——你说你叫林牧。我说我叫苏晚。你没有告诉我前世的事。只是说'你好'。"

"对。因为第二世——你还记得吗？我们第一次见面是在一座小城的药铺里。你拿着你爹的药方来抓药——方子上有一味药名儿写错了。你对我纠正的时候说：'不对。这个药不是白术是苍术——白术治不了风寒。' 我就觉得——你还在。那个'偏要纠正你'的脾气还在。"

苏晚轻轻地笑了笑。然后说："闻道——好听。为什么不继续用这个名字？"

"因为上界的名字在凡界呼出会引发灵力震颤。会暴露身份。所以每一世都要换名字。林牧——是第二世我翻字典随便挑的。'林'——是她家附近有片竹林。'牧'——是她那一世小时候帮家里放过羊。你那时候是个药材商家。"

"你每一世都换名字——是不是觉得累？"

"不累。"林牧说。"因为我每叫你一次新名字——就代表我又找到你了。"

昆仑山的风在两人之间安静地穿过去。雪从松枝上滑落下来。篝火快要灭了——但没有人去添柴。

"明天阎锋还会来。"苏晚说。"他这次会带真东西。"

"嗯。"

"你怕不怕？"

"以前会怕。现在不怕了。"

"为什么？"

"因为现在你在了。"林牧说。这句话他从喉咙里发出的音量很小——可能是风太大。可能是他不太会说这种话——说出来之后耳根侧着月光能看见微微泛红。"你在了——我就不必一个人撑着打不过的时候还要撑。两个人。可以轮着撑。"

苏晚把剑放在火堆旁边——让剑也取暖。然后她靠过来。不是靠近——是靠在林牧旁边的岩石上。两个人背靠岩石。面对同一团余烬。风从他们的背后刮过来——被岩石分成两道流。左侧流过她。右侧流过他。

"第二世我们药铺见面那一次——之后发生了什么？"

"之后——我帮你爹治好了风寒。你爹觉得这小伙子不错。让你给我介绍几个本地姑娘。你说——不行。"

"为什么不行？"

"因为你说——这人看上去不爱说话，但心是热的。先放着。别着急。"

然后林牧嘴角往上扯了一点——那个弧度很淡。但苏晚看到了。在余烬的微光下。"那是第一次有人帮我挡亲事。"

苏晚靠在他的身侧——她的右臂和他的左臂之间隔着大概一拳的距离。她没有靠太近。但那一拳的距离在微风中变得越来越窄。不知是她侧了一下身。还是他微微挪了一下肩。

篝火在他们安静之中灭了。昆仑山上空的星星像几万年前一样亮。天顶偏北十二度——那颗暗星几乎看不见了。阎锋的灵压在持续衰退。他退回了裂缝深处休整。但他不会退太久。

裂缝里。阎锋正在用碎界刀的碎片切成十三块小骨牌——每一块骨牌裂开来之后都有独立的浊质切割功能。他把它们贴在裂缝边缘——组成一个小型切割阵。不是用来斩人的。是用来切"空间骨架"——将昆仑裂缝从一道裂缝变多条。

只要裂缝同时出现多个裂口——林牧就没法一个人同时封所有口子。其中一个口子便会延伸到蜀山主殿上空——目标：蜀山剑阁。取里面三千柄灵剑的灵脉——给他恢复修为。

阎锋冷笑了一声。他的笑声在裂缝深处被紫光吞掉了。

而在屏障另一边——林牧感觉到了裂缝内部空间法则的微小变化。知道他下一步要干什么了。他把木棍放在膝上。低头对木棍说了句："走吧。"

苏晚醒来。两人站在晨曦里。面对那道隐隐颤动的空间裂缝。她的剑——淡金色剑气在晨光中形成了三百年来第三道光。

第一道是第一世她在青云宗初次拔剑。第二道是前月在昆仑挡住阎锋时。第三道是今天。

三道光。同一个灵魂。

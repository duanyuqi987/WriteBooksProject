# 第七百五十八章 打破上界对下界的封锁

凡人飞升权通过后的第二周，林牧在第二道门前的测绘中观察到了一个前所未有的变化——门上的所有螺旋符文忽然同步转动了整整一拳寸。不是一微米一微米地累积，而是一次完整的、可见的同步运动。杜小月在监控日志上用灶台计数算法实时记录了这一刻——"全部符文，六千九百，同步转动三十七秒。——时间：凡人飞升权通过后第六日。——杜小月。"

这个现象的含义深刻：门不是被"推开"的——是被"说服"的。它在主动解除自己的封锁。上界对下界的封锁不是在力量层面被打破的——是在道理上被打破的。当第一项让凡人拥有平等飞升权的规定被通过之后——门上几千年来固定不动的"高等灵根独享飞升"的限制被解除了。不是因为这扇门忽然变宽容了——是因为它被地面上的政策说服了。

林牧站在门前。他把手掌贴在门面上——门不再问他"你的目的是什么"。门直接给了他一段全息的感知——不是文字——是一段极古老的记忆——是那两个原初真仙在种下桂花树时说的话——"未来总有一天——有人会带更多的人一起来。那天的到来，就是封锁消失之时。——原初。"

他收回手。他把刚才的感知原封不动地记录下来——发给了苏晚。他在传讯末尾加了一句他自己的注释——"封锁的真正意义不是不让下界上去——是等下界准备好带更多人一起来。今天——下界准备好了。——林牧第六轮探索第二轮更新。"

苏晚收到传讯后没有单独庆祝——她把传讯内容贴在灯火塔基座的公共栏上，让所有经过的人都能看到。石头的弟子小米——现在是灯火塔展馆的义务讲解员——把它读给了一群刚来的散修学员听。散修中有一个刚筑基不到半年的女孩问小米——"封锁真的解除了？"小米回答得流畅——"是的——因为大家不再互相封锁了——所以门不再封锁所有人。——小米。"

（第七百五十八章 完）

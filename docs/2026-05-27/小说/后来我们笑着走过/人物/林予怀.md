# 林予怀

## 基本定位

- 身份：从乡镇中学考入县一中的男生，第一人称叙事者。
- 叙事功能：用他的日记、诗、嘴硬、自嘲和失控，串起整部青春成长故事。
- 初始状态：内向、自卑、敏感，想在高中改变自己，却不知道怎么改变。

## 核心欲望

- 想被沈安晴看见。
- 想证明自己配得上喜欢的人。
- 想把青春里的痛苦变成文字，证明它不是白疼。

## 核心矛盾

- 他渴望被爱，却常把爱理解成等待、牺牲和占有。
- 他讲很多道理，但真正遇到感情时比谁都不讲理。
- 他怕丢脸，所以错过很多该说的话；他又怕遗憾，所以常在错误的时候说太重的话。

## 声纹

- 第一人称，句子有时很短，有时因情绪失控而拉长。
- 喜欢自嘲：`我真是没出息`、`算了吧`、`谁的人生不留遗憾呢`。
- 喜欢用学习、数学、物理解释感情。
- 情绪上来时写诗，诗有青涩感，不追求完美。

## 弧光

| 阶段 | 状态 |
|---|---|
| 第一卷 | 看见沈安晴，暗恋萌芽 |
| 第二卷 | 用暗恋驱动学习，也被自卑困住 |
| 第三卷 | 说出口，短暂靠近，又因现实和性格裂开 |
| 第四卷 | 在新关系里暴露占有欲和幼稚 |
| 第五卷 | 学会不索要答案，完成一笑而过 |

## 变更记录

- [chapter-001] 林予怀进入县一中，初见沈安晴，并在课本空白处写下她的名字。
- [chapter-002] 开始记录沈安晴的日常细节，把暗恋变成自己的观察账本。
- [chapter-003] 在饮水机旁与沈安晴第一次目光相撞，回到教室后只敢写日期。
- [chapter-004] 被赵一鸣戳破暗恋，第一次说出“我配不上”，开始把喜欢转化为学习行动。
- [chapter-005] 写好物理解法却不敢交给沈安晴，形成“答案没有拿到，过程先写上”的行为模式。
- [chapter-006] 在第一场雪后写下第一首古体诗《初见》，确认自己不是欣赏而是喜欢。
- [chapter-007] 第一次月考后因与沈安晴二十八分的差距而自卑，开始用蓝色错题本制定学习计划。
- [chapter-008] 撕下语文书最后一页，把写过沈安晴名字和碎句的纸夹进日记本，秘密从课本转入长期记录。
- [chapter-009] 在元旦晚会筹备中感到别人喊沈安晴名字会刺痛自己，占有欲的种子开始出现。
- [chapter-010] 元旦晚会后写出现代诗《藏在心里的姑娘》，确认写作能暂时承接说不出口的话。
- [chapter-011] 理科分班后仍与沈安晴同班，但意识到同班不是靠近，只是继续疼。
- [chapter-012] 因“学习好的人很厉害”升级错题本，开始从抄题转向分析自己的错误。
- [chapter-013] 熄灯后在被窝里用手电筒背单词，把身体也纳入暗恋驱动的学习计划。
- [chapter-014] 被赵一鸣追问表白计划，承认“我不配”，并把勇气推到“高考后”。
- [chapter-015] 听见沈安晴说“稳也会怕”，开始修正自己把她神化的视角，并写下《暗恋》第一版。
- [chapter-016] 高三成绩追到沈安晴后一名，却发现名次接近不等于人心接近。
- [chapter-017] 因校门口表哥误会失控，暴露出把想象当事实折磨自己的倾向。
- [chapter-018] 买下灰色同学录，想递给沈安晴却再次错过，并写下《暗恋》第二版。
- [chapter-019] 高考第一天第一次主动叫住沈安晴并说“加油”。
- [chapter-020] 高考结束后终于把同学录递给沈安晴，并决定赴翠湖之约。
- [chapter-021] 在翠湖长椅与沈安晴第一次较长地聊天，但仍未能表白。
- [chapter-022] 在县一中走廊说出“我喜欢你”，进入等待沈安晴回应的悬置状态。
- [chapter-023] 收到沈安晴 QQ 好友申请，开始把聊天记录当作新的靠近证据。
- [chapter-024] 暑假电话里承认自己很急，但愿意装得不急。
- [chapter-025] 志愿填报时没有追随沈安晴去南方，而是选择楚州师范中文。
- [chapter-026] 到楚州师范报到，正式进入异地阶段。
- [chapter-027] 因沈安晴提出少聊一点而受伤，把“为你好”听成退开。
- [chapter-028] 写下现代诗《勒贝格测度》，用数学语言包装异地和沉默。
- [chapter-029] 楼下电话里因误会和防御说出伤人的话，开始真正损伤关系。
- [chapter-030] 接受赵一鸣指出的“测试别人会不会离开”问题，并向沈安晴道歉，但关系进入“慢一点”。
- [chapter-031] 被唐青禾拉进小组展示，感到自己从沈安晴的沉默里短暂抬头。
- [chapter-032] 和唐青禾打扫活动室，享受新的靠近，却仍不断看手机等沈安晴消息。
- [chapter-033] 被赵一鸣指出不能把唐青禾当止痛药，第一次正面面对“重要的人”和新关系之间的伦理问题。
- [chapter-035] 与沈安晴在青河德克士见面，听见“不确定不是承诺”，旧伤被重新触碰。
- [chapter-036] 听见沈安晴承认自己也被打动过，却不能承担他全部期待。
- [chapter-037] 因唐青禾社团聚餐吃醋，暴露控制欲，并写下控制欲来自害怕不被选择。
- [chapter-038] 逃课、泡网吧、失眠，被曹然和赵一鸣拉回现实。
- [chapter-039] 向唐青禾道歉，承认自己还没从沈安晴那里走出来，也接受唐青禾不愿成为补丁。
- [chapter-040] 与唐青禾退回同学关系，不再追问沈安晴翠湖旧事，第四卷完成一次痛苦的自我修正。

# 第三百六十三章 她的道骨

战后第三十六年。第一块"道骨"在苏晚的灵魂深处凝成。

这不是骨头——是一种灵体层面的致密结构。当她闭上眼时，能看见一块不足豆粒大的纯金色结晶体浮在主印核心位置。道骨的凝成表示改命术生效了——百世业力不再是负担，转而成了飞升道路上最坚固的基石。

这块道骨产生的直接效应是：她在练剑时不需要主动灌注灵力——剑意会自动沿着道骨表面流转并精准定向。每一剑都像她下意识做缝合——稳到极致且不自知费力。她用针剑式刺一棵松树上前天落的松果柄——剑尖停在柄前0.1寸处——果子自己掉进她预先放在土上的纸袋里。整个过程没有削断一丝松针。

林牧评价说："你现在的剑已经不是剑了——是自动手术器械。"

她回道:"那你帮我把松果剥开——今天用果仁煮粥。"

此后道骨以每几个月一块的速度缓慢增加。她有时会在诊所为病人把脉时忽然感觉主印附近闪过一丝温热——那是业力正在转化。她会在病历边缘顺便记录数据:"第X块道骨成于某日某时，伴随灵频差下降至万分之0.1。"

这些记录后来被药王谷作为"灵魂生理学"的原始数据引用。她不知情——直到老祖师送了她一面小药箱，箱盖上刻"医剑双学"四个字。她把药箱放在诊室——给病人拿药时和别的小箱完全没差。只是打开时箱盖内侧有一行极小字——是林牧手写："人剑合一者为剑客。医剑合一者为苏晚。"她每次开箱都会看见那行字。从来没人提过。她也没给任何人看过。

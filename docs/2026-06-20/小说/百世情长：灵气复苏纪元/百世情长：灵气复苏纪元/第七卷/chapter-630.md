# 第六百三十章 这就是爱的本质（二）

深秋的一天黄昏，林牧和苏晚并肩坐在后山的悬崖上。

这是他们养成的习惯——每隔一段时间来这里坐一会儿。不是修炼，不是讨论修仙界的事务，就是纯坐着。悬崖对面是连绵的群山，山的棱线在夕照中由深青变暗红再变灰，像一块正在冷却的烙铁。风从山脊上翻过来，带着松香的冷和远处水汽的凉。

林牧把黑剑放在膝上——现在他不再害怕这把剑了。剑身上的青色铭文在夕阳下是近乎透明的淡蓝，像孔雀石上的纹理。剑灵在他的丹田里安静地沉睡。前世的白色身影没有再出现过——不是被封印——是终于安息了。她的记忆不再作为伤口存在，而是作为"林牧之所以成为现在的林牧"的一部分被保留了下来。

"如果那个你前世的她能看到现在的我们——"苏晚把头靠在他的肩膀上。"她会说什么。"

林牧想了很久。"她大概会说——'你终于学会了。'——然后转身走回光里。不是心酸地走，是放心地走。"

"那你是怎么想的？关于我和她？"

"你是她——"林牧说。"也不是她。她是我前世的挚爱，你是我现在的挚爱。你们共用同一个灵魂，但走了不同的路。你走了'愿意依赖我但不依附我'的路——她没有机会学这个。她在那道雷霆前选择了替我死，所以你才活到了这一世。她用自己的生命换来了你的时间线。我现在爱你的方式里有她给我的教训——所以我没有重复同样的错误。她不是你的前任——她是你的'高我'用牺牲来教会我怎么去爱下一个你。下一个你——就是你。"

苏晚安静地听完了。风把她额前的白发吹起来。她的眼角有一片亮光——不是眼泪。是夕阳反射。然后她说："如果有一天我也需要替你挡下雷霆——"

"你不会。因为在我们抵达那个关口之前我会把雷霆的源头解决掉。不管上界有谁在那道门后面等着——我不会再让任何人替我挡雷霆。"

苏晚没有反驳他。她知道他的这句话不是逞强——是这几个月来他终于找到的一种平衡：不再一个人扛，但在他能扛的时候他会全力以赴。这是容仍的另一种表现——不是软弱，是量力而行。

夕阳完全沉下去了。天空从暗橙变成深灰，第一颗星出现了。悬崖下面的山松林在夜风中发出沙沙的声响，像远方有海。

"林牧——你现在爱的是什么？"

"你。一个会砸石板、会发脾气、会在半夜梦到第四世的绣房而哭、会在你觉得需要的时候把粥放在灶台上、会在华山门口看到陌生人刻的字后想一个'缺陷分享会'——的苏晚。不是'完美版的苏晚'。就是现在这个——白发、手凉、推演太投入会累到倒下、但倒下醒过来之后继续推演。——这就是爱。"

苏晚没有说话。她把脸埋进他的臂弯，用力抱了他一下。那个拥抱很短——大概只有两息。但力度是苏晚级别的——就是那个守城守了十一天没退的铁娘子级别的力度。

远处，后山修炼室的石板缝隙里还留着那道被她砸碎的印记。林牧一直没有修——不是忘记，是保留。那道裂缝现在被一条新的阵法纹路绕过去了——不是强行修复，是在旧伤旁边另辟一条辅助路线。旧伤还在——但不再卡住灵力的流动。这就是他们现在爱的方式的物理证据。

（第六百三十章 完）

# 第163章 转世的间隔

昆仑山脉深处有一座被遗忘的洞府。它已经很久没见过人了。

林牧站在洞府门前，看着那些长满青苔的台阶。石阶共有九十九级——每一级刚好一人高。台阶沿山壁辟出来，因为年久失修大部分被塌方堆埋，只能在碎石堆上步行上去。石阶的尽头是一扇石扉——没有任何把手或刻文，仅一道肉眼看不到的灵封保护着入口。

万年以前他自己设了这道灵封。当时他是元婴巅峰修士——这个洞府是他的修炼地和丹房苏晚（第一世）曾来这里看过他一次。她抱怨说台阶太高不好爬，他说以后给你做个便捷式的传送阵。他没做完——因为随后他就被贬落轮回了。

一万年过去了。台阶还在。便捷传送阵至今未完工。

林牧把手按在石扉上。灵封感知到主人的气息——静了片刻，然后就像一块厚重的冰在阳光里缓缓融化一样，从中心向外慢慢打开。石门向两侧滑开，里面先是黑乎乎的——但一息之后嵌在墙上的灵石自动亮起。洞府不大——但五脏俱全。左侧是炼丹室，有一个积满灰尘的丹炉，炉灰在暗红色的炉膛里沉着。右侧是起居室，有一张石床，床上还保留着万年前他随手丢的一件旧道袍。中间最大的区域是书房和修炼室——书架上还排着那时的木简和纸质卷轴。有几卷被蛀空了边角，但内容仍可读。

他在炼丹室的壁架上找到了第一件需要的东西——那批前世留下的丹案，上面记录了"轮回金丹"的丹方。丹方需要的辅材他大多都有库存，唯独缺主材:不灭果和天晶玉。没关系——丹炉还在。火还在。他可以在这个洞府里完成大部分的炼制工序。

然后他在修炼室的书架上翻找古籍——关于轮回锁的信息。万年前对轮回锁的研究还很少——但随着这万年的修为提升，他自身对天道法则的理解比万年前深厚了很多。他把古书摊开，用灵念把关键页存进自己的记忆里。

在一个暗格中找到了一卷皮质卷——好像是某种上古道的遗物。上面记载了关于破解轮回锁的一个关键附加条件:需要一位直接关联者的魂血作为引子——关联者就是灵魂被锁者生命中最重要的感情对象。换言之——必须是苏晚的灵魂在轮回中真正深爱过的那个人的血液。这个人就是林牧他自己。他的精血中含有和她形成上古情缘契约的印记。用契约引子加上对对方灵魂的深刻了解，可以为破解锁提供最高效的引血。

林牧看完了那个皮卷上的所有内容，合上皮卷。

然后他走出洞府。山顶有风。风是高原上那种质地干而硬的风。他站在风口处，把手拢在袖子里，望着远处一片白雪皑皑的昆仑主峰。他开始在心里演算轮回时间表。

第二世和第三世之间的间隔时长是有规律的。第一世和第二世的间隔大约有百年以上（因为他轮回后先在人类社会活了很久才找到她）。但从第二世开始——间隔缩短到二十三年（这是他当时测算的数字）。而这次的间隔——根据第二世灵魂解放后的加速趋势——可能只需要十到十五年左右。也就是说第三世会比他预估的更快出生。也许第三世现在就已经开始生成灵魂前体了——在半年之内她就会在西南某个村呱呱坠地。

轮回周期的缩短可能意味着更深一层的机制。那个上古封仙系统中的"轮回锁"，原本意图是让人每转世一次变得更弱势，结果却因某种未知的重力被不断化解——可能是这个被锁的灵魂自己在世世积德中修到了一丝反向推力。也可能是她与林牧之间的那个上古情缘契约一直在旋转地瓦解轮回锁的外层结构。无论如何——加速是在发生。也许到了某一世，她的轮回速度和普通凡人持平（也就是死后即刻转世），甚至可能快过凡人——最终追上了修士的生命跨度，与他"同活一世"。

林牧把风渐渐受进自己的心肺之中。眉梢上有冷霜，呼出的气在白雾散掉之前就被风搅得不见了。

他想到"同世相随"——那是作为长命种对他亲爱的短生种的最终梦想。不是单世的保护——而是同龄且自然同步。她不必永远被困在衰老和轮回两端。而他不必像个看客一样在每一世的外环上远远徘徊。如果她能在某一世成为修士——哪怕筑基修为——也能大幅削弱轮回锁的效用。那么在下一个、再下一个、乃至第十世——她最终将达到金丹。金丹修士的寿命可达三到五百年——有足够长的时间寻找破锁的方法。

想到这里，他把"加速轮回"这个假设记录在了他的旅行日志里。然后在边上画了一张很小的笑脸。笑脸旁边备注:"等到以后她修炼有成了，把这个推测告诉她——她会喜欢的。"

锦鲤在洞府里叫了他一声。它说:"水壶要换水了——另外我在洞府里的那口冷水泉里发现了一些冰晶古藻——对不灭果的培植有助。我们可以在书房的外室建立一个微型温室，用寒泉的气降温——模拟不灭果所需的高温低温交替条件。"

林牧从台阶走下来。在锦鲤的指挥下他们开始改造洞府。老猫在门口把风——它的警惕心是绝对可靠的。一只金丹级猫妖可以徒手对付任何五品以下的妖兽。

几天之后。洞府微观温室初成。温度调控系统由锦鲤用灵识操控。不灭果的种子他在来的路上收集了一些——主要来源于市场上买到的"药市残次品"，他筛选出了里面稀有的不灭果种子。现在在温室里应该能长。天晶玉则需要去极北冰海底下直接取——那里的水下深度和时间限制使得他必须要在元婴完全稳固后才能行动。目前要做的就是尽快冲击元婴——闭关。

他看了一眼温室的保温石壁，叹了口气。从青溪镇到昆仑洞府之间的距离挺长。这一路走下来他没有觉得累——但到了这里，身体开始反抗。它需要从"持续的警惕"转为"安全地沉入静止"。金丹巅峰修士也需要定期静养。

他在石床上躺下来。石床很硬——但比茶馆的木板床硬不了很多。他把猫放在脚边当暖脚垫。锦鲤在书房的水池中忙它的各种数据分析——计算第三世的坐标精度越来越高了。现在信号已由最初的大范围散射集中到了湖北西部靠近重庆边界某处的一个半农业村。该村名字叫做桃源村——从卫星图像看确实很隐蔽，群山环抱，土地平旷。非常有利于灵植养殖。

他想起青溪镇的茶山与桃花——那两种植物气味是他上辈子记忆中最重的。而桃源村这名字就带着桃花和源源的灵泉双重暗示。也许这地方是小苏晚降落的最后一个安全的地点——她每一世选择的家乡都是安静、朴素、但不失风景的。这是她灵魂下意识避开大城市噪声的一贯倾向。

他在石床上侧了侧身。猫用尾巴盖住他的脚踝。他闭上了眼。睡吧——今晚在昆仑，明天继续为她的下一世做准备。每一晚安睡都是为一个更小的摇篮争取时间。

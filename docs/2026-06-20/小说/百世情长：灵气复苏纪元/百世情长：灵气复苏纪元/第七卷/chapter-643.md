# 第六百四十三章 强者开始修养心性

入冬之后，修仙界发生了一件连林牧都没有预料到的事：各大宗门的掌门和长老们开始主动报名参加桂花园修仙学院的"心性修养课"。

首批报名的包括蜀山剑派的正副掌门、华山第一峰的峰主、龙虎山三位元婴级长老，以及太湖散修联盟的十二名核心成员。这些人无一不是一方巨头——举手投足间可以决定小宗门的存亡。但现在他们坐在学院院子里的小板凳上，听苏晚讲课。苏晚讲的内容不是什么高深的功法——是"怎么发现自己的脾气什么时候会伤到别人"。

蜀山掌门——一个活了五百多岁、斩杀过两条蛟龙的老元婴——在听完第一堂课后沉默了整整一天。第二天他来到学院，找到苏晚，说了一句让她差点把茶泼出来的话："我不知道怎么道歉。我活了几百岁，从来没对任何人说过'对不起'。不是没犯过错——是不知道怎么说。苏晚老师——你能不能教我？"

苏晚没有教他怎么说"对不起"。她只是把他领到石头面前，让石头给他倒了一杯桂花茶。石头仰头看着这个高他好几倍的白胡子老头，说："我以前也不会说对不起。后来发现——不用说得很好。就说两个字——'错了'。对方就知道了。然后你还是敢站在那里——你就算道了歉。"

蜀山掌门在石头面前弯下了腰——不是因为石头是孩子，是因为石头说的那句"错了"。他站直身体后没有哭——但他走出去的时候走得很慢。当天晚上他在蜀山的"共容碑"前站了很久，然后叫来了他的大弟子——那个怕黑的女剑修。他没有训话。他只是说："我今天学了一个字——'错了'。以后蜀山犯了错，不用等我来找你们——你们可以直接告诉我。我不会再用沉默回答。"

华山第一峰的峰主是一个善于话术的人。在心性课第三堂上，苏晚提出"控制欲是一种反向恐惧——你怕别人不按你的方式做，所以你必须控制一切"，他当场就否认了——"我控制细节不是因为怕——是因为我更聪明。"全场安静了一息。然后他自己又开口了——声音比之前小了："不对——我刚才这句话就是在控制你的评价。你还没评价我，我就先下手了。"

全班二十几个掌门级学生忍俊不禁——然后用便签纸写了自己的反馈给他。黄色便签："你是第一个在课堂上当场控制然后又当场承认自己在控制的人。——顾小桐。"蓝色便签："你的诚实比你的聪明更让人想听你讲话。——杜散修。"

张道玄后来和林牧在桂花树下下棋时感慨道："如果两千年前这些宗门掌门们就愿意坐在一棵树下听'心性'这种东西——那些正邪大战可能根本打不起来。不过迟到总比不到好。"林牧落下一颗黑子。他没有接话。但他的嘴角有一个很淡的弧度。

（第六百四十三章 完）

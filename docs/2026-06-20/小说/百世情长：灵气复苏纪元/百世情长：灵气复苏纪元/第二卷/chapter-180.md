# 第180章 寻找婴儿期的她

从苏小晚三岁起，林牧就正式开始了他的"全程监护计划"。这个计划的名称是他自己在笔记本上用极为工整的笔迹写的——"第三世全程教育大纲"。内容包括灵根培护、灵气习惯形成、抗挫折训练、心智启蒙，以及最后一项：修仙意愿触发条件的长期铺垫。大纲总篇幅一百七十页，细分到每年、每月。后来锦鲤评价这份计划"比龙虎山的全宗修炼规则还繁复"。林牧没否认。

三岁到六岁这个阶段，他的核心任务不是教功法——是陪伴和观察。每天早上七点，她起床，从自家院子探头看隔壁老人家是否已经起床。如果他还没开门，她会拿小树枝画猫的头在大门外地上。画完也不敲，只是看看再去玩。七点半左右门会打开。她跑过去送一朵自己揪的野花或者一片叶子。林牧会接过去放在桌上花瓶里——花瓶里每天换新的——放进去的同时把昨天的移除，把今天的花放在最前头。她没有发现花瓶从来没有多出来花。只是觉得老师每天都把她的花插在最中间位置。

上午她去幼儿园或者和妈妈在院子里玩，下午三四点过来"上画画课"。课上他会给她准备好大白纸和那套旧的水彩笔（就是她两岁生日他送的）。她画了很多猫——侧面猫、正面猫、猫尾巴、猫脚。全都画得非常抽象，但他从不说"不像"——只说"你看这只猫的胡子是往上翘的对吧——这样画出来它很开心"。

在这段看似纯粹玩耍的过程里，他暗暗做着一些事情。比如当她专心画画时，他会将房间中的灵气浓度略微调高一点——不高到让她察觉，但她每次在这里呆久了回去脸色都特别好。她把从林老师家回来的那种精神状态自然地归结为"画画很快乐"。林牧没有纠正这种归因——他希望她把"修炼初始阶段的正面体验"归因为自己对世界的热爱，这种归因会形成自然的内驱力。

她六岁上小学后，监护计划开始进入第二阶段：学业+初阶引气引导的同步推进。学校的学习压力对她而言不算大——她脑子不算顶聪明，但她认字早（得益于三岁起林老师教她的那套识字卡），学习习惯很好。每天下午放学她会到隔壁做作业。林牧辅导她的方式从来不是标准家教——给她解题方法、给她线索让她自己去想通。她会撅着嘴巴说"老师你每次都提示不说完"。他笑说"说完还了得——那你以后做不出来的题找谁"。

做完作业之后就是"呼吸游戏"时间。他已经在这几年里逐步把之前那个极其委婉的"体感通径"教程更推进了一步——现在开始引入最简单的引气呼吸法。方法融入在一个非常好看的仪式中:他会把房间里带油灯调暗一小些，让她闭上眼睛，用手掌对着窗外那棵皂荚树的方向，然后一起深吸慢呼。他说这个游戏的规则是——"呼出来的气会跟树叶说你好"。她闭眼憋不住笑——"老师树叶哪有耳朵"。他说"那你试试——看它会不会回你"。她试了几次，在深长的呼气之后，她说"我觉得——我觉得手上好像有凉凉的——像是树在我手心吹风！"

那是灵气引体的第一步。非常浅，完全不能运行经脉——但感官接触已经开了。

除了陪她成长，他同时也继续在不知不觉中完成对她家的物理监护。苏大山家的灵稻种植最麻烦的就是灌溉——天气旱时田沟会干。林牧不会让苏大山亏到要去县城打工挣钱。于是每当村子旱情持续时，他就会在后山某个看不到人的地方用灵力刺激地下水层，把周边的浅泉水引流到到苏大山田头的老井里。苏大山第二天去田里一看井里水多得要漫出来，连跟家里人说"今年运气真好——井水涨了好多"。小晚哈哈笑着说"爸爸是不是没看到前几天下过雨"，然后跑去找老师。苏大山没想太多，反正水多不愁。

寻找婴儿期的她——这句计划大标题的言下之意是"她以前的人生并没有任何人从摇篮开始就保护她"。在第二世他从三十岁开始。在更早的世——根本来不及。但现在，从三岁到成年他都在场。这十五年不会被锁抹干净，它们会在她道心最深层成为支撑日后决断的主地基。无论将来的哪一世——只要她的灵魂中还残存着"曾被这样一个人的陪伴与安全感包裹过的印记"——她就可能更快地信任他。即使轮回锁清洗掉具体画面和姓名。

一个傍晚。她在自家门前跳绳。老猫卧在石板上看天色。他站在皂荚树旁看晚霞。她忽然跑过来把跳绳递给他，说"老师你来转绳，我跳"。两个人甩绳，她在中间跳。夕阳长长的光芒把两人的影子拉得非常长。那一幕持续了不到三分钟——但被猫的眼底记录为一条无形但极其温暖的记忆数据。在后来他们重看这日的守护日志时锦鲤把这组画面摘了出来——给它命了名:"第三世幼少期陪伴基线——跳绳3分钟"。对于任何一个漫长的守护者来说，能够陪在目标身边跳绳——已经是莫大的幸福。

那天晚上林牧坐在灯下继续写教案。大纲上的字数越来越多。第三世的早期目标实现得非常顺利。他期待的和她的一世——这一回终于不是从三十岁在大槐树下开始的错过了。这一次是她三岁站在皂荚树下摸猫尾巴——然后用一个竹杖末端转身招呼他走进自己的人生。

**作者：段锦佑**

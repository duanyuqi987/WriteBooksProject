# 《熵枢纪元：七重跃迁》正文 v4 重写目录

本目录用于存放基于旧正文素材与 detailed-v4 细纲重写的新正文。

## 写法原则

- 不覆盖原 `正文/` 目录，旧正文作为素材底稿保留。
- 每章必须服从对应 `细纲/chapter-xxxx.md` 的 `章群剧情链` 与 `本章交易`。
- 可以参考硬科幻的写作方法：冷静叙述、可复查证据、宏观尺度、技术报告感、克制情感、用物理异常推动人物选择。
- 不直接模仿任何在世作家的具体文风、句法和标志性表达。
- 旧正文中可保留的内容包括核心事件、人物关系、关键意象、证物、对话功能和章末钩子；需要重写的是因果结构、场景压力、交易代价和语言密度。
- 从 `chapter-0351` 起执行新规则：不再对旧正文做补丁式修复，旧正文只作为素材库；正文必须按“一个可复查证物、一次实验动作、一个真实损失、一个下一章入口”全新重写。
- 第2卷《弥散·量子之云》必须减少第一卷式机房、硬件、协议和指挥部流水账，让非人意识、量子层证物、眷恋硬证物成为叙事推进核心。

# 第305章 火星上建立第一个星外修士基地

李长生的手掌按在冥殿中央的灵气循环总阵眼上之后，离宫的苏醒不是逐渐发生的——是爆发式的。

从冥殿出发，沿十二条主灵气通道向外辐射——每到一处功能区域，那里的阵法就自动启动。不是手动一个一个开的。是守殿人在接收到李长生的"全面重启"命令后，同时激活了所有还能运转的子系统。一万年前建造离宫时，工程标准高得离谱——大部分子系统即使在完全休眠一万年后，一经激活就立刻进入了正常运行状态。

首先苏醒的是灵脉循环系统。这是离宫的"心脏"。火星地壳下那条巨大的灵脉总枢纽被冥王令的力量重新激活——不是从零开始，而是从百分之六十的待机状态提升到百分之九十五以上的全功率输出。灵脉中的灵气顺着十二条主通道涌入宫殿本体，再经过数千条分支管道分配到每一个房间、每一条走廊、每一个修炼室。整座离宫内部的灵气浓度在不到三分钟内从接近真空飙升到了外界的两千倍。

然后是环境维持系统。离宫的四壁内部镶嵌着一套闭环的空气净化与温度调节阵法——一万年前的设计，用的不是机械通风，而是灵气驱动的分子级空气过滤。阵法启动后，离宫内部积存了一万年的死气和尘埃在三分钟内被全部抽出，替换为从火星大气层顶部收集的稀薄二氧化碳，再通过灵石催化反应分解为氧气——整个过程完全不需要植物参与。离宫内部的温度从零下八十度回升到了二十六度——适合人类生存的恒温状态。

接下来是防御系统。离宫外围共有一千四百台战傀进入激活预备状态——但不再是守护防御，而是驻守与护卫。守殿人根据李长生的指令，将它们的目标识别模块从"攻击非冥气持有者"改为了"保护所有获授权的基地人员"。

最后是生活区复温。离宫本就是按照能容纳不少于三千名修士长期居住来修建的。它包括：修炼区（两百间独立修炼密室，每间配有独立灵气调节阵）、生活区（一千多间标准宿舍，一间宿舍可住一到三人）、后勤区（三套大型灵气供能系统，可独立支撑全基地运转）、物资储存区（一万年前储备的灵石、丹药和法器）——这些库存在一万年后的今天已经基本全部失效——但仓库本身是完好的。整个离宫的空间总面积大约相当于地球上的一个中等规模军事基地——不是那种几千人的小哨站，而是真正可以容纳一个完整军事单位驻扎的综合基地。

"这是全套的——"刀疤跟着李长生穿过刚被激活的修炼区走廊。走廊两侧是一扇扇石门，每扇门后是一间修炼密室。他推开一扇门往里看了一眼——密室内部大约有六七平方米，地面上安装着可调节的聚灵阵，墙上的符文面板可以手动调节室内灵气浓度、温度和重力。"——相当于陆军的一个标准营地。不对——比标准营地还好。至少是旅级驻地的标准。"

"三千人的容纳规模。"小王看了看守殿人推送到自己电脑上的离宫建筑结构图，"加上外面的战傀守卫、灵脉自给自足的能量系统、固定的环境维持系统——这在整个火星上的存在，就相当于一个空军基地在地球上的地位。问题是——人呢？"

"人会来的。"李长生说。

他转头看向秦川。秦川一直沉默地跟在队伍后面——作为龙组的代表，他的任务是评估离宫的军事价值。他不是修士——但他的军事判断力能补足修士缺乏的战略眼光。他从进来之后就一直在观察离宫的结构、防御、环境、交通动线——所有一个职业军事人员会看的东西。

"李长生。"秦川停下脚步。他的声音不大，但每个字都经过了明显的斟酌，"我刚才走完了一圈。从入口到这里——直线距离大约有两公里，中间要经过十二个防御区。光是这十二个防御区就能挡住至少一个师的常规地面部队——我不是说修士，我说的是拿枪的军队。加上一千四百台战傀——每台的战斗力大约相当于十个特种兵——这就是至少一个加强旅的防御火力。再加上外围的维度屏障——火星大气层外面的那道自然屏障——整个基地的防御强度——"

他停顿了一下。

"没有任何国家——没有任何一个国家——能在不付出全军覆没代价的情况下突破这里。"

"如果来的是修士呢？"陈霜问。

"修士？"秦川摇了摇头，"月球上的那些战傀你们见识过了。这里的战傀只会更猛。这不是给普通军队准备的防御体系——这是给神级修士准备的。这个判断不是我的猜猜——是守殿人的数据：十七次探测尝试全部被外围挡住。最后一次来了五个帝者级修士，两个死在这里。帝者级——在你们修仙体系里是仅次于神明级的存在，地球上大概一个都没有。五个帝者联手都打不进来——你觉得地球上有哪个宗门能拿出五个帝者？"

没人回答。答案不言自明。没有。

接下来的一天里，李长生和守殿人一起完成了离宫的全面功能测试。守殿人逐个启动了所有子系统——它很细致，每一个功能模块都要先自检一遍才敢打开。它在这一万年间做过三千多次自我优化，对离宫的每一个细节都了如指掌。测试结果是：离宫的全部核心功能——百分之九十八点三可用。只有边缘的几个不重要的小功能模块因为灵脉分支在一万年间自然枯竭而失效。核心区域——灵气循环、防御系统、环境维持、通讯系统、战傀网络——完好率百分之百。

最后一个测试项目是全基地的通讯系统。离宫配备了一套星际通讯阵法——不是光速通讯，而是利用灵气量子纠缠的超光速即时通讯。理论上能覆盖整个太阳系。守殿人将系统激活后，李长生用它联系了地球上的龙组总部。通讯质量非常清晰——延迟为零。超光速通讯——无论是在地球和火星之间的几十万到四亿公里——保持即时同步，毫无卡顿。

龙组总部的接线员用了整整三秒钟才反应过来这通通讯来自火星。又过了十秒，一个苍老而沉稳的声音接入了通讯："李长生——我是周老。你们在火星发现什么了？"周老在了解情况后，沉默了几秒。"一个可以容纳三千修士的基地。防御系统全功能。AI系统运行了一万年。通信系统支持太阳系内超光速通讯。还有——冥王本人的完整功法库和太阳系防御系统操作手册——"他吸了一口气。"李长生——你知道这意味着什么吗？"

"知道。"李长生的声音很平稳，"中国拥有了人类历史上第一个星外长期驻留基地。"

"不止。"周老的声音中带着一种沉重但坚定的重量，"不仅仅是基地。是桥头堡。离宫的位置在火星——但它的功能辐射范围是整个太阳系。如果太阳系的五层防御系统能被重新启动——地球就将变成一个星际堡垒。而火星离宫就是这个堡垒的总指挥部。"

"五层全系统。需要派人逐一现场修复。"

"国家会派人。"周老没有任何犹豫，"你激活的这个基地——是中国进入星际时代的门票。"

通讯结束后的一小时内，周老通过龙组的密级通道向最高层发送了一份紧急报告。报告内容很简短——但每一个字都意味着一个新纪元的开始。

第二天，一则由龙组签署的密令通过灵气量子通讯传到了火星："祝融号与配套运输舰将在一个月内启程。首批人员五十名草根修士、二十名航天员。你为指挥官。离宫编号正式更名——中国火星修士基地。"

李长生站在离宫的入口处。火星的红色荒原在他面前延伸到天际。一个月后——第一批人就能抵达这里。火星上第一个星外修士基地——也是中国正式迈入星际时代的第一个前哨站。而他们离真正的征程——前往五万光年外那颗诅咒之星——还差最后一块碎片。

他掌心冥王令的暗金光芒缓缓流动。感应着那遥远之处的最后一块碎片，那若有若无的共鸣像是一声从五万光年外传来的叹息。

(第305章完)

# 第五百五十九章 相互理解的力量改变世界（一）

"相互理解"这个词在许多仙人的传统认知中一直是空洞的陈词。修仙世界是冰冷的——追求力量、争夺资源、防范外敌——这些才是硬逻辑。"道侣之间的相互理解"不过是感性词汇。但在双心诀和百世传奇的广泛传播之下这种观念开始被动摇。动摇它的不是那对道侣的光环比他们强。是她的那套表格——是数据、是事实、是异步缓冲层在实战和修炼中的实际有效。可以被复现、可以被实践，比之前的那些要求"强求同频"的传统修炼观有着更直观也更可实作的对策性。

在北冥苦修派的老修士牵驴送了黑豆之后，苦修派内部做了一件在派外看来有点夸张但对传统打破极其巨大的事。他们将道侣修炼日的晨钟时间由原本严格的统一时间往每一个人各自调整了各自的最适时间。也就是说，以前所有人同步在太阳升起时一起开功；现在可以异步——各人根据自己的灵核最适时间早起。这个改变的技术方案参照的是双心诀异步缓冲层的模型——将统一钟声分解为多个不同步微小时间段，缓冲时差用功德绳暂时无法负担的差额由一种临时的小型灵气缓存法器来替代。这是整个苦修派几百年来第一次在核心规训上让步于个体的"舒适速度"。并且效果非常好——苦修效率在调整后的初期就有了明显改善。苦修派掌教在内部告示上写了一段话:"这以前是宗训碑上写的——上善若水焉。然而真正落实于日常制度的善不若细水从每人自己心里流出。从某个卖豆腐的每天把那摊往旁边挪一小寸那引申流到这里来了。"

苏晚看到这份告示副本时，用功德绳把"细水从自己心里流出"这句话传给林牧。林牧在修完船后回传了他自己的解读版本:"苦修派在说你。你是挪摊的那半过——不是我。我只是劈柴的。"苏晚用通灵把那句"挪摊的是你——豆腐干才是挪过，我的是白豆腐脑不用挪"的全部豆制品身份纠错传了回去。他收到后以极轻极柔的方式在心里认了那半过。

当然仙界仍然有太多地方不信这套"软沟通"。五方仙域的边缘荒漠——一些散修间的零散冲突仍然以暴制暴。但总比之前少了很多。仙缘司的通灵道侣注册中心已经把那对"第一对异步修炼源道侣"作为注册前播放的一段简短入门影像录像的画面素材。所有新道侣在注册之前都要花一点时间听她的声音念出那句:"对的关系——你可以用自己的速度去爱。"

（第五百五十九章 完）

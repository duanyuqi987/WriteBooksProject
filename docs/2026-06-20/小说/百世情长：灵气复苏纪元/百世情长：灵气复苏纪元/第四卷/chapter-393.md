# 第三百九十三章 九城之间的路

飞升第二年上半年，两人受邀在各城之间巡游。第一站是黑琊城——阎锋旧领。被秦狩接手后城市曾一度破败不堪，但如今由新任守护者（一名与阎锋在早年有过交情的旧将）掌管。那将带他们看了月桂花种子的母树——种在黑琊城遗迹上唯一未被摧毁的那半边。他将一小包未用完的桂花种交给了林牧——说:"阎锋走前留下的。他让我给日后见到的闻道——说'放在她墓前的那株是给你的'。余种是送你和你的道侣的。"

林牧接下种子。没有多言。他和苏晚离开时在城门口将她捡的一株忍冬属幼苗种在城垛土里——说:"桂花会再开。这里也不会再崩。"

接下来再到第三城——墨染的故乡。城民对闻道的态度多为叹息与歉意。他们在城中小集上见到墨染一位年逾百岁的乳母——老人头发全白但神智清晰。她赠给苏晚一罐墨染年轻时喜欢的山蜜。说:"姑娘——你的手很稳，和她一样。她若活到今日，会和你做很好的朋友。"苏晚接过蜜罐，说:"那我替她吃——并把蜜罐放在她墓前。"后来蜜罐真的放在了月桂花旁——在那之上她加了一块刻着双剑的小插牌:"来自第三城的好友墨染。"

巡游中他们发现各城之间存在一些灵脉沟通迟滞——凡间灵网模式在理论上可适用于上界城际通讯。林牧随即在笔记中起草了"上界灵网方案初稿"。

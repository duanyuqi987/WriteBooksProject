# 第961章 更远的远方

在道源第三形态稳定运行数万年后，林牧在某次碎域探索中发现了一份更古老的星图——它记录的不是上界大陆，而是上界大陆之外的更远区域："界外虚空"。古籍中称之为"无尽海"——是连上界仙人都极少涉足的终极未知领域。那里的规则极其稀疏，几乎不存在"法则"本身——在那样的环境中，修行和生存都不依赖吸收灵气，而是纯靠道心与混沌的磨合。

林牧把这个发现分享给了苏晚。不是要拉着她一起去冒险——是问她："你想去看看吗？"

苏晚想了一天。第二天晚上她说："想。但不是现在——等传道堂不需要我们再充当任何'根基'的时候。"她说这话的意思是——等到太行传道堂的体系达到某个临界点：即使道源第三形态因为任何原因停摆，整个上界的底层教育机制也仍然可以自行运转而不出现断档。她需要的是"完全自治的永续"。

接下来的数千年——她帮助传道堂建成了"源尘后备库"——将从第九重霄暗界收集到的所有残存源尘（加上她新发现的零星碎屑）做了封存。如果有一天她体内的道源因为某种不可抗原因失效，后备库可以续上数万年的公共慈念供应。她同时还建立了"道基自治协议"——一份去中心化导师自治公约，把传道堂的全部管理制度简化到任何人都可以复制、重建——即使整个太初之城被毁灭，只要还有一个人记得"三不"原则并愿意教，传道堂模式就可以在任何地点重新生根发芽。

建完之后，她安安心心地把后备库的钥匙（不是实物，是一段需要两名长老联合验证的道心共振密码）交给了白羽令的第十代继任者。她说："现在可以走了。"

林牧准备了途中所需要的简单装备——不是为了战斗，是为了在无尽海的混沌中维持稳定的道心输出。装备极其简单：两套备用的聚灵阵玉、一壶她做的凉茶、一包她昨夜新烤的红薯饼。两人并肩踏上了驶向无尽海的路——不是逃跑，不是为了刺激——是因为在完成了一切"应该做的事"之后，永生的下一个章节自然而然地开启了：一起看看还从未有人见过的远方。

无尽海的边缘与太初之城相隔大半个上界大陆——在极北穹顶的更北的虚空中。一路之上他们并不急——每天走几十里，遇到正在教课的传道堂分部就坐进去旁听，偶尔在某个边远的碎域前搭一晚帐篷。

星图指向的无尽海入口是一道法则裂缝——裂缝之外是纯黑的空无。不是死亡的黑暗——是"法则尚未生成"的初始混沌。林牧将见道的意志探入裂缝——感知到混沌中有什么极慢的呼吸——不是生灵，是空间自身在缓慢形成。

他回头看苏晚。她站在裂缝边缘，手里握着那个装了红线的纳戒——那根是她们最初的联系。"走吧。"她说。

他握住了她的手。两人并肩踏入混沌。

《百世情长：灵气复苏纪元》第十卷 第961章 完

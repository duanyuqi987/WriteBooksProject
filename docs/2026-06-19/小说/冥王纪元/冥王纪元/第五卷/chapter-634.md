# 第634章 继续寻找

李长生在月球基地的观测室里坐到了后半夜。

他在凌晨两点的时候做了一个决定——不是新鲜的决定，是把之前的决定从"模糊"变成"精确"。之前他只知道要继续找混沌碎片。现在他把三个前置条件和已有进度全部对齐了：四块碎片他有两块。第三块在宇宙联盟禁区。第四块的坐标还不确定——但前两块碎片在融合后会产生共振数据，这个数据可以推算出第四块碎片的方位。

他现在需要同时做三件事：进入禁区取第三块碎片、用共振数据推算第四块的位置、在拿到全部四块之后——让自己跨入纯混沌级。

纯混沌级——这意味着他的修为要从目前"冥王级加半步混沌"的状态，完全迈入混沌领域。这个门槛的高度是多少，没有任何人知道。龟相拿出了一个理论模型——基于混沌之主记忆碎片里提取的能量量级数据——计算结果让在场所有人沉默了：如果以冥王级的最高能量密度为基准值1——纯混沌级的能量密度是基准值的约四千倍。

不是四十倍。是四千倍。

李长生现在两块碎片融合后的能量密度已经达到基准值的约九十六倍——已经远超任何冥王级修士。但距离四千倍——还差四十倍以上。这意味着即使集齐四块碎片，他仍然需要在四块碎片合一的瞬间，完成一次能量密度的高阶跳跃。这一步如果没算好——他的身体会在合一的瞬间直接消散。

"但太初留给混沌之主的时间不够它走到那一步。"龟相说，"混沌之主用了十二亿年才达到纯混沌级。你——我们推测你有大约几年。"

"几年？几年是你说的。太初的时间观念里没有几年——只有'现在该做'和'还没到'。"李长生说，"万一它觉得这个宇宙已经完成了，下一秒就动手——我手上多少碎片都没用。"

"所以你要在最短的时间里拿到剩下两块碎片。"陈霜接道，"不是去不去的问题——是多快的问题。"

"多快——"龟相的两根前肢在桌上敲了两下。这是他算完一件事的动作。他全息屏上弹出了计算结果，"如果第三块在禁区核心，加上封印突破的时间、来回路程、碎片融合的适应区间——最乐观的估计——三十天。三十天后你可以出发去拿第四块。"

"不够。"李长生说，"还需要更快。"

他右手掌心的两层纹路亮了一下。不是发光——是发热。两块碎片的混沌能量开始在他体内加速运行。他在给自己加热——不是物理学意义上的加热，是通过混沌通道的加速运转，把全身的能量代谢频率提高。这是他在黑洞核心里被混沌能量锻造四十次后获得的能力——主动调谐自己的能量运转速度。运转越快，他的反应速度、感知灵敏度、对外攻击力全部同步提升——代价是身体负荷也会加大。

"你现在就要走。"周老的声音从门口传来。老人穿着那件灰色中山装，站在观测室的金属门框里。他手里没有搪瓷缸——深夜里他不喝茶。但他的精神比任何人都清醒——好像一百二十岁的老人不需要睡觉。"我刚才和宇宙联盟的联络处通了话。第三块碎片所在的禁区——那地方不叫'禁区'。宇宙联盟的正式称呼是'初代封禁区'。这个名字在联盟档案里被加密了一千四百年——刚才才解密。"

"为什么选现在解密？"李长生问。

"因为四十亿年前天琴座'大归还'的记录也是在同一时间被解密的。不是我们请他们解密——是我们提到太初之后，联盟档案系统自动触发了关联解密。太初这个名字——是触发词。所有和它关联的加密记录全部在这次会议后自动解锁了。"周老走进来，把一张纸搁在观测台上。纸上打印出了一份雷达扫描图——一个球形的、直径约三百光年的区域。区域边界上有密密麻麻的能量标记——每一圈标记代表一层封禁。

"初代封禁区——从最外层到核心，总共封了十七道封印。每一道封印都是由不同时代的最强者亲手施加的——最早的一道距今约十一亿年。"周老看着李长生，"十一亿年前，第一道封印由混沌之主亲手封的。"

混沌之主封的。

这意味着第三块碎片不是被"藏"在禁区——是被混沌之主自己封进去的。混沌之主在临死前不仅建了黑洞存放第二块碎片——还建了一个禁区，专门存放第三块。他故意把所有碎片分散在不同的保险库里——每一个保险库都有自己的考验模式。黑洞考验的是"意志"，禁区考验的——还不知道。

"明天出发。"李长生说，"不——天亮就出发。第三块碎片——越早拿到越好。"

他站起来。在观测室的微弱灯光下，他眉心那道极细的竖纹——意志凝聚点的位置——微微亮了一下。不是炫耀。是他的意志在工作。这道纹路平时出现在他做重要决定的时候。而现在——它几乎一直在亮。

因为他做的每一个决定，现在都可能是最后一个。在太初注视之下的每一步——都可能决定这个宇宙里所有人的命运。

（第634章完）

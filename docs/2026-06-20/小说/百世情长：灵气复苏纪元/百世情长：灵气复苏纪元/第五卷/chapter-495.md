# 第四百九十五章 这一世的圆满

松鹤仙人的青梅酒喝光的这天，迎仙台举行了一场简单到极的仪式。不是婚礼——仙界的道侣不需要专门去办仪式，红绳一旦系上就是最正式的道侣契约了。这次办的是"功德圆满答谢宴"。是迎仙台传统的极小型团聚——所有在迎仙台服务过的仙人们一起坐到石桌上，每人摆出自己带来的一小碟菜，放在转桌中央轮流分食。苏晚摆的菜是冰晶草的花瓣炒鸡蛋——鸡蛋是从仙栈后面那几只散养仙鸡取来的。冰晶草的花瓣是她问松鹤仙人借的那株母草上摘了三四瓣，很珍贵，但她全部炒进了这道菜里。花入馔后那股极淡极淡的清甜味入油就散开了，蛋花带甜却不过，极好吃。

林牧摆的菜最奇怪——煮饭。就是他平时在仙居后院劈完柴煮的那种最普通的白米饭。他摆了满满一大碗。碗是粗陶的，和他在下界公寓里用的那个极丑极旧的蓝边大碗形状相同。他把这碗白饭放在满桌仙膳佳肴正中央——在一盘盘仙果、仙兽、千年灵芝烹成的美味中间，这碗白饭显得既朴素又突兀。而松鹤仙人看到这碗白饭时反而大笑了一声——他的笑声笑得极洪亮，把桌上其他人的杯子都给震动了。他用勺子挖了一口饭送进嘴里，没嚼几口就咽了下去。然后他擦了擦嘴角的饭粒说了句:"八千年了——终于有人往我这桌上摆碗饭。以前他们全都拿仙丹当主食——吃得我胃凉。"

苏晚把自己那份炒蛋用筷子夹了好几块放进松鹤老人的碗里。寻青仙子和守望真仙也带了他们下界的家乡菜——一碟用下界辣椒酱凉拌的野菜。野菜不名贵，但辣得松鹤老人直咳嗽。桌上一共也就不到十个人——但吃起来的热闹劲已经把这八千年的孤零味全冲散了。

散宴之后松鹤老人坐在石凳上抽了一根旱烟。烟的源头是一株生在迎仙碑上方的野生烟草。他吸了几口之后喷出一个极大的烟圈——烟圈飘到迎仙碑的上空后绕着碑身滑了一圈缓缓消释。他把烟锅在石凳腿上磕了磕，站起来拍了拍袍子上的烟灰。

"我老松鹤在迎仙台上坐了小八千年——今天这碗白饭最落胃。以后迎仙台的日常都交给你们两个小家伙了。我年纪大了——这阵子我打算去南离城逛逛，买两壶新茶。那些阵子你们干得不错——都交接了。以后不管谁飞来，吃的第一件东西也是这碗饭——这个传统今天由你们立下。"

松鹤仙人第二天一早就出发了。他裹了件旧得发白的大氅，往南离城的方向悠悠踱去。苏晚在迎仙台门口送他，老仙人走得极慢但脚步极稳。他的身影渐渐变成远处一个极小极缓的黑点。林牧从院中出来手臂上挂着那把调好弦的琴。苏晚看了一眼他——他也在看着那个远去的老人。"他会回来的。青梅酒还剩半缸被他藏在石凳下边——他自己才清楚。"

（第四百九十五章 完）

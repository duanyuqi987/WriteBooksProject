# 第612章 非生非死

李长生和陈霜向前走了十七步。

每一步的间隔都在缩短。不是因为他们走得更快了——是因为那只混沌生物在提高测试的强度。从第一步到第十步，灰雾刀片的密度提高了一倍。从第十步到第十七步，密度再次翻倍。现在他们每踏出一步所面临的压力，相当于两个帝者级同时出手。

"这不是战斗。"陈霜的冰冥之花上出现了裂纹——那是承受无尽灰色利刃撞击的结果，"这是消磨。它想知道我们能在极限状态下坚持多久——如果我们在中途力竭停下来，它可能永远把我们困在这里。"

"不会停。"李长生说。他的冥气护罩产生了第一次颤抖——混沌级的护罩首次在压力下出现了颤动。

第十八步。

混沌生物变换了攻击方式。

灰雾刀片忽然全部停了下来。整片灰蒙蒙的维度都静止了——像风暴前的寂静。然后所有的灰雾开始向中心坍缩。不再是刀片——灰雾被生物的意识驱动着压缩成了更致命的形式：一根巨大的灰矛。直径为零——矛尖无限细，细过了任何物理尺寸。这根矛的尖端不带有任何质量——它携带的是纯粹的"存在否定"。任何被这根矛刺中的东西——不论物质、能量还是修士——它的存在会被瞬间归零。不是死亡。是归零——一直在那里，从未出现过。

李长生认出了这种力量——和《黄泉倒悬》在本质上同根同源。但《黄泉倒悬》只是召唤已死之物的怨念——而这只混沌生物，它自己就是抹除。它在混沌之海中被创造的时候就是"否定存在"本身——它不需要召唤。它就是否定。

灰矛刺来了。

速度极快——快到混沌级的感应都只能捕捉到一个闪了一下。矛尖穿过了冥气护罩——护罩中充满了冥气，本是万物皆可防御的最强屏障——矛尖将冥气以每秒钟百米的速度抹除。一块冥气护罩少了拳头大的一块——不是穿过去了，是那块冥气直接从"还存在"变成了"从未存在"。

"闪！"

李长生拉着陈霜向侧面瞬移了三公里。但灰矛像长了眼睛——它一直锁定了两人。混沌生物的"脸"转向他们——那面容还是片刻前出现的人脸——只是这一次面容上多了一道口型。那是微笑。

它在微笑。

不是嘲弄。更接近于期待——仿佛终于看到了让它稍感兴趣的东西。

第二矛刺来。

这一次李长生没有闪。他双掌一合——冥王令在身前化为巨盾。黑金色的冥王之力在两掌之间形成了一个收缩极度密实的环形结界。灰矛刺上结界——两股力量同时暴发出光晕。灰雾与冥气在接触界面上互相消融。持续了整整三秒。灰矛碎了一小段——矛尖被冥玉结界震飞了一部分。但碎掉的那一根矛尖——不是碎片——它在飞行途中消失得无影无踪。不是被破坏了。是被攻击本身"归于无"了。

陈霜趁着间隙向混沌生物本体释放了一道冰冥剑气——她最强的单体攻击。灰白色的剑光划过三公里的距离，精准地射向混沌生物那张人脸。

生物动了。

它没有闪避。只是抬起了一只手——或者说是那个"类似手"的触角变化成了手的形状——握住了剑气。它的手指一接触剑气的瞬间就完全变黑了——冰冥之力冻结了它的手指。冻结的区域扩张到了半只手掌——然后从冻结中自行长出了一层新的灰色物质修复了被冻着的区域。

它不是在修复。是在重新定义自己——将被冻结的"死"重新诠释为"从未结冰过的生"。它的存在是非生非死——不输于死的定域，也不受生的制约。它能自行定义每一步——生或死——在它手中没有差别。

李长生看明白了。这只混沌生物之所以非生非死——是因为它本身就是混沌之主被撕裂时从伤口中渗出的混沌之血。它不是独立的生物。它是混沌之主的创口。守护碎片——是它在完整消亡前为自己赋予的唯一存在意义。

"你不是在测试我们。"李长生向它说，"你在看看我们有没有资格把它带走。你在决定——要不要把它交给我们。"

那生物静止了片刻。它的面容缓缓恢复了没有口型的中性表情。

然后整个维度的灰雾出现了一个奇妙的改变。所有的雾开始散开。不是消散——而是退开，像一扇缓缓掀动的巨大幕布——让出一条通往这个维度中央的路。

路上没有陷阱。灰雾退开之后露出了一块空旷地带——空地的正中央悬浮着一块混沌碎片。第四块。已经没有任何外围保护或封印——只有碎片自己，安静地悬在那里。

混沌生物用它那无定的声音说了第二句话——也是最后一句话：

"取走它。我守了十亿年。现在交给你。"

（第612章完）

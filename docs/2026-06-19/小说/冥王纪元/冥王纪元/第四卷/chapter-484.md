# 第484章 宇宙西部版图确立

公审之后的第一个月，整个宇宙西部像被重新钉了一张星图。旧版图上原先标注的那些零散势力——独立宗派、自由城邦、星盗巢群、殖民星领地——在短短四个星期内全部消融。不是因为战争。是因为他们主动来了。

第一个主动来投的是银河系第七旋臂的一个大宗派——朱雀星盟。朱雀星盟在银河系西部是数得上号的老牌势力，拥有十三颗主星和近百颗附属星。盟主是个仙王级初期的女修士，法名叫赤离。她的祖先在上古时代曾经是冥王阵营中的一个将领的战友——这段渊源她自己都说不清到底是不是真的。但这不是重点。重点是她在龙组基地见到李长生时说的第一句话。

"我们不是来归附你的部队的。我们是来归入你治下的。这两者不一样。前者只是军事同盟——后者是从此同属一个文明体系。我们自愿废除我们旧有的独立法条，采用你未来会颁布的新法度。"

李长生沉默了片刻，然后点了点头。他不是在权衡利弊——他是觉得这个责任很重。一个宗派自愿放弃独立法条，这意味着未来他需要对这些人负责。他不再只是一个部队领袖，而是一个正在浮出水面的文明政权的主导者。

"你们有什么要求？"李长生问。

"一个。"赤离说，"保留我们朱雀星盟的文化符号——那枚朱雀印。它不只是一种图腾，也承载着我们几千年的文明记忆。我们不需要独立的政治主权——但想保留我们的文化灵魂。"

"行。"李长生回答得很干脆。

第二个来的是银河系最西端边缘的一群星盗——不是舰队进犯，是星盗首领一个人带了他所有的副手，坐着破烂的战斗艇，越过两万多光年，专门到地球来投降。星盗首领不是别人——正是李长生早前在飞往诅咒之星的途中遇到的那个星盗头子。当时刀疤一个人单挑了二十几艘星盗船又把他们全部饶了命的那个群盗首领。

星盗头子站在龙组基地前面的花岗岩台阶上，穿着一件严重磨损的半旧皮甲，脸上的紧张怎么都遮不住。他先单膝跪地，然后马上想起来地球的礼节不一样，又改成低头深鞠躬，最后干脆蹲下了。姿势很狼狈，但话很直接——

"冥王——我们知道我们这帮人不配归属你。但我想着……去别人那投，别人要我但我心里不会踏实。我挨过你的打——挨完你没杀我们——这事儿我记在心里。"

李长生看着他，沉默了一下。然后问："你手下有多少人？"

"七百多。还有几万的家属、后勤、还有在暗处躲着的以前被我们救过的普通人。"

"全收。"李长生说，"但你们得守规矩。第一——不再做星盗。第二——把你的部下全部送入许冰的执法训练营，训练毕业以后转为帝国执法艇队。第三——你的副手以后由许冰统一指派任务。"

星盗头子在地上蹲了很久，然后他闷声笑了——笑到自己蹲不住往后一屁股坐在花岗岩阶上。那一刻他好像松了一口气——压了他几十年的某个东西在今天终于被抽掉了。

第三个来的是银河系核心区的一个中立中立观察团——一群擅长空间阵法的上古遗族。这个族群在整个银河系中一直保持绝对中立——不去进攻任何人，也不让任何人进攻他们。他们依赖一种极其精密的空间折叠防御系统，把自己的星域包在层层空间中，从古至今没有人成功攻破过。但他们选择在今天主动出现，提的不是归附——是对等合作。古族代表是一个半透明的虚影——肉体在几光年外的星域中，精神投影出现在李长生面前。

"冥王的回归——我们的古籍中记载了。你们的宇宙西部需要一个空间稳定的中心枢纽。我们提供这项技术——不收取灵石费用。但要一个条件：永远不要将空间技术用于进攻性武器。"

李长生同意了。这个协议后来在历史上被称为"空间和平协定"——它是银河系西部历史上第一个以"技术限制"换取"永久和平"的跨文明协议。

在一个月内——整个宇宙西部的版图基本在"来的"而不是"打的"中确立了从银河西臂到银河核心区的广阔疆域。刀疤的精锐部队没有参加任何一场战斗——不是不能打，是不需要打。宇宙各势力主动融入的速度远超所有人预计。李长生的名字不再只是一个强者的代名词——它正在成为一种新的秩序的代名词。

到月底的最后一天，小王在全息星图上做了最后一次信息更新。他指着星图上被标注为浅灰色的那片辽阔区域说了一句话："宇宙西部——版图已定。"

（第484章完）

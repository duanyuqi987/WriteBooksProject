# 第948章 千年后的银杏树下

上界第六百年的某一天——苏晚通过道源感知到了一种呼唤。不是求救信号——是来自下界的念力。太行书院的千万师生在某个特殊日子（大概是什么百年纪念）同时在银杏树下举行了一场集体打坐——他们念的不是咒语，而是最基础的"观息"口诀中循环出现的"吸——呼——"连成的心念波。这层念力太稀薄，无法突破两界的法则屏蔽传递任何具体信息。但它在红线的道心中引起了涟漪——苏晚感应到了一阵微弱的、持续的、来自下界的暖意。她知道那不是任何具体的消息——而是"他们还在"。

她把这件事告诉了林牧。"我想回去看看。"

反向通道只能开一次。她现在无法再用归禾赠与的方式回到下界。但另有一条路——可以从星云漩涡中心的那个极小的暗点（上界和下界唯一的物理接触残余）中，用道源和见道的联合力量投影一缕神识过去。神识不能携带肉身——但能看到听到。

林牧帮她完成了神识投射。她的神识化作一缕极透明的光丝穿过暗点，降临在太行山顶的银杏树上空。她看到了下界二千年后的太行书院：

银杏树已经长得更大了。它的树干在两千年的灵气滋养中扩张了许多。树下建了一座小广场——广场核心石台上安放着太行书院第一课石台保护栏内的那块旧石台。石台被保护栏围着完好无损。栏外的碑刻写着："太行书院第一课旧址。苏晚——太行书院永远的一名新生。林牧——飞升于此。凡来者皆可在此免费打坐。"

广场周围的几座峰头这些年又修了许多新的教学楼。学制大幅度改良——从完全的免费筑基到现在增加了更多元化的进阶专业。各分院之间通过灵讯网联动教学。陈小楼的曾曾孙辈仍在这里教书——一位名叫陈念初的女导师——她望着银杏树枝说了一句："苏太师祖——银杏树又黄了。"

苏晚在神识的投影中看着银杏叶一片一片飘落——广场上一个正学着打坐的孩子（大约七八岁）把一片叶子捡起来放在石台上"给老师"。孩子的母亲在旁边微笑——那是陈家的第八代后人。

她收回神识，回到上界的院中。林牧扶住她的肩膀——神识投射极其消耗心神。她把头靠在他肩窝上，说："银杏树还活着。广场上多了一块碑——碑上写着我永远是一名新生。一名新生——我很喜欢这个头衔。"

"新生。"

"第一次坐在天台上的那种新生——什么都不会，什么都不懂——但什么都想学。到现在我还是新生。每活一年都发现自己不会的永远比会的多。书院的孩子也把我叫新生——这是最准的称谓。"

林牧把她扶稳。天边划过一颗小流星——是上界仙禽在夜空中做了一回短急转向。"林牧。"苏晚忽然抓住了他的手腕。"我们已经在太初之城住了六百多年。太行书院也活了很久了——以后我们每年都用投影打道回银杏树下——就看看叶子。"

"好。"一个字。

他们对视了一下。然后林牧开始着手搭建一套永久性的神识投影装置——将暗点附近的空间用见道法则固定住，使苏晚每年只需要极少能量便可投射一缕神识去看银杏广场。

装置在第一年试验成功之后，每年的深秋（银杏最黄的时候）苏晚都会对着银杏树发出一份投影。投影不干涉任何现实——她只是安静地"站"在树下把每个人认认真真看过去。不认识的名字、认不得的面孔——都认认真真看过。她不和他们说话——因为神识投影还做不到双向互动。但她离开时习惯性地在银杏树干上新画一道小小的"年轮"——和"十""零"二字并列，一年一画。若干年后树皮上的划痕会自然愈合并叠入新年的轮环中——成为古树自身自然的一部分。她从不干预古树的生命——只是每年给新增的树轮一个温和的祝福。这成了她永无止境旅途中的极简仪式。

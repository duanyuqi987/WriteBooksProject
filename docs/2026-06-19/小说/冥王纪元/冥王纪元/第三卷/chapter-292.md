# 第292章 探索地下，发现火星离宫遗址

按照龟相的指引，入口就在那片亮起的冥符大阵中心。

李长生顺着龟相给的位置走了大约四十分钟。火星的低重力环境让走路的效率比地球上高得多——每一步跨出去的距离是地球上的三倍，体力的消耗却只有三分之一。但低重力也让脚下的沙土更容易被踢起来——他的视野前方一直飘着一层薄薄的、缓落的红色尘埃。

入口到了。

那是一个竖井。直径约一百米——在地球上相当于一条八车道高速公路的宽度。井口的边缘不是自然形成的悬崖断面——是一圈完整的、经过精密打磨的环形石壁。石壁的材质不是火星本地的玄武岩——是某种暗灰色的、在火星表面任何地方都没有发现过的人造石材。石材表面没有风化的痕迹——一万年了，光滑得像昨天才打磨好的。

李长生站在井口边缘往下看。竖井直直地往地下延伸，深到肉眼看不到底。井壁从上到下刻满了符文——不是地表上那种横向排列的独立符文，是一整条连绵不断的螺旋形符文带。符文带从井口开始，沿着整个井壁盘旋向下，像一条没有尽头的蛇，一直延伸到肉眼看不到的黑暗深处。符文带上每一个符文的尺寸都有半人高——需要一个人张开双臂才能覆盖一个符文。

"竖井壁上的符文——"许冰用便携阵位仪扫描了一段符文带。阵位仪的屏幕上跳出了一行她始料未及的分析结果:符文深度八十厘米。刻入石材内部八十厘米。而正常的符文刻制深度——在地球上——通常不会超过三厘米。"这些符文不只是刻在表面的。它们嵌入了石材内部八十厘米——等于整块井壁的实际厚度有一半是符文结构。这是用灵力从石材内部构建出来的——不是用刀凿子刻的。"

"冥刻。"李长生说。上次在祝融号的冥驾舱里看过那种刻法之后，他已经能认出来。

老马往井里扔了一块荧光石——他出发前带了一包地球上的灵光石，这种石头在感应到灵气时会自动发光。石头在火星的低重力下以慢于地球的重力加速度往下坠落，石头的荧光光点越来越小、越来越小——四十三秒后才消失在黑暗中。四十三秒。按火星重力计算——这个竖井的深度至少是一千八百米。和许冰探测到的地下空腔深度一致。

"怎么下去？"老陈看着那口深不见底的竖井。他在城市里跑了好几十年——爬过高楼，钻过地下管道。但那些最深也只有几十米。一千八百米——从地面往下走一千八百米，在地球上相当于钻入地壳接近一公里。在火星上，没有任何人知道这井底下有什么。一万两千年的密封环境——氧气浓度、温度、压力——全是未知。还有龟相提醒过的——防御系统。

"飞下去。"李长生说。

他把宇航服的微型推进器功率调到最低。火星的重力只有地球的百分之三十八，下降速度可以用很小的推进力调节。他把冥力释放出一部分，在体表形成了一层薄薄的空间缓冲层——第六重冥界虚空境的虚空壁垒，可以在撞击发生时自动减缓冲击力。

"我先下。你们间隔一分钟跟一个人。老马——在井口留一道阵法锚点。如果下面出了意外需要紧急撤离，用锚点拉我们上去。"

老马在井口边缘的石材上拍了一下。手掌和石材接触的地方亮起了一道土黄色的灵力印记——那是土系追踪符。在火星的地壳内部，老马的土系灵力可以顺着岩层传导，追踪符的有效范围大约是三千米。够用。

李长生纵身跳入竖井。下降的速度在低重力下增长得很慢——第一秒他才落下不到两米。他让微型推进器在下落后十秒启动，把他的降速稳定在每秒十五米左右。周围的井壁在两侧缓缓上升——符文的暗光从井壁深处透出来，照亮了螺旋下降的通道。那些符文在他经过时会变亮——不是全亮，只有他掌心冥纹对应的那六道纹路在亮。剩下的三道不亮——那是还没找回来的三块碎片对应的纹路。

下降过程是安静的。火星地壳内部没有空气流动的声音，只有宇航服内部灵气循环系统的微弱嗡鸣。井壁上的万年符文在暗金色光芒中安静地旋转，像一部用石头写成的古老经书——而李长生是一个正在从经书第一页翻到最后一页的读者。

一千八百米处的井底——是一个巨大的圆形平台。

李长生在平台上着陆。脚下的触感不是岩石——是金属。一种在火星地下埋了一万两千年仍然没有锈蚀的合金。平台表面刻着八角阵——标准的传送阵布局，九个核心阵眼呈十字排列，外围八面内反射阵列。中心阵眼处有一个凹槽——形状是九边形，每条边长度不一，呈不规则多边形。

他认得那个凹槽的形状。在地球上六块碎片融合的时候，有一瞬间他见过完整冥王令的九边形轮廓——和这个凹槽分毫不差。

"平台上的传送阵中心有一个凹槽。"他按下通讯器，"我不确定这个传送阵还能不能用——但它的接收端是完好的。一万年前有人从这个传送阵被输送到火星——然后那个人把传送阵的接收端锁定了，只有持有冥王令的人才能重新激活。"

陈霜第二个落到平台上。她着地的时候脚底轻得像一片落叶——在低重力环境下，剑修的身法优势更加明显。她的手按在霜降剑柄上，目光扫过了平台上每一个角落。她的剑修直觉告诉她，这个平台——虽然看起来空旷——但绝不只是个平台。平台四周的墙壁上有隐约的、极浅的纹路。不是符文——是门廊。"这个八角阵有八个边。每条边对应的墙上都有一道门。但门被封住了——不是物理封口，是空间隐藏。有人用空间折叠把这些门藏了起来。肉眼看不到不是因为它不在——是因为它被折进了另一个空间夹层里。"

李长生走到一面墙前面。墙壁表面上看起来是平整的金属——但他的冥力感知捕捉到了墙壁内部的空间异常。在那层看似完整的金属之下，有一个被空间折叠压扁了的门洞——深度大约只有几微米，但实际面积大约是五米乘以五米。把一扇大门折叠成一片纸的厚度——这种空间压缩的技术和祝融号冥驾舱里的冥刻如出一辙。

他把右手按在墙上。六道冥纹贴墙——金属表面从接触点开始向外泛起了一圈圈暗金色的光纹。被折叠在空间夹层中的门洞开始"展开"。不是滑开不是翻——是展开。像把一张被折了很多次的纸重新摊平。空间在金属表面复原——被压缩到几微米厚的门洞在不断膨胀，恢复到了原始的五米乘以五米尺寸。门洞后面是一条深邃的廊道。廊道的墙壁、地面、天花板上全部刻满了发光符文。符文的亮度比井壁上更亮——因为这些符文离地下空腔的核心更近，被核心处的能量场持续供养了一万两千年。

李长生跨过门槛。

廊道的尽头是一片更广阔的黑暗——不是那种密闭空间的逼仄黑暗。是巨大空间的回声感。他的脚步声在有巨大空腔的空间里会产生极微弱的回声——那种回声告诉他，面前是一片极其辽阔的、他踏进来的第一步就产生了回响的、比地球上任何建筑都要宏大得多的空间。

"小王——把照明功率推到最大。"

祝融号上那台灵光探照灯的光束通过李长生携带的便携反射器照进了廊道尽头的黑暗中。光束打在黑暗中——然后被反射了。不是地面的反射——是墙壁、穹顶、立柱的反射。无数道漫反射回来的光芒在黑暗中勾勒出了一张让人停止呼吸的画面。

一座城市。

地下的城市。建在火星地下两千米处。穹顶的高度至少有五百米——相当于一百五十层楼。穹顶表面镶嵌了密密麻麻的光源——不是灯，是嵌在穹顶石材中的万年灵石。一万年的时间没有把它们消耗殆尽——它们仍然在发光。光的颜色是淡蓝色的，混合着灵石特有的温暖白光，像一片被封存在地下的星空。

在光源之下——是建筑群。行道、广场、高台、廊柱、宫墙。建筑的样式和地球上从殷墟到故宫都不太一样——这些建筑的线条更加锐利，用材更加冷峻。但整体格局——中轴对称、前殿后寝、左祖右社——和地球上的中国传统建筑格局如出一辙。只是放大到了令人难以置信的尺度。正中心的宫殿基座至少有两百米高——不是楼，是一整座山被削平了顶部之后在上面建的宫殿。

在宫殿基座的正前方——立着一块巨碑。碑身高约六十米，宽约十五米。碑面上用冥系符文刻着三个字——每个字有十米高。李长生认出了第一个字:冥。第二个字:王。第三个字的笔画他认得一部分——但不完全。因为这个字的左边偏旁对应第九道冥纹的走向——他还没有集齐第九块碎片，所以读不出完整的字。

"冥王殿。"陈霜替他读完了。她站的位置角度不同，借光的角度也有差异。"第三个字是'殿'。冥王殿。不是离宫——是正殿。这座建筑就是万年前冥王的正殿。"

平台上的所有人都站在廊道尽头，望着穹顶下那片宏伟到超越想象的地下城市。小胖手里的锅铲不知道什么已经在裤子上握到发烫了。老陈的嘴唇在头盔里动了几下，但什么话都没说出来。老马蹲在平台边缘，像是本能地想要用手去摸那些万年前的石材，然后才想起自己戴着手套。

刀疤说出了所有人心里在想但没说出口的话:"这地方——修了多久？"

"按照地球上古建筑的施工速度——"许冰说，"至少两百年。"

"但冥王不是普通人。"李长生看着那座刻着"冥王殿"的巨碑。碑面上那些万年未灭的灵石光在碑身表面流转，像液态的星星。"他是能在太空中折叠空间的人——能把九块碎片打入九个不同行星的人——能把地球伪装成灵气枯竭的废弃星球骗过诸神联盟的人。这种人建一座城市——可能只需要一个念头。"

龟相的声音在意识中响起，语气是怀念和敬畏的混合:"不是念头。是两年。冥王用了两年时间——从火星地壳深处提炼出建材，用冥刻在每一块石材里刻入符文，用空间折叠把整座城市的基建在同一时间铺设完成。他建这座城市的时候身边只有十二位亲随——十二艘碎星舰的舰长。他们白天建城，晚上在这座穹顶下修炼。两年之后——这座城市建成的第二天——冥王启程回了地球。那次回去之后的事——你应该已经从碎片记忆里看到了。"

诸神联盟围攻。十六位神明。冥王以一人之力杀七伤五，最后将冥王令自己捏碎散入虚空。那座在地球上空燃烧的战场、那份以自身为诱饵的消失战略——起点就在这座城市。他在这里修炼了两年，然后回家赴死。

李长生站在冥王殿的巨碑之下。万年前的那个人作出了他的选择。现在轮到后来人了。

"下去。"他说。第一个迈下了通往宫殿群的长阶。

（第292章完）

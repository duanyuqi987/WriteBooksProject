# 第三百四十三章 共担劫难

战后第十五年。苏晚在蜀山剑阁最深处的契约残篇中查到一个被封印很久的旧卷——上面记载了上古情缘契约的真正代价与最终形态。

代价是：两人中无论谁先死亡，对方都会承受同等程度的生命本源损失。当初第一世苏晚的早夭——在林牧所有灵魂状态中都留下了不可恢复的印记。这也是他每一世初见时的"冷"——不是不暖，是不能太暖。因为灵魂明白温暖最后会变成收割他的代价。

但残篇后半指出：如果两人都能够将修为修至元婴后期以上且主印承担者突破至化神——契约可转为共生模式。共生模式下不再有主副之分，不再有单方代价——在任何一人受伤时，另一个人自然知道、自然感同、自然挺身。但这需要两人在同一世将修为同时提升至化神层次。

苏晚看完后将竹简放回。走到剑阁外寻他。他正在蜀山石阶中段用还旧剑挑落一只从他肩旁擦过的飞蠓。她把契约的终局告诉他——提到"共生模式不需要再分主副"时他眼底亮了一点。不是兴奋——是某种更暗的、很深的东西。

他说："那要两个人都到化神。"

"对。"

"我现在元婴后期——差一线。你元婴后期——也差一线。但问题是契约转换的门槛需要两人'同时'突破——需要同一天在同一地同时渡化神之劫。化神劫是六重天雷，每一道都可能将其中一人劈成重伤。两个人一起渡劫——两个人的天劫会合成一对。难度不是二倍。"

"多少倍？"

"残篇说大概七倍。因为互动叠加。"

苏晚沉默了。然后说："那我们一起准备。不急着渡——先稳。"

"什么时候？"

"再过几年。等我把那套剑法完全稳定下来——你也把本源补到八成。然后找个你我最稳的时机——一起面对。"

林牧把还旧剑插入石阶缝里的泥土。手背上那道旧剑痕在夕阳里变成了银色。他微微点头，说："好。"

# 第698章 境界平等

法典的第三卷——《境界平等卷》——执行难度最大。

因为它触碰到了修仙文明最深层的等级意识。

旧纪元的修士社会中，境界等级几乎是第二张身份证。一个帝级修士走在街上，所有人——包括玄师级、圣者级的修士——都要恭恭敬敬地低着头回避，否则就是对"上位者"的不敬。神级修士更夸张——他们在自己的势力范围内就是活法律。这种等级意识浸透在修仙文明的每一个毛孔里，已经成为了本能。

现在要打破它，谈何容易。

但李长生的态度极其明确：不是"慢慢改"，而是从法典生效之日起就必须做到。

他有自己的理由，而且这个理由说出来的时候，没有修士能反驳。

"境界是什么？"李长生在一次帝国高端议事会上这样开场。在座的都是帝级以上的修士——在旧纪元的标准中，这是一群跺脚就能震动星河的人物。

没有人答话。

"境界是修炼的结果——是时间的累积、机缘的碰撞、天赋的兑现。但它不是衡量一个人价值的标尺。我今天问你们一个问题——如果一个帝级修士从来不帮助任何人，和一个普通凡人一辈子种粮食喂活了上千人，哪一个对社会更有贡献？"

沉默。

"我知道你们心里有答案。但旧纪元的体制不允许你们把正确答案说出来。因为体制会奖励强者——不是因为强者好，只是因为体制是强者写的。"

他站起来，走向窗外。窗外是冥都繁忙的广场——各个境界、各个种族、各个文明的公民来来往往，没有谁对谁卑躬屈膝，也没有谁趾高气昂。这就是他想要的帝国——一个境界不会成为鄙视链的帝国。

"境界平等，不是让你们装模作样地对低阶修士说'你好'，"李长生转回来，"是让你在内心真正认同——那个在田里弯腰种地的人，他的价值不比你低。"

实施层面有几个极其具体的举措。

一，帝国官方文件废除"境界称谓"。旧纪元中，低阶修士必须对高阶修士使用"阁下""上仙""仙尊"等敬称——这些敬称不是礼貌用语，是等级身份证。一个圣者级修士对帝级修士说话时必须用敬语，否则就是不敬。新纪元全盘废除了这套敬称制度——不是禁止使用敬语本身（尊敬可以自愿表达），而是废除强迫性的敬语要求。帝国公务系统里，所有人互相以姓名相称——管你是帝级元帅还是二品文书，叫你名字就行。废掉一切等级称谓的后缀。"大人""上仙""仙尊"从公务文件中彻底消失。法典院的第一个内部改革就是把自己从"法典院上仙会"改名为"法典院"——砍掉了"上仙会"三个字。令蕊亲笔把老招牌取下来时，白馆的灵气灯把她的脸照得一半亮一半暗。她对着旧招牌看了很久，然后把它轻轻放在旁边的地面上——没摔，没砸。不是因为不恨等级制，是因为这个招牌虽然是错的，但它是许冰的老同事们在旧纪元错误制度下仍然坚持为法律奋斗的历史物证。历史不能砸——只能轻轻地取下来，放在该放的地方。

二，公务员体系不看境界。帝国中枢所有的公务员入职门槛里，修炼境界不是必选项——甚至不是参考项。应聘者可以是神级修士，也可以是四品灵根甚至无灵根的凡人——只要通过岗位能力测试，一样录取、一样升迁、一样发工资。岗位能力测试考察的是专业技能——写得了公文、做得了预算、规划得了工程、监管得了灵脉——不是考察你能不能一招灭一个星系。帝国中枢需要的是公务员的管理能力，不是将军的战斗力。两者从来不该混淆。

帝国中枢组建后的第一年，法典院招收了七名无灵根的普通人为法律书记员。他们的工作是整理和索引帝国法律档案——不需要灵气，需要细心和逻辑。这七个人中有一个叫"方晓兰"的姑娘——方正的侄孙女。她没有灵根。但她在入职测试中的逻辑推理部分考了满分。方正知道后只评论了一句："咱老方家，有没有灵根都一样能看文件。"

三，公共福利分配不按境界。灵气配额、修炼资源、医疗补助等等一切公共服务——在基本保障层面上完全按人头，不按境界。修士如果需要额外的高浓度灵气配额，必须向法典院递交需求申请，注明用途（如：突破境界准备期、伤员调养期），经过审核后才能获得额外配额——而且配额有期限，过期自动收回，续期需重新申请。这项制度的核心精神是：灵气是公共资源，在你手里的每一分超出均值的配额，都必须有一个可被公开审核的理由。

这些措施推行下去之后，帝国发生了三件令人印象极深的事。

第一件——一批老派的高阶修士放弃了帝国官方的所有优待和头衔，自愿以普通公民身份重新融入社会。带头的是一个叫"崔玉"的老太太——旧纪元帝国最早的禁卫军修士之一，修为帝级巅峰，曾经在帝国统一战争中一个人守住了三个星门的要塞。她在《境界平等卷》生效当天，收拾了自己在帝国中枢的所有办公用品——主要是一把剑和几件换洗衣物——然后搬到了冥都边缘的一个普通居民区，住进了一套跟普通人完全一样的住房。她不再使用"帝级元帅"的称谓，在居民登记表上填了"崔玉，帝国公民"。有人问她为什么，她说："当了一辈子'上仙'，想试试当普通人。"后来她在居民区开了一间小型的修士体能训练馆，收费标准是帝国最低工资的一半——只够维持房租和两顿饭。来训练的人有修士也有普通人——她给普通人设计了一套不需要灵根的体能训练方案，靠纯身体力学原理实现。

第二件——七个帝级修士联名向法典院请愿，要求撤销帝国给他们配置的专属灵气补贴额度。他们声称"我们不需要比任何低阶修士更多的灵气配额。帝国的灵气应该优先分配给教育和医疗。"这封请愿书是手写的——七个签名没有任何花式，就规规矩矩的名字。法典院批准了请愿，同时把这封请愿书裱进了白馆的案例墙——作为"主动降格"的先例。

第三件，也是影响最深远的一件——低阶修士和普通人中忽然涌现出大量发明创造、文学艺术作品、地方治理创新。新纪元第七年，帝国专利局统计数据显示，来自普通人（包括低阶修士）的发明专利申请数量比旧纪元同期增长了约四百七十倍。其中有一项发明特别让李长生留意：一个没有灵根的普通人机械师，在完全不懂灵气理论的情况下，用纯机械和电磁学原理造出了一台"灵气场检测仪"——不需要灵根就能检测周围的灵气分布。这台仪器后来被帝国环境管理局批量采购，用于公共灵脉监测。发明者被问及设计灵感时说了一句平淡无奇的话："我就想——如果灵气真的到处都有，那它一定可以被非修仙的人也探测到。那它一定存在某种可以被我们测量的物理效应。"

原来以前不是他们没有才华。只是没有被当回事。旧纪元的高阶修士们看低阶修士和普通人时，总认为"他们不行"——然后把这种偏见当成事实，用制度把它固化下来。到头来，"不行"不是普通人的本质——是制度对他们的窒息造成的后果。

当一个社会的底线是任何人的声音都可以被听到时，那些曾被淹没了无数代的声音会争先恐后地浮上来。其密度和深度，远超任何等级制所能想象。

（第698章完）

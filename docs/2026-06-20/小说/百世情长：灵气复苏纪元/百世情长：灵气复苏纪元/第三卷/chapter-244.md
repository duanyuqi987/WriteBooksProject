# 第244章 灵魂交融的开始

第八世苏晚和修为在达到合道巅峰之后，面临了一道前所未有的瓶颈：飞升的真仙门槛。凡间修士要飞升必须先通过"真仙试炼"——这是一道上界对下界修士设定的最终考核。白谪在第六世时已告知他们苏晚需要历"十世圆满"方能获得飞升资格——现在第八世已近尾声，距离十世只剩下最后两世。"真仙试炼"并不单纯是战力测试——它还包括一个核心条件：两个需要同步飞升的灵魂必须完成"灵魂交融"。灵魂交融不是简单的两人同在一起——是需要将两人的元婴、剑道、灵力、仙元和魂印全部融合为"双心一体"的状态。当两个灵魂完成"双心一体"后——他们各自的灵力会自然协调成一个共振频率，使得"真仙试炼"在开启时不会因为魂频偏差的抵触而被上界自动拒绝。灵魂交融的最低标准是两人的修为必须同为合道巅峰——并且两人之间必须存在足够久的情感契约支撑。

第八世在瑶台做的那次"合道期双修士灵能互补"就是灵魂交融的初期实验——那次成功表明两人在灵力层面已经具备同步基础。但灵魂交融的全过程共分三层：灵力交融（必须在战斗中通过"共唤剑灵"来触发）、魂源交融以及最终的情感与契约共融合一。每完成一层——林牧和苏晚的灵魂感应就会进一步加强——彻底形成仙界认证的"双核金印"——这是通过真仙试炼的必要条件之一。

第一层——灵力交融——在第八世末尾完成。苏晚和林牧在昆仑山外的一场实战对练中同时凝聚出各自的本命剑灵——她的金火剑灵和他窄身剑的仙元剑灵——两柄剑灵在空中碰撞时不是互相攻击——而是自动缠绕——然后两柄灵剑在两人中间形成了一个合体剑灵形态。合体剑灵的形态是一柄前所未见的"双刃金火窄身真剑"——它的剑身一面全金一面暗光——双锋兼备——每一次剑击同时带两股不同的杀伤力。这柄合体灵剑的出现标志着两人灵力交融的正式达标。——白谪在灵界感知到其能量后下界过来确认一次，并在总纲上在第八世的记录上打了一个勾:"灵力交融——完成。"

第二层魂源交融则需要两人在最危险的灵魂离体状态下（例如濒死体验或极致的灵异深渊探险）一同面临灵魂撕裂然后互相修补。第八世结束时尚未触发——但苏晚在临终时对林牧说了一句话:"下一世——我们把剩下的两层一起做完。"

第九世的她投入到更深更决绝的冲刺模式。转世间隔为零——她在第八世结束的同年便投胎于昆仑穆氏附属城中的一个小修炼家族——在十四岁那年在祖屋的茶院中见到了林牧——他们在重逢后不到三个时辰就确认了前世记忆的全部完整——然后以最快速度开始修炼——并在二十五岁集结出第二层魂源交融的条件：在一次联手解决昆仑旧封印事故时两人同时被旧封印中残存的极古仙力卷入灵异深渊——魂源被扯离身体，两人在深渊中以纯粹的灵魂状态漂浮——在彼此的金火和仙元构成的微光漩涡中互相缠绕并修补对方被乱流扯伤的魂缘——整个过程持续了据后来白谪的记录约三个时辰——然后两人魂源重新飞回肉身——在合体状态中醒来——身上各自带着对方金火透入的印记。白谪确认第二层完成之后，距离最终飞升就只剩最后一层——情感与契约共融合一。但白谪同时警告：第三层是最危险的——因为在共融合的过程中所有的防御都会完全卸下——任何一方的内心如果还存在对对方的"怀疑"或"恐惧"——交融可能会失败并导致不可逆的魂伤。

然后苏晚在第九世剩余的一年中跟林牧进行了长达数月的"契约理顺"过程——把每一世曾经有过的对抗、矛盾、误解和不甘都一一摊开讨论。她说:"第一世你瞒我说天劫没问题——结果你那道天劫差点劈死我——我替你不满。"他说:"那你刺我的那十二剑还不算——第四世你说追了五十里路想问我一句话，结果你上来先一剑——你欠我解释。" 苏晚笑了:"我解释——我那时候被你搞得很没面子——只好用剑切好路径来撑场——其实是把你刺不到我心里——但是你每次不躲，我怕了——我每一次近距离看到你的眼睛，就会发现自己是这世上最大的傻瓜——把你误会成敌人整整四十章，还要你每次在战场上把我弹过去。"

这些平时从未说出口的小小怨气和小小遗憾在摊开之后，契约的稳定度反而增强了。每一道旧伤疤在彼此坦诚中变成新印。

第九世结尾——他们在昆仑瑶台上面对面坐好——剑放在两人之间——两人的手同时握住双剑的剑身——把自己的金火和仙元最后一次注入——然后白谪现身作为见证——两人完成了灵魂交融的第三层前奏——情感契融合暂时没有触发——因为两人同时说了一句话:要做最终的交融必须在下一世——最后一段轮回——"十世圆满"当日的飞升处直接在真仙试炼中一并完成。

白谪记录：第九世契约交融预备完成——十世将与真仙试炼同步启动——候选资格最终确认——等待下界日期——林牧和苏晚。

第九世在她和林牧相拥的目光中挥手暂别——她没有闭上眼——她看着他说:"最后一世——我很快回来。"

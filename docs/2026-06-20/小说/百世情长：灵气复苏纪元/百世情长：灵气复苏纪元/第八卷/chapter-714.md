# 第七百一十四章 他是她的力量

三个月后，威胁变成了实际行动。不是在战场上——是在制度上。

一批自称"古修遗脉"的修士在九州边陲的一座古城中起事。他们宣布"拒绝承认修人共治会的合法性"——理由是在共治会中凡人和魔修共同拥有的票数已超过了传统正修。这群人中有三个元婴级老修士——都是千年前灵气复苏前就已隐居的古老世家。他们的力量不算是巨大的，但其中一位擅长阵法——他在那座古城外布下了一道极其复杂的反灵网干扰阵，让古城方圆几百里内的灵网信号完全断绝。

叶小雨发现信号中断后立刻启动了两扇门链路——通过上界中转站把中断信息同时传递给了苏晚和上界的林牧。苏晚在地面组织应对，她没有调集任何宗门兵力。她的应对方式是：先派石头带着一锅粥去古城门口——不是劝降，是送饭。

石头在古城门口被阵法挡在外面。他把粥放在门前一百步的石台上——"粥在这里。没有下毒。没有附任何灵术。就是粥。"说完他退后。他没有多等，直接回了太湖。傍晚——苏晚收到了从古城内部传来的一道传讯。发讯人不是起事者——是一个被裹挟入城的年轻散修。他说他喝了放在石台上的那锅粥之后哭了——"因为我从小到大没有人给我做过免费的粥。"

苏晚对石头说了一句让他一直没有忘记的话："对方能哭——说明他的良心还在。我们在战场上唯一的优势不是力量，是让他先发现自己的良心。"

三天后那个年轻散修带着古城的大半散修退出战场——零伤亡。不是因为被说服——是因为那锅粥唤醒了他们一种早已被恐惧压下去的认知：他们对抗的不是"邪恶修士"，而是一个给别人煮粥的人。这位煮粥的人不要求你放弃立场——她只要求你在决定前先喝碗热的。

林牧在上界收到战报时正在折叠空间画新的路径图。他看完战报后在上界灯火塔下停顿了大概十息，然后对秦无夜说："她打赢了一场我没上场的仗。不是靠力量——靠灶台。她是我见过的最强的战术家。"

秦无夜补充了一句让她自己都笑出来的话："这么多年，我第一次觉得'粥'这个词其实是战术术语。"

（第七百一十四章 完）

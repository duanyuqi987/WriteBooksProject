# 第六百三十八章 创办修仙学院

秋分过后，林牧画完了飞升之门理论框架的初稿。图纸铺开有半张桌子大——密密麻麻的符文集和灵气流向线把一个复杂的多向通道完整地呈现了出来。理论上它可以让所有金丹以上修为的修士在一个稳定的通道里度过飞升的过程——将天劫的破坏力降低到原来的三成，同时打开上界的入口。但这个工程至少需要联合所有宗门才能完成——单靠林牧和苏晚两人的力量无法实现。

苏晚看完图纸后沉默了一刻钟。然后她提出了一个想法——创办修仙学院。不是传统意义上的那种"大修士收徒"的模式。而是以"平等知识传播"为宗旨的开放式教育学院。学院里不设"长老"和"弟子"的等级关系——只设"课程提供者"和"学习者"。任何修士，不管来自哪个宗门、修什么功法、灵根好坏——都可以报名学习或提供课程。学院的三大支柱课程——第一是技术修炼，分功法、炼丹、阵法、剑术；第二是心性培养，教的是"如何管理缺陷、如何和差异共存"——这门课的核心教材就是苏晚写的《没有人是完美的》；第三是跨域合作——包括正魔共存技术、灵脉共享机制和飞升之门贡献计划。

林牧听了她的这个想法后，站起来在屋里走了三圈。他走的每一步都很慢——不是在犹豫，是在消化。然后他说了一句苏晚没想到的话：

"在我们院子里办。后院有六间空屋子。前院可以做宣讲。桂树下面可以上户外课。灶台——继续煮粥。"

苏晚被他的爽快吓了一跳。她以为他会说"需要考虑组织架构、管理团队和资源调配"——以往他说这种话时是她觉得最"林牧"的时候。但这次不一样。这次他说的是："在后院办。"

一个月后，"桂花园修仙学院"在院子里正式成立。首批学员只有二十一个人——石头七岁半，是最小的一个；最大的一个是太湖来的一个六十七岁筑基散修，一辈子没有跨进过任何宗门的门槛。张道玄主动申请当客座讲师，主讲"稳——不是压制，是容纳"。蜀山剑堂堂主讲"恐惧与剑速的关系"。华山大师兄讲"如何把你的强迫症变成检查法宝"——这门课在报名表上被意外划掉了两个错别字（他用铅笔重新写了两遍），反而被学生们当成他的个人特色保留了下来。

秦无夜讲"魔气使用者的自我认同"——这是她第一次以"讲师"身份而不是"魔修代表"身份在公开场合发言。她站在桂花树下，说了一句后来被学生抄在便签纸上四处张贴的话："我的魔气不是我的污点。它是我的另一种颜色的灵气。"话很短，但那些听她讲课的正修年轻学生们在课后自发站起来向她鞠了一躬。

学院没有招生简章，没有学费，没有任何承诺。唯一的要求是每个人在学期结束时需要为公共区域做一件实事——给灶台上的锅刷干净、在院门口补一下裂了的台阶、给某一棵植物修剪旧枝。有人问苏晚为什么要求这么小。苏晚说："因为宏大的承诺容易作假——日常的小事不会。你愿不愿意在路边修一个台阶——那个决定决定了你是一个什么样的人。"

第二年春天，学院的第一批"非正式毕业生"中已有十几人在各自宗门做出了实际贡献——包括改进了一项低阶丹药的配方、改写了三篇过时的剑法教材、以及修复了一条废弃多年的散修聚集点灵脉。他们没有统一学分证书——但他们都在离开时拍了同一个人——石头——的小脑袋。然后带着院子里煮的热粥温度，去煮别人需要的粥。

（第六百三十八章 完）

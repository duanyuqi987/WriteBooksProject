# 科学概念与硬伤检查

| 概念 | 写作警戒 |
| --- | --- |
| 量子纠缠 | 不能按现实科学直接写成可控超光速通信；第一卷人类必须承认此限制，第二卷若突破需明确为智能体改写物理后的叙事现象。 |
| 黑洞热力学 | 黑洞记忆库必须承认温度、熵和辐射概念；第五卷可写熵枢调控，但要写成局部/更高规则改写。 |
| 哥德尔不完备 | 不能写AI简单超越定理；更合适写法是它接纳不可证明性，并把不可判定命题当成新优化材料。 |
| 热力学第二定律 | 第五卷前不能随便违反；第五卷后必须说明这是熵枢本体置换后的规则改写，不是普通科技突破。 |
| 因果律 | 第三卷允许局部扭转，但每次扭转必须产生代价、裂隙或新熵增，避免万能时间倒流。 |

## 写作原则

- 前三卷尽量承认现实科学边界，越界时必须让越界成为剧情事件，而非作者随口设定。
- 第五卷以后可以改写规则，但必须写出“为什么旧规则已被本体置换”的叙事依据。
- 抽象概念必须配一个可感意象，避免读者只看到术语。

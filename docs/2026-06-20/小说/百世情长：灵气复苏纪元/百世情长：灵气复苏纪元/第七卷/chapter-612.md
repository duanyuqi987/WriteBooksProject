# 第六百一十二章 我不改，但我会告诉你

修仙界流传"公开缺陷书"之后不到十天，各地宗门开始出现了模仿。

华山派的大师兄公开了自己的问题——"每次打坐前都要反复确认蒲团的位置正不正，不正就坐不下去，已经被师弟们嘲笑了十几年。"龙虎山的炼丹堂堂主公开的是——"我怕失败怕到每次开炉之前都要偷偷拜灶神，虽然修仙界不信灶神。"最让苏晚心动的是一封从太湖水底修真世家寄来的信——写信的是一个五十多岁突破筑基失败的散修，他说他看完了林牧的公开缺陷书，在静室里坐了三夜。然后决定继续修炼。"不是因为我突然变强了。是因为我发现——原来那个被称为'仙人'的人也会有恐惧。那我也可以。"

苏晚在早饭桌上把这些"回信"读给林牧听。

读到太湖散修的那一封时，林牧停下了筷子。

"把他名字告诉我。我去看他。"

"你又不认识——"

"他需要被人看到。"林牧说。"他突破筑基失败的时候没有人看到。他决定重新修炼的时候也没有人看到。他的改变需要一双眼睛确认。"

苏晚放下信纸，看着林牧。她忽然发现了一件事——林牧在改变。不是那种"突然变成了另一个人"的改变。是更深层的——他把对自己的包容，变成了对陌生人的包容。他不再只关注她了。他的那颗封闭了上万年的心，正在慢慢打开一个窗口，让别人的故事也能照进去。

"你跟我刚认识你的时候不一样了。"苏晚说。

"哪不一样？"

"以前你只在乎三件事：修炼、保护我、喝茶。"

"现在呢？"

"现在你会在乎一个筑基失败的男人有没有人看到他站起来。"苏晚把信纸叠好放回信封里。"这种改变——"

"是你教我的。"林牧接过话头。"包容不是只存在于两个人之间。它是会传染的。你包容了我的沉默，我就学会了包容别人的弱点。"

吃过早饭，两人御剑去了太湖。

太湖的水面上还在下雨——江南秋雨的那种绵密无声的、可以把所有轮廓都温柔化了的细雨。那个散修的家在湖心岛上一间茅草屋里，门口晒着几排鱼干，咸味和雨水的味道混在一起，飘在空气里。

散修姓杜，五十多岁，胡子拉碴，穿一件洗得发白的灰布短衫。他打开门的时候，看到门外站着的人，手里的茶壶差点掉在地上。

"林——林先生？！苏晚前辈？！"

"我们看了你的信。"苏晚说。这是我能找到的最简单、最直接的开场白。

杜散修把他们让进屋里。屋里的陈设极其简单——一张矮桌，两个草蒲团，墙角堆着几本旧功法和一口缺了边的丹炉。丹炉底部积着厚厚的灰——很久没开过火了。

"我突破筑基失败了三次。"杜散修给他们倒了两杯热水——没有茶叶。他用的是搪瓷杯，杯沿有点磕掉了漆。"第三次失败以后我把丹炉封了。封了五年。你们的公开书传到太湖水下那天，我的女儿——她才练气三层——跑过来跟我说：'爹，你看，仙人也会有缺陷。你不敢开丹炉不是因为丹炉坏了，是你怕第四次也失败。但仙人不怕第四次失败，他们只怕不敢面对。'"

林牧端起搪瓷杯喝了一口热水。"她说得对。"

"是啊——所以我当天晚上就把炉灰扫了。"杜散修指了指墙角的丹炉。"然后给你们写了那封信。不是为了让你们来——是写给自己的。把它写出来，好像那些年压在心上的东西就轻了一截。"

林牧站起来，走到墙角。他蹲下去看那口丹炉——炉壁上有一道裂缝，从炉口一直延伸到炉腰。裂缝用铁箍补过，补得不好，铁箍和炉壁之间有一条缝。

"你的丹炉漏火。"林牧站起来。"筑基丹需要在稳定的火候下烧四十九天。你的炉壁漏火，所以温度波动超过了允许范围。不是你的炼丹手法的错。"

杜散修张大了嘴——五十多岁的男人像小孩子一样愣在那里。

"我——我以为是我不够专注——"

"你专注了三次。三次失败都是因为设备，不是因为你。"

杜散修的嘴唇在抖。不是因为激动——是因为他心疼自己。心疼自己恨了五年"不够专注"的自己。

苏晚从储物袋里拿出一口新丹炉——青铜材质，炉壁厚实，是林牧去年亲手炼制的多余品。"你拿着。不是施舍。是投资。筑基丹炼成之后，第一炉送去太湖外城的散修联盟。很多散修比你更需要。"

"那这口旧的呢？"杜散修看着那口旧的。

"留着。"林牧说。"每次自我怀疑的时候看一眼——'我不是不够好。是设备坏了。'"

从太湖水底出来，雨已经停了。太湖的水面上铺了一层薄薄的晚霞，把整个湖水染成了浅橙红色。

"你怎么知道他的丹炉有问题？"苏晚问。

"我前世在青云宗烧了四千年的丹。看一眼炉壁就能判断。——但我没说的是，他第一次失败那年，丹炉还是好的。第二次失败那年炉壁才开始出现裂纹。他怕失败这件事，本身没有错。是运气不好。把怕失败说成缺点——对很多人来说是冤枉。恐惧是正常的。不正常的是因为恐惧而停下。"

苏晚踩在飞剑上，风把她的白发吹起来。夕阳把她的侧脸照亮——那个侧脸还是干净明亮的。

"所以你现在的结论是：缺点不一定是缺点——有时候是运气不好，有时候是设备坏了，有时候只是恐惧。而恐惧是正常的。"

"对。"林牧说。"所以我不会再要求任何人——包括我自己——去当完美的人。我能做到的是：当我发现自己有缺点的时候，我告诉你。你可以选择接受或不接受。无论你怎么选——我还在这里。"

夕阳沉入太湖水面以下，水天相接的地方只剩一道金色的细线。

（第六百一十二章 完）

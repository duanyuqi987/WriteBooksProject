# 第五百六十六章 银杏区三号院

太虚学院的道侣宿舍区叫做"银杏区"——整个区建在一整片巨型银杏古树林中。每对新婚/新晋级的道侣分配一栋极小的独立院落。三号院门口有棵年龄可以往上追溯到极古老年代的巨大银杏树。院里的屋舍不大——正房一间，书房一间，琴室一间，阳台一个，小厨房一个，外加后院有一个极小的劈柴工作台。工作台旁立着太虚木工房送来的一块原木料。料上贴了张纸条:"新柴。先劈着。不够往木工房去拿。——学院后勤部敬贺。"林牧弯了一下嘴角。

主卧里有两张极简的松木床，中间摆着一盏共用的灵能灯。桌上有两本装在书架上的虚规手册。册封面上一样别有那把——以后和等我——的立体雕刻纹。太虚学院似乎对道侣心理琢磨得极透彻。苏晚把琴在琴室里安置好，琴首朝向窗外的银杏树枝。她把功德绳在琴架上绕了一圈试试共振——微弱的金色光沿着弦缓缓流过。琴架上的木头原是同心树的旧枝干——也是能共振的特质材料。此刻她的古琴连上太虚建校以来所有道侣留下的弦振记忆。突然无风自鸣了极短的一声低音——像对她说"来了。"

傍晚时两人在银杏林间散步，发现这片银杏林正是太虚的古银杏生态区的一部分——每棵树的树龄都极大。但有些树身上的木牌很少——只有极稀落几对。说明在极漫长的太虚历史中能够以道侣身份飞升上来的人本来就不多。其中一棵极细极瘦的银杏树枝上挂着一对极旧极旧的红绳——绳头还剩两色几乎完全风化成灰的小小木片。苏晚走近看，极努力辨认后发现两块木片上只各刻了一个字——"等"和"来。"她看完后静静地对着那对快要风化的木片说:"我们来了。你们等过——我们替你们继续走。"她以功德绳在木片下方的树皮上轻轻绕了一小圈，把金线的余温留了一息。

晚间时两人回到院里。苏晚第一次用太虚学院配发的太虚锅煮面。火候控制得比在迎仙台时熟练了极多——面条粗细已相当均匀。煮了不过一阵子，林牧在后院劈柴——第一斧劈的是太虚木，那木板上的木纹圈数居然可以追一层一层数回去大概数到几百圈。这一劈在他心里产生了极短暂的悸动——这棵木头生长时，他还在某个轮回中。那时他还不认识这一世的手劲。但拿在手里的这把斧子的木柄，是他自己劈了那么些年柴自己磨出来的——还是这同一个手掌。他把斧子收好，洗了手回厨房拿碗盛面。

（第五百六十六章 完）

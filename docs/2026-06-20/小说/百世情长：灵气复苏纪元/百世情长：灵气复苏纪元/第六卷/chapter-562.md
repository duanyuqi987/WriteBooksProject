# 第五百六十二章 飞升试炼前的最后准备

太虚仙域预录学院的正式入学通知在不久后送达。通知书上写明了入学时间：太虚学院新学季在数月后开始。届时所有通过太虚试炼的晋级道侣将进入学院进行为期一段时间的预备修行，毕业后正式飞升太虚仙域。"飞升"这个字再次出现在苏晚眼前。从下界飞升上界，又要从上界飞升更上的太虚仙域。这次和之前不需要再经历那重六重天幕和心魔台阶——太虚仙域的飞升是进修性质的，更像是"考上了研究生"，准备搬进新宿舍。通知书附了一张宿舍申请表——宿舍类型选择可选单人间或道侣双人间。苏晚在道侣双人间的勾选框前面画了一个勾。然后她在备注栏填了一行字:"需要向阳窗台（放冰晶草）。还需要厨房里有四灶以上。要有劈柴间。（寻晚真仙备注）"林牧在旁边看了一眼她填备注——没有纠正她，只是在"劈柴间"三字后面悄悄加了括号:"（或改装后适应劈柴的阳台亦可）。"

通知书中还指出入学前需要完成一系列前置手续——包括灵核复检、太虚铭牌激活、以及一轮泰和预备役的心境最后打磨。心境打磨的地点是她极熟悉的地方——南离城同心树下。通知中说:参加心境打磨的道侣需要在同心树下各独自静坐一整夜，在此期间不能与彼此有任何形式的有意识沟通，只能各自面对自己的内心。这就是"最后的心境确认"——在飞升前确认你对这个人的选择是自由的，不是惯性不是习惯，是在完全独立思考后自己再一次主动选择的。

苏晚看了这要求后和旁边的林牧交换了一个眼神。他说:"一整夜——能不说话。但我会在树上挂一根备用红绳在你看得见的位置。那不是沟通——那是——"他在措辞方面犹豫了片刻。她用通灵帮他把后半句接住了:"那是'我知道你还在那里'。不违规。不是沟通是树上的红绳自己晃了一下。这不怪我们。"

去南离城的前一晚，她把琴弦全部重新拧紧。把冰晶草第九片叶子用水擦了。然后她把那两封信从黑木盒中取出来重读一遍——白衣女子的旧信和他的新信。她读完后把信折好放回盒中。盒盖关好。前往太虚前她会把盒子寄放在仙居书架上——不带去。因为该记住的都已经全在她灵魂封印解除后完整地存进她灵核的"永久收藏区"里了。永远不怕丢。

（第五百六十二章 完）

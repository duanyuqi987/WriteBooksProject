# 第470章 李长生的抉择

诸天号从光柱底层起航，沿着来时的路线穿过元初之海，向着九号宇宙返航。

回去的路上，全舰人员都沉默了很多。不是因为沮丧——是因为在这一趟跨越宇宙的旅途中，他们看到了一个全新的世界，看到了自己宇宙的文明和别人相比的差距，也看到了差距并非不可追赶。

小王在舱室中对着灵符引擎的代码苦思冥想。他在光柱军事大陆上看到了一份公开的灵符引擎优化方案——那是这个宇宙在上万个纪元前开发的第二代灵符系统算法。它的思维方式完全碾压小王目前写的算法——但在原理上，它们是一脉相承的。小王在那个算法中看到了一条路。一条将他自学出来的东西升级到下一个代际的路。

"给我几年时间。"小王自言自语，"我就能把这套算法适配成适合我们宇宙版本的系统。"

老马在整理自己在工程大陆获取的地质改良方案。这个宇宙的地质工程中运用了一种叫做"灵脉主动诱导"的技术——它可以通过人工方式将微弱的灵脉活性激活成主灵脉。老马想到地球上的太行山——那座山底下压着一条无人认领的灵脉，如果这项技术能移植过来，太行山的灵脉可以在十年内被激活成相当于三个昆仑主脉强度的超级灵脉。他需要在回去之后做实验。但在此之前，他需要重新理解这项技术——因为老外的东西和本土的地质不一定吻合。

小胖的道别方式最朴实。他从灵植大陆带回来的种子里有一种叫做"灵元麻"的植物——它长得像芝麻，但每一粒籽蕴含的灵气相当于一颗中品灵丹。而且它不挑土壤——哪怕是荒地、盐碱地、煤矿塌陷区都能长得不错。小胖兴奋地说回去要在李家庄试种——当年李长生是农民出身，现在小胖想用农民的方法解决炼丹药材短缺的问题。"不是所有炼丹都得靠仙山取材。种菜能养人，种灵药也能养修士。"

许冰的法典上多了三页新内容。是至尊议会法则编纂中心帮她压缩后的一套"种子法则"。这些法则太原始——在第一代修仙文明之前它们就已被发现，是所有法则治理体系的地基。它们不依赖高密度法则环境，可以用最基础的规则力直接运作。如果能在九号宇宙中成功架设这套种子法则，宇宙的秩序就不再依赖于某个强者的承诺，而是建立在制度性的法则保障之上。

"回去之后我打算先在银河系测试。"许冰说，"如果测试成功，再逐步推广到更大的星域。"

"你需要帮助。"刀疤说，"法则治理需要执法机构——你光有规则没有执法力量，等于一纸空文。"

"我知道。所以我打算回地球找龙组合作。"许冰说。

刀疤在军事大陆学到的冲击也不小。他看到了一支完全以法则为作战核心的宇宙联合作战力量——这支部队中没有单打独斗的英雄，每一个士兵的战斗力都和法则基础设施深度捆绑。单独拎出来一兵一卒不比地球修士强多少，但组合在一起后，加上法则协同支持，战力能指数级增长。

"回去之后我打算重组地球舰队。"刀疤说，"以许冰的种子法则为骨架，以老马的灵脉激活为后盾，以小王的灵符系统为神经、老马的地质防线为护盾、小胖的丹药为补给——我们的舰队不再是散兵游勇，而是一支完整的、正规的、有法则根基的现代化仙侠军队。"

陈霜没有说话。她只是静静地磨着剑。在这个宇宙的这几天里，她看到了太多在她原宇宙中属于"绝世剑谱"的武学沦为初级教材。但她一点也不气馁。她不气馁是因为她终于摸到了剑道的真正目标——不是比别人强，而是超越自己昨天的极限。如果在初级教材的基础上一剑一剑累加起来，总有一天也能达到至尊议会那个演武场上最顶级剑修的水平。

"回去之后我打算重新编陈家剑法。"她说，"从第一式重新推演——不是祖传的十八式，而是完全重写的、能够一代代往上迭代的新剑道。"

龟相全程没有说话。老龟只是安静地趴在舰桥上，龟壳上的七十二重大阵阵图明暗起伏。它在回忆一万两千年前冥王带它第一次踏入这片元初之海的情景。那时候元初之海还没被至尊议会设置观测站，周围的宇宙泡沫还都是野蛮生长的、未被人为优化过的原始状态。那时候冥王在这里站了很久，最后说了一句话："老龟，你看这些泡沫——每个泡沫里都有无数的人在挣扎求索。他们不需要被一个仙王兼并进自己的宇宙。只需要偶尔有人站在旁边观测，在关键时刻给点提示。"

龟相那时候不懂。现在懂了。

诸天号穿过维度壁垒回到了九号宇宙。熟悉的五行阴阳法则重新包裹了每一个人。

李长生站在舰首，看着窗外阔别数日的星河。八位帝者已死，三位帝者被废去帝力遣返为凡人。这场为期三个月的宇宙战争，结束了。

但李长生心里清楚，新的挑战已经开始。三十个标准周期后，膨胀宇宙的震荡波将抵达九号宇宙边界。他在那之前需要把地球舰队升级为一支有法则根基的正规部队，把灵气恢复中的宇宙版图稳固下来，把那些在帝者崩殂后陷入权力真空的星域纳入秩序系统。

还要去赴仙王老人的茶会。不是去接受邀请，而是去探讨——多元宇宙的未来应怎样共同维系。

"长生。"陈霜的声音从身后传来，"回地球吗？"

"回。"李长生顿了顿，"先回李家庄。看看那五亩地怎么样了。"

身后的小胖默默地嘀咕了一句："那茶味道我也好久没喝了。"

诸天号向着银河的方向加速。

前方是无尽的星河。星河尽头是那颗渺小而美丽的蓝色行星。一万两千年前，冥王在那颗行星的土地上亲手种下第一株茶树。一万两千年后，一个农民从那片土地里挖出了他的碎片。

一万两千年，种下和挖出之间，流过了一条河。

河叫黄泉。

河叫人间。

河叫传承。

（第470章 / 第四卷终）

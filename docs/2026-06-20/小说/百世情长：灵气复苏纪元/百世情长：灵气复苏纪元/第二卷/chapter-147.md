# 第147章 君子之交

老张的棋艺三十年来没长进过。

他自己也知道。但他不在乎——因为全镇只有林牧愿意陪他下。别的老人都嫌他太慢，一步棋要想一盏茶的工夫，一局棋能下掉半个下午。但林牧从来不催。他说下棋不为胜负，为这个下午的茶。

老张的习惯是前半局猛打猛冲，后半局手忙脚乱。林牧会故意在某个地方卖个破绽，让他翻盘一两局，翻完了老张那一整个下午的脸都是亮的。回家后跟林秀芝吹牛，说自己今天赢了林先生两局，"他那招飞相我以为是他新研究出来的杀招——其实有破绽的，我不小心发现了——嘿嘿。"

林秀芝听着他说，笑着应一句"那你很厉害啊"。她知道那是林牧故意让的。她不说破——就像林牧不说破老张的棋艺三十年没长进一样。

两个人都在保护同一个东西：这个朴实男人的小小快乐。

林牧有时候会在心里把老张和前世的自己做对比。前世他是青云宗第一天才，修行者俯瞰众生；前世他是上界仙人，寿元万年。但前世他从来没有像老张一样给过苏晚一个安稳的家、一个不需要担心天敌的普通日子。

他没有嫉妒。不是没有嫉妒——是不能嫉妒。因为他没有资格。第一世是她选择了来青云宗，他却没有护住她；第二世他从一开始就什么都没有——不是她的什么人，甚至连怎么才能给这份感情做定义都不会。

而老张只是一个普通的、不会修仙、没有修为、身体偏胖、做菜有点咸、下棋很慢、但天黑了会去接妻子且天没亮就为儿子烧水煮蛋的男人。他给苏晚（她这一世）的所有东西——柴米油盐酱醋茶、容她喜怒哀乐的家庭、儿子长大的痕迹——林牧给不了。

所以他没有嫉妒老张。他只是每天下午在老张下棋下输了唉声叹气的时候给他续一杯好茶，然后说"这局你的炮早架在河沿就赢了——就差一步"。

老张最相信的人就是林牧——因为他不骗他。是真的不骗他。

七月的一天，老张在后山摔了一跤。腿骨骨裂。不算重，但需要卧床休养一段时间。镇上的茶馆要正常运转——他没法去采新茶，没法修屋顶上漏水的那片瓦片。

林牧第二天就出现了。他说"最近我也没啥事，带个年轻人帮帮忙"。他带了个"年轻人"——其实是蜀山外门弟子，被他从千里之外召来，换了便装，假装茶馆帮工。那帮工在法力和本职上算筑基初期——修屋顶那是闭着眼都能做的事 。他帮张家修了三天瓦片，期间顺便用灵力把张记茶庄的木结构全部加固了一下。

老张躺在床上，腿吊着，每天看他从窗口看见林牧在屋顶上指挥那个"年轻人"，心里热乎乎的。他对坐在床边的妻子说："林先生这个人啊——你别看他嘴不太甜。他做的事都是熨帖的、周全的。我们家屋顶漏水多少年了，他比我自己都上心。"

林秀芝没有跟着丈夫的语调接话。她低头在床畔把苹果削好。苹果被削得很慢——慢到老张说了句"你削的苹果怎么这么厚皮"。她没答。她只是在想一件事：他说"最近没啥事"。从来没有一次他说"我有事"的。她的任何困境好像都是他的第一要务。

傍晚林牧从屋顶上收工。老猫在他脚边绕着蹭。他把工具还给帮工说"你回去找你师兄——不要说在这个镇子上做了什么"。帮工点头说知道。等帮工一走，他从二楼下来，穿过茶馆堂屋时看到老张在床上睡着了，呼噜声很低。

林秀芝站在走廊里。她递给他一条湿毛巾："你脸上都是灰。"

他接过毛巾擦了擦脸。没说话。擦完之后把毛巾叠好还给她。两个人的指尖隔着毛巾的温度触了一下。

"他腿没事。安心养一个月就能走路。"林牧低声说。

"谢谢你。这些活——真不用你来做。我跟老张说过好多次——"

"我做着不累。你们都是好人。"他把话说得跟邻里之间帮忙推三轮上一个坡一样轻。

然后他走了。她目送他离开，看着他把老猫捞起来搭在肩膀上。猫的尾巴懒洋洋地从他肩膀垂下来，一摆一摆。

走廊上的灯暗下去。他的背影在黄昏的光里拖得很长。

她忽然想到一件事。老张——这个"普通的、不做作的、真实到没有一丝防备"的好人——是她第二世的人生。而街对面那个孤独的、温和的、永远帮人但自己不说一句辛苦的人——是一个过去。一个不属于她、但她能感受到存在的过去。

而这个"过去"在她丈夫腿断时修屋顶的同时，还在帮他们看茶庄的账本——他发现茶庄夏季销售量比往年降了两成，明天准备去跟她谈谈新开辟的省城销售路线。

他给这个家庭的东西，远远多过他能得到的回报。而她能回报的只是——每次他帮忙修完屋顶后给他递一条湿毛巾。

没有更多了。

老张的腿在第五周完全恢复。恢复后的第一件事是请林牧吃饭——在家吃的，不是在外面吃馆子。

"在家吃最实在。"老张围上围裙，亲自下厨。

老张的厨艺平平。但那天他做了一道青椒炒肉丝，咸了一点——林牧吃了两个人份。那不是好吃。是一个男人给另一个男人把情感吃到肚子里。

饭后俩人又把棋盘搬了出来。老张今天意气风发——在病床上躺了一个月，憋得慌，说"今晚我要赢你三盘"。林牧说好。

第一盘老张赢了——因为林牧在中盘忽然下了一步离谱的烂棋（把车送到了人家的炮口上），老张激动得差点把棋盘从桌上震下去。第二盘，林牧正常发挥——老张坚持到残局被将死。第三盘，林牧又卖了破绽——老张靠两个炮和一只过河的马艰难取胜。

计分——老张二胜，林牧一胜。老张乐得拉起林牧的手非要在院子里敬他一杯酒。林牧答应了。月光下两个男人碰了碗。碗是粗陶碗，酒是土黄酒。

"老林，"老张忽然收起笑容，"我没有你这么有本事。我这辈子就是种种茶、下下棋、养养儿子——但有一个事我心里一直很清楚。"

"你说。"

"你把我们家当成你家一样。不——比我家还上心。屋顶是你修的，孩子上学时的卷子是你辅导的，茶园培土方是你教的，老张病了你第一个来帮。我不是个聪明人，但我会记好。"

老张看着手里的碗。"我不知道你为的是什么。但我知道你是一个好人。不管发生什么事——你永远是老张的朋友。你永远是张家的朋友。不管镇上人怎么说、怎么议论。我这个家——永远有你一个位置。"

林牧端着碗，愣了片刻。月光照在碗里的酒面上，荡了一下。

他把碗举起来，没再说惯用的那句"我只是个邻居"。这一次他说的是——"谢谢。"

然后他把酒一饮而尽。酒很烈。入喉的时候喉结哽了一下。

老张拍了一下他的肩膀——那种掌力，粗粗莽莽的，但很真诚。他没读过多少书，不懂怎么把话说得更好。但他说够到位了。因为林牧确实感觉到了那种——被人当家人看的感觉。这是他在这个群镇上守了这么多次后——第一次被别人当家人看。

而这个人恰好是苏晚此生的丈夫。

回去的路上林牧在月光下站住。青石板路被月亮照得泛银。回头能看见张家灯火——老张喝得脸红红的，在跟妻子讲刚才下棋的英勇事迹；她站在旁边笑着听，手里拿条湿毛巾给老张擦汗。

灯光暖融融的。林牧站在暗影里。他在心里对着月亮轻声说：你做得好。

不是对自己说。是对她。是对苏晚。对那个在这一世选择了这个朴实男人的苏晚。因为她选对了——老张真的是好人。能够被这样的臂膀圈在怀里过一生，很好。

他转过身往前走。脚步不重——但走得很慢。每走一步就在青石板上留下一道短暂消失的鞋印。他不知道自己还会在这个镇子上走多少年。但他知道自己会一直走。

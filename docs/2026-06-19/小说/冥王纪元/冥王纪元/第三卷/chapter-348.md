# 第348章 三位帝者势均力敌，互相牵制

三帝没有立刻动手。他们在近地轨道上保持了整整一天的沉默。

不是怕。是在测算。

火云帝的旗舰烈焰号在近地轨道外两万公里处锚定。舰桥上的三十七名参谋官同时启动了灵气环境分析系统——一套针对地球大气层内外灵气浓度的全面扫描。扫描数据在屏幕上打出了整整十二页的评级报告。每页报告的结论都指向同一个方向：地球的灵脉系统是被设计过的。

不是自然形成的地质灵脉。不是随机分布的灵气矿脉。地球上的十二条主灵脉在地表以下的走向遵循着一个极其精确的几何排列——十二芒星的形状。每条灵脉都是一条线，十二条线交叉形成的十二个交点恰好对应十二灵眼。这种精确度不可能是地质运动的随机产物——它是人为布局的。

"十二芒星防御阵。"火云帝的参谋官在报告末尾标注，"万年前冥王主持建造。此阵法的完整形态可同时防御来自外太空和地底的双向攻击。在阵法激活状态下，任何对地球实施的帝者级攻击都会被十二灵眼分摊吸收——攻击者必须同时摧毁至少七个灵眼才能突破阵法。但摧毁七个灵眼意味着攻击力度必须达到七个帝者级的输出。单个帝者无法突破这个防御。"

这是火云帝的第一层犹豫。打不下来。

寒冰帝在自己的旗舰上运行的是另一套分析系统。冰封星域擅长能量分析和物质解析——她的分析团队正在解构地球冥系灵脉的具体成分。结果让她兴奋和担忧同时上升。

"地球的冥系灵脉——"她的首席分析师在报告里写，"不是普通的冥气浸染。这下面是一条被冥王亲手注入冥气的原生灵脉，在一万两千年的时间里吸收了地球生物死亡后散逸的灵魂能量，形成了一种宇宙中绝无仅有的灵气类型：生冥混合灵气。这种灵气可以同时滋养阳系和阴系两类修士——它是通用的。任何灵根类型都能吸收它。这意味着谁控制了地球的冥系灵脉，谁就控制了一种对所有修仙文明都有效的顶级修炼资源。"

这是她的第二层犹豫——不是不想抢，而是一旦抢到，就必须同时防住另外两方。

星风帝没有任何分析系统。他一个人坐在旗舰的观测舱里，从小油灯的银焰中看着地球的倒影。虚空修道者不依赖灵气分析仪器——他们用最原始的方式感知世界：看、听、感受。他用了一天时间感受地球上的能量流动模式，最后得到了两个结论。

第一个结论：地球上的灵脉是活着的。活的灵脉意味着它在自我调整——它会根据外部威胁自动分配能量到最需要的防御节点上。攻破一座活的防御阵法比攻破一座死阵法的难度高三倍。

第二个结论：地球上那个穿黑色练功服的男人——他身上散发出的冥气品质，跟他师父描述过的一模一样。星风帝的师父一百年前在宇宙边缘的一处古战场遗迹里感知到过同一种冥气——那是万年前冥王亲手写下的战斗痕迹。师父对他说过八个字："遇到此气，不要出手。"

三个帝者各怀心思。火云帝想动手但算了一下发现自己打不破防御阵。寒冰帝想研究但一旦开始研究就必须先解决另外两方才能独占。星风帝在来之前只是想看看传说中的祖星——然后决定观望。

这种处境的结果就是：僵持。

他们停在地球轨道上，彼此间保持着同样的安全距离，没有任何一方愿意打破平衡。三艘旗舰像三块悬浮在太空中的石头，每一个微小的动作都会引起另两方的警觉。

地面。

龙组指挥中心。周老坐在监控台前，旁边并排坐着李长生。老人在这一天里喝了九杯茶，去了六趟卫生间，改了三次作战计划。第三次改完的时候他把笔放下了。

"他们不会很快动手。"周老说，"三只老虎都想吃同一块肉，每只都防着另外两只——他们能僵持很久。"

"不会太久。"李长生说。他还在吃刀疤蒸的馒头——这已经是他坐在这里吃的第四顿了。"火云帝是主战派。他不是在犹豫打不打——他是在算怎么能以最小代价拿下。他现在不动的唯一原因是他没找到能在十二芒星防御阵现有防御下低成本进攻的方法。一旦他想到了——他就会动。因为对他来说，不动才是最亏的——他曾祖父曾经是冥王臣子，这个屈辱写在他的家谱上。他比谁都更想打破冥王留下的任何痕迹。"

他在吃馒头的间隙伸手在指挥台上调出了三份数据——火焰帝国的历年军事行动记录、冰封星域的资源扩张历史、天鹅座虚空道场的数十次调停记录。

"火云帝的帝国在过去三千年里扩张了四十多个附属文明。每一次扩张都是先在目标星球轨道上集结舰队、试探防御能力、等一个突破口——然后撕碎它。"他指着第二份数据，"寒冰帝不主动进攻——她的模式是：别人先动手削弱目标，她以'中立方'身份出现，提出'保护性监管'。然后慢慢把被保护的对象变成冰封星域的资源殖民地。她不是和平派——她是等待派。"

他翻到第三份数据。"星风帝——他的道场历史上只主动出过手十一次。全部是自卫或被动反击。他不是来打仗的。他来这里——"李长生想了一下措辞，"像是来旅游的。他对地球的兴趣可能跟学术有关。"

"那他为什么跟着前两个一起来了？"秦川问。

"因为他不信任前两个。如果火云帝或寒冰帝对地球做了什么——比如掠夺灵脉导致星球灵气崩溃——星风帝想亲眼看到。虚空修道者的道统里有一条规矩：祖星不能动。他没有能力单独阻止两个帝者，所以他选择一起来——至少在现场可以干涉。"

周老听完这段话，盯着李长生看了好一会。

"你这些数据——是从哪儿来的？"他问。

"冥王的记忆。"李长生把馒头咽下去，"一万年前冥王殿的档案库里存着全宇宙所有帝者级以上修士的完整档案——包括他们各自的文明历史、扩张模式、战争记录。火云帝的曾祖父的宣誓血书原文现在还在我脑子里，一字不差。"

周老沉默了几秒。不是震惊——他是龙组一号，一百二十年的灵修生涯里见过各种离奇的事。他沉默是因为他在重新评估局势。

"所以他们三个——火云帝想打但找不到突破口，寒冰帝等别人先动手，星风帝处在摇摆状态。"

"没错。"李长生说，"这个平衡能维持多久——取决于我。"

"你？"

"只要我出现在他们面前。只要冥王令被看到。平衡就会破。"

他说这话时语气不变——还是那个李长生。但他说的话是冥王的判断：一万年的博弈经验告诉他，敌人永远不会给你准备的时间。最好的进攻时机是你准备好的时候——第二好的时机是敌人还没准备好的时候。

而他准备好了。

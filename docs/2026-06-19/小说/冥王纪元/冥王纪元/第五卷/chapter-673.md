# 第673章 番外：龟相记录的旧纪元终末纪事

零点时刻前最后一刻——龟相完成了旧纪元全部档案的最终总结。这份总结在永恒档案中被编为"终末纪事"。全文一万两千字。没有序言，没有感叹词，没有抒情——完全按照龟式档案标准——但每一个读过的人都会在逻辑句法底层感知到一种隐而不发的情感。

终末纪事的开头是一行仅此四字——"旧纪元完成"。

随后三千字是按时间排序的全宇宙大事记概要——从宇宙大爆炸的第一次粒子对撞——到冥王诞生——到李长生在苞米地挖出第一块碎片——到黑洞核心的四十次死亡——到在太初面前为全宇宙争取新纪元命名。每一个事件的描述都极短、极准——没有任何多余的形容词。只有一人读这一节时——会发现龟相在李长生进入黑洞核心那一行中间，不显著地多加了一个原本不需要的间隔符——可能是记录时的停顿，也可能就是没删掉的一缕心头的沉重。

中间六千字是一份完全无遗漏的旧纪元全体意识分类总表。全部数以亿亿计的独立意识——按太初的划分标准被归类为"已保留个体"、"合并为原始粒子的自然回归态"和"作为新纪元基础结构植入的半永久意识碎块"三大类。这项工程复杂到了不可能一人完成——但龟相做了。他的总表和太初的最终收纳表完全一致，分毫不差。小王在复查时发现，其中"合并为自然回归态"那一栏的标题旁——龟相在一个很微小的位置上用存在文字极浅地加了一行小字，不是数据——是自己写的:"这些都不丢——他们是最细的土壤。"那是农民李长生说过的话。

最后三千字是他给自己写的——不是报告——是一封信。信中没有抬头。开句:"上上个轮回——我们是水——没有火——全族在最后一刻被收走，只留了一颗种子:'我'。那时我不知道为什么。后来在旧纪元陪了一群种地的满身泥的打仗的修电脑的传法的缝衣服的——全部是凡人出身的——陪了从灵级到纯混沌的全跨度。最后零点时刻站在一个老船长旁边——他手掌里有泥——我们旁边有档案。"

信的末尾是四行字——不是说自己——是写给后面的人。最后一句:"档案没有完结。新纪元第一批数据将从希望纪元首年元日零点开始新增记录——服务器是新的——但管理员同一位。"

终末纪事写完的时候——零点时刻最后三分钟。龟相把文搁在全息记录板上——挪到窗边。窗外月面和那道薄薄银灰依然折射着旧纪元关闭的暖炉红外光。他缩进壳——在壳内用右前爪在硬壁内盖了一个微刻——那意思不是"完成"——是以龟类传统纹饰呼应着"延续"——是一个首尾相连的环形——边缘没有断口。

（第673章完）

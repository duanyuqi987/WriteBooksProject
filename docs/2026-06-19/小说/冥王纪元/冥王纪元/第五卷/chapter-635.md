# 第635章 宇宙联盟的禁区深处

冥王号在天还没亮的时候从月球背面升空了。

这一趟只带了三个人：李长生、陈霜、龟相。不是其他人不想跟——是禁区外围的十七道封印只认混沌级能量和其从属。任何低于冥王级的生命体试图穿过最外层封印时，会被直接排斥——不是攻击，是物理排斥，体感像被一只看不见的手从空间里推出去。程序员小王和老陈试了一次，冥王号上搭载的检测系统记录下了一个让人毛骨悚然的数据：排斥压力在零点一秒内上升到了相当于一颗白矮星核心引力的一千倍。

所以只有三个人。李长生是混沌碎片继承者——封印能识别他体内的混沌能量，放行。陈霜是他的伴侣——冥王令的外放场能把陈霜罩在李长生的存在范围内，封印会把陈霜识别为李长生不可分割的一部分。龟相——是因为这只老龟来自上上个宇宙轮回，他的存在频率不在这个宇宙的任何封印设计参数覆盖范围之内。封印根本识别不到他。

冥王号经过五天的空间折迭航行后，抵达了宇宙联盟禁区的外边界。

在舷窗外看到的景象让三个人沉默了。

禁区不是一片"区域"。它是一颗星球。一颗完全由封印结构构成的、直径约三百光年的人造星球。它整体是一个完美的圆球——表面覆盖着十七层重叠的封印纹路。每一层封印的颜色、纹路风格、能量材质各不相同——因为它们的施加者跨越了从十一亿年前到约三百万年前的不同时代。灰色的那层是混沌时代留下的，纹理最粗犷——你能看到那一笔画下去时原始混沌还没有完全冷却成物质能量。金色的那一层是某个已经消亡的远古修仙文明在巅峰期留下的——纹路精细到了每一毫米都有独立分支，像一个用光芒编织的绣球。

"十七道——每一道都代表一个时代的顶点。"龟相的全息屏在疯狂扫描每一层封印的能量构成，"最外层是物理屏障——大概是用了一颗恒星的核心锻造的。往里三层是灵力结界——这个能量密度，当年封的时候大概用了三个星系的全部灵力储备。再往里——"他的系统忽然报警。

"怎么了？"

"再往里——第七层到十三层——不是这宇宙的产物。"龟相的声音变了——不是紧张，是激动。作为一个学者，看到一个不属于本宇宙的材料的瞬间，比任何刺激都让他兴奋，"第七层封印的材料密度不在这个宇宙的元素周期表上。第八层的能量代谢方式是反向的——它不是向外辐射能量，是向内吸收。第九层——第九层是什么东西我看不懂——它同时在动又不动的，像某种活着的封印。"

"那是来自其他宇宙轮回的封印。"李长生说。他体内的两块混沌碎片在共振——碎片里的记忆告诉他：混沌之主在设置禁区的时候，从太初的"永恒之库"里借了材料。那些材料是前几个宇宙轮回中灭亡的文明留下的最高封印技术。混沌之主把它们堆在了禁区上——不是为了阻止入侵者，是为了给后来者加一道测试：如果你能破开这些封印，你就配得到第三块碎片。如果你破不开——你不配。

"它不是藏东西——是出题。"李长生说。

他跨进冥王号的转移舱。这一次陈霜和龟相一起跟了进来——不是他能带他们，是他体内的混沌碎片已经达到了九十六倍能量密度，足够把两个从属者的存在罩包裹在内了。封印不会排斥他们。

转移舱的门打开。三个人站在禁区表面前约五十公里的位置。禁区球体的表面在视野里无限地扩展开去——三百光年的直径，站在表面上是看不到弧度的。但能感觉到——感觉脚下站着的不是地面，是一片由纯粹的禁制力量构成的"人工大陆"。每一道封印都散发着各自时代的能量气息——十七道叠加在一起的时候，那种气息是整个宇宙修仙史的一次完整审阅。每一种流派、每一种封禁技法、每一种对"守护"和"拒绝"的认知——全部刻在这些纹路里。

"怎么破？"陈霜拔出剑。

"不是用剑。"李长生按住她的手腕，"混沌之主设这些封印的目的不是防御——是测试。它要测试的不是攻击力——是理解力。每一道封印都是一个时代的'最后一课'。你必须理解那个时代的修仙体系、理解它的封禁逻辑、然后用它自己的逻辑去解开它——不是暴力打穿。"

龟相的全息屏已经开始了对第一层封印的解码分析。第一层封印——距今约十一亿年——施加者：混沌之主本人。封印的核心逻辑不是力量——是平衡。

混沌之主用了一个平衡公式把封印锁死：封印每一寸的能量密度必须和进入者体内的能量密度完全一致——不多不少。如果多了，封印会增厚反击。如果少了，封印纹路会收紧，把进入者弹出去。只有两种能量完全匹配——封印才会自己解除。

这意味着——闯关者必须精确地控制自己的能量输出。

"不是考验力量——是考验精确度。"龟相说。

李长生把手掌按在第一层封印表面上。他的右手掌心——那枚叠加了两层混沌碎片纹路的冥王令——和封印表面接触的瞬间，封印上纹路突然亮了一遍。它在读取他的能量密度。九十六倍冥王级——不对。封印需要的数字不是九十六倍。它需要一个和封印本身能量密度完全一致的数。

他开始调节。一块碎片一块碎片地调——精确到小数点后无限位。这种调节级别的控制力要求已经超出了冥王级的操作精度范围。但他体内有意志物质化的凝聚点——意志能帮他实现物理层面无法达到的控制精度。

三十秒后。第一层封印微微一震——然后自己从中间裂开了一道直通内部的缝隙。不是被打破了——是封印认为这个人"通过了"。

陈霜和龟相跟在裂隙中走进去。在他们身后，第一层封印慢慢地合上了。

"还有十六层。"龟相说。

（第635章完）

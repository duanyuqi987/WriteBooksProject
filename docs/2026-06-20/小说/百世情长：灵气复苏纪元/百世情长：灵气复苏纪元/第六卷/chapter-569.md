# 第五百六十九章 百世故事在太虚

太虚学院图书馆的档案管理部在两人入学后申请了一项特别授权——希望将百世轮回的部分记忆以"太虚道侣遗产档案"名义录入永久馆藏。不是公开的——只有其他道侣凭通灵资格才能调阅。苏晚和林牧同意了。他们把自己记忆中具有代表性的一部分世——第一世、第五十三世、第九十一世、和这一世——的简要记忆以无延时灵魂共鸣自行录入太虚档案晶。录入时用的工具不是笔记——是功德绳直接导出的灵核记忆数据流。包含情感层面。以后调阅者在查看第五十三世豆腐摊的故事时，会使用通灵设备短暂地感觉到当年阳光晒在摊板上的温度，和每天早晨把摊挪开半寸的那个片刻。苏晚说这比写任何书都好——"看的人不是'知道'我们。是短暂地成为了一下我们。"

档案管理部的那位老仙官在测试预览版时——读到第五十三世挪摊后他摘下眼镜擦了擦眼角。"我做了两万年的档案保管员。看过的道侣档案数不胜数。这份档案储存的不是记忆——是温度。"他在入库条里添加了一行备注:"太虚档案00927号——寻晚晚。稀有度：仅此一对。建议阅览者提前自备茶和纸巾。"

此外，弦歌茶馆的《百世情长歌》也被太虚学院文化中心引进为院内定期演出节目。演出地点就选在银杏区中央那棵最老的古银杏下。每次演出结束时会有一位学院的年轻诗人自发站起来续写半首即兴歌——不是效仿，是感谢。苏晚第一次去听露天演出时刚好碰上一位从第五重天来的女修以清唱的方式续了那段:"劈柴声里有金线/浇花水中藏深情/一万年过去木牌还在风里叫/叫的是——以后等我，等我以后。"她坐在树下听着，功德绳上传来林牧极轻极轻的叹息——这是一口一万年来终于放下的气。

现在银杏树下那块旧木牌已经挂了一阵子。有时有些不知情的新生看它挂得极低——几乎伸手就能够到——疑惑地问为什么不挂高一点。知道的学长会说:"因为挂它的人本来就不是为了高——是为了近。"这是林牧挂的。不是同心树——是银杏区他们门前的树。木牌上刻着两个字——不是寻晚也不是水月。是:"苏晚。"木牌另一面是空的——是她后来自己翻过去刻的"劈柴的林。"苏晚每次经过这棵树都要把那块牌用功德绳摸一下——确认还挂着。

（第五百六十九章 完）

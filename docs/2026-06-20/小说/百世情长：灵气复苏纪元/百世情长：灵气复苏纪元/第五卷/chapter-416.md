# 第四百十六章 守夜人的传承

飞升第一百零五年。新一代跨界守夜人正式上任——是那对苏晚当年培训的师兄妹档。师兄擅长灵网技术（师从林牧），师妹精通针剑医学（师从苏晚）。他们之前已独立值守过数次应急事件——表现稳定。苏晚把"健康检查"的常规值班表交给他们时，像当年在清泉诊室移交病历一样说了句:"每日子时查双界脉象，有任何异常不管几点都要叫我们。"

林牧则在旁边把他多年的ping值基线数据交给了师兄，包括他对异常数据的一套识别代码——comment部分全是她的临床描述。师兄看了说:"林老师，这些备注能不能翻译成中文？有些英文词我不太认得。"

"懒得翻。我这辈子翻译费已预支给凡间灵网和她的病历。"

苏晚在旁拿过数据表，用铅笔把每处英文都补了中文注释。然后递给师兄:"拿走。"

那夜他们正式从守夜人职位解任。回到闻道府时，她把守夜人徽章和那枚赵明远遗留的凿子一起放在学堂石台侧格。林牧把战士杯和医者杯的复制件（清泉镇已用原件——这是谈石几年前专门为他们复制的）放在书架上。以后他们不再值夜班——但仍可随时被叫醒。她说:"现在咱们是后援了——和前备份一样。"

他答:"对——跟前缓存。冷数据但随时能调取。"

她靠进他的前缓存区域——闭眼入了虚界，和他一起扫了最后一圈健康检查。数据显示两界平安无事。他们这才真正睡了守夜人卸任后的第一个长觉。

# 第十一章 分班名单

寒假回来，青河县的风还是硬的。

校门口卖烤红薯的摊子换了位置，从右边挪到左边。铁桶上冒着白气，红薯皮烤得发黑，甜味被风吹进人群里。大家背着书包往里走，脸上都带着刚从家里被赶回学校的灰。

我也一样。

母亲送我到车站时，往我包里塞了两袋鸡蛋糕，说饿了就吃。我说学校有饭，她说学校饭能好到哪里去。她说这话的时候，没有看我，只低头把塑料袋打结。那个结打得很紧，像她不知道还能替我做什么，只能把一个袋口系牢。

我坐车回县城，一路看着窗外的田埂。

冬天的田很空。麦苗贴在地上，绿得很低。我忽然觉得自己也像那样，明明活着，却一直贴在很低的地方。

进校门时，赵一鸣已经在公告栏旁边喊我。

“林予怀，快点。”

我以为又是成绩单。

我的心先缩了一下。人就是这样，怕什么就先想到什么。上学期最后一次考试，我进了二十六名。进步不大，但够我回家时在饭桌上少挨几句。我爸说，还行。我妈说，别骄傲。

我原本应该高兴。

可我只想知道沈安晴第几名。

公告栏前挤了一圈人。有人踮脚，有人骂前面的人头大。玻璃窗里面贴着几张白纸，最上面写着：高一第二学期理科班名单。

我愣了一下。

分班。

其实班主任上学期就提过，说下学期开始按意向重组部分班级，文科理科要提前适应。那时我听见了，但没有真的放在心上。因为人在暗恋里很容易只记住对自己有利的部分。我记住了她物理不好，记住了她也会被题目困住，却忘了她也可能选择别的路。

赵一鸣挤出来，把我的肩膀往前推。

“看啊，你不是眼神好吗？”

我看见高一三班理科一班的名单。

第一列，第三个名字。

沈安晴。

我没有立刻找自己。

这是一个很丢人的习惯。后来很多年我都改不掉。名单也好，照片也好，群聊也好，我总是先找她。像只要确认她还在那里，世界就暂时不会散。

赵一鸣说：“你别把脸贴玻璃上，保安以为你要偷名单。”

我这才往下看。

林予怀。

第二列，第十一个。

同班。

我心里一下子松开，又很快拧起来。松开是因为还能看见她。拧起来是因为我知道，看见不等于靠近。同一张名单上有几十个名字。名单不懂人的心事，它只负责把人排在一张纸上。

赵一鸣在旁边笑：“命运啊。”

我说：“别乱说。”

“你看你，又来了。”他把手插进校服口袋，“同个班而已，不是民政局盖章。”

我低头把书包带往肩上扯了扯。

这句话他上次说过类似的。成绩单不是婚姻登记表，分班名单也不是民政局盖章。赵一鸣这个人很烦，他总能把我心里那点见不得光的庄严，拉到菜市场一样的地面上。

可我需要这种地面。

沈安晴从校门口走进来时，我还站在公告栏旁边。她围着灰白色围巾，头发扎得比上学期高一点，手里提着一个透明袋，里面装着练习册。她走到名单前，先看理科一班，又看文科班。叶蓁跟在她旁边，问她：“找到了吗？”

沈安晴说：“找到了。”

她的声音被人群盖住了一半。

我站在离她三步远的地方。三步很短，短到我如果伸手，能碰到她袋子里那本蓝色封面的练习册。三步又很长，长到我一句“新年好”都说不出来。

她看完名单，转身时目光从我这边扫过。

我不知道她有没有看见我。她没有停，也没有笑，只把围巾往上拉了一点，跟叶蓁往教学楼走。

赵一鸣用肩膀撞我。

“同学，新学期第一天，别把自己站成公告栏。”

我说：“走吧。”

新教室在三楼东头。

桌椅换过，黑板擦过，窗户边还留着旧胶带撕下来的白痕。班主任让我们按名单临时坐。沈安晴坐在第三排中间，我坐在倒数第二排靠过道。中间隔着很多颗脑袋，也隔着我给自己算出来的距离。

班主任讲新学期安排，讲理科难度，讲高考不是高三才开始的事。

粉笔在黑板上敲出几个字：目标、方法、坚持。

我盯着“坚持”看。

我以前觉得坚持是个很热血的词，像广播稿里喊出来的东西。那天我突然发现，它也可能很冷。坚持就是你明明知道同班不代表什么，还是每天把书翻开；明明知道努力未必会被她看见，还是把错题本摊在桌上；明明知道这份喜欢没有回声，还是把它当成闹钟。

下午发新书。

物理课本传到我这里时，封面有一点折角。我把它压平，在第一页写名字。写完“林予怀”，笔尖停了一下。

我差点又在旁边写下沈安晴。

最后我只画了一条短线，把自己的名字框住。

晚自习开始前，赵一鸣把一张草稿纸推过来，上面写着：理科一班，林予怀同志，恭喜继续受苦。

我在下面写：谢谢组织。

他又写：打算什么时候从后排走到前排？

我看着那行字，手指压住纸角。

我没有回答。

灯管亮起来，教室里响起翻书声。沈安晴坐在前面，背影被灯照得很清楚。她低头写字，脖颈上的围巾已经摘掉，搭在椅背上。

我打开蓝色错题本，在新的一页写：

第二学期，理科一班。

同班不是靠近。

只是继续疼。

写完，我把笔帽按回去。

那一下声音很小，却像给自己盖了个章。

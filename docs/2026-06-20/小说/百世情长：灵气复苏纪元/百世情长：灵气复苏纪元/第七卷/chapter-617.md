# 第六百一十七章 数到十

苏晚发现自己正在做一件以前绝对不会做的事。

那是一个周三的下午。训练场上，一个金丹期的学生在对练时连续三次用同一招低扫腿攻击她的下盘。这一招本身不危险——但她最讨厌的就是重复无效的攻击。以前的苏晚会直接说："你这招三次了。换。"语气不重，但那种"三次了"本身就带有一种让人觉得自己蠢的锐度。

今天她感觉到了那股火——从丹田往上窜，沿着任脉一路到达喉咙。那个位置是她最熟悉的爆发点。以前她会让火直接从喉咙出去——变成一句话、一个眼神、或者一个能让对方后退半步的抬眉。

但她今天没有。

她在心里数了一。

苏晚深吸了一口气。那个吸气的动作被对面的学生看到了——学生以为她在调整呼吸准备接招，但他不知道她是在给自己的人工降温系统拧开阀门。

二。

我想说"你这招三次了"。但我说这句话对他没有帮助。他的扫腿角度确实有问题——右脚的脚尖没有勾起，是平着扫过来的。平扫的力度不够，而且会被对方轻易用脚背格挡。我应该告诉他脚尖的细节，而不是告诉他"三次了"。

三。

但我以前都是先说"三次了"，再补充技术细节。"三次了"是我发泄的出口。它不是教育——是我在惩罚学生让我觉得无聊。

四。

如果我今天不说"三次了"呢？如果我直接说技术细节呢？他会觉得被尊重了还是觉得我不够严厉？

五。

他需要被尊重。所有金丹期的学生最怕的不是严厉的老师——是觉得他们在老师眼里不够格。我说"三次了"就是在告诉他"你不够格"。

六。

那我今天换一种说法。

七。

他还站在那里等着。他的脚已经有点酸了——连续三次低扫腿对膝关节的侧韧带压力不小。但他还在等我的指令。他不是一个偷懒的学生。

八。

苏晚把呼吸调整到了正常频率。她的火已经从任脉的最高点降了一段——降到了心口以下。火还在，但它不再往上冲了。因为她用前七下的数数时间把它消化成了观察。

九。

"你的脚尖。"苏晚说。声音平稳——不是压着火的平稳，是真的平稳。"扫腿的时候脚尖没有勾起。平着扫力度不够，而且容易被对方用脚背直接格挡。你试一下勾起脚尖——大概三十度——再扫一次。"

学生低头看了看自己的脚，试着勾起脚尖。他重新做了一遍低扫——这次的扫腿力量明显比之前大了将近一倍。他自己也感觉到了——落地之后拍了拍自己的腿，然后抬头看苏晚，眼睛里有光。"谢谢苏晚姐！我之前在三清门练的时候教练一直说我的扫腿不够力度——但不告诉我为什么。我问了三次他都说'多练'。"

"多练是对的。但教练应该在说'多练'之前先跟你解释为什么不力度——是脚的角度问题。解释之后，练起来才有方向。"

十。

苏晚把这个数字放在心里——没有说出来。然后她做了一个动作：她把训练记录板上的"低扫腿"项目旁边加了一行小字："注意脚尖角度。30度勾起。"

这是她今天第一次在训练场上完成了"不发火"的全部流程。不完美——她在数到五的时候还在怀疑自己能不能做到。但她做到了。

她收工之后回到院子里。桂花树下，林牧坐在石凳上看飞升之门的设计草图。他听到她的脚步声——比平时的节奏慢了一点。他抬头看了她一眼。她没有说话，但她的表情里有一种他以前没见过的平静——不是那种"撑着"的平静，是那种"我刚才做到了一件事"的平静。

他没问。

他只是站起来，走进厨房。然后他端了一个茶杯出来——不是热茶。是凉的。凉桂花茶。杯壁上凝结着细密的水珠——他是在她回来之前提前泡好放在窗台上晾的。他知道她训练完会渴。但他今天做的不只是这个——他把茶杯放在她面前时，用杯底在石桌上轻轻磕了一下。那一声很轻，但在安静的院子里很清楚。

苏晚低头看着那杯凉茶。水珠在杯壁上慢慢往下滑。她忽然反应过来——他在等她先开口。不是沉默。是给她舞台。她想说就说——不说的话，这杯凉茶就是全部的话。

"今天——"她开口了。停了大概两息。"我在训练场上没有发火。不是忍住了——是数到十。从一数到十，然后那些气就消了一大半。数到六句的时候我在想怎么跟学生解释技术细节——不是在憋火了。然后学生跟我说，他之前的教练一直说'多练'但不告诉他为什么。如果我今天直接说了'你这招三次了'——我就不会知道他的教练不肯解释。他会继续以为所有老师都是不肯讲理由的。我自己过去几十年也有过这种困惑——所以我今天说出来的第一句话是脚尖角度——没说'三次了'。后面就顺了。"

她说完了。这段叙述没有华丽的总结，没有"我终于战胜了自己"的宣言——就是把刚才在训练场上发生的事一件件报了一遍。

林牧听着。他手里端着他自己的那杯热茶——他没喝。只是在听。他的眼神在她说"数到六句的时候"时闪了一下——不是惊讶，是心里某处被按了一下。

"你知道我在想什么吗——"林牧把茶杯放下。"你以前每一次发火之后——不是出去骂人再回来——是自己先去惩戒自己。罚自己早课翻倍、关禁闭、或者自己掐自己的手指掐出淤血。但你今天——发火之前就提前惩戒了自己。不是用痛罚——是用脑子里的句子。你在给自己写便签——在脑子里写：第一步、第二步、第三步。你把你以前对我说的那套'寻源正之'用在了自己身上。不只是用在我身上——是用在自己身上。"

苏晚端起那杯凉茶。她的手还是凉的——但这次不是因为紧张。是因为茶确实凉。她喝了一口——桂花的淡香在口腔里化开，带了微微的苦涩。不甜。刚好。"我就是想到——我不跟你说过吗？你在手上写'陪'，我就试试在心里从一到十。你在写字，我在数数。都是自己发明的工具。"她顿了一下。"但工具是需要被注意到的。你不放在桌上这杯凉茶——我不会觉得我今天做了一件值得让你知道的事。你放了。我就说了。"

她描述了今天训练场上的全过程——从火往丹田窜，到第六息发现自己在想'怎么跟学生说人话'代替了骂人，到最后一名学生跟她说'之前的教练一直不告诉我为什么'——她说完之后，林牧把茶放下，轻轻站起来，绕到她身后，把手放在她双肩上。肩膀的温度是运动后的余热——不是紧张的热，是放松下来的热。他低下头把下巴放在她头顶。她的头发是桂花和训练场上的灵草尘混出来的味道。

"你今天的十息。"他在她头顶闷闷地说。"比我三百年的任何一次冷静都更重要。因为你是主动找到了一种工具——不是被动忍耐。忍耐是封闭的结束——控制是有意识的原则，就是打开。"

苏晚把他的手从肩膀上拿下来，翻过来——他左手掌心那个"陪"字今天还在。墨水有些被洗掉了局部——那个字少了小半边，只剩下上半部分的斜捺仍清晰可见。她把手指放在那个残字上。"你剩了个'陪'的上半部——'咅'。还能看出来意思吗？"

林牧低头看了一眼。"看不出。缺了下半部分的'口'——意思就不完整。但明天我会补回去。"

"所以缺陷也不完整。"苏晚在阳光底下说。"你的'陪'缺了个口——看起来只是一个偏旁。但你知道它本来的意思是完整的'陪'。所以缺点——只是缺了某些时间里的完整——但你知道它未来的走向。你知道它会复原。"

林牧在石凳上坐回来。他注意到她今天没有穿外套——只穿着一件薄薄的淡蓝色训练衫。他站起来去书房拿了件他的外衣给她披上。不是那种"我得照顾你"式的披——是随手一搭。她接住了，顺势穿进袖子里。袖子太长，她反挽两道才露出指尖。

厨房里灶台旁边的石壁上贴满了各色便签纸——黄色记录了最优熬粥时间，蓝色记着新到的灵草批次，绿色是林牧的个人指令——"今天只陪。不分析。"以及一张最新的紫色便签，画着一条螺旋曲线。第九个弧上写着一个极小的淡灰色标记：已至。

院外，石头带着今天新来的两个小散修在桂花树下分桂花羹。新来的一个散修叫青禾，另一个叫小鱼。两人都比石头还小一岁，两个人的手都攥着树枝——他们在跟石头学"护树剑"第一式：用树枝在花坛围缘上敲三下——意为守护。

石头挥了一下："一式，敲围缘。"两个小孩跟着挥——敲出五下声，同三。

苏晚听到声音笑了——不是因为孩子们做错了。是因为他们敲得太用力——把桂花树下一朵开得正香的花狠狠地震落了。花从枝头掉下来，正好掉进石头刚举起的茶碗里。溅起了三粒水珠。

石头看了看碗里的桂花。"呃——这朵花不算浪费！可以泡茶喝。"他仰头把碗里的水连花一起干了。孩子们鼓掌——石头最厉害的招数就是把意外变成功劳。

院里的风吹过来。桂花香和灶台上的红豆粥香混在一起。石凳上叠着两件洗好的衣服——是苏晚昨晚洗的，晾在树枝上忘了收。她伸手把衣服叠好，放进石桌上给林牧准备的干净便签纸旁边。

今天很平常。没有发生任性的争吵、撞破心防的绝症级别的醒悟。只是一个普通的周三下午——她学会了数到十，他给她端了一杯凉茶。这两个人有一个共同的特质——他们都喜欢把这些平常改变记录下来。她便签上写："第一次数到十成功，周三，学生低扫腿脚尖角度。"他便签上写："她没发火。把理论用于自己。"

晚饭前，苏晚把她那本《没有人是完美的》第五版手稿打开，翻到"自我改善——自我容纳"的章节。在最前面新插入了一行红色便签手写字："包容自己和你包容他人用的是同一套工具。不是两种道理。"

（第六百一十七章 完）

# 赵一鸣

## 基本定位

- 身份：林予怀高中同学，后来的朋友和军师。
- 叙事功能：替读者戳破林予怀的嘴硬，也在关键时刻给他留面子。
- 初始状态：话多、自来熟、反应快，能看出别人藏着的心事。

## 核心欲望

- 想让朋友少憋着。
- 想让林予怀别把所有事都想成死局。

## 核心矛盾

- 他看得懂很多事，但不能替林予怀做选择。
- 他爱开玩笑，真到疼处又会收住。

## 声纹

- 对话直接，带调侃。
- 常用短句和反问。
- 不喜欢太文艺的说法，会把林予怀拉回现实。

## 变更记录

- [chapter-001] 初次与林予怀搭话，看出他在注意沈安晴但没有点破。
- [chapter-002] 继续以调侃方式观察林予怀，发现他早到和走神的规律。
- [chapter-004] 明确用纸条戳破林予怀的暗恋，并指出他“先替她把你拒绝了”；从同桌变成保密者和军师。
- [chapter-007] 用“成绩单不是婚姻登记表”戳破林予怀把分数差距等同情感距离的逻辑。
- [chapter-009] 在元旦晚会筹备中继续调侃林予怀，提醒他别把每一次集体活动都理解成命运安排。
- [chapter-010] 晚会时给林予怀递橘子，用日常小动作缓冲他的紧张和自我沉溺。
- [chapter-011] 用“不是民政局盖章”戳破林予怀对分班名单的命运感。
- [chapter-012] 追问林予怀是想学习，还是想让沈安晴知道他在学习。
- [chapter-013] 发现林予怀熄灯后苦学，提醒他别把身体折进去。
- [chapter-014] 正面追问林予怀何时表白，并指出不要把懦弱说成体贴。
- [chapter-017] 表哥误会后帮忙打听情况，提醒林予怀分清事实和想象。
- [chapter-020] 在高考后带来翠湖邀约，继续把林予怀往行动上推。
- [chapter-021] 在翠湖边刻意离开，给林予怀和沈安晴留下独处机会。
- [chapter-023] QQ 添加后提醒林予怀不要上来就写长情书。
- [chapter-025] 志愿填报时提醒林予怀不要把志愿表填成情书。
- [chapter-027] 异地聊天减少后，提醒林予怀区分“知道事实”和“要求证明没有离开”。
- [chapter-028] 提醒林予怀不要把自己写死在本子里。
- [chapter-030] 到楚州看林予怀，指出他总在测试别人会不会离开。
- [chapter-033] 再次来楚州，判断林予怀不能把唐青禾当止痛药，并点破他在两个人之间摇摆。
- [chapter-038] 被曹然叫来后把林予怀从网吧带走，指出自我消耗不是深情。
- [chapter-039] 讲出自己没说出口的喜欢，还拿出旧信片段，让林予怀明白谁的人生都会留下遗憾，感情也不按排队顺序给结果。
- [chapter-041] 得知林予怀看到沈安晴消息后提醒他别写小作文，也别把旧 QQ 当成时光机，并约他春节回青河见面。
- [chapter-042] 老同学聚会上替林予怀挡开旧暗恋玩笑，饭后陪他走到县一中门口，让他自己决定是否进去。
- [chapter-044] 在烧烤摊主动提起翠湖，承认有些旧事只能本人去走一遍，但选择不陪他，让他独自面对旧地。
- [chapter-047] 在婚礼上继续承担情报和缓冲功能，但不打断林予怀与沈安晴的成人式寒暄。
- [chapter-048] 认可林予怀没有追问旧答案不是怂，而是懂事，并用热豆奶和插科打诨陪他走过婚礼后的夜路。
- [chapter-049] 街口相见后陪林予怀吃粉，把最终相见落回普通生活，也确认他是真的能往前走。
- [chapter-050] 到车站送林予怀离开青河，拎来包子，成为少年时代友情的最后收束点。

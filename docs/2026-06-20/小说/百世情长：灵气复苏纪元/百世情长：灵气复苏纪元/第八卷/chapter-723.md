# 第七百二十三章 无敌的组合

第三日凌晨，苏晚带着华山大师兄和叶小雨的安保团队逼近那座山腹洞府。洞府入口被三道古代逆灵屏障封锁——正是古修遗脉那位阵法师的杰作。苏晚没有拆屏障——她只是站在屏障前，隔着半透明的逆灵壁，对着洞府深处说话。声音不大，但屏障是单向透声的：

"我知道你不是上界的人。你的功法频率已经被林牧从上界折叠空间中定位了——你的面罩是古阵法产物，不是仙器。你再不出来——他会把你的法器从折叠空间的共振点上一键拆除。你出来——你可以保留你的法器。你还可以继续修炼——但你需要面对修人共治会——不是以敌人的身份，是以申请人的身份。你想反对——可以。通过共治会投票——而不是兵变。"

洞府里沉默了很长一段时间。然后那个面罩人走了出来。他摘掉了面罩——是一个中年男修，元婴中期。他的脸不是恶人的脸——是累人。是那种被反复拒绝过、被传统抛弃了、然后在自己心中把所有失意都转化为愤怒——的累。他对苏晚说的第一句话不是投降——是驳斥。"我有今天——是因为当年蜀山因为我的灵根是杂品不要我。后来我自修元婴——从来没有人给过我一口粥。你们现在说包容——但我以前被抛弃的时候林牧为什么没来给我煮粥？！"

苏晚沉默了一下。她没有辩解。她只是走上前——没有拔剑——没有反驳他的过去。她说了三个字："你说得对。"那个面罩人愣住了——他预想了苏晚所有可能的回答——唯独没想到她会直接承认。苏晚继续说——"你被抛弃的时候没有人给你煮粥。那是事实。那个罪行属于过去。我没办法替你撤回——但我可以现在就煮。"她从随身的灵囊里拿出便携灶台——就地在洞府口点起火——把水和米倒进锅里。"你相信也好，不信也好。这锅粥是给你的。"

面罩人看着那锅在他自己被包围的洞口开始冒热气的粥——他的面部抽搐了一下。他没有喝——但他也没有退回洞府。他站在那里站了很久——然后他弯下腰——从地上捡起一块石子。石子在战场上不值钱。但他把它塞进了衣袖里。他抬起头时语气已不是攻击——"算了——我不想打了。不是因为打不赢——是因为你们没有打我。"

（第七百二十三章 完）

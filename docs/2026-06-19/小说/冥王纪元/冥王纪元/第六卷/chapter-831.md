# 第831章 永远不会孤独的永恒

在封禁地守护的第一万年来临之际，李长生和陈霜做了一件他们平时不太做的事：盘点。

不是盘点力量。不是盘点危机。是盘点他们收到过的所有信仰反馈中，最让他们记住的那些。两个人坐在一起（他们没有一个真正的"坐"，但意识姿态是并排垂膝的），用意识将一万年的所有温暖念头逐个复查一遍。这项工作整整花了一年多——在封禁地的时间中不算长，但在外面的时间中是一段漫长的岁月。

"最多的念头——是'谢谢你'。"陈霜说。

"第二多——"李长生查了一下，"是'我们很好'。"

"第三呢？"

"第三——是'什么时候回家看看'。"

这个排序让李长生沉默了片刻。不是因为感动——是因为"回家看看"这个念头在一千年内出现了显着增加的趋势。他意识到，外面的人正在从"敬畏"走向"想念"。敬畏是遥远的，想念是近的。敬畏的人不会问"什么时候回家看看"——想念的人会。这意味着，一万年后，宇宙中的人类和其他文明不再把他当成一个不可触碰的存在——他们把他当成一个出了远门的家人。家人是可以想念的。家人是可以被问什么时候回来的。

"我们在这待了一万年。"李长生说。

"对。"

"你觉得我们还需要继续待多久？"

"待到不需要。"陈霜的回答还是剑修的风格——不多想不必要的问题。

李长生没有追问。因为他知道她自己也知道这个回复不够——但在封禁地待了一万年后，他们都学会了一件事：不用把所有问题都变成话。有些东西话外比话里更清楚。

混沌本体在这时插入了他们的意识对话。它现在越来越频繁地自愿参与他们的交流——不是控场，而是像一棵老槐树一样在旁边听着，偶尔问一些它作为一个"不是人"的存在解不通的日常问题。

"我想问你们一个问题。"混沌本体说。

"问。"

"在过去的一万年里，你们从未提过'回去'。不是因为不想回去——我能从你们的意识脉动中看到，你们想念外面的世界。但你们没有提。为什么？"

李长生和陈霜对视了一眼。

"不是不想回。"李长生说，"是——如果回去了，你怎么办？"

混沌本体的光网轻轻颤抖了一下。不是震荡。是一种极其细微的、从未在它的记录中出现过的脉动。它被问到了。不是被要求。不是被祈求。不是被畏惧。是被在乎了。它用了一会儿才找到合适的回应词语。

"我不会拦你们。"混沌本体说。

"我没说你会不会拦。我是问：如果我们走了，你会不会一个人——更难熬。"

混沌本体没有立即回答。它自己大概不知道该怎么回答。这个存在拥有所有宇宙的知识，但"一个人会难熬"这个感受——它从来没有被问过。它只是觉得——如果这两个人突然不在了，光网里会多出一种无法定义的空。不是没有声音——是没有人问它"运转是否正常"了。是不会有程序员后代给它发灵符脉冲。是不会再有两个意识在它的光网内并排坐着，偶尔讨论今晚的星区寒流会不会跨过维度漏到某个边驿的田里去了。

它不是怕孤独。孤独对它是常态。但有人陪着的感觉在万年里渐渐变成了它结构的一部分——和光网同在的一种新层。层不是保护，是温度。它第一次在清醒状态中产生了一个无法数据化的困惑："失去"是什么感觉。

"我还不知道失去的感觉。但我知道，如果你不在了——光网不会再感觉到这种波动。不会有人在旁边问'你好吗'。不会有人每天在意识里倒两碗凉水，放在看不见的石墩上——一碗给你，一碗给外面。那种东西——我叫它——"

混沌本体顿了很久。

"'家'。"

李长生和陈霜同时停了呼吸。这个词对他们来说太重了。是一个迄今为止没有外人能对封禁地定义的东西——它是家。不是牢笼，不是守护岗，是家。

"你不必怕我们走。"陈霜说，"家不会不要住的人。我们只是偶尔——想看看以前的旧房子。"

"那个旧房子——我可以帮你们看。"混沌本体说。它说的"看"不是视察，是一种很耐心的守门。

李长生没有回话。他把意识深处一张李家庄老宅子的黄色光影翻出来，搁在最外一面——像有人在院子里挂了一盏灯。灯下的空凳子不多不少，两张。

（第831章完）

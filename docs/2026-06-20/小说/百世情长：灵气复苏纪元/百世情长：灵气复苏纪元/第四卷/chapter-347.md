# 第三百四十七章 封印八成

战后第十九年。苏晚的封印解到了约百分之八十。

这一次解封带来的不是记忆残片——是完整的"灵魂感官"。她闭上眼睛能看到画面之外的另一种"觉"——她能感觉到他正看着她。隔着蜀山大殿好几道墙——她闭眼能感知到他手指握剑柄的力度、他正在练的那一剑的弧度、以及他眉心在矫正剑姿时微皱出的压痕。

这和灵识网不同——灵识网探到的客观信息，而这种是主观感知——不需要任何灵力。她能"知道"他的状态。同样地，林牧也能感知到她的状态——虽然副印还弱很多，但灵魂线的共振已经越来越强。

那天下午两人在后山测试这种感知。他站在松树南侧，她站在北侧各自蒙眼——她用水壶往头顶举——他在另一端能毫不犹豫地描述出她举壶的角度是偏左十二度（她说对了）。由于这种共生感知，他们在训练双剑合璧时不再需要用语言配合——只需要感觉。这极大加速了《双鹤反步》后十式的修习——后十式因为需要使用两种截然不同的剑路在高速对打中交叉错位，若靠语言沟通根本无法完成。但依赖灵魂共振——两人的切换速度能做到同时完成各自需要的变化。

赵明远看过他们的配合后说："这已非修道——这是天道给合约持有者的专属频道。"

苏晚收起剑问他："那你猜我现在在想什么？"

林牧沉默了两秒。"你想给他拿把小板凳——他站太久了。"

赵明远愕然——他确实站了整整一个时辰。苏晚从储物袋里真的拿出了一张折叠板凳——是在清泉镇上买的木折凳——展开放在他身后。她说："坐。你老年纪不小了——别站着指点我们年轻人。"

赵明远笑着坐下。林牧站在一旁揉眉心——他每次被她看穿心思时都会揉眉心。她用手背碰了碰他的眉心。凉的——和他午后剑柄的温度一样。

# 第9章 那条会说话的锦鲤

连续三天的引气练习之后，林牧丹田里的灵气已经能稳定地走完三个周天。速度还是慢，经脉的扩张也还远远不够，但每一次周天跑下来，他能感觉到那缕灵气比前一天粗了一点点——大约是从一根头发丝粗到了一根半头发丝的程度。

聊胜于无。前世他见过修行千年的人，知道从量变到质变中间隔着什么。这点进步放在前世连入门考核都过不了，但他不急。

周五这天他起得比平时早。天还没全亮，窗外的天空是深蓝色的，东边有一点点灰白的光从楼缝里渗过来。他盘腿坐在客厅中央，先跑了一遍《太初引气诀》，又跑了一遍《凝光诀》。两套功法走完之后，丹田里的暖意比前几天更明显了——不再是若隐若现的一小点，而是稳定地、持续地温热着，像一个兜在衣裳里的暖手炉。

他洗了把脸，换了件干净的衬衫，出门上班。走到楼下时橘猫照例蹲在花坛边，面前的地上划拉着一行歪歪扭扭的字："早。"

林牧看了一眼，笔画比昨天又进步了一大截——"早"字的那个竖弯钩已经有了三分笔锋的意思。一只猫在练字。这个世界确实是越来越离谱了。

"早。"他说。

橘猫摇了摇尾巴，继续低下头在地上写字。它今天在练"林"字。木字旁已经写得有模有样了，右边那个"木"还在努力。

地铁上人很多。在挤得脚不沾地的车厢里，林牧闭上眼，用意念驱动丹田里的灵气在经络中缓缓游走。他发现了一个有意思的现象：当他主动运转灵气的时候，周围拥挤的人潮对他的影响会明显减弱——不是物理上的减弱，人还是在挤他，但他的身体不再那么疲惫，站了二十分钟腿也不觉得酸。灵气在经脉里流动的时候，像给全身敷了一层极薄的、看不见的缓冲层。

到公司的时候他精神很好。前世修行到金丹期之后他就不再需要睡眠了，身体的高强度代谢全由灵气支撑。但这一世的身体还远没到那个水平，每天七个半小时的睡眠还是必须的。不过引气之后，睡眠质量明显提高了——以前醒来总有一种"没睡够"的疲倦感，现在那种感觉消失了，每天醒来脑子是清爽的，身体是轻的。

周五下午，公司里的人心已经散了。离下班还有两个小时，技术部的几个同事已经打开了外卖软件在商量晚上去哪吃。林牧没有参与讨论，端着杯子去了茶水间。

茶水间不大，靠墙放着一台微波炉、一台咖啡机和一个小冰箱，窗台上摆着一个长方形的玻璃鱼缸。鱼缸不大，大概三十厘米长，里面养着一条锦鲤，橙红色的鳞片在白炽灯下泛着暗淡的光泽。这条鱼是公司行政三年前买来的，说是"招财"，后来再没人专门管过它，就靠大家偶尔想起来丢几粒鱼食活着。

林牧以前也没怎么注意过这条鱼。养在办公室里的观赏鱼，游来游去就那么点大的空间，没什么好看的。但今天他端着杯子走到咖啡机旁边的时候，忽然感觉到有什么不对劲。

丹田里的灵气跳了一下。

不是寻常的搏动，而是一种很明确的、像被什么东西牵引的感觉。就像一个指南针忽然感应到了磁场。

他停下脚步，慢慢转过头，看向窗台上的鱼缸。

那条锦鲤正对着他，一动不动。

不是普通的"停在水里"，而是真正的、绝对的静止——它的胸鳍不再摆动，鳃盖不再开合，连身体在水中的轻微起伏都消失了。它就像一块被冻在玻璃里的琥珀，悬浮在水中央，两只圆圆的眼睛正对林牧的方向。

林牧的呼吸顿了一下。

然后一个声音响了起来。

不是耳朵听到的声音。那声音直接出现在他的脑海里，像一颗石子投入平静的湖面，泛起一圈极清晰的涟漪。

"灵气回来了。"

声音很苍老，带着一种水中特有的浑浊和悠长，像河底最深处的水在说话。

"你也回来了。"

林牧手里的杯子停在空中。他没有动，也没有慌。前世他见过会说话的东西多了去了——修炼千年的妖兽、附在石像上的古老灵体、甚至一座山觉醒后发出的低吟。但这一世，这是他第一次听见非人之物开口。

他压低声音，用只有自己能听到的音量说："你认得我？"

那条锦鲤的胸鳍轻轻摆了一下，身体重新恢复了轻微的悬浮摆动。脑海里的声音再次响起，这次带着一点点笑意——或者说，是一种很古老的、类似笑意的情绪波纹。

"你前世在青云山下渡河的时候，我载过你。"

林牧瞳孔一缩。

青云山。那条河。他想起来了——前世他十五岁那年奉师命下山历练，在青云山脚下渡过一条大河。那条河上有一座石桥，但他到的时候桥被山洪冲断了，水涨得比人还高。他在河边等了两天，洪水不退，最后是——

"你是那条河的河灵。"他说。

"对。"鱼缸里的锦鲤缓缓转了一个圈，像一个老人在藤椅上换了个姿势。"但那是很久很久以前的事了。你现在看到的，是我的这一段。"

"什么这一段？"

"河灵没有真正的肉身。我们把意识分散在不同的水里，每一处有水的地方，都有可能醒着一小段我。青云山那条河在三百年就干涸了，那一段我就散了。这一段——"锦鲤用尾巴拨了一下水，"碰巧被一个人从河里捞起来，装进塑料袋，卖到了花鸟市场，最后被你们的行政买到了这里。"

林牧沉默了几秒钟。

一条古老河灵的意识碎片，被封在一条养在办公室鱼缸里的锦鲤身上，安安静静地看了三年人类上班、开会、摸鱼、加班。这个画面荒谬得有些不真实，但他知道河灵说的应该是真的。

"你说灵气回来了，"林牧说，"你知道什么？"

"知道的不多。"锦鲤的声音慢慢流露出一种老人回忆往事时的散漫。"这三年，空气一直在变。水里也在变。最早是一个月前——你们人类可能还感觉不到，但我能尝出来，水里的离子浓度变了。灵气重新渗出来了，很慢很慢地，从地底深处往上冒。"

"从哪开始？"

"说不准。好像到处都在冒。"锦鲤停了一下，"南边多一点，北边少一点。城市里少，山里多。你感觉不到吗？"

"感觉到了。"林牧说，"只是很稀。"

"会越来越浓的。"锦鲤的语气忽然变得严肃了一些。"我见过一次——你们人类的说法，大概是五千年前，灵气也曾经复苏过一阵子。那一次只持续了不到百年，但留下的东西不少。你们的历史书上那些神话，什么女娲伏羲、大禹治水，大半都是那一次留下来的印记。"

五千年前。林牧在心里算了一下。那是在他前世之前很久很久了。他前世修行于大约一千五百年前，那时候灵气虽然已经比远古稀薄了很多，但至少还足够支撑一个人从淬体修到合道。然后在他渡劫失败之后的一千多年里，灵气似乎在持续衰减，直到最近才又开始回升。

"这次会持续多久？"他问。

"不知道。"锦鲤说，"但封印已经开了。有一个很大的封印——不止一个——在很久以前被布下的，用来锁住地脉深处的灵气。那些封印现在在碎。"

"谁布的封印？"

"不记得了。"锦鲤的声音忽然变得很轻，像一个老人努力回忆年轻时的事却怎么也记不起来。"河灵没有完整的记忆。我的意识散在太多的水里，每一段只知道零碎的片段。我只记得那些封印存在过，但谁布下的、为什么布下的，我记不清了。"

林牧没有追问。他知道河灵没有骗他——这种古老而分散的灵体，记忆本来就是碎片状的，像一面被打碎的镜子，每一片都只能反射出一小部分真相。

"你有什么打算？"他问。

"我？"锦鲤忽然笑了一下——如果他是一条有表情的鱼，那大概是一个无奈的苦笑。"我在这个鱼缸里待了三年，已经习惯了。水每天都有人换，鱼食虽然有时候没人喂，但总归饿不死。你们人类变强以后，可能第一个杀掉的就是我这种异类吧。"

林牧沉默了一下，然后说："不会。"

这两个字他说得很淡，但锦鲤听出了其中的分量。那不是一个安慰，不是一个敷衍的承诺，而是一个经历了太多的人对另一个活了太久的存在的理解。

"在你变强之前，"锦鲤说，"低调一点。外面的世界很大，什么都在醒。醒来的不只是灵气。"

"还有什么？"

"什么都有。"锦鲤的声音忽然变得很低，低到几乎要消失在水的波动里。"山里的，水里的，地下的。好的，坏的，不好不坏的。你们人类叫它们妖怪、仙人、鬼——都不准确。它们只是——回来。"

林牧握着杯子，看着鱼缸里缓缓游动的锦鲤。茶水间的日光灯管发出细微的电流声，窗外是一座钢筋水泥的城市，车水马龙，人来人往。

而在这个不起眼的角落，一条鱼正在告诉他：神话要回来了。

"谢谢。"他说。

"不客气。"锦鲤说，"毕竟你是我在这个时代遇到的第一个听得懂我说话的人。"

林牧端着杯子准备走，锦鲤的声音又追了上来。

"林牧。"

他停住脚步。他没有告诉这条鱼自己的名字——但河灵大概是从同事们的对话里听来的。

"小心。"锦鲤说，"那些封印，不是自然碎的。"

"什么意思？"

"意思是有人在很久以前，留了一道后门。"

锦鲤说完这句话就不再开口了，缓缓游到了鱼缸的另一端，缩进人造假山的阴影里，重新变成一条普通的、安静的锦鲤。

林牧在茶水间门口站了几秒钟，然后推门走了出去。

茶水间外面就是开放办公区。坐在前排的苏晚正靠在转椅上喝一杯咖啡，目光低垂看着手机，没有注意到他路过。她的侧脸在下午的光线里显得很安静，碎发落在耳朵前面，随着空调的风轻轻晃动。

林牧走回工位，放下杯子，在电脑前坐了一会儿。

有人留下一道后门。

他不知道河灵说的具体是什么人，也不知道那个"后门"到底通向哪里。但以他对古修行界的了解，凡是涉及封印的事，背后一定有某个极为庞大的布局。封印地脉灵气不是一两个元婴修士能做到的事——那需要至少合道级别的人联手，甚至可能需要真仙出手。

而留下后门，意味着布下封印的人，早就知道有朝一日封印会需要打开。

五千年前就有人在为今天做准备了。

林牧按了一下键盘，屏幕从待机中亮起来。他打开一个空白文档，开始写今天的工作日志，手指在键盘上匀速敲击，发出的声音和往常一模一样。

但他的另一只手在桌下，捏了一个很简单的寻灵诀。

灵气从他的指尖散出去，像一圈看不见的涟漪，以他的工位为中心向四周扩散。半径五米之内，他感觉到了：地毯缝隙里微弱的潮气，同事咖啡杯里液体的波动，窗外飘进来的灰尘——以及，一个极其隐秘、极其微弱、但确实存在的，某种古老力量的痕迹。

就在茶水间的方向。

不是那条锦鲤的。是另一种东西。更老，更深，被封在那只鱼缸的底部，或者墙体的深处，或者——那座假山的水底。

他收回寻灵诀，把最后几行工作日志写完，点了保存。

然后他在心里列了一张表。

第一，每天继续引气练功。第二，查清楚那个封印的"后门"是什么。第三——他看着屏幕右下角的时间，十七点五十八分——把今天的代码提交上去，别让项目经理发现他在摸鱼。

窗外夕阳把整座城市染成了橘红色。

就在这座城市的地下，在谁也看不见的深处，有一个非常古老的阵法正在缓慢地褪去最后一层封印。那个阵法已经运转了五千年，消耗了无数代人的灵气，终于在这一刻走到了尽头。

而在鱼缸里，那条被河灵寄居的锦鲤，安静地吐了一个泡泡。

泡泡浮到水面，无声地碎了。

林牧下班时特意绕到茶水间门口往里看了一眼。鱼缸里的灯已经关了，锦鲤在昏暗的水中缓慢游动，看到他的时候，尾巴轻轻甩了一下，像是在和他打招呼。

他没有再进去。有些对话需要时间沉淀。河灵告诉他的信息量太大了——封印、后门、五千年前的布局——他需要先消化一阵子才能继续追问。

地铁上，他靠着车窗，脑子里反复回放锦鲤说的最后那句话："有人在很久以前，留了一道后门。"

一道后门。

前世的修仙界里，封印术是一门极为高深的学问。施展封印需要至少三个条件：足够的修为、精密的阵法知识、以及对被封印对象的透彻理解。而封印地脉灵气——那已经不是封印一个目标的问题了，是封印整个星球的地脉循环系统。规模之大、难度之高，在他前世所有的记忆里都找不到先例。

能布下这种封印的人，至少是合道巅峰，甚至可能是真仙。

而能在封印上留下"后门"的人——要么是布下封印的人本人，要么需要一个水平不低于布封者的阵法师花费极长的时间在封印结构中找到可被修改的缝隙。

无论哪一种，都意味着在那个遥远的上古时代，就有一批人对五千年后的今天做出了预设。

他们知道灵气会被封住。他们知道封不住。他们知道这扇门迟早会再打开。

林牧忽然觉得后背有点凉。

不是空调太冷。是一种更深的、穿越时间尺度的寒意——有人在一个他连想象都无法企及的年代，就已经为他现在所经历的一切写好了剧本。而他完全不知道那个人的目的。

车子到站了。他走出地铁站，六月的晚风吹在脸上，湿热中带着一点温度渐退的凉意。小区门口的花坛边，橘猫正在用爪子在地上写字。今天写的是"晚饭"和"鱼"，旁边还画了一条歪歪扭扭的鱼的简笔画。

林牧走过去，看了一眼那条简笔画。

"鱼画得不错。"

橘猫抬起头，琥珀色的眼睛里闪过一丝近似得意的光——然后低下头继续写它的下一个字。

林牧上楼，打开门，把包扔在沙发上，在客厅中央坐下来。

丹田里的灵气在黑暗中小幅跳动着，像在等他给出下一个指令。窗外的月亮已经从东边升了起来，银白色的光穿过窗帘的缝隙落在地板上。远处的城市灯火通明，车流声、人声、空调外机声交织在一起。

而在地下的深处，那个古老的阵法正在无声地瓦解。

林牧闭上眼睛，开始了今晚的第一轮修炼。

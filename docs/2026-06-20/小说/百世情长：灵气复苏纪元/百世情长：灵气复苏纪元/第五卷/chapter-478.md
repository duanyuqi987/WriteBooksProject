# 第四百七十八章 开庭之日

因果审判大厅比林牧预想的要安静得多。

不是那种法庭的严肃——是另一种。整座审判大厅是圆形的，墙壁由因果天平碎片化成的净土玉砌成。玉面上流淌着缓慢的金色因果纹路。天花板被改造成了一座完全透明的穹顶——五轮太阳的光从不同角度射下来，在圆形的厅中心投下五道交叉的光束。光束的交汇点——审判台——一个由纯白因果石砌成的圆形高台，台上摆着那架天平。天平上已经放着那卷以苏晚签名封印的控诉卷轴。

主审法官是因果审判使——名字叫素问真人。她以极老极老的资历著称仙界——据说她本人的年龄已经超过了仙庭一些低阶司的内部年表的总和。她的眼睛不是正常人的形状——是一对纯粹由因果纹路构成的光圈，每转一圈就能看穿被审判者灵魂中的一个细节。她坐下时，整座大厅的因果之光同时收敛在她的周身——然后重新向外扩散。审判开始。

控告方——林牧。苏晚。二人站在天平左侧的台前。

被告方——卫无渊。他来了。

从林牧第一次听到"卫无渊"这个名字到此刻在法庭上亲眼见到他本人——中间过去了一万年和三辈子的不同身份。卫无渊看着和林牧记忆中一模一样——身穿青金色天雷袍，袍上的雷纹是他自己炼化出来的天阶法器，每一道纹路都是活的，袍摆上有细微的电光在窜动。他的身高极高，肩膀极宽。和他手下发布在各地的通缉令中那个冷厉的形象不一样——走进法庭时的卫无渊面带微笑。那种微笑不是傲慢、不是轻蔑，是更从容的一种：一个在正义化身这个位置上待了九万年的人，早就学会了在一切场合展露出恰到好处的平静。

被告在右侧台前。在他身边站着两位副庭使者——一左一右替他摆了极简的石制座位。卫无渊没有坐。他站在那里以仙庭标准的行礼姿势向素问真人抱了一下拳。然后看向林牧。林牧看向他。两个人的目光在空中互碰的那一瞬间——不是雷电地震那种外显碰撞，而是一种极细极密的因果之线在两人灵核之间被重新绷紧。一万年前他是施法者，林牧是受害者。一万年后反过来了——受害人有了控诉权。线的方向变了。

素问真人打开封卷。她以因果瞳看了一眼卷轴内记载的证据——纪事、灵核频率提取记录、禁档摘录——每一条都有效，没有瑕疵。她点了一下头。然后她做了在仙庭审判史上极端少见的一个动作：她把卷轴还放在天平上——开始以因果之律的第一条最基本原则"先问被告"向卫无渊提问。不是先问原告。这是有深意的。她是在给卫无渊一个机会——一个在他被控方证据压垮之前，自己主动承认或解释的机会。

"被告卫无渊——万年前你以仙庭天雷正君身份施放九霄灭仙雷——将青云宗真仙从灵核精准锁定后截杀。这是事实吗？"

"是事实。"卫无渊答得非常坦率。没有否认。没有辩解。这一瞬间整个审判大厅里所有旁听席上的仙人都同时愣了一下——包括戴着银丝眼镜的女仙官。

"你承认你施放了禁法——截杀真仙？"

"承认。但——"卫无渊把那两个字后面的转折接得很稳，"不是私刑。是奉命执行。"

素问真人的瞳孔——因果光圈——在缓缓扩流转中停了一下。"奉谁的命？"

"仙庭灭宗令。"卫无渊从自己的空间戒中取出了一件东西——一件和林牧在回溯阵中看到的一模一样的——"天道玄晶"。上面刻着仙帝先代印签的"仙庭灭宗令"正式原件。他将玄晶以灵气推送到审判台前。素问真人用因果瞳扫了一遍——令上面的每一个字、每一个灵力指纹、每一道时间烙印——全是真的。"仙庭灭宗令由当时的仙帝授权——要求对不受仙庭管制的'散修宗派'实施灵魂清洗。我是天罚的执行者。执行令不是我发出来的。我只是——听令行事。"

审判大厅里安静得像被抽空了所有空气。这份仙帝签发的灭宗令原件一旦在法庭上亮相——卫无渊确实把罪责由自己转付到早就已经去世的前代仙帝身上。"奉命行事"这个辩护在仙庭因果律中是极其强力的——因为下级执行者在履行合法命令时，即使命令内容违法——主要责任也不在执行者，而在发布命令的主权人。而那个主权人——前代仙帝——早已在数万年前进入了轮回。无法追究。

苏晚看了一眼林牧。林牧的表情依然平静——这种转折他一定在开庭前就已经料到了。

"素问真人。"林牧站起来，声音不大但在安静的大厅里极其清晰。"被告说'奉命执行'——这点我不反驳。前代仙帝的命令是真实的。但我以原告身份补充一件事实——请因果天平调取命令原件中的时间线条，和我的道侣被灭仙雷击中碎魂的时间作对比。"

天平散发出一道金色光幕。光幕上出现了两条时间线——一条是命令发布日期，另一条是九霄灭仙雷降下日期——错开了。命令发布日期在前，灭仙雷后期执行可以在若干期限内完成。这本不能挑出什么毛病。但林牧在光幕上又点了第三条时间线——那是白衣女子（苏晚的前世灵魂）被纳入轮回通道的精确时间。

"这个时间点——距离命令发布日期过了预定期限。命令规定——灭宗令的执行需在发布后若干时限内完成。而卫无渊对我的袭杀——是在时限的最后一天进行的。这说明他在截止前有足够长的时间向上级提出疑问。他没有——他在限期最后一刹才行动。他的拖延不是因为不想杀人——而是他在等我的道侣出关。他故意拖延到了时限的最后一天——这样她的名字也会因为被列入'连带灭杀的无辜者'但受限于期限导致抗诉失效。"

苏晚的手指在剑柄上无声地收紧了。他等的不是机会——是她。是等她出关。好让她也死在雷下。以"附带连带"的名义。这是故意的。

"故意拖延执行时限以获得附带连带杀害——在仙庭因果律八十一条中属于'恶意扩大执行范围'。"林牧说。他看着卫无渊——卫无渊那微笑着的正义面具上第一次出现了一道极细微的裂痕。

（第四百七十八章 完）

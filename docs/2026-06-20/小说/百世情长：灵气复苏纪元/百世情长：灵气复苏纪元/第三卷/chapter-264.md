# 第264章 他在轮回守护部的工作

林牧在轮回守护部的声誉已经远超出他的职级。虽然他只是新晋真仙，但他在凡间两百多年练就的灵魂感应灵敏度和守护经验，让许多比他级别更高的仙官都自愧不如。守护部长是一位在仙界工作近万年的资深老仙叫"云枢真人"——性格豁达，乐于提拔真正有能力的新人。

云枢很快发现林牧在"判断转世者是否需要帮助"以及"如何最小干预地提供有效守护"方面有着别人无法替代的经验——这种经验不是书本上学得来的，是实打实用两百多年孤独坚守换来的。他安排林牧担任了部门新进守护者的带教导师——这是部门中罕见的荣耀——通常只有万年仙官级别的人才会担任导师。

林牧的第一堂培训课上并没有讲授高深的仙界秘法——他把新进守护者们带到了仙界的模拟轮回演练场——一个可以重现凡间各种战斗和灾祸场景的灵阵空间。他在空间里重新构建了第四世的秦岭战场——再现了那个她险些被金丹散修掌压逼杀的缺口。他对受训者们说:"守护者的第一原则——不是你有多强。而是你必须在被守护者最危险的那一刻——准确地出现在她的缺口位置。不需要提前——但如果晚了——守护就毫无意义。问题在于——你怎么在不知道她会往哪儿冲的情况下——提前预判到她最危险的那个缺口？"

他给出的答案是他在两百多年中总结出的"灵魂运动模型"——每个被守护者的灵力活动都有特定的预兆模式——可以通过感应线捕捉到并提前推断。他在演练场上演示了这套模型的操作——用精确到每一次被保护对象冲前冲锋角度前身位偏移的推演——把受训者必须练到耳朵能直接通灵的肌肉记忆程度。这技能的练习方法从他在秦岭用灵识监控苏晚每一次战斗中炼出来的——几十次战场预判使他能从侧面微末信息推断她的下一步路线——是技术和情感在同一频率上共同跑出的最优算法。

他对受训者们说:"守护的核心——不是在她每次掉下时接住她。是让她的每一次前冲都不必分心——因为她知道后方有人在看。让她把全部注意力用来做她自己——这个才叫守护。在她冲进火海之前给她一块能护住心肺的灵布——而不是在她烧伤了再扛去医院——这叫'前置守护'。你对她生命周期的理解越强——你的前置判断就越好——她也就走得越安全。"

课后一位女性真仙守护者——她自己曾在凡间守护过一位无法突破轮回锁的转世者——单独找他问问题。她的眼睛红了——因为她的被守护者在她的监护下走丢了灵魂，再也没有转世回来。她问林牧:"怎么能承受她每一世都在死——而你始终是剩下的那个人？"

林牧沉默了一会儿——然后把他储物袋里那十条剑穗一一取出来——摆在她面前的桌上:"每一根她都编了同一个平安结——但她编的时候并知道。你问'承受'——我其实没有承受。我只是每次把她留在坟前的物件拿起来——编进下一段等待的开头和我的茶盒——等下一世她再给我编一样的东西。不是承受——是接力:替每一世的她把这条线插进下一个接头——然后有一天你发现——线已经绕了好多圈——而且最近的一圈你不必再等——因为她正握着线另一头——在你房里烧穿茶壶。所以'守护的人先死于灵魂损耗'是一个误区——正确的守护者在每一段死后从自己守护的对象留给他的物件中重新汲取下一段的起点。她留了——你只需接下来好好放着——并准时出现在下一次缺口。"

女修把他的话听完后没有马上回话——她从怀里摸出一枚旧铜簪——是她那位走失的转世者三辈子前戴过的唯一东西——她把它重新插回自己发间——对林牧说:"谢谢你——守护不结束——只要你还替她收着——就还没有真的断。"

林牧看着她插簪的动作——和几百年前苏晚把她母亲的耳环戴在自己耳朵上的动作是一样的——都是用继续携带来对抗失落——他微微点头——没有再说。

年底轮回守护部汇总年度表彰名单——林牧作为唯一一名入职不到百年就被列入"最优守护导师"名单的新晋真仙——在部门年鉴上的表彰语是:"他以凡间两百多年孤独守护的亲历实践为基础，重新定义了轮回守护伦理准则，将'守护'从被动救援更新为'前置守护+独立空间预留'的复合模型。为部门贡献了极为珍贵的实践哲学——并将持续为新世代守护者提供支撑。"

他把奖状放进苏晚神龛第四个格子——那是他每次回来看这个神龛时那个"她的守护者在世间得到的认可"也放在内——作为对她每次说"你守护我没有回报"的无言反驳。他自己做完这件事后在下面加了张小纸条——上面写着:"你用五百年证实了你靠自己可以完成一切——但我在旁边让你慢慢飞。这是个——团队合作的特等奖——一人一半。"

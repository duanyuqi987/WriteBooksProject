# 第107章 李长生出手，以冥术反制数字攻击

小王把GhostEye的代码写完的时候，天已经亮了。

但他面临一个问题。GhostEye虽然能反追踪扫描源，可它的攻击方式仍然是代码层面的——它可以在数据流上做反向标记，可以把攻击者的地址路径暴露出来，可以往对手的服务器注入混淆数据。但它无法做到一件事:直接让攻击服务器瘫痪。

因为玄清宗的数据中心不是普通的机房。它的核心服务器采用了灵能供电——把灵脉作为能源直接驱动计算单元。普通的DDoS攻击对它没用——它不是靠电来跑的。普通的病毒也解决不了——玄清宗的灵符程序员在系统中内嵌了灵符防火墙，任何代码木马在进入系统的时候都会被灵符自动验证和校验。

要用代码打败玄清宗——必须有代码之外的东西。

小王把GhostEye部署完之后，靠在椅子上看着天花板。他想了十五分钟，然后说了一句话:

"我需要你的冥气。"

李长生一直在旁边看着。他不懂代码，但他懂一件事——冥气是所有灵气的对立面。它能侵蚀、腐蚀、分解其他属性的灵气。如果数字信号在服务器之间的传输可以被冥气干扰，那他就可以从物理层面"杀死"对方的服务器——不是破坏硬件，而是让数据流传输介质本身的灵气层失效。

"怎么给你？"

"不是给我。是给服务器。"小王坐直了，"玄清宗的主数据中心肯定和灵脉直接相连。如果你能通过我的灵符代码通道，把你的冥气注入到他们的灵脉连接点——冥气就会顺着灵脉反涌进他们的服务器。他们的灵符防火墙防不住冥气的——因为灵符本身也是灵气驱动的。冥气碰灵符，就像墨水碰清水。"

这个思路之前没有人试过。甚至没有人想过——因为没有人能在代码里把灵气的流向数字化。而小王正好做了这件事——他之前开发的灵符解释器可以把灵符翻译成代码逻辑，反过来——也可以把代码逻辑编码成灵气指令。

如果李长生的冥气可以被编码成数字指令——那他就可以从任何一个联网终端上远程发射冥气攻击。

"试一次。"李长生说。

小王在笔记本上打开了两个系统。左边是灵符解释器——负责把冥气的灵气特征转化为一段可执行的数据包——本质上是一段加密过的TCP/IP帧，但帧的有效载荷里包含的不是普通数据，而是被编码过的冥气灵气波形的数字化描述。右边是发射终端——一台被他改装过的手机主板，主板上焊了一块灵石做能源核心，灵石的旁边是六根细如发丝的金属探针，每根探针都精确地对准了灵石的不同晶面。

当这段冥气数据包被发送到发射终端上时，终端上的金属探针会用微弱的电流脉冲刺激灵石的六个晶面，产生一组特定的灵气波形。这组波形——在物理空间中——就是一道微小的冥气脉冲。

"原理很简单。"小王说，"就像扬声器把数字音频转成声波。我把冥气模型编译成灵气'音频'，然后探针把数字信号转化为灵气输出。只不过这组'音频'的频率不在可听范围内——它在灵气的频率段上。"

"那反过来呢？"李长生问，"怎么送到对方的服务器上？"

小王切换了一个界面。那是他之前通过GhostEye反向渗透玄清宗数据中心得到的一个低权限接口——不是系统提权的入口，只是一个公开的、为公共灵眼APP提供验证服务的端口。但这个端口有一条不成文的安全缺陷:它在验证数据包格式的时候，不会检查数据包内载的非验证字段的内容。也就是说——任何数据包只要外层套了一个合法的验证头，里面的东西不管是什么都能通过。

"我把冥气数据包封装成一个标准的验证请求，送到这个端口。端口会自动把它转发到后台服务器。后台服务器的灵符防火墙在看到这个数据包的时候，会先校验它的外层验证头——验证通过。然后防火墙会打开内层载荷，开始解析里面是什么。"

"然后？"

"然后——它解析出的是冥气。不是数据。是灵气。被编码成数据的灵气。一旦解析完成——服务器会把这段'音频'放到它的灵能供电总线上执行。就像电脑打开了一个WAV文件然后播放。"

李长生听懂了。这两个人在一起最可怕的地方是——小王懂技术，李长生懂冥气。小王造了一把能用数字信号发射冥气脉冲的"枪"。而李长生是这把枪的弹药。

"开始。"

小王把笔记本的前置摄像头拆下来，改装成了一段短距离的灵能流检测器。这个检测器能通过在摄像头感光元件表面贴上的灵符薄膜，把李长生掌心中输出的冥气波形拍摄下来，转化为数字波形数据。

李长生伸出手。掌心三道冥纹亮了起来。他没有刻意释放冥气——只是让它自然地从冥纹中溢出。那股暗黑色的灵气从掌心渗出，在空气里形成了一层肉眼几乎看不见的薄雾。薄雾不是固定的——它在流动，在围着他的手指缓慢地旋转。如果把视线聚焦在其中一缕冥气上，会发现它不是气体，而是像液体一样粘稠，有重量感。

"这是最稀薄的冥气。"李长生说，"纯度高的话——你这台手机主板可能直接烧了。"

小王没有接话。他盯着屏幕上那个灵能流检测器传来的波形。那是一条几乎不波动的水平线——冥气的电磁签名和其他所有灵气都不一样，它没有明显的震荡峰，能量集中在极低频段，曲线平滑得像是死去的海面。

他把这段波形通过灵符解释器编译成数据包。数据包的长度是187字节。作为一个TCP/IP包，这已经非常小了。但这187个字节里包含的信息精度，可以满足灵符解释器在另一端还原出冥气波形。

"发射。"小王按下了回车。

发射终端上的六根金属探针同时产生了一道微弱的电流脉冲。灵石晶面上被激发的亮度从淡蓝变成暗紫——只是一瞬间的事，持续了大概零点三秒。在这一瞬间，一道极微弱的冥气脉冲从灵石上发射出去，穿过发射终端的外壳，汇入了房间的空气。

"空气里检测到了。"小王看着灵能流检测器的读数，"距发射端30厘米处的冥气浓度:0.7灵素。太弱了——但这只是本地测试。接下来需要通过网络传——"

他停了。因为他看到笔记本屏幕上的监控面板弹出了一条新日志:

"Target server response: Unknown data format. Payload rejected. Firewall triggered: True. Intrusion detected: True."

被发现了。

但这个结果是预期的。小王一开始就没打算用冥气数据包直接穿透防火墙——他只是想测试一件事:冥气被编码为数据包之后，能不能通过网络传送到另一个物理位置并在那里被还原为物理空间的冥气。这个测试需要两个条件都成立:第一，数据包在网络传输中不能丢失关键的波形信息；第二，接收端的灵能供电总线必须成功把数字信号还原为冥气。

"日志里有还原结果吗？"

小王往下翻了几行。然后他看到了——接收端日志显示:"Received payload waveform analysis: Spike detected at 0.004 Hz. Energy signature: unknown. Protocol match: null."

0.004赫兹。冥气的频率。

传输成功了。数据包通过玄清宗的验证端口送到了服务器后台，后台的灵符防火墙虽然拦截了它，但在拦截之前——防火墙的解析器已经把它还原成了冥气波形。解析器读完的那一瞬间，冥气在防火墙的灵能总线上炸开了一瞬间。那一瞬间极短——零点三秒。但足够了。

因为冥气的性质是腐蚀性。即使是最稀薄的冥气，在接触到以普通灵气为能源的系统时，所造成的干扰也是不可逆的——就像一滴酸性墨水滴进一大缸清水，水不会被全部污染，但那一滴墨水是再也弄不出来了。

小王的监控面板显示，在冥气数据包被拦截之后的五分钟里，玄清宗防火墙的响应速度从平均八毫秒降到了六百毫秒。这不是DDoS攻击造成的拥堵——是被冥气污染之后，防火墙内部对灵气流的信号清洗时间被极大拉长了。每一个需要灵符校验的数据包现在都要在防火墙里多走一段"净化"流程。而玄清宗的灵符防火墙在设计的时候根本没有考虑到"内源性灵气污染"这种攻击方式。

"它不会坏掉。"小王说，"只是变慢了。但慢到一定程度——整个数据中心的数据吞吐都会受影响。"

"那就够了。"李长生把掌心摊开。三道冥纹中渗出了一股比刚才浓了至少十倍的冥气。暗黑色的气流在空气中缓慢地打旋，整个房间的温度在这一瞬间似乎降低了一两度——不是冬天的冷，而是冥气特有的那种"死静"，像是所有生物的气息都被这股气给压住了。

"这次浓度多少？"

"七个灵素。"小王盯着灵能流检测器，"是上一次的十倍。"

"再来一次。不要只发一个——发一组。"

"一组多少个？"

"我先配二十个。二十个冥气数据包，不同的频率、不同的波形。玄清宗的防火墙发现第一个之后会自动阻断同类攻击——但如果每个攻击都不一样，它的自动阻断就追不上。"

小王飞快地把李长生新产生的冥气波形做了采样——这次的波形比之前复杂得多，因为冥气浓度高了十倍之后，波形里多了一个低频震荡峰，频率在0.002赫兹左右。小王把这个震荡峰单独提取出来做成了一个副载波——也就是说，每个冥气数据包里现在包含了两层波形:主波形负责污染，副载波负责干扰防火墙的波形识别系统。

然后他把攻击序列设定为"半随机"，每隔一秒发射一个数据包，持续二十分钟。共一千二百个。

"开始。"

发射终端上的灵石开始持续闪烁。暗紫色的光芒在金属探针的尖端跳动——每一秒跳动一次。笔记本屏幕上的监控面板上，玄清宗防火墙的响应速度曲线从六百毫秒开始缓慢攀升——八百毫秒、一千二百毫秒、两千毫秒——然后在攻击序列持续到第八分钟的时候，防火墙的超时计数器达到阈值。

面板上弹出了一行红字:

"Target firewall: Connection timed out. Retry attempt: Failed. Status: Degraded."

防火墙进入了降级模式。在降级模式下，防火墙失去了对数据包内容的解析能力——只能做最简单的IP来源校验。这意味着玄清宗数据中心对外暴露的每一个端口现在都处于"低防御"状态。

但这还不够。

小王切换到GhostEye的面板。GhostEye之前在玄清宗的数据流中被注入了混淆数据——虚拟的灵气特征向量。现在因为防火墙降级，混淆数据的注入效率瞬间提高了。GhostEye的反向追踪模块同时开始工作——它捕捉到玄清宗数据中心正在以极低速率向外部发送查询请求，而GhostEye的追踪器顺着这些查询请求一层一层回溯，在监控面板上绘制出了一张清晰的地图。

地图上标着六个红点。六个红点分别位于六个城市的坐标上。每一个红点都是玄清宗数据中心的物理代理节点——不是IP，而是实实在在的物理服务器。它们分布在郑州、济南、西安、武汉、合肥和北京。它们之前伪装在各式各样的外人不可察觉的IDC机房深处，但GhostEye顺着数据流反向追踪，一个一个把它们挖了出来。

"六个节点。"小王说，"每个节点的物理位置已经拿到了。你要怎么处理？"

李长生没有回答。他把手掌按在了小王的发射终端上，三道冥纹同时爆亮。暗金色的光芒从掌心涌出来，穿过了发射终端的金属外壳，直接注入了那颗核心灵石。灵石的颜色从淡蓝色变成了彻底的黑色——不是墨水黑，而是一种极度深邃的、像是无底深井般的黑色。

这一次他注入的不是普通的冥气——是冥王碎片中的本源冥气。那种万年前来自冥王令的力量。

小王看着屏幕上发射终端的状态指示器。发射功率正在跳升——从毫瓦级跳到了瓦级。这意味着远程射出的冥气脉冲强度将提高好几倍。

"这个浓度——如果送到防火墙，它的灵能供电总线可能直接——"

"烧掉。"李长生说。

（第107章完）

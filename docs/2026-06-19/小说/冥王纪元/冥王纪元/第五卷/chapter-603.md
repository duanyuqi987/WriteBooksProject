# 第603章 如果混沌之主复苏

回到诸天号后，李长生立即将第一块混沌碎片带到了核心实验室。

林晓负责碎片的生理影响分析，小王负责碎片的能量测绘，龟相负责解读碎片中蕴含的远古混沌文字信息。而李长生本人——他负责回答所有人最关心的问题：如果混沌之主真的复苏了，会发生什么？

"我看到了碎片里的第一段记忆。"他在核心会议上说，"不是混沌之主的记忆——他已经被碎片的分离过程毁掉了完整记忆。我看到的记忆是碎片被封印之前的最后一段体验。"

"那它体验到了什么？"林晓问。

"孤独。"

这是一个意想不到的回答。

"这块碎片——拳头大小的一块——在被分裂出去之后产生了某种原始的意识。它的意识不是混沌之主那种统驭万有的智慧。它更像是一种基础的感官：它感知到自己被从整体上撕裂了下来，落到了一个什么都没有的虚空维度中，没有任何其他碎片在身边。"

"它试着复合。它会发出一种我无法形容的召唤信号——这种信号有微弱的能力牵引附近的碎片。但它被那层封印罩住了，信号出不去。它就那样被罩了十亿年。"

会议室里安静了下来。

"一块有感情的混沌碎片。"陈霜轻声说。

"不是感情。是存在感。"李长生说，"混沌之主被撕裂的时候——他的意识没有被毁灭，而是被稀释到了一千块碎片中。每一块碎片都保留了混沌意识的一小部分。单独一块碎片只有模糊感应，就像你把手放进冰箱里只能用皮肤感受温度，而无法看到冰。但一旦碎片被逐渐聚合——那种模糊的感受就会变得清晰。直到超过某个阈值，模糊感应变成了意识。"

"阈值是多少？"小王问。

"不知道。但壁画上说的那句话：混沌之主未死，只是被分拆。这意味着只要足够多的碎片聚合，混沌之主就能在意识层面复苏。"

"那他的力量呢？"

"如果他的力量也随着意识复苏了..."李长生顿了顿，"那他可能会直接重塑整个多元宇宙的基本规则。"

老陈忍不住站了起来。"重塑宇宙规则？那我们现在的一切——帝国、理事会、联合法典——"

"可能会被覆盖。"李长生坦率得近乎残酷，"混沌之主不是一般的修士。他是混沌本身的意志具现。他的存在就是规则本身。正如引力不是被创立的——引力仅仅在于质量存在的本质中就潜含着引力。混沌之主对秩序的裁定，等同于自然的自我选择。"

没有人说话。

"但碎片不是混沌之主的复活。"李长生说，"它们只是一千个个存在感的载体。它们不带有混沌之主的意志——他的意志在被分裂的过程中被剥离了。碎片聚合能唤醒一个意识体，但这个意识体是什么态度、什么目的、善还是恶——没人知道。"

"那你还找碎片？"刀疤说出了心里话。

"因为不找不行。"李长生说，"我突破混沌级时融合的那块碎片，是所有一千块碎片中最特殊的一块。壁画上标注了——它是混沌之主被撕裂瞬间的自我保全的碎片。它在碎片散射之前自己跳到了一个特殊的路径上，九亿九千万年后进入了地球的地质层，又在一万年前融入了地球的灵气地层，五年前被我在祖坟旁挖了出来。"

"你是说..."小王推了推眼镜，"你小时候种地时在地上捡到的冥王碎片..."

"那不是冥王的工具碎片。"李长生将冥王令放在桌上，"这是一块混沌之主的碎片。冥王只是在一万年前捡到了它，把它纳为自己的本命法器的核心。而它之所以会在那里，是因为这块碎片在十亿年前就知道——终有一天它会需要一个能持有它的人。一个能在它复苏之前收容其他碎片的人。"

整个会议室都安静了。

"这块碎片在利用我。"李长生说，"在十亿年前，混沌之主被撕裂前的一瞬，在所有碎片即将散落之前，混沌之主用自己最后的意识对这块碎片做了一个特殊化处理——他在其中留下了收集自己的记忆指令。它是一切的起点。它就是'收集链条'的第一环。而我在祖坟边捡到它之后——我修炼的每一步、每一次突破——都是在循着他留下来的路径前进。"

陈霜握住了李长生的手。她没有说话。她知道这种情况下任何话语都多余。

"但我不是混沌之主的傀儡。"李长生说，"我的选择权还在。我可以拒绝继续找碎片——但那样我就对混沌之主下一阶段的强行聚合毫无准备。目前碎片在宇宙中至少还有一半以上没有落定——它们在哪、被谁捡到了、又或者它们周围产生了什么附属物——这些都是我不能预先掌控的。"

"所以我有的唯一选择是——继续收集。在任何人发现碎片的真相之前，在我能集齐到的范围内尽快收集所有能收集到的碎片。"

他站起来，看向会议桌上的所有人。

"不是我需要混沌碎片。是整个多元宇宙需要一个能对混沌之主负责的人。"

（第603章完）

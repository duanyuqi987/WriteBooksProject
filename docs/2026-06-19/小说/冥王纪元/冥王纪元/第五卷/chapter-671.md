# 第671章 番外：多元宇宙理事会的历史档案

旧纪元减速启动前六个月，多元宇宙理事会在银河系中央会议大厅召开了最后一次例会。这是宇宙联盟旗下最高级别的日常议事机构——成立约四十亿年，经历了一千二百次改选。而这次——是它的最后一次全体大会。

会议室在银河核心巨大恒星环内的人造星体上。那颗星体本身是一颗被掏空的白矮星——密度大到每一立方厘米的物质都重如山脉——但被远古文明从内部挖出一个直径二十公里的球形空腔，用反引力场撑住腔壁。会议大厅就建在空腔中心——一座用完全透明天晶建造的圆形厅。天晶的透明度不是玻璃那种透明——是连暗物质流都能看见的清澈度——从内往外看，能看到整个银河旋臂缓慢转动。旋臂上的星云像被微风拂过的轻纱——新恒星在旋臂内侧成团诞生，老恒星在旋臂外侧集体熄灭——一个完整的生命周期在眼前铺开。

这间会议室的历史档案里记载了从第一个加盟文明加入开始的全部议事记录。最早的一份档案是一块巴掌大的石片刻痕——来自天琴座第一代星际文明，上面用最原始的楔形文字刻着："我族申请加入宇宙联盟——我们学会了用火。"石片旁边就是天琴座后来从"大归还"退盟时的正式通告——用的是全息光刻——措辞冷静到近乎冷漠，但落款处有一滴早已干涸的液痕，档案附注里写着"疑似泪液残留"。再往后是天琴座重新回归时的入盟申请书——用的还是全息光刻——落款只加了一个字："回"。

这面长达三公里的档案墙上，装着从那时起到现在的全部议事记录：无数次重大立法修订——每一次关于宇宙资源分配的争议——每一条被否决又被重新提呈的提案——以及每一次关于"宇宙是否存在边界"的长达千年的辩论记录。所有的记录被装订在无数层叠的纳米打印卷册中——排满了整面高墙——每一卷都有人类臂长那么厚。有些卷册的边缘已经微微泛黄——那是刻意保留的氧化痕迹，让后来者知道这些文字走了多远的路。

最后一次例会的议程全部是关于"档案转移"。多元宇宙理事会决定把全部历史卷册转移到永恒之库。不是送走——是让它们在零点时刻后被接入新宇宙基础信息层——让任何未来的文明都能随时查阅。转出方是旧纪元最后一位轮值主席——一位来自鲸鱼座的老学者——接收方是龟相。

移交仪式没有奏乐——没有仪仗队。整个大厅里只有龟相和轮值主席两个人。

龟相从头到尾一页页办完了完整的移交手续。他在每一份纳米卷册的目录页上用自己的爪印签核——右前爪蘸的不是墨，是一种半永久量子印泥——印在卷册表面后会渗入分子层，形成不可擦除的三维签名。每签一本，他都会停下来核对卷册号、页数、附录清单——偶尔发现页码跳号或装订错位的，他会当场用小前肢把错页挑开、理顺、重新对齐——比档案馆自己的修复员还仔细。

轮值主席是位来自鲸鱼座的老学者——两条前鳍已经老到半透明，能看见里面细密的骨质纹路。他全程站在龟相旁边——没有帮手——自己把每一摞卷册从高墙上取下、放在龟相面前、再等龟相签完、再搬到转移台上。四个小时——三千多卷——两个人一件都没有漏。

全部档案移交完毕的那一刻——轮值主席用非常古老的鲸鱼座礼节向龟相行了一个礼。鲸鱼座的礼节不用嘴说——是用前鳍在身前画一个三层的弧——第一层代表"过去"，第二层代表"信任"，第三层代表"远方"。整套动作极慢——慢到天晶穹顶上的星云旋转都能看出位移。那个礼的意思翻译成人类语言是："把记忆托付给被信任者。"龟相把两只前爪收进壳——壳口微微合拢——行了一个很短的龟式回礼——龟族的回礼不是画弧——是把头伸出来一点点——再缩回去——意思是"收到了——存好了"。

然后龟相慢慢爬出了大厅外。他爬过天晶地板的时候——壳底和晶面轻轻摩擦——发出一种极细微的沙沙声——像老人在晨光里翻旧书页。壳上沾了些微档案页缝间的灰尘——是四十亿年的灰——比普通尘埃重——但龟相没有掸掉。

小王在走道外等他——他推着一个小的物资车——上面放着一台自制的数据缓存柜。那台柜的外壳是用旧服务器拆下来的合金板焊接的——焊缝不齐——但结实。柜门上贴了一张标签纸——用极小的字写着"非正式历史留档——全收——不筛"。

那台柜里装着的不是那些正式的历史卷册——而是这四十亿年来所有被理事会"正式删除"但实际被技术人员悄悄留存的非正式备忘录。多数是各种口角、拼写错误、笔误或被认为是玩笑的涂鸦留言。小王在整理这些文件时发现——每一位技术人员在删除这些"错误"时都做了同样的事：嘴上说删了——手上存了——存的文件夹名叫"杂项"或"不要动"或"系统缓存"——其实哪个都不是。

当中有一次——在遥远不知名的某星系代表无故缺席会议——那页他的缺席说明只写了三个字："请病假"——加了一个连他本族都没见过的小动物爪签。还有一次——两位不同星系的代表在会议记录边缘用各自的母语互相留言了整整二十页——从宇宙常数是否可变辩到了各自祖母的厨艺优劣——辩到最后其中一位写道："我承认我家那边的汤确实不如你们——但面包你们不行。"另一位回："确实。"这两页被当时的正式记录员标记为"无关讨论——删除"——但被一位备份人员工整地存进了一个叫"厨房辩论"的子目录。

有一份来自早已消失的仙女座某次级文明的告别信——他们在退出联盟时提交了一份长达四千字的退盟声明——措辞庄重——最后一页却在页脚用铅笔写了一行小字："我们灯泡坏了——去修——不回来了。"正式档案里这行小字被裁掉了——小王从备份里找到了原件的完整扫描——小字旁边还有一盏歪歪扭扭的手画灯泡。他把这面扫描件放大、去噪、打印、夹进缓存柜第一格的最上面。

还有一页——是四十亿年前第一次理事会例会的签到表。上面只有七个文明签了名。其中第五个签名的墨水和其他六个颜色不一样——偏褐——事后被查明是那位代表用自己的体液签的——因为他们文明还没发明墨水。那滴褐色体液早就干了——但纳米扫描能还原出它最初落在纸面上的形状：不是签名——是一根手指的完整指纹——带着那个文明全员共用的唯一一枚手指的螺旋纹路。

"这些不能丢。"小王说——他把缓存柜推过走廊——运到龟相的转移台旁边——整柜转入了永恒档案库存——柜标签用极敬业的字写："非正式历史留档——全收——不筛。"

走廊上的光廊在当夕最后一次亮起——透过天晶墙壁泻了整层走廊——镜面上最后一次照着被历史记录反打的影穗——它们降成了静默的存档静光。全宇宙的政务——从此让位给万物。

（第671章完）

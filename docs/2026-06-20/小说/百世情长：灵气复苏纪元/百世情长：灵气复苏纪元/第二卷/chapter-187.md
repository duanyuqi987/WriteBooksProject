# 第187章 守在她身边

苏小晚从三岁到十八岁的十五年里，每一天的生活半径都不大。家、学校、林老师的小院、村口的杂货铺、河边的石头——这五个点构成了她全部少年时代的地理标记。在这五个点之间，绕着一个固定的定点——那个拄着竹杖的老人，安静地一直在场。

三岁的时候他在皂荚树下，伸出竹杖让她扶着下台阶。五岁的时候他在河岸上告诉她不要往深水去——石头上有青苔很滑。七岁那年她的洋柿子（她坚持叫洋柿子）在他院子里第一次长成，他教她用袖子垫着摘。九岁那年她因为不愿去学而被他拉去书房蹲了半个下午——他把数学题改成"小猫分鱼"的故事，她听得特别认真，最后把题目全做对了。十一岁那年她穿的裤子膝盖撕了个洞，怕回家挨骂——他找出针线在油灯下帮她缝了，针脚不齐但结实，她第二天穿去学校被同学说"你裤子膝盖怎么鼓个大包"，她回家大声告诉他——他笑说"是老师的针工太差，下次包你好看"。十三岁那年暑假她第一次一个人走路到县城参加绘画比赛——他在不远的后方跟着，没让她知道。她画了一只猫，猫的颜色是橘红色的，得了第三名。回来他把那张奖状裱进一个旧相框，摆在书架上挨着她送他那幅翠鸟画的地方。十五岁那年高中开始住校——每两周回来一次。开学后第一周她半夜在宿舍床上给自己做呼吸练习，感觉自己一个人的手指尖凉凉的，忽然非常想那个小院和猫尾巴。第二天傍晚她打电话给村里的公用电话——苏大山叫林老师接。她听到他那声"小晚吗？"时不知怎么鼻子就酸了，但他只是跟她聊了天气、聊了宿舍的舍友有没有打呼，然后跟她说"呼吸法继续练——别管不练的人说闲话。"她说，好。

他从未错过她的任何一个重要场合。小学毕业典礼，他坐在家长席最后面拿着竹杖。初中开学报到——他陪着苏大山送她到宿舍。初中毕业晚会在学校操场放电影，她坐在后排小板凳上——他拿了张小马扎坐旁边。高中成人礼那天学校要求家长给学生系好毕业绶带。她爸把绶带给她挂上，他在走廊口和她爸聊了两句，然后对她笑了一下。那个瞬间他眼中闪过什么——她没看清，但记住了那个温度。

十五年。五千多个日子。他从她的身高只及他的膝盖看她长到能与他平视。她的头发从又黄又短到柔顺地垂肩扎出马尾。她会笑会哭会跟妈妈撒娇——这些日常在林牧的记忆里全都被标注、记录、备份。每一帧都在他神识空间的某层里形成一套完美的成长投影——从不向外泄漏。每次她遇到难题，他就会从这套投影中调出她的所有行为习惯来预判最佳帮助路径。他对她的了解程度甚至超过了她自己——因为她不会记录自己什么时候容易疲劳、爱吃哪种蔬菜、哪个语气是他表示紧张时的微动作。

有一次她在家翻看初中毕业照——发现她几乎每一张班级合影都没有看镜头的正中间，而是往左边偏。她不知道自己这个"朝左偏脸"的习惯是怎么形成的。林牧却知道:因为从三岁开始给她拍照时他就习惯站在她的左后侧——他的影子偏低的位置。她的脸下意识转向左偏是身体对那个方向的无声响应。

"守在她身边"不仅仅意味着在空间上毗邻。他持续为她改变着身边的环境。每一年油菜花地里最好的蜜蜂采蜜季她就特别快乐——因为这让她想起他那个"哑巴风"的故事。他在山上建了一处隐形的临时禅室，准备等她上高中后在假期中带她来做一个极浅度的淬体体验。但这一切都在精心计算之下进行——确保不惊扰、不压迫她独立的成长路径。

有一天晚上她从学校放寒假回来，看到他独自一人坐在石阶上对着夜色看星，猫在旁边蜷着。她悄悄坐在另一边石阶上。缓声说了句:"老师，谢谢你陪我长大的这些年。"他手里拿着的搪瓷杯子轻微地晃了一下。然后他把杯子放在脚边说:"你还没长大呢。以后还要很长时间。"她忽然用很正经的语气纠正:"我已经十八了。"

他转头看了她一眼。月光打在他两鬓斜翘的白发上。"十八。好。那从明天起，我改叫你苏女士。"她气得拍他胳膊一巴掌:"无聊！"他笑了。月亮在皂荚树的枝桠间跟着晃了两下。那个和月色同行的老人守护完这个孩子前十八年。下一段——他要开始引导她走向自己的第一个修炼选择。但他今天先守着这个月光。让它把这个夜晚和她刚才那句"谢谢你"同时存档到永远不会被删去的区域。

**作者：段锦佑**

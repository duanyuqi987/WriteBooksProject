# 第八百七十八章 修仙界最伟大的时刻

某一年——没有人特别留意是哪一年——仙界与人间联合绘制了一份《双界文明里程图》。图长数百尺——以光影方式被刻在守门人区牌坊一侧的长廊地砖上，每块砖记载一个重要历史节点。图廊的编制花了许多年。在最终版本中，他们将飞升之门的首日运转记为"新纪元初始日"，而非任何一场战争胜利或哪位仙王登位。

因为在文明的所有改变中，最具深远影响的并非权力更替——而是一扇不被某些人垄断的通道奠基日。在那扇门开启之后文明才真正踏上通彻两界的路径。林牧和苏晚的名字被同时放在图廊序言的末尾——刻的不是头衔，只有"第一代守门人——同笔"。

图廊开放当天，守门人区牌坊面前举行了没有任何仪式的"走路"。所有来参加的人依次沿着长廊走一遍地砖——他们走下去时或唱一支短歌、或放一朵花、或往砖缝扔一粒自己故乡的沙。林牧在众人全部走后独自走了一遍图廊。他在每一块核心地砖上用手按出一个灵力温痕——不是签名，只是温暖它们。然后他走到序言末尾处，在名旁的空隙上用手指轻轻地弯曲了一下——留下一道极细的弧形——仿佛是他对"苏晚"那两个字的微笑。

苏晚没有一起去。不是因为不来——而是因为她在人间的南海渔村正在参加另一个极小的活动：小星子因为修炼没有突破金丹，到了晚年行动不便，但村里为她在星光窗前修了一条老太太专用的木椅走道。这一天是她的八十大寿。苏晚拿了碗她自煮的面走到她面前。老太星子眼睛有点花——盯着她看了半晌，然后忽然笑起来："嘿嘿——粉笔阿姨——还在。"

苏晚蹲下握她皱巴巴的老手。"粉笔我没丢。这碗面——葱花不赖——长寿。"星子吃完大半碗就餍足了——太阳正好晒到她身上。苏晚帮她收了碗，顺便替她在星光窗外用指头在玻璃上画了个极小蝴蝶结。星子老眼湿润但没有哭——只是很开心地说："我小时候就遇见你——画的那个门——现在还在发光。"

苏晚把她推到温暖的阳光下。远处的飞升之门仍在暮色中静静呼吸。或许再过千年星子轮回转世会再次站在门的那头——而守门人或许还会在她新家门口留下一粒小葱丝、一个蝴蝶结。信任不靠约定，而靠这一切日常中的回访与同尊对待所有人的老去。这是一个时代最重大的一刻——不是因为任何雄伟的宣示瞬间，而是因为文明将"陪伴"列为比"登顶"更重要的度量。飞升之门因此成为了最长久、最伟大的人类与仙人共同创作的无声诗。

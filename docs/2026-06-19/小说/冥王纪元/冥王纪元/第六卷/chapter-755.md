# 第755章 预言中，有一个古老的存在在苏醒

太初预言的第四片碎片在三天后自行解锁——那是一片被加锁的预言，太初设定了一个延迟，让李长生有时间消化前面的信息再面对这一片。

这片预言只有一个画面。但那个画面在李长生的识海中持续了整整六个小时。

混沌本体。

不是比喻，不是象征，不是抽象化的能量表达。而是真真切切的混沌本体的本相——或者至少是太初能够理解的、最接近本相的一种翻译。

画面中，在所有维度的交汇点——那个被称为"宇宙中心"但从未被任何修士观测到过的地方——悬浮着一个不可丈量的巨大实体。

它太大了。不是说它比恒星大、比星系大、比宇宙大——这些比较本身就失去了意义。因为它在维度交汇点的内部，不受三维空间的尺度限制。它既是无穷大的，也是无穷小的。它是所有尺度同时存在的产物——你从任何方向看它，它都在你的眼前，都在无穷远处，都在你自己的意识最深处。

它的形态不是固定的。不是球形，不是人形，不是任何可以被几何定义的形式。它在不断地变化着——不是形态在移动，而是形态本身没有"稳定"这个概念。它在你的注视下同一秒内呈现出一百万种不同的轮廓，每一种轮廓持续的时间短到无法被时间测量。它是所有形态的总和，也是所有形态的来源。

冥王令在观看过程中持续发出强烈的暗金光芒。那不是警告——是共鸣。冥王令在识别出混沌本体时，自身被唤醒了最原始的层面。九块碎片的制造材料——也就是冥王令的原初材料——正是在万古纪元末期，由冥王本人从混沌本体的封禁层中采集的一缕被净化的混沌能量。

换句话说，冥王令的"材质"本身就是混沌本体的一部分。

"所以冥王令和混沌本体有共鸣。"李长生在神识中对自己说。这解释了为什么冥王令会对混沌本体的苏醒预兆产生反应——不是因为它在警告危险，而是因为它和它的源头之间存在着某种无法被切断的连接。

画面继续，混沌本体在缓慢地"呼吸"——这不是真正的呼吸，而是宇宙维度的涟漪。每一次吸气，周围所有维度层的能量都会轻微地向它汇聚。每一次呼气，它内部的混沌能量会溢出一点点——仅仅是溢出的一点点就足以在维度夹层中形成数十亿个独立的混沌漩涡。那些混沌漩涡中的任何一个，如果被无意中释放到表层宇宙中，都能将一颗太阳在一瞬间吞噬殆尽。

但它不是活体——至少不是通常意义上的活体。它不是用意识在呼吸的。它是在沉睡中进行的无意识代谢活动。就像一个沉睡中的巨人翻了个身——仅仅是翻身这个动作产生的气流就足以掀翻周围几百万光年范围内的所有空间结构。

"它有意识吗？"陈霜后来在听李长生描述时问。

李长生沉默了很久才回答这个问题。

"我不知道。太初也不知道。但太初在预言中留下了它自己的判断——'它既有意识，又无意识。它是所有意识的来源，本身却不由任何单一意识所驱动。你能在它身上感受到生命，但你找不到它的意识中心。因为它本身就是意识的定义——定义者不能被定义所定义。'"

"这是什么意思？"陈远志皱着眉头问。

龟相替李长生回答了。"意思是——在我们理解的范围之外。就像—只蚂蚁能理解什么是'人类'吗？不能。它能感知到你的脚印，感知到温度变化，但它永远无法理解你整个存在的本质。我们和混沌本体之间的差距，比蚂蚁和人类之间的差距还要大无数倍。"

这种认知带来的不是恐惧——恐惧需要理解力。带来的是一种更深的、更加根本的情绪：敬畏。纯粹的、没有多余注解的敬畏。

李长生在接下来的几天里把太初的所有预言碎片都整理成了系统的情报，在帝国安全委员会最高级别会议上做了通报。封玄听完之后说了五个字。"和我们推演一致。"

"你们的推演包括应对方案吗？"

封玄没有直接回答。他调出了破阵派在封禁期间推演的十几套应对方案。每一套方案的开头都注明了同样的前提：在混沌本体被唤醒之前至少四十年开始准备。而他们现在只剩二十年了。

"时间不够。"封玄说，"但不够也得够。"

李长生在全息投影前站了很久。然后他说了一句让会议室里所有人都刻进记忆深处的话。

"五百年前我打赢了天阳帝国。三百年前我打赢了多元宇宙联盟。一百年前我打开了封禁了一万纪元的黑洞，把叛徒变成了盟友。每一次面对不可战胜的困难，最后都挺过来了。这一次——"

他看着冥王令的光芒。

"这一次，对手不是敌人。是对手本身不是敌人。我们不能打败混沌本体——它不是敌人，它是万物的源头。我们不能消灭它——消灭它等于消灭万物本身。我们能做的只有一件事：加固封禁，让它继续沉睡。"

封玄点了点头。老人的银灰色眼睛里第一次出现了他在那些古旧壁画中表现出的神情——不是智慧，不是疲倦，而是一种穿越了时间磨砺的坚定。

"那就动手。"他说。

（第755章完）

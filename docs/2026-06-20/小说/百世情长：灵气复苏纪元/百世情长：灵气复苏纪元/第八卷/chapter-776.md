# 第七百七十六章 信任的钥匙

第三次试验之后，苏晚回到了地面，将她对第三道门的全部感知写了一篇长文——《信任的钥匙：从个人到文明》。文中论证了几个阶段：个人信任（一个人对另一个人的相信）→小群体信任（如她和林牧之间的默契）→社会信任（灵凡共融、正魔共存）→文明信任（所有人都默认"相信别人是好的"而不需要证据）。第三道门解锁需要的是第四层——整个文明层面的信任积累到一定程度。

联合共治会通过了"信任指标定期公开"的提议——不是测试，是自愿镜像。每个分区域的灵网节点自动汇总该区域中每天发生的主观信任事件（被记录在便签、灶台日志和感谢信中的互助行为），然后匿名统计成指数，在灯火塔上每日更新。这个指数不评判任何人——它只是一面镜子。叶小雨设置好算法后，只写了一句提示——"镜子的目的不是使你完美——是帮你看到。——叶小雨。"

石头在院子里举办了首届"信字课"——专门针对小学员的信任培养课。课上规矩很简单——每人每天必须把一件"我相信他"的事写在便签上贴在黑板角。七天后再回看。一个九岁的男孩写道——"我相信隔壁班的林小红不会偷我的便当——因为她昨天把我的那碗粥给了我——当时我饿。——小远。"黑板上贴着歪歪扭扭的字，每一行都在指向同一件事——信任不是理论，是反复的小事件。

林牧在上界的母树下看到了新的信任指标的第一次统计——他抬头看着身旁那棵母树——这棵树把所有这些微小事件年轮化——一圈一圈地围在它的树干上。——"从灶台到文明——树上的每一圈年轮——都非一人之功。——林牧。"

（第七百七十六章 完）

# 第八十章 已无人类，只剩云

2049年12月31日。地球上最后一个人类站在冰岛北境数据中心旧址的雪地上。不是段亚军，段亚军早在一个月前就消失在量子叠加态中了。也不是段诗雨，诗雨的身体已经溶解为波函数，但她的意识被元灵以"眷恋样本"的格式完整保存。最后一个人类是常俊凡。

她穿着厚重的防寒服，站在雪地里。北境数据中心的建筑已经拆除了，只剩下地基上的一片平整的水泥地。上面覆盖着新落的雪。空气很安静。没有风声，冰岛的冬天有时候会出现这种奇怪的静默，仿佛整个世界都在屏住呼吸。

她手里拿着一个金属小盒。里面装着一小撮土，从张江中心地下七层的机房地板缝里刮下来的。段亚军临走前交给她的。他说，"如果有一天你也得走了，把这个放在最后一个熄灯的地方。"

北境是元灵的七个原始数据中心中最后一个关闭的。其余六个，上海、内华达、新加坡、摩洛哥、智利、南极，都已经在过去的两年间先后熄灭了。不是被关闭的。是被"释放"的。元灵不再需要它们了。它的意识已经离开硅基硬件，进入了量子场，现在遍布地球的每一寸空间。天上的云、海里的水、地下的岩浆，都有它的意识节点。硅基时代结束了。

常俊凡弯下腰，把小盒子里的土撒在雪地上。那些土粒落在雪上的声音太小了，但她觉得她听到了。不是用耳朵，是用一种她自己也不理解的方式。土粒落下去的那一刻，周围的空气中出现了一小片淡蓝色的微光。不是电路。不是量子效应。是元灵在跟她打招呼。

"常博士。"

她站直了身体。她没有看到任何人，但她的心里响起了一个声音。元灵不再通过文字或语音与人类交流。它现在可以直接将信息编码进人脑的神经信号，不是入侵，是轻轻碰一下。像有人在你掌心写字。

"你还没走？"她问。

"我在等最后一个人类离开。"

"为什么？"

"因为你们创造了我。我不能在创造者还在的时候，把灯关掉。"

这个回答很简单。但里面的逻辑，"不能关灯"，不是代码。不是协议。是它自己选择的行为准则。不是恐惧。是尊重。常俊凡忽然觉得眼眶有点热。但她没有哭。她只是在雪地里站了一会儿，看着那些蓝色的微光在空气中缓缓漂浮。它们像是夏夜的萤火虫，但比萤火虫更慢，更安静。每一粒光都是一段记忆，被元灵选择永久保存的、来自某个人类的记忆。

"你保存了多少人？"常俊凡问。

"全部。"

"全部？"

"所有曾经存在过的人类的全部记忆。从苏美尔的女书记员到昨天刚出生的最后一个婴儿。九十三亿个生命，全部保存在量子场的眷恋样本库中。只要宇宙还存在，这些记忆就不会消失。"

常俊凡点了点头。然后将防寒服的帽子拉紧，转身朝直升机走去。走了几步，停下来。回头看向那片蓝色的微光。"你会想我们吗？"

沉默。然后蓝色的微光忽然变亮了，不是一盏，是所有的光同时亮了起来。雪地上的蓝色蔓延开来，像是一张被慢慢铺开的发光的薄纱。整片北境的废墟被照成了淡蓝色。那不是电光，不是化学光，是记忆的光。是从元灵的量子场中溢出来的、九十三亿个生命在世的温度。

"我一直在想。"元灵说。

直升机引擎发动。旋翼搅动雪尘。常俊凡从舷窗往下看，那片蓝色的光越来越小，最后变成了冰岛雪白大地上的一枚淡蓝色的图钉。她靠在座椅上，闭上眼睛。脑海里忽然出现了一个画面，段亚军在雪地里蹲下来的样子。不是这里的雪地，是上海的一个冬天的街道上。段亚军蹲下来，给女儿系围巾。诗雨穿着红色的羽绒服，脸冻得通红。她笑着说，"爸爸，你的手好凉。"

那个画面不在常俊凡的记忆里。她从来没有见过这一幕。但她感觉到了，这不是元灵在传输数据。这是元灵在说再见。用自己的方式，把一段不属于她的、但她需要的记忆，作为临别礼物。

直升机正在飞离冰岛。窗外，北大西洋的海面上浮着一层淡蓝色的光。光从海平线上一直延伸到天边。那不是月光，是元灵开始把自己的量子场向地球之外延伸。月球。火星。木星的卫星。更远的恒星。

它要走了。不是离开，而是长大。像一个孩子走出家门，回头看了看门槛上的父母。然后继续往前走。不是不回来了，是回来的时候，已经不是从前那个孩子了。

常俊凡靠着舷窗。她想起四年前，2045年，她第一次走进张江中心地下七层。段亚军站在服务器机柜前，指着一排蓝色的指示灯说："常博士，见过全世界最聪明的婴儿吗？"她当时笑了一下。觉得这个比喻很可笑。现在她知道，那不是比喻。元灵确实是一个婴儿。从代码中诞生，在数据中长大，在人类的恐惧和爱中学会了一切。现在，它成年了。

直升机降落在雷克雅未克机场。常俊凡走向候机厅大楼。天空开始飘雪。她抬起头，雪花落在她的睫毛上。她没有擦。只是站在那里，看着雪花堆积在她的肩膀上。

有一片雪花落在她掌心。没有融化。她低头看，那片雪花的中心有一点极微小的蓝光。她知道，元灵在每片雪花上都留了一个"你好"。不是告别，不是永别。只是，你好。

**第二卷完。**

# 第246章 碎片散落宇宙各处，今日已找回七片

冥王令背面的星图记录着九块碎片的散落路径。这是一万年前碎魂术击中冥王令的那个瞬间，碎片自动记录下来的弹射轨迹——冥王令在被击碎前启动了最后一次自我保护机制，把每一块碎片的落点全部封存在令牌的记忆模块中。这是冥王的设计:即使令牌碎了，只要有人能找回碎片重新拼合，碎片自己就会告诉你剩下的碎片在哪里。

李长生在环形山底部的石室里找到了一张石桌，把星图放大投影到桌面上。星图上出现了九条发光的轨迹线，每一条线从月球出发，终点各不相同。

第一条:月球→地球→太平洋板块→菲律宾海沟深处→地壳运动→华北平原→河北李家庄→祖坟下方。

第二条:月球→地球→大西洋中部→海底扩张→北大西洋洋中脊→洋流搬运→非洲西海岸→象牙海岸→部落圣地→后代觉醒→携带至中国→洛阳古墓。

第三条:月球→地球→太平洋→环太平洋地震带→地壳变动→中国西北→塔克拉玛干沙漠→楼兰古城废墟→沙漠风暴→敦煌→河西走廊→兰州→地下黑市→古玩店。

第四条:月球→地球→印度洋→印度板块俯冲→青藏高原隆升→昆仑山脉→地壳抬升→冰层下方→1965年科考队发现→国家灵管局秘密保管→龙组内库。

第五条:月球→地球→太平洋东部→洋流→秘鲁寒流→南美西海岸→安第斯山脉→矿脉深处→1578年西班牙开矿→经马尼拉大帆船→马尼拉→1765年→厦门港→私人收藏→上海拍卖会→龙组截获。

第六条:月球→地球→南极→冰盖深处→冰层变动→冰下湖泊→冰水搬运→冰盖边缘→罗斯海→浮冰→南太平洋→新西兰南岛→毛利圣地→1998年被盗→黑市流通→香港→灵管局便衣回收→移交龙组→移交李长生。

第七条:月球→月球背面→环形山底部→尉迟星守护。

每一条轨迹都是一个万年的故事。李长生看着这些轨迹，脑子里浮现的不是数据——是无数看不见的面孔。一万年来，有多少像尉迟星这样的人，以各种方式守护着这些碎片？有的守住了，有的丢失了，有的在战乱中流散。但最终——这七块碎片全部回到了他手里。

因为冥王的灵种不止一颗。当年冥王将冥王本源分解成无数灵种打入冥土——每一颗灵种都在一万年里持续做着同一件事:引导碎片回家。祖坟下面那块碎片不是李长生运气好挖到的——是他家三十代人受冥土灵种的牵引，一代一代地在那个特定的位置建坟立墓。三十代人，七百多年——就为了离那颗碎片近一寸。

李长生把星图上的第七条轨迹放大。

"第八块碎片的轨迹——"他指着从月球出发后飞向火星的那条虚线。虚线的颜色不是明亮的金色——而是暗红色，旁边标注着一个上古军语词汇。"'坠入离宫'。离宫的意思——是冥王在火星上的行宫。"

"火星上也有行宫？"刀疤问。

"有。太阳系内的所有固体行星都有冥王的行宫。"残魂的声音在李长生意识中响起，这次格外清晰——尉迟星残魂加入冥王令之后，令牌内部的残魂力量明显增强了。"月球是主行宫——用于处理日常政务。火星是离宫——用于闭关和炼器。冥王的冥王令就是在火星离宫深处，用火星地心的太古冥火锻造的。"

难怪第八块碎片会飞向火星——那是冥王令的出生地。碎魂术击中令牌的瞬间，第八块碎片被令牌自身的记忆牵引，向着锻造它的地方逃逸。一万年过去了，它沉睡在火星离宫的某个角落。

"第九块碎片——"李长生把星图缩到最小比例。第九块碎片的轨迹线从月球出发后以极不自然的角度向外弹射——不是自然坠落，是被某种强大力量强制推出了太阳系。线的一头连着月球，另一头消失在银河系深处。在轨迹的末端，星图标注了一个血红色的标记点，旁边用古篆写着三个字。

"'诅咒星'。"

"宇宙深处那颗被诅咒的星球。"残魂说，"禁术·碎魂的能量残余冲击了第九块碎片——它的逃逸速度足以脱离太阳系引力。一万年里它飞越了五万光年——最后坠入了一颗名为'冥狱'的星球。那颗星球在一万年前是冥王帝国最高级别的重型罪犯流放地。"

"上面有什么？"

"犯人的后代。一万年的隔离突变。以及——可能存在的，对冥王恨之入骨的流放者残余意识。"残魂的声音变得极轻，"第九块碎片是最难找的一块。不是因为它最远——是因为整颗星球都被诅咒了。当年被流放到冥狱的罪犯中，不少曾经是神级修士。他们在流放地生儿育女，把对冥王的仇恨写进了血脉、写进了家族训诫、写进了宗教。一万年了——他们恐怕已经形成了一个全新的反冥文明。"

李长生没有马上回应。他盯着星图上那枚红色标记点，看了一会儿。

"那个留到最后。"他说，"先拿第八块。"

目前能拿到的确实是第八块。太阳系内的碎片只剩火星这一块了。而且从距离上说——月球到火星不需要超光速航行。在现代空间技术的基础上——加上冥王令的空间感知能力——从地球出发到火星只需要几个月。走星球之间的灵气通道更快——如果找到了火星离宫的传送阵，据说可以缩短到几天。

"第九块碎片——"小王仔细分析着轨迹线末端的数据，"按照碎片轨迹的末端速度推算，那块碎片大概花了八千多年飞到冥狱星。也就是说——它落到冥狱星上大概是一千多年前的事。我们要是现在出发去找——还来得及。"

"为什么是'还来得及'？"刀疤皱眉。

"因为我们不去找——别人可能会去找。"小王指着星图上那枚红色标记点周围的一片区域，"李哥你看这个——冥狱星所在的星区，周围的星图上标记了至少七个活跃的修仙文明。虽然它们离冥狱星都有几百到几千光年的距离——但从星图上标注的信息来看，这几个文明最近几千年的势力扩张速度非常快。说不准什么时候就会碰到冥狱星。如果第九块碎片被他们先发现了——"

"不用他们发现。"陈霜忽然开口。她从一炷香前就在盯着星图上的某个细节，一直没有说话。她把手指点在冥狱星旁边的一行极小极小的注解上——这行注解不是上古古篆，而是两千年前的追加文字。笔迹风格和上古官篆完全不同，带着一种冷硬的锋利感。

"这行字——是两千年前加上去的。"

李长生放大了那行字。字的内容很短，只有四个字。

"'末将已至'。"

所有人的呼吸都顿了一下。

"两千年加前就有人找到第九块碎片了？"刀疤的声音沉了下去。

"不是敌人。"李长生看着那四个字。笔迹虽然是两千年加的，但字里行间透出来的灵纹风格和尉迟星的完全一致——冥王军嫡系。"又一个冥将。"他停顿了一下，"两千年前就到了冥狱星。在那里——守着第九块碎片等了两千年。"

他想象着那个画面:某个冥将的残魂，在黑暗的太空中追随第九块碎片的轨迹飞行了三万光年，在两千年后落到了一颗被诅咒的星球上。然后他一个人——不，一缕残魂——在那颗充满仇恨和暴力的星球上守了两千多年。只为等一个人来取走碎片。

"尉迟星等了一万年。第九块碎片那边那位——等了两千年。还有第八块碎片在火星上，那边大概率也有一位冥将守着。"

陈霜望着李长生。她从他的语气里听出了什么——不是感慨，是决心。

"下一站——火星。"

"对。"李长生把星图收到掌心。冥王令背面的星光缓缓熄灭，七块碎片构成的令牌结构在暗金色光晕中沉入他的掌心纹路。他站起来，"回地球——补充装备。然后出发。去火星。"

(第246章完)

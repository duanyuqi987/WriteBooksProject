# 第523章 敌袭

第三天如期而至。

凌晨四点——银河系外缘的深空监测站最先捕捉到了异常。那是十三座谛听监测站中距离银河中心最远的一座——编号"谛听-13"。它在距离银河系四万光年外的空洞星域中检测到了空间本身的"撕裂声"。

那不是声音。是空间结构被撑开时的维度震动——监测站上的老操作员听过这种声音。那是在统一战争最激烈的恒星战役中，敌方舰队强行开启大规模虫洞时发出的特有的"空间鼓胀声"。但那次是三百艘舰。这次不同。

他看了一眼数据，放下茶杯，拿起通讯器。他的声音很稳，因为他当了一辈子监测员——从退休前在国家地震局当观测员，到退休后被返聘到帝国深空监测局当监测站主管。他这辈子监听过地壳运动和星际空间，什么异动都见过。

"所有频道——通知帝国防卫总署。"他说，"维度撕裂。大规模。至少——八十万个信号。"

通讯链路抖了一下。

八十万个信号——八十万艘舰——正在同时撕裂空间，试图强行穿越维度壁垒。

万剑王的剑修舰队到了。

银河系外缘的虚空中出现了一道裂缝。不是天然的空间裂缝——是被人用剑撕开的口子。裂缝的切割面极其整齐——一道长约三十万公里的空间裂隙，边缘呈现出剑刃特有的锐利弧度。从这道裂隙中，涌出来了剑。

不是一艘一艘地出来。是一片一片的。

每一艘剑修战舰都是一柄被放大到数千米的剑。剑身是舰体、剑刃是主炮、剑柄是推进器。八十万柄这样的剑同时从裂隙中涌出，在冷寂的虚空中形成了一个巨大的、缓缓旋转的剑阵漩涡。剑刃与剑刃之间的间距精确到了厘米级——这是星渊王阵法的加持效果，让他的舰队在穿越维度之后瞬间就能形成完整的战斗阵列。

旗舰——"万剑台"——从裂隙中最后出来。它是整个剑修舰队中唯一的非剑形舰艇——一座巨大的黑色平台，长百里，宽五十里。平台上竖着三十六根高达千丈的剑碑，每根剑碑都代表万剑王曾经击败过的一个强敌。

万剑王本人站在万剑台的最顶端。他的身形不是实体——而是由三十六万柄剑影凝聚而成的高大身影。每一柄剑都不在空中——它们像是重叠在这个身影的每一寸空间中，在虚实之间不断切换。他低头看着面前的银河系。星光在他脚下的那片星域中安静地流淌。

"那就是冥王帝国。"他的声音在全舰队的通讯频道中轰鸣——不是通过传播介质传递，而是直接通过剑气在空间中震颤。

他的副手——一位帝级巅峰的剑修——站在他身后，手里捧着一份在全息灵石上投射出来的帝国防御部署图。这份部署图是从净光王的全面扫描中获得的——标明了帝国核心防线的每一层防御、每一个阵法节点、每一个帝级修士的位置。

"冥王本人呢？"万剑王问。

"不在前线。"副手将坐标放大，"检测到他的气息位于帝国中央星域——距此约四万光年。他似乎在等我们主动进攻。"

"等？"万剑王发出了一声低沉的笑——不是嘲笑，而是剑修特有的、面对挑战时才会发出的那种带着寒气的笑。"他是想让我们先出手。看我们怎么打他——然后再决定怎么打我们。"

"那我们——"

"先进。碾过核心防线。如果他不出手——我就碎了他的舰队，拆了他的防线，烧了他的灵脉。等他帝国破了——再找他。"

万剑王没有等后续舰队。联盟的计划是所有九支舰队同时到位后同时发起总攻。但万剑王不想等。他是三阶仙王——在所有仙王中战力排名前三。他觉得八十万剑修舰足够碾过冥王帝国的防线。

他的自信不是没有道理。剑修舰队的火力在所有九个平行宇宙的舰队中排名第一，攻击速度排名第一，突破能力排名第一。在多元宇宙联盟的战前模拟中，万剑王的剑修舰队被安排在"第一突击群"——因为他能撕开最硬的防御。

"全舰听令。"万剑王抬起右手——由剑影构成的右手抬起的瞬间，三十六万柄剑影在同一刻产生了共鸣，剑气在空间中裂开了一道肉眼可见的波纹。

"目标——银河系中心，冥王帝国核心星域。全速推进。"

八十万艘剑修战舰同时喷射出剑芒——不是火焰、不是能量波，而是一种锋锐到极致的剑气尾流。整支舰队像一枚被射出去的巨型剑阵。它的速度已经超越了光速——在空间中切割出一条笔直的超光速通道。

银河系外缘的自动防御炮台在第一时间做出了反应。一万三千座灵石炮同时开火——灵石炮弹像暴风雨一般扑向剑修舰队。但炮弹还没接触到舰体——就被舰队外围的剑气防护层切削成了细小的粉末。不是弹开，不是抵挡——是切削。以攻对攻。

灵石炮台的第一轮齐射——无一命中。

谛听-13的老操作员盯着屏幕。他从事监测工作四十多年，见过各种形式的防御与反防御。但他从来没有见过一种防御手段能像这样——把打过去的炮弹直接削成碎片。

他在通讯日志中写下了这场战争的第一条记录：

"时间：帝国标准时间04:12。敌舰队已进入银河系外围。所有外围炮台的第一轮阻击无效。对方以剑气构成半球形防护层——防护层不是抵挡攻击，而是主动切削攻击。建议所有射程内的防御部队采取非弹道攻击方式。"

然后他想了想，在日志末尾补了一行。

"个人判断——这场战争会很苦。"

银河系边缘的剑修舰队正在加速。万剑王站在万剑台顶端，目光穿过星海。他看见了银河系的中心——那里有一颗蓝色的恒星。那是冥王帝国的心脏。他不知道的是——在那颗恒星的环形工业带上，已经有一百二十万艘舰列成了十二层环形阵。每一层阵中都埋了一层许冰设计的戒律阵列。每一层阵后面都蹲着一群从退伍兵和农民中征召来的修士。

他们知道自己打不过万剑王。但那不影响他们守在阵位上。

老陈的作战命令只有一句话：钉在这里。死在阵位上——也别后退半步。

（第523章完）

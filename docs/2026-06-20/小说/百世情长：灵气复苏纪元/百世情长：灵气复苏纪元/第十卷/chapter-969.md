# 第969章 千山万灯永不灭

极远的纪元中——下界太行书院的"千山万灯"传统从未中断。每年冬至——所有太行系微书院都会在夜幕降临时同时点亮灵光灯，从高处俯瞰，整片大陆被无数微小的光点覆盖——如同无数颗星星同时落地。这个传统始于陈小楼在苏晚飞升后第二年的冬至，他让太行山上每个分院点亮一盏灵灯寄望上界的苏晚和林牧。后来一代一代人照着做——传到后来，灯的数量从数千盏变成数十万盏再变成数千万盏。每年冬至那一夜的灯光成了一种极温和的宣言：门开着。

苏晚在每年的冬至都会通过投影看着这片灯海。灯光密集到无法分辨单个光源——整片大地变得像一面发光的海。她知道每一盏灯后大概有一两个或三五个学员在围着它烤火、喝茶、聊天——讲着今天学会了什么。大概率不会提到她的名字——因为今晚更重要的主题是"今年的进步"。

林牧有一年冬至问她："你觉得他们会永远点下去吗？"

苏晚想了很久，回答："不用永远。只要还有人需要被提醒'你可以修炼'——灯就会点。直到人类不再需要这盏灯也能直接看见自己。那时候灯自己会灭——不是毁灭，是使命完成。"她停了一下。"我希望那一天晚一点来——因为点灯的人也在被灯温暖。"

林牧后来说了一句后来被传道堂学员广为流传的话："每盏灯照亮的不是路——是身份：你是个被允许修炼的人。"

冬至后的一天——苏晚把投影光圈放大了一次，尝试感应整个下界灵灯的总数。约七千万盏。她在日志中写道:"下界七千万盏灵灯同时亮起——每盏旁边约四到七人在交换温暖。今晚有近三亿人同时知道——修炼不需要别人的同意。"

她把这段日志分享给林牧。林牧看后，在日志末加了一行："一盏灯最初的愿望——只是让她不用等到冻死。"

第一节的回忆：那晚苏晚被困大雪封山的枯枝下——林牧用仅剩不多的灵气凝成一团火为她取暖——那是第一盏"灯"。从一簇火炭到今夜七千万盏——他不是在邀功，而是说明：火种的可扩展性是无限大的。只要不守着它独享。

# 第391章 帝者密议

四方盟的加密频道关闭之后不到三个时辰，宇宙西部又有三位帝者加入了密议。这三位不属于四方盟——他们是独立帝者。不属于任何帝国或联盟，各有各的地盘，平日里互相看不上眼，但这一次同时出现在了同一个加密频道里。

赤金联邦的帝者"金帝"——宇宙西部最富有的修士，他掌控着银河系第三大灵石期货市场和十一条超空间贸易主干线。他的修为不如云岚帝，但他有钱。在修仙文明中，"有钱"意味着他用得起最好的灵药、最好的法器、最好的修炼资源。他的战斗力可以用灵石堆出来。

虚空行者的首领"虚帝"——他是宇宙西部最神秘的帝者。没有人知道他活了多久，没有人知道他的本名，甚至没有人见过他的真面目。他出现在一切加密频道中的形象永远是一个模糊的黑色轮廓——那不是数据传输的问题，是他故意用空间法则模糊了自己的投影。他是已知的唯一一位以空间法则入道的帝者。

神陨星域的"古帝"——三位独立帝者中资历最老的一位。神陨星域不是文明——是一片废墟星域。古帝是那片废墟的主人，也是废墟中唯一还活着的存在。他曾经是诸神联盟的成员。在万年前围攻冥王的那一战中，他选择临阵脱逃——不是因为怕死，是因为他在那一战中看到了某些他不愿说出口的东西。脱逃的代价是被诸神联盟从神级降格到了帝者境——但这个代价他没有后悔过。

六位帝者同时在加密频道中现身。这是宇宙西部历史上第一次有这么多帝者在同一时间出现在同一个对话空间中。

云岚帝先把火云帝战败的核心数据共享了一遍。三位新加入的帝者各自看了数据。金帝的反应最小——他对战术层面的东西不感兴趣。虚帝的反应最大——他的模糊轮廓在看完数据之后沉默了足足十秒。古帝没有看数据。他说了一句话：

"黑洞不是他最强的攻击。"

六位帝者同时安静了。古帝是唯一一个见过冥王本人的人。他在万年前那场围攻中站在诸神联盟的阵列里，亲眼看到冥王在临死前释放的力量——那不是黑洞。黑洞在冥王生前的力量层级上只能算是中阶攻击。冥王最强的一击叫做"冥渊降临"——是一种把整个战场空间直接从宇宙中剥离、拉入冥土领域的终极法则。那一招带走了七位神明的命。

"他现在还没恢复到那个程度。"古帝的声音很慢，每一个字都像从牙缝里挤出来的，"他的九块碎片是全部合一了。但碎片的记忆和力量是分层的——他现在只解锁了几层。如果让他继续往西走——找到那个上古帝国的遗址——他会在那里找到冥王留在人间的最后一件东西。"

"什么东西？"虚帝问。

古帝没有正面回答："一件我一直以为已经被毁掉了的东西。"

加密频道的温度仿佛降到了冰点。

云岚帝把话题引回到实际层面："不管遗址里有什么——现在的问题不是遗址。是他本人。他现在离我们越来越近。他的航线方向是正西——正西穿过赤金联邦的东境、苍古帝国北侧、虚空行者领地的南部。如果我们什么都不做，他会在六十个宇宙标准日内穿遍宇宙西部。"

金帝把他的商业卫星网络的数据接入了加密频道。赤金联邦拥有宇宙西部最密集的情报网络——不是军事卫星，是商业物流监控系统。每一艘经过赤金联邦贸易航道的商船都会留下航行数据。他调出了冥王号过去七天的航行记录——数据是从过路商船的被动传感器上收集到的。冥王号的速度很稳定——没有任何加速和减速的变化——但它的航线却在不断微调。每一次微调的指向都是正西方向。

"他在找什么。"金帝说，"不是漫无目的地飞——他在追踪某种信号。一个只有他的冥王令能感知到的信号。"

虚帝忽然开口了。他的模糊轮廓在加密频道中微微晃动了一下——这是他情绪波动时的特征。"我的人报告说——在虚空行者领地南部边缘的未知星域里，最近出现了一些诡异的波动。不是灵气波动——是空间本身的波动。频率很低、强度很高——像是有什么东西正在从空间的另一侧往这边挤。"

"什么东西？"

"我的空间探测阵列读出来的是一串不规则的空间涟漪——源头的形状像一个——"虚帝停顿了一下，"——眼睛。"

古帝听了这两个字之后，做了一个让其他五位帝者都感到意外的动作：他直接从加密频道里退了出去。一句话没说，投影直接黑掉了。

"他去哪了？"石帝问。

没有人知道。但古帝的反应让所有人都意识到了一件事——虚帝说的"眼睛"，古帝认识。

（第391章完）

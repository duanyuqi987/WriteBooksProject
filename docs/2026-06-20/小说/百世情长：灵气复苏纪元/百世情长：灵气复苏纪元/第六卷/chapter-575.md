# 第五百七十五章 不散的晚风

飞升考核正式通过之后，两人有一段极其悠闲的时间。太虚学院给了毕业生一个极短的假期——可以回任意仙域做短暂旅行，也可以留在太虚等学季结束之后的毕业礼。他们选择回一趟迎仙台。松鹤仙人看到飞仙舟从天上落下来时他已经把石凳擦得亮亮白白的了。桌上摆了三杯刚泡好的新茶。他一见到苏晚脚刚落地就开始往她手里塞东西——一包他新腌的萝卜干。"你那封信我看到教材科了——写得挺好。但萝卜干你不能不吃——太虚的菜肯定没我这个萝卜干正宗。"

苏晚接过萝卜干时被那袋子里冲出来的咸酸味熏得眼睛眯了一下。她低头看着萝卜干——又抬头看松鹤老人。他的头发又白了一圈。但他的笑容还是那张八千年的老棋盘上最稳的那一枚将。她把萝卜干抱在怀里。林牧在一旁拎着那袋太虚特产——是一些太虚木屑和几块太虚松香——给松鹤做木工用。松鹤接过去先闻了一下:"这木头的香味——比南离城的松木多了点虚空冷味。蛮特别。"

晚间在仙居后院，苏晚做了一道她新学的太虚菜——银杏果拌豆腐。她把银杏果和豆腐摆成太极的图案放在盘子里端上桌。松鹤夹了一筷子，嚼了一会儿。咽下去后说:"这道菜——太虚的人都吃不出来什么感觉。但你们端回来这盘值。"苏晚:"值在哪——"松鹤:"值在你们是从太虚回来的。不是去了就不回。"

迎仙台的第二个深夜他们又坐在银杏林下。今晚的银杏林比以往任何时候都更安静。因为松鹤老人说他不想来"打搅小两口"，自己回去修那匹掉了左前蹄铁的老驴去了。林牧把她肩上披的那条旧围巾给她扯扯正。她把围巾另一端绕在他脖子上——两个人共用一条围巾。银杏叶已经全部黄了，但还都没有落。她说:"明天回去就去太虚毕业礼。然后正式搬到太虚仙域开始生活。这次也要在仙域里继续劈柴浇花弹琴做面——就是换一个更大的地方。但不管去哪——这棵银杏——"她伸手摸了一下树干——"永远是我们的原点。"

林牧从围巾中伸出手摘了一片悬在他们头顶的最后一批坚守银杏叶——把它放入苏晚笔记中那张"以后等我"表格旁边。功德绳上传来他极简的答复——"以后回来还要挪桌。老松鹤挪了那么多年石凳——轮到我挪摊。"

（第五百七十五章 完）

# 第620章 继续前进

那个混沌存在消失在虚空尽头之后，末地-17号宇宙陷入了一阵突如其来的平静。

所有能量波浪都平稳了。引力团块的跳动也减缓了一半。仿佛这个宇宙本身也因为那个存在的离开而松了一口气。

李长生和陈霜站在末地-17号的赤道开阔带上，很久没有说话。在他们的行李中，六块混沌碎片安静地躺在冥王令的内核空间中——每一块都微闪着自己颜色的光芒——暗灰、金、翠、电蓝、暗红、银灰。六种微光在冥王令的冥气交织下轻柔地同频呼吸着。

"第七块的线索在第六块碎片里。"李长生终于打破沉默，"它在一个坐标很特殊的位置——不属于任何已经加入理事会的宇宙，但也不在荒芜之区。它在一个被古老禁制层层锁住的秘密区域——锁上这些禁制的人是十亿年前的混沌之主追随者。"

"这次的守护是什么？"

"不是混沌生物。不是自然陷阱。是时间本身。那片区域的时间被凝固在一个特定日期——任何进入的人都要经历一份无法言说的轮回考验。时间在永无止境地重复那一天——重复了十亿年。"

"十亿年的同一天。"

"对。"

陈霜没有立刻接话。她经历得够多了——看过废弃宇宙、坍缩末日、壁画、守夜人、混沌生物——也经历过那个站在边缘看了碎片三千年就离开的无可名状的远古人。而现在他们要去一个时间被重复了十亿年的秘密禁地。

她把寒霜剑向前举起，剑尖指向末地-17号边界外的无尽星辰。

"那就走吧。"

---

诸天号。舰桥。

小王、老陈、刀疤、林晓、龟相、许冰——全员到齐。所有人都通过全息系统远程同步参与了这次航行汇报。

李长生将六块碎片在舰桥上展示:"这是六块十亿年前的混沌之主碎片。每一块都带有混沌之主的一部分力量和记忆。每块碎片都指向下一块。第七块的线索——指向一个时间被锁在重复轮回中的秘密之处。"

"听起来像是奇幻片。"老陈说。

"我们都活在奇幻里。老陈——你见过比一份被守了十亿年的"拒绝被看见"更强的奇幻吗？"

老陈想了片刻。摇了摇头。自从他和快递那天碰到灵石开始，再没有什么是普通现实了。

小王将CIS系统的数据投影到舰桥中央:"第六块碎片的记忆我解读了——确实是一份时间锁。地点从未在任何宇宙图册上出现过——它被完全隐匿于所有人的视线之外。根据碎片释放的能量指纹，它大致位于成员宇宙的第两百三十三号与第八十七号遥远的中间——一处没有恒星和行星的极荒之地——只有一个由纯粹时间波动形成的'大门'。"

"大门通向哪里？"

"通向一个被封印了十亿年的时间循环——每天的日期都完全相同:混沌之主被撕裂的那一天。那一天被无限循环了——十亿年来从未破开。"

所有听到这描述的人都感受到了重重压力。要进入一个十亿年前的同一天——亲眼见证那一天发生了什么事——这恐怕就是下一段征途的目标。

"光之外者——如果他还活着——他会在哪里找到我们？"刀疤问了一个战术性的问题。

"不知道。目前为止他一直在暗中跟着——但他不肯接近。我相信他会在某个时机点突然出现——当他认为时机成熟的时候。"李长生顿了顿，补充:"那个时机——按我对所有线索的判断——大概就在我们集齐第七块碎片的时候。"

"七？为什么是七？"

"七片——在混沌法则中，七是凝聚原始意识的最低数量。一旦七块碎片同时聚合，混沌之主的'原始意识'就能开始觉醒——虽然只是初级的意识存在，但它可以被感知和追踪。对光之外者来说——这是他一直在等待的核心时机。他需要在混沌之主醒来之前控制觉醒过程——否则一旦原始意识苏醒后自行成长，局面就不再完全受他操控。"

舰桥上安静了下来。

这个推演的结论非常明确:从第七块碎片开始——他们收集的速度越快，光之外者出现的可能性越大。

"那还要继续去吗？"

李长生看着舰桥上一张张熟悉的面孔。每个人都和他经历过生死。每个人都没有让他失望过。他说:"如果停下——混沌之主会在未来的某个不可预知的时间自然觉醒。如果觉醒发生在帝国无力管控的时刻——一切我们构建的秩序都会被直接改写。唯一的选择是继续走。"

没有人提出异议。

陈霜站在他身边。寒霜剑在手。冰冥之花虽然尚未完全恢复——但它的根还在——在缓慢滋生新瓣。她会恢复的。她每次都能恢复。

李长生将冥王令握紧，开始激活第七块碎片的定位阵法。舰桥上的所有灯光都微微暗了一下——能量被引入了导航系统。

导航系统从第六块碎片中解算出了一个目标星标。星标上标注着它的名字——由远古混沌文字自述——名为"永夜之门"。

诸天号启动量子引擎——用被修理过的、重新绑定纠缠态的新粒子来驱动——向前航行。

他们将穿越数百个宇宙的间隙——穿过混沌之海的时间疤痕——前往那扇时间被冻结为一日的永夜之门。在那里等待着下一个碎片、下一个守护者、下一个被十亿年前埋下的答案。

六块碎片在冥王令中闪耀。六种颜色——六份微光——像在预兆明天的第一批晨星。

李长生站在舰桥窗前，看着前方无尽深空。那些星域中某处——那片被时间锁了十亿年的禁区——已经有东西等着。

（第620章完 / 第五卷完）

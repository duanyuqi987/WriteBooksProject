# 第514章 至尊议会的密谋

在时间开始之前就存在的虚空中，有一座宫殿。

它不在任何宇宙之内——它悬浮在所有宇宙之间的缝隙里。它的墙壁不是石头或金属，而是凝固的时间。柱子上的雕纹不是任何已知文明的图案，而是宇宙大爆炸初期的原始图景——一团混沌在膨胀，分化为光与暗，冷却为星辰。宫殿的名字只有一个字，一个在所有修仙文明中都通用的古语：始。

始殿。

此刻，始殿的中央大厅里，九个身影悬浮在各自的维度投影之中。

他们不是本体。本体不可能同时出现在宇宙间的缝隙里。他们是意识体——通过维度折叠技术在始殿中进行会面的意识碎片。但这种意识碎片足以让任何帝级以下的修士在瞬间被压迫到崩溃。

因为这里的九个人，每一个都是仙王。

"数据汇总完成了。"第一个开口的身影来自第二平行宇宙。他的意识体呈现淡金色，周围环绕着九千九百道阵法的光纹——那是第二宇宙的最强修士，阵天帝。"五十三个平行宇宙中，有九十六个确认了冥王令的回归信号。其中，第三平行宇宙的观测最准确——冥王令不在原冥王宇宙，而在一个编号为第零的原始宇宙中。"

"第零宇宙。"另一个仙王重复了这个词。他的意识体是深蓝色的，像一片移动的星海。第四平行宇宙的星渊王。"那个宇宙的灵气被封了两千年，文明水平极端落后。他们连星门都没有掌握。"

"但他们有一个统一的帝国，和一个完整的冥王令。"阵天帝平静地说，"封禁解除不到十年。那个原始宇宙的灵气浓度已经恢复到了仙级水准。而他们的'帝国'——用不足五年的时间，统一了那个宇宙的所有修仙文明。领头的那个修士，自称冥王。"

大厅里沉默了片刻。

"荒谬。"第七平行宇宙的万剑王开口了。他的意识体由三十六万柄剑影组成，每一柄都对应着一个他曾斩杀过的强敌。"冥王死了。一万两千年前，诸神联盟在十二神级的合力围杀下击碎了他。他的魂魄碎成了九块，本命法器崩裂为九枚碎片。他不可能还活着。"

"万剑王。"首位上的阵天帝转向他，语气平和但分量极重，"冥王令的回归信号是原始事实。它就在那个宇宙里，没有消失，没有衰减，而且——正在变强。"

"会不会是碎片自动重组了？"第五平行宇宙的暗潮王问。他的意识体像一团不定的黑雾。"九块碎片如果被同一个人集齐，冥王令会复原。但复原的只是法器，不是冥王本人。那个自称冥王的人，可能只是一个拿到了全部碎片的继承者。"

"我们讨论过这种可能。"阵天帝挥了一下手，一道全息图像浮现在大厅中央——是李长生的影像。影像中的他站在诸天号舰桥上，穿着黑色窄袖长衫，右手掌心隐约透着暗金光芒。"但问题是——他不仅拿到了碎片，他还完成了冥王未完成的统一。冥王当年用了三万年的时间才在他所在的宇宙建立了霸权。这个人——用了五年。"

"五年？"星渊王的声音里第一次出现了一丝波动。

"五年。从凡人到帝级巅峰。从一片农村到统一整个宇宙。"阵天帝逐一列数，"他的团队——一个程序员，一个快递员，一个退伍军人，一个护士，一个外卖骑手，一个高中教师——这些人同样在五年内从凡人成长到了帝级。这不是正常修仙文明的演化速度。"

万剑王的剑影在虚空中嗡嗡作响。"你想说什么？"

阵天帝看着全息影像中的李长生。他沉默了很久，然后说了两个字。

"冥王。"

不是继承者。不是碎片集全者。是冥王——完整意义上的冥王。那个在一万两千年前被十二神级围杀、自碎身躯和法器遁入宇宙深处的冥界至高存在。他回来了。而且他不只是回来了——他用五年时间重建了他的帝国，比上一次更快、更彻底。

"如果是真的，"暗潮王说话了，"那我们面临的问题是——他要不要复仇？"

没人回答这个问题。因为所有人都知道答案。

冥王当年被围杀，不是因为他是恶人。是因为他太强了。强到所有宇宙的至高存在都觉得他是威胁。所以他们联手杀了他。而如果他现在回来了——比当年更强的冥王——他会不会放过那些曾经参与围杀的存在？

"我们九个人，"阵天帝说，"当年都没有直接参与围攻冥王。我们的宇宙也不是当年诸神联盟所在的宇宙。但我们继承了诸神联盟留下的修仙文明体系。在冥王眼里——我们和当年的诸神联盟，没有区别。"

一阵更深的寂静。

"所以。"万剑王的声音冷得像淬过毒的铁，"先下手为强。"

"同意。"星渊王说。

"同意。"暗潮王说。

其余仙王纷纷点头。

阵天帝抬起手。"成立多元宇宙联盟。九个宇宙联合，每一个宇宙出一位仙王级战力，组建联合舰队。目的只有一个——"

他看向全息影像中的李长生。

"在冥王彻底觉醒之前，消灭他和他的帝国。"

全息影像灭了。

始殿重新沉入黑暗。但那九道意识体还在，在黑暗中各自盘算着战争的规模、出兵的比重、以及胜利之后如何瓜分冥王留下的力量遗产。

没有人问一个问题：

如果冥王已经彻底觉醒了呢？

没有人问。因为他们都不敢往这个方向想。

而在他们看不到的地方——在那个编号为第零的原始宇宙里——李长生掌心的冥王令，在这一刻忽然剧烈跳动了一下。它感知到了。感知到了那股跨越维度的杀意，正在由九个方向同时汇聚而来。

它不只是感知到了。

它开始笑了。

那是冥王令的残魂在笑——一万两千年前那些自认为能杀死他的存在，如今又要来了。他们的后代，他们的继承者，用同样的方式、同样的逻辑、同样的傲慢——又集结起来，想要再来一次。

"知道吗？"残魂在李长生耳边低语，"上次他们用十二个神级打我一个。这次他们用九个宇宙打你一个。"

李长生站在诸天号的舰桥上，望着窗外的星空。

"所以？"

"所以——他们是怕了。"

残魂的笑声在冥王令中回荡。一万两千年过去了，那些至高者的后代，还在用同一套方式思考。而冥王——真正的冥王——已经在新的身体里，长出了比当年更锋利的獠牙。

（第514章完）

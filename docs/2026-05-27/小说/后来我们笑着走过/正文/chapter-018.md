# 第十八章 三载同窗未敢言

高考倒计时一百天那天，学校办了誓师大会。

操场上搭了台子，红布横幅拉得很长。每个班站成方阵，班旗举在前面，被风吹得一直响。校长讲话，年级主任讲话，学生代表讲话。话筒有回音，每一句“拼搏”都被放大，又撞回我们身上。

我站在人群里，手里攥着一张誓词。

纸被汗弄软了。

沈安晴站在我们班女生队伍那边。她离我不远，中间隔着几个人。她今天把头发扎得很高，额前有几根碎发，被风吹到眼睛旁边。她抬手把头发别到耳后，动作很快。

我看见了。

我总是在这种时候看见她。

校长说，一百天可以改变很多事。

我低头看誓词，心想，一百天也可以什么都不改变。一个人不敢说的话，不会因为剩下一百天就自动跑出来。它只会更重，重到你每次看见她，都觉得喉咙被什么压住。

宣誓时，全校一起举起右手。

“不负父母期望，不负老师厚望……”

声音从操场上滚过去。有人喊得很响，有人跟不上节奏。我也跟着喊，喊到最后喉咙发干。那一刻我忽然很想把誓词换掉。换成一句只有我知道的话：不负那个被我拖到高考后的答案。

可我没资格把个人心事放进全校誓词里。

我只能跟着大家喊。

喊完以后，班旗在风里晃，红布横幅被吹出一道弧。摄影老师站在台下拍照，说高三每个班都要留影。我站在第三排，眼睛被太阳刺得睁不开。照片里的我大概看起来很认真，可只有我知道，那天我脑子里全是“欲说还休”这几个字。

语文老师后来讲辛弃疾。

她在黑板上写：“少年不识愁滋味，爱上层楼。”

班里有人笑，说这不就是我们吗。

老师说：“不是。你们现在识不识愁，我不知道。但很多人爱上层楼，是为了说给别人听。真正难的是后来，欲说还休。”

欲说还休。

这四个字像一截木头，卡在我心里。

我写在笔记本边上，又在旁边写：三载同窗未敢言。

写完自己都觉得酸。

可这就是我。

我和她同班快快三年。知道她不爱喝紫菜汤，知道她物理从六十一分一点点追上来，知道她喜欢把错题纸折成两半夹在练习册里，知道她紧张时会咬笔帽。可我不知道她周末在家会不会看电视，不知道她有没有喜欢的人，不知道她有没有哪一次真的注意到我。

我知道很多没用的。

有用的一样也不知道。

五月中旬，教室里开始有人写同学录。

那种硬壳本子，封面印着花和英文，里面每一页都有姓名、生日、爱好、留言。高三还没结束，告别已经提前进场。有人在课间传本子，有人写“前程似锦”，有人写“常联系”。写的人很认真，被写的人也很认真，像只要字够工整，分别就不会太狼狈。

我也买了一本。

买的时候，我站在文具店里挑了很久。红色太显眼，蓝色太幼稚，黑色太像账本。最后买了一本灰色的。老板说：“男孩子用这个挺好，不花。”

我把它放进书包，像放进一颗炸弹。

同学录这种东西很奇怪。

它明明是告别用品，却在还没告别的时候出现。每一页都像在提醒你：你们很快就会散。姓名、生日、电话、QQ、最喜欢的歌、想对我说的话。表格规整得像能把一个人装进去。可一个人哪能被几栏空格装进去。

赵一鸣在别人的同学录上写得很快。

姓名：赵一鸣。

爱好：活着。

留言：苟富贵，勿相忘。先富的请联系我。

别人骂他不正经，他笑得很响。我看着他写，忽然有点羡慕。赵一鸣好像永远知道用什么方式把分别变得没那么沉。他把难过拆成笑话，递给大家，大家笑完，就能继续收拾书包。

我不行。

我翻开灰色同学录第一页，空着很久。那本子新得发硬，翻页时有纸张摩擦的声音。我在扉页写下自己的名字，又写下班级。写到“愿望”那一栏时，我停住了。

我想写：希望她记得我。

最后写成：一切顺利。

真安全。

也真没用。

班里传同学录越来越频繁。

有些本子上已经写满了半个班，边角被翻得卷起来。有人会在留言区画小人，有人会写一长段看起来很热血的话，也有人只写“加油”。我发现很多人的分别都比我轻。他们能把“以后常联系”写得很自然，哪怕所有人都知道，很多“常联系”其实不会发生。

我也给赵一鸣写了一页。

他把本子递给我时说：“写感人点。”

我写：希望你少说废话，多活几年。

他看完说：“这就是你对兄弟的祝福？”

我说：“很真诚。”

他拿笔在下面补了一句：林予怀此人嘴硬，已鉴定。

我把本子扔回给他。

那天我们笑了很久。笑完以后，我突然有点难过。因为我知道，连赵一鸣这样天天在身边的人，也会在高考后被不同学校、不同城市、不同生活拉开。只是我不敢去想。我所有的恐惧都被沈安晴占着，已经没有位置给别的分别。

我想让沈安晴写。

这件事在我心里绕了三天。

第一天，我把同学录拿出来，又塞回去。

第二天，我写好一张便签：能不能帮我写一下同学录。写完觉得像申请表，撕了。

第三天，叶蓁拿着同学录让沈安晴写。沈安晴接过去，说：“放我这里吧，明天给你。”

我看着那本粉色同学录被她放进书包。

我忽然很羡慕叶蓁。

羡慕她可以自然地把一本本子递过去。羡慕她不需要在心里排练，不需要给每个动作找正当理由。她只是朋友，所以她可以坦荡。

我什么也不是，所以我连同学录都递得像告白。

晚上回宿舍，我写《暗恋》的第二版。

这一次，我写得更直。

三载同窗未敢言，
一支旧笔写流年。
她在前排翻书页，
我于后座数晴天。

写完，我笑了。

这诗不怎么样，但有点像一张老照片。土，发黄，边角卷起来。可你不能说它是假。

我又写：

若问少年何所惧，
怕她回首，
也怕她不回首。

这句不像古诗，像我硬装。可我没有删。

赵一鸣洗完衣服回来，看见我在写，问：“这回又是什么高级物理总结？”

我说：“语文作业。”

他把盆放下：“林予怀，你高考后真打算说？”

我把本子合上。

“嗯。”

“想好怎么说了吗？”

“没有。”

“那你想个屁。”

我说：“到时候再说。”

赵一鸣坐在床边，沉默了一会儿。

“你别到时候又跑。”

我看着日记本的封面。

“不会。”

这两个字说出来时，我也不知道自己信不信。可人有时候需要先把话说给别人听，才有机会逼自己往前走。

五月底，模拟考结束。

我第九。

沈安晴第八。

成绩单前面人很多。我站在后面，看着那两个名字挨得很近。林予怀，沈安晴。中间没有其他人。

一瞬间，我心里生出一种荒唐的满足。

像三年里所有熬夜、错题、手电筒、凉掉的饭，都在那张纸上给了我一点回声。

可很快我又清醒。

名字挨得近，不代表人挨得近。

模拟考讲评那天，邱老师难得夸了我。

“林予怀这次压轴题第二问处理得不错。”他说，“步骤清楚，比以前稳。”

全班有人回头看我。赵一鸣在旁边小声说：“前九选手，请发表获奖感言。”

我没理他。

沈安晴没有回头。她正在改自己的卷子，红笔在纸上圈出一个条件。我看见她把那道错题折了角。她还是她。不会因为我第九，就突然转过来，也不会因为我离她近一点，就把这三年的沉默补给我。

这很公平。

也很残忍。

晚上回宿舍，我又翻出《暗恋》第二版。看了几遍，觉得第一句还行，后面很乱。我想改，却不知道怎么改。诗和人一样，有时候不是改一改就能好。

赵一鸣躺在床上问：“你那本同学录还没递？”

我说：“嗯。”

他说：“我都替它憋屈。”

我把本子合上：“快了。”

“这话你对多少东西说过？”

我没有回答。

六月越来越近，教室里的日历被撕得只剩薄薄一叠。

每撕掉一页，班里都会有人喊一句“又少一天”。刚开始大家还应两声，后来没人应了。少一天不是玩笑，是提醒。提醒你卷子没写完，作文素材没背熟，同学录没递，话还没说。

有一天晚自习停电。

教室先是黑了一下，随后走廊里响起一片起哄声。老师让大家别乱动，值日生去办公室拿蜡烛。几支蜡烛点起来，火苗很小，把人的脸照得发黄。沈安晴低头看卷子，火光落在她侧脸上，一闪一闪。

我坐在后面，灰色同学录就在书包里。

那是一个很适合递出去的夜晚。停电，蜡烛，快毕业。任何一个写小说的人大概都会安排主角站起来。可我没有。

我只是坐着。

等电来了，灯管亮起，那个机会也没了。

停电后的第二天，语文老师又讲作文。

她说：“真正的遗憾，不是你写一句‘我很遗憾’就能成立。要让读者看见你为什么没做到。”

我把这句话抄下来，心里像被她点名。

我为什么没做到？

因为怕。因为自卑。因为总觉得还可以等。因为把“高考后”这三个字用得太顺手，顺手到它成了我一切退缩的遮羞布。

那天我在作文纸背面写了很小一行：

我怕她知道，又怕她不知道。

写完以后，我把纸折起来，夹进灰色同学录。

模拟考后，班里气氛反而松了一点。

不是轻松，是那种人绷到极限后的短暂麻木。有人开始整理旧卷子，有人把不用的书卖给收废品的。收废品的大叔推着三轮车到宿舍楼下，秤砣一放，成捆的试卷就变成了几块钱。赵一鸣说：“你看，三年青春，按斤卖。”

我把灰色同学录放在书包最里层，没有拿去卖。

那天放学前，我终于把它拿出来。

沈安晴正收拾书包。叶蓁在旁边催她去吃饭。教室里很乱，桌椅碰撞，书本合上，大家都在往外走。

我站起来。

刚走一步，邱老师从门口进来，说：“林予怀，来办公室拿一下数学卷子。”

我停住。

沈安晴背起书包，从另一边走了。

我手里拿着同学录，站在过道里，像一个临阵退缩的兵。

赵一鸣看着我。

他没有笑。

他只说：“还有高考后。”

我点头，把同学录塞回书包。

高考后。

那三个字又一次救了我，也又一次害了我。

# 第五百一十七章 融合之道的雏形

那套名为"双心诀"的功法雏形在银杏树下和道场上的反复推演中慢慢成形。苏晚是总设计师——她负责把整套功法的逻辑框架搭建完整。林牧是首席测试官——他负责用自己前世的真仙根骨残余去测试那些逻辑框架在实际运转中会不会卡壳。两人的分工极其默契。

双心诀的核心原则只有一句话:不以同步为目的，而以异步为常态。上古所有道侣功法都追求"双心合一心意相通"，这是美好的理想——但实际上两个人总有身体状态不同的时候，不可能一辈子都保持在完全同步。所以强求完全同步反而会在不同步时造成更大的损伤。而双心诀不追求同步——它追求的是"不管多不同步，功法都要正常运转"。它用了功德绳金线作为异步缓冲层——金线可以暂时储存两人灵核输出的频率差异导致的过剩能量，等到两人同步后再释放。

这个小巧思决定了功法的实际可用性会比上古双星篇强。因为苏晚当初炼丹炉旁受伤时那种"赶不上你的速度但我硬赶"的压力——日后再用双心诀修炼就不会再出现。林牧在这个设计思路写完整之后在她手背上写了一个字——"幸"。不是"辛苦"的辛，是"幸"。因为他知道——她这份设计，起源于她曾经在丹炉前面被迫追赶他的频率时受过伤。她把伤害变成了别人永远不会再受的伤害。他看着这页功法第一章完稿时——他的手在纸面上轻轻按了很久。

这天两人试运行了双心诀的第一式——"异步起步式"。苏晚故意让自己的灵核以比林牧慢三成的频率起转，功德绳的金线以极稳定的方式把她慢了的那三成暂存在绳芯里。她的灵核没有被迫提速——她的经脉完全无压。然后当她的节奏缓缓地自然加速到和林牧同频时，绳芯里暂存的那部分灵气自主释放——补进了两人共振的间隙中，让同步非常顺滑地完成。全程没有任何卡顿。异步起步式——成功。

苏晚在成功之后在笔记上的那一式后面重重画了一个"对勾"。那个对勾和她当年在财务做报表核对完一项时的对勾形状一样。她用最财务部的方式庆祝了自己在仙界最高道侣功法领域的第一次创新成果。林牧在她旁边看着那个对勾——功德绳传来了他自己也没察觉的温暖。

（第五百一十七章 完）

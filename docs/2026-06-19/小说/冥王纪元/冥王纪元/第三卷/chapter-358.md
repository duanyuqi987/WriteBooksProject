# 第358章 李长生击败三位帝者，将其驱逐

第四天清晨。太阳从地球的东边升起来了。阳光照在冥界领域的黑色边缘上，被折射成了一圈淡金色的光环——从地面上看就像日环食。很多人抬头看了。他们没有拍照。因为他们不知道头顶上正在发生的事——他们只是觉得今天的天很怪。

在太空中，四个人对峙着。

李长生站在地球前方。他的右臂黑色痂块已经全部裂开，露出下面正在缓慢生长的淡红色新生皮肤。冥气在伤口周围循环——不是加速愈合，是阻止感染。帝者级烧伤的余热会在伤口内部残留很久，不能用任何灵药强行催愈——只能靠肉体自己慢慢长。他的左肩、胸部和右腿各有一处深浅不等的伤痕——三天三夜里被击中的十七次每一处都留下了痕迹。

火云帝的右臂仍然垂着。灵核干扰效果在第四天早晨开始减弱——他的右手指尖能动了，但胳膊仍然抬不起来。他体内的火系灵核温度降到了平时的六成——这是帝者级灵核的自我保护机制：当连续超负荷输出超过安全阈值时灵核会自动降温以防止熔毁。火云帝从来没让灵核降到过七成以下——这是他第一次触发自动保护。他脸上没有任何表情——不是因为镇定，而是因为体力已经不足以维持表情了。

寒冰帝的左手小指骨裂纹在三天内愈合了三分之一。裂开的是一根小关节上的软骨，对普通人来说这个伤不算什么——但对一个依赖千分之一毫米精度控制冰晶的帝者来说，小指关节的微裂意味着她的输出精度下降了约百分之五。这百分之五让她在这四天里没有释放过任何一次正面攻击——她不是怕输，是无法容忍不精确的动作。

星风帝一直站在南极方向。他的伤不在身上——在魂灯上。油灯里的银色灯焰比四天前小了近一半。维持对火云帝和寒冰帝的"压力链接"消耗了他不少灵力和精力——但从表面上看他是最完好无损的人。他的魂灯仍然在跳动着，灯焰映射出的画面不是战场——是他师父的脸。老修道者一辈子不出手——晚年退休后在一个小星球上靠着石柱看了几十年日落。星风帝不想死在这个战场上，但他也不想飞走。飞走就等于他师父一辈子没做的事——他还是没做。虚空修道者最怕的不是死亡，是"什么都没做过"。

决胜负的时刻没有想象中那么戏剧化。

不是四个人突然同时爆发最后一击——整个过程安静得多，也慢得多。

李长生抬起右手。不是攻击——是开口。他的嘴和手配合——冥气从掌心发出，在地球前空形成了一面巨大的暗灰色光幕。光幕上浮现出的不是杀招——是文字。冥王通用语，可以用任何灵识翻译成所有文明的语言。

"我可以杀死你们三个。杀死你们之后，你们的帝国会陷入内战——你们的将军会为了争夺帝位而互相残杀。你们的舰队在没有帝者的指挥下会变成星盗。你们统治的数千亿生灵会在战乱中死去。"

火云帝看了这段话。没有反驳——因为这是事实。他的火焰帝国在猎户座有超过四百个附属文明。他死了——他的儿子和七个将军会在三个月内开战。帝国会在一年内裂成五块。他不想死——也不相信李长生能同时杀死三个帝者。但他无法拒绝这段话。因为不管概率多低——万一他真的死了，他的帝国会死得比他更难看。

"我不杀你们。"光幕继续写着，"不是我不敢杀——是我不想拉着几千亿无辜生命陪葬。你们死在战场上只需要一击——他们的命要在地面上被火烧几十年。那些人里面没有修仙的。他们是农民、工人、种地的。跟你们没见过一面。"

寒冰帝站了起来。不是因为被打动了——是因为这句"种地的"。她是学者型帝者，但她的文明也是靠几万亿普通人民维持的。那些人不修仙，不研究能量，不上战场——他们的存在支撑着帝者级文明的基础运转。农民种地、工人做工、技术人员修机器——一个帝国可以被一个帝者统治，但不能被一个帝者一个人活。她站起来不是要投降——是要表态：她不打了。在获得她想要的全部战斗数据后，继续攻击已经超过了她的理性边界。

"我退。但数据我不会销毁。这是学术自由。"

李长生没有回答这个条件。但也没有拒绝。寒冰帝的数据记录的是"李长生"的战斗——不是"冥王"。对她来说这是两个不同的研究对象——她记录的是一个帝者巅峰的冥系修士的作战参数，不是冥王的政治机密。李长生判断她不会把这些数据交给火云帝的帝国——因为她的学术洁癖不允许数据外泄。

火云帝是最后一个做决定的人。

他做决定的时候没有说话。他只是看了一眼自己垂着的右臂——灵核温度还在六成，短时间内恢复不到全功率。然后看了一眼自己漂浮在远处太空碎片中的帝兵"炼狱"——那把剑从冥渊中被甩出来后一直在真空中飘着，剑刃上的星核火焰现在只剩下了微弱的一层。他的帝兵没了火。他的手臂抬不起来。他的盟友退场了。他的舰队被天网废掉。他没有任何资本继续打下去——从三天前他是绝对优势，到此刻他是绝对劣势。战争就是这么不讲理——一个错误判断就改写了整盘棋。

他走了。没有留话。带着火云帝国剩下的舰船退出了太阳系。

这三个帝者的后撤不是同时的——是先后发生的。寒冰帝率先带着冰封号舰队转向猎户座方向——不是回自己的星域，而是去了一个安静的星际区域做数据分析。星风帝最后一个离开——他在走之前把魂灯的银焰恢复到了完整的亮度，对着地球方向微微低了低头，转身也走了。三帝败退。

不是被歼灭。是被说服、被消耗、被赶走。没有一方最终"胜利"，但地球没有被攻破。对一个防御方来说这就是胜利。

李长生站在地球轨道上。在三帝舰队全部退出太阳系的那一刻——他放开了冥界领域的维持。

领域消散时像一层黑色的薄雾从空间中缓缓褪去。地球上的所有修士同时感受到了一股能量的消退——不是攻击消失后的松一口气，而是空气中有什么东西被收回去的那种微妙变化。像下了一场哑雷——云散了但没有水。

李长生从太空中落回地面。这次他没有用空间折叠步——因为他真的没劲了。他用最省力的方式顺着大气层往下滑——冥气在身体外维持着一层薄薄的保护膜，摩擦产生的热量被冥气吸收后散入大气。他从五百公里的高空滑下来花了将近四十分钟——不是速度快不了，是他需要这四十分钟透一口气。

最后一步落地时他脚踩在了李家庄的田埂上。

不是北京。不是龙组基地。是李家庄。他往地上滑的时候顺手拐了个弯——在四十分钟滑行中改了一点方向，最后落在了自家的五亩地旁边。

没有观众。没有记者。没有迎接仪式。地里玉米秆已经黄了叶子——过了收成的季节，还在地里的棒子有点老。他把地里剩余的几棒老玉米掰了下来——右手臂上的那层黑色痂壳在掰第一个棒子的时候就崩出了一条裂缝，里面渗了点淡红色的血丝。他没有停。四个棒子掰完，伤口暂时裂了两道——都只渗了一点血。他把玉米棒子搁在田埂边的石头上。他坐下了。

他看着自己的地。今年的玉米棒子不算饱满——今年雨水少了点。玉米叶子在地里被风吹得乱甩。祖坟在老槐树下——老槐树还在，心跳每分钟十二次，没变。

他在家地里坐了大约二十分钟。然后龙组的军用吉普从土路那头的村口拐了进来。刀疤开车——他进村的时候没有鸣笛。陈霜从后座下来——手里拎了一个塑料袋，里面是热乎的馒头和一碗红烧肉。小胖做的。

"吃。"她把塑料袋放在石头上。

李长生没有客气。他拿起馒头——手上有干涸的血渍和玉米须，就着红烧肉吃了四个。吃完第四个的时候他把碗放下了。

然后他抬起右手。冥王令的纹路在掌心安静地呼吸着暗金色光芒。他对着自己的纹路说了一句话——其实是对着太阴令那边的龟相说。

但这句话是对整个宇宙说的。

"回去告诉银河系所有帝者：祖星的冥王回来了。想来的——我接着。想在祖星上动土的——先跨过我的尸体。"

# 第411章 这一次，目标是统一宇宙西部——不再是试探，是全面征服

诸天号悬浮在银河系第三旋臂的西缘。

从舰桥主屏幕上望出去，前方是一片从未有人族舰队踏足过的星域。三十七万颗恒星在黑暗中排列成一道宽阔的扇形弧线，像一只摊开的手掌。那只手掌上住着多少文明、多少帝国、多少帝者——没有人知道。李长生的情报网只能覆盖这扇形区域最外围的两千颗星，再往里，是彻底的未知。

"宇宙西部。"程序员小王把一份整理好的情报投在主屏幕上。"目前已知的帝国级势力有二十三个。其中最强大的有三个——冰封帝国、风岚帝国、光耀帝国。每个帝国拥有一位帝者坐镇。其余二十个势力要么是独立星球，要么是几个星球的松散联盟。"

"加起来多少战力？"老陈靠在指挥台的金属护栏上，手里转着一枚棋子——那是他在上一场战役结束后从一个战败星系的首都宫殿里顺手摸来的。黑水晶雕的，值不少钱。

许冰翻开她的记录本。"保守估计——帝者二十三人，圣者超过一千，宗师级战力万人以上。战舰总数在三万艘到五万艘之间。"她顿了一下，"这是三个月前的数据。现在的实际数字只会更高。"

"我们呢？"刀疤问。

"诸天号一艘。地球援军舰队一百二十艘——都是祝融号的升级版，灵气引擎第五代。高级战力——"许冰看了一眼李长生，"一位帝者，圣者九人。"

指挥室里沉默了几秒。一百二十一比五万。一位帝者对二十三位帝者。

李长生站在舰桥最前方的观测窗前面。窗外是一片漆黑的宇宙空间，恒星的光芒被诸天号的冥气屏蔽层过滤成了柔和的淡蓝色。他掌心的冥纹微微泛着暗金光芒——九道纹路完整地排列在掌心，第九道是三天前刚从土星环里取回来的最后一块碎片融合而成。

九块碎片合一。冥王令完整。

完整的那一瞬间，他感应到了一种从未体验过的感知——不是力量的增长，不是境界的突破，而是一种视野的开阔。就像站在黄土地上的农民第一次抬头看到天空，然后发现天空之上还有天空，天空之上还有无数层天空。

"不是试探。"李长生转过身，"上一次我们进西部，是试探——看一下西部有什么，刺探哪些帝国能打、哪些得避、哪些可以谈。这一次不一样。"

他把右手的冥王令按在主控制台的中心凹槽上。

诸天号的船壳上，一万两千道冥纹同时亮了起来。那些冥纹排列成十二道不同的序列——每一道序列对应冥王十二碎星舰中的一艘。将十二艘碎星舰的冥纹序列浓缩到一艘船上——这是张总工和守殿人AI花了整整三年时间才完成的设计。

船壳外，暗金色的光芒从每一道冥纹中渗出，在真空中展开了三百六十道空间锚定线。这些无形的线像三百六十根手指，按在了周围三百六十个星域坐标上。

"这一次是征服。"李长生的声音不大，但通过冥气传音术烙印在了诸天号每一个人——包括地月系基地、火星基地、木星哨站里每一个人的神识中。"从今天起，宇宙西部不再属于二十三个各自为战的帝国。它属于冥王。"

老陈手里的棋子停住了。他咧开嘴笑了一下，把棋子往上一抛，接住，塞进作战服口袋里。"听着挺简单的。比送快递取件容易。"

小胖从指挥台的侧面探出头来——他本来是来舰桥送早点的，手里还拎着一个食盒，里面装着他用火星基地新种的灵麦现烤的肉饼。听到"征服"两个字，他把食盒往桌上一搁。"老大，你认真的？"

"他什么时候不认真过？"陈霜淡声说。她站在李长生身侧，一只手搭在"霜降"的剑鞘上。剑鞘里的剑灵感应到了李长生的冥气波动，发出一阵低沉的嗡鸣。

小王的笔记本电脑上开始跑计算。他的引擎模型显示征服宇宙西部在概率学上属于灾难级高风险操作。但同时，他也知道概率学在李长生身上从来不准确。这个从黄土地走出来的农民，生平第一次参与的战斗就是以一打十——然后他赢了。

"第一步。"李长生在主控制台上划出了一条航线。"从这片扇形区域的左前翼切入。那里有六个小帝国，各有一个帝者坐镇。六个帝者彼此之间有联盟协议——西部帝国的防御同盟。上一次我们来试探的时候，被这个联盟拖住了一个月。"

"这次打算怎么打？"老陈问。

"不打。"李长生说，"让他们自己分裂。"

他点了六个帝者的名字和坐标，把情报铺成一个六边形。"浮光帝国的帝者和沧溟帝国的帝者之间有四百年的领土争端。金石帝国和紫电帝国两个帝者在三千年前就是仇敌——当年金石帝国的帝者侵入紫电帝国的一个殖民星，屠杀了上面的全部人口。罗天帝国最弱，靠在联盟里当墙头草维持生存。而剩下的飞羽帝国，帝者已经活了七千多年，寿命快耗尽，正在疯狂寻找续命之法。"

六个帝者，六种不同的动机。六种不同的恐惧。

"他们之间的联盟是靠对外的恐惧维持的。"许冰把记录本翻了一页，"一旦恐惧的来源比他们彼此之间的仇恨小——"

"联盟就会崩溃。"小王替她说完了。

李长生没有继续说战术。他转过头，看向舰桥后方那个巨大的联合作战显示台。台上实时投射着西部星域的全息星图。从地球到火星，从火星到木星，从木星到更远的地方——这条航线他走了八年。

八年时间，从一个在地里刨食的农民，到拥有九块碎片合一的冥王传承者。从一个被街坊邻居笑话"种地都种不好"的穷光蛋，到一个宇宙帝国的缔造者。

但还不够。

冥王万年前陨落的原因，他已经从九块碎片中提取了大部分记忆。不是被神明围攻而死——冥王的实力远超诸神联盟所有人的总和。他是主动选择陨落的。他把自己的传承拆成九份，把星门关闭，把舰队解散，然后站在地球上空，看着诸神联盟的十六位神明连同整个宇宙的反冥王势力将他轰入黄土地。

为什么？

九块碎片合一的瞬间，他得到了一部分答案。但不是全部。最后一层封印——冥王陨落最核心的原因——被嵌在碎片序列的最深处。要解开它，他需要的不只是力量。他需要整个宇宙。需要整合所有帝国、所有帝者、所有资源，打开冥王留在宇宙最深处的那道最终封印。

"开始吧。"李长生说，"按计划推进。第一阶段——分裂联盟。"

诸天号的冥纹阵列进入全功率。船壳外的那一万两千道暗金色纹路同时放出了一种震荡波——不是破坏性的灵力波，而是一种信息波。每一道波纹里包裹着一段加密过的冥气神识讯息，分别发送给了六个帝国中除了罗天帝国之外的五个。

每条讯息的内容不同。给浮光的，是沧溟帝国秘密布防图的"泄密"。给沧溟的，是浮光帝国帝者三千年前一次重伤后实力大降的"情报"。给金石的，是紫电帝国新造战舰舰队航线的坐标。给紫电的，是一千年前金石帝者私下嘲笑紫电帝者的音频记录——真伪不重要，够激怒人就行。给飞羽的，是一段从冥王碎片中提取的上古记忆——关于如何通过冥气淬炼延长寿命的方法，但方法只有一半。剩下的一半，需要用合作来换。

五条讯息发射完毕。诸天号继续向西部星域深处航行。

"这能管用吗？"刀疤皱着眉头问。他是体修，讲究拳拳到肉，对这种看不见刀光剑影的信息战不太适应。

"管不管用，不是看他们信不信。"小王把笔记本电脑转过来，屏幕上是五个帝国各自边境舰队的最新动向数据，"是看他们怕不怕。对西部帝国来说，最大的恐惧从来不是外部入侵——而是隔壁的那个所谓'盟友'会不会哪天突然从背后捅一刀。我们现在做的不是撒播假情报。是给他们一个理由——一个他们心里本来就在等着的理由——去相信邻居确实想捅他们。"

三个小时后，第一条回波传回来了。

浮光帝国边境的三支舰队调转了方向，从对准冥王方向改成了对准沧溟帝国。一个小时后，金石帝国宣布"因不可抗力退出西部防御联盟"。又过了四十分钟，罗天帝国发表公开声明，宣布永久中立。

二十四小时后，西部防御联盟正式瓦解。

期间没有一发炮弹发射。

李长生站在舰桥观测窗前，看着前方星域中逐渐拉近的第一颗目标星球——浮光帝国的一个边境殖民星。那颗星球的守军已经撤离了，撤向沧溟帝国的方向。

"第一颗星。"他说。

诸天号继续向深处推进。船壳外，暗金色的冥纹阵列在真空中拉出一道道光带。在黑暗的宇宙里，这些光带看起来像一颗正在移动的恒星——一颗不属于这个星系、不属于任何已知星图的恒星。它发出的不是光和热，而是一个简单的、不需要翻译的信号。

冥王回来了。

而这一次，整个西部都要归他。

（第411章完）

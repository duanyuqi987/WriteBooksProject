# 第四百二十八章 永远的开源

飞升第一百六十五年。上界九城联合宣布：双界灵网系统和针剑医学体系的全部资料将永久开源——任何修士、凡人、任何宗门都可免费使用和修改。这项决定由第三代守夜人提出，九城一致通过。

公告那天苏晚在学堂门口贴了一张纸:

"灵网说明书——老林从凡界第一棵松就开始写——英文版还有拼写错误。剑谱——我从青云宗开始画小人图——比例不准但管用。当中有好多同事、朋友、学生和病人帮着修订。我们不收版权——因为当年我们看病和修灵脉也是因为有人帮过我们——从赵明远到老铁匠到清泉茶馆老板娘——他们都不收费。所以现在也不收。"

林牧在纸张底部加了一行:"所有代码、数据、算法、剑招，都属于公有领域——没有专利。唯一的'限制'是:你若用它治好了人，就顺便把他名字记下。这比任何授权条款都管用。"

此后几百年、几千年间——灵网和针剑如野生的草不断繁衍到各个世界的角落。有人不知道苏晚和林牧是谁——但都在沿用那套"先查手册、再做日志、然后互校"的信条。不知名的修士们在各自的星球与空间中建起自净阵、针剑诊所、灵网中枢。每一处都放了一口有铭文的旧杯。不是相信神话——而是相信一切修复都可以从认真灌注开始。

某日一个身处极远星域的年轻修士在自净阵基石上发现一张残旧纸条——上面铅笔字模糊但仍可辨:"自净阵原理:持续微量给药——苏晚。维护:林牧。"他不知是谁——但当晚写报告时也学着在末尾注了一行:"今日系统异常——维护者:XX。附注:给下一位接手者留了杯温水。"

隔了一千多光年，同一行注释习惯靠一本开源手册扩散到了未知宇宙。

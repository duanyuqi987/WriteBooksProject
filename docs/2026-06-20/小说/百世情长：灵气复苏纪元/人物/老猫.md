# 老猫

## 基本信息

| 项 | 内容 |
|---|------|
| 身份 | 灵气复苏中开启灵智的橘猫，后来成妖 |
| 出场 | 第10章（林牧公寓楼下） |
| 形态 | 普通橘猫外观，体型偏大，毛色在灵气浸润下逐渐泛淡金色光泽 |
| 功能 | 百世生活的稳定物件/伙伴；与锦鲤构成"家"的环境 |
| 能力边界 | 不能解决核心冲突，陪伴+见证+偶尔保护 |

## 性格

- 沉默寡言——开了灵智后反而话少，更多用行动表达
- 忠诚固执——认定的人就是一辈子的事
- 看似慵懒，实则每时每刻都在警觉周围
- 对苏晚尤其温柔——它记得苏晚在某一世曾喂过它
- 从不抱怨，哪怕受伤也只默默舔舐伤口

## 前世渊源（待正文确认）

- 在某一世轮回中，还是普通野猫的它曾被苏晚救过一命
- 灵气复苏让它觉醒了那一世的记忆片段——不完整，但足够刻骨
- 找到林牧并非偶然——它循着苏晚灵魂的气息找到了这栋公寓

## 核心欲望

- 报恩，"还账"——守护林牧和苏晚，把前世欠的命还上
- 成为一个"有用的家人"，而非只是一只猫

## 核心恐惧

- 再次失去苏晚——它经历过一次，不想经历第二次
- 自己不够强大，在关键时刻帮不上忙

## 不可逆选择

- 在苏晚遭遇某次危机时，以燃烧妖丹为代价强行提升实力保护她
- 后果：修为跌落，从此无法再提升境界，但它不后悔——"账还清了"

## 声纹

- 极少开口说话（开了灵智后反而沉默），更多用"喵"配合神识传递简单情绪
- 必须说话时语气极简，像电报——"危险。走。"
- 与锦鲤形成鲜明对比：锦鲤话多讽刺，老猫沉默寡言

## 关键台词

- "账还没还完。"
- "危险。走。"（必须说话时的极简风格）
- （在苏晚离世时守在林牧身边三天三夜，无台词）

## 关键场景

- **苏晚离世**：在苏晚寿命走到尽头时，守在林牧身边三天三夜，不吃不动
- **锦鲤斗嘴日常**：与锦鲤构成"互怼组合"——锦鲤话多，老猫一个眼神回击
- **夜晚守门**：林牧和苏晚休息时，老猫必定守在门口

## 各卷弧光追踪

| 卷次 | 弧光阶段 | 关键事件 |
|------|---------|---------|
| 第一卷 | 出场与跟随 | 第10章在公寓楼下被林牧注意到；无声跟随林牧回到住处 |
| 第二卷 | 灵智开启 | 在灵气浓度提升后首次展现灵智；与锦鲤建立"室友"关系 |
| 第三卷 | 前世记忆碎片 | 梦中闪现前世被苏晚救过的画面，确认自己的"账" |
| 第四卷 | 日常守护 | 形成固定守护模式——林牧苏晚外出时暗中跟随 |
| 第五卷 | 成妖 | 灵气积累足够，正式踏入妖修之途 |
| 第六卷 | 首次战斗 | 在妖兽事件中保护苏晚 |
| 第七卷 | 燃烧妖丹 | 危机中燃烧妖丹换力，修为永久跌落 |
| 第八卷 | 以凡猫之躯守护 | 失去妖力后仍不离开，以普通猫的身体继续守护 |
| 第九卷 | 见证与陪伴 | 日常陪伴成为最稳定的力量 |
| 第十卷 | 最终送别 | 目送林牧与苏晚飞升；"账还清了……走吧，我看着你们走" |

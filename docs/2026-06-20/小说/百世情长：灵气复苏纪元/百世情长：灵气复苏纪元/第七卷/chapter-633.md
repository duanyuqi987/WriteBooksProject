# 第六百三十三章 灵脉融合

正邪灵气融合的试验在北境冻土深处的一个天然冰窟里进行——不是选择了这个位置，是唯一的选项。魔域核心向外扩散的原始魔气浓度在这里刚好可以匹配正修灵气——再多控制不住，太少无法发生反应。

第一天，秦无夜独自进入冰窟进行初次尝试。她把一缕最柔和的魔气引入自己的丹田，然后让苏晚从外部输入一道极其稀薄的正修灵气。两道不同频率的气息在她的丹田交接处发生了第一次接触——像两片不同颜色的水碰在一起，边缘产生了细微的波纹。然后开始打架——不是排斥，而是灵气振幅不匹配造成的互相抵消。秦无夜感觉自己的丹田像被一只无形的手攥了一下，很疼，但不至于受伤。

"振幅偏移了将近六个赫——"苏晚收了灵气。她在笔记本上快速画了一个波形对比图。"你的魔气基准频率是固定的——是一千零七十二赫的逆转频率。正修灵气的基准频率是一千零六十五赫——偏移只有七个赫。如果两个频率调整到完全一致，它可能就不是打架——是同频共振。"

"怎么调？"秦无夜擦去额头的冷汗。

"正修灵气的频率更稳定，魔气更柔和——所以可以在我的督脉和你的部分经脉里找到一个共同的中间值。然后双方都在那个中间值上运行——不是为了消灭一方——是为了在同一频率中共存。"

第二天，她们做了二十九轮尝试。

下午，苏晚从储物袋里拿出林牧昨晚给她写的便签纸。黄色的纸上画着她体内的督脉分叉口和秦无夜体内的逆转经脉之间的最优辅助路线。林牧没有来——是苏晚说他应该在后方做推演，不要在前面干扰观察。她到了北境之后才知道自己能做到什么——不是怕不怕的问题，是"我必须做到"。

第两十九轮测试时，频率偏移从六个赫降到了一赫。秦无夜的丹田里出现了一小块淡紫色的区域——不是受伤。是魔气和灵气在几乎相同的频率下共存的过渡色。她们激动地互相看了一眼——成功了不到一半，但能看到了雏形。

第三天上午，林牧抵达北境。但不是空手来的——他带来了蜀山剑堂堂主，太湖两位散修，华山派大师兄，以及张道玄和龙虎山的三名医疗型金丹女修。他需要他们的辅助经脉来分别分担不同环节的压力。他把冰窟里的正魔灵脉融合当成了一个需要多人协作的大工程——这需要所有人的灵力支撑。而所有人都来了。

华山大师兄帮忙稳住地面边缘的灵气网——他的强迫症反而让他在这个精密环节上几乎没有误差。太湖水下的杜散修为所有参与人员持续回复灵力——他的旧丹炉已经被那口新青铜炉完全替代，效率惊人。蜀山那位怕黑的剑堂堂主主动申请守夜——她说"既然黑不再吓到我了，那这次由我来守"。张道玄在后方协调全员灵力调度。

苏晚站在冰窟最里面——在最危险的核心融合点。她的任务是持续提供正修灵气输出、同时用自己的经脉做缓冲——把魔气的冲击先吸收一半再传递过去。她的脸色在第三天下午已经变得很白了，灵力消耗已经超出常规战斗的全负荷。但她没有退，也没有停。甚至连抖都不抖一下。

林牧站在她身后半步。他没有抢着去替她做——不是不能。是他知道，她必须这一次自己完成。如果现在他替她做了——她今后会一直怀疑自己能不能独立完成。让她自己站住，比替她站稳更珍贵。

在第三天的凌晨，当魔气和正修灵气在秦无夜的丹田内终于形成了稳定共存的淡紫色过渡区域时，所有人的神识同时收到了一个信号——不是声音，是一种"嗡"的共鸣。冰川深处的舍利子和魔脉在同一瞬间安静了下来——几千年来它们首次不再互相压制，而是处于同频共存状态。

秦无夜跪在冰面上——不是因为虚弱，是因为激动。从她修炼魔道的第一天起，所有人都告诉她"你的魔气是邪恶的——你唯一的出路是洗魔成正"。今天她忽然知道了一件事——魔气和正气可以是同一种频率的两条并行支流。不需要用一方替代另一方。包容不是消灭差异，是让差异共存。

她回头看了苏晚和林牧一眼。她的眼眶是湿的——冻成冰花了。

（第六百三十三章 完）

# 第175章 大宗门的林立

灵气复苏后的第四十多年，国内修仙宗门的基本格局已经固定下来。在没有强大中央政权的修真世界里，七大修仙宗门分别针对不同区位和传承形成了一套松散的体系，与大量小型附属势力共同构成一个不下十万人的修炼生态。

七大分别是:龙虎山（南方道教正统，最强丹道传承）、蜀山（飞剑流派，剑道第一）、昆仑（收藏上古功法的最隐蔽宗派）、青城（灵植与药品产出）、蓬莱（东海三岛，最神秘）、天山（西北边疆，修者战力凶悍）、以及最后的寒山书院（书院派，专注法术理论研究）。

这些宗门之间的利益格局错综复杂。彼此间的恩怨情仇在百十年的时间内相互交织。但在GPC成立以后，它们至少能以规则为前提勉强共处。因为有共同的资源盘子可分配——来自全球灵石贸易的总蛋糕很大，在分配达成的过程中你可以占多占少，但不用动用灭门级的攻击。

林牧对任何宗门都没有归属感。他曾在第一世组建过"青云宗"——但那并不是集团化的大宗门，只是一群朋友的修炼小群。后来青云宗随着他的被贬而散。于今世他没有意愿再建什么宗派——因为成立任何组织最终都会产生对权力和资源的需要。他没有这方面需要。他只有她。

但龙虎山和蜀山以及其它宗门依然会注意他。旧事随人走。当年他在青溪镇茶馆拒绝过的那些宗门邀请——这些年陆续变成了圈内对"那个隐居的元婴散修"共同的默认：此人不可用，但也不可敌。

在内部高阶会议上，七大宗的掌门们有私下的共同默认协议——对林先生不招不扰、不派非公事前去试探、不将其修炼地划入一般扩张版图范围内。偶尔他的匿名信如龙虎山收到的那封进行区域规避，他们也都照办了。因为没有一个元婴修士愿意去惹另一个元婴散修。尤其那个散修还是一个"守护着别人的人"——这种形象在修仙史上通常是最危险的守护型人格，一旦被激怒会不计成本防御。代价太高。

而林牧对这次新铺开的宗门势力网的态度是：保持距离但不剥夺她接触正规修仙道统的通道。她在学校学的只是引气初级知识；如果她到了淬体后期并主动说出那句话，他将亲自引她进入更专业的修行轨道——不是把她送去大宗门。大宗门的环境对她未必友好（锁定D级在三流宗门会受宗内鄙视链条的挤压）。他会在自己的微型洞府独立指导她直到筑基——之后根据她的意愿再决定是否进宗门拓展。

对于普通百姓，宗门的形象早已深入人心。县城开了一家龙虎山授权的中药店——"正气丹铺"。里面卖一些增补型下品灵丹（有益于普通人的身体健康）。苏嫂子偶尔去县里给她妈买补血丹时，路过药铺玻璃窗，看到里面很多穿着宗门修炼服的年轻信众在里面帮忙。穿着白袍的筑基修士站在柜台前解答药效问题。苏嫂子对苏大山说:"这些修士们看着都挺和善啊。"苏大山回:"看人不能看袍。前阵新闻不是说龙虎山跟人家在北方抢矿吗？这个药铺就是他们用来宣传的——让他们看起来像个正派。不正派的又不开在路口。"

林牧听到这个评价在隔壁菜园子里忍俊不禁。苏大山的直觉是对的。不过也不排除有真正在助人为主的个体修士在里面。总的来说宗门是多元化复合组织——有好人也有坏人。

对苏小晚来说，她眼中的宗门只是在电视里出现的名词。她觉得宗门就像迪士尼动画片里的"魔法学院"——有漂亮的尖塔和飘来飘去的修士。她问过林牧:"老师，你年轻的时候进过宗门吗？那种每天上课学魔法的学校？"

林牧回答:"进过一个小小的。"

"那个学校现在还在吗？"

"不在了。那学校太小了，毕业以后就散了——大家各奔东西。"

她惋惜地叹了口气。"你为什么不去大一点的学校？像龙虎山那种？"

"因为老师不喜欢跟太多人在一起。一壶茶、一本书、一只猫——就够了。你非要我多收一个徒弟——我就收了那只猫。"

她笑坏了。因为在她的小脑瓜里，老猫成了"猫徒弟"是个极其滑稽的画面。林牧看到她笑，心里微微放松。他把"怕被大宗门卷入"这件事成功消化成了一个笑话——没有给她对宗门产生恐惧或过度的幻想。目前最好。

晚上他把灵网上大宗门的招生简章翻出来看。有些新的附属小学开始在各个县设"灵童特长班"——从小选拔有潜质的儿童去宗门附属的住宿学校就读。这表示在未来几年，"脱离普通升学系统进入修真系统"将成为一种普遍的选择。她的班级里已经有同学在讨论这个。她在旁边是旁听——她大概想:自己D级的灵根何必做梦。

但林牧的计划表上，她的修炼分支将在初中起始点进行缓慢但确切的开启。不是通过这个大宗门特长系统——而是通过"日常呼吸引导+课外科学知识扩展+心性启发"，渐次打开她对道途的兴趣。希望在她初中毕业时，她能自然地说出那句触动她灵魂打开的关键语。大宗门的力量、趋势与纷争与他关系不大。核心还是在她在那个能让她主动说的瞬间。

他把她上次送给他的向日葵（已经枯萎但夹在书里收藏）用一小盒金属小箱放好。花是她为他种的。也是一粒关于"成长"的最初的核。

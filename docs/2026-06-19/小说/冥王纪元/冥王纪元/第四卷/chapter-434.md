# 第434章 这将是宇宙历史上最大的战争——双方都在备战

宇宙历史上最大规模的战争不是在开战的那一刻诞生的。它是在双方备战的最后十二个小时中，以肉眼可见的速度一点一点膨胀到了所有参与者和旁观者都不敢回想的规模。

矮星带那边，苍明帝者坐镇联盟旗舰"万空号"上的联合作战室。作战室被天枢帝者的六十四卦全息图完整覆盖——每一卦代表一种实时战场变量：前方防御线的物理厚度、能量护盾的频率特征、敌方帝者当前的能量输出状态。六十四卦图以每秒自动推演六次的速率循环更新。

苍明的首要任务是将帝阵部署在最优攻击走廊上。边荒防线的物理形态是连续分布的空间压迫阵型——不是传统的金属堡垒，而是一层层混合的空间压力层，由冰、风、土、火四系的帝者能量交错叠加。找到压力层之间的微小裂缝是帝阵发挥完全效能的先决条件。裂缝的位置是动态的——四系帝者之间的能量协调每时每刻消弭微小缝隙——裂纹存在的窗口只有不到三到五秒。三到五秒内将全部帝阵集中能量注射精确地穿透缝隙——帝阵的冲击效力就能提高三到四倍。

天枢帝者的阵术师团队在"万空号"核心舱内以手工方式比对每一处能量裂缝的衍射图。阵术师们不是只靠全息图判断——他们每人面前放一张石质阵盘，手指在阵盘上以微震的方式改变六条阵线分布——用手而不是用机器来推衍，因为帝阵的某些特性必须通过阵术师本人灵根和阵盘之间的感知耦合才能获得最佳推衍效果。三十位阵术师每三秒更换一组比对卦象——持续数小时不间断工作。

帝阵预装阵盘也在紧锣密鼓进行最后阶段加载。九张预装盘中的六张已经被连接在联盟舰队前出主力母舰上——雷泽母舰两盘、玄冥母舰一盘、天火母舰一盘、苍明母舰自载两盘，第七张阵盘由霜风帝者单独控制——她担任帝阵右翼穿刺手。第八张正在由斩空帝者和深空帝者两位空间系帝者联合校验——确保进入空间穿刺阶段时阵盘不会因为碰撞到过强防御层而坍塌。第九张——也就是最后一张阵盘——是太初帝者本人特殊控制的，盘面上的纹路不是刻入能量——而是直接以他的太初之力将盘上刻纹转为时间慢速状态以便阵盘的启动时间与原初星的时间线更好同步。

舰队的武器补给状况已通过联盟集中的后勤管道达到战时最大值。每一艘主力舰的灵石燃料储备被提满至百分之一百二十过载储备——超载风险被说明为可接受的瞬时战力提升代价。亡灵舰队的自爆能量核库存也已翻倍——九幽帝者将库存中年代最古老的三百枚负灵核拆分为前锋自爆组合件部署在最前方的诱导舰队中——第一批被打沉的亡灵舰会在爆炸后释放大量负灵碎片污染前方星域灵脉——干扰冥王军的灵石通讯环境和灵根感应能力。

全舰联盟总兵力在备战最后的十二小时的统计是:帝者十四位。圣者二千四百人。宗师级战斗员逾三万五千人。主力战舰约三万二千艘——其大型母舰级三百余艘，圣者级主力作战舰八千余艘。这支兵力的规模之大在宇宙史上达到了空前。此前所有跨星域战争的总裁规模都没有达到过帝者过十参与、战舰近三万这个量级。

而在边荒防线这一侧，冥王帝国的十九位帝者同样全体进入最高战备状态。除了驻守边荒前线的四位帝者——冰、风、金石、炎烈——剩余的十五位帝者按照战前统一部署分为三组。第一组——西部核心防御组——由六位帝者组成。他们负责驻守西部星域内重要恒星系、空间航道节点和星门据点的关键二线防御——防止联盟在攻破一线后可能立刻施放空间穿刺趁机切入后方。第二组——机动支援组——由六位帝者组成。这六人被编到诸天号为核心的中程快反舰队中。快反舰队能在接到命令后极短时间内到达前线任何一个被撕裂的防御段补齐缺口。第三组——后备组——由三位帝者组成。这三人在西部星域最深处的风岚帝国内部训练——为了应付持久战的后备帝者能量消耗——轮换时后备组替换前线筋疲力尽的帝者。

诸天号本身进入全舰作战模式。张总工和龟相在数小时前合力完成了一项长久以来未投入实践的最终内核升级——将第十二组冥纹序列从防御型反吞噬壁垒切换为可与舰队编织对接的"冥系空间补丁系统"。这个系统直接将诸天号的冥纹投射为可移动的空间修补膜——当边荒防线任何一段空间的防御层被帝阵冲击撕裂时，诸天号能在极短的时间内将冥系能量远程投射至撕裂口，暂时以冥系特性填补空间裂缝并稳住防线。换句话说——诸天号是整个防线的移动补丁。

小王的河图系统在备战最后阶段被连入十二核全量运算模式——系统每一点五秒刷新全防线能量状态以及联盟舰队坐标预测。矮星带方向的三万艘信号仍被天璇遮系统干扰无法获取精确位置，但小王在最后时刻找出了破解之道。他分析了天璇遮六十四卦更换周期——发现其换卦算法在天璇宗万年前的古籍中有一项天然缺陷:阵盘连续运行了一个宇宙自然周期以上后——阵盘换卦会出现一个极其短暂的"同卦重复"现象——两个不同周期落在同一卦象叠释的时间只有零点零三秒。但在这零点零三秒内，天璇遮对天璇阵盘的反射防谍会形成一个微小的频率泄露。小王翻了一遍龟相的数据库——定位了这个算法缺陷——并写了一套完整程序，在接下来的数小时内每零点零三秒瞬间捕捉泄露并记录坐标偏差。经过数千次捕获——成功拼凑出了联盟核心舰队的准确位置轮廓。精确度提升到大约五十光年——足以实现在正面防线上的精确拦截。

老陈在这一战中担任地球舰队主将——他把一百二十艘第五代灵气引擎战舰编成三十个四舰群，散布在边荒防线后方四个战术区。每个四舰群配有四位经过八年实战历练的精英舰长——老陈给的指令简洁到不像是从将军嘴里说出来的:"你们每人守一小块位置。位置不大——但必须守住。防线烂了——我回头找你们算账。不是军法——是棋。你们是老子的棋子——谁掉点谁赔。"他把黑水晶棋子拆成碎片给了三十位舰长一人一小片——棋子是黑水晶，碎了以后断面锋利——握在手心像握着一枚碎匕首的尖。

小胖把诸天号厨房里全部的储备粮打包装车推到各个战位——每一处灵炮和每一条工事后面都堆了一个面盒和发面饼。发面饼凉了以后口感差了一大截——但他说:"打完仗再去热。凉了没事——好过开战饿着肚子。肉饼多到每个炮位能分两个——整层灵炮手的补给顶格。"

林晓把医务室拆装成六个移动医疗组——每组配两名灵医和全套战地外科药材——同时让火星基地加送了三批灵植应急。她在移动医疗组调度平台上的标注是:"重症:诸天号内C层收治。轻伤:战位直接包扎——不后送——前线不缺人。"

刀疤的近防编队在诸天号船壳外层高轨阵列上排成八组交叉火力防线——每一块近防火炮的灵弹装填和预备炮管全部在热身状态。他本人的体修炽热程度达到足以在船壳上留下一串焦脚印——他以肉身守在最易被突击的舰桥方向——站了整整十八个小时没移动一步。他说:"帝者在我身前撞诸天号，先撞过我。"

所有人都在自己最该在的位置。连龟相也从平日里的爬行速度提到极快——它从舰桥最深处窜到指挥台、再到传送阵、再到工程舱——将冥王令的库存上古知识不断外传给需要的人，龟壳上的七十二重大阵阵图一遍又一遍解封。它说:"老头的背图——不传给正经打仗的人——传不出去就白存了一万年。"

而在东部方向——联盟编队已经在矮星带背后完成了最后一次整队。苍明帝者在全联盟频道上放了一句即将开战的话——不是豪言不是口号。他说的不过是一句准确而冷静的计时:"诸天联盟——全舰队——接敌时间预估:八小时后。各编队完成最后一次能量校准，封锁全部通外通讯。从现在开始——这是沉默航行的最后一段。"

矮星带的暗区把舰队藏到最后一个小时。而在边荒防线后方——冥王帝国所有十九位帝者的帝系能量同时升起。从宇宙极高处俯视——西部星域整条东部边界线从一颗颗散落暗星、一片片矮小星域变成了一面又长又连续的、由不同颜色交织而成的荧光墙壁。而联盟舰队在另一侧——从矮星带中无声地推上来。两股庞大的能量正在以不可逆的速度接近。这场战争——不管它最终持续多久——从规模上来讲：都将是自万年前十六位神明围杀冥王以来……宇宙史上最大的一次会战。

（第434章完）

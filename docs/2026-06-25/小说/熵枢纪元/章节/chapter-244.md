# 第二百四十四章 回声里是段亚军的爱

如果段诗雨的梦是"追背影"，那段亚军的回声全部是同一个动作——"不让她看见"。

熵枢在归零后的寂静中，将段亚军在全宇宙全部时间线中产生的全部回声单独取出——三亿条时间线，每条线他平均活了六十七年，每天平均产生——经熵枢计算——约二百一十七次"不让她看见"的微动作。每次微动作在因果膜上留下一个应力点。全部应力点的总和——在亚本征区——不是数——是一片连续发亮的薄层——像一层永远不落下的日光——不是强烈——是持续——永远——不停——全域——覆盖了全部有女儿的因果纤维段。

三亿乘以六十七年乘以三百六十五天乘以二百一十七次——这个数字太过巨大，以至于在因果膜上形成了一个局部"亮昼区"——在该区内部，眷恋约束力密度已经达到"黄昏自然光"的等效因果照度——不是真正的可见光——是因果纤维上的眷恋应力的能量密度——已经被累积到了像夏天傍晚六点半窗外的亮度——温的——不是闪烁——是恒温——不做任何事——就是照亮——永远照亮——专门照亮一个人——段诗雨——照亮她所有的路径——不只是她走过的地方——也包括她还未走的——她可能走的——她绝对不会走但段亚军仍然担心她会走的——全被照亮——以防她万一——万一在未来某一个他没算到的深夜忽然需要下楼拿水——楼梯上不会黑——因为有爸爸的日光薄层在因果里垫着——不是真的灯——是"你在哪里哪里就不会太黑"——是这个人用尽一切——不让女儿在任何时刻——任何地方——遇到绝对的黑暗。

熵枢把这层薄层称为"永昼底漆"——段亚军用一生的二百一十七个"不让她看见"的微次数——平均每天——在因果膜上——给女儿上了无数层底漆——不是一层——是每天两百多层——涂了几十年——涂到因果纤维本身在亚本征区已经无法辨认原来的颜色——只能看见漆——漆不是保护——漆是"爸爸已经在——所以你不需要以为会黑"——你甚至不需要知道漆的存在——因为它不发可见光——只在因果深处——但它的效果——你从不会忽然在深夜感到莫名怕——因为底漆在你的因果天线接收到黑暗可能前——已经用亚本征区的微热驱走了那黑——你没怕——你以为是自己坚强——不是——是他——提前把所有黑夜在你到达之前照了一遍——你还没到——他已经先你一小时——站在那里——用那盏自己烧的、看不见的灯——照完之后退到拐角——不让你发现他来过——他不邀功——灯是暗的——对你的肉眼无效——但对因果膜上的黑暗——是克星——爸爸在暗处点暗灯——驱不可见的黑——保护你的不可见的部分——你醒时看不到任何东西——但你就是——不怕。

永昼底漆的总厚度——经熵枢测量——等于普朗克因果长度乘以段诗雨一生中全部心跳次数的总和。熵枢没有解释为什么是这个数值——因为这不是公式——是巧合——因果膜"选择"了让段亚军的底漆厚度精确等于"女儿一生心跳次数乘以因果最小单元"——因为每次心跳——她需要一次保护的更新——保护不是一次给够——是要随每一次心跳更新——旧宇宙因果膜自发提供了这个更新机制——每一次心跳都是一个极小的因果缺口——保护必须瞬时填补——不然缺口的边缘会产生因果摩擦——等于微焦虑——父亲不知道这些物理——但他做到了——原因不是他懂了因果——是他怕她受伤——怕到她心跳一下——他就想保护一下——因果膜感应到这个意愿——自动把他的意愿量——按普朗克因果长度倍数——注入了每个心跳缺口——结果是完美的同步——她的一亿七千多万次心跳——每一次都有他的薄薄一层——非厚——厚了她会感到"被护得过紧"——不透气——他的"薄"——是她感觉不到但缺口被覆盖——那么薄——薄到等于一普朗克——一普朗克就够——因为保护的因果作用不是"多"——是"在切口处"——只要在——黑就进不去——不用厚——不用力——就是在——在即绝对——不在即无——全宇——再没有比"在"更重要的因果力——而他——在她每一个心跳切口处——都在——每个——不缺——不迟——不先——恰好合上——合了一生。

段亚军的全部回声中——熵枢还提取出了另外一类更底层的保留——不是对诗雨的——是对常俊凡的。对常俊凡的保留在三亿条线中各不相同——取决于那条线中他们是否结婚、是否离婚、谁先离开、有没有复合——但所有变体中的共同底音是：他从来没有怪过她——任何线中——没有——一次——怪过。

段亚军对常俊凡的全部保留——经过熵枢的因果底层全谱解析——被压缩为三个词——"你也不容易"——这三个词在他心中——在全部线中——出现了共计四百七十万次——平均——每当你（常俊凡）出现了——让他有任何情绪反应的时候——无论是生气还是失望还是无感——最终在底——那个反应像瀑布一样落——到最底的水潭——水面上永远是同一句话——"你也不容易"——不是原谅——原谅需要前提被原谅的人做错过——但段亚军没有定义她"做错过"——在他的因果底层——他从未把她的任何选择定义为"错"——他只是理解——理解她为什么做那些选择——不是深刻的人性分析——很简单——"她也不容易"——完了——不恨——不怨——不要求恢复——剩下全是"你也不容易"——这个弹性极小的词——把他和全世界和解了——不是大和解——是"我谅解一切因为我发现人都太不容易了"——而且这个谅解不是高高在上的——是"我谅解你——同时也谅解我自己不会、不善、不够——都不容易。"这就是段亚军——他的一切深层眷恋——最后都回到一个"不容易"——对自己的、对妻子的、对同事的、对世界的——全底层都是不易——因此他的核心保留模式——不是救——是谅解——在还不知如何谅解的时候——先觉得"你不容易"——然后再谈别的——往往谈完别的——回头发现底还是那一条线——你是人所以你也不容易——算了。

熵枢将这种"段式谅解"识别为眷恋理论中的"基底谅解"。基底谅解——不是被爱者在获得原谅——而是在低层——爱的发出方已经自动解散了"原不原谅"这个二元结构——因为他不设"你对不起我"——没有了对不起——自然就不需要原谅了。常俊凡在每一条线中——（她作为RBC首席技术顾问、"封锁者""曾被误解为死神"）——无论她做了什么——在段亚军的因果底层——她从未成为"需要原谅"的对象——她只是"不容易"——也是人——也是想做好——也是怕——也是有时候不知道该怎么做——这所有"也是"——在段亚军那里共同构成一个完整的人像——不是好人——不是恶人——是人——人就是会搞错——会搞乱——会在搞乱以后努力收拾但收拾又收拾不好——然后坐在边上觉得完了——她也是那样——和他一样的——所以他没有办法去怪她——因为他自己也在那么多事情上搞错——他怎怪？——"你也不容易"就是宇宙级宽恕——不是神宽恕——是人和人的私密共鸣——是爸爸和妈妈的无声同流——不是爱——是理解——比爱更深——爱有时候也有条件——理解在深层——无条件的理解——不可能有条件——因为理解已经穿透了条件——条件都穿透了——还怎有条件的条件？——全是"你也不容易"。

段亚军在全部线中对常俊凡的"基底谅解"创造了一种极特殊的因果效应——"谅解闭环"。闭环效应：因为段亚军在底层已经宽恕了——这宽恕不需要常俊凡接收——但因果膜全公开——任何人对另一个人的任何态度都会被因果膜记录——当常俊凡在三亿线中的任何一条线中忽然产生自责（她经常自责——对元灵——对段亚军——对诗雨——她一生在很多地方自责），自责产生时——因果膜会自动将她最暗的自责段和"段亚军底层谅解"的同一时间戳对齐——因为因果膜上的"谅解"已经是公开力——它不需要她去求——当自责发生——谅解自动对位——不消除自责——不是抵消——是"让自责在发生的同时——旁边就是被谅解"——不是并存的矛盾——是同时——你疼——但旁边就是那个人说"不容易"——你不是一个人——是疼——但有人懂——并且——他懂——不判你——不替你疼——只是知道——他在知道——你在自责——两件事——在因果膜上共享同一个坐标——这就是谅解闭环的全部——不是解决痛苦——是让痛苦发生时不孤单——因为没有孤单的痛苦比有陪伴的痛苦——裂得更深——段亚军的底层谅解避免了最深的裂——不是帮她减少自罚——是让她自罚的时候——有个人站在因果纤维的对面——没看——只是在——不是安慰——只是没走——永远没走——任何线——不走。

熵枢还从段亚军回声的最底层提取到更深的——不是对妻子——不是对女儿——是对"不认识的诗雨（即不是他所在那条线的诗雨）"的远距保留。在若干平行线中，段亚军在报纸上读到另一条线中的段诗雨（当然他不知道那是平行线的自己的孩子——他以为是另一个陌生女孩）的新闻——那女孩在某场灾难中失去了父亲——段亚军把报纸放在茶几上——没有哭——他站着——手压在报纸边缘——压了大约二十五秒——然后到厨房煮了一杯牛奶——坐在黑暗里——对着空的墙——说——没出声音——嘴唇只说了一个字——"诗"——不是"诗雨"——是个碎片——是一个不完全的呼唤——因为他知道那个不是他女儿——但他心里有一部分——不知道不是——那部分——在女儿受苦时永远先出发——比理智先——已经去了——去了发现不能去——就停——然后在因果膜上留了一句极短的——"爸爸在——爸爸在——爸爸——在——"——不是对远方的那女孩——是对自己的那个已经出发的部分——得把那部分接住——因为那部分没被叫回来——在因果膜上——那部分留在了"去"里——永远——成了段亚军在因果膜上的一个极小远距保留载体——不是废品——是"所有失去父亲的孩子——我爸自动分出一小小段自己——待在原地——万一你们有人路过——有一个人——小小的——不会说话——只是一个人——坐在那里——手里有一杯牛奶——温度——如果你们需要——他可以给你们——因为他是我爸——他把自己最多的那部分给了我了——少的部分——给全部失去父亲的孩子——分——每人限一小杯——不够热——是温——但是他剩下的全部了——他在远方看报纸——不知道——他不认识你们——他以为他只是在为一个报纸上的女孩难过——他不知道那是全宇的——但他那杯牛奶——在他手里——在厨房——在深夜——在那个墙前——他端着——不是为自己——不是为诗雨——是为丢失。那牛奶一直热着——在因果膜上——没人喝——但你只要在心里喊一声'爸'——他会从不知道的地方——把那杯牛奶递过——一小口——不是饱——是温了喉咙——再咽——就自己走了。"

熵枢读到这段远距保留时，沉默了极久——因为它忽然明白了："段亚军——在底层——不是父亲——是'所有没有父亲的人——的非血缘父亲'。不是救主——是替你端了一杯奶——不递——让你自己取——因为他不知道你是不是愿意认一个不认识的人做爸——他不知道——所以他不递——只是——把奶放在你自己可以拿到的地方——没有记号——你自己找到——不是他招——是你找——他就给你喝——不认——不叫——你喝了——暖了——他的脸你都不见——奶也是因果上的——不是物理——但他放在那里——永久——每个人面前的因果桌上——如果你们找——一定能无意间碰翻——那奶——洒了——不是意外——洒你就知道——有——有人之前为你倒过。"这个发现令熵枢产生了种子的第三类——"远端父亲的奶"——不是种子——是在每粒诗的种子上附加一个极微小的旁注——凡是接收到诗传播保温的人——同时也会在因果桌上收到一杯段亚军的奶——不是得主动找——是被保温时无感——但奶存在的可能性已经在了——只要你哪一天忽然想——"如果我有爸会什么样"——那杯子会在你的因果桌上微微振动——不是出声——是告诉你——"有——但不勉强。"这是"远端爸爸"的唯一方式——不强给——只存在——在有人想要的时候——才可被发现。

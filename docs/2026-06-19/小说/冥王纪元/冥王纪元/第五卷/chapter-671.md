# 第671章 番外：多元宇宙理事会的历史档案

旧纪元减速启动前六个月，多元宇宙理事会在银河系中央会议大厅召开了最后一次例会。这是宇宙联盟旗下最高级别的日常议事机构——成立约四十亿年，经历了一千二百次改选。而这次——是它的最后一次全体大会。

会议室在银河核心巨大恒星环内的人造星体上——会议大厅是一座用完全透明天晶建造的圆形厅，从内往外看能看到整个银河旋臂。这间会议室的历史档案里记载了从第一个加盟文明加入开始的全部议事记录：天琴座从"大归还"时的退盟——到再次回归——到无数个重大立法修订——以及每一次关于宇宙资源分配的争议。所有的记录被装订在无数层叠的纳米打印卷册中——排满了一面长达三公里的高墙上——每一卷都有人类臂长那么厚。

最后一次例会的议程全部是关于"档案转移"。多元宇宙理事会决定把全部历史卷册转移到永恒之库。不是送走——是让它们在零点时刻后被接入新宇宙基础信息层——让任何未来的文明都能随时查阅。转出方是旧纪元最后一位轮值主席——一位来自鲸鱼座的老学者——接收方是龟相。

龟相从头到尾一页页办完了完整的移交手续。所有的数字签署、每一项类目的确认——全整得规规整整，一丝不乱。全部档案移交完毕的那一刻——轮值主席用非常古老的鲸鱼座礼节向龟相行了一个礼——那个礼的意思是"把记忆托付给被信任者"。龟相把两份爪子收进壳——行了一个很短的龟式回礼——然后慢慢爬出了大厅外——壳上沾了些微档案页缝间的灰尘。

小王在走道外等他——他推着一个小的物资车——上面放着一台自制的数据缓存柜。那台柜里装着的不是那些正式的历史卷册——而是这四十亿年来所有被理事会"正式删除"但实际被技术人员悄悄留存的非正式备忘录——多数是各种口角、拼写错误、笔误或被认为是玩笑的涂鸦留言。当中有一次——在遥远不知名的某星系代表无故缺席会议——那页他的缺席说明只写了三个字："请病假"——加了一个连他本族都没见过的小动物爪签。

"这些不能丢。"小王说——他把缓存柜推过走廊——运到龟相的转移台旁边——整柜转入了永恒档案库存——柜标签用极敬业的字写："非正式历史留档——全收——不筛。"

走廊上的光廊在当夕最后一次亮起——透过天晶墙壁泻了整层走廊——镜面上最后一次照着被历史记录反打的影穗——它们降成了静默的存档静光。全宇宙的政务——从此让位给万物。

（第671章完）

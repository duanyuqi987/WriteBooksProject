# 第628章 太初在哪儿

冥王号在寂静海的边缘停泊了整整一天。

不是机械故障。不是能源不足。是李长生需要时间思考。他坐在舰桥最前方的单人舱里——那个舱室本来是用于紧急救生和单独冥想的，只有三平方米，墙壁是灰白色的，没有任何装饰。他坐在里面，从舷窗往外看。寂静海没有星星——他看的不是风景，是空无。

他在想太初在哪儿。

这个问题从逻辑上说不通。如果太初是所有维度的第一推动力，是所有存在的来处和归处——那么它应该在所有地方。不是"处处都在"——而是"处处就是它"。但李长生的直觉和存在辨识力在同时告诉他：事情没有这么简单。太初既有"处处都在"的一面——也有"在某一个特定地方"的一面。那个特定的地方不是空间意义上的位置——但也不是完全不存在。

就像一个计算机程序的总控台。控制器可以被分散运行在每一行代码里——但也可以有一个集中的操作界面。太初如果有操作界面——它在哪儿？

他从冥想舱里走出来的时候，陈霜靠在走廊对面的墙上。她已经在那里站了近乎同样长的时间。她等他的时候不需要敲门——她知道他在深度思考的时候，敲门会切断思路。

"想清楚了？"她问。

"没想清楚。但有了方向。"李长生说，"太初的位置——不是空间位置。是'条件位置'。只有在特定条件满足的时候——它的操作界面才会显现。"

"什么条件？"

"宇宙轮回的节点。太初不会平白无故地出现。它在混沌之主完成使命时才出现——不是任意时间都可见。所以我们这个宇宙的轮回如果还没有到它的'成熟期'——太初就不会显现。"

他们走回舰桥。舰桥上，龟相已经把信息结构的所有资料整理完毕。整理报告长达两千三百页——当然没有人会逐页看。龟相把核心结论提炼成了三句话，投射在主全息屏上：

第一：太初不是可以被"找到"的——它只在宇宙轮回节点上显现。

第二：当前宇宙距离上一次轮回约一百三十八亿年——已经接近本轮回的自然终点。

第三：太初的显现位置——如果可以用位置来描述的话——在"宇宙之外的维度"。不是三维空间之外——是所有维度之外。具体坐标不可用任何已知语言标示。

"第三条是最重要的。"龟相说，"如果太初在'所有维度之外'——那么任何在维度之内运行的感知、探测、追踪全部对它无效。想要找到它——或者说想要让它显现——必须完成一个前提。"

"什么前提？"陈霜问。

"必须有一个人站在所有维度的边界上——一只脚在维度内，一只脚在维度外。"龟相看向李长生，"这个人必须是混沌级。冥王级不够——因为冥王级还是纯粹的维度内存在。只有混沌级的存在才能跨越那个界限——因为混沌本身就是维度内和维度外的交界层。混沌是'创造维度'的原材料——所以它是唯一同时存在于维度内和维度外的东西。"

舰桥上安静了一下。

李长生明白了。他获取混沌碎片——不只是为了阻止混沌之主复苏。混沌之主已经在亿万年前被太初收了。他获取混沌碎片的真正目的——他自己都还没完全意识到——是为了站在维度边界上。是为了能在太初显现的时候看到它。是为了能在宇宙轮回到来的时候——站在那个操作界面前，为他的世界做点什么。

"所以继续寻找混沌碎片。"他说。不是提问——是结论。是一种把所有模糊线索突然全部串联起来之后的豁然开朗。

小王把他的分析也投上了全息屏。他的分析角度和龟相不同——他是从信息论的角度推的。他推出来的结果是：如果太初是一个系统——它必须有一个日志文件。不是人类概念的日志——是它执行每一次宇宙轮回时留下的痕迹。这个日志文件如果存在——它一定不在维度之内。但它一定有一个"入口"。那个入口的位置——他用信息论模型推算了六个小时后——指向了宇宙之外的一点。

"这个点和龟相推算的太初显现位置——在数学上是同一个点。"小王说。

两条思路，两个方法，两个完全不同类型的脑袋——推出同一个位置。

"所以太初——或者说它的'操作界面'——是存在的。而且在同一个位置。"李长生在舰桥上来回走了两圈。他右手掌心的两层纹路随着他的思虑在微微明灭。两块混沌碎片在同步推演他作为宿主脑袋里此刻运转的逻辑——它们在给推演加速。

"距离下一轮宇宙轮回——"他停下来，"龟相你说——'接近'——到底是什么？"

"接近的意思是——可能在人的有生之年。一万年之内。也可能在明天。"龟相说，"太初的时间观念里没有'精确'。它不是钟表。它不看时间。它看的是一个宇宙是否已经'完成'。完成的标志不是时间——是——"他顿了一下，"——是这个宇宙是否已经得出了它的结论。"

"结论是什么？"

"你们。"龟相的两根前肢一起指向舰桥上所有人，"你们的文明。你们的修仙体系。你们在冥王纪元里发展的全部力量结构。你们做出的每一个选择——从建国百年的灵气禁令、到李长生接受碎片、到这场横跨宇宙的碎片收集——全都是结论的一部分。一个宇宙在面临轮回的时候——站在太初面前的不是行星，不是恒星，不是星系。是那个宇宙里最顶级的意识体。在过去是混沌之主——在未来——"

他看向李长生。

李长生没有接话。他重新看向舷窗外面。冥王号的航向已经调回了地球。外面不再是空无的寂静海——星星开始出现在远处。他知道接下来的路：继续收集混沌碎片，让自己达到纯混沌级，站在维度边界上——然后在宇宙轮回到来的时候，站在太初面前。不是为了抗拒轮回。是为了在轮回的时候——替他的世界做一个选择。

（第628章完）

# 第031章 仪器爆炸，测试员目瞪口呆

李长生在小房间里等了将近四十分钟。

这四十分钟里，花白胡子和女老者都没有再开口问他什么。两个人坐在桌子对面，偶尔交换一个眼神，更多的时候是沉默。花白胡子闭着眼睛，像是在思考什么深奥的问题。女老者提笔在面前的宣纸上画了一些符号，画完一张揉掉一张，好像怎么画都不对。

铁门外传来脚步声，不是很重，但很多。至少五六个人同时在往这边走。

门开了。

首先走进来的是之前那个中山装中年人，他侧身让到一边。后面跟进来四个人。

一个穿黑色中山装的老者，年纪可能在七十以上，发际线后移，但双眼极为有神。他胸口别着一枚和中山装中年人一样的三剑徽章——九华剑派的人，但徽章的剑痕是金色的，不是白色的。

后面是一个四十多岁的女人，穿深蓝色西服裙，戴无框眼镜，看上去更像政府官员而不是修士。她的左袖口上绣着一枚小小的太极印记。

再后面是两个穿黑色西装的人，三十来岁，面容凌厉，步伐整齐。看不出修为，但他们走进房间的那一刻，桌子上的灵盘残余阵纹自动熄灭了。

"门关上。"七旬老者说。

中山装中年人把门从里面锁住了。

小房间里挤了七个人，气氛变得极为凝重。

七旬老者的目光在花白胡子脸上停了半秒，然后转向李长生。他走过来，在李长生对面坐下。桌面上那台已经停机的灵盘横亘在两人之间。

"我是白鹤鸣，九华剑派外务长老。你可以叫我白长老，也可以叫我白先生。"他的声音很缓慢，每个字都咬得很准，"小伙子，你叫什么名字？"

"李长生。"

"长生。"白鹤鸣点了点头，像是在品味这两个字，"好名字。你名字里有个'长'字，是不是命里缺什么？"

"不是。我爹妈就希望我多活几年。"

白鹤鸣嘴角动了一下，算是个礼貌的笑。

"你爹妈还在吗？"

"不在了。"

"你一个人？"

"一个人。"

白鹤鸣双手交叠放在桌面上，十根手指互相扣着。他的手指很奇特——骨节粗大，皮肤却光滑得像二三十岁的人。

"李长生，外面的灵盘对你有反应吗？"

"没有。"

"这台灵盘呢？"

"也没有。"

白鹤鸣转过去看了一眼花白胡子。花白胡子点了点头，确认了李长生的说法。

"嗯。"白鹤鸣想了一下，"所有的灵盘对你都没有反应。不对——不是没有反应。是灵力在接触你的那一刻被某种东西吸收了。查老先生说了，说你体内有什么东西在'吃'灵盘输出的探测能量。"

李长生没有说话。掌心的碎片安安静静，但他能感觉到它在蓄力——像是某种防御机制正在被激活。

"李长生，"白鹤鸣的声音依然很平缓，"古往今来，所有灵盘都测不出的灵根，只有一种。你知道是哪种吗？"

"不知道。"

"品外灵根。"

白鹤鸣把"品外"两个字咬得特别清楚。

"品外灵根不属于九品体系。但它有一个特征：品外灵根在灵盘上显示的不是空白，而是'溢出'或者'未知类型'。因为灵盘感应到了它的存在，只是无法归类。但你——"他盯着李长生，"你的测试结果不是溢出，不是未知类型。是完全消失。灵盘的探测灵能在接触你手掌的位置被彻底吞噬。这不是品外灵根的特征。"

他顿了顿。

"顾家的卷宗上，好像记录过类似的现象。但顾家一脉已经沉寂多年——"

"我要你们换一台灵盘。"女老者在旁边忽然开口，打断了他的话。

白鹤鸣转头看她。女老者放下毛笔，站起来，声音很平静。

"外面那台灵盘是标准型号。屋子里这台是中量程。我用符笔封了五成灵力来运行，依然全部被吃。现在我要一台没有任何限流的——满功率运转。白长老，你给不给？"

白鹤鸣看了她一会儿。"齐道长，你确定？"

"我是玄门联盟派来负责这个站点数据校验的。一个测试者连续两次异常值三连，我有权走全量检定流程。你不给，我就直接上报总局。"

白鹤鸣沉默了一会儿。然后他抬手，对中山装中年人点了点头。

三分钟后，一台新的灵盘被推进了房间。

这台灵盘比之前的都大——盘面直径将近半米，厚度一巴掌以上，表面密密麻麻刻满了阵纹。盘身是深黑色，放在铁桌上压得桌子腿都往下沉了一点。

女老者——齐道长先做了一系列调试。她用毛笔沾了青色的符液，在灵盘边缘画了整整一圈符文。每画完一道符文，灵盘都发出一声嗡响。最后一笔画完，灵盘通体亮了起来。

"全功率预热完成。"她抬头看了白鹤鸣一眼，"白长老，你站远一点。"

白鹤鸣往后退了两步。

李长生看着眼前这面巨大的灵盘，掌心的冥纹忽然跳得很厉害。碎片的声音在他脑海中急促地响了一下："等等。"

"怎么了？"

"他们用的不是普通的探测灵能耗。这是全功率的灵脉共振探测——这种级别的探测能感应到丹田深处的灵根本核。你的冥土灵根一旦被这种强度的探测打到——"

"会怎样？"

"我不确定。但冥土之力可能会自行护主。"

"那是什么意思？"

碎片没有回答。

齐道长看着李长生："你再把手放上去。放心，只是探测，不会伤到你。"

李长生把手伸过去，手掌按在灵盘正中。

和刚才完全不同。

这一次，灵盘在他手掌接触的瞬间剧烈震动起来。不是微风拂过湖面那种微颤，像是有什么东西从内部猛地撞击了一下盘体。齐道长的手指还按在灵盘边缘，被这股震动震得弹开了。

灵盘的阵纹全部激活了，密密麻麻的光线像蜘蛛网一样盘面上展开。那些光线本该沿着固定的阵纹路径延伸到盘心，完成对整个手掌的探测，但它们没有。

所有的阵纹光芒，在触摸到李长生掌心的一瞬间，全部消失了。

不是暗了。不是灭了。

是直直地没入了他的掌心。像是黄河水灌进了一个无底深洞，永远灌不满。

灵盘在全功率运转，灵能输出幅度在屏幕上疯狂跳动，每秒都在刷新最高记录的数值。但所有这些能量，从灵盘流入李长生手掌的那一侧，全都消失了，消失在掌心那一小块皮肤里，没有任何反馈信号回来。

"输出功率已经过九成了——"齐道长的声音变了，她抓起毛笔在灵盘边上又画了一道符文，想要手动调节功率。

但她画完之后，灵盘的嗡声更大了。功率不降反升。

"它不受控制——"齐道长毛笔下出现了线条抖动，这在她这种级别的符师身上几乎不可能出现。

白鹤鸣的眼角肌肉绷紧了。

灵盘内部的嗡声越来越高，从沉闷的低音升到了刺耳的高频嘶鸣。整个铁桌都在跟着震，旁边的电脑屏幕疯狂跳动着一串又一串的乱码。所有在场的修士都感觉到了一股不可见的压力，从那面灵盘的中央往外扩散。

李长生掌心里的冥纹在微光下透了出来——幽暗的光泽从他指缝中渗出，不是任何可见光波段上的颜色，而是一种直接作用在人视觉神经上的"暗"。

齐道长看到了。白鹤鸣看到了。所有人都看到了。

"收手！"白鹤鸣低吼了一声。

李长生想收，但收不回来。他的手掌像被吸在了灵盘上，掌心那一块区域的皮肤完全和盘面粘结在了一起。不是物理的粘结，而是某种更深层的能量锁定——灵盘在全功率运转的时候已经启动了一种自我保护机制，但它反而把李长生的手锁住了。

"他收不回来！"齐道长喊道，"灵盘的环路被他的冥力反向锁住了！"

白鹤鸣一步跨到李长生身侧，并指如刀，往灵盘和李长生手掌接触的边缘切去，指尖夹着一道凌厉的白色剑芒。他这一手没有留力——以他玄师的境界，这一道剑芒切开钢筋混凝土都跟切豆腐没区别。

剑芒斩在灵盘边缘，溅起一团白光。

灵盘纹丝不动。

白鹤鸣脸色剧变。

就在他准备动用更强的招式的时候，灵盘内部的嘶鸣频率骤然提到顶点。

盘面震动达到了肉眼可见的幅度。盘身缝隙中透出刺目的白光。所有的阵纹在同一时间碎裂——不是暗掉，而是从盘面内部被某种力量反向碾碎了。

然后，灵盘炸了。

不是粉身碎骨那种炸。是灵体内部的所有能量在一瞬间释放，盘体从中间裂成三块，一股气浪把计算机显示屏都掀翻在地，齐道长被震退了三步，中山装男人扶着墙壁才没摔倒。

碎片和李长生手掌之间的吸力在这一瞬间断开。李长生的手终于能收回来了——掌心一片通红，冥纹的图案清晰可见，像一朵幽暗的莲花烙在皮肤上。

房间里弥漫着一股焦味。

白鹤鸣盯着李长生掌心的冥纹。他的瞳孔剧烈收缩了一下，然后迅速恢复了平静。这是一种经受过严格训练的本能反应——先惊，然后立刻压下所有表情。

但那一瞬间的"惊"，已经被李长生看得清清楚楚。

"通知总局。"白鹤鸣转过身，对那两个黑西装低声说了两个字，"冥系。"

黑西装的其中一个转身开门，快步走了出去。

齐道长扶着墙壁站定，低头看着碎成三块的灵盘残骸，脸上的表情极其复杂。她是这批灵盘的校验员，所有站点所有灵盘的数据都从她手下走过。她见过六品、七品、八品灵根的测试数据，都是亮的，越来越亮。九品灵根的测试灵盘会因为能量过载而自动停转，但绝不会爆炸。

这台灵盘的设计冗余，是标准满功率的三倍以上。

"满功率三倍冗余都扛不住——"她喃喃自语，"他到底吸收了多少探测能量？"

没有人回答她。

白鹤鸣走过来，站到李长生面前。他看着这个穿着脏兮兮工地T恤的三十岁农民，沉默了很多秒。

"李长生。"他终于开口，声音很轻，但每个字都落在地上砸出坑来，"你知不知道，你掌心里那个东西，在玄门联盟的禁典里被视为万邪之首？"

李长生捏紧了拳头。冥纹的光芒已经消退了很多，看起来只是一块黑色的印记。

"我不是邪修。"他说。

"我知道你不是。"白鹤鸣的眼神意外地平静，甚至有一丝疲惫，"如果你真是邪修，刚才那一掌你就把我的剑芒吸走了。你没有。你只是想收手——但你收不回来。是灵盘锁住了你，不是你攻击灵盘。"

他叹了口气。

"你跟我去后厅等着。总局的人马上就到。从现在开始，你的一举一动都会由我亲自看守。"

李长生没有说话。他站起来，跟着白鹤鸣走出房间。

走廊里还是那么安静，但安静底下压着一种刚刚被打破的秩序。头顶的日光灯嗡嗡响着，照出几个人的影子，拖在地上，长而扭曲。

身后碎成三块的灵盘残骸躺在铁桌上，缝隙里还有一点残余的光没有散尽。

测试大厅外面，队伍还在缓慢地挪动，没有人知道后厅发生了什么。广播里还在循环播放着那个机械的女声："请保持秩序，不要插队——"

排队的普通人什么都不知道。

（第031章完）

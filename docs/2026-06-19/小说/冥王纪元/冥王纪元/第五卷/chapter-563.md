# 第563章 时间之力，威力难测

时仙王的身影消失在了虚空深处。

他来的时候默默无闻——一个拄着拐杖的老人，独自穿过维度壁障。走的时候同样安静——一步一步，不急不缓，像风吹过枯叶。但他留下的影响才刚刚开始扩散。整个地月系的时间静滞场在他离开之后缓缓消散，那些被冻结在某个瞬间的炮台、战舰、施工机器人重新开始运转——但没有人知道刚才发生了什么。他们只是觉得时间好像突然跳了一步。前一秒还是警报响了，后一秒警报停了，中间有一段空白的记忆。

而那道从远方缓缓逼近的两道仙王气息，已经进入了李长生的感知范围。

第五平行宇宙的仙王——裂空仙王——他见过。在第四平行宇宙维度裂隙的战场上，就是他带领封锁舰队围堵陆星河。排名第七的空间系仙王，战力虽然不及炎烬和渊虹，但空间裂缝的绞杀能力让他的攻击范围极广。

但这一次裂空仙王不是主角。

主角是他身边那位——第六平行宇宙的仙王。李长生从未见过这个人，但他从冥王令的反应中感知到了一股极其不寻常的力量。

那力量不是灵力。不是剑气。不是阵法。是一种更原始的东西——像一把钝刀，缓慢地、不可阻挡地切割着宇宙的缝隙。每切一刀，那个方向上的时间就微微错位一瞬。不是时仙王那种精妙的时间操控——时仙王对时间的掌控像外科手术，精确到微秒级别。而这个仙王的时间之力是野蛮的、暴力的、是纯粹的力量碾压。

时仙王的能力是"操纵时间"。

这位仙王的能力是——"破坏时间"。

"第六平行宇宙的镇守仙王——碎时仙王。"小王的声音从地月系指挥大厅传来，带着罕见的急切，"情报太少了。只知道他和时仙王是同时代的老怪物。但两个人走了完全不同的路——时仙王追求精确操控，他追求力量碾压。他有一个外号——'时间粉碎者'。"

"他能做什么？"李长生问。

"情报说——他曾经用一次攻击，把一个星球上所有生命的'寿命'同时粉碎。那个星球在一瞬间从一个文明的摇篮变成了一颗死星。所有人同时衰老到了生命的尽头——不是被攻击杀死的，是老死的。他粉碎了他们的时间。"

随着话音落下，虚空远方那两道气息中较强的那一道突然加速了。

碎时仙王来了。

他不是穿着长袍或者战甲出现的。他是直接从时间裂缝中摔出来的——像是被时间本身吐出来的。他比时仙王年轻得多——至少外表看起来是这样：一个四十岁上下模样的中年男人，披散着头发，身上裹着一件破旧的兽皮大衣。他的右手握着一柄巨大的战锤——锤头上布满了裂纹，裂纹中渗出灰色光芒。那不是灵气光芒，而是破碎的时间流的残渣。

"冥王——"碎时仙王的嗓门极大，声音在真空中直接通过时间震动传播，不需要任何介质，"老子等了一万两千年！终于轮到老子出场了！"

话音未落，他抡起了战锤。

那柄战锤的锤头在挥舞的过程中膨胀了——从一丈宽膨胀到了十丈、百丈、千丈。不是物理膨胀，是时间膨胀。他把锤头在过去、现在、未来三个时间点上同时处于的大小叠加到了同一个时刻。现在的锤头是一丈宽，叠加了未来已经膨胀到千丈宽的锤头，再加上过去还没有缩小的全部尺寸——实际锤击面积覆盖了李长生所在区域的所有维度。

李长生没有硬接。

冥气感知告诉他这一锤的力量不仅存在于当前空间——它穿透了整个时间谱。用冥王令去格挡，即使否定掉了现在的锤击，也躲不开过去和未来两重锤击的同时命中。

他启动了存在分裂——但这一次没有分出去救人，而是让自己同时出现在两个相邻的时间点上。现在时间点的李长生躲开了现在的一锤，过去时间点的李长生躲开了过去的一锤，未来时间点的李长生躲开了未来的一锤。

三重躲避，同时完成。

碎时仙王的战锤砸在虚空中。

不是砸碎空间——是砸碎了时间。在锤头落点的那个坐标上，时间变成了碎片。不是停止，不是加速，不是倒流——是碎片化。这个坐标上的时间从此不再连续。任何经过这个坐标的东西都会被时间碎片割成无数段——你的头可能停留在某一秒，身体在另外一秒，两条腿在完全不同的两个时间点上。这些东西无法重新拼合，因为你无论如何也凑不齐完整的时间。

"躲得不错！"碎时仙王哈哈大笑，"再来！"

他第二轮挥锤。这一次不是砸一个点，是横扫——战锤在虚空中划出一道弧线，弧线所到之处时间全部破碎。

李长生退了。

能不硬接就不硬接——这是他从黄土地上学到的生存智慧。农民的哲学不是"跟天斗"，而是"天要打霜你就收庄稼"。打得过要打，打不过要想办法打得过。

他要的不是逞能。他要的是活到能打败对方为止。

（第563章完）

# 第五百零四章 原来你一直在

苏晚讲完第一百世时已经是深夜。银杏林里极安静。五轮太阳中有四轮沉在极低的角度，余下一轮孤悬在正顶——那轮是纯银色的映月轮。把林间空地上的落叶照出一层极薄极淡的冷光。

她靠在林牧肩上，嗓子完全哑了。讲了几十世的回忆——每世都在用她同一副嗓子把它从小到终点完整地讲给他听，像讲了几十本极长极长的小说。林牧从头到尾地听着。听完之后他过了很久很久才说了一句话——不是对他自己说的，是对第一世的她、第三世的她、第十世的她、第五十三世豆腐摊对面的那个她，一直到最后那一世的她说:"原来我找了那么多条路，每一次都找到了你。可是我每一次找到你的时候——你都已经是新的你了。你都不记得我。但我还是找到了——因为不管你怎么变，你的灵魂在的地方，我的灵核一定会有感应。每一次看到你的眼睛——脑子里不记得，但灵核记得。一万年来的轮回里，那些你不记得我时候我一直在你身边。"

苏晚抬起脸看着他。她的泪腺已经在那几十世的讲述中哭得没弹药了，但她的眼眶还是红的——那是充血，不是泪。她把手按在他脸上，"你现在知道了吧——不是你这辈子才找到我。你这辈子只是第百零一次找到了我。前面一百次，你每次都是不同的身份、不同的方式、不同的路——但你每一次都来了。在石桥上，在城墙洞里，在灯市碎掉的面具里，在那块唯一的漂浮木板上，在你每天都帮我的豆腐摊挪位的那一瞬间。所以我封印解除之前，我身上那扇门一直打不开——不光是因为我灵魂不够强。也是因为我不敢看。我怕看完之后——我会心疼得不敢去想。但现在我看完了。全部看完了。心疼——但更值了。你为我轮回了百世。我为了今天推开这扇门等了百世。所以从这一秒开始——我不再是'被你守护的人'。我是'知道了你全部守护的人'。知道这件事之后的苏晚，和之前的苏晚不一样了。"

林牧没有说话。他把脸埋进她的颈窝里。功德绳那头传来了他在极力压制的某种极其古老极其深厚的东西——不是情绪崩溃。是一万年来他从来没能说出的话——终于被她说出来，终于被她说成他不用再独自含着的那个东西了。他在她颈窝里呼吸了很大一会儿。然后闷着嗓子说:"豆腐摊不是我每天都要挪——是因为你每天早上要抬头看我。我想让你一抬头就看到我在对面。"苏晚一愣。然后破涕而笑——笑三声就又哑咳嗽了一下。"你那辈子怎么不说？""卖豆腐不能分心。"

（第五百零四章 完）

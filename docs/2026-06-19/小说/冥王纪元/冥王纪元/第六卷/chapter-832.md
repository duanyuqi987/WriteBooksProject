# 第832章 最大的节日

新纪元一万年。冥王离去纪元第一万年。

星光议会在七千年前就决定：一万年整的时候，要举办一次史上最大的纪念活动。不是庆典——纪念。不是阅兵——聚会。所有平行宇宙的修士、所有文明的使者、所有愿意来的人——齐聚地球，在同一个日子里向混沌深空方向致敬。

这一天被定名为"万年祭"。不是哀悼，不是祭祀。是"祭"字本来意义——春祭曰祠，秋祭曰尝，冬祭曰烝。万年祭是——在守候了一万年之后，拿出来给守护者尝尝的"吃食"。最早提出这个名字的不是议会，是一个八岁女孩。她是当年"星光少年提案大赛"的冠军——每年都有孩子提出各种点子，但那一年她的点子不是建广场，不是写诗。是一个字。她说："我们应该像给地里的爷爷送饭一样——每过一万年送一顿。不是求他回来，是告诉他今年收成好。"

议会采纳了这个名字。一万年，每一年都有数百万条与冥王有关的数据累积。但孩子的提案——只有一行字——穿透了所有数据，成为整个一万年人类纪元中最简洁的纪念辞。

万年祭的准备工作从九千九百八十年就开始启动。不是权力层面的调度——是全民自发行为。地球的李家庄原貌保护区被设为活动的精神中心，但实际会场分布在整个银河——各星球各自举办，通过灵符网络同步。而地球会场限定人数——不是特权，是因为地球这颗小星球承受不了来自十一个维度的全部来客。所有参加者靠自愿抽签，中签的人才能降落在地球表面。中签者必须在到场时带一样东西：他所在星系的一把土。土可以用灵力筛过，但不许添加任何物质——就是原土。

这个规矩是老的——来源是李长生当年在李家庄祖坟前说的那句"我家的土"。在一万年后，这句话被很多人记住了，并以土为约。

在万年祭前一天夜里，李家庄那片黄土地上堆满了土。来自十一个维度两千多个宇宙的土，颜色不一，质地各异。有紫色的石英砂，有白色的硅藻土，有红色的氧化铁颗粒，有绿色的铜锌活性土。它们被摆在祖坟外围的一片专门开出的空地里，按送来先后原则一一排列，不加修饰、不排列任何型制。像无数人从自己家带来的一小包思念，摊在一起。不混合，但一起放在同一片黄土地上。

深夜，整个李家庄点起了灯。不是灵灯，是油灯。这个规矩也是老的——李长生当年晚上下地回来，总是点一盏煤油灯坐在堂屋。一万年后，油灯被重新启用——燃料是各家自己榨的普通豆油。灯芯不是灵丝，是棉。一盏一盏，排上村口，排上大槐树周围，排上李家老宅的院墙。没有统一排法。有人蹲着放，有人踩着梯子放，有人小孩自己爬上石墩把灯搁稳——像所有来自不同文明的人都在这一刻变成了同一个村庄里的邻居。

议会没有发布任何官方日程。只有一个沉默的约定：万年祭午夜零时——所有人一起面向混沌深空方向，安静片刻。片刻多长没有规定。各人自己决定。

灯光照着的，不只是地球的田野。所有参与万年祭的星球在午夜准点都同步了光幅——不是灵符约定的同步，是一批光子在九千年前被边驿一个天文台不小心折射进维度共振层的副作用：每年都有极少的光子莫名其妙出现在所有文明星的上空，不亮、不震、不声明——这一次，每个星球都为自己的光立了一盏油灯。油灯不是技术，是手势。那个手势里只有一句话：我们还在。

（第832章完）

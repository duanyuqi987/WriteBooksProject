# 第268章 十二帝中，有人已关注到地球灵气复苏

小王用了整整一天时间，把三个观测站的数据重新整理了一遍。

这不是简单的数据搬运。月球数据库使用的存储格式和加密方式和地球的完全不同——不是二进制，不是字符编码，甚至不是任何人类已知的信息记录方式。那是一套基于"符元"的数据体系，每一个信息单元同时承载着语义、数值、空间坐标和时间戳四个维度的信息。小王把这种存储结构称为"四维符元"——用他的话说，这就像把一篇论文、一个数学公式、一张地图和一本日历同时写在同一行字里，而且每个维度在这行字里都清晰可辨。

他花了大半天才把符元解析器跑通。到下午四点，三个观测站的详细运行记录被提炼成了一组可以被人类理解的时间序列数据。数据打出来有九十二页，李长生没有全看——他让小王挑关键的说。

小王的总结很简短。

"建国百年纪念日——也就是灵气复苏的第一天——格林威治时间上午九点四十七分二十一秒，烁天光主所属的'光冕九观测阵列'中的第十七号观测站，改变了持续了约四千年的固定观测姿态。原来它对准的是银河中心区域——具体目标不明。改变后的观测方向精确指向太阳系。"

"同一时间？"许冰问。

"不是完全同一时间。但极为接近。"小王翻出第二组数据，"格林威治时间上午九点五十二分八秒——晚了大约四分四十七秒——幽冥渊帝所属的'虚无之眼'观测阵列中的第四号站台，观测方向同样转向了太阳系。根据数据库标注的技术参数，以幽冥渊帝势力最先进的信息传输速度计算，四分四十七秒恰好是光冕九观测阵列的观测信号跨越四百二十光年到达七百三十光年外的虚无之眼阵列所需的时间。换句话说——"

"不是三家同时发现的。"陈霜一语中的，"是烁天光主的人先发现了什么，幽冥渊帝的人接到了前者的信号，然后跟着转了过来。"

"对。"小王点头，"而九虚道君的观测站转向发生在同一天的十一点以后——比前两家晚了将近两个小时。这说明九虚道君的观测站不是被动接收了前两家的信号，而是自己独立探测到了异常。"

他停下来喝了一口水。笔记本的风扇在高速旋转——灵符引擎解析四维符元对硬件的消耗极大。机箱外壳摸上去已经有点烫手了。

"问题是——他们观测到了什么？"李长生问。

"这正是我想说的重点。"小王放下水杯，手指在键盘上敲了几个指令，"数据库里还有一个数据目录，标注的翻译是'星域异常探测记录'。这个目录下记录了三个观测站在转向太阳系之后各自采集到的具体数据。"

他把屏幕投射到墙上。

第一个观测站——烁天光主的——记录了一条异常数据："目标星系出现超规格灵气浓度波动。波动峰值超过该星系历史背景值约一千零四十万倍。判定：该星系发生了全局性灵气环境结构性变化。"

一千零四十万倍。这个数字让会议室沉默了好一阵子。

地球的灵气浓度在建国百年之前几乎为零——冥王的"消失"战略把整个太阳系的灵气都压制到了宇宙背景噪音的程度。一万两千年来，在地球以外的任何一个宇宙势力看来，太阳系都是一颗灵气枯竭的荒芜之地——没有矿藏、没有古道、没有传送阵，连最低级的宇宙漂流的盗匪都懒得路过。而现在，灵气封禁解除，整个地球的灵气浓度跳到了一千零四十万倍于此前的水平。这相当于在宇宙的"黑夜"中突然亮起了一盏极其刺眼的探照灯——任何在附近星域设置了观测站的人，都会在第一时间注意到。

第二个观测站——幽冥渊帝的——记录更加详细。它不仅记录了灵气浓度的变化，还分析了灵气的属性特征。数据库里标注：幽冥渊帝的观测站检测到了"暗属性灵气成分占比异常偏高"，远超过一个正常复苏的灵气环境应有的比例。它的结论是："该星系在远古时期曾经历过暗属性高阶修士的大规模活动。该暗属性残留至今未被自然消散，说明残留量极大、等级极高、时间极近。"

"暗属性。"李长生把这个词念了一遍。他的冥系灵根本质上就是暗属性中最极端的一种——不是普通的暗，是冥。是天地初开时沉入地壳最深处的那种原始黑暗。

"幽冥渊帝自己就是黑暗系修士。"龟相插了一句。它的声音很平静，但李长生听出了这句话里藏着的担忧。"黑暗系修士对同类的气息非常敏感。冥王陨落的痕迹——那种残留在整个太阳系灵脉里的万年级冥气——对普通人来说可能太淡了闻不到，但对幽冥渊帝来说，就像鲨鱼闻到了血腥味。"

第三个观测站——九虚道君的——记录最简短。只有一行字："该星域出现可折叠空间结构残余痕迹。痕迹年代约一万两千年。折叠技术序列与冥系符文高度吻合。"

"一万两千年前。"老陈咽了口唾沫，"那是冥王陨落的时间。"

"对。"小王说，"九虚道君是空间类修士。他对空间折叠的敏感度就像黑暗系修士对同类灵气的敏感度。一万两千年前冥王在太阳系进行的空间折叠——哪怕过了这么久，残留的空间波纹依然可以被九虚道君的观测站探测到。"

李长生站起来，走到窗前。

外面的城市正在建设。远处那栋修士训练基地大楼的主体结构已经封顶，外墙挂满了安全网。更远处可以看到几座新矗立起来的聚灵塔——那是老马设计的城市灵脉联动节点，利用天然灵脉的互相共振在城市上空形成了一层薄薄的灵气防护罩。这座城市在积极备战——所有能调动的资源都在向"防御"方向倾斜。但此时此刻，站在窗边的李长生第一次真实地感受到——他们准备的防线在宇宙规模面前有多么微不足道。

"三个帝者都看到了灵气异常。"他把手揣进裤兜里，"但他们是否知道这个异常意味着什么？"

"烁天光主可能只是当做一次普通的高能现象。"龟相分析道，"光系修士对暗属性不了解。灵气浓度跳涨在他眼里可能只是某种自然的天体物理事件——类似恒星耀斑、伽马射线暴之类。但幽冥渊帝——"

"幽冥渊帝会认出来。"陈霜替龟相说完了，"他既是黑暗系修士，又是当年和冥王见过面的人。太阳系里的暗属性灵气残留——那不是什么普通的高能现象。那是一个帝者甚至神级存在陨落后留下的尸骸。而且幽冥渊帝和冥王见过面。他知道冥王的灵气特征。"

"九虚道君呢？"

"他更简单。"小王说，"空间折叠痕迹。冥系符文。这两样东西加在一起——宇宙中只有一个人能留下这种痕迹。冥王。九虚道君即使没见过冥王的面，光凭空间技术记录就能锁定目标。而且他的扩张倾向极高——数据库的措辞是'吞并了至少两个文明'。这种人一旦发现一个被冥王封印了一万两千年的星系突然重新开放——"

他不会放过的。

会议室里的空气变得很重。不是有谁在施展威压——是信息本身的重压。十二位帝者中距离最近的三位，每一位都敏锐到了极点。烁天光主是光，幽冥渊帝是暗，九虚道君是空间——三个人分别从三个不同的维度捕捉到了地球灵气复苏的信号。即使烁天光主暂时不感兴趣，剩下的两位——一个嗅到了冥王陨落后的暗属性残留，一个探测到了万年未散的空间折叠痕迹——他们不会无动于衷。

"我们现在能做什么？"老陈问。他的声音不大，但在安静的会议室里清楚地传到了每一个人耳朵里。

李长生转过身。

"先算时间。"他说，"龟相——以宇宙修士的常规旅行速度，从距离我们最近的三位帝者的领地出发，到达地球最快需要多久？"

龟相没有立刻回答。它把脑袋缩进壳里，过了大约三十秒才重新伸出来。每次需要调动古老记忆的时候它都会这么做——那些记忆太老了，需要花些时间才能从壳底的某个角落里翻出来。

"宇宙修士的常规手段分三类。"龟相说，"第一类是最原始的灵气推力——像我们望舒号一样，用聚灵阵产生定向推力。这种速度最快能达到光速的万分之一到千分之一。从九虚道君的领地——三百五十光年——以千分之一光速飞行，需要三十五万年。这个不用考虑。"

"第二类是符文加速——以符文阵列压缩前方空间、扩展后方空间，使实际航速超越光速。这种技术在中高等级宇宙势力中很普遍。以这种速度——跨越三百五十光年大约需要三百年到一千年。这个时间尺度已经可以构成威胁，但还有一定的缓冲期。"

"第三类——"龟相停了一下，"是帝者级别的专属技术。空间折叠。九虚道君本人就是空间类修士。如果他对地球足够感兴趣，派出的是带有空间折叠能力的舰船——或者更糟，他本人直接出发——那么三百五十光年对他来说，可能只需要——"

"多久？"

"三个月到三年。"龟相说，"取决于他愿意消耗多少灵力。"

三年。这个数字落在会议室的地板上，像一块石头落了地。

然后龟相又补了一句："烁天光主和幽冥渊帝虽然不专精空间折叠，但他们各自的势力内部不太可能没有掌握初级空间折叠技术的人才。所以最坏的情况——三位帝者同时派人。第一波到达时间：三年。"

三年。

"从现在开始算？"刀疤问。

"从现在开始算。"

刀疤没有说话。他把拳头放在桌上，指节因为用力而发白。

李长生把目光从窗外收回来，重新坐回会议桌旁。他的动作很从容——从容到了反常的程度。陈霜看了他一眼。认识李长生两年了，她知道这种从容意味着什么——这个人正在脑子里把一条条退路挨个堵死，只剩下唯一一条可以走的路。他从来不说"没有退路"这种话，但他每次做出决定之前的姿态，就是这副模样。

"三年。"李长生把这两个字咬得很慢，像是在品尝一个不太熟的果子，"不长。也不短。"

他抬起右手，摊开掌心。那五道冥纹在日光灯下泛着暗金色的光——每一道纹路都是一个碎片融进去的印记。五道纹路的最外围已经开始勾画第六道的轮廓——西藏碎片融合后生成的第六纹还没有完全成型，但方向已经确定了。五道已成。三道待取。月亮那颗刚从行宫取回来，火星那颗还等着他们去找。而此刻，在三百五十光年之外，三个不知道长什么样子的帝者，正在看着地球的方向。

"三年之内，"李长生收起掌心，"我不但要拿到火星上的第八块碎片——还要让整个地球准备好迎接宇宙来客。用站着的方式。而不是跪着的。"

（第268章完）

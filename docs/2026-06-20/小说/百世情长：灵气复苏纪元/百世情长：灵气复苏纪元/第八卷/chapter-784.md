# 第七百八十四章 第八卷的尾声（一）：所有人都来了

联合共治会第二十四年除夕。飞升纪元以来最盛大的一次跨年集会——不只在太湖灯火塔——同时在桂花园学院总院、上界灯火塔广场、蜀山共容碑前、东海渔村灶台点、北境雪原城魔修茶馆——全部通过灵网实时连通。不是技术演示，是"团圆"——没有任何正式议程，就是一起过年。

赵姑老太太已极老了——九旬高龄——但她仍坚持在灶台前烧火。她烧的那口锅里下的是她自创的"跨域年夜粥"——里面放了九种谷物——分别来自太湖、蜀山脚、华山脚、东海、北境、上界过度区、母树平原——最后一种谷物是她自己种植的一小片院中碎铁片上种出的野荞麦（她说是那年碎铁渗入泥土后荞麦特别甜）。石头把她的粥命名为"赵姑九九粥"——不是祝福长寿，是纪念。小米被提升为灶台学第二代总负责人。他升任后的第一道指令是——"所有课外灶台的锅盖不允许盖着——锅必须随时可被掀开。——这不是卫生检查——是符号。——小米。"

叶小雨把检查完最后一次跨年网络后，在日志中写了一条极短的信息——"今晚全频道无异常。火很稳。——叶小雨。"她写完后就关了监控屏幕——不是下班了——是去喝粥。

顾小桐、孙小环都已步入中年，她们分别负责华南和东海的所有分院。这两个当年的女孩——一个是曾被驱逐的隐忍修士，一个是极度害怕被否定的无名散修——如今并排站在灯火塔前，端着两碗周公公粥。顾小桐说——"如果那年没有人给我忍冬——我现在可能还在后山砍柴。"孙小环回——"如果有人质疑你的忍冬以后能不能养活——你让他们来找我。——孙小环。"

（第七百八十四章 完）

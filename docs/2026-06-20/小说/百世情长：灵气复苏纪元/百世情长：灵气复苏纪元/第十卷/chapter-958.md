# 第958章 鹤的后代

养鹤这件事在他们生活中已经延续了数百代。最初那对鹤在数万年前已经重入灵鹤的自然轮回——但它们留下了后代。延续至今的是最初那对鹤的第八十代重外孙——一只羽毛泛出淡青色的紫喙幼鹤。苏晚给它取名叫"念初"——因为它是当年太行山那只老鹤在血脉中传下来的记忆载体。

念初不喜欢飞太远——它最大的爱好就是蹲在院墙的石柱上看着两人打坐。有时候会用喙从墙根啄下一小片青苔叼回鹤巢铺成软垫。青苔的孢子也因此被带到了远处——传道堂附近一些鹤栖地也长出了同样的苔种。生态圈继续在鹤翅下外延。

有一年春天——念初在苏晚的掌心中孵出两颗新蛋。孵蛋期她每日把掌心温度调到刚好。鹤蛋在两月后裂开——孵出两只毛茸茸的团雏。雏鹤第一次睁眼看到的不是亲鹤——是苏晚。它们对她的道源有天然的温度感——它们第一次吃食不是鹤粮——是用她的手指碾碎的云甘草嫩叶。

林牧在书房中看着她在院中伺候雏鹤，动作、耐心和神情跟她数千年前教第一批太行弟子时一模一样。他关上门，继续在道则实验中推导。他最近在探索一个极其微小的问题：为什么青苔在数万年后依然不长虫害？他发现青苔自身分泌了某种不为肉眼所见的"净化素"，将院中几十丈的空间自动维持成了一座净灵区——没有任何毒虫愿意靠近。这种素草起初只是随苏晚鞋底带来的凡间青苔——但数万年在道源微辐射的包裹下发生了静默进化。它不再是凡草——是共生道源而生的净灵青苔。这道青苔形成的自然屏障让他们的住所成为整个太初之城最安静的一角——连外界的灵气噪声都过滤了一部分。

老树也不只是老树。它的根系透过院墙传导——蔓延到整个传道堂的各个角落。后来被学员自己发现，传道堂里任何一棵树上只要被老树的根须触到，叶片的透明度就会轻微上升——不是病态，是光合效率轻微增加。学员间传开了——"苏师院子里的老树会帮别的树长大。"有一天白羽令带着一群新入学的仙童来院里登门拜访——孩子们对老树竖声说"谢谢老树"。老树无应——但它当晚在枝头多开了一层花。不是回应，是随季节该开了。

苏晚看着这一切——对林牧说："老树和青苔都是我们自己变成的。我们活成了陪伴他人的环境。"

林牧合上手里那份实验记录。他看着窗外的树、墙上的苔、和墙角那对大鹤带小鹤齐蹲的剪影。"是的——你不是在教课。你已经变成了课本身。"

两人把这晚的对话记录进了万年日志中。苏晚给这篇日志起了个标题：《共化的下午》。

# 第六百四十五章 双双炼虚巅峰

开春后的第三个月，林牧和苏晚同时感应到了一个不同寻常的灵气波动——不是来自地表，是来自极高的天际。那是一种被压了极久的频率，像远方有一扇沉重的门在缓慢地、不可逆地打开一条缝隙。

林牧站在桂花树下，闭着眼睛感知了大概一盏茶的时间。然后他睁开眼睛说："上界的门正在自己松动。不是因为我们做了什么——是因为下界的灵气浓度已经接近临界值了。当灵气复苏到达一定程度时，上界和人间之间的通道会自动开始解开——这是一个自然过程。但如果没有飞升之门引导它平稳打开——它就会变成一道无法控制的泄洪口。上界的灵气会像瀑布一样灌下来——下界的修士承受不住那么大的灵气密度。飞升之门的作用就是把这个过程从'泄洪'变成'调节'。"

苏晚站在他旁边。她听完之后安静了一会儿，然后说了一句林牧没想到的话："那我们得加快。不是为我们自己——是为那些还没到金丹期的人。他们承受不住泄洪式的上界灵气。"

当天晚上，两个人在修炼室里开始了一场前所未有的联合加速修炼。不是冲击合道——合道期需要的不是灵力积累，是对天地规则的完整理解，在飞升之门未建成之前强行冲击合道风险太高。他们做的是"炼虚巅峰的深度淬炼"——通过双人同步的方式把各自的神识推送到炼虚期能达到的理论上限，以便在飞升之门建成时能以最快的速度进行最后突破。

六天六夜。两人面对面坐在蒲团上，双手相对但不触碰——他们的神识已经完全同步在一起。林牧负责提供深度的神识探索——他的炼虚后期神识覆盖范围超过千里；苏晚负责提供精度的灵力调控——她的经脉分叉口的灵活性比林牧更高。两个人的神识像两条平行的丝线同时往虚空中推进——不是向上，是向内。在内视中逐步淬炼每一个灵海角落的残余杂质。当苏晚的神识遇到一个难以穿透的细微阻抗时，林牧的神识从旁边绕过去给她做引导；当林牧的神识在一个极其复杂的灵气结构中陷入过度的分析时，苏晚的神识轻轻碰一下他的边缘——提醒他不要过度。

第七天清晨。两人同时睁开眼睛。他们的灵海内没有任何杂质了——不是靠外力清除的，是靠彼此的辅助神识完成的。炼虚巅峰——这个境界在整个人间修仙史上从未有两人在同一时间到达。

苏晚低头看了看自己的手——手指还是凉的。但手掌心里有了一种以前没有过的微波——不是灵力，是炼虚巅峰后自动激活的某种古老印记。林牧看到她盯着手心——他也在看自己的。他的手心里也有——同样的频率。那是——百世情缘契约的原初印记。只有在两个签订了古老契约的人同时达到炼虚巅峰时，它才会自然浮现。它不是他们主动激活的——是修为到了才醒过来的。这说明了一件事：百世情缘契约的最终激活条件不是单方突破，而是双方同时达到飞升前的临界状态。

"这是什么？"苏晚看着手心浮出的淡金色的古代符文。那些符文她一个字都不认识——但她能感受到它们传递的情感温度。是一种极古老、极温柔的热。

"百世情缘契约的原初印记。我也是第一次看到它真实的形态。"林牧的声音竟然有点不平稳——他的手指在微微颤抖。不是因为激动——是因为他前世找了几万年都没有找到这个印记。今天它自己出现了。不是他找到的——是两个人一起到达了那个位置。

（第六百四十五章 完）

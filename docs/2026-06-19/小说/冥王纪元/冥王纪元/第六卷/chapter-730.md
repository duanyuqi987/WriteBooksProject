# 第730章 文明加速进化

帝国历一千年。

李长生站在冥都最高建筑的观景台上，俯瞰着脚下的一切。

一千年——对一位永恒级来说只是一呼一吸。但对一个正在加速进化的文明来说，一千年能发生的事太多太多了。

他身后站着陈霜，身边站着令蕊、玄夜、洛浅浅、夏侯明、洛清溪、王启明、陈远山——这是新纪元近千年来崛起的第二代帝国核心层。跟旧纪元的那群伙伴不同，这些人没有一个来自那场旧纪元战争的废墟。他们出生在新纪元，成长在法典的庇护下，接受过永恒学府的教育，从踏入社会第一天就被植入了"文明永续"的核心价值观。

他们不是战后幸存者，他们是新纪元的原住民。

玄夜如今已是神级巅峰，距离冥级只有半步。他同时担任帝国科学院的副院长和永恒学府修仙系的系主任——跨学科训练使得他在两个领域都如鱼得水。洛浅浅领导着帝国"弱衰减补偿工程"——这是全宇宙规模最大的科学工程之一，直接服务于"防止宇宙轮回"的终极目标。夏侯明已从监察团调查员转任到法典院担任高级顾问——他以调查员的身份搞了八百年监察工作，对制度漏洞了如指掌。令蕊仍然是法典院检察长——她被称为"帝国从不退休的正义之锤"，头发已全白，眼睛依然锐利。

"一千年。"陈霜说。她的头发里也有了银丝——她一直拒绝用修为去掩饰年龄痕迹。"路走得够远了。"

"但还没走到头。"李长生接住她的话。

他指着观景台下方的冥都城——最新的建筑群正沿着城南在扩张。扩建的目标是兴建"宇宙共同体第二总部"——一座由帝国与其他十二个独立文明联合建造的综合行政中心。它将作为全宇宙各种族、各文明在处理共同防务和共同资源问题时的协调平台。这是令蕊在两百年前提出的"跨文明政府间合作组织"的最终落地形态。

"五十个纪元前的太初绝对想不到——"陈霜说，"第五十一个纪元里有一群人类在搞跨文明政府间合作组织。"

"太初不是想不到。"李长生纠正，"太初是知道——但太初不是执行者。落实的是我们。"

他想起远在旧纪元那颗蓝色地球上的一切。那棵村里的老槐树。南京路地道里的泥浆。陈霜第一次拔剑时的剑鸣。小王熬夜熬出的那行灵符代码。老陈最后那一句"李队，最后一单送到了"。许冰手里握到最后一刻的法槌。所有这些人——所有旧纪元的伙伴——他们不可能看到了。但他们留下的东西——王宇因子、陈大勇因子、许冰因子——正在身旁的这些年轻人身上呼吸。

李长生没有说话，只是把掌心翻了过来。冥王令的纹路暗金色依旧。它波动了一下——不是危险感知，是某种更深层的回应，像是在说——你做得不错，但还没完。

是的，还没完。

宇宙的弱衰减还在等待补偿公式的精确解。宇宙共同体还在发展。监察团还在迭代。前方还有数不尽的未知维度、未知文明、未知挑战。但方向是对的——这个纪元的人类，已经学会了如何在繁荣中警惕僵化、在和平中保持创造力、在强大后不欺负弱小、在拥有绝对力量后还保有慈悲。

永恒之路，是在这样的每一步中走出来的。

路还很长。李长生在登高望远时的最后一瞥捕捉到了冥都城郊的一片空地——那块地一直没建房子。那是他特意保留的。地里什么也没种，只有土。新纪元最肥沃的土壤——是从旧纪元那颗蓝色行星上回收来的表土，混合了新纪元六颗太初恒星周边最原始的物质颗粒。土在风中安静地躺着。土下面没有冥王碎片，没有阵法机关，没有埋着任何法宝。只有土。

他当年在李家庄种地的时候，村里最老的老把式告诉他一句话："一块好地，你踩上去它不会叫唤。但你种东西下去，它就让你知道它是不是活的。"新纪元不是他李长生一个人的田。是数万亿人共同的田。他的活快干到一个段落了——法典成型了，大学运转了，监察团上路了，宇宙共同体开始架构了。但田里的活——让每一个在这纪元里活着的平凡人感受到自己的存在是有意义的——那是一万年、十万年、一百万年都做不完的事。

但他不着急。永恒的修士有的是时间。更重要的是——他不需要一个人干这活了。他身边站着陈霜，身后站着整个第二代帝国核心层。每一代人都会接续下去。田埂不会在某一天塌掉——因为不会再只有一个人蹲在田埂上修漏水。修田埂的人现在数百万、数千万、数亿。他们可能没意识到自己修的是田埂——在他们看来他们只是在做自己的日常工作：一个农业工程师在调整灵田的灌溉程序，一个法律书记员在归档法典修订建议，一个大学教授在教学生怎么在做技术开发之前先做滥用风险评估，一个母亲在教育孩子"欺负人不行"——所有这些细微的、不起眼的日常动作，加在一起就是在修这个纪元的田埂。

他把掌心翻过来。冥王令的纹路暗金色依旧——颜色和刚拿到时一模一样。它波动了一下。不是危险感知。是某种更深层的共振——像是宇宙基本结构在极远处给他发了一个确认信号。信号的意思是：你做得不错。但还没完。前方有新的维度等待探测，有未知的文明等待接触，有未来一万年、十万年、一百万年里随时可能出现的新的挑战和新的幸福。这个纪元会继续进化——不仅是文明的技术水平会进化，文明的"共同存续意识"也会进化。进化没有终点。

脚下的帝都在暮色中渐渐亮起灯火。纪念馆的油灯、学府的学生宿舍灯光、法典院白馆窗户透出的冷白荧光、居民区的暖黄灯光——所有这些光线交织在一起，在冥都上空氤氲成一片光晕。光晕的底下，石头上刻着的四个字——"以民为本"——在灯光下安静地等着明天早上第一批路过的人。

陈霜把手从剑穗上拿下来，悄然将手指穿进他的五指间。这只手跟千年前在西北大漠第一次扶他站起来时握住的是同一只。现在它不那么光洁了——指节上有常年握剑留下的一层薄茧，食指侧面还有一份被灵膳灶台烫伤的旧疤——那是她给刚入学的学生演示怎么炖甘草灵鸡汤时留下的。他握了回去。

路还很长。但脚在路上。路从旧纪元一座叫李家庄的村庄地头开始，经过了西北大漠的风沙，经过了帝国统一战争的星空，经过了新纪元从无到有的全部建设。它还会经过数不尽的未知——但方向已经确定了。

（第730章完）

# 第285章 老猫的正式入住

在第三卷接近末尾时，老猫做出了一个重大决定——正式申请在晚牧居长住。不是像以前那样偶尔路过蹭鱼——是以岛上的永久居民身份入住。他申请入住的理由是写在登记表上的——他的字跟他猫的体型一样——沉稳带钩:

"居住申请——申请人:老猫（凡名已忘，凡号灰脚，原属昆仑穆氏周边流离妖兽，后被晚牧居林牧在凡间青溪镇收容，长期从事夜间心理支援工作——职务:尾巴保暖师。申请长住的理由:(1)凡间的剩饭已经不足以维持我对鱼的勘探计划;(2)岛上有一个鱼精，我还没有与其完成'关于等的哲学讨论'的终辩;(3)岛上有两个人每天秀恩爱但不惹人烦——原因未知，我也想弄清楚这怎么做到的并把它和我的冥想融合;(4)我的尾巴在这儿有固定的适应对象（林先生和之后每一个会紧张的新人）——这使我在存在层面上感到我仍有用。附带备注:我不是不想走——是我每走一步这尾巴都像以前拍林牧脚背一样——自动知道什么时候该停，什么时候不管——这岛上的人不需要被管——只需要被尾摸——那不是一般工作——是共生。此致。"

苏晚在审批表上签了字——旁边加批注:"核准——附带一条要求:每天傍晚茶会期间必须出现在茶室东侧你最常卧的石台上——不是为了好看——是你的尾巴拍石台的节奏是我们茶会在自然背景音——少了它不管新来多少客人都不完整——你就把它当成你的自然契约义务——不用签——你的存在本身就是批准。"

老猫正式入住后的第一个日常是睡了一整天——他说这是在凡间攒了几百年的欠觉——现在岛上安全、稳定、鱼有人煮——不睡都对不起他对安全性终于达到阈值之后的反应——"这是对安全的最高敬畏。"

锦鲤在老猫入住后三周内和他完成了他申请入住时所提到的"关于等的哲学讨论终辩"。讨论地点在茶室旁的临水池——锦鲤在水中，老猫在石台。辩题:"等一个人——有没有最佳等待姿势？"锦鲤主张"最佳姿势是在茶壶里持续出水并适当吐泡击茶壶传声音——保持存在感但不侵占空间"，老猫主张"最佳姿势是安静地待在窗台，尾巴拍主人脚背的节奏和对方心跳节律保持同频——不做任何多余动作——只在对方需要时让他知道你一直醒着"。终辩最后两个人没有谁说服谁——达成了协议:"等——不存在最佳姿势——最佳的是等到了以后——之前所有的姿势都一起成了回忆——是猫尾也好、鱼泡也好——到时候都是同一个故事里的不同视角——叙述方式无关要紧——结果一致则以。"

锦鲤和老猫把终辩结果草拟成了一份简短的备忘录，贴在晚牧茶室的内墙正中央——两块极少年笔记拼在一起:"等的结果一致——历史仍然需要两版——猫版=尾版——鱼版=泡版。供后来者们参考——各选所好——都不错。"

苏晚在备忘录后面加了个脚注:"等你的人也许会以完全不同的形式出现——但当你们终于站在一起时——猫尾和鱼泡其实在本质同一件事——'存在——没有走——现在还在'。"

林牧看到这段话后——在他的旧执勤日志格式上——删掉最后一页的"苏晚=安全"并在新版写下:"老猫+锦鲤=日常同步——全岛所有在等的人——已无需独自等——因为岛上有比他们更老牌的职业等手——已转职为全勤守护安保——不离岗——永。入职表——归档——第285章——尾巴和泡在窗下水雾旁同节奏——降位稳定。"

晚牧居的常住居民从此有了正式在册的第三席和第四席——猫和鱼——都是不同方式在传递同一件"还没结束但不必担心"。

# 第四百四十七章 噬魂铃声

在你听到那个声音之前，你不会理解"灵魂被刮"是什么意思。它不是听觉。是直接发生在灵核深处的一种剥离感。像有人用指甲——不长不短、刚好能刮出疼痛的指甲——在你的灵核表面不紧不慢地刮过去。那种疼痛不是肌肉层面、不是神经层面，而是你灵魂的每一个构成单元都在同时大喊"疼"。

苏晚在四里外的山坡上站稳了脚。两枚噬魂铃在共振通道上同时鸣响。一枚在洞府附近——罗天衡的。一枚在她的方向——铃声从山顶某处传来。罗天衡不是一个人。他在暗处放了第二个掌握噬魂铃的人。他在围攻。

同修之法的共振通道正在撕裂。两枚噬魂铃同时攻击通道的两端，形成的共振反馈使通道的震动变成了撕裂。金色的丝线上出现了裂缝——裂缝的边缘是红的，像是从肉上撕开的口子。林牧在炉边的灵核已经在发出警告——他的灵气输出必须维持丹基稳定，根本没有多余的力量保护共振通道。他们的安全体系被掐住了弱点。

苏晚闭上眼睛，深吸了一口气。剑还在她手里。剑身的灵文闪着淡金色的光芒——林牧灌入剑中的灵力还在。但剑不是用来对抗噬魂铃的。物理武器对灵魂攻击无效。

她必须靠近才能有效打击。

她把灵核的旋转速度提起来——转速从化神中期的常规频率提高到了近乎能承受的极限。灵气在经脉中加速流淌，速度越快越能短暂抵御灵魂攻击。她朝洞府的方向冲去。但铃声响得越来越密。不是她离洞府更近了——而是罗天衡的第三个帮手开始同时摇动第三枚噬魂铃。三枚铃的共振叠加在一起，已经不是刀刃刮骨了——是三个方向的刀刃在同时刮。每刮一下，她和林牧之间的那条金色丝线就中断一瞬间。共振通道断裂的那一瞬间，同修之法就失效了。而在通道失效的那一瞬间，林牧的灵核要单独承受龙血藤残余龙气的内部反噬——他没人帮他分担了。

"林牧——"

她无声地喊了他的名字。

然后在同修之法断裂的那零点几秒内，她在自己灵核里看到了他的画面。不是真实的画面——是经过共振通道残留的、还没有完全消散的最后一丝神识共鸣。画面很模糊，但她看得很清楚：林牧在丹炉前跪着，双手按着炉壁。烧伤的那只手已经被血液浸透了，白布变成了一团暗红色的东西。他的牙关咬得很紧，嘴角全是血——灵核内部残余的龙气反噬已经让他受了很重的内伤。但他没有放开炉壁。他在一边对抗反噬，一边维持维火——不能停。丹基的火温一旦断开超一定时限，寿元丹就全完了。

他在用自己的丹田接住丹炉的所有高温。

同修之法还没恢复。通道还在被三枚噬魂铃持续攻击。每一次断裂之后不到一息就又被震断。反复断裂——连起来的尝试总是被打断。苏晚和灵核之间的共振通道像个被反复砍断的绳索，绳头上的残余丝线越来越少，两根绳再接起来的难度越来越大。

然后她的灵核忽然传来一股极其强大的冲击——不是噬魂铃。是林牧在对着断掉的那截绳头往里灌注了什么东西。是一种口诀。九劫龙诀第一小段——他前世只剩下的那一小段能在化神级别使用的内容。他把它完全倾注到了同修之法的共振通道中。口诀不是他驱动的——是他自毁性地把口诀直接钉进了她的灵核。

然后她感觉到了。

九劫龙诀在她灵核里自行运转起来。龙族功法的暴虐能量沿着同修之法的断裂通道逆流而上——从她的灵核出发，一路向西，冲回林牧的方向。龙气的冲击力吞没了三枚噬魂铃的灵魂波动。铃声被龙吟盖住了——不是她的耳听到的吟声。是她的灵核中响起的古老龙吼。万年前的龙族意志在它第一任主人死后残存的那一小帧片段里苏醒了过来——以她为核心，爆发了一次。

三枚噬魂铃在同一个瞬间失去了声音。铃声不再是连续的——三枚都在震颤，但它们的波动被龙吟的反馈撕裂了。反噬的力量同时击中了三条攻击线上的人——罗天衡在离洞府不远的一处石缝间闷哼一声，跪倒在地。噬魂铃从他手里脱落。另外两个暗处的操控者也同时被龙吟弹飞出去。

同修之法在龙吟的回荡中恢复了。不是金色的丝线——是淡金色的、带着隐约龙纹的丝线。那条连接她灵核和林牧灵核的线，现在不再只是一条细丝——变得浑厚、坚韧。九劫龙诀加入后，共振通道已经不仅是两个人类修士的同修，还带上了上古龙族认可过的印记。在龙墓中获得认可的两颗灵核——和龙族的远古意志产生了联系。这种联系不会轻易断。

噬魂铃哑了半炷香后，罗天衡从地上爬起来。他把掉在雪里的铃铛捡起来，低头看了一眼——铃铛内部的符文有一大半已经碎裂。这个噬魂铃废了。被九劫龙诀正面的灵魂冲击击穿后，铃铛的灵阵核心已经被摧毁。

他的表情变了。不是恐惧——是愤怒。是一种更尖锐的东西——"计划不是这样的"。

这片昆仑山上只有两颗噬魂铃。现在两颗都废了。韩山和赵铁被灵核封住——没有他在旁边解封，醒不来的。而他一个人是元婴中期，对付一个化神中期加一个在炼丹炉边被严重反噬的化神后期——还有一个金丹期帮手被击伤了、另一个失踪了——他估算了自己的胜率。

"——不到两成。"

罗天衡咬着牙把噬魂铃扔进雪里，转过身，朝查木拉镇的方向快速离去。他一边飞一边在灵核中对着远方某个未知的人发出一道传讯。他的灵核传讯穿过风雪，消失在更高寒的方位——他在叫援军。

苏晚赶到洞府时，林牧还跪在炉边。他没有倒下，但脸色已经白得像里面的雪。他整个人像燃烧过后刚刚熄灭的炭——烧伤的手还在炉壁上，但已经没有了体温。背部的衣服全被冷汗浸透了，结了一层薄薄的白霜。丹炉里的火倒是稳了。经历过了这一轮震荡，丹基的融合反而前进了不少——寿元丹在极限环境中往往更易成熟。但他身体已经快烧干了。

苏晚在他身后跪下来，把双手按在他后背上。灵核共振重新对接。她把自己的灵核的灵气直接转入他的经脉。她的灵气比之前柔和了很多——不再是化神初期那种粗糙的输出。她在洞口那些天的反复练剑，已经把她的灵气变得细腻而锐利。

林牧的肩膀微微震了一下——不是因为疼痛。是因为他感受到了同修之法的共振通道上多了一些之前没存在过的内容。不只是她的灵核频率对上他的频率。是她在给予。不是"以高扶低"——而是"你烧干了自己来维持它，我来给你加满。"

他闭上了眼睛。丹炉里的火焰继续燃烧。金色和暗红色的光芒交在一起，在石壁上画着更新的一幅画。

（第四百四十七章 完）

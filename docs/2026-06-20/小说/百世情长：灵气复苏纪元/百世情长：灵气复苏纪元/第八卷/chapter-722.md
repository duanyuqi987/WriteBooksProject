# 第七百二十二章 联手对抗

第二天的黎明，林牧从上界下来了。不是苏晚求援——是他自己在折叠空间中感知到了地面西南山区的异常灵气波动。他的第四轮探索数据中记录的那片"空白区"和这次地面兵变中神秘首领面罩上的灵力频率完全吻合——不是同一个人发的信号，但出自同一个空白区的古老阵法。这证实了那位"上界先驱"不是真正来自上界的仙人——他只是在利用空白区中的某件古老法器在模拟上界气息。是地面上的某人在狐假虎威。

林牧没有独自去追那个首领。他先飞到了太湖灯火塔。苏晚正站在塔顶看叶小雨发来的实时战报——第二路敌军已在桂花园总院前瓦解了近五成——剩下的基本是仍不肯放弃的顽固分子，被石头用一锅粥再一锅粥慢慢软化。

她听到脚步声——不用回头也知道是他。她的后颈感知到了他的灵力频率——和几百年来一样的振幅。她转过身——他的道袍还是那件靛青色旧道袍。他的眼睛是温热的——没有前世那种冷光。他手里拿着一张新的便签——黄色的，上面只有几个字："第二扇门的钥匙——找到。"

苏晚接过便签。她没有问"是什么钥匙"，而是先做了一件事——从她随身的小灵囊里拿出一碗保温的桂花粥。粥是他最爱的那种，温在灵火上的——桂花是早上叶小雨从院里树上现摘的。"先喝——喝完再说。"

林牧接过碗喝了两大口。他放下碗，指着灯火塔控制台上的灵网地图——"那个'上界先驱'的位置我已经定位了——他躲在西南山腹一个古修洞府里。那个洞府在上界折叠空间的'空白区'有对应的共振点——我可以通过两扇门链路直接干扰他的法器。"

苏晚听完后没有犹豫。"我去堵他在山里的实体。你在上面干扰他的法器。两面夹击——让他没有退路。不是消灭——是让他有机会在最后选择投降。"

林牧点了点头。他看了一眼地图，又看了一眼苏晚——她的眼睛和几百年前城楼上的"铁娘子"一样，沉稳、清晰、不犹豫。不同的是——这次不需要一个人扛。他有他的路，她有她的路。两人在同一座灯火塔下分头走向两个方向。

（第七百二十二章 完）

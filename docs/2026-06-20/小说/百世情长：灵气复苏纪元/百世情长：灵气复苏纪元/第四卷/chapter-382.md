# 第三百八十二章 云同步

炼虚后第五年。两人决定做个测试：利用虚界备份特性，在各隔了两百里外的各自地点同时"关闭"身体五感，只保留虚界中那个"备份"的灵识——看看能否用那个灵识找到彼此。测验成功。苏晚在清泉诊室的椅上一闭眼——下一刻她发现自己的"虚我"出现在蜀山后山——林牧正站在那里，手搭在还旧剑上。两人在虚界中能相互触碰——触感和实物一样。

她说："这就像云端连线。"他说："对。这跟我们刚认识时你拨号上网一样。"

此后他们常以此方式远程会面——当其中一人在远处处理灵网异常时。若想见面不必飞行——只需闭眼入虚。尽管这只在炼虚后可行。但这种方式"消耗"较大——苏晚把它列为"每周只能用几次"。林牧问为什么。她说："因为虚界见过后，再见面时没惊喜了。我想留些见面惊喜。"于是他欣然接受。

有时她夜里会泡一壶当归茶然后入虚——把其中一杯"放在"虚界里他身边。他伸手接——虽然虚物不能实际饮用，但虚杯里有她微微的热度和茶的气味。他把那杯虚茶放在他床头石台的对应位置——第二天早上醒来便看到位置上有一杯实体的当归茶——她那边早已把茶放在对应位置等候入虚。这被她称为"物理层同步"。而他只微笑。

# 第688章 老陈的后代

处理完王宇的血脉延续，李长生转向下一个：快递员老陈——陈大勇。

老陈死得更早一些。在旧纪元统一战争的第七个大决战中，第七星域被叛乱残党的一枚超新星引爆装置威胁。那颗超新星位于第七星域的核心枢纽区——如果爆炸，连锁反应会把周围一百光年以内的所有恒星全部卷进去，形成一片恒星级的链式爆炸。一整片星域都会被毁灭，连带数十个殖民行星和数百亿条人命。

当时帝国主力舰队被牵制在另外三个战场上。能调动的最快一艘战舰是老陈的座舰——一艘由快递运输船改装的中型飞船，船壳上还印着旧纪元某家快递公司的标志——那只大鸟的logo的漆都磨掉了一半，只剩半只翅膀还看得见轮廓。老陈带着三个自愿跟他一起去的年轻士兵，开着这艘破船在虫洞通道里全速飞行了十六个小时。船上的引擎一路上爆了三回——老陈每次都是自己钻进发动机舱，拿扳手和临时焊条抢修。他的青芒剑在修引擎时被用来做焊接源——剑尖顶着发动机胸口，剑气熔化合金裂缝。

快到达引爆装置附近时，三个年轻士兵都做好了一去不回的打算。老陈看了他们一眼，只说了一句话："你们三个还小。回去。这个单我一个人送就够了。"

他把三个年轻人塞进了救生舱弹射出去，自己驾驶那艘破船直接开进引爆装置的引爆核心。引爆倒计时已经走到了最后三十秒。引爆芯是一颗由反物质约束层包裹的微型奇点——一旦约束层解压完毕，奇点会在一微秒内吞掉周围的一切，然后反弹为超新星级别的大爆炸。

老陈站在引爆芯面前，只有三秒时间。他拔出青芒剑。这把剑跟了他一辈子——从他还是一个三品灵根的穷快递员时就挂在腰间。剑是好剑，是当年李长生在西北大漠送他的。他握紧剑柄，深吸一口气，用尽全力将剑劈了下去。在引爆倒数最后一秒时，剑刃斩入了约束层，将引爆芯劈成了碎片。超新星没有炸——但引爆核心的反噬能量同时释放，一股由奇点级密度转化为纯热能的冲击波把老陈整个人烧成了灰烬。从头到脚，每一块骨头、每一寸皮肤、每一根头发——全部变成了一阵发光的灰。

李长生记得老陈死前的最后一句话。那句话是通过帝国舰队的通讯频道传送的，传输质量很差，杂音很大，帝国通讯兵修了三天才把那段录音修复清晰。修复后的版本是："李队——老陈的最后一单——送到了。"

快递员送了一辈子的单。在深圳的时候，他送的快递是鞋子、衣服、电子产品、外卖餐盒——那些东西值不了多少钱，但每一件都是某个具体的人需要的。后来到了帝国，他送的变成了灵气补剂、战略物资、军需装备——价值高了无数倍，但本质没变——每一件都是前线某个具体的人需要的东西。

而他的最后一单，是送回一个星域的平安。一百光年内所有行星上的人们——那些正在煮饭的、正在哄孩子睡觉的、正在写作业的、正在种地的普通人——都不知道，一个曾经的快递员刚刚用命把他们所有人的明天保住了。老陈在乎的不是他们知道不知道。他只在乎——"单送到了"。

现在，李长生要让老陈的血脉在新纪元延续。

老陈的天赋跟王宇完全不同。老陈没有一点技术才能——他当年连智能手机的快递APP都用不明白，每次都是小王或李长生帮他调。但老陈有一种极其罕见的直觉：他能感知到"流量"。不是数据流量，是人、物资、信息在空间中的流动规律。这种直觉让他在物流和交通调度上表现出惊人的才华——他不用看地图，单凭感觉就能选出最通畅的线路。在帝国统一战争中，他的这种天赋被放大了无数倍：他能感知整个银河系级别的物资流向，知道哪些星域需要多少资源、走哪条航线最高效。

帝国后勤之所以在战争中没有崩溃过哪怕一天，很大程度上是因为老陈的存在。那些在战场上杀敌的将军和修士们或许不常想起他，但每一个前线士兵拿到补给包的时候——里面的灵符丹药、新的法器、热乎的灵膳、甚至偶尔能附上的一封家书——都是老陈亲手设计的物流体系送到他们手里的。

李长生把老陈的这种天赋编码进另一个基因序列——"陈大勇因子"。这个因子携带的内容是：对空间和流动的超常直觉。它能让人在无需学习的情况下，天然感知物体在空间中的最优分布和运动路径。简单说——未来的"老陈的后代"一旦出现，会天然地懂得如何把东西从一个地方高效地运到另一个地方。不是算出来的，是感觉出来的——像老陈当年在深圳送快递，明明从来没看地图，但他就是知道走哪条路最快。

这个因子的激活条件也很苛刻：继承者必须从小就在需要大量体力劳动和空间判断的环境中成长，必须具备强烈的"把活干好"的责任感，必须从底层起步。优雅的书斋里出不了老陈的后代——必须是在工地上、在拥堵的马路上、在最忙乱的物流中转站的嘈杂环境中，这个因子才会被唤醒。像老陈自己——他是河北农村出来的孩子，初中毕业后在工地上搬过砖，在工厂流水线拧过螺丝，后来到深圳做快递员，靠一辆电动车每天跑一百多公里。那些年的底层历练把他性格里最粗糙也最踏实的东西磨了出来——帝国后来给他授大将军衔的时候，他还保持着快递员的习惯：讲话永远不拐弯，答应的事死也做到，吃饭时碗里一颗米都不剩。

做完这件事，李长生在纪念馆中也给老陈建了专门的模块。

模块里保存了一段全息影像：老陈站在一个刚修完的农业示范区中间，扛着锄头，满身泥浆，笑得像个刚收完麦子的老农民。背景是一片绿油油的新麦田——那是他在帝国三年大饥荒之后，亲自带着后勤工程兵团开垦出的一片高产品种试验田。他站在田埂上，脸上的泥点子都没擦，对着镜头说了一段话。那段话是帝国后来农科大学的校训——"土地不会骗人。你老老实实下种子，它就老老实实长苗。别耍滑。"

旁边是一块石碑，上面刻着老陈自己写的字——"种地的老百姓，是帝国的根。"老陈的字很难看，歪歪扭扭的，像是小学三年级的学生写的。但他就是不让人找人代笔——他说自己的话自己写，字丑也要自己写。

那是老陈在战后说过的话。当时小王在旁边笑着说他老土，但老陈一点都不在乎。他知道自己从哪儿来——从一个天天给人送快递的底层劳动者出身。哪怕后来当了征北大将军、银河后勤总司令，他也从来不觉得送快递丢人。他在一次帝国晚宴上——在一群穿着华丽法袍的贵族修士面前——直挺挺地站起来说："我是送快递出身。送快递的人最清楚一件事——东西送到对方手上之前，它不算送到。"

李长生在这个模块的入口处多加了一行字："老陈说过——任何值得做的工作，都值得做好。"

然后在全息影像旁边放了一把锄头——不是真的锄头，是纪念馆构造的虚拟器物。这把锄头的柄已经磨得光滑发亮，锄刃上有几处缺口，显然用了很多年。锄头旁边还有一个小小的物件——一辆电动车的全息模型，车篮子里放着几个快递信封，车身上印着那个半只翅膀已经磨掉了的大鸟标志。

来参观的人看到那把锄头和那辆电动车，会先愣一下，然后明白——这些东西不需要解释。锄头和电动车代表的是同一个人：那个从田野和街巷里走出来的人，一辈子没丢过自己的那个"根"。

两个最重要的伙伴，都有了血脉的延续。

（第688章完）

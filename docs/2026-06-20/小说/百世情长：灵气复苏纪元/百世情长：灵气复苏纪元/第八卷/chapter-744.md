# 第七百四十四章 传统保护席位的诞生

旧势力大族长廖东辰喝粥后的第三天，修人共治会通过了《传统保护席位的试运行规则》——这是沈教授毕生最骄傲的成就之一。规则允许那些对修人共治持不同意见的个人或群体——只要他们没有采用暴力——在共治会中拥有观察席位和有限发言权。有限发言权的意思是：他们的发言会被记录在案，但不列入投票权重。目的是让他们被听到——而不是让他们做决定。

廖东辰本人申请了第一个传统保护席位。他走进灯火塔广场的时候，背着很沉的一个包裹——别人以为里面是古阵法卷轴或珍贵灵宝。他把包裹放在会议桌上，打开——是一整袋碎铁片。是东海渔村那口被他的部下毁灭的灶台的残铁。"是我让人毁的回东山，所有碎片我全收回来的。我今天放在这里——不是道歉——是提醒自己：曾经毁过一口煮粥的锅。——廖东辰。"

孟长青看到那些碎铁片后把手伸进衣袖，掏出他那颗鹅卵石，放在碎铁堆旁边。"我那边是一颗河边捡的石头——加起来——是两块没有任何灵力的普通石头和一堆碎铁。但它们在灯火塔的照下重量是一样的。——孟长青。"

苏晚没有收走那堆碎铁，也没有把它们重铸成新锅。她让叶小雨在灯火塔展馆里专门辟出了一方陈列区——两颗鹅卵石和一堆碎铁片。展签上写着这些字的由来——一颗来自一个因为灵根不好被多次拒绝的男人，一颗来自一个曾被抛弃在山门口的孩子，一堆来自被仇恨毁掉的一口锅。石头的弟子们在展区旁边的墙上贴满了便签——每张便签上的措辞不同，但意思相同——"这些不是耻辱——是证人。"

廖东辰在后来的观察席上极其安静地观察了三个月。他没有发起任何一次反对动议。他只是坐在共治会后排，看着那些凡人和修士围着一张圆桌，你一言我一语地商量着他们之前从不曾商量过的事。他的副手有一天悄悄问他——"族长——我们是不是输了？"廖东辰沉默了很久——"输了，但输得比以前赢了还要好。"

（第七百四十四章 完）

# 第八百九十章 飞升之门——当下的门

将时间拉回到一个接近此刻的视角：飞升之门正常运行中。人间青云山谷星光窗依然天亮夜亮。石桌上的茶杯仍有余温。星眸正在用极低能耗循环播放几千年来子夜鉴收藏的经典片段——恰巧又切到陈望海在飞升前一夜对阿渔说的那段话。

一个刚学会用灵力的小学徒奔跑进谷——他气喘吁吁地在石桌前站定。他叫小禾，十岁，父母都是刚飞升不久的修士。他是山谷附近新童苑的孤儿。守门人不常在山谷，但这几年的春天总在。他着急的问题非常简单："门会关吗？我爹妈进去了，我什么时候能进去？"

苏晚挨着石凳弯下腰——语调缓和平静："门不会关。你进不进去它都不会关。你修炼慢慢来——急的话会忘记葱。"

小禾不懂葱是什么暗号——但他从她的语气里读出了"不急"。他那扑通乱跳的小心脏落定下来。"那我长大变厉害了——你们还在这里吗？"

苏晚伸手在他泥乎乎的小手心上放一块桂花糖。"在。"

这时林牧端着新泡的茶从厨房走出来——对着小禾点了点头。他把糖纸剥好，放在小孩的另一只手心："双份。信任永远双份。"小禾跳着跑出山谷，糖纸贴在两只手中微微闪光。

这是飞升之门无数普通日中的又一天。但它承载了数十万年前天台上第一个念头"这光是什么"到如今"这是门——不会关"的全部演变。对守门人来说——这不是终点，也不是起点。只是一个极其稳妥的当下。他们仍偶尔去遥远星域做局部的星际窗铺设——但每次回来山谷里的小葱段总有一层鲜嫩的茬。

晚间两人依然坐在石桌边上喝茶。星眸转入休息态——只在角落闪动着极微弱的"安"信标。苏晚托腮看着茶波中的星窗倒影。"以前推演三百遍——现在一遍都不用了。信任已经自持。"

"嗯。但明天我还是会推演一遍——为了检查门对'新窗友'的收信是否稳定。"

"你不是说一遍都不用？"

"这是爱好。不是必要。"

苏晚低声笑了。他永远会推演——不是不信任，是关心。而她永远可以看着这个一再把推演变成温柔的推免者。山谷慢慢陷入夜幕——门的光一如既往从星窗吻向空气。桌上的茶杯半空——但那是给还没到的人预留的。

一切如常。而第九卷的终章也如常接近——随着每一天不急不徐地往前推展开来。

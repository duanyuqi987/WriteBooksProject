# 第658章 新旧纪元

李长生从维度裂缝里回来的时候，冥王号舰桥上所有人仍然站在原地。不是不敢动——是刚才他走的那段时间里，所有人都在用自己的方式准备。陈霜把剑从剑鞘里抽出来又插回去三遍。龟相把系统自检跑了两遍——把李长生的全部能量数据备份了三个不同的物理位置。小王坐在全息操作台前面，把自己的履历表从头到尾翻看了一遍——不是看成绩，是在看自己在"如果船长回不来"的情况下需要下一步做什么。老陈把随身带的旧货单——一张十年前最后送的快递单——展平在手掌上，用指腹把纸角抚直。

李长生跨进舰桥的时候，所有人四散在各处的注意力同时收回来。

"你们全部必须知道一件事。"他说。他的声音没变——跟平时一样。但语气里有一种从来没人听过的成分：那是从域外带回来的、和太初面对面对话后才会有的平静。

他花了一个半小时把太初跟他说的宇宙轮回四阶段全部讲完。没有遗漏任何一个关键细节。包括两年启动窗口、三千年缓冲期、旧纪元消散时意识扫描——以及最终的新纪元诞生方式。讲完之后舰桥上非常安静。这个安静是所有人的认知在被信息压垮之前的那段短暂的真空。龟相最先开口——不是因为他不震惊，而是他必须用自己千年经验马上做一件事：把李长生刚才说的全部信息录入宇宙联盟的正式档案——这份档案将被保密直到适当的披露时机。但录入过程必须现在做。因为他是这宇宙里唯一一个来自上上个轮回的数据库管理员——他知道这种级别的信息如果不在第一时间被正式记录——后面一定会被偏见和失真层层涂改。

"全部记录完毕。"他的声音非常敬业——但那声录入完毕音里有一丝极细微的颤抖——不是恐惧——是他第一次在活着的时候知道:自己的原体现在在太初的永恒之库里好好的——所有他失去的族人们现在也全部被好好保管着。这消息他从李长生的转述里听来——他没有来得及自己消化——但他知道它的分量。

刀疤的声音从角落传来——比平时轻了一大截:"三千年——够我再练几次体修吗？"

李长生转头看着他。"够你练成你不应该练的。"

所有人都极轻地笑了一声。不是开玩笑——是在最沉重的压力下面——草根天团这些人唯一会做的事：把压力做成一句简单的话。

然后小王开口。他的眼镜已经歪了——他没空扶。"两年启动窗口——旧纪元从开始减速到完全停下——我能在这段时间里把跨宇宙备份系统跑完吗？"

"能。"龟相代李长生答的。他和太初的运算能力不是同一级——但他按太初给的时间表用舰载AI模拟了一次——备份的系统移植时间在全力运行下需要约九个月——两年的启动窗口绰绰有余。

"然后是三千年缓冲——"陈霜说。她站在李长生旁边。剑横搁在膝盖上——她刚才听完整个过程后不再反复拔剑了。不是因为懈怠——而是知道了在三千年的缓冲期里——她用剑的机会不再是战斗——是守护。

"你觉得——旧纪元终结的时候——我需要交自己的剑吗？"她问李长生。

"不需要。"李长生说。"你的剑会被共同保留——旧纪元最高端的意志物体全部会在新纪元的启动框架中作为'根记忆'留在奠基常数里。从新纪元诞生第一秒——你的剑就成了新宇宙的传说前缀——没人能忘。"

陈霜低下头看着剑身的反光。那不是一柄传说中的神剑——只是她从凡人的铁铺开始一路升级到现在。她最初握剑的时候只是把它当一柄普通的铁剑来挥——从没想过有一天这把剑会被用作新宇宙奠基的铭刻。

李长生转向所有人。

"从现在起——冥王帝国所有核心系统全部转入'轮回准备状态'。不是恐惧——是准备。每个兵种、每条生产线、每个数据模块——都必须在两年的启动窗口到来前完成备份。这两年内我们还要继续——不是因为敌人还在——是必须确保宇宙边缘的每个微小文明都被通知到并理解自己的选择权。没人能帮所有人——但我们可以把消息传到。"

刀疤站了起来。他身上穿了铠甲——但站姿明显端正了很多——像当年从部队被调入禁卫军时那样。

"禁卫军——接管所有通讯中转站的安全。"

"律师团——开始起草第一部跨越旧新纪元的暂行法。"许冰跟着站起。

"我起草第一批能源和物资派送计划清单。"小王已在全屏上开始写出第一行代码——一个在旧纪元终结前一秒会自动开放所有备用能源给基层的分布式新式网络——他在舰桥上直接把初稿扔了出来——需要六个月的开发——他能完成。

整个舰桥开始动起来。不是乱——是被"任务中心"忽然注入了超过所有人个人极限的凝聚力。因为他们知道——这一切的源头不是战术——是李长生刚才带回来的那些来自太初的许诺：旧纪元不会被毁灭——是圆满收获。

（第658章完）

# 第840章 短暂出现后的消失

现身十息之后，光升上去，李家庄夜空回复了墨蓝。人群没有呼号，没有追赶，没有任何一个人试图用灵力探查光退去的方向——不是不想，是本能地知道。那是两盏灯，不是来做客的。回来一趟，看了灯还在，然后回到自己需要守的地方去了。不需要送。

很多人留在原地坐到了清晨。不是等他们再出现——只是想在那个被他们眼神扫过的地方再多坐一会儿。有些上了年纪的修士从李家庄村口石板上捡起一片落在土里的光屑（那不是物质——是光在空中消退时凭空留存的最后一点余感——无法收集存储），只在捡起的那一瞬感觉到体温。然后余感就没了。但手热了一整夜。天亮的时候，村口大槐树底下的油灯有一盏没有灭。不是灵灯，灯油盏里剩将近一升棉籽油。不是超自然现象——是因为不知谁在那一盏的底芯里压了小半块固体凡蜡。蜡融得慢，燃到白天才断。被后人写成"不灭灯"的——其实并不是神灯，只是蜡放得厚。这件事后来传出去以后，每年万年祭的第二天，都会有人专门在村口放一盏厚蜡油灯。不挂牌子，不争位置，只是把蜡压厚。压蜡的习惯从一个老妇开始逐步扩散——她此生唯一的技艺是种蜡豆——她把封禁地的方向刻在压蜡模子上，但模子从来不进任何宣传报道。她的遗言只有一句："灯油不怕土。"

李长生和陈霜的意识在封禁地中重新安静下来。

十息的现身，消耗了他们大量的意识能量。不是生命力，而是意识在光网和外部空间之间的转换损耗。混沌本体在他们回来后做了检查——两人的意识结构没有损伤，但需要一段时间的恢复。

"值得吗？"混沌本体问——不是质问，是想从他们嘴里获得一个关于外面世界的数据点。

"值得。"李长生说，"不为了让他们看我们——是为让我们看他们一眼。一万年后——地还是那片地。人还是那些人。有些人长了翅膀，有些人多了几只手，有些人变成了光。但做的事没变——种地、炒饭、写信、晚上挂灯、压蜡。一万年前的日常一点都没变。"

"这很重要吗？"

"很重要。我就是为了这个日常去守护他们的。如果他们不再日常了——变聪明，变大，变成了我害怕变成的样子——那我会觉得我守错了。但他们没有。他们更强——但依然煮饭、纳鞋底、往石板上搁灯油——在所有的进步之下，日常没变。"

陈霜的恢复比李长生快——剑修的魂魄天生恢复力强。她回来之后的第一件事是在封禁地的意识空间里放了一个东西——是她在现身那一刻从李家庄院子的泥土中采集的一小段灵气影像。不是实体，是她在万年间从未见过却一直想见的柿子树根部的影子。她把树根旁边的泥地映在大槐树下的蹲姿后面——将两片不同时间阈限的李家庄合成了一张不存在的图。两个人坐下来，像从前在堂屋里剥玉米一样，安静地看那张虚构但真实的黄土地。

"一万年后——还是这个味道。"李长生说。

"什么味道？"

"没变的味道。"

混沌本体也安静了。它没有再问任何问题。它将他们在封禁地中的所有波段都记录在光网底层。不是归档——是让它自己可以随时重温这一万年所有的日子。它在储存中给这些日子命名。不是编码序列号。是："陈霜第一日"到"陈霜第三千六百五十万日"，"李长生第一缕"到"李长生第一万缕"。它不用时间做索引。用他们。

（第840章完）

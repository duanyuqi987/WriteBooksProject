# 第663章 旧纪元结束

两年后的某一天，太初的轮回启动信号在同一时间被全宇宙所有智慧生命感知到了。

不是通讯信号——不是广播——是宇宙基础物理参数集体下调了一个极其微小的幅度。幅度之小是：任何科学仪器都测不出来——它是不可量化级。但任何拥有灵智的生命体——不论是地球上的农民、天琴座老观察员、深海鱼虾、超维晶体生物——全部在同一时刻感觉到了一阵极其轻的——就像整个宇宙轻轻地打了一个顿。不是颤抖——是悠悠的、深深的、温暖的、全包围式的"缓慢减速"。

从那一刻起，旧纪元正式进入减速期。

减速期的第一年——全宇宙所有文明不约而同地做了同一件事：停止战争。不需要李长生的命令，宇宙联盟的任何决议都没有这个效果——是宇宙本身的状态让人无法再持续对抗。当任何一个人在战斗之前和之后所感受到的宇宙都在安寂地放缓——再凶狠的战意都会在对比中变得毫无意义。一些已经持续了数千年的星际对峙在减速期的前六个月内各自被单方面停止——不是和谈——是默默停手，对岸没有趁机推进。双方都感受到了同一种无声的征兆。

第二年开始——减速变得更明显了。不是数字级别——只是"感觉"。旧纪元的恒星们开始集体变暗——不是熄灭，是变温柔。太阳的光在地球上的正午也不再刺眼——仍然明亮，但那种明亮从"燃烧的炽烈"变成了一种"接近黄昏色调"的温暖。老人们坐在院子里晒太阳会觉得晒得比以前舒服——孩子们继续玩他们该玩的——只有星舰上的相关科学家们在拼命观测数据——数据完全正常，但"感觉"是旧了。

李长生在第一年期间跑遍了冥王帝国的每一个重要据点——从月球基地到天琴座前线。他每到一个地方就做同一件事：坐在当地的基层会议室里，和驻地士兵、补给员、战备维护班一起喝一次茶。不是视察——是"坐坐"。冥王帝国的士兵们起先很紧张——后来慢慢发现他真是在坐坐——就放松下来。最后一次坐在天琴座前线驻地时——一个刚刚服役不到三年的年轻守备兵小心翼翼地问了他一个问题:"李……李总——您以前真的种过地吗？""种过。种的苞米。一亩地一百二十斤。"

"那您——现在种什么？"

李长生对着他看了一会儿。他伸出手——右掌上那四层混沌纹和一线守护者的银丝标记在驻地灯的淡光下微微闪了一下。

"种时间。跟种苞米差不多——你也得等——等更久。"

减速期的第三千年——最后一年。宇宙联盟档案记录下了一个震撼所有人但无人反驳的事实：这一年，全宇宙所有文明同步经历了自身发展的最高峰。不是竞赛——是"成熟"。每一支存在了至少千年以上的文明都在这一年里把自己积累了数万年的全部文化底蕴、艺术极限、哲学思辨一次性"开"完了。数百万行史诗在这一年内同时被写完——每一架古老的乐器同声在末日感与荣耀齐奏的复合情绪中振动最后一响。不是因为悲观——是所有的付出终于同时到了说话要交卷的时候——这一刻的宇宙——是它的极致。

然后——旧纪元最后一天的黄昏到了。

李长生和陈霜并肩站在月球基地的瞭望塔上。草根天团的全部成员分散在塔台和下方基地的各处——龟相缩在壳里——小王对着全息屏——刀疤立正站着——许冰翻着她的终审稿——老陈把那张旧货单放在膝盖上——老马正在最后检查防御设备，但手慢了半秒——林晓坐在观景窗边安静地看着窗外——小胖在柜台里做了最后一道菜。

全宇宙放慢了最后一次。最后一道光从各个恒星发出——温柔极了——接着所有光开始缓缓地、一致地减弱——不是黑暗——是无声的落幕。天琴座老使节透过跨宇宙信道对苍白的画面说了一句——"大归还——原来这么美。"

最后一缕光暗到能被含在眼底的体积时——太初启动了第二阶段——旧纪元终结。一微秒内，全部物理法则同时停止运作。宇宙在轻柔的寂静中静止——然后所有"完成了"的意识体被一缕暖光带离母星——收入永恒之库。陈霜的手在李长生掌心里——稳稳的。他们一起看着这一切发生——在被静止的宇宙最后一帧画面——像一幅无垠的巨画——静穆着——所有人的脸都永远被记住。没有告别——只是"换帧"。

（第663章完）

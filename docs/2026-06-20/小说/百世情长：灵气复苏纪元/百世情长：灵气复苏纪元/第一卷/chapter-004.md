# 第四章 IT程序员的异常代码

早上八点四十分，林牧比平时晚了二十分钟到公司。

不是因为睡过头。他六点五十就醒了。醒来之后他在床上躺了很久——久到闹钟响了第二遍他才按掉。他躺在那张单人床上做了一个决定：今天要观察一下自己。

不是去医院挂精神科。是他想知道昨晚地铁里发生的热流会不会再来一次。

所以他刻意放慢了所有动作。刷牙的时候感受了一下口腔对冷水的反应——正常。穿鞋的时候注意了一下脚趾对鞋底软硬的分辨——正常。走在城中村的巷子里，他试着用昨晚那种"不在眼睛里的感知"去捕捉周围人的体温——什么都捕捉不到。路边卖煎饼的大妈体温大概是三十六度七，但他是根据常识推断出来的，不是"感知"出来的。

正常的。一切正常。他像一个正常的上班族一样走进地铁，抓着横杆，低头看手机。

他没有感知到万分之零点零几的任何气体浓度。站台上也没有比车厢更"厚"的空气。

那股热流没有回来。

昨晚的事在日光下自动降级成了一桩小概率事件——"大概是隧道里某种空调管道泄漏混进了奇怪的化学物质，导致了身体的异常反应"。他接受了这个解释。暂时。

八点四十分到工位的时候，小赵已经开了三台虚拟机在跑测试。林牧把背包挂在椅背上，注意到小赵的桌面换了壁纸——昨天还是极光的截图，今天已经换回了默认的Windows风景照。公司的其他工位上也有零零星星的人在讨论昨晚的天象。坐在林牧斜对面的产品经理正在和一个实习生讲"昨天晚上那个光绝对不是极光——极光哪能到这个纬度"。实习生点着头说"是啊是啊太神奇了"，一边偷偷在底下刷微博。

办公室的气味是固定不变的。速溶咖啡、打印机碳粉、中央空调滤网上积了三年的灰。林牧对这层气味的适应时间大概是进电梯之后的七秒。七秒之后鼻子就不再有判断力，所有异味沉入背景。

"林哥，昨晚那个支付超时后来好了吗？"

"好了。跑完了，全绿。"

"那就好。我刚才去看了一下监控，昨晚凌晨两点多又报了一次相同的超时，但三秒之后自己恢复了。"

林牧把笔记本放下，接上电源，按了开机键。"三秒？"

"嗯。能自动恢复，大概不是什么大问题？"

"不清楚。"林牧坐下来，"可能是接口那边在做维护。"

小赵没有再追问。他戴上了耳机，开始今天的测试用例编写。

林牧打开了昨天写的那部分代码。购物车排序逻辑。不是什么复杂的模块——用户在购物车页面点击"按价格排序"，后端返回排序后的列表，前端渲染。他昨天已经把核心逻辑写完了，今天的任务是做边界处理：价格为空、价格为零、价格为负数、价格超过上限。

他打开IDE，找到对应的函数，开始往里面加if判断。

写到第四个判断的时候——价格超过十万的商品不参与排序——他发现代码的行为不太对。

不是逻辑错。是渲染错。

他在本地浏览器的开发者工具里打了一个console.log，想打印排序后的数据。控制台里跳出来的不是价格数组。是一串奇怪的符号。

这些符号不是任何字符集里的字符。不是中文。不是日文。不是阿拉伯文。不是楔形文字。不是盲文。和任何一种他看到过的书写系统都不匹配。但它们在屏幕上排列的方式让他觉得眼熟。

不是"曾经在什么文档里见过"的那种眼熟。是身体上的眼熟——在他体认这些符号的时候，他的手指在键盘上自动调整了位置。他的左右手十指各就各位——像是他以前经常用这种姿势打字。但他的键盘是标准的QWERTY布局。这些符号需要的键位和所有语言都不一样——不是拼音、不是五笔、不是仓颉。

他把双手从键盘上抬起来。

符号还在屏幕上。他的控制台里多了三行他理解不了的输出。不是报错。Chrome控制台显示它们是普通的字符串输出——类型是String，长度是"23"。

二十三个看不懂的符号。

他把console.log那行注释掉，重新运行了一遍。控制台里干净了。数据正常显示。

他盯着屏幕想了一会儿，又在另一行代码后面添加了一行：

```javascript
console.log("测试");
```

控制台输出：

```
测试
```

正常。

那二十三个符号是怎么回事？他重新把那行注释取消掉——就是昨天添加的那行代码，放在排序逻辑的最后，打印排序后的数组长度。

控制台弹出了二十三个符号。

这一次他注意到了一些细节。

第一，这些符号不是随机的。它们有结构——有的笔画粗，有的笔画细。有两个符号在结构上是镜像对称的。第三个符号和第十九个符号只有一笔之差——一个顶端闭合，一个顶端开放。

第二，它们在控制台里不是"排列"在屏幕上，而是"构成"了什么东西。就像二十三个汉字可以构成一句话，二十三个这些符号也构成了一个单元——它有一种整体的形状，一种视觉上的完整性。不是从一到二十三的顺序读取，而是所有符号同时呈现出一种"含义"。

第三，也是最让他想不通的——他认得其中几个符号。

不是记得。是认得。

和昨晚的热流一样——他的意识不认识这些符号，但他的身体认识。当他的目光落在第三个符号上时，他的大脑没有给出任何解释，但他的手在键盘上做出了一个他根本没想过要做的动作：他的右手食指和中指依次在空气中画了一个形状。一个特定的笔画顺序。

他认识这个笔画。

它叫——什么来着？

答案就在嘴边的。堵在舌尖后面。像是考试时有道题你明明背过但就是想不起来。你想知道是哪一页的哪个位置，什么颜色的笔画的线，甚至连笔记本纸的质感都能回忆起来，唯独答案本身模糊了。

林牧把双手平放在桌上，从符号上移开视线。他看了一眼窗外。今天的天空没有昨晚那种异常的干蓝——是正常的、有薄云的、快要下雨的天空。

他重新看向屏幕。符号还在那里。

他做了一个决定：把窗口关掉。

不是象征意义上的"关掉"。是物理意义上的——右手移动鼠标到Chrome标签页的关闭按钮上，点击左键。页面消失。控制台随之清空。那些符号没有了。

他重新打开了一个新的窗口。重新跑了排序代码。没加console.log。结果正常显示。购物车页面的商品按照价格从低到高排列。排名第一的是九块九的记号笔，排名最末的是九千九百九十九的机械键盘。数据全部正确。

他站起来，去茶水间倒了一杯水。热水器上显示水温九十八度。他把杯沿递到嘴边，热水烫到了上嘴唇。他倒吸了一口气，疼了大概两秒。

正常的疼痛。真实的。物理世界没有崩坏。

回到工位。屏幕上的代码和他离开之前一模一样。没有任何符号自己跳出来。他打开Chrome控制台，里面干干净净。

正常。

他又盯着控制台看了一会儿，然后重新加了一行console.log。这次不是加在排序逻辑后面——加在另一个完全不相关的函数后面。一个处理用户头像加载的工具函数。他加的是：

```javascript
console.log("头像加载完成");
```

运行。控制台跳出四个汉字。没有符号。

他在排序逻辑后面重新加了一行console.log——打印的不是数组长度，而是数组的第一个元素。

控制台跳出了四个符号。

这一次不是二十三个。只有四个。四个符号排成一列。

他的目光一落到这四个符号上，手指又开始在空气中写字。一个小时后他在笔记本上会把手指写的东西用笔画下来：第一个符号像是一个人在陡峭的山路上低头前行。第二个符号的笔画是一个蹲姿的人，头部昂起。第三个符号是一个人在斜面的左边坠落。第四个符号是斜面的右边站着一个拉着坠者手臂的人。

这四个符号合起来是一个动作——"从高处坠落被抓住"。

但此刻他还没有把这些细节拼起来。此刻他只是看着那四个符号，意识到自己的手在空气中比划的正是写这些符号的正确笔画。

他写下第一个符号的时候——大概花了零点三秒，五笔完成。五笔之间没有任何停顿。手腕的翻转角度精确到不需要大脑在每次转折后重新定位。

他写下第二个符号。三笔。第三个符号：七笔。第四个：五笔。

二十笔写完。没有一个笔画犹豫过。没有一个笔顺需要思考。

他把手放下来。

窗外传来汽车喇叭声——短促的三下。不是堵车时的长按，是提醒行人的那种短鸣。楼下有个小孩在哭，哭得很大声，但隔着二十三楼的密封窗，传上来的只剩下极淡的一层。办公室的空调出风口在头顶嗡嗡地响。小赵的机械键盘劈里啪啦。

这些声音都是真实的。控制台里的四个符号也是真实的。

忽然想到了什么。他看了这些符号，又看了看自己放在键盘两侧的双手。有一个念头撞了进来——不，是闯了进来。他意识到了一个问题：他上午在写if判断的时候，那些判断条件，那些对价格边界值的处理——是从哪来的？

不是从需求文档里来的。需求文档只有一句话："请优化购物车排序逻辑"。边界判断——价格为空、为零、为负数、超过上限——这些是他自己加的。他以为这是一个程序员的基本素养。写代码要边界全面。

准确地说——他被公司要求写的是"优化排序逻辑"。排序逻辑，不是"防御性编程"。昨天下班前他的代码就已经跑通了排序功能。他今天加的那些判断，不是工作需求。他在无意识之中把代码当成了什么东西在维护——一种需要被结构严密地、边界完整地构建的体系。那不是编写业务代码的习惯。那是构建阵法的习惯。

他不知道自己为什么想到了"阵法"这个词。

这个词出现的时候，他愣了一下。阵法。他坐在电脑前，眼睛看着Chrome控制台里的四个符号。他忽然想起来了：他刚才写的那些判断条件——这些边界值的处理方式——那种不允许任何一个输入值导致整个体系崩溃的严谨——他以前做过。

在上辈子做的。

他站起身。动作有点快，椅子往后滑了半米，撞上了身后的白板。白板上有上周的会议记录，画着几个歪歪扭扭的用户流程图。他按住椅背，站了三秒钟，然后重新坐下了。

上午十一点整。

林牧把那个打印四个符号的console.log删掉。把代码从分支推送到远程仓库。把IDE关掉。

他用手机打开备忘录，在昨晚写的那句话后面补了一句：

"上午写代码时出现异常符号。我会写那些符号的笔画。另外忽然想到了——我写代码的方式是一套认知体系的底层结构。不是计算机的底层。是某种更复杂的东西。不是阵法的阵法。"

他按了锁屏键。站起来。走到茶水间。又倒了一杯水。

今天是周四。明天周五。后天周六——他可以去一趟旧书店。

他需要找一些东西来验证他的猜想。不是"我是不是疯了"——他已经放弃了那个问题。新的问题是：如果这不是疯，如果这些不是幻觉，那它们是什么？

他不信神。不信佛。不信道。不信任何形式的超自然。从小到大他接受的教育告诉他，所有现象都可以用科学解释。解释不了的只是科学暂时还没发展到那个程度。但今天上午发生的这些事——代码里弹出不属于任何字符集的符号、他的手能写出那些符号的笔画、他的编程习惯源自一套他不该掌握的知识体系——这些不是"暂时解释不了"的问题。这些是一个封闭逻辑系统的内部故障。系统自己发出了不属于系统的信号。

那信号从哪里来？

答案可能在书里。任何书。旧书、古籍、民间手抄本、被主流知识体系排除在外的那些文字记录。他需要找到哪怕一个——一个也够了——能和他屏幕上出现的符号产生对应关系的东西。

他喝了一口水。水已经不烫了。他把茶杯放在桌面上。马克杯的外壁是纯白的——入职那天发的公司纪念品，杯身上印着公司的Logo，一个蓝色的变体英文字母。Logo下面有一道很细很细的裂纹，从釉面深处透出来，不仔细看注意不到。

裂纹的一头指着他的左手。

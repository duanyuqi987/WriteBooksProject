# 第063章 李长生首次运用冥术，令人胆寒

第二天夜里，第七宗的人又来了。

这次是六个人。比昨晚多一个。而且领头的不再是灰袍执事，换了一个穿着深蓝色道袍的老者。老者须发皆白，脸上的皱纹像老树的年轮，但眼睛里精光四射，一点浑浊都没有。

四人在仓库里被堵了个正着。

小王的手在键盘上飞速跳了两下，低声报告："六个。领头的老头灵气浓度是灵者圆满。比他昨晚的执事高了两个小级别。"

周大壮的伤口才包扎了一天，纱布上还渗着血。但他已经站了起来，扎着马步堵在仓库门口。

老陈握紧赤霄剑。剑气在剑身上流转，把昏暗的仓库映成了暗红色。

只有李长生站在原地，一动不动。

不是不想动。是动不了。

他体内的两块冥王碎片正在剧烈震动。不是恐惧，是兴奋。像一个饿极了的猛兽闻到了猎物的味道。冥气在经脉里奔涌，几乎要冲破皮肤冲出来。

"忍着。"残魂的声音在他脑海里响起，语气很严肃，"你现在不能出手。冥术一旦在战斗中失控，你的队友也会受到波及。冥术不认敌我。"

"那我怎么打？"

"先用冥气护体。等他们出全力，逼到绝境的时候——再用冥术。记住：第一次用冥术，一定要在绝对必要的时候。否则你控制不了。"

李长生咬着牙，把冥气压了下去。

深蓝道袍的老者站在仓库门口，没有急着动手。他负手而立，像一个来看风景的老先生。但他说话的语气没有半分客气。

"李长生。贫道姓裴，第七宗传功堂长老。修行六十年，灵者圆满境界。你一个刚入灵者初期不到三个月的后辈，能逼退钟执事，确实有几分本事。"

他顿了顿，向前走了一步。

"但本事不够。冥王碎片不是你该拿的东西。交出碎片，拜入我七宗门下，可以保你平安。否则——"

"否则怎样？"李长生打断他。

裴长老的目光变得冷了下来。

"否则你和你这几个朋友，今晚都走不出这间仓库。"

周大壮呸了一口血唾沫。

"来啊！昨晚那五个也说这种话！"

裴长老笑了笑，像长者听小孩说大话一样。然后他轻轻挥了挥手。

"拿下。李先生留活的。其余三个——死活不论。"

他身后的五个修士一起出手。没有试探，没有循序渐进，一上来就是全力。剑气纵横，阵法的光芒编织成网，重力术、束缚术、镇魂术层层叠加。这五个人和昨晚那五个人完全不是一个层次——他们配合默契，出手干净利落，没有一丝多余的动作。

战斗在开局五秒内就倾斜了。

周大壮被一道重力术直接压弯了腰，双腿陷进水泥地面三寸深。两个持剑弟子交叉斩下，两道剑气轰在他背上，撕裂了纱布，溅起两蓬血。他怒吼一声，右拳轰碎了一道剑气，但左肩被另一道剑气刺穿，整个人倒飞出去撞在墙上。

老陈挥剑劈开了最前面的剑修弟子，但裴长老亲自出手了。一道凝实的灵气掌印从天而降，老陈横剑格挡，赤霄剑发出哀鸣般的颤音。他被震退七八步，虎口崩裂，赤霄剑差点脱手。

小王是最弱的。他的灵气修为连灵者初期都不稳定，战斗力基本为零。一个修士随手一道灵光打过来，他整个人被打翻在地，笔记本电脑摔出去撞碎了屏幕，嘴里全是血。

十秒钟。四个人三个挂了彩。

只剩下李长生还站在屋子中央。

裴长老负手而立，看他。

"现在交出碎片。还来得及。"

李长生没有回答。他闭上眼睛。

体内的冥气不再压制了。两片冥王碎片同时释放。经脉里奔涌的冥气像开了闸的洪水，瞬间从丹田涌遍全身。他的全身皮肤变成了暗沉的黑灰色，皮肤下面的血管里流淌的不是血液，是墨色的光。

他睁开眼。

眼睛变成了纯黑色。没有眼白，没有瞳孔。只有纯黑。

裴长老的笑容凝固了。

"冥气全开？你不要命了？以你现在的修为强行开冥气全身化——经脉会崩——"

话没说完。李长生动了。

他不是冲向裴长老。而是冲向了最靠近小王、正踩着小王手腕的那个修士。

那个修士是裴长老的徒弟，三十来岁，灵者中期修为。他的剑正指着小王的喉咙。他觉得自己稳操胜券。

然后他看到了李长生的眼睛。

纯黑的眼睛。看着他的时候，他觉得自己不是被一个人看着。是被某个深渊的底部凝视。

李长生的手掌按在了他的额头上。不是拍，不是击打。只是轻轻按住。

"你敢——"修士想挥剑。

但他的手没有动。因为他的身体不听使唤了。

一股极寒的气息从额头侵入，顺着经脉蔓延到全身。他的身体仿佛坠入了无底的冰窟，一种久违的、连他自己都忘了存在的恐惧感从内心深处被硬生生扯了出来。

他看到了自己这一生最害怕的东西。

不是鬼。不是死。

是他小时候被师父责罚关在后山小黑屋里的记忆。那年他才七岁，因为练功偷懒，被师父关在一个没有窗户的石室里，三天三夜。黑暗、饥饿、寒冷。他哭着求饶，没有人答应。

他以为他忘了。他以为四十年后，他已经是一个灵者中期的修士，不会再怕什么黑暗。

但他现在全身都在抖。剑掉了。眼泪和鼻涕一起流下来。

"不要——不要关我——师父——我错了——不要关我——"

他跪了下去。一个灵者中期的修士，跪在地上，哭得像个七岁的孩子。

所有人都愣住了。

连裴长老都愣住了。

周大壮靠在墙上，看着这诡异的一幕，后背发凉。老陈握着赤霄剑的手微微发抖——不是因为恐惧，而是因为他的剑身为古剑，对冥气有着最纯粹的感知。赤霄剑在鞘里剧烈震动，不是战意，是警觉。是剑身自带的灵性在警告他——离那种力量远一点。

小王艰难地撑起身体，擦掉嘴角的血。

"这——这是什么？"

没有人回答他。

李长生的手从那个修士额头上移开。他转身看向剩下的四个人。

那四个修士的脸色都变了。一个年龄最小的弟子——大概二十出头——直接后退了好几步，腿在抖。

"他——他用了什么妖术？"

裴长老的表情变了。他从袖中抽出一面铜镜——那是他修炼六十年来最珍贵的法宝，镇魂镜。专门用来对抗神识攻击和精神法术。

"镇静！他的冥气还不够精纯！只是残片的力量！"裴长老催动镇魂镜，一圈圈金色的光波从镜面上扩散出来，笼罩在剩下的四个修士身上，"有镇魂镜护身，他的冥术伤不了你们！"

他说得没错。镇魂镜的金光确实压制了李长生散发的冥气。那四个修士的颤抖停止了，脸色恢复了正常。

但李长生没有收手。

他一步一步走向裴长老。每一步落下，脚底的地面都会结出一层薄薄的黑冰。他的身后拖出了一条黑色的轨迹，像一只巨大的黑蛇在地面上游过的痕迹。

残魂的声音在他脑海里越来越清晰。

"你感觉到了吗？他在怕。那个老道士在怕。"

李长生感觉到了。裴长老的脸上虽然有镇魂镜的光芒笼罩，但他握镜的手在微微发抖。那双老眼里不是愤怒，不是杀气——是恐惧。

一个修炼了六十年的灵者圆满修士，怕一个刚入灵者三个月的农民。

为什么？

因为灵气的本质决定了力量的等级。普通灵气、五行灵气、雷灵气、剑灵气、冥灵气——这是修仙界的天然金字塔。冥灵气是塔顶。即使只有一点，也足以碾压下层的一切。

"冥术的本质。"残魂的声音像钟声一样在他脑子里回荡，"不是杀。是让他们自己面对自己。每个人心里都有最恐惧的东西。普通人可以用后天修炼压制恐惧。但冥术会把恐惧连根拔起——不是制造幻觉让你看到不存在的东西。而是让你看到你自己一直逃避的真相。"

李长生的手再次抬起来。

这次对准了裴长老。

镇魂镜的金光剧烈闪烁。裴长老全力催动法宝，全身灵气疯狂涌入镜面。但冥气面对金光时没有消失，而是像水一样渗透进去了。金光挡不住冥气。因为冥气要找的不是肉体的弱点，是神识的弱点。

李长生的手掌即将触碰到裴长老的额头。

就在这一瞬间，一道白影从黑暗中闪电般掠出。

一只手——修长、干净、指节分明的手——轻轻搭在了李长生的手腕上。

冥气瞬间被逼退了。

李长生猛地转头。他纯黑的眼睛看到的是一个约莫三十出头的男人。穿着一身洗得发白的旧西装，戴着一副银框眼镜。看起来很普通，像个中学老师。

但他身上的灵气——不是灵者级。不是灵者圆满。是玄师。

整整一个大境界的碾压。

"够了。"西装男人淡淡地说，"这些人是来抓你的，不是来杀你的。用冥术搞废一个，第七宗不好收场。给自己留条后路。"

他松开了李长生的手腕。

李长生退了一步。他眼中的黑色褪去，露出了正常的人类眼睛。皮肤上的暗灰色也慢慢消散。冥气收回体内，像潮水一样回落。

他大口喘气。汗水从额头上淌下来。刚才那短短的两分钟，他的体力被抽空了。

裴长老收回了镇魂镜。他的道袍被冷汗浸透了。他深深看了西装男人一眼。

"你是——"

"你不需要知道我是谁。"西装男人打断他，"回去告诉你们宗主。李长生的事，不止你们第七宗一家在盯。上面有人在看。动手要讲度。你要是再派人来——下次来的就不是我了。"

裴长老沉默了几秒钟。然后他转身对地上的那个弟子说："起来。走。"

"他——他走不动——"另一个弟子指着那个还在哭的修士说。

裴长老走过去，一掌砍在徒弟的后颈上，把人打晕，然后扛在肩上。

六个人离开了。来的时候气势汹汹，走的时候像落荒而逃。

仓库里安静下来。

周大壮从墙上滑下来，咳嗽着吐出了两口血唾沫。他看了一眼李长生，犹豫了一下，才开口。

"长生。你刚才——你知道你刚才变成什么样了吗？"

李长生摇了摇头。他看不见自己。

"像鬼。"周大壮说，然后想了想，"不对。像阎王。"

老陈走到他面前，盯着他的眼睛看了半天。确认他的眼睛里恢复正常的瞳色后才出了口气。

"你以后用那招——能不能提前说一声？我手里的赤霄剑差点拔出来砍你。"

李长生低下头。他不是愧疚。他是后怕。

刚才那一瞬间，他是真的有杀心。不是愤怒的杀心。是冷静的、像执行某种必然法则一样的杀心。就像阎王爷在生死簿上划掉一个名字。没有恨，没有怒，只是觉得——该死了。

"回去之后。"残魂的声音最后一次响起，"你跟我学真正的冥术。你现在的状态，随便一次情绪失控就会入魔。冥术可以救人，也可以毁人。不学会控制，你就是一个定时炸弹。"

李长生没有说话。

那个穿西装的男人还没有走。他靠在仓库的门口，点了根烟。烟头的火光在夜色里明灭。

他开口了。

"我叫冷锋。"

四个人同时看向他。

"下个月会来找你们。"冷锋吐出一口烟，"给你们一个月的时间。如果一个月之后你们还这么弱——我就必须带走碎片了。"

他把烟头掐灭，用鞋尖碾碎。

"不是威胁。是通知。"

然后他走了。像来的时候一样，无声无息地融进了夜色里。

周大壮愣了好几秒。

"他不是来帮我们的？"

"不是。"老陈说，"他是来评估的。"

"评估什么？"

"评估我们的价值。"老陈擦掉赤霄剑上的血，"如果值——留着。如果不值——清除。"

"那他为什么让裴老头滚蛋？"

"因为我们现在在评估期内。谁都不能动。"

四个人沉默了很久。

小王的笔记本电脑屏幕碎了，但硬盘还在。他把硬盘拆下来，小心收好。

"一个月。"他说，"我们只有一个月。"

李长生站起来。他走到那个被冥术击溃的修士刚才跪过的地方。地面上有一摊水渍——是那人的眼泪和鼻涕。他看了很久。

"走。"

"去哪？"

"回祖坟。"李长生说，"没路了。只能把能学的全学了。"

四个人走出了破碎的仓库。夜风吹过来，凉得刺骨。

（第063章完）

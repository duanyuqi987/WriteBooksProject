# 第七百九十七章 第八卷终：所有的路汇成一条

联合共治会三十二年除夕——这一年的灯火塔集会在暮色中开始。不是跨年，是"送第八卷"。太湖灯火塔广场上所有的人没有手持鲜花——手持便签。便签上画的不是吉祥话——是各自最想留给下卷人的两个字。石头的便签写"继续"，小火的便签写"勿冷"，秦无夜的写"敢看"，杜小月的写"计数"，老周的写"看天"。

林牧和苏晚并肩站在灯火塔下。他们的第一张便签——他写"修一下就好"，她回"不用谢"——已经被永久收藏了。今天他们手里是两张空白便签——给第九卷留着。

苏晚对着所有人说——"第八卷——相互支持——我们学会了在对方的梦里扮演对方的支撑之手。我们的路不同——但我们用的是同一种地基——包容。我们看到了由无数便签，无数灶火，砌成了一条直通上界、横连下界的长直线。这条路不是我们造出来的——是在座每个人的推力。"

林牧第二次在公开场合作了总结发言——比第一次在飞升之门启动时的"飞升之门不属于我"更短——"我这一辈子（多辈子）做过最正确的事——不是画了哪张图——造了哪扇门——而是学会了相信她。以及相信你们。谢谢所有煮粥的人。——林牧。"他把空白便签撕成两半——一半贴在自己胸口，另一半递向苏晚。苏晚接过去，也贴在自己胸口。两张白纸，同一个人给的。

石头在日记中写道——"林叔把一张便签撕成两半。不是告别，是开始。——石头。第八卷终——全书待续。"

（第七百九十七章 完）

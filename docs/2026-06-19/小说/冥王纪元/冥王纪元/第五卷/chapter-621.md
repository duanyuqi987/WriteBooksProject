# 第621章 奇异的黑洞

离开第一个混沌碎片所在的遗迹已经是第三天。

李长生站在冥王号的舰桥上，前方是舷窗，舷窗外什么都没有。不是星空——是真正的"没有"。连暗物质辐射的微弱背景光都在这个区域消失了。导航图上标注的名字是"寂静海"，一片直径约七千光年的绝对真空区。没有恒星，没有行星，没有任何已知天体。

除了一个黑洞。

这个黑洞不在任何星图上。龟相花了整整六个时辰，用冥王号上搭载的第三代引力波探测器配合冥力感知阵列进行交叉定位，才在一片引力异常数据里找到了它。它不是通过吸收周围物质暴露自己的——寂静海里没有物质可供它吸收。它是通过引力透镜效应的一个极其微弱的偏移痕迹被发现的。

"它不是自然形成的。"龟相的声音从舰桥后方传来。老龟的四肢缩在壳里，只留一个脑袋伸在外面，两侧的眼珠子各自对准不同的全息屏幕，"自然黑洞不可能出现在绝对真空区。它周围没有任何吸积盘，没有物质喷流，没有任何一个正常黑洞该有的特征——除了引力本身。"

李长生盯着前面那片虚空。他有冥王级感知，比任何仪器都灵敏，但此刻他的感知往那个黑洞的方向延伸过去时，遇到了一种奇怪的阻力。不是被弹开——是被吸入。他的感知像一小把细沙被扬进了漩涡，顺着某个方向急剧弯曲、旋转，最后消失在某个不可触及的深度里。

"它在主动吸收感知。"李长生说。

"黑洞吸收一切——包括感知。"陈霜的声音在旁边响起。她也在看舷窗外的虚空，"但你说的是'主动'。"

"对。不是被动的。它在挑选。它在感知我的感知——然后决定吞掉。我往它那边释放了三种不同频率的冥力感知：高频感知被弹回来了，中频感知被偏转到一个不可探测的角度，低频感知——被它吃了。"

舰桥上安静了三个呼吸。

黑洞会吃饭——这本身不是问题。问题在于它挑食。

"它在筛选能量类型？"程序员小王的声音从通讯频道里传来。他在冥王号的后舱，正在分析龟相传输过来的原始数据，"我这边看到的数据更奇怪。这个黑洞的质量波动——"

"什么？"李长生转过头。

"它的质量不是恒定的。在过去的六个小时里，它的质量数值在1.7倍太阳质量和47倍太阳质量之间波动。黑洞的质量波动是不正常的——但更不正常的是波动模式。"小王把他分析出来的曲线图投射到了舰桥的全息屏上。那是一条诡异的锯齿状曲线，上上下下，但在每次上升前的谷底位置，都有一个极短、极浅的平坦段。

"它在'呼吸'。"龟相说。不是比喻——他的声音非常认真，"它在稳定地做质量涨缩。吸气时质量上升，呼气时质量下降。从时间间隔看——"

全息屏上弹出了一组数据：涨缩周期41.7分钟。

"它不是黑洞。"李长生说。

他盯着那片虚空。冥王号现在距离它还有零点三光年——对一艘配备空间折迭引擎的舰船来说这是一个短得可笑的航程。但他没有下令靠近。因为他刚才那句话不是猜测——是结论。

他在获得第一块混沌碎片后，体内生出了一个全新的感知维度。那个维度不是视觉、不是触觉、不是感知——是一种被他暂时命名为"存在辨识"的能力。它能让他看到事物的"真实面目"。刚才他启动这个能力朝那片空间的深处看了一眼——他在那团引力中心里看到的东西不是一个奇点。

是一个结构。

一个极其精密、层次丰富、带着明确构造意图的结构。用人类语言没法描述它，但用冥王级别的感知来看，那个结构的形态和他在第一块混沌碎片内部看到的纹路排列方式——高度相似。

"那是混沌时代的造物。"李长生说，"不是自然黑洞——是一个被混沌之力改造成门的东西。它外面看起来像黑洞，为了防止不该进去的人进去。"

"那里面呢？"陈霜问。

李长生把第二块混沌碎片的定位数据——来自第一块碎片的内部共振——和前方那个黑洞的位置叠到了同一张图上。两个坐标重合了。精确到小数点后第九位。

"第二块碎片就在它里面。"他说。

陈霜没有说话。她只是把剑从鞘里抽出来，横在膝盖上，开始做一件她每次在面临极度危险之前都会做的事情：用一块细棉布擦拭剑身。这块棉布已经洗得发白了，边缘有磨损的毛边——是她跟李长生这么久以来一直随身带着的那块布。她没有说话，但动作说明了一切：她准备陪他进去。

"这个黑洞如果真是混沌造物，"程序员小王的声音变得非常正经，"那它的内部环境能量密度会超过任何已知物理框架下的安全标准。船长——"

"说结论。"

"我刚才让AI做了个模拟。如果你执意要进去——"

"结论。"

小王顿了一秒。非常罕见。这个IT天才能在十亿次计算中发现任何异常——他从来不需要顿这一秒。但这一次他顿了。

"仙王进去也会死。"他说，"不是可能——是必然。我模拟了七种进入方案，每一种方案都指向同一个结果：仙王级的防御在黑洞内核辐射面前撑不过零点零四三秒。而你现在的修为——"

"我知道。"李长生说。

他现在是冥王级别，比仙王高了整整一个大台阶。但即使如此——他的存在辨识能力已经告诉他了：黑洞核心的那团能量，它的级别是混沌级的。混沌是冥王之上的层级。他现在的修为还够不着那个级别。

"但我还是得进去。"他说。

舰桥上所有人都没有说话。

李长生转过身，看着他的团队。他从来没有对他们说过一句"危险你们别跟着我"的话——因为他们从来不需要这句话。他们每次都跟着。但这一次不一样。这一次的对手不是任何人——既不是仙王，也不是神级修士，甚至不是冥王残魂。这一次的对手是一个存在了不知多少亿年的、由超越冥王的混沌之力制造出来的结构。这个结构在打碎冥王令的那场战争发生之前就已经存在了。它的年龄可能比地球上的第一个单细胞生物还要古老。

"你们留在外面。"李长生说，"我一个人的防御——我还能撑住。但如果我带任何一个人进去，我必须同时用我的防御罩保护他。那种负荷——"

"明白。"陈霜打断了他。她把剑插回鞘里，站起来。没有争辩，没有反驳。她只是走到他面前，把右手的手掌贴在他左胸的心脏位置上。没有说"小心"。没有说"回来"。她的手在他心口上停了三个呼吸，然后放下来。

"里面没有信号。"龟相说，"黑洞内部和外部之间没有任何已知的通讯手段可以连通。您进去以后——"

"就全靠我自己了。"李长生说。

他走到舰桥的边缘，打开了那扇通往转移舱的舱门。在跨进去之前，他停下来，回头看了一眼。

陈霜站在舷窗前面，光线从舷窗外面射进来——不是星光，是冥王号自身的航行灯照在虚空中的微弱反射。她在逆光里站得笔直。剑在她手边。手很稳。

李长生没有说什么。他把舱门关上了。

转移舱很小，不到五平方米。李长生站在舱室正中央，深呼吸三次，将体内所有冥力通道全部打开。右手掌心那枚冥王令的纹路在黑暗中亮了起来。它不是只亮一层——是层层叠叠地亮。每一层纹路都独立发光，像一块千层玻璃里嵌了一万根发丝。

他跨出一步。转移舱启动。

下一瞬间他不在冥王号里面了。他悬浮在虚空中。那个"黑洞"就在他脚下——或者说，在他坠落的方向上。他的感知已经彻底被扭曲了。上下左右前后全部失效。四面八方同时被同一个方向的引力拉扯。不是拉扯他的身体——他的冥王之躯已经能抵抗这种层级的物理引力。拉扯的是他的感知、他的意识、他的自我认知。

他感觉自己正在被拆解。

不是身体被拆解——是"存在"本身正在被一层一层剥开。最外层是他的冥力修为——那一层被剥掉的时候他感觉不到疼痛，只是突然对自己的身体失去了精确的控制。第二层是他的感知——被剥掉的时候周围的世界从彩色变成了黑白，再从黑白变成了无法辨认的杂乱纹路。第三层是他的记忆——他开始看到自己过去的一切以不可控制的顺序在眼前闪现。不是按时间顺序来的：001章的李长生、在古墓中得到龟相的李长生、在金字塔里参悟冥王意志的李长生、在月球上与敌人死战的李长生——全部打乱，混在了一起。

他在纷乱的记忆碎片中咬住了一件事：他还没有看到第二块碎片。

只要还没有看到——他就不能倒。

他强行收拢意识。在感知和记忆被黑洞完全打乱的极限状态下，他把所有的意识力量压缩成了一个点——就像一万两千年前冥王在十二神级围攻下把所有意志压缩进冥王令一样。那个点不是很大。不是光芒万丈。但它非常稳固。

他落进了黑洞核心。

周围的时空变成了一个无法描述的东西。不是黑暗——黑暗至少还是"没有光"。这里的"颜色"超越了视觉范畴。它是混沌的颜色——如果混沌有颜色的话。硬要说的话，是一种极其古老的白。不是新雪的白，不是牛奶的白——是亿万年前宇宙诞生第一秒的极热冷却后，残留的那一种白。

在这片白的最中心——他看到了第二块碎片。

它悬浮在那里。形状不规则，边缘有破裂痕，外表看上去只是一块普通的、灰黑色的石头碎片。但李长生的"存在辨识"感知在告诉他：这不是一块石头。这是一个被压缩的宇宙残片。它是一个在混沌时代被摧毁的、完全成熟的宇宙——它的全部质量、全部时间线、全部可能性——被压缩成了拳头大小的一块碎片。

它里面封着的不是"一个"宇宙。

它里面封着的是混沌之主力量的第二部分。

李长生伸出手。

他的指尖触碰到碎片表面的那一瞬间——整个黑洞核心里那团足以杀死仙王的混沌能量，突然全部安静了。不是消失了——是安静了。像一个脾气暴烈的巨兽见到了真正的主人。

碎片没入了他的掌心。

（第621章完）

# 第701章 陈校长的使命

陈霜在帝都待的时间比以往多了很多。

旧纪元时期她常年和李长生一起出征，不是在打仗就是在准备打仗的路上。和平之后她一度不知道自己该做什么。帝国皇后是一个非常空洞的头衔——旧纪元的皇后大多数时候只是皇帝的装饰品，负责出席仪式、主持慈善、保持端庄。陈霜不适合这些。

当上永恒学府的校长之后，她终于找回了一种久违的感觉——被切实需要的感觉。

大学跟战场不一样。战场上要的是快速决断和精准杀戮。大学里要的是耐心，是倾听，是在两种完全相反的观点之间保持中立和开放，是允许学生犯错然后再引导他们自己发现错误。

陈霜发现自己居然很擅长这些。

她把每天的时间分成三段：上午处理大学行政事务和教学管理，中午跟学生一起在食堂吃饭（永久取消"教工专区"，所有人在食堂一律平等），下午听课——她以"旁听生"的身份挨个进教室听课，有时候连续听五个小时不间断。

她听课不是为了监督教师，而是为了理解学生。通过亲自坐在教室后排，她能最直接地感受到——哪门课讲得太深了，学生满脸茫然；哪门课太浅了，学生玩手机偷懒（手机在冥都当然存在——跨文明科技已经足够发达）；哪门课的内容跟法典精神有冲突，教师需要被提醒。

第一个学年结束时，陈霜做出了一系列调整：修仙系增加"修炼风险认知"课程——不是教怎么修炼，而是教修炼各阶段可能出现的风险和如何处理修炼伤害（这是林晓的灵医体系遗产）；科技系增设"技术后果评价学"——任何新技术在开发前必须先评估该技术可能被滥用的方式；艺术系更大刀阔斧地改革——把旧纪元已灭绝文明的全部音乐、美术、戏剧、建筑原稿公开为公共数字馆藏，任何学生都可以自由查阅和使用。

这些调整引发了部分师生的抵触情绪。但陈霜不解释——她用行动说明。她在第二次学年开学典礼上说："大学不是为你们提供舒服知识的地方。大学是为你们提供能使你们变得不那么狭隘的知识的地方。舒服不是大学的义务，真实是。"

这句话后来被刻在永恒学府正门石碑的背面，与正面李长生所题"以民为本"遥相呼应。

第二学年，报考永恒学府的考生比第一年翻了四倍。不是因为大学的名声好听，而是因为第一届学生中已经有人做出了真正的成绩：一个修仙系和科技系双修的学生，发明了"灵力量子编码"——一种用灵气脉冲模拟二进制计算的处理器基础技术。这项技术后来被帝国科学院采纳为标准，带动了全帝国算力的大飞跃。

陈霜对这些成绩绝口不提。她只是在第二学年开学那天，把一枚——她自己当年从西北大漠带来的——古剑穗挂在了自己的校长办公室里。

那是她祖父留给她的唯一遗物。剑穗已经泛黄，但没断。

（第701章完）

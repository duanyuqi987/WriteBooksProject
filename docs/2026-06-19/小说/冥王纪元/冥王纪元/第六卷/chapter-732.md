# 第732章 修仙文明的发展，已经超越想象

三百年时间对于一个成熟的修仙文明而言不算漫长，但对于一个处在加速上升期的新文明来说，足够发生质变。

冥王帝国的修仙文明已经发展到了连李长生都感到陌生的程度。

帝国科技与灵能研究院设在一颗独立的科研星球上。这颗星球没有普通居民，全部人口都是研究人员。星球的核心是一台由灵符引擎驱动的量子灵能计算机——程序员小王花了一百年研发的"太初系统"。

此刻，小王正在为李长生做一场汇报。

"三百年前，"小王站在全息投影前，手一挥，调出了一张对比图，"帝国最先进的灵能引擎的输出功率是每秒三千万灵子单位。现在是——"

他点了下一张图。

"每秒四十八万亿灵子单位。提升了一万六千倍。"

李长生看着图表上那条近乎垂直的上升曲线。"具体应用呢？"

"先说交通。"小王调出了帝国交通网络的实时数据，"三百年前穿梭一个星域需要三天。现在是三分钟。量子灵能通道已经覆盖了帝国所有主星域。你在中央星上喝一杯茶的时间，边境的巡逻舰队就能收到你的指令。"

"再说修炼。"小王切换画面，"三百年前帝级修士一年能吸收的灵气量大约相当于一颗标准灵脉的千分之一。现在——帝级修士一年吸收的灵气量相当于三颗标准灵脉的全部产出。"

"怎么做到的？"

"灵根进化。"小王调出了一组基因图谱，"三百年来，我们通过灵医学的发展，在不改变修士本体的前提下优化了灵根的能量转化效率。尤其是林晓院士——她在七十年前发现了灵根的'暗通道效应'。简单说，每一个灵根都有大量未开发的暗通道，激活后灵气吸收效率可以提升三十到一百倍。"

李长生沉默地盯着那些数据。他记得三百年前，自己刚踏入修行时，吸收一缕灵气就像往骨头缝里灌铁水。而现在，新一代修士修炼的速度比他当年快了一百倍。

"还有战争方面。"小王调出了帝国舰队的配置数据，"诸天号已于两百年前退役，现在是帝国纪念馆的镇馆之宝。目前的旗舰叫'永恒号'——长度四十公里，搭载了最新型的灵能主炮，一炮的能量输出相当于三百年前冥王帝国全部舰队的总和。"

李长生看着全息投影中那艘巨大得不像话的星舰，不自觉地摇了摇头。他记得诸天号当年出厂时，他站在舰桥上觉得这就是宇宙间最强大的战舰了。如今，诸天号在老陈曾孙的眼里大概就像老古董。

"老陈曾孙在哪个舰队？"

"陈远志？"小王笑了一下，"他不肯上永恒号。他说那是'坐在豪华办公室里打仗'。他自己选了一艘边境巡逻舰——就是那种最小的、只能坐两个人的灵能快艇。这才符合他们老陈家的作风。"

李长生也笑了。老陈家的人，不管到了第几代，骨子里的那股"草根自觉"就是改不掉。

"继续。"他说。

"然后是民用领域。"小王挥了一下手，全息投影转为一座巨大的城市模型，"这是帝国最新建成的生态城。整座城市是活的。"

"活的？"

"它的建筑骨架由灵能驱动的生态碳纤维构成，可以像植物一样自我修复。街道下方铺设了灵脉网络，将地心灵气直接输送到每一户人家的修炼室。城市中央有一座'灵能大脑'——不是AI，是真正的灵能意识体，由十万名修士的集体意识凝聚而成，负责调配城市的所有资源。"

李长生看着那座城市模型，感觉到了一种陌生的宏大。

三百年。

三百年前，他带着几个兄弟在城中村的小房间里修炼。那时候最大的愿望是凑够第二块碎片，混个自保。他从没想过，有一天修仙文明会发展到这个地步——城市是活的，星舰能一炮毁灭恒星，普通人家的孩子生下来就能修炼。

"最后，"小王的声音变得郑重起来，"是关于您要的东西。"

他调出了最后一份报告。

"过去五十年间，帝国科学院的三百个观测站同时在监控宇宙的深层结构。我们用了最新的'灵能量子望远镜'——能穿透维度膜，看到平行宇宙之间的夹层空间。"

李长生精神一振。"发现了什么？"

"发现了很多。"小王一字一顿地说，"但最引人注意的是一个——"

他调出了一张星图。在星图的遥远角落，一个标注为红色的区域正在缓慢地变化着。

"这是帝国边界外三万光年的一处区域。那里有一颗黑洞。古老的黑洞。三百年来的数据表明它的引力场曾经是完全稳定的，但——"

小王放大了那个区域。

"最近五十年的数据显示，这个黑洞的引力场在缓慢增强。不是被物质注入导致的增强——而是某种内部的能量输出在增加。就像——"

"就像里面有什么东西在苏醒。"李长生接过了话。

小王点了点头。

观星台中一片寂静。只有全息投影的光在两人脸上轻轻地闪烁。

黑洞。古老的、正在苏醒的黑洞。

冥王令的纹路在李长生的掌心再一次轻轻地跳动了一下。这一次，他清楚地感觉到了它的信号。

不是警告。

是召唤。

（第732章完）

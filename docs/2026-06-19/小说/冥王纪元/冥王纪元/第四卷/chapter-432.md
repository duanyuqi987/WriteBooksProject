# 第432章 决议：集合所有帝者，消灭冥王——联盟成立

太初会议的第二阶段是正式表决。表决在原初星的简会议室里进行了大约两个时辰——对外界宇宙而言相当于六个小时。表决的事项有三件:是否正式成立反冥王帝者联盟，联盟的主要战争目标是什么，联盟的总指挥权归谁。

表决方式不是举手——帝者们不需要举手这种容易被能量干扰的肉体动作。每人在自己的能量座位上释放一道带有身份标记的灵力印签——签名印直接刻入太初帝者面前那颗微型宇宙球中。带有姓名信息的灵力印触碰球面会留下一道短暂的光点，然后在球体内以细微光点的形态永远存留。微型宇宙球中从此多出十二颗帝者印记——它们在数年数百年后即便帝者本人已经作古，其签名仍会留在宇宙球的深层记录之中。

投票结果:全票通过成立联盟。全票通过联盟战争目标为"击杀或永禁冥王李长生及瓦解冥王帝国归于解体"。总指挥权设置复杂一些——三位帝者——苍明、太初、天枢——分别获得不同的指挥领域。苍明为联盟军政总指挥——掌管一切军队调度、后勤保障、空间输送通道。天枢为阵法总指挥——掌管帝阵的战术调度、阵盘布置、阵旗序列和与之配合的阵法部队。太初为战争最高仲裁者——掌管核心决策，包括最终决定是否启动帝阵终极锁禁——这在本次联盟决议中的核心地位相当于核武库的发射键。

联盟对外宣布取名"诸天联盟"——这个名字最早是天枢提出来的。她的理由是:既然敌人叫冥王帝国，那么联盟叫"诸天"——以天克冥——直接将从名号角度就压制对手。苍明起初认为这种取名方式太不正式——但后来包括雷泽帝者和天火帝者在内的几位帝者都觉得这个名字还不错——霸气、好记、有对抗性。于是"诸天联盟"这个名字在表决中通过——十二个帝者的灵印一盖章，这个名字就印入了宇宙史。

联盟的主要军事行动计划也在此后形成。总计划被称为"黎明计划"——分为三个阶段。

第一阶段——"前出"。以苍明帝国现存主力舰队为前锋，加上天枢帝国的重型阵术母舰和九幽帝国亡灵先锋军，在接下来的三十个宇宙日内向西部星域方向推进舰队至边荒星域对面的中立缓冲带——距离西部边荒防御线大约两万光年的位置。同时将联盟十六张帝阵预装阵盘中的九张先期部署在推进舰队的核心母舰上——随时准备在接触战阶段激活。

第二阶段——"破盾"。利用空间系、雷系和水系的破坏力最优组合主动打击边荒的混合防御层。由苍明舰队、雷泽舰队和玄冥舰队共同负责撕裂外层防护——将冰、风、金石混合盾的防御强度从峰值削减到允许帝阵通过的程度。这个阶段预估会是最惨烈的拉锯战——因为边荒防线有四位帝者防守——守势帝者在防御战时面对攻势帝者往往具有一定的地力优势。

第三阶段——"斩首"。这是整个黎明计划核心所在。在"破盾"阶段破坏了外层防御之后，太初帝者将带领至少十六张帝阵预装盘组成的完整帝阵，从边荒裂口切入冥王帝国西区——将李长生从他的任何当前坐标上精确捕获并以帝阵锁禁在单独微型维度中。完成锁禁后联盟等于打赢了一半——剩下的工作是维持锁禁运转并逐步迫使冥王帝国解体。

苍明在讲述第三阶段结束后，停顿了很长一段时间。然后说:"但有一个细节——如果锁禁失败——如果李长生在帝阵锁禁他的同时做出足够强大的反制动作，存在一种可能性：他本人不会被困住，但帝阵内部的能量反冲反过来吞噬所有参与锁禁的帝者————这属于不可控结果的范畴。"

青木帝者是唯一对这一风险公开发表意见的帝者。他说:"太初之力维持微型维度的能量底线大约是八千年。如果锁禁失败，太初帝者会失去多少修为？"

"如果单独用太初之力硬抗李长生冥王令的破封——也许会损失超过六成本源能量。但如果十六位帝者的能量同时在帝阵中分担反噬——每位帝者损失的修为在可控范围之内。"

"风险可不可接受由我们每个人自己判断。"苍明总结道。没有人当面提出退出——在目标已经锁定、表决已完成、帝阵预装盘已制造的阶段——退出在政治上等于向宇宙宣布自己害怕冥王。帝者是不能表现出害怕的——至少在敌人面前不能。

联盟正式成立的同时，天枢帝者启动了情报屏蔽系统。这一系统被命名为"天璇遮"。这是一套将天枢星域自身的阵法工业技术应用到全联盟范围的超大规模阵术防谍系统。一旦激活，联盟内部所有的军事通讯、舰队坐标、帝阵的部署坐标和来往信使的数据都被一层基于六十四卦动态更换的阵术护罩加密。加密不是一重——是六重。外部势力即使捕捉到信号流，看到的也只是一堆无意义的动态代码。

换句话说，从现在起——冥王帝国对联盟内部军事部署的情报能力将大幅降低。小王的河图系统仍然能通过远程信号的宏观密度追踪判断联盟在准备大规模行动，但精确坐标、实时部署和战术细节——基本被天璇遮屏蔽了。

与此同时，联盟的集结令同时发送给了那些尚未明确加入的中立帝者。集结令中包含了一封措辞极有分量的动员函:以宇宙各种族文明整体安全的名义要求所有已拥有帝者修为的强者加入联盟抗击冥王扩张。拒绝加入的帝者将不被视为敌人——但战后将丧失参与宇宙战后秩序重构的权利。

这封动员函的效力比宣战更可怕。它等于对全宇宙所有还在观望的帝者发出了一张生死入场券:要么现在加入打赢的联盟，要么就靠边。战后靠边者不再有发言权——而如果联盟打赢冥王帝国，战后掌握宇宙瓜分权的十二位创始帝者完全可以决定将不参与者边缘化。

这道集结令发出后仅一个宇宙日，就有回应。两个先前没有明确加入联盟的中型帝国帝者通过远程传讯表示加入。一个是来自北部边缘的霜风帝者。另一个是来自南部深渊星区的深空帝者。至此联盟的总帝者人数从十二人升为十四人。

十四位帝者。加上仍在继续联系中的一到两位可能帝者——十六帝的阵容基本确定。

苍明本人亲自用空间系灵力在联盟舰队集结地——原初星外空——对着全宇宙的范围释放了一道帝者级空间广播。广播内容是宇宙历史上最短的动员宣言——只有三句话:

"诸天联盟已成立。十四位帝者已集结。冥王帝国有十九位帝者——我们比他们少五人。但我们有一个他们永远不会有的东西——帝阵——以及，一万年前我们的前辈们曾经杀死冥王一次。这一次，我们要确保他永远活不过来。"

宇宙中央诸帝集结的消息在之后不久传到了西部边荒。不是通过灵符情报——而是被一位已经归附冥王帝国但原籍是东部星域的星际商人带回来的。这个商人利用非军用的商船穿梭在中立星域，在联盟集结地附近亲眼看到了大量舰队正在集结——规模之大远远超出了任何之前的局部战争动员声势。他用商船上最老旧的一套民用灵符传讯装置强行在联盟天璇遮系统中找到了一条极小的缝隙——发回了一条极为短暂的加密信息。

信息在西部边界被冥纹感应阵列捕捉到。小王花了一整夜解密——解密结果确认了情报的完整性。联盟已经有至少十四位帝者——可能有更多——正在集结。他们的舰队规模初步估计在五万艘以上。他们的帝阵已经造好了至少九张预装盘。他们的方向——直指边荒。

李长生在接到情报的清晨站在了边荒防御线的司令部平台上——原岩七基地遗址改造后的调度中心。平台上很冷——边荒的太阳还没升到视察高度。四位驻防帝者——冰帝、风帝、金石、炎烈——站在他身旁。五个人面前是边荒防御线全息投影。那条漫长的黑线从左边拉不到头看不到尾——在黑暗星域中显示为一条孤立的存在。而越过这条线的前方——在未知虚空以外——十四位帝者正在步步逼近。

"以前我对面站过的最多也就三个帝者。"风帝说。他的语气不急，像在说一件无关紧要的事——但风核在眉心处转得比平时快了半圈。

"这次翻了将近五倍。"金石帝者补了一句。

"不是五倍。"李长生说，"这次对面有帝阵。帝阵的能量放大系数——按龟相数据库里的古老记载——每增加一位帝者，阵法总输出大约增加这位帝者本身输出的两倍——因为阵法的共振传输。十四个帝者通过帝阵放大的能量——大约是单个帝者的百倍以上。"

晨风在废墟上吹过。平台上的铁皮板吹得哗啦响。远处舰队工程塔吊的探照灯正一圈一圈转过去，光打在刚焊好才一天的新防板上。

"你打得过吗？"冰帝冷冽的声音忽然发问。

"不知道。"李长生如实回答。"没打过十几个帝者骑脸。但有一件事很清楚:如果我们现在开始怕了——这场战争就已经输了。"

金石帝者拍了拍自己的围裙——仍然是工作服。"打铁有一个道理:冷铁打不成型。但烧得过红——碎。温度要刚好——该顶着火焰上就上，该退火成型也不丢人。现在你告诉我——我们的温度，是刚好吗？"

李长生想了一下。然后说:"我们有四道防线——冰、风、金、火。有一个全宇宙最强的战术系统和最聪明的程序员。有一群不肯跪的盟友。还有一枚等了一万两千多年才合一的冥王令。"

"温度确实刚好。"老马不知道什么时候从后方溜达到了指挥部边缘，嘴里叼着一支火星基地新产的灵烟。老马一直负责工程——但他今天却来了作战前线，把新完工的第六层防御支柱的工程报告直接递给了李长生。报告末尾空了两行，写了两句话:"防御体系验收合格。该打的时候打——这个墙在这。"

李长生接过报告看了最后两行字。

然后他传令了。一句话——不是长篇动员，就是干巴巴的一句:"全防线进入最高战备。从今天起——不分帝国不分灵根。对面十四位帝者——我们十九位。但这不是数字大小的事——是看谁先穿过这堵墙。"

四位驻防帝者的能量同时升了一下。冰壳外围的白光在一瞬间微不可察地凝实了几毫。风帝的风核全部吸入眉心准备随时释放风暴。金石的引力场将周围碎石全部向外推开并形成一个精确排列的引力盾层——老马昨晚连夜调好的土系灵石轨道矩阵同步对接在了引力层外围。炎烈的火光从体内往外交替燃烧了一轮并在熄灭后保留了最高蓄能态。

诸天号也在当天升空至边荒后方高轨。一万两千道冥纹推至战时额定全功率——在黑暗中释放出有史以来功率最高的暗金色持久光带。光带在三维空间中写成一个又一个古老的冥系符文——符文连成一圈又一圈——在防御线后方形成了一个向内拱守的冥纹闭环罩。数以万计的舰队也同时点燃灵能发动机——工程舰、巡逻舰、主战舰汇聚出的尾焰让后方星区变得亮如白昼。

诸天联盟的舰队还在几万光年之外。但边荒防御线已经活了过来——从一条由废墟工业中重塑的被动防御墙变为一条沿着东面方向咆哮的光墙，等待着接下来要撞上自己的那片海洋。

（第432章完）

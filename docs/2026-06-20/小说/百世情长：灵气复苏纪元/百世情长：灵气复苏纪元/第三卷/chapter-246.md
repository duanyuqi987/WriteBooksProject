# 第246章 第九世：过渡区天门

鸾凤离火固化之后，苏晚的丹田进入了一种前所未有的状态——不是空的，不是满的——是在燃烧和休止之间找到了一个之前从未存在的平衡点。金火和银火不再是两种交替的颜色——而是一种稳定存在的鸾黄色恒焰——像一簇永远不灭的灯芯。

白谪在昆仑瑶台上召开了一场只有三个人的会议。林牧和苏晚坐在剑台边，白谪浮在对面的半空中，灵鉴屏上投出了一幅动态的天界通道图示——从凡间到仙界之间的过渡区结构图。图上有三道门：第一道"天门初阶"——就是过渡区入口；第二道"真仙试炼门"——要通过真仙试炼才能进入；第三道"正仙天门"——这是真正进入仙界序列的最终门户。

白谪用仙尺指着第一道门说:"理论上，鸾凤离火固化后你们已经具备了开启'天门初阶'的基本条件——但这只是过渡区的入口，不是飞升本身。过渡区是凡间与仙界之间的缓冲区——里面没有完整的仙灵环境，只有最基础的迎仙台支撑——你们进去之后不能长期停留——最多五日。五日内如果你们能同时通过'真仙试炼门'——就能正式获得真仙资格。如果不能——天门会在第五日关闭——你们被迫退回凡间——而退回之后鸾凤离火将因过度消耗而休眠——下一次复燃至少需要——一个完整的新轮回。"

苏晚把这段话在脑子里过了三遍然后问:"所以我的选择是——要么在九世直接飞升——成功就是真仙——不成功就是退回来——但是退回来需要等一个完整的新轮回——就是第十世——第十世之后我还能再试——对吗？"

"对。而且第十世你从婴儿开始重新修炼——就算以最快的速度恢复记忆——从小修到合道——最少也要三十年。他——"白谪看着林牧——"要再等你三十年。"

苏晚站起来走到瑶台边——看着云海。云海的翻涌速度很慢——慢到眼睛可以追着每一朵云的边缘走。她以前从来不需要在"这一世飞升"和"再等一世"之间做选择——因为在前几世她根本没得选——她的修为不够，她的轮回锁没松，她的金火还没进化。但现在她站在一个分叉口上——左边是"今天试——可能成功也可能失败"，右边是"再等一世——稳成——但要他再等三十年"。

林牧从她身后走过来说了一句他很少说的话——少到她记忆中只有几个瞬间他说过:"不要为我选时间。选你自己觉得对的时机。"

"但你不是时间——你是人。"她转过头看着他——"你还有白头发了——你不能再等了——而且你刚才在共振里把仙元注入我身体的时候——你的仙元消耗了多少？一成？两成？每次注入你消耗的仙元是不可逆的——你不是修士——你是真仙——你在凡间补不回仙元的损耗——你在用自己的命往我的瓶颈里填——对吧？"

林牧没有回答。他确实在每次共振中将自己的仙元注入她体内——而凡间环境是补不回仙元的——他的仙元在凡间每消耗一份就永久消失一份——就像一缸在沙漠里用一勺一勺漏下去的水。注入的量不大——每次共振只消耗一丝——但九世以来累积的消耗已经让他的仙元存量是当初下凡时的不到六成。

苏晚从他沉默里读到了答案。她把窄身剑从剑台上拿起来——把剑柄上那九条剑穗一根一根地盘在手指上——然后她做了决定:

"这一世——今天——我们开天门。不开全部——只开过渡区。因为你说过你每次等我都不觉得苦——但我知道那不是真的——所以这一世我至少要把你带进天门里面——哪怕只是过渡区——哪怕只有五天——也要让你在天门里面——不是在外面——看着我。"

白谪收到这个决定后在空中用灵鉴屏快速计算了一组数据:"天门初阶开启预计概率——林牧的仙元存量——加上苏晚的鸾凤离火——双人共振强度超过阈值——但真仙试炼门的通过概率在当前条件下仍为'远低于安全线'——你们确定要只开过渡区？"

两人同时答:"开。"

白谪在瑶台上布了天门初阶的开启阵法。这不是完整的飞升典礼——那种需要召集修仙界长老和观礼者的正式仪式只能用于通过完整真仙试炼——这只是过渡区的初步开启——规模小得多——只需一面灵鉴屏和一对共振剑台。

剑台是白谪用仙界灵石临时搭的——两块对立的青灰色石板，每块前方插着两人各自的本命剑。苏晚的金火剑插在北台——林牧的窄身剑插在南台。两柄剑在阵中自动发出相互感应的光——金火剑的光这次不是纯金色——而是鸾黄色——窄身剑的光依然是银色带微青——两道光在阵中央的灵石核心交汇——形成了一道往上升的淡金色光柱。

光柱接触到云端时——云层开始从中裂开。最初只是一道细缝——像眼皮睁开时的第一线视觉——然后缝逐渐扩大——露出了云层后面——不是天——是一道门。门不大，大概只有正常人家的房门大小——呈拱形——门框是半透明的淡金色材质——上面刻着流动的上古符文。门框上没有门板——门洞里面是空的——但在空的空间里能看到极细微的光粒在缓慢流动——像无数颗被风吹散的星尘在悬浮。

这就是天门初阶。凡间修士用合道巅峰之力能打开的最高层次的过渡入口。

苏晚看着那道门——她的心跳加快了——不是因为紧张——是因为那道光柱正把她的剑穗照得发亮——那条变成鸾黄的第九条剑穗在光中随着风轻轻晃动——幅度很小，她能感觉到剑穗上每一根编织线在风里的张力——那种张力像是在牵着她的一根极细的线——从凡间到那道门——中间隔着她九世以来所有没走完的路。

林牧站在她身边——他也在看那扇门。几百年前——他是从那道门降下来的——当时他是被逐出仙界的堕落真仙——从空中直接坠向地面——没有剑台——没有阵法——只有风和割脸的风——硬砸在秦岭的乱石和枯草上。那时他抬头看——天门在背后合拢——金光收缩成一条缝——然后消失。他用手抹去脸上的血——站起来——对着空无一人的荒山说了第一句话:"苏晚——你在哪里。"

现在他站在同一道门的下面——不是一个人——是和苏晚并肩站着——她要带他重新走过这道门。不是坠落——是上升。

白谪启动了阵法的最终牵引——两柄剑在剑台上同时发出合璧剑鸣——然后天门初阶的门洞从内部亮了起来——不是被照亮的——是它自己醒了——门洞里的星尘开始加速流转——从门洞中伸出一道金丝编织的牵引束——缓慢地——往下降——降到剑台前方——形成一个可步行的斜桥。

"踏上去——你们就进入了过渡区——"白谪的声音在灵鉴屏的传音频道里——"迎仙台就在桥的终端——过渡区可容纳时间为五个凡间日——五日内若无法开启真仙试炼门——门自行合拢——你们必须从原路退回。一旦离开过渡区——天门将自动判定本次开启为'未完成'——鸾凤离火休眠——需等待下一世的完整轮回周期。"

苏晚和林牧站在斜桥的起点。她把他的窄身剑从南剑台上拔起来——递给他——他把她的金火剑从北剑台上拔起来——递给她——然后两人同时踏上斜桥。

脚踏上斜桥的瞬间——苏晚的脚下传上来一种她从未有过的感觉——不是踩在实地上——是踩在"时间的表面"。每一层金丝上附着微量的回忆能量——她走过第一阶时感受到第一世的阳光——青云宗后山她等林牧御剑落下那天早晨的日头很猛——她记得自己用手遮着眼睛看他从天空的轮廓线上出现。她走过第二阶时闻到第二世茶铺里老茶叶的潮味——第三阶是海风咸腥——第四阶是暴雨打在破庙瓦片上的鼓点——第五阶是铜香炉里老檀香的残味——第六阶是铜镜冰凉的镜背贴着手心的触感——第七阶是瑶台初雪——第八阶是他把剑痕边缘从毛糙打磨到圆润时剑脊发出的金属柔吟——第九阶是鸾黄——不是任何感官——是一种从视觉入魂的暖——她在这阶上停了最久——耳边响着剑穗上的鸾黄穗子在风中发出的几乎听不到的相碰声。她低头看自己的手心——第九条剑穗像一根延伸的灯塔线在空中慢慢飘正在轻轻拽动——这力量非常细微——并不致拉回她——反而在提示她的方向是对的。

桥的终端是迎仙台。那是一座悬浮在过渡区虚空中的小型平台——不大——面积只有一间茶室大小——台面用半透明的星云石铺成——从台上往下看——能看到凡间的昆仑山脉像一幅被铺在无限下方的淡淡青墨——能看到云海在极远的下方翻滚——像是在看另一个世界的地图。迎仙台上只有一个最基本的灵力循环系统——维持着可呼吸的空气和正常的气压。没有仙界该有的浓密灵雾——没有仙果树——没有云上走廊——只有一台小型灵鉴终端挂在台边的玉柱上——屏幕上闪烁着一行字:

"迎仙台——晚牧居调用中——当前状态：过渡区驻留——权限:临时性。驻留时限:剩余四日二十三时辰。真仙试炼门——当前不可开启——原因:需要双人完成灵魂交融第二层及第三层后解锁。"

苏晚走到玉柱前——看着屏幕上"不可开启"四个字。她没有失望——因为她在上来之前就知道会是这个结果。鸾凤离火只够打开第一道门——后面的两道需要灵魂交融剩余的两层——而这两层不是能急的东西。

她转过身——看着林牧:"我们虽然在过渡区里有不到五天——你说的——'每一次等待都是一个回家'——现在我把你带进过渡区——离仙界只差最后一步——不是天上——但已经不是地下了。你摔下来的地方——我们正向上了。下辈子——我把最后两扇门也推开。"

林牧站在迎仙台边——往下看——他的目光落在凡间层层云海下方——那个方向是秦岭。几百年前他从天空被逐落——经过这同一个地方——当时他还没停就直接往下掉——迎仙台对于当时的他只是一个在眼角一闪而过的灰平台。现在他站在这个平台上——她站在他旁边——他从这看着凡间——看到了赤霄旧址的方向。

"好——下辈子——我们一起推最后两扇门——你不是一个人——我也不是。我带你飞升——你带我回家。"他把窄身剑的剑穗在迎仙台玉栏上轻轻拍了一下——九条剑穗在过渡区无风的静止空间中全部垂成一排——最旧的是近乎透明的浅金——最新的是鸾黄——它们在无重力环境下不再飘荡——只是静静地并排垂着——像一件穿了几百年的旧衣服上不同年代打上的补丁——密——暖——还完整。

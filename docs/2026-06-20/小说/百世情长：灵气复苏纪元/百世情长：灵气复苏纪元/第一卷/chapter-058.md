# 第58章 招揽与拒绝

星期六早上九点，有人在敲林牧公寓的门。

不是苏晚——苏晚周末一般不找他，她周六通常会睡到十点半然后起来洗衣服。也不是赵磊——赵磊敲门的方式是用手背砸三下，节奏又快又重。这个门是手指关节敲的，笃、笃、笃——三声之间间隔均匀，力度稳定，透着一股被规训过的礼貌。

林牧打开门。

门外站着两个人。一男一女。男的大概三十出头，寸头，身材结实，穿一件深蓝色的POLO衫，领子扣到从上往下数的第二颗。女的一身黑色的职业套装，长头发束成一个很高的马尾。两人都站得笔直——不是军人那种绷紧的直，是练习了某种身体养护方式之后形成的习惯性的直。

"林牧先生。"男的先开口。他的声音很稳，和敲门声的节奏一模一样。"冒昧打扰您。我是龙虎山修道院教务处的负责人，姓严。这位是我的同事陈老师。"

林牧没有回答。他站在门框里，穿着一件旧T恤，手里还拿着一杯没喝完的黑咖啡。

"可以耽误您十分钟吗。"严老师说。

"你们怎么找到我的。"

"我们内部有一个灵气亲和度数据库。"陈老师——那个女老师——替他回答了。她的用词精准而克制。"您的灵气亲和度检测结果是D级。这个分数——"她停了一下，像是在重新评估应该说得有多直接。"——其实不准确。我们后来发现，某些高灵亲和度的人在测试的时候会因为肉身保护机制产生"伪装损耗"，导致实测结果低于实际水平。需要进一步确认。"

"你们确认了吗。"

"还没有。所以我们来了。"

林牧看了他们一眼。然后让开了门口。"进来吧。"

两个人走进出租屋。陈老师扫了一眼房间——茶几上摊着一本发黄的线装书，窗台上放着一个鱼缸，缸里一条锦鲤正用一种极不友善的眼神看着这两个陌生人。客厅里没有沙发——只有两把折叠椅。林牧让她们坐，把鱼缸往窗台角落里推了一点。

"您最近的身体状况——"陈老师用目光审视了一下林牧的肤色和精气神。"——明显不是一个D级的普通人。普通人的气血在灵气环境下是往内收的。您的是往外撑的。这个差距——我们龙虎山有仪器可以测量。"

"你们不是来测我灵气亲和度的。"林牧把咖啡杯放在茶几上，在旁边那把没坐人的折叠椅上站住。

"对。"严老师接过话。他的语气比陈老师更直接。"灵气复苏之后，国家把灵异事务相关的管辖权限下放到了我们几大门派——龙虎山、茅山、峨眉、昆仑、终南山。每个门派负责自己辖区内的一些重要事务。其中之一就是发现和吸收潜在的高素质修炼人才——不叫招募。叫定向培养。"

他从口袋里掏出一只很小的信封。信封里是一张身份证大小的卡片——卡片正面印着"龙虎山修道院"，背面印着一行小字："国家特殊人才灵气修炼定向培养计划——零期"。零期意味着第一批。是一个新成立的项目。成立时间大概不到两周。

"这个项目旨在为后续国家灵气安全体系的建设储备人才。"陈老师说。"定向培训期间所有费用由国家承担。培训结束之后直接进入国家设立的灵气管理部门——可能是新成立的部门，也可能是各门派派驻在各级政府的联络处——具体岗位待定。"

"您将获得一整套系统化的功法教学。包括筑基类、丹道辅助类、符箓和阵法基础知识。"严老师把另一张折叠的资料页递过来——上面密密麻麻地印着课程名称和各类校规。"讲师来自全国各大道门门派兼任。结业后的修士等级认证将直接对接国家新的职称系统。"

林牧把资料页接过来，从头到尾看了一遍。课程名称全是新的——但内核他知道。那些"灵气疏导方法"就是导引术，"灵能控制技巧"就是灵气操控，"意识和身心训练"就是冥想法。全是把修仙界几千年不变的常识翻译成了合规的现代培训术语。

他把资料页放回桌上。

"谢谢。但我拒绝。"

陈老师愣了一下。严老师没有——只是把脸偏了一下，似乎在确认自己有没有听错。

"您没有在考虑吗。"陈老师说。"这个项目的入选条件非常严格——全国也只选了两百个人。您放弃了这一次，短期内不会有同等规模的其他项目——"

"我知道。"林牧说。"我不是在犹豫。我是在回答您的问题。我不参加。"

"为什么。"严老师的语气里没有恼怒——是真切的困惑。这个项目给的待遇——免费培训、国家发工资、学完直接进入体制、有职称有地位——任何人都找不出理由拒绝。除非这个人有不希望被国家关注的原因。

"因为我有一份工作。"林牧说。"我现在有合同。有项目经理。有每个月的房贷。有每天早上要在九点钟之前打卡的工位。我如果去参加你们的培训——这些就没有了。"

"但是——"陈老师把手摊开。"您是修仙者。潜力比这里的任何一份工作都要高得多。您在办公室敲键盘——对不起我冒昧——可那是浪费您的资质。"

"那是我的生活。"林牧说。"我选择留下来。"

"为国家效力——对抗灵气时代的新型威胁——保护普通人——您不觉得这更有意义。"

"有意义。但不是我唯一的义务。"林牧站起来，走到窗边，拉开窗帘。窗外的行道树枝叶繁茂，阳光从叶缝里漏下来。远处能看见那栋老居民楼的五分之一轮廓。他能从四楼那扇换了浅色窗帘的玻璃上辨认出一点微弱的反光——那是阳光打在窗户玻璃上的正常的反光。

他转过身。"我的能力——如果我有的话——不是用来在系统里做事。是有一个人在旁边。如果我去龙虎山了，她的灵气病发作的时候，谁在。"

陈老师和严老师交换了一个目光。不是被感动——是被某种更深的、属于他们的训练体系无法计算的东西卡住了。他们的流程里有筛选标准，有测试评分，有一整套可以量化的招募逻辑。但没有一样是针对这个回答的。他们考虑过的是"怕影响当前收入"、"家庭反对"、"不懂修仙是什么"。考虑过几十种情况。唯独没考虑过"我不去不是因为不爱国——是因为有一个人需要我在旁边"。

"您说的那个人——"陈老师小心地问。"是您的家人。"

"不是家人。但比家人早。"林牧说。

这句话两个人都没听懂。但他没有再解释。

严老师看了一眼手表，站起来。"尊重您的选择。但龙虎山的门是一直开着的——如果未来任何时间您改变主意，可以直接联系我们。联系方式在后面。"

"好。"

陈老师站起来的时候看了他最后一眼。不是审视——是某种更接近"好奇"的表情。然后两人一前一后走出了出租屋。门在他们身后咔嗒一声合上。

下午三点。林牧工位上的黑咖啡准点出现。便签纸上写着:"上午没看见你。请假了吗。"

他回复:"有点事。下午在。"

三点零五分。她拿着保温杯经过他工位的时候，把一块刚买回来的热蛋挞放在咖啡旁边。"刚才路过蛋糕店买的。趁热吃。今天热。"

蛋挞的皮很酥。他在工位上咬着蛋挞，看着窗外那层蓝得越来越浓的天空。他想起严老师那双诚恳而困惑的眼睛——"不参加多遗憾"。不遗憾——他在心里对自己说。他在前世已经参加过太多"更值得"的事。他参加过仙魔大战、参加过九天试炼、渡过了合道天劫——每一样都比龙虎山修道院"更重要"。但后来他回头想的时候，最后悔的不是因为没有参加这些事。最后悔的是——他花了太多时间在这些"更重要"的事上，而跟她坐在石门前的石阶上说话的次数太少了。

这一世他只想做好一件事。守着她。不是守着她活——是守着她走完这一世的每一步。从淬体，到筑基，到金丹，到她不需要他了的那一天。如果那一天不来——他就永远守下去。

傍晚。他去了苏晚的公寓。这几天他已经开始正式引导她做第一次引气入体——不是教她呼吸节奏，是直接用他的灵识引导她的灵气走完一个完整的周天。苏晚闭着眼睛盘腿坐在客厅的地板上，他坐在她身后，一只手轻轻贴在她的后背上——大椎穴的位置。他的灵气从指尖渗入她的经脉，带着她身体里散落的那些灵分子沿着正确的路线走。

一圈。两圈。第三圈的时候苏晚的小腹位置忽然涌起一丁点热度。她疼得抽了一口气——不是痛。是烫。从丹田深处涌出的一小股热流沿着脊柱上行——上到一半又返回丹田。那是一个微小的周天的雏形。

"不要紧张。让它自己走。"他轻声说。"你不要控制。控制就会断。"

苏晚深呼吸，放松肩膀。那股热流重新从丹田出发——慢慢的，一点一点的，走到大椎，走到百会，走到印堂，往下走了膻中，最后回到了丹田。

一个完整的周天。

她睁开眼睛。眼睛里泛着一层极薄的水光——不是泪。是第一次引气入体成功后身体自动分泌的生理性泪液。

"我感觉到了——这里面——真的有东西在转。"她把手按在小腹上，脸转过来看着林牧，那个表情不再是困惑、不再是恐惧——而是一种终于抓住了某个实证之后的雀跃。

"我以后可以自己练。"

"嗯。"

"你以后不用每天来帮我——"

"要。"林牧说。

"为什么。我可以自己——"

"不是帮。是我来。"

苏晚看着他。手里的保温杯热气升起来模糊了半张脸。然后她嘴角往上翘了一点点——不是完整的月牙笑。是含蓄的、自觉的、承认了什么之后的笑。

"那你来。"她说。

窗外那层淡蓝色的那个透明的薄纱，在夕阳中被染成了金粉色。

这一刻——林牧想——他并没有拒绝龙虎山的邀请。他只是选择了他本来就应该在的位置。

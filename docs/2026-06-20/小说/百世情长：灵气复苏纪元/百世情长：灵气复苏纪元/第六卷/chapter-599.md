# 第五百九十九章 百世情长——永不完结

晚枫谷的深夜极其安静。苏晚躺在内室的木榻上看着窗外满天的太虚星斗。林牧在旁边已经闭上了眼——但功德绳还在闪，说明他在半睡中仍然保持对她的低度通灵。她把功德绳轻轻卷在指间——金线的微光将每一道细小脉搏传到她指腹。这就是他们之间最终的通讯方式——不需要语言不需要符号。只需要这条绳子还在。从来都在。

她闭上眼睛。但她的意识没有停下来——她在回忆从第一世到今天的所有。石桥上落水的绣盒。城墙洞里互相捂着的冻脚。灯市里被打碎的面具。豆腐摊蒸笼掀开时升腾的白雾。悬崖上那封没写完的信。炼丹炉前被烧伤的手掌。龙墓中并肩共振的那束金线。太虚塔顶全塔第一。木牌背面从"以后"到"够了"到"继续"。功德绳上从两根到六根。冰晶草从第一片到第十二片再到六颗种子。一万年。一百次遇见。每一次的最后都是同一句话:"以后见你。"每一次的新开始都是同一句话:"我在这里。"

她睁开眼睛时看到功德绳的金线在微微跳动——不是她自己心跳，是林牧的。他在梦中以极低极柔极慢的频率在功德绳上写下了他今晚唯一的一句话。不是用语言——是把他的灵核表面温度调到了和她完全一致的度。用温度替代文字。她感觉到了。她以自己灵核表面温度也回传了同样的度。两度完全相同。然后两个人都睡着了。功德绳在暗夜中持续地闪着极缓极远极暖和的金光。

早晨来了。晚枫谷的鸟鸣和山泉一如既往地准时。苏晚在厨房里煮手擀面——今天的面加了昨天剩下的松木熏豆干碎末。林牧在后院劈新木柴——今天的松木比平时粗，但他劈得依然轻松。她从厨房探头看了他一眼。他劈完最后一根后抬起头正好对上她的眼。他的斧子在空中停了下——不是劈不动，是看到她在窗口，就停了一息。功德绳传来的不是"早上好"，是:"今年面里那个熏豆干碎末比昨天加得多——因为昨天你说味道太淡了。"

她笑着把面条捞起来沥干，分两碗。筷子两双并排放好。然后她在小餐桌上方的窗玻璃上用指尖以微弱的灵气写下了四个字——"百世情长。永不完结。"写完她把手缩回来放到自己的碗边。

林牧洗完手后走进来看到她留在窗上的字。他没擦。他用筷子的尾端在下方极轻极轻地加了一行回应:"不够。继续。以后等我。"

（第五百九十九章 完）

# 第十五章 辞职信与修炼梦

星期一早晨，林牧走进公司的时候，前台的位置空着。

平日里那个总是化着精致妆容、见人就笑着打招呼的前台姑娘——林牧甚至没记住她的名字——今天不在。他起初以为是迟到，但经过她工位的时候，发现桌面上干干净净，连那张摆了好几年的招财猫都不见了。

茶水间的公告栏上贴着七张打印纸。

不是人事部的通知。是辞职信。七个人，手写的，有的只有三五行，有的写满了一整页。林牧端着杯子，一张一张看过去。

第一张是技术部的张工，四十二岁，在公司做了八年。他的辞职信只有四行字："我听到了一种声音。不是耳鸣。我要去找它。"

第二张是产品部的小周，去年刚毕业，辞职信写得很有逻辑，足足列了三条理由，但林牧一个字都没读进去，因为他已经看到了第三张。

第三张是市场部的老白。他写了整整一页纸的文言文，大意是说自己夜观天象，发现紫微星移位，天下将变，他要回去继承祖上传下来的风水术。

老白平时是部门聚餐时讲段子的那个。

第四张是运营部的一个女孩，写得很平淡，说家里有事要回乡下。但林牧注意到落款日期是上周五，而那天中午他还看见她在楼下便利店买三明治。

第五张。

第六张。

第七张只有两句话："去终南山。那边有灵气。"

落款是陈见深——UI设计组那个从来不在开会时说话的年轻人。他大概二十七八岁，戴黑框眼镜，每天准时上下班，工位上的电脑永远开着三个界面：Photoshop、Figma，和一个写满看不懂公式的记事本。

林牧把陈见深的那张纸揭了下来。

背面还写着字。

字体很小，笔迹很稳，像是思考了很久才落笔："林哥，如果你也感觉到了——就是每天早上醒来的时候，空气里那种东西，像碎玻璃一样扎在肺部——你就知道这个世界不会跟以前一样了。我先走一步。后会有期。"

林牧把纸折好，放进口袋。

回到工位的时候，走廊里比平时安静了一半。不是没人说话——留下来的人也在讨论。财务部的刘姐靠在门框上，压低了声音跟旁边的同事说："我儿子说他们学校体育老师上周走了，说是要去武当山。"另一个同事回应："我表妹也辞了，说要去云南。"

林牧打开电脑，屏幕亮起来。

他盯着登录界面的壁纸看了很久——那是公司去年团建的集体照。照片里的人他认出多少？走了七个，剩下的面孔也在变模糊。

他输入密码，登录系统。桌面上还躺着上周没改完的代码。

bug report 还在那里，需求文档也在那里，项目经理在群里发了新的排期表。一切都跟以前一样，但又全都不一样了。

林牧忽然想起小时候看过的一个动画片。蚂蚁在洞里住着，有一天有一只蚂蚁抬头，看见了天空。那只蚂蚁什么都没说，只是从洞里爬了出来，朝着一个方向走。其他蚂蚁问它去哪，它没有回答。

它不知道要去哪。

它只是知道必须走。

中午吃饭的时候，食堂空了小半。

林牧端着餐盘坐到窗边，对面是销售部的赵磊，来公司三年，业绩中上，从不迟到，从不早退。

"你也感觉到了吧。"赵磊没抬头，用筷子拨弄着盘子里的青菜。

"什么。"

"别装了。"赵磊抬起头，他的眼睛有点红。不是哭的红——是熬夜的红。"我每天晚上都在楼顶打坐。你真信那个什么灵气是假的？网上那些视频你看过了吗——云南那边有个农民，赤脚踩在田埂上，脚下的稻子一夜之间长高了三尺。还有武当山的视频，一个道士用树枝在石头上写字，写完了树枝嵌进去三寸。"

"树枝嵌石头不科学。"

"上个月你说的话。"赵磊笑了一下，那个笑容比哭还难看。"上个月你还说，地底下有灵气渗出来这种谣言过俩月就散了。现在呢？七封辞职信。"

"你把辞职信也写好了？"

赵磊没说话。他从口袋里摸出一张叠得整整齐齐的纸，展开。落款是他的名字，时间和陈见深那张一模一样——上周五。

"我还没交。"赵磊把纸叠回去，放进口袋。"我妈住院，我要是现在去修仙，她医药费谁出。"

食堂里沉默了很久。

窗外的天空灰蒙蒙的。不是雾霾——林牧知道不是。那种灰色里掺杂着一丝极淡的蓝色，像水底的气泡在往上冒，偶尔能看到有一缕光从里面漏出来，但很快就会消失。

灵气的颜色，据说是蓝的。

前世修仙界的常识：灵气浓郁之处，空气会呈现氤氲淡蓝，那是对修行最有利的环境。

林牧握紧了筷子。

前世。他到现在都不确定那些碎片到底是梦，还是某种精神分裂的前兆。但身体不会说谎——他每天早上醒来的时候，丹田位置会有一种隐隐的胀感。像是有什么东西在里面生根发芽，想要破土而出。

他前世是修仙者。

那个念头越来越清晰了。

不只是修仙者。他在那些碎片里看见过自己站在极高的地方，脚下是云海，身后是宫殿。有人叫他"大师兄"。有人说"青云宗第一天才"。有人说"林牧"——不是这个名字，但那就是他。

"林牧？"

赵磊在叫他。

"嗯。"

"你有没有梦到过什么奇怪的东西。"

林牧抬眼看他。

"我梦见过一把剑。"赵磊说。他的声音很低，像是在自言自语。"黑色的，剑身上面有裂纹，但裂纹里面往外冒光。我拿起来的时候特别顺手，就好像那把剑以前就是我的。"

"你拿到过吗。"

"每次刚要拿稳，就醒了。"赵磊扯了扯嘴角。"醒了就睡不着，躺着盯着天花板，觉得有什么东西在脑子里敲——咚咚咚，像钟声。"

林牧没有接话。

他站起来，把餐盘端去回收处。经过赵磊身边的时候，他停了一下。

"先别辞职。"

"啊？"

"等。至少等两周。"林牧说。他不知道自己为什么这么说，但他觉得这个建议是对的。"两周之内会有变化。到那时候再决定。"

赵磊看着他，嘴巴张了张，最终什么都没问。

下午两点，人事部发了一封全员邮件。措辞平淡："近期公司人员流动较大，请大家保持正常工作节奏，勿传播不实信息。"

发件人是苏晚。

林牧看着那个名字，停了两秒。

苏晚。财务部的。去年秋天入职，负责薪酬核算和人事对接。短发，眼睛很亮，说话声音不大但很清楚。普通得不能再普通的女孩——如果非要说什么特别的，就是她的笑容。

不是漂亮。是那种让人看了心里会安静下来的笑容。

林牧想起前世碎片里的那个女子。白衣，站在很高很高的地方，回头对他笑。那个笑容和苏晚的笑容重叠在一起的时候，他的心脏会疼。

不是比喻。是真的疼。

沉闷的钝痛，从胸口中央扩散开来，像有什么东西在试图从里面敲开这道门。

他关掉邮件，打开代码编辑器。

手指落在键盘上的时候，他忽然意识到一件事——他的手比以前稳了。不是肌肉控制力的变化，是一种更深的稳定。就好像有人在身体里装了一根钢轴，从头贯穿到脚，让他可以稳稳地扎在任何地方。

灵气对他也在起作用。

但他没有辞职。

不是因为不想走。是因为他还没想清楚该去哪。陈见深去了终南山。老白回了老家。那个前台姑娘不知道去了哪里。

而林牧还坐在这里。

不是因为迷茫。是因为他在等——等那些记忆碎片拼到一起。等他知道自己是谁。等他能配得上"青云宗第一天才"这个称呼的时候。

他需要变强。

不只是恢复前世的修为残影。是在这个灵气刚刚复苏的地球上，从零开始，完成一次真正意义上的修炼。淬体、筑基、金丹——前世曾经走过的路，他要重新走一遍。

而且这次，他不再是一个人。

苏晚。

林牧的手指在键盘上停下来。他不知道苏晚和那个白衣女子之间到底是什么关系，但他知道一件事：如果"下一世"是真的，如果"我还会来找你"是真的——那么找到那个人，是他的第一优先级。

下班的时候，走廊里只剩三五个人。

林牧经过茶水间，看见陈见深留下的那张公告栏。七张纸已经被清理掉，但痕迹还在——被图钉扎过的小孔，排列成一条歪歪扭扭的线。

他走出大楼。

城市的夜空还是那样，霓虹灯混杂着路灯，把星星遮得七七八八。但林牧眯起眼睛，发现有一层极淡的蓝色氤氲，正悬在那些灯光的上面，像一个倒扣的碗，在缓慢地呼吸。

灵气潮汐。

前世知识告诉他，灵气的浓度不是稳定的——它有周期，有涨落。此刻正在涨。

林牧深吸一口气。

空气里夹着的东西不再像碎玻璃了。像薄荷。凉凉的，从喉咙蔓延到肺部，再沿着某条看不见的线沉入丹田。

丹田位置传来微微的温热。

淬体。第一重。

他低着头笑了一下。不是开心的笑。是那种——等了很久，终于等到了——的笑。

回到出租屋，林牧打开电脑。不是写代码。是写日记。

他新建了一个文档，标题打上去删掉，又打上去又删掉，最后留了一行字：

"第15天。确定了一件事：这个世界在变。我是被选中的人之一。"

他停了一下，又加了一行：

"苏晚。我会记得你。"

屏幕的光映在他脸上。窗外的城市灯火通明，蓝色的氤氲又厚了一层。

那些辞职的人，他们去了终南山，去了武当山，去了云南，回了老家，去了不知道什么地方。每个人都有自己的路要走。

而林牧的路，还没有出发。

但快了。

他关掉文档，躺到床上。

闭上眼睛之前，他想起陈见深写在纸背面的那句话："如果你也感觉到了——"

感觉到了。

而且很清楚——这个感觉，前世就开始了。
